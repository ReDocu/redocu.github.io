### 3-2. 타일 속성

**왜 필요한가** — 타일의 "그림"과 "규칙"은 다르다.

```
   타일 인덱스 = 어떻게 보이는가 (그림)
   타일 속성   = 어떻게 동작하는가 (규칙)
```

```cpp
// Common/TileAttribute.h
enum TileAttr : uint8_t
{
    ATTR_NONE     = 0,
    ATTR_WALL     = 1 << 0,        // 통과 불가
    ATTR_WATER    = 1 << 1,        // 느려짐
    ATTR_DAMAGE   = 1 << 2,        // 데미지
    ATTR_SLIPPERY = 1 << 3,        // 미끄러움
    ATTR_TRIGGER  = 1 << 4,        // 이벤트 발동
    ATTR_LADDER   = 1 << 5,        // 사다리
    ATTR_HIDDEN   = 1 << 6,        // 숨겨진 통로
};
```

```
   ★ 비트 플래그를 쓰는 이유

   한 타일이 여러 속성을 동시에 가질 수 있다

   ATTR_WATER | ATTR_DAMAGE      →  용암
   ATTR_WALL  | ATTR_HIDDEN      →  숨겨진 벽

   uint8 하나로 8가지 속성
```

```cpp
    // 검사
    bool IsWall(const Tile* t)  { return t && (t->attribute & ATTR_WALL); }
    bool IsWater(const Tile* t) { return t && (t->attribute & ATTR_WATER); }

    // 설정
    t->attribute |=  ATTR_WALL;                // 켜기
    t->attribute &= ~ATTR_WALL;                // 끄기
    t->attribute ^=  ATTR_WALL;                // 토글
```

**이동 비용**

```cpp
int GetMoveCost(const Tile* t)
{
    if (!t) return -1;                         // 맵 밖
    if (t->attribute & ATTR_WALL)  return -1;  // 통과 불가

    int cost = 1;

    if (t->attribute & ATTR_WATER)  cost = 3;
    if (t->attribute & ATTR_LADDER) cost = 2;

    return cost;
}
```

> **이 이동 비용이 Day 62(다익스트라)의 입력이 된다.**

### 3-5. 타일 렌더링 (게임)

**왜 필요한가** — 툴과 게임의 렌더 요구가 다르다.

| | 툴 | 게임 |
|---|---|---|
| 격자 | 표시 | 안 함 |
| 빈 타일 | 체커보드 | 안 그림 |
| 속성 | 오버레이 | 안 보임 |
| 최적화 | 덜 중요 | **중요** |
| 레이어 | 선택적 표시 | 전부 + 순서 |

```cpp
void TileMapRenderer::Render(Renderer& r, const TileMap& map,
                             const TileSet& ts, const Camera2D& cam,
                             int layerFrom, int layerTo)
{
    int minC, minR, maxC, maxR;
    CalcVisibleRange(map, cam, &minC, &minR, &maxC, &maxR);

    for (int L = layerFrom; L <= layerTo && L < map.GetLayerCount(); L++)
    {
        for (int row = minR; row < maxR; row++)
        {
            for (int col = minC; col < maxC; col++)
            {
                const Tile* t = map.At(L, col, row);
                if (!t || t->tileIndex < 0) continue;      // ★ 빈 타일은 건너뛴다

                double wx, wy;
                map.TileToWorld(col, row, &wx, &wy);

                double sx, sy;
                cam.WorldToScreen(wx, wy, &sx, &sy);

                ts.Draw(r, t->tileIndex, (int)sx, (int)sy,
                        (int)(map.GetTileW() * cam.GetZoom()));
            }
        }
    }
}
```

### 3-6. 타일 충돌

**왜 필요한가** — 벽을 통과하면 맵이 의미가 없다.

```cpp
bool TileCollision::CanMoveTo(const TileMap& map, double wx, double wy)
{
    int col, row;
    map.WorldToTile(wx, wy, &col, &row);

    const Tile* t = map.At(1, col, row);       // 지형 레이어

    if (!t) return false;                      // 맵 밖
    if (t->attribute & ATTR_WALL) return false;

    return true;
}
```

**캐릭터 크기를 고려한 검사**

```cpp
bool TileCollision::CanMoveBox(const TileMap& map,
                               double x, double y, double w, double h)
{
    // 네 모서리를 검사
    double corners[4][2] = {
        { x,     y     },
        { x + w, y     },
        { x,     y + h },
        { x + w, y + h }
    };

    for (int i = 0; i < 4; i++)
        if (!CanMoveTo(map, corners[i][0], corners[i][1]))
            return false;

    return true;
}
```

```
   ★ 네 모서리만 검사하면 되나?

   캐릭터가 타일보다 크면 중간이 빠진다

   ┌──────────┐
   │ ●    ● │        ← 모서리는 통과 가능
   │    ▓▓    │      ← 중간에 벽이 있어도 못 잡는다
   │ ●    ● │
   └──────────┘

   ★ 캐릭터가 타일보다 작으면 모서리만으로 충분하다
     크면 범위 전체를 검사한다
```

**축 분리 이동 — 벽을 따라 미끄러지기**

```cpp
void Player::MoveWithCollision(double dx, double dy, const TileMap& map)
{
    // X축 먼저
    if (CanMoveBox(map, m_x + dx, m_y, m_w, m_h))
        m_x += dx;

    // Y축 따로
    if (CanMoveBox(map, m_x, m_y + dy, m_w, m_h))
        m_y += dy;
}
```

```
   ★ 축을 분리하는 이유

   합쳐서 검사하면:
     대각선으로 벽에 부딪히면 완전히 멈춘다

   분리해서 검사하면:
     X는 막히고 Y만 이동  →  벽을 따라 미끄러진다  ✔

   ★ 대부분의 2D 게임이 이렇게 한다
```

```cpp
void Player::Update(double dt)
{
    Input& in = m_core->GetInput();

    double ax = 0, ay = 0;
    if (in.IsKeyPress(VK_LEFT))  ax -= 1;
    if (in.IsKeyPress(VK_RIGHT)) ax += 1;
    if (in.IsKeyPress(VK_UP))    ay -= 1;
    if (in.IsKeyPress(VK_DOWN))  ay += 1;

    // 대각선 정규화
    if (ax != 0 && ay != 0) { ax *= 0.707; ay *= 0.707; }

    double dx = ax * m_speed * dt;
    double dy = ay * m_speed * dt;

    MoveWithCollision(dx, dy, *m_map);         // ★ 축 분리
}
```

void GameScene::CalcTileStats()
{
    memset(m_attrCount, 0, sizeof(m_attrCount));
    m_passableCount = 0;

    for (int r = 0; r < m_map.GetRows(); r++)
    {
        for (int c = 0; c < m_map.GetCols(); c++)
        {
            const Tile* t = m_map.At(1, c, r);
            if (!t) continue;

            if (!(t->attribute & ATTR_WALL)) m_passableCount++;

            for (int i = 0; i < ATTR_INFO_COUNT; i++)
                if (t->attribute & g_attrInfo[i].flag)
                    m_attrCount[i]++;
        }
    }
}
