## ③ 개념 설명

### 네 가지 기본 지표

| 지표 | 수식 | 단위 | 범위 |
|---|---|---|---|
| **MAE** | `mean(|y - ŷ|)` | 원래 단위 | 0 ~ ∞ |
| **MSE** | `mean((y - ŷ)²)` | 단위² | 0 ~ ∞ |
| **RMSE** | `√MSE` | 원래 단위 | 0 ~ ∞ |
| **R²** | `1 - SSE/SST` | 없음 | **-∞ ~ 1** |
| **MAPE** | `mean(|y - ŷ| / |y|) × 100` | % | 0 ~ ∞ |

### ① MAE — 평균 절대 오차

```
MAE = (1/n) Σ |실제 - 예측|
```

| 장점 | 단점 |
|---|---|
| **단위가 원래 값과 같음** → 설명이 쉬움 | 큰 오차를 방치할 수 있음 |
| **이상치에 강함** | 0에서 미분 불가 (학습 시) |
| **중앙값을 추종** | 구간마다 상대적 중요도를 반영 못 함 |

**"평균 3,200원씩 빗나갑니다"** — 비전문가도 이해합니다.

### ② MSE / RMSE — 큰 오차에 더 큰 벌점

```
MSE  = (1/n) Σ (실제 - 예측)²
RMSE = √MSE
```

**오차별 기여도**

| 오차 | MAE 기여 | MSE 기여 | 비율 |
|---|---|---|---|
| 1 | 1 | 1 | 1× |
| 2 | 2 | 4 | 2× |
| 5 | 5 | 25 | 5× |
| 10 | 10 | 100 | **10×** |
| 100 | 100 | 10,000 | **100×** |

**오차가 k배 커지면 MSE 기여는 k배 더 커집니다.**

**RMSE와 MAE의 관계**

```
항상  RMSE ≥ MAE

RMSE = MAE  →  모든 오차가 동일
RMSE / MAE  →  오차의 불균일도
```

| RMSE/MAE | 의미 |
|---|---|
| 1.0 | 모든 오차가 같음 (이론적) |
| **1.2 ~ 1.3** | 오차가 고른 편 |
| 1.5 ~ 2.0 | 큰 오차가 섞임 |
| **> 2.0** | **극단적 실패가 존재** |

> **RMSE/MAE 비율은 무료로 얻는 진단 지표입니다.**
> [Day 118](day-118.md)의 "두꺼운 꼬리"를 숫자 하나로 요약합니다.

### ③ R² — 결정계수

```
R² = 1 - SSE / SST

SSE = Σ(실제 - 예측)²        모델의 오차
SST = Σ(실제 - 평균)²        평균 예측의 오차
```

**"평균으로 예측하는 것보다 얼마나 나은가"** 를 나타냅니다.

| R² | 의미 |
|---|---|
| 1.0 | 완벽 |
| 0.8 | 타깃 분산의 80%를 설명 |
| **0.0** | **평균 예측과 동일** |
| **음수** | **평균 예측보다 못함** |

**R²가 음수가 되는 경우**

| 상황 | 예 |
|---|---|
| 모델이 학습 실패 | [Day 117](day-117.md) 패턴 ④ |
| **타깃 되돌리기를 잊음** | [Day 115](day-115.md) Step 3의 ⑤ |
| **검증셋의 평균이 학습셋과 다름** | 분포 이동 |
| 상수 예측 (평균이 아닌 값) | 중앙값 예측 등 |

> ⚠️ **R²는 "검증셋의 평균"을 기준으로 계산됩니다.**
> 학습셋 평균으로 예측하는 모델이라도, 검증셋 평균이 다르면 R²가 음수가 될 수 있습니다.
> [Day 108](day-108.md)에서 중앙값 예측의 R²가 -0.0577이었던 이유입니다.

**R²의 함정 3가지**

```
① 특성을 추가하면 R²는 항상 올라갑니다 (학습셋에서)
   → 조정된 R² (Adjusted R²) 사용

② 타깃의 분산이 크면 R²가 높게 나옵니다
   → 서로 다른 데이터셋의 R²를 비교하면 안 됩니다

③ R² 0.85가 "85% 정확"이 아닙니다
   → "타깃 분산의 85%를 설명"입니다. 완전히 다른 뜻입니다
```

**조정된 R²**

```
Adjusted R² = 1 - (1 - R²) × (n - 1) / (n - p - 1)

n = 샘플 수, p = 특성 수
```

**특성을 늘려도 성능이 안 늘면 조정 R²는 떨어집니다.**

### ④ MAPE — 평균 절대 백분율 오차

```
MAPE = (100/n) Σ |실제 - 예측| / |실제|
```

**비율로 보므로 "체감 오차"에 가깝습니다.**

| 장점 | 단점 |
|---|---|
| **단위 무관** — 다른 문제와 비교 가능 | **실제값이 0이면 무한대** |
| 사용자 체감과 일치 | 작은 값에 과도한 벌점 |
| 직관적 ("평균 12% 틀림") | **과대 예측과 과소 예측이 비대칭** |

**0 근처에서의 폭발**

```
실제 1원, 예측 100원   →  |1-100|/1 = 99 → 9,900%
실제 0원, 예측 100원   →  100/0 = inf
```

**비대칭성**

```
실제 100, 예측 200  →  |100-200|/100 = 100%
실제 200, 예측 100  →  |200-100|/200 =  50%
```

**같은 크기의 오차인데 MAPE가 2배 다릅니다.**
**MAPE를 최소화하면 모델이 과소 예측 쪽으로 치우칩니다.**

### MAPE의 대안

| 지표 | 수식 | 특징 |
|---|---|---|
| **sMAPE** | `mean(2|y-ŷ| / (|y|+|ŷ|)) × 100` | 대칭. 0~200% |
| **WAPE** | `Σ|y-ŷ| / Σ|y| × 100` | **가중 평균.** 0에 강함 |
| **MdAPE** | `median(|y-ŷ|/|y|) × 100` | 중앙값. 이상치에 강함 |
| **MASE** | `MAE / MAE_naive` | 나이브 예측 대비 비율 |

**WAPE가 실무에서 가장 안전합니다.**

```
WAPE = 전체 오차 합 / 전체 실제값 합
     = "전체 매출 대비 몇 % 틀렸는가"
```

**0이 있어도 분모가 전체 합이라 폭발하지 않습니다.**

### 지표별 최적 예측값 — 무엇을 추종하는가

**하나의 값으로만 예측한다면?**

| 지표 | 최적 상수 |
|---|---|
| **MSE / RMSE** | **평균** |
| **MAE** | **중앙값** |
| **MAPE** | 평균보다 작은 값 (과소 예측 쪽) |
| MdAPE | 기하평균 근처 |

**[Day 106](day-106.md)에서 배운 것의 확장입니다.**

```
오른쪽 꼬리 분포:  중앙값 < 평균
→ MAE로 학습하면 평균보다 낮게 예측하는 경향
→ MAPE로 학습하면 더 낮게
```

### ★ 로그 변환한 타깃의 지표 해석

**[Day 111](day-111.md)에서 강조한 것을 정식화합니다.**

```python
model.fit(X, np.log1p(y))
pred_log = model.predict(X_val)
```

| 계산 | 의미 | 다른 모델과 비교 |
|---|---|---|
| `MAE(log(y), pred_log)` | 로그 공간 MAE | **불가** |
| `MAE(y, expm1(pred_log))` | **원래 공간 MAE** | **가능** |

**로그 공간 MAE의 실제 의미**

```
|log(y) - log(ŷ)| = |log(y/ŷ)|
```

**로그 공간의 절대 오차 = 원래 공간의 비율 오차의 로그입니다.**

```
로그 공간 MAE 0.10  →  exp(0.10) = 1.105  →  평균 약 10.5% 오차
로그 공간 MAE 0.22  →  exp(0.22) = 1.246  →  평균 약 24.6% 오차
```

> **로그 공간 MAE는 사실상 MAPE와 비슷한 것을 재고 있습니다.**
> **"로그 변환하면 MAE가 좋아진다"는 것은 "비율 오차를 최적화한다"는 뜻입니다.**

### 문제 유형별 지표 선택

| 문제 | 주 지표 | 부 지표 | 근거 |
|---|---|---|---|
| **가격 예측 (넓은 범위)** | **MAPE 또는 WAPE** | MAE, RMSE | 체감이 비율 |
| 가격 예측 (좁은 범위) | MAE | RMSE | 단위가 직관적 |
| **수요 예측 (재고)** | **WAPE** | MAE | 0이 흔함 |
| **안전 관련 (의료 등)** | **RMSE** | 최대 오차 | 큰 실수가 치명적 |
| 물리량 측정 | RMSE | MAE | 정규 오차 가정 |
| **여러 문제 비교** | **R²** 또는 MAPE | — | 단위 무관 |
| 대회·벤치마크 | 주최 측 지정 | — | 지정된 것으로 학습 |

**"가격 예측은 왜 MAE와 MAPE를 함께 보는가"**

```
MAE  : "평균 3,200원 틀림"        → 절대적 크기를 안다
MAPE : "평균 12% 틀림"            → 체감을 안다
둘 다 : "평균 3,200원, 12% 틀림"  → 완전한 그림
```

**하나만 보면 반드시 놓칩니다.**

### 손실 함수와 평가 지표를 맞추기

```
평가 지표가 MAE인데 MSE로 학습  →  최적화 대상이 다름
```

| 평가 지표 | 권장 손실 함수 |
|---|---|
| MAE | **MAE** (또는 Huber) |
| RMSE | **MSE** |
| MAPE | **MAPE** 또는 **로그 타깃 + MSE** |
| R² | MSE (R²는 MSE의 단조 변환) |

> **R²와 MSE는 같은 순위를 줍니다.** (같은 데이터에서)
> ```
> R² = 1 - SSE/SST,  SST는 상수  →  R²를 최대화 = SSE 최소화 = MSE 최소화
> ```
> **따라서 R²로 모델을 비교하는 것과 RMSE로 비교하는 것은 동일합니다.**

## ④ 단계별 실습

### Step 1. ★ 네 지표 직접 구현

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.metrics import (mean_absolute_error, mean_absolute_percentage_error,
                             mean_squared_error, r2_score)

SEED = 42
np.random.seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3


# ═══════════════════════════════════════════════════════════
# 직접 구현
# ═══════════════════════════════════════════════════════════
def my_mae(y, p):
    return float(np.mean(np.abs(np.asarray(y) - np.asarray(p))))


def my_mse(y, p):
    return float(np.mean((np.asarray(y) - np.asarray(p)) ** 2))


def my_rmse(y, p):
    return float(np.sqrt(my_mse(y, p)))


def my_r2(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    sse = np.sum((y - p) ** 2)          # 모델의 오차 제곱합
    sst = np.sum((y - y.mean()) ** 2)   # 평균 예측의 오차 제곱합
    return float(1 - sse / sst)


def my_mape(y, p, eps=1e-9):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.mean(np.abs(y - p) / np.maximum(np.abs(y), eps)) * 100)


def my_smape(y, p, eps=1e-9):
    y, p = np.asarray(y, float), np.asarray(p, float)
    denom = np.maximum((np.abs(y) + np.abs(p)) / 2, eps)
    return float(np.mean(np.abs(y - p) / denom) * 100)


def my_wape(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.sum(np.abs(y - p)) / np.sum(np.abs(y)) * 100)


def my_mdape(y, p, eps=1e-9):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.median(np.abs(y - p) / np.maximum(np.abs(y), eps)) * 100)


def my_adj_r2(y, p, n_features):
    n = len(y)
    r2 = my_r2(y, p)
    return float(1 - (1 - r2) * (n - 1) / (n - n_features - 1))


# ── 검증: sklearn과 대조 ──
rng = np.random.default_rng(SEED)
y_true = rng.uniform(5000, 80000, 500)
y_pred = y_true + rng.normal(0, 4000, 500)

checks = [
    ("MAE", my_mae(y_true, y_pred), mean_absolute_error(y_true, y_pred)),
    ("MSE", my_mse(y_true, y_pred), mean_squared_error(y_true, y_pred)),
    ("RMSE", my_rmse(y_true, y_pred),
     float(np.sqrt(mean_squared_error(y_true, y_pred)))),
    ("R²", my_r2(y_true, y_pred), r2_score(y_true, y_pred)),
    ("MAPE(%)", my_mape(y_true, y_pred),
     mean_absolute_percentage_error(y_true, y_pred) * 100),
]

print("=" * 76)
print("직접 구현 vs sklearn")
print("=" * 76)
print(f"{'지표':<12}{'직접 구현':>18}{'sklearn':>18}{'차이':>14}{'일치':>8}")
print("-" * 76)
for name, mine, sk in checks:
    diff = abs(mine - sk)
    ok = "✓" if diff < 1e-6 * max(abs(sk), 1) else "✗"
    print(f"{name:<12}{mine:>18.6f}{sk:>18.6f}{diff:>14.2e}{ok:>8}")
print("=" * 76)

# ── sklearn에 없는 지표들 ──
print("\n[sklearn에 없는 지표 — 직접 구현 필요]")
print(f"  sMAPE  : {my_smape(y_true, y_pred):>10.4f}%")
print(f"  WAPE   : {my_wape(y_true, y_pred):>10.4f}%")
```

```python
def metric_report(y_true, y_pred, n_features=None, name="model"):
    """모든 지표를 한 번에 + 진단"""
    y = np.asarray(y_true, float)
    p = np.asarray(y_pred, float)
    has_zero = bool((np.abs(y) < 1e-9).any())

    m = {
        "MAE": my_mae(y, p),
        "RMSE": my_rmse(y, p),
        "R²": my_r2(y, p),
        "MAPE(%)": np.nan if has_zero else my_mape(y, p),
        "sMAPE(%)": my_smape(y, p),
        "WAPE(%)": my_wape(y, p),
        "MdAPE(%)": np.nan if has_zero else my_mdape(y, p),
        "RMSE/MAE": my_rmse(y, p) / max(my_mae(y, p), 1e-12),
        "편향": float((p - y).mean()),
        "편향(중앙값)": float(np.median(p - y)),
    }
    if n_features:
        m["Adj R²"] = my_adj_r2(y, p, n_features)

    notes = []
    if m["R²"] < 0:
        notes.append("🔴 R² 음수 — 평균 예측보다 못함. 되돌리기·학습 실패 확인")
    if m["RMSE/MAE"] > 2:
        notes.append("🟡 RMSE/MAE > 2 — 극단적 실패 존재. 오차 top-N 확인 (Day 118)")
    elif m["RMSE/MAE"] > 1.5:
        notes.append("🔵 RMSE/MAE > 1.5 — 큰 오차가 섞임")
    if has_zero:
        notes.append("🟡 타깃에 0 존재 — MAPE 사용 불가. WAPE/sMAPE 사용")
    if abs(m["편향"]) > 0.02 * np.abs(y).mean():
        d = "과대" if m["편향"] > 0 else "과소"
        notes.append(f"🟡 체계적 {d} 예측 (편향 {m['편향']:+.4f})")
    if not np.isnan(m.get("MAPE(%)", np.nan)) and m["MAPE(%)"] > m["MdAPE(%)"] * 2:
        notes.append("🔵 MAPE ≫ MdAPE — 소수의 작은 타깃에서 큰 비율 오차")
    if not notes:
        notes.append("⚪ 특이사항 없음")

    return m, notes


def choose_metric(target_min, target_max, has_zero, cost_of_large_error,
                  audience, compare_across_datasets=False):
    """조건을 넣으면 지표를 추천"""
    span = target_max / max(target_min, 1e-9)
    rec = {"주 지표": None, "부 지표": [], "근거": []}

    if compare_across_datasets:
        rec["주 지표"] = "R² 또는 sMAPE"
        rec["근거"].append("데이터셋 간 비교 → 단위 무관 지표")
    elif cost_of_large_error == "치명적":
        rec["주 지표"] = "RMSE"
        rec["근거"].append("큰 오차가 치명적 → 제곱 벌점")
        rec["부 지표"] += ["최대 오차", "MAE"]
    elif has_zero:
        rec["주 지표"] = "WAPE"
        rec["근거"].append("타깃에 0 존재 → MAPE 불가, WAPE는 안전")
        rec["부 지표"] += ["MAE", "sMAPE"]
    elif span > 20:
        rec["주 지표"] = "sMAPE 또는 WAPE"
        rec["근거"].append(f"타깃 범위가 {span:.0f}배 → 비율 오차가 체감에 가까움")
        rec["부 지표"] += ["MAE", "MdAPE"]
    else:
        rec["주 지표"] = "MAE"
        rec["근거"].append(f"타깃 범위가 {span:.1f}배로 좁음 → 절대 오차가 직관적")
        rec["부 지표"] += ["RMSE", "R²"]

    if audience == "비전문가":
        rec["부 지표"].append("MAE (설명용)")
        rec["근거"].append("비전문가 대상 → 단위가 같은 MAE를 함께 제시")

    rec["부 지표"] += ["RMSE/MAE (오차 균일도)", "구간별 오차율 (Day 118)"]
    rec["손실 함수"] = {
        "MAE": "MAE 또는 Huber", "RMSE": "MSE",
        "WAPE": "MAE (+ 로그 타깃)", "sMAPE 또는 WAPE": "로그 타깃 + MSE",
        "R² 또는 sMAPE": "MSE",
    }.get(rec["주 지표"], "MSE")
    return rec
```

```python
import numpy as np
import pandas as pd
from sklearn.metrics import (mean_absolute_error, mean_absolute_percentage_error,
                             mean_squared_error, r2_score)

# ═══ 수정 1·2·3: 원래 공간으로 되돌린 뒤 평가 ═══
model.fit(X_train, np.log1p(y_train))

pred_log_val = np.asarray(model.predict(X_val)).ravel()      # ★ 수정 9
pred_log_train = np.asarray(model.predict(X_train)).ravel()

pred_val = np.expm1(pred_log_val)          # ★ 원래 공간
pred_train = np.expm1(pred_log_train)

y_v = np.asarray(y_val, dtype=float)
y_t = np.asarray(y_train, dtype=float)


def full_report(y, p, tag):
    mae = mean_absolute_error(y, p)
    rmse = float(np.sqrt(mean_squared_error(y, p)))
    r2 = r2_score(y, p)
    has_zero = bool((np.abs(y) < 1e-9).any())      # ★ 수정 8

    out = {
        "구분": tag,
        "MAE": round(mae, 4),
        "RMSE": round(rmse, 4),                     # ★ 수정 6
        "RMSE/MAE": round(rmse / max(mae, 1e-12), 3),
        "R²": round(r2, 4),
        "편향": round(float((p - y).mean()), 4),      # ★ 수정 7
        "편향(중앙값)": round(float(np.median(p - y)), 4),
    }
    if has_zero:
        out["MAPE(%)"] = "N/A (타깃에 0)"
        out["WAPE(%)"] = round(float(np.sum(np.abs(y - p)) / np.sum(np.abs(y)) * 100), 2)
    else:
        out["MAPE(%)"] = round(mean_absolute_percentage_error(y, p) * 100, 2)
        out["WAPE(%)"] = round(float(np.sum(np.abs(y - p)) / np.sum(np.abs(y)) * 100), 2)
    return out


rows = [
    full_report(y_t, pred_train, "학습셋 (참고)"),
    full_report(y_v, pred_val, "검증셋 ★"),
]
print(pd.DataFrame(rows).to_string(index=False))

# ★ 수정 4: 검증셋 기준으로만 판단
val = rows[1]

# ★ 수정 5: R²를 올바르게 설명
print(f"""
[올바른 해석]
  R² {val['R²']:.4f}
    → "타깃 분산의 {val['R²']*100:.1f}%를 설명"
    → "평균으로 예측할 때보다 오차 제곱합이 {val['R²']*100:.1f}% 적음"
    ✗ "{val['R²']*100:.0f}% 정확하다"는 잘못된 표현

  MAE {val['MAE']:.4f}
    → "평균적으로 {val['MAE']:.4f}만큼 빗나감"
    → 타깃 평균 {y_v.mean():.4f} 대비 {val['MAE']/y_v.mean()*100:.1f}%

  RMSE/MAE {val['RMSE/MAE']:.3f}
    → {"오차가 고른 편" if val['RMSE/MAE'] < 1.35 else
       "큰 오차가 섞임" if val['RMSE/MAE'] < 2 else "★ 극단적 실패 존재"}

  편향 {val['편향']:+.4f}
    → {"체계적 " + ("과대" if val['편향'] > 0 else "과소") + " 예측"
       if abs(val['편향']) > 0.02 * y_v.mean() else "편향 없음"}
""")

# ── 참고: 로그 공간 지표 (비교 불가임을 명시) ──
log_mae = mean_absolute_error(np.log1p(y_v), pred_log_val)
print(f"[참고] 로그 공간 MAE {log_mae:.4f}")
print(f"       ≈ 비율 오차 {(np.exp(log_mae)-1)*100:.2f}%")
print("       ★ 이 값은 다른 모델(로그 변환 안 한)과 비교할 수 없습니다.")
```

```
              큰 오차가 치명적? ─── 예 ──→ RMSE (+ 최대 오차)
                    (의료·안전)     │
                              아니오
                               ↓
                 타깃에 0 존재? ─── 예 ──→ WAPE
                               │           (MAPE 사용 불가)
                              아니오
                               ↓
              타깃 범위 20배 이상? ─ 예 ──→ sMAPE 또는 WAPE
                               │
                              아니오
                               ↓
                            MAE
                    (RMSE·R² 부 지표)

  ★ 어느 경로든 반드시 함께 볼 것:
      RMSE/MAE 비율 · 편향(평균·중앙값) · 구간별 오차율
```

**채점 기준**

| 항목 | 배점 | 감점 |
|---|---|---|
| ① 지표 7종 구현 + 대조 | 15 | sklearn 대조 없으면 -5 |
| ② **이상치 민감도** | **15** | 배수 표 없으면 -8 |
| ③ **순위 뒤바뀜 재현** | **15** | **순위표가 없으면 -10** |
| ④ R² 함정 3가지 | 10 | — |
| ⑤ MAPE 함정 + 대안 | 10 | 대안 비교 없으면 -5 |
| ⑥ 로그 타깃 해석 | 10 | — |
| ⑦ 선택 순서도 | 10 | 분기 조건이 없으면 -5 |
| ⑧ **프로젝트 지표 결정** | **25** | **"MAE를 쓰겠다"만 쓰면 0점** |

> **⑧에서 순서도를 실제로 적용한 과정이 보여야 합니다.**
> **"타깃에 0이 13.5% 있으므로 MAPE 불가 → WAPE"** 같은 논리 사슬이 핵심입니다.
</details>

## 오늘의 정리

| 지표 | 단위 | 이상치 | 최적 상수 | 언제 |
|---|---|---|---|---|
| **MAE** | 원래 | 낮음 | 중앙값 | 범위가 좁을 때 · 설명용 |
| **RMSE** | 원래 | **매우 높음** | 평균 | **큰 오차가 치명적일 때** |
| **R²** | 없음 | **매우 높음** | 평균 | 데이터셋 간 비교 |
| **MAPE** | % | 중간 | 평균보다 작음 | **0이 없을 때만** |
| **sMAPE** | % | 낮음 | 기하평균 | MAPE의 대칭 버전 |
| **WAPE** | % | 낮음 | 중앙값 | **0이 있을 때** |
| **MdAPE** | % | **매우 낮음** | — | 전형적 오차 |

| 개념 | 핵심 |
|---|---|
| **RMSE ≥ MAE** | 항상. 비율이 **오차의 불균일도** |
| RMSE/MAE > 2 | **극단적 실패 존재** |
| R² = 0 | **평균 예측과 동일** |
| R² < 0 | 평균보다 못함. 되돌리기·학습 실패 확인 |
| R² 함정 ① | 특성 늘리면 **학습 R²는 항상 상승** |
| R² 함정 ② | **타깃 분산이 분모** → 데이터셋 간 비교 불가 |
| R² 함정 ③ | "85% 정확"이 아니라 "분산의 85% 설명" |
| MAPE 함정 ① | **0 근처에서 폭발** |
| MAPE 함정 ② | **비대칭** → 과소 예측 편향 |
| 로그 공간 MAE | = **비율 오차**. 다른 모델과 비교 불가 |
| 지표 ↔ 손실 | **맞추면 유리.** MAE↔MAE, RMSE↔MSE, MAPE↔로그타깃 |
| 이상치 0.1% | **RMSE 2.2배, R² 0.92→0.61** |
| 최소 3개 | MAE + RMSE + 비율 지표를 함께 |

**오늘 반드시 기억할 세 가지**
> ① **지표를 바꾸면 모델 순위가 바뀝니다.** 지표를 먼저 정하고 손실 함수를 맞추세요.
> ② **타깃에 0이 있으면 MAPE를 쓸 수 없습니다.** WAPE를 쓰세요.
> ③ **R²는 이상치 하나에 무너집니다.** 그리고 "몇 % 정확"이 아닙니다.

**과제** — 지표 선택 가이드를 작성하세요.

**필수 포함 항목**

| 항목 | 내용 |
