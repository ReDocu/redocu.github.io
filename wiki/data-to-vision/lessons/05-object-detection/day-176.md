## ② 왜 필요한가

### 어제까지 만든 것

[Day 175](day-175.md)에서 전 구간을 **한 번** 관통시켰습니다.

```
카메라 → 검출 → 이벤트 → 스냅샷 → DB → 알림 → 서버 → 웹
                                                        ↑
                                          ★ 여기까지 한 번 도달했습니다
```

**축하할 일입니다. 그런데 이것은 아직 시스템이 아닙니다.**

### "한 번 됐다" 와 "항상 된다" 는 다릅니다

| | 한 번 됐다 | 항상 된다 |
|---|---|---|
| 실행 방법 | 터미널 4개를 손으로 켬 | **부팅하면 알아서** |
| 조건 | 낮 · 밝은 실내 · 사람 1명 | 밤 · 역광 · 여러 명 · 아무도 없음 |
| 지속 시간 | 3분 | **1시간 이상** |
| 실패 시 | 다시 실행 | **스스로 복구** |
| 근거 | "제가 봤어요" | **테스트 기록** |
| 재현 | ? | **명령 한 줄** |

**★ 발표장에서 실제로 벌어지는 일** — 조명이 아카데미와 다르고(역광 · 색온도), 심사위원 3명이 동시에 카메라 앞을 지나가고, Wi-Fi 에 40명이 붙어 느리고, 시연 도중 USB 케이블이 살짝 빠지고, "아무도 없을 때는 어떻게 되나요?" 라는 질문이 들어옵니다. **어제 성공한 그 3분과는 전혀 다른 환경입니다.**

### ★ 관측 지점 — "어디서 끊겼는지" 를 알 수 있게

"웹에 이벤트가 안 보여요" 라는 말만으로는 검출인지, 판정인지, 전송인지, 서버 400 인지, DB 는 됐는데 화면만인지 알 수 없습니다. **5군데를 하나씩 들여다보면 40분이 사라집니다.** 관측 지점이 있으면 이렇게 됩니다.

```
  $ tail -f /var/log/cctv/trace.log | grep 20260811-091422-a3f9c2

  09:14:22.481 | pi-01 | 20260811-091422-a3f9c2 | S03:DETECT | OK    | 118.4 | person=2
  09:14:22.483 | pi-01 | 20260811-091422-a3f9c2 | S04:EVENT  | OK    |   0.6 | roi_enter
  09:14:22.512 | pi-01 | 20260811-091422-a3f9c2 | S05:SNAP   | OK    |  28.1 | 61.2KB
  09:14:22.520 | pi-01 | 20260811-091422-a3f9c2 | S06:LOCALDB| OK    |   7.9 | rowid=418
  09:14:22.522 | pi-01 | 20260811-091422-a3f9c2 | S07:NOTIFY | QUEUED|   0.2 |
  09:14:27.641 | pi-01 | 20260811-091422-a3f9c2 | S08:SYNC   | FAIL  |5002.0 | timeout

  ★ 5초 만에 원인이 보입니다 — 서버 타임아웃
```

**★ 핵심은 `trace_id` 하나가 파이에서 웹까지 따라가는 것입니다.**

```
trace_id 규칙   YYYYMMDD-HHMMSS-<6자리 hex>  →  20260811-091422-a3f9c2

  · 파이에서 ★ 이벤트가 생성될 때 1회 발급
  · 스냅샷 파일명 · 로컬 DB · 전송 payload · 서버 DB · 웹 상세까지 그대로
  · ★ event_id 와 동일한 값을 씁니다 (따로 두면 대조가 어려움)

로그 한 줄 (파이·서버 공통)
  <ISO8601+09:00> | <device> | <trace_id> | <stage> | <status> | <ms> | <detail>
```

| 필드 | 왜 필요한가 |
|---|---|
| ISO8601 **+09:00** | 시간대 명시. UTC/KST 혼동이 통합 사고 1위 |
| device | 파이가 2대 이상일 때 |
| **trace_id** | 전 구간 추적의 열쇠 |
| stage | `S01`~`S11` |
| status | `OK` / `FAIL` / `SKIP` / `QUEUED` / `RETRY` |
| ms | 지연 분석 · 병목 찾기 |
| detail | 사람이 읽을 한 줄 |

> ⚠️ **`print()` 로 남기지 마세요.**
> systemd 로 띄우면 `print` 는 버퍼링되어 몇 분 뒤에 몰려 나옵니다. `logging` 을 쓰세요.

#### 근거리 / 원거리 — [Day 167](day-167.md) 픽셀 계산과 대조

```
초점거리(픽셀) f_px = (이미지_폭 / 2) / tan(수평화각 / 2)

  HFOV 66° · 검출 입력 폭 640 px
  f_px = 320 / tan(33°) = 320 / 0.6494 = ★ 492.8 px

대상 픽셀 높이 = 실제_높이(m) × f_px / 거리(m)
```

| 거리 | 사람(1.7m) | 안전모(0.25m) | 검출 가능성 |
|---|---|---|---|
| 2 m | 419 px | 62 px | 매우 안정 |
| 5 m | 168 px | 25 px | 안정 |
| 8 m | 105 px | 15 px | 사람 ✓ / 안전모 위험 |
| 10 m | 84 px | 12 px | 사람 ✓ / 안전모 ✗ |
| **12 m** | **70 px** | 10 px | **경계선** |
| 15 m | 56 px | 8 px | 불안정 |
| 20 m | 42 px | 6 px | ✗ |

```
★ 경험칙 — YOLO 640 에서 안정적으로 잡히는 최소 크기는 ★ 32~40 px
  (COCO 의 "small object" 정의가 32×32 px 미만)

  우리 데이터셋은 2~10m 에서 촬영했습니다 ([Day 172](day-172.md))
  → 12m 에서 검출률이 낮으면 "모델 결함" 이 아니라 "데이터 범위 밖"

  대응 두 가지
    ⓐ 요구사항에 "유효 거리 2~10m" 명시   ← 오늘 할 수 있음
    ⓑ 원거리 데이터를 추가 학습            ← 5시간. 시간 없음
```

> ⚠️ **"모델을 다시 학습하자" 는 선택지는 오늘 없습니다.**
> 학습 3시간 + 검증 1시간 + 재배포 1시간 = 5시간입니다.

#### ★ 우선순위 = 심각도 × 빈도 × 시연 노출도

```
  결함 A  Critical · 1000번에 1번 · 시연 경로 밖
  결함 B  Major    · 항상        · ★ 시연 첫 화면
  ★ B 를 먼저 고쳐야 합니다
```

| 축 | 값 | 계수 |
|---|---|---|
| **심각도(S)** | Blocker / Critical / Major / Minor / Trivial | 100 / 50 / 20 / 5 / 1 |
| **빈도(F)** | 항상 F1 / 자주 F2 / 가끔 F3 / 드묾 F4 / 1회 F5 | 1.0 / 0.7 / 0.4 / 0.2 / 0.1 |
| **시연 노출도(E)** | 시연 경로 위 E1 / 시연 중 발생 가능 E2 / 무관 E3 | 1.0 / 0.5 / 0.2 |

```
★ P = S × F × E
  P ≥ 30       → P0  ★ 오늘 안에 고친다
  10 ≤ P < 30  → P1     내일(Day 177) 오전
  3 ≤ P < 10   → P2     시간이 남으면
  P < 3        → P3  안 고친다 (기록만)
```

| 결함 | S | F | E | P | 등급 |
|---|---|---|---|---|---|
| 카메라 분리 후 미복구 | 100 | 1.0 | 1.0 | **100** | P0 |
| 빈 화면 오탐 | 50 | 0.4 | 1.0 | **20** | P1 |
| 로그 회전 안 됨 | 5 | 1.0 | 0.2 | **1.0** | P3 |
| 페이지 제목 오타 | 1 | 1.0 | 0.5 | **0.5** | P3 |

```
★ 점수를 뒤집는 단 하나의 변수 — 수정 비용

  제목 오타 P=0.5 → P3 (안 고침). 그런데 ★ 수정에 1분 걸립니다
  → 실무 규칙: "P3 라도 10분 미만 · 회귀 위험 없음이면 그냥 고친다"

  반대로 P1 인데 수정에 5시간(재학습)
```


#### `pi/cctv.py` — 메인 루프 (전 구간 배선)

[Day 170](day-170.md) Step 6 의 `pi/main.py` 를 그대로 이어받되, **통합에 필요한 5가지**가 바뀌었습니다. 아래에는 **바뀐 부분만** 싣습니다.

| # | 항목 | Day 170 `pi/main.py` | Day 176 `pi/cctv.py` |
|---|---|---|---|
| 1 | 설정 | 코드 상단 `CONFIG` + 환경변수 | `pi/config.yaml` 한 곳 |
| 2 | 로그 | `logging` · 사람이 읽는 문장 | `pi/trace.py` · 구간 ID · `trace_id` · `ms` |
| 3 | S01 재연결 | 없음 (열기 실패 시 종료) | `open_camera()` 재호출 · 연속 3회 실패 시 전환 |
| 4 | S07 · S08 | 메인 루프에서 동기 호출 | `outbox` 큐 + **워커 스레드** |
| 5 | 생존 신호 | `/dev/shm/cctv.hb` 터치 | `health.json` (FPS · 큐 · 디스크 · 카메라 상태) |

`__init__` 은 설정 로드 → 검출기 → 판정기 → 로컬 DB → 알림 → 전송 순서로 Day 170 과 같습니다. 달라진 것은 마지막에 `self.outbox = queue.Queue(maxsize=200)` 을 만들고 `_outbox_loop` 워커 스레드를 띄우는 부분뿐입니다.

```python
"""pi/cctv.py — CCTV 메인 프로세스 (Day 176 전 구간 배선)

S01 장치 → S02 캡처 → S03 검출 → S04 판정 → S05 스냅샷
        → S06 로컬DB → S07 알림 → S08 전송 큐

★ 원칙
  · 어떤 구간이 실패해도 ★ 프로세스는 죽지 않는다
  · 모든 구간은 trace 로그를 남긴다
  · 알림·전송은 메인 루프를 막지 않는다
"""
KST = timezone(timedelta(hours=9))


def now_iso() -> str:
    """항상 시간대를 붙인다 — UTC/KST 혼동이 통합 사고 1위"""
    return datetime.now(KST).isoformat(timespec="milliseconds")


class CCTVApp:
    # ───────────────────────── S01 장치 ─────────────────────────
    def open_camera(self) -> bool:
        c = self.cfg["camera"]
        t0 = time.time()
        try:
            if self.cap is not None:
                self.cap.release()
        except Exception:
            pass
        try:
            self.cap = LatestFrameCapture(c["source"], width=c["width"],
                                          height=c["height"], fps=c["fps"])
            time.sleep(c["warmup_sec"])              # AE/AWB 안정화
            ok, frame = self.cap.read()
            if not ok or frame is None:
                raise RuntimeError("첫 프레임 획득 실패")
            h, w = frame.shape[:2]
            self.trace.log("-", "S01:CAMERA", "OK", (time.time() - t0) * 1000,
                           f"{w}x{h} src={c['source']}")
            return True
        except Exception as e:
            self.trace.log("-", "S01:CAMERA", "FAIL", (time.time() - t0) * 1000,
                           f"{type(e).__name__}: {e}")
            self.cap = None
            return False
```

`run()` 의 `while` 루프는 **S02 캡처 → S03 검출** 까지는 Day 170 과 같습니다. `self.cap` 이 `None` 이면 `open_camera()` 를 다시 부르고, 캡처가 연속 3회(`max_read_fail`) 실패하면 `self.cap = None` 으로 되돌려 **S01 로 되돌아갑니다.** 검출 예외는 `continue` 로 **그 프레임만 버립니다.**

아래는 검출이 끝난 뒤 — **이벤트 1건이 S04 부터 S08 까지 지나가는 길** 입니다.

```python
            t2 = time.time()                         # ── S04 이벤트 판정 ──
            decision = self.decider.update(dets, frame.shape[1], frame.shape[0])
            if decision is None:
                self.trace.log("-", "S04:EVENT", "SKIP",
                               (time.time() - t2) * 1000, self.decider.last_reason)
                last_health = self._maybe_health(last_health)
                continue

            tid = new_trace_id()
            self.stat["events"] += 1
            self.trace.log(tid, "S04:EVENT", "OK", (time.time() - t2) * 1000,
                           f"type={decision['type']} {counts}")

            snap_name = None                         # ── S05 스냅샷 ──
            t3 = time.time()
            st = self.cfg["storage"]
            try:
                free = free_space_mb(st["snapshot_dir"])
                if free < st["min_free_mb"]:
                    purge_old(st["snapshot_dir"], days=st["keep_days"])
                    free = free_space_mb(st["snapshot_dir"])
                if free < st["min_free_mb"]:
                    raise OSError(f"디스크 부족 ({free:.0f}MB)")
                snap_name = save_snapshot(frame, dets, st["snapshot_dir"], tid)
                kb = (Path(st["snapshot_dir"]) / snap_name).stat().st_size / 1024

            except Exception as e:
                # ★ 스냅샷이 실패해도 이벤트는 계속 간다
                self.trace.log(tid, "S05:SNAP", "FAIL",
                               (time.time() - t3) * 1000,
                               f"{type(e).__name__}: {e}")

            event = {"event_id": tid, "trace_id": tid,
                     "device_id": self.device_id,
                     "ts": now_iso(),                # ★ +09:00 포함
                     "type": decision["type"], "classes": counts,
                     "max_conf": round(max_conf, 3), "detections": dets,
                     "snapshot_name": snap_name, "model": res.get("model", {})}

            t4 = time.time()                         # ── S06 로컬 DB ──
            try:
                rowid = self.db.insert_event(event)
                self.trace.log(tid, "S06:LOCALDB", "OK",
                               (time.time() - t4) * 1000, f"rowid={rowid}")
            except Exception as e:
                self.trace.log(tid, "S06:LOCALDB", "FAIL",
                               (time.time() - t4) * 1000,
                               f"{type(e).__name__}: {e}")

            snap_path = (str(Path(st["snapshot_dir"]) / snap_name)
                         if snap_name else None)
            try:                                     # ── S07·S08 은 워커에게 ──
                self.outbox.put_nowait((event, snap_path))
                self.trace.log(tid, "S07:NOTIFY", "QUEUED", 0.0,
                               f"outbox={self.outbox.qsize()}")
            except queue.Full:
                # 큐가 꽉 차도 메인 루프는 계속 — 알림만 포기
                self.trace.log(tid, "S07:NOTIFY", "FAIL", 0.0,
                               "outbox full (200) — 알림 생략")

            last_health = self._maybe_health(last_health)

        self.shutdown()

    # _maybe_health() 는 10초마다 health.json 을 원자적으로 덮어씁니다
    # (uptime · fps_capture · fps_infer · events · queue_pending · free_mb ·
    #  camera 상태). 뒤의 "좀비" 절에서 이 파일의 mtime 을 감시합니다.

    # ─────────────── S07·S08 워커 (별도 스레드) ───────────────
    def _outbox_loop(self):
        while not self._stop.is_set():
            try:
                self._outbox_once()
            except Exception:
                # 여기서 잡지 않으면 워커 스레드가 조용히 사라진다
                self.trace.log("-", "S07:WORKER", "FAIL", 0, "워커 예외 — 계속")
                self.trace.logger.exception("outbox worker")
                time.sleep(2.0)

    def _outbox_once(self):
        try:
            event, snap_path = self.outbox.get(timeout=1.0)
        except queue.Empty:
            return
        tid = event["event_id"]

        t0 = time.time()                             # ── S07 알림 ──
        try:
            ok = self.notifier.send(event, snap_path)
            self.trace.log(tid, "S07:NOTIFY", "OK" if ok else "FAIL",
                           (time.time() - t0) * 1000, "telegram")
        except Exception as e:
            self.trace.log(tid, "S07:NOTIFY", "FAIL", (time.time() - t0) * 1000,
                           f"{type(e).__name__}: {e}")

        t1 = time.time()                             # ── S08 전송 큐 ──
        try:
            sent = self.sync.send(event, snap_path)
            self.trace.log(tid, "S08:SYNC", "OK" if sent else "QUEUED",
                           (time.time() - t1) * 1000,
                           f"pending={self.sync.pending_count()}")
        except Exception as e:
            self.trace.log(tid, "S08:SYNC", "FAIL", (time.time() - t1) * 1000,
                           f"{type(e).__name__}: {e}")


def main():
    app = CCTVApp(sys.argv[1] if len(sys.argv) > 1 else "pi/config.yaml")
    try:
        app.run()
    except Exception:
        app.trace.logger.exception("치명적 오류 — 프로세스 종료")
        raise                                        # systemd 가 재시작하게


if __name__ == "__main__":
    main()
```

> ⚠️ **`except Exception` 을 남발한 것처럼 보이지만 의도적입니다.**
> 각 구간의 실패는 **그 구간에서 흡수**하고 로그를 남깁니다.
> 흡수하지 않은 예외만 `main()` 까지 올라가 프로세스를 종료시키고 **systemd 가 재시작**합니다.
> **★ "어디까지 견디고 어디서 죽을 것인가" 를 설계하는 것이 통합입니다.**

### Step 2. `smoke_test.py` — 전 구간 자동 스모크 테스트

```python
"""tools/smoke_test.py — 전 구간 스모크 테스트 (Day 176)

★ 목적 — 코드를 고칠 때마다 10초 안에 "11단계가 아직 이어지는가" 확인

사용법
  python tools/smoke_test.py                       # 전체 (파이에서)
  python tools/smoke_test.py --skip S01,S02,S07    # 카메라·알림 제외
  python tools/smoke_test.py --server-only         # 서버 쪽만 (S09~S11)
  python tools/smoke_test.py --json out.json       # 결과 저장

종료 코드  0 전부 PASS · 1 하나 이상 FAIL · 2 실행 자체가 불가
"""
from __future__ import annotations

import argparse
import json
import os
import sqlite3
import sys
import time
import uuid
from datetime import datetime, timezone, timedelta
from pathlib import Path

import requests
import yaml

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))

KST = timezone(timedelta(hours=9))
FIXTURE = ROOT / "tests/fixtures/person_5m.jpg"   # ★ 사람이 2명 있는 고정 이미지
MARK = {"PASS": "✓", "FAIL": "✗", "SKIP": "-", "WARN": "!"}


class Result:
    def __init__(self, sid, name):
        self.sid, self.name, self.status, self.ms, self.detail = \
            sid, name, "SKIP", 0.0, ""

    def row(self):
        return (f"  {MARK[self.status]} {self.sid:<4} {self.name:<14} "
                f"{self.status:<5} {self.ms:>8.1f}ms  {self.detail}")


class Smoke:
    def __init__(self, cfg_path, args):
        self.args = args
        self.cfg = yaml.safe_load(Path(cfg_path).read_text(encoding="utf-8"))
        self.skip = {x.strip().upper() for x in (args.skip or "").split(",") if x}
        self.server = (args.server or self.cfg["sync"]["server_url"]).rstrip("/")
        self.results: list[Result] = []
        self.test_id = f"smoke-{uuid.uuid4().hex[:8]}"
        self.detector = None
        self.frame = None

    def _event(self):
        return {"event_id": self.test_id, "trace_id": self.test_id,
                "device_id": self.cfg["device_id"],
                "ts": datetime.now(KST).isoformat(timespec="milliseconds"),
                "type": "smoke", "classes": {"person": 1}, "max_conf": 0.9,
                "detections": [], "snapshot_name": None, "model": {}}

    def run_stage(self, sid, name, fn):
        r = Result(sid, name)
        self.results.append(r)
        if sid in self.skip:
            r.detail = "--skip 지정"
            return r
        t0 = time.time()
        try:
            ok, detail = fn()
            r.status = "PASS" if ok is True else ("WARN" if ok == "warn" else "FAIL")
            r.detail = detail
        except Exception as e:
            r.status, r.detail = "FAIL", f"{type(e).__name__}: {e}"
        r.ms = (time.time() - t0) * 1000
        return r

    # ───────────────────── S01 · S02 카메라 ─────────────────────
    def s01_camera(self):
        import cv2
        cap = cv2.VideoCapture(self.cfg["camera"]["source"])
        try:
            if not cap.isOpened():
                return False, f"장치를 열 수 없음 ({self.cfg['camera']['source']})"
            return True, "opened"
        finally:
            cap.release()

    def s02_capture(self):
        import cv2
        cap = cv2.VideoCapture(self.cfg["camera"]["source"])
        try:
            got = 0
            for _ in range(10):
                ok, frame = cap.read()
                if ok and frame is not None:
                    got += 1
                    self.frame = frame
            if got < 8:
                return False, f"10프레임 중 {got}개만 획득"
            h, w = self.frame.shape[:2]
            return True, f"{got}/10 frames {w}x{h}"
        finally:
            cap.release()

    # ───────────────────────── S03 검출 ─────────────────────────
    def s03_detect(self):
        from src.detector import get_detector
        d = self.cfg["detect"]
        if self.detector is None:
            self.detector = get_detector(profile=d["profile"],
                                         weights=d["weights"], imgsz=d["imgsz"])
        if not FIXTURE.exists():
            return False, f"고정 이미지 없음: {FIXTURE}"
        res = self.detector.predict_image(str(FIXTURE), conf=d["conf"],
                                          iou=d["iou"], classes=d["classes"])
        n = res["counts_by_class"].get("person", 0)
        ms = res["timing_ms"].get("total", 0)
        if n < 2:                       # 이 이미지에는 사람이 2명 있다
            return False, f"person={n} (기대 2) infer={ms:.1f}ms"
        if ms > 400:                    # 임계 시간
            return "warn", f"person={n} 느림 {ms:.1f}ms"
        return True, f"person={n} infer={ms:.1f}ms"

    # ─────────────────────── S04 이벤트 판정 ───────────────────────
    def s04_event(self):
        from pi.events import EventDecider
        dec = EventDecider(**self.cfg["event"])
        fake = [{"class_id": 0, "class_name": "person", "conf": 0.8,
                 "box": [500, 400, 700, 900]}]              # ROI 안쪽
        out = None
        for _ in range(self.cfg["event"]["min_hits"] + 1):
            out = dec.update(fake, 1280, 720)
            if out:
                break
        if out is None:
            return False, f"min_hits 후에도 이벤트 없음 ({dec.last_reason})"
        if dec.update(fake, 1280, 720) is not None:         # 쿨다운 확인
            return False, "쿨다운이 동작하지 않음 (연속 이벤트)"
        return True, f"type={out['type']} cooldown OK"

    # ───────────────────────── S05 스냅샷 ─────────────────────────
    def s05_snapshot(self):
        import cv2
        from pi.storage import save_snapshot
        img = self.frame if self.frame is not None else cv2.imread(str(FIXTURE))
        if img is None:
            return False, "테스트할 이미지가 없음"
        dets = [{"class_id": 0, "class_name": "person", "conf": 0.8,
                 "box": [100, 100, 300, 500]}]
        name = save_snapshot(img, dets, self.cfg["storage"]["snapshot_dir"],
                             self.test_id)
        p = Path(self.cfg["storage"]["snapshot_dir"]) / name
        if not p.exists():
            return False, f"파일이 생성되지 않음: {p}"
        kb = p.stat().st_size / 1024
        p.unlink(missing_ok=True)                           # 테스트 흔적 제거
        return (True, f"{kb:.1f}KB") if kb >= 5 else \
               (False, f"파일이 너무 작음 ({kb:.1f}KB)")

    def s06_localdb(self):

        LocalDB(self.cfg["storage"]["db_path"]).insert_event(self._event())
        con = sqlite3.connect(self.cfg["storage"]["db_path"])
        try:
            n = con.execute("SELECT COUNT(*) FROM events WHERE event_id=?",
                            (self.test_id,)).fetchone()[0]
            con.execute("DELETE FROM events WHERE event_id=?", (self.test_id,))

            return False, f"멱등성 실패 (재전송 → {r2.status_code})"

        if ids.count(self.test_id) != 1:
            return False, f"중복 저장 {ids.count(self.test_id)}건"
        return True, f"total={r.json()['total']} 중복 없음"
```

### Step 3. 관측 지점 심기 — 구간 로그 표준화

#### `pi/trace.py`

```python
"""pi/trace.py — 구간 추적 로그 (Day 176)

형식
  <ISO8601+09:00> | <device> | <trace_id> | <stage> | <status> | <ms> | <detail>

★ 이 형식을 파이와 서버가 ★ 똑같이 씁니다.
  두 로그를 합쳐 정렬하면 전 구간 타임라인이 나옵니다.
"""
from __future__ import annotations

import logging
import logging.handlers
import uuid
from datetime import datetime, timezone, timedelta
from pathlib import Path

KST = timezone(timedelta(hours=9))
VALID_STATUS = {"OK", "FAIL", "SKIP", "QUEUED", "RETRY"}


def new_trace_id() -> str:
    """20260811-091422-a3f9c2 — 시각이 앞에 와서 정렬이 곧 시간순"""
    return (datetime.now(KST).strftime("%Y%m%d-%H%M%S")
            + "-" + uuid.uuid4().hex[:6])


class Trace:
    def __init__(self, device_id: str, log_dir: str, level: str = "INFO",
                 max_mb: int = 20, backups: int = 5):
        self.device_id = device_id
        d = Path(log_dir)
        d.mkdir(parents=True, exist_ok=True)
        self.logger = logging.getLogger(f"trace.{device_id}")
        self.logger.setLevel(getattr(logging, level.upper(), logging.INFO))
        self.logger.propagate = False
        if self.logger.handlers:
            return
        # 회전 없이 두면 하루 300MB 를 넘깁니다
        fh = logging.handlers.RotatingFileHandler(
            d / "trace.log", maxBytes=max_mb * 1024 * 1024,
            backupCount=backups, encoding="utf-8")
        fh.setFormatter(logging.Formatter("%(message)s"))
        self.logger.addHandler(fh)
        sh = logging.StreamHandler()
        sh.setFormatter(logging.Formatter("%(message)s"))
        self.logger.addHandler(sh)

    def log(self, trace_id: str, stage: str, status: str,
            ms: float, detail: str = ""):
        if status not in VALID_STATUS:
            status = "FAIL"
        ts = datetime.now(KST).isoformat(timespec="milliseconds")
        line = (f"{ts} | {self.device_id} | {trace_id or '-'} | "
                f"{stage} | {status} | {ms:.1f} | {detail}")
        (self.logger.error if status == "FAIL" else self.logger.info)(line)
```

#### `web/trace.py` — 서버도 같은 형식

`init_trace()` 는 `pi/trace.py` 와 똑같이 `RotatingFileHandler` 를 붙일 뿐입니다. **중요한 것은 출력 한 줄의 모양이 파이와 완전히 같다는 것** 입니다. 장치 이름 자리에만 `server` 가 들어갑니다.

```python
    if _logger is None:
        init_trace()
    ts = datetime.now(KST).isoformat(timespec="milliseconds")
    _logger.info(f"{ts} | server | {trace_id or '-'} | {stage} | "
```

#### `/api/events` 에 관측 지점 추가

엔드포인트 자체는 [Day 159](day-159.md) 에서 만든 것 그대로이고, **각 갈림길에 `trace()` 한 줄씩을 심은 것** 이 오늘의 작업입니다. 스냅샷 파일 저장 블록(`request.files["snapshot"]` → `save_bytes`)도 Day 159 와 같아 아래에서는 생략했습니다. 저장에 실패하면 `S09:SNAP FAIL` 만 남기고 **이벤트는 그대로 받습니다.**

```python
"""web/blueprints/api.py — 이벤트 수신 (Day 159 → Day 176 계측 추가)"""
REQUIRED = ("event_id", "device_id", "ts", "type")


@bp.post("/events")
def receive_event():
    """★ 파이가 이벤트를 보내는 멱등 엔드포인트"""
    t0 = time.time()
    raw = request.form.get("event")
    if not raw:
        trace("-", "S09:RECV", "FAIL", (time.time() - t0) * 1000, "400 event 없음")
        return jsonify({"error": "missing_event"}), 400
    try:
        ev = json.loads(raw)
    except json.JSONDecodeError as e:
        trace("-", "S09:RECV", "FAIL", (time.time() - t0) * 1000, f"400 JSON: {e}")
        return jsonify({"error": "bad_json"}), 400

    tid = ev.get("trace_id") or ev.get("event_id") or "-"
    missing = [k for k in REQUIRED if not ev.get(k)]
    if missing:
        trace(tid, "S09:RECV", "FAIL", (time.time() - t0) * 1000,
              f"400 필수 필드 누락 {missing}")
        return jsonify({"error": "missing_fields", "fields": missing}), 400

    db = get_db()
    try:
        if db.execute("SELECT 1 FROM events WHERE event_id=?",
                      (ev["event_id"],)).fetchone():
            trace(tid, "S09:RECV", "OK", (time.time() - t0) * 1000, "200 duplicate")
            return jsonify({"ok": True, "duplicate": True}), 200

        t2 = time.time()
        db.execute("""INSERT INTO events
            (event_id, device_id, ts, received_at, type, classes_json,
             max_conf, snapshot_name, raw_json) VALUES (?,?,?,?,?,?,?,?,?)""",
                   (ev["event_id"], ev["device_id"], ev["ts"],
                    datetime.now(KST).isoformat(timespec="milliseconds"),
                    ev["type"],
                    json.dumps(ev.get("classes", {}), ensure_ascii=False),
                    ev.get("max_conf", 0.0), snap_name,
                    json.dumps(ev, ensure_ascii=False)))
        db.commit()
        trace(tid, "S10:DB", "OK", (time.time() - t2) * 1000, "insert")
    except Exception as e:
        db.rollback()
        trace(tid, "S10:DB", "FAIL", (time.time() - t0) * 1000,
              f"{type(e).__name__}: {e}")
        return jsonify({"error": "server_error"}), 500
    finally:
        db.close()

    trace(tid, "S09:RECV", "OK", (time.time() - t0) * 1000, "201 created")
    return jsonify({"ok": True, "duplicate": False,
                    "event_id": ev["event_id"]}), 201
```

### Step 6. 성공 기준 대비 측정

```python
"""tools/measure_kpi.py — Day 171 성공 기준 실측 (Day 176)

trace.log 와 서버 API 를 읽어 SC-3 ~ SC-8 을 계산합니다.
SC-1 · SC-2 (mAP) 는 model.val() 결과를 인자로 받습니다.

정규식 한 줄로 trace.log 를 파싱해 dict 목록(rows)으로 만들고,
아래 목표표와 대조해 PASS / FAIL 을 찍습니다.
"""

TARGET = {
    "SC-1": ("mAP@0.5 (전체)", 0.75, "ge"),
    "SC-2": ("person AP@0.5", 0.80, "ge"),
    "SC-3": ("파이 처리 FPS", 5.0, "ge"),
    "SC-4": ("이벤트→알림 지연(초)", 5.0, "le"),
    "SC-5": ("이벤트→웹 표시 지연(초)", 10.0, "le"),
    "SC-6": ("빈 화면 오탐(건/30분)", 0, "le"),
    "SC-7": ("미검출률 2~10m (%)", 10.0, "le"),
    "SC-8": ("무중단(분)", 30.0, "ge"),
}


def latency(rows, from_stage, to_stage):
    """★ trace_id 로 두 구간을 짝지어 지연 계산"""
    a = {r["tid"]: r["dt"] for r in rows
         if r["stage"] == from_stage and r["st"] == "OK" and r["tid"] != "-"}
    b = {}
    for r in rows:
        if r["stage"] == to_stage and r["st"] == "OK" and r["tid"] in a:
            b.setdefault(r["tid"], r["dt"])
    d = sorted((b[t] - a[t]).total_seconds() for t in b)
    if not d:
        return None, "짝지어진 이벤트 없음"
    p95 = d[min(len(d) - 1, int(len(d) * 0.95))]
    return statistics.median(d), (f"n={len(d)} median={statistics.median(d):.2f}s "
                                  f"p95={p95:.2f}s max={d[-1]:.2f}s")


def uptime_minutes(rows):
    """SC-8 — 마지막 BOOT 이후 마지막 로그까지"""
    boots = [r["dt"] for r in rows if r["stage"] == "S00:BOOT"]
    if not boots:
        return None, "BOOT 로그 없음"
    last_boot, last = boots[-1], rows[-1]["dt"]
    stops = [r for r in rows
             if r["dt"] > last_boot and r["stage"] == "S00:SHUTDOWN"]
    note = f"boot={last_boot:%H:%M:%S} last={last:%H:%M:%S}"
    if stops:
        note += f" ★ 중단 {len(stops)}회"
    return (last - last_boot).total_seconds() / 60, note
```

나머지 계산은 같은 꼴입니다. SC-3 은 `S03:DETECT OK` 의 개수 ÷ 구간 초, SC-6 은 `--idle-start` 부터 30분 구간의 서버 이벤트 수, SC-1 · SC-2 · SC-7 은 인자로 받은 값을 그대로 씁니다. `main()` 이 이 8개를 모아 목표와 비교해 한 줄씩 출력합니다.

| 담당 | **사람 이름.** "팀" 은 아무도 아니다 |
| 기능 동결 | 오늘 18:00 · 태그 `v2.2-freeze` · 롤백 지점 |

**오늘 반드시 기억할 세 가지**
> ① **오늘은 발견하는 날입니다.** 결함을 만나면 목록에 적고 다음 테스트로 넘어가세요. 즉시 고치기 시작하면 12개 시나리오 중 3개도 못 돌립니다.
> ② **우선순위는 심각도만으로 정하지 않습니다.** `심각도 × 빈도 × 시연 노출도`. 시연에서 안 보이는 Minor 는 버려도 되고, **버리기로 한 것도 기록**합니다.
> ③ **"프로세스가 살아 있다"는 아무것도 보장하지 않습니다.** 살아서 일을 안 하는 좀비가 가장 위험합니다. **자동 복구까지 확인해야** 장애 테스트가 끝난 것입니다.
