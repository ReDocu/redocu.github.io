## 3. 개념

### 3-1. 지형 표현 — 높이 배열

**왜 필요한가** — 가장 단순하고 빠른 방식이다.

```cpp
class Terrain
{
public:
    void Init(int width, int height);
    int  GetHeightAt(int x) const { return m_height[x]; }
    void Destroy(int cx, int cy, int radius);

private:
    int* m_height = nullptr;                   // ★ x 마다 지면 y
    int  m_width = 0;
    int  m_screenH = 0;
};
```

```
   높이 배열

   x:      0   1   2   3   4   5   6   7 ...
   height: 480 478 475 470 468 470 476 480

   ▓ = 땅

              ▓▓
            ▓▓▓▓▓▓
          ▓▓▓▓▓▓▓▓▓▓
        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓
      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
```

| 장점 | 단점 |
|---|---|
| 메모리 작음 (width × 4바이트) | **동굴/터널 불가** |
| 충돌 판정 O(1) | 오버행 불가 |
| 파괴가 간단 | |

```
   ★ 높이 배열로 못 만드는 것

        ▓▓▓▓▓▓▓        ← 위에 땅
             ↑ 여기 빈 공간
        ▓▓▓▓▓▓▓        ← 아래에도 땅

   한 x 에 지면이 하나뿐이라 표현 불가
```

### 3-2. 지형 표현 — 픽셀 마스크

**왜 필요한가** — 동굴을 만들 수 있다. 포트리스는 이 방식이다.

```cpp
class Terrain
{
private:
    BYTE* m_mask = nullptr;                    // ★ width × height, 0 또는 1
    int m_width = 0, m_height = 0;
};

    bool IsSolid(int x, int y) const
    {
        if (x < 0 || x >= m_width || y < 0 || y >= m_height) return false;
        return m_mask[y * m_width + x] != 0;
    }
```

```
   픽셀 마스크 (0 = 빈 공간, 1 = 땅)

   y=0   0 0 0 0 0 0 0 0
   y=1   0 0 0 1 1 0 0 0
   y=2   0 0 1 1 1 1 0 0
   y=3   0 1 1 0 0 1 1 0     ← 동굴!
   y=4   1 1 1 1 1 1 1 1
```

| 지형 방식 | 메모리 (800×600) | 동굴 | 충돌 |
|---|:--:|:--:|---|
| 높이 배열 | 3.2 KB | ✗ | O(1) |
| **픽셀 마스크** | **480 KB** | **✓** | O(1) |

```
   ★ 오늘은 높이 배열로 시작한다

   단순하고, 오늘 배울 것에 집중할 수 있다
   확장 과제에서 마스크로 바꾼다
```

### 3-3. 파괴 — 원형 깎기

**왜 필요한가** — 착탄 지점을 중심으로 원 모양으로 판다.

```cpp
void Terrain::Destroy(int cx, int cy, int radius)
{
    int left  = cx - radius;
    int right = cx + radius;

    if (left < 0) left = 0;
    if (right >= m_width) right = m_width - 1;

    for (int x = left; x <= right; x++)
    {
        int dx = x - cx;
        int dySq = radius * radius - dx * dx;

        if (dySq < 0) continue;

        int dy = (int)sqrt((double)dySq);      // ★ 원의 방정식

        int circleBottom = cy + dy;            // 원의 아래쪽 끝

        // 지면이 원 안에 있으면 원 아래로 내린다
        if (m_height[x] < circleBottom)
            m_height[x] = circleBottom;

        if (m_height[x] > m_screenH)
            m_height[x] = m_screenH;
    }
}
```

```
   원의 방정식

   dx² + dy² = r²
   dy = √(r² - dx²)

   중심 (cx, cy), 반경 r

        dx=-r         dx=0          dx=+r
          │  ╭───────────────────╮  │
          │ ╱                     ╲ │
          ├●───────── cy ──────────●┤
          │ ╲                     ╱ │
          │  ╰───────────────────╯  │
                    dy 만큼 아래
```

```
   ★ 높이 배열에서는 "원 아래쪽"만 쓴다

   지면을 원의 하단까지 내리면
   결과적으로 원 모양 구덩이가 생긴다
```

**파괴 결과**

```
   파괴 전
   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓

   반경 30으로 파괴
   ▓▓▓▓▓▓╲          ╱▓▓▓▓
          ╲________╱

   같은 자리 또 파괴
   ▓▓▓▓╲              ╱▓▓
        ╲            ╱
         ╲__________╱      ← 더 깊어진다
```

### 3-5. 알파 블렌딩 — 반투명

**왜 필요한가** — 폭발, 연기, 그림자를 자연스럽게 그린다.

```
   Day 41의 투명 처리 (TransparentBlt)

   ┌───────┐
   │  ███  │   특정 색 = 완전히 안 그림
   │ █████ │   나머지  = 완전히 그림
   └───────┘

   → 0% 또는 100%.  중간이 없다
```

```
   알파 블렌딩

   결과 = 원본 × (1 - α)  +  새 색 × α

   α = 0.0  →  안 보임
   α = 0.5  →  반투명
   α = 1.0  →  완전 불투명
```

**공식**

```
   R = Rd × (1-α) + Rs × α
   G = Gd × (1-α) + Gs × α
   B = Bd × (1-α) + Bs × α

   d = destination (배경)
   s = source (그릴 것)
```

```
   예)  배경 (50, 80, 120),  폭발 (255, 200, 0),  α = 0.6

   R = 50  × 0.4 + 255 × 0.6 = 20  + 153 = 173
   G = 80  × 0.4 + 200 × 0.6 = 32  + 120 = 152
   B = 120 × 0.4 + 0   × 0.6 = 48  + 0   = 48

   → (173, 152, 48)   주황빛이 배경에 섞였다
```

### 3-6. AlphaBlend API

**왜 필요한가** — GDI가 제공하는 하드웨어 지원 블렌딩.

```cpp
#include <wingdi.h>
#pragma comment(lib, "Msimg32.lib")            // ★ 필수

void Renderer::DrawImageAlpha(Image* img, int x, int y, BYTE alpha)
{
    BLENDFUNCTION bf;
    bf.BlendOp             = AC_SRC_OVER;
    bf.BlendFlags          = 0;
    bf.SourceConstantAlpha = alpha;            // 0 ~ 255
    bf.AlphaFormat         = 0;                // 0 = 픽셀 알파 없음

    HDC memDC = CreateCompatibleDC(m_hdc);
    HBITMAP old = (HBITMAP)SelectObject(memDC, img->GetBitmap());

    AlphaBlend(m_hdc, x, y, img->GetWidth(), img->GetHeight(),
               memDC, 0, 0, img->GetWidth(), img->GetHeight(), bf);

    SelectObject(memDC, old);
    DeleteDC(memDC);
}
```

```
   ★ Msimg32.lib 를 링크해야 한다

   빠뜨리면:  "unresolved external symbol AlphaBlend"
```

| 필드 | 값 | 의미 |
|---|---|---|
| `BlendOp` | `AC_SRC_OVER` | 유일한 옵션 |
| `SourceConstantAlpha` | 0~255 | 전체 투명도 |
| `AlphaFormat` | 0 | 상수 알파만 |
| `AlphaFormat` | `AC_SRC_ALPHA` | 픽셀별 알파(32비트 비트맵) |

### 3-7. ⚠️ AlphaBlend + 투명색

**왜 필요한가** — 둘을 동시에 쓰려면 순서가 중요하다.

```
   원하는 것

   폭발 이미지를
   ① 배경색(마젠타)은 안 그리고
   ② 나머지는 반투명으로

   → AlphaBlend 는 투명색을 모른다  ✗
```

**해결 — 2단계**

```cpp
void Renderer::DrawImageAlphaTrans(Image* img, int x, int y,
                                   BYTE alpha, COLORREF transColor)
{
    int w = img->GetWidth(), h = img->GetHeight();

    // ① 임시 DC에 배경을 복사
    HDC tempDC = CreateCompatibleDC(m_hdc);
    HBITMAP tempBmp = CreateCompatibleBitmap(m_hdc, w, h);
    HBITMAP oldTemp = (HBITMAP)SelectObject(tempDC, tempBmp);

    BitBlt(tempDC, 0, 0, w, h, m_hdc, x, y, SRCCOPY);

    // ② 임시 DC 위에 투명 처리로 그린다
    HDC srcDC = CreateCompatibleDC(m_hdc);
    HBITMAP oldSrc = (HBITMAP)SelectObject(srcDC, img->GetBitmap());

    TransparentBlt(tempDC, 0, 0, w, h, srcDC, 0, 0, w, h, transColor);

    // ③ 임시 DC 전체를 알파 블렌딩으로 화면에
    BLENDFUNCTION bf = { AC_SRC_OVER, 0, alpha, 0 };
    AlphaBlend(m_hdc, x, y, w, h, tempDC, 0, 0, w, h, bf);

    SelectObject(srcDC, oldSrc);
    DeleteDC(srcDC);
    SelectObject(tempDC, oldTemp);
    DeleteObject(tempBmp);
    DeleteDC(tempDC);
}
```

```
   ★ 흐름

   화면 배경 ──복사──▶ 임시 DC
                        │
   폭발 이미지 ──투명──▶ 임시 DC 위에 합성
                        │
                        └──알파──▶ 화면

   결과: 투명색은 배경 그대로, 나머지는 반투명
```

```
   ⚠️ 매 프레임 DC/비트맵을 만들면 느리다

   → 임시 DC 는 재사용하도록 캐싱하는 것이 좋다
     (Renderer 멤버로 보유)
```

### 3-8. 직접 픽셀 블렌딩

**왜 필요한가** — 세밀한 제어가 필요할 때. 그리고 원리를 이해하기 위해.

```cpp
void Renderer::BlendCircle(int cx, int cy, int radius,
                           COLORREF color, double alpha)
{
    BYTE sr = GetRValue(color);
    BYTE sg = GetGValue(color);
    BYTE sb = GetBValue(color);

    for (int y = cy - radius; y <= cy + radius; y++)
    {
        if (y < 0 || y >= m_height) continue;

        for (int x = cx - radius; x <= cx + radius; x++)
        {
            if (x < 0 || x >= m_width) continue;

            int dx = x - cx, dy = y - cy;
            double dist = sqrt((double)(dx*dx + dy*dy));

            if (dist > radius) continue;

            // ★ 가장자리로 갈수록 흐리게
            double a = alpha * (1.0 - dist / radius);

            COLORREF d = GetPixel(m_hdc, x, y);

            BYTE r = (BYTE)(GetRValue(d) * (1-a) + sr * a);
            BYTE g = (BYTE)(GetGValue(d) * (1-a) + sg * a);
            BYTE b = (BYTE)(GetBValue(d) * (1-a) + sb * a);

            SetPixel(m_hdc, x, y, RGB(r, g, b));
        }
    }
}
```

```
   ⚠️ GetPixel / SetPixel 은 매우 느리다

   80×80 = 6400 픽셀 → 12800 회 호출 → 수 ms

   ★ 실제로는 DIB 직접 접근을 쓴다 (3-9)
```

### 3-9. DIB 직접 접근

**왜 필요한가** — 픽셀 조작을 100배 빠르게.

```cpp
class Renderer
{
private:
    HBITMAP m_backBmp = nullptr;
    BYTE*   m_bits = nullptr;                  // ★ 픽셀 배열 직접 포인터
    int     m_pitch = 0;                       // 한 줄 바이트 수
};

void Renderer::CreateBackBuffer(int w, int h)
{
    BITMAPINFO bi = {};
    bi.bmiHeader.biSize        = sizeof(BITMAPINFOHEADER);
    bi.bmiHeader.biWidth       = w;
    bi.bmiHeader.biHeight      = -h;           // ★ 음수 = 위에서 아래로
    bi.bmiHeader.biPlanes      = 1;
    bi.bmiHeader.biBitCount    = 32;
    bi.bmiHeader.biCompression = BI_RGB;

    m_backBmp = CreateDIBSection(m_hdc, &bi, DIB_RGB_COLORS,
                                 (void**)&m_bits, nullptr, 0);

    m_pitch = w * 4;
}
```

```cpp
inline void Renderer::BlendPixel(int x, int y, BYTE r, BYTE g, BYTE b, double a)
{
    if (x < 0 || x >= m_width || y < 0 || y >= m_height) return;

    BYTE* p = m_bits + y * m_pitch + x * 4;

    p[0] = (BYTE)(p[0] * (1-a) + b * a);       // B
    p[1] = (BYTE)(p[1] * (1-a) + g * a);       // G
    p[2] = (BYTE)(p[2] * (1-a) + r * a);       // R
}
```

```
   ★ 32비트 DIB의 픽셀 배치

   p[0] = Blue
   p[1] = Green
   p[2] = Red
   p[3] = Alpha (또는 미사용)

   ⚠️ BGRA 순서다.  RGB 아니다
```

| 방식 | 6400픽셀 블렌딩 시간 |
|---|:--:|
| GetPixel/SetPixel | 약 8 ms |
| **DIB 직접** | **약 0.05 ms** |

```
   ★ 160배 차이

   Day 51의 "동적 생성의 대가"와 같은 교훈
   → API 호출 오버헤드는 실측해야 안다
```

### 3-10. 폭발 이펙트

**왜 필요한가** — 파괴에 시각적 피드백을 준다.

```cpp
class Explosion
{
public:
    void Spawn(double x, double y, double maxRadius);
    void Update(double dt);
    void Render(Renderer& r);
    bool IsAlive() const { return m_alive; }

private:
    double m_x = 0, m_y = 0;
    double m_maxRadius = 40;
    double m_life = 0;
    double m_duration = 0.5;
    bool   m_alive = false;
};

void Explosion::Update(double dt)
{
    if (!m_alive) return;

    m_life += dt;
    if (m_life >= m_duration) m_alive = false;
}

void Explosion::Render(Renderer& r)
{
    if (!m_alive) return;

    double t = m_life / m_duration;            // 0 → 1

    // ★ 크기는 커지고, 투명도는 낮아진다
    double radius = m_maxRadius * (0.3 + t * 0.7);
    double alpha  = 1.0 - t;

    // 안쪽 (밝은 노랑)
    r.BlendCircle((int)m_x, (int)m_y, (int)(radius * 0.5),
                  RGB(255, 240, 150), alpha);

    // 바깥 (주황)
    r.BlendCircle((int)m_x, (int)m_y, (int)radius,
                  RGB(255, 140, 30), alpha * 0.7);
}
```

```
   시간에 따른 변화

   t=0.0   ●        작고 진하다
   t=0.3   ◉◉
   t=0.6   ◎◎◎
   t=1.0   ○○○○     크고 흐리다 → 사라짐
```

### 3-12. 탱크 낙하

**왜 필요한가** — 발밑을 파면 탱크가 떨어져야 한다.

```cpp
void Tank::Update(double dt)
{
    int groundY = m_terrain->GetHeightAt((int)m_x);

    if (m_y < groundY - 1)
    {
        // ★ 공중이면 낙하
        m_fallVy += GRAVITY * dt;
        m_y += m_fallVy * dt;

        if (m_y >= groundY)
        {
            double impact = m_fallVy;
            m_y = groundY;
            m_fallVy = 0;

            // 낙하 피해
            if (impact > 400)
            {
                int dmg = (int)((impact - 400) / 20);
                TakeDamage(dmg);
                DebugLog("[낙하] 속도 %.0f, 피해 %d\n", impact, dmg);
            }
        }
    }
    else
    {
        m_y = (double)groundY;
        m_fallVy = 0;
    }
}
```

{
    srand(seed);

    double base = m_screenH * 0.72;

    // 여러 사인파를 겹쳐 자연스러운 언덕
    double a1 = 30 + rand() % 40;
    double a2 = 15 + rand() % 20;
    double a3 = 8 + rand() % 10;

    double f1 = 0.004 + (rand() % 20) * 0.0002;
    double f2 = 0.011 + (rand() % 20) * 0.0004;
    double f3 = 0.027 + (rand() % 20) * 0.0008;

    double p1 = (rand() % 628) * 0.01;
    double p2 = (rand() % 628) * 0.01;
    double p3 = (rand() % 628) * 0.01;

    for (int x = 0; x < m_width; x++)
    {
        double y = base
                 + sin(x * f1 + p1) * a1
                 + sin(x * f2 + p2) * a2
                 + sin(x * f3 + p3) * a3;

        if (y > m_screenH - 10) y = m_screenH - 10;

        m_height[x] = (int)y;

    m_destroyCount = 0;
    m_removedPixels = 0;
}

void Terrain::Destroy(int cx, int cy, int radius)

    m_destroyCount++;

    int left  = max(0, cx - radius);
    int right = min(m_width - 1, cx + radius);

    for (int x = left; x <= right; x++)

            m_height[x] = bottom;
        }
    }
}

```cpp
void Renderer::BlendCircle(int cx, int cy, int radius,
                           COLORREF color, double alpha)
{
    if (alpha <= 0) return;
    if (alpha > 1) alpha = 1;

    BYTE sr = GetRValue(color), sg = GetGValue(color), sb = GetBValue(color);

    int y0 = max(0, cy - radius), y1 = min(m_height - 1, cy + radius);
    int rSq = radius * radius;

    for (int y = y0; y <= y1; y++)
    {
        int dy = y - cy;
        int dxMax = (int)sqrt((double)(rSq - dy*dy));

        int x0 = max(0, cx - dxMax), x1 = min(m_width - 1, cx + dxMax);

        for (int x = x0; x <= x1; x++)
        {
            int dx = x - cx;
            double dist = sqrt((double)(dx*dx + dy*dy));

            double a = alpha * (1.0 - dist / radius);
            if (a <= 0) continue;

            BlendPixel(x, y, sr, sg, sb, a);
        }
    }
}
```

struct Smoke
{
    double x, y, vx, vy, life, maxLife, radius;
    bool alive;
};

void SmokeManager::Spawn(double x, double y)
{
    for (int k = 0; k < 8; k++)
    {
        Smoke* s = FindFree();
        if (!s) return;

        double a = (rand() % 628) * 0.01;
        double sp = 20 + rand() % 40;

        s->x = x; s->y = y;
        s->vx = cos(a) * sp;
        s->vy = -fabs(sin(a)) * sp - 20;       // 위로 뜨게
        s->life = 0;
        s->maxLife = 1.2 + (rand() % 60) * 0.01;
        s->radius = 8 + rand() % 12;
        s->alive = true;
    }
}

void SmokeManager::Update(double dt)
{
    for (int i = 0; i < MAX; i++)
    {
        Smoke& s = m_pool[i];
        if (!s.alive) continue;

        s.life += dt;
        if (s.life >= s.maxLife) { s.alive = false; continue; }

        s.x += s.vx * dt;
        s.y += s.vy * dt;
        s.vy += 30 * dt;                       // 약한 중력
        s.vx *= 0.98;                          // 감속
        s.radius += 14 * dt;                   // 퍼진다
    }
}

void SmokeManager::Render(Renderer& r)
{
    for (int i = 0; i < MAX; i++)
    {
        Smoke& s = m_pool[i];
        if (!s.alive) continue;

        double t = s.life / s.maxLife;
        double a = (1.0 - t) * 0.4;            // ★ 점점 흐려진다

        r.BlendCircle((int)s.x, (int)s.y, (int)s.radius, RGB(80, 80, 80), a);
    }
}

| 증상 | 원인 | 해결 |
|---|---|---|

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| **높이 배열** | `int height[width]`. 단순·빠름, 동굴 불가 |
| 픽셀 마스크 | `BYTE mask[w*h]`. 동굴 가능, 메모리 큼 |
| **원형 파괴** | `dy = √(r² - dx²)`. 지면을 원 아래로 |
| 깎이기만 | `if (height < bottom)`. 메워지지 않게 |
| **알파 블렌딩** | `결과 = 배경×(1-α) + 새색×α` |
| AlphaBlend API | `BLENDFUNCTION`. Msimg32.lib 필요 |
| **DIB 직접 접근** | `CreateDIBSection`. GetPixel보다 100배+ |
| BGRA 순서 | `p[0]=B, p[1]=G, p[2]=R, p[3]=A` |
| `biHeight` 음수 | top-down DIB |
| 폭발 이펙트 | 커지면서 흐려진다 |
| 탱크 낙하 | 발밑을 파면 떨어지고 피해 |
