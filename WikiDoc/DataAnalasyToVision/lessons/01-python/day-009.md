## ② 왜 필요한가

어제 만든 인사 함수를 봅시다.

```python
def greet(name, greeting):
    print(f"{greeting}, {name}님!")

greet("홍길동", "안녕하세요")
greet("김철수", "안녕하세요")
greet("이영희", "안녕하세요")     # 매번 같은 인사말을 써야 함
```

대부분 "안녕하세요"인데 매번 적는 게 번거롭습니다. **기본값**이 있으면 좋겠습니다.

그리고 이런 상황도 있습니다.

```python
def total(a, b):
    return a + b

total(1, 2)              # 좋음
total(1, 2, 3)           # 에러! 3개는 못 받음
```

숫자를 몇 개 받을지 미리 알 수 없다면? **가변 인자**가 필요합니다.

오늘 배우는 것들은 **파이썬 라이브러리를 읽을 때** 반드시 만납니다.
대단원 03에서 `model.fit(x, y, epochs=10, batch_size=32, verbose=1)` 같은 코드를 보게 되는데,
`epochs=10` 이 왜 저렇게 쓰이는지, 안 쓰면 어떤 값이 들어가는지 오늘 배우면 알게 됩니다.

## ③ 개념 설명

### 기본값 매개변수

매개변수에 `=` 로 기본값을 주면, 호출할 때 생략할 수 있습니다.

```python
def greet(name, greeting="안녕하세요"):
    print(f"{greeting}, {name}님!")

greet("홍길동")                    # 기본값 사용
greet("김철수", "반갑습니다")        # 기본값 대신 직접 지정
```

실행 결과:

```
안녕하세요, 홍길동님!
반갑습니다, 김철수님!
```

> ⚠️ **기본값이 있는 매개변수는 뒤쪽에 몰아야 합니다.**
> ```python
> def greet(greeting="안녕", name):   # SyntaxError!
> ```
> 앞에 기본값이 있으면 파이썬이 어떤 인자가 어디로 가는지 알 수 없기 때문입니다.

### 위치 인자와 키워드 인자

```python
def introduce(name, age, city="서울"):
    print(f"{name}({age}세) - {city}")

introduce("홍길동", 25)                       # 위치 인자
introduce("홍길동", 25, "부산")                # 위치 인자
introduce(name="홍길동", age=25, city="대구")  # 키워드 인자
introduce("홍길동", city="광주", age=25)       # 섞어 쓰기 (위치가 먼저)
```

실행 결과:

```

홍길동(25세) - 부산
홍길동(25세) - 대구
홍길동(25세) - 광주
```

> **키워드 인자를 쓰면 좋은 이유** — 인자가 많을 때 무엇이 무엇인지 읽힙니다.
> `create_model(32, 3, 2, True)` 보다 `create_model(filters=32, kernel=3, pool=2, dropout=True)` 가 훨씬 명확합니다.

### `*args` — 개수가 정해지지 않은 위치 인자

매개변수 앞에 `*` 를 붙이면, 넘어온 값들을 **튜플로 묶어** 받습니다.

```python
def total(*numbers):
    print(numbers, type(numbers))
    result = 0
    for n in numbers:
        result += n
    return result

print(total(1, 2))
print(total(1, 2, 3, 4, 5))
print(total())
```

실행 결과:

```
(1, 2) <class 'tuple'>
3
(1, 2, 3, 4, 5) <class 'tuple'>
15
() <class 'tuple'>
0
```

> 이름은 꼭 `args` 가 아니어도 됩니다. `*numbers`, `*scores` 처럼 뜻이 보이는 이름이 더 좋습니다.
> 중요한 건 **`*` 기호**입니다.

### `**kwargs` — 개수가 정해지지 않은 키워드 인자

`**` 를 붙이면 `이름=값` 형태의 인자들을 **딕셔너리로 묶어** 받습니다.

```python
def print_profile(**info):
    print(info, type(info))
    for key, value in info.items():
        print(f"  {key}: {value}")

print_profile(name="홍길동", age=25, city="서울")
```

실행 결과:

```
{'name': '홍길동', 'age': 25, 'city': '서울'} <class 'dict'>
  name: 홍길동
  age: 25
  city: 서울
```

> 딕셔너리는 [Day 013](day-013.md)에서 제대로 배웁니다. 지금은 "이름표가 붙은 값들의 묶음" 정도로 이해하면 충분합니다.

### lambda — 이름 없는 한 줄 함수

간단한 함수는 `lambda` 로 한 줄에 쓸 수 있습니다.

```python
lambda 매개변수: 반환값
```

```python
# 일반 함수
def square(x):
    return x ** 2

# lambda 로 같은 것
square_lambda = lambda x: x ** 2

print(square(5))          # 25
print(square_lambda(5))   # 25
```

`lambda` 는 **다른 함수에 인자로 넘길 때** 진가를 발휘합니다.

```python
scores = "85 92 78 90 65"
numbers = scores.split()

# 문자열을 숫자로 바꿔 정렬
sorted_scores = sorted(numbers, key=lambda x: int(x), reverse=True)
print(sorted_scores)
```

실행 결과:

```
['92', '90', '85', '78', '65']
```

> **언제 lambda 를 쓰는가** — 한 번만 쓰고 버릴 짧은 함수일 때입니다.
> 두 줄이 넘어가면 `def` 로 이름을 붙이세요. 읽기 어려운 `lambda` 는 안 쓰느니만 못합니다.

### 재귀 함수 — 자기 자신을 부르는 함수

```python
def countdown(n):
    if n <= 0:              # ① 종료 조건 (필수!)
        print("발사!")
        return

    print(n)
    countdown(n - 1)        # ② 자기 자신 호출 (조건에 가까워지게)

countdown(3)
```

실행 결과:

```
3
2
1
발사!
```

**동작 원리 — 함수가 쌓였다가 하나씩 풀립니다.**

```
countdown(3) → print(3) → countdown(2)
                             → print(2) → countdown(1)
                                             → print(1) → countdown(0)
                                                             → print("발사!") → return
```

**팩토리얼 예제**

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))       # 5 * 4 * 3 * 2 * 1 = 120
```

실행 결과:

```
120
```

> ⚠️ **재귀에는 반드시 종료 조건이 있어야 합니다.** 없으면 `RecursionError` 가 납니다.
> 파이썬은 기본적으로 약 1,000번까지만 재귀를 허용합니다.
>
> **실무에서는 반복문이 더 자주 쓰입니다.** 재귀는 트리 탐색·폴더 순회처럼 구조가 스스로를 닮은 경우에 씁니다.
> 지금은 "이런 것이 있다" 정도로 이해하고, 동작 원리를 그림으로 그려 보는 것에 집중하세요.

def make_coffee(kind="아메리카노", size="레귤러", ice=True, shots=1):

### Step 2. 가변 인자로 통계 함수 만들기

```python
def get_sum(*numbers):
    """받은 모든 숫자의 합을 반환합니다."""
    total = 0
    for n in numbers:
        total += n
    return total


def get_average(*numbers):
    """받은 모든 숫자의 평균을 반환합니다. 없으면 0."""
    if len(numbers) == 0:
        return 0
    return get_sum(*numbers) / len(numbers)


def get_max(*numbers):
    """받은 숫자 중 최댓값을 반환합니다. 없으면 None."""
    if len(numbers) == 0:
        return None

    result = numbers[0]
    for n in numbers:
        if n > result:
            result = n
    return result


print(get_sum(1, 2, 3))                 # 6
print(get_sum(10, 20, 30, 40, 50))      # 150
print(get_average(85, 92, 78))          # 85.0
print(get_max(85, 92, 78))              # 92
print(get_average())                    # 0
```

실행 결과:

```
6
150
85.0
92
0
```

> `get_sum(*numbers)` 처럼 호출할 때도 `*` 를 붙이면, 묶여 있던 튜플이 **다시 낱개로 풀려서** 전달됩니다.
> 이것을 **언패킹(unpacking)** 이라고 합니다.
>
> 참고 — 파이썬에는 이미 `sum()`, `max()`, `min()`, `len()` 이 내장되어 있습니다.
> 여기서 직접 만들어 보는 이유는 **원리를 이해하기 위해서**입니다. 실제 코드에서는 내장 함수를 쓰세요.

### Step 4. 재귀 함수 이해하기

```python
def factorial(n):
    """n! 을 계산합니다."""
    print(f"  factorial({n}) 호출됨")

    if n <= 1:
        print(f"  factorial({n}) → 1 반환")
        return 1

    result = n * factorial(n - 1)
    print(f"  factorial({n}) → {result} 반환")
    return result


print("factorial(4) 계산 시작")
answer = factorial(4)
print(f"최종 결과: {answer}")
```

실행 결과:

```
factorial(4) 계산 시작
  factorial(4) 호출됨
  factorial(3) 호출됨
  factorial(2) 호출됨
  factorial(1) 호출됨
  factorial(1) → 1 반환
  factorial(2) → 2 반환
  factorial(3) → 6 반환
  factorial(4) → 24 반환
최종 결과: 24
```

> **호출이 전부 쌓인 뒤, 가장 안쪽부터 값이 돌아옵니다.** 이 출력을 보면 재귀의 동작이 눈에 보입니다.
> 재귀가 헷갈릴 때는 이렇게 `print` 를 넣어 흐름을 직접 확인하는 것이 가장 빠른 학습법입니다.

**같은 계산을 반복문으로**

```python
def factorial_loop(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

print(factorial_loop(4))      # 24
```

### Step 5. 텍스트 RPG 전투 시스템 (오늘의 종합 예제)

내일 완성할 RPG의 뼈대를 함수로 설계합니다.

```python
import random


def create_character(name, hp=100, attack=10, defense=5):
    """캐릭터 정보를 문자열로 요약해 반환합니다."""
    return f"{name} (HP {hp} / 공격 {attack} / 방어 {defense})"


def calculate_damage(attack, defense, critical_rate=0.2):
    """공격력과 방어력으로 데미지를 계산합니다. 확률적으로 치명타가 발생합니다."""
    base = attack - defense // 2

    if base < 1:
        base = 1

    # 무작위 변동 (±20%)
    damage = int(base * random.uniform(0.8, 1.2))

    # 치명타 판정
    is_critical = random.random() < critical_rate
    if is_critical:
        damage *= 2

    return damage, is_critical


def show_hp_bar(name, current, maximum, width=20):
    """체력 바를 시각적으로 출력합니다."""
    if current < 0:
        current = 0

    filled = int(width * current / maximum)
    bar = "█" * filled + "░" * (width - filled)
    print(f"{name:<8} [{bar}] {current}/{maximum}")


def is_alive(hp):
    """살아 있는지 확인합니다."""
    return hp > 0


# ── 전투 시작 ──
PLAYER_MAX_HP = 100
ENEMY_MAX_HP = 80

player_hp = PLAYER_MAX_HP
enemy_hp = ENEMY_MAX_HP

print("=" * 40)
print(create_character("용사", PLAYER_MAX_HP, 15, 5))
print(create_character("고블린", ENEMY_MAX_HP, 12, 3))
print("=" * 40)

turn = 1

while is_alive(player_hp) and is_alive(enemy_hp):
    print(f"\n--- {turn}턴 ---")

    # 플레이어 공격
    damage, crit = calculate_damage(attack=15, defense=3)
    enemy_hp -= damage
    mark = " 치명타!" if crit else ""
    print(f"용사의 공격! 고블린에게 {damage}의 피해{mark}")

    if not is_alive(enemy_hp):
        break

    # 적 공격
    damage, crit = calculate_damage(attack=12, defense=5)
    player_hp -= damage
    mark = " 치명타!" if crit else ""
    print(f"고블린의 공격! 용사에게 {damage}의 피해{mark}")

    print()
    show_hp_bar("용사", player_hp, PLAYER_MAX_HP)
    show_hp_bar("고블린", enemy_hp, ENEMY_MAX_HP)

    turn += 1

print("\n" + "=" * 40)
if is_alive(player_hp):
    print("승리! 고블린을 물리쳤습니다.")
else:
    print("패배... 용사가 쓰러졌습니다.")
print("=" * 40)
```

실행 결과 (무작위이므로 매번 달라집니다):

```

고블린 (HP 80 / 공격 12 / 방어 3)
========================================

--- 1턴 ---
용사의 공격! 고블린에게 14의 피해
고블린의 공격! 용사에게 21의 피해 치명타!

용사     [████████████████░░░░] 79/100
고블린   [████████████████░░░░] 66/80

--- 2턴 ---
용사의 공격! 고블린에게 28의 피해 치명타!
고블린의 공격! 용사에게 9의 피해

용사     [██████████████░░░░░░] 70/100
고블린   [█████████░░░░░░░░░░░] 38/80

```

> **눈여겨볼 점 4가지**
> - `calculate_damage` 는 **데미지와 치명타 여부를 함께 반환**합니다. (`return damage, is_critical`)
> - `critical_rate=0.2` 기본값 덕분에 보통은 신경 쓰지 않고 호출하다가, 보스전에서만 `critical_rate=0.05` 로 낮출 수 있습니다.
> - `random.uniform(0.8, 1.2)` 는 실수 난수, `random.random()` 은 0~1 사이 난수입니다. 확률 판정의 기본 도구입니다.
> - **메인 코드가 짧습니다.** 계산·출력·판정이 전부 함수로 빠져 있어 전투 흐름만 남았습니다. 내일 이 구조를 확장합니다.

## ⑤ 자주 하는 실수

### `SyntaxError` — 기본값 매개변수를 앞에 둠

```python
def greet(greeting="안녕", name):
    ...
```

```
SyntaxError: parameter without a default follows parameter with a default
```

**원인** — 기본값이 있는 매개변수 뒤에 기본값 없는 매개변수를 둘 수 없습니다.
**해결** — 기본값 없는 것을 앞으로: `def greet(name, greeting="안녕"):`

### 기본값으로 리스트를 씀 (파이썬의 유명한 함정)

```python
def add_item(item, basket=[]):     # 위험!
    basket.append(item)
    return basket

print(add_item("사과"))     # ['사과']
print(add_item("바나나"))   # ['사과', '바나나']  ← 기대와 다름!
```

**원인** — 기본값은 **함수를 정의할 때 딱 한 번** 만들어집니다. 호출할 때마다 새로 만들어지지 않습니다.
**해결** — `None` 을 기본값으로 두고 함수 안에서 만듭니다.

```python
def add_item(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket
```

> 리스트는 [Day 011](day-011.md)에서 배웁니다. 지금은 "**기본값에 리스트·딕셔너리를 쓰지 않는다**"만 기억하세요.

### `*args` 를 받는 함수에 리스트를 그대로 넘김

```python
def get_sum(*numbers):
    total = 0
    for n in numbers:
        total += n
    return total

scores = [85, 92, 78]
print(get_sum(scores))       # TypeError
```

```
TypeError: unsupported operand type(s) for +=: 'int' and 'list'
```

**원인** — 리스트 하나를 통째로 넘겼습니다. `numbers` 는 `([85, 92, 78],)` 이 됩니다.
**해결** — `*` 로 풀어서 넘깁니다.

```python
print(get_sum(*scores))      # 255
```

### 위치 인자를 키워드 인자 뒤에 씀

```python
introduce(name="홍길동", 25)
```

```
SyntaxError: positional argument follows keyword argument
```

**원인** — 키워드 인자가 나온 뒤에는 위치 인자를 쓸 수 없습니다.
**해결** — 위치 인자를 먼저: `introduce("홍길동", age=25)`

### `RecursionError` — 재귀 종료 조건 누락

```python
def countdown(n):
    print(n)
    countdown(n - 1)     # 종료 조건 없음

countdown(3)
```

```
RecursionError: maximum recursion depth exceeded
```

**원인** — 자기 자신을 무한히 부릅니다.
**해결** — 종료 조건을 반드시 넣습니다.

```python
def countdown(n):
    if n <= 0:
        return
    print(n)
    countdown(n - 1)
```

### lambda 를 너무 복잡하게 씀

```python
grade = lambda s: "A" if s >= 90 else ("B" if s >= 80 else ("C" if s >= 70 else "F"))
```

**문제** — 동작은 하지만 읽을 수가 없습니다.
**해결** — 세 줄이 넘어가면 `def` 를 쓰세요.

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    return "F"
```

## ⑥ 확인 문제

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
def show(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)

show(1)
show(1, 5, 7, 9, x=10)
```

<details>
<summary>답 보기</summary>

```
1 2 () {}
1 5 (7, 9) {'x': 10}
```

- 첫 호출: `a=1`, `b` 는 기본값 `2`, 나머지는 비어 있음.
- 두 번째 호출: `a=1`, `b=5`, 남은 위치 인자 `7, 9` 는 `args` 튜플로, 키워드 인자 `x=10` 은 `kwargs` 딕셔너리로 들어갑니다.

**순서 규칙** — 일반 → 기본값 → `*args` → `**kwargs`
</details>

**2.** 여러 개의 점수를 받아 **최고점과 최저점을 제외한 평균**을 반환하는 함수를 만드세요. (체조 점수 방식)

<details>
<summary>답 보기</summary>

```python
def trimmed_average(*scores):
    """최고점과 최저점을 제외한 평균을 반환합니다."""
    if len(scores) < 3:
        return None                # 3개 미만이면 계산 불가

    total = 0
    highest = scores[0]
    lowest = scores[0]

    for s in scores:
        total += s
        if s > highest:
            highest = s
        if s < lowest:
            lowest = s

    trimmed_total = total - highest - lowest
    return trimmed_total / (len(scores) - 2)


print(trimmed_average(9.5, 9.8, 9.2, 9.9, 9.6))
print(trimmed_average(10, 20))
```

실행 결과:

```
9.633333333333333
None
```

**포인트 3가지**
- `*scores` 로 개수 제한 없이 받습니다.
- 인자가 3개 미만이면 계산이 불가능하므로 `None` 을 반환해 알립니다.
- 리스트를 배우면 `sorted(scores)[1:-1]` 로 훨씬 짧게 쓸 수 있습니다. ([Day 011](day-011.md))
</details>

**3.** 아래 코드가 왜 예상과 다르게 동작하는지 설명하고 고치세요.

```python
def add_log(message, logs=[]):
    logs.append(f"[LOG] {message}")
    return logs

print(add_log("첫 번째"))
print(add_log("두 번째"))
print(add_log("세 번째"))
```

<details>
<summary>답 보기</summary>

실제 출력:

```
['[LOG] 첫 번째']
['[LOG] 첫 번째', '[LOG] 두 번째']
['[LOG] 첫 번째', '[LOG] 두 번째', '[LOG] 세 번째']
```

기대했던 출력:

```
['[LOG] 첫 번째']
['[LOG] 두 번째']
['[LOG] 세 번째']
```

**원인** — 기본값 `[]` 는 **함수를 정의하는 순간 딱 한 번만** 만들어집니다.
그 하나의 리스트를 모든 호출이 **공유**하기 때문에 계속 쌓입니다.

**해결**

```python
def add_log(message, logs=None):
    if logs is None:
        logs = []                  # 호출할 때마다 새로 만듦
    logs.append(f"[LOG] {message}")
    return logs


print(add_log("첫 번째"))     # ['[LOG] 첫 번째']
print(add_log("두 번째"))     # ['[LOG] 두 번째']
```

> 이것을 **가변 기본 인자(mutable default argument)** 문제라고 하며, 파이썬에서 가장 유명한 함정 중 하나입니다.
> **규칙** — 기본값에는 숫자·문자열·`True`/`False`·`None` 만 씁니다. 리스트·딕셔너리·세트는 절대 쓰지 않습니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 기본값 매개변수 | `def f(a, b=10)` — **기본값은 뒤쪽에** |
| 키워드 인자 | `f(b=10, a=5)` — 순서 무관, 가독성 향상 |
| `*args` | 남은 위치 인자를 **튜플**로 |
| `**kwargs` | 남은 키워드 인자를 **딕셔너리**로 |
| 순서 | 일반 → 기본값 → `*args` → `**kwargs` |
| 언패킹 | `f(*리스트)` — 묶인 것을 낱개로 풀어 전달 |
| `lambda` | `lambda x: x**2` — 짧을 때만 |
| 재귀 | **종료 조건 필수** · 파이썬은 약 1000회 한계 |

**오늘 반드시 기억할 한 가지**
> 기본값에 **리스트·딕셔너리를 쓰지 마세요.** 모든 호출이 그 하나를 공유합니다. `None` 을 쓰고 함수 안에서 만드세요.

예: `print_stars(n, char="*", align="left")`, `get_total(*numbers)`
