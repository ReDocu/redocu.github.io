## 2부 · 평균 회귀의 원인 진단

### 기울기 0.52가 의미하는 것

```
      예측
       │           ╱ (이상: 기울기 1.0)
   50  │        ╱
       │     ╱  ····
   40  │  ╱  ·:::::·
       │╱ ·:::::·        ← 실제 기울기 0.52
   30  │·:::·
       │
       └──────────────── 실제
        20   40   60
```

```
실제 20% → 예측 약 30%  (과대)
실제 60% → 예측 약 45%  (과소)
→ 모두 평균(34%) 쪽으로 끌림
```

### 원인 3가지와 구분법

| 원인 | 확인 방법 | 조치 |
|---|---|---|
| **① 특성 정보 부족** | 학습셋에서도 기울기가 낮은가 | **특성 공학** |
| ② 과적합 | 학습 기울기 1.0, 검증 0.5 | 규제 |
| ③ 손실 함수 | MAE는 중앙값 추종 | MSE 병행 확인 |

**핵심 진단**

```python
slope_train = linregress(y_train, pred_train).slope
slope_val = linregress(y_val, pred_val).slope
```

```
학습 0.95 / 검증 0.52  →  ② 과적합
학습 0.60 / 검증 0.52  →  ★ ① 특성 정보 부족
```

### 특성 정보 부족의 대응

```
① 새 특성 추가        ← 오늘의 주제
② 상호작용 항
③ 외부 데이터 결합
④ 문제 재정의 (예측 범위 축소)
```

## 3부 · 새 특성 설계

### ① 상호작용 항

**두 특성의 조합이 각각보다 유용한 경우입니다.**

```
"오래된 게임"        → 할인율 높음
"인기 많은 게임"      → 할인율 낮음
"오래됐는데 인기 많음" → ?  ← 조합이 정보
```

**만드는 법**

```python
df["age_x_popularity"] = df["log_days"] * df["log_reviews"]
df["price_x_age"] = df["log_price"] * df["years_since_release"]
```

**또는 자동 생성**

```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=2, interaction_only=True, include_bias=False)
```

> ⚠️ **자동 생성은 특성 수가 폭발합니다.**
> 50개 → 1,275개. **상위 몇 개만 골라 수동으로 만드세요.**

### ② 구간화 (Binning)

**연속 특성을 구간으로 나눕니다.**

| 언제 유용한가 | 예 |
|---|---|
| 관계가 계단형 | 출시 1년/3년/5년 경계 |
| **선형 모델**에 비선형을 주입 | 가격대 |
| 극단값 완화 | 리뷰 수 구간 |

```python
df["price_tier"] = pd.qcut(df["initial_price"], q=5, labels=False)
df["review_tier"] = pd.qcut(df["review_count"], q=5, labels=False)
```

> **트리 모델에는 효과가 작습니다.** 트리가 이미 구간을 만들기 때문입니다.
> **선형·신경망에서 효과가 큽니다.**

### ③ 비율·차이 특성

```python
# 장르 평균 대비 이 게임의 가격
```

## 4부 · 특성 선택

### 왜 특성을 줄이는가

| 이유 | 설명 |
|---|---|
| 과적합 감소 | 특성이 적으면 P/S 비율 개선 |
| **학습 속도** | 특성 절반 → 학습 2배 빠름 |
| 해석 용이 | 20개보다 10개가 설명하기 쉬움 |
| 노이즈 제거 | 무의미한 특성이 학습을 방해 |

### 방법 3가지

| 방법 | 코드 | 특징 |
|---|---|---|
| **필터** | `SelectKBest(f_regression, k=20)` | 빠름. 상호작용 무시 |
| **래퍼** | `RFE(estimator, n_features_to_select=20)` | 느림. 모델 기반 |
| **임베디드** | `SelectFromModel(Lasso())` | 학습 중 자동 |

### ★ 반드시 Pipeline 안에서

```python
# ✗ 밖에서 (Day 122: 9.5% 부풀림)
X_sel = SelectKBest(k=20).fit_transform(X, y)

# ✓ Pipeline 안에서
Pipeline([("sel", SelectKBest(k=20)), ("model", model)])
```

```python
class Tracker:
    COLS = ["exp_id", "timestamp", "parent", "변경", "모델", "특성수",
            "val_MAE", "val_RMSE", "val_R2", "기울기", "train_MAE", "격차",
            "규칙대비(%)", "부모대비(%)", "학습(s)", "관찰", "다음시도"]

    def __init__(self, path):
        self.path = Path(path)
        self.df = (pd.read_csv(self.path) if self.path.exists()
                   else pd.DataFrame(columns=self.COLS))

    def next_id(self):
        return f"F{len(self.df)+1:03d}"

    def log(self, **kw):
        row = {c: kw.get(c) for c in self.COLS}
        row["exp_id"] = row["exp_id"] or self.next_id()
        row["timestamp"] = time.strftime("%H:%M:%S")
        if row["parent"] and not self.df.empty:
            p = self.df[self.df["exp_id"] == row["parent"]]
            if len(p) and row["val_MAE"]:
                before = float(p.iloc[0]["val_MAE"])
                row["부모대비(%)"] = round((before - row["val_MAE"]) / before * 100, 2)

            row["규칙대비(%)"] = round(
                (BASE_MAE_RULE - row["val_MAE"]) / BASE_MAE_RULE * 100, 2)
        self.df = pd.concat([self.df, pd.DataFrame([row])], ignore_index=True)
        self.df.to_csv(self.path, index=False, encoding="utf-8-sig")
        return row["exp_id"]

    def view(self, n=None):
        cols = ["exp_id", "parent", "변경", "모델", "특성수", "val_MAE",
                "기울기", "규칙대비(%)", "부모대비(%)", "관찰"]
        d = self.df[cols]
        return d.tail(n) if n else d
```

### Step 2. 공통 평가 함수와 기준선 재현

```python
import time

import numpy as np
import pandas as pd
from scipy import stats as sps
from sklearn.compose import ColumnTransformer
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.impute import SimpleImputer
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, TargetEncoder

SEED = 42


def build_frames(df, feats):
    """특성 + 그룹 열을 담은 학습/검증 프레임"""
    cols = feats + ["developer", "publisher"]
    return (df.loc[tr_mask, cols], df.loc[va_mask, cols],
            df.loc[tr_mask, TARGET], df.loc[va_mask, TARGET])


def make_preprocessor(feats, df):
    binary_like = [c for c in feats
                   if df[c].dropna().isin([0, 1]).all() and df[c].nunique() <= 2]
    numeric = [c for c in feats if c not in binary_like]
    num_pipe = Pipeline([("impute", SimpleImputer(strategy="median")),
                         ("scale", StandardScaler())])
    return ColumnTransformer([
        ("num", num_pipe, numeric),
        ("bin", "passthrough", binary_like),
        ("dev", Pipeline([("te", TargetEncoder(smooth="auto", cv=5, random_state=SEED)),
                          ("sc", StandardScaler())]), ["developer"]),
        ("pub", Pipeline([("te", TargetEncoder(smooth="auto", cv=5, random_state=SEED)),
                          ("sc", StandardScaler())]), ["publisher"]),
    ], remainder="drop", verbose_feature_names_out=False)


def make_model(kind="hgb"):
    if kind == "hgb":
        return HistGradientBoostingRegressor(
            max_iter=400, random_state=SEED, early_stopping=True,
            validation_fraction=0.15, n_iter_no_change=25)
    if kind == "rf":
        from sklearn.ensemble import RandomForestRegressor
        return RandomForestRegressor(n_estimators=400, min_samples_leaf=2,
                                     random_state=SEED, n_jobs=-1)
    if kind == "ridge":
        from sklearn.linear_model import RidgeCV
        return RidgeCV(alphas=np.logspace(-3, 3, 30))
    raise ValueError(kind)


def evaluate(df, feats, kind="hgb", extra_steps=None, label=""):
    """특성 목록으로 학습·평가. 진단 지표까지 반환"""
    Xtr, Xva, ytr, yva = build_frames(df, feats)
    steps = [("pre", make_preprocessor(feats, df))]
    if extra_steps:
        steps += extra_steps
    steps.append(("m", make_model(kind)))
    pipe = Pipeline(steps)

    t0 = time.perf_counter()
    pipe.fit(Xtr, ytr)
    el = time.perf_counter() - t0

    p_va = np.clip(pipe.predict(Xva), 0, 90)
    p_tr = np.clip(pipe.predict(Xtr), 0, 90)

    slope_va = float(sps.linregress(yva, p_va).slope)
    slope_tr = float(sps.linregress(ytr, p_tr).slope)
    mae_va = mean_absolute_error(yva, p_va)
    mae_tr = mean_absolute_error(ytr, p_tr)

    return {
        "모델": kind, "특성수": len(feats),
        "val_MAE": round(mae_va, 4),
        "val_RMSE": round(float(np.sqrt(mean_squared_error(yva, p_va))), 4),
        "val_R2": round(r2_score(yva, p_va), 4),
        "기울기": round(slope_va, 4),
```

## ⑤ 자주 하는 실수

### 기울기를 보고 "모델을 키우자"

```
기울기 0.52 → "모델이 약한가?" → 층 추가
→ 학습 기울기도 0.71이었음 → 특성 문제
```

**학습·검증 기울기를 함께 보고 원인을 구분하세요.**

### 개별 순열 중요도만 보고 특성 제거

```
log_days 중요도 1.24, days_since_release 0.12
→ "days_since_release를 지우자"
→ 그룹으로 섞으면 4.18. 둘 다 중요했음
```

**상관이 높은 특성은 그룹으로 측정하세요.**

### 특성 선택을 Pipeline 밖에서

**Step 5에서 6.17% 부풀림을 확인했습니다.**

### 여러 특성을 한 번에 추가

```
F002에서 파생 20개를 한꺼번에 추가
→ 무엇이 효과였는지 모름
```

**한 번에 하나의 "그룹"씩 추가하세요.**

### 상호작용 항을 자동으로 대량 생성

```python
PolynomialFeatures(degree=2)      # 61개 → 1,891개
```

**P/S 비율이 폭발합니다. 상위 특성끼리만 수동으로.**

### 집계 특성을 전체 데이터로 계산

```python
df["price_vs_genre"] = df["price"] / df.groupby("genre")["price"].transform("median")
```

**약한 누수입니다. 학습셋 기준 매핑을 만들어 적용하세요.**

### 신경망이 지는 것을 인정 안 함

```
"딥러닝 과정이니까 신경망을 써야 한다"
→ 검증셋을 여러 번 보며 신경망만 튜닝
→ 검증셋 과적합
```

**정직하게 보고하는 것이 더 좋은 프로젝트입니다.** ([Day 108](day-108.md))
