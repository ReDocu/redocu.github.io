## ② 왜 필요한가

### 어제 계단 함수로 XOR을 풀었습니다. 그런데

[Day 081](day-081.md) Step 6에서 퍼셉트론이 AND를 스스로 학습했습니다.
**XOR은 다층으로 풀 수 있다는 것도 알았습니다.**

그런데 **다층 퍼셉트론을 학습시키는 코드는 안 나왔습니다.** 왜일까요?

```python
def step(z):
    return 1 if z > 0 else 0
```

**계단 함수는 미분이 안 됩니다.**

```
계단 함수의 기울기
  z < 0 구간: 0
  z > 0 구간: 0
  z = 0 지점: 무한대 (정의 불가)
```

**거의 모든 곳에서 기울기가 0입니다.**

[Day 084](day-084.md)에서 배울 학습 방법(경사하강법)은 **기울기를 따라 내려가는 것**입니다.
기울기가 0이면 **어느 쪽으로 가야 할지 알 수 없습니다.**

```
"가중치를 0.01 늘리면 오차가 줄어드나?"
계단 함수: "출력이 그대로예요"       ← 아무 정보가 없음
Sigmoid:  "오차가 0.003 줄어요"     ← 방향을 알 수 있음
```

**그래서 계단 함수를 매끄러운 함수로 바꿉니다.** 그것이 오늘의 주제입니다.

### 그리고 더 중요한 이유 — 활성화 함수가 없으면 층이 무의미합니다

[Day 081](day-081.md) ⑤에서 잠깐 언급했습니다. 오늘 제대로 증명합니다.

```
활성화 함수 없이 2층을 쌓으면

  h = X·W₁ + b₁
  y = h·W₂ + b₂
    = (X·W₁ + b₁)·W₂ + b₂
    = X·(W₁W₂) + (b₁W₂ + b₂)
    = X·W' + b'                    ← 1층과 완전히 동일!
```

**100층을 쌓아도 1층입니다.**

```
직선 + 직선 = 직선
```

**비선형 함수를 사이에 넣어야 층이 의미를 갖습니다.**

### 오늘 배우는 것이 앞으로 매일 나옵니다

```python
model = Sequential([
    Dense(128, activation="relu"),      # ← 이것
    Dense(64, activation="relu"),       # ← 이것

])
```

## ③ 개념 설명

### 활성화 함수의 역할

```
   x₁ ──w₁──┐
            ├──→ [ Σ ] ──→ [ f ] ──→ y
   x₂ ──w₂──┘      ↑        ↑
                   b     활성화 함수
                          └─ 비선형성을 넣는 곳
```

| 역할 | 설명 |
|---|---|
| **비선형성 도입** | 없으면 층을 쌓아도 직선 하나 |
| **출력 범위 조절** | 확률(0~1)로 만들거나, 음수를 제거하거나 |
| **기울기 전달** | 학습 신호가 뒤로 흐르게 함 ([Day 084](day-084.md)) |

### Sigmoid

```
        1
σ(z) = ─────────
       1 + e^(-z)
```

```
σ(z)
 1.0│              ╭────────────
    │           ╭─╯
 0.5│─ ─ ─ ─ ─╭╯─ ─ ─ ─ ─ ─ ─
    │      ╭─╯
 0.0│─────╯
    └──────┼──────────────── z
   -6      0        6
```

| 특징 | 값 |
|---|---|
| 출력 범위 | **0 ~ 1** |
| σ(0) | **0.5** |
| σ(-∞) | 0 |
| σ(+∞) | 1 |
| 미분 | **σ'(z) = σ(z)(1 - σ(z))** |

**미분이 아름답습니다.** 자기 자신으로 표현됩니다.

```
σ'(0) = 0.5 × 0.5 = 0.25      ← 최댓값
σ'(4) = 0.982 × 0.018 = 0.018
σ'(8) = 0.9997 × 0.0003 = 0.0003
```

```
σ'(z)
0.25│      ╱╲
    │    ╱    ╲
    │  ╱        ╲
0.00│─╯          ╰──────
    └──────┼──────────── z
   -6      0        6
```

> **미분값의 최댓값이 0.25입니다.** 이것이 나중에 큰 문제가 됩니다.

### 기울기 소실 (Vanishing Gradient)

**역전파는 미분값을 층마다 곱해 가며 뒤로 전달합니다.** ([Day 084](day-084.md))

```
10층 신경망에서 첫 층까지 전달되는 기울기

최선의 경우 (모든 층에서 σ' = 0.25):
  0.25^10 = 0.00000095

보통의 경우 (σ' = 0.1):
  0.1^10 = 0.0000000001
```

**첫 층에는 신호가 사실상 도달하지 않습니다.**

| 결과 | 설명 |
|---|---|
| 앞쪽 층이 학습 안 됨 | 가중치가 거의 안 바뀜 |
| 깊은 신경망이 얕은 것보다 못함 | 층을 늘려도 성능이 안 오름 |
| 학습이 매우 느림 | 수렴에 오래 걸림 |

> **이 문제 때문에 1990~2000년대에 딥러닝이 정체됐습니다.**
> **ReLU(2011)의 등장이 돌파구 중 하나였습니다.**

**추가 문제 — Sigmoid의 출력이 항상 양수**

```
σ(z) > 0  항상
```

출력이 전부 양수면 다음 층의 기울기가 **전부 같은 부호**가 됩니다.
가중치 업데이트가 지그재그로 진행되어 학습이 느려집니다.
tanh는 이 문제를 해결합니다(출력이 -1~1).

### tanh (하이퍼볼릭 탄젠트)

```
          e^z - e^(-z)
tanh(z) = ─────────────  = 2σ(2z) - 1
          e^z + e^(-z)
```

```
tanh(z)
  1│           ╭──────────
   │        ╭─╯
  0│─ ─ ─╭─╯─ ─ ─ ─ ─ ─ ─
   │  ╭─╯
 -1│──╯
   └───────┼────────────── z
  -4       0       4
```

| | Sigmoid | tanh |
|---|---|---|
| 출력 범위 | 0 ~ 1 | **-1 ~ 1** |
| 중심 | 0.5 | **0** (제로 중심) |
| 미분 최댓값 | 0.25 | **1.0** |
| 기울기 소실 | 심함 | **덜 심함** |

**tanh가 Sigmoid보다 낫습니다.** 그런데 여전히 양 끝에서 기울기가 0에 수렴합니다.

> **Sigmoid는 출력층(이진 분류)에만, 은닉층에는 tanh나 ReLU를 씁니다.**

### ReLU (Rectified Linear Unit)

```
ReLU(z) = max(0, z)
```

```
ReLU
  4│           ╱
   │         ╱
  2│       ╱
   │     ╱
  0│────╯
   └─────┼──────────── z
   -4    0      4
```

**너무 단순해 보이는데 이것이 딥러닝을 바꿨습니다.**

| 장점 | 설명 |
|---|---|
| **기울기 소실 없음** | z > 0 구간에서 미분값이 **정확히 1** |
| **계산이 빠름** | 지수 함수 없음. 비교 한 번 |
| **희소성** | 음수를 0으로 → 일부 뉴런만 활성화 |

```
ReLU'(z) = 1  (z > 0)
         = 0  (z < 0)
```

**미분값이 1이므로 층을 아무리 쌓아도 신호가 그대로 전달됩니다.**

```
1^100 = 1        ← 기울기 소실 없음
0.25^100 = 0     ← Sigmoid
```

**단점 — Dying ReLU**

```
z < 0 이면 출력 0, 기울기도 0
→ 그 뉴런은 영원히 업데이트되지 않음
→ 죽은 뉴런(dead neuron)
```

학습률이 너무 크면 대량의 뉴런이 한꺼번에 죽을 수 있습니다.

### ReLU의 변형들

| 함수 | 수식 | 특징 |
|---|---|---|
| **LeakyReLU** | `max(0.01z, z)` | 음수에 작은 기울기 → 죽지 않음 |
| **PReLU** | `max(αz, z)`, α는 학습 | α를 데이터에서 학습 |
| **ELU** | `z (z>0)`, `α(e^z - 1) (z≤0)` | 부드러움. 평균이 0에 가까움 |
| **GELU** | `z·Φ(z)` | Transformer에서 표준 |
| **Swish/SiLU** | `z·σ(z)` | 깊은 망에서 ReLU보다 나은 경우 |

```
LeakyReLU
  4│           ╱
   │         ╱
  2│       ╱
   │     ╱
  0│────╯
   │ ╱ (기울기 0.01)
 -1│╱
   └─────┼──────────── z
```

> **실무에서는 ReLU로 시작하세요.** 문제가 있으면 LeakyReLU나 ELU를 시도합니다.
> 대부분의 경우 ReLU로 충분합니다.

### Softmax — 다중 분류의 출력층

**여러 클래스 중 하나를 고를 때 씁니다.**

```
             e^(zᵢ)
softmax(zᵢ) = ─────────
             Σ e^(zⱼ)
```

**계산 예시** — 3클래스, `z = [2.0, 1.0, 0.1]`

```
e^2.0 = 7.389
e^1.0 = 2.718
e^0.1 = 1.105
합계  = 11.212

softmax = [7.389/11.212, 2.718/11.212, 1.105/11.212]
        = [0.659, 0.242, 0.099]
                              합 = 1.000 ✓
```

| 특징 | 설명 |
|---|---|
| 출력 범위 | 각각 0 ~ 1 |
| **합** | **항상 1** → 확률로 해석 가능 |
| 큰 값 강조 | 지수 함수라 차이가 벌어짐 |
| 상호 배타 | 하나가 올라가면 나머지가 내려감 |

**Sigmoid vs Softmax**

| | Sigmoid | Softmax |
|---|---|---|
| 출력 노드 수 | 1개 | **클래스 수만큼** |
| 합 | — | **1** |
| 쓰는 곳 | 이진 분류, **다중 라벨** | **다중 분류** |
| 예 | "스팸인가?" | "개/고양이/새 중 무엇?" |

> **다중 라벨(multi-label)** — 한 이미지에 여러 정답이 가능한 경우입니다.
> "이 사진에 사람도 있고 자동차도 있다" → 각 클래스마다 **독립적인 Sigmoid**를 씁니다.
> 대단원 05의 Object Detection에서 이 구분이 중요해집니다.

### ★ 문제 유형별 선택표 — 이 표를 외우세요

| 문제 | 출력 노드 | 출력층 활성화 | 손실 함수 | 예시 |
|---|---|---|---|---|
| **회귀** | 1 | **없음 (linear)** | `mse` | 집값 예측 |
| **이진 분류** | 1 | **sigmoid** | `binary_crossentropy` | 늑대 vs 허스키 |
| **다중 분류** | 클래스 수 | **softmax** | `categorical_crossentropy` | MNIST 0~9 |
| **다중 분류(정수 라벨)** | 클래스 수 | softmax | `sparse_categorical_crossentropy` | 위와 동일 |
| **다중 라벨** | 라벨 수 | **sigmoid** | `binary_crossentropy` | 사진 속 물체 여러 개 |

**은닉층은?**

```
은닉층 활성화 함수 = ReLU        ← 고민하지 마세요. 기본값입니다.
```

> ⚠️ **가장 흔한 실수 — 출력층에 ReLU를 씀**
> ```python

> ```

## ④ 단계별 실습

### Step 1. 활성화 함수 직접 구현하고 그리기

```python
import matplotlib.pyplot as plt
import numpy as np


# ── 활성화 함수들 ──
def step(z):
    return np.where(z > 0, 1.0, 0.0)


def sigmoid(z):
    return 1 / (1 + np.exp(-z))


def tanh(z):
    return np.tanh(z)


def relu(z):
    return np.maximum(0, z)


def leaky_relu(z, alpha=0.01):
    return np.where(z > 0, z, alpha * z)


def elu(z, alpha=1.0):
    return np.where(z > 0, z, alpha * (np.exp(np.minimum(z, 0)) - 1))


def swish(z):
    return z * sigmoid(z)


# ── 미분 ──
def sigmoid_d(z):
    s = sigmoid(z)
    return s * (1 - s)


def tanh_d(z):
    return 1 - np.tanh(z) ** 2


def relu_d(z):
    return np.where(z > 0, 1.0, 0.0)


def leaky_relu_d(z, alpha=0.01):
    return np.where(z > 0, 1.0, alpha)


def elu_d(z, alpha=1.0):
    return np.where(z > 0, 1.0, alpha * np.exp(np.minimum(z, 0)))


z = np.linspace(-6, 6, 500)

functions = [
    ("Step", step, None, "#888888"),
    ("Sigmoid", sigmoid, sigmoid_d, "#1f77b4"),
    ("tanh", tanh, tanh_d, "#ff7f0e"),
    ("ReLU", relu, relu_d, "#2ca02c"),
    ("LeakyReLU", leaky_relu, leaky_relu_d, "#d62728"),
    ("ELU", elu, elu_d, "#9467bd"),
]

fig, axes = plt.subplots(2, 3, figsize=(16, 8))

for ax, (name, f, fd, color) in zip(axes.ravel(), functions):
    ax.plot(z, f(z), color=color, linewidth=2.5, label=name)
    if fd is not None:
        ax.plot(z, fd(z), color=color, linewidth=1.6, linestyle="--",
                alpha=0.75, label=f"{name}' (derivative)")
    ax.axhline(0, color="black", linewidth=0.6)
    ax.axvline(0, color="black", linewidth=0.6)
    ax.set_title(name, fontsize=12)
    ax.set_xlabel("z")
    ax.set_ylim(-1.6, 3.2)
    ax.legend(fontsize=8.5)
    ax.grid(alpha=0.3)

fig.suptitle("Activation functions (solid) and their derivatives (dashed)", fontsize=14)
fig.tight_layout()
plt.show()

# ── 수치 확인 ──
test_z = np.array([-5, -2, -0.5, 0, 0.5, 2, 5], dtype=float)

print("=" * 84)
print("입력값에 따른 출력 비교")
print("=" * 84)
print(f"{'z':>8}{'Step':>10}{'Sigmoid':>10}{'tanh':>10}{'ReLU':>10}"
      f"{'LeakyReLU':>12}{'ELU':>10}{'Swish':>10}")
print("-" * 84)
for v in test_z:
    print(f"{v:>8.1f}{step(v):>10.3f}{sigmoid(v):>10.3f}{tanh(v):>10.3f}"
          f"{relu(v):>10.3f}{leaky_relu(v):>12.3f}{elu(v):>10.3f}{swish(v):>10.3f}")
print("=" * 84)

print("\n[미분값 비교] — 학습 신호가 얼마나 잘 전달되는가")
print(f"{'z':>8}{'Sigmoid_d':>12}{'tanh_d':>12}{'ReLU_d':>12}{'LeakyReLU_d':>14}")
print("-" * 60)
for v in test_z:
    print(f"{v:>8.1f}{sigmoid_d(v):>12.4f}{tanh_d(v):>12.4f}"
          f"{relu_d(v):>12.4f}{leaky_relu_d(v):>14.4f}")
print("-" * 60)
print(f"미분 최댓값: Sigmoid {sigmoid_d(z).max():.4f}  "
      f"tanh {tanh_d(z).max():.4f}  ReLU 1.0000")
```

### Step 4. Softmax — 다중 분류 확률 만들기

```python
import matplotlib.pyplot as plt
import numpy as np


def softmax_naive(z):
    """교과서 그대로 — 오버플로 위험 있음"""
    e = np.exp(z)
    return e / e.sum()


def softmax(z):
    """안전한 구현 — 최댓값을 빼서 오버플로 방지"""
    z = np.asarray(z, dtype=float)
    e = np.exp(z - z.max())
    return e / e.sum()


print("=" * 70)
print("Softmax 계산 과정")
print("=" * 70)

z = np.array([2.0, 1.0, 0.1])
classes = ["개", "고양이", "새"]

e = np.exp(z)
print(f"{'클래스':>8}{'z':>10}{'e^z':>14}{'e^z / 합':>14}")
print("-" * 70)
for c, zi, ei in zip(classes, z, e):
    print(f"{c:>8}{zi:>10.2f}{ei:>14.6f}{ei / e.sum():>14.6f}")
print("-" * 70)
print(f"{'합계':>8}{'':>10}{e.sum():>14.6f}{(e / e.sum()).sum():>14.6f}")
print("=" * 70)

# ── 성질 ──
print("\n[Softmax의 성질]")
p = softmax(z)
print(f"1) 합 = {p.sum():.10f}   → 항상 1")
print(f"2) 모든 값이 0~1 사이: {p.min():.4f} ~ {p.max():.4f}")
print(f"3) 순서 보존: z의 순서 {np.argsort(z)[::-1]} = p의 순서 {np.argsort(p)[::-1]}")

# 평행이동 불변
print(f"\n4) 평행이동 불변 — 모든 z에 같은 수를 더해도 결과 동일")
for shift in [0, 10, 100]:
    print(f"   z + {shift:>3}: {np.round(softmax(z + shift), 6)}")

# ── 오버플로 문제 ──
print("\n" + "=" * 70)
print("왜 최댓값을 빼는가 — 오버플로 방지")

try:
    with np.errstate(over="raise"):
        naive = softmax_naive(big)
    print(f"naive 결과: {naive}")
except FloatingPointError:
    print("naive 결과: OverflowError!  e^1000 = inf")
print(f"안전한 구현: {np.round(softmax(big), 6)}")

# ── 온도(temperature) 효과 ──

print(f"{'배율':>8}{'z':>28}{'softmax':>34}")
print("-" * 70)

    zz = base * scale
    print(f"{scale:>8.1f}{str(np.round(zz, 2)):>28}{str(np.round(softmax(zz), 4)):>34}")
print("-" * 70)
print("배율이 크면 → 확률이 한쪽으로 몰림 (모델이 확신)")
print("배율이 작으면 → 확률이 고르게 (모델이 불확실)")

            ha="center", fontsize=11)
```

## ⑥ 확인 문제

**1.** 아래 값들에 대해 Sigmoid, ReLU, tanh 출력을 손으로 계산(또는 추정)하고, 각 함수의 미분값도 구하세요.

```
z = -2, 0, 3
```

<details>
<summary>답 보기</summary>

**Sigmoid** `σ(z) = 1/(1+e^-z)`, `σ'(z) = σ(z)(1-σ(z))`

| z | e^(-z) | σ(z) | σ'(z) |
|---|---|---|---|
| -2 | 7.389 | 1/8.389 = **0.1192** | 0.1192 × 0.8808 = **0.1050** |
| 0 | 1.000 | 1/2 = **0.5000** | 0.5 × 0.5 = **0.2500** |
| 3 | 0.0498 | 1/1.0498 = **0.9526** | 0.9526 × 0.0474 = **0.0452** |

**ReLU** `max(0,z)`, 미분은 `z>0`이면 1, 아니면 0

| z | ReLU(z) | ReLU'(z) |
|---|---|---|
| -2 | **0** | **0** |
| 0 | **0** | 0 (관례) |
| 3 | **3** | **1** |

**tanh** `tanh(z)`, `tanh'(z) = 1 - tanh²(z)`

| z | tanh(z) | tanh'(z) |
|---|---|---|
| -2 | **-0.9640** | 1 - 0.9293 = **0.0707** |
| 0 | **0.0000** | 1 - 0 = **1.0000** |
| 3 | **0.9951** | 1 - 0.9902 = **0.0098** |

**검산 코드**

```python
import numpy as np

for z in [-2, 0, 3]:
    s = 1 / (1 + np.exp(-z))
    t = np.tanh(z)
    r = max(0, z)
    print(f"z = {z:>3}")
    print(f"  Sigmoid : {s:.4f}   미분 {s * (1 - s):.4f}")
    print(f"  tanh    : {t:>7.4f}   미분 {1 - t ** 2:.4f}")
    print(f"  ReLU    : {r:.4f}   미분 {1.0 if z > 0 else 0.0:.4f}")
    print()
```

- **tanh 미분은 z=0에서 1.0으로 최대**입니다. Sigmoid(0.25)의 4배입니다.
  그런데 z=3에서는 0.0098로 Sigmoid보다도 작습니다. **양 끝에서는 tanh가 더 빨리 죽습니다.**
- **ReLU는 z>0에서 언제나 정확히 1**입니다. 값이 아무리 커도 신호가 그대로입니다.
</details>

**3.** 활성화 함수 비교 실험을 수행하고 표로 정리하세요.
① 6개 함수(step, sigmoid, tanh, relu, leaky_relu, elu)를 직접 구현하고 그래프 그리기
② 각 함수의 미분을 수치미분으로 구해 그래프에 겹쳐 그리기
③ 깊이 1/3/6/10층 신경망에서 활성화 함수별 성능 비교
④ 기울기 소실이 실제로 일어나는지 층별 가중치 변화량으로 확인
⑤ 비교표 작성 — 각 함수의 출력범위·미분범위·장점·단점·쓰는 곳

<summary>답 보기</summary>

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


# ── ① 함수 구현 ──
def step(z):
    return np.where(z > 0, 1.0, 0.0)


def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))


def tanh(z):
    return np.tanh(z)


def relu(z):
    return np.maximum(0, z)


def leaky_relu(z, a=0.01):
    return np.where(z > 0, z, a * z)


def elu(z, a=1.0):
    return np.where(z > 0, z, a * (np.exp(np.minimum(z, 0)) - 1))


FUNCS = {
    "step": step, "sigmoid": sigmoid, "tanh": tanh,
    "relu": relu, "leaky_relu": leaky_relu, "elu": elu,
}


# ── ② 수치미분 ──
def numeric_grad(f, z, h=1e-5):
    return (f(z + h) - f(z - h)) / (2 * h)


z = np.linspace(-5, 5, 1000)

fig, axes = plt.subplots(2, 3, figsize=(16, 8))
for ax, (name, f) in zip(axes.ravel(), FUNCS.items()):
    ax.plot(z, f(z), linewidth=2.5, label=name)
    ax.plot(z, numeric_grad(f, z), "--", linewidth=1.6, alpha=0.8,
            label=f"{name}' (numeric)")
    ax.axhline(0, color="black", linewidth=0.6)
    ax.axvline(0, color="black", linewidth=0.6)
    ax.set_ylim(-1.6, 3.0)
    ax.set_title(name)
    ax.legend(fontsize=8.5)
    ax.grid(alpha=0.3)
fig.suptitle("Activation functions and numeric derivatives", fontsize=14)
fig.tight_layout()
plt.show()

# ── ⑤ 비교표 (수치 기반) ──
spec_rows = []
for name, f in FUNCS.items():
    out = f(z)
    grad = numeric_grad(f, z)
    spec_rows.append({
        "함수": name,
        "출력_최소": round(float(out.min()), 3),
        "출력_최대": round(float(out.max()), 3),
        "미분_최대": round(float(grad.max()), 4),
        "미분_0인_비율": f"{(np.abs(grad) < 1e-6).mean():.1%}",
        "제로중심": "예" if abs(float(out.mean())) < 0.1 else "아니오",
    })

spec = pd.DataFrame(spec_rows)
print("=" * 84)
print("⑤ 활성화 함수 특성 비교 (z ∈ [-5, 5] 기준)")
print("=" * 84)
print(spec.to_string(index=False))
print("=" * 84)

# ── ③ 깊이별 성능 ──

X_train, X_test, y_train, y_test = train_test_split(
    digits.data, digits.target, test_size=0.3, random_state=42, stratify=digits.target
)

perf_rows = []
for act in ["identity", "logistic", "tanh", "relu"]:
    for n_layers in [1, 3, 6, 10]:
        hidden = (64,) * n_layers
        pipe = make_pipeline(
            StandardScaler(),
            MLPClassifier(hidden_layer_sizes=hidden, activation=act,
                          max_iter=400, random_state=42, learning_rate_init=0.01),
        )
        pipe.fit(X_train, y_train)
        mlp = pipe.named_steps["mlpclassifier"]

        # ④ 층별 가중치 크기 — 학습이 됐는지의 간접 지표
        w_norms = [round(float(np.abs(w).mean()), 5) for w in mlp.coefs_]

        perf_rows.append({
            "활성화": act, "층수": n_layers,
            "train": round(pipe.score(X_train, y_train), 4),
            "test": round(pipe.score(X_test, y_test), 4),
            "손실": round(mlp.loss_, 4),
            "반복": mlp.n_iter_,
            "첫층_|w|": w_norms[0],
            "끝층_|w|": w_norms[-1],
        })

perf = pd.DataFrame(perf_rows)
print("\n" + "=" * 90)
print("③ 활성화 함수 × 깊이 — digits 분류")
print("=" * 90)
print(perf.to_string(index=False))
print("=" * 90)

print("\n④ 기울기 소실의 흔적 — 첫 층과 끝 층의 가중치 크기 비")
print(f"{'활성화':<12}{'층수':>6}{'첫층/끝층':>14}{'해석':>24}")
print("-" * 60)
for _, r in perf[perf["층수"].isin([1, 10])].iterrows():
    ratio = r["첫층_|w|"] / r["끝층_|w|"] if r["끝층_|w|"] else float("inf")
    note = ""
    if r["층수"] == 10 and ratio < 0.5:
        note = "첫 층이 거의 안 움직임"
    print(f"{r['활성화']:<12}{int(r['층수']):>6}{ratio:>14.3f}{note:>24}")

# ── 그래프 ──

    ax.plot(sub["층수"], sub["test"], "o-", label=act, linewidth=2, markersize=8)
ax.set_xlabel("hidden layers")

ax.set_xticks([1, 3, 6, 10])
ax.legend()
ax.grid(alpha=0.3)

ax = axes[1]

ax.set_xlabel("hidden layers")
ax.set_ylabel("mean |weight| of first layer")
ax.set_title("④ First-layer weights (learning signal)")
ax.set_xticks([1, 3, 6, 10])

ax.grid(alpha=0.3)
```

|---|---|---|---|---|---|---|
| **step** | {0, 1} | 0 | ✗ | 개념이 명확 | **미분 불가 → 학습 불가** | 이론 설명용 |
| **sigmoid** | (0, 1) | 0.25 | ✗ | **확률 해석** | 기울기 소실, 느림 | **이진 분류 출력층** |
| **tanh** | (-1, 1) | 1.0 | ✓ | Sigmoid보다 나음 | 여전히 양 끝에서 소실 | RNN, 얕은 망 |
| **ReLU** | [0, ∞) | 1.0 | ✗ | **빠름, 소실 없음** | Dying ReLU | **은닉층 기본값** |
| **LeakyReLU** | (-∞, ∞) | 1.0 | ✗ | 죽지 않음 | 하이퍼파라미터 α | ReLU가 죽을 때 |
| **ELU** | (-α, ∞) | 1.0 | ✓ | 부드럽고 제로중심 | 지수 계산으로 느림 | 정확도가 중요할 때 |
| **Softmax** | (0,1), 합=1 | — | — | **다중 분류 확률** | 출력층 전용 | **다중 분류 출력층** |

> **실무 기본값**
> ```
> 은닉층 = ReLU
> 출력층 = 문제에 따라 (없음 / sigmoid / softmax)
> ```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 활성화 함수의 존재 이유 | 없으면 **몇 층을 쌓아도 직선 하나** |
| 계단 함수 | 미분이 거의 0 → **학습 불가** |
| Sigmoid | `1/(1+e^-z)`, 0~1, **미분 최대 0.25** |
| Sigmoid 미분 | `σ(z)(1-σ(z))` — 자기 자신으로 표현 |
| **기울기 소실** | 깊어지면 `0.25^n` → 앞쪽 층이 학습 안 됨 |
| tanh | -1~1, **제로 중심**, 미분 최대 1.0 |
| **ReLU** | `max(0,z)`, **z>0에서 미분 정확히 1**, 빠름 |
| Dying ReLU | z<0이면 영원히 0 → LeakyReLU/ELU로 완화 |
| Softmax | `e^zᵢ / Σe^zⱼ`, **합=1**, 다중 분류 |
| Softmax 구현 | **최댓값을 빼서** 오버플로 방지 |
| 은닉층 | **ReLU** (고민하지 말 것) |
| 출력층 | 회귀=없음, 이진=sigmoid, 다중=softmax |
| 손실 함수 짝 | mse / binary_ce / categorical_ce |

**오늘 반드시 기억할 세 가지**
> ① **활성화 함수가 없으면 딥러닝이 아닙니다.** 직선 하나짜리 모델입니다.
> ② **은닉층은 ReLU, 출력층은 문제에 따라.** 출력층에 ReLU를 쓰면 확률이 안 나옵니다.
> ③ **Sigmoid는 깊은 은닉층에 쓰지 마세요.** 10층에서 학습이 아예 안 되는 것을 확인했습니다.

**과제** — 활성화 함수 비교표를 작성하세요.

**필수 포함 항목**

| 항목 | 내용 |
|---|---|
| 1 | **6개 이상**의 활성화 함수를 직접 구현 (라이브러리 사용 금지) |
| 2 | 함수와 그 **미분**을 한 그래프에 겹쳐 그리기 (2×3 서브플롯) |
| 3 | 각 함수의 출력 범위·미분 최댓값·제로중심 여부를 **수치로 측정**한 표 |
| 4 | 깊이 1/3/6/10층에서의 성능 비교 실험 |
| 5 | **기울기 소실 증거** — 층별 가중치 변화량 또는 활성화 분포 |
| 6 | 문제 유형별 출력층 선택표 (회귀 / 이진 / 다중 / 다중 라벨) |
| 7 | **결론** — 언제 무엇을 쓸 것인가, 본인의 판단 기준 |

**추가 조건**
- 수치미분(`(f(z+h) - f(z-h)) / 2h`)으로 미분을 구하고, **Sigmoid는 공식과 대조 검증**하세요.
- Softmax는 **오버플로 안전 버전**으로 구현하고, `[1000, 999, 998]` 입력으로 검증하세요.
