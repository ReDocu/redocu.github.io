## ② 왜 필요한가

### 어제 얻은 두 개의 숫자

```
val 0.7053      ← 올려야 합니다
counter 0.5410  ← ★ 이것도 올려야 합니다
```

**보통의 수업이라면 오늘은 "정확도 올리기"만 합니다.**
이 프로젝트는 다릅니다.

| 목표 | 어제 | 오늘 목표 | 난이도 |
|---|---|---|---|
| val 정확도 | 0.7053 | ≥ 0.88 | 쉬움 — 전이학습 하나로 대부분 해결 |
| **counter 정확도** | **0.5410** | **≥ 0.78** | **어려움 — 오늘의 진짜 과제** |
| 격차 | 0.1643 | ≤ 0.10 | |

> **val만 올리는 것은 오후 2시면 끝납니다.**
> 남은 시간을 전부 두 번째 목표에 씁니다.

### 실험이 무너지는 가장 흔한 방식

```
❌ 흔한 수요일
   "증강도 넣고 전이학습도 하고 lr도 낮췄더니 0.91 나왔어요!"
   → 무엇 덕분인지 모름
   → 목요일 "증강을 빼면 어떻게 되나요?" → 답 못 함
   → 다시 실험할 시간 없음
```

```
✅ 좋은 수요일
   실험 3: 베이스라인 + 증강만        → 0.76  (+0.05)
   실험 4: 베이스라인 + Dropout만     → 0.74  (+0.03)
   실험 5: 전이학습(특징 추출)만      → 0.89  (+0.19) ★
   실험 6: 실험 5 + 미세조정          → 0.92  (+0.03)
   → "전이학습이 결정적이었다"를 숫자로 말할 수 있음
```

> **오늘 만드는 것은 모델이 아니라 "표"입니다.**
> 표의 각 행이 발표 슬라이드 한 장이 됩니다.

### 검증셋도 닳습니다

```
실험 1회  → val로 비교
실험 5회  → val로 비교
실험 30회 → val에서 가장 높은 것을 고름
          = val에 대한 과적합
```

**검증셋 45×2=90장에서 1장은 1.1%p입니다.**
30번 고르면 우연히 val이 높은 모델이 뽑힙니다.

| 실험 횟수 | 위험 |
|---|---|
| ~10회 | 안전 |
| 10~20회 | 주의 — 상위 모델들의 차이가 0.02 이내면 사실상 동점 |
| 20회 초과 | **val 과적합.** 테스트에서 떨어질 가능성 큼 |

> **오늘의 실험 상한은 12회로 정합니다.**
> 그 이상은 "더 좋아 보이는 것"을 고르는 것이지 "더 좋은 것"을 찾는 게 아닙니다.

### ★ 왜 CutOut이 배경 편향에 듣는가

```
CutOut = 이미지의 랜덤한 사각형 영역을 지운다

지워진 곳이 동물일 때  → 배경만 보고 맞혀야 함 → 어려움
지워진 곳이 배경일 때  → 동물을 봐야 함
```

```
결과: "어느 한 부분에만 의존하면 자주 틀린다"
     → 모델이 여러 곳을 보게 됨
     → 배경 하나에 의존하는 전략이 손해가 됨
```

> **증강은 "데이터를 늘리는 것"만이 아닙니다.**
> **어떤 단서를 못 쓰게 만드는 것**이기도 합니다.
> 좌우반전은 방향 단서를, CutOut은 위치 단서를, 색 변환은 색 단서를 무력화합니다.

### 같은 조건이란

| 항목 | 왜 |
|---|---|
| 같은 데이터 분할 | 당연 |
| 같은 seed | 초기 가중치·셔플 순서 |
| **같은 평가 시점** | 마지막 에폭 vs 최적 에폭을 섞으면 안 됨 |
| **같은 에폭 상한** | 한쪽만 200에폭 돌리면 불공정 |
| 같은 지표 | val_accuracy 기준 |

### seed 한 개의 함정

```
seed 42 → 0.891
seed 1  → 0.868
seed 7  → 0.902

같은 설정인데 0.034 차이
```

**0.02 차이는 seed 차이일 수 있습니다.**

| 두 실험의 차이 | 판정 |
|---|---|
| < 0.02 | **사실상 동점** — 단순한 쪽을 선택 |
| 0.02 ~ 0.05 | 유의미할 수 있음 — seed 3개로 재확인 |
| > 0.05 | 명확한 차이 |

> **최종 후보만 seed 3개로 재현합니다.** (실험 12)
> 모든 실험을 3번씩 하면 시간이 3배가 됩니다.

## 4부 · 무엇을 최종 모델로 고를 것인가

### 두 축으로 봅니다

```
        counter 정확도 (견고성)
             ↑
    0.85 │  ④          ③ ★ 목표
         │
    0.65 │  ①          ②
         └──────────────────→  val 정확도 (성능)
            0.75        0.92
```

| 사분면 | 상태 | 판단 |
|---|---|---|
| ① 낮음·낮음 | 학습이 덜 됨 | 개선 필요 |
| ② 성능만 높음 | **배경을 학습** | **위험. 발표에서 지적당함** |
| ③ 둘 다 높음 | 목표 | ★ 선택 |
| ④ 견고하지만 성능 낮음 | 과도한 증강? | 균형 조정 |

### 선정 규칙 — 미리 정해 둡니다

```
① counter ≥ 0.75 인 모델들 중에서
② val이 가장 높은 것을 선택
③ 동점(차이 0.02 이내)이면 더 단순한 모델
```

**왜 미리 정하는가** — 결과를 보고 규칙을 만들면 원하는 답이 나오게 고르게 됩니다.

> ⚠️ **주의: counter는 모델 선택에 쓰면 안 된다고 하지 않았나요?**
>
> 엄밀히는 맞습니다. 그래서 이렇게 합니다.
>
> ```
> counter를 '통과/불통과' 기준으로만 사용 (≥0.75)
> 순위 매기기는 val로만
> ```
>
> **counter의 소수점을 보고 1위를 고르면** counter도 검증셋이 됩니다.
> **문턱으로만 쓰고, 최종 수치는 [Day 104](day-104.md)에 처음 보는 것으로 취급**합니다.

## ④ 단계별 실습

### Step 1. 실험 러너 — 모든 실험을 같은 방식으로

```python
"""
Day 103 Step 1 — 실험 러너
project_wolf/runner.py

모든 실험을 이 함수 하나로 실행합니다.
→ 조건이 자동으로 통일되고, 기록이 자동으로 남습니다.
"""
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import EarlyStopping, ModelCheckpoint

from experiment_log import log_experiment           # Day 102 Step 6

AUTOTUNE = tf.data.AUTOTUNE
PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
SPLIT, COUNTER = PROJ / "data" / "split", PROJ / "data" / "counter"
MODEL_DIR = PROJ / "models"
IMG_SIZE, BATCH, SEED = (224, 224), 32, 42

# ══════════════════════════════════════════
# 데이터 — 한 번만 로드해서 계속 재사용
# ══════════════════════════════════════════
def load_all(seed=SEED):
    tr = keras.utils.image_dataset_from_directory(
        SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
        label_mode="binary", shuffle=True, seed=seed)
    va = keras.utils.image_dataset_from_directory(
        SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH,
        label_mode="binary", shuffle=False)
    co = keras.utils.image_dataset_from_directory(
        COUNTER, image_size=IMG_SIZE, batch_size=BATCH,
        label_mode="binary", shuffle=False)
    names = tr.class_names
    return (tr.cache().prefetch(AUTOTUNE), va.cache().prefetch(AUTOTUNE),
            co.cache().prefetch(AUTOTUNE), names)


TRAIN_DS, VAL_DS, COUNTER_DS, CLASS_NAMES = load_all()
print(f"클래스: {CLASS_NAMES}   (0={CLASS_NAMES[0]}, 1={CLASS_NAMES[1]})")


# ══════════════════════════════════════════
# 증강 블록 — 강도별
# ══════════════════════════════════════════
class RandomCutout(layers.Layer):
    """이미지의 랜덤 사각 영역을 지웁니다 (배경 의존 완화)"""

    def __init__(self, size=64, **kw):
        super().__init__(**kw)
        self.size = size

    def call(self, x, training=None):
        if not training:
            return x
        shape = tf.shape(x)
        b, h, w = shape[0], shape[1], shape[2]
        cy = tf.random.uniform([b], 0, h, dtype=tf.int32)
        cx = tf.random.uniform([b], 0, w, dtype=tf.int32)
        yy = tf.range(h)[None, :, None]
        xx = tf.range(w)[None, None, :]
        half = self.size // 2
        mask_y = tf.abs(yy - cy[:, None, None]) > half
        mask_x = tf.abs(xx - cx[:, None, None]) > half
        mask = tf.cast(tf.logical_or(mask_y, mask_x), x.dtype)[..., None]
        return x * mask


def augment_block(level="none"):
    """증강 강도를 이름으로 지정합니다"""
    if level == "none":
        return []
    if level == "light":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.08),
                layers.RandomZoom(0.10)]
    if level == "strong":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.15),
                layers.RandomZoom(0.20),
                layers.RandomTranslation(0.10, 0.10),
                layers.RandomContrast(0.20)]
    if level == "cutout":
        return augment_block("strong") + [RandomCutout(size=64)]
    if level == "cutout_color":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.15),
                layers.RandomZoom(0.20),
                layers.RandomTranslation(0.10, 0.10),
                layers.RandomContrast(0.35),
                layers.RandomBrightness(0.25, value_range=(0, 255)),
                RandomCutout(size=72)]
    raise ValueError(level)


# ══════════════════════════════════════════
# 모델 빌더
# ══════════════════════════════════════════
BACKBONES = {
    "MobileNetV2": (keras.applications.MobileNetV2,
                    keras.applications.mobilenet_v2.preprocess_input),
    "EfficientNetB0": (keras.applications.EfficientNetB0,
                       keras.applications.efficientnet.preprocess_input),
}


def build_scratch(aug="none", dropout=0.0):
    """밑바닥 CNN (Day 102 베이스라인과 동일 구조)"""
    return keras.Sequential([
        keras.Input(shape=(*IMG_SIZE, 3)),
        *augment_block(aug),
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Conv2D(64, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Conv2D(128, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Flatten(),
        layers.Dense(128, activation="relu"),
        *([layers.Dropout(dropout)] if dropout else []),
        layers.Dense(1, activation="sigmoid"),
    ], name="scratch")


def build_transfer(backbone="MobileNetV2", aug="light", dropout=0.3):
    """전이학습 모델 (백본 동결) — Day 098·099"""
    fn, preprocess = BACKBONES[backbone]
    base = fn(weights="imagenet", include_top=False,
              input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*IMG_SIZE, 3))
    x = inputs
    for layer in augment_block(aug):
        x = layer(x)
    x = preprocess(x)
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)
    outputs = layers.Dense(1, activation="sigmoid")(x)
    return keras.Model(inputs, outputs, name=f"transfer_{backbone}"), base


# ══════════════════════════════════════════
# 실험 실행기 — ★ 모든 실험이 이걸 거칩니다
# ══════════════════════════════════════════
def run(name, changed, builder, config,
        lr=1e-3, epochs=40, finetune=None, seed=SEED,
        observation="", next_try="", save=False, verbose=True):
    """
    builder  : () -> model  또는  () -> (model, base)
    finetune : dict(lr=1e-5, epochs=40, n_unfreeze=20) 또는 None
    """
    keras.backend.clear_session()
    keras.utils.set_random_seed(seed)              # ★ 조건 통일

    built = builder()
    model, base = built if isinstance(built, tuple) else (built, None)

    if verbose:
        print("=" * 74)
        print(f"[{name}]  {changed}")
        print("=" * 74)
        print(f"  설정: {config}")
        print(f"  파라미터: {model.count_params():,}")

    cbs = [EarlyStopping(monitor="val_loss", patience=10,
                         restore_best_weights=True, verbose=0)]
    if save:
        cbs.append(ModelCheckpoint(str(MODEL_DIR / f"{name}.keras"),
                                   monitor="val_loss", save_best_only=True))

    t0 = time.time()
    model.compile(optimizer=keras.optimizers.Adam(lr),
                  loss="binary_crossentropy", metrics=["accuracy"])
    h = model.fit(TRAIN_DS, epochs=epochs, validation_data=VAL_DS,
                  callbacks=cbs, verbose=0).history
    n_ep = len(h["loss"])

    # ── 2단계 미세조정 ──
    if finetune and base is not None:
        base.trainable = True
        for layer in base.layers[:-finetune["n_unfreeze"]]:
            layer.trainable = False
        for layer in base.layers:
            if isinstance(layer, keras.layers.BatchNormalization):
                layer.trainable = False              # ★ BN 동결 (Day 099)
        model.compile(optimizer=keras.optimizers.Adam(finetune["lr"]),
                      loss="binary_crossentropy", metrics=["accuracy"])
        h2 = model.fit(TRAIN_DS, epochs=finetune["epochs"],
                       initial_epoch=n_ep, validation_data=VAL_DS,
                       callbacks=cbs, verbose=0).history
        for k in h:
            h[k] += h2[k]
        n_ep = len(h["loss"])

    sec = time.time() - t0
    best = int(np.argmin(h["val_loss"]))
    _, counter_acc = model.evaluate(COUNTER_DS, verbose=0)
    metrics = {"train_acc": h["accuracy"][best],
               "val_acc": h["val_accuracy"][best],
               "counter_acc": counter_acc, "epochs": n_ep, "sec": sec}

    if verbose:
        print(f"\n  train {metrics['train_acc']:.4f} | "
              f"val {metrics['val_acc']:.4f} | "
              f"counter {metrics['counter_acc']:.4f}")
        print(f"  격차 {metrics['train_acc'] - metrics['val_acc']:+.4f} | "
              f"하락 {metrics['val_acc'] - counter_acc:+.4f} | "
              f"{n_ep}에폭 {sec:.0f}초")

    log_experiment(name, changed, config, metrics,
                   observation=observation, next_try=next_try)
    return model, h, metrics
```

## ⑤ 자주 하는 실수

### 여러 개를 한꺼번에 바꾼다

```python
# ❌
model = build_transfer(backbone="EfficientNetB0", aug="strong", dropout=0.5)
run(..., lr=3e-4, epochs=100)     # 백본·증강·dropout·lr·epochs 전부 변경
```

**결과** — 0.91이 나와도 무엇 덕분인지 말할 수 없습니다.
**해결** — `run()` 호출 사이에 **한 인자만** 바꿉니다.

### `clear_session()` / `set_random_seed()` 를 빼먹는다

```
ResourceExhaustedError: OOM when allocating tensor
```

또는 같은 코드인데 실행할 때마다 결과가 다릅니다.
**해결** — `run()` 안에 넣어 두고 항상 그 함수로만 실행합니다.

### 증강을 검증·테스트에도 적용한다

```python
# ❌
val_ds = val_ds.map(lambda x, y: (augment(x), y))
```

**증상** — val 정확도가 이상하게 낮고 실행마다 다릅니다.
**해결** — 증강을 **모델 안의 레이어**로 넣으면 `training=False` 에서 자동으로 꺼집니다.

### CutOut을 추론에도 적용한다

```python
# ❌ training 인자 무시
def call(self, x):
    return x * mask
```

**증상** — 예측할 때마다 결과가 달라집니다.
**해결** — `def call(self, x, training=None)` 로 받고 `if not training: return x`.

### counter로 모델을 고른다

```python
# ❌
best = max(models, key=lambda m: counter_acc(m))
```

**해결** — 통과/불통과 문턱으로만 씁니다. 순위는 val로.

### 미세조정 학습률을 안 낮춘다

**증상** — 미세조정 후 성능이 **떨어집니다.** 사전학습 가중치가 망가집니다.
**해결** — 1/100 (1e-3 → 1e-5). ([Day 099](day-099.md))

### BatchNorm을 함께 학습시킨다

```python
base.trainable = True     # BN도 같이 풀림
```

**증상** — 소량 데이터에서 통계가 흔들려 val이 요동칩니다.
**해결** — BN 레이어만 `trainable = False` 로 되돌립니다. (`run()` 에 포함됨)

### 실패 실험을 지운다

```
"lr 1e-2는 실패했으니까 기록에서 뺄게요"
```

**해결** — 남깁니다. **탐색 범위를 보여 주는 증거**입니다.

## ⑥ 확인 문제

### 문제 1

실험 5→6에서 **val은 올랐는데 counter는 거의 안 올랐고 하락폭은 커졌습니다.**

```
exp5  val 0.8842  counter 0.6721  하락 0.2121
exp6  val 0.9158  counter 0.6885  하락 0.2273
```

**왜 이런 일이 생기는지** 설명하세요.

<details>
<summary>답 보기</summary>

**미세조정이 "이 데이터셋에 더 맞추는" 과정이기 때문입니다.**

```
exp5 (특징 추출)
  백본 = ImageNet에서 배운 일반적 특징 (동물 형태, 질감)
  분류기만 우리 데이터에 맞춤
  → 상대적으로 일반적

exp6 (미세조정)
  백본 상위 20층도 우리 데이터에 맞춤
  우리 데이터에는 "눈 ↔ 늑대" 상관이 (완전히는 아니어도) 남아 있음
  → ★ 백본이 그 상관까지 학습
  → val ↑ (같은 편향을 가진 데이터라서)
  → counter ↑는 거의 없음
```

**핵심 문장**

> **미세조정은 성능을 올리는 동시에 데이터셋의 편향도 함께 학습합니다.**

**일반적 원리로 확장하면**

| 모델이 강해질수록 | |
|---|---|
| 진짜 특징을 배울 능력 | ↑ |
| **지름길을 찾을 능력** | **↑↑** |

지름길이 더 쉬우므로, **능력이 커지면 지름길을 더 잘 씁니다.**

**대응**

```
① 데이터에서 상관을 없앤다        (Day 102 층화 — 이미 함)
② 지름길을 못 쓰게 만든다         (CutOut, 색 증강 — exp8·9)
③ 미세조정 층 수를 줄인다         (n_unfreeze 20 → 10)
④ 미세조정을 생략한다             (exp5 수준에서 멈춤)
```

**실제로 exp8에서 ②를 적용하자 하락폭이 0.227 → 0.102로 줄었습니다.**
</details>

### 문제 2

두 팀이 최종 모델을 골랐습니다. **각각의 판단을 평가**하고, 여러분이라면 무엇을 선택할지 근거와 함께 쓰세요.

```
[사용 가능한 모델]
  #6  val 0.9158  counter 0.6885  MobileNetV2  743초
  #8  val 0.9053  counter 0.8033  MobileNetV2  1004초
  #9  val 0.8947  counter 0.8361  MobileNetV2  1082초

A팀: "정확도가 가장 높은 #6을 고르겠습니다"
B팀: "counter가 가장 높은 #9를 고르겠습니다"
```

<details>
<summary>답 보기</summary>

**A팀 — 부적절합니다.**

```
성공 기준 B (Day 101): counter ≥ 0.75, 격차 ≤ 0.10
#6: counter 0.6885, 격차 0.2273  → 두 조건 모두 미달
```

**"기준을 세워 놓고 결과가 나오자 무시한 것"** 이 문제입니다.
val 0.9158은 **같은 편향을 가진 검증셋에서의 숫자**라 실제 성능이 아닙니다.

**B팀 — 결론은 타당하지만 근거가 부족합니다.**

```
"counter가 가장 높아서" = counter로 순위를 매긴 것
→ counter가 검증셋이 되어 버립니다
→ Day 104의 counter 평가가 낙관적으로 편향됩니다
```

**올바른 서술**

> "counter ≥ 0.75를 통과한 #8·#9 중에서 val 기준으로 골랐습니다.
> 두 모델의 val 차이 0.0106은 seed 표준편차(0.0086) 수준이라 동점으로 보고,
> 구조가 같고 견고성 여유가 큰 #9를 선택했습니다."

**정답 예시 — #9 선택**

| 근거 | 내용 |
|---|---|
| 기준 통과 | A(val≥0.85) ✔ B(counter≥0.75, 격차≤0.10) ✔ |
| val 손실 | #6 대비 −0.021 — seed 흔들림의 2.5배 수준으로 작음 |
| counter 이득 | #6 대비 +0.148 — 표준편차의 7배로 명확 |
| 격차 | 0.0586 — 목표 0.10 대비 여유 |
| 비용 | 1082초, 학습 시간 수용 가능 |

**#8을 골라도 정답입니다.** 단 근거가 이래야 합니다.

> "#9는 증강이 강해 학습 데이터 분포에서의 성능이 약간 희생됐다.
> counter 0.80으로도 기준을 통과하므로, 실사용 분포가 학습과 유사하다면 #8이 낫다."

> **채점 포인트는 "무엇을 골랐는가"가 아니라 "왜 골랐는가"입니다.**
</details>

### 문제 3

여러분의 데이터로 **최소 6회 이상의 실험**을 수행하고 기록표를 완성하세요.

| 요구 | 내용 |
|---|---|
| 1 | 실험 6회 이상, 각 행에 **observation·next_try** 포함 |
| 2 | **한 번에 하나만** 바꿨음을 config 열로 확인 가능 |
| 3 | **편향 완화 실험 최소 2회** (CutOut·색 증강 등) |
| 4 | **실패 실험 1회 이상** 포함 |
| 5 | seed 3개 재현으로 **흔들림 폭** 측정 |
| 6 | 사분면 그래프 + 최종 후보 선정 근거 |

<details>
<summary>답 보기</summary>

**Step 1~6의 코드가 답입니다. 여기서는 기록표 작성 요령을 제시합니다.**

**① observation — 좋은 예 / 나쁜 예**

```
❌ "0.89 나옴"
❌ "전이학습 좋음"
✅ "val 0.8842로 baseline 대비 +0.179. 파라미터는 1/6.
    그러나 counter 0.6721로 하락폭이 오히려 커짐(0.16→0.21)"
```

**형식** — `[지표 변화] + [비교 대상 대비] + [예상과 다른 점]`

**② next_try — 좋은 예 / 나쁜 예**

```
❌ "더 개선"
❌ "하이퍼파라미터 튜닝"
✅ "미세조정으로 백본 상위층 해제 (실험 6)"
✅ "counter가 안 오르므로 CutOut으로 배경 의존 차단 시도 (실험 8)"
```

**③ 실험 순서 — 우리 결과가 보여 준 것**

| 기법 | val 기여 | counter 기여 |
|---|---|---|
| 증강(light) | +0.063 | +0.033 |
| Dropout | +0.032 | +0.016 |
| **전이학습** | **+0.179** | +0.131 |
| 미세조정 | +0.032 | +0.016 |
| 강한 증강 | −0.011 | +0.033 |
| **CutOut** | +0.000 | **+0.082** |
| **색 증강** | −0.011 | **+0.033** |

> **두 열의 1등이 다릅니다.**
> val은 전이학습이, counter는 CutOut이 가장 크게 기여했습니다.
> **목표가 두 개면 기법도 두 갈래로 준비해야 합니다.**

**④ 실패 실험 서술 예시**

```
| 11 | lr 1e-2 | val 0.5053 | 손실이 2에폭 만에 발산. 학습 자체가 안 됨.
                              Adam 기본값 1e-3이 이 문제의 상한 |
```

**⑤ 흔들림 측정 후 판정 기준을 표에 명시**

```
seed 3개 val 표준편차 = 0.0086
→ 실험 간 val 차이가 0.017(2σ) 이내면 동점 처리
→ 이 기준을 보고서 '방법' 절에 명시
```

**⑥ 최종 선정 근거 — 반드시 포함할 4가지**

```
1. 선정 규칙을 언제 정했는가        ("Day 101에 사전 확정")
2. 탈락한 모델과 탈락 사유          ("#6은 counter 0.69로 기준 B 미달")
3. 동점 처리 방식                   ("seed σ 기준 0.017 이내는 동점")
4. 선택하지 않은 대안과 이유        ("#10은 성능 동일, 시간 1.5배")
```

> **흔한 감점** — 결과가 좋은 모델을 먼저 고르고 규칙을 나중에 쓴 것이 보이는 보고서.
> `models/final_choice.json` 의 `frozen_at` 필드가 그 증거가 됩니다.
</details>
