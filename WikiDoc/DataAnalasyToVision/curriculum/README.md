## 8. 운영 원칙

1. **매일 마지막 차시는 그날 코드 정리 및 GitHub 푸시**에 사용합니다. 수료 시 GitHub 잔디가 곧 포트폴리오입니다.
2. **금요일 5~8차시는 주간 종합 실습**입니다. 새 개념을 넣지 않고 그 주 내용만으로 하나를 완성시킵니다.
3. **프로젝트 주차의 마지막 날은 발표와 회고**입니다. 코드를 더 붙이지 않고 정리·문서화합니다.

5. 대단원 03부터는 **실험 기록표**(하이퍼파라미터 / 지표 / 관찰)를 의무 작성합니다. 이 습관이 04·05 프로젝트의 품질을 결정합니다.
