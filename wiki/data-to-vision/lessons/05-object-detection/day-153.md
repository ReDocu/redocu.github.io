| | RTX 3060 | i7 CPU | 라즈베리파이 4 |
|---|---|---|---|
| 연산 성능 | 12.7 TFLOPS | ~0.5 TFLOPS | **~0.02 TFLOPS** |
| 코어 | 3,584 CUDA | 8코어 | 4코어 ARM Cortex-A72 |
| 메모리 대역폭 | 360 GB/s | 50 GB/s | **~5 GB/s** |
| SIMD | Tensor Core | AVX2 | NEON |
| 우리 모델 추론 | 8.4 ms | 141 ms | **~520 ms** |

**★ 그런데 PyTorch 자체가 ARM에 최적화되어 있지 않습니다.**

```
PyTorch     범용 프레임워크. 학습·추론 모두 지원
            → 유연하지만 무겁고, ARM 최적화가 약함

NCNN        Tencent 제작. ★ 모바일/임베디드 전용 추론 엔진
            → ARM NEON 명령어 직접 활용
            → 같은 하드웨어에서 2~3배 빠름
```

### 정확도를 얼마나 잃는가

```
FP32 → FP16    mAP50 -0.002 ~ -0.005    ★ 사실상 손실 없음
FP32 → INT8    mAP50 -0.01  ~ -0.04     ★ 눈에 띄는 손실
PyTorch → ONNX 손실 없음 (같은 정밀도)
PyTorch → NCNN 손실 거의 없음 (FP16 사용 시 소폭)
```

**★ 대부분의 경우 "공짜로" 2~3배 빨라집니다.**

    simplify=True,      # ★ ONNX 그래프 단순화

### 양자화 — FP32 → FP16 → INT8

```
FP32   32비트 부동소수점   기본. 정확
FP16   16비트 부동소수점   ★ 메모리 절반, GPU에서 2배 빠름
INT8    8비트 정수         ★ 메모리 1/4, 하지만 정확도 손실
```

**FP16**

```
장점
  · 모델 크기 절반 (5.5MB → 2.8MB)
  · GPU Tensor Core 활용 → 2배
  · ★ 정확도 손실 거의 없음 (-0.002~-0.005)

단점
  · ★ CPU 에서는 오히려 느릴 수 있음 (변환 오버헤드)
  · 오래된 GPU 는 지원 안 함
```

**INT8**

```
원리: 실수 범위를 256단계 정수로 매핑

  실제 값  -2.34 ~ 3.71
  → 스케일 계산 → 0~255 정수로 표현
  → 연산 후 다시 실수로

장점
  · 모델 크기 1/4
  · ARM/모바일에서 2~4배
  · 메모리 대역폭 절약 (★ 라즈베리파이에서 중요)

단점
  · ★ 정확도 손실 -0.01~-0.04
  · ★ 캘리브레이션 데이터 필요 (대표 이미지 100~500장)
  · 형식별 지원이 제각각
```

**★ 캘리브레이션이란**

```
INT8 로 바꾸려면 "실수 값의 범위"를 알아야 합니다

  대표 이미지 100~500장을 모델에 통과시켜
  각 층의 활성값 분포를 측정
  → 그 범위를 256단계로 나눔

★ 캘리브레이션 데이터가 실제 운영 데이터와 다르면
  → 정확도가 크게 떨어집니다
  → ★ 우리 val 셋을 쓰는 것이 맞습니다
```

### ★ FPS 측정 — 올바른 방법

```python
def measure_fps(fn, warmup=10, runs=50):
    """올바른 속도 측정"""
    import time
    import numpy as np

    # ① 워밍업
    for _ in range(warmup):
        fn()

    # ② 여러 번 측정
    times = []
    for _ in range(runs):
        t0 = time.perf_counter()          # ★ time.time() 아님
        fn()
        times.append(time.perf_counter() - t0)

    times = np.array(times) * 1000        # ms
    return {
        "mean_ms": times.mean(),
        "median_ms": np.median(times),    # ★ 이상치에 강함
        "std_ms": times.std(),
        "min_ms": times.min(),
        "p95_ms": np.percentile(times, 95),   # ★ 최악 케이스
        "fps": 1000 / np.median(times),
    }
```

**★ 왜 중앙값을 쓰는가**

```
50회 측정
  대부분 140~145 ms
  가끔  380 ms      ← OS 스케줄링 · GC · 디스크 I/O

평균   152 ms  (이상치에 끌림)
중앙값 142 ms  ★ 실제 체감에 가까움
p95    168 ms  ★ "95%는 이 안에 들어온다"
```

### 병목 분석 — 어디가 느린가

```
전체 파이프라인
  ① 이미지 로드      디스크 → 메모리
  ② 전처리          리사이즈 · 패딩 · 정규화 · 텐서 변환
  ③ ★ 추론          모델 순전파
  ④ 후처리          NMS · 좌표 변환
  ⑤ 그리기          박스 그리기 (선택)
```

**전형적인 비율**

| 단계 | GPU | CPU | 라즈베리파이 |
|---|---|---|---|
| 로드 | 8 ms (49%) | 8 ms (5%) | 22 ms (7%) |
| 전처리 | 2 ms (12%) | 6 ms (4%) | 18 ms (6%) |
| **추론** | **4 ms (24%)** | **★ 138 ms (89%)** | **★ 240 ms (80%)** |
| 후처리 | 2 ms (12%) | 3 ms (2%) | 12 ms (4%) |
| 그리기 | 0.5 ms | 1 ms | 8 ms (3%) |

```
★ GPU 에서는 로드가 병목입니다
   → 추론을 더 빠르게 해도 소용없음
   → 이미지 로드를 병렬화해야 함

★ CPU/파이에서는 추론이 병목입니다
   → 경량화가 정확히 효과적
```

> **★ 병목이 아닌 곳을 최적화하면 시간 낭비입니다.**
> 대단원 04에서 배운 것과 같습니다 — **먼저 측정하고 판단하세요.**

### 해상도와 속도의 관계

```
연산량은 해상도의 ★ 제곱에 비례합니다

  640 → 960   픽셀 2.25배   추론 ★ 약 2.2배 느림
  960 → 1280  픽셀 1.78배   추론 약 1.8배 느림
  640 → 416   픽셀 0.42배   추론 약 0.45배 (2.2배 빠름)

| **640** | **1.00×** | **4.1** | **0.52** |
| 960 | 2.25× | 1.8 | 0.65 |

### 프레임 스킵 전략

```
추론 4 FPS · 카메라 15 FPS 라면?

전략 ① 매 프레임 추론
       → 큐가 쌓임 → ★ 지연 누적 → 실시간 아님

전략 ② N프레임마다 추론
       → 15 FPS 중 4프레임만 → 실효 4 FPS

전략 ③ ★ 최신 프레임만 (프레임 드롭)
       → 추론이 끝나면 "지금 이 순간" 프레임을 가져옴
       → ★ 지연 없음
```

```python
"""export_all.py — 형식별 내보내기"""
import shutil
import time
from pathlib import Path

import pandas as pd
from ultralytics import YOLO

WEIGHTS = Path("models/v2.0-yolo11n-960-ep120-cctv_v2-s42.pt")
OUT = Path("models/export")
OUT.mkdir(parents=True, exist_ok=True)

FORMATS = [
    {"format": "onnx",      "imgsz": 640, "half": False, "simplify": True},
    {"format": "onnx",      "imgsz": 960, "half": False, "simplify": True},
    {"format": "ncnn",      "imgsz": 640, "half": True},
    {"format": "ncnn",      "imgsz": 960, "half": True},
    {"format": "openvino",  "imgsz": 640, "half": False},
    {"format": "torchscript", "imgsz": 640},
]

rows = []
for spec in FORMATS:
    fmt = spec["format"]
    imgsz = spec["imgsz"]
    tag = f"{fmt}_{imgsz}" + ("_fp16" if spec.get("half") else "")
    try:
        m = YOLO(WEIGHTS)
        t0 = time.perf_counter()
        path = m.export(**spec, device="cpu")
        dt = time.perf_counter() - t0

        src = Path(path)
        # NCNN·OpenVINO 는 폴더로 나옴
        dst = OUT / f"{WEIGHTS.stem}_{tag}{src.suffix}"
        if src.is_dir():
            dst = OUT / f"{WEIGHTS.stem}_{tag}"
            if dst.exists():
                shutil.rmtree(dst)
            shutil.copytree(src, dst)
            size = sum(f.stat().st_size for f in dst.rglob("*") if f.is_file())
        else:
            shutil.copy2(src, dst)
            size = dst.stat().st_size

        rows.append({"형식": fmt, "imgsz": imgsz,
                     "FP16": "✓" if spec.get("half") else "",
                     "크기(MB)": round(size / 1024**2, 2),
                     "변환(초)": round(dt, 1),
                     "경로": dst.name, "상태": "✓"})
    except Exception as e:
        rows.append({"형식": fmt, "imgsz": imgsz,
                     "FP16": "", "크기(MB)": None, "변환(초)": None,
                     "경로": "", "상태": f"✗ {type(e).__name__}"})

df = pd.DataFrame(rows)

print("=" * 100)
print("형식별 내보내기")
print("=" * 100)
print(df.to_string(index=False))
print("-" * 100)
orig = WEIGHTS.stat().st_size / 1024**2
print(f"  원본 (.pt)  {orig:.2f} MB")
print("""
★ 참고
  · NCNN 은 .param(구조) + .bin(가중치) 2개 파일로 나옵니다
  · OpenVINO 는 .xml + .bin 폴더
  · ONNX 는 단일 파일 → ★ 배포가 가장 편함
""")
print("=" * 100)
```

"""benchmark_formats.py — 형식별 CPU 추론 속도"""
import time
from pathlib import Path

import cv2
import numpy as np
import pandas as pd
from ultralytics import YOLO

SAMPLE = "tests/data/sample.jpg"
IMG = cv2.imread(SAMPLE)


def measure(fn, warmup=10, runs=40):
    for _ in range(warmup):
        fn()
    times = []
    for _ in range(runs):
        t0 = time.perf_counter()
        fn()
        times.append(time.perf_counter() - t0)
    t = np.array(times) * 1000
    return {
        "mean": round(t.mean(), 1),
        "median": round(float(np.median(t)), 1),
        "std": round(t.std(), 1),
        "p95": round(float(np.percentile(t, 95)), 1),
        "fps": round(1000 / float(np.median(t)), 2),
    }


MODELS = [
    ("PyTorch (.pt) 640", "models/v2.0-....pt", 640),

### Step 5. 병목 분석

```python
"""profile_pipeline.py — 어디가 느린가"""
import time
from pathlib import Path

import cv2
import numpy as np
import pandas as pd
from ultralytics import YOLO

from detector import Detector

SAMPLE = "tests/data/sample.jpg"


def profile(weights, imgsz, device="cpu", runs=30):
    m = YOLO(weights, task="detect")
    img_path = Path(SAMPLE)

    # 워밍업
    img = cv2.imread(str(img_path))
    for _ in range(8):
        m.predict(img, imgsz=imgsz, device=device, verbose=False)

    stages = {"로드": [], "추론(전처리)": [], "추론(순전파)": [],
              "추론(후처리)": [], "그리기": []}

    for _ in range(runs):
        t0 = time.perf_counter()
        arr = np.fromfile(str(img_path), dtype=np.uint8)
        img = cv2.imdecode(arr, cv2.IMREAD_COLOR)
        t1 = time.perf_counter()
        stages["로드"].append(t1 - t0)

        r = m.predict(img, imgsz=imgsz, device=device, verbose=False)[0]
        # ★ Ultralytics 가 내부 단계별 시간을 제공
        stages["추론(전처리)"].append(r.speed["preprocess"] / 1000)
        stages["추론(순전파)"].append(r.speed["inference"] / 1000)
        stages["추론(후처리)"].append(r.speed["postprocess"] / 1000)

        t2 = time.perf_counter()
        r.plot()
        stages["그리기"].append(time.perf_counter() - t2)

    rows = []
    for k, v in stages.items():
        ms = float(np.median(v)) * 1000
        rows.append({"단계": k, "중앙(ms)": round(ms, 2)})
    df = pd.DataFrame(rows)
    total = df["중앙(ms)"].sum()
    df["비율(%)"] = (df["중앙(ms)"] / total * 100).round(1)
    return df, total


CASES = [
    ("PyTorch 640 CPU", "models/v2.0-....pt", 640, "cpu"),
    ("NCNN 640 CPU", "models/export/..._ncnn_640_fp16", 640, "cpu"),
    ("PyTorch 640 GPU", "models/v2.0-....pt", 640, 0),
]

for label, w, imgsz, dev in CASES:
    if not Path(w).exists():
        continue
    df, total = profile(w, imgsz, dev)
    print("=" * 76)
    print(f"병목 분석 — {label}  (총 {total:.1f} ms)")
    print("=" * 76)
    for _, r in df.iterrows():
        bar = "█" * int(r["비율(%)"] / 2)
        mark = "★" if r["비율(%)"] > 50 else " "
        print(f"  {mark} {r['단계']:<16}{r['중앙(ms)']:>8.2f} ms  "
              f"{bar} {r['비율(%)']:.1f}%")
    print()

def strategy_every_frame(video, det, max_frames=150):
    """① 매 프레임 추론 — 지연 누적"""
    cap = cv2.VideoCapture(str(video))
    n, t0, lags = 0, time.perf_counter(), []
    src_fps = cap.get(cv2.CAP_PROP_FPS) or 30
    while n < max_frames:
        ok, frame = cap.read()
        if not ok:
            break
        det.predict(frame)
        n += 1
        # 지연 = 처리한 시간 - 영상 시간
        lags.append((time.perf_counter() - t0) - n / src_fps)
    cap.release()
    dt = time.perf_counter() - t0
    return {"전략": "① 매 프레임", "처리": n, "소요": round(dt, 1),
            "실효FPS": round(n / dt, 2),
            "최종 지연(초)": round(lags[-1], 1) if lags else 0}


def strategy_skip(video, det, skip=4, max_frames=150):
    """② N프레임마다 추론"""
    cap = cv2.VideoCapture(str(video))
    n, inf, t0 = 0, 0, time.perf_counter()
    src_fps = cap.get(cv2.CAP_PROP_FPS) or 30
    last = None
    while n < max_frames:
        ok, frame = cap.read()
        if not ok:
            break
        if n % skip == 0:
            last = det.predict(frame)
            inf += 1
        n += 1
    cap.release()
    dt = time.perf_counter() - t0
    return {"전략": f"② {skip}프레임 스킵", "처리": n, "소요": round(dt, 1),
            "실효FPS": round(n / dt, 2),
            "최종 지연(초)": round(dt - n / src_fps, 1)}


def strategy_latest(video, det, max_seconds=10):
    """③ ★ 항상 최신 프레임 (프레임 드롭)"""
    cap = cv2.VideoCapture(str(video))
    cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
    src_fps = cap.get(cv2.CAP_PROP_FPS) or 30

    t0 = time.perf_counter()
    inf, grabbed = 0, 0
    while time.perf_counter() - t0 < max_seconds:
        # ★ 밀린 프레임을 버리고 최신 것만
        for _ in range(int(src_fps * 0.05) + 1):
            if not cap.grab():
                break
            grabbed += 1
        ok, frame = cap.retrieve()
        if not ok:
            break
        det.predict(frame)
        inf += 1
    cap.release()
    dt = time.perf_counter() - t0
    return {"전략": "③ ★ 최신 프레임", "처리": grabbed, "소요": round(dt, 1),
            "실효FPS": round(inf / dt, 2), "최종 지연(초)": 0.0}


rows = [
    strategy_every_frame(VIDEO, DET),
    strategy_skip(VIDEO, DET, skip=4),
    strategy_latest(VIDEO, DET),
]
df = pd.DataFrame(rows)

class LatestFrameCapture:
    """★ 별도 스레드로 계속 읽어 최신 프레임만 유지"""

    def __init__(self, source, width=None, height=None):
        self.cap = cv2.VideoCapture(source)
        self.cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
        if width:
            self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, width)
        if height:
            self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)
        self._frame = None
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self._t = threading.Thread(target=self._reader, daemon=True)
        self._t.start()

    def _reader(self):
        while not self._stop.is_set():
            ok, f = self.cap.read()
            if not ok:
                time.sleep(0.01)
                continue
            with self._lock:
                self._frame = f            # ★ 항상 덮어씀

    def read(self):
        with self._lock:
            return None if self._frame is None else self._frame.copy()

    def release(self):
        self._stop.set()
        self._t.join(timeout=1)
        self.cap.release()

import argparse

from ultralytics import YOLO


def benchmark(weights, imgsz, device="cpu", n_warmup=10, n_runs=50,
              image=None, threads=None):
    import torch
    if threads:
        torch.set_num_threads(threads)

    m = YOLO(weights, task="detect")
    img = cv2.imread(image) if image else np.zeros((imgsz, imgsz, 3), np.uint8)

    for _ in range(n_warmup):
        m.predict(img, imgsz=imgsz, device=device, verbose=False)

    times, counts = [], []
    for _ in range(n_runs):
        t0 = time.perf_counter()
        r = m.predict(img, imgsz=imgsz, device=device, verbose=False)[0]
        times.append(time.perf_counter() - t0)
        counts.append(len(r.boxes))

    t = np.array(times) * 1000
    return {
        "weights": Path(weights).name,
        "imgsz": imgsz, "device": str(device),
        "cpu": platform.processor()[:40],
        "threads": torch.get_num_threads(),
        "median_ms": round(float(np.median(t)), 2),
        "mean_ms": round(float(t.mean()), 2),
        "std_ms": round(float(t.std()), 2),
        "p95_ms": round(float(np.percentile(t, 95)), 2),
        "fps": round(1000 / float(np.median(t)), 2),
        "detections": int(np.median(counts)),
        "note": "★ 순수 추론만. 이미지 로드·그리기 제외",

**구현 설계**

```python
"""cctv_pipeline.py — 라즈베리파이 실시간 파이프라인"""
import threading
import time
from collections import deque

import cv2
import numpy as np

from detector import get_detector


class Pipeline:
    """3단 구조: 캡처 스레드 · 추론 루프 · 이벤트 처리"""

    def __init__(self, source=0, width=1280, height=720,
                 idle_interval=0.5, active_interval=0.0):
        self.det = get_detector(profile="pi")

        # ── 캡처 스레드 ──
        self.cap = cv2.VideoCapture(source)
        self.cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
        self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, width)
        self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)
        self._frame = None
        self._lock = threading.Lock()
        self._stop = threading.Event()
        threading.Thread(target=self._reader, daemon=True).start()

        # ── ★ 적응형 주기 ──
        self.idle_interval = idle_interval        # 아무도 없을 때
        self.active_interval = active_interval    # 사람이 있을 때 (최대 속도)
        self.recent = deque(maxlen=5)

    def _reader(self):
        while not self._stop.is_set():
            ok, f = self.cap.read()
            if ok:
                with self._lock:
                    self._frame = f               # ★ 최신만 유지
            else:
                time.sleep(0.01)

    def latest(self):
        with self._lock:
            return None if self._frame is None else self._frame.copy()

    def run(self, on_detection=None):
        next_t = 0.0
        while not self._stop.is_set():
            now = time.perf_counter()
            if now < next_t:
                time.sleep(min(0.01, next_t - now))
                continue

            frame = self.latest()
            if frame is None:
                time.sleep(0.02)
                continue

            res = self.det.predict(frame)
            has = res["count"] > 0
            self.recent.append(has)

            if on_detection:
                on_detection(frame, res)

            # ★ 적응형: 최근에 검출이 있었으면 빠르게, 없으면 느리게
            interval = (self.active_interval if any(self.recent)
                        else self.idle_interval)
            next_t = time.perf_counter() + interval

    def stop(self):
        self._stop.set()
        self.cap.release()
```

**★ 적응형 주기의 효과**

```
현관 카메라의 하루

  아무도 없음   23시간 (96%)  →  0.5초 주기 = 2 FPS
  사람 있음      1시간  (4%)  →  최대 속도 = 5.4 FPS

평균 CPU 사용률
  고정 5.4 FPS  →  ★ 100% (항상 최대)
  적응형        →  ★ 약 40%

→ 발열 감소 → 스로틀링 완화 → ★ 필요할 때 더 빠름
```

**지연 예산**

```

  캡처 → 최신 프레임 획득     0 ms (별도 스레드)
  추론                       186 ms (5.4 FPS)
  이벤트 판정 (3프레임 연속)  × 3 = 558 ms
  알림 전송                  200~500 ms
  ─────────────────────────────────────
  합계                       ★ 758~1,058 ms

⚠️ 아슬아슬합니다

대응
  · 3프레임 → 2프레임 연속으로 완화
    (오탐이 늘지만 ROI·쿨다운으로 보완)
  · 알림 전송을 별도 스레드로 (비동기)
    → 판정 즉시 반환, 전송은 백그라운드

```

def build_calibration_set(dataset_root, n=500):
    """★ 다양성이 핵심"""

    import random

    groups = defaultdict(list)
    for p in Path(dataset_root, "images/train").glob("*.jpg"):

        out += files[:per]

```

**★ 조건부 재검토 시나리오**

```
아래 상황이 되면 INT8 을 다시 검토합니다

  ① 라즈베리파이에서 960 을 꼭 써야 하는데 속도가 부족
     → INT8 960 (118×1.4 = 165ms → 6 FPS)
     → mAP 0.85 (캘리브레이션 개선 후)
     → ★ FP16 640 (0.821) 보다 나음

  ② 더 저사양 하드웨어 (Pi Zero, 마이크로컨트롤러)
  ③ 배터리 구동으로 전력이 중요
  ④ 여러 카메라를 한 대로 처리
```

**★ 실험을 낭비로 만들지 않기 — 기록**

```markdown

★ 박스 좌표 정밀도가 특히 손상됨.

### 결정
★ 채택하지 않음. FP16 로 요구사항이 이미 충족됨.

### 재검토 조건
· 960 해상도가 필수가 되는 경우
· 더 저사양 하드웨어로 이전하는 경우

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| Pi 가 느린 이유 | 연산 600배 · 메모리 대역폭 72배 · **ARM 미최적화** |
| ★ 스로틀링 | 80°C 넘으면 클럭 하락 — **30% 손실** |
| 내보내기 | `model.export(format=...)` |
| **ONNX** | 범용 표준 · **1.3~1.8×** · 단일 파일 |
| **NCNN** | ★ **ARM 최적** · 2~3× · 라즈베리파이 |
| **OpenVINO** | Intel CPU 전용 · **2~3×** |
| FP16 | 크기 절반 · **손실 -0.002** · GPU 2배 |
| INT8 | 크기 1/4 · **손실 -0.01~-0.06** · 캘리브레이션 필요 |
| ★ 캘리브레이션 | **우리 데이터로** — COCO 쓰면 손실 큼 |
| ★ FPS 측정 | **워밍업 10 + 50회 + `perf_counter` + 중앙값** |
| p95 | 최악 케이스 — 실시간에 중요 |
| 병목 (CPU/Pi) | ★ **추론 (75~80%)** |
| 병목 (GPU) | ★ **이미지 로드 (40%)** |
| 해상도-속도 | ★ **제곱 비례** (640→960 = 2.2배) |
| 수확 체감 | 960 이상은 **mAP +0.007** 뿐 |
| 영상 전략 | ★ **최신 프레임** (지연 0) |
| 버퍼 | `CAP_PROP_BUFFERSIZE=1` |
| 적응형 주기 | 사람 없으면 느리게 → **CPU 40%** |
| 변환 후 | ★ **정확도 검증 + conf 재탐색** |
| 원칙 | ★ **필요할 때만 최적화** |

**오늘 반드시 기억할 세 가지**
> ① **NCNN 변환으로 정확도 손실 없이 2~3배 빨라집니다.** Day 150의 속도 문제가 이것으로 해결됐습니다.
> ② **FPS는 워밍업 후 50회 중앙값으로 재세요.** 1회 측정은 2~5배 틀립니다.
> ③ **실시간은 "최신 프레임"으로 만듭니다.** 매 프레임 처리하면 지연이 무한히 쌓입니다.
