## ③ 개념 설명

### 모듈이란

**모듈(module)** = 파이썬 코드가 들어 있는 `.py` 파일 하나.

```
calc.py  ← 이 파일 자체가 'calc' 모듈
```

다른 파일에서 `import calc` 라고 쓰면 그 안의 함수·클래스·변수를 쓸 수 있습니다.

### import 의 네 가지 형태

**`calc.py`**

```python
PI = 3.14159

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b
```

**① `import 모듈` — 가장 안전**

```python
import calc

print(calc.add(3, 5))       # 모듈 이름을 붙여 씁니다
print(calc.PI)
```

**② `import 모듈 as 별명`**

```python
import calc as c

print(c.add(3, 5))
```

> 대단원 02의 `import pandas as pd`, `import numpy as np` 가 이 형태입니다.
> **관례로 굳어진 별명은 반드시 따르세요.** 모두가 `pd` 를 쓰는데 혼자 `pandas_lib` 를 쓰면 읽기 힘듭니다.

**③ `from 모듈 import 이름` — 짧게 쓸 때**

```python
from calc import add, PI

print(add(3, 5))            # 모듈 이름 없이 바로
print(PI)
```

**④ `from 모듈 import *` — 권장하지 않음**

```python
from calc import *          # 전부 가져옴

print(add(3, 5))
```

> ⚠️ **`import *` 를 쓰지 마세요.**
> 어떤 이름이 들어왔는지 알 수 없고, 내 변수와 이름이 충돌하면 조용히 덮어씁니다.
>
> ```python
> from calc import *
> from utils import *       # utils 에도 add 가 있으면? 나중 것이 이김
> add(3, 5)                 # 어느 add 인지 알 수 없음
> ```

### 어떤 형태를 쓸 것인가

| 상황 | 권장 |
|---|---|
| 일반적인 경우 | `import 모듈` — 출처가 명확 |
| 관례가 있는 라이브러리 | `import pandas as pd` |
| 자주 쓰는 이름 몇 개 | `from 모듈 import 이름1, 이름2` |
| 어떤 경우든 | `from 모듈 import *` ❌ |

### 모듈 검색 경로

파이썬은 `import calc` 를 만나면 이 순서로 찾습니다.

```
① 현재 실행 중인 스크립트가 있는 폴더
② PYTHONPATH 환경변수에 등록된 폴더
③ 표준 라이브러리 폴더
④ site-packages (pip 로 설치한 것들)
```

```python
import sys

for path in sys.path:
    print(path)
```

> **`ModuleNotFoundError` 가 나면** 이 목록에 내 파일이 있는 폴더가 없는 것입니다.
> 가장 흔한 원인은 **실행 위치가 잘못된 것**입니다. ([Day 027](day-027.md))

### `__name__` 과 `__main__`

모든 모듈에는 `__name__` 이라는 변수가 자동으로 생깁니다.

```python
# calc.py
print(f"calc.py 의 __name__ = {__name__}")
```

**직접 실행하면**

```powershell
python calc.py
```
```
calc.py 의 __name__ = __main__
```

**import 하면**

```python
# main.py
import calc
```
```
calc.py 의 __name__ = calc
```

| 실행 방법 | `__name__` 값 |
|---|---|
| 직접 실행 (`python calc.py`) | `"__main__"` |
| import 됨 | `"calc"` (모듈 이름) |

**이걸 이용해 "직접 실행할 때만 도는 코드"를 씁니다.**

```python
# calc.py

def add(a, b):
    return a + b


if __name__ == "__main__":
    # 직접 실행할 때만 실행됨 — import 되면 실행 안 됨
    print("=== calc.py 테스트 ===")
    print(f"add(3, 5) = {add(3, 5)}")
    assert add(3, 5) == 8
    print("모든 테스트 통과!")
```

**왜 필요한가**

```python
# ❌ 이렇게 쓰면
def add(a, b):
    return a + b

print(add(3, 5))          # 테스트용인데...

# main.py 에서 import calc 만 해도 "8" 이 출력됨
```

```python
# ✅ 이렇게 쓰면
if __name__ == "__main__":
    print(add(3, 5))      # import 할 때는 조용함
```

> **모든 모듈에 `if __name__ == "__main__":` 블록을 두고 간단한 테스트를 넣는 것**이 좋은 습관입니다.
> 그 파일만 실행해 동작을 확인할 수 있습니다.

### 모듈은 한 번만 실행됩니다

```python
# config.py
print("config 로드됨")
SETTING = "값"
```

```python
# main.py
import config
import config          # 두 번 써도
import config          # 세 번 써도
```
```
config 로드됨          ← 한 번만 출력
```

> 파이썬은 이미 불러온 모듈을 `sys.modules` 에 캐싱합니다.
> **모듈 최상단의 코드는 첫 import 때 딱 한 번 실행**됩니다.

### 순환 참조 (circular import)

두 모듈이 서로를 import 하면 문제가 생깁니다.

```python
# a.py
import b

def func_a():
    return b.func_b()
```

```python
# b.py
import a                  # a 가 아직 다 로드되지 않았는데 a 를 부름

def func_b():
    return "B"
```

```
ImportError: cannot import name 'func_b' from partially initialized module 'b'
(most likely due to a circular import)
```

**해결 방법 세 가지**

| 방법 | 설명 |
|---|---|
| **구조 재설계** (최선) | 공통 부분을 제3의 모듈로 분리 |
| 함수 안에서 import | 필요한 순간에만 불러옴 |
| `from x import y` 대신 `import x` | 이름 참조를 늦춤 |

```python
# 함수 안에서 import — 임시방편
def func_a():
    import b              # 호출될 때 로드
    return b.func_b()
```

> **근본 해결은 설계입니다.** A와 B가 서로 필요하다면, 보통 그 공통 부분을 C로 빼야 한다는 신호입니다.

### Step 1. 첫 모듈 만들기

폴더를 하나 만들고 파일 두 개를 작성합니다.

**`calc.py`**

```python
"""간단한 계산 기능을 모아 둔 모듈."""

PI = 3.14159
E = 2.71828


def add(a, b):
    """두 수를 더합니다."""
    return a + b


def subtract(a, b):
    """두 수를 뺍니다."""
    return a - b


def multiply(a, b):
    """두 수를 곱합니다."""
    return a * b


def divide(a, b):
    """두 수를 나눕니다. 0으로 나누면 None."""
    if b == 0:
        return None
    return a / b


def circle_area(radius):
    """원의 넓이를 반환합니다."""
    return PI * radius ** 2


# ── 직접 실행할 때만 도는 테스트 ──
if __name__ == "__main__":
    print("=== calc.py 자체 테스트 ===")

    assert add(3, 5) == 8
    assert subtract(10, 3) == 7
    assert multiply(4, 5) == 20
    assert divide(10, 2) == 5.0
    assert divide(10, 0) is None
    assert abs(circle_area(2) - 12.56636) < 0.0001

    print("모든 테스트 통과!")
    print(f"원주율: {PI}")
    print(f"반지름 5인 원의 넓이: {circle_area(5):.2f}")
```

**`main.py`**

```python
"""calc 모듈을 사용하는 프로그램."""

print("=" * 40)

# ① import 모듈 형태

print(f"10 / 3     = {calc.divide(10, 3):.4f}")

### Step 2. 유틸리티 모듈 만들기

지금까지 만든 함수들을 모듈로 정리합니다.

**`myutils.py`**

```python
"""자주 쓰는 입력·출력·검증 함수 모음."""


# ══════════ 입력 ══════════

def input_int(prompt, low=None, high=None):
    """정수를 입력받습니다. 올바른 값이 올 때까지 반복합니다."""
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("  → 숫자를 입력해 주세요.")
            continue

        if low is not None and value < low:
            print(f"  → {low} 이상이어야 합니다.")
            continue
        if high is not None and value > high:
            print(f"  → {high} 이하여야 합니다.")
            continue

        return value


def input_float(prompt, low=None):
    """실수를 입력받습니다."""
    while True:
        try:
            value = float(input(prompt))
        except ValueError:
            print("  → 숫자를 입력해 주세요.")
            continue

        if low is not None and value < low:
            print(f"  → {low} 이상이어야 합니다.")
            continue

        return value


def input_text(prompt, allow_empty=False):
    """비어 있지 않은 문자열을 입력받습니다."""
    while True:
        value = input(prompt).strip()
        if value or allow_empty:
            return value
        print("  → 내용을 입력해 주세요.")


def input_yes_no(prompt):
    """예/아니오를 입력받아 True/False 를 반환합니다."""
    while True:
        answer = input(f"{prompt} (y/n): ").strip().lower()
        if answer in ("y", "yes", "예"):
            return True
        if answer in ("n", "no", "아니오"):
            return False
        print("  → y 또는 n 으로 입력해 주세요.")


# ══════════ 출력 ══════════

def print_box(text, width=44, char="=", align="center"):
    """텍스트를 박스 안에 출력합니다."""
    print(char * width)
    if align == "center":
        print(text.center(width))
    elif align == "left":
        print(text.ljust(width))
    else:
        print(text.rjust(width))
    print(char * width)


def print_line(width=44, char="-"):
    """구분선을 출력합니다."""
    print(char * width)


def print_table(headers, rows, widths=None):
    """표를 출력합니다."""
    if widths is None:
        widths = [max(len(str(h)), 10) for h in headers]

    header_line = "".join(f"{h:<{w}}" for h, w in zip(headers, widths))
    print(header_line)
    print("-" * len(header_line))

    for row in rows:
        print("".join(f"{str(c):<{w}}" for c, w in zip(row, widths)))


def make_bar(value, maximum, width=20, filled="█", empty="░"):
    """진행 바 문자열을 만듭니다."""
    if maximum <= 0:
        return empty * width
    ratio = max(0.0, min(value / maximum, 1.0))
    n = int(width * ratio)
    return filled * n + empty * (width - n)


# ══════════ 검증 ══════════

def is_valid_email(text):
    """아주 단순한 이메일 형식 검사."""
    return "@" in text and "." in text.split("@")[-1] and len(text) > 5


def clamp(value, low, high):
    """값을 low ~ high 범위로 제한합니다."""
    return max(low, min(value, high))


# ══════════ 자체 테스트 ══════════

if __name__ == "__main__":
    print_box("myutils 모듈 테스트")

    print("\n[make_bar]")
    for hp in (100, 75, 40, 10, 0):
        print(f"  HP {hp:>3}/100  {make_bar(hp, 100)}")

    print("\n[clamp]")
    for v in (-10, 50, 200):
        print(f"  clamp({v}, 0, 100) = {clamp(v, 0, 100)}")

    print("\n[is_valid_email]")
    for e in ("hong@test.com", "abc", "a@b"):
        print(f"  {e:<20} → {is_valid_email(e)}")

    print("\n[print_table]")
    print_table(
        ["이름", "점수", "학점"],
        [["홍길동", 85, "B"], ["김철수", 92, "A"], ["이영희", 78, "C"]],
        widths=[12, 8, 6],
    )

    print()
    print_box("테스트 완료", char="*")
```

### Step 3. 모듈로 나눈 성적 관리 (오늘의 종합 예제)

[Day 014](day-014.md)에서 만든 프로그램을 **3개 모듈**로 나눕니다.

**`storage.py` — 저장·불러오기 담당**

```python
"""데이터 저장과 불러오기를 담당하는 모듈."""

import json
import os

DB_FILE = "students.json"


def load(filename=DB_FILE):
    """JSON 파일을 불러옵니다. 없거나 손상되면 빈 딕셔너리."""
    if not os.path.exists(filename):
        return {}

    try:
        with open(filename, "r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        print(f"⚠ '{filename}' 이(가) 손상되었습니다. 새로 시작합니다.")
        return {}
    except Exception as e:
        print(f"⚠ 불러오기 실패: {e}")
        return {}


def save(data, filename=DB_FILE):
    """딕셔너리를 JSON 파일로 저장합니다. 성공하면 True."""
    try:
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    except Exception as e:
        print(f"⚠ 저장 실패: {e}")
        return False


def backup(filename=DB_FILE):
    """백업 파일을 만듭니다."""
    data = load(filename)
    if not data:
        return False
    return save(data, filename.replace(".json", "_backup.json"))


if __name__ == "__main__":
    print("=== storage.py 테스트 ===")

    test_data = {"홍길동": {"국어": 85, "영어": 90}}

```python
"""성적 계산 로직을 담당하는 모듈."""

SUBJECTS = ("국어", "영어", "수학")

GRADE_CUTOFFS = (
    (90, "A"),
    (80, "B"),
    (70, "C"),
    (60, "D"),
)


def get_total(scores):
    """총점을 반환합니다."""
    return sum(scores.values())


def get_average(scores):
    """평균을 반환합니다. 과목이 없으면 0."""
    if not scores:
        return 0.0
    return get_total(scores) / len(scores)


def get_grade(average):
    """평균에 해당하는 학점을 반환합니다."""
    for cutoff, letter in GRADE_CUTOFFS:
        if average >= cutoff:
            return letter
    return "F"


def get_rank(db, name):
    """평균 기준 등수를 반환합니다. 없으면 None."""
    if name not in db:
        return None

    ranked = sorted(db.items(), key=lambda x: get_average(x[1]), reverse=True)
    for i, (n, _) in enumerate(ranked, start=1):
        if n == name:
            return i
    return None


def get_subject_average(db, subject):
    """특정 과목의 전체 평균을 반환합니다."""
    values = [s[subject] for s in db.values() if subject in s]
    return sum(values) / len(values) if values else 0.0


def get_class_average(db):
    """학급 전체 평균을 반환합니다."""
    if not db:
        return 0.0
    return sum(get_average(s) for s in db.values()) / len(db)


if __name__ == "__main__":
    print("=== grades.py 테스트 ===")

    sample = {"국어": 85, "영어": 90, "수학": 80}
    print(f"총점: {get_total(sample)}")
    print(f"평균: {get_average(sample):.1f}")
    print(f"학점: {get_grade(get_average(sample))}")

    db = {
        "홍길동": {"국어": 85, "영어": 90, "수학": 80},
        "김철수": {"국어": 92, "영어": 88, "수학": 95},
    }
    print(f"김철수 등수: {get_rank(db, '김철수')}등")
    print(f"국어 평균: {get_subject_average(db, '국어'):.1f}")
    print(f"학급 평균: {get_class_average(db):.1f}")

"""파티클과 화면 흔들림 효과 모듈."""

import pygame
import random
import math

# 이 모듈이 필요로 하는 설정
DEFAULT_COLORS = [
    (231, 76, 60), (241, 196, 15), (46, 204, 113),
    (52, 152, 219), (155, 89, 182),
]


class Particle(pygame.sprite.Sprite):
    """수명이 있는 작은 조각."""

    def __init__(self, x, y, color, speed=5.0, life=35, size=6, gravity=0.12):
        super().__init__()
        angle = random.uniform(0, math.tau)
        spd = random.uniform(speed * 0.3, speed)

        self.vel_x = math.cos(angle) * spd
        self.vel_y = math.sin(angle) * spd
        self.pos_x, self.pos_y = float(x), float(y)

        self.life = life
        self.max_life = life
        self.base_size = size
        self.color = color
        self.gravity = gravity

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        self.rect = self.image.get_rect(center=(x, y))
        self._redraw()

    def _redraw(self):
        ratio = max(self.life / self.max_life, 0)
        size = max(int(self.base_size * ratio), 1)
        alpha = int(255 * ratio)

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (*self.color, alpha), (size, size), size)
        self.rect = self.image.get_rect(center=self.rect.center)

    def update(self):
        self.life -= 1
        if self.life <= 0:
            self.kill()
            return

        self.vel_y += self.gravity
        self.vel_x *= 0.98
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self._redraw()


class ScreenShake:
    """화면 흔들림을 관리합니다."""

    def __init__(self):
        self.timer = 0
        self.power = 0

    def shake(self, power=8, duration=12):
        if power >= self.power:
            self.power = power
            self.timer = duration

    def update(self):
        if self.timer > 0:
            self.timer -= 1
        else:
            self.power = 0

    @property
    def offset(self):
        if self.timer <= 0:
            return 0, 0
        return (random.randint(-self.power, self.power),
                random.randint(-self.power, self.power))


def make_explosion(x, y, group, color=None, count=22, power=6.0, max_particles=400):
    """폭발 파티클을 생성합니다. 개수 상한을 지킵니다."""
    if len(group) >= max_particles:
        return 0

    c = color or random.choice(DEFAULT_COLORS)
    made = 0

    for _ in range(count):
        if len(group) >= max_particles:
            break
        group.add(Particle(x, y, c, speed=power,
                           life=random.randint(25, 45),
                           size=random.randint(4, 9)))
        made += 1

    return made


# ── 모듈 자체 테스트 ──
if __name__ == "__main__":
    pygame.init()
    screen = pygame.display.set_mode((640, 480))
    pygame.display.set_caption("effects.py 테스트")
    clock = pygame.time.Clock()
    font = pygame.font.SysFont("malgungothic", 16)

    surface = pygame.Surface((640, 480))
    particles = pygame.sprite.Group()
    shaker = ScreenShake()

    running = True
    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            elif event.type == pygame.MOUSEBUTTONDOWN:
                make_explosion(*event.pos, particles)
                shaker.shake(7, 10)

        particles.update()
        shaker.update()

        surface.fill((20, 22, 32))
        particles.draw(surface)

        dx, dy = shaker.offset
        screen.fill((0, 0, 0))
        screen.blit(surface, (dx, dy))
        screen.blit(font.render(f"클릭하세요 · 파티클 {len(particles)}개",
                                True, (240, 240, 240)), (10, 10))

        pygame.display.flip()
        clock.tick(60)

    pygame.quit()

```

**해결 ② 타입 검사를 없애기 (더 파이썬다움)**

애초에 `isinstance` 검사가 필요 없게 만듭니다.

```python
# weapons.py — 아무것도 import 하지 않음
class Sword:
    def hit(self, target):
        """target 이 take_damage 를 가지고 있으면 그냥 부른다."""
        target.take_damage(10)
```

> 이것을 **덕 타이핑(duck typing)** 이라고 합니다.
> "오리처럼 걷고 오리처럼 운다면 오리로 취급한다" — **타입을 검사하지 말고 그냥 메서드를 부르라**는 뜻입니다.

**해결 ③ 함수 안에서 import (임시방편)**

```python
# weapons.py
class Sword:
    def hit(self, target):
        import player                    # 호출 시점에 로드
        if isinstance(target, player.Player):
            print("플레이어를 공격!")
```

동작은 하지만 **문제를 미룰 뿐**입니다. 구조를 다시 보는 것이 맞습니다.

> **교훈** — **순환 참조는 설계가 잘못됐다는 신호**입니다.
> "A가 B를 알아야 하고 B도 A를 알아야 한다"면, 보통 **둘 다 알아야 할 공통 개념**이 따로 있습니다.
> 그것을 별도 모듈로 빼세요. [Day 028](day-028.md)에서 `settings.py` 가 그 역할을 합니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 모듈 | `.py` 파일 하나 |
| `import 모듈` | `모듈.함수()` — 출처가 명확 (권장) |
| `import 모듈 as 별명` | 관례 별명은 반드시 따르기 (`pd`, `np`) |
| `from 모듈 import 이름` | 짧게 쓸 때 |
| `from 모듈 import *` | **쓰지 말 것** |
| 검색 경로 | 현재 폴더 → PYTHONPATH → 표준 → site-packages |
| `__name__` | 직접 실행 = `"__main__"` / import = 모듈 이름 |
| `if __name__ == "__main__":` | 직접 실행할 때만 도는 테스트 코드 |
| 캐싱 | 모듈 최상단 코드는 **첫 import 때 한 번만** |
| 금지 | 표준 라이브러리와 같은 파일명 (`random.py` 등) |

**오늘 반드시 기억할 세 가지**
> ① 모듈 최상단에는 **정의만**, 실행 코드는 `if __name__ == "__main__":` 안에.
> ② `from 모듈 import *` 는 쓰지 마세요.
> ③ 파일 이름을 `random.py` `json.py` 처럼 짓지 마세요.

각 모듈에 `if __name__ == "__main__":` 테스트를 넣습니다.
