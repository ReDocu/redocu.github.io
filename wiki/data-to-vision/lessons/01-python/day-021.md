## ② 왜 필요한가

어제 만든 코인 게임의 메인 루프를 다시 봅시다.

```python
while running:
    keys = pygame.key.get_pressed()
    player.handle_input(keys)
    player.update(screen_rect)
    for coin in coins:
        coin.update()

    screen.fill(BG)
    for coin in coins:
        coin.draw(screen)
    player.draw(screen)
```

객체가 2종류일 때는 괜찮습니다. 그런데 이번 주에 만들 슈팅게임에는 이런 것들이 등장합니다.

```
플레이어 1 · 총알 20 · 적 15 · 적 총알 30 · 아이템 3 · 폭발 이펙트 8
```

**총 77개의 객체**를 매 프레임 갱신하고 그려야 합니다.
`for` 문을 6번 쓰고, 삭제·추가를 각각 관리하면 코드가 금세 무너집니다.

pygame은 이 문제를 위해 **`Sprite` 와 `Group`** 을 제공합니다.

```python
all_sprites.update()          # 전부 갱신
all_sprites.draw(screen)      # 전부 그리기
```

**두 줄입니다.** 객체가 몇 개든, 몇 종류든 상관없습니다.
오늘은 그 구조의 기초인 `Player` 클래스를 제대로 만듭니다.

## ③ 개념 설명

### update / draw 분리 원칙

게임 객체는 **두 가지 일**을 합니다.

| 메서드 | 하는 일 | 하지 말아야 할 일 |
|---|---|---|
| `update()` | 위치·상태 **계산** | 화면에 그리기 |
| `draw()` | 화면에 **표시** | 상태 변경 |

```python
class Player:
    def update(self):
        self.x += self.speed        # 계산만
        # screen.blit(...)          # ❌ 여기서 그리면 안 됨

    def draw(self, surface):
        surface.blit(self.image, self.rect)     # 표시만
        # self.x += 1               # ❌ 여기서 상태를 바꾸면 안 됨
```

**왜 나누는가**

1. **모든 계산이 끝난 뒤에 그려야** 화면이 일관됩니다. 계산 중간에 그리면 어떤 객체는 옛 위치, 어떤 객체는 새 위치로 보입니다.
2. 일시정지는 `update()` 만 건너뛰면 됩니다. `draw()` 는 계속 돌려 화면이 유지됩니다.
3. 나중에 화면 없이 로직만 테스트할 수 있습니다.

### pygame.sprite.Sprite

pygame이 제공하는 **게임 객체의 표준 부모 클래스**입니다.

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()                        # ← 반드시 호출!
        self.image = make_player_surface()        # 필수 속성 ①
        self.rect = self.image.get_rect(center=(x, y))   # 필수 속성 ②

    def update(self):
        ...
```

**규칙 세 가지**

| 규칙 | 이유 |
|---|---|
| `super().__init__()` 호출 | 그룹 관리에 필요한 내부 준비 |
| `self.image` 속성 필수 | `Group.draw()` 가 이걸 씁니다 |
| `self.rect` 속성 필수 | 위치와 충돌 판정에 씁니다 |

> `Sprite` 를 상속하면 `draw()` 를 직접 만들지 않아도 됩니다. **`Group` 이 `image` 와 `rect` 를 보고 알아서 그립니다.**

### pygame.sprite.Group

여러 스프라이트를 담는 **컨테이너**입니다.

```python
all_sprites = pygame.sprite.Group()

player = Player(400, 500)
all_sprites.add(player)

# 게임 루프에서
all_sprites.update()               # 모든 스프라이트의 update() 호출
all_sprites.draw(screen)           # 모든 스프라이트를 화면에 그림
```

| 메서드 | 하는 일 |
|---|---|
| `.add(스프라이트)` | 추가 |
| `.remove(스프라이트)` | 제거 |
| `.update(*args)` | 모든 멤버의 `update()` 호출 (인자 전달 가능) |
| `.draw(surface)` | 모든 멤버를 `image`·`rect` 기준으로 그림 |
| `.empty()` | 전부 비우기 |
| `len(그룹)` | 개수 |
| `for s in 그룹:` | 순회 |

**`kill()` — 자기 자신을 모든 그룹에서 제거**

```python
bullet.kill()      # 이 스프라이트가 속한 모든 그룹에서 사라짐
```

> **이것이 `Group` 의 가장 큰 장점입니다.** [Day 011](day-011.md)에서 배운 "순회 중 삭제" 함정을 피할 수 있습니다.
> 리스트로 직접 관리하면 `for` 문 중에 `remove()` 를 하면 안 되지만, `kill()` 은 안전합니다.

### 여러 그룹에 동시에 넣기

```python
all_sprites = pygame.sprite.Group()      # 그리기용 (전부)
bullets = pygame.sprite.Group()          # 충돌 판정용 (총알만)
enemies = pygame.sprite.Group()          # 충돌 판정용 (적만)

bullet = Bullet(...)
all_sprites.add(bullet)
bullets.add(bullet)                      # 두 그룹에 동시에 소속
```

이렇게 하면:
- 그리기는 `all_sprites.draw(screen)` 한 줄
- 충돌 판정은 `groupcollide(bullets, enemies, ...)` 한 줄

**하나의 스프라이트가 여러 그룹에 속할 수 있다**는 점이 핵심입니다.

### 위치를 float 으로 관리하기

`Rect` 의 `x`, `y` 는 **정수만** 저장합니다.

```python
rect = pygame.Rect(0, 0, 10, 10)
rect.x = 10.7
print(rect.x)       # 10   ← 소수점이 잘림
```

그래서 속도가 `0.5` 면 이런 일이 생깁니다.

```python
rect.x += 0.5       # 10 → 10 (변화 없음)
rect.x += 0.5       # 10 → 10
# 영원히 안 움직임!
```

**해결 — 실제 위치를 `float` 으로 따로 두고, `rect` 는 표시용으로만 씁니다.**

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = make_surface()
        self.rect = self.image.get_rect(center=(x, y))

        self.pos_x = float(x)          # 실제 위치 (정밀)
        self.pos_y = float(y)

    def update(self):
        self.pos_x += self.vel_x       # float 로 계산
        self.pos_y += self.vel_y

        self.rect.centerx = int(self.pos_x)     # rect 에 반영
        self.rect.centery = int(self.pos_y)
```

> 이 패턴은 앞으로 모든 움직이는 객체에 씁니다. 총알·적·아이템 전부 마찬가지입니다.

### 무적 시간 (피격 후 깜빡임)

적과 겹쳐 있으면 매 프레임 피해를 입어 순식간에 죽습니다. 그래서 **피격 후 잠깐 무적**을 줍니다.

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, ...):
        self.invincible_timer = 0

    def take_damage(self, amount):
        if self.invincible_timer > 0:
            return False                        # 무적 중엔 무시
        self.hp -= amount
        self.invincible_timer = INVINCIBLE_TIME
        return True

    def update(self):
        if self.invincible_timer > 0:
            self.invincible_timer -= 1

        # 깜빡임 표현 — 6프레임 주기로 이미지 교체
        if self.invincible_timer > 0 and (self.invincible_timer // 6) % 2 == 0:
            self.image = self.image_dim
        else:
            self.image = self.image_normal
```

## ④ 단계별 실습

### Step 1. Sprite 로 Player 만들기

`player_v1.py` 를 만들어 실행합니다.

```python
import pygame

# ══════════ 상수 ══════════
SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60
PLAYER_SPEED = 6
PLAYER_SIZE = 48

COLOR_BG = (18, 20, 30)
COLOR_PLAYER = (52, 152, 219)
COLOR_COCKPIT = (241, 196, 15)
COLOR_TEXT = (240, 240, 240)


def make_player_surface(size=PLAYER_SIZE, color=COLOR_PLAYER):
    """플레이어 우주선 모양 Surface 를 만듭니다."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, color, [
        (size // 2, 0), (size, size), (size // 2, size * 0.78), (0, size),
    ])
    pygame.draw.circle(surf, COLOR_COCKPIT, (size // 2, size // 2), size // 7)
    return surf


class Player(pygame.sprite.Sprite):
    """플레이어 우주선."""

    def __init__(self, x, y):
        super().__init__()                 # Sprite 초기화 — 필수!

        self.image = make_player_surface()
        self.rect = self.image.get_rect(center=(x, y))

        # 실제 위치는 float 으로 관리
        self.pos_x = float(x)
        self.pos_y = float(y)

        self.speed = PLAYER_SPEED

    def handle_input(self, keys):
        """키 상태를 받아 이동 방향을 계산합니다."""
        dx = dy = 0

        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        # 대각선 정규화
        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx /= length
            dy /= length

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        """float 위치를 rect 에 반영하고 화면 경계를 지킵니다."""
        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)

        # 경계 제한 후, 보정된 값을 float 위치에도 되돌림
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x = float(self.rect.centerx)
        self.pos_y = float(self.rect.centery)


# ══════════ 초기화 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 021 - Player 클래스")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 80)

all_sprites = pygame.sprite.Group()
all_sprites.add(player)

# ══════════ 게임 루프 ══════════
running = True
while running:
    # ① 이벤트
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # ② 갱신
    keys = pygame.key.get_pressed()
    player.handle_input(keys)
    all_sprites.update()               # 그룹의 모든 update() 호출

    # ③ 그리기
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)           # 그룹의 모든 스프라이트를 그림

    info = [
        f"float 위치: ({player.pos_x:.2f}, {player.pos_y:.2f})",
        f"rect 위치:  {player.rect.center}",
        f"스프라이트: {len(all_sprites)}개",
        f"FPS: {clock.get_fps():.0f}",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **`draw()` 메서드를 만들지 않았는데도 그려집니다.**
> `Group.draw()` 가 `self.image` 와 `self.rect` 를 보고 알아서 `blit` 하기 때문입니다.
>
> **float 위치 확인** — 대각선으로 이동하면 `float 위치` 는 소수점이 나오지만 `rect 위치` 는 정수입니다.
> 이 덕분에 정규화된 대각선 이동(× 0.7071)이 정확하게 동작합니다.

### Step 2. 체력과 무적 시간 추가

```python
import pygame
import random

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60
PLAYER_SPEED = 6
PLAYER_SIZE = 48
PLAYER_MAX_HP = 100
INVINCIBLE_FRAMES = 90          # 1.5초

COLOR_BG = (18, 20, 30)
COLOR_PLAYER = (52, 152, 219)
COLOR_PLAYER_HIT = (231, 76, 60)
COLOR_TEXT = (240, 240, 240)
COLOR_HP = (46, 204, 113)
COLOR_HP_LOW = (231, 76, 60)
COLOR_GRAY = (60, 62, 75)


def make_player_surface(size, color):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, color, [
        (size // 2, 0), (size, size), (size // 2, size * 0.78), (0, size),
    ])
    pygame.draw.circle(surf, (241, 196, 15), (size // 2, size // 2), size // 7)
    return surf


class Player(pygame.sprite.Sprite):
    """체력과 무적 시간을 가진 플레이어."""

    def __init__(self, x, y):
        super().__init__()

        # 이미지 두 장을 미리 만들어 둡니다 (깜빡임용)
        self.image_normal = make_player_surface(PLAYER_SIZE, COLOR_PLAYER)
        self.image_hit = make_player_surface(PLAYER_SIZE, COLOR_PLAYER_HIT)
        self.image = self.image_normal

        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x = float(x)
        self.pos_y = float(y)

        self.speed = PLAYER_SPEED
        self.max_hp = PLAYER_MAX_HP
        self._hp = PLAYER_MAX_HP
        self.invincible_timer = 0

    # ── property 로 체력 보호 (Day 018) ──
    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, min(value, self.max_hp))

    @property
    def is_alive(self):
        return self._hp > 0

    @property
    def is_invincible(self):
        return self.invincible_timer > 0

    # ── 동작 ──
    def take_damage(self, amount):
        """피해를 입습니다. 무적 중이면 무시하고 False 를 반환합니다."""
        if self.is_invincible:
            return False

        self.hp -= amount
        self.invincible_timer = INVINCIBLE_FRAMES
        return True

    def heal(self, amount):
        before = self._hp
        self.hp += amount
        return self._hp - before

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx /= length
            dy /= length

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        # 무적 타이머 감소
        if self.invincible_timer > 0:
            self.invincible_timer -= 1

        # 깜빡임 — 6프레임 주기
        if self.is_invincible and (self.invincible_timer // 6) % 2 == 0:
            self.image = self.image_hit
        else:
            self.image = self.image_normal

        # 위치 반영
        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x = float(self.rect.centerx)
        self.pos_y = float(self.rect.centery)

    def draw_hp_bar(self, surface, x=10, y=SCREEN_HEIGHT - 40, width=200, height=18):
        """체력 바를 그립니다. (HUD 는 별도 메서드로)"""
        pygame.draw.rect(surface, COLOR_GRAY, (x, y, width, height))

        ratio = self._hp / self.max_hp
        color = COLOR_HP if ratio > 0.3 else COLOR_HP_LOW
        pygame.draw.rect(surface, color, (x, y, int(width * ratio), height))
        pygame.draw.rect(surface, COLOR_TEXT, (x, y, width, height), 2)


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 021 - 체력과 무적")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)
big_font = pygame.font.SysFont("malgungothic", 40)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2)
all_sprites = pygame.sprite.Group(player)      # 생성 시 바로 추가 가능

damage_log = []

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_SPACE:
                amount = random.randint(8, 20)
                if player.take_damage(amount):
                    damage_log.append(f"-{amount} 피해!")
                else:
                    damage_log.append("무적! (피해 없음)")
                damage_log = damage_log[-5:]
            elif event.key == pygame.K_h:
                healed = player.heal(25)
                damage_log.append(f"+{healed} 회복")
                damage_log = damage_log[-5:]
            elif event.key == pygame.K_r:
                player.hp = player.max_hp
                player.invincible_timer = 0
                damage_log.clear()

    keys = pygame.key.get_pressed()
    if player.is_alive:
        player.handle_input(keys)

    all_sprites.update()

    # ── 그리기 ──
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)
    player.draw_hp_bar(screen)

    info = [
        f"HP: {player.hp}/{player.max_hp}",
        f"무적: {'예 (' + str(player.invincible_timer) + ')' if player.is_invincible else '아니오'}",
        "",
        "SPACE=피해   H=회복   R=리셋",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 22))

    for i, line in enumerate(damage_log):
        screen.blit(font.render(line, True, COLOR_TEXT), (SCREEN_WIDTH - 200, 10 + i * 22))

    if not player.is_alive:
        msg = big_font.render("GAME OVER", True, COLOR_HP_LOW)
        screen.blit(msg, msg.get_rect(center=(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2)))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

**직접 해 보세요** — 스페이스를 연타하면 무적 시간 동안은 피해를 입지 않고 캐릭터가 깜빡입니다.

> **무적 시간이 없다면** 적과 겹친 순간 1초에 60번 피해를 입어 체력이 즉시 0이 됩니다.
> 실제 게임에서 이 처리는 필수입니다.

### Step 3. 그룹 활용 — 여러 스프라이트 관리 (오늘의 종합 예제)

```python
import pygame
import random

# ══════════ 상수 ══════════
SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

PLAYER_SPEED = 6
PLAYER_SIZE = 48
PLAYER_MAX_HP = 100
INVINCIBLE_FRAMES = 60

ITEM_SIZE = 26
HAZARD_SIZE = 34
HAZARD_SPEED_MIN, HAZARD_SPEED_MAX = 1.5, 4.0

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)
COLOR_GRAY = (60, 62, 75)
COLOR_PLAYER = (52, 152, 219)
COLOR_PLAYER_HIT = (231, 76, 60)
COLOR_ITEM = (46, 204, 113)
COLOR_HAZARD = (231, 76, 60)
COLOR_HP = (46, 204, 113)
COLOR_HP_LOW = (231, 76, 60)


# ══════════ Surface 생성 ══════════
def make_ship(size, color):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, color, [
        (size // 2, 0), (size, size), (size // 2, size * 0.78), (0, size),
    ])
    pygame.draw.circle(surf, (241, 196, 15), (size // 2, size // 2), size // 7)
    return surf


def make_circle(size, color, border=None):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, color, (size // 2, size // 2), size // 2)
    if border:
        pygame.draw.circle(surf, border, (size // 2, size // 2), size // 2, 2)
    return surf


def make_spike(size, color):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    points = []
    import math
    for i in range(8):
        angle = math.pi * 2 * i / 8
        r = size // 2 if i % 2 == 0 else size // 4
        points.append((size // 2 + r * math.cos(angle),
                       size // 2 + r * math.sin(angle)))
    pygame.draw.polygon(surf, color, points)
    return surf


# ══════════ 클래스 ══════════
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image_normal = make_ship(PLAYER_SIZE, COLOR_PLAYER)
        self.image_hit = make_ship(PLAYER_SIZE, COLOR_PLAYER_HIT)
        self.image = self.image_normal
        self.rect = self.image.get_rect(center=(x, y))

        self.pos_x, self.pos_y = float(x), float(y)
        self.speed = PLAYER_SPEED
        self.max_hp = PLAYER_MAX_HP
        self._hp = PLAYER_MAX_HP
        self.invincible_timer = 0
        self.score = 0

    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, min(value, self.max_hp))

    @property
    def is_alive(self):
        return self._hp > 0

    @property
    def is_invincible(self):
        return self.invincible_timer > 0

    def take_damage(self, amount):
        if self.is_invincible:
            return False
        self.hp -= amount
        self.invincible_timer = INVINCIBLE_FRAMES
        return True

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        if self.invincible_timer > 0:
            self.invincible_timer -= 1

        self.image = (self.image_hit
                      if self.is_invincible and (self.invincible_timer // 6) % 2 == 0
                      else self.image_normal)

        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


class Item(pygame.sprite.Sprite):
    """먹으면 점수를 주는 아이템."""

    def __init__(self, x, y):
        super().__init__()
        self.image = make_circle(ITEM_SIZE, COLOR_ITEM, (30, 150, 80))
        self.rect = self.image.get_rect(center=(x, y))
        self.timer = random.randint(0, 60)

    def update(self):
        """위아래로 살짝 흔들립니다."""
        self.timer += 1
        self.rect.y += 1 if (self.timer // 25) % 2 == 0 else -1

    @classmethod
    def spawn(cls, margin=50):
        return cls(random.randint(margin, SCREEN_WIDTH - margin),
                   random.randint(margin, SCREEN_HEIGHT - margin))


class Hazard(pygame.sprite.Sprite):
    """부딪히면 피해를 주는 장애물."""

    def __init__(self, x, y):
        super().__init__()
        self.image = make_spike(HAZARD_SIZE, COLOR_HAZARD)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)

        angle = random.uniform(0, 6.283)
        speed = random.uniform(HAZARD_SPEED_MIN, HAZARD_SPEED_MAX)
        import math
        self.vel_x = math.cos(angle) * speed
        self.vel_y = math.sin(angle) * speed

    def update(self):
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y

        half = HAZARD_SIZE // 2
        if self.pos_x <= half:
            self.pos_x, self.vel_x = half, abs(self.vel_x)
        elif self.pos_x >= SCREEN_WIDTH - half:
            self.pos_x, self.vel_x = SCREEN_WIDTH - half, -abs(self.vel_x)

        if self.pos_y <= half:
            self.pos_y, self.vel_y = half, abs(self.vel_y)
        elif self.pos_y >= SCREEN_HEIGHT - half:
            self.pos_y, self.vel_y = SCREEN_HEIGHT - half, -abs(self.vel_y)

        self.rect.center = (int(self.pos_x), int(self.pos_y))

    @classmethod
    def spawn(cls, margin=80):
        return cls(random.randint(margin, SCREEN_WIDTH - margin),
                   random.randint(margin, SCREEN_HEIGHT - margin))


# ══════════ 초기화 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 021 - 스프라이트 그룹")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)
big_font = pygame.font.SysFont("malgungothic", 42)


def reset_game():
    """게임 상태를 초기화하고 (player, 그룹들)을 반환합니다."""
    player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2)

    items = pygame.sprite.Group(Item.spawn() for _ in range(5))
    hazards = pygame.sprite.Group(Hazard.spawn() for _ in range(4))

    all_sprites = pygame.sprite.Group()
    all_sprites.add(player, *items, *hazards)

    return player, items, hazards, all_sprites


player, items, hazards, all_sprites = reset_game()

# ══════════ 게임 루프 ══════════
running = True
while running:
    # ① 이벤트
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_r:
                player, items, hazards, all_sprites = reset_game()

    # ② 갱신
    if player.is_alive:
        keys = pygame.key.get_pressed()
        player.handle_input(keys)
        all_sprites.update()               # 모든 스프라이트를 한 줄로 갱신

        # 아이템 획득 — 충돌한 것을 자동으로 kill()
        got = pygame.sprite.spritecollide(player, items, dokill=True)
        for _ in got:
            player.score += 10
            new_item = Item.spawn()
            items.add(new_item)
            all_sprites.add(new_item)

        # 장애물 충돌 — 삭제하지 않음
        hit = pygame.sprite.spritecollide(player, hazards, dokill=False)
        if hit:
            player.take_damage(15)

    # ③ 그리기
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)               # 모든 스프라이트를 한 줄로 그리기

    # HP 바
    pygame.draw.rect(screen, COLOR_GRAY, (10, SCREEN_HEIGHT - 40, 220, 20))
    ratio = player.hp / player.max_hp
    hp_color = COLOR_HP if ratio > 0.3 else COLOR_HP_LOW
    pygame.draw.rect(screen, hp_color, (10, SCREEN_HEIGHT - 40, int(220 * ratio), 20))
    pygame.draw.rect(screen, COLOR_TEXT, (10, SCREEN_HEIGHT - 40, 220, 20), 2)

    hud = [
        f"점수: {player.score}",
        f"HP: {player.hp}/{player.max_hp}",
        f"스프라이트: {len(all_sprites)}개 "
        f"(아이템 {len(items)} · 장애물 {len(hazards)})",
        "이동=방향키/WASD   R=재시작   ESC=종료",
    ]
    for i, line in enumerate(hud):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 24))

    if not player.is_alive:
        msg = big_font.render(f"GAME OVER  —  {player.score}점", True, COLOR_HP_LOW)
        sub = font.render("R 을 눌러 다시 시작", True, COLOR_TEXT)
        screen.blit(msg, msg.get_rect(center=(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2 - 20)))
        screen.blit(sub, sub.get_rect(center=(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2 + 30)))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print(f"최종 점수: {player.score}")
```

> **눈여겨볼 점 6가지**
> - **`all_sprites.update()` / `all_sprites.draw(screen)` 두 줄**로 모든 객체가 처리됩니다. 종류가 늘어도 이 줄은 안 바뀝니다.
> - 하나의 스프라이트가 **`all_sprites` 와 `items` 두 그룹에 동시에** 속합니다. 그리기용과 충돌용을 나눈 것입니다.
> - `pygame.sprite.spritecollide(player, items, dokill=True)` — 충돌한 아이템을 **자동으로 모든 그룹에서 제거**합니다. [Day 011](day-011.md)의 "순회 중 삭제" 문제가 원천적으로 없습니다.
> - `dokill=False` — 장애물은 부딪혀도 사라지지 않아야 하므로 `False`.
> - `pygame.sprite.Group(Item.spawn() for _ in range(5))` — 제너레이터를 그대로 넘길 수 있습니다.
> - `reset_game()` 함수로 초기화 로직을 모았습니다. R키 재시작이 한 줄로 끝납니다.

### `super().__init__()` 을 빠뜨림

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        self.image = make_ship()          # super() 호출 없음

group.add(Player(0, 0))

AttributeError: 'Player' object has no attribute '_Sprite__g'
```

**원인** — `Sprite` 가 그룹 관리를 위해 내부에 만드는 변수가 없습니다.
**해결** — `__init__` **맨 위**에 `super().__init__()` 을 넣습니다. ([Day 017](day-017.md))

### `self.image` 나 `self.rect` 가 없음

```python
class Bullet(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.surface = make_bullet()      # 이름이 image 가 아님
```

```
AttributeError: 'Bullet' object has no attribute 'image'
```

**원인** — `Group.draw()` 는 반드시 `image` 와 `rect` 라는 **정확한 이름**을 찾습니다.
**해결** — 속성 이름을 `self.image`, `self.rect` 로 맞춥니다.

### `rect` 에 실수를 대입해 움직이지 않음

```python
self.rect.x += 0.5          # 정수로 잘려서 변화 없음
```

**해결** — `float` 위치를 따로 두고 `rect` 에 반영합니다.

```python
self.pos_x += 0.5
self.rect.centerx = int(self.pos_x)
```

### `clamp_ip` 후 float 위치를 안 되돌림

```python
self.rect.clamp_ip(screen_rect)
# self.pos_x 는 여전히 화면 밖 값 그대로
```

**증상** — 벽에 붙어 있으면 계속 밖으로 나가려 해서, 반대 방향 키를 눌러도 한참 반응이 없습니다.
**해결** — 보정된 `rect` 값을 `float` 위치에 되돌립니다.

```python
self.rect.clamp_ip(screen_rect)
self.pos_x = float(self.rect.centerx)
self.pos_y = float(self.rect.centery)
```

### `update()` 안에서 그림을 그림

```python
def update(self, surface):
    self.pos_x += self.speed
    surface.blit(self.image, self.rect)     # ❌
```

**문제** — 계산과 표시가 섞이면 일시정지·리플레이·테스트가 전부 어려워집니다.
**해결** — `update()` 는 계산만. 그리기는 `Group.draw()` 에 맡기세요.

### 이미지를 `update()` 안에서 새로 만듦

```python
def update(self):
    self.image = make_ship(PLAYER_SIZE, COLOR_PLAYER)     # 매 프레임 생성!
```

**증상** — FPS가 급락합니다.
**해결** — `__init__` 에서 필요한 이미지를 **전부 미리 만들어 두고** 교체만 합니다.

### `kill()` 대신 리스트에서 직접 제거

```python
for item in items:
    if collided:
        items.remove(item)      # 순회 중 수정 — 위험
```

**해결** — `item.kill()` 을 쓰거나 `spritecollide(..., dokill=True)` 를 씁니다.

### 무적 시간을 안 둠

```python
if pygame.sprite.spritecollide(player, hazards, False):
    player.hp -= 15          # 겹쳐 있는 동안 1초에 60번!
```

**증상** — 장애물에 스치면 체력이 순식간에 0이 됩니다.
**해결** — `take_damage()` 안에서 무적 타이머를 확인합니다.

## ⑥ 확인 문제

**1.** `update()` 와 `draw()` 를 나누는 이유를 세 가지 쓰세요.

<details>
<summary>답 보기</summary>

1. **화면의 일관성** — 모든 객체의 계산이 끝난 뒤 한 번에 그려야, 같은 시점의 상태가 화면에 나타납니다. 계산 중간에 그리면 어떤 객체는 이전 프레임, 어떤 객체는 현재 프레임 위치로 보입니다.

2. **일시정지 구현이 간단** — `update()` 만 건너뛰면 됩니다. `draw()` 는 계속 돌아 화면이 유지되고, 위에 "PAUSED" 메시지만 얹으면 됩니다.
   ```python
   if not paused:
       all_sprites.update()
   all_sprites.draw(screen)
   ```

3. **테스트와 재사용** — 화면 없이 로직만 실행해 검증할 수 있습니다. 리플레이 기능, 서버 검증, AI 학습용 고속 시뮬레이션 등에 필요합니다.

> 보너스 — **역할이 분명해 코드를 찾기 쉽습니다.** "왜 안 움직이지?" → `update()` 를 보고, "왜 안 보이지?" → `draw()` 를 봅니다.
</details>

**2.** `Player` 에 **대시(dash)** 기능을 추가하세요. 스페이스를 누르면 바라보는 방향으로 순간 이동하고, 3초의 쿨타임이 있습니다.

<details>
<summary>답 보기</summary>

```python
DASH_DISTANCE = 150
DASH_COOLDOWN = 180          # 3초 (60 FPS 기준)


class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = make_ship(PLAYER_SIZE, COLOR_PLAYER)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.speed = PLAYER_SPEED

        self.last_dx = 0.0           # 마지막 이동 방향 기억
        self.last_dy = -1.0          # 기본은 위쪽
        self.dash_cooldown = 0

    @property
    def can_dash(self):
        return self.dash_cooldown <= 0

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length
            self.last_dx, self.last_dy = dx, dy      # 방향 기억

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def dash(self):
        """대시. 성공하면 True."""
        if not self.can_dash:
            return False

        self.pos_x += self.last_dx * DASH_DISTANCE
        self.pos_y += self.last_dy * DASH_DISTANCE
        self.dash_cooldown = DASH_COOLDOWN
        return True

    def update(self):
        if self.dash_cooldown > 0:
            self.dash_cooldown -= 1

        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


# ── 게임 루프에서 ──
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
        if player.dash():
            print("대시!")
        else:
            print(f"쿨타임 {player.dash_cooldown // 60 + 1}초 남음")

# ── HUD 에 쿨타임 표시 ──
if player.can_dash:
    text = "대시 준비 완료 (SPACE)"
else:
    text = f"대시 쿨타임 {player.dash_cooldown / 60:.1f}초"
screen.blit(font.render(text, True, COLOR_TEXT), (10, 100))
```

**포인트 4가지**
- **대시는 이벤트 방식**(`KEYDOWN`)입니다. 상태 방식이면 1초에 60번 대시합니다. ([Day 020](day-020.md))
- `last_dx`, `last_dy` 로 **마지막 이동 방향을 기억**합니다. 멈춰 있을 때 대시해도 방향이 있습니다.
- 대시 후에도 `update()` 의 `clamp_ip` 가 화면 밖으로 나가는 것을 막아 줍니다. **경계 처리를 한 곳에 모아 둔 덕분**입니다.
- `can_dash` 를 `@property` 로 만들면 밖에서 `player.can_dash` 로 깔끔하게 확인할 수 있습니다. ([Day 018](day-018.md))
</details>

**3.** 아래 코드는 플레이어가 화면 왼쪽 벽에 붙으면, 오른쪽 키를 눌러도 한동안 움직이지 않습니다. 원인과 해결책을 쓰세요.

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = make_ship(48, COLOR_PLAYER)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x = float(x)
        self.pos_y = float(y)

    def handle_input(self, keys):
        if keys[pygame.K_LEFT]:
            self.pos_x -= 6
        if keys[pygame.K_RIGHT]:
            self.pos_x += 6

    def update(self):
        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)
        self.rect.clamp_ip(pygame.Rect(0, 0, 800, 600))
```

<details>
<summary>답 보기</summary>

**원인 — `float` 위치와 `rect` 위치가 어긋납니다.**

`clamp_ip` 는 `rect` 만 화면 안으로 되돌립니다. **`pos_x` 는 그대로 화면 밖 값을 유지합니다.**

왼쪽 키를 3초간 누르고 있었다면:

```
pos_x:   24 → 18 → 12 → 6 → 0 → -6 → -12 → ... → -1050
rect.centerx: 24 → ... → 24 (clamp 로 계속 24 로 고정)
```

이제 오른쪽 키를 누르면 `pos_x` 는 -1050 에서 시작해 6씩 늘어납니다.
**화면에 다시 나타나려면 (1050 + 24) / 6 ≈ 179 프레임, 약 3초가 걸립니다.**

누른 시간이 길수록 반응이 늦어지는, 아주 찾기 어려운 버그입니다.

**해결 — `clamp_ip` 로 보정한 값을 `float` 위치에 되돌립니다.**

```python
def update(self):
    self.rect.centerx = int(self.pos_x)
    self.rect.centery = int(self.pos_y)

    self.rect.clamp_ip(pygame.Rect(0, 0, 800, 600))

    # 보정된 rect 값을 float 위치에 반영 — 이 두 줄이 핵심
    self.pos_x = float(self.rect.centerx)
    self.pos_y = float(self.rect.centery)
```

**다른 해결 방법 — float 단계에서 직접 제한**

```python
def update(self):
    half_w = self.rect.width / 2
    half_h = self.rect.height / 2

    self.pos_x = max(half_w, min(self.pos_x, 800 - half_w))
    self.pos_y = max(half_h, min(self.pos_y, 600 - half_h))

    self.rect.center = (int(self.pos_x), int(self.pos_y))
```

> **교훈** — **같은 정보를 두 곳에 저장하면 반드시 어긋납니다.**
> `pos_x` 와 `rect.centerx` 는 같은 것을 나타내므로, 한쪽을 고치면 **반드시 다른 쪽도 맞춰야** 합니다.
>
> 이 원칙은 앞으로도 계속 나옵니다. 체력을 `hp` 와 `hp_bar_width` 두 곳에 저장하면 같은 문제가 생깁니다.
> **계산할 수 있는 값은 저장하지 말고 매번 계산하세요.** ([Day 018](day-018.md)의 `@property`)
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| update / draw | 계산과 표시를 분리 |
| `Sprite` 상속 | `super().__init__()` + `self.image` + `self.rect` **3종 필수** |
| `Group` | `.update()` `.draw(surface)` — 객체가 몇 개든 두 줄 |
| 다중 소속 | 하나의 스프라이트가 여러 그룹에 동시에 |
| `kill()` | 모든 그룹에서 자기 자신 제거 — 순회 중 삭제 안전 |
| `spritecollide` | `dokill=True` 면 충돌한 것을 자동 제거 |
| float 위치 | `pos_x` 로 계산하고 `rect` 에 `int()` 로 반영 |
| 경계 처리 | `clamp_ip` 후 **float 위치도 되돌리기** |
| 무적 시간 | 피격 후 타이머 — 없으면 1초에 60번 피해 |

**오늘 반드시 기억할 세 가지**
> ① `Sprite` 상속 3종 세트 — `super().__init__()`, `self.image`, `self.rect`.
> ② 위치는 `float` 로 계산하고 `rect` 는 표시용.
> ③ `clamp_ip` 로 보정했으면 **`float` 위치도 함께 되돌리세요.**
