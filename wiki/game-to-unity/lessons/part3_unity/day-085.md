### 3-5. 카메라 기준 이동

**왜 필요한가** — "화면 위쪽"으로 가야 한다.

```csharp
    // ✗ 월드 기준
    Vector3 move = new Vector3(h, 0, v);

    // ✔ 카메라 기준
    Transform cam = Camera.main.transform;

    Vector3 forward = cam.forward;
    Vector3 right = cam.right;

    forward.y = 0; forward.Normalize();        // ★ 수평 성분만
    right.y = 0;   right.Normalize();

    Vector3 move = (forward * v + right * h).normalized;
```

```
   ★ y를 0으로 만드는 이유

   카메라가 아래를 보고 있으면
   forward에 -y 성분이 있다
   → 그대로 쓰면 캐릭터가 땅으로 파고든다
```

```
        카메라 (위에서 아래를 봄)
           ●
          ╱ forward = (0, -0.7, 0.7)
         ╱
        ▼
      대상

   y=0 → (0, 0, 0.7) → 정규화 → (0, 0, 1)
```

```
   ★ 캐릭터 회전도 이동 방향으로

   Quaternion target = Quaternion.LookRotation(move);
   transform.rotation = Quaternion.Slerp(transform.rotation, target, ...);
```

### 3-6. Cinemachine Impulse — 화면 흔들림

**왜 필요한가** — Day 48의 화면 흔들림을 3D로.

```
   구성

   ① CinemachineImpulseSource     충격을 발생시키는 쪽
   ② CinemachineImpulseListener   충격을 받는 쪽 (vcam에 추가)
```

```csharp
using Unity.Cinemachine;
using UnityEngine;

public class CameraShaker : MonoBehaviour
{
    public static CameraShaker Instance { get; private set; }

    [SerializeField] private CinemachineImpulseSource source;

    void Awake() { Instance = this; }

    public void Shake(float force = 1f)
    {
        source.GenerateImpulse(force);
    }

    public void ShakeDirectional(Vector3 dir, float force)
    {
        source.GenerateImpulseWithVelocity(dir.normalized * force);
    }
}
```

```
   ★ Impulse Definition

   Impulse Shape:     Recoil / Bump / Explosion / Rumble
   Impulse Duration:  지속 시간
   Default Velocity:  기본 방향·세기
   Dissipation:       감쇠 방식
```

```
   ★ Part 2 Day 48과 비교

   Part 2:  m_camera->Shake(6.0, 0.2);
            → sin × 감쇠를 직접 계산

   Unity:   source.GenerateImpulse(1f);
            → 파형·감쇠·전파를 엔진이 처리
```

```
   ⚠️ 흔들림이 과하면 멀미가 난다

   ★ 기준
   가벼운 타격   0.2 ~ 0.4
   강한 타격     0.6 ~ 1.0
   폭발          1.5 ~ 2.5

   지속 시간은 0.15 ~ 0.3초
```

### 3-7. 히트스톱 (Day 48)

**왜 필요한가** — 타격의 무게를 만든다.

```
   ★ 원리

   맞는 순간 아주 짧게 시간을 멈춘다
   → 뇌가 "닿았다"고 인식한다

   시간 →
   정상 ████████│░░│████████
                  ↑ 0.05~0.1초 정지
```

```csharp
using System.Collections;
using UnityEngine;

public class HitStop : MonoBehaviour
{
    public static HitStop Instance { get; private set; }

    private Coroutine running;

    void Awake() { Instance = this; }

    public void Stop(float duration, float scale = 0f)
    {
        if (running != null) StopCoroutine(running);
        running = StartCoroutine(StopRoutine(duration, scale));
    }

    private IEnumerator StopRoutine(float duration, float scale)
    {
        Time.timeScale = scale;

        // ★ 물리 스텝도 함께 줄인다
        Time.fixedDeltaTime = 0.02f * Mathf.Max(scale, 0.01f);

        yield return new WaitForSecondsRealtime(duration);   // ★ Realtime

        Time.timeScale = 1f;
        Time.fixedDeltaTime = 0.02f;

        running = null;
    }
}
```

```
   ⚠️ WaitForSeconds를 쓰면 영원히 안 끝난다

   Day 75에서 배운 그 함정
   → WaitForSecondsRealtime
```

```
   ⚠️ fixedDeltaTime 복구를 잊으면

   물리가 영구히 느려진다
```

```
   ★ 완전 정지 vs 슬로우

   scale = 0     완전 정지. 강한 타격
   scale = 0.1   슬로우. 부드럽다
   scale = 0.05  절충  ★
```

```
   ★ 히트스톱 시간 기준

   약공격  0.04 ~ 0.06초
   강공격  0.08 ~ 0.12초
   마무리  0.15 ~ 0.25초
```

### 3-8. 넉백 (Day 48)

**왜 필요한가** — 맞은 쪽이 밀려야 한다.

```csharp
    // NavMeshAgent가 있는 적
    private IEnumerator KnockbackRoutine(Vector3 dir, float force, float duration)
    {
        agent.isStopped = true;

        float t = 0;

        while (t < duration)
        {
            t += Time.deltaTime;

            // ★ 감쇠 곡선
            float decay = 1f - (t / duration);

            agent.Move(dir * force * decay * Time.deltaTime);

            yield return null;
        }

        agent.isStopped = false;
    }
```

```
   ★ agent.Move()를 쓰는 이유

   transform.position 직접 수정  →  NavMesh와 어긋난다
   agent.Move()                  →  NavMesh 위를 따라 이동  ✔
```

```
   ★ 감쇠 곡선

      │████
      │████▄▄
      │████████▄▄▄
      └──────────────▶ 시간
```

**왜 필요한가** — 액션 게임의 기본 방어 수단.

```csharp
    private IEnumerator DodgeRoutine(Vector3 dir)
    {
        isDodging = true;
        animator.SetTrigger(HashDodge);

        // ★ 무적 시작 (애니메이션 이벤트로 하는 것이 더 정확)
        isInvincible = true;

        float t = 0;
        while (t < dodgeDuration)
        {
            t += Time.deltaTime;

            float speed = dodgeSpeed * dodgeCurve.Evaluate(t / dodgeDuration);
            rb.linearVelocity = new Vector3(
                dir.x * speed, rb.linearVelocity.y, dir.z * speed);

            // ★ 무적은 앞부분만
            if (t > invincibleDuration) isInvincible = false;

            yield return null;
        }

        isInvincible = false;
        isDodging = false;
        dodgeCooldown = dodgeCooldownTime;
    }
```

```csharp
using System.Collections;
using UnityEngine;

public class HitFlash : MonoBehaviour
{
    [SerializeField] private Renderer[] renderers;
    [SerializeField] private Color flashColor = Color.white;
    [SerializeField] private float duration = 0.08f;
    [SerializeField] private float intensity = 3f;

    private static readonly int HashEmission = Shader.PropertyToID("_EmissionColor");

    private MaterialPropertyBlock block;
    private Coroutine running;

    void Awake()
    {
        block = new MaterialPropertyBlock();

        if (renderers == null || renderers.Length == 0)
            renderers = GetComponentsInChildren<Renderer>();
    }

    public void Flash()
    {
        if (running != null) StopCoroutine(running);
        running = StartCoroutine(FlashRoutine());
    }

    private IEnumerator FlashRoutine()
    {
        SetEmission(flashColor * intensity);

        yield return new WaitForSecondsRealtime(duration);   // ★ 히트스톱 중에도

        SetEmission(Color.black);
        running = null;
    }

    private void SetEmission(Color c)
    {
        foreach (Renderer r in renderers)
        {
            if (r == null) continue;
            r.GetPropertyBlock(block);
            block.SetColor(HashEmission, c);
            r.SetPropertyBlock(block);
        }
    }
}
```

```csharp
using TMPro;
using UnityEngine;

public class DamageNumber : MonoBehaviour
{
    [SerializeField] private TextMeshPro text;
    [SerializeField] private float riseHeight = 1.5f;
    [SerializeField] private float duration = 0.9f;

    public void Show(int amount)

        StartCoroutine(Routine());

    private IEnumerator Routine()
    {

        // ★ 랜덤 좌우 흔들림

        float t = 0;

        while (t < duration)

            float p = t / duration;

                + Vector3.up * (riseHeight * (1 - (1 - p) * (1 - p)))

            c.a = 1f - p * p;
            text.color = c;

            yield return null;
        }

        PoolManager.Instance.Return(gameObject);
    }
}
```

```csharp
    private void ToggleLockOn()
    {
        if (lockedTarget != null)
        {
            lockedTarget = null;
            lockOnCam.Priority = 5;
            return;
        }

        // ★ 화면 중앙에 가장 가까운 적
        EnemyController best = null;
        float bestScore = float.MaxValue;

        foreach (EnemyController e in FindAliveEnemies())
        {
            Vector3 vp = Camera.main.WorldToViewportPoint(e.transform.position);

            if (vp.z < 0) continue;            // 카메라 뒤
            if (vp.x < 0 || vp.x > 1 || vp.y < 0 || vp.y > 1) continue;

            float centerDist = Vector2.Distance(new Vector2(vp.x, vp.y),
                                                 new Vector2(0.5f, 0.5f));
            float worldDist = Vector3.Distance(transform.position, e.transform.position);

            float score = centerDist * 2f + worldDist * 0.1f;

            if (score < bestScore) { bestScore = score; best = e; }
        }

        if (best == null) return;

        lockedTarget = best;
        lockOnCam.LookAt = best.transform;
        lockOnCam.Priority = 20;               // ★ 우선순위를 올려 전환
    }
```

- [ ] `ClosestPoint`로 위치가 자연스럽다
- [ ] 적이 흰색으로 반짝인다
- [ ] MaterialPropertyBlock이 배칭을 유지한다
- [ ] 적이 뒤로 밀린다 (`agent.Move`)
- [ ] `transform.position`으로 하면 NavMesh가 어긋난다
- [ ] 데미지 숫자가 떠오른다 (빌보드)
- [ ] HP 바에 지연 잔상이 있다
- [ ] 적 머리 위 HP가 카메라를 향한다
- [ ] 적이 쓰러지고 가라앉으며 사라진다
- [ ] Space로 구르고 무적 프레임이 있다
- [ ] (선택) Tab으로 록온이 전환된다
- [ ] 적 3기를 모두 처치할 수 있다

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 카메라가 안 움직임 | Follow 미지정 | 대상 연결 |
| 마우스가 안 먹음 | Input Axis Controller | 축 연결 확인 |
| **카메라가 벽 통과** | Deoccluder 없음 | Extension 추가 |
| 카메라가 붙어버림 | Player 레이어 포함 | 제외 |
| **이동 방향이 이상** | 월드 기준 | 카메라 forward 변환 |
| 캐릭터가 땅으로 | `forward.y` 미제거 | y=0 후 정규화 |
| 히트스톱이 안 끝남 | `WaitForSeconds` | `WaitForSecondsRealtime` |
| **물리가 영구히 느림** | `fixedDeltaTime` 미복구 | 복구 |
| 흔들림이 없음 | Listener 없음 | vcam에 Extension |
| 멀미 | 흔들림 과다 | 0.2~0.6 |
| 플래시가 안 보임 | Emission 비활성 | 머티리얼에서 켜기 |
| 배칭이 깨짐 | `r.material` 사용 | MaterialPropertyBlock |
| 넉백 후 이상함 | `transform` 직접 이동 | `agent.Move` |
| 데미지 숫자가 뒤집힘 | 빌보드 없음 | `forward = cam.forward` |
| 파티클이 안 보임 | Play On Awake ✗ + Play 미호출 | 코드로 `Play()` |
| 파티클이 안 사라짐 | 풀 반납 누락 | `AutoReturnToPool` |
| 록온이 안 됨 | Priority 미변경 | 값 올리기 |
