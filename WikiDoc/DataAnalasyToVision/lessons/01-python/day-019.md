## ② 왜 필요한가

지금까지 만든 프로그램은 전부 이런 식이었습니다.

```
입력을 기다린다 → 처리한다 → 출력한다 → 입력을 기다린다 → ...
```

**사용자가 무언가를 칠 때까지 프로그램이 멈춰 있습니다.**

게임은 다릅니다. 플레이어가 아무것도 안 해도 적은 계속 움직이고, 총알은 날아가고, 시간은 흐릅니다.

```
1초에 60번:  입력 확인 → 모든 것을 갱신 → 화면을 다시 그린다
```

이 **끊임없이 도는 반복문**을 **게임 루프(game loop)** 라고 합니다.
오늘 배우는 게임 루프는 게임뿐 아니라 **모든 실시간 프로그램의 기본 구조**입니다.

> 대단원 05에서 만들 CCTV 시스템도 똑같은 구조입니다.
> `while True: 카메라 프레임 읽기 → 객체 검출 → 화면에 표시`

## ③ 개념 설명

### pygame 이란

**pygame** 은 파이썬으로 2D 게임을 만들 수 있게 해 주는 라이브러리입니다.
화면 그리기, 이미지 표시, 소리 재생, 키보드·마우스 입력을 모두 담당합니다.

```powershell
pip install pygame
```

> Day 001에서 이미 설치했습니다. `pip list` 로 확인하세요. 없으면 위 명령을 실행합니다.

### 게임 루프 — 게임의 심장

```python
while running:
    # ① 이벤트 처리 — 무슨 일이 일어났나?
    # ② 상태 갱신   — 위치·체력·점수를 계산
    # ③ 화면 그리기 — 지우고 다시 그린다
    # ④ 프레임 대기 — 너무 빠르지 않게
```

```
     ┌──────────────────────────────────────┐
     │                                      │
     ▼                                      │
 ① 이벤트 → ② 갱신 → ③ 그리기 → ④ tick ────┘
   (입력)    (계산)   (표시)    (60fps 유지)

     이 한 바퀴가 1프레임. 1초에 60바퀴.
```

**왜 매 프레임 화면을 지우고 다시 그리나?**
캐릭터가 움직이면 이전 자리의 그림이 남습니다. 그래서 **매번 전체를 지우고 처음부터 다시 그립니다.**
1초에 60번 반복되므로 사람 눈에는 부드럽게 움직이는 것으로 보입니다.

### 가장 작은 pygame 프로그램

```python
import pygame

pygame.init()                                    # ① 초기화

screen = pygame.display.set_mode((800, 600))     # ② 창 만들기
pygame.display.set_caption("내 첫 게임")           # 창 제목

clock = pygame.time.Clock()                      # ③ 시간 관리자
running = True

while running:                                   # ④ 게임 루프
    for event in pygame.event.get():             # 이벤트 처리
        if event.type == pygame.QUIT:
            running = False

    screen.fill((30, 30, 40))                    # 화면 지우기

    pygame.display.flip()                        # 화면에 반영
    clock.tick(60)                               # 60 FPS 유지

pygame.quit()                                    # ⑤ 정리
```

각 줄의 역할입니다.

| 코드 | 하는 일 |
|---|---|
| `pygame.init()` | pygame의 모든 기능을 준비 |
| `display.set_mode((800, 600))` | 800×600 창을 만들고 **Surface**(그림판)를 돌려줌 |
| `time.Clock()` | 프레임 속도를 조절하는 시계 |
| `event.get()` | 그 사이 일어난 사건(키 입력, 창 닫기 등) 목록 |
| `screen.fill(색)` | 화면 전체를 한 색으로 덮음 (지우기) |
| `display.flip()` | 그린 내용을 실제 화면에 반영 |
| `clock.tick(60)` | 1초에 60프레임이 되도록 남는 시간만큼 대기 |
| `pygame.quit()` | 자원 정리 |

### 좌표계 — 수학 시간과 다릅니다

```
   (0,0) ─────────────────► x 증가
     │
     │        ● (300, 200)
     │
     │
     ▼
   y 증가
```

| | 수학 | pygame |
|---|---|---|
| 원점 | 화면 가운데 | **왼쪽 위 모서리** |
| x 증가 | 오른쪽 | 오른쪽 (같음) |
| y 증가 | **위쪽** | **아래쪽** ⚠️ |

> **y가 아래로 증가한다**는 점이 가장 헷갈립니다.
> "위로 올라간다" = `y -= 5`, "아래로 내려간다" = `y += 5` 입니다.

### 색 — RGB 튜플

```python
BLACK  = (0, 0, 0)
WHITE  = (255, 255, 255)
RED    = (255, 0, 0)
GREEN  = (0, 255, 0)
BLUE   = (0, 0, 255)
YELLOW = (255, 255, 0)
```

각 값은 0~255입니다. `(R, G, B)` 순서입니다.
[Day 012](day-012.md)에서 배운 **튜플**을 씁니다. 색은 바뀌지 않으므로 튜플이 적절합니다.

투명도를 넣으려면 4개짜리 `(R, G, B, A)` 를 씁니다. A는 0(투명)~255(불투명)입니다.

### 도형 그리기

```python
pygame.draw.rect(surface, color, rect, width=0)
pygame.draw.circle(surface, color, center, radius, width=0)
pygame.draw.line(surface, color, start, end, width=1)
pygame.draw.polygon(surface, color, points, width=0)
```

| 함수 | 인자 | 예 |
|---|---|---|
| `rect` | `(x, y, 너비, 높이)` | `pygame.draw.rect(screen, RED, (100, 100, 50, 80))` |
| `circle` | 중심 좌표, 반지름 | `pygame.draw.circle(screen, BLUE, (400, 300), 40)` |
| `line` | 시작점, 끝점 | `pygame.draw.line(screen, WHITE, (0, 0), (800, 600), 3)` |
| `polygon` | 점들의 리스트 | `pygame.draw.polygon(screen, GREEN, [(100,100), (200,100), (150,50)])` |

> **`width=0` 은 "속을 채운다"** 는 뜻입니다. `width=3` 이면 두께 3의 테두리만 그립니다.

### Rect — 사각형 객체

pygame에서 **위치와 크기**를 다루는 핵심 도구입니다.

```python
rect = pygame.Rect(100, 200, 50, 80)      # x, y, 너비, 높이

print(rect.x, rect.y)          # 100 200   왼쪽 위 모서리
print(rect.width, rect.height) # 50 80
print(rect.left, rect.right)   # 100 150
print(rect.top, rect.bottom)   # 200 280
print(rect.center)             # (125, 240)
print(rect.centerx)            # 125
```

**편리한 점 — 어느 지점을 지정해도 나머지가 자동 계산됩니다.**

```python
rect.center = (400, 300)       # 중심을 화면 가운데로
print(rect.x, rect.y)          # 375 260  ← 자동으로 맞춰짐

rect.bottom = 600              # 바닥을 화면 아래에 붙임
rect.centerx = 400             # 가로 중앙 정렬
```

**이동**

```python
rect.x += 5                    # 오른쪽으로 5
rect.move_ip(5, -3)            # 제자리에서 이동 (in place)
new_rect = rect.move(5, -3)    # 새 Rect 를 반환 (원본 유지)
```

> `Rect` 는 앞으로 **모든 게임 객체의 위치·크기·충돌 판정**에 씁니다. [Day 021](day-021.md)부터 본격적으로 활용합니다.

### FPS와 프레임 독립 이동

```python
clock.tick(60)      # 1초에 60프레임을 넘지 않게 대기
```

`tick()` 은 **남는 시간만큼 프로그램을 재웁니다.** 이게 없으면 컴퓨터가 낼 수 있는 최대 속도로 돌아가
CPU를 100% 쓰고, 빠른 컴퓨터에서는 캐릭터가 순식간에 날아갑니다.

```python
print(clock.get_fps())          # 실제 FPS 확인
```

**컴퓨터 성능에 상관없이 같은 속도로 움직이게 하려면** 경과 시간을 반영합니다.

```python
dt = clock.tick(60) / 1000      # 지난 프레임 이후 흐른 시간(초)
x += speed * dt                 # 속도(픽셀/초) × 시간
```

> 초보 단계에서는 `clock.tick(60)` 만으로 충분합니다.
> 다만 `dt` 방식이 있다는 것은 알아 두세요. 프레임이 떨어지는 상황에서도 게임 속도가 일정해집니다.

### 이벤트 — 무슨 일이 일어났나

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:              # 창 닫기 버튼
        running = False
    elif event.type == pygame.KEYDOWN:         # 키를 누른 순간
        if event.key == pygame.K_ESCAPE:
            running = False
    elif event.type == pygame.MOUSEBUTTONDOWN: # 마우스 클릭
        print(event.pos)                       # 클릭 좌표
```

| 이벤트 타입 | 언제 |
|---|---|
| `QUIT` | 창 닫기 버튼 |
| `KEYDOWN` / `KEYUP` | 키를 누른/뗀 **순간** |
| `MOUSEBUTTONDOWN` / `UP` | 마우스 클릭 |
| `MOUSEMOTION` | 마우스 이동 |

> ⚠️ **`event.get()` 을 매 프레임 호출하지 않으면 창이 멈춥니다.**
> 운영체제가 "이 프로그램이 응답하지 않는다"고 판단하기 때문입니다. 게임 루프 첫머리에 반드시 넣으세요.

```python
font = pygame.font.SysFont("malgungothic", 24)     # 한글 폰트
```

## ④ 단계별 실습

### Step 1. 창 띄우기

`game01.py` 를 만들어 실행합니다.

```python
import pygame

# ── 설정 ──
SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
FPS = 60
BG_COLOR = (30, 30, 40)

# ── 초기화 ──
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 019 - 첫 창")
clock = pygame.time.Clock()

# ── 게임 루프 ──
running = True
while running:
    # ① 이벤트 처리
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False

    # ② 상태 갱신 (아직 없음)

    # ③ 화면 그리기
    screen.fill(BG_COLOR)

    # ④ 반영 및 대기
    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print("게임 종료")
```

실행하면 **어두운 회색 창**이 하나 뜹니다. 창 닫기 버튼이나 `ESC` 로 종료됩니다.

> 아무것도 안 보이지만 이 창은 **1초에 60번** 다시 그려지고 있습니다.

### Step 2. 도형 그리기와 좌표계 확인

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Day 019 - 도형과 좌표계")
clock = pygame.time.Clock()

# 색 정의 (튜플)
BG = (25, 25, 35)
WHITE = (240, 240, 240)
RED = (231, 76, 60)
GREEN = (46, 204, 113)
BLUE = (52, 152, 219)
YELLOW = (241, 196, 15)
GRAY = (80, 80, 95)

font = pygame.font.SysFont("malgungothic", 16)     # 루프 밖에서 한 번만!

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill(BG)

    # ── 격자 (100px 간격) ──
    for x in range(0, 801, 100):
        pygame.draw.line(screen, GRAY, (x, 0), (x, 600), 1)
    for y in range(0, 601, 100):
        pygame.draw.line(screen, GRAY, (0, y), (800, y), 1)

    # ── 도형들 ──
    # 사각형: (x, y, 너비, 높이)
    pygame.draw.rect(screen, RED, (100, 100, 120, 80))
    pygame.draw.rect(screen, GREEN, (300, 100, 120, 80), 4)      # 테두리만

    # 원: 중심 좌표, 반지름
    pygame.draw.circle(screen, BLUE, (150, 350), 50)
    pygame.draw.circle(screen, YELLOW, (350, 350), 50, 5)

    # 선
    pygame.draw.line(screen, WHITE, (500, 100), (700, 250), 4)

    # 다각형 (삼각형)
    pygame.draw.polygon(screen, GREEN, [(600, 350), (700, 500), (500, 500)])

    # ── 좌표 안내 ──
    labels = [
        ("(0, 0) 원점", (10, 5)),
        ("x는 오른쪽으로 →", (10, 570)),
        ("y는 아래로 ↓", (700, 5)),
        ("rect(100,100,120,80)", (100, 185)),
        ("circle((150,350), 50)", (100, 405)),
    ]
    for text, pos in labels:
        surface = font.render(text, True, WHITE)
        screen.blit(surface, pos)

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

실행하면 격자 위에 도형들이 그려집니다. **격자를 보며 좌표 감각을 익히세요.**

> `for x in range(0, 801, 100)` — [Day 007](day-007.md)에서 배운 `range` 의 step 을 씁니다.
> 격자 하나 그리는 데 반복문 2개면 충분합니다.

### Step 3. 움직이는 사각형 (게임 루프 체감하기)

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Day 019 - 튕기는 공")
clock = pygame.time.Clock()

BG = (25, 25, 35)
BALL_COLOR = (231, 76, 60)
WHITE = (240, 240, 240)

font = pygame.font.SysFont("malgungothic", 18)

# ── 공의 상태 ──
ball = pygame.Rect(400, 300, 40, 40)      # x, y, 너비, 높이
speed_x = 5
speed_y = 4
bounce_count = 0

running = True
while running:
    # ① 이벤트
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_SPACE:
                # 스페이스로 속도 반전
                speed_x = -speed_x
                speed_y = -speed_y

    # ② 상태 갱신
    ball.x += speed_x
    ball.y += speed_y

    # 벽 충돌 → 반사
    if ball.left <= 0 or ball.right >= 800:
        speed_x = -speed_x
        bounce_count += 1
        # 화면 밖으로 나가지 않게 위치 보정
        ball.left = max(ball.left, 0)
        ball.right = min(ball.right, 800)

    if ball.top <= 0 or ball.bottom >= 600:
        speed_y = -speed_y
        bounce_count += 1
        ball.top = max(ball.top, 0)
        ball.bottom = min(ball.bottom, 600)

    # ③ 그리기
    screen.fill(BG)
    pygame.draw.rect(screen, BALL_COLOR, ball)

    info = [
        f"위치: ({ball.x}, {ball.y})",
        f"속도: ({speed_x}, {speed_y})",
        f"반사: {bounce_count}회",
        f"FPS: {clock.get_fps():.1f}",
        "SPACE=반전  ESC=종료",
    ]
    for i, line in enumerate(info):
        surface = font.render(line, True, WHITE)
        screen.blit(surface, (10, 10 + i * 24))

    # ④ 반영
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

> **눈여겨볼 점 4가지**
> - `ball.left`, `ball.right`, `ball.top`, `ball.bottom` — `Rect` 가 알아서 계산해 줍니다. `ball.x + ball.width` 를 쓸 필요가 없습니다.
> - **속도를 뒤집는 것**(`speed_x = -speed_x`)이 반사입니다. 물리 계산이 필요 없습니다.
> - 반사 후 **위치를 보정**합니다. 안 하면 벽에 파묻혀 계속 방향이 뒤집히는 "떨림" 현상이 생깁니다.
> - `clock.tick(60)` 을 지우고 실행해 보세요. 공이 순식간에 사라지고 CPU 팬이 돕니다.

**실험해 볼 것**

| 바꿔 볼 것 | 결과 |
|---|---|
| `clock.tick(60)` → `clock.tick(10)` | 뚝뚝 끊기며 느려짐 |
| `clock.tick(60)` → `clock.tick(240)` | 4배 빨라짐 (프레임과 속도가 묶여 있다는 증거) |
| `screen.fill(BG)` 삭제 | 잔상이 길게 남아 그림이 됨 |
| `pygame.display.flip()` 삭제 | 아무것도 안 보임 |

### Step 4. 여러 도형 관리하기 (오늘의 종합 예제)

```python
import pygame
import random

# ══════════ 설정 ══════════
WIDTH, HEIGHT = 800, 600
FPS = 60

BG = (20, 22, 32)
WHITE = (240, 240, 240)
COLORS = [
    (231, 76, 60), (46, 204, 113), (52, 152, 219),
    (241, 196, 15), (155, 89, 182), (26, 188, 156),
]


# ══════════ 클래스 ══════════
class Ball:
    """튕겨 다니는 공."""

    def __init__(self, x, y, radius, color):
        self.x = float(x)
        self.y = float(y)
        self.radius = radius
        self.color = color
        self.speed_x = random.uniform(-4, 4)
        self.speed_y = random.uniform(-4, 4)
        self.bounces = 0

    def update(self):
        """위치를 갱신하고 벽 반사를 처리합니다."""
        self.x += self.speed_x
        self.y += self.speed_y

        if self.x - self.radius <= 0:
            self.x = self.radius
            self.speed_x = abs(self.speed_x)
            self.bounces += 1
        elif self.x + self.radius >= WIDTH:
            self.x = WIDTH - self.radius
            self.speed_x = -abs(self.speed_x)
            self.bounces += 1

        if self.y - self.radius <= 0:
            self.y = self.radius
            self.speed_y = abs(self.speed_y)
            self.bounces += 1
        elif self.y + self.radius >= HEIGHT:
            self.y = HEIGHT - self.radius
            self.speed_y = -abs(self.speed_y)
            self.bounces += 1

    def draw(self, surface):
        """자기 자신을 그립니다."""
        pygame.draw.circle(surface, self.color,
                           (int(self.x), int(self.y)), self.radius)

    @property
    def speed(self):
        """속력(스칼라)."""
        return (self.speed_x ** 2 + self.speed_y ** 2) ** 0.5


def create_ball():
    """무작위 공을 하나 만듭니다."""
    radius = random.randint(10, 35)
    return Ball(
        random.randint(radius, WIDTH - radius),
        random.randint(radius, HEIGHT - radius),
        radius,
        random.choice(COLORS),
    )


# ══════════ 초기화 ══════════
pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Day 019 - 공 여러 개")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

balls = [create_ball() for _ in range(5)]      # 컴프리헨션!

# ══════════ 게임 루프 ══════════
running = True
while running:
    # ① 이벤트
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_SPACE:
                balls.append(create_ball())            # 공 추가
            elif event.key == pygame.K_BACKSPACE:
                if balls:
                    balls.pop()                        # 공 제거
            elif event.key == pygame.K_r:
                balls = [create_ball() for _ in range(5)]   # 리셋

        elif event.type == pygame.MOUSEBUTTONDOWN:
            # 클릭한 자리에 공 추가
            mx, my = event.pos
            b = create_ball()
            b.x, b.y = float(mx), float(my)
            balls.append(b)

    # ② 갱신 — 모든 공에게 update() 를 시킴 (다형성의 씨앗)
    for ball in balls:
        ball.update()

    # ③ 그리기
    screen.fill(BG)

    for ball in balls:
        ball.draw(screen)

    total_bounces = sum(b.bounces for b in balls)
    fastest = max(balls, key=lambda b: b.speed) if balls else None

    info = [
        f"공 개수: {len(balls)}",
        f"총 반사: {total_bounces}회",
        f"최고 속력: {fastest.speed:.1f}" if fastest else "공이 없습니다",
        f"FPS: {clock.get_fps():.0f}",
        "",
        "SPACE=추가  BACKSPACE=제거  R=리셋  클릭=그 자리에 추가",
    ]
    for i, line in enumerate(info):
        surface = font.render(line, True, WHITE)
        screen.blit(surface, (10, 10 + i * 22))

    # ④ 반영
    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 5가지**
> - **`update()` 와 `draw()` 를 분리**했습니다. 계산과 표시를 나누는 것이 게임 코드의 기본 원칙입니다. [Day 021](day-021.md)에서 본격적으로 다룹니다.
> - `balls = [create_ball() for _ in range(5)]` — 리스트 컴프리헨션([Day 012](day-012.md))으로 객체 5개를 한 줄에 만듭니다.
> - `for ball in balls: ball.update()` — 공이 5개든 500개든 이 코드는 그대로입니다.
> - **좌표를 `float` 으로 저장**하고 그릴 때만 `int()` 로 바꿉니다. 정수로만 저장하면 느린 속도(0.5픽셀/프레임)를 표현할 수 없습니다.
> - `sum(b.bounces for b in balls)`, `max(balls, key=lambda b: b.speed)` — [Day 011](day-011.md)·[Day 009](day-009.md)에서 배운 것이 그대로 쓰입니다.

**스페이스를 30번 눌러 공을 늘려 보세요.** FPS가 어떻게 변하는지 관찰하면 성능 감각이 생깁니다.

## ⑤ 자주 하는 실수

### `pygame.event.get()` 을 안 불러서 창이 멈춤

```python
while running:
    screen.fill(BG)
    pygame.display.flip()
    clock.tick(60)
```

**증상** — 창이 하얗게 되거나 "응답 없음" 이 뜨고, 닫기 버튼도 안 먹습니다.
**원인** — 이벤트 큐를 비우지 않으면 운영체제가 프로그램이 멈춘 것으로 판단합니다.
**해결** — 게임 루프 첫머리에 반드시 이벤트 처리를 넣습니다.

### `pygame.display.flip()` 을 빼먹음

**증상** — 검은 창만 보이고 아무것도 안 그려집니다.
**원인** — `draw` 함수들은 **메모리 위 Surface** 에 그릴 뿐입니다. 실제 화면에 반영하려면 `flip()` 이 필요합니다.
**해결** — 루프 끝에 `pygame.display.flip()` (또는 `pygame.display.update()`)을 넣습니다.

### `screen.fill()` 을 안 해서 잔상이 남음

**증상** — 캐릭터가 지나간 자리에 흔적이 계속 쌓입니다.
**원인** — 이전 프레임의 그림이 그대로 남아 있습니다.
**해결** — 그리기 시작 전에 `screen.fill(배경색)`.

> 반대로 **일부러 지우지 않아 그림을 그리는 효과**를 낼 수도 있습니다. Step 3에서 실험해 보세요.

### `clock.tick()` 을 빼먹음

**증상** — 캐릭터가 순식간에 날아가고, CPU 사용률이 100%가 됩니다.
**해결** — 루프 끝에 `clock.tick(60)`.

### y축 방향을 착각

```python
if event.key == pygame.K_UP:
    player.y += 5          # 위 키를 눌렀는데 아래로 감
```

**해결** — pygame에서 **위쪽은 y 감소**입니다. `player.y -= 5`

### 폰트를 루프 안에서 만듦

```python
while running:
    font = pygame.font.SysFont("malgungothic", 24)     # 매 프레임 생성!
    text = font.render("점수", True, WHITE)
```

**증상** — FPS가 급격히 떨어집니다.
**해결** — 폰트·이미지·소리는 **루프 밖에서 한 번만** 만들어 재사용합니다.

### 한글이 네모로 나옴

```python
font = pygame.font.SysFont("arial", 24)
text = font.render("점수: 100", True, WHITE)
```

**원인** — 그 폰트에 한글 글자가 없습니다.
**해결** — 한글 폰트를 지정합니다.

```python
font = pygame.font.SysFont("malgungothic", 24)     # Windows
# font = pygame.font.SysFont("applegothic", 24)    # macOS
```

사용 가능한 폰트 목록은 이렇게 확인합니다.

```python
print(pygame.font.get_fonts())
```

### 벽 충돌 후 위치 보정을 안 해서 "떨림" 발생

```python
if ball.left <= 0:
    speed_x = -speed_x        # 위치 보정 없음
```

**증상** — 공이 벽에 붙어 부들부들 떱니다.
**원인** — 속도를 뒤집어도 공이 여전히 `left < 0` 이면, 다음 프레임에 또 뒤집힙니다.
**해결** — 방향을 바꾸면서 **위치도 벽 안쪽으로 밀어 넣습니다.**

```python
if ball.left <= 0:
    ball.left = 0
    speed_x = abs(speed_x)     # 확실하게 오른쪽으로
```

### `pygame.quit()` 을 안 함

**증상** — 창을 닫아도 프로세스가 남거나, VS Code에서 다음 실행이 이상해집니다.
**해결** — 루프가 끝난 뒤 `pygame.quit()` 을 호출합니다.

## ⑥ 확인 문제

**1.** 게임 루프의 4단계를 순서대로 쓰고, `screen.fill()` 이 왜 필요한지 설명하세요.

<details>
<summary>답 보기</summary>

**게임 루프 4단계**

```
① 이벤트 처리   pygame.event.get() — 키 입력, 창 닫기 등을 확인
② 상태 갱신     위치·체력·점수를 계산 (아직 화면에는 안 나타남)
③ 화면 그리기   지우고 → 모든 객체를 다시 그림
④ 프레임 대기   clock.tick(60) — 다음 프레임까지 대기
```

**`screen.fill()` 이 필요한 이유**

pygame은 **이전에 그린 것을 자동으로 지우지 않습니다.**
매 프레임 새 위치에 캐릭터를 그리면, 이전 위치의 그림이 그대로 남아 궤적처럼 쌓입니다.

그래서 **"전체를 지우고 → 처음부터 전부 다시 그린다"** 를 1초에 60번 반복합니다.
비효율적으로 보이지만, 무엇이 바뀌었는지 추적하는 것보다 훨씬 간단하고 빠릅니다.
</details>

**2.** 화면 가운데에서 시작해 **점점 커지다가 최대 크기가 되면 다시 작아지는** 원을 만드세요.

<details>
<summary>답 보기</summary>

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("숨쉬는 원")
clock = pygame.time.Clock()

BG = (20, 22, 32)
CIRCLE = (52, 152, 219)
WHITE = (240, 240, 240)

font = pygame.font.SysFont("malgungothic", 18)

radius = 20
grow_speed = 1.5          # 프레임당 변화량
MIN_RADIUS = 20
MAX_RADIUS = 200

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # ② 갱신
    radius += grow_speed

    if radius >= MAX_RADIUS:
        radius = MAX_RADIUS
        grow_speed = -grow_speed        # 방향 반전
    elif radius <= MIN_RADIUS:
        radius = MIN_RADIUS
        grow_speed = -grow_speed

    # ③ 그리기
    screen.fill(BG)
    pygame.draw.circle(screen, CIRCLE, (400, 300), int(radius))

    text = font.render(f"반지름: {radius:.1f}  방향: {'커짐' if grow_speed > 0 else '작아짐'}",
                       True, WHITE)
    screen.blit(text, (10, 10))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**포인트 3가지**
- **Step 3의 공 반사와 완전히 같은 구조**입니다. 위치 대신 반지름이 왔다 갔다 할 뿐입니다.
- 한계에 닿으면 **값을 보정한 뒤** 방향을 뒤집습니다. 안 하면 최대치를 넘어갔다 돌아오며 미세하게 떨립니다.
- `radius` 를 실수로 두고 그릴 때만 `int()` 로 바꿉니다. `grow_speed` 를 0.3 같은 작은 값으로 해도 동작하게 하기 위해서입니다.

**응용** — 색도 함께 변하게 해 보세요.
```python
color_value = int(255 * (radius - MIN_RADIUS) / (MAX_RADIUS - MIN_RADIUS))
pygame.draw.circle(screen, (color_value, 100, 255 - color_value), (400, 300), int(radius))
```

**3.** 아래 코드는 공이 화면 오른쪽으로 나가면 다시는 돌아오지 않습니다. 원인과 해결책을 쓰세요.

```python
ball = pygame.Rect(400, 300, 40, 40)
speed_x = 5

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    ball.x += speed_x

    if ball.x >= 800:
        speed_x = -speed_x

    screen.fill(BG)
    pygame.draw.rect(screen, RED, ball)
    pygame.display.flip()
    clock.tick(60)
```

<details>
<summary>답 보기</summary>

**원인 두 가지**

**① `ball.x` 는 왼쪽 모서리입니다.**
`ball.x >= 800` 은 "왼쪽 모서리가 화면 밖으로 완전히 나갔을 때"를 뜻합니다.
그전에 이미 공 전체가 화면 밖입니다. 오른쪽 끝을 검사하려면 `ball.right` 를 써야 합니다.

**② 위치 보정이 없습니다.**
속도를 뒤집어도 `ball.x` 가 여전히 800 이상이면, 다음 프레임에 조건이 또 참이 되어 **매 프레임 방향이 뒤집힙니다.**
결과적으로 공은 화면 밖에서 제자리 떨림에 갇힙니다.

```
프레임 1: x=800 → 조건 참 → speed = -5
프레임 2: x=795 → 조건 거짓 → 정상 이동

… 처럼 보이지만 x가 정확히 800을 넘어 805가 되면:
프레임 1: x=805 → speed = -5,  x=800
프레임 2: x=800 → 조건 참! → speed = +5   ← 또 뒤집힘
```

**해결**

```python
ball.x += speed_x

if ball.right >= 800:
    ball.right = 800          # 위치를 벽 안쪽으로 보정
    speed_x = -abs(speed_x)   # 확실하게 왼쪽으로
elif ball.left <= 0:
    ball.left = 0
    speed_x = abs(speed_x)    # 확실하게 오른쪽으로
```

**`-speed_x` 대신 `-abs(speed_x)` 를 쓰는 이유** — 방향을 "반전"이 아니라 "지정"하기 때문입니다.
어떤 이유로 이미 왼쪽으로 가고 있어도 오른쪽 벽에 닿았다면 무조건 왼쪽으로 보냅니다. 떨림이 원천 차단됩니다.

> **교훈** — 게임에서 경계 처리는 **"방향 바꾸기"와 "위치 되돌리기"가 한 쌍**입니다.
> 이 원칙은 [Day 021](day-021.md)의 플레이어 이동 제한, [Day 024](day-024.md)의 충돌 처리에서 계속 나옵니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 게임 루프 | ① 이벤트 ② 갱신 ③ 그리기 ④ tick — 1초에 60번 |
| 초기화 | `pygame.init()` → `display.set_mode((W,H))` → `time.Clock()` |
| 좌표계 | 원점은 **왼쪽 위** · **y는 아래로 증가** |
| 색 | `(R, G, B)` 튜플, 0~255 |
| 도형 | `draw.rect/circle/line/polygon` · `width=0` 이면 채움 |
| `Rect` | `x y width height` + `left right top bottom center` 자동 계산 |
| 이벤트 | `for event in pygame.event.get():` — **매 프레임 필수** |
| 화면 반영 | `screen.fill()` → 그리기 → `display.flip()` |
| FPS | `clock.tick(60)` — 없으면 CPU 폭주 |
| 폰트 | **루프 밖에서 한 번만** 생성 · 한글은 `malgungothic` |

**오늘 반드시 기억할 세 가지**
> ① `event.get()`, `screen.fill()`, `display.flip()`, `clock.tick()` — **네 개 중 하나만 빠져도** 게임이 이상해집니다.
> ② pygame의 **y축은 아래로 증가**합니다.
> ③ 벽에 부딪히면 **방향을 바꾸고 위치도 보정**하세요.

**과제** — 화면 안에서 대각선으로 움직이는 도형 3개(사각형·원·삼각형)를 만들고, 각각 다른 속도로 벽에 반사되게 하세요.
