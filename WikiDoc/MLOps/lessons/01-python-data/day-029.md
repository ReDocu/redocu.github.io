## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 수집 → 정제 → 저장을 **독립된 단계(Stage)** 로 분리해 설계할 수 있다.
- yaml 설정 하나로 파이프라인 전체를 정의하고 실행할 수 있다.
- 실패한 단계부터 **재시작**할 수 있는 구조를 만들 수 있다.
- 실행 이력을 기록하고 다음 실행에서 활용할 수 있다.

## ③ 개념 설명

### 파이프라인의 구성 요소

```
┌─────────────────────────────────────────────────────┐
│  Pipeline                                            │
│                                                      │
│   Stage 1        Stage 2        Stage 3             │
│  ┌────────┐    ┌────────┐    ┌────────┐            │
│  │ collect│───▶│  clean │───▶│  store │            │
│  └────────┘    └────────┘    └────────┘            │
│     ↓ 저장        ↓ 저장        ↓ 저장               │
│  raw.parquet  clean.parquet  final/                 │
└─────────────────────────────────────────────────────┘
                        ↓
                   실행 이력 (state.json)
```

**핵심 설계 원칙 네 가지**

| 원칙 | 설명 |
|---|---|
| **단계 분리** | 각 단계가 독립적으로 실행·테스트 가능 |
| **중간 결과 저장** | 다음 단계의 입력. 재시작의 기반 |
| **멱등성** | 같은 입력으로 여러 번 돌려도 같은 결과 |
| **관측 가능** | 무엇이 언제 얼마나 처리됐는지 기록 |

### 왜 단계를 나누는가

**나누지 않으면:**

```python
def run_everything():
    data = fetch_api()          # 5분
    clean = clean_data(data)    # 2분
    save(clean)                 # 여기서 실패하면
    # → 7분을 다시 처리해야 함
```

**나누면:**

```
collect  ✓ 5분 → data/raw/2026-08-12.parquet
clean    ✓ 2분 → data/clean/2026-08-12.parquet
store    ✗ 실패

$ pipeline run --resume
store    ✓ 재실행 (앞 단계는 저장된 결과 재사용)
```

**추가 이점**

- 단계마다 테스트할 수 있습니다
- 정제만 고쳤을 때 수집을 다시 안 해도 됩니다
- 각 단계를 다른 사람이 개발할 수 있습니다
- 병렬 실행 가능한 단계를 식별할 수 있습니다

### 멱등성 (idempotency)

**같은 입력으로 여러 번 실행해도 결과가 같아야 합니다.**

```python
# ❌ 멱등하지 않음 — 실행할 때마다 데이터가 늘어남
df.to_csv(path, mode="a")

# ✅ 멱등함 — 항상 같은 결과
df.to_parquet(path)              # 덮어씀
```

**왜 중요한가**

```
파이프라인이 중간에 죽음 → 다시 실행
  → 멱등하지 않으면 중복 데이터가 쌓임
  → 이미 저장된 100만 행이 200만 행이 됨
```

**W09 [Day 043](../02-sql-pipeline/day-043.md)의 핵심 개념**이고,
주차 체크포인트가 "같은 파이프라인을 두 번 돌려도 데이터가 중복되지 않는가"입니다.

### 상태 관리

**어디까지 성공했는지 기록해야 재시작이 가능합니다.**

```json
{
  "run_id": "20260812_143022",
  "started_at": "2026-08-12T14:30:22",
  "config_hash": "a3f9c1...",
  "stages": {
    "collect": {"status": "success", "rows": 3000, "seconds": 12.4,
                "output": "data/raw/20260812.parquet"},
    "clean":   {"status": "success", "rows": 2847, "seconds": 3.1,
                "output": "data/clean/20260812.parquet"},
    "store":   {"status": "failed", "error": "PermissionError: ..."}
  }
}
```

**설정이 바뀌면 재사용하면 안 됩니다.** 그래서 `config_hash` 를 저장합니다.

```python
if output_exists and not force and config_unchanged:
```

```bash

```

### 단계 인터페이스

**모든 단계가 같은 모양이어야 조합할 수 있습니다.**

```python
class Stage(ABC):
    name: str

    @abstractmethod
    def run(self, context: Context) -> StageResult:
        """단계를 실행합니다."""

    def output_path(self, context: Context) -> Path:
        """이 단계의 결과 파일 경로."""
```

### 로깅과 관측

**파이프라인은 사람이 안 보는 시간에 돕니다.**

```python
logger.info("[%s] 시작", stage.name)
logger.info("[%s] 완료 — %d행, %.1f초", stage.name, rows, elapsed)
logger.error("[%s] 실패: %s", stage.name, error)
```

**최소한 이 세 가지는 기록해야 합니다.**

| 항목 | 왜 |
|---|---|
| 시작·종료 시각 | 언제 얼마나 걸렸나 |
| 입출력 행 수 | 데이터가 예상대로 흘렀나 |
| 실패 원인 | 무엇을 고쳐야 하나 |

**행 수 변화가 특히 중요합니다.**

```
어제: 수집 3,000 → 정제 2,847 (95%)
오늘: 수집 3,000 → 정제 120   (4%)      ← 이상!
```

```python
"""파이프라인 설정."""

from __future__ import annotations

import hashlib
import json
import os
import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

import yaml

ENV_PATTERN = re.compile(r"\$\{([A-Za-z_][A-Za-z0-9_]*)\}")


class ConfigError(Exception):
    """설정이 잘못됨."""


def expand_env(value: Any, strict: bool = True) -> Any:
    """${VAR} 를 환경 변수로 치환합니다."""
    if isinstance(value, str):
        def replace(m: re.Match) -> str:
            name = m.group(1)
            env = os.getenv(name)
            if env is None:
                if strict:
                    raise ConfigError(f"환경 변수 {name} 가 설정되지 않았습니다")
                return ""
            return env
        return ENV_PATTERN.sub(replace, value)
    if isinstance(value, dict):
        return {k: expand_env(v, strict) for k, v in value.items()}
    if isinstance(value, list):
        return [expand_env(v, strict) for v in value]
    return value


@dataclass(frozen=True)
class StageConfig:
    """단계 하나의 설정."""

    name: str
    type: str
    enabled: bool = True
    params: dict[str, Any] = field(default_factory=dict)

    def __post_init__(self) -> None:
        if not self.name:
            raise ConfigError("단계의 name 은 필수입니다")
        if not self.type:
            raise ConfigError(f"[{self.name}] type 은 필수입니다")


@dataclass(frozen=True)
class PipelineConfig:
    """파이프라인 전체 설정."""

    name: str = "pipeline"
    data_dir: Path = Path("data")
    state_dir: Path = Path("state")
    log_level: str = "INFO"
    stages: list[StageConfig] = field(default_factory=list)
    raw: dict[str, Any] = field(default_factory=dict, repr=False)

    @property
    def enabled_stages(self) -> list[StageConfig]:
        return [s for s in self.stages if s.enabled]

    def stage(self, name: str) -> StageConfig | None:
        for s in self.stages:
            if s.name == name:
                return s
        return None

    def hash(self) -> str:
        """설정의 해시. 설정이 바뀌면 캐시를 무효화하는 데 씁니다."""
        payload = json.dumps(self.raw, sort_keys=True, ensure_ascii=False,
                             default=str)
        return hashlib.sha256(payload.encode("utf-8")).hexdigest()[:12]


STAGE_KEYS = ("name", "type", "enabled", "params")
PIPELINE_KEYS = ("name", "data_dir", "state_dir", "log_level", "stages")


def _check_unknown(data: dict, allowed: tuple[str, ...], where: str) -> None:
    unknown = set(data) - set(allowed)
    if unknown:
        raise ConfigError(
            f"{where} 에 알 수 없는 키: {sorted(unknown)} (가능: {sorted(allowed)})")


def load_config(path: Path | str, strict_env: bool = True) -> PipelineConfig:
    """yaml 설정을 읽어 검증된 PipelineConfig 를 돌려줍니다."""
    path = Path(path)
    if not path.exists():
        raise ConfigError(f"설정 파일이 없습니다: {path}")

    try:
        raw = yaml.safe_load(path.read_text(encoding="utf-8"))
    except yaml.YAMLError as e:
        raise ConfigError(f"YAML 문법 오류 ({path}): {e}") from e

    if not isinstance(raw, dict):
        raise ConfigError(f"설정의 최상위는 딕셔너리여야 합니다: {path}")

    expanded = expand_env(raw, strict=strict_env)
    _check_unknown(expanded, PIPELINE_KEYS, "설정 최상위")

    stages_raw = expanded.get("stages") or []
    if not isinstance(stages_raw, list) or not stages_raw:
        raise ConfigError("stages 는 비어 있지 않은 리스트여야 합니다")

    stages, seen = [], set()
    for i, s in enumerate(stages_raw):
        if not isinstance(s, dict):
            raise ConfigError(f"stages[{i}] 는 딕셔너리여야 합니다")
        _check_unknown(s, STAGE_KEYS, f"stages[{i}]")
        stage = StageConfig(**{k: v for k, v in s.items() if k in STAGE_KEYS})
        if stage.name in seen:
            raise ConfigError(f"단계 이름이 중복됩니다: {stage.name}")
        seen.add(stage.name)
        stages.append(stage)

    return PipelineConfig(
        name=str(expanded.get("name", "pipeline")),
        data_dir=Path(expanded.get("data_dir", "data")),
        state_dir=Path(expanded.get("state_dir", "state")),
        log_level=str(expanded.get("log_level", "INFO")).upper(),
        stages=stages,
        raw=raw,
    )
```

```python
"""실행 컨텍스트 — 단계 간 정보 전달."""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date, datetime
from pathlib import Path
from typing import Any

from dpipe.config import PipelineConfig


@dataclass
class Context:
    """파이프라인 실행 컨텍스트."""

    config: PipelineConfig
    run_id: str
    run_date: date
    force: bool = False
    artifacts: dict[str, Any] = field(default_factory=dict)

    @classmethod
    def create(cls, config: PipelineConfig, run_date: date | None = None,
               force: bool = False) -> "Context":
        now = datetime.now()
        return cls(
            config=config,
            run_id=now.strftime("%Y%m%d_%H%M%S"),
            run_date=run_date or now.date(),
            force=force,
        )

    @property
    def date_str(self) -> str:
        return self.run_date.strftime("%Y%m%d")

    def stage_dir(self, stage_name: str) -> Path:
        """단계별 출력 폴더."""
        path = self.config.data_dir / stage_name
        path.mkdir(parents=True, exist_ok=True)
        return path

    def output_path(self, stage_name: str, suffix: str = ".parquet") -> Path:
        """단계의 출력 파일 경로. 날짜별로 나뉩니다."""
        return self.stage_dir(stage_name) / f"{self.date_str}{suffix}"

    def set(self, key: str, value: Any) -> None:
        self.artifacts[key] = value

    def get(self, key: str, default: Any = None) -> Any:
        return self.artifacts.get(key, default)
```

`src/dpipe/state.py`:

```python
"""실행 상태 저장·복원."""

from __future__ import annotations

import json
import logging
from dataclasses import asdict, dataclass, field
from datetime import datetime
from pathlib import Path
from typing import Any, Literal

logger = logging.getLogger(__name__)

Status = Literal["pending", "running", "success", "failed", "skipped"]


@dataclass
class StageState:
    """단계 하나의 실행 상태."""

    name: str
    status: Status = "pending"
    rows_in: int = 0
    rows_out: int = 0
    seconds: float = 0.0
    output: str | None = None
    error: str | None = None
    started_at: str | None = None
    finished_at: str | None = None
    metrics: dict[str, Any] = field(default_factory=dict)

    @property
    def ok(self) -> bool:
        return self.status in ("success", "skipped")


@dataclass
class RunState:
    """한 번의 파이프라인 실행 상태."""

    run_id: str
    run_date: str
    config_hash: str
    started_at: str = field(default_factory=lambda: datetime.now().isoformat(timespec="seconds"))
    finished_at: str | None = None
    stages: dict[str, StageState] = field(default_factory=dict)

    @property
    def success(self) -> bool:
        return bool(self.stages) and all(s.ok for s in self.stages.values())

    @property
    def failed_stages(self) -> list[str]:
        return [n for n, s in self.stages.items() if s.status == "failed"]

    def record(self, state: StageState) -> None:
        self.stages[state.name] = state

    def to_dict(self) -> dict[str, Any]:
        d = asdict(self)
        d["success"] = self.success
        d["failed_stages"] = self.failed_stages
        return d

    def save(self, state_dir: Path) -> Path:
        state_dir.mkdir(parents=True, exist_ok=True)

        # 실행별 이력
        history = state_dir / f"run_{self.run_id}.json"
        history.write_text(json.dumps(self.to_dict(), ensure_ascii=False, indent=2),
                           encoding="utf-8")

        # 최신 상태 (재시작에 사용)
        latest = state_dir / "latest.json"
        latest.write_text(json.dumps(self.to_dict(), ensure_ascii=False, indent=2),
                          encoding="utf-8")

        logger.debug("상태 저장: %s", history)
        return history

    @classmethod
    def load_latest(cls, state_dir: Path) -> "RunState | None":
        path = Path(state_dir) / "latest.json"
        if not path.exists():
            return None

        try:
            data = json.loads(path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError) as e:
            logger.warning("상태 파일을 읽지 못했습니다 (%s) — 무시합니다", e)
            return None

        state = cls(
            run_id=data.get("run_id", ""),
            run_date=data.get("run_date", ""),
            config_hash=data.get("config_hash", ""),
            started_at=data.get("started_at", ""),
            finished_at=data.get("finished_at"),
        )
        for name, s in (data.get("stages") or {}).items():
            state.stages[name] = StageState(**{
                k: v for k, v in s.items()
                if k in StageState.__dataclass_fields__
```

```python
"""단계 공통 인터페이스."""

from __future__ import annotations

import logging
import time
from abc import ABC, abstractmethod
from datetime import datetime
from pathlib import Path

import pandas as pd

from dpipe.config import StageConfig
from dpipe.context import Context
from dpipe.state import StageState

logger = logging.getLogger(__name__)


class StageError(Exception):
    """단계 실행 실패."""


class Stage(ABC):
    """파이프라인 단계.

    자식은 execute() 만 구현하면 됩니다.
    캐싱·타이밍·로깅·상태 기록은 부모가 처리합니다.
    """

    def __init__(self, config: StageConfig):
        self.config = config
        self.name = config.name
        self.params = config.params

    # ---------- 자식이 구현 ----------

    @abstractmethod
    def execute(self, context: Context, data: pd.DataFrame | None
                ) -> pd.DataFrame:
        """실제 작업. 결과 DataFrame 을 돌려줍니다."""

    # ---------- 공통 ----------

    def output_path(self, context: Context) -> Path:
        return context.output_path(self.name)

    def is_cached(self, context: Context) -> bool:
        """이미 완료된 결과가 있는가."""
        return self.output_path(context).exists()

    def load_cached(self, context: Context) -> pd.DataFrame:
        return pd.read_parquet(self.output_path(context))

    def save(self, context: Context, df: pd.DataFrame) -> Path:
        path = self.output_path(context)
        path.parent.mkdir(parents=True, exist_ok=True)
        df.to_parquet(path, index=False, compression="zstd")
        return path

    def validate(self, df: pd.DataFrame) -> list[str]:
        """결과를 검증합니다. 문제를 문자열 목록으로 돌려줍니다."""
        problems = []
        min_rows = self.params.get("min_rows", 1)
        if len(df) < min_rows:
            problems.append(f"행 수가 {len(df)}로 최소({min_rows})보다 적습니다")
        required = self.params.get("required_columns", [])
        missing = [c for c in required if c not in df.columns]
        if missing:
            problems.append(f"필수 컬럼 누락: {missing}")
        return problems

    def run(self, context: Context, data: pd.DataFrame | None = None
            ) -> tuple[pd.DataFrame, StageState]:
        """캐싱·타이밍·검증을 포함한 실행."""
        state = StageState(name=self.name,
                           started_at=datetime.now().isoformat(timespec="seconds"))
        state.rows_in = len(data) if data is not None else 0

        # 캐시 확인
        if not context.force and self.is_cached(context):
            logger.info("[%s] 캐시 사용 — %s", self.name, self.output_path(context))
            result = self.load_cached(context)
            state.status = "skipped"
            state.rows_out = len(result)
            state.output = str(self.output_path(context))
            state.finished_at = datetime.now().isoformat(timespec="seconds")
            return result, state

        logger.info("[%s] 시작", self.name)
        state.status = "running"
        start = time.perf_counter()

        try:
            result = self.execute(context, data)
        except Exception as e:
            state.status = "failed"
            state.error = f"{type(e).__name__}: {e}"
            state.seconds = round(time.perf_counter() - start, 2)
            state.finished_at = datetime.now().isoformat(timespec="seconds")
            logger.exception("[%s] 실패", self.name)
            raise StageError(f"[{self.name}] {e}") from e

        problems = self.validate(result)
        if problems:
            state.status = "failed"
            state.error = "; ".join(problems)
            state.seconds = round(time.perf_counter() - start, 2)
            state.finished_at = datetime.now().isoformat(timespec="seconds")
            logger.error("[%s] 검증 실패: %s", self.name, state.error)
            raise StageError(f"[{self.name}] 검증 실패: {state.error}")

        path = self.save(context, result)

        state.status = "success"
        state.rows_out = len(result)
        state.seconds = round(time.perf_counter() - start, 2)
        state.output = str(path)
        state.finished_at = datetime.now().isoformat(timespec="seconds")
        state.metrics = {
            "columns": len(result.columns),
            "memory_mb": round(result.memory_usage(deep=True).sum() / 1024**2, 2),
            "file_mb": round(path.stat().st_size / 1024**2, 2),
        }

        logger.info("[%s] 완료 — %d행 → %d행, %.1f초, %s",
                    self.name, state.rows_in, state.rows_out,
                    state.seconds, path.name)
        return result, state

    def __repr__(self) -> str:
        return f"{type(self).__name__}(name={self.name!r})"
```

```python
from __future__ import annotations

import logging

import numpy as np
import pandas as pd

from dpipe.context import Context
from dpipe.stages.base import Stage, StageError

logger = logging.getLogger(__name__)

STATIONS = [f"{n}구" for n in [
    "중", "종로", "용산", "성동", "광진", "동대문", "중랑", "성북", "강북", "도봉",
    "노원", "은평", "서대문", "마포", "양천", "강서", "구로", "금천", "영등포",
    "동작", "관악", "서초", "강남", "송파", "강동"]]


class CollectStage(Stage):
    """데이터를 수집합니다.

    params:
        source: "mock" | "csv" | "api"
        path: source="csv" 일 때 원본 경로
        rows: source="mock" 일 때 생성할 행 수
        seed: 난수 시드
    """

    def execute(self, context: Context, data: pd.DataFrame | None) -> pd.DataFrame:
        source = self.params.get("source", "mock")

        if source == "csv":
            return self._from_csv(context)
        if source == "mock":
            return self._mock(context)
        raise StageError(f"지원하지 않는 source: {source}")

    def _from_csv(self, context: Context) -> pd.DataFrame:
        path = self.params.get("path")
        if not path:
            raise StageError("source='csv' 이면 params.path 가 필요합니다")

        from pathlib import Path
        p = Path(path)
        if not p.exists():
            raise StageError(f"원본 파일이 없습니다: {p}")

        df = pd.read_csv(p, encoding=self.params.get("encoding", "utf-8-sig"))
        logger.info("[%s] %s 에서 %d행 읽음", self.name, p, len(df))
        return df

    def _mock(self, context: Context) -> pd.DataFrame:
        """실습용 데이터를 생성합니다 (일부러 지저분하게)."""
        rows = int(self.params.get("rows", 5000))
        seed = int(self.params.get("seed", 42))
        rng = np.random.default_rng(seed + context.run_date.toordinal())

        base = pd.Timestamp(context.run_date)
        df = pd.DataFrame({
            "measured_at": base + pd.to_timedelta(rng.integers(0, 1440, rows), unit="m"),
            "station": rng.choice(STATIONS, rows),
            "pm10": rng.integers(8, 120, rows).astype(float),
            "pm25": rng.integers(3, 70, rows).astype(float),
            "o3": rng.uniform(0.005, 0.11, rows).round(4),
            "temperature": rng.uniform(18, 36, rows).round(1),
        })

        # 결측 5%
        idx = rng.choice(rows, size=rows // 20, replace=False)
        df.loc[idx, "pm10"] = np.nan

        # 이상치
        idx2 = rng.choice(rows, size=max(1, rows // 300), replace=False)
        df.loc[idx2, "pm10"] = rng.integers(700, 1400, len(idx2))

        # 중복 2%
        dup = df.sample(max(1, rows // 50), random_state=seed)
        df = pd.concat([df, dup], ignore_index=True)

        # 공백
        idx3 = rng.choice(len(df), size=len(df) // 25, replace=False)
        df.loc[idx3, "station"] = " " + df.loc[idx3, "station"] + " "

        df["collected_at"] = pd.Timestamp.now()
        logger.info("[%s] 모의 데이터 %d행 생성", self.name, len(df))
        return df.sample(frac=1, random_state=seed).reset_index(drop=True)
```

```python
"""정제 단계 — Day 023 의 절차."""

from __future__ import annotations

import logging

import numpy as np
import pandas as pd

from dpipe.context import Context
from dpipe.stages.base import Stage, StageError

logger = logging.getLogger(__name__)


class CleanStage(Stage):
    """데이터를 정제합니다.

    params:
        domain_rules: {컬럼: [최소, 최대]}
        dedup_keys: 중복 판단 기준 컬럼
        fill_strategy: "median" | "mean" | "drop"
        fill_group: 그룹별 대치에 쓸 컬럼
        outlier_method: "clip" | "nan" | "drop" | "none"
        max_drop_ratio: 이 비율 이상 사라지면 실패로 간주
    """

    def execute(self, context: Context, data: pd.DataFrame | None) -> pd.DataFrame:
        if data is None or data.empty:
            raise StageError("입력 데이터가 없습니다")

        df = data.copy()
        original = len(df)
        log = []

        # 1) 타입
        if "measured_at" in df.columns:
            df["measured_at"] = pd.to_datetime(df["measured_at"], errors="coerce")

        numeric_cols = self.params.get("numeric_columns",
                                       ["pm10", "pm25", "o3", "temperature"])
        for col in numeric_cols:
            if col in df.columns and df[col].dtype == "object":
                df[col] = pd.to_numeric(
                    df[col].astype(str).str.replace(",", "", regex=False),
                    errors="coerce")

        # 2) 문자열 정규화
        for col in df.select_dtypes("object").columns:
            df[col] = df[col].str.strip()
        log.append(f"문자열 정규화")

        # 3) 중복 제거
        before = len(df)
        keys = self.params.get("dedup_keys")
        df = df.drop_duplicates(subset=keys).reset_index(drop=True)
        removed = before - len(df)
        log.append(f"중복 {removed}건 제거")

        # 4) 도메인 규칙
        rules = self.params.get("domain_rules", {})
        for col, bounds in rules.items():
            if col not in df.columns:
                continue
            low, high = bounds
            invalid = (df[col] < low) | (df[col] > high)
            count = int(invalid.sum())
            if count:
                df.loc[invalid, col] = np.nan
                log.append(f"{col} 범위 밖 {count}건 → 결측")

        # 5) 이상치
        method = self.params.get("outlier_method", "clip")
        if method != "none":
            for col in numeric_cols:
                if col not in df.columns:
                    continue
                q1, q3 = df[col].quantile([0.25, 0.75])
                iqr = q3 - q1
                lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
                mask = (df[col] < lower) | (df[col] > upper)
                count = int(mask.sum())
                if not count:
                    continue
                if method == "clip":
                    df[col] = df[col].clip(lower, upper)
                elif method == "nan":
                    df.loc[mask, col] = np.nan
                elif method == "drop":
                    df = df[~mask].reset_index(drop=True)
                log.append(f"{col} 이상치 {count}건 {method}")

        # 6) 결측 처리
        strategy = self.params.get("fill_strategy", "median")
        group = self.params.get("fill_group")

        for col in numeric_cols:
            if col not in df.columns:
                continue
            na = int(df[col].isna().sum())
            if not na:
                continue

            if strategy == "drop":
                df = df.dropna(subset=[col]).reset_index(drop=True)
            elif group and group in df.columns:
                df[col] = df.groupby(group)[col].transform(
                    lambda s: s.fillna(s.median() if strategy == "median" else s.mean()))
                df[col] = df[col].fillna(df[col].median())
            else:
                value = df[col].median() if strategy == "median" else df[col].mean()
                df[col] = df[col].fillna(value)
            log.append(f"{col} 결측 {na}건 {strategy}")

        # 7) 손실률 검증
        drop_ratio = 1 - len(df) / original if original else 0
        max_drop = float(self.params.get("max_drop_ratio", 0.3))
        if drop_ratio > max_drop:
            raise StageError(
                f"데이터 손실이 너무 큽니다: {original} → {len(df)} "
                f"({drop_ratio:.1%} > {max_drop:.0%})")

        for line in log:
            logger.debug("[%s] %s", self.name, line)
        logger.info("[%s] %d행 → %d행 (%.1f%% 손실), %d개 처리",
                    self.name, original, len(df), drop_ratio * 100, len(log))

        return df
```

```python
"""변환 단계 — 파생 컬럼과 dtype 최적화."""

from __future__ import annotations

import logging

import numpy as np
import pandas as pd

from dpipe.context import Context
from dpipe.stages.base import Stage, StageError

logger = logging.getLogger(__name__)


class TransformStage(Stage):
    """파생 컬럼을 만들고 dtype 을 최적화합니다.

    params:
        add_time_features: 시간 파생 컬럼 추가
        add_group_stats: 그룹 통계 파생
        group_column: 그룹 기준
        grade_column: 등급을 매길 컬럼
        grade_thresholds: [경계1, 경계2, 경계3]
        grade_labels: [라벨1, 라벨2, 라벨3, 기본]
        optimize_dtypes: dtype 최적화 여부
    """

    def execute(self, context: Context, data: pd.DataFrame | None) -> pd.DataFrame:
        if data is None or data.empty:
            raise StageError("입력 데이터가 없습니다")

        df = data.copy()
        added = []

        # 시간 파생
        if self.params.get("add_time_features", True) and "measured_at" in df.columns:
            df["date"] = df["measured_at"].dt.date.astype(str)
            df["hour"] = df["measured_at"].dt.hour.astype("uint8")
            df["weekday"] = df["measured_at"].dt.dayofweek.astype("uint8")
            df["is_weekend"] = df["weekday"] >= 5
            added += ["date", "hour", "weekday", "is_weekend"]

        # 그룹 통계
        group = self.params.get("group_column", "station")
        target = self.params.get("grade_column", "pm10")

        if self.params.get("add_group_stats", True) and group in df.columns:
            df[f"{group}_avg"] = df.groupby(group)[target].transform("mean").round(2)
            df["deviation"] = (df[target] - df[f"{group}_avg"]).round(2)
            added += [f"{group}_avg", "deviation"]

        # 등급
        thresholds = self.params.get("grade_thresholds", [80, 50, 30])
        labels = self.params.get("grade_labels", ["나쁨", "약간나쁨", "보통", "좋음"])
        if target in df.columns and len(thresholds) == len(labels) - 1:
            conditions = [df[target] > t for t in thresholds]
            df["grade"] = np.select(conditions, labels[:-1], default=labels[-1])
            added.append("grade")

        # dtype 최적화 (Day 026)
        if self.params.get("optimize_dtypes", True):
            df = self._optimize(df)

        logger.info("[%s] 파생 컬럼 %d개 추가: %s",
                    self.name, len(added), ", ".join(added))
        return df

    @staticmethod
    def _optimize(df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        for col in df.columns:
            if pd.api.types.is_integer_dtype(df[col]):
                kind = "unsigned" if df[col].min() >= 0 else "integer"
                df[col] = pd.to_numeric(df[col], downcast=kind)
            elif pd.api.types.is_float_dtype(df[col]):
                df[col] = pd.to_numeric(df[col], downcast="float")
            elif df[col].dtype == "object":
                if df[col].nunique() / max(len(df), 1) < 0.5:
                    df[col] = df[col].astype("category")
        return df
```

```python
from __future__ import annotations

import logging

import pandas as pd

from dpipe.context import Context

class StoreStage(Stage):
    """최종 결과를 저장하고 요약을 만듭니다.

    params:
        output_dir: 최종 저장 폴더
        partition_cols: 파티션 컬럼
        also_csv: CSV 로도 저장할지
        summary_group: 요약 집계 기준
        summary_value: 요약 대상 컬럼
    """

    def execute(self, context: Context, data: pd.DataFrame | None) -> pd.DataFrame:
        if data is None or data.empty:
            raise StageError("입력 데이터가 없습니다")

        out_dir = Path(self.params.get("output_dir",
                                       context.config.data_dir / "final"))
        out_dir.mkdir(parents=True, exist_ok=True)

        # 1) Parquet (파티션 선택)
        partition_cols = self.params.get("partition_cols")
        if partition_cols:
            missing = [c for c in partition_cols if c not in data.columns]
            if missing:
                raise StageError(f"파티션 컬럼이 없습니다: {missing}")
            target = out_dir / "partitioned"
            data.to_parquet(target, index=False, partition_cols=partition_cols,
                            compression="zstd")
            files = list(target.rglob("*.parquet"))
            logger.info("[%s] 파티션 저장 — %d 파일", self.name, len(files))
        else:
            target = out_dir / f"{context.date_str}.parquet"
            data.to_parquet(target, index=False, compression="zstd")

        # 2) 요약
        group = self.params.get("summary_group", "station")
        value = self.params.get("summary_value", "pm10")

        if group in data.columns and value in data.columns:
            summary = (data.groupby(group, observed=True)[value]
                       .agg(["count", "mean", "median", "std", "min", "max"])
                       .round(2)
                       .sort_values("mean", ascending=False)
                       .reset_index())
            summary_path = out_dir / f"summary_{context.date_str}.csv"
            summary.to_csv(summary_path, index=False, encoding="utf-8-sig")
            context.set("summary", summary)
            logger.info("[%s] 요약 저장 — %s (%d행)",
                        self.name, summary_path.name, len(summary))

        # 3) CSV (사람이 볼 것)
        if self.params.get("also_csv", False):
            csv_path = out_dir / f"{context.date_str}.csv"
            data.to_csv(csv_path, index=False, encoding="utf-8-sig")
            logger.info("[%s] CSV 저장 — %s (%.1f MB)",
                        self.name, csv_path.name,
                        csv_path.stat().st_size / 1024**2)

        return data
```

```python
"""파이프라인 실행."""

from __future__ import annotations

import logging
from datetime import date, datetime

import pandas as pd

from dpipe.config import PipelineConfig
from dpipe.context import Context
from dpipe.stages import StageError, create_stage
from dpipe.state import RunState, StageState

logger = logging.getLogger(__name__)


def run_pipeline(
    config: PipelineConfig,
    run_date: date | None = None,
    force: bool = False,
    force_stages: list[str] | None = None,
    only: list[str] | None = None,
    resume: bool = False,
) -> RunState:
    """파이프라인을 실행합니다."""
    context = Context.create(config, run_date, force)
    state = RunState(run_id=context.run_id,
                     run_date=context.date_str,
                     config_hash=config.hash())

    stages = config.enabled_stages
    if only:
        stages = [s for s in stages if s.name in only]
        missing = set(only) - {s.name for s in stages}
        if missing:
            logger.warning("설정에 없거나 비활성화된 단계: %s", sorted(missing))

    if not stages:
        logger.warning("실행할 단계가 없습니다")
        state.finished_at = datetime.now().isoformat(timespec="seconds")
        return state

    # 재시작 — 이전에 성공한 단계는 건너뜁니다
    skip_until: set[str] = set()
    if resume:
        previous = RunState.load_latest(config.state_dir)
        if previous is None:
            logger.info("이전 실행 기록이 없습니다 — 처음부터 실행합니다")
        elif previous.config_hash != config.hash():
            logger.warning("설정이 변경되었습니다 — 처음부터 실행합니다")
        else:
            skip_until = {n for n, s in previous.stages.items() if s.ok}
            if skip_until:
                logger.info("재시작: 이전에 성공한 단계 %s 는 캐시를 사용합니다",
                            sorted(skip_until))

    logger.info("파이프라인 '%s' 시작 — run_id=%s, 날짜=%s, 단계 %d개",
                config.name, context.run_id, context.date_str, len(stages))

    data: pd.DataFrame | None = None

    for stage_config in stages:
        stage = create_stage(stage_config)

        stage_force = force
        if force_stages and stage.name in force_stages:
            stage_force = True
        if resume and stage.name in skip_until:
            stage_force = False

        stage_context = Context(
            config=context.config, run_id=context.run_id,
            run_date=context.run_date, force=stage_force,
            artifacts=context.artifacts,
        )

        try:
            data, stage_state = stage.run(stage_context, data)
        except StageError as e:
            stage_state = StageState(
                name=stage.name, status="failed", error=str(e),
                finished_at=datetime.now().isoformat(timespec="seconds"))
            state.record(stage_state)
            state.finished_at = datetime.now().isoformat(timespec="seconds")
            state.save(config.state_dir)
            logger.error("파이프라인 중단 — [%s] 에서 실패", stage.name)
            return state

        state.record(stage_state)
        state.save(config.state_dir)          # 단계마다 저장 (중간에 죽어도 남음)

    state.finished_at = datetime.now().isoformat(timespec="seconds")
    state.save(config.state_dir)

    total = sum(s.seconds for s in state.stages.values())
    logger.info("파이프라인 완료 — %d단계, %.1f초", len(state.stages), total)
    return state


def print_report(state: RunState) -> None:
    print("\n" + "=" * 78)
    print(f"파이프라인 실행 리포트  (run_id={state.run_id}, 날짜={state.run_date})")
    print("=" * 78)
    print(f"  시작: {state.started_at}")
    print(f"  종료: {state.finished_at}")
    print()
    print(f"  {'단계':<14}{'상태':<10}{'입력':>9}{'출력':>9}{'변화':>9}{'시간(초)':>10}")
    print("  " + "-" * 62)

    marks = {"success": "✓", "skipped": "⊝", "failed": "✗",
             "running": "…", "pending": "·"}

    for name, s in state.stages.items():
        mark = marks.get(s.status, "?")
        change = ""
        if s.rows_in and s.rows_out:
            change = f"{(s.rows_out - s.rows_in) / s.rows_in:+.1%}"
        print(f"  {name:<14}{mark} {s.status:<8}{s.rows_in:>9,}{s.rows_out:>9,}"
              f"{change:>9}{s.seconds:>10.2f}")
        if s.error:
            print(f"    └ {s.error}")

    print("  " + "-" * 62)
    total = sum(s.seconds for s in state.stages.values())
    print(f"  {'합계':<14}{'':<10}{'':>9}{'':>9}{'':>9}{total:>10.2f}")

    if state.success:
        print("\n  ✓ 전체 성공")
    else:
        print(f"\n  ✗ 실패한 단계: {', '.join(state.failed_stages)}")
        print(f"    → pipeline run --resume 으로 실패 지점부터 재실행하세요")
```

```python
"""명령행 인터페이스."""

from __future__ import annotations

import argparse
import json
import logging
import sys
from datetime import date, datetime
from pathlib import Path

from dotenv import load_dotenv

from dpipe import __version__

from dpipe.runner import print_report, run_pipeline
from dpipe.state import RunState

logger = logging.getLogger(__name__)


def setup_logging(level: str) -> None:
    logging.basicConfig(
        level=level,
        format="%(asctime)s [%(levelname)-8s] %(name)-20s %(message)s",
        datefmt="%H:%M:%S",
        stream=sys.stderr,
        force=True,
    )


def parse_date(value: str) -> date:
    try:
        return datetime.strptime(value, "%Y-%m-%d").date()
    except ValueError:
        raise argparse.ArgumentTypeError(f"날짜 형식은 YYYY-MM-DD 입니다: {value}")


def cmd_run(args) -> int:
    config = load_config(args.config)
    setup_logging(args.log_level or config.log_level)

    state = run_pipeline(
        config,
        run_date=args.date,
        force=args.force,
        force_stages=args.force_stage,
        only=args.only,
        resume=args.resume,
    )

    if args.json:
        print(json.dumps(state.to_dict(), ensure_ascii=False, indent=2))
    else:
        print_report(state)

    return 0 if state.success else 1


def cmd_validate(args) -> int:
    setup_logging(args.log_level or "INFO")
    config = load_config(args.config, strict_env=False)

    print(f"✓ 설정이 유효합니다: {args.config}\n")
    print(f"  이름       : {config.name}")
    print(f"  데이터 폴더 : {config.data_dir}")
    print(f"  상태 폴더  : {config.state_dir}")
    print(f"  설정 해시  : {config.hash()}")
    print(f"\n  단계 {len(config.stages)}개 (활성 {len(config.enabled_stages)}개)")
    print(f"  {'순서':<6}{'이름':<14}{'타입':<14}{'활성':<6}{'파라미터'}")
    print("  " + "-" * 62)
    for i, s in enumerate(config.stages, start=1):
        mark = "✓" if s.enabled else "-"
        keys = ", ".join(list(s.params)[:3]) or "(없음)"
        print(f"  {i:<6}{s.name:<14}{s.type:<14}{mark:<6}{keys}")
    return 0


def cmd_status(args) -> int:
    setup_logging(args.log_level or "WARNING")
    config = load_config(args.config, strict_env=False)

    state = RunState.load_latest(config.state_dir)
    if state is None:
        print("실행 기록이 없습니다.")
        return 0

    if args.json:
        print(json.dumps(state.to_dict(), ensure_ascii=False, indent=2))
    else:
        print_report(state)
    return 0 if state.success else 1


def cmd_history(args) -> int:
    setup_logging(args.log_level or "WARNING")
    config = load_config(args.config, strict_env=False)

    files = sorted(Path(config.state_dir).glob("run_*.json"), reverse=True)
    if not files:
        print("실행 기록이 없습니다.")
        return 0

    print(f"{'run_id':<18}{'날짜':<12}{'결과':<8}{'단계':<8}{'시간(초)':>10}")
    print("-" * 58)
    for path in files[:args.limit]:
        try:
            d = json.loads(path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError):
            continue
        stages = d.get("stages", {})
        total = sum(s.get("seconds", 0) for s in stages.values())
        result = "✓ 성공" if d.get("success") else "✗ 실패"
        print(f"{d.get('run_id', '?'):<18}{d.get('run_date', '?'):<12}"
              f"{result:<8}{len(stages):<8}{total:>10.1f}")
    return 0


def cmd_clean(args) -> int:
    setup_logging(args.log_level or "INFO")
    config = load_config(args.config, strict_env=False)

    import shutil

    targets = []
    if args.data:
        targets.append(config.data_dir)
    if args.state:
        targets.append(config.state_dir)
    if not targets:
        targets = [config.data_dir, config.state_dir]

    for path in targets:
        if not path.exists():
            continue
        if not args.yes:
            answer = input(f"{path} 를 삭제할까요? (y/N): ").strip().lower()
            if answer != "y":
                print("  건너뜁니다.")
                continue
        shutil.rmtree(path)
        print(f"  삭제: {path}")
    return 0


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="pipeline", description="설정 기반 데이터 파이프라인")
    parser.add_argument("--version", action="version", version=f"dpipe {__version__}")
    parser.add_argument("-c", "--config", type=Path,
                        default=Path("configs/config.yaml"))
    parser.add_argument("-l", "--log-level",
                        choices=["DEBUG", "INFO", "WARNING", "ERROR"])

    sub = parser.add_subparsers(dest="command")

    p_run = sub.add_parser("run", help="파이프라인 실행")
    p_run.add_argument("-d", "--date", type=parse_date,
                       help="실행 기준 날짜 (YYYY-MM-DD, 기본: 오늘)")
    p_run.add_argument("-f", "--force", action="store_true",
                       help="캐시를 무시하고 전부 다시 실행")
    p_run.add_argument("--force-stage", nargs="+", metavar="NAME",
                       help="지정한 단계만 강제 재실행")
    p_run.add_argument("--only", nargs="+", metavar="NAME",
                       help="지정한 단계만 실행")
    p_run.add_argument("--resume", action="store_true",
                       help="이전에 실패한 단계부터 재실행")
    p_run.add_argument("--json", action="store_true", help="결과를 JSON 으로")
    p_run.set_defaults(func=cmd_run)

    p_val = sub.add_parser("validate", help="설정 검증")
    p_val.set_defaults(func=cmd_validate)

    p_st = sub.add_parser("status", help="최근 실행 상태")
    p_st.add_argument("--json", action="store_true")
    p_st.set_defaults(func=cmd_status)

    p_hist = sub.add_parser("history", help="실행 이력")
    p_hist.add_argument("-n", "--limit", type=int, default=10)
    p_hist.set_defaults(func=cmd_history)

    p_clean = sub.add_parser("clean", help="생성물 삭제")
    p_clean.add_argument("--data", action="store_true", help="데이터만")
    p_clean.add_argument("--state", action="store_true", help="상태만")
    p_clean.add_argument("-y", "--yes", action="store_true", help="확인 없이")
    p_clean.set_defaults(func=cmd_clean)

    return parser


def main(argv: list[str] | None = None) -> int:
    load_dotenv()
    parser = build_parser()
    args = parser.parse_args(argv)

    if args.command is None:
        parser.print_help()
        return 2

    try:
        return args.func(args)
    except ConfigError as e:
        print(f"✗ 설정 오류: {e}", file=sys.stderr)
        return 2
    except KeyboardInterrupt:
        print("\n중단되었습니다.", file=sys.stderr)
        return 130
    except Exception:
        logger.exception("예상치 못한 오류")
        print("✗ 예상치 못한 오류입니다. -l DEBUG 로 확인하세요.", file=sys.stderr)
        return 1


if __name__ == "__main__":
    sys.exit(main())
```

**멱등성 = 같은 입력으로 몇 번 실행해도 결과가 같다**

```python
# 2) DB INSERT
cursor.execute("INSERT INTO t VALUES (...)")
# 실행할 때마다 행이 늘어남      ❌

# 3) 카운터 증가
state["total"] += len(df)      ❌

# 4) 폴더에 타임스탬프로 저장
df.to_parquet(f"out/{datetime.now()}.parquet")
# 실행할 때마다 새 파일        ❌
```

**왜 중요한가 — 실패는 반드시 일어납니다**

```
새벽 3시 파이프라인 실행
  → 수집 완료 (100만 행 저장)
  → 정제 중 메모리 부족으로 프로세스 종료
  → 아침에 발견하고 재실행
  → 멱등하지 않으면 200만 행이 됨
```

**재시도는 자동화의 기본입니다.**
- cron이 실패하면 다시 돕니다
- Airflow는 자동 재시도합니다
- 네트워크 오류로 중간에 끊깁니다
- 배포 중 프로세스가 재시작됩니다

**멱등하지 않으면 재시도가 데이터를 망칩니다.**

**고치는 방법**

**① 덮어쓰기**

```python
df.to_parquet(path)                    # ✅ 항상 같은 결과
df.to_csv(path, mode="w")              # ✅
```

**② 키 기준 upsert**

```python
if path.exists():
    existing = pd.read_parquet(path)
    combined = pd.concat([existing, df])
    combined = combined.drop_duplicates(subset=KEYS, keep="last")
else:
    combined = df
combined.to_parquet(path)
```

**③ DB에서는 `ON CONFLICT`** (W09 [Day 042](../02-sql-pipeline/day-042.md))

```sql
INSERT INTO measurements (date, station, pm10)
VALUES (%s, %s, %s)
ON CONFLICT (date, station)
DO UPDATE SET pm10 = EXCLUDED.pm10;
```

**④ 날짜·파티션 단위로 통째로 교체**

```python
# 그날 데이터를 지우고 다시 넣기
target = out_dir / f"{date_str}.parquet"
df.to_parquet(target)          # 덮어쓰기 = 그날 데이터 교체
```

**⑤ 상태를 누적하지 않고 매번 계산**

```python
# ❌
state["total"] += len(df)

# ✅
state["total"] = len(df)                  # 이번 실행의 값
# 또는 결과 파일에서 다시 계산
```

**이 파이프라인에서 멱등성을 지킨 방법**

```python
def output_path(self, context):
    return context.data_dir / self.name / f"{context.date_str}.parquet"

def save(self, context, df):
    df.to_parquet(self.output_path(context), index=False)      # 덮어쓰기
```

**날짜별로 파일이 나뉘고, 같은 날짜는 항상 덮어씁니다.**

**검증 방법**

```python
def test_멱등성():
    run_pipeline(config, run_date=date(2026, 8, 12))
    first = pd.read_parquet(output_path)

    run_pipeline(config, run_date=date(2026, 8, 12), force=True)
    second = pd.read_parquet(output_path)

    assert len(first) == len(second)
    assert first["pm10"].sum() == second["pm10"].sum()
```

**멱등하지 않아도 되는 경우**

- 로그 이어쓰기 (append가 목적)
- 실행 이력 저장 (매번 새 기록이 맞음)
- 감사 추적(audit trail)

**"데이터"는 멱등하게, "이력"은 누적**이 원칙입니다.

**W09 [Day 045](../02-sql-pipeline/day-045.md)의 주차 체크포인트**가
"같은 파이프라인을 두 번 돌려도 데이터가 중복되지 않는가"입니다.
</details>

**3.** 파이프라인 CLI가 종료 코드와 로그를 제대로 다뤄야 하는 이유는 무엇인가요?

<details>
<summary>답 보기</summary>

**파이프라인은 사람이 안 보는 시간에 자동으로 돕니다.**

```bash
# cron — 매일 새벽 3시
0 3 * * * cd /app && venv/bin/pipeline run >> /var/log/pipeline.log 2>&1
```

**아무도 화면을 보고 있지 않습니다.**
"성공했는가"와 "왜 실패했는가"를 알 방법은 **종료 코드와 로그뿐**입니다.

**① 종료 코드 — 자동화가 성공/실패를 판단하는 유일한 수단**

```bash
$ pipeline run
$ echo $?
0        # 성공
1        # 실패
```

**종료 코드를 잘못 다루면**

| 상황 | 결과 |
|---|---|
| 실패했는데 0 반환 | cron이 성공으로 판단 → **알림 없음** |
| CI에서 0 반환 | 깨진 데이터로 **다음 단계가 진행** |
| 조건부 실행 `A && B` | A가 실패했는데 B가 실행 |
| 모니터링 | 실패율이 0%로 보고됨 |

**실제 사고 시나리오**

```bash
0 3 * * * pipeline run && deploy_model.sh
```

파이프라인이 실패했는데 0을 반환하면 **깨진 데이터로 모델을 배포**합니다.

**올바른 구현**

```python
def main(argv=None) -> int:
    state = run_pipeline(config)
    print_report(state)
    return 0 if state.success else 1

if __name__ == "__main__":
    sys.exit(main())          # 반환값을 종료 코드로
```

**관례**

| 코드 | 의미 |
|---|---|
| 0 | 성공 |
| 1 | 일반적 실패 |
| 2 | 설정·사용법 오류 |
| 130 | Ctrl+C |

**② 로그 — 사후에 원인을 찾는 유일한 단서**

새벽 3시에 실패했습니다. 아침에 알 수 있는 것은 로그뿐입니다.

**최소한 기록해야 할 것**

```python
logger.info("파이프라인 시작 — run_id=%s, 날짜=%s", run_id, date_str)
logger.info("[%s] 시작", stage.name)
logger.info("[%s] 완료 — %d행 → %d행, %.1f초", name, rows_in, rows_out, seconds)
logger.error("[%s] 실패: %s", name, error)
logger.exception("[%s] 실패", name)          # Traceback 포함
```

| 항목 | 왜 필요한가 |
|---|---|
| **시각** | 언제 시작·종료했나, 얼마나 걸렸나 |
| **run_id** | 여러 실행 중 어느 것인가 |
| **단계 이름** | 어디서 실패했나 |
| **입출력 행 수** | 데이터가 예상대로 흘렀나 |
| **에러 + Traceback** | 무엇을 고쳐야 하나 |

**③ 표준 출력 vs 표준 에러**

```python
print(json.dumps(result))                   # stdout — 결과
logger.info("...")                          # stderr — 로그
print(f"✗ {error}", file=sys.stderr)        # stderr — 에러
```

**분리해야 파이프가 동작합니다.**

```bash
pipeline run --json | jq '.total_rows'      # 로그가 섞이면 파싱 실패
pipeline run 2>> error.log                  # 에러만 따로
```

**④ 실행 이력 — 추세를 보기 위해**

```bash
$ pipeline history
run_id            날짜          결과      단계        시간(초)
20260812_154620   20260812    ✓ 성공     4              0.3
20260811_030012   20260811    ✓ 성공     4              0.3
20260810_030008   20260810    ✗ 실패     2              0.1
```

**한 번의 실패보다 패턴이 중요합니다.**
- 매주 월요일마다 실패한다 → 주말 데이터 문제
- 시간이 점점 늘어난다 → 데이터가 커지고 있다
- 행 수가 갑자기 줄었다 → 소스 문제

**⑤ 알림 (W27 예고)**

```python
if not state.success:
    send_webhook(f"파이프라인 실패: {state.failed_stages}")
```

**종료 코드와 로그가 있어야 알림도 만들 수 있습니다.**

**체크리스트**

- [ ] 실패 시 0이 아닌 종료 코드
- [ ] `sys.exit(main())` 으로 반환값 전달
- [ ] `logging` 사용 (print 아님)
- [ ] 로그에 시각·단계·행 수·소요 시간
- [ ] 실패 시 `logger.exception()` 으로 Traceback
- [ ] 결과는 stdout, 로그는 stderr
- [ ] 실행 이력을 파일로 저장

## 오늘의 정리

| 항목 | 내용 |
|---|---|
| 설계 원칙 | 단계 분리 · 중간 결과 저장 · **멱등성** · 관측 가능 |
| Stage | 추상 클래스 — `execute()` 만 구현, 캐싱·타이밍은 부모가 |
| Context | 단계 간 정보 전달 · 순환 참조 방지 |
| State | 실행 상태 저장 — 재시작의 기반 |
| 캐싱 | 출력이 있으면 건너뜀 · **설정 해시로 무효화** |
| 재시작 | `--resume` — 이전 성공 단계는 캐시 |
| 강제 실행 | `--force` 전체 · `--force-stage NAME` 일부 |
| 멱등성 | 덮어쓰기 · 키 기준 dedup · 날짜별 파일 |
| 검증 | 최소 행 수 · 필수 컬럼 · **손실률 상한** |
| 종료 코드 | **0 성공 / 1 실패 / 2 설정 오류** |
| 로그 | 시각·단계·행 수·소요 시간 · 실패 시 Traceback |
| 이력 | `run_*.json` 누적 · `latest.json` 최신 |
| 날짜 인자 | `--date` — 과거 데이터 재처리(backfill) |
