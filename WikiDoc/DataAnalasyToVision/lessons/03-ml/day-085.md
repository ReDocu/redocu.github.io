
### 모델 만드는 세 가지 방법

| 방법 | 언제 |
|---|---|
| **Sequential** | 층을 **일렬로** 쌓을 때. 대부분의 경우 |
| **Functional API** | 갈라지거나 합쳐지는 구조 ([Day 089](day-089.md)) |
| Subclassing | 완전히 자유로운 구조 |

```python
# Sequential — 오늘 쓸 방법
model = keras.Sequential([
    layers.Input(shape=(784,)),
    layers.Dense(128, activation="relu"),
    layers.Dense(10, activation="softmax"),
])
```

**또는 `add()` 로 하나씩**

```python
model = keras.Sequential()
model.add(layers.Input(shape=(784,)))
model.add(layers.Dense(128, activation="relu"))
model.add(layers.Dense(10, activation="softmax"))
```

### 주요 층

| 층 | 하는 일 | 파라미터 |
|---|---|---|
| `Input(shape=)` | 입력 형태 선언 | 0 |
| **`Dense(n, activation=)`** | 완전연결층 ([Day 083](day-083.md)) | `(입력×n) + n` |
| **`Flatten()`** | 다차원 → 1차원 | **0** |
| `Dropout(rate)` | 무작위로 뉴런 끄기 ([Day 096](day-096.md)) | 0 |
| `BatchNormalization()` | 정규화 ([Day 096](day-096.md)) | 4×채널 |
| `Rescaling(1/255)` | 픽셀 정규화 ([Day 093](day-093.md)) | 0 |

**`Flatten` 이 중요합니다.**

```
(28, 28)  →  Flatten  →  (784,)
이미지          펼치기      1차원 벡터
```

**Dense 층은 1차원 입력만 받습니다.** 그래서 이미지를 펼쳐야 합니다.
**이것이 [Day 086](day-086.md)에서 다룰 문제의 시작점입니다.**

### compile — 학습 방법 설정

```python
model.compile(
    optimizer="adam",                            # Day 084
    loss="sparse_categorical_crossentropy",      # Day 083
    metrics=["accuracy"],                        # Day 080
)
```

| 인자 | 의미 | 배운 날 |
|---|---|---|
| `optimizer` | 가중치를 어떻게 갱신할지 | [Day 084](day-084.md) |
| `loss` | 무엇을 최소화할지 | [Day 083](day-083.md) |
| `metrics` | 사람이 볼 지표 (학습엔 안 씀) | [Day 080](day-080.md) |

**옵티마이저 세부 설정**

```python
from tensorflow.keras.optimizers import Adam

model.compile(optimizer=Adam(learning_rate=0.0005), ...)
```

> **`metrics` 와 `loss` 의 차이** — `loss` 는 모델이 최소화하는 대상(미분 가능해야 함),
> `metrics` 는 사람이 보는 숫자입니다. 정확도는 미분이 안 되므로 `loss` 로 쓸 수 없습니다.

### fit — 학습

```python
history = model.fit(
    X_train, y_train,
    epochs=20,
    batch_size=32,
    validation_split=0.2,
    verbose=1,
)
```

| 인자 | 의미 | 기본값 |
|---|---|---|
| `epochs` | 전체 데이터를 몇 번 볼지 | 1 |
| `batch_size` | 한 번에 처리할 샘플 수 | **32** |
| `validation_split` | 학습셋에서 검증용으로 뗄 비율 | 0 |
| `validation_data` | 검증셋을 직접 지정 | None |
| `shuffle` | 에폭마다 섞기 | **True** |
| `verbose` | 0=조용, 1=진행바, 2=에폭당 한 줄 | 1 |
| `callbacks` | 학습 중 개입 ([Day 097](day-097.md)) | None |

> ⚠️ **`validation_split` 은 데이터를 섞지 않고 뒤에서 자릅니다.**
> 데이터가 라벨 순으로 정렬되어 있으면 검증셋에 한 클래스만 들어갑니다.
> **미리 섞어 두거나 `validation_data` 로 직접 지정**하세요.

### history — 학습 기록

```python
history.history        # dict
# {'loss': [...], 'accuracy': [...], 'val_loss': [...], 'val_accuracy': [...]}
```

**이것으로 학습 곡선을 그립니다.** [Day 079](day-079.md)에서 배운 과적합 진단을 그대로 적용합니다.

### evaluate와 predict

```python
loss, acc = model.evaluate(X_test, y_test)      # 손실과 지표
proba = model.predict(X_test)                    # 확률 (softmax 출력)
pred = proba.argmax(axis=1)                      # 예측 클래스
```

| | 반환 |
|---|---|
| `evaluate` | `[loss, metric1, metric2, ...]` |
| `predict` | **확률 배열** (클래스가 아님) |

> **`predict` 는 클래스가 아니라 확률을 반환합니다.**
> scikit-learn의 `predict` 와 다릅니다. `argmax` 를 붙여야 클래스가 나옵니다.

### Step 1. 첫 Keras 모델 — 어제 만든 것과 대조

[Day 084](day-084.md) Step 4에서 직접 만든 신경망을 Keras로 다시 만듭니다.

```python
import numpy as np
import tensorflow as tf
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)
np.random.seed(42)

# ── 데이터 (Day 084와 동일) ──
X, y = make_moons(n_samples=1000, noise=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)
sc = StandardScaler().fit(X_train)
Xtr, Xte = sc.transform(X_train), sc.transform(X_test)

# ── 모델: 2 → 16 → 1 (Day 084와 같은 구조) ──
model = keras.Sequential([
    layers.Input(shape=(2,)),
    layers.Dense(16, activation="relu"),
    layers.Dense(1, activation="sigmoid"),
])

model.compile(
    optimizer=keras.optimizers.SGD(learning_rate=0.5),
    loss="binary_crossentropy",
    metrics=["accuracy"],
)

print("=" * 66)
model.summary()

print("\n파라미터 손계산")
print("  층1: 2×16 + 16 = 32 + 16 = 48")
print("  층2: 16×1 + 1  = 16 + 1  = 17")
print("  합계: 65")
print(f"  model.count_params() = {model.count_params()}")

# ── 학습 ──
print("\n" + "=" * 66)
print("학습 (Day 084에서 직접 구현한 것과 같은 설정)")
print("=" * 66)

history = model.fit(
    Xtr, y_train,
    epochs=300,
    batch_size=len(Xtr),        # 전체 배치 = Day 084와 동일
    validation_data=(Xte, y_test),
    verbose=0,
)

for ep in [0, 49, 99, 199, 299]:
    h = history.history
    print(f"  epoch {ep + 1:>4}: loss {h['loss'][ep]:.4f}  "
          f"acc {h['accuracy'][ep]:.4f}  val_loss {h['val_loss'][ep]:.4f}")

loss, acc = model.evaluate(Xte, y_test, verbose=0)
print(f"\n최종 테스트 손실   : {loss:.4f}")
print(f"최종 테스트 정확도 : {acc:.4f}")
print()
print("[Day 084 직접 구현 결과]")
print("  최종 테스트 정확도 : 0.9533")
print("→ 거의 같습니다. 초기 가중치가 다를 뿐 하는 일이 동일합니다.")
print("=" * 66)
```

### Step 2. MNIST 데이터 살펴보기

### Step 5. 구조 실험 — 층 수와 노드 수 바꿔 보기

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_train_full, y_train_full), (X_test, y_test) = keras.datasets.mnist.load_data()
X_train_full = X_train_full.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
X_val, y_val = X_train_full[:6000], y_train_full[:6000]
X_train, y_train = X_train_full[6000:], y_train_full[6000:]


def build_and_train(hidden, name, epochs=15, lr=0.001, seed=42):
    tf.random.set_seed(seed)
    model = keras.Sequential(
        [layers.Input(shape=(28, 28)), layers.Flatten()]
        + [layers.Dense(n, activation="relu") for n in hidden]
        + [layers.Dense(10, activation="softmax")],
        name=name,
    )
    model.compile(optimizer=keras.optimizers.Adam(learning_rate=lr),
                  loss="sparse_categorical_crossentropy",
                  metrics=["accuracy"])
    hist = model.fit(X_train, y_train, epochs=epochs, batch_size=128,
                     validation_data=(X_val, y_val), verbose=0)
    return model, hist


구조들 = [
    ([], "선형 (은닉층 없음)"),
    ([32], "32"),
    ([128], "128"),
    ([512], "512"),
    ([128, 64], "128-64"),
    ([256, 128, 64], "256-128-64"),
    ([512, 256, 128, 64], "512-256-128-64"),
]

rows, histories = [], {}

for hidden, label in 구조들:
    model, hist = build_and_train(hidden, label.replace(" ", "_").replace("(", "").replace(")", ""))
    test_loss, test_acc = model.evaluate(X_test, y_test, verbose=0)
    h = hist.history
    best_ep = int(np.argmin(h["val_loss"])) + 1

    rows.append({
        "구조": label,
        "층수": len(hidden),
        "파라미터": model.count_params(),
        "train_acc": round(h["accuracy"][-1], 4),
        "val_acc": round(h["val_accuracy"][-1], 4),
        "test_acc": round(test_acc, 4),
        "격차": round(h["accuracy"][-1] - test_acc, 4),
        "최적에폭": best_ep,
    })
    histories[label] = h

df = pd.DataFrame(rows)

print("  층을 깊게 해도 Dense만으로는 98% 부근이 한계")
print("\n  ★ 왜 한계인가? → Day 086에서 답합니다.")

fig, axes = plt.subplots(1, 3, figsize=(18, 5))

ax = axes[0]
for label in ["선형 (은닉층 없음)", "128", "128-64", "512-256-128-64"]:
    ax.plot(histories[label]["val_accuracy"], label=label, linewidth=2)
ax.set_xlabel("epoch")
ax.set_ylabel("validation accuracy")
ax.set_ylim(0.88, 0.99)
ax.set_title("Depth vs accuracy")
ax.legend(fontsize=9)
```

```python
def run(name, layers_spec, lr=0.001, batch=128, epochs=20, seed=42, **kw):
    tf.random.set_seed(seed)

        [layers.Input(shape=(28, 28)), layers.Flatten()] + layers_spec
        + [layers.Dense(10, activation="softmax")],
```

**결론 5가지**

**① 개선 폭: 0.9772 → 0.9851 (+0.79%p)**
틀린 개수로 보면 **228건 → 149건**, 35% 감소입니다.

**② Dropout이 가장 큰 기여를 했습니다.**

```
격차: 0.0178 → 0.0104 (Dropout 추가 시)
최적에폭: 6 → 14 (더 오래 학습해도 과적합 안 함)
```

**③ BatchNorm은 성능보다 "안정성"에 기여했습니다.**
val_loss 곡선이 훨씬 매끄러워지고, 학습률에 덜 민감해집니다.

**④ 학습률을 낮추니(0.001 → 0.0005) 격차가 더 줄었습니다.**
대신 에폭을 20 → 25로 늘려야 했습니다. **학습률과 에폭 수는 함께 조정합니다.**

**⑤ 확신도 기반 설계가 실무적 해답입니다.**

```
전부 자동 처리   : 정확도 98.51%,  오류 149건
91% 자동 + 9% 사람: 자동분 정확도 99.9%, 오류 9건
```

**사람이 9%만 보면 오류가 149건에서 9건으로 줄어듭니다.**
"모델 정확도를 99.9%까지 올리기"보다 훨씬 쉽고 현실적입니다.

> **그런데 Dense 모델의 한계는 명확합니다.**
> 파라미터를 24만 개 쓰고 온갖 기법을 동원해 98.5%입니다.
> **[Day 089](day-089.md)의 CNN은 파라미터 6만 개로 99.2%를 냅니다.**
> **구조를 바꾸는 것이 튜닝보다 강력합니다.**
</details>

## 오늘의 정리 · W17 총정리

| 개념 | 핵심 |
|---|---|
| `Sequential` | 층을 일렬로 쌓기 |
| `Flatten()` | 다차원 → 1차원. **파라미터 0** |
| `Dense(n, activation=)` | 완전연결층. `(입력×n) + n` |
| `compile` | optimizer([D084](day-084.md)) / loss([D083](day-083.md)) / metrics([D080](day-080.md)) |
| `fit` | epochs · **batch_size 32~128** · validation_data |
| `history.history` | 학습 곡선용 dict |
| `evaluate` | `[loss, metric]` 반환 |
| **`predict`** | **확률 반환.** `argmax` 필요 |
| `summary()` | **파라미터 수를 손계산으로 검증** |
| 이미지 정규화 | **`/255.0`** 필수 |
| `validation_split` | **섞지 않고 뒤에서 자름** — 주의 |
| 과적합 신호 | **`val_loss` 가 정확도보다 먼저 오름** |
| 모델 저장 | `.keras` · Colab은 **드라이브에** |
| 확신도 활용 | 확실한 것만 자동, 나머지는 사람 |
