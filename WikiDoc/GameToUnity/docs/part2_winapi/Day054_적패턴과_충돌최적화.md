### 3-1. 스크롤 배경과 패럴랙스

**왜 필요한가** — 속도감과 깊이감을 만든다. (Day 35의 별 깊이감과 같은 원리)

```
   레이어별 스크롤 속도

   원경 (별)     ────▶            속도 × 0.2
   중경 (구름)   ──────▶          속도 × 0.5
   근경 (지형)   ──────────▶      속도 × 1.0

   ★ 느리게 움직이면 멀리 있는 것처럼 보인다
```

**이미지 두 장 순환 방식**

```cpp
class ScrollLayer
{
public:
    void Init(const char* imageKey, double speed)
    {
        m_image = ImageManager::Get().Find(imageKey);
        m_speed = speed;
        m_offsetY = 0.0;
    }

    void Update(double dt)
    {
        m_offsetY += m_speed * dt;

        if (m_image && m_offsetY >= m_image->GetHeight())
            m_offsetY -= m_image->GetHeight();     // ★ 순환
    }

    void Render(Renderer& r) const
    {
        if (!m_image) return;

        int h = m_image->GetHeight();
        int y = (int)m_offsetY;

        m_image->Draw(r.GetDC(), 0, y);            // 아래쪽
        m_image->Draw(r.GetDC(), 0, y - h);        // 위쪽 (이어붙임)
    }

private:
    Image* m_image = nullptr;
    double m_speed = 0.0;
    double m_offsetY = 0.0;
};
```

### 3-3. 탄막 패턴

**왜 필요한가** — 적의 개성을 만든다.

```cpp
void FireSingle(double x, double y, double speed)
{
    g_bulletMgr->RequestFire(x, y, 0, speed, TAG_ENEMY_BULLET);
}

void FireSpread(double x, double y, int count, double spread, double speed)
{
    double base = 3.14159265 / 2;              // 아래 방향

    for (int i = 0; i < count; i++)
    {
        double t = (count > 1) ? (double)i / (count - 1) - 0.5 : 0.0;
        double angle = base + t * spread;

        g_bulletMgr->RequestFire(x, y,
                                 cos(angle) * speed,
                                 sin(angle) * speed,
                                 TAG_ENEMY_BULLET);
    }
}

void FireCircle(double x, double y, int count, double speed, double offset)
{
    for (int i = 0; i < count; i++)
    {
        double angle = offset + (2 * 3.14159265 * i) / count;

        g_bulletMgr->RequestFire(x, y,
                                 cos(angle) * speed,
                                 sin(angle) * speed,
                                 TAG_ENEMY_BULLET);
    }
}

void FireAimed(double x, double y, double targetX, double targetY, double speed)
{
    double dx = targetX - x;
    double dy = targetY - y;
    double len = sqrt(dx*dx + dy*dy);

    if (len < 0.001) return;

    g_bulletMgr->RequestFire(x, y, dx/len*speed, dy/len*speed, TAG_ENEMY_BULLET);
}
```

### 3-5. 충돌 최적화 ② — 공간 분할 (그리드)

**왜 필요한가** — 화면 반대편에 있는 것끼리는 검사할 필요가 없다.

```
   화면을 격자로 나눈다 (예: 8 × 6 = 48칸)

   ┌────┬────┬────┬────┬────┬────┬────┬────┐
   │    │    │ ▼  │    │    │    │    │    │
   ├────┼────┼────┼────┼────┼────┼────┼────┤
   │    │ ▲  │ ▲  │    │    │ ▼  │    │    │
   ├────┼────┼────┼────┼────┼────┼────┼────┤
   │    │    │    │ ▲  │    │    │    │    │
   └────┴────┴────┴────┴────┴────┴────┴────┘

   ★ 같은 칸(또는 인접 칸)에 있는 것끼리만 검사한다
```

```cpp
class SpatialGrid
{
public:
    static const int COLS = 8;
    static const int ROWS = 6;
    static const int MAX_PER_CELL = 64;

    void Init(int screenW, int screenH)
    {
        m_cellW = screenW / (double)COLS;
        m_cellH = screenH / (double)ROWS;
    }

    void Clear()
    {
        for (int i = 0; i < COLS * ROWS; i++)
            m_cellCount[i] = 0;
    }

    void Insert(GameObject* obj)
    {
        int cx, cy;
        if (!GetCell(obj->GetX(), obj->GetY(), &cx, &cy)) return;

        int idx = cy * COLS + cx;

        if (m_cellCount[idx] < MAX_PER_CELL)
            m_cells[idx][m_cellCount[idx]++] = obj;
    }

    // 주변 3×3 칸의 오브젝트를 out 에 채운다
    int Query(double x, double y, GameObject** out, int maxOut)
    {
        int cx, cy;
        if (!GetCell(x, y, &cx, &cy)) return 0;

        int count = 0;

        for (int dy = -1; dy <= 1; dy++)
        {
            for (int dx = -1; dx <= 1; dx++)
            {
                int nx = cx + dx, ny = cy + dy;
                if (nx < 0 || nx >= COLS || ny < 0 || ny >= ROWS) continue;

                int idx = ny * COLS + nx;

                for (int i = 0; i < m_cellCount[idx] && count < maxOut; i++)
                    out[count++] = m_cells[idx][i];
            }
        }
        return count;
    }

private:
    bool GetCell(double x, double y, int* cx, int* cy) const
    {
        *cx = (int)(x / m_cellW);
        *cy = (int)(y / m_cellH);

        return (*cx >= 0 && *cx < COLS && *cy >= 0 && *cy < ROWS);
    }

    GameObject* m_cells[COLS * ROWS][MAX_PER_CELL];
    int         m_cellCount[COLS * ROWS] = { 0 };
    double      m_cellW = 0, m_cellH = 0;
};
```

```
   ★ 왜 주변 3×3 인가?

   오브젝트가 칸 경계에 걸쳐 있을 수 있다

   ┌────┬────┐
   │  ▲─┼─▲  │      총알이 두 칸에 걸쳐 있다
   └────┴────┘      → 인접 칸도 검사해야 놓치지 않는다
```

### 3-6. 언제 최적화할 것인가

**왜 필요한가** — 무조건 최적화하면 코드만 복잡해진다.

```
   ★ 최적화 순서

   ① 측정한다              →  진짜 병목인가?
   ② 그룹별 검사           →  대부분 여기서 해결
   ③ 영역 필터링           →  화면 밖 제외, 거리 사전 검사
   ④ 공간 분할             →  오브젝트 500개 이상일 때
   ⑤ 더 복잡한 자료구조     →  쿼드트리 등 (여기까지 갈 일은 드물다)

| 오브젝트 수 | 권장 |
|:--:|---|
| ~100 | 그룹별로 충분 |
| 100~500 | 그룹별 + 영역 필터 |
| **500~2000** | **+ 공간 분할** |
| 2000+ | 쿼드트리, 정렬 기반 |

```
   ★ 조기 최적화는 해롭다

   "느릴 것 같아서" 최적화하지 말고
   "측정해서 느려서" 최적화한다

### 3-7. 간단한 사전 검사

**왜 필요한가** — 공간 분할 없이도 크게 줄일 수 있다.

```cpp
    // 거리 사전 검사 (제곱근 없이)
    double dx = a->GetX() - b->GetX();
    double dy = a->GetY() - b->GetY();
    double distSq = dx*dx + dy*dy;

    const double MAX_R = 60.0;                 // 두 오브젝트의 최대 반경 합

    if (distSq > MAX_R * MAX_R) continue;      // ★ AABB 계산 생략

    // 여기서만 정밀 검사
    if (IsOverlap(a->GetBounds(), b->GetBounds())) { /* 히트 */ }
```

```
   ★ sqrt 를 쓰지 않는다

   거리 비교는 제곱끼리 비교하면 된다
   sqrt(distSq) > R    ⟺    distSq > R*R

   sqrt 는 약 20~40 사이클, 곱셈은 3~5 사이클
```

**Y축 사전 검사 (종스크롤에 특히 효과적)**

```cpp
    // 세로 거리만 먼저 본다
    if (fabs(a->GetY() - b->GetY()) > 60.0) continue;
```

```
   종스크롤에서는 세로 분포가 넓다
   → Y만 먼저 걸러도 대부분 제외된다
```

void ShootScene::CheckGroup(int attackerTag, int targetTag)
{
    // 태그별로 미리 모아 둔다
    GameObject** attackers = m_taggedObjects[attackerTag];
    int attackerCount      = m_taggedCount[attackerTag];

    GameObject** targets   = m_taggedObjects[targetTag];
    int targetCount        = m_taggedCount[targetTag];

    for (int i = 0; i < attackerCount; i++)
    {
        if (!attackers[i]->IsActive()) continue;

        RectF a = attackers[i]->GetBounds();

        for (int j = 0; j < targetCount; j++)
        {
            if (!targets[j]->IsActive()) continue;

            g_checkCount++;

            if (IsOverlap(a, targets[j]->GetBounds()))
            {
                attackers[i]->OnCollide(targets[j]);
                targets[j]->OnCollide(attackers[i]);
                break;                         // 총알은 하나만 맞힌다
            }
        }
    }
}
```

void ShootScene::CheckWithGrid(int attackerTag, int targetTag)
{
    m_grid.Clear();

    for (int i = 0; i < m_taggedCount[targetTag]; i++)
        if (m_taggedObjects[targetTag][i]->IsActive())
            m_grid.Insert(m_taggedObjects[targetTag][i]);

    GameObject* nearby[128];

    for (int i = 0; i < m_taggedCount[attackerTag]; i++)
    {
        GameObject* atk = m_taggedObjects[attackerTag][i];
        if (!atk->IsActive()) continue;

        int n = m_grid.Query(atk->GetX(), atk->GetY(), nearby, 128);

        RectF a = atk->GetBounds();

        for (int j = 0; j < n; j++)
        {
            g_checkCount++;

            if (IsOverlap(a, nearby[j]->GetBounds()))
            {
                atk->OnCollide(nearby[j]);
                nearby[j]->OnCollide(atk);
                break;
            }
        }
    }
}
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 배경 이음새가 보임 | 타일링 불가 이미지 | 위아래가 이어지는 이미지 사용 |
| 배경이 떨림 | `offsetY`를 `int`로 | `double`로 유지 |
| 사인 이동이 화면 밖으로 | `amplitude` 과다 | 화면 폭 고려해 제한 |
| 편대가 겹침 | 오프셋 부족 | 간격 조정 |
| 조준탄이 안 맞음 | 정규화 누락 | `dx/len`, `dy/len` |
| 그리드에서 충돌 누락 | 3×3 검사 안 함 | 인접 칸 포함 |
| 그리드 칸 초과 | `MAX_PER_CELL` 부족 | 크기 증가 또는 칸 세분화 |
| 최적화해도 안 빨라짐 | 병목이 다른 곳 | 프로파일러로 재확인 |
| 같은 적을 여러 총알이 맞힘 | `break` 누락 | 총알은 하나만 맞히고 종료 |
