## ② 왜 필요한가

어제까지 배운 것으로는 **한 페이지 20건**이 한계입니다.

```
Day 052   1페이지 → 20건
Day 053   50페이지 → 1,000건
```

건수만 늘어나는 게 아닙니다. **문제의 종류가 바뀝니다.**

| | 1페이지 수집 | 50페이지 수집 |
|---|---|---|
| 소요 시간 | 1초 | **1분 이상** |
| 중간 실패 | 다시 실행하면 됨 | **앞의 성공분도 날아감** |
| 서버 부담 | 없음 | **차단당할 수 있음** |
| 실패 원인 | 화면에 보임 | **어디서 실패했는지 모름** |
| 중복 | 없음 | **같은 항목이 여러 번 들어옴** |

40페이지째에서 네트워크가 끊겼다고 해봅시다.

```
❌ 나쁜 설계 : 처음부터 다시 → 39페이지를 또 요청 (서버에도 민폐)
✅ 좋은 설계 : 40페이지부터 이어서 → 이미 받은 건 건드리지 않음
```

**오늘의 핵심은 "중간에 죽어도 괜찮은 수집기"를 만드는 것입니다.**
수집은 성공하는 코드보다 **실패를 견디는 코드**가 중요합니다.

## ③ 개념 설명

### 페이지네이션 4가지 유형

수집을 시작하기 전에 **2페이지로 이동해 URL이 어떻게 바뀌는지** 확인합니다.

| 유형 | 예시 | 다음 페이지 만들기 |
|---|---|---|
| **경로형** | `/catalogue/page-2.html` | 숫자만 바꿔서 문자열 생성 |
| **쿼리형** | `/list?page=2&sort=new` | `params={"page": 2}` |
| **offset형** | `/list?offset=40&limit=20` | `offset += limit` |
| **링크 추적형** | `<a class="next">` | HTML에서 다음 링크를 찾아 따라감 |

```python
# ① 경로형
url = f"http://books.toscrape.com/catalogue/page-{page}.html"

# ② 쿼리형
res = requests.get(BASE, params={"page": page, "sort": "new"})

# ③ offset형
res = requests.get(BASE, params={"offset": (page - 1) * 20, "limit": 20})

# ④ 링크 추적형  (Day 052 에서 사용)
next_link = soup.select_one("li.next a")
url = urljoin(current_url, next_link["href"]) if next_link else None
```

> **④ 링크 추적형이 가장 안전합니다.**
> 사이트가 정한 다음 페이지를 그대로 따라가므로, URL 규칙이 바뀌어도 동작합니다.
> 다만 **마지막 페이지 판정**을 사이트에 맡기게 되므로 `max_pages` 상한은 반드시 함께 둡니다.

**개발자도구에서 확인하는 법**

```
F12 → Network 탭 → 2페이지 클릭 → 맨 위 요청의 Request URL 확인
```

### 반복 루프의 종료 조건 — 4개를 모두 넣습니다

무한 루프는 **크롤링에서 가장 흔한 사고**입니다. 종료 조건은 하나로 부족합니다.

```python
while True:
    if page > MAX_PAGES:        # ① 상한 (안전장치, 필수)
        break

    items = parse(fetch(url))

    if not items:               # ② 결과 0건 → 마지막 페이지 지나침
        break

    if url in visited:          # ③ 이미 방문한 URL → 순환 감지
        break

    if all_duplicated(items):   # ④ 전부 이미 있는 항목 → 같은 페이지 반복
        break
```

| 조건 | 막아 주는 사고 |
|---|---|
| ① 상한 | 사이트가 무한히 페이지를 만들어 주는 경우 |
| ② 0건 | 마지막 페이지 이후에도 200 응답을 주는 사이트 |
| ③ 방문 URL | `next` 링크가 자기 자신을 가리키는 경우 |
| ④ 전부 중복 | 범위를 벗어나면 **1페이지를 되돌려 주는** 사이트 |

> ⚠️ **④가 실무에서 가장 자주 걸립니다.**
> `?page=999` 를 넣었을 때 "결과 없음"이 아니라 **1페이지를 그대로 돌려주는** 사이트가 많습니다.
> 종료 조건이 ①②뿐이면 상한까지 같은 20건을 계속 수집하게 됩니다.

### 지연 — 얼마나 쉬어야 하나

```python
time.sleep(1.0)                          # 고정 지연
time.sleep(random.uniform(0.8, 1.5))     # 랜덤 지연 (권장)
```

| 방식 | 특징 |
|---|---|
| 지연 없음 | ❌ **절대 금지.** 사실상 부하 공격입니다 |
| 고정 1초 | 무난한 기본값. 수업 실습은 이걸로 충분 |
| 랜덤 0.8~1.5초 | 요청 간격이 일정하지 않아 서버 쪽 부담이 고르게 퍼짐 |
| `Crawl-delay` 준수 | `robots.txt` 에 명시돼 있으면 **그 값이 최우선** |

```python
# robots.txt 에 Crawl-delay: 5 가 있으면
DELAY = 5.0        # 명시된 값을 따릅니다
```

> **1초가 길게 느껴진다면** 100페이지 = 100초입니다. 커피 한 잔 시간입니다.
> 지연을 없애서 아낀 100초 때문에 IP가 차단되면 **그 사이트는 영원히 못 씁니다.**

### 재시도와 지수 백오프

일시적 실패(타임아웃·연결 끊김·5xx)는 **잠깐 기다렸다 다시 요청**하면 대개 성공합니다.

```python
for attempt in range(retries + 1):
    try:
        res = requests.get(url, headers=HEADERS, timeout=10)
    except requests.RequestException:
        wait = BACKOFF_BASE * (2 ** attempt)      # 1 → 2 → 4 → 8초
        time.sleep(wait)
        continue
```

```
시도 1 실패 → 1초 대기
시도 2 실패 → 2초 대기
시도 3 실패 → 4초 대기
시도 4 실패 → 포기하고 기록
```

**재시도해도 되는 것과 안 되는 것**

| 상황 | 재시도 | 이유 |
|---|---|---|
| `Timeout` · `ConnectionError` | ✅ | 일시적 |
| `500` `502` `503` `504` | ✅ | 서버 일시 장애 |
| `404` | ❌ | 없는 페이지. 다시 해도 없음 |
| `401` `403` | ❌ | **접근이 거부됨. 즉시 중단** |
| `429` | ❌ | **너무 빠르다는 신호. 즉시 중단** |

> ⚠️ **`429` 를 재시도로 넘기려 하지 마세요.**
> `429 Too Many Requests` 는 "지금 속도가 과하다"는 서버의 명시적 경고입니다.
> 코드가 알아서 기다렸다 계속하는 게 아니라, **중단하고 사람이 지연 값을 늘린 뒤 다시 설계**하는 것이 맞습니다.
> ([Day 051](day-051.md) 수집 윤리 원칙과 동일합니다.)

### 중간 저장 — 오늘의 핵심

**나쁜 설계** — 전부 모은 뒤 마지막에 한 번 저장

```python
all_items = []
for page in range(1, 51):

df = pd.DataFrame(all_items)              # 여기까지 못 옴

```

**좋은 설계** — 페이지마다 저장하고, 이미 있으면 건너뜀

```
data/
├── raw/
│   ├── page_001.json      ← 페이지 단위로 즉시 저장
│   ├── page_002.json
│   └── ...
├── failures.csv           ← 실패한 페이지 기록
└── books.csv              ← 마지막에 합친 최종 결과
```

```python
path = RAW_DIR / f"page_{page:03d}.json"

if path.exists():          # 이미 수집한 페이지는 건너뜀
    continue

items = crawl_page(page)
path.write_text(json.dumps(items, ensure_ascii=False), encoding="utf-8")
```

| 효과 | 설명 |
|---|---|
| **재시작 가능** | 다시 실행하면 남은 페이지만 수집 |
| **서버 부담 감소** | 이미 받은 페이지를 다시 요청하지 않음 |
| **원본 보존** | 파싱 규칙이 틀렸을 때 **재수집 없이** 다시 파싱 가능 |
| **디버깅 용이** | 문제가 생긴 페이지의 원본을 직접 열어 볼 수 있음 |

> **원본 보존이 특히 중요합니다.**
> 1,000건을 수집하고 나서 "가격 파싱이 틀렸네"를 발견해도,
> 원본이 있으면 **재수집 없이 파싱만 다시** 하면 됩니다.
> 이것이 `raw` / `processed` 폴더를 나누는 이유입니다. ([Day 060](day-060.md)에서 다시 다룹니다)

### 목록 → 상세 2단계 수집

목록 페이지에 없는 정보는 **상세 페이지에 들어가야** 얻을 수 있습니다.

```
목록 페이지 1개  →  항목 20개  →  상세 페이지 20개
```

```python
# ① 목록에서 링크 수집
links = [urljoin(BASE, get_attr(item, "a", "href"))
         for item in soup.select("article.product_pod")]

# ② 각 링크에 들어가 추가 정보 수집
for link in links:
    detail = fetch(link)
    ...
```

> ⚠️ **요청 수가 21배가 됩니다.**
> 50페이지 목록 = 요청 50회지만, 상세까지 들어가면 **50 + 1,000 = 1,050회**입니다.
> 1초 지연이면 **17분**입니다.
>
> **대책 3가지**
> 1. 상세가 정말 필요한지 먼저 판단 — 목록에 있는 정보로 충분한 경우가 많습니다
> 2. 상위 N건만 상세 수집 (예: 평점 상위 100건)
> 3. 상세도 **개별 파일로 중간 저장** — 중단돼도 이어서 가능

### 중복 제거 — 키를 정해야 합니다

```python
df.drop_duplicates()                              # 모든 열이 같은 행
df.drop_duplicates(subset=["url"])                # url 기준
df.drop_duplicates(subset=["title", "author"])    # 조합 기준
df.drop_duplicates(subset=["url"], keep="last")   # 나중 것을 남김
```

| 키 후보 | 신뢰도 | 비고 |
|---|---|---|
| **상세 URL** | ★★★ | 가장 안전. 사이트가 부여한 고유 주소 |
| 상품코드·게시글 ID | ★★★ | 있으면 최우선 |
| 제목 | ★☆☆ | 동명이인·동일 제목이 흔함 |
| 제목 + 작성자 + 날짜 | ★★☆ | 조합하면 쓸 만함 |

```python
before = len(df)
df = df.drop_duplicates(subset=["url"]).reset_index(drop=True)
print(f"중복 제거: {before} → {len(df)} ({before - len(df)}건 제거)")
```

> **중복이 생기는 진짜 이유를 확인하세요.**
> 정상: 사이트가 인기 상품을 여러 페이지에 노출 → 제거하면 끝
> **비정상: 페이지네이션이 안 돌아 같은 페이지를 반복 수집** → 코드를 고쳐야 함
>
> 중복률이 5%를 넘으면 후자를 의심합니다.

### `pd.read_html` — 표를 통째로

HTML 안에 `<table>` 이 있다면 **파싱 없이 한 줄로** 가져올 수 있습니다.

```python
import pandas as pd

tables = pd.read_html(url)        # 페이지 안의 모든 <table> → DataFrame 리스트
print(len(tables))                # 표 개수
df = tables[0]                    # 첫 번째 표
```

**주요 인자**

| 인자 | 설명 |
|---|---|
| `match="키워드"` | 그 문자열이 포함된 표만 |
| `header=0` | 첫 행을 열 이름으로 |
| `index_col=0` | 첫 열을 인덱스로 |
| `encoding="utf-8"` | 인코딩 지정 |
| `thousands=","` | `1,234` 를 숫자로 |
| `flavor="bs4"` | 파서 지정 (`lxml` / `bs4` / `html5lib`) |

```python
tables = pd.read_html(url, match="가격", header=0, thousands=",")
```

**되는 것과 안 되는 것**

| 상황 | `read_html` |
|---|---|
| 진짜 `<table>` 태그 | ✅ 완벽 |
| `<div>` 로 만든 표 모양 레이아웃 | ❌ 안 됨 → BeautifulSoup |
| JavaScript 로 그리는 표 | ❌ 안 됨 → Selenium ([Day 054](day-054.md)) |
| 로그인 필요 페이지 | ❌ URL 직접 전달 시 안 됨 → `requests` 로 받아 넘김 |

**직접 받은 HTML 을 넘기는 법** — 헤더·지연을 적용하려면 이 방식을 씁니다.

```python
from io import StringIO

res = requests.get(url, headers=HEADERS, timeout=10)
res.encoding = res.apparent_encoding
tables = pd.read_html(StringIO(res.text))       # StringIO 로 감싸기
```

> ⚠️ **pandas 2.1 부터 문자열을 그대로 넘기면 경고가 납니다.**
> ```
> FutureWarning: Passing literal html to 'read_html' is deprecated
> ```
> `StringIO(html)` 로 감싸세요. 이후 버전에서는 **에러**가 됩니다.

## ④ 단계별 실습

실습 대상은 크롤링 연습용으로 공개된 **`books.toscrape.com`** 입니다.
**1,000권 · 50페이지 · 페이지당 20권** 구조라 반복 수집 연습에 적합합니다.

### Step 1. 페이지네이션 파악하기

```python
"""페이지네이션 구조를 확인합니다."""

import time

import requests
from bs4 import BeautifulSoup

BASE = "http://books.toscrape.com"
HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)"
    )
}
DELAY = 1.0

print("=" * 74)
print("                   페이지네이션 구조 파악")
print("=" * 74)

# ── ① URL 패턴 확인 ──
print("\n[① URL 패턴]")
for page in (1, 2, 50):
    url = f"{BASE}/catalogue/page-{page}.html"
    print(f"  {page:>2}페이지 : {url}")

print("\n  → 경로형(path) 페이지네이션. 숫자만 바꾸면 됩니다.")

# ── ② 페이지 정보 읽기 ──
time.sleep(DELAY)
res = requests.get(f"{BASE}/catalogue/page-1.html",
                   headers=HEADERS, timeout=10)
res.encoding = res.apparent_encoding          # ⚠ 인코딩 주의 (아래 설명)

soup = BeautifulSoup(res.text, "html.parser")

items = soup.select("article.product_pod")
pager = soup.select_one("li.current")
next_link = soup.select_one("li.next a")

print(f"\n[② 1페이지 정보]")
print(f"  상태 코드   : {res.status_code}")
print(f"  선언 인코딩 : {res.encoding}")
print(f"  항목 수     : {len(items)}개")
print(f"  페이저      : {pager.get_text(' ', strip=True) if pager else '(없음)'}")
print(f"  다음 링크   : {next_link.get('href') if next_link else '(없음)'}")

# ── ③ 마지막 페이지 이후는 어떻게 되나 ──
print(f"\n[③ 범위를 벗어난 페이지 — 종료 조건 확인]")
for page in (50, 51):
    time.sleep(DELAY)
    res2 = requests.get(f"{BASE}/catalogue/page-{page}.html",
```

```python
"""페이지를 순회하며 수집합니다. 중단돼도 이어서 실행할 수 있습니다."""

import json
import logging
import random
import time
from pathlib import Path
from urllib.parse import urljoin

import pandas as pd
import requests
from bs4 import BeautifulSoup

# ══════════ 설정 ══════════
BASE = "http://books.toscrape.com"
LIST_URL = BASE + "/catalogue/page-{page}.html"

HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)"
    )
}

DELAY_MIN, DELAY_MAX = 0.8, 1.5      # 랜덤 지연 범위(초)
TIMEOUT = 10
RETRIES = 2
BACKOFF_BASE = 1.0
MAX_PAGES = 10                        # 안전장치 (실습은 10페이지 = 200건)
STOP_CODES = {401, 403, 429}          # 만나면 즉시 중단

DATA_DIR = Path("data")
RAW_DIR = DATA_DIR / "raw"
RAW_DIR.mkdir(parents=True, exist_ok=True)

logging.basicConfig(level=logging.INFO,
                    format="%(asctime)s [%(levelname)s] %(message)s",
                    datefmt="%H:%M:%S")
log = logging.getLogger("crawler")


# ══════════ 안전한 추출 (Day 052) ══════════

def get_text(parent, selector=None, default=""):
    if parent is None:
        return default
    el = parent if selector is None else parent.select_one(selector)
    return el.get_text(" ", strip=True) if el else default


def get_attr(parent, selector, attr, default=""):
    if parent is None:
        return default
    el = parent.select_one(selector)
    if el is None:
        return default
    value = el.get(attr, default)
    return " ".join(value) if isinstance(value, list) else value


def to_float(text, default=0.0):
    import re
    match = re.search(r"-?\d+\.?\d*", str(text or "").replace(",", ""))
    return float(match.group()) if match else default


# ══════════ 요청 ══════════

class BlockedError(Exception):
    """수집이 거부되었을 때. 재시도하지 않고 즉시 중단합니다."""


def polite_sleep():
    time.sleep(random.uniform(DELAY_MIN, DELAY_MAX))


def fetch(url, session):
    """
    페이지를 가져옵니다.

    반환 : Response  또는 None(최종 실패)
    예외 : BlockedError — 401/403/429
    """
    for attempt in range(RETRIES + 1):
        polite_sleep()

        try:
            res = session.get(url, headers=HEADERS, timeout=TIMEOUT)
        except requests.RequestException as e:
            wait = BACKOFF_BASE * (2 ** attempt)
            log.warning(f"  {type(e).__name__} — {wait:.0f}초 후 재시도 "
                        f"({attempt + 1}/{RETRIES})")
            time.sleep(wait)
            continue

        if res.status_code in STOP_CODES:
            raise BlockedError(f"HTTP {res.status_code} — 수집이 거부되었습니다")

        if res.status_code == 404:            # 재시도 무의미
            log.info(f"  HTTP 404 — 없는 페이지")
            return None

        if res.ok:
            res.encoding = res.apparent_encoding or "utf-8"
            return res

        wait = BACKOFF_BASE * (2 ** attempt)  # 5xx
        log.warning(f"  HTTP {res.status_code} — {wait:.0f}초 후 재시도")
        time.sleep(wait)

    return None


# ══════════ 파싱 ══════════

STAR_MAP = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5}


def parse_list(html, page):
    """목록 페이지에서 도서 정보를 추출합니다."""
    soup = BeautifulSoup(html, "html.parser")
    results = []

    for i, card in enumerate(soup.select("article.product_pod")):
        try:
            href = get_attr(card, "h3 a", "href")
            stars = card.select_one("p.star-rating")
            rating = next((STAR_MAP[c] for c in (stars.get("class", []) if stars else [])
                           if c in STAR_MAP), 0)

            results.append({
                "title": get_attr(card, "h3 a", "title") or get_text(card, "h3 a"),
                "price": to_float(get_text(card, "p.price_color")),
                "price_text": get_text(card, "p.price_color", "-"),
                "rating": rating,
                "in_stock": "In stock" in get_text(card, "p.instock"),
                "url": urljoin(f"{BASE}/catalogue/", href),
                "page": page,
            })

        except Exception as e:
            log.warning(f"  항목 {i} 파싱 실패: {type(e).__name__}: {e}")

    return results


# ══════════ 수집 루프 ══════════

def crawl_list(max_pages=MAX_PAGES, force=False):
    """
    목록 페이지를 순회합니다.

    force : True 면 저장된 파일을 무시하고 다시 수집
    반환  : (전체 항목 리스트, 실패 리스트)
    """
    session = requests.Session()
    all_items, failures = [], []
    seen_urls = set()

    log.info(f"수집 시작 — 최대 {max_pages}페이지")

    for page in range(1, max_pages + 1):
        cache = RAW_DIR / f"page_{page:03d}.json"

        # ── ① 이미 수집한 페이지는 건너뜀 ──
        if cache.exists() and not force:
            items = json.loads(cache.read_text(encoding="utf-8"))
            all_items.extend(items)
            seen_urls.update(it["url"] for it in items)
            log.info(f"[{page:>2}/{max_pages}] 캐시 사용 ({len(items)}건)")
            continue

        url = LIST_URL.format(page=page)

        # ── ② 요청 ──
        try:
            res = fetch(url, session)
        except BlockedError as e:
            log.error(f"⛔ {e} — 전체 중단")
            break

        if res is None:
            failures.append({"page": page, "url": url, "reason": "요청 실패"})
            log.warning(f"[{page:>2}/{max_pages}] 실패 — 기록 후 계속")
            continue

        # ── ③ 파싱 ──
        items = parse_list(res.text, page)

        # ── ④ 종료 조건: 결과 0건 ──
        if not items:
            log.info(f"[{page:>2}/{max_pages}] 항목 0건 — 마지막 페이지로 판단")
            break

        # ── ⑤ 종료 조건: 전부 중복 ──
        new_urls = {it["url"] for it in items} - seen_urls
        if not new_urls:
            log.warning(f"[{page:>2}/{max_pages}] 전부 중복 — 같은 페이지 반복 의심, 중단")
            break

        # ── ⑥ 즉시 저장 ──
        cache.write_text(json.dumps(items, ensure_ascii=False, indent=1),
                         encoding="utf-8")

        all_items.extend(items)
        seen_urls.update(it["url"] for it in items)

        log.info(f"[{page:>2}/{max_pages}] {len(items)}건 "
                 f"(신규 {len(new_urls)}건 · 누적 {len(all_items)}건)")

    session.close()
    return all_items, failures
```

### Step 3. 상세 페이지 진입 + `read_html` (오늘의 종합 예제)

상세 페이지에는 `<table>` 이 있으므로 **`pd.read_html` 을 씁니다.**

`crawl_detail.py`

```python
"""목록에서 수집한 URL 로 상세 페이지에 들어가 추가 정보를 수집합니다."""

import json
import logging
import re
from io import StringIO
from pathlib import Path

import pandas as pd
import requests
from bs4 import BeautifulSoup

from crawler import (BASE, HEADERS, RAW_DIR, DATA_DIR, BlockedError,
                     fetch, get_text, to_float)

DETAIL_DIR = DATA_DIR / "raw_detail"
DETAIL_DIR.mkdir(parents=True, exist_ok=True)

log = logging.getLogger("detail")


def slug_of(url):
    """URL 에서 파일 이름으로 쓸 식별자를 만듭니다."""
    return re.sub(r"[^a-zA-Z0-9_-]", "_", url.rstrip("/").split("/")[-2])[:60]


def parse_detail(html):
    """
    상세 페이지에서 정보를 추출합니다.
    표는 pd.read_html, 나머지는 BeautifulSoup 을 씁니다.
    """
    soup = BeautifulSoup(html, "html.parser")

    info = {
        "category": get_text(soup, "ul.breadcrumb li:nth-of-type(3) a"),
        "description": get_text(soup, "#product_description ~ p")[:200],
    }

    # ── 표는 read_html 로 통째로 ──
    try:
        tables = pd.read_html(StringIO(html))
    except ValueError:                     # 표가 하나도 없을 때
        return info

    if not tables:
        return info

    table = tables[0]
    table.columns = ["key", "value"]       # 이 표는 2열 구조
    spec = dict(zip(table["key"], table["value"]))

    info.update({
        "upc": spec.get("UPC", ""),
        "price_excl_tax": to_float(spec.get("Price (excl. tax)", "")),
        "price_incl_tax": to_float(spec.get("Price (incl. tax)", "")),
        "tax": to_float(spec.get("Tax", "")),
        "stock_count": to_float(spec.get("Availability", ""), 0),
        "review_count": to_float(spec.get("Number of reviews", ""), 0),
    })

    return info


def crawl_details(urls, limit=None):
    """상세 페이지를 순회합니다. 개별 파일로 중간 저장합니다."""
    session = requests.Session()
    targets = urls[:limit] if limit else urls

    results, failures = [], []
    log.info(f"상세 수집 시작 — {len(targets)}건")

    for i, url in enumerate(targets, 1):
        cache = DETAIL_DIR / f"{slug_of(url)}.json"

        if cache.exists():
            results.append(json.loads(cache.read_text(encoding="utf-8")))
            continue

        try:
            res = fetch(url, session)
        except BlockedError as e:
            log.error(f"⛔ {e} — 중단")
            break

        if res is None:
            failures.append({"url": url, "reason": "요청 실패"})
            continue

        try:
            info = parse_detail(res.text)
        except Exception as e:
            failures.append({"url": url, "reason": f"{type(e).__name__}: {e}"})
            continue

        info["url"] = url
        cache.write_text(json.dumps(info, ensure_ascii=False, indent=1),
                         encoding="utf-8")
        results.append(info)

        if i % 10 == 0:
            log.info(f"  {i}/{len(targets)} 완료 (누적 {len(results)}건)")

    session.close()
    return results, failures


# ══════════ 실행 ══════════
if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO,
                        format="%(asctime)s [%(levelname)s] %(message)s",
                        datefmt="%H:%M:%S")

    # ── ① 목록 결과 불러오기 ──
    books = pd.read_csv(DATA_DIR / "books.csv")
    print(f"[목록] {len(books)}건")

    # ── ② 상위 30건만 상세 수집 (요청 수 절약) ──
    targets = books.nlargest(30, "price")["url"].tolist()
    details, failures = crawl_details(targets)

    print("\n" + "=" * 78)
    print(f"  상세 수집 — 성공 {len(details)}건 · 실패 {len(failures)}건")
    print("=" * 78)

    if not details:
        raise SystemExit("상세 데이터가 없습니다.")

    detail_df = pd.DataFrame(details)

    # ── ③ 목록 + 상세 병합 ──
    merged = books.merge(detail_df, on="url", how="inner")

    print(f"\n[병합] 목록 {books.shape} + 상세 {detail_df.shape} "
          f"→ {merged.shape}")

    print(f"\n[상세에서만 얻은 열]")
    for col in detail_df.columns:
        if col != "url":
            print(f"  · {col}")

    # ── ④ 검증: 목록 가격과 상세 가격이 일치하는가 ──
    gap = (merged["price"] - merged["price_incl_tax"]).abs()
    print(f"\n[교차 검증] 목록 가격 vs 상세 가격(세금 포함)")
    print(f"  최대 차이 : £{gap.max():.2f}")
    print(f"  불일치    : {(gap > 0.01).sum()}건")

    # ── ⑤ 카테고리별 집계 ──
    print(f"\n[카테고리별]")
    agg = (merged.groupby("category")
                 .agg(권수=("title", "count"),
                      평균가=("price", "mean"),
                      평균별점=("rating", "mean"),
                      리뷰합=("review_count", "sum"))
                 .sort_values("권수", ascending=False)
                 .head(8))
    print(agg.round(2).to_string())

    print(f"\n[재고]")
    print(f"  평균 재고 : {merged['stock_count'].mean():.1f}권")
    print(f"  최소 재고 : {merged['stock_count'].min():.0f}권 "
          f"({merged.loc[merged['stock_count'].idxmin(), 'title'][:40]})")

    merged.to_csv(DATA_DIR / "books_full.csv", index=False, encoding="utf-8-sig")
    print(f"\n[저장] data/books_full.csv  ({len(merged)}행 × {merged.shape[1]}열)")

    if failures:
        pd.DataFrame(failures).to_csv(DATA_DIR / "detail_failures.csv",
                                      index=False, encoding="utf-8-sig")
        print(f"[저장] data/detail_failures.csv ({len(failures)}건)")

    print("\n" + "=" * 78)
```

> **눈여겨볼 점 7가지**
> - **표는 `pd.read_html`, 나머지는 BeautifulSoup** — 도구를 섞어 쓰는 것이 정상입니다.
> - `StringIO(html)` — pandas 2.1+ 경고를 피하는 필수 처리입니다.
> - **상세도 개별 파일로 캐시** — 30건 중 25건째에서 끊겨도 25건은 남습니다.
> - **상위 30건만 수집** — 200건 전부 들어가면 요청이 200회입니다. 필요한 만큼만.
> - `merge(on="url")` — **URL 이 키**입니다. 제목으로 병합하면 동명 도서에서 어긋납니다.
> - **교차 검증** — 목록 가격과 상세 가격을 비교해 파싱이 맞았는지 스스로 확인합니다.
> - `except ValueError` — **표가 없는 페이지**에서 `read_html` 은 `ValueError` 를 던집니다.

**문제 9가지**

| # | 문제 | 결과 |
|---|---|---|
| 1 | **종료 조건 없음** | 무한 루프 |
| 2 | **지연 없음** | 초당 수십 회 요청 → 차단 |
| 3 | `headers` · `timeout` 없음 | 봇 차단, 무한 대기 |
| 4 | 상태 코드 확인 없음 | 404 HTML 을 파싱 |
| 5 | 인코딩 미지정 | 한글 깨짐 |
| 6 | `select_one().get_text()` | 요소가 없으면 `AttributeError` |
| 7 | **중간 저장 없음** | 중단 시 전부 소멸 |
| 8 | 가격이 문자열 | `mean()` 불가 |
| 9 | 중복 제거 없음 · `index=False` 누락 | 중복 포함, 불필요한 인덱스 열 |

**수정**

```python
"""안전한 반복 수집기."""

import json
import logging
import random
import re
import time
from pathlib import Path

import pandas as pd
import requests
from bs4 import BeautifulSoup

BASE = "https://example.com/list"
HEADERS = {"User-Agent": "Mozilla/5.0 ... (educational-purpose)"}
DELAY_MIN, DELAY_MAX = 0.8, 1.5
MAX_PAGES = 50                      # ① 상한
STOP_CODES = {401, 403, 429}

RAW = Path("data/raw")
RAW.mkdir(parents=True, exist_ok=True)

logging.basicConfig(level=logging.INFO, format="%(message)s")
log = logging.getLogger("crawl")


def get_text(parent, selector, default=""):          # ⑥ 안전한 추출
    el = parent.select_one(selector)
    return el.get_text(" ", strip=True) if el else default


def to_int(text, default=0):                          # ⑧ 숫자 정제
    digits = re.sub(r"[^\d-]", "", str(text or ""))
    return int(digits) if digits and digits != "-" else default


def parse(html, page):
    soup = BeautifulSoup(html, "html.parser")
    rows = []

    for card in soup.select(".item"):
        name = get_text(card, ".name")
        if not name:                                  # 필수 항목 검증
            continue

        href = (card.select_one("a") or {}).get("href", "")
        rows.append({
            "name": name,
            "price": to_int(get_text(card, ".price")),
            "price_text": get_text(card, ".price", "-"),
            "url": requests.compat.urljoin(BASE, href),
            "page": page,
        })

    return rows


all_items, failures = [], []
seen = set()
session = requests.Session()

for page in range(1, MAX_PAGES + 1):                  # ① 상한
    cache = RAW / f"page_{page:03d}.json"

    if cache.exists():                                # ⑦ 캐시
        rows = json.loads(cache.read_text(encoding="utf-8"))
        all_items.extend(rows)
        seen.update(r["url"] for r in rows)
        continue

    time.sleep(random.uniform(DELAY_MIN, DELAY_MAX))  # ② 지연

    try:                                              # ③ 헤더·타임아웃
        res = session.get(BASE, params={"page": page},
                          headers=HEADERS, timeout=10)
    except requests.RequestException as e:
        failures.append({"page": page, "reason": type(e).__name__})
        continue

    if res.status_code in STOP_CODES:                 # ④ 상태 코드
        log.error(f"⛔ HTTP {res.status_code} — 중단")
        break

    if not res.ok:
        failures.append({"page": page, "reason": f"HTTP {res.status_code}"})
        continue

    res.encoding = res.apparent_encoding or "utf-8"   # ⑤ 인코딩

    rows = parse(res.text, page)

    if not rows:                                      # ① 종료: 0건
        log.info(f"{page}페이지 0건 — 종료")
        break

    new = {r["url"] for r in rows} - seen
    if not new:                                       # ① 종료: 전부 중복
        log.warning(f"{page}페이지 전부 중복 — 종료")
        break

    cache.write_text(json.dumps(rows, ensure_ascii=False),   # ⑦ 즉시 저장
                     encoding="utf-8")

    all_items.extend(rows)
    seen.update(r["url"] for r in rows)
    log.info(f"{page}페이지 {len(rows)}건 (누적 {len(all_items)})")

session.close()

df = pd.DataFrame(all_items)
before = len(df)
df = df.drop_duplicates(subset=["url"]).reset_index(drop=True)   # ⑨ 중복 제거

log.info(f"중복 제거 {before} → {len(df)}")
df.to_csv("data/result.csv", index=False, encoding="utf-8-sig")  # ⑨

if failures:
    pd.DataFrame(failures).to_csv("data/failures.csv", index=False,
                                  encoding="utf-8-sig")
    log.warning(f"실패 {len(failures)}페이지 — data/failures.csv")
```

**핵심 4가지**

| 원칙 | 구현 |
|---|---|
| **끝날 수 있게** | 상한 + 0건 + 전부 중복 |
| **천천히** | 랜덤 지연 · Session 재사용 |
| **죽어도 남게** | 페이지 단위 즉시 저장 |
| **뭐가 빠졌는지 알게** | `failures.csv` |
</details>

**2.** 아래 상황에 맞는 종료 조건을 각각 코드로 작성하세요.

| 상황 | 사이트 동작 |
|---|---|
| A | 마지막 페이지 다음은 **HTTP 404** |
| B | 마지막 페이지 다음은 **200 + 빈 목록** |
| C | 마지막 페이지 다음은 **200 + 1페이지 내용** |
| D | 페이지 수를 모름. `<a class="next">` 만 있음 |

<details>
<summary>답 보기</summary>

```python
"""페이지네이션 유형별 종료 조건."""

import time
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

HEADERS = {"User-Agent": "Mozilla/5.0 ... (educational-purpose)"}
MAX_PAGES = 100          # 네 경우 모두 공통으로 두는 안전장치


def fetch(url, session, **kw):
    time.sleep(1.0)
    res = session.get(url, headers=HEADERS, timeout=10, **kw)
    res.encoding = res.apparent_encoding or "utf-8"
    return res


# ══════════ A. 404 로 끝나는 경우 ══════════
def crawl_a(base, parse):
    session, items = requests.Session(), []

    for page in range(1, MAX_PAGES + 1):
        res = fetch(f"{base}/page-{page}.html", session)

        if res.status_code == 404:                 # ← 종료
            print(f"  {page}페이지 404 — 종료")
            break
        if not res.ok:
            continue

        items.extend(parse(res.text))

    return items


# ══════════ B. 빈 목록으로 끝나는 경우 ══════════
def crawl_b(base, parse):
    session, items = requests.Session(), []

    for page in range(1, MAX_PAGES + 1):
        res = fetch(base, session, params={"page": page})
        if not res.ok:
            break

        rows = parse(res.text)

        if not rows:                                # ← 종료
            print(f"  {page}페이지 0건 — 종료")
            break

        items.extend(rows)

    return items


# ══════════ C. 1페이지를 되돌려 주는 경우 ══════════
def crawl_c(base, parse, key="url"):
    """신규 항목이 없으면 종료합니다. 가장 까다로운 유형."""
    session, items = requests.Session(), []
    seen = set()

    for page in range(1, MAX_PAGES + 1):
        res = fetch(base, session, params={"page": page})
        if not res.ok:
            break

        rows = parse(res.text)
        if not rows:
            break

        new = [r for r in rows if r[key] not in seen]

        if not new:                                 # ← 종료
            print(f"  {page}페이지 신규 0건 — 되돌림 감지, 종료")
            break

        if len(new) < len(rows):                    # 부분 중복은 경고만
            print(f"  {page}페이지 중복 {len(rows) - len(new)}건")

        items.extend(new)
        seen.update(r[key] for r in new)

    return items


# ══════════ D. next 링크를 따라가는 경우 ══════════
def crawl_d(start_url, parse):
    session, items = requests.Session(), []
    visited = set()
    url, page = start_url, 0

    while url and page < MAX_PAGES:                 # ← 상한
        if url in visited:                          # ← 순환 종료
            print(f"  이미 방문한 URL — 종료: {url}")
            break

        visited.add(url)
        page += 1

        res = fetch(url, session)
        if not res.ok:
            break

        items.extend(parse(res.text))

        soup = BeautifulSoup(res.text, "html.parser")
        next_a = soup.select_one("a.next, li.next a")

        if not next_a or not next_a.get("href"):    # ← 링크 없음 종료
            print(f"  다음 링크 없음 — 종료 ({page}페이지)")
            break

        url = urljoin(res.url, next_a["href"])

    return items
```

**정리**

| 유형 | 판정 기준 | 놓치면 |
|---|---|---|
| A | `status_code == 404` | 404 HTML 을 파싱해 이상한 데이터가 섞임 |
| B | `len(rows) == 0` | 빈 페이지를 상한까지 요청 |
| C | **신규 항목 0건** | 같은 20건을 100번 수집 |
| D | `next` 링크 없음 + **방문 URL 집합** | 순환 링크에서 무한 루프 |

> **네 경우 모두 `MAX_PAGES` 를 함께 둡니다.**
> 종료 조건은 사이트 동작에 의존하지만, 상한은 **내 코드가 통제하는 유일한 안전장치**입니다.
>
> **실무에서는 A~D를 다 넣습니다.** 사이트 동작을 미리 다 알 수 없기 때문입니다.
</details>

**3.** 수집 진행 상황을 관리하는 `Checkpoint` 클래스를 작성하세요.
중단된 지점부터 이어서 수집할 수 있어야 하고, 진행률과 실패 목록을 관리해야 합니다.

```python
"""수집 진행 상황 관리."""

import json
from pathlib import Path

import pandas as pd


class Checkpoint:
    """
    수집 진행 상황을 파일로 관리합니다.

    done     : 완료한 작업 키 집합
    failed   : 실패한 작업 {키: 사유}
    meta     : 자유롭게 쓰는 부가 정보
    """

    def __init__(self, path="data/checkpoint.json", total=None):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)

        self.done = set()
        self.failed = {}
        self.meta = {"total": total}

        self.load()

    # ══════════ 저장 / 복원 ══════════

    def load(self):
        """저장된 진행 상황을 불러옵니다."""
        if not self.path.exists():
            return False

        try:
            data = json.loads(self.path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, OSError) as e:
            print(f"⚠ 체크포인트 손상 ({type(e).__name__}) — 새로 시작합니다")
            return False

        self.done = set(data.get("done", []))
        self.failed = data.get("failed", {})
        self.meta.update(data.get("meta", {}))

        print(f"[체크포인트] 완료 {len(self.done)}건 · 실패 {len(self.failed)}건 "
              f"— 이어서 시작합니다")
        return True

    def save(self):
        """현재 상태를 파일에 씁니다."""
        tmp = self.path.with_suffix(".tmp")          # 원자적 쓰기
        tmp.write_text(json.dumps({
            "done": sorted(self.done),
            "failed": self.failed,
            "meta": self.meta,
        }, ensure_ascii=False, indent=1), encoding="utf-8")
        tmp.replace(self.path)

    # ══════════ 기록 ══════════

    def is_done(self, key):
        return str(key) in self.done

    def mark_done(self, key, save=True):
        key = str(key)
        self.done.add(key)
        self.failed.pop(key, None)                  # 재시도 성공 시 실패 해제
        if save:
            self.save()

    def mark_failed(self, key, reason, save=True):
        self.failed[str(key)] = str(reason)
        if save:
            self.save()

    def pending(self, all_keys):
        """아직 처리하지 않은 작업만 돌려줍니다."""
        return [k for k in all_keys if not self.is_done(k)]

    def retry_targets(self):
        """실패한 작업 목록 (재시도용)."""
        return list(self.failed.keys())

    # ══════════ 조회 ══════════

    @property
    def progress(self):
        total = self.meta.get("total")
        return len(self.done) / total * 100 if total else 0.0

    def report(self):
        total = self.meta.get("total") or (len(self.done) + len(self.failed))
        bar_len = 30
        filled = int(bar_len * len(self.done) / total) if total else 0

        print("=" * 62)
        print("                    수집 진행 상황")
        print("=" * 62)
        print(f"  [{'█' * filled}{'░' * (bar_len - filled)}] "
              f"{self.progress:5.1f}%")
        print(f"  완료 {len(self.done):>4}건 / 전체 {total}건")
        print(f"  실패 {len(self.failed):>4}건")

        if self.failed:
            print(f"\n  [실패 목록]")
            reasons = pd.Series(list(self.failed.values())).value_counts()
            for reason, cnt in reasons.items():
                print(f"    {reason:<32}{cnt}건")

            print(f"\n  [실패 키 (앞 5개)]")
            for k in list(self.failed)[:5]:
                print(f"    {k}  ← {self.failed[k]}")

        print("=" * 62)

    def reset(self):
        """처음부터 다시 시작합니다."""
        self.done.clear()
        self.failed.clear()
        if self.path.exists():
            self.path.unlink()
        print("[체크포인트] 초기화 완료")


# ══════════ 사용 예 ══════════
if __name__ == "__main__":
    PAGES = list(range(1, 21))

    cp = Checkpoint("data/checkpoint.json", total=len(PAGES))

    def crawl_page(page):
        """수집을 흉내 냅니다. 7, 13페이지는 실패."""
        if page in (7, 13):
            raise TimeoutError("Read timed out")
        return [{"page": page}] * 20

    # ── ① 남은 작업만 수행 ──
    todo = cp.pending(PAGES)
    print(f"\n처리할 페이지: {len(todo)}개\n")

    for page in todo:
        try:
            crawl_page(page)
        except Exception as e:
            cp.mark_failed(page, f"{type(e).__name__}: {e}")
            print(f"  {page:>2}페이지 ✗ {type(e).__name__}")
        else:
            cp.mark_done(page)
            print(f"  {page:>2}페이지 ✓")

    print()
    cp.report()

    # ── ② 실패분만 재시도 ──
    print(f"\n\n>>> 실패분 재시도\n")

    def crawl_page_fixed(page):        # 지연을 늘려 해결됐다고 가정
        return [{"page": page}] * 20

    for key in cp.retry_targets():
        try:
            crawl_page_fixed(int(key))
        except Exception as e:
            cp.mark_failed(key, str(e))
        else:
            cp.mark_done(key)
            print(f"  {key:>2}페이지 ✓ (재시도 성공)")

    print()
    cp.report()
```

**설계 포인트 6가지**

| # | 설계 | 이유 |
|---|---|---|
| ① | `pending()` 으로 **남은 것만** | 재실행이 이어서 진행됨 |
| ② | `mark_done` 마다 **즉시 저장** | 언제 죽어도 직전까지 보존 |
| ③ | **원자적 쓰기** (`.tmp` → `replace`) | 저장 도중 죽어도 파일이 깨지지 않음 |
| ④ | 성공 시 `failed` 에서 **제거** | 재시도 성공이 반영됨 |
| ⑤ | `retry_targets()` | 실패분만 골라 다시 돌림 |
| ⑥ | 키를 **문자열로 통일** | JSON 은 정수 키를 문자열로 바꿔 저장함 |

> **⑥번을 놓치면 재실행 시 캐시가 전부 무효가 됩니다.**
> `json.dump({1: "a"})` → `{"1": "a"}` 로 저장되므로,
> 불러온 뒤 `1 in done` 은 `False`, `"1" in done` 은 `True` 가 됩니다.
> **저장·조회 양쪽에서 `str(key)` 로 통일**해야 합니다.
>
> **③번 원자적 쓰기**도 중요합니다.
> `write_text` 도중에 프로세스가 죽으면 JSON 이 반만 쓰인 상태가 되고,
> 다음 실행에서 `JSONDecodeError` 로 **진행 상황을 통째로 잃습니다.**
> 임시 파일에 다 쓰고 `replace` 로 바꾸면 파일은 항상 완전한 상태입니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 페이지네이션 | 경로형 · 쿼리형 · offset형 · **링크 추적형** |
| 종료 조건 | **상한 + 0건 + 방문 URL + 전부 중복** — 4개 모두 |
| 지연 | `random.uniform(0.8, 1.5)` · `Crawl-delay` 우선 |
| 재시도 | 타임아웃·5xx만 · **지수 백오프** |
| 즉시 중단 | **401 · 403 · 429** — 재시도 금지 |
| 404 | 재시도 무의미 — 건너뜀 |
| **중간 저장** | 페이지 단위 `raw/page_XXX.json` · **저장 후 누적** |
| 재시작 | `cache.exists()` → 건너뜀 |
| 실패 로그 | 페이지 · URL · 원인 → `failures.csv` |
| 상세 수집 | 요청 수가 **N배** — 필요한 만큼만 |
| 중복 제거 | **URL·상품코드**를 키로 · 제거 건수 출력 |
| `read_html` | `<table>` 전용 · `StringIO` 로 감싸기 · `match` `thousands` |

**오늘 반드시 기억할 세 가지**
> ① **종료 조건은 4개를 다 넣으세요.** 하나만 믿으면 언젠가 무한 루프에 빠집니다.
> ② **페이지마다 저장하세요.** 저장을 먼저, 누적을 나중에. 디스크에 있는 것만 살아남습니다.
> ③ **실패 건수를 반드시 출력하세요.** "완료"에는 항상 `성공 N / 실패 M` 이 붙어야 합니다.
