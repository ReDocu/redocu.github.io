**게다가 지도는 상호작용이 됩니다.**

| 기능 | 효과 |
|---|---|
| 확대·축소 | 전국 → 동네까지 |
| 마커 클릭 | 이름·평점·가격 확인 |

| HTML 저장 | **파이썬 없이도 열림** ⭐ |

### 웹 지도의 원리 — 타일

지도는 **256×256 픽셀 정사각형 이미지(타일)** 를 격자로 이어 붙인 것입니다.

```
줌 0        줌 1            줌 2
┌───┐      ┌─┬─┐         ┌─┬─┬─┬─┐
│세계│  →   ├─┼─┤    →    ├─┼─┼─┼─┤
└───┘      └─┴─┘         ├─┼─┼─┼─┤
1장         4장           └─┴─┴─┴─┘
                          16장
```

**줌 레벨이 1 올라가면 타일 수가 4배**가 됩니다.

| 줌 | 보이는 범위 | 용도 |
|---|---|---|
| 0~3 | 세계 | 대륙 비교 |
| **6~7** | **한반도 전체** | 전국 분포 ⭐ |
| 10~11 | 광역시 | 도시 단위 |
| **13~14** | **구·동** | 지역 상세 ⭐ |
| 16~18 | 건물 | 개별 위치 |

```python
folium.Map(location=[36.5, 127.8], zoom_start=7)     # 한반도 전체
folium.Map(location=[37.5665, 126.9780], zoom_start=13)   # 서울 도심
```

> ⚠️ **`location` 은 `[위도, 경도]` 순서입니다.** ([Day 066](day-066.md))
> 바꿔 넣으면 지도가 **엉뚱한 곳**을 보여 줍니다.

### 타일 종류

```python
folium.Map(tiles="OpenStreetMap")        # 기본. 상세하고 컬러풀
folium.Map(tiles="CartoDB positron")     # 밝은 회색 — 데이터 강조 ⭐
folium.Map(tiles="CartoDB dark_matter")  # 어두운 배경
folium.Map(tiles="CartoDB voyager")      # 중간 채도
```

| 타일 | 언제 |
|---|---|
| `OpenStreetMap` | 위치 파악이 목적 (도로·상호명 보임) |
| **`CartoDB positron`** | **데이터가 주인공** — 배경이 연해서 마커가 돋보임 ⭐ |
| `CartoDB dark_matter` | 히트맵·발광 효과 |

> ⚠️ **외부 타일(Stamen 등)은 `attr` 이 필수입니다.**
> ```python
> folium.Map(tiles="https://...{z}/{x}/{y}.png",
>            attr="© 제공처 이름")        # 없으면 에러
> ```
> ```
> ValueError: Custom tiles must have an attribution
> ```
> 저작권 표기 의무 때문입니다. **기본 제공 타일은 자동으로 붙습니다.**

### 마커

```python
folium.Marker(
    location=[37.5760, 126.9769],
    popup="경복궁",                       # 클릭하면 나옴
    tooltip="마우스를 올려 보세요",         # 올리면 나옴

).add_to(m)
```

**`Icon` 색 — 정해진 목록만 됩니다**

```
red, blue, green, purple, orange, darkred, lightred,
beige, darkblue, darkgreen, cadetblue, darkpurple,
white, pink, lightblue, lightgreen, gray, black, lightgray
```

> ⚠️ **hex 색(`#2563eb`)은 `folium.Icon` 에서 안 됩니다.**
> 자유로운 색을 쓰려면 **`CircleMarker`** 를 쓰세요.

**아이콘 모양**

```python
folium.Icon(icon="info-sign")                     # Bootstrap (기본)
folium.Icon(icon="star", prefix="fa")             # Font Awesome ⭐
folium.Icon(icon="camera", prefix="fa", color="green")
```

| `prefix` | 아이콘 세트 | 예 |
|---|---|---|
| `"glyphicon"` (기본) | Bootstrap 3 | `info-sign` `cloud` `flag` |
| **`"fa"`** | Font Awesome 4 | `star` `camera` `tree` `utensils` |

### `CircleMarker` vs `Circle`

```python
# 픽셀 단위 — 확대해도 크기가 그대로 ⭐
folium.CircleMarker(
    location=[lat, lng],
    radius=8,                    # 픽셀
    color="#2563eb",             # 테두리 (hex 가능!)
    fill=True,
    fill_color="#2563eb",
    fill_opacity=0.7,
    weight=2,
).add_to(m)

# 미터 단위 — 확대하면 같이 커짐
folium.Circle(
    location=[lat, lng],
    radius=500,                  # 미터 ⭐
    color="#ef4444",
    fill=True,
).add_to(m)
```

| | `CircleMarker` | `Circle` |
|---|---|---|
| `radius` 단위 | **픽셀** | **미터** |
| 확대 시 | 크기 유지 | 같이 커짐 |
| 용도 | 점 표시 | **반경 표현** (5km 권역 등) |

> **데이터 포인트에는 `CircleMarker`, 영역 표시에는 `Circle`** 입니다.

### 팝업 — HTML 을 넣을 수 있습니다

```python
# ① 간단한 텍스트
folium.Marker([lat, lng], popup="경복궁").add_to(m)

# ② 너비 지정
folium.Marker([lat, lng],
              popup=folium.Popup("긴 내용...", max_width=300)).add_to(m)

# ③ HTML ⭐
html = f"""
<div style="font-family:'Malgun Gothic',sans-serif; width:220px">
  <h4 style="margin:0 0 6px 0">{name}</h4>
  <table style="font-size:12px; width:100%">
    <tr><td>평점</td><td><b>{rating}</b></td></tr>
    <tr><td>가격</td><td>{price:,}원</td></tr>
  </table>
</div>
"""
folium.Marker([lat, lng],
              popup=folium.Popup(html, max_width=260)).add_to(m)
```

> ```

```python
"""folium 첫 지도 — 타일과 줌 레벨."""

from pathlib import Path

import folium
import numpy as np
import pandas as pd

OUT = Path("output/maps")
OUT.mkdir(parents=True, exist_ok=True)

KOREA_CENTER = [36.5, 127.8]
SEOUL = [37.5665, 126.9780]

print("=" * 76)
print("                       folium 첫 지도")
print("=" * 76)

# ══════════ ① 타일 비교 ══════════
TILES = {
    "osm": ("OpenStreetMap", "도로·상호명이 자세함"),
    "positron": ("CartoDB positron", "밝은 회색 — 데이터 강조 ⭐"),
    "dark": ("CartoDB dark_matter", "어두운 배경 — 히트맵용"),
    "voyager": ("CartoDB voyager", "중간 채도"),
}

print(f"\n[① 타일 비교]")
print(f"  {'파일':<28}{'타일':<24}설명")
print("  " + "-" * 74)

for key, (tile, desc) in TILES.items():
    m = folium.Map(location=SEOUL, zoom_start=12, tiles=tile)

    folium.Marker(SEOUL, tooltip="서울시청",
                  icon=folium.Icon(color="red", icon="star",
                                   prefix="fa")).add_to(m)

    path = OUT / f"tile_{key}.html"
    m.save(str(path))

    print(f"  {path.name:<28}{tile:<24}{desc}")

# ══════════ ② 줌 레벨 ══════════
print(f"\n[② 줌 레벨]")
print(f"  {'줌':<5}{'파일':<24}{'보이는 범위'}")
print("  " + "-" * 60)

ZOOM_DESC = {6: "한반도 전체", 8: "권역 (수도권)", 11: "도시 (서울)",
             14: "구 단위", 17: "건물"}

for zoom, desc in ZOOM_DESC.items():
    center = KOREA_CENTER if zoom <= 7 else SEOUL

    m = folium.Map(location=center, zoom_start=zoom, tiles="CartoDB positron")
    folium.Marker(SEOUL, tooltip="서울시청").add_to(m)

    path = OUT / f"zoom_{zoom:02d}.html"
    m.save(str(path))

    print(f"  {zoom:<5}{path.name:<24}{desc}")

# ══════════ ③ 마커 종류 ══════════
print(f"\n[③ 마커 종류]")

m = folium.Map(location=SEOUL, zoom_start=13, tiles="CartoDB positron")

# 기본 마커
folium.Marker(
    [37.5760, 126.9769],
    tooltip="Marker — 핀 모양",
    popup="경복궁",
    icon=folium.Icon(color="blue", icon="star", prefix="fa"),
).add_to(m)

# 원 마커 (픽셀)
folium.CircleMarker(
    [37.5512, 126.9882],
    radius=10,
    tooltip="CircleMarker — 픽셀 단위 (확대해도 그대로)",
    popup="남산타워",
    color="#2563eb", fill=True, fill_color="#2563eb", fill_opacity=0.7,
).add_to(m)

# 원 (미터)
folium.Circle(
    [37.5665, 126.9780],
    radius=1000,
    tooltip="Circle — 반경 1km (확대하면 같이 커짐)",
    color="#ef4444", fill=True, fill_opacity=0.15, weight=2,
).add_to(m)

# 아이콘 모양들
ICONS = [
    ("tree", "green", [37.5826, 126.9850], "자연"),
    ("camera", "purple", [37.5700, 127.0050], "체험"),
    ("utensils", "orange", [37.5600, 126.9900], "음식"),
    ("shopping-cart", "cadetblue", [37.5500, 127.0100], "쇼핑"),
]

for icon, color, loc, label in ICONS:
    folium.Marker(loc, tooltip=f"{label} ({icon})",
                  icon=folium.Icon(color=color, icon=icon,
                                   prefix="fa")).add_to(m)

folium.LayerControl().add_to(m)
m.save(str(OUT / "marker_types.html"))

print(f"  marker_types.html — Marker / CircleMarker / Circle + 아이콘 4종")

print(f"\n[사용 가능한 Icon 색]")
ICON_COLORS = ["red", "blue", "green", "purple", "orange", "darkred",
               "lightred", "beige", "darkblue", "darkgreen", "cadetblue",

               "gray", "black", "lightgray"]
for i in range(0, len(ICON_COLORS), 5):
    print(f"  {', '.join(ICON_COLORS[i:i+5])}")

print(f"\n  ⚠ hex 색(#2563eb)은 Icon 에서 불가 → CircleMarker 사용")

print("\n" + "=" * 76)
print(f"  브라우저로 열기: output/maps/*.html")
print("=" * 76)
```

### Step 2. 데이터를 지도에 올리기 (오늘의 종합 예제)

```python
"""수집한 관광지를 지도에 표시합니다."""

import html as html_lib
from pathlib import Path

import folium
import numpy as np
import pandas as pd

OUT = Path("output/maps")
OUT.mkdir(parents=True, exist_ok=True)

# ── 실습 데이터 (Day 066 지오코딩 결과를 가정) ──
rng = np.random.default_rng(42)

REGIONS = {
    "서울": (37.5665, 126.9780, 0.12),
    "부산": (35.1796, 129.0756, 0.10),
    "제주": (33.4996, 126.5312, 0.15),
    "강릉": (37.7519, 128.8761, 0.10),
    "전주": (35.8242, 127.1480, 0.08),
    "경주": (35.8562, 129.2247, 0.08),
}

CATEGORIES = ["자연", "역사", "체험", "쇼핑", "음식"]

rows = []
for i in range(180):
    region = rng.choice(list(REGIONS))
    base_lat, base_lng, spread = REGIONS[region]

    rows.append({
        "id": 1000 + i,
        "name": f"{region}{rng.choice(CATEGORIES)}명소{i:03d}",
        "region": region,
        "category": rng.choice(CATEGORIES, p=[0.3, 0.24, 0.2, 0.14, 0.12]),
        "lat": base_lat + rng.normal(0, spread),
        "lng": base_lng + rng.normal(0, spread),
        "rating": round(min(5, max(1, rng.normal(4.0, 0.5))), 1),
        "price": int(rng.choice([0, 0, 3000, 5000, 8000, 12000, 20000])),
        "visitors": int(rng.lognormal(8.5, 1.1)),
    })

df = pd.DataFrame(rows)
```

> **눈여겨볼 점 8가지**
> - **`fit_bounds`** — 데이터 범위에 맞춰 자동으로 확대·이동합니다. `zoom_start` 추측이 불필요합니다.
> - **툴팁과 팝업 분리** — 훑어볼 때는 툴팁, 자세히 볼 때는 팝업.
> - **`html.escape`** — 이름에 `<` 나 `&` 가 있어도 팝업이 안 깨집니다.
> - **`np.log1p` 로 원 크기 계산** — 방문객이 극단적으로 치우쳐 있어 로그가 필요합니다.
> - **`FeatureGroup` 이름에 개수 표시** — `"자연 (52)"` 처럼 하면 클릭 전에 규모를 압니다.
> - **`DivIcon`** — 아이콘 대신 **HTML 을 그대로** 지도에 올립니다. 텍스트 라벨용.
> - **범례를 `position:fixed` 로** — 지도를 움직여도 제자리에 있습니다.
> - **`Circle` 반지름은 미터** — 지역 요약 원은 확대하면 같이 커져야 하므로 `Circle` 을 썼습니다.

### Step 3. 반경 검색 지도

```python
"""특정 지점 반경 안의 관광지를 지도로 보여 줍니다."""

import folium
import numpy as np

EARTH_R = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))
    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlng/2)**2
    return 2 * EARTH_R * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


def radius_map(df, center, name, radii=(5, 10, 20), save_path=None):
    """중심점 반경별로 관광지를 표시한 지도를 만듭니다."""
    c_lat, c_lng = center

    work = df.copy()
    work["distance_km"] = haversine(c_lat, c_lng, work["lat"], work["lng"])

    max_r = max(radii)
    inside = work[work["distance_km"] <= max_r].sort_values("distance_km")

    m = folium.Map(location=center, zoom_start=11, tiles="CartoDB positron",
                   control_scale=True)

    # ── 반경 원 (큰 것부터 그려야 작은 것이 위에) ──
    RING_COLORS = ["#94a3b8", "#60a5fa", "#2563eb"]

    for r, color in zip(sorted(radii, reverse=True), RING_COLORS):
        folium.Circle(
            center, radius=r * 1000,
            color=color, weight=2, dash_array="6,6",
            fill=True, fill_opacity=0.05,
            tooltip=f"반경 {r}km",
        ).add_to(m)

    # ── 중심점 ──
    folium.Marker(
        center,
        tooltip=f"{name} (중심)",
        icon=folium.Icon(color="red", icon="crosshairs", prefix="fa"),
    ).add_to(m)

    # ── 반경별 그룹 ──
    prev = 0
    for r, color in zip(sorted(radii), RING_COLORS[::-1]):
        band = inside[(inside["distance_km"] > prev)
                      & (inside["distance_km"] <= r)]

        group = folium.FeatureGroup(name=f"{prev}~{r}km ({len(band)}곳)")

        for _, row in band.iterrows():
            folium.CircleMarker(
                [row["lat"], row["lng"]], radius=7,
                tooltip=f"{row['name']} · {row['distance_km']:.1f}km",
                popup=folium.Popup(make_popup_html(row), max_width=260),
                color=color, weight=2,
                fill=True, fill_color=color, fill_opacity=0.7,
            ).add_to(group)

            # 중심과 연결선
            folium.PolyLine(
                [center, [row["lat"], row["lng"]]],
                color=color, weight=1, opacity=0.25,
            ).add_to(group)

        group.add_to(m)
        prev = r

    folium.LayerControl(collapsed=False).add_to(m)
    m.fit_bounds([[c_lat - max_r/111, c_lng - max_r/89],
                  [c_lat + max_r/111, c_lng + max_r/89]])

    if save_path:
        m.save(str(save_path))

    return m, inside


print("=" * 78)
print("                       반경 검색 지도")
print("=" * 78)

CENTERS = {

    if inside.empty:

        continue

    for lo, hi in [(0, 5), (5, 10), (10, 20)]:
        band = inside[(inside["distance_km"] > lo)
                      & (inside["distance_km"] <= hi)]
        bar = "■" * len(band)
        print(f"  {lo:>2}~{hi:>2}km : {len(band):>3}곳  {bar}")

    print(f"  합계     : {len(inside)}곳")

    if len(inside):
        nearest = inside.iloc[0]
        print(f"  최근접   : {nearest['name']} "
              f"({nearest['distance_km']:.2f}km, {nearest['rating']}점)")

print("\n" + "=" * 78)
```

## ⑤ 자주 하는 실수

### `location` 순서 뒤바뀜

```python
folium.Map(location=[126.98, 37.57])       # 남극 근처
```

**해결** — `[위도, 경도]`

### 좌표에 `NaN` 이 섞임

```python
folium.Marker([np.nan, 126.98])            # 마커가 안 나오거나 지도가 깨짐
```

**해결** — 그리기 전에 필터

```python
df = df[df["lat"].notna() & df["lng"].notna()]
```

### `Icon` 에 hex 색

```python
folium.Icon(color="#2563eb")               # 무시되거나 기본색
```

**해결** — 정해진 색 이름을 쓰거나 `CircleMarker` 를 씁니다.

### `numpy` 타입을 그대로 전달

```python
folium.CircleMarker(radius=np.float64(8))  # 직렬화 오류가 날 수 있음
```

**해결** — `float(size)`, `int(n)` 으로 변환

### `CircleMarker` 와 `Circle` 혼동

```python
folium.CircleMarker(radius=1000)           # 화면을 덮는 거대한 원 (픽셀!)
```

**해결** — 반경(미터)은 `Circle`, 점 표시는 `CircleMarker`

### 팝업에 이스케이프 없이 데이터 삽입

```python
popup=f"<b>{name}</b>"                     # name 에 <script> 가 있으면?
```

**해결** — `html.escape(str(name))`

### 마커를 2,000개 이상

브라우저가 버벅이거나 멈춥니다.

**해결** — `MarkerCluster` ([Day 068](day-068.md)) 또는 상위 N개

### `fit_bounds` 없이 `zoom_start` 만

데이터가 화면 밖에 있어 **빈 지도**로 보입니다.

**해결** — `m.fit_bounds([[lat_min, lng_min], [lat_max, lng_max]])`

### 저장 안 하고 `m` 만

스크립트(`.py`)에서는 아무것도 안 보입니다.

**해결** — `m.save("output/map.html")`

### 커스텀 타일에 `attr` 누락

```
ValueError: Custom tiles must have an attribution
```

**해결** — `folium.Map(tiles=url, attr="© 제공처")`

### 반복문에서 매번 `Map` 생성

**해결** — 지도 하나에 `FeatureGroup` 으로 나눕니다.

### 툴팁 없이 팝업만

마커 100개를 **하나씩 클릭**해야 내용을 압니다.

**해결** — 툴팁에 핵심 정보(이름·평점)를 넣습니다.

```python
"""DataFrame → folium 지도 변환기."""

import html as html_lib
from pathlib import Path

import folium
import numpy as np
import pandas as pd

DEFAULT_PALETTE = ["#0072B2", "#E69F00", "#009E73", "#CC79A7",
                   "#56B4E9", "#D55E00", "#F0E442", "#8c8c8c"]

ICON_COLOR_MAP = {
    "#0072B2": "blue", "#E69F00": "orange", "#009E73": "green",
    "#CC79A7": "purple", "#56B4E9": "lightblue", "#D55E00": "red",
    "#F0E442": "beige", "#8c8c8c": "gray",
}


def df_to_map(df, lat_col="lat", lng_col="lng", name_col="name",
              color_by=None, size_by=None, popup_cols=None,
              tooltip_cols=None, tiles="CartoDB positron",
              layer_by=None, palette=None, use_log_size=True,
              radius_range=(4, 18), save_path=None, verbose=True):
    """
    DataFrame 을 folium 지도로 변환합니다.

    color_by  : 색을 나눌 범주형 열
    size_by   : 크기를 정할 수치형 열
    layer_by  : 레이어로 나눌 열 (보통 color_by 와 동일)
    popup_cols: 팝업에 표시할 열 목록
    """
    palette = palette or DEFAULT_PALETTE

    # ══════════ ① 유효 좌표 필터 ══════════
    valid = (df[lat_col].notna() & df[lng_col].notna()
             & df[lat_col].between(-90, 90) & df[lng_col].between(-180, 180))

    work = df[valid].copy()
    dropped = len(df) - len(work)

    if work.empty:
        raise ValueError("표시할 유효한 좌표가 없습니다")

    # ══════════ ② 색 매핑 ══════════
    if color_by and color_by in work.columns:
        categories = sorted(work[color_by].dropna().astype(str).unique())
        color_map = {c: palette[i % len(palette)]
                     for i, c in enumerate(categories)}
        work["_color"] = work[color_by].astype(str).map(color_map).fillna("#8c8c8c")
    else:
        categories, color_map = [], {}
        work["_color"] = palette[0]

    # ══════════ ③ 크기 매핑 ══════════
    lo, hi = radius_range

    if size_by and size_by in work.columns:
        v = pd.to_numeric(work[size_by], errors="coerce").fillna(0)
        v = np.log1p(v.clip(lower=0)) if use_log_size else v

        span = v.max() - v.min()
        work["_radius"] = (lo + (hi - lo) * (v - v.min()) / span
                           if span > 0 else (lo + hi) / 2)
    else:
        work["_radius"] = (lo + hi) / 2

    # ══════════ ④ 팝업 ══════════
    popup_cols = popup_cols or [c for c in work.columns
                                if not c.startswith("_")
                                and c not in (lat_col, lng_col)][:6]

    def build_popup(row):
        title = html_lib.escape(str(row.get(name_col, "")))
        color = row["_color"]

        rows_html = ""
        for i, col in enumerate(popup_cols):
            if col == name_col or col not in row.index:
                continue

            val = row[col]
            if pd.isna(val):
                val = "-"
            elif isinstance(val, (int, np.integer)):
                val = f"{val:,}"
            elif isinstance(val, (float, np.floating)):
                val = f"{val:,.2f}"

            bg = "background:#f8fafc" if i % 2 else ""
            rows_html += (
                f'<tr style="{bg}">'
                f'<td style="padding:4px 8px;color:#64748b;white-space:nowrap">'
                f'{html_lib.escape(str(col))}</td>'
                f'<td style="padding:4px 8px">'
                f'{html_lib.escape(str(val))}</td></tr>')

        return f"""
        <div style="font-family:'Malgun Gothic',sans-serif;width:220px">
          <div style="background:{color};color:white;padding:8px 10px;
                      border-radius:4px 4px 0 0;font-weight:bold;font-size:13px">
            {title}</div>
          <table style="width:100%;font-size:12px;border-collapse:collapse">
            {rows_html}</table>
        </div>"""

    def build_tooltip(row):
        cols = tooltip_cols or [name_col]
        parts = [str(row[c]) for c in cols if c in row.index and pd.notna(row[c])]
        return html_lib.escape(" · ".join(parts))

    # ══════════ ⑤ 지도 ══════════
    center = [work[lat_col].mean(), work[lng_col].mean()]
    m = folium.Map(location=center, zoom_start=7, tiles=tiles,
                   control_scale=True)

    # ══════════ ⑥ 마커 ══════════
    if layer_by and layer_by in work.columns:
        groups = {}
        for key, sub in work.groupby(layer_by):
            groups[key] = folium.FeatureGroup(name=f"{key} ({len(sub)})")
    else:
        groups = {None: m}

    for _, row in work.iterrows():
        target = (groups.get(row[layer_by]) if layer_by and layer_by in row.index
                  else groups.get(None, m))

        folium.CircleMarker(
            [float(row[lat_col]), float(row[lng_col])],
            radius=float(row["_radius"]),
            tooltip=build_tooltip(row),
            popup=folium.Popup(build_popup(row), max_width=250),
            color=row["_color"], weight=1.5,
            fill=True, fill_color=row["_color"], fill_opacity=0.65,
        ).add_to(target)

    for key, group in groups.items():
        if key is not None:
            group.add_to(m)

    if layer_by:
        folium.LayerControl(collapsed=False).add_to(m)

    # ══════════ ⑦ 범례 ══════════
    if color_map:
        items = "".join(
            f'<div style="margin:3px 0;white-space:nowrap">'
            f'<span style="display:inline-block;width:12px;height:12px;'
            f'background:{color};border-radius:50%;margin-right:6px;'
            f'vertical-align:middle"></span>'
            f'<span style="font-size:12px">{html_lib.escape(cat)}</span></div>'
            for cat, color in color_map.items())

        size_note = (f'<div style="font-size:11px;color:#94a3b8;'
                     f'margin-top:6px;border-top:1px solid #e2e8f0;'
                     f'padding-top:5px">원 크기 = {size_by}</div>'
                     if size_by else "")

        legend = f"""
        <div style="position:fixed;bottom:24px;left:24px;z-index:9999;
                    background:white;padding:10px 14px;border-radius:6px;
                    box-shadow:0 2px 8px rgba(0,0,0,.2);
                    font-family:'Malgun Gothic',sans-serif">
          <div style="font-weight:bold;font-size:13px;margin-bottom:6px">
            {html_lib.escape(str(color_by))}</div>
          {items}{size_note}
        </div>"""

        m.get_root().html.add_child(folium.Element(legend))

    # ══════════ ⑧ 화면 맞추기 ══════════
    m.fit_bounds([[work[lat_col].min(), work[lng_col].min()],
                  [work[lat_col].max(), work[lng_col].max()]],
                 padding=(30, 30))

    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)
        m.save(str(save_path))

    if verbose:
        print("=" * 74)
        print("                      지도 생성 완료")
        print("=" * 74)
        print(f"\n  마커      : {len(work):,}개"
              f"{f' (좌표 무효 {dropped}건 제외)' if dropped else ''}")
        print(f"  타일      : {tiles}")
        print(f"  중심      : ({center[0]:.4f}, {center[1]:.4f})")

        if color_by:
            print(f"  색 구분   : {color_by} ({len(categories)}개 범주)")
        if size_by:
            print(f"  크기      : {size_by}"
                  f"{' (로그 변환)' if use_log_size else ''}")
        if layer_by:
            print(f"  레이어    : {layer_by} ({len(groups)}개)")

        if len(work) > 1500:
            print(f"\n  ⚠ 마커가 {len(work):,}개입니다 — 브라우저가 느려질 수 있습니다")
            print(f"    MarkerCluster (Day 068) 또는 상위 N개 필터를 검토하세요")

        if save_path:
            print(f"\n  저장      : {save_path}")

        print("=" * 74)

    return m


# ══════════ 사용 ══════════
if __name__ == "__main__":
    df_to_map(
        df,
        color_by="category",
        size_by="visitors",
        layer_by="category",
        popup_cols=["region", "category", "rating", "price", "visitors"],
        tooltip_cols=["name", "rating"],
        save_path="output/maps/auto_map.html",
    )
```

| # | 처리 | 이유 |
|---|---|---|
| ① | 유효 좌표 필터 | `NaN` 하나로 지도가 깨짐 |
| ② | 색 자동 배정 | 색약 안전 팔레트 순환 |
| ③ | **로그 크기 변환** | 극단값 대응 ⭐ |
| ④ | 팝업 표 자동 생성 | 숫자 서식·이스케이프 포함 |
| ⑤ | 툴팁 | 훑어보기 |
| ⑥ | 레이어 그룹 | on/off 컨트롤 |
| ⑦ | **범례 자동 생성** | 색이 뭘 뜻하는지 ⭐ |
| ⑧ | `fit_bounds` | 줌 추측 불필요 |

> 함수에 넣어 두면 빠뜨릴 수 없습니다.
>
> **마커 1,500개 초과 시 경고**를 넣은 것도 의도적입니다.
> 저장은 되지만 **브라우저에서 열 때 문제**가 생기므로 미리 알려 줍니다.

```python
"""folium 지도 품질 검사."""

import re
from pathlib import Path


def audit_map(m=None, html_path=None, df=None,
              lat_col="lat", lng_col="lng", verbose=True):
    """
    folium 지도의 완성도를 검사합니다.

    m         : folium.Map 객체
    html_path : 저장된 HTML 경로
    df        : 원본 데이터 (비교용)
    """
    issues = []

    if html_path and Path(html_path).exists():
        html = Path(html_path).read_text(encoding="utf-8")
        size_kb = Path(html_path).stat().st_size / 1024
    elif m is not None:
        html = m.get_root().render()
        size_kb = len(html.encode("utf-8")) / 1024
    else:
        raise ValueError("m 또는 html_path 중 하나가 필요합니다")

    line = "=" * 78

    if verbose:
        print(line)
        print("                        지도 품질 검사")
        print(line)

    # ══════════ ① 크기 ══════════
    if verbose:
        print(f"\n[① 파일]")
        print(f"  크기 : {size_kb:,.1f} KB")

    if size_kb > 8000:
        issues.append(("치명", f"파일 {size_kb/1024:.1f}MB — "
                               f"브라우저가 열지 못할 수 있음"))
    elif size_kb > 3000:
        issues.append(("경고", f"파일 {size_kb:,.0f}KB — "
                               f"로딩이 느림. 클러스터링 검토"))

    # ══════════ ② 마커 개수 ══════════
    n_circle = len(re.findall(r"L\.circleMarker\(", html))
    n_marker = len(re.findall(r"L\.marker\(", html))
    n_circle_m = len(re.findall(r"L\.circle\(", html))
    total = n_circle + n_marker

    if verbose:
        print(f"\n[② 마커]")
        print(f"  CircleMarker : {n_circle:,}")
        print(f"  Marker       : {n_marker:,}")
        print(f"  Circle       : {n_circle_m:,}")
        print(f"  합계         : {total:,}")

    if total == 0:
        issues.append(("치명", "마커가 하나도 없음"))
    elif total > 2000:
        issues.append(("경고", f"마커 {total:,}개 — "
                               f"MarkerCluster 사용 권장 (Day 068)"))

    if n_marker > 500:
        issues.append(("경고", f"Marker(핀) {n_marker}개 — "
                               f"CircleMarker 가 더 가벼움"))

    # ══════════ ③ 데이터 대비 누락 ══════════
    if df is not None:
        expected = df[lat_col].notna().sum() if lat_col in df.columns else len(df)
        if total < expected * 0.9:
            issues.append(("경고", f"데이터 {expected}건 중 {total}개만 표시 "
                                   f"— 좌표 결측 확인"))
        if verbose:
            print(f"  원본 대비    : {total}/{expected} "
                  f"({total/max(expected,1)*100:.0f}%)")

    # ══════════ ④ 필수 요소 ══════════
    checks = {
        "툴팁": (r"bindTooltip", "마우스만 올려도 정보가 보이게"),
        "팝업": (r"bindPopup", "클릭 시 상세 정보"),
        "범례": (r"position:\s*fixed|position:fixed", "색이 뭘 뜻하는지"),
        "축척": (r"L\.control\.scale", "거리 감각"),
        "레이어 컨트롤": (r"L\.control\.layers", "선택적 표시"),
        "fit_bounds": (r"fitBounds", "모든 마커가 보이게"),
    }

    if verbose:
        print(f"\n[③ 요소]")

    for name, (pattern, why) in checks.items():
        found = bool(re.search(pattern, html))

        if verbose:
            print(f"  {'✓' if found else '✗'} {name:<14}{why}")

        if not found:
            level = "경고" if name in ("툴팁", "범례", "fit_bounds") else "권장"
            issues.append((level, f"{name} 없음 — {why}"))

    # ══════════ ⑤ 타일 ══════════
    tile_match = re.search(r'tiles?["\s:]+.*?(openstreetmap|cartodb|stamen)',
                           html, re.I)
    tile_name = tile_match.group(1).lower() if tile_match else "?"

    has_attr = bool(re.search(r'attribution', html, re.I))

    if verbose:
        print(f"\n[④ 타일]")
        print(f"  종류 : {tile_name}")
        print(f"  저작권 표기 : {'✓' if has_attr else '✗'}")

    if not has_attr:
        issues.append(("경고", "저작권 표기(attribution) 없음"))

    # ══════════ ⑥ 좌표 타당성 ══════════
    coords = re.findall(r"\[([-\d.]+),\s*([-\d.]+)\]", html)
    korea_coords = 0
    suspicious = 0

    for a, b in coords[:2000]:
        try:
            lat, lng = float(a), float(b)
        except ValueError:
            continue

        if 33 <= lat <= 39 and 124 <= lng <= 132:
            korea_coords += 1
        elif 33 <= lng <= 39 and 124 <= lat <= 132:
            suspicious += 1

    if verbose:
        print(f"\n[⑤ 좌표]")
        print(f"  한국 범위    : {korea_coords:,}개")
        if suspicious:
            print(f"  ⚠ 뒤바뀜 의심 : {suspicious:,}개")

    if suspicious > korea_coords * 0.1:
        issues.append(("치명", f"위경도가 뒤바뀐 좌표 {suspicious}개 의심"))

    # ══════════ ⑦ HTML 안전성 ══════════
    unescaped = len(re.findall(r"<script[^>]*>(?!.*leaflet|.*folium)",
                               html, re.I))
    if verbose:
        print(f"\n[⑥ 안전성]")
        print(f"  팝업 이스케이프 : "
              f"{'확인 필요' if '&lt;' not in html else '✓ (escape 흔적 있음)'}")

    # ══════════ 결과 ══════════
    fatal = sum(1 for l, _ in issues if l == "치명")
    warn = sum(1 for l, _ in issues if l == "경고")
    rec = sum(1 for l, _ in issues if l == "권장")

    score = max(0, 100 - fatal * 30 - warn * 10 - rec * 4)

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 제출 가능" if score >= 85
                 else "🟡 보완 권장" if score >= 65 else "❌ 재작업")
        print(f"  완성도: {score}점 / 100   {grade}")
        print(line)

        for level, msg in issues:
            icon = {"치명": "🔴", "경고": "🟡", "권장": "🔵"}[level]
            print(f"  {icon} {msg}")

        if not issues:
            print("  문제 없음")

        print(f"\n  [체크리스트]")
        for item in [
            "브라우저에서 실제로 열어 봤는가",
            "마커를 클릭해 팝업이 제대로 나오는가",
            "한글이 깨지지 않는가",
            "범례의 색과 실제 마커 색이 일치하는가",
            "확대·축소가 부드러운가",
        ]:
            print(f"    □ {item}")

        print(line)

    return {"score": score, "issues": issues, "markers": total,
            "size_kb": round(size_kb, 1)}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    print(">>> 기본 지도\n")
    audit_map(html_path="output/maps/spots_circles.html", df=df)

    print("\n\n>>> 요소가 빠진 지도\n")
    bad = folium.Map(location=[37.5, 127], zoom_start=15)
    for _, r in df.head(30).iterrows():
        folium.Marker([r["lat"], r["lng"]]).add_to(bad)
    audit_map(m=bad, df=df.head(30))
```

| ① | 파일 크기 | 마커 과다 → 브라우저 정지 |

| ⑥ | HTML 안전성 | 이스케이프 누락 |

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 타일 | 256px 이미지 격자 · 줌 +1 = 타일 4배 |
| 줌 레벨 | **7=한반도 · 11=도시 · 14=구** |
| 지도 생성 | `folium.Map(location=[위도, 경도], zoom_start=, tiles=)` |
| 타일 선택 | 데이터가 주인공이면 **`CartoDB positron`** |
| 마커 | `Marker`(핀) · **`CircleMarker`**(픽셀) · `Circle`(미터) |
| **색** | `Icon` 은 정해진 색만 · **hex 는 `CircleMarker`** |
| 팝업 | `folium.Popup(html, max_width=)` · **`html.escape` 필수** |
| 툴팁 | 훑어보기용 — 이름·핵심 지표 |
| 레이어 | `FeatureGroup` + **`LayerControl`** |
| **화면** | **`fit_bounds([[남서], [북동]])`** |
| 저장 | `m.save("map.html")` — **HTML 하나로 완결** |
| 성능 | 2,000개 넘으면 클러스터 ([Day 068](day-068.md)) |

**오늘 반드시 기억할 세 가지**
> ① **`location=[위도, 경도]`** 입니다. 바꾸면 남극이 나옵니다.
> ② **`fit_bounds` 를 쓰세요.** `zoom_start` 를 추측할 필요가 없어집니다.
> ③ **툴팁과 범례를 넣으세요.** 없으면 마커를 하나씩 클릭해야 하고, 색의 뜻을 모릅니다.

**과제**
① 지오코딩한 데이터([Day 066](day-066.md)) 전체를 **마커로 표시한 지도 HTML** 제작
② **카테고리별 마커 색**을 다르게 하고 **범례** 추가
③ 팝업에 **이름·평점·가격** 이상을 표로 표시
④ 툴팁 + `fit_bounds` + 축척 적용
⑤ 특정 지점 **반경 5·10·20km 원**을 그린 지도 1개 추가 제작
