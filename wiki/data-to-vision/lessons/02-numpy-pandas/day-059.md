## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

## ② 왜 필요한가

수집 데이터에는 날짜가 **문자열**로 들어 있습니다.

```python
df["modified"].head()
```

```
0    20250114104348
1    20240823091200
```

이 상태로는 아무것도 못 합니다.

```python
df[df["modified"] > "2025-01-01"]     # 문자열 비교 — 우연히 맞을 수도, 틀릴 수도
df["modified"].dt.year                # AttributeError
df.resample("ME")                     # 안 됨
```

`datetime` 으로 바꾸는 순간 **전부 열립니다.**

```python
df["modified"] = pd.to_datetime(df["modified"], format="%Y%m%d%H%M%S")

df["modified"].dt.year                       # 2025
df["modified"].dt.day_name()                 # 'Tuesday'
df.set_index("modified").resample("ME").size()   # 월별 건수
df["modified"].max() - df["modified"].min()  # 기간
```

**범주형도 마찬가지입니다.**

```python
df["price"].describe()      # 평균 14,846원 — 그래서?
```

숫자 그대로는 해석하기 어렵습니다. **구간으로 나누면 말이 됩니다.**

```
무료(0원)          312곳   28%
저가(~5천원)       401곳   36%
중가(~1만5천원)    287곳   26%
고가(1만5천원~)    112곳   10%
```

> **"평균 14,846원"보다 "36%가 5천원 이하"가 훨씬 유용합니다.**
> 오늘 배우는 것은 **숫자를 의미로 바꾸는 일**입니다.

## 1부 · 날짜

### `to_datetime` — 변환

```python
pd.to_datetime(s)                                  # 자동 추론
pd.to_datetime(s, format="%Y-%m-%d")               # 형식 지정 ⭐
pd.to_datetime(s, errors="coerce")                 # 실패는 NaT ⭐
pd.to_datetime(s, format="ISO8601")                # ISO 형식
pd.to_datetime(s, format="mixed")                  # 행마다 형식이 다를 때
pd.to_datetime(s, dayfirst=True)                   # 05/03 → 3월 5일
pd.to_datetime(s, unit="s")                        # 유닉스 타임스탬프
```

**형식 문자열**

| 코드 | 의미 | 예 |
|---|---|---|
| `%Y` | 4자리 연도 | 2026 |
| `%y` | 2자리 연도 | 26 |
| `%m` | 월 (01~12) | 08 |
| `%d` | 일 | 08 |
| `%H` | 시 (24시간) | 14 |
| `%M` | 분 | 30 |
| `%S` | 초 | 00 |
| `%p` | AM/PM | PM |

```python
pd.to_datetime("20250114104348", format="%Y%m%d%H%M%S")
pd.to_datetime("2026년 8월 8일", format="%Y년 %m월 %d일")
pd.to_datetime("08/08/2026 02:30 PM", format="%m/%d/%Y %I:%M %p")
```

> ⚠️ **`format` 을 지정하면 10배 이상 빠릅니다.**
> 지정하지 않으면 pandas 가 **행마다 형식을 추측**합니다.
> 100만 행이면 체감 차이가 큽니다.

> ⚠️ **`errors="coerce"` 를 습관처럼 붙이세요.**
> ```python
> pd.to_datetime(["2026-08-08", "없음"])
> # DateParseError — 한 건 때문에 전체가 실패
>
> pd.to_datetime(["2026-08-08", "없음"], errors="coerce")
> # [2026-08-08, NaT]  ✅
> ```

```python
pd.to_datetime("03/05/2026")                  # 3월 5일 (미국식, 기본)
pd.to_datetime("03/05/2026", dayfirst=True)   # 5월 3일 (유럽식)
```

데이터만 보고는 알 수 없습니다. **출처 문서를 확인해야 합니다.**

### `dt` 접근자 — 성분 추출

```python
s.dt.year      s.dt.month     s.dt.day
s.dt.hour      s.dt.minute    s.dt.second
s.dt.quarter                          # 분기 (1~4)
s.dt.dayofweek                        # 월=0 ... 일=6  ⭐

s.dt.is_quarter_end   s.dt.is_year_end
s.dt.date      s.dt.time
s.dt.to_period("M")                   # 2026-08 (기간)
```

**한글 요일**

```python
WEEKDAY_KO = ["월", "화", "수", "목", "금", "토", "일"]

df["weekday"] = df["date"].dt.dayofweek.map(lambda i: WEEKDAY_KO[i])
df["is_weekend"] = df["date"].dt.dayofweek >= 5
```

### 기간 계산 — `Timedelta`

```python
df["days"] = (df["end"] - df["start"]).dt.days
df["hours"] = (df["end"] - df["start"]).dt.total_seconds() / 3600

df["date"] + pd.Timedelta(days=7)
df["date"] + pd.DateOffset(months=1)      # 월 단위 (말일 처리 자동)
df["date"] - pd.Timestamp("2026-01-01")
```

| | `Timedelta` | `DateOffset` |
|---|---|---|
| 단위 | 일·시·분·초 (**고정 길이**) | 월·연 (**달력 기준**) |
| `+ 1개월` | ❌ (월은 길이가 다름) | ✅ |

```python
pd.Timestamp("2026-01-31") + pd.DateOffset(months=1)   # 2026-02-28 ✅
pd.Timestamp("2026-01-31") + pd.Timedelta(days=30)     # 2026-03-02
```

```python
s.dt.tz_localize("Asia/Seoul")           # 시간대 정보 부여
```

### `resample` — 시간 단위 집계

**날짜를 인덱스로 만든 뒤** 사용합니다.

```python
ts = df.set_index("date")

ts.resample("D").size()          # 일별 건수
ts.resample("W").sum()           # 주별 합계
ts.resample("ME").mean()         # 월별 평균
ts.resample("QE").sum()          # 분기별
ts.resample("YE").max()          # 연별
ts.resample("h").count()         # 시간별
```

**빈도 문자열**

| 코드 | 의미 |
|---|---|
| `D` | 일 |
| `W` | 주 (일요일 기준) |
| `W-MON` | 주 (월요일 기준) |
| **`ME`** | 월말 |
| `MS` | 월초 |
| **`QE`** | 분기말 |
| **`YE`** | 연말 |
| `h` | 시간 |
| `min` | 분 |

> ⚠️ **pandas 2.2 부터 별칭이 바뀌었습니다.**
> ```
> FutureWarning: 'M' is deprecated and will be removed... use 'ME' instead
> ```
> | 예전 | 지금 |
> |---|---|
> | `M` | **`ME`** |
> | `Q` | **`QE`** |
> | `Y` / `A` | **`YE`** |
> | `H` | **`h`** |
> | `T` | **`min`** |
> | `S` | **`s`** |

**여러 집계를 한 번에**

```python
ts.resample("ME").agg({
    "visitors": ["sum", "mean", "max"],
    "price": "median",
    "id": "count",
})
```

**`groupby` 와의 차이**

```python
df.groupby(df["date"].dt.to_period("M")).size()   # 데이터가 있는 달만
ts.resample("ME").size()                           # 없는 달도 0으로 채움 ⭐
```

> **추이를 볼 때는 `resample`** 이 맞습니다.
> 데이터가 없는 달이 빠지면 **그래프에서 선이 이어져 버려** 착시가 생깁니다.

### 이동·비교

```python
ts["visitors"].shift(1)                    # 한 칸 밀기 (전날 값)
ts["visitors"].diff()                       # 전날 대비 차이
ts["visitors"].pct_change() * 100           # 전날 대비 증감률(%)
ts["visitors"].rolling(7).mean()            # 7일 이동평균 ⭐
ts["visitors"].rolling(7, min_periods=1).mean()
ts["visitors"].cumsum()                     # 누적합
```

> **이동평균은 요일 변동을 걷어냅니다.**
> 방문객 수는 주말에 튀기 마련입니다. **7일 이동평균**을 보면 진짜 추세가 보입니다.

## 2부 · 범주형

### `cut` — 값 기준으로 나누기

```python
pd.cut(df["price"], bins=4)                          # 등간격 4구간
pd.cut(df["price"], bins=[0, 5000, 15000, 50000])    # 직접 지정 ⭐
pd.cut(df["price"], bins=[...], labels=["저", "중", "고"])
pd.cut(df["price"], bins=[...], right=False)         # [a, b) 형태
pd.cut(df["price"], bins=[...], include_lowest=True) # 최솟값 포함
```

```python
BINS = [-1, 0, 5000, 15000, 50000, float("inf")]
LABELS = ["무료", "저가", "중가", "고가", "최고가"]

df["price_grade"] = pd.cut(df["price"], bins=BINS, labels=LABELS)
```

> ⚠️ **경계값 처리를 조심하세요.**
> 기본은 `(a, b]` — **왼쪽 열림, 오른쪽 닫힘**입니다.
> `bins=[0, 5000]` 이면 **0원은 어디에도 안 들어갑니다** (`NaN`).
>
> **해결**
> ```python
> bins=[-1, 0, 5000, ...]            # 시작을 -1 로
> include_lowest=True                # 최솟값 포함
> right=False                        # [a, b) 로 바꿈
> ```

### `qcut` — 개수 기준으로 나누기

```python
pd.qcut(df["price"], q=4)                            # 4분위
pd.qcut(df["price"], q=5, labels=["1등급", ..., "5등급"])
pd.qcut(df["price"], q=[0, 0.5, 0.9, 1.0])           # 백분위 직접 지정
pd.qcut(df["price"], q=4, duplicates="drop")         # 경계 중복 허용
```

**각 구간에 같은 개수가 들어갑니다.**

| | `cut` | `qcut` |
|---|---|---|
| 기준 | **값의 범위** | **개수(백분위)** |
| 각 구간 크기 | 다름 | **같음** |
| 쓸 때 | 의미 있는 경계가 있을 때 | 상대적 등급을 매길 때 |

```
가격: [0, 100, 200, 300, 10000]

cut(bins=2)   →  [0~5000]에 4개,  [5000~10000]에 1개
qcut(q=2)     →  각각 2~3개씩
```

> ⚠️ **`qcut` 은 같은 값이 많으면 실패합니다.**
> ```
> ValueError: Bin edges must be unique
> ```
> 무료(0원)가 30%면 경계가 겹칩니다. **`duplicates="drop"`** 을 쓰거나 `cut` 을 쓰세요.

### `Categorical` — 순서가 있는 범주

```python
df["grade"] = pd.Categorical(
    df["grade"],
    categories=["저가", "중가", "고가"],
    ordered=True,
)
```

**순서를 주면 비교와 정렬이 됩니다.**

```python
df[df["grade"] > "저가"]                  # 중가·고가만
df.sort_values("grade")                    # 저가 → 중가 → 고가 순
df.groupby("grade", observed=True).size()  # 정의한 순서대로 나옴 ⭐
```

**순서가 없으면 가나다순으로 정렬됩니다.**

```
문자열   : 고가, 저가, 중가        ← 가나다순 (의미 없음)
Categorical: 저가, 중가, 고가      ← 정의한 순서  ✅
```

| 장점 | 설명 |
|---|---|
| **정렬·비교** | 의미 있는 순서 |
| **메모리 절약** | 반복되는 문자열을 코드로 저장 |
| **groupby 순서** | 정의 순서 유지 |

> ⚠️ **pandas 2.x 에서 `groupby` 에 `observed` 를 지정하세요.**
> ```
> FutureWarning: The default of observed=False is deprecated
> ```
> `observed=True` — 실제로 나타난 범주만 (기본이 될 예정)
> `observed=False` — 정의된 모든 범주 (안 나온 것도 0으로)

### `map` — 라벨링

```python
CONTENT_TYPES = {12: "관광지", 14: "문화시설", 39: "음식점"}

df["type_name"] = df["type_id"].map(CONTENT_TYPES)
df["type_name"] = df["type_id"].map(CONTENT_TYPES).fillna("기타")
```

| 함수 | 대상 | 없는 키 |
|---|---|---|
| `map` | Series | **`NaN`** |
| `replace` | Series/DataFrame | **원래 값 유지** |

```python
s.map({1: "A"})        # 2 → NaN
s.replace({1: "A"})    # 2 → 2
```

> **라벨링에는 `map` 이 낫습니다.** 사전에 없는 값이 `NaN` 으로 드러나기 때문입니다.
> `replace` 를 쓰면 **누락된 코드를 영영 발견하지 못합니다.**

## ④ 단계별 실습

### Step 1. 날짜 변환의 함정

```python
"""여러 형식의 날짜를 안전하게 변환합니다."""

import numpy as np
import pandas as pd

raw = pd.Series([
    "2026-08-08",
    "2026/08/09",
    "2026.08.10",
    "20260811",
    "2026년 8월 12일",
    "08/13/2026",
    "13/08/2026",
    "2026-08-14 15:30:00",
    "2026-08-15T09:00:00Z",
    "없음",
    "",
    None,
])

print("=" * 76)
print("                    날짜 변환 진단")
print("=" * 76)

# ══════════ ① 무작정 변환 ══════════
print(f"\n[① errors 기본값 — 하나만 틀려도 전체 실패]")
try:
    pd.to_datetime(raw)
    print("  성공")
except Exception as e:
    print(f"  ✗ {type(e).__name__}: {str(e)[:70]}")

# ══════════ ② coerce ══════════
print(f"\n[② errors='coerce' — 실패는 NaT]")

converted = pd.to_datetime(raw, errors="coerce", format="mixed")

print(f"  {'원본':<26}{'변환 결과':<24}")
print("  " + "-" * 52)
for orig, conv in zip(raw, converted):
    mark = "✗" if pd.isna(conv) else " "
    print(f" {mark}{str(orig)!r:<26}{str(conv):<24}")

print(f"\n  성공 {converted.notna().sum()}/{len(raw)}건 · "
      f"실패 {converted.isna().sum()}건")

# ══════════ ③ 형식별로 나눠 변환 ══════════
print(f"\n[③ 형식을 나눠서 정확하게]")

FORMATS = [
    ("%Y-%m-%d %H:%M:%S", r"^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$"),
    ("%Y-%m-%d",          r"^\d{4}-\d{2}-\d{2}$"),
    ("%Y/%m/%d",          r"^\d{4}/\d{2}/\d{2}$"),
    ("%Y.%m.%d",          r"^\d{4}\.\d{2}\.\d{2}$"),
    ("%Y%m%d",            r"^\d{8}$"),
    ("%Y년 %m월 %d일",     r"^\d{4}년 \d{1,2}월 \d{1,2}일$"),
]

result = pd.Series(pd.NaT, index=raw.index, dtype="datetime64[ns]")
s = raw.astype("string").str.strip()

for fmt, pattern in FORMATS:
    mask = s.str.match(pattern, na=False) & result.isna()
    if mask.any():
        result[mask] = pd.to_datetime(s[mask], format=fmt, errors="coerce")
        print(f"  {fmt:<22}{mask.sum()}건")

leftover = s[result.isna() & s.notna()]
if len(leftover):
    print(f"  {'분류 안 됨':<22}{len(leftover)}건: {leftover.tolist()}")

print(f"\n  성공 {result.notna().sum()}/{len(raw)}건")

# ══════════ ④ 날짜 순서 모호성 ══════════
print(f"\n[④ 08/13 vs 13/08 — 어느 쪽이 월인가]")

ambiguous = pd.Series(["08/13/2026", "13/08/2026", "05/06/2026"])
first = ambiguous.str.split("/").str[0].astype(int)

print(f"  첫 숫자: {first.tolist()}")
print(f"  13 이상 존재: {(first > 12).any()}  "
      f"→ {'일이 앞 (dayfirst=True)' if (first > 12).any() else '판단 불가'}")

print(f"\n  {'원본':<16}{'기본(월 먼저)':<22}{'dayfirst=True':<22}")
print("  " + "-" * 58)
for v in ambiguous:
    a = pd.to_datetime(v, errors="coerce", format="mixed")
    b = pd.to_datetime(v, errors="coerce", format="mixed", dayfirst=True)
    print(f"  {v:<16}{str(a.date()) if pd.notna(a) else 'NaT':<22}"
          f"{str(b.date()) if pd.notna(b) else 'NaT':<22}")

print(f"\n  ⚠ '05/06/2026' 은 두 해석 모두 유효합니다. 출처 확인 필수.")

# ══════════ ⑤ 시간대 ══════════
print(f"\n[⑤ 시간대 — UTC vs 한국시간]")

utc_times = pd.to_datetime(
```

```python
"""방문 로그를 요일·시간대별로 집계합니다."""

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
N = 3000

# ── 실습 데이터: 방문 로그 ──
base = pd.Timestamp("2026-01-01")
minutes = rng.integers(0, 365 * 24 * 60, N)

log = pd.DataFrame({
    "visit_id": range(1, N + 1),
    "visited_at": base + pd.to_timedelta(minutes, unit="m"),
    "spot": rng.choice(["경복궁", "남산타워", "북촌", "청계천", "창덕궁"], N),
    "party": rng.integers(1, 6, N),
})

# 주말·낮 시간에 방문이 몰리도록 가중치 반영
weekend_boost = rng.random(N) < 0.35
log.loc[weekend_boost, "visited_at"] += pd.to_timedelta(
    (5 - log.loc[weekend_boost, "visited_at"].dt.dayofweek) % 7, unit="D")

hour_shift = rng.normal(0, 3, N).astype(int)
log["visited_at"] = (log["visited_at"].dt.normalize()
                     + pd.to_timedelta(np.clip(13 + hour_shift, 6, 21), unit="h")
                     + pd.to_timedelta(rng.integers(0, 60, N), unit="m"))

log = log.sort_values("visited_at").reset_index(drop=True)

# ══════════ 성분 추출 ══════════
WEEKDAY_KO = ["월", "화", "수", "목", "금", "토", "일"]

d = log["visited_at"].dt

log["year"] = d.year
log["month"] = d.month
log["day"] = d.day
log["hour"] = d.hour
log["weekday_no"] = d.dayofweek
log["weekday"] = d.dayofweek.map(lambda i: WEEKDAY_KO[i])
log["is_weekend"] = d.dayofweek >= 5
log["quarter"] = d.quarter
log["week"] = d.isocalendar().week
log["date"] = d.date

print("=" * 78)
print("                     시간 성분 집계")
print("=" * 78)

print(f"\n[데이터] {len(log):,}건  "
      f"{log['visited_at'].min():%Y-%m-%d} ~ {log['visited_at'].max():%Y-%m-%d}")

# ══════════ ① 요일별 ══════════
print(f"\n[① 요일별 방문]")

by_day = (log.groupby("weekday_no")
             .agg(방문=("visit_id", "count"), 평균인원=("party", "mean")))
by_day.index = [WEEKDAY_KO[i] for i in by_day.index]

top = by_day["방문"].max()
print(f"  {'요일':<6}{'방문':>7}{'비율':>8}{'평균인원':>10}  분포")
print("  " + "-" * 56)
for day, row in by_day.iterrows():
    bar = "■" * int(row["방문"] / top * 22)
    pct = row["방문"] / len(log) * 100
    mark = "★" if day in ("토", "일") else " "
    print(f" {mark}{day:<5}{row['방문']:>7,}{pct:>7.1f}%"
          f"{row['평균인원']:>10.2f}  {bar}")

weekend_rate = log["is_weekend"].mean() * 100
print(f"\n  주말 비중: {weekend_rate:.1f}% (이틀이므로 기대값 28.6%)")

# ══════════ ② 시간대별 ══════════
print(f"\n[② 시간대별 방문]")

by_hour = log.groupby("hour").size()
top = by_hour.max()

for hour, cnt in by_hour.items():
    bar = "■" * int(cnt / top * 34)
    print(f"  {hour:>2}시 │{bar} {cnt:,}")

peak = by_hour.idxmax()
print(f"\n  피크: {peak}시 ({by_hour.max():,}건)")

# ══════════ ③ 요일 × 시간대 히트맵 ══════════
print(f"\n[③ 요일 × 시간대 (텍스트 히트맵)]")

pivot = log.pivot_table(index="weekday_no", columns="hour",
                        values="visit_id", aggfunc="count", fill_value=0)

hours = sorted(log["hour"].unique())
levels = " ░▒▓█"
vmax = pivot.values.max()

print(f"      {''.join(f'{h:>2}' for h in hours)}")
for i in range(7):
    if i not in pivot.index:
        continue
    row = ""
    for h in hours:
        v = pivot.loc[i, h] if h in pivot.columns else 0
        idx = min(int(v / vmax * (len(levels) - 1)), len(levels) - 1)
        row += levels[idx] * 2
    mark = "★" if i >= 5 else " "
    print(f"  {mark}{WEEKDAY_KO[i]} │{row}")

print(f"      {'':>2}(진할수록 방문 많음)")

# ══════════ ④ 월별 추이 (resample) ══════════
print(f"\n[④ 월별 추이]")

ts = log.set_index("visited_at")
monthly = ts.resample("ME").agg(방문=("visit_id", "count"),
                                인원=("party", "sum"))
monthly["전월대비%"] = monthly["방문"].pct_change().mul(100).round(1)
monthly["이동평균3"] = monthly["방문"].rolling(3, min_periods=1).mean().round(0)

monthly.index = monthly.index.strftime("%Y-%m")

top = monthly["방문"].max()
print(f"  {'월':<10}{'방문':>7}{'인원':>8}{'전월%':>8}{'MA3':>8}  분포")
print("  " + "-" * 60)
for month, row in monthly.iterrows():
    bar = "■" * int(row["방문"] / top * 16)
    chg = f"{row['전월대비%']:+.1f}" if pd.notna(row["전월대비%"]) else "-"
    print(f"  {month:<10}{row['방문']:>7,}{row['인원']:>8,}"
          f"{chg:>8}{row['이동평균3']:>8,.0f}  {bar}")

# ══════════ ⑤ 장소별 × 주말 ══════════
print(f"\n[⑤ 장소별 주말 선호도]")

cross = pd.crosstab(log["spot"], log["is_weekend"], normalize="index") * 100
cross.columns = ["평일%", "주말%"]
cross = cross.sort_values("주말%", ascending=False).round(1)

print(f"  {'장소':<12}{'평일%':>8}{'주말%':>8}  주말 편중")
print("  " + "-" * 48)
for spot, row in cross.iterrows():
    bar = "■" * int(row["주말%"] / 2)
    print(f"  {spot:<12}{row['평일%']:>8.1f}{row['주말%']:>8.1f}  {bar}")

print("\n" + "=" * 78)
```

### Step 3. 구간화와 등급 부여 (오늘의 종합 예제)

```python
"""연속형을 의미 있는 등급으로 나눕니다."""

import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
N = 500

spots = pd.DataFrame({
    "id": range(1, N + 1),
    "name": [f"관광지{i:03d}" for i in range(1, N + 1)],
    "category": rng.choice(["자연", "역사", "체험", "쇼핑"], N),
    "price": np.concatenate([
        np.zeros(140),                                   # 무료 28%
        rng.lognormal(8.4, 0.7, N - 140).round(-2),
    ]),
    "rating": rng.normal(4.0, 0.55, N).round(1).clip(1, 5),
    "visitors": rng.lognormal(8.5, 1.2, N).round(),
    "age": rng.integers(10, 75, N),
})
spots = spots.sample(frac=1, random_state=1).reset_index(drop=True)

print("=" * 80)
print("                       구간화와 등급 부여")
print("=" * 80)

# ══════════ ① cut — 의미 있는 경계 ══════════
print(f"\n[① 가격 등급 — cut (의미 있는 경계)]")

PRICE_BINS = [-1, 0, 5_000, 15_000, 30_000, np.inf]
PRICE_LABELS = ["무료", "저가", "중가", "고가", "최고가"]

spots["price_grade"] = pd.cut(spots["price"],
                              bins=PRICE_BINS, labels=PRICE_LABELS)

grade_count = spots["price_grade"].value_counts().reindex(PRICE_LABELS)
top = grade_count.max()

print(f"  {'등급':<8}{'구간':<22}{'개수':>7}{'비율':>8}  분포")
print("  " + "-" * 62)

ranges = ["0원", "1~5,000원", "5,001~15,000원", "15,001~30,000원", "30,001원~"]
for label, rng_text in zip(PRICE_LABELS, ranges):
    cnt = grade_count[label]
    bar = "■" * int(cnt / top * 20)
    print(f"  {label:<8}{rng_text:<22}{cnt:>7}{cnt / len(spots) * 100:>7.1f}%  {bar}")

print(f"\n  ⚠ bins 시작이 -1 인 이유: 0원(무료)을 포함시키기 위해")
print(f"     bins=[0, ...] 이면 0원은 NaN 이 됩니다")

# ══════════ ② qcut — 상대 등급 ══════════
print(f"\n[② 방문객 등급 — qcut (상대 등급)]")

spots["popularity"] = pd.qcut(
    spots["visitors"], q=5,
    labels=["하위20%", "20-40%", "40-60%", "60-80%", "상위20%"])

pop = spots.groupby("popularity", observed=True).agg(
    개수=("id", "count"),
    최소=("visitors", "min"),
    최대=("visitors", "max"),
    평균=("visitors", "mean"))

print(f"  {'등급':<12}{'개수':>7}{'최소':>10}{'최대':>12}{'평균':>12}")
print("  " + "-" * 56)
for label, row in pop.iterrows():
    print(f"  {label:<12}{row['개수']:>7}{row['최소']:>10,.0f}"
          f"{row['최대']:>12,.0f}{row['평균']:>12,.0f}")

print(f"\n  ✓ 각 등급의 개수가 100개로 균등합니다 (qcut의 특징)")

# ══════════ ③ cut vs qcut 비교 ══════════
print(f"\n[③ 같은 데이터, 다른 방식]")

cut_result = pd.cut(spots["visitors"], bins=5).value_counts().sort_index()
qcut_result = pd.qcut(spots["visitors"], q=5).value_counts().sort_index()

print(f"\n  cut(bins=5) — 값 범위를 5등분")
for interval, cnt in cut_result.items():
    bar = "■" * int(cnt / cut_result.max() * 28)
    print(f"    {str(interval):<28}{cnt:>5}  {bar}")

print(f"\n  qcut(q=5) — 개수를 5등분")
for interval, cnt in qcut_result.items():
    bar = "■" * int(cnt / qcut_result.max() * 28)
    print(f"    {str(interval):<28}{cnt:>5}  {bar}")

print(f"\n  → cut 은 한 구간에 {cut_result.max()}개가 몰렸습니다 (치우친 분포)")
print(f"    qcut 은 각 100개로 균등합니다")

# ══════════ ④ 연령대 구간화 ══════════
print(f"\n[④ 연령대 — 10년 단위]")

spots["age_group"] = pd.cut(
    spots["age"],
    bins=[0, 19, 29, 39, 49, 59, 200],
    labels=["10대", "20대", "30대", "40대", "50대", "60대+"])

age_dist = spots["age_group"].value_counts().sort_index()
for label, cnt in age_dist.items():
    bar = "■" * int(cnt / age_dist.max() * 26)
    print(f"  {label:<8}{cnt:>5}  {bar}")

# ══════════ ⑤ 순서형 범주로 만들기 ══════════
print(f"\n[⑤ Categorical — 순서 부여]")
```

```python
import pandas as pd

WEEKDAY_KO = ["월", "화", "수", "목", "금", "토", "일"]

    print(f"⚠ 날짜 변환 실패 {failed}건 "
          f"({failed / len(df) * 100:.1f}%) — 원본 확인 필요")
    print(df.loc[df["date"].isna(), "created_at"].head(3).tolist())

df["date"] = df["date"].dt.tz_convert("Asia/Seoul")     # ③ KST 로

# ── ② 성분 추출 ──                                     ④⑤
d = df["date"].dt
df["hour"] = d.hour
df["weekday_no"] = d.dayofweek
df["weekday"] = d.dayofweek.map(lambda i: WEEKDAY_KO[i] if pd.notna(i) else None)
df["is_weekend"] = d.dayofweek >= 5
df["week"] = d.isocalendar().week                       # ⑤
df["month"] = d.to_period("M")

# ── ③ resample (인덱스 설정 + 새 별칭) ──              ⑥⑦

monthly = (valid.set_index("date")                       # ⑥
                .resample("ME")                          # ⑦
                .agg(건수=("price", "size"),
                     매출=("price", "sum")))

monthly["전월대비%"] = monthly["건수"].pct_change().mul(100).round(1)

print(f"\n[월별 추이]")
print(monthly.to_string())

# ── ④ 구간화 (경계 + 순서 + observed) ──               ⑧
BINS = [-np.inf, 0, 10_000, 50_000, np.inf]              # ⑧ 0원 포함

# 구간 밖(결측) 확인
unclassified = df["grade"].isna().sum() - df["price"].isna().sum()
if unclassified > 0:

print(f"\n[등급 분포]")
```

```python
"""시계열 데이터 품질 검사."""

import numpy as np
import pandas as pd


def check_timeseries(df, time_col, expected_freq=None, verbose=True):
    """
    시계열 품질을 점검합니다.

    expected_freq : 'D', 'h', 'ME' 등. None 이면 자동 추정
    """
    issues = []
    s = df[time_col]

    line = "=" * 78

    if verbose:
        print(line)
        print(f"                시계열 품질 검사 — {time_col}")
        print(line)

    # ══════════ ① 타입 ══════════
    if not pd.api.types.is_datetime64_any_dtype(s):
        issues.append(("치명", f"'{time_col}' 이 datetime 이 아님 ({s.dtype})"))
        if verbose:
            print(f"\n  ✗ 타입: {s.dtype} — to_datetime 변환 필요")
            print(line)
        return {"passed": False, "issues": issues}

    valid = s.dropna()

    if verbose:
        print(f"\n[① 기본]")
        print(f"  전체      : {len(s):,}건")
        print(f"  유효      : {len(valid):,}건")
        print(f"  결측(NaT) : {s.isna().sum():,}건")
        print(f"  기간      : {valid.min()} ~ {valid.max()}")
        print(f"  시간대    : {valid.dt.tz or '없음 (naive)'}")

    if s.isna().any():
        pct = s.isna().mean() * 100
        level = "치명" if pct > 20 else "경고"
        issues.append((level, f"NaT {s.isna().sum()}건 ({pct:.1f}%)"))

    if valid.dt.tz is None:
        issues.append(("경고", "시간대 정보 없음 — UTC/KST 확인 필요"))

    if len(valid) < 2:
        return {"passed": False, "issues": issues}

    # ══════════ ② 정렬 ══════════
    is_sorted = valid.is_monotonic_increasing

    if verbose:
        print(f"\n[② 정렬]")
        print(f"  오름차순  : {'✓' if is_sorted else '✗ 정렬 필요'}")

    if not is_sorted:
        issues.append(("경고", "시간순 정렬이 안 됨 — sort_values 필요"))

    # ══════════ ③ 중복 시각 ══════════
    dup = valid.duplicated().sum()

    if verbose:
        print(f"\n[③ 중복 시각]")
        print(f"  중복      : {dup:,}건")

        if dup:
            worst = valid.value_counts().head(3)
            for t, n in worst.items():
                print(f"    {t} — {n}건")

    if dup:
        level = "경고" if dup / len(valid) < 0.1 else "치명"
        issues.append((level, f"중복 시각 {dup}건"))

    # ══════════ ④ 간격 분석 ══════════
    sorted_s = valid.sort_values()
    gaps = sorted_s.diff().dropna()

    if len(gaps) == 0:
        return {"passed": not any(i[0] == "치명" for i in issues), "issues": issues}

    mode_gap = gaps.mode()[0] if len(gaps.mode()) else gaps.median()

    if verbose:
        print(f"\n[④ 간격]")
        print(f"  최빈 간격 : {mode_gap}")
        print(f"  중앙값    : {gaps.median()}")
        print(f"  최소      : {gaps.min()}")
        print(f"  최대      : {gaps.max()}")

    # 최빈 간격의 3배 이상 = 누락 구간
    threshold = mode_gap * 3
    big_gaps = gaps[gaps > threshold]

    if verbose:
        print(f"\n[⑤ 누락 의심 구간]  (최빈 간격의 3배 초과)")

        if len(big_gaps):
            print(f"  {len(big_gaps)}개 발견")
            for idx in big_gaps.nlargest(5).index:
                pos = sorted_s.index.get_loc(idx)
                prev = sorted_s.iloc[pos - 1]
                print(f"    {prev} → {sorted_s.loc[idx]}  "
                      f"({big_gaps[idx]} 공백)")
        else:
            print("  없음")

    if len(big_gaps):
        issues.append(("경고", f"누락 의심 구간 {len(big_gaps)}개 "
                               f"(최대 {big_gaps.max()})"))

    # ══════════ ⑥ 기대 빈도 대비 ══════════
    if expected_freq:
        full_range = pd.date_range(valid.min(), valid.max(), freq=expected_freq)
        actual = set(valid.dt.floor(
            expected_freq.lower().replace("e", "")
            if expected_freq[-1] == "E" else expected_freq))
        missing = [t for t in full_range if t not in actual]

        if verbose:
            print(f"\n[⑥ 기대 빈도 '{expected_freq}' 대비]")
            print(f"  기대 : {len(full_range):,}개 시점")
            print(f"  실제 : {len(actual):,}개 시점")
            print(f"  누락 : {len(missing):,}개 "
                  f"({len(missing) / len(full_range) * 100:.1f}%)")

            if missing:
                print(f"  예시 : {[str(t.date()) for t in missing[:5]]}")

        if missing:
            pct = len(missing) / len(full_range) * 100
            level = "치명" if pct > 30 else "경고"
            issues.append((level, f"기대 시점 중 {len(missing)}개 누락 ({pct:.1f}%)"))

    # ══════════ ⑦ 미래·과거 이상값 ══════════
    now = pd.Timestamp.now(tz=valid.dt.tz)
    future = (valid > now).sum()
    ancient = (valid < pd.Timestamp("1990-01-01", tz=valid.dt.tz)).sum()

    if verbose:
        print(f"\n[⑦ 범위 이상]")
        print(f"  미래 시각     : {future}건")
        print(f"  1990년 이전   : {ancient}건")

    if future:
        issues.append(("경고", f"미래 시각 {future}건 — 시간대 오류 의심"))
    if ancient:
        issues.append(("경고", f"1990년 이전 {ancient}건 — 기본값(1970) 의심"))

    # ══════════ 결과 ══════════
    fatal = [i for i in issues if i[0] == "치명"]
    passed = not fatal

    if verbose:
        print(f"\n{line}")
        print(f"  판정: {'✅ 통과' if passed else '❌ 재검토'}"
              f"   (치명 {len(fatal)} · 경고 {len(issues) - len(fatal)})")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} [{level}] {msg}")

        if not issues:
            print("  문제 없음")

        print(line)

    return {"passed": passed, "issues": issues}
```

```python
"""구간화 품질 검증 및 제안."""

import numpy as np
import pandas as pd


def evaluate_bins(series, bins, labels=None, verbose=True):
    """
    구간화 결과를 평가합니다.

    반환: dict(balanced, coverage, issues)
    """
    s = series.dropna()
    result = pd.cut(s, bins=bins, labels=labels)

    counts = result.value_counts().sort_index()
    total = len(s)
    unclassified = result.isna().sum()

    issues = []

    if verbose:
        print("=" * 74)
        print("                       구간화 평가")
        print("=" * 74)

        print(f"\n[구간 분포]  n={total:,}")
        print(f"  {'구간':<26}{'개수':>8}{'비율':>8}  분포")
        print("  " + "-" * 58)

        top = counts.max() or 1
        for label, cnt in counts.items():
            pct = cnt / total * 100
            bar = "■" * int(cnt / top * 20)
            mark = "⚠" if pct < 5 or pct > 50 else " "
            print(f" {mark}{str(label):<26}{cnt:>8,}{pct:>7.1f}%  {bar}")

    # ── ① 미분류 ──
    if unclassified:
        pct = unclassified / total * 100
        issues.append(("치명", f"구간에 안 들어간 값 {unclassified}건 ({pct:.1f}%)"))

        if verbose:
            out = s[result.isna()]
            print(f"\n  ✗ 미분류 {unclassified}건 — "
                  f"범위 [{out.min():,.1f} ~ {out.max():,.1f}]")
            print(f"    bins 시작을 -inf, 끝을 inf 로 바꾸세요")

    # ── ② 빈 구간 ──
    empty = counts[counts == 0]
    if len(empty):
        issues.append(("경고", f"비어 있는 구간 {len(empty)}개: {list(empty.index)}"))

    # ── ③ 편중 ──
    if len(counts) > 0:
        max_pct = counts.max() / total * 100
        min_pct = counts.min() / total * 100

        if max_pct > 60:
            issues.append(("경고",
                           f"'{counts.idxmax()}' 구간에 {max_pct:.0f}% 집중 "
                           f"— 구간을 더 나누세요"))

        if 0 < min_pct < 3:
            issues.append(("경고",
                           f"'{counts.idxmin()}' 구간이 {min_pct:.1f}% "
                           f"— 인접 구간과 합치세요"))

    balance = counts.min() / counts.max() if counts.max() else 0

    if verbose:
        print(f"\n[균형도]")
        print(f"  최대/최소 비율 : {counts.max()}/{counts.min()} "
              f"= {counts.max() / max(counts.min(), 1):.1f}배")
        print(f"  균형 점수      : {balance:.2f} "
              f"({'양호' if balance > 0.3 else '불균형'})")

    # ── ④ 대안 제안 ──
    if verbose:
        print(f"\n[대안 비교]")

        alternatives = {
            "현재 (cut)": result,
            "qcut(q=5)": pd.qcut(s, q=5, duplicates="drop"),
            "cut(bins=5)": pd.cut(s, bins=5),
        }

        # 로그 스케일 구간 (치우친 분포용)
        if s.min() >= 0 and s.max() / max(s[s > 0].min(), 1) > 100:
            log_bins = np.unique(np.concatenate([
                [-np.inf],
                np.logspace(np.log10(max(s[s > 0].min(), 1)),
                            np.log10(s.max()), 5),
                [np.inf]]))
            alternatives["로그 구간"] = pd.cut(s, bins=log_bins)

        print(f"  {'방식':<16}{'구간수':>8}{'최대비중':>10}"
              f"{'최소비중':>10}{'균형':>8}")
        print("  " + "-" * 54)

        for name, res in alternatives.items():
            c = res.value_counts()
            c = c[c > 0]
            if len(c) == 0:
                continue
            mx, mn = c.max() / len(s) * 100, c.min() / len(s) * 100
            bal = c.min() / c.max()
            mark = "★" if bal > 0.5 else " "
            print(f" {mark}{name:<16}{len(c):>8}{mx:>9.1f}%"
                  f"{mn:>9.1f}%{bal:>8.2f}")

    # ── ⑤ 권장 경계 ──
    if verbose:
        print(f"\n[참고: 분위수 경계]")
        qs = s.quantile([0, 0.2, 0.4, 0.5, 0.6, 0.8, 0.9, 0.95, 1.0])
        for q, v in qs.items():
            print(f"  {q * 100:>5.0f}%  {v:>14,.1f}")

        print(f"\n{'=' * 74}")
        if issues:
            for level, msg in issues:
                print(f"  {'🔴' if level == '치명' else '🟡'} [{level}] {msg}")
        else:
            print("  ✅ 구간 설계에 문제 없음")
        print("=" * 74)

    return {"balanced": balance > 0.3,
            "coverage": 1 - unclassified / total,
            "issues": issues}
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 변환 | `to_datetime(s, format=..., errors="coerce")` |
| 형식 지정 | **10배 빠름** · `format="mixed"` 는 형식이 섞였을 때 |
| 날짜 순서 | `05/06` 은 모호 → **출처 확인** · `dayfirst` |
| **시간대** | API는 대부분 **UTC** → `tz_convert("Asia/Seoul")` |
| `dt` 접근자 | `year` `month` `hour` `dayofweek`(월=0) `quarter` |
| 요일 한글 | `dayofweek.map(lambda i: ["월",...][i])` |
| 주차 | **`dt.isocalendar().week`** (`dt.week` 삭제됨) |
| `resample` | **인덱스가 datetime** 이어야 함 |
| 빈도 별칭 | **`ME` `QE` `YE` `h` `min`** (`M` `Q` `Y` `H` 폐기) |
| 추이 도구 | `shift` `diff` `pct_change` **`rolling`** |
| `cut` | **값 기준** · `bins=[-inf, ..., inf]` 로 감싸기 |
| `qcut` | **개수 기준** · 같은 값 많으면 `duplicates="drop"` |
| `Categorical` | **`ordered=True`** 로 비교·정렬 가능 |
| `groupby` | **`observed=True`** 명시 |
| 라벨링 | **`map`** (없는 키가 `NaN` 으로 드러남) |

**오늘 반드시 기억할 세 가지**
> ① **시간대를 확인하세요.** UTC를 KST로 안 바꾸면 모든 시간별 집계가 9시간 틀립니다.
> ② **`cut` 의 bins 는 `-inf` ~ `inf` 로 감싸세요.** 경계 밖 값이 조용히 `NaN` 이 됩니다.
> ③ **등급은 `Categorical(ordered=True)` 로.** 문자열이면 `고가 < 무료 < 저가` 로 정렬됩니다.

**과제**
① 수집 데이터의 날짜 열을 **형식 지정 + coerce** 로 변환하고 실패 건수 기록
② **시간대를 확인**하고 KST 기준으로 통일 — 확인 근거 서술
③ 요일별·시간대별·월별 집계표 3종 작성 (시간 축 그래프용 데이터)
④ 가격 또는 방문객을 **5등급으로 구간화** — `cut` 과 `qcut` 을 모두 시도해 비교
⑤ 구간 경계를 정한 **근거를 한 문단**으로 작성 (왜 이 숫자인가)
