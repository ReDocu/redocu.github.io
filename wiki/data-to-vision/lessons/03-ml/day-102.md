## ② 왜 필요한가

### 오늘 데이터가 확정됩니다

```
Day 101  수집·계획
Day 102  ★ 데이터 확정 ← 오늘 이후로는 바꾸지 않습니다
Day 103  실험 (모델만 바꿉니다)
Day 104  평가
```

**왜 확정해야 하는가** — 데이터를 바꾸면 어제까지의 실험 결과가 전부 무효가 됩니다.

```
실험 1~4: 데이터 A로  → val 0.78
실험 5: "데이터를 좀 늘렸어요" → val 0.85

이 0.07은 무엇 때문인가?
  모델 개선인가, 데이터가 늘어서인가?
→ 알 수 없음. 실험 1~4를 다시 해야 함
```

> **"한 번에 하나만 바꾼다"의 첫 번째 적용입니다.**
> 데이터를 고정해야 모델 실험이 의미를 갖습니다.

### 정확도 0.62를 봐야 합니다

오늘 만들 베이스라인은 **일부러 약한 모델**입니다.

```
밑바닥 CNN, 증강 없음, 규제 없음
→ 예상 정확도 0.65~0.75
```

**왜 좋은 모델을 먼저 만들지 않는가**

| | 베이스라인 없이 시작 | 베이스라인 먼저 |
|---|---|---|
| 전이학습 결과 0.91 | "좋네요" | **"베이스라인 0.68 → +0.23. 전이학습이 결정적"** |
| 증강 결과 0.73 | "별로네" | **"베이스라인 대비 +0.05. 효과 있음"** |
| 발표 | 숫자 하나 | **개선 과정 전체** |

> **베이스라인은 "얼마나 나아졌는가"를 말하기 위한 원점입니다.**
> 원점이 없으면 0.91이 잘한 것인지 알 수 없습니다.

### 그리고 오늘 이미 편향이 보일 것입니다

베이스라인을 학습시킨 뒤 **counter 셋으로도** 평가해 봅니다.

```
주 검증셋      0.72
배경 교차셋    0.51   ← 무작위와 같음
```

**이 숫자를 오늘 확인하는 것이 중요합니다.**
수요일 내내 정확도만 올리다가 목요일에 발견하면 고칠 시간이 없습니다.

## 1부 · 데이터 누수 3종

### 누수란

**학습에 쓴 정보가 평가에 새어 들어가는 것.** 성능이 실제보다 높게 나옵니다.

```
증상: 테스트 정확도가 이상하게 높다 (0.99, 1.00)
      그런데 새 이미지에서는 형편없다
```

### ① 중복 누수 — 같은 이미지가 양쪽에

```
wolf_0012.jpg  →  train
wolf_0077.jpg  →  test    (내용은 같은 사진)

모델은 시험 문제를 미리 본 것과 같습니다
```

**대응** — 분할 **전에** 중복을 제거합니다. ([Day 092](day-092.md)의 `dhash`)

> **[Day 101](day-101.md) Step 4에서 5쌍을 찾았습니다.** 그걸 오늘 반영합니다.

### ② 그룹 누수 — 같은 개체·같은 촬영

**중복은 아니지만 사실상 같은 정보인 경우입니다.**

```
husky_0031.jpg   같은 강아지, 정면
husky_0032.jpg   같은 강아지, 측면      ← 연속 촬영
husky_0033.jpg   같은 강아지, 앉은 자세

0031 → train,  0033 → test 로 나뉘면
"이 강아지"를 외운 모델이 test에서 맞힙니다
```

**대응** — **그룹 단위로 분할**합니다. 같은 그룹은 통째로 한쪽에만.

| 그룹을 정하는 방법 | 방식 |
|---|---|
| 파일명 규칙 | `husky_park_01.jpg` → `husky_park` 이 그룹 |
| 출처 URL | 같은 앨범·같은 페이지에서 온 이미지 |
| **해시 근접** | 유사도가 높은 것들을 한 그룹으로 (자동) |

### ③ 증강 후 분할 — 가장 흔한 실수

```
❌ 1000장 → 증강으로 5000장 → 랜덤 분할
   원본 A의 회전본이 train에, 좌우반전본이 test에
   → 사실상 같은 이미지

✅ 1000장 → 분할 → train에만 증강
```

> **증강은 학습셋에만.** ([Day 094](day-094.md))
> 이 프로젝트에서는 증강을 **모델 안의 레이어**로 넣어 원천 차단합니다.

### 누수를 발견하는 법

```
① 테스트 정확도가 0.98 이상인데 데이터가 몇백 장뿐 → 의심
② train/test 간 dhash 최소 거리를 계산 → 5 이하면 중복
③ 파일명 접두어가 양쪽에 걸쳐 있는지 확인
```

## 2부 · 테스트셋 3종 설계

### 왜 3개인가

| 셋 | 구성 | 답하는 질문 |
|---|---|---|
| **val** (검증) | 학습과 같은 분포 | 어느 설정이 더 나은가 — **Day 103에서 계속 씀** |
| **test** (주 테스트) | 학습과 같은 분포 | 최종 성능은 얼마인가 — **1회만** |
| **counter** (배경 교차) | **배경을 반대로** | **배경을 보고 있는가** ★ |

```
val    : 매일 봅니다 (실험 비교)
test   : Day 104에 1번 봅니다
counter: Day 104에 1번 봅니다  ← 오늘은 베이스라인 진단용으로만 1번 살짝
```

> **오늘 counter를 한 번 쓰는 것은 예외입니다.**
> "편향이 있는가"를 수요일 전에 알아야 수요일 계획을 세울 수 있기 때문입니다.
> **모델 선택에는 절대 쓰지 않습니다.**

### 분포 내(in-distribution) vs 분포 외(out-of-distribution)

```
val / test   : in-distribution   — 학습 데이터와 같은 세상
counter      : out-of-distribution — 학습 데이터에 없던 조합
```

**실제 서비스에서 만나는 것은 언제나 후자입니다.**

| | 실험실 | 현장 |
|---|---|---|
| 조명 | 학습과 비슷 | 다름 |
| 배경 | 학습과 비슷 | **완전히 다름** |
| 화질 | 학습과 비슷 | 스마트폰·CCTV |

> **counter 셋은 "현장"의 축소판입니다.**
> 대단원 05의 CCTV 프로젝트에서 이 감각이 그대로 필요합니다.

### 분할 비율

| 셋 | 비율 | 클래스당 | 이유 |
|---|---|---|---|
| train | 70% | ~210 | 학습 |
| val | 15% | ~45 | 실험 비교. 너무 작으면 순위가 흔들림 |
| test | 15% | ~45 | 최종 평가 |
| counter | 별도 수집 | ~30 | **분할이 아니라 별도 데이터** |

**계층 분할(stratified)** — 클래스뿐 아니라 **배경 태그도** 층화합니다.

```
train/val/test 각각에서
  wolf의 눈 비율 ≈ husky의 눈 비율 ≈ 50%
```

## 3부 · 기준선과 베이스라인

### 기준선(baseline)은 여러 층이 있습니다

| 층 | 이름 | 정확도 예상 | 의미 |
|---|---|---|---|
| 0 | 무작위 | 0.50 | 최저선 |
| 1 | 최빈 클래스 | 0.50 | 균형 데이터라 동일 |
| **2** | **평균 색상만 보는 모델** | **0.60~0.75** | **★ 배경 단서의 크기** |
| 3 | **밑바닥 CNN** | 0.65~0.78 | 오늘의 베이스라인 |
| 4 | 전이학습 | 0.88~0.94 | [Day 103](day-103.md) |

### ★ 층 2가 이 프로젝트의 핵심 진단입니다

**이미지의 평균 RGB 3개 숫자만으로 분류해 봅니다.**

```python
특징 = [평균 R, 평균 G, 평균 B]   ← 형태 정보 0
로지스틱 회귀로 분류
```

```
정확도 0.52 → 색만으로는 못 맞힘. 데이터가 건강함
정확도 0.78 → ★ 색(=배경)만으로 78%. 심각한 편향
```

> **CNN을 학습시키기 전에 이 숫자를 보세요.**
> 3픽셀짜리 정보로 0.78이 나오면, CNN이 0.85를 내도 **동물을 봤다는 증거가 없습니다.**

### 밑바닥 CNN 베이스라인 설계

```python
Conv(32) → Pool → Conv(64) → Pool → Conv(128) → Pool
→ Flatten → Dense(128) → Dense(1, sigmoid)
```

**의도적으로 넣지 않는 것**

| 안 넣는 것 | 이유 |
|---|---|
| 증강 | [Day 103](day-103.md) 실험 2의 변수 |
| Dropout | 실험 4의 변수 |
| 전이학습 | 실험 5의 변수 |
| 콜백 튜닝 | 기본값 고정 |

**넣는 것** — `Rescaling(1/255)` (없으면 학습 자체가 안 됨), `EarlyStopping` (시간 절약)

> **베이스라인은 "가장 단순한 것"이지 "아무렇게나"가 아닙니다.**
> 정규화 같은 필수 요소는 넣고, **개선 기법만** 뺍니다.

## 4부 · 데이터 카드

### 데이터 카드(datasheet)란

**"이 데이터셋이 무엇인가"를 한 장으로 설명하는 문서.**
논문·기업에서 표준으로 쓰입니다.

| 항목 | 내용 |
|---|---|
| 목적 | 무엇을 위해 만들었나 |
| 구성 | 클래스별·분할별 개수 |
| 수집 | 출처·기간·수집자·라이선스 |
| 전처리 | 크기·품질 통일 방식 |
| **알려진 편향** | **★ 배경 분포, 화질 차이** |
| 한계 | 쓰면 안 되는 용도 |

> **"알려진 편향"을 스스로 적는 것이 이 문서의 가치입니다.**
> 발표에서 "저희 데이터의 한계는 이것입니다"라고 먼저 말하는 팀이 신뢰를 얻습니다.

### 데이터 통계로 봐야 할 것

| 통계 | 위험 신호 |
|---|---|
| 클래스별 개수 | 비율 2:1 이상 → 불균형 대응 필요 ([Day 093](day-093.md)) |
| 분할별 클래스 비율 | 분할 간 차이 5%p 이상 → 층화 실패 |
| **배경 태그 분포** | **클래스 간 격차 20%p 이상 → 편향** |
| 해상도 분포 | 클래스별 중앙값 차이 2배 이상 → 경로 편향 |
| 파일 크기 | 위와 같음 |
| 평균 밝기·채도 | **클래스별 차이가 크면 색 단서 존재** |

## ④ 단계별 실습

### Step 1. 정제 파이프라인 — 제거·통일·재저장

```python
"""
Day 102 Step 1 — 정제 파이프라인
raw/ → clean/  (원본은 절대 수정하지 않습니다)

하는 일
  ① drop_list 반영 (깨짐·저해상도·중복·라벨 오류)
  ② 224x224 레터박스 리사이즈  ← 화질·해상도 조건 통일
  ③ JPEG 품질 90으로 재저장    ← ★ 파일 크기 편향 제거
  ④ RGB 변환 · EXIF 회전 반영
"""
from pathlib import Path

import numpy as np
import pandas as pd
from PIL import Image, ImageOps

PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
RAW, CLEAN = PROJ / "data" / "raw", PROJ / "data" / "clean"
SIZE, QUALITY = (224, 224), 90
CLASSES = ["husky", "wolf"]          # ★ 알파벳 순 = 라벨 인덱스 0, 1

drop = set()
drop_p = PROJ / "docs" / "drop_list.csv"
if drop_p.exists():
    drop = {Path(p).name for p in pd.read_csv(drop_p)["path"]}


def letterbox(img, size=SIZE, fill=(0, 0, 0)):
    """가로세로비를 유지하며 여백을 채웁니다 (Day 091)"""
    img = ImageOps.exif_transpose(img).convert("RGB")
    w, h = img.size
    scale = min(size[0] / w, size[1] / h)
    nw, nh = int(w * scale), int(h * scale)
    resized = img.resize((nw, nh), Image.BILINEAR)
    canvas = Image.new("RGB", size, fill)
    canvas.paste(resized, ((size[0] - nw) // 2, (size[1] - nh) // 2))
    return canvas


def clean_all(verbose=True):
    stats = []
    for cls in CLASSES:
        src_dir, dst_dir = RAW / cls, CLEAN / cls
        dst_dir.mkdir(parents=True, exist_ok=True)
        for old in dst_dir.glob("*.jpg"):
            old.unlink()                        # 매번 새로 만듭니다

        kept, dropped, failed = 0, 0, 0
        for f in sorted(src_dir.iterdir()):
            if f.suffix.lower() not in {".jpg", ".jpeg", ".png", ".webp"}:
                continue
            if f.name in drop:
                dropped += 1
                continue
            try:
                with Image.open(f) as img:
                    out = letterbox(img)
                out.save(dst_dir / f"{f.stem}.jpg", "JPEG", quality=QUALITY)
                kept += 1
            except Exception:
                failed += 1
        stats.append({"class": cls, "원본": len(list(src_dir.iterdir())),
                      "제외": dropped, "실패": failed, "정제본": kept})

    df = pd.DataFrame(stats)
    if verbose:
        line = "=" * 66
        print(line)
        print("정제 파이프라인  raw/ → clean/")
        print(line)
        print(df.to_string(index=False))
        print("-" * 66)
        print(f"{'합계':<8}{df['원본'].sum():>8}{df['제외'].sum():>8}"
              f"{df['실패'].sum():>8}{df['정제본'].sum():>10}")
        print(line)
        print(f"  크기   : {SIZE[0]}x{SIZE[1]} 레터박스")
        print(f"  품질   : JPEG {QUALITY}")
        print(f"  ★ 모든 이미지가 같은 조건 — 화질이 단서가 될 수 없습니다")
    return df


stats = clean_all()

# ── 통일 검증 ──
sizes, kbs = [], {c: [] for c in CLASSES}
for cls in CLASSES:
    for f in (CLEAN / cls).glob("*.jpg"):
        with Image.open(f) as img:
            sizes.append(img.size)
        kbs[cls].append(f.stat().st_size / 1024)

print(f"\n[통일 검증]")
print(f"  해상도 종류: {set(sizes)}  "
      f"{'✓ 모두 동일' if len(set(sizes)) == 1 else '✗ 확인 필요'}")
print(f"  {'클래스':<10}{'평균 KB':>10}{'표준편차':>10}")
print("  " + "-" * 30)
for cls in CLASSES:
    print(f"  {cls:<10}{np.mean(kbs[cls]):>10.1f}{np.std(kbs[cls]):>10.1f}")
ratio = max(np.mean(kbs[c]) for c in CLASSES) / min(np.mean(kbs[c]) for c in CLASSES)
print(f"\n  클래스 간 파일 크기 비: {ratio:.2f}배", end="  ")
print("✓ 통일됨" if ratio < 1.3 else "🟡 내용 차이(복잡도)로 인한 잔여 차이")
```

실행 결과:

```
==================================================================
정제 파이프라인  raw/ → clean/
==================================================================
class  원본  제외  실패  정제본
husky   331     9     1     321
 wolf   327    11     2     314
------------------------------------------------------------------
합계        658      20       3       635
==================================================================
  크기   : 224x224 레터박스
  품질   : JPEG 90
  ★ 모든 이미지가 같은 조건 — 화질이 단서가 될 수 없습니다

[통일 검증]
  해상도 종류: {(224, 224)}  ✓ 모두 동일
  클래스        평균 KB     표준편차
  ------------------------------
  husky           14.2       3.1
  wolf            15.8       3.6
```

### Step 2. 그룹 인식 분할 + counter 셋 분리

```python
"""
Day 102 Step 2 — 누수 없는 분할
  ① dhash로 유사 이미지를 그룹으로 묶는다  (그룹 누수 차단)
  ② 클래스 × 배경 층화                     (편향 균형)
  ③ 그룹 단위로 train/val/test 배분
  ④ counter는 분할에 참여시키지 않는다      (★ 별도 데이터)
"""
import shutil
from pathlib import Path

import numpy as np
import pandas as pd
from PIL import Image

PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
CLEAN, SPLIT = PROJ / "data" / "clean", PROJ / "data" / "split"
COUNTER = PROJ / "data" / "counter"
CLASSES = ["husky", "wolf"]
RATIOS, SEED = (0.70, 0.15, 0.15), 42

log = pd.read_csv(PROJ / "docs" / "collection_log.csv")
bg_map = dict(zip(log["file"], log["background"]))


def dhash(path, hash_size=8):
    img = Image.open(path).convert("L").resize(
        (hash_size + 1, hash_size), Image.LANCZOS)
    a = np.array(img, dtype=int)
    return (a[:, 1:] > a[:, :-1]).flatten()


def hamming(a, b):
    return int(np.sum(a != b))


def build_groups(files, threshold=12):
    """유사 이미지를 같은 그룹으로 묶습니다 (단순 union-find)"""
    hashes = [dhash(f) for f in files]
    parent = list(range(len(files)))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for i in range(len(files)):
        for j in range(i + 1, len(files)):
            if hamming(hashes[i], hashes[j]) <= threshold:
                ri, rj = find(i), find(j)
                if ri != rj:
                    parent[ri] = rj

    groups = {}
    for i, f in enumerate(files):
        groups.setdefault(find(i), []).append(f)
    return list(groups.values())


def split_dataset(verbose=True):
    for sub in ["train", "val", "test"]:
        for cls in CLASSES:
            d = SPLIT / sub / cls
            if d.exists():
                shutil.rmtree(d)
            d.mkdir(parents=True, exist_ok=True)

    rng = np.random.default_rng(SEED)
    rows = []

    for cls in CLASSES:
        files = sorted((CLEAN / cls).glob("*.jpg"))
        groups = build_groups(files)

        # ── 그룹을 배경 태그로 층화 ──
        by_bg = {"snow": [], "other": []}
        for g in groups:
            tags = [bg_map.get(f.name, "other") for f in g]
            key = "snow" if tags.count("snow") * 2 >= len(tags) else "other"
            by_bg[key].append(g)

        for bg, glist in by_bg.items():
            glist = list(rng.permutation(np.array(glist, dtype=object)))
            n_img = sum(len(g) for g in glist)
            want = [int(n_img * RATIOS[0]), int(n_img * (RATIOS[0] + RATIOS[1]))]

            acc, cursor, bucket = 0, 0, ["train", "val", "test"]
            for g in glist:
                sub = bucket[cursor]
                for f in g:
                    shutil.copy2(f, SPLIT / sub / cls / f.name)
                    rows.append({"file": f.name, "class": cls, "bg": bg,
                                 "split": sub, "group_size": len(g)})
                acc += len(g)
                if cursor == 0 and acc >= want[0]:
                    cursor = 1
                elif cursor == 1 and acc >= want[1]:
                    cursor = 2

    df = pd.DataFrame(rows)
    df.to_csv(PROJ / "docs" / "split_manifest.csv", index=False)

    if verbose:
        line = "=" * 78
        print(line)
        print("그룹 인식 층화 분할")
        print(line)

        print("\n[분할 × 클래스]")
        print(pd.crosstab(df["split"], df["class"],
                          margins=True, margins_name="합계").to_string())

        print("\n[분할별 눈 배경 비율 — 층화가 됐는가]")
        print(f"  {'분할':<8}{'클래스':<8}{'눈':>6}{'비눈':>7}{'눈 비율':>10}")
        print("  " + "-" * 40)
        for sub in ["train", "val", "test"]:
            for cls in CLASSES:
                g = df[(df["split"] == sub) & (df["class"] == cls)]
                s = (g["bg"] == "snow").sum()
                print(f"  {sub:<8}{cls:<8}{s:>6}{len(g) - s:>7}"
                      f"{s / max(len(g), 1):>9.1%}")

        print(f"\n[그룹 통계]")
        gs = df["group_size"]
        print(f"  단일 이미지 그룹: {(gs == 1).sum()}장")
        print(f"  2장 이상 그룹에 속한 이미지: {(gs > 1).sum()}장")
        print(f"  최대 그룹 크기: {gs.max()}장")
        print(f"  → 같은 그룹은 통째로 한 분할에만 들어갔습니다")
    return df


manifest = split_dataset()

# ══════════════════════════════════════════
# counter 셋 점검 — 분할에 섞이지 않았는지
# ══════════════════════════════════════════
print("\n" + "=" * 78)
print("배경 교차 테스트셋 (counter)")
print("=" * 78)

split_names = set(manifest["file"])
counter_rows = []
for cls in CLASSES:
    for f in sorted((COUNTER / cls).glob("*.jpg")):
        counter_rows.append({"file": f.name, "class": cls,

print(f"\n  {'클래스':<10}{'장수':>7}   배경 구성")
print("  " + "-" * 46)
for cls in CLASSES:
    g = cdf[cdf["class"] == cls]
    comp = g["bg"].value_counts().to_dict()
    print(f"  {cls:<10}{len(g):>7}   {comp}")

print(f"\n  분할 데이터와 파일명 중복: {len(overlap)}건", end="  ")
print("✓ 완전 분리" if not overlap else f"🔴 {sorted(overlap)[:3]} — 즉시 제거하세요")

print(f"""
```

```python
def load_features(root, classes=CLASSES):
    """이미지 1장 → 평균 RGB 3개 (형태 정보 없음)"""
```

### Step 5. 밑바닥 CNN 베이스라인

```python
"""
Day 102 Step 5 — 베이스라인 학습
증강 없음 · 규제 없음 · 전이학습 없음  (Day 103의 비교 원점)
"""
import json
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import EarlyStopping

AUTOTUNE = tf.data.AUTOTUNE
PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
SPLIT, COUNTER = PROJ / "data" / "split", PROJ / "data" / "counter"
IMG_SIZE, BATCH, SEED = (224, 224), 32, 42

keras.utils.set_random_seed(SEED)

train_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
    label_mode="binary", shuffle=True, seed=SEED)
val_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH,
    label_mode="binary", shuffle=False)
counter_raw = keras.utils.image_dataset_from_directory(
    COUNTER, image_size=IMG_SIZE, batch_size=BATCH,
    label_mode="binary", shuffle=False)

CLASS_NAMES = train_raw.class_names
print(f"클래스: {CLASS_NAMES}  (0={CLASS_NAMES[0]}, 1={CLASS_NAMES[1]})")

train_ds = train_raw.cache().prefetch(AUTOTUNE)
val_ds = val_raw.cache().prefetch(AUTOTUNE)
counter_ds = counter_raw.cache().prefetch(AUTOTUNE)


def build_baseline():
    """밑바닥 CNN — Day 089 구조 그대로"""
    return keras.Sequential([
        keras.Input(shape=(*IMG_SIZE, 3)),
        layers.Rescaling(1.0 / 255),               # 필수 (없으면 학습 실패)
        layers.Conv2D(32, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Conv2D(64, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Conv2D(128, 3, activation="relu", padding="same"),
        layers.MaxPooling2D(),
        layers.Flatten(),
        layers.Dense(128, activation="relu"),
        layers.Dense(1, activation="sigmoid"),
    ], name="baseline_cnn")


keras.backend.clear_session()
model = build_baseline()
model.compile(optimizer=keras.optimizers.Adam(1e-3),
              loss="binary_crossentropy", metrics=["accuracy"])

line = "=" * 74
print("\n" + line)
print("베이스라인 학습 — 밑바닥 CNN (증강·규제 없음)")
print(line)
model.summary()

t0 = time.time()
hist = model.fit(train_ds, epochs=40, validation_data=val_ds,
                 callbacks=[EarlyStopping(monitor="val_loss", patience=8,
                                          restore_best_weights=True, verbose=1)],
                 verbose=0).history
elapsed = time.time() - t0

best = int(np.argmin(hist["val_loss"]))
train_acc = hist["accuracy"][best]
val_acc = hist["val_accuracy"][best]
_, counter_acc = model.evaluate(counter_ds, verbose=0)

print(f"\n  에폭        : {len(hist['loss'])} (최적 {best + 1})")
print(f"  시간        : {elapsed:.0f}초")
print(f"  train_acc   : {train_acc:.4f}")
print(f"  val_acc     : {val_acc:.4f}")
print(f"  격차        : {train_acc - val_acc:+.4f}")
print(f"  counter_acc : {counter_acc:.4f}   ★ 배경 교차")
print(f"  하락폭      : {val_acc - counter_acc:+.4f}")

print("\n" + line)
if val_acc - counter_acc > 0.20:
    print("  🔴 배경 편향이 강하게 의심됩니다")
    print("     내일(Day 103)에 편향 완화 실험을 반드시 포함하세요")
elif val_acc - counter_acc > 0.10:
    print("  🟡 배경 의존이 어느 정도 있습니다")
else:
    print("  ✓ 배경 교차에서도 성능이 유지됩니다")
print(line)

model.save(PROJ / "models" / "baseline_cnn.keras")

# ── 학습 곡선 ──
fig, axes = plt.subplots(1, 3, figsize=(17, 4.6))

ax = axes[0]
ax.plot(hist["accuracy"], label="train", lw=2)
ax.plot(hist["val_accuracy"], label="val", lw=2)
ax.axvline(best, color="gray", ls="--", alpha=0.7, label=f"best ep {best+1}")
ax.axhline(0.5, color="red", ls=":", alpha=0.6)
ax.set_xlabel("epoch"); ax.set_ylabel("accuracy")
ax.set_title("Baseline accuracy"); ax.legend(); ax.grid(alpha=0.3)

ax = axes[1]
ax.plot(hist["loss"], label="train", lw=2)
ax.plot(hist["val_loss"], label="val", lw=2)
ax.axvline(best, color="gray", ls="--", alpha=0.7)
ax.set_xlabel("epoch"); ax.set_ylabel("loss")
ax.set_title("Baseline loss"); ax.legend(); ax.grid(alpha=0.3)

ax = axes[2]
names = ["random", "color-only", "baseline CNN"]
vals = [0.50, 0.6316, val_acc]
cnts = [0.50, 0.3607, counter_acc]
x = np.arange(3)
ax.bar(x - 0.2, vals, 0.4, label="val", color="#4c9be8")
ax.bar(x + 0.2, cnts, 0.4, label="counter", color="#e8964c")
ax.axhline(0.5, color="red", ls="--", alpha=0.7)
ax.set_xticks(x); ax.set_xticklabels(names, fontsize=9)
ax.set_ylim(0, 1); ax.set_title("Where we are now")
ax.legend(); ax.grid(axis="y", alpha=0.3)

fig.tight_layout()
plt.savefig(PROJ / "figures" / "day102_baseline.png", dpi=110)
plt.show()
```

```python
"""
Day 102 Step 6 — 실험 기록 모듈
experiment_log.py — Day 103에서 계속 사용합니다.

사용:
    from experiment_log import log_experiment, show_log
    log_experiment("baseline", "밑바닥 CNN", cfg, metrics,
                   observation="...", next_try="...")
"""
from datetime import datetime
from pathlib import Path

import matplotlib.pyplot as plt
import pandas as pd

PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
EXP_CSV = PROJ / "experiments" / "experiments.csv"

COLUMNS = ["no", "date", "name", "changed", "config",
           "train_acc", "val_acc", "counter_acc", "gap", "drop",
           "epochs", "sec", "observation", "next_try"]


def load_experiments():
    if EXP_CSV.exists():
        return pd.read_csv(EXP_CSV)
    return pd.DataFrame(columns=COLUMNS)


def log_experiment(name, changed, config, metrics,
                   observation="", next_try=""):
    """실험 1회를 기록합니다.

    metrics: dict(train_acc, val_acc, counter_acc, epochs, sec)
    observation / next_try 가 비면 경고합니다 — 그게 기록의 핵심입니다.
    """
    df = load_experiments()
    no = len(df) + 1

    row = {
        "no": no,
        "date": f"{datetime.now():%m/%d %H:%M}",
        "name": name,
        "changed": changed,
        "config": str(config),
        "train_acc": round(metrics.get("train_acc", float("nan")), 4),
        "val_acc": round(metrics["val_acc"], 4),
        "counter_acc": round(metrics.get("counter_acc", float("nan")), 4),
        "gap": round(metrics.get("train_acc", 0) - metrics["val_acc"], 4),
        "drop": round(metrics["val_acc"] - metrics.get("counter_acc", 0), 4),
        "epochs": metrics.get("epochs", ""),
        "sec": round(metrics.get("sec", 0)),
        "observation": observation,
        "next_try": next_try,
    }
    df = pd.concat([df, pd.DataFrame([row])], ignore_index=True)
    df.to_csv(EXP_CSV, index=False)

    if not observation or not next_try:
        print("  ⚠ observation / next_try 가 비었습니다 — "
              "숫자만 있는 것은 로그이지 기록이 아닙니다")
    print(f"  기록 #{no} 저장: {name}")
    return df


def show_log(df=None):
    df = load_experiments() if df is None else df
    if len(df) == 0:
        print("기록이 없습니다")
        return

    line = "=" * 104
    print(line)
    print(f"실험 기록표 — {len(df)}회")
    print(line)
    print(f"{'#':>3} {'실험':<18}{'바꾼 것':<20}"
          f"{'train':>8}{'val':>8}{'counter':>9}{'격차':>8}{'하락':>8}{'에폭':>6}")
    print("-" * 104)
    for _, r in df.iterrows():
        star = " ★" if r["val_acc"] == df["val_acc"].max() else "  "
        print(f"{int(r['no']):>3} {str(r['name'])[:17]:<18}"
              f"{str(r['changed'])[:19]:<20}"
              f"{r['train_acc']:>8.4f}{r['val_acc']:>8.4f}"
              f"{r['counter_acc']:>9.4f}{r['gap']:>8.4f}{r['drop']:>8.4f}"
              f"{str(r['epochs']):>6}{star}")
    print("-" * 104)

    best = df.loc[df["val_acc"].idxmax()]
    best_robust = df.loc[df["counter_acc"].idxmax()]
    print(f"  val 최고     : #{int(best['no'])} {best['name']} "
          f"({best['val_acc']:.4f})")
    print(f"  counter 최고 : #{int(best_robust['no'])} {best_robust['name']} "
          f"({best_robust['counter_acc']:.4f})")
    if int(best["no"]) != int(best_robust["no"]):
        print("  ★ 둘이 다릅니다 — 어느 쪽을 최종 모델로 할지 근거를 쓰세요")
    print(line)


def plot_log(df=None):
    df = load_experiments() if df is None else df
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    ax = axes[0]
    ax.plot(df["no"], df["val_acc"], "o-", lw=2, label="val")
    ax.plot(df["no"], df["counter_acc"], "s-", lw=2, label="counter")
    ax.axhline(0.5, color="red", ls=":", alpha=0.6)
    ax.set_xlabel("experiment #"); ax.set_ylabel("accuracy")
    ax.set_title("Progress"); ax.legend(); ax.grid(alpha=0.3)
    for _, r in df.iterrows():
        ax.annotate(str(r["name"])[:10], (r["no"], r["val_acc"]),

    ax.axhline(0.10, color="red", ls="--", label="target ≤ 0.10")
    ax.set_xlabel("experiment #"); ax.set_ylabel("val − counter")
    ax.set_title("Background dependence (lower is better)")
    ax.legend(); ax.grid(axis="y", alpha=0.3)

    fig.tight_layout()
    plt.savefig(PROJ / "figures" / "experiment_progress.png", dpi=110)
    plt.show()
```

> 목요일에 보고서를 쓸 때 **이 두 열만 이어 붙이면 "방법" 절이 완성됩니다.**

## ⑤ 자주 하는 실수

### 정제·분할을 하고 나서 이미지를 더 추가한다

```
화요일 오후: 분할 완료
수요일 오전: "50장 더 모았어요" → clean/에 추가 → 재분할
→ 화요일 실험 결과와 비교 불가
```

**해결** — 추가하려면 **모든 실험을 다시 합니다.** 그럴 시간이 없으므로 화요일에 확정합니다.

### 랜덤 분할만 하고 그룹을 무시한다

```python
# ❌
files = list(all_images)
random.shuffle(files)
train, val, test = files[:70%], ...
```

**증상** — 테스트 정확도가 0.95인데 새 사진에서는 0.7.
**해결** — Step 2처럼 유사 이미지를 그룹으로 묶어 통째로 배분합니다.

### counter 셋을 학습이나 모델 선택에 쓴다

```python
# ❌ 이렇게 하는 순간 counter는 검증셋이 됩니다
best = max(models, key=lambda m: m.evaluate(counter_ds))
```

**해결** — counter는 **진단용 관찰**입니다. 오늘 1회, [Day 104](day-104.md) 1회만 봅니다.
모델 선택은 `val` 로만 합니다.

### `label_mode` 를 안 맞춘다

```
ValueError: logits and labels must have the same shape ((32, 1) vs (32,))
```

**원인** — 출력이 `Dense(1, sigmoid)` 인데 라벨이 정수형.
**해결** — `image_dataset_from_directory(..., label_mode="binary")`

### 클래스 폴더 이름 순서를 착각한다

```python
CLASS_NAMES = ['husky', 'wolf']   # 알파벳 순
# husky = 0,  wolf = 1
```

`sigmoid` 출력 0.9는 **wolf 확률 0.9** 입니다. 반대로 해석하면 혼동행렬 전체가 뒤집힙니다.
**해결** — `train_raw.class_names` 를 출력해서 **눈으로 확인하고 코드에 주석**을 답니다.

### 베이스라인에 이것저것 넣는다

```
"어차피 할 거니까 증강도 넣고 Dropout도 넣자"
→ 내일 "증강의 효과"를 측정할 수 없음
```

**해결** — 베이스라인은 **가장 단순하게**. 개선 기법은 [Day 103](day-103.md)에서 하나씩.

### 원본 해상도를 그대로 쓴다

```
클래스별 해상도 차이 = 단서
1600x1067(wolf) vs 900x600(husky)
```

**해결** — 전부 같은 크기·같은 품질로 재저장합니다. (Step 1)

### 실험 기록에 숫자만 적는다

```
❌ | 2 | baseline | 0.94 | 0.71 |
✅ | 2 | baseline | 0.94 | 0.71 | 심한 과적합, counter 0.54 | 증강 추가 |
```

**"관찰"과 "다음 시도"가 없으면 로그이지 기록이 아닙니다.**

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 데이터 확정 | **오늘 이후 데이터를 바꾸지 않는다** |
| 누수 ① 중복 | 같은 이미지가 train/test에 → 분할 **전에** 제거 |
| 누수 ② 그룹 | 같은 개체·연속 촬영 → **그룹 단위 분할** |
| 누수 ③ 증강 후 분할 | 증강은 **분할 뒤, 학습셋에만** |
| 조건 통일 | 크기·품질을 같게 → **화질이 단서가 되는 것을 차단** |
| 레터박스 | 비율 왜곡도 단서가 될 수 있음 |
| 층화 | 클래스 + **배경 태그**까지 |
| **테스트 3종** | val(매일) · test(1회) · **counter(편향)** |
| counter 원칙 | **모델 선택에 쓰지 않는다** |
| 기준선 0·1 | 무작위·최빈 = 0.50 |
| **기준선 2** | **평균 RGB 3개** — 색·배경 단서의 크기 ★ |
| 0.5 미만 정확도 | **규칙이 반대로 작동** = 편향의 증거 |
| 베이스라인 | 증강·규제·전이학습 **없이**. 원점 |
| 읽는 법 | train−val = 과적합 / **CNN−색기준선 = 진짜 학습량** |
| 데이터 카드 | 구성·수집·전처리·**알려진 편향**·한계 |
| 실험 기록 | 숫자 + **관찰 + 다음 시도** |

**오늘 반드시 기억할 세 가지**
> ① **색 기준선(0.63)과 CNN(0.71)의 차이가 진짜 학습량입니다.** 0.71만 보면 착각합니다.
> ② **counter 0.54를 오늘 알았습니다.** 목요일에 알았으면 고칠 시간이 없었습니다.
> ③ **데이터는 오늘 확정입니다.** 내일부터는 모델만 바꿉니다.

**오늘의 산출물**
① **정제본** (`data/clean/`) — 224×224, JPEG 90 통일
② **분할** (`data/split/`) + 분할 명세 (`docs/split_manifest.csv`)
③ **counter 셋** (`data/counter/`) — 61장, 분할과 중복 0건
④ **데이터 카드** (`docs/data_card.md`) — 알려진 편향 직접 작성
⑤ **기준선 3종 결과** (`experiments/day102_baselines.csv`)
