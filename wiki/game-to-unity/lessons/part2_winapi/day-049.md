## 2. 막히는 상황

지금까지는 캐릭터 하나만 만들었다. 두 명으로 늘리면 문제가 쏟아진다.

```cpp
    Character* m_player1;
    Character* m_player2;
```

```
   ① 두 명이 같은 키로 조작된다
      → 방향키를 누르면 둘 다 움직인다

   ② 서로 통과한다
      → 겹쳐서 하나로 보인다

   ③ 항상 오른쪽만 본다
      → 상대가 왼쪽에 있어도 오른쪽을 향해 공격한다

   ④ 화면 밖으로 나간다
      → 한 명이 도망가면 안 보인다

   ⑤ 체력이 0이 되어도 계속 싸운다
      → 끝이 없다
```

```
   지금:   캐릭터 하나를 위한 코드

   필요:   ① 입력 매핑 분리
           ② 밀어내기 (pushbox)
           ③ 자동 방향 전환
           ④ 화면 경계 + 카메라
           ⑤ 라운드 진행
```

> **대전이 성립하는 구조가 필요하다.**

### 3-2. 자동 방향 전환

**왜 필요한가** — 격투게임에서는 항상 상대를 바라본다.

```cpp
void Character::FaceOpponent()
{
    if (!m_opponent) return;

    // 특정 상태에서는 방향을 고정한다
    switch (m_state)
    {
    case STATE_ATTACK:
    case STATE_C_ATTACK:
    case STATE_J_ATTACK:
    case STATE_HIT:
    case STATE_DOWN:
    case STATE_GETUP:
        return;                               // ★ 방향 고정
    default:
        break;
    }

    m_facingLeft = (m_opponent->GetX() < m_x);
}
```

```
   ★ 공격 중에 방향이 바뀌면 안 된다

   공격 발생 전에 상대가 뒤로 돌아가면
   → 판정이 갑자기 뒤쪽에 생긴다
   → 이상한 판정이 된다

   격투게임에서는 "공격 시작 시점의 방향"으로 고정한다
```

**가드 방향**

```cpp
bool Character::IsGuardingCorrectDirection() const
{

    Input& in = m_core->GetInput();

        return in.IsKeyPress(m_keys.left);     // 상대가 오른쪽 → 왼쪽 입력
```

### 3-3. 밀어내기 (pushbox)

**왜 필요한가** — 캐릭터가 겹치면 누가 어디 있는지 알 수 없다.

```cpp
RectF Character::GetPushbox() const
{
    float w = 40.0f;
    float h = (m_state == STATE_CROUCH) ? 50.0f : 80.0f;

    RectF r;
    r.x = (float)m_x - w / 2;
    r.y = (float)m_y - h;
    r.w = w;
    r.h = h;
    return r;
}
```

```cpp
void FightScene::ResolvePush()
{
    RectF a = m_player1->GetPushbox();
    RectF b = m_player2->GetPushbox();

    if (!IsOverlap(a, b)) return;

    // 겹친 가로 깊이
    double overlapX = min(a.x + a.w, b.x + b.w) - max(a.x, b.x);

    // 서로 반대 방향으로 절반씩 밀어낸다
    double push = overlapX / 2.0 + 0.5;

    if (m_player1->GetX() < m_player2->GetX())
    {
        m_player1->AddX(-push);
        m_player2->AddX(+push);
    }
    else
    {
        m_player1->AddX(+push);
        m_player2->AddX(-push);
    }
}
```

```
   겹친 상태                    밀어낸 후

   ┌────┬────┐                ┌────┐ ┌────┐
   │ P1 │▓P2 │                │ P1 │ │ P2 │
   │    │▓   │       →        │    │ │    │
   └────┴────┘                └────┘ └────┘
        ▲                        ← 절반씩 →
     overlapX
```

> ### ⚠️ 밀어내기는 물리 갱신 **뒤에** 한다
>
> ```
>   순서:  입력 → 물리(이동) → 밀어내기 → 화면 경계 → 렌더
>
>   밀어내기를 먼저 하면 이동으로 다시 겹친다
> ```

**공중에서는 밀어내지 않는다**

```cpp
    if (!m_player1->IsOnGround() && !m_player2->IsOnGround())
        return;                               // 공중 캐릭터끼리는 통과
```


**방법 2 — 추적 카메라 (본격적)**

```cpp
class FightCamera
{
public:
    void Update(double p1x, double p2x, double dt)
    {
        double center = (p1x + p2x) / 2.0;
        double dist   = fabs(p1x - p2x);

        // 화면 중앙이 두 캐릭터 중앙을 따라가게
        double targetX = center - m_screenW / 2.0;

        // 스테이지 경계 클램프
        if (targetX < 0) targetX = 0;
        if (targetX > m_stageW - m_screenW) targetX = m_stageW - m_screenW;

        // 부드럽게 추적
        m_x += (targetX - m_x) * 5.0 * dt;
    }

    double GetX() const { return m_x; }

private:
    double m_x = 0;
    double m_screenW = 800, m_stageW = 1600;
};
```

### 3-5. 라운드 진행 — 또 하나의 FSM

**왜 필요한가** — 라운드에도 상태와 흐름이 있다.

```cpp
{
    ROUND_INTRO,        // "ROUND 1" 표시
    ROUND_READY,        // "READY?" (조작 불가)

    ROUND_KO,           // "K.O." 연출
```

```cpp
void FightScene::UpdateRound(double dt)
{
    m_roundTimer += dt;

    switch (m_roundState)
    {
    case ROUND_INTRO:
        if (m_roundTimer >= 1.5) ChangeRoundState(ROUND_READY);
        break;

    case ROUND_READY:
        if (m_roundTimer >= 1.0) ChangeRoundState(ROUND_FIGHT);
        break;

    case ROUND_FIGHT:
        m_timeLeft -= dt;

        if (m_player1->GetHp() <= 0 || m_player2->GetHp() <= 0 || m_timeLeft <= 0)
            ChangeRoundState(ROUND_KO);
        break;

    case ROUND_KO:
        if (m_roundTimer >= 2.0) ChangeRoundState(ROUND_RESULT);
        break;

    case ROUND_RESULT:
        if (m_roundTimer >= 2.0)
        {
            if (m_winCount1 >= 2 || m_winCount2 >= 2)
                ChangeRoundState(ROUND_MATCH_END);
            else
                StartNextRound();
        }
        break;

    case ROUND_MATCH_END:
        if (m_core->GetInput().IsKeyDown(VK_RETURN))
            m_core->GetSceneManager().ChangeScene(new TitleScene());
        break;
    }
}
```

### 3-6. 승패 판정

**왜 필요한가** — 시간 초과 시에도 승자를 정해야 한다.

```cpp
int FightScene::JudgeWinner()
{
    int hp1 = m_player1->GetHp();
    int hp2 = m_player2->GetHp();

    if (hp1 <= 0 && hp2 <= 0) return 0;       // 더블 KO — 무승부
    if (hp2 <= 0)             return 1;       // P1 승
    if (hp1 <= 0)             return 2;       // P2 승

    // 시간 초과 — 체력이 많은 쪽
    if (hp1 > hp2) return 1;
    if (hp2 > hp1) return 2;
    return 0;                                  // 동점 — 무승부
}
```

| 결과 | 표시 |
|---|---|
| P1 승 | "P1 WIN" |
| P2 승 | "P2 WIN" |
| 무승부 | "DRAW" (양쪽 승수 +1 또는 재경기) |

### 3-7. 라운드 초기화

**왜 필요한가** — 초기화를 빠뜨리면 이전 라운드 상태가 남는다.

```cpp
void FightScene::StartNextRound()
{
    m_currentRound++;

    // 캐릭터 초기화

    m_player2->ResetForRound(600.0, 480.0, true);

    // 라운드 상태

```

```cpp
void Character::ResetForRound(double x, double y, bool facingLeft)
{
    m_x = x;
    m_y = y;
    m_vx = m_vy = 0;

    m_hp = m_maxHp;
    m_onGround = true;
    m_jumpCount = 0;
    m_facingLeft = facingLeft;

    m_hitStopTimer = 0;
    m_comboCount = 0;
    m_comboTimer = 0;
    ClearHitRecord();

    m_state = STATE_IDLE;                     // ★ ChangeState 아님 (전이표 무시)
    m_prevState = STATE_IDLE;
    m_stateTimer = 0;
    m_animator.Play("idle", true);

    m_hpBar.Reset(m_maxHp);
}
```

```
   ★ 초기화 체크리스트

   □ 위치, 속도
   □ 체력, 게이지(지연분 포함)
   □ 상태, 상태 타이머
   □ 애니메이션
   □ 히트 기록, 콤보
   □ 히트스톱 타이머
   □ 점프 카운트
   □ 방향

   ★ 하나라도 빠지면 "2라운드에서 이상하다" 버그가 난다
```

> **`ChangeState`가 아니라 직접 대입한다.**
> 전이표에 `DOWN → IDLE`이 없을 수 있기 때문이다.

```cpp
void FightScene::ClampToScreen()
{
    double halfW = 22.0;

    for (Character* c : { m_player1, m_player2 })

        double x = c->GetX();
```

```cpp
void FightScene::ChangeRoundState(RoundState s)
{
    m_roundState = s;
    m_roundTimer = 0.0;

    switch (s)
    {
    case ROUND_KO:
        {
            int winner = JudgeWinner();
            if (winner == 1) { m_winCount1++; m_player1->ChangeState(STATE_WIN); }
            if (winner == 2) { m_winCount2++; m_player2->ChangeState(STATE_WIN); }
```

```cpp
{

    int cy = r.GetHeight() / 2 - 60;

    switch (m_roundState)
    {
    case ROUND_INTRO:
        r.DrawTextCentered(cx, cy, RGB(255, 240, 120), 48, "ROUND %d", m_currentRound);
        break;

    case ROUND_READY:

        break;

    case ROUND_FIGHT:

            r.DrawTextCentered(cx, cy, RGB(255, 80, 80), 56, "FIGHT!");
        break;

    case ROUND_KO:
        r.DrawTextCentered(cx, cy, RGB(255, 60, 60), 64, "K.O. !!");
        break;

    case ROUND_RESULT:
        if      (m_lastWinner == 1) r.DrawTextCentered(cx, cy, RGB(255,220,60), 48, "P1 WIN");
        else if (m_lastWinner == 2) r.DrawTextCentered(cx, cy, RGB(255,220,60), 48, "P2 WIN");
        else                        r.DrawTextCentered(cx, cy, RGB(200,200,200), 48, "DRAW");
        break;

    case ROUND_MATCH_END:
        r.DrawTextCentered(cx, cy - 40, RGB(255,220,60), 56,
                           m_winCount1 >= 2 ? "PLAYER 1 WINS!" : "PLAYER 2 WINS!");
        r.DrawTextCentered(cx, cy + 40, RGB(200,200,220), 24, "[Enter] 타이틀로");
        break;
    }
}
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 둘 다 같이 움직임 | 키 매핑 미분리 | `KeyMapping` 구조체 |
| 서로 통과함 | 밀어내기 미구현 | `ResolvePush` |
| 밀어내도 다시 겹침 | 밀어내기를 물리 전에 함 | 물리 **뒤**로 |
| 공격 판정이 뒤에 생김 | 공격 중 방향 전환 | 상태별로 방향 고정 |
| 2라운드에서 이상함 | 초기화 누락 | 체크리스트 확인 |
| `DOWN`에서 `IDLE`로 안 감 | `ChangeState` 사용 (전이표 차단) | 직접 대입 |
| 연출 중에도 움직임 | 입력 차단 누락 | `SetInputEnabled` |
| 타이머가 연출 중에도 감소 | 상태 확인 없음 | `ROUND_FIGHT`일 때만 |
| KO 후 계속 때림 | 상태 전환 후 판정 계속 | `ROUND_FIGHT`에서만 `CheckHits` |
| 승수가 안 늘어남 | `JudgeWinner` 호출 위치 | `ROUND_KO` 진입 시 한 번 |
