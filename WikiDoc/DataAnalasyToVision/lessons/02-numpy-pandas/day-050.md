## ② 왜 필요한가

**분석 질문의 대부분이 "~별로" 입니다.**

```
"지역별 평균 매출은?"
"카테고리별 주문 건수는?"
"월별 방문자 추이는?"
"플레이어별 최고 점수는?"
```

`groupby` 없이 하려면 반복문이 필요합니다.

```python
# 반복문
for stage in df["stage"].unique():
    sub = df[df["stage"] == stage]
    print(stage, sub["score"].mean())

# groupby
df.groupby("stage")["score"].mean()
```

그리고 **실제 데이터는 여러 파일에 흩어져 있습니다.**

```
주문.csv    (주문번호, 고객ID, 상품ID, 수량)
고객.csv    (고객ID, 이름, 지역)
상품.csv    (상품ID, 상품명, 가격)
```

"지역별 매출"을 구하려면 **세 파일을 합쳐야** 합니다. 그것이 `merge` 입니다.

> **`groupby` 와 `merge` 는 pandas 의 두 기둥**입니다.
> 오늘 배우는 것으로 W10 이 완성되고, W15 프로젝트에서 계속 씁니다.

## ③ 개념 설명

### groupby 의 원리 — 분할·적용·결합

```
        원본                 ① 분할            ② 적용         ③ 결합
┌────────┬───────┐      ┌────────┬─────┐
│ region │ sales │      │ 서울   │ 100 │      mean()
├────────┼───────┤      │ 서울   │ 200 │  →   = 150
│ 서울   │  100  │      └────────┴─────┘                  ┌────────┬─────┐
│ 부산   │  300  │  →                                  →  │ 서울   │ 150 │
│ 서울   │  200  │      ┌────────┬─────┐                  │ 부산   │ 350 │
│ 부산   │  400  │      │ 부산   │ 300 │      mean()      └────────┴─────┘
└────────┴───────┘      │ 부산   │ 400 │  →   = 350
                        └────────┴─────┘
```

이것을 **split-apply-combine** 이라고 합니다.

### 기본 사용

```python
df.groupby("region")["sales"].mean()          # 한 열
df.groupby("region")[["sales", "count"]].sum()  # 여러 열
df.groupby("region").mean(numeric_only=True)   # 모든 수치 열
df.groupby(["region", "category"])["sales"].sum()   # 다중 키
```

**주요 집계 함수**

```python
.count()      # 개수 (결측 제외)
.size()       # 개수 (결측 포함)
.sum()  .mean()  .median()
.min()  .max()  .std()  .var()
.first()  .last()
.nunique()    # 고유값 개수
.describe()   # 여러 통계 한 번에
```

> **`count()` 와 `size()` 의 차이** — `count` 는 결측을 빼고, `size` 는 행 수를 그대로 셉니다.

### agg — 여러 집계를 한 번에

```python
# 여러 함수
df.groupby("region")["sales"].agg(["mean", "sum", "count", "max"])

# 열마다 다른 함수
df.groupby("region").agg({
    "sales": ["mean", "sum"],
    "quantity": "sum",
    "customer_id": "nunique",
})

# 이름 지정 (권장) — 결과 열 이름이 깔끔해짐
df.groupby("region").agg(
    평균매출=("sales", "mean"),
    총매출=("sales", "sum"),
    주문수=("sales", "size"),
    고객수=("customer_id", "nunique"),
)
```

> **이름 지정 방식(named aggregation)이 가장 좋습니다.**
> 다중 인덱스 열이 생기지 않아 이후 처리가 간단합니다.

**사용자 정의 함수**

```python
df.groupby("region")["sales"].agg(lambda x: x.max() - x.min())

df.groupby("region").agg(
    범위=("sales", lambda x: x.max() - x.min()),
    상위25=("sales", lambda x: x.quantile(0.75)),
)
```

### transform — 원본 크기 유지

**`agg` 는 그룹당 하나의 값**을, **`transform` 은 원본 각 행에 값**을 돌려줍니다.

```python
df.groupby("region")["sales"].mean()          # 지역 수만큼 (3행)
df.groupby("region")["sales"].transform("mean")  # 원본 행 수만큼 (100행)
```

```
원본                      transform("mean")
region  sales             region  sales  region_avg
서울     100               서울     100      150      ← 서울 평균
부산     300               부산     300      350      ← 부산 평균
서울     200               서울     200      150
부산     400               부산     400      350
```

**언제 쓰나**

```python
# ① 각 행이 자기 그룹 평균 대비 얼마인지
df["vs_avg"] = df["sales"] / df.groupby("region")["sales"].transform("mean")

# ② 그룹별 결측을 그룹 평균으로 채우기
df["sales"] = df["sales"].fillna(df.groupby("region")["sales"].transform("mean"))

# ③ 그룹별 표준화
g = df.groupby("region")["sales"]
df["z"] = (df["sales"] - g.transform("mean")) / g.transform("std")
```

> **②번이 특히 유용합니다.** 전체 평균이 아니라 **그룹 평균으로 결측을 채우면** 훨씬 정확합니다.
> [Day 056](day-056.md)에서 자세히 다룹니다.

### filter — 그룹 단위 필터링

```python
# 5건 이상인 그룹만 남기기
df.groupby("region").filter(lambda g: len(g) >= 5)

# 평균이 100 넘는 그룹만
df.groupby("region").filter(lambda g: g["sales"].mean() > 100)
```

> **행이 아니라 그룹 전체를 남기거나 버립니다.**

### apply — 그룹마다 자유로운 처리

```python
# 그룹별 상위 3개
df.groupby("region").apply(lambda g: g.nlargest(3, "sales"))

# 그룹별 사용자 정의 계산
df.groupby("region").apply(lambda g: pd.Series({
    "매출": g["sales"].sum(),
    "1등": g.loc[g["sales"].idxmax(), "name"],
}))
```

> `apply` 는 자유롭지만 느립니다. `agg`/`transform` 으로 가능하면 그쪽을 쓰세요.

### 그룹별 상위 n개 — 자주 쓰는 패턴

```python
# 방법 ① sort + groupby + head (가장 빠름)
df.sort_values("sales", ascending=False).groupby("region").head(3)

# 방법 ② apply + nlargest
df.groupby("region").apply(lambda g: g.nlargest(3, "sales"))

# 방법 ③ rank 로 순위를 매기고 필터
df["rank"] = df.groupby("region")["sales"].rank(ascending=False, method="min")
df[df["rank"] <= 3]
```

### pivot_table — 교차표

```python
pd.pivot_table(
    df,
    index="region",           # 행
    columns="category",       # 열
    values="sales",           # 값
    aggfunc="sum",            # 집계 방법
    fill_value=0,             # 빈 칸 채우기
    margins=True,             # 합계 행·열 추가
)
```

```
category   가전    식품    의류   All
region
서울       1200   800    600   2600
부산        900   700    400   2000
All        2100  1500   1000   4600
```

| | `groupby` | `pivot_table` |
|---|---|---|
| 결과 형태 | 세로 (긴 형태) | **가로 (넓은 형태)** |
| 보기 | 데이터 처리용 | **사람이 읽기 좋음** |
| 엑셀 비유 | — | **피벗 테이블** |

**`crosstab` — 빈도 교차표**

```python
pd.crosstab(df["region"], df["category"])              # 개수
pd.crosstab(df["region"], df["category"], normalize="index")   # 행 비율
```

### merge — 열 기준으로 합치기 (SQL JOIN)

```python
pd.merge(left, right, on="key", how="inner")
```

| `how` | 결과 |
|---|---|
| `"inner"` (기본) | **양쪽에 다 있는 것만** |
| `"left"` | 왼쪽 전부 + 오른쪽에서 매칭되는 것 |
| `"right"` | 오른쪽 전부 |
| `"outer"` | 양쪽 전부 (합집합) |

```
left            right           inner        left
A 1             A x             A 1 x        A 1 x
B 2             B y             B 2 y        B 2 y
C 3             D z                          C 3 NaN
```

**주요 옵션**

```python
pd.merge(a, b, on="id")                          # 같은 이름의 키
pd.merge(a, b, left_on="a_id", right_on="b_id")  # 다른 이름
pd.merge(a, b, on=["id", "date"])                # 여러 키
pd.merge(a, b, on="id", suffixes=("_주문", "_고객"))  # 중복 열 이름
pd.merge(a, b, on="id", indicator=True)          # 어디서 왔는지 표시
a.merge(b, on="id")                               # 메서드 방식
```

> **`indicator=True` 가 유용합니다.** `_merge` 열이 생겨
> `left_only` / `right_only` / `both` 를 확인할 수 있습니다. **매칭 실패를 발견**하는 데 필수입니다.

### concat — 단순히 이어 붙이기

```python
pd.concat([df1, df2])                      # 위아래로 (기본 axis=0)
pd.concat([df1, df2], ignore_index=True)   # 인덱스 재부여
pd.concat([df1, df2], axis=1)              # 좌우로
pd.concat([df1, df2], keys=["A", "B"])     # 출처 표시
```

| | `merge` | `concat` |
|---|---|---|
| 기준 | **키(공통 열)** | 위치·인덱스 |
| 방향 | 좌우 (열 추가) | **위아래(기본)** 또는 좌우 |
| 비유 | SQL JOIN | 파일 이어 붙이기 |
| 쓰는 곳 | 다른 정보를 붙임 | 같은 구조의 데이터를 모음 |

> **크롤링한 페이지 100개를 합칠 때는 `concat`, 고객 정보를 붙일 때는 `merge`.**

### join — 인덱스 기준 병합

```python
left.join(right)                    # 인덱스 기준
left.join(right, on="key")          # 왼쪽 열 ↔ 오른쪽 인덱스
```

> `merge` 로 대부분 해결되므로 `join` 은 인덱스가 의미 있을 때만 쓰세요.

## ④ 단계별 실습

### Step 1. groupby 기본

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 500

df = pd.DataFrame({
    "order_id": np.arange(1, n + 1),
    "region": rng.choice(["서울", "부산", "제주", "강원"], n, p=[.4, .25, .2, .15]),
    "category": rng.choice(["가전", "식품", "의류", "도서"], n, p=[.2, .35, .3, .15]),
    "customer_id": rng.integers(1, 80, n),
    "quantity": rng.integers(1, 10, n),
    "price": rng.integers(5000, 200000, n),
})
df["sales"] = df["price"] * df["quantity"]

print("=" * 74)
print("                    groupby 기본")
print("=" * 74)
print(f"\n전체 {len(df)}건 · 총매출 {df['sales'].sum():,}원")

# ── ① 단일 그룹 ──
print(f"\n[① 지역별 평균 매출]")
print(df.groupby("region")["sales"].mean().round(0).to_string())

# ── ② 여러 집계 함수 ──
print(f"\n[② 지역별 여러 통계]")
print(df.groupby("region")["sales"]
        .agg(["count", "sum", "mean", "max"])
        .round(0).to_string())

# ── ③ 이름 지정 (권장) ──
print(f"\n[③ named aggregation — 열 이름이 깔끔]")
summary = df.groupby("region").agg(
    주문수=("order_id", "size"),
    총매출=("sales", "sum"),
    평균매출=("sales", "mean"),
    최대매출=("sales", "max"),
    고객수=("customer_id", "nunique"),
    평균수량=("quantity", "mean"),
).round(0)

summary["객단가"] = (summary["총매출"] / summary["고객수"]).round(0)
summary = summary.sort_values("총매출", ascending=False)
print(summary.to_string())

# ── ④ 다중 키 ──
print(f"\n[④ 지역 × 카테고리별 매출]")
multi = df.groupby(["region", "category"])["sales"].sum()
print(multi.head(8).to_string())
print(f"  ... 총 {len(multi)}개 조합")

# ── ⑤ 정렬 ──
print(f"\n[⑤ 상위 5개 조합]")
print(multi.nlargest(5).to_string())

# ── ⑥ count vs size ──
df_na = df.copy()
df_na.loc[rng.choice(n, 50, replace=False), "sales"] = np.nan

print(f"\n[⑥ count vs size — 결측 50건 있을 때]")
cmp = pd.DataFrame({
    "size (행 수)": df_na.groupby("region")["sales"].size(),
    "count (결측 제외)": df_na.groupby("region")["sales"].count(),
})
cmp["결측"] = cmp["size (행 수)"] - cmp["count (결측 제외)"]
print(cmp.to_string())

print("\n" + "=" * 74)
```

### Step 2. transform · filter · 그룹별 상위 n개

```python
import numpy as np
import pandas as pd

# (위 df 사용)

print("=" * 76)
print("              transform / filter / 그룹별 상위")
print("=" * 76)

# ══════════ transform ══════════
print(f"\n[transform — 원본 크기 유지]")

agg_result = df.groupby("region")["sales"].mean()
trans_result = df.groupby("region")["sales"].transform("mean")

print(f"  agg      → {len(agg_result):>4}행 (지역 수)")
print(f"  transform → {len(trans_result):>4}행 (원본 행 수)")

d = df.copy()
d["지역평균"] = d.groupby("region")["sales"].transform("mean").round(0)
d["평균대비"] = (d["sales"] / d["지역평균"] * 100).round(0)
d["지역내순위"] = d.groupby("region")["sales"].rank(
    ascending=False, method="min").astype(int)

print(f"\n  [활용 예]")
print(d[["region", "sales", "지역평균", "평균대비", "지역내순위"]]
      .head(6).to_string(index=False))

# ── 그룹별 결측 채우기 ──
d2 = df.copy()
d2.loc[np.random.default_rng(1).choice(len(d2), 40, replace=False), "sales"] = np.nan

before = d2["sales"].isna().sum()
d2["sales_filled"] = d2["sales"].fillna(
    d2.groupby("region")["sales"].transform("mean"))
after = d2["sales_filled"].isna().sum()

print(f"\n  [그룹 평균으로 결측 채우기]")
print(f"    결측 {before}건 → {after}건")
print(f"    전체 평균으로 채우면: {d2['sales'].mean():,.0f}원 (모두 같은 값)")
print(f"    지역 평균으로 채우면: 지역마다 다른 값  ← 더 정확")

# ── 그룹별 표준화 ──
g = df.groupby("region")["sales"]
d["z_score"] = ((df["sales"] - g.transform("mean")) / g.transform("std")).round(2)
print(f"\n  [그룹별 표준화] 각 지역의 z-score 평균: "
      f"{d.groupby('region')['z_score'].mean().round(6).to_dict()}")

# ══════════ filter ══════════
print(f"\n{'=' * 76}")
print("[filter — 그룹 단위로 남기거나 버리기]")
print("=" * 76)

big_regions = df.groupby("region").filter(lambda g: len(g) >= 130)
print(f"\n  130건 이상인 지역만: {big_regions['region'].unique()}")
print(f"  {len(df)}건 → {len(big_regions)}건")

high_avg = df.groupby("category").filter(lambda g: g["sales"].mean() > 570000)
print(f"\n  평균 매출 57만원 초과 카테고리: {sorted(high_avg['category'].unique())}")

# ══════════ 그룹별 상위 n개 ══════════
print(f"\n{'=' * 76}")
print("[그룹별 상위 3개 — 3가지 방법]")
print("=" * 76)

# 방법 ① sort + head (가장 빠름)
top1 = (df.sort_values("sales", ascending=False)
          .groupby("region").head(3)
          .sort_values(["region", "sales"], ascending=[True, False]))

# 방법 ② rank 로 필터
d3 = df.copy()
d3["rank"] = d3.groupby("region")["sales"].rank(ascending=False, method="first")
top2 = d3[d3["rank"] <= 3].sort_values(["region", "rank"])

print(f"\n  방법 ①: sort_values().groupby().head(3)  → {len(top1)}건")
print(f"  방법 ②: rank() 로 순위 매기고 필터          → {len(top2)}건")

print(f"\n  [지역별 매출 상위 3건]")
print(top1[["region", "category", "quantity", "sales"]].to_string(index=False))

print("\n" + "=" * 76)
```

실행 결과 (일부):

```
==========================================================================
              transform / filter / 그룹별 상위
==========================================================================

[transform — 원본 크기 유지]
```

```python

    # 일부러 없는 고객 ID 섞기 (매칭 실패 확인용)

                  + pd.to_timedelta(rng.integers(0, 180), unit="D"),
})

print("=" * 78)
print("                        merge 실습")
print("=" * 78)
print(f"\n  customers: {customers.shape}   products: {products.shape}   "

      f"{sorted(only_orders['customer_id'].unique())[:10]}")

# ══════════ 3개 테이블 연결 ══════════
print(f"\n{'=' * 78}")

print("=" * 78)

print("\n" + "=" * 78)
print("정리:")
```

## ⑥ 확인 문제

**1.** 아래 각 상황에 `agg` / `transform` / `filter` 중 무엇을 쓸지 고르세요.

① 지역별 평균 매출 표 만들기
② 각 주문이 자기 지역 평균의 몇 %인지 계산
③ 주문이 100건 넘는 지역의 데이터만 남기기
④ 결측치를 그 지역의 평균으로 채우기

<details>
<summary>답 보기</summary>

| # | 선택 | 이유 | 결과 크기 |
|---|---|---|---|
| ① | **`agg`** | 그룹당 하나의 값 → 요약표 | 그룹 수 |
| ② | **`transform`** | 원본 각 행에 그룹 값이 필요 | 원본 행 수 |
| ③ | **`filter`** | 그룹 전체를 남기거나 버림 | 원본 이하 |
| ④ | **`transform`** | 각 행에 그 그룹의 평균이 필요 | 원본 행 수 |

```python
import numpy as np
import pandas as pd

# ① agg — 요약표
summary = df.groupby("region").agg(
    주문수=("sales", "size"),
    평균매출=("sales", "mean"),
).round(0)
print(f"① agg      → {summary.shape}  (지역 수)")

# ② transform — 원본에 붙이기
d = df.copy()
d["지역평균"] = d.groupby("region")["sales"].transform("mean")
d["평균대비%"] = (d["sales"] / d["지역평균"] * 100).round(1)
print(f"② transform → {len(d)}행  (원본 크기 유지)")

# ③ filter — 그룹 단위 필터
big = df.groupby("region").filter(lambda g: len(g) > 100)
print(f"③ filter    → {len(df)}행 → {len(big)}행  "
      f"(남은 지역: {sorted(big['region'].unique())})")

# ④ transform — 그룹 평균으로 결측 채우기
d2 = df.copy()
d2.loc[np.random.default_rng(0).choice(len(d2), 30, replace=False), "sales"] = np.nan

print(f"\n④ 결측 채우기 비교")
print(f"   결측: {d2['sales'].isna().sum()}건")

# 전체 평균 (부정확)
global_fill = d2["sales"].fillna(d2["sales"].mean())

# 그룹 평균 (정확)
group_fill = d2["sales"].fillna(
    d2.groupby("region")["sales"].transform("mean"))

comparison = pd.DataFrame({
    "region": d2.loc[d2["sales"].isna(), "region"],
    "전체평균으로": global_fill[d2["sales"].isna()].round(0),
    "지역평균으로": group_fill[d2["sales"].isna()].round(0),
}).head(5)
print(comparison.to_string(index=False))
print(f"   → 전체 평균은 모두 같은 값, 지역 평균은 지역마다 다름")
```

**핵심 구분법**

```
결과가 그룹 수만큼        → agg
결과가 원본 행 수만큼      → transform
그룹 자체를 남기거나 버림   → filter
```

> **④번이 실무에서 중요합니다.**
> 서울의 결측을 전국 평균으로 채우면 서울의 특성이 사라집니다.
> **그룹 평균으로 채우면 훨씬 합리적**입니다. [Day 056](day-056.md)에서 다시 다룹니다.

**2.** 주문·고객·상품 3개 테이블을 합쳐 아래를 구하세요.
① 지역별 × 카테고리별 매출 피벗 ② VIP 고객의 인기 상품 TOP 3 ③ 매칭 실패 건수

<details>
<summary>답 보기</summary>

```python
import numpy as np
import pandas as pd


def merge_and_check(orders, customers, products):
    """
    3개 테이블을 병합하고 매칭 상태를 진단합니다.
    반환: (병합 결과, 진단 정보 dict)
    """
    report = {"원본 주문": len(orders)}

    # ── ① 병합 전 키 검증 ──
    for name, df, key in [("customers", customers, "customer_id"),
                          ("products", products, "product_id")]:
        dup = df[key].duplicated().sum()
        if dup:
            print(f"  ⚠ {name} 의 {key} 에 중복 {dup}건 — 행이 늘어날 수 있음")

    # ── ② 고객 병합 (left 로 주문 보존) ──
    step1 = orders.merge(customers, on="customer_id",
                         how="left", indicator="cust_match")
    report["고객 매칭 실패"] = (step1["cust_match"] == "left_only").sum()

    # ── ③ 상품 병합 ──
    full = step1.merge(products, on="product_id",
                       how="left", indicator="prod_match")
    report["상품 매칭 실패"] = (full["prod_match"] == "left_only").sum()

    report["병합 후"] = len(full)
    report["완전한 행"] = ((full["cust_match"] == "both")
                          & (full["prod_match"] == "both")).sum()

    # ── ④ 매출 계산 ──
    full["sales"] = full["price"] * full["quantity"]

    return full, report


# ══════════ 실행 ══════════

print("=" * 70)
print("[병합 진단]")
print("=" * 70)
for k, v in report.items():
    print(f"  {k:<16}{v:>6,}건")

if report["고객 매칭 실패"]:
    missing = full.loc[full["cust_match"] == "left_only", "customer_id"].unique()
    print(f"\n  ⚠ 고객 정보가 없는 customer_id: {sorted(missing)[:10]}")

# 완전한 행만 분석에 사용
valid = full[(full["cust_match"] == "both")
             & (full["prod_match"] == "both")].copy()

print(f"\n  분석 대상: {len(valid):,}건 "
      f"({len(valid)/len(full)*100:.1f}%)")

# ══════════ ① 지역 × 카테고리 매출 ══════════
print(f"\n{'=' * 70}")
print("① 지역별 × 카테고리별 매출")
print("=" * 70)

pivot = pd.pivot_table(
    valid, index="region", columns="category", values="sales",
    aggfunc="sum", fill_value=0, margins=True, margins_name="합계",
)
print(pivot.map(lambda x: f"{x:,.0f}").to_string())

# 비율로도
print(f"\n   [행 기준 비율 %]")
pct = pivot.iloc[:-1, :-1]
pct = (pct.div(pct.sum(axis=1), axis=0) * 100).round(1)
print(pct.to_string())

# ══════════ ② VIP 인기 상품 TOP 3 ══════════
print(f"\n{'=' * 70}")
print("② VIP 고객의 인기 상품 TOP 3")
print("=" * 70)

vip = valid[valid["grade"] == "VIP"]

top3 = (vip.groupby(["product_name", "category"])
           .agg(주문수=("order_id", "size"),
                총수량=("quantity", "sum"),
                총매출=("sales", "sum"))
           .sort_values("총매출", ascending=False)
           .head(3)
           .reset_index())

print(f"\n  VIP 주문 {len(vip)}건 (전체의 {len(vip)/len(valid)*100:.1f}%)")
print(top3.to_string(index=False))

# 일반 고객과 비교
print(f"\n   [등급별 비교]")
grade_cmp = valid.groupby("grade").agg(
    고객수=("customer_id", "nunique"),
    주문수=("order_id", "size"),
    총매출=("sales", "sum"),
    평균객단가=("sales", "mean"),
).round(0)
grade_cmp["1인당주문"] = (grade_cmp["주문수"] / grade_cmp["고객수"]).round(1)
grade_cmp["1인당매출"] = (grade_cmp["총매출"] / grade_cmp["고객수"]).round(0)
print(grade_cmp.to_string())
```

**설계 포인트 5가지**

| 항목 | 이유 |
|---|---|
| **병합 전 키 중복 확인** | 중복이 있으면 행이 곱해짐 |
| **`how="left"`** | 왼쪽(주문)을 잃지 않음 |
| **`indicator`** | 매칭 실패를 정량적으로 확인 |
| 진단 결과를 dict 로 반환 | 나중에 로그로 남기거나 검증에 사용 |
| 완전한 행만 분석 | 결측이 섞인 채 집계하면 잘못된 결론 |

> **`how="inner"` 를 썼다면 28건이 조용히 사라졌을 것**입니다.
> `merge` 전후로 **행 수를 반드시 비교**하는 습관을 들이세요.

**3.** 아래 코드는 결과가 이상합니다. 문제 3가지를 찾고 고치세요.

```python
import pandas as pd

df["region_avg"] = df.groupby("region")["sales"].mean()

merged = orders.merge(products, on="product_id")

result = df.groupby("region").agg({"sales": ["mean", "sum"]})
print(result["평균"])
```

<details>
<summary>답 보기</summary>

**문제 3가지**

**① `agg` 결과를 원본 열에 대입 — 대부분 `NaN`**

```python
df["region_avg"] = df.groupby("region")["sales"].mean()
```

`groupby().mean()` 은 **지역 수만큼(4행)** 인데, `df` 는 500행입니다.
인덱스가 `["서울","부산",...]` 이라 원본 인덱스(0~499)와 맞지 않아 **전부 `NaN`** 이 됩니다.

```python
print(df["region_avg"].isna().sum())      # 500 (전부 결측)
```

**해결** — `transform` 을 씁니다.

```python
df["region_avg"] = df.groupby("region")["sales"].transform("mean")
```

**② `merge` 의 `how` 미지정 — 데이터가 조용히 사라짐**

```python
merged = orders.merge(products, on="product_id")     # how="inner" 기본
```

매칭 안 되는 주문이 **경고 없이 제거**됩니다.

**해결** — `how="left"` + `indicator=True` 로 확인합니다.

```python
merged = orders.merge(products, on="product_id",
                      how="left", indicator=True)
print(merged["_merge"].value_counts())
```

**③ 다중 인덱스 열에 잘못된 이름으로 접근**

```python
result = df.groupby("region").agg({"sales": ["mean", "sum"]})
result["평균"]        # KeyError
```

열이 `("sales","mean")`, `("sales","sum")` 형태의 **다중 인덱스**입니다.
`"평균"` 이라는 열은 없습니다.

**해결 — named aggregation**

```python
result = df.groupby("region").agg(
    평균=("sales", "mean"),
    합계=("sales", "sum"),
)
result["평균"]        # ✅
```

**전체 수정**

```python
import pandas as pd

# ── ① transform 사용 ──
df = df.copy()
df["region_avg"] = df.groupby("region")["sales"].transform("mean").round(0)
df["vs_avg_pct"] = (df["sales"] / df["region_avg"] * 100).round(1)

print(f"① region_avg 결측: {df['region_avg'].isna().sum()}건  (0이어야 정상)")
print(df[["region", "sales", "region_avg", "vs_avg_pct"]].head(3).to_string(index=False))

# ── ② how 명시 + 검증 ──
before = len(orders)
merged = orders.merge(products, on="product_id", how="left", indicator=True)
after = len(merged)

print(f"\n② merge 전후: {before}건 → {after}건")
print(merged["_merge"].value_counts().to_string())

failed = (merged["_merge"] == "left_only").sum()
if failed:
    print(f"   ⚠ 매칭 실패 {failed}건 — product_id 확인 필요")

merged = merged.drop(columns=["_merge"])

# ── ③ named aggregation ──
result = df.groupby("region").agg(
    건수=("sales", "size"),
    평균=("sales", "mean"),
    합계=("sales", "sum"),
    최대=("sales", "max"),
).round(0)

print(f"\n③ 열 이름: {list(result.columns)}   ← 단일 인덱스")
print(result.to_string())
print(f"\n   result['평균'] 접근 가능: {result['평균'].iloc[0]:,.0f}")
```

## 오늘의 정리 · W10 총정리

| 개념 | 핵심 |
|---|---|
| `groupby` | **분할–적용–결합** |
| `agg` | 그룹당 하나의 값 → **요약표** (그룹 수) |
| **named agg** | `agg(이름=("열", "함수"))` — 다중 인덱스 방지 |
| `transform` | **원본 각 행에** 그룹 값 (원본 행 수) |
| `filter` | 그룹 전체를 남기거나 버림 |
| 그룹별 상위 n | `sort_values().groupby().head(n)` |
| `pivot_table` | 교차표 (넓은 형태) · `margins=True` 로 합계 |
| `crosstab` | 빈도 교차표 · `normalize="index"` 로 비율 |
| **`merge`** | 키 기준 (SQL JOIN) · **`how` 명시** · `indicator=True` |
| `concat` | 같은 구조를 이어 붙임 · `ignore_index=True` |
