## 3. 개념

### 3-1. 포맷 설계의 원칙

```
   │  ③ 크기 정보      "얼마나 읽어야 하나?"                   │
   │  ④ 검증           "손상되지 않았나?"                      │
   │  ⑤ 확장 여지      "나중에 필드를 추가할 수 있나?"         │
```

### 3-2. `.map` 포맷 설계

**왜 필요한가** — 오늘 만들 실제 포맷.

```
   ┌────────────────────────── 헤더 (32바이트) ──────────────────────┐
   │ 오프셋 │ 크기 │ 타입     │ 내용                                  │
   ├────────┼──────┼──────────┼───────────────────────────────────────┤
   │   0    │  4   │ char[4]  │ 매직 "KMAP"                           │
   │   4    │  4   │ uint32   │ 버전 (현재 2)                         │
   │   8    │  4   │ int32    │ 맵 폭 (cols)                          │
   │  12    │  4   │ int32    │ 맵 높이 (rows)                        │
   │  16    │  4   │ int32    │ 타일 폭 (픽셀)                        │
   │  20    │  4   │ int32    │ 타일 높이 (픽셀)                      │
   │  24    │  4   │ int32    │ 레이어 수                             │
   │  28    │  1   │ uint8    │ 맵 타입 (0=그리드, 1=아이소)          │
   │  29    │  3   │ uint8[3] │ 예약 (0으로 채움)                     │
   ├────────┴──────┴──────────┴───────────────────────────────────────┤
   │                       타일셋 이름 (64바이트)                      │
   ├──────────────────────────────────────────────────────────────────┤
   │  레이어 0 데이터    cols × rows × sizeof(TileData)                │
   │  레이어 1 데이터                                                  │
   │  레이어 2 데이터                                                  │
   ├──────────────────────────────────────────────────────────────────┤
   │  체크섬 (4바이트)                                                 │
   └──────────────────────────────────────────────────────────────────┘
```

```cpp
// Common/MapFormat.h
#pragma once
#include <cstdint>

#define MAP_MAGIC     0x50414D4B          // "KMAP" (리틀 엔디안)
#define MAP_VERSION   2

#pragma pack(push, 1)                     // ★ 패딩 제거

struct MapHeader
{
    uint32_t magic;
    uint32_t version;
    int32_t  cols;
    int32_t  rows;
    int32_t  tileW;
    int32_t  tileH;
    int32_t  layerCount;
    uint8_t  mapType;                     // 0=grid, 1=iso
    uint8_t  reserved[3];
    char     tilesetName[64];
};

struct TileData
{
    int16_t  tileIndex;                   // -1 = 비어 있음
    uint8_t  attribute;                   // 통과 가능, 이동 비용
    uint8_t  height;                      // 높이 (아이소용)
};

#pragma pack(pop)
```

```
   ★ #pragma pack(push, 1) 을 쓰는 이유

   Day 26에서 배운 구조체 패딩 문제

   패딩 있음:  sizeof(TileData) = 4 또는 8 (컴파일러마다)
   패딩 없음:  sizeof(TileData) = 4 (항상)

   → 파일 크기가 환경에 따라 달라지지 않는다
```

### 3-3. ⚠️ 매직 넘버와 엔디안

**왜 필요한가** — 바이트 순서를 잘못 이해하면 매직 넘버가 안 맞는다.

```
   "KMAP" 을 uint32 로 읽으면?

   파일의 바이트:   'K'(0x4B) 'M'(0x4D) 'A'(0x41) 'P'(0x50)

   리틀 엔디안(x86)에서 uint32 로 읽으면:
     0x50414D4B                     ← 역순!

   ★ 그래서 상수를 0x50414D4B 로 정의한다
```

**더 안전한 방법 — 문자 배열로**

```cpp
    // 비교가 명확하다
    char magic[4];
    fread(magic, 1, 4, fp);

    if (memcmp(magic, "KMAP", 4) != 0)
    {
        // 다른 파일
    }
```

> **문자 배열 방식을 권한다.** 엔디안을 신경 쓸 필요가 없다.

### 3-4. 버전 관리

**왜 필요한가** — 포맷은 반드시 바뀐다. 옛 파일을 못 읽으면 작업물이 날아간다.

```
   버전 1  →  버전 2 변경 사항

   v1:  레이어 1개, 타일에 index/attribute만
   v2:  레이어 여러 개, height 추가, 타일셋 이름 추가
```

```cpp
bool LoadMap(const char* path, TileMap& map)
{
    FILE* fp = nullptr;
    if (fopen_s(&fp, path, "rb") != 0) return false;

    MapHeader h;
    if (fread(&h, sizeof(h), 1, fp) != 1) { fclose(fp); return false; }

    if (memcmp(&h.magic, "KMAP", 4) != 0)
    {
        DebugLog("[Map] 지원하지 않는 파일\n");
        fclose(fp); return false;
    }

    if (h.version > MAP_VERSION)
    {
        DebugLog("[Map] 파일 버전 %d 이 프로그램 버전 %d 보다 높습니다\n",
                 h.version, MAP_VERSION);
        fclose(fp); return false;              // 미래 버전은 못 읽는다
    }

    bool ok = false;

    switch (h.version)
    {
    case 1: ok = LoadV1(fp, h, map); break;    // ★ 옛 버전 지원
    case 2: ok = LoadV2(fp, h, map); break;
    default:
        DebugLog("[Map] 알 수 없는 버전 %d\n", h.version);
        break;
    }

    fclose(fp);
    return ok;
}
```

```
   ★ 버전 정책

   상위 호환 (옛 프로그램이 새 파일 읽기)  →  대부분 불가능
   하위 호환 (새 프로그램이 옛 파일 읽기)  →  ★ 반드시 지원

   → 저장은 항상 최신 버전으로
   → 로드는 모든 버전 지원
```

### 3-5. 검증 — 손상된 파일 방어

**왜 필요한가** — 아무 파일이나 열었을 때 죽으면 안 된다.

```cpp
bool ValidateHeader(const MapHeader& h)
{
    if (h.cols <= 0 || h.cols > 4096)   { DebugLog("[Map] 잘못된 폭\n");   return false; }
    if (h.rows <= 0 || h.rows > 4096)   { DebugLog("[Map] 잘못된 높이\n"); return false; }
    if (h.tileW <= 0 || h.tileW > 512)  { return false; }
    if (h.tileH <= 0 || h.tileH > 512)  { return false; }
    if (h.layerCount <= 0 || h.layerCount > 8) { return false; }
    if (h.mapType > 1)                  { return false; }

    // 총 크기 검사 (메모리 폭탄 방지)
    long long total = (long long)h.cols * h.rows * h.layerCount;
    if (total > 16 * 1024 * 1024)       { DebugLog("[Map] 너무 큼\n"); return false; }

    return true;
}
```

```
   ★ 왜 상한을 두는가

   손상된 파일에 cols = 2000000000 이 들어 있으면
   → malloc(2000000000 * 4) 시도
   → 메모리 부족 크래시 또는 시스템 정지

   ★ 악의적 파일에 대한 방어이기도 하다
```

**파일 크기 검증**

```cpp
    // 헤더에서 계산한 크기와 실제 파일 크기 비교
    fseek(fp, 0, SEEK_END);
    long fileSize = ftell(fp);
    fseek(fp, sizeof(MapHeader), SEEK_SET);

    {
        DebugLog("[Map] 파일 크기 불일치: 실제 %ld, 기대 %ld\n", fileSize, expected);
        return false;
    }
```

### 3-6. 체크섬

**왜 필요한가** — 파일이 중간에 손상됐는지 확인한다.

```cpp
uint32_t CalcChecksum(const void* data, size_t size)
{
    const uint8_t* p = (const uint8_t*)data;
    uint32_t sum = 0;

    for (size_t i = 0; i < size; i++)
    {
        sum = (sum << 1) | (sum >> 31);        // 순환 시프트
        sum += p[i];
    }

    return sum;
}
```

```
   ★ 간단한 체크섬으로 충분하다

   목적:  "파일이 깨졌나?" 확인
   목적 아님:  보안, 위변조 방지

   더 강력한 것: CRC32, MD5, SHA
   → 게임 데이터에는 과하다
```

```cpp
    // 저장 시
    uint32_t checksum = CalcChecksum(tileData, dataSize);
    fwrite(&checksum, sizeof(checksum), 1, fp);

    // 로드 시
    uint32_t fileChecksum;
    fread(&fileChecksum, sizeof(fileChecksum), 1, fp);

    uint32_t calcChecksum = CalcChecksum(tileData, dataSize);

    if (fileChecksum != calcChecksum)
    {
        DebugLog("[Map] 체크섬 불일치 — 파일이 손상되었습니다\n");
        return false;
    }
```

### 3-7. ⚠️ 안전 저장

**왜 필요한가** — `"w"` 모드로 열면 기존 파일이 즉시 지워진다. (Day 26)

```
   ✘ 위험한 저장

   fopen_s(&fp, "stage01.map", "wb");   ← 이 순간 원본이 지워진다
   fwrite(...);                          ← 여기서 실패하면?
   fclose(fp);

   → 원본도 없고 새 파일도 깨졌다
```

```
   ✔ 안전한 저장 (3단계)

   ① 임시 파일에 쓴다        stage01.map.tmp
   ② 성공하면 백업을 만든다   stage01.map → stage01.map.bak
   ③ 임시를 정식으로 바꾼다   stage01.map.tmp → stage01.map
```

```cpp
bool SaveMapSafe(const char* path, const TileMap& map)
{
    char tmpPath[MAX_PATH], bakPath[MAX_PATH];
    sprintf_s(tmpPath, "%s.tmp", path);
    sprintf_s(bakPath, "%s.bak", path);

    // ① 임시 파일에 저장
    if (!SaveMapRaw(tmpPath, map))
    {
        remove(tmpPath);                       // 실패 시 정리
        DebugLog("[Map] 임시 파일 저장 실패\n");
        return false;
    }

    // ② 기존 파일을 백업으로
    FILE* test = nullptr;
    if (fopen_s(&test, path, "rb") == 0)
    {
        fclose(test);

        remove(bakPath);                       // 이전 백업 제거
        if (rename(path, bakPath) != 0)
            DebugLog("[Map] 백업 생성 실패 (계속 진행)\n");
    }

    // ③ 임시를 정식으로
    if (rename(tmpPath, path) != 0)
    {
        DebugLog("[Map] 파일 교체 실패\n");
        return false;
    }

    DebugLog("[Map] 저장 완료: %s\n", path);
    return true;
}
```

```
   ★ 이 절차의 이득

   어느 단계에서 실패해도 원본이나 백업이 남는다

   ①에서 실패  →  원본 그대로
   ②에서 실패  →  원본 그대로 (백업만 없음)
   ③에서 실패  →  백업에 원본이 있다
```

### 3-8. 파일 대화상자

**왜 필요한가** — 경로를 코드에 박아 두면 쓸 수 없다.

```cpp
#include <commdlg.h>
#pragma comment(lib, "comdlg32.lib")

bool ShowSaveDialog(HWND hWnd, char* outPath, int outSize)
{
    char file[MAX_PATH] = "";

    OPENFILENAMEA ofn;
    ZeroMemory(&ofn, sizeof(ofn));             // ★ 반드시 초기화

    ofn.lStructSize  = sizeof(ofn);
    ofn.hwndOwner    = hWnd;
    ofn.lpstrFilter  = "맵 파일 (*.map)\0*.map\0모든 파일\0*.*\0";
    ofn.lpstrFile    = file;
    ofn.nMaxFile     = MAX_PATH;
    ofn.lpstrDefExt  = "map";
    ofn.Flags        = OFN_OVERWRITEPROMPT | OFN_PATHMUSTEXIST;

    if (!GetSaveFileNameA(&ofn)) return false;

    strcpy_s(outPath, outSize, file);
    return true;
}

bool ShowOpenDialog(HWND hWnd, char* outPath, int outSize)
{
    char file[MAX_PATH] = "";

    OPENFILENAMEA ofn;
    ZeroMemory(&ofn, sizeof(ofn));

    ofn.lStructSize = sizeof(ofn);
    ofn.hwndOwner   = hWnd;
    ofn.lpstrFilter = "맵 파일 (*.map)\0*.map\0모든 파일\0*.*\0";
    ofn.lpstrFile   = file;
    ofn.nMaxFile    = MAX_PATH;
    ofn.Flags       = OFN_FILEMUSTEXIST | OFN_PATHMUSTEXIST;

    if (!GetOpenFileNameA(&ofn)) return false;

    strcpy_s(outPath, outSize, file);
    return true;
}
```

### 3-10. 텍스트 포맷 (디버그용)

```cpp
bool ExportText(const char* path, const TileMap& map)
{
    FILE* fp = nullptr;
    if (fopen_s(&fp, path, "w") != 0) return false;

    fprintf(fp, "# KMAP Text Export\n");
    fprintf(fp, "size %d %d\n", map.GetCols(), map.GetRows());
    fprintf(fp, "tile %d %d\n", map.GetTileW(), map.GetTileH());
    fprintf(fp, "type %d\n", map.GetMapType());
    fprintf(fp, "layers %d\n\n", map.GetLayerCount());

    for (int L = 0; L < map.GetLayerCount(); L++)
    {
        fprintf(fp, "[layer %d]\n", L);

        for (int r = 0; r < map.GetRows(); r++)
        {
            for (int c = 0; c < map.GetCols(); c++)
            {
                const Tile* t = map.At(L, c, r);
                fprintf(fp, "%3d ", t ? t->tileIndex : -1);
            }
            fprintf(fp, "\n");
        }
        fprintf(fp, "\n");
    }

    fclose(fp);
    return true;
}
```

```cpp
bool SaveMapRaw(const char* path, const TileMap& map)
{
    FILE* fp = nullptr;
    if (fopen_s(&fp, path, "wb") != 0)
    {
        DebugLog("[Map] 파일 생성 실패: %s\n", path);
        return false;
    }

    // 헤더
    MapHeader h;
    memset(&h, 0, sizeof(h));

    memcpy(&h.magic, "KMAP", 4);
    h.version    = MAP_VERSION;
    h.cols       = map.GetCols();
    h.rows       = map.GetRows();
    h.tileW      = map.GetTileW();
    h.tileH      = map.GetTileH();
    h.layerCount = map.GetLayerCount();
    h.mapType    = (uint8_t)map.GetMapType();

    strcpy_s(h.tilesetName, sizeof(h.tilesetName), map.GetTilesetName());

    if (fwrite(&h, sizeof(h), 1, fp) != 1) { fclose(fp); return false; }

    // 타일 데이터
    int total = h.cols * h.rows;
    TileData* buf = new TileData[total];

    uint32_t checksum = 0;

    for (int L = 0; L < h.layerCount; L++)
    {
        for (int i = 0; i < total; i++)
        {
            const Tile* t = map.At(L, i % h.cols, i / h.cols);

            buf[i].tileIndex = (int16_t)(t ? t->tileIndex : -1);
            buf[i].attribute = (uint8_t)(t ? t->attribute : 0);
            buf[i].height    = (uint8_t)(t ? t->height : 0);
        }

        if (fwrite(buf, sizeof(TileData), total, fp) != (size_t)total)
        {
            delete[] buf; fclose(fp); return false;
        }

        checksum += CalcChecksum(buf, sizeof(TileData) * total);
    }

    delete[] buf;

    // 체크섬
    fwrite(&checksum, sizeof(checksum), 1, fp);

    fclose(fp);
    return true;
}
```

**✅ 여기까지 실행하면** — `.map` 파일이 만들어진다.

> **파일 크기를 계산과 비교한다.**
> `96 + 64*48*3*4 + 4 = 36,964` 바이트

### Step 3 — 로드

```cpp
bool LoadMapV2(const char* path, TileMap& map)
{
    FILE* fp = nullptr;
    if (fopen_s(&fp, path, "rb") != 0) return false;

    // 파일 크기
    fseek(fp, 0, SEEK_END);
    long fileSize = ftell(fp);
    fseek(fp, 0, SEEK_SET);

    if (fileSize < (long)sizeof(MapHeader))
    {
        DebugLog("[Map] 파일이 너무 짧습니다\n");
        fclose(fp); return false;
    }

    // 헤더
    MapHeader h;
    if (fread(&h, sizeof(h), 1, fp) != 1) { fclose(fp); return false; }

    // 매직
    if (memcmp(&h.magic, "KMAP", 4) != 0)
    {
        DebugLog("[Map] 맵 파일이 아닙니다\n");
        fclose(fp); return false;
    }

    // 버전
    if (h.version > MAP_VERSION)
    {
        DebugLog("[Map] 지원하지 않는 버전 %u (최대 %u)\n", h.version, MAP_VERSION);
        fclose(fp); return false;
    }

    // 값 검증
    if (!ValidateHeader(h)) { fclose(fp); return false; }

    // 크기 검증
    long expected = sizeof(MapHeader)
                  + (long)h.cols * h.rows * h.layerCount * sizeof(TileData)
                  + sizeof(uint32_t);

    if (fileSize != expected)
    {
        DebugLog("[Map] 크기 불일치: %ld != %ld\n", fileSize, expected);
        fclose(fp); return false;
    }

    // 맵 생성
    if (!map.Create(h.cols, h.rows, h.tileW, h.tileH, h.layerCount))
    {
        fclose(fp); return false;
    }

    map.SetMapType((MapType)h.mapType);
    map.SetTilesetName(h.tilesetName);

    // 타일 데이터
    int total = h.cols * h.rows;
    TileData* buf = new TileData[total];

    uint32_t checksum = 0;

    for (int L = 0; L < h.layerCount; L++)
    {
        if (fread(buf, sizeof(TileData), total, fp) != (size_t)total)
        {
            delete[] buf; fclose(fp); return false;
        }

        checksum += CalcChecksum(buf, sizeof(TileData) * total);

        for (int i = 0; i < total; i++)
        {
            Tile* t = map.At(L, i % h.cols, i / h.cols);
            if (!t) continue;

            t->tileIndex = buf[i].tileIndex;
            t->attribute = buf[i].attribute;
            t->height    = buf[i].height;
        }
    }

    delete[] buf;

    // 체크섬
    uint32_t fileChecksum = 0;
    fread(&fileChecksum, sizeof(fileChecksum), 1, fp);

    fclose(fp);

    if (fileChecksum != checksum)
    {
        DebugLog("[Map] 체크섬 불일치 — 손상된 파일\n");
        return false;
    }

    DebugLog("[Map] 로드 성공: %s (%dx%d, 레이어 %d)\n",
             path, h.cols, h.rows, h.layerCount);
    return true;
}
```

**✅ 여기까지 실행하면** — 저장한 맵이 그대로 복원된다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 저장 후 로드하면 깨짐 | 쓰기/읽기 순서 불일치 | 포맷 표대로 대조 |
| 파일 크기가 환경마다 다름 | 구조체 패딩 | `#pragma pack(push,1)` |
| 매직 비교가 안 맞음 | 엔디안 | 문자 배열로 비교 |
| 대화상자에서 크래시 | `OPENFILENAME` 미초기화 | `ZeroMemory` |
| 필터가 안 보임 | 널 문자 형식 오류 | `"이름\0패턴\0\0"` |
| 대화상자 후 화면이 튐 | `dt` 폭증 | `Timer::Reset()` |
| 원본이 날아감 | `"wb"`로 직접 저장 | 안전 저장 3단계 |
| 큰 파일에서 크래시 | 크기 검증 없음 | `ValidateHeader` 상한 |
| 체크섬이 항상 불일치 | 저장/로드 계산 범위 다름 | 같은 데이터로 계산 |
| v1 파일이 안 열림 | 버전 분기 없음 | `switch (version)` |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| **매직 넘버** | "우리 파일이 맞나?" 문자 배열로 비교 |
| **버전 필드** | 하위 호환 필수. 로드는 모든 버전, 저장은 최신 |
| `#pragma pack(1)` | 패딩 제거. 파일 크기가 환경에 무관 |
| **값 검증** | 상한을 둬서 메모리 폭탄 방지 |
| 크기 검증 | 헤더 계산값과 실제 파일 크기 비교 |
| **체크섬** | 손상 감지. 보안용은 아니다 |
| **안전 저장** | 임시 → 백업 → 교체 3단계 |
| 파일 대화상자 | `GetOpenFileName` / `GetSaveFileName` |
| 수정 추적 | `*` 표시 + 종료 확인 |
| 텍스트 내보내기 | 디버그·버전관리용 |
