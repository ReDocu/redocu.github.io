## ③ 개념 설명

### HTML 문서 구조

```html
<!DOCTYPE html>              <!-- 문서 타입 선언 -->
<html lang="ko">             <!-- ★ 언어 (스크린리더·번역) -->
<head>
  <meta charset="utf-8">     <!-- ★ 한글 -->
  <meta name="viewport"
        content="width=device-width, initial-scale=1">   <!-- ★ 모바일 -->
  <title>제목</title>          <!-- 브라우저 탭 -->
  <link rel="stylesheet" href="...">
</head>
<body>
  <!-- 화면에 보이는 내용 -->
</body>
</html>
```

**★ `viewport` meta 가 없으면**

```
휴대폰이 페이지를 980px 데스크톱으로 가정하고 축소해서 보여 줍니다
→ 글씨가 아주 작아짐
→ ★ 미디어 쿼리도 동작하지 않음
```

### 핵심 태그 10개

| 태그 | 용도 | 특성 |
|---|---|---|
| **`<div>`** | 의미 없는 묶음 | 블록 |
| **`<span>`** | 의미 없는 인라인 묶음 | 인라인 |
| `<h1>`~`<h6>` | 제목 | 블록 · ★ 순서대로 |
| `<p>` | 문단 | 블록 |
| **`<a>`** | 링크 | 인라인 |
| **`<img>`** | 이미지 | 인라인 · ★ `alt` 필수 |
| **`<form>`** | 입력 묶음 | 블록 |
| **`<input>`** | 입력 필드 | 인라인 |
| **`<button>`** | 버튼 | 인라인 |
| **`<table>`** | 표 | 블록 |

**의미 태그 (semantic)**

```html
<header>   머리말
<nav>      네비게이션
<main>     ★ 주요 내용 (페이지당 1개)
<section>  구역
<article>  독립적인 글
<aside>    부가 정보
<footer>   꼬리말
<figure>   그림 + 설명
<figcaption>  그림 설명
```

```
★ 왜 <div> 대신 쓰나
  · 스크린리더가 구조를 이해
  · 코드를 읽기 쉬움
  · 검색엔진이 이해 (우리 프로젝트엔 무관)

★ 우리는 header · nav · main · footer · figure 정도만 씁니다
```

### 블록 vs 인라인

```
블록 (block)
  · 가로 전체를 차지
  · 위아래로 쌓임
  · width · height 지정 가능
  · div · p · h1 · table · form

인라인 (inline)
  · 내용만큼만 차지
  · 옆으로 나열
  · ★ width · height 무시됨
  · span · a · img · input · button

인라인 블록 (inline-block)
  · 옆으로 나열되면서 크기 지정 가능
```

```css
display: block;
display: inline;
display: inline-block;
display: flex;          /* ★ 오늘의 핵심 */
display: grid;
display: none;          /* 숨김 */
```

### ★ 박스 모델

```
┌─────────────────────────────────────┐
│           margin (바깥 여백)          │
│  ┌───────────────────────────────┐  │
│  │        border (테두리)         │  │
│  │  ┌─────────────────────────┐  │  │
│  │  │    padding (안쪽 여백)    │  │  │
│  │  │  ┌───────────────────┐  │  │  │
│  │  │  │     content       │  │  │  │
│  │  │  │   width × height  │  │  │  │
│  │  │  └───────────────────┘  │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

**★ `box-sizing` — 가장 중요한 CSS 한 줄**

```css
/* 기본 (content-box) */
.a { width: 200px; padding: 20px; border: 2px solid; }
/* → 실제 너비 = 200 + 20*2 + 2*2 = ★ 244px */

/* ★ border-box */
* { box-sizing: border-box; }
.a { width: 200px; padding: 20px; border: 2px solid; }
/* → 실제 너비 = ★ 200px (padding·border 포함) */
```

```
★ 모든 프로젝트에서 첫 줄에 이걸 씁니다

* { box-sizing: border-box; }
```

**여백 단축 표기**

```css
padding: 10px;                  /* 상하좌우 */
padding: 10px 20px;             /* 상하 | 좌우 */
padding: 10px 20px 30px;        /* 상 | 좌우 | 하 */
padding: 10px 20px 30px 40px;   /* 상 | 우 | 하 | 좌 (시계방향) */
```

**★ margin 상쇄 (collapsing)**

```html
<p style="margin-bottom: 20px">A</p>
<p style="margin-top: 30px">B</p>
```

```
간격이 50px 이 아니라 ★ 30px (큰 쪽만 적용)

→ 세로 여백은 겹칩니다
→ Flexbox 안에서는 ★ 상쇄가 일어나지 않습니다
```

### CSS 선택자

```css
/* 태그 */
p { }

/* 클래스 — ★ 가장 많이 씀 */
.card { }

/* id — 페이지에 하나만 */
#header { }

/* 자손 (모든 하위) */
.card p { }

/* 자식 (직계만) */
.card > p { }

/* 여러 개 */
h1, h2, h3 { }

/* 속성 */
input[type="file"] { }

/* 가상 클래스 */
a:hover { }
button:disabled { }
tr:nth-child(even) { }
li:first-child { }

/* 가상 요소 */
.badge::before { content: "●"; }
```

**우선순위 (특이성)**

```
인라인 style     1000
#id               100
.class · :hover    10
태그 · ::before     1

★ 같은 점수면 나중에 쓴 것이 이김
★ !important 는 전부 무시 — 쓰지 마세요
```

```
★ 우리 프로젝트 규칙
  · 클래스만 사용 (id 는 JS 용으로만)
  · 중첩은 2단계까지
  · !important 금지
```

### 단위

| 단위 | 기준 | 용도 |
|---|---|---|
| `px` | 절대 | 테두리 · 작은 여백 |
| `%` | 부모 크기 | 너비 |
| **`rem`** | ★ 루트 글꼴 (보통 16px) | **글자 · 여백** |
| `em` | 자신의 글꼴 | 상대 여백 |
| `vw` `vh` | 뷰포트 너비/높이 | 전체 화면 |
| `fr` | Grid 비율 | Grid 전용 |

```css
font-size: 1rem;        /* 16px */
font-size: 0.875rem;    /* 14px */
padding: 1rem 1.5rem;   /* 16px 24px */
```

> **★ `rem` 을 쓰면 사용자가 브라우저 글꼴 크기를 키웠을 때 함께 커집니다.**
> 접근성에 좋습니다. 다만 우리 프로젝트에서는 `px` 도 무방합니다.

### ★ Flexbox — 한 방향 배치

```css
.container {
  display: flex;
}
```

**주축(main axis)과 교차축(cross axis)**

```
flex-direction: row (기본)
  주축 →  가로
  교차축 ↓ 세로

  ┌─────────────────────────┐
  │ [A] [B] [C]             │  → justify-content
  │                         │  ↓ align-items
  └─────────────────────────┘

flex-direction: column
  주축 ↓  세로
  교차축 → 가로
```

**주요 속성**

```css
.container {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse */
  justify-content: flex-start;  /* ★ 주축 정렬 */
  align-items: stretch;         /* ★ 교차축 정렬 */
  gap: 12px;                    /* ★ 항목 간격 */
  flex-wrap: wrap;              /* ★ 줄바꿈 허용 */
}
```

**`justify-content` (주축)**

```
flex-start     [A][B][C]········
center         ····[A][B][C]····
flex-end       ········[A][B][C]
space-between  [A]····[B]····[C]     ★ 양끝 붙음
space-around   ··[A]···[B]···[C]··
space-evenly   ···[A]··[B]··[C]···
```

**`align-items` (교차축)**

```
stretch     ← 기본. 높이를 채움
flex-start  ← 위쪽
center      ← ★ 세로 가운데
flex-end    ← 아래쪽
baseline    ← 글자 기준선
```

**자식 속성**

```css
.item {
  flex: 1;              /* ★ 남은 공간을 균등 분배 */
  flex: 0 0 200px;      /* 늘어나지도 줄지도 않고 200px */
  flex-grow: 1;         /* 남은 공간 차지 비율 */
  flex-shrink: 0;       /* ★ 0 이면 줄어들지 않음 */
  flex-basis: 200px;    /* 기본 크기 */
  align-self: center;   /* 이 항목만 다르게 */
}
```

**★ 자주 쓰는 3가지 패턴**

```css
/* ① 가로 중앙 정렬 + 양끝 배치 (헤더) */
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

/* ② 세로 중앙 정렬 */
.center {
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 200px;
}

/* ③ 남은 공간 채우기 */
.sidebar { flex: 0 0 240px; }   /* 고정 */
.content { flex: 1; }            /* ★ 나머지 전부 */
```

### Grid — 격자 배치

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);    /* 3등분 */
  gap: 16px;
}

/* ★ 반응형 자동 배치 — 가장 유용 */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

```
auto-fit + minmax 의 동작

  화면 1000px → 220px 이상 카드 4개
  화면 700px  → 3개
  화면 500px  → 2개
  화면 390px  → ★ 1개

★ 미디어 쿼리 없이 반응형이 됩니다
```

**Flexbox vs Grid**

```
Flexbox  한 방향 (가로 또는 세로)
         · 헤더 · 네비게이션 · 버튼 그룹
         · 크기가 내용에 따라 달라질 때

Grid     두 방향 (행 + 열)
         · 카드 목록 · 갤러리 · 대시보드
         · ★ 정해진 격자에 배치할 때
```

### 반응형 — 미디어 쿼리

```css
/* 기본 = 모바일 (★ Mobile First) */
.container { padding: 12px; }
.grid { grid-template-columns: 1fr; }

/* 태블릿 이상 */
@media (min-width: 640px) {
  .container { padding: 20px; }
  .grid { grid-template-columns: repeat(2, 1fr); }
}

/* 데스크톱 */
@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}
```

**★ 기준 화면 크기**

| 기기 | 너비 | 비고 |
|---|---|---|
| **iPhone SE** | **375px** | ★ 가장 작은 기준 |
| iPhone 14 | 390px | ★ **우리 기준** |
| iPhone 14 Pro Max | 430px | |
| 태블릿 | 768px | |
| 노트북 | 1280px | |
| 데스크톱 | 1920px | |

```
★ 우리 프로젝트 기준: 390px 에서 안 깨지면 합격
```

**두 가지 접근**

```css
/* Mobile First (권장) */
.x { font-size: 14px; }
@media (min-width: 640px) { .x { font-size: 16px; } }

/* Desktop First */
.x { font-size: 16px; }
@media (max-width: 639px) { .x { font-size: 14px; } }
```

**2.** 아래 레이아웃을 **Flexbox 와 Grid 중 무엇으로** 만들지 정하고 CSS 를 작성하세요.

```
(a) 헤더: 왼쪽 로고, 오른쪽 메뉴 3개
(b) 카드 목록: 화면 너비에 따라 1~4열, 카드 최소 240px
(c) 사이드바 240px 고정 + 본문 나머지 전부
(d) 통계 타일 4개: 데스크톱 4열, 태블릿 2열, 모바일 1열
(e) 이미지 2장 나란히, 모바일에서는 세로로
(f) 버튼 그룹: 오른쪽 정렬, 좁으면 줄바꿈
```

<details>
<summary>답 보기</summary>

### (a) 헤더 — **Flexbox**

```
이유: 한 방향(가로) · 양끝 배치 · 크기가 내용에 따라 달라짐
```

```css
.header-inner {
  display: flex;
  align-items: center;              /* 세로 가운데 */
  justify-content: space-between;   /* ★ 양끝 */
  gap: 16px;
  min-height: 60px;
  flex-wrap: wrap;
}
.nav { display: flex; gap: 4px; }

@media (max-width: 480px) {
  .header-inner { flex-direction: column; align-items: stretch; }
  .nav { justify-content: center; }
}
```

### (b) 카드 목록 — **Grid**

```
이유: ★ auto-fit + minmax 로 미디어 쿼리 없이 반응형
```

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}
```

```
동작
  1000px → 4열   (240×4 = 960 + gap)
   760px → 3열
   520px → 2열
   390px → ★ 1열

★ 미디어 쿼리 한 줄도 없이 됩니다
```

> **`auto-fit` vs `auto-fill`**
> ```
> auto-fit   항목이 적으면 ★ 남은 공간을 채워 늘어남
> auto-fill  빈 열을 유지 (항목이 작게 유지됨)
>
> → 카드 목록에는 auto-fit
> ```

### (c) 사이드바 + 본문 — **Flexbox**

```
이유: 한쪽 고정 + 한쪽 유동 → flex: 0 0 / flex: 1
```

```css
.layout {
  display: flex;
  gap: 20px;
  align-items: flex-start;
}
.sidebar {
  flex: 0 0 240px;        /* ★ 늘지도 줄지도 않고 240px */
}
.content {
  flex: 1;                /* ★ 나머지 전부 */
  min-width: 0;           /* ★ 중요! 넘침 방지 */
}

@media (max-width: 768px) {
  .layout { flex-direction: column; }
  .sidebar { flex: none; width: 100%; }
}
```

> **★ `min-width: 0` 이 없으면**
> flex 항목의 기본 `min-width: auto` 때문에
> **내용이 긴 표나 코드가 있으면 줄어들지 않아 가로 스크롤이 생깁니다.**

**Grid 로도 가능**

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  gap: 20px;
}
@media (max-width: 768px) {
  .layout { grid-template-columns: 1fr; }
}
```

```
★ 이 경우는 Grid 가 더 명확합니다
  "240px 과 나머지" 를 그대로 표현
```

| 상황 | 선택 | 이유 |

  탭할 때 자동으로 확대합니다
```

**해결**

```css
input, select, textarea {
  font-size: 16px;            /* ★ 필수 (iOS) */
}

/* 시각적으로 작게 하고 싶으면 */
@media (min-width: 768px) {
  input, select, textarea { font-size: 14px; }   /* 데스크톱만 */
}
```

**보조 (권장하지 않음)**

```html
<!-- 확대 자체를 막는 방법 — ★ 접근성 저해 -->
<meta name="viewport" content="width=device-width, initial-scale=1,
                               maximum-scale=1, user-scalable=no">
```

```
⚠️ user-scalable=no 는 ★ 시력이 약한 사용자가 확대를 못 하게 만듭니다
→ font-size: 16px 로 해결하세요
```

### 문제 5 — 미리보기 이미지가 넘침

**원인**

```javascript
preview.src = URL.createObjectURL(file);
```

```
이미지 원본 크기가 4000×3000 이면
CSS 제약이 없을 때 그대로 표시됩니다
```

**해결**

```css
.preview {
  max-width: 100%;           /* ★ 필수 */
  max-height: 340px;
  height: auto;
  margin-inline: auto;
  display: block;
  border-radius: 6px;
  object-fit: contain;
}

@media (max-width: 480px) {
  .preview { max-height: 240px; }
}
```

**★ 메모리 누수도 함께 해결**

```javascript
let currentUrl = null;

input.addEventListener('change', () => {
  const file = input.files[0];
  if (!file) return;

  // ★ 이전 URL 해제 (메모리 누수 방지)
  if (currentUrl) URL.revokeObjectURL(currentUrl);
  currentUrl = URL.createObjectURL(file);

  preview.src = currentUrl;
  preview.hidden = false;
  inner.hidden = true;

  // ★ 파일 크기 표시
  const mb = (file.size / 1024 / 1024).toFixed(1);
  document.getElementById('file-info').textContent =
    `${file.name} · ${mb} MB`;

  // ★ 크기 제한 미리 확인
  if (file.size > 16 * 1024 * 1024) {
    alert('파일이 너무 큽니다 (최대 16MB)');
    input.value = '';
    preview.hidden = true;
    inner.hidden = false;
  }
});
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| ★ `box-sizing` | **`border-box`** — 첫 줄에 |
| ★ 뷰포트 meta | 없으면 **미디어 쿼리 무동작** |
| 블록 vs 인라인 | 가로 전체 vs 내용만 |
| 박스 모델 | content → padding → border → margin |
| margin 상쇄 | 세로 여백은 **큰 쪽만** |
| 선택자 우선순위 | 인라인 > id > class > 태그 |
| `!important` | ★ **금지** |
| CSS 변수 | `:root { --accent: ... }` |
| **Flexbox** | ★ **한 방향** · 헤더 · 버튼 그룹 |
| `justify-content` | 주축 정렬 |
| `align-items` | 교차축 정렬 |
| `flex: 1` | ★ 남은 공간 차지 |
| `min-width: 0` | ★ **flex 항목 넘침 방지** |
| **Grid** | ★ **격자** · 카드 · 대시보드 |
| ★ `auto-fit + minmax` | **미디어 쿼리 없이 반응형** |
| 기준 화면 | ★ **390px** |
| Mobile First | 기본=모바일, `min-width` 로 확장 |
| 이미지 | `max-width: 100%` |
| 표 | ★ **`overflow-x: auto`** |
| 터치 영역 | ★ **44px 이상** |
| iOS 확대 방지 | ★ **입력창 `font-size: 16px`** |
| CDN | ★ **사용 금지** (오프라인 동작) |

**오늘 반드시 기억할 세 가지**
> ① **`box-sizing: border-box` 와 뷰포트 meta 는 필수입니다.** 없으면 레이아웃이 근본적으로 어긋납니다.
> ② **`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`** 하나면 반응형 카드 목록이 끝납니다.
> ③ **입력창 `font-size` 를 16px 로 하세요.** iOS에서 탭할 때 화면이 확대되는 것을 막습니다.

**오늘의 산출물**

| # | 산출물 | 경로 |
|---|---|---|
| 1 | ★ **CSS 리셋 + 변수** | `static/css/style.css` |

| 3 | ★ **업로드 폼** | `templates/upload.html` |
| 4 | 드래그 앤 드롭 + 미리보기 | `static/js/app.js` |
| 5 | ★ **결과 표시 영역** | `templates/result.html` |
| 6 | 통계 타일 (Grid) | |
