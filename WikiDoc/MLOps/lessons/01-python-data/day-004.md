## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- `if` / `elif` / `else` 로 상황에 따라 다르게 동작하는 프로그램을 만들 수 있다.
- `for` 와 `range` · `enumerate` 로 정해진 횟수·목록을 순회할 수 있다.
- `while` 로 조건이 만족될 때까지 반복하고, 무한 루프를 피할 수 있다.
- `break` · `continue` 로 반복의 흐름을 제어할 수 있다.

---

## ② 왜 필요한가

지금까지 만든 프로그램은 **위에서 아래로 한 번 흐르고 끝**입니다. 계산기입니다.

여러분이 W04에서 만들 수집기는 이렇게 동작해야 합니다.

```
1페이지부터 마지막 페이지까지 반복:            ← for
    페이지를 요청한다
    만약 응답이 실패면:                        ← if
        3번까지 재시도한다                      ← while
        그래도 실패면 로그 남기고 다음으로       ← continue
    데이터가 비어 있으면 수집을 멈춘다           ← break
    1초 쉰다
```

조건문과 반복문 없이는 **자동화가 불가능**합니다. 그리고 자동화가 이 과정의 이름(MLOps)입니다.

| 조건문·반복문이 쓰이는 곳 | 시점 |
|---|---|
| 응답 실패 시 재시도, 페이지 순회 | W04 |
| 결측값이면 대치, 아니면 통과 | W05 |
| 1GB 파일을 100개 조각으로 나눠 처리 | W06 |
| 검증 규칙 5개를 행마다 적용 | W09 |
| 에폭 수만큼 학습 루프를 돈다 | W16 |
| 컨테이너가 죽으면 재시작한다 | W25 |

## ③ 개념 설명

### if 문의 구조

```python
if 조건:
    조건이 참일 때 실행할 코드
```

**콜론(`:`)** 과 **들여쓰기**가 문법의 일부입니다. 다른 언어의 중괄호 `{}` 역할을 합니다.

```python
score = 85

if score >= 60:
    print("합격")
```

```
합격
```

### elif와 else

```python
if 조건1:
    ...
elif 조건2:      # 조건1이 거짓일 때만 검사
    ...
elif 조건3:
    ...
else:            # 위가 전부 거짓일 때
    ...
```

**위에서부터 순서대로 검사하고, 처음 참인 것 하나만 실행한 뒤 빠져나옵니다.**

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:      # 85는 여기서 걸림
    grade = "B"
elif score >= 70:      # 검사조차 안 함
    grade = "C"
else:
    grade = "F"
```

> **순서가 중요합니다.** 만약 `score >= 70` 을 맨 위에 쓰면 85점도 C가 됩니다.
> 조건이 겹칠 때는 **좁은 조건(엄격한 조건)을 먼저** 씁니다.

### 들여쓰기 규칙

| 규칙 | 설명 |
|---|---|
| 공백 4칸 | 파이썬 관례. VS Code에서 Tab을 누르면 자동으로 4칸이 됩니다 |
| 같은 블록은 같은 깊이 | 한 칸이라도 어긋나면 `IndentationError` |
| Tab과 Space 섞기 금지 | 눈으로는 같아 보여도 에러가 납니다 |

### 중첩 조건

조건 안에 조건을 넣을 수 있습니다.

```python
if is_logged_in:
    if is_admin:
        print("관리자 페이지")
    else:
        print("사용자 페이지")
else:
    print("로그인 필요")
```

> **깊이는 2단까지가 읽기 좋습니다.** 3단이 넘어가면 조건을 합치거나 함수로 빼세요 (Day 006).

### for 문 — 정해진 것을 순회

```python
for 변수 in 순회할것:
    반복할 코드
```

```python
for fruit in ["사과", "바나나", "포도"]:
    print(fruit)
```

```
사과
바나나
포도
```

문자열도 순회됩니다.

```python
for ch in "abc":
    print(ch)
```

### range() — 숫자 범위 만들기

| 사용법 | 만들어지는 수 |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

**끝 숫자는 포함되지 않습니다.** 슬라이싱과 같은 규칙입니다.

```python
for i in range(1, 6):
    print(i, end=" ")
```

```
1 2 3 4 5
```

> `end=" "` 는 "줄바꿈 대신 공백을 붙여라"는 뜻입니다. `print()` 의 기본은 `end="\n"` 입니다.

### enumerate() — 번호와 값을 같이

리스트를 돌면서 "몇 번째인지"도 필요할 때 씁니다.

```python
fruits = ["사과", "바나나", "포도"]

for i, fruit in enumerate(fruits):
    print(i, fruit)
```

```
0 사과
1 바나나
2 포도
```

1부터 세고 싶으면 `start=1` 을 줍니다.

```python
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
```

```
1. 사과
2. 바나나
3. 포도
```

> **인덱스를 직접 관리하지 마세요.** 아래처럼 쓰는 것은 초보 신호입니다.
> ```python
> i = 0
> for fruit in fruits:
>     print(i, fruit)
>     i += 1          # ← enumerate를 쓰면 필요 없음
> ```

### while 문 — 조건이 참인 동안 반복

```python
while 조건:
    반복할 코드
```

**횟수를 모를 때** 씁니다. "사용자가 올바른 값을 넣을 때까지", "응답이 성공할 때까지" 같은 상황입니다.

```python
count = 0
while count < 3:
    print(f"시도 {count + 1}")
    count += 1
```

```
시도 1
시도 2
시도 3
```

> **무한 루프 주의** — `count += 1` 을 빼먹으면 조건이 영원히 참이라 프로그램이 멈추지 않습니다.
> 실행 중 멈추려면 터미널에서 `Ctrl + C` 를 누릅니다.

### for와 while 중 무엇을 쓸까

| 상황 | 쓸 것 |
|---|---|
| 리스트·문자열의 모든 요소를 본다 | `for` |
| 정확히 N번 반복한다 | `for` + `range` |
| 조건이 만족될 때까지 (횟수 모름) | `while` |
| 사용자 입력이 올바를 때까지 | `while` |
| 재시도 (성공하거나 한도 초과까지) | `while` |

### break와 continue

| 키워드 | 하는 일 |
|---|---|
| `break` | 반복문을 **완전히 빠져나감** |
| `continue` | 이번 회차만 건너뛰고 **다음 회차로** |

```python
for i in range(1, 11):
    if i == 5:
        continue        # 5는 건너뜀
    if i == 8:
        break           # 8에서 멈춤
    print(i, end=" ")
```

```
1 2 3 4 6 7
```

**수집기에서의 용도**

```python
for page in range(1, 100):
    data = fetch(page)
    if not data:
        break           # 빈 페이지가 나오면 마지막이므로 종료
    if is_invalid(data):
        continue        # 이상한 페이지는 건너뛰고 계속
    save(data)
```

### 반복문 안에서 값 누적하기

가장 자주 쓰는 패턴입니다.

```python
total = 0                # 1) 빈 그릇 준비
for n in [10, 20, 30]:
    total += n           # 2) 하나씩 담기
print(total)             # 3) 결과 사용
```

```
60
```

이 "빈 그릇 → 반복하며 채우기 → 사용" 3단 패턴은 앞으로 수백 번 씁니다.

### Step 3. 입력 검증 루프

`validate_input.py` 를 만듭니다. W04 수집기에서 쓸 재시도 패턴의 원형입니다.

```python
while True:
    raw = input("나이를 입력하세요 (0-120): ").strip()

    if raw == "":
        print("  → 아무것도 입력하지 않았습니다.")
        continue

    if not raw.isdigit():
        print(f"  → '{raw}' 는 숫자가 아닙니다.")
        continue

    age = int(raw)
    if age > 120:
        print(f"  → {age} 는 범위를 벗어났습니다.")
        continue

    break      # 여기까지 왔다면 올바른 값

print(f"입력 완료: {age}세")
```

실행 결과:

```

  → 아무것도 입력하지 않았습니다.
나이를 입력하세요 (0-120): 스물다섯
  → '스물다섯' 는 숫자가 아닙니다.
나이를 입력하세요 (0-120): 200
  → 200 는 범위를 벗어났습니다.
나이를 입력하세요 (0-120): 25
입력 완료: 25세
```

> `while True:` 는 "일단 무한 반복"이고, 조건이 맞았을 때 `break` 로 빠져나오는 구조입니다.
> **검증 로직에서 아주 흔한 관용구**입니다. `.isdigit()` 은 문자열이 숫자로만 되어 있는지 확인합니다.

### Step 4. 재시도 로직 — W04 예고편

`retry_demo.py` 를 만듭니다.

```python
import random
import time

MAX_RETRY = 3

for page in range(1, 6):
    attempt = 0
    success = False

    while attempt < MAX_RETRY:
        attempt += 1
        # 실제로는 여기서 서버에 요청합니다 (W04)
        status = random.choice([200, 200, 503])

        if status == 200:
            print(f"[page {page}] 성공 (시도 {attempt}회)")
            success = True
            break
        else:
            print(f"[page {page}] 실패 status={status}, {attempt}회째 재시도")
            time.sleep(0.3)

    if not success:
        print(f"[page {page}] {MAX_RETRY}회 실패 — 건너뜁니다")
        continue

    print(f"[page {page}] 저장 완료")
```

```
[page 2] 저장 완료
[page 3] 실패 status=503, 1회째 재시도
```

### Step 5. 숫자 맞추기 게임

`guess.py` 를 만듭니다.

```python
import random

answer = random.randint(1, 100)
MAX_TRY = 7
tries = 0

print("1부터 100 사이의 숫자를 맞춰 보세요.")
print(f"기회는 {MAX_TRY}번입니다.\n")

while tries < MAX_TRY:
    tries += 1
    remain = MAX_TRY - tries

    raw = input(f"[{tries}/{MAX_TRY}] 숫자: ").strip()
    if not raw.isdigit():
        print("  숫자만 입력하세요. (기회는 소모되지 않습니다)")
        tries -= 1
        continue

    guess = int(raw)

    if guess == answer:
        print(f"\n정답입니다! {tries}번 만에 맞췄습니다.")
        break
    elif guess < answer:
        print(f"  더 큽니다. (남은 기회 {remain}번)")
    else:
        print(f"  더 작습니다. (남은 기회 {remain}번)")
else:
    print(f"\n기회를 모두 썼습니다. 정답은 {answer} 였습니다.")
```

실행 결과:

```
1부터 100 사이의 숫자를 맞춰 보세요.
기회는 7번입니다.

[1/7] 숫자: 50
  더 큽니다. (남은 기회 6번)
[2/7] 숫자: 75
  더 작습니다. (남은 기회 5번)
[3/7] 숫자: 62
  더 큽니다. (남은 기회 4번)
[4/7] 숫자: 68
정답입니다! 4번 만에 맞췄습니다.
```

> **`while ... else`** 를 썼습니다. 파이썬 특유의 문법으로, **`break` 없이 정상 종료했을 때만** `else` 가 실행됩니다.
> "끝까지 못 찾았을 때"를 표현하기에 딱 맞습니다. `for ... else` 도 같은 방식으로 동작합니다.

### Step 6. 누적 패턴 — 로그 집계

`log_stats.py` 를 만듭니다.

```python
logs = [
    "2026-08-12 14:23:05 [ERROR] api.collector - 요청 실패",
    "2026-08-12 14:23:06 [INFO] api.collector - 재시도",
    "2026-08-12 14:23:08 [INFO] api.collector - 성공",
    "2026-08-12 14:25:11 [WARN] db.loader - 느린 쿼리 3.2s",
    "2026-08-12 14:31:02 [ERROR] db.loader - 연결 끊김",
    "2026-08-12 14:31:05 [INFO] db.loader - 재연결",
]

error_count = 0
warn_count = 0
info_count = 0
error_lines = []

for line in logs:
    if "[ERROR]" in line:
        error_count += 1
        error_lines.append(line)
    elif "[WARN]" in line:
        warn_count += 1
    elif "[INFO]" in line:
        info_count += 1

total = len(logs)

print(f"전체 {total}줄")
print(f"  ERROR : {error_count:>2}줄  ({error_count / total:.1%})")
print(f"  WARN  : {warn_count:>2}줄  ({warn_count / total:.1%})")
print(f"  INFO  : {info_count:>2}줄  ({info_count / total:.1%})")

if error_count > 0:
    print("\n[에러 상세]")
    for i, line in enumerate(error_lines, start=1):
        time = line[11:19]
        msg = line[line.find(" - ") + 3:]
        print(f"  {i}. {time}  {msg}")
```

```
전체 6줄
  ERROR :  2줄  (33.3%)
  WARN  :  1줄  (16.7%)
  INFO  :  3줄  (50.0%)

[에러 상세]
  1. 14:23:05  요청 실패
  2. 14:31:02  연결 끊김
```

```
    print("합격")
    ^
IndentationError: expected an indented block after 'if' statement on line 2
```

**원인** — `if` 다음 줄을 들여쓰지 않았습니다.
**해결** — 콜론 다음 줄은 반드시 들여씁니다 (공백 4칸).

```python
if score >= 60:
    print("합격")      # ← 들여쓰기
```

### `IndentationError: unindent does not match any outer indentation level`

**원인** — 들여쓰기 깊이가 어긋났습니다. Tab과 Space를 섞었을 때 자주 납니다.
**해결** — VS Code 하단의 `Spaces: 4` 를 클릭 → `Convert Indentation to Spaces` 로 통일합니다.
`파일 > 기본 설정 > 설정` 에서 `Editor: Insert Spaces` 를 켜 두면 재발하지 않습니다.

### `SyntaxError: expected ':'`

```python
if score >= 60
    print("합격")
```

```
  File "test.py", line 1
    if score >= 60
                  ^
SyntaxError: expected ':'
```

**원인** — 콜론을 빠뜨렸습니다. `if`, `elif`, `else`, `for`, `while`, `def` 모두 콜론이 필요합니다.
**해결** — 줄 끝에 `:` 를 붙입니다.

### `if x = 5:` — 대입과 비교 혼동

```python
if score = 60:
```

```
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

**원인** — `=` 는 대입, `==` 가 비교입니다.
**해결** — `if score == 60:`

### elif 순서를 잘못 써서 조용히 틀림

```python
if score >= 60:
    grade = "D"
elif score >= 90:      # 여기 절대 도달 못 함
    grade = "A"
```

**원인** — 95점도 첫 조건 `>= 60` 에 걸려 D가 됩니다. **에러가 안 납니다.**
**해결** — 조건이 겹칠 때는 **엄격한 것부터 위에** 씁니다. `>= 90` → `>= 80` → ... 순.

이런 종류를 **논리 버그**라고 하며, 문법 에러보다 훨씬 찾기 어렵습니다.
확인 방법은 간단합니다. **경계값(59, 60, 89, 90)을 직접 넣어 보세요.**

### 무한 루프

```python
count = 0
while count < 3:
    print("반복")
    # count += 1 을 빠뜨림
```

**원인** — 조건을 바꾸는 코드가 없어 영원히 참입니다.
**해결** — `Ctrl + C` 로 멈추고, 반복문 안에 **조건 변수를 바꾸는 줄이 있는지** 확인합니다.

`while` 을 쓸 때는 항상 이 두 가지를 확인하는 습관을 들이세요.
① 언제 조건이 거짓이 되는가 ② 그 코드가 반복문 안에 있는가

### 반복문 밖에서 변수를 만들지 않아 `NameError`

```python
for n in [1, 2, 3]:
    total += n          # total이 아직 없음
```

```
NameError: name 'total' is not defined
```

**원인** — 누적할 변수를 반복문 **앞에서 먼저 만들어야** 합니다.
**해결** —

```python
total = 0               # ← 빈 그릇 먼저
for n in [1, 2, 3]:
    total += n
```

### `range(1, 10)` 이 10을 포함한다고 착각

```python
for i in range(1, 10):
    print(i)            # 1~9 까지만 나옴
```

**원인** — `range` 의 끝 숫자는 **미포함**입니다. 슬라이싱과 같습니다.
**해결** — 10까지 원하면 `range(1, 11)`.

## ⑥ 확인 문제

**1.** 아래 코드의 출력은 무엇인가요?

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    if i > 7:
        break
    print(i, end=" ")
```

<details>
<summary>답 보기</summary>

```
1 2 4 5 7 
```

한 회차씩 따라가 보면:

| i | `i % 3 == 0` | `i > 7` | 결과 |
|---|---|---|---|
| 1 | 거짓 | 거짓 | 출력 |
| 2 | 거짓 | 거짓 | 출력 |
| 3 | **참** | — | `continue` (건너뜀) |
| 4 | 거짓 | 거짓 | 출력 |
| 5 | 거짓 | 거짓 | 출력 |
| 6 | **참** | — | `continue` |
| 7 | 거짓 | 거짓 | 출력 |
| 8 | 거짓 | **참** | `break` (종료) |

`continue` 는 **이번 회차만** 건너뛰고, `break` 는 **반복문 전체**를 끝냅니다.
</details>

**2.** 아래 코드는 95점을 넣어도 `"D"` 를 출력합니다. 왜 그런가요?

```python
score = 95
if score >= 60:
    grade = "D"
elif score >= 70:
    grade = "C"
elif score >= 80:
    grade = "B"
elif score >= 90:
    grade = "A"
print(grade)
```

<details>
<summary>답 보기</summary>

`if`/`elif` 는 **위에서부터 검사하다가 처음 참인 것 하나만 실행하고 빠져나옵니다.**

95는 첫 조건 `score >= 60` 에서 이미 참이므로 `grade = "D"` 가 실행되고,
아래 `elif` 들은 **검사조차 되지 않습니다.**

조건이 겹치는 구간이 있을 때는 **가장 엄격한(좁은) 조건을 위에** 놓아야 합니다.

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
```

이 버그는 **에러가 나지 않기 때문에** 위험합니다.
확인하는 가장 빠른 방법은 **경계값 테스트**입니다. 59·60·69·70·89·90·100을 넣어 보면 즉시 드러납니다.
Day 014에서 이걸 자동으로 확인하는 테스트 코드 작성법을 배웁니다.
</details>

**3.** 아래 두 코드는 같은 일을 합니다. 어느 쪽이 더 좋은 코드이고, 왜인가요?

```python
# A
i = 0
for name in names:
    print(i, name)
    i += 1

# B
for i, name in enumerate(names):
    print(i, name)
```

<details>
<summary>답 보기</summary>

**B가 더 좋습니다.** 이유는 세 가지입니다.

1. **버그 여지가 없습니다.** A는 `i += 1` 을 빠뜨리거나 `continue` 앞에 두면 번호가 어긋납니다.
   예를 들어 아래는 조용히 틀립니다.
   ```python
   i = 0
   for name in names:
       if name == "":
           continue        # ← i += 1 을 건너뛰어 번호가 밀림
       print(i, name)
       i += 1
   ```

2. **의도가 드러납니다.** `enumerate` 는 "번호와 함께 순회한다"는 뜻이 이름에 있습니다.
   A는 코드를 읽어 봐야 `i` 가 무엇인지 압니다.

3. **줄 수가 줄어듭니다.** 관리할 상태가 하나 적습니다.

파이썬에서는 이런 관용적 표현을 **파이써닉(Pythonic)** 하다고 부릅니다.
같은 맥락에서 `range(len(names))` 로 인덱스를 돌리는 것도 피합니다.
</details>

## 오늘의 정리

| 항목 | 문법 | 언제 |
|---|---|---|
| 조건 | `if` / `elif` / `else` + 콜론 + 들여쓰기 | 상황에 따라 다르게 |
| 조건 표현식 | `A if 조건 else B` | 짧은 분기를 값으로 |
| 반복(횟수) | `for i in range(n):` | N번 반복 |
| 반복(목록) | `for x in 리스트:` | 모든 요소 순회 |
| 반복(번호와 함께) | `for i, x in enumerate(리스트):` | 순번이 필요할 때 |
| 반복(조건) | `while 조건:` | 횟수를 모를 때 |
| 흐름 제어 | `break` 완전 종료 · `continue` 다음 회차 | 재시도·건너뛰기 |
| 누적 패턴 | 빈 그릇 → 반복하며 채우기 → 사용 | 집계 전반 |
