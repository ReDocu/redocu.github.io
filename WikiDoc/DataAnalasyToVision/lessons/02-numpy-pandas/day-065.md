## ② 왜 필요한가

이번 주에 그래프 그리는 법을 배웠습니다. 그런데 실제로 데이터를 받으면 이렇게 됩니다.

```
"자, 그래프를 그려 보자... 뭘 그리지?"
```

**그래프를 그릴 줄 아는 것과 무엇을 그릴지 아는 것은 다릅니다.**

그리고 그린 뒤에도 문제가 남습니다.

```
그래프 12개를 그렸다  →  "그래서 뭘 알게 됐나요?"  →  "음..."
```

**EDA 는 이 두 문제를 해결하는 절차입니다.**

| | 그냥 그리기 | EDA |
|---|---|---|
| 시작 | 아무거나 | **질문부터** |
| 진행 | 무작위 | **구조 → 단변량 → 이변량 → 다변량** |
| 그래프 | 많이 | **질문에 답하는 것만** |
| 끝 | 그래프 모음 | **발견 목록** |

> **EDA(Exploratory Data Analysis)** 는 존 튜키가 1977년에 정리한 개념입니다.
> 핵심은 **"데이터가 무슨 말을 하는지 먼저 들어라"** 입니다.
>
> ```
> 확증적 분석  가설을 세우고 → 검증한다        (통계 검정)
> 탐색적 분석  데이터를 보고 → 가설을 만든다   (EDA)  ⭐
> ```
>
> **EDA 없이 바로 모델링에 들어가면**, 데이터가 이상한 것을 모른 채
> "정확도 95%"를 얻고 **왜 그런지 설명하지 못하게** 됩니다.

## ③ 개념 설명

## 1부 · EDA 절차

### 5단계

```
① 구조 파악    몇 행 몇 열인가, 어떤 타입인가, 결측은 얼마나
      ↓
② 단변량       각 변수 하나씩 — 분포는? 이상치는?
      ↓
③ 이변량       두 변수씩 — 관계가 있는가?
      ↓
④ 다변량       세 변수 이상 — 그룹을 나누면 달라지는가?
      ↓
⑤ 정리         발견 3~5가지 + 다음 할 일
```

### ① 구조 파악 — 5분 안에

```python
df.shape                    # 몇 행 몇 열
df.head(), df.tail()        # 앞뒤 훑기
df.info()                   # 타입 + 결측
df.describe()               # 숫자 요약
df.describe(include="O")    # 문자열 요약
df.isna().sum()             # 결측
df.nunique()                # 고유값
df.duplicated().sum()       # 중복
```

**여기서 확인할 것 6가지**

| # | 확인 | 이상 신호 |
|---|---|---|
| ① | 행 수 | 예상과 다름 → 수집 문제 |
| ② | 타입 | 숫자가 `object` → 변환 필요 |
| ③ | 결측 | 특정 열에 집중 |
| ④ | 고유값 1개 | 정보 없는 열 |
| ⑤ | 고유값 = 행 수 | 식별자 (분석 대상 아님) |
| ⑥ | 중복 | 수집 반복 |

### ② 단변량 — 변수 하나씩

**수치형**

```python
df["price"].describe()
df["price"].skew()          # 왜도
df["price"].kurt()          # 첨도

ax.hist(df["price"], bins=30)         # 분포 모양
ax.boxplot(df["price"])                # 이상치
```

**볼 것**

```
평균 vs 중앙값 차이  →  치우침
왜도 |skew| > 1      →  로그 변환 검토
봉우리 개수          →  숨은 그룹?
0 이나 특정 값 집중  →  결측을 채운 흔적?
```

**범주형**

```python
df["category"].value_counts()
df["category"].value_counts(normalize=True)

ax.barh(counts.index, counts.values)
```

**볼 것**

```
고유값 개수          →  너무 많으면 상위 N개 + 기타
극단적 불균형        →  99% 가 한 값이면 분석에 무의미
표기 불일치          →  '서울'과 '서울시'  (Day 058)
```

### ③ 이변량 — 두 변수

| 조합 | 방법 |
|---|---|
| 수치 ↔ 수치 | 산점도 · **상관계수** |
| 범주 ↔ 수치 | 박스플롯 · 그룹 평균 |
| 범주 ↔ 범주 | 교차표 · 히트맵 |

```python
df.corr(numeric_only=True)                      # 전체 상관
df.groupby("category")["price"].describe()      # 그룹별
pd.crosstab(df["a"], df["b"], normalize="index")  # 교차 비율
```

### ④ 다변량 — 그룹을 나누면?

```python
sns.scatterplot(data=df, x="price", y="rating", hue="category")
sns.boxplot(data=df, x="category", y="price", hue="season")
```

> ⚠️ **심슨의 역설을 조심하세요.**
> 전체로 보면 양의 상관인데, **그룹별로 보면 전부 음의 상관**인 경우가 있습니다.
>
> ```
> 전체:      가격↑ → 평점↑
> 카테고리별: 자연 가격↑ → 평점↓
>            역사 가격↑ → 평점↓
> ```
> 이건 **카테고리마다 가격대와 평점대가 다르기 때문**입니다.
> **항상 그룹을 나눠 한 번 더 확인**하세요.

### ⑤ 정리 — 발견 목록

```
발견 1: [관찰] ... [근거 그래프] ... [의미] ...
발견 2: ...
발견 3: ...

다음 할 일:
- 확인이 필요한 것
- 추가로 모아야 할 데이터
```

## 2부 · 반복 루프

### 그래프 → 발견 → 가설 → 확인

```
      ┌──────────────────────────────────┐
      ↓                                  │
   그래프를 그린다                        │
      ↓                                  │
   무언가 눈에 띈다 (발견)                 │
      ↓                                  │
   "왜 그럴까?" (가설)                    │
      ↓                                  │
   확인할 그래프를 정한다 ─────────────────┘
```

**예시**

```
① 그래프  가격 히스토그램
② 발견    0원에 22%가 몰려 있다
③ 가설    "무료 시설이 많은 건가? 아니면 결측을 0으로 채운 건가?"
④ 확인    카테고리별로 0원 비율을 본다
      ↓
① 그래프  카테고리 × 무료여부 교차표
② 발견    '자연'의 45%가 무료, '쇼핑'은 8%
③ 가설    "공원·산책로가 자연으로 분류돼 무료인 듯"
④ 확인    자연 카테고리의 이름을 샘플로 본다
```

> **한 번의 그래프로 끝나는 EDA 는 없습니다.**
> 좋은 발견은 **3~4번 파고든 뒤**에 나옵니다.

### 무엇이 "발견"인가

| | 발견이 아님 | 발견 |
|---|---|---|
| 당연한 것 | "방문객이 많으면 리뷰도 많다" | — |
| 정의상 참 | "매출 = 단가 × 수량이라 상관 0.9" | — |
| 숫자 나열 | "평균 4.09점입니다" | — |
| **예상과 다름** | | **"여름에 방문객이 줄어든다"** ⭐ |
| **비대칭** | | "서울이 전체의 22%" |
| **그룹 간 차이** | | "무료 시설의 평점이 더 높다" |
| **결측·이상 패턴** | | "비싼 곳만 방문객 정보가 없다" |

## 3부 · 리포트 구조

### 5단 구성

```markdown
# [분석 제목]

## 1. 질문
무엇을 알고 싶었는가. 왜 중요한가.

## 2. 데이터
출처 / 기간 / 건수 / 주요 열 / 알려진 한계

## 3. 방법
어떻게 정제했는가. 무엇을 제외했는가. 왜.

## 4. 결과
발견 1 (그래프 + 해석 2줄 이상)
발견 2
발견 3

## 5. 결론과 한계
답 / 답하지 못한 것 / 다음 할 일
```

### 각 그래프마다 해석 2줄

```markdown
![월별 방문객](fig1.png)

**8월에 방문객이 1,124만 명으로 연중 최고를 기록했고, 2월(487만)의 2.3배였다.**
**여름 휴가철 집중으로 보이나, 겨울 관광지(스키장 등)가 데이터에 적게
포함됐을 가능성도 있어 카테고리별 확인이 필요하다.**
```

**나쁜 예 vs 좋은 예**

| ❌ | ✅ |
|---|---|
| "8월이 가장 높다" | "8월 1,124만 명으로 최저인 2월의 2.3배" |
| "관계가 있다" | "r=0.37, 변동의 14% 설명" |
| "차이가 크다" | "무료 4.15점 vs 유료 4.02점, 신뢰구간 겹침" |

## ④ 단계별 실습

### Step 1. 구조 파악 (5분)

```python
"""EDA 1단계 — 데이터가 어떻게 생겼나."""

import platform
from pathlib import Path

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                              else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

OUT = Path("output/eda")
OUT.mkdir(parents=True, exist_ok=True)

OKABE = ["#0072B2", "#E69F00", "#009E73", "#CC79A7", "#56B4E9", "#D55E00"]

# ── 데이터 (Day 060 전처리 결과를 가정) ──
rng = np.random.default_rng(42)
N = 1200

df = pd.DataFrame({
    "id": [f"{100000+i}" for i in range(N)],
    "name": [f"관광지{i:04d}" for i in range(N)],
    "sido": rng.choice(["서울특별시", "부산광역시", "제주특별자치도",
                        "강원특별자치도", "경기도", "전라남도",
                        "경상북도", "충청남도"], N,
                       p=[0.22, 0.13, 0.14, 0.13, 0.16, 0.08, 0.08, 0.06]),
    "category": rng.choice(["자연", "역사", "체험", "쇼핑", "음식"], N,
                           p=[0.31, 0.24, 0.19, 0.15, 0.11]),
    "month": rng.integers(1, 13, N),
    "source": "TourAPI",
})

# 카테고리별로 무료 비율을 다르게 (발견거리 심기)
free_prob = df["category"].map({"자연": 0.45, "역사": 0.25, "체험": 0.10,
                                "쇼핑": 0.08, "음식": 0.12})
is_free = rng.random(N) < free_prob

df["price"] = np.where(is_free, 0.0,
                       rng.lognormal(8.6, 0.62, N).round(-2))

# 여름 집중
season_boost = df["month"].map({6: 1.6, 7: 2.1, 8: 2.4, 9: 1.3}).fillna(1.0)
df["visitors"] = (rng.lognormal(8.3, 1.0, N) * season_boost).round()

# 무료가 평점이 약간 높게
df["rating"] = (rng.normal(4.0, 0.45, N)
                + is_free * 0.14
                + np.log1p(df["visitors"]) / 90).round(1).clip(1, 5)

# 비싼 곳의 방문객 정보 누락 (MNAR)
df.loc[df["price"] > df["price"].quantile(0.9), "visitors"] = np.nan

print("=" * 80)
print("                     EDA ① 구조 파악")
print("=" * 80)

# ── 기본 ──
print(f"\n[규모]")
print(f"  행 × 열 : {df.shape[0]:,} × {df.shape[1]}")
print(f"  메모리  : {df.memory_usage(deep=True).sum()/1024**2:.2f} MB")
print(f"  중복 행 : {df.duplicated().sum()}건")

# ── 열별 요약 ──
summary = pd.DataFrame({
    "타입": df.dtypes.astype(str),
    "결측": df.isna().sum(),
    "결측%": (df.isna().mean() * 100).round(1),
    "고유값": df.nunique(),
    "예시": [str(df[c].dropna().iloc[0])[:18] if df[c].notna().any() else ""
             for c in df.columns],
})

summary["비고"] = ""
summary.loc[summary["고유값"] == 1, "비고"] = "⚠ 값이 하나뿐 (정보 없음)"
summary.loc[summary["고유값"] == len(df), "비고"] = "식별자"
summary.loc[summary["결측%"] > 20, "비고"] += " ⚠ 결측 많음"

print(f"\n[열별 요약]")
print(summary.to_string())

# ── 수치 요약 ──
num_cols = df.select_dtypes(include=np.number).columns.tolist()

print(f"\n[수치형 요약]")
desc = df[num_cols].describe().T
desc["왜도"] = df[num_cols].skew()
desc["중앙값/평균"] = (desc["50%"] / desc["mean"]).round(2)
print(desc.round(2).to_string())

print(f"\n[⚠ 확인 필요]")
issues = []

for col in num_cols:
    s = df[col].dropna()
    if len(s) < 10:
        continue
    if abs(s.skew()) > 1.5:
        issues.append(f"'{col}' 왜도 {s.skew():.2f} — 로그 변환 검토")
    zero_rate = (s == 0).mean()
    if zero_rate > 0.1:
        issues.append(f"'{col}' 값의 {zero_rate*100:.0f}%가 0 — "
                      f"진짜 0인지 결측 대체인지 확인")

for col in df.columns:
    if df[col].nunique() == 1:
        issues.append(f"'{col}' 이 전부 같은 값 — 분석에서 제외 가능")
    if df[col].isna().mean() > 0.2:
        issues.append(f"'{col}' 결측 {df[col].isna().mean()*100:.0f}% — "
                      f"MNAR 여부 확인 필요")

for i in issues:
    print(f"  · {i}")

print("\n" + "=" * 80)
```

"""EDA 리포트를 자동으로 조립합니다."""

from datetime import date


def build_eda_report(df, findings, figures, meta, path="output/eda_report.md"):
    """
    EDA 리포트를 Markdown 으로 생성합니다.

    findings : [{"제목", "관찰", "해석", "그래프", "다음"}, ...]
    figures  : {"이름": "경로"}
    meta     : {"질문", "출처", "기간", "제외", "한계"}
    """
    lines = [
        f"# EDA 리포트 — {meta.get('title', '데이터 분석')}",
        "",
        f"> 작성일 {meta.get('date', '(날짜)')} · "
        f"작성자 {meta.get('author', '(이름)')}",
        "",
        "---",
        "",
        "## 1. 질문",
        "",
        meta.get("question", "(무엇을 알고 싶었는가)"),
        "",
        "## 2. 데이터",
        "",
        "| 항목 | 내용 |",
        "|---|---|",
        f"| 출처 | {meta.get('source', '-')} |",
        f"| 수집 시점 | {meta.get('collected', '-')} |",
        f"| 기간 | {meta.get('period', '-')} |",
        f"| 건수 | {len(df):,}행 × {df.shape[1]}열 |",
        f"| 주요 열 | {', '.join(meta.get('key_columns', df.columns[:6]))} |",
        "",
        "### 결측 현황",
        "",
        "| 열 | 결측 | 비율 | 의미 |",
        "|---|---|---|---|",
    ]

    na = df.isna().sum()
    for col, n in na[na > 0].sort_values(ascending=False).items():
        meaning = meta.get("na_meaning", {}).get(col, "-")
        lines.append(f"| `{col}` | {n:,} | {n/len(df)*100:.1f}% | {meaning} |")

    if na.sum() == 0:
        lines.append("| - | 0 | 0% | 결측 없음 |")

    lines += [
        "",
        "## 3. 방법",
        "",
        meta.get("method", "(어떻게 정제했는가)"),
        "",
        "**제외한 것**",
        "",
    ]

    for item in meta.get("excluded", ["없음"]):
        lines.append(f"- {item}")

    lines += ["", "## 4. 결과", ""]

    for i, f in enumerate(findings, 1):
        lines += [
            f"### 발견 {i}. {f['제목']}",
            "",
        ]

        if f.get("그래프"):
            lines += [f"![{f['제목']}]({f['그래프']})", ""]

        lines += [
            f"**{f['관찰']}**",
            "",
            f"{f['해석']}",
            "",
        ]

        if f.get("다음"):
            lines += [f"> 다음 확인: {f['다음']}", ""]

    lines += [
        "## 5. 결론과 한계",
        "",
        "### 답한 것",
        "",
    ]

    for item in meta.get("answered", []):
        lines.append(f"- {item}")

    lines += ["", "### 답하지 못한 것", ""]
    for item in meta.get("unanswered", []):
        lines.append(f"- {item}")

    lines += ["", "### 한계", ""]
    for item in meta.get("limits", []):
        lines.append(f"- ⚠ {item}")

    lines += ["", "### 다음 할 일", ""]
    for item in meta.get("next_steps", []):
        lines.append(f"- [ ] {item}")

    lines += [
        "",
        "---",
        "",
        f"*재현: `python src/preprocess.py && jupyter nbconvert "
        f"--execute notebooks/eda.ipynb`*",
    ]

    Path(path).parent.mkdir(parents=True, exist_ok=True)
    Path(path).write_text("\n".join(lines), encoding="utf-8")

    return "\n".join(lines)

```python
"""EDA 리포트 품질 검사."""

import re
from pathlib import Path


def audit_eda_report(path, verbose=True):
    """
    Markdown EDA 리포트의 완성도를 검사합니다.

    반환: dict(score, issues)
    """
    text = Path(path).read_text(encoding="utf-8")
    lines = text.splitlines()

    issues = []
    checks = []

    def check(name, ok, level="필수", hint=""):
        checks.append((name, ok, level))
        if not ok:
            issues.append((level, f"{name}{' — ' + hint if hint else ''}"))
        return ok

    line = "=" * 80

    if verbose:
        print(line)
        print("                       EDA 리포트 검사")
        print(line)
        print(f"\n  파일: {path}")
        print(f"  분량: {len(lines)}줄 · {len(text):,}자")

    # ══════════ ① 필수 섹션 ══════════
    SECTIONS = {
        "질문": r"##\s*\d*\.?\s*(질문|목적|Question)",
        "데이터": r"##\s*\d*\.?\s*(데이터|Data)",
        "방법": r"##\s*\d*\.?\s*(방법|전처리|Method)",
        "결과": r"##\s*\d*\.?\s*(결과|발견|Result|Finding)",
        "결론/한계": r"##\s*\d*\.?\s*(결론|한계|Conclusion|Limit)",
    }

    if verbose:
        print(f"\n[① 필수 섹션]")

    for name, pattern in SECTIONS.items():
        found = bool(re.search(pattern, text, re.I))
        check(f"'{name}' 섹션", found, "필수")
        if verbose:
            print(f"  {'✓' if found else '✗'} {name}")

    # ══════════ ② 발견 개수 ══════════
    findings = re.findall(r"###\s*발견\s*\d+|###\s*Finding\s*\d+", text, re.I)
    n_findings = len(findings)

    check("발견 3개 이상", n_findings >= 3, "필수",
          f"현재 {n_findings}개")

    if verbose:
        print(f"\n[② 발견]")
        print(f"  개수: {n_findings}개  {'✓' if n_findings >= 3 else '✗ (3개 이상)'}")

    # ══════════ ③ 숫자 포함 ══════════
    # 발견 섹션마다 숫자가 있는지
    finding_blocks = re.split(r"###\s*발견\s*\d+", text)[1:]
    with_numbers = sum(1 for b in finding_blocks
                       if re.search(r"\d[\d,.]*\s*(%|점|명|곳|건|원|배|배다)", b))

    check("발견마다 숫자 근거", with_numbers == n_findings and n_findings > 0,
          "필수", f"{with_numbers}/{n_findings}개만 숫자 포함")

    if verbose:
        print(f"  숫자 근거: {with_numbers}/{n_findings}개")

    # ══════════ ④ 해석 길이 ══════════
    short_blocks = []
    for i, b in enumerate(finding_blocks, 1):
        body = re.sub(r"!\[.*?\]\(.*?\)", "", b)          # 이미지 제외
        body = re.sub(r"[#>*`|-]", "", body).strip()
        if len(body) < 100:
            short_blocks.append(i)

    check("발견마다 해석 충분", not short_blocks, "권장",
          f"발견 {short_blocks} 이 100자 미만")

    if verbose:
        print(f"  해석 100자 이상: "
              f"{n_findings - len(short_blocks)}/{n_findings}개")

    # ══════════ ⑤ 그래프 참조 ══════════
    images = re.findall(r"!\[.*?\]\((.*?)\)", text)

    check("그래프 3개 이상", len(images) >= 3, "권장",
          f"현재 {len(images)}개")

    if verbose:
        print(f"\n[③ 그래프]")
        print(f"  참조: {len(images)}개")

        missing = [p for p in images
                   if not (Path(path).parent / p).exists()]
        if missing:
            print(f"  ⚠ 파일 없음: {missing[:3]}")
            issues.append(("경고", f"그래프 파일 {len(missing)}개 없음"))

    # ══════════ ⑥ 데이터 메타 ══════════
    META_KEYS = {
        "출처": r"출처|source",
        "건수": r"\d[\d,]*\s*(행|건|rows)",
        "기간/시점": r"수집|기간|기준|20\d\d[-.]\d\d",
    }

    if verbose:
        print(f"\n[④ 데이터 메타]")

    for name, pattern in META_KEYS.items():
        found = bool(re.search(pattern, text, re.I))
        check(f"{name} 명시", found, "필수")
        if verbose:
            print(f"  {'✓' if found else '✗'} {name}")

    # ══════════ ⑦ 제외·한계 ══════════
    has_excluded = bool(re.search(r"제외|excluded|걸러", text, re.I))
    has_limits = bool(re.search(r"한계|limitation|주의|⚠", text, re.I))

    check("제외 항목 명시", has_excluded, "필수")
    check("한계 명시", has_limits, "필수")

    if verbose:
        print(f"\n[⑤ 투명성]")
        print(f"  {'✓' if has_excluded else '✗'} 무엇을 제외했는지")
        print(f"  {'✓' if has_limits else '✗'} 한계")

    # ══════════ ⑧ 위험 표현 ══════════
    RISKY = {
        r"(때문에|덕분에|영향을 주|원인|야기)": "인과 표현 — 상관으로 인과를 주장하지 않았는지 확인",
        r"(명확히|분명히|확실히)\s*(차이|다르)": "단정 표현 — 신뢰구간 확인 필요",
        r"완벽|절대|100%\s*(확실|정확)": "과도한 확신 표현",
    }

    if verbose:
        print(f"\n[⑥ 표현 검토]")

    found_risky = False
    for pattern, warning in RISKY.items():
        matches = re.findall(pattern, text)
        if matches:
            found_risky = True
            issues.append(("권장", f"{warning} ({len(matches)}곳)"))
            if verbose:
                print(f"  ⚠ {warning} — {len(matches)}곳")

    if verbose and not found_risky:
        print(f"  위험 표현 없음")

    # ══════════ ⑨ 다음 할 일 ══════════
    has_next = bool(re.search(r"다음|next|todo|\[ \]", text, re.I))
    check("다음 할 일", has_next, "권장")

    if verbose:
        print(f"  {'✓' if has_next else '✗'} 다음 할 일 명시")

    # ══════════ 점수 ══════════
    required_fail = sum(1 for l, _ in issues if l == "필수")
    recommend_fail = sum(1 for l, _ in issues if l in ("권장", "경고"))

    score = max(0, 100 - required_fail * 12 - recommend_fail * 5)

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 제출 가능" if score >= 85
                 else "🟡 보완 필요" if score >= 65 else "❌ 재작성")
        print(f"  완성도: {score}점 / 100   {grade}")
        print(f"  (필수 미충족 {required_fail}건 × -12, "
              f"권장 {recommend_fail}건 × -5)")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '필수' else '🟡'} {msg}")

        if not issues:
            print("  문제 없음")

        print(line)

    return {"score": score, "issues": issues,
            "n_findings": n_findings, "n_figures": len(images)}

```python
"""EDA 자동 1차 스캔 — 확인할 거리를 뽑아 줍니다."""

import numpy as np
import pandas as pd


def eda_scan(df, id_cols=None, verbose=True):
    """
    데이터를 훑고 '확인해 볼 것' 목록을 만듭니다.

    반환: DataFrame(우선순위, 대상, 관찰, 확인방법)
    """
    id_cols = set(id_cols or [])
    todos = []

    def add(priority, target, observation, how):
        todos.append({"우선순위": priority, "대상": target,
                      "관찰": observation, "확인 방법": how})

    n = len(df)

    # ══════════ ① 열 수준 ══════════
    for col in df.columns:
        s = df[col]
        nunique = s.nunique(dropna=True)
        na_rate = s.isna().mean()

        # 정보 없는 열
        if nunique <= 1:
            add("낮음", col, f"고유값 {nunique}개 — 정보 없음",
                "분석에서 제외")
            continue

        if col in id_cols or nunique == n:
            continue

        # 결측
        if na_rate > 0.05:
            other_num = [c for c in df.select_dtypes(include=np.number).columns
                         if c != col and df[c].isna().mean() < 0.3]
            if other_num:
                flag = s.isna()
                gaps = {}
                for c in other_num[:5]:
                    std = df[c].std()
                    if std and not np.isnan(std):
                        gap = abs(df.loc[flag, c].mean()
                                  - df.loc[~flag, c].mean()) / std
                        gaps[c] = gap

                worst = max(gaps, key=gaps.get) if gaps else None

                if worst and gaps[worst] > 0.5:
                    add("높음", col,
                        f"결측 {na_rate*100:.0f}% · 결측 그룹의 '{worst}' 평균이 "
                        f"{gaps[worst]:.1f}σ 차이 — MNAR 의심",
                        f"df.groupby(df['{col}'].isna())['{worst}'].mean()")
                else:
                    add("보통", col, f"결측 {na_rate*100:.0f}%",
                        "결측 원인과 처리 전략 결정")

        if pd.api.types.is_numeric_dtype(s):
            v = s.dropna()
            if len(v) < 10:
                continue

            # 특정 값 집중
            top_val = v.value_counts().index[0]
            top_rate = (v == top_val).mean()
            if top_rate > 0.1:
                add("높음", col,
                    f"값 {top_val:,.0f} 이 {top_rate*100:.0f}% 차지",
                    f"df.groupby('범주열')['{col}'].apply(lambda s: (s=={top_val}).mean())")

            # 왜도
            skew = v.skew()
            if abs(skew) > 1.5:
                add("보통", col, f"왜도 {skew:.2f} — 심하게 치우침",
                    f"np.log1p(df['{col}']) 변환 후 분포 재확인")

            # 봉우리 2개 의심 (간이)
            hist, edges = np.histogram(v, bins=20)
            peaks = sum(1 for i in range(1, len(hist) - 1)
                        if hist[i] > hist[i-1] and hist[i] > hist[i+1]
                        and hist[i] > hist.max() * 0.3)
            if peaks >= 2:
                add("높음", col, f"봉우리 {peaks}개 — 숨은 그룹 가능성",
                    f"범주열별로 나눠 histplot(hue=...)")

            # 음수
            if (v < 0).any() and v.median() > 0:
                add("높음", col, f"음수 {(v<0).sum()}건 — 오류값 의심",
                    f"df[df['{col}'] < 0] 확인")

        else:
            # 범주 과다
            if nunique > 30:
                add("보통", col, f"범주 {nunique}개 — 너무 많음",
                    "상위 N개 + '기타'로 묶기")

            # 표기 불일치 의심
            vals = s.dropna().astype(str)
            stripped = vals.str.strip().str.lower()
            if stripped.nunique() < vals.nunique():
                add("높음", col,
                    f"공백·대소문자만 다른 값 존재 "
                    f"({vals.nunique()} → {stripped.nunique()})",
                    "Day 058 문자열 정규화 적용")

            # 극단적 불균형
            top_rate = s.value_counts(normalize=True).iloc[0]
            if top_rate > 0.9:
                add("보통", col,
                    f"'{s.value_counts().index[0]}' 가 {top_rate*100:.0f}%",
                    "분석에 유용한지 판단")

    # ══════════ ② 관계 수준 ══════════
    num_cols = [c for c in df.select_dtypes(include=np.number).columns
                if c not in id_cols and df[c].nunique() > 5]

    if len(num_cols) >= 2:
        pearson = df[num_cols].corr()
        spearman = df[num_cols].corr(method="spearman")

        for i, a in enumerate(num_cols):
            for b in num_cols[i+1:]:
                p, sp = pearson.loc[a, b], spearman.loc[a, b]

                if abs(p) > 0.7:
                    add("높음", f"{a} ↔ {b}",
                        f"상관 r={p:.2f} — 매우 강함",
                        "파생 관계(계산으로 만든 것)인지 확인")

                elif abs(sp) - abs(p) > 0.2:
                    add("높음", f"{a} ↔ {b}",
                        f"피어슨 {p:.2f} vs 스피어만 {sp:.2f} — 비선형 의심",
                        f"scatterplot 으로 곡선 형태 확인")

    # ══════════ ③ 그룹 수준 ══════════
    cat_cols = [c for c in df.columns
                if c not in id_cols and df[c].dtype == "object"
                and 2 <= df[c].nunique() <= 10]

    for cat in cat_cols[:3]:
        for num in num_cols[:4]:
            grouped = df.groupby(cat)[num].mean()
            if len(grouped) < 2 or grouped.std() == 0:
                continue

            overall_std = df[num].std()
            if overall_std and (grouped.max() - grouped.min()) > overall_std:
                add("높음", f"{cat} × {num}",
                    f"그룹 간 평균 차이가 전체 표준편차보다 큼 "
                    f"({grouped.idxmax()} {grouped.max():,.1f} vs "
                    f"{grouped.idxmin()} {grouped.min():,.1f})",
                    f"boxplot(x='{cat}', y='{num}') + 신뢰구간 확인")

    result = pd.DataFrame(todos)

    if not result.empty:
        order = {"높음": 0, "보통": 1, "낮음": 2}
        result = (result.assign(_o=result["우선순위"].map(order))
                        .sort_values("_o").drop(columns="_o")
                        .reset_index(drop=True))

    if verbose:
        print("=" * 96)
        print("                          EDA 자동 스캔 — 확인할 거리")
        print("=" * 96)

        print(f"\n  대상: {n:,}행 × {df.shape[1]}열")

        if result.empty:
            print(f"\n  특별히 확인할 것이 없습니다.")
            print("=" * 96)
            return result

        print(f"  확인 항목: {len(result)}건 "
              f"(높음 {(result['우선순위']=='높음').sum()} · "
              f"보통 {(result['우선순위']=='보통').sum()} · "
              f"낮음 {(result['우선순위']=='낮음').sum()})")

        for priority in ("높음", "보통", "낮음"):
            sub = result[result["우선순위"] == priority]
            if sub.empty:
                continue

            icon = {"높음": "🔴", "보통": "🟡", "낮음": "🔵"}[priority]
            print(f"\n{'━' * 96}")
            print(f"  {icon} 우선순위 {priority}")
            print("━" * 96)

            for _, r in sub.iterrows():
                print(f"\n  · [{r['대상']}]")
                print(f"    관찰: {r['관찰']}")
                print(f"    확인: {r['확인 방법']}")

        print(f"\n{'=' * 96}")
        print("  ⚠ 자동 스캔은 '볼 거리'를 뽑을 뿐, 발견을 대신하지 않습니다.")
        print("     각 항목을 그래프로 확인하고 해석을 직접 작성하세요.")
        print("=" * 96)

    return result


# ══════════ 사용 ══════════
if __name__ == "__main__":
    eda_scan(df, id_cols=["id", "name"])
