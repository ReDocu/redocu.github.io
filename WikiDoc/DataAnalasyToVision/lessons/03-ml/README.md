## 이 단원부터 달라지는 것

### 규칙을 사람이 쓰지 않습니다

대단원 02까지 여러분이 한 일은 이런 것이었습니다.

```python
if 평점 >= 4.5 and 리뷰수 >= 100:
    추천한다 = True
```

**기준(4.5, 100)을 사람이 정했습니다.** 여행지 추천 프로젝트에서 가중치를 손으로 조정했던 그 작업입니다.

머신러닝은 이 순서를 뒤집습니다.

```
[기존]    사람이 규칙을 쓴다  →  프로그램이 답을 낸다
[ML]      데이터와 답을 준다  →  프로그램이 규칙을 찾아낸다
```

**"고양이 사진을 판별하는 if문"을 쓸 수 있습니까?** 쓸 수 없습니다.
털 색, 귀 모양, 각도, 조명 — 규칙으로 적을 수 없는 문제가 세상에는 훨씬 많습니다.
그 문제를 푸는 방법이 이 단원의 주제입니다.

### 사고방식이 바뀝니다 — 알아내는 것 → 예측하는 것

| | 대단원 02 | 대단원 03 |
|---|---|---|
| 목표 | 데이터에서 사실을 **알아낸다** | 처음 보는 데이터의 답을 **예측한다** |
| 데이터 | 있는 것을 다 쓴다 | **반드시 나눠 쓴다** (학습/검증/테스트) |
| 정답 | 해석이 타당하면 정답 | **처음 보는 데이터에서도 맞아야** 정답 |
| 실패 | 에러 없이 틀린 결론 | **학습 데이터에서만 잘 맞음**(과적합) |
| 작업 단위 | 분석 한 번 | **실험 여러 번 + 기록** |

> ⚠️ **이 단원의 가장 큰 위험은 "과적합"입니다.**
> 학습에 쓴 데이터에서 정확도 99%가 나와도, 처음 보는 데이터에서 60%면 그 모델은 쓸모가 없습니다.
> 그래서 이 단원에서는 **처음부터 데이터를 나눠 두고 시작합니다.** ([Day 077](day-077.md))

### 코드는 짧아지고, 시간은 더 걸립니다

모델을 만드는 코드는 이 정도입니다.

```python
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
model.score(X_test, y_test)
```

**3줄입니다.** 그런데 수업은 30일입니다.

나머지 시간은 전부 이런 질문에 답하는 데 씁니다.

- 왜 정확도가 62%밖에 안 나오는가
- 학습 정확도는 99%인데 테스트가 60%면 무엇이 잘못됐는가
- `n_neighbors` 를 5로 한 근거가 무엇인가
- 정확도 95%인 이 모델을 실제로 써도 되는가

> **그래서 이 단원부터 실험 기록표를 씁니다.**
> 무엇을 바꿨나 / 지표는 어떻게 변했나 / 왜 그렇게 됐다고 보는가 — 매 실습마다 남깁니다.
> 이 습관이 대단원 04·05 프로젝트의 품질을 결정합니다.

## 이 문서들을 읽는 법

각 일차 문서는 **6개 블록의 고정 구조**를 갖습니다. (대단원 01·02와 동일)

| 블록 | 내용 |
|---|---|
| ① 학습 목표 | 오늘을 마치면 할 수 있게 되는 것 |
| ② 왜 필요한가 | 이 개념이 없으면 무엇이 안 되는지 |
| ③ 개념 설명 | 용어와 원리. 표·그림 중심 |
| ④ 단계별 실습 | Step 1 → N, 코드 + 실행 결과 |
| ⑤ 자주 하는 실수 | 에러 메시지 원문 + 원인 + 해결 |
| ⑥ 확인 문제 | 3문항. 답은 접혀 있음 |

**실행 결과에 대한 주의** — 이 단원부터 실행 결과의 숫자는 **여러분 환경과 다를 수 있습니다.**
모델 학습에는 난수가 들어가기 때문입니다. `random_state` 를 고정해도 라이브러리 버전이 다르면 소수점이 달라집니다.

> **숫자를 외우지 말고 경향을 보세요.**
> "정확도 0.9737" 이 아니라 **"학습 0.99 / 테스트 0.95 → 조금 과적합"** 이 읽어야 할 내용입니다.

## 이 단원을 마치면

- [ ] 지도 학습의 흐름(분리 → 학습 → 예측 → 평가)을 스스로 설계할 수 있다
- [ ] 신경망이 어떻게 학습하는지(순전파 → 손실 → 역전파 → 갱신) 설명할 수 있다
- [ ] 합성곱과 풀링의 출력 크기·파라미터 수를 **손으로 계산**할 수 있다
- [ ] 직접 모은 이미지로 데이터셋을 만들고 분류 모델을 학습시킬 수 있다
- [ ] 학습 곡선을 보고 다음에 무엇을 바꿔야 할지 말할 수 있다
- [ ] "정확도 95%"를 듣고 되물어야 할 질문을 할 수 있다
