## ② 왜 필요한가

**분석의 마지막 단계는 "전달"입니다.**

```
아무리 잘 분석해도
   → 전달되지 않으면
      → 아무 일도 일어나지 않습니다
```

**그리고 발표는 실력을 드러냅니다.**

| 질문 | 답할 수 있으면 |
|---|---|
| "왜 도보 20분인가요?" | **근거를 갖고 설계했다** |
| "이 데이터 믿을 수 있나요?" | **한계를 알고 있다** |
| "가중치는 어떻게 정했나요?" | **임의로 만들지 않았다** |

> **"열심히 했습니다"는 평가 기준이 아닙니다.**
> **"이렇게 판단했고, 그 근거는 이것입니다"** 가 기준입니다.

**오늘 하루**

```
09:00~12:00  발표 자료 완성 + 리허설 + 예상 질문 준비
13:00~15:30  발표회 (팀당 10분 + 질의응답 5분)
15:30~16:30  상호 평가 · 강평
16:30~18:00  회고문서 작성 · GitHub 정리
```

## 2부 · 예상 질문

### 반드시 나오는 질문 8가지

| # | 질문 | 답의 핵심 |
|---|---|---|
| 1 | **왜 이 주제인가요?** | 기존 추천의 빈틈 |
| 2 | **데이터는 몇 건이고 어디서?** | 숫자 + 출처 + 수집일 |
| 3 | **가중치는 어떻게 정했나요?** | 근거 표 |
| 4 | **왜 도보 20분인가요?** | 후보 수 비교표 |
| 5 | **결측은 어떻게 처리했나요?** | 전략 + 왜 |
| 6 | **이 추천이 맞다는 걸 어떻게 아나요?** | 검증 지표 + 한계 인정 |
| 7 | **다른 지역에도 되나요?** | 일반화 가능성 |
| 8 | **가장 어려웠던 점은?** | 구체적 사례 |

### 답변 3원칙

```
① 숫자로 답한다        "1,472건입니다" (많이 ❌)
② 근거를 댄다          "15분은 20%뿐이라 후보가 부족했습니다"
③ 모르면 인정한다      "확인하지 못했습니다. 다음에 ~로 확인하겠습니다"
```

> ⚠️ **모르는 걸 아는 척하면 바로 들킵니다.**
> "좋은 지적입니다. 그건 확인하지 못했는데, ~를 보면 알 수 있을 것 같습니다."
> 이게 **훨씬 좋은 답변**입니다.

### 곤란한 질문 대응

| 질문 | 대응 |
|---|---|
| "이거 그냥 인기순 아닌가요?" | 인기 지표를 뺀 근거 + 다양성 수치 |
| "지하철역 10개면 의미 없지 않나요?" | **한계로 이미 인정** + 영향 범위 설명 |
| "무료가 좋은 건가요?" | 타깃(20대 예산 제약) 근거 |

## 3부 · 상호 평가

### 평가 기준 5축

| 축 | 배점 | 보는 것 |
|---|---|---|
| **질문의 명확성** | 20 | 누구에게 무엇을, 구체적인가 |
| **데이터 처리** | 20 | 수집·정제 과정과 근거 |
| **분석의 깊이** | 20 | 발견이 있는가, 파고들었는가 |
| **결과물 완성도** | 20 | 그래프·지도·보고서 |
| **한계 인식** | 20 | 자기 작업의 약점을 아는가 |

> **"한계 인식"에 20점을 주는 이유**
> 한계를 모르는 분석은 **과신**입니다. 자기 결과의 약점을 아는 것이
> 다음 개선의 출발점입니다.

### 평가 시 주의

```
❌ "발표를 잘하네요"           → 내용이 아니라 전달력만
✅ "가중치 근거가 명확했어요"   → 구체적 지점
```

## 4부 · 회고문서

`여행지 추천_학습문서.html` 형식을 따릅니다.

```
1. 프로젝트 개요       무엇을 만들었나
2. 분석 파이프라인     어떤 순서로 처리했나
3. 핵심 학습 개념      이 프로젝트에서 쓴 기술
4. 분석 노트           막혔던 것과 해결
5. 배운 점 & 회고      다음에 다르게 할 것
```

### 회고의 핵심 — "다음에 다르게 할 것"

```
❌ "열심히 했다. 팀워크가 좋았다."
✅ "지하철역 데이터를 화요일에야 확인해서 10개만 확보했다.
    다음엔 월요일 검증 단계에서 전체 건수까지 확인하겠다."
```

> **회고는 감상문이 아니라 개선 계획**입니다.
> **구체적인 행동**으로 써야 다음에 실제로 달라집니다.

### Step 2. 예상 질문 대비

```python
"""예상 질문에 대한 근거 자료를 미리 뽑아 둡니다."""

import json
from pathlib import Path

import numpy as np
import pandas as pd

df = pd.read_parquet("data/processed/analysis_table.parquet")
result = pd.read_csv("output/recommend_result.csv")
design = json.loads(Path("docs/recommend_design.json").read_text(encoding="utf-8"))

print("=" * 82)
print("                        예상 질문 대비 자료")
print("=" * 82)

QA = []


def add_qa(q, a, evidence=None):
    QA.append({"질문": q, "답변": a, "근거": evidence or ""})


# ══════════ Q1. 데이터 규모 ══════════
add_qa(
    "데이터는 몇 건이고 어디서 가져왔나요?",
    f"한국관광공사 TourAPI 에서 부산 관광지 1,563건을 수집했고, "
    f"정제 후 {len(df):,}건입니다. 2026-08-09 수집, API 호출 422회입니다.",
    f"카테고리: {df['category'].value_counts().to_dict()}")

# ══════════ Q2. 도보 20분 근거 ══════════
walk = df["walk_min"].dropna()
walk_table = {f"{m}분": f"{int((walk<=m).sum())}곳 ({(walk<=m).mean()*100:.0f}%)"
              for m in (10, 15, 20, 30, 45)}

add_qa(
    "왜 도보 20분인가요?",
    "15분은 후보가 287곳(20%)으로 부족했고, 30분은 52%라서 변별력이 없었습니다. "
    "20분이 429곳(29%)으로 적정했습니다.",
    str(walk_table))

# ══════════ Q3. 가중치 근거 ══════════
```

### Step 3. 상호 평가

```python
"""팀 상호 평가 집계."""

import numpy as np
import pandas as pd

CRITERIA = {
    "질문의 명확성": (20, "누구에게 무엇을 추천하는지 구체적인가"),
    "데이터 처리": (20, "수집·정제 과정과 근거가 타당한가"),
    "분석의 깊이": (20, "발견이 있고 파고들었는가"),
    "결과물 완성도": (20, "그래프·지도·보고서가 완성됐는가"),
    "한계 인식": (20, "자기 작업의 약점을 알고 있는가"),
}


def evaluation_sheet(teams, criteria=CRITERIA):
    """평가지 양식을 출력합니다."""
    print("=" * 82)
    print("                        상호 평가지")
    print("=" * 82)

    print(f"\n[평가 기준]")
    print(f"  {'항목':<16}{'배점':>6}  보는 것")
    print("  " + "-" * 66)
    for name, (score, desc) in criteria.items():
        print(f"  {name:<16}{score:>6}  {desc}")
    print(f"  {'합계':<16}{sum(s for s, _ in criteria.values()):>6}")

    print(f"\n[평가지]")
    for team in teams:
        print(f"\n  ┌{'─' * 74}┐")
        print(f"  │ 팀: {team:<69}│")
        print(f"  ├{'─' * 74}┤")
        for name, (score, _) in criteria.items():
            print(f"  │ {name:<16} [    ] / {score:<3}"
                  f"{'':<48}│")
        print(f"  │ {'합계':<16} [    ] / 100{'':<45}│")
        print(f"  ├{'─' * 74}┤")
        print(f"  │ 배울 점 (구체적으로):{'':<52}│")
        print(f"  │ {'':<73}│")
        print(f"  ├{'─' * 74}┤")
        print(f"  │ 개선 제안:{'':<63}│")
        print(f"  │ {'':<73}│")
        print(f"  └{'─' * 74}┘")

    print(f"\n[작성 요령]")
    print(f"  ❌ '발표를 잘했다'        → 내용이 아니라 전달력만")
    print(f"  ✅ '가중치 근거가 명확'   → 구체적 지점")
    print(f"  ❌ '더 열심히 하세요'     → 실행 불가능")
    print(f"  ✅ '역 데이터를 CSV로 받으면 정확도가 올라갈 것'  → 실행 가능")

    print("\n" + "=" * 82)


def aggregate_evaluations(scores_df, criteria=CRITERIA, verbose=True):
    """
    평가 결과를 집계합니다.

    scores_df : 열 = [평가자, 대상팀, 항목, 점수]
    """
    # 자기 팀 평가 제외
    valid = scores_df[scores_df["평가자"] != scores_df["대상팀"]]

    by_team = valid.pivot_table(index="대상팀", columns="항목",
                                values="점수", aggfunc="mean")
    by_team = by_team[[c for c in criteria if c in by_team.columns]]
    by_team["합계"] = by_team.sum(axis=1)
    by_team = by_team.sort_values("합계", ascending=False).round(1)

    if verbose:
        print("=" * 82)
        print("                        상호 평가 결과")
        print("=" * 82)

        print(f"\n  평가자 {valid['평가자'].nunique()}명 · "
              f"대상 {valid['대상팀'].nunique()}팀 · "
              f"평가 {len(valid)}건 (자기 팀 제외)")

        print(f"\n{by_team.to_string()}")

        # ── 항목별 전체 평균 ──
        print(f"\n[항목별 전체 평균]")
        overall = valid.groupby("항목")["점수"].agg(["mean", "std"]).round(2)
        overall = overall.reindex([c for c in criteria if c in overall.index])

        print(f"  {'항목':<16}{'평균':>8}{'배점':>6}{'달성률':>9}"
              f"{'편차':>7}  분포")
        print("  " + "-" * 62)
        for name, r in overall.iterrows():
            full = criteria[name][0]
            rate = r["mean"] / full * 100
            bar = "■" * int(rate / 5)
            print(f"  {name:<16}{r['mean']:>8.1f}{full:>6}"
                  f"{rate:>8.0f}%{r['std']:>7.1f}  {bar}")

        weakest = overall["mean"].idxmin()
        print(f"\n  → 전체적으로 '{weakest}' 가 가장 낮습니다 "
              f"({overall.loc[weakest, 'mean']:.1f}/{criteria[weakest][0]})")

        # ── 편차가 큰 항목 ──
        high_var = overall["std"].idxmax()
        print(f"  → '{high_var}' 는 팀별 편차가 큽니다 "
              f"(표준편차 {overall.loc[high_var, 'std']:.1f})")

        print("\n" + "=" * 82)

    return by_team


# ══════════ 사용 ══════════
if __name__ == "__main__":
    TEAMS = ["A팀 (부산·뚜벅이)", "B팀 (제주·가족)",
             "C팀 (서울·외국인)", "D팀 (강원·시니어)"]

    evaluation_sheet(TEAMS)

    # 예시 데이터
    rng = np.random.default_rng(42)
    rows = []
    base = {"A팀 (부산·뚜벅이)": 17, "B팀 (제주·가족)": 16,
            "C팀 (서울·외국인)": 15, "D팀 (강원·시니어)": 16}

    for evaluator in TEAMS:
        for target in TEAMS:
            if evaluator == target:
                continue
            for item in CRITERIA:
                score = np.clip(rng.normal(base[target], 1.8), 8, 20)
                rows.append({"평가자": evaluator, "대상팀": target,
                             "항목": item, "점수": round(score)})

    print("\n\n")
    aggregate_evaluations(pd.DataFrame(rows))
```
