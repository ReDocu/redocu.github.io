### 3-3. 사운드

**왜 필요한가** — 타격감의 절반이 소리에서 온다.

**가장 간단한 방법 — `PlaySound`**

```cpp
#pragma comment(lib, "winmm.lib")

    PlaySound("assets/sfx/hit.wav", NULL, SND_FILENAME | SND_ASYNC);
```

| 플래그 | 뜻 |
|---|---|
| `SND_FILENAME` | 파일 경로 |
| `SND_ASYNC` | 비동기 (게임이 안 멈춘다) ← **필수** |
| `SND_LOOP` | 반복 (BGM) |
| `SND_NOSTOP` | 재생 중이면 무시 |

```
   ★ PlaySound 의 한계

   ① 동시에 하나만 재생된다  →  효과음이 서로 끊는다
   ② BGM 과 효과음을 함께 못 쓴다
   ③ 볼륨 조절 불가

   ★ 학습용으로는 충분하지만, 제대로 하려면...
```

**제대로 하려면 — 여러 선택지**

| 방법 | 난이도 | 동시 재생 | 볼륨 |
|---|---|:--:|:--:|
| `PlaySound` | 매우 쉬움 | X | X |
| `MCI` (`mciSendString`) | 쉬움 | 제한적 | O |
| **XAudio2** | 중간 | O | O |
| FMOD / miniaudio | 쉬움(라이브러리) | O | O |

```
   ★ 이 과정에서는 PlaySound 로 충분하다

   목적:  "소리가 있는 것과 없는 것의 차이"를 체감
   Unity(Day 75)에서는 AudioSource 하나로 전부 해결된다
```

**필요한 효과음**

| 상황 | 소리 |
|---|---|
| 타격 (정타) | 묵직한 타격음 |
| 타격 (가드) | 막는 소리 |
| 점프 | 짧은 도약음 |
| 착지 | 발소리 |
| KO | 강한 타격 + 쓰러짐 |
| 메뉴 이동 | 짧은 클릭 |
| 메뉴 결정 | 확정음 |

> **무료 효과음**: freesound.org, Kenney Audio, zapsplat 등. **라이선스 확인 필수.**

### 3-5. 밸런스 조정

**왜 필요한가** — Day 20의 방식으로 격투게임도 검증한다.

**측정할 것**

| 지표 | 목표 |
|---|---|
| 라운드 평균 시간 | 30~50초 |
| 시간 초과 비율 | 20% 이하 |
| 평균 콤보 길이 | 2~4히트 |
| 최대 콤보 데미지 | 최대 체력의 40% 이하 |
| 캐릭터별 승률 | 45~55% |

**계산으로 검증**

```
   체력 200, 평균 데미지 10  →  20번 맞아야 KO
   초당 공격 기회 약 1.5회, 히트율 30%  →  초당 0.45히트
   → 20 / 0.45 ≈ 44초

   ★ 목표 범위(30~50초) 안에 든다
```

### Step 1 — `TitleScene`

```cpp
class TitleScene : public Scene
{
public:
    bool Init(Core* core) override
    {
        Scene::Init(core);
        m_menuIndex = 0;
        SoundManager::Get().PlayBgm("title_bgm");
        return true;
    }

    void Update(double dt) override
    {
        Input& in = m_core->GetInput();

        if (in.IsKeyDown(VK_UP))
        {
            m_menuIndex = (m_menuIndex + MENU_COUNT - 1) % MENU_COUNT;
            SoundManager::Get().PlaySfx("menu_move");
        }
        if (in.IsKeyDown(VK_DOWN))
        {
            m_menuIndex = (m_menuIndex + 1) % MENU_COUNT;
            SoundManager::Get().PlaySfx("menu_move");
        }

        if (in.IsKeyDown(VK_RETURN))
        {
            SoundManager::Get().PlaySfx("menu_select");

            switch (m_menuIndex)
            {
            case 0: m_core->GetSceneManager().ChangeScene(new SelectScene()); break;
            case 1: m_showHelp = !m_showHelp; break;
            case 2: m_core->Quit(); break;
            }
        }
    }

    void Render(Renderer& r) override
    {
        r.DrawImage("title_bg", 0, 0);

        int cx = r.GetWidth() / 2;

        r.DrawTextCentered(cx, 120, RGB(255, 240, 120), 56, "F I G H T E R");

        const char* items[] = { "대전 시작", "조작 설명", "종료" };

        for (int i = 0; i < MENU_COUNT; i++)
        {
            COLORREF c = (i == m_menuIndex) ? RGB(255, 220, 60) : RGB(160, 160, 180);
            const char* prefix = (i == m_menuIndex) ? "▶ " : "  ";

            r.DrawTextCentered(cx, 280 + i * 40, c, 28, "%s%s", prefix, items[i]);
        }

        if (m_showHelp) RenderHelp(r);
    }

private:
    static const int MENU_COUNT = 3;
    int  m_menuIndex = 0;
    bool m_showHelp  = false;
};
```

### Step 3 — `SelectScene`

```cpp
class SelectScene : public Scene
{
public:
    void Update(double dt) override
    {
        Input& in = m_core->GetInput();

        // P1 선택
        if (!m_p1Confirmed)
        {
            if (in.IsKeyDown('A')) m_p1Index = (m_p1Index + CHARACTER_COUNT - 1) % CHARACTER_COUNT;
            if (in.IsKeyDown('D')) m_p1Index = (m_p1Index + 1) % CHARACTER_COUNT;
            if (in.IsKeyDown('G')) { m_p1Confirmed = true; PlaySfx("select"); }
        }

        // P2 선택
        if (!m_p2Confirmed)
        {
            if (in.IsKeyDown(VK_LEFT))  m_p2Index = (m_p2Index + CHARACTER_COUNT - 1) % CHARACTER_COUNT;
            if (in.IsKeyDown(VK_RIGHT)) m_p2Index = (m_p2Index + 1) % CHARACTER_COUNT;
            if (in.IsKeyDown(VK_NUMPAD1)) { m_p2Confirmed = true; PlaySfx("select"); }
        }

        // 둘 다 확정되면 대전으로
        if (m_p1Confirmed && m_p2Confirmed)
        {
            m_startTimer += dt;
            if (m_startTimer >= 0.8)
                m_core->GetSceneManager().ChangeScene(
                    new FightScene(m_p1Index, m_p2Index));
        }

        if (in.IsKeyDown(VK_ESCAPE))
            m_core->GetSceneManager().ChangeScene(new TitleScene());
    }

    void Render(Renderer& r) override
    {
        // 초상화 + 이름 + 능력치 표시
        for (int i = 0; i < CHARACTER_COUNT; i++)
        {
            int x = 150 + i * 200;

            r.DrawImage(g_characters[i].portraitKey, x, 200);

            COLORREF c = RGB(160,160,180);
            if (i == m_p1Index) c = RGB(80, 160, 255);
            if (i == m_p2Index) c = RGB(255, 100, 100);

            r.DrawRect(x - 4, 196, 128, 128, c, false);
            r.DrawTextCentered(x + 60, 340, c, 24, "%s", g_characters[i].name);
        }
        // ...
    }
};
```

### Step 4 — 사운드 매니저

```cpp
class SoundManager
{
public:
    static SoundManager& Get() { static SoundManager s; return s; }

    void PlaySfx(const char* key)
    {
        if (!m_enabled) return;

        char path[MAX_PATH];
        GetAssetPath(FindPath(key), path, sizeof(path));

        PlaySoundA(path, nullptr, SND_FILENAME | SND_ASYNC);
    }

    void PlayBgm(const char* key)
    {
        if (!m_enabled) return;

        char path[MAX_PATH];
        GetAssetPath(FindPath(key), path, sizeof(path));

        PlaySoundA(path, nullptr, SND_FILENAME | SND_ASYNC | SND_LOOP);
    }

    void StopAll() { PlaySoundA(nullptr, nullptr, 0); }

    void SetEnabled(bool e) { m_enabled = e; if (!e) StopAll(); }

private:
    bool m_enabled = true;
};
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 씬 전환 시 크래시 | 즉시 `delete` | 다음 프레임에 교체 (Day 40) |
| 씬 간 데이터가 안 넘어감 | 전달 방법 없음 | 생성자 인자 또는 전역 구조체 |
| 소리가 끊김 | `PlaySound`는 동시 하나 | 정상. 중요한 소리만 재생 |
| 게임이 멈춤 | `SND_ASYNC` 누락 | 플래그 확인 |
| 캐릭터 추가 시 코드 수정 | 데이터 분리 미흡 | 테이블에만 추가되게 |
| 다른 PC에서 실행 안 됨 | 런타임 의존성 | `/MT` 설정 |
| 애셋을 못 찾음 | 빌드 후 복사 누락 | 빌드 이벤트 확인 |
| Release에서 디버그 표시 | `#ifdef` 누락 | 조건부 컴파일 |
| 밸런스가 이상함 | 측정 없이 감으로 조정 | 10판 측정 후 조정 |
