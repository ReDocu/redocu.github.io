# A1 · C·Java·Python 문법 비교표

> [부록 목차](README.md) · 근거 강: [02](../01-foundation/lesson-02.md)·[03](../02-programming/lesson-03.md)·[04](../02-programming/lesson-04.md)·[05](../02-programming/lesson-05.md)·[06](../02-programming/lesson-06.md)강

## 1. 기본기

| 항목 | C | Java | Python |
|---|---|---|---|
| 변수 선언 | `int a = 7;` (자료형 필수) | `int a = 7;` (자료형 필수) | `a = 7` (자료형 없음) |
| 문장 끝 | `;` 필수 | `;` 필수 | 없음 (들여쓰기가 블록) |
| 출력 | `printf("%d", a)` — 포맷 필수, `\n` 수동 | `System.out.println(a)` — 자동 줄바꿈 | `print(a)` — 자동 줄바꿈 |
| 주석 | `//`, `/* */` | `//`, `/* */` | `#` |
| 논리값 출력 | `1` / `0` | `true` / `false` | `True` / `False` |

## 2. 연산 ⚠️ 최다 실점 구역

| 항목 | C | Java | Python |
|---|---|---|---|
| `7 / 2` (정수끼리) | `3` (몫) | `3` (몫) | `3.5` (항상 실수) |
| 몫 | `7 / 2` | `7 / 2` | `7 // 2` |
| 나머지 | `7 % 2` → 1 | 동일 | 동일 |
| 거듭제곱 | (없음 — pow 함수) | (없음 — Math.pow) | `2 ** 3` → 8 |
| 증감 `++` `--` | 있음 (전위/후위 구분) | 있음 | **없음** (`a += 1`) |
| 문자열+숫자 | 불가 | `"A"+1` → `"A1"` (자동 연결) | 불가 (`str()` 필요) |
| 문자열 반복 | 불가 | 불가 | `"가" * 3` → `가가가` |
| 연쇄 비교 `0 < a < 10` | 의도대로 안 됨 (항상 참꼴) | 컴파일 에러 | **의도대로 동작** |
| 논리 연산자 | `&& \|\| !` | `&& \|\| !` | `and or not` |

## 3. 제어문

| 항목 | C | Java | Python |
|---|---|---|---|
| 다중 분기 | `else if` | `else if` | `elif` |
| switch | 있음 (break 필수) | 있음 | **없음** (if/elif로) |
| 삼항 | `조건 ? 참 : 거짓` | 동일 | `참 if 조건 else 거짓` (참이 앞) |
| for | `for (i=0; i<5; i++)` | 동일 | `for i in range(5):` (0~4) |
| do-while | 있음 (최소 1회) | 있음 | **없음** |

## 4. 배열·문자열

| 항목 | C | Java | Python |
|---|---|---|---|
| 배열/리스트 | `int a[3] = {1,2,3};` 크기 고정 | `int[] a = {1,2,3};` 크기 고정 | `a = [1,2,3]` 가변 (`append`) |
| 길이 | strlen(s) — 문자열만 | 배열 `a.length` / 문자열 `s.length()` | 모두 `len(x)` |
| n번째 문자 | `s[n]` | `s.charAt(n)` | `s[n]` (음수 인덱스 가능) |
| 부분 추출 | (직접 구현) | `s.substring(b, e)` — e 미포함 | `s[b:e]` — e 미포함, `[b:e:step]`·`[::-1]` |
| 문자열 비교 | `strcmp(a,b) == 0` | `a.equals(b)` (⚠️ `==`는 주소) | `a == b` |
| 범위 밖 접근 | **침묵(쓰레기값)** | 예외 발생 | 예외 발생 (단, 슬라이싱은 관대) |
| 문자열 끝 | `'\0'` 널 문자 | 없음 | 없음 |

## 5. 함수·심화

| 항목 | C | Java | Python |
|---|---|---|---|
| 함수 정의 | `int f(int x) { }` | `static int f(int x) { }` | `def f(x):` (기본값 `def f(x, y=10)`) |
| 원본 변경 전달 | 포인터 `f(&a)` / `int *x` / `*x` | (기본형은 불가 — 배열·객체는 참조) | (불변형은 불가 — 리스트는 가능) |
| 언어 고유 빈출 | 포인터(`*(p+i)`≡`p[i]`), 구조체(`.`/`->`) | 상속·오버라이딩·다형성·예외(try-catch-finally) | 튜플(불변)·딕셔너리·집합(중복 제거)·슬라이싱 |

## 6. 답안 표기 주의

- 정수/실수 표기: Java `7` vs `7.0` (오버로딩 결과), C `%.1f` → `3.5` / `%f` → `3.500000`
- Python 리스트 출력은 **`[1, 2, 3]` 대괄호·쉼표 그대로**
- 논리값은 언어별 표기(1/true/True)를 그대로
