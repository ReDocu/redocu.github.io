## ③ 개념 설명

### 콜백(Callback)이란

**학습 중 특정 시점에 자동으로 실행되는 코드입니다.**

```
학습 시작
  → on_train_begin
  에폭 시작
    → on_epoch_begin
    배치 처리
      → on_batch_begin / on_batch_end
    → on_epoch_end      ← 대부분의 콜백이 여기서 동작
  → on_train_end
```

```python
model.fit(X, y, epochs=100, callbacks=[cb1, cb2, cb3])
```

### EarlyStopping — 조기 종료

```python
from tensorflow.keras.callbacks import EarlyStopping

early = EarlyStopping(
    monitor="val_loss",
    patience=10,
    restore_best_weights=True,
    verbose=1,
)
```

| 인자 | 의미 | 권장 |
|---|---|---|
| `monitor` | 감시할 지표 | **`"val_loss"`** |
| `patience` | 개선 없이 참을 에폭 수 | **10~20** |
| `restore_best_weights` | **최적 가중치로 복원** | **반드시 `True`** |
| `min_delta` | 개선으로 인정할 최소 변화 | 0 (기본) |
| `mode` | `"min"` / `"max"` / `"auto"` | auto |
| `baseline` | 이 값에 못 미치면 즉시 중단 | None |

**동작 예시** — `patience=5`

```
epoch  8: val_loss 1.20  ← 최고 기록
epoch  9: val_loss 1.25  (1/5)
epoch 10: val_loss 1.31  (2/5)
epoch 11: val_loss 1.28  (3/5)
epoch 12: val_loss 1.35  (4/5)
epoch 13: val_loss 1.42  (5/5) → 중단!
                              → 8에폭 가중치로 복원
```

> ⚠️ **`restore_best_weights=False`(기본값)이면 마지막 에폭 가중치가 남습니다.**
> 즉 위 예시에서 **13에폭(val_loss 1.42)의 모델**이 됩니다.
> **반드시 `True` 로 설정하세요.**

**`monitor` 선택**

| 지표 | 언제 |
|---|---|
| **`val_loss`** | **기본. 가장 민감** |
| `val_accuracy` | 정확도가 최종 목표일 때 |
| `val_auc` | 불균형 데이터 ([Day 080](day-080.md)) |

> **`val_loss` 가 `val_accuracy` 보다 먼저 나빠집니다.** ([Day 096](day-096.md))
> 그래서 `val_loss` 를 감시하는 것이 더 빨리 멈춥니다.

**`patience` 선택**

| patience | 특징 |
|---|---|
| 3~5 | 빨리 멈춤. 지역 정체에 속을 수 있음 |
| **10~15** | **일반적** |
| 20~30 | 안전하지만 오래 걸림 |

```
증강·규제가 강하면 → patience를 크게 (수렴이 느림)
학습률 스케줄링과 함께 → patience를 크게
```

### ModelCheckpoint — 최적 가중치 저장

```python
from tensorflow.keras.callbacks import ModelCheckpoint

ckpt = ModelCheckpoint(
    filepath="best_model.keras",
    monitor="val_loss",
    save_best_only=True,
    save_weights_only=False,
    verbose=1,
)
```

| 인자 | 의미 |
|---|---|
| `filepath` | 저장 경로. `{epoch}`, `{val_loss:.4f}` 사용 가능 |
| `save_best_only` | **`True`** — 개선될 때만 저장 |
| `save_weights_only` | `False` = 전체 모델, `True` = 가중치만 |
| `save_freq` | `"epoch"` 또는 배치 수 |

**파일명에 정보 넣기**

```python
ModelCheckpoint("ckpt_ep{epoch:03d}_loss{val_loss:.4f}.keras")
# → ckpt_ep023_loss0.4218.keras
```

**EarlyStopping과의 차이**

| | EarlyStopping | ModelCheckpoint |
|---|---|---|
| 하는 일 | **학습 중단** | **파일 저장** |
| 최적 복원 | 메모리 상에서 | 디스크에서 |
| Colab 끊김 | **소용 없음** | **복구 가능** |

> **둘 다 쓰세요.** EarlyStopping으로 시간을 아끼고, ModelCheckpoint로 안전장치를 겁니다.

### ReduceLROnPlateau — 학습률 자동 감소

```python
from tensorflow.keras.callbacks import ReduceLROnPlateau

reduce_lr = ReduceLROnPlateau(
    monitor="val_loss",
    factor=0.5,
    patience=5,
    min_lr=1e-6,
    verbose=1,
)
```

| 인자 | 의미 | 권장 |
|---|---|---|
| `factor` | 곱할 배율 | **0.5 또는 0.2** |
| `patience` | 참을 에폭 | **EarlyStopping의 1/2** |
| `min_lr` | 최소 학습률 | 1e-6 |
| `cooldown` | 감소 후 대기 | 0~2 |

**동작 예시**

```
epoch 20: val_loss 0.52  lr=0.001
epoch 25: 개선 없음 → lr = 0.001 × 0.5 = 0.0005
epoch 26: val_loss 0.48  ← 다시 개선!
epoch 33: 개선 없음 → lr = 0.00025
```

> **`ReduceLROnPlateau` 의 `patience` 는 `EarlyStopping` 보다 작아야 합니다.**
> 안 그러면 학습률을 줄여 보기도 전에 학습이 끝납니다.
>
> ```
> ReduceLROnPlateau patience=5
> EarlyStopping     patience=12      ← 2배 이상
> ```

### 학습률 스케줄링

**ReduceLROnPlateau는 "반응형"이고, 스케줄러는 "계획형"입니다.**

**① Step Decay**

```python
def step_decay(epoch, lr):
    if epoch > 0 and epoch % 20 == 0:
        return lr * 0.5
    return lr

from tensorflow.keras.callbacks import LearningRateScheduler
scheduler = LearningRateScheduler(step_decay, verbose=1)
```

```
lr
0.001│━━━━━━━━━━┓
     │          ┗━━━━━━━━━━┓
0.0005│                     ┗━━━━━━━━━━
     └────────────────────────── epoch
      0        20         40
```

**② Cosine Decay**

```python
import numpy as np

def cosine_decay(epoch, lr, total_epochs=100, initial_lr=0.001):
    return initial_lr * 0.5 * (1 + np.cos(np.pi * epoch / total_epochs))
```

```
lr
0.001│╲
     │ ╲___
     │     ╲___
     │         ╲__
0.000│            ╲___
     └────────────────── epoch
```

**③ Warmup + Cosine** (최신 모델의 표준)

```
처음 5에폭: lr을 0에서 목표까지 올림 (warmup)
그 후: cosine으로 감소
```

| 방식 | 특징 |
|---|---|
| 고정 | 단순. 기본 |
| ReduceLROnPlateau | **반응형. 튜닝 부담 적음** |
| Step | 예측 가능. 논문 재현에 유용 |
| **Cosine** | **최근 표준. 부드러움** |
| Warmup + Cosine | 큰 모델·큰 배치에 유용 |

### ★ 권장 전략 — 에폭을 크게 잡고 맡긴다

```python
callbacks = [
    EarlyStopping(monitor="val_loss", patience=15,
                  restore_best_weights=True, verbose=1),
    ModelCheckpoint("best.keras", monitor="val_loss",
                    save_best_only=True, verbose=0),
    ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                      patience=6, min_lr=1e-6, verbose=1),
    CSVLogger("log.csv"),
]

model.fit(train_ds, epochs=200, validation_data=val_ds,
          callbacks=callbacks)
```

**에폭 200은 상한선일 뿐입니다.** EarlyStopping이 알아서 멈춥니다.

| 장점 | 설명 |
|---|---|
| **에폭 튜닝 불필요** | 설정마다 최적 에폭이 달라도 됨 |
| **최적 모델 확보** | restore_best_weights |
| **시간 절약** | 불필요한 학습 안 함 |
| **안전** | 체크포인트 파일 남음 |

### 콜백 실행 순서

```python
callbacks=[A, B, C]      # 리스트 순서대로 실행
```

**주의할 조합**

```python
# ✗ EarlyStopping이 먼저면 ModelCheckpoint가 마지막 에폭을 저장 못 할 수도
callbacks=[EarlyStopping(...), ModelCheckpoint(...)]

# ✓ 저장을 먼저
callbacks=[ModelCheckpoint(...), EarlyStopping(...), ReduceLROnPlateau(...)]
```

## ④ 단계별 실습

### Step 1. EarlyStopping 없이 vs 있이

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import EarlyStopping

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()

N_TRAIN = 8000
X_train = X_full[5000:5000 + N_TRAIN].astype("float32")
y_train = y_full[5000:5000 + N_TRAIN]
X_val, y_val = X_full[:2000].astype("float32"), y_full[:2000]
X_test = X_test.astype("float32")


def build():
    return keras.Sequential([
        layers.Input(shape=(32, 32, 3)),
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dense(256, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ])


EPOCHS = 60

print("=" * 70)
print("① EarlyStopping 없이 60에폭")
print("=" * 70)
tf.random.set_seed(42)
m1 = build()
m1.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
           metrics=["accuracy"])
t0 = time.time()
h1 = m1.fit(X_train, y_train, epochs=EPOCHS, batch_size=64,
            validation_data=(X_val, y_val), verbose=0).history
time1 = time.time() - t0
_, acc1 = m1.evaluate(X_test, y_test, verbose=0)

best_ep = int(np.argmin(h1["val_loss"])) + 1
print(f"  학습 시간   : {time1:.1f}초 ({EPOCHS}에폭)")
print(f"  테스트 정확도: {acc1:.4f}")
print(f"  val_loss 최소: {best_ep}에폭 ({h1['val_loss'][best_ep-1]:.4f})")
print(f"  60에폭 val_loss: {h1['val_loss'][-1]:.4f}  "
      f"({h1['val_loss'][-1]/h1['val_loss'][best_ep-1]:.1f}배 악화)")
print(f"  → {best_ep}에폭 시점의 모델을 잃어버렸습니다")

print("\n" + "=" * 70)
print("② EarlyStopping 적용 (patience=10, restore_best_weights=True)")
print("=" * 70)
tf.random.set_seed(42)
m2 = build()
m2.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
           metrics=["accuracy"])
early = EarlyStopping(monitor="val_loss", patience=10,
                      restore_best_weights=True, verbose=1)
t0 = time.time()
h2 = m2.fit(X_train, y_train, epochs=EPOCHS, batch_size=64,
            validation_data=(X_val, y_val), callbacks=[early], verbose=0).history
time2 = time.time() - t0
_, acc2 = m2.evaluate(X_test, y_test, verbose=0)

print(f"\n  실제 학습 에폭: {len(h2['loss'])} / {EPOCHS}")
print(f"  학습 시간     : {time2:.1f}초")
print(f"  테스트 정확도 : {acc2:.4f}")
print(f"  복원된 에폭   : {int(np.argmin(h2['val_loss'])) + 1}")

print("\n" + "=" * 70)
print("③ restore_best_weights=False 면?")
print("=" * 70)
tf.random.set_seed(42)
m3 = build()
m3.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
           metrics=["accuracy"])
early_no = EarlyStopping(monitor="val_loss", patience=10,
                         restore_best_weights=False, verbose=0)
h3 = m3.fit(X_train, y_train, epochs=EPOCHS, batch_size=64,
            validation_data=(X_val, y_val), callbacks=[early_no],
            verbose=0).history
_, acc3 = m3.evaluate(X_test, y_test, verbose=0)
print(f"  실제 학습 에폭: {len(h3['loss'])}")
print(f"  테스트 정확도 : {acc3:.4f}   ← 마지막 에폭 가중치")
print(f"  restore=True 와 차이: {acc2 - acc3:+.4f}")

print("\n" + "=" * 78)
print("종합")
print("=" * 78)
summary = pd.DataFrame([
    {"설정": "EarlyStopping 없음", "에폭": EPOCHS, "시간(s)": round(time1, 1),
     "test": round(acc1, 4)},
    {"설정": "ES + restore=True", "에폭": len(h2["loss"]),
     "시간(s)": round(time2, 1), "test": round(acc2, 4)},
    {"설정": "ES + restore=False", "에폭": len(h3["loss"]),
     "시간(s)": round(time2 * len(h3["loss"]) / len(h2["loss"]), 1),
     "test": round(acc3, 4)},
])
print(summary.to_string(index=False))
print("=" * 78)
print(f"\n시간 절약: {(1 - time2/time1):.1%}")
print(f"성능 개선: {acc2 - acc1:+.4f}")
print("\n★ restore_best_weights=True 가 핵심입니다.")
print("  False면 조기 종료의 의미가 절반으로 줄어듭니다.")

# ── 그래프 ──
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

ax = axes[0]
ax.plot(h1["loss"], linewidth=2, label="train")
ax.plot(h1["val_loss"], linewidth=2, label="validation")
ax.axvline(best_ep - 1, color="green", linestyle="--", linewidth=2,
           label=f"best epoch {best_ep}")
ax.axvspan(best_ep - 1, EPOCHS, alpha=0.12, color="red",
           label="wasted epochs")
ax.set_xlabel("epoch"); ax.set_ylabel("loss")
ax.set_title("① Without EarlyStopping — 60 epochs")
ax.legend(fontsize=8.5); ax.grid(alpha=0.3)

ax = axes[1]
ax.plot(h2["loss"], linewidth=2, label="train")
ax.plot(h2["val_loss"], linewidth=2, label="validation")
stop_ep = len(h2["loss"])
best2 = int(np.argmin(h2["val_loss"])) + 1
ax.axvline(best2 - 1, color="green", linestyle="--", linewidth=2,
           label=f"restored epoch {best2}")
ax.axvline(stop_ep - 1, color="red", linestyle="--", linewidth=2,
           label=f"stopped at {stop_ep}")
ax.set_xlabel("epoch"); ax.set_ylabel("loss")
ax.set_title("② With EarlyStopping")
ax.legend(fontsize=8.5); ax.grid(alpha=0.3)

ax = axes[2]
ax.bar(summary["설정"], summary["test"], color=["crimson", "seagreen", "orange"])
ax.set_ylabel("test accuracy")
ax.set_ylim(0.6, 0.75)
ax.set_title("Test accuracy")
ax.tick_params(axis="x", rotation=15, labelsize=8.5)
for i, v in enumerate(summary["test"]):
    ax.text(i, v + 0.003, f"{v:.4f}", ha="center", fontsize=9)
ax.grid(alpha=0.3, axis="y")

fig.tight_layout()
plt.show()
```

### Step 3. ReduceLROnPlateau와 학습률 스케줄링

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import (EarlyStopping, LearningRateScheduler,
                                        ReduceLROnPlateau)


def build():
    return keras.Sequential([
        layers.Input(shape=(32, 32, 3)),
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.1),
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same", use_bias=False),
        layers.BatchNormalization(), layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Conv2D(64, 3, padding="same", use_bias=False),
        layers.BatchNormalization(), layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Conv2D(128, 3, padding="same", use_bias=False),
        layers.BatchNormalization(), layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Flatten(), layers.Dropout(0.4),
        layers.Dense(128, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ])


EPOCHS = 60
INITIAL_LR = 0.002


def step_decay(epoch, lr):
    """20에폭마다 절반"""
    if epoch > 0 and epoch % 20 == 0:
        return lr * 0.5
    return lr


def cosine_decay(epoch, lr):
    """코사인 감소"""
    return INITIAL_LR * 0.5 * (1 + np.cos(np.pi * epoch / EPOCHS))


def warmup_cosine(epoch, lr):
    """5에폭 워밍업 후 코사인"""
    warmup = 5
    if epoch < warmup:
        return INITIAL_LR * (epoch + 1) / warmup
    progress = (epoch - warmup) / (EPOCHS - warmup)
    return INITIAL_LR * 0.5 * (1 + np.cos(np.pi * progress))


전략들 = [
    ("고정 lr", []),
    ("ReduceLROnPlateau", [ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                                             patience=5, min_lr=1e-6, verbose=0)]),
    ("Step decay", [LearningRateScheduler(step_decay, verbose=0)]),
    ("Cosine decay", [LearningRateScheduler(cosine_decay, verbose=0)]),
    ("Warmup + Cosine", [LearningRateScheduler(warmup_cosine, verbose=0)]),
]

rows, histories = [], {}

print("=" * 78)
print(f"학습률 스케줄링 비교 — 초기 lr {INITIAL_LR}, {EPOCHS}에폭")
print("=" * 78)

for name, cbs in 전략들:
    tf.random.set_seed(42)
    m = build()
    m.compile(optimizer=keras.optimizers.Adam(learning_rate=INITIAL_LR),
              loss="sparse_categorical_crossentropy", metrics=["accuracy"])

    # 학습률 기록용
    lr_history = []

    class LRLogger(keras.callbacks.Callback):
        def on_epoch_end(self, epoch, logs=None):
            lr = self.model.optimizer.learning_rate
            lr_history.append(float(keras.backend.get_value(lr)))

    h = m.fit(X_train, y_train, epochs=EPOCHS, batch_size=64,
              validation_data=(X_val, y_val),
              callbacks=cbs + [LRLogger()], verbose=0).history
    _, acc = m.evaluate(X_test, y_test, verbose=0)

    rows.append({"전략": name, "train": round(h["accuracy"][-1], 4),
                 "val_최고": round(max(h["val_accuracy"]), 4),
                 "test": round(acc, 4),
                 "최종lr": f"{lr_history[-1]:.2e}",
                 "최적에폭": int(np.argmin(h["val_loss"])) + 1})
    histories[name] = {"history": h, "lr": lr_history}
    print(f"{name:<22} test {acc:.4f}  최종 lr {lr_history[-1]:.2e}")

df = pd.DataFrame(rows)
print("\n" + "=" * 90)
print(df.to_string(index=False))
print("=" * 90)

best = df.loc[df["test"].idxmax()]
print(f"\n최고: {best['전략']} → test {best['test']:.4f}")
print(f"고정 lr 대비: {best['test'] - df.iloc[0]['test']:+.4f}")

print("\n[해석]")
print("  고정 lr        : 후반에 진동. 미세 조정 못 함")
print("  ReduceLROnPlateau: 정체될 때 자동 감소. 튜닝 부담 적음")
print("  Step decay     : 예측 가능. 감소 시점을 미리 정해야 함")
print("  Cosine         : 부드러운 감소. 최근 표준")
print("  Warmup+Cosine  : 초반 불안정 방지. 큰 배치·큰 모델에 유용")

# ── 그래프 ──
fig, axes = plt.subplots(2, 2, figsize=(15, 10))

    ax.plot(histories[name]["lr"], linewidth=2.5, label=name)

ax.legend(fontsize=9); ax.grid(alpha=0.3)

ax.set_title("Validation loss")
ax.legend(fontsize=9); ax.grid(alpha=0.3)

ax = axes[1, 1]
ax.bar(df["전략"], df["test"], color="steelblue")
ax.set_ylabel("test accuracy")
ax.set_ylim(df["test"].min() - 0.02, df["test"].max() + 0.01)
ax.set_title("Final test accuracy")
ax.tick_params(axis="x", rotation=20, labelsize=8.5)
for i, v in enumerate(df["test"]):
    ax.text(i, v + 0.002, f"{v:.4f}", ha="center", fontsize=8.5)
ax.grid(alpha=0.3, axis="y")

fig.tight_layout()
plt.show()

OUT = Path("/content/drive/MyDrive/ml_course/experiments")
OUT.mkdir(parents=True, exist_ok=True)
df.to_csv(OUT / "day097_lr_schedules.csv", index=False, encoding="utf-8-sig")
```

> **Cosine은 전체 에폭 수를 미리 알아야 합니다.** EarlyStopping과 함께 쓰기 어렵습니다.
> **ReduceLROnPlateau는 EarlyStopping과 조합이 자연스럽습니다.**

```python
class TimeHistory(keras.callbacks.Callback):
    """에폭별 소요 시간 기록"""

    def on_train_begin(self, logs=None):
        self.times = []

    def on_epoch_begin(self, epoch, logs=None):
        self._start = time.time()

    def on_epoch_end(self, epoch, logs=None):
        self.times.append(time.time() - self._start)


class GapMonitor(keras.callbacks.Callback):
    """train-val 격차를 감시하고 경고"""

    def __init__(self, threshold=0.15, verbose=1):
        super().__init__()
        self.threshold = threshold
        self.verbose = verbose
        self.gaps = []

    def on_epoch_end(self, epoch, logs=None):
        gap = logs.get("accuracy", 0) - logs.get("val_accuracy", 0)
        self.gaps.append(gap)
        if gap > self.threshold and self.verbose:
            print(f"  ⚠️ epoch {epoch+1}: 격차 {gap:.4f} — 과적합 주의")


class ProgressPrinter(keras.callbacks.Callback):
    """N에폭마다 한 줄로 진행 상황 출력"""

    def __init__(self, every=10):
        super().__init__()
        self.every = every

    def on_epoch_end(self, epoch, logs=None):
        if (epoch + 1) % self.every == 0:
            lr = float(keras.backend.get_value(self.model.optimizer.learning_rate))
            print(f"  epoch {epoch+1:>3}: loss {logs['loss']:.4f}  "
                  f"val_loss {logs['val_loss']:.4f}  "
                  f"val_acc {logs['val_accuracy']:.4f}  lr {lr:.1e}")
```

```python
def make_callbacks(name, monitor="val_loss", patience=15, lr_patience=6,

    print("=" * 70)
    print(f"  최대 에폭 : {max_epochs} (EarlyStopping이 조절)")
    print(f"  파라미터  : {model.count_params():,}")

    fit_kwargs = dict(epochs=max_epochs, callbacks=callbacks, verbose=0)
    if y_train is not None:
        fit_kwargs.update(validation_data=(val_data, y_val))
        if batch_size:
            fit_kwargs["batch_size"] = batch_size
        history = model.fit(train_data, y_train, **fit_kwargs)
    else:
        fit_kwargs.update(validation_data=val_data)
        history = model.fit(train_data, **fit_kwargs)

    h = history.history
    n_epochs = len(h["loss"])
    best_ep = int(np.argmin(h["val_loss"])) + 1

    print(f"\n  실제 에폭 : {n_epochs} / {max_epochs}")
    print(f"  복원 에폭 : {best_ep}")
    print(f"  총 시간   : {sum(time_cb.times):.1f}초 "
          f"({np.mean(time_cb.times):.2f}초/에폭)")
    print(f"  최종 val_loss : {h['val_loss'][best_ep-1]:.4f}")
    print(f"  최종 val_acc  : {h['val_accuracy'][best_ep-1]:.4f}")

    # 메타데이터 저장
    meta = {
        "name": name,
        "params": int(model.count_params()),
        "max_epochs": max_epochs,
        "actual_epochs": n_epochs,
        "best_epoch": best_ep,
        "best_val_loss": float(h["val_loss"][best_ep - 1]),
        "best_val_acc": float(h["val_accuracy"][best_ep - 1]),
        "total_time_sec": float(sum(time_cb.times)),
        "sec_per_epoch": float(np.mean(time_cb.times)),
    }
    (LOG_DIR / f"{name}_meta.json").write_text(
        json.dumps(meta, indent=2, ensure_ascii=False))

    model.save(MODEL_DIR / f"{name}.keras")
    print(f"  저장 완료 : {MODEL_DIR / f'{name}.keras'}")
    print("=" * 70)

    return model, history, meta

def plot_history(history, name="", log_path=None):
    h = history.history if hasattr(history, "history") else history
    best_ep = int(np.argmin(h["val_loss"]))

    n_cols = 3 if log_path or "learning_rate" in h else 2
    fig, axes = plt.subplots(1, n_cols, figsize=(6 * n_cols, 5))

    ax = axes[0]
    ax.plot(h["loss"], linewidth=2, label="train")
    ax.plot(h["val_loss"], linewidth=2, label="validation")
    ax.axvline(best_ep, color="green", linestyle="--", linewidth=2,
               label=f"best epoch {best_ep+1}")
    ax.set_xlabel("epoch"); ax.set_ylabel("loss")
    ax.set_title(f"{name} — Loss"); ax.legend(); ax.grid(alpha=0.3)

    ax = axes[1]
    ax.plot(h["accuracy"], linewidth=2, label="train")
    ax.plot(h["val_accuracy"], linewidth=2, label="validation")
    ax.axvline(best_ep, color="green", linestyle="--", linewidth=2)
    ax.fill_between(range(len(h["accuracy"])), h["accuracy"],
                    h["val_accuracy"], alpha=0.12, color="red")
    ax.set_xlabel("epoch"); ax.set_ylabel("accuracy")
    ax.set_title("Accuracy"); ax.legend(); ax.grid(alpha=0.3)

    if n_cols == 3:
        ax = axes[2]
        if log_path and Path(log_path).exists():
            log = pd.read_csv(log_path)
            if "learning_rate" in log.columns:
                ax.plot(log["epoch"], log["learning_rate"], linewidth=2.5,
                        color="purple", drawstyle="steps-post")
        elif "learning_rate" in h:
            ax.plot(h["learning_rate"], linewidth=2.5, color="purple",
                    drawstyle="steps-post")
        ax.set_yscale("log")
        ax.set_xlabel("epoch"); ax.set_ylabel("learning rate (log)")
        ax.set_title("Learning rate"); ax.grid(alpha=0.3)

    fig.tight_layout()
    plt.show()


def compare_runs(names):
    """여러 실험의 로그를 비교"""
    rows = []
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))
    for name in names:
        meta_path = LOG_DIR / f"{name}_meta.json"
        log_path = LOG_DIR / f"{name}_log.csv"
        if not meta_path.exists():
            continue
        meta = json.loads(meta_path.read_text())
        rows.append(meta)
        log = pd.read_csv(log_path)
        axes[0].plot(log["epoch"], log["val_loss"], linewidth=2, label=name)
        axes[1].plot(log["epoch"], log["val_accuracy"], linewidth=2, label=name)

    axes[0].set_xlabel("epoch"); axes[0].set_ylabel("val loss")
    axes[0].set_title("Validation loss"); axes[0].legend(); axes[0].grid(alpha=0.3)
    axes[1].set_xlabel("epoch"); axes[1].set_ylabel("val accuracy")
    axes[1].set_title("Validation accuracy"); axes[1].legend(); axes[1].grid(alpha=0.3)
    fig.tight_layout()
    plt.show()

    return pd.DataFrame(rows)
```

**문제점 7가지**

| # | 문제 | 결과 |
|---|---|---|
| 1 | `monitor="val_acc"` | TF 2.x에서는 **`val_accuracy`** — 콜백 미동작 |
| 2 | `restore_best_weights` 없음 | 마지막 에폭 가중치가 남음 |
| 3 | `patience=3` 너무 짧음 | 일시적 정체에 속아 조기 종료 |
| 4 | `/content/` 저장 | **Colab 종료 시 소실** |
| 5 | `.h5` 확장자 | TF 2.13+에서는 `.keras` |
| 6 | ReduceLR이 `loss` 감시 | **train loss는 계속 내려감** → 발동 안 함 |
| 7 | ReduceLR patience > ES patience | 학습률 줄이기 전에 종료 |
| 8 | `epochs=20` 고정 | EarlyStopping의 의미가 없음 |
| 9 | `validation_data` 없음 | **val_* 지표 자체가 없음** |

```python
"""
train_utils.py (확장판)
Day 098~105 에서 계속 사용

import json
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras.callbacks import (CSVLogger, EarlyStopping,
                                        ModelCheckpoint, ReduceLROnPlateau)

BASE = Path("/content/drive/MyDrive/ml_course")
CKPT_DIR, LOG_DIR, MODEL_DIR = (BASE / "checkpoints", BASE / "logs",
                                BASE / "models")
for d in [CKPT_DIR, LOG_DIR, MODEL_DIR]:
    d.mkdir(parents=True, exist_ok=True)


# ══════════════════════════════════════════
# ⑤ 커스텀 콜백
# ══════════════════════════════════════════
class TimeHistory(keras.callbacks.Callback):
    """에폭별 소요 시간"""
    def on_train_begin(self, logs=None):
        self.times = []

    def on_epoch_begin(self, epoch, logs=None):
        self._t = time.time()

    def on_epoch_end(self, epoch, logs=None):
        self.times.append(time.time() - self._t)


class GapMonitor(keras.callbacks.Callback):
    """train-val 격차 감시 + 자동 진단"""
    def __init__(self, threshold=0.15, warn_every=10):
        super().__init__()
        self.threshold, self.warn_every = threshold, warn_every
        self.gaps = []
        self._warned = 0

    def on_epoch_end(self, epoch, logs=None):
        gap = logs.get("accuracy", 0) - logs.get("val_accuracy", 0)
        self.gaps.append(gap)
        if gap > self.threshold and (epoch - self._warned) >= self.warn_every:
            print(f"  ⚠️ ep {epoch+1}: 격차 {gap:.3f} — 규제 강화 검토")
            self._warned = epoch


class ProgressPrinter(keras.callbacks.Callback):
    """N에폭마다 요약 출력"""
    def __init__(self, every=10):
        super().__init__()
        self.every = every

    def on_epoch_end(self, epoch, logs=None):
        if (epoch + 1) % self.every == 0:
            lr = float(keras.backend.get_value(
                self.model.optimizer.learning_rate))
            gap = logs.get("accuracy", 0) - logs.get("val_accuracy", 0)
            print(f"  ep {epoch+1:>3} | loss {logs['loss']:.4f} "
                  f"val_loss {logs['val_loss']:.4f} "
                  f"val_acc {logs['val_accuracy']:.4f} "
                  f"gap {gap:+.3f} lr {lr:.1e}")


class StopOnNaN(keras.callbacks.Callback):
    """NaN 발생 시 원인 안내와 함께 중단"""
    def on_batch_end(self, batch, logs=None):
        loss = logs.get("loss")
        if loss is not None and (np.isnan(loss) or np.isinf(loss)):
            print("\n" + "=" * 60)
            print("손실이 NaN — 학습 중단")
            print("  ① 학습률을 1/10로")
            print("  ② 입력 정규화 확인 (0~255를 그대로 넣었나)")
            print("  ③ np.isnan(X).sum()")
            print("  ④ 출력층 활성화와 손실 함수 짝")
            print("  ⑤ optimizer에 clipnorm=1.0 추가")
            print("=" * 60)
            self.model.stop_training = True


# ══════════════════════════════════════════
# ① 표준 콜백 세트
# ══════════════════════════════════════════
def make_callbacks(name, monitor="val_loss", mode="auto", patience=15,
                   lr_patience=6, lr_factor=0.5, min_lr=1e-6, min_delta=0.0,
                   print_every=10, save_latest=False, gap_threshold=0.15):
    """
    프로젝트 표준 콜백 세트

    save_latest=True 면 재개용 체크포인트를 추가로 저장합니다.
    """
    cbs = [
        ModelCheckpoint(str(CKPT_DIR / f"{name}_best.keras"),
                        monitor=monitor, mode=mode,
                        save_best_only=True, verbose=0),
    ]
    if save_latest:                                    # ⑥ 재개용
        cbs.append(ModelCheckpoint(str(CKPT_DIR / f"{name}_latest.keras"),
                                   save_best_only=False, verbose=0))
    cbs += [
        EarlyStopping(monitor=monitor, mode=mode, patience=patience,
                      min_delta=min_delta,
                      restore_best_weights=True, verbose=1),
        ReduceLROnPlateau(monitor=monitor, mode=mode, factor=lr_factor,
                          patience=lr_patience, min_lr=min_lr, verbose=1),
        CSVLogger(str(LOG_DIR / f"{name}_log.csv"), append=save_latest),
        ProgressPrinter(every=print_every),
        GapMonitor(threshold=gap_threshold),
        StopOnNaN(),
    ]
    return cbs


# ══════════════════════════════════════════
# ② 학습 실행 + 메타데이터
# ══════════════════════════════════════════
def train_model(model, train_data, val_data, name, max_epochs=200,
                y_train=None, y_val=None, batch_size=None,
                config=None, resume=False, **cb_kwargs):
    """
    config: 실험 설정 딕셔너리 (메타데이터에 함께 저장)
    resume: True면 latest 체크포인트에서 이어서 학습
    """
    initial_epoch = 0
    if resume:                                          # ⑥ 재개
        latest = CKPT_DIR / f"{name}_latest.keras"
        log_path = LOG_DIR / f"{name}_log.csv"
        if latest.exists() and log_path.exists():
            model = keras.models.load_model(latest)
            initial_epoch = len(pd.read_csv(log_path))
            print(f"체크포인트에서 재개: {initial_epoch}에폭부터")
        else:
            print("재개할 체크포인트가 없어 처음부터 시작합니다")

    time_cb = TimeHistory()
    gap_cb = GapMonitor()
    callbacks = make_callbacks(name, save_latest=resume, **cb_kwargs)
    callbacks += [time_cb]

    print("=" * 70)
    print(f"학습 — {name}")
    print("=" * 70)
    print(f"  최대 에폭 : {max_epochs} (EarlyStopping이 조절)")
    print(f"  시작 에폭 : {initial_epoch}")
    print(f"  파라미터  : {model.count_params():,}")
    if config:
        print(f"  설정      : {config}")

    fit_kwargs = dict(epochs=max_epochs, initial_epoch=initial_epoch,
                      callbacks=callbacks, verbose=0)
    if y_train is not None:
        fit_kwargs.update(validation_data=(val_data, y_val))
        if batch_size:
            fit_kwargs["batch_size"] = batch_size
        history = model.fit(train_data, y_train, **fit_kwargs)
    else:
        fit_kwargs.update(validation_data=val_data)
        history = model.fit(train_data, **fit_kwargs)

    h = history.history
    best_ep = int(np.argmin(h["val_loss"])) + 1

    meta = {
        "name": name,
        "config": config or {},
        "params": int(model.count_params()),
        "max_epochs": max_epochs,
        "actual_epochs": len(h["loss"]) + initial_epoch,
        "best_epoch": best_ep + initial_epoch,
        "best_val_loss": float(h["val_loss"][best_ep - 1]),
        "best_val_acc": float(h["val_accuracy"][best_ep - 1]),
        "final_gap": float(h["accuracy"][best_ep - 1]
                           - h["val_accuracy"][best_ep - 1]),
        "total_time_sec": float(sum(time_cb.times)),
        "sec_per_epoch": float(np.mean(time_cb.times)) if time_cb.times else 0,
    }
    (LOG_DIR / f"{name}_meta.json").write_text(
        json.dumps(meta, indent=2, ensure_ascii=False))
    model.save(MODEL_DIR / f"{name}.keras")

    print(f"\n  실제 에폭 : {meta['actual_epochs']}")
    print(f"  복원 에폭 : {meta['best_epoch']}")
    print(f"  val_acc   : {meta['best_val_acc']:.4f}")
    print(f"  격차      : {meta['final_gap']:+.4f}")
    print(f"  시간      : {meta['total_time_sec']:.1f}초 "
          f"({meta['sec_per_epoch']:.2f}초/에폭)")
    print("=" * 70)

    return model, history, meta

# ══════════════════════════════════════════
def plot_history(history, name="", show_lr=True):
    h = history.history if hasattr(history, "history") else history
    best_ep = int(np.argmin(h["val_loss"]))
    log_path = LOG_DIR / f"{name}_log.csv"
    has_lr = show_lr and log_path.exists()

    n = 3 if has_lr else 2
    fig, axes = plt.subplots(1, n, figsize=(6 * n, 5))

    axes[0].plot(h["loss"], linewidth=2, label="train")
    axes[0].plot(h["val_loss"], linewidth=2, label="validation")
    axes[0].axvline(best_ep, color="green", linestyle="--", linewidth=2,
                    label=f"best {best_ep+1}")
    axes[0].set_xlabel("epoch"); axes[0].set_ylabel("loss")
    axes[0].set_title(f"{name} — Loss"); axes[0].legend(); axes[0].grid(alpha=0.3)

    axes[1].plot(h["accuracy"], linewidth=2, label="train")
    axes[1].plot(h["val_accuracy"], linewidth=2, label="validation")
    axes[1].axvline(best_ep, color="green", linestyle="--", linewidth=2)
    axes[1].fill_between(range(len(h["accuracy"])), h["accuracy"],
                         h["val_accuracy"], alpha=0.12, color="red")
    axes[1].set_xlabel("epoch"); axes[1].set_ylabel("accuracy")
    axes[1].set_title("Accuracy"); axes[1].legend(); axes[1].grid(alpha=0.3)

    if has_lr:
        log = pd.read_csv(log_path)
        if "learning_rate" in log.columns:
            axes[2].plot(log["epoch"], log["learning_rate"], linewidth=2.5,
                         color="purple", drawstyle="steps-post")
            axes[2].set_yscale("log")
            axes[2].set_xlabel("epoch"); axes[2].set_ylabel("lr (log)")
            axes[2].set_title("Learning rate"); axes[2].grid(alpha=0.3)

    fig.tight_layout()
    plt.show()

def compare_runs(names, metric="val_accuracy"):
    rows = []
    fig, axes = plt.subplots(1, 3, figsize=(18, 5))

    for name in names:
        meta_p, log_p = (LOG_DIR / f"{name}_meta.json",
                         LOG_DIR / f"{name}_log.csv")
        if not meta_p.exists():
            print(f"건너뜀: {name} (메타데이터 없음)")
            continue
        meta = json.loads(meta_p.read_text())
        rows.append({
            "실험": meta["name"],
            "파라미터": meta["params"],
            "에폭": meta["actual_epochs"],
            "최적에폭": meta["best_epoch"],
            "val_acc": round(meta["best_val_acc"], 4),
            "val_loss": round(meta["best_val_loss"], 4),
            "격차": round(meta["final_gap"], 4),
            "시간(s)": round(meta["total_time_sec"], 1),
        })
        log = pd.read_csv(log_p)
        axes[0].plot(log["epoch"], log["val_loss"], linewidth=2, label=name)
        axes[1].plot(log["epoch"], log["val_accuracy"], linewidth=2, label=name)
        if "learning_rate" in log.columns:
            axes[2].plot(log["epoch"], log["learning_rate"], linewidth=2,
                         label=name, drawstyle="steps-post")

    axes[0].set_xlabel("epoch"); axes[0].set_ylabel("val loss")
    axes[0].set_title("Validation loss"); axes[0].legend(fontsize=8.5)
    axes[0].grid(alpha=0.3)

    axes[2].grid(alpha=0.3)
    fig.tight_layout(); plt.show()

    df = pd.DataFrame(rows).sort_values("val_acc", ascending=False)
    print(df.to_string(index=False))
    return df

if True:
    from tensorflow.keras import layers

    AUTOTUNE = tf.data.AUTOTUNE
    SPLIT = BASE / "datasets" / "my_dataset" / "split"
    IMG_SIZE, BATCH = (224, 224), 32

    train_ds = keras.utils.image_dataset_from_directory(
        SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
        shuffle=True, seed=42)
    val_ds = keras.utils.image_dataset_from_directory(

    CLASS_NAMES = train_ds.class_names
    N = len(CLASS_NAMES)
    train_ds = train_ds.cache().prefetch(AUTOTUNE)
    val_ds = val_ds.cache().prefetch(AUTOTUNE)
    test_ds = test_ds.cache().prefetch(AUTOTUNE)


    def build(dropout=0.4, lr=0.001):
        m = keras.Sequential([
            layers.Input(shape=(*IMG_SIZE, 3)),
            layers.RandomFlip("horizontal"),
            layers.RandomRotation(0.08),
            layers.RandomZoom(0.08),
            layers.Rescaling(1.0 / 255),
            layers.Conv2D(32, 3, padding="same", use_bias=False),
            layers.BatchNormalization(), layers.Activation("relu"),
            layers.MaxPooling2D(2), layers.Dropout(0.2),
            layers.Conv2D(64, 3, padding="same", use_bias=False),
            layers.BatchNormalization(), layers.Activation("relu"),
            layers.MaxPooling2D(2), layers.Dropout(0.2),
            layers.Conv2D(128, 3, padding="same", use_bias=False),
            layers.BatchNormalization(), layers.Activation("relu"),
            layers.MaxPooling2D(2), layers.Dropout(0.25),
            layers.Conv2D(128, 3, padding="same", use_bias=False),
            layers.BatchNormalization(), layers.Activation("relu"),
            layers.MaxPooling2D(2), layers.Dropout(0.25),
            layers.GlobalAveragePooling2D(), layers.Dropout(dropout),
            layers.Dense(64, activation="relu"),
            layers.Dense(1 if N == 2 else N,
                         activation="sigmoid" if N == 2 else "softmax"),
        ])
        m.compile(optimizer=keras.optimizers.Adam(learning_rate=lr),
                  loss="binary_crossentropy" if N == 2
                  else "sparse_categorical_crossentropy",
                  metrics=["accuracy"])
        return m


    # 3가지 설정 비교
    experiments = [
        ("mycnn_lr001_do4", dict(lr=0.001, dropout=0.4)),
        ("mycnn_lr0005_do4", dict(lr=0.0005, dropout=0.4)),
        ("mycnn_lr001_do5", dict(lr=0.001, dropout=0.5)),
    ]

    for name, cfg in experiments:
        tf.random.set_seed(42)
        model = build(**cfg)
        model, hist, meta = train_model(
            model, train_ds, val_ds, name=name, max_epochs=200,
            config=cfg, patience=20, lr_patience=8, print_every=20)
        plot_history(hist, name=name)
        _, acc = model.evaluate(test_ds, verbose=0)
        print(f"  테스트 정확도: {acc:.4f}\n")

    print("\n" + "=" * 90)
    print("실험 비교")
    print("=" * 90)
    compare_runs([n for n, _ in experiments])
```

| `patience` | **10~20**. 규제가 강하면 크게 |
| `monitor` | **`val_loss`** 기본. 불균형이면 `val_pr_auc` |
| `min_delta` | 미세한 개선을 무시. 느린 수렴에 유용 |
| **ModelCheckpoint** | 파일로 저장. **Colab 끊김 대비** |
| 확장자 | 전체 `.keras` / 가중치 `.weights.h5` |
| **ReduceLROnPlateau** | 정체 시 lr 감소. **patience는 ES의 1/2** |
| `factor` | **0.5** 권장 (0.9는 너무 약함) |
| CSVLogger | 학습 기록을 파일로. `append=True` 로 재개 |
| Step decay | 정해진 에폭마다 감소 |
| **Cosine** | 부드러운 감소. 최근 표준 |
| Warmup + Cosine | 초반 안정화. 큰 모델·배치 |
| **권장 전략** | **에폭 200 + EarlyStopping에 맡김** |
| 학습 재개 | `initial_epoch` + `save_best_only=False` |
| 커스텀 콜백 | `keras.callbacks.Callback` 상속 |
| 저장 위치 | **드라이브** (`/content/` 금지) |

**오늘 반드시 기억할 세 가지**
> ① **`restore_best_weights=True` 를 반드시 명시하세요.** 기본값은 `False` 입니다.
> ② **에폭을 크게 잡고 EarlyStopping에 맡기세요.** 설정마다 최적 에폭이 다릅니다.
> ③ **ReduceLROnPlateau의 patience는 EarlyStopping의 절반 이하**로 두세요.
