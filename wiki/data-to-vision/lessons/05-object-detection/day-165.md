## ③ 개념 설명

### 개발 서버 경고문 한 줄씩 해부

```
WARNING: This is a development server.
         Do not use it in a production deployment.
         Use a production WSGI server instead.
```

Flask 개발 서버(Werkzeug `run_simple`)는 **개발 편의를 위해 만들어졌고, 그 편의가 그대로 운영의 위험**입니다.

| # | 개발 서버의 특징 | 개발에서는 | 운영에서는 |
|---|---|---|---|
| 1 | **동시 처리 제한** | 나 혼자 쓰니까 문제 없음 | 5명만 붙어도 대기열 |
| 2 | **보안 미검증** | 127.0.0.1 이라 외부 접근 불가 | 공격 표면이 검증된 적 없음 |
| 3 | **성능 미최적화** | 요청이 초당 1건도 안 됨 | 커넥션·버퍼 관리가 단순 |
| 4 | **파일 변경 시 자동 재시작** | 저장하면 바로 반영 — 편함 | 처리 도중 서버가 재시작 |
| 5 | **예외 시 디버거 노출** | 브라우저에서 바로 디버깅 | **원격 코드 실행** |

#### 1 — 동시 처리 제한

```python
app.run()                       # ★ threaded=True 가 기본 (Flask 2.x)
app.run(threaded=False)         # 요청 1건씩 순서대로
app.run(processes=4)            #   Windows 에서 동작하지 않음
```

```
★ threaded=True 여도 "운영 가능" 을 뜻하지 않습니다

  · 요청마다 ★ 스레드를 새로 만듭니다 (스레드 풀 없음)
  · 동시 100건 → 스레드 100개 → 메모리·스케줄링 폭발
  · 큐잉·백프레셔·연결 수 제한이 전혀 없습니다
  · 느린 클라이언트 하나가 스레드를 계속 붙잡습니다
```

| 서버 | 동시성 모델 | 연결 수 제한 | 큐 |
|---|---|---|---|
| Flask 개발 서버 | 요청마다 스레드 생성 | 없음 | 없음 |
| **waitress** | **고정 스레드 풀** | `connection_limit=100` | 있음 |
| **gunicorn** | **프로세스 풀**(+스레드) | `backlog=2048` | 있음 |

#### 2 — 보안 미검증

```
Werkzeug 문서의 표현
  "not designed to be particularly efficient, stable, or secure"

★ HTTP 파서가 이상한 요청을 어떻게 처리하는지
  검증·감사를 받은 적이 없습니다.

  · 헤더 개수·길이 제한이 느슨
  · 슬로우로리스(Slowloris) 류 공격에 대한 대비 없음
  · 잘못된 청크 인코딩 처리
```

#### 4 — 자동 재시작이 운영에서 위험한 이유

```python
app.run(debug=True)         # ★ use_reloader=True 가 함께 켜집니다
```

> ⚠️ **운영에서는 리로더를 절대 켜지 않습니다.**
> WSGI 서버로 띄우면 리로더 자체가 존재하지 않습니다.

#### 5 — ★ `debug=True` + 외부 공개 = 원격 코드 실행

이것이 오늘 배우는 것 중 **가장 중요한 한 가지**입니다.

```
[정상 흐름]
  요청 → 예외 발생 → 500 페이지

[debug=True]
  요청 → 예외 발생 → ★ 대화형 트레이스백 페이지
                      · 소스코드 전체 표시
                      · 지역 변수 값 표시
                      · ★ 각 프레임 옆 콘솔 아이콘
                      · 콘솔에서 임의 파이썬 코드 실행
```

```
★ 위험도 요약

  debug=True  + host=127.0.0.1   →  나만 접근 가능 (개발 OK)
  debug=True  + host=0.0.0.0     →  ★   절대 금지
  debug=False + host=0.0.0.0     →  오늘 하는 것 (단, WSGI 서버로)
```

> ⚠️ **`debug=True` 로 `0.0.0.0` 에 바인딩하는 순간, 같은 네트워크의 누구든 내 컴퓨터를 조작할 수 있다고 가정해야 합니다.**
> 오늘 `ProdConfig.DEBUG` 를 **환경변수가 아니라 상수 `False`** 로 박는 이유입니다.

### WSGI 란 무엇인가

**WSGI**(Web Server Gateway Interface, PEP 3333) 는
**웹 서버와 파이썬 앱 사이의 약속** 입니다.

```
[휴대폰 브라우저]
      │  HTTP/1.1 요청 (TCP 소켓, 바이트)
      ▼
┌───────────────────────────────────────────────┐
│  WSGI 서버   (waitress · gunicorn)             │
│                                               │
│   · 소켓 accept · TCP 연결 관리                 │
│   · HTTP 파싱 (요청줄 · 헤더 · 본문)             │
│   · 스레드/프로세스 풀 · 큐 · 타임아웃           │
│   · keep-alive · 청크 인코딩                    │
└───────────────────────────────────────────────┘
      │  ★ WSGI 호출 — 여기가 경계
      │     application(environ, start_response)
      ▼
┌───────────────────────────────────────────────┐
│  Flask 앱  (우리 코드)                          │
│                                               │
│   · 라우팅 (@app.route)                        │
│   · 템플릿 렌더링                               │
│   · detector.predict_image()   ★ Day 161       │
│   · SQLite 기록                  Day 164       │
└───────────────────────────────────────────────┘
```

```
★ 경계의 의미

  왼쪽(WSGI 서버) 은 "HTTP 를 아는 쪽"
  오른쪽(앱) 은 "HTTP 를 몰라도 되는 쪽"

  덕분에
   · 앱을 고치지 않고 서버만 바꿀 수 있습니다
   · 같은 앱을 waitress · gunicorn · uWSGI 어디서든 띄웁니다
   · 테스트에서는 서버 없이 앱을 직접 호출합니다 (test_client)
```

### ★ WSGI 인터페이스를 직접 구현해 봅니다

**약속은 딱 이것 하나입니다.**

```
호출 가능한 객체 하나를 제공하라.
  · 인자 2개를 받는다 — environ(dict), start_response(callable)
  · start_response(status, headers) 를 호출한다
  · 바이트 조각을 순회할 수 있는 것(iterable)을 반환한다
```

```python
"""tools/minimal_wsgi.py — ★ 프레임워크 없이 WSGI 앱 만들기"""
import json


def application(environ, start_response):
    """★ 이것이 WSGI 앱의 전부입니다 (Flask 도 결국 이 모양)"""
    method = environ.get("REQUEST_METHOD", "GET")      # "GET"
    path = environ.get("PATH_INFO", "/")               # "/health"
    query = environ.get("QUERY_STRING", "")            # "a=1&b=2"
    host = environ.get("HTTP_HOST", "-")               #   HTTP_ 접두사
    addr = environ.get("REMOTE_ADDR", "-")

    if path == "/health":
        payload = {"ok": True, "server": environ["SERVER_SOFTWARE"]}
        body = json.dumps(payload).encode("utf-8")
        status = "200 OK"
        ctype = "application/json; charset=utf-8"
    elif path == "/":
        body = (f"{method} {path}?{query}\n"
                f"host={host} from={addr}\n").encode("utf-8")
        status = "200 OK"
        ctype = "text/plain; charset=utf-8"
    else:
        body = b"not found\n"
        status = "404 Not Found"
        ctype = "text/plain; charset=utf-8"

    headers = [("Content-Type", ctype),
               ("Content-Length", str(len(body)))]     #   바이트 길이
    start_response(status, headers)                    #   상태·헤더 전달
    return [body]                                      #   바이트의 리스트
```

**띄워 봅니다.**

```bash
pip install waitress
waitress-serve --host=127.0.0.1 --port=8080 tools.minimal_wsgi:application
```

**`environ` 에 무엇이 들어 있나**

| 키 | 예시 | 의미 |
|---|---|---|
| `REQUEST_METHOD` | `POST` | HTTP 메서드 |
| `PATH_INFO` | `/detect` | 경로 |
| `QUERY_STRING` | `page=2&type=person` | 쿼리 |
| `CONTENT_TYPE` | `multipart/form-data; ...` | 본문 형식 |
| `CONTENT_LENGTH` | `2418733` | 본문 크기 |
| `SERVER_NAME` / `SERVER_PORT` | `0.0.0.0` / `8000` | 서버 |
| `REMOTE_ADDR` | `192.168.0.42` | 클라이언트 IP |
| `HTTP_HOST` | `192.168.0.15:8000` | 헤더는 `HTTP_` 접두사 |
| `HTTP_USER_AGENT` | `Mozilla/5.0 (iPhone...)` | 휴대폰 판별 |
| `HTTP_X_FORWARDED_FOR` | `203.0.113.7` | 프록시 경유 시 원래 IP |
| `wsgi.input` | 파일 객체 | 요청 본문 스트림 |
| `wsgi.url_scheme` | `http` | http / https |

### ★ WSGI 미들웨어 — 앱을 감싸는 함수

WSGI 앱은 "함수" 이므로 **다른 함수로 감쌀 수 있습니다.**
이것이 미들웨어입니다. 오늘 액세스 로그를 이 방식으로 만듭니다.

```python
"""web/middleware.py — ★ WSGI 미들웨어"""
import logging
import time

logger = logging.getLogger("access")


class AccessLog:
    """모든 요청을 한 줄로 기록한다 — Flask 라우트 코드는 그대로 둔 채."""

    def __init__(self, app, slow_ms=1000, skip=("/api/health",)):
        self.app, self.slow_ms, self.skip = app, slow_ms, set(skip)

    def __call__(self, environ, start_response):
        started = time.perf_counter()
        holder = {}

        def _start(status, headers, exc_info=None):
            holder["status"] = status              # ★ 상태코드 가로채기
            return start_response(status, headers, exc_info)

        result = self.app(environ, _start)
        path = environ.get("PATH_INFO", "/")
        if path in self.skip:                      # 헬스체크는 로그에서 제외
            return result

        elapsed = (time.perf_counter() - started) * 1000
        ip = (environ.get("HTTP_X_FORWARDED_FOR", "").split(",")[0].strip()
              or environ.get("REMOTE_ADDR", "-"))
        line = "%s %-5s %-28s %s %6.0fms" % (
            ip, environ.get("REQUEST_METHOD", "-"), path[:28],
            holder.get("status", "???").split()[0], elapsed)
        if elapsed >= self.slow_ms:
            logger.warning("%s    SLOW", line)     # 느린 요청만 경고로
        else:
            logger.info(line)
        return result
```

> ⚠️ **`app.wsgi_app` 을 감싸야 합니다.**
> `app = AccessLog(app)` 처럼 Flask 객체 자체를 바꾸면 `app.test_client()`·
> `app.config` 같은 Flask 기능에 접근할 수 없게 됩니다.
> 관례는 **`app.wsgi_app = Middleware(app.wsgi_app)`** 입니다.

### WSGI 서버 비교

| 서버 | OS | 동시성 | 설치 | 우리 프로젝트 |
|---|---|---|---|---|
| **waitress** | **Windows · Linux 모두** | 스레드 풀 | `pip install waitress` | **실습 기본** |
| **gunicorn** | Linux · macOS (Windows 불가) | 프로세스 + 스레드 | `pip install gunicorn` | 파이·서버 |
| uWSGI | Linux | 프로세스 | 빌드 필요 | 설정이 방대 |
| mod_wsgi | Apache | Apache 통합 | 복잡 | 사용 안 함 |
| Hypercorn / Uvicorn | 전부 | async (ASGI) | pip | Flask 는 WSGI |

```python
"""web/log_setup.py — 로깅 초기화 (waitress · gunicorn 공용)"""
import logging
import logging.handlers
from pathlib import Path

FMT = "%(asctime)s %(levelname)-7s [%(name)s] %(message)s"
DATEFMT = "%Y-%m-%d %H:%M:%S"


def _rotating(path, fmt):          # 10MB × 5개 (Day 164 와 동일 정책)
    h = logging.handlers.RotatingFileHandler(
        path, maxBytes=10 * 1024 * 1024, backupCount=5, encoding="utf-8")
    h.setFormatter(fmt)
    return h


def setup_logging(log_dir: Path, level="INFO"):
    log_dir = Path(log_dir)
    log_dir.mkdir(parents=True, exist_ok=True)
    fmt = logging.Formatter(FMT, datefmt=DATEFMT)
    console = logging.StreamHandler()
    console.setFormatter(fmt)

    root = logging.getLogger()
    root.setLevel(getattr(logging, str(level).upper(), logging.INFO))
    for h in list(root.handlers):
        root.removeHandler(h)          # ★ 중복 핸들러 방지 (재적재 사고)
    root.addHandler(console)
    root.addHandler(_rotating(log_dir / "app.log", fmt))

    access = logging.getLogger("access")   # 액세스 로그는 파일 분리
    access.propagate = False
    access.setLevel(logging.INFO)
    access.addHandler(_rotating(
        log_dir / "access.log",
        logging.Formatter("%(asctime)s %(message)s", datefmt=DATEFMT)))
    access.addHandler(console)

    logging.getLogger("waitress.queue").setLevel(logging.WARNING)
    return root
```

> 남습니다. 이 메시지가 보이면 **threads 가 부족하다는 신호**입니다.

**공식 문서의 권장**

```

```
★ 이 공식이 가정하는 것

  "요청의 대부분 시간은 기다리는 시간이다"
    · DB 응답 대기
    · 외부 API 대기
    · 디스크 I/O

  → 워커가 놀고 있으므로 코어보다 많이 띄워도 됨
```

**★ 우리 앱은 정반대입니다.**

```
요청 1건의 시간 구성 ([Day 161](day-161.md) 측정)

  업로드 수신·검증     18 ms
  ★ 추론              146 ms   ← ★ CPU 100%
  박스 그리기·인코딩    31 ms   ← CPU

```

공식대로 하면 (4코어 8스레드 노트북)

  workers = (2 × 8) + 1 = ★ 17

### ★ `--preload` 와 모델 로딩

여기가 [Day 161](day-161.md) 과 직접 연결되는 지점입니다.

```

    ├─ 워커1 시작 → ★ import wsgi → 모델 로드 (1.2초, 512MB)
    ├─ 워커2 시작 →   import wsgi → 모델 로드 (1.2초, 512MB)
    └─ 워커3 시작 →   import wsgi → 모델 로드 (1.2초, 512MB)

**★ preload 를 쓸 때의 함정 3가지**

  → SQLite 커넥션은 반드시 워커 안에서 열어야 합니다

### ★ 스트리밍과 워커의 충돌 ([Day 163](day-163.md))

```
MJPEG 스트림의 정체

  GET /video_feed
  → Response(generator, mimetype="multipart/x-mixed-replace")
  → ★ 응답이 영원히 끝나지 않습니다

  즉, 요청 1건이 워커(또는 스레드) 1개를 계속 붙잡습니다
```

**해결책 4가지**

| # | 방법 | 설정 | 장점 | 단점 |
|---|---|---|---|---|
| 1 | **스레드 워커** | `--worker-class gthread --threads 4` | 간단 | 스레드도 유한 |
| 2 | **동시 스트림 제한** | 세마포어 + 429 응답 | 확실 | 사용자 거절 |
| 3 | **스트림 전용 포트** | 8001 에 별도 프로세스 | 완전 격리 | 주소 2개 |
| 4 | 스냅샷 폴링으로 대체 | 2초마다 `/snapshot.jpg` | 연결 점유 없음 | 실시간성 저하 |

```python
"""web/stream_guard.py — ★ 동시 스트림 수 제한 (해결책 2)"""
import logging
import threading

logger = logging.getLogger(__name__)


class StreamLimiter:
    """스트림 1개 = 워커 스레드 1개를 무한 점유하므로 수를 제한한다."""

    def __init__(self, max_streams=2):
        self.max = max_streams
        self._sem = threading.BoundedSemaphore(max_streams)
        self._lock = threading.Lock()
        self.active = 0

    def try_acquire(self) -> bool:
        got = self._sem.acquire(blocking=False)      # ★ 즉시 실패 (대기 없음)
        with self._lock:
            self.active += 1 if got else 0
        logger.info("스트림 %s (%d/%d)",
                    "시작" if got else "거절", self.active, self.max)
        return got

    def release(self):
        with self._lock:
            self.active = max(0, self.active - 1)
        try:
            self._sem.release()
        except ValueError:
            pass                                     # 이중 release 방어
```

> ⚠️ **`finally` 에서 반납하지 않으면 슬롯이 영구히 새어 나갑니다.**
> 브라우저 탭을 닫으면 제너레이터에 `GeneratorExit` 가 던져지는데,
> 이때도 `finally` 는 실행됩니다.

```python
"""web/tools/net_info.py — ★ 접속 주소를 자동으로 알려 준다"""
import socket
import sys

BOGUS = [("127.", "루프백 — 이 컴퓨터에서만"),
         ("169.254.", "APIPA — DHCP 실패"),
         ("172.17.", "Docker 브리지 — 접속 불가"),
         ("172.28.", "WSL 가상 스위치 — 접속 불가"),
         ("192.168.56.", "VirtualBox Host-Only — 접속 불가")]


def primary_ip() -> str:
    """외부로 나가는 경로의 IP 를 구한다 (패킷은 실제로 안 보냄)"""
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(("8.8.8.8", 80))       # UDP 라 실제 통신은 없음
        return s.getsockname()[0]
    except OSError:
        return "127.0.0.1"
    finally:
        s.close()


def classify(ip: str) -> str:
    for prefix, msg in BOGUS:
        if ip.startswith(prefix):
            return msg
    return ("사설망 — 같은 Wi-Fi 기기에서 접속 가능"
            if ip.startswith(("192.168.", "10.", "172.16.")) else "공인 IP")


def port_open(port: int, host="127.0.0.1") -> bool:
    s = socket.socket()
    s.settimeout(0.4)
    try:
        return s.connect_ex((host, port)) == 0
    finally:
        s.close()


def main(port=8000):
    ip = primary_ip()
    print(f"  {ip:<16} {classify(ip)}")
    print(f"  포트 {port} : "
          f"{'열려 있음' if port_open(port) else '닫힘 (서버 미실행?)'}")
    print(f"\n  ★ 휴대폰 주소창에 입력:  http://{ip}:{port}")
    print("  같은 Wi-Fi 에 연결되어 있어야 합니다 (LTE/5G ✗)")


if __name__ == "__main__":
    main(int(sys.argv[1]) if len(sys.argv) > 1 else 8000)
```

```python
"""web/config.py — ★ 환경변수 기반 설정 (Day 160 확장)"""
from __future__ import annotations

import os
import secrets
from pathlib import Path

from dotenv import load_dotenv

BASE_DIR = Path(__file__).resolve().parent          # web/
PROJECT_DIR = BASE_DIR.parent                       # cctv_project/

for candidate in (BASE_DIR / ".env", PROJECT_DIR / ".env"):
    if candidate.exists():
        load_dotenv(candidate, override=False)      # ★ web/ → 루트 순으로 탐색
        break


def env_str(key, default=""):
    return os.environ.get(key, default).strip()


def _cast(key, default, fn):
    try:
        return fn(os.environ.get(key, default))
    except (TypeError, ValueError):
        return default


def env_int(key, default):
    return _cast(key, default, int)


def env_float(key, default):
    return _cast(key, default, float)


def env_bool(key, default=False):
    raw = os.environ.get(key)
    return default if raw is None else raw.strip().lower() in (
        "1", "true", "yes", "on")


def env_path(key, default) -> Path:
    """★ 상대 경로는 프로젝트 루트 기준으로 절대화"""
    p = Path(os.environ.get(key, default))
    return p if p.is_absolute() else (PROJECT_DIR / p).resolve()


class Config:
    """공통 설정 — 값은 전부 환경변수에서 온다"""

    SECRET_KEY = env_str("SECRET_KEY")
    MAX_CONTENT_LENGTH = env_int("MAX_UPLOAD_MB", 16) * 1024 * 1024
    BASE_DIR, PROJECT_DIR = BASE_DIR, PROJECT_DIR

    MODEL_PATH = env_path("MODEL_PATH", "models/best.pt")
    DB_PATH = env_path("DB_PATH", "web/instance/cctv.db")
    UPLOAD_DIR = env_path("UPLOAD_DIR", "web/static/uploads")
    RESULT_DIR = env_path("RESULT_DIR", "web/static/results")
    LOG_DIR = env_path("LOG_DIR", "web/logs")

    CONF_THRESHOLD = env_float("CONF_THRESHOLD", 0.45)
    TORCH_THREADS = env_int("TORCH_THREADS", 2)
    HOST, PORT = env_str("HOST", "127.0.0.1"), env_int("PORT", 8000)
    THREADS, WORKERS = env_int("THREADS", 6), env_int("WORKERS", 2)
    ENABLE_STREAM = env_bool("ENABLE_STREAM", True)
    MAX_STREAMS = env_int("MAX_STREAMS", 2)
    LOG_LEVEL = env_str("LOG_LEVEL", "INFO")
    SLOW_REQUEST_MS = env_int("SLOW_REQUEST_MS", 1000)
    SEND_FILE_MAX_AGE_DEFAULT = 3600      # 정적 파일 캐시 1시간

    @classmethod
    def validate(cls) -> list[str]:
        """★ 시작 전에 설정을 검증한다 — 실패는 즉시 알려야 한다"""
        errors = []
        if not cls.SECRET_KEY:
            errors.append("SECRET_KEY 가 비어 있습니다 (.env 확인)")
        elif len(cls.SECRET_KEY) < 32:
            errors.append("SECRET_KEY 가 너무 짧습니다 (64자 권장)")
        elif cls.SECRET_KEY in ("dev", "secret", "changeme"):
            errors.append("SECRET_KEY 가 기본값입니다 — 반드시 교체")
        if not cls.MODEL_PATH.exists():
            errors.append(f"모델 파일이 없습니다: {cls.MODEL_PATH}")
        if cls.MAX_STREAMS >= cls.THREADS:
            errors.append(
                f"MAX_STREAMS({cls.MAX_STREAMS}) 가 "
                f"THREADS({cls.THREADS}) 이상입니다 — 사이트가 멈춥니다")
        return errors


class DevConfig(Config):
    DEBUG = True
    SECRET_KEY = Config.SECRET_KEY or secrets.token_hex(32)
    SEND_FILE_MAX_AGE_DEFAULT = 0


class ProdConfig(Config):
    DEBUG = False                              # ★ 절대 True 금지
    SESSION_COOKIE_HTTPONLY = True
    SESSION_COOKIE_SAMESITE = "Lax"


CONFIGS = {"development": DevConfig, "production": ProdConfig}


def get_config(name: str | None = None):
    return CONFIGS.get(name or env_str("FLASK_ENV", "production"), ProdConfig)
```

> ⚠️ **`DEBUG` 를 환경변수로 켤 수 있게 만들지 마세요.**
> `ProdConfig.DEBUG = env_bool("FLASK_DEBUG")` 로 두면
> 누군가 `.env` 에 `FLASK_DEBUG=1` 을 넣는 순간 **원격 코드 실행이 열립니다.**
> **운영 설정에서는 `False` 를 상수로 박습니다.**

### 정적 파일 서빙

```
운영에서 Flask 가 static 을 직접 서빙하면 안 된다 — 라는 말의 근거

  ① 파이썬 프로세스가 ★ 파일 전송 시간 동안 워커를 점유
       2MB 이미지 × 느린 휴대폰 = 3초 → 워커 1개가 3초 묶임
  ② nginx 는 sendfile() 로 커널이 직접 전송 (파이썬을 안 거침)
  ③ gzip/brotli 압축 · Range 요청 · 캐시 헤더를 nginx 가 더 잘함
  ④ 처리량 차이가 큼
```

**★ 그런데 우리 규모에서는 괜찮습니다.**

```
우리 시스템의 실제 부하

  동시 사용자        최대 5명 (팀 + 강사)
  페이지당 정적 파일  CSS 1 · JS 1 · 이미지 2 = 4개
  이미지 크기        결과 JPEG 평균 180KB
  필요 처리량        5명 × 4개 / 2초 = ★ 10 req/s

### HTTPS — 왜 필요하고, 왜 오늘은 안 하는가

```
HTTP 로 주고받는 것들 — 전부 평문입니다

  · 업로드하는 사진 (★ 얼굴이 담긴 이미지)
  · 세션 쿠키 (★ 훔치면 그 사람 행세 가능)
  · 검출 결과 JSON

  같은 Wi-Fi 에 있는 사람이 패킷을 보면 그대로 읽힙니다
```

**자체 서명 인증서(self-signed)의 한계**

| 문제 | 내용 |
|---|---|
| 브라우저 경고 | "안전하지 않음" 전체 화면 경고 |
| 휴대폰 | 인증서를 **신뢰 저장소에 수동 설치**해야 함 (iOS 는 2단계) |
| **습관** | 사용자가 **경고를 무시하는 훈련**을 받게 됨 — 이게 더 위험 |
| IP 기반 | IP 로 발급한 인증서는 IP 가 바뀌면 무효 |
| Let's Encrypt | **공인 도메인이 필요** — 사설 IP 에는 발급 불가 |

```
★ 우리 결정

  · 로컬망 전용이므로 ★ HTTP 유지
  · 대신 비밀번호·로그인 기능을 만들지 않습니다
    (평문으로 오갈 비밀 자체를 만들지 않는다)
  · 인터넷에 공개하는 순간 HTTPS 가 필수 조건이 됩니다
  · 필요해지면 리버스 프록시(Caddy·nginx) + 도메인 + Let's Encrypt
    → 자체 서명이 아니라 정식 인증서로
```

> ⚠️ **HTTPS 가 아니면 못 쓰는 브라우저 기능이 있습니다.**
> `navigator.mediaDevices.getUserMedia`(휴대폰 카메라 직접 촬영)는
> **`localhost` 를 제외하면 HTTPS 에서만 동작**합니다.
> 그래서 우리는 **`<input type="file" accept="image/*" capture="environment">`** 를 씁니다.
> 이 방식은 **HTTP 에서도 카메라 앱을 띄웁니다.**

```html

"""web/wsgi.py — ★ WSGI 진입점

  waitress-serve  wsgi:app
  gunicorn        wsgi:app
  python run_waitress.py

  ★ 이 파일은 "앱 객체 하나" 를 만드는 것이 전부입니다.
    서버 실행 코드를 여기에 넣지 마세요.
"""
from __future__ import annotations

import logging
import sys
import time

#   web/ 를 import 경로에 넣는다 (어느 디렉터리에서 실행해도 동작)
sys.path.insert(0, str(__import__("pathlib").Path(__file__).resolve().parent))

from app import create_app                 # Day 160 애플리케이션 팩토리
from config import get_config
from log_setup import setup_logging
from middleware import AccessLog

logger = logging.getLogger(__name__)

Config = get_config()                      # FLASK_ENV 에 따라 결정

# ── ① 로깅 먼저 (그래야 이후 오류가 기록됨) ──
setup_logging(Config.LOG_DIR, Config.LOG_LEVEL)

# ── ②   설정 검증 — 틀리면 시작하지 않는다 ──
errors = Config.validate()
if errors:
    for e in errors:
        logger.critical("설정 오류: %s", e)
    raise SystemExit(                      #   조용히 뜨는 것보다 낫다
        "  설정 오류로 시작할 수 없습니다:\n  - " + "\n  - ".join(errors))

# ── ③ 앱 생성 ──
app = create_app(Config)

# ── ④   모델 로드 + 워밍업 (Day 161) ──
def _warmup():
    """  첫 사용자가 2.4초를 기다리지 않도록 미리 태운다"""
    import numpy as np
    from detector import get_detector      # src/detector.py (Day 152·155)

    try:
        import torch
        torch.set_num_threads(Config.TORCH_THREADS)   #   과잉 구독 방지
    except ImportError:
        pass

    t0 = time.perf_counter()
    det = get_detector(profile=Config.DETECTOR_PROFILE,
                       weights=str(Config.MODEL_PATH))
    load_ms = (time.perf_counter() - t0) * 1000

    dummy = np.zeros((640, 640, 3), dtype="uint8")
    t1 = time.perf_counter()
    det.predict_image(dummy, conf=Config.CONF_THRESHOLD)
    warm_ms = (time.perf_counter() - t1) * 1000

    t2 = time.perf_counter()
    det.predict_image(dummy, conf=Config.CONF_THRESHOLD)
    ready_ms = (time.perf_counter() - t2) * 1000

    logger.info("모델 준비 완료 — 로드 %.0fms · 첫추론 %.0fms · 이후 %.0fms",
                load_ms, warm_ms, ready_ms)
    return det


try:
    _warmup()
except Exception:
    logger.exception("  모델 워밍업 실패 — 검출 요청은 500 을 반환합니다")

# ── ⑤   액세스 로그 미들웨어 ──
app.wsgi_app = AccessLog(app.wsgi_app, slow_ms=Config.SLOW_REQUEST_MS)

logger.info("WSGI 앱 준비 완료 (env=%s debug=%s)",
            Config.__name__, app.debug)

#   개발 서버 실행 코드는 여기에 두지 않습니다.
#   실수로 waitress 아래에서 app.run() 이 돌아가는 사고를 막습니다.
```

### Step 2. waitress 로 실행 + 개발 서버 비교

```python
"""web/run_waitress.py — ★ 운영 실행 스크립트 (Windows 기본)"""
import logging

from waitress import serve

from config import get_config
from tools.net_info import primary_ip
from wsgi import app                       # ★ 여기서 검증·워밍업이 끝난다

logger = logging.getLogger("run")
Config = get_config()


def banner(host, port, threads):
    line = "=" * 60
    print(f"{line}\n  CCTV 검출 웹 서버 (waitress)\n{line}")
    print(f"  바인딩       : {host}:{port}")
    print(f"  스레드       : {threads}")
    print(f"  모델         : {Config.MODEL_PATH.name}")
    print(f"  스트리밍      : {'ON' if Config.ENABLE_STREAM else 'OFF'} "
          f"(최대 {Config.MAX_STREAMS})")
    print("-" * 60)
    print(f"  ★ 이 컴퓨터   : http://127.0.0.1:{port}")
    if host == "0.0.0.0":
        print(f"  ★ 다른 기기   : http://{primary_ip()}:{port}")
        print("  ★ 휴대폰은 같은 Wi-Fi 에 연결되어 있어야 합니다")
    else:
        print("  외부 접속 불가 — HOST=0.0.0.0 으로 바꾸세요")
    print(line)


if __name__ == "__main__":
    host, port, threads = Config.HOST, Config.PORT, Config.THREADS
    banner(host, port, threads)
    logger.info("waitress 시작 %s:%s threads=%s", host, port, threads)
    serve(app, host=host, port=port, threads=threads,
          connection_limit=100,            # ★ 동시 연결 상한
          channel_timeout=300,             # 스트리밍을 고려해 늘림
          ident="cctv")                    # Server 헤더
```

### Step 3. gunicorn 설정 파일 + preload 메모리 비교

```python
"""web/gunicorn.conf.py — ★ gunicorn 설정 (Linux · 라즈베리파이)

  실행:  gunicorn -c gunicorn.conf.py wsgi:app
"""
import multiprocessing
import os
from pathlib import Path

BASE = Path(__file__).resolve().parent
LOG_DIR = BASE / os.environ.get("LOG_DIR", "logs")
LOG_DIR.mkdir(parents=True, exist_ok=True)

# ── 바인딩 ──
bind = f"{os.environ.get('HOST', '0.0.0.0')}:{os.environ.get('PORT', 8000)}"
backlog = 2048

# ── ★ 워커 ──
workers = int(os.environ.get("WORKERS", 2))          #   공식(2n+1) 아님
worker_class = "gthread"                             #   스트리밍 때문에 필수
threads = int(os.environ.get("GTHREADS", 4))
worker_connections = 100

# ──   preload — 모델을 1회만 로드해 fork 로 공유 ──
preload_app = True                                   #   CPU 추론이라 가능
#   GPU(CUDA)를 쓴다면   False 로 두고 post_fork 에서 로드해야 합니다

# ── 타임아웃 ──
timeout = int(os.environ.get("GUNICORN_TIMEOUT", 120))   #   기본 30 은 너무 짧다
graceful_timeout = 30
keepalive = 5

# ──   워커 재활용 (메모리 누수 방어) ──
max_requests = 500
max_requests_jitter = 50                             #   동시에 재시작하지 않게

# ── 로그 ──
accesslog = str(LOG_DIR / "gunicorn-access.log")
errorlog = str(LOG_DIR / "gunicorn-error.log")
loglevel = os.environ.get("LOG_LEVEL", "info").lower()
capture_output = True                                #   print 도 로그로
access_log_format = ('%(h)s %(m)s %(U)s%(q)s %(s)s '
                     '%(b)s %(M)sms "%(a)s"')

# ── 기타 ──
proc_name = "cctv-web"
worker_tmp_dir = "/dev/shm"        #   하트비트 파일을 램디스크에 (SD카드 보호)
limit_request_line = 4094
limit_request_field_size = 8190


# ───────────────────────── 훅 ─────────────────────────

def on_starting(server):
    server.log.info("  gunicorn 시작 — workers=%s threads=%s preload=%s",
                    workers, threads, preload_app)


def post_fork(server, worker):
    """  fork 직후 — 워커마다 따로 가져야 하는 것을 여기서 만든다"""
    import gc
    gc.freeze()                    #   COW 페이지 복사를 줄인다

    #   SQLite 커넥션은 절대 부모에서 물려받으면 안 됩니다
    try:
        from db import reset_connection
        reset_connection()
    except ImportError:
        pass

    try:
        import torch
        torch.set_num_threads(int(os.environ.get("TORCH_THREADS", 2)))
    except ImportError:
        pass

    server.log.info("워커 %s 준비 완료", worker.pid)


def worker_int(worker):
    worker.log.info("워커 %s 인터럽트", worker.pid)


def worker_abort(worker):
    """  타임아웃으로 죽을 때 스택을 남긴다 — 원인 추적용"""
    import threading
    import traceback
    worker.log.error("  워커 %s 강제 종료 — 스택 덤프", worker.pid)
    for tid, frame in sys._current_frames().items():
        worker.log.error("--- thread %s ---\n%s", tid,
                         "".join(traceback.format_stack(frame)))


def child_exit(server, worker):
    server.log.info("워커 %s 종료", worker.pid)


import sys  # worker_abort 에서 사용
```

# web/tools/firewall.ps1 — ★ 관리자 PowerShell 에서 실행
param([int]$Port = 8000, [string]$Name = "CCTV Web", [switch]$Remove)

$ruleName = "$Name $Port"

if ($Remove) {
    Get-NetFirewallRule -DisplayName $ruleName -ErrorAction SilentlyContinue |
        Remove-NetFirewallRule
    Write-Host "규칙 삭제: $ruleName"
    exit
}

foreach ($p in Get-NetConnectionProfile) {          # ★ 프로필 먼저 확인
    Write-Host ("  {0,-22} {1}" -f $p.InterfaceAlias, $p.NetworkCategory)
    if ($p.NetworkCategory -eq "Public") {
        Write-Warning "$($p.InterfaceAlias) 가 Public 입니다. Private 규칙이 무시됩니다."
    }
}

if (Get-NetFirewallRule -DisplayName $ruleName -ErrorAction SilentlyContinue) {
    Write-Host "이미 존재합니다: $ruleName"
} else {
    New-NetFirewallRule -DisplayName $ruleName `
        -Direction Inbound -Protocol TCP -LocalPort $Port `
        -Action Allow -Profile Private | Out-Null
    Write-Host "규칙 추가 완료: $ruleName (TCP/$Port, Private)"
}

### Step 8. 배포 체크리스트 자동 점검

```python
"""web/tools/preflight.py — ★ 배포 전 자동 점검

  python tools/preflight.py
"""
from __future__ import annotations

import socket
import subprocess
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from config import get_config                       # noqa: E402

Config = get_config()
RESULTS: list[tuple[str, str, bool, str]] = []


def check(group, name, ok, msg=""):
    RESULTS.append((group, name, bool(ok), msg))


def _sh(args) -> str:
    try:
        return subprocess.run(args, capture_output=True, text=True,
                              timeout=10).stdout
    except (OSError, subprocess.TimeoutExpired):
        return ""


def _bound_addr(port) -> str:
    for line in _sh(["netstat", "-ano"]).splitlines():
        if f":{port} " in line and "LISTENING" in line.upper():
            return line.split()[1].rsplit(":", 1)[0]
    return ""


def _port_open(port) -> bool:
    s = socket.socket(); s.settimeout(0.5)
    try:
        return s.connect_ex(("127.0.0.1", port)) == 0
    finally:
        s.close()


def main():
    env = Config.BASE_DIR / ".env"

    check("서버", "운영 설정 사용", Config.__name__ == "ProdConfig",
          f"현재 {Config.__name__}")
    check("서버", "DEBUG 꺼짐", getattr(Config, "DEBUG", True) is False,
          "★ DEBUG=True 는 원격 코드 실행 위험")
    check("서버", "스트림 제한 적정", Config.MAX_STREAMS < Config.THREADS,
          f"MAX_STREAMS={Config.MAX_STREAMS} < THREADS={Config.THREADS}")
    check("네트워크", "0.0.0.0 바인딩", _bound_addr(Config.PORT) == "0.0.0.0",
          f"현재 {_bound_addr(Config.PORT) or '미실행'}")
    check("네트워크", "포트 응답", _port_open(Config.PORT),
          f"127.0.0.1:{Config.PORT}")
    check("설정", "SECRET_KEY 길이", len(Config.SECRET_KEY) >= 32,
          f"{len(Config.SECRET_KEY)}자")
    check("설정", ".env / .env.example 존재",
          env.exists() and (Config.BASE_DIR / ".env.example").exists())
    check("설정", "★ .env 가 Git 추적 안 됨",
          _sh(["git", "ls-files", str(env)]).strip() == "",
          "추적 중이면 SECRET_KEY 재발급")
    check("파일", "모델 존재", Config.MODEL_PATH.exists(),
          str(Config.MODEL_PATH))
    check("안정성", "설정 검증 통과", not Config.validate(),
          "; ".join(Config.validate()))
    check("안정성", "액세스 로그 생성",
          (Config.LOG_DIR / "access.log").exists())

    group = None
    passed = 0
    for g, name, ok, msg in RESULTS:
        if g != group:
            print(("-" if group else "=") * 66 + f"\n [{g}]")
            group = g
        print(f"  {'✓' if ok else '✗'} {name:<24} {msg}")
        passed += ok
    print("=" * 66)
    print(f"  ★ {passed}/{len(RESULTS)} 통과")
    if passed < len(RESULTS):
        print("  ✗ 항목을 해결한 뒤 배포하세요")
        sys.exit(1)                        # ★ CI·배포 스크립트가 막을 수 있게
    print("  배포 준비 완료")


if __name__ == "__main__":
    main()
```

### 해결 ① `post_fork` 에서 초기화

# gunicorn.conf.py
def post_fork(server, worker):
    import gc
    gc.freeze()                       # ★ COW 페이지 복사 감소
    from db import reset_connection
    reset_connection()                # 워커마다 새 커넥션
    server.log.info("워커 %s 준비 완료", worker.pid)

### 해결 ② ★ 요청마다·스레드마다 커넥션 (권장)

```python
"""web/db.py — ★ 요청마다 새 커넥션 (Flask g 에 보관)"""
import sqlite3

from flask import current_app, g


def get_db():
    if "db" not in g:
        g.db = sqlite3.connect(current_app.config["DB_PATH"], timeout=5.0)
        g.db.row_factory = sqlite3.Row
        g.db.execute("PRAGMA journal_mode=WAL")  # ★ 읽기-쓰기 동시성
        g.db.execute("PRAGMA busy_timeout=5000")
    return g.db


def close_db(exc=None):
    db = g.pop("db", None)
    if db is not None:
        db.close()


def reset_connection():
    """fork 직후 호출 — 물려받은 커넥션을 버린다"""
    close_db()


def init_app(app):
    app.teardown_appcontext(close_db)            # 요청 끝나면 자동 close
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 개발 서버 | **동시성 · 보안 · 성능 · 리로더 · 디버거** 5가지가 운영에 부적합 |
| `debug=True` + `0.0.0.0` | **원격 코드 실행** — 절대 금지 |
| WSGI | 서버(HTTP)와 앱(로직)의 **경계** |
| WSGI 앱 규약 | `application(environ, start_response)` → **바이트 iterable** |
| 미들웨어 | `app.wsgi_app = Mw(app.wsgi_app)` |
| **waitress** | Windows 기본 · **스레드 풀** · `threads=6` |
| **gunicorn** | Linux · **프로세스 풀** · Windows 불가(`fcntl`) |
| 워커 수 | **`(2n+1)` 공식 아님** — min(CPU 상한, 메모리 상한) |
| 우리 값 | **workers=2 · gthread · threads=4** |
| `--preload` | 모델 1회 로드 → fork 공유 · **2,048MB → 748MB** |
| preload 함정 | **DB 커넥션은 `post_fork`** · CUDA 는 fork 불가 |
| `--timeout` | 기본 30초 → **120** · 스트리밍은 **gthread** |
| 스트리밍 | 요청 1건 = 슬롯 1개 **무한 점유** → 제한 필수 |
| `0.0.0.0` | "주소" 가 아니라 **"모든 인터페이스"** |
| 방화벽 | **인바운드 규칙 + 프로필(Private)** 둘 다 |
| 휴대폰 진단 | **Wi-Fi → ping → 바인딩 → 자기 IP → 방화벽** |
| `.env` | 비밀값은 코드 밖 · **`.gitignore`** · 커밋했으면 **키 재발급** |
| `SECRET_KEY` | 고정값 필수 — 워커마다 다르면 **플래시가 사라짐** |
| 정적 파일 | 우리 규모(10 req/s)엔 **Flask 로 충분** · 캐시 헤더는 필수 |
| ngrok · 클라우드 | **Day 154 결정(로컬망 전용)과 충돌** · 카메라는 여기 있다 |

**오늘 반드시 기억할 세 가지**

> ① **`debug=True` 로 `0.0.0.0` 에 띄우지 마세요.** 그건 배포가 아니라 내 컴퓨터를 남에게 내주는 일입니다.
> ② **워커 수는 공식이 아니라 계산입니다.** 모델이 메모리를 먹으므로 `min(CPU 상한, 메모리 상한)` 이고, 우리 노트북에서는 **2** 입니다.
> ③ **`0.0.0.0` · 방화벽 · 같은 Wi-Fi — 셋 다 통과해야 접속됩니다.** 하나만 빠져도 증상은 똑같이 "연결할 수 없음" 입니다.

**오늘의 산출물**

**과제 — 배포된 웹 앱**

```
1. wsgi.py 를 만들고 설정을 .env 로 분리합니다.
     SECRET_KEY 생성 · Config.validate() 로 시작 전 검증
     ★ .env 를 .gitignore 에 추가하고 .env.example 커밋
2. waitress 로 띄우고 개발 서버와 비교표를 만듭니다.
     동시 1 / 5 / 10 · 평균 · p95 · 실패 건수 · req/s
3. gunicorn 설정 파일을 만들고 preload 유무 메모리를 측정합니다.
     (WSL 또는 라즈베리파이) workers 1 / 2 / 4 · USS 합계로 비교
4. host=0.0.0.0 + 방화벽 인바운드 규칙을 추가합니다.
     netstat 으로 바인딩 확인 · 네트워크 프로필이 Private 인지 확인
5. ★ 휴대폰으로 접속해 사진을 올리고 검출 결과를 확인합니다.
     화면 캡처 3장 · 접속이 안 됐다면 진단 과정을 기록
6. 부하 테스트를 실행하고 결과표를 제출합니다 (목표 3초 대비 여유율).
7. README.md 를 작성하고 ★ 다른 조에게 주고 그대로 띄우게 해 봅니다.
8. 배포 체크리스트 20항목을 점검합니다 (preflight.py 결과 첨부).
```
