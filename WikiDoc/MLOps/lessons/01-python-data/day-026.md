## ③ 개념 설명

### 파일 크기 ≠ 메모리 사용량

**CSV 1GB를 읽으면 메모리는 얼마나 쓸까요?**

```
1GB CSV  →  Pandas DataFrame  →  2~10GB 메모리
```

**보통 2~5배**입니다. 이유는:

| 원인 | 설명 |
|---|---|
| 문자열 오버헤드 | CSV의 `"강남구"` 9바이트 → 파이썬 str 객체 ~58바이트 |
| 기본 타입이 큼 | `1` 은 CSV에서 1바이트, 메모리에서 `int64` 8바이트 |
| 인덱스 | 행마다 8바이트 추가 |
| 읽는 중 임시 버퍼 | 파싱 중 일시적으로 더 씀 |

**실제 사용량 확인**

```python
df.memory_usage(deep=True).sum() / 1024**2      # MB
df.info(memory_usage="deep")
```

> **`deep=True` 가 필수입니다.** 없으면 문자열의 **포인터만** 세고 실제 문자열 크기는 빠집니다.
> object 컬럼이 있으면 실제와 10배 이상 차이 납니다.

### dtype별 메모리

| dtype | 바이트/값 | 범위 |
|---|---|---|
| `int8` | 1 | -128 ~ 127 |
| `int16` | 2 | ±32,767 |
| `int32` | 4 | ±21억 |
| `int64` | 8 | 기본 |
| `uint8` | 1 | 0 ~ 255 |
| `float32` | 4 | 유효숫자 ~7자리 |
| `float64` | 8 | 기본 |
| `bool` | 1 | |
| `category` | ~1~4 + 사전 | 반복되는 문자열 ⭐ |
| `object` (str) | **~58 + 문자** | 기본 (매우 큼) |

**100만 행 기준**

```
int64   →  8 MB
int32   →  4 MB       절반
int8    →  1 MB       1/8
object(문자열, 평균 10자)  →  ~68 MB
category (고유값 25개)     →  ~1 MB      1/68 ⭐
```

### category — 문자열 메모리의 결정타

**반복되는 문자열**에 씁니다.

```
object                          category
"강남구" (58 bytes) × 100만행    코드 배열 (1 byte × 100만) + 사전 25개
= 58 MB                        = 1 MB
```

```python
df["station"] = df["station"].astype("category")
```

**언제 쓰나**

| 조건 | category 적합 |
|---|---|
| 고유값 / 전체 행 < 0.5 | ✅ |
| 고유값이 수십~수백 개 | ✅ |
| 고유값이 거의 전부 다름 (ID·주소) | ❌ 오히려 커짐 |

```python
ratio = df["col"].nunique() / len(df)
if ratio < 0.5:
    df["col"] = df["col"].astype("category")
```

**주의점**

```python
df["cat"].str.upper()          # 동작하지만 object 로 돌아감
df["cat"] + "구"                # 에러
pd.concat([df1, df2])          # 카테고리가 다르면 object 가 됨
```

**연산 전에 `.astype(str)` 로 되돌리거나, 연산 후에 다시 category로** 바꿔야 합니다.

### 다운캐스팅

```python
pd.to_numeric(df["x"], downcast="integer")     # 가장 작은 int
pd.to_numeric(df["x"], downcast="float")       # float32
pd.to_numeric(df["x"], downcast="unsigned")    # 음수가 없으면 uint
```

**자동으로 값 범위에 맞는 최소 타입**을 골라 줍니다.

> ⚠ **오버플로 주의** ([Day 021](day-021.md))
> `int8` 로 줄인 컬럼에 나중에 큰 값이 들어오면 **조용히 순환**합니다.
> 앞으로 들어올 값의 범위를 고려하세요.

> ⚠ **float32 정밀도**
> 유효숫자가 7자리입니다. 금액·좌표처럼 정밀도가 중요하면 `float64` 를 유지하세요.

### chunksize — 나눠 읽기

```python
for chunk in pd.read_csv(path, chunksize=100_000):
    process(chunk)          # chunk 는 10만 행짜리 DataFrame
```

**메모리에는 한 번에 10만 행만 올라옵니다.**

```
1000만 행 파일
  전체 읽기 : 8 GB 필요        ❌
  chunk 100만: 800 MB 필요     ✅
  chunk 10만 : 80 MB 필요      ✅
```

**chunk로 할 수 있는 것 / 없는 것**

| 가능 | 불가능 (또는 어려움) |
|---|---|
| 합계·개수·최대·최소 | 중앙값 (전체를 봐야 함) |
| 그룹별 합계·개수 | 정확한 고유값 개수 (근사는 가능) |
| 필터링 후 저장 | 전체 정렬 |
| 행별 변환 | 전체 기준 순위 |
| 평균 (합/개수로) | 표준편차 (합·제곱합으로 가능) |

**"전체를 한 번에 봐야 하는 것"** 은 두 번 훑거나 다른 방법이 필요합니다.

### 청크 집계 패턴

```python
# 1) 단순 합계
total = 0
count = 0
for chunk in pd.read_csv(path, chunksize=100_000):
    total += chunk["x"].sum()
    count += chunk["x"].count()
mean = total / count

# 2) 그룹별 집계 — 부분 결과를 모아 최종 집계
partials = []
for chunk in pd.read_csv(path, chunksize=100_000):
    partials.append(chunk.groupby("g")["x"].agg(["sum", "count"]))

combined = pd.concat(partials).groupby(level=0).sum()
result = combined["sum"] / combined["count"]

# 3) 필터링 후 저장
first = True
for chunk in pd.read_csv(path, chunksize=100_000):
    filtered = chunk[chunk["x"] > 100]
    filtered.to_csv(out, mode="w" if first else "a",
                    header=first, index=False)
    first = False
```

**2번 패턴이 핵심입니다.** "부분 집계 → 최종 집계"는 분산 처리의 기본 원리이기도 합니다.

### 표준편차를 chunk로 계산하기

```python
# 합, 제곱합, 개수만 모으면 됩니다
n = total = sq_total = 0
for chunk in pd.read_csv(path, chunksize=100_000):
    x = chunk["value"].dropna()
    n += len(x)
    total += x.sum()
    sq_total += (x ** 2).sum()

mean = total / n
var = sq_total / n - mean ** 2      # E[X²] - E[X]²
std = var ** 0.5
```

> **수치 안정성 주의** — 값이 크고 분산이 작으면 이 공식이 부정확할 수 있습니다.
> 정밀도가 중요하면 Welford 알고리즘을 쓰거나 두 번 훑으세요.

### 필요한 컬럼만 읽기

**가장 쉽고 효과적인 최적화입니다.**

```python

```

컬럼이 20개인데 3개만 쓴다면 **메모리가 1/7** 이 됩니다.

```python
    "station": "category",
```

## ④ 단계별 실습

### Step 1. 대용량 테스트 파일 만들기

`make_large_data.py` 를 만듭니다.

```python
"""대용량 실습 데이터 생성. 메모리를 쓰지 않도록 chunk 로 씁니다."""

import argparse
import time
from pathlib import Path

import numpy as np
import pandas as pd

STATIONS = [f"{name}구" for name in [
    "중", "종로", "용산", "성동", "광진", "동대문", "중랑", "성북", "강북", "도봉",
    "노원", "은평", "서대문", "마포", "양천", "강서", "구로", "금천", "영등포",
    "동작", "관악", "서초", "강남", "송파", "강동"]]
REGIONS = ["도심", "동북", "서북", "서남", "동남"]
GRADES = ["좋음", "보통", "약간나쁨", "나쁨"]


def generate(path: Path, total_rows: int, chunk_rows: int = 500_000,
             seed: int = 42) -> None:
    rng = np.random.default_rng(seed)
    start = time.perf_counter()
    written = 0
    first = True

    base_time = pd.Timestamp("2025-01-01")

    while written < total_rows:
        n = min(chunk_rows, total_rows - written)

        chunk = pd.DataFrame({
            "measured_at": base_time + pd.to_timedelta(
                rng.integers(0, 365 * 24 * 60, n), unit="m"),
            "station": rng.choice(STATIONS, n),
            "region": rng.choice(REGIONS, n),
            "pm10": rng.integers(5, 180, n),
            "pm25": rng.integers(2, 95, n),
            "o3": rng.uniform(0.005, 0.12, n).round(4),
            "no2": rng.uniform(0.005, 0.09, n).round(4),
            "temperature": rng.uniform(-15, 38, n).round(1),
            "humidity": rng.integers(20, 100, n),
            "grade": rng.choice(GRADES, n, p=[0.35, 0.42, 0.18, 0.05]),
            "device_id": rng.integers(1000, 9999, n),
            "is_valid": rng.random(n) > 0.03,
        })

        chunk.to_csv(path, mode="w" if first else "a",
                     header=first, index=False)
        first = False
        written += n
        print(f"\r  {written:,} / {total_rows:,} 행 "
              f"({written / total_rows:.0%})", end="")

    elapsed = time.perf_counter() - start
    size_mb = path.stat().st_size / 1024**2
    print(f"\n  완료: {path} ({size_mb:,.1f} MB, {elapsed:.1f}초)")


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="대용량 실습 데이터 생성")
    parser.add_argument("-n", "--rows", type=int, default=3_000_000,
                        help="생성할 행 수 (기본: 300만)")
    parser.add_argument("-o", "--out", type=Path, default=Path("data/large.csv"))
    args = parser.parse_args()

    args.out.parent.mkdir(parents=True, exist_ok=True)
    print(f"{args.rows:,}행 생성 중...")
    generate(args.out, args.rows)
```

```powershell
$ python make_large_data.py -n 3000000
3,000,000행 생성 중...
  3,000,000 / 3,000,000 행 (100%)
  완료: data\large.csv (351.7 MB, 42.3초)
```

> **생성할 때도 chunk를 썼습니다.** 300만 행을 한 번에 만들면 그것만으로 1GB를 씁니다.
> 메모리가 부족하면 `-n 1000000` 으로 줄여서 실습하세요.

### Step 2. 메모리 사용량 측정

`measure_memory.py` 를 만듭니다.

```python
"""파일 크기와 메모리 사용량 비교."""

from pathlib import Path

import pandas as pd

PATH = Path("data/large.csv")
SAMPLE_ROWS = 500_000

file_mb = PATH.stat().st_size / 1024**2
print(f"파일 크기: {file_mb:,.1f} MB\n")

print(f"앞 {SAMPLE_ROWS:,}행만 읽어 측정합니다 (전체는 메모리가 부족할 수 있음)\n")

df = pd.read_csv(PATH, nrows=SAMPLE_ROWS)

print("=" * 72)
print("1) 컬럼별 메모리 (deep=True)")
print("=" * 72)
mem = df.memory_usage(deep=True)
shallow = df.memory_usage(deep=False)

table = pd.DataFrame({
    "dtype": ["-"] + [str(d) for d in df.dtypes],
    "shallow(MB)": (shallow / 1024**2).round(2),
    "deep(MB)": (mem / 1024**2).round(2),
    "고유값": ["-"] + [df[c].nunique() for c in df.columns],
})
print(table.to_string())

print(f"\n  shallow 합계: {shallow.sum() / 1024**2:,.1f} MB")
print(f"  deep 합계   : {mem.sum() / 1024**2:,.1f} MB")
print(f"  → deep 을 안 쓰면 문자열 크기를 {mem.sum() / shallow.sum():.1f}배 과소 추정합니다")

print("\n" + "=" * 72)
print("2) 파일 크기 대비 메모리")
print("=" * 72)
sample_file_mb = file_mb * SAMPLE_ROWS / 3_000_000     # 대략적인 비율
print(f"  이 {SAMPLE_ROWS:,}행의 파일 상 크기(추정): {sample_file_mb:,.1f} MB")
print(f"  메모리 사용량                        : {mem.sum() / 1024**2:,.1f} MB")
print(f"  배율                                : {mem.sum() / 1024**2 / sample_file_mb:.1f}배")

print("\n" + "=" * 72)
print("3) 전체 파일을 읽으면?")
print("=" * 72)
per_row_bytes = mem.sum() / len(df)
total_rows = 3_000_000
estimated_gb = per_row_bytes * total_rows / 1024**3
print(f"  행당 메모리 : {per_row_bytes:,.0f} bytes")
print(f"  전체 {total_rows:,}행 예상: {estimated_gb:.2f} GB")
print(f"\n  ⚠ 노트북 RAM 이 8GB 라면 위험합니다.")
print(f"     운영체제·브라우저·IDE 가 이미 3~4GB 를 씁니다.")

print("\n" + "=" * 72)
print("4) object 컬럼의 비용")
print("=" * 72)
obj_cols = df.select_dtypes("object").columns
if len(obj_cols):
    obj_mem = df[obj_cols].memory_usage(deep=True).sum()
    print(f"  object 컬럼: {list(obj_cols)}")
    print(f"  차지하는 메모리: {obj_mem / 1024**2:,.1f} MB "
          f"({obj_mem / mem.sum():.0%})")
    print(f"\n  {'컬럼':<14}{'고유값':>10}{'행 대비':>10}{'category 적합?':>16}")
    print("  " + "-" * 52)
    for col in obj_cols:
        unique = df[col].nunique()
        ratio = unique / len(df)
        suitable = "✅ 예" if ratio < 0.5 else "❌ 아니오"
        print(f"  {col:<14}{unique:>10,}{ratio:>10.4f}{suitable:>16}")
```

```python
"""dtype 최적화로 메모리 줄이기."""

from pathlib import Path

import pandas as pd

ROWS = 500_000


def report_memory(df: pd.DataFrame, label: str) -> float:
    mb = df.memory_usage(deep=True).sum() / 1024**2
    print(f"  {label:<28}{mb:>10,.1f} MB")
    return mb


def optimize(df: pd.DataFrame, category_threshold: float = 0.5,
             verbose: bool = True) -> pd.DataFrame:
    """dtype 을 자동 최적화합니다."""
    df = df.copy()
    changes = []

    for col in df.columns:
        original = str(df[col].dtype)
        original_mb = df[col].memory_usage(deep=True) / 1024**2

        if pd.api.types.is_integer_dtype(df[col]):
            if df[col].min() >= 0:
                df[col] = pd.to_numeric(df[col], downcast="unsigned")
            else:
                df[col] = pd.to_numeric(df[col], downcast="integer")

        elif pd.api.types.is_float_dtype(df[col]):
            df[col] = pd.to_numeric(df[col], downcast="float")

        elif df[col].dtype == "object":
            # 날짜처럼 보이면 datetime 으로
            sample = df[col].dropna().head(100)
            if len(sample) and sample.astype(str).str.match(r"\d{4}-\d{2}-\d{2}").all():
                converted = pd.to_datetime(df[col], errors="coerce")
                if converted.notna().mean() > 0.95:
                    df[col] = converted
                    changes.append((col, original, str(df[col].dtype),
                                    original_mb,
                                    df[col].memory_usage(deep=True) / 1024**2))
                    continue

            # 고유값이 적으면 category 로
            ratio = df[col].nunique() / len(df)
            if ratio < category_threshold:
                df[col] = df[col].astype("category")

        new = str(df[col].dtype)
        if new != original:
            changes.append((col, original, new, original_mb,
                            df[col].memory_usage(deep=True) / 1024**2))

    if verbose and changes:
        print(f"\n  {'컬럼':<14}{'변경 전':<16}{'변경 후':<20}"
              f"{'전(MB)':>9}{'후(MB)':>9}{'절감':>8}")
        print("  " + "-" * 78)
        for col, before, after, mb_before, mb_after in changes:
            saved = (mb_before - mb_after) / mb_before if mb_before else 0
            print(f"  {col:<14}{before:<16}{after:<20}"
                  f"{mb_before:>9.1f}{mb_after:>9.1f}{saved:>7.0%}")

    return df
```

```python
"""대용량 파일 처리 유틸리티."""

from __future__ import annotations

import logging
from collections.abc import Callable, Iterator
from pathlib import Path
from typing import Any

import numpy as np
import pandas as pd

logger = logging.getLogger(__name__)


def estimate_memory(path: Path | str, sample_rows: int = 100_000,
                    **read_kwargs) -> dict[str, Any]:
    """샘플로 전체 메모리 사용량을 추정합니다."""
    path = Path(path)
    sample = pd.read_csv(path, nrows=sample_rows, **read_kwargs)

    # 전체 행 수 세기 (메모리를 안 쓰고)
    with path.open("rb") as f:
        total_rows = sum(1 for _ in f) - 1      # 헤더 제외

    per_row = sample.memory_usage(deep=True).sum() / len(sample)

    return {
        "file_mb": path.stat().st_size / 1024**2,
        "total_rows": total_rows,
        "sample_rows": len(sample),
        "bytes_per_row": per_row,
        "estimated_mb": per_row * total_rows / 1024**2,
        "columns": len(sample.columns),
        "dtypes": sample.dtypes.astype(str).to_dict(),
    }


def optimize_dtypes(df: pd.DataFrame, category_threshold: float = 0.5,
                    keep_float64: tuple[str, ...] = ()) -> pd.DataFrame:
    """dtype 을 자동으로 최적화합니다.

    Args:
        category_threshold: 고유값/전체 비율이 이 값 미만이면 category 로
        keep_float64: 정밀도가 필요해 float64 를 유지할 컬럼
    """
    df = df.copy()

    for col in df.columns:
        if col in keep_float64:
            continue

        if pd.api.types.is_integer_dtype(df[col]):
            kind = "unsigned" if df[col].min() >= 0 else "integer"
            df[col] = pd.to_numeric(df[col], downcast=kind)

        elif pd.api.types.is_float_dtype(df[col]):
            df[col] = pd.to_numeric(df[col], downcast="float")

        elif df[col].dtype == "object":
            if df[col].nunique() / max(len(df), 1) < category_threshold:
                df[col] = df[col].astype("category")

    return df


def suggest_dtypes(path: Path | str, sample_rows: int = 100_000,
                   category_threshold: float = 0.5) -> dict[str, str]:
    """샘플을 보고 read_csv 에 넘길 dtype 딕셔너리를 제안합니다."""
    sample = pd.read_csv(path, nrows=sample_rows)
    optimized = optimize_dtypes(sample, category_threshold)
    return {col: str(dtype) for col, dtype in optimized.dtypes.items()
            if not str(dtype).startswith("datetime")}


def iter_chunks(path: Path | str, chunksize: int = 200_000,
                progress: bool = True, **read_kwargs) -> Iterator[pd.DataFrame]:
    """진행 상황을 표시하며 chunk 를 순회합니다."""
    path = Path(path)
    rows = 0
    for i, chunk in enumerate(pd.read_csv(path, chunksize=chunksize, **read_kwargs),
                              start=1):
        rows += len(chunk)
        if progress:
            print(f"\r  chunk {i:>3} — 누적 {rows:,}행", end="", flush=True)
        yield chunk
    if progress:
        print()
    logger.info("%s — %d chunk, %d행 처리", path.name, i, rows)


def chunked_groupby(path: Path | str, group_cols: list[str], value_col: str,
                    chunksize: int = 200_000,
                    filter_func: Callable[[pd.DataFrame], pd.DataFrame] | None = None,
                    **read_kwargs) -> pd.DataFrame:
    """chunk 로 그룹별 집계를 수행합니다 (합·개수·최소·최대·평균)."""
    partials = []

    for chunk in iter_chunks(path, chunksize, **read_kwargs):
        if filter_func is not None:
            chunk = filter_func(chunk)
        if chunk.empty:
            continue
        part = chunk.groupby(group_cols, observed=True)[value_col].agg(
            ["sum", "count", "min", "max"])
        partials.append(part)

    if not partials:
        return pd.DataFrame()

    combined = pd.concat(partials).groupby(level=list(range(len(group_cols)))).agg({
        "sum": "sum", "count": "sum", "min": "min", "max": "max",
    })
    combined["mean"] = combined["sum"] / combined["count"]
    return combined


def chunked_stats(path: Path | str, value_col: str, chunksize: int = 200_000,
                  **read_kwargs) -> dict[str, float]:
    """chunk 로 평균·표준편차를 계산합니다."""
    n = 0
    total = 0.0
    sq_total = 0.0
    minimum = np.inf
    maximum = -np.inf

    for chunk in iter_chunks(path, chunksize, **read_kwargs):
        x = chunk[value_col].dropna().astype("float64")
        if x.empty:
            continue
        n += len(x)
        total += x.sum()
        sq_total += (x ** 2).sum()
        minimum = min(minimum, x.min())
        maximum = max(maximum, x.max())

    if n == 0:
        return {"count": 0}

    mean = total / n
    var = max(sq_total / n - mean ** 2, 0.0)     # 수치 오차로 음수가 될 수 있음
    return {
        "count": n,
        "mean": mean,
        "std": var ** 0.5,
        "min": minimum,
        "max": maximum,
        "sum": total,
    }


def chunked_filter_to_file(path: Path | str, out_path: Path | str,
                           condition: Callable[[pd.DataFrame], pd.Series],
                           chunksize: int = 200_000, **read_kwargs) -> int:
    """조건에 맞는 행만 새 파일로 저장합니다. 저장한 행 수를 돌려줍니다."""
    out_path = Path(out_path)
    out_path.parent.mkdir(parents=True, exist_ok=True)

    kept = 0
    first = True

    for chunk in iter_chunks(path, chunksize, **read_kwargs):
        filtered = chunk[condition(chunk)]
        if filtered.empty:
            continue
        filtered.to_csv(out_path, mode="w" if first else "a",
                        header=first, index=False, encoding="utf-8-sig")
        first = False
        kept += len(filtered)

    logger.info("%s → %s (%d행)", Path(path).name, out_path.name, kept)
    return kept
```

**1.** 1GB CSV 파일을 읽었더니 메모리 사용량이 3GB가 됐습니다. 왜 그렇고, 어떻게 줄이나요?

<details>
<summary>답 보기</summary>

**왜 3배가 되는가**

| 원인 | 설명 | 예 |
|---|---|---|
| **문자열 오버헤드** | 파이썬 str 객체는 헤더만 49바이트 | `"강남구"` 9B → 58B |

| 인덱스 | 행마다 8바이트 | 100만 행 → 8MB |
| 읽는 중 버퍼 | 파싱 중 일시적으로 더 씀 | 피크가 더 높음 |

**object 컬럼이 대부분을 차지합니다.**

```python
df.memory_usage(deep=True).sort_values(ascending=False).head()
```

고유값이 25개라면 **98% 절감**됩니다.

```
object   : 58 bytes × 100만행 = 58 MB
category : 1 byte × 100만행 + 사전 = 1 MB
```

문자열 `"2026-08-12 14:23:00"` (68B) → datetime64 (8B), **88% 절감**.

**2.** chunk로 전체 평균은 계산할 수 있지만 중앙값은 안 됩니다. 왜인가요? 어떻게 해결하나요?

<details>
<summary>답 보기</summary>

**평균은 결합 가능(associative)하고, 중앙값은 아닙니다.**

**평균이 되는 이유**

```
전체 평균 = 전체 합 / 전체 개수
         = (chunk1 합 + chunk2 합 + ...) / (chunk1 개수 + chunk2 개수 + ...)
```

**부분 결과(합·개수)만 들고 있으면** 최종 계산이 가능합니다.

```python
total = count = 0
for chunk in chunks:
    total += chunk["x"].sum()
    count += chunk["x"].count()
mean = total / count      # ✅ 정확
```

**중앙값이 안 되는 이유**

중앙값은 **전체를 정렬해야** 알 수 있습니다.

```
chunk1: [1, 2, 3]        중앙값 2
chunk2: [100, 200, 300]  중앙값 200

부분 중앙값의 평균 = (2 + 200) / 2 = 101
실제 전체 중앙값   = [1,2,3,100,200,300] → (3+100)/2 = 51.5
```

**완전히 다릅니다.**

**결합 가능 여부 정리**

| 통계 | 결합 가능? | chunk 계산법 |
|---|---|---|
| sum | ✅ | 합의 합 |
| count | ✅ | 개수의 합 |
| min / max | ✅ | 최소의 최소 |
| **mean** | ✅ | sum / count |
| **std / var** | ✅ | 합·제곱합·개수로 |
| median | ❌ | — |
| quantile | ❌ | — |
| mode | ❌ | — |
| nunique | ❌ (근사만) | — |

**표준편차는 되는 이유**

```
Var(X) = E[X²] - (E[X])²
```

합, **제곱합**, 개수만 모으면 됩니다.

```python
n = s = sq = 0
for chunk in chunks:
    x = chunk["x"].dropna().astype("float64")
    n += len(x)
    s += x.sum()
    sq += (x ** 2).sum()

mean = s / n
std = (sq / n - mean ** 2) ** 0.5
```

> **수치 안정성 주의** — 값이 크고 분산이 작으면 `sq/n` 과 `mean²` 이 비슷해져
> 자릿수 손실이 생깁니다. 정밀도가 중요하면 Welford 알고리즘을 쓰세요.

**중앙값 해결 방법 4가지**

**① 그 컬럼만 전체 읽기 (가장 실용적)** ⭐

```python
values = pd.read_csv(path, usecols=["pm10"], dtype={"pm10": "uint8"})["pm10"]
median = values.median()
```

300만 행 × 1바이트 = **3MB**입니다. 전혀 문제가 안 됩니다.
**컬럼 하나만 필요할 때는 대부분 이 방법으로 됩니다.**

**② 히스토그램으로 근사**

```python
from collections import Counter

counter = Counter()
for chunk in chunks:
    counter.update(chunk["pm10"].dropna().astype(int))

# 누적 개수로 중앙값 찾기
total = sum(counter.values())
cumulative = 0
for value in sorted(counter):
    cumulative += counter[value]
    if cumulative >= total / 2:
        median = value
        break
```

**정수 값이고 범위가 좁을 때** 정확합니다.

**③ 근사 알고리즘**

`t-digest`, `P²` 같은 스트리밍 분위수 알고리즘이 있습니다.
`tdigest` 라이브러리를 쓰면 됩니다. 오차는 보통 0.1% 미만입니다.

**④ DB에 넣고 SQL로 (W07)** ⭐

```sql
SELECT PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY pm10) FROM measurements;
```

**DB는 이런 계산에 최적화돼 있습니다.**
데이터가 계속 커진다면 이것이 근본 해결입니다.

**실무 판단**

```
데이터가 chunk 로 처리해야 할 만큼 크다
    → 그런데 중앙값·분위수가 필요하다
        → 그 컬럼만 읽어서 되는가?  → 예: ①
                                  → 아니오: DB (W07) ④
```

**대부분 ①로 해결됩니다.** 컬럼 하나는 전체 데이터의 1/12 이하이고,
dtype을 줄이면 더 작아집니다.

이것이 W07에서 SQL을 배우는 이유이기도 합니다.
"파일로 하기 어려운 것을 DB가 대신해 준다"가 [Day 031](../02-sql-pipeline/day-031.md)의 시작입니다.
</details>

**3.** `dtype` 최적화로 메모리를 92% 줄였습니다. 이때 주의해야 할 위험 두 가지는 무엇인가요?
