## ③ 개념 설명

### 산술 연산자

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `7 + 3` | `10` |
| `-` | 빼기 | `7 - 3` | `4` |
| `*` | 곱하기 | `7 * 3` | `21` |
| `/` | 나누기 | `7 / 3` | `2.333...` |
| `//` | **몫** (버림 나눗셈) | `7 // 3` | `2` |
| `%` | **나머지** | `7 % 3` | `1` |
| `**` | 거듭제곱 | `7 ** 3` | `343` |

> **`/` 와 `//` 의 차이가 중요합니다.**
> `/` 는 나누어떨어져도 결과가 항상 실수입니다. `10 / 2` 는 `5` 가 아니라 `5.0` 입니다.
> `//` 는 소수점 이하를 버리고 정수 몫만 남깁니다.

**`%` (나머지)는 생각보다 자주 씁니다.**

| 쓰임 | 코드 | 의미 |
|---|---|---|
| 짝수 판별 | `num % 2 == 0` | 2로 나눈 나머지가 0이면 짝수 |
| 배수 판별 | `num % 3 == 0` | 3의 배수인가 |
| 초 → 분·초 | `sec // 60`, `sec % 60` | 130초 = 2분 10초 |

### 연산자 우선순위

수학과 같습니다. **거듭제곱 → 곱셈·나눗셈 → 덧셈·뺄셈** 순이고, 괄호가 가장 먼저입니다.

```python
2 + 3 * 4        # 14  (곱셈 먼저)
(2 + 3) * 4      # 20  (괄호 먼저)
2 ** 3 * 2       # 16  (거듭제곱 먼저: 8 * 2)
```

> 헷갈리면 **괄호를 쓰세요.** 우선순위를 외우는 것보다 괄호를 치는 편이 읽기도 좋고 실수도 없습니다.

### 복합 할당 연산자

같은 변수에 계산 결과를 다시 넣을 때 짧게 쓰는 방법입니다.

```python
score = 10
score = score + 5     # 이렇게 쓰는 대신
score += 5            # 이렇게 씁니다 (같은 뜻)
```

| 연산자 | 같은 표현 |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |
| `x //= 2` | `x = x // 2` |
| `x %= 3` | `x = x % 3` |

### 비교 연산자 — 결과는 항상 True/False

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `==` | 같다 | `5 == 5` | `True` |
| `!=` | 다르다 | `5 != 3` | `True` |
| `>` | 크다 | `5 > 3` | `True` |
| `<` | 작다 | `5 < 3` | `False` |
| `>=` | 크거나 같다 | `5 >= 5` | `True` |
| `<=` | 작거나 같다 | `5 <= 3` | `False` |

> ⚠️ **`=` 와 `==` 를 구분하세요.**
> `=` 는 **넣기**(대입), `==` 는 **비교**입니다. 초보자가 가장 많이 헷갈리는 부분입니다.
> `age = 20` 은 "age에 20을 넣어라", `age == 20` 은 "age가 20이냐?" 입니다.

파이썬은 범위 비교를 수학처럼 이어서 쓸 수 있습니다.

```python
score = 85
print(80 <= score < 90)    # True  ("80 이상 90 미만인가?")
```

### 논리 연산자 — 조건 여러 개 묶기

| 연산자 | 뜻 | 참이 되는 조건 |
|---|---|---|
| `and` | 그리고 | **둘 다** 참일 때만 참 |
| `or` | 또는 | **하나라도** 참이면 참 |
| `not` | 아니다 | 참↔거짓을 뒤집음 |

```python
age = 25
has_ticket = True

print(age >= 19 and has_ticket)   # True  (둘 다 만족)
print(age < 19 or has_ticket)     # True  (뒤쪽이 참)
print(not has_ticket)             # False (True를 뒤집음)
```

**진리표**

| A | B | `A and B` | `A or B` |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

### 문자열 인덱싱 — 한 글자 꺼내기

문자열의 각 글자에는 **번호(인덱스)** 가 붙어 있습니다. **0부터 시작**합니다.

```
문자열:   P   y   t   h   o   n
양수 인덱스:  0   1   2   3   4   5
음수 인덱스: -6  -5  -4  -3  -2  -1
```

```python
word = "Python"
print(word[0])     # P   (첫 글자)
print(word[3])     # h
print(word[-1])    # n   (마지막 글자)
print(word[-2])    # o   (뒤에서 두 번째)
```

> **음수 인덱스**는 뒤에서부터 셉니다. 마지막 글자를 꺼낼 때 길이를 계산할 필요가 없어 편리합니다.

### 문자열 슬라이싱 — 여러 글자 잘라내기

`문자열[시작:끝]` 형태로 씁니다. **시작은 포함, 끝은 포함하지 않습니다.**

```python
word = "Python"
print(word[0:3])     # Pyt   (0,1,2번 - 3번은 제외)
print(word[2:5])     # tho
print(word[:3])      # Pyt   (시작 생략 = 처음부터)
print(word[3:])      # hon   (끝 생략 = 마지막까지)
print(word[:])       # Python (전체 복사)
print(word[::2])     # Pto   (2칸씩 건너뛰기)
print(word[::-1])    # nohtyP (거꾸로!)
```

> **`[끝]` 이 포함되지 않는 이유** — `word[0:3]` 은 "0번부터 3개" 라고 외우면 편합니다.
> `[::-1]` 로 문자열을 뒤집는 것은 자주 쓰는 관용구이니 기억해 두세요.

### 문자열 메서드

**메서드(method)** 는 특정 값에 붙어 있는 기능입니다. `값.기능()` 형태로 씁니다.

| 메서드 | 하는 일 | 예 | 결과 |
|---|---|---|---|
| `.upper()` | 전부 대문자 | `"abc".upper()` | `"ABC"` |
| `.lower()` | 전부 소문자 | `"ABC".lower()` | `"abc"` |
| `.strip()` | 앞뒤 공백 제거 | `"  hi  ".strip()` | `"hi"` |
| `.replace(a, b)` | a를 b로 바꾸기 | `"a-b".replace("-","+")` | `"a+b"` |
| `.split(구분자)` | 나눠서 리스트로 | `"a,b".split(",")` | `["a","b"]` |
| `.count(x)` | x가 몇 번 나오나 | `"banana".count("a")` | `3` |
| `.find(x)` | x의 위치(없으면 -1) | `"python".find("t")` | `2` |
| `.startswith(x)` | x로 시작하나 | `"hello".startswith("he")` | `True` |
| `len(문자열)` | 길이 (메서드 아님) | `len("python")` | `6` |

> ⚠️ **문자열 메서드는 원본을 바꾸지 않습니다.** 새 문자열을 만들어 돌려줄 뿐입니다.
> ```python
> name = "  홍길동  "
> name.strip()          # 결과를 안 받으면 아무 소용 없음
> print(name)           # "  홍길동  "  ← 그대로!
>
> name = name.strip()   # 이렇게 다시 넣어 줘야 합니다
> print(name)           # "홍길동"
> ```

```python
# 전체 초를 시:분:초 로 바꿉니다
```

### Step 4. 주민등록번호로 성별 판별하기

주민등록번호 뒷자리 첫 숫자는 성별을 나타냅니다. `1`·`3` 은 남자, `2`·`4` 는 여자입니다.

```python
# 형식: 990101-1234567
jumin = input("주민등록번호를 입력하세요 (예: 990101-1234567): ")

# 하이픈 뒤 첫 글자 = 인덱스 7번
gender_code = jumin[7]

# 출생 연도 앞 2자리
year = jumin[0:2]

print(f"성별 코드: {gender_code}")
print(f"출생 연도 뒷자리: {year}년생")
print(f"남자인가? {gender_code == '1' or gender_code == '3'}")
```

실행 결과:

```

성별 코드: 1
출생 연도 뒷자리: 99년생
남자인가? True
```

> `gender_code` 는 문자열이므로 `'1'` 처럼 따옴표를 붙여 비교해야 합니다.
> 실제로 성별을 "남자/여자" 글자로 출력하는 것은 [Day 004 조건문](day-004.md)에서 합니다.

### Step 5. 이메일 정보 추출하기 (오늘의 종합 예제)

```python
print("=== 이메일 분석기 ===")

# strip() 으로 앞뒤 공백을 없애고, lower() 로 소문자로 통일합니다
email = input("이메일을 입력하세요: ").strip().lower()

# @ 의 위치를 찾습니다
at_index = email.find("@")

# @ 앞뒤로 잘라 냅니다
user_id = email[:at_index]
domain = email[at_index + 1:]

print()
print(f"입력값:      {email}")
print(f"아이디:      {user_id}")
print(f"도메인:      {domain}")
print(f"아이디 길이: {len(user_id)}자")
print(f"@ 포함 여부: {'@' in email}")
print(f"gmail 인가?: {domain == 'gmail.com'}")
```

> 문자열의 길이는 `email.length` 가 아니라 **`len(email)`** 입니다. 파이썬에는 `.length` 가 없습니다.

실행 결과:

```
=== 이메일 분석기 ===
이메일을 입력하세요:   Hong@Gmail.com

입력값:      hong@gmail.com
아이디:      hong
도메인:      gmail.com
아이디 길이: 4자
@ 포함 여부: True
gmail 인가?: True
```

> `.strip().lower()` 처럼 메서드를 **연달아 붙여 쓸 수 있습니다.** 왼쪽부터 차례로 적용됩니다.
> `in` 연산자는 "포함되어 있는가"를 True/False 로 알려 줍니다.

## ⑤ 자주 하는 실수

### `IndexError: string index out of range`

```python
word = "Python"
print(word[6])
```

```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    print(word[6])
IndexError: string index out of range
```

**원인** — 인덱스는 0부터 시작하므로 6글자 문자열의 마지막 인덱스는 **5** 입니다. 6번은 없습니다.
**해결** — `word[5]` 또는 `word[-1]` 을 씁니다. 길이를 모를 땐 `word[len(word)-1]` 이 아니라 `word[-1]` 이 안전합니다.

> 참고 — **슬라이싱은 범위를 넘어도 에러가 나지 않습니다.** `word[0:100]` 은 그냥 전체를 돌려줍니다.

### `SyntaxError: invalid syntax` — `=` 와 `==` 혼동

```python
age = 20
print(age = 20)
```

```
  File "test.py", line 2
    print(age = 20)
          ^^^^^^^^
SyntaxError: invalid syntax
```

**원인** — 비교하려는 자리에 대입(`=`)을 썼습니다.
**해결** — 비교는 `==` 입니다. `print(age == 20)`

### 메서드를 썼는데 원본이 안 바뀝니다

```python
name = "  홍길동  "
name.strip()
print(f"[{name}]")
```

```
[  홍길동  ]
```

**원인** — 문자열 메서드는 원본을 수정하지 않고 **새 문자열을 반환**합니다. 그 결과를 아무 데도 담지 않았습니다.
**해결** — 결과를 다시 변수에 넣습니다.

```python
name = name.strip()
print(f"[{name}]")     # [홍길동]
```

> 이 성질을 **불변(immutable)** 이라고 합니다. Day 011의 리스트는 반대로 원본이 바뀌므로 대비해서 기억하세요.

### `TypeError: '>' not supported between instances of 'str' and 'int'`

```python
score = input("점수: ")
print(score > 60)
```

```
TypeError: '>' not supported between instances of 'str' and 'int'
```

**원인** — `input()` 결과는 문자열입니다. 문자열과 숫자는 크기 비교를 할 수 없습니다.
**해결** — `score = int(input("점수: "))`

### `and` / `or` 를 `&` / `|` 로 잘못 씀

```python
print(age >= 19 & has_ticket)
```

**원인** — `&` 는 비트 연산자로 의미가 다르고 우선순위도 달라 엉뚱한 결과가 나옵니다.
**해결** — 파이썬에서 논리 연산은 **`and` / `or` / `not`** 을 씁니다. (단, 대단원 02의 pandas에서는 `&` `|` 를 씁니다 — 그때 다시 다룹니다)

```python
print(f"{year}년 {int(month)}월 {int(day)}일")
```

실행 결과:

```
2026년 8월 7일
```

**포인트** — 슬라이싱 결과는 문자열이므로 `"08"` 이 됩니다. 앞의 0을 없애려면 `int()` 로 바꿔 출력합니다.

`split()` 을 쓰면 더 간단합니다. (Day 011에서 리스트를 배우면 이 방식을 씁니다)

```python
year, month, day = date.split("-")
print(f"{year}년 {int(month)}월 {int(day)}일")
```
</details>

**3.** 사용자에게 단어를 입력받아 **회문(앞뒤가 같은 단어)** 인지 판별해 True/False 로 출력하세요. 대소문자와 앞뒤 공백은 무시합니다.

<details>
<summary>답 보기</summary>

```python
word = input("단어를 입력하세요: ").strip().lower()

# 뒤집은 문자열과 원본이 같으면 회문입니다
print(f"'{word}' 는 회문인가? {word == word[::-1]}")
```

실행 결과:

```
단어를 입력하세요:  Level
'level' 는 회문인가? True
```

**포인트 3가지**
- `.strip()` 으로 공백 제거, `.lower()` 로 대소문자 통일 → 두 개를 연달아 붙여 씁니다.
- `[::-1]` 이 문자열을 뒤집는 관용구입니다.
- `==` 비교 결과가 곧 `True`/`False` 이므로 조건문 없이도 출력할 수 있습니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 몫과 나머지 | `//` 몫 · `%` 나머지 · `/` 는 항상 실수 |
| 복합 할당 | `x += 5` 는 `x = x + 5` |
| 비교 연산자 | `==` `!=` `>` `<` `>=` `<=` → 결과는 `True`/`False` |
| 논리 연산자 | `and` 둘 다 · `or` 하나라도 · `not` 뒤집기 |
| 인덱싱 | `s[0]` 첫 글자 · `s[-1]` 마지막 글자 |
| 슬라이싱 | `s[시작:끝]` — **끝은 포함 안 됨** · `s[::-1]` 뒤집기 |
| 문자열 메서드 | `.strip()` `.lower()` `.split()` `.replace()` — **원본은 안 바뀜** |

**오늘 반드시 기억할 한 가지**
> `=` 는 넣기, `==` 는 비교입니다. 그리고 문자열 메서드의 결과는 **다시 변수에 담아야** 합니다.
