## 1부 · 분할 전략 결정

### 판정 1 — 그룹 구조가 있는가

```python
n_dev = df["developer"].nunique()
rows_per_dev = len(df) / n_dev
```

| 그룹당 행 수 | 판정 |
|---|---|
| ~1.2 | 그룹 없음. 무작위 분할 |
| **1.2 ~ 3** | 약한 그룹. 상황에 따라 |
| **> 3** | **그룹 분할 필요** |

**우리 데이터**

```
개발사 842종 / 3,013행 = 3.6행/개발사
퍼블리셔 387종 / 3,013행 = 7.8행/퍼블리셔
```

**→ 그룹 구조가 있습니다.**

### 그런데 그룹 분할이 항상 옳은 것은 아닙니다

**"이 모델을 어떻게 쓸 것인가"로 결정합니다.**

| 사용 상황 | 분할 |
|---|---|
| **기존 개발사의 신작** 할인율 예측 | 무작위 분할 OK |
| **새 개발사의 게임** 할인율 예측 | **그룹 분할 필수** |
| 둘 다 | **두 성능을 모두 보고** |

> **권장 — 두 방식을 모두 평가하고 보고하는 것입니다.**
> 그룹 분할 성능이 훨씬 나쁘면 "이 모델은 기존 개발사에만 유효"라고 명시합니다.

### 판정 2 — 시계열인가

```
출시일이 있고, 예측 대상이 "미래에 나올 게임"이라면 시계열
```

**확인 방법**

```python
corr = df["release_dt"].rank().corr(df[TARGET].rank())
```

| 순위 상관 | 판정 |
|---|---|
| \|r\| < 0.1 | 시간 효과 약함 |
| **\|r\| > 0.2** | **시간 순 분할 검토** |

**우리 데이터** — `release_year` 와 타깃 상관이 -0.41입니다.

```
오래된 게임일수록 할인율이 높다 → 강한 시간 추세
```

**그런데 이것은 "출시 시점"이지 "예측 시점"이 아닙니다.**

```
우리는 2024-12-20 세일의 할인율을 예측합니다.
모든 게임이 같은 시점에 세일합니다.
→ 시계열 분할이 아니라 "출시경과일"이 특성인 것입니다
```

> **판정: 시계열 분할 불필요.**
> **단, "2025년 신작에 이 모델을 쓸 수 있는가"는 별개 문제입니다.** 보고서에 명시합니다.

### ③ ★ 규칙 기반 — 이 프로젝트의 진짜 베이스라인

```python
def rule_based(X):
    """도메인 규칙: 출시 경과에 따라 할인율 결정"""
    years = X["days_since_release"] / 365.25
    return np.select(
        [years < 1, years < 3, years < 5],
        [20, 35, 45],
        default=55,
    )
```

**규칙을 정하는 법**

```
① 데이터를 보고 구간별 중앙값을 확인
② 반올림해서 사람이 쓸 만한 규칙으로
③ ★ 학습셋에서만 확인 (검증셋을 보면 안 됨)
```

> **이 규칙을 못 이기면 모델을 쓸 이유가 없습니다.**
> **[Day 126](day-126.md)의 "실패 조건" 첫 항목입니다.**

import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, TargetEncoder

SEED = 42

# ── 열 분류 ──
binary_like = [c for c in FEATURES
               if data[c].dropna().isin([0, 1]).all() and data[c].nunique() <= 2]
numeric = [c for c in FEATURES if c not in binary_like]

print("=" * 84)

print("-" * 84)

num_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("scale", StandardScaler()),
])

preprocessor = ColumnTransformer([
    ("num", num_pipe, numeric),
    ("bin", "passthrough", binary_like),
], remainder="drop", verbose_feature_names_out=False)

Xt = preprocessor.fit_transform(X_train)
print(f"  변환 결과  : {X_train.shape} → {Xt.shape}")
print(f"  결측       : {np.isnan(Xt).sum()}개")

print("=" * 84)


# ═══════════════════════════════════════════════════════════
# 개발사 타깃 인코딩을 포함한 확장 파이프라인
# ═══════════════════════════════════════════════════════════
def make_full_frame(idx):
    """특성 + 개발사·퍼블리셔 열을 함께 담은 DataFrame"""
    f = data.loc[idx, FEATURES + ["developer", "publisher"]].copy()
    return f


Xf_train = make_full_frame(X_train.index)
Xf_val = make_full_frame(X_val.index)
Xf_test = make_full_frame(X_test.index)

preprocessor_full = ColumnTransformer([
    ("num", num_pipe, numeric),
    ("bin", "passthrough", binary_like),
    # ★ 타깃 인코딩은 반드시 Pipeline 안에서 (Day 122: 밖에서 하면 54% 부풀림)
    ("dev", Pipeline([("te", TargetEncoder(smooth="auto", cv=5, random_state=SEED)),
                      ("sc", StandardScaler())]), ["developer"]),
    ("pub", Pipeline([("te", TargetEncoder(smooth="auto", cv=5, random_state=SEED)),
                      ("sc", StandardScaler())]), ["publisher"]),
], remainder="drop", verbose_feature_names_out=False)

Xtf = preprocessor_full.fit_transform(Xf_train, y_train)

print(f"    → 교차검증·최종 학습 모두에서 누수가 구조적으로 불가능")

    print(f"  → {'★ 1.0 — 정답이 그대로 특성이 됨' if corr_single > 0.99 else ''}")

te_ok = TargetEncoder(smooth="auto", cv=5, random_state=SEED)
enc_ok = te_ok.fit_transform(Xf_train[["developer"]], y_train).ravel()
corr_ok = np.corrcoef(enc_ok[mask_single.values], y_train[mask_single].values)[0, 1]
print(f"  Pipeline 방식(cv=5) 상관: {corr_ok:.4f}  → 정상")

def score_all(y_true, pred, clip=(0, 90)):
    """지표 계산 — 예측을 유효 범위로 clip"""

    pred = np.clip(np.asarray(pred, float), *clip)
    mae = mean_absolute_error(y_true, pred)
    rmse = float(np.sqrt(mean_squared_error(y_true, pred)))
    return {
        "MAE": round(mae, 4),
        "RMSE": round(rmse, 4),
        "R2": round(r2_score(y_true, pred), 4),
        "MAPE(%)": round(float(np.mean(np.abs((y_true - pred) / y_true)) * 100), 2),
        "RMSE/MAE": round(rmse / max(mae, 1e-12), 3),
    }
