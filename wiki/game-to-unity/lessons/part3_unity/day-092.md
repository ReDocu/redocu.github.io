## 3. 개념

### 3-1. 웨이포인트 — 순서 있는 점들

**왜 필요한가** — 가장 단순하고 확실한 방법.

```
   트랙 위 경로 점군

     P0 ── P1 ── P2 ── P3
                        ╲
                         P4      ← 선행 지점(lookahead) = 현재 위치 기준 N개 앞
                          ╲
                           P5

   조향     = (선행 지점 방향) - (현재 진행 방향)
   목표 속도 = 최대속도 × (1 - 각도차 / 180)

   각도차가 크다 = 코너다 → 미리 감속
```

```
   ★ 웨이포인트가 담는 정보

   ① 위치 (Vector3)
   ② 방향 (다음 점을 향하는 벡터)
   ③ 트랙 폭 (허용 이탈 범위)
   ④ 권장 속도 (선택)
   ⑤ 곡률 (계산으로 얻을 수 있다)
```

```csharp
[System.Serializable]
public struct Waypoint
{
    public Vector3 position;
    public float width;                        // 트랙 반폭
    public float recommendedSpeed;             // 0 = 자동 계산

    [System.NonSerialized] public Vector3 forward;   // 다음 점 방향
    [System.NonSerialized] public float distanceFromStart;
    [System.NonSerialized] public float curvature;
}
```

```
   ★ Point Cloud라는 이름

   "위치 + 부가 정보를 가진 점들의 집합"
   → 순서가 있으면 경로(Path)
   → 순서가 없으면 단순 점군
```

### 3-2. 왜 격자나 NavMesh가 아닌가

**왜 필요한가** — 도구 선택의 이유.

| | 격자 A\* | NavMesh | **웨이포인트** |
|---|---|---|---|
| 경로 모양 | 최단 | 최단 | **의도한 라인** ★ |
| 트랙 폭 개념 | 없음 | 없음 | **있다** |
| 진행도 계산 | 어려움 | 어려움 | **쉽다** |
| 랩 판정 | 어려움 | 어려움 | **쉽다** |
| 제작 | 자동 | 자동 베이크 | **수동 배치** |
| 동적 변화 | 가능 | 가능 | 어려움 |

```
   ★ 레이싱에서는 웨이포인트가 표준이다

   ① 레벨 디자이너가 라인을 의도할 수 있다
   ② 진행도(0~1)를 바로 얻는다
   ③ 순위 계산이 단순하다
```

```
   ★ 하지만 조합도 가능하다

   메인 라인:  웨이포인트
   회피 기동:  주변 탐색 또는 NavMesh
```

### 3-5. 선형 보간 vs 스플라인

**왜 필요한가** — 점 사이를 어떻게 잇나.

```
   선형 보간                     Catmull-Rom 스플라인

   ●───●───●                     ●╮  ╭●╮  ╭●
      ╱   ╲                        ╰──╯ ╰──╯
   각지다                        부드럽다
```

```csharp
    // 선형
    public Vector3 GetPointLinear(int index, float t)
    {
        Vector3 a = waypoints[index].position;
        Vector3 b = waypoints[(index + 1) % waypoints.Count].position;

        return Vector3.Lerp(a, b, t);
    }
```

**Catmull-Rom 스플라인**

```
   ★ 4개 점으로 가운데 두 점 사이를 보간

   P0 ──── P1 ═══════ P2 ──── P3
            ↑ 이 구간을 계산
            (P0, P3는 방향 참고용)
```

```csharp
    public static Vector3 CatmullRom(Vector3 p0, Vector3 p1,
                                     Vector3 p2, Vector3 p3, float t)
    {
        float t2 = t * t;
        float t3 = t2 * t;

        return 0.5f * (
            2f * p1 +
            (-p0 + p2) * t +
            (2f * p0 - 5f * p1 + 4f * p2 - p3) * t2 +
            (-p0 + 3f * p1 - 3f * p2 + p3) * t3
        );
    }
```

```
   ★ Catmull-Rom의 성질

   ① 모든 제어점을 반드시 지난다  ★
   ② C1 연속 (기울기가 이어진다)
   ③ 계산이 단순하다
```

```
   ★ 베지에와의 차이 (Day 80)

   베지에:      제어점을 지나지 않는다 (당기기만)
   Catmull-Rom: 제어점을 지난다  ★ 경로에 적합
```

```csharp
    public Vector3 GetPointSpline(int index, float t)
    {
        int n = waypoints.Count;

        // ★ 순환 처리
        Vector3 p0 = waypoints[(index - 1 + n) % n].position;
        Vector3 p1 = waypoints[index].position;
        Vector3 p2 = waypoints[(index + 1) % n].position;
        Vector3 p3 = waypoints[(index + 2) % n].position;

        return CatmullRom(p0, p1, p2, p3, t);
    }
```

```
   ⚠️ 열린 경로(순환 아님)에서는

   첫 점과 마지막 점을 중복해서 넣는다
   P0, P0, P1, P2, ..., Pn, Pn
```

### 3-6. 가장 가까운 점 찾기

**왜 필요한가** — 차의 현재 위치를 경로 위에 매핑한다.

```csharp
    // ✗ 단순 최근접 — 문제가 있다
    public int FindNearestIndex(Vector3 pos)
    {
        int best = 0;
        float bestSq = float.MaxValue;

        for (int i = 0; i < waypoints.Count; i++)
        {
            float sq = (waypoints[i].position - pos).sqrMagnitude;
            if (sq < bestSq) { bestSq = sq; best = i; }
        }

        return best;
    }
```

```
   ⚠️ 문제 — 트랙이 겹치는 구간

   ┌──────────────────────┐
   │   P5 ──────── P6     │
   │   ═════════════      │  ← 다리 아래
   │   P20 ─────── P21    │
   └──────────────────────┘

   차가 P5 근처에 있는데 P20이 더 가까울 수 있다
   → 진행도가 갑자기 튄다
   → 랩 판정이 꼬인다
```

**해결 1 — 이전 인덱스 근처만 탐색**

```csharp
    private int lastIndex;

    public int FindNearestIndex(Vector3 pos, int searchRange = 12)
    {
        int n = waypoints.Count;
        int best = lastIndex;
        float bestSq = float.MaxValue;

        // ★ 이전 인덱스 주변만 본다
        for (int offset = -searchRange / 3; offset <= searchRange; offset++)
        {
            int i = ((lastIndex + offset) % n + n) % n;

            float sq = (waypoints[i].position - pos).sqrMagnitude;
            if (sq < bestSq) { bestSq = sq; best = i; }
        }

        lastIndex = best;
        return best;
    }
```

```
   ★ 앞쪽을 더 넓게 본다

   뒤로 4칸, 앞으로 12칸
   → 역주행은 조금만 허용
```

**해결 2 — 진행 방향 필터**

### 3-7. 진행도와 중심선 거리

**왜 필요한가** — 순위 계산과 이탈 판정.

```csharp
    public struct PathSample
    {
        public int index;                      // 가장 가까운 점
        public float segmentT;                 // 구간 내 비율 (0~1)
        public Vector3 closestPoint;           // 중심선 위의 점
        public float lateralDistance;          // 중심선에서의 거리
        public float distanceAlongPath;        // 시작부터의 거리
        public bool isOffTrack;
    }

    public PathSample Sample(Vector3 pos, Vector3 forward)
    {
        int i = FindNearestIndex(pos);
        int next = (i + 1) % waypoints.Count;

        Vector3 a = waypoints[i].position;
        Vector3 b = waypoints[next].position;

        // ★ 선분 위의 가장 가까운 점
        Vector3 ab = b - a;
        float len2 = ab.sqrMagnitude;

        float t = len2 > 0.0001f
            ? Mathf.Clamp01(Vector3.Dot(pos - a, ab) / len2)
            : 0f;

        Vector3 closest = a + ab * t;

        // ★ 수직 거리 (y 무시)
        Vector3 diff = pos - closest;
        diff.y = 0;
        float lateral = diff.magnitude;

        float width = Mathf.Lerp(waypoints[i].width, waypoints[next].width, t);

        return new PathSample
        {
            index = i,
            segmentT = t,
            closestPoint = closest,
            lateralDistance = lateral,
            distanceAlongPath = waypoints[i].distanceFromStart
                                + Vector3.Distance(a, closest),
            isOffTrack = lateral > width,
        };
    }
```

```
   ★ 선분 위의 최근접점 공식

   t = dot(P - A, B - A) / |B - A|²
   closest = A + (B - A) × clamp(t, 0, 1)
```

```
        P (차 위치)
        │
        │ lateral
        ▼
   A────●────────B
        closest
        ←─ t ─→
```

```
   ★ 진행도 (0~1)

   progress = distanceAlongPath / totalLength
```

### 3-8. 곡률 계산

**왜 필요한가** — 코너를 미리 알아야 감속할 수 있다.

```csharp
    private void CalculateCurvature()
    {
        int n = waypoints.Count;

        for (int i = 0; i < n; i++)
        {
            Vector3 prev = waypoints[(i - 1 + n) % n].position;
            Vector3 cur = waypoints[i].position;
            Vector3 next = waypoints[(i + 1) % n].position;

            Vector3 inDir = (cur - prev).normalized;
            Vector3 outDir = (next - cur).normalized;

            // ★ 방향 변화 각도
            float angle = Vector3.Angle(inDir, outDir);

            Waypoint wp = waypoints[i];
            wp.curvature = angle;                        // 0 = 직선, 90 = 급코너
            waypoints[i] = wp;
        }
    }
```

```
   ★ 곡률에 따른 권장 속도

   0도    →  최고 속도
   30도   →  70%
   60도   →  45%
   90도+  →  30%
```

```csharp
    public float GetRecommendedSpeed(int index, float maxSpeed)
    {
        Waypoint wp = waypoints[index];

        if (wp.recommendedSpeed > 0) return wp.recommendedSpeed;   // 수동 지정

        // ★ 앞쪽 몇 개 점의 최대 곡률을 본다
        float maxCurve = 0;

        for (int k = 0; k < lookaheadForSpeed; k++)
        {
            int i = (index + k) % waypoints.Count;
            if (waypoints[i].curvature > maxCurve) maxCurve = waypoints[i].curvature;
        }

        float factor = Mathf.Clamp01(1f - maxCurve / 90f);
        factor = Mathf.Lerp(0.3f, 1f, factor);   // 최소 30%

        return maxSpeed * factor;
    }
```

```
   ★ 앞을 미리 보는 것이 핵심

   현재 점의 곡률만 보면 코너에 들어가서야 감속한다
   → 이미 늦었다
```

### 3-9. 선행 지점 (Lookahead)

**왜 필요한가** — Day 93의 AI 조향에 쓴다.

```csharp
    public Vector3 GetLookaheadPoint(Vector3 pos, float distance)
    {
        PathSample s = Sample(pos, Vector3.forward);

        float target = s.distanceAlongPath + distance;

        // ★ 순환
        if (target > TotalLength) target -= TotalLength;

        return GetPointAtDistance(target);
    }

    public Vector3 GetPointAtDistance(float dist)
    {
        dist = Mathf.Repeat(dist, TotalLength);

        // ★ 이진 탐색으로 구간 찾기
        int lo = 0, hi = waypoints.Count - 1;

        while (lo < hi)
        {
            int mid = (lo + hi + 1) / 2;
            if (waypoints[mid].distanceFromStart <= dist) lo = mid;
            else hi = mid - 1;
        }

        int next = (lo + 1) % waypoints.Count;

        float segStart = waypoints[lo].distanceFromStart;
        float segLen = Vector3.Distance(waypoints[lo].position,
                                        waypoints[next].position);

        float t = segLen > 0.0001f ? (dist - segStart) / segLen : 0;

        return useSpline
            ? GetPointSpline(lo, t)
            : Vector3.Lerp(waypoints[lo].position, waypoints[next].position, t);
    }
```

```
   ★ 이진 탐색

   거리 배열이 정렬돼 있으므로 O(log n)
   → 점 1000개도 10번 비교
```

```
   ★ Mathf.Repeat(x, len)

   0 ~ len 범위로 순환시킨다
   → 음수도 처리 (x % len 과 다르다)
```

```csharp
public class TrackPath : MonoBehaviour
{

    [SerializeField] private List<Waypoint> waypoints = new List<Waypoint>();
    [SerializeField] private bool isLoop = true;
    [SerializeField] private bool useSpline = true;

    [Header("기본값")]
    [SerializeField] private float defaultWidth = 6f;

    [Header("속도")]
    [SerializeField] private int lookaheadForSpeed = 4;
    [SerializeField] private float minSpeedFactor = 0.3f;

    [Header("기즈모")]
    [SerializeField] private bool showGizmos = true;
    [SerializeField] private bool showIndices = false;
    [SerializeField] private bool showWidth = true;
    [SerializeField] private bool showSpline = true;

    public IReadOnlyList<Waypoint> Waypoints => waypoints;
    public int Count => waypoints.Count;
    public float TotalLength { get; private set; }
    public bool IsLoop => isLoop;

    private int lastIndex;

    void Awake() { Rebuild(); }

    void OnValidate() { if (waypoints.Count >= 2) Rebuild(); }

    // ─── 빌드 ───

    public void Rebuild()
    {
        int n = waypoints.Count;
        if (n < 2) return;

        float dist = 0;

        for (int i = 0; i < n; i++)
        {
            Waypoint wp = waypoints[i];

            int next = isLoop ? (i + 1) % n : Mathf.Min(i + 1, n - 1);
            int prev = isLoop ? (i - 1 + n) % n : Mathf.Max(i - 1, 0);

            // 방향
            Vector3 dir = waypoints[next].position - wp.position;
            wp.forward = dir.sqrMagnitude > 0.0001f ? dir.normalized : Vector3.forward;

            // 누적 거리
            wp.distanceFromStart = dist;

            // 곡률
            Vector3 inDir = (wp.position - waypoints[prev].position).normalized;
            Vector3 outDir = wp.forward;
            wp.curvature = Vector3.Angle(inDir, outDir);

            if (wp.width <= 0) wp.width = defaultWidth;

            waypoints[i] = wp;

            if (i < n - 1 || isLoop)
                dist += Vector3.Distance(wp.position, waypoints[next].position);
        }

        TotalLength = dist;
    }
}
```

### Step 6 — 스플라인

3-5절의 `CatmullRom`과 `GetPointSpline`을 구현한다.

```csharp
    public static Vector3 CatmullRom(Vector3 p0, Vector3 p1,
                                     Vector3 p2, Vector3 p3, float t)
    {
        float t2 = t * t;
        float t3 = t2 * t;

        return 0.5f * (
            2f * p1 +
            (-p0 + p2) * t +
            (2f * p0 - 5f * p1 + 4f * p2 - p3) * t2 +
            (-p0 + 3f * p1 - 3f * p2 + p3) * t3
        );
    }

    public Vector3 GetPointSpline(int index, float t)
    {
        int n = waypoints.Count;

        Vector3 p0 = waypoints[Wrap(index - 1, n)].position;
        Vector3 p1 = waypoints[Wrap(index, n)].position;
        Vector3 p2 = waypoints[Wrap(index + 1, n)].position;
        Vector3 p3 = waypoints[Wrap(index + 2, n)].position;

        return CatmullRom(p0, p1, p2, p3, t);
    }

    private static int Wrap(int i, int n) => ((i % n) + n) % n;
```

### Step 7 — 스플라인 튐 확인

**점을 매우 가깝게 두 개 배치한다.**

**✅ 이렇게 하면**

```
   ② Centripetal Catmull-Rom 사용 (α=0.5)
```

```csharp
    // Centripetal 버전 (튐이 적다)
    public static Vector3 CatmullRomCentripetal(
        Vector3 p0, Vector3 p1, Vector3 p2, Vector3 p3, float t, float alpha = 0.5f)
    {
        float t0 = 0;
        float t1 = t0 + Mathf.Pow(Vector3.Distance(p0, p1), alpha);
        float t2 = t1 + Mathf.Pow(Vector3.Distance(p1, p2), alpha);
        float t3 = t2 + Mathf.Pow(Vector3.Distance(p2, p3), alpha);

        float tt = Mathf.Lerp(t1, t2, t);

        Vector3 a1 = (t1 - tt) / (t1 - t0) * p0 + (tt - t0) / (t1 - t0) * p1;
        Vector3 a2 = (t2 - tt) / (t2 - t1) * p1 + (tt - t1) / (t2 - t1) * p2;
        Vector3 a3 = (t3 - tt) / (t3 - t2) * p2 + (tt - t2) / (t3 - t2) * p3;

        Vector3 b1 = (t2 - tt) / (t2 - t0) * a1 + (tt - t0) / (t2 - t0) * a2;
        Vector3 b2 = (t3 - tt) / (t3 - t1) * a2 + (tt - t1) / (t3 - t1) * a3;

        return (t2 - tt) / (t2 - t1) * b1 + (tt - t1) / (t2 - t1) * b2;
    }
```


```csharp
    public int FindNearestIndex(Vector3 pos, bool useCache = true)
    {
        int n = waypoints.Count;
        if (n == 0) return 0;

        int best = 0;
        float bestSq = float.MaxValue;

        if (useCache)
        {
            // ★ 이전 인덱스 주변만
            for (int offset = -4; offset <= 12; offset++)
            {
                int i = Wrap(lastIndex + offset, n);

                float sq = (waypoints[i].position - pos).sqrMagnitude;
                if (sq < bestSq) { bestSq = sq; best = i; }
            }
        }
        else
        {
            for (int i = 0; i < n; i++)
            {
                float sq = (waypoints[i].position - pos).sqrMagnitude;
                if (sq < bestSq) { bestSq = sq; best = i; }
            }
        }

        lastIndex = best;
        return best;
    }
```

### Step 10 — Sample

```csharp
    public PathSample Sample(Vector3 pos)
    {
        int n = waypoints.Count;
        int i = FindNearestIndex(pos);
        int next = Wrap(i + 1, n);

        Vector3 a = waypoints[i].position;
        Vector3 b = waypoints[next].position;

        Vector3 ab = b - a;
        float len2 = ab.sqrMagnitude;

        float t = len2 > 0.0001f
            ? Mathf.Clamp01(Vector3.Dot(pos - a, ab) / len2)
            : 0f;

        Vector3 closest = a + ab * t;

        Vector3 diff = pos - closest;
        diff.y = 0;
        float lateral = diff.magnitude;

        float width = Mathf.Lerp(waypoints[i].width, waypoints[next].width, t);

        float along = waypoints[i].distanceFromStart + Vector3.Distance(a, closest);

        return new PathSample
        {
            index = i,
            segmentT = t,
            closestPoint = closest,
            forward = ab.normalized,
            lateralDistance = lateral,
            distanceAlongPath = along,
            progress = TotalLength > 0 ? along / TotalLength : 0,
            isOffTrack = lateral > width,
        };
    }
```

**✅ 여기까지 하면** — 차의 진행도와 중심선 거리를 얻는다.

```csharp
    public float GetRecommendedSpeed(int index, float maxSpeed)
    {
        Waypoint wp = waypoints[index];

        if (wp.recommendedSpeed > 0) return wp.recommendedSpeed;

        float maxCurve = 0;

        for (int k = 0; k < lookaheadForSpeed; k++)
        {
            int i = Wrap(index + k, waypoints.Count);
            if (waypoints[i].curvature > maxCurve) maxCurve = waypoints[i].curvature;
        }

        float factor = Mathf.Clamp01(1f - maxCurve / 90f);
        factor = Mathf.Lerp(minSpeedFactor, 1f, factor);

        return maxSpeed * factor;
    }
```

```csharp
    }
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **점 순서가 꼬임** | Hierarchy 순서 | 이름 3자리 + 정렬 |
| 경로가 안 보임 | 기즈모 토글 | Scene 뷰 Gizmos ✔ |
| **인덱스가 튐** | 전체 탐색 + 겹친 트랙 | 캐시 + 범위 제한 |
| 역주행 판정 | 방향 미고려 | `Dot`으로 필터 |
| 스플라인이 부풀음 | 점 간격 불균등 | Centripetal 또는 균등 배치 |
| 스플라인 0으로 나눔 | 점이 겹침 | 최소 간격 강제 |
| 진행도가 뒤로 감 | 캐시 범위가 뒤로 넓음 | 앞을 더 넓게 |
| 정상 주행 중 이탈 판정 | 트랙 폭 좁음 | 실제보다 넓게 |
| 리스폰 위치가 이상 | 중심선 미사용 | `closestPoint` 사용 |
| 리스폰 후 튀어나감 | velocity 미초기화 | `ResetCar` |
| 총 길이가 0 | `Rebuild` 미호출 | `Awake`/`OnValidate` |
| 순환 처리 오류 | 음수 인덱스 | `((i % n) + n) % n` |
