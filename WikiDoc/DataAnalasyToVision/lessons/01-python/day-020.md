## ② 왜 필요한가

어제 만든 것은 도형뿐이었습니다. 게임처럼 보이려면 **그림**이 필요합니다.

그리고 어제의 공은 **혼자 움직였습니다.** 플레이어가 조종할 수 없으면 게임이 아닙니다.

오늘 배우는 두 가지가 그 간극을 메웁니다.

특히 **키 입력의 두 방식**을 구분하는 것이 중요합니다.

```python
# 이벤트 방식 — 누른 "순간" 한 번
if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
    shoot()

# 상태 방식 — 누르고 "있는 동안" 계속
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:
    player.x -= 5
```

이걸 반대로 쓰면 **캐릭터가 뚝뚝 끊기며 움직이거나, 총알이 1초에 60발 나갑니다.**
초보자가 반드시 한 번은 겪는 문제입니다.

## ③ 개념 설명

### Surface — pygame의 그림판

pygame에서 **모든 이미지는 `Surface` 객체**입니다.

| Surface | 무엇 |
|---|---|
| `screen` | 화면 전체 (`display.set_mode()` 가 돌려준 것) |
| `image.load()` 결과 | 파일에서 불러온 그림 |
| `font.render()` 결과 | 글자를 그린 그림 |

**`blit`** 은 한 Surface를 다른 Surface 위에 붙이는 동작입니다. (block transfer 의 줄임말)

```python
screen.blit(붙일_이미지, (x, y))
```

### 이미지 불러오기

```python
image = pygame.image.load("player.png")
image = pygame.image.load("player.png").convert_alpha()
```

| 메서드 | 언제 |
|---|---|
| `.convert()` | 투명 부분이 **없는** 이미지 (JPG 등) |
| `.convert_alpha()` | 투명 부분이 **있는** 이미지 (PNG) |
| (아무것도 안 붙임) | 동작은 하지만 **느립니다** |

> ⚠️ **`convert_alpha()` 를 빼먹으면** PNG의 투명 배경이 검은 사각형으로 나오거나, 프레임이 떨어집니다.
> **PNG는 항상 `.convert_alpha()`** 를 붙이세요.

> ⚠️ **`convert` 계열은 `set_mode()` 이후에만 호출할 수 있습니다.** 창을 만들기 전에 부르면 에러가 납니다.

### 크기 조절과 회전

```python
image = pygame.transform.scale(image, (64, 64))          # 지정 크기로
image = pygame.transform.scale_by(image, 2)              # 배율로
image = pygame.transform.rotate(image, 45)               # 45도 회전 (반시계)
image = pygame.transform.flip(image, True, False)        # 좌우 반전
```

> **`transform` 은 새 Surface 를 반환합니다.** 원본은 바뀌지 않으므로 결과를 받아야 합니다.
> 그리고 **루프 안에서 매 프레임 변환하지 마세요.** 미리 변환해 두고 재사용합니다.

### 이미지의 Rect 얻기

```python
image = pygame.image.load("player.png").convert_alpha()
rect = image.get_rect()                       # (0, 0, 이미지너비, 이미지높이)

rect = image.get_rect(center=(400, 300))      # 중심을 지정하며 생성
rect = image.get_rect(topleft=(100, 50))
rect = image.get_rect(midbottom=(400, 600))
```

이렇게 하면 **이미지와 위치를 한 쌍으로** 관리할 수 있습니다.

```python
screen.blit(image, rect)      # Rect 를 그대로 넘겨도 됩니다
```

### 이미지가 없을 때 — 대체 Surface 만들기

실습용 이미지가 없어도 진행할 수 있게, **코드로 그림을 만들 수 있습니다.**

```python
# 32x32 크기의 빈 Surface (투명)
surf = pygame.Surface((32, 32), pygame.SRCALPHA)
pygame.draw.circle(surf, (231, 76, 60), (16, 16), 14)
```

> 이 방법으로 만든 Surface도 `blit` 으로 붙이고 `get_rect()` 로 위치를 잡을 수 있습니다.
> **오늘 실습은 이미지 파일 없이도 전부 실행됩니다.**

### 키 입력 방식 ① — 이벤트 (누른 순간)

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            print("스페이스를 눌렀다")
    elif event.type == pygame.KEYUP:
        if event.key == pygame.K_SPACE:
            print("스페이스를 뗐다")
```

**누르는 순간 딱 한 번** 발생합니다. 계속 누르고 있어도 한 번뿐입니다.

| 쓰는 곳 | 이유 |
|---|---|
| 총알 발사 | 한 번 누르면 한 발 |
| 점프 | 한 번 누르면 한 번 |
| 메뉴 선택 | 한 번 |
| 일시정지 토글 | 한 번 |

### 키 입력 방식 ② — 상태 (누르고 있는 동안)

```python
keys = pygame.key.get_pressed()

if keys[pygame.K_LEFT]:
    x -= 5
if keys[pygame.K_RIGHT]:
    x += 5
```

**매 프레임 "지금 눌려 있는가"** 를 확인합니다.

| 쓰는 곳 | 이유 |
|---|---|
| 캐릭터 이동 | 누르고 있는 동안 계속 |
| 조준 | 계속 |
| 가속 | 계속 |

### 두 방식 비교

```
        키를 3초간 누르고 있으면…

이벤트 방식(KEYDOWN):   ●                        → 1번 발생
상태 방식(get_pressed): ●●●●●●●●●●●●●●●●●●●●●●  → 매 프레임 참
```

> **`if` 를 `elif` 로 쓰지 마세요.**
> ```python
> if keys[pygame.K_LEFT]:  x -= 5
> elif keys[pygame.K_UP]:  y -= 5      # ❌ 대각선 이동 불가
> ```
> `if` 를 나란히 써야 왼쪽+위를 동시에 눌러 대각선으로 갈 수 있습니다.

### 주요 키 상수

| 상수 | 키 |
|---|---|
| `K_LEFT` `K_RIGHT` `K_UP` `K_DOWN` | 방향키 |
| `K_a` ~ `K_z` | 알파벳 |
| `K_0` ~ `K_9` | 숫자 |
| `K_SPACE` | 스페이스 |
| `K_RETURN` | 엔터 |
| `K_ESCAPE` | ESC |
| `K_LSHIFT` `K_RSHIFT` | 시프트 |
| `K_TAB` | 탭 |

### 프레임 독립 이동

```python
# 방식 A — 프레임 기준 (간단, 초보 단계 권장)
x += 5                              # 프레임당 5픽셀 → 60fps 에서 초당 300픽셀

# 방식 B — 시간 기준 (정확)
dt = clock.tick(60) / 1000          # 지난 프레임 이후 경과 초
x += 300 * dt                       # 초당 300픽셀 (FPS와 무관)
```

> 방식 B는 프레임이 떨어져도 게임 속도가 일정합니다.
> 오늘은 방식 A로 시작하고, 마지막 실습에서 B를 소개합니다.

### 대각선 이동 속도 문제

```python
if keys[K_LEFT]:  x -= 5
if keys[K_UP]:    y -= 5
```

왼쪽+위를 동시에 누르면 실제 이동 거리는 `√(5² + 5²) ≈ 7.07` 입니다.
**대각선이 직선보다 약 1.41배 빠릅니다.**

**해결 — 방향 벡터를 정규화합니다.**

```python
dx = dy = 0
if keys[K_LEFT]:  dx -= 1
if keys[K_RIGHT]: dx += 1
if keys[K_UP]:    dy -= 1
if keys[K_DOWN]:  dy += 1

if dx != 0 and dy != 0:                  # 대각선이면
    dx *= 0.7071                         # 1/√2
    dy *= 0.7071

x += dx * SPEED
y += dy * SPEED
```

### 화면 경계 처리

```python
# Rect 의 편의 속성을 쓰면 간단합니다
rect.left = max(rect.left, 0)
rect.right = min(rect.right, SCREEN_WIDTH)
rect.top = max(rect.top, 0)
rect.bottom = min(rect.bottom, SCREEN_HEIGHT)
```

pygame은 아예 이런 메서드도 제공합니다.

```python
rect.clamp_ip(screen.get_rect())      # 화면 안으로 강제 (in place)
```

### Step 1. 이미지 없이 캐릭터 만들기

실습용 이미지가 없어도 되도록, 코드로 그림을 만듭니다.
`game02.py` 를 만들어 실행합니다.

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Day 020 - Surface 만들기")
clock = pygame.time.Clock()

BG = (20, 22, 32)
WHITE = (240, 240, 240)


def make_player_surface(size=48):
    """플레이어 모양의 Surface 를 코드로 만듭니다."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)   # 투명 배경

    # 몸통 (삼각형 우주선)
    pygame.draw.polygon(surf, (52, 152, 219), [
        (size // 2, 0),
        (size, size),
        (size // 2, size * 0.75),
        (0, size),
    ])
    # 조종석
    pygame.draw.circle(surf, (241, 196, 15), (size // 2, size // 2), size // 6)

    return surf


def make_enemy_surface(size=40):
    """적 모양의 Surface."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, (231, 76, 60), (size // 2, size // 2), size // 2)
    pygame.draw.circle(surf, (192, 57, 43), (size // 2, size // 2), size // 2, 3)
    # 눈
    pygame.draw.circle(surf, WHITE, (size // 3, size // 3), size // 8)
    pygame.draw.circle(surf, WHITE, (size * 2 // 3, size // 3), size // 8)
    return surf


# ── 이미지(Surface) 준비 — 루프 밖에서 한 번만! ──
player_img = make_player_surface(48)
enemy_img = make_enemy_surface(40)

# get_rect() 로 위치 잡기
player_rect = player_img.get_rect(center=(400, 500))
enemy_rect = enemy_img.get_rect(center=(400, 120))

font = pygame.font.SysFont("malgungothic", 18)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill(BG)

    # blit — Surface 를 화면에 붙이기
    screen.blit(player_img, player_rect)
    screen.blit(enemy_img, enemy_rect)

    info = [
        f"player_rect = {player_rect}",
        f"  center = {player_rect.center}",
        f"  topleft = {player_rect.topleft}",
        f"  size = {player_rect.size}",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, WHITE), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

실행 결과 — 파란 우주선과 빨간 적이 표시됩니다.

> **이미지 파일이 있다면** 이렇게 대체하면 됩니다.
> ```python
> player_img = pygame.image.load("assets/player.png").convert_alpha()
> player_img = pygame.transform.scale(player_img, (48, 48))
> player_rect = player_img.get_rect(center=(400, 500))
> ```
> 나머지 코드는 **한 글자도 바뀌지 않습니다.** Surface 는 만들어진 방법과 무관하게 똑같이 동작합니다.

### Step 2. 키 입력 두 방식 비교하기

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Day 020 - 키 입력 두 방식")
clock = pygame.time.Clock()

BG = (20, 22, 32)
WHITE = (240, 240, 240)
BLUE = (52, 152, 219)
RED = (231, 76, 60)

font = pygame.font.SysFont("malgungothic", 20)
big_font = pygame.font.SysFont("malgungothic", 28)

event_count = 0        # 이벤트 방식: 누른 "순간"만 셈
state_count = 0        # 상태 방식: 누르고 "있는 동안" 계속 셈

running = True
while running:
    # ── ① 이벤트 방식 ──
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                event_count += 1          # 누를 때 딱 한 번
            elif event.key == pygame.K_r:
                event_count = 0
                state_count = 0
            elif event.key == pygame.K_ESCAPE:
                running = False

    # ── ② 상태 방식 ──
    keys = pygame.key.get_pressed()
    if keys[pygame.K_SPACE]:
        state_count += 1                  # 누르고 있는 동안 매 프레임

    # ── 그리기 ──
    screen.fill(BG)

    title = big_font.render("스페이스를 3초간 눌러 보세요", True, WHITE)
    screen.blit(title, (150, 60))

    lines = [
        (f"① 이벤트 방식 (KEYDOWN):  {event_count}", BLUE),
        (f"② 상태 방식 (get_pressed): {state_count}", RED),
        ("", WHITE),
        ("→ 이벤트: 발사·점프·메뉴 선택에 사용", WHITE),
        ("→ 상태  : 이동·조준·가속에 사용", WHITE),
        ("", WHITE),
        ("R=초기화   ESC=종료", WHITE),
    ]
    for i, (line, color) in enumerate(lines):
        screen.blit(font.render(line, True, color), (150, 160 + i * 32))

    # 시각화 막대
    pygame.draw.rect(screen, BLUE, (150, 420, min(event_count * 20, 500), 30))
    pygame.draw.rect(screen, RED, (150, 460, min(state_count * 2, 500), 30))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**직접 해 보세요** — 스페이스를 3초간 누르고 있으면:

```
① 이벤트 방식:  1
② 상태 방식:  180      (60 FPS × 3초)
```

> **이 차이를 몸으로 느끼는 것이 오늘의 핵심입니다.**
> 총알 발사를 상태 방식으로 만들면 3초에 180발이 나갑니다.

### Step 3. 캐릭터 조종하기

```python
import pygame

# ══════════ 설정 ══════════
WIDTH, HEIGHT = 800, 600
FPS = 60
SPEED = 6
DIAGONAL = 0.7071          # 1 / √2

BG = (20, 22, 32)
WHITE = (240, 240, 240)
GRAY = (60, 62, 75)


def make_player(size=48):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, (52, 152, 219), [
        (size // 2, 0), (size, size), (size // 2, size * 0.75), (0, size),
    ])
    pygame.draw.circle(surf, (241, 196, 15), (size // 2, size // 2), size // 6)
    return surf


pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Day 020 - 캐릭터 조종")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

player_img = make_player(48)
player_rect = player_img.get_rect(center=(WIDTH // 2, HEIGHT // 2))

screen_rect = screen.get_rect()
trail = []                 # 이동 궤적
show_trail = True

running = True
while running:
    # ── ① 이벤트 (한 번만 반응할 것) ──
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_t:
                show_trail = not show_trail       # 토글
                trail.clear()
            elif event.key == pygame.K_r:
                player_rect.center = (WIDTH // 2, HEIGHT // 2)
                trail.clear()

    # ── ② 상태 (계속 반응할 것) ──
    keys = pygame.key.get_pressed()

    dx = dy = 0
    if keys[pygame.K_LEFT] or keys[pygame.K_a]:
        dx -= 1
    if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
        dx += 1
    if keys[pygame.K_UP] or keys[pygame.K_w]:
        dy -= 1                                   # 위는 y 감소!
    if keys[pygame.K_DOWN] or keys[pygame.K_s]:
        dy += 1

    # 대각선 보정
    if dx != 0 and dy != 0:
        dx *= DIAGONAL
        dy *= DIAGONAL

    # 시프트로 가속
    speed = SPEED * 2 if keys[pygame.K_LSHIFT] else SPEED

    player_rect.x += int(dx * speed)
    player_rect.y += int(dy * speed)

    # 화면 밖으로 못 나가게
    player_rect.clamp_ip(screen_rect)

    # 궤적 기록
    if show_trail and (dx != 0 or dy != 0):
        trail.append(player_rect.center)
        if len(trail) > 120:
            trail.pop(0)                          # 오래된 것부터 제거

    # ── ③ 그리기 ──
    screen.fill(BG)

    # 궤적
    for i, pos in enumerate(trail):
        radius = int(1 + 4 * i / len(trail))
        pygame.draw.circle(screen, GRAY, pos, radius)

    screen.blit(player_img, player_rect)

    info = [
        f"위치: {player_rect.center}",
        f"방향: ({dx:+.2f}, {dy:+.2f})   속도: {speed}",
        f"FPS: {clock.get_fps():.0f}",
        "",
        "방향키/WASD=이동   SHIFT=가속",
        "T=궤적 토글   R=중앙으로   ESC=종료",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, WHITE), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 5가지**
> - **이벤트는 `for event` 안에, 이동은 `keys` 로** — 두 방식을 목적에 맞게 나눠 썼습니다.
> - `if` 를 나란히 써서 **대각선 이동**이 됩니다. `elif` 로 바꿔 보면 차이를 알 수 있습니다.
> - `dy -= 1` 로 위쪽 이동 — **y축은 아래로 증가**하기 때문입니다.
> - `clamp_ip(screen_rect)` 한 줄로 경계 처리가 끝납니다.
> - `trail.pop(0)` — 리스트가 무한히 커지지 않게 오래된 것을 지웁니다. **메모리 관리의 기본**입니다.

### Step 4. 클래스로 정리하기 (오늘의 종합 예제)

[Day 016~018](day-016.md)에서 배운 클래스를 pygame에 적용합니다. 내일부터 이 구조로 게임을 만듭니다.

```python
import pygame
import random

# ══════════ 설정 ══════════
WIDTH, HEIGHT = 800, 600
FPS = 60

BG = (18, 20, 30)
WHITE = (240, 240, 240)
GRAY = (60, 62, 75)
YELLOW = (241, 196, 15)


# ══════════ Surface 생성 함수 ══════════
def make_player_surface(size=48):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, (52, 152, 219), [
        (size // 2, 0), (size, size), (size // 2, size * 0.75), (0, size),
    ])
    pygame.draw.circle(surf, YELLOW, (size // 2, size // 2), size // 6)
    return surf


def make_coin_surface(size=24):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, YELLOW, (size // 2, size // 2), size // 2)
    pygame.draw.circle(surf, (200, 160, 10), (size // 2, size // 2), size // 2, 2)
    return surf


# ══════════ 클래스 ══════════
class Player:
    """플레이어. 이미지와 위치, 이동 로직을 함께 가집니다."""

    SPEED = 6
    DIAGONAL = 0.7071

    def __init__(self, x, y):
        self.image = make_player_surface(48)
        self.rect = self.image.get_rect(center=(x, y))
        self.score = 0
        self.boost = False

    def handle_input(self, keys):
        """키 상태를 받아 이동 방향을 계산합니다."""
        dx = dy = 0

        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        if dx != 0 and dy != 0:
            dx *= Player.DIAGONAL
            dy *= Player.DIAGONAL

        self.boost = keys[pygame.K_LSHIFT]
        speed = Player.SPEED * 2 if self.boost else Player.SPEED

        self.rect.x += int(dx * speed)
        self.rect.y += int(dy * speed)

    def update(self, bounds):
        """화면 밖으로 나가지 않게 합니다."""
        self.rect.clamp_ip(bounds)

    def draw(self, surface):
        surface.blit(self.image, self.rect)


class Coin:
    """먹을 수 있는 코인."""

    def __init__(self, x, y):
        self.image = make_coin_surface(24)
        self.rect = self.image.get_rect(center=(x, y))
        self.timer = 0

    def update(self):
        """살짝 위아래로 흔들립니다."""
        self.timer += 1
        self.rect.y += 1 if (self.timer // 20) % 2 == 0 else -1

    def draw(self, surface):
        surface.blit(self.image, self.rect)

    @classmethod
    def create_random(cls, margin=40):
        """화면 안 무작위 위치에 코인을 만듭니다."""
        return cls(
            random.randint(margin, WIDTH - margin),
            random.randint(margin, HEIGHT - margin),
        )


# ══════════ 초기화 ══════════
pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Day 020 - 코인 먹기")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 20)
big_font = pygame.font.SysFont("malgungothic", 40)

screen_rect = screen.get_rect()
player = Player(WIDTH // 2, HEIGHT // 2)
coins = [Coin.create_random() for _ in range(6)]

time_left = 30 * FPS          # 30초
game_over = False

# ══════════ 게임 루프 ══════════
running = True
while running:
    # ── ① 이벤트 ──
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_r and game_over:
                player = Player(WIDTH // 2, HEIGHT // 2)
                coins = [Coin.create_random() for _ in range(6)]
                time_left = 30 * FPS
                game_over = False

    if not game_over:
        # ── ② 갱신 ──
        keys = pygame.key.get_pressed()
        player.handle_input(keys)
        player.update(screen_rect)

        for coin in coins:
            coin.update()

        # 충돌 검사 — 순회 중 삭제를 피하려고 복사본을 돕니다 (Day 011)
        for coin in coins[:]:
            if player.rect.colliderect(coin.rect):
                coins.remove(coin)
                player.score += 10
                coins.append(Coin.create_random())      # 새 코인 생성

        time_left -= 1
        if time_left <= 0:
            game_over = True

    # ── ③ 그리기 ──
    screen.fill(BG)

    for coin in coins:
        coin.draw(screen)

    player.draw(screen)

    # HUD
    seconds = max(time_left // FPS, 0)
    hud = [
        f"점수: {player.score}",
        f"남은 시간: {seconds}초",
        f"코인: {len(coins)}개",
        "이동=방향키/WASD   SHIFT=가속",
    ]
    for i, line in enumerate(hud):
        screen.blit(font.render(line, True, WHITE), (10, 10 + i * 24))

    # 시간 바
    bar_width = int(700 * time_left / (30 * FPS))
    pygame.draw.rect(screen, GRAY, (50, HEIGHT - 30, 700, 12))
    pygame.draw.rect(screen, YELLOW, (50, HEIGHT - 30, max(bar_width, 0), 12))

    if game_over:
        msg = big_font.render(f"종료!  최종 점수 {player.score}", True, YELLOW)
        sub = font.render("R=다시 시작   ESC=종료", True, WHITE)
        screen.blit(msg, msg.get_rect(center=(WIDTH // 2, HEIGHT // 2 - 20)))
        screen.blit(sub, sub.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 30)))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print(f"최종 점수: {player.score}")
```

> **눈여겨볼 점 6가지**
> - **`Player` 와 `Coin` 이 각자 `update()` 와 `draw()` 를 가집니다.** 이 구조가 내일부터 만들 게임의 표준입니다.
> - `handle_input(keys)` — 입력 처리를 클래스 안으로 넣었습니다. 메인 루프는 `player.handle_input(keys)` 한 줄입니다.
> - `Coin.create_random()` 은 `@classmethod` ([Day 017](day-017.md))로 만든 **팩토리 메서드**입니다. 객체를 만드는 방법이 여러 가지일 때 유용합니다.
> - `player.rect.colliderect(coin.rect)` — Rect 끼리의 충돌 판정입니다. [Day 024](day-024.md)에서 자세히 다룹니다.
> - `for coin in coins[:]` — **복사본을 순회**하며 원본을 수정합니다. [Day 011](day-011.md)에서 배운 그 함정입니다.
> - 게임 상태(`game_over`)에 따라 갱신을 멈추고 메시지를 띄웁니다. [Day 025](day-025.md)의 씬 관리로 발전합니다.

**2.** 마우스를 따라다니는 캐릭터를 만드세요. 단, 순간이동이 아니라 **일정 속도로 부드럽게** 따라와야 합니다.

<details>
<summary>답 보기</summary>

```python
import pygame

WIDTH, HEIGHT = 800, 600
SPEED = 5

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("마우스 추적")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

BG = (20, 22, 32)
WHITE = (240, 240, 240)


def make_follower(size=40):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, (46, 204, 113), (size // 2, size // 2), size // 2)
    return surf


img = make_follower(40)
rect = img.get_rect(center=(WIDTH // 2, HEIGHT // 2))

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # ── 마우스 위치 ──
    mx, my = pygame.mouse.get_pos()

    # ── 방향 벡터 계산 ──
    dx = mx - rect.centerx
    dy = my - rect.centery
    distance = (dx ** 2 + dy ** 2) ** 0.5

    # 충분히 가까우면 멈춤 (떨림 방지)
    if distance > SPEED:
        # 정규화 후 속도만큼 이동
        rect.centerx += int(dx / distance * SPEED)
        rect.centery += int(dy / distance * SPEED)

    # ── 그리기 ──
    screen.fill(BG)

    pygame.draw.line(screen, (60, 62, 75), rect.center, (mx, my), 1)
    pygame.draw.circle(screen, (231, 76, 60), (mx, my), 5)
    screen.blit(img, rect)

    info = [
        f"캐릭터: {rect.center}",
        f"마우스: ({mx}, {my})",
        f"거리: {distance:.1f}",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, WHITE), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**포인트 4가지**
- **방향 벡터 정규화** — `dx / distance` 는 항상 -1~1 사이가 되어, 거리에 상관없이 일정한 속도를 냅니다.
- `if distance > SPEED:` — 목표에 아주 가까울 때 멈춥니다. 안 하면 목표를 넘어갔다 되돌아오며 **떨립니다.**
- `pygame.mouse.get_pos()` 는 **상태 방식**입니다. 매 프레임 현재 위치를 알려 줍니다.
- 이 "정규화 후 이동" 패턴은 [Day 023](day-023.md)에서 **적이 플레이어를 추적하는 로직**으로 그대로 쓰입니다.
</details>

**3.** 아래 코드는 캐릭터가 대각선으로 움직일 때 더 빠릅니다. 원인과 해결책을 쓰세요.

```python
keys = pygame.key.get_pressed()
SPEED = 5

if keys[pygame.K_LEFT]:
    player.rect.x -= SPEED
if keys[pygame.K_RIGHT]:
    player.rect.x += SPEED
if keys[pygame.K_UP]:
    player.rect.y -= SPEED
if keys[pygame.K_DOWN]:
    player.rect.y += SPEED
```

<details>
<summary>답 보기</summary>

**원인 — 피타고라스 정리**

왼쪽+위를 동시에 누르면 x로 5, y로 5 움직입니다.
실제 이동 거리는 두 변이 5인 직각삼각형의 빗변입니다.

```
      5
   ┌──────
   │＼
 5 │  ＼  √(5² + 5²) ≈ 7.07
   │    ＼
```

**직선 이동 5픽셀 vs 대각선 이동 7.07픽셀 — 약 1.41배(√2) 빠릅니다.**

플레이어가 이걸 알면 항상 대각선으로만 움직이게 됩니다. 게임 밸런스가 무너집니다.

**해결 — 방향을 먼저 모으고 정규화합니다.**

```python
keys = pygame.key.get_pressed()
SPEED = 5
DIAGONAL = 0.7071          # 1 / √2 ≈ 0.7071

dx = dy = 0
if keys[pygame.K_LEFT]:
    dx -= 1
if keys[pygame.K_RIGHT]:
    dx += 1
if keys[pygame.K_UP]:
    dy -= 1
if keys[pygame.K_DOWN]:
    dy += 1

# 대각선이면 각 성분을 1/√2 로 줄임
if dx != 0 and dy != 0:
    dx *= DIAGONAL
    dy *= DIAGONAL

player.rect.x += int(dx * SPEED)
player.rect.y += int(dy * SPEED)
```

검산: `dx = dy = 0.7071 × 5 = 3.54` → 빗변 `√(3.54² + 3.54²) = 5.0` ✅

**더 일반적인 방법 — 벡터 길이로 나누기**

```python
length = (dx ** 2 + dy ** 2) ** 0.5
if length > 0:
    dx /= length
    dy /= length
```

이 방식은 대각선뿐 아니라 어떤 방향이든 일정한 속도를 보장합니다.
마우스 추적(2번 문제)에서 쓴 것과 **같은 계산**입니다.

> **주의 — 정수 변환 손실**
> `int(0.7071 * 5) = int(3.535) = 3` 이라 미세하게 어긋납니다.
> 정확하게 하려면 위치를 `float` 으로 관리하고 그릴 때만 `Rect` 에 반영합니다.
> ```python
> self.x += dx * SPEED          # float
> self.rect.centerx = int(self.x)
> ```
> [Day 021](day-021.md)에서 이 방식으로 정리합니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| Surface | pygame의 모든 이미지. `screen` 도 Surface |
| 불러오기 | `image.load(경로)` + **PNG는 `.convert_alpha()`** |
| 변환 | `transform.scale/rotate/flip` — **새 Surface 반환, 루프 밖에서** |
| 위치 | `image.get_rect(center=(x, y))` |
| 그리기 | `screen.blit(image, rect)` |
| 이벤트 방식 | `KEYDOWN` — 누른 **순간 한 번**. 발사·점프·토글 |
| 상태 방식 | `key.get_pressed()` — 누르는 **동안 계속**. 이동·가속 |
| 대각선 | `if` 를 나란히 (elif ❌) + **정규화**(× 0.7071) |
| 경계 | `rect.clamp_ip(screen.get_rect())` |
| 회전 | **원본을 보관**하고 매번 원본에서 회전 |

**오늘 반드시 기억할 세 가지**
> ① **이동은 상태 방식, 발사는 이벤트 방식.**
> ② PNG는 `.convert_alpha()`, 이미지 변환은 루프 밖에서.
> ③ 대각선 이동은 **√2 만큼 빠르므로 정규화**가 필요합니다.
