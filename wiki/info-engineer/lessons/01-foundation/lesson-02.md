## ② 왜 필요한가

**모든 코드 문제는 변수에서 시작합니다.** 시험에 나오는 어떤 어려운 코드도 결국 "변수에 값이 저장되고 → 연산으로 바뀌고 → 출력된다"의 반복입니다. 이 사슬의 첫 고리(변수·자료형·출력)가 흔들리면 2단원 전체가 무너집니다.

특히 **나눗셈은 실기 최빈출 함정**입니다. 같은 `7 / 2`라도 C·Java에서는 `3`, Python에서는 `3.5`가 나옵니다. 이 한 줄 차이로 20문항 중 한 문제가 갈립니다. 언어별 차이를 "외울 것"이 아니라 "이유(자료형)"로 이해하는 것이 이 강의 목적입니다.

**시험에서의 중요도와 출제 형태** — 변수·자료형·출력 자체가 단독 문제로 나오기보다, **모든 코드 문제의 마지막 한 줄(출력 형식)을 결정**합니다. 출력값을 다 맞게 계산하고도 `3.5`를 `3`으로, `A12`를 `A3`으로 써서 틀리는 것이 이 영역의 실전 함정입니다. DB 파트(DB·DBMS 정의, DBMS 필수 기능)는 이론 단답으로 직접 출제되는 시험 표현입니다.

## ③ 개념 설명

### 3-1. 변수와 자료형

**변수(variable)** 는 값을 저장하는 이름표 붙은 상자이고, **자료형(data type)** 은 그 상자에 담기는 값의 종류(정수·실수·문자·문자열 등)입니다. C·Java는 상자를 만들 때 종류를 미리 선언하고(정적 타입), Python은 담기는 값이 종류를 정합니다(동적 타입).

| 종류 | C | Java | Python |
|---|---|---|---|
| 정수 | `int a = 7;` | `int a = 7;` | `a = 7` |
| 실수 | `double d = 3.5;` (`float`도 있음) | `double d = 3.5;` | `d = 3.5` |
| 문자 1개 | `char c = 'A';` | `char c = 'A';` | (구분 없음 — 길이 1 문자열) |
| 문자열 | `char s[] = "HI";` (char 배열) | `String s = "HI";` | `s = "HI"` |
| 논리 | (0 = 거짓, 그 외 참) | `boolean b = true;` | `b = True` |

⚖️ **혼동 주의** — C·Java에서 `'A'`(작은따옴표)는 문자 1개, `"A"`(큰따옴표)는 문자열입니다. Python은 둘 다 문자열입니다. C의 문자는 내부적으로 정수(문자 코드)라서 `'A'` = 65로 계산에 쓰일 수 있습니다(→ ⑥ 형성평가에 등장).

### 3-2. 출력문 비교

| 언어 | 출력문 | 줄바꿈 | 비고 |
|---|---|---|---|
| C | `printf("포맷", 값)` | `\n`을 써야 줄바꿈 | 포맷 지정자 필수 |
| Java | `System.out.println(값)` | 자동 줄바꿈 | `print`는 줄바꿈 없음, `printf`는 C와 동일 포맷 |
| Python | `print(값)` | 자동 줄바꿈 | 여러 값은 쉼표 → 공백으로 구분 출력 |

📌 **반드시 암기 — C 포맷 지정자** (Java의 `printf`도 동일)

| 지정자 | 의미 | 예 |
|---|---|---|
| `%d` | 10진 정수 | `printf("%d", 7)` → `7` |
| `%f` | 실수 (기본 소수점 6자리) | `printf("%f", 3.5)` → `3.500000` |
| `%.1f` | 소수점 1자리 실수 | `printf("%.1f", 3.5)` → `3.5` |
| `%c` | 문자 1개 | `printf("%c", 'A')` → `A` |
| `%s` | 문자열 | `printf("%s", "HI")` → `HI` |
| `%o` / `%x` | 8진수 / 16진수 | `printf("%o", 8)` → `10` |

### 3-3. 산술 연산과 나눗셈 — 최빈출 함정

📌 **반드시 암기 — 세 언어의 나눗셈**

| 식 | C | Java | Python |
|---|---|---|---|
| `7 / 2` (정수끼리) | `3` (몫만) | `3` (몫만) | `3.5` (항상 실수) |
| `7 / 2.0` (실수 포함) | `3.5` | `3.5` | `3.5` |
| `7 // 2` | (없음) | (없음) | `3` (몫) |
| `7 % 2` | `1` (나머지) | `1` (나머지) | `1` (나머지) |

- 규칙: **C·Java는 피연산자가 모두 정수면 결과도 정수(소수점 버림)**, 하나라도 실수면 실수입니다. **Python의 `/`는 항상 실수**이고, 몫이 필요하면 `//`를 씁니다.
- Python에는 거듭제곱 `**`(예: `2 ** 3` = `8`)과 문자열 반복 `*`(예: `"가" * 3` = `가가가`)이 있습니다 — 다른 두 언어에는 없는 Python 고유 문법으로, 출력 문제에 자주 섞입니다.

⚖️ **혼동 비교 — 이 강의 3대 혼동**

| 혼동 | 구분 |
|---|---|
| `/` vs `//` vs `%` | `/` 나눗셈(언어별 규칙 위 표), `//` Python 몫, `%` 나머지 — 단 `printf` 안의 `%d`는 나머지가 아니라 포맷 지정자 |
| `print` vs `printf` vs `println` | Python 자동 줄바꿈 / C 포맷 필수·수동 줄바꿈 / Java 자동 줄바꿈 |
| 숫자 `+` vs 문자열 `+` | Java에서 `"A" + 1`은 덧셈이 아니라 **문자열 연결** → `"A1"`. 왼쪽부터 차례로 판정 (④ Step 3) |

### 3-4. 데이터베이스·DBMS·SQL

| 용어 | 쉬운 설명 | 시험 표현 (📌 이대로 암기) |
|---|---|---|
| 데이터베이스(DB) | 여러 사람이 함께 쓰는 정리된 데이터 창고 | 통합(중복 최소화)·저장(저장 매체 보관)·운영(업무 수행에 사용)·공유(여러 사용자 동시 사용) 데이터 |
| DBMS | 그 창고를 관리하는 소프트웨어 (Oracle, MySQL 등) | 데이터베이스를 생성·관리하는 소프트웨어. **필수 기능: 정의·조작·제어** |
| SQL | 창고에 말을 거는 표준 언어 | 관계형 데이터베이스의 표준 질의 언어 (정의어 DDL·조작어 DML·제어어 DCL로 구분 — 10강 상세) |

⚖️ **혼동 주의** — "데이터베이스 = 프로그램"이 아닙니다. 데이터베이스는 **데이터 그 자체**, DBMS가 **프로그램**, SQL이 **언어**입니다. (비유: 도서관 장서 = DB, 사서 = DBMS, 대출 신청서 양식 = SQL)

SELECT 문의 뼈대는 다음과 같고, 4주차부터 본격적으로 다룹니다.

```sql
SELECT 열이름        -- 무엇을 (열 선택)
FROM   테이블이름     -- 어디서 (테이블)
WHERE  조건;         -- 어떤 행만 (행 선택, 생략 가능)
```

## ④ 단계별 실습

실습은 **종이에 결과를 먼저 쓰고 → 온라인 컴파일러로 검증**하는 순서로 합니다.

### Step 1. 같은 프로그램, 세 언어 — 나눗셈 비교

**언어: C · 난이도: 🟢 입문 · 학습 개념: 자료형, 정수 나눗셈, 포맷 지정자**

```c
#include <stdio.h>
int main(void) {
    int a = 7, b = 2;
    printf("%d\n", a / b);
    printf("%d\n", a % b);
    printf("%.1f\n", a / 2.0);
    return 0;
}
```

```
$ gcc div.c -o div && ./div
3
1
3.5
```

**언어: Java · 난이도: 🟢 입문 · 학습 개념: 동일 개념의 Java 표기**

```java
public class Main {
    public static void main(String[] args) {
        int a = 7, b = 2;
        System.out.println(a / b);
        System.out.println(a % b);
        System.out.println(a / 2.0);
    }
}
```

```
$ javac Main.java && java Main
3
1
3.5
```

**언어: Python · 난이도: 🟢 입문 · 학습 개념: `/`·`//`·`%`의 구분**

```python
a, b = 7, 2
print(a / b)
print(a // b)
print(a % b)
```

```
$ python div.py
3.5
3
1
```

실행 순서 해설: 세 프로그램 모두 위에서 아래로 한 줄씩 실행됩니다. 핵심 비교 — C·Java의 `a / b`는 int÷int라서 몫 `3`, 셋째 줄은 `2.0`(실수)이 끼어 실수 나눗셈 `3.5`. Python의 `/`는 정수끼리도 `3.5`이고 몫은 `//`로 따로 구합니다.

### Step 2. 변수 교환 추적표 — 시험 단골 패턴

**언어: C · 난이도: 🟢 입문 · 학습 개념: 임시 변수를 이용한 값 교환(swap)**

```c
#include <stdio.h>
int main(void) {
    int a = 3, b = 5, t;
    t = a;
    a = b;
    b = t;
    printf("%d %d\n", a, b);
    return 0;
}
```

| 실행한 줄 | a | b | t | 설명 |
|---|---|---|---|---|
| `int a = 3, b = 5, t;` | 3 | 5 | ? | t는 아직 값 없음 |
| `t = a;` | 3 | 5 | 3 | a의 값을 t에 복사(백업) |
| `a = b;` | 5 | 5 | 3 | b의 값으로 a를 덮어씀 |
| `b = t;` | 5 | 3 | 3 | 백업해 둔 3을 b에 저장 |

```
$ ./swap
5 3
```

`t` 없이 `a = b; b = a;`로 쓰면 a의 원래 값 3이 사라져 `5 5`가 됩니다 — 교환에 임시 변수가 필요한 이유이며, 빈칸 문제(`t = ___;`)로 자주 출제되는 패턴입니다.

### Step 3. 문자열 연결 실험 — Java `+`의 두 얼굴

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 문자열 연결과 평가 순서(왼쪽부터)**

```java
public class Concat {
    public static void main(String[] args) {
        System.out.println(1 + 2 + "A");
        System.out.println("A" + 1 + 2);
    }
}
```

```
$ javac Concat.java && java Concat
3A
A12
```

왼쪽부터 차례로 판정합니다. 첫 줄: `1 + 2`는 숫자끼리 → `3`, `3 + "A"`는 문자열이 끼어 → `"3A"`. 둘째 줄: `"A" + 1` → `"A1"`, `"A1" + 2` → `"A12"`. **같은 재료, 순서만 달라도 답이 다릅니다** — 오답 포인트로 표시해 두세요.

### Step 4. 첫 SQL 질의

4주차부터 계속 쓸 과정 공용 예제 스키마의 STUDENT 테이블을 미리 만납니다. (전체 스키마 4개 테이블은 07강에서 정의)

**STUDENT** (미리보기 4행)

| 학번 | 이름 | 학년 |
|---|---|---|
| 1001 | 김하늘 | 1 |
| 1002 | 이준호 | 2 |
| 1003 | 박서연 | 2 |
| 1004 | 최민수 | 3 |

**사용 테이블: STUDENT · 난이도: 🟢 입문 · 학습 개념: SELECT-FROM-WHERE**

```sql
SELECT 이름, 학년
FROM   STUDENT
WHERE  학년 = 2;
```

**예상 결과**

| 이름 | 학년 |
|---|---|
| 이준호 | 2 |
| 박서연 | 2 |

실행 원리: ① `FROM`으로 STUDENT 테이블을 편다 → ② `WHERE`로 학년이 2인 **행**만 남긴다 → ③ `SELECT`로 이름·학년 **열**만 고른다. "행을 거르고(WHERE) 열을 고른다(SELECT)"의 순서 감각이 이후 모든 SQL의 기초입니다.

## ⑤ 자주 하는 실수

| 에러/증상 원문 | 언어 | 원인 | 해결 |
|---|---|---|---|
| `error: expected ';' before 'printf'` | C | 앞 줄 끝의 세미콜론 누락 | C·Java는 문장 끝마다 `;` — Python은 쓰지 않음 |
| `error: incompatible types: possible lossy conversion from double to int` | Java | `int x = 7 / 2.0;` — 실수 결과를 정수 변수에 담으려 함 | 변수를 `double`로 하거나 `(int)` 명시 형변환 |
| `IndentationError: unexpected indent` | Python | 줄 앞에 불필요한 공백(들여쓰기) | Python은 들여쓰기가 문법 — 같은 블록은 같은 깊이로 |
| `TypeError: can only concatenate str (not "int") to str` | Python | `"나이: " + 20` — Python은 문자열+숫자 자동 연결 불가 | `str(20)`으로 변환 (Java와 달리 자동 변환 안 됨 — 언어 차이 오답 포인트) |
| `no such column: 김하늘` | SQL | `WHERE 이름 = 김하늘` — 문자열에 따옴표 누락 → 열 이름으로 해석됨 | 문자값은 `'김하늘'`처럼 작은따옴표로 감싼다 |
| 출력이 `3.500000`처럼 길게 나옴 | C | `%f`의 기본 소수 자리는 6자리 | 문제의 요구 형식 확인 — `%.1f` 등 자리 지정. 시험에서는 **보이는 그대로** 답안에 옮긴다 |
| `%d`에 실수를 넣었더니 이상한 값이 나옴 | C | 포맷 지정자와 값의 자료형 불일치(정의되지 않은 동작) | 지정자와 자료형을 반드시 짝 맞춘다 — 오류 찾기 유형의 단골 |

## ⑥ 확인 문제

1. [결과 예측] 다음 Java 코드의 출력을 쓰시오.
   ```java
   int a = 9, b = 4;
   System.out.println(a / b + a % b);
   ```
2. [빈칸] 출력이 `1`이 되도록 빈칸에 연산자 하나를 쓰시오.
   ```python
   print(10 ___ 3)
   ```
3. [오류 찾기] 다음 SQL은 이름과 학년 두 열을 조회하려던 질의다. 잘못된 부분과 이유를 쓰시오.
   ```sql
   SELECT 이름 학년 FROM STUDENT;
   ```

<details>
<summary>정답과 해설</summary>

1. **`3`** — `a / b`는 int÷int → 몫 `2`, `a % b`는 나머지 `1`, 합해서 3.
   - 대표 오답: `3.25` — `9 / 4`를 실수 나눗셈 `2.25`로 계산한 경우. **Java에서 정수끼리 `/`는 몫만 남습니다** (Python과의 언어 차이 오답 포인트).
2. **`%`** — `10 % 3` = 나머지 1.
   - 대표 오답: `//` — `10 // 3`은 몫 `3`이므로 조건(출력 1)에 맞지 않음. `/`는 `3.33...`.
3. **`이름`과 `학년` 사이에 쉼표(`,`) 누락.** 열을 여러 개 고를 때는 `SELECT 이름, 학년`처럼 쉼표로 구분해야 한다.
   - 함정 해설: 이 질의는 에러가 아니라 **`학년`이 `이름` 열의 별칭(alias)으로 해석되어 열 하나만 나올 수 있습니다**(9강 별칭에서 재등장). "에러가 안 나는데 결과가 이상한" 유형의 대표 사례.

</details>

## 마무리

**오늘의 요약** — 변수는 값을 담는 상자, 자료형은 값의 종류입니다. C·Java는 정수끼리 `/`가 몫이 되고 Python `/`는 항상 실수(`//`가 몫)라는 것이 오늘의 최빈출 함정입니다. C 포맷 지정자(`%d` `%f` `%c` `%s`)와 Java 문자열 연결(왼쪽부터 판정), 그리고 DB(데이터)·DBMS(소프트웨어, 필수 기능 정의·조작·제어)·SQL(언어)의 구분까지가 오늘의 암기 대상입니다.

**복습 체크리스트**

- [ ] 나눗셈 표(3-3)를 안 보고 세 언어로 재현할 수 있다
- [ ] 포맷 지정자 6종의 의미를 말할 수 있다
- [ ] Step 2 교환 추적표를 안 보고 다시 만들 수 있다
- [ ] `"A" + 1 + 2`와 `1 + 2 + "A"`의 출력을 즉답할 수 있다
- [ ] DB·DBMS·SQL을 비유와 시험 표현으로 각각 설명할 수 있다

**과제 — 1주차 형성평가 (10문항, 다음 강 첫 복습 퀴즈와 연동)**

1. C: `printf("%d", 5 / 2);`의 출력은?
2. Python: `print(5 / 2)`의 출력은?
3. Java: `System.out.println(5 % 2);`의 출력은?
4. C에서 문자열을 출력하는 포맷 지정자는?
5. Python: `print(2 ** 3)`의 출력은?
6. Java: `int x = 10; x = x + 5;` 실행 후 `x`의 값은?
7. 빈칸: `______ * FROM COURSE;` (테이블 전체 조회)
8. DBMS의 필수 기능 3가지는?
9. Python: `print("가" * 3)`의 출력은?
10. C: `int a = 65; printf("%c", a);`의 출력은?

<details>
<summary>형성평가 정답</summary>

| 번호 | 정답 | 측정 개념 |
|---|---|---|
| 1 | `2` | C 정수 나눗셈 |
| 2 | `2.5` | Python `/`는 항상 실수 |
| 3 | `1` | 나머지 연산 |
| 4 | `%s` | 포맷 지정자 |
| 5 | `8` | Python 거듭제곱 `**` |
| 6 | `15` | 변수 재대입 |
| 7 | `SELECT` | SELECT 구조 |
| 8 | 정의·조작·제어 | DBMS 필수 기능 (시험 표현) |
| 9 | `가가가` | Python 문자열 반복 |
| 10 | `A` | `%c`와 문자 코드(65 = 'A') |

</details>
