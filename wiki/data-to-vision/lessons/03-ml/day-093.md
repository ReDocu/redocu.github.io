```
→ 학습이 느리거나 발산
```

## ③ 개념 설명

### 픽셀 정규화 방법 3가지

**① 0~1 스케일링 (가장 흔함)**

```
x' = x / 255.0
```

| 장점 | 단점 |
|---|---|
| 단순, 빠름 | 평균이 0이 아님 (보통 0.4~0.5) |
| 범위가 고정 | — |

**② -1~1 스케일링**

```
x' = (x / 127.5) - 1.0
```

**평균이 0에 가까워** 학습에 유리합니다.
**MobileNet, EfficientNet 등이 이 방식**을 씁니다. ([Day 098](day-098.md))

**③ 채널별 표준화**

```
x' = (x - 채널평균) / 채널표준편차
```

**ImageNet 표준값**

```
평균     = [0.485, 0.456, 0.406]
표준편차 = [0.229, 0.224, 0.225]
```

| 방법 | 결과 범위 | 쓰는 곳 |
|---|---|---|
| `/255` | 0 ~ 1 | **기본. 밑바닥 학습** |
| `/127.5 - 1` | -1 ~ 1 | MobileNet, EfficientNet |
| 채널 표준화 | 약 -2 ~ 2 | ResNet, VGG (ImageNet 사전학습) |

> ⚠️ **전이학습([Day 098](day-098.md))에서는 그 모델 전용 전처리를 써야 합니다.**
> ```python
> from tensorflow.keras.applications.mobilenet_v2 import preprocess_input
> ```
> 잘못 쓰면 성능이 크게 떨어집니다. Day 098에서 다시 강조합니다.

### Rescaling / Normalization 층

**전처리를 모델에 내장하는 방식입니다.**

```python
model = keras.Sequential([
    layers.Input(shape=(224, 224, 3)),
    layers.Rescaling(1.0 / 255),          # 0~255 → 0~1
    layers.Conv2D(32, 3, ...),
    ...
])
```

**-1~1로 하려면**

```python
layers.Rescaling(scale=1.0 / 127.5, offset=-1.0)
```

**채널별 표준화**

```python
norm = layers.Normalization(axis=-1)
norm.adapt(train_ds.map(lambda x, y: x))     # 학습 데이터로 평균·분산 계산
model = keras.Sequential([norm, ...])
```

**모델에 내장하는 것의 장점**

| 장점 | 설명 |
|---|---|
| **추론 시 실수 방지** | 정규화를 깜빡할 수 없음 |
| 모델 저장에 포함 | `.keras` 파일 하나로 완결 |
| 배포가 단순 | 원본 이미지를 그대로 넣으면 됨 |

```python
# 저장된 모델은 0~255 이미지를 그대로 받습니다
img = np.array(Image.open("test.jpg").resize((224, 224)))
model.predict(img[np.newaxis])      # 정규화 불필요
```

### 클래스 불균형 진단

```python
import numpy as np
labels = np.concatenate([y.numpy() for _, y in train_ds])
counts = np.bincount(labels)
print(counts, counts.max() / counts.min())
```

| 비율 | 판정 | 대응 |
|---|---|---|
| < 1.5:1 | 균형 | 없음 |
| 1.5~3:1 | 약한 불균형 | `class_weight` 고려 |
| 3~10:1 | 불균형 | `class_weight` 필요 |
| **> 10:1** | **심한 불균형** | 여러 기법 조합 + **지표 재검토** ([Day 080](day-080.md)) |

### class_weight

**소수 클래스의 오류에 더 큰 벌점을 줍니다.**

```python
from sklearn.utils.class_weight import compute_class_weight

weights = compute_class_weight("balanced", classes=np.unique(y), y=y)
class_weight = dict(enumerate(weights))
model.fit(train_ds, class_weight=class_weight, ...)
```

**계산식**

```
weight_i = 전체 샘플 수 / (클래스 수 × 클래스 i의 샘플 수)
```

**예시** — 정상 900, 불량 100

```
정상: 1000 / (2 × 900) = 0.556
불량: 1000 / (2 × 100) = 5.000      ← 9배 무겁게
```

> **[Day 080](day-080.md) Step 5에서 표 데이터로 확인한 것과 같습니다.**
> `class_weight` 는 **판별력을 높이는 게 아니라 판정 기준을 옮기는 것**입니다.
> 재현율은 오르고 정밀도는 내려갑니다.

### 오버샘플링 vs 언더샘플링

| 방법 | 하는 일 | 장점 | 단점 |
|---|---|---|---|
| **언더샘플링** | 다수 클래스를 줄임 | 빠름, 균형 | **데이터 낭비** |
| **오버샘플링** | 소수 클래스를 복제 | 데이터 보존 | **과적합 위험** |
| **증강 오버샘플링** | 소수 클래스를 **증강**해 늘림 | 과적합 완화 | 계산 비용 |
| `class_weight` | 손실 가중치 | 데이터 그대로 | 극단적 불균형엔 부족 |

**이미지에서는 "증강 오버샘플링"이 가장 좋습니다.**

```
불량 100장 → 회전·반전·밝기 조절로 900장 생성
→ 균형 맞춤 + 다양성 확보
```

**[Day 094](day-094.md)의 데이터 증강이 이 역할을 합니다.**

### Step 1. 정규화 유무에 따른 학습 곡선

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()

X_train_raw = X_full[5000:].astype("float32")       # 0~255
X_val_raw = X_full[:5000].astype("float32")
X_test_raw = X_test.astype("float32")
y_train, y_val = y_full[5000:], y_full[:5000]

print("=" * 66)
print("정규화 방식별 비교 — CIFAR-10")
print("=" * 66)
print(f"원본 픽셀 범위: {X_train_raw.min():.0f} ~ {X_train_raw.max():.0f}")
print(f"원본 평균     : {X_train_raw.mean():.2f}")
print(f"원본 표준편차 : {X_train_raw.std():.2f}")


def build(rescale="none"):
    L = [layers.Input(shape=(32, 32, 3))]
    if rescale == "0to1":
        L.append(layers.Rescaling(1.0 / 255))
    elif rescale == "-1to1":
        L.append(layers.Rescaling(1.0 / 127.5, offset=-1.0))
    elif rescale == "standardize":
        norm = layers.Normalization(axis=-1)
        norm.adapt(X_train_raw)
        L.append(norm)
    L += [
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ]
    return keras.Sequential(L)


방법들 = [
    ("정규화 없음 (0~255)", "none"),
    ("0~1 (÷255)", "0to1"),
    ("-1~1 (÷127.5-1)", "-1to1"),
    ("채널 표준화", "standardize"),
]

rows, histories = [], {}
EPOCHS = 20

for name, mode in 방법들:
    tf.random.set_seed(42)
    m = build(mode)
    m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])

    t0 = time.time()
    hist = m.fit(X_train_raw, y_train, epochs=EPOCHS, batch_size=128,
                 validation_data=(X_val_raw, y_val), verbose=0)
    elapsed = time.time() - t0
    _, acc = m.evaluate(X_test_raw, y_test, verbose=0)
    h = hist.history

    # 5에폭 시점 성능 (초기 수렴 속도)
    rows.append({
        "정규화": name,
        "1에폭_손실": round(h["loss"][0], 4),
        "5에폭_val_acc": round(h["val_accuracy"][4], 4),
        "최종_val_acc": round(h["val_accuracy"][-1], 4),
        "test_acc": round(acc, 4),
        "시간(s)": round(elapsed, 1),
    })
    histories[name] = h
    print(f"{name:<24} test {acc:.4f}  (1에폭 손실 {h['loss'][0]:.4f})")

df = pd.DataFrame(rows)
print("\n" + "=" * 96)
print(df.to_string(index=False))
print("=" * 96)

# ── 실제 입력값 확인 ──
print("\n입력 데이터가 모델에 들어갈 때의 실제 값")
print(f"{'방법':<24}{'평균':>12}{'표준편차':>12}{'최소':>10}{'최대':>10}")
print("-" * 70)
print(f"{'정규화 없음':<24}{X_train_raw.mean():>12.4f}{X_train_raw.std():>12.4f}"
      f"{X_train_raw.min():>10.2f}{X_train_raw.max():>10.2f}")

x01 = X_train_raw / 255.0
print(f"{'0~1':<24}{x01.mean():>12.4f}{x01.std():>12.4f}"
      f"{x01.min():>10.2f}{x01.max():>10.2f}")

xm11 = X_train_raw / 127.5 - 1.0
print(f"{'-1~1':<24}{xm11.mean():>12.4f}{xm11.std():>12.4f}"
      f"{xm11.min():>10.2f}{xm11.max():>10.2f}")

mean = X_train_raw.mean(axis=(0, 1, 2))
std = X_train_raw.std(axis=(0, 1, 2))
xstd = (X_train_raw - mean) / std
print(f"{'채널 표준화':<24}{xstd.mean():>12.4f}{xstd.std():>12.4f}"
      f"{xstd.min():>10.2f}{xstd.max():>10.2f}")

print("\n→ -1~1 과 표준화는 평균이 0에 가깝습니다. 학습에 유리합니다.")

# ── 그래프 ──
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

ax = axes[0]
for name in histories:
    ax.plot(histories[name]["loss"], linewidth=2, label=name)
ax.set_xlabel("epoch")
ax.set_ylabel("train loss")
ax.set_yscale("log")
ax.set_title("Training loss (log scale)")
ax.legend(fontsize=8.5)
ax.grid(alpha=0.3)

ax = axes[1]
for name in histories:
    ax.plot(histories[name]["val_accuracy"], linewidth=2, label=name)
ax.set_xlabel("epoch")
ax.set_ylabel("val accuracy")
ax.set_title("Validation accuracy")
ax.legend(fontsize=8.5)
ax.grid(alpha=0.3)

ax = axes[2]
for label, data in [("raw (0~255)", X_train_raw[:500].ravel()),
                    ("0~1", x01[:500].ravel()),
                    ("-1~1", xm11[:500].ravel()),
                    ("standardized", xstd[:500].ravel())]:
    ax.hist(data, bins=60, alpha=0.5, label=label, density=True)
ax.axvline(0, color="black", linestyle="--", alpha=0.6)
ax.set_xlabel("pixel value")
ax.set_ylabel("density")
ax.set_title("Input distributions")
ax.legend(fontsize=8.5)

fig.tight_layout()
plt.show()
```

```python
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()
X_train = X_full[5000:].astype("float32")
X_val = X_full[:5000].astype("float32")
X_test = X_test.astype("float32")
y_train, y_val = y_full[5000:], y_full[:5000]


def build_body():
    return [
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ]


# ── ① 정규화를 밖에서 (전통적 방식) ──
tf.random.set_seed(42)
model_outside = keras.Sequential([layers.Input(shape=(32, 32, 3))] + build_body())
model_outside.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
                      metrics=["accuracy"])
model_outside.fit(X_train / 255.0, y_train, epochs=12, batch_size=128,
                  validation_data=(X_val / 255.0, y_val), verbose=0)

# ── ② 정규화를 모델에 내장 ──
tf.random.set_seed(42)
model_inside = keras.Sequential(
    [layers.Input(shape=(32, 32, 3)), layers.Rescaling(1.0 / 255)] + build_body())
model_inside.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
                     metrics=["accuracy"])
model_inside.fit(X_train, y_train, epochs=12, batch_size=128,
                 validation_data=(X_val, y_val), verbose=0)

print("=" * 74)
print("정규화 위치에 따른 차이")
print("=" * 74)
_, acc_out = model_outside.evaluate(X_test / 255.0, y_test, verbose=0)
_, acc_in = model_inside.evaluate(X_test, y_test, verbose=0)
print(f"  ① 밖에서 정규화 : {acc_out:.4f}")
print(f"  ② 모델에 내장   : {acc_in:.4f}")
print(f"  → 성능은 사실상 동일합니다 (차이 {abs(acc_out-acc_in):.4f})")

# ── 핵심: 추론 시 실수 방지 ──
print("\n" + "=" * 74)

_, acc_out_wrong = model_outside.evaluate(raw_test, y_test[:1000], verbose=0)

print(f"  ① 밖에서 정규화한 모델 : {acc_out_wrong:.4f}   ← 망가짐 ⚠️")

print("      다만 내장하면 '원본 이미지를 그대로 넣는다'는 규칙이 단순합니다.")

print("=" * 74)

MODEL_DIR = Path("/content/drive/MyDrive/ml_course/models")
MODEL_DIR.mkdir(parents=True, exist_ok=True)
```

```python
# ── 2클래스 불균형 데이터 만들기 (고양이 vs 개) ──
CAT, DOG = 3, 5
CLASSES = ["cat", "dog"]


def make_imbalanced(X, y, n_major=4000, n_minor=400, seed=42):
    rng = np.random.default_rng(seed)
    cat_idx = np.where(y == CAT)[0]
    dog_idx = np.where(y == DOG)[0]
    cat_idx = rng.permutation(cat_idx)[:n_major]
    dog_idx = rng.permutation(dog_idx)[:n_minor]
    idx = np.concatenate([cat_idx, dog_idx])
    idx = rng.permutation(idx)
    Xs = X[idx].astype("float32")
    ys = (y[idx] == DOG).astype("int32")      # cat=0, dog=1
    return Xs, ys


X_tr, y_tr = make_imbalanced(X_full[5000:], y_full[5000:], 4000, 400, seed=1)

print(f"    테스트셋 : {majority_acc_test:.4f}   ← 균형이라 50%")
print(f"  → 학습셋 정확도로 판단하면 완전히 속습니다 (Day 080)")

tf.random.set_seed(42)
```

### Step 4. 불균형 대응 4가지 비교

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.metrics import (average_precision_score, confusion_matrix,
                             f1_score, precision_score, recall_score,
                             roc_auc_score)
from sklearn.utils.class_weight import compute_class_weight
from tensorflow import keras
from tensorflow.keras import layers

# (Step 3의 X_tr, y_tr, X_va, y_va, X_te, y_te 사용)


def build():
    return keras.Sequential([
        layers.Input(shape=(32, 32, 3)),
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.GlobalAveragePooling2D(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(1, activation="sigmoid"),
    ])


def evaluate(model, X, y, threshold=0.5):
    proba = model.predict(X, verbose=0).ravel()
    pred = (proba > threshold).astype(int)
    tn, fp, fn, tp = confusion_matrix(y, pred).ravel()
    return {
        "정확도": round((tp + tn) / len(y), 4),
        "정밀도": round(precision_score(y, pred, zero_division=0), 4),
        "재현율": round(recall_score(y, pred), 4),
        "F1": round(f1_score(y, pred, zero_division=0), 4),
        "ROC_AUC": round(roc_auc_score(y, proba), 4),
        "PR_AUC": round(average_precision_score(y, proba), 4),
        "FN": int(fn),
    }, proba


results, probas = {}, {}

# ── ① 대응 없음 ──
tf.random.set_seed(42)
m1 = build()
m1.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
m1.fit(X_tr, y_tr, epochs=20, batch_size=64, validation_data=(X_va, y_va), verbose=0)
results["① 대응 없음"], probas["① 대응 없음"] = evaluate(m1, X_te, y_te)

# ── ② class_weight ──
weights = compute_class_weight("balanced", classes=np.array([0, 1]), y=y_tr)
cw = dict(enumerate(weights))
print(f"class_weight = {{0: {cw[0]:.4f}, 1: {cw[1]:.4f}}}")
print(f"  계산: {len(y_tr)} / (2 × {np.bincount(y_tr)[1]}) = {cw[1]:.4f}")

tf.random.set_seed(42)
m2 = build()
m2.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
m2.fit(X_tr, y_tr, epochs=20, batch_size=64, validation_data=(X_va, y_va),
       class_weight=cw, verbose=0)
results["② class_weight"], probas["② class_weight"] = evaluate(m2, X_te, y_te)

# ── ③ 언더샘플링 ──
rng = np.random.default_rng(42)
minor_n = np.bincount(y_tr).min()
idx_major = rng.permutation(np.where(y_tr == 0)[0])[:minor_n]
idx_minor = np.where(y_tr == 1)[0]
idx_under = rng.permutation(np.concatenate([idx_major, idx_minor]))
X_under, y_under = X_tr[idx_under], y_tr[idx_under]
print(f"\n언더샘플링: {len(y_tr)}장 → {len(y_under)}장 "
      f"({np.bincount(y_under)})")

tf.random.set_seed(42)
m3 = build()
m3.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
m3.fit(X_under, y_under, epochs=20, batch_size=64,
       validation_data=(X_va, y_va), verbose=0)
results["③ 언더샘플링"], probas["③ 언더샘플링"] = evaluate(m3, X_te, y_te)

# ── ④ 오버샘플링 (단순 복제) ──
major_n = np.bincount(y_tr).max()
idx_minor_over = rng.choice(np.where(y_tr == 1)[0], size=major_n, replace=True)
idx_over = rng.permutation(np.concatenate([np.where(y_tr == 0)[0], idx_minor_over]))
X_over, y_over = X_tr[idx_over], y_tr[idx_over]
print(f"오버샘플링: {len(y_tr)}장 → {len(y_over)}장 ({np.bincount(y_over)})")

tf.random.set_seed(42)
m4 = build()
m4.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
m4.fit(X_over, y_over, epochs=20, batch_size=64,
       validation_data=(X_va, y_va), verbose=0)
results["④ 오버샘플링"], probas["④ 오버샘플링"] = evaluate(m4, X_te, y_te)

# ── ⑤ 임계값 조정 (①의 모델에 적용) ──
best_t, best_f1 = 0.5, 0
proba1 = probas["① 대응 없음"]
for t in np.arange(0.05, 0.96, 0.05):
    f1 = f1_score(y_te, (proba1 > t).astype(int), zero_division=0)
    if f1 > best_f1:
        best_f1, best_t = f1, t
results["⑤ ① + 임계값 조정"], _ = evaluate(m1, X_te, y_te, threshold=best_t)
print(f"\n최적 임계값: {best_t:.2f}")

df = pd.DataFrame(results).T
print("\n" + "=" * 92)
print("클래스 불균형 대응 비교 (train 10:1, test 1:1)")
print("=" * 92)
print(df.to_string())
print("=" * 92)

print("\n[해석]")
print("  ① 대응 없음   : 재현율 0.24. 소수 클래스를 못 찾음")
print("  ② class_weight: 재현율 크게 개선. 정밀도는 하락")
```

```python
def make_balanced(X, y, batch_size=64, seed=42):
    ds_list = []
    for cls in np.unique(y):
        idx = np.where(y == cls)[0]
        d = (tf.data.Dataset.from_tensor_slices((X[idx], y[idx]))
             .shuffle(len(idx), seed=seed)
             .repeat())                       # ★ 소수 클래스가 소진되지 않도록
        ds_list.append(d)

    balanced = tf.data.Dataset.sample_from_datasets(
        ds_list, weights=[1.0 / len(ds_list)] * len(ds_list), seed=seed)
    return balanced.batch(batch_size).prefetch(AUTOTUNE)
```

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.metrics import (average_precision_score, confusion_matrix,
                             f1_score, precision_score, recall_score,
                             roc_auc_score)
from sklearn.utils.class_weight import compute_class_weight
from tensorflow import keras
from tensorflow.keras import layers

# (Step 3~4의 데이터 재사용)
AUTOTUNE = tf.data.AUTOTUNE


def build(rescale="0to1"):
    L = [layers.Input(shape=(32, 32, 3))]
    if rescale == "0to1":
        L.append(layers.Rescaling(1.0 / 255))
    elif rescale == "-1to1":
        L.append(layers.Rescaling(1.0 / 127.5, offset=-1.0))
    L += [
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.GlobalAveragePooling2D(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(1, activation="sigmoid"),
    ]
    return keras.Sequential(L)


def metrics_of(model, X, y, threshold=0.5):
    proba = model.predict(X, verbose=0).ravel()
    pred = (proba > threshold).astype(int)
    tn, fp, fn, tp = confusion_matrix(y, pred).ravel()
    return {
        "정확도": round((tp + tn) / len(y), 4),
        "정밀도": round(precision_score(y, pred, zero_division=0), 4),
        "재현율": round(recall_score(y, pred), 4),
        "F1": round(f1_score(y, pred, zero_division=0), 4),
        "PR_AUC": round(average_precision_score(y, proba), 4),
        "FN": int(fn),
    }

    ("#8", "#4 + 임계값 0.4", dict(rescale="0to1", cw=True, threshold=0.4)),
]

    rescale = kw.get("rescale", "0to1")
    use_cw = kw.get("cw", False)
    sampling = kw.get("sampling")
    threshold = kw.get("threshold", 0.5)

    Xt, yt = X_tr, y_tr
    if sampling == "under":
        n = np.bincount(y_tr).min()
        idx = np.concatenate([rng.permutation(np.where(y_tr == 0)[0])[:n],
                              np.where(y_tr == 1)[0]])

    m.fit(Xt, yt, epochs=20, batch_size=64, validation_data=(X_va, y_va),
          class_weight=cw if use_cw else None, verbose=0)

    met = metrics_of(m, X_te, y_te, threshold)

                 "임계값": threshold, **met})
    print(f"{num:<5}{desc:<26} F1 {met['F1']:.4f}  재현율 {met['재현율']:.4f}")
```

**문제점 4가지**

| # | 문제 | 결과 |

| 1 | **`adapt` 에 검증셋 포함** | 데이터 누수 |

**입력값이 어떻게 되는가**

```
원본 0~255
→ .map(x/255)      : 0~1
→ Normalization     : 표준화 (이미 0~1인 데이터를 0~255 통계로)
→ Rescaling(1/255)  : 0~0.004
```

```python
    return m


def evaluate(model, X, y, t=0.5):
    proba = model.predict(X, verbose=0).ravel()
    pred = (proba > t).astype(int)
    tn, fp, fn, tp = confusion_matrix(y, pred).ravel()
    return {
        "정확도": round((tp + tn) / len(y), 4),
        "정밀도": round(precision_score(y, pred, zero_division=0), 4),
        "재현율": round(recall_score(y, pred), 4),
        "F1": round(f1_score(y, pred, zero_division=0), 4),
        "ROC_AUC": round(roc_auc_score(y, proba), 4),
        "PR_AUC": round(average_precision_score(y, proba), 4),
        "FN": int(fn), "FP": int(fp),
    }, proba
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 정규화 필요성 | **없으면 F1 0.12 vs 0.37**. 필수 |
| `/255` | 0~1. **기본 선택** |
| `/127.5 - 1` | -1~1. **평균 0에 가까움**. MobileNet |
| 채널 표준화 | 평균 0, 표준편차 1. ResNet/VGG |
| 방식 간 차이 | **거의 없음.** 하느냐 안 하느냐가 중요 |
| `Rescaling` 층 | **모델에 내장** → 추론 실수 방지 |
| `Normalization.adapt` | **학습셋으로만** (누수 방지) |
| 정규화 중복 | 두 번 하면 신호가 사라짐 |
| 분할 원칙 | 분할 먼저 · 층화 · **그룹 단위** · 시간순 |
| 불균형 진단 | `counts.max() / counts.min()`. **10:1 이상은 심각** |
| `class_weight` | `전체 / (클래스수 × 개수)`. 학습에만 적용 |
| 언더샘플링 | **데이터 낭비.** PR-AUC 하락 |
| 오버샘플링 | 복제는 과적합 위험 → **증강과 함께** ([Day 094](day-094.md)) |
| 임계값 조정 | **재학습 없이** 개선. PR-AUC는 불변 |
| PR-AUC vs F1 | **판별력 vs 특정 지점 성능** |
| 전이학습 전처리 | **모델별 `preprocess_input` 확인** ([Day 098](day-098.md)) |

**오늘 반드시 기억할 세 가지**
> ① **정규화는 필수입니다.** 방식보다 하느냐 안 하느냐가 훨씬 중요합니다.
> ② **`Rescaling` 을 모델에 넣으세요.** "원본을 그대로 넣는다"는 규칙 하나면 됩니다.
> ③ **PR-AUC로 모델을 고르고, 임계값으로 운영 지점을 정하세요.** 순서가 중요합니다.
