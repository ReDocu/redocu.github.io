## ③ 개념 설명

### 해로운 증강 — 라벨을 바꾸는 변형

**증강의 대전제**

```
증강 후에도 라벨이 그대로여야 한다.
```

이것이 깨지면 **라벨 노이즈**를 주입하는 것과 같습니다.

| 데이터 | 위험한 증강 | 이유 |
|---|---|---|
| 손글씨 숫자 | **상하/좌우 반전** | 6↔9, 2↔5 |
| 도로 표지판 | **좌우 반전** | 좌회전↔우회전 |
| 흉부 X-ray | **좌우 반전** | 심장 위치가 바뀜 |
| 과일 신선도 | **색조 변환** | 갈변이 판단 근거 |
| 신호등 | **색조 변환** | 빨강↔초록 |
| 텍스트 이미지 | **반전, 큰 회전** | 글자를 못 읽음 |
| 위성 사진 | 회전 OK | 방향이 의미 없음 |

**"방향이 의미를 갖는가"가 핵심 질문입니다.**

```
위성 사진: 북쪽이 위든 아래든 같은 건물 → 회전 자유
동물 사진: 하늘이 위 → 상하반전은 부자연스러움
숫자     : 방향이 곧 의미 → 반전 금지
```

### 증강 강도의 적정선

```
너무 약함                적정                    너무 강함
   ↓                      ↓                        ↓
증강 효과 없음         과적합 해소              원본을 못 알아봄
train 0.99            train 0.89               train 0.75
test  0.81            test  0.88               test  0.79
격차 0.18             격차 0.01                격차 -0.04
```

**진단표**

| 신호 | 진단 | 대응 |
|---|---|---|
| 격차 > 0.10 | 증강 부족 | 강도 ↑ |
| 격차 0.00~0.05 | **적정** | 유지 |
| **격차 < -0.03** | **증강 과함** | 강도 ↓ |
| train이 계속 낮음 | 과소적합 | 강도 ↓ 또는 모델 ↑ |

> **`train < test` 는 증강의 특징적 신호입니다.**
> 학습 시에는 변형된 어려운 이미지를, 평가 시에는 원본을 보기 때문입니다.
> **약간(0~0.03)은 정상이지만 크면 과합니다.**

### 소량 데이터에서 효과가 큰 이유

```
데이터 100장, 파라미터 25만 개
→ 샘플당 파라미터 2,500개
→ 통째로 외우기 매우 쉬움
→ 증강으로 "매번 다른 100장"을 만들면 외울 수 없음

데이터 50,000장, 파라미터 25만 개
→ 샘플당 파라미터 5개
→ 애초에 외우기 어려움
→ 증강 효과가 상대적으로 작음
```

**[Day 094](day-094.md) Step 5에서 확인한 것**

| 데이터 | 증강 개선율 (무작위 대비) |
|---|---|
| 100장 | 93.8% |
| 4,000장 | 15.8% |

### 증강 검증 절차

```
① 눈으로 확인      증강 이미지 9장 — 라벨이 유지되는가
② 강도 실험        약/중/강 3조건 학습
③ 격차 확인        train - test
④ 개별 증강 검증   하나씩 빼면서(ablation) 기여도 측정
⑤ 최종 조합 선정
```

**④ Ablation study(제거 실험)**

```
전체 조합: 0.876
- Flip 제거: 0.851      → Flip의 기여 +0.025
- Rotation 제거: 0.869  → Rotation의 기여 +0.007
- Zoom 제거: 0.872      → Zoom의 기여 +0.004
```

**기여도가 낮은 증강은 빼도 됩니다.** 시간을 아낄 수 있습니다.

### TTA (Test-Time Augmentation)

**추론할 때도 증강을 쓰는 기법입니다.**

```
테스트 이미지 1장
  → 원본, 좌우반전, 소폭 회전 ... 5가지 변형
  → 각각 예측
  → 확률을 평균
```

| 장점 | 단점 |
|---|---|
| 정확도 +1~2%p | **추론 시간 5배** |
| 예측이 안정적 | 실시간 서비스에 부적합 |

### Step 1. 해로운 증강 — MNIST 반전 실험

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.mnist.load_data()
X_full = X_full.astype("float32")[..., np.newaxis]
X_test = X_test.astype("float32")[..., np.newaxis]
X_val, y_val = X_full[:6000], y_full[:6000]
X_train, y_train = X_full[6000:], y_full[6000:]

# ── 반전이 무엇을 하는지 먼저 확인 ──
print("=" * 66)
print("MNIST에 반전을 적용하면?")
print("=" * 66)

samples = {}
for digit in [2, 5, 6, 9]:
    idx = np.where(y_train == digit)[0][0]
    samples[digit] = X_train[idx]

fig, axes = plt.subplots(3, 4, figsize=(11, 8.5))
for col, (digit, img) in enumerate(samples.items()):
    axes[0, col].imshow(img[:, :, 0], cmap="gray_r")
    axes[0, col].set_title(f"original: {digit}", fontsize=11)

    flipped_h = tf.image.flip_left_right(img[np.newaxis])[0]
    axes[1, col].imshow(flipped_h[:, :, 0], cmap="gray_r")
    axes[1, col].set_title(f"h-flip (label still {digit})", fontsize=9.5,
                           color="red")

    flipped_v = tf.image.flip_up_down(img[np.newaxis])[0]
    axes[2, col].imshow(flipped_v[:, :, 0], cmap="gray_r")
    axes[2, col].set_title(f"v-flip (label still {digit})", fontsize=9.5,
                           color="red")

for ax in axes.ravel():
    ax.axis("off")
fig.suptitle("6 flipped vertically looks like 9 — but the label says 6",
             fontsize=14)
fig.tight_layout()
plt.show()

print("  6 상하반전 → 9처럼 보임 (라벨은 6)")
print("  9 상하반전 → 6처럼 보임 (라벨은 9)")
print("  2 좌우반전 → 5처럼 보임 (라벨은 2)")
print("\n→ 모델에게 모순된 정보를 주는 것입니다")


# ── 실험 ──
def build(aug_layers):
    L = [layers.Input(shape=(28, 28, 1))] + list(aug_layers)
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ]
    m = keras.Sequential(L)
    m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
    return m


실험들 = [
    ("증강 없음", []),
    ("안전: 회전+이동+확대", [layers.RandomRotation(0.08),
                              layers.RandomTranslation(0.1, 0.1),
                              layers.RandomZoom(0.1)]),
    ("위험: 좌우반전", [layers.RandomFlip("horizontal")]),
    ("위험: 상하반전", [layers.RandomFlip("vertical")]),
    ("위험: 양방향 반전", [layers.RandomFlip("horizontal_and_vertical")]),
    ("위험: 큰 회전(0.5)", [layers.RandomRotation(0.5)]),
]

rows, histories = [], {}
print("\n" + "=" * 70)
print("증강 종류별 성능 — MNIST, 15에폭")
print("=" * 70)

for name, aug in 실험들:
    tf.random.set_seed(42)
    m = build(aug)
    h = m.fit(X_train, y_train, epochs=15, batch_size=128,
              validation_data=(X_val, y_val), verbose=0).history
    _, acc = m.evaluate(X_test, y_test, verbose=0)
    rows.append({"증강": name,
                 "train": round(h["accuracy"][-1], 4),
                 "test": round(acc, 4),
                 "격차": round(h["accuracy"][-1] - acc, 4)})
    histories[name] = h
    print(f"{name:<24} test {acc:.4f}  train {h['accuracy'][-1]:.4f}")

df = pd.DataFrame(rows)
base = df[df["증강"] == "증강 없음"]["test"].iloc[0]
df["변화"] = (df["test"] - base).round(4)
df["판정"] = ["기준" if v == 0 else ("도움 ✓" if v > 0.001 else "해로움 ✗")
              for v in df["변화"]]

print("\n" + "=" * 84)
print(df.to_string(index=False))
print("=" * 84)
print("\n★ 반전 계열이 전부 성능을 떨어뜨렸습니다.")
print("  특히 상하반전은 6↔9 혼동을 유발합니다.")

# ── 어떤 숫자에서 틀리는지 확인 ──
from sklearn.metrics import confusion_matrix

tf.random.set_seed(42)
m_bad = build([layers.RandomFlip("vertical")])
m_bad.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
pred_bad = m_bad.predict(X_test, verbose=0).argmax(axis=1)

tf.random.set_seed(42)
m_good = build([layers.RandomRotation(0.08), layers.RandomTranslation(0.1, 0.1)])
m_good.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
pred_good = m_good.predict(X_test, verbose=0).argmax(axis=1)

cm_bad = confusion_matrix(y_test, pred_bad)
cm_good = confusion_matrix(y_test, pred_good)

print("\n" + "=" * 70)
print("상하반전 증강이 어떤 숫자를 망가뜨리는가")
print("=" * 70)
print(f"{'숫자':>6}{'안전한 증강':>14}{'상하반전':>14}{'차이':>12}")
print("-" * 70)
for d in range(10):
    a = cm_good[d, d] / cm_good[d].sum()
    b = cm_bad[d, d] / cm_bad[d].sum()
    mark = "  ← 큰 하락" if b - a < -0.05 else ""
    print(f"{d:>6}{a:>14.4f}{b:>14.4f}{b-a:>+12.4f}{mark}")
print("=" * 70)
print(f"\n6을 9로 오인: {cm_bad[6, 9]}건 (안전한 증강에서는 {cm_good[6, 9]}건)")
print(f"9를 6으로 오인: {cm_bad[9, 6]}건 (안전한 증강에서는 {cm_good[9, 6]}건)")

fig, axes = plt.subplots(1, 2, figsize=(14, 5))
ax = axes[0]
ax.bar(df["증강"], df["test"], color=["gray"] + ["green" if v > 0 else "crimson"
                                                for v in df["변화"][1:]])
ax.axhline(base, color="black", linestyle="--", alpha=0.6, label="baseline")
ax.set_ylim(0.9, 1.0)
ax.set_ylabel("test accuracy")
ax.set_title("Harmful augmentations hurt performance")
ax.tick_params(axis="x", rotation=25, labelsize=8)
ax.legend()

ax = axes[1]
digits = np.arange(10)
good_acc = cm_good.diagonal() / cm_good.sum(axis=1)
bad_acc = cm_bad.diagonal() / cm_bad.sum(axis=1)
ax.bar(digits - 0.2, good_acc, 0.4, label="safe augmentation")
ax.bar(digits + 0.2, bad_acc, 0.4, label="vertical flip")
ax.set_xticks(digits)
ax.set_xlabel("digit")
ax.set_ylabel("per-class accuracy")
ax.set_ylim(0.7, 1.0)
ax.set_title("6 and 9 suffer the most")
ax.legend()
ax.grid(alpha=0.3, axis="y")

fig.tight_layout()
plt.show()
```

### Step 2. 색 변환이 해로운 경우

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

# ── 색이 판단 근거인 인공 데이터 만들기 ──
# "빨간 도형" vs "초록 도형" — 형태는 같고 색만 다름
def make_color_dataset(n_per_class=2000, size=32, seed=42):
    rng = np.random.default_rng(seed)
    X, y = [], []
    for cls, base_color in enumerate([(200, 40, 40), (40, 180, 60)]):
        for _ in range(n_per_class):
            img = np.full((size, size, 3), 240, dtype=np.uint8)   # 밝은 배경
            # 무작위 위치·크기의 원
            cx, cy = rng.integers(10, size - 10, 2)
            r = rng.integers(5, 10)
            yy, xx = np.ogrid[:size, :size]
            mask = (xx - cx) ** 2 + (yy - cy) ** 2 <= r ** 2
            color = np.array(base_color) + rng.integers(-25, 25, 3)
            img[mask] = np.clip(color, 0, 255)
            X.append(img)
            y.append(cls)
    X = np.array(X, dtype="float32")
    y = np.array(y, dtype="int32")
    idx = rng.permutation(len(y))
    return X[idx], y[idx]

# ── 색조 변환 레이어 (Keras에 없어 직접 구현) ──
class RandomHue(layers.Layer):
    def __init__(self, factor=0.2, **kw):
        super().__init__(**kw)
        self.factor = factor

    def call(self, x, training=None):
        if not training:
            return x
        return tf.image.random_hue(x / 255.0, self.factor) * 255.0


class RandomSaturation(layers.Layer):
    def __init__(self, lower=0.5, upper=1.5, **kw):
        super().__init__(**kw)
        self.lower, self.upper = lower, upper

    def call(self, x, training=None):
        if not training:
            return x
        return tf.image.random_saturation(x / 255.0, self.lower, self.upper) * 255.0


class ToGrayscale(layers.Layer):
    def call(self, x, training=None):
        g = tf.image.rgb_to_grayscale(x)
        return tf.image.grayscale_to_rgb(g)

    L = [layers.Input(shape=(32, 32, 3))] + make_aug(strength)
    L += [

### Step 5. 오늘의 종합 — 3조건 비교 실험

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.metrics import classification_report, confusion_matrix
from tensorflow import keras
from tensorflow.keras import layers

AUTOTUNE = tf.data.AUTOTUNE
SPLIT = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset/split")
IMG_SIZE = (224, 224)
BATCH = 32
EPOCHS = 80

# ══════════════════════════════════════════
# 데이터
# ══════════════════════════════════════════
train_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH, shuffle=True, seed=42)
val_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)
test_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "test", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)

CLASS_NAMES = train_raw.class_names
N_CLASSES = len(CLASS_NAMES)
print(f"클래스: {CLASS_NAMES}")

train_ds = train_raw.cache().prefetch(AUTOTUNE)
val_ds = val_raw.cache().prefetch(AUTOTUNE)
test_ds = test_raw.cache().prefetch(AUTOTUNE)

# ══════════════════════════════════════════
# 3조건
# ══════════════════════════════════════════
CONDITIONS = {
    "(a) 증강 없음": [],
    "(b) 약한 증강": [
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.08),
        layers.RandomZoom(0.08),
    ],
    "(c) 강한 증강": [
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.25),
        layers.RandomZoom(0.25),
        layers.RandomTranslation(0.25, 0.25),
        layers.RandomContrast(0.4),
        layers.RandomBrightness(0.3, value_range=(0, 255)),
    ],
}


def build(aug_layers):
    L = [layers.Input(shape=(*IMG_SIZE, 3))] + list(aug_layers)
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.GlobalAveragePooling2D(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
    ]
    if N_CLASSES == 2:
        L.append(layers.Dense(1, activation="sigmoid"))
        loss = "binary_crossentropy"
    else:
        L.append(layers.Dense(N_CLASSES, activation="softmax"))
        loss = "sparse_categorical_crossentropy"
    m = keras.Sequential(L)
    m.compile(optimizer="adam", loss=loss, metrics=["accuracy"])
    return m


# ── 증강 시각화 (필수) ──
for images, labels in train_ds.take(1):
    sample = images[:1]
    sample_cls = CLASS_NAMES[int(labels[0])]
    break

fig, axes = plt.subplots(3, 7, figsize=(16, 7))
for row, (name, aug_layers) in enumerate(CONDITIONS.items()):
    axes[row, 0].imshow(sample[0].numpy().astype("uint8"))
    axes[row, 0].set_title("original", fontsize=8.5)
    axes[row, 0].axis("off")
    if aug_layers:
        aug = keras.Sequential(aug_layers)
        for col in range(1, 7):
            out = aug(sample, training=True)
            axes[row, col].imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
            axes[row, col].set_title(name.split()[0], fontsize=8.5)
            axes[row, col].axis("off")
    else:
        for col in range(1, 7):
            axes[row, col].imshow(sample[0].numpy().astype("uint8"))
            axes[row, col].set_title("(no aug)", fontsize=8.5)
            axes[row, col].axis("off")
fig.suptitle(f"Three conditions — sample class: {sample_cls}", fontsize=14)
fig.tight_layout()
plt.show()

print("\n★ 강한 증강 이미지를 보세요. 원본을 알아볼 수 있습니까?")
print("  알아보기 어렵다면 모델도 배울 것이 없습니다.")

# ══════════════════════════════════════════
# 학습
# ══════════════════════════════════════════
rows, histories, models = [], {}, {}

print("\n" + "=" * 70)
print(f"3조건 비교 실험 — {EPOCHS}에폭")
print("=" * 70)

for name, aug_layers in CONDITIONS.items():
    tf.random.set_seed(42)
    m = build(aug_layers)
    t0 = time.time()
    h = m.fit(train_ds, epochs=EPOCHS, validation_data=val_ds, verbose=0).history
    elapsed = time.time() - t0
    _, test_acc = m.evaluate(test_ds, verbose=0)
    gap = h["accuracy"][-1] - test_acc

    if gap > 0.10:
        diag = "과적합"
    elif gap < -0.03:
        diag = "증강 과함"
    else:
        diag = "적정"

    rows.append({
        "조건": name,
        "train": round(h["accuracy"][-1], 4),
        "val": round(h["val_accuracy"][-1], 4),
        "test": round(test_acc, 4),
        "격차": round(gap, 4),
        "val_최고": round(max(h["val_accuracy"]), 4),
        "최적에폭": int(np.argmin(h["val_loss"])) + 1,
        "시간(s)": round(elapsed, 1),
        "진단": diag,
    })
    histories[name] = h
    models[name] = m
    print(f"{name:<16} test {test_acc:.4f}  격차 {gap:+.4f}  {diag}")

df = pd.DataFrame(rows)
print("\n" + "=" * 110)
print(df.to_string(index=False))
print("=" * 110)

base = df.iloc[0]
print("\n증강 없음 대비")
for _, r in df.iloc[1:].iterrows():
    print(f"  {r['조건']:<16} test {r['test'] - base['test']:+.4f}  "
          f"격차 {r['격차'] - base['격차']:+.4f}  "
          f"시간 {r['시간(s)']/base['시간(s)']:.2f}배")

# ══════════════════════════════════════════
# 최고 모델 상세 분석
# ══════════════════════════════════════════
best_name = df.loc[df["test"].idxmax(), "조건"]
best_model = models[best_name]

y_true = np.concatenate([y.numpy() for _, y in test_ds])
proba = best_model.predict(test_ds, verbose=0)
if N_CLASSES == 2:
    pred = (proba.ravel() > 0.5).astype(int)
else:
    pred = proba.argmax(axis=1)

print("\n" + "=" * 70)
print(f"최고 조건 상세 — {best_name}")
print("=" * 70)
print(classification_report(y_true, pred, target_names=CLASS_NAMES, digits=4))

cm = confusion_matrix(y_true, pred)
print("혼동행렬")
print(f"{'':>12}", end="")
for c in CLASS_NAMES:
    print(f"{'예측 '+c:>14}", end="")
print()
for i, c in enumerate(CLASS_NAMES):
    print(f"{'실제 '+c:>12}", end="")
    for j in range(len(CLASS_NAMES)):
        print(f"{cm[i, j]:>14}", end="")
    print()

# ══════════════════════════════════════════
# 그래프
# ══════════════════════════════════════════
fig, axes = plt.subplots(2, 2, figsize=(15, 10))

ax = axes[0, 0]
for name in histories:
    ax.plot(histories[name]["val_accuracy"], linewidth=2, label=name)
ax.set_xlabel("epoch"); ax.set_ylabel("val accuracy")
ax.set_title("Validation accuracy")
ax.legend(fontsize=9); ax.grid(alpha=0.3)

ax = axes[0, 1]
for name in histories:
    ax.plot(histories[name]["val_loss"], linewidth=2, label=name)
ax.set_xlabel("epoch"); ax.set_ylabel("val loss")
ax.set_title("Validation loss")
ax.legend(fontsize=9); ax.grid(alpha=0.3)

ax = axes[1, 0]
for name in histories:
    h = histories[name]
    ax.plot(h["accuracy"], "--", alpha=0.6, linewidth=1.6)
    ax.plot(h["val_accuracy"], linewidth=2.2, label=name)
ax.set_xlabel("epoch"); ax.set_ylabel("accuracy")
ax.set_title("Train (dashed) vs Val (solid)")
ax.legend(fontsize=9); ax.grid(alpha=0.3)

ax = axes[1, 1]
x = np.arange(len(df))
ax.bar(x - 0.2, df["train"], 0.4, label="train")
ax.bar(x + 0.2, df["test"], 0.4, label="test")
ax.set_xticks(x)
ax.set_xticklabels([c.split()[0] for c in df["조건"]])
ax.set_ylabel("accuracy")
ax.set_title("Train vs Test (gap)")
ax.legend(); ax.grid(alpha=0.3, axis="y")
for i, g in enumerate(df["격차"]):
    ax.text(i, max(df.loc[i, "train"], df.loc[i, "test"]) + 0.01,
            f"{g:+.3f}", ha="center", fontsize=9,
            color="darkred" if abs(g) > 0.1 else "black")

fig.tight_layout()
plt.show()

OUT = Path("/content/drive/MyDrive/ml_course/experiments")
OUT.mkdir(parents=True, exist_ok=True)
df.to_csv(OUT / "day095_three_conditions.csv", index=False, encoding="utf-8-sig")

MODEL_DIR = Path("/content/drive/MyDrive/ml_course/models")
MODEL_DIR.mkdir(parents=True, exist_ok=True)
best_model.save(MODEL_DIR / "day095_best.keras")
print(f"\n저장 완료: {OUT}, {MODEL_DIR / 'day095_best.keras'}")
```

| **(e)** | 표정 인식 | **좌우반전**, 소폭 회전, 밝기, 확대 | 상하반전, 강한 회전 | 얼굴은 좌우 대칭. 뒤집힌 얼굴은 없음 |

**(a) 위성 사진이 특별한 이유**

```
일반 사진: 하늘이 위, 땅이 아래 → 방향이 정해짐
위성 사진: 위에서 내려다봄 → 어느 방향이든 유효

→ RandomRotation(1.0) 도 안전합니다 (360° 전체)
→ 증강으로 데이터를 사실상 4~8배 늘릴 수 있습니다
```

**대단원 05의 Object Detection에서도 위성/드론 영상은 이 특성을 활용합니다.**

**(b) 알파벳에서 반전이 위험한 조합**

```
b ↔ d   (좌우반전)
p ↔ q   (좌우반전)
b ↔ p   (상하반전)
d ↔ q   (상하반전)
n ↔ u   (상하반전)
```

**소문자에서 특히 위험합니다.**

**(c) 피부 병변 — 의료 영상의 원칙**

```

  A: Asymmetry (비대칭)       → 회전·반전 OK (비대칭은 유지)
  B: Border (경계 불규칙)     → 회전·반전 OK

  D: Diameter (크기)          → ★ 강한 확대/축소 주의
  E: Evolving (변화)          → -

→ 기하 변환은 안전, 색과 크기는 주의
```

"""

import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.metrics import classification_report, confusion_matrix
from tensorflow import keras
from tensorflow.keras import layers

AUTOTUNE = tf.data.AUTOTUNE
SPLIT = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset/split")
OUT = Path("/content/drive/MyDrive/ml_course/experiments")
OUT.mkdir(parents=True, exist_ok=True)

IMG_SIZE = (224, 224)
BATCH = 32
EPOCHS = 80
SEED = 42

# ══════════════════════════════════════════
# 데이터
# ══════════════════════════════════════════
def load(subset, shuffle=False):
    return keras.utils.image_dataset_from_directory(
        SPLIT / subset, image_size=IMG_SIZE, batch_size=BATCH,
        shuffle=shuffle, seed=SEED)


train_raw, val_raw, test_raw = load("train", True), load("val"), load("test")
CLASS_NAMES = train_raw.class_names
N_CLASSES = len(CLASS_NAMES)

train_ds = train_raw.cache().prefetch(AUTOTUNE)
val_ds = val_raw.cache().prefetch(AUTOTUNE)
test_ds = test_raw.cache().prefetch(AUTOTUNE)

n_train = sum(len(y) for _, y in train_raw)
print(f"클래스 {CLASS_NAMES}, 학습 {n_train}장")


# ══════════════════════════════════════════
# 모델
# ══════════════════════════════════════════
def build(aug_layers):
    L = [layers.Input(shape=(*IMG_SIZE, 3))] + list(aug_layers)
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"), layers.MaxPooling2D(2),
        layers.GlobalAveragePooling2D(), layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
    ]
    if N_CLASSES == 2:
        L.append(layers.Dense(1, activation="sigmoid"))
        loss = "binary_crossentropy"
    else:
        L.append(layers.Dense(N_CLASSES, activation="softmax"))
        loss = "sparse_categorical_crossentropy"
    m = keras.Sequential(L)
    m.compile(optimizer="adam", loss=loss, metrics=["accuracy"])
    return m


def run(aug_layers, epochs=EPOCHS, tag=""):
    tf.random.set_seed(SEED)
    m = build(aug_layers)
    t0 = time.time()
    h = m.fit(train_ds, epochs=epochs, validation_data=val_ds, verbose=0).history
    elapsed = time.time() - t0
    _, acc = m.evaluate(test_ds, verbose=0)
    gap = h["accuracy"][-1] - acc
    diag = ("과적합" if gap > 0.10 else
            "증강 과함" if gap < -0.03 else "적정")
    return m, h, {
        "train": round(h["accuracy"][-1], 4),
        "val": round(h["val_accuracy"][-1], 4),
        "test": round(acc, 4),
        "격차": round(gap, 4),
        "val_최고": round(max(h["val_accuracy"]), 4),
        "최적에폭": int(np.argmin(h["val_loss"])) + 1,
        "시간(s)": round(elapsed, 1),
        "진단": diag,
    }


def visualize(aug_layers, title, n=9):
    """② 증강 이미지 시각화"""
    for images, labels in train_ds.take(1):
        sample = images[:1]
        cls = CLASS_NAMES[int(labels[0])]
        break
    aug = keras.Sequential(aug_layers) if aug_layers else None
    plt.figure(figsize=(9, 9))
    for i in range(n):
        plt.subplot(3, 3, i + 1)
        out = sample if aug is None else aug(sample, training=True)
        plt.imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
        plt.title(f"#{i+1}", fontsize=9)
        plt.axis("off")
    plt.suptitle(f"{title}  (class: {cls})", fontsize=14)
    plt.tight_layout()
    plt.show()

class RandomHue(layers.Layer):
    def __init__(self, factor=0.3, **kw):
        super().__init__(**kw)
        self.factor = factor

    def call(self, x, training=None):
        if not training:
            return x
        return tf.image.random_hue(x / 255.0, self.factor) * 255.0


class ToGrayscale(layers.Layer):
    def call(self, x, training=None):
        return tf.image.grayscale_to_rgb(tf.image.rgb_to_grayscale(x))

## 오늘의 정리 · W19 총정리

| 개념 | 핵심 |
|---|---|
| 증강의 대전제 | **증강 후에도 라벨이 그대로여야 함** |
| 판단 질문 ① | "이 변형을 한 이미지가 **실제로 존재**할 수 있는가?" |
| 판단 질문 ② | "이 변형이 **라벨을 바꾸는가**?" |
| 방향이 의미 없음 | 위성 사진 → 회전 자유 |
| 방향이 의미 있음 | 숫자·문자·표지판 → **반전 금지** |
| 색이 판단 근거 | 신호등·과일·병변 → **색 변환 금지** |
| 강도 진단 | 격차 > 0.10 부족 / **0.00~0.05 적정** / < -0.03 과함 |
| 최적 강도 | CIFAR 0.15~0.20 · **소량 데이터 0.05~0.10** |
| `train < test` | 증강의 특징. **약간은 정상, 크면 과함** |
| Ablation | 하나씩 빼며 기여도 측정 |
| 기여도 1위 | **좌우 반전** (대부분의 데이터에서) |
| 소량 데이터 | **약한 증강**이 유리 |
| 최적 에폭 | 증강하면 **3~5배 늘어남** |
| TTA | 추론 시 증강. +1~2%p, **시간 5배** |
