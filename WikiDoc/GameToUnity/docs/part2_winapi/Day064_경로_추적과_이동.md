## 3. 개념

### 3-1. `parent`로 경로 역추적

**왜 필요한가** — 탐색 중에 기록해 둔 정보를 되짚는다.

```
   탐색 중 기록

   각 노드가 "어디서 왔는지"를 저장한다

   (3,2).parent = (2,2)
   (4,2).parent = (3,2)
   (5,2).parent = (4,2)
   ...
   (7,4).parent = (7,3)
```

```
   역추적

   목표 (7,4)
      ↓ parent
   (7,3)
      ↓ parent
   (7,2)
      ↓ parent
   (6,2)
      ↓ ...
   (2,2) 시작   ← parent 가 없으면 종료

   ★ 거꾸로 나왔으므로 뒤집어야 한다
```

```cpp
bool PathFinder::BuildPath(int goalCol, int goalRow,
                           PathPoint* outPath, int maxLen, int* outLen)
{
    *outLen = 0;

    const PathNode* n = At(goalCol, goalRow);
    if (!n || !n->visited) return false;       // 도달 불가

    // ① 역추적하며 임시 배열에 담는다
    PathPoint temp[MAX_PATH_LEN];
    int count = 0;

    int c = goalCol, r = goalRow;

    while (c >= 0 && r >= 0)
    {
        if (count >= MAX_PATH_LEN) return false;   // 무한 루프 방지

        temp[count++] = { c, r };

        const PathNode* node = At(c, r);
        if (!node) break;

        int pc = node->parentCol;
        int pr = node->parentRow;

        if (pc < 0 || pr < 0) break;           // 시작점 도달

        c = pc; r = pr;
    }

    // ② 뒤집는다
    if (count > maxLen) return false;

    for (int i = 0; i < count; i++)
        outPath[i] = temp[count - 1 - i];      // ★ 역순

    *outLen = count;
    return true;
}
```

```
   temp (역추적 순서)          outPath (뒤집은 뒤)

   [0] (7,4)  목표             [0] (2,2)  시작
   [1] (7,3)                   [1] (3,2)
   [2] (7,2)                   [2] (4,2)
   ...                         ...
   [8] (2,2)  시작             [8] (7,4)  목표
```

### 3-2. ⚠️ 무한 루프 방지

**왜 필요한가** — `parent`가 순환하면 프로그램이 멈춘다.

```
   버그 상황

   A.parent = B
   B.parent = A

   → 역추적이 A → B → A → B → ... 무한
```

```cpp
    if (count >= MAX_PATH_LEN) return false;   // ★ 상한
```

```
   ★ 정상적인 A* 에서는 순환이 생기지 않는다

   하지만 갱신 로직에 버그가 있으면 생길 수 있다
   → 안전장치를 반드시 넣는다

   ★ MAX_PATH_LEN 은 맵 크기(cols × rows) 이상으로
```

```cpp
void RenderPathArrows(Renderer& r, const PathPoint* path, int len)
{
    for (int i = 0; i < len - 1; i++)
    {
        int dc = path[i+1].col - path[i].col;
        int dr = path[i+1].row - path[i].row;

        const char* arrow = (dc > 0) ? "→"
                          : (dc < 0) ? "←"
                          : (dr > 0) ? "↓" : "↑";

        double sx, sy;
        TileToScreen(path[i].col, path[i].row, &sx, &sy);

        int size = (int)(m_map.GetTileW() * m_camera.GetZoom());

        r.DrawText((int)sx + size/2 - 6, (int)sy + size/2 - 8,
                   arrow, RGB(255, 240, 120));
    }

    // 목표 지점 강조
    if (len > 0)
    {
        double sx, sy;
        TileToScreen(path[len-1].col, path[len-1].row, &sx, &sy);
        int size = (int)(m_map.GetTileW() * m_camera.GetZoom());

        r.DrawRect((int)sx, (int)sy, size, size, RGB(255, 240, 120), false);
    }
}
```

### 3-4. 경로 따라 이동

**왜 필요한가** — 순간이동이 아니라 걸어가야 한다.

```cpp
class Unit
{
public:
    void StartMove(const PathPoint* path, int len)
    {
        if (len < 2) return;

        for (int i = 0; i < len; i++) m_path[i] = path[i];
        m_pathLen   = len;
        m_pathIndex = 0;
        m_moveTimer = 0.0;
        m_moving    = true;
    }

    void UpdateMove(double dt)
    {
        if (!m_moving) return;

        m_moveTimer += dt;

        double t = m_moveTimer / m_moveDuration;   // 0.0 ~ 1.0

        if (t >= 1.0)
        {
            // 다음 칸으로
            m_pathIndex++;
            m_moveTimer = 0.0;

            if (m_pathIndex >= m_pathLen - 1)
            {
                // 도착
                m_col = m_path[m_pathLen-1].col;
                m_row = m_path[m_pathLen-1].row;
                UpdateWorldPos();
                m_moving = false;
                OnMoveComplete();
                return;
            }

            t = 0.0;
        }

        // 현재 칸과 다음 칸 사이를 보간
        const PathPoint& from = m_path[m_pathIndex];
        const PathPoint& to   = m_path[m_pathIndex + 1];

        double fx, fy, tx, ty;
        TileCenterToWorld(from.col, from.row, &fx, &fy);
        TileCenterToWorld(to.col,   to.row,   &tx, &ty);

        m_worldX = fx + (tx - fx) * t;         // ★ 선형 보간
        m_worldY = fy + (ty - fy) * t;

        // 방향
        if (to.col > from.col) m_facing = DIR_RIGHT;
        if (to.col < from.col) m_facing = DIR_LEFT;
        if (to.row > from.row) m_facing = DIR_DOWN;
        if (to.row < from.row) m_facing = DIR_UP;
    }

private:
    PathPoint m_path[MAX_PATH_LEN];
    int       m_pathLen = 0;
    int       m_pathIndex = 0;
    double    m_moveTimer = 0.0;
    double    m_moveDuration = 0.2;            // 한 칸당 시간
    bool      m_moving = false;
};
```

```
   ★ 선형 보간 (linear interpolation)

   result = from + (to - from) × t

   t = 0.0  →  from
   t = 0.5  →  중간
   t = 1.0  →  to

   ★ Day 22의 위치 갱신과 같은 원리
```

### 3-5. 이동 속도

**왜 필요한가** — 너무 빠르면 안 보이고, 너무 느리면 답답하다.

| 한 칸 시간 | 체감 |
|:--:|---|
| 0.05초 | 거의 순간이동 |
| 0.10초 | 빠르다 (스킵용) |
| **0.15~0.25초** | **적당** |
| 0.4초 | 느리다 |

```cpp
    // 지형에 따라 속도 변경 (선택)
    double GetMoveDuration(const Tile* t) const
    {
        double base = 0.18;

        if (t->attribute & ATTR_WATER)  return base * 1.8;
        if (t->attribute & ATTR_FOREST) return base * 1.4;

        return base;
    }
```

```

   → 시각적으로도 "힘들게 간다"는 느낌
```

### 3-7. 이동 취소

**왜 필요한가** — 실수로 이동했을 때 되돌릴 수 있어야 한다.

```cpp
class Unit
{
    int  m_startCol, m_startRow;               // 턴 시작 위치
    bool m_hasMoved = false;

public:
    void BeginTurn()
    {
        m_startCol = m_col;
        m_startRow = m_row;
        m_hasMoved = false;
        m_hasActed = false;
    }

    {

        m_row = m_startRow;

        m_hasMoved = false;
```

```cpp
void TacticsScene::RenderPathInfo(Renderer& r)
{
    int x = 20, y = r.GetHeight() - 140;
    const int LH = 18;

    r.DrawRect(x - 8, y - 8, 420, 130, RGB(20, 20, 32));

    r.DrawTextF(x, y, RGB(255,220,120), "─ 경로 ─"); y += LH;

    if (m_pathLen == 0)
    {
        r.DrawTextF(x, y, RGB(160,160,180), "경로 없음");
        return;
    }

    int cost = m_pathFinder.GetCost(m_path[m_pathLen-1].col,
                                    m_path[m_pathLen-1].row);

    r.DrawTextF(x, y, RGB(255,255,255),
                "길이      %d칸    비용 %d", m_pathLen, cost); y += LH;

    // 경로 좌표 (앞 3개 + ... + 마지막)
    char buf[256] = "";
    int show = min(m_pathLen, 4);

    for (int i = 0; i < show; i++)
    {
        char tmp[32];
        sprintf_s(tmp, "(%d,%d)", m_path[i].col, m_path[i].row);
        strcat_s(buf, sizeof(buf), tmp);
        if (i < show - 1) strcat_s(buf, sizeof(buf), "→");
    }

    if (m_pathLen > 4)
    {
        char tmp[32];
        sprintf_s(tmp, "→...→(%d,%d)",
                  m_path[m_pathLen-1].col, m_path[m_pathLen-1].row);
        strcat_s(buf, sizeof(buf), tmp);
    }

    r.DrawTextF(x, y, RGB(200,220,255), "경로      %s", buf); y += LH;

    r.DrawTextF(x, y, RGB(255,255,255),
                "이동 시간 %.2f 초", (m_pathLen-1) * m_moveDuration); y += LH;

    const char* stateName = (m_phase == PHASE_MOVING) ? "이동 중"
                          : "미리보기 (클릭하면 이동)";

    r.DrawTextF(x, y, RGB(180,200,255), "상태      %s", stateName);
}
```

**✅ 여기까지 실행하면** — 1절의 완성 화면이 나온다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 경로가 거꾸로 | 뒤집기 누락 | `temp[count-1-i]` |
| 무한 루프 | `parent` 순환 | `MAX_PATH_LEN` 상한 |
| 경로가 끊김 | `parent` 갱신 누락 | 비용 갱신 시 함께 |
| 순간이동 | 보간 없음 | 선형 보간 |
| 뚝뚝 튐 | `t` 계산 오류 | `m_moveTimer / m_moveDuration` |
| 마지막 칸에 안 도착 | 인덱스 범위 | `m_pathIndex >= m_pathLen - 1` |
| 이동 중 조작 가능 | 상태 검사 없음 | `PHASE_MOVING` 확인 |
| 취소해도 안 돌아감 | 시작 위치 미저장 | `BeginTurn`에서 저장 |
| 방향이 안 바뀜 | `m_facing` 갱신 누락 | 보간 중에 갱신 |
| 미리보기가 느림 | 매 프레임 재탐색 | 이동 범위의 parent 재사용 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| **경로 역추적** | `parent`를 따라가고 **뒤집는다** |
