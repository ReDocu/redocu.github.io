## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- **검출(detection)과 이벤트(event)의 차이**를 설명하고 승격 규칙을 설계할 수 있다.
- **이벤트 3종**(클래스 등장 · 체류 · ROI 침입)을 **상태 기계**로 구현할 수 있다.
- **N-of-M 규칙 · 최소 박스 크기 · 최소 신뢰도**로 단일 프레임 오검출을 걸러낼 수 있다.
- **관심 영역(ROI)** 을 폴리곤으로 정의하고 `cv2.pointPolygonTest` 로 침입을 판정할 수 있다.
- **IoU 기반 간이 추적**으로 객체에 ID를 부여하고 **체류 시간**을 측정할 수 있다.
- **쿨다운 · 이벤트 병합**으로 알림 폭주를 막을 수 있다.
- **스냅샷 · 프리롤 버퍼 · SQLite 로그**를 규칙에 따라 남길 수 있다.
- **텔레그램 봇과 이메일**로 알림을 보내고 실패를 재시도할 수 있다.
- **`systemd` 서비스**로 부팅 시 자동 실행하고 크래시 시 자동 복구할 수 있다.
- **저장 용량과 SD 카드 수명**을 고려한 보관 정책을 세울 수 있다.

## ③ 개념 설명

### 검출을 이벤트로 승격하는 4개의 관문

```
프레임 ─▶ detector.predict_image ─▶ detections
   │
   ├─ 관문 1     필터    conf ≥ 0.55 · 면적비 ≥ 1.5% · 관심 클래스인가
   ├─ 관문 2     ROI     박스    바닥 중앙이 폴리곤 안인가
   ├─ 관문 3     시간    최근 5프레임 중 3프레임 이상 · 체류는 N초 연속
   └─ 관문 4     중복    쿨다운 30초 · track당 1회 · 30초 내 병합
   ▼
★ 이벤트 1건

★ 현관 카메라 1시간 실측 — 원본 30,960 프레임 → 관문1 3,180 → 관문2 1,240
  → 관문3 1,190 → 알림 17통. 비율 0.055%
  "얼마나 많이 버리는가"가 CCTV 설계의 핵심입니다
```

### ★ 이벤트 정의 3종

| # | 이벤트 | 트리거 | 필요한 상태 | 부가 기능 | `type` 값 |
|---|---|---|---|---|---|
| ① | **클래스 등장** | `person` 이 나타남 | 직전에 있었는가 | 없음 | `person_detected` |
| ② | **체류** | N초 이상 계속 있음 | 언제부터 있었는가 | 추적 | `loiter` |
| ③ | **ROI 침입** | 지정 구역 안으로 진입 | 밖 → 안 전이 | 폴리곤 + 추적 | `intrusion` |

**★ 세 가지는 배타적이지 않습니다.** 한 사람이 들어와 서 있으면
① 등장 14:30:22 · ③ 침입 14:30:24 · ② 체류 14:30:54 — 이벤트 3건입니다.
알림은 몇 통이어야 하는가? 뒤의 "이벤트 병합"에서 다룹니다.

> ⚠️ **[Day 154](day-154.md) I-03 계약을 어기지 않습니다.**
> `type` 의 **값**이 늘어난 것이고 **필드 구조는 그대로**입니다(규칙 2 — 필드 추가는 자유).
> 서버([Day 164](day-164.md))는 `type` 을 TEXT 로 저장하므로 **수정 없이 받습니다.**

### 상태 기계란 무엇인가

```python
# ✗ 상태 없음 — 매 프레임이 독립적
if "person" in result["counts_by_class"]:
    notify("사람 감지")
```

**★ 상태 기계**는 "지금 어떤 상태인가"를 기억하고 입력에 따라 상태를 옮깁니다.
**전이할 때 하는 동작**이 곧 **★ 이벤트 발행**입니다.

### ★ 이벤트 ① — 클래스 등장

```
                     검출 없음
                 ┌──────────────────────┐
                 ▼                      │
          ┌─────────────┐  N-of-M 충족  ┌┴────────────┐
   시작 ─▶│   ABSENT    │─────────────▶│   PRESENT   │
          └─────────────┘  ★ 이벤트 발행 └─────────────┘
                 ▲                      │
                 └──────────────────────┘  miss ≥ 10프레임 → ★ 종료 이벤트

  ABSENT  → PRESENT :  최근 5프레임 중    3프레임 이상  → event(status="open")
  PRESENT → ABSENT  :     연속 10프레임 미검출 (약 1.2초) → event(status="closed")
```

> ⚠️ **들어가는 조건과 나가는 조건을 다르게 하세요 (히스테리시스).**
> 둘 다 "3프레임"이면 경계에서 **ABSENT ↔ PRESENT 를 초당 몇 번씩 왕복**합니다.
> **★ 들어갈 때는 빡빡하게(3/5), 나갈 때는 넉넉하게(연속 10프레임).**

```
히스테리시스 없음                       히스테리시스 있음
 14:30:22.1 ABSENT→PRESENT  ★ 알림      14:30:22.1 ABSENT→PRESENT  ★ 알림
 14:30:22.6 PRESENT→ABSENT              14:30:22.6 (miss 1)
 14:30:22.9 ABSENT→PRESENT     알림      14:30:22.9 (검출 — miss 리셋)
 14:30:23.8 ABSENT→PRESENT     알림      14:30:35.4 PRESENT→ABSENT  종료 기록만
 → 기둥에 잠깐 가려졌을 뿐인데    3통     →    1통
```

### ★ 이벤트 ② — 체류 (loitering)

```
   ABSENT ──객체 등장(track 생성)──▶ TRACKING ──경과 ≥ 30초──▶ LOITERING
      ▲          first_seen 기록          │      ★ 1회만 발행    │    재발행 금지
      └──────────track 소멸(miss ≥ 10)────┴─────────────────────┘
                 종료 이벤트 (duration 기록)

★ 핵심 — "누가" 30초 있었는지를 알아야 합니다
  A. 한 사람이 30초 서 있음 → 체류(알려야 함) / B. 6명이 5초씩 → 체류 아님(오탐)
  추적 없이 "person 이 30초 연속 검출됨"으로 판정하면 A 와 B 를 구분 못 합니다
```

### ★ 이벤트 ③ — ROI 침입 (intrusion)

```
   OUTSIDE ──앵커 점이 폴리곤 안    연속 3프레임──▶ INSIDE
      ▲                                             │
      └────── 앵커 점이 폴리곤 밖    연속 5프레임 ─────┘

★ OUTSIDE → INSIDE 전이 순간에만 이벤트 (INSIDE 유지 중에는 발행 안 함)
★ "안에 있다" 가 아니라 "밖에서 안으로 들어왔다" 가 이벤트입니다
  "안에 있음"으로 하면 배달원이 문 앞에 5분 있을 때 2,580건, "들어옴(전이)"이면
  1건 — 나갔다 다시 들어오면 1건 더 (그게 맞습니다)
```

| | ① 등장 | ② 체류 | ③ 침입 |
|---|---|---|---|
| 추적 필요 | ✗ | **필수** | **필수** |
| ROI 필요 | ✗ | 선택 | **필수** |
| 발행 시점 | 상태 전이 | 시간 경과 | 상태 전이 |
| 재발행 | 종료 후 재진입 | **track당 1회** | 재진입 시 |
| 대표 오탐 | 그림자·나뭇가지 | 정지 물체(의자) | 경계선 위 떨림 |

### 잡음 억제 ① — N-of-M 규칙

```
실제 로그 (현관, 3분간)
  112  ○ 0.61  ★ 커튼이 바람에 흔들림      602  ○ 0.72  사람 (진짜)
  113  ✗                                  603  ○ 0.79  사람
  287  ○ 0.58     벽에 비친 그림자          604  ○ 0.81  사람
  288  ✗                                  605  ○ 0.83  사람

오검출은 1~2 프레임만 튀고 사라지고, 진짜 객체는 연속으로 나옵니다
→ "최근 M 프레임 중 N 프레임 이상" 이면 진짜로 본다
```

```python
self.hits = deque(maxlen=m)                  # ★ maxlen 이 알아서 밀어냅니다
self.hits.append(1 if detected else 0)
detected_enough = sum(self.hits) >= n        # 최근 M 중 N 이상
```

| N/M | 반응 지연 | 오탐 억제 | 놓침 위험 | 권장 상황 |
|---|---|---|---|---|
| 1/1 · 2/3 | 0.12 · 0.23초 | 없음 · 낮음 | 없음 · 낮음 | ✗ · 빠른 반응이 중요할 때 |
| **3/5** | **0.35초** | 보통 | 낮음 | **기본값** |
| 5/8 · 8/10 | 0.58 · 0.93초 | 높음 · 매우 높음 | 보통 · 높음 | 오탐 많은 환경 · 과함 |

> ⚠️ **FPS 가 낮은 파이에서는 M 을 크게 잡으면 안 됩니다.**
> `M=20` 은 PC(30 FPS)에서 0.67초지만 파이(8.6 FPS)에서는 **2.3초**입니다.
> **★ M 은 프레임 수가 아니라 "몇 초를 볼 것인가"로 정하고 FPS 로 나누세요.**

### 잡음 억제 ② — 최소 박스 크기 · ③ 최소 신뢰도

```
① person conf=0.68  12×28 px    면적비 0.04%   ★ 멀리 있는 사람? 노이즈?
② person conf=0.71  148×415 px  면적비  6.7%   진짜
③ person conf=0.59  8×11 px     면적비 0.01%   거의 확실히 노이즈

작은 박스가 위험한 이유 — 학습 데이터에 8×11px 사람이 거의 없어 모델이 추측하고,
나뭇잎·전선·얼룩이 작은 박스로 잘 검출되며, 알림을 받아도 사람이 판단할 수 없습니다
면적비 = (x2-x1) × (y2-y1) / (frame_w × frame_h) × 100 (%)
```

| 기준 | 640×480 | 1280×720 | 판정 |
|---|---|---|---|
| 픽셀 절대값 100×100 | 3.3% | 1.1% | 해상도가 바뀌면 기준이 달라짐 |
| **면적비 1.5%** | 96×48 상당 | 137×68 상당 | **해상도와 무관** |

```
★ 우리 기본값 — min_area_ratio = 1.5(%) · min_box_height = 40(px)
★ conf 는 두 단계 — 모델 conf 0.35(후보를 넉넉히) / 이벤트 conf 0.55(여기서 거름)
  0.35 로 뽑아 두면 "0.4~0.55 사이가 몇 건이었나"를 나중에 볼 수 있습니다
  → 임계값을 바꿀 때 모델을 다시 안 돌려도 됩니다
```

| + conf ≥ 0.55 | 11,204 | 21 | 11,183 | 0 | 0.19% | 100% |
| + 면적비 ≥ 1.5% | 6,880 | 21 | 6,859 | 0 | 0.31% | 100% |
| + N-of-M (3/5) | 6,102 | 21 | 6,081 | 0 | 0.34% | 100% |
| + **상태 전이(등장만)** | 96 | 21 | 75 | 0 | 21.9% | 100% |
| + **ROI** | 34 | 20 | 14 | 1 | 58.8% | 95.2% |
| + **쿨다운 30초** | **23** | **20** | **3** | 1 | **87.0%** | **95.2%** |

**★ 읽는 법** — ① conf·면적·N-of-M 은 건수를 3분의 1로 줄이지만 정밀도는 0.34%
로 **거의 무의미**합니다. ② **상태 전이(등장 순간만 발행)가 결정적** — 6,102 → 96건,
**64배 감소.** ③ ROI 가 그다음이지만 **FN 1건**이 생겼습니다(경계로 들어온 사람을 놓침).
④ 쿨다운은 마지막에 남은 중복을 정리합니다.

> ⚠️ **"필터를 많이 걸면 좋다"가 아닙니다.**
> ROI 를 켠 순간 **놓친 사건이 1건 생겼습니다(FN)**.
> **★ 침입 감지에서 FN 1건은 FP 100건보다 나쁩니다.**
> 무엇을 우선할지는 용도가 정합니다 ([Day 148](day-148.md) — CCTV는 재현율 우선).

### ★ 관심 영역 (ROI)

```
카메라가 현관을 향해 있지만 화각에 ★ 도로가 같이 들어옵니다

  ┌──────────────────────────────────────────┐
  │      ▒▒▒▒▒ 도로 ▒▒▒▒▒   🚶 🚶  🚶         │ ← ★ 하루 400명이 지나감
  │  ────────────────────────────────────    │
  │          ┌────────────┐                  │
  │          │     현관 ROI │  🚶             │ ←    여기 들어온 사람만
  │          └────────────┘                  │
  └──────────────────────────────────────────┘

  ROI 없음 : 하루 알림    412통      ROI 있음 : 하루 알림    12통
```

ROI 의 목적은 **무관한 영역 제외**(도로·옆집 마당·하늘), **개인정보 최소화**
(이웃집 창문), **오탐원 회피**(흔들리는 나무·TV 화면·포스터 속 사람),
그리고 **구역별 다른 규칙**(현관=즉시알림 / 마당=체류30초)입니다.

```
실제 바닥 (위에서)      카메라 화면 (원근)      사각형 ROI 로 덮으면
   ┌───────┐              ╱▔▔▔▔▔╲            ┌──────────┐
   │       │      →      ╱        ╲          │╱▔▔▔▔▔╲   │ ←    모서리에
   └───────┘            └──────────┘         │└───────┘  │   도로가 들어옴
                     ★ 사다리꼴이 됩니다      └──────────┘
카메라는 거의 항상 비스듬하게 답니다 → 폴리곤이 기본입니다
```

**ROI JSON 형식**

### ★ 박스의 어느 점으로 판정할 것인가 — 중심 vs 바닥 중앙

**오늘 가장 자주 틀리는 부분입니다.**

```
  박스 중심 (cx, cy)             바닥 중앙 (cx, y2)
  ┌─────────────┐             ┌─────────────┐
  │      ●      │ ← 중심      │             │
  └─────────────┘             └──────●──────┘ ←    발

상황 — 카메라가 비스듬히 아래를 봄. ROI 는 바닥의 현관 매트
  ┌──────────────────────────────────────┐
  │            ┌───┐                     │
  │            │ ● │ ← 중심 (   ROI 밖)    │
  │      ╱▔▔▔▔▔●▔▔▔▔▔╲  ← 발 (   ROI 안)   │
  │     ╱   현관 매트   ╲                  │
  └──────────────────────────────────────┘

★ 사람은 발이 바닥에 닿습니다.
★ 바닥 평면 위에 그린 ROI 에는    바닥 중앙 (cx, y2) 을 써야 합니다.
```

| 앵커 | 좌표 | 맞는 경우 / 틀리는 경우 |
|---|---|---|
| 중심 | `((x1+x2)/2, (y1+y2)/2)` | 천장 직하 카메라 / 비스듬한 카메라 |
| **바닥 중앙** | `((x1+x2)/2, y2)` | **사람·차량, 비스듬한 카메라** / 공중의 물체 |
| 박스 전체 | 박스와 폴리곤 IoU | 큰 물체 / 사람은 과하게 잡힘 |

기본은 `pt = ((x1 + x2) / 2.0, y2)` — **★ 발이 닿는 지점**입니다.
대안은 `(cx, (y1+y2)/2)` 중심, `(cx, y1 + (y2-y1)*0.85)` 발이 잘렸을 때 보정.

> ⚠️ **화면 아래쪽에서 발이 잘리면 `y2` 가 프레임 끝(720)이 됩니다.**
> **★ `y2 >= frame_h - 2` 이면 "잘린 객체"로 표시**하고 별도로 처리하세요.

### 간단한 추적 — IoU 매칭

**★ SORT · DeepSORT 는 오늘 쓰지 않습니다.** 파이에서 무겁고 우리 목적에는 과합니다.

```
필요한 것은 두 가지뿐
  ① 이 사람이 아까 그 사람인가   → 체류 시간 측정
  ② 이 사람에게 이미 알렸는가    → 중복 알림 방지
  → ★ 프레임 간 IoU 매칭으로 충분합니다 (30줄)

  프레임 t          프레임 t+1
  track#3  ─IoU 0.78─▶ det A    ★ 0.3 이상 → 같은 객체 → track#3 유지
  track#4  ─IoU 0.02─▶ det B       매칭 실패 → track#5 신규 · track#4 는 miss+1
```

| 임계값 | 결과 | 상황 |
|---|---|---|
| 0.5 | 빠른 움직임에서 매칭 실패 → ID가 자꾸 바뀜 | 30 FPS 이상 |
| **0.3** | **기본값** | 8~15 FPS |
| 0.15 | 옆 사람과 잘못 매칭 | 사람이 드문 곳 |

**★ FPS 가 낮을수록 프레임 간 이동량이 큽니다.** 8.6 FPS → 간격 116ms →
걷는 사람 1.4 m/s × 0.116s = **16cm 이동** → 겹침이 줄어듦 → 임계값을 낮게(0.3).

> ⚠️ **IoU 매칭은 "사람이 서로 교차해 지나갈 때" ID가 바뀝니다.**
> 우리 목적(체류 시간·중복 억제)에는 **허용 가능**하지만,
> "몇 명이 지나갔는가"를 정확히 세야 한다면 **SORT 이상**이 필요합니다.

### 조용한 시간대 (야간 무음)

```python
QUIET = (dtime(23, 0), dtime(7, 0))      # ★ 자정을 넘는 구간
ALWAYS_LOUD = {"intrusion"}              # ★ 침입은 야간에도 소리

def in_quiet_hours(now, start=QUIET[0], end=QUIET[1]) -> bool:
    t = now.time()
    if start <= end:
        return start <= t < end          # 09:00~18:00 같은 경우
    return t >= start or t < end         # 23:00~07:00 (자정 통과)
```

> ⚠️ **자정을 넘는 시간 비교를 `start <= t <= end` 로 쓰면 항상 False 입니다.**
> `23:00 <= 02:00 <= 07:00` → **False.**
> **★ 야간 알림이 안 오는 버그의 1순위 원인입니다.**

### ★ SD 카드 수명 — 로그 쓰기를 줄여야 하는 이유

microSD 는 **★ 쓰기 횟수 제한**이 있습니다 — TLC 셀당 500~1,000회, 고내구
3,000~10,000회, 산업용 60,000회+. **24시간 CCTV 는 "쓰기가 멈추지 않는" 워크로드**입니다.

```python
# ✗ 무심코 만드는 최악의 코드 — 매 프레임 DB 쓰기
while True:
    result = detector.predict_image(frame)
    db.execute("INSERT INTO frames ..."); db.commit()     # ★ 초당 8.6회
# 8.6 commit/초 × 86,400초 = 743,040 쓰기/일
# SQLite 는 commit 마다 저널 + 본체 → 하루 150만 회 물리 쓰기
# → 두세 달 만에 카드 사망 (실제로 자주 일어납니다)
```

**★ 줄이는 방법 6가지** — ① 이벤트만 기록(743,040 → 하루 120 commit) ② WAL 모드
③ `synchronous=NORMAL` ④ 로그를 RAM 으로 ⑤ DEBUG 로그를 파일로 남기지 않음
⑥ 스냅샷·클립은 USB 메모리로.

```python
db.execute("PRAGMA journal_mode=WAL")       # ★ 쓰기 성능 + 수명
db.execute("PRAGMA synchronous=NORMAL")     # ★ 매 트랜잭션 fsync 안 함
```


### Step 1. `pi/events.py` — 이벤트 규칙 엔진

> ★ 이 파일은 Step 3 의 `tracker.py` 를 임포트합니다. 먼저 Step 3 을 읽어도 좋습니다.

```python
"""pi/events.py — 검출(detection)을 이벤트(event)로 승격하는 규칙 엔진

  관문 1  필터      conf · 최소 크기 · 관심 클래스
  관문 2  ROI       바닥 중앙 앵커 + 공간 히스테리시스
  관문 3  시간      N-of-M · 체류 시간
  관문 4  중복 억제  쿨다운 (type, roi)

Day 154 I-02(detector 응답)를 받아 I-03(이벤트) 을 만듭니다.
"""
from __future__ import annotations

import logging
import uuid
from collections import deque
from datetime import datetime, timedelta, timezone

import cv2
import numpy as np

from tracker import IoUTracker

logger = logging.getLogger("cctv.events")
KST = timezone(timedelta(hours=9))

DEFAULTS = {
    "device_id": "pi-entrance-01",
    "classes": ["person"],
    "min_conf": 0.55,          # ★ 이벤트 승격 임계값 (모델 conf 와 별개)
    "min_area_ratio": 1.5,     # ★ 프레임 대비 %
    "min_box_height": 40,      # px
    "nofm_n": 3, "nofm_m": 5,  # 최근 5프레임 중 3프레임
    "off_frames": 10,          # 연속 10프레임 미검출이면 종료 (히스테리시스)
    "roi_enter_frames": 3,
    "roi_exit_frames": 5,
    "roi_margin_px": 8.0,      # 공간 히스테리시스
    "anchor": "bottom",        # 바닥 중앙 — 사람은 발이 바닥에 닿습니다
    "loiter_sec": 30.0,
    "cooldown_sec": 30.0,
    "iou_match": 0.3,
    "track_max_miss": 10,
}


def now_iso(ts: datetime | None = None) -> str:
    """타임존 포함 ISO 8601 (Day 154 I-03 규격)"""
    return (ts or datetime.now(KST)).isoformat(timespec="milliseconds")


def anchor_point(box, mode="bottom"):
    """ROI 판정에 쓸 대표 점"""
    x1, y1, x2, y2 = box
    cx = (x1 + x2) / 2.0
    if mode == "bottom":
        return (cx, y2)                        # 발이 닿는 지점
    if mode == "center":
        return (cx, (y1 + y2) / 2.0)
    if mode == "bottom_third":
        return (cx, y1 + (y2 - y1) * 0.85)     # 발이 잘렸을 때 보정
    raise ValueError(f"알 수 없는 anchor: {mode}")


class NofM:
    """최근 M 프레임 중 N 프레임 이상 검출되면 True"""

    def __init__(self, n=3, m=5):
        self.n, self.m = n, m
        self.hits = deque(maxlen=m)            # maxlen 이 알아서 밀어냅니다

    def update(self, detected: bool) -> bool:
        self.hits.append(1 if detected else 0)
        return sum(self.hits) >= self.n

    def reset(self):
        self.hits.clear()


class Region:
    """폴리곤 관심 영역"""

    def __init__(self, name, points, classes=None, rules=None, enabled=True):
        self.name = name
        self.points = [(int(x), int(y)) for x, y in points]
        self.classes = set(classes) if classes else None
        self.rules = rules or {}
        self.enabled = enabled
        self._poly = np.array(self.points, np.int32)   # int32 필수

    def scaled(self, sx, sy) -> "Region":
        """ROI 를 그린 해상도와 현재 스트림 해상도가 다를 때"""
        pts = [(round(x * sx), round(y * sy)) for x, y in self.points]
        return Region(self.name, pts, self.classes, self.rules, self.enabled)

    def distance(self, pt) -> float:
        """+ 안쪽 / - 바깥쪽 (px)"""
        return cv2.pointPolygonTest(self._poly,
                                    (float(pt[0]), float(pt[1])), True)

    def accepts(self, class_name) -> bool:
        return self.classes is None or class_name in self.classes


def load_regions(path, frame_w, frame_h):
    """roi.json 로드 + 현재 해상도로 스케일링"""
    import json
    from pathlib import Path

    p = Path(path)
    if not p.exists():
        logger.warning("ROI 파일 없음: %s — ROI 규칙을 사용하지 않습니다", p)
        return []
    data = json.loads(p.read_text(encoding="utf-8"))
    src = data.get("frame", {})
    sx = frame_w / src.get("width", frame_w)                # 해상도 보정
    sy = frame_h / src.get("height", frame_h)
    regions = [Region(r["name"], r["points"], r.get("classes"), r.get("rules"))
               for r in data.get("regions", []) if r.get("enabled", True)]
    regions = [r if (sx == 1 and sy == 1) else r.scaled(sx, sy) for r in regions]
    logger.info("ROI %d개 로드 (%s) scale=%.3f,%.3f", len(regions),
                ", ".join(r.name for r in regions), sx, sy)
    return regions


class EventEngine:
    """검출 → 이벤트. 프레임마다 process() 를 호출합니다."""

    def __init__(self, config=None, regions=None):
        self.cfg = {**DEFAULTS, **(config or {})}
        self.regions = regions or []
        self.tracker = IoUTracker(self.cfg["iou_match"],
                                  self.cfg["track_max_miss"])
        self.nofm = {c: NofM(self.cfg["nofm_n"], self.cfg["nofm_m"])
                     for c in self.cfg["classes"]}
        self.present = {c: False for c in self.cfg["classes"]}
        self.miss = {c: 0 for c in self.cfg["classes"]}
        self.open_ev = {}          # class_name -> event(dict)  진행 중인 등장
        self._cooldown = {}        # (type, roi) -> 마지막 발행 시각(datetime)
        self.stats = {"frames": 0, "filtered": 0, "events": 0, "suppressed": 0}

    # ────────── 관문 1. 필터 ──────────
    def _filter(self, result):
        w = result["image"]["width"]
        h = result["image"]["height"]
        keep = []
        for d in result.get("detections", []):
            name = d.get("class") or d.get("class_name")
            if name not in self.cfg["classes"]:
                continue
            conf = float(d["conf"])
            if conf < self.cfg["min_conf"]:
                continue
            b = d["box"]
            box = ([b["x1"], b["y1"], b["x2"], b["y2"]]
                   if isinstance(b, dict) else list(b))
            bw, bh = box[2] - box[0], box[3] - box[1]
            if bh < self.cfg["min_box_height"]:
                continue
            if bw * bh / (w * h) * 100.0 < self.cfg["min_area_ratio"]:
                continue
            keep.append({"class_name": name, "conf": conf, "box": box,
                         "truncated": box[3] >= h - 2})     # 발 잘림 표시
        return keep, w, h

    # ────────── 관문 2. ROI ──────────
    def _update_roi_state(self, track):
        """트랙별 · 구역별 IN/OUT 상태를 갱신하고 '진입' 목록을 반환"""
        entered = []
        pt = anchor_point(track.box, self.cfg["anchor"])
        margin = self.cfg["roi_margin_px"]
        for reg in self.regions:
            if not reg.accepts(track.class_name):
                continue
            state = track.roi_state.get(reg.name, "OUTSIDE")
            d = reg.distance(pt)
            inside = d > margin if state == "OUTSIDE" else d > -margin
            key = reg.name
            if inside == (state == "INSIDE"):
                track.roi_streak[key] = 0
                continue
            track.roi_streak[key] = track.roi_streak.get(key, 0) + 1
            need = (self.cfg["roi_enter_frames"] if state == "OUTSIDE"
                    else self.cfg["roi_exit_frames"])
            if track.roi_streak[key] >= need:
                track.roi_state[key] = "INSIDE" if inside else "OUTSIDE"
                track.roi_streak[key] = 0
                if inside:
                    entered.append(reg)
        return entered

    def current_roi(self, track):
        for name, st in track.roi_state.items():
            if st == "INSIDE":
                return name
        return None

    # ────────── 관문 4. 쿨다운 ──────────
    def _allowed(self, etype, roi, ts) -> bool:
        key = (etype, roi or "-")                       # (type, roi) 조합
        last = self._cooldown.get(key)
        if last and (ts - last).total_seconds() < self.cfg["cooldown_sec"]:
            self.stats["suppressed"] += 1
            return False
        self._cooldown[key] = ts
        return True

    # ────────── 이벤트 생성 ──────────
    def _make(self, etype, ts, dets, roi=None, track=None, status="open"):
        eid = f"evt_{ts.strftime('%Y%m%d_%H%M%S')}_{uuid.uuid4().hex[:8]}"
        classes = {}
        for d in dets:
            classes[d["class_name"]] = classes.get(d["class_name"], 0) + 1
        return {                                        # Day 154 I-03 형식
            "event_id": eid,
            "type": etype,
            "ts": now_iso(ts),
            "device_id": self.cfg["device_id"],
            "classes": classes,
            "max_conf": round(max((d["conf"] for d in dets), default=0.0), 4),
            "roi": roi,
            "track_id": getattr(track, "track_id", None),
            "status": status,
            "snapshot": None,                           # storage 가 채웁니다
            "detections": [{"class_name": d["class_name"],
                            "conf": round(d["conf"], 4),
                            "box": [round(v, 1) for v in d["box"]]}
                           for d in dets],
        }

    # ────────── 메인 ──────────
    def process(self, result, ts=None):
        """프레임 1장 처리 → 발행할 이벤트 목록"""
        ts = ts or datetime.now(KST)
        self.stats["frames"] += 1
        dets, w, h = self._filter(result)
        self.stats["filtered"] += len(dets)
        events = []

        # ── 추적 ──
        alive, dead = self.tracker.update(dets, ts.timestamp())

        # ── ① 클래스 등장 / 종료 ──
        for cls in self.cfg["classes"]:
            cls_dets = [d for d in dets if d["class_name"] == cls]
            hit = bool(cls_dets)
            enough = self.nofm[cls].update(hit)
            if not self.present[cls]:
                if enough:
                    self.present[cls] = True
                    self.miss[cls] = 0
                    ev = self._make("person_detected" if cls == "person"
                                    else f"{cls}_detected", ts, cls_dets)
                    self.open_ev[cls] = ev
                    if self._allowed(ev["type"], None, ts):
                        events.append(ev)
                    else:
                        ev["_suppressed"] = True         # 기록은 하되 알림 없음
                        events.append(ev)
            else:
                self.miss[cls] = 0 if hit else self.miss[cls] + 1
                if self.miss[cls] >= self.cfg["off_frames"]:
                    self.present[cls] = False
                    self.nofm[cls].reset()
                    op = self.open_ev.pop(cls, None)
                    if op:
                        start = datetime.fromisoformat(op["ts"])
                        events.append({**op, "status": "closed",
                                       "ts_end": now_iso(ts),
                                       "duration_sec": round(
                                           (ts - start).total_seconds(), 1),
                                       "_close_of": op["event_id"]})

        # ── ③ ROI 침입 · ② 체류 ──
        for tr in alive:
            for reg in self._update_roi_state(tr):
                ev = self._make("intrusion", ts,
                                [{"class_name": tr.class_name,
                                  "conf": tr.conf, "box": tr.box}],
                                roi=reg.name, track=tr)
                if not self._allowed("intrusion", reg.name, ts):
                    ev["_suppressed"] = True
                events.append(ev)

            roi = self.current_roi(tr)
            limit = self.cfg["loiter_sec"]
            for reg in self.regions:
                if reg.name == roi and reg.rules.get("loiter_sec"):
                    limit = float(reg.rules["loiter_sec"])
            if ("loiter" not in tr.flags and limit > 0
                    and tr.age_sec >= limit):
                tr.flags.add("loiter")                   # track 당 1회만
                ev = self._make("loiter", ts,
                                [{"class_name": tr.class_name,
                                  "conf": tr.conf, "box": tr.box}],
                                roi=roi, track=tr)
                ev["duration_sec"] = round(tr.age_sec, 1)
                if not self._allowed("loiter", roi, ts):
                    ev["_suppressed"] = True
                events.append(ev)

        # ── 사라진 트랙 정리 ──
        for tr in dead:
            if "loiter" in tr.flags:
                logger.info("체류 종료 track=%d %.1f초", tr.track_id, tr.age_sec)

        self.stats["events"] += len(events)
        for ev in events:
            logger.info("EVENT %s roi=%s track=%s conf=%.2f%s",
                        ev["type"], ev.get("roi"), ev.get("track_id"),
                        ev["max_conf"],
                        " (쿨다운 억제)" if ev.get("_suppressed") else "")
        return events
```

### Step 2. `pi/roi_tool.py` — ROI 를 마우스로 그려 JSON 저장

```python
"""pi/roi_tool.py — 화면에서 마우스로 ROI 폴리곤을 그려 roi.json 으로 저장

  좌클릭 점 추가 · 우클릭 마지막 점 취소 · n 구역 확정 · r 초기화 · s 저장 후 종료
  python pi/roi_tool.py frame.jpg pi/roi.json
"""
import json, sys
from datetime import datetime
from pathlib import Path

import cv2
import numpy as np

state = {"pts": [], "regions": []}


def on_mouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        state["pts"].append((x, y))
    elif event == cv2.EVENT_RBUTTONDOWN and state["pts"]:
        state["pts"].pop()                                # ★ 마지막 점 취소


def commit(name):
    state["regions"].append({
        "name": name or f"roi{len(state['regions']) + 1}",
        "points": [list(p) for p in state["pts"]],
        "classes": ["person"],
        "rules": {"intrusion": True, "loiter_sec": 30},
        "enabled": True})
    state["pts"].clear()


base = cv2.imread(sys.argv[1])
h, w = base.shape[:2]
out = Path(sys.argv[2])
cv2.namedWindow("ROI")
cv2.setMouseCallback("ROI", on_mouse)

while True:
    img = base.copy()
    for r in state["regions"]:
        cv2.polylines(img, [np.array(r["points"], np.int32)],
                      True, (0, 255, 120), 2)
    for p in state["pts"]:
        cv2.circle(img, p, 5, (0, 200, 255), -1)
    cv2.imshow("ROI", img)

    k = cv2.waitKey(20) & 0xFF
    if k == ord("r"):
        state["pts"].clear()
    elif k == ord("n") and len(state["pts"]) >= 3:        # 폴리곤 최소 3점
        commit(input("구역 이름: ").strip())
    elif k == ord("s"):
        if len(state["pts"]) >= 3:
            commit("")
        out.write_text(json.dumps({
            "version": 1, "device_id": "pi-entrance-01",
            "created_at": datetime.now().isoformat(timespec="seconds"),
            "frame": {"width": w, "height": h},           # ★ 반드시 기록
            "regions": state["regions"]},
            indent=2, ensure_ascii=False), encoding="utf-8")
        cv2.imwrite(str(out.with_suffix(".preview.jpg")), img)
        print(f"저장: {out}  (구역 {len(state['regions'])}개)")
        break
    elif k in (ord("q"), 27):
        break
cv2.destroyAllWindows()
```

### Step 3. `pi/tracker.py` — IoU 기반 간이 추적

```python
"""pi/tracker.py — 프레임 간 IoU 매칭으로 객체에 ID 를 부여 (SORT 없이)

  목적은 두 가지뿐입니다.
    ① 체류 시간 측정 (누가 언제부터 있었나)
    ② 중복 알림 억제 (이 사람에게 이미 알렸나)
"""
from __future__ import annotations

import itertools


def iou(a, b) -> float:
    """a, b = (x1, y1, x2, y2)"""
    ix1, iy1 = max(a[0], b[0]), max(a[1], b[1])
    ix2, iy2 = min(a[2], b[2]), min(a[3], b[3])
    iw, ih = max(0.0, ix2 - ix1), max(0.0, iy2 - iy1)
    inter = iw * ih
    if inter <= 0:
        return 0.0
    area_a = max(0.0, a[2] - a[0]) * max(0.0, a[3] - a[1])
    area_b = max(0.0, b[2] - b[0]) * max(0.0, b[3] - b[1])
    return inter / (area_a + area_b - inter)


class Track:
    __slots__ = ("track_id", "class_name", "box", "conf", "first_seen",
                 "last_seen", "hits", "miss", "flags", "roi_state", "roi_streak")

    def __init__(self, tid, det, ts):
        self.track_id = tid
        self.class_name = det["class_name"]
        self.box = det["box"]
        self.conf = det["conf"]
        self.first_seen = ts
        self.last_seen = ts
        self.hits = 1
        self.miss = 0
        self.flags = set()          # ★ "loiter" 등 이미 발행한 이벤트 표시
        self.roi_state = {}         # 구역명 -> "INSIDE" | "OUTSIDE"
        self.roi_streak = {}        # 구역명 -> 연속 전이 후보 프레임 수

    def update(self, det, ts):
        self.box = det["box"]
        self.conf = det["conf"]
        self.last_seen = ts
        self.hits += 1
        self.miss = 0

    @property
    def age_sec(self) -> float:
        return self.last_seen - self.first_seen


class IoUTracker:
    """★ 30줄짜리 추적기 — 파이에서 비용이 사실상 0"""

    def __init__(self, iou_threshold=0.3, max_miss=10, max_tracks=64):
        self.thr = iou_threshold
        self.max_miss = max_miss
        self.max_tracks = max_tracks
        self.tracks: list[Track] = []
        self._ids = itertools.count(1)

    def update(self, detections, ts):
        """returns (살아있는 트랙, 이번에 사라진 트랙)"""
        pairs = sorted(
            ((iou(t.box, d["box"]), ti, di)
             for ti, t in enumerate(self.tracks)
             for di, d in enumerate(detections)
             if t.class_name == d["class_name"]),          # 같은 클래스끼리만
            reverse=True)

        used_t, used_d = set(), set()
        for score, ti, di in pairs:                        # 탐욕적 매칭
            if score < self.thr or ti in used_t or di in used_d:
                continue
            self.tracks[ti].update(detections[di], ts)
            used_t.add(ti)
            used_d.add(di)

        for ti, t in enumerate(self.tracks):
            if ti not in used_t:
                t.miss += 1

        for di, d in enumerate(detections):                # 매칭 안 된 검출 → 신규
            if di not in used_d and len(self.tracks) < self.max_tracks:
                self.tracks.append(Track(next(self._ids), d, ts))

        dead = [t for t in self.tracks if t.miss > self.max_miss]
        self.tracks = [t for t in self.tracks if t.miss <= self.max_miss]
        return list(self.tracks), dead
```

### Step 4. `pi/notify.py` — 텔레그램 + 이메일 + 재시도

```python
"""pi/notify.py — 비동기 알림 (텔레그램)

  · 메인 루프를 절대 막지 않습니다 (큐 + 워커 스레드)
  · 실패 시 지수 백오프 3회 → 폴백(아래 설명) → 폐기
  · 야간(23~07시)에는 무음. 단 intrusion 은 예외
  · 30초 창 안의 같은 (type, roi) 는 요약 1통으로 병합
"""
from __future__ import annotations

import logging
import os
import queue
import threading
import time
from datetime import datetime, time as dtime, timedelta, timezone
from pathlib import Path

import requests

logger = logging.getLogger("cctv.notify")
KST = timezone(timedelta(hours=9))

QUIET_START, QUIET_END = dtime(23, 0), dtime(7, 0)
ALWAYS_LOUD = {"intrusion"}
TYPE_LABEL = {"person_detected": "사람 감지", "intrusion": "구역 침입",
              "loiter": "장시간 체류"}
TYPE_ICON = {"person_detected": "👤", "intrusion": "🚨", "loiter": "⏱"}


def in_quiet_hours(now, start=QUIET_START, end=QUIET_END) -> bool:
    t = now.time()
    if start <= end:
        return start <= t < end
    return t >= start or t < end          # ★ 자정을 넘는 구간


class Notifier:
    def __init__(self, aggregate_sec=30.0, max_queue=200, dry_run=False):
        self.token = os.environ.get("TELEGRAM_BOT_TOKEN")
        self.chat = os.environ.get("TELEGRAM_CHAT_ID")
        self.dry_run = dry_run
        self.aggregate_sec = aggregate_sec
        self.q = queue.Queue(maxsize=max_queue)
        self._pending = {}                # (type, roi) -> {"first":ts,"items":[]}
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self.sent = self.failed = self.merged = 0
        if not self.token:
            logger.warning("★ TELEGRAM_BOT_TOKEN 이 없습니다 — 알림 비활성")
        threading.Thread(target=self._worker, daemon=True).start()
        threading.Thread(target=self._flusher, daemon=True).start()

    # ────────── 외부 API ──────────
    def push(self, event, snapshot=None):
        """메인 루프에서 호출. 즉시 반환합니다."""
        key = (event["type"], event.get("roi") or "-")
        with self._lock:
            slot = self._pending.get(key)
            if slot is None:                                # 첫 건은 즉시 발송
                self._pending[key] = {"first": time.time(), "items": []}
                self._enqueue({"kind": "single", "event": event,
                               "snapshot": snapshot})
            else:
                slot["items"].append(event)                 # 이후는 병합 버퍼로
                self.merged += 1

    def stop(self, timeout=5.0):
        self._stop.set()

    # ────────── 큐 ──────────
    def _enqueue(self, item):
        try:
            self.q.put_nowait(item)
        except queue.Full:
            logger.error("알림 큐 가득 참 — 가장 오래된 항목 폐기")
            try:
                self.q.get_nowait()
                self.q.put_nowait(item)      # 최신을 살립니다
            except queue.Empty:
                pass

    def _flusher(self):
        """30초 창이 끝나면 요약 1통"""
        while not self._stop.wait(2.0):
            now = time.time()
            with self._lock:
                for key in list(self._pending):
                    slot = self._pending[key]
                    if now - slot["first"] < self.aggregate_sec:
                        continue
                    items = slot["items"]
                    del self._pending[key]
                    if len(items) >= 2:      # 1건뿐이면 이미 보냈으므로 생략
                        self._enqueue({"kind": "summary", "key": key,
                                       "events": items})

    def _worker(self):
        while not self._stop.is_set():
            try:
                item = self.q.get(timeout=1.0)
            except queue.Empty:
                continue
            try:
                if item["kind"] == "single":
                    self._send(self._format(item["event"]),
                               item.get("snapshot"), item["event"])
                else:
                    self._send(self._format_summary(item["key"], item["events"]),
                               None, item["events"][0])
            except Exception:
                logger.exception("알림 처리 실패")
            finally:
                self.q.task_done()

    # ────────── 본문 ──────────
    def _format(self, ev):
        ts = datetime.fromisoformat(ev["ts"]).strftime("%m-%d %H:%M:%S")
        cls = " · ".join(f"{k} {v}명" for k, v in ev["classes"].items()) or "-"
        lines = [f"{TYPE_ICON.get(ev['type'], '🔔')} "
                 f"{TYPE_LABEL.get(ev['type'], ev['type'])}",
                 f"시각 {ts}", f"대상 {cls}", f"신뢰도 {ev['max_conf']:.2f}"]
        if ev.get("roi"):
            lines.append(f"구역 {ev['roi']}")
        if ev.get("duration_sec"):
            lines.append(f"체류 {ev['duration_sec']:.0f}초")
        return "\n".join(lines + [f"장치 {ev['device_id']}"])

    def _format_summary(self, key, events):
        etype, roi = key
        t0 = datetime.fromisoformat(events[0]["ts"])
        t1 = datetime.fromisoformat(events[-1]["ts"])
        peak = max((sum(e["classes"].values()) for e in events), default=0)
        return (f"{TYPE_ICON.get(etype, '🔔')} {TYPE_LABEL.get(etype, etype)} 요약\n"
                f"{t0:%H:%M:%S} ~ {t1:%H:%M:%S} ({(t1 - t0).total_seconds():.0f}초)\n"
                f"구역 {roi} · 이벤트 {len(events) + 1}건 · 최대 동시 {peak}명 · "
                f"최고 신뢰도 {max(e['max_conf'] for e in events):.2f}")

    # ────────── 발송 ──────────
    def _send(self, text, snapshot, ev):
        silent = ev["type"] not in ALWAYS_LOUD and in_quiet_hours(
            datetime.now(KST))
        for attempt in range(3):
            ok, retry = self._telegram(text, snapshot, silent)
            if ok:
                self.sent += 1
                return True
            if retry is False:                      # 4xx — 재시도 무의미
                break
            wait = 2 ** attempt if retry is True else retry
            logger.warning("텔레그램 실패 — %.0f초 후 재시도 (%d/3)",
                           wait, attempt + 1)
            time.sleep(wait)
        self.failed += 1
        logger.error("알림 최종 실패 — 폴백으로 넘깁니다")
        return False

    def _telegram(self, text, snapshot, silent):
        """returns (성공?, 재시도할까 / 대기초)"""
        if self.dry_run or not self.token:
            logger.info("[DRY-RUN 알림]\n%s", text)
            return True, False
        base = f"https://api.telegram.org/bot{self.token}"
        try:
            if snapshot and Path(snapshot).exists():
                with open(snapshot, "rb") as f:
                    r = requests.post(
                        f"{base}/sendPhoto", timeout=30,
                        data={"chat_id": self.chat, "caption": text[:1024],
                              "disable_notification": silent},
                        files={"photo": ("snap.jpg", f, "image/jpeg")})
            else:
                r = requests.post(
                    f"{base}/sendMessage", timeout=10,
                    data={"chat_id": self.chat, "text": text[:4096],
                          "disable_notification": silent})
        except requests.RequestException as e:
            logger.warning("텔레그램 네트워크 오류: %s", e)
            return False, True
        if r.status_code == 200:
            return True, False
        if r.status_code == 429:                    # 속도 제한
            wait = r.json().get("parameters", {}).get("retry_after", 5)
            return False, float(wait)
        if 400 <= r.status_code < 500:
            logger.error("텔레그램 %s (재시도 안 함): %s",
                         r.status_code, r.text[:200])
            return False, False
        return False, True
```

> ⚠️ **이메일 폴백은 여기서는 코드를 싣지 않습니다.**
> `_send()` 가 3회 실패한 자리에 `_email(text, snapshot)` 을 두고,
> 앞의 개념 설명에 나온 `EmailMessage` + `smtplib.SMTP("smtp.gmail.com", 587)`
> + `starttls()` + **앱 비밀번호** 조합을 그대로 넣으면 됩니다.
> 환경변수는 `SMTP_USER` · `SMTP_PASS` · `SMTP_TO` 3개이며, 텔레그램과 같은
> `.env` 에 둡니다. **이메일은 즉시성이 없으므로 "마지막 보루"로만 씁니다.**

### Step 5. `pi/storage.py` — 스냅샷 · 프리롤 · DB · 정리

```python
"""pi/storage.py — 이벤트 저장소

  · SQLite events 테이블 (Day 164 서버 스키마와 정합)
  · 스냅샷 (박스본 + 원본), 프리롤 클립
  · 보관 기간 정책 + 디스크 압박 시 강제 정리

CLI:
  python pi/storage.py --cleanup        systemd timer 가 매일 호출
"""
from __future__ import annotations

import argparse
import json
import logging
import shutil
import sqlite3
from collections import deque
from datetime import datetime, timedelta, timezone
from pathlib import Path

import cv2

logger = logging.getLogger("cctv.storage")
KST = timezone(timedelta(hours=9))
ROOT = Path(__file__).resolve().parent          # ★ 절대경로 — systemd 대비
DATA = ROOT / "data"

SCHEMA = """
CREATE TABLE IF NOT EXISTS events (
    event_id TEXT PRIMARY KEY, device_id TEXT NOT NULL, ts TEXT NOT NULL,
    type TEXT NOT NULL, classes_json TEXT NOT NULL DEFAULT '{}', max_conf REAL,
    snapshot_path TEXT, detections_json TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
    ts_end TEXT, status TEXT NOT NULL DEFAULT 'open', duration_sec REAL,
    track_id INTEGER, roi TEXT, raw_path TEXT, clip_path TEXT,
    notified INTEGER NOT NULL DEFAULT 0, synced INTEGER NOT NULL DEFAULT 0,
    sync_attempts INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_ev_ts     ON events(ts);
CREATE INDEX IF NOT EXISTS idx_ev_type   ON events(type, ts);
CREATE INDEX IF NOT EXISTS idx_ev_synced ON events(synced) WHERE synced = 0;
"""

RETENTION = {"clips": 2, "raw": 3, "snapshots": 7, "rows": 90}


class PreRollBuffer:
    """★ 최근 N초 프레임을 메모리에 유지 (640×480 으로 축소해서)"""

    def __init__(self, seconds=5.0, fps=8.6, size=(640, 480)):
        self.buf = deque(maxlen=max(1, int(seconds * fps)))
        self.size = size

    def push(self, frame, ts):
        small = cv2.resize(frame, self.size)
        self.buf.append((ts, small.copy()))          # copy 필수
        return self

    def frames(self):
        return list(self.buf)


class Storage:
    def __init__(self, db_path=None, snap_root=None):
        self.db_path = Path(db_path or DATA / "cctv.db")
        self.snap_root = Path(snap_root or DATA)
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self.db = sqlite3.connect(self.db_path, check_same_thread=False)
        self.db.row_factory = sqlite3.Row
        self.db.execute("PRAGMA journal_mode=WAL")      # SD 카드 수명
        self.db.execute("PRAGMA synchronous=NORMAL")
        self.db.execute("PRAGMA busy_timeout=5000")
        self.db.executescript(SCHEMA)
        self._close_orphans()

    def _close_orphans(self):
        """★ 지난번 비정상 종료로 남은 status='open' 행을 시작할 때 정리"""
        n = self.db.execute("""
            UPDATE events SET status='closed',
                   ts_end = COALESCE(ts_end, ts),
                   duration_sec = COALESCE(duration_sec, 0)
             WHERE status='open'""").rowcount
        self.db.commit()
        if n:
            logger.warning("고아 이벤트 %d건 정리 (지난번 비정상 종료)", n)

    # ────────── 스냅샷 ──────────
    def _paths(self, ev):
        ts = datetime.fromisoformat(ev["ts"])
        cls = max(ev["classes"], key=ev["classes"].get, default="obj")
        stem = (f"{ts.strftime('%Y%m%d_%H%M%S')}_{cls}_"
                f"{ev['event_id'][-8:]}")               # 파일명 규칙
        sub = ts.strftime("%Y/%m/%d")
        return (self.snap_root / "snapshots" / sub / f"{stem}.jpg",
                self.snap_root / "snapshots" / sub / f"{stem}_raw.jpg",
                self.snap_root / "clips" / sub / f"{stem}.mp4")

    def save_snapshot(self, ev, frame, drawn=None):
        """박스본 + 원본을 함께 저장"""
        p_box, p_raw, _ = self._paths(ev)
        p_box.parent.mkdir(parents=True, exist_ok=True)
        q = [cv2.IMWRITE_JPEG_QUALITY, 88]
        cv2.imwrite(str(p_raw), frame, q)
        cv2.imwrite(str(p_box), drawn if drawn is not None else frame, q)
        ev["snapshot"] = str(p_box.relative_to(self.snap_root))
        return p_box, p_raw

    def save_clip(self, ev, frames, fps=8.6, size=(640, 480)):
        """프리롤 버퍼의 프레임들을 mp4 로 기록. ★ isOpened() 확인이 핵심"""
        _, _, path = self._paths(ev)
        path.parent.mkdir(parents=True, exist_ok=True)
        vw = cv2.VideoWriter(str(path),
                             cv2.VideoWriter_fourcc(*"mp4v"), fps, size)
        if not vw.isOpened():                          # 예외를 안 던짐
            logger.error("VideoWriter 열기 실패: %s", path)
            return None
        for _, f in frames:
            vw.write(f if (f.shape[1], f.shape[0]) == size
                     else cv2.resize(f, size))
        vw.release()
        return path

    # ────────── 이벤트 ──────────
    def insert(self, ev, snapshot=None, raw=None, clip=None):
        self.db.execute("""
            INSERT OR IGNORE INTO events
              (event_id, device_id, ts, type, classes_json, max_conf,
               snapshot_path, detections_json, status, track_id, roi,
               raw_path, clip_path, duration_sec)
            VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)""",
            (ev["event_id"], ev["device_id"], ev["ts"], ev["type"],
             json.dumps(ev["classes"], ensure_ascii=False), ev["max_conf"],
             str(snapshot) if snapshot else None,
             json.dumps(ev.get("detections", []), ensure_ascii=False),
             ev.get("status", "open"), ev.get("track_id"), ev.get("roi"),
             str(raw) if raw else None, str(clip) if clip else None,
             ev.get("duration_sec")))
        self.db.commit()

    def close_event(self, event_id, ts_end, duration_sec):
        self.db.execute(
            "UPDATE events SET status='closed', ts_end=?, duration_sec=? "
            "WHERE event_id=?", (ts_end, duration_sec, event_id))
        self.db.commit()

    def mark_notified(self, event_id):
        self.db.execute("UPDATE events SET notified=1 WHERE event_id=?",
                        (event_id,))
        self.db.commit()

    def unsynced(self, limit=20):
        """Day 169 sync.py 가 읽어 갈 아웃박스"""
        return self.db.execute(
            "SELECT * FROM events WHERE synced=0 AND sync_attempts<100 "
            "ORDER BY ts LIMIT ?", (limit,)).fetchall()

    # ────────── 정리 ──────────
    def cleanup(self, retention=None):
        """RETENTION 을 기본값으로, 디스크 사용률에 따라 보관일을 줄여 삭제"""
        ret = dict(RETENTION, **(retention or {}))
        total, used, _ = shutil.disk_usage(self.snap_root)
        pct = used / total * 100
        if pct >= 90:                                  # 압박 단계별 축소
            ret = {**ret, "clips": 0, "raw": 1, "snapshots": 2}
        elif pct >= 80:
            ret = {**ret, "clips": 1, "raw": 1}
        stats = {"disk_pct": round(pct, 1)}
        for folder in ("clips", "snapshots"):
            stats[folder] = self._purge(self.snap_root / folder,
                                        ret[folder], ret["raw"])
        cutoff = (datetime.now(KST) - timedelta(days=ret["rows"])).isoformat()
        stats["rows_deleted"] = self.db.execute(
            "DELETE FROM events WHERE ts < ? AND synced=1", (cutoff,)).rowcount
        self.db.commit()
        self.db.execute("VACUUM")                      # 파일 크기 회수
        logger.info("정리 완료 %s", stats)
        return stats
```

`_purge(root, days, raw_days)` 는 `root.rglob("*")` 를 돌며 `st_mtime` 이 기준보다

### Step 6. `pi/main.py` — CCTV 데몬

```python
"""pi/main.py — CCTV 데몬 (Day 170)

  카메라 → 검출 → 이벤트 판정 → 스냅샷/DB → 알림 → 서버 전송

  실행:  .venv/bin/python -u pi/main.py
  종료:  Ctrl+C 또는 systemctl stop cctv
"""
from __future__ import annotations

import logging
import os
import signal
import sys
import time
from datetime import datetime, timedelta, timezone
from pathlib import Path

import cv2

ROOT = Path(__file__).resolve().parents[1]      # ★ 절대경로 (systemd cwd 대비)
sys.path.insert(0, str(ROOT / "src"))
sys.path.insert(0, str(ROOT / "pi"))

from detector import get_detector                       # noqa: E402  Day 152
from events import EventEngine, load_regions            # noqa: E402
from notify import Notifier                             # noqa: E402
from storage import PreRollBuffer, Storage              # noqa: E402
from sync import EventSync                              # noqa: E402  Day 169

KST = timezone(timedelta(hours=9))
HEARTBEAT = Path(os.environ.get("CCTV_HEARTBEAT", "/dev/shm/cctv.hb"))

logging.basicConfig(
    level=logging.INFO,
    format="[%(levelname)s] %(message)s")     # ★ 시각은 journald 가 붙입니다
logger = logging.getLogger("cctv")

CONFIG = {
    "device_id": os.environ.get("CCTV_DEVICE_ID", "pi-entrance-01"),
    "classes": ["person"],
    "min_conf": float(os.environ.get("CCTV_MIN_CONF", 0.55)),
    "cooldown_sec": float(os.environ.get("CCTV_COOLDOWN", 30)),
    "loiter_sec": float(os.environ.get("CCTV_LOITER", 30)),
}
MODEL_CONF = 0.35            # 모델은 넉넉히 뽑고 events.py 에서 다시 거릅니다
CAM_INDEX = int(os.environ.get("CCTV_CAM", 0))
FRAME_W, FRAME_H = 1280, 720
PREROLL_SEC = 5.0

running = True


def _stop(signum, frame):
    global running
    logger.info("종료 신호 수신 (%s) — 정리 중", signum)
    running = False


def open_camera(retries=30, delay=2.0):
    """부팅 직후에는 카메라가 아직 준비되지 않을 수 있습니다"""
    for i in range(retries):
        cap = cv2.VideoCapture(CAM_INDEX)
        cap.set(cv2.CAP_PROP_FRAME_WIDTH, FRAME_W)
        cap.set(cv2.CAP_PROP_FRAME_HEIGHT, FRAME_H)
        cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)     # 최신 프레임 (Day 153)
        if cap.isOpened():
            ok, _ = cap.read()
            if ok:
                logger.info("카메라 열기 성공 %dx%d",
                            int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)),
                            int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)))
                return cap
        cap.release()
        logger.warning("카메라 열기 실패 (%d/%d) — %.0f초 후 재시도",
                       i + 1, retries, delay)
        time.sleep(delay)
    raise RuntimeError("카메라를 열 수 없습니다")


def draw(frame, dets):
    img = frame.copy()                          # 원본을 건드리지 않습니다
    for d in dets:
        x1, y1, x2, y2 = [int(v) for v in d["box"]]
        cv2.rectangle(img, (x1, y1), (x2, y2), (0, 220, 0), 2)
        cv2.putText(img, f'{d["class_name"]} {d["conf"]:.2f}',
                    (x1, max(16, y1 - 6)), cv2.FONT_HERSHEY_SIMPLEX,
                    0.55, (0, 220, 0), 2)
    cv2.putText(img, datetime.now(KST).strftime("%Y-%m-%d %H:%M:%S"),
                (10, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 255, 255), 2)
    return img


def main():
    signal.signal(signal.SIGINT, _stop)
    signal.signal(signal.SIGTERM, _stop)

    logger.info("모델 로드 시작")
    t0 = time.perf_counter()
    det = get_detector(profile="pi")                     # NCNN (Day 153)
    logger.info("모델 로드 완료 (%.2fs)", time.perf_counter() - t0)

    cap = open_camera()
    regions = load_regions(ROOT / "pi/roi.json", FRAME_W, FRAME_H)
    engine = EventEngine(CONFIG, regions)
    store = Storage()
    notifier = Notifier(aggregate_sec=CONFIG["cooldown_sec"])
    sync = EventSync(os.environ.get("CCTV_SERVER_URL", ""), storage=store)
    preroll = PreRollBuffer(PREROLL_SEC, fps=8.6)

    logger.info("감시 시작 device=%s classes=%s ROI=%d개",
                CONFIG["device_id"], CONFIG["classes"], len(regions))

    frames = fail = 0
    last_hb = last_report = time.time()
    t_start = time.time()

    while running:
        ok, frame = cap.read()
        if not ok or frame is None:
            fail += 1
            logger.warning("프레임 읽기 실패 (%d)", fail)
            if fail >= 10:                               # 카메라 재연결
                logger.error("카메라 재연결 시도")
                cap.release()
                cap = open_camera()
                fail = 0
            time.sleep(0.2)
            continue
        fail = 0
        frames += 1
        now = datetime.now(KST)
        preroll.push(frame, now.timestamp())

        try:
            result = det.predict_image(frame, conf=MODEL_CONF)
        except Exception:
            logger.exception("추론 실패 — 이 프레임을 건너뜁니다")
            continue

        for ev in engine.process(result, now):
            if ev.get("_close_of"):                      # 종료 이벤트
                store.close_event(ev["_close_of"], ev["ts_end"],
                                  ev["duration_sec"])
                continue

            drawn = draw(frame, [{"class_name": d["class_name"],
                                  "conf": d["conf"], "box": d["box"]}
                                 for d in ev["detections"]])
            p_box, p_raw = store.save_snapshot(ev, frame, drawn)
            clip = (store.save_clip(ev, preroll.frames())
                    if ev["type"] == "intrusion" else None)
            store.insert(ev, snapshot=p_box, raw=p_raw, clip=clip)

            if not ev.get("_suppressed"):                # 쿨다운 통과분만 알림
                notifier.push(ev, snapshot=p_box)
                store.mark_notified(ev["event_id"])
            sync.enqueue(ev, p_box)                      # Day 169 아웃박스

        if time.time() - last_hb > 10:                   # 하트비트 (tmpfs)
            HEARTBEAT.write_text(str(int(time.time())))
            last_hb = time.time()

        if time.time() - last_report > 300:              # 5분마다 요약
            el = time.time() - t_start
            logger.info("가동 %.0f분 · %d프레임 · %.1f FPS · 이벤트 %d "
                        "· 억제 %d · 알림 %d/%d · 미전송 %d",
                        el / 60, frames, frames / el, engine.stats["events"],
                        engine.stats["suppressed"], notifier.sent,
                        notifier.sent + notifier.failed, len(store.unsynced()))
            last_report = time.time()

    logger.info("정리 중 — 카메라 해제")
    cap.release()
    notifier.stop()
    sync.stop()
    logger.info("종료 완료 (총 %d프레임, 이벤트 %d건)",
                frames, engine.stats["events"])


if __name__ == "__main__":
    main()
```

### 상태 기계 — "사라짐(removal)" 이벤트

```
   NO_BOX ──ROI 안에서 ★ 30초 이상 연속 검출──▶ PRESENT
      ▲                                          │ 미검출 시작
      │                                          ▼
```

**① ★ 확인 지연을 길게** — 사람이 상자 앞을 지나가면 1~3초 가려집니다.
3초로 판정하면 하루에 수십 번 "상자 분실" 알림. **60초를 기다립니다.**

**② ★ 사람이 함께 있었는지 확인** — 상자는 스스로 걸어가지 않습니다.

```python
if state == "MISSING?" and missing_sec >= 60:

        etype = "box_removed_by_person"     # ★ 누가 가져감 (알림)
    else:
        etype = "box_lost_detection"        # 사람 없이 사라짐 = 검출 실패 의심
```

**③ ★ 낮은 conf 로 재확인(2단 임계값)** — 있음 판정은 `conf ≥ 0.55`(엄격),
없음 판정은 `conf ≥ 0.25` 로도 안 보일 때만(관대). 상자가 그림자에 들어가
conf 가 0.38 로 떨어진 것을 "사라졌다"고 하면 안 됩니다.

- [ ] `roi.json` 에 **`frame` 크기**가 기록되어 있다 · 추적으로 `track_id` 가 부여된다
- [ ] 체류 이벤트가 ★ **track 당 1회**만 · 쿨다운 키가 **`(type, roi)`** 이다
- [ ] 스냅샷 파일명에 콜론·공백이 없다 · 프리롤이 **`frame.copy()`** 를 쓴다
- [ ] `events` 테이블이 **Day 164 스키마와 정합**이고 `synced` 로 미전송을 추적한다
- [ ] ★ **토큰이 코드에 없다** (`.env` + `.gitignore`)
- [ ] 알림이 ★ **별도 스레드**에서 나간다 · 야간 무음이 **자정을 넘어 동작**한다
- [ ] `.service` 에 `WorkingDirectory` · **venv 절대경로** · `RestartSec` 이 있다
- [ ] ★ **전원을 뽑았다 꽂아** 자동 시작을 확인했다
- [ ] `systemd timer` 로 정리가 예약되어 있다
- [ ] 매 프레임 DB 쓰기를 하지 않는다 · 하트비트를 **tmpfs** 에 쓴다
