맛집커뮤니티 — 화면 목업

360×740 기준 반응형 화면 8장. 디자인 토큰·타이포·스페이싱·컴포넌트 상태는 책의 규칙을 그대로 따랐고, 브랜드 컬러만 따뜻한 녹색(Moss)으로 다시 뽑았습니다.

이 페이지는 목업입니다. 지도는 CSS로 그린 모형이고, 네이버 지역 검색 결과·구글 로그인·DB·이미지 업로드는 모두 화면 안에 넣어 둔 더미 데이터입니다. 실제 연동은 Day 24~27에서 BFF와 API 키로 대체합니다. 화면 전환과 상태 변화는 실제로 동작하니 눌러 보세요.
