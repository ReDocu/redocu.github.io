## 문서 구조

각 일차 문서는 아래 7절로 되어 있다. (PRD 7절 구조를 1일 단위로 압축)

| 절 | 내용 |
|:--:|---|
| 1 | **오늘 만드는 것** — 완성 화면을 글로 묘사 (30초 안에 감이 오게) |
| 2 | **막히는 상황** — 왜 오늘 개념이 필요해졌는가 |
| 3 | **개념** — 3~13개. 각각 "왜 필요한가" 한 줄 + 설명 + 코드 + 도해 |
| 4 | **따라 만들기** — Step 1..N. 각 Step은 그 시점에서 실행 가능 |
| 5 | **실행 결과** — 정상이면 무엇이 보이는가 (자가 검증 체크리스트) |
| 6 | **자주 막히는 곳** — 증상 / 원인 / 해결 표 |
| 7 | **정리** — 배운 것 / 앞으로 쓰이는 곳 / 확장 과제 / 다음 시간 |

> 모든 Step은 **그 시점에서 빌드해 돌려볼 수 있는 상태**여야 한다. (PRD 5.1)
> 이미지 파일 없이 코드·모노스페이스 도해·표만으로 설명이 성립한다. (PRD 6절)
