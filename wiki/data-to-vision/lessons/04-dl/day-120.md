```
심사자: "왜 이 모델을 고르셨나요?"
학생:   "MAE가 가장 낮았습니다."

```

**[Day 114](day-114.md)에서 배운 것입니다.**

```
seed 10개 변동폭이 ±0.019인데
1등과 2등의 차이가 0.0017
→ 차이의 1/11. 완전한 노이즈
```

**두 모델은 동등합니다.** 그러면 **다른 기준**으로 골라야 합니다.

### 그리고 선택 기준은 미리 정해야 합니다

```
[나쁜 순서]
실험 20개 → 결과를 봄 → "MAE가 좋은 걸로 하자" → 선정

[좋은 순서]
목표 정의 → 실험 20개 → 사전 기준으로 판정 → 선정
```

**결과를 보고 기준을 정하면, 자기가 원하는 답이 나오게 기준을 고르게 됩니다.**

이것을 **사후 합리화(post-hoc rationalization)** 라고 하며, 연구 부정행위의 흔한 형태입니다.

## ③ 개념 설명

### "성능이 좋다"의 조건 — 시작 시점에 정하기

**4가지를 정해야 합니다.**

| 항목 | 예시 |
|---|---|
| **주 지표** | MAE (부: RMSE, R²) |
| **목표치** | MAE < 0.40 |
| **비교 기준** | 평균 예측(0.906) 대비 55% 이상 개선 |
| **구분 가능한 최소 차이** | 5% (검증셋 크기로 계산) |

**"구분 가능한 최소 차이"가 오늘의 핵심입니다.**

```
[Day 114] n = (2σ / 목표차이)²

검증셋 4,128건, 오차 표준편차 0.46
→ 구분 가능한 차이 = 2 × 0.46 / √4128 = 0.0143

즉, MAE 차이가 0.0143 미만이면 "동등"입니다.
```

### 유의미성 판단 — 3가지 방법

**① seed 반복 + 표준편차**

```python
scores = [run(seed=s) for s in range(10)]
print(f"{np.mean(scores):.4f} ± {np.std(scores):.4f}")
```

**두 모델의 구간이 겹치면 동등합니다.**

```
모델 A: 0.3187 ± 0.0184  →  [0.300, 0.337]
모델 B: 0.3204 ± 0.0191  →  [0.301, 0.340]
                            └─── 크게 겹침 ───┘
```

**② 쌍체 비교 (paired comparison)** — 더 강력합니다

```python
diff = [a_s - b_s for a_s, b_s in zip(scores_a, scores_b)]   # 같은 seed끼리
```

**같은 분할에서 비교하므로 분할의 영향이 상쇄됩니다.**

```
차이 평균 -0.0017 ± 0.0021
표준오차 = 0.0021 / √10 = 0.00066
|평균| / 표준오차 = 2.58   →  경계선
```

**판정 기준**

| \|평균차이\| / 표준오차 | 판정 |
|---|---|
| < 2 | **동등** |
| 2 ~ 3 | 경계. 추가 실험 권장 |
| > 3 | **유의미한 차이** |

**③ 승률 (win rate)**

```python
wins = sum(a < b for a, b in zip(scores_a, scores_b))
```

| 승률 | 판정 |
|---|---|
| 40~60% | **동등** (동전 던지기) |
| 60~80% | 약한 우위 |
| **> 80%** | **명확한 우위** |

> **세 가지를 함께 보세요.**
> 승률 90%인데 평균 차이가 작으면 **"일관되게 조금 낫다"** 입니다.
> 승률 60%인데 평균 차이가 크면 **"가끔 크게 낫다"** 입니다. 안정성이 낮습니다.

### 동등할 때의 결정 기준 — 우선순위

```
성능이 통계적으로 동등하다면:

① 더 단순한 모델        (오컴의 면도날)
② 더 빠른 모델
③ 더 해석 가능한 모델
④ 더 안정적인 모델      (곡선 진단, 표준편차)
⑤ 팀이 다룰 수 있는 모델
⑥ 배포 환경에 적합한 모델
```

> **"성능이 같으면 단순한 것을 고른다"** 가 기본 원칙입니다.
> 단순한 모델은 디버깅·설명·유지보수가 전부 쉽습니다.

### 선정 사유 3줄 형식

```
1줄: 무엇을 골랐고 그 성능은 얼마인가
2줄: 왜 그것인가 (1~2등이 동등하면 결정 기준을 명시)
3줄: 어떤 한계를 알고 있는가
```

**예시**

```
① HistGB (log1p)를 채택. 검증 MAE 0.3018 ± 0.0091, 베이스라인 대비 66.7% 개선.
② 신경망(0.3187)과 통계적으로 동등하나(쌍체 차이 0.0169 ± 0.0142, 승률 65%),
   학습이 24배 빠르고 특성 중요도로 설명이 가능해 선택.
③ 최상위 가격 구간에서 오차율 14.8%로 취약. 타깃 상한 절단(4.7%)이 원인이며
   데이터로는 해결 불가. 해당 구간은 "참고값"으로만 제공.
```

### Step 2. 후보 모델 3종 학습

```python
import time

import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.compose import TransformedTargetRegressor
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

SEED = 42


def build_nn(n_features, units=(128, 64, 32), dropout=0.2, lr=3e-4, seed=SEED):
    tf.random.set_seed(seed)
    m = keras.Sequential([layers.Input(shape=(n_features,))])
    for u in units:
        m.add(layers.Dense(u, activation="relu"))
        if dropout:
            m.add(layers.Dropout(dropout))
    m.add(layers.Dense(1))
    m.compile(optimizer=keras.optimizers.Adam(lr), loss="mse", metrics=["mae"])
    return m


def train_candidate(name, X_tr, y_tr, X_va, y_va, seed=SEED):
    """후보 하나를 학습하고 예측·시간·크기를 반환"""
    t0 = time.perf_counter()

    if name == "A. 릿지":
        model = TransformedTargetRegressor(
            regressor=Pipeline([("sc", StandardScaler()),
                                ("m", RidgeCV(alphas=np.logspace(-3, 3, 30)))]),
            func=np.log1p, inverse_func=np.expm1)
        model.fit(X_tr, y_tr)
        fit_t = time.perf_counter() - t0
        t1 = time.perf_counter()
        pred = model.predict(X_va)
        pred_t = time.perf_counter() - t1
        hist = None
        size_kb = 4

    elif name == "B. HistGB":
        model = TransformedTargetRegressor(
            regressor=HistGradientBoostingRegressor(max_iter=300, random_state=seed),
            func=np.log1p, inverse_func=np.expm1)
        model.fit(X_tr, y_tr)
        fit_t = time.perf_counter() - t0
        t1 = time.perf_counter()
        pred = model.predict(X_va)
        pred_t = time.perf_counter() - t1
        hist = None
        size_kb = 1840

    elif name == "C. 신경망":
        sc = StandardScaler().fit(X_tr)
        Xtr_s, Xva_s = sc.transform(X_tr), sc.transform(X_va)
        m = build_nn(Xtr_s.shape[1], seed=seed)
        es = keras.callbacks.EarlyStopping(monitor="val_loss", patience=25,
                                           restore_best_weights=True)
        rl = keras.callbacks.ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                                               patience=10, min_lr=1e-6)
        hist = m.fit(Xtr_s, np.log1p(y_tr),
                     validation_data=(Xva_s, np.log1p(y_va)),
                     epochs=300, batch_size=64, callbacks=[es, rl], verbose=0)
        fit_t = time.perf_counter() - t0
        t1 = time.perf_counter()
        pred = np.expm1(m.predict(Xva_s, verbose=0).ravel())
        pred_t = time.perf_counter() - t1
        model = (sc, m)
        size_kb = 187
    else:
        raise ValueError(name)

    return {"model": model, "pred": pred, "hist": hist,
            "fit_time": fit_t, "pred_time_ms": pred_t * 1000,
            "size_kb": size_kb}


CANDIDATES = ["A. 릿지", "B. HistGB", "C. 신경망"]
results = {c: train_candidate(c, X_train, y_train, X_val, y_val)
           for c in CANDIDATES}

print("=" * 92)
print("후보 3종 — 기본 지표")
print("=" * 92)
rows = []
for name, r in results.items():
    p = r["pred"]
    rows.append({
        "모델": name,
        "MAE": round(mean_absolute_error(y_val, p), 4),
        "RMSE": round(float(np.sqrt(mean_squared_error(y_val, p))), 4),
        "R²": round(r2_score(y_val, p), 4),
        "베이스라인대비(%)": round((base_mae - mean_absolute_error(y_val, p)) / base_mae * 100, 1),
        "학습(s)": round(r["fit_time"], 2),
        "예측(ms)": round(r["pred_time_ms"], 1),
        "크기(KB)": r["size_kb"],
    })

basic["목표달성"] = np.where(basic["MAE"] < goal["목표치 MAE"], "✓", "✗")
print(basic.to_string(index=False))
print("=" * 92)

best_mae = basic["MAE"].min()
near = basic[basic["MAE"] - best_mae < goal["구분 가능한 최소 차이"]]
print(f"\n최고 MAE {best_mae:.4f}")
print(f"구분 가능한 최소 차이 {goal['구분 가능한 최소 차이']:.4f} 이내 모델: "

print(f"→ {'★ 동등한 후보가 여러 개입니다. 다른 기준이 필요합니다.' if len(near) > 1 else '1위가 명확합니다.'}")

fig, axes = plt.subplots(3, 3, figsize=(19, 15))

diag_rows = []

    ax.set_xlim(lo, hi); ax.set_ylim(lo, hi)

    ax.set_xlabel("target bin"); ax.set_ylabel("error rate (%)")
    ax.set_title(f"{name} — worst bin {rate.max():.1f}%")

    diag_rows.append({
        "모델": name,

**① 유의미성 판정**

**Q vs R**

```
평균 차이   -60
표준편차    148
표준오차    148 / √10 = 46.8
t비         |−60| / 46.8 = 1.28
```

| 기준 | 값 | 판정 |
|---|---|---|
| t비 | 1.28 | **< 2 → 동등** |
| 승률 | 70% | 60~80% → 약한 우위 |
| 차이(60) vs 구분 가능(294) | 60 < 294 | **구분 불가** |

**→ Q와 R은 통계적으로 동등합니다.**

**P vs Q**

```
평균 차이   +640
표준오차    156 / √10 = 49.3
t비         640 / 49.3 = 12.98
승률        0% (Q가 10/10 승)
차이(640) vs 구분 가능(294)  →  640 > 294
```

**→ Q가 P보다 유의미하게 낫습니다.**

**② 선정: Q (LightGBM)**

**③ 선정 사유 3줄**

```
① Q(LightGBM)를 채택. 검증 MAE 4,180 ± 184 (seed 10회)로 목표(4,500) 달성,
   베이스라인 6,340 대비 34.1% 개선.

② R(신경망, 4,240)과는 통계적으로 동등하나(t비 1.28, 차이 60 < 구분 가능 294),
   학습 13배·예측 8배 빠르고 특성 중요도로 설명 가능하며 seed 변동이 24% 작아 선택.

③ 최악 구간 오차율 22%로 특정 구간에서 취약. P(릿지)는 목표 미달(4,820)이고
   최악 구간 38%로 탈락.
```

**②의 논리가 핵심입니다.**

```
성능이 동등 → 다른 기준으로 결정
  · 속도:     Q가 13배 빠름
  · 해석성:   Q가 우위
  · 안정성:   Q 표준편차 184 vs R 241
→ 세 기준 모두 Q
```

> **"MAE가 낮아서 Q를 골랐다"고 쓰면 감점입니다.**
> **Q와 R은 동등합니다.** 동등함을 인정하고 다른 근거를 대는 것이 정확합니다.

**추가로 확인할 것**

```

   → 다만 목표 미달이므로 현재는 탈락

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 목표 정의 시점 | **실험 전에.** 결과를 보고 정하면 사후 합리화 |
| 정의서 4요소 | 주 지표 · 목표치 · **비교 기준** · **구분 가능한 최소 차이** |
| 구분 가능한 차이 | **`2σ / √n`.** 이보다 작으면 동등 |
| 유의미성 ① | seed 반복 + 표준편차. **구간이 겹치면 동등** |
| 유의미성 ② | **쌍체 비교.** t비 = \|평균차이\| / 표준오차 |
| t비 판정 | **< 2 동등 · 2~3 경계 · > 3 유의미** |
| 유의미성 ③ | 승률. **40~60% 동전 던지기 · > 80% 명확한 우위** |
| 쌍체의 조건 | **같은 분할에서 모든 모델 평가** |
| 통합 근거표 | 성능 · 안정성 · **신뢰성** · 비용 · 운영 |
| 신뢰성 항목 | 기울기 · 잔차 편향 · 이분산 · **최악 구간 오차율** |
| 동등 시 결정 | **단순성 → 속도 → 해석성 → 안정성 → 팀 역량** |
| 모델별 곡선 | 신경망 에폭 · **트리 반복 수** · 선형 규제 강도 |
| 트리의 격차 | 커도 정상. **모델 종류별 정상 범위**가 다름 |
| 선정 사유 3줄 | ①무엇·성능 ②왜(동등하면 결정 기준) ③**한계** |
| 탈락 사유 | 반드시 명시. "왜 다른 건 안 되나요?" |
| 테스트셋 | **아직 봉인.** [Day 125](day-125.md)에서 1회 |

**오늘 반드시 기억할 세 가지**
> ① **"성능이 좋다"의 기준을 실험 전에 숫자로 정하세요.**
> ② **차이가 구분 가능한 최소 차이보다 작으면 동등입니다.** 억지로 순위를 매기지 마세요.
> ③ **동등하면 단순한 것을 고르세요.** 그리고 그 근거를 3줄로 말할 수 있어야 합니다.
