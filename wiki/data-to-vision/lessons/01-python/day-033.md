## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- `INSERT` 로 데이터를 넣고 **파라미터 바인딩**으로 SQL 인젝션을 막을 수 있다.
- `SELECT` + `WHERE` + `ORDER BY` + `LIMIT` 으로 원하는 데이터만 꺼낼 수 있다.
- `COUNT` `SUM` `AVG` `MAX` `GROUP BY` 로 집계할 수 있다.

## ② 왜 필요한가

어제 표를 만들었습니다. **빈 표입니다.**

오늘 배우는 `SELECT` 는 데이터베이스에서 **가장 많이 쓰는 명령**입니다.
실무에서 SQL 작업의 80%가 조회입니다.

그리고 **파라미터 바인딩**은 보안의 기본입니다.

```python
# ❌ 이렇게 쓰면 서비스가 털립니다
name = input("이름: ")
cursor.execute(f"SELECT * FROM users WHERE name = '{name}'")
```

사용자가 `' OR '1'='1` 을 입력하면 **전체 사용자 정보가 노출**됩니다.
이것을 **SQL 인젝션**이라고 하며, 오늘 그 방어법을 배웁니다.

## ③ 개념 설명

### INSERT — 데이터 넣기

```sql
INSERT INTO scores (player_name, score, kills) VALUES ('홍길동', 15000, 152);
```

**파이썬에서 — 반드시 `?` 파라미터 바인딩**

```python
cursor.execute(
    "INSERT INTO scores (player_name, score, kills) VALUES (?, ?, ?)",
    ("홍길동", 15000, 152),          # 튜플로 전달
)
```

> ⚠️ **값이 하나여도 튜플이어야 합니다.** `("홍길동",)` — 콤마 필수. ([Day 012](day-012.md))

**여러 건 한 번에 — `executemany`**

```python
records = [
    ("홍길동", 15000, 152),
    ("김철수", 23000, 210),
    ("이영희", 18500, 178),
]
cursor.executemany(
    "INSERT INTO scores (player_name, score, kills) VALUES (?, ?, ?)",
    records,
)
```

> `executemany` 는 반복문으로 `execute` 를 부르는 것보다 **훨씬 빠릅니다.**

**방금 넣은 행의 id 얻기**

```python
cursor.execute("INSERT INTO scores (player_name, score) VALUES (?, ?)", ("홍길동", 100))
new_id = cursor.lastrowid
```

### SQL 인젝션 — 왜 `?` 를 써야 하는가

```python
# ❌ 위험한 코드
name = "' OR '1'='1"
cursor.execute(f"SELECT * FROM users WHERE name = '{name}'")
```

실제로 실행되는 SQL:

```sql
SELECT * FROM users WHERE name = '' OR '1'='1'
                                      ↑ 항상 참 → 전체 조회
```

더 심하면:

```python
name = "'; DROP TABLE users; --"
```

```sql
SELECT * FROM users WHERE name = ''; DROP TABLE users; --'
                                     ↑ 테이블이 삭제됨
```

**`?` 를 쓰면 안전합니다.**

```python
cursor.execute("SELECT * FROM users WHERE name = ?", (name,))
```

파이썬이 값을 **데이터로만** 취급합니다. 안에 SQL 이 들어 있어도 문자열로 처리됩니다.

> **규칙 — 문자열 포맷팅(f-string, `%`, `+`)으로 SQL 을 만들지 마세요.**
> 값은 항상 `?` 로 넘깁니다. 예외는 없습니다.

### 이름 있는 파라미터

```python
cursor.execute(
    "INSERT INTO scores (player_name, score) VALUES (:name, :score)",
    {"name": "홍길동", "score": 15000},
)
```

> 인자가 많을 때 순서를 헷갈리지 않아 좋습니다.

### SELECT 기본

```sql
SELECT * FROM scores;                            -- 전체 열
SELECT player_name, score FROM scores;           -- 특정 열만
SELECT player_name AS 이름, score AS 점수 FROM scores;   -- 별명
SELECT DISTINCT player_name FROM scores;         -- 중복 제거
```

### 결과 꺼내기

```python
cursor.execute("SELECT * FROM scores")

row = cursor.fetchone()          # 한 줄 (없으면 None)
rows = cursor.fetchmany(5)       # 5줄
rows = cursor.fetchall()         # 전부

# 반복문으로 (메모리 효율적)
for row in cursor.execute("SELECT * FROM scores"):
    print(row["player_name"])
```

> `row_factory = sqlite3.Row` 를 설정하면 `row["player_name"]` 처럼 **이름으로 접근**할 수 있습니다.

### WHERE — 조건

```sql
SELECT * FROM scores WHERE score > 10000;
SELECT * FROM scores WHERE player_name = '홍길동';
SELECT * FROM scores WHERE score BETWEEN 10000 AND 20000;
SELECT * FROM scores WHERE player_name IN ('홍길동', '김철수');
SELECT * FROM scores WHERE player_name LIKE '홍%';        -- 홍으로 시작
SELECT * FROM scores WHERE player_name LIKE '%길%';       -- 길 포함
SELECT * FROM scores WHERE returned_at IS NULL;           -- NULL 검사
SELECT * FROM scores WHERE score > 10000 AND kills > 100;
SELECT * FROM scores WHERE score > 20000 OR kills > 200;
SELECT * FROM scores WHERE NOT score > 10000;
```

| 연산자 | 뜻 |
|---|---|
| `=` `!=` (`<>`) | 같다 / 다르다 |
| `>` `<` `>=` `<=` | 비교 |
| `BETWEEN a AND b` | a 이상 b 이하 |
| `IN (...)` | 목록에 있음 |
| `LIKE` | 패턴 (`%` 아무 문자열, `_` 한 글자) |
| `IS NULL` / `IS NOT NULL` | **NULL 은 `=` 로 비교 불가** |
| `AND` `OR` `NOT` | 논리 |

> ⚠️ **`WHERE col = NULL` 은 항상 거짓입니다.** 반드시 `IS NULL` 을 쓰세요.
> NULL 은 "값 없음"이라 무엇과도 같지 않습니다(자기 자신과도).

### ORDER BY · LIMIT

```sql
SELECT * FROM scores ORDER BY score DESC;                 -- 내림차순
SELECT * FROM scores ORDER BY score DESC, kills DESC;     -- 2차 정렬
SELECT * FROM scores ORDER BY score DESC LIMIT 10;        -- 상위 10건
SELECT * FROM scores ORDER BY score DESC LIMIT 10 OFFSET 20;  -- 21~30위
```

| 키워드 | 뜻 |
|---|---|
| `ASC` | 오름차순 (기본값, 생략 가능) |
| `DESC` | 내림차순 |
| `LIMIT n` | n건만 |
| `OFFSET m` | m건 건너뛰고 (페이지네이션) |

### 집계 함수

```sql
SELECT COUNT(*) FROM scores;                    -- 전체 건수
SELECT COUNT(DISTINCT player_name) FROM scores; -- 고유 플레이어 수
SELECT SUM(kills) FROM scores;                  -- 합계
SELECT AVG(score) FROM scores;                  -- 평균
SELECT MAX(score), MIN(score) FROM scores;      -- 최대·최소
SELECT ROUND(AVG(score), 1) FROM scores;        -- 반올림
```

**한 번에**

```sql
SELECT
    COUNT(*)          AS 게임수,
    SUM(kills)        AS 총처치,
    ROUND(AVG(score)) AS 평균점수,
    MAX(score)        AS 최고점수
FROM scores;
```

### GROUP BY — 묶어서 집계

```sql
SELECT player_name, COUNT(*) AS games, MAX(score) AS best
FROM scores
GROUP BY player_name
ORDER BY best DESC;
```

```
player_name  games  best
홍길동          3   23000
김철수          2   18500
```

**`HAVING` — 집계 결과로 거르기**

```sql
SELECT player_name, COUNT(*) AS games
FROM scores
GROUP BY player_name
HAVING games >= 3                    -- 3판 이상 한 사람만
ORDER BY games DESC;
```

> **`WHERE` 와 `HAVING` 의 차이**
> - `WHERE` — **묶기 전에** 행을 거름
> - `HAVING` — **묶은 뒤에** 집계 결과를 거름
>
> ```sql
> SELECT player_name, AVG(score) AS avg_score
> FROM scores
> WHERE score > 1000              -- ① 1000점 넘는 기록만 대상으로
> GROUP BY player_name            -- ② 이름으로 묶고
> HAVING avg_score > 15000        -- ③ 평균이 15000 넘는 사람만
> ```

### 계산과 조건 표현식

```sql
-- 계산 열
SELECT player_name, hits * 100.0 / shots AS accuracy
FROM scores WHERE shots > 0;

-- 조건 분기
SELECT player_name, score,
       CASE
           WHEN score >= 20000 THEN 'S'
           WHEN score >= 15000 THEN 'A'
           WHEN score >= 10000 THEN 'B'
           ELSE 'C'
       END AS grade
FROM scores;

-- NULL 처리
SELECT player_name, COALESCE(email, '(없음)') FROM players;
```

> ⚠️ **정수 나눗셈 주의** — `hits / shots` 는 정수 나눗셈이 됩니다.
> `hits * 100.0 / shots` 처럼 **실수를 섞어야** 소수점이 나옵니다.

### JOIN 맛보기

두 테이블을 합칩니다.

```sql
SELECT b.title, m.name, l.due_at
FROM loans l
JOIN books b   ON l.book_id = b.id
JOIN members m ON l.member_id = m.id
WHERE l.returned_at IS NULL;
```

> 이 과정에서는 단일 테이블 위주로 다룹니다. `JOIN` 은 "이런 것이 있다" 정도로 알아 두세요.

### Step 1. 데이터 넣고 조회하기

`db_query.py`

```python
"""데이터 삽입과 조회 실습."""

import random
import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).resolve().parent / "game.db"


def get_connection():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn


def init():
    """테이블을 만들고 비웁니다."""
    conn = get_connection()
    with conn:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS scores (
                id            INTEGER PRIMARY KEY AUTOINCREMENT,
                player_name   TEXT    NOT NULL,
                score         INTEGER NOT NULL DEFAULT 0,
                kills         INTEGER NOT NULL DEFAULT 0,
                shots         INTEGER NOT NULL DEFAULT 0,
                hits          INTEGER NOT NULL DEFAULT 0,
                play_seconds  INTEGER NOT NULL DEFAULT 0,
                stage         INTEGER NOT NULL DEFAULT 1,
                created_at    TEXT    NOT NULL DEFAULT (datetime('now','localtime'))
            )
        """)
        conn.execute("DELETE FROM scores")           # 실습을 위해 비움
    conn.close()


def insert_sample_data(count=50):
    """샘플 데이터를 넣습니다."""
    names = ["홍길동", "김철수", "이영희", "박민수", "최지우"]
    records = []

    for _ in range(count):
        shots = random.randint(50, 500)
        hits = random.randint(int(shots * 0.3), shots)
        records.append((
            random.choice(names),
            random.randint(1000, 30000),        # score
            random.randint(10, 250),            # kills
            shots,
            hits,
            random.randint(60, 900),            # play_seconds
            random.randint(1, 10),              # stage
        ))

    conn = get_connection()
    with conn:
        conn.executemany("""
            INSERT INTO scores
                (player_name, score, kills, shots, hits, play_seconds, stage)
            VALUES (?, ?, ?, ?, ?, ?, ?)
        """, records)
    conn.close()

    print(f"샘플 데이터 {count}건 삽입 완료")


def show_top(n=10):
    """상위 n건을 출력합니다."""
    conn = get_connection()

    rows = conn.execute("""
        SELECT player_name, score, kills, stage,
               CASE WHEN shots > 0 THEN hits * 100.0 / shots ELSE 0 END AS accuracy
        FROM scores
        ORDER BY score DESC
        LIMIT ?
    """, (n,)).fetchall()

    print(f"\n{'=' * 62}")
    print(f"                    TOP {n} 랭킹")
    print("=" * 62)
    print(f"{'순위':<6}{'이름':<12}{'점수':>10}{'처치':>8}{'스테이지':>10}{'명중률':>10}")
    print("-" * 62)

    for i, r in enumerate(rows, start=1):
        print(f"{i:<6}{r['player_name']:<12}{r['score']:>10,}"
              f"{r['kills']:>8}{r['stage']:>10}{r['accuracy']:>9.1f}%")

    print("=" * 62)
    conn.close()


def search_by_name(name):
    """이름으로 검색합니다. (파라미터 바인딩)"""
    conn = get_connection()

    rows = conn.execute("""
        SELECT id, score, kills, created_at
        FROM scores
        WHERE player_name = ?
        ORDER BY score DESC
    """, (name,)).fetchall()

    print(f"\n[{name}] 검색 결과 {len(rows)}건")
    if not rows:
        print("  기록이 없습니다.")
    else:
        for r in rows[:5]:
            print(f"  #{r['id']:<5}{r['score']:>8,}점  "
                  f"{r['kills']:>4}처치  {r['created_at']}")
        if len(rows) > 5:
            print(f"  ... 외 {len(rows) - 5}건")

    conn.close()


def show_stats():
    """전체 통계를 출력합니다."""
    conn = get_connection()

    row = conn.execute("""
        SELECT
            COUNT(*)                        AS games,
            COUNT(DISTINCT player_name)     AS players,
            SUM(kills)                      AS total_kills,
            ROUND(AVG(score))               AS avg_score,
            MAX(score)                      AS best_score,
            MIN(score)                      AS worst_score,
            SUM(play_seconds)               AS total_seconds
        FROM scores
    """).fetchone()

    print(f"\n{'=' * 46}")
    print("                 전체 통계")
    print("=" * 46)
    print(f"  총 게임 수:     {row['games']:>10,}판")
    print(f"  플레이어:       {row['players']:>10}명")
    print(f"  총 처치:        {row['total_kills']:>10,}마리")
    print(f"  평균 점수:      {row['avg_score']:>10,.0f}점")
    print(f"  최고 점수:      {row['best_score']:>10,}점")
    print(f"  최저 점수:      {row['worst_score']:>10,}점")
    print(f"  총 플레이 시간: {row['total_seconds'] // 3600:>10}시간 "
          f"{row['total_seconds'] % 3600 // 60}분")
    print("=" * 46)

    conn.close()


def show_by_player():
    """플레이어별 집계 (GROUP BY)."""
    conn = get_connection()

    rows = conn.execute("""
        SELECT
            player_name,
            COUNT(*)          AS games,
            MAX(score)        AS best,
            ROUND(AVG(score)) AS avg_score,
            SUM(kills)        AS total_kills,
            MAX(stage)        AS best_stage
        FROM scores
        GROUP BY player_name
        HAVING games >= 3
        ORDER BY best DESC
    """).fetchall()

    print(f"\n{'=' * 68}")
    print("           플레이어별 기록 (3판 이상)")
    print("=" * 68)
    print(f"{'이름':<12}{'판수':>7}{'최고점':>11}{'평균점':>11}"
          f"{'총처치':>9}{'최고스테이지':>12}")
    print("-" * 68)

    for r in rows:
        print(f"{r['player_name']:<12}{r['games']:>7}{r['best']:>11,}"
              f"{r['avg_score']:>11,.0f}{r['total_kills']:>9,}{r['best_stage']:>12}")

    print("=" * 68)
    conn.close()


if __name__ == "__main__":
    init()
    insert_sample_data(50)
    show_top(10)
    show_stats()
    show_by_player()
    search_by_name("홍길동")
    search_by_name("없는사람")
```

### Step 2. SQL 인젝션 실험

`sql_injection.py`

```python
"""SQL 인젝션의 위험과 방어를 직접 확인합니다."""

import sqlite3

conn = sqlite3.connect(":memory:")
conn.row_factory = sqlite3.Row

with conn:
    conn.execute("""
        CREATE TABLE users (
            id       INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT NOT NULL,
            password TEXT NOT NULL,
            email    TEXT
        )
    """)
    conn.executemany(
        "INSERT INTO users (username, password, email) VALUES (?, ?, ?)",
        [
            ("admin", "super_secret_1234", "admin@company.com"),
            ("hong", "hong1234", "hong@test.com"),
            ("kim", "kim5678", "kim@test.com"),
        ],
    )


def login_unsafe(username, password):
    """❌ 위험한 방식 — 문자열 조합."""
    sql = (f"SELECT * FROM users "
           f"WHERE username = '{username}' AND password = '{password}'")
    print(f"    실행된 SQL: {sql}")

    try:
        return conn.execute(sql).fetchall()
    except sqlite3.Error as e:
        print(f"    에러: {e}")
        return []


def login_safe(username, password):
    """✅ 안전한 방식 — 파라미터 바인딩."""
    sql = "SELECT * FROM users WHERE username = ? AND password = ?"
    print(f"    실행된 SQL: {sql}")
    print(f"    파라미터: ({username!r}, {password!r})")

    return conn.execute(sql, (username, password)).fetchall()


print("=" * 72)
print("                    SQL 인젝션 실험")
print("=" * 72)

tests = [
    ("정상 로그인", "hong", "hong1234"),
    ("잘못된 비밀번호", "hong", "wrong"),
    ("인젝션 공격 ①", "admin", "' OR '1'='1"),
    ("인젝션 공격 ②", "' OR 1=1 --", "아무거나"),
]

for label, username, password in tests:
    print(f"\n[{label}]  아이디={username!r} 비번={password!r}")

    print("  ❌ 위험한 방식:")
    result = login_unsafe(username, password)
    if result:
        names = [r["username"] for r in result]
        print(f"    → 로그인 성공! 노출된 계정: {names}")
    else:
        print(f"    → 로그인 실패")

    print("  ✅ 안전한 방식:")
    result = login_safe(username, password)
    if result:
        print(f"    → 로그인 성공: {result[0]['username']}")
    else:
        print(f"    → 로그인 실패")

print("\n" + "=" * 72)
print("결론: 파라미터 바인딩(?)을 쓰면 값 안에 SQL 이 있어도")
print("      데이터로만 취급되어 공격이 통하지 않습니다.")
print("=" * 72)

conn.close()
```

```
    실행된 SQL: SELECT * FROM users WHERE username = 'admin' AND password = '' OR '1'='1'

  ❌ 위험한 방식:
    실행된 SQL: SELECT * FROM users WHERE username = '' OR 1=1 --' AND password = '아무거나'

```

```python
"""게임 기록 조회 함수 모음."""

import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).resolve().parent.parent.parent / "data" / "game.db"


def get_connection():
    DB_PATH.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn


def add_score(player_name, score, kills=0, shots=0, hits=0,
              play_seconds=0, stage=1, max_combo=0):
    """기록을 추가하고 새 id 를 반환합니다."""
    conn = get_connection()
    try:
        with conn:
            cursor = conn.execute("""
                INSERT INTO scores
                    (player_name, score, kills, max_combo,
                     shots, hits, play_seconds, stage)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            """, (player_name, score, kills, max_combo,
                  shots, hits, play_seconds, stage))
            return cursor.lastrowid
    finally:
        conn.close()


def get_top_scores(limit=10):
    """상위 기록을 반환합니다."""
    conn = get_connection()
    try:
        return conn.execute("""
            SELECT id, player_name, score, kills, stage, created_at,
                   CASE WHEN shots > 0 THEN hits * 100.0 / shots ELSE 0 END AS accuracy
            FROM scores
            ORDER BY score DESC, kills DESC
            LIMIT ?
        """, (limit,)).fetchall()
    finally:
        conn.close()


def get_player_best(player_name):
    """특정 플레이어의 최고 기록을 반환합니다. 없으면 None."""
    conn = get_connection()
    try:
        return conn.execute("""
            SELECT * FROM scores
            WHERE player_name = ?
            ORDER BY score DESC
            LIMIT 1
        """, (player_name,)).fetchone()
    finally:
        conn.close()


def get_player_rank(score):
    """이 점수가 몇 위인지 반환합니다."""
    conn = get_connection()
    try:
        row = conn.execute(
            "SELECT COUNT(*) + 1 AS rank FROM scores WHERE score > ?",
            (score,),
        ).fetchone()
        return row["rank"]
    finally:
        conn.close()


def is_new_record(score, top_n=10):
    """랭킹에 들어갈 점수인지 확인합니다."""
    conn = get_connection()
    try:
        count = conn.execute("SELECT COUNT(*) AS c FROM scores").fetchone()["c"]
        if count < top_n:
            return True

        row = conn.execute(
            "SELECT score FROM scores ORDER BY score DESC LIMIT 1 OFFSET ?",
            (top_n - 1,),
        ).fetchone()
        return row is None or score > row["score"]
    finally:
        conn.close()


def get_player_summary():
    """플레이어별 요약 통계를 반환합니다."""
    conn = get_connection()
    try:
        return conn.execute("""
            SELECT
                player_name,
                COUNT(*)                AS games,
                MAX(score)              AS best_score,
                ROUND(AVG(score))       AS avg_score,
                SUM(kills)              AS total_kills,
                MAX(stage)              AS best_stage,
                SUM(play_seconds)       AS total_seconds,
                CASE WHEN SUM(shots) > 0
                     THEN SUM(hits) * 100.0 / SUM(shots) ELSE 0 END AS accuracy
            FROM scores
            GROUP BY player_name
            ORDER BY best_score DESC
        """).fetchall()
    finally:
        conn.close()


def get_recent(limit=5):
    """최근 기록을 반환합니다."""
    conn = get_connection()
    try:
        return conn.execute("""
            SELECT player_name, score, created_at
            FROM scores ORDER BY created_at DESC LIMIT ?
        """, (limit,)).fetchall()
    finally:
        conn.close()


def get_daily_stats(days=7):
    """최근 N일간 일별 통계를 반환합니다."""
    conn = get_connection()
    try:
        return conn.execute("""
            SELECT
                DATE(created_at)  AS day,
                COUNT(*)          AS games,
                MAX(score)        AS best,
                ROUND(AVG(score)) AS avg_score
            FROM scores
            WHERE created_at >= datetime('now', ?, 'localtime')
            GROUP BY day
            ORDER BY day DESC
        """, (f"-{days} days",)).fetchall()
    finally:
        conn.close()


def search(keyword=None, min_score=None, min_stage=None, limit=20):
    """조건에 맞는 기록을 검색합니다. 조건은 선택적으로 조합됩니다."""
    conditions = []
    params = []

    if keyword:
        conditions.append("player_name LIKE ?")
        params.append(f"%{keyword}%")
    if min_score is not None:
        conditions.append("score >= ?")
        params.append(min_score)
    if min_stage is not None:
        conditions.append("stage >= ?")
        params.append(min_stage)

    where = f"WHERE {' AND '.join(conditions)}" if conditions else ""
    params.append(limit)

    conn = get_connection()
    try:
        return conn.execute(f"""
            SELECT player_name, score, kills, stage, created_at
            FROM scores
            {where}
            ORDER BY score DESC
            LIMIT ?
        """, params).fetchall()
    finally:
        conn.close()


if __name__ == "__main__":
    print("=" * 66)
    print("                    랭킹 조회 테스트")
    print("=" * 66)

    print("\n[TOP 5]")
    for i, r in enumerate(get_top_scores(5), 1):
        print(f"  {i}위  {r['player_name']:<10}{r['score']:>9,}점  "
              f"명중률 {r['accuracy']:.1f}%")

    print("\n[플레이어별 요약]")
    for r in get_player_summary():
        print(f"  {r['player_name']:<10}{r['games']:>3}판  "
              f"최고 {r['best_score']:>8,}  평균 {r['avg_score']:>8,.0f}  "
              f"명중률 {r['accuracy']:.1f}%")

    print("\n[검색: 이름에 '김' 포함 + 10000점 이상]")
    for r in search(keyword="김", min_score=10000, limit=5):
        print(f"  {r['player_name']:<10}{r['score']:>9,}점  "
              f"스테이지 {r['stage']}")

    print(f"\n[순위 확인] 25000점은 {get_player_rank(25000)}위입니다")
    print(f"[신기록 여부] 5000점: {is_new_record(5000)}")

    print("\n[최근 기록]")
    for r in get_recent(3):
        print(f"  {r['created_at']}  {r['player_name']:<10}{r['score']:>9,}점")

    print("\n" + "=" * 66)
```

> **눈여겨볼 점 5가지**
> - **모든 값이 `?` 로 전달됩니다.** f-string 은 `WHERE` 절 **구조**를 만들 때만 쓰고, 값은 절대 넣지 않습니다.
> - `search()` 는 조건을 **선택적으로 조합**합니다. 조건이 없으면 `WHERE` 절 자체가 없습니다.
> - `COUNT(*) + 1` 로 순위를 구합니다. "나보다 높은 점수가 몇 개인가 + 1".
> - `try/finally` 로 예외가 나도 연결이 닫힙니다.
> - 각 함수가 **하나의 질문에만 답합니다.** ([Day 008](day-008.md)의 "하나의 함수는 하나의 일")

## ⑤ 자주 하는 실수

### f-string 으로 SQL 값을 조합

```python
cursor.execute(f"SELECT * FROM scores WHERE player_name = '{name}'")
```

**해결** — `cursor.execute("... WHERE player_name = ?", (name,))`

> **예외 없습니다.** 값은 항상 `?` 입니다.

### 파라미터를 튜플로 안 넘김

```python
cursor.execute("SELECT * FROM scores WHERE id = ?", 5)
```

```
ValueError: parameters are of unsupported type
```

**해결** — `(5,)` — 콤마 필수.

### `WHERE col = NULL`

```sql
SELECT * FROM loans WHERE returned_at = NULL;     -- 항상 0건
```

**해결** — `WHERE returned_at IS NULL`

### 정수 나눗셈으로 명중률이 0

```sql
SELECT hits / shots * 100 FROM scores;            -- 대부분 0
```

**원인** — `150 / 300` 이 정수 나눗셈으로 `0` 이 됩니다.
**해결** — `hits * 100.0 / shots` — 실수를 섞습니다.

### 0으로 나누기

```sql
SELECT hits * 100.0 / shots FROM scores;          -- shots=0 이면?
```

> SQLite 는 0으로 나누면 에러 대신 `NULL` 을 반환합니다. 하지만 명시적으로 처리하는 편이 좋습니다.

**해결** — `CASE WHEN shots > 0 THEN ... ELSE 0 END`

### `GROUP BY` 없이 집계와 일반 열을 섞음

```sql
SELECT player_name, MAX(score) FROM scores;
```

**문제** — 다른 DB에서는 에러입니다. SQLite 는 허용하지만 **어느 행의 이름인지 보장되지 않습니다.**
**해결** — `GROUP BY player_name` 을 추가합니다.

### `HAVING` 대신 `WHERE` 로 집계 결과를 거름

```sql
SELECT player_name, COUNT(*) AS games
FROM scores WHERE games >= 3 GROUP BY player_name;
```

```
sqlite3.OperationalError: misuse of aggregate function COUNT()
```

**해결** — 집계 결과 조건은 `HAVING` 에 씁니다.

### `fetchall()` 을 두 번 호출

```python
cursor.execute("SELECT * FROM scores")
rows = cursor.fetchall()
rows2 = cursor.fetchall()      # []  — 이미 다 꺼냄
```

**원인** — 커서는 한 번 읽으면 소진됩니다.
**해결** — 결과를 변수에 담아 재사용합니다.

### `LIKE` 에서 `%` 를 파라미터 밖에 붙임

```python
cursor.execute("SELECT * FROM scores WHERE player_name LIKE '%?%'", (keyword,))
```

**문제** — 따옴표 안의 `?` 는 파라미터로 인식되지 않습니다.
**해결** — 값에 `%` 를 포함시킵니다.

```python
cursor.execute("SELECT * FROM scores WHERE player_name LIKE ?", (f"%{keyword}%",))
```

## ⑥ 확인 문제

**1.** 아래 SQL 의 결과와, 각 절(`WHERE`/`GROUP BY`/`HAVING`/`ORDER BY`)이 어떤 순서로 적용되는지 설명하세요.

```sql
SELECT player_name, COUNT(*) AS games, AVG(score) AS avg_score
FROM scores
WHERE stage >= 5
GROUP BY player_name
HAVING games >= 2
ORDER BY avg_score DESC
LIMIT 3;
```

<details>
<summary>답 보기</summary>

**적용 순서 (SQL 실행 순서)**

```
① FROM      scores 테이블에서 시작
② WHERE     stage >= 5 인 행만 남김          ← 묶기 전 필터
③ GROUP BY  player_name 으로 묶음
④ HAVING    묶은 결과 중 games >= 2 만 남김   ← 묶은 후 필터
⑤ SELECT    필요한 열·집계 계산
⑥ ORDER BY  avg_score 내림차순 정렬
⑦ LIMIT     상위 3건만
```

> **작성 순서와 실행 순서가 다릅니다.**
> 우리는 `SELECT` 를 먼저 쓰지만, DB는 `FROM` 부터 처리합니다.
> 그래서 `SELECT` 에서 붙인 별명(`games`)을 `WHERE` 에서는 못 쓰고 `HAVING`/`ORDER BY` 에서는 쓸 수 있습니다.

**결과 해석**

> "스테이지 5 이상에 도달한 기록 중, 그런 기록이 2판 이상 있는 플레이어를,
> 평균 점수 높은 순으로 상위 3명"

**핵심 — `WHERE` 와 `HAVING` 의 차이**

```sql
-- WHERE: 개별 기록을 거름 (스테이지 5 미만 기록은 아예 제외)
WHERE stage >= 5

-- HAVING: 묶은 결과를 거름 (그런 기록이 2판 미만인 사람은 제외)
HAVING games >= 2
```

만약 홍길동이 스테이지 3에 5판, 스테이지 7에 1판 했다면:
- `WHERE` 로 스테이지 7 기록 1건만 남음
- `HAVING games >= 2` 에서 탈락 (1판이므로)
</details>

**3.** 아래 함수는 SQL 인젝션에 취약합니다. 취약점을 지적하고 안전하게 고치세요.

```python
def search_scores(conn, name=None, min_score=None, order_by="score"):
    sql = "SELECT * FROM scores WHERE 1=1"

    if name:
        sql += f" AND player_name LIKE '%{name}%'"
    if min_score:
        sql += f" AND score >= {min_score}"
```

<details>
<summary>답 보기</summary>

**취약점 3가지**

**① `name` 이 SQL 에 직접 삽입됩니다.**

```python
search_scores(conn, name="' OR '1'='1")
# → WHERE 1=1 AND player_name LIKE '%' OR '1'='1%'   전체 노출
```

**② `min_score` 도 직접 삽입됩니다.**

```python
search_scores(conn, min_score="0; DROP TABLE scores; --")
# → AND score >= 0; DROP TABLE scores; --   테이블 삭제
```

**③ `order_by` 가 검증 없이 삽입됩니다.**

```python
search_scores(conn, order_by="score; DROP TABLE scores; --")
```

**핵심 문제** — `order_by` 는 **열 이름**이라 `?` 파라미터 바인딩이 안 됩니다.
`ORDER BY ?` 는 열 이름이 아니라 문자열 리터럴로 해석되어 정렬이 안 됩니다.
따라서 **화이트리스트 검증**이 필수입니다.

**안전한 버전**

```python
# 허용된 정렬 열만 명시 (화이트리스트)
ALLOWED_ORDER_COLUMNS = {
    "score": "score",
    "kills": "kills",
    "stage": "stage",
    "date": "created_at",
    "name": "player_name",
}
ALLOWED_DIRECTIONS = {"ASC", "DESC"}


def search_scores(conn, name=None, min_score=None,
                  order_by="score", direction="DESC", limit=50):
    """
    조건에 맞는 기록을 검색합니다.

    order_by: ALLOWED_ORDER_COLUMNS 의 키 중 하나
    direction: 'ASC' 또는 'DESC'
    """
    # ── ① 정렬 열 검증 (화이트리스트) ──
    column = ALLOWED_ORDER_COLUMNS.get(order_by)
    if column is None:
        raise ValueError(
            f"허용되지 않은 정렬 기준: {order_by!r} "
            f"(가능: {', '.join(ALLOWED_ORDER_COLUMNS)})"
        )

    # ── ② 정렬 방향 검증 ──
    direction = direction.upper()
    if direction not in ALLOWED_DIRECTIONS:
        raise ValueError(f"허용되지 않은 정렬 방향: {direction!r}")

    # ── ③ 조건은 파라미터 바인딩 ──
    conditions = []
    params = []

    if name:
        conditions.append("player_name LIKE ?")
        params.append(f"%{name}%")           # % 를 값에 포함

    if min_score is not None:
        conditions.append("score >= ?")
        params.append(int(min_score))        # 타입도 확실히

    where = f"WHERE {' AND '.join(conditions)}" if conditions else ""

    params.append(int(limit))

    # column 과 direction 은 화이트리스트를 통과한 값이므로 안전
    sql = f"""
        SELECT id, player_name, score, kills, stage, created_at
        FROM scores
        {where}
        ORDER BY {column} {direction}
        LIMIT ?
    """

    return conn.execute(sql, params).fetchall()
```

**사용 예**

```python
# 정상
rows = search_scores(conn, name="홍", min_score=10000, order_by="score")

# 공격 시도 — 값은 데이터로만 취급됨
rows = search_scores(conn, name="' OR '1'='1")        # 0건 (그런 이름이 없으므로)

# 공격 시도 — 검증에서 차단
try:
    search_scores(conn, order_by="score; DROP TABLE scores; --")
except ValueError as e:
    print(f"차단: {e}")
    # 차단: 허용되지 않은 정렬 기준: 'score; DROP TABLE scores; --' (가능: score, kills, ...)
```

**정리 — SQL 을 안전하게 만드는 3원칙**

| 무엇 | 방법 |
|---|---|
| **값** (조건에 넣는 데이터) | 반드시 `?` 파라미터 바인딩 |
| **열/테이블 이름** | `?` 사용 불가 → **화이트리스트 검증** |
| **타입** | `int()` 등으로 명시적 변환 |

> **`WHERE 1=1` 트릭** — 원래 코드의 `WHERE 1=1` 은 조건을 `AND` 로 계속 붙이기 위한 흔한 기법입니다.
> 나쁘지는 않지만, 위처럼 **조건 리스트를 만들어 `join`** 하는 편이 더 명확합니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `INSERT` | `VALUES (?, ?)` + 튜플 · 여러 건은 `executemany` |
| **파라미터 바인딩** | 값은 **항상 `?`** · f-string 금지 |
| 열 이름 | `?` 사용 불가 → **화이트리스트 검증** |
| `SELECT` | `*` / 특정 열 / `AS` 별명 / `DISTINCT` |
| `WHERE` | `BETWEEN` `IN` `LIKE` · **NULL 은 `IS NULL`** |
| `ORDER BY` | `DESC` 내림차순 · `LIMIT n OFFSET m` |
| 집계 | `COUNT` `SUM` `AVG` `MAX` `MIN` |
| `GROUP BY` | 묶어서 집계 · 집계 조건은 **`HAVING`** |
| 실행 순서 | FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT |
| 나눗셈 | `hits * 100.0 / shots` — **실수를 섞을 것** |

**오늘 반드시 기억할 세 가지**
> ① **값은 항상 `?` 로 넘기세요.** f-string 으로 SQL 을 만들지 마세요.
> ② 열 이름은 `?` 가 안 되므로 **화이트리스트**로 검증하세요.
> ③ `NULL` 비교는 `= NULL` 이 아니라 **`IS NULL`** 입니다.
