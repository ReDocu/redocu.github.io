## ② 왜 필요한가

지금 `todo` 를 실행하면 메뉴가 뜨고 숫자를 골라야 합니다. **사람만 쓸 수 있습니다.**

하지만 W23에서는 이런 것이 필요합니다.

```bash
# cron으로 매일 새벽 3시에 자동 실행
0 3 * * * /usr/local/bin/collect run --config /etc/collector.yaml
```

**자동화되려면 대화형이면 안 됩니다.** 명령 한 줄로 끝나야 합니다.

| 대화형 메뉴 | 명령행 인자 |
|---|---|
| 사람이 앉아 있어야 함 | 자동 실행 가능 |
| 스크립트에서 못 씀 | 셸 스크립트·cron·CI에서 사용 |
| 파이프 연결 불가 | `todo list --json \| jq` 가능 |
| 테스트하기 어려움 | 인자를 넘겨 바로 테스트 |

그리고 이 과정의 **모든 산출물이 "명령 한 줄로 재현"** 을 요구합니다.

| 산출물 | 요구되는 명령 |
|---|---|
| [Day 030](day-030.md) 전처리 패키지 | `collect run --config config.yaml` |
| MP1 | `etl run --date 2026-08-12` |
| MP2 | `train --config train.yaml` |
| MP3 | `uvicorn api.main:app` |
| MP4 | `docker compose up` |

**오늘 배우는 argparse가 그 시작입니다.**

그리고 **README** — 채용 담당자가 여러분의 GitHub를 열었을 때 가장 먼저 보는 것입니다.
코드가 아무리 좋아도 README가 없으면 그냥 닫습니다.

## ③ 개념 설명

### argparse 기본

```python
import argparse

parser = argparse.ArgumentParser(description="할 일 관리 CLI")
parser.add_argument("title", help="할 일 제목")
parser.add_argument("--priority", default="보통", help="우선순위")

args = parser.parse_args()
print(args.title, args.priority)
```

```bash
$ python app.py "장보기" --priority 높음
장보기 높음
```

**도움말이 자동으로 생깁니다.**

```bash
$ python app.py --help
usage: app.py [-h] [--priority PRIORITY] title

할 일 관리 CLI

positional arguments:
  title                할 일 제목

options:
  -h, --help           show this help message and exit
  --priority PRIORITY  우선순위
```

### 인자의 종류

| 종류 | 표기 | 필수? | 예 |
|---|---|---|---|
| 위치 인자 | `parser.add_argument("title")` | 필수 | `todo add 장보기` |
| 선택 인자 | `parser.add_argument("--priority")` | 선택 | `--priority 높음` |
| 짧은 이름 | `parser.add_argument("-p", "--priority")` | 선택 | `-p 높음` |
| 플래그 | `action="store_true"` | 선택 | `--verbose` |
| 여러 값 | `nargs="+"` | | `--tags 업무 급함` |

### 주요 옵션

```python
parser.add_argument(
    "--priority",
    default="보통",                    # 기본값
    choices=["높음", "보통", "낮음"],    # 허용 목록 (아니면 자동 에러)
    help="우선순위 (기본: 보통)",
)

parser.add_argument("--count", type=int, default=10)      # 타입 자동 변환
parser.add_argument("--verbose", "-v", action="store_true")  # 플래그
parser.add_argument("--tags", nargs="*", default=[])      # 0개 이상
parser.add_argument("--config", type=Path, required=True) # 필수 선택 인자
```

> **`choices` 를 쓰면 검증 코드를 안 써도 됩니다.**
> ```
> $ todo add "x" --priority 매우높음
> error: argument --priority: invalid choice: '매우높음' (choose from '높음', '보통', '낮음')
> ```

### 서브커맨드

`git add`, `git commit` 처럼 명령을 나눕니다.

parser = argparse.ArgumentParser(prog="todo")
subparsers = parser.add_subparsers(dest="command", required=True)

# todo list

p_list.add_argument("--status", choices=["all", "todo", "done"], default="all")

args = parser.parse_args()

if args.command == "add":
    ...
elif args.command == "list":
    ...
```

```bash
$ todo add "장보기" --priority 높음
$ todo list --status todo
$ todo --help              # 전체 도움말
$ todo add --help          # add 명령의 도움말
```

### 종료 코드

```python
import sys

sys.exit(0)      # 성공
sys.exit(1)      # 실패
```

**왜 중요한가** — 셸 스크립트와 CI가 성공/실패를 이걸로 판단합니다.

```bash
$ todo add ""
$ echo $?
1                     # 실패

$ todo add "장보기" && echo "성공"     # 성공했을 때만 다음 명령 실행
```

W26의 GitHub Actions는 **종료 코드가 0이 아니면 파이프라인을 중단**합니다.
에러가 났는데 0을 반환하면 **실패가 조용히 통과됩니다.**

| 코드 | 관례 |
|---|---|
| 0 | 성공 |
| 1 | 일반적인 실패 |
| 2 | 사용법 오류 (argparse가 자동으로 씀) |

### 표준 출력과 표준 에러

| 스트림 | 용도 | 파이썬 |
|---|---|---|
| **stdout** | 프로그램의 **결과** | `print(...)` |
| **stderr** | 로그·에러·진행 상황 | `print(..., file=sys.stderr)` · logging |

**결과와 로그를 섞으면 파이프가 깨집니다.**

```bash
$ todo list --json > todos.json      # stdout만 파일로
$ todo list --json | jq '.[] | .title'
```

로그가 stdout으로 나가면 JSON이 오염됩니다.
`logging` 의 `StreamHandler` 는 기본이 stderr라 **자동으로 올바르게 동작합니다.**

### Step 1. argparse 감 잡기

`argparse_demo.py` 를 루트에 만듭니다.

```python
"""argparse 기본 동작 확인."""

import argparse


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="demo",
        description="argparse 학습용 데모",
        epilog="예: python argparse_demo.py 장보기 -p 높음 -t 업무 급함 -v",
    )
    parser.add_argument("title", help="할 일 제목")
    parser.add_argument("-p", "--priority", default="보통",
                        choices=["높음", "보통", "낮음"], help="우선순위 (기본: 보통)")
    parser.add_argument("-t", "--tags", nargs="*", default=[], help="태그 (여러 개 가능)")
    parser.add_argument("-n", "--count", type=int, default=1, help="반복 횟수")
    parser.add_argument("-v", "--verbose", action="store_true", help="상세 출력")
    return parser


args = build_parser().parse_args()

print(f"title    : {args.title!r}")
print(f"priority : {args.priority!r}")
print(f"tags     : {args.tags}")
print(f"count    : {args.count} ({type(args.count).__name__})")
print(f"verbose  : {args.verbose}")

if args.verbose:
    print(f"\n[전체 args] {vars(args)}")
```

### Step 2. 서브커맨드 CLI 설계

`src/todoapp/cli.py` 를 전면 개편합니다. **대화형과 명령형을 모두 지원**합니다.

```python
"""명령행 인터페이스."""

import argparse
import json
import logging
import os
import sys
from pathlib import Path

from todoapp import __version__, storage
from todoapp.logging_config import setup_logging
from todoapp.models import PRIORITIES, TodoError
from todoapp.service import TodoList

logger = logging.getLogger(__name__)

MARK = {True: "✔", False: " "}
PRIORITY_MARK = {"높음": "!!", "보통": "! ", "낮음": "  "}


# ===================== 출력 =====================

def format_todo(t) -> str:
    tags = ", ".join(t.tags) if t.tags else "-"
    return (f"{t.id:>3} [{MARK[t.done]}] {PRIORITY_MARK[t.priority]} "
            f"{t.title:<24}{tags:<18}{t.created_at}")


def print_todos(todos, label: str = "목록") -> None:
    print(f"\n[{label}] {len(todos)}건")
    if not todos:
        print("  항목이 없습니다.")
        return
    for t in todos:
        print(" ", format_todo(t))


def print_stats(todo_list: TodoList) -> None:
    s = todo_list.stats()
    print("\n[통계]")
    if s["total"] == 0:
        print("  등록된 할 일이 없습니다.")
        return
    filled = int(s["rate"] * 20)
    print(f"  전체 {s['total']}건 · 완료 {s['done']}건 · 미완료 {s['todo']}건")
    print(f"  진행률 {'■' * filled}{'□' * (20 - filled)} {s['rate']:.1%}")
    print("\n  [우선순위별]")
    for p in PRIORITIES:
        c = s["by_priority"].get(p, 0)
        print(f"    {p:<5}{c:>3}건 {'■' * c}")
    if s["by_tag"]:
        print("\n  [태그별 — 많은 순]")
        for tag, c in sorted(s["by_tag"].items(), key=lambda kv: kv[1], reverse=True)[:5]:
            print(f"    {tag:<14}{c:>3}건 {'■' * c}")


# ===================== 명령 처리 =====================

def load_list(path: Path) -> TodoList:
    items, warning = storage.load(path)
    if warning:
        logger.warning(warning)
        print(f"⚠ {warning}", file=sys.stderr)
    return TodoList(items)


def save_list(todos: TodoList, path: Path) -> int:
    ok, error = storage.save(todos, path)
    if not ok:
        logger.error(error)
        print(f"✗ {error}", file=sys.stderr)
        return 1
    return 0


def cmd_add(args) -> int:
    todos = load_list(args.file)
    try:
        todo = todos.add(args.title, args.priority, args.tags)
    except TodoError as e:
        print(f"✗ {e}", file=sys.stderr)
        return 1

    if code := save_list(todos, args.file):
        return code
    print(f"✓ {todo.id}번 '{todo.title}' 등록됨")
    return 0


def cmd_list(args) -> int:
    todos = load_list(args.file)
    items = todos.filter(args.status)

    if args.tag:
        items = [t for t in items if args.tag in t.tags]

    if args.json:
        print(json.dumps([t.to_dict() for t in items], ensure_ascii=False, indent=2))
        return 0

    label = {"todo": "미완료", "done": "완료"}.get(args.status, "전체")
    if args.tag:
        label += f" · 태그 '{args.tag}'"
    print_todos(items, label)
    return 0


def cmd_done(args) -> int:
    todos = load_list(args.file)
    try:
        todo = todos.toggle(args.id)
    except TodoError as e:
        print(f"✗ {e}", file=sys.stderr)
        return 1

    if code := save_list(todos, args.file):
        return code
    print(f"✓ {todo.id}번 '{todo.title}' → {'완료' if todo.done else '미완료'}")
    return 0


def cmd_remove(args) -> int:
    todos = load_list(args.file)
    try:
        todo = todos.get(args.id)
    except TodoError as e:
        print(f"✗ {e}", file=sys.stderr)
        return 1

    if not args.yes:
        answer = input(f"'{todo.title}' 를 삭제할까요? (y/N): ").strip().lower()
        if answer != "y":
            print("취소했습니다.")
            return 0

    todos.remove(args.id)
    if code := save_list(todos, args.file):
        return code
    print(f"✓ {args.id}번 '{todo.title}' 삭제됨")
    return 0


def cmd_search(args) -> int:
    todos = load_list(args.file)
    found = todos.search(args.keyword)

    if args.json:
        print(json.dumps([t.to_dict() for t in found], ensure_ascii=False, indent=2))
        return 0

    print_todos(found, f"'{args.keyword}' 검색 결과")
    return 0 if found else 1          # 못 찾으면 1 — grep 과 같은 관례


def cmd_stats(args) -> int:
    todos = load_list(args.file)
    if args.json:
        print(json.dumps(todos.stats(), ensure_ascii=False, indent=2))
        return 0
    print_stats(todos)
    return 0


def cmd_menu(args) -> int:
    """대화형 메뉴 (인자 없이 실행했을 때)."""
    todos = load_list(args.file)
    print(f"할 일 {len(todos)}건을 불러왔습니다.")

    while True:
        print()
        print("=" * 52)
        print(f"                할 일 관리 CLI v{__version__}")
        print("=" * 52)
        print(" 1. 추가    2. 목록    3. 완료 토글    4. 삭제")
        print(" 5. 검색    6. 통계    0. 저장하고 종료")
        print("-" * 52)

        choice = input("선택 > ").strip()

        if choice == "0":
            code = save_list(todos, args.file)
            if code == 0:
                print(f"{len(todos)}건 저장 완료.")
            return code

        elif choice == "1":
            title = input("  제목: ")
            priority = input(f"  우선순위 ({'/'.join(PRIORITIES)}) [엔터=보통]: ").strip() or "보통"
            tags = [t for t in input("  태그 (쉼표 구분): ").split(",")]
            try:
                todo = todos.add(title, priority, tags)
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos, args.file)
            print(f"  ✓ {todo.id}번 등록됨")

        elif choice == "2":
            f = input("  1=전체 2=미완료 3=완료 [엔터=전체]: ").strip()
            status = {"2": "todo", "3": "done"}.get(f, "all")
            print_todos(todos.filter(status), {"todo": "미완료", "done": "완료"}.get(status, "전체"))

        elif choice == "3":
            print_todos(todos.filter("todo"), "미완료")
            raw = input("\n  토글할 ID: ").strip()
            if not raw.isdigit():
                print("  ✗ 숫자를 입력하세요.")
                continue
            try:
                t = todos.toggle(int(raw))
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos, args.file)
            print(f"  ✓ {t.id}번 → {'완료' if t.done else '미완료'}")

        elif choice == "4":
            print_todos(todos.filter())
            raw = input("\n  삭제할 ID: ").strip()
            if not raw.isdigit():
                print("  ✗ 숫자를 입력하세요.")
                continue
            try:
                t = todos.remove(int(raw))
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos, args.file)
            print(f"  ✓ '{t.title}' 삭제됨")

        elif choice == "5":
            tags = todos.all_tags()
            if tags:
                print(f"\n  사용 중인 태그: {', '.join(sorted(tags))}")
            keyword = input("  검색어: ")
            print_todos(todos.search(keyword), f"'{keyword.strip()}' 검색 결과")

        elif choice == "6":
            print_stats(todos)

        else:
            print("  0에서 6 사이의 숫자를 입력하세요.")


# ===================== 파서 =====================

def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="todo",
        description="터미널에서 쓰는 할 일 관리 CLI",
        epilog="인자 없이 실행하면 대화형 메뉴가 열립니다.",
    )
    parser.add_argument("--version", action="version", version=f"todo {__version__}")
    parser.add_argument("-f", "--file", type=Path, default=Path("todos.json"),
                        help="데이터 파일 경로 (기본: todos.json)")
    parser.add_argument("-v", "--verbose", action="store_true", help="DEBUG 로그 출력")

    sub = parser.add_subparsers(dest="command")

    p_add = sub.add_parser("add", help="할 일 추가")
    p_add.add_argument("title", help="할 일 제목")
    p_add.add_argument("-p", "--priority", default="보통", choices=list(PRIORITIES),
                       help="우선순위 (기본: 보통)")
    p_add.add_argument("-t", "--tags", nargs="*", default=[], help="태그")
    p_add.set_defaults(func=cmd_add)

    p_list = sub.add_parser("list", help="목록 보기")
    p_list.add_argument("-s", "--status", default="all", choices=["all", "todo", "done"],
                        help="상태 필터 (기본: all)")
    p_list.add_argument("-t", "--tag", help="태그 필터")
    p_list.add_argument("--json", action="store_true", help="JSON으로 출력")
    p_list.set_defaults(func=cmd_list)

    p_done = sub.add_parser("done", help="완료 여부 토글")
    p_done.add_argument("id", type=int, help="할 일 ID")
    p_done.set_defaults(func=cmd_done)

    p_rm = sub.add_parser("rm", help="삭제")
    p_rm.add_argument("id", type=int, help="할 일 ID")
    p_rm.add_argument("-y", "--yes", action="store_true", help="확인 없이 삭제")
    p_rm.set_defaults(func=cmd_remove)

    p_search = sub.add_parser("search", help="검색 (제목·태그)")
    p_search.add_argument("keyword", help="검색어")
    p_search.add_argument("--json", action="store_true", help="JSON으로 출력")
    p_search.set_defaults(func=cmd_search)

    p_stats = sub.add_parser("stats", help="통계 보기")
    p_stats.add_argument("--json", action="store_true", help="JSON으로 출력")
    p_stats.set_defaults(func=cmd_stats)

    return parser


def main(argv: list[str] | None = None) -> int:
    """CLI 진입점. 종료 코드를 돌려줍니다."""
    parser = build_parser()
    args = parser.parse_args(argv)

    level = "DEBUG" if args.verbose else os.getenv("TODO_LOG_LEVEL", "WARNING").upper()
    setup_logging(level=level, log_file=os.getenv("TODO_LOG_FILE"))
    logger.debug("args=%s", vars(args))

    if args.command is None:
        return cmd_menu(args)

    try:
        return args.func(args)
    except KeyboardInterrupt:
        print("\n중단되었습니다.", file=sys.stderr)
        return 130                              # 관례: 128 + SIGINT(2)
    except Exception:
        logger.exception("예상치 못한 오류")
        print("✗ 예상치 못한 오류가 발생했습니다. -v 로 자세히 보세요.", file=sys.stderr)
        return 1


if __name__ == "__main__":
    sys.exit(main())
```

> **`set_defaults(func=cmd_add)`** 가 핵심 기법입니다.
> 서브커맨드마다 처리 함수를 미리 붙여 두면, `if/elif` 없이 `args.func(args)` 한 줄로 분기됩니다.
> 명령이 20개로 늘어도 `main()` 은 안 바뀝니다.
>
> **`main(argv=None)`** — 인자를 받게 만든 이유는 **테스트 때문**입니다.
> `main(["add", "테스트"])` 처럼 직접 넘겨 확인할 수 있습니다.

### Step 4. CLI 테스트

`tests/test_cli.py` 를 만듭니다. **`main(argv)` 형태 덕분에 테스트가 쉽습니다.**

```python
"""CLI 테스트."""

import json

import pytest

from todoapp.cli import main


@pytest.fixture
def data_file(tmp_path):
    """테스트용 임시 데이터 파일 경로."""
    return tmp_path / "todos.json"


def run(argv, data_file):
    """--file 을 자동으로 붙여 실행합니다."""
    return main(["--file", str(data_file)] + argv)


class TestAdd:
    def test_추가_성공(self, data_file, capsys):
        code = run(["add", "장보기"], data_file)

        assert code == 0
        assert "1번" in capsys.readouterr().out
        assert data_file.exists()

    def test_빈_제목은_실패(self, data_file, capsys):
        code = run(["add", "   "], data_file)

        assert code == 1
        assert "비워 둘 수 없습니다" in capsys.readouterr().err

    def test_잘못된_우선순위는_argparse가_막는다(self, data_file):
        with pytest.raises(SystemExit) as exc:
            run(["add", "장보기", "-p", "매우높음"], data_file)

        assert exc.value.code == 2          # argparse 사용법 오류

    def test_태그가_저장된다(self, data_file):
        run(["add", "장보기", "-t", "업무", "급함"], data_file)

        data = json.loads(data_file.read_text(encoding="utf-8"))
        assert data[0]["tags"] == ["급함", "업무"]


class TestList:
    @pytest.fixture
    def three(self, data_file):
        run(["add", "A", "-p", "높음", "-t", "업무"], data_file)
        run(["add", "B", "-p", "보통"], data_file)
        run(["add", "C", "-p", "낮음", "-t", "업무"], data_file)
        run(["done", "2"], data_file)
        return data_file

    def test_전체(self, three, capsys):
        assert run(["list"], three) == 0
        assert "3건" in capsys.readouterr().out

    def test_미완료만(self, three, capsys):
        run(["list", "-s", "todo"], three)
        assert "2건" in capsys.readouterr().out

    def test_완료만(self, three, capsys):
        run(["list", "-s", "done"], three)
        assert "1건" in capsys.readouterr().out

    def test_태그_필터(self, three, capsys):
        run(["list", "-t", "업무"], three)
        assert "2건" in capsys.readouterr().out

    def test_json_출력이_파싱된다(self, three, capsys):
        run(["list", "--json"], three)

        data = json.loads(capsys.readouterr().out)      # 파싱되면 오염 없음
        assert len(data) == 3
        assert data[0]["title"] == "A"

    def test_빈_목록(self, data_file, capsys):
        assert run(["list"], data_file) == 0
        assert "0건" in capsys.readouterr().out


class TestDone:
    def test_토글(self, data_file, capsys):
        run(["add", "장보기"], data_file)

        run(["done", "1"], data_file)
        assert "완료" in capsys.readouterr().out

        run(["done", "1"], data_file)
        assert "미완료" in capsys.readouterr().out

    def test_없는_id는_실패(self, data_file, capsys):
        code = run(["done", "999"], data_file)

        assert code == 1
        assert "999번" in capsys.readouterr().err


class TestRemove:
    def test_yes_플래그로_바로_삭제(self, data_file, capsys):
        run(["add", "장보기"], data_file)

        code = run(["rm", "1", "-y"], data_file)

        assert code == 0
        assert json.loads(data_file.read_text(encoding="utf-8")) == []

    def test_없는_id는_실패(self, data_file):
        assert run(["rm", "999", "-y"], data_file) == 1


class TestSearch:
    def test_찾으면_0(self, data_file):
        run(["add", "장보기", "-t", "집안일"], data_file)

        assert run(["search", "장"], data_file) == 0
        assert run(["search", "집안일"], data_file) == 0

    def test_못_찾으면_1(self, data_file):
        run(["add", "장보기"], data_file)

        assert run(["search", "ZZZ"], data_file) == 1


class TestStats:
    def test_json_통계(self, data_file, capsys):
        run(["add", "A"], data_file)
        run(["add", "B"], data_file)
        run(["done", "1"], data_file)

        run(["stats", "--json"], data_file)

        s = json.loads(capsys.readouterr().out)
        assert s["total"] == 2
        assert s["done"] == 1
        assert s["rate"] == pytest.approx(0.5)

    def test_빈_목록도_안전(self, data_file, capsys):
        assert run(["stats"], data_file) == 0
        assert "없습니다" in capsys.readouterr().out


class TestGlobal:
    def test_version(self, capsys):
        with pytest.raises(SystemExit) as exc:
            main(["--version"])

        assert exc.value.code == 0
        assert "todo" in capsys.readouterr().out

    def test_알_수_없는_명령(self):
        with pytest.raises(SystemExit) as exc:
            main(["nonexistent"])

        assert exc.value.code == 2
```

> **`capsys`** 는 pytest 기본 픽스처로, `print` 출력을 가로챕니다.
> `capsys.readouterr()` 는 `.out`(stdout)과 `.err`(stderr)를 나눠서 돌려줍니다.
> **에러가 stderr로 나가는지도 이걸로 검증**합니다.
>
> **`pytest.raises(SystemExit)`** — argparse는 잘못된 인자를 만나면 `sys.exit(2)` 를 호출합니다.
> 그래서 예외로 잡아 종료 코드를 확인합니다.

## 사용법

### 기본 명령

| 명령 | 하는 일 |
|---|---|
| `todo` | 대화형 메뉴 열기 |
| `todo add <제목>` | 할 일 추가 |
| `todo list` | 목록 보기 |
| `todo done <ID>` | 완료 여부 토글 |
| `todo rm <ID>` | 삭제 |
| `todo search <검색어>` | 제목·태그 검색 |
| `todo stats` | 통계 |

### 예시

```bash
# 추가 — 우선순위와 태그
todo add "MP1 데이터 선정" --priority 높음 --tags 프로젝트 급함

# 목록 — 미완료만, 특정 태그만
todo list --status todo
todo list --tag 프로젝트

# 완료 처리 (다시 실행하면 미완료로)
todo done 1

# 삭제 (확인 없이)
todo rm 3 --yes

# 검색
todo search 프로젝트

# JSON으로 출력해서 다른 도구와 연결
todo list --json > backup.json
todo stats --json | jq '.rate'
```

### 전역 옵션

| 옵션 | 설명 |
|---|---|
| `-f, --file <경로>` | 데이터 파일 지정 (기본: `todos.json`) |
| `-v, --verbose` | DEBUG 로그 출력 |
| `--version` | 버전 표시 |

### 환경 변수

| 변수 | 설명 |
|---|---|
| `TODO_LOG_LEVEL` | 로그 레벨 (`DEBUG` / `INFO` / `WARNING`) |
| `TODO_LOG_FILE` | 로그 파일 경로 |

```bash
TODO_LOG_LEVEL=DEBUG TODO_LOG_FILE=logs/todo.log todo list
```

### 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 성공 |
| 1 | 실패 (없는 ID, 검증 실패, 검색 결과 없음) |
| 2 | 사용법 오류 (잘못된 인자) |
| 130 | 사용자 중단 (Ctrl+C) |

```python
"""제출 전 자가 점검."""

import subprocess
import sys
from pathlib import Path

CHECKS = []


def check(label: str, ok: bool, detail: str = "") -> None:
    CHECKS.append((label, ok, detail))
    mark = "✓" if ok else "✗"
    print(f"  {mark} {label}" + (f" — {detail}" if detail and not ok else ""))


def run(cmd: list[str]) -> tuple[int, str]:
    r = subprocess.run(cmd, capture_output=True, text=True)
    return r.returncode, (r.stdout + r.stderr).strip()

print("=== 파일 구조 ===")
for f in ["pyproject.toml", "README.md", ".gitignore", "src/todoapp/__init__.py"]:
    check(f, Path(f).exists())

check("tests/ 에 테스트 파일 3개 이상",
      len(list(Path("tests").glob("test_*.py"))) >= 3)

print("\n=== README 필수 항목 ===")
readme = Path("README.md").read_text(encoding="utf-8")
for keyword in ["설치", "사용법", "pip install", "pytest", "구조"]:
    check(f"'{keyword}' 언급", keyword in readme)

check("실행 예시 블록 3개 이상", readme.count("```") >= 6)

print("\n=== 실행 ===")
code, out = run([sys.executable, "-m", "todoapp", "--version"])
check("python -m todoapp --version", code == 0, out)

code, out = run([sys.executable, "-m", "todoapp", "--help"])
check("도움말 출력", code == 0 and "add" in out)

print("\n=== 테스트 ===")
code, out = run([sys.executable, "-m", "pytest", "-q"])
check("pytest 통과", code == 0, out.splitlines()[-1] if out else "")

passed = out.count(" passed")
check("테스트 20개 이상", "passed" in out and int(out.split(" passed")[0].split()[-1]) >= 20)

print("\n" + "=" * 50)
failed = [c for c in CHECKS if not c[1]]
if failed:
    print(f"✗ {len(failed)}개 항목 미충족")
    for label, _, detail in failed:
        print(f"    - {label}")
    sys.exit(1)
print(f"✓ 전체 {len(CHECKS)}개 항목 통과 — 제출 준비 완료")
```

**2.** 아래 CLI는 실패해도 항상 종료 코드 0을 반환합니다. 왜 문제이고 어떻게 고치나요?

```python
def main():
    args = parser.parse_args()
    try:
        todos.toggle(args.id)
        print("완료")
    except NotFoundError as e:
        print(f"오류: {e}")

if __name__ == "__main__":
    main()
```

<details>
<summary>답 보기</summary>

**문제: 실패가 성공으로 보고됩니다.**

`main()` 이 아무것도 반환하지 않으므로 `None` → 파이썬은 종료 코드 0으로 끝냅니다.

**구체적 피해**

```bash
$ todo done 999
오류: 999번 할 일이 없습니다.
$ echo $?
0                      # 성공이라고 보고!
```

| 상황 | 결과 |
|---|---|
| 셸 스크립트 `todo done 1 && deploy.sh` | 실패했는데 **배포가 진행됨** |
| CI 파이프라인 (W26) | 실패한 단계를 **통과로 판정** |
| cron + 알림 | 실패해도 **알림이 안 옴** |
| `set -e` 스크립트 | 중단되지 않고 계속 진행 |

W26 [Day 129](../05-infra-mlops/day-129.md)의 자동 배포에서 이 실수는 **깨진 코드를 운영에 올립니다.**

**해결**

```python
def main(argv=None) -> int:
    args = parser.parse_args(argv)
    try:
        todos.toggle(args.id)
    except NotFoundError as e:
        print(f"오류: {e}", file=sys.stderr)     # 에러는 stderr로
        return 1                                  # 실패를 반환
    print("완료")
    return 0

if __name__ == "__main__":
    sys.exit(main())                              # 반환값을 종료 코드로
```

**두 가지가 함께 고쳐졌습니다.**

1. `return 1` — 실패를 종료 코드로 전달
2. `file=sys.stderr` — 에러가 결과 스트림을 오염시키지 않음

**종료 코드 관례**

| 코드 | 의미 |
|---|---|
| 0 | 성공 |
| 1 | 일반적 실패 |
| 2 | 사용법 오류 (argparse 자동) |
| 130 | Ctrl+C (128 + SIGINT 2) |

`grep` 은 "찾지 못함"을 1로 반환합니다. 이 프로젝트의 `search` 도 같은 관례를 따랐습니다.
그래서 이렇게 쓸 수 있습니다.

```bash
if todo search "긴급"; then
    notify "긴급한 할 일이 있습니다"
fi
```

## 오늘의 정리

| 항목 | 문법 |
|---|---|
| 파서 생성 | `argparse.ArgumentParser(prog=, description=)` |
| 위치 인자 | `add_argument("title")` — 필수 |
| 선택 인자 | `add_argument("-p", "--priority", default=)` |
| 플래그 | `action="store_true"` |
| 타입 변환 | `type=int` · `type=Path` |
| 허용 목록 | `choices=["높음", "보통", "낮음"]` — 검증 자동 |
| 여러 값 | `nargs="*"` (0개 이상) · `nargs="+"` (1개 이상) |
| 서브커맨드 | `add_subparsers()` + `set_defaults(func=...)` |
| 분기 | `args.func(args)` — if/elif 불필요 |
| 종료 코드 | `sys.exit(main())` · 0 성공 / 1 실패 / 2 사용법 |
