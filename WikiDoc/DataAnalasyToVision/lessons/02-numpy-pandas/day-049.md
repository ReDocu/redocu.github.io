이 레슨을 마치면 이렇게 할 수 있습니다.

- 열을 추가·삭제·이름 변경하고 자료형을 바꿀 수 있다.
- `apply` `map` `replace` 로 값을 가공할 수 있다.
- **원본 열에서 분석에 필요한 파생 변수를 설계**할 수 있다.

---

## ② 왜 필요한가

**원본 데이터에는 우리가 원하는 열이 없습니다.**

| 원본에 있는 것 | 분석에 필요한 것 |
|---|---|
| 발사 수, 명중 수 | **명중률** |
| 가격 | **가격대(저/중/고)** |
| 생년월일 | **나이**, 연령대 |
| 주소 | **시/도**, 구/군 |
| 방문일시 | **요일**, 시간대, 성수기 여부 |
| 리뷰 수, 평점 | **인기 점수**(가중합) |

**파생 변수를 잘 만드는 것이 분석의 절반입니다.**

머신러닝에서는 이것을 **특성 공학(feature engineering)** 이라고 부르며,
대단원 04에서 모델 성능을 좌우하는 핵심 작업이 됩니다.

> **모델을 바꾸는 것보다 좋은 특성을 하나 만드는 것이 성능을 더 올립니다.**

## ③ 개념 설명

### 열 추가

```python
df["total"] = df["price"] * df["quantity"]        # 계산
df["region"] = "서울"                              # 상수 (모든 행)
df["rank"] = range(1, len(df) + 1)                # 순서
df["accuracy"] = df["hits"] / df["shots"] * 100   # 비율
```

**위치를 지정해 삽입**

```python
df.insert(1, "new_col", values)          # 1번 위치에 삽입
```

**여러 열을 한 번에 — `assign`**

```python
df = df.assign(
    total=df["price"] * df["quantity"],
    discount=lambda d: d["total"] * 0.1,       # 앞에서 만든 열 참조 가능
    final=lambda d: d["total"] - d["discount"],
)
```

> **`assign` 의 장점** — 원본을 수정하지 않고 **새 DataFrame 을 반환**합니다.
> 메서드 체인으로 연결할 수 있어 전처리 파이프라인을 만들 때 유용합니다.

### 열 삭제

```python
df.drop("col", axis=1)                    # 새 DataFrame 반환
df.drop(["a", "b"], axis=1)               # 여러 개
df.drop(columns=["a", "b"])               # 더 명확 (권장)
df.drop(columns=["a"], inplace=True)      # 원본 수정
del df["col"]                              # 즉시 삭제
df.pop("col")                              # 삭제하며 값 반환
```

> **`axis=1` 이 열입니다.** [Day 043](day-043.md)의 `axis` 와 같은 규칙입니다.
> 헷갈리면 `columns=` 를 쓰세요.

### 열 이름 변경

```python
df.rename(columns={"old": "new"})                     # 일부만
df.rename(columns=str.lower)                          # 함수 적용
df.columns = ["a", "b", "c"]                          # 전부 교체
df.columns = df.columns.str.strip().str.lower()       # 정리
```

**실전 — 공공데이터 열 이름 정리**

```python
df.columns = (df.columns
              .str.strip()                    # 앞뒤 공백
              .str.replace(" ", "_")          # 공백 → 밑줄
              .str.replace(r"[()]", "", regex=True))
```

### 자료형 변환

```python
df["score"] = df["score"].astype(int)
df["price"] = df["price"].astype(float)
df["code"] = df["code"].astype(str)
df["flag"] = df["flag"].astype(bool)
df["category"] = df["category"].astype("category")     # 메모리 절약
```

**변환 실패에 안전한 방법**

```python
pd.to_numeric(df["price"], errors="coerce")       # 실패 시 NaN
pd.to_datetime(df["date"], errors="coerce")       # 실패 시 NaT
```

| `errors` | 동작 |
|---|---|
| `"raise"` (기본) | 실패하면 에러 |
| `"coerce"` | 실패하면 `NaN` |

> **`errors="coerce"` 가 실전에서 유용합니다.**
> 1만 건 중 3건이 이상해서 전체가 멈추는 것보다, 3건을 결측으로 만들고 진행하는 편이 낫습니다.
> 다만 **몇 건이 실패했는지 반드시 확인**하세요.

### apply — 함수 적용

```python
df["col"].apply(func)                     # Series 의 각 값에
df.apply(func)                            # 각 열에 (기본 axis=0)
df.apply(func, axis=1)                    # 각 행에
```

**Series 에 적용**

```python
df["grade"] = df["score"].apply(lambda x: "합격" if x >= 60 else "불합격")

def categorize(price):
    if price < 10000:
        return "저가"
    elif price < 50000:
        return "중가"
    return "고가"

df["price_level"] = df["price"].apply(categorize)
```

**행 단위로 적용 (여러 열 조합)**

```python
def calc_score(row):
    return row["rating"] * 20 + row["reviews"] / 100

df["popularity"] = df.apply(calc_score, axis=1)
```

> ⚠️ **`apply(axis=1)` 은 느립니다.** 행마다 파이썬 함수를 호출하기 때문입니다.
> 벡터화로 가능하면 그쪽을 쓰세요.
> ```python
> # 느림
> df.apply(lambda r: r["a"] + r["b"], axis=1)
>
> # 빠름 (수십 배)
> df["a"] + df["b"]
> ```

### map — 값 매핑

```python
# 딕셔너리로 치환
df["region_code"] = df["region"].map({"서울": 1, "부산": 2, "제주": 3})

# 함수 적용 (apply 와 비슷)
df["score2"] = df["score"].map(lambda x: x * 1.1)

# 매핑에 없으면 NaN
df["region"].map({"서울": 1})        # 부산·제주는 NaN
```

| | `map` | `apply` | `replace` |
|---|---|---|---|
| 대상 | Series 만 | Series, DataFrame | Series, DataFrame |
| 딕셔너리 | ✅ | ❌ | ✅ |
| 매핑에 없으면 | **`NaN`** | — | **원래 값 유지** |
| 속도 | 빠름 | 느림 | 보통 |

> **`map` 과 `replace` 의 차이가 중요합니다.**
> ```python
> s = pd.Series(["서울", "부산", "대구"])
> s.map({"서울": "SEOUL"})          # ['SEOUL', NaN, NaN]
> s.replace({"서울": "SEOUL"})      # ['SEOUL', '부산', '대구']
> ```
> **일부만 바꾸려면 `replace`, 전체를 새 값으로 대응시키려면 `map`.**

### replace — 값 치환

```python
df["region"].replace("서울시", "서울")
df["region"].replace({"서울시": "서울", "부산시": "부산"})
df.replace(-999, np.nan)                          # 전체에서
df["price"].replace(0, np.nan)                    # 0을 결측으로
df["text"].replace(r"\s+", " ", regex=True)       # 정규식
```

### 문자열 열 가공 — str 접근자

```python
df["name"].str.strip()                # 공백 제거
df["name"].str.lower()                # 소문자
df["name"].str.replace("주식회사", "")
df["name"].str.len()                  # 길이
df["name"].str.contains("카페")        # 포함 여부
df["name"].str[:3]                    # 앞 3글자
df["addr"].str.split(" ").str[0]      # 첫 단어
df["addr"].str.split(" ", expand=True)  # 여러 열로 분리
```

> `str` 접근자는 [Day 058](day-058.md)에서 자세히 다룹니다.

### 구간화 — cut / qcut

```python
# 값 기준 구간
pd.cut(df["age"], bins=[0, 19, 29, 39, 49, 100],
       labels=["10대", "20대", "30대", "40대", "50대+"])

# 개수 기준 구간 (사분위)
pd.qcut(df["score"], q=4, labels=["하위", "중하", "중상", "상위"])
```

| | `cut` | `qcut` |
|---|---|---|
| 기준 | **값의 범위** | **개수(분위)** |
| 각 구간의 크기 | 다를 수 있음 | **거의 같음** |
| 쓰는 곳 | 나이대, 가격대 | 상위 25%, 사분위 |

### 파생 변수 설계 사고법

**"원본 열로 무엇을 알 수 있나?"** 를 묻습니다.

| 원본 | 파생 변수 | 왜 유용한가 |
|---|---|---|
| 발사, 명중 | 명중률 | 실력을 정규화해 비교 |
| 점수, 시간 | 분당 점수 | 효율 측정 |
| 가격, 평점 | 가성비 | 순위 매기기 |
| 날짜 | 요일, 월, 성수기 | 주기성 발견 |
| 주소 | 시/도 | 지역별 집계 |
| 리뷰 수, 평점 | 신뢰 가중 평점 | 리뷰 3개 5.0점의 함정 방지 |

**좋은 파생 변수의 조건 4가지**

| 조건 | 설명 |
|---|---|
| **의미가 있다** | 도메인 관점에서 설명할 수 있다 |
| **정규화되어 있다** | 규모가 다른 것을 비교 가능하게 |
| **원본에 없는 정보** | 단순 복사·스케일 변경은 무의미 |
| **결측·0에 안전하다** | 분모가 0이 될 수 있는지 확인 |

## ④ 단계별 실습

### Step 1. 열 추가·삭제·이름 변경

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 100

df = pd.DataFrame({
    " 상품 명 ": [f"상품{i}" for i in range(1, n + 1)],      # 공백 있는 열 이름
    "가격(원)": rng.integers(1000, 100000, n),
    "수량": rng.integers(1, 20, n),
    "할인율": rng.choice([0, 5, 10, 20, 30], n),
    "지역": rng.choice(["서울시", "부산시", "제주도"], n),
    "불필요": "삭제대상",
})

print("=" * 70)
print("                  열 가공")
print("=" * 70)

print(f"\n[원본 열 이름]")
print(f"  {list(df.columns)}")

# ── ① 열 이름 정리 ──
df.columns = (df.columns
              .str.strip()                              # 앞뒤 공백
              .str.replace(" ", "_")                    # 공백 → 밑줄
              .str.replace(r"[()]", "", regex=True))    # 괄호 제거

print(f"\n[정리 후]")
print(f"  {list(df.columns)}")

# ── ② 열 추가 (계산) ──
df["총액"] = df["가격원"] * df["수량"]
df["할인액"] = (df["총액"] * df["할인율"] / 100).round(0).astype(int)
df["실결제액"] = df["총액"] - df["할인액"]

print(f"\n[계산 열 3개 추가]  shape={df.shape}")
print(df.head(3).to_string(index=False))

# ── ③ assign 으로 한 번에 (체인) ──
df2 = (df
       .drop(columns=["총액", "할인액", "실결제액"])
       .assign(
           총액=lambda d: d["가격원"] * d["수량"],
           할인액=lambda d: (d["총액"] * d["할인율"] / 100).round(0).astype(int),
           실결제액=lambda d: d["총액"] - d["할인액"],
       ))

print(f"\n[assign 으로 같은 결과]  같은가? {df.equals(df2)}")

# ── ④ 열 삭제 ──
df = df.drop(columns=["불필요"])
print(f"\n[불필요 열 삭제]  shape={df.shape}")

# ── ⑤ 위치 지정 삽입 ──
df.insert(0, "번호", range(1, len(df) + 1))
print(f"\n[0번 위치에 '번호' 삽입]")
print(f"  {list(df.columns)}")

# ── ⑥ 이름 변경 ──
df = df.rename(columns={"가격원": "단가", "지역": "배송지"})
print(f"\n[이름 변경]")
print(f"  {list(df.columns)}")

# ── ⑦ 자료형 변환 ──
print(f"\n[자료형]")
print(df.dtypes.to_string())

df["배송지"] = df["배송지"].astype("category")
print(f"\n  '배송지' 를 category 로 변환")
print(f"  메모리: {df['배송지'].memory_usage(deep=True) / 1024:.1f} KB")

df_obj = df.copy()
df_obj["배송지"] = df_obj["배송지"].astype(str)
print(f"  object 였다면: {df_obj['배송지'].memory_usage(deep=True) / 1024:.1f} KB")

print("\n" + "=" * 70)
```

### Step 2. apply · map · replace 비교

```python
import numpy as np
import pandas as pd
import time

df = pd.DataFrame({
    "region": ["서울시", "부산시", "대구시", "서울시", "제주도"],
    "score": [85, 72, 91, 68, 79],
    "price": [15000, 45000, 8000, 120000, 33000],
})

print("=" * 68)
print("              apply / map / replace")
print("=" * 68)
print(f"\n{df.to_string(index=False)}")

# ══════════ map vs replace — 결정적 차이 ══════════
print(f"\n[map vs replace — 매핑에 없는 값의 처리]")

mapping = {"서울시": "서울", "부산시": "부산"}       # 대구시·제주도는 없음

print(f"\n  매핑: {mapping}")
print(f"\n  {'원본':<10}{'map':<12}{'replace':<12}")
print("  " + "-" * 34)

mapped = df["region"].map(mapping)
replaced = df["region"].replace(mapping)

for orig, m, r in zip(df["region"], mapped, replaced):
    m_str = "NaN" if pd.isna(m) else m
    print(f"  {orig:<10}{m_str:<12}{r:<12}")

print(f"\n  → map: 매핑에 없으면 NaN")
print(f"  → replace: 매핑에 없으면 원래 값 유지")

# 안전한 map — 기본값 지정
mapped_safe = df["region"].map(mapping).fillna(df["region"])
print(f"\n  안전한 map: .map(mapping).fillna(원본) → {list(mapped_safe)}")

# ══════════ apply — Series ══════════
print(f"\n[apply — Series 에 함수 적용]")


def categorize_price(p):
    if p < 10000:
        return "저가"
    if p < 50000:
        return "중가"
    return "고가"


df["price_level"] = df["price"].apply(categorize_price)
df["grade"] = df["score"].apply(lambda x: "A" if x >= 85 else "B" if x >= 70 else "C")

print(df[["price", "price_level", "score", "grade"]].to_string(index=False))

# ══════════ apply(axis=1) — 여러 열 조합 ══════════
print(f"\n[apply(axis=1) — 행 단위]")


def make_label(row):
    return f"{row['region']} {row['price_level']} ({row['grade']})"


df["label"] = df.apply(make_label, axis=1)
print(df[["region", "price_level", "grade", "label"]].to_string(index=False))

# ══════════ 속도 비교 ══════════
print(f"\n{'=' * 68}")
print("[속도 비교] apply(axis=1) vs 벡터화")
print("=" * 68)

big = pd.DataFrame({
    "a": np.random.randint(1, 100, 200_000),
    "b": np.random.randint(1, 100, 200_000),
})

# apply(axis=1)
start = time.perf_counter()
r1 = big.apply(lambda row: row["a"] * row["b"], axis=1)
t1 = time.perf_counter() - start

# 벡터화
start = time.perf_counter()
r2 = big["a"] * big["b"]
t2 = time.perf_counter() - start

# apply on Series
start = time.perf_counter()
r3 = big["a"].apply(lambda x: x * 2)
t3 = time.perf_counter() - start

start = time.perf_counter()
r4 = big["a"] * 2
t4 = time.perf_counter() - start

print(f"\n  20만 행, 두 열 곱하기")
print(f"    apply(axis=1) : {t1:>8.4f}초")
print(f"    벡터화 (a*b)   : {t2:>8.4f}초   → {t1/t2:>6.0f}배 빠름")

print(f"\n  20만 행, 한 열에 2 곱하기")
print(f"    apply         : {t3:>8.4f}초")
print(f"    벡터화 (a*2)   : {t4:>8.4f}초   → {t3/t4:>6.0f}배 빠름")

print(f"\n  결과 같은가? {r1.equals(r2)} / {r3.equals(r4)}")

print(f"\n{'=' * 68}")
print("원칙: 벡터화로 가능하면 apply 를 쓰지 않는다")
print("      apply 는 조건 분기가 복잡할 때만")
print("=" * 68)
```

```
  대구시       NaN         대구시
  서울시       서울          서울
  제주도       NaN         제주도

  → map: 매핑에 없으면 NaN
  → replace: 매핑에 없으면 원래 값 유지

  안전한 map: .map(mapping).fillna(원본) → ['서울', '부산', '대구시', '서울', '제주도']

    apply         :   0.0421초
    벡터화 (a*2)   :   0.0004초   →    105배 빠름

  결과 같은가? True / True
```

### Step 3. 파생 변수 설계 (오늘의 종합 예제)

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 400

# ── 원본 데이터 ──
df = pd.DataFrame({
    "id": np.arange(1, n + 1),
    "player": rng.choice(["홍길동", "김철수", "이영희", "박민수", "최지우"], n),
    "score": 0,          # 아래에서 계산
    "kills": 0,
    "shots": 0,
    "hits": 0,
    "play_seconds": 0,
    "stage": rng.integers(1, 6, n),
    "played_at": pd.Timestamp("2026-06-01")
                 + pd.to_timedelta(rng.integers(0, 90 * 24 * 60, n), unit="m"),
})

df["kills"] = (df["stage"] * 30 + rng.normal(0, 15, n)).clip(5).astype(int)
df["shots"] = (df["kills"] * rng.uniform(1.8, 4.0, n)).astype(int)
df["hits"] = np.minimum((df["kills"] * rng.uniform(1.0, 1.5, n)).astype(int),
                        df["shots"])
df["play_seconds"] = (df["stage"] * 40 + rng.normal(0, 20, n)).clip(10).astype(int)
df["score"] = (df["kills"] * 100 + df["stage"] * 500
               + rng.normal(0, 900, n)).clip(0).astype(int)

# 일부러 0 발사 케이스 만들기 (분모 0 테스트)
df.loc[rng.choice(n, 5, replace=False), ["shots", "hits", "kills"]] = 0

print("=" * 78)
print("                     파생 변수 설계")
print("=" * 78)

print(f"\n[원본 열 {df.shape[1]}개]")
print(f"  {list(df.columns)}")


# ══════════ 파생 변수 생성 ══════════
def add_features(df):
    """
    분석에 필요한 파생 변수를 추가합니다.
    원본은 수정하지 않고 새 DataFrame 을 반환합니다.
    """
    d = df.copy()

    # ── ① 비율 — 분모 0 처리 필수 ──
    d["accuracy"] = np.where(
        d["shots"] > 0,
        (d["hits"] / d["shots"].replace(0, np.nan) * 100).round(1),
        np.nan,                                   # 발사가 없으면 명중률 없음
    )

    # ── ② 효율 — 시간당 성과 ──
    d["score_per_min"] = (d["score"] / (d["play_seconds"] / 60)).round(0)
    d["kills_per_min"] = (d["kills"] / (d["play_seconds"] / 60)).round(1)

    # ── ③ 정규화 — 스테이지 대비 ──
    stage_avg = d.groupby("stage")["score"].transform("mean")
    d["score_vs_stage_avg"] = (d["score"] / stage_avg * 100).round(0)

    # ── ④ 날짜 파생 ──
    d["year"] = d["played_at"].dt.year
    d["month"] = d["played_at"].dt.month
    d["weekday"] = d["played_at"].dt.dayofweek           # 0=월
    d["weekday_name"] = d["played_at"].dt.day_name()
    d["hour"] = d["played_at"].dt.hour
    d["is_weekend"] = d["weekday"].isin([5, 6])
    d["time_slot"] = pd.cut(
        d["hour"],
        bins=[-1, 5, 11, 17, 21, 24],
        labels=["새벽", "오전", "오후", "저녁", "심야"],
    )

    # ── ⑤ 구간화 ──
    d["score_level"] = pd.cut(
        d["score"],
        bins=[-np.inf, 5000, 10000, 15000, np.inf],
        labels=["하", "중", "상", "최상"],
    )
    d["score_quartile"] = pd.qcut(
        d["score"], q=4, labels=["Q1(하위)", "Q2", "Q3", "Q4(상위)"]
    )

    # ── ⑥ 복합 지표 ──
    #   실력 점수 = 명중률(50%) + 분당 처치(30%) + 스테이지(20%)
    acc_norm = (d["accuracy"].fillna(0) / 100).clip(0, 1)
    kpm_norm = (d["kills_per_min"] / d["kills_per_min"].max()).fillna(0)
    stage_norm = d["stage"] / d["stage"].max()

    d["skill_score"] = ((acc_norm * 0.5 + kpm_norm * 0.3
                         + stage_norm * 0.2) * 100).round(1)

    # ── ⑦ 플래그 ──
    d["is_high_score"] = d["score"] >= d["score"].quantile(0.9)
    d["is_efficient"] = d["score_per_min"] >= d["score_per_min"].median()
    d["is_invalid"] = d["shots"] == 0

    return d


df2 = add_features(df)

print(f"\n[파생 변수 추가 후]  {df.shape[1]}개 → {df2.shape[1]}개")
new_cols = [c for c in df2.columns if c not in df.columns]

print(f"\n① 요일별 평균 점수")
weekday_order = ["Monday", "Tuesday", "Wednesday", "Thursday",

korean = ["월", "화", "수", "목", "금", "토", "일"]
by_weekday = (df2.groupby("weekday_name")["score"].agg(["mean", "size"])

for (day, kr), (mean, size) in zip(zip(weekday_order, korean),

    print(f"   {kr}요일  {bar:<30}{mean:>8,.0f}점  ({int(size)}건)")

print(f"\n② 시간대별 플레이")
by_slot = df2["time_slot"].value_counts().sort_index()
for slot, cnt in by_slot.items():
    bar = "■" * int(cnt / by_slot.max() * 28)
    print(f"   {str(slot):<6}{bar:<30}{cnt:>4}건")

print(f"\n③ 주말 vs 평일")
for is_weekend, label in [(False, "평일"), (True, "주말")]:

print(f"\n⑥ 이상 데이터")
print(f"   발사 0건(무효): {df2['is_invalid'].sum()}건")
print(f"   명중률 결측:    {df2['accuracy'].isna().sum()}건")

print("\n" + "=" * 78)
print("파생 변수 설계 원칙:")
print("  ① 분모가 0이 될 수 있는지 확인 (accuracy)")
```

> **눈여겨볼 점 6가지**
> - **`np.where(shots > 0, ..., np.nan)`** — 분모 0을 명시적으로 결측 처리합니다.
> - `groupby("stage")["score"].transform("mean")` — **각 행에 그 스테이지의 평균**을 붙입니다. `transform` 은 [Day 050](day-050.md)에서 배웁니다.
> - `.dt` 접근자로 날짜에서 연·월·요일·시간을 뽑습니다. ([Day 059](day-059.md))
> - `pd.cut` 은 값 기준, `pd.qcut` 은 개수 기준 구간화입니다.
> - **복합 지표는 각 요소를 0~1로 정규화한 뒤 가중합**합니다. 그냥 더하면 규모가 큰 것이 지배합니다.
> - `add_features(df)` 를 **함수로 만들어** 원본을 수정하지 않고 재사용 가능하게 했습니다. ([Day 060](day-060.md)의 파이프라인)

```python
import pandas as pd


def add_game_features(df, weights=None):
    """
    게임 기록에 파생 변수를 추가합니다.

    weights : 종합 점수 가중치 딕셔너리
              기본 {"accuracy": .4, "efficiency": .3, "speed": .2, "stage": .1}

    반환: 파생 변수가 추가된 새 DataFrame (원본 유지)
    """
    d = df.copy()

    if weights is None:
        weights = {"accuracy": 0.4, "efficiency": 0.3,
                   "speed": 0.2, "stage": 0.1}

    # ── ① 명중률 (%) — 분모 0 처리 ──
    d["accuracy"] = np.where(
        d["shots"] > 0,
        (d["hits"] / d["shots"].replace(0, np.nan) * 100).round(1),
        np.nan,
    )

    # ── ② 분당 점수 — 시간 0 처리 ──
    minutes = (d["play_seconds"] / 60).replace(0, np.nan)
    d["score_per_min"] = (d["score"] / minutes).round(0)
    d["kills_per_min"] = (d["kills"] / minutes).round(2)

    # ── ③ 킬당 발사 수 (낮을수록 효율적) ──
    d["shots_per_kill"] = np.where(
        d["kills"] > 0,
        (d["shots"] / d["kills"].replace(0, np.nan)).round(1),
        np.nan,
    )
    #    효율 = 역수 (높을수록 좋게 방향 통일)
    d["efficiency"] = np.where(
        d["shots_per_kill"] > 0,
        (1 / d["shots_per_kill"] * 100).round(1),
        np.nan,
    )

    # ── ④ 시간대 ──
    d["hour"] = d["played_at"].dt.hour
    d["time_slot"] = pd.cut(
        d["hour"],
        bins=[-1, 5, 11, 17, 23],
        labels=["새벽(0-5)", "오전(6-11)", "오후(12-17)", "저녁(18-23)"],
    )

    # ── ⑤ 종합 실력 점수 (0~100) ──
    #    각 요소를 0~1 로 정규화한 뒤 가중합
    def normalize(s):
        """0~1 정규화. 모두 같은 값이면 0.5."""
        lo, hi = s.min(), s.max()
        if pd.isna(lo) or hi == lo:
            return pd.Series(0.5, index=s.index)
        return ((s - lo) / (hi - lo)).fillna(0)

    components = {
        "accuracy": normalize(d["accuracy"]),
        "efficiency": normalize(d["efficiency"]),
        "speed": normalize(d["kills_per_min"]),
        "stage": normalize(d["stage"].astype(float)),
    }

    d["skill_score"] = sum(
        components[k] * w for k, w in weights.items()
    ).mul(100).round(1)

    # ── 유효성 플래그 ──
    d["is_valid"] = (d["shots"] > 0) & (d["play_seconds"] > 0) & (d["kills"] > 0)

    return d


# ══════════ 사용 ══════════
if __name__ == "__main__":
    rng = np.random.default_rng(42)
    n = 300

    stage = rng.integers(1, 6, n)
    kills = (stage * 30 + rng.normal(0, 15, n)).clip(5).astype(int)
    shots = (kills * rng.uniform(1.8, 4.0, n)).astype(int)

        "stage": stage,

                     + pd.to_timedelta(rng.integers(0, 90 * 1440, n), unit="m"),

    # 무효 데이터 섞기
```

**문제 4가지**

**① 원본을 수정합니다.**

`df["accuracy"] = ...` 가 인자로 받은 DataFrame 을 직접 바꿉니다.
호출한 쪽의 `data` 도 함께 변합니다.

**② 0으로 나누기**

`shots` 가 0이면 `inf` 또는 `NaN` 이 생기고, **평균이 `inf`** 가 됩니다.

```python
pd.Series([50.0, np.inf, 70.0]).mean()      # inf
```

**③ `apply(axis=1)` 로 단순 문자열 연결**

벡터화로 하면 수백 배 빠릅니다.

**④ `df.drop("shots")` 가 동작하지 않음**

- `axis=1` 이 없어 **인덱스에서 찾다가 `KeyError`**
- 설령 맞더라도 **반환값을 안 받아** 삭제가 반영되지 않음

**해결**

```python
import numpy as np
import pandas as pd


def process(df, drop_source=False):
    """
    게임 기록에 파생 변수를 추가합니다.

    df          : 원본 (수정하지 않음)
    drop_source : True 면 계산에 쓴 원본 열을 제거
    반환: 새 DataFrame
    """
    d = df.copy()                                   # ① 원본 보호

    # ② 0으로 나누기 방지
    d["accuracy"] = np.where(
        d["shots"] > 0,
        (d["hits"] / d["shots"].replace(0, np.nan) * 100).round(1),
        np.nan,
    )

    # 구간화는 pd.cut 이 더 명확하고 빠름
    d["level"] = pd.cut(
        d["score"],
        bins=[-np.inf, 5000, 10000, np.inf],
        labels=["저", "중", "고"],
    )

    # ③ 벡터화 문자열 연결
    d["label"] = d["player"] + "_" + d["level"].astype(str)

    # ④ 반환값을 받고 columns= 사용
    if drop_source:
        d = d.drop(columns=["shots", "hits"])

    return d

    wrong = data["hits"] / data["shots"] * 100
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 열 추가 | `df["new"] = ...` · `assign()` (체인) |
| 열 삭제 | **`df.drop(columns=[...])`** — 반환값 받기 |
| 이름 변경 | `rename(columns={})` · `df.columns.str.strip()` |
| 자료형 | `astype()` · **`pd.to_numeric(errors="coerce")`** |
| `map` | 딕셔너리 매핑 — **없으면 `NaN`** (누락 발견에 유리) |
| `replace` | 일부 치환 — **없으면 원래 값 유지** |
| `apply` | 함수 적용 · **`axis=1` 은 매우 느림** |
| 구간화 | `pd.cut` (값 기준) · `pd.qcut` (개수 기준) |
| 파생 변수 | 비율 · 효율 · 정규화 · 날짜 분해 · 복합 지표 |
| 주의 | **분모 0** · 원본 훼손 · 방향 통일 |

**오늘 반드시 기억할 세 가지**
> ① **나눗셈 전에 분모가 0일 수 있는지** 확인하세요. `NaN` 하나가 평균 전체를 망칩니다.
> ② `apply(axis=1)` 대신 **벡터화**를 쓰세요. 수백~수천 배 차이입니다.
> ③ 파생 변수 함수는 **`df.copy()` 로 시작**해 원본을 지키세요.
