## 2부 · 근거를 쓰는 법

### 3단 구성

```
① 무엇을 했는가       (사실)
② 왜 그렇게 했는가     (근거 — 측정값)
③ 대안은 무엇이었나    (비교)
```

### 예시

```
① 개발사·퍼블리셔를 TargetEncoder(cv=5)로 인코딩했다.

② 개발사는 1,841종으로 원핫 인코딩 시 특성이 1,841개 늘어
   P/S 비율이 0.3 미만이 된다(Day 107 기준). 라벨 인코딩은
   순서가 없는 범주에 순서를 부여해 Ridge 기준 성능이 37%
   나빠졌다(Day 113 측정).

③ 대안으로 빈도 인코딩(MAE 8.21)과 상위 20개만 원핫(8.04)을
   시도했으나 TargetEncoder(7.84)가 가장 좋았다.
   단, Pipeline 밖에서 적용하면 예측-타깃 상관이 1.0000이 되는
   누수가 발생하므로(218행 검증) 반드시 Pipeline 안에 넣었다.
```

**"측정값이 없는 근거"는 근거가 아닙니다.**

   분류 정확도가 높으면 6.1까지 가능
```

**★ 검증 방법**: 분류기의 오류가 회귀로 전파되므로,
**결합 후 전체 MAE**로 평가해야 한다. 단계별 지표만 보면 착각한다.
```
