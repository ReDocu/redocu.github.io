## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- **도메인 갭**이 무엇인지 설명하고, 학습 데이터를 **실제 설치 조건에 맞춰** 수집할 수 있다.
- **촬영 변수 조합표**를 만들어 편향 없이 목표 장수를 배분할 수 있다.

- **촬영 세션 단위로 분할**해 프레임 누수 없는 val/test 를 만들 수 있다.
- 데이터셋 **v1 을 태깅**하고 통계 리포트를 첨부해 재현 가능하게 관리할 수 있다.

## ③ 개념 설명

### ★ 학습 분포와 운영 분포

머신러닝의 전제는 하나입니다.

```
★ "학습 데이터와 운영 데이터가 같은 분포에서 나온다"

  이 전제가 깨지면 성능 보장이 전부 무효가 됩니다
  val mAP 는 ★ "학습 분포 안에서의 성능"일 뿐입니다
```

**검출에서 분포를 결정하는 것**

| 요소 | 무엇이 바뀌는가 | 영향 |
|---|---|---|
| **카메라 높이** | 부감각(俯瞰角) | 박스 종횡비 자체가 변함 |
| **하향 각도** | 사람이 보이는 부위 | 다리 소실 · 머리 확대 |
| **렌즈 / 화각** | 왜곡 · 원근 | 가장자리 물체가 늘어남 |
| **해상도** | 원거리 객체 픽셀 수 | 24px 기준 미달 여부 |
| **조명** | 색·대비·노이즈 | 야간 IR 은 흑백 |
| **배경** | 오탐 유발 물체 | 학습에 없던 배경 = 오탐 |
| **대상 자체** | 옷·안전모 색·자세 | 클래스 내 다양성 |

```
★ 설치 후 절대 안 바뀌는 것 — 높이 · 각도 · 렌즈 · 해상도 · 배경
   → 고정입니다. 그러니까 그 조건으로만 찍으면 됩니다

  바뀌는 것 — 조명(시간대) · 대상(사람) · 날씨
   → 이건 다양하게 찍어야 합니다
```

> **★ 이 구분이 오늘의 핵심 전략입니다.**
> 고정 조건은 **정확히 일치**시키고, 변동 조건은 **골고루** 담습니다.
> 반대로 하면(높이를 여러 개, 조명은 하나) 데이터가 두 배로 필요해집니다.

### 웹에서 주운 이미지를 섞으면 왜 위험한가

[Day 145](day-145.md)에서 공개 데이터셋을 20~30% 섞는 것을 배웠습니다.
**최종 프로젝트에서는 기준이 더 엄격해집니다.**

```
공개 데이터 / 웹 이미지의 문제

  ① 시점       대부분 눈높이 · 우리는 하향 20도
  ② 해상도     원본 크기가 제각각 · 리사이즈 흔적
  ③ 조명       스튜디오 · 야외 정오 · 우리는 창고 실내
  ④ 렌즈       광각·망원 뒤섞임 · 왜곡 특성 다름
  ⑤ 라벨 기준  ★ 남의 기준. 작은 사람도 다 침 / 안 침
  ⑥ 배경       우리 창고에 없는 물체 → 학습 예산 낭비
```

**그래도 섞어도 되는 3가지 경우**

| 경우 | 왜 괜찮은가 | 비율 상한 |
|---|---|---|
| **① 클래스 절대 부족** | helmet 이 60개뿐이면 학습 자체가 안 됨 | 해당 클래스의 30% |
| **② 하드 네거티브 보강** | 오탐 유발 물체(마네킹·포스터) | 전체의 5% |
| ★ **③ 사전학습 가중치** | 이미 COCO 로 학습된 backbone | 제한 없음 |

```
★ ③ 이 가장 중요합니다

  우리는 yolo11n.pt 에서 시작합니다 = COCO 12만 장의 "일반적인 사람"을 이미 배운 상태
  → 웹 이미지를 데이터셋에 섞을 이유가 크게 줄어듭니다
  → 우리 데이터는 "이 카메라에서는 이렇게 보인다"만 가르치면 됩니다
```

> ⚠️ **"데이터가 많을수록 좋다"는 조건부입니다.**
> 같은 분포일 때만 성립합니다.
> **다른 분포의 데이터 200장을 섞으면 mAP 가 내려간 사례가 매년 나옵니다.**
> 작년 한 팀은 웹 이미지 300장을 섞고 실제 설치 위치 mAP 가 0.71 → 0.63 으로 떨어졌습니다.

### ★ 촬영 변수 체크리스트 7축

고정 조건(높이·각도·렌즈·해상도)은 그대로 두고, **아래 7축만 변화**시킵니다.

| # | 축 | 수준 | 비고 |
|---|---|---|---|
| 1 | **조명** | 주간 / 흐림·실내등 / 야간 / **역광** | ★ 역광은 반드시 |
| 2 | **거리** | 근(3m) / 중(5m) / 원(7m) | 바닥 테이프 기준 |
| 3 | **각도** | 정면 / 측면 / 뒷면 / 사선 | 출입 동선 기준 |
| 4 | **가림** | 없음 / 부분(팔레트·문틀) / 상호 가림 | 실전에서 흔함 |
| 5 | **대상 수** | 0명 / 1명 / 2~3명 / 4명 이상 | ★ 0명이 negative |
| 6 | **배경 변화** | 셔터 열림 / 닫힘 / 팔레트 유무 | |
| 7 | **날씨·기타** | 맑음 / 비(반사) / 문 여닫힘 | 가능한 범위 |

**이 중 자주 빠지는 것**

```
빠지기 쉬운 조건            빠뜨리면 생기는 일
────────────────────       ──────────────────────────
역광                        정오 이후 출입구 전면광 → ★ 실루엣만 남아 미검출

```

> ⚠️ **"찍기 편한 것만 찍는" 편향이 가장 흔한 실패입니다.**
> 밝고, 가깝고, 정면이고, 한 명인 사진이 400장 모입니다.
> 그리고 **야간에 두 명이 겹쳐 지나갈 때** 아무것도 안 잡힙니다.

### ★ 음성 샘플(negative) — 오탐을 줄이는 유일한 방법

```
음성 샘플 = ★ 라벨이 하나도 없는 이미지 (빈 .txt 파일)

  "여기에는 아무것도 없다" 를 가르칩니다
```

**왜 필요한가 — 오탐의 정체**

```
모델이 오탐을 내는 물체 (창고 환경)
  벽에 걸린 작업복 · 그림자 · 소화기 · 청소도구함  → person
  노란 안전 고깔 → helmet   ·   팔레트 더미 → box

★ 이것들이 "사람 없음" 이미지에 등장한 적이 없으면
  모델은 그것들을 배경으로 인식할 기회가 없습니다
```

**비율 가이드**

| 데이터 성격 | 배경 이미지 비율 | 근거 |

| 오탐이 치명적인 시스템 | 15~20% | 보안·의료 |
| 20% 초과 | ✗ | 재현율이 떨어짐 |

```
★ 우리 목표
```

### ★ 연속 프레임의 함정

**이것이 오늘 가장 위험한 함정입니다.**

```
1분 영상에서 0.1초 간격으로 600장을 뽑았다고 합시다

  frm_0001 ┐
  frm_0002 │
  frm_0003 ├─ ★ 사실상 같은 사진
  ...      │
  frm_0100 ┘

  → "600장 데이터셋" 이라고 말하지만
  → ★ 실제 정보량은 20~30장 수준입니다
```

**그리고 이것을 무작위로 분할하면**

```
무작위 8:2 분할
  frm_0042 → train  ·  frm_0043 → ★ val   (두 장의 차이: 사람이 3cm 이동)

  → val 은 "처음 보는 이미지"가 아닙니다
  → mAP 0.95 가 나옵니다 (거짓). 실제 운영에서는 0.4
```

**누수의 크기를 계산해 봅시다.**

```
가정  영상 8개 × 프레임 70장 = 560장 · 무작위 8:2 분할 → val 112장

  각 val 이미지에 대해 "0.5초 이내의 이웃 프레임이 train 에 있을 확률"
  인접 프레임 2개(앞·뒤) 중 train 에 갈 확률 = 1 - 0.2² = 0.96

  → ★ val 의 96% 가 train 에 쌍둥이를 가짐 = val mAP 는 사실상 train mAP
```

> ⚠️ **"데이터를 늘렸는데 val mAP 가 갑자기 0.95 로 뛰었다"면 누수를 의심하세요.**
> 검출에서 val mAP 0.95 는 **정상적인 숫자가 아닙니다.**
> 프레임 추출 데이터에서 이 숫자를 봤다면 99% 누수입니다.

### 유사 프레임 제거 — 3단 방어

[Day 145](day-145.md)에서 3가지 방법을 배웠습니다. 오늘은 **3개를 순서대로 겁니다.**

```
[1단] 시간 간격        0.5초 간격으로만 추출
        비용 0 · 1,800 → 120장

[2단] 프레임 차이      직전 채택 프레임과 픽셀 차이
        빠름 · 120 → 60장

[3단] ★ 지각 해시      pHash 해밍 거리 (전체 쌍 비교)
        중간 · 60 → 42장
        ★ 시간이 떨어져 있어도 비슷하면 잡음
```

```
왜 2단만으로 부족한가

  프레임 차이는 ★ "직전 채택 프레임" 하고만 비교합니다

  0초 : 빈 복도       → 채택
  10초: 사람 지나감    → 채택
  20초: ★ 다시 빈 복도 → 직전(사람)과 다르므로 채택
  30초: 빈 복도       → 직전과 같으므로 제외

  → 0초와 20초가 거의 같은데 둘 다 남습니다
  → pHash 전체 비교가 이걸 잡습니다
```

**pHash 원리 요약**

```
① 32×32 흑백으로 축소
② DCT (이산 코사인 변환) → 저주파 8×8 만 사용
③ 중앙값보다 크면 1, 작으면 0 → ★ 64비트 해시
④ 두 해시의 해밍 거리(다른 비트 수)로 유사도 판정

   거리 0~4   : 사실상 같은 이미지
   거리 5~10  : 비슷한 장면
   거리 11+   : 다른 장면
```

| 임계값 | 남는 비율 | 우리 선택 |
|---|---|---|
| 거리 ≤ 3 만 제거 | 92% | 너무 관대 |
| ★ **거리 ≤ 6 제거** | **68%** | **채택** |
| 거리 ≤ 10 제거 | 41% | 너무 공격적 |

### 1차 선별 — 버릴 기준

자동 제거를 통과해도 **사람이 봐야 걸러지는 것**이 있습니다.

| # | 버릴 기준 | 판단 | 비고 |
|---|---|---|---|
| 1 | **흔들림 · 초점 나감** | 라플라시안 분산 < 60 | 자동 계산 가능 |
| 2 | **노출 실패** | 평균 밝기 < 25 또는 > 230 | 자동 |
| 3 | **대상 없음 과다** | 음성 목표 초과분 | 조합표 대조 |
| 4 | **중복 잔여** | 눈으로 봐도 같은 장면 | 수동 |
| 5 | **프레임 손상** | 티어링 · 색 깨짐 | 수동 |
| 6 | **개인정보 문제** | 동의 안 한 외부인 얼굴 | 무조건 삭제 |
| 7 | **화각 벗어남** | 카메라가 흔들려 각도 변함 | 수동 |

**자동 + 수동의 2단 선별**

```
[자동] 흔들림 · 노출 → 즉시 제외 폴더로      420장 → 371장 (49장 제외)
[수동] ★ 격자 뷰어로 한 화면에 20장씩         371장 → 344장 (27장 제외)

  1장씩 열어 보면 344장 × 3초 = 17분, 20장 격자면 5분
```

**흔들림 판정 — 라플라시안 분산** `cv2.Laplacian(gray, cv2.CV_64F).var()`
(구현은 아래 `extract_frames.py`)

```
★ 절대 기준이 아닙니다 — 해상도·장면 복잡도에 따라 값이 달라집니다
  → 우리 데이터에서 하위 10% 를 보고 임계값을 정합니다
```

### ★ 교차 검수 — 불일치를 숫자로

**"우리는 가이드를 봤으니까 괜찮다"는 착각을 깨는 절차입니다.**

```
방법
  ① 전원이 ★ 같은 이미지 20장을 라벨링합니다
     (자기 할당량과 별개로, 시작 전에)
  ② 6쌍(4C2)의 일치율과 평균 IoU 를 측정합니다
  ③ 목표 미달이면 ★ 규칙을 보완하고 다시 20장
  ④ 통과하면 본 작업 시작
```

**측정 지표 (Day 143 정의 승계)**

```
                A 박스 중 B 와 매칭되는 것
일치율 = ───────────────────────────────────
                (A 박스 수 + B 박스 수) / 2

매칭 기준: 같은 클래스 + IoU ≥ 0.5
평균 IoU: 매칭된 쌍들의 IoU 평균
```

**불일치 유형 분류**

| 유형 | 증상 | 원인 | 조치 |
|---|---|---|---|
| **누락형** | 한쪽만 박스가 있음 | 경계 사례 판단 차이 | ★ 결정표에 추가 |
| **과잉형** | 한쪽이 훨씬 많음 | 반사·인쇄물을 침 | 결정표 4번 재교육 |
| **클래스형** | 같은 위치, 다른 클래스 | helmet vs person 혼동 | 클래스 정의 재확인 |
| **타이트함형** | IoU 0.6~0.75 | 여백 습관 차이 | 예시 카드로 눈 맞추기 |
| **분할형** | 1개 vs 2개 | 겹친 사람을 하나로 침 | 결정표에 추가 |

**재작업 판단 기준**

```
일치율 ≥ 95% 이고 IoU ≥ 0.85     → ✓ 통과. 본 작업 진행
일치율 90~95%                     → ★ 규칙 보완 후 20장 재측정 (30분 소요)
일치율 < 90%                      → 그 사람의 기준이 다름. 1:1 로 20장을 같이 보며
                                     조정하고, 이미 작업한 것은 전량 재검토
특정 클래스만 낮음 (helmet 78%)   → 그 클래스 정의만 다시 씀 (전량 재작업 불필요)
```

```
★ 20장에 40분을 쓰는 것이 아깝습니까?

  일치율 88% 로 560장을 작업하면 약 67장이 서로 다른 기준 → mAP 0.04~0.08 손해
  40분 vs mAP 0.06 — 40분이 훨씬 쌉니다
```

### Step 2. `extract_frames.py` — 프레임 추출 + 유사 프레임 제거

```python
"""data_tools/extract_frames.py
   영상 → 프레임 추출 + 3단 유사 제거 (간격 · 프레임차 · pHash)
   ★ 세션 정보를 파일명과 manifest 에 함께 기록합니다."""
import argparse
import csv
import re
from pathlib import Path

import cv2
import numpy as np

# 파일명: S05_day_mid_side_01.mp4  /  ★ 음성 세션은 각도 생략 S25_day_neg_01.mp4
NAME_RE = re.compile(
    r"^(?P<session>S\d{2})_(?P<light>[a-z]+)_(?P<dist>[a-z]+)_"
    r"(?:(?P<angle>[a-z]+)_)?(?P<seq>\d+)\.(mp4|avi|mov)$", re.I)


# ── 유틸 ────────────────────────────────────────────────
def parse_name(path: Path) -> dict:
    """파일명에서 세션 메타를 뽑는다. 규칙 위반이면 예외."""
    m = NAME_RE.match(path.name)
    if not m:
        raise ValueError(
            f"파일명 규칙 위반: {path.name}\n"
            f"  형식: S05_day_mid_side_01.mp4 (음성은 S25_day_neg_01.mp4)")
    d = m.groupdict()
    d["session"] = d["session"].upper()
    d["angle"] = d["angle"] or "-"          # ★ 음성 세션은 각도가 없다
    return d


def phash(img, hash_size=8, highfreq=4):
    """★ 지각 해시 — 64비트 정수로 반환"""
    size = hash_size * highfreq                      # 32
    g = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    g = cv2.resize(g, (size, size), interpolation=cv2.INTER_AREA)
    dct = cv2.dct(np.float32(g))
    low = dct[:hash_size, :hash_size]                # ★ 저주파만
    med = np.median(low[1:, 1:])                     # DC 성분 제외
    bits = (low > med).flatten()
    val = 0
    for b in bits:
        val = (val << 1) | int(b)
    return val


def hamming(a: int, b: int) -> int:
    return bin(a ^ b).count("1")


def frame_diff(a, b, size=(160, 90)):
    """0~1. 작을수록 비슷"""
    ga = cv2.cvtColor(cv2.resize(a, size), cv2.COLOR_BGR2GRAY).astype(np.float32)
    gb = cv2.cvtColor(cv2.resize(b, size), cv2.COLOR_BGR2GRAY).astype(np.float32)
    return float(np.abs(ga - gb).mean() / 255.0)


def blur_score(img):
    """라플라시안 분산 — 작을수록 흐림"""
    g = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    return float(cv2.Laplacian(g, cv2.CV_64F).var())


def brightness(img):
    return float(cv2.cvtColor(img, cv2.COLOR_BGR2GRAY).mean())


# ── 본체 ────────────────────────────────────────────────
def extract_one(video: Path, out_dir: Path, every_sec=0.5,
                diff_thr=0.012, phash_thr=6, jpeg_q=94):
    """영상 1개 → 프레임. 반환: (record 리스트, 통계 dict)"""
    meta = parse_name(video)
    out_dir.mkdir(parents=True, exist_ok=True)

    cap = cv2.VideoCapture(str(video))
    if not cap.isOpened():
        raise RuntimeError(f"열 수 없음: {video}")

    fps = cap.get(cv2.CAP_PROP_FPS) or 30.0
    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    step = max(1, int(round(fps * every_sec)))

    kept, hashes = [], []          # kept: (frame, hash, t_sec)
    n_read = n_sampled = n_diff_skip = n_hash_skip = 0
    last_kept = None
    idx = 0

    while True:
        ok, frame = cap.read()
        if not ok:
            break
        n_read += 1
        if idx % step != 0:
            idx += 1
            continue
        idx += 1
        n_sampled += 1

        # [2단] 직전 채택 프레임과의 픽셀 차이
        if last_kept is not None and frame_diff(last_kept, frame) < diff_thr:
            n_diff_skip += 1
            continue

        # [3단] 지금까지 채택한 모든 프레임과 pHash 비교
        h = phash(frame)
        if any(hamming(h, hp) <= phash_thr for hp in hashes):
            n_hash_skip += 1
            continue

        hashes.append(h)
        kept.append((frame, h, n_read / fps))
        last_kept = frame

    cap.release()

    # ── 저장 ──
    records = []
    for i, (frame, h, t) in enumerate(kept, 1):
        stem = f"{meta['session']}_{meta['seq']}_{i:03d}"
        path = out_dir / f"{stem}.jpg"
        cv2.imwrite(str(path), frame, [cv2.IMWRITE_JPEG_QUALITY, jpeg_q])
        records.append({
            "file": path.name, "session": meta["session"],
            "light": meta["light"], "dist": meta["dist"],
            "angle": meta["angle"], "video": video.name,
            "t_sec": round(t, 2),
            "blur": round(blur_score(frame), 1),
            "bright": round(brightness(frame), 1),
            "phash": f"{h:016x}",
        })

    stat = {"video": video.name, "session": meta["session"],
            "총프레임": total, "샘플": n_sampled,
            "차이제외": n_diff_skip, "★해시제외": n_hash_skip,
            "저장": len(kept),
            "압축률": f"{(1 - len(kept)/n_sampled)*100:.0f}%" if n_sampled else "-"}
    return records, stat


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--videos", default="C:/vision/final/raw/videos")
```

### Step 5. `check_labels.py` — 라벨 품질 자동 점검

```python
"""data_tools/check_labels.py — 라벨 품질 자동 점검
   ERROR 1건이라도 있으면 종료 코드 1 (★ 학습 전 게이트로 쓸 수 있게)"""
import argparse, sys
from collections import Counter
from pathlib import Path

IMG_EXT = {".jpg", ".jpeg", ".png", ".bmp"}
AR_MIN, AR_MAX = 0.08, 12.0        # 종횡비 w/h 허용 범위
AREA_MIN = 0.0001                  # 전체 면적의 0.01% 미만이면 WARN
DUP_IOU = 0.90


def iou_yolo(a, b):
    """YOLO(cx,cy,w,h) 정규화 좌표끼리 IoU"""
    def xy(v):
        cx, cy, w, h = v
        return cx - w/2, cy - h/2, cx + w/2, cy + h/2
    ax1, ay1, ax2, ay2 = xy(a)
    bx1, by1, bx2, by2 = xy(b)
    iw = max(0.0, min(ax2, bx2) - max(ax1, bx1))
    ih = max(0.0, min(ay2, by2) - max(ay1, by1))
    inter = iw * ih
    ua = (ax2-ax1)*(ay2-ay1) + (bx2-bx1)*(by2-by1) - inter
    return inter / ua if ua > 0 else 0.0


def check(img_dir, lbl_dir, names):
    img_dir, lbl_dir = Path(img_dir), Path(lbl_dir)
    errors, warns = [], []
    stat = {"images": 0, "labels": 0, "boxes": 0, "empty": 0}
    per_class, bpi = Counter(), []

    images = sorted(p for p in img_dir.iterdir() if p.suffix.lower() in IMG_EXT)
    stat["images"] = len(images)
    stems = {p.stem for p in images}

    for lp in lbl_dir.glob("*.txt"):                       # ① 고아 라벨
        if lp.stem != "classes" and lp.stem not in stems:
            warns.append(("고아 라벨", lp.name, "짝 이미지 없음"))
    for p in images:                                       # ② 확장자 대소문자
        if p.suffix != p.suffix.lower():
            warns.append(("확장자 대문자", p.name, "★ Colab 에서 실패 가능"))

    for p in images:
        lp = lbl_dir / f"{p.stem}.txt"
        if not lp.exists():
            errors.append(("라벨 없음", p.name, "★ 0바이트 .txt 를 만드세요"))
            continue
        stat["labels"] += 1
        lines = [x for x in lp.read_text(encoding="utf-8").splitlines()
                 if x.strip()]
        if not lines:
            stat["empty"] += 1
            bpi.append(0)
            continue

        parsed = []
        for i, ln in enumerate(lines, 1):
            f = ln.split()
            where = f"{lp.name}:{i}"
            if len(f) != 5:
                errors.append(("필드 수", where, f"{len(f)}개 (5개여야 함)"))
                continue
            try:
                cid, v = int(f[0]), [float(x) for x in f[1:]]
            except ValueError:
                errors.append(("숫자 아님", where, ln[:40]))
                continue
            if not (0 <= cid < len(names)):
                errors.append(("클래스 ID", where, f"{cid} (0~{len(names)-1})"))
                continue

                errors.append(("0 크기 박스", where,
                               f"w={v[2]:.4f} h={v[3]:.4f}"))
                continue
            if (v[0]-v[2]/2 < -1e-6 or v[0]+v[2]/2 > 1+1e-6 or
                    v[1]-v[3]/2 < -1e-6 or v[1]+v[3]/2 > 1+1e-6):
                warns.append(("박스 화면 이탈", where, "잘라내기 권장"))
            ar = v[2] / v[3]
            if not (AR_MIN <= ar <= AR_MAX):
                warns.append(("종횡비 이상", where,
                              f"w/h={ar:.2f} ({names[cid]})"))
            if v[2] * v[3] < AREA_MIN:
                warns.append(("아주 작은 박스", where,
                              f"면적 {v[2]*v[3]*100:.4f}%"))
            parsed.append((cid, v))
            per_class[names[cid]] += 1

        for i in range(len(parsed)):                       # ③ 중복 박스
            for j in range(i + 1, len(parsed)):
                if parsed[i][0] == parsed[j][0]:
                    v = iou_yolo(parsed[i][1], parsed[j][1])
                    if v >= DUP_IOU:
                        warns.append(("중복 박스", f"{lp.name}:{i+1},{j+1}",
                                      f"IoU {v:.3f}"))
        stat["boxes"] += len(parsed)
        bpi.append(len(parsed))
    return errors, warns, stat, per_class, bpi


def report(title, errors, warns, stat, per_class, bpi):
    print("=" * 88)
    print(f"라벨 품질 점검 — {title}")
    print("=" * 88)
    pos = [n for n in bpi if n > 0]
    print(f"  이미지 {stat['images']}장 · 라벨 {stat['labels']}개 · "
          f"박스 {stat['boxes']}개 · ★ 빈 라벨 {stat['empty']}장 "
          f"({stat['empty']/max(1,stat['images'])*100:.1f}%)")
    print(f"  이미지당 박스 {sum(bpi)/max(1,len(bpi)):.2f} "
          f"(양성만 {sum(pos)/max(1,len(pos)):.2f}) · 최대 {max(bpi or [0])}")
    print("  클래스별  " + " · ".join(f"{k} {v}" for k, v in per_class.items()))
    print("-" * 88)
    if errors:
        print(f"  ★ ERROR {len(errors)}건")
        for k, c in Counter(k for k, _, _ in errors).most_common():
            print(f"      {k:<14} {c}건")
        for k, w, d in errors[:6]:
            print(f"        {k:<14} {w:<22} {d}")
    else:
        print("  ✓ ERROR 0건")
    if warns:
        print(f"  WARN {len(warns)}건  " + " · ".join(
            f"{k} {c}" for k, c in Counter(k for k, _, _ in warns).most_common()))
    else:
        print("  ✓ WARN 0건")
    print("=" * 88)
    return len(errors)


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
```

```python
"""data_tools/cross_check.py — 교차 검수 (Day 143 consistency.py 확장)
   ★ 추가된 것: 불일치 유형 자동 분류 · 클래스별 일치율"""
from collections import Counter, defaultdict
from itertools import combinations
from pathlib import Path

import cv2
import numpy as np

NAMES = ["person", "helmet", "box"]
MATCH_IOU = 0.5
ROOT = Path("C:/vision/final/work/cross")


def yolo_to_voc(v, w, h):
    cx, cy, bw, bh = v
    return (int((cx-bw/2)*w), int((cy-bh/2)*h),
            int((cx+bw/2)*w), int((cy+bh/2)*h))


def iou(a, b):
    iw = max(0, min(a[2], b[2]) - max(a[0], b[0]))
    ih = max(0, min(a[3], b[3]) - max(a[1], b[1]))
    inter = iw * ih
    ua = (a[2]-a[0])*(a[3]-a[1]) + (b[2]-b[0])*(b[3]-b[1]) - inter
    return inter / ua if ua > 0 else 0.0


def load(lbl_dir, stem, w, h):
    p = Path(lbl_dir) / f"{stem}.txt"
    if not p.exists():
        return []
    out = []
    for ln in p.read_text(encoding="utf-8").splitlines():
        f = ln.split()
        if len(f) == 5:
            out.append((int(f[0]),
                        yolo_to_voc([float(x) for x in f[1:]], w, h)))
    return out


def match(A, B, thr=MATCH_IOU):
    """탐욕 매칭. 반환 (쌍, A미매칭 idx, B미매칭 idx)"""
    pairs, used = [], set()
    for i, (ca, ba) in enumerate(A):
        best, bj = 0.0, -1
        for j, (cb, bb) in enumerate(B):
            if j not in used and ca == cb:
                v = iou(ba, bb)
                if v > best:
                    best, bj = v, j
        if best >= thr:
            used.add(bj)
            pairs.append((i, bj, best))
    ua = [i for i in range(len(A)) if i not in {p[0] for p in pairs}]
    ub = [j for j in range(len(B)) if j not in used]
    return pairs, ua, ub


def classify(A, B, pairs, ua, ub):
    """★ 불일치 유형 분류 — 무엇을 고쳐야 하는지 알려 준다"""
    k = Counter()
    for _, _, v in pairs:
        if v < 0.75:
            k["타이트함형"] += 1
    for i in ua:
        hit = any(iou(A[i][1], bb) >= MATCH_IOU for _, bb in B)
        k["클래스형" if hit else "누락형(B가 안 침)"] += 1
    for j in ub:
        hit = any(iou(ba, B[j][1]) >= MATCH_IOU for _, ba in A)
        k["클래스형" if hit else "누락형(A가 안 침)"] += 1
    return k


def compare(img_dir, da, db):
    na = nb = nm = 0
    ious, kinds = [], Counter()
    ca, cb, cm = Counter(), Counter(), Counter()
    for p in sorted(Path(img_dir).glob("*.jpg")):
        img = cv2.imread(str(p))
        if img is None:
            continue
        h, w = img.shape[:2]
        A, B = load(da, p.stem, w, h), load(db, p.stem, w, h)
        pairs, ua, ub = match(A, B)
        na += len(A); nb += len(B); nm += len(pairs)
        ious += [v for _, _, v in pairs]
        kinds += classify(A, B, pairs, ua, ub)
        for c, _ in A:
            ca[NAMES[c]] += 1
        for c, _ in B:
            cb[NAMES[c]] += 1
        for i, _, _ in pairs:
            cm[NAMES[A[i][0]]] += 1
    d = (na + nb) / 2 or 1
    return {"A": na, "B": nb, "m": nm, "agree": nm / d, "kinds": kinds,
            "iou": float(np.mean(ious)) if ious else 0.0,
            "cls": {n: (ca[n], cb[n], cm[n]) for n in NAMES}}


res = {(a, b): compare(ROOT / "images", ROOT / f"labels_{a}",
                       ROOT / f"labels_{b}")
       for a, b in combinations("ABCD", 2)}

print("=" * 88)
print("★ 교차 검수 — 공통 20장 · 4명 · 6쌍")
print(f"{'쌍':<8}{'A박스':>8}{'B박스':>8}{'매칭':>8}{'일치율':>10}{'평균IoU':>10}   판정")
print("-" * 88)
wa = wi = 1.0
for (a, b), r in res.items():
    ok = r["agree"] >= 0.95 and r["iou"] >= 0.85
    wa, wi = min(wa, r["agree"]), min(wi, r["iou"])
    print(f"{a}-{b:<6}{r['A']:>8}{r['B']:>8}{r['m']:>8}"
          f"{r['agree']*100:>9.1f}%{r['iou']:>10.3f}   {'✓' if ok else '★ 미달'}")
print("-" * 88)
print(f"  ★ 최솟값  일치율 {wa*100:.1f}%  IoU {wi:.3f}   (목표 95% / 0.85)")

total = Counter()
for r in res.values():
    total += r["kinds"]
print("\n[불일치 유형]  " + " · ".join(f"{k} {v}건" for k, v in total.most_common()))

print(f"\n[클래스별 일치율]  {'클래스':<10}{'A합':>7}{'B합':>7}{'매칭':>7}{'일치율':>9}")
for n in NAMES:
    sa = sum(r["cls"][n][0] for r in res.values())
    sb = sum(r["cls"][n][1] for r in res.values())
    sm = sum(r["cls"][n][2] for r in res.values())
    d = (sa + sb) / 2 or 1
    print(f"{'':<19}{n:<10}{sa:>7}{sb:>7}{sm:>7}{sm/d*100:>8.1f}%"
          f"{'  ★ 문제' if sm/d < 0.9 else ''}")
print("=" * 88)
```

### Step 7. `split_dataset.py` — 세션 단위 분할

```python
"""data_tools/split_dataset.py — ★ 촬영 세션 단위 분할
   제약 ① 세션은 쪼개지 않는다  ② 각 조명이 val 에 최소 1세션
        ③ val 클래스별 인스턴스 ≥ 20  ④ 비율 70/20/10 ±5%"""
import argparse, csv, random, shutil
from collections import Counter, defaultdict
from pathlib import Path

NAMES = ["person", "helmet", "box"]
SPLITS = ("train", "val", "test")
LIGHT_OF = {}


def load_plan(path):
    with open(path, encoding="utf-8-sig") as f:
        for r in csv.DictReader(f):
            LIGHT_OF[r["session"]] = r["조명"]


def scan(work):
    """세션별 (이미지·라벨) 목록과 클래스 카운트"""
    sess = defaultdict(lambda: {"imgs": [], "cnt": Counter(), "empty": 0})
    for m in "ABCD":
        img_d, lbl_d = Path(work)/m/"images", Path(work)/m/"labels"
        for p in sorted(img_d.glob("*.jpg")):
            lp = lbl_d / f"{p.stem}.txt"
            lines = ([x for x in lp.read_text(encoding="utf-8").splitlines()
                      if x.strip()] if lp.exists() else [])
            s = sess[p.name.split("_")[0]]
            s["imgs"].append((p, lp))
            if not lines:
                s["empty"] += 1
            for ln in lines:
                s["cnt"][NAMES[int(ln.split()[0])]] += 1
    return sess


def split(sess, ratio=(0.70, 0.20, 0.10), seed=42, tries=3000):
    """★ 제약을 만족하는 배정을 무작위 재시작으로 찾는다"""
    rng = random.Random(seed)
    ids = list(sess)
    total = sum(len(sess[s]["imgs"]) for s in ids)
    lights = {LIGHT_OF.get(s, "?") for s in ids}
    best, best_cost = None, 1e9

    for _ in range(tries):
        rng.shuffle(ids)
        assign, got = {}, dict.fromkeys(SPLITS, 0)
        for s in ids:          # 부족분이 가장 큰 쪽에 세션을 통째로
            need = {k: ratio[i]*total - got[k] for i, k in enumerate(SPLITS)}
            k = max(need, key=need.get)
            assign[s] = k
            got[k] += len(sess[s]["imgs"])

        miss = lights - {LIGHT_OF.get(s, "?") for s in ids if assign[s] == "val"}
        for m in miss:         # ★ 빠진 조명은 train 에서 하나 끌어온다
            c = [s for s in ids if LIGHT_OF.get(s) == m and assign[s] == "train"]
            if c:
                assign[rng.choice(c)] = "val"

        vc = Counter()
        for s in ids:
            if assign[s] == "val":
                vc += sess[s]["cnt"]
        if any(vc[n] < 20 for n in NAMES):
            continue
        got = Counter()
        for s in ids:
            got[assign[s]] += len(sess[s]["imgs"])
        cost = sum(abs(got[k]/total - ratio[i]) for i, k in enumerate(SPLITS))
        if cost < best_cost:
            best, best_cost = dict(assign), cost
    if best is None:
        raise SystemExit("★ 제약을 만족하는 분할 실패 — 세션을 더 잘게 나누세요")

def materialize(sess, assign, out):

                    "", encoding="utf-8")
            rows.append({"file": ip.name, "session": s,

        w = csv.DictWriter(f, fieldnames=["file", "session", "light", "split"])
```

```python
"""data_tools/leak_check.py — train/val 사이 pHash 근접 쌍 탐지"""
from pathlib import Path

import cv2
import numpy as np

ROOT = Path("cctv_project/datasets/final_v1/images")


def phash(p, hs=8):
    g = cv2.cvtColor(cv2.imread(str(p)), cv2.COLOR_BGR2GRAY)
    g = cv2.resize(g, (hs*4, hs*4), interpolation=cv2.INTER_AREA)
    low = cv2.dct(np.float32(g))[:hs, :hs]
    v = 0
    for b in (low > np.median(low[1:, 1:])).flatten():
        v = (v << 1) | int(b)
    return v


tr = {p: phash(p) for p in sorted((ROOT/"train").glob("*.jpg"))}
va = {p: phash(p) for p in sorted((ROOT/"val").glob("*.jpg"))}
hits = sorted((bin(hv ^ ht).count("1"), pv.name, pt.name)
              for pv, hv in va.items() for pt, ht in tr.items()
              if bin(hv ^ ht).count("1") <= 6)

print("=" * 74)
```

"""data_tools/dataset_report.py — 통계 리포트 (표 + ASCII 히스토그램)"""
import argparse
from collections import Counter, defaultdict
from pathlib import Path

import cv2

NAMES = ["person", "helmet", "box"]
SPLITS = ["train", "val", "test"]


def bar(v, vmax, width=40):
    n = int(round(v / vmax * width)) if vmax else 0
    return "█" * n + "·" * (width - n)


def bucket(area):
    """COCO 기준 small/medium/large"""
    return "small" if area < 32*32 else ("medium" if area < 96*96 else "large")


def collect(root):
    data = {}
    for sp in SPLITS:
        img_d, lbl_d = Path(root)/"images"/sp, Path(root)/"labels"/sp
        if not img_d.exists():
            continue
        recs = []
        for p in sorted(img_d.glob("*.jpg")):
            h, w = cv2.imread(str(p)).shape[:2]
            lp, boxes = lbl_d / f"{p.stem}.txt", []
            if lp.exists():
                for ln in lp.read_text(encoding="utf-8").splitlines():
                    f = ln.split()
                    if len(f) == 5:
                        bw, bh = float(f[3])*w, float(f[4])*h
                        boxes.append((NAMES[int(f[0])], bw*bh))
            recs.append({"session": p.name.split("_")[0], "boxes": boxes})
        data[sp] = recs
    return data


def main(root, out_md):
    data = collect(root)
    lines = []

    def P(s=""):
        print(s); lines.append(s)

    P("=" * 84)
    P("데이터셋 통계 리포트 — final_v1")
    P("=" * 84)

    P("|---|---|---|---|---|---|")
    for sp, recs in data.items():
        nb = sum(len(r["boxes"]) for r in recs)
        ne = sum(1 for r in recs if not r["boxes"])
        P(f"| {sp} | {len(recs)} | {nb} | {ne} ({ne/len(recs)*100:.0f}%) "
          f"| {nb/len(recs):.2f} | {len({r['session'] for r in recs})} |")

    cls = defaultdict(Counter)
    for sp, recs in data.items():
        for r in recs:
            for name, _ in r["boxes"]:
                cls[sp][name] += 1
    tot = Counter()
    for c in cls.values():
        tot += c

    P("\n## ② 클래스별 박스 수\n")
    P("```")
    for n in NAMES:
        P(f"  {n:<8} {tot[n]:>5}  {bar(tot[n], max(tot.values()))}")
    P(f"\n  ★ 최다/최소 비 = {max(tot.values())/max(1,min(tot.values())):.1f} : 1")
    P("```")
    P("\n| 클래스 | train | val | test | 합계 |")
    P("|---|---|---|---|---|")
    for n in NAMES:
        P(f"| {n} | {cls['train'][n]} | {cls['val'][n]} | {cls['test'][n]} "
          f"| {tot[n]} |")

    buck = defaultdict(Counter)
    for recs in data.values():
        for r in recs:
            for name, area in r["boxes"]:
                buck[name][bucket(area)] += 1
    P("\n## ③ 박스 크기 분포 (COCO 기준)\n")
    P("```")
    P(f"  {'클래스':<8}{'small':>8}{'medium':>9}{'large':>8}   분포")
    for n in NAMES:
        b = buck[n]
        t = sum(b.values()) or 1
        P(f"  {n:<8}{b['small']:>8}{b['medium']:>9}{b['large']:>8}   "
          f"{'s'*int(b['small']/t*30)}{'m'*int(b['medium']/t*30)}"
          f"{'L'*int(b['large']/t*30)}")
    allb = Counter()
    for b in buck.values():
        allb += b
    P(f"\n  ★ small 비율 {allb['small']/max(1,sum(allb.values()))*100:.1f}%")
    P("     40% 초과면 imgsz 를 올리는 것을 검토하세요")
    P("```")

    hist = Counter()
    for recs in data.values():
        for r in recs:
            hist[min(len(r["boxes"]), 10)] += 1
    P("\n## ④ 이미지당 객체 수\n")
    P("```")
    for k in range(11):

    sess = Counter()

    Path(out_md).parent.mkdir(parents=True, exist_ok=True)
    Path(out_md).write_text("\n".join(lines), encoding="utf-8")
    P(f"\n  저장: {out_md}")
