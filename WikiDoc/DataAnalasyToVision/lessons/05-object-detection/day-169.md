## ③ 개념 설명

### 구성 ① — 파이에서 직접 추론

```
┌─ 현장 (파이) ──────────────────────────┐
│  [카메라 1280×720 15FPS]               │
│      │ BGR ndarray                    │
│  [detector NCNN 640]  ★ 186 ms        │
│      │ dict                            │
│  [이벤트 판정 3프레임 연속]              │
└──────┼─────────────────────────────────┘
       │ JSON 1.2 KB + JPEG 110 KB · 하루 20~40건만
       ▼
  [Flask 서버]  저장 · 조회만 (추론 안 함)
```

**핵심 성질**

| 성질 | 내용 |
|---|---|
| 추론 위치 | **파이 (엣지)** |
| 네트워크에 흐르는 것 | **이벤트만** (결과 + 스냅샷) |
| 서버가 하는 일 | 저장 · 조회 · 화면 (추론 안 함) |
| 서버가 죽으면 | **파이는 계속 검출** (큐에 쌓임) |
| 원본 영상 | **파이 밖으로 안 나감** |
| 모델 크기 한계 | yolo11n + NCNN 640 이 상한 |

이것이 [Day 154](day-154.md) 결정서의 **"1단계 + 2단계 전송"** 이며,
[Day 168](day-168.md)에서 파이가 5.4 FPS 를 냈으므로 **이미 가능합니다.**

### 구성 ② — 파이는 촬영·전송, 서버가 추론

```
┌─ 현장 (파이) ─────────────────┐
│  [카메라 640×480]             │  JPEG 50 KB × 10 FPS
│      │ imencode q75          ├──────────────────────┐
│   파이는 추론 안 함            │  ★ 4.0 Mbps 상시     │
└───────────────────────────────┘                     ▼
                        ┌─ 서버 (GPU) ──────────────────────┐
                        │  POST /api/frames                │
                        │  → imdecode 3 ms                 │
                        │  → yolo11s GPU 14 ms             │
                        │  → 이벤트 판정 → DB              │
                        └──────────────────────────────────┘
```

**핵심 성질**

| 성질 | 내용 |
|---|---|
| 추론 위치 | **서버** |
| 네트워크에 흐르는 것 | **모든 프레임** |
| 파이가 하는 일 | 촬영 · JPEG 인코딩 · POST (CPU 12%) |
| 서버가 죽으면 | **감지 자체가 멈춤** (단일 실패점) |
| 원본 영상 | **계속 네트워크로 나감** |
| 모델 크기 한계 | **거의 없음** (yolo11m/l 도 가능) |

> ⚠️ **구성 ②는 "나쁜 설계"가 아닙니다.**
> 실제 상용 시스템 중에도 이 구조가 많습니다 — 카메라가 싸고(RTSP IP캠 3만원),
> 서버에 GPU 가 있고, 네트워크가 유선 기가비트인 환경이라면 **오히려 정답**입니다.
> **우리 환경에서 부적합할 뿐입니다.** 오늘 그 "우리 환경"을 숫자로 확인합니다.

### ★ 대역폭 — 하루 몇 GB 인지 반드시 계산하세요

**1프레임 JPEG 크기 (실측)**

| 해상도 | 품질 | 평균 크기 | 용도 |
|---|---|---|---|
| 640×480 | q75 | **50 KB** | 구성 ② 기본값 |
| 1280×720 | q80 | **110 KB** | 이벤트 스냅샷 |
| 1920×1080 | q85 | 240 KB | 원본 보관 |

**계산식** — `KB/프레임 × FPS × 86,400 ÷ 10⁶ = GB/일`
구성 ① 은 프레임이 아니라 건수입니다 — `(1.2 + 110) KB × 하루 건수`

환산표 (`bandwidth_calc.py` 출력):

```
      해상도  FPS   KB/s  Mbps  GB/일  TB/월
 640×480 q75    5  250.0  2.00   21.6   0.65
 640×480 q75   10  500.0  4.00   43.2   1.30      ★ 구성 ② 기본 설정
 640×480 q75   15  750.0  6.00   64.8   1.94
1280×720 q80   10 1100.0  8.80   95.0   2.85
1920×1080 q85  10 2400.0 19.20  207.4   6.22
  구성 ① 하루  20건 →    2.22 MB/일 ·  0.07 GB/월
  구성 ① 하루  40건 →    4.45 MB/일 ·  0.13 GB/월
  구성 ① 하루 100건 →   11.12 MB/일 ·  0.33 GB/월
```

**★ 이 숫자가 오늘 문서에서 가장 중요합니다.**

```
구성 ② 640×480 10 FPS  →  하루 43.2 GB  ·  한 달 1.30 TB
구성 ①    하루 20건    →  하루 2.22 MB  ·  한 달 0.07 GB
                          → 19,459 배 차이

감이 안 오면
  43.2 GB/일 = 유튜브 1080p 를 24시간 연속 재생하는 것과 같습니다
  2.22 MB/일 = 카카오톡 사진 2장
```

> ⚠️ **"우리 집은 무제한 요금제인데요?"**
> 무제한은 **하향(다운로드)** 기준입니다. 파이 → 서버는 **상향(업로드)** 입니다.
> 가정용 인터넷의 상향은 하향보다 훨씬 좁고, 4 Mbps 를 상시 점유하면
> **가족의 화상회의·게임이 먼저 끊깁니다.**

### 트리거 설계 — 움직임을 어떻게 감지하나

`pi/trigger.py` 의 트리거들은 모두 `update(frame) → (fired, ratio)` 인터페이스로
바꿔 끼울 수 있게 만듭니다. 가장 가벼운 **프레임 차분**의 핵심은 세 줄입니다.

```python
small = cv2.GaussianBlur(                          # 320×240 축소가 핵심
    cv2.cvtColor(cv2.resize(frame, (320, 240)), cv2.COLOR_BGR2GRAY), (5, 5), 0)
diff = cv2.absdiff(self.prev, small)
_, mask = cv2.threshold(diff, 25, 255, cv2.THRESH_BINARY)
ratio = cv2.countNonZero(mask) / mask.size         # ratio >= 0.004 면 움직임
```

배경 차분은 `cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=16)` 로
같은 자리를 대신하고, 앞 30프레임은 배경 학습 구간이라 판정하지 않습니다.

| 방법 | 파이 5 비용 | 오탐 원인 | 야간 | 초기 지연 | 구성 ②에서 |
|---|---|---|---|---|---|
| ① 프레임 차분 | **1.2 ms** | 조명 · 흔들림 · 나뭇잎 | 약함 | 없음 | 사용 가능 |
| ② MOG2 | 15.8 ms | 비 · 눈 · 급격한 조명 | 보통 | 30프레임 학습 | 사용 가능 |
| ③ 검출 기반 | 186 ms | 거의 없음 | 모델 성능 | 없음 | ✗ **순환 논리** |
| ④ PIR 센서 | **0 ms** (하드웨어) | 열원 · 동물 | 강함 | 없음 | 사용 가능 |

> ⚠️ **구성 ②에서 ③ 검출 기반 트리거는 쓸 수 없습니다.**
> "검출 결과가 있어야 보낼지 결정하는데, 검출은 서버가 한다" → **순환 논리**입니다.
> 구성 ②에서는 **반드시 추론 없는 트리거(① 또는 ②)** 여야 합니다.
> **하이브리드 설계에서 가장 많이 틀리는 부분입니다.**

**PIR 센서 (HC-SR501, 3,000원)** — CPU 비용 0, 완전 암흑에서도 동작.
단 **유리창 너머는 감지 못 합니다**(적외선이 유리를 통과하지 못함). GPIO 는 [Day 170](day-170.md).

**★ 트리거 상태 머신과 프리롤**

```
                  ratio ≥ 0.004 (즉시 켬)
     ┌──────┐  ────────────────→  ┌──────────┐
     │ IDLE │                     │ STREAMING│
     └──────┘  ←────────────────  └──────────┘
              ratio < 0.004 가 연속 5초

켜는 것은 즉시, 끄는 것은 5초 뒤
  사람이 잠깐 멈추면 ratio 가 0 이 됩니다
  → 즉시 끄면 전송이 딸꾹질합니다
```

**프리롤** — 최근 2초의 JPEG 를 `deque(maxlen=20)` 에 늘 담아 두었다가,
트리거가 켜지는 순간 **그 20장을 먼저 보낸 뒤** 실시간 전송을 이어 갑니다.

```
프리롤이 없으면
  트리거가 켜진 순간 사람은 이미 화면 한가운데 있습니다
  → "어디서 들어왔는지" 가 기록에 없습니다

비용: 2초 × 10 FPS × 50 KB = 1 MB · 하루 30회 → 30 MB (8% 증가)
```

### 전송 방식 비교

| 방식 | 연결 | 프레임당 오버헤드 | 실패 감지 | 재전송/큐 | 방화벽·NAT | 구현 난이도 | 라이브러리 |
|---|---|---|---|---|---|---|---|
| **HTTP POST (multipart)** | 요청마다 | **~600 B** | **상태 코드** | **직접 · 단순** | 통과 | **낮음** | `requests` |
| **HTTP POST (JSON+base64)** | 요청마다 | **+33% 본문** | 상태 코드 | 단순 | 통과 | 낮음 | 표준 |
| **MJPEG 스트림** | 지속 | ~50 B | 끊김만 | ✗ 없음 | 통과 | 보통 | Flask `Response` |
| **RTSP (H.264)** | 지속 | **최소** | 세션 단위 | ✗ 없음 | **포트·NAT 문제** | **높음** | GStreamer |
| **MQTT** | 지속 | **~4 B** | **QoS 1/2** | **브로커가 보관** | 브로커 필요 | 보통 | `paho-mqtt` |
| **WebSocket** | 지속 | ~6 B | ping/pong | 직접 구현 | 통과 | 보통 | `websockets` |

**각 방식의 성격**

```
HTTP POST   파이 ──POST──→ 서버 ←──201──
            한 번에 하나 · 성공/실패가 ★ 명확 · "건" 단위 데이터에 최적
MJPEG       서버 → 브라우저 방향 (Day 163) · 파이 → 서버로 쓰려면 역방향
RTSP        서버 ──PLAY──→ 파이(RTSP 서버) ←── RTP 스트림
            H.264 라 대역폭 1/10 · 대신 파이 IP 고정 · 포트 개방 필요
MQTT        파이 ──publish──→ [브로커] ──subscribe──→ 서버
            기기가 많을 때 최적 · QoS 1/2 보장 · 대신 브로커를 운영해야 함
WebSocket   파이 ←── 양방향 지속 연결 ──→ 서버
            서버가 파이에 명령 가능 · 재연결·하트비트를 직접 구현
```

### ★ 우리가 HTTP POST 를 고르는 이유

```
① 서버가 이미 Flask 입니다 — 라우트 하나만 추가하면 끝
   ([Day 156](day-156.md)~[Day 165](day-165.md)) · MQTT 는 브로커 운영이 새 숙제
② 요청-응답이 1:1 — 201 = 확실히 저장, 타임아웃 = 확실히 모름 → 재시도
   → ★ 큐 로직이 열 줄이면 끝납니다
③ 상태 코드가 표준 — 400 은 재시도 무의미, 5xx 는 재시도, 429 는 대기
④ curl 한 줄로 테스트됩니다 — 파이가 없어도 서버를 디버깅할 수 있습니다
⑤ 멱등성을 만들기 쉬움 — event_id 를 PK 로 → INSERT 실패 = 중복 → 세 줄
⑥ 방화벽·프록시를 그냥 통과 (80/443 외 포트가 막힌 망이 많습니다)
⑦ 팀 전원이 이미 아는 기술 — 남은 26일에 새 기술을 배울 여유가 없습니다
```

**단점도 씁니다 (정직하게)**

```
✗ 프레임 스트리밍에는 비효율 — 요청마다 헤더 ~600 B, 10 FPS 면 6 KB/s(1.2%)
  → requests.Session() 으로 연결을 재사용하면 대부분 사라집니다
✗ 서버 → 파이 방향 명령이 불가능 — 파이가 GET /api/config 를 폴링 (Day 176)
✗ MQTT 의 QoS 같은 프로토콜 수준 보장이 없음
  → 그래서 오늘 아웃박스 큐를 ★ 우리가 직접 만듭니다
```

**채택 요약 (리포트에 그대로 쓰세요)**

```

근거:     기존 Flask 재사용 · 상태 코드 기반 재시도 · 멱등성 구현 용이
대안:     MQTT (기기 20대 이상으로 확장 시 재검토)
```

**필드 규약**

| 필드 | 필수 | 타입 | 규칙 |
|---|---|---|---|
| `schema` | 필수 | str | `cctv.event/<major>.<minor>` · **major 가 다르면 400** |
| `event_id` | **필수** | str | **전역 유일** · 영숫자·`_`·`-` 만 · 길이 8~64 |
| `device_id` | 필수 | str | 헤더 `X-Device-Id` 와 **일치해야 함** |
| `ts` | 필수 | str | ISO 8601 · **타임존 필수** |
| `ts_monotonic_ms` | 선택 | int | 파이 부팅 후 경과 ms (시계 보정용) |
| `type` | 필수 | str | `person_detected` \| `box_appeared` \| `box_removed` \| `helmet_missing` |
| `classes` | 필수 | dict | `{"person": 2}` · 값은 양의 정수 |
| `max_conf` | 선택 | float | 0.0~1.0 |
| `detections` | 선택 | list | [Day 152](day-152.md) `detections` 형식 |
| `image` | 선택 | dict | 첨부 파일의 메타 · `sha256` 로 무결성 확인 |
| `agent` | 선택 | dict | 어느 버전이 보냈는지 — 사후 추적에 필수 |

> ⚠️ **`event_id` 는 파이가 만듭니다. 서버가 만들지 않습니다.**
> 서버가 만들면 **재전송할 때마다 새 ID 가 생겨 중복을 막을 수 없습니다.**
> 이것이 **멱등성의 출발점**입니다.

**`event_id` 생성 규칙**

```python
def make_event_id(device_id: str, when: datetime | None = None) -> str:
    """사람이 읽을 수 있으면서 전역 유일한 ID"""
    when = when or datetime.now().astimezone()
    return f"evt_{when.strftime('%Y%m%d_%H%M%S')}_{uuid.uuid4().hex[:6]}"


# evt_20260115_143022_a3f9c2
#     └─ 날짜 ─┘└ 시각 ┘└ 랜덤 ┘
#   랜덤: 같은 초에 두 이벤트가 나면 시각만으로는 충돌
#   날짜: uuid4 만 쓰면 로그에서 ★ 언제 일인지 못 읽습니다
```

**응답**

```jsonc

{"ok": true, "event_id": "evt_20260115_143022_a3f9c2", "duplicate": false,
 "received_at": "2026-01-15T14:30:22.612+09:00",
 "clock_skew_ms": -131,
 "image_saved": "2026/01/15/evt_20260115_143022_a3f9c2.jpg"}

```

**★ 상태 코드 → 파이의 행동 (이 표가 계약의 핵심입니다)**

| 코드 | 의미 | 응답 예 | 파이의 행동 |
|---|---|---|---|
| **201** | 새로 저장 | `duplicate: false` | **큐에서 제거** |
| **200** | **중복** | `duplicate: true` | **큐에서 제거** (성공 취급) |
| **400** | 스키마 오류 | `invalid_event` | **재시도 무의미 → dead 로 이동 + 로그** |
| **401** | 인증 실패 | `unauthorized` | 재시도 중단 + **관리자 알림** |
| **413** | 이미지 초과 | `image_too_large` | **이미지 떼고 1회 재시도** |
| **415** | Content-Type 오류 | `unsupported_media_type` | dead 로 이동 |
| **429** | 과부하 | `rate_limited` + `Retry-After` | **헤더만큼 대기** 후 재시도 |
| **500** | 서버 내부 오류 | `internal_error` | 지수 백오프 재시도 |
| **503** | 서버 점검 | `unavailable` + `Retry-After` | 대기 후 재시도 |
| **타임아웃** | 응답 없음 | — | 지수 백오프 재시도 |
| **연결 실패** | DNS · 라우팅 | — | 지수 백오프 재시도 |

> ⚠️ **409 Conflict 를 쓰지 마세요.**
> "이미 있음"을 409 로 주면 파이는 **오류로 판단**합니다.
> → 큐에서 제거하지 않음 → **영원히 재시도** → 30초마다 같은 요청 → 로그 폭발.
> **중복은 "성공"입니다. 200 으로 주세요.**

### ★ 멱등성 — 두 번 보내도 한 번만 저장된다

```
왜 두 번 보내게 되는가

  ① 파이 → 서버 POST
  ② 서버가 DB INSERT 성공  ← 여기까지는 완벽
  ③ 서버가 201 응답 전송
  ④ ★ 그 순간 Wi-Fi 가 끊김 / 파이가 재부팅 / 타임아웃 5초 초과
  ⑤ 파이: "응답을 못 받았다 = 실패다" → 큐에 남김
  ⑥ 30초 뒤 재전송 → ⑦ 서버에는 이미 있음

파이는 ②가 성공했는지 알 수 없습니다
네트워크에서 "보냈는데 응답이 없다" 는 영원히 모호합니다
  (이것을 분산 시스템에서 "두 장군 문제" 라고 합니다)
```

**해결 — at-least-once 전송 + 멱등 수신**

```
파이:  최소 한 번은 보낸다 (at-least-once)
       → 확실치 않으면 또 보낸다 → 중복은 발생할 수 있다

서버:  같은 event_id 는 한 번만 저장한다 (idempotent)
       → 중복이 와도 200 으로 받아 준다 → DB 에는 1건

결과:  ★ exactly-once 와 같은 효과
```

**구현은 세 줄입니다**

```sql
CREATE TABLE events (
    event_id  TEXT PRIMARY KEY,      -- ★ 이 한 줄이 멱등성의 전부
    ...
);
```

```python
try:
    db.execute("INSERT INTO events (event_id, ...) VALUES (?, ...)", (...))
    db.commit()
    return jsonify({"ok": True, "duplicate": False}), 201
except sqlite3.IntegrityError:            # UNIQUE 위반 = 중복
    return jsonify({"ok": True, "duplicate": True}), 200
```

> ⚠️ **`SELECT` 로 먼저 확인하고 `INSERT` 하지 마세요.**
> 파이가 재시도로 **동시에 두 번** 보내면 두 요청이 모두 SELECT 를 통과합니다.
> **`PRIMARY KEY` 제약에 맡기세요. DB 가 원자적으로 처리합니다.**

**중복 요청의 이미지는 어떻게 하나**

```
① 이미지도 다시 저장  →  디스크 낭비 · 파일명 충돌
② 이미지를 무시       →  ★ 채택
③ sha256 비교 후 갱신 →  복잡. 이벤트는 불변이므로 불필요

단, 기존 레코드에 이미지가 없고 이번에 왔다면 보완 저장합니다 (Step 4)
```

### ★ 시계 동기화 — 시각이 다르면 이력이 뒤섞입니다

**라즈베리파이에는 RTC(실시간 시계) 배터리가 없습니다.**

```
전원을 뽑았다 꽂으면
  ① 부팅 → 시각 = 마지막 종료 시각 (또는 1970-01-01)
  ② 네트워크 연결
  ③ NTP 동기화       ← ★ 여기까지 5~30초
  ④ 시각이 갑자기 점프
  ②~③ 사이에 이벤트가 나면 ts 가 엉망입니다

이력 페이지 (ts 내림차순)
  2026-01-15 14:32:10   person 1     ← 정상
  1970-01-01 09:00:03   person 3     ← 맨 뒤에 처박힘
사용자: "방금 지나갔는데 왜 기록이 없죠?"
```

**★ 해결 3단 — 셋을 다 합니다**

```
[1] 파이에서 NTP 를 확실히 켠다
[2] 서버가 수신 시각(received_at)을 함께 기록한다
[3] 왕복 측정으로 시계 차이(skew)를 계산해 로그에 남긴다
```

**[1] 파이 NTP**

```bash
timedatectl status
#   System clock synchronized: yes        ← 이게 yes 여야 함

sudo timedatectl set-ntp true
sudo timedatectl set-timezone Asia/Seoul

# systemd unit 에서 서비스 시작을 시각 동기화 이후로 미루기
#   [Unit]
#   After=network-online.target time-sync.target
```

에이전트는 시작할 때 `datetime.now().year < 2024` 와 `timedatectl show -p
NTPSynchronized` 로 **자기 시계를 스스로 의심**합니다(확인 실패로 죽지는 않습니다).

**[2] 서버가 수신 시각을 병기**

```sql
CREATE TABLE events (
    event_id      TEXT PRIMARY KEY,
    ts            TEXT NOT NULL,      -- 파이가 주장하는 시각
    received_at   TEXT NOT NULL,      -- ★ 서버가 받은 시각 (신뢰 가능)
    clock_skew_ms INTEGER,            -- 둘의 차이
    ...
);
```

```
무엇을 화면에 쓰나
  이력 정렬       →  received_at  (서버 기준 — 절대 뒤섞이지 않음)
  "언제 일어났나" →  ts             (현장 기준)
  차이가 크면     →  화면에 경고 배지 "시계 오차 5.2s"
```

**[3] ★ 왕복 측정 (NTP 의 축소판)**

```
파이                                    서버
 │  t1 = 송신 시각                       │
 ├──────────── POST ───────────────────→│  t2 = 수신 시각
 │←─────────── 응답 ─────────────────────┤  t3 = 응답 송신 시각
 │  t4 = 수신 시각                       │

  왕복 시간   rtt    = (t4 - t1) - (t3 - t2)
  시계 차이 offset = ((t2 - t1) + (t3 - t4)) / 2
  → 네트워크 지연이 양방향 대칭이라고 가정. 오차는 대략 rtt/2 이내
```

`pi/clock_sync.py` 는 서버의 `GET /api/time`(Step 4)을 **7회 호출해
offset·rtt 의 중앙값**을 냅니다.

실행 결과:

```
$ python -m pi.clock_sync --server http://192.168.0.10:8000
  샘플 7회
  ★ offset  -131.4 ms   (파이 시계가 서버보다 131 ms 빠름)
     rtt       18.2 ms
     spread     4.9 ms   ← 흔들림이 작아야 신뢰 가능
  판정: 오차 131 ms < 1,000 ms  → 정상
```

> ⚠️ **offset 이 크다고 프로그램이 파이 시계를 고치지 마세요.**
> `date -s` 로 시각을 강제로 바꾸면 **`time.time()` 이 뒤로 점프**해
> 타이머·쿨다운·백오프가 전부 꼬입니다.
> **NTP 에 맡기고, 우리는 "기록하고 경고"만 합니다.**

```python

event["ts_monotonic_ms"] = int(time.monotonic() * 1000)     # 절대 뒤로 안 감
```

```
time.time()      — 벽시계. NTP 가 고치면 점프한다
time.monotonic() — 부팅 후 경과. ★ 절대 뒤로 가지 않는다

  이벤트 간격 계산 · 백오프 타이머  →  monotonic
  "언제 일어났나" 표시              →  time
```

### 인증 — 로컬망이라도 최소한의 구분이 필요합니다

```python
import hmac
from functools import wraps

from flask import current_app, jsonify, request


def require_device(fn):
    """★ 디바이스 토큰 검사 데코레이터"""

    @wraps(fn)
    def wrapper(*args, **kwargs):
        did = request.headers.get("X-Device-Id", "")
        tok = request.headers.get("X-Device-Token", "")
        expected = current_app.config["DEVICE_TOKENS"].get(did)
        # compare_digest — 타이밍 공격 방지
        if not expected or not tok or not hmac.compare_digest(tok, expected):
            current_app.logger.warning("인증 실패 device=%r ip=%s",
                                       did, request.remote_addr)
            return jsonify({"ok": False, "error": "unauthorized"}), 401
        request.device_id = did
        return fn(*args, **kwargs)

    return wrapper
```

```python
"""pi/imaging.py — ★ 목표 크기에 맞춰 인코딩"""
import cv2


def encode_jpeg(frame, max_w=1280, quality=80,
                target_kb=300, min_quality=55):
    """리사이즈 → 인코딩 → 너무 크면 품질을 낮춰 재시도"""
    h, w = frame.shape[:2]
    if w > max_w:
        scale = max_w / w
        frame = cv2.resize(frame, (max_w, int(h * scale)),
                           interpolation=cv2.INTER_AREA)

    q = quality
    for _ in range(4):
        ok, buf = cv2.imencode(".jpg", frame,
                               [cv2.IMWRITE_JPEG_QUALITY, q])
        if not ok:
            raise RuntimeError("JPEG 인코딩 실패")
        data = buf.tobytes()
        if len(data) <= target_kb * 1024 or q <= min_quality:
            return data, {"w": frame.shape[1], "h": frame.shape[0],
                          "quality": q, "bytes": len(data)}
        q -= 5                                       # 품질 하향
    return data, {"w": frame.shape[1], "h": frame.shape[0],
                  "quality": q, "bytes": len(data)}


def make_thumbnail(frame, max_w=640, quality=70):
    """큐가 밀렸을 때 쓰는 저용량 버전"""
    return encode_jpeg(frame, max_w=max_w, quality=quality,
                       target_kb=60, min_quality=45)
```

```
  서버가 죽어 있는 10분 동안 → 20번 시도 → 20번 실패
  → 로그 20줄 · CPU · 네트워크 낭비
  → 서버가 살아나는 순간 모든 파이가 동시에 몰려듦 (thundering herd)

★ 지수 백오프
  5s → 10s → 20s → 40s → 80s → 160s → 300s → 300s ...
  → 10분 동안 7번만 시도 · 지터(jitter)를 섞으면 파이들이 흩어짐
```

```python
def backoff_delay(attempts, base=5.0, factor=2.0, cap=300.0, jitter=0.2):
    """지수 백오프 + 지터 — 1→5초, 2→10, 3→20, ... 7 이상 → 300초"""
    delay = min(base * (factor ** max(0, attempts - 1)), cap)
    return delay * (1 + random.uniform(-jitter, jitter))   # ±20% 흔들기
```

| 시도 | 계산 | 지연 | 누적 대기 |
|---|---|---|---|
| 1 | 5 × 2⁰ | 5초 | 5초 |
| 2 | 5 × 2¹ | 10초 | 15초 |
| 3 | 5 × 2² | 20초 | 35초 |
| 4 | 5 × 2³ | 40초 | 1분 15초 |
| 5 | 5 × 2⁴ | 80초 | 2분 35초 |
| 6 | 5 × 2⁵ | 160초 | 5분 15초 |
| 7 | 5 × 2⁶ → cap | **300초** | 10분 15초 |
| 8+ | cap | 300초 | 5분마다 |

```
cap(상한) 이 왜 필요한가
  상한이 없으면 10회째에 2,560초(42분)
  → 서버가 살아나도 42분 동안 아무 일도 안 함 → ★ 5분이면 충분합니다
```

### 큐 보관 정책 — 무한히 쌓을 수는 없습니다

```
서버가 3일간 죽어 있으면?   20건/일 × 3일 = 60건 × 110 KB = 6.6 MB   괜찮습니다
서버가 30일간 죽어 있으면?  600건 × 110 KB = 66 MB                    아직 괜찮습니다
트리거가 오작동해 1분에 10건씩 쌓이면?
  14,400건/일 × 110 KB = ★ 1.58 GB/일  →  3일이면 microSD 가 찹니다
```

**★ 3단 방어**

| 단계 | 조건 | 동작 |
|---|---|---|
| **1단 — 강등** | 대기 50건 초과 | 새 이벤트의 이미지를 **썸네일**로 (110 KB → 32 KB) |
| **2단 — 이미지 폐기** | 대기 200건 초과 | 오래된 것부터 **이미지만 삭제**, 메타는 유지 |
| **3단 — 완전 폐기** | 대기 2,000건 또는 7일 경과 | 오래된 것부터 **행 삭제** + `dropped` 카운터 증가 |

```
왜 "이미지만 먼저" 버리나
  이벤트 메타 1.2 KB  vs  이미지 110 KB   → 92배 차이
  "14:30 에 사람 2명" 이라는 사실은 1.2 KB 면 보존됩니다

MAX_PENDING = 2_000 · MAX_AGE_DAYS = 7 · DEGRADE_AT = 50 · DROP_IMAGE_AT = 200
```

> ⚠️ **폐기는 반드시 로그와 카운터로 남기세요.**
> 조용히 버리면 나중에 "왜 이벤트 수가 안 맞지?" 를 **영원히 못 찾습니다.**
> `dropped_total` 을 `/api/health` 로 노출하면 웹에서 바로 보입니다.

### 순서 보장과 중복 — at-least-once 의 대가

```
큐를 비울 때 20건을 한꺼번에 처리하면
  evt_...143022  전송 성공
  evt_...143045  전송 실패 (일시적)
  evt_...143101  전송 성공
  → 서버 도착 순서: 143022, 143101, ..., (나중에) 143045
  → ★ 순서가 뒤집힙니다

✗ 순서에 의존하는 설계
  "box_appeared 다음에 box_removed 가 오면 택배 회수" → 뒤집히면 오작동
✓ 순서에 의존하지 않는 설계
  각 이벤트에 ts 가 있으므로 서버는 ts 로 정렬해서 해석합니다
  → 도착 순서가 어떻든 결과가 같습니다
```

| 보장 수준 | 의미 | 구현 비용 | 우리 선택 |
|---|---|---|---|
| at-most-once | 중복 없음, 유실 가능 | 낮음 | ✗ CCTV 에 부적합 |
| **at-least-once** | **유실 없음**, 중복 가능 | 보통 | **채택** |
| exactly-once | 유실·중복 없음 | 매우 높음 | ✗ 분산 트랜잭션 필요 |

```
★ at-least-once + 멱등 수신 = 실질적 exactly-once
  파이:  "확실치 않으면 또 보낸다"
  서버:  "같은 ID 는 한 번만 저장한다"
  결과:  DB 에는 정확히 한 건
```

### 지연시간 — 어디부터 어디까지가 "지연"인가

```
★ 지연의 정의부터 합의해야 합니다
  "사람이 화각에 진입한 순간"부터 "웹 화면에 그 사건이 보이는 순간"까지

  T0  사람이 화각에 진입 (물리적 사건)
  T1  카메라가 그 프레임을 노출·전송 완료
  T2  파이가 프레임을 획득 (cap.read() 반환)
  T3  추론 완료 (detector.predict_image 반환)
  T4  이벤트 확정 (3프레임 연속 조건 충족)
  T5  서버가 DB 에 저장 완료 (201 응답)
  T6  브라우저 화면에 표시
```

| 구간 | 이름 | 구성 ① | 구성 ② | 측정 방법 |
|---|---|---|---|---|
| T0→T1 | 카메라 노출·전송 | 45 ms | 45 ms | 측정 불가 (카메라 스펙) |
| T1→T2 | 프레임 획득 | 22 ms | 22 ms | `read()` 앞뒤 `perf_counter` |
| T2→T3 | **추론** | **186 ms** | **9 ms** (서버 GPU) | `timing_ms.total` |
| — | JPEG 인코딩 | (이벤트 시만) | 18 ms | `imencode` 앞뒤 |
| — | **네트워크 전송** | 128 ms (이벤트 시) | **96 ms** (매 프레임) | 요청 앞뒤 |
| T3→T4 | 이벤트 판정 | 372 ms (2프레임) | 200 ms | 프레임 간격 × N |
| T4→T5 | 큐 적재 + 전송 + 저장 | 158 ms | 24 ms | 아래 |
| T5→T6 | **웹 표시** | 0~3,000 ms | 0~3,000 ms | 폴링 주기에 의존 |

> ⚠️ **T5→T6 (웹 표시) 가 가장 큽니다.**
> 웹 페이지가 5초마다 새로고침하면 **평균 2.5초**가 그냥 더해집니다.
> **아무리 추론을 최적화해도 여기서 다 까먹습니다.**
> [Day 170](day-170.md) 에서는 텔레그램 알림(300~800 ms)으로 이 구간을 우회합니다.

**★ 구간별 측정 방법 — 타임스탬프를 이벤트에 심습니다**

```python
marks = {}

def mark(name):
    marks[name] = time.perf_counter()

mark("t1"); frame = cam.read()
mark("t2"); result = detector.predict_image(frame)
mark("t3"); jpg, meta = encode_jpeg(frame)
mark("t3b"); event = build_event(result, meta)
mark("t4"); uploader.enqueue(event, jpg)
mark("t5")

def gap(a, b):
    return round((marks[b] - marks[a]) * 1000, 1)

# 이벤트에 심어서 서버로 보냄
event["timing_ms"] = {"capture": gap("t1", "t2"), "infer": gap("t2", "t3"),
                      "encode": gap("t3", "t3b"), "build": gap("t3b", "t4"),
                      "enqueue": gap("t4", "t5")}
```

**★ 아웃박스 본체**

```python
"""pi/uploader.py — ★ 네트워크가 끊겨도 이벤트를 잃지 않는 전송기

설계 원칙
  ① 이벤트 생성과 전송을 ★ 분리 (검출 루프는 절대 안 멈춘다)
  ② 큐는 ★ SQLite 파일 — 재부팅해도 살아남는다
  ③ 이미지는 ★ 파일로 따로 — 용량 압박 시 이미지만 먼저 버린다
  ④ at-least-once — 확실치 않으면 다시 보낸다
  ⑤ 4xx 는 재시도하지 않는다 (400/401/415)
"""
from __future__ import annotations

import json
import logging
import random
import sqlite3
import threading
import time
from pathlib import Path

import requests

logger = logging.getLogger(__name__)

SCHEMA = """
CREATE TABLE IF NOT EXISTS outbox (
    event_id   TEXT PRIMARY KEY,
    payload    TEXT    NOT NULL,
    image_name TEXT,
    attempts   INTEGER NOT NULL DEFAULT 0,
    next_try   REAL    NOT NULL DEFAULT 0,
    created    REAL    NOT NULL,
    last_error TEXT,
    state      TEXT    NOT NULL DEFAULT 'pending'   -- pending | dead
);
CREATE INDEX IF NOT EXISTS idx_outbox_ready ON outbox(state, next_try);
CREATE TABLE IF NOT EXISTS counters (
    name TEXT PRIMARY KEY, value INTEGER NOT NULL DEFAULT 0);
"""


class Uploader:
    """★ 아웃박스 패턴 전송기"""

    def __init__(self, base_url, device_id, token,
                 db_path="outbox.db", image_dir="outbox_images",
                 connect_timeout=3.05, read_timeout=10.0,
                 batch=20, poll_interval=2.0,
                 backoff_base=5.0, backoff_cap=300.0, backoff_jitter=0.2,
                 max_pending=2000, max_age_days=7,
                 degrade_at=50, drop_image_at=200):
        self.url = base_url.rstrip("/")
        self.db_path = str(db_path)
        self.image_dir = Path(image_dir)
        self.image_dir.mkdir(parents=True, exist_ok=True)
        self.timeout = (connect_timeout, read_timeout)
        self.batch, self.poll_interval = batch, poll_interval
        self.backoff_base, self.backoff_cap = backoff_base, backoff_cap
        self.backoff_jitter = backoff_jitter
        self.max_pending, self.max_age_sec = max_pending, max_age_days * 86400
        self.degrade_at, self.drop_image_at = degrade_at, drop_image_at

        # ★ 연결 재사용 — 매 요청 TCP 핸드셰이크를 피한다
        self.session = requests.Session()
        self.session.headers.update({"X-Device-Id": device_id,
                                     "X-Device-Token": token,
                                     "User-Agent": f"cctv-pi/{device_id}"})
        self._stop, self._wake = threading.Event(), threading.Event()
        self._thread = None
        self._init_db()

    # ────────────────── DB ──────────────────

    def _connect(self):
        db = sqlite3.connect(self.db_path, timeout=10.0)
        db.row_factory = sqlite3.Row
        db.execute("PRAGMA journal_mode=WAL")      # ★ 동시 읽기/쓰기
        db.execute("PRAGMA synchronous=NORMAL")    # ★ SD카드 수명 배려
        return db

    def _init_db(self):
        db = self._connect()
        try:
            db.executescript(SCHEMA)
            db.commit()
        finally:
            db.close()

    def _bump(self, db, name, delta=1):
        db.execute("INSERT INTO counters(name, value) VALUES(?, ?) "
                   "ON CONFLICT(name) DO UPDATE SET value = value + ?",
                   (name, delta, delta))

    # ────────────────── 적재 ──────────────────

    def enqueue(self, event, image_bytes=None, thumb_fn=None) -> str:
        """★ 큐에 넣고 즉시 반환한다 (전송은 워커가 한다)"""
        eid = event["event_id"]
        pending = self.pending_count()

        if image_bytes and pending >= self.degrade_at and thumb_fn:
            try:                                   # ★ 1단 방어: 강등
                image_bytes, _ = thumb_fn()
                event.setdefault("flags", []).append("degraded_thumbnail")
                logger.warning("큐 %d건 — 썸네일로 강등: %s", pending, eid)
            except Exception:
                logger.exception("썸네일 생성 실패 — 원본 유지")

        if image_bytes and pending >= self.drop_image_at:
            image_bytes = None                     # ★ 2단 방어: 이미지 폐기
            event.setdefault("flags", []).append("image_dropped")
            logger.warning("큐 %d건 — 이미지 폐기: %s", pending, eid)

        image_name = None
        if image_bytes:
            image_name = f"{eid}.jpg"
            (self.image_dir / image_name).write_bytes(image_bytes)

        db = self._connect()
        try:
            db.execute("INSERT OR IGNORE INTO outbox "
                       "(event_id, payload, image_name, created, next_try) "
                       "VALUES (?, ?, ?, ?, 0)",
                       (eid, json.dumps(event, ensure_ascii=False),
                        image_name, time.time()))
            self._bump(db, "enqueued")
            db.commit()
        finally:
            db.close()

        self._wake.set()                           # ★ 워커를 즉시 깨움
        logger.info("큐 적재 %s (대기 %d건)", eid, pending + 1)
        self._enforce_limits()
        return eid

    def _enforce_limits(self):
        """★ 3단 방어: 개수·나이 상한 초과 시 오래된 것부터 폐기"""
        db = self._connect()
        try:
            cutoff = time.time() - self.max_age_sec
            victims = {r["event_id"]: r["image_name"] for r in db.execute(
                "SELECT event_id, image_name FROM outbox WHERE created < ?",
                (cutoff,))}
            victims.update({r["event_id"]: r["image_name"] for r in db.execute(
                "SELECT event_id, image_name FROM outbox "
                "ORDER BY created DESC LIMIT -1 OFFSET ?", (self.max_pending,))})
            if not victims:
                return
            for eid, iname in victims.items():
                if iname:
                    (self.image_dir / iname).unlink(missing_ok=True)
                db.execute("DELETE FROM outbox WHERE event_id = ?", (eid,))
            self._bump(db, "dropped", len(victims))
            db.commit()
            logger.error("★ 큐 상한 초과 — %d건 폐기", len(victims))
        finally:
            db.close()

    def sweep_orphan_images(self) -> int:
        """★ DB 에 없는 이미지 파일 정리 (시작 시 1회)"""
        db = self._connect()
        try:
            known = {r[0] for r in db.execute(
                "SELECT image_name FROM outbox WHERE image_name IS NOT NULL")}
        finally:
            db.close()
        n = 0
        for p in self.image_dir.glob("*.jpg"):
            if p.name not in known:
                p.unlink(missing_ok=True)
                n += 1
        return n

    # ────────────────── 전송 ──────────────────

    def _backoff(self, attempts) -> float:
        d = min(self.backoff_base * (2 ** max(0, attempts - 1)), self.backoff_cap)
        return d * (1 + random.uniform(-self.backoff_jitter, self.backoff_jitter))

    def _post(self, row) -> tuple[str, str]:
        """한 건 전송 → ("ok" | "dead" | "retry" | "retry_no_image", 메시지)"""
        event = json.loads(row["payload"])
        files, fh = {}, None
        img = self.image_dir / row["image_name"] if row["image_name"] else None
        try:
            if img and img.exists():
                fh = open(img, "rb")
                files["image"] = (img.name, fh, "image/jpeg")
            r = self.session.post(
                f"{self.url}/api/events",
                data={"event": json.dumps(event, ensure_ascii=False)},
                files=files,
                headers={"X-Client-Sent-At": time.strftime("%Y-%m-%dT%H:%M:%S%z")},
                timeout=self.timeout)
        except requests.RequestException as e:
            return "retry", f"{type(e).__name__}: {e}"
        finally:
            if fh:
                fh.close()

        code = r.status_code
        if code in (200, 201):
            try:
                dup = " (중복)" if r.json().get("duplicate") else ""
            except ValueError:
                dup = ""
            return "ok", f"{code}{dup}"
        if code == 413:
            return "retry_no_image", "413 이미지 초과 → 이미지 제거 후 재시도"
        if code == 429:
            return "retry", f"429 rate_limited " \
                            f"(Retry-After={r.headers.get('Retry-After', '10')})"
        if 400 <= code < 500:
            return "dead", f"{code} {r.text[:180]}"   # ★ 다시 보내도 결과가 같다
        return "retry", f"{code} {r.text[:180]}"

    def flush_once(self) -> dict:
        """★ 지금 보낼 수 있는 것들을 한 번 비운다"""
        db = self._connect()
        try:
            rows = db.execute(
                "SELECT * FROM outbox WHERE state='pending' AND next_try <= ? "
                "ORDER BY created LIMIT ?", (time.time(), self.batch)).fetchall()
        finally:
            db.close()

        stat = {"tried": 0, "ok": 0, "retry": 0, "dead": 0}
        for row in rows:
            if self._stop.is_set():
                break
            stat["tried"] += 1
            result, msg = self._post(row)
            eid, iname = row["event_id"], row["image_name"]
            db = self._connect()
            try:
                if result == "ok":
                    if iname:
                        (self.image_dir / iname).unlink(missing_ok=True)
                    db.execute("DELETE FROM outbox WHERE event_id=?", (eid,))
                    self._bump(db, "sent")
                    stat["ok"] += 1
                    logger.info("전송 성공 %s — %s", eid, msg)
                elif result == "dead":
                    db.execute("UPDATE outbox SET state='dead', last_error=? "
                               "WHERE event_id=?", (msg, eid))
                    self._bump(db, "dead")
                    stat["dead"] += 1
                    logger.error("★ 전송 거부(재시도 안 함) %s — %s", eid, msg)
                elif result == "retry_no_image":
                    if iname:
                        (self.image_dir / iname).unlink(missing_ok=True)
                    db.execute("UPDATE outbox SET image_name=NULL, next_try=?, "
                               "last_error=? WHERE event_id=?",
                               (time.time(), msg, eid))
                    stat["retry"] += 1
                    logger.warning("%s — %s", eid, msg)
                else:                                    # retry
                    attempts = row["attempts"] + 1
                    delay = self._backoff(attempts)
                    db.execute("UPDATE outbox SET attempts=?, next_try=?, "
                               "last_error=? WHERE event_id=?",
                               (attempts, time.time() + delay, msg, eid))
                    stat["retry"] += 1
                    logger.warning("전송 실패 %s (%d회) %.0f초 뒤 재시도 — %s",
                                   eid, attempts, delay, msg)
                db.commit()
            finally:
                db.close()
        return stat

    # ────────────────── 워커 ──────────────────

    def _worker(self):
        logger.info("업로더 워커 시작 (서버 %s)", self.url)
        self._repair_clock_skew()
        while not self._stop.is_set():
            try:
                self.flush_once()
            except Exception:
                logger.exception("워커 오류 — 계속 진행")
            self._wake.wait(self.poll_interval)   # ★ 새 이벤트가 오면 즉시 깨어남
            self._wake.clear()
        logger.info("업로더 워커 종료")

    def _repair_clock_skew(self):
        """★ 시계가 뒤로 점프하면 next_try 가 미래에 박제된다 → 보정"""
        now = time.time()
        db = self._connect()
        try:
            n = db.execute("UPDATE outbox SET next_try=? WHERE next_try > ?",
                           (now, now + self.backoff_cap)).rowcount
            db.commit()
            if n:
                logger.warning("★ next_try 미래값 %d건 보정 (시계 점프 추정)", n)
        finally:
            db.close()

    def start(self):
        if self._thread and self._thread.is_alive():
            return
        self._stop.clear()
        self._thread = threading.Thread(target=self._worker, name="uploader",
                                        daemon=True)
        self._thread.start()

    def stop(self, timeout=5.0):
        self._stop.set()
        self._wake.set()
        if self._thread:
            self._thread.join(timeout)
        self.session.close()

    # ────────────────── 조회 ──────────────────

    def pending_count(self) -> int:
        db = self._connect()
        try:
            return db.execute("SELECT COUNT(*) FROM outbox "
                              "WHERE state='pending'").fetchone()[0]
        finally:
            db.close()

    def stats(self) -> dict:
        db = self._connect()
        try:
            pending = db.execute("SELECT COUNT(*) FROM outbox "
                                 "WHERE state='pending'").fetchone()[0]
            dead = db.execute("SELECT COUNT(*) FROM outbox "
                              "WHERE state='dead'").fetchone()[0]
            oldest = db.execute("SELECT MIN(created) FROM outbox "
                                "WHERE state='pending'").fetchone()[0]
            counters = {r["name"]: r["value"]
                        for r in db.execute("SELECT * FROM counters")}
        finally:
            db.close()
        img = sum(p.stat().st_size for p in self.image_dir.glob("*.jpg"))
        return {"pending": pending, "dead": dead,
                "oldest_age_sec": round(time.time() - oldest, 1) if oldest else None,
                "queue_images_mb": round(img / 1024 / 1024, 2), **counters}
```

### Step 2. `pi/agent.py` — 구성 ① (캡처 → 검출 → 이벤트 → 큐)

```python
"""pi/agent.py — ★ 구성 ① : 파이에서 추론하고 이벤트만 보낸다

  카메라 → 검출 → (N프레임 연속 + 쿨다운) → 이벤트 → ★ 큐 적재
                                                     ↓
                                        업로더 워커가 알아서 전송
"""
from __future__ import annotations

import argparse
import logging
import signal
import time
import uuid
from collections import defaultdict
from datetime import datetime
from hashlib import sha256

import cv2

from pi import config
from pi.imaging import encode_jpeg, make_thumbnail
from pi.uploader import Uploader
from src.detector import get_detector

logger = logging.getLogger("agent")
EVENT_TYPE = {"person": "person_detected", "box": "box_appeared",
              "helmet": "helmet_detected"}


class EventEngine:
    """★ N프레임 연속 + 쿨다운으로 이벤트를 확정한다"""

    def __init__(self, classes=config.EVENT_CLASSES,
                 consecutive=config.CONSECUTIVE_FRAMES,
                 cooldown=config.COOLDOWN_SEC, min_conf=0.35):
        self.classes = set(classes)
        self.consecutive, self.cooldown, self.min_conf = (
            consecutive, cooldown, min_conf)
        self.streak = defaultdict(int)          # 클래스별 연속 프레임
        self.last_fired = {}                    # 클래스별 마지막 발화 시각

    def update(self, result: dict) -> list[dict]:
        now = time.monotonic()                  # ★ 단조 시계
        present = defaultdict(float)
        for d in result.get("detections", []):
            name = d.get("class_name") or d.get("class")
            if name in self.classes and d["conf"] >= self.min_conf:
                present[name] = max(present[name], d["conf"])

        fired = []
        for name in self.classes:
            if name not in present:
                self.streak[name] = 0
                continue
            self.streak[name] += 1
            if self.streak[name] < self.consecutive:
                continue
            if now - self.last_fired.get(name, -1e9) < self.cooldown:
                continue                        # ★ 쿨다운 중
            self.last_fired[name] = now
            fired.append({"class": name,
                          "count": result.get("counts_by_class", {}).get(name, 1),
                          "conf": round(present[name], 4),
                          "streak": self.streak[name]})
        return fired


def build_event(hit, result, jpg, jpg_meta, timing):
    when = datetime.now().astimezone()
    eid = f"evt_{when.strftime('%Y%m%d_%H%M%S')}_{uuid.uuid4().hex[:6]}"
    event = {
        "schema": "cctv.event/1.1",
        "event_id": eid,
        "device_id": config.DEVICE_ID,
        "ts": when.isoformat(timespec="milliseconds"),
        "ts_monotonic_ms": int(time.monotonic() * 1000),
        "type": EVENT_TYPE.get(hit["class"], "object_detected"),
        "classes": {hit["class"]: hit["count"]},
        "max_conf": hit["conf"],
        "duration_frames": hit["streak"],
        "roi": "entrance",
        "detections": result.get("detections", [])[:10],      # ★ 상한
        "timing_ms": timing,
        "agent": {"version": config.AGENT_VERSION,
                  "model": result.get("model", {}).get("name",
                                                       "yolo11n-ncnn-640"),
                  "conf": config.DETECT_CONF, "iou": config.DETECT_IOU},
    }
    if jpg:
        event["image"] = {"name": f"{eid}.jpg", "w": jpg_meta["w"],
                          "h": jpg_meta["h"], "bytes": len(jpg),
                          "sha256": sha256(jpg).hexdigest()}
    return event


def run(show=False, max_seconds=None):
    problems = config.check()
    if problems:
        for p in problems:
            logger.error("설정 오류: %s", p)
        return 2

    detector = get_detector(profile="pi", conf=config.DETECT_CONF,
                            iou=config.DETECT_IOU)
    logger.info("모델 로드 완료")

    up = Uploader(config.SERVER_URL, config.DEVICE_ID, config.DEVICE_TOKEN,
                  db_path=config.OUTBOX_DB, image_dir=config.OUTBOX_IMAGES)
    up.sweep_orphan_images()
    up.start()

    engine = EventEngine()
    cap = cv2.VideoCapture(config.CAM_INDEX)
    cap.set(cv2.CAP_PROP_FRAME_WIDTH, config.CAM_W)
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, config.CAM_H)
    cap.set(cv2.CAP_PROP_FPS, config.CAM_FPS)
    cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)          # ★ 최신 프레임만
    if not cap.isOpened():
        logger.error("카메라를 열 수 없습니다 (index=%s)", config.CAM_INDEX)
        up.stop()
        return 3

    stop = {"flag": False}
    for sig in (signal.SIGINT, signal.SIGTERM):
        signal.signal(sig, lambda *_: stop.update(flag=True))

    started, frames, events = time.monotonic(), 0, 0
    try:
        while not stop["flag"]:
            if max_seconds and time.monotonic() - started > max_seconds:
                break

            t0 = time.perf_counter()
            ok, frame = cap.read()
            t1 = time.perf_counter()
            if not ok or frame is None:
                logger.warning("프레임 획득 실패 — 1초 뒤 재시도")
                time.sleep(1.0)
                continue

            try:
                result = detector.predict_image(frame)
            except Exception:
                logger.exception("추론 실패 — 이 프레임을 건너뜁니다")
                continue
            t2 = time.perf_counter()
            frames += 1

            for hit in engine.update(result):
                jpg, meta = encode_jpeg(frame)
                t3 = time.perf_counter()
                timing = {"capture": round((t1 - t0) * 1000, 1),
                          "infer": round((t2 - t1) * 1000, 1),
                          "encode": round((t3 - t2) * 1000, 1)}
                event = build_event(hit, result, jpg, meta, timing)
                t4 = time.perf_counter()
                up.enqueue(event, jpg,
                           thumb_fn=lambda f=frame: make_thumbnail(f))
                timing["enqueue"] = round((time.perf_counter() - t4) * 1000, 1)
                events += 1
                logger.info("★ 이벤트 %s %s×%d conf %.2f "
                            "(추론 %.0fms · 인코딩 %.0fms · 적재 %.1fms)",
                            event["event_id"], hit["class"], hit["count"],
                            hit["conf"], timing["infer"], timing["encode"],
                            timing["enqueue"])

            if show:
                cv2.imshow("agent", frame)
                if cv2.waitKey(1) & 0xFF == ord("q"):
                    break
    finally:
        cap.release()
        if show:
            cv2.destroyAllWindows()
        elapsed = time.monotonic() - started
        logger.info("정지 — %d프레임 %.1f초 (%.2f FPS) · 이벤트 %d건",
                    frames, elapsed, frames / max(elapsed, 1e-9), events)
        logger.info("큐 상태 %s", up.stats())
        up.stop()
    return 0


if __name__ == "__main__":
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)-7s %(name)s | %(message)s")
    ap = argparse.ArgumentParser()
    ap.add_argument("--show", action="store_true")
    ap.add_argument("--seconds", type=int, default=None)
    a = ap.parse_args()
    raise SystemExit(run(show=a.show, max_seconds=a.seconds))
```

### Step 3. `pi/streamer.py` — 구성 ② (프레임 전송만)

구성 ②의 파이는 **촬영 · 인코딩 · 전송만** 합니다. `agent.py` 와 결정적으로
다른 점은 **큐가 없다**는 것입니다 — 실패하면 그냥 버립니다(drop-on-fail).
3초 지난 프레임은 가치가 없기 때문입니다.

```python
"""pi/streamer.py — ★ 구성 ② : 파이는 촬영·인코딩·전송만 한다"""

class FrameStreamer:
    def __init__(self, base_url, device_id, token, fps=10,
                 width=640, quality=75):
        self.url = base_url.rstrip("/") + "/api/frames"
        self.fps, self.interval = fps, 1.0 / fps
        self.width, self.quality = width, quality
        self.timeout = (2.0, 4.0)              # 프레임은 오래 기다리지 않는다
        self.session = requests.Session()      # keep-alive 연결 풀
        self.session.headers.update({"X-Device-Id": device_id,
                                     "X-Device-Token": token})
        self.seq = self.sent = self.failed = self.bytes_sent = 0
        self.rtt = deque(maxlen=200)

    def send_frame(self, frame):
        jpg, meta = encode_jpeg(frame, max_w=self.width, quality=self.quality,
                                target_kb=120, min_quality=50)
        self.seq += 1
        t1 = time.perf_counter()
        try:
            r = self.session.post(
                self.url,
                data={"meta": json.dumps({"seq": self.seq, **meta})},
                files={"frame": (f"f{self.seq}.jpg", jpg, "image/jpeg")},
                timeout=self.timeout)
        except requests.RequestException:
            self.failed += 1
            return None                        # ★ 버린다. 큐에 안 넣는다
        self.rtt.append((time.perf_counter() - t1) * 1000)
        self.bytes_sent += len(jpg)
        if r.status_code != 200:
            self.failed += 1
            return None
        self.sent += 1
        return r.json()
```

전송 루프는 `agent.py` 와 같은 모양이되 **FPS 제한**(`next_at` 기준)을 두고,
밀렸을 때는 따라잡지 않고 현재 시각으로 리셋합니다.

> 복구된 뒤 **10분 전의 프레임을 뒤늦게 쏟아붓습니다.**
> **★ 실시간 데이터는 버리는 것이 정답입니다.**

|---|---|---|
| 실패 시 | **큐에 보관 → 재전송** | **즉시 폐기** |
| 데이터의 가치 | 시간이 지나도 유지 | 초 단위로 소멸 |
| 중복 | 서버가 막아야 함 | 무해 (seq 로 구분) |
| 유실 | **치명적** | 허용 (다음 프레임이 옴) |
| 저장 | SQLite + 파일 | 없음 |

> ⚠️ **`raw_json` 을 남기는 이유.**
> 파이가 v1.2 스키마로 새 필드를 보내기 시작했는데 서버가 아직 v1.1 이면,
> **파싱하지 못한 필드가 영원히 사라집니다.**

```python
"""web/events_api.py — ★ 파이가 보내는 이벤트를 받는 정식 엔드포인트"""
from __future__ import annotations

import json
import re
import time
from datetime import datetime
from hashlib import sha256
from pathlib import Path

from flask import Blueprint, current_app, jsonify, request

from .auth import require_device            # ★ ③에서 만든 데코레이터
from .db import get_db                      # Day 164 의 커넥션 헬퍼

bp = Blueprint("events_api", __name__)

EVENT_ID_RE = re.compile(r"^[A-Za-z0-9_\-]{8,64}$")
SUPPORTED_MAJOR = 1
MAX_IMAGE_BYTES = 2 * 1024 * 1024          # ★ 2 MB
ALLOWED_TYPES = {"person_detected", "box_appeared", "box_removed",
                 "helmet_detected", "helmet_missing", "object_detected"}
JPEG_MAGIC = b"\xff\xd8\xff"


class EventError(Exception):
    def __init__(self, message, field=None, code="invalid_event"):
        super().__init__(message)
        self.message, self.field, self.code = message, field, code


def parse_event(raw: str, device_id: str) -> dict:
    """★ 스키마 검증 — 여기를 통과하면 DB 에 넣어도 안전하다"""
    try:
        ev = json.loads(raw)
    except (TypeError, ValueError) as e:
        raise EventError(f"event 가 올바른 JSON 이 아닙니다: {e}", "event")
    if not isinstance(ev, dict):
        raise EventError("event 는 객체여야 합니다", "event")

    m = re.match(r"^cctv\.event/(\d+)\.(\d+)$", str(ev.get("schema", "")))
    if not m:
        raise EventError(f"알 수 없는 schema: {ev.get('schema')!r}", "schema")
    if int(m.group(1)) != SUPPORTED_MAJOR:                # ★ major 가 다르면 거부
        raise EventError(f"지원하지 않는 스키마 버전 (서버는 {SUPPORTED_MAJOR}.x)",
                         "schema", "unsupported_schema")

    eid = ev.get("event_id", "")
    if not isinstance(eid, str) or not EVENT_ID_RE.match(eid):
        raise EventError("event_id 는 영숫자·_·- 로 8~64자여야 합니다", "event_id")
    if ev.get("device_id") != device_id:                  # ★ 헤더와 본문 대조
        raise EventError(f"device_id 불일치 (헤더 {device_id!r} vs 본문 "
                         f"{ev.get('device_id')!r})", "device_id")
    try:
        ts = datetime.fromisoformat(str(ev.get("ts")))
    except (TypeError, ValueError):
        raise EventError(f"ts 형식 오류: {ev.get('ts')!r} (ISO 8601 필요)", "ts")
    if ts.tzinfo is None:
        raise EventError("ts 에 타임존이 없습니다", "ts")
    if ev.get("type") not in ALLOWED_TYPES:
        raise EventError(f"알 수 없는 type: {ev.get('type')!r}", "type")

    classes = ev.get("classes")
    if not isinstance(classes, dict) or not classes:
        raise EventError("classes 는 비어 있지 않은 객체여야 합니다", "classes")
    for k, v in classes.items():
        if not isinstance(v, int) or v < 0:
            raise EventError(f"classes[{k}] 는 0 이상의 정수여야 합니다", "classes")
    mc = ev.get("max_conf")
    if mc is not None and not (0.0 <= float(mc) <= 1.0):
        raise EventError("max_conf 는 0.0~1.0", "max_conf")

    ev["_ts_parsed"] = ts
    return ev


def validate_image(fs) -> bytes:
    """★ [Day 159](day-159.md) 의 검증을 이벤트 이미지에도 적용"""
    data = fs.read()
    fs.seek(0)
    if not data:
        raise EventError("빈 이미지입니다", "image", "empty_image")
    if len(data) > MAX_IMAGE_BYTES:
        raise EventError(f"이미지가 너무 큽니다 ({len(data)/1024/1024:.2f}MB, "
                         f"최대 {MAX_IMAGE_BYTES//1024//1024}MB)",
                         "image", "image_too_large")
    if not data.startswith(JPEG_MAGIC):
        raise EventError("JPEG 이 아닙니다", "image", "not_a_jpeg")
    return data


def save_event_image(data: bytes, event_id: str, ts: datetime) -> str:
    """★ 날짜별 폴더 — 한 폴더에 파일 수만 개는 느려집니다"""
    rel = Path(ts.strftime("%Y/%m/%d")) / f"{event_id}.jpg"
    path = Path(current_app.config["SNAPSHOT_DIR"]) / rel
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".jpg.part")
    tmp.write_bytes(data)
    tmp.replace(path)                       # ★ 원자적 교체
    return rel.as_posix()


@bp.post("/api/events")
@require_device
def receive_event():
    """★ 파이 → 서버 이벤트 수신 (멱등)"""
    received = datetime.now().astimezone()

    if "event" not in request.form:
        return jsonify({"ok": False, "error": "invalid_event",
                        "message": "event 필드가 없습니다", "field": "event"}), 400
    try:
        ev = parse_event(request.form["event"], request.device_id)
    except EventError as e:
        current_app.logger.warning("이벤트 거부 device=%s %s (%s)",
                                   request.device_id, e.message, e.field)
        return jsonify({"ok": False, "error": e.code,
                        "message": e.message, "field": e.field}), 400

    eid, ts = ev["event_id"], ev["_ts_parsed"]
    skew_ms = int((ts - received).total_seconds() * 1000)

    image_data = None
    fs = request.files.get("image")
    if fs is not None and fs.filename:
        try:
            image_data = validate_image(fs)
        except EventError as e:
            status = 413 if e.code == "image_too_large" else 400
            return jsonify({"ok": False, "error": e.code, "message": e.message,
                            "max_bytes": MAX_IMAGE_BYTES}), status
        declared = (ev.get("image") or {}).get("sha256")
        if declared and sha256(image_data).hexdigest() != declared:
            # ★ 거부하지는 않습니다 — 기록만 (전송 중 손상 추적용)
            current_app.logger.warning("★ 이미지 해시 불일치 %s", eid)

    db = get_db()
    try:
        row = db.execute("SELECT image_name, received_at FROM events "
                         "WHERE event_id = ?", (eid,)).fetchone()

        if row is not None:                              # ── ★ 중복 → 200 ──
            saved = row["image_name"]
            if not saved and image_data:                 # ★ 부분 복구
                saved = save_event_image(image_data, eid, ts)
                db.execute("UPDATE events SET image_name=?, image_bytes=?, "
                           "image_sha256=? WHERE event_id=?",
                           (saved, len(image_data),
                            sha256(image_data).hexdigest(), eid))
                db.commit()
                current_app.logger.info("중복 이벤트에 이미지 보완: %s", eid)
            current_app.logger.info("중복 이벤트 %s (device=%s)",
                                    eid, request.device_id)
            return jsonify({
                "ok": True, "event_id": eid, "duplicate": True,
                "received_at": received.isoformat(timespec="milliseconds"),
                "first_received_at": row["received_at"],
                "image_saved": saved}), 200

        image_name = save_event_image(image_data, eid, ts) if image_data else None
        db.execute("""
            INSERT INTO events
              (event_id, device_id, ts, received_at, clock_skew_ms, type,
               classes_json, max_conf, duration_frames, roi,
               image_name, image_bytes, image_sha256,
               detections_json, timing_json, agent_json, raw_json)
            VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)
        """, (eid, request.device_id,
              ts.isoformat(timespec="milliseconds"),
              received.isoformat(timespec="milliseconds"),
              skew_ms, ev["type"],
              json.dumps(ev["classes"], ensure_ascii=False),
              ev.get("max_conf"), ev.get("duration_frames"), ev.get("roi"),
              image_name, len(image_data) if image_data else None,
              sha256(image_data).hexdigest() if image_data else None,
              json.dumps(ev.get("detections", []), ensure_ascii=False),
              json.dumps(ev.get("timing_ms", {}), ensure_ascii=False),
              json.dumps(ev.get("agent", {}), ensure_ascii=False),
              request.form["event"]))
        db.execute("""
            INSERT INTO devices (device_id, last_seen, last_skew_ms,
                                 event_count, agent_version)
            VALUES (?,?,?,1,?)
            ON CONFLICT(device_id) DO UPDATE SET
              last_seen=excluded.last_seen, last_skew_ms=excluded.last_skew_ms,
              event_count=event_count+1, agent_version=excluded.agent_version
        """, (request.device_id, received.isoformat(timespec="seconds"),
              skew_ms, (ev.get("agent") or {}).get("version")))
        db.commit()
    except Exception:
        db.rollback()
        current_app.logger.exception("이벤트 저장 실패 %s", eid)
        return jsonify({"ok": False, "error": "internal_error"}), 500

    if abs(skew_ms) > 5000:
        current_app.logger.warning("★ 시계 오차 큼 device=%s skew=%dms",
                                   request.device_id, skew_ms)
    current_app.logger.info("이벤트 저장 %s device=%s type=%s img=%s skew=%dms",
                            eid, request.device_id, ev["type"],
                            image_name or "-", skew_ms)
    return jsonify({"ok": True, "event_id": eid, "duplicate": False,
                    "received_at": received.isoformat(timespec="milliseconds"),
                    "clock_skew_ms": skew_ms, "image_saved": image_name}), 201


@bp.get("/api/time")
def api_time():
    """★ 파이가 시계 차이를 재는 데 쓰는 엔드포인트"""
    recv = time.time()
    return jsonify({"recv_ts": recv, "send_ts": time.time()})


@bp.get("/api/devices")
def api_devices():
    """★ 어느 파이가 언제 마지막으로 보냈나 — 죽은 기기 발견용"""
    now = datetime.now().astimezone()
    items = []
    for r in get_db().execute("SELECT * FROM devices ORDER BY last_seen DESC"):
        try:
            age = (now - datetime.fromisoformat(r["last_seen"])
                   .astimezone()).total_seconds()
        except Exception:
            age = None
        items.append({"device_id": r["device_id"], "last_seen": r["last_seen"],
                      "age_sec": round(age, 1) if age is not None else None,
                      "alive": age is not None and age < 300,     # ★ 5분 기준
                      "event_count": r["event_count"],
                      "last_skew_ms": r["last_skew_ms"]})
    return jsonify({"count": len(items), "items": items})
```

| 항목 | 핵심 |

| 구성 ① 파이 추론 | **이벤트만 전송** · 오프라인 동작 · 하루 **2~10 MB** |
| 구성 ② 서버 추론 | 모든 프레임 전송 · 큰 모델 가능 · 하루 **42 GB** |
| 구성 ③ 하이브리드 | 움직임 시에만 · 평상시 대역폭 **27 bps** |
| 대역폭 계산 | `KB/프레임 × FPS × 86,400` — **반드시 먼저** |
| 카메라 10대 | ①은 선형 · ②는 **GPU 7대에서 포화** |
| 지연 | ②가 평균 빠름 · **①이 p95·p99 우수** |
| 전송 방식 | **HTTP POST multipart** (Flask 재사용·상태 코드) |
| `event_id` | **파이가 만든다** — 멱등성의 출발점 |
| 멱등성 | 같은 ID → **200 + `duplicate: true`** (409 ✗) |
| 구현 | `event_id TEXT PRIMARY KEY` + `IntegrityError` |
| 아웃박스 | SQLite 큐 — **재부팅해도 살아남음** |
| 적재 비용 | **3 ms** — 검출 루프가 안 멈춤 |
| 지수 백오프 | 5→10→20→40→80→160→**300초 상한** + 지터 |
| 4xx · 413 | 4xx 는 **재시도 안 함**(dead) · 413 은 **이미지 떼고 재전송** |
| 큐 상한 | 강등 50 → 이미지 폐기 200 → 완전 폐기 2,000·7일 |
| 프레임 vs 이벤트 | 프레임은 **버린다** · 이벤트는 **절대 안 버린다** |
| 시계 | `ts`(파이) + **`received_at`**(서버) + `clock_skew_ms` |
| 왕복 측정 | `offset = ((t2-t1)+(t3-t4))/2` |
| 인증 | `X-Device-Token` + **`hmac.compare_digest`** |
| 장애 주입 | 서버 10분 정지 → 큐 14건 → **유실 0 · 중복 0** |

**오늘 반드시 기억할 세 가지**

> ① **네트워크는 반드시 끊깁니다.** "가끔"이 아니라 "반드시"로 설계해야
> 이벤트를 잃지 않습니다. 아웃박스 큐 200줄이 그 값입니다.
> ② **at-least-once + 멱등 수신 = 실질적 exactly-once.**
> 파이는 확실치 않으면 또 보내고, 서버는 같은 `event_id` 를 한 번만 저장합니다.
> ③ **프레임은 버리고 이벤트는 지킵니다.** 실시간 데이터는 늦으면 가치가 없고,
> 사건 기록은 늦어도 가치가 그대로입니다. 이 차이가 큐의 유무를 결정합니다.
