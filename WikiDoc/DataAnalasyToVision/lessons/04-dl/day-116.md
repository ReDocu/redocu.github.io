같은 최종 MAE 4,874가 나와도, 학습 과정은 완전히 다를 수 있습니다.

```
[경우 B]  10에폭에서 이미 최저, 이후 계속 나빠짐 (과적합)

[경우 D]  아직 내려가는 중인데 에폭이 끝남 (학습 부족)
```

**A는 그대로 쓰면 되고, B는 조기 종료, C는 학습률 조정, D는 에폭 증가가 필요합니다.**

**숫자만 보면 넷을 구분할 수 없습니다.**

## ③ 개념 설명

### History 객체

```python
history = model.fit(X_train, y_train, validation_data=(X_val, y_val), epochs=100)
```

`fit()` 은 `History` 객체를 반환합니다.

```python
type(history)               # <class 'keras.callbacks.History'>
history.history             # dict
history.epoch               # [0, 1, 2, ..., 99]
history.params              # {'verbose': 0, 'epochs': 100, 'steps': 207}
history.model               # 학습된 모델 자체
```

**`history.history` 의 구조**

```python
{
    "loss":     [1.234, 0.876, 0.654, ...],      # 에폭마다 하나씩
    "mae":      [0.891, 0.712, 0.598, ...],
    "val_loss": [1.198, 0.834, 0.641, ...],
    "val_mae":  [0.874, 0.698, 0.587, ...],
}
```

| 키 | 의미 |
|---|---|
| `loss` | 학습셋 손실 (compile의 `loss`) |
| `val_loss` | 검증셋 손실 |
| `<metric>` | compile의 `metrics` 에 넣은 것 |
| `val_<metric>` | 그 지표의 검증셋 값 |
| `lr` | 학습률 (스케줄러를 쓴 경우) |

```python
list(history.history.keys())
# ['loss', 'mae', 'val_loss', 'val_mae']
```

> ⚠️ **`validation_data` 를 안 주면 `val_*` 키가 없습니다.**
> 함수를 만들 때 이 경우를 처리해야 합니다.

### 주의 — train loss와 val loss는 측정 시점이 다릅니다

```
train_loss : 에폭 "도중" 배치마다 계산한 값의 평균
             (앞쪽 배치는 아직 덜 학습된 가중치로 계산됨)
val_loss   : 에폭 "끝"에 최종 가중치로 한 번 계산
```

**그래서 초반에는 val_loss가 train_loss보다 낮게 나오는 것이 정상입니다.**

```
Epoch 1:  loss 2.418 - val_loss 1.204     ← val이 낮음. 이상하지 않음
Epoch 2:  loss 1.187 - val_loss 0.987
...
```

> **[Day 117](day-117.md)의 패턴 ⑤와 함께 기억하세요.**
> Dropout도 같은 방향으로 작용합니다. **둘 다 정상 현상입니다.**

### 축 스케일 — 언제 로그를 쓰는가

```python
ax.set_yscale("log")
```

| 상황 | 스케일 |
|---|---|
| 손실이 1.5 → 0.3 정도 변화 | **선형** (기본) |
| 손실이 1000 → 0.5 로 급감 | **로그** |
| 초기 몇 에폭의 급락 때문에 나머지가 안 보임 | **로그** |
| MSE 손실 (제곱이라 변화폭이 큼) | **로그가 유용한 경우 많음** |
| MAE 지표 | 대개 선형 |

**로그 스케일이 필요한 전형적 상황**

```
선형 스케일:
 loss
  1000│●
      │
      │
     0│ ●─────────────────────  ← 2에폭 이후가 전부 바닥에 붙어 안 보임
      └────────────────────────

로그 스케일:
 loss
  10³ │●
  10² │ ●
  10¹ │  ●●
  10⁰ │    ●●●●●
  10⁻¹│         ●●●●●●●●●●●●  ← 후반의 개선이 보임
      └────────────────────────
```

**대안 — 초반 몇 에폭을 잘라내기**

```python
skip = 5
ax.plot(range(skip, len(loss)), loss[skip:])
```

### 최적 에폭 표시

```python
best_epoch = int(np.argmin(history.history["val_loss"])) + 1
ax.axvline(best_epoch, color="green", linestyle="--")
```

**왜 중요한가**

| 최적 에폭 위치 | 의미 |
|---|---|
| **마지막 에폭 근처** | 아직 개선 중. **에폭을 늘려야 함** |
| 중간 (30~70%) | 정상. EarlyStopping이 잘 작동 |
| **매우 초반 (10% 이내)** | 학습률이 너무 크거나 모델이 과함 |

> **EarlyStopping의 `restore_best_weights=True` 를 썼다면**
> **최종 모델은 마지막 에폭이 아니라 최적 에폭의 가중치**입니다.
> **그래프에 이것을 표시하지 않으면 오해합니다.**

### Step 1. History 객체 들여다보기

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

SEED = 42
np.random.seed(SEED)
tf.random.set_seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

y_bins = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)

sc = StandardScaler().fit(X_train)
Xtr, Xva, Xte = sc.transform(X_train), sc.transform(X_val), sc.transform(X_test)


def build(units=(64, 32), dropout=0.0, lr=1e-3, seed=SEED):
    tf.random.set_seed(seed)
    m = keras.Sequential([layers.Input(shape=(Xtr.shape[1],))])
    for u in units:
        m.add(layers.Dense(u, activation="relu"))
        if dropout > 0:
            m.add(layers.Dropout(dropout))
    m.add(layers.Dense(1))
    m.compile(optimizer=keras.optimizers.Adam(lr), loss="mse", metrics=["mae"])
    return m


model = build()
history = model.fit(Xtr, y_train, validation_data=(Xva, y_val),
                    epochs=60, batch_size=64, verbose=0)

print("=" * 72)
print("History 객체 구조")
print("=" * 72)
print(f"타입          : {type(history).__name__}")
print(f"에폭 목록      : {history.epoch[:5]} ... {history.epoch[-3:]}  "
      f"(총 {len(history.epoch)}개)")
print(f"params        : {history.params}")
print(f"기록된 키      : {list(history.history.keys())}")
print("-" * 72)

hist_df = pd.DataFrame(history.history)
hist_df.index.name = "epoch"
print("\n[앞 5에폭]")
print(hist_df.head().round(4).to_string())
print("\n[뒤 5에폭]")
print(hist_df.tail().round(4).to_string())
print("=" * 72)

# ── 핵심 값들 ──
best_epoch = int(np.argmin(history.history["val_loss"]))
print(f"\n최적 에폭 (val_loss 최소) : {best_epoch + 1} / {len(history.epoch)}")
print(f"  그때 val_loss : {history.history['val_loss'][best_epoch]:.4f}")
print(f"  그때 val_mae  : {history.history['val_mae'][best_epoch]:.4f}")
print(f"마지막 에폭 val_loss      : {history.history['val_loss'][-1]:.4f}")
print(f"  차이 : {history.history['val_loss'][-1] - history.history['val_loss'][best_epoch]:+.4f}")

# ── 초반 val < train 현상 확인 ──
print(f"\n[초반 5에폭 — val이 train보다 낮은가]")
print(f"{'epoch':>6}{'loss':>10}{'val_loss':>12}{'차이':>10}")
print("-" * 40)
for i in range(5):
    d = history.history["val_loss"][i] - history.history["loss"][i]
    print(f"{i+1:>6}{history.history['loss'][i]:>10.4f}"
          f"{history.history['val_loss'][i]:>12.4f}{d:>+10.4f}")
print("-" * 40)
print("★ 초반에 val_loss가 더 낮은 것은 정상입니다.")
print("  train_loss는 에폭 '도중' 평균, val_loss는 에폭 '끝'에 측정하기 때문입니다.")

# ── DataFrame으로 저장 ──
hist_df.to_csv("dl_course/logs_day116_baseline.csv")
```

### Step 2. ★ `plot_history()` 함수 만들기 — 1차 버전

```python
import numpy as np
import matplotlib.pyplot as plt


def plot_history_v1(history, title=None):
    """가장 단순한 버전 — 손실과 지표를 2분할로"""
    h = history.history if hasattr(history, "history") else history

    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    # ── 왼쪽: 손실 ──
    ax = axes[0]
    ax.plot(h["loss"], label="train")
    if "val_loss" in h:
        ax.plot(h["val_loss"], label="validation")
    ax.set_xlabel("epoch"); ax.set_ylabel("loss")
    ax.set_title("Loss")
    ax.legend()

    # ── 오른쪽: 지표 ──
    metric_keys = [k for k in h if not k.startswith("val_") and k != "loss" and k != "lr"]
    if metric_keys:
        mk = metric_keys[0]
        ax = axes[1]
        ax.plot(h[mk], label="train")
        if f"val_{mk}" in h:
            ax.plot(h[f"val_{mk}"], label="validation")
        ax.set_xlabel("epoch"); ax.set_ylabel(mk)
        ax.set_title(mk.upper())
        ax.legend()

    if title:
        fig.suptitle(title, fontsize=13)
    fig.tight_layout()
    return fig
```

### Step 3. `plot_history()` 완성판

```python
from pathlib import Path

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt


def plot_history(history, title=None, skip=0, log_scale="auto",
                 metrics=None, save_path=None, figsize=None, show_lr=True):
    """학습 곡선을 그리는 재사용 함수

    Parameters
    ----------
    history : keras History / dict / DataFrame / csv 경로
    title   : 그래프 제목
    skip    : 앞의 몇 에폭을 건너뛸지 (초반 급락 제거)
    log_scale : "auto" | True | False — y축 로그 스케일
    metrics : 그릴 지표 목록. None이면 자동 탐지
    save_path : 저장 경로 (None이면 저장 안 함)
    show_lr : 학습률이 기록되어 있으면 함께 그릴지
    """
    # ── 입력 정규화 ──
    if hasattr(history, "history"):
        h = history.history
    elif isinstance(history, (str, Path)):
        h = pd.read_csv(history).drop(columns=["epoch"], errors="ignore").to_dict("list")
    elif isinstance(history, pd.DataFrame):
        h = history.to_dict("list")
    else:
        h = dict(history)

    # ── 그릴 항목 결정 ──
    if metrics is None:
        metrics = [k for k in h
                   if not k.startswith("val_") and k not in ("loss", "lr", "epoch")]
    panels = ["loss"] + list(metrics)
    has_lr = show_lr and "lr" in h
    n_panels = len(panels) + (1 if has_lr else 0)

    if figsize is None:
        figsize = (6.2 * n_panels, 4.8)
    fig, axes = plt.subplots(1, n_panels, figsize=figsize)
    if n_panels == 1:
        axes = [axes]

    epochs = np.arange(1, len(h["loss"]) + 1)
    sl = slice(skip, None)

    for ax, key in zip(axes, panels):
        tr = np.asarray(h[key], dtype=float)
        va = np.asarray(h.get(f"val_{key}", []), dtype=float)

        ax.plot(epochs[sl], tr[sl], linewidth=1.9, label="train", color="#1f77b4")
        if va.size:
            ax.plot(epochs[sl], va[sl], linewidth=1.9, label="validation",
                    color="#ff7f0e")

            # ── 최적 에폭 ──
            best = int(np.argmin(va))
            ax.axvline(best + 1, color="green", linestyle="--", alpha=0.75,
                       label=f"best ep {best+1}")
            ax.scatter([best + 1], [va[best]], s=90, color="green",
                       zorder=5, edgecolor="k", linewidth=0.6)
            ax.annotate(f"{va[best]:.4f}", (best + 1, va[best]),
                        xytext=(6, 8), textcoords="offset points",
                        fontsize=9, color="darkgreen", fontweight="bold")

            # ── 격차 음영 ──
            ax.fill_between(epochs[sl], tr[sl], va[sl], alpha=0.12, color="red")

            # ── 최종 값 ──
            ax.annotate(f"final {va[-1]:.4f}", (epochs[-1], va[-1]),
                        xytext=(-70, -14), textcoords="offset points",
                        fontsize=8.5, color="#cc5500")

        # ── 로그 스케일 자동 판단 ──
        use_log = log_scale
        if log_scale == "auto":
            vals = tr[sl][tr[sl] > 0]
            use_log = vals.size > 0 and (vals.max() / vals.min() > 50)
        if use_log:
            ax.set_yscale("log")

        ax.set_xlabel("epoch")
        ax.set_ylabel(key)
        ax.set_title(f"{key.upper()}" + (" (log scale)" if use_log else ""))
        ax.legend(fontsize=8.5)
        ax.grid(alpha=0.3)

    # ── 학습률 패널 ──
    if has_lr:
        ax = axes[-1]
        ax.plot(epochs[sl], np.asarray(h["lr"], dtype=float)[sl],
                linewidth=2, color="purple")
        ax.set_yscale("log")
        ax.set_xlabel("epoch"); ax.set_ylabel("learning rate")
        ax.set_title("LEARNING RATE")
        ax.grid(alpha=0.3)

    if title:
        fig.suptitle(title, fontsize=13, fontweight="bold")
    fig.tight_layout()

    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)
        fig.savefig(save_path, dpi=110, bbox_inches="tight")
    return fig


def summarize_history(history, name="model"):
    """곡선의 핵심 수치를 표 한 줄로"""
    h = history.history if hasattr(history, "history") else history
    tr = np.asarray(h["loss"], dtype=float)
    va = np.asarray(h.get("val_loss", h["loss"]), dtype=float)
    best = int(np.argmin(va))
    n = len(tr)

    return {
        "이름": name,
        "에폭수": n,
        "최적에폭": best + 1,
        "최적위치(%)": round((best + 1) / n * 100, 1),
        "best_val_loss": round(float(va[best]), 4),
        "final_val_loss": round(float(va[-1]), 4),
        "final_train_loss": round(float(tr[-1]), 4),
        "격차": round(float(va[-1] - tr[-1]), 4),
        "과적합후퇴": round(float(va[-1] - va[best]), 4),
    }
```

```python
import numpy as np
```

```python
def plot_histories(histories, metric="val_loss", title=None, skip=0,
                   log_scale="auto", save_path=None, mark_best=True,
                   figsize=(13, 5.5)):
    """여러 실험의 곡선을 한 장에 겹쳐 그리기

    histories : {이름: History or dict}
    metric    : 그릴 키 ("val_loss", "val_mae" 등)
    """
    fig, axes = plt.subplots(1, 2, figsize=figsize)
    cmap = plt.cm.tab10

    rows = []
    for i, (name, hist) in enumerate(histories.items()):
        h = hist.history if hasattr(hist, "history") else hist
        if metric not in h:
            continue
        v = np.asarray(h[metric], dtype=float)
        ep = np.arange(1, len(v) + 1)
        color = cmap(i % 10)

        axes[0].plot(ep[skip:], v[skip:], linewidth=1.9, label=name, color=color)

        if mark_best:
            b = int(np.argmin(v))
            axes[0].scatter([b + 1], [v[b]], s=70, color=color,
                            edgecolor="k", zorder=5, linewidth=0.6)

        train_key = metric.replace("val_", "")
        tr = np.asarray(h.get(train_key, []), dtype=float)
        rows.append({
            "실험": name,
            "에폭": len(v),
            "최적에폭": int(np.argmin(v)) + 1,
            f"best_{metric}": round(float(v.min()), 4),
            f"final_{metric}": round(float(v[-1]), 4),
            "격차": round(float(v[-1] - tr[-1]), 4) if tr.size else np.nan,
        })

    ax = axes[0]
    use_log = log_scale
    if log_scale == "auto":
        allv = np.concatenate([np.asarray(
            (h.history if hasattr(h, "history") else h)[metric], dtype=float)
            for h in histories.values()])
        allv = allv[allv > 0]
        use_log = allv.size > 0 and allv.max() / allv.min() > 50
    if use_log:
        ax.set_yscale("log")

    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)

    return fig, df
```

```python
VIZ_MODULE = '''
"""학습 곡선 시각화 유틸 (Day 116)"""
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def _as_dict(history):
    """History / dict / DataFrame / csv 경로 → dict"""
    if hasattr(history, "history"):
        return history.history
    if isinstance(history, (str, Path)):
        return pd.read_csv(history).drop(columns=["epoch"], errors="ignore").to_dict("list")
    if isinstance(history, pd.DataFrame):
        return history.to_dict("list")
    return dict(history)


def plot_history(history, title=None, skip=0, log_scale="auto",
                 metrics=None, save_path=None, figsize=None, show_lr=True):
    """단일 실험의 학습 곡선. 최적 에폭·최종값·격차 음영 표시"""
    h = _as_dict(history)
    if metrics is None:
        metrics = [k for k in h
                   if not k.startswith("val_") and k not in ("loss", "lr", "epoch")]
    panels = ["loss"] + list(metrics)
    has_lr = show_lr and "lr" in h
    n = len(panels) + (1 if has_lr else 0)

    fig, axes = plt.subplots(1, n, figsize=figsize or (6.2 * n, 4.8))
    if n == 1:
        axes = [axes]
    epochs = np.arange(1, len(h["loss"]) + 1)
    sl = slice(skip, None)

    for ax, key in zip(axes, panels):
        tr = np.asarray(h[key], dtype=float)
        va = np.asarray(h.get(f"val_{key}", []), dtype=float)
        ax.plot(epochs[sl], tr[sl], linewidth=1.9, label="train", color="#1f77b4")
        if va.size:
            ax.plot(epochs[sl], va[sl], linewidth=1.9, label="validation", color="#ff7f0e")
            b = int(np.argmin(va))
            ax.axvline(b + 1, color="green", linestyle="--", alpha=0.75,
                       label=f"best ep {b+1}")
            ax.scatter([b + 1], [va[b]], s=90, color="green", zorder=5,
                       edgecolor="k", linewidth=0.6)
            ax.annotate(f"{va[b]:.4f}", (b + 1, va[b]), xytext=(6, 8),
                        textcoords="offset points", fontsize=9,
                        color="darkgreen", fontweight="bold")
            ax.fill_between(epochs[sl], tr[sl], va[sl], alpha=0.12, color="red")
        use_log = log_scale
        if log_scale == "auto":
            v = tr[sl][tr[sl] > 0]
            use_log = v.size > 0 and v.max() / v.min() > 50
        if use_log:
            ax.set_yscale("log")
        ax.set_xlabel("epoch"); ax.set_ylabel(key)
        ax.set_title(key.upper() + (" (log)" if use_log else ""))
        ax.legend(fontsize=8.5); ax.grid(alpha=0.3)

    if has_lr:
        ax = axes[-1]
        ax.plot(epochs[sl], np.asarray(h["lr"], dtype=float)[sl],
                linewidth=2, color="purple")
        ax.set_yscale("log"); ax.set_xlabel("epoch"); ax.set_ylabel("lr")
        ax.set_title("LEARNING RATE"); ax.grid(alpha=0.3)

    if title:
        fig.suptitle(title, fontsize=13, fontweight="bold")
    fig.tight_layout()
    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)
        fig.savefig(save_path, dpi=110, bbox_inches="tight")
    return fig


def plot_histories(histories, metric="val_loss", title=None, skip=0,
                   log_scale="auto", save_path=None, figsize=(13, 5.5)):
    """여러 실험 겹쳐 그리기 + 순위 막대"""
    fig, axes = plt.subplots(1, 2, figsize=figsize)
    cmap = plt.cm.tab10
    rows = []
    for i, (name, hist) in enumerate(histories.items()):
        h = _as_dict(hist)
        if metric not in h:
            continue
        v = np.asarray(h[metric], dtype=float)
        ep = np.arange(1, len(v) + 1)
        c = cmap(i % 10)
        axes[0].plot(ep[skip:], v[skip:], linewidth=1.9, label=name, color=c)
        b = int(np.argmin(v))
        axes[0].scatter([b + 1], [v[b]], s=70, color=c, edgecolor="k",
                        zorder=5, linewidth=0.6)
        tr = np.asarray(h.get(metric.replace("val_", ""), []), dtype=float)
        rows.append({"실험": name, "에폭": len(v), "최적에폭": b + 1,
                     f"best_{metric}": round(float(v.min()), 4),
                     f"final_{metric}": round(float(v[-1]), 4),
                     "격차": round(float(v[-1] - tr[-1]), 4) if tr.size else np.nan})

    ax = axes[0]
    if log_scale is True:
        ax.set_yscale("log")
    ax.set_xlabel("epoch"); ax.set_ylabel(metric)
    ax.set_title(f"{metric} across experiments")
    ax.legend(fontsize=8.5); ax.grid(alpha=0.3)

    df = pd.DataFrame(rows).sort_values(f"best_{metric}")
    ax = axes[1]
    colors = [cmap(list(histories).index(n) % 10) for n in df["실험"]]
    ax.barh(range(len(df)), df[f"best_{metric}"], color=colors, edgecolor="black")
    ax.set_yticks(range(len(df))); ax.set_yticklabels(df["실험"], fontsize=9)
    ax.invert_yaxis(); ax.set_xlabel(f"best {metric}"); ax.set_title("Ranking")
    for i, v in enumerate(df[f"best_{metric}"]):
        ax.text(v, i, f" {v:.4f}", va="center", fontsize=8.5)

    if title:
        fig.suptitle(title, fontsize=13, fontweight="bold")
    fig.tight_layout()
    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)
        fig.savefig(save_path, dpi=110, bbox_inches="tight")
    return fig, df


def summarize_history(history, name="model"):
    """곡선의 핵심 수치 한 줄"""
    h = _as_dict(history)
    tr = np.asarray(h["loss"], dtype=float)
    va = np.asarray(h.get("val_loss", h["loss"]), dtype=float)
    b = int(np.argmin(va)); n = len(tr)
    return {"이름": name, "에폭수": n, "최적에폭": b + 1,
            "최적위치(%)": round((b + 1) / n * 100, 1),
            "best_val_loss": round(float(va[b]), 4),
            "final_val_loss": round(float(va[-1]), 4),
            "final_train_loss": round(float(tr[-1]), 4),
            "격차": round(float(va[-1] - tr[-1]), 4),
            "과적합후퇴": round(float(va[-1] - va[b]), 4)}


def diagnose(summary_row, gap_threshold=0.05):
    """요약 한 줄 → 진단 문자열 (Day 117에서 확장)"""
    notes = []
    if summary_row["최적위치(%)"] > 90:
        notes.append("에폭 부족 가능 — 늘려 볼 것")
    if summary_row["최적위치(%)"] < 20:
        notes.append("너무 빨리 최적 — 학습률 과다 의심")
    if summary_row["격차"] > gap_threshold:
        notes.append("과적합 — 규제 추가")
    if summary_row["격차"] < -0.01:
        notes.append("val < train — 규제가 걸린 정상 상태")
    if summary_row["과적합후퇴"] > 0.02:
        notes.append("최적 이후 악화 — EarlyStopping 필요")
    return " · ".join(notes) if notes else "안정적"
'''
```

```python
def plot_seed_band(histories_by_seed, metric="val_loss", label=None, ax=None):
    """같은 설정을 seed 여러 개로 돌린 결과를 밴드로"""
    arrs = [np.asarray(_as_dict(h)[metric], dtype=float)
            for h in histories_by_seed]
    n = min(len(a) for a in arrs)
    M = np.stack([a[:n] for a in arrs])
    ep = np.arange(1, n + 1)
    mean, lo, hi = M.mean(0), M.min(0), M.max(0)

    ax = ax or plt.gca()
    ax.plot(ep, mean, linewidth=2.2, label=f"{label} (mean of {len(arrs)})")
    ax.fill_between(ep, lo, hi, alpha=0.2)
    return ax
```

```python
def diagnose(s, gap_threshold=0.05):
    notes, actions = [], []

    if s["최적위치(%)"] > 90:
        notes.append("에폭 부족 가능")
        actions.append("epochs를 2~3배로 늘리기")
    if s["최적위치(%)"] < 20:
        notes.append("너무 빨리 최적")
        actions.append("학습률을 1/5~1/10로")
    if s["격차"] > gap_threshold:
        notes.append("과적합")
        actions.append("Dropout 0.2 추가 또는 모델 축소")
    if s["격차"] < -0.01:
        notes.append("val < train (정상)")
    if s["과적합후퇴"] > 0.02:
        notes.append("최적 이후 악화")
        actions.append("EarlyStopping(patience=15) 적용")
    if s["final_train_loss"] > 0.5 and s["격차"] < 0.01:
        notes.append("★ 과소적합")
        actions.append("모델 키우기 또는 특성 추가")

    return {
        "진단": " · ".join(notes) if notes else "안정적",
        "다음 조치": " → ".join(actions) if actions else "현 설정 유지",
    }
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `History` 객체 | `fit()` 의 반환값. `history.history` 가 dict |
| 기록되는 키 | `loss` · 지표 · `val_*` · (`lr` — 스케줄러 사용 시) |
| `val_loss` 없음 | **`validation_data` 를 안 준 것** |
| 초반 val < train | **정상.** train은 에폭 도중 평균, val은 에폭 끝 측정 |
| 로그 스케일 | 손실 변화 폭이 **50배 넘으면** 유용 |
| 초반 잘라내기 | `skip=` 로 후반을 자세히. 발표용 |
| **최적 에폭 표시** | EarlyStopping을 썼다면 **필수** |
| 최적위치(%) | **90% 초과 → 에폭 부족** · **20% 미만 → 학습률 과다** |
| 격차 | `final_val - final_train`. **양수 크면 과적합** |
| 과적합후퇴 | `final_val - best_val`. **크면 EarlyStopping 필요** |
| 여러 실험 비교 | **한 축에** 겹쳐 그리기. 각각 그리면 비교 불가 |
| 타깃 변환이 다르면 | **loss 높이를 비교하면 안 됨** (모양만 비교) |
| `CSVLogger` | 로그를 파일로. **노트북을 껐다 켜도 복원 가능** |
| `ReduceLROnPlateau` | **학습률 곡선도 함께 그리기** |
| 에폭 번호 | **1부터** 표시 (Keras 로그와 맞춤) |
| 그래프 저장 | `save_path=` 를 항상 지정 |
| 곡선의 목적 | **"그래서 다음에 무엇을 바꿀 것인가"** |
