## ② 왜 필요한가

W05에서 이런 상황을 반드시 만나게 됩니다.

```
공공데이터 CSV에서 읽은 '나이' 컬럼:  "25", "34", "미상", "41"
```

전부 **문자열**입니다. 이대로는 평균을 낼 수 없습니다. 숫자로 바꿔야 하는데, `"미상"` 은 바꿀 수 없습니다.
여기서 무슨 일이 일어나는지 모르면 `ValueError` 하나에 하루를 씁니다.

| 타입을 모르면 생기는 일 | 언제 터지나 |
|---|---|
| `"10" + 5` 를 하면 에러 | 오늘 |
| CSV 숫자 컬럼이 전부 문자열이라 집계가 안 됨 | W05 |
| DB에 넣을 때 컬럼 타입이 안 맞아 적재 실패 | W09 |
| 모델에 문자열을 넣어 학습이 통째로 실패 | W11 |

## ③ 개념 설명

### 변수 (variable)

**변수**는 값에 붙이는 이름표입니다.

```python
age = 25
```

이 한 줄은 "25라는 값에 `age` 라는 이름을 붙였다"는 뜻입니다.
`=` 는 "같다"가 아니라 **"넣는다(대입)"** 입니다. 같다는 `==` 로 씁니다 (Day 003).

```
   age  ──────▶  25
 (이름)         (값)
```

값은 언제든 바꿀 수 있습니다.

```python
age = 25
age = 30      # 이제 age는 30
```

### 변수 이름 규칙

| 규칙 | 좋은 예 | 나쁜 예 |
|---|---|---|
| 영문·숫자·`_` 만 사용 | `user_name` | `user-name` (하이픈 불가) |
| 숫자로 시작 불가 | `data1` | `1data` |
| 대소문자 구분 | `Age` 와 `age` 는 다른 변수 | — |
| 예약어 사용 불가 | `count` | `class`, `if`, `for` |
| 소문자+밑줄 (파이썬 관례) | `total_price` | `TotalPrice` |

> **왜 이름이 중요한가** — W06에서 여러분이 만들 패키지는 여러 파일로 나뉩니다.
> 3주 뒤의 내가 `a`, `b`, `tmp` 를 읽고 이해할 수 있을까요? 이름은 미래의 나에게 쓰는 메모입니다.

### 기본 자료형 4종

| 타입 | 이름 | 예 | 뜻 |
|---|---|---|---|
| `int` | 정수 | `25`, `-3`, `0` | 소수점 없는 수 |
| `float` | 실수 | `3.14`, `-0.5`, `2.0` | 소수점 있는 수 |
| `str` | 문자열 | `"안녕"`, `'25'` | 따옴표로 감싼 글자 |
| `bool` | 논리값 | `True`, `False` | 참/거짓 (첫 글자 대문자!) |

**`25` 와 `"25"` 는 완전히 다릅니다.** 전자는 숫자, 후자는 글자 두 개입니다.

```python
25 + 5      # 30   (덧셈)
"25" + "5"  # "255" (이어붙이기)
```

타입을 확인할 때는 `type()` 을 씁니다.

```python
type(25)      # <class 'int'>
type("25")    # <class 'str'>
```

### int와 float의 차이

```python
10 / 3      # 3.3333333333333335   ← 나눗셈 결과는 항상 float
10 // 3     # 3                    ← 몫만 (버림)
10 % 3      # 1                    ← 나머지
```

> **float의 함정** — `0.1 + 0.2` 는 `0.3` 이 아니라 `0.30000000000000004` 입니다.
> 컴퓨터가 소수를 2진수로 근사 저장하기 때문입니다. 돈 계산처럼 정확도가 중요하면 정수(원 단위)로 다룹니다.
> W11 이후 모델 성능 지표를 비교할 때도 이 오차 때문에 `==` 대신 "차이가 아주 작은가"로 비교합니다.

### 형변환 (type casting)

값의 타입을 바꾸는 것입니다.

| 함수 | 하는 일 | 예 |
|---|---|---|
| `int(x)` | 정수로 | `int("25")` → `25` |
| `float(x)` | 실수로 | `float("3.14")` → `3.14` |
| `str(x)` | 문자열로 | `str(25)` → `"25"` |
| `bool(x)` | 논리값으로 | `bool(0)` → `False` |

**실패할 수 있습니다.**

```python
int("25")      # 25      ✅
int("25.7")    # ValueError ❌  (소수점이 있는 문자열은 int로 못 감)
int("미상")     # ValueError ❌
float("25.7")  # 25.7    ✅
int(25.7)      # 25      ✅ (버림, 반올림 아님)
```

`int("25.7")` 이 안 되는 것은 자주 걸리는 함정입니다. `int(float("25.7"))` 로 두 번 거쳐야 합니다.

### 거짓으로 취급되는 값

`bool()` 로 바꿨을 때 `False` 가 되는 값들을 **falsy** 라고 합니다.

| falsy 값 | 설명 |
|---|---|
| `0`, `0.0` | 숫자 0 |
| `""` | 빈 문자열 |
| `[]`, `{}`, `()` | 빈 컨테이너 (Day 007–008) |
| `None` | 값 없음 |

나머지는 전부 `True` 입니다. `"0"` 은 **문자열이므로 True** 입니다. 이건 Day 004 조건문에서 사고를 냅니다.

### input()은 항상 문자열을 준다

```python
age = input("나이를 입력하세요: ")
```

사용자가 `25` 를 쳐도 `age` 에는 **문자열 `"25"`** 가 들어갑니다. 예외 없습니다.
그래서 계산하려면 반드시 형변환해야 합니다.

```python
age = int(input("나이를 입력하세요: "))
```

### f-string — 값을 문자열에 끼워 넣기

문자열 앞에 `f` 를 붙이고, 중괄호 `{}` 안에 변수를 씁니다.

```python
name = "홍길동"
age = 25
print(f"{name}님은 {age}살입니다.")
```

```
홍길동님은 25살입니다.
```

**서식 지정**도 됩니다. 이건 W05에서 리포트를 찍을 때 계속 씁니다.

| 서식 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `:.2f` | 소수점 2자리 | `f"{3.14159:.2f}"` | `3.14` |
| `:,` | 천 단위 쉼표 | `f"{1234567:,}"` | `1,234,567` |
| `:>10` | 오른쪽 정렬 폭 10 | `f"{'가':>10}"` | `         가` |
| `:<10` | 왼쪽 정렬 폭 10 | `f"{'가':<10}"` | `가         ` |
| `:.1%` | 백분율 1자리 | `f"{0.8543:.1%}"` | `85.4%` |

마지막 `:.1%` 는 W12에서 모델 정확도를 출력할 때 그대로 씁니다.

## ⑤ 자주 하는 실수

### `TypeError: can only concatenate str (not "int") to str`

```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    print("나이: " + age)
TypeError: can only concatenate str (not "int") to str
```

**원인** — 문자열과 숫자를 `+` 로 이으려 했습니다. 파이썬은 이걸 허용하지 않습니다.
**해결** — 셋 중 하나를 쓰세요.

```python
print("나이: " + str(age))   # 형변환
print("나이:", age)          # 쉼표로 나열 (자동으로 공백 하나 들어감)
print(f"나이: {age}")        # f-string ← 권장
```

### `ValueError: invalid literal for int() with base 10: '25.7'`

```
Traceback (most recent call last):
  File "test.py", line 1, in <module>
    age = int("25.7")
ValueError: invalid literal for int() with base 10: '25.7'
```

**원인** — `int()` 는 소수점이 들어간 문자열을 받지 못합니다.
**해결** — `int(float("25.7"))` 처럼 두 단계로 변환하거나, 애초에 `float()` 을 씁니다.

같은 에러가 빈 문자열에서도 납니다.

```
ValueError: invalid literal for int() with base 10: ''
```

사용자가 아무것도 입력하지 않고 엔터를 쳤을 때입니다. Day 009에서 `try/except` 로 막습니다.

### `NameError: name 'age' is not defined`

```
Traceback (most recent call last):
  File "test.py", line 1, in <module>
    print(age)
NameError: name 'age' is not defined
```

**원인** — ① 변수를 만들기 전에 썼거나 ② 이름을 오타 냈습니다 (`Age` vs `age`).
**해결** — 변수는 반드시 **쓰기 전에 먼저 대입**해야 합니다. 대소문자도 정확히 맞추세요.

### `SyntaxError: invalid syntax` — True/False 대소문자

```python
is_student = true
```

```
NameError: name 'true' is not defined
```

**원인** — 파이썬의 논리값은 `True` · `False` 로 **첫 글자가 대문자**입니다. JavaScript·Java와 다릅니다.
**해결** — `True`, `False` 로 고칩니다.

### `SyntaxError: cannot assign to literal`

```python
25 = age
```

```
SyntaxError: cannot assign to literal here. Maybe you meant '==' instead of '='?
```

**원인** — 대입 방향이 반대입니다. **왼쪽이 이름, 오른쪽이 값**입니다.
**해결** — `age = 25`.

### f-string 앞에 `f` 를 빼먹음

```python
print("{name}님 안녕하세요")
```

```
{name}님 안녕하세요
```

**원인** — 에러는 안 나지만 중괄호가 그대로 출력됩니다. 조용히 틀리는 실수라 더 위험합니다.
**해결** — 문자열 앞에 `f` 를 붙입니다. `print(f"{name}님 안녕하세요")`.

## ⑥ 확인 문제

**1.** 아래 코드의 출력은 무엇일까요? 그리고 왜 그런가요?

```python
a = "10"
b = 3
print(a * b)
```

<details>
<summary>답 보기</summary>

```
101010
```

`a` 는 문자열 `"10"` 입니다. **문자열 × 정수**는 곱셈이 아니라 **반복**입니다.
`"10"` 을 3번 이어붙여 `"101010"` 이 됩니다.

숫자 30을 얻으려면 `int(a) * b` 로 형변환해야 합니다.
CSV에서 읽은 숫자가 문자열이라는 사실을 잊으면 W05에서 정확히 이 사고가 납니다.
</details>

**2.** 사용자에게 나이를 입력받아 10년 뒤 나이를 출력하려 합니다. 아래 코드는 왜 실패하나요?

```python
age = input("나이: ")
print(age + 10)
```

<details>
<summary>답 보기</summary>

`input()` 은 **항상 문자열을 돌려줍니다.** 사용자가 `25` 를 쳐도 `age` 에는 `"25"` 가 들어갑니다.
문자열 `"25"` 와 정수 `10` 을 `+` 로 더할 수 없으므로 `TypeError: can only concatenate str (not "int") to str` 이 납니다.

고치는 방법:

```python
age = int(input("나이: "))
print(age + 10)
```

또는

```python
age = input("나이: ")
print(int(age) + 10)
```
</details>

**3.** 아래 값들을 `bool()` 로 변환하면 각각 무엇이 될까요? 그리고 `"0"` 이 헷갈리는 이유는 무엇인가요?

```python
bool(0)     bool("")     bool("0")     bool(0.0)     bool(" ")
```

<details>
<summary>답 보기</summary>

| 값 | 결과 | 이유 |
|---|---|---|
| `bool(0)` | `False` | 숫자 0은 falsy |
| `bool("")` | `False` | 빈 문자열은 falsy |
| `bool("0")` | **`True`** | **비어 있지 않은 문자열**이므로 truthy |
| `bool(0.0)` | `False` | 실수 0도 falsy |
| `bool(" ")` | **`True`** | 공백 한 칸도 글자이므로 비어 있지 않음 |

`"0"` 이 `True` 인 이유는 파이썬이 **"내용이 0인가"가 아니라 "비어 있는가"** 를 보기 때문입니다.
CSV에서 읽은 값은 전부 문자열이므로, `"0"` 을 그대로 조건문에 넣으면 항상 참이 됩니다.
W05에서 결측값을 판단할 때 반드시 걸리는 함정입니다.
</details>
