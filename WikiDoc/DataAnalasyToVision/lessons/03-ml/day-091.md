## ③ 개념 설명

### Pillow vs OpenCV

| | Pillow (PIL) | OpenCV (cv2) |
|---|---|---|
| 설치 | `pip install pillow` | `pip install opencv-python` |
| 색 순서 | **RGB** | **BGR** ⚠️ |
| 이미지 객체 | `Image` 객체 | **numpy 배열** |
| 강점 | 단순, 파일 포맷 다양 | **빠름**, 영상 처리 기능 풍부 |
| 한글 경로 | 잘 됨 | **문제 발생** ⚠️ |
| 주 용도 | 간단한 변환 | 실시간 처리, 영상 |

```python
# Pillow
from PIL import Image
img = Image.open("photo.jpg")        # RGB
arr = np.array(img)                   # (H, W, 3) RGB

# OpenCV
import cv2
img = cv2.imread("photo.jpg")         # BGR! (H, W, 3)
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)   # 반드시 변환
```

> **어느 것을 쓸까** — 정적 이미지 전처리는 **Pillow**, 영상·실시간은 **OpenCV**.
> 대단원 05의 라즈베리파이 CCTV에서는 OpenCV가 필수입니다.

### ★ BGR 함정

**OpenCV가 BGR을 쓰는 이유** — 1990년대 초기 카메라·코덱이 BGR 순서였기 때문입니다. 역사적 유산입니다.

```python
img_bgr = cv2.imread("wolf.jpg")

plt.imshow(img_bgr)                              # ✗ 색이 뒤집힘
plt.imshow(cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB))   # ✓
```

**언제 문제가 되는가**

| 상황 | 문제 |
|---|---|
| 시각화 | 색이 이상하게 보임 (바로 알아챔) |
| **모델 학습** | **성능 저하** (에러 없음, 알아채기 어려움) |
| **학습과 추론의 불일치** | **치명적** — 학습은 RGB, 추론은 BGR |

```
학습: Pillow로 읽어 RGB로 학습
추론: OpenCV로 읽어 BGR로 입력
→ 색 채널이 뒤바뀐 이미지를 넣는 것
→ 정확도 급락
```

> **원칙 — 파이프라인 전체에서 하나의 색 순서를 쓰세요.**
> Keras는 RGB를 전제합니다. **RGB로 통일**하는 것이 안전합니다.

### 색 공간

| 색 공간 | 채널 | 특징 | 용도 |
|---|---|---|---|
| **RGB** | R, G, B | 화면 표시 표준 | **딥러닝 기본** |
| BGR | B, G, R | OpenCV 기본 | (변환 필요) |
| **Gray** | 밝기 1채널 | 색 정보 없음 | 엣지 검출, 용량 절감 |
| **HSV** | 색상, 채도, 명도 | **색을 직관적으로 다룸** | 색 기반 필터링 |
| LAB | 밝기, a, b | 사람 인지에 가까움 | 색 보정 |

**Gray 변환 공식**

```
Gray = 0.299×R + 0.587×G + 0.114×B
```

**왜 균등하지 않은가** — 사람 눈은 **초록에 가장 민감**하고 파랑에 둔감합니다.

**HSV가 유용한 경우**

```
"빨간 물체만 찾기"
  RGB로: R이 높고 G,B가 낮은 조건 → 조명에 따라 크게 달라짐
  HSV로: H(색상)가 0~10 또는 170~180 → 조명 변화에 강함
```

### 리사이즈와 보간법

**보간(interpolation)** — 크기를 바꿀 때 없는 픽셀 값을 추정하는 방법.

```
원본 2×2          확대 4×4 (nearest)      확대 4×4 (bilinear)
[10 20]           [10 10 20 20]          [10 13 17 20]
[30 40]           [10 10 20 20]          [17 20 23 27]
                  [30 30 40 40]          [23 27 30 33]
                  [30 30 40 40]          [30 33 37 40]
                  계단처럼 뚝뚝            부드럽게 이어짐
```

| 방법 | 속도 | 품질 | 언제 |
|---|---|---|---|
| **NEAREST** | 가장 빠름 | 계단 현상 | **마스크·라벨 이미지** |
| **BILINEAR** | 빠름 | 무난 | 일반적 |
| **BICUBIC** | 보통 | 좋음 | **확대** |
| **LANCZOS** | 느림 | 가장 좋음 | 고품질 축소 |
| **AREA** | 보통 | **축소에 최적** | **축소** (OpenCV) |

> **축소와 확대에서 최적이 다릅니다.**
> - **축소** → `AREA`(cv2) 또는 `LANCZOS`(PIL) — 여러 픽셀을 평균내 앨리어싱 방지
> - **확대** → `BICUBIC` 또는 `BILINEAR`
>
> **라벨/마스크 이미지는 반드시 `NEAREST`** — 보간하면 없던 클래스 값이 생깁니다.
> 대단원 05의 세그멘테이션에서 중요합니다.

### 종횡비 — 강제 리사이즈 vs 패딩

**원본이 800×600(4:3)인데 224×224(1:1)로 만들어야 한다면?**

**① 강제 리사이즈 (squash)**

```
800×600  →  224×224
가로가 눌림. 물체가 왜곡됨
```

**② 중앙 크롭 (center crop)**

```
800×600 → 가운데 600×600 잘라내기 → 224×224
왜곡 없음. 가장자리 정보 손실
```

**③ 패딩 (letterbox)**

```
800×600 → 224×168로 축소 → 위아래에 28px씩 검은 띠 → 224×224
왜곡 없음. 정보 손실 없음. 대신 빈 공간 발생
```

| 방법 | 왜곡 | 정보 손실 | 언제 |
|---|---|---|---|
| 강제 리사이즈 | **있음** | 없음 | 종횡비가 비슷할 때 |
| 중앙 크롭 | 없음 | **있음** | 대상이 가운데 있을 때 |
| **패딩** | 없음 | 없음 | **Object Detection** |

> **분류 문제에서는 강제 리사이즈도 많이 씁니다.** 학습·추론에서 일관되게만 하면 모델이 적응합니다.
> **Object Detection(대단원 05)에서는 패딩이 표준**입니다. 박스 좌표가 왜곡되면 안 되기 때문입니다.

### 주요 연산 정리

| 연산 | Pillow | OpenCV |
|---|---|---|
| 읽기 | `Image.open(path)` | `cv2.imread(path)` |
| 저장 | `img.save(path)` | `cv2.imwrite(path, img)` |
| 리사이즈 | `img.resize((w,h))` | `cv2.resize(img, (w,h))` |
| 크롭 | `img.crop((l,t,r,b))` | `img[t:b, l:r]` |
| 회전 | `img.rotate(deg)` | `cv2.warpAffine(...)` |
| 좌우 반전 | `img.transpose(Image.FLIP_LEFT_RIGHT)` | `cv2.flip(img, 1)` |
| 흑백 변환 | `img.convert("L")` | `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)` |

> ⚠️ **크기 지정 순서가 다릅니다.**
> - Pillow: `(가로, 세로)` = `(width, height)`
> - OpenCV `resize`: `(가로, 세로)` — 같음
> - **numpy shape**: `(세로, 가로, 채널)` = `(height, width, channels)` — **반대!**

```python
try:
    import cv2
    cv_img = cv2.imread(str(sample_path))
    print("\n" + "=" * 66)
    print("OpenCV")
    print("=" * 66)
    print(f"타입      : {type(cv_img)}")
    print(f"배열 shape: {cv_img.shape}   ← (height, width, channels)")
    print(f"dtype     : {cv_img.dtype}")
    print(f"픽셀(0,0) : {cv_img[0, 0]}   ← B, G, R 순서 ⚠️")
    print()
    print("두 라이브러리의 픽셀 값 비교")

    print(f"  OpenCV (BGR): {cv_img[0, 0]}")

    cv_rgb = cv2.cvtColor(cv_img, cv2.COLOR_BGR2RGB)
    print(f"\ncvtColor 후 전체 일치: {np.array_equal(pil_arr, cv_rgb)}")

    HAS_CV2 = True
except ImportError:
    print("\nOpenCV가 없습니다. !pip install opencv-python")
    HAS_CV2 = False

# ── 시각화 ──
if HAS_CV2:
    fig, axes = plt.subplots(1, 4, figsize=(16, 4))

    axes[0].imshow(pil_arr)
    axes[0].set_title("Pillow (RGB)\ncorrect", fontsize=11)

    axes[1].imshow(cv_img)
    axes[1].set_title("OpenCV raw (BGR)\n⚠️ WRONG COLORS", fontsize=11, color="red")

    axes[2].imshow(cv_rgb)
    axes[2].set_title("OpenCV + cvtColor\ncorrect", fontsize=11)

    diff = np.abs(pil_arr.astype(int) - cv_img.astype(int)).mean(axis=2)
    im = axes[3].imshow(diff, cmap="hot")
    axes[3].set_title(f"|Pillow - OpenCV raw|\nmean {diff.mean():.1f}", fontsize=11)

    fig.tight_layout()
    plt.show()
```

### Step 2. 색 공간 변환

```python
import matplotlib.pyplot as plt
import numpy as np
from PIL import Image

try:
    import cv2
    HAS_CV2 = True
except ImportError:
    HAS_CV2 = False

from pathlib import Path
WORK = Path("/content/drive/MyDrive/ml_course/datasets/day091")
img = np.array(Image.open(WORK / "sample.jpg"))

print("=" * 66)
print("색 공간 변환")
print("=" * 66)

# ── Gray 변환 ──
gray_pil = np.array(Image.open(WORK / "sample.jpg").convert("L"))
gray_manual = (0.299 * img[:, :, 0] + 0.587 * img[:, :, 1]
               + 0.114 * img[:, :, 2]).astype(np.uint8)

print(f"원본  shape: {img.shape}")
print(f"Gray  shape: {gray_pil.shape}   ← 채널 차원이 사라짐")
print()
print("Gray 변환 공식 검증 (픽셀 (0,0))")
r, g, b = img[0, 0]
manual = 0.299 * r + 0.587 * g + 0.114 * b
print(f"  RGB = ({r}, {g}, {b})")
print(f"  0.299×{r} + 0.587×{g} + 0.114×{b} = {manual:.2f}")
print(f"  Pillow 결과: {gray_pil[0, 0]}")
print(f"  직접 계산  : {gray_manual[0, 0]}")
print()
print("왜 균등하지 않은가: 사람 눈은 초록에 가장 민감, 파랑에 둔감")

# ── HSV 변환 ──
if HAS_CV2:
    bgr = cv2.cvtColor(img, cv2.COLOR_RGB2BGR)
    hsv = cv2.cvtColor(bgr, cv2.COLOR_BGR2HSV)
    print("\n" + "=" * 66)
    print("HSV 변환")
    print("=" * 66)
    print(f"HSV shape: {hsv.shape}")
    print(f"{'채널':<10}{'의미':<16}{'범위(OpenCV)':<20}{'예시 값':>12}")
    print("-" * 66)
    print(f"{'H':<10}{'색상 (Hue)':<16}{'0 ~ 179':<20}{hsv[0,0,0]:>12}")
    print(f"{'S':<10}{'채도 (Saturation)':<16}{'0 ~ 255':<20}{hsv[0,0,1]:>12}")
    print(f"{'V':<10}{'명도 (Value)':<16}{'0 ~ 255':<20}{hsv[0,0,2]:>12}")
    print()
    print("H 값의 의미 (OpenCV 기준, 0~179)")
    for name, lo, hi in [("빨강", 0, 10), ("주황", 11, 25), ("노랑", 26, 34),
                         ("초록", 35, 85), ("파랑", 86, 125),
                         ("보라", 126, 155), ("빨강(반대편)", 156, 179)]:
        print(f"  {name:<14}{lo:>4} ~ {hi:<4}")

# ── 시각화 ──
n_cols = 6 if HAS_CV2 else 4
fig, axes = plt.subplots(2, n_cols, figsize=(3 * n_cols, 7))

axes[0, 0].imshow(img)
axes[0, 0].set_title("RGB (original)")
axes[0, 1].imshow(gray_pil, cmap="gray")
axes[0, 1].set_title("Grayscale")
axes[0, 2].imshow(img[:, :, 0], cmap="Reds")
axes[0, 2].set_title("R channel")
axes[0, 3].imshow(img[:, :, 1], cmap="Greens")
axes[0, 3].set_title("G channel")

if HAS_CV2:
    axes[0, 4].imshow(img[:, :, 2], cmap="Blues")
    axes[0, 4].set_title("B channel")
```

### Step 4. 종횡비 처리 — 3가지 방법 비교

```python
import matplotlib.pyplot as plt
import numpy as np
from PIL import Image, ImageOps

from pathlib import Path
WORK = Path("/content/drive/MyDrive/ml_course/datasets/day091")

# 종횡비가 극단적인 이미지 만들기
orig = Image.open(WORK / "sample.jpg")
wide = orig.resize((600, 200), Image.LANCZOS)      # 3:1 가로로 긴 이미지
TARGET = (224, 224)


def squash(img, size):
    """강제 리사이즈 — 종횡비 무시"""
    return img.resize(size, Image.BILINEAR)


def center_crop_resize(img, size):
    """중앙을 정사각형으로 크롭 후 리사이즈"""
    w, h = img.size
    side = min(w, h)
    left = (w - side) // 2
    top = (h - side) // 2
    cropped = img.crop((left, top, left + side, top + side))
    return cropped.resize(size, Image.BILINEAR)


def letterbox(img, size, fill=(0, 0, 0)):
    """종횡비 유지 + 패딩 (letterbox)"""
    tw, th = size
    w, h = img.size
    scale = min(tw / w, th / h)
    nw, nh = int(w * scale), int(h * scale)
    resized = img.resize((nw, nh), Image.BILINEAR)

    canvas = Image.new("RGB", size, fill)
    canvas.paste(resized, ((tw - nw) // 2, (th - nh) // 2))
    return canvas


def letterbox_padded_edge(img, size):
    """패딩을 가장자리 색으로 채우기"""
    tw, th = size
    w, h = img.size
    scale = min(tw / w, th / h)
    nw, nh = int(w * scale), int(h * scale)
    resized = img.resize((nw, nh), Image.BILINEAR)
    arr = np.array(resized)

    canvas = np.zeros((th, tw, 3), dtype=np.uint8)
    y0, x0 = (th - nh) // 2, (tw - nw) // 2
    canvas[y0:y0 + nh, x0:x0 + nw] = arr

    # 위아래를 가장자리 행으로 채움
    if y0 > 0:
        canvas[:y0] = arr[0]
        canvas[y0 + nh:] = arr[-1]
    if x0 > 0:
        canvas[:, :x0] = canvas[:, x0:x0 + 1]
        canvas[:, x0 + nw:] = canvas[:, x0 + nw - 1:x0 + nw]
    return Image.fromarray(canvas)


methods = [
    ("original", wide),
    ("squash (강제)", squash(wide, TARGET)),
    ("center crop", center_crop_resize(wide, TARGET)),
    ("letterbox (검정)", letterbox(wide, TARGET)),
    ("letterbox (가장자리)", letterbox_padded_edge(wide, TARGET)),
]

fig, axes = plt.subplots(1, 5, figsize=(18, 4.5))

plt.show()

print("종횡비 처리 방법 비교")
print("=" * 74)
print(f"원본: {wide.size}  종횡비 {wide.size[0]/wide.size[1]:.2f}:1")
print(f"목표: {TARGET}  종횡비 1.00:1")
print()
print(f"{'방법':<22}{'왜곡':<10}{'정보 손실':<14}{'빈 공간':<12}{'용도':<20}")
print("-" * 74)
print(f"{'강제 리사이즈':<21}{'있음':<10}{'없음':<14}{'없음':<12}{'분류 (일관되면 OK)':<20}")
print(f"{'중앙 크롭':<22}{'없음':<10}{'큼':<14}{'없음':<12}{'대상이 가운데':<20}")
print(f"{'letterbox':<22}{'없음':<10}{'없음':<14}{'있음':<12}{'Object Detection':<20}")
print("=" * 74)

# ── 정보 손실량 계산 ──
w, h = wide.size
side = min(w, h)
crop_ratio = (side * side) / (w * h)
lb_scale = min(TARGET[0] / w, TARGET[1] / h)
lb_used = (int(w * lb_scale) * int(h * lb_scale)) / (TARGET[0] * TARGET[1])

print(f"\n정보 손실 정량화")
print(f"  중앙 크롭 : 원본의 {crop_ratio:.1%}만 사용 "

print(f"  letterbox : 출력의 {lb_used:.1%}만 실제 이미지 "
```

### Step 5. 일괄 전처리 스크립트

```python
import shutil
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from PIL import Image, ImageOps, UnidentifiedImageError

# ── 실습용 이미지 100장 생성 (크기·종횡비를 랜덤하게) ──
from tensorflow import keras

(X, y), _ = keras.datasets.cifar10.load_data()

RAW = Path("/content/drive/MyDrive/ml_course/datasets/day091/raw")
OUT = Path("/content/drive/MyDrive/ml_course/datasets/day091/processed")
if RAW.exists():
    shutil.rmtree(RAW)
RAW.mkdir(parents=True, exist_ok=True)

rng = np.random.default_rng(42)
print("실습용 이미지 100장 생성 중 (크기·확장자를 다양하게)...")
for i in range(100):
    w = int(rng.integers(120, 800))
    h = int(rng.integers(120, 800))
    ext = rng.choice(["jpg", "png", "jpeg"])
    Image.fromarray(X[i]).resize((w, h), Image.BICUBIC).save(
        RAW / f"img_{i:03d}.{ext}"
    )

# 일부러 깨진 파일도 만들기
(RAW / "broken.jpg").write_bytes(b"not an image")
(RAW / "readme.txt").write_text("this is not an image")

files = sorted(RAW.iterdir())
print(f"생성 완료: {len(files)}개 파일 (이미지 100 + 문제 파일 2)")


# ══════════════════════════════════════════════════════════
# 일괄 전처리 함수 — Day 092 이후 계속 사용합니다
# ══════════════════════════════════════════════════════════
VALID_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}


def letterbox(img: Image.Image, size, fill=(0, 0, 0)) -> Image.Image:
    """종횡비를 유지하며 size로 맞춤 (남는 곳은 fill로 채움)"""
    tw, th = size
    w, h = img.size
    scale = min(tw / w, th / h)
    nw, nh = max(1, int(w * scale)), max(1, int(h * scale))
    resized = img.resize((nw, nh), Image.BILINEAR)
    canvas = Image.new("RGB", size, fill)
    canvas.paste(resized, ((tw - nw) // 2, (th - nh) // 2))
    return canvas


def preprocess_folder(src_dir, dst_dir, size=(224, 224), mode="letterbox",
                      quality=92, verbose=True):
    """
    폴더의 모든 이미지를 일괄 전처리

    mode: "letterbox" | "squash" | "center_crop"
    반환: 처리 결과 DataFrame
    """
    src_dir, dst_dir = Path(src_dir), Path(dst_dir)
    dst_dir.mkdir(parents=True, exist_ok=True)

    records = []
    t0 = time.time()

    for path in sorted(src_dir.iterdir()):
        rec = {"파일": path.name, "상태": "", "원본크기": "", "종횡비": np.nan}

        # ① 확장자 확인
        if path.suffix.lower() not in VALID_EXT:
            rec["상태"] = "건너뜀 (확장자)"
            records.append(rec)
            continue

        # ② 열기 시도
        try:
            img = Image.open(path)
            img.verify()                      # 손상 검사
            img = Image.open(path)            # verify 후에는 다시 열어야 함
        except (UnidentifiedImageError, OSError) as e:
            rec["상태"] = f"실패 (손상): {type(e).__name__}"
            records.append(rec)
            continue

        rec["원본크기"] = f"{img.size[0]}×{img.size[1]}"
        rec["종횡비"] = round(img.size[0] / img.size[1], 3)

        # ③ EXIF 회전 보정 (스마트폰 사진 필수)
        img = ImageOps.exif_transpose(img)

        # ④ RGB로 통일 (RGBA, P, L 모드 처리)
        if img.mode != "RGB":
            rec["상태"] = f"모드 변환 {img.mode}→RGB · "
            img = img.convert("RGB")

        # ⑤ 크기 맞추기
        if mode == "letterbox":
            out = letterbox(img, size)
        elif mode == "squash":
            out = img.resize(size, Image.BILINEAR)
        elif mode == "center_crop":
            w, h = img.size
            side = min(w, h)
            l, t = (w - side) // 2, (h - side) // 2
            out = img.crop((l, t, l + side, t + side)).resize(size, Image.BILINEAR)
        else:
            raise ValueError(mode)

        # ⑥ 저장 (확장자를 jpg로 통일)
        out.save(dst_dir / f"{path.stem}.jpg", quality=quality)
        rec["상태"] += "성공"
        records.append(rec)

    df = pd.DataFrame(records)
    elapsed = time.time() - t0

    if verbose:
        ok = df["상태"].str.contains("성공").sum()
        print(f"\n{'='*66}")
        print(f"일괄 전처리 완료 — mode='{mode}', size={size}")
        print(f"{'='*66}")
        print(f"  전체 파일 : {len(df)}개")
        print(f"  성공      : {ok}개")
        print(f"  건너뜀    : {df['상태'].str.contains('건너뜀').sum()}개")
        print(f"  실패      : {df['상태'].str.contains('실패').sum()}개")
        print(f"  소요 시간 : {elapsed:.2f}초 ({elapsed/max(ok,1)*1000:.1f}ms/장)")
        print(f"  저장 위치 : {dst_dir}")

        problems = df[~df["상태"].str.contains("성공")]
        if len(problems):
```

### Step 6. 오늘의 종합 — 전처리 방식이 성능에 미치는 영향

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from PIL import Image
from tensorflow import keras
from tensorflow.keras import layers

# ── CIFAR-10을 "다양한 크기의 사진"으로 만든 뒤 전처리 방식별 비교 ──
(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()

N_TRAIN, N_TEST = 8000, 2000
rng = np.random.default_rng(42)

# 원본 32×32를 랜덤한 크기/종횡비로 늘렸다가 다시 줄이는 상황 시뮬레이션
def to_varied(X, n, seed=0):
    r = np.random.default_rng(seed)
    out = []
    for i in range(n):
        w = int(r.integers(48, 160))
        h = int(r.integers(48, 160))
        out.append(Image.fromarray(X[i]).resize((w, h), Image.BICUBIC))
    return out


train_imgs = to_varied(X_full, N_TRAIN, seed=1)
test_imgs = to_varied(X_test, N_TEST, seed=2)
y_tr, y_te = y_full[:N_TRAIN], y_test[:N_TEST]

TARGET = (48, 48)


def squash(img, size):
    return img.resize(size, Image.BILINEAR)


def center_crop_resize(img, size):
    w, h = img.size
    s = min(w, h)
    l, t = (w - s) // 2, (h - s) // 2
    return img.crop((l, t, l + s, t + s)).resize(size, Image.BILINEAR)


def letterbox(img, size, fill=(0, 0, 0)):
    tw, th = size
    w, h = img.size
    sc = min(tw / w, th / h)
    nw, nh = max(1, int(w * sc)), max(1, int(h * sc))
    canvas = Image.new("RGB", size, fill)
    canvas.paste(img.resize((nw, nh), Image.BILINEAR),
                 ((tw - nw) // 2, (th - nh) // 2))
    return canvas


def to_array(imgs, fn, size):
    return np.stack([np.array(fn(im, size), dtype="float32") / 255.0
                     for im in imgs])


방법들 = {
    "squash (강제)": squash,
    "center crop": center_crop_resize,
    "letterbox": letterbox,
}


def build():
    return keras.Sequential([
        layers.Input(shape=(*TARGET, 3)),
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ])


rows = []
print("=" * 70)
print(f"전처리 방식이 성능에 미치는 영향 — 목표 크기 {TARGET}")
print("=" * 70)

for name, fn in 방법들.items():
    t0 = time.time()
    Xtr = to_array(train_imgs, fn, TARGET)
    Xte = to_array(test_imgs, fn, TARGET)
    prep_time = time.time() - t0

    tf.random.set_seed(42)
    m = build()
    m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
    m.fit(Xtr, y_tr, epochs=20, batch_size=64, validation_split=0.15, verbose=0)
    _, acc = m.evaluate(Xte, y_te, verbose=0)

    rows.append({"전처리": name, "test_acc": round(acc, 4),
                 "전처리시간(s)": round(prep_time, 1)})
    print(f"{name:<20} test_acc {acc:.4f}  (전처리 {prep_time:.1f}s)")

# ── 학습/추론 전처리 불일치 실험 ──
print("\n" + "=" * 70)
print("학습과 추론의 전처리가 다르면? (가장 흔한 실무 버그)")
print("=" * 70)

Xtr_lb = to_array(train_imgs, letterbox, TARGET)
tf.random.set_seed(42)
m = build()
m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
          metrics=["accuracy"])
m.fit(Xtr_lb, y_tr, epochs=20, batch_size=64, validation_split=0.15, verbose=0)

print("학습: letterbox 로 전처리")
print(f"{'추론 전처리':<20}{'정확도':>12}{'하락':>12}")
print("-" * 46)
base = None
for name, fn in 방법들.items():
    Xte = to_array(test_imgs, fn, TARGET)
    _, acc = m.evaluate(Xte, y_te, verbose=0)
    if base is None:
        pass
    if name == "letterbox":
        base = acc
    print(f"{name:<20}{acc:>12.4f}", end="")
    print(f"{acc - base:>12.4f}" if base is not None else "")

# BGR 실수 시뮬레이션
Xte_bgr = to_array(test_imgs, letterbox, TARGET)[:, :, :, ::-1]
_, acc_bgr = m.evaluate(Xte_bgr, y_te, verbose=0)
print(f"{'letterbox + BGR 실수':<20}{acc_bgr:>12.4f}{acc_bgr - base:>12.4f}")

print("=" * 70)
print("★ BGR 실수 하나로 정확도가 크게 떨어집니다.")
print("  에러가 나지 않으므로 알아채기 매우 어렵습니다.")

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

ax = axes[0]
ax.bar(df["전처리"], df["test_acc"], color=["#d62728", "#ff7f0e", "#2ca02c"])
ax.set_ylabel("test accuracy")
ax.set_ylim(0.4, 0.75)
ax.set_title("Preprocessing method vs accuracy")
for i, v in enumerate(df["test_acc"]):
    ax.text(i, v + 0.005, f"{v:.4f}", ha="center", fontsize=10)
ax.grid(alpha=0.3, axis="y")

ax = axes[1]
sample = train_imgs[3]
for i, (name, fn) in enumerate(방법들.items()):
    ax2 = fig.add_subplot(2, 3, 3 + i + 1)

    ax2.axis("off")
ax.axis("off")

plt.show()
```

```python
from pathlib import Path

import cv2
import numpy as np
from PIL import Image, ImageOps
from tensorflow import keras

model = keras.models.load_model("wolf_husky.keras")
CLASSES = ["husky", "wolf"]


def preprocess(path, size=(224, 224)):
    """학습 때와 동일한 전처리 — 함수로 만들어 재사용"""
    path = Path(path)
    if not path.exists():
        raise FileNotFoundError(path)

    # ① 한글 경로 → Pillow 사용 (또는 imdecode)
    img = Image.open(path)
    # ③ EXIF 회전 보정
    img = ImageOps.exif_transpose(img)
    # ② RGB로 통일 (Pillow는 원래 RGB, RGBA만 처리하면 됨)
    img = img.convert("RGB")
    # ④ 리사이즈
    img = img.resize(size, Image.BILINEAR)

    arr = np.array(img, dtype="float32") / 255.0        # ⑤ 정규화
    return arr


arr = preprocess("test/늑대사진.jpg")
print(f"입력 shape: {arr.shape}, 범위 {arr.min():.2f}~{arr.max():.2f}")

print(f"예측: {CLASSES[int(prob > 0.5)]}  (확률 {prob:.4f})")
```

```python
def preprocess_cv2(path, size=(224, 224)):
```

```python
"""
image_utils.py — Day 092 이후 계속 사용하는 전처리 모듈

사용 예:
    from image_utils import preprocess_image, preprocess_folder

    # 학습 데이터 준비
    preprocess_folder("raw/wolf", "data/train/wolf", size=(224,224))

    # 추론 시 (같은 함수!)
    arr = preprocess_image("new_photo.jpg", size=(224,224), normalize=True)
    model.predict(arr[np.newaxis])
"""
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from PIL import Image, ImageOps, UnidentifiedImageError

VALID_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp", ".tif", ".tiff"}

RESAMPLE = {
    "nearest": Image.NEAREST,
    "bilinear": Image.BILINEAR,
    "bicubic": Image.BICUBIC,
    "lanczos": Image.LANCZOS,
}


# ══════════════════════════════════════════════════
# ④ 3가지 크기 조정 모드
# ══════════════════════════════════════════════════
def _squash(img, size, resample):
    return img.resize(size, resample)


def _center_crop(img, size, resample):
    w, h = img.size
    side = min(w, h)
    l, t = (w - side) // 2, (h - side) // 2
    return img.crop((l, t, l + side, t + side)).resize(size, resample)


def _letterbox(img, size, resample, fill=(0, 0, 0)):
    tw, th = size
    w, h = img.size
    scale = min(tw / w, th / h)
    nw, nh = max(1, int(round(w * scale))), max(1, int(round(h * scale)))
    canvas = Image.new("RGB", size, fill)
    canvas.paste(img.resize((nw, nh), resample), ((tw - nw) // 2, (th - nh) // 2))
    return canvas


MODES = {"squash": _squash, "center_crop": _center_crop, "letterbox": _letterbox}


# ══════════════════════════════════════════════════
# ⑦ 핵심 함수 — 학습·추론 양쪽에서 사용
# ══════════════════════════════════════════════════
def preprocess_image(source, size=(224, 224), mode="letterbox",
                     resample="bilinear", normalize=False, as_array=None):
    """
    이미지 하나를 전처리합니다.

    source    : 파일 경로 또는 PIL Image
    size      : (width, height)
    mode      : "squash" | "center_crop" | "letterbox"
    resample  : "nearest" | "bilinear" | "bicubic" | "lanczos"
    normalize : True면 0~1 float32 배열 반환
    as_array  : True면 numpy 배열, False면 PIL Image
                (None이면 normalize 값을 따름)

    ★ 학습 데이터 생성과 추론에서 반드시 같은 인자로 호출하세요.
    """
    if as_array is None:
        as_array = normalize

    if isinstance(source, (str, Path)):
        img = Image.open(source)
    else:
        img = source

    # ③ EXIF 회전 보정 + RGB 변환
    img = ImageOps.exif_transpose(img)
    if img.mode != "RGB":
        img = img.convert("RGB")

    out = MODES[mode](img, size, RESAMPLE[resample])

    if as_array:
        arr = np.array(out, dtype="float32")
        return arr / 255.0 if normalize else arr.astype("uint8")
    return out


# ══════════════════════════════════════════════════
# ①②⑤ 폴더 일괄 처리
# ══════════════════════════════════════════════════
def preprocess_folder(src_dir, dst_dir, size=(224, 224), mode="letterbox",
                      resample="bilinear", quality=92, verbose=True,
                      log_path=None):
    """폴더 안의 모든 이미지를 일괄 전처리하고 리포트를 반환합니다."""
    src_dir, dst_dir = Path(src_dir), Path(dst_dir)
    dst_dir.mkdir(parents=True, exist_ok=True)

    records = []
    t0 = time.time()

    for path in sorted(src_dir.rglob("*")):
        if path.is_dir():
            continue

        rec = {"파일": path.name, "상태": "성공", "사유": "",
               "원본_W": np.nan, "원본_H": np.nan,
               "종횡비": np.nan, "원본_모드": "", "용량_KB": np.nan}

        # ② 확장자 검사
        if path.suffix.lower() not in VALID_EXT:
            rec.update(상태="건너뜀", 사유=f"확장자 {path.suffix}")
            records.append(rec)
            continue

        # ② 손상 검사
        try:
            with Image.open(path) as probe:
                probe.verify()
            img = Image.open(path)
        except (UnidentifiedImageError, OSError, SyntaxError) as e:
            rec.update(상태="실패", 사유=type(e).__name__)
            records.append(rec)
            continue

        rec["원본_W"], rec["원본_H"] = img.size
        rec["종횡비"] = round(img.size[0] / img.size[1], 3)
        rec["원본_모드"] = img.mode
        rec["용량_KB"] = round(path.stat().st_size / 1024, 1)

        # 너무 작은 이미지 경고
        if min(img.size) < min(size) * 0.5:
            rec["사유"] = f"작은 이미지 ({img.size}) — 확대됨"

        try:
            out = preprocess_image(img, size=size, mode=mode, resample=resample)
            out.save(dst_dir / f"{path.stem}.jpg", quality=quality)
        except Exception as e:
            rec.update(상태="실패", 사유=f"저장 실패: {type(e).__name__}")

        records.append(rec)

    df = pd.DataFrame(records)
    elapsed = time.time() - t0

    if verbose:
        ok = (df["상태"] == "성공").sum()
        print("=" * 74)
        print(f"일괄 전처리 리포트 — mode='{mode}', size={size}, resample='{resample}'")
        print("=" * 74)
        print(f"  원본 폴더 : {src_dir}")
        print(f"  저장 폴더 : {dst_dir}")
        print(f"  전체      : {len(df)}개")
        print(f"  성공      : {ok}개 ({ok/max(len(df),1):.1%})")
        print(f"  건너뜀    : {(df['상태']=='건너뜀').sum()}개")
        print(f"  실패      : {(df['상태']=='실패').sum()}개")
        print(f"  소요 시간 : {elapsed:.2f}초 ({elapsed/max(ok,1)*1000:.1f}ms/장)")

        valid = df[df["종횡비"].notna()]
        if len(valid):
            print(f"\n  [원본 통계]")
            print(f"    크기 범위 : {int(valid['원본_W'].min())}×{int(valid['원본_H'].min())}"
                  f" ~ {int(valid['원본_W'].max())}×{int(valid['원본_H'].max())}")
            print(f"    종횡비    : {valid['종횡비'].min():.2f} ~ {valid['종횡비'].max():.2f}"
                  f"  (평균 {valid['종횡비'].mean():.2f})")
            print(f"    파일 크기 : 평균 {valid['용량_KB'].mean():.0f} KB")
            modes = valid["원본_모드"].value_counts()
            print(f"    색 모드   : {dict(modes)}")

        problems = df[df["상태"] != "성공"]
        if len(problems):
            print(f"\n  [문제 파일 {len(problems)}개]")
            for _, r in problems.head(10).iterrows():
                print(f"    {r['파일']:<24}{r['상태']:<8}{r['사유']}")

        warn = df[(df["상태"] == "성공") & (df["사유"] != "")]
        if len(warn):
            print(f"\n  [경고 {len(warn)}개]")
            for _, r in warn.head(5).iterrows():
                print(f"    {r['파일']:<24}{r['사유']}")
        print("=" * 74)

    if log_path:
        df.to_csv(log_path, index=False, encoding="utf-8-sig")
        print(f"로그 저장: {log_path}")

    return df
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| Pillow | **RGB**, `Image` 객체, 한글 경로 OK |
| OpenCV | **BGR** ⚠️, numpy 배열, 빠름, 한글 경로 문제 |
| **BGR 함정** | `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)` **필수** |
| 크기 순서 | Pillow `size` = `(W, H)`, numpy `shape` = `(H, W, C)` |
| Gray 변환 | `0.299R + 0.587G + 0.114B` (초록에 가중치) |
| HSV | H(색상) 0~179, **조명 변화에 강함** |
| 보간법 축소 | **LANCZOS**(PIL) / **INTER_AREA**(cv2) |
| 보간법 확대 | **BICUBIC** |
| **마스크 보간** | **반드시 NEAREST** |
| 강제 리사이즈 | 왜곡 있음, 손실 없음 |
| 중앙 크롭 | 왜곡 없음, **손실 큼** |
| **letterbox** | 왜곡·손실 없음, 빈 공간 생김. **OD 표준** |
| **EXIF 회전** | `ImageOps.exif_transpose()` — 스마트폰 사진 필수 |
| RGBA | `.convert("RGB")` 로 알파 제거 |
| 손상 파일 | `verify()` + try/except |
| **★ 최우선 원칙** | **학습과 추론의 전처리를 똑같이** |

**오늘 반드시 기억할 세 가지**
> ① **OpenCV는 BGR입니다.** 이 실수 하나로 정확도가 34%p 떨어집니다.
> ② **전처리 함수를 하나로 만들고 학습·추론 양쪽에서 부르세요.** 방식보다 일관성이 중요합니다.
> ③ **스마트폰 사진은 `exif_transpose` 가 필수**입니다. 안 하면 절반이 눕습니다.

**과제** — 일괄 전처리 스크립트를 작성하세요.
