## 3. 개념

### 3-1. 밸런싱의 기본 — DPS와 HP

**왜 필요한가** — 감이 아니라 계산.

```
   ★ 핵심 부등식

   보유 DPS × 적이 사거리에 머무는 시간  ≥  적 총 HP

   → 이걸 만족하면 클리어
```

```
   ★ 필요 DPS 계산

   필요 DPS = 웨이브 총 HP / 적이 맵을 통과하는 시간
```

| 항목 | 값 | 계산 |
|---|---|---|
| 웨이브 총 HP | 1,170 | Day 86의 `TotalHp` |
| 스폰 소요 시간 | 6.4초 | `EstimatedDuration` |
| 이동 시간 | 15초 | 경로 길이 / 속도 |
| 총 노출 시간 | 21.4초 | 스폰 + 이동 |
| **필요 DPS** | **54.7** | 1170 / 21.4 |

```
   ⚠️ 이것은 이상적인 값이다

   실제로는
   ① 타워마다 사거리가 다르다
   ② 적이 항상 사거리 안에 있지 않다
   ③ 조준 시간, 투사체 비행 시간이 있다
   ④ 오버킬(과잉 데미지)이 있다

   ★ 실효 DPS = 이론 DPS × 0.5 ~ 0.7
```

```
   ★ 그래서 보정 계수를 둔다

   필요 DPS = 총HP / 노출시간 / 효율계수(0.6)
```

### 3-2. 커버리지

**왜 필요한가** — 타워가 실제로 쏘는 시간.

```
   ★ 커버리지 = 사거리가 경로를 덮는 길이 / 전체 경로 길이

   ┌────────────────────────────────┐
   │  ●━━━━━━━━━━━━━━━━━━━━━━━━━●  │  경로 40m
   │       ╱‾‾‾╲                    │
   │      │ 타워 │  사거리 6m        │  덮는 구간 약 11m
   │       ╲___╱                    │
   └────────────────────────────────┘

   커버리지 = 11 / 40 = 0.275
```

```
   ★ 타워의 실효 DPS

   실효 DPS = 이론 DPS × 커버리지 비율
```

```
   ⚠️ 그래서 사거리가 데미지보다 중요할 때가 많다

   사거리 2배 → 커버 구간 2배 → 실효 DPS 2배
   데미지 2배 → 실효 DPS 2배

   그런데 사거리는 여러 경로 구간을 동시에 덮을 수 있다
   → 코너에 놓으면 3배 이상
```

```csharp
    // 경로를 샘플링해 커버리지 계산
    public float CalcCoverage(Vector3 towerPos, float range,
                              Vector3[] pathPoints)
    {
        float covered = 0, total = 0;
        float rangeSq = range * range;

        for (int i = 0; i < pathPoints.Length - 1; i++)
        {
            Vector3 a = pathPoints[i];
            Vector3 b = pathPoints[i + 1];

            float segLen = Vector3.Distance(a, b);
            total += segLen;

            // ★ 구간을 잘게 나눠 검사
            int samples = Mathf.Max(2, Mathf.CeilToInt(segLen / 0.5f));

            int inRange = 0;
            for (int s = 0; s < samples; s++)
            {
                Vector3 p = Vector3.Lerp(a, b, s / (float)(samples - 1));
                Vector3 d = p - towerPos; d.y = 0;

                if (d.sqrMagnitude <= rangeSq) inRange++;
            }

            covered += segLen * (inRange / (float)samples);
        }

        return total > 0 ? covered / total : 0;
    }
```

```csharp
                        .OrderBy(e => Vector3.Distance(pos, e.Position))
```

### 3-8. 드로우 콜 줄이기

**왜 필요한가** — 렌더링 비용.

```
   ★ 드로우 콜 = CPU가 GPU에게 "이걸 그려라"라고 시키는 횟수

   많을수록 CPU가 바쁘다
```

| 방법 | 설명 |
|---|---|
| **머티리얼 통합** | 같은 머티리얼끼리 묶인다 |
| **Static Batching** | 안 움직이는 오브젝트 병합 |
| **GPU Instancing** | 같은 메시를 한 번에 |
| SRP Batcher | URP의 자동 최적화 |
| 텍스처 아틀라스 | 여러 텍스처를 하나로 |
| LOD | 멀면 단순한 메시 |

```
   ★ Static Batching

   오브젝트 Inspector 우상단 → Static 체크
   → 벽, 지형, 장식에 적용
   ⚠️ 움직이는 것에는 쓰면 안 된다
```

```
   ★ GPU Instancing

   Material Inspector → Enable GPU Instancing ✔
   → 같은 메시+머티리얼 오브젝트가 한 번에 그려진다
   → 적 100기가 같은 프리팹이면 효과가 크다
```

```
   ⚠️ MaterialPropertyBlock을 쓰면 Instancing이 깨질 수 있다
```

```csharp
    // ★ ③ 프레임 분산
    public class TowerManager : MonoBehaviour
    {
        [SerializeField] private int updateBatches = 4;

        private int cursor;

        void Update()
        {
            float dt = Time.deltaTime;

            // 조준·발사는 매 프레임 (반응성)
            for (int i = towers.Count - 1; i >= 0; i--)
            {
                if (towers[i] == null) { towers.RemoveAt(i); continue; }
                towers[i].Tick(dt);
            }

            // ★ 타겟 재탐색은 나눠서
            if (towers.Count == 0) return;

            int perFrame = Mathf.CeilToInt(towers.Count / (float)updateBatches);

            for (int i = 0; i < perFrame; i++)
            {
                int idx = (cursor + i) % towers.Count;
                towers[idx]?.Retarget();
            }

            cursor = (cursor + perFrame) % towers.Count;
        }
    }
```

```
   → 충분히 빠르다
```

### 3-12. 자동 테스트

**왜 필요한가** — 손으로 10웨이브를 반복할 수는 없다.

```csharp
using System.Collections;
using UnityEngine;

public class BalanceTestRunner : MonoBehaviour
{
    [SerializeField] private bool autoRun = false;
    [SerializeField] private float timeScale = 4f;      // ★ 빨리 감기
    [SerializeField] private TowerData[] autoBuildOrder;

    private readonly List<string> log = new List<string>();

    void Start()
    {
        if (autoRun) StartCoroutine(RunTest());
    }

    private IEnumerator RunTest()
    {
        Time.timeScale = timeScale;

        WaveManager wm = WaveManager.Instance;

        int buildIndex = 0;

        while (wm.State != WaveState.Clear && wm.State != WaveState.GameOver)
        {
            // ★ 골드가 되면 자동 건설
            if (buildIndex < autoBuildOrder.Length)
            {
                TowerData next = autoBuildOrder[buildIndex];

                if (wm.Gold >= next.cost && TryAutoPlace(next))
                    buildIndex++;
            }

            // 웨이브 대기 중이면 즉시 시작
            if (wm.State == WaveState.Resting)
                wm.StartNextWave();

            yield return new WaitForSeconds(0.5f);

            RecordSnapshot(wm);
        }

        Time.timeScale = 1f;
        PrintReport();
    }

    private void RecordSnapshot(WaveManager wm)
    {
        log.Add($"{wm.CurrentWaveNumber},{wm.Life},{wm.Gold}," +
                $"{TowerManager.Instance.Count}," +
                $"{TowerManager.Instance.TotalDps:F1}," +
                $"{1f / Time.unscaledDeltaTime:F1}");
    }

    private void PrintReport()
    {
        Debug.Log("=== 테스트 결과 ===");
        Debug.Log("웨이브,라이프,골드,타워수,총DPS,FPS");

        foreach (string line in log) Debug.Log(line);
```

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| **필요 DPS** | 총HP / 노출시간 / 효율계수 |

| **프로파일러** | 튄 곳 → Hierarchy → 정렬 |
| **GC Alloc** | 문자열·LINQ·`new`·Instantiate |

| Static Batching | 안 움직이는 것 |
| GPU Instancing | 같은 메시 다수 |
| **자동 테스트** | `timeScale` 빨리 감기 |
