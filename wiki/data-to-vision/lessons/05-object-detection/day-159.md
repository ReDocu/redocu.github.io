## ③ 개념 설명

### GET vs POST

| | GET | POST |
|---|---|---|
| 데이터 위치 | ★ **URL** | 본문(body) |
| 길이 제한 | ~2,000자 | 사실상 없음 |
| 브라우저 기록 | ★ 남음 | 안 남음 |
| 북마크 | 가능 | 불가 |
| 새로고침 | 안전 | ★ 재전송 경고 |
| 캐시 | 됨 | 안 됨 |
| **파일 전송** | ✗ | ★ **가능** |
| 용도 | 조회 · 검색 · 필터 | 생성 · 수정 · 업로드 |

```
★ 판단 기준
  "이 요청을 여러 번 반복해도 안전한가?"

  안전 (조회)     → GET
  부작용 있음     → POST
```

**우리 프로젝트**

```
GET   /events?type=person&page=2        이력 필터 (★ 공유 가능해야)
GET   /upload                            업로드 폼 표시
POST  /detect                            ★ 이미지 업로드 + 검출
POST  /api/events                        파이가 이벤트 전송
```

### ★ 파일 검증 4단계

```
[1단계] 존재 확인
[2단계] 확장자 화이트리스트
[3단계] 크기 제한
[4단계] ★ 실제 내용 검증 (매직 넘버 · 디코딩)
```

**1단계 — 존재 확인**

```python
if "image" not in request.files:
    return error("파일 필드가 없습니다")

f = request.files["image"]
if not f or f.filename == "":
    return error("파일이 선택되지 않았습니다")
```

```
★ 두 번을 확인하는 이유
  · 필드 자체가 없는 경우 (KeyError)
  · 필드는 있는데 파일을 안 고른 경우 (filename == "")
```

**2단계 — 확장자 화이트리스트**

```python
ALLOWED = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}

ext = Path(f.filename).suffix.lower()
if ext not in ALLOWED:
    return error(f"지원하지 않는 형식: {ext}")
```

```
★ 화이트리스트 (허용 목록) vs 블랙리스트 (금지 목록)

  블랙리스트  ✗ ".exe", ".php" 를 금지
              → .PHP · .php5 · .phtml · shell.jpg.php ...
              → ★ 끝없이 우회 가능

  화이트리스트 ✓ ".jpg", ".png" 만 허용
              → ★ 나머지는 전부 거부
```

**3단계 — 크기 제한**

```python
app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024      # 16MB
```

```
★ Flask 가 자동으로 처리합니다
  초과하면 ★ 413 Payload Too Large
  → 요청 본문을 다 받기 전에 끊음 (디스크·메모리 보호)
```

**★ 4단계 — 실제 내용 검증 (가장 중요)**

```
확장자와 Content-Type 은 ★ 사용자가 마음대로 정합니다

  malware.exe → photo.jpg 로 이름만 변경
  → 2단계 통과
  → ★ 4단계에서 잡아야 합니다
```

**방법 ① 매직 넘버 (파일 시그니처)**

```python
MAGIC = {
    b"\xff\xd8\xff": "jpg",
    b"\x89PNG\r\n\x1a\n": "png",
    b"BM": "bmp",
    b"GIF87a": "gif",
    b"GIF89a": "gif",
    b"RIFF": "webp",         # 8바이트 뒤에 "WEBP"
}


def detect_type(head: bytes) -> str | None:
    for sig, name in MAGIC.items():
        if head.startswith(sig):
            if name == "webp" and head[8:12] != b"WEBP":
                continue
            return name
    return None
```

### ★ 파일명 처리

**문제 — 사용자 파일명을 그대로 쓰면**

```python
f.save(f"uploads/{f.filename}")
```

```
공격 ①  ../../../etc/passwd
        → ★ 시스템 파일 덮어쓰기

공격 ②  ..\..\windows\system32\drivers\etc\hosts

공격 ③  같은 이름 동시 업로드
        → ★ 덮어쓰기 · 결과 뒤바뀜

문제 ④  한글·공백·특수문자
        → cv2.imread 실패 (Day 136)
```

**해결 — `secure_filename` + UUID**

```python
from werkzeug.utils import secure_filename
import uuid

original = secure_filename(f.filename)     # ★ 경로 조작 제거
ext = Path(original).suffix.lower()
stored = f"{uuid.uuid4().hex}{ext}"        # ★ 충돌 불가
f.save(UPLOAD_DIR / stored)
```

**`secure_filename` 이 하는 일**

```python
secure_filename("../../../etc/passwd")   → "etc_passwd"
secure_filename("내 사진.jpg")            → ★ "jpg"   ← 한글이 사라짐!
secure_filename("photo (1).jpg")         → "photo_1.jpg"
secure_filename("")                      → ""
```

> ⚠️ **`secure_filename` 은 비ASCII 문자를 전부 제거합니다.**
> 한글 파일명 `"내 사진.jpg"` → `"jpg"` 가 되어 **확장자만 남습니다.**
> **그래서 UUID 로 저장하고 원본 이름은 DB 에만 보관합니다.**

**★ 권장 전략**

```python
def save_upload(file, upload_dir):
    """안전한 저장 — UUID 파일명 + 원본명 별도 보관"""
    original = file.filename                          # 표시용
    ext = Path(secure_filename(original) or "x.jpg").suffix.lower()
    if not ext:
        ext = ".jpg"
    stored = f"{uuid.uuid4().hex}{ext}"               # ★ 저장용
    path = Path(upload_dir) / stored
    file.save(path)
    return {"stored": stored, "original": original, "path": path}
```

```
저장 파일명  a3f9c21b8e0447d2b1c5f8e9d0a1b2c3.jpg    ★ 안전
표시 이름    내 사진.jpg                              ★ DB 에 보관
```


## ④ 단계별 실습

### Step 1. 업로드 유틸

```python
"""web/upload_utils.py — 안전한 업로드 처리"""
from __future__ import annotations

import io
import uuid
from datetime import datetime, timedelta
from pathlib import Path

import cv2
import numpy as np
from werkzeug.utils import secure_filename

ALLOWED_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}
MAX_BYTES = 16 * 1024 * 1024
MAX_PIXELS = 50_000_000          # ★ 디컴프레션 폭탄 방지
MIN_SIDE = 32

MAGIC = [
    (b"\xff\xd8\xff", "jpg"),
    (b"\x89PNG\r\n\x1a\n", "png"),
    (b"BM", "bmp"),
    (b"GIF87a", "gif"),
    (b"GIF89a", "gif"),
    (b"RIFF", "webp"),
]


class UploadError(Exception):
    """업로드 검증 실패 — 사용자에게 보여줄 메시지를 담는다"""

    def __init__(self, message, code="invalid_file", status=400):
        super().__init__(message)
        self.message = message
        self.code = code
        self.status = status


def sniff_type(head: bytes) -> str | None:
    """매직 넘버로 실제 파일 종류 판별"""
    for sig, name in MAGIC:
        if head.startswith(sig):
            if name == "webp" and head[8:12] != b"WEBP":
                continue
            return name
    return None


def validate_and_decode(file_storage) -> tuple[np.ndarray, bytes, dict]:
    """★ 4단계 검증 + 디코딩

    Returns:
        (이미지 배열, 원본 bytes, 메타 정보)
    Raises:
        UploadError
    """
    # ── [1] 존재 ──
    if file_storage is None or not file_storage.filename:
        raise UploadError("파일이 선택되지 않았습니다", "no_file")

    original_name = file_storage.filename

    # ── [2] 확장자 화이트리스트 ──
    safe = secure_filename(original_name)
    ext = Path(safe).suffix.lower() if safe else ""
    if ext not in ALLOWED_EXT:
        raise UploadError(
            f"지원하지 않는 형식입니다: {ext or '(확장자 없음)'}",
            "unsupported_format")

    # ── [3] 크기 ──
    file_storage.stream.seek(0, io.SEEK_END)
    size = file_storage.stream.tell()
    file_storage.stream.seek(0)
    if size == 0:
        raise UploadError("빈 파일입니다", "empty_file")
    if size > MAX_BYTES:
        raise UploadError(
            f"파일이 너무 큽니다 ({size/1024/1024:.1f}MB, "
            f"최대 {MAX_BYTES/1024/1024:.0f}MB)", "file_too_large", 413)

    data = file_storage.read()
    file_storage.seek(0)

    # ── [4] ★ 실제 내용 검증 ──
    sniffed = sniff_type(data[:16])
    if sniffed is None:
        raise UploadError("이미지 파일이 아닙니다", "not_an_image")

    arr = np.frombuffer(data, np.uint8)
    img = cv2.imdecode(arr, cv2.IMREAD_COLOR)
    if img is None:
        raise UploadError("손상된 이미지이거나 읽을 수 없습니다",
                          "decode_failed")

    h, w = img.shape[:2]
    if h * w > MAX_PIXELS:
        raise UploadError(
            f"이미지가 너무 큽니다 ({w}×{h})", "image_too_large")
    if min(h, w) < MIN_SIDE:
        raise UploadError(
            f"이미지가 너무 작습니다 ({w}×{h}, 최소 {MIN_SIDE}px)",
            "image_too_small")

    meta = {
        "original_name": original_name,
        "size_bytes": size,
        "size_mb": round(size / 1024 / 1024, 2),
        "ext": ext,
        "sniffed_type": sniffed,
        "width": w, "height": h,
        "megapixels": round(w * h / 1e6, 2),
    }
    return img, data, meta


def save_bytes(data: bytes, directory, ext=".jpg", prefix="") -> dict:
    """UUID 파일명으로 안전하게 저장"""
    directory = Path(directory)
    directory.mkdir(parents=True, exist_ok=True)
    stored = f"{prefix}{uuid.uuid4().hex}{ext}"
    path = directory / stored
    path.write_bytes(data)
    return {"stored_name": stored, "path": path,
            "size_bytes": len(data)}


def save_image(img: np.ndarray, directory, ext=".jpg",
               prefix="", quality=92) -> dict:
    """numpy 이미지를 저장"""
    directory = Path(directory)
    directory.mkdir(parents=True, exist_ok=True)
    stored = f"{prefix}{uuid.uuid4().hex}{ext}"
    path = directory / stored
    params = ([cv2.IMWRITE_JPEG_QUALITY, quality]
              if ext in (".jpg", ".jpeg") else [])
    ok = cv2.imwrite(str(path), img, params)
    if not ok:
        raise UploadError("이미지 저장에 실패했습니다", "save_failed", 500)
    return {"stored_name": stored, "path": path,
            "size_bytes": path.stat().st_size}


def cleanup_old_files(directory, days=7, dry_run=False) -> dict:
    """오래된 파일 정리 — ★ 디스크 고갈 방지"""
    directory = Path(directory)
    if not directory.exists():
        return {"scanned": 0, "deleted": 0, "freed_mb": 0}

    cutoff = (datetime.now() - timedelta(days=days)).timestamp()
    scanned = deleted = 0
    freed = 0
    for p in directory.iterdir():
        if not p.is_file():
            continue
        scanned += 1
        if p.stat().st_mtime < cutoff:
            freed += p.stat().st_size
            if not dry_run:
                p.unlink(missing_ok=True)
            deleted += 1
    return {"scanned": scanned, "deleted": deleted,
            "freed_mb": round(freed / 1024 / 1024, 2),
            "dry_run": dry_run}
```

```python
def admin_storage():
    """★ 디스크 사용량 확인"""
    def dir_stats(path):
        path = Path(path)
        if not path.exists():
            return {"files": 0, "size_mb": 0, "oldest": None}
        files = [p for p in path.iterdir() if p.is_file()]
        size = sum(p.stat().st_size for p in files)
        oldest = min((p.stat().st_mtime for p in files), default=None)
        return {
            "files": len(files),
            "size_mb": round(size / 1024 / 1024, 2),
            "oldest": (datetime.fromtimestamp(oldest).isoformat(
                timespec="seconds") if oldest else None),
        }

    import shutil
    total, used, free = shutil.disk_usage(BASE)

        "results": dir_stats(RESULT_DIR),
        "meta": dir_stats(META_DIR),

            "used_gb": round(used / 1024**3, 1),
            "free_gb": round(free / 1024**3, 1),
            "used_pct": round(used / total * 100, 1),
```

```python
"""안전한 업로드"""
import io
import logging
import uuid
from pathlib import Path

import cv2
import numpy as np
from flask import Flask, jsonify, render_template, request
from werkzeug.utils import secure_filename

app = Flask(__name__)
app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024      # ★ 4
logging.basicConfig(level=logging.INFO)

BASE = Path(__file__).resolve().parent
UPLOAD = BASE / "static/uploads"
UPLOAD.mkdir(parents=True, exist_ok=True)                # ★ 9

ALLOWED = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}
MAGIC = [(b"\xff\xd8\xff", "jpg"), (b"\x89PNG\r\n\x1a\n", "png"),
         (b"BM", "bmp"), (b"RIFF", "webp")]


def sniff(head: bytes):
    for sig, name in MAGIC:
        if head.startswith(sig):
            if name == "webp" and head[8:12] != b"WEBP":
                continue
            return name
    return None


@app.route("/upload", methods=["POST"])
def upload():
    # ── ★ 7, 8 존재 확인 ──
    f = request.files.get("image")
    if f is None or not f.filename:
        return jsonify({"error": "no_file",
                        "message": "파일이 선택되지 않았습니다"}), 400

    # ── ★ 2 확장자 (소문자 + 화이트리스트) ──
    safe = secure_filename(f.filename)
    ext = Path(safe).suffix.lower() if safe else ""
    if ext not in ALLOWED:
        app.logger.warning("거부된 확장자: %r from %s",       # ★ 12
                           f.filename, request.remote_addr)
        return jsonify({"error": "unsupported_format",
                        "message": f"지원하지 않는 형식: {ext}",
                        "allowed": sorted(ALLOWED)}), 400

    # ── 크기 ──
    f.stream.seek(0, io.SEEK_END)
    size = f.stream.tell()
    f.stream.seek(0)
    if size == 0:
        return jsonify({"error": "empty_file"}), 400

    data = f.read()
    f.seek(0)

    # ── ★ 3 실제 내용 검증 ──
    if sniff(data[:16]) is None:
        app.logger.warning("이미지가 아닌 파일: %r from %s",
                           f.filename, request.remote_addr)
        return jsonify({"error": "not_an_image",
                        "message": "이미지 파일이 아닙니다"}), 400

    img = cv2.imdecode(np.frombuffer(data, np.uint8), cv2.IMREAD_COLOR)
    if img is None:
        return jsonify({"error": "decode_failed",
                        "message": "손상된 이미지입니다"}), 400

    h, w = img.shape[:2]
    if h * w > 50_000_000:
        return jsonify({"error": "image_too_large"}), 400

    # ── ★ 1, 5 UUID 파일명 (경로 조작·충돌 불가) ──
    stored = f"{uuid.uuid4().hex}{ext}"
    path = UPLOAD / stored
    try:                                                   # ★ 10
        path.write_bytes(data)
    except OSError:
        app.logger.exception("저장 실패")
        return jsonify({"error": "save_failed"}), 500

    app.logger.info("업로드 %s → %s (%dx%d, %.1fKB)",
                    f.filename, stored, w, h, size / 1024)

    # ── ★ 6 템플릿으로 반환 (자동 이스케이프) ──
    return render_template("uploaded.html",
                           filename=stored,
                           original=f.filename,
                           width=w, height=h)


@app.errorhandler(413)
def too_large(e):
    return jsonify({"error": "file_too_large", "max_mb": 16}), 413
```

```
  브라우저·사진 앱  → EXIF 를 읽어 회전해서 보여 줌
  ★ cv2.imread     → EXIF 를 무시 → 누운 채로 처리
```

**해결**

```python
from PIL import Image, ImageOps
import io
import cv2
import numpy as np


def load_image_with_exif(data: bytes) -> np.ndarray:
    """★ EXIF 회전을 반영해 디코딩"""
    pil = Image.open(io.BytesIO(data))
    pil = ImageOps.exif_transpose(pil)          # ★ 핵심
    pil = pil.convert("RGB")
    return cv2.cvtColor(np.array(pil), cv2.COLOR_RGB2BGR)
```

```
★ 검출에 미치는 영향

  누운 사진으로 추론하면
  · 사람이 가로로 누워 있는 것으로 보임
  · ★ 학습 데이터에 없는 방향 → 검출 실패
  · Recall 이 크게 떨어짐

→ ★ 반드시 EXIF 를 처리해야 합니다
```

```python
"""web/api_events.py"""
import json
import sqlite3
from datetime import datetime, timedelta
from pathlib import Path

from flask import Blueprint, current_app, jsonify, request

from upload_utils import UploadError, validate_and_decode, save_bytes

bp = Blueprint("api_events", __name__, url_prefix="/api")

REQUIRED = ("event_id", "device_id", "ts", "type")
MAX_EVENT_JSON = 64 * 1024               # ★ JSON 크기 제한


def get_db():
    db = sqlite3.connect(current_app.config["DB_PATH"])
    db.row_factory = sqlite3.Row
    return db


def init_db(path):
    db = sqlite3.connect(path)
    db.executescript("""
        CREATE TABLE IF NOT EXISTS events (
            event_id      TEXT PRIMARY KEY,     -- ★ 중복 방지
            device_id     TEXT NOT NULL,
            ts            TEXT NOT NULL,
            type          TEXT NOT NULL,
            classes_json  TEXT NOT NULL,
            max_conf      REAL,
            snapshot_name TEXT,
            payload_json  TEXT NOT NULL,
            received_at   TEXT DEFAULT (datetime('now'))
        );
        CREATE INDEX IF NOT EXISTS idx_events_ts ON events(ts);
        CREATE INDEX IF NOT EXISTS idx_events_device
            ON events(device_id, ts);
        CREATE INDEX IF NOT EXISTS idx_events_type ON events(type);
    """)
    db.commit()
    db.close()


@bp.post("/events")
def receive_event():
    """★ 파이가 이벤트를 전송 — 멱등 처리"""
    # ── ① JSON 파싱 ──
    raw = request.form.get("event")
    if not raw:
        return jsonify({"ok": False, "error": "missing_event",
                        "message": "event 필드가 없습니다"}), 400
    if len(raw) > MAX_EVENT_JSON:
        return jsonify({"ok": False, "error": "event_too_large"}), 413

    try:
        event = json.loads(raw)
    except json.JSONDecodeError as e:
        return jsonify({"ok": False, "error": "invalid_json",
                        "message": str(e)}), 400

    # ── ② 필수 필드 ──
    missing = [k for k in REQUIRED if k not in event or not event[k]]
    if missing:
        return jsonify({"ok": False, "error": "missing_fields",
                        "message": f"필수 필드 누락: {missing}",
                        "required": list(REQUIRED)}), 400

    event_id = str(event["event_id"])
    if not (8 <= len(event_id) <= 64):
        return jsonify({"ok": False, "error": "invalid_event_id"}), 400

    # ── ③ 시각 검증 ──
    try:
        ts = datetime.fromisoformat(event["ts"])
    except ValueError:
        return jsonify({"ok": False, "error": "invalid_timestamp",
                        "message": "ts 는 ISO 8601 형식이어야 합니다"}), 400

    # ★ 미래 시각 방어 (시계 오차 5분 허용)
    if ts.replace(tzinfo=None) > datetime.now() + timedelta(minutes=5):
        return jsonify({"ok": False, "error": "future_timestamp"}), 400

    # ── ④ ★ 멱등성 — 이미 있으면 200 ──
    db = get_db()
    try:
        row = db.execute("SELECT event_id FROM events WHERE event_id = ?",
                         (event_id,)).fetchone()
        if row:
            current_app.logger.info("중복 이벤트 무시: %s", event_id)
            return jsonify({"ok": True, "event_id": event_id,
                            "duplicate": True}), 200

        # ── ⑤ 스냅샷 (선택) ──
        snapshot_name = None
        snap = request.files.get("snapshot")
        if snap and snap.filename:
            try:
                img, data, meta = validate_and_decode(snap)
            except UploadError as e:
                return jsonify({"ok": False, "error": e.code,
                                "message": e.message}), e.status

            # ★ 날짜별 폴더 (파일 수 분산)
            sub = Path(ts.strftime("%Y/%m/%d"))
            snap_dir = Path(current_app.config["SNAPSHOT_DIR"]) / sub
            saved = save_bytes(data, snap_dir, meta["ext"], prefix="")
            snapshot_name = str(sub / saved["stored_name"]).replace("\\", "/")

        # ── ⑥ 저장 ──
        classes = event.get("classes", {})
        db.execute("""
            INSERT INTO events
                (event_id, device_id, ts, type, classes_json,
                 max_conf, snapshot_name, payload_json)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
        """, (event_id, str(event["device_id"]), event["ts"],
              str(event["type"]), json.dumps(classes, ensure_ascii=False),
              event.get("max_conf"), snapshot_name,
              json.dumps(event, ensure_ascii=False)))
        db.commit()
    except sqlite3.IntegrityError:
        # ★ 동시 요청으로 PK 충돌 → 중복으로 처리
        return jsonify({"ok": True, "event_id": event_id,
                        "duplicate": True}), 200
    except Exception:
        current_app.logger.exception("이벤트 저장 실패")
        return jsonify({"ok": False, "error": "internal_error"}), 500
    finally:
        db.close()

    current_app.logger.info("이벤트 수신 %s from %s (%s)",
                            event_id, event["device_id"], event["type"])
    return jsonify({"ok": True, "event_id": event_id}), 201


@bp.get("/events")
def list_events():
    """이력 조회"""
    limit = min(request.args.get("limit", type=int, default=50), 500)
    offset = max(request.args.get("offset", type=int, default=0), 0)
    device = request.args.get("device")
    etype = request.args.get("type")
    date_from = request.args.get("from")
    date_to = request.args.get("to")

    where, params = [], []
    if device:
        where.append("device_id = ?"); params.append(device)
    if etype:
        where.append("type = ?"); params.append(etype)
    if date_from:
        where.append("ts >= ?"); params.append(date_from)
    if date_to:
        where.append("ts <= ?"); params.append(date_to + "T23:59:59")

    clause = ("WHERE " + " AND ".join(where)) if where else ""

    db = get_db()
    try:
        total = db.execute(
            f"SELECT COUNT(*) c FROM events {clause}", params).fetchone()["c"]
        rows = db.execute(
            f"""SELECT event_id, device_id, ts, type, classes_json,
                       max_conf, snapshot_name
                FROM events {clause}
                ORDER BY ts DESC LIMIT ? OFFSET ?""",
            params + [limit, offset]).fetchall()
    finally:
        db.close()

    items = []
    for r in rows:
        items.append({
            "event_id": r["event_id"], "device_id": r["device_id"],
            "ts": r["ts"], "type": r["type"],
            "classes": json.loads(r["classes_json"]),
            "max_conf": r["max_conf"],
            "snapshot_url": (f"/static/snapshots/{r['snapshot_name']}"
                             if r["snapshot_name"] else None),
        })

    return jsonify({"total": total, "returned": len(items),
                    "offset": offset, "limit": limit,
                    "has_more": offset + len(items) < total,
                    "items": items})
```

### 파이 쪽 전송 (재시도 큐)

```python
"""pi/sync.py — 실패 시 로컬 큐에 보관 후 재전송"""
import json
import logging
import sqlite3
import threading
import time
from pathlib import Path

import requests

logger = logging.getLogger(__name__)


class EventSync:
    """★ 네트워크가 끊겨도 이벤트를 잃지 않는다"""

    def __init__(self, server_url, queue_db="queue.db",
                 timeout=5.0, retry_interval=30, max_retries=100):
        self.url = server_url.rstrip("/") + "/api/events"
        self.timeout = timeout
        self.retry_interval = retry_interval
        self.max_retries = max_retries
        self.db_path = queue_db
        self._init_db()
        self._stop = threading.Event()
        threading.Thread(target=self._retry_loop, daemon=True).start()

    def _init_db(self):
        db = sqlite3.connect(self.db_path)
        db.execute("""
            CREATE TABLE IF NOT EXISTS queue (
                event_id  TEXT PRIMARY KEY,
                payload   TEXT NOT NULL,
                snapshot  TEXT,
                attempts  INTEGER DEFAULT 0,
                last_try  REAL DEFAULT 0,
                created   REAL DEFAULT (strftime('%s','now'))
            )""")
        db.commit()
        db.close()

    def send(self, event: dict, snapshot_path=None) -> bool:
        """즉시 전송 시도. 실패하면 큐에 저장."""
        if self._post(event, snapshot_path):
            return True
        self._enqueue(event, snapshot_path)
        return False

    def _post(self, event, snapshot_path) -> bool:
        files = {}
        fh = None
        try:
            data = {"event": json.dumps(event, ensure_ascii=False)}
            if snapshot_path and Path(snapshot_path).exists():
                fh = open(snapshot_path, "rb")
                files["snapshot"] = (Path(snapshot_path).name, fh,
                                     "image/jpeg")
            r = requests.post(self.url, data=data, files=files,
                              timeout=self.timeout)
            # ★ 201(신규) · 200(중복) 모두 성공으로 처리
            if r.status_code in (200, 201):
                return True
            if 400 <= r.status_code < 500:
                # ★ 클라이언트 오류는 재시도해도 소용없음
                logger.error("전송 거부(재시도 안 함) %s: %s",
                             r.status_code, r.text[:200])
                return True                     # 큐에서 제거
            logger.warning("전송 실패 %s", r.status_code)
            return False
        except requests.RequestException as e:
            logger.warning("전송 오류: %s", e)
            return False
        finally:
            if fh:
                fh.close()

    def _enqueue(self, event, snapshot_path):
        db = sqlite3.connect(self.db_path)
        try:
            db.execute(
                "INSERT OR IGNORE INTO queue (event_id, payload, snapshot) "
                "VALUES (?, ?, ?)",
                (event["event_id"],
                 json.dumps(event, ensure_ascii=False),
                 str(snapshot_path) if snapshot_path else None))
            db.commit()
            logger.info("큐에 보관: %s", event["event_id"])
        finally:
            db.close()

    def _retry_loop(self):
        while not self._stop.wait(self.retry_interval):
            try:
                self._flush()
            except Exception:
                logger.exception("재전송 루프 오류")

    def _flush(self):
        db = sqlite3.connect(self.db_path)
        db.row_factory = sqlite3.Row
        try:
            rows = db.execute(
                "SELECT * FROM queue WHERE attempts < ? "
                "ORDER BY created LIMIT 20",
                (self.max_retries,)).fetchall()
        finally:
            db.close()

        if not rows:
            return
        logger.info("재전송 시도 %d건", len(rows))

        for row in rows:
            event = json.loads(row["payload"])
            ok = self._post(event, row["snapshot"])
            db = sqlite3.connect(self.db_path)
            try:
                if ok:
                    db.execute("DELETE FROM queue WHERE event_id = ?",
                               (row["event_id"],))
                else:
                    db.execute(
                        "UPDATE queue SET attempts = attempts + 1, "
                        "last_try = strftime('%s','now') WHERE event_id = ?",
                        (row["event_id"],))
                db.commit()
            finally:
                db.close()

    def pending_count(self) -> int:
        db = sqlite3.connect(self.db_path)
        try:
            return db.execute("SELECT COUNT(*) FROM queue").fetchone()[0]
        finally:
            db.close()

    def stop(self):
        self._stop.set()
```

### ★ 멱등성이 핵심인 이유

```
시나리오
  1. 파이가 이벤트 전송
  2. 서버가 DB 에 저장 (성공)
  3. ★ 응답이 오는 도중 네트워크 끊김
  4. 파이는 "실패"로 판단 → 큐에 보관
  5. 30초 뒤 재전송
  6. ★ 서버에는 이미 있음

  → 409 Conflict 로 주면?
     파이가 "오류"로 판단 → 계속 재시도 → ★ 무한 루프

  → ★ 200 + duplicate: true 로 주면
     파이가 "성공"으로 처리 → 큐에서 제거 → 정상
```

### 저장 용량 관리

```python
@bp.post("/admin/cleanup")
def cleanup_events():
    """★ 30일 이전 이벤트·스냅샷 삭제"""
    days = request.form.get("days", type=int, default=30)
    cutoff = (datetime.now() - timedelta(days=days)).isoformat()

    db = get_db()
    try:
        rows = db.execute(
            "SELECT event_id, snapshot_name FROM events WHERE ts < ?",
            (cutoff,)).fetchall()

        snap_root = Path(current_app.config["SNAPSHOT_DIR"])
        deleted_files = 0
        for r in rows:
            if r["snapshot_name"]:
                p = snap_root / r["snapshot_name"]
                if p.exists():
                    p.unlink()
                    deleted_files += 1

        db.execute("DELETE FROM events WHERE ts < ?", (cutoff,))
        db.commit()

        # ★ 빈 날짜 폴더 정리
        for d in sorted(snap_root.rglob("*"), reverse=True):
            if d.is_dir() and not any(d.iterdir()):
                d.rmdir()
    finally:
        db.close()

    return jsonify({"ok": True, "deleted_events": len(rows),
                    "deleted_files": deleted_files, "days": days})
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| GET vs POST | 조회 vs **부작용 있음** · 파일은 **POST** |
| ★ `enctype` | **`multipart/form-data`** — 없으면 파일 안 옴 |
| `request.files` | `FileStorage` (form 아님) |
| `f.read()` 후 | ★ **`f.seek(0)`** |
| 검증 1 | 존재 (필드 + filename) |
| 검증 2 | ★ **확장자 화이트리스트** (블랙리스트 ✗) |
| 검증 3 | `MAX_CONTENT_LENGTH` → **413** |
| ★ 검증 4 | **매직 넘버 + 실제 디코딩** |
| 픽셀 제한 | 디컴프레션 폭탄 방지 |
| `secure_filename` | 경로 조작 제거 · ★ **한글 소실** |
| ★ 저장 파일명 | **UUID** · 원본명은 별도 보관 |
| ★ PRG | POST → **redirect** → GET |
| 플래시 | `secret_key` 필수 · 1회 표시 |
| ★ EXIF | **`ImageOps.exif_transpose`** — 휴대폰 사진 |
| 전역 변수 | ★ **금지** — 동시 요청에 뒤바뀜 |
| 멱등성 | 같은 ID 재전송 → **200 + duplicate** |
| 정리 | 오래된 파일 **자동 삭제** |
| 클라이언트 검증 | ★ **UX 용.** 서버 검증이 진짜 |
| 로깅 | 거부된 업로드를 ★ **기록** |
