### 3-5. 코드 컨벤션

**왜 필요한가** — 남의 코드를 읽을 수 있다.

```
   ★ Day 99에서 정한 것을 문서로
```

| 대상 | 규칙 | 예 |
|---|---|---|
| 클래스 | PascalCase | `PlayerController` |
| 메서드 | PascalCase | `TakeDamage()` |
| public 필드/속성 | PascalCase | `MaxHp` |
| private 필드 | camelCase | `currentHp` |
| `[SerializeField]` private | camelCase | `moveSpeed` |
| 상수 | PascalCase | `MaxLevel` |
| 지역 변수 | camelCase | `targetPos` |
| 인터페이스 | I + PascalCase | `IDamageable` |
| enum | PascalCase | `GameState.Playing` |
| 이벤트 | On + 동사 | `OnPlayerDied` |

```
   ★ 파일 구조 순서

   1. using
   2. namespace
   3. 클래스
      a. 상수
      b. [SerializeField] 필드
      c. private 필드
      d. 속성
      e. 이벤트
      f. Unity 생명주기 (Awake → Start → Update → ...)
      g. public 메서드
      h. private 메서드
```

```csharp
using UnityEngine;

namespace OneFloor.Player
{
    [RequireComponent(typeof(Rigidbody))]
    public class PlayerController : MonoBehaviour
    {
        // ─── 상수 ───
        private const float MinMoveThreshold = 0.01f;

        // ─── Inspector ───
        [Header("이동")]
        [SerializeField] private float moveSpeed = 6f;
        [SerializeField] private float rotationSpeed = 12f;

        // ─── 내부 상태 ───
        private Rigidbody rb;
        private Vector3 inputDir;

        // ─── 속성 ───
        public bool IsMoving => inputDir.sqrMagnitude > MinMoveThreshold;

        // ─── 이벤트 ───
        public event System.Action OnPlayerDied;

        // ─── 생명주기 ───
        private void Awake() { rb = GetComponent<Rigidbody>(); }
        private void Update() { ReadInput(); }
        private void FixedUpdate() { Move(); }

        // ─── public ───
        public void TakeDamage(int amount) { }

        // ─── private ───
        private void ReadInput() { }
        private void Move() { }
    }
}
```

```
   ★ 금지 사항 (Part 2·3에서 배운 것)

   × 매 프레임 문자열 생성          (Day 89)
```

### 3-8. 매니저 초기화 순서

**왜 필요한가** — Day 72의 Awake/Start 문제.

```
   ★ 문제

   GameManager가 PoolManager를 Awake에서 참조
   → PoolManager의 Awake가 먼저 돌았는지 보장 없음
```

```
   ★ 해결 1 — Script Execution Order

   Project Settings → Script Execution Order
   → PoolManager: -100
   → GameManager: -50
   → 나머지: 0
```

```
   ★ 해결 2 — 부트스트랩 패턴 (권장)
```

```csharp
namespace OneFloor.Core
{
    public class Bootstrap : MonoBehaviour
    {
        [SerializeField] private PoolManager poolManager;
        [SerializeField] private AudioManager audioManager;
        [SerializeField] private GameManager gameManager;

        private void Awake()
        {
            // ★ 순서를 명시적으로 제어
            poolManager.Initialize();
            audioManager.Initialize();
            gameManager.Initialize();
        }
    }
}
```

```
   ★ 각 매니저는 Awake에서 아무것도 하지 않는다
```

### 3-10. 화면 디버그 HUD

**왜 필요한가** — 빌드에서도 상태를 본다.

```csharp
namespace OneFloor.Core
{
    public class DebugHUD : MonoBehaviour
    {
        [SerializeField] private bool showByDefault = true;
        [SerializeField] private KeyCode toggleKey = KeyCode.F3;

        private bool visible;
        private float fps;
        private readonly System.Text.StringBuilder sb = new System.Text.StringBuilder();

        private void Awake()
        {
#if UNITY_EDITOR || DEVELOPMENT_BUILD
            visible = showByDefault;
#else
            gameObject.SetActive(false);        // ★ 릴리즈에서는 비활성
#endif
        }

        private void Update()
        {
            if (Input.GetKeyDown(toggleKey)) visible = !visible;

            fps = Mathf.Lerp(fps, 1f / Time.unscaledDeltaTime, 0.1f);
        }

        private void OnGUI()
        {
            if (!visible) return;

            sb.Clear();
            sb.AppendLine($"FPS   {fps:F1}");
            sb.AppendLine($"Frame {Time.unscaledDeltaTime * 1000f:F1} ms");
            sb.AppendLine($"Objects {UnityEngine.Object.FindObjectsByType<Transform>(FindObjectsSortMode.None).Length}");

            GUI.Label(new Rect(10, 10, 400, 200), sb.ToString(),
                      new GUIStyle(GUI.skin.label) { fontSize = 15 });
        }
    }
}
```

```
   ⚠️ FindObjectsByType은 느리다

   → 실제로는 주기적으로만 갱신 (Day 88)
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **다른 PC에서 참조 깨짐** | `.meta` 미커밋 | `.gitignore` 확인 |
| 프로젝트 강제 업그레이드 | Unity 버전 불일치 | 버전 통일 |
| 저장소가 수 GB | `Library/` 커밋 | `git rm -r --cached Library` |
| 이식 후 컴파일 오류 | 의존성 누락 | Export 시 의존성 포함 |
| 이식 후 참조 끊김 | `.meta` 없이 복사 | 함께 복사 |
| 매니저 null | 초기화 순서 | Bootstrap 패턴 |
| 빌드 실패 | 컴파일 오류 | Console 첫 오류부터 |
| 씬이 안 열림 | Scene List 미등록 | 등록 |
| push 인증 실패 | 비밀번호 방식 폐지 | Personal Access Token |
| 폴더 이동 후 참조 끊김 | 탐색기에서 이동 | Unity 안에서 이동 |
