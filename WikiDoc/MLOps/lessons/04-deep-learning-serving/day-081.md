## ② 왜 필요한가

이번 주부터 진짜 딥러닝의 판(이미지)입니다. 그리고 이 판의 상수(常數)가 하나 있습니다 —
**모델의 파라미터가 데이터보다 압도적으로 많다**는 것.

```
오늘의 실습:  파라미터 1,578,506개  vs  학습 이미지 4,000장     (394배)
```

[Day 052](../03-machine-learning/day-052.md)의 언어로 말하면, 이 모델은 4,000장을 통째로
**암기할 능력**이 있습니다. 실제로 오늘 train 정확도 96%를 찍는 동안 valid는 41%에 머무는
장면을 보게 됩니다. 딥러닝 실무의 기본기는 화려한 구조가 아니라 **이 간격을 읽고 다스리는
기술**이고, 주간 체크포인트("검증 손실이 오르기 시작할 때 무엇을 할지 3가지")가 그 시험입니다.

다행히 개념은 전부 재회입니다: 과적합 게이지([Day 054](../03-machine-learning/day-054.md)),
가중치 벌점(Ridge의 L2 = 오늘의 weight decay), 조기 종료([Day 059](../03-machine-learning/day-059.md) 부스팅,
[Day 079](day-079.md) 체크포인트). 오늘은 그것들이 신경망 세계에서 어떤 얼굴인지 확인하는 날입니다.

## ③ 개념 설명

### 학습 곡선의 세 얼굴

에폭마다 train/valid 지표를 찍으면 곡선 모양이 진단서가 됩니다.

```
과소적합         적정                과적합
train 낮음      train 높음           train ↑↑ (계속 상승)
valid 낮음      valid 비슷하게 높음   valid ⌒ (오르다 꺾여 내려감)
→ 더 크게/오래   → 여기서 멈춰라      → 간격이 벌어지는 지점부터는 암기
```

**"검증 손실이 오르기 시작하면?"** 의 답 (3가지 이상):

| 대응 | 무엇을 하나 | 어디서 배웠나 |
|---|---|---|
| **조기 종료** | 최고 valid 시점의 가중치로 되돌림 | [Day 079](day-079.md) 과제의 체크포인트 |
| **드롭아웃** | 학습 중 뉴런을 무작위로 꺼서 암기 방해 | 오늘 |
| **가중치 감쇠** | 큰 가중치에 벌점 (L2 = Ridge의 그것) | [Day 054](../03-machine-learning/day-054.md) |
| 데이터 증강 | 이미지를 뒤집고 잘라 데이터를 불림 | 오늘 과제 (Colab) |
| 모델 축소 | 파라미터를 줄임 | [Day 058](../03-machine-learning/day-058.md)의 가지치기와 같은 정신 |

### 드롭아웃 — 의도된 방해 공작

`nn.Dropout(0.5)`: **학습 순전파마다** 그 층 출력의 절반을 무작위로 0으로 만듭니다.
특정 뉴런 조합에 기대는 암기가 불가능해져, 여러 경로에 분산된 일반적 특징을 배우게 됩니다.

핵심 규칙: 드롭아웃은 **학습 때만**. 평가·서빙에서는 전부 켜야 하며, 그 전환이
`model.train()` / `model.eval()` 입니다 — [Day 079](day-079.md)에서 "지금은 차이 없지만
곧 중요해진다"던 그 스위치가 오늘부터 실제로 일합니다.

### 가중치 감쇠 — Ridge의 재회

`optim.Adam(..., weight_decay=1e-4)` — 손실에 계수² 벌점을 더하는 것과 같은 효과입니다.
[Day 054](../03-machine-learning/day-054.md)에서 "과적합의 전형은 계수가 비정상적으로 커지는 것"
이라 했던 진단과 처방이 신경망에도 그대로 적용됩니다.

### Step 1. 이번 주의 데이터 — CIFAR-10 (1교시)

```python
# day081_overfit.py — 과적합 제어
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, Subset
from torchvision import datasets, transforms

torch.manual_seed(42)

print("== A. 이번 주의 데이터: CIFAR-10 ==")
tf = transforms.Compose([
    transforms.ToTensor(),                                    # PIL → (3,32,32) 텐서, 0~1
    transforms.Normalize((0.49, 0.48, 0.45), (0.25, 0.24, 0.26)),   # 채널별 표준화
])
full = datasets.CIFAR10("data", train=True, transform=tf)
test_set = datasets.CIFAR10("data", train=False, transform=tf)
print(f"train 원본 {len(full)}장 · test {len(test_set)}장 · 클래스: {full.classes}")
x0, y0 = full[0]
print(f"이미지 한 장: shape {tuple(x0.shape)} (채널, 높이, 너비) · 라벨 {y0} = {full.classes[y0]}")

# CPU 실습용 축소: 학습 4,000 / 검증 1,000 (GPU라면 전체 5만 장으로)
train_ds = Subset(full, range(0, 4000))
valid_ds = Subset(full, range(45000, 46000))
train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
valid_dl = DataLoader(valid_ds, batch_size=512)
print(f"실습 규모: train {len(train_ds)} / valid {len(valid_ds)}")
```

실행 결과:

```
== A. 이번 주의 데이터: CIFAR-10 ==
train 원본 50000장 · test 10000장 · 클래스: ['airplane', 'automobile', 'bird', 'cat', 'deer', 'dog', 'frog', 'horse', 'ship', 'truck']
이미지 한 장: shape (3, 32, 32) (채널, 높이, 너비) · 라벨 6 = frog
실습 규모: train 4000 / valid 1000
```

`transforms.Compose` 가 이미지 세계의 전처리 파이프라인입니다 — ToTensor(픽셀 0~255 → 0~1)
+ 채널별 표준화. [Day 077](day-077.md)의 교훈(경사하강엔 표준화)이 여기서도 관례로 박혀 있고,
이 transform은 **서빙에서도 똑같이** 적용돼야 합니다 ([Day 097](day-097.md)의 복선).
첫 다운로드는 170MB — 받는 동안 클래스 10종을 훑어 두세요.

### Step 2. 과적합 극장 — 민낯의 MLP (2~4교시)

지난주의 MLP를 규제 없이 이미지에 던집니다. 학습 함수는 에폭마다 train/valid 정확도를
같이 찍습니다 (= 학습 곡선).

```python
def accuracy(model, dl):
    model.eval()
    hit = n = 0
    with torch.no_grad():
        for xb, yb in dl:
            hit += (model(xb).argmax(dim=1) == yb).sum().item()
            n += len(yb)
    model.train()
    return hit / n


def train(model, epochs=15, weight_decay=0.0):
    opt = torch.optim.Adam(model.parameters(), lr=0.001, weight_decay=weight_decay)
    loss_fn = nn.CrossEntropyLoss()
    best_va, best_ep = 0.0, 0
    for epoch in range(1, epochs + 1):
        for xb, yb in train_dl:
            loss = loss_fn(model(xb), yb)
            loss.backward()
            opt.step()
            opt.zero_grad()
        tr_acc, va_acc = accuracy(model, train_dl), accuracy(model, valid_dl)
        if va_acc > best_va:
            best_va, best_ep = va_acc, epoch
        if epoch in (1, 3, 5, 10, 15):
            print(f"  epoch {epoch:>2}: train {tr_acc:.3f} · valid {va_acc:.3f} · 간격 {tr_acc-va_acc:+.3f}")
    print(f"  → 최고 valid {best_va:.3f} (epoch {best_ep})")
    return best_va


print("\n== B. 민낯의 MLP — 과적합 극장 ==")
mlp = nn.Sequential(
    nn.Flatten(),                     # (3,32,32) → (3072,)
    nn.Linear(3072, 512), nn.ReLU(),
    nn.Linear(512, 10),
)
print(f"파라미터 {sum(p.numel() for p in mlp.parameters()):,}개 vs 학습 이미지 4,000장")
train(mlp)
```

실행 결과:

```
== B. 민낯의 MLP — 과적합 극장 ==
파라미터 1,578,506개 vs 학습 이미지 4,000장
  epoch  1: train 0.453 · valid 0.354 · 간격 +0.099
  epoch  3: train 0.643 · valid 0.409 · 간격 +0.234
  epoch  5: train 0.769 · valid 0.406 · 간격 +0.363
  epoch 10: train 0.915 · valid 0.431 · 간격 +0.484
  epoch 15: train 0.964 · valid 0.412 · 간격 +0.552
  → 최고 valid 0.431 (epoch 10)
```

곡선을 읽으세요. train은 0.45 → **0.96** 직진 (4,000장 암기 진행 중). valid는 0.43 근처에서
멈추다 **내려갑니다** (epoch 10 정점 → 15에서 0.412). 간격 +0.55 — 교과서적 과적합입니다.
[Day 078](day-078.md)에서 test로 훔쳐보던 이 곡선을, 지금은 valid로 합법 관측하고 있다는 것도
확인하세요.

### Step 3. 규제 투입 — 드롭아웃 + 가중치 감쇠 (5~6교시)

```python
print("\n== C. 드롭아웃 + 가중치 감쇠 ==")
reg_mlp = nn.Sequential(
    nn.Flatten(),
    nn.Linear(3072, 512), nn.ReLU(),
    nn.Dropout(0.5),                      # 학습 때만 뉴런 절반을 무작위로 끔
    nn.Linear(512, 10),
)
train(reg_mlp, weight_decay=1e-4)
```

실행 결과:

```
== C. 드롭아웃 + 가중치 감쇠 ==
  epoch  1: train 0.426 · valid 0.347 · 간격 +0.079
  epoch  3: train 0.553 · valid 0.390 · 간격 +0.163
  epoch  5: train 0.636 · valid 0.415 · 간격 +0.221
  epoch 10: train 0.751 · valid 0.438 · 간격 +0.313
  epoch 15: train 0.795 · valid 0.397 · 간격 +0.398
  → 최고 valid 0.438 (epoch 10)
```

비교표로 정리하면:

| | 민낯 | 규제 (드롭아웃+감쇠) |
|---|---|---|
| train (15에폭) | 0.964 | 0.795 — **암기가 방해받음** |
| 간격 | +0.552 | +0.398 — 좁아짐 |
| 최고 valid | 0.431 | 0.438 — **+0.007뿐** |

여기서 오늘의 가장 중요한 통찰이 나옵니다. 규제는 간격을 확실히 줄였지만(0.55 → 0.40),
**최고 valid는 거의 그대로**(0.43대)입니다. 이 모델의 문제는 암기(분산)만이 아니라
**표현의 방식 자체**이기 때문입니다 — Flatten이 이미지를 3,072개의 무관한 숫자로 펴 버려서,
"고양이 귀가 어디에 있든 고양이"라는 공간 구조를 배울 수 없습니다. 규제로는 상한을 못
올립니다. 상한을 올리는 것은 **구조**이고, 그것이 내일의 CNN입니다.

## ⑤ 자주 하는 실수

### eval() 없이 평가해 점수가 출렁임

**증상** — 같은 모델을 두 번 평가했는데 valid 정확도가 다름 (드롭아웃 도입 후부터).
**원인** — train 모드에서는 드롭아웃이 평가 중에도 뉴런을 끕니다 — 예측이 무작위로 흔들립니다.
**해결** — [Day 079](day-079.md)의 evaluate 함수처럼 eval()/train() 전환을 함수 안에 내장. 서빙에서 eval()을 잊으면 **운영 예측이 흔들리는** 사고가 됩니다 ([Day 096](day-096.md)에서 재점검).

### 드롭아웃을 아무 데나 꽂음

**증상** — 출력층 직후에 Dropout을 넣어 확률의 절반이 0이 되거나, 너무 여러 겹 넣어 과소적합.
**원인** — 드롭아웃의 자리는 관례가 있습니다.
**해결** — 은닉층 활성화 **뒤**, 출력층 **앞**이 기본 자리. 비율은 0.2~0.5에서 시작. 과소적합 신호(train조차 낮음)면 비율을 낮추거나 뺍니다.

### 간격만 보고 성공을 선언

**증상** — "간격이 0.55에서 0.40으로! 규제 성공!" — 그런데 valid는 0.431 → 0.438.
**원인** — 목표는 간격 축소가 아니라 **valid(일반화 성능) 상승**입니다. 간격은 진단 지표일 뿐.
**해결** — 보고 기준은 항상 최고 valid. 간격이 줄어도 valid가 안 오르면 "분산 문제가 아니라 표현력·데이터 문제"라는 진단으로 넘어갑니다 (오늘의 결론).

### weight_decay를 손실 코드에 또 구현

**증상** — 손실에 L2 항을 직접 더했는데 optimizer에도 weight_decay가 켜져 있어 이중 벌점.
**원인** — 같은 기능이 두 자리에 있을 수 있음을 모름.
**해결** — PyTorch에서는 optimizer 인자 하나로 끝냅니다. 손실 수식은 건드리지 않는 것이 관례입니다.

### 규제를 켠 채 train 정확도가 낮다고 당황

**증상** — "train이 0.795밖에 안 나와요. 학습이 안 되는 건가요?"
**원인** — 그게 규제가 **일하고 있다**는 신호입니다. 드롭아웃 켠 학습 중 지표는 원래 낮게 나옵니다.
**해결** — 판단은 valid로. train 지표는 "암기 진행률"로만 읽으세요 — train이 100%에 붙어 있는 쪽이 오히려 경보입니다.

<summary>답 보기</summary>
