## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

### 왜 가능한가

```
ImageNet: 1,400만 장, 1,000개 클래스로 학습된 모델
  → 엣지, 질감, 무늬, 부분 형태를 이미 알고 있음

늑대 vs 허스키
  → "동물의 털 질감", "귀 모양", "눈 형태"를 새로 배울 필요 없음
  → 이미 아는 특징들을 어떻게 조합할지만 배우면 됨
```

**[Day 089](day-089.md)에서 확인한 것**

```
층 1 → 엣지, 색 변화
층 2 → 모서리, 곡선
층 3 → 질감
층 4 → 부분
층 5 → 물체 전체
```

**앞쪽 층은 어떤 이미지에나 공통입니다.** 그래서 가져다 쓸 수 있습니다.

### 실무에서 밑바닥 학습은 거의 안 합니다

```
데이터 100만 장 이상 + GPU 여러 대 + 며칠  → 밑바닥 학습
```

## ③ 개념 설명

### 사전학습 모델 (Pre-trained Model)

**대규모 데이터로 미리 학습해 둔 모델입니다.**

```
ImageNet (ILSVRC)
  이미지 1,400만 장
  클래스 1,000개 (개 품종만 120종, 고양이, 자동차, 가구 …)
  학습에 GPU 수십 대 × 며칠
```

**이 학습 결과(가중치)를 공개해 둔 것을 가져다 씁니다.**

```python
base = keras.applications.MobileNetV2(weights="imagenet")
# 처음 실행 시 가중치 파일을 다운로드 (약 14MB)
```

| `weights` 값 | 의미 |
|---|---|
| `"imagenet"` | **ImageNet 사전학습 가중치** |
| `None` | 무작위 초기화 (구조만 사용) |
| 파일 경로 | 직접 저장한 가중치 |

### 왜 남의 모델이 도움이 되는가

**핵심 — 저수준 특징은 공통입니다.**

```
    ImageNet 모델이 배운 것          내 문제(늑대 vs 허스키)에 필요한 것
층1  엣지, 색 변화                    엣지, 색 변화              ← 동일
층2  모서리, 곡선                     모서리, 곡선               ← 동일
층3  질감, 무늬                       털 질감                    ← 거의 동일
층4  부분 (눈, 귀, 바퀴)              눈, 귀, 코                 ← 상당 부분 공통
층5  물체 전체 (1000종)               늑대/허스키                ← 여기만 다름
```

**앞쪽 4개 층은 그대로 쓰고 마지막만 바꾸면 됩니다.**

**시각적 근거** — 학습된 첫 층 필터는 어떤 데이터셋이든 비슷합니다.

```
ImageNet으로 학습한 conv1 필터  ≈  MNIST로 학습한 conv1 필터
                                 ≈  의료 영상으로 학습한 conv1 필터
                                 → 전부 엣지 검출기
```

**[Day 089](day-089.md)에서 학습된 필터가 소벨과 유사도 0.82였던 것**과 같은 이야기입니다.

### 전이학습의 두 가지 방식

**① 특징 추출 (Feature Extraction) — 오늘 배웁니다**

```
[사전학습 모델] → 동결(freeze)
       ↓
[새 분류기]    → 학습
```

```python
base.trainable = False              # 사전학습 부분을 고정
model = keras.Sequential([
    base,
    layers.GlobalAveragePooling2D(),
    layers.Dense(n_classes, activation="softmax"),   # 이것만 학습
])
```

**② 미세조정 (Fine-tuning) — [Day 099](day-099.md)**

```
[사전학습 모델 상위층] → 해제하고 낮은 학습률로 재학습
[사전학습 모델 하위층] → 동결 유지
[새 분류기]           → 학습
```

| | 특징 추출 | 미세조정 |
|---|---|---|
| 학습 파라미터 | 분류기만 (수천~수만) | 상위층 + 분류기 (수십만~) |
| 속도 | **매우 빠름** | 느림 |
| 데이터 요구량 | **적음 (수백 장)** | 중간 (수천 장) |
| 성능 | 좋음 | **더 좋음** |
| 과적합 위험 | 낮음 | 중간 |
| 순서 | **먼저 이것** | 그다음 |

> **반드시 특징 추출을 먼저 하고, 그다음 미세조정합니다.** ([Day 099](day-099.md))
> 분류기가 무작위 상태에서 미세조정하면 사전학습 가중치가 망가집니다.

### include_top

```python
base = keras.applications.MobileNetV2(
    weights="imagenet",
    include_top=False,           # ★ 1000클래스 분류기를 뺌
    input_shape=(224, 224, 3),
)
```

| `include_top` | 출력 |
|---|---|
| `True` (기본) | `(None, 1000)` — ImageNet 1000클래스 확률 |
| **`False`** | **`(None, 7, 7, 1280)`** — 특징맵 |

**`include_top=False` 로 특징 추출부만 가져옵니다.**

```
MobileNetV2 전체 : 3,538,984 파라미터
include_top=False : 2,257,984 파라미터      (분류기 128만 개 제외)
```

> **`include_top=False` 여야 `input_shape` 을 자유롭게 지정할 수 있습니다.**
> `True` 면 반드시 224×224여야 합니다 (Dense 층이 크기에 의존).

### ★ preprocess_input — 가장 흔한 실수

**모델마다 입력 전처리 방식이 다릅니다.** ([Day 093](day-093.md))

| 모델 | 입력 범위 | 전처리 |
|---|---|---|
| MobileNetV2 / V3 | **-1 ~ 1** | `x / 127.5 - 1` |
| Xception, InceptionV3 | -1 ~ 1 | 동일 |
| ResNet50, VGG16 | 채널별 평균 빼기 | caffe 스타일 |
| EfficientNet (B0~B7) | **0 ~ 255 그대로** | 내부에서 처리 |
| DenseNet | 채널 표준화 | torch 스타일 |

```python
from tensorflow.keras.applications.mobilenet_v2 import preprocess_input

inputs = keras.Input(shape=(224, 224, 3))
x = preprocess_input(inputs)          # ★ 모델 전용 전처리
x = base(x, training=False)
```

**잘못 쓰면**

```
올바른 전처리 : 0.92
Rescaling(1/255) 사용 : 0.78      (-14%p)
```

> **"전이학습인데 성능이 더 나쁘다"의 1순위 원인입니다.**
> [Day 093](day-093.md)에서 예고한 그대로입니다.

### 대표 사전학습 모델 비교

| 모델 | 파라미터 | 크기 | ImageNet Top-1 | 추론 속도 | 특징 |
|---|---|---|---|---|---|
| **MobileNetV2** | 3.5M | 14MB | 71.3% | **매우 빠름** | **모바일·임베디드** |
| MobileNetV3-Small | 2.9M | 12MB | 68.1% | 가장 빠름 | 초경량 |
| EfficientNetB0 | 5.3M | 21MB | 77.1% | 빠름 | **효율 최고** |
| ResNet50 | 25.6M | 98MB | 74.9% | 보통 | 가장 널리 쓰임 |
| VGG16 | 138M | 528MB | 71.3% | 느림 | 단순·오래됨 |
| InceptionV3 | 23.9M | 92MB | 77.9% | 보통 | 다중 스케일 |
| DenseNet121 | 8.1M | 33MB | 75.0% | 보통 | 파라미터 효율 |
| **EfficientNetV2S** | 21.5M | 88MB | **83.9%** | 보통 | 최신·고성능 |

**선택 기준**

```
데이터 적음 + 빠른 실험     → MobileNetV2
정확도 우선                → EfficientNetV2S, ResNet50
모바일·라즈베리파이 배포    → MobileNetV3-Small
논문 재현·베이스라인       → ResNet50
```

> **VGG16은 138M 파라미터로 매우 무겁습니다.** 교육용 예제에 자주 나오지만 실무에서는 잘 안 씁니다.
> **대단원 05의 라즈베리파이 배포를 생각하면 MobileNet 계열**이 현실적입니다.

### 전이학습 모델 구조

```python
inputs = keras.Input(shape=(224, 224, 3))

# ① 증강 (선택)
x = layers.RandomFlip("horizontal")(inputs)
x = layers.RandomRotation(0.1)(x)

# ② 모델 전용 전처리
x = preprocess_input(x)

# ③ 사전학습 백본 (동결)
x = base(x, training=False)          # ★ training=False 중요

# ④ 새 분류기
x = layers.GlobalAveragePooling2D()(x)
x = layers.Dropout(0.3)(x)
outputs = layers.Dense(n_classes, activation="softmax")(x)

model = keras.Model(inputs, outputs)
```

**`base(x, training=False)` 가 왜 중요한가**

```
BatchNorm 층이 학습 모드면 → 배치 통계로 이동평균을 갱신
동결했는데 통계가 바뀌면   → 사전학습 효과가 손상
→ training=False 로 추론 모드 고정
```

> **`base.trainable = False` 만으로는 부족합니다.**
> Keras 2.x 이후 `trainable=False` 면 BatchNorm도 추론 모드가 되지만,
> **명시적으로 `training=False` 를 주는 것이 안전**합니다.

### GlobalAveragePooling이 필수인 이유

```
base 출력: (7, 7, 1280)

Flatten  → 62,720 → Dense(2) = 125,442 파라미터
GAP      →  1,280 → Dense(2) =   2,562 파라미터      (49배 적음)
```

**[Day 088](day-088.md)에서 배운 그대로입니다.**
데이터가 400장인데 12만 파라미터를 학습하면 과적합합니다.

### Step 1. 사전학습 모델 불러와서 살펴보기

```python
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

print("=" * 70)
print("사전학습 모델 불러오기")
print("=" * 70)

# ── 전체 모델 (분류기 포함) ──
full = keras.applications.MobileNetV2(weights="imagenet")
print(f"[include_top=True]")
print(f"  입력 : {full.input_shape}")
print(f"  출력 : {full.output_shape}        ← ImageNet 1000클래스")
print(f"  파라미터: {full.count_params():,}")

# ── 특징 추출부만 ──
base = keras.applications.MobileNetV2(
    weights="imagenet", include_top=False, input_shape=(224, 224, 3))
print(f"\n[include_top=False]")
print(f"  입력 : {base.input_shape}")
print(f"  출력 : {base.output_shape}   ← 특징맵")
print(f"  파라미터: {base.count_params():,}")
print(f"  층 개수 : {len(base.layers)}")
print(f"\n분류기 파라미터: {full.count_params() - base.count_params():,}")

# ── ImageNet 예측 확인 ──
print("\n" + "=" * 70)
print("사전학습 모델이 실제로 무엇을 아는가")
print("=" * 70)

from tensorflow.keras.applications.mobilenet_v2 import (decode_predictions,
                                                        preprocess_input)

# CIFAR-10 이미지를 224로 확대해 테스트
(X, y), _ = keras.datasets.cifar10.load_data()
CIFAR = ["airplane", "automobile", "bird", "cat", "deer",
         "dog", "frog", "horse", "ship", "truck"]

idxs = [7, 12, 25, 3]      # 다양한 클래스
imgs = tf.image.resize(X[idxs].astype("float32"), (224, 224))
preds = full.predict(preprocess_input(imgs), verbose=0)
decoded = decode_predictions(preds, top=3)

for i, (idx, dec) in enumerate(zip(idxs, decoded)):
    print(f"\nCIFAR 정답: {CIFAR[int(y[idx])]}")
    print("  ImageNet 예측 TOP 3:")
    for _, name, prob in dec:
        print(f"    {name:<24}{prob:.4f}")

print("\n→ 32×32를 확대한 저화질 이미지인데도 대략 맞힙니다")
print("  ImageNet에는 개 품종만 120종이 있습니다")

# ── 사용 가능한 모델 목록 ──
print("\n" + "=" * 82)
print("주요 사전학습 모델 비교")
print("=" * 82)
print(f"{'모델':<24}{'파라미터':>14}{'출력 shape':>20}{'크기(MB)':>12}")
print("-" * 82)

MODELS = {
    "MobileNetV2": keras.applications.MobileNetV2,
    "MobileNetV3Small": keras.applications.MobileNetV3Small,
    "EfficientNetB0": keras.applications.EfficientNetB0,
    "ResNet50": keras.applications.ResNet50,
    "DenseNet121": keras.applications.DenseNet121,
    "VGG16": keras.applications.VGG16,
}

for name, fn in MODELS.items():
    try:
        m = fn(weights=None, include_top=False, input_shape=(224, 224, 3))
        size_mb = m.count_params() * 4 / 1024**2
        print(f"{name:<24}{m.count_params():>14,}{str(m.output_shape[1:]):>20}"
              f"{size_mb:>12.1f}")
        del m
    except Exception as e:
        print(f"{name:<24}{'로드 실패':>14}")

print("=" * 82)
print("\n※ weights=None 으로 구조만 확인 (가중치 다운로드 생략)")
print("  실제 사용 시 weights='imagenet' 을 지정합니다")
```

```python
# 전이학습 모델 (특징 추출 방식)
# ══════════════════════════════════════════
def build_transfer(n_classes=N_CLASSES, dropout=0.3, augment=True):
    # ① 백본
    base = keras.applications.MobileNetV2(
        weights="imagenet", include_top=False, input_shape=(*IMG_SIZE, 3))
    base.trainable = False                       # ★ 동결

    inputs = keras.Input(shape=(*IMG_SIZE, 3))

    # ② 증강 (선택)
    x = inputs
    if augment:
        x = layers.RandomFlip("horizontal")(x)
        x = layers.RandomRotation(0.1)(x)
        x = layers.RandomZoom(0.1)(x)

    # ③ 모델 전용 전처리 ★
    x = preprocess_input(x)

    # ④ 백본 통과 (추론 모드)
    x = base(x, training=False)                  # ★ training=False

    # ⑤ 새 분류기
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)
    if n_classes == 2:
        outputs = layers.Dense(1, activation="sigmoid")(x)
        loss = "binary_crossentropy"
    else:
        outputs = layers.Dense(n_classes, activation="softmax")(x)
        loss = "sparse_categorical_crossentropy"

    model = keras.Model(inputs, outputs, name="transfer_mobilenetv2")
    model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
                  loss=loss, metrics=["accuracy"])
    return model, base
```

### Step 4. 백본 모델 비교

```python
# 모델별 전처리 함수 매핑 ★
BACKBONES = {
    "MobileNetV2": (
        keras.applications.MobileNetV2,
        keras.applications.mobilenet_v2.preprocess_input),
    "MobileNetV3Small": (
        keras.applications.MobileNetV3Small,

        keras.applications.resnet50.preprocess_input),
    "DenseNet121": (
        keras.applications.DenseNet121,
        keras.applications.densenet.preprocess_input),
}


def build_with_backbone(name, dropout=0.3):
    fn, preprocess = BACKBONES[name]
    base = fn(weights="imagenet", include_top=False,
              input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*IMG_SIZE, 3))
    x = layers.RandomFlip("horizontal")(inputs)
    x = layers.RandomRotation(0.1)(x)
    x = preprocess(x)                            # ★ 모델 전용
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)
    if N_CLASSES == 2:
        outputs = layers.Dense(1, activation="sigmoid")(x)
        loss = "binary_crossentropy"
    else:
        outputs = layers.Dense(N_CLASSES, activation="softmax")(x)
        loss = "sparse_categorical_crossentropy"

    m = keras.Model(inputs, outputs, name=f"transfer_{name}")
    m.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
              loss=loss, metrics=["accuracy"])
    return m, base
```

```python
"""
day098_transfer_report.py
전이학습 vs 밑바닥 비교
"""
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.metrics import classification_report
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import EarlyStopping, ReduceLROnPlateau

AUTOTUNE = tf.data.AUTOTUNE
BASE_DIR = Path("/content/drive/MyDrive/ml_course")
SPLIT = BASE_DIR / "datasets" / "my_dataset" / "split"
OUT = BASE_DIR / "experiments"
OUT.mkdir(parents=True, exist_ok=True)

IMG_SIZE, BATCH, SEED = (224, 224), 32, 42

train_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=True, seed=SEED)
val_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=False).cache().prefetch(AUTOTUNE)
test_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "test", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=False).cache().prefetch(AUTOTUNE)

CLASS_NAMES = train_raw.class_names
N = len(CLASS_NAMES)
train_ds = train_raw.cache().prefetch(AUTOTUNE)
n_batches = tf.data.experimental.cardinality(train_raw).numpy()

BACKBONES = {
    "MobileNetV2": (keras.applications.MobileNetV2,
                    keras.applications.mobilenet_v2.preprocess_input),
    "MobileNetV3Small": (keras.applications.MobileNetV3Small,
                         keras.applications.mobilenet_v3.preprocess_input),
    "EfficientNetB0": (keras.applications.EfficientNetB0,
                       keras.applications.efficientnet.preprocess_input),
    "ResNet50": (keras.applications.ResNet50,
                 keras.applications.resnet50.preprocess_input),
}


def head(x, dropout=0.3):
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)
    if N == 2:
        return layers.Dense(1, activation="sigmoid")(x), "binary_crossentropy"
    return (layers.Dense(N, activation="softmax")(x),
            "sparse_categorical_crossentropy")


def build_scratch(lr=0.001):
    inputs = keras.Input(shape=(*IMG_SIZE, 3))
    x = layers.RandomFlip("horizontal")(inputs)
    x = layers.RandomRotation(0.1)(x)
    x = layers.RandomZoom(0.1)(x)
    x = layers.Rescaling(1.0 / 255)(x)
    for f in [32, 64, 128, 128]:
        x = layers.Conv2D(f, 3, padding="same", use_bias=False)(x)
        x = layers.BatchNormalization()(x)
        x = layers.Activation("relu")(x)
        x = layers.MaxPooling2D(2)(x)
        x = layers.Dropout(0.2)(x)
    outputs, loss = head(x, 0.4)
    m = keras.Model(inputs, outputs, name="scratch")
    m.compile(optimizer=keras.optimizers.Adam(lr), loss=loss,
              metrics=["accuracy"])
    return m


def build_transfer(backbone="MobileNetV2", prep="correct", lr=0.001):
    fn, preprocess = BACKBONES[backbone]
    base = fn(weights="imagenet", include_top=False,
              input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*IMG_SIZE, 3))
    x = layers.RandomFlip("horizontal")(inputs)
    x = layers.RandomRotation(0.1)(x)
    x = layers.RandomZoom(0.1)(x)

    if prep == "correct":
        x = preprocess(x)
    elif prep == "rescale":
        x = layers.Rescaling(1.0 / 255)(x)
    elif prep == "none":
        pass

    x = base(x, training=False)
    outputs, loss = head(x)
    m = keras.Model(inputs, outputs, name=f"transfer_{backbone}")
    m.compile(optimizer=keras.optimizers.Adam(lr), loss=loss,
              metrics=["accuracy"])
    return m, base


def run(model, ds=None, epochs=150, patience=15):
    ds = ds if ds is not None else train_ds
    cbs = [EarlyStopping(monitor="val_loss", patience=patience,
                         restore_best_weights=True, verbose=0),
           ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                             patience=patience // 2, verbose=0)]
    t0 = time.time()
    h = model.fit(ds, epochs=epochs, validation_data=val_ds,
                  callbacks=cbs, verbose=0).history
    train_time = time.time() - t0
    t0 = time.time()
    _, acc = model.evaluate(test_ds, verbose=0)
    infer_time = time.time() - t0
    trainable = int(np.sum([np.prod(w.shape) for w in model.trainable_weights]))
    return h, {
        "전체_파라미터": model.count_params(),
        "학습_파라미터": trainable,
        "에폭": len(h["loss"]),
        "train": round(h["accuracy"][-1], 4),
        "test": round(acc, 4),
        "격차": round(h["accuracy"][-1] - acc, 4),
        "학습(s)": round(train_time, 1),
        "추론(s)": round(infer_time, 2),
    }


# ══════════════════════════════════════════
# ① 밑바닥 vs 전이학습
# ══════════════════════════════════════════
print("=" * 100)
print("① 밑바닥 vs 전이학습")
print("=" * 100)

rows, hists = [], {}

tf.random.set_seed(SEED)
h, met = run(build_scratch())
rows.append({"방식": "밑바닥 CNN", **met})
hists["밑바닥"] = h
print(f"밑바닥 CNN   test {met['test']:.4f}  ({met['에폭']}에폭)")

tf.random.set_seed(SEED)
m, _ = build_transfer("MobileNetV2")
h, met = run(m)
rows.append({"방식": "전이학습 MobileNetV2", **met})
hists["전이학습"] = h
print(f"전이학습     test {met['test']:.4f}  ({met['에폭']}에폭)")

compare_df = pd.DataFrame(rows)
print("\n" + compare_df.to_string(index=False))

# ══════════════════════════════════════════
# ② 백본 비교
# ══════════════════════════════════════════
print("\n" + "=" * 110)
print("② 백본 비교")
print("=" * 110)

bb_rows, bb_hists = [], {}
for name in BACKBONES:
    keras.backend.clear_session()

    m, base = build_transfer(name)

    del m, base

bb_df = pd.DataFrame(bb_rows).sort_values("test", ascending=False)
print("\n" + bb_df.to_string(index=False))

# ══════════════════════════════════════════
# ③ preprocess_input 오류 재현
# ══════════════════════════════════════════
print("\n" + "=" * 78)
print("③ preprocess_input 오류의 영향")
print("=" * 78)

prep_rows = []
for prep, label in [("correct", "올바름 (preprocess_input)"),
                    ("rescale", "Rescaling(1/255) ✗"),
                    ("none", "전처리 없음 ✗")]:
```

| 개념 | 핵심 |
|---|---|
| 사전학습 모델 | ImageNet 1,400만 장으로 학습된 가중치 |
| 왜 되는가 | **저수준 특징(엣지·질감)은 공통** |
| **특징 추출** | 백본 동결 + 분류기만 학습. **소량 데이터에 최적** |
| 미세조정 | 상위층 해제 + 낮은 lr ([Day 099](day-099.md)) |
| 순서 | **특징 추출 먼저 → 미세조정** |
| `include_top=False` | 분류기를 뺀 특징 추출부만 |
| `base.trainable = False` | **동결. 반드시 확인** |
| `training=False` | BatchNorm 추론 모드 고정 |
| **★ `preprocess_input`** | **모델 전용. 틀리면 -40%p** |
| GlobalAveragePooling | Flatten 대신. 파라미터 49배 절감 |
| 증강 위치 | **전처리보다 먼저** |
| 학습률 | 특징 추출은 **0.001** |
| MobileNetV2 | 2.3M. 균형. **기본 선택** |
| MobileNetV3Small | 939K. **모바일·라즈베리파이** |
| EfficientNetB0 | 4.0M. **효율 최고** |
| ResNet50 | 23.6M. 논문 베이스라인 |
| 효과 | 400장에서 **0.733 → 0.933** |

**오늘 반드시 기억할 세 가지**
> ① **`preprocess_input` 은 반드시 그 모델의 모듈에서 import 하세요.** 틀리면 -40%p입니다.
> ② **`base.trainable = False` 와 `training=False` 를 둘 다 지정**하세요.
> ③ **소량 데이터에서는 전이학습이 다른 모든 기법을 합친 것보다 효과적**입니다.
