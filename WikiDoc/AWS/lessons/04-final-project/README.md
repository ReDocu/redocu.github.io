## 이 문서들을 읽는 법

최종 프로젝트 단원의 본문은 앞 단원과 구조가 조금 다릅니다. ③블록이 **워크숍 진행 가이드**, ④블록이 **스프린트 작업 지시**로 바뀝니다.

| 블록 | 이름 | 이 단원에서의 내용 |
|---|---|---|
| ① | 학습 목표 | 이 강에서 팀이 도달해야 할 상태 |
| ② | 왜 필요한가 | 이 단계를 건너뛰면 프로젝트에서 무엇이 무너지는지 |
| ③ | 개념 설명 / 워크숍 가이드 | 보안·DR·관측성·WA 리뷰의 판단 기준과 진행법 |
| ④ | 스프린트 작업 | Step 1 → N · 팀 작업 지시 · **비용 표 + 정리 체크리스트** |
| ⑤ | 자주 하는 실수 | 프로젝트에서 실제로 자주 터지는 문제와 해결 |
| ⑥ | 마일스톤 점검 | 제출물 체크리스트 (M1~M4) |

명령 블록 규칙은 [전체 진도표](../README.md#이-문서들을-읽는-법)를 참고하세요.

> 🔴 **이 단원은 이 과정에서 비용이 가장 많이 발생하는 구간입니다.**
> 팀별로 ① 작업 시간 외 축소(ECS 0대 / RDS 중지) ② NAT 대신 VPC 엔드포인트 ③ 야간 자동 축소 중 **최소 2가지를 반드시 적용**하고, 매주 팀 비용을 공유합니다.
> 팀당 4주 합계 **$60 이하**가 목표입니다.
