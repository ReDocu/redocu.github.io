## ② 왜 필요한가

**지금까지는 "오늘 배운 범위"라는 힌트가 있었습니다.** 04강 문제는 반복문일 것이고, 09강 문제는 JOIN일 것이라는 예측이 절반의 풀이였습니다. 실제 시험에는 그 힌트가 없습니다 — 1번이 Java 다형성, 2번이 정규화, 3번이 C 포인터입니다. 영역 전환 자체가 피로를 만들고, 이 피로가 아는 문제를 틀리게 합니다. 오늘의 90분 세트는 그 전환 근육을 만드는 훈련입니다.

또 하나, 필답형은 **답을 아는 것과 답안이 인정되는 것이 다릅니다**. `[2, 4, 6]`을 `2 4 6`으로 쓰면, DISTINCT를 빼먹으면, 인정받지 못할 수 있습니다. 오늘부터 채점자는 (강사가 아니라) 답안지만 봅니다.

**시험에서의 중요도와 출제 형태** — 이 강 자체가 시험의 축소판입니다. 세트 구성(코드 8 · SQL 4 · 이론 4)은 기출 복원 경향(비공식)의 근사 비율입니다.

## ③ 개념 설명

### 3-1. 시간 배분 전략 — 150분을 셋으로 자른다

📌 **기본 계획 (20문항 기준)**

| 단계 | 시간 | 할 일 |
|---|---|---|
| ① 훑기 | 5분 | 전 문항을 훑으며 문항마다 ◎(바로 풀 수 있음) / △(시간 들면 풀 수 있음) / ✕(모르겠음) 표시 |
| ② 1차 풀이 | 90분 | **◎부터** 전부 → △ 순서로. 한 문항 10분 넘으면 표시하고 넘어감 |
| ③ 2차 + 검산 | 45분 | ✕ 도전 → 코드 추적표 재검산 → 답안 형식 최종 점검 |
| 예비 | 10분 | 답안 옮겨 적기·누락 확인 |

- 평균 7분/문항이지만 균등 배분이 아닙니다 — 이론 단답은 1분, 긴 코드 추적은 12분까지도 정상입니다. **◎를 다 쓸어 담은 뒤 △에 시간을 쓰는 순서**가 합격점(60점) 전략의 핵심입니다.
- 60점 = 12문항입니다. 20문항을 다 풀려다 12문항의 정확도를 잃는 것이 최악의 배분입니다.

### 3-2. 답안 작성 규칙 — 채점자는 답안지만 본다

📌 **반드시 지킬 것**

| 규칙 | 예 |
|---|---|
| 출력은 **보이는 그대로** (공백·줄바꿈·대소문자·괄호·쉼표) | `[1, 3, 5]`를 `1,3,5`로 쓰지 않기 / `7.0`을 `7`로 쓰지 않기 |
| 문제가 요구한 **키워드·방식**을 사용 | "BETWEEN을 사용하여" → 부등호로 풀면 감점 위험 |
| 용어는 **통용 표기 + 필요 시 영문 병기** | 옵서버(Observer), 2NF(제2정규형) |
| 코드 빈칸은 **문법 요소까지 정확히** | 세미콜론·괄호 포함 여부를 지문 형식에 맞춤 |
| 계산 문제는 **과정을 남기고 답에 단위** | 부재 "7회", 우선순위 "2.67" |
| 모르는 문항도 **빈칸으로 두지 않기** | 부분 지식이라도 관련 용어 기입 (감점은 없고 득점 기회만 있음) |

| 요구 키워드 무시 | "HAVING을 사용하여"인데 서브쿼리로 풂 | 지문의 지정 방식이 채점 기준 |
| 모르는 문제를 빈칸으로 | 필답형은 오답 감점이 없음 | 관련 용어라도 기입 |
| 검산을 "다시 풀기"로 함 | 시간 부족 | 검산은 **행 수·형식·철자**만 빠르게 대조 |

## 마무리

**오늘의 요약** — 실전은 "훑기 5분 → ◎ 쓸어 담기 → △ → 검산"의 순서이고, 60점=12문항이라는 산수가 배분의 기준입니다. 답안은 보이는 그대로(형식)·요구한 대로(키워드)·정확한 철자로 쓰며, 오답은 개념/절차/형식으로 유형화해 기록합니다. 통합 세트의 채점 결과는 버리지 말고 14강 진단의 원료로 가져갑니다.

**복습 체크리스트**

- [ ] 시간 배분 3단계 계획을 안 보고 말할 수 있다
- [ ] 답안 작성 규칙 6가지를 재현할 수 있다
- [ ] 내 오답 전부에 유형 표시(개념/절차/형식)를 붙였다
- [ ] 10번(ON 추가 조건 LEFT JOIN)이 5행인 이유를 설명할 수 있다

**과제** — ① 세트 오답 전부 오답노트 기록(유형 표시 필수), ② 영역별·유형별 정답 수 집계표 작성해 14강에 지참, ③ 형성평가(1~6주차분) 중 아직 재풀이하지 않은 오답 문항 전부 재풀이. (7주차 형성평가는 14강 과제)

**다음 강 예고** — 14강은 지금까지의 모든 채점 데이터를 **진단 매트릭스**로 모아 취약 칸을 수치로 찾고, 트랙별(코드/SQL/이론) 보완 세트를 처방합니다. 원서접수 상태 점검도 함께 합니다.
