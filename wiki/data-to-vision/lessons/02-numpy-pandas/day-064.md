## ② 왜 필요한가

지금까지 그래프를 **하나씩** 그렸습니다. 그런데 보고할 때는 이렇게 됩니다.

```
"1번 그래프를 보시면... 아 그리고 2번 그래프도 같이 보셔야 하는데...
 잠깐만요, 3번 그래프에서는..."
```

**한 장에 모아 놓으면 한 번에 이해됩니다.**

```
┌─────────────────────┬─────────────────────┐
│  월별 방문객 추이    │  카테고리별 구성     │
├─────────────────────┼─────────────────────┤
│  가격 분포          │  지역별 상위 10      │
└─────────────────────┴─────────────────────┘
```

**그리고 가독성 문제도 있습니다.**

```
❌ x축: 서울특별시종로구  부산광역시해운대구  제주특별자치도서귀포시
        (글자가 겹쳐서 못 읽음)

❌ y축: 1e7  2e7  3e7
        (몇인지 감이 안 옴)

❌ 색:  빨강과 초록으로 구분
        (남성 8%가 구분하지 못함)
```

> **그래프가 "맞는" 것과 "읽히는" 것은 다릅니다.**
> 오늘은 **읽는 사람**을 위한 작업입니다.

## 1부 · 레이아웃

### `subplots` — 격자 배치

```python
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

axes[0, 0].plot(...)
axes[0, 1].bar(...)
axes[1, 0].hist(...)
axes[1, 1].scatter(...)
```

**1차원으로 펴서 쓰기**

```python
fig, axes = plt.subplots(2, 3, figsize=(18, 10))
axes = axes.ravel()          # 또는 .flatten()

for i, ax in enumerate(axes):
    ax.plot(...)
```

> ⚠️ **행이나 열이 1이면 차원이 줄어듭니다.**
> ```python
> fig, axes = plt.subplots(1, 3)      # axes.shape = (3,)  → axes[0]
> fig, axes = plt.subplots(2, 2)      # axes.shape = (2,2) → axes[0, 0]
> fig, ax   = plt.subplots()           # ax 하나 (배열 아님)
> ```
> 항상 2차원으로 받으려면 `squeeze=False` 를 씁니다.

### 축 공유

```python
fig, axes = plt.subplots(3, 1, figsize=(10, 9), sharex=True)
```

| 인자 | 효과 |
|---|---|
| `sharex=True` | x축 눈금·범위 공유 → **아래쪽만 라벨 표시** |
| `sharey=True` | y축 공유 → **값 비교가 정확해짐** ⭐ |

> **여러 그래프를 나란히 두고 비교할 때는 `sharey=True` 를 쓰세요.**
> 축 범위가 다르면 **눈으로 비교한 결과가 틀립니다.**

### 크기가 다른 격자 — `gridspec`

```python
fig = plt.figure(figsize=(15, 9))
gs = fig.add_gridspec(2, 3, width_ratios=[2, 1, 1], height_ratios=[1, 1],
                      hspace=0.3, wspace=0.25)

ax_main = fig.add_subplot(gs[:, 0])       # 왼쪽 전체 (2행 차지)
ax1 = fig.add_subplot(gs[0, 1])
ax2 = fig.add_subplot(gs[0, 2])
ax3 = fig.add_subplot(gs[1, 1:])          # 아래 오른쪽 2칸
```

```
┌─────────┬─────┬─────┐
│         │ ax1 │ ax2 │
│ ax_main ├─────┴─────┤
│         │    ax3    │
└─────────┴───────────┘
```

### `subplot_mosaic` — 그림으로 배치 (matplotlib 3.7+)

```python
fig, axd = plt.subplot_mosaic(
    """
    AAB
    AAC
    DDD
    """,
    figsize=(14, 10), height_ratios=[1, 1, 0.8],
)

axd["A"].plot(...)
axd["B"].bar(...)
```

> **레이아웃이 코드에 그림으로 보입니다.** `gridspec` 보다 직관적입니다.

### 여백 정리

```python
fig.tight_layout()                       # 자동 조정 ⭐
fig.tight_layout(rect=[0, 0, 1, 0.96])   # suptitle 공간 확보

fig, axes = plt.subplots(2, 2, layout="constrained")   # 더 똑똑함 ⭐
fig.subplots_adjust(hspace=0.35, wspace=0.25)          # 수동
```

| 방법 | 특징 |
|---|---|
| `tight_layout()` | 간단. **`suptitle` 과 겹칠 수 있음** |
| `layout="constrained"` | **범례·suptitle 까지 고려** (3.6+) |
| `subplots_adjust` | 수동. 미세 조정용 |

> ⚠️ **`tight_layout()` 은 `suptitle` 을 모릅니다.**
> 제목이 잘리면 `rect=[0, 0, 1, 0.96]` 을 주거나 `constrained` 를 쓰세요.

### 전체 제목

```python
fig.suptitle("2026년 관광 데이터 대시보드", fontsize=18,
             fontweight="bold", y=0.98)
```

## 2부 · 가독성

### 눈금 서식

```python
from matplotlib.ticker import FuncFormatter, MaxNLocator, PercentFormatter

# 천 단위 콤마
ax.yaxis.set_major_formatter(FuncFormatter(lambda v, p: f"{v:,.0f}"))

# 단위 축약
def compact(v, pos):
    for unit, div in (("억", 1e8), ("만", 1e4), ("천", 1e3)):
        if abs(v) >= div:
            return f"{v/div:,.1f}{unit}"
    return f"{v:,.0f}"

ax.yaxis.set_major_formatter(FuncFormatter(compact))

# 퍼센트
ax.yaxis.set_major_formatter(PercentFormatter(xmax=1.0))    # 0.35 → 35%

# 눈금 개수 제한
ax.yaxis.set_major_locator(MaxNLocator(6))
```

### 라벨 회전

```python
ax.tick_params(axis="x", rotation=45)

plt.setp(ax.get_xticklabels(), rotation=45, ha="right")     # 정렬까지 ⭐
```

> **`ha="right"` 를 함께 쓰세요.**
> 회전만 하면 라벨이 눈금에서 어긋나 보입니다.

**더 좋은 방법 — 가로 막대로 바꾸기**

```python
ax.barh(labels, values)         # 라벨이 가로로 읽힘. 회전 불필요 ⭐
```

### 주석

```python
# ── 화살표로 가리키기 ──
ax.annotate("최고점",
            xy=(x_point, y_point),          # 가리킬 위치
            xytext=(x_text, y_text),        # 글자 위치
            arrowprops=dict(arrowstyle="->", color="#ef4444", lw=1.5),
            fontsize=10, color="#ef4444")

# ── 그냥 글자 ──
ax.text(x, y, "설명", fontsize=10, ha="center", va="bottom")

# ── 비율 좌표 (데이터 범위와 무관) ──
ax.text(0.02, 0.95, "요약", transform=ax.transAxes, va="top")

# ── 상자 씌우기 ──
ax.text(x, y, "중요", bbox=dict(boxstyle="round,pad=0.4",
                                facecolor="#fef3c7", edgecolor="none"))
```

| `arrowstyle` | 모양 |
|---|---|
| `"->"` | 화살표 |
| `"-|>"` | 채워진 화살표 |
| `"fancy"` | 굵은 화살표 |
| `"wedge"` | 쐐기 |

### 강조선·강조 영역

```python
ax.axhline(target, color="gray", linestyle="--", label="목표")
ax.axvline(event_date, color="red", linestyle=":")

ax.axhspan(0, 100, color="green", alpha=0.1)          # 가로 띠
ax.axvspan("2026-07", "2026-08", color="orange", alpha=0.15)   # 세로 띠
```

### 불필요한 요소 제거 — 데이터-잉크 비율

```python
# 테두리 제거
for spine in ("top", "right"):
    ax.spines[spine].set_visible(False)

# 눈금 표시선 제거 (라벨은 유지)
ax.tick_params(length=0)

# 격자를 은은하게
ax.grid(True, alpha=0.25, linestyle="--", linewidth=0.8)
ax.set_axisbelow(True)          # 격자를 데이터 뒤로 ⭐
```

> **`set_axisbelow(True)` 를 꼭 쓰세요.**
> 안 그러면 격자선이 막대 **위를 가로질러** 지저분해집니다.

**덜어낼 것 5가지**

| 요소 | 판단 |
|---|---|
| 위·오른쪽 테두리 | **거의 항상 제거** |
| 배경색 | 제거 (흰색) |
| 3D 효과·그림자 | **항상 제거** |
| 과한 격자 | `alpha=0.25` 로 |
| 모든 막대에 값 라벨 | **강조할 것만** |

## 3부 · 색

### 색은 3종류

| 종류 | 데이터 | 예 | 팔레트 |
|---|---|---|---|
| **범주형** | 순서 없음 (지역, 카테고리) | 서울/부산/제주 | `tab10` `Set2` `colorblind` |
| **순차형** | 낮음→높음 | 인구, 방문객 | `Blues` `viridis` `YlOrRd` |
| **발산형** | 음수↔0↔양수 | 증감률, 상관계수 | `RdBu_r` `coolwarm` |

```python
# 범주형
colors = plt.cm.tab10.colors
colors = sns.color_palette("colorblind", 5)

# 순차형
ax.scatter(x, y, c=values, cmap="viridis")

# 발산형 — 중앙을 반드시 고정
ax.imshow(data, cmap="RdBu_r", vmin=-1, vmax=1)
```

> ⚠️ **발산형은 중앙값을 고정하지 않으면 거짓말을 합니다.**
> `vmin=-1, vmax=1` 또는 `center=0` 을 반드시 지정하세요.

### 색약 고려 — 남성의 약 8%

**빨강-초록 조합은 피합니다.**

```
❌ 증가=초록, 감소=빨강           (적록색약이 구분 못 함)
✅ 증가=파랑, 감소=주황           (Okabe-Ito)
✅ 증가=↑ 화살표, 감소=↓ 화살표    (형태로도 구분) ⭐
```

**안전한 팔레트 (Okabe-Ito)**

```python
OKABE_ITO = [
    "#0072B2",   # 파랑
    "#E69F00",   # 주황
    "#009E73",   # 청록
    "#CC79A7",   # 분홍
    "#56B4E9",   # 하늘
    "#D55E00",   # 주황빨강
    "#F0E442",   # 노랑
    "#000000",   # 검정
]
```

**이중 부호화 — 색 + 다른 것**

```python
# 색만으로 구분 ❌
ax.plot(x, y1, color="red")
ax.plot(x, y2, color="green")

# 색 + 선 모양 ✅
ax.plot(x, y1, color="#0072B2", linestyle="-", marker="o")
ax.plot(x, y2, color="#E69F00", linestyle="--", marker="s")
```

> **흑백으로 인쇄해도 구분되는가?**
> 이 질문을 통과하면 색약도 대부분 통과합니다.

### 쓰지 말아야 할 컬러맵

| 컬러맵 | 문제 |
|---|---|
| **`jet`** | 밝기가 들쭉날쭉 → **없는 경계를 만들어 냄** |
| `rainbow` | 같은 문제 |
| `hsv` | 같은 문제 |

```python
# ❌
ax.imshow(data, cmap="jet")

# ✅ 밝기가 균일하게 증가하는 컬러맵
ax.imshow(data, cmap="viridis")      # 또는 magma, plasma, cividis
```

> **`viridis` 계열은 "인지적으로 균일"** 하게 설계됐습니다.
> 값이 2배가 되면 **밝기도 그만큼** 변합니다. 흑백 인쇄에서도 순서가 유지됩니다.

### 강조 색 전략

```python
# 하나만 강조하고 나머지는 회색
colors = ["#cbd5e1"] * len(values)
colors[highlight_index] = "#0072B2"

ax.bar(labels, values, color=colors)
```

> **모든 것을 강조하면 아무것도 강조되지 않습니다.**
> 색은 **한두 개**에만 쓰고 나머지는 회색으로 두세요.

## ④ 단계별 실습

### Step 1. 레이아웃 3가지 방법

```python
"""subplots / gridspec / mosaic 비교."""

import platform
from pathlib import Path

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                              else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

OUT = Path("output")
OUT.mkdir(exist_ok=True)

# ── 실습 데이터 ──
rng = np.random.default_rng(42)
N = 800

df = pd.DataFrame({
    "sido": rng.choice(
        ["서울특별시", "부산광역시", "제주특별자치도", "강원특별자치도",
         "경기도", "전라남도", "경상북도", "충청남도"], N,
        p=[0.22, 0.15, 0.14, 0.12, 0.15, 0.08, 0.08, 0.06]),
    "category": rng.choice(["자연", "역사", "체험", "쇼핑", "음식"], N),
    "price": np.concatenate([np.zeros(180),
                             rng.lognormal(8.5, 0.6, N - 180).round(-2)]),
    "visitors": rng.lognormal(8.6, 1.1, N).round(),
    "month": rng.integers(1, 13, N),
})
df["rating"] = (rng.normal(3.9, 0.45, N) + df["price"] / 60000).round(1).clip(1, 5)

print("=" * 76)
print("                    레이아웃 3가지 방법")
print("=" * 76)

# ══════════ ① subplots — 균등 격자 ══════════
fig, axes = plt.subplots(2, 2, figsize=(13, 9))

axes[0, 0].plot(df.groupby("month").size(), marker="o")
axes[0, 0].set_title("① 균등 격자 (2×2)")

for ax in axes.ravel():
    ax.text(0.5, 0.5, "", transform=ax.transAxes)

fig.suptitle("subplots(2, 2) — 모든 칸이 같은 크기",
             fontsize=14, fontweight="bold")
fig.tight_layout(rect=[0, 0, 1, 0.96])
fig.savefig(OUT / "layout1_subplots.png")
plt.close(fig)

# ══════════ ② gridspec — 크기 다르게 ══════════
fig = plt.figure(figsize=(14, 8))
gs = fig.add_gridspec(2, 3, width_ratios=[2, 1, 1],
                      hspace=0.32, wspace=0.28)

ax_main = fig.add_subplot(gs[:, 0])
ax_a = fig.add_subplot(gs[0, 1])
ax_b = fig.add_subplot(gs[0, 2])
ax_c = fig.add_subplot(gs[1, 1:])

for ax, name in [(ax_main, "main (2행 차지)"), (ax_a, "A"),
                 (ax_b, "B"), (ax_c, "C (2칸 차지)")]:
    ax.text(0.5, 0.5, name, transform=ax.transAxes,
            ha="center", va="center", fontsize=13)
    ax.set_xticks([])
    ax.set_yticks([])

fig.suptitle("gridspec — width_ratios=[2,1,1] 로 크기 조절",
             fontsize=14, fontweight="bold")
fig.savefig(OUT / "layout2_gridspec.png")
plt.close(fig)

# ══════════ ③ mosaic — 그림으로 배치 ══════════
fig, axd = plt.subplot_mosaic(
    """
    AAB
    AAC
    DDD
    """,
    figsize=(13, 9), height_ratios=[1, 1, 0.7],
    layout="constrained",
)

for key, ax in axd.items():
    ax.text(0.5, 0.5, key, transform=ax.transAxes,
            ha="center", va="center", fontsize=20, fontweight="bold")
    ax.set_xticks([])
    ax.set_yticks([])

fig.suptitle('subplot_mosaic("""AAB / AAC / DDD""") — 레이아웃이 눈에 보임',
             fontsize=14, fontweight="bold")
fig.savefig(OUT / "layout3_mosaic.png")
plt.close(fig)

print(f"\n  {'방법':<20}{'장점':<28}{'쓸 때'}")
print("  " + "-" * 72)
print(f"  {'subplots(r, c)':<20}{'가장 간단':<28}균등 격자")
print(f"  {'gridspec':<20}{'크기·병합 자유':<28}주 그래프 + 보조 그래프")
print(f"  {'subplot_mosaic':<20}{'레이아웃이 코드에 보임':<28}복잡한 배치 (3.7+)")

print("\n" + "=" * 76)
```

실행 결과:

```

============================================================================

  방법                장점                        쓸 때
  ------------------------------------------------------------------------
  subplots(r, c)      가장 간단                   균등 격자
  gridspec            크기·병합 자유              주 그래프 + 보조 그래프
  subplot_mosaic      레이아웃이 코드에 보임      복잡한 배치 (3.7+)
```

def compact_won(v, pos=None):
    """숫자를 한글 단위로 축약합니다."""

> **눈여겨볼 점 8가지**
> - **`layout="constrained"`** — `suptitle` 과 겹치지 않게 자동 조정합니다.
> - **`loc="left"`** — 제목을 왼쪽 정렬하면 읽기 시작점과 맞아 자연스럽습니다.
> - **`clean_axis()` 함수로 반복 제거** — 4개 패널에 같은 정리를 적용합니다.
> - **강조는 각 패널에 하나씩** — ①은 최고점 주석, ②는 1위 색.
> - **③에서 "무료 제외"를 명시** — 데이터를 걸렀으면 반드시 밝힙니다.
> - **④ 히트맵의 글자 색을 값에 따라 전환** — 진한 배경엔 흰 글자.
> - **출처·건수·날짜를 오른쪽 아래에** — 이 그림 하나만 돌아다녀도 출처를 압니다.
> - **`compact_won` 을 재사용** — 모든 패널의 숫자 형식이 통일됩니다.

"""색약 시뮬레이션과 안전한 팔레트 검사."""

import matplotlib.colors as mcolors
import matplotlib.pyplot as plt
import numpy as np

# ── 색약 변환 행렬 (Brettel/Viénot 근사) ──
CVD_MATRICES = {
    "정상": np.eye(3),
    "적색맹(Protanopia)": np.array([
        [0.567, 0.433, 0.000],
        [0.558, 0.442, 0.000],
        [0.000, 0.242, 0.758]]),
    "녹색맹(Deuteranopia)": np.array([
        [0.625, 0.375, 0.000],
        [0.700, 0.300, 0.000],
        [0.000, 0.300, 0.700]]),
    "청색맹(Tritanopia)": np.array([
        [0.950, 0.050, 0.000],
        [0.000, 0.433, 0.567],
        [0.000, 0.475, 0.525]]),
}

OKABE_ITO = ["#0072B2", "#E69F00", "#009E73", "#CC79A7",
             "#56B4E9", "#D55E00", "#F0E442", "#000000"]


def simulate_cvd(hex_color, kind):
    """색을 색약 시각으로 변환합니다."""
    rgb = np.array(mcolors.to_rgb(hex_color))
    converted = CVD_MATRICES[kind] @ rgb
    return tuple(np.clip(converted, 0, 1))


def color_distance(c1, c2):
    """두 색의 지각적 거리 (간이 계산)."""
    r1, g1, b1 = mcolors.to_rgb(c1)
    r2, g2, b2 = mcolors.to_rgb(c2)

    rm = (r1 + r2) / 2
    dr, dg, db = r1 - r2, g1 - g2, b1 - b2

    return np.sqrt((2 + rm) * dr ** 2 + 4 * dg ** 2 + (3 - rm) * db ** 2)


def check_palette(colors, labels=None, min_distance=0.35,
                  save_path="output/cvd_check.png", verbose=True):
    """
    팔레트가 색약자에게도 구분되는지 검사합니다.

    반환: dict(safe, problems)
    """
    labels = labels or [f"색{i+1}" for i in range(len(colors))]
    problems = []

    # ── 시뮬레이션 그림 ──
    fig, axes = plt.subplots(len(CVD_MATRICES), 1,
                             figsize=(1.6 * len(colors) + 3, 6))

    for ax, (kind, _) in zip(axes, CVD_MATRICES.items()):
        sim = [simulate_cvd(c, kind) for c in colors]

        for i, (c, label) in enumerate(zip(sim, labels)):
            ax.add_patch(plt.Rectangle((i, 0), 0.92, 1, color=c))
            lum = 0.299 * c[0] + 0.587 * c[1] + 0.114 * c[2]
            ax.text(i + 0.46, 0.5, label, ha="center", va="center",
                    fontsize=9, color="white" if lum < 0.5 else "black")

        ax.set_xlim(0, len(colors))
        ax.set_ylim(0, 1)
        ax.set_xticks([])
        ax.set_yticks([])
        ax.set_ylabel(kind, rotation=0, ha="right", va="center", fontsize=10)

        for spine in ax.spines.values():
            spine.set_visible(False)

    fig.suptitle("색약 시뮬레이션", fontsize=15, fontweight="bold")
    fig.tight_layout(rect=[0, 0, 1, 0.94])

    Path(save_path).parent.mkdir(parents=True, exist_ok=True)
    fig.savefig(save_path, dpi=150, bbox_inches="tight", facecolor="white")
    plt.close(fig)

    # ── 구분 가능성 검사 ──
    if verbose:
        print("=" * 78)
        print("                     팔레트 색약 안전성 검사")
        print("=" * 78)
        print(f"\n  색 개수: {len(colors)}개")
        print(f"  그림   : {save_path}")

    for kind in CVD_MATRICES:
        sim = [simulate_cvd(c, kind) for c in colors]
        pairs = []

        for i in range(len(sim)):
            for j in range(i + 1, len(sim)):
                d = color_distance(sim[i], sim[j])
                if d < min_distance:
                    pairs.append((labels[i], labels[j], d))

        if verbose:
            mark = "✓" if not pairs else "✗"
            print(f"\n  {mark} {kind}")

            if pairs:
                for a, b, d in sorted(pairs, key=lambda t: t[2])[:5]:
                    print(f"      ⚠ '{a}' 과 '{b}' 구분 어려움 (거리 {d:.3f})")
            else:
                print(f"      모든 색이 구분됨")

        problems += [(kind, a, b, d) for a, b, d in pairs]

    safe = not problems

    if verbose:
        print(f"\n{'=' * 78}")
        print(f"  판정: {'✅ 안전' if safe else '❌ 개선 필요'}"
              f"   (문제 조합 {len(problems)}건)")
        print("=" * 78)

        if not safe:
            print(f"\n  [대안]")
            print(f"    ① Okabe-Ito 팔레트 사용:")
            print(f"       {OKABE_ITO[:5]}")
            print(f"    ② 색 외에 형태도 다르게 (선 모양·마커·해칭)")
            print(f"    ③ 색 개수를 줄이고 강조 대상만 색으로")
            print("=" * 78)

    return {"safe": safe, "problems": problems}


# ══════════ 사용 ══════════
if __name__ == "__main__":

> **남성 12명 중 1명은 적록 계열을 구분하기 어렵습니다.**
> 20명 규모의 발표에서 **한 명은 그래프를 못 읽습니다.**
>
> **"증가=초록, 감소=빨강"은 가장 흔하면서 가장 위험한 조합**입니다.
>
> **가장 안전한 방법은 이중 부호화입니다.**
> ```python
> # 색 + 기호
> ax.bar(x, y, color=[BLUE if v > 0 else ORANGE for v in y])
> for xi, v in zip(x, y):
>     ax.text(xi, v, "▲" if v > 0 else "▼", ha="center")
> ```
> 색을 못 봐도 **▲▼ 로 알 수 있습니다.**

```python
"""대시보드 완성도 검사."""

import matplotlib.colors as mcolors
import matplotlib.pyplot as plt
import numpy as np


def audit_dashboard(fig, verbose=True):
    """
    대시보드 전체의 완성도를 검사합니다.

    반환: dict(score, issues)
    """
    issues = []
    axes = [ax for ax in fig.get_axes()
            if not getattr(ax, "_colorbar", None)]

    line = "=" * 80

    if verbose:
        print(line)
        print("                       대시보드 완성도 검사")
        print(line)

        w, h = fig.get_size_inches()
        print(f"\n[전체]")
        print(f"  크기     : {w:.1f} × {h:.1f} inch "
              f"({w*fig.dpi:.0f} × {h*fig.dpi:.0f} px)")
        print(f"  패널 수  : {len(axes)}개")

    # ══════════ ① 패널 개수 ══════════
    if len(axes) > 9:
        issues.append(("경고", f"패널 {len(axes)}개 — 6개 이하 권장 "
                               f"(읽는 사람이 포기함)"))
    elif len(axes) == 0:
        issues.append(("치명", "패널이 없음"))

    # ══════════ ② 전체 제목 ══════════
    has_suptitle = bool(fig._suptitle and fig._suptitle.get_text().strip())

    if verbose:
        print(f"  전체 제목: "
              f"{fig._suptitle.get_text() if has_suptitle else '❌ 없음'}")

    if not has_suptitle and len(axes) > 1:
        issues.append(("경고", "전체 제목(suptitle) 없음 — "
                               "무슨 대시보드인지 알 수 없음"))

    # ══════════ ③ 출처 표기 ══════════
    texts = [t.get_text() for t in fig.texts]
    has_source = any(any(k in t for k in ("출처", "데이터", "n=", "작성", "source"))
                     for t in texts)

    if verbose:
        print(f"  출처 표기: {'✓' if has_source else '❌ 없음'}")

    if not has_source:
        issues.append(("경고", "출처·건수·작성일 표기 없음 — "
                               "그림만 돌아다니면 근거 불명"))

    # ══════════ ④ 패널별 검사 ══════════
    if verbose:
        print(f"\n[패널별]")
        print(f"  {'#':<4}{'제목':<26}{'x라벨':>8}{'y라벨':>8}"
              f"{'범례':>7}{'y0':>6}")
        print("  " + "-" * 62)

    y_ranges = []

    for i, ax in enumerate(axes):
        title = ax.get_title() or ax.get_title(loc="left")
        has_x = bool(ax.get_xlabel().strip())
        has_y = bool(ax.get_ylabel().strip())
        n_series = len(ax.get_lines()) + len(ax.containers)
        has_legend = ax.get_legend() is not None
        ymin, _ = ax.get_ylim()
        has_bars = len(ax.containers) > 0

        y_ranges.append(ax.get_ylim())

        if verbose:
            print(f"  {i:<4}{(title[:24] or '(없음)'):<26}"
                  f"{'✓' if has_x else '✗':>8}{'✓' if has_y else '✗':>8}"
                  f"{'✓' if has_legend else '-':>7}"
                  f"{'✓' if ymin >= 0 else '✗':>6}")

        if not title.strip():
            issues.append(("경고", f"패널 {i}: 제목 없음"))
        if not has_x and not has_y:
            issues.append(("경고", f"패널 {i}: 축 라벨 없음"))
        if n_series > 1 and not has_legend:
            issues.append(("경고", f"패널 {i}: 계열 {n_series}개인데 범례 없음"))
        if has_bars and ymin > 0:
            issues.append(("치명", f"패널 {i}: 막대 y축이 {ymin:,.0f}부터 "
                                   f"— 차이 과장"))

        # 지수 표기 확인
        for axis in (ax.xaxis, ax.yaxis):
            labels = [t.get_text() for t in axis.get_ticklabels()]
            if any("1e" in l or "e+" in l for l in labels):
                issues.append(("경고", f"패널 {i}: 지수 표기 눈금 "
                                       f"— FuncFormatter 권장"))
                break

        # 라벨 겹침 추정
        xlabels = [t.get_text() for t in ax.get_xticklabels()]
        long_labels = [l for l in xlabels if len(l) > 6]
        if len(long_labels) > 4:
            rot = (ax.get_xticklabels()[0].get_rotation()
                   if ax.get_xticklabels() else 0)
            if rot == 0:
                issues.append(("경고", f"패널 {i}: 긴 라벨 {len(long_labels)}개 "
                                       f"회전 없음 — barh 또는 rotation 권장"))

    # ══════════ ⑤ 위험한 컬러맵 ══════════
    BAD_CMAPS = {"jet", "rainbow", "hsv", "gist_rainbow", "nipy_spectral"}

    for i, ax in enumerate(axes):
        for im in ax.images + ax.collections:
            cmap = getattr(im, "get_cmap", lambda: None)()
            name = getattr(cmap, "name", "")

            if name in BAD_CMAPS:
                issues.append(("경고", f"패널 {i}: '{name}' 컬러맵 "
                                       f"— viridis 계열 권장"))
                break

    # ══════════ ⑥ 색 개수 ══════════
    all_colors = set()
    for ax in axes:
        for line_obj in ax.get_lines():
            all_colors.add(mcolors.to_hex(line_obj.get_color()))
        for container in ax.containers:
            for patch in container:
                if hasattr(patch, "get_facecolor"):
                    all_colors.add(mcolors.to_hex(patch.get_facecolor()))

    if verbose:
        print(f"\n[색]")
        print(f"  사용된 고유 색: {len(all_colors)}개")

    if len(all_colors) > 10:
        issues.append(("경고", f"고유 색 {len(all_colors)}개 — "
                               f"강조 1~2개 + 회색 권장"))

    # ══════════ ⑦ y축 범위 불일치 ══════════
    if len(y_ranges) >= 2:
        spans = [hi - lo for lo, hi in y_ranges]
        if spans and max(spans) / max(min(spans), 1e-9) > 100:
            if verbose:
                print(f"  ℹ 패널 간 y축 범위 차이가 큼 — "
                      f"비교가 목적이면 sharey=True 검토")

    # ══════════ 결과 ══════════
    fatal = sum(1 for l, _ in issues if l == "치명")
    warn = sum(1 for l, _ in issues if l == "경고")
    score = max(0, 100 - fatal * 25 - warn * 7)

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 발표 가능" if score >= 85
                 else "🟡 보완 권장" if score >= 65 else "❌ 재작업")
        print(f"  완성도: {score}점 / 100   {grade}")
        print(f"  (치명 {fatal}건 × -25, 경고 {warn}건 × -7)")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} {msg}")

        if not issues:
            print("  문제 없음")

        print(line)

    return {"score": score, "issues": issues}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    fig, axes = plt.subplots(2, 2, figsize=(12, 8))

    axes[0, 0].bar(["가", "나", "다"], [102, 105, 108])
    axes[0, 0].set_ylim(100, 110)

    axes[0, 1].plot([1, 2, 3], [1e7, 2e7, 3e7])
    axes[0, 1].plot([1, 2, 3], [2e7, 1e7, 2.5e7])

    axes[1, 0].imshow(np.random.rand(5, 5), cmap="jet")

    axes[1, 1].bar(["서울특별시", "부산광역시", "제주특별자치도",
                    "강원특별자치도", "경상북도"], [5, 3, 4, 2, 3])

    print(">>> 문제가 많은 대시보드\n")
    audit_dashboard(fig)
    plt.close(fig)
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 균등 격자 | `plt.subplots(r, c)` · 1행이면 **1차원 인덱싱** |
| 축 공유 | **`sharey=True`** — 비교할 때 필수 |
| 자유 배치 | `gridspec(width_ratios=...)` · **`subplot_mosaic`** |
| 여백 | `tight_layout(rect=...)` 또는 **`layout="constrained"`** |
| 눈금 서식 | **`FuncFormatter`** — 천 단위·단위 축약 |
| 긴 라벨 | **`barh`** (회전보다 근본적) |
| 주석 | `annotate(xy=, xytext=, arrowprops=)` |
| 강조선 | `axhline` `axvline` `axhspan` `axvspan` |
| 덜어내기 | `spines` 제거 · `tick_params(length=0)` · **`set_axisbelow(True)`** |
| 색 종류 | 범주형 `tab10` / 순차형 **`viridis`** / 발산형 **`RdBu_r`** |
| **금지** | **`jet` `rainbow`** — 없는 경계를 만듦 |
| **색약** | **빨강-초록 금지** · Okabe-Ito · **이중 부호화** |
| 강조 | **1~2개만** 색, 나머지 회색 |
| 대시보드 | **4~6패널** · Z 배치 · **출처 표기** |

**오늘 반드시 기억할 세 가지**
> ① **긴 라벨은 회전이 아니라 `barh` 로 해결하세요.** 더 읽기 쉽습니다.
> ② **`jet` 을 쓰지 마세요.** 데이터에 없는 경계를 만들어 냅니다. `viridis` 를 쓰세요.
> ③ **대시보드에 출처·건수·날짜를 넣으세요.** 그림은 혼자 돌아다닙니다.

**과제**

④ 색약 시뮬레이션으로 자기 팔레트 검사 결과 첨부
