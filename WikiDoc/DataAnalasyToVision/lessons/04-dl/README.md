## 이 단원부터 달라지는 것

### "무엇인가"에서 "얼마인가"로

대단원 03에서 여러분이 만든 모델은 이런 답을 냈습니다.

```python
model.predict(사진)      # → "허스키"  (또는 늑대)
```

**답이 정해진 몇 개 중 하나였습니다.** 맞거나 틀리거나 둘 중 하나였고, 그래서 "정확도 88%"라고 말할 수 있었습니다.

이 단원의 모델은 이런 답을 냅니다.

```python
model.predict(게임정보)   # → 12,347.8
```

**정답이 12,000원이었다면 이 예측은 맞은 겁니까, 틀린 겁니까?**

347원 차이입니다. 맞았다고 하기도, 틀렸다고 하기도 애매합니다.
**회귀에는 정확도가 없습니다.** 대신 "평균적으로 얼마나 빗나가는가"를 재고, 그 숫자가 쓸 만한지 판단해야 합니다.

> 이것이 이 단원 전체를 관통하는 변화입니다.
> **채점표가 사라지고, 판단이 시작됩니다.**

### 데이터가 이미지에서 표로 돌아옵니다

| | 대단원 03 | 대단원 04 |
|---|---|---|
| 데이터 | 이미지 (비정형) | **표 (정형)** |
| 특성 | 픽셀 — 하나하나에 의미 없음 | **열 하나하나가 의미를 가짐** |
| 문제 | 분류 — "무엇인가?" | **회귀 — "얼마인가?"** |
| 출력층 | Softmax / Sigmoid | **활성화 없음 (선형)** |
| 손실 함수 | 크로스엔트로피 | **MSE / MAE** |
| 평가 | 정확도 · F1 · 혼동행렬 | **MAE · RMSE · R²** |
| 강한 모델 | CNN (압도적) | **트리 앙상블이 이기는 일이 흔함** |
| 이 단원의 초점 | 모델 구조 이해 | **전처리와 검증·튜닝 절차** |

**대단원 02(pandas)에서 다뤘던 그 표가 돌아옵니다.** 다른 점은, 이제 그 표로 **예측**을 한다는 것입니다.

### 이 단원의 진짜 주제는 모델이 아니라 절차입니다

새로 배우는 모델은 거의 없습니다. Dense 층은 [Day 085](../03-ml/day-085.md)에서 이미 배웠습니다.

이 단원 30일 동안 반복해서 훈련하는 것은 이것입니다.

```
문제 정의 → 데이터 → EDA → 전처리 → 분할 → 학습 → 검증 → 튜닝 → 최종 평가 → 해석
```

**이 순서에서 한 칸만 어긋나도 결과 전체가 무효가 됩니다.**

```python
# ❌ 이 두 줄의 순서 때문에 논문이 철회되고 서비스가 망합니다
X_scaled = scaler.fit_transform(X)                     # 전체 데이터로 스케일링
X_train, X_test = train_test_split(X_scaled, ...)      # 그다음 분할
```

이것을 **데이터 누수(leakage)** 라고 합니다. [Day 109](day-109.md)에서 일부러 재현해 보고, 이후 25일 동안 매일 확인합니다.

> ⚠️ **"성능이 너무 좋으면 의심하세요."**
> 대단원 03의 위험이 **과적합**이었다면, 이 단원의 위험은 **누수**입니다.
> 과적합은 곡선에 보이지만, **누수는 아무 데도 안 보입니다.** 절차로만 막을 수 있습니다.

## 이 문서들을 읽는 법

각 일차 문서는 **6개 블록의 고정 구조**를 갖습니다. (대단원 01·02·03과 동일)

| 블록 | 내용 |
|---|---|
| ① 학습 목표 | 오늘을 마치면 할 수 있게 되는 것 |
| ② 왜 필요한가 | 이 개념이 없으면 무엇이 안 되는지 |
| ③ 개념 설명 | 용어와 원리. 표·그림 중심 |
| ④ 단계별 실습 | Step 1 → N, 코드 + 실행 결과 |
| ⑤ 자주 하는 실수 | 에러 메시지 원문 + 원인 + 해결 |
| ⑥ 확인 문제 | 3문항. 답은 접혀 있음 |

**실행 결과의 숫자에 대한 주의** — 대단원 03과 마찬가지로 **여러분 환경과 다를 수 있습니다.**
`random_state` 를 고정해도 라이브러리 버전이 다르면 소수점이 달라집니다.

> **숫자를 외우지 말고 관계를 보세요.**
> "MAE 3,214원"이 아니라 **"평균 가격이 15,000원인데 MAE가 3,214원 → 20% 오차 → 실무에 쓰기 어렵다"** 가 읽어야 할 내용입니다.
> 이 단원의 모든 지표는 **비교 대상이 있어야 의미가 생깁니다.**

## 이 단원을 마치면

- [ ] 회귀 문제의 출력층·손실 함수·평가 지표를 스스로 설계할 수 있다
- [ ] EDA → 이상치 → 인코딩 → 분할 → 정규화를 **올바른 순서로** 수행할 수 있다
- [ ] 전처리를 `Pipeline` 으로 묶어 **새 데이터 한 행에 그대로 재적용**할 수 있다
- [ ] 학습 곡선·잔차 플롯을 보고 다음에 무엇을 바꿀지 말할 수 있다
- [ ] MAE·RMSE·R² 중 이 문제에 맞는 지표를 근거를 대며 고를 수 있다
- [ ] 하이퍼파라미터를 체계적으로 탐색하고 그 과정을 기록으로 남길 수 있다
- [ ] **"RMSE 3,200원"에 어떤 조건을 함께 밝혀야 하는지** 안다

|---|---|---|---|---|---|---|---|---|---|---|
| E01 | 09/14 | v1 | 표준화 | 평균 예측 | — | 5,120 | 7,340 | 0.00 | 베이스라인 확보 | 선형회귀 |

| E03 | 09/14 | v1 | 표준화 | Dense 64-32 | lr 1e-3, 100ep | 3,610 | 5,240 | 0.49 | 선형 대비 소폭 개선 | 로그 타깃 |
