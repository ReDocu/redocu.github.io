## ② 왜 필요한가

### 모델보다 데이터가 중요합니다

[Day 090](day-090.md)에서 확인한 것을 다시 봅시다.

```
필터 2배 (파라미터 4배)   →  +0.7%p
Dropout 추가 (파라미터 0) →  +2.7%p
```

**그리고 아직 시도하지 않은 것이 남아 있습니다.**

```
데이터 증강              →  +5~8%p  (Day 094)
데이터를 2배로 늘리기      →  +5~10%p
```

> "더 좋은 알고리즘보다 더 많은 데이터"
> — 실무에서 가장 자주 인용되는 경험칙

**모델 구조를 아무리 손봐도 데이터가 나쁘면 한계가 있습니다.**

### 나쁜 데이터셋이 만드는 문제

```
① 클래스 불균형     늑대 500장, 허스키 50장
                    → 모델이 전부 "늑대"라고 답해도 90% 정확도 (Day 080)

② 다양성 부족       늑대는 전부 눈밭 사진
                    → 모델이 "눈밭 = 늑대"를 학습 (배경 편향)

③ 라벨 오류         허스키 사진 20장이 늑대 폴더에
                    → 모델이 잘못된 규칙을 학습

④ 중복             같은 사진이 학습셋과 테스트셋에
                    → 테스트 정확도가 부풀려짐 (Day 077의 그룹 누수)
```

**이 네 가지가 오늘 다룰 문제입니다.**

## ③ 개념 설명

### 좋은 데이터셋의 조건

**① 클래스 균형**

```
좋음:  늑대 200장, 허스키 200장         비율 1:1
보통:  늑대 300장, 허스키 200장         비율 1.5:1
나쁨:  늑대 500장, 허스키  50장         비율 10:1
```

**불균형이 심하면**

| 문제 | 설명 |
|---|---|
| 다수 클래스 편향 | 모델이 다수 쪽으로 찍음 |
| 정확도 왜곡 | [Day 080](day-080.md)의 99% 함정 |
| 소수 클래스 학습 부족 | 패턴을 못 배움 |

**대응** — 수집 단계에서 맞추는 것이 최선. 안 되면 `class_weight` ([Day 093](day-093.md))

**② 다양성**

```
늑대 200장이 전부:
  ✗ 같은 개체        → 그 개체만 인식
  ✗ 같은 배경(눈밭)  → 배경을 학습
  ✗ 같은 각도(정면)  → 옆모습 못 맞힘
  ✗ 같은 조명        → 어두운 사진 실패
```

**체크리스트**

| 축 | 다양해야 할 것 |
|---|---|
| 개체 | 서로 다른 늑대/허스키 |
| 배경 | 눈, 풀밭, 실내, 도로 |
| 각도 | 정면, 측면, 후면, 위 |
| 거리 | 클로즈업, 전신, 원경 |
| 조명 | 밝음, 어두움, 역광 |
| 자세 | 서 있음, 앉음, 뛰는 중 |

> **"모델이 무엇으로 판단하기를 원하는가"를 생각하세요.**
> 동물의 형태로 판단하기를 원한다면, **배경은 모든 클래스에 골고루** 있어야 합니다.

**③ 라벨 정확성**

```
라벨 오류율 5%  →  성능 상한이 95%로 제한됨
```

**모델은 잘못된 라벨도 그대로 학습합니다.**

**대응**
- 수집 후 **전수 검토** (400장이면 30분이면 됩니다)
- 애매한 것은 **버리세요** (분류가 확실한 것만)
- 2인이 교차 검토하면 더 좋습니다

### 폴더 구조 규약

```
my_dataset/
├── train/
│   ├── wolf/
│   │   ├── wolf_0001.jpg
│   │   ├── wolf_0002.jpg
│   │   └── ...
│   └── husky/
│       ├── husky_0001.jpg
│       └── ...
├── val/
│   ├── wolf/
│   └── husky/
└── test/
    ├── wolf/
    └── husky/
```

**규칙**

| 규칙 | 이유 |
|---|---|
| **폴더 이름 = 클래스 이름** | Keras가 자동으로 라벨링 |
| 폴더 이름은 **영문 소문자** | 한글·공백은 문제 소지 |
| 파일명은 **클래스_번호** | 정렬·추적이 쉬움 |
| 확장자 통일 (`.jpg`) | [Day 091](day-091.md)에서 처리 |

**클래스 순서**

```python
train_ds.class_names      # ['husky', 'wolf']   ← 알파벳 순
```

**Keras는 폴더 이름을 알파벳 순으로 정렬해 0, 1, 2... 를 부여합니다.**

```
husky → 0
wolf  → 1
```

> ⚠️ **클래스 인덱스를 하드코딩하지 마세요.** 폴더를 추가하면 순서가 바뀝니다.
> 항상 `class_names` 를 확인하고 그것을 쓰세요.

### 분할 비율

```
train : val : test = 70 : 15 : 15      (일반적)
                   = 80 : 10 : 10      (데이터가 적을 때)
```

**400장 기준**

| 셋 | 비율 | 장수 | 클래스당 |
|---|---|---|---|
| train | 70% | 280 | 140 |
| val | 15% | 60 | 30 |
| test | 15% | 60 | 30 |

> ⚠️ **테스트셋 60장은 매우 작습니다.** 1장 틀리면 1.7%p입니다.
> **프로젝트에서는 클래스당 300장 이상**을 목표로 하는 이유입니다. ([Day 101](day-101.md))

**★ 반드시 지킬 것 — 같은 개체가 여러 셋에 들어가면 안 됩니다**

```
✗ wolf_A_01.jpg → train
  wolf_A_02.jpg → test      ← 거의 같은 사진. 그룹 누수 (Day 077)

✓ wolf_A_*.jpg → 전부 train
  wolf_B_*.jpg → 전부 test
```

### 중복 이미지 찾기

**왜 문제인가** — 같은 이미지가 train과 test에 있으면 테스트 성능이 부풀려집니다.

| 방법 | 찾는 것 | 속도 |
|---|---|---|
| **파일 해시 (MD5)** | 완전히 동일한 파일 | 매우 빠름 |
| **이미지 해시 (dHash)** | 시각적으로 비슷한 이미지 | 빠름 |
| 특징 벡터 유사도 | 의미적으로 비슷한 이미지 | 느림 |

**dHash (difference hash)**

```
① 이미지를 9×8 흑백으로 축소
② 좌우 픽셀을 비교해 0/1로 변환 → 64비트
③ 두 해시의 다른 비트 수(해밍 거리)로 유사도 판단
```

```
해밍 거리 0     → 완전히 동일
해밍 거리 1~5   → 매우 비슷 (크기 변경, 약간의 압축)
해밍 거리 6~10  → 비슷
해밍 거리 > 15  → 다른 이미지
```

> **크기가 다르거나 JPEG 압축률이 달라도 잡아냅니다.**
> 웹에서 모은 이미지는 같은 사진의 여러 버전이 흔합니다.

### image_dataset_from_directory

```python
train_ds = keras.utils.image_dataset_from_directory(
    "my_dataset/train",
    labels="inferred",           # 폴더 이름에서 라벨 추출
    label_mode="int",            # 0, 1, 2, ... (sparse_categorical용)
    image_size=(224, 224),
    batch_size=32,
    shuffle=True,
    seed=42,
)
```

| 인자 | 설명 |
|---|---|
| `labels` | `"inferred"` = 폴더 이름 사용 |
| `label_mode` | `"int"` / `"categorical"`(원핫) / `"binary"` |
| `image_size` | 리사이즈 크기 (bilinear) |
| `batch_size` | 배치 크기 |
| `validation_split` | 검증셋 비율 (subset과 함께) |
| `subset` | `"training"` / `"validation"` |
| `color_mode` | `"rgb"` / `"grayscale"` |

**반환값은 `tf.data.Dataset`**

```python
for images, labels in train_ds.take(1):
    print(images.shape)      # (32, 224, 224, 3)
    print(labels.shape)      # (32,)
    print(images.dtype)      # float32, 범위 0~255 (정규화 안 됨!)
```

> ⚠️ **`image_dataset_from_directory` 는 정규화를 하지 않습니다.** 0~255 그대로입니다.
> `Rescaling(1./255)` 층을 모델에 넣거나 `.map()` 으로 처리해야 합니다. ([Day 093](day-093.md))

**성능 최적화**

```python
AUTOTUNE = tf.data.AUTOTUNE
train_ds = train_ds.cache().shuffle(1000).prefetch(AUTOTUNE)
```

| 메서드 | 효과 |
|---|---|
| `.cache()` | 첫 에폭 후 메모리에 유지 → 2배 이상 빠름 |
| `.prefetch()` | GPU 학습 중 다음 배치를 미리 준비 |
| `.shuffle(n)` | 버퍼 n개 안에서 섞음 |

### Step 1. 데이터셋 폴더 구조 만들기

```python
import shutil
from pathlib import Path

import numpy as np
from PIL import Image
from tensorflow import keras

# ── 실습용: CIFAR-10에서 2클래스를 뽑아 "직접 모은 사진"처럼 만들기 ──
# 실제로는 이 부분이 "인터넷/직접 촬영으로 수집"에 해당합니다
(X, y), _ = keras.datasets.cifar10.load_data()
y = y.ravel()

CLASS_MAP = {3: "cat", 5: "dog"}       # 고양이 vs 개
BASE = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset")
RAW = BASE / "raw"

if BASE.exists():
    shutil.rmtree(BASE)

rng = np.random.default_rng(42)

print("=" * 66)
print("실습용 원본 이미지 생성 (수집 단계 시뮬레이션)")
print("=" * 66)

for cls_id, cls_name in CLASS_MAP.items():
    out_dir = RAW / cls_name
    out_dir.mkdir(parents=True, exist_ok=True)

    idxs = np.where(y == cls_id)[0][:220]     # 일부러 220장 (중복 포함 예정)
    for i, idx in enumerate(idxs[:200]):
        w = int(rng.integers(150, 600))
        h = int(rng.integers(150, 600))
        Image.fromarray(X[idx]).resize((w, h), Image.BICUBIC).save(
            out_dir / f"{cls_name}_{i:04d}.jpg", quality=90)

    # 중복 이미지 10장 (같은 원본을 다른 크기/품질로 저장)
    for i in range(10):
        src_idx = idxs[i]
        Image.fromarray(X[src_idx]).resize((320, 320), Image.BICUBIC).save(
            out_dir / f"{cls_name}_dup_{i:02d}.jpg", quality=75)

    # 손상 파일 1장
    (out_dir / f"{cls_name}_broken.jpg").write_bytes(b"not an image")

    print(f"  {cls_name:<8}: 200장 + 중복 10장 + 손상 1장 = "
          f"{len(list(out_dir.iterdir()))}개")

print("=" * 66)
print(f"저장 위치: {RAW}")

# ── 폴더 구조 출력 ──
def show_tree(root, prefix="", max_files=3):
    root = Path(root)
    entries = sorted(root.iterdir())
    dirs = [e for e in entries if e.is_dir()]
    files = [e for e in entries if e.is_file()]

    for d in dirs:
        print(f"{prefix}├── {d.name}/")
        show_tree(d, prefix + "│   ", max_files)
    for f in files[:max_files]:
        print(f"{prefix}├── {f.name}")
    if len(files) > max_files:
        print(f"{prefix}└── ... ({len(files)}개 파일)")


print("\n현재 구조")
print(f"{RAW.name}/")
show_tree(RAW)
```

### Step 2. 데이터 품질 검사 — 깨진 파일과 중복 찾기

```python
from collections import defaultdict
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from PIL import Image, UnidentifiedImageError

RAW = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset/raw")
VALID_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}


# ══════════════════════════════════════════
# ① 손상 파일 검사
# ══════════════════════════════════════════
def check_broken(root):
    """열 수 없는 파일 목록 반환"""
    broken, ok = [], []
    for p in sorted(Path(root).rglob("*")):
        if not p.is_file():
            continue
        if p.suffix.lower() not in VALID_EXT:
            broken.append((p, "확장자"))
            continue
        try:
            with Image.open(p) as im:
                im.verify()
            ok.append(p)
        except (UnidentifiedImageError, OSError, SyntaxError) as e:
            broken.append((p, type(e).__name__))
    return ok, broken


# ══════════════════════════════════════════
# ② 중복 검사 — dHash
# ══════════════════════════════════════════
def dhash(path, hash_size=8):
    """difference hash — 64비트 정수 반환"""
    img = Image.open(path).convert("L").resize(
        (hash_size + 1, hash_size), Image.LANCZOS)
    px = np.array(img, dtype=int)
    diff = px[:, 1:] > px[:, :-1]          # 좌우 픽셀 비교
    return int("".join("1" if v else "0" for v in diff.ravel()), 2)


def hamming(a, b):
    return bin(a ^ b).count("1")


def find_duplicates(paths, threshold=5):
    """해밍 거리가 threshold 이하인 쌍을 찾음"""
    hashes = {}
    for p in paths:
        try:
            hashes[p] = dhash(p)
        except Exception:
            continue

    items = list(hashes.items())
    groups = []
    used = set()

    for i, (p1, h1) in enumerate(items):
        if p1 in used:
            continue
        group = [p1]
        for p2, h2 in items[i + 1:]:
            if p2 in used:
                continue
            d = hamming(h1, h2)
            if d <= threshold:
                group.append(p2)
                used.add(p2)
        if len(group) > 1:
            used.add(p1)
            groups.append(group)
    return groups, hashes
```

```python
# ── Day 091의 전처리 함수 재사용 ──
def letterbox(img, size, fill=(0, 0, 0)):
    tw, th = size
    w, h = img.size
    sc = min(tw / w, th / h)
    nw, nh = max(1, int(round(w * sc))), max(1, int(round(h * sc)))
    canvas = Image.new("RGB", size, fill)
    canvas.paste(img.resize((nw, nh), Image.BILINEAR),
                 ((tw - nw) // 2, (th - nh) // 2))
    return canvas


def preprocess_image(source, size=SIZE):
    img = Image.open(source) if isinstance(source, (str, Path)) else source
    img = ImageOps.exif_transpose(img)
    if img.mode != "RGB":
        img = img.convert("RGB")
    return letterbox(img, size)


def dhash(path, hash_size=8):
    img = Image.open(path).convert("L").resize(
        (hash_size + 1, hash_size), Image.LANCZOS)
    px = np.array(img, dtype=int)
    diff = px[:, 1:] > px[:, :-1]
    return int("".join("1" if v else "0" for v in diff.ravel()), 2)


def hamming(a, b):
    return bin(a ^ b).count("1")


# ══════════════════════════════════════════
# 정제 파이프라인
# ══════════════════════════════════════════
def clean_dataset(raw_dir, clean_dir, size=SIZE, dup_threshold=5, verbose=True):
    raw_dir, clean_dir = Path(raw_dir), Path(clean_dir)
    if clean_dir.exists():
        shutil.rmtree(clean_dir)

    report = []

    for cls_dir in sorted(d for d in raw_dir.iterdir() if d.is_dir()):
        cls = cls_dir.name
        out_dir = clean_dir / cls
        out_dir.mkdir(parents=True, exist_ok=True)

        n_total = n_broken = n_dup = n_small = 0
        hashes = {}
        kept = []

        for p in sorted(cls_dir.iterdir()):
            if not p.is_file():
                continue
            n_total += 1

            # ① 확장자·손상 검사
            if p.suffix.lower() not in VALID_EXT:
                n_broken += 1
                continue
            try:
                with Image.open(p) as im:
                    im.verify()
                img = Image.open(p)
                img = ImageOps.exif_transpose(img).convert("RGB")
            except Exception:
                n_broken += 1
                continue

            # ② 너무 작은 이미지 제외
            if min(img.size) < 64:
                n_small += 1
                continue

            # ③ 중복 검사
            try:
                h = dhash(p)
            except Exception:
                n_broken += 1
                continue

            is_dup = any(hamming(h, hv) <= dup_threshold for hv in hashes.values())
            if is_dup:
                n_dup += 1
                continue
            hashes[p] = h
            kept.append((p, img))

        # ④ 전처리 후 저장 (파일명 재부여)
        for i, (p, img) in enumerate(kept):
            preprocess_image(img, size).save(
                out_dir / f"{cls}_{i:04d}.jpg", quality=92)

        report.append({
            "클래스": cls, "원본": n_total, "손상": n_broken,
            "너무작음": n_small, "중복": n_dup, "최종": len(kept),
        })

    df = pd.DataFrame(report)
    if verbose:
        print("=" * 74)
        print(f"데이터셋 정제 리포트 — 크기 {size}, 중복 임계값 {dup_threshold}")
        print("=" * 74)
        print(df.to_string(index=False))
        print("-" * 74)
        print(f"{'합계':<10}{df['원본'].sum():>8}{df['손상'].sum():>8}"
              f"{df['너무작음'].sum():>10}{df['중복'].sum():>8}{df['최종'].sum():>8}")
        print("=" * 74)

        # 균형 확인
        counts = df.set_index("클래스")["최종"]
        ratio = counts.max() / counts.min()
        print(f"클래스 균형: {dict(counts)}")
        print(f"최대/최소 비율: {ratio:.2f}배  ", end="")
        print("→ 균형 양호 ✓" if ratio < 1.5 else "→ 불균형 주의 ⚠️")
    return df


clean_report = clean_dataset(RAW, CLEAN)

def split_dataset(clean_dir, split_dir, ratios=(0.7, 0.15, 0.15), seed=42,
                  verbose=True):
    clean_dir, split_dir = Path(clean_dir), Path(split_dir)
    if split_dir.exists():
        shutil.rmtree(split_dir)

    assert abs(sum(ratios) - 1.0) < 1e-9, "비율의 합이 1이어야 합니다"
    names = ["train", "val", "test"]
    rng = np.random.default_rng(seed)
    rows = []

    for cls_dir in sorted(d for d in clean_dir.iterdir() if d.is_dir()):
        cls = cls_dir.name
        files = sorted(cls_dir.glob("*.jpg"))
        idx = rng.permutation(len(files))

        n = len(files)
        n_train = int(n * ratios[0])
        n_val = int(n * ratios[1])
        bounds = [(0, n_train), (n_train, n_train + n_val), (n_train + n_val, n)]

        row = {"클래스": cls, "전체": n}
        for name, (a, b) in zip(names, bounds):
            dst = split_dir / name / cls
            dst.mkdir(parents=True, exist_ok=True)
            for i in idx[a:b]:
                shutil.copy2(files[i], dst / files[i].name)
            row[name] = b - a
        rows.append(row)

    df = pd.DataFrame(rows)
    if verbose:
        print("\n" + "=" * 66)
        print(f"데이터셋 분할 — {ratios[0]:.0%} : {ratios[1]:.0%} : {ratios[2]:.0%}")
        print("=" * 66)
        print(df.to_string(index=False))
        print("-" * 66)
        print(f"{'합계':<10}{df['전체'].sum():>8}{df['train'].sum():>8}"
              f"{df['val'].sum():>8}{df['test'].sum():>8}")
        print("=" * 66)
        print(f"저장 위치: {split_dir}")
        print()
        print("⚠️  테스트셋이 작으면 성능 추정이 불안정합니다.")
        test_per_class = df["test"].min()
        print(f"   클래스당 테스트 {test_per_class}장 → 1장 오답 = "
              f"{1/test_per_class:.1%}p 변동")
    return df


split_report = split_dataset(CLEAN, SPLIT)
```

```python
    """데이터셋 전수 점검 리포트"""
    split_dir = Path(split_dir)
    rows = []

    for subset in ["train", "val", "test"]:
        sub = split_dir / subset
        if not sub.exists():
            continue
        for cls_dir in sorted(d for d in sub.iterdir() if d.is_dir()):
            files = sorted(cls_dir.glob("*.jpg"))
            brightness, sizes = [], []
            for p in files:
                img = Image.open(p)
                sizes.append(img.size)
                arr = np.array(img.convert("L"))
                brightness.append(arr.mean())
            rows.append({
                "셋": subset, "클래스": cls_dir.name, "장수": len(files),
                "평균밝기": round(float(np.mean(brightness)), 1),
                "밝기표준편차": round(float(np.std(brightness)), 1),
                "너무어두움": int(sum(b < 40 for b in brightness)),
                "너무밝음": int(sum(b > 215 for b in brightness)),
                "크기일치": len(set(sizes)) == 1,
            })
    return pd.DataFrame(rows)

def dhash(path, hash_size=8):
    img = Image.open(path).convert("L").resize(
        (hash_size + 1, hash_size), Image.LANCZOS)
    px = np.array(img, dtype=int)
    diff = px[:, 1:] > px[:, :-1]
    return int("".join("1" if v else "0" for v in diff.ravel()), 2)


def hamming(a, b):
    return bin(a ^ b).count("1")
```

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

SPLIT = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset/split")
IMG_SIZE = (224, 224)
BATCH = 32
AUTOTUNE = tf.data.AUTOTUNE

train_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH, shuffle=True, seed=42)
val_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)
test_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "test", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)

class_names = train_ds.class_names
print(f"클래스: {class_names}")

train_ds = train_ds.cache().shuffle(300).prefetch(AUTOTUNE)
val_ds = val_ds.cache().prefetch(AUTOTUNE)
test_ds = test_ds.cache().prefetch(AUTOTUNE)

# ── 모델 (Rescaling을 모델에 내장 — Day 093에서 자세히) ──
model = keras.Sequential([
    layers.Input(shape=(*IMG_SIZE, 3)),
    layers.Rescaling(1.0 / 255),                # ★ 정규화를 모델에 내장

    layers.Conv2D(32, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),
    layers.Conv2D(64, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),
    layers.Conv2D(128, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),
    layers.Conv2D(128, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),

    layers.GlobalAveragePooling2D(),
    layers.Dropout(0.4),
    layers.Dense(64, activation="relu"),
    layers.Dense(1, activation="sigmoid"),      # 2클래스 → 1노드 sigmoid
], name="my_dataset_cnn")

model.compile(optimizer="adam", loss="binary_crossentropy",
              metrics=["accuracy"])
model.summary()

print("\n" + "=" * 66)
print("학습 시작 — 직접 만든 데이터셋 400장")
print("=" * 66)
```

```python
import re
from collections import defaultdict

import numpy as np


def split_by_group(files, ratios=(0.7, 0.15, 0.15), seed=42):
    """파일명에서 개체 ID를 추출해 그룹 단위로 분할"""
    groups = defaultdict(list)
    for p in files:
        m = re.match(r"([a-z]+_\d+)", p.stem)      # wolf_001
        gid = m.group(1) if m else p.stem
        groups[gid].append(p)

    gids = sorted(groups)
    rng = np.random.default_rng(seed)
    idx = rng.permutation(len(gids))

    n = len(gids)
    n_tr, n_va = int(n * ratios[0]), int(n * ratios[1])
    bounds = [(0, n_tr), (n_tr, n_tr + n_va), (n_tr + n_va, n)]

    out = []
    for a, b in bounds:
        subset = []
        for i in idx[a:b]:
            subset.extend(groups[gids[i]])
        out.append(subset)
    return out      # [train_files, val_files, test_files]
```

```python
"""
build_dataset.py — 개인 데이터셋 구축 파이프라인

사용:
    1. raw/클래스명/ 에 수집한 이미지를 넣는다
    2. 이 스크립트를 실행한다
    3. split/ 에 완성된 데이터셋이 생성된다
"""
import json
import re
import shutil
from collections import defaultdict
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from PIL import Image, ImageOps, UnidentifiedImageError

BASE = Path("/content/drive/MyDrive/ml_course/datasets/my_project")
RAW = BASE / "raw"
CLEAN = BASE / "clean"
SPLIT = BASE / "split"

SIZE = (224, 224)
VALID_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}
DUP_THRESHOLD = 5
MIN_SIDE = 64
RATIOS = (0.70, 0.15, 0.15)
SEED = 42


# ══════════════════════════════════════════════════
# 유틸
# ══════════════════════════════════════════════════
def letterbox(img, size, fill=(0, 0, 0)):
    tw, th = size
    w, h = img.size
    sc = min(tw / w, th / h)
    nw, nh = max(1, int(round(w * sc))), max(1, int(round(h * sc)))
    canvas = Image.new("RGB", size, fill)
    canvas.paste(img.resize((nw, nh), Image.BILINEAR),
                 ((tw - nw) // 2, (th - nh) // 2))
    return canvas


def preprocess(img, size=SIZE):
    img = ImageOps.exif_transpose(img)
    if img.mode != "RGB":
        img = img.convert("RGB")
    return letterbox(img, size)


def dhash(source, hash_size=8):
    img = Image.open(source) if isinstance(source, (str, Path)) else source
    img = img.convert("L").resize((hash_size + 1, hash_size), Image.LANCZOS)
    px = np.array(img, dtype=int)
    diff = px[:, 1:] > px[:, :-1]
    return int("".join("1" if v else "0" for v in diff.ravel()), 2)


def hamming(a, b):
    return bin(a ^ b).count("1")


def group_id(path):
    """파일명에서 개체 ID 추출: wolf_001_a.jpg → wolf_001"""
    m = re.match(r"^([a-zA-Z]+_\d+)", path.stem)
    return m.group(1) if m else path.stem


# ══════════════════════════════════════════════════
# ① 정제
# ══════════════════════════════════════════════════
def clean_step(raw_dir=RAW, clean_dir=CLEAN, verbose=True):
    raw_dir, clean_dir = Path(raw_dir), Path(clean_dir)
    if clean_dir.exists():
        shutil.rmtree(clean_dir)

    rows, all_hashes = [], {}

    for cls_dir in sorted(d for d in raw_dir.iterdir() if d.is_dir()):
        cls = cls_dir.name
        out_dir = clean_dir / cls
        out_dir.mkdir(parents=True, exist_ok=True)

        stats = dict(원본=0, 확장자=0, 손상=0, 작음=0, 중복=0, 최종=0)
        cls_hashes = {}

        for p in sorted(cls_dir.iterdir()):
            if not p.is_file():
                continue
            stats["원본"] += 1

            if p.suffix.lower() not in VALID_EXT:
                stats["확장자"] += 1
                continue

            try:
                with Image.open(p) as probe:
                    probe.verify()
                img = preprocess(Image.open(p))
            except Exception:
                stats["손상"] += 1
                continue

            with Image.open(p) as orig:
                if min(orig.size) < MIN_SIDE:
                    stats["작음"] += 1
                    continue

            h = dhash(img)
            if any(hamming(h, hv) <= DUP_THRESHOLD for hv in cls_hashes.values()):
                stats["중복"] += 1
                continue
            cls_hashes[p] = h
            all_hashes[p] = (h, cls)

            # 원본 파일명 유지 (개체 ID 추적용)
            img.save(out_dir / f"{p.stem}.jpg", quality=92)
            stats["최종"] += 1

        rows.append({"클래스": cls, **stats})

    df = pd.DataFrame(rows)

    # 클래스 간 중복 검사 (라벨 오류)
    items = list(all_hashes.items())
    cross = []
    for i, (p1, (h1, c1)) in enumerate(items):
        for p2, (h2, c2) in items[i + 1:]:
            if c1 != c2 and hamming(h1, h2) <= DUP_THRESHOLD:
                cross.append((p1, p2))

    if verbose:
        print("=" * 82)
        print("① 정제 리포트")
        print("=" * 82)
        print(df.to_string(index=False))
        print("-" * 82)
        print(f"{'합계':<10}", end="")
        for c in ["원본", "확장자", "손상", "작음", "중복", "최종"]:
            print(f"{df[c].sum():>12}", end="")
        print()
        print("=" * 82)

        counts = df.set_index("클래스")["최종"]
        ratio = counts.max() / max(counts.min(), 1)
        print(f"클래스 균형: {dict(counts)}  (최대/최소 {ratio:.2f}배)")
        print("  ✓ 균형 양호" if ratio < 1.5 else "  ⚠️ 불균형 — 수집 보완 권장")

        if cross:
            print(f"\n⚠️ 클래스 간 중복 {len(cross)}쌍 — 라벨 오류 의심")
            for p1, p2 in cross[:5]:
                print(f"    {p1.parent.name}/{p1.name} ↔ {p2.parent.name}/{p2.name}")
            print("  → 반드시 직접 확인하고 잘못된 쪽을 삭제하세요")
        else:
            print("\n✓ 클래스 간 중복 없음")

    return df, cross


# ══════════════════════════════════════════════════
# ② 개체 단위 분할
# ══════════════════════════════════════════════════
def split_step(clean_dir=CLEAN, split_dir=SPLIT, ratios=RATIOS,
               seed=SEED, by_group=True, verbose=True):
    clean_dir, split_dir = Path(clean_dir), Path(split_dir)
    if split_dir.exists():
        shutil.rmtree(split_dir)

    names = ["train", "val", "test"]
    rng = np.random.default_rng(seed)
    rows = []

    for cls_dir in sorted(d for d in clean_dir.iterdir() if d.is_dir()):
        cls = cls_dir.name
        files = sorted(cls_dir.glob("*.jpg"))

        if by_group:
            groups = defaultdict(list)
            for p in files:
                groups[group_id(p)].append(p)
            keys = sorted(groups)
            idx = rng.permutation(len(keys))
            n = len(keys)
            n_tr, n_va = int(n * ratios[0]), int(n * ratios[1])
            bounds = [(0, n_tr), (n_tr, n_tr + n_va), (n_tr + n_va, n)]
            buckets = [[p for i in idx[a:b] for p in groups[keys[i]]]
                       for a, b in bounds]
            n_groups = n
        else:
            idx = rng.permutation(len(files))
            n = len(files)
            n_tr, n_va = int(n * ratios[0]), int(n * ratios[1])
            bounds = [(0, n_tr), (n_tr, n_tr + n_va), (n_tr + n_va, n)]
            buckets = [[files[i] for i in idx[a:b]] for a, b in bounds]
            n_groups = n

        row = {"클래스": cls, "전체": len(files), "개체수": n_groups}
        for name, bucket in zip(names, buckets):
            dst = split_dir / name / cls
            dst.mkdir(parents=True, exist_ok=True)
            for p in bucket:
                shutil.copy2(p, dst / p.name)
            row[name] = len(bucket)
        rows.append(row)

    df = pd.DataFrame(rows)
    if verbose:
        print("\n" + "=" * 78)
        print(f"② 분할 리포트 — {'개체 단위' if by_group else '파일 단위'}, "
              f"{ratios[0]:.0%}:{ratios[1]:.0%}:{ratios[2]:.0%}")
        print("=" * 78)
        print(df.to_string(index=False))
        print("-" * 78)
        print(f"{'합계':<10}{df['전체'].sum():>8}{df['개체수'].sum():>8}"
              f"{df['train'].sum():>8}{df['val'].sum():>8}{df['test'].sum():>8}")
        print("=" * 78)
        if by_group:
            print("★ 개체 단위 분할: 같은 개체의 사진은 같은 셋에만 들어갑니다")
            print("  → 그룹 누수(Day 077) 방지")
    return df


# ══════════════════════════════════════════════════
# ③ 최종 검증
# ══════════════════════════════════════════════════
def verify_step(split_dir=SPLIT, verbose=True):
    split_dir = Path(split_dir)
    checks = []

    counts = defaultdict(dict)
    all_hashes, all_groups = {}, defaultdict(set)
    sizes = set()

    for subset in ["train", "val", "test"]:
        for cls_dir in sorted((split_dir / subset).iterdir()):
            files = list(cls_dir.glob("*.jpg"))
            counts[subset][cls_dir.name] = len(files)
            for p in files:
                all_hashes[p] = (dhash(p), subset, cls_dir.name)
                all_groups[group_id(p)].add(subset)
                sizes.add(Image.open(p).size)

    # ① 클래스 균형
    tr = counts["train"]
    ratio = max(tr.values()) / max(min(tr.values()), 1)
    checks.append(("클래스 균형", ratio < 1.5, f"{ratio:.2f}배"))

    # ② 크기 통일
    checks.append(("크기 통일", len(sizes) == 1,
                   f"{sizes.pop() if len(sizes)==1 else f'{len(sizes)}종류'}"))

    # ③ 셋 간 중복
    items = list(all_hashes.items())
    leak = sum(1 for i, (p1, (h1, s1, _)) in enumerate(items)
               for p2, (h2, s2, _) in items[i + 1:]
               if s1 != s2 and hamming(h1, h2) <= DUP_THRESHOLD)
    checks.append(("셋 간 이미지 중복", leak == 0, f"{leak}쌍"))

    # ④ 개체 누수
    group_leak = sum(1 for subsets in all_groups.values() if len(subsets) > 1)
    checks.append(("개체 누수", group_leak == 0, f"{group_leak}개체"))

    # ⑤ 테스트셋 크기
    test_min = min(counts["test"].values())
    checks.append(("테스트셋 크기", test_min >= 30, f"클래스당 최소 {test_min}장"))

    if verbose:
        print("\n" + "=" * 66)
        print("③ 최종 검증")
        print("=" * 66)
        for name, ok, detail in checks:
            print(f"  {'✓' if ok else '⚠️'} {name:<22}{detail}")
        print("=" * 66)
        all_pass = all(ok for _, ok, _ in checks)
        print("  전체 통과 ✓ — 학습에 사용 가능" if all_pass
              else "  일부 항목 미충족 — 위 내용을 확인하세요")

    return pd.DataFrame(checks, columns=["항목", "통과", "상세"])


# ══════════════════════════════════════════════════
# 실행
# ══════════════════════════════════════════════════
clean_df, cross_dups = clean_step()
split_df = split_step(by_group=True)
verify_df = verify_step()

# 메타데이터 저장
class_names = sorted(d.name for d in (SPLIT / "train").iterdir() if d.is_dir())
meta = {
    "class_names": class_names,
    "image_size": list(SIZE),
    "split_ratios": list(RATIOS),
    "seed": SEED,
    "counts": {s: {c: len(list((SPLIT / s / c).glob("*.jpg")))
                   for c in class_names}
               for s in ["train", "val", "test"]},
}
(BASE / "dataset_info.json").write_text(
    json.dumps(meta, indent=2, ensure_ascii=False))
print(f"\n메타데이터 저장: {BASE / 'dataset_info.json'}")
print(json.dumps(meta, indent=2, ensure_ascii=False))
```

**이 파이프라인의 설계 포인트 6가지**

**① 3단계로 분리** — 정제 → 분할 → 검증.
각 단계를 따로 재실행할 수 있습니다.

**② 원본을 건드리지 않습니다.**
`raw/` 는 그대로 두고 `clean/`, `split/` 을 새로 만듭니다. 언제든 다시 시작할 수 있습니다.

**③ 개체 단위 분할이 기본값**입니다.
`by_group=False` 로 끌 수 있지만, **켜는 것이 맞습니다.**

**④ 클래스 간 중복을 라벨 오류로 경고**합니다.
자동으로 지우지 않고 **사람이 확인**하게 합니다. 어느 쪽이 맞는지는 사람만 압니다.

**⑤ 검증을 별도 단계로 둡니다.**
"만들었으니 되겠지"가 아니라 **5개 항목을 기계적으로 확인**합니다.

**⑥ 메타데이터를 JSON으로 저장**합니다.
`class_names` 순서, 이미지 크기, seed를 기록해 **재현 가능**하게 합니다.
추론 코드에서 이 파일을 읽어 클래스 이름을 얻습니다.
