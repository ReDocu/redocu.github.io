## ③ 개념 설명

### 딕셔너리란

**키(key)로 값(value)을 찾는** 자료구조입니다. 실제 사전과 같습니다.

```python
person = {"name": "홍길동", "age": 25, "city": "서울"}
```

| 리스트 | 딕셔너리 |
|---|---|
| `scores[0]` — **번호**로 찾음 | `person["name"]` — **이름**으로 찾음 |
| 순서가 의미 있음 | 키가 의미를 담음 |
| "3번째 값이 뭐였더라?" | "name 값이 뭐지?" — 명확 |

**튜플 대신 딕셔너리를 쓰면 코드가 설명이 됩니다.**

```python
rec = ("지출", "식비", "점심", 9000)
rec[3]                              # 이게 뭐였지?

rec = {"kind": "지출", "category": "식비", "memo": "점심", "amount": 9000}
rec["amount"]                       # 명확
```

### 만들기와 접근

```python
person = {"name": "홍길동", "age": 25}

person["name"]          # '홍길동'
person["age"]           # 25
person["email"]         # KeyError!  ← 없는 키
```

**값 추가·수정·삭제**

```python
person["email"] = "hong@example.com"    # 추가 (없으면 새로 만듦)
person["age"] = 26                      # 수정 (있으면 덮어씀)
del person["email"]                     # 삭제
```

### 키의 조건

키는 **변하지 않는 값(immutable)** 만 가능합니다.

| 키로 쓸 수 있음 | 키로 쓸 수 없음 |
|---|---|
| 문자열 `"name"` | 리스트 `[1, 2]` |
| 정수 `42` | 딕셔너리 `{}` |
| 튜플 `(37.5, 127.0)` | 세트 `{1, 2}` |

> 실무에서는 **거의 항상 문자열**을 씁니다. 좌표처럼 여러 값을 묶어 키로 쓸 때만 튜플을 씁니다.

### `get()` — 없어도 죽지 않게

```python
person = {"name": "홍길동"}

person["email"]                          # KeyError
person.get("email")                      # None
person.get("email", "없음")               # '없음'  ← 기본값 지정
```

**실무 코드에서는 `get()` 을 기본으로 쓰세요.**
외부에서 온 데이터(API·CSV)는 **필드가 없을 수 있습니다.** `[]` 로 접근하면 서비스가 죽습니다.

```python
# ❌ API 응답에 'count' 가 없으면 서버가 500 에러
count = item["count"]

# ✅ 없으면 0으로 처리
count = item.get("count", 0)
```

### `setdefault()` 와 집계 패턴

**"없으면 만들고, 있으면 더한다"** 는 집계의 기본형입니다.

```python
# 방법 1) get 사용 — 가장 많이 씁니다
totals = {}
for category, amount in data:
    totals[category] = totals.get(category, 0) + amount

# 방법 2) setdefault
totals = {}
for category, amount in data:
    totals.setdefault(category, 0)
    totals[category] += amount

# 방법 3) in 으로 확인
totals = {}
for category, amount in data:
    if category not in totals:
        totals[category] = 0
    totals[category] += amount
```

셋 다 같은 결과입니다. **방법 1을 외우세요.**

리스트를 모을 때는 `setdefault` 가 편합니다.

```python
groups = {}
for name, team in members:
    groups.setdefault(team, []).append(name)
# {'A팀': ['홍길동', '김철수'], 'B팀': ['이영희']}
```

### 순회 — keys / values / items

```python
person = {"name": "홍길동", "age": 25, "city": "서울"}

for key in person:                 # 키만 (기본)
    print(key)

for key in person.keys():          # 키만 (명시적)
    print(key)

for value in person.values():      # 값만
    print(value)

for key, value in person.items():  # 키와 값 둘 다  ← 가장 많이 씀
    print(f"{key}: {value}")
```

```
name: 홍길동
age: 25
city: 서울
```

> **파이썬 3.7부터 딕셔너리는 넣은 순서를 유지합니다.** 예전에는 순서가 뒤죽박죽이었습니다.

### 유용한 연산

```python
"name" in person             # True   ← 키가 있는지 (값이 아님!)
len(person)                  # 3
list(person.keys())          # ['name', 'age', 'city']
person.pop("age")            # 25 를 돌려주고 삭제
person.update({"age": 30, "job": "개발자"})   # 여러 개 한 번에 추가/수정
dict.fromkeys(["a", "b"], 0) # {'a': 0, 'b': 0}
```

**값 기준 정렬**은 `items()` 와 `sorted` 를 조합합니다.

```python
totals = {"식비": 21000, "교통": 55000, "여가": 14000}

sorted(totals.items(), key=lambda kv: kv[1], reverse=True)
# [('교통', 55000), ('식비', 21000), ('여가', 14000)]
```

### 딕셔너리 컴프리헨션

```python
{키식: 값식 for 변수 in 반복대상 if 조건}
```

```python
prices = {"사과": 3000, "바나나": 2500, "포도": 8000}

# 10% 할인
{k: int(v * 0.9) for k, v in prices.items()}
# {'사과': 2700, '바나나': 2250, '포도': 7200}

# 5000원 이상만
{k: v for k, v in prices.items() if v >= 5000}
# {'포도': 8000}

# 키와 값 뒤집기
{v: k for k, v in prices.items()}
# {3000: '사과', 2500: '바나나', 8000: '포도'}
```

### 중첩 구조 — JSON과의 대응

**JSON은 딕셔너리와 리스트의 조합입니다.** 표기법이 거의 같습니다.

| JSON | 파이썬 |
|---|---|
| `{...}` object | `dict` |
| `[...]` array | `list` |
| `"text"` string | `str` |
| `42` number | `int` |
| `3.14` number | `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

**대소문자만 주의하면 됩니다.** JSON의 `true` 는 파이썬에서 `True` 입니다.

```python
data = {
    "response": {
        "header": {"resultCode": "00", "resultMsg": "NORMAL SERVICE"},
        "body": {
            "totalCount": 1284,
            "items": [
                {"stationName": "강남", "count": 48293},
                {"stationName": "홍대입구", "count": 51042},
            ],
        },
    }
}
```

**접근은 왼쪽부터 한 겹씩** 벗깁니다.

```python
data["response"]                                    # dict
data["response"]["body"]                            # dict
data["response"]["body"]["items"]                   # list
data["response"]["body"]["items"][0]                # dict
data["response"]["body"]["items"][0]["count"]       # 48293
```

**안전하게 접근하려면 `get()` 을 이어 씁니다.**

```python
items = data.get("response", {}).get("body", {}).get("items", [])
```

중간에 없어도 빈 딕셔너리·빈 리스트가 돌아와 `KeyError` 로 죽지 않습니다.
W04에서 API 응답을 다룰 때 **반드시 이렇게 씁니다.**

### Step 2. 단어 빈도 카운터

`word_count.py` 를 만듭니다. **집계 패턴의 원형**입니다.

```python
text = """
데이터는 수집되고 정제되고 저장된다
정제된 데이터는 모델을 학습시키고
학습된 모델은 서비스로 배포된다
서비스는 데이터를 다시 만들어낸다
"""

words = text.split()

counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

# 빈도 높은 순으로 정렬
ranked = sorted(counts.items(), key=lambda kv: kv[1], reverse=True)

print(f"전체 단어 {len(words)}개, 고유 단어 {len(counts)}개\n")
print(f"{'단어':<12}{'횟수':>4}  분포")
print("-" * 34)
for word, count in ranked[:10]:
    bar = "■" * count
    print(f"{word:<12}{count:>4}  {bar}")

print()
once = [w for w, c in counts.items() if c == 1]
print(f"한 번만 나온 단어 {len(once)}개")
```

### Step 3. 가계부 v2 — 딕셔너리로 재작성

[Day 006](day-006.md)의 가계부를 딕셔너리 레코드로 바꿉니다. `budget.py` 의 계산 부분만 발췌합니다.

```python
records = [
    {"kind": "수입", "category": "수입", "memo": "8월 급여", "amount": 2_800_000},
    {"kind": "지출", "category": "식비", "memo": "점심", "amount": 9_000},
    {"kind": "지출", "category": "교통", "memo": "정기권", "amount": 55_000},
    {"kind": "지출", "category": "식비", "memo": "저녁", "amount": 12_000},
    {"kind": "지출", "category": "여가", "memo": "영화", "amount": 14_000},
]


def total_by_kind(records, kind):
    """수입 또는 지출의 합계."""
    return sum(r["amount"] for r in records if r["kind"] == kind)


def totals_by_category(records):
    """지출을 분류별로 집계합니다. 분류가 몇 개든 코드는 그대로."""
    totals = {}
    for r in records:
        if r["kind"] != "지출":
            continue
        cat = r["category"]
        totals[cat] = totals.get(cat, 0) + r["amount"]
    return totals


def summarize(records):
    """요약 정보를 딕셔너리로 돌려줍니다."""
    income = total_by_kind(records, "수입")
    expense = total_by_kind(records, "지출")
    return {
        "income": income,
        "expense": expense,
        "balance": income - expense,
        "by_category": totals_by_category(records),
        "count": len(records),
    }


s = summarize(records)

print(f"총 수입 : {s['income']:>12,} 원")
print(f"총 지출 : {s['expense']:>12,} 원")
print("-" * 27)
print(f"잔액    : {s['balance']:>12,} 원")

print("\n[지출 분류별 — 큰 순]")
ranked = sorted(s["by_category"].items(), key=lambda kv: kv[1], reverse=True)
for category, amount in ranked:
    ratio = amount / s["expense"]
    bar = "■" * int(ratio * 20)
    print(f"  {category:<6}{amount:>9,} 원  {ratio:>6.1%}  {bar}")
```

실행 결과:

```
총 수입 :    2,800,000 원
총 지출 :       90,000 원
---------------------------
잔액    :    2,710,000 원

[지출 분류별 — 큰 순]
  교통      55,000 원   61.1%  ■■■■■■■■■■■■
  여가      14,000 원   15.6%  ■■■
  식비      21,000 원   23.3%  ■■■■
```

> `sum(r["amount"] for r in records if ...)` 는 **제너레이터 표현식**입니다.
> 리스트 컴프리헨션에서 대괄호를 뗀 것으로, 리스트를 만들지 않고 바로 합산해 **메모리를 아낍니다.**
> W06 대용량 처리에서 이 차이가 중요해집니다.
>
> **Day 006과 비교하세요.** `CATEGORIES` 튜플을 미리 정의할 필요가 없어졌습니다.

### Step 4. 중첩 딕셔너리 — API 응답 다루기

`api_response.py` 를 만듭니다. **W04의 예고편이자 오늘의 핵심 실습**입니다.

```python
# 공공데이터 API 응답을 흉내 낸 구조
response = {
    "response": {
        "header": {"resultCode": "00", "resultMsg": "NORMAL SERVICE"},
        "body": {
            "numOfRows": 3,
            "pageNo": 1,
            "totalCount": 1284,
            "items": [
                {"stationName": "강남", "line": "2호선", "date": "2026-08-12", "boarding": 48293, "alighting": 47108},
                {"stationName": "홍대입구", "line": "2호선", "date": "2026-08-12", "boarding": 51042, "alighting": 49873},
                {"stationName": "잠실", "line": "2호선", "date": "2026-08-12", "boarding": 39187},
            ],
        },
    }
}


def get_items(resp):
    """응답에서 items 목록을 안전하게 꺼냅니다."""
    return (
        resp.get("response", {})
            .get("body", {})
            .get("items", [])
    )


def is_success(resp):
    """정상 응답인지 확인합니다."""
    code = resp.get("response", {}).get("header", {}).get("resultCode")
    return code == "00"


if not is_success(response):
    msg = response.get("response", {}).get("header", {}).get("resultMsg", "알 수 없음")
    print(f"API 오류: {msg}")
else:
    items = get_items(response)
    body = response["response"]["body"]

    print(f"전체 {body['totalCount']:,}건 중 {len(items)}건 수신 (페이지 {body['pageNo']})\n")

    print(f"{'역명':<10}{'노선':<8}{'승차':>10}{'하차':>10}{'합계':>10}")
    print("-" * 48)

    total_boarding = 0
    for item in items:
        # 'alighting' 이 없는 행이 섞여 있습니다 — get으로 방어
        boarding = item.get("boarding", 0)
        alighting = item.get("alighting", 0)
        total = boarding + alighting
        total_boarding += boarding

        mark = "" if "alighting" in item else "  ← 하차 데이터 없음"
        print(f"{item['stationName']:<10}{item['line']:<8}{boarding:>10,}{alighting:>10,}{total:>10,}{mark}")

    print("-" * 48)
    print(f"{'승차 합계':<18}{total_boarding:>10,}")

    # 가장 붐빈 역
    busiest = max(items, key=lambda x: x.get("boarding", 0))
    print(f"\n최다 승차역: {busiest['stationName']} ({busiest['boarding']:,}명)")

    # 없는 키에 [] 로 접근하면 어떻게 되는지 확인
    print("\n[없는 키 접근 비교]")

    except KeyError as e:
        print(f"  []   : KeyError {e} — 프로그램이 죽습니다")
```

```python
members = [
    ("홍길동", "A팀", 85),
    ("김철수", "B팀", 92),

# 팀별로 이름 모으기

for name, team, score in members:
    by_team.setdefault(team, []).append(name)

print("[팀별 인원]")
for team in sorted(by_team):
    names = by_team[team]
    print(f"  {team}: {len(names)}명 — {', '.join(names)}")

print()

# 팀별 점수 통계
```

### Step 6. 중첩 딕셔너리 검색 함수

`deep_search.py` 를 만듭니다. 과제로 나갈 함수의 완성본입니다.

```python
config = {
    "app": {
        "name": "collector",
        "version": "1.0.0",
        "debug": False,
    },
    "database": {
        "host": "localhost",
        "port": 5432,
        "credentials": {"user": "mlops", "password": "***"},
    },
    "collectors": [
        {"name": "api", "url": "https://api.example.com", "interval": 3600},
        {"name": "crawler", "url": "https://news.example.com", "interval": 1800},
    ],
}


def deep_get(data, path, default=None):
    """'database.credentials.user' 같은 경로로 중첩 값을 꺼냅니다.

    Args:
        data: 탐색할 딕셔너리
        path: 점으로 구분된 키 경로
        default: 못 찾았을 때 돌려줄 값

    Returns:
        찾은 값 또는 default
    """
    current = data
    for key in path.split("."):
        if not isinstance(current, dict):
            return default
        if key not in current:
            return default
        current = current[key]
    return current


def flatten(data, prefix=""):
    """중첩 딕셔너리를 'a.b.c: 값' 형태로 평탄화합니다."""
    result = {}
    for key, value in data.items():
        full_key = f"{prefix}.{key}" if prefix else key
        if isinstance(value, dict):
            result.update(flatten(value, full_key))
        else:
            result[full_key] = value
    return result


print("[deep_get]")
for path in ("app.name", "database.port", "database.credentials.user", "database.missing", "app.name.nope"):
    print(f"  {path:<32} → {deep_get(config, path, '(없음)')}")

print("\n[flatten — 리스트를 제외한 모든 설정]")
for key, value in flatten(config).items():
    print(f"  {key:<32} = {value}")

print("\n[수집기 목록]")
for c in config["collectors"]:
    print(f"  {c['name']:<10} {c['url']:<32} {c['interval']:>6}초마다")
```

실행 결과:

```
[deep_get]
  app.name                         → collector
  database.port                    → 5432
  database.credentials.user        → mlops
  database.missing                 → (없음)
  app.name.nope                    → (없음)

[flatten — 리스트를 제외한 모든 설정]
  app.name                         = collector
  app.version                      = 1.0.0
  app.debug                        = False
  database.host                    = localhost
  database.port                    = 5432
  database.credentials.user        = mlops
  database.credentials.password    = ***
  collectors                       = [{'name': 'api', ...}]

[수집기 목록]
  api        https://api.example.com          3600초마다
  crawler    https://news.example.com         1800초마다
```

> `isinstance(value, dict)` 는 "이 값이 딕셔너리인가"를 확인합니다. `type(value) == dict` 보다 권장되는 방식입니다.
> `flatten` 은 **자기 자신을 호출**합니다. 이것을 **재귀(recursion)** 라고 하며, 중첩 구조를 다룰 때 자연스럽게 나옵니다.
>
> 이 `deep_get` 은 [Day 020](day-020.md)의 yaml 설정 로딩에서 그대로 재사용합니다.

## ⑤ 자주 하는 실수

### `KeyError: 'email'`

```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    print(person["email"])
KeyError: 'email'
```

**원인** — 없는 키에 `[]` 로 접근했습니다. 외부 데이터를 다룰 때 **가장 많이 나는 에러**입니다.
**해결** —

```python
person.get("email")               # None
person.get("email", "미등록")      # 기본값
if "email" in person: ...         # 존재 확인
```

**중첩이면 이어 씁니다.**

```python
items = data.get("response", {}).get("body", {}).get("items", [])
```

### `in` 이 값이 아니라 키를 검사한다

```python
person = {"name": "홍길동"}
print("홍길동" in person)      # False!
```

**원인** — 딕셔너리의 `in` 은 **키**를 검사합니다.
**해결** — 값을 찾으려면 `person.values()` 를 봅니다.

```python
"홍길동" in person.values()      # True
```

### `TypeError: unhashable type: 'list'`

```python
d = {[1, 2]: "값"}
```

```
TypeError: unhashable type: 'list'
```

**원인** — 리스트는 변할 수 있어서 키가 될 수 없습니다.
**해결** — 튜플로 바꿉니다. `d = {(1, 2): "값"}`

### 반복 중에 딕셔너리 수정

```python
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    if d[k] < 3:
        del d[k]
```

```
RuntimeError: dictionary changed size during iteration
```

**원인** — 순회 중 크기가 바뀌었습니다. 리스트와 달리 **명확한 에러**가 납니다 (다행입니다).
**해결** — 새 딕셔너리를 만들거나, 키 목록을 먼저 복사합니다.

```python
d = {k: v for k, v in d.items() if v >= 3}      # 권장
# 또는
for k in list(d.keys()):
    if d[k] < 3:
        del d[k]
```

### 딕셔너리도 대입은 복사가 아니다

```python
a = {"x": 1}
b = a
b["y"] = 2
print(a)          # {'x': 1, 'y': 2}
```

**원인** — 리스트와 같습니다. 딕셔너리도 **가변 객체**입니다.
**해결** — `b = a.copy()`. 중첩이면 `copy.deepcopy(a)`.

이 함정은 **함수 인자로 딕셔너리를 넘길 때** 특히 위험합니다.

```python
def add_default(config):
    config["timeout"] = 30      # ← 호출한 쪽의 딕셔너리도 바뀜!
    return config
```

호출한 쪽 원본을 바꾸지 않으려면 함수 안에서 복사하세요.

```python
def add_default(config):
    config = config.copy()
    config["timeout"] = 30
    return config
```

### `.items()` 없이 언패킹 시도

```python
for k, v in person:
    print(k, v)
```

```
ValueError: too many values to unpack (expected 2)
```

**원인** — 딕셔너리를 그냥 순회하면 **키만** 나옵니다. 키가 문자열이면 글자로 쪼개려다 실패합니다.
**해결** — `for k, v in person.items():`

### `.get()` 의 기본값을 매번 새로 만드는 실수

```python
groups.get(team, []).append(name)      # ❌ 동작하지 않음
```

**원인** — `get` 은 **딕셔너리에 넣어 주지 않습니다.** 임시로 만든 빈 리스트에 추가하고 버립니다.
**해결** — `setdefault` 를 쓰세요.

```python
groups.setdefault(team, []).append(name)      # ✅
```

에러가 안 나고 결과만 비는 **조용한 버그**입니다.

## ⑥ 확인 문제

**1.** 아래 코드에서 `counts` 의 최종 값을 예측하고, `get(word, 0)` 의 역할을 설명하세요.

```python
words = ["a", "b", "a", "c", "b", "a"]
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts)
```

<details>
<summary>답 보기</summary>

```
{'a': 3, 'b': 2, 'c': 1}
```

`get(word, 0)` 은 **"이 키가 이미 있으면 그 값을, 없으면 0을 달라"** 는 뜻입니다.

| 회차 | word | `counts.get(word, 0)` | 결과 |
|---|---|---|---|
| 1 | a | 0 (없음) | `{'a': 1}` |
| 2 | b | 0 (없음) | `{'a': 1, 'b': 1}` |
| 3 | a | 1 (있음) | `{'a': 2, 'b': 1}` |
| 4 | c | 0 | `{'a': 2, 'b': 1, 'c': 1}` |
| 5 | b | 1 | `{'a': 2, 'b': 2, 'c': 1}` |
| 6 | a | 2 | `{'a': 3, 'b': 2, 'c': 1}` |

`get` 없이 `counts[word] + 1` 을 하면 **첫 등장에서 `KeyError`** 가 납니다.

"없으면 초기값, 있으면 누적"이 **모든 집계의 기본 패턴**입니다.
W05의 `df.groupby().count()`, W09의 `GROUP BY` 가 이 일을 대신해 줄 뿐, 원리는 같습니다.
</details>

**2.** 아래 API 응답에서 `items` 의 첫 번째 항목의 `count` 값을 안전하게 꺼내는 코드를 쓰세요. 중간에 어떤 키가 없어도 프로그램이 죽으면 안 됩니다.

```python
resp = {"response": {"body": {"items": [{"name": "강남"}]}}}
```

<details>
<summary>답 보기</summary>

```python
items = resp.get("response", {}).get("body", {}).get("items", [])
count = items[0].get("count", 0) if items else 0
print(count)     # 0
```

**설명**

- `get("response", {})` — 없으면 **빈 딕셔너리**를 돌려주므로 다음 `.get()` 을 이어 쓸 수 있습니다.
  `None` 을 돌려주면 `None.get()` 에서 `AttributeError` 가 납니다.
- `get("items", [])` — 없으면 빈 리스트. 그러면 `if items` 가 거짓이 되어 인덱싱하지 않습니다.
- `items[0]` 은 리스트라 `get` 이 없으므로 **길이 검사가 별도로 필요**합니다.
  빈 리스트에 `[0]` 을 하면 `IndexError` 입니다.
- 이 예시에서는 `items[0]` 에 `count` 키 자체가 없으므로 `get("count", 0)` 이 `0` 을 돌려줍니다.

**함수로 만들어 두면 재사용됩니다.**

```python
def first_item_count(resp):
    items = resp.get("response", {}).get("body", {}).get("items", [])
    if not items:
        return 0
    return items[0].get("count", 0)
```

실제 공공데이터 API는 **오류일 때 응답 구조 자체가 달라집니다.**
(`items` 가 리스트가 아니라 빈 문자열 `""` 로 오는 경우도 있습니다.)
그래서 W04에서는 `resultCode` 를 먼저 확인하고 진행합니다.
</details>

**3.** [Day 005](day-005.md)의 가계부는 분류별 합계를 변수 5개로 관리했습니다. 딕셔너리로 바꾸면 무엇이 달라지나요? 코드로 비교하며 답하세요.

**달라지는 점**

## 오늘의 정리

| 항목 | 내용 |
|---|---|
| 만들기 | `{"key": "value"}` · 빈 딕셔너리 `{}` |
| 접근 | `d["key"]` (없으면 `KeyError`) · `d.get("key", 기본값)` **← 실무 기본** |
| 추가/수정 | `d["key"] = 값` · `d.update({...})` |
| 삭제 | `del d["key"]` · `d.pop("key")` |
| 순회 | `for k, v in d.items():` **← 가장 많이 씀** |
| 집계 | `d[k] = d.get(k, 0) + 값` |
| 그룹핑 | `d.setdefault(k, []).append(값)` |
| 정렬 | `sorted(d.items(), key=lambda kv: kv[1], reverse=True)` |
| 컴프리헨션 | `{k: v for k, v in d.items() if 조건}` |
| JSON 대응 | object↔dict · array↔list · `true`↔`True` · `null`↔`None` |
| 금기 | 반복 중 수정 (`RuntimeError`) · `get(k, []).append()` |

**과제** — 중첩 딕셔너리 검색 함수 `deep_get(data, path, default)` 를 직접 구현하고,
아래 세 가지를 모두 통과시키세요.
① `deep_get(cfg, "db.credentials.user")` 로 값을 꺼낸다
② 중간 키가 없으면 `default` 를 돌려준다
③ 중간 값이 딕셔너리가 아니면(예: 문자열) `KeyError`·`TypeError` 없이 `default` 를 돌려준다
