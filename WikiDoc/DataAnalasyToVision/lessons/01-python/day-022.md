## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 총알처럼 **생겼다 사라지는 객체**를 생성·관리·제거할 수 있다.
- 쿨타임으로 연사 속도를 제어할 수 있다.
- 화면 밖으로 나간 객체를 정리해 메모리 누수를 막을 수 있다.

---

## ② 왜 필요한가

플레이어는 하나지만 총알은 다릅니다.

```
0.0초: 총알 0개
0.2초: 총알 1개 생성
0.4초: 총알 2개
1.0초: 총알 5개 (1번 총알은 화면 밖으로 나감 → 제거해야 함)
```

**끊임없이 태어나고 죽는 객체**를 다루는 것이 오늘의 주제입니다.

여기서 두 가지 함정이 있습니다.

| 함정 | 결과 |
|---|---|
| 화면 밖 총알을 안 지움 | 1분이면 수천 개가 쌓여 FPS 급락 |
| 발사를 상태 방식으로 | 1초에 60발 (게임 붕괴) |

이 패턴은 게임 밖에서도 계속 나옵니다.
대단원 05의 CCTV 시스템도 "프레임마다 검출 결과가 생기고, 오래된 것은 지운다"는 같은 구조입니다.

## ③ 개념 설명

### 총알의 생애주기

```
① 생성  플레이어가 발사키를 누름 → Bullet 객체 생성 → 그룹에 추가
② 이동  매 프레임 위로 이동
③ 소멸  ㄱ. 화면 밖으로 나감
        ㄴ. 적에게 명중 (Day 024)
```

**③이 없으면 프로그램이 죽습니다.** 반드시 구현해야 합니다.

### Bullet 클래스

```python
class Bullet(pygame.sprite.Sprite):
    """위로 날아가는 총알."""

    def __init__(self, x, y, speed=-12):
        super().__init__()
        self.image = make_bullet_surface()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.speed = speed              # 음수 = 위쪽 (y축은 아래로 증가)

    def update(self):
        self.pos_y += self.speed
        self.rect.centery = int(self.pos_y)

        # 화면 밖으로 나가면 스스로 사라진다
        if self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT:
            self.kill()
```

> **`self.kill()` 이 핵심입니다.** 총알이 **스스로** 자신을 정리합니다.
> 밖에서 "누가 화면을 나갔는지" 검사하는 코드를 쓸 필요가 없습니다.

### `kill()` 이 순회 중 삭제 문제를 해결하는 이유

[Day 011](day-011.md)에서 배운 함정입니다.

```python
# ❌ 리스트로 직접 관리 — 요소를 건너뜀
for bullet in bullets:
    if bullet.rect.bottom < 0:
        bullets.remove(bullet)         # 위험!
```

```python
# ✅ Group 과 kill()
for bullet in bullets:                 # Group.update() 가 알아서
    bullet.update()                    # update() 안에서 kill() 호출
```

pygame의 `Group.update()` 는 **내부적으로 복사본을 순회**하므로, 순회 중에 `kill()` 을 해도 안전합니다.

### 쿨타임 — 연사 속도 제어

**방법 ① 프레임 카운터 (간단, 권장)**

```python
class Player(pygame.sprite.Sprite):
    SHOOT_COOLDOWN = 12          # 12프레임(0.2초)마다 한 발

    def __init__(self, ...):
        self.shoot_timer = 0

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1

    def can_shoot(self):
        return self.shoot_timer <= 0

    def shoot(self):
        """발사 가능하면 총알을 만들어 반환, 아니면 None."""
        if not self.can_shoot():
            return None
        self.shoot_timer = Player.SHOOT_COOLDOWN
        return Bullet(self.rect.centerx, self.rect.top)
```

**방법 ② 시간 기준 (`pygame.time.get_ticks()`)**

```python
now = pygame.time.get_ticks()          # 프로그램 시작 후 흐른 밀리초
if now - self.last_shot > 200:         # 200ms 마다
    self.last_shot = now
    shoot()
```

> 프레임 방식이 이해하기 쉽고 FPS가 고정돼 있으면 충분합니다. 오늘은 ①번을 씁니다.

### 발사 입력 — 두 방식 조합

```python
# ① 단발 — 누른 순간
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
        bullet = player.shoot()
        if bullet:
            all_sprites.add(bullet)
            bullets.add(bullet)

# ② 연사 — 누르고 있으면 쿨타임마다
keys = pygame.key.get_pressed()
if keys[pygame.K_SPACE]:
    bullet = player.shoot()            # 쿨타임이 알아서 제어
    if bullet:
        all_sprites.add(bullet)
        bullets.add(bullet)
```

> **연사에는 상태 방식 + 쿨타임을 씁니다.** 쿨타임이 있으니 폭주하지 않습니다.
> 쿨타임 없이 상태 방식만 쓰면 1초에 60발이 나갑니다. ([Day 020](day-020.md))

### 총알을 여러 발 동시에 — 확산탄

```python
def shoot_spread(self, count=3, spread=6):
    """부채꼴로 여러 발을 발사합니다."""
    if not self.can_shoot():
        return []

    self.shoot_timer = Player.SHOOT_COOLDOWN
    bullets = []

    # count=3 이면 -1, 0, 1 / count=5 면 -2..2
    start = -(count // 2)
    for i in range(count):
        offset = start + i
        b = Bullet(self.rect.centerx, self.rect.top)
        b.vel_x = offset * spread      # 좌우로 퍼짐
        bullets.append(b)

    return bullets
```

### 스프라이트 생성을 함수/그룹으로 묶기

발사할 때마다 그룹 두 곳에 추가해야 하니 반복이 생깁니다.

```python
def spawn_bullet(bullet, *groups):
    """총알을 여러 그룹에 한 번에 등록합니다."""
    for g in groups:
        g.add(bullet)
    return bullet
```

pygame은 아예 `Sprite` 생성자에서 그룹을 받을 수 있게 해 뒀습니다.

```python
class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y, *groups):
        super().__init__(*groups)      # 생성과 동시에 그룹에 소속
        ...

Bullet(x, y, all_sprites, bullets)     # 두 그룹에 바로 등록
```

> 이 방식이 코드가 짧아지지만, 처음에는 **명시적으로 `add()` 하는 편**이 무슨 일이 일어나는지 보기 좋습니다.

### 객체 수 관리 — 상한 두기

```python
MAX_BULLETS = 40

if len(bullets) < MAX_BULLETS:
    spawn_bullet(...)
```

> 실수로 쿨타임이 0이 되거나 버그가 나도 **최악의 상황을 막아 주는 안전장치**입니다.
> 실무에서도 "무한히 늘어날 수 있는 것"에는 반드시 상한을 둡니다.

## ④ 단계별 실습

### Step 1. 첫 총알 발사

`shooting_v1.py` 를 만들어 실행합니다.

```python
import pygame

# ══════════ 상수 ══════════
SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

PLAYER_SPEED = 6
PLAYER_SIZE = 48
BULLET_SPEED = -12               # 음수 = 위쪽
BULLET_COOLDOWN = 12             # 프레임
MAX_BULLETS = 40

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)
COLOR_PLAYER = (52, 152, 219)
COLOR_BULLET = (241, 196, 15)


# ══════════ Surface ══════════
def make_ship(size, color):
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, color, [
        (size // 2, 0), (size, size), (size // 2, size * 0.78), (0, size),
    ])
    pygame.draw.circle(surf, (241, 196, 15), (size // 2, size // 2), size // 7)
    return surf


def make_bullet(width=6, height=18, color=COLOR_BULLET):
    surf = pygame.Surface((width, height), pygame.SRCALPHA)
    pygame.draw.rect(surf, color, (0, 0, width, height), border_radius=3)
    return surf


# ══════════ 클래스 ══════════
class Bullet(pygame.sprite.Sprite):
    """위로 날아가는 총알."""

    def __init__(self, x, y, speed=BULLET_SPEED):
        super().__init__()
        self.image = make_bullet()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.speed = speed

    def update(self):
        self.pos_y += self.speed
        self.rect.centery = int(self.pos_y)

        # 화면 밖이면 스스로 제거 — 이게 없으면 총알이 무한히 쌓입니다
        if self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT:
            self.kill()


class Player(pygame.sprite.Sprite):
    """총을 쏘는 플레이어."""

    def __init__(self, x, y):
        super().__init__()
        self.image = make_ship(PLAYER_SIZE, COLOR_PLAYER)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)

        self.speed = PLAYER_SPEED
        self.shoot_timer = 0
        self.shots_fired = 0

    @property
    def can_shoot(self):
        return self.shoot_timer <= 0

    def shoot(self):
        """발사 가능하면 Bullet 을 반환, 아니면 None."""
        if not self.can_shoot:
            return None

        self.shoot_timer = BULLET_COOLDOWN
        self.shots_fired += 1
        return Bullet(self.rect.centerx, self.rect.top)

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1

        self.rect.centerx = int(self.pos_x)
        self.rect.centery = int(self.pos_y)
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


# ══════════ 초기화 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 022 - 총알 발사")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 80)

all_sprites = pygame.sprite.Group(player)
bullets = pygame.sprite.Group()

max_bullets_seen = 0

# ══════════ 게임 루프 ══════════
running = True
while running:
    # ① 이벤트
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # ② 갱신
    keys = pygame.key.get_pressed()
    player.handle_input(keys)

    # 연사 — 상태 방식 + 쿨타임
    if keys[pygame.K_SPACE] and len(bullets) < MAX_BULLETS:
        bullet = player.shoot()
        if bullet:
            all_sprites.add(bullet)
            bullets.add(bullet)

    all_sprites.update()

    max_bullets_seen = max(max_bullets_seen, len(bullets))

    # ③ 그리기
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)

    info = [
        f"화면의 총알: {len(bullets)}개  (최대 기록 {max_bullets_seen})",
        f"총 발사: {player.shots_fired}발",
        f"쿨타임: {player.shoot_timer}",
        f"전체 스프라이트: {len(all_sprites)}개",
        f"FPS: {clock.get_fps():.0f}",
        "",
        "SPACE=발사(누르고 있으면 연사)   방향키=이동",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print(f"총 {player.shots_fired}발 발사")
```

**직접 확인하세요** — 스페이스를 계속 누르고 있으면 총알이 일정 간격으로 나갑니다.
그리고 **`화면의 총알` 개수가 어느 선에서 안정**됩니다. 화면 밖으로 나간 총알이 `kill()` 로 사라지기 때문입니다.

> **실험** — `update()` 에서 `self.kill()` 부분을 주석 처리하고 30초간 연사해 보세요.
> `전체 스프라이트` 가 수천 개로 늘어나고 FPS가 떨어지는 것을 볼 수 있습니다.

### Step 2. 총알 종류 늘리기 — 상속 활용

```python
import pygame
import math

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)
COLOR_PLAYER = (52, 152, 219)


def make_bullet_surface(w, h, color, shape="rect"):
    surf = pygame.Surface((w, h), pygame.SRCALPHA)
    if shape == "rect":
        pygame.draw.rect(surf, color, (0, 0, w, h), border_radius=3)
    else:
        pygame.draw.circle(surf, color, (w // 2, h // 2), min(w, h) // 2)
    return surf


class Bullet(pygame.sprite.Sprite):
    """총알의 부모 클래스."""

    SPEED = -12
    DAMAGE = 1
    COLOR = (241, 196, 15)
    SIZE = (6, 18)

    def __init__(self, x, y, vel_x=0.0):
        super().__init__()
        self.image = make_bullet_surface(*self.SIZE, self.COLOR)
        self.rect = self.image.get_rect(center=(x, y))

        self.pos_x, self.pos_y = float(x), float(y)
        self.vel_x = vel_x
        self.vel_y = float(self.SPEED)
        self.damage = self.DAMAGE

    def update(self):
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        if (self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT
                or self.rect.right < 0 or self.rect.left > SCREEN_WIDTH):
            self.kill()


class NormalBullet(Bullet):
    """기본 총알 — 직선."""
    pass


class SpreadBullet(Bullet):
    """확산탄 — 좌우로 퍼짐. 느리고 약함."""
    SPEED = -9
    DAMAGE = 1
    COLOR = (46, 204, 113)
    SIZE = (8, 8)


class HeavyBullet(Bullet):
    """강화탄 — 느리지만 강함."""
    SPEED = -7
    DAMAGE = 3
    COLOR = (231, 76, 60)
    SIZE = (14, 24)


class WaveBullet(Bullet):
    """물결탄 — 좌우로 흔들리며 날아감."""
    SPEED = -10
    DAMAGE = 2
    COLOR = (155, 89, 182)
    SIZE = (10, 14)

    def __init__(self, x, y, vel_x=0.0, phase=0.0):
        super().__init__(x, y, vel_x)
        self.start_x = float(x)
        self.timer = 0
        self.phase = phase

    def update(self):
        self.timer += 1
        self.pos_y += self.vel_y
        # 사인파로 좌우 진동
        self.pos_x = self.start_x + math.sin(self.timer * 0.15 + self.phase) * 45
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        if self.rect.bottom < 0:
            self.kill()


class Player(pygame.sprite.Sprite):
    COOLDOWN = {"normal": 10, "spread": 20, "heavy": 30, "wave": 16}

    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((48, 48), pygame.SRCALPHA)
        pygame.draw.polygon(self.image, COLOR_PLAYER,
                            [(24, 0), (48, 48), (24, 37), (0, 48)])
        pygame.draw.circle(self.image, (241, 196, 15), (24, 24), 7)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)

        self.speed = 6
        self.weapon = "normal"
        self.shoot_timer = 0

    def switch_weapon(self, weapon):
        if weapon in Player.COOLDOWN:
            self.weapon = weapon
            self.shoot_timer = 0

    def shoot(self):
        """무기 종류에 따라 총알 리스트를 반환합니다."""
        if self.shoot_timer > 0:
            return []

        self.shoot_timer = Player.COOLDOWN[self.weapon]
        cx, top = self.rect.centerx, self.rect.top

        if self.weapon == "normal":
            return [NormalBullet(cx, top)]

        elif self.weapon == "spread":
            # -2, -1, 0, 1, 2 방향으로 5발
            return [SpreadBullet(cx, top, vel_x=offset * 3.0)
                    for offset in range(-2, 3)]

        elif self.weapon == "heavy":
            return [HeavyBullet(cx, top)]

        elif self.weapon == "wave":
            return [WaveBullet(cx, top, phase=0),
                    WaveBullet(cx, top, phase=math.pi)]

        return []

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT]:
            dx -= 1
        if keys[pygame.K_RIGHT]:
            dx += 1
        if keys[pygame.K_UP]:
            dy -= 1
        if keys[pygame.K_DOWN]:
            dy += 1

        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length

        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 022 - 총알 종류")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 80)
all_sprites = pygame.sprite.Group(player)
bullets = pygame.sprite.Group()

WEAPON_KEYS = {
    pygame.K_1: "normal",
    pygame.K_2: "spread",
    pygame.K_3: "heavy",
    pygame.K_4: "wave",
}

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key in WEAPON_KEYS:
                player.switch_weapon(WEAPON_KEYS[event.key])

    keys = pygame.key.get_pressed()
    player.handle_input(keys)

    if keys[pygame.K_SPACE] and len(bullets) < 120:
        for b in player.shoot():                 # 리스트를 반환하므로 반복
            all_sprites.add(b)
            bullets.add(b)

    all_sprites.update()

    screen.fill(COLOR_BG)
    all_sprites.draw(screen)

    total_damage = sum(b.damage for b in bullets)
    info = [
        f"무기: {player.weapon}   (1=기본 2=확산 3=강화 4=물결)",
        f"총알: {len(bullets)}개   화면 총 데미지: {total_damage}",
        f"쿨타임: {player.shoot_timer}/{Player.COOLDOWN[player.weapon]}",
        f"FPS: {clock.get_fps():.0f}",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 5가지**
> - **클래스 변수로 총알 특성을 정의**했습니다(`SPEED`, `DAMAGE`, `COLOR`, `SIZE`). 자식 클래스가 값만 바꾸면 새 총알이 됩니다.
> - `make_bullet_surface(*self.SIZE, self.COLOR)` — `self.SIZE` 는 튜플이므로 `*` 로 풀어 넘깁니다. ([Day 009](day-009.md))
> - `WaveBullet` 은 `update()` 를 **오버라이딩**해 사인파 이동을 구현합니다. 나머지는 부모 것을 그대로 씁니다.
> - `shoot()` 이 **리스트를 반환**합니다. 한 발이든 다섯 발이든 호출하는 쪽 코드가 같습니다.
> - `sum(b.damage for b in bullets)` — 종류가 섞여 있어도 하나의 식으로 계산됩니다. **다형성**입니다. ([Day 017](day-017.md))

### Step 3. 총알 관리 실험 — kill() 유무 비교 (오늘의 종합 예제)

```python
import pygame

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)
COLOR_WARN = (231, 76, 60)
COLOR_OK = (46, 204, 113)


def make_bullet(color=(241, 196, 15)):
    surf = pygame.Surface((6, 16), pygame.SRCALPHA)
    pygame.draw.rect(surf, color, (0, 0, 6, 16), border_radius=3)
    return surf


class Bullet(pygame.sprite.Sprite):
    """kill() 여부를 토글할 수 있는 총알."""

    auto_kill = True               # 클래스 변수 — 모든 총알이 공유

    def __init__(self, x, y):
        super().__init__()
        self.image = make_bullet(COLOR_OK if Bullet.auto_kill else COLOR_WARN)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.speed = -10.0

    def update(self):
        self.pos_y += self.speed
        self.rect.centery = int(self.pos_y)

        if Bullet.auto_kill and self.rect.bottom < 0:
            self.kill()


class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 40), pygame.SRCALPHA)
        pygame.draw.polygon(self.image, (52, 152, 219),
                            [(20, 0), (40, 40), (20, 31), (0, 40)])
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x = float(x)
        self.shoot_timer = 0

    def shoot(self):
        if self.shoot_timer > 0:
            return None
        self.shoot_timer = 4              # 아주 빠른 연사 (실험용)
        return Bullet(self.rect.centerx, self.rect.top)

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1
        self.rect.centerx = int(self.pos_x)
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x = float(self.rect.centerx)


pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 022 - kill() 실험")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)
big_font = pygame.font.SysFont("malgungothic", 30)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 60)
all_sprites = pygame.sprite.Group(player)
bullets = pygame.sprite.Group()

fps_samples = []

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_k:
                Bullet.auto_kill = not Bullet.auto_kill
            elif event.key == pygame.K_c:
                bullets.empty()                  # 총알 전부 제거
                all_sprites.empty()
                all_sprites.add(player)
                fps_samples.clear()

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player.pos_x -= 8
    if keys[pygame.K_RIGHT]:
        player.pos_x += 8

    if keys[pygame.K_SPACE]:
        b = player.shoot()
        if b:
            all_sprites.add(b)
            bullets.add(b)

    all_sprites.update()

    fps_samples.append(clock.get_fps())
    if len(fps_samples) > 120:
        fps_samples.pop(0)
    avg_fps = sum(fps_samples) / len(fps_samples) if fps_samples else 0

    # ── 그리기 ──
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)

    mode_color = COLOR_OK if Bullet.auto_kill else COLOR_WARN
    mode_text = "kill() 켜짐 — 화면 밖 총알 자동 제거" if Bullet.auto_kill \
        else "kill() 꺼짐 — 총알이 계속 쌓임!"

    screen.blit(big_font.render(mode_text, True, mode_color), (20, 20))

    info = [
        f"총알 개수: {len(bullets)}",
        f"전체 스프라이트: {len(all_sprites)}",
        f"현재 FPS: {clock.get_fps():.1f}",
        f"평균 FPS(2초): {avg_fps:.1f}",
        "",
        "SPACE=연사   ←→=이동   K=kill() 토글   C=전부 제거",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (20, 70 + i * 24))

    if len(bullets) > 500:
        warn = big_font.render("⚠ 총알이 500개를 넘었습니다!", True, COLOR_WARN)
        screen.blit(warn, warn.get_rect(center=(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 60)))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print(f"종료 시점 총알: {len(bullets)}개")
```

**실험 순서**

1. 실행 후 **`K` 를 눌러 kill() 을 끕니다.** (총알이 빨간색으로 바뀝니다)
2. **스페이스를 30초간 누르고 있습니다.**
3. `총알 개수` 와 `평균 FPS` 를 관찰합니다.

| 경과 | kill() 켜짐 | kill() 꺼짐 |
|---|---|---|
| 5초 | 약 15개 · 60 FPS | 약 75개 · 60 FPS |
| 15초 | 약 15개 · 60 FPS | 약 225개 · 55 FPS |
| 30초 | 약 15개 · 60 FPS | 약 450개 · 40 FPS 이하 |

> **왜 이렇게 되는가** — 화면 밖으로 나간 총알도 매 프레임 `update()` 가 호출되고, `draw()` 대상에 포함됩니다.
> 보이지도 않는 것을 계속 계산하는 것입니다.
>
> **이 문제는 게임 밖에서도 똑같이 일어납니다.**

## ⑤ 자주 하는 실수

### 화면 밖 총알을 제거하지 않음

**증상** — 시간이 지날수록 FPS가 떨어지고, 결국 프로그램이 멈춥니다.
**해결** — `update()` 안에서 경계를 벗어나면 `self.kill()`.

```python
if self.rect.bottom < 0:
    self.kill()
```

> **모든 방향을 확인하세요.** 위로만 검사하면 좌우로 퍼지는 확산탄이 안 지워집니다.
> ```python
> if (self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT
>         or self.rect.right < 0 or self.rect.left > SCREEN_WIDTH):
>     self.kill()
> ```

**2.** 총알이 **화면 위쪽 벽에 부딪히면 아래로 튕겨 나오는** `BounceBullet` 을 만드세요. 최대 3번까지 튕기고 그 뒤에 사라집니다.

<details>
<summary>답 보기</summary>

```python
class BounceBullet(Bullet):
    """벽에 튕기는 총알. 최대 3번."""

    SPEED = -10
    DAMAGE = 2
    COLOR = (26, 188, 156)
    SIZE = (10, 10)
    MAX_BOUNCES = 3

    def __init__(self, x, y, vel_x=3.0):
        super().__init__(x, y, vel_x)
        self.bounces = 0

    def update(self):
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        bounced = False

        # 위/아래 벽
        if self.rect.top <= 0:
            self.rect.top = 0
            self.pos_y = float(self.rect.centery)
            self.vel_y = abs(self.vel_y)          # 아래로
            bounced = True
        elif self.rect.bottom >= SCREEN_HEIGHT:
            self.rect.bottom = SCREEN_HEIGHT
            self.pos_y = float(self.rect.centery)
            self.vel_y = -abs(self.vel_y)         # 위로
            bounced = True

        # 좌/우 벽
        if self.rect.left <= 0:
            self.rect.left = 0
            self.pos_x = float(self.rect.centerx)
            self.vel_x = abs(self.vel_x)
            bounced = True
        elif self.rect.right >= SCREEN_WIDTH:
            self.rect.right = SCREEN_WIDTH
            self.pos_x = float(self.rect.centerx)
            self.vel_x = -abs(self.vel_x)
            bounced = True

        if bounced:
            self.bounces += 1
            if self.bounces >= BounceBullet.MAX_BOUNCES:
                self.kill()
```

**포인트 5가지**
- **위치 보정과 방향 지정을 함께** 합니다. `-self.vel_y` 가 아니라 `abs()` / `-abs()` 를 쓰면 떨림이 원천 차단됩니다. ([Day 019](day-019.md))
- `rect` 를 보정한 뒤 **`pos_x`/`pos_y` 도 되돌립니다.** 안 하면 [Day 021](day-021.md)의 어긋남 버그가 납니다.
- `bounced` 플래그를 써서, 모서리에서 x·y 양쪽에 부딪혀도 **튕김 횟수는 1로 셉니다.**
- 부모의 `update()` 를 쓰지 않고 완전히 새로 썼습니다. 부모의 `kill()` 조건(화면 밖)이 이 총알에는 맞지 않기 때문입니다.
- `MAX_BOUNCES` 를 클래스 변수로 두어 나중에 조정하기 쉽게 했습니다.
</details>

**3.** 아래는 확산탄 발사 코드입니다. 실행하면 총알이 전부 같은 자리에서 겹쳐 위로만 날아갑니다. 원인과 해결책을 쓰세요.

```python
class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = make_bullet()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.vel_x = 0
        self.vel_y = -10

        self.pos_y += self.vel_y
        self.rect.centery = int(self.pos_y)
        if self.rect.bottom < 0:
            self.kill()


def shoot_spread(player):
    bullets = []
    for offset in range(-2, 3):
        b = Bullet(player.rect.centerx, player.rect.top)
        b.vel_x = offset * 3
        bullets.append(b)
    return bullets
```

<details>
<summary>답 보기</summary>

**원인 — `update()` 가 `vel_x` 를 전혀 사용하지 않습니다.**

밖에서 `b.vel_x = offset * 3` 으로 값을 설정했지만,
`update()` 안에는 `self.pos_y += self.vel_y` 만 있고 **x 이동 코드가 없습니다.**

그리고 `pos_x` 라는 속성 자체가 없습니다. `rect.centerx` 는 생성 시 값 그대로 고정됩니다.

**해결**

```python
class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y, vel_x=0.0, vel_y=-10.0):
        super().__init__()
        self.image = make_bullet()
        self.rect = self.image.get_rect(center=(x, y))

        self.pos_x = float(x)          # ← x 위치도 float 으로 관리
        self.pos_y = float(y)
        self.vel_x = float(vel_x)
        self.vel_y = float(vel_y)

    def update(self):
        self.pos_x += self.vel_x       # ← x 이동 추가
        self.pos_y += self.vel_y
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        # 네 방향 모두 확인
        if (self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT
                or self.rect.right < 0 or self.rect.left > SCREEN_WIDTH):
            self.kill()


def shoot_spread(player, count=5, spread=3.0):
    """부채꼴로 여러 발을 발사합니다."""
    start = -(count // 2)
    return [
        Bullet(player.rect.centerx, player.rect.top, vel_x=(start + i) * spread)
        for i in range(count)
    ]
```

**포인트 3가지**
- **속도를 생성자 인자로 받는 편이 안전합니다.** 밖에서 속성을 직접 설정하는 방식은 `update()` 가 그 값을 쓰는지 보장할 수 없습니다.
- x 방향으로도 움직이므로 **좌우 경계 검사**를 반드시 추가해야 합니다. 안 하면 옆으로 나간 총알이 영원히 남습니다.
- `float` 로 관리해야 `vel_x = 1.5` 같은 미세한 각도를 표현할 수 있습니다.

> **교훈** — **객체의 속성은 `update()` 가 실제로 사용해야 의미가 있습니다.**
> "값을 설정했는데 아무 일도 안 일어난다" 면, 그 값을 읽는 코드가 있는지 먼저 확인하세요.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 생애주기 | 생성 → 이동 → **소멸** (③이 필수) |
| `kill()` | 스프라이트가 스스로 모든 그룹에서 제거 |
| 경계 검사 | **네 방향 모두** 확인 (좌우로 움직이는 총알 주의) |
| 쿨타임 3종 | ① 설정 ② **감소** ③ 확인 |
| 발사 입력 | 단발=`KEYDOWN` / 연사=`get_pressed` + 쿨타임 |
| 그룹 등록 | 그리기용(`all_sprites`) + 충돌용(`bullets`) **양쪽에** |
| 총알 종류 | 클래스 변수로 특성 정의 → 상속으로 확장 |
| 상한 | `if len(bullets) < MAX_BULLETS:` 안전장치 |

**오늘 반드시 기억할 세 가지**
> ① **만든 것은 반드시 지웁니다.** 화면 밖 총알은 `kill()`.
> ② 쿨타임은 **설정·감소·확인 세 곳**이 모두 있어야 동작합니다.
> ③ 총알은 **그리기용과 충돌용 두 그룹**에 모두 등록하세요.
