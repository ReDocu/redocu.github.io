## ② 왜 필요한가

Day 005에서 만든 계산기를 떠올려 봅시다. 지금은 계산이 한 번뿐이라 괜찮았습니다.
그런데 프로그램 여기저기서 "두 수를 더한 뒤 소수점 둘째 자리로 반올림해 출력" 하는 일이 필요하다면?

```python
result = round(a + b, 2)
print(f"결과: {result}")
# ... 200줄 뒤 ...
result = round(x + y, 2)
print(f"결과: {result}")
# ... 또 100줄 뒤 ...
result = round(p + q, 2)
print(f"결과: {result}")
```

이 코드에는 세 가지 문제가 있습니다.

| 문제 | 설명 |
|---|---|
| **중복** | 같은 코드가 세 곳에 있습니다 |
| **수정 지옥** | 소수점을 3자리로 바꾸려면 세 곳을 모두 고쳐야 합니다. 하나 빠뜨리면 버그 |
| **의미 불명** | `round(a + b, 2)` 만 봐서는 이게 무슨 계산인지 알 수 없습니다 |

**함수는 코드 묶음에 이름을 붙이는 일**입니다. 이름을 붙이면 재사용할 수 있고, 고칠 곳이 한 군데가 되고, 무슨 일을 하는지 읽힙니다.

```python
def add_price(a, b):
    return round(a + b, 2)

print(f"결과: {add_price(1000, 2500)}")
```

W05에서 게임을 만들 때, 코드가 300줄을 넘어가면 함수 없이는 관리가 불가능해집니다.

## ③ 개념 설명

### 함수의 정의와 호출

```python
def 함수이름(매개변수):
    실행할 코드
    return 반환값
```

```python
# 정의 — 만들어만 두는 것. 이 시점엔 실행되지 않습니다
def greet():
    print("안녕하세요!")

# 호출 — 실제로 실행하는 것
greet()
greet()
```

실행 결과:

```
안녕하세요!
안녕하세요!
```

> **정의(define)와 호출(call)은 다릅니다.**
> `def` 는 "이런 기능을 만들어 두겠다" 는 선언일 뿐이고, 실제 실행은 `greet()` 이라고 이름을 부를 때 일어납니다.
> 그래서 **함수는 호출하기 전에 정의되어 있어야 합니다.**

### 매개변수와 인자 — 값을 넘기기

```python
def greet(name):          # name 은 매개변수(parameter)
    print(f"{name}님, 안녕하세요!")

greet("홍길동")            # "홍길동" 은 인자(argument)
greet("김철수")
```

실행 결과:

```
홍길동님, 안녕하세요!
김철수님, 안녕하세요!
```

| 용어 | 뜻 | 위치 |
|---|---|---|
| **매개변수** (parameter) | 함수가 받기로 한 값의 이름 | `def` 줄의 괄호 안 |
| **인자** (argument) | 실제로 넘긴 값 | 호출할 때 괄호 안 |

매개변수는 여러 개일 수 있습니다. **순서대로** 대응됩니다.

```python
def introduce(name, age, city):
    print(f"{name}({age}세)은 {city}에 삽니다.")

introduce("홍길동", 25, "서울")
```

실행 결과:

```
홍길동(25세)은 서울에 삽니다.
```

**키워드 인자**를 쓰면 순서를 바꿔도 됩니다.

```python
introduce(age=25, city="서울", name="홍길동")   # 같은 결과
```

### return — 결과를 돌려주기

`print` 는 화면에 보여 줄 뿐, 그 값을 다른 곳에서 쓸 수 없습니다.
계산 결과를 **다시 쓰려면** `return` 이 필요합니다.

```python
# print 만 하는 함수
def add_print(a, b):
    print(a + b)

# return 하는 함수
def add_return(a, b):
    return a + b

add_print(3, 5)              # 화면에 8 출력. 하지만 값을 못 씀
result = add_return(3, 5)    # 값을 받아 변수에 담을 수 있음
print(result * 2)            # 16
```

실행 결과:

```
8
16
```

**`return` 의 두 가지 성질**

1. `return` 을 만나면 **함수가 즉시 끝납니다.** 그 아래 코드는 실행되지 않습니다.
2. `return` 이 없거나 값 없이 `return` 만 쓰면 **`None`** 이 반환됩니다.

```python
def check(score):
    if score >= 60:
        return "합격"
    return "불합격"          # else 없이도 됨 (위에서 return 하면 여기 안 옴)

print(check(85))            # 합격
print(check(40))            # 불합격
```

```python
def no_return():
    print("실행됨")

result = no_return()
print(result)               # None
```

### return 을 이용한 조기 종료 (가드 절)

```python
def divide(a, b):
    if b == 0:
        print("0으로 나눌 수 없습니다")
        return None          # 여기서 함수 끝
    return a / b

print(divide(10, 2))         # 5.0
print(divide(10, 0))         # None (에러 메시지 출력 후)
```

> 잘못된 경우를 **함수 앞부분에서 걸러 내고 바로 `return`** 하는 방식을 **가드 절(guard clause)** 이라고 합니다.
> 중첩 `if` 를 줄여 주므로 읽기가 훨씬 편해집니다.

### 여러 값 반환하기

`return` 뒤에 값을 콤마로 나열하면 여러 개를 돌려줄 수 있습니다.

```python
def get_stats(a, b, c):
    total = a + b + c
    average = total / 3
    return total, average          # 두 값을 함께 반환

t, avg = get_stats(80, 90, 70)     # 두 변수로 나눠 받기
print(f"총점 {t}, 평균 {avg:.1f}")
```

실행 결과:

```
총점 240, 평균 80.0
```

### 스코프 — 변수가 사는 범위

함수 안에서 만든 변수는 **함수 안에서만** 존재합니다. 이것을 **지역변수(local variable)** 라고 합니다.

```python
def my_func():
    message = "함수 안"       # 지역변수
    print(message)

my_func()
print(message)               # NameError!
```

```
함수 안
NameError: name 'message' is not defined
```

반대로 함수 밖에서 만든 변수는 **전역변수(global variable)** 이고, 함수 안에서 **읽을 수는** 있습니다.

```python
count = 10                   # 전역변수

def show():
    print(count)             # 읽기는 가능

show()                       # 10
```

하지만 **값을 바꾸려 하면 문제가 생깁니다.**

```python
count = 10

def increase():
    count = count + 1        # UnboundLocalError!

increase()
```

```
UnboundLocalError: cannot access local variable 'count'
where it is not associated with a value
```

**이유** — 함수 안에서 `count = ...` 라고 쓰는 순간, 파이썬은 `count` 를 새 지역변수로 판단합니다.
그런데 오른쪽의 `count + 1` 을 계산하려니 아직 값이 없어서 에러가 납니다.

**해결 방법 두 가지**

```python
# 방법 1: global 선언 (권장하지 않음)
count = 10

def increase():
    global count
    count = count + 1

increase()
print(count)                 # 11
```

```python
# 방법 2: 인자로 받고 결과를 return (권장)
def increase(n):
    return n + 1

count = 10
count = increase(count)
print(count)                 # 11
```

> **왜 `global` 을 권장하지 않는가** — 함수가 바깥 세상을 몰래 바꾸면, 나중에 버그가 났을 때 **어디서 값이 바뀌었는지 추적이 불가능**해집니다.
> 좋은 함수는 **"받은 것만 보고, 결과만 돌려준다"** 는 원칙을 지킵니다.

### 좋은 함수의 조건

| 원칙 | 설명 |
|---|---|
| **하나의 일만 한다** | 이름에 "그리고"가 들어가면 나눠야 할 신호 |
| **이름이 하는 일을 말한다** | `f()`, `func1()` ❌ → `calculate_bmi()` ✅ |
| **동사로 시작한다** | `get_`, `calc_`, `is_`, `print_`, `save_` |
| **참/거짓을 반환하면 `is_`/`has_`** | `is_valid()`, `has_ticket()` |
| **20줄을 넘지 않는다** | 넘으면 안에서 또 나눌 수 있는지 본다 |

### Step 2. 계산기를 함수로 분리하기

Day 005의 계산기를 함수로 다시 만듭니다.

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    if b == 0:
        return None          # 0으로 나누는 경우 None 반환
    return a / b


def calculate(a, op, b):
    """연산자에 따라 알맞은 계산 함수를 호출합니다."""
    if op == "+":
        return add(a, b)
    elif op == "-":
        return subtract(a, b)
    elif op == "*":
        return multiply(a, b)
    elif op == "/":
        return divide(a, b)
    else:
        return None


# 사용
num1 = float(input("첫 번째 숫자: "))
op = input("연산자 (+ - * /): ").strip()
num2 = float(input("두 번째 숫자: "))

result = calculate(num1, op, num2)

if result is None:
    print("계산할 수 없습니다. (0으로 나누기 또는 잘못된 연산자)")
else:
    print(f"{num1} {op} {num2} = {result:.2f}")
```

실행 결과:

```
첫 번째 숫자: 17
연산자 (+ - * /): /
두 번째 숫자: 5
17.0 / 5.0 = 3.40
```

> **Day 005 버전과 비교해 보세요.** 조건문 안에 계산식이 뒤엉켜 있던 것이, 이제는
> "계산 함수 4개" + "무엇을 부를지 고르는 함수 1개" + "입출력" 으로 역할이 나뉘었습니다.
> 새 연산자(`%`)를 추가하려면 함수 하나를 만들고 `calculate` 에 한 줄만 더하면 됩니다.

### Step 3. 검증 함수 만들기

참/거짓을 반환하는 함수는 조건문을 훨씬 읽기 좋게 만듭니다.

```python
def is_valid_score(score):
    """점수가 0~100 범위인지 확인합니다."""
    return 0 <= score <= 100


def is_adult(age):
    """성인인지 확인합니다."""
    return age >= 19


def is_palindrome(word):
    """앞뒤가 같은 단어인지 확인합니다."""
    cleaned = word.strip().lower()
    return cleaned == cleaned[::-1]


# 사용 — 조건문이 문장처럼 읽힙니다
score = 85
if is_valid_score(score):
    print("유효한 점수입니다")

print(is_adult(20))              # True
print(is_palindrome(" Level "))  # True
print(is_palindrome("python"))   # False
```

실행 결과:

```
유효한 점수입니다
True
True
False
```

> **`is_` 로 시작하는 함수는 True/False 를 반환한다**는 것이 파이썬 관례입니다.
> `if is_valid_score(score):` 는 영어 문장처럼 읽힙니다. 이름을 잘 지으면 주석이 필요 없어집니다.

### Step 4. 학점 계산 함수화

```python
def get_grade(score):
    """점수를 받아 학점을 반환합니다."""
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    elif score >= 60:
        return "D"
    else:
        return "F"


def get_stats(scores_text):
    """공백으로 구분된 점수 문자열을 받아 (총점, 평균, 최고, 최저)를 반환합니다."""
    total = 0
    count = 0
    highest = 0
    lowest = 100

    for part in scores_text.split():
        score = int(part)
        total += score
        count += 1
        if score > highest:
            highest = score
        if score < lowest:
            lowest = score

    if count == 0:
        return 0, 0, 0, 0

    return total, total / count, highest, lowest


# 사용
text = input("점수를 공백으로 구분해 입력하세요: ")
total, average, high, low = get_stats(text)

print(f"총점:   {total}")
print(f"평균:   {average:.1f} ({get_grade(average)}학점)")
print(f"최고점: {high} ({get_grade(high)}학점)")
print(f"최저점: {low} ({get_grade(low)}학점)")
```

실행 결과:

```
점수를 공백으로 구분해 입력하세요: 85 92 78 90 65
총점:   410
평균:   82.0 (B학점)
최고점: 92 (A학점)
최저점: 65 (D학점)
```

### Step 5. 함수로 만든 ATM (오늘의 종합 예제)

Day 006의 ATM을 함수 구조로 다시 만듭니다.

```python
def print_menu():
    """메뉴를 출력합니다."""
    print()
    print("1. 잔액 조회   2. 입금   3. 출금   4. 종료")


def get_amount(label):
    """금액을 입력받아 검증합니다. 잘못되면 None 을 반환합니다."""
    amount = int(input(f"{label}: "))
    if amount <= 0:
        print("→ 0원보다 큰 금액을 입력해 주세요.")
        return None
    return amount


def deposit(balance, amount):
    """입금 후 새 잔액을 반환합니다."""
    new_balance = balance + amount
    print(f"→ {amount:,}원 입금 완료. 잔액 {new_balance:,}원")
    return new_balance


def withdraw(balance, amount):
    """출금 후 새 잔액을 반환합니다. 잔액이 부족하면 원래 잔액을 그대로 반환합니다."""
    if amount > balance:
        print(f"→ 잔액이 부족합니다. (현재 {balance:,}원)")
        return balance

    new_balance = balance - amount
    print(f"→ {amount:,}원 출금 완료. 잔액 {new_balance:,}원")
    return new_balance


# ── 메인 프로그램 ──
balance = 100_000

print("=" * 40)
print("             MBC 은행 ATM")
print("=" * 40)

while True:
    print_menu()
    menu = input("메뉴 선택: ").strip()

    if menu == "1":
        print(f"→ 현재 잔액은 {balance:,}원 입니다.")

    elif menu == "2":
        amount = get_amount("입금액")
        if amount is not None:
            balance = deposit(balance, amount)

    elif menu == "3":
        amount = get_amount("출금액")
        if amount is not None:
            balance = withdraw(balance, amount)

    elif menu == "4":
        print("→ 이용해 주셔서 감사합니다.")
        break

    else:
        print("→ 1~4 중에서 선택해 주세요.")

print("=" * 40)
```

실행 결과:

```
========================================
             MBC 은행 ATM
========================================

1. 잔액 조회   2. 입금   3. 출금   4. 종료
메뉴 선택: 3
출금액: 150000
→ 잔액이 부족합니다. (현재 100,000원)

1. 잔액 조회   2. 입금   3. 출금   4. 종료
메뉴 선택: 2
입금액: 50000
→ 50,000원 입금 완료. 잔액 150,000원

1. 잔액 조회   2. 입금   3. 출금   4. 종료
메뉴 선택: 4
→ 이용해 주셔서 감사합니다.
========================================
```

> **눈여겨볼 점 3가지**
> - `deposit` / `withdraw` 는 `global balance` 를 쓰지 않고, **잔액을 받아 새 잔액을 반환**합니다.
>   그래서 `balance = deposit(balance, amount)` 처럼 결과를 다시 받아야 합니다. 번거로워 보이지만 이것이 안전한 방식입니다.
> - 메인 프로그램(`while` 블록)이 30줄 이내로 짧아졌습니다. **무슨 일을 하는지 한눈에 보입니다.**
> - `get_amount` 는 검증까지 담당합니다. 검증 로직을 한 곳에 모아 두면 나중에 규칙이 바뀌어도 한 군데만 고치면 됩니다.

## ⑤ 자주 하는 실수

### 함수를 정의만 하고 호출하지 않음

```python
def greet():
    print("안녕하세요")
```

실행 결과: **아무것도 출력되지 않음**

**원인** — `def` 는 "만들어 두기"일 뿐입니다.
**해결** — 아래에 `greet()` 을 추가합니다.

### 호출할 때 괄호를 빠뜨림

```python
def greet():
    print("안녕하세요")

greet          # 괄호 없음
```

실행 결과: **아무것도 출력되지 않음** (에러도 안 남)

**원인** — `greet` 는 "함수 자체"를 가리킬 뿐, 실행하지 않습니다.
**해결** — `greet()` 처럼 괄호를 붙입니다.

> `print(greet)` 를 해 보면 `<function greet at 0x...>` 이 나옵니다. 함수도 값이라는 뜻입니다.

### `TypeError: greet() missing 1 required positional argument`

```python
def greet(name):
    print(f"{name}님")

greet()
```

```
TypeError: greet() missing 1 required positional argument: 'name'
```

**원인** — 함수가 받기로 한 값을 안 넘겼습니다.
**해결** — `greet("홍길동")`. 또는 매개변수에 기본값을 주면 됩니다. ([Day 009](day-009.md))

### `return` 을 빠뜨려 결과가 `None` 이 됨

```python
def add(a, b):
    a + b            # 계산만 하고 돌려주지 않음

result = add(3, 5)
print(result)        # None
```

**원인** — `return` 이 없으면 함수는 `None` 을 반환합니다.
**해결** — `return a + b`

> **`print` 와 `return` 을 혼동하지 마세요.**
> `print` 는 화면에 보여 주는 것, `return` 은 값을 돌려주는 것입니다. 둘은 완전히 다릅니다.

### `UnboundLocalError` — 전역변수를 함수 안에서 수정

```python
total = 0

def add_score(score):
    total += score      # UnboundLocalError

add_score(10)
```

**원인** — 함수 안에서 대입하면 지역변수로 취급되는데, 초기값이 없습니다.
**해결** — 인자로 받아 결과를 반환하는 형태로 바꿉니다.

```python
def add_score(total, score):
    return total + score

total = 0
total = add_score(total, 10)
```

### 함수 안의 변수를 밖에서 쓰려고 함

```python
def calculate():
    result = 100

calculate()
print(result)        # NameError
```

**원인** — `result` 는 함수 안에서만 존재하는 지역변수입니다.
**해결** — `return result` 로 돌려주고, 밖에서 받습니다.

```python
def calculate():
    result = 100
    return result

result = calculate()
print(result)        # 100
```

### 함수를 정의하기 전에 호출

```python
greet("홍길동")

def greet(name):
    print(f"{name}님")
```

```
NameError: name 'greet' is not defined
```

**원인** — 파이썬은 위에서 아래로 읽습니다. 호출 시점에 아직 함수가 없습니다.
**해결** — 함수 정의를 파일 위쪽에 모아 두고, 실행 코드를 아래에 씁니다.

## ⑥ 확인 문제

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
def mystery(a, b):
    if a > b:
        return a
    return b
    print("여기 실행됨")

print(mystery(3, 7))
```

<details>
<summary>답 보기</summary>

```
7
```

- `3 > 7` 이 거짓이므로 `return b` 가 실행되어 `7` 을 반환합니다.
- `print("여기 실행됨")` 은 **절대 실행되지 않습니다.** `return` 을 만나는 순간 함수가 끝나기 때문입니다.

> `return` 아래에 코드를 쓰면 죽은 코드(dead code)가 됩니다. VS Code에서 흐리게 표시되니 참고하세요.
</details>

**2.** 원의 반지름을 받아 **넓이와 둘레를 함께 반환**하는 함수를 만들고 사용하세요. (원주율 3.14159)

<details>
<summary>답 보기</summary>

```python
PI = 3.14159


def circle_info(radius):
    """반지름을 받아 (넓이, 둘레)를 반환합니다."""
    if radius <= 0:
        return None, None

    area = PI * radius ** 2
    circumference = 2 * PI * radius
    return area, circumference


r = float(input("반지름: "))
area, circ = circle_info(r)

if area is None:
    print("반지름은 0보다 커야 합니다.")
else:
    print(f"넓이: {area:.2f}")
    print(f"둘레: {circ:.2f}")
```

실행 결과:

```
반지름: 5
넓이: 78.54
둘레: 31.42
```

**포인트 3가지**
- `return area, circumference` 로 두 값을 함께 돌려주고, `area, circ = ...` 로 나눠 받습니다.
- 잘못된 입력일 때도 **반환 형태를 맞춰야** 합니다. (`return None, None`) 형태가 다르면 받는 쪽에서 에러가 납니다.
- `PI` 를 상수로 빼 두면 정밀도를 바꿀 때 한 곳만 고치면 됩니다. (실제로는 `import math` 후 `math.pi` 를 씁니다)
</details>

**3.** 아래 코드는 의도대로 동작하지 않습니다. 문제를 찾고 고치세요.

```python
scores = ""

def add_score(score):
    scores += f"{score} "

add_score(90)
add_score(85)
print(scores)
```

<details>
<summary>답 보기</summary>

```
UnboundLocalError: cannot access local variable 'scores'
where it is not associated with a value
```

**원인** — 함수 안에서 `scores += ...` 를 쓰는 순간 파이썬은 `scores` 를 **지역변수**로 판단합니다.
그런데 `+=` 는 기존 값을 읽어야 하는데, 지역변수 `scores` 에는 아직 값이 없어 에러가 납니다.

**해결 (권장) — 받아서 반환하기**

```python
def add_score(scores, score):
    """기존 문자열에 점수를 덧붙여 반환합니다."""
    return scores + f"{score} "


scores = ""
scores = add_score(scores, 90)
scores = add_score(scores, 85)
print(scores)         # 90 85
```

**해결 (비권장) — global 사용**

```python
scores = ""

def add_score(score):
    global scores
    scores += f"{score} "
```

> `global` 은 동작하긴 하지만, 함수가 바깥 상태를 몰래 바꾸므로 프로그램이 커지면 추적이 어려워집니다.
> **"받은 것만 보고, 결과만 돌려준다"** 는 원칙을 지키세요. 이 습관이 W05에서 게임 코드를 만들 때 큰 차이를 만듭니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 정의 | `def 이름(매개변수):` — 만들어 두기만 함 |
| 호출 | `이름(인자)` — **괄호가 있어야 실행됨** |
| `return` | 값을 돌려주고 **함수를 즉시 종료** |
| `return` 없음 | `None` 이 반환됨 |
| 여러 값 반환 | `return a, b` → `x, y = func()` |
| 지역변수 | 함수 안에서만 존재. 밖에서 못 씀 |
| 전역변수 수정 | `global` 대신 **인자로 받고 결과를 반환** |
| 좋은 함수 | 하나의 일만 · 동사로 시작하는 이름 · 20줄 이내 |

**오늘 반드시 기억할 한 가지**
> `print` 는 **보여 주기**, `return` 은 **돌려주기**. 계산 결과를 다시 쓰려면 반드시 `return` 이 필요합니다.
