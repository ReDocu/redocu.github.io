### 3-1. 게임 상태 머신

**왜 필요한가** — Day 46·75·82에서 반복해 나온 구조.

```
   ┌────────┐  입력   ┌─────────┐  종료조건  ┌────────┐
   │ Ready  │────────▶│ Playing │──────────▶│ Result │
   └────────┘         └─────────┘           └────────┘
        ▲                  │  ▲                  │
        │                  │  │ 재개              │ 재시작
        │                  ▼  │                  │
        │             ┌─────────┐                │
        │             │ Paused  │                │
        │             └─────────┘                │
        └───────────────────────────────────────┘
```

```csharp
namespace OneFloor.Core
{
    public enum GameState { Ready, Playing, Paused, Result }

    public class GameManager : MonoBehaviour
    {
        public static GameManager Instance { get; private set; }

        public GameState State { get; private set; } = GameState.Ready;

        public event System.Action<GameState> OnStateChanged;

        public void SetState(GameState next)
        {
            if (State == next) return;

            GameState prev = State;
            State = next;

            // ★ 상태별 부수 효과를 한곳에서
            Time.timeScale = (next == GameState.Paused || next == GameState.Result)
                             ? 0f : 1f;

            DebugUtil.Log($"[상태] {prev} → {next}");

            OnStateChanged?.Invoke(next);
        }
    }
}
```

```
   ★ 한곳에서 관리하는 이유

   "일시정지인데 적이 움직인다"
   "결과 화면인데 공격이 된다"
   → 상태가 흩어져 있으면 반드시 생긴다
```

```csharp
    // 각 컴포넌트는 상태를 확인한다
    private void Update()
    {
        if (!GameManager.Instance.IsPlaying) return;
        // ...
    }
```

```
   ★ 또는 이벤트로 켜고 끈다

   private void HandleStateChanged(GameState s)
   {
       enabled = (s == GameState.Playing);
   }
```

    [SerializeField] private int totalFloors = 3;

    public int CurrentFloor { get; private set; } = 1;

    public void OnFloorCleared()
    {
        CurrentFloor++;

        if (CurrentFloor > totalFloors) { EndGame(true); return; }

        StartCoroutine(NextFloorRoutine());
    }

    private IEnumerator NextFloorRoutine()
    {
        // 짧은 연출 시간
        yield return new WaitForSeconds(0.6f);

        SpawnFloor(CurrentFloor);
    }
```

```

## 4. 진행 순서

### Step 1 — GameManager 상태 머신

3-1절의 코드를 만든다.

```csharp
namespace OneFloor.Core
{
    public enum GameState { Ready, Playing, Paused, Result }

    public class GameManager : MonoBehaviour
    {
        public static GameManager Instance { get; private set; }

        [Header("진행")]
        [SerializeField] private int totalFloors = 3;
        [SerializeField] private int baseEnemyCount = 2;
        [SerializeField] private GameObject enemyPrefab;
        [SerializeField] private Transform[] spawnPoints;
        [SerializeField] private Transform playerSpawn;

        [Header("참조")]
        [SerializeField] private Health playerHealth;

        public GameState State { get; private set; } = GameState.Ready;
        public int CurrentFloor { get; private set; } = 1;
        public int TotalFloors => totalFloors;
        public int AliveEnemies { get; private set; }
        public int TotalKills { get; private set; }
        public float PlayTime => State == GameState.Playing
                                 ? Time.time - startTime : lastPlayTime;

        public bool IsPlaying => State == GameState.Playing;

        public event System.Action<GameState> OnStateChanged;

        private float startTime;
        private float lastPlayTime;
        private bool isWin;

        private void Awake()
        {
            if (Instance != null && Instance != this) { Destroy(gameObject); return; }
            Instance = this;

            Time.timeScale = 1f;               // ★ 씬 재로드 대비
        }

        public void Initialize()
        {
            SetState(GameState.Ready);
        }
    }
}
```

**✅ 여기까지 하면** — 상태 기반 구조.

### Step 2 — 상태 전환

### Step 5 — 적 스폰

```csharp
    private readonly List<SimpleEnemy> activeEnemies = new List<SimpleEnemy>();

    private void SpawnFloor(int floor)
    {
        ClearAllEnemies();

        int count = baseEnemyCount + floor;

        for (int i = 0; i < count; i++)
        {
            Vector3 pos = GetSpawnPosition(i, count);

            GameObject go = Instantiate(enemyPrefab, pos, Quaternion.identity);
            SimpleEnemy e = go.GetComponent<SimpleEnemy>();

            activeEnemies.Add(e);
        }

        AliveEnemies = count;

        DebugUtil.Log($"[층 {floor}] 적 {count}기 스폰");
    }

    private Vector3 GetSpawnPosition(int index, int total)
    {
        // ★ 원형 배치 (Day 84)
        float angle = (index / (float)total) * Mathf.PI * 2f;
        float radius = 8f;

        return new Vector3(Mathf.Cos(angle) * radius, 1f, Mathf.Sin(angle) * radius);
    }

    private void ClearAllEnemies()
    {
        for (int i = activeEnemies.Count - 1; i >= 0; i--)
        {
            if (activeEnemies[i] != null) Destroy(activeEnemies[i].gameObject);
        }
        activeEnemies.Clear();
    }
```

**✅ 여기까지 실행하면** — 적이 원형으로 나타난다.

            if (Input.GetKeyDown(KeyCode.Escape)) SetState(GameState.Paused);

            break;
