## 단원 개요

### 이 단원을 마치면

- 이미지 속 **여러 물체의 위치와 종류**를 찾아내는 모델을 학습시킬 수 있다.
- 데이터를 직접 라벨링해 **자신만의 검출 데이터셋**을 구축할 수 있다.
- 학습한 모델을 **Flask 웹사이트에 올려 누구나 쓸 수 있게** 만들 수 있다.
- **라즈베리파이 + 카메라**로 실시간 CCTV 시스템을 구성할 수 있다.

### 이 단원의 성격 — 과정의 종착점

앞선 4개 대단원이 "모델을 만드는 법"이었다면, 이 단원은 **"만든 모델을 실제로 쓰이게 하는 법"** 입니다.
지금까지의 결과물은 전부 노트북 안에 있었습니다. 여기서 처음으로 **노트북 밖으로 나옵니다.**

```
데이터 라벨링(W28–W29) → 모델 학습(W30–W31) → 웹 서비스(W32–W33) → 엣지 디바이스(W34) → 통합(W35–W36)
```

9주 중 **4주가 프로젝트/통합 성격**입니다. 취업 포트폴리오의 핵심이 되는 단원이므로 시간을 넉넉히 배정했습니다.

| 학습은 됐는데 아무것도 검출되지 않습니다 | `conf` 임계값을 0.1까지 낮춰 보세요. 그래도 없으면 라벨 좌표 형식이 잘못됐을 가능성이 큽니다. 라벨을 이미지에 그려서 눈으로 확인하세요. |

| Flask에서 웹캠 스트리밍이 멈춥니다 | 개발 서버는 단일 스레드입니다. `threaded=True`로 실행하거나 WSGI 서버(waitress/gunicorn)를 사용하세요. |
