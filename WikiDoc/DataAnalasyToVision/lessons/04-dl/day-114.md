## ② 왜 필요한가

### "성능이 0.5% 좋아졌습니다"가 의미 있습니까

[Day 113](day-113.md)에서 이런 결과를 봤습니다.

```
C. 타입별 최적   HistGB  MAE 4,918
D. 타깃 인코딩   HistGB  MAE 4,874
```

**차이 44원 (0.9%). D가 더 좋다고 말할 수 있습니까?**

**말할 수 없습니다.** 왜냐하면 이 실험을 **seed를 바꿔서** 다시 하면 이런 결과가 나오기 때문입니다.

```
seed=42  →  C: 4,918   D: 4,874    D 승
seed=1   →  C: 5,102   D: 5,241    C 승
seed=7   →  C: 4,781   D: 4,802    C 승
seed=99  →  C: 5,014   D: 4,893    D 승
seed=13  →  C: 4,892   D: 5,108    C 승
```

**분할 방식 하나로 성능이 ±3% 흔들립니다.** 그 안에서 0.9% 차이는 노이즈입니다.

> **오늘의 핵심** — **"성능 차이가 분할 변동폭보다 큰가"** 를 확인하는 습관.
> 이것 없이는 [Day 120](day-120.md)의 "근거 있는 모델 선택"이 불가능합니다.

### 검증셋이 작으면 벌어지는 일

```
검증셋 100건 → 1건 차이가 1%p
검증셋 88건  → [Day 110](day-110.md) 확인문제 3에서 순위가 뒤집혔음
```

[Day 110](day-110.md)에서 442행 데이터를 다뤘습니다.

```
검증셋(88건) 순위:  HistGB > RF
교차검증(354건) 순위: RF > HistGB      ← 뒤바뀜
```

**88건으로는 모델을 고를 수 없습니다.**

### 분할이 먼저 — 이번에는 숫자로

[Day 109](day-109.md)에서 "분할이 전처리보다 먼저"를 배웠습니다.
그런데 **스케일링만 놓고 보면 차이가 거의 없었습니다.**

```
A. 올바름 (분할→스케일)  MAE 0.5332
B. 누수  (스케일→분할)  MAE 0.5332       ← 차이 0.0000
```

**"그럼 신경 안 써도 되겠네"** 라고 생각한 사람이 있을 것입니다.

**오늘 전처리 종류별로 측정합니다.** 스케일링은 안전하지만, 다른 것들은 그렇지 않습니다.

```
스케일링       차이  0.0%
결측치 대체     차이  ?
이상치 절단     차이  ?
타깃 인코딩     차이  ?
특성 선택      차이  ?
```

## ③ 개념 설명

### 분할 비율 — 비율이 아니라 절대 크기

**흔히 쓰는 비율**

| 비율 | 학습 : 검증 : 테스트 |
|---|---|
| 6 : 2 : 2 | 표준. 데이터 1천~1만 |
| 7 : 1.5 : 1.5 | 데이터 1만~10만 |
| 8 : 1 : 1 | 데이터 10만 이상 |
| 98 : 1 : 1 | 데이터 100만 이상 |

**그런데 진짜 기준은 이것입니다.**

```
검증셋 크기 = max(전체의 10~20%, 최소 필요 건수)
```

**최소 필요 건수는 어떻게 정하는가**

```
검증 MAE의 표준오차 ≈ 오차의 표준편차 / √n

예: 오차 표준편차 5,000원, 검증셋 n건일 때
    n=100  → 표준오차 500원
    n=500  → 표준오차 224원
    n=1000 → 표준오차 158원
    n=4000 → 표준오차  79원
```

**두 모델의 MAE 차이가 표준오차의 2배보다 작으면 구분할 수 없습니다.**

| 구분하고 싶은 차이 | 필요한 검증셋 크기 (오차 std 5,000 기준) |
|---|---|
| 1,000원 | 약 100건 |
| 500원 | 약 400건 |
| 200원 | 약 2,500건 |
| **100원** | **약 10,000건** |

> **"MAE를 100원 단위로 비교하려면 검증셋이 1만 건 필요합니다."**
> 데이터가 5,000행이면 그런 비교는 애초에 불가능합니다.

### 계층 분할 — 회귀에서 하는 법

```python
y_bins = pd.qcut(y, q=10, labels=False, duplicates="drop")
train_test_split(X, y, stratify=y_bins, random_state=SEED)
```

**구간 개수(q) 정하기**

| 데이터 크기 | 권장 q |
|---|---|
| ~1,000 | 5 |
| 1,000~10,000 | **10** |
| 10,000+ | 10~20 |

**너무 크면 안 됩니다.**

```
q=50, 데이터 500행 → 구간당 10건 → 테스트셋에 2건씩
→ stratify가 실패하거나 의미가 없어짐
```

**언제 효과가 큰가**

| 상황 | 효과 |
|---|---|
| 데이터가 작음 (~2,000) | **큼** |
| 타깃이 심하게 치우침 | **큼** |
| 극단값이 소수 | **큼** |
| 데이터가 큼 (1만+), 분포 완만 | 작음 (무작위로도 충분) |

### 홀드아웃 vs 교차검증

| | 홀드아웃 | 교차검증 (K-Fold) |
|---|---|---|
| 학습 횟수 | 1회 | **K회** |
| 검증 데이터 | 20% | **100%** (돌아가며) |
| 성능 추정 | 불안정 | **안정 (평균±표준편차)** |
| 시간 | 빠름 | **K배 느림** |
| 딥러닝 | 실용적 | 부담 큼 |

**언제 무엇을 쓰나**

```
데이터 < 2,000행        →  교차검증 필수
2,000 ~ 20,000행       →  둘 다 가능. 최종 비교는 교차검증
20,000행 이상          →  홀드아웃으로 충분
딥러닝 + 학습 시간 긴 경우 →  홀드아웃 (교차검증은 비현실적)
```

**교차검증 안에서도 테스트셋은 따로 뗍니다.**

```
전체 데이터
├── 개발 데이터 80%  →  K-Fold 교차검증으로 모델 선택
└── 테스트 20%       →  최종 1회 평가
```

### Nested CV — 튜닝과 평가를 모두 교차검증으로

```
바깥 루프 (5-fold): 성능 추정
  └── 안쪽 루프 (5-fold): 하이퍼파라미터 탐색
```

**25번 학습해야 합니다.** 정확하지만 매우 비쌉니다.

> **이 과정에서는 Nested CV를 쓰지 않습니다.**
> 개념만 알아 두고, **"개발 데이터로 CV → 테스트셋 1회"** 를 표준으로 씁니다.

### 시계열 분할

```
[무작위]  ✗           [시간 순]  ✓
1 2 3 4 5 6          1 2 3 4 5 6
학 검 학 학 검 학       학 학 학 학 검 테
```

```python
from sklearn.model_selection import TimeSeriesSplit

tscv = TimeSeriesSplit(n_splits=5, test_size=None, gap=0)
```

| 파라미터 | 의미 |
|---|---|
| `n_splits` | 폴드 수 |
| `test_size` | 각 검증 구간 크기 |
| **`gap`** | **학습과 검증 사이 간격** (누수 방지) |

**`gap` 이 필요한 경우**

```
[예측 대상] 3일 후 가격
[학습 마지막 날] 1월 10일
[검증 첫날]     1월 11일    ← 1월 11일 예측에 1월 8일 데이터가 필요
                            → 학습에 이미 썼음 = 미묘한 누수
gap=3 으로 두면 1월 14일부터 검증
```

### 그룹 분할

```python
from sklearn.model_selection import GroupKFold, GroupShuffleSplit, StratifiedGroupKFold
```

| 클래스 | 용도 |
|---|---|
| `GroupShuffleSplit` | 홀드아웃 + 그룹 |
| `GroupKFold` | 교차검증 + 그룹 |
| `StratifiedGroupKFold` | 교차검증 + 그룹 + 계층 |

> **[Day 109](day-109.md)에서 배운 그룹 누수의 해결책입니다.**
> 스팀 데이터에서 "같은 시리즈"나 "같은 개발사"가 그룹이 될 수 있습니다.

### ★ 전처리 종류별 누수 위험도

| 전처리 | 학습셋 통계 사용 | 누수 위험 | 성능 부풀림 |
|---|---|---|---|
| `StandardScaler` | 평균·표준편차 | 낮음 | ~0% |
| `MinMaxScaler` | **최대·최소** | **중간** | 소~중 |
| `SimpleImputer(mean)` | 평균 | 낮음 | ~0% |
| `SimpleImputer(most_frequent)` | 최빈값 | 낮음 | ~0% |
| **이상치 절단** | 분위수 | 중간 | 소 |
| `PowerTransformer` | λ 추정 | 중간 | 소 |
| **`TargetEncoder`** | **타깃 값** | **높음** | **큼** |
| **`SelectKBest`** | **타깃 상관** | **매우 높음** | **매우 큼** |
| **PCA** | 전체 분산 구조 | 중간~높음 | 중 |
| **SMOTE / 증강** | 샘플 자체 | **매우 높음** | **매우 큼** |

> **"스케일링만 봤을 때 차이가 없었다"고 안심하면 안 되는 이유가 이 표입니다.**
> **`MinMaxScaler` 는 이상치 하나에 크게 좌우됩니다.** 테스트셋의 최댓값이 새면 위험합니다.

## ④ 단계별 실습

### Step 1. 검증셋 크기와 성능 추정의 정밀도

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_california_housing
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import train_test_split

SEED = 42
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

# ── 고정된 큰 학습셋 + 테스트셋 ──
X_pool, X_test, y_pool, y_test = train_test_split(
    X_all, y_all, test_size=0.3, random_state=SEED)

model = HistGradientBoostingRegressor(max_iter=200, random_state=SEED)
model.fit(X_pool, y_pool)

# ── 검증셋 크기별로 MAE 추정의 흔들림 측정 ──
rng = np.random.default_rng(SEED)
sizes = [50, 100, 250, 500, 1000, 2000, 4000, 6192]
n_repeat = 200

print("=" * 84)
print("검증셋 크기와 성능 추정의 정밀도")
print("=" * 84)
print(f"{'검증셋 크기':>12}{'MAE 평균':>12}{'MAE 표준편차':>14}"
      f"{'95% 구간 폭':>14}{'구분 가능한 차이':>18}")
print("-" * 84)

results = []
full_pred = model.predict(X_test)
full_err = np.abs(y_test.values - full_pred)

for n in sizes:
    maes = []
    for _ in range(n_repeat):
        idx = rng.choice(len(X_test), size=min(n, len(X_test)), replace=False)
        maes.append(full_err[idx].mean())
    maes = np.array(maes)
    ci_width = 2 * 1.96 * maes.std()
    results.append({"n": n, "mean": maes.mean(), "std": maes.std(),
                    "ci": ci_width, "detect": 2 * maes.std()})
    print(f"{n:>12,}{maes.mean():>12.4f}{maes.std():>14.4f}"
          f"{ci_width:>14.4f}{2*maes.std():>18.4f}")

print("=" * 84)
print("★ '구분 가능한 차이' = 2×표준편차. 이보다 작은 차이는 노이즈입니다.")
print(f"  검증셋 100건  → {results[1]['detect']:.4f} 이상 차이나야 구분 가능")
print(f"  검증셋 4000건 → {results[6]['detect']:.4f} 이상 차이나야 구분 가능")
print(f"  → 정밀도가 {results[1]['detect']/results[6]['detect']:.1f}배 좋아집니다")

# ── √n 법칙 확인 ──
res_df = pd.DataFrame(results)
res_df["이론값"] = full_err.std() / np.sqrt(res_df["n"])
print("\n[표준오차 ≈ 오차표준편차 / √n 확인]")
print(f"  오차의 표준편차: {full_err.std():.4f}")
print(res_df[["n", "std", "이론값"]].round(4).to_string(index=False))

# ── 그래프 ──
fig, axes = plt.subplots(1, 2, figsize=(15, 5))

ax = axes[0]
ax.errorbar(res_df["n"], res_df["mean"], yerr=1.96 * res_df["std"],
            fmt="o-", capsize=5, linewidth=2, markersize=7)
ax.set_xscale("log")
ax.set_xlabel("validation set size (log)")
ax.set_ylabel("estimated MAE")
ax.set_title("MAE estimate ± 95% CI")

ax = axes[1]
ax.plot(res_df["n"], res_df["std"], "o-", linewidth=2, label="measured std")
ax.plot(res_df["n"], res_df["이론값"], "s--", linewidth=2, label="theory: σ/√n")
ax.set_xscale("log"); ax.set_yscale("log")
ax.set_xlabel("validation set size (log)")
ax.set_ylabel("std of MAE estimate (log)")
ax.set_title("Precision improves as √n")
ax.legend()

fig.tight_layout()
plt.show()
```

> **검증셋 크기를 정할 때 이렇게 계산하세요.**
> ```
> ① 구분하고 싶은 성능 차이를 정한다 (예: MAE 5% 차이)
> ② 오차의 표준편차를 추정한다 (예비 실험)
> ③ n = (2σ / 목표차이)² 로 필요 크기를 계산
> ```

### Step 4. 홀드아웃 vs 교차검증

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.ensemble import HistGradientBoostingRegressor, RandomForestRegressor
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import KFold, cross_val_score, train_test_split

SEEDS_20 = list(range(20))

print("=" * 92)
print("홀드아웃 vs 5-Fold 교차검증 — 500행 데이터에서")
print("=" * 92)

n = 500
sub_idx = np.random.default_rng(0).choice(len(X_all), size=n, replace=False)
Xs, ys = X_all.iloc[sub_idx], y_all.iloc[sub_idx]

hold_rf, hold_hgb, cv_rf, cv_hgb = [], [], [], []

for s in SEEDS_20:
    X_dev, _, y_dev, _ = train_test_split(Xs, ys, test_size=0.2, random_state=s)

    # 홀드아웃
    X_tr, X_va, y_tr, y_va = train_test_split(X_dev, y_dev, test_size=0.25, random_state=s)

    hold_hgb.append(mean_absolute_error(y_va, hgb.predict(X_va)))

        RandomForestRegressor(n_estimators=200, random_state=s, n_jobs=-1),
        X_dev, y_dev, cv=cv, scoring="neg_mean_absolute_error").mean())

        HistGradientBoostingRegressor(max_iter=200, random_state=s),
```

### Step 6. ★ 전처리 종류별 누수 영향 측정

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.feature_selection import SelectKBest, f_regression
from sklearn.impute import SimpleImputer
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_absolute_error, r2_score
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler, PowerTransformer, StandardScaler

SEED = 42
rng = np.random.default_rng(SEED)

# ── 특성이 많은 상황을 재현 (특성 선택 누수를 보기 위해) ──
n_noise = 200
X_wide = pd.concat([
    X_all.reset_index(drop=True),
    pd.DataFrame(rng.standard_normal((len(X_all), n_noise)),
                 columns=[f"noise_{i}" for i in range(n_noise)]),
], axis=1)

# ── 결측치도 인위적으로 주입 ──
X_missing = X_wide.copy()
miss_idx = rng.choice(len(X_missing), size=int(len(X_missing) * 0.1), replace=False)
X_missing.loc[miss_idx, "MedInc"] = np.nan


def run(preprocess_name, leak_first, n_repeat=5):
    """leak_first=True 면 전처리 → 분할 (누수), False 면 분할 → 전처리"""
    scores = []
    for s in range(n_repeat):
        if preprocess_name == "특성선택":
            Xd, yd = X_wide, y_all
        elif preprocess_name == "결측대체":
            Xd, yd = X_missing, y_all
        else:
            Xd, yd = X_all, y_all

        if leak_first:
            # ✗ 전체로 전처리한 뒤 분할
            if preprocess_name == "StandardScaler":
                Xp = pd.DataFrame(StandardScaler().fit_transform(Xd), columns=Xd.columns)
            elif preprocess_name == "MinMaxScaler":
                Xp = pd.DataFrame(MinMaxScaler().fit_transform(Xd), columns=Xd.columns)
            elif preprocess_name == "결측대체":
                Xp = pd.DataFrame(SimpleImputer(strategy="mean").fit_transform(Xd),
                                  columns=Xd.columns)
            elif preprocess_name == "이상치절단":
                Xp = Xd.clip(Xd.quantile(0.01), Xd.quantile(0.99), axis=1)
            elif preprocess_name == "PowerTransform":
                Xp = pd.DataFrame(PowerTransformer().fit_transform(Xd), columns=Xd.columns)
            elif preprocess_name == "특성선택":
                sel = SelectKBest(f_regression, k=15).fit(Xd, yd)
                Xp = pd.DataFrame(sel.transform(Xd))
            elif preprocess_name == "PCA":
                Xp = pd.DataFrame(PCA(n_components=6, random_state=SEED).fit_transform(
                    StandardScaler().fit_transform(Xd)))
            X_tr, X_va, y_tr, y_va = train_test_split(Xp, yd, test_size=0.25, random_state=s)
        else:
            # ✓ 분할 후 학습셋으로만 fit
            X_tr0, X_va0, y_tr, y_va = train_test_split(Xd, yd, test_size=0.25, random_state=s)
            if preprocess_name == "StandardScaler":
                sc = StandardScaler().fit(X_tr0)
                X_tr, X_va = sc.transform(X_tr0), sc.transform(X_va0)
            elif preprocess_name == "MinMaxScaler":
                sc = MinMaxScaler().fit(X_tr0)
                X_tr, X_va = sc.transform(X_tr0), sc.transform(X_va0)
            elif preprocess_name == "결측대체":
                im = SimpleImputer(strategy="mean").fit(X_tr0)
                X_tr, X_va = im.transform(X_tr0), im.transform(X_va0)
            elif preprocess_name == "이상치절단":
                lo, hi = X_tr0.quantile(0.01), X_tr0.quantile(0.99)
                X_tr, X_va = X_tr0.clip(lo, hi, axis=1), X_va0.clip(lo, hi, axis=1)
            elif preprocess_name == "PowerTransform":
                pt = PowerTransformer().fit(X_tr0)
                X_tr, X_va = pt.transform(X_tr0), pt.transform(X_va0)
            elif preprocess_name == "특성선택":
                sel = SelectKBest(f_regression, k=15).fit(X_tr0, y_tr)
                X_tr, X_va = sel.transform(X_tr0), sel.transform(X_va0)
            elif preprocess_name == "PCA":
                sc = StandardScaler().fit(X_tr0)
                p = PCA(n_components=6, random_state=SEED).fit(sc.transform(X_tr0))
                X_tr, X_va = p.transform(sc.transform(X_tr0)), p.transform(sc.transform(X_va0))

        m = RidgeCV(alphas=np.logspace(-3, 3, 20)).fit(X_tr, y_tr)
        scores.append(mean_absolute_error(y_va, m.predict(X_va)))
    return np.mean(scores)


preprocesses = ["StandardScaler", "MinMaxScaler", "결측대체", "이상치절단",
                "PowerTransform", "PCA", "특성선택"]

rows = []
for p in preprocesses:
    leak = run(p, leak_first=True)
    ok = run(p, leak_first=False)
    rows.append({
        "전처리": p,
        "누수(전처리→분할)": round(leak, 4),
        "올바름(분할→전처리)": round(ok, 4),
        "차이": round(ok - leak, 4),
        "부풀림(%)": round((ok - leak) / ok * 100, 2),
    })

res = pd.DataFrame(rows).sort_values("부풀림(%)", ascending=False)

print("=" * 92)
print("전처리 종류별 누수 영향 — 분할 순서를 어겼을 때 성능이 얼마나 부풀려지나")
print("=" * 92)
print(res.to_string(index=False))
print("=" * 92)
print("★ 스케일링·결측대체는 영향이 거의 없습니다. (Day 109 결과 재확인)")
print("★ 특성 선택은 압도적으로 위험합니다.")
print("★ '차이가 작으니 안전하다'가 아니라 '이 전처리에서는 작다'입니다.")

# ── 그래프 ──
fig, ax = plt.subplots(figsize=(11, 5.5))
colors = ["#d62728" if v > 3 else "#ff7f0e" if v > 0.5 else "#2ca02c"
          for v in res["부풀림(%)"]]
ax.barh(res["전처리"], res["부풀림(%)"], color=colors)
ax.invert_yaxis()
ax.axvline(0, color="black", linewidth=1)
ax.set_xlabel("performance inflation (%)")
ax.set_title("Leakage impact by preprocessing type")
for i, v in enumerate(res["부풀림(%)"]):
    ax.text(v + 0.2, i, f"{v:+.2f}%", va="center", fontsize=9)
fig.tight_layout()
plt.show()
```

```python
def recommend_split(n_rows, has_group=False, has_time=False,
                    target_skew=0.0, error_std=None, target_mean=None,
                    detect_pct=5.0):
    """데이터 특성을 받아 분할 전략을 추천"""
    rec = {}

    # ① 홀드아웃 vs 교차검증
    if n_rows < 2000:
        rec["검증 방식"] = "교차검증 (5-fold) 필수"
        rec["근거_검증"] = f"{n_rows}행 — 홀드아웃 변동률 15% 이상 예상"
    elif n_rows < 20000:
        rec["검증 방식"] = "홀드아웃 + 최종 비교는 교차검증"
        rec["근거_검증"] = f"{n_rows}행 — 둘 다 가능"
    else:
        rec["검증 방식"] = "홀드아웃으로 충분"
        rec["근거_검증"] = f"{n_rows}행 — 검증셋 {int(n_rows*0.2):,}건 확보"

    # ② 비율
    if n_rows < 1000:
        rec["비율"] = "개발 80 : 테스트 20 (개발셋 안에서 CV)"
    elif n_rows < 100000:
        rec["비율"] = "6 : 2 : 2"
    else:
        rec["비율"] = "8 : 1 : 1"

    # ③ 계층 분할
    q = 5 if n_rows < 1000 else 10 if n_rows < 50000 else 20
    rec["계층 분할"] = f"O (q={q})"
    rec["근거_계층"] = (f"타깃 왜도 {target_skew:.2f} — 효과 큼" if abs(target_skew) > 0.5
                    else "왜도는 작지만 비용이 없으므로 적용")

    # ④ 그룹/시간
    if has_group:
        rec["그룹"] = "GroupShuffleSplit / StratifiedGroupKFold 필수"
    else:
        rec["그룹"] = "불필요"
    if has_time:
        rec["시간"] = "TimeSeriesSplit 또는 시간 순 홀드아웃"
    else:
        rec["시간"] = "불필요"

    # ⑤ 검증셋 최소 크기
    if error_std is not None and target_mean is not None:
        target_diff = target_mean * detect_pct / 100
        n_needed = int((2 * error_std / target_diff) ** 2)
        rec["검증셋 최소 크기"] = f"{n_needed:,}건 ({detect_pct}% 차이 구분용)"
        actual = int(n_rows * 0.2)
        rec["충족 여부"] = "✓ 충족" if actual >= n_needed else f"✗ 부족 (현재 {actual:,})"

    rec["seed"] = "42 고정 + 최종 비교는 seed 5개 이상 반복"
    rec["순서"] = "★ 분할 → 전처리 (Pipeline 사용)"
    return rec
```

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.feature_selection import SelectKBest, f_regression
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import TimeSeriesSplit, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

SEED = 42
TARGET = "매출"

df = pd.read_csv("sales.csv").sort_values("date").reset_index(drop=True)

X_all = df.drop(columns=[TARGET, "date"])
y_all = df[TARGET]
dates = df["date"]

# ═══════════════════════════════════════════════════════════
# ★ 수정 1: 시계열이므로 시간 순 분할
# ★ 수정 5: 3분할
# ═══════════════════════════════════════════════════════════
n = len(df)
i_train, i_val = int(n * 0.6), int(n * 0.8)

X_train, y_train = X_all.iloc[:i_train], y_all.iloc[:i_train]
X_val, y_val = X_all.iloc[i_train:i_val], y_all.iloc[i_train:i_val]
X_test, y_test = X_all.iloc[i_val:], y_all.iloc[i_val:]

print("=" * 72)
print("시간 순 분할")
print("=" * 72)
for tag, idx in [("학습", slice(0, i_train)), ("검증", slice(i_train, i_val)),
                 ("테스트", slice(i_val, n))]:
    print(f"  {tag:<8}{dates.iloc[idx].min()} ~ {dates.iloc[idx].max()}  "
          f"({len(dates.iloc[idx]):,}건)")
print("=" * 72)

# ═══════════════════════════════════════════════════════════
# ★ 수정 2·3: 전처리를 Pipeline 안으로 (학습셋으로만 fit)
# ═══════════════════════════════════════════════════════════
def make_pipe(n_estimators):
    return Pipeline([
        ("scale", StandardScaler()),
        ("select", SelectKBest(f_regression, k=20)),
        ("model", RandomForestRegressor(n_estimators=n_estimators,
                                        random_state=SEED, n_jobs=-1)),
    ])

# ═══════════════════════════════════════════════════════════
# ★ 수정 4: 같은 분할에서 두 모델을 비교
# ★ 수정 6: TimeSeriesSplit으로 여러 구간에서 반복
# ═══════════════════════════════════════════════════════════
X_dev, y_dev = X_all.iloc[:i_val], y_all.iloc[:i_val]
tscv = TimeSeriesSplit(n_splits=5)

candidates = {"A. RF 100": 100, "B. RF 500": 500}
records = {k: [] for k in candidates}

print("\n" + "=" * 72)
print("TimeSeriesSplit 5폴드 — 같은 분할에서 두 모델 비교")
print("=" * 72)
print(f"{'폴드':>6}", end="")
for k in candidates:
    print(f"{k:>14}", end="")
print(f"{'승자':>12}")
print("-" * 72)

for i, (tr, va) in enumerate(tscv.split(X_dev), 1):
    print(f"{i:>6}", end="")
    scores = {}
    for name, ne in candidates.items():
        pipe = make_pipe(ne)
        pipe.fit(X_dev.iloc[tr], y_dev.iloc[tr])
        mae = mean_absolute_error(y_dev.iloc[va], pipe.predict(X_dev.iloc[va]))
        records[name].append(mae)
        scores[name] = mae
        print(f"{mae:>14.2f}", end="")
    print(f"{min(scores, key=scores.get):>12}")

print("-" * 72)
for name, v in records.items():
    v = np.array(v)
    print(f"{name:<14} 평균 {v.mean():>10.2f} ± {v.std():.2f}   "
          f"범위 [{v.min():.2f}, {v.max():.2f}]")

diff = np.array(records["A. RF 100"]) - np.array(records["B. RF 500"])
print("-" * 72)
print(f"A - B: 평균 {diff.mean():+.2f} ± {diff.std():.2f}")
print(f"B 승리: {(diff > 0).sum()}/5 폴드")

if abs(diff.mean()) > 2 * diff.std() / np.sqrt(len(diff)):
    winner = "B. RF 500" if diff.mean() > 0 else "A. RF 100"
    print(f"→ ★ {winner} 가 유의미하게 낫습니다")
else:
    print("→ 두 모델의 차이는 폴드 간 변동폭 안에 있습니다. 구분 불가.")
    print("  더 단순한 A. RF 100 을 선택합니다 (학습 5배 빠름).")
print("=" * 72)

# ═══════════════════════════════════════════════════════════
# 최종 평가는 테스트셋에서 한 번만
# ═══════════════════════════════════════════════════════════
FINAL = False
if FINAL:
    final = make_pipe(100)
    final.fit(X_dev, y_dev)
    print(f"\n[테스트셋] MAE {mean_absolute_error(y_test, final.predict(X_test)):.2f}")
```

```markdown
| 항목 | 값 | 영향 |
|---|---|---|
| 전체 행 수 | 6,000 | 홀드아웃 가능, CV 병행 권장 |
| 타깃 왜도 | 1.43 | 계층 분할 효과 큼 |
| 그룹 구조 | 개발사 712종 (평균 8.4행) | ★ GroupShuffleSplit 필요 |
| 시간 정보 | 출시일 있음 | ★ 시간 순 분할 검토 |
| 오차 표준편차 (예비) | 5,104 | 5% 차이 구분에 364건 필요 |

### 2. 결정
| 항목 | 결정 | 근거 |
|---|---|---|
| 비율 | 60 : 20 : 20 | 검증셋 1,200건 (필요치 364건의 3.3배) |
| 계층 분할 | O (q=10) | 왜도 1.43. 변동폭 25% 감소 확인 |
| 그룹 | **GroupShuffleSplit(개발사)** | 무작위 분할 시 R² 0.993 → 0.902 (10% 부풀림) |
| 시간 | **미적용** | 아래 판정 참조 |
| 검증 방식 | 홀드아웃 + 최종 3개 후보만 5-fold CV | 6,000행. 홀드아웃 변동률 8% |
| seed | 42 고정, 최종 비교는 10개 반복 | 변동폭 측정 결과 반영 |
| 순서 | 분할 → 전처리 (Pipeline) | 특성 선택 누수 9.5% 확인 |

### 3. 시간 분할 미적용 판정 근거
- 예측 대상이 "새 게임의 세일가"이므로 시계열성이 있음
- 그러나 출시일과 타깃의 순위상관이 -0.08로 약함
- TimeSeriesSplit 적용 시 MAE 5,104 → 5,287 (3.6% 악화)
- ★ 3.6%는 구분 가능 한계(5%) 미만 → 시간 효과가 유의미하지 않음
- **결론: 시간 순 분할 미적용. 단, 보고서에 이 판정 근거를 명시**

### 4. 측정 결과 요약

### 5. 이 프로젝트의 판단 기준
> **"검증 MAE 차이가 5% 미만이면 동등하다고 본다."**
> 이보다 작은 차이는 검증셋 크기(1,200건)로 구분할 수 없습니다.
> 성능이 동등하면 **더 단순하고 빠른 모델**을 선택합니다.
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 분할 비율 | 비율보다 **검증셋의 절대 크기** |
| 검증셋 최소 크기 | `n = (2σ / 목표차이)²` |
| 표준오차 | **σ/√n** — 4배 크게 하면 정밀도 2배 |
| **seed 변동폭** | **성능 차이가 이보다 작으면 구분 불가** |
| 쌍체 비교 | **같은 분할에서 모든 모델 평가.** 분할 영향이 상쇄됨 |
| 작은 데이터의 위험 | 500행 → 변동률 27%, 승률 35% (동전 던지기) |
| 홀드아웃 vs CV | CV 표준편차가 홀드아웃의 **약 0.4배** |
| CV 사용 기준 | **2,000행 미만은 필수** · 학습이 매우 느리면 홀드아웃 |
| 계층 분할 | `pd.qcut(y, q)` 후 `stratify`. **비용 0, 효과 확실** |
| q 정하기 | 500행→5 · 1만행→10 · 5만행+→20 |
| 시계열 분할 | `TimeSeriesSplit`. **`gap` 으로 누수 방지** |
| 시계열 폴드 추이 | MAE가 커지면 **분포 변화 신호** → 재학습 주기 |
| 그룹 분할 | `GroupShuffleSplit` / `GroupKFold` / `LeaveOneGroupOut` |
| 전처리 누수 위험도 | **특성선택(9.5%) ≫ PCA(1.4%) > 절단 > 스케일링(0%)** |
| 가장 안전한 방법 | **`Pipeline`** — 판단 자체가 필요 없어짐 |

**오늘 반드시 기억할 세 가지**
> ① **성능 차이가 seed 변동폭보다 작으면 그 비교는 무의미합니다.**
> ② **같은 분할에서 모든 모델을 평가하세요.** 쌍체 비교가 분할 영향을 지웁니다.
> ③ **2,000행 미만이면 교차검증이 선택이 아니라 필수입니다.**
