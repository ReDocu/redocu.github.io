## 1부 · `str` 접근자

pandas 의 문자열 열은 `.str` 을 붙여 **전체에 한 번에** 적용합니다.

```python

```

### 공백·대소문자

```python
s.str.strip()             # 양쪽 공백 제거
s.str.lstrip()  s.str.rstrip()
s.str.lower()   s.str.upper()   s.str.title()
s.str.replace(r"\s+", " ", regex=True)      # 연속 공백 → 하나
```

### 검색

```python
s.str.contains("서울")                    # 포함 여부 (정규식 사용 가능)
s.str.contains("서울", na=False)          # 결측을 False 로  ← 중요
s.str.contains("서울|부산", regex=True)
s.str.startswith("서울")   s.str.endswith("시")
s.str.match(r"^\d{3}")                    # 처음부터 일치
s.str.find("구")                          # 위치 (없으면 -1)
```

> ⚠️ **`contains` 는 결측에 `NaN` 을 반환합니다.**
> ```python

> # ValueError: Cannot mask with non-boolean array containing NA / NaN values
> ```
> **`na=False` 를 습관처럼 붙이세요.**

### 치환

```python
s.str.replace("서울시", "서울특별시")                    # 문자열 그대로
s.str.replace(r"[^\d]", "", regex=True)                 # 정규식
s.str.replace(r"(\d{3})(\d{4})", r"\1-\2", regex=True)  # 그룹 참조
```

> ⚠️ **pandas 2.0부터 `regex` 기본값이 `False` 입니다.**
> 정규식을 쓰려면 **반드시 `regex=True`** 를 명시해야 합니다.

## 2부 · 정규표현식

### 기본 문자

| 패턴 | 의미 | 예 |
|---|---|---|
| `.` | 아무 문자 1개 (개행 제외) | `a.c` → `abc`, `a1c` |
| `\d` | 숫자 `[0-9]` | `\d\d` → `42` |
| `\D` | 숫자가 아닌 것 | |
| `\w` | 글자·숫자·`_` (**한글 포함**) | |
| `\W` | `\w` 가 아닌 것 | |
| `\s` | 공백·탭·개행 | |
| `\S` | 공백이 아닌 것 | |

### 문자 클래스

```
[abc]        a 또는 b 또는 c
[a-z]        영소문자
[A-Za-z]     영문자
[0-9]        숫자
[가-힣]       한글 완성형     ⭐
[ㄱ-ㅎㅏ-ㅣ]  한글 자모 (ㅋㅋㅋ, ㅜㅜ)
[^abc]       a,b,c 가 아닌 것   (^ 는 부정)
```

### 수량자

| 패턴 | 의미 |
|---|---|
| `*` | 0개 이상 |
| `+` | **1개 이상** |
| `?` | 0개 또는 1개 |
| `{3}` | 정확히 3개 |
| `{2,4}` | 2~4개 |
| `{2,}` | 2개 이상 |
| `+?` `*?` | **최소 매칭 (lazy)** ⭐ |

**탐욕(greedy) vs 최소(lazy)**

```python
text = "<b>굵게</b> 그리고 <i>기울임</i>"

re.findall(r"<.+>", text)      # ['<b>굵게</b> 그리고 <i>기울임</i>']  ← 통째로
re.findall(r"<.+?>", text)     # ['<b>', '</b>', '<i>', '</i>']       ✅
```

> **`+` 는 최대한 많이 먹습니다.** `?` 를 붙이면 최소한만 먹습니다.
> HTML 태그 제거처럼 **구분자가 반복될 때** `?` 가 필수입니다.

### 위치

| 패턴 | 의미 |
|---|---|
| `^` | 문자열 시작 |
| `$` | 문자열 끝 |
| `\b` | 단어 경계 |
| `(?=...)` | 뒤에 이것이 옴 (전방탐색) |
| `(?!...)` | 뒤에 이것이 오지 않음 |

```python
re.sub(r"(\d)(?=(\d{3})+$)", r"\1,", "1234567")     # '1,234,567'
```

### 그룹

```python
r"(\d{3})-(\d{4})"              # 번호 그룹 → \1, \2
r"(?P<area>\d{3})-(?P<num>\d+)" # 이름 그룹 → \g<area>
r"(?:서울|부산)"                  # 캡처하지 않는 그룹
```

```python
re.sub(r"(\d{3})(\d{4})", r"\1-\2", "01012345678")
```

### `re` 모듈

```python
import re

re.search(pattern, text)        # 첫 매칭 (없으면 None)
re.match(pattern, text)         # 처음부터 매칭
re.fullmatch(pattern, text)     # 전체가 일치
re.findall(pattern, text)       # 모든 매칭 리스트
re.finditer(pattern, text)      # 매칭 객체 이터레이터
re.sub(pattern, repl, text)     # 치환
re.split(pattern, text)         # 분리

p = re.compile(pattern)         # 반복 사용 시 컴파일 ⭐
p.search(text)
```

| 플래그 | 의미 |
|---|---|
| `re.I` | 대소문자 무시 |
| `re.M` | `^` `$` 가 줄마다 |
| `re.S` | `.` 이 개행도 포함 |
| `re.X` | 공백·주석 허용 (긴 패턴 가독성) |

```python
PHONE = re.compile(r"""
    (0\d{1,2})      # 지역번호
    [-.\s]?
    (\d{3,4})       # 국번
    [-.\s]?
    (\d{4})         # 번호
""", re.X)
```

> **반복 사용하는 패턴은 `re.compile` 하세요.**
> 100만 행에 `str.replace` 를 여러 번 돌리면 차이가 큽니다.

## 3부 · 보이지 않는 문제들

### 눈에 안 보이는 공백

크롤링 데이터의 단골입니다.

| 문자 | 코드 | 어디서 오나 |
|---|---|---|
| 일반 공백 | `\x20` | 정상 |
| **`&nbsp;`** | `\xa0` | **HTML** ⭐ |
| 탭 | `\t` | 복사·붙여넣기 |
| 전각 공백 | `\u3000` | 한중일 문서 |
| **폭 없는 공백** | `\u200b` | **눈에 아예 안 보임** ⭐ |
| BOM | `\ufeff` | 파일 앞머리 |

```python
print(repr(df["name"].iloc[0]))     # '경복궁\xa0'   ← repr 로 확인!
```

```python
INVISIBLE = r"[\u200b-\u200f\u2028\u2029\ufeff\xa0\u3000]"

df["name"] = (df["name"]
              .str.replace(INVISIBLE, " ", regex=True)
              .str.replace(r"\s+", " ", regex=True)
              .str.strip())
```

> **`repr()` 로 확인하는 습관을 들이세요.**
> `print()` 로는 `\xa0` 이 그냥 공백처럼 보입니다.

### 유니코드 정규화 — 한글의 함정

**같아 보이는데 다른 문자**가 있습니다.

```python
a = "한글"          # 완성형 (NFC) — 2글자
b = "한글"          # 자모 분리 (NFD) — 6글자

a == b              # False!
len(a), len(b)      # (2, 6)
```

```python
import unicodedata

unicodedata.normalize("NFC", text)      # 완성형으로 통일 ⭐
```

> ⚠️ **macOS 에서 만든 파일명·데이터는 NFD 인 경우가 많습니다.**
> Windows 는 NFC 입니다. 두 환경의 데이터를 합치면 **같은 글자가 안 맞습니다.**
> **데이터를 읽자마자 NFC로 정규화**하는 것이 안전합니다.

### 전각 문자

```
ＡＢＣ１２３   ← 전각 (full-width)
ABC123       ← 반각 (half-width)
```

```python
unicodedata.normalize("NFKC", "ＡＢＣ１２３")     # 'ABC123'
```

| 형식 | 하는 일 |
|---|---|
| `NFC` | 자모를 완성형으로 합침 (**한글 필수**) |
| `NFKC` | NFC + **전각→반각**, 호환 문자 변환 |

> **`NFKC` 는 강력하지만 조심하세요.**
> `①` → `1`, `㈜` → `(주)`, `Ⅳ` → `IV` 로도 바뀝니다.
> 의도한 변환인지 확인하고 쓰세요.

### 이모지·특수문자

## 4부 · 표기 통일

### 3단계 전략

```
① 정규화   공백·대소문자·유니코드를 맞춤       → 자동
② 매핑     알려진 변형을 사전으로 치환           → 수동 (핵심)
③ 검증     남은 값을 확인하고 사전에 추가        → 반복
```

**① 정규화**

```python
def normalize(s):
    return (s.astype(str)
             .str.normalize("NFC")
             .str.replace(INVISIBLE, " ", regex=True)
             .str.replace(r"\s+", " ", regex=True)
             .str.strip())
```

**② 매핑 사전**

```python
SIDO_MAP = {
    "서울": "서울특별시", "서울시": "서울특별시", "서울 특별시": "서울특별시",
    "SEOUL": "서울특별시", "Seoul": "서울특별시",
    "부산": "부산광역시", "부산시": "부산광역시",
    "제주": "제주특별자치도", "제주도": "제주특별자치도", "제주시": "제주특별자치도",
}

df["sido"] = df["sido"].replace(SIDO_MAP)
```

**규칙 기반이 더 나은 경우도 있습니다**

```python
SIDO_RULES = [
    (r"^서울", "서울특별시"),
    (r"^부산", "부산광역시"),
    (r"^제주", "제주특별자치도"),
    (r"^경기", "경기도"),
]

for pattern, standard in SIDO_RULES:
    mask = df["sido"].str.contains(pattern, regex=True, na=False)
    df.loc[mask, "sido"] = standard
```

| 방식 | 장점 | 단점 |
|---|---|---|
| **매핑 사전** | 정확·명시적 | 새 변형이 나오면 추가 필요 |
| **규칙(정규식)** | 변형을 폭넓게 흡수 | **의도치 않은 것까지 매칭** |

> **둘을 함께 쓰세요.** 규칙으로 대부분 잡고, 예외는 사전으로 처리합니다.
> 그리고 **③ 검증을 반드시** — 남은 고유값을 눈으로 확인합니다.

## ④ 단계별 실습

### Step 1. 지저분한 문자열 진단

```python
"""문자열 열의 숨은 문제를 찾아냅니다."""

import re
import unicodedata

import pandas as pd

INVISIBLE = r"[\u200b-\u200f\u2028\u2029\ufeff\xa0\u3000\t]"
EMOJI = re.compile(
    "[\U0001F300-\U0001FAFF\U00002700-\U000027BF"
    "\U00002600-\U000026FF\U0001F1E6-\U0001F1FF\uFE0F]+")

# ── 실습 데이터 (크롤링 결과를 흉내 냄) ──
df = pd.DataFrame({
    "name": [
        "경복궁", "경복궁 ", " 남산타워", "북촌한옥마을\xa0",
        "🏯 창덕궁", "덕수궁\u200b", "ＮＳ타워", "청계천  산책로",
    ],
    "addr": [
        "서울특별시 종로구 사직로 161",
        "서울시 중구 세종대로 110",
        "서울 용산구 남산공원길 105",
        "서울특별시  종로구 계동길 37",
        "SEOUL 종로구 율곡로 99",
        "서울 특별시 중구 세종대로 99",
        "부산광역시 해운대구 우동",
        "부산시 중구 광복로",
    ],
    "tel": [
        "02-3700-3900", "0237003900", "02)3700-3900", "02 3700 3900",
        "+82-2-3700-3900", "없음", "02-3700-3900 (내선 1)", "",
    ],
    "price": [
        "3,000원", "무료", "1,000 원", "₩5,000",
        "성인 3,000원 / 청소년 1,500원", "10000", "3천원", "-",
    ],
    "category": [
        "고궁", "고궁 ", "궁궐", "한옥마을",
        "고궁/문화재", "고궁", "전망대", "공원",
    ],
})

print("=" * 78)
print("                    문자열 진단")
print("=" * 78)

# ══════════ ① 보이지 않는 문자 ══════════
print(f"\n[① 보이지 않는 문자]")

for col in df.columns:
    problems = []

    for i, v in df[col].items():
        if not isinstance(v, str):
            continue

        found = []
        if re.search(r"^\s|\s$", v):
            found.append("앞뒤공백")
        if "\xa0" in v:
            found.append("nbsp(\\xa0)")
        if "\u200b" in v:
            found.append("폭없는공백")
        if re.search(r"\s{2,}", v):
            found.append("연속공백")
        if EMOJI.search(v):
            found.append("이모지")
        if v != unicodedata.normalize("NFC", v):
            found.append("NFD(자모분리)")
        if any(ord(c) > 0xFF00 and ord(c) < 0xFFEF for c in v):
            found.append("전각문자")

        if found:
            problems.append((i, repr(v)[:30], ", ".join(found)))
```

### Step 2. 정제 함수 만들기

```python
"""재사용 가능한 문자열 정제 도구."""

import re
import unicodedata

import numpy as np
import pandas as pd

# ══════════ 상수 ══════════
INVISIBLE_PATTERN = r"[\u200b-\u200f\u2028\u2029\ufeff\xa0\u3000\t\r\n]"

EMOJI_PATTERN = re.compile(
    "["
    "\U0001F300-\U0001FAFF"
    "\U00002700-\U000027BF"
    "\U00002600-\U000026FF"
    "\U0001F1E6-\U0001F1FF"
    "\u2190-\u21FF\u2B00-\u2BFF\uFE0F\u20E3"
    "]+", flags=re.UNICODE)

NA_TEXTS = {"", "-", "--", "없음", "미상", "N/A", "n/a", "null", "NULL",
            "?", "nan", "None", "정보없음", "해당없음"}


# ══════════ 기본 정제 ══════════

def clean_text(series, full_width=False, keep_emoji=False):
    """
    문자열 열의 기본 정제.

    full_width : True 면 전각→반각 변환 (NFKC)
    keep_emoji : True 면 이모지 유지
    """
    s = series.astype("string")

    # ① 유니코드 정규화 — 한글 자모 분리 해결
    form = "NFKC" if full_width else "NFC"
    s = s.map(lambda v: unicodedata.normalize(form, v)
              if isinstance(v, str) else v)

    # ② 보이지 않는 문자 → 공백
    s = s.str.replace(INVISIBLE_PATTERN, " ", regex=True)

    # ③ 이모지 제거
    if not keep_emoji:
        s = s.str.replace(EMOJI_PATTERN, "", regex=True)

    # ④ 연속 공백 → 하나, 앞뒤 제거
    s = s.str.replace(r"\s+", " ", regex=True).str.strip()

    # ⑤ 결측 표현 통일
    s = s.mask(s.isin(NA_TEXTS), pd.NA)

    return s


def keep_korean(series, extra=""):
    """한글·영문·숫자·공백만 남깁니다."""
    pattern = rf"[^가-힣a-zA-Z0-9\s{re.escape(extra)}]"
    return (series.str.replace(pattern, "", regex=True)
                  .str.replace(r"\s+", " ", regex=True)
                  .str.strip())


# ══════════ 도메인별 정제 ══════════

SIDO_RULES = [
    (r"^(서울|SEOUL|Seoul)", "서울특별시"),
    (r"^부산", "부산광역시"),
    (r"^대구", "대구광역시"),
    (r"^인천", "인천광역시"),
    (r"^광주", "광주광역시"),
    (r"^대전", "대전광역시"),
    (r"^울산", "울산광역시"),
    (r"^세종", "세종특별자치시"),
    (r"^경기", "경기도"),
    (r"^강원", "강원특별자치도"),
    (r"^(충북|충청북)", "충청북도"),
    (r"^(충남|충청남)", "충청남도"),
    (r"^(전북|전라북)", "전북특별자치도"),
    (r"^(전남|전라남)", "전라남도"),
    (r"^(경북|경상북)", "경상북도"),
    (r"^(경남|경상남)", "경상남도"),
    (r"^제주", "제주특별자치도"),
]


def parse_address(series):
    """
    주소에서 시도·시군구를 추출합니다.

    반환: DataFrame(sido, sigungu, rest)
    """
    s = clean_text(series)

    result = pd.DataFrame(index=s.index,
                          columns=["sido", "sigungu", "rest"], dtype="object")

    # ── 시도 표준화 ──
    for pattern, standard in SIDO_RULES:
        mask = s.str.contains(pattern, regex=True, na=False)
        result.loc[mask, "sido"] = standard

    # ── 시군구 추출 ──
    sigungu = s.str.extract(r"([가-힣]+(?:시|군|구))(?:\s|$)", expand=False)

    # 시도 이름 자체가 잡힌 경우 제외 (예: '서울특별시'의 '시')
    is_sido = sigungu.isin([v for _, v in SIDO_RULES])
    result["sigungu"] = sigungu.mask(is_sido)

    # ── 나머지 ──
    result["rest"] = s

    return result


PHONE_RE = re.compile(r"(0\d{1,2}|\+?82[-\s]?\d{1,2})[-.)\s]*(\d{3,4})[-.\s]*(\d{4})")


def normalize_phone(series):
    """전화번호를 0X-XXXX-XXXX 형식으로 통일합니다."""
    s = clean_text(series)

    def convert(v):
        if pd.isna(v):
            return pd.NA

        m = PHONE_RE.search(str(v))
        if not m:
            return pd.NA

        area = m.group(1).replace("+82", "0").replace("-", "").replace(" ", "")
        if not area.startswith("0"):
            area = "0" + area

        return f"{area}-{m.group(2)}-{m.group(3)}"

    return s.map(convert)


KOREAN_UNITS = {"조": 10**12, "억": 10**8, "만": 10**4, "천": 10**3, "백": 100}


def parse_price(series, free_words=("무료", "무료입장", "0원", "없음")):
    """
    가격 문자열에서 숫자를 뽑습니다.

    반환: DataFrame(price, price_note)
    """
    s = clean_text(series)
    out = pd.DataFrame(index=s.index, columns=["price", "note"], dtype="object")

    for i, v in s.items():
        if pd.isna(v):
            out.loc[i] = [pd.NA, "결측"]
            continue

        text = str(v)

        # ── 무료 ──
        if any(w in text for w in free_words):
            out.loc[i] = [0.0, "무료"]
            continue

        # ── 한글 단위 (3천원, 1만5천원) ──
        unit_match = re.findall(r"(\d+(?:\.\d+)?)\s*([조억만천백])", text)
        if unit_match:
            total = sum(float(n) * KOREAN_UNITS[u] for n, u in unit_match)
            tail = re.search(r"[조억만천백]\s*(\d+)\s*원?$", text)
            if tail:
                total += float(tail.group(1))
            out.loc[i] = [total, "한글단위"]
            continue

        # ── 일반 숫자 ──
        nums = re.findall(r"\d[\d,]*", text)
        if not nums:
            out.loc[i] = [pd.NA, "숫자없음"]
            continue

        values = [float(n.replace(",", "")) for n in nums]
        note = "정상" if len(values) == 1 else f"여러값({len(values)}개) 첫값사용"
        out.loc[i] = [values[0], note]

    out["price"] = pd.to_numeric(out["price"], errors="coerce")
    return out
```

## ⑤ 자주 하는 실수

### `.str` 없이 문자열 메서드 호출

```python
df["name"].strip()
```

```
AttributeError: 'Series' object has no attribute 'strip'
```

**해결** — `df["name"].str.strip()`

### `contains` 에 `na=False` 누락

```python
df[df["addr"].str.contains("서울")]
```

```
ValueError: Cannot mask with non-boolean array containing NA / NaN values
```

**해결** — `df["addr"].str.contains("서울", na=False)`

### `replace` 에 `regex=True` 누락 (pandas 2.0+)

```python
df["tel"].str.replace(r"[^\d]", "")        # 아무 일도 안 일어남
```

**해결** — `regex=True` 를 명시합니다.

### 탐욕 매칭으로 통째로 삭제

```python
re.sub(r"<.+>", "", "<b>굵게</b> 일반 <i>기울임</i>")     # ''  전부 사라짐
```

**해결** — `re.sub(r"<.+?>", "", text)`

### `\xa0` 를 못 보고 지나감

```python
df[df["name"] == "경복궁"]      # 0건
print(df["name"].iloc[0])       # '경복궁'  ← 똑같아 보임
print(repr(df["name"].iloc[0])) # '경복궁\xa0'  ← 이제 보임
```

**해결** — `repr()` 로 확인하고 `strip()` + 보이지 않는 문자 제거

### 한글 자모 분리(NFD)를 모름

```python
"한글" == "한글"        # False (하나는 NFD)
```

**해결** — 읽자마자 `unicodedata.normalize("NFC", ...)`

### 정규식 특수문자를 이스케이프하지 않음

```python
df["price"].str.replace("(", "", regex=True)
```

```
re.error: missing ), unterminated subpattern
```

**해결** — `re.escape("(")` 또는 `regex=False`

### `strip()` 이 한 종류 공백만 지운다고 착각

```python
"경복궁\xa0".strip()      # '경복궁\xa0'  ← \xa0 는 안 지워짐
```

**해결** — 보이지 않는 문자를 **먼저 일반 공백으로 치환**한 뒤 `strip()`

### 매핑 사전만 쓰고 검증 안 함

```python
df["sido"] = df["sido"].replace(SIDO_MAP)
# 사전에 없는 '서울시 ' (공백 포함)는 그대로 남음
```

**해결** — **정규화 → 매핑 → 남은 고유값 확인** 순서로, 결과를 눈으로 봅니다.

### 숫자 추출 시 여러 숫자를 무시

```python
re.findall(r"\d+", "성인 3000원 청소년 1500원")[0]      # 3000 — 맞나?
```

**해결** — 여러 개면 **플래그를 남겨** 사람이 확인하게 합니다.

```python
df["num"] = df["tel"].str.extract(r"(\d{3})-(\d{4})")
```

```
ValueError: Expected a 1D array, got an array with shape (8, 2)
```

**해결** — 그룹이 1개면 `expand=False`, 여러 개면 DataFrame으로 받습니다.

```python
df["price"] = df["price"].str.replace(r"[^\d]", "", regex=True).astype(int)
```

| # | 기법 | 쓰임 |
|---|---|---|
| ① | `^...$` | **완전 일치** — 형식 검증 |
| ② | `[^...]` | **부정 문자 클래스** — "이것 빼고 다" |
| ③ | `(?:...)` | **캡처하지 않는 그룹** — `findall` 결과가 깔끔해짐 |
| ④ | `(?=...)` | **전방탐색** — 위치만 확인하고 소비하지 않음 |
| ⑤ | `[-.\s]?` | **선택적 구분자** — 형식이 제각각일 때 |

```python
# ── ① 기본 정제 (모든 문자열 열) ──                          ①⑧
for col in df.select_dtypes(include="object").columns:
    df[col] = (df[col].astype("string")
               .map(lambda v: unicodedata.normalize("NFC", v)
                    if isinstance(v, str) else v)
               .str.replace(INVISIBLE, " ", regex=True)          # ⑧
               .str.replace(r"\s+", " ", regex=True)
               .str.strip())

# ── ② 가격: 원본 보존 + 안전 변환 ──                          ②③
df["price_text"] = df["price"]
digits = df["price"].str.replace(r"[^\d]", "", regex=True)       # ②
df["price"] = pd.to_numeric(digits.replace("", np.nan),          # ③
                            errors="coerce")

# '무료' 는 0 으로
df.loc[df["price_text"].str.contains("무료", na=False), "price"] = 0

print(f"[가격] 변환 성공 {df['price'].notna().sum()}/{len(df)}건")

# ── ③ 시도 표준화를 먼저, 필터는 나중에 ──                    ⑤⑥⑦
df["sido"] = pd.NA

for pattern, standard in SIDO_RULES:
    mask = df["addr"].str.contains(pattern, regex=True, na=False)  # ④
    df.loc[mask & df["sido"].isna(), "sido"] = standard

unmatched = df["sido"].isna().sum()
if unmatched:
    print(f"[시도] 미분류 {unmatched}건: "
          f"{df.loc[df['sido'].isna(), 'addr'].head(3).tolist()}")

# ── ④ 표준화된 값으로 필터 ──                                 ⑤
seoul = df[df["sido"] == "서울특별시"].copy()
print(f"[필터] 서울 {len(seoul)}건 "
      f"(원본 '서울' 문자열 매칭: "
      f"{original['addr'].str.contains('서울', na=False).sum()}건)")

# ── ⑤ 전화번호: 형식 통일 (제거가 아니라) ──
PHONE_RE = re.compile(r"(0\d{1,2})[-.)\s]*(\d{3,4})[-.\s]*(\d{4})")

def normalize_phone(v):
    if pd.isna(v):
        return pd.NA
    m = PHONE_RE.search(str(v))
    return f"{m.group(1)}-{m.group(2)}-{m.group(3)}" if m else pd.NA

df["tel_raw"] = df["tel"]
df["tel"] = df["tel"].map(normalize_phone)

print(f"[전화] 정규화 성공 {df['tel'].notna().sum()}/{len(df)}건")

# ── ⑥ 검증 ──
print(f"\n[시도별 집계]")
print(df["sido"].value_counts(dropna=False).to_string())

print(f"\n[정제 효과]")
raw_sido = original["addr"].str.split().str[0].nunique()
print(f"  주소 첫 단어 고유값 : {raw_sido}개")
print(f"  표준화 후 시도      : {df['sido'].nunique()}개")
```

**핵심 4가지**

| 원칙 | 이유 |
|---|---|
| **정규화 → 표준화 → 필터** | 순서가 바뀌면 표기 변형을 놓침 |
| **`.str` + `na=False` + `regex=True`** | pandas 문자열 3종 세트 |
| **원본 열 보존** (`price_text`, `tel_raw`) | 변환이 이상할 때 확인 가능 |
| **미분류 건수 출력** | 규칙에 없는 값을 발견 |

> **⑤번(필터 순서)이 가장 중요한 교훈입니다.**
> `contains("서울")` 로 필터하면 `SEOUL 종로구` 가 빠집니다.
> **표준화를 먼저 하면** `sido == "서울특별시"` 로 정확히 잡을 수 있습니다.
>
> 반대로 `contains("서울")` 은 **`서울대공원`(경기도 과천시)** 같은 것도 잡아 버립니다.
> 문자열 포함 여부로 필터하는 것은 **양쪽으로 위험**합니다.
</details>

```python
"""표기 불일치 자동 탐지 및 통일 제안."""

import re
import unicodedata
from difflib import SequenceMatcher

import pandas as pd

INVISIBLE = r"[\u200b-\u200f\ufeff\xa0\u3000\t\r\n]"


def canonical_key(text):
    """비교용 표준 키 — 공백·기호·대소문자를 모두 제거한 형태."""
    if pd.isna(text):
        return ""

    s = unicodedata.normalize("NFKC", str(text))
    s = re.sub(INVISIBLE, "", s)
    s = re.sub(r"[\s\-_·/,.()]", "", s)
    return s.lower()


def similarity(a, b):
    return SequenceMatcher(None, a, b).ratio()


def find_variants(series, min_similarity=0.72, min_count=1, verbose=True):
    """
    같은 것을 다르게 쓴 값들을 찾아 묶습니다.

    반환: DataFrame(대표값, 변형들, 총건수, 사유)
    """
    counts = series.dropna().value_counts()
    values = counts.index.tolist()

    # ── ① 표준 키로 1차 그룹핑 (확실한 경우) ──
    key_groups = {}
    for v in values:
        key_groups.setdefault(canonical_key(v), []).append(v)

    groups = []
    used = set()

    for key, members in key_groups.items():
        if len(members) > 1:
            groups.append({"members": members, "reason": "공백·기호만 다름"})
            used.update(members)

    # ── ② 유사도로 2차 그룹핑 (추정) ──
    remaining = [v for v in values if v not in used]

    for i, a in enumerate(remaining):
        if a in used:
            continue

        similar = [a]

        for b in remaining[i + 1:]:
            if b in used:
                continue

            ka, kb = canonical_key(a), canonical_key(b)

            # 포함 관계 (서울 ⊂ 서울특별시)
            contained = (ka and kb and (ka in kb or kb in ka)
                         and min(len(ka), len(kb)) >= 2)

            if contained or similarity(ka, kb) >= min_similarity:
                similar.append(b)
                used.add(b)

        if len(similar) > 1:
            used.add(a)
            reason = ("포함 관계" if any(canonical_key(similar[0]) in canonical_key(x)
                                     or canonical_key(x) in canonical_key(similar[0])
                                     for x in similar[1:])
                      else f"유사도 ≥{min_similarity}")
            groups.append({"members": similar, "reason": reason})

    # ── ③ 대표값 선정 ──
    rows = []
    for g in groups:
        members = g["members"]
        total = sum(counts[m] for m in members)

        if total < min_count:
            continue

        # 대표: ①빈도 높은 것 → ②긴 것(정식 명칭일 확률)
        rep = max(members, key=lambda m: (counts[m], len(str(m))))

        rows.append({
            "대표값": rep,
            "변형": [m for m in members if m != rep],
            "변형수": len(members) - 1,
            "총건수": total,
            "사유": g["reason"],
        })

    result = pd.DataFrame(rows)
    if not result.empty:
        result = result.sort_values("총건수", ascending=False).reset_index(drop=True)

    if verbose:
        print("=" * 84)
        print(f"            표기 불일치 탐지 — 고유값 {len(values)}개")
        print("=" * 84)

        if result.empty:
            print("\n  통일할 후보가 없습니다.")
            print("=" * 84)
            return result

        for _, r in result.iterrows():
            icon = "🟢" if r["사유"] == "공백·기호만 다름" else "🟡"
            print(f"\n  {icon} 대표: {r['대표값']!r}  (총 {r['총건수']}건, {r['사유']})")
            for v in r["변형"]:
                print(f"       ← {v!r}  ({counts[v]}건)")

        after = len(values) - result["변형수"].sum()
        print(f"\n{'=' * 84}")
        print(f"  고유값 {len(values)}개 → {after}개 "
              f"({result['변형수'].sum()}개 통합 가능)")
        print(f"  🟢 확실 (자동 적용 가능)  |  🟡 추정 (사람이 확인 필요)")
        print("=" * 84)

    return result


def build_mapping(variants_df, only_certain=False):
    """탐지 결과로 매핑 사전을 만듭니다."""
    mapping = {}

    for _, r in variants_df.iterrows():
        if only_certain and r["사유"] != "공백·기호만 다름":
            continue
        for v in r["변형"]:
            mapping[v] = r["대표값"]

    return mapping


# ══════════ 사용 ══════════
if __name__ == "__main__":
    messy = pd.Series([
        "서울특별시", "서울특별시", "서울시", "서울", "서울 특별시",
        "서울특별시 ", "SEOUL", "부산광역시", "부산광역시", "부산시",
        "부산", "제주특별자치도", "제주도", "제주", "경기도", "경기",
        "강원특별자치도", "인천광역시",
    ])

    variants = find_variants(messy)

    print("\n\n[생성된 매핑 사전]")
    mapping = build_mapping(variants)
    for k, v in list(mapping.items())[:10]:
        print(f"  {k!r:<20} → {v!r}")

    print("\n[적용 결과]")
    cleaned = messy.replace(mapping)
    print(f"  {messy.nunique()}개 → {cleaned.nunique()}개")
    print(cleaned.value_counts().to_string())
```

**탐지 기법 3가지**

| # | 기법 | 잡는 것 | 신뢰도 |
|---|---|---|---|
| ① | **표준 키 일치** | `'서울 특별시'` = `'서울특별시'` | **확실** 🟢 |
| ② | **포함 관계** | `'서울'` ⊂ `'서울특별시'` | 추정 🟡 |
| ③ | **문자열 유사도** | `'스타벅스'` ≈ `'스타박스'` | 추정 🟡 |

> **🟢 과 🟡 를 구분하는 것이 이 도구의 핵심입니다.**
>
> **①(표준 키)은 자동 적용해도 안전합니다.** 공백과 기호만 다르니까요.
>
> **②③은 반드시 사람이 확인해야 합니다.** 위험한 예를 봅시다.
>
> ```
> '광주광역시' 와 '광주시'(경기도 광주시)  →  포함 관계지만 다른 지역!
> '고양시' 와 '고양이'                      →  유사도가 높지만 완전히 다름
> ```
>
> **자동화는 후보를 좁혀 주는 것이지, 결정하는 것이 아닙니다.**
> 실무에서는 이 도구로 목록을 뽑고, **매핑 사전을 파일로 저장해 버전 관리**합니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `str` 접근자 | `df["col"].str.메서드()` — `.str` 필수 |
| `contains` | **`na=False`** 를 항상 |
| `replace` | pandas 2.0+ 는 **`regex=True`** 명시 |
| `extract` | 그룹 1개는 `expand=False`, 여러 개는 DataFrame |
| `split(expand=True)` | 열로 펼치기 |
| 정규식 기본 | `\d` `\w` `\s` `[가-힣]` `+` `*` `?` `{n,m}` |
| **lazy 매칭** | `.+?` — HTML 태그 제거의 필수 |
| 그룹 | `(...)` 캡처 · `(?:...)` 비캡처 · `(?P<n>...)` 이름 |
| **보이지 않는 문자** | `\xa0` `\u200b` — **`repr()` 로 확인** |
| **유니코드 정규화** | `NFC`(한글 필수) · `NFKC`(전각→반각) |
| 표기 통일 | **정규화 → 매핑 → 검증** 3단계 |
| 원본 보존 | `price_text`, `tel_raw` 를 남긴다 |

**오늘 반드시 기억할 세 가지**
> ① **`repr()` 로 확인하세요.** `print()` 로는 `\xa0` 와 공백이 똑같아 보입니다.
> ② **표준화를 먼저, 필터는 나중에.** `contains("서울")` 은 `SEOUL` 을 놓치고 `서울대공원`을 잘못 잡습니다.
> ③ **자동 통일은 후보 제안까지입니다.** `광주광역시` 와 `경기도 광주시` 는 사람만 구분할 수 있습니다.

**과제**
① **정규표현식 10문제** — 위 문제를 직접 풀고, 자기 데이터에 맞는 패턴 3개 추가 작성
② 수집 데이터의 **보이지 않는 문자**를 찾아 목록화 (`repr()` 로 확인)
③ 주소 열에서 **시도·시군구 추출** — 미분류 건수와 원인 정리
④ **표기 통일 매핑표**를 CSV 로 작성 (`변형 → 대표값` 형식)
⑤ 가격·전화번호 등 형식이 제각각인 열 1개 이상을 **하나의 형식으로 통일**
