## 3. 개념

### 3-1. 타격감의 구성 요소

**왜 필요한가** — 타격감은 하나가 아니라 여러 요소의 합이다.

```
   ┌──────────────────────────────────────────────────────────┐
   │  타격의 순간 (0.0 ~ 0.3초 사이에 일어나는 일들)            │
   │                                                           │
   │  0.00s  판정 성립                                          │
   │         ├─ 히트스톱 시작    (0.05~0.08초 정지)             │
   │         ├─ 화면 셰이크 시작 (0.15초)                       │
   │         ├─ 이펙트 생성      (섬광, 파티클)                 │
   │         └─ 효과음 재생                                     │
   │  0.06s  히트스톱 해제                                      │
   │         └─ 넉백 시작        (밀려나기)                     │
   │  0.15s  셰이크 종료                                        │
   │  0.25s  경직 해제           (조작 복귀)                    │
   │  0.50s  체력 게이지 지연분 감소 완료                        │
   └──────────────────────────────────────────────────────────┘
```

| 요소 | 지속 | 효과 |
|---|---|---|
| **히트스톱** | 0.03~0.10초 | "묵직함" — 가장 큰 영향 |
| **넉백** | 0.2~0.5초 | "밀린다" |
| **경직** | 0.2~0.6초 | 콤보를 가능하게 |
| **셰이크** | 0.1~0.3초 | "충격" |
| 이펙트 | 0.2~0.4초 | 시각적 강조 |
| 효과음 | — | 청각적 강조 |

```
   ★ 히트스톱이 가장 효과가 크다
     0.06초만 멈춰도 타격감이 완전히 달라진다
```

### 3-2. 히트스톱 (hitstop / hitlag)

**왜 필요한가** — 때리는 쪽과 맞는 쪽이 **동시에** 잠깐 멈춘다.

```
   히트스톱 없음                 히트스톱 있음

   ▶●  →  ▶ ●  →  ▶  ●         ▶●  →  ▶●  →  ▶●  →  ▶ ●
   부드럽게 지나감               ▲ 여기서 0.06초 멈춤
   "스친 것 같다"                "쿵 하고 박혔다"
```

```cpp
class Character
{
    double m_hitStopTimer = 0.0;

public:
    void ApplyHitStop(double duration)
    {
        if (duration > m_hitStopTimer)
            m_hitStopTimer = duration;
    }

    bool IsInHitStop() const { return m_hitStopTimer > 0.0; }
};

void Character::Update(double dt)
{
    if (m_hitStopTimer > 0.0)
    {
        m_hitStopTimer -= dt;

        m_animator.Update(0.0);               // ★ 애니메이션도 멈춘다
        return;                                // 물리·입력 전부 정지
    }

    // 평소 갱신
    ProcessInput(dt);
    UpdateState(dt);
    ApplyPhysics(dt);
    m_animator.Update(dt);
}
```

```
   ★ 때린 쪽과 맞는 쪽 둘 다 멈춰야 한다

   attacker->ApplyHitStop(0.06);
   defender->ApplyHitStop(0.06);

   한쪽만 멈추면 어색하다
```

**강도별 히트스톱**

| 공격 | 히트스톱 |
|---|:--:|
| 약공격 | 0.03초 |
| 중공격 | 0.06초 |
| 강공격 | 0.10초 |
| 필살기 | 0.15초 |

### 3-3. 넉백

**왜 필요한가** — 맞으면 밀려나야 거리 개념이 생긴다.

```cpp
void Character::TakeHit(int damage, double kbX, double kbY, double stun)
{
    m_hp -= damage;
    if (m_hp < 0) m_hp = 0;

    m_vx = kbX;                               // ★ 속도를 덮어쓴다
    m_vy = kbY;

    if (kbY < 0) m_onGround = false;          // 띄우기

    ChangeState(STATE_HIT);
    m_hitStunTime = stun;
}
```

```cpp
void Character::UpdateHit(double dt)
{
    m_vx *= 0.90;                             // 감쇠 (마찰)

    if (m_stateTimer >= m_hitStunTime)
    {
        if (m_onGround) ChangeState(STATE_IDLE);
        else            ChangeState(STATE_FALL);
    }
}
```

```
   넉백 감쇠 (0.90/프레임, 60fps)

   시간(초)  속도
   0.00      220
   0.05      130
   0.10       77
   0.15       46
   0.25       16       ← 경직 해제 시점에 거의 멈춤

   ★ 감쇠 계수를 dt 에 맞춰야 정확하다
     m_vx *= pow(0.90, dt * 60.0)
     또는 간단히 m_vx -= m_vx * 6.0 * dt
```

**공중 넉백**

```
   지상 히트  →  kbY = 0     그냥 뒤로 밀림
   띄우기     →  kbY = -300  위로 떠오름 (콤보 시작)
   내리찍기   →  kbY = +200  땅에 처박음
```

### 3-4. 경직 (hitstun)

**왜 필요한가** — 경직이 콤보를 가능하게 한다. 격투게임의 핵심 설계.

```
   경직 시간과 공격 후딜의 관계

   [ 콤보 불가 ]
   공격 A ────────────┐
   후딜        ████████│  (0.3초)
   상대 경직   ██████  │  (0.25초)  ← 경직이 먼저 끝난다
                       ▼
                  상대가 반격 가능


   [ 콤보 가능 ]
   공격 A ──────┐
   후딜    ████ │  (0.2초)
   상대 경직 ████████  (0.35초)  ← 경직이 더 길다
                ▼
           다음 공격 연결 가능
```

```
   ★ 이 관계가 게임 밸런스를 결정한다

   경직 > 후딜  →  콤보 가능 (공격이 유리)
   경직 < 후딜  →  콤보 불가 (방어가 유리)
   경직 ≈ 후딜  →  상황에 따라
```

| 공격 | 후딜 | 경직 | 콤보 |
|---|:--:|:--:|---|
| 약공격 | 0.15초 | 0.20초 | 가능 |
| 중공격 | 0.25초 | 0.28초 | 아슬아슬 |
| 강공격 | 0.40초 | 0.35초 | 불가 (빗나가면 위험) |

### 3-5. 화면 셰이크

**왜 필요한가** — 충격을 시각적으로 전달한다.

```cpp
class Camera
{
public:
    void Shake(double intensity, double duration)
    {
        if (intensity > m_shakeIntensity)
        {
            m_shakeIntensity = intensity;
            m_shakeTimer     = duration;
            m_shakeDuration  = duration;
        }
    }

    void Update(double dt)
    {
        if (m_shakeTimer <= 0.0) { m_offsetX = m_offsetY = 0; return; }

        m_shakeTimer -= dt;

        double t = m_shakeTimer / m_shakeDuration;         // 1.0 → 0.0
        double power = m_shakeIntensity * t;               // 점점 약해진다

        m_offsetX = (rand() % 200 - 100) / 100.0 * power;
        m_offsetY = (rand() % 200 - 100) / 100.0 * power;
    }

    int GetOffsetX() const { return (int)m_offsetX; }
    int GetOffsetY() const { return (int)m_offsetY; }

private:
    double m_shakeIntensity = 0, m_shakeTimer = 0, m_shakeDuration = 0;
    double m_offsetX = 0, m_offsetY = 0;
};
```

```cpp
    // 모든 렌더에 오프셋 적용
    int drawX = (int)m_x + camera.GetOffsetX();
    int drawY = (int)m_y + camera.GetOffsetY();
```

```
   ★ 셰이크 강도

   약공격    2~3 픽셀
   중공격    4~6 픽셀
   강공격    8~12 픽셀
   필살기    15~20 픽셀

   ★ 너무 크면 화면을 못 본다. 절제한다.
```

> **감쇠를 넣는 것이 중요하다.** 일정한 강도로 흔들면 멀미가 난다.

### 3-6. 체력 게이지 — 지연 게이지

**왜 필요한가** — 얼마나 맞았는지 눈으로 보이게 한다.

```
   ┌─────────────────────────────────────────────────┐
   │  ████████████████░░░░░░░░░░░░░░░░░░  120/200    │  ← 실제 체력 (빨강)
   │  ████████████████████░░░░░░░░░░░░░░               │  ← 지연 게이지 (노랑)
   │                    └──┘                          │
   │                   방금 받은 데미지                 │
   └─────────────────────────────────────────────────┘

   ★ 지연 게이지가 천천히 따라오면서
     "방금 얼마나 맞았는지"를 보여준다
```

```cpp
class HealthBar
{
public:
    void SetHp(int hp, int maxHp)
    {
        m_hp = hp;
        m_maxHp = maxHp;
        // m_delayedHp 는 건드리지 않는다
    }

    void Update(double dt)
    {
        m_delayTimer -= dt;

        if (m_delayTimer <= 0.0 && m_delayedHp > m_hp)
        {
            m_delayedHp -= DELAY_SPEED * dt;       // 초당 60씩 감소
            if (m_delayedHp < m_hp) m_delayedHp = m_hp;
        }
    }

    void OnDamaged() { m_delayTimer = 0.4; }       // 0.4초 후부터 따라온다

private:
    int    m_hp = 200, m_maxHp = 200;
    double m_delayedHp = 200.0;
    double m_delayTimer = 0.0;

    static constexpr double DELAY_SPEED = 90.0;
};
```

**게이지 그리기**

```cpp
void HealthBar::Render(Renderer& r, int x, int y, int w, int h, bool rightAlign)
{
    double ratio      = (double)m_hp / m_maxHp;
    double delayRatio = m_delayedHp / m_maxHp;

    // 배경
    r.DrawRect(x, y, w, h, RGB(30, 30, 40));

    // 지연분 (노랑)
    int dw = (int)(w * delayRatio);
    if (rightAlign) r.DrawRect(x + w - dw, y, dw, h, RGB(220, 200, 60));
    else            r.DrawRect(x, y, dw, h, RGB(220, 200, 60));

    // 실제 체력 (빨강→초록 그라데이션)
    int hw = (int)(w * ratio);
    COLORREF c = (ratio > 0.5) ? RGB(60, 220, 80)
               : (ratio > 0.2) ? RGB(230, 200, 50)
                               : RGB(230, 60, 60);

    if (rightAlign) r.DrawRect(x + w - hw, y, hw, h, c);
    else            r.DrawRect(x, y, hw, h, c);

    // 테두리
    r.DrawRect(x, y, w, h, RGB(200, 200, 220), false);
}
```

### 3-7. 가드

**왜 필요한가** — 막을 방법이 없으면 계속 때리기만 하면 이긴다.

```cpp
bool Character::IsGuarding() const
{
    return m_state == STATE_GUARD;
}

bool Character::CanGuardAgainst(const HitboxData& hit) const
{
    if (!IsGuarding()) return false;

    // 뒤쪽에서 온 공격은 못 막는다
    // (Day 49에서 상대 방향을 알게 되면 정확해진다)

    // 하단 공격은 서서 가드 불가 (선택)
    if (hit.isLow && m_state != STATE_CROUCH) return false;

    return true;
}
```

```cpp
void Character::TakeHit(const HitboxData& d, double kbX, double kbY)
{
    if (CanGuardAgainst(d))
    {
        // 가드 성공
        m_hp -= d.damage / 4;                 // 데미지 1/4
        m_vx = kbX * 0.4;                     // 넉백 약화
        m_guardStunTimer = d.hitStun * 0.5;   // 경직 절반

        ApplyHitStop(0.04);                   // 히트스톱도 약하게
        // 상태는 GUARD 유지

        DebugLog("[GUARD] 방어 성공\n");
        return;
    }

    // 정타
    m_hp -= d.damage;
    m_vx = kbX;
    m_vy = kbY;
    ChangeState(STATE_HIT);
    ApplyHitStop(0.06);
}
```

### 3-8. 콤보 카운터

**왜 필요한가** — 연속 히트가 눈에 보이면 성취감이 생긴다.

```cpp
class Character
{
    int    m_comboCount = 0;
    double m_comboTimer = 0.0;

public:
    void OnHitConfirm()                       // 내 공격이 맞았을 때
    {
        m_comboCount++;
        m_comboTimer = COMBO_RESET_TIME;      // 1.0초
    }

    void UpdateCombo(double dt)
    {
        if (m_comboTimer > 0.0)
        {
            m_comboTimer -= dt;
            if (m_comboTimer <= 0.0) m_comboCount = 0;
        }
    }
};
```

```
   ★ 콤보 리셋 조건

   ① 일정 시간 히트 없음 (1초)
   ② 상대가 경직에서 벗어남
   ③ 라운드 종료

   ★ 콤보 보정 (damage scaling)

   콤보가 길어질수록 데미지를 줄인다
   → 무한 콤보로 한 번에 죽이는 것을 방지

   damage = baseDamage * (1.0 - combo * 0.08)     최소 30%
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 히트스톱이 어색함 | 한쪽만 멈춤 | 양쪽 모두 `ApplyHitStop` |
| 히트스톱 중 애니메이션 계속 | `m_animator.Update(dt)` 호출 | `return`으로 전부 정지 |
| 넉백이 안 멈춤 | 감쇠 없음 | `m_vx -= m_vx * k * dt` |
| 넉백이 즉시 멈춤 | 감쇠가 너무 강함 | 계수 조정 |
| 경직이 안 풀림 | 타이머 비교 오류 | `m_stateTimer >= m_hitStunTime` |
| 셰이크가 멀미남 | 강도 과다 / 감쇠 없음 | 강도를 절반으로, 감쇠 추가 |
| 게이지가 즉시 줄어듦 | 지연 게이지 미구현 | `m_delayedHp` 추가 |
| 가드가 안 먹힘 | 상태 전이 차단 | 전이표의 GUARD 칸 확인 |
| 콤보가 안 리셋 | 타이머 미갱신 | `UpdateCombo` 호출 확인 |
| 무한 콤보 가능 | 콤보 보정 없음 | damage scaling 추가 |
