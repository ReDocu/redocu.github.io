## 1부 · 연결 구조

### 전체 파이프라인

```
   [원본]            [정제]           [분석]           [출력]

data/raw/     →  preprocess.py  →  prepare()   →  ┌─ 표 (CSV)
  API JSON        (Day 060)         점수 계산      ├─ 지도 (HTML)
  크롤링 CSV                        (Day 069)     ├─ 그래프 (PNG)
  지오코딩                                         └─ 요약 (Markdown)
                                        ↑
                                   사용자 조건
```

### 계층을 나누는 이유

```python
src/
├── config.py       설정 (경로·가중치·상수)
├── loader.py       데이터 로드 + 캐시
├── preprocess.py   정제 (Day 060)
├── scoring.py      점수 계산 (Day 069)
├── viz.py          그래프 (Day 061~064)
├── mapping.py      지도 (Day 067~068)
└── recommend.py    이 모든 것을 조립
```

| 계층 | 책임 | 바뀌는 빈도 |
|---|---|---|
| `config` | 상수·경로 | **자주** |
| `loader` | 읽기 | 거의 없음 |
| `preprocess` | 정제 규칙 | 가끔 |
| `scoring` | 점수 로직 | **자주** |
| `viz`/`mapping` | 표현 | 가끔 |
| `recommend` | 조립 | 거의 없음 |

> **자주 바뀌는 것을 한곳에 모으면** 수정이 쉬워집니다.
> 가중치를 바꾸려고 지도 코드를 건드릴 일이 없어야 합니다.

### 캐시 전략

```
[느림] 원본 로드 + 전처리 + 점수 계산   →  한 번만
[빠름] 필터 + 정렬 + 출력               →  질의마다
```

```python
_CACHE = {}

def get_data(force=False):
    """전처리+점수 계산은 한 번만."""
    if "data" not in _CACHE or force:
        raw = load_raw()
        clean, _ = preprocess(raw)

```

> **질의마다 3,000건을 다시 전처리하면 안 됩니다.**
> 무거운 것은 **모듈 로드 시 한 번**, 가벼운 것만 질의마다.

## 2부 · 프로토타입 설계

### 입력 — 하나의 객체로

```python
from dataclasses import dataclass, field

@dataclass
class TravelQuery:
    """사용자 조건."""
    region: str | None = None
    categories: list | None = None
    budget: int | None = None
    origin: tuple | None = None
    max_distance_km: float | None = None
    k: int = 5
    diversity: float = 0.3
    weights: dict = field(default_factory=dict)

    def describe(self):
        parts = []
        if self.region:
            parts.append(self.region)
        if self.categories:
            parts.append("/".join(self.categories))
        if self.budget is not None:
            parts.append(f"{self.budget:,}원 이하")
        if self.max_distance_km:
            parts.append(f"{self.max_distance_km}km 이내")
        return " · ".join(parts) or "조건 없음"
```

> **파라미터가 8개를 넘으면 객체로 묶으세요.**
> 함수 시그니처가 짧아지고, 조건을 저장·재사용하기 쉬워집니다.

### 출력 — 여러 형태를 한 번에

```python
@dataclass
class TravelResult:
    """추천 결과."""
    query: TravelQuery
    items: pd.DataFrame
    table_path: Path | None = None
    map_path: Path | None = None
    chart_path: Path | None = None
    summary: str = ""
    warnings: list = field(default_factory=list)

    @property
    def ok(self):
        return not self.items.empty
```

### 실패를 다루는 법

| 상황 | 대응 |
|---|---|
| 조건에 맞는 결과 0건 | **완화 후 재시도** + 경고 |
| 좌표 없는 항목 | 표에는 넣고 **지도에서만 제외** + 경고 |
| 데이터 파일 없음 | 명확한 에러 메시지 + 해결 방법 |
| 그래프 생성 실패 | 표·지도는 정상 출력 (**부분 실패 허용**) |

> **프로토타입에서 가장 중요한 것은 "죽지 않는 것"** 입니다.
> 발표 중에 예외가 터지면 그 자리에서 끝납니다.
> **부분 실패를 허용**하고 무엇이 실패했는지 알려 주세요.

```python
"""src/loader.py — 데이터 로드와 캐시."""

import numpy as np
import pandas as pd

from config import CACHE_DIR, CATEGORIES, PROCESSED_DIR, REGION_CENTER

_CACHE = {}


def _make_sample_data(n=1200, seed=42):
    """실습용 데이터 생성 (실제로는 processed CSV 를 읽음)."""
    rng = np.random.default_rng(seed)
    regions = list(REGION_CENTER)

    sido = rng.choice(regions, n, p=[.24, .16, .14, .12, .22, .12])

    rows = []
    for i, s in enumerate(sido):
        lat0, lng0 = REGION_CENTER[s]
        spread = 0.5 if s in ("경기도", "경상북도", "강원특별자치도") else 0.15

        cat = rng.choice(CATEGORIES, p=[.30, .24, .20, .14, .12])
        free_p = {"자연": .45, "역사": .25, "체험": .10,
                  "쇼핑": .08, "음식": .12}[cat]

        price = 0.0 if rng.random() < free_p else float(
            rng.lognormal(8.6, 0.62).round(-2))

        rows.append({
            "id": 10000 + i,
            "name": f"{s[:2]}{cat}명소{i:04d}",
            "sido": s,
            "category": cat,
            "price": price,
            "lat": lat0 + rng.normal(0, spread),
            "lng": lng0 + rng.normal(0, spread),
            "visitors": float(rng.lognormal(8.4, 1.3).round()),
            "review_count": int(rng.negative_binomial(2, 0.02)),
        })

    df = pd.DataFrame(rows)
    df["rating"] = np.clip(
        rng.normal(4.0, 0.5, len(df))
        + np.log1p(df["review_count"]) / 60
        + (df["price"] == 0) * 0.12, 1, 5).round(1)

    return df


def load_data(force=False, verbose=True):
    """
    분석용 데이터를 로드합니다. (캐시)

    실제 프로젝트에서는:
        pd.read_parquet(PROCESSED_DIR / "analysis_table.parquet")
    """
    if "raw" in _CACHE and not force:
        return _CACHE["raw"]

    path = PROCESSED_DIR / "analysis_table.parquet"

    if path.exists():
        df = pd.read_parquet(path)
        source = str(path)
    else:
        df = _make_sample_data()
        source = "샘플 생성 (processed 파일 없음)"

    # ── 좌표 검증 ──
    valid = df["lat"].between(33, 39) & df["lng"].between(124, 132)
    dropped = (~valid).sum()
    df = df[valid].reset_index(drop=True)

    _CACHE["raw"] = df

    if verbose:
        print(f"[데이터] {len(df):,}건 · 출처: {source}"
              + (f" · 좌표 무효 {dropped}건 제외" if dropped else ""))

    return df
```

### Step 2. 점수와 추천 계층

```python
"""src/scoring.py — 점수 계산 (Day 069)."""

import numpy as np
import pandas as pd

from config import BAYES_PRIOR, PRICE_BINS, PRICE_LABELS

EARTH_R = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))
    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlng/2)**2
    return 2 * EARTH_R * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


def bayesian_rating(rating, count, m=BAYES_PRIOR):
    C = rating.mean()
    return (count / (count + m)) * rating + (m / (count + m)) * C


def prepare(df, verbose=True):
    """
    전체 기준 점수를 미리 계산합니다. (무거움 — 한 번만)
    """
    out = df.copy()

    out["_adj_rating"] = bayesian_rating(out["rating"], out["review_count"])
    out["_s_rating"] = out["_adj_rating"].rank(pct=True)
    out["_s_popularity"] = np.log1p(out["visitors"]).rank(pct=True)
    out["_pop_pct"] = out["visitors"].rank(pct=True)

    out["price_grade"] = pd.cut(out["price"], bins=PRICE_BINS,
                                labels=PRICE_LABELS)
    out["is_free"] = out["price"] == 0

    if verbose:
        print(f"[점수 준비] {len(out):,}건 · "
              f"평점 보정(m={BAYES_PRIOR}) · 순위 정규화 완료")

    return out
```

```python
"""src/recommend.py — 조립."""

from dataclasses import dataclass, field
from pathlib import Path

import numpy as np
import pandas as pd

from config import (DEFAULT_DIVERSITY, DEFAULT_K, DEFAULT_WEIGHTS,
                    OUTPUT_DIR, RELAX_STEPS)
from scoring import haversine


@dataclass
class TravelQuery:
    """사용자 조건."""
    region: str = None
    categories: list = None
    budget: int = None
    origin: tuple = None
    max_distance_km: float = None
    k: int = DEFAULT_K
    diversity: float = DEFAULT_DIVERSITY
    weights: dict = None
    exclude_popular: bool = False        # 숨은 명소 모드

    def describe(self):
        parts = []
        if self.region:
            parts.append(self.region)
        if self.categories:
            parts.append("/".join(self.categories))
        if self.budget is not None:
            parts.append(f"{self.budget:,}원 이하")
        if self.max_distance_km:
            parts.append(f"{self.max_distance_km:.0f}km 이내")
        if self.exclude_popular:
            parts.append("숨은 명소")
        return " · ".join(parts) or "조건 없음"

    def slug(self):
        import re
        s = self.describe().replace(" · ", "_").replace(" ", "")
        return re.sub(r"[^\w가-힣]", "", s)[:40] or "all"


@dataclass
class TravelResult:
    """추천 결과."""
    query: TravelQuery
    items: pd.DataFrame
    pool_size: int = 0
    relaxations: list = field(default_factory=list)
    warnings: list = field(default_factory=list)
    outputs: dict = field(default_factory=dict)

    @property
    def ok(self):
        return not self.items.empty


def recommend(df, query, verbose=False):
    """조건에 맞는 추천 결과를 반환합니다."""
    weights = query.weights or DEFAULT_WEIGHTS
    total = sum(weights.values())
    weights = {k: v / total for k, v in weights.items()}

    relaxations, warnings_list = [], []

    # ══════════ 필터 ══════════
    def build_pool(budget_mult=1.0, distance_mult=1.0,
                   use_category=True, use_region=True):
        pool = df

        if query.region and use_region:
            pool = pool[pool["sido"] == query.region]

        if query.categories and use_category:
            pool = pool[pool["category"].isin(query.categories)]

        if query.budget is not None:
            pool = pool[pool["price"] <= query.budget * budget_mult]

        if query.exclude_popular:
            pool = pool[pool["_pop_pct"] < 0.7]

        pool = pool.copy()

        if query.origin is not None:
            pool["_distance"] = haversine(query.origin[0], query.origin[1],
                                          pool["lat"], pool["lng"])
            if query.max_distance_km:
                pool = pool[pool["_distance"]
                            <= query.max_distance_km * distance_mult]

        return pool

    pool = build_pool()

    # ══════════ 완화 ══════════
    for kwargs, label in RELAX_STEPS:
        if len(pool) >= query.k:
            break
        wider = build_pool(**kwargs)
        if len(wider) > len(pool):
            pool = wider
            relaxations.append(label)

    if pool.empty:
        warnings_list.append("조건에 맞는 결과가 없습니다")
        return TravelResult(query, pd.DataFrame(), 0, relaxations,
                            warnings_list)

    if relaxations:
        warnings_list.append(f"조건 완화: {', '.join(relaxations)}")

    # ══════════ 점수 (풀 기준 재계산) ══════════
    pool = pool.copy()
    pool["_s_value"] = 1 - pool["price"].rank(pct=True)
    pool["_s_distance"] = (1 - pool["_distance"].rank(pct=True)
                           if "_distance" in pool.columns else 0.5)

    pool["score"] = sum(pool[f"_s_{k}"] * w for k, w in weights.items()
                        if f"_s_{k}" in pool.columns)

    # ══════════ 다양성 (MMR) ══════════
    if query.diversity > 0 and len(pool) > query.k:
        selected, remaining = [], pool.sort_values("score", ascending=False)

        while len(selected) < query.k and len(remaining):
            if not selected:
                pick = remaining.index[0]
            else:
                used = {pool.loc[i, "category"] for i in selected}
                penalty = remaining["category"].isin(used).astype(float)
                pick = ((1 - query.diversity) * remaining["score"]
                        - query.diversity * penalty * 0.3).idxmax()
            selected.append(pick)
            remaining = remaining.drop(pick)

        items = pool.loc[selected].copy()
    else:
        items = pool.nlargest(query.k, "score").copy()

    # ══════════ 이유 생성 ══════════
    LABEL = {"rating": "높은 평점", "popularity": "많은 방문객",
             "value": "좋은 가성비", "distance": "가까운 거리"}

    def reason(row):
        contrib = {k: row.get(f"_s_{k}", 0) * w for k, w in weights.items()}
        top2 = sorted(contrib, key=contrib.get, reverse=True)[:2]
        return " · ".join(
            f"{LABEL.get(k, k)}(상위 {(1-row.get(f'_s_{k}',0))*100:.0f}%)"
            for k in top2)

    items["reason"] = items.apply(reason, axis=1)
    items["rank"] = range(1, len(items) + 1)

    # ══════════ 경고 ══════════
    no_coord = items["lat"].isna().sum()
    if no_coord:
        warnings_list.append(f"좌표 없는 {no_coord}건은 지도에서 제외됩니다")

    if len(items) < query.k:
        warnings_list.append(
            f"요청 {query.k}건 중 {len(items)}건만 찾았습니다")

    if verbose:
        print(f"  후보 {len(pool)}곳 → 추천 {len(items)}곳")

    return TravelResult(query, items, len(pool), relaxations, warnings_list)
```

```python
def make_chart(result, all_data=None, save=True):
    """추천 결과를 그래프로 요약합니다."""
    if not result.ok:
        return None

    items = result.items

    fig, axes = plt.subplots(1, 3, figsize=(16, 4.8), layout="constrained")

    def clean(ax, grid="y"):
        for s in ("top", "right"):
            ax.spines[s].set_visible(False)
        ax.tick_params(length=0)
        ax.grid(True, axis=grid, alpha=0.25, linestyle="--")
        ax.set_axisbelow(True)

    # ── ① 점수 구성 (스택 막대) ──
    ax = axes[0]
    score_cols = [c for c in items.columns if c.startswith("_s_")]
    weights = result.query.weights or {}

    if not weights:
        from config import DEFAULT_WEIGHTS
        weights = DEFAULT_WEIGHTS
    total_w = sum(weights.values())

    labels = items["name"].str[-6:]
    bottom = np.zeros(len(items))

    LABEL_KO = {"rating": "평점", "popularity": "인기",
                "value": "가성비", "distance": "거리"}

    for i, (key, w) in enumerate(weights.items()):
        col = f"_s_{key}"
        if col not in items.columns:
            continue
        contrib = items[col] * w / total_w
        ax.barh(labels, contrib, left=bottom,
                color=OKABE_ITO[i], label=LABEL_KO.get(key, key),
                edgecolor="white", height=0.65)
        bottom += contrib.values

    ax.set_title("① 점수 구성", loc="left", fontweight="bold")
    ax.set_xlabel("점수 기여도")
    ax.legend(fontsize=9, ncol=2, loc="lower right")
    ax.invert_yaxis()
    clean(ax, grid="x")

    # ── ② 후보 대비 위치 ──
    ax = axes[1]

    if all_data is not None:
        pool = all_data
        if result.query.region:
            pool = pool[pool["sido"] == result.query.region]

        ax.scatter(pool["price"], pool["rating"],
                   s=16, alpha=0.2, color="#cbd5e1", label="후보")

    ax.scatter(items["price"], items["rating"],
               s=140, color="#0072B2", edgecolors="white", linewidths=2,
               zorder=5, label="추천")

    for _, r in items.iterrows():
        ax.annotate(f"{r['rank']}", (r["price"], r["rating"]),
                    color="white", fontsize=9, fontweight="bold",
                    ha="center", va="center", zorder=6)

    ax.set_title("② 후보 대비 위치", loc="left", fontweight="bold")
    ax.set_xlabel("입장료 (원)")
    ax.set_ylabel("평점 (점)")
    ax.xaxis.set_major_formatter(mpl.ticker.FuncFormatter(_compact))
    ax.legend(fontsize=9)
    clean(ax)

    # ── ③ 카테고리 구성 ──
    ax = axes[2]
    counts = items["category"].value_counts()
    colors = [CATEGORY_STYLE.get(c, {}).get("color", "#8c8c8c")
              for c in counts.index]

    bars = ax.bar(counts.index, counts.values, color=colors,
                  edgecolor="white", width=0.6)
    for bar, v in zip(bars, counts.values):
        ax.text(bar.get_x() + bar.get_width()/2, v + 0.06, str(v),
                ha="center", fontsize=10)

    diversity = counts.nunique() / len(items)
    ax.set_title(f"③ 카테고리 구성 (다양성 {diversity:.2f})",
                 loc="left", fontweight="bold")
    ax.set_ylabel("개수")
    ax.set_ylim(0, counts.max() + 0.8)
    clean(ax)

    fig.suptitle(f"추천 결과 — {result.query.describe()}",
                 fontsize=15, fontweight="bold")

    fig.text(0.99, 0.01,
             f"후보 {result.pool_size:,}곳 · 추천 {len(items)}곳",
             ha="right", fontsize=9, color="#94a3b8")

    if save:
        path = OUTPUT_DIR / f"chart_{result.query.slug()}.png"
        fig.savefig(path, dpi=FIG_DPI, bbox_inches="tight",
                    facecolor="white")
        result.outputs["chart"] = path

    plt.close(fig)
    return fig

def make_summary(result):
    """결과를 텍스트로 요약합니다."""
    if not result.ok:
        return f"조건 '{result.query.describe()}' 에 맞는 결과가 없습니다."

    items = result.items

    lines = [
        f"■ 조건: {result.query.describe()}",
        f"■ 후보 {result.pool_size:,}곳 → 추천 {len(items)}곳",
        "",
    ]

    for _, r in items.iterrows():
        dist = (f" · {r['_distance']:.1f}km" if "_distance" in r.index else "")
        lines.append(
            f"  {r['rank']}. {r['name']} ({r['category']}) "
            f"— {_fmt_price(r['price'])} · {r['rating']}점{dist}")
        lines.append(f"     💡 {r['reason']}")

    lines += [
        "",
        f"■ 요약",
        f"  평균 평점 {items['rating'].mean():.2f} · "
        f"평균 가격 {items['price'].mean():,.0f}원 · "
        f"무료 {int((items['price'] == 0).sum())}곳",
        f"  카테고리 {items['category'].nunique()}종 "
        f"(다양성 {items['category'].nunique()/len(items):.2f})",
    ]

    if "_distance" in items.columns:
        lines.append(f"  평균 거리 {items['_distance'].mean():.1f}km "
                     f"(최근접 {items['_distance'].min():.1f}km)")

    if result.warnings:
        lines += ["", "■ 알림"]
        lines += [f"  ⚠ {w}" for w in result.warnings]

    return "\n".join(lines)
```

> - **②번 그래프의 회색 점** — 추천이 후보 중 어느 위치인지 보여 줍니다.

## ⑤ 자주 하는 실수

### 질의마다 전처리를 다시

3,000건 전처리가 매번 돌아 응답이 10초씩 걸립니다.

**해결** — 모듈 수준 캐시(`get_data()`)

### 모든 로직을 노트북에

셀 순서가 바뀌면 결과가 달라지고, 재사용도 안 됩니다.

**해결** — `src/` 모듈로 분리하고 노트북은 **호출만**

### 설정이 코드 곳곳에 흩어짐

가중치를 바꾸려면 3개 파일을 고쳐야 합니다.

**해결** — `config.py` 한곳에

### 예외 하나로 전체 중단

지도 생성 실패로 표까지 못 봅니다.

**해결** — `try/except` 로 감싸고 경고에 기록

### 결과 0건에 대한 안내 없음

**해결** — 완화 전략 + 완화 사실 표시

### 좌표 없는 항목을 지도에 넣으려 함

**해결** — 표에는 포함, 지도에서만 제외 + 경고

### 출력 파일이 서로 덮어씀

**해결** — 조건 기반 파일명(`slug()`)

### 지도에 조건이 안 적혀 있음

지도 HTML 만 전달받으면 무슨 조건인지 모릅니다.

**해결** — 조건 배너를 지도에 삽입

### 추천 이유가 없음

**해결** — 기여도 상위 지표를 문장으로 ([Day 069](day-069.md))

### 한계를 안 밝힘

**해결** — 노트북 마지막에 한계 절을 둡니다.

### `Restart & Run All` 을 안 해 봄

발표 당일 처음부터 실행하면 에러가 납니다.

**해결** — 제출 전 반드시 한 번

### 실행에 10분 이상

**해결** — 캐시·샘플링으로 5분 이내로 줄입니다.

| ⑤ | 실행 예시 3종 이상 | 다양한 조건에서 작동함을 증명 |
| ⑥ | **품질 검증 표** | 주관이 아닌 숫자로 |
| ⑦ | **한계 + 다음 단계** | 과신 방지 · 발전 방향 |

> **⑦번이 심사에서 점수를 가릅니다.**
> "완벽합니다"보다 **"이런 한계가 있고 이렇게 해결하겠습니다"** 가
> 훨씬 신뢰를 얻습니다.
</details>

```python
"""프로토타입 통합 점검."""

import time
import traceback
from pathlib import Path

import numpy as np
import pandas as pd


def smoke_test(travel_recommend_fn, get_data_fn, verbose=True):
    """
    프로토타입이 다양한 조건에서 죽지 않는지 확인합니다.

    반환: dict(passed, failed, results)
    """
    results = []
    line = "=" * 82

    if verbose:
        print(line)
        print("                      프로토타입 통합 점검")
        print(line)

    # ══════════ ① 데이터 준비 ══════════
    t0 = time.perf_counter()
    try:
        df = get_data_fn()
        load_time = time.perf_counter() - t0
        data_ok = True
    except Exception as e:
        if verbose:
            print(f"\n🔴 데이터 로드 실패: {type(e).__name__}: {e}")
            print(line)
        return {"passed": 0, "failed": 1, "results": []}

    if verbose:
        print(f"\n[① 데이터]")
        print(f"  {len(df):,}행 × {df.shape[1]}열 · 로드 {load_time:.1f}초")

    required = ["id", "name", "sido", "category", "price",
                "rating", "lat", "lng", "_s_rating", "_s_popularity"]
    missing = [c for c in required if c not in df.columns]

    if missing:
        if verbose:
            print(f"  🔴 필수 열 누락: {missing}")
        data_ok = False
    elif verbose:
        print(f"  ✓ 필수 열 모두 존재")

    # ══════════ ② 케이스 정의 ══════════
    regions = df["sido"].unique().tolist()
    cats = df["category"].unique().tolist()

    CASES = [
        ("정상 — 지역+예산", dict(region=regions[0], budget=50000)),
        ("정상 — 지역+카테고리+거리",
         dict(region=regions[0], categories=[cats[0]], budget=30000,
              origin=(35.18, 129.08), max_distance_km=30)),
        ("정상 — 전국", dict(budget=100000, k=10)),
        ("경계 — 예산 0원", dict(region=regions[0], budget=0)),
        ("경계 — k=1", dict(region=regions[0], budget=50000, k=1)),
        ("경계 — k=100", dict(region=regions[0], budget=50000, k=100)),
        ("경계 — 거리 1km", dict(region=regions[0], budget=50000,
                                origin=(35.18, 129.08), max_distance_km=1)),
        ("경계 — 다양성 0", dict(region=regions[0], budget=50000,
                                diversity=0.0)),
        ("경계 — 다양성 1", dict(region=regions[0], budget=50000,
                                diversity=1.0)),
        ("예외 — 없는 지역", dict(region="존재하지않는도", budget=50000)),
        ("예외 — 없는 카테고리", dict(categories=["존재하지않음"],
                                     budget=50000)),
        ("예외 — 음수 예산", dict(region=regions[0], budget=-1000)),
        ("예외 — 조건 없음", dict()),
        ("옵션 — 숨은 명소", dict(region=regions[0], budget=50000,
                                 exclude_popular=True)),
        ("옵션 — 가중치 지정",
         dict(region=regions[0], budget=50000,
              weights={"rating": 1.0, "popularity": 0, "value": 0,
                       "distance": 0})),
    ]

    if verbose:
        print(f"\n[② 케이스 {len(CASES)}종]")
        print(f"  {'케이스':<28}{'결과':>7}{'시간':>8}{'경고':>6}  비고")
        print("  " + "-" * 70)

    # ══════════ ③ 실행 ══════════
    for label, params in CASES:
        t = time.perf_counter()
        record = {"케이스": label, "성공": False, "건수": 0,
                  "시간": 0.0, "경고": 0, "비고": ""}

        try:
            r = travel_recommend_fn(**params, make_outputs=False,
                                    verbose=False)
            elapsed = time.perf_counter() - t

            record.update({
                "성공": True,
                "건수": len(r.items),
                "시간": elapsed,
                "경고": len(r.warnings),
            })

            # ── 결과 검증 ──
            problems = []

            if r.ok:
                k_req = params.get("k", 5)

                if len(r.items) > k_req:
                    problems.append(f"k={k_req} 인데 {len(r.items)}건 반환")

                if "score" in r.items.columns:
                    if not r.items["score"].between(0, 1.001).all():
                        problems.append("점수가 0~1 범위 밖")
                    if not r.items["score"].is_monotonic_decreasing:
                        problems.append("점수 내림차순 아님")

                if "rank" in r.items.columns:
                    if list(r.items["rank"]) != list(
                            range(1, len(r.items) + 1)):
                        problems.append("rank 가 1..n 이 아님")

                if r.items["id"].duplicated().any():
                    problems.append("중복 항목 포함")

                # 조건 위반 확인 (완화가 없었다면)
                if not r.relaxations:
                    if params.get("region") and \
                            (r.items["sido"] != params["region"]).any():
                        problems.append("지역 조건 위반")
                    if params.get("budget") is not None and \
                            params["budget"] >= 0 and \
                            (r.items["price"] > params["budget"]).any():
                        problems.append("예산 조건 위반")

            record["비고"] = " / ".join(problems) if problems else ""

            if elapsed > 5:
                record["비고"] += f" (느림 {elapsed:.1f}초)"

        except Exception as e:
            record["시간"] = time.perf_counter() - t
            record["비고"] = f"{type(e).__name__}: {str(e)[:40]}"

        results.append(record)

        if verbose:
            mark = ("✓" if record["성공"] and not record["비고"]
                    else "△" if record["성공"] else "✗")
            print(f"  {label:<28}{mark + ' ' + str(record['건수']):>7}"
                  f"{record['시간']:>7.2f}s{record['경고']:>6}  "
                  f"{record['비고'][:26]}")

    # ══════════ ④ 출력 파일 생성 ══════════
    if verbose:
        print(f"\n[③ 출력 파일]")

    t = time.perf_counter()
    output_ok = True

    try:
        r = travel_recommend_fn(region=regions[0], budget=50000,
                                origin=(35.18, 129.08), max_distance_km=30,
                                make_outputs=True, verbose=False)
        gen_time = time.perf_counter() - t

        for kind, path in r.outputs.items():
            exists = Path(path).exists()
            size = Path(path).stat().st_size / 1024 if exists else 0

            if verbose:
                print(f"  {'✓' if exists else '✗'} {kind:<8}"
                      f"{size:>9,.0f} KB  {Path(path).name[:40]}")

            if not exists:
                output_ok = False

            if kind == "map" and size > 3000:
                if verbose:
                    print(f"      ⚠ 지도가 {size/1024:.1f}MB — 공유 어려움")

        if verbose:
            print(f"  생성 시간: {gen_time:.1f}초")

        if gen_time > 10:
            output_ok = False
            if verbose:
                print(f"  ⚠ 출력 생성이 {gen_time:.0f}초 — 발표에 부담")

    except Exception as e:
        output_ok = False
        if verbose:
            print(f"  🔴 출력 생성 실패: {type(e).__name__}: {e}")
            traceback.print_exc(limit=2)

    # ══════════ 결과 ══════════
    passed = sum(1 for r in results if r["성공"] and not r["비고"])
    partial = sum(1 for r in results if r["성공"] and r["비고"])
    failed = sum(1 for r in results if not r["성공"])

    avg_time = np.mean([r["시간"] for r in results])
    max_time = max(r["시간"] for r in results)

    score = (passed * 100 + partial * 60) / len(results)
    if not data_ok:
        score *= 0.5
    if not output_ok:
        score *= 0.7

    if verbose:
        print(f"\n{line}")
        print(f"  통과 {passed} · 부분 {partial} · 실패 {failed} "
              f"/ 전체 {len(results)}")
        print(f"  평균 응답 {avg_time:.2f}초 · 최대 {max_time:.2f}초")

        grade = ("✅ 발표 가능" if score >= 85
                 else "🟡 보완 필요" if score >= 65 else "❌ 재작업")
        print(f"  종합: {score:.0f}점 / 100   {grade}")
        print(line)

        if failed or partial:
            print(f"\n  [수정이 필요한 케이스]")
            for r in results:
                if not r["성공"] or r["비고"]:
                    icon = "🔴" if not r["성공"] else "🟡"
                    print(f"  {icon} {r['케이스']}: {r['비고']}")

        print(f"\n  [발표 전 체크리스트]")
        for item in [
            "Restart & Run All 이 통과하는가",
            "생성된 지도 HTML 을 브라우저에서 열어 봤는가",
            "그래프의 한글이 깨지지 않는가",
            "예외 케이스에서도 안내 메시지가 나오는가",
            "실행 시간이 발표 중 기다릴 만한가 (5초 이내)",
            "한계를 문서에 적었는가",
        ]:
            print(f"    □ {item}")

        print(line)

    return {"passed": passed, "partial": partial, "failed": failed,
            "score": score, "results": pd.DataFrame(results)}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    from main import get_data, travel_recommend
    smoke_test(travel_recommend, get_data)
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 프로토타입 | **작동 증명**이 목적. 완제품 아님 |
| 계층 분리 | `config` / `loader` / `scoring` / `output` / `main` |
| **캐시** | 무거운 것(전처리·점수)은 **한 번만** |
| 입력 | 파라미터 8개 넘으면 **데이터클래스** |
| 출력 | 표(CSV) + **지도(HTML)** + 그래프(PNG) + 요약 |
| **부분 실패 허용** | 지도가 실패해도 표는 나오게 |
| 파일명 | 조건 기반 `slug()` 로 구분 |
| 지도 | **조건 배너** + 순위 마커 + 추천 이유 |
| 그래프 | **점수 구성** + 후보 대비 위치 + 다양성 |
| 노트북 | **사용법을 맨 위에** · 셀마다 해석 |
| 검증 | 정상·경계·예외 15종 + **결과 무결성** |
| 마무리 | **한계 + 다음 단계** |

**오늘 반드시 기억할 세 가지**
> ① **무거운 계산은 한 번만.** 질의마다 전처리하면 프로토타입이 아니라 배치 작업입니다.
> ② **죽지 않게 만드세요.** 발표 중 예외가 터지면 그 자리에서 끝입니다.
> ③ **한계를 먼저 밝히세요.** "완벽합니다"보다 신뢰를 얻습니다.
