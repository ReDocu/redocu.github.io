## ② 왜 필요한가

**분석 질문은 대부분 조건으로 표현됩니다.**

```
"서울 지역 데이터만"
"평점 4.0 이상이면서 리뷰가 100건 넘는 곳"
"이름에 '카페'가 들어간 상호"
"결측치가 있는 행만"
"2026년 상반기 데이터"
```

[Day 044](day-044.md)의 numpy 마스킹과 원리가 같지만, pandas 는 **열 이름으로 조건을 쓸 수 있어** 훨씬 읽기 좋습니다.

```python
# numpy
data[(data[:, SCORE] >= 80) & (data[:, STAGE] == 5)]

# pandas
df[(df["score"] >= 80) & (df["stage"] == 5)]
```

그리고 **`SettingWithCopyWarning`** 은 pandas 입문자가 가장 많이 만나는 경고입니다.
오늘 원인을 이해하면 앞으로 헤매지 않습니다.

## ③ 개념 설명

### 불리언 인덱싱

```python
df[df["score"] >= 80]
```

**동작 원리**

```
df["score"] >= 80    →    [True, True, False, True, ...]     불리언 Series
df[불리언 Series]     →    True 인 행만 남김
```

```python
mask = df["score"] >= 80
print(type(mask))      # Series
print(mask.dtype)      # bool
df[mask]               # 필터링
```

> **마스크를 변수로 빼면 재사용할 수 있고 읽기도 좋습니다.**
> ```python
> is_high = df["score"] >= 80
> is_seoul = df["region"] == "서울"
> df[is_high & is_seoul]
> ```

### 여러 조건 결합

```python
df[(df["score"] >= 80) & (df["stage"] == 5)]       # AND
df[(df["score"] >= 90) | (df["kills"] >= 150)]     # OR
df[~(df["region"] == "서울")]                       # NOT
```

> ⚠️ **`and` / `or` / `not` 을 쓰면 안 됩니다.**
> ```
> ValueError: The truth value of a Series is ambiguous.
> Use a.empty, a.bool(), a.item(), a.any() or a.all().
> ```

> ⚠️ **괄호를 반드시 치세요.** `&` 가 `>=` 보다 우선순위가 높습니다.

### 유용한 조건 함수

```python
df[df["region"].isin(["서울", "부산"])]           # 목록에 포함
df[~df["region"].isin(["서울"])]                  # 제외
df[df["score"].between(70, 90)]                   # 범위 (양끝 포함)
df[df["score"].between(70, 90, inclusive="left")] # 70 이상 90 미만
df[df["name"].str.contains("카페")]               # 문자열 포함
df[df["name"].str.startswith("스타")]             # 시작
df[df["name"].str.endswith("점")]                 # 끝
df[df["score"].isna()]                            # 결측인 행
df[df["score"].notna()]                           # 결측 아닌 행
```

| 함수 | 대체 표현 | 장점 |
|---|---|---|
| `isin([a, b, c])` | `(x==a)\|(x==b)\|(x==c)` | 짧고 빠름 |
| `between(a, b)` | `(x>=a) & (x<=b)` | 읽기 쉬움 |
| `str.contains()` | — | 부분 문자열 |
| `isna()` / `notna()` | — | 결측 처리 |

> ⚠️ **`str.contains()` 는 결측이 있으면 에러**가 납니다.
> ```python
> df[df["name"].str.contains("카페", na=False)]      # 결측은 False 로
> ```

### query() — SQL 처럼 쓰기

```python
df.query("score >= 80 and stage == 5")
df.query("score >= 80 & stage == 5")               # 둘 다 됨
df.query("region in ['서울', '부산']")
df.query("score >= @threshold")                     # 변수는 @
```

| | 불리언 인덱싱 | `query()` |
|---|---|---|
| 가독성 | 괄호가 많음 | **문장처럼 읽힘** |
| `and`/`or` | ❌ | ✅ 사용 가능 |
| 열 이름에 공백 | OK | 백틱 필요 (`` `열 이름` ``) |
| 속도 | 빠름 | 대용량에서 유리 |
| 외부 변수 | 그대로 | **`@변수`** |

> **조건이 3개를 넘으면 `query()` 가 읽기 좋습니다.**
> ```python
> df.query("score >= 80 and stage >= 3 and region == '서울' and kills > 100")
> ```

### 정렬

```python
df.sort_values("score")                             # 오름차순
df.sort_values("score", ascending=False)            # 내림차순
df.sort_values(["stage", "score"], ascending=[True, False])   # 다중 키
df.sort_values("score", na_position="first")        # 결측을 앞으로
df.sort_index()                                      # 인덱스로 정렬
```

**상위·하위 n개**

```python
df.nlargest(10, "score")                # 상위 10개 (더 빠름)
df.nsmallest(5, "score")                # 하위 5개
df.sort_values("score", ascending=False).head(10)    # 같은 결과
```

> **`nlargest` 가 빠른 이유** — 전체를 정렬하지 않고 상위 n개만 찾습니다.

**순위 매기기**

```python
df["rank"] = df["score"].rank(ascending=False)              # 평균 순위
df["rank"] = df["score"].rank(ascending=False, method="min")  # 공동 순위
```

| `method` | 동점 처리 | 예 (100, 90, 90, 80) |
|---|---|---|
| `average` (기본) | 평균 | 1, 2.5, 2.5, 4 |
| `min` | 최소 | 1, 2, 2, 4 |
| `max` | 최대 | 1, 3, 3, 4 |
| `dense` | 건너뛰지 않음 | 1, 2, 2, 3 |
| `first` | 나온 순서 | 1, 2, 3, 4 |

### SettingWithCopyWarning — 오늘의 핵심

```python
subset = df[df["score"] > 80]
subset["grade"] = "A"
```

```
SettingWithCopyWarning:
A value is trying to be set on a copy of a slice from a DataFrame.
Try using .loc[row_indexer,col_indexer] = value instead
```

**원인** — `df[조건]` 의 결과가 **복사본인지 뷰인지 pandas 도 확신할 수 없습니다.**
복사본이면 원본이 안 바뀌고, 뷰면 바뀝니다. **어느 쪽인지 보장되지 않으므로 경고**합니다.

**해결 3가지**

```python
# ① 명시적 복사 — 원본과 분리하고 싶을 때
subset = df[df["score"] > 80].copy()
subset["grade"] = "A"

# ② loc 으로 한 번에 — 원본을 수정하고 싶을 때
df.loc[df["score"] > 80, "grade"] = "A"

# ③ 체인 인덱싱 금지
df[df["score"] > 80]["grade"] = "A"        # ❌ 반영조차 안 됨
```

**판단 기준**

| 하고 싶은 일 | 방법 |
|---|---|
| 원본을 수정 | `df.loc[조건, "열"] = 값` |
| 별도 데이터로 작업 | `subset = df[조건].copy()` |

> **③번이 가장 위험합니다.** 경고만 나오고 **값이 반영되지 않습니다.**
> 에러가 아니라 조용히 실패하므로 발견이 늦습니다.

### 조건부 값 대입

```python
# 단일 조건
df.loc[df["score"] >= 90, "grade"] = "A"

# 여러 조건 — 순서대로 덮어씀
df.loc[df["score"] >= 60, "grade"] = "D"
df.loc[df["score"] >= 70, "grade"] = "C"
df.loc[df["score"] >= 80, "grade"] = "B"
df.loc[df["score"] >= 90, "grade"] = "A"

# np.select 로 한 번에 (권장)
import numpy as np
df["grade"] = np.select(
    [df["score"] >= 90, df["score"] >= 80, df["score"] >= 70, df["score"] >= 60],
    ["A", "B", "C", "D"],
    default="F",
)

# np.where — 2분기
df["pass"] = np.where(df["score"] >= 60, "합격", "불합격")
```

### Step 1. 기본 필터링

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 200

df = pd.DataFrame({
    "id": np.arange(1, n + 1),
    "name": [f"장소{i}" for i in range(1, n + 1)],
    "category": rng.choice(["카페", "음식점", "관광지", "숙박"], n,
                           p=[.3, .35, .25, .1]),
    "region": rng.choice(["서울", "부산", "제주", "강원"], n,
                         p=[.4, .25, .2, .15]),
    "rating": rng.normal(4.0, 0.6, n).clip(1.0, 5.0).round(1),
    "reviews": rng.integers(0, 2000, n),
    "price": rng.integers(5000, 80000, n),
})

print("=" * 68)
print("                  조건 필터링")
print("=" * 68)
print(f"\n전체 {len(df)}건")

# ── 단일 조건 ──
print(f"\n[단일 조건]")
cases = [
    ("평점 4.5 이상",       df["rating"] >= 4.5),
    ("리뷰 1000건 초과",     df["reviews"] > 1000),
    ("서울",                df["region"] == "서울"),
    ("카페가 아님",          df["category"] != "카페"),
]
for label, mask in cases:
    print(f"  {label:<20}{mask.sum():>4}건 ({mask.mean()*100:>5.1f}%)")

# ── 조건 결합 ──
print(f"\n[조건 결합]")
combos = [
    ("평점 4.5+ AND 리뷰 500+",
     (df["rating"] >= 4.5) & (df["reviews"] >= 500)),
    ("서울 OR 부산",
     (df["region"] == "서울") | (df["region"] == "부산")),
    ("서울 아님 (NOT)",
     ~(df["region"] == "서울")),
    ("카페 AND 서울 AND 평점 4.0+",
     (df["category"] == "카페") & (df["region"] == "서울") & (df["rating"] >= 4.0)),
]
for label, mask in combos:
    print(f"  {label:<32}{mask.sum():>4}건")

# ── 편의 함수 ──
print(f"\n[편의 함수]")
funcs = [
    ("isin(['서울','제주'])",   df["region"].isin(["서울", "제주"])),
    ("between(4.0, 4.5)",      df["rating"].between(4.0, 4.5)),
    ("between left only",      df["rating"].between(4.0, 4.5, inclusive="left")),
    ("name.str.contains('1')", df["name"].str.contains("1", na=False)),
    ("price 3만원 이하",         df["price"] <= 30000),
]
for label, mask in funcs:
    print(f"  {label:<28}{mask.sum():>4}건")

# ── query() 비교 ──
print(f"\n[불리언 인덱싱 vs query()]")

r1 = df[(df["rating"] >= 4.0) & (df["reviews"] >= 500) & (df["region"] == "서울")]
r2 = df.query("rating >= 4.0 and reviews >= 500 and region == '서울'")

print(f"  불리언: df[(df['rating']>=4.0) & (df['reviews']>=500) & ...]")
print(f"  query : df.query(\"rating >= 4.0 and reviews >= 500 and region == '서울'\")")
print(f"  결과 같은가? {r1.equals(r2)}   ({len(r1)}건)")

# 외부 변수 사용
min_rating = 4.3
r3 = df.query("rating >= @min_rating")
print(f"\n  변수 사용: df.query('rating >= @min_rating')  → {len(r3)}건")

print("\n" + "=" * 68)
```

### Step 2. 정렬과 순위

```python
import pandas as pd

# (위 df 를 그대로 사용)

print("=" * 72)
print("                     정렬과 순위")
print("=" * 72)

# ── 단일 정렬 ──
print(f"\n[평점 상위 5개]")
print(df.sort_values("rating", ascending=False)
        .head(5)[["name", "category", "region", "rating", "reviews"]]
        .to_string(index=False))

# ── 다중 키 정렬 ──
print(f"\n[지역 오름차순, 평점 내림차순]")
print(df.sort_values(["region", "rating"], ascending=[True, False])
        .groupby("region").head(2)[["region", "name", "rating"]]
        .to_string(index=False))

# ── nlargest ──
print(f"\n[nlargest — 리뷰 상위 5개]")
print(df.nlargest(5, "reviews")[["name", "reviews", "rating"]]
        .to_string(index=False))

# ── 순위 매기기 ──
ranked = df.copy()
ranked["rank_avg"] = ranked["rating"].rank(ascending=False, method="average")
ranked["rank_min"] = ranked["rating"].rank(ascending=False, method="min")
ranked["rank_dense"] = ranked["rating"].rank(ascending=False, method="dense")

top = ranked.nlargest(8, "rating")[
    ["name", "rating", "rank_avg", "rank_min", "rank_dense"]]

print(f"\n[순위 method 비교 — 동점 처리]")
print(top.to_string(index=False))
print(f"""
  average : 동점끼리 평균 순위 (1, 2.5, 2.5, 4)
  min     : 동점 중 가장 높은 순위 (1, 2, 2, 4)  ← 스포츠 방식
  dense   : 순위를 건너뛰지 않음 (1, 2, 2, 3)
""")

# ── 그룹별 상위 ──
print(f"[카테고리별 평점 1위]")
best = (df.sort_values("rating", ascending=False)
          .groupby("category")
          .head(1)[["category", "name", "region", "rating"]]
          .sort_values("rating", ascending=False))
print(best.to_string(index=False))

print("=" * 72)
```

### Step 3. SettingWithCopyWarning 완전 이해

```python
import warnings

import pandas as pd

df = pd.DataFrame({
    "name": ["A", "B", "C", "D", "E"],
    "score": [95, 82, 71, 88, 64],
})

print("=" * 66)
print("           SettingWithCopyWarning")
print("=" * 66)

# ══════════ ❌ 방법 1: 체인 인덱싱 — 값이 반영조차 안 됨 ══════════
print(f"\n[❌ 체인 인덱싱]")
test1 = df.copy()

with warnings.catch_warnings(record=True) as w:
    warnings.simplefilter("always")
    test1[test1["score"] >= 80]["grade"] = "A"
    if w:
        print(f"  경고: {w[0].category.__name__}")

print(f"  'grade' 열이 생겼는가? {'grade' in test1.columns}")
print(f"  → 경고만 나오고 아무 일도 일어나지 않았습니다!")

# ══════════ ❌ 방법 2: 필터링 후 대입 — 경고 발생 ══════════
print(f"\n[❌ 필터링 결과에 바로 대입]")
test2 = df.copy()

with warnings.catch_warnings(record=True) as w:
    warnings.simplefilter("always")
    subset = test2[test2["score"] >= 80]
    subset["grade"] = "A"
    if w:
        print(f"  경고: {w[0].category.__name__}")

print(f"  subset 에는 grade 가 있는가? {'grade' in subset.columns}")
print(f"  원본에는? {'grade' in test2.columns}")
print(f"  → 동작은 했지만 pandas 가 확신할 수 없어 경고합니다")

# ══════════ ✅ 해결 1: .copy() — 별도 데이터로 작업 ══════════
print(f"\n[✅ .copy() — 원본과 분리]")
test3 = df.copy()

subset = test3[test3["score"] >= 80].copy()
subset["grade"] = "A"

print(f"  subset:")
print(subset.to_string(index=False))
print(f"  원본에 grade 가 생겼는가? {'grade' in test3.columns}  ← 분리됨")

# ══════════ ✅ 해결 2: loc — 원본을 수정 ══════════
print(f"\n[✅ .loc — 원본을 직접 수정]")
test4 = df.copy()

test4.loc[test4["score"] >= 80, "grade"] = "A"
test4.loc[test4["score"] < 80, "grade"] = "B"

print(test4.to_string(index=False))

# ══════════ 실전 패턴 ══════════
print(f"\n{'=' * 66}")
print("[실전 패턴]")
print("=" * 66)

data = df.copy()

# ① 여러 조건을 순서대로 (뒤에 오는 것이 덮어씀)
data.loc[data["score"] >= 0, "grade"] = "F"
data.loc[data["score"] >= 70, "grade"] = "C"
data.loc[data["score"] >= 80, "grade"] = "B"
data.loc[data["score"] >= 90, "grade"] = "A"

print(f"\n① loc 순차 대입")
print(data.to_string(index=False))

# ② np.select 로 한 번에 (권장)
import numpy as np

data2 = df.copy()
data2["grade"] = np.select(
    [data2["score"] >= 90, data2["score"] >= 80, data2["score"] >= 70],
    ["A", "B", "C"],
    default="F",
)
print(f"\n② np.select")
print(data2.to_string(index=False))
print(f"   같은 결과? {data['grade'].equals(data2['grade'])}")

# ③ 필터링해서 별도 분석
high = df[df["score"] >= 80].copy()
high["bonus"] = high["score"] * 0.1
high = high.reset_index(drop=True)

print(f"\n③ 필터링 → 복사 → 가공 → 인덱스 정리")
print(high.to_string(index=False))

print("\n" + "=" * 66)
print("규칙:")
print("  원본 수정      → df.loc[조건, '열'] = 값")
print("  별도 데이터    → subset = df[조건].copy()")
print("  절대 금지      → df[조건]['열'] = 값")
print("=" * 66)
```

### Step 4. 여행지 데이터 조건 검색 (오늘의 종합 예제)

W15 프로젝트(여행지 추천)의 예고편입니다.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 500

CATEGORIES = ["카페", "음식점", "관광지", "숙박", "체험"]
REGIONS = ["서울", "부산", "제주", "강원", "경주"]

df = pd.DataFrame({
    "id": np.arange(1, n + 1),
    "name": [f"{rng.choice(REGIONS)}{rng.choice(CATEGORIES)}{i}"
             for i in range(1, n + 1)],
    "category": rng.choice(CATEGORIES, n, p=[.25, .3, .2, .15, .1]),
    "region": rng.choice(REGIONS, n, p=[.3, .2, .25, .15, .1]),
    "rating": rng.normal(4.0, 0.55, n).clip(1.0, 5.0).round(1),
    "reviews": rng.integers(0, 3000, n),
    "price": rng.integers(0, 100000, n),
    "open_hour": rng.integers(6, 12, n),
    "close_hour": rng.integers(18, 24, n),
})

# 결측 넣기
df.loc[rng.choice(n, 30, replace=False), "price"] = np.nan

print("=" * 78)
print("                    여행지 조건 검색")
print("=" * 78)
print(f"\n전체 {len(df)}건 · 결측 {df['price'].isna().sum()}건(price)")


def search(df, region=None, category=None, min_rating=None,
           min_reviews=None, max_price=None, open_before=None):
    """
    조건에 맞는 여행지를 검색합니다.
    None 인 조건은 무시합니다.
    """
    mask = pd.Series(True, index=df.index)          # 전부 True 로 시작
    applied = []

    if region:
        regions = [region] if isinstance(region, str) else region
        mask &= df["region"].isin(regions)
        applied.append(f"지역={regions}")

    if category:
        cats = [category] if isinstance(category, str) else category
        mask &= df["category"].isin(cats)
        applied.append(f"분류={cats}")

    if min_rating is not None:
        mask &= df["rating"] >= min_rating
        applied.append(f"평점≥{min_rating}")

    if min_reviews is not None:
        mask &= df["reviews"] >= min_reviews
        applied.append(f"리뷰≥{min_reviews}")

    if max_price is not None:
        # 결측은 제외 (가격 정보가 없으면 조건 판단 불가)
        mask &= df["price"].notna() & (df["price"] <= max_price)
        applied.append(f"가격≤{max_price:,}")

    if open_before is not None:
        mask &= df["open_hour"] <= open_before
        applied.append(f"{open_before}시 이전 오픈")

    result = df[mask].copy().reset_index(drop=True)

    print(f"\n  조건: {' AND '.join(applied) if applied else '(없음)'}")
    print(f"  결과: {len(result)}건 ({len(result)/len(df)*100:.1f}%)")

    return result


# ══════════ 검색 시나리오 ══════════
print(f"\n{'─' * 78}")
print("[시나리오 1] 제주도 고평점 카페")
r1 = search(df, region="제주", category="카페", min_rating=4.3)
if len(r1):
    print(r1.nlargest(5, "rating")[
        ["name", "rating", "reviews", "price"]].to_string(index=False))

print(f"\n{'─' * 78}")
print("[시나리오 2] 서울·부산의 인기 음식점 (리뷰 1000+)")
r2 = search(df, region=["서울", "부산"], category="음식점", min_reviews=1000)
if len(r2):
    print(r2.nlargest(5, "reviews")[
        ["name", "region", "rating", "reviews"]].to_string(index=False))

print(f"\n{'─' * 78}")
print("[시나리오 3] 3만원 이하 · 평점 4.0+ · 오전 9시 이전 오픈")
r3 = search(df, min_rating=4.0, max_price=30000, open_before=9)
if len(r3):
    print(r3.nlargest(5, "rating")[
        ["name", "category", "region", "rating", "price"]].to_string(index=False))

# ══════════ query() 버전 ══════════
print(f"\n{'=' * 78}")
print("[query() 로 같은 검색]")
print("=" * 78)

min_rating, max_price = 4.0, 30000
q = df.query(
    "rating >= @min_rating and price <= @max_price and open_hour <= 9"
).reset_index(drop=True)

print(f"\n  df.query('rating >= @min_rating and price <= @max_price and open_hour <= 9')")
print(f"  → {len(q)}건")
print(f"  search() 결과와 같은가? {len(q) == len(r3)}")
print(f"  ※ query 는 결측을 자동으로 제외합니다 (NaN <= 30000 은 False)")

# ══════════ 조건별 통계 ══════════
print(f"\n{'=' * 78}")
print("[조건별 요약]")
print("=" * 78)

conditions = {
    "전체":            pd.Series(True, index=df.index),
    "평점 4.5+":       df["rating"] >= 4.5,
    "리뷰 2000+":      df["reviews"] >= 2000,
    "무료 (0원)":       df["price"] == 0,
    "제주":            df["region"] == "제주",
    "24시간 근접":      (df["open_hour"] <= 7) & (df["close_hour"] >= 23),
}

print(f"\n  {'조건':<16}{'건수':>7}{'비율':>8}{'평균평점':>10}{'평균리뷰':>10}")
print("  " + "-" * 52)
for label, mask in conditions.items():
    sub = df[mask]
    if len(sub) == 0:
        continue
    print(f"  {label:<16}{len(sub):>7}{len(sub)/len(df)*100:>7.1f}%"
          f"{sub['rating'].mean():>10.2f}{sub['reviews'].mean():>10,.0f}")

# ══════════ 등급 부여 ══════════
print(f"\n{'=' * 78}")
print("[추천 등급 부여]")
print("=" * 78)

scored = df.copy()
scored["grade"] = np.select(
    [
        (scored["rating"] >= 4.5) & (scored["reviews"] >= 1000),
        (scored["rating"] >= 4.2) & (scored["reviews"] >= 500),
        (scored["rating"] >= 4.0),
        (scored["rating"] >= 3.5),
    ],
    ["S (강력추천)", "A (추천)", "B (보통)", "C (참고)"],
    default="D (비추천)",
)

vc = scored["grade"].value_counts()
print()
for grade in ["S (강력추천)", "A (추천)", "B (보통)", "C (참고)", "D (비추천)"]:
    if grade not in vc:
        continue
    cnt = vc[grade]
    bar = "■" * int(cnt / vc.max() * 30)
    print(f"  {grade:<14}{bar:<32}{cnt:>4}건 ({cnt/len(df)*100:>5.1f}%)")

print(f"\n  [S등급 목록]")
s_grade = scored[scored["grade"] == "S (강력추천)"].nlargest(5, "reviews")
print(s_grade[["name", "category", "region", "rating", "reviews"]]
      .to_string(index=False))

print("\n" + "=" * 78)
```

> **눈여겨볼 점 5가지**

> - `np.select` 로 5단계 등급을 한 번에 부여합니다.
> - **조건별 요약표**를 만들면 데이터의 성격을 빠르게 파악할 수 있습니다.

## ⑤ 자주 하는 실수

### `and` / `or` 사용

```python
df[(df["a"] > 1) and (df["b"] < 5)]
```

```
ValueError: The truth value of a Series is ambiguous.
```

**해결** — `&` `|` `~` 를 씁니다. (`query()` 안에서는 `and`/`or` 가능)

### 괄호 누락

```python
df[df["score"] >= 80 & df["stage"] == 5]
```

**원인** — `&` 우선순위가 높아 `80 & df["stage"]` 가 먼저 계산됩니다.
**해결** — 각 조건을 괄호로 감쌉니다.

### 체인 인덱싱으로 값 대입

```python
df[df["score"] > 80]["grade"] = "A"       # 반영 안 됨!
```

**해결** — `df.loc[df["score"] > 80, "grade"] = "A"`

### `SettingWithCopyWarning`

```python
subset = df[df["score"] > 80]
subset["grade"] = "A"
```

**해결** — `.copy()` 를 붙입니다.

### `str.contains()` 에서 결측 에러

```python
df[df["name"].str.contains("카페")]
```

```
ValueError: Cannot mask with non-boolean array containing NA / NaN values
```

**해결** — `na=False` 를 줍니다.

```python
df[df["name"].str.contains("카페", na=False)]
```

### `between` 의 양끝 포함 여부

```python
df["score"].between(70, 90)                      # 70 <= x <= 90
df["score"].between(70, 90, inclusive="left")    # 70 <= x < 90
df["score"].between(70, 90, inclusive="neither") # 70 < x < 90
```

**기본은 양끝 포함**입니다. 헷갈리면 명시하세요.

### 결측치가 조건에서 조용히 제외됨

```python
df[df["price"] <= 30000]      # NaN 은 자동 제외
```

**주의** — `NaN <= 30000` 은 `False` 입니다. 결측 행이 조용히 사라집니다.
의도한 것이면 괜찮지만, **몇 건이 제외됐는지 확인**하세요.

```python
print(f"결측 {df['price'].isna().sum()}건이 제외됨")
```

### `query()` 에서 외부 변수를 그냥 씀

```python
threshold = 80
df.query("score >= threshold")
```

```
UndefinedVariableError: name 'threshold' is not defined
```

**해결** — `@` 를 붙입니다. `df.query("score >= @threshold")`

### 열 이름에 공백이 있을 때 `query()`

```python
df.query("최종 점수 >= 80")          # 에러
df.query("`최종 점수` >= 80")        # 백틱으로 감싸기
```

### 정렬 후 인덱스를 안 고침

```python
top = df.sort_values("score", ascending=False)
top.loc[0]        # 원본 인덱스 0인 행 — 1등이 아님!
```

**해결** — `reset_index(drop=True)` 또는 `iloc` 사용. ([Day 047](day-047.md))

```python
import pandas as pd

# ── 방법 ① 불리언 인덱싱 ──
result = df[
    df["region"].isin(["서울", "부산"])
    & df["rating"].between(4.0, 4.8)
```

| 방법 | 장점 | 단점 |
|---|---|---|
| `np.select` | 조건이 자유로움 (여러 열 조합 가능) | 조건과 값을 두 리스트로 관리 |
| `pd.cut` | **구간이 명확**하고 순서형 범주가 됨 | 단일 열의 구간에만 사용 가능 |
| `loc` 순차 | 직관적 | 줄이 많고 순서 실수 위험 |

> **`pd.cut` 은 결과가 `category` 자료형**이 되어 순서가 보존됩니다.
> 정렬하면 A, B, C, D, F 순서가 유지됩니다. [Day 059](day-059.md)에서 자세히 다룹니다.
>
> **`groupby().agg()`** 는 [Day 050](day-050.md)에서 배웁니다. 여기서는 미리 맛보기입니다.
</details>

**3.** 아래 코드는 경고가 나고 값이 반영되지 않습니다. 3가지 방법으로 고치세요.

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["A", "B", "C", "D"],
    "score": [95, 72, 88, 61],
    "region": ["서울", "부산", "서울", "제주"],
})

seoul = df[df["region"] == "서울"]
seoul["bonus"] = seoul["score"] * 0.1
seoul["total"] = seoul["score"] + seoul["bonus"]

print(seoul)
print(df)
```

<details>
<summary>답 보기</summary>

**문제** — `df[df["region"] == "서울"]` 이 복사본인지 뷰인지 불명확해 경고가 납니다.

```
SettingWithCopyWarning: A value is trying to be set on a copy of a slice from a DataFrame.
```

**의도가 무엇인가에 따라 해결책이 다릅니다.**

**해결 ① 서울 데이터만 별도로 분석 — `.copy()`**

```python
seoul = df[df["region"] == "서울"].copy()      # ← 명시적 복사
seoul["bonus"] = (seoul["score"] * 0.1).round(1)
seoul["total"] = (seoul["score"] + seoul["bonus"]).round(1)
seoul = seoul.reset_index(drop=True)

print("[서울만 분석]")
print(seoul.to_string(index=False))
print(f"\n원본은 그대로: {list(df.columns)}")
```

```
[서울만 분석]
name  score region  bonus  total
   A     95     서울    9.5  104.5
   C     88     서울    8.8   96.8

원본은 그대로: ['name', 'score', 'region']
```

**해결 ② 원본에 서울만 값을 넣기 — `.loc`**

```python
df2 = df.copy()
is_seoul = df2["region"] == "서울"

df2.loc[is_seoul, "bonus"] = (df2.loc[is_seoul, "score"] * 0.1).round(1)
df2.loc[is_seoul, "total"] = (df2.loc[is_seoul, "score"]
                              + df2.loc[is_seoul, "bonus"]).round(1)

print("[원본에 직접 — 서울만]")
print(df2.to_string(index=False))
```

```
[원본에 직접 — 서울만]
name  score region  bonus  total
   A     95     서울    9.5  104.5
   B     72     부산    NaN    NaN
   C     88     서울    8.8   96.8
   D     61     제주    NaN    NaN
```

**해결 ③ 전체에 계산하고 조건부 값 — `np.where`**

```python
import numpy as np

df3 = df.copy()
is_seoul = df3["region"] == "서울"

df3["bonus"] = np.where(is_seoul, (df3["score"] * 0.1).round(1), 0)
df3["total"] = (df3["score"] + df3["bonus"]).round(1)

print("[전체 계산 — 비서울은 0]")
print(df3.to_string(index=False))
```

```
[전체 계산 — 비서울은 0]
name  score region  bonus  total
   A     95     서울    9.5  104.5
   B     72     부산    0.0   72.0
   C     88     서울    8.8   96.8
   D     61     제주    0.0   61.0
```

**어느 것을 쓸 것인가**

| 상황 | 방법 |
|---|---|
| 서울 데이터만 따로 보고서를 만든다 | **① `.copy()`** |
| 원본에 서울만 보너스를 기록한다 (나머지는 결측) | **② `.loc`** |
| 전체 행에 값이 있어야 한다 (비서울은 0) | **③ `np.where`** |

> **결측(`NaN`)이 남는 ②번을 주의하세요.**
> 나중에 `total` 로 정렬하거나 합계를 낼 때 결측 처리가 필요합니다.
> **전체 행에 값이 필요하면 ③번**이 안전합니다.
>
> **`SettingWithCopyWarning` 을 무시하지 마세요.**
> 지금은 동작해도 pandas 버전이 올라가면 실제로 반영되지 않을 수 있습니다.
> pandas 3.0 부터는 **Copy-on-Write** 가 기본이 되어 동작이 명확해집니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 불리언 인덱싱 | `df[df["col"] >= 값]` |
| 조건 결합 | **`&` `\|` `~`** + **괄호 필수** |
| `isin` | 목록에 포함 |
| `between(a, b)` | 범위 (기본 양끝 포함) |
| `str.contains` | 부분 문자열 · **`na=False` 필수** |
| `query()` | SQL 처럼 · `and`/`or` 가능 · 변수는 **`@`** |
| 정렬 | `sort_values(키, ascending=)` · **`nlargest(n, 열)`** |
| 순위 | `rank(method="min")` — 동점 처리 방식 선택 |
| **원본 수정** | **`df.loc[조건, "열"] = 값`** |
| **별도 데이터** | **`df[조건].copy()`** |
| 금지 | `df[조건]["열"] = 값` — **반영 안 됨** |

**오늘 반드시 기억할 세 가지**
> ① pandas 조건 결합은 **`&` `|` `~`** 이고 **괄호가 필수**입니다.
> ② 원본 수정은 **`.loc[조건, 열] = 값`**, 별도 작업은 **`.copy()`**.
> ③ `df[조건]["열"] = 값` 은 **경고만 나고 반영되지 않습니다.**
