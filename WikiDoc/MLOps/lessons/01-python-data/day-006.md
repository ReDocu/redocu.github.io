## ③ 개념 설명

### 함수의 기본 구조

```python
def 함수이름(매개변수):
    """함수 설명 (docstring)"""
    실행할 코드
    return 돌려줄값
```

```python
def add(a, b):
    """두 수를 더해 돌려줍니다."""
    return a + b

result = add(3, 5)
print(result)      # 8
```

| 용어 | 뜻 |
|---|---|
| **정의(define)** | `def add(a, b):` — 함수를 만드는 것 |
| **호출(call)** | `add(3, 5)` — 함수를 실행하는 것 |
| **매개변수(parameter)** | `a`, `b` — 받을 값의 이름 |
| **인자(argument)** | `3`, `5` — 실제로 넣은 값 |
| **반환값(return value)** | `a + b` 의 결과 — 돌려주는 값 |

> **정의만 하면 아무 일도 안 일어납니다.** 호출해야 실행됩니다.

### return의 성질

```python
def check(score):
    if score >= 60:
        return "합격"        # 여기서 함수가 끝남
    return "불합격"           # 위에서 return 됐다면 실행 안 됨
```

**`return` 을 만나는 순간 함수는 즉시 끝납니다.** 아래 코드는 실행되지 않습니다.

`return` 이 없으면 `None` 을 돌려줍니다.

```python
def greet(name):
    print(f"안녕하세요, {name}님")

result = greet("홍길동")
print(result)      # None
```

> **`print` 와 `return` 은 완전히 다릅니다.**
> `print` 는 화면에 보여 주는 것, `return` 은 값을 돌려주는 것입니다.
> `print` 만 하는 함수의 결과는 **다른 계산에 쓸 수 없습니다.** 초보가 가장 자주 헷갈리는 지점입니다.

```python
def bad_add(a, b):
    print(a + b)          # ❌ 결과를 쓸 수 없음

def good_add(a, b):
    return a + b          # ✅ 다른 계산에 쓸 수 있음

total = good_add(1, 2) + good_add(3, 4)     # 10
total = bad_add(1, 2) + bad_add(3, 4)       # TypeError (None + None)
```

### 여러 값 반환

`return` 에 쉼표로 나열하면 튜플로 묶여 나옵니다.

```python
def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

lo, hi, avg = stats([10, 20, 30, 40])
print(lo, hi, avg)      # 10 40 25.0
```

### 기본값(default) 매개변수

```python
def greet(name, greeting="안녕하세요"):
    return f"{greeting}, {name}님"

print(greet("홍길동"))                  # 안녕하세요, 홍길동님
print(greet("홍길동", "반갑습니다"))     # 반갑습니다, 홍길동님
```

**기본값이 있는 매개변수는 반드시 뒤쪽에** 와야 합니다.

```python
def f(a=1, b):      # SyntaxError
```

### 위치 인자 vs 키워드 인자

```python
def make_url(host, port=80, path="/", secure=False):
    scheme = "https" if secure else "http"
    return f"{scheme}://{host}:{port}{path}"

# 위치로 전달 — 순서를 지켜야 함
make_url("api.example.com", 8080, "/data")

# 키워드로 전달 — 순서 무관, 읽기 좋음
make_url("api.example.com", path="/data", secure=True)
```

> **인자가 3개를 넘으면 키워드로 넘기세요.** `fetch(url, 3, 1.5, True)` 는 반년 뒤에 아무도 못 읽습니다.
> `fetch(url, retries=3, timeout=1.5, verify=True)` 는 설명이 필요 없습니다.

### `*args` — 개수를 모르는 위치 인자

```python
def total(*numbers):
    result = 0
    for n in numbers:
        result += n
    return result

print(total(1, 2, 3))          # 6
print(total(1, 2, 3, 4, 5))    # 15
print(total())                 # 0
```

`numbers` 는 **튜플**로 받습니다.

### `**kwargs` — 개수를 모르는 키워드 인자

```python
def show_config(**options):
    for key, value in options.items():
        print(f"  {key} = {value}")

show_config(host="localhost", port=5432, debug=True)
```

```
  host = localhost
  port = 5432
  debug = True
```

`options` 는 **딕셔너리**로 받습니다 (Day 008).

**둘을 같이 쓸 때의 순서**는 정해져 있습니다.

```python
def f(필수, 기본값=None, *args, **kwargs):
    ...
```

> `*args` / `**kwargs` 는 **남의 함수를 감쌀 때** 주로 씁니다.
> W04에서 `requests.get()` 에 옵션을 그대로 넘기는 래퍼 함수를 만들 때 씁니다.

### 스코프(scope) — 변수가 보이는 범위

```python
total = 100          # 전역(global) 변수

def f():
    total = 50       # 지역(local) 변수 — 완전히 다른 변수
    print(total)     # 50

f()
print(total)         # 100  ← 안 바뀜
```

**함수 안에서 만든 변수는 함수 밖에서 안 보입니다.**

읽기만 하면 바깥 변수가 보입니다.

```python
TAX_RATE = 0.1       # 상수는 대문자로 쓰는 관례

def with_tax(price):
    return price * (1 + TAX_RATE)     # 읽기는 가능
```

바꾸려면 `global` 이 필요한데, **쓰지 마세요.**

```python
count = 0

def bad_increment():
    global count       # ❌ 피해야 할 패턴
    count += 1

def good_increment(count):
    return count + 1   # ✅ 받아서 돌려주기
```

> **왜 `global` 을 피하나** — 어디서 값이 바뀌는지 추적할 수 없기 때문입니다.
> 함수가 100개인 프로젝트에서 전역 변수 하나가 잘못되면, 100곳을 다 봐야 합니다.
> **함수는 인자로 받아서 값을 돌려주기만 한다** — 이 원칙을 지키면 테스트도 쉬워집니다.

### Step 2. 통계 함수 직접 구현

`stats.py` 를 만듭니다. 파이썬 내장 함수를 쓰지 않고 만들어 봅니다.

```python
def my_sum(numbers):
    """합계를 구합니다."""
    total = 0
    for n in numbers:
        total += n
    return total


def my_mean(numbers):
    """평균을 구합니다. 빈 목록이면 None."""
    if len(numbers) == 0:
        return None
    return my_sum(numbers) / len(numbers)


def my_max(numbers):
    """최댓값을 구합니다. 빈 목록이면 None."""
    if len(numbers) == 0:
        return None
    biggest = numbers[0]
    for n in numbers:
        if n > biggest:
            biggest = n
    return biggest


def my_std(numbers):
    """표준편차(모집단)를 구합니다."""
    if len(numbers) == 0:
        return None
    avg = my_mean(numbers)
    squared_diff = 0
    for n in numbers:
        squared_diff += (n - avg) ** 2
    return (squared_diff / len(numbers)) ** 0.5


scores = [88, 92, 79, 95, 68, 84]

print(f"합계     : {my_sum(scores)}")
print(f"평균     : {my_mean(scores):.2f}")
print(f"최댓값   : {my_max(scores)}")
print(f"표준편차 : {my_std(scores):.2f}")

# 빈 목록도 죽지 않는지 확인
print(f"빈 목록  : {my_mean([])}")
```

실행 결과:

```
합계     : 506
평균     : 84.33
최댓값   : 95
표준편차 : 8.88
빈 목록  : None
```

> **빈 목록을 먼저 처리한 것**에 주목하세요. 이걸 `가드 절(guard clause)` 이라고 합니다.
> W05에서 결측 데이터를 만나면 정확히 이 방어가 필요합니다. `ZeroDivisionError` 는 실서비스를 멈춥니다.
>
> 참고로 실무에서는 `statistics` 표준 라이브러리나 NumPy(Day 021)를 씁니다.
> 오늘 직접 만든 이유는 **함수 분해 연습**과 **평균이 어떻게 계산되는지 몸으로 알기 위해서**입니다.

### Step 3. 검증 함수 모음

`validators.py` 를 만듭니다. W09의 데이터 품질 검증(Day 044)의 축소판입니다.

```python
def is_valid_email(text):
    """이메일 형식인지 대략 판정합니다."""
    text = text.strip()
    if "@" not in text:
        return False
    if text.count("@") != 1:
        return False
    user, domain = text.split("@")
    if len(user) == 0 or len(domain) == 0:
        return False
    if "." not in domain:
        return False
    return True


def is_valid_phone(text):
    """01012345678 또는 010-1234-5678 형식인지 판정합니다."""
    digits = text.replace("-", "").replace(" ", "")
    if not digits.isdigit():
        return False
    if not digits.startswith("010"):
        return False
    return len(digits) == 11


def in_range(value, low, high):
    """값이 [low, high] 범위 안인지 판정합니다."""
    return low <= value <= high


def parse_amount(raw):
    """'12,000원' 같은 문자열을 정수로 바꿉니다. 실패하면 None."""
    cleaned = raw.strip().replace(",", "").replace("원", "").strip()
    if cleaned == "" or not cleaned.isdigit():
        return None
    return int(cleaned)


# 확인
tests_email = ["a@b.com", "no-at-sign", "a@@b.com", "@b.com", "a@b"]
for t in tests_email:
    print(f"{t:<15} → {is_valid_email(t)}")

print()
tests_phone = ["01012345678", "010-1234-5678", "0212345678", "010abc45678"]
for t in tests_phone:
    print(f"{t:<15} → {is_valid_phone(t)}")

print()
tests_amount = [" 12,000원 ", "5000", "오만원", "", "1,234,567"]
for t in tests_amount:
    print(f"{t!r:<15} → {parse_amount(t)}")
```

```
no-at-sign      → False
a@@b.com        → False
@b.com          → False
a@b             → False

01012345678     → True
010-1234-5678   → True

010abc45678     → False

'5000'          → 5000
'오만원'          → None

```

> 이름만 보고도 조건문에 바로 쓸 수 있음을 알 수 있습니다.
>
> `parse_amount` 가 실패 시 `None` 을 돌려주는 방식은 **에러를 값으로 표현**하는 방법입니다.

### Step 4. 가계부 리팩터링 — 함수로 분해

`budget.py` 를 함수 중심으로 다시 씁니다. **Day 005 코드와 비교해 보세요.**

```python
CATEGORIES = ("식비", "교통", "주거", "여가", "기타")


# ---------- 입력 ----------

def input_amount(prompt="  금액(원): "):
    """올바른 금액이 들어올 때까지 반복해 묻습니다."""
    while True:
        raw = input(prompt).strip().replace(",", "")
        if raw == "":
            print("  → 금액을 입력하세요.")
            continue
        if not raw.isdigit():
            print(f"  → '{raw}' 는 숫자가 아닙니다.")
            continue
        amount = int(raw)
        if amount <= 0:
            print("  → 0보다 큰 금액을 입력하세요.")
            continue
        return amount


def input_category():
    """지출 분류를 고릅니다."""
    print("  분류:", " / ".join(CATEGORIES))
    while True:
        cat = input("  분류 선택: ").strip()
        if cat in CATEGORIES:
            return cat
        print(f"  → '{cat}' 는 목록에 없습니다.")


# ---------- 계산 ----------

def total_by_kind(records, kind):
    """수입 또는 지출의 합계를 구합니다."""
    total = 0
    for rec in records:
        if rec[0] == kind:
            total += rec[3]
    return total


def total_by_category(records, category):
    """특정 분류의 지출 합계를 구합니다."""
    total = 0
    for rec in records:
        if rec[0] == "지출" and rec[1] == category:
            total += rec[3]
    return total


def summarize(records):
    """수입·지출·잔액을 계산해 돌려줍니다."""
    income = total_by_kind(records, "수입")
    expense = total_by_kind(records, "지출")
    return income, expense, income - expense


# ---------- 출력 ----------

def show_menu():
    print()
    print("=" * 41)
    print("            콘솔 가계부 v1")
    print("=" * 41)
    print("1. 수입 추가    2. 지출 추가")
    print("3. 내역 보기    4. 요약 보기")
    print("0. 종료")
    print("-" * 41)


def show_records(records):
    if not records:
        print("  등록된 내역이 없습니다.")
        return
    print(f"  {'No':>3}  {'구분':<4} {'분류':<6} {'내용':<16} {'금액':>12}")
    print("  " + "-" * 47)
    for i, rec in enumerate(records, start=1):
        kind, category, memo, amount = rec
        sign = "+" if kind == "수입" else "-"
        print(f"  {i:>3}  {kind:<4} {category:<6} {memo:<16} {sign}{amount:>11,}")


def show_summary(records):
    if not records:
        print("  등록된 내역이 없습니다.")
        return

    income, expense, balance = summarize(records)
    print(f"  총 수입 : {income:>12,} 원")
    print(f"  총 지출 : {expense:>12,} 원")
    print("  " + "-" * 27)
    print(f"  잔액    : {balance:>12,} 원")

    if expense > 0:
        print("\n  [지출 분류별]")
        for category in CATEGORIES:
            amount = total_by_category(records, category)
            ratio = amount / expense
            print(f"    {category}  {amount:>10,} 원  ({ratio:>5.1%})")

    if balance < 0:
        print(f"\n  ⚠ 적자입니다. {-balance:,}원 초과 지출했습니다.")
    elif income > 0:
        print(f"\n  저축률 {balance / income:.1%} 입니다.")


# ---------- 메인 ----------
```

### Step 6. `*args` / `**kwargs` 활용

```python
def log_call(func_name, *args, **kwargs):
    """함수 호출을 로그 형식으로 남깁니다."""
    parts = []
    for a in args:
        parts.append(repr(a))
    for k, v in kwargs.items():
        parts.append(f"{k}={v!r}")
    print(f"[CALL] {func_name}({', '.join(parts)})")


def fetch(url, timeout=5.0, retries=3, verify=True):
    log_call("fetch", url, timeout=timeout, retries=retries, verify=verify)
    return {"status": 200, "url": url}


fetch("https://api.example.com/data")
fetch("https://api.example.com/users", timeout=10.0, retries=5)
```

### 함수가 `None` 을 돌려줌 — `return` 누락

```python
def calc_total(items):
    total = 0
    for i in items:
        total += i
    print(total)          # ← return이 아니라 print

result = calc_total([1, 2, 3])
print(result * 2)
```

```
6
Traceback (most recent call last):
TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'
```

**원인** — `print` 는 화면에 보여 줄 뿐, 값을 돌려주지 않습니다. 함수는 `None` 을 반환합니다.
**해결** — `return total` 로 바꿉니다.

> **`NoneType` 이 들어간 에러를 보면 "return을 빠뜨렸나?"부터 의심하세요.**
> 이 과정에서 가장 자주 나오는 논리 실수입니다.

### `UnboundLocalError: cannot access local variable 'count'`

```python
count = 0

def increment():
    count += 1        # 읽으려는데 지역 변수로 판단됨

increment()
```

```
UnboundLocalError: cannot access local variable 'count' where it is not associated with a value
```

**원인** — 함수 안에서 **대입하는 변수**는 파이썬이 자동으로 지역 변수로 봅니다.
그런데 `count += 1` 은 "기존 값을 읽어서 더한다"이므로, 아직 값이 없는 지역 변수를 읽으려다 실패합니다.
**해결** — `global` 대신 **받아서 돌려주기**로 고칩니다.

```python
def increment(count):
    return count + 1

count = increment(count)
```

### 기본값에 리스트를 쓰는 함정

```python
def add_item(item, basket=[]):        # ❌ 위험
    basket.append(item)
    return basket

print(add_item("사과"))     # ['사과']
print(add_item("바나나"))   # ['사과', '바나나']  ← 왜?!
```

**원인** — 기본값은 **함수를 정의할 때 딱 한 번** 만들어집니다. 호출할 때마다 새로 만들어지지 않습니다.
그래서 같은 리스트가 계속 재사용됩니다.
**해결** — 기본값은 `None` 으로 두고 안에서 만듭니다.

```python
def add_item(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket
```

> 파이썬 면접 단골 질문입니다. **"변할 수 있는 값(리스트·딕셔너리)을 기본값으로 쓰지 마라"** 로 외우세요.

## ⑥ 확인 문제

**1.** 아래 두 함수의 차이를 설명하고, `total` 에 무엇이 들어가는지 답하세요.

```python
def f1(numbers):
    print(sum(numbers))

def f2(numbers):
    return sum(numbers)

total = f1([1, 2, 3]) 
```

<details>
<summary>답 보기</summary>

`total` 에는 **`None`** 이 들어갑니다.

| 함수 | 화면 출력 | 반환값 |
|---|---|---|
| `f1` | `6` 이 출력됨 | `None` (return이 없음) |
| `f2` | 아무것도 출력 안 됨 | `6` |

`print` 는 **사람에게 보여 주는 것**, `return` 은 **프로그램에게 값을 넘기는 것**입니다.

`f1` 의 결과는 다른 계산에 쓸 수 없습니다.

```python
total = f1([1, 2, 3]) + f1([4, 5])      # TypeError: NoneType + NoneType
```

**원칙** — 계산하는 함수는 `return` 만 하고, 출력은 호출하는 쪽에서 합니다.
그래야 같은 함수를 화면 출력·파일 저장·API 응답 어디에나 쓸 수 있습니다.
W20에서 학습 코드의 전처리 함수를 서빙 API가 그대로 재사용할 수 있는 이유가 이것입니다.
</details>

**2.** 아래 함수를 두 번 호출하면 결과가 이상합니다. 왜 그런지 설명하고 고치세요.

```python
def collect(item, bucket=[]):
    bucket.append(item)
    return bucket

print(collect("a"))
print(collect("b"))
```

<details>
<summary>답 보기</summary>

**출력**

```
['a']
['a', 'b']       ← 기대는 ['b']
```

**원인** — 기본값 `[]` 는 **함수를 정의하는 순간 딱 한 번만** 만들어집니다.
호출할 때마다 새 리스트가 생기는 것이 아니라, **같은 리스트 객체를 계속 재사용**합니다.
그래서 이전 호출에서 넣은 값이 남아 있습니다.

리스트·딕셔너리·세트처럼 **변할 수 있는(mutable)** 값이 기본값일 때 발생합니다.
정수·문자열·튜플처럼 변하지 않는 값은 안전합니다.

**해결**

```python
def collect(item, bucket=None):
    if bucket is None:
        bucket = []          # 호출할 때마다 새로 만듦
    bucket.append(item)
    return bucket
```

`if bucket is None` 에서 `==` 이 아니라 `is` 를 쓰는 것도 관례입니다.
`None` 은 세상에 하나뿐인 값이라 **동일성 비교(`is`)** 가 더 정확하고 빠릅니다.
</details>

**3.** 아래 함수는 "하나의 일만 한다"는 원칙을 어기고 있습니다. 어떻게 나누는 것이 좋을까요?

```python
def process_and_report(raw_lines):
    cleaned = []
    for line in raw_lines:
        line = line.strip()
        if line == "" or line.startswith("#"):
            continue
        cleaned.append(line)

    error_count = 0
    for line in cleaned:
        if "[ERROR]" in line:
            error_count += 1

    print(f"전체 {len(cleaned)}줄, 에러 {error_count}줄")
    print(f"에러율 {error_count / len(cleaned):.1%}")
```

<details>
<summary>답 보기</summary>

이 함수는 **세 가지 일**을 합니다. ① 정제 ② 집계 ③ 출력.

세 가지가 붙어 있으면 이런 문제가 생깁니다.
- 정제 결과만 파일로 저장하고 싶어도 못 합니다.
- 에러 개수만 다른 계산에 쓰고 싶어도 못 합니다 (`print`만 하고 `return` 이 없음).
- 출력 형식을 바꾸려면 정제 로직이 든 함수를 건드려야 합니다.
- `cleaned` 가 비면 `ZeroDivisionError` 로 죽습니다.

**셋으로 나눕니다.**

```python
def clean_lines(raw_lines):
    """빈 줄과 주석(#)을 제거합니다."""
    cleaned = []
    for line in raw_lines:
        line = line.strip()
        if line == "" or line.startswith("#"):
            continue
        cleaned.append(line)
    return cleaned


def count_errors(lines):
    """[ERROR] 가 포함된 줄 수를 셉니다."""
    count = 0
    for line in lines:
        if "[ERROR]" in line:
            count += 1
    return count


def report(lines):
    """집계 결과를 화면에 출력합니다."""
    total = len(lines)
    errors = count_errors(lines)
    print(f"전체 {total}줄, 에러 {errors}줄")
    if total > 0:
        print(f"에러율 {errors / total:.1%}")


# 사용
cleaned = clean_lines(raw_lines)
report(cleaned)
```

이제 각 함수를 **따로 테스트**할 수 있고, 정제 결과만 저장하거나 에러 수만 알림에 쓸 수도 있습니다.

</details>

## 오늘의 정리

| 항목 | 문법 |
|---|---|
| 정의 | `def 이름(매개변수):` + docstring |
| 반환 | `return 값` — 만나면 함수 즉시 종료 |
| 여러 값 반환 | `return a, b, c` → `x, y, z = f()` |
| 기본값 | `def f(a, b=10):` — 기본값은 뒤쪽에 |
| 키워드 인자 | `f(a=1, b=2)` — 인자 3개 넘으면 권장 |
| 가변 인자 | `*args` (튜플) · `**kwargs` (딕셔너리) |
| 스코프 | 함수 안 변수는 밖에서 안 보임 · `global` 은 쓰지 않는다 |
| 좋은 함수 | 하나의 일 · 동사 이름 · 20줄 이내 · 인자 4개 이내 |
| 함정 | 기본값에 리스트 금지 · `print` ≠ `return` |
