## ② 왜 필요한가

**어제 배운 기술은 "할 수 있다"이고, 오늘은 "해도 되는가"입니다.**

크롤링은 기술적으로 쉽습니다. 20줄이면 사이트 하나를 통째로 긁을 수 있습니다.
그래서 오히려 **사고가 많이 납니다.**

| 실제로 벌어지는 일 | 결과 |
|---|---|
| 간격 없이 초당 100회 요청 | IP 차단. 학원·회사 전체가 막힘 |
| 개인정보가 든 게시글 수집 | **개인정보보호법 위반** |
| 뉴스 기사 본문 전체를 저장·재배포 | **저작권 침해** |
| 로그인 후 유료 콘텐츠 수집 | 이용약관 위반 + 민사 책임 |
| 서버에 과부하를 줘 서비스 장애 | **업무방해** — 형사 문제 |

**국내에도 판례가 있습니다.** 크롤링 자체가 불법은 아니지만,
**어떻게 했는가와 무엇을 했는가**에 따라 결과가 완전히 달라집니다.

그리고 이건 취업 후에도 계속됩니다.

## ③ 개념 설명

### robots.txt

사이트가 **"크롤러에게 보내는 안내문"** 입니다. 항상 루트에 있습니다.

```
https://example.com/robots.txt
```

```
User-agent: *
Disallow: /admin/
Disallow: /private/
Allow: /public/
Crawl-delay: 10

User-agent: BadBot
Disallow: /

Sitemap: https://example.com/sitemap.xml
```

| 항목 | 뜻 |
|---|---|
| `User-agent: *` | 모든 크롤러에게 |
| `User-agent: Googlebot` | 특정 크롤러에게만 |
| `Disallow: /admin/` | 이 경로는 수집하지 마세요 |
| `Disallow: /` | **전체 금지** |
| `Allow: /public/` | Disallow 안의 예외 허용 |
| `Crawl-delay: 10` | 요청 간격 10초 |
| `Sitemap:` | 수집해도 되는 페이지 목록 |

**중요한 사실**

| 오해 | 사실 |
|---|---|
| "robots.txt는 법적 강제력이 있다" | 기술적 강제력은 없습니다. **하지만 지키지 않으면 고의성 증거가 됩니다** |
| "robots.txt에 없으면 다 해도 된다" | 아닙니다. **이용약관·저작권·개인정보법이 별도로 적용**됩니다 |
| "Disallow가 없으면 허용" | 명시적 안내가 없을 뿐입니다. 다른 조건을 확인해야 합니다 |

> **robots.txt는 최소 조건이지 충분 조건이 아닙니다.**
> "허용됨"이 아니라 **"명시적으로 금지되지는 않음"** 으로 읽으세요.

### 파이썬으로 robots.txt 확인

```python
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()

rp.can_fetch("MyBot/1.0", "https://example.com/news/1")     # True/False
rp.crawl_delay("MyBot/1.0")                                  # 10 또는 None
rp.request_rate("MyBot/1.0")                                 # RequestRate 또는 None
rp.site_maps()                                               # 사이트맵 URL 목록
```

### 요청 간격 (rate limiting)

**간격 없는 수집은 공격과 구분되지 않습니다.**

| 간격 | 초당 요청 | 평가 |
|---|---|---|
| 없음 | 20~100회 | **공격으로 간주** |
| 0.1초 | 10회 | 여전히 과함 |
| **1초** | 1회 | 일반적으로 안전 ⭐ |
| 2~3초 | 0.3~0.5회 | 보수적 |
| `Crawl-delay` 값 | 사이트 지정 | **명시돼 있으면 반드시 준수** |

```python
import time

for page in pages:
    fetch(page)
    time.sleep(1.0)          # 매 요청 후 1초
```

**더 나은 방법 — 실제 소요 시간을 고려**

```python
import time

last_request = 0.0
MIN_INTERVAL = 1.0

def polite_get(url):
    global last_request
    elapsed = time.monotonic() - last_request
    if elapsed < MIN_INTERVAL:
        time.sleep(MIN_INTERVAL - elapsed)
    r = session.get(url, timeout=10)
    last_request = time.monotonic()
    return r
```

요청 자체가 0.8초 걸렸다면 0.2초만 더 기다립니다. 불필요한 대기가 없습니다.

> `time.monotonic()` 은 시스템 시각 변경에 영향받지 않는 시계입니다.
> **경과 시간 측정에는 `time.time()` 이 아니라 이걸 쓰세요.**

### 지수 백오프 (exponential backoff)

실패했을 때 **간격을 점점 늘려 가며** 재시도합니다.

```python
for attempt in range(1, max_attempts + 1):
    r = session.get(url, timeout=10)
    if r.ok:
        return r
    if not should_retry(r.status_code):
        break                                     # 4xx 는 즉시 포기
    wait = base_delay * (2 ** (attempt - 1))      # 1 → 2 → 4 → 8초
    time.sleep(wait)
```

**왜 늘리나** — 서버가 과부하일 때 모든 클라이언트가 1초마다 다시 오면 **부하가 더 심해집니다.**
점점 물러나 주는 것이 서버가 회복할 시간을 줍니다.

**지터(jitter)를 넣으면 더 좋습니다.**

```python
import random
wait = base_delay * (2 ** (attempt - 1)) * (0.5 + random.random())
```

여러 클라이언트가 동시에 실패하면 **같은 시각에 몰려서** 다시 옵니다.
무작위 요소를 섞으면 분산됩니다.

### User-Agent — 정체를 밝히기

```python
headers = {
    "User-Agent": "MLOpsStudyBot/1.0 (교육용 수집; hong@example.com)"
}
```

| 방식 | 평가 |
|---|---|
| 기본값 `python-requests/2.32.3` | 많은 사이트가 차단 |
| **정체와 연락처를 밝힘** | ⭐ 권장. 문제 시 사이트가 연락 가능 |
| 브라우저인 척 위장 | **회피 목적이면 고의성 증거** |

> **브라우저 UA를 쓰는 것 자체가 불법은 아닙니다.**
> 하지만 **차단을 우회할 목적**이라면 이야기가 다릅니다.
> 차단당했다면 그건 "오지 말라"는 신호입니다. 우회가 아니라 **중단하거나 문의**하는 것이 맞습니다.

### 페이지네이션 패턴

| 방식 | URL 예 | 종료 판단 |
|---|---|---|
| 페이지 번호 | `?page=1`, `?page=2` | 빈 결과 또는 총 페이지 수 |
| offset/limit | `?offset=0&limit=20` | 결과 수 < limit |
| 커서 | `?cursor=abc123` | 다음 커서가 없음 |
| 다음 링크 | `<a rel="next">` | 링크 없음 |

**종료 조건을 반드시 두 겹으로** 두세요.

```python
MAX_PAGES = 100                       # 안전장치

for page in range(1, MAX_PAGES + 1):
    items = fetch_page(page)
    if not items:
        break                         # 정상 종료
    ...
else:
    logger.warning("최대 페이지 도달 — 데이터가 더 있을 수 있음")
```

**무한 루프 방지가 핵심입니다.** 사이트가 잘못된 응답을 주면 영원히 돌 수 있습니다.

### 중복 방지와 재개

```python
seen: set[str] = set()

for url in urls:
    if url in seen:
        continue
    seen.add(url)
    ...
```

**세트를 쓰는 이유**는 [Day 007](day-007.md)에서 배웠습니다. 100만 건에서 `in` 검사가 즉시 됩니다.

**중단됐을 때 이어서 하려면 진행 상황을 저장**합니다.

```python
STATE = Path("crawl_state.json")

def save_state(page, seen):
    STATE.write_text(json.dumps({"page": page, "seen": sorted(seen)}), encoding="utf-8")

def load_state():
    if STATE.exists():
        d = json.loads(STATE.read_text(encoding="utf-8"))
        return d["page"], set(d["seen"])
    return 1, set()
```

1000페이지를 수집하다 800페이지에서 죽으면, 처음부터 다시 하는 것은 **서버에도 민폐**입니다.

### 법적·윤리적 점검 항목

**수집 전에 반드시 확인하세요.**

| # | 항목 | 확인 방법 |
|---|---|---|
| 1 | **robots.txt** | `사이트/robots.txt` 에서 해당 경로 확인 |
| 2 | **이용약관** | "크롤링", "자동화", "수집" 검색 |
| 3 | **개인정보 포함 여부** | 이름·연락처·주소·주민번호·아이디 등 |
| 4 | **저작권** | 기사 본문·이미지·음원은 저작물 |
| 5 | **로그인 필요 여부** | 로그인 후 콘텐츠는 계약 관계가 생김 |
| 6 | **공식 API 존재** | 있으면 **반드시 API를 쓰세요** |
| 7 | **요청 부하** | 간격·시간대·총 요청 수 |
| 8 | **사용 목적** | 개인 학습 / 연구 / 상업적 이용 |

### 개인정보 — 가장 위험한 항목

**개인정보보호법상 "살아 있는 개인을 알아볼 수 있는 정보"** 는 수집·저장 자체가 규제 대상입니다.

| 개인정보인 것 | 개인정보가 아닌 것 |
|---|---|
| 이름, 전화번호, 이메일 | 집계된 통계 (역별 승차 인원) |
| 주소, 생년월일 | 익명화된 코드 |
| 아이디, 닉네임 (특정 가능하면) | 공개된 법인 정보 |
| IP 주소 (결합 시) | 날씨·교통량 |
| 사진 (얼굴 식별 가능) | |

**공개된 정보라도 마음대로 수집·저장할 수 없습니다.**
"인터넷에 공개돼 있으니 괜찮다"는 흔한 오해입니다.

> **이 과정의 원칙: 개인정보가 포함된 데이터는 수집하지 않습니다.**
> 로드맵 6절에 명시돼 있고, 모든 프로젝트의 통과 요건입니다.
>
> 실습용으로는 **집계·통계 데이터**를 쓰세요. 공공데이터포털의 대부분이 여기 해당합니다.

### 저작권

| 대상 | 저작물? | 수집 시 |
|---|---|---|
| 뉴스 기사 **본문** | ✅ | 저장·재배포 금지. 제목·링크·요약은 인용 범위 |
| 사진·이미지 | ✅ | 원칙적으로 금지 |
| 사실 데이터 (기온, 인구수) | ❌ | 자유롭게 사용 가능 |
| DB 자체의 구성 | ✅ (DB제작자 권리) | 대량 복제 주의 |
| 공공데이터포털 데이터 | 대부분 개방 | 출처 표기 조건 확인 |

**안전한 방법**

```
❌ 기사 본문 전체를 DB에 저장
✅ 제목 + URL + 발행일 + 카테고리만 저장
```

링크와 메타데이터는 대개 문제가 없습니다. **본문을 통째로 복제하지 마세요.**

### 공식 API가 있으면 반드시 그것을

| | 크롤링 | 공식 API |
|---|---|---|
| 적법성 | 회색 지대 | **명확히 허용됨** |
| 안정성 | 화면 바뀌면 깨짐 | 버전 관리됨 |
| 속도 | 느림 (HTML 파싱) | 빠름 |
| 데이터 품질 | 파싱 오류 가능 | 구조화됨 |

**API가 있는데 크롤링하면 그 자체가 문제**가 될 수 있습니다.
이용약관에 "API를 통해서만 접근"이라고 명시된 경우가 많습니다.

## ④ 단계별 실습

### Step 1. robots.txt 확인 도구

`check_robots.py` 를 만듭니다.

```python
"""수집 전 robots.txt 확인 도구."""

import sys
from urllib.parse import urlparse, urljoin
from urllib.robotparser import RobotFileParser

import requests

MY_AGENT = "MLOpsStudyBot/1.0 (교육용 수집; hong@example.com)"


def check(target_url: str, agent: str = MY_AGENT) -> dict:
    """URL에 대한 robots.txt 정책을 확인합니다."""
    parsed = urlparse(target_url)
    robots_url = f"{parsed.scheme}://{parsed.netloc}/robots.txt"

    result = {
        "target": target_url,
        "robots_url": robots_url,
        "exists": False,
        "allowed": None,
        "crawl_delay": None,
        "sitemaps": [],
        "raw": "",
    }

    # 원문도 받아 둡니다 (사람이 읽어야 하므로)
    try:
        r = requests.get(robots_url, timeout=10,
                         headers={"User-Agent": agent})
        if r.status_code == 200:
            result["exists"] = True
            result["raw"] = r.text
        elif r.status_code == 404:
            result["raw"] = "(robots.txt 없음 — 명시적 안내가 없다는 뜻)"
        else:
            result["raw"] = f"(HTTP {r.status_code})"
    except requests.RequestException as e:
        result["raw"] = f"(확인 실패: {e})"
        return result

    rp = RobotFileParser()
    rp.set_url(robots_url)
    try:
        rp.read()
    except Exception as e:
        result["raw"] += f"\n(파싱 실패: {e})"
        return result

    result["allowed"] = rp.can_fetch(agent, target_url)
    result["crawl_delay"] = rp.crawl_delay(agent)
    result["sitemaps"] = rp.site_maps() or []
    return result


def report(target_url: str) -> None:
    r = check(target_url)

    print("=" * 66)
    print(f"대상 URL : {r['target']}")
    print(f"robots   : {r['robots_url']}")
    print("=" * 66)

    if not r["exists"]:
        print("\n⚠ robots.txt 를 찾지 못했습니다.")
        print("  → '허용'이 아니라 '명시적 안내가 없음'입니다.")
        print("  → 이용약관·저작권·개인정보를 별도로 확인해야 합니다.")
    else:
        mark = "✅ 허용" if r["allowed"] else "❌ 금지"
        print(f"\n수집 가능 여부 : {mark}")
        delay = r["crawl_delay"]
        print(f"권장 요청 간격 : {delay}초" if delay else "권장 요청 간격 : 명시 없음 (1초 이상 권장)")
        if r["sitemaps"]:
            print(f"사이트맵       : {len(r['sitemaps'])}개")
            for s in r["sitemaps"][:3]:
                print(f"  - {s}")

    print(f"\n--- robots.txt 원문 (앞 25줄) ---")
    for line in r["raw"].splitlines()[:25]:
        print(f"  {line}")

    print("\n" + "-" * 66)
    print("⚠ robots.txt 는 '최소 조건'입니다. 아래도 반드시 확인하세요.")
    print("   1) 이용약관에 '크롤링/자동수집' 금지 조항이 있는가")
    print("   2) 개인정보(이름·연락처·아이디)가 포함되는가")
    print("   3) 저작물(기사 본문·이미지)을 복제하게 되는가")
    print("   4) 공식 API 가 있는가 (있으면 반드시 API 사용)")
    print("-" * 66)


if __name__ == "__main__":
    url = sys.argv[1] if len(sys.argv) > 1 else "https://www.data.go.kr/"
    report(url)
```

### Step 2. 요청 간격 제어기

`rate_limiter.py` 를 만듭니다.

```python
"""요청 간격 제어."""

import random
import time


class RateLimiter:
    """최소 간격을 보장합니다. 요청에 걸린 시간을 고려합니다."""

    def __init__(self, min_interval: float = 1.0, jitter: float = 0.0):
        self.min_interval = min_interval
        self.jitter = jitter
        self._last = 0.0
        self.total_waited = 0.0
        self.call_count = 0

    def wait(self) -> float:
        """필요한 만큼 대기하고, 실제 대기 시간을 돌려줍니다."""
        now = time.monotonic()
        elapsed = now - self._last

        interval = self.min_interval
        if self.jitter:
            interval += random.uniform(0, self.jitter)

        waited = 0.0
        if self._last > 0 and elapsed < interval:
            waited = interval - elapsed
            time.sleep(waited)

        self._last = time.monotonic()
        self.total_waited += waited
        self.call_count += 1
        return waited

    def __repr__(self) -> str:
        return (f"RateLimiter(간격={self.min_interval}초, "
                f"호출 {self.call_count}회, 총 대기 {self.total_waited:.2f}초)")


if __name__ == "__main__":
    print("--- 간격 없이 (❌ 서버에 부담) ---")
    start = time.monotonic()
    for i in range(5):
        time.sleep(0.05)                       # 요청 처리 시간 흉내
        print(f"  요청 {i + 1}  경과 {time.monotonic() - start:.2f}초")

    print("\n--- 1초 간격 (✅) ---")
    limiter = RateLimiter(min_interval=1.0)
    start = time.monotonic()
    for i in range(5):
        waited = limiter.wait()
        time.sleep(0.05)
        print(f"  요청 {i + 1}  대기 {waited:.2f}초  경과 {time.monotonic() - start:.2f}초")
    print(f"  {limiter}")

    print("\n--- 요청이 오래 걸리면 추가 대기가 줄어듭니다 ---")
    limiter = RateLimiter(min_interval=1.0)
    start = time.monotonic()
    for i, work in enumerate([0.05, 0.8, 1.5, 0.1], start=1):
        waited = limiter.wait()
        time.sleep(work)                       # 요청이 work 초 걸렸다고 가정
        print(f"  요청 {i}  처리 {work:.2f}초  대기 {waited:.2f}초  "
              f"경과 {time.monotonic() - start:.2f}초")

### Step 3. 재시도와 지수 백오프

`retry.py` 를 만듭니다.

```python
"""지수 백오프 재시도."""

import logging
import random
import time
from typing import Callable, TypeVar

import requests

logger = logging.getLogger(__name__)

T = TypeVar("T")

RETRYABLE_STATUS = {408, 429, 500, 502, 503, 504}


def should_retry_status(status: int) -> bool:
    """이 상태 코드는 재시도할 가치가 있는가."""
    return status in RETRYABLE_STATUS


def backoff_delay(attempt: int, base: float = 1.0, cap: float = 30.0,
                  jitter: bool = True) -> float:
    """n번째 시도 후 대기 시간 (지수 백오프 + 지터)."""
    delay = min(base * (2 ** (attempt - 1)), cap)
    if jitter:
        delay *= 0.5 + random.random()          # 50%~150%
    return delay


def request_with_retry(
    session: requests.Session,
    url: str,
    max_attempts: int = 3,
    timeout: float = 10.0,
    base_delay: float = 1.0,
    **kwargs,
) -> requests.Response | None:
    """재시도를 포함한 GET 요청. 실패하면 None."""
    for attempt in range(1, max_attempts + 1):
        try:
            r = session.get(url, timeout=timeout, **kwargs)
        except (requests.Timeout, requests.ConnectionError) as e:
            if attempt == max_attempts:
                logger.error("최종 실패 %s — %s", url, type(e).__name__)
                return None
            delay = backoff_delay(attempt, base_delay)
            logger.warning("네트워크 오류 (%d/%d) %s — %.1f초 후 재시도",
                           attempt, max_attempts, type(e).__name__, delay)
            time.sleep(delay)
            continue

        if r.ok:
            if attempt > 1:
                logger.info("재시도 성공 (%d회차) %s", attempt, url)
            return r

        if not should_retry_status(r.status_code):
            logger.error("재시도 불가 상태 %d — %s", r.status_code, url)
            return None                          # 4xx: 즉시 포기

        if attempt == max_attempts:
            logger.error("최종 실패 HTTP %d — %s", r.status_code, url)
            return None

        # 429 는 서버가 알려 준 대기 시간을 우선
        retry_after = r.headers.get("Retry-After")
        delay = float(retry_after) if retry_after and retry_after.isdigit() \
            else backoff_delay(attempt, base_delay)

        logger.warning("HTTP %d (%d/%d) — %.1f초 후 재시도",
                       r.status_code, attempt, max_attempts, delay)
        time.sleep(delay)

    return None


if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO,
                        format="  %(levelname)-8s %(message)s")

    print("--- 백오프 대기 시간 (지터 없음) ---")
    for attempt in range(1, 7):
        print(f"  {attempt}회차 실패 후: {backoff_delay(attempt, jitter=False):>6.1f}초")

    print("\n--- 지터 적용 (3회 반복) ---")
    for _ in range(3):
        delays = [f"{backoff_delay(a):.2f}" for a in range(1, 5)]
        print(f"  {delays}")

    print("\n--- 상태 코드별 재시도 판단 ---")
    for code in (200, 400, 404, 408, 429, 500, 503):
        mark = "재시도" if should_retry_status(code) else "포기"
        print(f"  {code}: {mark}")

    print("\n--- 실제 요청 (로컬 모의 서버 필요) ---")
    with requests.Session() as s:
        s.headers.update({"User-Agent": "MLOpsStudyBot/1.0"})
        r = request_with_retry(s, "http://127.0.0.1:8000/api/stations",
                               max_attempts=4, base_delay=0.5,
                               params={"page": 1, "size": 3})
        if r:
            items = r.json()["response"]["body"]["items"]
            print(f"  ✓ {len(items)}건 수신")
        else:
            print("  ✗ 실패 (mock_server.py 가 실행 중인지 확인하세요)")
```

### Step 4. 예의 바른 크롤러

`polite_crawler.py` 를 만듭니다. **오늘 배운 것을 전부 합칩니다.**

```python
"""robots.txt 준수 · 간격 제어 · 재시도가 들어간 크롤러."""

import json
import logging
import time
from dataclasses import dataclass, field
from pathlib import Path
from urllib.parse import urljoin, urlparse
from urllib.robotparser import RobotFileParser

import requests
from bs4 import BeautifulSoup

from rate_limiter import RateLimiter
from retry import request_with_retry

logger = logging.getLogger(__name__)


class CrawlBlocked(Exception):
    """robots.txt 등에 의해 수집이 금지됨."""


@dataclass
class CrawlConfig:
    user_agent: str = "MLOpsStudyBot/1.0 (교육용 수집; hong@example.com)"
    min_interval: float = 1.0
    max_pages: int = 50
    max_attempts: int = 3
    timeout: float = 10.0
    respect_robots: bool = True
    state_file: Path = field(default=Path("crawl_state.json"))


@dataclass
class CrawlStats:
    pages_fetched: int = 0
    items_collected: int = 0
    duplicates: int = 0
    failures: int = 0
    total_wait: float = 0.0
    elapsed: float = 0.0


class PoliteCrawler:
    """예의 바른 크롤러.

    - robots.txt 를 확인하고 금지된 경로는 수집하지 않습니다
    - Crawl-delay 가 있으면 그 값을 따릅니다
    - 요청 간격을 보장합니다
    - 실패 시 지수 백오프로 재시도합니다
    - 중복을 제거하고 진행 상황을 저장합니다
    """

    def __init__(self, base_url: str, config: CrawlConfig | None = None):
        self.base_url = base_url
        self.config = config or CrawlConfig()
        self.stats = CrawlStats()

        self.session = requests.Session()
        self.session.headers.update({"User-Agent": self.config.user_agent})

        self.seen: set[str] = set()
        self.records: list[dict] = []
        self.failures: list[dict] = []

        self._rp: RobotFileParser | None = None
        self._setup_robots()

        interval = self.config.min_interval
        if self._rp:
            delay = self._rp.crawl_delay(self.config.user_agent)
            if delay and delay > interval:
                logger.info("robots.txt 의 Crawl-delay %.1f초를 따릅니다", delay)
                interval = float(delay)
        self.limiter = RateLimiter(min_interval=interval, jitter=0.3)

    # ---------- robots ----------

    def _setup_robots(self) -> None:
        if not self.config.respect_robots:
            logger.warning("robots.txt 확인이 꺼져 있습니다 — 권장하지 않습니다")
            return

        parsed = urlparse(self.base_url)
        robots_url = f"{parsed.scheme}://{parsed.netloc}/robots.txt"
        rp = RobotFileParser()
        rp.set_url(robots_url)
        try:
            rp.read()
            self._rp = rp
            logger.info("robots.txt 확인 완료: %s", robots_url)
        except Exception as e:
            logger.warning("robots.txt 를 읽지 못했습니다 (%s) — 보수적으로 진행합니다", e)

    def can_fetch(self, url: str) -> bool:
        if self._rp is None:
            return True
        return self._rp.can_fetch(self.config.user_agent, url)

    # ---------- 수집 ----------

    def fetch(self, url: str, **params) -> requests.Response | None:
        if not self.can_fetch(url):
            raise CrawlBlocked(f"robots.txt 가 금지한 경로입니다: {url}")

        waited = self.limiter.wait()
        self.stats.total_wait += waited

        r = request_with_retry(
            self.session, url,
            max_attempts=self.config.max_attempts,
            timeout=self.config.timeout,
            params=params or None,
        )
        if r is None:
            self.stats.failures += 1
            self.failures.append({"url": url, "params": params})
            return None

        self.stats.pages_fetched += 1
        return r

    def parse_list(self, html: str, page_url: str) -> list[dict]:
        """목록 페이지에서 레코드를 추출합니다. 사이트에 맞게 오버라이드하세요."""
        soup = BeautifulSoup(html, "html.parser")
        records = []

        for li in soup.select("li.news-item:not(.ad)"):
            link = li.select_one("a.title")
            if link is None:
                continue
            href = link.get("href", "")
            if not href.startswith("/news"):
                continue

            def text_of(sel: str, default: str = "") -> str:
                found = li.select_one(sel)
                return found.get_text(strip=True) if found else default

            records.append({
                "id": link.get("data-id"),
                "title": link.get_text(strip=True),
                "url": urljoin(page_url, href),
                "date": text_of("span.date"),
                "category": text_of("span.category", "미분류"),
                # 본문은 저장하지 않습니다 — 저작권 (③ 참고)
            })
        return records

    def crawl(self, list_path: str = "/list") -> list[dict]:
        """페이지네이션을 따라 수집합니다."""
        start = time.monotonic()
        list_url = urljoin(self.base_url, list_path)

        for page in range(1, self.config.max_pages + 1):
            r = self.fetch(list_url, page=page)
            if r is None:
                logger.error("%d페이지 수집 실패 — 중단", page)
                break

            items = self.parse_list(r.text, r.url)
            if not items:
                logger.info("%d페이지가 비어 있습니다 — 정상 종료", page)
                break

            new = 0
            for item in items:
                if item["url"] in self.seen:
                    self.stats.duplicates += 1
                    continue
                self.seen.add(item["url"])
                self.records.append(item)
                new += 1

            self.stats.items_collected += new
            logger.info("%d페이지 — 신규 %d건 / 전체 %d건 (누적 %d건)",
                        page, new, len(items), len(self.records))

            if new == 0:
                logger.info("신규 항목이 없습니다 — 종료")
                break
        else:
            logger.warning("최대 페이지(%d) 도달 — 데이터가 더 있을 수 있습니다",
                           self.config.max_pages)

        self.stats.elapsed = time.monotonic() - start
        return self.records

    # ---------- 리포트 ----------

    def report(self) -> None:
        s = self.stats
        print("\n" + "=" * 54)
        print("수집 리포트")
        print("=" * 54)
        print(f"  페이지 요청     : {s.pages_fetched}회")
        print(f"  수집 항목       : {s.items_collected}건")
        print(f"  중복 제외       : {s.duplicates}건")
        print(f"  실패            : {s.failures}건")
        print(f"  총 대기 시간    : {s.total_wait:.1f}초")
        print(f"  총 소요 시간    : {s.elapsed:.1f}초")
        if s.elapsed > 0:
            print(f"  평균 요청 속도  : {s.pages_fetched / s.elapsed:.2f}회/초")
        print(f"  {self.limiter}")

        if self.failures:
            print(f"\n  [실패 목록]")
            for f in self.failures[:5]:
                print(f"    {f['url']} {f['params']}")

    def save(self, path: Path = Path("data/crawled.json")) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(
            json.dumps(self.records, ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        print(f"\n  저장: {path} ({len(self.records)}건)")


if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO,
                        format="  %(levelname)-8s %(message)s")

    crawler = PoliteCrawler(
        "http://127.0.0.1:8001",
        CrawlConfig(min_interval=0.5, max_pages=10),
    )

    try:
        crawler.crawl("/list")
    except CrawlBlocked as e:
        print(f"\n✗ 수집 중단: {e}")
    else:
        crawler.report()
        crawler.save()

### Step 5. 적법성 점검표

`legal_check.py` 를 만듭니다. **과제로 제출할 점검표를 생성합니다.**

```python
"""수집 대상 적법성 점검표 생성기."""

import sys
from datetime import datetime
from pathlib import Path
from urllib.parse import urlparse

from check_robots import check

QUESTIONS = [
    ("robots.txt", "robots.txt 에서 해당 경로가 금지되어 있지 않은가?", True),
    ("이용약관", "이용약관에 '크롤링/자동수집/스크래핑' 금지 조항이 없는가?", True),
    ("개인정보", "수집 데이터에 개인정보(이름·연락처·주소·아이디)가 **포함되지 않는가**?", True),
    ("저작권", "기사 본문·이미지·음원 등 저작물을 복제하지 **않는가**?", True),
    ("로그인", "로그인 없이 접근 가능한 공개 페이지인가?", True),
    ("공식 API", "공식 API가 없거나, 있다면 API를 사용하는가?", True),
    ("요청 부하", "요청 간격 1초 이상, 총 요청 수가 합리적인가?", True),
    ("사용 목적", "개인 학습·연구 목적이며 상업적 재배포를 하지 않는가?", True),
    ("출처 표기", "README에 데이터 출처와 수집 일시를 표기할 것인가?", True),
]


def make_checklist(url: str, purpose: str = "교육 과정 실습") -> str:
    parsed = urlparse(url)
    robots = check(url)

    lines = [
        f"# 수집 대상 적법성 점검표",
        "",
        f"| 항목 | 내용 |",
        f"|---|---|",
        f"| 대상 사이트 | {parsed.netloc} |",
        f"| 대상 URL | {url} |",
        f"| 수집 목적 | {purpose} |",
        f"| 점검 일시 | {datetime.now():%Y-%m-%d %H:%M} |",
        f"| 점검자 | (이름을 적으세요) |",
        "",
        "## 자동 확인 결과",
        "",
        f"| 항목 | 결과 |",
        f"|---|---|",
        f"| robots.txt 존재 | {'있음' if robots['exists'] else '없음'} |",
        f"| 해당 경로 허용 | {robots['allowed'] if robots['allowed'] is not None else '판단 불가'} |",
        f"| Crawl-delay | {robots['crawl_delay'] or '명시 없음 (1초 이상 권장)'} |",
        "",
        "## 점검 항목 (전부 ✅ 여야 수집 가능)",
        "",
        "| # | 항목 | 확인 질문 | 결과 | 근거·비고 |",
        "|---|---|---|---|---|",
    ]

    for i, (name, question, _) in enumerate(QUESTIONS, start=1):
        lines.append(f"| {i} | {name} | {question} | ⬜ | |")

    lines += [
        "",
        "## 수집 계획",
        "",
        "| 항목 | 값 |",
        "|---|---|",
        "| 수집 필드 | (예: 제목, URL, 발행일, 카테고리 — **본문 제외**) |",
        "| 요청 간격 | 1.0초 |",
        "| 최대 페이지 | 50 |",
        "| 예상 총 요청 수 | 50회 |",
        "| 수집 시간대 | (트래픽이 적은 시간 권장) |",
        "| 저장 형식 | CSV / JSON |",
        "| 보관 기간 | 과정 종료 시 삭제 |",
        "",
        "## 결론",
        "",
        "- [ ] 위 항목이 **모두 ✅** 이므로 수집을 진행합니다",
        "- [ ] 하나라도 ❌ 이므로 **수집하지 않습니다** (대체 데이터: ______)",
        "",
        "## 출처 표기 문구 (README에 넣을 것)",
        "",
        "```markdown",
        f"## 데이터 출처",
        "",
        f"- 출처: {parsed.netloc}",
        f"- URL: {url}",
        f"- 수집 일시: {datetime.now():%Y-%m-%d}",
        f"- 수집 범위: 제목·링크·발행일 등 메타데이터 (본문 미포함)",
        f"- 이용 조건: (해당 사이트의 이용약관·라이선스를 확인해 적으세요)",
        f"- 개인정보 포함 여부: 없음",
        "```",
    ]

    return "\n".join(lines)


if __name__ == "__main__":
    url = sys.argv[1] if len(sys.argv) > 1 else "https://www.data.go.kr/"
    content = make_checklist(url)

    out = Path("docs/legal_check.md")
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(content, encoding="utf-8")

    print(content)
    print(f"\n\n저장: {out}")
```

### `429 Too Many Requests` 를 받고 계속 요청

```
429 Too Many Requests
Retry-After: 60
```

**원인** — 간격 없이 반복 호출했습니다.
**해결** — `Retry-After` 헤더를 **반드시 존중**하세요.

```python
if r.status_code == 429:
    wait = int(r.headers.get("Retry-After", 60))
    logger.warning("요청 제한 — %d초 대기", wait)
    time.sleep(wait)
```

무시하고 계속 보내면 **일시 차단이 영구 차단**이 됩니다.

### IP가 차단되어 브라우저로도 접속이 안 됨

**원인** — 간격 없이 대량 요청했습니다. 공용 네트워크라면 **학원·회사 전체가 막힙니다.**
**해결** — 즉시 중단하고, 사이트에 문의하세요. **우회하지 마세요.**
프록시·VPN으로 우회하면 **고의성이 인정**됩니다.

**예방이 유일한 답입니다.** 처음부터 1초 이상 간격을 두세요.

### 무한 루프로 같은 페이지를 계속 요청

```python
page = 1
while True:
    items = fetch(page)
    if not items:
        break
    page += 1              # 이 줄을 빠뜨리면?
```

**원인** — 종료 조건이 없거나 페이지 번호가 안 늘어납니다.
**해결** — **안전장치를 반드시** 두세요.

```python
for page in range(1, MAX_PAGES + 1):      # 상한이 구조적으로 보장됨
    ...
```

그리고 **"신규 항목이 0건이면 종료"** 조건도 추가하세요.
사이트가 마지막 페이지 이후에도 같은 내용을 반복해서 주는 경우가 있습니다.

### robots.txt를 확인하지 않고 수집

**원인** — 확인 절차를 건너뛰었습니다.
**해결** — 수집기 **코드 안에** 확인을 넣으세요. 잊어버릴 수 없게 됩니다.

```python
if not self.can_fetch(url):
    raise CrawlBlocked(f"robots.txt 가 금지한 경로: {url}")
```

Step 4의 `PoliteCrawler` 가 그렇게 만들어졌습니다.

### 기사 본문을 통째로 저장

```python
record["body"] = article.select_one(".article-body").get_text()      # ⚠
```

**원인** — 편의를 위해 전부 저장했습니다.
**문제** — 기사 본문은 **저작물**입니다. 저장·재배포는 침해가 될 수 있습니다.
**해결** — 필요한 최소한만 저장하세요.

```python
record["title"] = ...       # 제목 — 통상 문제없음
record["url"] = ...         # 링크 — 안전
record["published"] = ...   # 날짜 — 사실 정보
record["summary"] = body[:200]      # 짧은 인용 (그래도 신중히)
```

**분석에 본문이 꼭 필요하다면** 공개 데이터셋(AI Hub·Kaggle)이나
라이선스가 명시된 코퍼스를 쓰세요.

### 개인정보가 포함된 줄 모르고 수집

```

**원인** — 게시판·리뷰·댓글에는 대개 개인정보가 섞여 있습니다.
**해결** — 수집 **전에** 필드를 확인하고, 개인정보 필드는 **아예 수집하지 마세요.**

def mask_email(email: str) -> str:

    return f"{user[:2]}***@{domain}"

headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ..."}

**문제** — 차단당한 뒤 이걸로 우회하면 **회피 의도**가 명확해집니다.

**해결** — 상태를 저장하세요.

state = {"last_page": page, "seen": sorted(seen)}
Path("crawl_state.json").write_text(json.dumps(state), encoding="utf-8")
```

## ⑥ 확인 문제

**1.** `robots.txt` 에 `Disallow` 가 없다면 자유롭게 수집해도 되나요? 왜 그런지 설명하세요.

<details>
<summary>답 보기</summary>

**아닙니다.** `robots.txt` 는 **최소 조건이지 충분 조건이 아닙니다.**

`robots.txt` 는 "검색 엔진 크롤러에게 보내는 안내"로 만들어진 것입니다.
**법적 효력을 가진 계약서가 아닙니다.** 별도로 적용되는 것들이 있습니다.

**① 이용약관**

많은 사이트가 약관에 명시합니다.

> "회원은 자동화된 수단(로봇, 스파이더, 스크래퍼 등)을 이용하여 서비스에 접근할 수 없습니다."

**약관은 계약입니다.** 서비스를 이용하는 순간 동의한 것으로 간주됩니다.
`robots.txt` 에 아무 말이 없어도 약관이 금지하면 **위반입니다.**

**② 저작권법**

기사 본문·사진·음원은 저작물입니다. `robots.txt` 와 무관하게 **복제·배포가 제한**됩니다.

**③ 개인정보보호법**

이름·연락처·아이디가 포함된 데이터는 **공개돼 있어도** 수집·저장이 규제됩니다.
"인터넷에 공개돼 있으니 괜찮다"는 흔한 오해입니다.

**④ 정보통신망법 (업무방해)**

과도한 요청으로 서비스에 장애를 일으키면 **형사 문제**가 됩니다.
`robots.txt` 가 허용해도 초당 100회를 보내면 안 됩니다.

**⑤ 데이터베이스제작자의 권리**

DB의 상당 부분을 복제하면 별도의 권리를 침해할 수 있습니다.

**올바른 판단 순서**

```
1. 공식 API가 있는가?         → 있으면 무조건 API
2. robots.txt 확인            → 금지면 중단
3. 이용약관 확인              → 크롤링 금지 조항 검색
4. 수집 데이터에 개인정보?      → 있으면 중단 또는 필드 제외
5. 저작물을 복제하는가?         → 메타데이터만 수집
6. 요청 부하는 적절한가?        → 1초 이상 간격
7. 출처 표기 계획              → README에 명시
```

**`robots.txt` 는 이 중 하나일 뿐입니다.**

Step 5의 점검표가 이 7단계를 문서로 만든 것이고,
**이 과정의 모든 프로젝트에서 제출 요건**입니다.
</details>

**2.** 아래 코드의 문제점을 세 가지 이상 찾고, 각각 어떻게 고쳐야 하는지 설명하세요.

```python
import requests
from bs4 import BeautifulSoup

page = 1
while True:
    r = requests.get(f"https://news.example.com/list?page={page}")
    soup = BeautifulSoup(r.text, "html.parser")
    for a in soup.select("a.title"):
        print(a.text)
    page += 1
```

<details>
<summary>답 보기</summary>

**① 종료 조건이 없음 — 무한 루프**

`while True` 인데 `break` 가 없습니다. 페이지가 끝나도 계속 요청합니다.
사이트가 마지막 이후에도 200을 주면 **영원히 돕니다.**

```python
MAX_PAGES = 50
for page in range(1, MAX_PAGES + 1):
    items = soup.select("a.title")
    if not items:
        break
```

**두 겹의 안전장치**가 필요합니다. `range` 로 상한을 두고, 빈 결과에서 `break`.

**② 요청 간격이 없음**

초당 수십 회를 보냅니다. **차단당하거나 서버에 장애를 일으킵니다.**

```python
time.sleep(1.0)          # 최소한
```

더 좋게는 `RateLimiter` 로 요청 시간까지 고려합니다.

**③ robots.txt 를 확인하지 않음**

금지된 경로를 긁고 있을 수 있습니다.

```python
rp = RobotFileParser()
rp.set_url("https://news.example.com/robots.txt")
rp.read()
if not rp.can_fetch(USER_AGENT, url):
    raise CrawlBlocked(url)
```

**④ 타임아웃이 없음**

서버가 응답을 안 주면 **영원히 멈춥니다** ([Day 016](day-016.md)).

```python
requests.get(url, timeout=10)
```

**⑤ 상태 코드를 확인하지 않음**

404·500이어도 그대로 파싱합니다. 에러 페이지를 파싱하면 조용히 0건이 됩니다.

```python
r.raise_for_status()
```

**⑥ User-Agent 를 지정하지 않음**

`python-requests/2.32.3` 로 나갑니다. 차단 대상이 되기 쉽고, 정체가 불분명합니다.

**⑦ Session 을 쓰지 않음**

매 요청마다 TCP 연결을 새로 맺어 **느리고 서버 부담이 큽니다**.

**⑧ 예외 처리가 없음**

네트워크 오류 하나로 전체가 중단됩니다.

**⑨ 결과를 저장하지 않음**

`print` 만 하고 끝납니다. 프로그램이 끝나면 사라집니다.

**전부 고친 형태**가 Step 4의 `PoliteCrawler` 입니다.
</details>

<summary>답 보기</summary>

| **발행일시** | ⭕ | 사실 정보. 저작권 대상 아님 |
| **카테고리** | ⭕ | 사실 정보 |
| **언론사명** | ⭕ | 오히려 **출처 표기에 필요** |
| **조회수·댓글 수** | ⭕ | 숫자 사실 |
| **기사 본문** | ❌ | **저작물**. 복제·저장은 침해 소지 |
| **사진·이미지** | ❌ | 저작물. 별도 권리자가 있을 수도 |
| **기자 이름** | ⚠ | **개인정보**. 꼭 필요하지 않으면 제외 |

**핵심 원칙 세 가지**

**① 최소 수집 (data minimization)**

분석 목적에 **꼭 필요한 것만** 수집합니다.
"나중에 쓸지도 모르니 다 받아 두자"는 가장 위험한 태도입니다.

목적이 "카테고리별 기사 수 추이 분석"이라면 **제목·날짜·카테고리면 충분**합니다.

**② 사실 vs 표현**

저작권은 **표현**을 보호하고 **사실**은 보호하지 않습니다.

| 사실 (자유) | 표현 (보호) |
|---|---|
| 기온 27도 | 기온을 묘사한 문장 |
| 발행일 2026-08-12 | 기사 본문 |
| 조회수 1,204 | 사진 |

**③ 본문이 꼭 필요하다면**

- 공개 데이터셋을 쓰세요 (AI Hub 뉴스 코퍼스, Kaggle)
- 언론사의 **공식 API·RSS**를 확인하세요 (요약 제공)
- CC 라이선스가 명시된 출처를 찾으세요
- 정말 필요하면 **저작권자에게 문의**하세요

**실무 저장 예시**

```python
record = {
    "title": link.get_text(strip=True),
    "url": urljoin(base, link.get("href", "")),
    "published_at": text_of(li, ".date"),
    "category": text_of(li, ".category", "미분류"),
    "publisher": text_of(li, ".press"),
    "collected_at": datetime.now().isoformat(),
    # body, image, author, comments 는 수집하지 않습니다
}
```

**README에 반드시 표기**

```markdown
## 데이터 출처

- 출처: 예시뉴스 (news.example.com)
- 수집 범위: 제목·링크·발행일·카테고리 (**본문 미포함**)
- 수집 일시: 2026-08-12
- 요청 간격: 1초, 총 50회
- robots.txt 준수 여부: 확인 완료 (허용)
- 개인정보 포함 여부: 없음
- 이용 조건: 개인 학습 목적, 재배포하지 않음
```

**이 표기가 MP1부터 최종 프로젝트까지 모든 제출물의 통과 요건입니다.**
Step 5의 점검표가 이 문구를 자동으로 만들어 줍니다.
</details>

## 오늘의 정리

| 항목 | 내용 |
|---|---|
| robots.txt | `사이트/robots.txt` · `RobotFileParser` · **최소 조건이지 충분 조건 아님** |
| 요청 간격 | **1초 이상** · `Crawl-delay` 가 있으면 그 값 · 요청 시간 고려 |
| 백오프 | `base * 2**(attempt-1)` + 지터 · 상한(cap) 설정 |
| 재시도 대상 | 408·429·5xx ⭕ · 4xx ❌ (즉시 포기) |
| `Retry-After` | 429에서 서버가 알려 준 시간을 **반드시 존중** |
| User-Agent | **정체와 연락처를 밝히기** — 위장 회피는 고의성 증거 |
| 페이지네이션 | `range(1, MAX+1)` + 빈 결과 `break` — **두 겹 안전장치** |
| 중복 방지 | `set` 으로 URL 관리 |
| 재개 | 진행 상황을 파일에 저장 |
| 개인정보 | **수집하지 않음** — 이름·연락처·아이디·주소 |
| 저작권 | 본문·이미지 저장 금지 · **메타데이터만** |
| 우선순위 | **공식 API > RSS > 크롤링** |
| 필수 절차 | 점검표 작성 → 수집 → README에 출처 표기 |

**과제** — 수집하려는 사이트를 하나 정하고 **적법성 점검표**를 완성해 제출하세요.
① `legal_check.py` 로 초안을 생성하고 **9개 항목을 직접 채우기** (근거를 구체적으로)
② robots.txt 원문에서 해당 경로 관련 부분을 인용
③ 이용약관에서 자동화 관련 조항을 찾아 인용 (없으면 "확인했으나 없음"이라고 명시)
④ 수집할 필드 목록과 **제외하는 필드와 그 이유**를 표로 작성
⑤ 결론: 수집 진행 또는 중단 — **중단이라면 대체 데이터를 제시**

> 하나라도 ❌ 가 나오면 **수집하지 않는 것이 정답입니다.**
> 공공데이터포털·서울열린데이터광장·Kaggle에는 안전한 대체 데이터가 충분히 있습니다.
