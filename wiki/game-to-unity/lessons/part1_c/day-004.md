## 1. 오늘 만드는 것

**화면 출력은 어제와 완전히 똑같다.** 대신 `main` 함수가 20줄 아래로 줄어든다.

```c
int main(void)
{
    int heroHp  = MAX_HERO_HP;
    int slimeHp = MAX_SLIME_HP;

    PrintStatus(heroHp, slimeHp);           // 상태 출력

    int choice = SelectAction();            // 행동 선택
    int damage = CalcDamage(20, SLIME_DEF); // 데미지 계산
    slimeHp = ApplyDamage(slimeHp, damage); // 데미지 적용

    // ...
    return 0;
}
```

> 오늘의 결과물은 **눈에 보이지 않는다.** 화면은 그대로인데 코드만 바뀐다.
> 이런 작업을 **리팩터링(refactoring)** 이라고 한다. 동작을 바꾸지 않고 구조만 개선하는 것.

## 2. 막히는 상황

어제 코드에서 상태를 출력하는 부분을 세어 보자.

```c
    // 전투 시작할 때
    printf("  용사    HP %3d / %3d\n", heroHp, MAX_HERO_HP);
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);

    // 공격한 뒤에
    printf("  용사    HP %3d / %3d\n", heroHp, MAX_HERO_HP);
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);

    // 반격당한 뒤에
    printf("  용사    HP %3d / %3d\n", heroHp, MAX_HERO_HP);
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);
```

**같은 코드가 세 군데 있다.** 여기서 체력 바를 추가하고 싶어졌다.
세 군데를 다 고쳐야 하는데, 한 군데를 빠뜨린다. 그리고 실행하면 화면이 제각각이 된다.

```
   지금:  같은 일 = 같은 코드 세 벌
          ┌─────────┐  ┌─────────┐  ┌─────────┐
          │ 상태출력 │  │ 상태출력 │  │ 상태출력 │
          └─────────┘  └─────────┘  └─────────┘
             수정 O       수정 O       수정 X  ← 여기서 버그

   필요:  같은 일 = 코드 한 벌 + 세 번 호출
                    ┌─────────┐
          ┌────────▶│ 상태출력 │◀────────┐
          │         └─────────┘         │
          │              ▲              │
       호출 1         호출 2          호출 3      ← 고칠 곳은 한 군데
```

> **한 번 쓰고 여러 번 부르는 방법이 필요하다.** → **함수**

## 3. 개념

### 3-1. 함수 — 이름 붙인 코드 덩어리

**왜 필요한가** — 같은 일을 하는 코드를 한 군데로 모아 두면, 고칠 곳도 한 군데다.

```c
반환형 함수이름(매개변수 목록)
{
    // 하는 일
    return 반환값;
}
```

```c
void PrintStatus(int heroHp, int slimeHp)
{
    printf("  용사    HP %3d / %3d\n", heroHp,  MAX_HERO_HP);
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);
}
```

**호출**

```c
PrintStatus(100, 30);          // 값을 넣어 부른다
PrintStatus(heroHp, slimeHp);  // 변수를 넣어도 된다
```

### 3-2. 매개변수와 반환값 — 함수의 입구와 출구

**왜 필요한가** — 함수가 밖의 값을 받고(입구), 결과를 돌려줘야(출구) 쓸모가 있다.

```
                    ┌──────────────────────────┐
   atk = 20  ──────▶│                          │
   def =  3  ──────▶│      CalcDamage()        │──────▶  17
                    │  damage = atk - def      │
                    │  if (damage < 1) = 1     │
                    └──────────────────────────┘
      매개변수(입구)         하는 일              반환값(출구)
```

```c
int CalcDamage(int attack, int defense)
{
    int damage = attack - defense;

    if (damage < 1)
        damage = 1;

    return damage;        // 계산 결과를 밖으로 돌려준다
}

// 사용
int dmg = CalcDamage(20, 3);     // dmg == 17
```

**반환형 `void`** — 돌려줄 값이 없을 때

```c
void PrintTitle(void)        // 받는 것도 없고 돌려주는 것도 없다
{
    printf("=== 전투 시작 ===\n");
}
```

| 반환형 | 뜻 | 예 |
|---|---|---|
| `int` | 정수를 돌려준다 | `CalcDamage` |
| `float` | 실수를 돌려준다 | `GetRatio` |
| `void` | 아무것도 안 돌려준다 | `PrintStatus` |

> `return`을 만나면 **그 즉시 함수가 끝난다.** 아래 코드는 실행되지 않는다.
>
> ```c
> int CalcDamage(int atk, int def)
> {
>     if (atk <= def) return 1;      // 여기서 끝. 아래로 안 내려간다
>     return atk - def;
> }
> ```

### 3-3. 함수 원형 선언 — "이런 함수가 있다"고 미리 알려주기

**왜 필요한가** — C는 위에서 아래로 읽는다. `main` 아래에 정의된 함수를 `main`에서 부르면 모른다고 한다.

```c
#include <stdio.h>

// ✘ 오류: main이 PrintStatus를 모른다
int main(void)
{
    PrintStatus(100, 30);        // error C3861: 'PrintStatus': 식별자를 찾을 수 없습니다
    return 0;
}

void PrintStatus(int a, int b) { /* ... */ }
```

**해결 방법 두 가지**

```c
// 방법 A — 함수를 main 위에 정의한다
void PrintStatus(int a, int b) { /* ... */ }

int main(void) { PrintStatus(100, 30); return 0; }
```

```c
// 방법 B — 원형(prototype)만 위에 선언한다  ★ 권장
void PrintStatus(int heroHp, int slimeHp);      // 선언 — 몸통 없이 세미콜론
int  CalcDamage(int attack, int defense);

int main(void)
{
    PrintStatus(100, 30);
    return 0;
}

void PrintStatus(int heroHp, int slimeHp)       // 정의 — 몸통 있음
{
    /* ... */
}
```

```
   ┌────────────────────────────────────┐
   │  #include                          │
   │  #define                           │
   │                                    │
   │  함수 원형 선언들   ← "이런 함수들이 있다"
   │                                    │
   │  int main() { ... }  ← 읽기 시작점을 위로
   │                                    │
   │  함수 정의들        ← 실제 내용은 아래에
   └────────────────────────────────────┘
```

> **방법 B를 쓴다.** `main`이 위에 있어야 프로그램의 흐름이 먼저 보인다.
> 나중에 파일을 나눌 때(`.h` / `.c`) 이 구조가 그대로 헤더 파일이 된다.

### 3-4. 지역 변수와 유효 범위 — 함수 안에서 바꾼 값이 밖에 안 남는다

**왜 필요한가** — 오늘 반드시 겪게 될 현상이다. 지금은 원리만 알고, 해결은 Day 18에서 한다.

```c
void Heal(int hp)
{
    hp = hp + 20;                    // 여기서 hp는 120이 된다
    printf("함수 안: %d\n", hp);     // 120
}

int main(void)
{
    int heroHp = 100;
    Heal(heroHp);
    printf("함수 밖: %d\n", heroHp); // 100 — 안 바뀌었다!
    return 0;
}
```

```
   main 의 heroHp                 Heal 의 hp
   ┌──────────┐    값을 복사     ┌──────────┐
   │   100    │ ──────────────▶ │   100    │
   └──────────┘                  └──────────┘
        ▲                             │ +20
        │                             ▼
        │                        ┌──────────┐
        └── 아무 일도 안 일어남    │   120    │  ← 이 사본만 바뀐다
                                  └──────────┘
                                       │
                                  함수가 끝나면 사라진다
```

**이것을 값에 의한 전달(call by value)** 이라고 한다.

| 구분 | 설명 |
|---|---|
| **지역 변수** | 함수 안(`{ }` 안)에서 선언된 변수. 함수가 끝나면 사라진다 |
| **유효 범위(scope)** | 그 변수를 쓸 수 있는 구간. 선언된 `{ }` 안 |
| **값 전달** | 함수에 값을 넘기면 **사본**이 만들어진다 |

> **오늘은 이 벽을 그냥 인정하고 넘어간다.**
> 해결책은 `return`으로 결과를 받아오는 것이다. 근본적인 해결(포인터)은 **Day 18**.
>
> ```c
> int Heal(int hp) { return hp + 20; }        // 결과를 돌려주고
> heroHp = Heal(heroHp);                       // 받아서 다시 넣는다  ✔
> ```

### 3-5. 좋은 함수의 조건

**왜 필요한가** — 함수로 나누기만 하면 되는 게 아니다. 잘못 나누면 더 읽기 어려워진다.

| 조건 | 설명 | 나쁜 예 → 좋은 예 |
|---|---|---|
| **하나의 일만** | 함수 이름을 "~하고 ~한다"로 설명해야 하면 나눠야 한다 | `DoBattle()` → `CalcDamage()` + `PrintStatus()` |
| **이름이 곧 설명** | 주석 없이 이름만 봐도 무엇을 하는지 안다 | `func1()` → `CalcDamage()` |
| **동사로 시작** | 함수는 행동이다 | `damage()` → `CalcDamage()` |
| **짧게** | 화면 한 눈에 들어오는 길이 (대략 20줄 이내) | |
| **부작용 최소** | 이름에 없는 일을 몰래 하지 않는다 | `GetHp()`가 HP를 깎으면 안 된다 |

## 4. 따라 만들기

### Step 1 — 상태 출력을 함수로

```c
#include <stdio.h>

#define MAX_HERO_HP    100
#define MAX_SLIME_HP    30

void PrintStatus(int heroHp, int slimeHp);       // ← 추가 (원형 선언)

int main(void)
{
    int heroHp  = MAX_HERO_HP;
    int slimeHp = MAX_SLIME_HP;

    PrintStatus(heroHp, slimeHp);                // ← 세 줄이 한 줄로

    return 0;
}

void PrintStatus(int heroHp, int slimeHp)        // ← 추가 (정의)
{
    printf("===============================\n");
    printf("  용사    HP %3d / %3d\n", heroHp,  MAX_HERO_HP);
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);
    printf("===============================\n");
}
```

**✅ 여기까지 실행하면** — Day 3과 **똑같은 상태 화면**이 나온다. 코드만 짧아졌다.

### Step 2 — 데미지 계산을 함수로

```c
int CalcDamage(int attack, int defense);        // ← 원형 추가

// ...

int CalcDamage(int attack, int defense)         // ← 정의 추가
{
    int damage = attack - defense;

    if (damage < 1)
        damage = 1;

    return damage;
}
```

사용:

```c
    int damage = CalcDamage(20, SLIME_DEF);
    printf("슬라임에게 %d 데미지\n", damage);
```

**✅ 여기까지 실행하면** — 데미지 계산 결과가 이전과 동일하다. 최소 1 보장도 그대로 동작한다.

### Step 3 — 데미지 적용을 함수로 (값 전달의 벽 체험)

먼저 **일부러 잘못된 방식**으로 만들어 본다.

```c
void ApplyDamageWrong(int hp, int damage)       // ← void 반환
{
    hp -= damage;
    if (hp < 0) hp = 0;
}
```

```c
    ApplyDamageWrong(slimeHp, damage);
    printf("슬라임 HP: %d\n", slimeHp);     // 30 — 안 바뀐다!
```

**✅ 여기까지 실행하면** — HP가 **전혀 줄지 않는다.** 3-4절에서 배운 그 현상이다.

이제 `return`으로 고친다.

```c
int ApplyDamage(int hp, int damage)             // ← int 반환
{
    hp -= damage;
    if (hp < 0) hp = 0;
    return hp;                                  // ← 결과를 돌려준다
}
```

```c
    slimeHp = ApplyDamage(slimeHp, damage);     // ← 받아서 다시 넣는다
    printf("슬라임 HP: %d\n", slimeHp);         // 21 ✔
```

**✅ 여기까지 실행하면** — HP가 정상적으로 깎인다.

### Step 4 — 행동 선택을 함수로

```c
int SelectAction(void)
{
    printf("\n무엇을 하시겠습니까?\n");
    printf("  1. 공격   2. 방어   3. 도망\n");
    printf("선택: ");

    int choice = 0;
    scanf_s("%d", &choice);

    return choice;
}
```

**✅ 여기까지 실행하면** — 메뉴가 뜨고 선택한 값이 `main`으로 돌아온다.

### Step 5 — 상태 판정도 함수로

```c
void PrintCondition(int hp, int maxHp)
{
    int ratio = hp * 100 / maxHp;

    if (ratio <= 0)       printf("전투불능\n");
    else if (ratio <= 30) printf("빈사\n");
    else if (ratio <= 60) printf("위험\n");
    else                  printf("여유\n");
}
```

**✅ 여기까지 실행하면** — 용사와 슬라임 양쪽에 같은 함수를 써서 상태를 표시할 수 있다.

### Step 6 — 최종 `main`

```c
int main(void)
{
    int heroHp  = MAX_HERO_HP;
    int slimeHp = MAX_SLIME_HP;

    PrintStatus(heroHp, slimeHp);

    int choice = SelectAction();

    if (choice == 1)
    {
        int damage = CalcDamage(HERO_ATK, SLIME_DEF);
        slimeHp = ApplyDamage(slimeHp, damage);

        printf("\n용사의 공격!  슬라임에게 %d 데미지\n", damage);
        PrintStatus(heroHp, slimeHp);
        PrintCondition(slimeHp, MAX_SLIME_HP);
    }

    if (slimeHp > 0)
    {
        int counter = CalcDamage(SLIME_ATK, HERO_DEF);
        heroHp = ApplyDamage(heroHp, counter);

        printf("\n슬라임의 반격!  용사에게 %d 데미지\n", counter);
        PrintStatus(heroHp, slimeHp);
    }

    return 0;
}
```

**✅ 여기까지 실행하면** — Day 3과 화면이 동일하고, `main`은 25줄 안팎이다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `error C3861: 식별자를 찾을 수 없습니다` | 함수 원형 선언 누락, 또는 `main` 아래 정의 | `main` 위에 원형 선언 추가 |
| `error C2371: 재정의` | 원형과 정의의 **반환형·매개변수가 다름** | 두 곳을 똑같이 맞춘다 |
| 함수에서 바꾼 값이 안 남음 | 값 전달(call by value) | `return`으로 받거나 → **Day 18 포인터** |
| `warning C4716: 값을 반환해야 합니다` | `int` 함수인데 `return` 없음 | `return` 추가 |
| 함수 안에서 `main`의 변수를 못 찾음 | 유효 범위 밖 | 매개변수로 넘긴다 |
| 원형에 세미콜론을 빼먹음 | `void Print(int a)` (세미콜론 없음) | `void Print(int a);` |
| 함수가 너무 길어짐 | 여러 일을 한 함수에 몰아넣음 | 더 작게 나눈다 |
| 매개변수 순서를 헷갈림 | `CalcDamage(def, atk)` 처럼 뒤바꿈 | 이름을 명확하게, 호출부 재확인 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| 함수 | 이름 붙인 코드 덩어리. 한 번 쓰고 여러 번 부른다 |
| 매개변수 / 반환값 | 함수의 입구와 출구 |
| `void` | 받지 않거나 돌려주지 않을 때 |
| 원형 선언 | `main` 위에 "이런 함수가 있다"고 미리 알린다 |
| 지역 변수 | 함수 안에서만 살아 있다. 끝나면 사라진다 |
| **값 전달** | 함수는 값의 **사본**을 받는다 → 밖의 값은 안 바뀐다 |
| 좋은 함수 | 하나의 일만, 동사로 시작하는 이름, 짧게 |

### 직접 해보기

| 난이도 | 과제 | 힌트 |
|:--:|---|---|
| ★ | `PrintTitle()` 함수를 만들어 타이틀 출력 분리 | `void`, 매개변수 없음 |
