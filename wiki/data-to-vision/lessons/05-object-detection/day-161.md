- **싱글턴 + `threading.Lock`(이중 검사 잠금)** 으로 모델이 정확히 한 번만 로드되게 만들 수 있다.

- 요청 처리 흐름을 **단계별로 시간을 나눠 측정**하고 로그와 응답에 함께 실을 수 있다.
- **세마포어로 동시 추론 수를 제한**하고 대기 초과 시 **503** 을 돌려줄 수 있다.
- 모델 파일이 없거나 손상됐을 때도 **앱이 뜨고 `/api/health` 가 원인을 알려주게** 만들 수 있다.

### 모델 로드는 얼마나 비싼가

말로 하지 말고 재 보겠습니다.

```python
"""scripts/measure_load.py — 로드 비용 측정"""
import time

import numpy as np

t = [time.perf_counter()]
from ultralytics import YOLO                                  # noqa: E402
t.append(time.perf_counter())

model = YOLO("models/v2.1-yolo11s-960-ep120-cctv_v2-s42.pt")
t.append(time.perf_counter())

kw = dict(imgsz=960, half=True, device=0, verbose=False)
dummy = np.zeros((960, 960, 3), np.uint8)
model.predict(dummy, **kw)                    # ★ 첫 추론
t.append(time.perf_counter())
for _ in range(20):
    model.predict(dummy, **kw)
t.append(time.perf_counter())

print(f"import ultralytics : {(t[1] - t[0]) * 1000:8.0f} ms")
print(f"YOLO() 로드        : {(t[2] - t[1]) * 1000:8.0f} ms")
print(f"첫 추론            : {(t[3] - t[2]) * 1000:8.0f} ms")

```

### 싱글턴 — 왜 `if _INSTANCE is None` 만으로는 부족한가

[Day 152](day-152.md) 의 `get_detector()` 는 이렇게 생겼습니다.

```python
_INSTANCE = None

def get_detector(profile=None, **kw):
    global _INSTANCE
    if _INSTANCE is None:
        _INSTANCE = Detector(**load_profile(profile), **kw)
    return _INSTANCE
```

**단일 스레드에서는 완벽합니다.** 그런데 Flask 개발 서버는 기본이 `threaded=True` 입니다.

```
ms     스레드 A                     스레드 B
────────────────────────────────────────────────────────────
  0    if _INSTANCE is None: True
  1                                 if _INSTANCE is None: True  아직 None
  2    Detector(...) 시작            Detector(...) 시작
2840   _INSTANCE = <A의 모델>
2845                                _INSTANCE = <B의 모델>      ★ 덮어씀

결과 · 모델을 ★ 2번 로드 (5.7초)
     · VRAM 2,240MB (A의 모델은 즉시 해제되지 않음)
     · 서버 기동 직후 동시 접속에서 재현됩니다
```

**★ 해결 — 이중 검사 잠금 (double-checked locking)**

```python
import threading

_LOCK = threading.Lock()
_INSTANCE = None


def get_instance():
    global _INSTANCE
    if _INSTANCE is None:              # ★ ① 락 없이 빠른 검사
        with _LOCK:                    # ★ ② 진짜로 만들 때만 락
            if _INSTANCE is None:      # ★ ③ 락 안에서 한 번 더
                _INSTANCE = build()
    return _INSTANCE
```

| 검사 | 목적 |
|---|---|
| ① 락 밖 `is None` | 이미 로드됐으면 **락을 건드리지도 않음** (요청당 0.1µs) |
| ② `with _LOCK` | 생성 구간을 한 스레드만 통과 |
| ③ 락 안 `is None` | 락을 기다리는 동안 다른 스레드가 이미 만들었을 수 있음 |

```
★ ③ 을 빼면 무슨 일이 일어나는가

  A 가 락을 잡고 2,840ms 동안 로드
  B 는 락 앞에서 대기
  A 가 락을 놓음
  B 가 락을 잡음  →  ★ ③ 검사가 없으면 또 만듭니다
```

```
★ ① 을 빼면 무슨 일이 일어나는가

  요청마다 락을 잡았다 놓습니다
  초당 200요청이면 ★ 락 경합이 그대로 지연이 됩니다
  (로드가 끝난 뒤에는 락이 필요 없는데도)
```

> ⚠️ **락은 "모델을 만드는 동안"만 필요합니다.**
> 다 만든 뒤에도 계속 락을 잡으면 그 서버는 **동시성이 1** 인 서버가 됩니다.

**왜 두 번인가**

```
debug=True 로 켜면 Werkzeug 는 프로세스를 ★ 두 개 씁니다

  [부모]  파일 변경을 감시하다가 자식을 재시작시킴
    │     ★ 여기서도 run.py 를 끝까지 실행 → create_app() 이 한 번 더 돕니다
    ↓ spawn (환경변수 WERKZEUG_RUN_MAIN=true 를 붙임)
  [자식]  실제로 요청을 처리
```

| 프로세스 | `WERKZEUG_RUN_MAIN` | 요청 처리 | 모델이 필요한가 |
|---|---|---|---|
| 부모(감시자) | 없음 | ✗ | **불필요** |
| 자식(실행) | `"true"` | ✓ | 필요 |

```
★ 그대로 두면 기동 5.7초 → 11.4초 · VRAM 2,240MB (절반은 감시자가 점유)
   파일을 저장할 때마다 자식만 재시작 → 그때마다 또 2.8초
```

**★ 해결**

```python
import os

def _should_warmup(app) -> bool:
    if not app.config.get("DETECT_WARMUP"):
        return False
    if app.config.get("TESTING"):
        return False
    # ★ 리로더의 부모 프로세스에서는 로드하지 않습니다
    if app.debug and os.environ.get("WERKZEUG_RUN_MAIN") != "true":
        return False
    return True
```

```
★ 판정표

  debug=False                    → 워밍업 O   (운영 · waitress)
  debug=True, RUN_MAIN 없음      → ★ 워밍업 X (부모 = 감시자)
  debug=True, RUN_MAIN="true"    → 워밍업 O   (자식 = 실행)
  TESTING=True                   → 워밍업 X
```

> ⚠️ **`use_reloader=False` 로 끄는 것은 해결이 아닙니다.**
> 코드를 고칠 때마다 손으로 서버를 껐다 켜야 합니다.
> **감시자 프로세스에서만 로드를 건너뛰는 것**이 맞는 해법입니다.

### 워밍업 — 첫 추론은 왜 느린가

로드가 끝났는데도 **첫 추론은 2,140ms** 입니다. 두 번째는 45ms 입니다.

```
첫 추론에서만 일어나는 일
  ① CUDA 컨텍스트 생성          ~700ms
  ② cuDNN 커널 자동 선택        ~600ms  ← 여러 알고리즘을 재보고 고름
  ③ 워크스페이스 메모리 할당    ~350ms
  ④ FP16 캐스팅 · 그래프 최적화 ~300ms
  ⑤ 실제 연산 ~45ms   ⑥ 파이썬/넘파이 지연 초기화 ~145ms
                                ────────  합계 2,140ms

★ 이 비용은 없앨 수 없습니다. 다만 "누가 낼 것인가"는 고를 수 있습니다
  워밍업 없음 → ★ 첫 사용자가 냄 (2.1초)  |  있음 → 서버 기동 때 냄
```

**더미 이미지로 예열합니다**

```python
def warmup(self):
    import numpy as np
    imgsz = self.detector.imgsz               # ★ 실제 추론과 같은 크기로
    dummy = np.zeros((imgsz, imgsz, 3), np.uint8)
    self.detector.predict_image(dummy)
```

**워밍업 전후 측정** (같은 사진 `sample_1920x1080.jpg` 로 10회)

| 회차 | 1 | 2 | 3 | 4 | 6~10 평균 | **전체 평균** | 최댓값 |

### 동시 요청 — 세마포어와 503

락은 **정확성**을 지킵니다. 그런데 **대기열**은 여전히 무제한입니다.

```
동시 접속 50명이 4K 사진을 올렸습니다

  50 × 45ms = 2,250ms          ← 마지막 사람의 대기 시간
  50 × 24MB = 1,200MB          ← ★ 각 스레드가 디코딩된 이미지를 들고 있음
  브라우저 타임아웃 → 새로고침 → ★ 요청이 더 늘어납니다
```

**★ 세마포어로 입장 인원을 제한합니다**

```python
self._sem = threading.BoundedSemaphore(max_concurrency)

if not self._sem.acquire(timeout=queue_timeout):
    raise DetectorBusy(...)          # ★ 503
try:
    ...추론...
finally:
    self._sem.release()              # ★ 반드시 finally
```

| 설정 | 값 | 의미 |
|---|---|---|
| `DETECT_MAX_CONCURRENCY` | **2** | 동시에 추론 구간에 들어갈 수 있는 요청 수 |
| `DETECT_QUEUE_TIMEOUT` | **3.0** | 대기 제한(초). 넘으면 503 |

```
★ 왜 2 인가 (GPU 1장)
  1 → 대기가 길어짐. 검증·그리기 구간이 놀게 됨
  2 → ★ 한 요청이 추론할 때 다른 하나가 전처리를 마치고 대기
  4 → VRAM 경합. 4,480MB 필요 → OOM
CPU 프로파일이면 max(1, 코어수 // 2) — torch 가 이미 멀티코어를 씁니다
```

**503 을 돌려주는 기준** — 대기 3초 초과 시 `503` + `Retry-After: 5`.

```json
{"error": "busy", "message": "서버가 혼잡합니다. 잠시 후 다시 시도해 주세요.",
 "inflight": 2, "waiting": 7, "retry_after": 5}
```

```
★ 503 은 "실패"가 아니라 "지금은 안 됩니다"입니다

  500  서버 버그        →  재시도해도 똑같이 실패
  503  일시적 과부하    →  재시도하면 성공
  429  요청이 너무 잦음 →  클라이언트별 제한 (Day 165)

  라즈베리파이의 재전송 큐(Day 159)는
  ★ 503 을 받으면 큐에 넣고 나중에 다시 보냅니다
```

> ⚠️ **`acquire()` 를 했으면 `release()` 는 반드시 `finally` 에서 합니다.**
> 추론 중 예외가 나면 세마포어가 영영 회수되지 않고,
> **2번 실패하면 서버가 모든 요청에 503 을 뱉는 좀비가 됩니다.**

```python
"""web/services/detector_service.py — src/detector.py 를 웹에 연결하는 계층

★ 이 파일이 하는 일 (추론 로직은 한 줄도 없습니다)
    ① 언제 로드할지     지연 로딩 + 설정
    ② 몇 번 로드할지    threading.Lock 이중 검사
    ③ 몇 개가 동시에    threading.BoundedSemaphore
    ④ 얼마나 걸렸는지   통계 수집

규칙: web 패키지의 다른 모듈을 import 하지 않습니다 (순환 방지)
"""
from __future__ import annotations

import os
import sys
import threading
import time
from pathlib import Path

import numpy as np
from flask import current_app

EXT_KEY = "detector"


class DetectorUnavailable(RuntimeError):
    """모델을 쓸 수 없는 상태 (비활성 · 로드 실패) — 503"""

    def __init__(self, message: str, reason: str = "unavailable"):
        super().__init__(message)
        self.message, self.reason, self.status = message, reason, 503


class DetectorBusy(RuntimeError):
    """동시 추론 한도 초과 — 잠시 후 재시도하면 됩니다 (503)"""

    def __init__(self, message: str, waiting: int = 0, retry_after: int = 5):
        super().__init__(message)
        self.message, self.waiting = message, waiting
        self.retry_after, self.status = retry_after, 503


class DetectorService:
    """앱마다 하나. 모델은 앱마다 하나.

    상태는 self 가 아니라 app.extensions 에 둡니다.
    (Day 160 ResultStore 와 같은 패턴 — 테스트에서 앱이 여러 개이므로)
    """

    # ────────────────────────── 초기화 ──────────────────────────

    def init_app(self, app) -> None:
        """create_app() 에서 호출. 여기서는 로드하지 않습니다 (0.4ms)"""
        max_conc = int(app.config.get("DETECT_MAX_CONCURRENCY", 2))
        app.extensions[EXT_KEY] = {
            "instance": None,
            "lock": threading.Lock(),              # ★ 로드 1회 보장
            "infer_lock": threading.RLock(),       # ★ 추론 직렬화
            "sem": threading.BoundedSemaphore(max_conc),
            "stats_lock": threading.Lock(),
            "enabled": bool(app.config.get("DETECT_ENABLED", True)),
            "profile": app.config.get("DETECT_PROFILE"),
            "weights": app.config.get("MODEL_PATH"),
            "max_concurrency": max_conc,
            "queue_timeout": float(app.config.get("DETECT_QUEUE_TIMEOUT", 3.0)),
            "warmup_runs": int(app.config.get("DETECT_WARMUP_RUNS", 2)),
            # ── 상태 ──
            "load_ms": None, "warmup_ms": None, "warmed": False,
            "error": None, "loaded_at": None, "pid": None,
            # ── 통계 ──
            "requests": 0, "failures": 0, "busy_rejects": 0,
            "infer_ms_sum": 0.0, "infer_ms_max": 0.0,
            "inflight": 0, "waiting": 0,
        }
        app.logger.debug("DetectorService 등록 — profile=%s enabled=%s "
                         "max_concurrency=%d",
                         app.config.get("DETECT_PROFILE"),
                         app.config.get("DETECT_ENABLED"), max_conc)

    # ────────────────────────── 내부 ──────────────────────────

    @staticmethod
    def _state(app=None) -> dict:
        app = app or current_app
        try:
            return app.extensions[EXT_KEY]
        except KeyError as e:
            raise RuntimeError(
                "DetectorService 가 초기화되지 않았습니다. "
                "create_app() 안에서 detector.init_app(app) 을 호출하세요."
            ) from e

    @staticmethod
    def _src_on_path() -> None:
        """cctv_project/src 를 sys.path 에 넣어 `import detector` 가 되게"""
        src = Path(__file__).resolve().parents[2] / "src"
        if str(src) not in sys.path:
            sys.path.insert(0, str(src))

    # ────────────────────────── 로딩 ──────────────────────────

    def get(self, app=None):
        """Detector 인스턴스를 돌려줍니다 (없으면 이때 로드)"""
        app = app or current_app
        state = self._state(app)

        if not state["enabled"]:
            raise DetectorUnavailable(
                "이 앱은 검출 기능이 꺼져 있습니다", "disabled")

        if state["instance"] is not None:          # ★ ① 락 없이 빠른 검사
            return state["instance"]

        with state["lock"]:                        # ★ ② 생성 구간만 락
            if state["instance"] is not None:      # ★ ③ 락 안에서 재확인
                return state["instance"]
            if state["error"]:                     # 이전에 실패한 상태
                raise DetectorUnavailable(state["error"], "load_failed")
            self._load(app, state)
        return state["instance"]

    def _load(self, app, state: dict) -> None:
        """실제 로드 — 반드시 lock 안에서만 호출됩니다"""
        t0 = time.perf_counter()
        self._src_on_path()
        try:
            from detector import get_detector      # ★ 함수 안 import
            kwargs = {"profile": state["profile"], "warmup": False}
            if state["weights"]:
                kwargs["weights"] = state["weights"]
            state["instance"] = get_detector(**kwargs)
        except FileNotFoundError as e:
            state["error"] = f"가중치 파일이 없습니다: {e}"
            app.logger.error("모델 로드 실패 — %s", state["error"])
            raise DetectorUnavailable(state["error"], "not_found") from e
        except Exception as e:
            state["error"] = f"{type(e).__name__}: {e}"
            app.logger.exception("모델 로드 실패")
            raise DetectorUnavailable(state["error"], "load_failed") from e

        state["load_ms"] = round((time.perf_counter() - t0) * 1000, 1)
        state["loaded_at"] = time.strftime("%Y-%m-%d %H:%M:%S")
        state["pid"] = os.getpid()
        det = state["instance"]
        app.logger.info(
            "★ 모델 로드 %.0fms — %s (imgsz=%d, classes=%s, pid=%d)",
            state["load_ms"], Path(det.weights).name, det.imgsz,
            list(det.class_names.values()), state["pid"])

    # ────────────────────────── 워밍업 ──────────────────────────

    def warmup(self, app) -> bool:
        """★ 기동 시 1회 — 첫 사용자가 2.1초를 기다리지 않게"""
        state = self._state(app)
        if not state["enabled"] or state["warmed"]:
            return False

        with app.app_context():
            try:
                det = self.get(app)
            except DetectorUnavailable as e:
                app.logger.warning("워밍업 생략 — %s", e.message)
                return False

            imgsz = getattr(det, "imgsz", 640) or 640
            dummy = np.zeros((imgsz, imgsz, 3), np.uint8)   # ★ 실제와 같은 크기
            t0 = time.perf_counter()
            try:
                for _ in range(max(1, state["warmup_runs"])):
                    det.predict_image(dummy)
            except Exception:
                app.logger.exception("워밍업 실패 (검출은 계속 시도합니다)")
                return False

            state["warmup_ms"] = round((time.perf_counter() - t0) * 1000, 1)
            state["warmed"] = True
            app.logger.info("★ 워밍업 완료 %.0fms (%d회, %d×%d)",
                            state["warmup_ms"], state["warmup_runs"],
                            imgsz, imgsz)
        return True

    @staticmethod
    def probe(app) -> dict:
        """로드하지 않고 가중치 파일만 확인 (0.3ms)"""
        raw = app.config.get("MODEL_PATH")
        if not raw:
            return {"ok": True, "reason": "profile_default"}
        p = Path(raw)
        if not p.exists():
            return {"ok": False, "reason": "not_found", "path": str(p)}
        size = p.stat().st_size
        if size < 1024 * 1024:
            return {"ok": False, "reason": "too_small",
                    "path": str(p), "size": size}
        return {"ok": True, "path": str(p),
                "size_mb": round(size / 1024 / 1024, 1)}

    # ────────────────────────── 추론 ──────────────────────────

    def predict(self, image, conf=None, iou=None, classes=None,
                app=None) -> dict:
        """★ 웹이 부르는 유일한 추론 진입점

        · 세마포어로 동시 추론 수를 제한
        · RLock 으로 모델 객체 접근을 직렬화
        · 통계를 남김
        예외: DetectorUnavailable(503) · DetectorBusy(503)
        """
        app = app or current_app
        state = self._state(app)
        det = self.get(app)                       # 필요하면 여기서 로드

        with state["stats_lock"]:
            state["waiting"] += 1
        got = state["sem"].acquire(timeout=state["queue_timeout"])
        with state["stats_lock"]:
            state["waiting"] -= 1

        if not got:
            with state["stats_lock"]:
                state["busy_rejects"] += 1
                waiting = state["waiting"]
            app.logger.warning("혼잡 — %.1f초 대기 후 거부 (waiting=%d)",
                               state["queue_timeout"], waiting)
            raise DetectorBusy(
                "서버가 혼잡합니다. 잠시 후 다시 시도해 주세요.",
                waiting=waiting, retry_after=5)

        with state["stats_lock"]:
            state["inflight"] += 1
        t0 = time.perf_counter()
        try:
            with state["infer_lock"]:             # ★ 모델 객체는 한 번에 하나
                result = det.predict_image(image, conf=conf, iou=iou,
                                           classes=classes)
        except Exception:
            with state["stats_lock"]:
                state["failures"] += 1
            app.logger.exception("추론 실패")
            raise
        finally:
            state["sem"].release()                # ★ 반드시 finally
            with state["stats_lock"]:
                state["inflight"] -= 1

        ms = (time.perf_counter() - t0) * 1000
        with state["stats_lock"]:
            state["requests"] += 1
            state["infer_ms_sum"] += ms
            state["infer_ms_max"] = max(state["infer_ms_max"], ms)
        return result

    # ────────────────────────── 상태 ──────────────────────────

    def info(self, app=None) -> dict:
        """/api/health · /status 가 쓰는 요약"""
        s = self._state(app)
        n = s["requests"]
        det = s["instance"]
        out = {k: s[k] for k in
               ("enabled", "warmed", "error", "profile", "load_ms",
                "warmup_ms", "loaded_at", "pid", "max_concurrency",
                "inflight", "waiting", "requests", "failures",
                "busy_rejects")}
        out["loaded"] = det is not None
        out["weights"] = Path(det.weights).name if det is not None else None
        out["imgsz"] = getattr(det, "imgsz", None) if det is not None else None
        out["classes"] = (list(det.class_names.values())
                          if det is not None else None)
        out["avg_infer_ms"] = round(s["infer_ms_sum"] / n, 1) if n else None
        out["max_infer_ms"] = round(s["infer_ms_max"], 1) if n else None
        return out

    def reset(self, app=None) -> None:
        """테스트 전용 — 인스턴스를 버립니다"""
        state = self._state(app)
        state["instance"] = None
        state["error"] = None
        state["warmed"] = False
        state["load_ms"] = None
```

```python
    app.logger.info("앱 생성 완료 config=%s blueprints=%s routes=%d",
                    config_name, list(app.blueprints),
                    len(list(app.url_map.iter_rules())))
    return app


def _prepare_detector(app: Flask) -> None:
    """★ 가중치 점검 → (조건 충족 시) 로드 + 워밍업"""
    if not app.config.get("DETECT_ENABLED"):
        app.logger.info("검출 기능 비활성 (DETECT_ENABLED=False)")
        return

    probe = detector.probe(app)
    if not probe["ok"]:
        app.logger.warning("가중치 점검 실패 — %s: %s",
                           probe["reason"], probe.get("path"))
        app.logger.warning("검출 없이 기동합니다 (/api/health 를 확인하세요)")
        return
    app.logger.info("가중치 확인 — %s (%.1fMB)",
                    Path(probe["path"]).name, probe["size_mb"])

    if not _should_warmup(app):
        app.logger.info("워밍업 생략 — 첫 요청에서 로드합니다")
        return

    detector.warmup(app)


def _should_warmup(app: Flask) -> bool:
    """★ 리로더의 부모 프로세스에서는 로드하지 않습니다"""
    if not app.config.get("DETECT_WARMUP"):
        return False
    if app.config.get("TESTING"):
        return False
    if app.debug and os.environ.get("WERKZEUG_RUN_MAIN") != "true":
        app.logger.debug("리로더 감시 프로세스 — 모델을 로드하지 않습니다")
        return False
    return True


# ── _configure_logging() · _ensure_dirs() 는 Day 160 과 동일합니다 ──
```

### Step 3. `web/utils/draw.py` — 결과 이미지 그리기

```python
"""web/utils/draw.py — 검출 결과를 이미지에 그립니다

★ 추론과 분리되어 있습니다 (Day 152 의 원칙 그대로).
   API 는 JSON 만 필요하므로 draw 를 부르지 않습니다.
"""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np

# ★ 클래스별 고정 색 (BGR) — 화면마다 같은 색이어야 합니다
CLASS_COLORS = {
    "person": (60, 200, 60),      # 초록
    "helmet": (60, 160, 255),     # 주황
    "box": (220, 120, 60),        # 파랑
}
FALLBACK_COLORS = [
    (200, 80, 220), (60, 220, 220), (180, 180, 60), (140, 60, 200),
]

FONT = cv2.FONT_HERSHEY_SIMPLEX
_FONT_CACHE: dict[int, object] = {}

FONT_CANDIDATES = [
    r"C:\Windows\Fonts\malgun.ttf",
    "/usr/share/fonts/truetype/nanum/NanumGothic.ttf",
    "/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf",
    "/System/Library/Fonts/AppleSDGothicNeo.ttc",
]

KO_NAMES = {"person": "사람", "helmet": "안전모", "box": "상자"}


def color_for(name: str, class_id: int = 0) -> tuple[int, int, int]:
    """클래스 이름 우선, 없으면 id 로 폴백"""
    if name in CLASS_COLORS:
        return CLASS_COLORS[name]
    return FALLBACK_COLORS[class_id % len(FALLBACK_COLORS)]


def _fit(img: np.ndarray, max_side: int) -> tuple[np.ndarray, float]:
    """긴 변을 max_side 로 축소. 배율을 함께 돌려줍니다"""
    h, w = img.shape[:2]
    longest = max(h, w)
    if not max_side or longest <= max_side:
        return img, 1.0
    scale = max_side / longest
    small = cv2.resize(img, (int(w * scale), int(h * scale)),
                       interpolation=cv2.INTER_AREA)
    return small, scale


def draw_boxes(image: np.ndarray, result: dict, *,
               max_side: int = 1280, min_conf: float | None = None,
               thickness: int | None = None, show_conf: bool = True,
               korean: bool = False) -> np.ndarray:
    """★ 박스를 그린 새 이미지를 반환합니다 (원본은 건드리지 않음)

    image=원본 BGR · result=predict_image() 표준 응답
    max_side=긴 변 상한(0=축소 안 함) · min_conf=이 값 미만은 안 그림
    korean=True 면 PIL 로 한글 라벨 (이미지당 +14ms)
    """
    canvas, scale = _fit(image, max_side)
    h, w = canvas.shape[:2]

    # ★ 응답 좌표는 원본 기준 → 축소 배율을 곱합니다
    rw = result.get("image", {}).get("width") or image.shape[1]
    rh = result.get("image", {}).get("height") or image.shape[0]
    sx, sy = w / rw, h / rh

    if thickness is None:                      # 해상도에 비례한 굵기
        thickness = max(2, round(max(h, w) / 480))
    font_scale = max(0.45, min(0.9, max(h, w) / 1600))

    labels = []
    for d in result.get("detections", []):
        if min_conf is not None and d.get("conf", 0) < min_conf:
            continue
        name = d.get("class", "obj")
        color = color_for(name, d.get("class_id", 0))
        b = d["box"]
        x1 = int(round(b["x1"] * sx)); y1 = int(round(b["y1"] * sy))
        x2 = int(round(b["x2"] * sx)); y2 = int(round(b["y2"] * sy))
        x1 = max(0, min(x1, w - 1)); x2 = max(0, min(x2, w - 1))
        y1 = max(0, min(y1, h - 1)); y2 = max(0, min(y2, h - 1))

        cv2.rectangle(canvas, (x1, y1), (x2, y2), color, thickness)

        text = KO_NAMES.get(name, name) if korean else name
        if show_conf:
            text += f" {d.get('conf', 0):.2f}"
        labels.append((text, x1, y1, color))

    if korean:
        canvas = _draw_labels_pil(canvas, labels, font_scale)
    else:
        for text, x1, y1, color in labels:
            _put_label(canvas, text, x1, y1, color, font_scale,
                       max(1, thickness - 1))
    return canvas


def _put_label(img, text, x, y, color, scale=0.5, thickness=1) -> None:
    """라벨 배경 박스 + 흰 글씨. 화면 밖으로 나가지 않게"""
    (tw, th), base = cv2.getTextSize(text, FONT, scale, thickness)
    h, w = img.shape[:2]
    x = max(0, min(x, w - tw - 8))
    ty = y - 5 if y - th - 8 >= 0 else y + th + 8      # 위가 좁으면 아래로
    cv2.rectangle(img, (x, ty - th - 4), (x + tw + 6, ty + base - 2),
                  color, -1)                          # 채운 배경
    cv2.putText(img, text, (x + 3, ty), FONT, scale,
                (255, 255, 255), thickness, cv2.LINE_AA)


def _load_font(size: int):
    """★ 폰트는 크기별로 한 번만 로드해 캐시합니다"""
    if size in _FONT_CACHE:
        return _FONT_CACHE[size]
    from PIL import ImageFont

    font = None
    for path in FONT_CANDIDATES:
        if Path(path).exists():
            try:
                font = ImageFont.truetype(path, size)
                break
            except OSError:
                continue
    _FONT_CACHE[size] = font or ImageFont.load_default()  # ★ 폴백은 한글 깨짐
    return _FONT_CACHE[size]


def _draw_labels_pil(img: np.ndarray, labels, font_scale: float) -> np.ndarray:
    """한글 라벨 — PIL 로 그린 뒤 다시 BGR 로"""
    from PIL import Image, ImageDraw

    size = max(14, int(font_scale * 34))
    font = _load_font(size)
    pil = Image.fromarray(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
    drawer = ImageDraw.Draw(pil)

    for text, x, y, color in labels:
        rgb = (color[2], color[1], color[0])          # BGR → RGB
        left, top, right, bottom = drawer.textbbox((0, 0), text, font=font)
        tw, th = right - left, bottom - top
        ty = y - th - 6 if y - th - 6 >= 0 else y + 4
        drawer.rectangle([x, ty, x + tw + 8, ty + th + 6], fill=rgb)
        drawer.text((x + 4, ty + 2), text, font=font, fill=(255, 255, 255))

    return cv2.cvtColor(np.array(pil), cv2.COLOR_RGB2BGR)


def draw_empty_note(image: np.ndarray, max_side: int = 1280) -> np.ndarray:
    """★ 검출 0건일 때 — 축소본 좌상단에 'no detection' 만 찍습니다"""
    canvas, _ = _fit(image, max_side)
    (tw, th), _ = cv2.getTextSize("no detection", FONT, 0.6, 2)
    cv2.rectangle(canvas, (8, 8), (20 + tw, 20 + th), (60, 60, 60), -1)
    cv2.putText(canvas, "no detection", (14, 12 + th), FONT, 0.6,
                (220, 220, 220), 2, cv2.LINE_AA)
    return canvas
```

```python
"""web/blueprints/detect.py — 업로드부터 갤러리까지 (Day 161 갱신)

★ Day 160 대비 바뀐 곳은 ④ 검출 · ⑤ 결과 이미지 두 군데뿐입니다.
"""
from __future__ import annotations

import time

from flask import (Blueprint, abort, current_app, flash, redirect,
                   render_template, request, url_for)

from ..extensions import detector, store
from ..models.record import (DetectionParams, DetectionRecord, UploadInfo,

                                  validate_and_decode)

bp = Blueprint("detect", __name__)


class Stopwatch:
    """구간별 경과 시간을 ms 로 모읍니다"""

    def __init__(self):
        self._t0 = time.perf_counter()
        self._last = self._t0
        self.marks: dict[str, float] = {}

    def lap(self, name: str) -> float:
        now = time.perf_counter()
        ms = (now - self._last) * 1000
        self.marks[name] = round(ms, 1)
        self._last = now
        return ms

    def total(self) -> float:
        return round((time.perf_counter() - self._t0) * 1000, 1)

    def to_dict(self) -> dict:
        return {**self.marks, "total": self.total()}


# ── _parse_params() · upload() 는 Day 160 과 동일합니다 (수정 없음) ──


@bp.route("/detect", methods=["POST"])
def do_detect():
    """★ 업로드 → 검증 → 추론 → 결과 이미지 → 저장 → 리다이렉트(PRG)"""
    sw = Stopwatch()

    # ── ① 파일 검증 + 디코딩 ──
    try:
        img, data, meta = validate_and_decode(request.files.get("image"))
    except UploadError as e:
        current_app.logger.warning("업로드 거부: %s (%s) from %s",
                                   e.message, e.code, request.remote_addr)
        flash(e.message, "error")
        return redirect(url_for(".upload"))
    sw.lap("validate")

    # ── ② 파라미터 검증 ──
    params, err = _parse_params()
    if err:
        flash(err, "error")
        return redirect(url_for(".upload"))

    # ── ③ 원본 저장 ──
    try:
        saved = save_bytes(data, current_app.config["UPLOAD_DIR"],
                           meta["ext"], prefix="up_")
    except UploadError as e:
        current_app.logger.exception("원본 저장 실패")
        flash(e.message, "error")
        return redirect(url_for(".upload"))
    sw.lap("save_upload")

    # ── ④ ★ 검출 (Day 160 의 make_placeholder_result 를 대체) ──
    try:
        result = detector.predict(img, conf=params.conf, iou=params.iou,
                                  classes=params.classes)
    except DetectorBusy as e:
        current_app.logger.warning("혼잡으로 거부 — waiting=%d", e.waiting)
        flash("서버가 혼잡합니다. 10초 뒤 다시 시도해 주세요.", "error")
        return redirect(url_for(".upload"))
    except DetectorUnavailable as e:
        current_app.logger.error("검출 불가 — %s", e.message)
        flash(f"검출 기능을 쓸 수 없습니다: {e.message}", "error")
        result = make_placeholder_result(meta["width"], meta["height"],
                                         params.conf, params.iou)
        result["error"] = e.reason           # 화면에 이유를 남깁니다
    except Exception:
        current_app.logger.exception("추론 실패")
        flash("검출 중 오류가 발생했습니다. 다른 이미지로 시도해 보세요.",
              "error")
        return redirect(url_for(".upload"))
    sw.lap("infer")

    # ── ⑤ ★ 결과 이미지 ──
    cfg = current_app.config
    if cfg.get("DETECT_DRAW", True):
        if result.get("count"):
            vis = draw_boxes(img, result,
                             max_side=cfg["DETECT_DRAW_MAX_SIDE"],
                             min_conf=cfg.get("DETECT_DRAW_MIN_CONF"))
        else:
            vis = draw_empty_note(img, cfg["DETECT_DRAW_MAX_SIDE"])
    else:
        vis = img
    sw.lap("draw")

    result_saved = save_image(vis, cfg["RESULT_DIR"], ".jpg", prefix="res_")
    sw.lap("save_result")

    # ── ⑥ 레코드 저장 ──
    model_timing = result.get("timing_ms", {})
    result["timing_ms"] = {**sw.to_dict(), "model": model_timing}

    record = DetectionRecord(
        rid=store.new_id(),
        upload=UploadInfo(
            original_name=meta["original_name"],
            stored_name=saved["stored_name"],
            size_bytes=meta["size_bytes"],
            width=meta["width"], height=meta["height"],
            ext=meta["ext"], sniffed_type=meta["sniffed_type"]),
        params=params,
        result=result,
        result_image=result_saved["stored_name"])
    rid = store.save(record.to_dict())
    sw.lap("meta")
    result["timing_ms"] = {**sw.to_dict(), "model": model_timing}

    # ── ⑦ 로그 + PRG ──
    current_app.logger.info(
        "[검출] rid=%s %dx%d conf=%.2f → %d건 %s | %s",
        rid, meta["width"], meta["height"], params.conf,
        result.get("count", 0), result.get("counts_by_class") or {},
        " ".join(f"{k}={v}" for k, v in sw.to_dict().items()))

    summary = (" · ".join(f"{k} {v}" for k, v in
                          (result.get("counts_by_class") or {}).items())
               or "검출 없음")
    flash(f"검출 완료 — {summary} ({sw.total():.0f}ms)", "success")
    return redirect(url_for(".show_result", rid=rid))
```

```python
        body["hint"] = ("models/ 에 가중치를 두거나 "
                        "CCTV_MODEL_PATH 환경변수를 설정하세요")
    return jsonify(body), (200 if ok else 503)


@bp.post("/detect")
def detect():
    """★ JSON API — 그리기 없이 결과만 (파이 · 외부 클라이언트용)"""
    try:
        img, data, meta = validate_and_decode(request.files.get("image"))
    except UploadError as e:
        current_app.logger.warning("API 업로드 거부: %s (%s)", e.message, e.code)
        return jsonify({"error": e.code, "message": e.message}), e.status

    conf = request.form.get("conf", type=float,
                            default=current_app.config["DEFAULT_CONF"])
    iou = request.form.get("iou", type=float,
                           default=current_app.config["DEFAULT_IOU"])
    if not 0.01 <= conf <= 0.99:
        return jsonify({"error": "invalid_parameter",
                        "message": "conf 는 0.01~0.99 사이여야 합니다",
                        "field": "conf", "got": conf}), 400

    request_id = uuid.uuid4().hex[:12]
    try:
        result = detector.predict(img, conf=conf, iou=iou)
    except DetectorBusy as e:
        resp = jsonify({"error": "busy", "message": e.message,
                        "waiting": e.waiting, "retry_after": e.retry_after,
                        "request_id": request_id})
        resp.headers["Retry-After"] = str(e.retry_after)   # ★ 표준 헤더
        return resp, 503
    except DetectorUnavailable as e:
        return jsonify({"error": e.reason, "message": e.message,
                        "request_id": request_id}), 503
    except Exception as e:
        current_app.logger.exception("API 추론 실패")
        return jsonify({"error": "inference_failed",
                        "message": f"{type(e).__name__}",
                        "request_id": request_id}), 500

    return jsonify({
        "request_id": request_id,
        "image": result["image"],
        "model": result["model"],
        "timing_ms": result["timing_ms"],
        "count": result["count"],
        "counts_by_class": result["counts_by_class"],
        "detections": result["detections"],
    })
```

```python
"""scripts/bench_concurrent.py — 동시 요청 부하 측정

    python scripts/bench_concurrent.py --concurrency 4 --total 40
"""
from __future__ import annotations

import argparse
import statistics
import time
from concurrent.futures import ThreadPoolExecutor

import requests

URL = "http://127.0.0.1:5000/api/detect"
SAMPLE = "samples/site_1920x1080.jpg"


def one_request(idx: int) -> dict:
    with open(SAMPLE, "rb") as f:
        payload = {"image": ("photo.jpg", f.read(), "image/jpeg")}
    t0 = time.perf_counter()
    try:
        r = requests.post(URL, files=payload, data={"conf": "0.45"},
                          timeout=30)
        ms = (time.perf_counter() - t0) * 1000
        return {"idx": idx, "status": r.status_code, "ms": ms}
    except requests.RequestException as e:
        return {"idx": idx, "status": -1, "ms": 0.0, "error": str(e)}


def run(concurrency: int, total: int) -> dict:
    t0 = time.perf_counter()
    with ThreadPoolExecutor(max_workers=concurrency) as pool:
        rows = list(pool.map(one_request, range(total)))
    wall = time.perf_counter() - t0

    ok = sorted(r["ms"] for r in rows if r["status"] == 200)
    return {
        "동시": concurrency, "총요청": total, "성공": len(ok),
        "503": sum(1 for r in rows if r["status"] == 503),
        "평균ms": round(statistics.mean(ok), 1) if ok else 0,
        "p95ms": round(ok[int(len(ok) * 0.95) - 1], 1) if ok else 0,
        "최대ms": round(max(ok), 1) if ok else 0,
        "처리량": round(len(ok) / wall, 1),
    }


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--concurrency", type=int, default=4)
    ap.add_argument("--total", type=int, default=40)
    args = ap.parse_args()
    print(run(args.concurrency, args.total))
```

## ⑥ 확인 문제

### 문제 1 — 이 코드의 버그 두 개

```python
def get(self):
    with self.lock:
        if self.instance is None:
            self.instance = build()
        return self.instance

def predict(self, img):
    self.sem.acquire()
    r = self.get().predict_image(img)
    self.sem.release()
    return r
```

<details>
<summary>답 보기</summary>

**버그 ① — 락을 항상 잡습니다.** 로드가 끝난 뒤에도 모든 요청이 `self.lock` 을
통과해 동시성이 **사실상 1** 이 됩니다. 세마포어가 2여도 의미가 없습니다.

```python
if self.instance is not None:        # ★ 락 밖 빠른 검사
    return self.instance
with self.lock:
    if self.instance is None:        # ★ 락 안 재확인
        self.instance = build()
return self.instance
```

**버그 ② — `release()` 가 `finally` 에 없습니다.**
`predict_image` 가 예외를 던지면 세마포어가 반납되지 않습니다.

```python
if not self.sem.acquire(timeout=self.queue_timeout):
    raise DetectorBusy(...)          # ★ 무한 대기도 막습니다
try:
    return self.get().predict_image(img)
finally:
    self.sem.release()
```

| 버그 | 증상 |
|---|---|
| ① | 동시 8요청 처리량 20.6 → 14.9 |
| ② | 추론 실패 2번 → 이후 모든 요청 503 |

</details>

### 문제 3 — 결과가 뒤바뀝니다

동시 접속 4명 중 한 명이 **다른 사람의 사진 결과**를 받았습니다.
파일명은 UUID 라 충돌이 없습니다. 원인은?

<details>
<summary>답 보기</summary>

**Ultralytics predictor 가 인스턴스 상태(`self.batch` · `self.results`)를 씁니다.**

```
스레드 A: self.batch = A의 이미지
스레드 B: self.batch = B의 이미지     ★ 덮어씀
스레드 A: return self.results         ★ B 의 결과
```

**"GIL 이 있어서 안전하다"는 틀렸습니다.** `torch`·`cv2` 의 C++ 구간은 **GIL 을 해제**합니다.
추론의 90% 가 그 구간이므로 진짜로 동시에 들어갑니다.

**해결 — 추론 구간만 직렬화**

```python
with state["infer_lock"]:
    result = det.predict_image(image, conf=conf, iou=iou)
```

| 대응 | 방치 | 스레드마다 모델 | 추론 락 |
|---|---|---|---|
| 동시성 / VRAM | 높음 / 1× | N / N× | 1 / 1× |
| 판정 | 결과 섞임 | 4GB 에 3개 한계 | ★ 채택 |

락을 걸면 오히려 빨라집니다 (218.4ms → 191.3ms). GPU 는 어차피 하나이기 때문입니다.

|---|---|---|---|---|

```

  짧으면(0.5) 조금만 몰려도 503 폭증
```
