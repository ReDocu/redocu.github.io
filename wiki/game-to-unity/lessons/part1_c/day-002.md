## 2. 막히는 상황

어제 만든 코드를 보자.

```c
printf("  슬라임  HP %3d / %3d\n", 30, 30);
```

여기서 `30`은 **글자로 박혀 있다.** 공격을 해도 이 숫자는 절대 바뀌지 않는다.
바꾸려면 소스를 고치고 다시 빌드해야 하는데, 그건 게임이 아니다.

```
   어제:  printf("HP %d", 30);      ← 30이 코드에 붙어 있다
                     ▲
                     └── 실행 중에는 손댈 수 없다

   필요한 것:  어딘가에 30을 넣어 두고
              그 자리를 12만큼 줄인 다음
              그 자리의 값을 출력한다
```

> **값을 담아 두고, 실행 중에 바꿀 수 있는 그릇이 필요하다.** → **변수**

## 3. 개념

### 3-1. 변수 — 값을 담는 그릇

**왜 필요한가** — 실행 중에 값이 변해야 게임이 된다.

```c
int slimeHp = 30;      // 정수를 담는 그릇 slimeHp를 만들고 30을 넣는다

slimeHp = slimeHp - 12;   // 그릇의 값을 12만큼 줄여서 다시 넣는다

printf("HP %d\n", slimeHp);   // 18
```

```
   메모리 (컴퓨터의 기억 공간)

   ┌──────────┬──────────┬──────────┐
   │ heroHp   │ slimeHp  │ damage   │   ← 변수 이름
   ├──────────┼──────────┼──────────┤
   │   100    │    30    │    12    │   ← 담긴 값
   └──────────┴──────────┴──────────┘

   slimeHp = slimeHp - damage;
                ▲          ▲
                │          └─ 12를 꺼내서
                └─ 30에서 빼고, 결과 18을 다시 slimeHp에 넣는다
```

**선언과 초기화**

```c
int hp;            // 선언만 — 안에 무엇이 들었는지 모른다 (쓰레기 값)
int hp = 100;      // 선언 + 초기화 — 항상 이렇게 쓴다
```

> **초기화하지 않은 변수는 쓰지 않는다.** 값이 0이 아니라 "직전에 그 메모리를 쓰던 누군가가
> 남긴 쓰레기"다. 게임에서 가장 찾기 어려운 버그의 단골 원인이다.

**변수 이름 규칙**

| 규칙 | 예 |
|---|---|
| 영문·숫자·`_` 만 사용 | `heroHp`, `slime_hp`, `atk1` |
| 숫자로 시작 불가 | ~~`1hp`~~ |
| 대소문자 구분 | `hp`와 `HP`는 다른 변수 |
| 예약어 사용 불가 | ~~`int`~~, ~~`return`~~ |
| **의미가 보이게** | ~~`a`, `x1`~~ → `heroHp`, `damage` |

### 3-2. 자료형 — 그릇의 종류

**왜 필요한가** — 정수와 실수는 메모리에 저장되는 방식이 다르다. 잘못 쓰면 값이 깨진다.

| 자료형 | 크기 | 표현 범위 | 게임에서 쓰는 곳 |
|---|:--:|---|---|
| `char` | 1바이트 | -128 ~ 127 | 맵 타일 (`'#'`, `'.'`), 문자 |
| `int` | 4바이트 | 약 -21억 ~ 21억 | HP, 점수, 좌표, 개수 |
| `float` | 4바이트 | 소수 약 7자리 | 좌표(실수), 속도, 확률 |
| `double` | 8바이트 | 소수 약 15자리 | 정밀한 계산 |
| `unsigned int` | 4바이트 | 0 ~ 약 43억 | 음수가 없는 값 (프레임 수 등) |

```c
int   hp    = 100;      // 정수
float speed = 3.5f;     // 실수 (f를 붙여 float임을 명시)
char  tile  = '#';      // 문자 하나 — 작은따옴표
```

**크기 확인**

```c
printf("int  는 %zu 바이트\n", sizeof(int));     // 4
printf("char 는 %zu 바이트\n", sizeof(char));    // 1
```

### 3-3. 연산자

**왜 필요한가** — 데미지 계산, 확률, 좌표 이동이 전부 연산이다.

**산술 연산자**

| 연산자 | 뜻 | 예 (`a=7, b=2`) | 결과 |
|:--:|---|---|:--:|
| `+` `-` `*` | 더하기·빼기·곱하기 | `a * b` | 14 |
| `/` | 나누기 | `a / b` | **3** (정수끼리는 소수점 버림!) |
| `%` | 나머지 | `a % b` | 1 |

> **정수 나눗셈의 함정** — `7 / 2`는 `3.5`가 아니라 **`3`**이다. 소수점 아래가 버려진다.
> 나머지 `%`는 나중에 아주 많이 쓴다. 난수 범위 만들기(Day 16), 스프라이트 시트 좌표 계산(Day 42)까지.

```c
printf("%d\n", 7 / 2);          // 3      ← 정수 나눗셈
printf("%f\n", 7.0 / 2);        // 3.5    ← 하나만 실수여도 실수 나눗셈
printf("%f\n", (float)7 / 2);   // 3.5    ← 형변환
```

**복합 대입 연산자** — 게임 코드에서 압도적으로 자주 쓴다.

| 표기 | 같은 뜻 |
|---|---|
| `hp -= 12;` | `hp = hp - 12;` |
| `score += 100;` | `score = score + 100;` |
| `x *= 2;` | `x = x * 2;` |

**증감 연산자**

```c
turn++;    // turn = turn + 1
turn--;    // turn = turn - 1
```

### 3-4. `scanf_s` — 값 입력받기

**왜 필요한가** — 게임의 세 칸 중 **입력**을 담당한다.

```c
int damage = 0;

printf("공격력을 입력하세요: ");
scanf_s("%d", &damage);      // & 를 빼먹으면 안 된다
```

```
   scanf_s("%d", &damage);
            ▲      ▲
            │      └── damage가 있는 "주소". 여기에 값을 써 달라는 뜻
            └── 정수 하나를 읽겠다
```

> **`&`를 빼먹는 것이 입문자 오류 1위다.** `scanf_s("%d", damage)`로 쓰면 값이 안 들어오거나
> 프로그램이 죽는다. 왜 `&`가 필요한지는 **Day 18(포인터)** 에서 완전히 이해하게 된다.
> 지금은 "`scanf`에는 `&`를 붙인다"로 외우고 넘어간다. (단, 문자열 `%s`는 예외)

**자료형별 입력**

```c
int   n;      scanf_s("%d", &n);
float f;      scanf_s("%f", &f);
char  c;      scanf_s(" %c", &c);     // %c 앞 공백은 이전 Enter를 건너뛰기 위함
```

**Visual Studio의 `scanf` 경고**

`scanf`를 쓰면 `error C4996: 'scanf': This function or variable may be unsafe` 가 뜬다.
해결은 셋 중 하나.

| 방법 | 코드 |
|---|---|
| **A. `scanf_s` 사용 (권장)** | `scanf_s("%d", &n);` |
| B. 파일 맨 위에 매크로 | `#define _CRT_SECURE_NO_WARNINGS` (`#include`보다 **위**에) |
| C. 프로젝트 설정 | 속성 → C/C++ → 전처리기 → `_CRT_SECURE_NO_WARNINGS` 추가 |

### 3-5. 상수 — 바뀌지 않는 값에 이름 붙이기

**왜 필요한가** — 최대 체력 `100`이 코드 다섯 군데에 박혀 있으면, 밸런싱할 때 하나를 빠뜨린다.

```c
#define MAX_HERO_HP   100          // 전처리기 방식
const int MAX_SLIME_HP = 30;       // const 방식

int heroHp = MAX_HERO_HP;
printf("HP %d / %d\n", heroHp, MAX_HERO_HP);
```

| 방식 | 특징 |
|---|---|
| `#define` | 컴파일 전에 글자 그대로 치환. 자료형이 없다 |
| `const` | 진짜 변수인데 값을 못 바꿈. 자료형 검사가 된다 |

> 게임에서 밸런스 수치(최대 체력, 이동 속도, 데미지 배율)는 **전부 상수로 뽑아 둔다.**
> Day 20에서 이 습관이 왜 중요한지 체감하게 된다.

## 4. 따라 만들기

### Step 1 — 값을 변수에 넣기

```c
#include <stdio.h>

int main(void)
{
    int heroHp  = 100;      // ← 추가
    int slimeHp =  30;      // ← 추가

    printf("===============================\n");
    printf("      전투 시작!\n");
    printf("-------------------------------\n");
    printf("  용사    HP %3d / %3d\n", heroHp,  100);    // ← 100 → heroHp
    printf("  슬라임  HP %3d / %3d\n", slimeHp,  30);    // ← 30 → slimeHp
    printf("===============================\n");

    return 0;
}
```

**✅ 여기까지 실행하면** — 화면은 Day 1과 **똑같다**. 하지만 이제 값이 변수 안에 들어 있다.

### Step 2 — 최대 체력을 상수로

```c
#include <stdio.h>

#define MAX_HERO_HP    100      // ← 추가
#define MAX_SLIME_HP    30      // ← 추가

int main(void)
{
    int heroHp  = MAX_HERO_HP;     // ← 수정
    int slimeHp = MAX_SLIME_HP;    // ← 수정

    printf("===============================\n");
    printf("      전투 시작!\n");
    printf("-------------------------------\n");
    printf("  용사    HP %3d / %3d\n", heroHp,  MAX_HERO_HP);    // ← 수정
    printf("  슬라임  HP %3d / %3d\n", slimeHp, MAX_SLIME_HP);   // ← 수정
    printf("===============================\n");

    return 0;
}
```

**✅ 여기까지 실행하면** — 화면은 그대로. 이제 `MAX_HERO_HP`를 `200`으로 바꾸면 **두 곳이 동시에** 바뀐다.

### Step 3 — 입력받기

```c
    printf("===============================\n\n");

    int damage = 0;                              // ← 추가
    printf("공격력을 입력하세요: ");              // ← 추가
    scanf_s("%d", &damage);                      // ← 추가

    printf("\n입력받은 공격력: %d\n", damage);    // ← 추가 (확인용)
```

**✅ 여기까지 실행하면** — 숫자를 입력하고 Enter를 치면 그 숫자가 그대로 다시 출력된다.

### Step 4 — 실제로 체력 깎기

```c
    int damage = 0;
    printf("공격력을 입력하세요: ");
    scanf_s("%d", &damage);

    int beforeHp = slimeHp;      // ← 추가 (출력용으로 이전 값 보관)
    slimeHp -= damage;           // ← 추가 ★ 오늘의 핵심 한 줄

    printf("\n용사의 공격!  슬라임에게 %d 데미지\n", damage);   // ← 추가
    printf("슬라임 HP %3d → %3d\n", beforeHp, slimeHp);        // ← 추가
```

**✅ 여기까지 실행하면** — 1절의 완성 화면이 나온다. 슬라임 HP가 입력한 만큼 실제로 줄어든다.

### Step 5 — 방어력 넣기 (확장)

```c
#define SLIME_DEF   3        // ← 추가

    // ...
    int realDamage = damage - SLIME_DEF;    // ← 추가

    printf("\n용사의 공격!  (공격력 %d - 방어력 %d)\n", damage, SLIME_DEF);
    printf("슬라임에게 %d 데미지\n", realDamage);

    int beforeHp = slimeHp;
    slimeHp -= realDamage;
    printf("슬라임 HP %3d → %3d\n", beforeHp, slimeHp);
```

**✅ 여기까지 실행하면** — 공격력 12를 넣으면 방어력 3을 뺀 **9**만큼만 깎인다.

> 여기서 이미 문제가 하나 보인다. 공격력에 `1`을 넣으면 데미지가 `-2`가 되어 **HP가 올라간다.**
> 이걸 막으려면 "만약 음수라면 최소 1로" 라는 **판단**이 필요하다. → 내일.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 입력이 무시되고 그냥 넘어감 | `scanf_s("%d", damage)` — **`&` 누락** | `&damage` |
| `error C4996: scanf ... unsafe` | 구버전 함수 경고 | `scanf_s` 사용 |
| 값이 이상하게 큼/작음 | `%d`에 `float` 변수를 넣음 | 서식 지정자와 자료형 일치 |
| 나눗셈 결과가 소수가 아님 | 정수 / 정수 | `(float)a / b` 또는 `a / 2.0` |
| HP가 오히려 올라감 | 데미지가 음수 | 최소 데미지 처리 (내일 `if`로 해결) |
| `error C2065: 선언되지 않은 식별자` | 변수 선언 전에 사용 | 선언을 위로 이동 |
| 값이 매번 다르게 나옴 | 초기화 안 한 변수 사용 | 선언 시 `= 0` 등으로 초기화 |
| `%3d`인데 정렬이 안 맞음 | 한글은 폭 2칸 | 한글 뒤 공백 수를 직접 조정 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| 변수 | 실행 중에 값을 바꿀 수 있는 그릇. **반드시 초기화한다** |
| 자료형 | `int`(정수) `float`(실수) `char`(문자). 크기와 용도가 다르다 |
| 정수 나눗셈 | `7 / 2 == 3`. 소수가 필요하면 형변환 |
| 복합 대입 | `hp -= 12`는 `hp = hp - 12` |
| `scanf_s` | 입력받기. **`&`를 붙인다** (이유는 Day 18) |
| 상수 | 밸런스 수치는 `#define`/`const`로 한 곳에서 관리 |

### 직접 해보기

| 난이도 | 과제 | 힌트 |
|:--:|---|---|
| ★ | 용사도 슬라임에게 반격당하게 하기 | `heroHp -= 5;` 한 줄 |
| ★★ | 남은 HP 비율을 소수로 출력 (`21 / 30 = 70.0%`) | `(float)slimeHp / MAX_SLIME_HP * 100` |
| ★★★ | 공격 2회를 연속으로 입력받아 처리하기 | `scanf_s`를 두 번. 중간 결과도 출력 |
