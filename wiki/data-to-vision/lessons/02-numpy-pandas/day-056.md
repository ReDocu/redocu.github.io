## ② 왜 필요한가

지난주에 수집한 데이터를 다시 봅시다. ([Day 055](day-055.md))

```
[결측]
  address        118건 (2.3%)
  tel          2,904건 (57.0%)
```

전화번호의 **57%가 비어 있습니다.** 이걸 어떻게 해야 할까요?

```python
df["tel"].mean()          # 문자열이라 애초에 안 됨
df.dropna()               # 57%가 날아감 → 5,096건 → 2,192건
df["tel"].fillna("없음")   # 이건 맞나?
```

**정답은 "무엇을 하려는가"에 따라 다릅니다.**

| 목적 | tel 결측 처리 |
|---|---|
| 관광지 위치 지도 | 전화번호가 필요 없음 → **열 삭제** |
| 전화 문의 리스트 만들기 | 전화번호가 핵심 → **결측 행 삭제** |
| "연락처 제공률" 분석 | **결측 자체가 데이터** → 플래그로 변환 |

> ⚠️ **오늘의 가장 큰 위험은 "에러 없이 틀린 결론"입니다.**
>
> ```python
> df["price"].mean()        # 결측은 자동으로 빼고 계산됨 → 8,500
> ```
> 에러가 나지 않습니다. 그런데 **비싼 상품만 가격이 비어 있었다면** 이 평균은 틀렸습니다.
> 결측을 확인하지 않으면 **그럴듯한 숫자에 속습니다.**

## ③ 개념 설명

### 결측치의 정체

pandas 에서 결측은 여러 얼굴로 나타납니다.

| 표현 | 의미 | 나타나는 곳 |
|---|---|---|
| `NaN` | Not a Number (float) | 숫자 열 |
| `None` | 파이썬 None | object 열 |
| `NaT` | Not a Time | datetime 열 |
| `pd.NA` | pandas 통합 결측 | 확장 dtype |

```python
import numpy as np
import pandas as pd

np.nan == np.nan        # False  ← 자기 자신과도 다름!
np.nan is np.nan        # True
pd.isna(np.nan)         # True   ← 반드시 이걸로 확인
```

> ⚠️ **`== np.nan` 으로는 결측을 찾을 수 없습니다.**
> ```python
> df[df["price"] == np.nan]     # ❌ 항상 빈 결과
> df[df["price"].isna()]        # ✅
> ```

### 결측으로 인식되지 않는 결측 — 가장 위험한 함정

```python
df = pd.DataFrame({"tel": ["02-1234-5678", "", "-", "N/A", "없음", None]})

df["tel"].isna().sum()          # 1  ← None 하나만 잡힘
```

**빈 문자열·`"-"`·`"N/A"`·`"없음"` 은 결측이 아니라 "값"입니다.**

```python
# ✅ 읽을 때 지정
df = pd.read_csv("data.csv",
                 na_values=["", "-", "N/A", "n/a", "없음", "미상", "null", "?"])

# ✅ 나중에 변환
df = df.replace(["", "-", "N/A", "없음"], np.nan)

# 공백만 있는 값도
df["tel"] = df["tel"].replace(r"^\s*$", np.nan, regex=True)
```

> **`0` 은 조심해서 판단하세요.**
> 매출 0원은 "0원을 벌었다"일 수도, "값이 없다"일 수도 있습니다.
> **데이터 제공처에 확인하거나, 분포를 보고 판단**해야 합니다.
> 강수량 0mm는 진짜 0이지만, 나이 0세는 결측일 가능성이 높습니다.

### 결측이 생기는 이유 3가지

| 유형 | 설명 | 예시 | 처리 방향 |
|---|---|---|---|
| **미입력** | 있어야 하는데 안 넣음 | 회원가입 시 전화번호 생략 | 대체 또는 삭제 |
| **수집 실패** | 가져오다 실패 | 크롤링 중 요소 누락 | **재수집 먼저 고려** |
| **해당 없음** | 애초에 존재하지 않음 | 미혼자의 배우자 이름 | **결측이 정답** — 채우면 안 됨 |

> **"해당 없음"을 평균으로 채우면 없던 사실을 만들어 냅니다.**
> 관광지의 `tel` 이 없는 건 대부분 **전화번호가 없는 시설**입니다.
> 여기에 평균 전화번호를 넣을 수는 없습니다. 이 경우 결측은 **정보**입니다.

### 결측 패턴 3가지 (통계 용어)

| 유형 | 뜻 | 예 | 삭제해도 되나 |
|---|---|---|---|
| **MCAR** | 완전 무작위 | 장비 오작동으로 무작위 누락 | ✅ 안전 |
| **MAR** | 다른 변수와 관련 | 고령층이 소득 응답을 자주 생략 | ⚠️ 조건부 대체 |
| **MNAR** | 값 자체와 관련 | **고소득자가 소득을 숨김** | ❌ **삭제하면 편향** |

> **MNAR이 가장 위험합니다.**
> 비싼 상품만 가격이 비어 있는데 결측 행을 지우면, **남은 데이터는 저가 상품뿐**입니다.
> 평균 가격이 실제보다 낮게 나오고, **에러는 나지 않습니다.**
>
> **판별법** — 결측 여부로 그룹을 나눠 다른 열의 분포를 비교합니다.
> ```python
> df.groupby(df["price"].isna())["rating"].mean()
> ```
> 두 그룹의 값이 크게 다르면 무작위가 아닙니다.

### 탐지

```python
df.isna()                       # 전체 True/False 표
df.isna().sum()                 # 열별 결측 개수
df.isna().sum() / len(df)       # 열별 결측 비율
df.isna().sum(axis=1)           # 행별 결측 개수
df.isna().any(axis=1).sum()     # 결측이 하나라도 있는 행 수
df.notna().sum()                # 값이 있는 개수

df.info()                       # Non-Null Count 로 한눈에
```

**결측 조합 패턴 보기**

```python
df.isna().value_counts()        # 어떤 열들이 함께 비는지
```

```
address  tel
False    True     2904        ← 주소는 있고 전화만 없음 (가장 많음)
False    False    2074
True     True      100
True     False      18
```

> **함께 비는 열들이 있다면 원인이 같습니다.**
> 위 예에서 `address` 와 `tel` 이 **동시에** 비는 100건은
> 아마 수집 자체가 실패한 행일 겁니다. 재수집 대상입니다.

### 처리 전략 4가지와 선택 기준

```
① 행 삭제      결측이 적고, 그 행 없이도 충분할 때
② 열 삭제      결측이 너무 많거나, 그 열이 필요 없을 때
③ 대푯값 대체   결측이 무작위이고, 값이 꼭 필요할 때
④ 보간         시계열처럼 앞뒤 값에 의미가 있을 때
```

**선택 기준표**

| 결측 비율 | 기본 판단 | 예외 |
|---|---|---|
| **~5%** | 행 삭제해도 무방 | MNAR이면 대체 |
| **5~30%** | 대체 검토 | 핵심 열이면 재수집 |
| **30~60%** | 신중히 — 플래그로 전환 검토 | 대체하면 왜곡 큼 |
| **60%~** | **열 삭제 검토** | 있는 값이 매우 중요하면 유지 |

> ⚠️ **이 표는 출발점이지 규칙이 아닙니다.**
> 3%만 비어도 그게 **가장 중요한 열**이면 재수집해야 하고,
> 80%가 비어도 **있는 20%가 결정적**이면 남겨야 합니다.
> **비율보다 "그 열이 분석에서 하는 역할"이 먼저입니다.**

### ① 행 삭제 — `dropna`

```python
df.dropna()                              # 하나라도 결측이면 삭제
df.dropna(how="all")                     # 전부 결측인 행만
df.dropna(subset=["price", "name"])      # 이 열들만 검사  ← 가장 실용적
df.dropna(thresh=3)                      # 값이 3개 미만인 행 삭제
df.dropna(axis=1)                        # 열 삭제
df.dropna(axis=1, thresh=len(df) * 0.7)  # 70% 이상 채워진 열만 유지
```

| 옵션 | 의미 |
|---|---|
| `how="any"` | 하나라도 결측 (기본) |
| `how="all"` | 전부 결측 |
| `subset=[...]` | **검사할 열 지정** |
| `thresh=n` | **값이 n개 이상**이면 유지 |

> **`subset` 을 쓰세요.** 그냥 `dropna()` 는 관계없는 열의 결측 때문에
> 멀쩡한 행까지 날립니다.
>
> ```python
> df.dropna()                      # tel 이 없다고 관광지가 삭제됨
> df.dropna(subset=["lat", "lng"])  # 좌표 없는 것만 삭제  ✅
> ```

### ② 열 삭제

```python
df = df.drop(columns=["tel", "fax"])

# 결측 비율 기준 자동 삭제
threshold = 0.6
drop_cols = df.columns[df.isna().mean() > threshold]
df = df.drop(columns=drop_cols)
```

### ③ 대푯값 대체 — `fillna`

```python
df["price"].fillna(0)                          # 고정값
df["price"].fillna(df["price"].mean())         # 평균
df["price"].fillna(df["price"].median())       # 중앙값
df["city"].fillna(df["city"].mode()[0])        # 최빈값 (범주형)

df.fillna({"price": 0, "city": "미상"})         # 열마다 다르게
```

**평균 vs 중앙값**

| 상황 | 선택 |
|---|---|
| 분포가 대칭 | 평균 |
| **이상치·왜곡 있음** | **중앙값** ✅ |
| 범주형 | 최빈값 |

```python
prices = [10, 12, 11, 13, 10, 12, 9800]      # 하나가 극단값

np.mean(prices)      # 1409.7   ← 이걸로 채우면 이상해짐
np.median(prices)    # 12.0     ← 훨씬 타당
```

> **의심스러우면 중앙값**입니다. 이상치에 흔들리지 않습니다.

**그룹별 대체 — 훨씬 정확합니다**

```python
# 전체 평균 (거칠다)
df["price"] = df["price"].fillna(df["price"].mean())

# 카테고리별 평균 (정확하다)  ✅
df["price"] = df["price"].fillna(
    df.groupby("category")["price"].transform("mean"))
```

```
전체 평균으로 채움    : 숙박 결측 → 35,000 (음식점까지 섞인 평균)
카테고리별로 채움      : 숙박 결측 → 82,000 (숙박만의 평균)
```

> **`transform` 은 그룹 집계 결과를 원래 행 수에 맞춰 돌려줍니다.**
> `groupby().mean()` 은 그룹 수만큼 나오지만, `transform("mean")` 은 원래 길이 그대로입니다.
> 그래서 `fillna` 에 바로 넣을 수 있습니다. ([Day 050](day-050.md))

**앞뒤 값으로 채우기**

```python
df["temp"].ffill()          # 앞의 값으로 (forward fill)
df["temp"].bfill()          # 뒤의 값으로 (backward fill)
df["temp"].ffill(limit=2)   # 연속 2개까지만
```

> ⚠️ **pandas 2.x부터 `fillna(method="ffill")` 는 폐기 예정입니다.**
> ```
> FutureWarning: DataFrame.fillna with 'method' is deprecated
> ```
> **`df.ffill()` / `df.bfill()`** 을 쓰세요.

### ④ 보간 — `interpolate`

**앞뒤 값 사이를 계산해서 채웁니다.** 시계열에 적합합니다.

```python
df["temp"].interpolate()                    # 선형 (기본)
df["temp"].interpolate(method="linear")
df["temp"].interpolate(method="time")       # 시간 간격 반영 (인덱스가 시간일 때)
df["temp"].interpolate(method="spline", order=2)
df["temp"].interpolate(limit_direction="both")   # 양쪽 끝도 채움
```

```
원본     10, NaN, NaN, 16, 18
ffill    10, 10,  10,  16, 18       ← 계단
보간     10, 12,  14,  16, 18       ← 자연스러움  ✅
```

> ⚠️ **범주형·순서 없는 데이터에는 절대 쓰지 마세요.**
> 지역 코드 `[1, NaN, 6]` 을 보간하면 `3.5` 가 됩니다. **존재하지 않는 지역**입니다.

### 결측을 정보로 — 플래그 열

**채우기 전에 "원래 비어 있었다"를 기록합니다.**

```python
df["tel_missing"] = df["tel"].isna()
df["tel"] = df["tel"].fillna("정보없음")
```

| 이유 | 설명 |
|---|---|
| **되돌아볼 수 있음** | 나중에 "채운 값"과 "원래 값"을 구분 |
| **결측 자체가 신호** | 전화번호 없는 시설의 특성이 있을 수 있음 |
| **모델 입력으로 유용** | 머신러닝에서 결측 여부가 예측력을 갖는 경우가 많음 |

```python
# 결측 여부로 다른 값이 달라지는지 확인
df.groupby("tel_missing")[["visitors", "rating"]].mean()
```

```
tel_missing   visitors   rating
False          12,400      4.2
True            3,100      3.8       ← 확연히 다름 → MNAR 의심
```

### 처리 전후 반드시 비교

```python
before = df["price"].describe()
df["price"] = df["price"].fillna(df["price"].mean())
after = df["price"].describe()

pd.concat([before, after], axis=1, keys=["처리 전", "처리 후"])
```

| 지표 | 평균 대체 시 | 중앙값 대체 시 |
|---|---|---|
| 평균 | **변하지 않음** | 약간 변함 |
| **표준편차** | **줄어듦** ⚠️ | 줄어듦 |
| 분포 모양 | **가운데가 뾰족해짐** | 뾰족해짐 |

> ⚠️ **대체는 항상 분산을 줄입니다.**
> 같은 값을 여러 개 넣으니 당연합니다.
> **결측이 30%인데 평균으로 채우면 "가짜 데이터 30%"** 가 만들어집니다.
> 채운 뒤에는 반드시 분포를 다시 확인하세요.

## ④ 단계별 실습

### Step 1. 결측 진단

```python
"""결측 현황을 종합적으로 파악합니다."""

import numpy as np
import pandas as pd

# ── 실습용 데이터 (수집 데이터를 흉내 냄) ──
rng = np.random.default_rng(42)
N = 200

df = pd.DataFrame({
    "id": range(1, N + 1),
    "name": [f"관광지{i:03d}" for i in range(1, N + 1)],
    "category": rng.choice(["자연", "역사", "체험", "쇼핑"], N),
    "area": rng.choice(["서울", "부산", "제주", "강원"], N),
    "price": rng.integers(0, 30000, N).astype(float),
    "rating": (rng.normal(4.0, 0.6, N)).round(1).clip(1, 5),
    "visitors": rng.integers(100, 50000, N).astype(float),
    "tel": [f"0{rng.integers(2, 64)}-{rng.integers(100, 999)}-"
            f"{rng.integers(1000, 9999)}" for _ in range(N)],
    "opened": pd.date_range("2015-01-01", periods=N, freq="15D"),
})

# ── 의도적으로 결측 만들기 (패턴을 다르게) ──
# ① 무작위 결측 (MCAR)
df.loc[rng.choice(N, 12, replace=False), "rating"] = np.nan

# ② 전화번호는 절반 이상 없음
df.loc[rng.choice(N, 118, replace=False), "tel"] = np.nan

# ③ 비싼 곳만 방문객 수가 없음 (MNAR!)
expensive = df[df["price"] > 22000].index
df.loc[expensive, "visitors"] = np.nan

# ④ 결측으로 인식 안 되는 값들
df.loc[rng.choice(N, 8, replace=False), "category"] = ""
df.loc[rng.choice(N, 5, replace=False), "area"] = "-"

print("=" * 76)
print("                       결측 진단")
print("=" * 76)

# ══════════ ① 겉으로 보이는 결측 ══════════
print(f"\n[① isna() 로 잡히는 결측]")
print(f"  {'열':<12}{'결측':>8}{'비율':>9}  분포")
print("  " + "-" * 52)

for col in df.columns:
    n = df[col].isna().sum()
    pct = n / len(df) * 100
    bar = "■" * int(pct / 3)
    mark = "⚠" if pct > 30 else " "
    print(f" {mark}{col:<12}{n:>8}{pct:>8.1f}%  {bar}")

# ══════════ ② 숨은 결측 ══════════
print(f"\n[② 결측으로 인식되지 않는 값]")
```

### Step 3. 결측 처리 파이프라인 (오늘의 종합 예제)

```python
"""근거를 남기며 결측을 처리하는 재사용 가능한 함수."""

import numpy as np
import pandas as pd

HIDDEN_NA = ["", " ", "-", "--", "N/A", "n/a", "NA", "없음", "미상",
             "null", "NULL", "?", "nan", "None"]


def normalize_na(df, extra=None):
    """숨은 결측을 NaN 으로 변환합니다."""
    values = HIDDEN_NA + (extra or [])
    out = df.replace(values, np.nan)

    for col in out.select_dtypes(include="object").columns:
        out[col] = out[col].replace(r"^\s*$", np.nan, regex=True)

    return out


def missing_report(df, name="데이터"):
    """결측 현황 표를 만듭니다."""
    report = pd.DataFrame({
        "dtype": df.dtypes.astype(str),
        "결측수": df.isna().sum(),
        "결측률": (df.isna().mean() * 100).round(1),
        "고유값": df.nunique(),
    })
    report["권장"] = report["결측률"].apply(
        lambda p: "그대로" if p == 0
        else "행삭제" if p <= 5
        else "대체" if p <= 30
        else "플래그+대체" if p <= 60
        else "열삭제 검토")

    return report.sort_values("결측률", ascending=False)


def diagnose_mnar(df, col, compare_cols, threshold=0.4):
    """
    결측이 무작위인지 판별합니다.

    반환: (무작위 여부, 근거 표)
    """
    if df[col].isna().sum() == 0:
        return True, None

    flag = df[col].isna()
    numeric = [c for c in compare_cols
               if c in df.columns and pd.api.types.is_numeric_dtype(df[c])]

    if not numeric:
        return True, None

    table = df.groupby(flag)[numeric].mean()
    table.index = ["값 있음", "결측"]

    suspicious = []
    for c in numeric:
        std = df[c].std()
        if std and abs(table.loc["결측", c] - table.loc["값 있음", c]) > std * threshold:
            suspicious.append(c)

    return len(suspicious) == 0, table.round(2)


def handle_missing(df, plan, verbose=True):
    """
    계획표에 따라 결측을 처리합니다.

    plan : {열이름: 전략}
        'drop_row'    행 삭제
        'drop_col'    열 삭제
        'mean'        평균
        'median'      중앙값
        'mode'        최빈값
        'zero'        0
        'ffill'       앞의 값
        'interpolate' 보간
        ('group', 기준열, 'median')   그룹별
        ('const', 값)                 고정값
        'flag'        플래그만 만들고 그대로 둠

    반환: (처리된 df, 처리 이력)
    """
    out = df.copy()
    history = []

    def log(col, strategy, before, note=""):
        after = out[col].isna().sum() if col in out.columns else 0
        history.append({
            "열": col, "전략": strategy,
            "처리전": before, "처리후": after,
            "채움": before - after, "비고": note,
        })

    # ── ① 플래그 먼저 (채우기 전에!) ──
    for col, strategy in plan.items():
        if col not in out.columns:
            continue
        if strategy in ("flag",) or (isinstance(strategy, str)
                                     and strategy not in ("drop_col",)):
            if out[col].isna().any():
                out[f"{col}_was_na"] = out[col].isna()

    # ── ② 열 삭제 ──
    drop_cols = [c for c, s in plan.items() if s == "drop_col" and c in out.columns]
    if drop_cols:
        for c in drop_cols:
            history.append({"열": c, "전략": "drop_col",
                            "처리전": out[c].isna().sum(), "처리후": 0,
                            "채움": 0, "비고": "열 제거"})
        out = out.drop(columns=drop_cols)

    # ── ③ 행 삭제 ──
    row_cols = [c for c, s in plan.items() if s == "drop_row" and c in out.columns]
    if row_cols:
        before_rows = len(out)
        out = out.dropna(subset=row_cols)
        history.append({"열": ", ".join(row_cols), "전략": "drop_row",
                        "처리전": before_rows, "처리후": len(out),
                        "채움": before_rows - len(out), "비고": "행 제거"})

    # ── ④ 채우기 ──
    for col, strategy in plan.items():
        if col not in out.columns or strategy in ("drop_col", "drop_row", "flag"):
            continue

        before = out[col].isna().sum()
        if before == 0:
            continue

        if isinstance(strategy, tuple):
            kind = strategy[0]

            if kind == "group":
                _, by, agg = strategy
                out[col] = out[col].fillna(
                    out.groupby(by)[col].transform(agg))
                out[col] = out[col].fillna(getattr(out[col], agg)())   # 잔여
                log(col, f"group({by}, {agg})", before)

            elif kind == "const":
                out[col] = out[col].fillna(strategy[1])
                log(col, f"const({strategy[1]})", before)

        elif strategy == "mean":
            out[col] = out[col].fillna(out[col].mean())
            log(col, "mean", before, f"{out[col].mean():,.1f}")

        elif strategy == "median":
            out[col] = out[col].fillna(out[col].median())
            log(col, "median", before, f"{out[col].median():,.1f}")

        elif strategy == "mode":
            mode = out[col].mode()
            if len(mode):
                out[col] = out[col].fillna(mode[0])
            log(col, "mode", before, str(mode[0]) if len(mode) else "-")

        elif strategy == "zero":
            out[col] = out[col].fillna(0)
            log(col, "zero", before)

        elif strategy == "ffill":
            out[col] = out[col].ffill().bfill()
            log(col, "ffill+bfill", before)

        elif strategy == "interpolate":
            out[col] = out[col].interpolate(limit_direction="both")
            log(col, "interpolate", before)

    hist = pd.DataFrame(history)

    if verbose and len(hist):
        print("\n[처리 이력]")
        print(hist.to_string(index=False))

    return out, hist


# ══════════ 실행 ══════════
if __name__ == "__main__":
    print("=" * 80)
    print("                     결측 처리 파이프라인")
    print("=" * 80)

    # ── ① 숨은 결측 정규화 ──
    clean = normalize_na(df)

    print("\n[① 결측 현황과 권장 전략]")
    print(missing_report(clean).to_string())

    # ── ② MNAR 진단 ──
    print("\n[② 무작위 결측 진단]")
    for col in ["visitors", "rating"]:
        is_random, table = diagnose_mnar(clean, col, ["price", "rating", "visitors"])
        verdict = "✓ 무작위(MCAR)" if is_random else "⚠ 무작위 아님(MNAR)"
        print(f"\n  {col}: {verdict}")
        if table is not None:
            print(table.to_string())

    # ── ③ 처리 계획 ──
    plan = {
        "tel": "drop_col",                       # 59% 결측 + 분석에 불필요
        "category": ("const", "미분류"),          # 범주형 — 별도 값으로
        "area": ("const", "미상"),
        "rating": ("group", "category", "median"),   # 무작위 → 그룹 중앙값
        "visitors": "flag",                      # MNAR → 채우지 않고 플래그만
    }

    print(f"\n[③ 처리 계획]")
    for col, s in plan.items():
        print(f"  {col:<12}{s}")

    if len(remaining):

    print(f"\n[⑤ 분포 훼손 확인]")
    for col in ["rating"]:

        print(f"    중앙값   {b.median():.3f} → {a.median():.3f}")
        print(f"    표준편차 {b.std():.3f} → {a.std():.3f} "
              f"({(a.std() / b.std() - 1) * 100:+.1f}%)")

    print(f"\n[⑥ 결측 플래그의 활용]")
    if "visitors_was_na" in processed.columns:
        cmp = processed.groupby("visitors_was_na")["price"].agg(["count", "mean"])

        print(f"    이 플래그는 버리지 말고 분석 변수로 쓰세요.")
```

### `== np.nan` 으로 결측 찾기

### 숨은 결측을 못 봄

```python
df["tel"].isna().sum()           # 0건 — 사실은 "-" 가 50건
```

**해결** — 읽을 때 `na_values` 지정 또는 `replace` 로 변환

```python
pd.read_csv(path, na_values=["", "-", "N/A", "없음"])
```

### 그냥 `dropna()`

```python
df.dropna()                      # 관계없는 열 때문에 66% 소멸
```

**해결** — `df.dropna(subset=["핵심열1", "핵심열2"])`

```python
df = df.dropna(subset=["visitors"])     # 비싼 곳이 통째로 사라짐
```

**해결** — 결측 여부로 그룹을 나눠 다른 열의 평균을 비교합니다.

### 이상치가 있는데 평균으로 대체

```python
df["price"].fillna(df["price"].mean())     # 극단값에 끌려간 평균
```

**해결** — 중앙값을 쓰거나, 이상치를 먼저 처리합니다. ([Day 057](day-057.md))


**해결** — 최빈값 또는 `"미상"` 같은 별도 범주

```python
df["area_code"].interpolate()     # [1, NaN, 6] → [1, 3.5, 6]
```

**해결** — 보간은 **시계열·연속형에만** 씁니다.

```python
"""결측 처리 전략 자동 추천."""

import numpy as np
import pandas as pd


def recommend_strategy(df, target_cols=None, critical=None,
                       group_candidates=None, verbose=True):
    """
    열별로 결측 처리 전략을 추천합니다.

    critical         : 반드시 값이 있어야 하는 열 (분석의 핵심)
    group_candidates : 그룹별 대체에 쓸 수 있는 범주형 열
    """
    cols = target_cols or df.columns.tolist()
    critical = set(critical or [])
    group_candidates = group_candidates or [
        c for c in df.columns
        if df[c].dtype == "object" and 2 <= df[c].nunique() <= 20
    ]

    rows = []

    for col in cols:
        s = df[col]
        n_na = s.isna().sum()
        rate = n_na / len(df) * 100

        info = {
            "열": col,
            "타입": str(s.dtype),
            "결측률": round(rate, 1),
            "고유값": s.nunique(),
        }

        # ── 결측 없음 ──
        if n_na == 0:
            info.update(전략="없음", 근거="결측 없음", 위험="-")
            rows.append(info)
            continue

        is_num = pd.api.types.is_numeric_dtype(s)
        is_dt = pd.api.types.is_datetime64_any_dtype(s)

        # ── 무작위성 검사 ──
        random_ok, evidence = True, ""
        numeric_cols = [c for c in df.columns
                        if c != col and pd.api.types.is_numeric_dtype(df[c])
                        and df[c].isna().mean() < 0.5]

        if numeric_cols:
            flag = s.isna()
            for c in numeric_cols[:5]:
                std = df[c].std()
                if not std or np.isnan(std):
                    continue
                gap = abs(df.loc[flag, c].mean() - df.loc[~flag, c].mean())
                if gap > std * 0.5:
                    random_ok = False
                    evidence = f"{c} 평균차 {gap:,.0f} (>0.5σ)"
                    break

        # ── 전략 결정 ──
        if rate > 70 and col not in critical:
            strategy = "drop_col"
            reason = f"결측 {rate:.0f}% — 정보량 부족"
            risk = "낮음"

        elif not random_ok:
            strategy = "flag (채우지 않음)"
            reason = f"MNAR 의심 — {evidence}"
            risk = "높음 — 어떤 대체도 왜곡"

        elif col in critical:
            strategy = "drop_row"
            reason = "핵심 열 — 추정값 사용 불가"
            risk = f"데이터 {rate:.0f}% 손실"

        elif is_dt:
            strategy = "interpolate(time) 또는 NaT 유지"
            reason = "날짜 — 고정값 대체 금지"
            risk = "중간"

        elif is_num:
            if s.nunique() <= 20 and (s.dropna() % 1 == 0).all():
                strategy = "const(-1) 또는 mode"
                reason = "정수 코드로 보임 — 평균 금지"
                risk = "낮음"
            else:
                skew = s.skew()
                agg = "median" if abs(skew) > 1 else "mean"

                if group_candidates:
                    best = max(group_candidates,
                               key=lambda g: df.groupby(g)[col].std().mean()
                               if df[g].notna().any() else 0)
                    strategy = f"group({best}, {agg})"
                    reason = f"왜도 {skew:.2f} → {agg}, 그룹별 대체"
                else:
                    strategy = agg
                    reason = f"왜도 {skew:.2f}"

                risk = f"표준편차 약 {rate * 0.4:.0f}% 감소 예상"

        else:
            if rate <= 5:
                strategy = "drop_row"
                reason = f"결측 {rate:.1f}% — 손실 미미"
                risk = "낮음"
            else:
                strategy = "const('미분류')"
                reason = "범주형 — 별도 범주로 보존"
                risk = "낮음"

        info.update(전략=strategy, 근거=reason, 위험=risk)
        rows.append(info)

    result = pd.DataFrame(rows)
    result = result[result["결측률"] > 0].sort_values("결측률", ascending=False)

    if verbose:
        print("=" * 96)
        print("                          결측 처리 전략 추천")
        print("=" * 96)

        if result.empty:
            print("\n  결측이 없습니다.")
            return result

        for _, r in result.iterrows():
            icon = {"높음": "🔴", "중간": "🟡"}.get(str(r["위험"])[:2], "🟢")
            print(f"\n  {icon} {r['열']}  ({r['타입']}, 결측 {r['결측률']}%)")
            print(f"     전략 : {r['전략']}")
            print(f"     근거 : {r['근거']}")
            print(f"     위험 : {r['위험']}")

        print("\n" + "=" * 96)
        print("  ⚠ 이것은 '추천'입니다. 최종 판단은 분석 목적에 따라 사람이 합니다.")
        print("=" * 96)

    return result


if __name__ == "__main__":
    recommend_strategy(
        df,
        critical=["price"],
        group_candidates=["category", "area"],
    )
```

| # | 조건 | 전략 | 이유 |
|---|---|---|---|
| ① | 결측 70% 초과 (비핵심) | **열 삭제** | 남은 30%로는 신뢰 못 함 |
| ② | **MNAR 의심** | **플래그만** | 어떤 값으로 채워도 왜곡 |

| ⑤ | 정수 + 고유값 적음 | `-1` / 최빈값 | **코드일 가능성** — 평균 금지 |
| ⑥ | 연속형 + 왜도 큼 | **중앙값** | 이상치에 강함 |
| ⑦ | 범주형 | 별도 범주 | "미분류"도 하나의 정보 |

> **⑤번이 실수하기 쉽습니다.**
> `area_code`, `sigungu_code`, `type_id` 는 **숫자로 저장돼 있지만 범주**입니다.
> 평균을 내면 존재하지 않는 코드가 나옵니다.
>
> **판별 힌트** — 고유값이 20개 이하이고 전부 정수면 코드일 확률이 높습니다.
> 확실히 하려면 **열 이름에 `code`·`id`·`type` 이 있는지** 함께 봅니다.

처리가 데이터를 얼마나 훼손했는지 정량적으로 보여야 합니다.

```python
"""결측 처리 전후 검증."""

import numpy as np
import pandas as pd


def validate_imputation(before, after, key=None, verbose=True):
    """
    결측 처리 전후를 비교해 훼손 정도를 측정합니다.

    반환: dict(passed, warnings, metrics)
    """
    warnings_list = []
    metrics = {}

    line = "=" * 84

    if verbose:
        print(line)
        print("                        결측 처리 검증")
        print(line)

    # ══════════ ① 규모 ══════════
    row_loss = (len(before) - len(after)) / len(before) * 100
    metrics["row_loss_pct"] = round(row_loss, 2)

    if verbose:
        print(f"\n[① 규모]")
        print(f"  행 : {len(before):,} → {len(after):,}  ({row_loss:+.1f}%)")
        print(f"  열 : {before.shape[1]} → {after.shape[1]}")

    if row_loss > 30:
        warnings_list.append(("치명", f"행 손실 {row_loss:.0f}% — 대체 전략 재검토"))
    elif row_loss > 10:
        warnings_list.append(("경고", f"행 손실 {row_loss:.0f}%"))

    dropped = set(before.columns) - set(after.columns)
    added = set(after.columns) - set(before.columns)

    if verbose:
        if dropped:
            print(f"  제거된 열 : {sorted(dropped)}")
        if added:
            print(f"  추가된 열 : {sorted(added)}")

    # ══════════ ② 결측 해소 ══════════
    na_before = before.isna().sum().sum()
    na_after = after.isna().sum().sum()
    metrics["na_before"], metrics["na_after"] = int(na_before), int(na_after)

    if verbose:
        print(f"\n[② 결측]")
        print(f"  {na_before:,}개 → {na_after:,}개 "
              f"({(1 - na_after / na_before) * 100:.1f}% 해소)"
              if na_before else "  결측 없음")

    # ══════════ ③ 분포 훼손 ══════════
    common = [c for c in before.columns
              if c in after.columns and pd.api.types.is_numeric_dtype(before[c])]

    if verbose and common:
        print(f"\n[③ 수치형 분포 변화]")
        print(f"  {'열':<14}{'평균Δ%':>9}{'중앙값Δ%':>11}"
              f"{'표준편차Δ%':>12}{'왜도Δ':>9}  판정")
        print("  " + "-" * 70)

    for col in common:
        b, a = before[col].dropna(), after[col].dropna()

        if len(b) < 2 or len(a) < 2 or b.mean() == 0:
            continue

        d_mean = (a.mean() - b.mean()) / abs(b.mean()) * 100
        d_med = ((a.median() - b.median()) / abs(b.median()) * 100
                 if b.median() else 0)
        d_std = (a.std() - b.std()) / b.std() * 100 if b.std() else 0
        d_skew = a.skew() - b.skew()

        metrics[f"{col}_std_change"] = round(d_std, 1)

        if abs(d_std) > 20:
            verdict, level = "❌ 심각", "치명"
        elif abs(d_std) > 10:
            verdict, level = "⚠ 주의", "경고"
        else:
            verdict, level = "✓", None

        if level:
            warnings_list.append(
                (level, f"'{col}' 표준편차 {d_std:+.1f}% — 분산 왜곡"))

        if abs(d_mean) > 5:
            warnings_list.append(
                ("경고", f"'{col}' 평균 {d_mean:+.1f}% 이동 — 편향 발생"))

        if verbose:
            print(f"  {col:<14}{d_mean:>8.1f}%{d_med:>10.1f}%"
                  f"{d_std:>11.1f}%{d_skew:>9.2f}  {verdict}")

    # ══════════ ④ 값 집중 검사 ══════════
    if verbose:
        print(f"\n[④ 특정 값 집중 (대체 흔적)]")

    concentrated = False
    for col in common:
        vc = after[col].value_counts(normalize=True)
        if len(vc) == 0:
            continue

        top_val, top_pct = vc.index[0], vc.iloc[0] * 100
        before_pct = (before[col] == top_val).mean() * 100

        if top_pct > 10 and top_pct - before_pct > 5:
            concentrated = True
            if verbose:
                print(f"  ⚠ {col:<14}값 {top_val:,.1f} 이 {top_pct:.1f}% "
                      f"(처리 전 {before_pct:.1f}%)")
            warnings_list.append(
                ("경고", f"'{col}' 대체값이 {top_pct:.0f}%를 차지 — 히스토그램 확인"))

    if verbose and not concentrated:
        print("  없음")

    # ══════════ ⑤ 범주 구성 변화 ══════════
    cat_cols = [c for c in before.columns
                if c in after.columns and before[c].dtype == "object"
                and before[c].nunique() <= 20]

    if verbose and cat_cols:
        print(f"\n[⑤ 범주 구성 변화 (최대 변화폭)]")

    for col in cat_cols:
        b = before[col].value_counts(normalize=True) * 100
        a = after[col].value_counts(normalize=True) * 100
        diff = (a - b).abs().max()

        if pd.isna(diff):
            continue

        mark = "⚠" if diff > 5 else " "
        if verbose:
            print(f" {mark}{col:<16}{diff:>6.1f}%p")

        if diff > 5:
            warnings_list.append(("경고", f"'{col}' 범주 비율이 {diff:.1f}%p 변동"))

    # ══════════ ⑥ 키 무결성 ══════════
    if key and key in before.columns and key in after.columns:
        dup = after[key].duplicated().sum()
        lost = len(set(before[key]) - set(after[key]))

        if verbose:
            print(f"\n[⑥ 키 '{key}']")
            print(f"  중복 : {dup}건")
            print(f"  소실 : {lost}건")

        if dup:
            warnings_list.append(("치명", f"키 '{key}' 중복 {dup}건"))

    # ══════════ 결과 ══════════
    fatal = [w for w in warnings_list if w[0] == "치명"]
    warn = [w for w in warnings_list if w[0] == "경고"]
    passed = not fatal

    if verbose:
        print(f"\n{line}")
        print(f"  판정: {'✅ 통과' if passed else '❌ 재검토 필요'}"
              f"   (치명 {len(fatal)} · 경고 {len(warn)})")
        print(line)

        for level, msg in warnings_list:
            print(f"  {'🔴' if level == '치명' else '🟡'} [{level}] {msg}")

        if not warnings_list:
            print("  문제 없음")

        print(line)

    return {"passed": passed, "warnings": warnings_list, "metrics": metrics}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    # 나쁜 처리: 26% 결측을 전부 평균으로
    bad = df.copy()
    bad["visitors"] = bad["visitors"].fillna(bad["visitors"].mean())
    bad["rating"] = bad["rating"].fillna(bad["rating"].mean())
    bad = bad.dropna()

    print(">>> 나쁜 처리 검증\n")
    validate_imputation(df, bad, key="id")
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 탐지 | **`isna()`** (`== np.nan` ❌) · `df.info()` |
| 숨은 결측 | `""` `"-"` `"N/A"` → **`na_values`** 로 읽거나 `replace` |
| 결측 이유 | 미입력 / 수집 실패 / **해당 없음** (채우면 안 됨) |
| **MNAR** | 값 자체 때문에 비는 것 → **삭제하면 편향** |
| 판별법 | `df.groupby(df[col].isna())[다른열].mean()` 비교 |
| 행 삭제 | **`dropna(subset=[...])`** — 그냥 `dropna()` ❌ |
| 열 삭제 | 결측 60~70% 초과 + 분석에 불필요할 때 |
| 대체 | 왜도 크면 **중앙값** · 범주형은 최빈값/별도 범주 |
| **그룹 대체** | `groupby(g)[c].transform("median")` — 훨씬 정확 |
| 보간 | **시계열·연속형만** · 범주형 ❌ |
| 플래그 | **채우기 전에** `df[c+"_was_na"] = df[c].isna()` |
| 검증 | **표준편차 감소**(대체) · **평균 이동**(삭제 편향) |

**오늘 반드시 기억할 세 가지**
> ① **`isna()` 가 0이어도 결측이 없는 게 아닙니다.** `""` `"-"` `"N/A"` 를 먼저 확인하세요.
> ② **삭제 전에 편향을 확인하세요.** 결측 여부로 그룹을 나눠 다른 열의 평균을 비교합니다.
> ③ **채운 뒤 표준편차를 확인하세요.** 20% 이상 줄었다면 분포를 망가뜨린 것입니다.

**과제**
① 수집 데이터의 **숨은 결측**을 찾아 `na_values` 목록 작성
② 열별 결측률 표와 **MNAR 진단 결과** 정리
③ 열마다 처리 전략과 **선택 근거를 한 문장씩** 문서화
④ 처리 전후 `describe()` 비교표 제출 — 표준편차 변화율 포함
⑤ 결측 플래그 열을 만들어 **결측 여부가 다른 변수와 관련 있는지** 확인
