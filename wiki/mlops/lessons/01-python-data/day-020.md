## ② 왜 필요한가

지금 수집기는 소스를 하나 추가할 때마다 **코드를 고쳐야** 합니다.

```python
collector = AirQualityCollector(key, sido="서울")     # 서울만
```

부산도 받으려면? 대구도? 미세먼지 말고 기상 데이터도?
**클래스를 만들고, 파일을 고치고, 다시 배포해야** 합니다.

**설정으로 분리하면 이렇게 됩니다.**

```yaml
sources:
  - name: air_seoul
    type: public_data
    params: { sidoName: 서울 }
  - name: air_busan
    type: public_data
    params: { sidoName: 부산 }
```

```bash
$ collect run --config config.yaml
```

## ③ 개념 설명

### 왜 yaml인가

| 형식 | 주석 | 가독성 | 중첩 | 용도 |
|---|---|---|---|---|
| JSON | ❌ | 보통 | ⭕ | 데이터 교환 |
| **YAML** | ✅ | **좋음** | ⭕ | **설정** ⭐ |
| TOML | ✅ | 좋음 | 제한적 | `pyproject.toml` |
| `.env` | ✅ | 단순 | ❌ | 시크릿·환경 변수 |

**설정 파일에는 주석이 필수입니다.** "이 값이 왜 이건지"를 적어야 합니다.
JSON은 주석을 쓸 수 없습니다.

### YAML 문법

```yaml
# 주석은 # 으로

# 스칼라
name: airquality           # 문자열 (따옴표 생략 가능)
enabled: true              # 불리언
interval: 3600             # 정수
rate: 1.5                  # 실수
memo: null                 # None  (~ 도 가능)

# 문자열에 특수문자가 있으면 따옴표
url: "http://api.example.com:8080/v1?a=1"
version: "1.0"             # 따옴표 없으면 실수 1.0 이 됨!

# 리스트
tags:
  - 업무
  - 급함
tags_inline: [업무, 급함]    # 같은 뜻

# 딕셔너리 (중첩은 들여쓰기 2칸)
database:
  host: localhost
  port: 5432
  credentials:
    user: mlops

# 리스트 안의 딕셔너리
sources:
  - name: air_seoul
    type: public_data
    enabled: true
  - name: news
    type: crawler
    enabled: false

# 여러 줄 문자열
description: |
  줄바꿈이
  그대로 유지됩니다
summary: >
  줄바꿈이
  공백으로 합쳐집니다

# 환경 변수 참조 (직접 구현해야 함 — YAML 표준 기능 아님)
service_key: ${PUBLIC_DATA_KEY}
```

### YAML 함정

| 함정 | 결과 | 해결 |
|---|---|---|
| `version: 1.0` | 실수 `1.0` | `version: "1.0"` |
| `enabled: yes` | 불리언 `True` (1.1) 또는 문자열 (1.2) | `true` 를 쓰기 |
| `code: 00` | 정수 `0` | `code: "00"` |
| **탭 문자** | 파싱 에러 | **공백만** 사용 |
| 들여쓰기 불일치 | 파싱 에러 | 2칸으로 통일 |
| `key:value` (공백 없음) | 문자열 하나로 인식 | `key: value` |

> **`yaml.safe_load()` 를 쓰세요.** `yaml.load()` 는 임의 파이썬 객체를 만들 수 있어 **보안 위험**입니다.

### 설정 로딩

```python
import yaml
from pathlib import Path

def load_config(path: Path) -> dict:
    with path.open(encoding="utf-8") as f:
        return yaml.safe_load(f) or {}
```

### 환경 변수 치환

**시크릿은 yaml에 직접 쓰면 안 됩니다.** 참조만 두고 실행 시 채웁니다.

```yaml
service_key: ${PUBLIC_DATA_KEY}
```

```python
import os
import re

PATTERN = re.compile(r"\$\{([A-Za-z_][A-Za-z0-9_]*)\}")

def expand_env(value):
    """설정 안의 ${VAR} 를 환경 변수로 치환합니다."""
    if isinstance(value, str):
        def replace(m):
            name = m.group(1)
            env = os.getenv(name)
            if env is None:
                raise KeyError(f"환경 변수 {name} 가 설정되지 않았습니다")
            return env
        return PATTERN.sub(replace, value)
    if isinstance(value, dict):
        return {k: expand_env(v) for k, v in value.items()}
    if isinstance(value, list):
        return [expand_env(v) for v in value]
    return value
```

**설정 파일은 커밋해도 안전하고, 실제 값은 `.env` 에 있습니다.**

### 설정 검증

**잘못된 설정은 로딩 시점에 거부해야 합니다.**

```python
@dataclass(frozen=True)
class SourceConfig:
    name: str
    type: str
    url: str
    enabled: bool = True
    params: dict = field(default_factory=dict)

    def __post_init__(self):
        if not self.name:
            raise ConfigError("name 은 필수입니다")
        if self.type not in ("public_data", "crawler", "json_api"):
            raise ConfigError(f"알 수 없는 type: {self.type}")
```

**yaml의 딕셔너리를 그대로 쓰지 말고 dataclass로 변환**하세요 ([Day 012](day-012.md)).
오타(`enabld: true`)를 즉시 발견할 수 있습니다.

```python
"""데이터 모델과 예외. 아무것도 import하지 않습니다."""

from dataclasses import dataclass, field
from datetime import datetime
from typing import Any


# ---------- 예외 ----------

class CollectKitError(Exception):
    """이 패키지의 기본 예외."""


class ConfigError(CollectKitError):
    """설정이 잘못됨."""


class SourceError(CollectKitError):
    """수집 실패."""


class AuthError(SourceError):
    """인증 실패 — 재시도 무의미."""


class QuotaExceeded(SourceError):
    """호출 한도 초과."""


class NoMoreData(SourceError):
    """더 이상 데이터 없음 — 정상 종료 신호."""


class Blocked(SourceError):
    """robots.txt 등에 의해 금지됨."""


# ---------- 통계 ----------

@dataclass
class SourceStats:
    """소스 하나의 수집 통계."""

    name: str
    requests: int = 0
    pages: int = 0
    items: int = 0
    dropped: int = 0
    retries: int = 0
    failures: int = 0
    wait_seconds: float = 0.0
    elapsed: float = 0.0
    error: str | None = None

    @property
    def ok(self) -> bool:
        return self.error is None and self.items > 0

    def as_dict(self) -> dict[str, Any]:
        return {
            "name": self.name,
            "requests": self.requests,
            "pages": self.pages,
            "items": self.items,
            "dropped": self.dropped,
            "retries": self.retries,
            "failures": self.failures,
            "wait_seconds": round(self.wait_seconds, 2),
            "elapsed_seconds": round(self.elapsed, 2),
            "error": self.error,
            "ok": self.ok,
        }


@dataclass
class RunResult:
    """전체 실행 결과."""

    started_at: str = field(default_factory=lambda: datetime.now().isoformat(timespec="seconds"))
    finished_at: str = ""
    stats: list[SourceStats] = field(default_factory=list)

    @property
    def total_items(self) -> int:
        return sum(s.items for s in self.stats)

    @property
    def failed_sources(self) -> list[str]:
        return [s.name for s in self.stats if not s.ok]

    @property
    def success(self) -> bool:
        return bool(self.stats) and not self.failed_sources

    def as_dict(self) -> dict[str, Any]:
        return {
            "started_at": self.started_at,
            "finished_at": self.finished_at,
            "total_items": self.total_items,
            "sources": [s.as_dict() for s in self.stats],
            "failed_sources": self.failed_sources,
            "success": self.success,
        }
```

### Step 3. 설정 계층

`src/collectkit/config.py`:

```python
"""설정 로딩·검증·환경 변수 치환."""

import os
import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

import yaml

from collectkit.models import ConfigError

ENV_PATTERN = re.compile(r"\$\{([A-Za-z_][A-Za-z0-9_]*)\}")

SOURCE_TYPES = ("public_data", "json_api", "crawler")


def expand_env(value: Any, strict: bool = True) -> Any:
    """설정 안의 ${VAR} 를 환경 변수로 치환합니다."""
    if isinstance(value, str):
        def replace(m: re.Match) -> str:
            name = m.group(1)
            env = os.getenv(name)
            if env is None:
                if strict:
                    raise ConfigError(
                        f"환경 변수 {name} 가 설정되지 않았습니다. "
                        f".env 파일 또는 환경 변수를 확인하세요."
                    )
                return ""
            return env
        return ENV_PATTERN.sub(replace, value)
    if isinstance(value, dict):
        return {k: expand_env(v, strict) for k, v in value.items()}
    if isinstance(value, list):
        return [expand_env(v, strict) for v in value]
    return value


@dataclass(frozen=True)
class FetchConfig:
    """요청 관련 설정."""

    timeout: float = 15.0
    max_attempts: int = 3
    min_interval: float = 1.0
    base_delay: float = 1.0
    max_delay: float = 30.0
    user_agent: str = "CollectKit/0.1 (교육용; hong@example.com)"
    respect_robots: bool = True

    def __post_init__(self) -> None:
        if self.timeout <= 0:
            raise ConfigError(f"timeout 은 0보다 커야 합니다: {self.timeout}")
        if self.max_attempts < 1:
            raise ConfigError(f"max_attempts 는 1 이상이어야 합니다: {self.max_attempts}")
        if self.min_interval < 0:
            raise ConfigError(f"min_interval 은 0 이상이어야 합니다: {self.min_interval}")


@dataclass(frozen=True)
class SourceConfig:
    """수집 소스 하나의 설정."""

    name: str
    type: str
    url: str
    enabled: bool = True
    num_of_rows: int = 100
    max_pages: int = 50
    params: dict[str, Any] = field(default_factory=dict)
    selectors: dict[str, str] = field(default_factory=dict)
    fields: list[str] = field(default_factory=list)

    def __post_init__(self) -> None:
        if not self.name:
            raise ConfigError("소스의 name 은 필수입니다")
        if self.type not in SOURCE_TYPES:
            raise ConfigError(
                f"[{self.name}] 알 수 없는 type: {self.type!r} "
                f"(가능: {', '.join(SOURCE_TYPES)})"
            )
        if not self.url:
            raise ConfigError(f"[{self.name}] url 은 필수입니다")
        if self.max_pages < 1:
            raise ConfigError(f"[{self.name}] max_pages 는 1 이상이어야 합니다")
        if self.type == "crawler" and not self.selectors:
            raise ConfigError(f"[{self.name}] crawler 는 selectors 가 필요합니다")


@dataclass(frozen=True)
class AppConfig:
    """전체 설정."""

    output_dir: Path = Path("data")
    log_level: str = "INFO"
    fetch: FetchConfig = field(default_factory=FetchConfig)
    sources: list[SourceConfig] = field(default_factory=list)

    @property
    def enabled_sources(self) -> list[SourceConfig]:
        return [s for s in self.sources if s.enabled]


def _pick(data: dict, keys: tuple[str, ...]) -> dict:
    """dataclass 가 받는 키만 골라냅니다 (오타 방지)."""
    return {k: v for k, v in data.items() if k in keys}


def _check_unknown(data: dict, allowed: tuple[str, ...], where: str) -> None:
    unknown = set(data) - set(allowed)
    if unknown:
        raise ConfigError(
            f"{where} 에 알 수 없는 키가 있습니다: {sorted(unknown)} "
            f"(가능: {sorted(allowed)})"
        )


FETCH_KEYS = tuple(FetchConfig.__dataclass_fields__)
SOURCE_KEYS = tuple(SourceConfig.__dataclass_fields__)
APP_KEYS = ("output_dir", "log_level", "fetch", "sources")


def load_config(path: Path | str, strict_env: bool = True) -> AppConfig:
    """yaml 설정 파일을 읽어 검증된 AppConfig 를 돌려줍니다."""
    path = Path(path)
    if not path.exists():
        raise ConfigError(f"설정 파일이 없습니다: {path}")

    try:
        raw = yaml.safe_load(path.read_text(encoding="utf-8"))
    except yaml.YAMLError as e:
        raise ConfigError(f"YAML 문법 오류 ({path}): {e}") from e

    if raw is None:
        raise ConfigError(f"설정 파일이 비어 있습니다: {path}")
    if not isinstance(raw, dict):
        raise ConfigError(f"설정 파일의 최상위는 딕셔너리여야 합니다: {path}")

    raw = expand_env(raw, strict=strict_env)
    _check_unknown(raw, APP_KEYS, "설정 최상위")

    fetch_raw = raw.get("fetch") or {}
    if not isinstance(fetch_raw, dict):
        raise ConfigError("fetch 는 딕셔너리여야 합니다")
    _check_unknown(fetch_raw, FETCH_KEYS, "fetch")
    fetch = FetchConfig(**_pick(fetch_raw, FETCH_KEYS))

    sources_raw = raw.get("sources") or []
    if not isinstance(sources_raw, list):
        raise ConfigError("sources 는 리스트여야 합니다")
    if not sources_raw:
        raise ConfigError("sources 가 비어 있습니다. 최소 하나가 필요합니다.")

    sources = []
    seen_names = set()
    for i, s in enumerate(sources_raw):
        if not isinstance(s, dict):
            raise ConfigError(f"sources[{i}] 는 딕셔너리여야 합니다")
        _check_unknown(s, SOURCE_KEYS, f"sources[{i}]")
        source = SourceConfig(**_pick(s, SOURCE_KEYS))
        if source.name in seen_names:
            raise ConfigError(f"소스 이름이 중복됩니다: {source.name}")
        seen_names.add(source.name)
        sources.append(source)

    return AppConfig(
        output_dir=Path(raw.get("output_dir", "data")),
        log_level=str(raw.get("log_level", "INFO")).upper(),
        fetch=fetch,
        sources=sources,
    )
```

> **`_check_unknown()` 이 핵심입니다.** yaml에 `enabld: true` 라고 오타를 내면
> **조용히 무시되어 소스가 비활성화된 채로 돌아갑니다.**
> 알 수 없는 키를 에러로 처리하면 즉시 발견됩니다.

### Step 4. 소스 계층

`src/collectkit/sources/base.py`:

```python
"""수집 소스 공통 부모."""

import logging
import random
import time
from abc import ABC, abstractmethod
from typing import Any
from urllib.parse import urlparse
from urllib.robotparser import RobotFileParser

import requests

from collectkit.config import FetchConfig, SourceConfig
from collectkit.models import (
    Blocked, NoMoreData, SourceError, SourceStats,
)

logger = logging.getLogger(__name__)

RETRYABLE_STATUS = {408, 429, 500, 502, 503, 504}


class BaseSource(ABC):
    """수집 소스의 공통 동작.

    자식은 fetch_page() 와 parse() 만 구현합니다.
    """

    def __init__(self, config: SourceConfig, fetch: FetchConfig):
        self.config = config
        self.fetch_config = fetch
        self.stats = SourceStats(name=config.name)

        self.session = requests.Session()
        self.session.headers.update({"User-Agent": fetch.user_agent})

        self.records: list[dict] = []
        self._last_request = 0.0
        self._rp: RobotFileParser | None = None

        if fetch.respect_robots:
            self._load_robots()

    # ---------- robots ----------

    def _load_robots(self) -> None:
        parsed = urlparse(self.config.url)
        if not parsed.scheme:
            return
        robots_url = f"{parsed.scheme}://{parsed.netloc}/robots.txt"
        rp = RobotFileParser()
        rp.set_url(robots_url)
        try:
            rp.read()
            self._rp = rp
            logger.debug("[%s] robots.txt 확인: %s", self.config.name, robots_url)
        except Exception as e:
            logger.debug("[%s] robots.txt 읽기 실패 (%s)", self.config.name, e)

    def _check_allowed(self, url: str) -> None:
        if self._rp is None:
            return
        if not self._rp.can_fetch(self.fetch_config.user_agent, url):
            raise Blocked(f"robots.txt 가 금지한 경로: {url}")

    # ---------- 요청 ----------

    def _wait(self) -> None:
        elapsed = time.monotonic() - self._last_request
        interval = self.fetch_config.min_interval
        if self._last_request > 0 and elapsed < interval:
            waited = interval - elapsed
            time.sleep(waited)
            self.stats.wait_seconds += waited
        self._last_request = time.monotonic()

    def _backoff(self, attempt: int) -> float:
        delay = min(
            self.fetch_config.base_delay * (2 ** (attempt - 1)),
            self.fetch_config.max_delay,
        )
        return delay * (0.5 + random.random())

    def request(self, url: str, params: dict | None = None) -> requests.Response:
        """재시도를 포함한 GET 요청."""
        self._check_allowed(url)
        cfg = self.fetch_config

        for attempt in range(1, cfg.max_attempts + 1):
            self._wait()
            self.stats.requests += 1

            try:
                r = self.session.get(url, params=params, timeout=cfg.timeout)
            except (requests.Timeout, requests.ConnectionError) as e:
                if attempt >= cfg.max_attempts:
                    raise SourceError(f"네트워크 오류: {type(e).__name__}") from e
                delay = self._backoff(attempt)
                logger.warning("[%s] %s (%d/%d) — %.1f초 후 재시도",
                               self.config.name, type(e).__name__,
                               attempt, cfg.max_attempts, delay)
                self.stats.retries += 1
                time.sleep(delay)
                continue

            if r.status_code in RETRYABLE_STATUS:
                if attempt >= cfg.max_attempts:
                    raise SourceError(f"HTTP {r.status_code} (최대 재시도 도달)")
                retry_after = r.headers.get("Retry-After", "")
                delay = (float(retry_after) if retry_after.isdigit()
                         else self._backoff(attempt))
                logger.warning("[%s] HTTP %d (%d/%d) — %.1f초 후 재시도",
                               self.config.name, r.status_code,
                               attempt, cfg.max_attempts, delay)
                self.stats.retries += 1
                time.sleep(delay)
                continue

            if not r.ok:
                raise SourceError(f"HTTP {r.status_code} — 재시도 불가")

            return r

        raise SourceError("알 수 없는 요청 실패")

    # ---------- 자식이 구현 ----------

    @abstractmethod
    def fetch_page(self, page: int) -> Any:
        """한 페이지를 가져옵니다. 원본 응답(dict 또는 str)을 돌려줍니다."""

    @abstractmethod
    def parse(self, payload: Any) -> tuple[list[dict], int]:
        """(레코드 목록, 전체 개수)를 돌려줍니다."""

    def transform(self, item: dict) -> dict | None:
        """레코드 하나를 정제합니다. None 이면 버립니다."""
        return item

    # ---------- 공통 실행 ----------

    def collect(self) -> list[dict]:
        start = time.monotonic()
        cfg = self.config
        logger.info("[%s] 수집 시작 (%s)", cfg.name, cfg.type)

        try:
            total_pages: int | None = None

            for page in range(1, cfg.max_pages + 1):
                try:
                    payload = self.fetch_page(page)
                    items, total_count = self.parse(payload)
                except NoMoreData:
                    logger.info("[%s] %d페이지 — 데이터 없음, 종료", cfg.name, page)
                    break

                if not items:
                    logger.info("[%s] %d페이지가 비어 있습니다 — 종료", cfg.name, page)
                    break

                if total_pages is None and total_count:
                    total_pages = -(-total_count // cfg.num_of_rows)   # 올림 나눗셈
                    logger.info("[%s] 전체 %s건 / 약 %d페이지",
                                cfg.name, f"{total_count:,}", total_pages)

                added = dropped = 0
                for item in items:
                    record = self.transform(item)
                    if record is None:
                        dropped += 1
                        continue
                    self.records.append(record)
                    added += 1

                self.stats.pages += 1
                self.stats.items += added
                self.stats.dropped += dropped
                logger.info("[%s] %d페이지 — %d건 수집, %d건 제외 (누적 %d건)",
                            cfg.name, page, added, dropped, len(self.records))

                if total_pages and page >= total_pages:
                    break
            else:
                logger.warning("[%s] 최대 페이지(%d) 도달", cfg.name, cfg.max_pages)

        except SourceError as e:
            self.stats.error = f"{type(e).__name__}: {e}"
            logger.error("[%s] 수집 실패: %s", cfg.name, e)

        self.stats.elapsed = time.monotonic() - start
        logger.info("[%s] 완료 — %d건 (%.1f초)",
                    cfg.name, len(self.records), self.stats.elapsed)
        return self.records

    def __repr__(self) -> str:
        return f"{type(self).__name__}(name={self.config.name!r}, records={len(self.records)})"
```

```python
import logging
from typing import Any

from collectkit.models import AuthError, NoMoreData, QuotaExceeded, SourceError
from collectkit.sources.base import BaseSource

RESULT_MESSAGES = {
    "00": "정상", "01": "애플리케이션 에러", "03": "데이터 없음",
    "20": "서비스 접근 거부", "22": "호출 횟수 초과",
    "30": "등록되지 않은 서비스키", "31": "활용 기간 만료",
    "32": "등록되지 않은 IP",
}
FATAL_CODES = {"20", "30", "31", "32"}


def to_float(value: Any) -> float | None:
    """'-' 나 빈 값은 None (결측)."""
    if value in (None, "", "-", "–"):
        return None
    try:
        return float(str(value).replace(",", ""))
    except (TypeError, ValueError):
        return None


class PublicDataSource(BaseSource):
    """공공데이터포털 표준 응답 형식."""

    def fetch_page(self, page: int) -> dict:
        params = {
            "pageNo": page,
            "numOfRows": self.config.num_of_rows,
            "returnType": "json",
            "_type": "json",
            **self.config.params,
        }
        r = self.request(self.config.url, params)

        if "xml" in r.headers.get("Content-Type", "").lower():
            logger.error("[%s] XML 응답: %s", self.config.name, r.text[:200])
            raise SourceError("XML 응답 — 파라미터나 인증키를 확인하세요")

        try:
            return r.json()
        except ValueError as e:
            logger.error("[%s] JSON 파싱 실패: %s", self.config.name, r.text[:200])
            raise SourceError(f"JSON 파싱 실패: {e}") from e

    def parse(self, payload: dict) -> tuple[list[dict], int]:
        response = payload.get("response", {})
        header = response.get("header", {})
        code = str(header.get("resultCode", ""))
        msg = header.get("resultMsg", "")
        label = RESULT_MESSAGES.get(code, msg)

        if code == "03":
            raise NoMoreData(label)
        if code in FATAL_CODES:
            raise AuthError(f"[{code}] {label}")
        if code == "22":
            raise QuotaExceeded(f"[{code}] {label}")
        if code != "00":
            raise SourceError(f"[{code}] {label}")

        body = response.get("body", {})
        items = body.get("items", [])
        if isinstance(items, dict):
            items = items.get("item", [])
        if isinstance(items, dict):
            items = [items]
        if not isinstance(items, list):
            items = []

        return items, int(body.get("totalCount", 0) or 0)

    def transform(self, item: dict) -> dict | None:
        """설정의 fields 목록에 있는 필드만 남깁니다."""
        fields = self.config.fields
        if not fields:
            return item

        record = {}
        for f in fields:
            value = item.get(f)
            record[f] = value.strip() if isinstance(value, str) else value

        # 필수로 볼 첫 필드가 비면 버립니다
        if fields and not record.get(fields[0]):
            return None
        return record
```

```python
"""HTML 크롤링 소스."""

import logging
from urllib.parse import urljoin

from bs4 import BeautifulSoup

from collectkit.sources.base import BaseSource

logger = logging.getLogger(__name__)


class CrawlerSource(BaseSource):
    """CSS 선택자 설정으로 HTML을 파싱합니다.

    설정 예:
        selectors:
          item: "li.news-item:not(.ad)"
          title: "a.title"
          url: "a.title@href"          # @속성 으로 속성 추출
          date: "span.date"
    """

    def fetch_page(self, page: int) -> str:
        params = {**self.config.params, "page": page}
        r = self.request(self.config.url, params)
        self._last_url = r.url
        return r.text

    def _extract(self, element, spec: str) -> str:
        """선택자 스펙으로 값을 뽑습니다. 'sel@attr' 이면 속성."""
        selector, _, attr = spec.partition("@")
        found = element.select_one(selector.strip()) if selector.strip() else element
        if found is None:
            return ""
        if attr:
            return found.get(attr.strip(), "")
        return found.get_text(strip=True)

    def parse(self, html: str) -> tuple[list[dict], int]:
        soup = BeautifulSoup(html, "html.parser")
        selectors = dict(self.config.selectors)
        item_selector = selectors.pop("item", None)

        if not item_selector:
            raise ValueError(f"[{self.config.name}] selectors.item 이 필요합니다")

        elements = soup.select(item_selector)
        if not elements:
            logger.debug("[%s] '%s' 로 아무것도 못 찾음", self.config.name, item_selector)
            return [], 0

        records = []
        for el in elements:
            record = {key: self._extract(el, spec) for key, spec in selectors.items()}
            records.append(record)

        return records, 0        # 크롤링은 총 개수를 모르는 경우가 대부분

    def transform(self, item: dict) -> dict | None:
        # 첫 필드가 비어 있으면 버립니다
        keys = list(item)
        if not keys or not item[keys[0]]:
            return None

        # 상대 URL 을 절대 URL 로
        base = getattr(self, "_last_url", self.config.url)
        for key, value in item.items():
            if key.endswith("url") and value and not value.startswith(("http://", "https://")):
                item[key] = urljoin(base, value)
        return item
```

```python
def save_records(records: list[dict], name: str, out_dir: Path,

    """레코드를 JSON·CSV 로 저장합니다."""

    stamp = stamp or datetime.now().strftime("%Y%m%d_%H%M%S")
    paths: dict[str, Path] = {}

                         encoding="utf-8")

        # 모든 레코드의 키 합집합 (필드가 다른 레코드가 섞여도 안전)
        fields: list[str] = []

            for k in r:
                if k not in fields:
                    fields.append(k)

        csv_path = out_dir / f"{name}_{stamp}.csv"
        with csv_path.open("w", encoding="utf-8", newline="") as f:
            writer = csv.DictWriter(f, fieldnames=fields, restval="")
            writer.writeheader()
            writer.writerows(records)
        paths["csv"] = csv_path

    logger.info("저장: %s (%d건)", ", ".join(str(p) for p in paths.values()), len(records))
    return paths
```

```python
"""여러 소스를 실행합니다."""

import logging
from datetime import datetime
from pathlib import Path

from collectkit.config import AppConfig
from collectkit.models import AuthError, QuotaExceeded, RunResult
from collectkit.sources import create_source
from collectkit.storage import save_records, save_run_meta

logger = logging.getLogger(__name__)


def run(config: AppConfig, only: list[str] | None = None,
        dry_run: bool = False) -> RunResult:
    """설정의 모든 (또는 지정한) 소스를 수집합니다."""
    result = RunResult()
    stamp = datetime.now().strftime("%Y%m%d_%H%M%S")

    targets = config.enabled_sources
    if only:
        targets = [s for s in targets if s.name in only]
        missing = set(only) - {s.name for s in targets}
        if missing:
            logger.warning("설정에 없거나 비활성화된 소스: %s", sorted(missing))

    if not targets:
        logger.warning("실행할 소스가 없습니다.")
        result.finished_at = datetime.now().isoformat(timespec="seconds")
        return result

    logger.info("소스 %d개 실행: %s", len(targets), ", ".join(s.name for s in targets))

    for source_config in targets:
        source = create_source(source_config, config.fetch)

        if dry_run:
            logger.info("[%s] dry-run — 실제 요청은 하지 않습니다 (url=%s)",
                        source_config.name, source_config.url)
            source.stats.error = None
            result.stats.append(source.stats)
            continue

        try:
            records = source.collect()
        except (AuthError, QuotaExceeded) as e:
            source.stats.error = f"{type(e).__name__}: {e}"
            logger.error("[%s] 치명적 오류 — 이 소스를 건너뜁니다: %s",
                         source_config.name, e)
            result.stats.append(source.stats)
            continue

        if records:
            save_records(records, source_config.name, config.output_dir, stamp)
        else:
            logger.warning("[%s] 수집 결과가 0건입니다 — 선택자나 파라미터를 확인하세요",
                           source_config.name)
            if source.stats.error is None:
                source.stats.error = "수집 결과 0건"

        result.stats.append(source.stats)

    result.finished_at = datetime.now().isoformat(timespec="seconds")
    save_run_meta(result.as_dict(), config.output_dir, stamp)
    return result


def print_report(result: RunResult) -> None:
    print("\n" + "=" * 72)
    print("수집 리포트")
    print("=" * 72)
    print(f"  시작 : {result.started_at}")
    print(f"  종료 : {result.finished_at}")
    print()
    print(f"  {'소스':<16}{'상태':<6}{'건수':>8}{'제외':>6}{'요청':>6}"
          f"{'재시도':>7}{'소요':>8}")
    print("  " + "-" * 62)

    for s in result.stats:
        mark = "✓" if s.ok else "✗"
        print(f"  {s.name:<16}{mark:<6}{s.items:>8,}{s.dropped:>6}{s.requests:>6}"
              f"{s.retries:>7}{s.elapsed:>7.1f}s")
        if s.error:
            print(f"    └ {s.error}")

    print("  " + "-" * 62)
    print(f"  {'합계':<16}{'':<6}{result.total_items:>8,}")

    if result.failed_sources:
        print(f"\n  ⚠ 실패한 소스: {', '.join(result.failed_sources)}")
```

```python
import argparse

def setup_logging(level: str) -> None:
    logging.basicConfig(
        level=level,
        format="%(asctime)s [%(levelname)-8s] %(name)-24s %(message)s",
        datefmt="%H:%M:%S",

def cmd_run(args) -> int:
    config = load_config(args.config, strict_env=not args.dry_run)
    setup_logging(args.log_level or config.log_level)

        config = type(config)(
            output_dir=args.output, log_level=config.log_level,

def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="collect",
        description="설정 기반 데이터 수집 툴킷",
    )
    parser.add_argument("--version", action="version", version=f"collectkit {__version__}")
    parser.add_argument("-c", "--config", type=Path, default=Path("configs/config.yaml"),
                        help="설정 파일 경로 (기본: configs/config.yaml)")
    parser.add_argument("-l", "--log-level",
                        choices=["DEBUG", "INFO", "WARNING", "ERROR"],
                        help="로그 레벨 (설정 파일보다 우선)")

    sub = parser.add_subparsers(dest="command")

    p_run = sub.add_parser("run", help="수집 실행")
    p_run.add_argument("--only", nargs="+", metavar="NAME",

def main(argv: list[str] | None = None) -> int:
    load_dotenv()
    parser = build_parser()
    args = parser.parse_args(argv)

    if args.command is None:
        parser.print_help()
        return 2

    try:
        return args.func(args)
    except ConfigError as e:
        print(f"✗ 설정 오류: {e}", file=sys.stderr)
```

**2.** `_check_unknown()` 으로 알 수 없는 설정 키를 에러 처리하는 이유는 무엇인가요? 없으면 어떤 일이 생기나요?

<details>
<summary>답 보기</summary>

**오타가 조용히 무시되는 것을 막기 위해서입니다.**

**없으면 벌어지는 일**


`_pick()` 이 알 수 없는 키를 걸러내므로 `enabld` 는 **그냥 사라집니다.**
`enabled` 는 기본값 `True` 가 되어 **비활성화하려던 소스가 계속 실행됩니다.**

| 증상 | 원인을 찾기까지 |
|---|---|
| API 호출 한도가 계속 초과됨 | 며칠 |
| 안 쓰는 소스가 매일 돌아감 | 몇 주 |
| 설정을 고쳤는데 반영이 안 됨 | 몇 시간 |

**에러가 안 나기 때문에** 아무도 의심하지 않습니다.

**다른 오타 예시**

| 오타 | 결과 |
|---|---|
| `max_page: 5` (`max_pages` 아님) | 기본값 50페이지가 돌아감 |
| `num_of_row: 100` | 기본값 100 (우연히 같아서 더 안 보임) |
| `selector:` (`selectors` 아님) | crawler 검증에서 걸림 (다행) |
| `Enabled: false` (대문자) | 무시됨 |

**있으면**

```
✗ 설정 오류: sources[0] 에 알 수 없는 키가 있습니다: ['enabld']
              (가능: ['enabled', 'fields', 'max_pages', ...])
```

**즉시, 정확한 위치와 함께, 올바른 키 목록까지** 알려 줍니다.

**구현**

```python
def _check_unknown(data: dict, allowed: tuple, where: str) -> None:
    unknown = set(data) - set(allowed)
    if unknown:
        raise ConfigError(
            f"{where} 에 알 수 없는 키가 있습니다: {sorted(unknown)} "
            f"(가능: {sorted(allowed)})"

```

`allowed` 는 dataclass에서 자동으로 얻습니다.

```python
SOURCE_KEYS = tuple(SourceConfig.__dataclass_fields__)
```

**3.** 크롤링 소스의 선택자를 설정으로 뺐습니다. 이 방식의 한계는 무엇이고, 언제 코드로 돌아가야 하나요?

<details>
<summary>답 보기</summary>

**설정으로 되는 것**

```yaml
selectors:
  item: "li.news-item:not(.ad)"
  title: "a.title"
  url: "a.title@href"
  date: "span.date"
```

**단순한 "선택 → 텍스트/속성 추출"** 은 완벽하게 커버됩니다.
사이트가 바뀌면 선택자만 고치면 되고, 새 사이트를 추가할 때 코드를 안 씁니다.

**설정으로 안 되는 것**

| 상황 | 왜 안 되나 |
|---|---|
| **값 정제** | `"1,204명"` → `1204` 변환 규칙을 어떻게 표현? |
| **조건부 추출** | "특정 클래스가 있으면 A, 없으면 B" |
| **여러 요소 조합** | 제목 = 앞부분 + " - " + 뒷부분 |
| **상세 페이지 방문** | 목록에서 링크를 따라 들어가 추가 수집 |
| **로그인·세션** | 인증 흐름 |
| **JavaScript 렌더링** | 브라우저 자동화 필요 |
| **날짜 형식 통일** | `"08-12"`, `"2026.08.12"`, `"3일 전"` |

**한계의 신호 — 설정에 로직이 들어가기 시작할 때**

```yaml
# ⚠ 이렇게 되기 시작하면 위험 신호
selectors:
  price:
    selector: "span.price"
    transform: "replace(',','')|strip('원')|int"
    fallback: "span.price-alt"
    condition: "has_class('sale')"
```

**"설정 파일로 프로그래밍"** 을 하고 있는 것입니다.
- yaml에 함수·조건·변환 규칙을 표현하려면 결국 **작은 언어를 만들게** 됩니다
- 그 언어는 디버깅이 안 되고, 타입 검사가 안 되고, IDE 지원이 없습니다
- 파이썬으로 3줄이면 될 것이 yaml 20줄이 됩니다

**돌아가는 방법 — 자식 클래스로 오버라이드**

```python
class NewsSource(CrawlerSource):
    """뉴스 사이트 전용. 선택자는 설정에서, 정제는 코드에서."""

    def transform(self, item: dict) -> dict | None:
        record = super().transform(item)      # 부모의 기본 처리 (URL 절대화 등)
        if record is None:
            return None

        # 여기부터는 코드로
        record["views"] = self._parse_count(record.get("views", ""))
        record["published_at"] = self._parse_date(record.get("date", ""))
        return record

    @staticmethod
    def _parse_count(text: str) -> int:
        cleaned = text.replace(",", "").replace("명", "").strip()
        return int(cleaned) if cleaned.isdigit() else 0

    @staticmethod
    def _parse_date(text: str) -> str:
        if "일 전" in text:
            days = int(text.split("일")[0])
            return (datetime.now() - timedelta(days=days)).strftime("%Y-%m-%d")
        return text
```

```python
    "news": NewsSource,          # 새 타입
}
```

**설정은 그대로 씁니다.**

```yaml
- name: news_site
  type: news              # 전용 타입
  selectors: { ... }      # 선택자는 여전히 설정
```

**좋은 경계**

```
설정  →  무엇을 (what)   — URL, 선택자, 페이지 수, 필드 목록
코드  →  어떻게 (how)    — 정제 규칙, 조건 분기, 형변환
```

**실무 판단 기준**

| 질문 | 예 → 설정 | 아니오 → 코드 |
|---|---|---|
| 값 하나를 그대로 넣는가? | ✅ | |
| if/for 가 필요한가? | | ✅ |
| 테스트를 쓰고 싶은가? | | ✅ |
| 코드를 모르는 사람이 고칠 것인가? | ✅ | |

**"설정으로 뺄 수 있다"와 "설정으로 빼야 한다"는 다릅니다.**
설정은 **변경 빈도가 높고 로직이 없는 것**에만 씁니다.
</details>
