### 조립에는 규칙이 있습니다

```python
# 이렇게 하면 안 됩니다
Conv2D(512, 3) → Conv2D(256, 3) → Conv2D(128, 3) → ...    # 필터 수 감소
MaxPool → MaxPool → MaxPool → Conv2D                       # 풀링만 연속
Conv2D(32, 11) → Dense(10)                                 # 큰 필터, 얕은 구조
```

```python
# 표준 패턴
Conv2D(32, 3) → Pool → Conv2D(64, 3) → Pool → Conv2D(128, 3) → Pool
→ Flatten → Dense(64) → Dense(10)
```

**이 패턴에는 이유가 있습니다.** 오늘 그 이유를 하나씩 확인합니다.

### 그리고 CNN이 무엇을 보는지 눈으로 봅니다

```
층 1 → 엣지, 색상 변화
층 2 → 모서리, 곡선
층 3 → 질감, 무늬
층 4 → 부분 (눈, 코, 바퀴)
층 5 → 물체 전체
```

**이 계층 구조를 특성맵으로 직접 확인합니다.**

## ③ 개념 설명

### 전형적인 CNN 구조

```
입력 이미지
   ↓
┌─────────────────────┐
│ Conv2D(32, 3) + ReLU│  ← 특징 추출 블록 1
│ MaxPooling2D(2)     │
└─────────────────────┘
   ↓
┌─────────────────────┐
│ Conv2D(64, 3) + ReLU│  ← 특징 추출 블록 2
│ MaxPooling2D(2)     │
└─────────────────────┘
   ↓
┌─────────────────────┐
│ Conv2D(128,3) + ReLU│  ← 특징 추출 블록 3
│ MaxPooling2D(2)     │
└─────────────────────┘
   ↓
Flatten 또는 GlobalAveragePooling
   ↓
┌─────────────────────┐
│ Dense(64) + ReLU    │  ← 분류기
│ Dropout(0.5)        │
│ Dense(클래스수) + softmax│
└─────────────────────┘
```

**두 부분으로 나뉩니다.**

| 부분 | 역할 | 층 |
|---|---|---|
| **특징 추출부** (backbone) | 이미지에서 특징을 뽑음 | Conv, Pool |
| **분류부** (head) | 특징으로 클래스를 판단 | Flatten/GAP, Dense |

> **전이학습([Day 098](day-098.md))이 이 구분을 활용합니다.**
> 남의 모델의 **특징 추출부만 가져오고** 분류부는 내 문제에 맞게 새로 붙입니다.

### 층이 깊어질수록 무엇을 보는가

```
층 1  ━━━━  |  ／  ＼  ●        엣지, 색 변화        (수용 영역 3×3)
층 2  ┌  ┐  ○  ∿                모서리, 곡선          (수용 영역 7×7)
층 3  ▨ ▩ ◍                     질감, 패턴            (수용 영역 15×15)
층 4  👁 👃 🐾                    부분 (눈, 코, 발)     (수용 영역 31×31)
층 5  🐺 🐕                       물체 전체             (수용 영역 63×63)
```

**왜 이렇게 되는가**

```
층 1: 원본 픽셀의 3×3 영역만 봄
층 2: 층 1 출력의 3×3 = 원본의 5×5~7×7 영역
층 3: 더 넓은 영역
...
```

**수용 영역(receptive field)이 커지면서 더 큰 구조를 볼 수 있게 됩니다.**

**중요한 점** — 이 계층 구조를 **사람이 설계하지 않았습니다.**
"층 1은 엣지를 검출해라"라고 지시한 적이 없는데 학습으로 그렇게 됩니다.

### 설계 원칙 6가지

**① 필터 수는 늘려간다**

```
32 → 64 → 128 → 256      (2배씩)
```

공간이 줄어드는 만큼 채널로 보완합니다. ([Day 088](day-088.md))

**② 필터 크기는 3×3**

```
Conv2D(32, 3)      ✓ 표준
Conv2D(32, 5)      첫 층에서 가끔
Conv2D(32, 7)      매우 큰 이미지의 첫 층
```

3×3 두 층 = 5×5 한 층의 수용 영역, 파라미터는 28% 적음 ([Day 087](day-087.md))

**③ `padding="same"` 을 쓰면 크기 관리가 쉽다**

```
same:  28 → 28 → Pool → 14 → 14 → Pool → 7
valid: 28 → 26 → Pool → 13 → 11 → Pool → 5     (계산 복잡)
```

**④ 풀링은 2~4회**

```
28×28  → 2회 → 7×7
224×224 → 5회 → 7×7
```

**최종 특성맵을 7×7 정도로** 맞추는 것이 관례입니다.

**⑤ Conv를 2개 연속 쓰는 패턴**

```python
Conv2D(64, 3, padding="same"), Conv2D(64, 3, padding="same"), MaxPool(2)
```

VGG 스타일입니다. 수용 영역을 키우면서 비선형성을 늘립니다.

**⑥ 분류부는 작게**

```python
Flatten → Dense(64) → Dense(10)        # ✓
Flatten → Dense(4096) → Dense(4096) → Dense(10)     # 옛날 방식(AlexNet). 과적합 위험
```

**파라미터의 대부분이 여기 몰립니다.** ([Day 088](day-088.md))

### Keras 함수형 API

**Sequential의 한계** — 일렬로만 쌓을 수 있습니다.

```python
# 이런 구조는 Sequential로 못 만듭니다
       ┌─→ Conv3×3 ─┐
입력 ──┤            ├─→ 합치기 → 출력
       └─→ Conv5×5 ─┘
```

**함수형 API**

```python
from tensorflow import keras
from tensorflow.keras import layers

inputs = keras.Input(shape=(28, 28, 1))

x = layers.Conv2D(32, 3, activation="relu")(inputs)
x = layers.MaxPooling2D(2)(x)
x = layers.Conv2D(64, 3, activation="relu")(x)
x = layers.Flatten()(x)
outputs = layers.Dense(10, activation="softmax")(x)

model = keras.Model(inputs, outputs)
```

**층을 함수처럼 호출합니다.** `layer(입력)` → 출력

| 함수형 API로만 가능한 것 |
|---|
| 여러 입력 / 여러 출력 |
| 층 건너뛰기 (skip connection, ResNet) |
| 가지치기와 합치기 (Inception) |
| **중간층 출력 꺼내기** ← 오늘 씁니다 |

**중간층 출력 꺼내기**

```python
feature_model = keras.Model(
    inputs=model.inputs,
    outputs=[model.get_layer("conv1").output,
             model.get_layer("conv2").output],
)
fmaps = feature_model.predict(image)
```

**특성맵 시각화에 필수입니다.**

## ④ 단계별 실습

### Step 1. 기본 CNN 만들고 학습

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

# ── 데이터 ──
(X_full, y_full), (X_test, y_test) = keras.datasets.mnist.load_data()
X_full = (X_full.astype("float32") / 255.0)[..., np.newaxis]
X_test = (X_test.astype("float32") / 255.0)[..., np.newaxis]

X_val, y_val = X_full[:6000], y_full[:6000]
X_train, y_train = X_full[6000:], y_full[6000:]

print(f"학습 {X_train.shape}, 검증 {X_val.shape}, 테스트 {X_test.shape}")

# ── 모델 ──
model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),

    # 블록 1
    layers.Conv2D(32, 3, padding="same", activation="relu", name="conv1"),
    layers.MaxPooling2D(2, name="pool1"),

    # 블록 2
    layers.Conv2D(64, 3, padding="same", activation="relu", name="conv2"),
    layers.MaxPooling2D(2, name="pool2"),

    # 블록 3
    layers.Conv2D(128, 3, padding="same", activation="relu", name="conv3"),
    layers.MaxPooling2D(2, name="pool3"),

    # 분류부
    layers.Flatten(),
    layers.Dropout(0.4),
    layers.Dense(64, activation="relu"),
    layers.Dense(10, activation="softmax"),
], name="mnist_cnn")

model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])

model.summary()

print("\nshape 흐름 손계산")
print("  28×28×1")
print("  → Conv(32,same)  28×28×32")
print("  → Pool(2)        14×14×32")
print("  → Conv(64,same)  14×14×64")
print("  → Pool(2)         7× 7×64")
print("  → Conv(128,same)  7× 7×128")
print("  → Pool(2)         3× 3×128")
print("  → Flatten        1152")
print("  → Dense(64)      64")
print("  → Dense(10)      10")

# ── 학습 ──
print("\n" + "=" * 66)
print("학습 시작")
print("=" * 66)

history = model.fit(
    X_train, y_train,
    epochs=15,
    batch_size=128,
    validation_data=(X_val, y_val),
    verbose=2,
)

test_loss, test_acc = model.evaluate(X_test, y_test, verbose=0)
train_loss, train_acc = model.evaluate(X_train, y_train, verbose=0)

print("\n" + "=" * 66)
print("최종 결과")
print("=" * 66)
print(f"학습셋   정확도 {train_acc:.4f}")
print(f"테스트셋 정확도 {test_acc:.4f}")
print(f"격차            {train_acc - test_acc:+.4f}")
print(f"틀린 개수       {int((1 - test_acc) * 10000)} / 10,000")
print()
print("[Day 085 Dense 모델과 비교]")
print("  Dense: 파라미터 109,386, 정확도 0.9781")
print(f"  CNN  : 파라미터 {model.count_params():,}, 정확도 {test_acc:.4f}")
print("=" * 66)

# ── 학습 곡선 ──
h = history.history
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

axes[0].plot(h["loss"], label="train", linewidth=2)
axes[0].plot(h["val_loss"], label="validation", linewidth=2)
axes[0].set_xlabel("epoch")
axes[0].set_ylabel("loss")
axes[0].set_title("Loss")
axes[0].legend()
axes[0].grid(alpha=0.3)

axes[1].plot(h["accuracy"], label="train", linewidth=2)
axes[1].plot(h["val_accuracy"], label="validation", linewidth=2)
axes[1].set_ylim(0.97, 1.0)
axes[1].set_xlabel("epoch")
axes[1].set_ylabel("accuracy")
axes[1].set_title("Accuracy")
axes[1].legend()
axes[1].grid(alpha=0.3)

fig.tight_layout()
plt.show()
```

### Step 2. 함수형 API로 다시 만들고 특성맵 꺼내기

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_full, y_full), (X_test, y_test) = keras.datasets.mnist.load_data()
X_full = (X_full.astype("float32") / 255.0)[..., np.newaxis]
X_test = (X_test.astype("float32") / 255.0)[..., np.newaxis]
X_train, y_train = X_full[6000:], y_full[6000:]

# ── 함수형 API ──
inputs = keras.Input(shape=(28, 28, 1), name="image")

x = layers.Conv2D(32, 3, padding="same", activation="relu", name="conv1")(inputs)
x = layers.MaxPooling2D(2, name="pool1")(x)
x = layers.Conv2D(64, 3, padding="same", activation="relu", name="conv2")(x)
x = layers.MaxPooling2D(2, name="pool2")(x)
x = layers.Conv2D(128, 3, padding="same", activation="relu", name="conv3")(x)
x = layers.MaxPooling2D(2, name="pool3")(x)

x = layers.Flatten()(x)
x = layers.Dropout(0.4)(x)
x = layers.Dense(64, activation="relu", name="fc")(x)
outputs = layers.Dense(10, activation="softmax", name="prediction")(x)

model = keras.Model(inputs, outputs, name="mnist_cnn_functional")
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])

print("함수형 API로 만든 모델")
print(f"파라미터: {model.count_params():,}   (Sequential과 동일)")

model.fit(X_train, y_train, epochs=8, batch_size=128, verbose=0)
_, acc = model.evaluate(X_test, y_test, verbose=0)
print(f"테스트 정확도: {acc:.4f}")

# ── 중간층 출력 모델 ──
layer_names = ["conv1", "conv2", "conv3"]
feature_model = keras.Model(
    inputs=model.inputs,
    outputs=[model.get_layer(n).output for n in layer_names],
)

sample_idx = 0
sample = X_test[sample_idx:sample_idx + 1]
fmaps = feature_model.predict(sample, verbose=0)

print("\n" + "=" * 66)
print("층별 특성맵 shape")
print("=" * 66)
print(f"{'층':<12}{'출력 shape':>20}{'값의 개수':>16}")
print("-" * 66)
print(f"{'입력':<12}{str(sample.shape[1:]):>20}{np.prod(sample.shape[1:]):>16,}")
for name, fm in zip(layer_names, fmaps):
    print(f"{name:<12}{str(fm.shape[1:]):>20}{np.prod(fm.shape[1:]):>16,}")
print("=" * 66)

# ── 특성맵 시각화 ──
fig = plt.figure(figsize=(16, 10))
gs = fig.add_gridspec(4, 8, height_ratios=[1.4, 1, 1, 1])

ax = fig.add_subplot(gs[0, 0])
ax.imshow(sample[0, :, :, 0], cmap="gray_r")
```

```python
def build(blocks, kernel=3, head="flatten", dense_units=64, dropout=0.4,
          double_conv=False):
    L = [layers.Input(shape=(28, 28, 1))]
    for f in blocks:
        L.append(layers.Conv2D(f, kernel, padding="same", activation="relu"))
        if double_conv:
            L.append(layers.Conv2D(f, kernel, padding="same", activation="relu"))
        L.append(layers.MaxPooling2D(2))
    L.append(layers.Flatten() if head == "flatten"
             else layers.GlobalAveragePooling2D())
    if dropout:
        L.append(layers.Dropout(dropout))
    if dense_units:
        L.append(layers.Dense(dense_units, activation="relu"))
    L.append(layers.Dense(10, activation="softmax"))
    return keras.Sequential(L)
```

**① A(블록1)가 파라미터는 가장 많은데 성능은 가장 낮습니다.**


**풀링을 적게 하면 Flatten 크기가 커져 Dense가 무거워집니다.** ([Day 088](day-088.md))

**② C(파라미터 167K)가 E(606K)와 거의 같은 성능입니다.**
파라미터를 3.6배 늘려 얻은 것은 0.06%p입니다. **수확 체감.**

**③ G(VGG 스타일)가 최고입니다.**
Conv를 2개씩 쌓으면 수용 영역이 커지고 비선형성이 늘어납니다.

**④ I(필터 수 역순)가 하위권입니다.**
`128 → 64 → 32` 로 줄여가면 성능이 떨어집니다. **관례가 근거 있는 것**임을 확인했습니다.

### Step 5. 오답 분석과 최종 모델

```python
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import tensorflow as tf
from sklearn.metrics import classification_report, confusion_matrix
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_full, y_full), (X_test, y_test) = keras.datasets.mnist.load_data()
X_full = (X_full.astype("float32") / 255.0)[..., np.newaxis]
X_test = (X_test.astype("float32") / 255.0)[..., np.newaxis]
X_val, y_val = X_full[:6000], y_full[:6000]
X_train, y_train = X_full[6000:], y_full[6000:]

# ── 최종 모델 (Step 4에서 가장 좋았던 VGG 스타일) ──
model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),

    layers.Conv2D(32, 3, padding="same", activation="relu"),
    layers.Conv2D(32, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),

    layers.Conv2D(64, 3, padding="same", activation="relu"),
    layers.Conv2D(64, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),

    layers.Flatten(),
    layers.Dropout(0.4),
    layers.Dense(64, activation="relu"),
    layers.Dense(10, activation="softmax"),
], name="mnist_vgg_style")

model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.summary()

history = model.fit(X_train, y_train, epochs=15, batch_size=128,
                    validation_data=(X_val, y_val), verbose=2)

_, test_acc = model.evaluate(X_test, y_test, verbose=0)
print(f"\n테스트 정확도: {test_acc:.4f}  (틀린 개수 {int((1-test_acc)*10000)})")

# ── 오답 분석 ──
proba = model.predict(X_test, verbose=0)
pred = proba.argmax(axis=1)
conf = proba.max(axis=1)
wrong = np.where(pred != y_test)[0]

print("\n" + "=" * 70)
print(classification_report(y_test, pred, digits=4))

cm = confusion_matrix(y_test, pred)
fig, axes = plt.subplots(1, 2, figsize=(15, 6))

sns.heatmap(cm, annot=True, fmt="d", cmap="Blues", cbar=False, ax=axes[0],
            xticklabels=range(10), yticklabels=range(10))
axes[0].set_xlabel("Predicted")
axes[0].set_ylabel("Actual")
axes[0].set_title(f"Confusion Matrix (acc {test_acc:.4f})")

cm_off = cm.copy()
np.fill_diagonal(cm_off, 0)
pairs = [(i, j, cm_off[i, j]) for i in range(10) for j in range(10) if cm_off[i, j] > 0]
pairs.sort(key=lambda t: -t[2])
labels = [f"{i}→{j}" for i, j, _ in pairs[:10]]
counts = [c for _, _, c in pairs[:10]]
axes[1].barh(labels[::-1], counts[::-1], color="crimson")
axes[1].set_xlabel("count")
axes[1].set_title("Most confused pairs")

fig.tight_layout()
plt.show()

# ── 틀린 이미지 ──
wrong_sorted = wrong[np.argsort(-conf[wrong])]
n_show = min(20, len(wrong_sorted))
fig, axes = plt.subplots(2, 10, figsize=(18, 4.5))
for ax, i in zip(axes.ravel(), wrong_sorted[:n_show]):
    ax.imshow(X_test[i, :, :, 0], cmap="gray_r")
    ax.set_title(f"T{y_test[i]} P{pred[i]}\n{conf[i]:.2f}", fontsize=8.5)
    ax.axis("off")
for ax in axes.ravel()[n_show:]:
    ax.axis("off")
fig.suptitle(f"All {len(wrong)} mistakes (top {n_show} by confidence)", fontsize=13)
fig.tight_layout()
plt.show()

print("\n" + "=" * 70)
print("오답 분석")
print("=" * 70)
print(f"총 틀린 개수: {len(wrong)}")
print(f"평균 확신도 (맞힌 것): {conf[pred == y_test].mean():.4f}")
```


[Day 082](day-082.md)의 선택표를 다시 보세요.

### 첫 층 필터를 너무 많이 둠

```python
layers.Conv2D(512, 3),      # 첫 층부터 512개
```

**첫 층은 엣지 같은 단순 패턴만 검출합니다.** 512개나 필요 없습니다.
`32` 또는 `64`로 시작해서 늘려가세요.

### `Conv2D` 를 여러 개 쌓고 Pool을 안 함

```python
Conv2D(32,3,same) → Conv2D(64,3,same) → Conv2D(128,3,same) → Flatten
```

```
28×28×128 → Flatten → 100,352 → Dense(64) = 6,422,592 파라미터
```

**중간중간 Pool을 넣어 크기를 줄이세요.**

### GlobalAveragePooling을 작은 이미지에 씀

```python
# 28×28 MNIST에서
Conv 블록 3개 → (3,3,128) → GAP → (128,)
```

**3×3의 공간 정보를 전부 버립니다.** Step 4에서 GAP이 0.9887로 낮았던 이유입니다.

> **GAP은 큰 이미지(224×224)에서 유용합니다.** 작은 이미지에서는 Flatten이 나을 수 있습니다.

### 함수형 API에서 `Model` 을 안 만듦

```python

from tensorflow.keras import layers


def build(filters=(32, 64, 128, 256), dense=128):
    L = [layers.Input(shape=(64, 64, 3))]
    for f in filters:
        L += [layers.Conv2D(f, 3, padding="same", activation="relu"),
              layers.MaxPooling2D(2)]
    L += [layers.GlobalAveragePooling2D(), layers.Dropout(0.4),
          layers.Dense(dense, activation="relu"),
          layers.Dense(10, activation="softmax")]
    return keras.Sequential(L)
```

```python
    x = layers.Flatten()(x)
    x = layers.Dropout(0.4)(x)
    x = layers.Dense(64, activation="relu")(x)
    out = layers.Dense(10, activation="softmax")(x)
    return keras.Model(inp, out, name="cnn_model")

    return out
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 표준 구조 | `[Conv → ReLU → Pool] × N → Flatten/GAP → Dense → 출력` |
| 두 부분 | **특징 추출부**(Conv/Pool) + **분류부**(Dense) |
| 필터 수 | **32 → 64 → 128** (2배씩 증가) |
| 필터 크기 | **3×3** 표준 |
| 패딩 | `"same"` 이면 크기 관리가 쉬움 |
| 풀링 횟수 | 최종 **7×7 정도**가 되도록 |
| VGG 스타일 | **Conv 2개 연속** 후 Pool. 수용 영역↑, 비선형성↑ |
| 층별 특징 | 엣지 → 모서리 → 질감 → 부분 → 물체 |
| 수용 영역 | 깊을수록 넓어짐 |
| 함수형 API | `layer(입력)` 형태. **중간층 출력** 가능 |
| 특성맵 시각화 | `keras.Model(inputs, [중간층 출력들])` |
| 학습된 필터 | **소벨 등 고전 필터를 재발견** |
| 파라미터 ≠ 연산량 | CNN은 파라미터 적고 **연산은 많음** |

**오늘 반드시 기억할 세 가지**
> ① **`[Conv → Pool]` 블록을 쌓고 필터를 2배씩 늘리는 것**이 표준입니다.
> ② **CNN은 층이 깊어질수록 추상적인 것을 봅니다.** 특성맵으로 확인할 수 있습니다.
> ③ **CNN이 소벨 필터를 스스로 발견했습니다.** 규칙을 데이터에서 찾는다는 것의 실제 사례입니다.
