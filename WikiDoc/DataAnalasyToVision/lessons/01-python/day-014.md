## ③ 개념 설명

### 예외(Exception)란

프로그램 실행 중에 발생하는 문제 상황을 **예외**라고 합니다.
예외가 발생하면 파이썬은 그 자리에서 실행을 멈추고 에러 메시지를 출력합니다.

```
정상: 코드1 → 코드2 → 코드3 → 끝
예외: 코드1 → 코드2(💥) →  ✕  프로그램 중단
```

**예외 처리**는 이 상황을 미리 준비해 두고, 죽는 대신 다르게 대응하는 것입니다.

### try / except — 기본형

```python
try:
    위험할 수 있는 코드
except:
    예외가 났을 때 실행할 코드
```

```python
try:
    age = int(input("나이: "))
    print(f"내년에는 {age + 1}살")
except:
    print("숫자를 입력해 주세요.")

print("프로그램은 계속됩니다.")
```

실행 결과:

```
나이: 스물다섯
숫자를 입력해 주세요.
프로그램은 계속됩니다.
```

### 예외 종류를 지정하기

`except:` 만 쓰면 **모든 예외**를 잡습니다. 이건 위험합니다. 진짜 버그까지 숨겨 버리기 때문입니다.

```python
try:
    num = int(input("숫자: "))
    result = 100 / num
    print(result)

except ValueError:
    print("숫자가 아닙니다.")

except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

실행 결과:

```
숫자: 0
0으로 나눌 수 없습니다.
```

**여러 예외를 한 번에**

```python
except (ValueError, TypeError):
    print("입력값이 잘못되었습니다.")
```

**에러 메시지 받아 보기**

```python
try:
    num = int("abc")
except ValueError as e:
    print(f"오류 내용: {e}")
```

실행 결과:

```
오류 내용: invalid literal for int() with base 10: 'abc'
```

### try / except / else / finally

```python
try:
    위험한 코드
except 예외:
    예외 발생 시
else:
    예외가 안 났을 때만
finally:
    예외 여부와 관계없이 항상
```

```python
try:
    num = int(input("숫자: "))
except ValueError:
    print("잘못된 입력입니다.")
else:
    print(f"입력값의 제곱은 {num ** 2}")
finally:
    print("입력 처리를 마쳤습니다.")
```

| 블록 | 실행 시점 | 주 용도 |
|---|---|---|
| `try` | 항상 (시도) | 위험한 코드 |
| `except` | 예외 발생 시 | 대응 |
| `else` | 예외가 **안** 났을 때 | 성공했을 때만 할 일 |
| `finally` | **언제나** | 뒷정리 (파일 닫기, 연결 해제) |

### raise — 직접 예외를 일으키기

```python
def set_age(age):
    if age < 0:
        raise ValueError("나이는 0 이상이어야 합니다")
    return age


try:
    set_age(-5)
except ValueError as e:
    print(f"오류: {e}")
```

실행 결과:

```
오류: 나이는 0 이상이어야 합니다
```

> **언제 `raise` 를 쓰는가** — 함수 안에서 "이건 잘못된 상황이다" 를 알려야 하는데, 그 자리에서 처리할 수 없을 때입니다.
> 어떻게 대응할지는 **함수를 호출한 쪽**이 결정하게 넘기는 것입니다.

### 파일 열고 닫기 — with open

```python
with open("파일명", "모드", encoding="utf-8") as f:
    작업
```

| 모드 | 뜻 | 파일이 없으면 | 파일이 있으면 |
|---|---|---|---|
| `"r"` | 읽기 (기본값) | 에러 | 읽음 |
| `"w"` | 쓰기 | 새로 만듦 | **전부 지우고 새로 씀** ⚠️ |
| `"a"` | 이어쓰기 | 새로 만듦 | 뒤에 덧붙임 |
| `"x"` | 새로 만들기 | 새로 만듦 | 에러 |

> ⚠️ **`"w"` 모드는 기존 내용을 전부 지웁니다.** 실수로 중요한 파일을 열면 그 즉시 비워집니다. 주의하세요.

> **`with` 를 쓰는 이유** — 블록이 끝나면 파일을 **자동으로 닫아 줍니다.**
> `with` 없이 `open()` 만 쓰면 `f.close()` 를 직접 호출해야 하고, 중간에 에러가 나면 파일이 열린 채 남습니다.

> **`encoding="utf-8"` 을 꼭 쓰세요.** 안 쓰면 Windows에서 한글이 깨지거나 `UnicodeDecodeError` 가 납니다.

### 텍스트 파일 쓰기

```python
# 새로 쓰기 (기존 내용 삭제)
with open("memo.txt", "w", encoding="utf-8") as f:
    f.write("첫 번째 줄\n")
    f.write("두 번째 줄\n")

# 이어쓰기
with open("memo.txt", "a", encoding="utf-8") as f:
    f.write("세 번째 줄\n")

# 여러 줄 한 번에
lines = ["네 번째\n", "다섯 번째\n"]
with open("memo.txt", "a", encoding="utf-8") as f:
    f.writelines(lines)
```

> `f.write()` 는 **줄바꿈을 자동으로 넣지 않습니다.** `\n` 을 직접 써야 합니다.

### 텍스트 파일 읽기

```python
# 방법 1: 전체를 하나의 문자열로
with open("memo.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)

# 방법 2: 줄 단위 리스트로
with open("memo.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
print(lines)      # ['첫 번째 줄\n', '두 번째 줄\n', ...]

# 방법 3: 한 줄씩 순회 (대용량 파일에 권장)
with open("memo.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())      # strip() 으로 줄바꿈 제거
```

| 방법 | 메모리 | 쓸 때 |
|---|---|---|
| `read()` | 전체를 메모리에 | 작은 파일, 전체 내용이 필요할 때 |
| `readlines()` | 전체를 리스트로 | 줄 개수를 알아야 할 때 |
| `for line in f` | 한 줄씩만 | **대용량 파일** (권장) |

### CSV 파일 다루기

CSV(Comma-Separated Values)는 콤마로 구분된 표 데이터입니다. 엑셀에서 바로 열립니다.

```
이름,국어,영어,수학
홍길동,85,90,78
김철수,92,88,95
```

**직접 처리하기 (원리 이해용)**

```python
# 쓰기
students = [
    ["홍길동", 85, 90, 78],
    ["김철수", 92, 88, 95],
]

with open("scores.csv", "w", encoding="utf-8") as f:
    f.write("이름,국어,영어,수학\n")
    for row in students:
        line = ",".join(str(v) for v in row)
        f.write(line + "\n")

# 읽기
with open("scores.csv", "r", encoding="utf-8") as f:
    header = f.readline().strip().split(",")
    for line in f:
        values = line.strip().split(",")
        print(values)
```

**`csv` 모듈로 처리하기 (실무 권장)**

```python
import csv

# 쓰기 — newline="" 을 반드시 넣습니다
with open("scores.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["이름", "국어", "영어", "수학"])
    writer.writerow(["홍길동", 85, 90, 78])

# 읽기
with open("scores.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

**딕셔너리로 읽고 쓰기 (가장 편리)**

```python
import csv

students = [
    {"이름": "홍길동", "국어": 85, "영어": 90},
    {"이름": "김철수", "국어": 92, "영어": 88},
]

with open("scores.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["이름", "국어", "영어"])
    writer.writeheader()
    writer.writerows(students)

with open("scores.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["이름"], row["국어"])
```

> ⚠️ **`newline=""` 을 빼면** Windows에서 줄 사이에 빈 줄이 하나씩 끼어듭니다. 쓰기 모드에서는 항상 넣으세요.
> ⚠️ **CSV로 읽은 값은 전부 문자열입니다.** 계산하려면 `int()` 로 바꿔야 합니다.

### JSON — 오늘의 핵심

**JSON(JavaScript Object Notation)** 은 데이터를 주고받는 표준 형식입니다.
구조가 파이썬의 **딕셔너리·리스트와 거의 같습니다.**

```json
{
  "name": "홍길동",
  "age": 25,
  "scores": {"국어": 85, "영어": 90},
  "hobbies": ["독서", "등산"]
}
```

| 파이썬 | JSON |
|---|---|
| `dict` | object `{}` |
| `list` | array `[]` |
| `str` | string |
| `int` / `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

**저장하기**

```python
import json

data = {
    "name": "홍길동",
    "age": 25,
    "scores": {"국어": 85, "영어": 90},
}

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

| 옵션 | 뜻 | 안 쓰면 |
|---|---|---|
| `ensure_ascii=False` | 한글을 그대로 저장 | `종길동` 처럼 깨져 보임 |
| `indent=2` | 들여쓰기로 보기 좋게 | 한 줄로 뭉쳐 저장 |

**불러오기**

```python
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data["name"])                  # 홍길동
print(data["scores"]["국어"])         # 85
print(type(data))                    # <class 'dict'>
```

**문자열로 변환 (파일 없이)**

```python
text = json.dumps(data, ensure_ascii=False)     # 딕셔너리 → 문자열
back = json.loads(text)                          # 문자열 → 딕셔너리
```

> **`dump` / `load` 는 파일용, `dumps` / `loads` 는 문자열용**입니다. `s` 는 string 의 s 입니다.
> API 응답을 처리할 때는 `loads` 를 씁니다. (대단원 02)

### CSV vs JSON — 언제 무엇을 쓰나

| | CSV | JSON |
|---|---|---|
| 구조 | 표 (행 × 열) | 중첩 가능 |
| 사람이 읽기 | 엑셀로 편함 | 텍스트로 가능 |
| 중첩 데이터 | ❌ 불가능 | ✅ 가능 |
| 자료형 | 전부 문자열 | 숫자·불리언 보존 |
| 용도 | 성적표, 매출 데이터 | 설정값, API 응답, 게임 세이브 |

### Step 1. 안전한 입력 함수 만들기

`safe_input.py` 를 만들어 실행합니다.

```python
def input_int(prompt, low=None, high=None):
    """정수를 입력받습니다. 올바른 값이 들어올 때까지 반복합니다."""
    while True:
        try:
            value = int(input(prompt))

            if low is not None and value < low:
                print(f"  → {low} 이상이어야 합니다.")
                continue

            if high is not None and value > high:
                print(f"  → {high} 이하여야 합니다.")
                continue

            return value

        except ValueError:
            print("  → 숫자를 입력해 주세요.")


def input_float(prompt, low=None):
    """실수를 입력받습니다."""
    while True:
        try:
            value = float(input(prompt))
            if low is not None and value < low:
                print(f"  → {low} 이상이어야 합니다.")
                continue
            return value
        except ValueError:
            print("  → 숫자를 입력해 주세요.")


# ── 사용 ──
age = input_int("나이(0~120): ", low=0, high=120)
height = input_float("키(cm): ", low=0)

print(f"\n{age}세, {height}cm 로 등록되었습니다.")
```

실행 결과:

```
나이(0~120): 스물다섯
  → 숫자를 입력해 주세요.
나이(0~120): 200
  → 120 이하여야 합니다.
나이(0~120): 25
키(cm): abc
  → 숫자를 입력해 주세요.
키(cm): 175.5

25세, 175.5cm 로 등록되었습니다.
```

> **이 함수를 앞으로 계속 쓰세요.** Day 010의 `get_choice()` 를 일반화한 것입니다.
> `input_int()` 하나만 있으면 입력 관련 크래시가 사라집니다.

### Step 2. 메모장 프로그램

```python
FILENAME = "memo.txt"


def write_memo(text):
    """메모를 파일 끝에 추가합니다."""
    with open(FILENAME, "a", encoding="utf-8") as f:
        f.write(text + "\n")
    print("→ 저장했습니다.")


def read_memo():
    """메모 전체를 읽어 출력합니다."""
    try:
        with open(FILENAME, "r", encoding="utf-8") as f:
            lines = f.readlines()

        if not lines:
            print("→ 메모가 비어 있습니다.")
            return

        print("\n" + "─" * 34)
        for i, line in enumerate(lines, start=1):
            print(f"  {i}. {line.strip()}")
        print("─" * 34)
        print(f"  총 {len(lines)}줄")

    except FileNotFoundError:
        print("→ 아직 메모가 없습니다.")


def clear_memo():
    """메모를 전부 지웁니다."""
    with open(FILENAME, "w", encoding="utf-8") as f:
        pass          # 아무것도 안 쓰면 빈 파일이 됩니다
    print("→ 모두 삭제했습니다.")


# ── 실행 ──
print("=" * 34)
print("           간단 메모장")
print("=" * 34)

while True:
    print("\n1. 메모 보기   2. 메모 쓰기   3. 전체 삭제   4. 종료")
    menu = input("> ").strip()

    if menu == "1":
        read_memo()
    elif menu == "2":
        text = input("내용: ").strip()
        if text:
            write_memo(text)
        else:
            print("→ 내용을 입력해 주세요.")
    elif menu == "3":
        confirm = input("정말 삭제할까요? (y/n): ").strip().lower()
        if confirm == "y":
            clear_memo()
    elif menu == "4":
        print("→ 종료합니다.")
        break
    else:
        print("→ 1~4 중에서 선택해 주세요.")
```

실행 결과:

```
==================================
           간단 메모장
==================================

1. 메모 보기   2. 메모 쓰기   3. 전체 삭제   4. 종료
> 1
→ 아직 메모가 없습니다.

1. 메모 보기   2. 메모 쓰기   3. 전체 삭제   4. 종료
> 2
내용: 오늘 배운 것: 예외 처리
→ 저장했습니다.

1. 메모 보기   2. 메모 쓰기   3. 전체 삭제   4. 종료
> 2
내용: 내일 할 것: 파일 입출력 복습
→ 저장했습니다.

1. 메모 보기   2. 메모 쓰기   3. 전체 삭제   4. 종료
> 1

──────────────────────────────────
  1. 오늘 배운 것: 예외 처리
  2. 내일 할 것: 파일 입출력 복습
──────────────────────────────────
  총 2줄
```

> **`FileNotFoundError`** 를 처리한 것이 핵심입니다. 처음 실행할 때는 파일이 없는 게 정상이므로, 에러가 아니라 "아직 메모가 없다"고 안내합니다.

### Step 3. CSV로 성적 저장하고 읽기

```python
import csv

FILENAME = "scores.csv"
FIELDS = ["이름", "국어", "영어", "수학"]


def save_csv(students):
    """학생 목록(딕셔너리 리스트)을 CSV로 저장합니다."""
    with open(FILENAME, "w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=FIELDS)
        writer.writeheader()
        writer.writerows(students)
    print(f"→ {len(students)}명을 {FILENAME} 에 저장했습니다.")


def load_csv():
    """CSV를 읽어 학생 목록을 반환합니다."""
    students = []
    try:
        with open(FILENAME, "r", encoding="utf-8") as f:
            reader = csv.DictReader(f)
            for row in reader:
                # CSV는 전부 문자열이므로 숫자로 변환합니다
                students.append({
                    "이름": row["이름"],
                    "국어": int(row["국어"]),
                    "영어": int(row["영어"]),
                    "수학": int(row["수학"]),
                })
        print(f"→ {len(students)}명을 불러왔습니다.")

    except FileNotFoundError:
        print("→ 저장된 파일이 없습니다. 새로 시작합니다.")
    except (ValueError, KeyError) as e:
        print(f"→ 파일 형식이 잘못되었습니다: {e}")

    return students


def show(students):
    """성적표를 출력합니다."""
    if not students:
        print("  (데이터 없음)")
        return

    print("\n" + "-" * 44)
    print(f"{'이름':<10}{'국어':>7}{'영어':>7}{'수학':>7}{'평균':>9}")
    print("-" * 44)

    for s in students:
        avg = (s["국어"] + s["영어"] + s["수학"]) / 3
        print(f"{s['이름']:<10}{s['국어']:>7}{s['영어']:>7}{s['수학']:>7}{avg:>9.1f}")

    print("-" * 44)

    {"이름": "이영희", "국어": 70, "영어": 75, "수학": 82},

show(loaded)
```

```python
import json
import os

DB_FILE = "students.json"


def load_db():
    """저장된 학생 데이터를 불러옵니다."""
    if not os.path.exists(DB_FILE):
        return {}

    try:
        with open(DB_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        print("⚠ 데이터 파일이 손상되어 새로 시작합니다.")
        return {}


def save_db(db):
    """학생 데이터를 저장합니다."""
    try:
        with open(DB_FILE, "w", encoding="utf-8") as f:
            json.dump(db, f, ensure_ascii=False, indent=2)
        return True
    except Exception as e:
        print(f"⚠ 저장 실패: {e}")
        return False


def input_int(prompt, low=0, high=100):
    """범위 안의 정수를 입력받습니다."""
    while True:
        try:
            value = int(input(prompt))
            if low <= value <= high:
                return value
            print(f"  → {low}~{high} 사이로 입력해 주세요.")
        except ValueError:
            print("  → 숫자를 입력해 주세요.")


def add_student(db):
    """학생을 추가합니다."""
    name = input("이름: ").strip()
    if not name:
        print("→ 이름을 입력해 주세요.")
        return

    if name in db:
        confirm = input(f"'{name}' 이(가) 이미 있습니다. 덮어쓸까요? (y/n): ").strip().lower()
        if confirm != "y":
            print("→ 취소했습니다.")
            return

    db[name] = {
        "국어": input_int("  국어: "),
        "영어": input_int("  영어: "),
        "수학": input_int("  수학: "),
    }
    save_db(db)
    print(f"→ '{name}' 저장 완료.")


def show_all(db):
    """전체 성적표를 출력합니다."""
    if not db:
        print("→ 등록된 학생이 없습니다.")
        return

    print("\n" + "=" * 48)
    print(f"{'이름':<10}{'국어':>7}{'영어':>7}{'수학':>7}{'평균':>9}{'학점':>5}")
    print("-" * 48)

    ranked = sorted(db.items(), key=lambda x: sum(x[1].values()), reverse=True)

    for name, s in ranked:
        avg = sum(s.values()) / len(s)
        grade = "A" if avg >= 90 else "B" if avg >= 80 else "C" if avg >= 70 else "D" if avg >= 60 else "F"
        print(f"{name:<10}{s['국어']:>7}{s['영어']:>7}{s['수학']:>7}{avg:>9.1f}{grade:>5}")

    print("-" * 48)
    all_avg = sum(sum(s.values()) / 3 for s in db.values()) / len(db)
    print(f"전체 {len(db)}명 · 학급 평균 {all_avg:.1f}점")
    print("=" * 48)


def delete_student(db):
    """학생을 삭제합니다."""
    name = input("삭제할 이름: ").strip()

    if name not in db:
        print(f"→ '{name}' 학생이 없습니다.")
        return

    del db[name]
    save_db(db)
    print(f"→ '{name}' 삭제 완료.")


# ── 메인 ──
db = load_db()

print("=" * 48)
print("              성적 관리 프로그램")
print("=" * 48)
print(f"저장된 학생 {len(db)}명을 불러왔습니다.")

while True:
    print("\n1. 전체 보기   2. 추가   3. 삭제   4. 종료")
    menu = input("> ").strip()

    if menu == "1":
        show_all(db)
    elif menu == "2":
        add_student(db)
    elif menu == "3":
        delete_student(db)
    elif menu == "4":
        save_db(db)
        print("→ 저장 후 종료합니다.")
        break
    else:
        print("→ 1~4 중에서 선택해 주세요.")
```

**해결** — 예상되는 예외만 명시적으로 잡고, 메시지도 함께 출력합니다.

### 파일을 `"w"` 로 열어 내용이 날아감

```python
with open("important.txt", "w", encoding="utf-8") as f:
    content = f.read()          # 읽으려던 건데...
```

```
io.UnsupportedOperation: not readable
```

**원인** — `"w"` 로 여는 순간 **파일이 비워집니다.** 에러가 나든 안 나든 이미 늦었습니다.
**해결** — 읽을 때는 반드시 `"r"`, 덧붙일 때는 `"a"` 를 씁니다.

> **`"w"` 를 쓰기 전에 항상 한 번 더 확인하세요.** 되돌릴 방법이 없습니다.

### `encoding` 을 안 써서 한글이 깨짐

> 대단원 02에서 공공데이터 CSV를 읽을 때 이 문제를 다시 만납니다. 그때는 `cp949` 를 써야 하는 경우도 있습니다.

### JSON에 저장할 수 없는 값을 넣음

```python

with open("data.txt", "w", encoding="utf-8") as f:
    f.write("내용")
```

```python
                    total += float(line)
                    ok += 1
                except ValueError:
                    print(f"  ⚠ {line_no}번째 줄 '{line}' 은(는) 숫자가 아닙니다.")
                    fail += 1

    except FileNotFoundError:
        print(f"  ⚠ '{filename}' 파일이 없습니다.")
        return 0, 0, 0

    return total, ok, fail


# 테스트용 파일 만들기
with open("numbers.txt", "w", encoding="utf-8") as f:
    f.write("10\n20\nabc\n30\n\n40.5\n")

total, ok, fail = sum_from_file("numbers.txt")
print(f"\n합계: {total}  (성공 {ok}건 / 실패 {fail}건)")

print()
sum_from_file("없는파일.txt")
```

실행 결과:

```
  ⚠ 3번째 줄 'abc' 은(는) 숫자가 아닙니다.

합계: 100.5  (성공 4건 / 실패 1건)

  ⚠ '없는파일.txt' 파일이 없습니다.
```

**포인트 3가지**
- **`try` 를 두 겹으로** 썼습니다. 바깥은 파일 자체, 안쪽은 줄 하나. 한 줄이 잘못돼도 나머지는 계속 처리합니다.
- `enumerate(f, start=1)` 로 줄 번호를 함께 얻어, 어느 줄이 문제인지 정확히 알려 줍니다.
- 성공/실패 건수를 함께 반환해, 호출한 쪽이 "얼마나 신뢰할 수 있는 결과인지" 판단할 수 있게 합니다.
</details>

**3.** 아래 코드는 설정을 JSON으로 저장하는데, 실행할 때마다 이전 설정이 사라집니다. 원인과 해결책을 쓰세요.

```python
import json

def save_setting(key, value):
    settings = {key: value}
    with open("config.json", "w", encoding="utf-8") as f:
        json.dump(settings, f, ensure_ascii=False, indent=2)

save_setting("volume", 80)
save_setting("theme", "dark")

with open("config.json", "r", encoding="utf-8") as f:
    print(json.load(f))
```

<details>
<summary>답 보기</summary>

**실제 출력**

```
{'theme': 'dark'}
```

`volume` 이 사라졌습니다.

**원인** — `save_setting` 이 호출될 때마다 **새 딕셔너리를 만들어 통째로 덮어씁니다.**
게다가 `"w"` 모드는 파일을 비우고 시작하므로, 이전 내용은 완전히 사라집니다.

```
1회차: {"volume": 80}       파일에 씀
2회차: {"theme": "dark"}    파일을 비우고 새로 씀 ← volume 소멸
```

**해결 — 기존 설정을 읽어서 갱신한 뒤 저장**

```python
import json
import os

CONFIG_FILE = "config.json"


def load_settings():
    """기존 설정을 불러옵니다. 없으면 빈 딕셔너리."""
    if not os.path.exists(CONFIG_FILE):
        return {}
    try:
        with open(CONFIG_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        return {}


def save_setting(key, value):
    """기존 설정을 유지하며 하나만 갱신합니다."""
    settings = load_settings()        # ① 먼저 읽고
    settings[key] = value             # ② 수정하고
    with open(CONFIG_FILE, "w", encoding="utf-8") as f:
        json.dump(settings, f, ensure_ascii=False, indent=2)   # ③ 전체를 저장


save_setting("volume", 80)
save_setting("theme", "dark")

print(load_settings())
```

실행 결과:

```
{'volume': 80, 'theme': 'dark'}
```

> **교훈** — JSON 파일에는 "일부만 수정" 이 없습니다. 항상 **① 전체 읽기 → ② 메모리에서 수정 → ③ 전체 쓰기** 순서입니다.
> W07에서 배울 데이터베이스는 이 문제를 해결합니다. `UPDATE` 문으로 필요한 행만 고칠 수 있습니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `try` / `except` | 예외가 나도 프로그램이 안 죽음 |
| 예외 지정 | `except:` 만 쓰지 말고 종류를 명시 |
| `else` / `finally` | 예외 없을 때만 / 언제나 |
| `raise` | 직접 예외 발생 |
| `with open()` | 자동으로 파일을 닫아 줌 |
| 모드 | `r` 읽기 · **`w` 는 내용 삭제** · `a` 이어쓰기 |
| 인코딩 | **항상 `encoding="utf-8"`** |
| CSV | `csv.DictReader` / `DictWriter` · 쓰기엔 `newline=""` · **값은 전부 문자열** |
| JSON | `json.dump/load` (파일) · `dumps/loads` (문자열) |
| JSON 옵션 | `ensure_ascii=False` (한글) · `indent=2` (보기 좋게) |

**오늘 반드시 기억할 세 가지**
> ① `"w"` 모드는 파일 내용을 **전부 지웁니다.**
> ② 파일을 다룰 때는 항상 `encoding="utf-8"`.
> ③ JSON 저장은 **읽기 → 수정 → 전체 쓰기** 순서입니다.
