## 1부 · 저장 형식

### 무엇을 저장해야 하는가

| 항목 | 이유 |
|---|---|
| 모델 파이프라인 | 예측 |
| **특성 순서** | 순서가 바뀌면 결과가 달라짐 |
| **파생 특성 코드** | 재현 필수 |
| 기본값 / 결측 대체값 | 누락 입력 처리 |
| 학습 데이터 통계 | 이상 입력 탐지 |
| 버전 정보 | sklearn·numpy 버전 |
| **성능·사용 제한** | 신뢰도 판단 |

### 형식 비교

| 형식 | 대상 | 특징 |
|---|---|---|
| `joblib` | sklearn | 빠름, 파이썬 전용 |
| `.keras` | 케라스 | 케라스 전용 |
| `pickle` | 아무거나 | ★ 보안 위험 |
| ONNX | 범용 | 언어 무관, 변환 필요 |

**우리는 sklearn 파이프라인이므로 `joblib` 입니다.**

> **신뢰할 수 없는 출처의 모델 파일을 로드하지 마세요.**

## 2부 · 입력 스키마

### 3계층으로 나눕니다

```
① 필수 입력 (사용자가 반드시 줘야 함)
   name, price_krw, release_date, genres

② 선택 입력 (있으면 좋음, 없으면 기본값)
   review_count, positive_ratio, metacritic_score, developer, ...

③ 파생 특성 (코드가 계산)
   days_since_release, price_log, genre_* ...
```

### 검증 항목

| 검증 | 예 |
|---|---|
| 존재 | 필수 키가 있는가 |
| 타입 | `price_krw` 가 숫자인가 |
| 범위 | 가격 ≥ 0, 비율 0~1 |
| 형식 | 날짜가 `YYYY-MM-DD` 인가 |
| **분포** | 학습 범위를 크게 벗어나는가 |

### ★ 범위 검증과 분포 검증은 다릅니다

```
범위 검증: price_krw = -1000  →  오류 (물리적으로 불가능)
분포 검증: price_krw = 5,000,000  →  경고 (가능하지만 학습에 없던 값)
```

**오류는 거부, 경고는 예측하되 신뢰도를 낮춥니다.**

## 4부 · 예외 처리 계층

### 예외를 종류별로 나눕니다

```python
class PredictorError(Exception): ...
class InputValidationError(PredictorError): ...     # 400
class ModelNotLoadedError(PredictorError): ...      # 503
class PredictionError(PredictorError): ...          # 500
```

**대단원 05에서 HTTP 상태 코드로 바로 매핑됩니다.**

### 실패해도 되는 것과 안 되는 것

| 상황 | 처리 |
|---|---|
| 필수 키 누락 | **거부** (오류) |
| 선택 키 누락 | 기본값으로 대체 (경고) |
| 값이 범위 밖 | **거부** |
| 값이 분포 밖 | 예측하되 신뢰도 하락 |
| 모델 로드 실패 | **거부** |
| 예측 중 예외 | **거부** (추측값 반환 금지) |

> ⚠️ **예측이 실패했는데 기본값(평균)을 조용히 반환하면 안 됩니다.**
> **사용자는 그것이 예측인 줄 압니다.**

## 5부 · 신뢰도 등급

### [Day 131](day-131.md)의 취약 구간을 코드로

```

예측값 0~1% 또는 75% 초과                   →  ★ 낮음 (사용 권장 안 함)
```

### Step 1. 파생 특성 모듈 분리

```python
from pathlib import Path

SRC = Path("steam_project/src")
SRC.mkdir(parents=True, exist_ok=True)

FEATURES_PY = '''
"""파생 특성 — 학습·서빙 공용 (steam_project/src/features.py)

★ 이 파일 하나만 고치면 학습과 서빙이 함께 바뀝니다.
  Day 127에서 노트북에 흩어져 있던 로직을 여기로 모았습니다.
"""
from datetime import datetime

import numpy as np
import pandas as pd

GENRE_VOCAB = [
    "Action", "Adventure", "RPG", "Simulation", "Strategy", "Sports",
    "Racing", "Indie", "Casual", "Puzzle", "Horror", "Shooter",
    "Platformer", "Roguelike", "Survival", "Sandbox", "MMO", "Card",
]
PLATFORM_VOCAB = ["windows", "mac", "linux", "steamdeck"]
FEATURE_VOCAB = ["multiplayer", "coop", "controller", "cloud",
                 "achievements", "workshop", "vr"]

DEFAULTS = {
    "review_count": 0,
    "positive_ratio": 0.75,
    "metacritic_score": np.nan,
    "sale_count_1y": 0,
    "max_hist_discount": np.nan,
    "mean_hist_discount": np.nan,
    "days_since_last_sale": np.nan,
    "dlc_count": 0,
    "developer": "__unknown__",
    "publisher": "__unknown__",
    "genres": [],
    "platforms": ["windows"],
    "features": [],
}

REQUIRED = ["price_krw", "release_date"]


def derive(raw: dict, as_of=None) -> pd.DataFrame:
    """원시 dict 하나 → 파생 특성이 채워진 1행 DataFrame.

    as_of : 기준일. 학습 시에는 수집일, 서빙 시에는 요청일.
            ★ 반드시 명시적으로 넘기세요 (재현성).
    """
    as_of = pd.Timestamp(as_of) if as_of is not None else pd.Timestamp.now()
    r = {**DEFAULTS, **{k: v for k, v in raw.items() if v is not None}}

    rel = pd.Timestamp(r["release_date"])
    price = float(r["price_krw"])
    out = {}

    # ── 가격 ──
    out["price_krw"] = price
    out["price_log"] = float(np.log1p(price))
    out["is_free"] = int(price == 0)
    out["price_tier"] = int(np.digitize(price, [5000, 15000, 40000, 70000]))

    # ── 출시 경과 ──
    days = max((as_of - rel).days, 0)
    out["days_since_release"] = days
    out["days_since_release_log"] = float(np.log1p(days))
    out["release_year"] = int(rel.year)
    out["release_month"] = int(rel.month)
    out["release_month_sin"] = float(np.sin(2 * np.pi * rel.month / 12))
    out["release_month_cos"] = float(np.cos(2 * np.pi * rel.month / 12))
    out["is_over_1y"] = int(days > 365)
    out["is_over_3y"] = int(days > 1095)

    # ── 리뷰 ──
    rc = float(r["review_count"])
    out["review_count"] = rc
    out["review_count_log"] = float(np.log1p(rc))
    out["positive_ratio"] = float(r["positive_ratio"])
    out["review_per_year"] = float(rc / max(days / 365.25, 0.25))
    out["is_popular"] = int(rc >= 1000)

    # ── 평점 ──
    mc = r["metacritic_score"]
    out["metacritic_score"] = float(mc) if mc is not None and not pd.isna(mc) else np.nan
    out["has_metacritic"] = int(not pd.isna(out["metacritic_score"]))

    # ── 할인 이력 ──
    for k in ["sale_count_1y", "max_hist_discount", "mean_hist_discount",
              "days_since_last_sale"]:
        out[k] = float(r[k]) if r[k] is not None and not pd.isna(r[k]) else np.nan
    out["sale_count_1y"] = 0.0 if pd.isna(out["sale_count_1y"]) else out["sale_count_1y"]
    out["has_sale_history"] = int(out["sale_count_1y"] > 0)
    out["sale_freq"] = float(out["sale_count_1y"] / max(days / 365.25, 0.25))
    out["hist_discount_range"] = float(
        (out["max_hist_discount"] - out["mean_hist_discount"])
        if not (pd.isna(out["max_hist_discount"]) or pd.isna(out["mean_hist_discount"]))
        else np.nan)

    # ── DLC ──
    out["dlc_count"] = float(r["dlc_count"])
    out["has_dlc"] = int(out["dlc_count"] > 0)

    # ── 상호작용 ──
    out["price_x_age"] = float(out["price_log"] * out["days_since_release_log"])
    out["price_per_review"] = float(price / max(rc, 1))

    # ── 다중 레이블 ──
    genres = [g for g in (r["genres"] or [])]
    for g in GENRE_VOCAB:
        out[f"genre_{g}"] = int(g in genres)
    out["genre_count"] = len(genres)
    out["primary_genre"] = genres[0] if genres else "__unknown__"

    for p in PLATFORM_VOCAB:
        out[f"plat_{p}"] = int(p in (r["platforms"] or []))
    for f in FEATURE_VOCAB:
        out[f"feat_{f}"] = int(f in (r["features"] or []))

    # ── 범주형 원본 ──
    out["developer"] = str(r["developer"])
    out["publisher"] = str(r["publisher"])

    return pd.DataFrame([out])


def derive_batch(rows, as_of=None) -> pd.DataFrame:
    """여러 건을 한 번에."""
    return pd.concat([derive(r, as_of) for r in rows], ignore_index=True)
'''

(SRC / "features.py").write_text(FEATURES_PY.strip() + "\n", encoding="utf-8")
print(f"작성: {SRC / 'features.py'}  ({len(FEATURES_PY.splitlines())}줄)")
```

### Step 2. ★ 학습-서빙 일치 검증

```python
import sys
from pathlib import Path

import numpy as np
import pandas as pd

ROOT = Path("steam_project")
sys.path.insert(0, str(ROOT.resolve().parent))
from steam_project.src.features import derive, derive_batch   # noqa: E402

df = pd.read_csv(ROOT / "data" / "processed" / "analysis_v2.csv")
raw = pd.read_json(ROOT / "data" / "raw" / "steam_apps.jsonl", lines=True)
AS_OF = pd.Timestamp(json.loads((ROOT / "docs" / "problem_definition.json")
                                .read_text(encoding="utf-8"))["수집일"])

print("=" * 92)
print("★ 학습-서빙 일치 검증 — 가장 중요한 단계")
print("=" * 92)
print(f"  기준일(as_of): {AS_OF.date()}   ← 학습 데이터 수집일")

# ── 원시 데이터 30건을 features.py로 다시 계산 ──
sample_ids = df["appid"].sample(30, random_state=42).tolist()
rebuilt = []
for aid in sample_ids:
    r = raw[raw["appid"] == aid].iloc[0].to_dict()
    rebuilt.append(derive({
        "price_krw": r["price_krw"], "release_date": r["release_date"],
        "review_count": r["review_count"], "positive_ratio": r["positive_ratio"],
        "metacritic_score": r.get("metacritic_score"),
        "sale_count_1y": r.get("sale_count_1y"),
        "max_hist_discount": r.get("max_hist_discount"),
        "mean_hist_discount": r.get("mean_hist_discount"),
        "days_since_last_sale": r.get("days_since_last_sale"),
        "dlc_count": r.get("dlc_count"), "genres": r.get("genres"),
        "platforms": r.get("platforms"), "features": r.get("features"),
        "developer": r.get("developer"), "publisher": r.get("publisher"),
    }, as_of=AS_OF))
rebuilt = pd.concat(rebuilt, ignore_index=True)
stored = df[df["appid"].isin(sample_ids)].set_index("appid").loc[sample_ids]

common = [c for c in rebuilt.columns if c in stored.columns]
print(f"\n  비교 대상: {len(common)}개 특성 × 30건")

diffs = []
for c in common:
    a = pd.to_numeric(rebuilt[c], errors="coerce").to_numpy()
    b = pd.to_numeric(stored[c].to_numpy(), errors="coerce")
    if np.issubdtype(a.dtype, np.number) and np.issubdtype(b.dtype, np.number):
        d = np.nanmax(np.abs(a - b)) if len(a) else 0.0
    else:
        d = float((rebuilt[c].astype(str).to_numpy()
                   != stored[c].astype(str).to_numpy()).sum())
    if d > 1e-6:
        diffs.append({"특성": c, "최대 차이": round(float(d), 6)})

if diffs:
    print(f"\n  ★★ 불일치 {len(diffs)}개 발견 — 반드시 고쳐야 합니다")
    print(pd.DataFrame(diffs).to_string(index=False))
else:
    print(f"\n  ✓ 전 {len(common)}개 특성 일치 (최대 차이 < 1e-6)")
    print("    → 학습-서빙 왜곡 없음")

# ── 예측값까지 일치하는지 ──
import joblib
from sklearn.metrics import mean_absolute_error

bundle = joblib.load(ROOT / "models" / "final_model.joblib")
model, FEATS = bundle["model"], bundle["features"]
COLS = FEATS + ["developer", "publisher"]

p_stored = model.predict(stored[COLS])
p_rebuilt = model.predict(rebuilt[COLS])
maxdiff = float(np.abs(p_stored - p_rebuilt).max())
print(f"\n  예측값 최대 차이: {maxdiff:.10f}")
print(f"  → {'✓ 완전 일치' if maxdiff < 1e-8 else '★ 불일치 — 원인 추적 필요'}")
print("=" * 92)
```

```python
PREDICTOR_PY = '''
"""스팀 할인율 예측 모듈 (steam_project/src/predictor.py)

사용:
    from src.predictor import Predictor
    p = Predictor()
    p.predict({"price_krw": 44000, "release_date": "2018-04-24",
               "genres": ["Strategy"], "review_count": 8412})

대단원 05에서 Flask가 이 predict() 를 그대로 호출합니다.
"""
from datetime import datetime
from pathlib import Path

import joblib
import numpy as np
import pandas as pd

from .features import DEFAULTS, REQUIRED, derive

BUNDLE_PATH = Path(__file__).resolve().parents[1] / "models" / "predictor_bundle.joblib"


# ────────────────────────── 예외 ──────────────────────────
class PredictorError(Exception):
    """모듈 최상위 예외."""
    http_status = 500


class InputValidationError(PredictorError):
    """입력이 잘못됨 — 사용자 잘못."""
    http_status = 400


class ModelNotLoadedError(PredictorError):
    """모델 파일 문제 — 서버 잘못."""
    http_status = 503


class PredictionError(PredictorError):
    """예측 중 실패."""
    http_status = 500


# ────────────────────────── 검증 ──────────────────────────
RANGES = {
    "price_krw": (0, 1_000_000),
    "review_count": (0, 10_000_000),
    "positive_ratio": (0.0, 1.0),
    "metacritic_score": (0, 100),
    "sale_count_1y": (0, 365),
    "dlc_count": (0, 1000),
    "max_hist_discount": (0, 90),
    "mean_hist_discount": (0, 90),
    "days_since_last_sale": (0, 20000),
}


def validate(raw: dict, stats: dict) -> list:
    """입력 검증. 오류는 예외, 경고는 리스트로 반환."""
    if not isinstance(raw, dict):
        raise InputValidationError(f"dict 가 필요합니다 (받은 타입: {type(raw).__name__})")

    # ① 필수 키
    missing = [k for k in REQUIRED if raw.get(k) is None]
    if missing:
        raise InputValidationError(f"필수 항목 누락: {missing}")

    # ② 타입 · 범위
    for key, (lo, hi) in RANGES.items():
        v = raw.get(key)
        if v is None or (isinstance(v, float) and np.isnan(v)):
            continue
        try:
            v = float(v)
        except (TypeError, ValueError):
            raise InputValidationError(f"{key} 는 숫자여야 합니다 (받은 값: {v!r})")
        if not (lo <= v <= hi):
            raise InputValidationError(f"{key} 범위 초과: {v} (허용 {lo}~{hi})")

    # ③ 날짜
    try:
        rel = pd.Timestamp(raw["release_date"])
    except Exception:
        raise InputValidationError(
            f"release_date 형식 오류: {raw['release_date']!r} (예: '2018-04-24')")
    if rel > pd.Timestamp.now() + pd.Timedelta(days=365 * 3):
        raise InputValidationError(f"release_date 가 너무 미래입니다: {rel.date()}")

    # ④ 리스트 항목
    for key in ["genres", "platforms", "features"]:
        v = raw.get(key)
        if v is not None and not isinstance(v, (list, tuple)):
            raise InputValidationError(f"{key} 는 리스트여야 합니다 (받은 타입: {type(v).__name__})")

    # ⑤ 분포 검증 — 경고만
    warns = []
    for key, st in stats.items():
        v = raw.get(key)
        if v is None or (isinstance(v, float) and np.isnan(v)):
            if key not in DEFAULTS:
                continue
            warns.append(f"{key} 미입력 → 기본값 {DEFAULTS.get(key)} 사용")
            continue
        v = float(v)
        if v < st["p01"] or v > st["p99"]:
            warns.append(
                f"{key}={v:g} 가 학습 분포(1~99%: {st['p01']:g}~{st['p99']:g}) 밖")
    return warns


# ────────────────────────── 예측기 ──────────────────────────
class Predictor:
    def __init__(self, bundle_path=None):
        path = Path(bundle_path or BUNDLE_PATH)
        if not path.exists():
            raise ModelNotLoadedError(f"모델 파일이 없습니다: {path}")
        try:
            b = joblib.load(path)
        except Exception as e:
            raise ModelNotLoadedError(f"모델 로드 실패: {e}") from e

        self.model = b["model"]
        self.meta = b["meta"]
        self.stats = b["train_stats"]
        self.cols = self.meta["feature_order"]
        self.steps = np.array(self.meta["steam_discount_steps"], dtype=float)
        self.limits = self.meta["usage_limits"]
        self.seg_mae = self.meta["segment_mae"]

    # ── 신뢰도 (Day 131 취약 구간 반영) ──
    def _confidence(self, pred, raw, warns):
        reasons = []
        lo, hi = self.limits["reliable_range"]

        if pred > self.limits["unreliable_above"]:
            level = "낮음"
            reasons.append(
                f"예측 {pred:.0f}% 는 대폭 할인 구간 — 이 구간 MAE {self.seg_mae['76~90%']:.1f}%p")
        elif pred < 1:
            level = "낮음"
            reasons.append(f"무할인 예측은 별도 분류 모델이 필요 (MAE {self.seg_mae['0%']:.1f}%p)")
        elif lo <= pred <= hi:
            level = "높음"
        else:
            level = "보통"
            reasons.append(f"예측 {pred:.0f}% 는 신뢰 구간 {lo}~{hi}% 밖")

        days = raw.get("_days_since_release", 9999)
        if days < self.limits["min_days_since_release"]:
            level = "낮음" if level != "낮음" else level
            reasons.append(f"출시 {days}일 — 할인 이력이 없어 신뢰도 낮음")

        rc = float(raw.get("review_count") or 0)
        if rc < self.limits["min_review_count"]:
            level = "보통" if level == "높음" else level
            reasons.append(f"리뷰 {rc:.0f}건 — 인기도 신호 부족")

        if len(warns) >= 3:
            level = "보통" if level == "높음" else level
            reasons.append(f"입력 경고 {len(warns)}건")
        return level, reasons

    def _expected_error(self, pred):
        edges = [(0, 1, "0%"), (1, 15, "1~15%"), (15, 30, "16~30%"),
                 (30, 50, "31~50%"), (50, 75, "51~75%"), (75, 101, "76~90%")]
        for lo, hi, key in edges:
            if lo <= pred < hi:
                return self.seg_mae[key], key
        return self.meta["performance"]["test_mae"], "전체"

    def predict(self, raw: dict, as_of=None, round_to_step=True) -> dict:
        """원시 dict 하나 → 예측 결과 dict."""
        warns = validate(raw, self.stats)
        as_of = pd.Timestamp(as_of) if as_of is not None else pd.Timestamp.now()

        try:
            X = derive(raw, as_of=as_of)
        except Exception as e:
            raise PredictionError(f"특성 생성 실패: {e}") from e

        missing_cols = [c for c in self.cols if c not in X.columns]
        if missing_cols:
            raise PredictionError(f"특성 누락: {missing_cols[:5]}"
                                  f"{' 외 ' + str(len(missing_cols)-5) + '개' if len(missing_cols) > 5 else ''}")

        try:
            raw_pred = float(self.model.predict(X[self.cols])[0])
        except Exception as e:
            raise PredictionError(f"예측 실패: {e}") from e

        if not np.isfinite(raw_pred):
            raise PredictionError(f"예측값이 유효하지 않습니다: {raw_pred}")

        pred = float(np.clip(raw_pred, 0, 90))
        stepped = float(self.steps[np.argmin(np.abs(self.steps - pred))])
        final = stepped if round_to_step else pred

        raw_aug = {**raw, "_days_since_release": int(X["days_since_release"].iloc[0])}
        level, reasons = self._confidence(pred, raw_aug, warns)
        err, seg = self._expected_error(pred)
        price = float(raw["price_krw"])

        return {
            "discount_percent": round(final, 1),
            "discount_percent_raw": round(pred, 2),
            "original_price": int(price),
            "discounted_price": int(round(price * (1 - final / 100))),
            "saving": int(round(price * final / 100)),
            "confidence": level,
            "confidence_reasons": reasons,
            "expected_error": f"±{err:.1f}%p",
            "error_segment": seg,
            "warnings": warns,
            "as_of": str(as_of.date()),
            "model_version": self.meta["model_version"],
        }

    def predict_batch(self, rows, as_of=None, round_to_step=True) -> list:
        """여러 건. 개별 실패는 error 항목으로 담아 계속 진행합니다."""
        out = []
        for i, r in enumerate(rows):
            try:
                out.append({"index": i, **self.predict(r, as_of, round_to_step)})
            except PredictorError as e:
                out.append({"index": i, "error": str(e),
                            "error_type": type(e).__name__,
                            "http_status": e.http_status})
        return out

    def info(self) -> dict:
        """모델 카드 요약."""
        return {
            "model_version": self.meta["model_version"],
            "algorithm": self.meta["algorithm"],
            "trained_at": self.meta["created_at"],
            "n_train": self.meta["n_train"],
            "n_features": self.meta["n_features"],
            "performance": self.meta["performance"],
            "usage_limits": self.meta["usage_limits"],
            "versions": self.meta["versions"],
        }
'''
```

```python
BAR = "─" * 62


def render(res: dict) -> str:
    mark = {"높음": "●", "보통": "◐", "낮음": "○"}[res["confidence"]]
    lines = [
        BAR,
        f"  예상 할인율   {res['discount_percent']:>5.0f}%"

    except PredictorError as e:
        print(f"[{type(e).__name__}] {e}", file=sys.stderr)
        return 1 if e.http_status == 400 else 2

    print(json.dumps(res, ensure_ascii=False, indent=2) if a.json else render(res))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## ⑤ 자주 하는 실수

### ★ 파생 특성을 서빙 코드에 다시 씀

```
학습:  np.log1p(price)
서빙:  np.log(price)      ← 조용히 틀림
```

**`features.py` 하나를 양쪽에서 import 하세요.**
**Step 2의 일치 검증을 반드시 통과시키세요.**

### 기준일(`as_of`)을 하드코딩

```python
days = (datetime.now() - release).days     # ✗
def derive(raw, as_of): ...                # ✓
```

**`as_of` 를 안 받으면 학습 재현이 불가능합니다.**

### 특성 순서를 저장 안 함

```python
X = pd.DataFrame([out])          # dict 순서에 의존 ✗
X[self.cols]                     # 저장된 순서 사용 ✓
```

### 예측 실패 시 평균값 반환

```python
try:
    return model.predict(X)
except:
    return 20.0                  # ★ 사용자는 이게 예측인 줄 압니다
```

**실패는 실패로 알려야 합니다.**

### 예외를 한 종류로만

```python
raise Exception("에러")          # ✗
raise InputValidationError(...)  # ✓ HTTP 400 매핑 가능
```

### 요청마다 모델 로드

```python
def predict(raw):
    model = joblib.load(...)     # ★ 284ms 낭비
```

**기동 시 1회 로드하고 재사용하세요.**

### 사용 제한을 문서에만

```
README에 "75% 이상은 부정확" ← 아무도 안 읽음
반환값에 confidence: "낮음"  ← 무시할 수 없음
```

### 버전을 기록 안 함

```
sklearn 1.3에서 저장 → 1.7에서 로드 → 경고 또는 실패
```

### 테스트가 "돌아가는지"만 확인

```python
def test_predict():
    assert p.predict(VALID) is not None      # ✗ 너무 약함
```

**학습 예측과 일치하는지까지 검증하세요.**

### 신뢰도를 예측값만으로 판단

```
예측 30% → "높음"
그런데 출시 5일 된 게임입니다
```

**입력 조건도 함께 봐야 합니다.**

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 저장 형식 | sklearn → **`joblib`**. 신뢰 못 할 파일은 로드 금지 |
| 번들 내용 | 모델 + **특성 순서** + 통계 + 버전 + **사용 제한** |
| ★ 최대 위험 | **학습-서빙 왜곡** (training-serving skew) |
| 해결책 | **`features.py` 하나를 양쪽에서 import** |
| 검증 방법 | 원시 데이터 재계산 → **최대 차이 < 1e-6** |
| 기준일 | **`as_of` 를 인자로** 받아야 재현 가능 |
| 입력 계층 | 필수 / 선택(기본값) / 파생 |
| 범위 vs 분포 | 범위 밖 = **거부**, 분포 밖 = **경고** |
| 예외 계층 | `InputValidation`(400) · `ModelNotLoaded`(503) · `Prediction`(500) |
| 실패 처리 | **추측값 반환 금지** |
| 신뢰도 | [Day 131](day-131.md) 취약 구간을 **코드로 강제** |
| 반환값 | 숫자만 X → **신뢰도 · 예상 오차 · 경고** 포함 |
| 단계 반올림 | 스팀 실제 단계로. **원시값도 함께 반환** |
| 배치 | 한 건 실패해도 **나머지 계속** |
| 성능 | 로드 284ms(1회) · 단건 **8.4ms** |
