## ③ 개념 설명

### 딕셔너리 만들기

중괄호 `{ }` 안에 `키: 값` 쌍을 콤마로 나열합니다.

```python
person = {
    "name": "홍길동",
    "age": 25,
    "city": "서울",
}

empty = {}                 # 빈 딕셔너리
```

```
      키          값
    ┌────────┬──────────┐
    │ "name" │ "홍길동"  │
    │ "age"  │    25    │
    │ "city" │  "서울"   │
    └────────┴──────────┘
```

| 용어 | 뜻 | 규칙 |
|---|---|---|
| **키(key)** | 이름표 | **중복 불가**, 변하지 않는 값만(문자열·숫자·튜플) |
| **값(value)** | 실제 데이터 | 무엇이든 가능 (리스트·딕셔너리도 됨) |

### 값 꺼내기

```python
person = {"name": "홍길동", "age": 25}

print(person["name"])      # 홍길동
print(person["age"])       # 25
print(person["email"])     # KeyError!
```

```
KeyError: 'email'
```

**없는 키에 접근하면 프로그램이 죽습니다.** 그래서 `get()` 을 씁니다.

```python
print(person.get("email"))              # None  (에러 안 남)
print(person.get("email", "없음"))       # 없음   (기본값 지정)
```

| 방식 | 없는 키일 때 | 언제 쓰나 |
|---|---|---|
| `d["key"]` | `KeyError` 발생 | 반드시 있어야 하는 키 |
| `d.get("key")` | `None` 반환 | 없을 수도 있는 키 |
| `d.get("key", 기본값)` | 기본값 반환 | 없으면 대체값을 쓰고 싶을 때 |

**있는지 먼저 확인하기**

```python
if "email" in person:
    print(person["email"])
else:
    print("이메일이 없습니다")
```

> `in` 은 **키**를 검사합니다. 값을 검사하려면 `in person.values()` 를 씁니다.

### 추가·수정·삭제

```python
person = {"name": "홍길동", "age": 25}

person["email"] = "hong@test.com"      # 없으면 추가
person["age"] = 26                     # 있으면 수정
print(person)
# {'name': '홍길동', 'age': 26, 'email': 'hong@test.com'}

del person["email"]                    # 삭제
removed = person.pop("age")            # 삭제하며 값을 꺼냄
print(removed, person)                 # 26 {'name': '홍길동'}

person.update({"city": "서울", "age": 30})   # 여러 개 한 번에
print(person)
# {'name': '홍길동', 'city': '서울', 'age': 30}
```

> **추가와 수정이 같은 문법**입니다. 키가 있으면 덮어쓰고, 없으면 새로 만듭니다.
> 이것이 편리하기도 하고 위험하기도 합니다. 오타 난 키를 쓰면 에러 없이 새 항목이 생겨 버립니다.

### 순회하기 — keys / values / items

```python
scores = {"국어": 85, "영어": 92, "수학": 78}

# 키만
for subject in scores:               # 기본은 키를 꺼냄
    print(subject, end=" ")
print()

# 키만 (명시적)
for subject in scores.keys():
    print(subject, end=" ")
print()

# 값만
for score in scores.values():
    print(score, end=" ")
print()

# 키와 값 함께 (가장 많이 씀)
for subject, score in scores.items():
    print(f"{subject}: {score}점")
```

실행 결과:

```
국어 영어 수학
국어 영어 수학
85 92 78
국어: 85점
영어: 92점
수학: 78점
```

> **`.items()` 가 딕셔너리 순회의 기본**입니다. `for 키, 값 in 딕셔너리.items():` 를 외워 두세요.

### 딕셔너리에 쓰는 함수

```python
scores = {"국어": 85, "영어": 92, "수학": 78}

print(len(scores))                   # 3      항목 개수
print(sum(scores.values()))          # 255    값의 합
print(max(scores.values()))          # 92     최댓값
print(list(scores.keys()))           # ['국어', '영어', '수학']
```

**값이 가장 큰 키 찾기**

```python
best = max(scores, key=scores.get)
print(f"최고 점수 과목: {best} ({scores[best]}점)")     # 영어 (92점)
```

> `max(대상, key=함수)` 는 "함수 결과가 가장 큰 것"을 찾습니다.
> `scores.get` 은 각 키의 값을 돌려주므로, 결과적으로 "값이 가장 큰 키"를 찾게 됩니다.

**값 기준으로 정렬**

```python
sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)
print(sorted_items)
# [('영어', 92), ('국어', 85), ('수학', 78)]
```

> `.items()` 는 `(키, 값)` 튜플의 모음이므로, `x[1]` 은 값을 뜻합니다.
> `lambda` 는 [Day 009](day-009.md)에서 배웠습니다.

### 중첩 구조 — 딕셔너리 안의 딕셔너리·리스트

```python
player = {
    "name": "홍길동",
    "level": 5,
    "stats": {                          # 딕셔너리 안의 딕셔너리
        "hp": 120,
        "attack": 18,
        "defense": 6,
    },
    "inventory": ["회복약", "검", "방패"],   # 딕셔너리 안의 리스트
}

print(player["name"])                   # 홍길동
print(player["stats"]["hp"])            # 120
print(player["inventory"][0])           # 회복약
print(len(player["inventory"]))         # 3

# 수정
player["stats"]["hp"] -= 30
player["inventory"].append("포션")

print(player["stats"]["hp"])            # 90
print(player["inventory"])              # ['회복약', '검', '방패', '포션']
```

**딕셔너리 리스트 — 표 데이터의 표준 형태**

```python
students = [
    {"name": "홍길동", "score": 85},
    {"name": "김철수", "score": 92},
    {"name": "이영희", "score": 78},
]

for s in students:
    print(f"{s['name']}: {s['score']}점")

# 점수 순 정렬
students.sort(key=lambda s: s["score"], reverse=True)
print(students[0]["name"])             # 김철수
```

> ⚠️ f-string 안에서 딕셔너리 키에 접근할 때는 **따옴표 종류를 다르게** 써야 합니다.
> `f"{s['name']}"` ✅ / `f"{s["name"]}"` ❌ (파이썬 3.12 미만에서 SyntaxError)

> **이 "딕셔너리들의 리스트" 형태가 매우 중요합니다.**
> JSON 파일, API 응답, CSV 한 줄 한 줄 — 전부 이 구조입니다.
> 대단원 02에서 `pd.DataFrame(students)` 한 줄로 표가 만들어집니다.

### 딕셔너리 컴프리헨션

```python
{키_식: 값_식 for 변수 in 대상}
```

```python
# 제곱표
squares = {i: i**2 for i in range(1, 6)}
print(squares)                # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 키와 값 뒤집기
scores = {"국어": 85, "영어": 92}
flipped = {v: k for k, v in scores.items()}
print(flipped)                # {85: '국어', 92: '영어'}

# 조건 필터링
high = {k: v for k, v in scores.items() if v >= 90}
print(high)                   # {'영어': 92}
```

### 값을 세는 패턴

가장 자주 쓰는 딕셔너리 활용법입니다.

```python
text = "banana"
counter = {}

for ch in text:
    if ch in counter:
        counter[ch] += 1
    else:
        counter[ch] = 1

print(counter)                # {'b': 1, 'a': 3, 'n': 2}
```

`get()` 을 쓰면 더 짧습니다.

```python
counter = {}
for ch in text:
    counter[ch] = counter.get(ch, 0) + 1
```

> `counter.get(ch, 0)` 은 "있으면 그 값, 없으면 0" 이므로 `if` 가 필요 없습니다.
> 이 관용구는 데이터 분석에서 계속 나옵니다. 확실히 익혀 두세요.

### Step 2. 단어 빈도 세기

```python
def count_words(text):
    """공백으로 나눈 단어들의 등장 횟수를 딕셔너리로 반환합니다."""
    counter = {}
    for word in text.lower().split():
        word = word.strip(".,!?")           # 문장부호 제거
        if not word:
            continue
        counter[word] = counter.get(word, 0) + 1
    return counter


def show_top(counter, n=5):
    """상위 n개를 출력합니다."""
    ranked = sorted(counter.items(), key=lambda x: x[1], reverse=True)

    print(f"\n[상위 {n}개 단어]")
    for i, (word, count) in enumerate(ranked[:n], start=1):
        bar = "▇" * count
        print(f"  {i}. {word:<10} {bar} {count}회")


text = """
파이썬은 배우기 쉽습니다. 파이썬은 강력합니다.
데이터 분석에도 파이썬을 씁니다. 인공지능에도 파이썬이 쓰입니다.
배우기 쉬운 언어가 강력하기까지 하니 좋습니다.
"""

counter = count_words(text)
print(f"전체 단어 수(중복 포함): {sum(counter.values())}개")
print(f"고유 단어 수:           {len(counter)}개")
show_top(counter, 5)
```

실행 결과:

```
전체 단어 수(중복 포함): 17개
고유 단어 수:           15개

[상위 5개 단어]
  1. 파이썬은     ▇▇ 2회
  2. 배우기      ▇▇ 2회
  3. 쉽습니다     ▇ 1회
  4. 강력합니다    ▇ 1회
  5. 데이터      ▇ 1회
```

> `enumerate(ranked[:n], start=1)` 에서 각 요소가 `(word, count)` 튜플이므로,
> `for i, (word, count) in ...` 처럼 **괄호로 묶어 언패킹**합니다.

### Step 3. 아이템 인벤토리

```python
inventory = {}


def add_item(inv, name, count=1):
    """아이템을 추가합니다."""
    inv[name] = inv.get(name, 0) + count
    print(f"→ {name} {count}개 획득! (보유 {inv[name]}개)")


def use_item(inv, name, count=1):
    """아이템을 사용합니다. 성공하면 True."""
    if name not in inv:
        print(f"→ {name}을(를) 가지고 있지 않습니다.")
        return False

    if inv[name] < count:
        print(f"→ {name}이(가) 부족합니다. (보유 {inv[name]}개)")
        return False

    inv[name] -= count

    if inv[name] == 0:
        del inv[name]                        # 0개면 목록에서 제거
        print(f"→ {name} {count}개 사용. (전부 소진)")
    else:
        print(f"→ {name} {count}개 사용. (남은 {inv[name]}개)")

    return True


def show_inventory(inv):
    """인벤토리를 출력합니다."""
    print("\n" + "=" * 26)
    print("        인벤토리")
    print("=" * 26)

    if not inv:
        print("  (비어 있음)")
    else:
        for name, count in sorted(inv.items()):
            print(f"  {name:<12} x {count}")

    print("=" * 26)
    print(f"  총 {sum(inv.values())}개 / {len(inv)}종류")


# ── 실행 ──
add_item(inventory, "회복약", 3)
add_item(inventory, "검")
add_item(inventory, "회복약", 2)
show_inventory(inventory)

use_item(inventory, "회복약", 4)
use_item(inventory, "방패")
use_item(inventory, "검")
show_inventory(inventory)
```

실행 결과:

```
→ 회복약 3개 획득! (보유 3개)
→ 검 1개 획득! (보유 1개)
→ 회복약 2개 획득! (보유 5개)

==========================
        인벤토리
==========================
  검            x 1
  회복약          x 5
==========================
  총 6개 / 2종류
→ 회복약 4개 사용. (남은 1개)
→ 방패을(를) 가지고 있지 않습니다.
→ 검 1개 사용. (전부 소진)

==========================
        인벤토리
==========================
  회복약          x 1
==========================
  총 1개 / 1종류
```

> **`if not inv:`** — 빈 딕셔너리는 거짓으로 취급됩니다. `len(inv) == 0` 과 같지만 더 파이썬답습니다.
> `del inv[name]` 로 0개인 항목을 지우는 것이 핵심입니다. 안 그러면 `{"검": 0}` 같은 쓰레기가 쌓입니다.

### Step 4. 몬스터 도감 (중첩 딕셔너리)

```python
monsters = {
    "슬라임": {"hp": 30, "attack": 5, "exp": 3, "drop": ["젤리"]},
    "고블린": {"hp": 80, "attack": 12, "exp": 15, "drop": ["가죽", "동전"]},
    "오크":   {"hp": 150, "attack": 20, "exp": 40, "drop": ["곤봉", "가죽", "동전"]},
    "드래곤": {"hp": 500, "attack": 60, "exp": 300, "drop": ["비늘", "보석", "황금"]},
}


def show_monster(name, data):
    """몬스터 한 마리의 정보를 출력합니다."""
    print(f"\n  【 {name} 】")
    print(f"   체력 {data['hp']:>4}   공격 {data['attack']:>3}   경험치 {data['exp']:>4}")
    print(f"   드롭: {', '.join(data['drop'])}")


def find_by_hp(monsters, min_hp):
    """체력이 min_hp 이상인 몬스터 이름 목록을 반환합니다."""
    return [name for name, data in monsters.items() if data["hp"] >= min_hp]


def find_by_drop(monsters, item):
    """특정 아이템을 드롭하는 몬스터 목록을 반환합니다."""
    return [name for name, data in monsters.items() if item in data["drop"]]


def get_total_exp(monsters):
    """전체 몬스터의 경험치 합계를 반환합니다."""
    return sum(data["exp"] for data in monsters.values())


# ── 실행 ──
print("=" * 42)
print("               몬스터 도감")
print("=" * 42)

for name, data in monsters.items():
    show_monster(name, data)

print("\n" + "=" * 42)
print(f"등록 몬스터:      {len(monsters)}종")
print(f"전체 경험치:      {get_total_exp(monsters)}")
print(f"체력 100 이상:    {find_by_hp(monsters, 100)}")
```

### Step 5. 학생 성적 관리 (오늘의 종합 예제)

내일 파일 저장 기능을 붙일 프로그램의 뼈대입니다.

```python
students = {}


def add_student(db, name, korean, english, math):
    """학생을 추가합니다."""
    if name in db:
        print(f"→ '{name}' 은(는) 이미 등록되어 있습니다. 덮어씁니다.")

    db[name] = {
        "국어": korean,
        "영어": english,
        "수학": math,
    }
    print(f"→ '{name}' 등록 완료.")


def get_summary(scores):
    """점수 딕셔너리를 받아 (총점, 평균, 학점)을 반환합니다."""
    total = sum(scores.values())
    average = total / len(scores)

    if average >= 90:
        grade = "A"
    elif average >= 80:
        grade = "B"
    elif average >= 70:
        grade = "C"
    elif average >= 60:
        grade = "D"
    else:
        grade = "F"

    return total, average, grade


def show_all(db):
    """전체 성적표를 출력합니다."""
    print("\n" + "=" * 54)
    print(f"{'이름':<10}{'국어':>7}{'영어':>7}{'수학':>7}{'총점':>8}{'평균':>8}{'학점':>5}")
    print("-" * 54)

    if not db:
        print("  등록된 학생이 없습니다.")
        print("=" * 54)
        return

    # 평균 기준 내림차순 정렬
    ranked = sorted(db.items(),
                    key=lambda x: sum(x[1].values()),
                    reverse=True)

    for name, scores in ranked:
        total, average, grade = get_summary(scores)
        print(f"{name:<10}{scores['국어']:>7}{scores['영어']:>7}{scores['수학']:>7}"
              f"{total:>8}{average:>8.1f}{grade:>5}")

    print("-" * 54)

    # 과목별 평균
    subject_avg = {}
    for subject in ["국어", "영어", "수학"]:
        subject_avg[subject] = sum(s[subject] for s in db.values()) / len(db)

    line = "   ".join(f"{k} {v:.1f}" for k, v in subject_avg.items())
    print(f"과목 평균: {line}")
    print("=" * 54)


def search(db, name):
    """학생을 조회합니다."""
    scores = db.get(name)

    if scores is None:
        print(f"→ '{name}' 학생을 찾을 수 없습니다.")
        return

    total, average, grade = get_summary(scores)
    print(f"\n  【 {name} 】")
    for subject, score in scores.items():
        print(f"   {subject}: {score}점")
    print(f"   총점 {total} / 평균 {average:.1f} / {grade}학점")


# ── 실행 ──
add_student(students, "홍길동", 85, 90, 78)
add_student(students, "김철수", 92, 88, 95)
add_student(students, "이영희", 70, 75, 82)
add_student(students, "박민수", 60, 55, 68)

show_all(students)
search(students, "김철수")
search(students, "최지우")
```

실행 결과:

```

→ '김철수' 등록 완료.
→ '이영희' 등록 완료.
→ '박민수' 등록 완료.

======================================================
이름            국어     영어     수학      총점      평균   학점
------------------------------------------------------
김철수            92     88     95     275    91.7    A
홍길동            85     90     78     253    84.3    B
이영희            70     75     82     227    75.7    C
박민수            60     55     68     183    61.0    D
------------------------------------------------------
과목 평균: 국어 76.8   영어 77.0   수학 80.8
======================================================

  【 김철수 】
   국어: 92점
   영어: 88점
   수학: 95점
   총점 275 / 평균 91.7 / A학점

```

> **눈여겨볼 점 4가지**
> - 전체 구조는 `{이름: {과목: 점수}}` 인 **중첩 딕셔너리**입니다. 이름으로 바로 찾을 수 있어 검색이 빠릅니다.
> - `sorted(db.items(), key=lambda x: sum(x[1].values()), reverse=True)` — `x` 는 `(이름, 점수딕셔너리)` 튜플이므로 `x[1]` 이 점수, `sum(x[1].values())` 가 총점입니다.
> - `db.get(name)` 을 쓰고 `if scores is None:` 으로 검사해, 없는 학생을 조회해도 프로그램이 죽지 않습니다.
> - `sum(s[subject] for s in db.values())` — 모든 학생의 특정 과목 점수를 모아 더합니다. 대단원 02의 `groupby` 가 하는 일을 손으로 하는 셈입니다.

## ⑤ 자주 하는 실수

### `KeyError` — 없는 키에 접근

```python
person = {"name": "홍길동"}
print(person["age"])
```

```
KeyError: 'age'
```

**해결** — `get()` 을 쓰거나 `in` 으로 먼저 확인합니다.

```python
print(person.get("age", 0))
if "age" in person:
    print(person["age"])
```

### 키 오타를 냈는데 에러가 안 남 (더 위험)

```python
player = {"hp": 100}
player["hpp"] = 80          # 오타! 그런데 에러가 안 남
print(player)               # {'hp': 100, 'hpp': 80}
```

**원인** — 딕셔너리는 없는 키에 대입하면 **새 항목을 만듭니다.**
**해결** — 키를 상수로 빼거나, 클래스([Day 016](day-016.md))를 쓰세요. 클래스는 없는 속성에 대입해도 자동완성이 잡아 줍니다.

### `TypeError: unhashable type: 'list'` — 리스트를 키로 씀

```python
d = {}
d[[1, 2]] = "값"
```

```
TypeError: unhashable type: 'list'
```

**원인** — 키는 **변하지 않는 값**이어야 합니다. 리스트는 변할 수 있어 안 됩니다.
**해결** — 튜플을 쓰세요. `d[(1, 2)] = "값"`

### f-string 안에서 같은 따옴표를 씀

```python
s = {"name": "홍길동"}
print(f"{s["name"]}")
```

파이썬 3.11 이하:

```
SyntaxError: f-string: unmatched '['
```

**해결** — 바깥과 안쪽 따옴표를 다르게 씁니다.

```python
print(f"{s['name']}")       # 바깥 " / 안쪽 '
```

> 파이썬 3.12부터는 허용되지만, 호환성을 위해 다르게 쓰는 것이 안전합니다.

### 순회 중에 딕셔너리를 수정

```python
scores = {"국어": 85, "영어": 55, "수학": 92}

for subject in scores:
    if scores[subject] < 60:
        del scores[subject]
```

```
RuntimeError: dictionary changed size during iteration
```

**원인** — 리스트와 마찬가지로, 순회 중 크기를 바꾸면 안 됩니다.
**해결** — 키 목록을 복사하거나, 새 딕셔너리를 만듭니다.

```python
# 방법 1: 키 목록을 복사
for subject in list(scores.keys()):
    if scores[subject] < 60:
        del scores[subject]

# 방법 2: 새 딕셔너리 (권장)
scores = {k: v for k, v in scores.items() if v >= 60}
```

> 리스트는 조용히 잘못된 결과를 내지만, 딕셔너리는 **에러를 내 줍니다.** 그 점에서는 더 친절합니다.

### 중첩 딕셔너리 복사 함정

```python
default = {"hp": 100, "stats": {"attack": 10}}

player1 = default.copy()
player1["stats"]["attack"] = 999

print(default["stats"]["attack"])      # 999  ← 원본도 바뀜!
```

**원인** — `.copy()` 는 **얕은 복사(shallow copy)** 입니다. 바깥 딕셔너리만 새로 만들고, 안쪽 딕셔너리는 공유합니다.
**해결** — 깊은 복사를 씁니다.

```python
import copy
player1 = copy.deepcopy(default)
```

> Day 011의 리스트 복사 함정이 중첩 구조에서 한 단계 더 깊어진 형태입니다.
> **"중첩 구조는 `.copy()` 로 부족하다"** 를 기억하세요.

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
d = {"a": 1, "b": 2}

d["c"] = d.get("c", 0) + 10
d["a"] = d.get("a", 0) + 10

print(d)
print(len(d), sum(d.values()))
```

<details>
<summary>답 보기</summary>

```
{'a': 11, 'b': 2, 'c': 10}
3 23
```

- `d.get("c", 0)` → `"c"` 가 없으므로 `0`, 거기에 10을 더해 `d["c"] = 10` (새로 생성)
- `d.get("a", 0)` → `"a"` 가 있으므로 `1`, 거기에 10을 더해 `d["a"] = 11` (수정)

**핵심** — `d[k] = d.get(k, 0) + n` 은 "있으면 더하고 없으면 새로 만든다"를 한 줄로 처리하는 관용구입니다.
누적 집계에서 계속 씁니다.
</details>

**2.** 학생 성적 딕셔너리를 받아, **각 과목의 최고 점수를 받은 학생 이름**을 담은 딕셔너리를 반환하는 함수를 만드세요.

```python
students = {
    "홍길동": {"국어": 85, "영어": 90, "수학": 78},
    "김철수": {"국어": 92, "영어": 88, "수학": 95},
    "이영희": {"국어": 70, "영어": 95, "수학": 82},
}
# 기대 결과: {'국어': '김철수', '영어': '이영희', '수학': '김철수'}
```

<details>
<summary>답 보기</summary>

```python
def get_subject_top(students):
    """과목별 1등 학생 이름을 딕셔너리로 반환합니다."""
    if not students:
        return {}

    # 첫 학생의 과목 목록을 기준으로 삼습니다
    subjects = list(next(iter(students.values())).keys())

    result = {}
    for subject in subjects:
        best_name = None
        best_score = -1

        for name, scores in students.items():
            score = scores.get(subject, 0)
            if score > best_score:
                best_score = score
                best_name = name

        result[subject] = best_name

    return result


print(get_subject_top(students))
```

실행 결과:

```
{'국어': '김철수', '영어': '이영희', '수학': '김철수'}
```

**더 짧은 방법 (max + lambda)**

```python
def get_subject_top(students):
    if not students:
        return {}
    subjects = list(next(iter(students.values())).keys())
    return {
        sub: max(students, key=lambda n: students[n].get(sub, 0))
        for sub in subjects
    }
```

**포인트 3가지**
- `next(iter(딕셔너리.values()))` 는 "첫 번째 값"을 꺼내는 방법입니다. 과목 목록을 알아내는 데 씁니다.
- `scores.get(subject, 0)` 을 써서, 어떤 학생이 그 과목을 안 들었어도 프로그램이 죽지 않게 합니다.
- `best_score = -1` 로 시작하는 이유는, 0점을 받은 학생도 후보가 되게 하기 위해서입니다.
</details>

**3.** 아래 코드가 왜 두 캐릭터의 체력이 함께 줄어드는지 설명하고 고치세요.

```python
DEFAULT_STATS = {"hp": 100, "mp": 50, "items": ["회복약"]}

player1 = DEFAULT_STATS.copy()
player2 = DEFAULT_STATS.copy()

player1["hp"] -= 30
player1["items"].append("검")

print(player1)
print(player2)
```

<details>
<summary>답 보기</summary>

**실제 출력**

```
{'hp': 70, 'mp': 50, 'items': ['회복약', '검']}
{'hp': 100, 'mp': 50, 'items': ['회복약', '검']}
```

**체력(`hp`)은 정상**입니다. 문제는 **아이템 목록**입니다. `player2` 도 검을 갖게 됐습니다.

**원인** — `.copy()` 는 **얕은 복사**입니다.

```
DEFAULT_STATS ─┐
player1       ─┼─→ 각자 다른 딕셔너리 (hp, mp 는 안전)
player2       ─┘
                      │
                      └─→ items 리스트는 셋이 공유!
```

`hp` 는 숫자라서 `player1["hp"] -= 30` 이 새 값을 대입하므로 안전합니다.
하지만 `items` 는 리스트이고, `.append()` 는 **그 리스트 자체를 수정**하므로 공유된 하나가 바뀝니다.

**해결 — 깊은 복사**

```python
import copy

DEFAULT_STATS = {"hp": 100, "mp": 50, "items": ["회복약"]}

player1 = copy.deepcopy(DEFAULT_STATS)
player2 = copy.deepcopy(DEFAULT_STATS)

player1["hp"] -= 30
player1["items"].append("검")

print(player1)      # {'hp': 70, 'mp': 50, 'items': ['회복약', '검']}
print(player2)      # {'hp': 100, 'mp': 50, 'items': ['회복약']}
```

**해결 — 함수로 매번 새로 만들기 (더 권장)**

```python
def create_player():
    """새 캐릭터 데이터를 만들어 반환합니다."""
    return {"hp": 100, "mp": 50, "items": ["회복약"]}

player1 = create_player()
player2 = create_player()
```

> **교훈** — 중첩 구조를 복사할 때는 `.copy()` 로 부족합니다.
> `copy.deepcopy()` 를 쓰거나, **아예 함수로 매번 새로 만드는 편**이 안전하고 읽기도 좋습니다.
> [Day 016](day-016.md)에서 클래스를 배우면 `Player()` 라고 쓰는 것만으로 이 문제가 해결됩니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 생성 | `{"키": 값}` · 빈 딕셔너리 `{}` |
| 꺼내기 | `d["키"]` (없으면 KeyError) · `d.get("키", 기본값)` (안전) |
| 추가/수정 | `d["키"] = 값` — **같은 문법** |
| 삭제 | `del d["키"]` · `d.pop("키")` |
| 순회 | `for k, v in d.items():` ← **기본형** |
| 집계 | `sum(d.values())` · `max(d, key=d.get)` |
| 누적 관용구 | `d[k] = d.get(k, 0) + 1` |
| 컴프리헨션 | `{k: v for k, v in d.items() if 조건}` |
| 키 규칙 | **중복 불가** · 변하지 않는 값만 (리스트 ❌, 튜플 ✅) |
| 복사 | 중첩 구조는 `copy.deepcopy()` 필요 |

**오늘 반드시 기억할 두 가지**
> ① 없을 수도 있는 키는 `d.get(키, 기본값)` 으로 접근하세요.
> ② `for 키, 값 in 딕셔너리.items():` 가 순회의 기본형입니다.
