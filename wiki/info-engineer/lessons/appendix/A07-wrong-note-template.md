# A7 · 학습자용 오답노트 양식

> [부록 목차](README.md) · 사용 시점: 1주차부터 **모든 평가·확인 문제**에 적용. [14강 진단 매트릭스](../05-exam-prep/lesson-14.md)의 원천 데이터입니다.

## 양식 (문항 1개당 1블록)

```
[날짜]        2026-__-__
[출처]        (예: 08강 중간평가 9번 / 4주차 형성평가 3번)
[영역]        C / Java / Python / SQL / DB이론 / SW공학 / 네트워크·보안·OS
[유형]        결과 예측 / 빈칸 / 오류 찾기 / 작성·해석 / 단답 / 계산
[문제 요약]   (한 줄 — 전체를 베끼지 않는다)
[내 답]       (틀린 그대로 적는다 — 지우지 않기)
[정답]
[틀린 이유]   개념 / 절차 / 형식  중 하나 표시 + 한 줄 설명
[핵심 개념]   (다음에 같은 유형을 푸는 데 필요한 규칙 한 줄)
[재풀이]      1차 __/__ (O/X) · 2차 __/__ (O/X)   ★=재풀이도 틀림
```

## 작성 규칙

1. **답이 아니라 이유를 기록한다** — "정답 3.5"가 아니라 "Python `/`는 정수끼리도 실수"를 남긴다.
2. 틀린 이유는 반드시 **개념/절차/형식** 중 하나로 분류한다 ([13강 Step 3](../05-exam-prep/lesson-13.md)) — 처방이 달라진다.
3. 코드 문항은 **추적표(또는 호출 트리·그림)를 다시 그려** 붙인다.
4. 재풀이는 최소 2회 — 2차까지 틀리면 ★를 붙이고 [A6 계획](A06-final-7days.md)의 D-3 오후로 보낸다.
5. 철자를 틀린 용어(영문 포함)는 하단 여백에 **3회 반복 기입**한다.

## 작성 예시

```
[날짜]        2026-08-27
[출처]        08강 중간평가 9번
[영역]        C
[유형]        결과 예측
[문제 요약]   int *p = a; p += 2; *p + *(p-1) 출력
[내 답]       12
[정답]        15
[틀린 이유]   절차 — p의 현재 위치를 그림 없이 암산, *(p-1)을 a[0]로 착각
[핵심 개념]   p += 2 후 p는 a[2]. *(p-1)은 "p 기준 한 칸 앞" = a[1]
[재풀이]      1차 09-02 (O) · 2차 09-09 (O)
```
