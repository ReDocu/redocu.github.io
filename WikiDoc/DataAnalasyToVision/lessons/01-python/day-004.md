이 레슨을 마치면 이렇게 할 수 있습니다.

- 들여쓰기로 코드의 묶음(블록)을 정확히 표현할 수 있다.
- 조건 여러 개를 논리 연산자로 묶고, 중첩 조건문을 작성할 수 있다.

---

## ② 왜 필요한가

지금까지 만든 프로그램은 **위에서 아래로 한 줄씩, 예외 없이** 실행됐습니다.
그런데 우리가 쓰는 모든 프로그램은 사실 끊임없이 판단을 합니다.

| 상황 | 판단 |
|---|---|
| 로그인 | 비밀번호가 맞으면 들여보내고, 틀리면 막는다 |
| 쇼핑몰 | 3만 원 이상이면 무료배송, 아니면 배송비 3천 원 |
| 게임 | 체력이 0 이하면 게임 오버 |
| BMI 계산기 | 25 이상이면 "과체중", 18.5 미만이면 "저체중" |

Day 002에서 만든 BMI 계산기는 숫자만 보여 줄 뿐 **"그래서 정상인가?"** 를 말해 주지 못했습니다.
오늘 그 마지막 조각을 채웁니다.

그리고 조건문은 앞으로 매일 씁니다. 내일 배울 반복문 안에서도, W05의 게임 충돌 판정에서도, 대단원 04의 이상치 제거에서도 조건문이 중심입니다.

## ③ 개념 설명

### if — 조건이 참일 때만 실행

```python
if 조건:
    실행할 코드
```

읽는 법: **"만약 조건이 참이면, 아래 코드를 실행하라"**

```python
age = 20

if age >= 19:
    print("성인입니다")
```

실행 결과:

```
성인입니다
```

`age` 가 `15` 였다면 아무것도 출력되지 않습니다. 조건이 거짓이라 블록을 건너뛰기 때문입니다.

**문법에서 놓치기 쉬운 두 가지**

1. 조건 뒤에 **콜론(`:`)** 을 반드시 붙입니다.
2. 실행할 코드는 **들여쓰기**를 합니다.

### 들여쓰기 — 파이썬에서는 문법입니다

다른 언어는 중괄호 `{ }` 로 묶음을 표시하지만, **파이썬은 들여쓰기로 묶음을 표시합니다.**
즉 들여쓰기가 틀리면 프로그램의 의미가 바뀌거나 아예 실행되지 않습니다.

```python
age = 15

if age >= 19:
    print("성인입니다")      # if 에 속함 → 조건이 참일 때만
print("확인 완료")            # if 밖 → 항상 실행
```

실행 결과:

```
확인 완료
```

> **규칙** — 들여쓰기는 **스페이스 4칸**을 씁니다. VS Code에서 `Tab` 키를 누르면 자동으로 4칸이 들어갑니다.
> 한 파일 안에서 스페이스와 탭을 섞어 쓰면 에러가 납니다. 섞지 마세요.

### if ~ else — 두 갈래로 나누기

```python
if 조건:
    조건이 참일 때
else:
    조건이 거짓일 때
```

```python
score = 55

if score >= 60:
    print("합격입니다")
else:
    print("불합격입니다")
```

실행 결과:

```
불합격입니다
```

> `else` 뒤에는 조건을 쓰지 않습니다. "그 외 나머지 전부"라는 뜻이기 때문입니다.

### if ~ elif ~ else — 여러 갈래로 나누기

**`elif`** 는 `else if` 의 줄임말입니다. 갈래가 셋 이상일 때 씁니다.

```python
score = 85

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("F학점")
```

실행 결과:

```
B학점
```

**동작 원리 — 위에서부터 순서대로 검사하고, 처음 참인 것 하나만 실행한 뒤 나머지는 건너뜁니다.**

```
score = 85

 ① score >= 90 ?  → False,  다음으로
 ② score >= 80 ?  → True!   "B학점" 출력하고 전체 종료
 ③ score >= 70 ?  → 검사조차 하지 않음
 ④ else          → 실행 안 됨
```

> ⚠️ **순서가 중요합니다.** 아래처럼 쓰면 모든 점수가 "C학점"이 됩니다.
> ```python
> if score >= 70:      # 85점도, 95점도 여기서 걸림
>     print("C학점")
> elif score >= 80:
>     print("B학점")    # 영원히 실행되지 않음
> ```
> 범위 조건은 **좁은 것(엄격한 것)부터** 씁니다.

### if 여러 개 vs elif — 결정적 차이

| 코드 | 동작 |
|---|---|
| `if` … `elif` … `elif` | **하나만** 실행 |
| `if` … `if` … `if` | 조건마다 **각각 검사**, 여러 개 실행될 수 있음 |

```python
score = 95

# elif — 하나만 실행됨
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
# 출력: A

# if 세 번 — 참인 것이 전부 실행됨
if score >= 90:
    print("A")
if score >= 80:
    print("B")
# 출력: A 와 B 둘 다!
```

### 중첩 조건문 — 조건 안의 조건

들여쓰기를 한 단계 더 넣어 조건 안에 조건을 넣을 수 있습니다.

```python
age = 25
has_ticket = True

if age >= 19:
    if has_ticket:
        print("입장하세요")
    else:
        print("티켓을 구매해 주세요")
else:
    print("미성년자는 입장할 수 없습니다")
```

같은 내용을 `and` 로 평평하게 쓸 수도 있습니다.

```python
if age >= 19 and has_ticket:
    print("입장하세요")
elif age >= 19:
    print("티켓을 구매해 주세요")
else:
    print("미성년자는 입장할 수 없습니다")
```

> **어느 쪽이 좋은가?** 중첩이 2단계를 넘어가면 읽기 어려워집니다. 가능하면 `and` 로 펴서 쓰세요.
> 다만 "먼저 나이를 확인하고, 통과한 사람만 티켓을 본다" 는 **단계가 뚜렷할 때**는 중첩이 더 명확합니다.

### 삼항 표현식 — 한 줄로 쓰기

간단한 두 갈래는 한 줄로 줄일 수 있습니다.

```python
값 = 참일_때 if 조건 else 거짓일_때
```

```python
age = 20
result = "성인" if age >= 19 else "미성년자"
print(result)      # 성인
```

> 짧은 판단에만 쓰세요. 조건이 복잡해지면 오히려 읽기 어려워집니다.

### 참/거짓으로 취급되는 값들

조건 자리에 True/False 가 아닌 값을 넣으면 파이썬이 알아서 판단합니다.

| 거짓(False)으로 취급 | 참(True)으로 취급 |
|---|---|
| `0`, `0.0` | 0이 아닌 모든 숫자 |
| `""` (빈 문자열) | 내용이 있는 문자열 |
| `[]` (빈 리스트) | 내용이 있는 리스트 |
| `None` | 그 외 대부분 |

```python
name = input("이름: ")

if name:                     # name 이 빈 문자열이 아니면 참
    print(f"{name}님 환영합니다")
else:
    print("이름을 입력해 주세요")
```

`grade.py` 를 만들어 실행합니다.

```python
score = int(input("점수를 입력하세요 (0~100): "))

# 잘못된 입력을 먼저 걸러 냅니다
if score < 0 or score > 100:

elif score >= 90:
    print("A학점입니다")
elif score >= 80:
    print("B학점입니다")

    print("C학점입니다")
elif score >= 60:
    print("D학점입니다")
else:
    print("F학점입니다")
```

실행 결과:

```
점수를 입력하세요 (0~100): 85

```

```

```

> **잘못된 입력을 맨 위에서 먼저 거르는 것**이 좋은 습관입니다. 뒤쪽 조건이 단순해집니다.

### Step 2. 윤년 판별기

윤년 규칙은 이렇습니다.
① 4로 나누어떨어지면 윤년 ② 단, 100으로 나누어떨어지면 평년 ③ 단, 400으로 나누어떨어지면 다시 윤년

```python
year = int(input("연도를 입력하세요: "))

if year % 400 == 0:
    is_leap = True
elif year % 100 == 0:
    is_leap = False
elif year % 4 == 0:
    is_leap = True
else:
    is_leap = False

if is_leap:
    print(f"{year}년은 윤년입니다 (2월이 29일)")
else:
    print(f"{year}년은 평년입니다 (2월이 28일)")
```

실행 결과:

```
연도를 입력하세요: 2024
2024년은 윤년입니다 (2월이 29일)
```

```
연도를 입력하세요: 1900
1900년은 평년입니다 (2월이 28일)
```

> 400 → 100 → 4 순서로 검사하는 이유를 생각해 보세요. `2000` 을 넣어 확인하면 순서의 중요성을 알 수 있습니다.
>
> 참고로 위 판별은 논리 연산자 한 줄로도 가능합니다.
> ```python
> is_leap = (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
> ```

### Step 4. 가위바위보 (1회전)

```python
import random   # 무작위 값을 만드는 도구를 불러옵니다

user = input("가위, 바위, 보 중 하나를 입력하세요: ").strip()
computer = random.choice(["가위", "바위", "보"])

print(f"나: {user} / 컴퓨터: {computer}")

if user not in ["가위", "바위", "보"]:
    print("잘못 입력했습니다.")
elif user == computer:
    print("비겼습니다!")
elif (user == "가위" and computer == "보") or \
     (user == "바위" and computer == "가위") or \

```

### Step 5. BMI 판정기 완성 (오늘의 종합 예제)

Day 002에서 만든 BMI 계산기에 드디어 판정 기능을 붙입니다.

```python
print("=== BMI 판정기 ===")

name = input("이름: ").strip()
weight = float(input("몸무게(kg): "))
height_cm = float(input("키(cm): "))

# 입력값 검증
if weight <= 0 or height_cm <= 0:
    print("몸무게와 키는 0보다 커야 합니다.")
else:
    height_m = height_cm / 100
    bmi = weight / (height_m ** 2)

    # 대한비만학회 기준
    if bmi < 18.5:
        category = "저체중"
        advice = "균형 잡힌 식사로 체중을 늘려 보세요."
    elif bmi < 23:
        category = "정상"
        advice = "현재 상태를 잘 유지하세요."
    elif bmi < 25:
        category = "과체중"
        advice = "가벼운 운동을 시작해 보세요."
    else:
        category = "비만"
        advice = "식단 조절과 규칙적인 운동을 권합니다."

    print()
    print(f"{name}님의 BMI: {bmi:.1f}")
    print(f"판정: {category}")
    print(f"조언: {advice}")
```

실행 결과:

```
=== BMI 판정기 ===
이름: 홍길동
몸무게(kg): 70
키(cm): 175

홍길동님의 BMI: 22.9
판정: 정상
조언: 현재 상태를 잘 유지하세요.
```

> **눈여겨볼 점** — `bmi < 23` 조건에 "18.5 이상" 을 쓰지 않았습니다.
> 앞의 `if bmi < 18.5` 에서 이미 걸러졌기 때문에, 여기 도달했다는 것 자체가 "18.5 이상"이라는 뜻입니다.
> `elif` 를 쓰면 이렇게 조건을 간결하게 쓸 수 있습니다.

## ⑤ 자주 하는 실수

### `IndentationError: expected an indented block`

```python
if age >= 19:
print("성인입니다")
```

```
  File "test.py", line 2
    print("성인입니다")
    ^
IndentationError: expected an indented block after 'if' statement on line 1
```

**원인** — `if` 뒤에 들여쓰기된 코드가 없습니다.
**해결** — 실행할 코드를 스페이스 4칸 들여씁니다.

### `IndentationError: unexpected indent`

```python
age = 20
    print(age)
```

```
IndentationError: unexpected indent
```

**원인** — 들여쓸 이유가 없는 곳을 들여썼습니다.
**해결** — 불필요한 공백을 제거합니다. `if` `for` `def` 같은 블록 시작 문장 뒤에서만 들여씁니다.

### `SyntaxError: expected ':'`

```python
if age >= 19
    print("성인입니다")
```

```
  File "test.py", line 1
    if age >= 19
                ^
SyntaxError: expected ':'
```

**원인** — 조건 끝에 콜론(`:`)을 빠뜨렸습니다.
**해결** — `if 조건:` 처럼 콜론을 붙입니다. `elif` `else` `for` `while` `def` 도 모두 콜론이 필요합니다.

### 조건 순서를 잘못 써서 항상 같은 결과가 나옴

```python
score = 95

if score >= 60:
    print("D학점")     # 95점인데 D학점이 출력됨
elif score >= 90:
    print("A학점")     # 절대 실행되지 않음
```

**원인** — `elif` 는 위에서부터 검사하므로, 넓은 조건이 위에 있으면 아래 조건은 도달하지 못합니다.
**해결** — 범위 조건은 **엄격한 것부터 위에** 씁니다. `90 → 80 → 70 → 60` 순.

### `else` 에 조건을 붙임

```python
if score >= 90:
    print("A")
else score >= 80:      # 에러
    print("B")
```

```
SyntaxError: invalid syntax
```

**원인** — `else` 는 "나머지 전부"이므로 조건을 가질 수 없습니다.
**해결** — 조건이 필요하면 `elif` 를 씁니다.

### 문자열 비교 시 대소문자·공백 때문에 안 맞음

```python
answer = input("계속할까요? (yes/no): ")

if answer == "yes":
    print("계속합니다")
```

사용자가 `Yes` 나 ` yes ` 를 입력하면 조건이 거짓이 됩니다.

**해결** — 비교 전에 정리합니다. Day 003의 메서드를 씁니다.

```python
answer = input("계속할까요? (yes/no): ").strip().lower()
```

## ⑥ 확인 문제

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
x = 10

if x > 5:
    print("A")
if x > 8:
    print("B")
elif x > 3:
    print("C")
else:
    print("D")
```

<details>
<summary>답 보기</summary>

```
A
B
```

- 첫 번째 `if` 는 **독립된 조건문**입니다. `10 > 5` 가 참이므로 `A` 출력.
- 두 번째 `if ~ elif ~ else` 는 별개의 묶음입니다. `10 > 8` 이 참이므로 `B` 출력하고 나머지(`elif`, `else`)는 건너뜁니다.

**핵심** — `if` 를 새로 시작하면 앞의 조건문과 무관한 새 판단이 시작됩니다.
</details>

**2.** 택배 요금 계산기를 만드세요.
무게가 5kg 이하면 3,000원, 5kg 초과 10kg 이하면 5,000원, 10kg 초과면 8,000원입니다. 단, 지역이 `제주` 면 항상 3,000원이 추가됩니다.

<details>
<summary>답 보기</summary>

```python
weight = float(input("무게(kg): "))
region = input("지역: ").strip()

# 기본 요금 결정
if weight <= 5:
    fee = 3000
elif weight <= 10:
    fee = 5000
else:
    fee = 8000

# 제주 추가 요금
if region == "제주":
    fee += 3000

print(f"배송비는 {fee:,}원 입니다.")
```

실행 결과:

```
무게(kg): 7
지역: 제주
배송비는 8,000원 입니다.
```

**포인트 3가지**
- 기본 요금과 추가 요금을 **두 단계로 나눠** 계산하면 조건이 단순해집니다. 한 번에 6가지 경우를 다 쓰려 하지 마세요.
- `fee += 3000` 으로 기존 값에 더합니다.
- `{fee:,}` 는 천 단위 콤마를 넣는 서식입니다.
</details>

**3.** 아래 코드에는 논리적 오류가 있습니다. 무엇이 문제이고 어떻게 고쳐야 할까요?

```python
temperature = 30

if temperature > 10:
    print("겉옷이 필요합니다")
elif temperature > 25:
    print("반팔을 입으세요")
else:
    print("따뜻하게 입으세요")
```

<details>
<summary>답 보기</summary>

**문제** — 30도인데 `"겉옷이 필요합니다"` 가 출력됩니다.
`elif temperature > 25` 는 영원히 실행되지 않습니다. 25보다 큰 값은 이미 첫 조건(`> 10`)에서 전부 걸리기 때문입니다.

**해결** — 조건을 **엄격한 것부터** 배치합니다.

```python
temperature = 30

if temperature > 25:
    print("반팔을 입으세요")
elif temperature > 10:
    print("겉옷이 필요합니다")
else:
    print("따뜻하게 입으세요")
```

실행 결과:

```
반팔을 입으세요
```

> 이 실수는 실무에서도 자주 나옵니다. `elif` 를 여러 개 쓸 때는 **테스트 값을 각 구간마다 하나씩 넣어 보는 것**이 확실한 검증 방법입니다. (30, 15, 5 를 각각 넣어 보세요)
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `if 조건:` | 조건이 참일 때만 실행. **콜론과 들여쓰기 필수** |
| `else:` | 나머지 전부. 조건을 붙일 수 없음 |
| `elif 조건:` | 갈래가 셋 이상일 때. **위에서부터 검사, 하나만 실행** |
| 조건 순서 | 범위 조건은 **엄격한 것부터** 위에 |
| `if` 여러 개 | 각각 독립 판단. 여러 개가 실행될 수 있음 |
| 중첩 조건문 | 들여쓰기 한 단계 더. 2단계를 넘으면 `and` 로 펴기 |
| 삼항 표현식 | `A if 조건 else B` |

**오늘 반드시 기억할 한 가지**
> `elif` 는 **위에서부터 검사해 처음 참인 것 하나만** 실행합니다. 그래서 **조건의 순서가 결과를 바꿉니다.**

(기준: 8세 미만 무료 / 8~13세 6,000원 / 14~19세 9,000원 / 20세 이상 12,000원 / 회원이면 20% 할인)
