## ② 왜 필요한가

이번 주에 NumPy·Pandas·정제·집계·시각화를 배웠습니다.
도구는 익혔지만 **"무엇을 볼 것인가"** 는 아직 훈련하지 않았습니다.

**EDA(Exploratory Data Analysis, 탐색적 데이터 분석)** 는 도구가 아니라 **절차**입니다.

| 잘못된 EDA | 좋은 EDA |
|---|---|
| 일단 `describe()` 부터 찍는다 | **질문을 먼저 적는다** |
| 차트를 20개 그린다 | 질문에 답하는 차트 3~5개 |
| "평균이 41입니다" | "평균 41인데, 지역별로 39~47로 갈리고 서남권이 가장 높습니다" |
| 노트북 하나에 300셀 | 스크립트로 정리해 재실행 가능 |

**그리고 이 과정의 모든 프로젝트가 "노트북만으로 끝나는 결과물"을 금지합니다.**

```
탐색은 노트북으로 → 결론이 나면 스크립트로 옮긴다 → 명령 한 줄로 재현
```

## ③ 개념 설명

### EDA 5단계

```
1. 질문 정의    무엇을 알고 싶은가? (3~5개, 구체적으로)
        ↓
2. 데이터 이해   구조·타입·결측·중복 — 답할 수 있는 데이터인가?
        ↓
3. 정제        답을 왜곡할 수 있는 문제 제거 (Day 023)
        ↓
4. 탐색·시각화  질문마다 근거를 만든다 (Day 024)
        ↓
5. 요약·기록    질문 → 근거 → 결론 → 한계
```

**1번을 건너뛰면 4번에서 길을 잃습니다.**

### 좋은 질문의 조건

| 나쁜 질문 | 좋은 질문 |
|---|---|
| "데이터를 분석해 보자" | "서울 25개 구 중 미세먼지가 가장 나쁜 곳은 어디인가?" |
| "관계를 보자" | "강수량이 있는 날 미세먼지가 실제로 낮아지는가?" |
| "패턴이 있나?" | "주말과 평일의 미세먼지 차이가 지역마다 다른가?" |

**조건 세 가지**
1. **답이 표나 차트 하나로 나오는가**
2. **데이터로 답할 수 있는가** (없는 컬럼을 요구하지 않는가)
3. **답이 어느 쪽이든 의미가 있는가** (예상과 달라도 발견)

### 질문 유형 6가지

| 유형 | 예 | 도구 |
|---|---|---|
| **분포** | 미세먼지 값이 어떻게 퍼져 있나? | 히스토그램 · `describe()` |
| **비교** | 어느 지역이 가장 나쁜가? | `groupby` · 막대 |
| **추이** | 12일간 어떻게 변했나? | 선 그래프 |
| **관계** | 기온이 높으면 오존도 높은가? | 산점도 · 상관 |
| **구성** | 등급별 비율은? | `value_counts` · 막대 |
| **이상** | 평소와 다른 날/지역이 있나? | 편차 · 박스플롯 |

**리포트에는 이 중 3~5개를 고릅니다.** 전부 넣으면 초점이 흐려집니다.

### 노트북 → 스크립트

| | 노트북 (.ipynb) | 스크립트 (.py) |
|---|---|---|
| 목적 | **탐색·실험** | **재현·자동화** |
| 실행 | 셀 단위, 순서 자유 | 위에서 아래로 한 번 |
| 상태 | 남아 있음 (위험) | 매번 새로 시작 |
| 버전 관리 | diff가 지저분 | 깔끔 |
| 테스트 | 어려움 | 가능 |
| 배포 | 불가 | 가능 |

**노트북의 가장 큰 위험 — 실행 순서**

```
셀 1: df = pd.read_csv(...)
셀 5: df = df.dropna()
셀 3: print(len(df))       ← 이걸 나중에 실행하면?
```

**같은 노트북이 실행 순서에 따라 다른 결과를 냅니다.**
"어제는 됐는데 오늘은 안 돼요"의 주범입니다.

**옮기는 방법**

```
노트북에서 탐색 → 결론이 난 부분을 함수로 추출 → 스크립트에 정리
                                                → 노트북은 "탐색 기록"으로 보관
```

### 리포트 구조

```markdown
# 제목 — 무엇을 분석했는가

## 요약 (3줄)
가장 중요한 발견 3개

## 데이터
출처 · 기간 · 규모 · 정제 내역

## 질문 1: ~인가?
### 근거
[표 또는 차트]
### 결론
한 문장

## 질문 2: ...

## 한계
- 무엇을 알 수 없는가
- 어떤 가정을 했는가

## 재현 방법
```bash
python eda.py --config config.yaml
```
```

**"요약"을 맨 위에 쓰세요.** 읽는 사람은 3분밖에 없습니다.

### 결론을 쓸 때 주의

| 과장 | 정확 |
|---|---|
| "강수량이 미세먼지를 낮춥니다" | "강수가 있는 날의 평균이 12% 낮았습니다 (r = -0.28, 12일 관측)" |
| "서남권이 가장 오염됐습니다" | "서남권 평균이 43.2로 가장 높지만, 권역 간 차이(4.2)가 권역 내 변동(±13.7)보다 작습니다" |
| "주말에 미세먼지가 줍니다" | "표본이 12일(주말 4일)로 적어 결론을 내리기 어렵습니다" |

**데이터가 말하는 것 이상을 쓰지 마세요.**

## ④ 단계별 실습

### Step 1. 질문 정의

`docs/questions.md` 를 만듭니다. **코드보다 먼저 씁니다.**

```markdown
# 분석 질문

데이터: 서울시 25개 구 대기질 측정값 (2026-08-01 ~ 08-12, 12일)
       + 측정소 정보(권역·인구밀도) + 일별 날씨

## Q1. 미세먼지 값은 어떻게 분포하는가? (분포)
- 왜: 이후 모든 분석의 전제. 정규분포인가, 치우쳐 있는가
- 답 형태: 히스토그램 + 기술통계표
- 판단 기준: 평균과 중앙값의 차이, 왜도

## Q2. 지역(권역)에 따라 미세먼지 수준이 다른가? (비교)
- 왜: 지역별 대응이 필요한지 판단
- 답 형태: 권역별 박스플롯 + 집계표
- 판단 기준: 권역 간 평균 차이 vs 권역 내 표준편차

## Q3. 12일간 어떤 추이를 보였는가? (추이)
- 왜: 특정 시점에 전역적 악화가 있었는지
- 답 형태: 일별 선 그래프 (최소~최대 밴드 포함)
- 판단 기준: 전체가 함께 움직이는 날이 있는가

## Q4. 기상 조건과 미세먼지는 관계가 있는가? (관계)
- 왜: 예측 모델의 특성 후보 탐색 (W11 대비)
- 답 형태: 산점도 3종 + 상관계수표
- 판단 기준: |r| > 0.3 이면 주목, 단 인과 아님

## Q5. 평소와 다르게 나빴던 지역·날짜가 있는가? (이상)
- 왜: 이상 이벤트 탐지. 데이터 오류인지 실제 현상인지 구분
- 답 형태: 자기 평균 대비 편차 상위 목록
- 판단 기준: 같은 날 여러 지역이 함께 높았는가(전역) vs 한 곳만(국지)

## 답할 수 없는 것 (한계로 명시)
- 인과관계 — 관측 데이터이므로 상관만 확인 가능
- 계절성 — 12일 데이터로는 알 수 없음
- 원인(교통량·공장·중국발) — 해당 데이터가 없음
```

> **질문마다 "답 형태"와 "판단 기준"을 미리 적으세요.**
> 그래야 차트를 그리고 나서 "그래서 뭐?"가 되지 않습니다.

### Step 2. EDA 스크립트 — 설정과 로딩

`eda.py` 를 만듭니다. 긴 파일이므로 나눠서 작성합니다.

```python
"""공공데이터 EDA 리포트 생성기.

사용법:
    python eda.py                      # 기본 설정으로 실행
    python eda.py --out reports/0812   # 출력 폴더 지정
    python eda.py --no-charts          # 표만 생성 (빠름)
"""

from __future__ import annotations

import argparse
import platform
import sys
from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# ==================== 설정 ====================

pd.set_option("display.width", 160)
pd.set_option("display.max_columns", None)


def setup_font() -> None:
    """한글 폰트를 설정합니다."""
    system = platform.system()
    font = {"Windows": "Malgun Gothic", "Darwin": "AppleGothic"}.get(system, "NanumGothic")
    plt.rcParams["font.family"] = font
    plt.rcParams["axes.unicode_minus"] = False
    plt.rcParams["figure.dpi"] = 100
    plt.rcParams["savefig.bbox"] = "tight"


@dataclass
class Config:
    air_path: Path = Path("data/air_quality_raw.csv")
    station_path: Path = Path("data/station_info.csv")
    weather_path: Path = Path("data/weather.csv")
    out_dir: Path = Path("reports")
    make_charts: bool = True

    # 도메인 규칙 (Day 023)
    domain_rules: dict = field(default_factory=lambda: {
        "미세먼지": (0, 600),
        "초미세먼지": (0, 400),
        "오존": (0, 0.6),
    })

    @property
    def chart_dir(self) -> Path:
        return self.out_dir / "charts"


@dataclass
class Findings:
    """리포트에 들어갈 발견 사항."""
    summary: list[str] = field(default_factory=list)
    sections: list[dict] = field(default_factory=list)
    limitations: list[str] = field(default_factory=list)
    cleaning: list[dict] = field(default_factory=list)

    def add_section(self, question: str, evidence: str, conclusion: str,
                    chart: str | None = None) -> None:
        self.sections.append({
            "question": question,
            "evidence": evidence,
            "conclusion": conclusion,
            "chart": chart,
        })


# ==================== 1) 로딩과 정제 ====================

def load_and_clean(config: Config, findings: Findings) -> pd.DataFrame:
    """데이터를 읽고 정제합니다. Day 023 의 절차를 따릅니다."""
    print("=" * 74)
    print("1. 데이터 로딩과 정제")
    print("=" * 74)

    raw = pd.read_csv(config.air_path, encoding="utf-8-sig")
    original_rows = len(raw)
    print(f"  원본: {raw.shape[0]}행 × {raw.shape[1]}열")

    df = raw.copy()

    # 타입 변환
    df["측정일시"] = pd.to_datetime(df["측정일시"], errors="coerce")
    for col in ["미세먼지", "초미세먼지", "누적측정건수"]:
        df[col] = pd.to_numeric(
            df[col].astype(str).str.replace(",", "", regex=False).str.strip(),
            errors="coerce",
        )
    findings.cleaning.append({
        "단계": "타입 변환", "건수": len(df),
        "설명": f"미세먼지 결측 {df['미세먼지'].isna().sum()}건 발생 ('-' 표기)",
    })

    # 문자열 정규화
    before_unique = df["측정소명"].nunique()
    df["측정소명"] = df["측정소명"].str.strip()
    findings.cleaning.append({
        "단계": "문자열 정규화", "건수": len(df),
        "설명": f"측정소 고유값 {before_unique} → {df['측정소명'].nunique()}개",
    })

    # 중복 제거
    dup = df.duplicated().sum()
    df = df.drop_duplicates().reset_index(drop=True)
    findings.cleaning.append({
        "단계": "중복 제거", "건수": len(df), "설명": f"완전 중복 {dup}건 제거",
    })

    # 도메인 규칙
    for col, (low, high) in config.domain_rules.items():
        if col not in df.columns:
            continue
        invalid = ((df[col] < low) | (df[col] > high)).sum()
        if invalid:
            df.loc[(df[col] < low) | (df[col] > high), col] = np.nan
            findings.cleaning.append({
                "단계": f"도메인 규칙 ({col})", "건수": len(df),
                "설명": f"{low}~{high} 밖 {invalid}건을 결측 처리",
            })

    # 결측 대치 (측정소별 중앙값)
    for col in ["미세먼지", "초미세먼지"]:
        na = df[col].isna().sum()
        if na:
            df[col] = df.groupby("측정소명")[col].transform(lambda s: s.fillna(s.median()))
            df[col] = df[col].fillna(df[col].median())
            findings.cleaning.append({
                "단계": f"결측 대치 ({col})", "건수": len(df),
                "설명": f"측정소별 중앙값으로 {na}건 대치",
            })

    print(f"  정제 후: {len(df)}행 ({(len(df) - original_rows) / original_rows:+.1%})")

    # 보조 데이터 결합
    station = pd.read_csv(config.station_path, encoding="utf-8-sig")
    weather = pd.read_csv(config.weather_path, encoding="utf-8-sig",
                          parse_dates=["측정일시"])

    before = len(df)
    df = df.merge(station, on="측정소명", how="left", validate="many_to_one")
    df = df.merge(weather, on="측정일시", how="left", validate="many_to_one")
    assert len(df) == before, f"merge 로 행 수가 변했습니다: {before} → {len(df)}"

    unmatched = df["권역"].isna().sum()
    if unmatched:
        df["권역"] = df["권역"].fillna("미분류")
        print(f"  ⚠ 측정소 정보가 없는 행 {unmatched}건 → '미분류'")

    # 파생 컬럼
    df["요일"] = df["측정일시"].dt.dayofweek.map(
        {0: "월", 1: "화", 2: "수", 3: "목", 4: "금", 5: "토", 6: "일"})
    df["주말"] = df["측정일시"].dt.dayofweek >= 5
    df["일자"] = df["측정일시"].dt.strftime("%m-%d")
    df["비온날"] = df["강수량"] > 0
    df["측정소평균"] = df.groupby("측정소명")["미세먼지"].transform("mean")
    df["평균대비"] = (df["미세먼지"] - df["측정소평균"]).round(1)

    conditions = [df["미세먼지"] > 80, df["미세먼지"] > 50, df["미세먼지"] > 30]
    df["등급"] = np.select(conditions, ["나쁨", "약간나쁨", "보통"], default="좋음")

    print(f"  최종: {df.shape[0]}행 × {df.shape[1]}열")
    print(f"  기간: {df['측정일시'].min():%Y-%m-%d} ~ {df['측정일시'].max():%Y-%m-%d}"
          f" ({df['측정일시'].nunique()}일)")
    print(f"  측정소: {df['측정소명'].nunique()}개, 권역: {df['권역'].nunique()}개")

    findings.limitations.append(
        f"관측 기간이 {df['측정일시'].nunique()}일로 짧아 계절성·장기 추세는 알 수 없습니다."
    )
    findings.limitations.append(
        "관측 데이터이므로 상관관계만 확인 가능하며 인과관계는 주장할 수 없습니다."
    )
    if unmatched:
        findings.limitations.append(
            f"측정소 정보가 없는 {unmatched}건은 권역 분석에서 '미분류'로 처리했습니다."
        )
    return df
```

def q1_distribution(df: pd.DataFrame, config: Config, findings: Findings) -> None:
    print("\n" + "=" * 74)

        "초미세먼지": df["초미세먼지"].describe(),

    print(stats.to_string())

    mean, median = x.mean(), x.median()
    skew = x.skew()
    print(f"\n  평균 {mean:.1f} / 중앙값 {median:.1f} (차이 {mean - median:+.1f})")
    print(f"  왜도(skewness) {skew:.3f}")

    if abs(skew) < 0.5:
        shape = "좌우 대칭에 가까운 분포"
    elif skew > 0:
        shape = "오른쪽으로 꼬리가 긴 분포 (높은 값이 드물게 존재)"
    else:
        shape = "왼쪽으로 꼬리가 긴 분포"

    q1, q3 = x.quantile([0.25, 0.75])
    print(f"  IQR: {q1:.0f} ~ {q3:.0f} (중간 50%)")
    print(f"  형태: {shape}")

    chart = None
    if config.make_charts:
        fig, axes = plt.subplots(1, 2, figsize=(13, 4.5))

        ax = axes[0]
        ax.hist(x, bins=25, color="#4c8bf5", edgecolor="white", alpha=0.85)
        ax.axvline(mean, color="crimson", ls="--", lw=2, label=f"평균 {mean:.1f}")
        ax.axvline(median, color="darkgreen", lw=2, label=f"중앙값 {median:.1f}")
        ax.axvspan(q1, q3, alpha=0.12, color="green", label=f"IQR {q1:.0f}~{q3:.0f}")
        ax.set_title("미세먼지 분포", fontsize=13, fontweight="bold")
        ax.set_xlabel("미세먼지 (㎍/㎥)")
        ax.set_ylabel("빈도")
        ax.legend(fontsize=9)
        ax.grid(axis="y", alpha=0.3)

        ax = axes[1]
        counts = df["등급"].value_counts()
        order = [g for g in ["좋음", "보통", "약간나쁨", "나쁨"] if g in counts.index]
        colors = {"좋음": "#2ecc71", "보통": "#3498db",
                  "약간나쁨": "#f39c12", "나쁨": "#e74c3c"}
        bars = ax.bar(order, [counts[g] for g in order],
                      color=[colors[g] for g in order], alpha=0.85)
        for bar, g in zip(bars, order):
            ax.text(bar.get_x() + bar.get_width() / 2, bar.get_height() + 2,
                    f"{counts[g]}건\n({counts[g] / len(df):.0%})",
                    ha="center", fontsize=9)
        ax.set_title("등급별 분포", fontsize=13, fontweight="bold")
        ax.set_ylabel("관측 수")
        ax.grid(axis="y", alpha=0.3)

        chart = "q1_distribution.png"

        plt.close()
        print(f"  차트: {chart}")

    good_ratio = (df["등급"].isin(["좋음", "보통"])).mean()

            f"전체의 {good_ratio:.0%}가 '좋음' 또는 '보통' 등급입니다."

        chart=chart,

    )

def q2_region(df: pd.DataFrame, config: Config, findings: Findings) -> None:
    print("\n" + "=" * 74)
    print("Q2. 지역(권역)에 따라 미세먼지 수준이 다른가?")
    print("=" * 74)

    by_region = df.groupby("권역").agg(
        측정소수=("측정소명", "nunique"),
        관측수=("미세먼지", "count"),
        평균=("미세먼지", "mean"),
        중앙값=("미세먼지", "median"),
        표준편차=("미세먼지", "std"),
        최대=("미세먼지", "max"),
    ).round(2).sort_values("평균", ascending=False)
    print(by_region.to_string())

    between = by_region["평균"].max() - by_region["평균"].min()
    within = df.groupby("권역")["미세먼지"].std().mean()
    print(f"\n  권역 간 평균 차이 : {between:.2f}")
    print(f"  권역 내 평균 표준편차: {within:.2f}")
    print(f"  비율(간/내)        : {between / within:.2f}")

    if between / within > 1:
        verdict = "권역 간 차이가 권역 내 변동보다 커서 지역 효과가 뚜렷합니다"
    else:
        verdict = ("권역 간 차이가 권역 내 변동보다 작아, 지역보다 "
                   "다른 요인(날짜·기상)의 영향이 큰 것으로 보입니다")
    print(f"  → {verdict}")

    top = df.groupby("측정소명")["미세먼지"].mean().sort_values(ascending=False)
    print(f"\n  측정소 상위 5: {', '.join(f'{s}({v:.1f})' for s, v in top.head(5).items())}")
    print(f"  측정소 하위 5: {', '.join(f'{s}({v:.1f})' for s, v in top.tail(5).items())}")

    chart = None
    if config.make_charts:
        fig, axes = plt.subplots(1, 2, figsize=(15, 6),
                                 gridspec_kw={"width_ratios": [1, 1.3]})

        ax = axes[0]
        regions = by_region.index.tolist()
        data = [df.loc[df["권역"] == r, "미세먼지"] for r in regions]
        bp = ax.boxplot(data, labels=regions, patch_artist=True, showmeans=True)
        for patch in bp["boxes"]:
            patch.set_facecolor("#a8c8f0")
        ax.axhline(df["미세먼지"].mean(), color="crimson", ls="--", lw=1.5,
                   label=f"전체 평균 {df['미세먼지'].mean():.1f}")
        ax.set_title("권역별 미세먼지 분포", fontsize=13, fontweight="bold")
        ax.set_ylabel("미세먼지 (㎍/㎥)")
        ax.legend(fontsize=9)
        ax.grid(axis="y", alpha=0.3)

        ax = axes[1]
        sorted_top = top.sort_values()
        colors = ["#e74c3c" if v > df["미세먼지"].mean() else "#3498db"
                  for v in sorted_top]
        bars = ax.barh(sorted_top.index, sorted_top.values, color=colors, alpha=0.85)
        ax.axvline(df["미세먼지"].mean(), color="black", ls="--", lw=1.5)
        for bar, v in zip(bars, sorted_top.values):
            ax.text(v + 0.3, bar.get_y() + bar.get_height() / 2,
                    f"{v:.1f}", va="center", fontsize=8)
        ax.set_title("측정소별 평균 미세먼지", fontsize=13, fontweight="bold")
        ax.set_xlabel("미세먼지 (㎍/㎥)")
        ax.grid(axis="x", alpha=0.3)

        plt.tight_layout()
        chart = "q2_region.png"
        plt.savefig(config.chart_dir / chart)
        plt.close()
        print(f"  차트: {chart}")

    findings.add_section(
        question="Q2. 지역(권역)에 따라 미세먼지 수준이 다른가?",
        evidence=by_region.to_markdown(),
        conclusion=(
            f"권역별 평균은 {by_region['평균'].min():.1f}~{by_region['평균'].max():.1f}로 "
            f"{between:.1f} 차이가 있고, 가장 높은 곳은 {by_region.index[0]}입니다. "
            f"다만 권역 내 표준편차가 {within:.1f}로 권역 간 차이보다 크므로, {verdict}."
        ),
        chart=chart,
    )
    findings.summary.append(
        f"권역별 평균 차이는 {between:.1f}로, 권역 내 변동({within:.1f})보다 작음"
    )

def q3_trend(df: pd.DataFrame, config: Config, findings: Findings) -> None:
    print("\n" + "=" * 74)
    print("Q3. 12일간 어떤 추이를 보였는가?")
    print("=" * 74)

    daily = df.groupby("일자").agg(
        평균=("미세먼지", "mean"),
        중앙값=("미세먼지", "median"),
        최소=("미세먼지", "min"),
        최대=("미세먼지", "max"),
        표준편차=("미세먼지", "std"),
        강수량=("강수량", "first"),
        기온=("평균기온", "first"),
    ).round(1)
    print(daily.to_string())

    worst = daily["평균"].idxmax()
    best = daily["평균"].idxmin()
    swing = daily["평균"].max() - daily["평균"].min()
    print(f"\n  최악: {worst} (평균 {daily.loc[worst, '평균']:.1f})")
    print(f"  최선: {best} (평균 {daily.loc[best, '평균']:.1f})")
    print(f"  일별 평균 변동폭: {swing:.1f}")

    # 전역적 악화인가 국지적인가
    worst_day = df[df["일자"] == worst]
    above = (worst_day["평균대비"] > 0).mean()
    print(f"  {worst} 에 자기 평균보다 높았던 측정소 비율: {above:.0%}")
    scope = "전역적 악화" if above > 0.7 else "일부 지역에 국한"
    print(f"  → {scope}")

    chart = None
    if config.make_charts:
        fig, ax1 = plt.subplots(figsize=(12, 5))

        ax1.fill_between(daily.index, daily["최소"], daily["최대"],
                         alpha=0.18, color="#4c8bf5", label="최소~최대")
        ax1.plot(daily.index, daily["평균"], marker="o", lw=2.5,
                 color="#1a5fc4", label="일평균")
        ax1.axhline(df["미세먼지"].mean(), color="crimson", ls="--", lw=1.2,
                    label=f"전체 평균 {df['미세먼지'].mean():.1f}")
        ax1.annotate(f"최악 {daily.loc[worst, '평균']:.1f}",
                     xy=(worst, daily.loc[worst, "평균"]),
                     xytext=(0, 22), textcoords="offset points",
                     ha="center", fontsize=9,
                     arrowprops=dict(arrowstyle="->", color="crimson"))
        ax1.set_ylabel("미세먼지 (㎍/㎥)", color="#1a5fc4")
        ax1.tick_params(axis="y", labelcolor="#1a5fc4")
        ax1.set_xlabel("날짜")
        ax1.grid(alpha=0.3)

        ax2 = ax1.twinx()
        ax2.bar(daily.index, daily["강수량"], alpha=0.3, color="skyblue",
                width=0.55, label="강수량")
        ax2.set_ylabel("강수량 (mm)", color="steelblue")
        ax2.tick_params(axis="y", labelcolor="steelblue")

        lines1, labels1 = ax1.get_legend_handles_labels()
        lines2, labels2 = ax2.get_legend_handles_labels()
        ax1.legend(lines1 + lines2, labels1 + labels2, loc="upper left", fontsize=9)
        ax1.set_title("일별 미세먼지 추이와 강수량", fontsize=14, fontweight="bold")
        plt.setp(ax1.get_xticklabels(), rotation=45, ha="right")

        plt.tight_layout()
        chart = "q3_trend.png"
        plt.savefig(config.chart_dir / chart)
        plt.close()
        print(f"  차트: {chart}")

    findings.add_section(
        question="Q3. 12일간 어떤 추이를 보였는가?",
        evidence=daily.to_markdown(),
        conclusion=(
            f"일별 평균은 {daily['평균'].min():.1f}~{daily['평균'].max():.1f}로 "
            f"{swing:.1f} 변동했습니다. 가장 나빴던 날은 {worst}이며, "
            f"이날 측정소의 {above:.0%}가 자기 평균을 웃돌아 {scope}으로 보입니다."
        ),
        chart=chart,
    )
    findings.summary.append(f"가장 나빴던 날은 {worst}(평균 {daily.loc[worst, '평균']:.1f})")


# ==================== 5) Q4 — 기상과의 관계 ====================

def q4_weather(df: pd.DataFrame, config: Config, findings: Findings) -> None:
    print("\n" + "=" * 74)
    print("Q4. 기상 조건과 미세먼지는 관계가 있는가?")
    print("=" * 74)

    cols = ["평균기온", "강수량", "평균풍속", "평균습도", "초미세먼지", "인구밀도"]
    cols = [c for c in cols if c in df.columns]
    corr = df[["미세먼지"] + cols].corr()["미세먼지"].drop("미세먼지")
    corr = corr.sort_values(key=abs, ascending=False)

    table = pd.DataFrame({
        "상관계수": corr.round(3),
        "방향": ["양(+)" if v > 0 else "음(-)" for v in corr],
        "강도": ["강함" if abs(v) > 0.5 else "보통" if abs(v) > 0.3 else "약함"
                for v in corr],
    })
    print(table.to_string())

    rain = df.groupby("비온날")["미세먼지"].agg(["count", "mean", "std"]).round(2)
    rain.index = ["비 안 온 날", "비 온 날"]
    print(f"\n  강수 유무별 비교:")
    print(rain.to_string())

    if len(rain) == 2:
        diff = rain.loc["비 온 날", "mean"] - rain.loc["비 안 온 날", "mean"]
        pct = diff / rain.loc["비 안 온 날", "mean"]
        print(f"  차이: {diff:+.2f} ({pct:+.1%})")

    chart = None
    if config.make_charts:
        pairs = [("초미세먼지", "미세먼지"), ("평균풍속", "미세먼지"),
                 ("평균기온", "미세먼지")]
        pairs = [(x, y) for x, y in pairs if x in df.columns]

        fig, axes = plt.subplots(1, len(pairs), figsize=(5 * len(pairs), 4.5))
        if len(pairs) == 1:
            axes = [axes]

        for ax, (x, y) in zip(axes, pairs):
            valid = df[[x, y]].dropna()
            ax.scatter(valid[x], valid[y], alpha=0.35, s=20,
                       color="#4c8bf5", edgecolors="white", linewidth=0.3)
            if len(valid) > 2:
                coef = np.polyfit(valid[x], valid[y], 1)
                xs = np.linspace(valid[x].min(), valid[x].max(), 50)
                ax.plot(xs, np.polyval(coef, xs), color="crimson", lw=2)
                r = valid[x].corr(valid[y])
                ax.text(0.05, 0.95, f"r = {r:.3f}", transform=ax.transAxes,
                        va="top", fontsize=11, fontweight="bold",
                        bbox=dict(boxstyle="round", facecolor="white", alpha=0.85))
            ax.set_xlabel(x)
            ax.set_ylabel(y)
            ax.set_title(f"{x} vs {y}", fontsize=12, fontweight="bold")
            ax.grid(alpha=0.3)

        plt.tight_layout()
        chart = "q4_weather.png"
        plt.savefig(config.chart_dir / chart)
        plt.close()
        print(f"  차트: {chart}")

    strongest = corr.abs().idxmax()
    findings.add_section(
        question="Q4. 기상 조건과 미세먼지는 관계가 있는가?",
        evidence=table.to_markdown(),
        conclusion=(
            f"가장 강한 관계는 {strongest} (r = {corr[strongest]:.3f})입니다. "
            f"기상 변수 중에서는 "
            f"{corr.drop('초미세먼지', errors='ignore').abs().idxmax()}의 상관이 가장 큽니다. "
            f"다만 관측 기간이 12일이고 관측 데이터이므로 **인과관계로 해석할 수 없습니다.**"
        ),
        chart=chart,
    )
    findings.limitations.append(
        "기상 변수는 일 단위이고 미세먼지는 측정소 단위여서, "
        "같은 날의 모든 측정소가 동일한 기상값을 갖습니다. "
        "이로 인해 상관이 과대 추정될 수 있습니다."
    )


# ==================== 6) Q5 — 이상 탐지 ====================

def q5_anomaly(df: pd.DataFrame, config: Config, findings: Findings) -> None:
    print("\n" + "=" * 74)
    print("Q5. 평소와 다르게 나빴던 지역·날짜가 있는가?")
    print("=" * 74)

    threshold = df["평균대비"].std() * 2
    unusual = df[df["평균대비"] > threshold].nlargest(10, "평균대비")

    print(f"  기준: 자기 측정소 평균 + {threshold:.1f} (표준편차 2배)")
    print(f"  해당: {len(df[df['평균대비'] > threshold])}건\n")

    if len(unusual):
        print(unusual[["일자", "측정소명", "권역", "미세먼지", "측정소평균",
                       "평균대비", "강수량"]].to_string(index=False))

    by_day = df.groupby("일자")["평균대비"].mean().sort_values(ascending=False)
    print(f"\n  날짜별 평균 편차 상위 3:")
    for day, value in by_day.head(3).items():
        print(f"    {day}: {value:+.2f}")

    chart = None
    if config.make_charts and len(unusual):
        fig, ax = plt.subplots(figsize=(11, 5))
        pivot = df.pivot_table(index="측정소명", columns="일자",
                               values="평균대비", aggfunc="mean")
        im = ax.imshow(pivot.values, cmap="RdYlGn_r", aspect="auto",
                       vmin=-25, vmax=25)
        ax.set_xticks(range(len(pivot.columns)))
        ax.set_xticklabels(pivot.columns, rotation=45, ha="right", fontsize=8)
        ax.set_yticks(range(len(pivot.index)))
        ax.set_yticklabels(pivot.index, fontsize=7)
        ax.set_title("측정소 × 날짜 — 자기 평균 대비 편차",

        fig.colorbar(im, ax=ax, label="평균 대비 편차 (㎍/㎥)")
        plt.tight_layout()
        chart = "q5_anomaly.png"
        plt.savefig(config.chart_dir / chart)
        plt.close()
        print(f"  차트: {chart}")

    top_case = unusual.iloc[0] if len(unusual) else None
    conclusion = (
        f"자기 평균 대비 {threshold:.1f} 이상 높았던 관측이 "
        f"{len(df[df['평균대비'] > threshold])}건 있습니다. "
        + (f"가장 큰 이탈은 {top_case['일자']} {top_case['측정소명']}"
           f"({top_case['미세먼지']:.0f}, 평균 대비 +{top_case['평균대비']:.1f})입니다. "

# ==================== 7) 리포트 생성 ====================

def write_report(df: pd.DataFrame, config: Config, findings: Findings) -> Path:
    """마크다운 리포트를 생성합니다."""
    now = datetime.now()
    lines = [
        f"# 서울시 대기질 EDA 리포트",
        "",
        f"> 생성 일시: {now:%Y-%m-%d %H:%M} · "
        f"분석 기간: {df['측정일시'].min():%Y-%m-%d} ~ {df['측정일시'].max():%Y-%m-%d}",
        "",
        "---",
        "",
        "## 요약",
        "",
    ]
    for i, s in enumerate(findings.summary, start=1):
        lines.append(f"{i}. {s}")

    lines += [
        "",
        "---",
        "",
        "## 데이터",
        "",
        "| 항목 | 값 |",
        "|---|---|",
        f"| 출처 | 서울시 대기질 측정 데이터 (실습용 생성) |",
        f"| 기간 | {df['측정일시'].min():%Y-%m-%d} ~ {df['측정일시'].max():%Y-%m-%d} "
        f"({df['측정일시'].nunique()}일) |",
        f"| 측정소 | {df['측정소명'].nunique()}개 |",
        f"| 권역 | {df['권역'].nunique()}개 |",
        f"| 관측 수 | {len(df):,}건 |",
        f"| 결합 데이터 | 측정소 정보(권역·인구밀도), 일별 날씨 |",
        "",
        "### 정제 내역",
        "",
        "| 단계 | 처리 후 건수 | 설명 |",
        "|---|---|---|",
    ]
    for step in findings.cleaning:
        lines.append(f"| {step['단계']} | {step['건수']} | {step['설명']} |")

    lines += ["", "---", ""]

    for i, section in enumerate(findings.sections, start=1):
        lines += [
            f"## {section['question']}",
            "",
            "### 근거",
            "",
            section["evidence"],
            "",
        ]
        if section["chart"]:
            lines += [f"![{section['question']}](charts/{section['chart']})", ""]
        lines += ["### 결론", "", section["conclusion"], "", "---", ""]

    lines += ["## 한계", ""]
    for lim in findings.limitations:
        lines.append(f"- {lim}")

    lines += [
        "",
        "---",
        "",
        "## 재현 방법",
        "",
        "```bash",
        "pip install -r requirements.txt",
        "python make_data.py          # 실습용 데이터 생성",
        "python make_extra_data.py    # 보조 데이터 생성",
        "python eda.py                # 이 리포트 생성",
        "```",
        "",
        "생성물:",
        "",
        "```",
        f"{config.out_dir}/",
        "├── report.md          이 문서",
        "├── summary.csv        요약 통계",
        "└── charts/            차트 이미지",
        "```",
        "",
    ]

    path = config.out_dir / "report.md"
    path.write_text("\n".join(lines), encoding="utf-8")
    return path


def write_summary_csv(df: pd.DataFrame, config: Config) -> Path:
    """요약 통계를 CSV로 저장합니다."""
    summary = df.groupby(["권역", "측정소명"]).agg(
        관측수=("미세먼지", "count"),
        평균=("미세먼지", "mean"),
        중앙값=("미세먼지", "median"),
        표준편차=("미세먼지", "std"),
        최소=("미세먼지", "min"),
        최대=("미세먼지", "max"),
        초미세평균=("초미세먼지", "mean"),
    ).round(2).reset_index().sort_values("평균", ascending=False)

    path = config.out_dir / "summary.csv"
    summary.to_csv(path, index=False, encoding="utf-8-sig")
    return path


# ==================== 8) 메인 ====================

def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="공공데이터 EDA 리포트 생성")
    parser.add_argument("-o", "--out", type=Path, default=Path("reports"),
                        help="출력 폴더 (기본: reports)")
    parser.add_argument("--air", type=Path, default=Path("data/air_quality_raw.csv"))
    parser.add_argument("--station", type=Path, default=Path("data/station_info.csv"))
    parser.add_argument("--weather", type=Path, default=Path("data/weather.csv"))
    parser.add_argument("--no-charts", action="store_true", help="차트 생성 생략")
    return parser


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)

    config = Config(
        air_path=args.air,
        station_path=args.station,
        weather_path=args.weather,
        out_dir=args.out,
        make_charts=not args.no_charts,
    )

    for path in (config.air_path, config.station_path, config.weather_path):
        if not path.exists():
            print(f"✗ 파일이 없습니다: {path}", file=sys.stderr)
            print("  먼저 make_data.py 와 make_extra_data.py 를 실행하세요.",
                  file=sys.stderr)
            return 1

    config.out_dir.mkdir(parents=True, exist_ok=True)
    if config.make_charts:
        config.chart_dir.mkdir(parents=True, exist_ok=True)
        setup_font()

    findings = Findings()

    df = load_and_clean(config, findings)
    q1_distribution(df, config, findings)
    q2_region(df, config, findings)
    q3_trend(df, config, findings)
    q4_weather(df, config, findings)
    q5_anomaly(df, config, findings)

    print("\n" + "=" * 74)
    print("리포트 생성")
    print("=" * 74)
    report = write_report(df, config, findings)
    summary = write_summary_csv(df, config)
    print(f"  리포트: {report}")
    print(f"  요약  : {summary}")
    if config.make_charts:
        charts = sorted(config.chart_dir.glob("*.png"))
        print(f"  차트  : {len(charts)}개")
        for c in charts:
            print(f"    - {c.name}")

    print("\n" + "=" * 74)
    print("요약")
    print("=" * 74)
    for i, s in enumerate(findings.summary, start=1):
        print(f"  {i}. {s}")

    print(f"\n  한계 {len(findings.limitations)}가지가 리포트에 기록되었습니다.")
    return 0


if __name__ == "__main__":
    sys.exit(main())

노트북은 JSON이고 출력·실행 카운트·메타데이터가 전부 들어 있습니다.

**⑥ 협업 — 충돌이 안 남**

두 사람이 같은 노트북을 고치면 **JSON 병합 충돌**이 나서 수동으로 못 고칩니다.

**그럼 노트북을 안 쓰나요?**

**씁니다. 역할이 다릅니다.**

```
노트북  →  탐색·실험·시각적 확인       (과정)
스크립트 →  확정된 로직·재현·자동화     (결과물)
```

**좋은 흐름**

```
1. 노트북에서 자유롭게 탐색
2. 의미 있는 발견이 나오면 함수로 추출
3. 스크립트에 정리
4. 노트북은 "탐색 기록"으로 커밋 (Restart & Run All 확인 후)
5. 평가·배포 대상은 스크립트

> "모든 결과물은 실행 가능한 패키지·서비스 형태로 만듭니다.

**3.** 여러분의 EDA 리포트를 처음 보는 사람이 신뢰하려면 무엇이 있어야 하나요?

<details>
<summary>답 보기</summary>

**① 데이터의 출처와 범위**

```markdown
| 출처 | 서울열린데이터광장 대기질 정보 |
| 기간 | 2026-08-01 ~ 08-12 (12일) |
| 규모 | 25개 측정소 × 12일 = 300건 |
| 수집 일시 | 2026-08-12 18:30 |
```

**"어떤 데이터로 말하고 있는가"** 를 모르면 결론을 평가할 수 없습니다.

**② 정제 내역과 그 영향**

```markdown
| 단계 | 건수 | 설명 |
|---|---|---|
| 중복 제거 | 300 | 12건 제거 |
| 도메인 규칙 | 300 | 600 초과 8건을 결측 처리 |
| 결측 대치 | 300 | 측정소별 중앙값으로 23건 |

영향: 평균 66.3 → 41.0 (이상치 제거 효과)
```

**"312행이 300행이 된 이유"** 를 설명할 수 있어야 합니다.
특히 **정제가 결론을 바꿨다면** 반드시 밝혀야 합니다.

**③ 질문 → 근거 → 결론의 연결**

```markdown
## Q2. 지역에 따라 다른가?

### 근거
[집계표: 권역별 평균 38.9~43.2, 표준편차 13.0~14.6]
[박스플롯]

### 결론
권역별 평균 차이는 4.2이나, 권역 내 표준편차가 13.9로 더 큽니다.
따라서 지역 효과보다 다른 요인의 영향이 큰 것으로 보입니다.
```

**결론만 있고 근거가 없으면 믿을 수 없고,
근거만 있고 결론이 없으면 읽는 사람이 해석해야 합니다.**

**④ 한계의 솔직한 명시**

```markdown
## 한계
- 12일 관측이라 계절성·장기 추세는 알 수 없습니다.
- 관측 데이터이므로 상관만 확인 가능하며 인과는 주장할 수 없습니다.
- 기상 변수가 일 단위여서 같은 날 모든 측정소가 동일한 값을 가집니다.
  이로 인해 상관이 과대 추정될 수 있습니다.
- 미세먼지 300건 중 23건(7.7%)은 대치한 추정값입니다.
```

**한계를 쓰면 오히려 신뢰가 올라갑니다.**
"이 사람은 자기 분석의 경계를 안다"는 신호이기 때문입니다.

한계가 없는 리포트는 **의심스럽습니다.** 완벽한 데이터는 없습니다.

**⑤ 재현 방법**

```bash
pip install -r requirements.txt
python make_data.py
python eda.py
```

**읽는 사람이 직접 돌려 볼 수 있어야** 최종적으로 신뢰합니다.
"이 숫자가 맞나?" 싶으면 직접 확인할 수 있습니다.

**⑥ 표현의 절제**

| 신뢰를 깎는 표현 | 신뢰를 주는 표현 |
|---|---|
| "명확히 증명되었다" | "~로 보입니다" |
| "A가 B의 원인이다" | "A와 B는 상관이 있습니다 (r=0.4)" |
| "가장 오염된 지역" | "평균이 가장 높은 지역 (43.2, 차이 4.2)" |
| (표본 크기 미표기) | "12일 관측 기준" |

**⑦ 예상과 다른 결과도 기록**

```markdown
Q4에서 강수량과의 상관이 -0.28로 예상보다 약했습니다.
12일 중 강수일이 4일뿐이어서 표본이 부족한 것으로 보입니다.
```

**"안 나왔다"도 결과입니다.** 원하는 결과만 보고하는 리포트는 신뢰할 수 없습니다.

**체크리스트**

- [ ] 데이터 출처·기간·규모가 있는가
- [ ] 정제 내역과 그 영향이 있는가
- [ ] 질문마다 근거(표/차트)와 결론이 연결되는가
- [ ] 차트 제목이 질문에 답하는 문장인가
- [ ] 표본 크기를 결론에 명시했는가
- [ ] 인과를 주장하지 않았는가
- [ ] 한계 섹션이 있는가
- [ ] 재현 명령이 있는가
- [ ] 예상과 다른 결과도 썼는가

**이 체크리스트가 MP1~MP4의 "결과 보고서" 평가 기준과 같습니다.**
