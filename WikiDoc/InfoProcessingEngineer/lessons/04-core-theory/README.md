## 이 문서들을 읽는 법

모든 본문은 같은 자리에서 같은 종류의 내용을 찾을 수 있도록 6블록 + 마무리로 고정되어 있습니다.

| 블록 | 내용 | 규칙 |
|---|---|---|
| ① 학습 목표 | 마치면 할 수 있게 되는 것 | 행동 동사로 3~5개 |
| ② 왜 필요한가 | 이 개념이 없으면 무엇이 안 되는지 + 시험에서의 중요도·출제 형태 | 실패 상황·비유로 동기 부여 |
| ③ 개념 설명 | 용어와 원리 + 반드시 암기할 내용(📌) + 혼동 비교(⚖️) | 개념 정의 → 쉬운 설명 → **시험 표현** → 예시 → 비교 순서 |
| ④ 단계별 실습 | Step 1(🔁 복습 퀴즈) → N | 이론 단원에서는 "설명→용어" 방향의 스피드 훈련과 계산 실습 |
| ⑤ 자주 하는 실수 | 혼동 페어 + 원인 + 해결 | 이론 단원은 에러 대신 **혼동 페어** 중심 |
| ⑥ 확인 문제 | 시험형 변형 문제 3문항 | 답·해설·대표 오답은 `<details>`로 접어 둠 |
| 마무리 | 요약 → 복습 체크리스트 → 과제·다음 강 예고 | 형성평가는 12강 과제 |

**이론 블록 규칙**

- 시험은 "설명을 주고 용어를 쓰게" 하므로, 모든 용어는 **시험 표현(그대로 답안이 되는 문장)** 과 함께 정리합니다.
- 암기 항목은 두문자·비교표로 압축하고, 영역별 중요도·배정 시간은 [커리큘럼 04](../../curriculum/04-core-theory.md)의 표를 따릅니다.
- 저빈출 영역(통합 구현·인터페이스, 신기술·프로젝트 관리)은 용어 수준으로 축소하며 사유를 표기합니다.
