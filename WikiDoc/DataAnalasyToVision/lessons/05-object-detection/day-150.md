## ③ 개념 설명

### ★ 성능 개선 점검 순서 6단계

```
① 라벨 품질
② 데이터 양 · 다양성
③ 해상도 (imgsz)
④ 모델 크기
⑤ 에폭 · 학습률
⑥ 증강
```

**왜 이 순서인가**

| 순위 | 이유 |
|---|---|
| ① 라벨 | ★ **모델 성능의 상한을 정함.** 나쁜 라벨 위에서는 무엇도 안 됨 |
| ② 데이터 | 라벨이 정확해도 양이 적으면 배울 것이 없음 |
| ③ 해상도 | 데이터가 충분해도 **볼 수 없으면** 못 배움 |
| ④ 모델 | 위 셋이 갖춰진 뒤에야 표현력이 병목이 됨 |
| ⑤ 학습 | 미세 조정 |
| ⑥ 증강 | 마지막 짜내기 |

**★ 순서를 어기면 생기는 일**

```
라벨이 나쁜 상태에서 모델을 키우면
  → 나쁜 라벨을 더 잘 외움
  → ★ 오히려 나빠짐

데이터가 적은 상태에서 모델을 키우면
  → 과적합
  → ★ 오히려 나빠짐
```

### ★ seed 변동폭 — 실험의 기준선

```
같은 조건을 seed 만 바꿔 N회 반복
  → mAP 의 표준편차 또는 최대-최소 범위
  → ★ 이 값보다 작은 차이는 노이즈
```

```
측정 예시 (우리 데이터, yolo11n/640/50ep)

  seed 42  →  0.7890
  seed 7   →  0.7712
  seed 99  →  0.8141

  평균     0.7914
  표준편차 0.0176
  범위     0.0429

★ 판정 기준
  차이 < 1σ (0.018)     →  노이즈. 채택 안 함
  차이 1σ~2σ            →  애매. 반복 실험 필요
  차이 > 2σ (0.035)     →  ★ 유의미한 개선
```

**왜 seed 하나로는 안 되는가**

```
seed 가 바꾸는 것
  · 가중치 초기화 (일부 층)
  · 데이터 셔플 순서
  · 증강 난수 (회전 각도, 반전 여부 등)
  · Mosaic 조합

→ ★ 데이터가 적을수록 변동이 큽니다
→ 555장은 매우 적은 편
```

## ④ 단계별 실습

### Step 1. ★ seed 변동폭 측정

```python
"""seed_variance.py — 실험 기준선 확보"""
import platform
from pathlib import Path

import numpy as np
import pandas as pd
from ultralytics import YOLO

DATA = "C:/vision/datasets/cctv_v1/data.yaml"
PROJECT = "C:/vision/runs/w30"
WORKERS = 0 if platform.system() == "Windows" else 8

COMMON = dict(
    data=DATA, epochs=50, imgsz=640, batch=16, device=0,
    workers=WORKERS, patience=0,          # ★ 조기 종료 끔 — 에폭 고정
    deterministic=True, project=PROJECT, exist_ok=True,
    hsv_v=0.5, degrees=8.0, close_mosaic=10, plots=False,
)

SEEDS = [42, 7, 99]
rows = []

for s in SEEDS:
    m = YOLO("yolo11n.pt")
    r = m.train(**COMMON, seed=s, name=f"seed_{s}")
    rows.append({
        "seed": s,
        "mAP50": float(r.box.map50),
        "mAP50-95": float(r.box.map),
        "P": float(r.box.mp),
        "R": float(r.box.mr),
    })

df = pd.DataFrame(rows)

print("=" * 84)
print("★ seed 변동폭 측정 (yolo11n / 640 / 50ep)")
print("=" * 84)
print(df.to_string(index=False, float_format=lambda x: f"{x:.4f}"))
print("-" * 84)
print(f"{'지표':<12}{'평균':>10}{'표준편차':>12}{'최소':>10}{'최대':>10}{'범위':>10}")
print("-" * 84)
for col in ("mAP50", "mAP50-95", "P", "R"):
    v = df[col]
    print(f"{col:<12}{v.mean():>10.4f}{v.std():>12.4f}"
          f"{v.min():>10.4f}{v.max():>10.4f}{v.max()-v.min():>10.4f}")

sigma = df["mAP50"].std()
print(f"""
★ 판정 기준 (mAP50)
   1σ = {sigma:.4f}     차이가 이보다 작으면 → 노이즈, 채택 안 함
   2σ = {2*sigma:.4f}     이보다 크면 → 유의미한 개선

   ★ 앞으로 모든 비교는 이 기준으로 판정합니다
""")

df.to_csv("C:/vision/day150/seed_variance.csv", index=False,
          encoding="utf-8-sig")
print("=" * 84)
```

"""hard_negatives.py — 오검출을 자동 수집해 배경 이미지로"""
from pathlib import Path

import cv2
from ultralytics import YOLO

MODEL = Path("C:/vision/runs/w30/E02_yolo11n_960/weights/best.pt")
BG_VIDEOS = Path("C:/vision/day150/background_videos")   # ★ 사람이 없는 영상

def collect_hard_negatives(model_path, videos, out_dir,
                           conf=0.15, every_sec=1.0, max_per_video=40):
    """객체가 없는 영상에서 검출되는 프레임 = 전부 오검출"""
    out_img = Path(out_dir) / "images"
    out_lbl = Path(out_dir) / "labels"
    out_crop = Path(out_dir) / "crops"
    for d in (out_img, out_lbl, out_crop):
        d.mkdir(parents=True, exist_ok=True)

    model = YOLO(model_path)
    total, saved = 0, 0
    report = []

    for v in sorted(Path(videos).glob("*.mp4")):
        cap = cv2.VideoCapture(str(v))
        fps = cap.get(cv2.CAP_PROP_FPS) or 30
        step = max(1, int(fps * every_sec))
        idx, n_v = 0, 0

        while True:
            ok, frame = cap.read()
            if not ok:
                break
            if idx % step == 0:
                total += 1
                r = model.predict(frame, conf=conf, verbose=False)[0]
                if len(r.boxes):
                    stem = f"hn_{v.stem}_{idx:06d}"
                    cv2.imwrite(str(out_img / f"{stem}.jpg"), frame,
                                [cv2.IMWRITE_JPEG_QUALITY, 92])
                    # ★ 빈 라벨 = 배경 이미지
                    (out_lbl / f"{stem}.txt").write_text("", encoding="utf-8")

                    # 무엇을 착각했는지 크롭 저장
                    for j, b in enumerate(r.boxes):
                        x1, y1, x2, y2 = (int(v_) for v_ in b.xyxy[0].tolist())
                        pad = int(max(x2-x1, y2-y1) * 0.2)
                        h, w = frame.shape[:2]
                        crop = frame[max(0, y1-pad):min(h, y2+pad),
                                     max(0, x1-pad):min(w, x2+pad)]
                        if crop.size:
                            cls = model.names[int(b.cls)]
                            cv2.imwrite(
                                str(out_crop / f"{stem}_{j}_{cls}_"
                                    f"{float(b.conf):.2f}.jpg"), crop)
                    saved += 1
                    n_v += 1
                    report.append((v.name, idx, len(r.boxes),
                                   float(r.boxes.conf.max())))
                    if n_v >= max_per_video:
                        break
            idx += 1
        cap.release()

    return {"검토 프레임": total, "오검출 프레임": saved,
            "오검출률": f"{saved/max(total,1)*100:.1f}%"}, report


stat, report = collect_hard_negatives(MODEL, BG_VIDEOS, OUT)

    for p in HN[:n_add]:
        shutil.copy2(p, dst / "images/train" / p.name)
        (dst / "labels/train" / f"{p.stem}.txt").write_text("", encoding="utf-8")

    for c in (dst / "labels").rglob("*.cache"):
        c.unlink()
    # data.yaml path 갱신 (생략)

    m = YOLO("yolo11n.pt")
    r = m.train(data=str(dst / "data.yaml"), epochs=120, imgsz=960,
                batch=8, seed=42, deterministic=True, patience=0,
                workers=0, project="C:/vision/runs/hn", name=f"hn_{n_add}",
                exist_ok=True)

    n_bg = 46 + n_add
    total = 443 + n_add
    results.append({
        "추가": n_add, "배경 총": n_bg,
        "배경 비율": f"{n_bg/total*100:.1f}%",
        "mAP50": float(r.box.map50), "P": float(r.box.mp),
        "R": float(r.box.mr),
    })

df = pd.DataFrame(results)
print(df.to_string(index=False, float_format=lambda x: f"{x:.4f}"))
```

**1.**
```
.pt   사전학습 가중치. COCO 12만 장으로 학습된 필터를 물려받음
      → 우리 데이터에 맞게 조정만 하면 됨

      → 수렴에 300~500에폭 + 수만 장 필요

**2.**
```
문제
  · Windows는 프로세스를 spawn 방식으로 생성
  · 데이터 로더가 무한 대기하거나 BrokenPipeError

대응 ①  workers=0 으로 설정
대응 ②  학습 코드를 if __name__ == "__main__": 안에 넣음
        (이러면 workers>0 도 동작)
```

**3.**
```
방법
  model = YOLO(".../weights/last.pt")
  model.train(resume=True)

  · resume=True 만 주면 나머지 인자는 args.yaml 에서 자동 로드
  · 중단된 에폭 다음부터 이어서 진행

best.pt 로 안 되는 이유
  · best.pt 에는 ★ 옵티마이저 상태(모멘텀 등)가 없음
  · 학습 스케줄 정보도 없음
  · last.pt 는 이것들을 포함하므로 파일 크기가 2배
```

**4.**
```
box_loss  예측 박스와 정답 박스의 위치·크기 오차 (CIoU 기반)
cls_loss  각 위치의 클래스 예측 오차 (BCE)
dfl_loss  박스 경계를 확률 분포로 학습하는 오차 (Distribution Focal Loss)

"box 정체, cls 감소" 라면
  → 클래스는 맞추는데 ★ 위치를 못 맞춤
  → 의심할 것
      ① 라벨 좌표 오류 (정규화 · W/H 교체 · 증강 시 박스 미변환)
      ② 해상도 부족 (imgsz 상향 검토)
      ③ 라벨 타이트함 불일치
  → ★ train_batch0.jpg 를 열어 박스 위치부터 확인
```

**5.**
```
Ultralytics 규약: 행 = 예측, 열 = 정답

미검출 (FN)  →  ★ background 행
                 (정답은 클래스인데 예측이 background)
                 cm[nc, c]

오검출 (FP)  →  ★ background 열
                 (정답은 background 인데 클래스로 예측)
                 cm[c, nc]

대각선 = TP
대각선 밖 클래스 간 = 클래스 혼동
```

**6.**
```
정답 A = (400, 200, 600, 700)
예측 B = (420, 190, 610, 720)

교집합
  ix1 = max(400, 420) = 420
  iy1 = max(200, 190) = 200
  ix2 = min(600, 610) = 600
  iy2 = min(700, 720) = 700
  iw = 180, ih = 500
  inter = 90,000

면적
  A = 200 × 500 = 100,000
  B = 190 × 530 = 100,700
  union = 100,000 + 100,700 - 90,000 = 110,700

IoU = 90,000 / 110,700 = ★ 0.8130

판정
  IoU 0.5  기준 → 0.813 ≥ 0.5  → ✓ TP
  IoU 0.75 기준 → 0.813 ≥ 0.75 → ✓ TP
```

**7.**
```
mAP@0.5
  IoU 임계값 0.5 하나로 계산
  → "찾았는가" 를 잼

mAP@0.5:0.95
  IoU 0.50, 0.55, ..., 0.95 (10개)에서 각각 계산한 mAP 의 평균
  → ★ "찾았고 박스가 정확한가" 를 잼

비율이 0.5 미만이면
  → ★ 박스 위치·크기가 부정확하다는 뜻
  → 의심할 것
      ① 라벨이 여유 있게 쳐짐 (타이트함 문제)
      ② 회전 증강 각도가 과함 (박스 팽창)
      ③ 해상도 부족
      ④ 작업자 간 기준 불일치

정상 범위는 0.60~0.70
```

**8.**
```
iou 0.45 → 0.7 로 올리면

  · NMS 가 "이만큼 겹치면 지운다"는 기준이 완화됨
  · ★ 억제가 약해짐 → 박스가 더 많이 남음

해결되는 문제
  ★ 겹쳐 서 있는 두 객체가 하나로 병합되던 현상
    (두 사람의 IoU 가 0.5~0.6 이면 0.45 기준에서는 하나가 지워짐)

부작용
  · 같은 객체에 대한 중복 박스가 늘어남
  · Precision 하락
  · (실측 예) Precision 0.834 → 0.820, Recall 0.728 → 0.731
```

**9.**
```
① 라벨 품질
② 데이터 양·다양성
③ 해상도 (imgsz)
④ 모델 크기
⑤ 에폭·학습률
⑥ 증강

라벨이 1순위인 이유
  · ★ 모델 성능의 상한을 정하기 때문
  · 라벨이 모순되면 모델은 그 모순을 그대로 학습
  · 나쁜 라벨 위에서 모델을 키우면 ★ 오히려 나빠짐
    (나쁜 라벨을 더 잘 외움)
  · 실측 효과: 라벨 개선 +0.15 vs 학습률 튜닝 +0.01 (15배)
  · 특히 ★ 라벨 누락은 "덜 배우는" 것이 아니라
    "틀린 것을 배우는" 것 (그 자리를 배경으로 학습)
```

**10.**
```
차이 = 0.840 - 0.821 = 0.019
σ 배수 = 0.019 / 0.022 = 0.86σ

★ 결론: 노이즈. B를 채택하지 않는다

이유
  · 같은 조건을 seed 만 바꿔 돌려도 0.022(1σ) 만큼 흔들림
  · 0.019 는 그보다 작은 차이
  · 즉 B가 좋아 보이는 것은 ★ 우연일 가능성이 높음

판정 기준
  차이 < 1σ         → 노이즈. 채택 안 함
  1σ ≤ 차이 < 2σ    → 애매. 반복 실험 필요
  차이 ≥ 2σ         → 유의미한 개선

추가 조치
  · 꼭 판단이 필요하면 B를 seed 3개로 반복
  · 평균이 A 평균보다 2σ 이상 높은지 확인
  · 또는 ★ 다른 축(데이터·라벨)으로 방향 전환
```
