## ② 왜 필요한가

같은 문제도 자료구조를 잘못 고르면 코드가 세 배로 길어집니다.

**예 — "방문자 중 재방문자를 찾아라"**

```python
# 리스트로 (느리고 길다)
visitors = ["A", "B", "A", "C", "B", "A"]
repeat = []
for v in visitors:
    if visitors.count(v) > 1 and v not in repeat:
        repeat.append(v)
```

```python
# 딕셔너리로 (짧고 빠르다)
counter = {}
for v in visitors:
    counter[v] = counter.get(v, 0) + 1
repeat = [k for k, c in counter.items() if c > 1]
```

**"어떤 자료구조를 쓸 것인가"는 코드를 치기 전에 결정하는 일**입니다.
오늘 그 판단 기준을 정리하고, 3주 동안 배운 것을 하나로 합칩니다.

## ③ 개념 설명

### 네 가지 자료구조 비교

| | 리스트 `[]` | 튜플 `()` | 세트 `{}` | 딕셔너리 `{k:v}` |
|---|---|---|---|---|
| 순서 | ✅ 있음 | ✅ 있음 | ❌ 없음 | ✅ 입력 순서 유지 |
| 중복 | ✅ 허용 | ✅ 허용 | ❌ 자동 제거 | 키는 ❌ / 값은 ✅ |
| 수정 | ✅ 가능 | ❌ 불가 | ✅ 가능 | ✅ 가능 |
| 인덱싱 | `lst[0]` | `tup[0]` | ❌ 불가 | `d["키"]` |
| 값 찾기 속도 | 느림 (O(n)) | 느림 | **빠름 (O(1))** | **빠름 (O(1))** |

> **"빠름 / 느림"의 의미** — 리스트에서 `x in lst` 는 처음부터 하나씩 다 비교합니다. 10만 개면 10만 번 비교합니다.
> 세트·딕셔너리는 값을 직접 계산해 찾아가므로 개수와 무관하게 거의 일정합니다.
> 데이터가 수만 건이 되는 대단원 02부터 이 차이가 체감됩니다.

### 선택 기준 — 이 순서로 물어보세요

```
1. 이름표(키)로 찾아야 하나?          → 예: 딕셔너리
2. 중복을 없애야 하나? 포함 여부만?    → 예: 세트
3. 절대 바뀌면 안 되나?               → 예: 튜플
4. 그 외 순서 있는 목록               → 리스트
```

### 상황별 정답표

| 상황 | 자료구조 | 이유 |
|---|---|---|
| 학생 30명의 점수 목록 | 리스트 | 순서 있고, 중복 가능 |
| 이름으로 학생 찾기 | 딕셔너리 | 이름이 키 |
| 화면 크기 `(800, 600)` | 튜플 | 안 바뀜 |
| 중복 없는 방문자 명단 | 세트 | 중복 제거 |
| 게임 캐릭터 정보 | 딕셔너리 | 항목마다 이름이 있음 |
| 로또 번호 6개 | 리스트 (뽑을 때 세트) | 정렬해서 보여 줌 |
| 좌표 `(x, y)` | 튜플 | 안 바뀜 + 세트/키에 넣을 수 있음 |
| 성적표 여러 명 | **딕셔너리들의 리스트** | 표 데이터의 표준형 |
| 단어 빈도 | 딕셔너리 | 단어가 키, 횟수가 값 |
| 금지어 목록 (포함 검사만) | 세트 | 검사가 빠름 |

### 표 데이터의 두 가지 표현

같은 데이터를 두 방식으로 담을 수 있습니다. **둘 다 알아야 합니다.**

```python
# (A) 딕셔너리들의 리스트 — 행 중심
students = [
    {"이름": "홍길동", "국어": 85, "영어": 90},
    {"이름": "김철수", "국어": 92, "영어": 88},
]

# (B) 딕셔너리 (이름이 키) — 조회 중심
students = {
    "홍길동": {"국어": 85, "영어": 90},
    "김철수": {"국어": 92, "영어": 88},
}
```

| | (A) 리스트 방식 | (B) 딕셔너리 방식 |
|---|---|---|
| 순서 | 유지됨 | 입력 순서 유지 |
| 이름으로 찾기 | 전체를 훑어야 함 (느림) | `students["홍길동"]` (빠름) |
| 같은 이름 여러 명 | 가능 | 불가능 (덮어씀) |
| CSV 저장 | 자연스러움 | 변환 필요 |
| 대단원 02 | `pd.DataFrame(students)` 로 바로 변환 | 변환 한 단계 더 |

> **판단 기준** — "이름으로 자주 찾는가?" 면 (B), "순서대로 처리하고 파일로 저장하는가?" 면 (A).

### Step 2. 속도 차이 직접 확인하기

```python
import time

SIZE = 100_000

data_list = list(range(SIZE))
data_set = set(range(SIZE))

# 리스트에서 마지막 값 찾기
start = time.time()
for _ in range(1000):
    result = (SIZE - 1) in data_list
list_time = time.time() - start

# 세트에서 마지막 값 찾기
start = time.time()
for _ in range(1000):
    result = (SIZE - 1) in data_set
set_time = time.time() - start

print(f"리스트에서 1000번 검색: {list_time:.4f}초")
print(f"세트에서   1000번 검색: {set_time:.6f}초")
print(f"세트가 약 {list_time / set_time:.0f}배 빠릅니다")
```

### Step 3. W03 종합 — 도서 관리 프로그램

지금까지 배운 것을 전부 쓰는 프로그램입니다.

```python
import json
import os

DB_FILE = "books.json"


# ══════════ 데이터 입출력 ══════════

def load_books():
    """저장된 도서 목록을 불러옵니다."""
    if not os.path.exists(DB_FILE):
        return []
    try:
        with open(DB_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        print("⚠ 데이터 파일이 손상되어 새로 시작합니다.")
        return []


def save_books(books):
    """도서 목록을 저장합니다."""
    try:
        with open(DB_FILE, "w", encoding="utf-8") as f:
            json.dump(books, f, ensure_ascii=False, indent=2)
        return True
    except Exception as e:
        print(f"⚠ 저장 실패: {e}")
        return False


# ══════════ 입력 도우미 ══════════

def input_text(prompt, allow_empty=False):
    """비어 있지 않은 문자열을 입력받습니다."""
    while True:
        value = input(prompt).strip()
        if value or allow_empty:
            return value
        print("  → 내용을 입력해 주세요.")


def input_int(prompt, low=None, high=None):
    """정수를 입력받습니다."""
    while True:
        try:
            value = int(input(prompt))
            if low is not None and value < low:
                print(f"  → {low} 이상이어야 합니다.")
                continue
            if high is not None and value > high:
                print(f"  → {high} 이하여야 합니다.")
                continue
            return value
        except ValueError:
            print("  → 숫자를 입력해 주세요.")


# ══════════ 기능 ══════════

def add_book(books):
    """도서를 추가합니다."""
    title = input_text("제목: ")

    # 중복 검사 — 제목 세트를 만들어 빠르게 확인
    titles = {b["title"] for b in books}
    if title in titles:
        print(f"→ '{title}' 은(는) 이미 등록되어 있습니다.")
        return

    book = {
        "title": title,
        "author": input_text("저자: "),
        "year": input_int("출판연도: ", low=1000, high=2100),
        "tags": [t.strip() for t in input_text("태그(콤마 구분): ").split(",") if t.strip()],
        "borrowed": False,
    }

    books.append(book)
    save_books(books)
    print(f"→ '{title}' 등록 완료.")


def show_books(books, filtered=None):
    """도서 목록을 출력합니다."""
    target = books if filtered is None else filtered

    print("\n" + "=" * 62)
    print(f"{'번호':<5}{'제목':<20}{'저자':<12}{'연도':>6}{'상태':>8}")
    print("-" * 62)

    if not target:
        print("  (도서가 없습니다)")
    else:
        for i, b in enumerate(target, start=1):
            status = "대출중" if b["borrowed"] else "대출가능"
            print(f"{i:<5}{b['title']:<20}{b['author']:<12}{b['year']:>6}{status:>8}")

    print("-" * 62)
    borrowed = sum(1 for b in target if b["borrowed"])
    print(f"총 {len(target)}권 · 대출중 {borrowed}권 · 대출가능 {len(target) - borrowed}권")
    print("=" * 62)


def search_books(books):
    """제목·저자·태그로 검색합니다."""
    keyword = input_text("검색어: ").lower()

    result = [
        b for b in books
        if keyword in b["title"].lower()
        or keyword in b["author"].lower()
        or any(keyword in t.lower() for t in b["tags"])
    ]

    if not result:
        print(f"→ '{keyword}' 검색 결과가 없습니다.")
    else:
        print(f"→ '{keyword}' 검색 결과 {len(result)}건")
        show_books(books, result)


def toggle_borrow(books):
    """대출/반납 상태를 바꿉니다."""
    if not books:
        print("→ 등록된 도서가 없습니다.")
        return

    show_books(books)
    num = input_int(f"번호 선택(1~{len(books)}): ", low=1, high=len(books))
    book = books[num - 1]

    book["borrowed"] = not book["borrowed"]
    save_books(books)

    action = "대출" if book["borrowed"] else "반납"
    print(f"→ '{book['title']}' {action} 처리했습니다.")


def show_stats(books):
    """통계를 출력합니다."""
    if not books:
        print("→ 등록된 도서가 없습니다.")
        return

    # 저자별 권수 — 딕셔너리 누적
    by_author = {}
    for b in books:
        by_author[b["author"]] = by_author.get(b["author"], 0) + 1

    # 태그 집계 — 세트로 고유 태그, 딕셔너리로 횟수
    tag_count = {}
    for b in books:
        for t in b["tags"]:
            tag_count[t] = tag_count.get(t, 0) + 1

    years = [b["year"] for b in books]

    print("\n" + "=" * 40)
    print("               통계")
    print("=" * 40)
    print(f"전체 도서:   {len(books)}권")
    print(f"고유 저자:   {len(by_author)}명")
    print(f"출판연도:    {min(years)} ~ {max(years)}")
    print(f"평균 연도:   {sum(years) / len(years):.0f}")

    print("\n[저자별 보유 권수]")
    for author, count in sorted(by_author.items(), key=lambda x: x[1], reverse=True):
        print(f"  {author:<12} {'▇' * count} {count}권")

    if tag_count:
        print("\n[인기 태그]")
        for tag, count in sorted(tag_count.items(), key=lambda x: x[1], reverse=True)[:5]:
            print(f"  #{tag:<10} {count}회")

    print("=" * 40)


# ══════════ 메인 ══════════

books = load_books()

print("=" * 62)
print("                    도서 관리 시스템")
print("=" * 62)
print(f"저장된 도서 {len(books)}권을 불러왔습니다.")

while True:
    print("\n1. 목록  2. 추가  3. 검색  4. 대출/반납  5. 통계  6. 종료")
    menu = input("> ").strip()

    if menu == "1":
        show_books(books)
    elif menu == "2":
        add_book(books)
    elif menu == "3":
        search_books(books)
    elif menu == "4":
        toggle_borrow(books)
    elif menu == "5":
        show_stats(books)
    elif menu == "6":
        save_books(books)
        print("→ 저장 후 종료합니다.")
        break
    else:
        print("→ 1~6 중에서 선택해 주세요.")
```

## ⑤ 자주 하는 실수

### 자료구조를 잘못 골라 코드가 길어짐

```python
# ❌ 리스트로 개수 세기 (느리고 김)
counts = []
for word in words:
    found = False
    for c in counts:
        if c[0] == word:
            c[1] += 1
            found = True
            break
    if not found:
        counts.append([word, 1])

# ✅ 딕셔너리로 (짧고 빠름)
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
```

**판단 요령** — "무언가를 세거나 이름으로 찾는다" 면 거의 항상 딕셔너리입니다.

### 큰 리스트에 `in` 을 반복 사용

```python
seen = []
for item in huge_data:          # 10만 건
    if item not in seen:        # 매번 전체를 훑음 → 매우 느림
        seen.append(item)
```

**해결** — 세트를 씁니다.

```python
seen = set()
for item in huge_data:
    if item not in seen:        # 즉시 판정
        seen.add(item)
```

### 딕셔너리 키를 리스트로 만들려 함

```python
d = {}
d[["a", "b"]] = 1               # TypeError: unhashable type: 'list'
```

**해결** — 튜플로 바꿉니다. `d[("a", "b")] = 1`

### 표 데이터 구조를 중간에 바꿈

```python
# 처음엔 리스트 방식
students = [{"name": "홍길동", "score": 85}]

# 나중에 딕셔너리 방식이 편해 보여서 섞어 씀
students["김철수"] = {"score": 92}    # TypeError
```

**해결** — **시작할 때 구조를 정하고 끝까지 유지**하세요. 바꿔야 한다면 변환 함수를 만듭니다.

```python
def to_dict(students):
    """리스트 방식 → 딕셔너리 방식"""
    return {s["name"]: {k: v for k, v in s.items() if k != "name"} for s in students}
```

**2. [종합 구현]** 아래 요구사항을 만족하는 **투표 집계 프로그램**을 작성하세요.

- 후보자 목록을 미리 정한다 (변경 불가)
- 투표를 반복해서 받는다. `q` 를 입력하면 종료
- 잘못된 후보 이름은 무효 처리하고 계속 진행 (프로그램이 죽지 않아야 함)
- 종료 시 득표수 순으로 결과를 출력하고, 득표율과 막대그래프를 함께 보인다
- 결과를 JSON 파일로 저장한다

<details>
<summary>답 보기</summary>

```python
import json

CANDIDATES = ("김파이", "이썬", "박코딩")      # 튜플 — 변경 불가
RESULT_FILE = "vote_result.json"


def collect_votes(candidates):
    """투표를 받아 후보별 득표수 딕셔너리를 반환합니다."""
    votes = {name: 0 for name in candidates}     # 딕셔너리 컴프리헨션
    invalid = 0
    valid_set = set(candidates)                  # 빠른 검사를 위해 세트로

    print("후보:", " / ".join(candidates))
    print("투표할 후보 이름을 입력하세요. (종료: q)")

    while True:
        answer = input("> ").strip()

        if answer.lower() == "q":
            break

        if not answer:
            print("  → 이름을 입력해 주세요.")
            continue

        if answer not in valid_set:
            invalid += 1
            print(f"  → '{answer}' 은(는) 후보가 아닙니다. (무효표 {invalid}표)")
            continue

        votes[answer] += 1
        print(f"  → {answer} 투표 완료. (현재 {votes[answer]}표)")

    return votes, invalid


def show_result(votes, invalid):
    """결과를 출력합니다."""
    total = sum(votes.values())

    print("\n" + "=" * 44)
    print("                투표 결과")
    print("=" * 44)

    if total == 0:
        print("  투표가 없습니다.")
        print("=" * 44)
        return

    ranked = sorted(votes.items(), key=lambda x: x[1], reverse=True)

    for rank, (name, count) in enumerate(ranked, start=1):
        rate = count / total * 100
        bar = "█" * int(rate / 4)
        print(f"  {rank}위  {name:<8} {bar:<25} {count:>3}표 ({rate:5.1f}%)")

    print("-" * 44)
    print(f"  유효표 {total}표 · 무효표 {invalid}표")

    # 동점 처리
    top_count = ranked[0][1]
    winners = [name for name, c in ranked if c == top_count]

    if len(winners) == 1:
        print(f"  당선: {winners[0]}")
    else:
        print(f"  동점: {', '.join(winners)} — 재투표 필요")

    print("=" * 44)


def save_result(votes, invalid):
    """결과를 JSON으로 저장합니다."""
    data = {
        "candidates": list(CANDIDATES),
        "votes": votes,
        "invalid": invalid,
        "total": sum(votes.values()),
    }

    try:
        with open(RESULT_FILE, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        print(f"→ 결과를 {RESULT_FILE} 에 저장했습니다.")
    except Exception as e:
        print(f"→ 저장 실패: {e}")


# ── 실행 ──
votes, invalid = collect_votes(CANDIDATES)
show_result(votes, invalid)
save_result(votes, invalid)
```

투표할 후보 이름을 입력하세요. (종료: q)

**채점 포인트 6가지**
- [ ] 후보 목록을 **튜플**로 만들었는가 (변경 불가)
- [ ] 득표 집계를 **딕셔너리**로 했는가
- [ ] 후보 검사에 **세트**를 썼는가 (또는 그 이유를 설명할 수 있는가)
- [ ] 잘못된 입력에도 프로그램이 **죽지 않는가**
- [ ] `total == 0` 인 경우를 처리했는가 (`ZeroDivisionError` 방지)
- [ ] JSON 저장 시 `ensure_ascii=False` 를 넣었는가

**버그 ① — `load_scores` 에 인코딩과 예외 처리가 없음**

파일이 없으면 `FileNotFoundError` 로 프로그램이 죽고, 한글이 있으면 `UnicodeDecodeError` 가 납니다.

```python
import os

def load_scores(filename):
    """점수를 불러옵니다. 파일이 없으면 빈 딕셔너리."""
    if not os.path.exists(filename):
        return {}
    try:
        with open(filename, "r", encoding="utf-8") as f:      # encoding 추가
            return json.load(f)
    except json.JSONDecodeError:
        print("⚠ 파일이 손상되었습니다.")
        return {}
```

**버그 ② — `add_score` 에서 없는 키에 접근**

`scores["홍길동"]` 이 없으면 `KeyError` 가 납니다.

```python
def add_score(scores, name, value):

    scores[name] = scores.get(name, 0) + value      # get 으로 안전하게

```

**수정된 전체 코드**

```python
import json
import os


def load_scores(filename):
    """점수를 불러옵니다. 파일이 없으면 빈 딕셔너리."""
    if not os.path.exists(filename):
        return {}
    try:
        with open(filename, "r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        print("⚠ 파일이 손상되었습니다.")
        return {}


def add_score(scores, name, value):
    """점수를 더합니다. 없으면 새로 만듭니다."""
    scores[name] = scores.get(name, 0) + value
    return scores


def get_top(scores, n=3):
    """상위 n개를 반환합니다."""
    ranked = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return ranked[:n]


scores = load_scores("scores.json")
scores = add_score(scores, "홍길동", 100)
scores = add_score(scores, "김철수", 250)
scores = add_score(scores, "홍길동", 50)

print(get_top(scores))          # [('김철수', 250), ('홍길동', 150)]
```

## 오늘의 정리 · W03 총정리

### 자료구조 선택 4단계

```
1. 이름표로 찾나?      → 딕셔너리
2. 중복 제거 / 포함검사? → 세트
3. 바뀌면 안 되나?      → 튜플
4. 그 외 순서 있는 목록  → 리스트
```
