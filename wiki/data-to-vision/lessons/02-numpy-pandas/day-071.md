**그런데 프로젝트가 실패하는 이유는 기술이 아닙니다.**

| 실패 원인 | 증상 | 발생 시점 |
|---|---|---|
| **질문이 없음** | "데이터는 모았는데 뭘 보여 주지?" | 목요일 |
| **데이터를 못 구함** | "그 사이트 크롤링이 막혀 있어요" | 화요일 |

| **범위가 큼** | "전국 데이터 10만 건 수집할게요" | 금요일 |

```

       ↓ 실제로 구해지나?
   [오늘 검증] ← 여기까지 오늘 안에 끝냅니다
```

> **오늘 하루의 목표는 "월요일에 방향을 확정하는 것"** 입니다.

## 2부 · 분석 질문

### 한 문장 정의

```
[누구]에게 [어떤 기준]으로 [무엇]을 추천한다.
```

**예시**

```
✅ "부산을 처음 방문하는 20대 뚜벅이에게, 지하철역 도보 15분 이내이면서
    가성비가 좋은 관광지 5곳을 추천한다."

❌ "관광 데이터를 분석해 인사이트를 도출한다."
   → 누구? 어떤 기준? 무엇을?
```

### 좋은 질문의 조건 5가지

| # | 조건 | 확인 방법 |
|---|---|---|
| ① | **대상이 구체적** | "사용자" ❌ → "20대 뚜벅이" ✅ |
| ② | **기준이 측정 가능** | "좋은 곳" ❌ → "평점 4.0 이상, 5천원 이하" ✅ |
| ③ | **출력이 명확** | "인사이트" ❌ → "5곳 목록 + 지도" ✅ |
| ④ | **데이터로 답할 수 있음** | 필요한 데이터가 실제로 존재하는가 |
| ⑤ | **5일 안에 가능** | 범위가 감당 가능한가 |

### 질문에서 데이터로

```
질문: "지하철역 도보 15분 이내이면서 가성비가 좋은 곳"
         ↓ 분해
필요한 것:
  · 관광지 위치 (위도·경도)      ← TourAPI
  · 지하철역 위치               ← 공공데이터포털
  · 입장료                      ← TourAPI (detailIntro)
  · 평점                        ← 크롤링 또는 대체 지표
         ↓
계산해야 할 것:
  · 최근접 지하철역까지 거리 → 도보 시간 (1.2km ≈ 15분)
  · 가성비 점수 = f(평점, 가격)
```

> **질문 → 필요한 데이터 → 계산**으로 분해하세요.
> 여기서 "구할 수 없는 데이터"가 드러나면 **질문을 바꿔야** 합니다.

### 확보 가능성 검증 — 오늘 반드시

```
"있을 것 같다"  ❌
"3건 받아 봤다" ✅
```

**최소 검증 3단계**

```
① 접속되나          응답 코드 200인가
② 데이터가 오나      3건만 요청해서 눈으로 확인
③ 필요한 필드가 있나  우리가 쓸 열이 실제로 들어 있나
```

> ⚠️ **"공공데이터포털에 있으니까 되겠지"가 가장 위험합니다.**
> 실제로는 이런 일이 흔합니다.
> - 승인에 3일 걸림 → 프로젝트가 끝남
> - 필드는 있는데 **90%가 결측**
> - 문서와 실제 응답이 다름
> - 서울만 있고 부산은 없음

## 2. 분석 질문

### 2-1. 한 문장

> **부산을 처음 방문하는 20대 뚜벅이(대중교통 이용자)에게,
> 지하철역에서 도보 15분 이내이면서 가성비가 좋은 관광지 5곳을 추천한다.**

### 2-2. 왜 이 질문인가

- 20대의 부산 여행은 렌터카 없이 대중교통으로 다니는 비중이 높다
- 기존 추천은 "유명한 곳" 위주여서 **접근성이 반영되지 않는다**
- 도보 접근성 + 가성비를 결합한 추천은 흔하지 않다

### 2-3. 세부 질문 3가지

| # | 질문 | 답하는 방법 |
|---|---|---|
| 1 | 지하철역 접근성이 좋은 관광지는 어디에 몰려 있나? | 지도 + 밀집도 |
| 2 | 접근성과 가격·평점은 관련이 있나? | 상관 분석 + 산점도 |
| 3 | 카테고리별로 접근성이 다른가? | 그룹 비교 + 박스플롯 |

### 2-4. 최종 산출물

- 조건 입력 → **추천 5곳 표**
- **지도 HTML** (추천 5곳 + 지하철역 + 도보권 원)
- 분석 보고서 (질문–데이터–방법–결과–한계)

"""오늘 반드시 — 데이터가 실제로 구해지는지 확인합니다."""

import json
import os

from pathlib import Path

from dotenv import load_dotenv

load_dotenv()

CHECK_DIR = Path("data/feasibility")
CHECK_DIR.mkdir(parents=True, exist_ok=True)

HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                   "AppleWebKit/537.36 (KHTML, like Gecko) "
                   "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)")

def check_source(name, fetch_fn, required_fields, min_count=1,
                 plan_b=None, verbose=True):
    """
    데이터 소스의 확보 가능성을 검증합니다.

    fetch_fn        : 샘플 데이터를 가져오는 함수 → list[dict]
    required_fields : 반드시 있어야 하는 필드
    plan_b          : 실패 시 대안 설명
    """
    result = {
        "소스": name, "상태": "❌ 실패", "건수": 0,
        "필드누락": [], "결측필드": [], "소요": 0.0,
        "메모": "", "대안": plan_b or "-",
    }

    t0 = time.perf_counter()

    try:
        records = fetch_fn()
    except Exception as e:
        result["메모"] = f"{type(e).__name__}: {str(e)[:60]}"
        result["소요"] = time.perf_counter() - t0

        if verbose:
            print(f"\n  ❌ {name}")
            print(f"     오류: {result['메모']}")
            if plan_b:
                print(f"     → Plan B: {plan_b}")
        return result

    result["소요"] = time.perf_counter() - t0
    result["건수"] = len(records)

    if not records:
        result["메모"] = "응답은 왔으나 데이터가 0건"
        if verbose:
            print(f"\n  ⚠ {name} — 데이터 0건")
            if plan_b:
                print(f"     → Plan B: {plan_b}")
        return result

    # ── 필드 존재 확인 ──
    keys = set(records[0].keys())
    missing = [f for f in required_fields if f not in keys]
    result["필드누락"] = missing

    # ── 결측률 확인 (샘플 기준) ──
    empty_fields = []
    for f in required_fields:
        if f in keys:
            filled = sum(1 for r in records
                         if r.get(f) not in (None, "", [], {}))
            rate = filled / len(records)
            if rate < 0.5:
                empty_fields.append(f"{f}({rate*100:.0f}%)")

    result["결측필드"] = empty_fields

    if missing:
        result["상태"] = "⚠ 필드 부족"
    elif empty_fields:
        result["상태"] = "⚠ 결측 많음"
    elif len(records) < min_count:
        result["상태"] = "⚠ 건수 부족"
    else:
        result["상태"] = "✅ 확보 가능"

    # ── 샘플 저장 (증거) ──
    sample_path = CHECK_DIR / f"sample_{name.replace(' ', '_')}.json"
    sample_path.write_text(
        json.dumps(records[:3], ensure_ascii=False, indent=2),
        encoding="utf-8")

    if verbose:
        print(f"\n  {result['상태']} {name}")
        print(f"     건수    : {len(records)}건 ({result['소요']:.1f}초)")
        print(f"     필드    : {len(keys)}개")

        if missing:
            print(f"     ⚠ 누락  : {missing}")
        if empty_fields:
            print(f"     ⚠ 결측  : {empty_fields}")
        if (missing or empty_fields) and plan_b:
            print(f"     → Plan B: {plan_b}")

        print(f"     샘플    : {sample_path}")
        print(f"     첫 레코드:")
        for k, v in list(records[0].items())[:6]:
            print(f"       {k:<16}{str(v)[:44]}")

    return result

def fetch_tourapi():
    """TourAPI 관광지 3건."""
    key = os.getenv("DATA_GO_KR_KEY")
    if not key:
        raise RuntimeError("DATA_GO_KR_KEY 없음 — .env 확인")

    res = requests.get(
        "http://apis.data.go.kr/B551011/KorService1/areaBasedList1",
        params={"serviceKey": key, "numOfRows": 3, "pageNo": 1,
                "MobileOS": "ETC", "MobileApp": "Project",
                "_type": "json", "areaCode": 6, "contentTypeId": 12},
        headers=HEADERS, timeout=15)
    res.raise_for_status()

    if res.text.lstrip().startswith("<"):
        raise RuntimeError("XML 응답 — _type 확인")

    data = res.json()
    header = data.get("response", {}).get("header", {})

    if str(header.get("resultCode", "")).strip() not in ("00", "0000"):
        raise RuntimeError(f"API 오류 [{header.get('resultCode')}] "
                           f"{header.get('resultMsg')}")

    items = data["response"]["body"].get("items")
    if not items:
        return []

    item = items.get("item") if isinstance(items, dict) else items
    return [item] if isinstance(item, dict) else item


def fetch_tourapi_detail():
    """TourAPI 상세 (요금 필드 확인) — Must 항목의 핵심 검증."""
    key = os.getenv("DATA_GO_KR_KEY")
    if not key:
        raise RuntimeError("DATA_GO_KR_KEY 없음")

    base = fetch_tourapi()
    if not base:
        raise RuntimeError("기본 정보를 못 받아 상세 확인 불가")

    results = []
    for item in base[:3]:
        time.sleep(0.3)
        res = requests.get(
            "http://apis.data.go.kr/B551011/KorService1/detailIntro1",
            params={"serviceKey": key, "MobileOS": "ETC",
                    "MobileApp": "Project", "_type": "json",
                    "contentId": item["contentid"],
                    "contentTypeId": item.get("contenttypeid", 12)},
            headers=HEADERS, timeout=15)

        if not res.ok or res.text.lstrip().startswith("<"):
            continue

        body = res.json().get("response", {}).get("body", {})
        its = body.get("items")
        if not its:
            continue

        it = its.get("item") if isinstance(its, dict) else its
        it = it[0] if isinstance(it, list) and it else it

        if isinstance(it, dict):
            results.append(it)

    return results


def fetch_kakao_geocode():
    """카카오 지오코딩 3건."""
    key = os.getenv("KAKAO_REST_KEY")
    if not key:
        raise RuntimeError("KAKAO_REST_KEY 없음 — .env 확인")

    samples = ["부산광역시 해운대구 우동", "부산광역시 중구 광복로",
               "부산광역시 사하구 감내2로 203"]
    out = []

    for addr in samples:
        time.sleep(0.15)
        res = requests.get(
            "https://dapi.kakao.com/v2/local/search/address.json",
            params={"query": addr, "size": 1},
            headers={"Authorization": f"KakaoAK {key}"}, timeout=10)
        res.raise_for_status()

        docs = res.json().get("documents", [])
        if docs:
            out.append({"query": addr, "x": docs[0]["x"],
                        "y": docs[0]["y"],
                        "address_name": docs[0]["address_name"]})

    return out

def check_robots(url):

### 일정에 여유가 없음

**해결** — Could 항목은 **포기해도 되는 것**으로만 채웁니다.

```python
"""프로젝트 기획서 점검."""

import re
from pathlib import Path

import pandas as pd


def audit_plan(path, verbose=True):
    """
    기획서(Markdown)의 완성도를 점검합니다.

    반환: dict(score, missing, warnings)
    """
    text = Path(path).read_text(encoding="utf-8")

    checks = []
    warnings_list = []

    def check(category, item, ok, weight=1, hint=""):
        checks.append({"구분": category, "항목": item, "충족": ok,
                       "가중치": weight, "힌트": hint})
        return ok

    # ══════════ ① 팀 ══════════
    has_roles = all(re.search(kw, text) for kw in ("수집", "전처리", "시각화"))
    check("팀", "역할 4분할 명시", has_roles, 2,
          "수집/전처리/시각화/발표 담당자를 표로")

    check("팀", "GitHub 저장소", bool(re.search(r"github|저장소|repo", text, re.I)),
          1, "저장소 주소와 브랜치 규칙")

    check("팀", "협업 규칙", bool(re.search(r"스탠드업|매일|커밋|브랜치", text)),
          1, "매일 스탠드업·커밋 시각")

    # ══════════ ② 질문 ══════════
    # "누구에게 ~ 추천한다" 패턴
    has_target = bool(re.search(
        r"(\d+대|가족|시니어|외국인|커플|혼자|뚜벅이|초보)", text))
    check("질문", "대상이 구체적", has_target, 3,
          "'사용자' 말고 '20대 뚜벅이'처럼")

    has_criteria = bool(re.search(
        r"\d+\s*(원|분|km|점|시간)\s*(이내|이하|이상)", text))
    check("질문", "기준이 측정 가능", has_criteria, 3,
          "'좋은' 말고 '5천원 이하'처럼 숫자로")

    has_output = bool(re.search(r"\d+\s*곳|목록|지도|표", text))
    check("질문", "출력이 명확", has_output, 2,
          "'인사이트' 말고 '5곳 목록 + 지도'")

    has_sub = len(re.findall(r"세부 질문|질문\s*\d", text)) > 0
    check("질문", "세부 질문 3개", has_sub, 1, "큰 질문을 3개로 분해")

    # ══════════ ③ 데이터 ══════════
    has_sources = bool(re.search(r"TourAPI|공공데이터|API|크롤링", text))
    check("데이터", "소스 명시", has_sources, 2, "어디서 구할 것인가")

    has_verify = bool(re.search(r"검증|확인|✅|3건|샘플", text))
    check("데이터", "확보 검증 결과", has_verify, 3,
          "'있을 것 같다' 말고 '3건 받아 봤다'")

    has_plan_b = bool(re.search(r"Plan B|대안|플랜 ?B", text, re.I))
    check("데이터", "Plan B", has_plan_b, 3,
          "Must 데이터마다 대안이 있어야")

    has_fields = bool(re.search(r"필드|열|컬럼", text))
    check("데이터", "필요 필드 목록", has_fields, 1, "쓸 열을 미리 정의")

    has_license = bool(re.search(r"라이선스|이용약관|출처|robots", text, re.I))
    check("데이터", "라이선스·수집 윤리", has_license, 2,
          "robots.txt·이용약관 확인")

    # ══════════ ④ 범위 ══════════
    has_moscow = all(kw in text for kw in ("Must", "Should"))
    check("범위", "MoSCoW", has_moscow, 2, "Must/Should/Could/Won't")

    has_wont = bool(re.search(r"Won'?t|하지 않|제외", text, re.I))
    check("범위", "Won't 명시", has_wont, 3,
          "하지 않을 것을 못 박아야 시간을 지킴")

    # 범위 과대 신호
    if re.search(r"전국|10만|100,?000|전체 시도", text):
        if not re.search(r"한정|축소|제한", text):
            warnings_list.append(
                "범위가 커 보입니다 — 지역 하나로 한정하는 것을 권합니다")

    if re.search(r"머신러닝|딥러닝|AI 모델", text):
        if not re.search(r"Won'?t|하지 않", text, re.I):
            warnings_list.append(
                "머신러닝 언급 — 이 단원 범위 밖입니다. Won't 에 넣으세요")

    # ══════════ ⑤ 일정 ══════════
    has_schedule = len(re.findall(r"07[1-5]|월|화|수|목|금", text)) >= 5
    check("일정", "5일 일정표", has_schedule, 2, "Day 별 목표와 완료 조건")

    has_risk = bool(re.search(r"위험|리스크|risk|지연", text, re.I))
    check("일정", "위험 관리", has_risk, 2,
          "무엇이 잘못될 수 있고 어떻게 대응할지")

    # ══════════ ⑥ 완료 조건 ══════════
    has_dod = bool(re.search(r"완료 조건|Definition of Done|DoD", text, re.I))
    check("완료", "완료 조건", has_dod, 2, "무엇을 만들면 끝인지")

    n_checkbox = len(re.findall(r"- \[ \]|□", text))
    check("완료", "체크박스 5개 이상", n_checkbox >= 5, 1,
          f"현재 {n_checkbox}개")

    # ══════════ 집계 ══════════
    df = pd.DataFrame(checks)

    earned = (df["충족"] * df["가중치"]).sum()
    total = df["가중치"].sum()
    score = earned / total * 100

    missing = df[~df["충족"]]

    if verbose:
        line = "=" * 82
        print(line)
        print("                       프로젝트 기획서 점검")
        print(line)

        print(f"\n  파일: {path}")
        print(f"  분량: {len(text.splitlines())}줄 · {len(text):,}자")

        print(f"\n[구분별 점수]")
        by_cat = df.groupby("구분").apply(
            lambda g: pd.Series({
                "충족": int(g["충족"].sum()),
                "전체": len(g),
                "점수": (g["충족"] * g["가중치"]).sum() / g["가중치"].sum() * 100,
            }), include_groups=False)

        print(f"  {'구분':<10}{'충족':>7}{'전체':>7}{'점수':>9}  분포")
        print("  " + "-" * 52)
        for cat, r in by_cat.iterrows():
            bar = "■" * int(r["점수"] / 5)
            print(f"  {cat:<10}{r['충족']:>7.0f}{r['전체']:>7.0f}"
                  f"{r['점수']:>8.0f}%  {bar}")

        if len(missing):
            print(f"\n[미충족 항목]  {len(missing)}개")
            for _, r in missing.sort_values("가중치", ascending=False).iterrows():
                icon = "🔴" if r["가중치"] >= 3 else ("🟡" if r["가중치"] == 2
                                                    else "🔵")
                print(f"  {icon} [{r['구분']}] {r['항목']}")
                if r["힌트"]:
                    print(f"       → {r['힌트']}")

        if warnings_list:
            print(f"\n[경고]")
            for w in warnings_list:
                print(f"  ⚠ {w}")

        print(f"\n{line}")
        grade = ("✅ 진행 가능" if score >= 85
                 else "🟡 보완 후 진행" if score >= 65
                 else "❌ 재작성 필요")
        print(f"  완성도: {score:.0f}점 / 100   {grade}")
        print(line)

        # ── 오늘 안에 해야 할 것 ──
        critical = missing[missing["가중치"] >= 3]
        if len(critical):
            print(f"\n  [오늘 안에 반드시]")
            for _, r in critical.iterrows():
                print(f"    · {r['항목']} — {r['힌트']}")
            print(f"\n  ⚠ 이 항목들은 화요일로 넘기면 프로젝트가 흔들립니다")
            print(line)

    return {"score": score, "missing": missing, "warnings": warnings_list}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    audit_plan("docs/project_plan.md")

| 주제 차별화 | **지역 × 타깃 × 기준** 조합 |
| **분석 질문** | **[누구]에게 [어떤 기준]으로 [무엇]을 추천한다** |
| 좋은 질문 | 대상 구체 · **기준 측정 가능** · 출력 명확 |
| 질문 분해 | 질문 → 필요 데이터 → 계산 |
| 소스 조사 | 획득·인증·한도·필드·**라이선스·위험** |
| **확보 검증** | **오늘 3건 실제로 받아 보기** ⭐ |
| 필드 결측률 | 있다고 다 쓸 수 있는 게 아님 |
| **Plan B** | Must 데이터마다 대안 |
| 범위 | MoSCoW · **`Won't` 를 반드시** |
| 일정 | 화요일까지 데이터, 목요일까지 결과물 |
| 컬럼 정의서 | 초안을 오늘, 갱신은 수요일 |

**오늘 반드시 기억할 세 가지**
> ① **질문을 한 문장으로 확정하세요.** "누구에게 어떤 기준으로 무엇을"이 없으면 목요일에 헤맵니다.
> ② **오늘 데이터를 3건이라도 받아 보세요.** "있을 것 같다"는 검증이 아닙니다.
> ③ **`Won't` 를 쓰세요.** 하지 않을 것을 정해야 할 것을 지킬 수 있습니다.
