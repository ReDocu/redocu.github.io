**백본 225만 개는 ImageNet 그대로입니다.**

**그런데 ImageNet은 내 문제와 정확히 같지 않습니다.**

```

→ 내 문제에 맞게 조금 조정하면 더 나아짐
```

**그것이 미세조정입니다.**

```
0.9333  →  0.9667 (미세조정 후)
```

### 그런데 위험합니다


```
→ ImageNet에서 배운 것을 다 잊음
→ 400장으로 225만 파라미터를 처음부터 학습하는 셈
```

## ③ 개념 설명

### 미세조정이란

```
[특징 추출]                    [미세조정]

  입력                           입력
   ↓                              ↓
[백본 전체 동결] ❄️            [백본 하위층 동결] ❄️
   ↓                           [백본 상위층 해제] 🔥
[분류기] 🔥                       ↓
                              [분류기] 🔥
```

| | 특징 추출 | 미세조정 |
|---|---|---|
| 학습 파라미터 | 1,281 | 40만~200만 |
| 학습률 | 0.001 | **0.00001 (1/100)** |
| 데이터 요구 | 수백 장 | **수천 장 이상 권장** |
| 시간 | 빠름 | 느림 |
| 성능 | 좋음 | **더 좋음** |
| 위험 | 낮음 | **가중치 파괴 가능** |

### 왜 상위층부터 해제하는가

```
층 1~50   엣지, 색 변화              → 어떤 이미지에나 공통. 그대로 두기
층 51~100 질감, 무늬                 → 대체로 공통
층 101~140 부분 (눈, 귀, 바퀴)       → 도메인에 따라 다름
층 141~154 고수준 조합               → ★ 내 문제에 맞게 조정 필요
```

**[Day 089](day-089.md)에서 특성맵으로 확인한 계층 구조 그대로입니다.**

```python
# 상위 30개 층만 해제
base.trainable = True
for layer in base.layers[:-30]:
    layer.trainable = False
```

**하위층을 해제하면 안 되는 이유**

```
엣지 검출기는 어떤 데이터셋이든 거의 같습니다
→ 다시 학습할 이유가 없음
→ 오히려 400장으로 재학습하면 더 나빠짐
```

### ★ 학습률을 크게 낮추는 이유

```
사전학습 가중치: ImageNet에서 최적화된 상태
큰 학습률(0.001)로 한 스텝 = 그 최적점에서 멀리 이동
→ 몇 스텝 만에 ImageNet에서 배운 것이 사라짐
```

**비유**

```
정밀하게 조율된 악기를 미세 조정하는 것
→ 나사를 조금씩 돌려야 함
→ 크게 돌리면 처음부터 다시 조율해야 함
```

**권장 학습률**

| 단계 | 학습률 |
|---|---|
| 1단계 (특징 추출) | **0.001** |
| 2단계 (미세조정) | **0.00001 ~ 0.0001** |

```
비율: 1/10 ~ 1/100
```

> **일반적으로 1/100(1e-5)을 씁니다.**
> 데이터가 많으면 1/10(1e-4)까지 올릴 수 있습니다.

### ★ 2단계 학습 절차

**1단계 — 특징 추출 (분류기 학습)**

```python
base.trainable = False
model.compile(optimizer=Adam(1e-3), ...)
model.fit(train_ds, epochs=20, ...)
```

**2단계 — 미세조정**

```python
base.trainable = True
for layer in base.layers[:-30]:
    layer.trainable = False

model.compile(optimizer=Adam(1e-5), ...)      # ★ 반드시 재컴파일
model.fit(train_ds, epochs=20, initial_epoch=20, ...)
```

**왜 1단계를 먼저 해야 하는가**

```
분류기가 무작위 상태에서 미세조정하면
→ 큰 손실 → 큰 기울기 → 백본에 큰 업데이트
→ 사전학습 가중치 파괴

1단계로 분류기를 먼저 안정화하면
→ 작은 손실 → 작은 기울기 → 백본이 조금씩만 변함
```

> ⚠️ **`trainable` 을 바꾸면 반드시 `compile()` 을 다시 호출해야 합니다.**
> 안 하면 변경이 반영되지 않습니다.

### BatchNorm 처리

**미세조정 시 BatchNorm은 특별히 다뤄야 합니다.**

```python
base.trainable = True
for layer in base.layers:
    if isinstance(layer, keras.layers.BatchNormalization):
        layer.trainable = False      # ★ BN은 계속 동결
```

**이유**

```
BatchNorm의 이동평균/분산은 ImageNet 통계
→ 400장의 배치 통계로 갱신하면 불안정
→ 소량 데이터에서는 동결 유지가 안전
```

**또는 `training=False` 유지**

```python
x = base(x, training=False)      # BN을 추론 모드로 고정
```

> **데이터가 충분(수만 장)하면 BN도 학습시키는 것이 낫습니다.**
> **소량 데이터에서는 동결**하세요.

### 해제 층 수와 데이터 양

| 데이터 | 해제 층 수 | 근거 |
|---|---|---|
| < 500장 | **0 (특징 추출만)** | 미세조정 시 과적합 |
| 500~2,000장 | 상위 10~30층 | 조심스럽게 |
| 2,000~10,000장 | 상위 30~60층 | 일반적 |
| > 10,000장 | 전체 또는 대부분 | 충분한 데이터 |

**경험칙**

```
학습 파라미터 ≈ 데이터 수 × 10 이하로 유지
```

```
데이터 280장 → 학습 파라미터 2,800개 이하 권장
              → 특징 추출(1,281개)이 적정
              → 미세조정(40만 개)은 과함
```

> **그런데 실제로는 미세조정이 도움이 되는 경우가 많습니다.**
> 사전학습 가중치가 좋은 시작점이라 처음부터 학습하는 것과 다르기 때문입니다.
> **실험으로 확인해야 합니다.**

### 도메인 차이와 미세조정

| 내 데이터 vs ImageNet | 권장 |
|---|---|
| **매우 유사** (동물, 사물 사진) | 특징 추출 또는 소폭 미세조정 |
| 다소 다름 (위성 사진, 문서) | 중간 정도 미세조정 |
| **매우 다름** (의료 영상, X-ray) | **깊게 미세조정** 또는 밑바닥 |

```
늑대 vs 허스키 → ImageNet에 개 품종 120종이 있음 → 매우 유사
흉부 X-ray    → ImageNet에 없는 도메인 → 깊은 미세조정 필요
```

|---|---|---|

| 160×160 | 좋음 | 보통 |
| **224×224** | **가장 좋음** | 보통 |

## ④ 단계별 실습

### Step 1. 잘못된 미세조정 — 가중치 파괴 재현

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.applications.mobilenet_v2 import preprocess_input
from tensorflow.keras.callbacks import EarlyStopping

AUTOTUNE = tf.data.AUTOTUNE
SPLIT = Path("/content/drive/MyDrive/ml_course/datasets/my_dataset/split")
IMG_SIZE, BATCH, SEED = (224, 224), 32, 42

train_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=True, seed=SEED).cache().prefetch(AUTOTUNE)
val_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=False).cache().prefetch(AUTOTUNE)
test_ds = keras.utils.image_dataset_from_directory(
    SPLIT / "test", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=False).cache().prefetch(AUTOTUNE)

CLASS_NAMES = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH).class_names
N = len(CLASS_NAMES)
print(f"클래스: {CLASS_NAMES}")


def build_base_model(dropout=0.3):
    base = keras.applications.MobileNetV2(
        weights="imagenet", include_top=False, input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*IMG_SIZE, 3))
    x = layers.RandomFlip("horizontal")(inputs)
    x = layers.RandomRotation(0.1)(x)
    x = layers.RandomZoom(0.1)(x)
    x = preprocess_input(x)
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)
    if N == 2:
        outputs = layers.Dense(1, activation="sigmoid")(x)
        loss = "binary_crossentropy"
    else:
        outputs = layers.Dense(N, activation="softmax")(x)
        loss = "sparse_categorical_crossentropy"
    model = keras.Model(inputs, outputs)
    return model, base, loss


print("=" * 70)
print("① 1단계: 특징 추출 (Day 098과 동일)")
print("=" * 70)

tf.random.set_seed(SEED)
model, base, loss = build_base_model()
model.compile(optimizer=keras.optimizers.Adam(1e-3), loss=loss,
              metrics=["accuracy"])

h1 = model.fit(train_ds, epochs=30, validation_data=val_ds,
               callbacks=[EarlyStopping(monitor="val_loss", patience=10,
                                        restore_best_weights=True, verbose=0)],
               verbose=0).history
_, acc_stage1 = model.evaluate(test_ds, verbose=0)
print(f"1단계 결과: test {acc_stage1:.4f}  ({len(h1['loss'])}에폭)")

# 가중치 백업
model.save_weights("/content/stage1.weights.h5")

print("\n" + "=" * 70)
print("② 잘못된 미세조정 — 학습률 그대로 (1e-3)")
print("=" * 70)

base.trainable = True
model.compile(optimizer=keras.optimizers.Adam(1e-3),      # ✗ 그대로
              loss=loss, metrics=["accuracy"])

trainable = int(np.sum([np.prod(w.shape) for w in model.trainable_weights]))
print(f"학습 파라미터: {trainable:,}  (1단계 1,281개에서 급증)")

h_bad = model.fit(train_ds, epochs=15, validation_data=val_ds,
                  verbose=0).history
_, acc_bad = model.evaluate(test_ds, verbose=0)

print(f"\n에폭별 val_accuracy:")
for i in [0, 1, 2, 4, 9, 14]:
    if i < len(h_bad["val_accuracy"]):
        print(f"  epoch {i+1:>2}: {h_bad['val_accuracy'][i]:.4f}")

print(f"\n1단계: {acc_stage1:.4f}")
print(f"잘못된 미세조정 후: {acc_bad:.4f}  ({acc_bad - acc_stage1:+.4f})")
print("\n★ 첫 에폭부터 성능이 무너집니다")
print("  큰 학습률이 사전학습 가중치를 파괴했습니다")

print("\n" + "=" * 70)
print("③ 올바른 미세조정 — 학습률 1/100 (1e-5)")
print("=" * 70)

tf.random.set_seed(SEED)
model2, base2, loss2 = build_base_model()
model2.compile(optimizer=keras.optimizers.Adam(1e-3), loss=loss2,
               metrics=["accuracy"])
model2.load_weights("/content/stage1.weights.h5")
_, acc_check = model2.evaluate(test_ds, verbose=0)
print(f"1단계 가중치 복원 확인: {acc_check:.4f}")

base2.trainable = True
for layer in base2.layers[:-30]:
    layer.trainable = False
for layer in base2.layers:
    if isinstance(layer, keras.layers.BatchNormalization):
        layer.trainable = False

model2.compile(optimizer=keras.optimizers.Adam(1e-5),     # ★ 1/100
               loss=loss2, metrics=["accuracy"])

trainable2 = int(np.sum([np.prod(w.shape) for w in model2.trainable_weights]))
print(f"학습 파라미터: {trainable2:,}  (상위 30층만)")

h_good = model2.fit(train_ds, epochs=25, validation_data=val_ds,
                    callbacks=[EarlyStopping(monitor="val_loss", patience=10,
                                             restore_best_weights=True,
                                             verbose=0)],
                    verbose=0).history
_, acc_good = model2.evaluate(test_ds, verbose=0)

print(f"\n1단계: {acc_stage1:.4f}")
print(f"올바른 미세조정 후: {acc_good:.4f}  ({acc_good - acc_stage1:+.4f})")

# ── 정리 ──
summary = pd.DataFrame([
    {"단계": "1단계 (특징 추출)", "학습_파라미터": 1281, "lr": "1e-3",
     "test": round(acc_stage1, 4)},
    {"단계": "잘못된 미세조정 (lr 1e-3)", "학습_파라미터": trainable, "lr": "1e-3",
     "test": round(acc_bad, 4)},
    {"단계": "올바른 미세조정 (lr 1e-5)", "학습_파라미터": trainable2, "lr": "1e-5",
     "test": round(acc_good, 4)},
])
print("\n" + "=" * 82)
print(summary.to_string(index=False))
print("=" * 82)

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

ax = axes[0]
ax.plot(range(1, len(h_bad["val_accuracy"]) + 1), h_bad["val_accuracy"],
        "o-", linewidth=2.5, color="crimson", label="lr 1e-3 (wrong)")
ax.plot(range(1, len(h_good["val_accuracy"]) + 1), h_good["val_accuracy"],
        "s-", linewidth=2.5, color="seagreen", label="lr 1e-5 (correct)")
ax.axhline(acc_stage1, color="black", linestyle="--", alpha=0.7,
           label=f"stage 1 ({acc_stage1:.3f})")
ax.set_xlabel("fine-tuning epoch"); ax.set_ylabel("val accuracy")
ax.set_title("Learning rate matters in fine-tuning")
ax.legend(); ax.grid(alpha=0.3)

ax = axes[1]
colors = ["gray", "crimson", "seagreen"]
ax.barh(summary["단계"], summary["test"], color=colors)
ax.set_xlim(0.4, 1.0)
ax.set_xlabel("test accuracy")
ax.set_title("Result comparison")
for i, v in enumerate(summary["test"]):
    ax.text(v + 0.008, i, f"{v:.4f}", va="center", fontsize=9)
fig.tight_layout()
plt.show()
```

```python
"""
finetune_utils.py — 2단계 전이학습 파이프라인
Day 101~105 프로젝트에서 사용
"""
import json
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.callbacks import (EarlyStopping, ModelCheckpoint,
                                        ReduceLROnPlateau)

BASE_DIR = Path("/content/drive/MyDrive/ml_course")
CKPT_DIR, LOG_DIR, MODEL_DIR = (BASE_DIR / "checkpoints", BASE_DIR / "logs",
                                BASE_DIR / "models")
for d in [CKPT_DIR, LOG_DIR, MODEL_DIR]:
    d.mkdir(parents=True, exist_ok=True)

BACKBONES = {
    "MobileNetV2": (keras.applications.MobileNetV2,
                    keras.applications.mobilenet_v2.preprocess_input),
    "MobileNetV3Small": (keras.applications.MobileNetV3Small,
                         keras.applications.mobilenet_v3.preprocess_input),
    "EfficientNetB0": (keras.applications.EfficientNetB0,
                       keras.applications.efficientnet.preprocess_input),
    "ResNet50": (keras.applications.ResNet50,
                 keras.applications.resnet50.preprocess_input),
}


def build_transfer_model(backbone="MobileNetV2", img_size=(224, 224),
                         n_classes=2, dropout=0.3, augment=True):
    """전이학습 모델 생성 (백본 동결 상태)"""
    fn, preprocess = BACKBONES[backbone]
    base = fn(weights="imagenet", include_top=False,
              input_shape=(*img_size, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*img_size, 3))
    x = inputs
    if augment:
        x = layers.RandomFlip("horizontal")(x)
        x = layers.RandomRotation(0.1)(x)
        x = layers.RandomZoom(0.1)(x)
    x = preprocess(x)
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(dropout)(x)

    if n_classes == 2:
        outputs = layers.Dense(1, activation="sigmoid")(x)
        loss = "binary_crossentropy"
    else:
        outputs = layers.Dense(n_classes, activation="softmax")(x)
        loss = "sparse_categorical_crossentropy"

    model = keras.Model(inputs, outputs, name=f"transfer_{backbone}")
    return model, base, loss


def callbacks_for(name, stage, patience=12):
    return [
        ModelCheckpoint(str(CKPT_DIR / f"{name}_{stage}_best.keras"),
                        monitor="val_loss", save_best_only=True, verbose=0),
        EarlyStopping(monitor="val_loss", patience=patience,
                      restore_best_weights=True, verbose=1),
        ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                          patience=patience // 2, min_lr=1e-8, verbose=0),
    ]


def train_two_stage(train_ds, val_ds, test_ds, name,
                    backbone="MobileNetV2", img_size=(224, 224),
                    n_classes=2, dropout=0.3,
                    stage1_lr=1e-3, stage1_epochs=50,
                    stage2_lr=1e-5, stage2_epochs=50,
                    n_unfreeze=20, freeze_bn=True, verbose=True):
    """
    2단계 전이학습

    1단계: 백본 동결 + 분류기 학습 (lr 1e-3)
    2단계: 상위 n_unfreeze 층 해제 + 저학습률 재학습 (lr 1e-5)
    """
    model, base, loss = build_transfer_model(
        backbone, img_size, n_classes, dropout)

    # ═══ 1단계 ═══
    if verbose:
        print("=" * 70)
        print(f"[1단계] 특징 추출 — {backbone}, lr={stage1_lr:.0e}")
        print("=" * 70)

    model.compile(optimizer=keras.optimizers.Adam(stage1_lr),
                  loss=loss, metrics=["accuracy"])
    n_trainable_1 = int(np.sum([np.prod(w.shape)
                                for w in model.trainable_weights]))
    if verbose:
        print(f"  학습 파라미터: {n_trainable_1:,} / {model.count_params():,}")

    t0 = time.time()
    h1 = model.fit(train_ds, epochs=stage1_epochs, validation_data=val_ds,
                   callbacks=callbacks_for(name, "s1"), verbose=0).history
    t1 = time.time() - t0
    _, acc1 = model.evaluate(test_ds, verbose=0)

    if verbose:
        print(f"  에폭 {len(h1['loss'])}, {t1:.1f}초")
        print(f"  test accuracy: {acc1:.4f}")

    # ═══ 2단계 ═══
    if n_unfreeze <= 0:
        if verbose:
            print("\n  n_unfreeze=0 → 2단계 생략")
        meta = {"name": name, "backbone": backbone,
                "stage1": {"lr": stage1_lr, "epochs": len(h1["loss"]),
                           "trainable": n_trainable_1, "test_acc": float(acc1),
                           "time_sec": t1},
                "stage2": None, "final_test_acc": float(acc1)}
        model.save(MODEL_DIR / f"{name}.keras")
        return model, {"stage1": h1, "stage2": None}, meta

    if verbose:
        print("\n" + "=" * 70)
        print(f"[2단계] 미세조정 — 상위 {n_unfreeze}층 해제, "
              f"lr={stage2_lr:.0e} (1/{int(stage1_lr/stage2_lr)})")
        print("=" * 70)

    base.trainable = True
    for layer in base.layers[:-n_unfreeze]:
        layer.trainable = False
    if freeze_bn:
        for layer in base.layers:
            if isinstance(layer, keras.layers.BatchNormalization):
                layer.trainable = False

    model.compile(optimizer=keras.optimizers.Adam(stage2_lr),   # ★ 재컴파일
                  loss=loss, metrics=["accuracy"])
    n_trainable_2 = int(np.sum([np.prod(w.shape)
                                for w in model.trainable_weights]))
    if verbose:
        print(f"  학습 파라미터: {n_trainable_2:,} "
              f"({n_trainable_2/n_trainable_1:.0f}배 증가)")
        print(f"  BatchNorm: {'동결' if freeze_bn else '학습'}")

    t0 = time.time()
    h2 = model.fit(train_ds, epochs=stage1_epochs + stage2_epochs,
                   initial_epoch=len(h1["loss"]),
                   validation_data=val_ds,
                   callbacks=callbacks_for(name, "s2"), verbose=0).history
    t2 = time.time() - t0
    _, acc2 = model.evaluate(test_ds, verbose=0)

    if verbose:
        print(f"  에폭 {len(h2['loss'])}, {t2:.1f}초")
        print(f"  test accuracy: {acc2:.4f}  ({acc2 - acc1:+.4f})")
        print("=" * 70)
        if acc2 < acc1 - 0.01:
            print("  ⚠️ 미세조정 후 성능이 떨어졌습니다")
            print("     → 학습률을 더 낮추거나 해제 층 수를 줄이세요")

    meta = {
        "name": name, "backbone": backbone,
        "stage1": {"lr": stage1_lr, "epochs": len(h1["loss"]),
                   "trainable": n_trainable_1, "test_acc": float(acc1),
                   "time_sec": t1},
        "stage2": {"lr": stage2_lr, "epochs": len(h2["loss"]),
                   "n_unfreeze": n_unfreeze, "freeze_bn": freeze_bn,
                   "trainable": n_trainable_2, "test_acc": float(acc2),
                   "time_sec": t2},
        "final_test_acc": float(acc2),
        "improvement": float(acc2 - acc1),
    }
    (LOG_DIR / f"{name}_meta.json").write_text(
        json.dumps(meta, indent=2, ensure_ascii=False))
    model.save(MODEL_DIR / f"{name}.keras")

    return model, {"stage1": h1, "stage2": h2}, meta
```

## ⑤ 자주 하는 실수

### 학습률을 안 낮춤

### `trainable` 을 바꾸고 재컴파일 안 함


**해결** — 반드시 `compile()` 을 다시 호출하세요.

```python
def build_model(dropout=0.3):
    base = keras.applications.MobileNetV2(
        weights="imagenet", include_top=False, input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    x = layers.RandomZoom(0.1)(x)

def cbs(patience=12):
    return [EarlyStopping(monitor="val_loss", patience=patience,
                          restore_best_weights=True, verbose=0),
            ReduceLROnPlateau(monitor="val_loss", factor=0.5,
                              patience=patience // 2, min_lr=1e-8, verbose=0)]


def two_stage(ds=None, n_unfreeze=20, s2_lr=1e-5, freeze_bn=True,
              s1_lr=1e-3, s1_epochs=50, s2_epochs=50, seed=SEED):
    ds = ds if ds is not None else train_ds
    keras.backend.clear_session()
    tf.random.set_seed(seed)

    model, base, loss = build_model()

    # 1단계
    model.compile(optimizer=keras.optimizers.Adam(s1_lr), loss=loss,
                  metrics=["accuracy"])
    t0 = time.time()
    h1 = model.fit(ds, epochs=s1_epochs, validation_data=val_ds,
                   callbacks=cbs(), verbose=0).history
    t1 = time.time() - t0
    _, acc1 = model.evaluate(test_ds, verbose=0)
    p1 = int(np.sum([np.prod(w.shape) for w in model.trainable_weights]))

    if n_unfreeze <= 0:
        return {"stage1_acc": round(acc1, 4), "final_acc": round(acc1, 4),
                "improvement": 0.0, "s1_params": p1, "s2_params": p1,
                "s1_epochs": len(h1["loss"]), "s2_epochs": 0,
                "time": round(t1, 1)}, {"h1": h1, "h2": None}

    # 2단계
    base.trainable = True
    for layer in base.layers[:-n_unfreeze]:
        layer.trainable = False
    if freeze_bn:
        for layer in base.layers:
            if isinstance(layer, keras.layers.BatchNormalization):
                layer.trainable = False

    model.compile(optimizer=keras.optimizers.Adam(s2_lr), loss=loss,
                  metrics=["accuracy"])
    p2 = int(np.sum([np.prod(w.shape) for w in model.trainable_weights]))

    t0 = time.time()
    h2 = model.fit(ds, epochs=s1_epochs + s2_epochs,
                   initial_epoch=len(h1["loss"]),
                   validation_data=val_ds, callbacks=cbs(), verbose=0).history
    t2 = time.time() - t0
    _, acc2 = model.evaluate(test_ds, verbose=0)

    del model, base
    return {"stage1_acc": round(acc1, 4), "final_acc": round(acc2, 4),
            "improvement": round(acc2 - acc1, 4),
            "s1_params": p1, "s2_params": p2,
            "s1_epochs": len(h1["loss"]), "s2_epochs": len(h2["loss"]),
            "time": round(t1 + t2, 1)}, {"h1": h1, "h2": h2}
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 미세조정 | 백본 **상위층을 해제**해 내 문제에 맞게 조정 |
| **★ 2단계 절차** | ① 동결 학습(lr 1e-3) → ② 해제 후 저학습률(lr 1e-5) |
| 왜 2단계인가 | 분류기가 무작위면 백본이 파괴됨 |
| **★ 학습률** | **1/10 ~ 1/100**. 보통 **1e-5** |
| 학습률 실패 | 1e-3 그대로 → **0.933 → 0.550** |
| 해제 방향 | **상위층부터**. 하위층은 공통 특징 |
| 해제 층 수 | 데이터 400장 → **20층 최적** |
| 전체 해제 | 소량 데이터에서 **오히려 나쁨** |
| **BatchNorm** | **동결 권장** (소량 데이터) |
| 재컴파일 | `trainable` 변경 후 **반드시 `compile()`** |
| `initial_epoch` | 2단계에서 에폭 번호 이어가기 |
| 데이터별 권장 | <500장 0~10층 · 500~2000장 10~30층 · >2000장 30~60층 |
| 도메인 차이 | **다를수록 깊게** 미세조정 |
| 성능 하락 시 | lr↓ → 해제층↓ → BN 동결 → 특징 추출만 |
| 최종 결과 | 400장으로 **0.6333 → 0.9667** |

**오늘 반드시 기억할 세 가지**
> ① **미세조정 학습률은 1/100(1e-5)입니다.** 그대로 두면 사전학습 가중치가 파괴됩니다.
> ② **반드시 2단계로 하세요.** 1단계 없이 미세조정하면 백본이 망가집니다.
> ③ **`trainable` 을 바꾸면 `compile()` 을 다시 호출**해야 반영됩니다.

**과제** — 미세조정 실험 3회 이상을 기록하세요.

**필수 포함 항목**

| 항목 | 내용 |
|---|---|
| 1 | **2단계 학습 파이프라인** 구현 (재사용 가능한 함수로) |
| 2 | **잘못된 미세조정 재현** — lr을 그대로 뒀을 때의 성능 붕괴 |
| 3 | **해제 층 수 5단계 이상** 탐색 + 곡선 |
| 4 | **학습률 5단계 이상** 탐색 + 곡선 |
| 5 | **BatchNorm 동결 여부** 비교 |
| 6 | 데이터 양별(100/50/25%) 최적 해제 층 수 |
| 7 | 2단계 학습 곡선 (미세조정 시작 지점 표시) |
| 8 | 실험 기록표 (번호 / 실험 / 바꾼 것 / 결과 / **관찰** / **다음 시도**) |
| 9 | 최종 권장 설정 (복사 가능한 코드) |
| 10 | **유보 사항** |
