## 3. 개념

### 3-1. Raycast — 화면에서 월드로

**왜 필요한가** — 3D에서 클릭 지점을 찾는다.

```csharp
    Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);

    if (Physics.Raycast(ray, out RaycastHit hit, 100f, groundLayer))
    {
        Vector3 worldPos = hit.point;          // ★ 부딪힌 지점
        Vector3 normal = hit.normal;           // 표면 방향
        Collider col = hit.collider;           // 무엇에 맞았나
        float dist = hit.distance;
    }
```

| `RaycastHit` 필드 | 의미 |
|---|---|
| **`point`** | 충돌 지점 (월드 좌표) |
| **`normal`** | 표면의 법선 |
| **`collider`** | 맞은 콜라이더 |
| `distance` | 광선 시작점부터의 거리 |
| `transform` | 맞은 오브젝트의 Transform |

```
   ⚠️ Raycast가 안 맞는 이유

   ① 대상에 Collider가 없다
   ② LayerMask에서 제외됐다
   ③ 거리(maxDistance)가 짧다
   ④ Collider가 Trigger인데 Physics 설정에서 무시
   ⑤ 광선이 콜라이더 안에서 시작 (기본은 안 맞는다)
```

```
   ★ Queries Hit Triggers

   Edit → Project Settings → Physics
   → Queries Hit Triggers 체크 여부

   또는 코드에서
   Physics.Raycast(..., QueryTriggerInteraction.Ignore);
```

**UI 위에서는 무시하기**

```csharp
using UnityEngine.EventSystems;

    if (EventSystem.current.IsPointerOverGameObject())
        return;                                // ★ UI 클릭이면 무시
```


**왜 필요한가** — 성능이 크게 다르다.

| Trigger Collider | 낮음 | 진입/이탈 이벤트 |

```csharp

    int count = Physics.OverlapSphereNonAlloc(
        transform.position, range, buffer, enemyLayer);
```

```csharp
    // ② 거리 계산 (Day 86의 EnemyManager 활용)
    private Enemy FindTarget()
    {
        var enemies = EnemyManager.Instance.Active;

        float rangeSq = range * range;         // ★ 제곱 비교
        Enemy best = null;
        float bestScore = float.MinValue;

        for (int i = 0; i < enemies.Count; i++)
        {
            Enemy e = enemies[i];
            if (e == null || !e.IsAlive) continue;

            // ★ 비행 유닛 타격 가능 여부
            if (e.Data.moveType == EnemyMoveType.Flying && !canHitFlying) continue;

            Vector3 d = e.Position - transform.position;
            d.y = 0;

            if (d.sqrMagnitude > rangeSq) continue;

            float score = EvaluateTarget(e, d.sqrMagnitude);

            if (score > bestScore) { bestScore = score; best = e; }
        }

        return best;
    }
```

```
   ★ sqrMagnitude를 쓰는 이유

   magnitude = sqrt(x² + y² + z²)   ← sqrt는 비싸다
   sqrMagnitude = x² + y² + z²      ← 곱셈만

   비교만 할 거라면 제곱끼리 비교하면 된다
   → Day 24에서 배운 최적화
```

```
   ★ 성능 비교 (적 200기, 타워 20기)

   OverlapSphere:  1.4 ms
   거리 계산:      0.3 ms
```

### 3-8. 타겟 선정 규칙

**왜 필요한가** — 전략의 핵심.

| 규칙 | 설명 | 용도 |
|---|---|---|
| **First** | 가장 앞선 적 (진행도 최대) | 기본. 놓치지 않게 |
| Last | 가장 뒤처진 적 | 후속 타워 |
| **Closest** | 가장 가까운 적 | 감속 타워 |
| Strongest | HP가 가장 많은 적 | 보스 저격 |
| Weakest | HP가 가장 적은 적 | 마무리 |
| Random | 무작위 | 광역 |

```csharp
public enum TargetPriority { First, Last, Closest, Strongest, Weakest }

    private float EvaluateTarget(Enemy e, float distSq)
    {
        switch (priority)
        {
        case TargetPriority.First:     return e.Progress;
        case TargetPriority.Last:      return -e.Progress;
        case TargetPriority.Closest:   return -distSq;
        case TargetPriority.Strongest: return e.CurrentHp;
        case TargetPriority.Weakest:   return -e.CurrentHp;
        default: return 0;
        }
    }
```

```
   ★ Progress는 Day 86에서 만든 것

   목표에 얼마나 가까운지 (0~1)
```

```

   놓치면 라이프가 준다
   → 가장 위험한 적부터 처리
```

### 3-11. 발사와 투사체

**왜 필요한가** — Day 51~52의 총알 구조.

```

   ① 실제 투사체 (프리팹 이동)    시각적으로 좋다. 빗나갈 수 있다
   ② 히트스캔 (즉시 판정)          정확. 레이저·저격에
   ③ 유도탄 (타겟 추적)            반드시 맞는다  ★ 타워 디펜스에 흔함
```

```csharp
public class Projectile : MonoBehaviour, IPoolable
{
    [SerializeField] private float speed = 18f;
    [SerializeField] private float lifetime = 4f;
    [SerializeField] private bool homing = true;

    private Enemy target;
    private Vector3 lastKnownPos;
    private int damage;
    private float splashRadius;
    private float slowMultiplier = 1f;
    private float slowDuration;
    private float timer;
    private PooledObject pooled;

    void Awake() { pooled = GetComponent<PooledObject>(); }

    public void Launch(Enemy t, TowerData data)
    {
        target = t;
        lastKnownPos = t.Position;

        damage = data.damage;
        splashRadius = data.splashRadius;
        slowMultiplier = data.slowMultiplier;
        slowDuration = data.slowDuration;

        timer = lifetime;
    }

    public void Tick(float dt)
    {
        timer -= dt;
        if (timer <= 0) { Despawn(); return; }

        // ★ 타겟이 죽었으면 마지막 위치로
        Vector3 targetPos = (target != null && target.IsAlive)
                            ? target.Position + Vector3.up * 0.5f
                            : lastKnownPos;

        if (target != null && target.IsAlive) lastKnownPos = targetPos;

        Vector3 dir = targetPos - transform.position;
        float dist = dir.magnitude;

        // ★ 도달
        if (dist < speed * dt + 0.2f)
        {
            Impact(targetPos);
            return;
        }

        dir /= dist;

        if (homing)
            transform.rotation = Quaternion.LookRotation(dir);

        transform.position += dir * speed * dt;
    }

    private void Impact(Vector3 pos)
    {
        if (splashRadius > 0)
        {
            // ★ 광역
            var enemies = EnemyManager.Instance.Active;
            float rSq = splashRadius * splashRadius;

            for (int i = enemies.Count - 1; i >= 0; i--)
            {
                Enemy e = enemies[i];
                if (e == null || !e.IsAlive) continue;

                if ((e.Position - pos).sqrMagnitude > rSq) continue;

                ApplyEffect(e);
            }
        }
        else if (target != null && target.IsAlive)
        {
            ApplyEffect(target);
        }

        // 이펙트 (Day 88)
        PoolManager.Instance.Get("hit_effect", pos, Quaternion.identity);

        Despawn();
    }

    private void ApplyEffect(Enemy e)
    {
        e.TakeDamage(new DamageInfo { amount = damage });

        if (slowMultiplier < 1f)
            e.ApplySlow(slowMultiplier, slowDuration, e.Data.slowResist);
    }

    private void Despawn()
    {
        target = null;
        if (pooled != null) pooled.ReturnToPool();
        else Destroy(gameObject);
    }

    public void OnSpawn() { target = null; timer = lifetime; }
    public void OnDespawn() { }
}
```

```csharp
using UnityEngine;

public class GridSystem : MonoBehaviour
{
    public static GridSystem Instance { get; private set; }

            Mathf.FloorToInt(world.x / cellSize),      // ★ FloorToInt

    }

    public Vector3 CellToWorld(Vector2Int cell)
    {

    public void Free(Vector2Int cell) => occupied.Remove(cell);

        && cell.y >= gridMin.y && cell.y <= gridMax.y;

    // ─── 기즈모 ───
```

```csharp
using UnityEngine;

public class Tower : MonoBehaviour
{
    [Header("참조")]
    [SerializeField] private Transform turret;
    [SerializeField] private Transform muzzle;
    [SerializeField] private RangeIndicator rangeIndicator;

    [Header("설정")]
    [SerializeField] private float aimTolerance = 12f;
    [SerializeField] private float retargetInterval = 0.15f;

    private TowerData data;
    private Vector2Int cell;

    private Enemy currentTarget;
    private TargetPriority priority;
    private float fireTimer;
    private float retargetTimer;

    public TowerData Data => data;
    public Vector2Int Cell => cell;
    public Enemy CurrentTarget => currentTarget;

    public void Setup(TowerData d, Vector2Int c)
    {
        data = d;
        cell = c;
        priority = d.defaultPriority;

        rangeIndicator?.Hide();
    }

    // ★ TowerManager가 호출
    public void Tick(float dt)
    {
        fireTimer -= dt;
        retargetTimer -= dt;

        // 타겟 유효성
        if (currentTarget != null && !IsValidTarget(currentTarget))
            currentTarget = null;

        if (currentTarget == null || retargetTimer <= 0)
        {
            retargetTimer = retargetInterval;
            currentTarget = FindTarget();
        }

        Aim(dt);

        if (currentTarget != null && fireTimer <= 0 && IsAimed())
        {
            Fire();
            fireTimer = 1f / data.fireRate;
        }
    }

    // ─── 타겟 ───

    private bool IsValidTarget(Enemy e)
    {
        if (e == null || !e.IsAlive) return false;
        if (e.Data.moveType == EnemyMoveType.Flying && !data.canHitFlying) return false;

        Vector3 d = e.Position - transform.position;
        d.y = 0;

        return d.sqrMagnitude <= data.range * data.range;
    }

    private Enemy FindTarget()
    {
        var enemies = EnemyManager.Instance.Active;

        float rangeSq = data.range * data.range;
        Enemy best = null;
        float bestScore = float.MinValue;

        for (int i = 0; i < enemies.Count; i++)
        {
            Enemy e = enemies[i];
            if (e == null || !e.IsAlive) continue;
            if (e.Data.moveType == EnemyMoveType.Flying && !data.canHitFlying) continue;

            Vector3 d = e.Position - transform.position;
            d.y = 0;

            float distSq = d.sqrMagnitude;
            if (distSq > rangeSq) continue;

            float score = EvaluateTarget(e, distSq);
            if (score > bestScore) { bestScore = score; best = e; }
        }

        return best;
    }

    private float EvaluateTarget(Enemy e, float distSq) => priority switch
    {
        TargetPriority.First     => e.Progress,
        TargetPriority.Last      => -e.Progress,
        TargetPriority.Closest   => -distSq,
        TargetPriority.Strongest => e.CurrentHp,
        TargetPriority.Weakest   => -e.CurrentHp,
        _ => 0f
    };

    // ─── 조준 ───

    private void Aim(float dt)
    {
        if (currentTarget == null) return;

        Vector3 dir = currentTarget.Position - turret.position;
        dir.y = 0;

        if (dir.sqrMagnitude < 0.01f) return;

        Quaternion target = Quaternion.LookRotation(dir);

        turret.rotation = Quaternion.Slerp(
            turret.rotation, target, data.turnSpeed * dt);
    }

    private bool IsAimed()
    {
        Vector3 dir = currentTarget.Position - turret.position;
        dir.y = 0;

        return Vector3.Angle(turret.forward, dir) < aimTolerance;
    }

    // ─── 발사 ───

    private void Fire()
    {
        GameObject go = PoolManager.Instance.Get(
            data.projectilePoolKey, muzzle.position, turret.rotation);

        if (go == null) return;

        go.GetComponent<Projectile>()?.Launch(currentTarget, data);

        // 총구 화염 (Day 88)
        PoolManager.Instance.Get("muzzle_flash", muzzle.position, turret.rotation);
    }

    // ─── 선택 ───

    public void ShowRange() => rangeIndicator?.Show(data.range);
    public void HideRange() => rangeIndicator?.Hide();

    public void CyclePriority()
    {
        priority = (TargetPriority)(((int)priority + 1) % 5);
        Debug.Log($"[타워] 타겟 우선순위: {priority}");
    }

    void OnDrawGizmosSelected()
    {
        if (data == null) return;

        Gizmos.color = new Color(0.3f, 0.8f, 1f, 0.3f);
        Gizmos.DrawWireSphere(transform.position, data.range);

        if (currentTarget != null)
        {
            Gizmos.color = Color.red;
            Gizmos.DrawLine(muzzle.position, currentTarget.Position);
        }
    }
}
```

```csharp
    public static TowerManager Instance { get; private set; }
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **Raycast가 안 맞음** | Collider 없음 | 추가 |
| Raycast가 안 맞음 | LayerMask 오류 | 확인 |
| Raycast가 안 맞음 | 거리 부족 | `maxDistance` 늘리기 |
| **UI 뒤에도 배치됨** | 검사 누락 | `IsPointerOverGameObject` |
| 격자가 어긋남 | `(int)` 캐스팅 | `FloorToInt` / `Round` |
| 고스트가 불투명 | 머티리얼 Opaque | Transparent 셰이더 |
| 고스트가 실제로 동작 | 컴포넌트 잔존 | Tower/Collider 제거 |
| 포탑이 홱 돎 | 즉시 회전 | `Quaternion.Slerp` |
| 포탑이 기울어짐 | `dir.y` 미제거 | y = 0 |
| 엉뚱한 방향으로 발사 | 조준 판정 없음 | `IsAimed` |
| 사거리 검사가 무거움 | 매 프레임 + OverlapSphere | 주기 + 거리 계산 |
| 투사체가 안 맞음 | 유도 로직 | `homing` 확인 |
| 타겟이 죽으면 투사체 소멸 | 처리 방식 | 마지막 위치로 |
| 감속이 안 걸림 | `slowMultiplier` 1 | 1 미만으로 |
| 타워가 안 쏨 | 매니저 미등록 | `Register` 호출 |
