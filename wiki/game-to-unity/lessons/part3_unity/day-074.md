## 3. 개념

### 3-1. 프리팹

**왜 필요한가** — 오브젝트 템플릿. Part 2에서 클래스로 하던 일.

```
   Part 2                        Unity

   class Coin : GameObject       Coin 프리팹 애셋
   {                             ├─ Transform
       Sprite* sprite;           ├─ MeshRenderer + Material
       int value;                ├─ SphereCollider (Trigger)
   };                            └─ Coin.cs (value = 1)

   new Coin()                    Instantiate(coinPrefab)
```

```
   ★ 프리팹은 "컴포넌트 조합 + 설정값"의 저장본

   코드가 아니라 애셋이다
   → 프로그래머가 아니어도 수정할 수 있다
```

**만드는 법**

```
   Hierarchy의 오브젝트를 Project 창의 Prefabs 폴더로 드래그
   → 파란색 아이콘이 되면 프리팹 인스턴스
```

**프리팹 편집**

| 방식 | 방법 | 영향 |
|---|---|---|
| 프리팹 모드 | Project에서 더블클릭 | **모든 인스턴스** |
| 인스턴스 편집 | Hierarchy에서 값 변경 | **그 인스턴스만** (오버라이드) |
| Apply | 인스턴스 → Overrides → Apply All | 원본에 반영 |
| Revert | Overrides → Revert All | 오버라이드 취소 |

```
   ★ 오버라이드 표시

   Inspector에서 굵은 글씨 + 왼쪽 파란 줄
   → "이 인스턴스만 원본과 다르다"
```

```
   ⚠️ 흔한 혼란

   "값을 바꿨는데 다른 인스턴스는 그대로다"
   → 인스턴스만 고쳤다.  Apply 하거나 프리팹 모드에서 수정

   "프리팹을 고쳤는데 어떤 인스턴스만 안 바뀐다"
   → 그 인스턴스에 오버라이드가 걸려 있다.  Revert
```

**중첩 프리팹**

```
   P_TerrainChunk (프리팹)
   ├─ Ground
   ├─ P_Coin (프리팹)          ← 프리팹 안의 프리팹
   ├─ P_Coin
   └─ P_Obstacle (프리팹)
```

```
   ★ Unity 2018.3부터 지원

   Coin 프리팹을 고치면 모든 청크의 코인이 바뀐다
```

### 3-3. GC — 새로운 형태의 오래된 문제

**왜 필요한가** — Day 51의 문제가 다른 얼굴로 나타난다.

```
   C++ (Part 2)                  C# (Unity)

   new  →  힙 할당               new  →  힙 할당
   delete → 즉시 해제             (해제 없음)
                                  ↓
                                  쓰레기가 쌓인다
                                  ↓
                                  GC가 주기적으로 청소
                                  ↓
                                  ★ 청소하는 동안 멈춘다
```

```
   프레임 시간

   16.6ms ┤ ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁
          │             █
   40ms   ┤             █          ← GC 스파이크
          │ ▁▁▁▁▁▁▁▁▁▁▁▁█▁▁▁▁▁▁▁▁▁
          └──────────────────────────▶ 시간

   평균은 60fps인데 가끔 뚝 끊긴다
```

```
   ★ Day 70에서 배운 것

   "평균이 아니라 최악을 봐야 한다"
```

**GC 할당을 만드는 것들**

| 코드 | 할당 | 대안 |
|---|:--:|---|
| `Instantiate` / `Destroy` | 큼 | 오브젝트 풀 |
| `new List<>()` 매 프레임 | 있음 | 재사용 |
| `GetComponent` (일부) | 있음 | 캐싱 |
| `"문자열" + 변수` | 있음 | `StringBuilder` |
| `foreach` (일부 컬렉션) | 있음 | `for` |
| `new WaitForSeconds()` | 있음 | 필드로 캐싱 |
| `GameObject.Find` | 있음 | 캐싱 |
| `Physics.RaycastAll` | 있음 | `RaycastNonAlloc` |

### 3-4. 오브젝트 풀 — Day 52를 C#으로

**왜 필요한가** — 오늘의 핵심.

```
   Day 52에서 만든 것

   ① 미리 N개 만들어 둔다
   ② 필요하면 "비활성" 중 하나를 켠다
   ③ 다 쓰면 끄고 돌려놓는다
   ④ 할당/해제가 0

   Unity에서도 똑같다
   Destroy 대신  →  SetActive(false)
   Instantiate 대신 →  SetActive(true)
```

```csharp
using System.Collections.Generic;
using UnityEngine;

public class SimplePool : MonoBehaviour
{
    [SerializeField] private GameObject prefab;
    [SerializeField] private int initialSize = 20;

    private readonly Queue<GameObject> pool = new Queue<GameObject>();
    private readonly List<GameObject> all = new List<GameObject>();

    void Awake()
    {
        for (int i = 0; i < initialSize; i++)
            Create();
    }

    private GameObject Create()
    {
        GameObject go = Instantiate(prefab, transform);
        go.SetActive(false);
        pool.Enqueue(go);
        all.Add(go);
        return go;
    }

    public GameObject Get(Vector3 pos, Quaternion rot)
    {
        // ★ 비어 있으면 늘린다 (Day 52의 "풀이 고갈되면")
        if (pool.Count == 0) Create();

        GameObject go = pool.Dequeue();

        go.transform.SetPositionAndRotation(pos, rot);
        go.SetActive(true);

        return go;
    }

    public void Return(GameObject go)
    {
        if (!go.activeSelf) return;            // ★ 이중 반납 방지

        go.SetActive(false);
        pool.Enqueue(go);
    }

    public int ActiveCount => all.Count - pool.Count;
    public int TotalCount  => all.Count;
}
```

```
   ★ Queue를 쓴 이유

   Day 52의 free list와 같은 역할
   Enqueue/Dequeue 가 O(1)
```

```
   ⚠️ 이중 반납

   같은 오브젝트를 두 번 Return 하면
   → 큐에 두 번 들어간다
   → 두 곳에서 동시에 꺼내 쓴다

   Day 53에서 겪은 그 문제
   → activeSelf 검사로 막는다
```

### 3-5. Unity 내장 ObjectPool&lt;T&gt;

**왜 필요한가** — 직접 만들지 않아도 된다. 하지만 원리를 안 뒤에.

```csharp
using UnityEngine.Pool;

public class BulletSpawner : MonoBehaviour
{
    [SerializeField] private Bullet prefab;

    private ObjectPool<Bullet> pool;

    void Awake()
    {
        pool = new ObjectPool<Bullet>(
            createFunc:      () => Instantiate(prefab),
            actionOnGet:     b  => b.gameObject.SetActive(true),
            actionOnRelease: b  => b.gameObject.SetActive(false),
            actionOnDestroy: b  => Destroy(b.gameObject),
            collectionCheck: true,             // ★ 이중 반납 검사
            defaultCapacity: 20,
            maxSize: 200
        );
    }

    public Bullet Spawn(Vector3 pos)
    {
        Bullet b = pool.Get();
        b.transform.position = pos;
        b.SetPool(pool);                       // 스스로 반납하도록
        return b;
    }
}
```

| 항목 | 직접 구현 | 내장 `ObjectPool<T>` |
|---|---|---|
| 코드량 | 40줄 | 10줄 |
| 이중 반납 검사 | 직접 | `collectionCheck` |
| 최대 크기 제한 | 직접 | `maxSize` |
| 학습 가치 | **높음** | 낮음 |

```
   ★ 순서가 중요하다

   ① 직접 만들어 원리를 안다 (Day 52 + 오늘)
   ② 내장을 쓴다

   반대로 하면 문제가 생겼을 때 못 고친다
```

### 3-6. 풀에서 꺼낸 오브젝트 초기화

**왜 필요한가** — Day 52에서 겪은 그 함정.

```
   ★ 풀에서 꺼낸 것은 "이전 상태"를 그대로 가지고 있다

   × 속도가 남아 있다
   × HP가 0이다
   × 애니메이션이 중간이다
   × 파티클이 재생 중이다
   × 자식 오브젝트가 꺼져 있다
```

```csharp
public class Coin : MonoBehaviour, IPoolable
{
    [SerializeField] private int value = 1;
    private float rotOffset;

    public void OnSpawn()                      // ★ 꺼낼 때
    {
        rotOffset = Random.value * 360f;
        transform.localRotation = Quaternion.Euler(0, rotOffset, 0);
        transform.localScale = Vector3.one * 0.4f;

        GetComponent<Collider>().enabled = true;
        GetComponent<Renderer>().enabled = true;
    }

    public void OnDespawn()                    // ★ 넣을 때
    {
        // 필요하면 정리
    }
}
```

```csharp
public interface IPoolable
{
    void OnSpawn();
    void OnDespawn();
}
```

```csharp
    // 풀에서 호출
    public GameObject Get(Vector3 pos, Quaternion rot)
    {
        if (pool.Count == 0) Create();

        GameObject go = pool.Dequeue();
        go.transform.SetPositionAndRotation(pos, rot);
        go.SetActive(true);

        // ★ 초기화 호출
        foreach (var p in go.GetComponentsInChildren<IPoolable>(true))
            p.OnSpawn();

        return go;
    }
```

### 3-7. 무한 스크롤 — 청크 방식

**왜 필요한가** — 지형을 조각 단위로 관리한다.

```
   ★ 두 가지 접근

   ① 플레이어가 앞으로 이동, 지형은 고정
      → 좌표가 계속 커진다
      → 부동소수점 정밀도 문제 (100,000 넘어가면 떨림)

   ② 플레이어는 제자리, 지형이 뒤로 이동
      → 좌표가 안정적
      → 카메라도 고정
```

```
   ①이 일반적이다 (러너 게임은 몇 km 수준이라 문제없음)
   무한 러너나 오픈월드는 ② 또는 좌표 원점 이동(floating origin)
```

**청크 배치**

```
   청크 길이 = 20

   z:  -20    0    20    40    60    80
       [ 0 ][ 1 ][ 2 ][ 3 ][ 4 ]
              ▲              ▲
           플레이어        생성 경계

   플레이어가 청크 2에 들어서면
   → 청크 5를 만들고
   → 청크 0을 회수
```

```csharp
public class TerrainGenerator : MonoBehaviour
{
    [SerializeField] private Transform player;
    [SerializeField] private float chunkLength = 20f;
    [SerializeField] private int chunksAhead = 4;
    [SerializeField] private int chunksBehind = 1;

    private readonly List<GameObject> active = new List<GameObject>();
    private float nextSpawnZ = 0f;

    void Update()
    {
        // ★ 앞에 생성
        while (nextSpawnZ < player.position.z + chunksAhead * chunkLength)
        {
            SpawnChunk(nextSpawnZ);
            nextSpawnZ += chunkLength;
        }

        // ★ 뒤에 회수
        float despawnZ = player.position.z - chunksBehind * chunkLength;

        for (int i = active.Count - 1; i >= 0; i--)   // ★ 역순 (Day 53)
        {
            if (active[i].transform.position.z < despawnZ)
            {
                pool.Return(active[i]);
                active.RemoveAt(i);
            }
        }
    }
}
```

```
   ★ while 을 쓴 이유

   프레임이 크게 튀어 플레이어가 여러 청크를 한 번에 지나가면
   if 로는 하나만 생성된다 → 구멍
```

### 3-9. 청크 안 콘텐츠 배치

**왜 필요한가** — 코인·장애물을 매번 다르게.

**방법 1 — 프리팹에 고정 배치**

```
   P_Chunk_A:  코인 3개 + 장애물 1개 (고정 위치)
   P_Chunk_B:  장애물 2개
   P_Chunk_C:  코인 5개

   → 랜덤으로 청크를 골라 다양성 확보
```

```
   장점:  디자인 가능. 재미있는 배치를 만들 수 있다
   단점:  패턴이 반복된다
```

**방법 2 — 스폰 포인트 + 랜덤**

```csharp
public class TerrainChunk : MonoBehaviour
{
    [SerializeField] private Transform[] spawnPoints;
    [SerializeField, Range(0f, 1f)] private float coinChance = 0.5f;
    [SerializeField, Range(0f, 1f)] private float obstacleChance = 0.2f;

    private readonly List<GameObject> spawned = new List<GameObject>();

    public void PopulateContent(SimplePool coinPool, SimplePool obstaclePool)
    {
        ClearContent(coinPool, obstaclePool);

        foreach (Transform p in spawnPoints)
        {
            float r = Random.value;

            if (r < obstacleChance)
                spawned.Add(obstaclePool.Get(p.position, p.rotation));
            else if (r < obstacleChance + coinChance)
                spawned.Add(coinPool.Get(p.position, p.rotation));
        }
    }
}
```

```
   ⚠️ 청크를 회수할 때 안의 내용물도 함께 회수해야 한다

   빠뜨리면 코인이 허공에 남는다
```

```csharp
using System.Collections.Generic;
using UnityEngine;

public class SimplePool : MonoBehaviour
{
    [SerializeField] private GameObject prefab;
    [SerializeField] private int initialSize = 10;
    [SerializeField] private int maxSize = 100;

    private readonly Queue<GameObject> idle = new Queue<GameObject>();
    private int totalCreated;

    public string PoolName => prefab != null ? prefab.name : "(none)";
    public int TotalCount  => totalCreated;
    public int IdleCount   => idle.Count;
    public int ActiveCount => totalCreated - idle.Count;

    void Awake()
    {
        for (int i = 0; i < initialSize; i++)
            idle.Enqueue(CreateNew());
    }

    private GameObject CreateNew()
    {
        GameObject go = Instantiate(prefab, transform);
        go.SetActive(false);

        PooledObject po = go.GetComponent<PooledObject>();
        if (po == null) po = go.AddComponent<PooledObject>();
        po.Owner = this;

        totalCreated++;
        return go;
    }

    public GameObject Get(Vector3 pos, Quaternion rot)
    {
        GameObject go;

        if (idle.Count > 0) go = idle.Dequeue();
        else
        {
            if (totalCreated >= maxSize)
            {
                Debug.LogWarning($"[풀] {PoolName} 최대치 {maxSize} 도달");
                return null;
            }
            go = CreateNew();
        }

        go.transform.SetPositionAndRotation(pos, rot);
        go.SetActive(true);

        go.GetComponent<PooledObject>().NotifySpawn();

        return go;
    }

    public void Return(GameObject go)
    {
        if (go == null) return;
        if (!go.activeSelf) return;            // ★ 이중 반납 방지

        go.GetComponent<PooledObject>().NotifyDespawn();

        go.SetActive(false);
        go.transform.SetParent(transform);
        idle.Enqueue(go);
    }
}
```

```csharp
using System.Collections.Generic;
using UnityEngine;

public class TerrainGenerator : MonoBehaviour
{
    [Header("참조")]
    [SerializeField] private Transform player;

    [Header("청크")]
    [SerializeField] private string[] chunkKeys;
    [SerializeField] private float chunkLength = 20f;
    [SerializeField] private int chunksAhead = 4;
    [SerializeField] private int chunksBehind = 1;

    [Header("모드")]
    [SerializeField] private bool usePooling = true;
    [SerializeField] private GameObject[] chunkPrefabs;    // 나이브 모드용

    private readonly List<GameObject> active = new List<GameObject>();
    private float nextSpawnZ;

    void Start()
    {
        nextSpawnZ = 0f;

        // 시작 시 몇 개 미리
        for (int i = 0; i < chunksAhead + chunksBehind; i++)
        {
            SpawnChunk(nextSpawnZ);
            nextSpawnZ += chunkLength;
        }
    }

    void Update()
    {
        while (nextSpawnZ < player.position.z + chunksAhead * chunkLength)
        {
            SpawnChunk(nextSpawnZ);
            nextSpawnZ += chunkLength;
        }

        float despawnZ = player.position.z - chunksBehind * chunkLength;

        for (int i = active.Count - 1; i >= 0; i--)
        {
            if (active[i] == null) { active.RemoveAt(i); continue; }

            if (active[i].transform.position.z + chunkLength < despawnZ)
            {
                DespawnChunk(active[i]);
                active.RemoveAt(i);
            }
        }
    }

    private void SpawnChunk(float z)
    {
        GameObject go;

        if (usePooling)
        {
            string key = chunkKeys[Random.Range(0, chunkKeys.Length)];
            go = PoolManager.Instance.Get(key, new Vector3(0, 0, z), Quaternion.identity);
            if (go == null) return;
        }
        else
        {
            int i = Random.Range(0, chunkPrefabs.Length);
            go = Instantiate(chunkPrefabs[i], new Vector3(0, 0, z), Quaternion.identity);
        }

        TerrainChunk chunk = go.GetComponent<TerrainChunk>();
        if (chunk != null) chunk.PopulateContent(usePooling);

        active.Add(go);
    }

    private void DespawnChunk(GameObject go)
    {
        TerrainChunk chunk = go.GetComponent<TerrainChunk>();
        if (chunk != null) chunk.ClearContent(usePooling);

        if (usePooling) PoolManager.Instance.Return(go);
        else            Destroy(go);
    }

    public void SetPooling(bool on)
    {
        // ★ 모드 전환 시 전부 정리
        foreach (GameObject go in active)
        {
            if (go == null) continue;
            TerrainChunk c = go.GetComponent<TerrainChunk>();
            if (c != null) c.ClearContent(usePooling);

            if (usePooling) PoolManager.Instance.Return(go);
            else            Destroy(go);
        }
        active.Clear();

        usePooling = on;
        nextSpawnZ = Mathf.Floor(player.position.z / chunkLength) * chunkLength;

        for (int i = 0; i < chunksAhead + chunksBehind; i++)
        {
            SpawnChunk(nextSpawnZ);
            nextSpawnZ += chunkLength;
        }
    }

    public bool IsPooling => usePooling;
    public int ActiveChunks => active.Count;
}
```

```csharp
using System.Collections.Generic;
using UnityEngine;

public class TerrainChunk : MonoBehaviour
{
    [SerializeField] private Transform[] spawnPoints;

    [Range(0f, 1f)][SerializeField] private float obstacleChance = 0.2f;
    [Range(0f, 1f)][SerializeField] private float coinChance = 0.5f;

    private readonly List<GameObject> spawned = new List<GameObject>();

    public void PopulateContent(bool usePooling)
    {
        ClearContent(usePooling);

        foreach (Transform p in spawnPoints)
        {
            float r = Random.value;

            string key = null;

            if (r < obstacleChance)                        key = "obstacle";
            else if (r < obstacleChance + coinChance)       key = "coin";
            else continue;

            GameObject go;

            if (usePooling)
                go = PoolManager.Instance.Get(key, p.position, p.rotation);
            else
                go = Instantiate(GetPrefab(key), p.position, p.rotation);

            if (go != null) spawned.Add(go);
        }
    }

    public void ClearContent(bool usePooling)
    {
        foreach (GameObject go in spawned)
        {
            if (go == null) continue;

            if (usePooling) PoolManager.Instance.Return(go);
            else            Destroy(go);
        }
        spawned.Clear();
    }

    // 나이브 모드용 프리팹 참조
    [SerializeField] private GameObject coinPrefab;
    [SerializeField] private GameObject obstaclePrefab;

    private GameObject GetPrefab(string key)
        => key == "coin" ? coinPrefab : obstaclePrefab;
}
```

```csharp
                  $"모드: {(generator.IsPooling ? "오브젝트 풀" : "Instantiate/Destroy")}   [F1] 전환", s);
        y += 24;

        GUI.Label(new Rect(10, y, 500, 24),
                  $"FPS {fps:F1}   최악 프레임 {worstFrame * 1000f:F1} ms", s);
        y += 24;

        GUI.Label(new Rect(10, y, 500, 24),
                  $"활성 청크 {generator.ActiveChunks}   씬 오브젝트 {CountSceneObjects()}", s);
        y += 24;

        if (PoolManager.Instance != null)
        {
            foreach (SimplePool p in PoolManager.Instance.AllPools)
            {
                GUI.Label(new Rect(10, y, 500, 22),
                          $"  {p.PoolName,-20} 활성 {p.ActiveCount,3} / 총 {p.TotalCount,3}", s);

            }
        }
    }

    private int CountSceneObjects()
    {
        return FindObjectsByType<Transform>(FindObjectsSortMode.None).Length;
    }
}
```

### Step 17 — 난이도 곡선

```csharp
public class DifficultyManager : MonoBehaviour
{
    public static DifficultyManager Instance { get; private set; }

    [SerializeField] private float startSpeed = 8f;
    [SerializeField] private float maxSpeed = 20f;
    [SerializeField] private float speedPerSecond = 0.15f;

    [SerializeField] private AnimationCurve obstacleCurve
        = AnimationCurve.Linear(0, 0.15f, 300, 0.45f);

    public float CurrentSpeed { get; private set; }
    public float ObstacleChance => obstacleCurve.Evaluate(elapsed);

    private float elapsed;

    void Awake() { Instance = this; CurrentSpeed = startSpeed; }

    void Update()
    {
        if (GameManager.Instance.IsGameOver) return;

        elapsed += Time.deltaTime;

        CurrentSpeed = Mathf.Min(maxSpeed, startSpeed + elapsed * speedPerSecond);
    }
}
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 청크 사이에 틈 | 길이 불일치 | 접합 마커 또는 고정 길이 |
| 청크가 겹침 | `nextSpawnZ` 갱신 오류 | while 루프 확인 |
| **꺼낸 오브젝트에 이전 상태** | 초기화 누락 | `OnSpawn`에서 리셋 |
| 코인이 허공에 남음 | 청크 회수 시 내용물 미회수 | `ClearContent` |
| 풀에서 null 반환 | `Destroy`로 없앰 | `Return` 사용 |
| 같은 오브젝트가 둘 | 이중 반납 | `activeSelf` 검사 |
| 초반에만 렉 | 초기 크기 부족 | `initialSize` 늘리기 |
| 오브젝트가 안 나옴 | `maxSize` 도달 | 로그 확인 후 조정 |
| GC가 여전히 발생 | 다른 곳에서 할당 | 프로파일러 Hierarchy 확인 |
| Hierarchy가 계속 증가 | 회수 안 됨 | despawn 조건 확인 |
| 프리팹 수정이 반영 안 됨 | 인스턴스 오버라이드 | Revert 또는 Apply |
| 한 프레임에 구멍 | `if` 로 생성 | `while` 로 변경 |
| 풀이 Awake 순서 문제 | `AddComponent` + Awake | `Setup`에서 초기화 |
