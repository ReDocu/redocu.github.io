## 이 단원부터 달라지는 것

### 노트북 밖으로 나갑니다

지금까지 만든 모델 4개는 전부 같은 곳에 있었습니다.

```
슈팅게임        → 내 컴퓨터
여행지 추천      → 주피터 노트북
늑대 vs 허스키   → 주피터 노트북
스팀 가격 예측   → 주피터 노트북
```

**아무도 쓸 수 없습니다.** 코드를 받아서, 파이썬을 깔고, 패키지를 맞추고, 셀을 순서대로 돌려야 결과를 봅니다.

이 단원의 결과물은 이렇게 씁니다.

```
휴대폰 브라우저 → 사진 업로드 → 3초 뒤 검출 결과
현관 카메라     → 사람 감지   → 텔레그램 알림
```

> **"모델을 만드는 법"에서 "만든 모델을 쓰이게 하는 법"으로 넘어갑니다.**
> 45일 중 25일이 배포·서비스·기기 연동입니다. 모델 학습은 10일뿐입니다.

### "무엇인가"에서 "어디에 몇 개 있는가"로

대단원 03의 CNN은 사진 한 장에 답 하나를 냈습니다.

```python
model.predict(사진)      # → "허스키"
```

**사진에 허스키가 세 마리면 어떻게 됩니까?** 여전히 "허스키" 하나입니다. 몇 마리인지, 어디에 있는지는 모릅니다.

검출 모델의 답은 이렇습니다.

```python
model.predict(사진)
# → [{"class": "dog", "conf": 0.94, "box": [ 34,  88, 210, 340]},
#     {"class": "dog", "conf": 0.87, "box": [280, 110, 430, 360]},
#     {"class": "dog", "conf": 0.51, "box": [455,  95, 512, 300]}]
```

**답의 개수가 정해져 있지 않습니다.** 0개일 수도, 30개일 수도 있습니다.
그래서 채점 방법부터 다시 만들어야 합니다. 그것이 [Day 148](day-148.md)의 mAP입니다.

| | 대단원 03 (분류) | 대단원 05 (검출) |
|---|---|---|
| 입력 | 이미지 | 이미지 |
| 출력 | 클래스 1개 | **객체 N개 (클래스 + 좌표 + 신뢰도)** |
| 정답 라벨 | 폴더 이름 | **박스 좌표 파일** |
| 라벨 만들기 | 사진을 폴더에 넣기 | **한 장씩 손으로 박스 치기** |
| 평가 | 정확도 · F1 | **IoU · AP · mAP** |
| 틀리는 방식 | 오분류 하나 | **미검출 / 오검출 / 박스 어긋남 / 중복** |
| 임계값 | 없음 (argmax) | **`conf` · `iou` 두 개를 내가 정함** |

### 데이터를 처음으로 직접 만듭니다

| 대단원 | 데이터 출처 |
|---|---|
| 02 | 공개 API · 크롤링 |
| 03 | 이미지 검색 · 공개 데이터셋 |
| 04 | 스팀 공개 API |
| **05** | **직접 촬영하고 직접 박스를 칩니다** |

500장에 박스를 치면 대략 **6~10시간**입니다. 팀이 나눠도 하루 이상 걸립니다.

> ⚠️ **이 단원의 성능은 라벨링에서 결정됩니다.**
> 대단원 03의 적은 **과적합**, 대단원 04의 적은 **누수**였습니다.
> 이 단원의 적은 **일관성 없는 라벨**입니다.
> 어제의 나와 오늘의 나가 다른 기준으로 박스를 치면, 모델은 그 모순을 그대로 배웁니다.

### 처음으로 "느리면 실패"가 됩니다

```
스팀 가격 예측 : 1건 예측에 0.3초  →  아무 문제 없음
CCTV          : 1프레임에 0.3초   →  3.3 FPS  →  사람이 지나가면 놓침
```

정확도만 보던 지금까지와 달리, 이 단원에서는 **정확도와 속도를 동시에 만족**시켜야 합니다.
그리고 라즈베리파이라는, 노트북보다 20배 느린 기계 위에서 그걸 해야 합니다([Day 168](day-168.md)).

> 같은 이미지 500장이라도 분류는 5분, 검출은 30~60분 걸립니다.
> **Colab 무료 티어는 세션이 끊깁니다.** [Day 146](day-146.md)의 `resume` 를 반드시 익히세요.

## 실험 기록표 양식 (대단원 05 확장판)

대단원 04의 양식에 **데이터셋 버전 · 해상도 · 추론 속도** 열이 추가됩니다.
검출은 "정확도만"이 아니라 "이 속도에서 이 정확도"를 기록해야 의미가 있습니다.
