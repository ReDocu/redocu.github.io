## ② 왜 필요한가

**Java 문제의 절대 다수는 "상속 + 오버라이딩 + 다형성" 3종 세트입니다.** `Animal a = new Dog(); a.sound();`가 무엇을 출력하는지 — 이 한 줄의 판정 규칙을 모르면 Java 문제 대부분을 찍게 되고, 알면 거꾸로 가장 기계적으로 풀리는 유형이 됩니다(기출 복원 기반 비공식 경향). 예외 처리는 "에러가 나면 어디로 점프하고, finally는 언제 실행되는가"라는 **흐름 추적 문제**로 출제됩니다.

Python은 문법이 짧아 쉬워 보이지만, 그래서 **한 줄에 함정을 심기 좋은 언어**입니다. `a[::-1]`, `set()`의 중복 제거, 튜플의 불변처럼 "짧지만 모르면 못 푸는" 표현이 결과 예측 유형으로 나옵니다.

**시험에서의 중요도와 출제 형태** — 결과 예측(다형성 출력, 예외 흐름, 슬라이싱), 빈칸(`extends`, `@Override`, 슬라이싱 범위), 단답(오버라이딩 정의, 예외 이름) 유형. 오늘로 2단원(코드)이 완성되고, 7주차 통합 세트와 모의고사에서 계속 재출제됩니다.

## ③ 개념 설명

### 3-1. 클래스와 객체, 생성자

**클래스(class)** 는 붕어빵 틀, **객체(object)** 는 그 틀로 찍은 붕어빵입니다. **생성자(constructor)** 는 객체가 만들어질 때 자동으로 한 번 실행되는 특별한 메서드(클래스와 같은 이름, 반환형 없음)입니다.

**상속(inheritance)** 은 부모 클래스의 멤버를 자식이 물려받는 것 — Java는 `class Dog extends Animal`로 표기합니다.

📌 **반드시 암기 — 생성자 실행 순서**: 자식 객체를 만들면 **부모 생성자가 먼저, 자식 생성자가 나중에** 실행됩니다. (건물 기초 공사가 먼저라는 비유) → ④ Step 2에서 `AB` 출력으로 확인.

### 3-2. 오버라이딩 vs 오버로딩 — 최빈출 비교

⚖️ **혼동 비교 (📌 표째 암기)**

| 구분 | 오버라이딩 (Overriding) | 오버로딩 (Overloading) |
|---|---|---|
| 뜻 | 부모의 메서드를 자식이 **재정의** | 한 클래스에서 **같은 이름**의 메서드를 매개변수 다르게 여러 개 |
| 관계 | 상속 관계 **필수** | 상속 무관 (한 클래스 안에서 가능) |
| 시그니처 | 이름·매개변수 **동일**해야 함 | 이름 동일, 매개변수(개수·타입) **달라야 함** |
| 선택 시점 | 실행 시(어떤 객체인가) | 컴파일 시(어떤 인자인가) |
| 기억법 | 라이딩 = 위에 **올라타기**(덮어쓰기) | 로딩 = 옆에 **쌓기**(추가) |

`@Override`는 "오버라이딩 의도"를 컴파일러에 알리는 표기로, 이름 오타 시 에러를 내 줍니다(없어도 오버라이딩은 성립 — ⑤ 함정 참고).

### 3-3. 다형성 — 부모 그릇에 자식 내용물

**다형성(polymorphism)** 은 부모 타입 변수가 자식 객체를 담을 수 있는 성질입니다: `Animal a = new Dog();`

📌 **반드시 암기 — 호출 판정 2규칙**

| 규칙 | 내용 |
|---|---|
| 1 | **어떤 메서드가 실행되는가 = 실제 객체(new 뒤)** 기준 — 오버라이딩된 메서드는 **자식 것**이 실행 |
| 2 | **어떤 메서드를 부를 수 있는가 = 변수 타입(선언부)** 기준 — 자식에만 있는 메서드는 부모 타입 변수로 **호출 불가**(컴파일 에러) |

"그릇(변수 타입)이 메뉴판을 정하고, 내용물(객체)이 맛을 정한다"로 기억하세요.

### 3-4. 예외 처리 — try-catch-finally

**예외(exception)** 는 실행 중 발생하는 오류 상황이고, 예외 처리는 프로그램을 죽이지 않고 지정된 곳으로 흐름을 옮기는 장치입니다.

| 블록 | 역할 | 실행 규칙 |
|---|---|---|
| `try` | 감시 구역 | 예외 발생 **줄에서 즉시 중단**, 나머지 try 코드는 건너뜀 |
| `catch (예외타입 e)` | 예외 발생 시 점프해 오는 곳 | 타입이 맞는 catch 하나만 실행 |
| `finally` | 마무리 구역 | 예외가 **나든 안 나든 항상** 실행 |

📌 **반드시 암기 — 주요 예외 이름** (철자까지 단답 출제 가능)

| 예외 | 언제 |
|---|---|
| `ArithmeticException` | 정수를 0으로 나눔 (`/ by zero`) |
| `ArrayIndexOutOfBoundsException` | 배열 범위 밖 인덱스 |
| `NullPointerException` | null인 참조로 멤버 접근 |
| `NumberFormatException` | 숫자가 아닌 문자열을 숫자로 변환 |

### 3-5. Python 자료형 4종

📌 **반드시 암기 (표째)**

| 자료형 | 표기 | 순서 | 중복 | 변경 | 대표 용도 |
|---|---|---|---|---|---|
| 리스트 list | `[1, 2, 3]` | O | O | **가능(가변)** | 배열처럼 — `append`, `sort` |
| 튜플 tuple | `(1, 2, 3)` | O | O | **불가(불변)** | 고정 묶음 |
| 딕셔너리 dict | `{"키": 값}` | (키로 접근) | 키 중복 X | 가능 | 이름표로 찾기 — `d["키"]` |
| 집합 set | `{1, 2, 3}` | **X** | **X (중복 제거)** | 가능 | 중복 없애기, 집합 연산 |

⚖️ **혼동 주의**: `()`인데 바꾸려 하면 에러(튜플), `{}`인데 콜론이 없으면 집합·있으면 딕셔너리. `set([1, 2, 2, 3])`처럼 **리스트를 set에 넣는 순간 중복이 사라지는** 것이 결과 예측 단골입니다.

### 3-6. 슬라이싱 — [시작:끝:간격]

📌 **반드시 암기**: `s[start:end:step]` — start **포함**, end **미포함**, step 간격. 생략 시 처음/끝/1. 음수 인덱스는 뒤에서부터(`s[-1]`이 마지막). **`s[::-1]`은 역순 전체**.

### 3-7. 함수와 주요 내장 함수

```python
def f(a, b=10):      # b는 기본값 인자 — 안 주면 10
    return a + b
```

| 내장 함수 | 뜻 | 예 |
|---|---|---|
| `len(x)` | 길이 | `len("ABC")` → 3 |
| `sum(x)` / `max(x)` / `min(x)` | 합/최대/최소 | `sum([1,2,3])` → 6 |
| `sorted(x)` | **정렬된 새 리스트 반환** (원본 유지) | ⚖️ `x.sort()`는 원본을 바꾸고 None 반환 |
| `round(x)` | 반올림 | `round(3.6)` → 4 |
| `str(x)` / `int(x)` | 형 변환 | `int("7")` → 7 |

### Step 2. 상속과 생성자 실행 순서

**언어: Java · 난이도: 🟡 기본 · 학습 개념: extends, 부모 생성자 우선**

```java
class A {
    A() { System.out.print("A"); }
}
class B extends A {
    B() { System.out.print("B"); }
}
public class Main {
    public static void main(String[] args) {
        B b = new B();
    }
}
```

```
$ javac Main.java && java Main
AB
```

`new B()` 하나로 **부모 A의 생성자가 먼저** 실행됩니다(자식 생성자 첫 줄에 부모 호출이 숨어 있음). 대표 오답 `B`, `BA` — "만든 건 B인데 왜 A부터?"가 이 유형의 출제 의도입니다.

### Step 3. 다형성 — 이 강의 핵심 한 줄

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 오버라이딩 + 부모 타입 변수**

```java
class Animal {
    void sound() { System.out.println("동물 소리"); }
}
class Dog extends Animal {
    @Override
    void sound() { System.out.println("멍멍"); }
    void run() { System.out.println("달린다"); }
}
public class Poly {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
        // a.run();   ← 컴파일 에러: 변수 타입 Animal의 메뉴판에 run이 없음
    }
}
```

```
$ javac Poly.java && java Poly
멍멍
```

판정 절차(3-3의 2규칙): ①호출 가능한가? — 변수 타입 Animal에 `sound()` 있음 → 가능 ②무엇이 실행되나? — 실제 객체가 Dog이고 sound는 오버라이딩됨 → **자식 것** `멍멍`. 주석의 `a.run()`은 규칙 2에 걸려 **실행 전에 컴파일 에러**가 나는 것까지가 출제 범위입니다.

### Step 4. 오버로딩 — 인자가 메서드를 고른다

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 같은 이름, 다른 매개변수**

```java
public class Load {
    static int add(int a, int b) { return a + b; }
    static double add(double a, double b) { return a + b; }
    public static void main(String[] args) {
        System.out.println(add(3, 4));
        System.out.println(add(3.0, 4.0));
    }
}
```

```
$ javac Load.java && java Load
7
7.0
```

`add(3, 4)`는 int판, `add(3.0, 4.0)`은 double판이 선택됩니다. 출력의 `7`과 `7.0` 차이(정수/실수 표기)까지 그대로 옮겨 적어야 정답입니다 — 필답형 표기 함정.

### Step 5. 예외 흐름 추적

**언어: Java · 난이도: 🟡 기본 · 학습 개념: try-catch-finally 실행 순서**

```java
public class Ex {
    public static void main(String[] args) {
        try {
            System.out.print("A");
            int r = 10 / 0;
            System.out.print("B");
        } catch (ArithmeticException e) {
            System.out.print("C");
        } finally {
            System.out.print("D");
        }
        System.out.print("E");
    }
}
```

```
$ javac Ex.java && java Ex
ACDE
```

흐름: `A` 출력 → `10 / 0`에서 `ArithmeticException` 발생, **그 줄에서 try 중단**(B는 영원히 건너뜀) → catch로 점프해 `C` → finally는 항상 `D` → 예외가 처리됐으므로 프로그램은 계속되어 `E`. **B가 빠지는 이유**를 설명할 수 있어야 합니다.

### Step 6. Python 자료형 — 한 화면 비교

**언어: Python · 난이도: 🟡 기본 · 학습 개념: 리스트·튜플·딕셔너리·집합의 구분**

### Step 7. 슬라이싱과 함수

**언어: Python · 난이도: 🟡 기본 · 학습 개념: 슬라이싱 3인자, 역순, 기본값 인자**

```python
a = [10, 20, 30, 40, 50]
print(a[1:4])
print(a[::2])
print(a[::-1])

def f(x, y=10):
    return x + y
print(f(5), f(5, 20))
```

```
$ python slice.py
[20, 30, 40]
[10, 30, 50]
[50, 40, 30, 20, 10]
15 25
```

| 식 | 해석 | 결과 |
|---|---|---|
| `a[1:4]` | 1·2·3번 (끝 4 미포함) | [20, 30, 40] |
| `a[::2]` | 처음부터 끝까지 2칸씩 | [10, 30, 50] |
| `a[::-1]` | 역순 전체 | [50, 40, 30, 20, 10] |
| `f(5)` | y는 기본값 10 | 15 |

리스트 출력은 **대괄호·쉼표까지 그대로**(`[20, 30, 40]`) 적어야 정답 처리됩니다 — 필답형 표기 함정.

| `NullPointerException` | Java | null인 참조로 메서드/필드 접근 | 객체 생성(new) 여부 확인 |
| 오버라이딩했는데 부모 메서드가 실행됨 | Java | 메서드 이름 오타 → 재정의가 아니라 **새 메서드**가 됨 (에러 없음 함정) | `@Override`를 붙이면 오타 시 컴파일 에러로 잡아 줌 |
| `TypeError: 'tuple' object does not support item assignment` | Python | `t[1] = 99` — 튜플은 불변 | 변경이 필요하면 리스트 사용 (튜플 vs 리스트 구분 단답 소재) |
| `KeyError: '영어'` | Python | 딕셔너리에 없는 키 접근 `d["영어"]` | 키 존재 확인(`"영어" in d`) — IndexError(범위)와 KeyError(키) 구분 |
| `sorted(a)`와 `a.sort()` 혼동 | Python | `print(a.sort())`는 **None** 출력 (원본만 바뀜) | 반환값이 필요하면 `sorted(a)` — 결과 예측 함정 |
| `IndexError: list index out of range` | Python | 길이 밖 인덱스 — 슬라이싱은 범위를 넘어도 에러가 안 나지만 **인덱스는 남** | `a[10]`은 에러, `a[2:10]`은 조용히 끝까지만 — 이 비대칭이 함정 |

## ⑥ 확인 문제

1. [결과 예측] 다음 Java 코드의 출력을 쓰시오.
   ```java
   class A {
       A() { System.out.print("A"); }
       void m() { System.out.print("M"); }
   }
   class B extends A {
       B() { System.out.print("B"); }
       @Override
       void m() { System.out.print("N"); }
   }
   public class Q {
       public static void main(String[] args) {
           A obj = new B();
           obj.m();
       }
   }
   ```
2. [결과 예측] 다음 Python 코드의 출력을 쓰시오.
   ```python
   s = "PROCESSING"
   print(s[1:4], s[-3:])
   ```
3. [코드 해석] Step 5의 코드에서 `10 / 0`을 `10 / 2`로 바꾸면 출력이 어떻게 되는지 쓰고, 이유를 설명하시오.

<details>
<summary>정답과 해설</summary>

1. **`ABN`** — `new B()`에서 부모 생성자 먼저 `A`, 자식 생성자 `B` → `obj.m()`은 다형성 규칙 1에 따라 실제 객체(B)의 오버라이딩 메서드 `N`.
   - 대표 오답: `ABM` — "변수 타입이 A니까 A의 m"이라고 판정한 경우. **실행되는 메서드는 객체 기준, 호출 가능 여부만 타입 기준**입니다.
2. **`ROC ING`** — P(0) R(1) O(2) C(3) E(4) S(5) S(6) I(7) N(8) G(9). `s[1:4]`는 1·2·3번 = ROC, `s[-3:]`는 뒤에서 3글자 = ING.
   - 대표 오답: `ROCE ING` — 끝 인덱스 4를 포함해 버린 경우. 끝은 **항상 미포함**입니다.
3. **`ABDE`** — 예외가 발생하지 않으므로 try가 끝까지 실행되어 `A`, `B` 출력 → catch는 **건너뜀** → finally는 예외 유무와 무관하게 `D` → `E`.
   - 오답 원인: "catch도 항상 실행된다"는 오해 — catch는 예외가 **났을 때만**, finally는 **항상**입니다.

</details>

## 마무리

**오늘의 요약** — 자식 객체 생성 시 부모 생성자가 먼저(AB), 오버라이딩은 재정의(올라타기)·오버로딩은 같은 이름 추가(쌓기), 다형성 판정은 "호출 가능 = 변수 타입, 실제 실행 = 객체" 2규칙입니다. 예외는 발생 줄에서 try 중단 → 맞는 catch → finally 항상. Python은 리스트(가변)·튜플(불변)·딕셔너리(키)·집합(중복 제거) 4형제와 슬라이싱 `[start:end:step]`(끝 미포함, `[::-1]` 역순)이 전부 결과 예측 재료입니다. 이것으로 2단원(코드)이 완성되었습니다.

**복습 체크리스트**

- [ ] 오버라이딩 vs 오버로딩 표를 안 보고 재현할 수 있다
- [ ] `Animal a = new Dog();`의 호출 판정 2규칙을 말할 수 있다
- [ ] Step 5에서 B가 출력되지 않는 이유를 설명할 수 있다
- [ ] 주요 예외 4개의 이름과 발생 상황을 짝지을 수 있다
- [ ] 자료형 4종 표와 `s[::-1]`의 의미를 즉답할 수 있다

**과제 — 3주차 형성평가 (10문항, 07강 첫 복습 퀴즈와 연동)**

3. C: `f(n) = n * f(n-1)`, `f(1) = 1` 일 때 `f(3)` 의 값은? (05강 누적)
4. Java: 부모 클래스의 메서드를 자식 클래스가 같은 이름·같은 매개변수로 재정의하는 것을 무엇이라 하는가?
5. Java: `A a = new B();` 에서 B가 A의 메서드 `m()`을 오버라이딩했다면 `a.m()`은 누구의 메서드를 실행하는가?
6. Java: `int[] x = new int[2]; x[3] = 1;` 실행 시 발생하는 예외의 이름은?

8. Python: 튜플의 요소를 `t[0] = 1`처럼 변경할 수 있는가? 그 이유는?
9. Python: `print("PYTHON"[::-1])` 의 출력은?
