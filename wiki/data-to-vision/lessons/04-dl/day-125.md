## ③ 개념 설명

### 최종 모델 확정 4단계

```
① 검증셋으로 후보 선정          (Day 120, 122, 124)
       ↓
② 전체 개발 데이터로 재학습      ★ 학습 + 검증을 합쳐서
       ↓
③ 테스트셋 1회 평가             ★ 딱 한 번
       ↓
④ 결과 보고 + 모델 카드
```

### ② 왜 전체 개발 데이터로 재학습하는가

```
탐색 단계: 학습 60% / 검증 20%  →  모델이 60%만 봄
최종 단계: 학습 80%              →  20% 더 많은 데이터
```

**데이터가 20% 늘면 성능이 개선됩니다.**

| 주의 | 설명 |
|---|---|
| **에폭 수** | 검증셋이 없으므로 EarlyStopping 불가 → **탐색 시의 최적 에폭을 고정** |
| 하이퍼파라미터 | **바꾸지 않음.** 검증셋에서 정한 그대로 |
| 전처리 | 학습+검증 전체로 다시 fit |

**에폭 고정 방법**

```python
# 탐색 시 최적 에폭이 93이었다면
best_epoch = 93
scale = len(X_dev) / len(X_train)      # 데이터가 1.33배 늘었으므로
final_epochs = int(best_epoch * 1.0)   # 보통 그대로 또는 약간 늘림
final_model.fit(X_dev, y_dev, epochs=final_epochs)   # validation_data 없음
```

> **대안** — 개발 데이터에서 다시 작은 검증셋을 떼어 EarlyStopping을 쓰는 방법도 있습니다.
> 데이터가 충분하면 이쪽이 안전합니다.

### ③ 테스트셋 1회 평가 — 규칙

```
✓ 모든 튜닝이 끝난 뒤
✓ 최종 모델 1개(또는 소수 후보)에 대해
✓ 딱 한 번
✓ 그 결과로 모델을 바꾸지 않는다
```

**"바꾸지 않는다"가 가장 어렵습니다.**

```
테스트 MAE 0.35 (검증 0.31보다 나쁨)
→ "Dropout을 조금 줄여 볼까?"
→ ★ 그 순간 테스트셋이 검증셋이 됩니다
```

**이미 봤다면?**

```
정직하게 보고하세요:
"테스트셋을 3회 확인했으므로 보고된 성능은 낙관적일 수 있습니다"

숨기는 것보다 훨씬 나은 보고서입니다.
```

### 성능 보고 양식

**최소 요건 3가지**

| 요소 | 예 |
|---|---|
| **지표 + 값** | 테스트 MAE 0.3142 |
| **신뢰 범위** | 95% CI [0.3021, 0.3263] |
| **조건** | 데이터·전처리·제외 구간 |

**신뢰구간 계산 — 부트스트랩**

```python
rng = np.random.default_rng(42)
boots = []
for _ in range(2000):
    idx = rng.integers(0, len(y_test), len(y_test))
    boots.append(mean_absolute_error(y_test[idx], pred[idx]))
ci_low, ci_high = np.percentile(boots, [2.5, 97.5])
```

**표준오차 기반 (간단)**

```python
err = np.abs(y_test - pred)
se = err.std(ddof=1) / np.sqrt(len(err))
ci = (err.mean() - 1.96 * se, err.mean() + 1.96 * se)
```

> **부트스트랩이 더 정확합니다.** 오차 분포가 정규분포가 아니어도 됩니다.

### Step 1. ① 후보 선정 — 교차검증으로 최종 확인

```python
import numpy as np
import pandas as pd
from itertools import combinations
from sklearn.base import clone

SEED = 42

# ── Day 124에서 나온 최종 후보 3종 ──
CANDIDATES = {
    "A. 릿지": TransformedTargetRegressor(
        regressor=Pipeline([("sc", StandardScaler()),
                            ("m", RidgeCV(alphas=np.logspace(-3, 3, 30)))]),
        func=np.log1p, inverse_func=np.expm1),

    "B. HistGB (튜닝)": TransformedTargetRegressor(
        regressor=HistGradientBoostingRegressor(
            learning_rate=0.0618, max_leaf_nodes=58, min_samples_leaf=12,
            l2_regularization=0.2842, max_features=0.8104,
            max_iter=800, early_stopping=True, n_iter_no_change=30,
            validation_fraction=0.15, random_state=SEED),
        func=np.log1p, inverse_func=np.expm1),

    "C. 랜덤포레스트": TransformedTargetRegressor(
        regressor=RandomForestRegressor(n_estimators=400, min_samples_leaf=2,
                                        max_features=0.6,
                                        random_state=SEED, n_jobs=-1),
        func=np.log1p, inverse_func=np.expm1),
}


def score_all(y_true, pred):
    y_true = np.asarray(y_true, float)
    pred = np.asarray(pred, float)
    mae = mean_absolute_error(y_true, pred)
    rmse = float(np.sqrt(mean_squared_error(y_true, pred)))
    return {
        "MAE": mae, "RMSE": rmse, "R2": r2_score(y_true, pred),
        "MAPE": mean_absolute_percentage_error(y_true, pred) * 100,
        "WAPE": float(np.sum(np.abs(y_true - pred)) / np.sum(np.abs(y_true)) * 100),
        "RMSE/MAE": rmse / max(mae, 1e-12),
    }


# ── 5-Fold × 3회 교차검증 (같은 폴드) ──
yb_dev = pd.qcut(y_dev, q=10, labels=False, duplicates="drop")
rskf = RepeatedStratifiedKFold(n_splits=5, n_repeats=3, random_state=SEED)
splits = list(rskf.split(np.zeros(len(yb_dev)), yb_dev))

fold_scores = {n: [] for n in CANDIDATES}
fit_times = {n: [] for n in CANDIDATES}

print("=" * 92)
print(f"① 후보 선정 — 5-Fold × 3회 = {len(splits)} 폴드 (Day 122)")
print("=" * 92)

for tr, va in splits:
    Xtr_f, Xva_f = X_dev.iloc[tr], X_dev.iloc[va]
    ytr_f, yva_f = y_dev.iloc[tr], y_dev.iloc[va]
    for name, model in CANDIDATES.items():
        t0 = time.perf_counter()
        m = clone(model).fit(Xtr_f, ytr_f)
        fit_times[name].append(time.perf_counter() - t0)
        fold_scores[name].append(mean_absolute_error(yva_f, m.predict(Xva_f)))

cv_summary = pd.DataFrame({
    "후보": list(CANDIDATES),
    "CV MAE": [f"{np.mean(fold_scores[n]):.4f} ± {np.std(fold_scores[n], ddof=1):.4f}"
               for n in CANDIDATES],
    "평균": [round(float(np.mean(fold_scores[n])), 5) for n in CANDIDATES],
    "표준오차": [round(float(np.std(fold_scores[n], ddof=1) / np.sqrt(len(splits))), 5)
             for n in CANDIDATES],
    "학습(s)": [round(float(np.mean(fit_times[n])), 2) for n in CANDIDATES],
})
print(cv_summary.to_string(index=False))
print("=" * 92)
```

```markdown
| MAE | 4,318원 | [4,102, 4,541] |
| RMSE | 6,847원 | [6,412, 7,284] |
| R² | 0.841 | [0.812, 0.867] |
| WAPE | 18.4% | — |

- seed 5회 반복: 4,324 ± 87원
- 부트스트랩 2,000회, 테스트 1,200건 기준

### 해석
- R² 0.841은 **타깃 분산의 84.1%를 설명**한다는 뜻이며,
  "84% 정확"이 아닙니다.
- 교차검증 MAE 4,102원은 하이퍼파라미터 탐색에 165회 사용한 뒤의 값으로
  **낙관적**입니다. 실제 성능은 테스트셋 4,318원입니다.
```

```python
    건수=("actual", "size"), 실제평균=("actual", "mean"),
    MAE=("abs_err", "mean")).round(4)
```

| **① 후보 선정** | 검증셋 + 교차검증 + 쌍체 비교 | 동등하면 단순한 쪽 |
| **② 재학습** | **학습 + 검증 전체**로 | **하이퍼파라미터 변경 금지** |
| **③ 테스트셋** | **딱 한 번** | **결과로 모델을 바꾸지 않음** |
| **④ 보고** | 신뢰 범위 + 조건 + 한계 | 모델 카드 |

| 개념 | 핵심 |
|---|---|
| 검증셋 낙관 편향 | 352회 참조 → 테스트 대비 +2.39% |
| 재학습 효과 | 데이터 1.33배 → 성능 개선 |
| 신뢰구간 | **부트스트랩 2000회** (정규분포 가정 불필요) |
| 불확실성 2원천 | seed(±0.0014) vs **샘플링(±0.0054)** — 후자가 3.7배 |
| 성능 보고 3요소 | **지표 + 신뢰 범위 + 조건** |
| 과대 보고 방지 | 검증 참조 횟수·구간별·한계를 밝히기 |
| R² 표현 | "몇 % 정확"이 아니라 **"분산의 몇 %를 설명"** |
| 구간별 성능 | 전체 MAE가 감추는 실패 (11.9~30.9%) |
| 집단별 성능 | 공정성. **최대/최소 비 1.5배 초과 시 검토** |
| 모델 카드 | **2.2 의도되지 않은 사용처** · **7 한계** · **10 폐기 조건** |
| 아티팩트 | model · **preprocessor** · config · metrics · **model_card** |

**오늘 반드시 기억할 세 가지**
> ① **테스트셋은 딱 한 번, 그리고 그 결과로 모델을 바꾸지 않습니다.**
> ② **성능은 "지표 + 신뢰 범위 + 조건"으로 보고하세요.**
> ③ **모델 카드의 "어디에 쓰면 안 되는가"가 가장 중요한 절입니다.**
