## ② 왜 필요한가

어제 설계서를 만들었습니다. 오늘은 그 설계를 **실제 데이터베이스로 만듭니다.**

```
설계서 (문서)          →       데이터베이스 (실물)
┌────┬──────┬─────┐          game.db 파일
│ id │ name │score│    →      ├─ scores 테이블
└────┴──────┴─────┘          └─ settings 테이블
```

그리고 여기서 배우는 **연결(connect) → 커서(cursor) → 실행(execute) → 커밋(commit)** 흐름은
SQLite 뿐 아니라 MySQL·PostgreSQL 에서도 똑같습니다.
**한 번 배우면 모든 관계형 DB에 통합니다.**

## ③ 개념 설명

### sqlite3 기본 흐름

```python
import sqlite3

conn = sqlite3.connect("game.db")     # ① 연결 (파일이 없으면 생성)
cursor = conn.cursor()                # ② 커서 얻기

cursor.execute("CREATE TABLE ...")    # ③ SQL 실행

conn.commit()                         # ④ 저장 확정
conn.close()                          # ⑤ 연결 종료
```

| 단계 | 하는 일 | 비유 |
|---|---|---|
| `connect()` | DB 파일을 엶 | 파일 열기 |
| `cursor()` | 명령을 보내고 결과를 받는 통로 | 대화 창구 |
| `execute()` | SQL 실행 | 명령 전달 |
| `commit()` | 변경을 확정 | **저장 버튼** |
| `close()` | 연결 종료 | 파일 닫기 |

> ⚠️ **`commit()` 을 안 하면 변경이 사라집니다.** 가장 흔한 실수입니다.
> `SELECT`(조회)는 커밋이 필요 없지만, `CREATE`/`INSERT`/`UPDATE`/`DELETE` 는 반드시 필요합니다.

### with 문으로 안전하게

```python
with sqlite3.connect("game.db") as conn:
    cursor = conn.cursor()
    cursor.execute("INSERT INTO scores ...")
    # 블록이 정상 종료되면 자동 commit
    # 예외가 나면 자동 rollback
```

> ⚠️ **주의** — `with sqlite3.connect(...)` 는 **연결을 닫아 주지 않습니다.** 커밋/롤백만 처리합니다.
> 완전히 안전하게 하려면 `contextlib.closing` 을 함께 씁니다.

```python
from contextlib import closing

with closing(sqlite3.connect("game.db")) as conn:
    with conn:                               # 커밋/롤백
        conn.execute("INSERT INTO ...")
```

> `conn.execute()` 처럼 커서 없이 바로 실행할 수도 있습니다. 파이썬이 임시 커서를 만들어 줍니다.

### CREATE TABLE

```sql
CREATE TABLE IF NOT EXISTS scores (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    player_name  TEXT    NOT NULL,
    score        INTEGER NOT NULL DEFAULT 0,
    kills        INTEGER NOT NULL DEFAULT 0,
    created_at   TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
);
```

| 요소 | 뜻 |
|---|---|
| `IF NOT EXISTS` | 이미 있으면 건너뜀 (에러 방지) |
| `PRIMARY KEY` | 각 행을 구분하는 고유값 |
| `AUTOINCREMENT` | 자동으로 1씩 증가 |
| `NOT NULL` | 값을 반드시 넣어야 함 |
| `DEFAULT 0` | 안 넣으면 0 |
| `UNIQUE` | 중복 불가 |
| `CHECK (조건)` | 조건을 만족해야 저장 가능 |

### 제약 조건 (constraint)

**제약 조건은 잘못된 데이터가 들어오는 것을 DB가 막아 줍니다.**

```sql
CREATE TABLE players (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    name     TEXT    NOT NULL UNIQUE,
    level    INTEGER NOT NULL DEFAULT 1 CHECK (level >= 1 AND level <= 99),
    email    TEXT    UNIQUE,
    hp       INTEGER NOT NULL DEFAULT 100 CHECK (hp >= 0)
);
```

```python
cursor.execute("INSERT INTO players (name, level) VALUES ('홍길동', 150)")
```

```
sqlite3.IntegrityError: CHECK constraint failed: level >= 1 AND level <= 99
```

> **파이썬에서 검증하는 것과 DB에서 검증하는 것은 다릅니다.**
> 파이썬 코드를 우회해 DB에 직접 접근할 수도 있고, 다른 프로그램이 쓸 수도 있습니다.
> **중요한 규칙은 DB에도 걸어 두세요.**

### 자료형 친화성 (type affinity)

SQLite는 자료형이 느슨합니다.

```python
cursor.execute("CREATE TABLE t (num INTEGER)")
cursor.execute("INSERT INTO t VALUES ('abc')")     # 에러 안 남!
```

> SQLite는 **선언한 타입과 다른 값도 받아들입니다.** 다른 DB와 크게 다른 점입니다.
> 그래서 **파이썬 쪽에서 타입을 확실히 맞춰 넣는 것**이 중요합니다.

### 테이블 구조 확인하기

```python
# 테이블 목록
cursor.execute("SELECT name FROM sqlite_master WHERE type='table'")
print(cursor.fetchall())

# 특정 테이블의 열 정보
cursor.execute("PRAGMA table_info(scores)")
for col in cursor.fetchall():
    print(col)      # (순번, 이름, 타입, NOT NULL, 기본값, 기본키여부)

# 테이블을 만든 SQL 원문
cursor.execute("SELECT sql FROM sqlite_master WHERE name='scores'")
print(cursor.fetchone()[0])
```

### 인덱스 — 검색을 빠르게

```sql
CREATE INDEX IF NOT EXISTS idx_scores_score ON scores(score DESC);
CREATE INDEX IF NOT EXISTS idx_scores_name  ON scores(player_name);
```

**인덱스는 책의 색인과 같습니다.**
색인이 없으면 처음부터 끝까지 훑어야 하지만, 있으면 바로 찾아갑니다.

| | 인덱스 없음 | 인덱스 있음 |
|---|---|---|
| 검색 속도 | 느림 (전체 훑기) | 빠름 |
| 삽입 속도 | 빠름 | 조금 느림 (색인도 갱신) |
| 파일 크기 | 작음 | 큼 |

> **자주 검색·정렬하는 열에만** 인덱스를 만드세요. 모든 열에 만들면 오히려 느려집니다.
> `PRIMARY KEY` 에는 인덱스가 자동으로 생깁니다.

### 스키마 변경

```sql
ALTER TABLE scores ADD COLUMN stage INTEGER NOT NULL DEFAULT 1;
ALTER TABLE scores RENAME TO game_scores;
ALTER TABLE scores RENAME COLUMN kills TO enemy_kills;
DROP TABLE scores;                    -- 삭제 (되돌릴 수 없음!)
```

> ⚠️ SQLite 는 **열 삭제와 타입 변경을 지원하지 않습니다.** (구버전 기준)
> 필요하면 새 테이블을 만들고 데이터를 옮겨야 합니다. **그래서 처음 설계가 중요합니다.**

### Step 1. 첫 데이터베이스 만들기

`db_create.py`

```python
"""슈팅게임 데이터베이스를 생성합니다."""

import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).resolve().parent / "game.db"


def create_tables():
    """테이블과 인덱스를 만듭니다."""
    conn = sqlite3.connect(DB_PATH)
    cursor = conn.cursor()

    # ── scores 테이블 ──
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS scores (
            id            INTEGER PRIMARY KEY AUTOINCREMENT,
            player_name   TEXT    NOT NULL,
            score         INTEGER NOT NULL DEFAULT 0 CHECK (score >= 0),
            kills         INTEGER NOT NULL DEFAULT 0 CHECK (kills >= 0),
            max_combo     INTEGER NOT NULL DEFAULT 0,
            shots         INTEGER NOT NULL DEFAULT 0,
            hits          INTEGER NOT NULL DEFAULT 0,
            play_seconds  INTEGER NOT NULL DEFAULT 0,
            stage         INTEGER NOT NULL DEFAULT 1,
            created_at    TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
        )
    """)

    # ── settings 테이블 ──
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS settings (
            key    TEXT PRIMARY KEY,
            value  TEXT NOT NULL
        )
    """)

    # ── 인덱스 ──
    cursor.execute("CREATE INDEX IF NOT EXISTS idx_scores_score "
                   "ON scores(score DESC)")
    cursor.execute("CREATE INDEX IF NOT EXISTS idx_scores_name "
                   "ON scores(player_name)")
    cursor.execute("CREATE INDEX IF NOT EXISTS idx_scores_date "
                   "ON scores(created_at DESC)")

    conn.commit()          # ← 이게 없으면 아무것도 저장되지 않습니다!
    conn.close()

    print(f"데이터베이스 생성 완료: {DB_PATH.name}")


def show_schema():
    """테이블 구조를 출력합니다."""
    conn = sqlite3.connect(DB_PATH)
    cursor = conn.cursor()

    # 테이블 목록 (sqlite 내부 테이블 제외)
    cursor.execute("""
        SELECT name FROM sqlite_master
        WHERE type='table' AND name NOT LIKE 'sqlite_%'
        ORDER BY name
    """)
    tables = [row[0] for row in cursor.fetchall()]

    print(f"\n{'=' * 68}")
    print(f"데이터베이스: {DB_PATH.name}  (테이블 {len(tables)}개)")
    print("=" * 68)

    for table in tables:
        cursor.execute(f"PRAGMA table_info({table})")
        columns = cursor.fetchall()

        print(f"\n[{table}]  열 {len(columns)}개")
        print(f"  {'열 이름':<16}{'타입':<10}{'NOT NULL':<10}{'기본값':<28}{'PK'}")
        print("  " + "-" * 64)

        for cid, name, dtype, notnull, default, pk in columns:
            default_str = str(default) if default is not None else "-"
            print(f"  {name:<16}{dtype:<10}{'예' if notnull else '-':<10}"
                  f"{default_str:<28}{'예' if pk else '-'}")

    # 인덱스 목록
    cursor.execute("""
        SELECT name, tbl_name FROM sqlite_master
        WHERE type='index' AND name NOT LIKE 'sqlite_%'
        ORDER BY tbl_name, name
    """)
    indexes = cursor.fetchall()

    if indexes:
        print(f"\n[인덱스] {len(indexes)}개")
        for name, table in indexes:
            print(f"  {name:<28} → {table}")

    print("=" * 68)
    conn.close()


if __name__ == "__main__":
    create_tables()
    show_schema()
```

### Step 2. 제약 조건 확인하기

`db_constraints.py`

```python
"""제약 조건이 잘못된 데이터를 어떻게 막는지 확인합니다."""

import sqlite3

conn = sqlite3.connect(":memory:")       # 메모리 DB — 파일을 만들지 않음
cursor = conn.cursor()

cursor.execute("""
    CREATE TABLE players (
        id     INTEGER PRIMARY KEY AUTOINCREMENT,
        name   TEXT    NOT NULL UNIQUE,
        level  INTEGER NOT NULL DEFAULT 1 CHECK (level BETWEEN 1 AND 99),
        hp     INTEGER NOT NULL DEFAULT 100 CHECK (hp >= 0),
        email  TEXT    UNIQUE
    )
""")
conn.commit()

print("=" * 60)
print("            제약 조건 테스트")
print("=" * 60)

tests = [
    ("정상 입력",
     "INSERT INTO players (name, level, hp) VALUES ('홍길동', 5, 100)"),

    ("NOT NULL 위반 (이름 없음)",
     "INSERT INTO players (level, hp) VALUES (5, 100)"),

    ("UNIQUE 위반 (이름 중복)",
     "INSERT INTO players (name, level) VALUES ('홍길동', 3)"),

    ("CHECK 위반 (레벨 150)",
     "INSERT INTO players (name, level) VALUES ('김철수', 150)"),

    ("CHECK 위반 (체력 음수)",
     "INSERT INTO players (name, hp) VALUES ('이영희', -10)"),

    ("기본값 사용 (레벨·체력 생략)",
     "INSERT INTO players (name) VALUES ('박민수')"),

    ("NULL 허용 열 (email 생략)",
     "INSERT INTO players (name, email) VALUES ('최지우', NULL)"),

    ("NULL 은 UNIQUE 중복으로 안 봄",
     "INSERT INTO players (name, email) VALUES ('정수현', NULL)"),
]

for label, sql in tests:
    try:
        cursor.execute(sql)
        conn.commit()
        print(f"  ✓ {label}")
    except sqlite3.IntegrityError as e:
        print(f"  ✗ {label}")
        print(f"      → {e}")

print("\n" + "-" * 60)
print("저장된 데이터:")
cursor.execute("SELECT id, name, level, hp, email FROM players")
print(f"  {'id':<4}{'이름':<10}{'레벨':<6}{'체력':<6}{'이메일'}")
for row in cursor.fetchall():
    email = row[4] if row[4] else "-"
    print(f"  {row[0]:<4}{row[1]:<10}{row[2]:<6}{row[3]:<6}{email}")

print("=" * 60)
conn.close()
```

> **눈여겨볼 점 3가지**
> - `:memory:` 로 연결하면 **파일 없이 메모리에서만** 동작합니다. 테스트에 유용합니다.
> - `id` 가 1, 6, 7, 8 로 **건너뜁니다.** `AUTOINCREMENT` 는 실패한 시도의 번호도 소모합니다.
> - **`NULL` 은 UNIQUE 중복으로 보지 않습니다.** `NULL` 은 "값 없음"이라 서로 비교할 수 없기 때문입니다.

### Step 3. 스키마 관리 모듈 (오늘의 종합 예제)

`game/db/schema.py`

```python
"""데이터베이스 스키마 정의와 초기화."""

import sqlite3
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent.parent
DATA_DIR = BASE_DIR / "data"
DB_PATH = DATA_DIR / "game.db"

SCHEMA_VERSION = 1

# ══════════ 테이블 정의 ══════════

CREATE_SCORES = """
CREATE TABLE IF NOT EXISTS scores (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    player_name   TEXT    NOT NULL,
    score         INTEGER NOT NULL DEFAULT 0  CHECK (score >= 0),
    kills         INTEGER NOT NULL DEFAULT 0  CHECK (kills >= 0),
    max_combo     INTEGER NOT NULL DEFAULT 0  CHECK (max_combo >= 0),
    shots         INTEGER NOT NULL DEFAULT 0  CHECK (shots >= 0),
    hits          INTEGER NOT NULL DEFAULT 0  CHECK (hits >= 0),
    play_seconds  INTEGER NOT NULL DEFAULT 0  CHECK (play_seconds >= 0),
    stage         INTEGER NOT NULL DEFAULT 1  CHECK (stage >= 1),
    created_at    TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
)
"""

CREATE_SETTINGS = """
CREATE TABLE IF NOT EXISTS settings (
    key         TEXT PRIMARY KEY,
    value       TEXT NOT NULL,
    updated_at  TEXT NOT NULL DEFAULT (datetime('now', 'localtime'))
)
"""

CREATE_META = """
CREATE TABLE IF NOT EXISTS meta (
    key    TEXT PRIMARY KEY,
    value  TEXT NOT NULL
)
"""

INDEXES = [
    "CREATE INDEX IF NOT EXISTS idx_scores_score ON scores(score DESC)",
    "CREATE INDEX IF NOT EXISTS idx_scores_name  ON scores(player_name)",
    "CREATE INDEX IF NOT EXISTS idx_scores_date  ON scores(created_at DESC)",
]

DEFAULT_SETTINGS = {
    "volume": "0.5",
    "difficulty": "normal",
    "last_player": "",
}


# ══════════ 함수 ══════════

def get_connection():
    """데이터베이스 연결을 반환합니다."""
    DATA_DIR.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row        # 결과를 이름으로 접근 가능하게
    conn.execute("PRAGMA foreign_keys = ON")
    return conn


def init_db():
    """데이터베이스를 초기화합니다. 프로그램 시작 시 한 번 호출합니다."""
    conn = get_connection()

    try:
        with conn:                        # 자동 커밋 / 예외 시 롤백
            conn.execute(CREATE_SCORES)
            conn.execute(CREATE_SETTINGS)
            conn.execute(CREATE_META)

            for sql in INDEXES:
                conn.execute(sql)

            # 스키마 버전 기록
            conn.execute(
                "INSERT OR IGNORE INTO meta (key, value) VALUES ('schema_version', ?)",
                (str(SCHEMA_VERSION),),
            )

            # 기본 설정 (이미 있으면 건드리지 않음)
            for key, value in DEFAULT_SETTINGS.items():
                conn.execute(
                    "INSERT OR IGNORE INTO settings (key, value) VALUES (?, ?)",
                    (key, value),
                )

        return True

    except sqlite3.Error as e:
        print(f"[오류] DB 초기화 실패: {e}")
        return False

    finally:
        conn.close()


def get_schema_version():
    """현재 스키마 버전을 반환합니다."""
    conn = get_connection()
    try:
        row = conn.execute(
            "SELECT value FROM meta WHERE key = 'schema_version'"
        ).fetchone()
        return int(row["value"]) if row else 0
    except sqlite3.Error:
        return 0
    finally:
        conn.close()


def get_table_info():
    """테이블 구조를 딕셔너리로 반환합니다."""
    conn = get_connection()
    info = {}

    try:
        tables = conn.execute("""
            SELECT name FROM sqlite_master
            WHERE type='table' AND name NOT LIKE 'sqlite_%'
            ORDER BY name
        """).fetchall()

        for t in tables:
            name = t["name"]
            columns = conn.execute(f"PRAGMA table_info({name})").fetchall()
            count = conn.execute(f"SELECT COUNT(*) AS c FROM {name}").fetchone()["c"]

            info[name] = {
                "columns": [dict(c) for c in columns],
                "row_count": count,
            }

        return info

    finally:
        conn.close()


def reset_db(confirm=False):
    """데이터베이스 파일을 삭제하고 다시 만듭니다. 되돌릴 수 없습니다."""
    if not confirm:
        print("[경고] reset_db(confirm=True) 로 호출해야 실행됩니다.")
        return False

    if DB_PATH.exists():
        DB_PATH.unlink()
        print(f"삭제: {DB_PATH.name}")

    return init_db()


if __name__ == "__main__":
    print("=" * 68)
    print("            데이터베이스 초기화")
    print("=" * 68)

    if init_db():
        print(f"  ✓ 초기화 완료")
        print(f"  경로: {DB_PATH}")
        print(f"  스키마 버전: {get_schema_version()}")

        print("\n" + "-" * 68)
        for table, info in get_table_info().items():
            print(f"[{table}]  열 {len(info['columns'])}개 · "
                  f"데이터 {info['row_count']}건")
            for col in info["columns"]:
                flags = []
                if col["pk"]:
                    flags.append("PK")
                if col["notnull"]:
                    flags.append("NOT NULL")
                if col["dflt_value"] is not None:
                    flags.append(f"DEFAULT {col['dflt_value']}")

                flag_str = f"  ({', '.join(flags)})" if flags else ""
                print(f"    {col['name']:<16}{col['type']:<10}{flag_str}")
            print()

    print("=" * 68)
```

> **눈여겨볼 점 6가지**
> - `conn.row_factory = sqlite3.Row` — 결과를 `row["player_name"]` 처럼 **이름으로 접근**할 수 있습니다. 인덱스 번호를 세지 않아도 됩니다.
> - `with conn:` — 블록이 끝나면 자동 커밋, 예외가 나면 자동 롤백입니다.
> - `INSERT OR IGNORE` — 이미 있으면 조용히 건너뜁니다. 기본 설정을 넣을 때 유용합니다.
> - **`meta` 테이블에 스키마 버전을 기록**합니다. 나중에 구조가 바뀌었을 때 어떤 버전인지 알 수 있습니다.
> - `finally: conn.close()` — 예외가 나도 연결이 닫힙니다.
> - `reset_db(confirm=True)` — **위험한 작업에는 명시적 확인**을 요구합니다.

## ⑤ 자주 하는 실수

### `commit()` 을 안 함

```python
cursor.execute("INSERT INTO scores ...")
conn.close()                              # 커밋 없이 종료
```

**증상** — 프로그램은 정상 종료되는데 **데이터가 하나도 없습니다.**
**해결** — `conn.commit()` 또는 `with conn:` 블록을 씁니다.

> **가장 흔한 실수입니다.** 데이터가 안 보이면 제일 먼저 확인하세요.

### `with sqlite3.connect()` 가 연결을 닫는다고 착각

```python
with sqlite3.connect("game.db") as conn:
    conn.execute("...")
# 연결이 아직 열려 있습니다!
```

**해결** — `contextlib.closing` 을 함께 쓰거나, `try/finally` 로 명시적으로 닫습니다.

### `IF NOT EXISTS` 를 빠뜨림

```python
cursor.execute("CREATE TABLE scores (...)")     # 두 번째 실행에서 에러
```

```
sqlite3.OperationalError: table scores already exists
```

**해결** — `CREATE TABLE IF NOT EXISTS scores (...)`

### `sqlite3.Row` 없이 인덱스로 접근

```python
row = cursor.fetchone()
print(row[3])                # 3번이 무슨 열인지 알 수 없음
```

**해결** — `conn.row_factory = sqlite3.Row` 를 설정하고 `row["kills"]` 로 접근합니다.

### 테이블 이름을 f-string 으로 조합

```python
table = input("테이블 이름: ")
cursor.execute(f"SELECT * FROM {table}")     # SQL 인젝션 위험!
```

**문제** — 사용자가 `scores; DROP TABLE scores;--` 를 입력하면 테이블이 사라집니다.
**해결** — 테이블 이름은 **코드에 고정**하고, 값만 파라미터로 넘깁니다. ([Day 033](day-033.md))

> **테이블/열 이름은 파라미터 바인딩(`?`)이 안 됩니다.** 반드시 화이트리스트로 검증하세요.
> ```python
> ALLOWED_TABLES = {"scores", "settings"}
> if table not in ALLOWED_TABLES:
>     raise ValueError("허용되지 않은 테이블")
> ```

### 열 추가를 SQLite 에서 자유롭게 할 수 있다고 생각

```sql
ALTER TABLE scores DROP COLUMN kills;         -- 구버전 SQLite 에서 실패
ALTER TABLE scores ALTER COLUMN score TEXT;   -- 지원 안 함
```

**해결** — 새 테이블을 만들고 데이터를 옮깁니다.

```sql
CREATE TABLE scores_new (...);
INSERT INTO scores_new SELECT id, player_name, score FROM scores;
DROP TABLE scores;
ALTER TABLE scores_new RENAME TO scores;
```

> **그래서 처음 설계가 중요합니다.** ([Day 031](day-031.md))

### 모든 열에 인덱스를 만듦

**증상** — 삽입이 느려지고 파일 크기가 커집니다.
**해결** — `WHERE` / `ORDER BY` 에 자주 쓰는 열에만 만듭니다.

### `datetime('now')` 가 UTC 인 것을 모름

```sql
created_at TEXT DEFAULT (datetime('now'))     -- UTC 시각!
```

**증상** — 저장된 시각이 9시간 빠릅니다.
**해결** — `datetime('now', 'localtime')` 을 씁니다.

## ⑥ 확인 문제

**1.** 아래 코드를 실행하면 데이터가 저장되지 않습니다. 원인과 해결책을 쓰세요.

```python
import sqlite3

conn = sqlite3.connect("test.db")
cursor = conn.cursor()

cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)")
cursor.execute("INSERT INTO users (name) VALUES ('홍길동')")

conn.close()

# 다시 열어서 확인
conn = sqlite3.connect("test.db")
cursor = conn.cursor()
cursor.execute("SELECT * FROM users")
print(cursor.fetchall())        # []
conn.close()
```

<details>
<summary>답 보기</summary>

**원인 — `conn.commit()` 이 없습니다.**

SQLite는 `INSERT`/`UPDATE`/`DELETE` 를 **트랜잭션 안에서** 실행합니다.
`commit()` 을 호출해야 실제 파일에 확정되고, 안 하면 `close()` 시점에 **자동으로 롤백**됩니다.

**흥미로운 점** — `CREATE TABLE` 은 저장됩니다. 표는 만들어졌는데 데이터만 없습니다.
(SQLite 는 DDL 을 자동 커밋하는 경우가 있습니다)

**해결 ① 명시적 커밋**

```python
cursor.execute("INSERT INTO users (name) VALUES ('홍길동')")
conn.commit()               # ← 추가
conn.close()
```

**해결 ② `with conn:` (권장)**

```python
import sqlite3
from contextlib import closing

with closing(sqlite3.connect("test.db")) as conn:
    with conn:                                        # 자동 커밋/롤백
        conn.execute("CREATE TABLE IF NOT EXISTS users "
                     "(id INTEGER PRIMARY KEY, name TEXT)")
        conn.execute("INSERT INTO users (name) VALUES ('홍길동')")

with closing(sqlite3.connect("test.db")) as conn:
    print(conn.execute("SELECT * FROM users").fetchall())
    # [(1, '홍길동')]
```

> **`with conn:` 의 장점** — 블록 안에서 예외가 나면 **자동으로 롤백**됩니다.
> 여러 개를 넣다가 중간에 실패해도 부분 저장이 남지 않습니다. ([Day 034](day-034.md)의 트랜잭션)
</details>

```python
"""도서 관리 데이터베이스 스키마."""

import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).resolve().parent / "library.db"

CREATE_BOOKS = """
CREATE TABLE IF NOT EXISTS books (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    title           TEXT    NOT NULL,
    author          TEXT    NOT NULL,
    isbn            TEXT    UNIQUE,
    published_year  INTEGER CHECK (published_year BETWEEN 1000 AND 2100),
    created_at      TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
)
"""

CREATE_MEMBERS = """
CREATE TABLE IF NOT EXISTS members (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    name       TEXT    NOT NULL,
    phone      TEXT    UNIQUE,
    joined_at  TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
)
"""

CREATE_LOANS = """
CREATE TABLE IF NOT EXISTS loans (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    book_id      INTEGER NOT NULL,
    member_id    INTEGER NOT NULL,
    loaned_at    TEXT    NOT NULL DEFAULT (datetime('now', 'localtime')),
    due_at       TEXT    NOT NULL,
    returned_at  TEXT,
    FOREIGN KEY (book_id)   REFERENCES books(id)   ON DELETE CASCADE,
    FOREIGN KEY (member_id) REFERENCES members(id) ON DELETE CASCADE
)
"""

INDEXES = [
    "CREATE INDEX IF NOT EXISTS idx_books_title   ON books(title)",
    "CREATE INDEX IF NOT EXISTS idx_books_author  ON books(author)",
    "CREATE INDEX IF NOT EXISTS idx_loans_book    ON loans(book_id)",
    "CREATE INDEX IF NOT EXISTS idx_loans_member  ON loans(member_id)",
    # 대출 중인 책을 빠르게 찾기 위한 부분 인덱스
    "CREATE INDEX IF NOT EXISTS idx_loans_active  ON loans(book_id) "
    "WHERE returned_at IS NULL",
]


def get_connection():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")      # 외래키 제약 활성화
    return conn


def init_db():
    conn = get_connection()
    try:
        with conn:
            conn.execute(CREATE_BOOKS)
            conn.execute(CREATE_MEMBERS)
            conn.execute(CREATE_LOANS)
            for sql in INDEXES:
                conn.execute(sql)
        return True
    except sqlite3.Error as e:
        print(f"[오류] {e}")
        return False
    finally:
        conn.close()


if __name__ == "__main__":
    init_db()
    print(f"생성 완료: {DB_PATH.name}\n")

    conn = get_connection()

    # 샘플 데이터
    with conn:
        conn.execute("INSERT OR IGNORE INTO books (title, author, isbn, published_year) "
                     "VALUES ('파이썬 코딩의 기술', '브렛 슬라킨', '9791162245651', 2020)")
        conn.execute("INSERT OR IGNORE INTO members (name, phone) "
                     "VALUES ('홍길동', '010-1234-5678')")
        conn.execute("INSERT INTO loans (book_id, member_id, due_at) "
                     "VALUES (1, 1, datetime('now', '+14 days', 'localtime'))")

    # 구조 확인
    for table in ("books", "members", "loans"):
        count = conn.execute(f"SELECT COUNT(*) AS c FROM {table}").fetchone()["c"]
        cols = conn.execute(f"PRAGMA table_info({table})").fetchall()
        print(f"[{table}]  열 {len(cols)}개 · 데이터 {count}건")

    # 대출 중인 책
    print("\n[현재 대출 중]")
    rows = conn.execute("""
        SELECT b.title, m.name, l.due_at
        FROM loans l
        JOIN books b   ON l.book_id = b.id
        JOIN members m ON l.member_id = m.id
        WHERE l.returned_at IS NULL
    """).fetchall()

    for r in rows:
        print(f"  {r['title']} → {r['name']} (반납 예정 {r['due_at'][:10]})")

    conn.close()
```

**실행 결과**

```

[books]  열 6개 · 데이터 1건
[members]  열 4개 · 데이터 1건
[loans]  열 6개 · 데이터 1건

  파이썬 코딩의 기술 → 홍길동 (반납 예정 2026-08-21)
```

**포인트 5가지**
- **`FOREIGN KEY`** 로 `loans.book_id` 가 실제 존재하는 책을 가리키게 강제합니다.
- **`PRAGMA foreign_keys = ON`** — SQLite 는 외래키 제약이 **기본으로 꺼져 있습니다.** 연결마다 켜야 합니다.
- `ON DELETE CASCADE` — 책이 삭제되면 관련 대출 기록도 함께 삭제됩니다.
- **부분 인덱스**(`WHERE returned_at IS NULL`) — 대출 중인 기록만 색인해 크기를 줄입니다.
- `datetime('now', '+14 days', 'localtime')` — SQLite 에서 날짜 계산이 가능합니다.

import sqlite3

conn = sqlite3.connect("game.db")

with conn:
    # ① 상수 기본값으로 열 추가
    conn.execute("ALTER TABLE scores ADD COLUMN created_at TEXT "
                 "NOT NULL DEFAULT '1970-01-01 00:00:00'")

    # ② 기존 데이터를 원하는 값으로 갱신 (필요하다면)
    conn.execute("UPDATE scores SET created_at = datetime('now', 'localtime') "
                 "WHERE created_at = '1970-01-01 00:00:00'")

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 흐름 | `connect` → `cursor` → `execute` → **`commit`** → `close` |
| `commit()` | **없으면 저장 안 됨** (가장 흔한 실수) |
| `with conn:` | 자동 커밋 / 예외 시 롤백 (연결은 안 닫음) |
| `CREATE TABLE` | 항상 `IF NOT EXISTS` |
| 제약 조건 | `NOT NULL` `UNIQUE` `DEFAULT` `CHECK` `PRIMARY KEY` |
| `row_factory` | `sqlite3.Row` 로 이름 접근 |
| 인덱스 | 자주 검색·정렬하는 열에만 |
| 시각 | `datetime('now', 'localtime')` — `localtime` 필수 |
| `:memory:` | 파일 없이 테스트용 DB |
| 스키마 변경 | 열 삭제·타입 변경 불가 → **처음 설계가 중요** |

**오늘 반드시 기억할 세 가지**
> ① `commit()` 을 잊지 마세요. 데이터가 안 보이면 제일 먼저 확인할 것.
> ② `datetime('now')` 는 UTC 입니다. **`'localtime'` 을 꼭 붙이세요.**
> ③ 테이블/열 이름을 사용자 입력으로 조합하지 마세요.

**과제** — 어제 작성한 설계서대로 `game.db` 를 만들고, DB Browser 로 열어 구조를 확인하세요.
`meta` 테이블에 스키마 버전을 기록하고, 기본 설정 3개를 넣습니다.
