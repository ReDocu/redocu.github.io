## 단원 개요

### 이 단원을 마치면

- 팀 저장소에서 **브랜치 전략과 PR 리뷰로 협업**할 수 있다.
- Linux 서버에 접속해 **서비스를 배포하고 프로세스·로그를 관리**할 수 있다.
- 서비스를 **Docker 이미지로 만들고 Compose로 다중 컨테이너 구성**을 운영할 수 있다.
- GitHub Actions로 **테스트→빌드→배포가 자동으로 도는 CI/CD**를 만들 수 있다.
- DVC·Airflow·모니터링으로 **데이터/모델 버전 관리와 재학습 파이프라인**을 구성할 수 있다.

### 왜 7주인가

이 과정의 이름이 걸린 단원입니다. MP3까지는 "내 노트북에서 도는 서비스"였다면,
이 단원이 끝나면 **남의 서버에서 자동으로 갱신되며 도는 서비스**가 됩니다.
Git 협업(W22) → 서버(W23) → 컨테이너(W24–25) → 자동화(W26) → ML 특화 운영(W27)의 순서는
각 주가 다음 주의 도구를 전제하기 때문에 바꿀 수 없습니다.
