## ② 왜 필요한가

## ③ 개념 설명

### 매직 메서드 — 파이썬 문법과 연결되는 메서드

`__이름__` 형태의 메서드는 파이썬의 **기본 문법과 연결**되어 있습니다.

| 매직 메서드 | 연결된 문법 | 반환 |
|---|---|---|
| `__init__` | `Player()` | 없음 |
| `__str__` | `print(p)`, `str(p)` | 문자열 (사용자용) |
| `__repr__` | `p` (셸에서), 리스트 출력 | 문자열 (개발자용) |
| `__eq__` | `p1 == p2` | bool |
| `__lt__` | `p1 < p2`, `sorted()` | bool |
| `__len__` | `len(p)` | int |
| `__getitem__` | `p[0]` | 아무거나 |
| `__contains__` | `x in p` | bool |
| `__add__` | `p1 + p2` | 아무거나 |
| `__bool__` | `if p:` | bool |

### `__str__` 과 `__repr__`

```python
class Player:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def __str__(self):
        """사용자에게 보여 줄 형태."""
        return f"{self.name} (HP {self.hp})"

    def __repr__(self):
        """개발자용. 가능하면 '이 코드를 실행하면 같은 객체가 된다' 형태로."""
        return f"Player(name={self.name!r}, hp={self.hp})"


p = Player("홍길동", 100)

print(p)              # 홍길동 (HP 100)     ← __str__
print(str(p))         # 홍길동 (HP 100)     ← __str__
print(repr(p))        # Player(name='홍길동', hp=100)  ← __repr__
print([p])            # [Player(name='홍길동', hp=100)] ← 리스트 안에서는 __repr__
```

> **`__str__` 만 정의해도 대부분 충분합니다.** 하지만 리스트에 담아 출력할 일이 많다면 `__repr__` 도 정의하세요.
> `__str__` 이 없으면 파이썬은 `__repr__` 을 대신 씁니다. 하나만 만든다면 `__repr__` 이 낫습니다.
>
> `{self.name!r}` 의 `!r` 은 "repr 형태로" 라는 뜻입니다. 문자열이면 따옴표가 붙습니다.

### `__eq__` — 같음을 정의하기

기본적으로 파이썬은 **객체의 주소**로 같음을 판단합니다.

```python
class Item:
    def __init__(self, name):
        self.name = name

a = Item("검")
b = Item("검")

print(a == b)      # False!  내용은 같지만 다른 객체
```

`__eq__` 를 정의하면 **내용으로 비교**할 수 있습니다.

```python
class Item:
    def __init__(self, name):
        self.name = name

    def __eq__(self, other):
        if not isinstance(other, Item):
            return NotImplemented
        return self.name == other.name

    def __hash__(self):
        """__eq__ 를 정의하면 __hash__ 도 함께 정의해야 세트/딕셔너리에 넣을 수 있습니다."""
        return hash(self.name)


a = Item("검")
b = Item("검")

print(a == b)              # True
print(a is b)              # False  (여전히 다른 객체)
print(len({a, b}))         # 1      (세트에서 중복으로 인식)
```

> ⚠️ **`__eq__` 를 정의하면 `__hash__` 도 정의하세요.** 안 하면 세트나 딕셔너리 키로 쓸 수 없게 됩니다.

### `__lt__` — 정렬 기준 정하기

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __lt__(self, other):
        """점수가 낮으면 작다."""
        return self.score < other.score

    def __repr__(self):
        return f"{self.name}({self.score})"


students = [Student("홍길동", 85), Student("김철수", 92), Student("이영희", 78)]

print(sorted(students))                    # [이영희(78), 홍길동(85), 김철수(92)]
print(max(students))                       # 김철수(92)
print(sorted(students, reverse=True))      # [김철수(92), 홍길동(85), 이영희(78)]
```

> `__lt__` 하나만 정의해도 `sorted()`, `max()`, `min()` 이 전부 동작합니다.
> 다만 `key=lambda s: s.score` 를 쓰는 방법도 있으니, **정렬 기준이 명확히 하나일 때만** `__lt__` 를 쓰세요.

### `__len__`, `__getitem__`, `__contains__` — 컨테이너처럼 만들기

```python
class Inventory:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __bool__(self):
        """비어 있으면 False."""
        return len(self.items) > 0


inv = Inventory()
inv.add("검")
inv.add("방패")

print(len(inv))            # 2
print(inv[0])              # 검
print("검" in inv)          # True

for item in inv:           # __getitem__ 덕분에 반복도 됨
    print(item)

if inv:                    # __bool__
    print("아이템이 있습니다")
```

> **이 매직 메서드들 덕분에 내가 만든 클래스가 리스트처럼 자연스럽게 동작합니다.**
> `inv.get_items()[0]` 대신 `inv[0]` 이라고 쓸 수 있는 것이 파이썬다움입니다.

### 캡슐화 — 내부를 감추기

파이썬에는 진짜 `private` 이 없습니다. 대신 **이름 규칙**으로 의도를 표현합니다.

| 이름 | 뜻 | 접근 |
|---|---|---|
| `self.name` | 공개 (public) | 자유롭게 |
| `self._name` | **내부용** (관례) | 가능하지만 "건드리지 마세요" |
| `self.__name` | 이름 변경(name mangling) | 밖에서 직접 접근 어려움 |

```python
class Player:
    def __init__(self, name, hp):
        self.name = name          # 공개
        self._hp = hp             # 내부용
        self.__secret = "비밀"     # 이름이 바뀜


p = Player("홍길동", 100)

print(p.name)          # 홍길동
print(p._hp)           # 100    (가능은 하다)
print(p.__secret)      # AttributeError!
print(p._Player__secret)   # 비밀  (실제로는 이름이 바뀌었을 뿐)
```

> **밑줄 하나(`_hp`)가 실무 표준**입니다. 강제하지는 않지만 "이건 내부 구현이니 직접 쓰지 마세요"라는 약속입니다.
> 밑줄 두 개는 상속 시 이름 충돌을 피할 때만 씁니다.

### `@property` — 메서드를 속성처럼

`_hp` 를 감췄는데 읽기는 편하게 하고 싶다면?

```python
class Player:
    def __init__(self, name, max_hp):
        self.name = name
        self._hp = max_hp
        self._max_hp = max_hp

    @property
    def hp(self):
        """읽기 — p.hp 라고 쓰면 이 메서드가 실행됩니다."""
        return self._hp

    @hp.setter
    def hp(self, value):
        """쓰기 — p.hp = 50 이라고 쓰면 이 메서드가 실행됩니다."""
        if value < 0:
            value = 0
        elif value > self._max_hp:
            value = self._max_hp
        self._hp = value

    @property
    def hp_percent(self):
        """계산된 값도 속성처럼 노출할 수 있습니다."""
        return self._hp / self._max_hp * 100

    @property
    def is_alive(self):
        return self._hp > 0


p = Player("홍길동", 100)

print(p.hp)                # 100   (괄호 없이!)
print(p.hp_percent)        # 100.0
print(p.is_alive)          # True

p.hp = -50                 # setter 가 0으로 보정
print(p.hp)                # 0

p.hp = 99999               # setter 가 최대치로 보정
print(p.hp)                # 100
```

> **`@property` 의 가치** — 밖에서 보면 그냥 속성처럼 쓰지만, **안에서는 검증 로직이 돕니다.**
> 나중에 규칙이 바뀌어도 클래스 안만 고치면 되고, 이 클래스를 쓰는 코드는 안 바뀝니다.
>
> 다만 **모든 속성에 property 를 만들 필요는 없습니다.** 검증이나 계산이 필요한 것에만 쓰세요.

### 상속 vs 컴포지션

| | 상속 (is-a) | 컴포지션 (has-a) |
|---|---|---|
| 관계 | "A는 B다" | "A는 B를 가진다" |
| 코드 | `class Dog(Animal):` | `self.engine = Engine()` |
| 예 | 전사는 캐릭터다 | 자동차는 엔진을 가진다 |
| 결합도 | 강함 (부모 변경이 자식에 직접 영향) | 약함 |
| 유연성 | 낮음 (하나의 부모) | 높음 (여러 부품 조합) |

```python
# ❌ 상속 오용
class Car(Engine):        # 자동차는 엔진이 아니다
    pass

# ✅ 컴포지션
class Engine:
    def __init__(self, horsepower):
        self.horsepower = horsepower

    def start(self):
        print(f"엔진 시동 ({self.horsepower}마력)")


class Wheel:
    def __init__(self, size):
        self.size = size


class Car:
    def __init__(self, name, horsepower):
        self.name = name
        self.engine = Engine(horsepower)              # 가진다
        self.wheels = [Wheel(18) for _ in range(4)]   # 가진다

    def start(self):
        print(f"{self.name} 출발!")
        self.engine.start()                           # 위임


car = Car("소나타", 200)
car.start()
```

실행 결과:

```
소나타 출발!
엔진 시동 (200마력)
```

> **"상속보다 컴포지션을 선호하라"** 는 객체지향의 유명한 원칙입니다.
> 상속은 부모와 자식이 강하게 묶여, 부모를 고치면 모든 자식이 영향을 받습니다.
> 컴포지션은 부품을 갈아 끼우기 쉽습니다.
>
> **실무 판단** — 정말 "종류가 다른 같은 것"이면 상속, 그 외에는 컴포지션.

### Step 1. 매직 메서드로 파이썬다운 클래스 만들기

`magic.py` 를 만들어 실행합니다.

```python
class Vector:
    """2차원 벡터. pygame 의 좌표 계산에 쓰이는 개념입니다."""

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        """v1 + v2"""
        return Vector(self.x + other.x, self.y + other.y)

    def __sub__(self, other):
        """v1 - v2"""
        return Vector(self.x - other.x, self.y - other.y)

    def __mul__(self, scalar):
        """v * 3"""
        return Vector(self.x * scalar, self.y * scalar)

    def __eq__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return self.x == other.x and self.y == other.y

    def __hash__(self):
        return hash((self.x, self.y))

    def length(self):
        """벡터의 길이(원점으로부터의 거리)."""
        return (self.x ** 2 + self.y ** 2) ** 0.5


a = Vector(3, 4)
b = Vector(1, 2)

print(f"a       = {a}")
print(f"b       = {b}")
print(f"a + b   = {a + b}")
print(f"a - b   = {a - b}")
print(f"a * 3   = {a * 3}")
print(f"a 길이   = {a.length()}")
print(f"a == b  ? {a == b}")
print(f"a == Vector(3,4) ? {a == Vector(3, 4)}")
print(f"리스트에서: {[a, b]}")
print(f"세트에서:   {len({Vector(3,4), Vector(3,4), Vector(1,2)})}개")
```

실행 결과:

```

b       = (1, 2)
a + b   = (4, 6)
a - b   = (2, 2)
a * 3   = (9, 12)
a 길이   = 5.0
a == b  ? False
a == Vector(3,4) ? True
리스트에서: [Vector(3, 4), Vector(1, 2)]
세트에서:   2개
```

> `pygame` 에는 이미 `pygame.Vector2` 가 있습니다. 여기서 직접 만들어 보는 이유는 **내일 좌표 계산을 이해하기 위해서**입니다.

### Step 2. `@property` 로 안전한 캐릭터 만들기

```python
class Character:
    """체력이 절대 범위를 벗어나지 않는 캐릭터."""

    def __init__(self, name, max_hp, attack):
        self.name = name
        self._max_hp = max_hp
        self._hp = max_hp
        self._attack = attack

    # ── 체력 ──
    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        """0 ~ max_hp 범위로 자동 보정합니다."""
        self._hp = max(0, min(value, self._max_hp))

    @property
    def max_hp(self):
        """최대 체력은 읽기 전용입니다."""
        return self._max_hp

    # ── 계산되는 속성 ──
    @property
    def hp_percent(self):
        return self._hp / self._max_hp * 100

    @property
    def is_alive(self):
        return self._hp > 0

    @property
    def status(self):
        """체력 비율에 따른 상태."""
        pct = self.hp_percent
        if pct == 0:
            return "사망"
        elif pct < 25:
            return "위험"
        elif pct < 60:
            return "부상"
        return "양호"

    # ── 공격력 ──
    @property
    def attack(self):
        return self._attack

    @attack.setter
    def attack(self, value):
        if value < 1:
            raise ValueError("공격력은 1 이상이어야 합니다")
        self._attack = value

    # ── 메서드 ──
    def __str__(self):
        width = 12
        filled = int(width * self._hp / self._max_hp)
        bar = "█" * filled + "░" * (width - filled)
        return f"{self.name:<8} [{bar}] {self._hp:>3}/{self._max_hp} ({self.status})"


c = Character("홍길동", 100, 15)

print(c)

print("\n[체력을 마음대로 조작해 보기]")
c.hp = -999
print(c)

c.hp = 45
print(c)

c.hp = 10
print(c)

c.hp = 99999
print(c)

print("\n[읽기 전용 속성]")
try:
    c.max_hp = 200
except AttributeError as e:
    print(f"  오류: {e}")

print("\n[공격력 검증]")
c.attack = 25
print(f"  공격력 {c.attack}")
try:
    c.attack = 0
except ValueError as e:
    print(f"  오류: {e}")
```

실행 결과:

```

[체력을 마음대로 조작해 보기]
홍길동      [░░░░░░░░░░░░]   0/100 (사망)
홍길동      [█████░░░░░░░]  45/100 (부상)
홍길동      [█░░░░░░░░░░░]  10/100 (위험)
홍길동      [████████████] 100/100 (양호)

[읽기 전용 속성]
  오류: property 'max_hp' of 'Character' object has no setter

  공격력 25
```

> **`c.hp = -999` 를 써도 안전합니다.** 밖에서 무슨 값을 넣든 클래스가 스스로를 지킵니다.
> `setter` 를 만들지 않은 `max_hp` 는 **읽기 전용**이 되어 실수로 바꿀 수 없습니다.

### Step 3. 컴포지션 — 인벤토리 시스템

```python
class Item:
    """아이템 하나."""

    def __init__(self, name, price, weight):
        self.name = name
        self.price = price
        self.weight = weight

    def __str__(self):
        return f"{self.name}({self.price}G, {self.weight}kg)"

    def __repr__(self):
        return f"Item({self.name!r})"

    def __eq__(self, other):
        return isinstance(other, Item) and self.name == other.name

    def __hash__(self):
        return hash(self.name)


class Inventory:
    """아이템을 담는 가방. Item 을 '가진다'(has-a)."""

    def __init__(self, max_weight=50):
        self._items = []
        self.max_weight = max_weight

    # ── 매직 메서드로 리스트처럼 동작하게 ──
    def __len__(self):
        return len(self._items)

    def __getitem__(self, index):
        return self._items[index]

    def __contains__(self, item):
        return item in self._items

    def __bool__(self):
        return len(self._items) > 0

    def __str__(self):
        if not self._items:
            return "(비어 있음)"
        return "\n".join(f"  - {item}" for item in self._items)

    # ── 계산 속성 ──
    @property
    def total_weight(self):
        return sum(i.weight for i in self._items)

    @property
    def total_value(self):
        return sum(i.price for i in self._items)

    @property
    def free_weight(self):
        return self.max_weight - self.total_weight

    # ── 기능 ──
    def add(self, item):
        """아이템을 넣습니다. 무게를 초과하면 실패."""
        if self.total_weight + item.weight > self.max_weight:
            print(f"  ✗ 무게 초과! {item.name}({item.weight}kg) — 여유 {self.free_weight}kg")
            return False

        self._items.append(item)
        print(f"  ✓ {item.name} 획득 ({self.total_weight}/{self.max_weight}kg)")
        return True

    def remove(self, name):
        """이름으로 아이템을 버립니다."""
        for item in self._items:
            if item.name == name:
                self._items.remove(item)
                print(f"  ✓ {name} 버림 ({self.total_weight}/{self.max_weight}kg)")
                return item

        print(f"  ✗ {name} 을(를) 가지고 있지 않습니다")
        return None

    def sort_by_value(self):
        """가치 순으로 정렬합니다."""
        self._items.sort(key=lambda i: i.price, reverse=True)


class Player:
    """플레이어. Inventory 를 '가진다'(has-a)."""

    def __init__(self, name, max_weight=50):

        self.gold = 0
        self.inventory = Inventory(max_weight)      # 컴포지션
```

### Step 4. 상속 + 컴포지션 함께 쓰기 (오늘의 종합 예제)

```python
import random


class Weapon:
    """무기 — 캐릭터가 '가지는' 부품."""

    def __init__(self, name, damage, crit_rate=0.1):
        self.name = name
        self.damage = damage
        self.crit_rate = crit_rate

    def roll_damage(self):
        """공격력을 굴립니다. (데미지, 치명타 여부)"""
        base = int(self.damage * random.uniform(0.9, 1.1))
        is_crit = random.random() < self.crit_rate
        return (base * 2 if is_crit else base), is_crit

    def __str__(self):
        return f"{self.name}(공격 {self.damage}, 치명 {self.crit_rate * 100:.0f}%)"


class Armor:
    """방어구 — 캐릭터가 '가지는' 부품."""

    def __init__(self, name, defense):
        self.name = name
        self.defense = defense

    def __str__(self):
        return f"{self.name}(방어 {self.defense})"


class Character:
    """캐릭터의 부모 클래스. 무기와 방어구를 '가진다'."""

    def __init__(self, name, max_hp, weapon=None, armor=None):
        self.name = name
        self._max_hp = max_hp
        self._hp = max_hp
        self.weapon = weapon              # 컴포지션
        self.armor = armor                # 컴포지션

    # ── property ──
    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, min(value, self._max_hp))

    @property
    def is_alive(self):
        return self._hp > 0

    @property
    def defense(self):
        """장착한 방어구의 방어력. 없으면 0."""
        return self.armor.defense if self.armor else 0

    # ── 매직 메서드 ──
    def __str__(self):
        width = 12
        filled = int(width * self._hp / self._max_hp)
        bar = "█" * filled + "░" * (width - filled)
        role = self.__class__.__name__
        return f"{self.name:<8}({role:<8}) [{bar}] {self._hp:>3}/{self._max_hp}"

    def __repr__(self):
        return f"{self.__class__.__name__}({self.name!r})"

    # ── 메서드 ──
    def equip(self, gear):
        """무기나 방어구를 장착합니다."""
        if isinstance(gear, Weapon):
            self.weapon = gear
            print(f"  {self.name}: {gear.name} 장착")
        elif isinstance(gear, Armor):
            self.armor = gear
            print(f"  {self.name}: {gear.name} 착용")

    def attack(self, target):
        """대상을 공격합니다."""
        if self.weapon is None:
            damage, is_crit = random.randint(1, 4), False       # 맨손
            weapon_name = "맨손"
        else:
            damage, is_crit = self.weapon.roll_damage()
            weapon_name = self.weapon.name

        actual = max(damage - target.defense, 1)
        target.hp -= actual

        mark = " 치명타!" if is_crit else ""
        print(f"  {self.name}({weapon_name}) → {target.name} {actual} 피해{mark}")
        return actual


class Warrior(Character):
    """전사 — 방어구 효과가 1.5배."""

    @property
    def defense(self):
        return int(super().defense * 1.5)


class Rogue(Character):
    """도적 — 회피 확률이 있다."""

    DODGE_RATE = 0.25

    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        """피해를 입을 때만 회피 판정을 합니다."""
        if value < self._hp and random.random() < Rogue.DODGE_RATE:
            print(f"    ↳ {self.name} 회피!")
            return
        self._hp = max(0, min(value, self._max_hp))


# ── 실행 ──
hero = Warrior("아서", 150)
thief = Rogue("실비", 90)

print("=" * 52)
print("                  장비 장착")
print("=" * 52)

hero.equip(Weapon("대검", 22, crit_rate=0.15))
hero.equip(Armor("판금 갑옷", 8))
thief.equip(Weapon("단검", 14, crit_rate=0.35))
thief.equip(Armor("가죽 갑옷", 3))

print(f"\n  아서 방어력: {hero.defense}  (판금 8 × 1.5 = 전사 특성)")
print(f"  실비 방어력: {thief.defense}")

print("\n" + "=" * 52)
print("                  결투 시작!")
print("=" * 52)

turn = 1
while hero.is_alive and thief.is_alive and turn <= 20:
    print(f"\n--- {turn}턴 ---")
    hero.attack(thief)
    if not thief.is_alive:
        break
    thief.attack(hero)

    print()
    print(f"  {hero}")
    print(f"  {thief}")
    turn += 1

print("\n" + "=" * 52)
winner = hero if hero.is_alive else thief
print(f"  승자: {winner.name} ({winner.__class__.__name__})")
print("=" * 52)
```

```python
class Temperature:
    """온도. 내부적으로는 섭씨로 저장합니다."""

    ABSOLUTE_ZERO = -273.15

    def __init__(self, celsius=0):
        self.celsius = celsius          # setter 를 거침

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < Temperature.ABSOLUTE_ZERO:
            raise ValueError(f"절대영도({Temperature.ABSOLUTE_ZERO}℃) 아래는 불가능합니다")
        self._celsius = value

    @property
    def fahrenheit(self):
        """화씨로 읽기."""
        return self._celsius * 9 / 5 + 32

    @fahrenheit.setter
    def fahrenheit(self, value):
        """화씨로 쓰기 — 섭씨로 변환해 저장합니다."""
        self.celsius = (value - 32) * 5 / 9      # celsius setter 가 검증까지 함

    @property
    def kelvin(self):
        """켈빈으로 읽기 (읽기 전용)."""
        return self._celsius - Temperature.ABSOLUTE_ZERO

    def __str__(self):
        return f"{self._celsius:.1f}℃ / {self.fahrenheit:.1f}℉ / {self.kelvin:.2f}K"

    def __lt__(self, other):
        return self._celsius < other._celsius

    def __eq__(self, other):
        return isinstance(other, Temperature) and abs(self._celsius - other._celsius) < 1e-9

    def __hash__(self):
        return hash(round(self._celsius, 9))
```


**포인트 4가지**
- **`fahrenheit` setter 가 `self.celsius = ...` 를 씁니다.** `self._celsius` 를 직접 쓰지 않으면 검증 로직이 자동으로 재사용됩니다. 검증 코드가 한 곳에만 있습니다.
- `__init__` 에서도 `self.celsius = celsius` (밑줄 없이)를 써서 생성 시점부터 검증이 걸립니다.
- `kelvin` 은 setter 가 없어 **읽기 전용**입니다.
- 실수 비교는 `==` 대신 `abs(a - b) < 1e-9` 를 씁니다. 부동소수점 오차 때문입니다.
</details>

**3.** 아래 코드는 `Team` 이 `Player` 를 상속받았습니다. 무엇이 문제이고 어떻게 고쳐야 할까요?

```python
class Player:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def play(self):
        print(f"{self.name} 플레이!")


class Team(Player):
    def __init__(self, team_name):
        super().__init__(team_name, 0)
        self.members = []

    def add_member(self, player):
        self.members.append(player)


team = Team("드림팀")
team.add_member(Player("홍길동", 10))
team.play()
print(team.score)
```

<details>
<summary>답 보기</summary>

**문제 — 관계가 잘못되었습니다.**

"팀은 선수다(Team **is a** Player)"? 아닙니다.
**"팀은 선수들을 가진다(Team **has** Players)"** 가 맞습니다.

상속 때문에 생기는 이상한 일들:

```python
team.play()          # 팀이 직접 플레이한다? 의미가 이상함
team.score           # 팀의 점수인가, 팀이라는 선수의 점수인가?
team.name            # 팀 이름을 선수 이름 자리에 억지로 넣음
```

`Player` 에 새 메서드(`get_ranking()`, `retire()`)가 추가되면 `Team` 도 자동으로 갖게 됩니다.
`team.retire()` — 의미가 없는 메서드가 생깁니다.

**해결 — 컴포지션으로 바꿉니다.**

```python
class Player:
    def __init__(self, name, score=0):
        self.name = name
        self.score = score

    def play(self):
        print(f"  {self.name} 플레이! (+{self.score}점)")

    def __repr__(self):
        return f"Player({self.name!r}, {self.score})"


class Team:
    """팀은 선수를 '가진다'."""

    def __init__(self, team_name):
        self.team_name = team_name
        self.members = []              # 컴포지션

    def add_member(self, player):
        self.members.append(player)
        print(f"  {player.name} 이(가) {self.team_name}에 합류")

    @property
    def total_score(self):
        """팀 점수는 선수 점수의 합."""
        return sum(p.score for p in self.members)

    @property
    def best_player(self):
        return max(self.members, key=lambda p: p.score) if self.members else None

    def play_all(self):
        """모든 선수가 플레이합니다."""
        print(f"\n[{self.team_name} 출전]")
        for p in self.members:
            p.play()

    def __len__(self):
        return len(self.members)

    def __str__(self):
        return f"{self.team_name} ({len(self)}명, {self.total_score}점)"


# ── 사용 ──
team = Team("드림팀")
team.add_member(Player("홍길동", 10))
team.add_member(Player("김철수", 25))
team.add_member(Player("이영희", 18))

team.play_all()

print(f"\n{team}")
print(f"에이스: {team.best_player}")
```

실행 결과:

```
  홍길동 이(가) 드림팀에 합류
  김철수 이(가) 드림팀에 합류
  이영희 이(가) 드림팀에 합류

[드림팀 출전]
  홍길동 플레이! (+10점)
  김철수 플레이! (+25점)
  이영희 플레이! (+18점)

드림팀 (3명, 53점)
에이스: Player('김철수', 25)
```

> **판단법을 다시 정리하면** —
> - "A는 B다" 가 자연스러운가? → 상속 (`Warrior is a Character` ✅)
> - "A는 B를 가진다" 가 자연스러운가? → 컴포지션 (`Team has Players` ✅)
>
> 헷갈릴 때는 **"부모의 모든 메서드가 자식에게도 말이 되는가"** 를 물어보세요.
> `team.retire()` 가 말이 안 되면 상속이 아닙니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `__str__` / `__repr__` | `print()` 용 / 개발자용. **문자열을 반환** |
| `__eq__` | 내용 비교. **`__hash__` 도 함께 정의** |
| `__lt__` | `sorted()`, `max()` 가 동작하게 |
| `__len__` `__getitem__` `__contains__` | 리스트처럼 쓸 수 있게 |
| 캡슐화 | `_name` = 내부용 (관례) |
| `@property` | 메서드를 **속성처럼** (괄호 없이) |
| `@이름.setter` | 대입 시 검증. 없으면 **읽기 전용** |
| property 내부 저장 | 반드시 **`_다른이름`** (무한 재귀 방지) |
| 상속 vs 컴포지션 | **is-a** vs **has-a** · 애매하면 컴포지션 |

**오늘 반드시 기억할 두 가지**
> ① `@property` 의 내부 저장은 `self._hp` 처럼 **다른 이름**을 쓰세요. 같으면 무한 재귀입니다.
> ② "A는 B다" 가 어색하면 상속이 아니라 **컴포지션**입니다.

체력을 `@property` 로 보호하세요. `MonsterBook` 에는 `__len__`, `__getitem__`, `__contains__` 를 추가합니다.
