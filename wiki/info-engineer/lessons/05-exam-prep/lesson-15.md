## ① 학습 목표

이 강을 마치면 다음을 할 수 있습니다.

- 20문항·150분 시험을 **실전 규칙 그대로 완주할 수 있다**
- 훑기→◎→△→검산의 시간 배분 전략을 **실측 환경에서 적용할 수 있다**
- 자신의 실전 점수와 실점 위치를 **확정할 수 있다**

---

## ② 왜 필요한가

**연습의 마지막 단계는 시험을 미리 한 번 치르는 것입니다.** 150분을 실제로 앉아 보면 아는 것과 다른 사실들이 드러납니다 — 90분쯤의 집중력 저하, 검산 시간의 부족, 답안지에 옮길 때의 실수. 이 발견을 시험장에서 처음 하면 늦습니다. 오늘 하면 16강에서 고칠 수 있습니다.

**실전 규칙** — ①150분 연속, 중간 이탈·질문 불가 ②답안지 형식 인쇄물([A10 양식](../appendix/A10-answer-sheet.md))에 작성 ③검은색 필기구만 ④종료 후 즉시 가채점. 문제지는 기출 원문 복제가 없는 창작 1회분이며, 영역 비율(코드 10·SQL 5·이론 5)은 기출 복원 경향(비공식)의 근사치입니다.

| 답안 규칙 | 출력은 보이는 그대로 / 요구 키워드 사용 / 철자 정확히 / 빈칸 금지 |

## ④ 단계별 실습

### Step 1. 🏁 실전 모의고사 (20문항 · 150분 · 각 5점 · 총 100점)

SQL 문제는 [공용 예제 스키마](../03-database/lesson-07.md) 기준입니다.

**A. 코드 (1~10번)**

1. [C] 다음 코드의 출력을 쓰시오.
   ```c
   int x = 10, y = 3;
   printf("%d %d %.1f", x % y, x / y, (float)x / y);
   ```
2. [C] 다음 코드의 출력을 쓰시오.
   ```c
   int a[6] = {2, 5, 8, 11, 14, 17};
   int i, cnt = 0;
   for (i = 0; i < 6; i++) {
       if (a[i] % 2 == 1) cnt++;
   }
   printf("%d", cnt);
   ```
3. [C] 다음 코드의 출력을 쓰시오.
   ```c
   int a[] = {10, 20, 30, 40, 50};
   int *p = a + 3;
   printf("%d", *(p - 2) + *(p + 1));
   ```
4. [C] 다음 함수에서 `f(1234)`의 반환값과, 이 함수가 구하는 것을 한 문장으로 쓰시오.
   ```c
   int f(int n) {
       if (n == 0) return 0;
       return n % 10 + f(n / 10);
   }
   ```
5. [Java] 다음 코드의 출력을 쓰시오.
   ```java
   int s = 0;
   for (int i = 1; i <= 20; i++) {
       if (i % 3 == 0 && i % 2 == 0) s += i;
   }
   System.out.println(s);
   ```
6. [Java] 다음 코드의 출력을 쓰시오.
   ```java
   class Shape {
       void draw() { System.out.print("도형"); }
   }
   class Circle extends Shape {
       @Override
       void draw() { System.out.print("원"); }
       void draw(int n) { System.out.print(n); }
   }
   public class Main {
       public static void main(String[] args) {
           Circle c = new Circle();
           c.draw();
           c.draw(3);
           Shape s = c;
           s.draw();
       }
   }
   ```
7. [Java] 다음 코드의 출력을 쓰시오.
   ```java
   String s = "INFORMATION";
   System.out.println(s.substring(2, 6) + s.charAt(0));
   ```
8. [Python] 다음 코드의 출력을 쓰시오.
   ```python
   a = [1, 2, 3, 4, 5, 6]
   print(a[1::2], sum(a[:3]))
   ```
9. [Python] 다음 코드의 출력을 쓰시오.
   ```python
   t = ("A", "B", "C")
   d = {"A": 90, "B": 80, "C": 70}
   s = 0
   for k in t:
       if d[k] >= 80:
           s += 1
   print(s)
   ```
10. [Python·빈칸] 5! = 120이 출력되도록 빈칸을 채우시오.
    ```python
    def fact(n):
        if n <= 1:
            return 1
        return n * fact(________)
    print(fact(5))
    ```

**B. SQL (11~15번)**

11. [작성] 3학년 학생의 이름과 학과코드를 학번 오름차순으로 조회하는 SQL을 쓰시오.
12. [결과 예측] 다음 SQL의 결과를 쓰시오.
    ```sql
    SELECT 과목코드, MAX(성적)
    FROM   ENROLL
    GROUP BY 과목코드
    HAVING MAX(성적) >= 90;
    ```
13. [빈칸] 수강 기록이 있는 학생의 이름을 조회한다. → `SELECT 이름 FROM STUDENT WHERE 학번 ______ (SELECT 학번 FROM ENROLL);`
14. [빈칸] STUDENT 테이블에서 이메일 열을 삭제한다. → `ALTER TABLE STUDENT ______ COLUMN 이메일;`
15. [단답] 트랜잭션의 일부만 되돌릴 수 있도록 중간 지점을 표시해 두는 TCL 명령은?

**C. 이론 (16~20번)**

16. [단답] 응집도 중 가장 바람직한(높은) 단계를 쓰시오.
17. [단답] 입력 자료의 경계(양 끝) 값에서 오류가 잦다는 점을 이용하는 블랙박스 테스트 기법은?
18. [단답] 웹 입력란에 악의적인 질의문을 삽입하여 데이터베이스를 비정상적으로 조작하는 공격은?
19. [단답] TCP가 동작하며 종단 간 신뢰성 있는 전송을 담당하는 OSI 계층은?
20. [계산] 참조 순서 `A, B, C, A, B, D` · 프레임 3개 · FIFO 기법일 때 페이지 부재 횟수를 쓰시오.

## ⑤ 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| 훑기 생략하고 1번부터 | 3·4번(🔴)에 초반 30분을 잃는 구조 | 훑기 5분은 생략 불가 절차 |
| 코드 추적을 문제지 구석에 흘려 씀 | 검산 단계에서 재활용 불가 | 문항 번호를 붙인 추적표 형태로 |
| 답안지 옮겨 적기를 마지막 5분에 | 옮기다 시간 종료가 실전 최다 사고 | ◎ 문항은 풀 때마다 바로 답안지에 |
| SQL 결과 예측에서 행 수를 안 셈 | 12번처럼 "몇 행인가"가 함정의 본체 | 결과를 표로 그리고 행 수 명기 |
| `3.3`을 `3.33`으로 | %.1f의 자리 지정 무시 | 포맷 지정자를 문제의 일부로 읽기 |

## 마무리

**오늘의 요약** — 150분 실측으로 나의 실전 점수와 실점 지도가 확정되었습니다. 점수보다 중요한 것은 실점의 유형 분포이고, 그것이 16강 해설과 A6 7일 계획의 입력값입니다.

**복습 체크리스트**

- [ ] 가채점 완료, 점수 처방 표에서 내 위치 확인
- [ ] 실점 문항에 개념/절차/형식 표시 완료
- [ ] 오답 전부 오답노트 기록 (16강 해설 전까지)

**과제** — ① 오답노트 기록 완료, ② 틀린 코드 문항은 추적표를 다시 만들어 재풀이, ③ 16강 준비물: 오답노트 전체 + 14강 진단 매트릭스.

**다음 강 예고** — 16강(마지막 강)은 모의고사 전 문항 상세 해설과 대표 오답 분석, 최종 암기 스피드 런, 그리고 [시험 직전 7일 계획(A6)](../appendix/A06-final-7days.md)의 개인화입니다.
