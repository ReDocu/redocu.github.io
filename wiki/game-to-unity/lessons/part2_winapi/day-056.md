## 3. 개념

### 3-1. 툴과 게임의 분리

**왜 필요한가** — 툴 코드가 게임에 섞이면 안 된다.

```
   ┌──────────────────────────────────────────────────────────┐
   │  MapTool.exe (개발용)          Game.exe (배포용)          │
   │                                                           │
   │  - 타일 팔레트 UI              - 맵 파일 로드              │
   │  - 마우스 편집                 - 타일 렌더                 │
   │  - 저장/불러오기               - 충돌 판정                 │
   │  - Undo/Redo                                              │
   │  - 격자 표시                                              │
   │         │                              ▲                  │
   │         └──────  .map 파일  ───────────┘                  │
   └──────────────────────────────────────────────────────────┘

   ★ 공유하는 것은 "파일 포맷"뿐이다
```

| | 툴 | 게임 |
|---|---|---|
| 목적 | 데이터 제작 | 데이터 사용 |
| 사용자 | 개발자·기획자 | 플레이어 |
| 배포 | 안 함 | 함 |
| 성능 | 덜 중요 | 중요 |
| UI | 복잡 | 단순 |

**공유 코드**

```
   Engine/          프레임워크 (양쪽 다 사용)
   Common/
     ├─ TileMap.h/.cpp      맵 데이터 구조
     ├─ MapFormat.h         파일 포맷 정의
     └─ TileSet.h/.cpp      타일셋 관리

   MapTool/         툴 전용
   Game/            게임 전용
```

> **`Common/`을 만들어 두면 포맷이 바뀔 때 한 곳만 고치면 된다.**

### 3-2. 타일맵 데이터 구조

**왜 필요한가** — 맵의 본질은 2차원 배열이다. (Day 12의 그것)

```cpp
struct Tile
{
    int  tileIndex;                            // 타일셋에서의 번호 (-1 = 비어 있음)
    int  attribute;                            // 통과 가능, 이동 비용 등
};

class TileMap
{
public:
    bool Create(int cols, int rows, int tileW, int tileH);
    void Release();

    Tile* At(int col, int row)
    {
        if (col < 0 || col >= m_cols || row < 0 || row >= m_rows) return nullptr;
        return &m_tiles[row * m_cols + col];    // ★ 1차원 배열로 관리
    }

    int GetCols() const { return m_cols; }
    int GetRows() const { return m_rows; }
    int GetTileW() const { return m_tileW; }
    int GetTileH() const { return m_tileH; }

    int GetPixelWidth()  const { return m_cols * m_tileW; }
    int GetPixelHeight() const { return m_rows * m_tileH; }

private:
    Tile* m_tiles = nullptr;
    int   m_cols = 0, m_rows = 0;
    int   m_tileW = 32, m_tileH = 32;
};
```

```
   ★ 2차원 배열 대신 1차원 배열 + 계산

   Tile m_tiles[rows][cols]      →  크기가 컴파일 시점에 고정
   Tile* m_tiles = new Tile[rows*cols]  →  실행 중 크기 결정  ✔

   접근:  m_tiles[row * cols + col]

   ★ Day 42의 스프라이트 시트 인덱스 계산과 같은 공식
```

### 3-3. 좌표 3종

**왜 필요한가** — 세 좌표계를 섞으면 커서가 어긋난다. **오늘 가장 중요한 개념.**

```
   ┌──────────────────────────────────────────────────────────┐
   │  ① 화면 좌표 (Screen)                                     │
   │     창의 왼쪽 위가 (0,0). 마우스 메시지가 주는 값          │
   │                                                           │
   │  ② 월드 좌표 (World)                                      │
   │     맵 전체의 왼쪽 위가 (0,0). 픽셀 단위                   │
   │                                                           │
   │  ③ 타일 좌표 (Tile)                                       │
   │     맵의 몇 번째 칸인가. 정수                              │
   └──────────────────────────────────────────────────────────┘
```

```
   맵 전체 (월드)  2048 × 1536 픽셀 = 64 × 48 타일

   ┌────────────────────────────────────────────────┐ (0,0) 월드
   │                                                 │
   │        ┌──────────────────┐                     │
   │        │  화면 (보이는 곳) │                     │
   │        │                  │  ← 카메라 (128, 64) │
   │        │      ● 마우스     │                     │
   │        │                  │                     │
   │        └──────────────────┘                     │
   │                                                 │
   └────────────────────────────────────────────────┘

   마우스 화면 좌표  (367, 158)
   카메라           (128,  64)
   마우스 월드 좌표  (367+128, 158+64) = (495, 222)
   타일 좌표        (495/32, 222/32)   = (15, 6)
```

**변환 공식**

```
   화면 → 월드      world = screen + camera
   월드 → 화면      screen = world - camera

   월드 → 타일      tile = floor(world / tileSize)
   타일 → 월드      world = tile * tileSize        (타일의 좌상단)
```

```cpp
// 화면 → 월드
void ScreenToWorld(double sx, double sy, double* wx, double* wy) const
{
    *wx = sx / m_zoom + m_cameraX;
    *wy = sy / m_zoom + m_cameraY;
}

// 월드 → 화면
void WorldToScreen(double wx, double wy, double* sx, double* sy) const
{
    *sx = (wx - m_cameraX) * m_zoom;
    *sy = (wy - m_cameraY) * m_zoom;
}

// 월드 → 타일
void WorldToTile(double wx, double wy, int* col, int* row) const
{
    *col = (int)floor(wx / m_tileW);           // ★ floor
    *row = (int)floor(wy / m_tileH);
}

// 타일 → 월드 (좌상단)
void TileToWorld(int col, int row, double* wx, double* wy) const
{
    *wx = col * (double)m_tileW;
    *wy = row * (double)m_tileH;
}
```

### 3-4. ⚠️ `floor` vs 정수 나눗셈

**왜 필요한가** — 음수 좌표에서 한 칸 어긋난다.

```
   타일 크기 32

   월드 x = -10  →  타일 -1 이어야 한다

   (int)(-10 / 32)     =  (int)(-0.3125)  =  0     ✘  (0 쪽으로 절삭)
   (int)floor(-10/32)  =  (int)(-1.0)     = -1     ✔
```

```
   ★ 정수 나눗셈은 0 쪽으로 자른다

    7 / 32 =  0    ✔
   -7 / 32 =  0    ✘  (-1이어야 한다)

   ★ floor 는 항상 작은 쪽으로

   floor( 7/32.0) =  0    ✔
   floor(-7/32.0) = -1    ✔
```

```cpp
    // 정수 연산으로 floor 효과 내기 (빠르다)
    int FloorDiv(int a, int b)
    {
        return (a >= 0) ? (a / b) : -(((-a) + b - 1) / b);
    }
```

> **맵 밖을 클릭할 때 이 차이가 드러난다.** 반드시 `floor`를 쓴다.

### 3-5. 카메라

**왜 필요한가** — 맵이 화면보다 크면 스크롤이 필요하다.

```cpp
class Camera2D
{
public:
    void SetPosition(double x, double y) { m_x = x; m_y = y; Clamp(); }
    void Move(double dx, double dy)      { m_x += dx; m_y += dy; Clamp(); }

    void SetBounds(double mapW, double mapH, double screenW, double screenH)
    {
        m_mapW = mapW; m_mapH = mapH;
        m_screenW = screenW; m_screenH = screenH;
        Clamp();
    }

    double GetX() const { return m_x; }
    double GetY() const { return m_y; }

private:
    void Clamp()
    {
        double maxX = m_mapW - m_screenW / m_zoom;
        double maxY = m_mapH - m_screenH / m_zoom;

        if (maxX < 0) maxX = 0;
        if (maxY < 0) maxY = 0;

        if (m_x < 0) m_x = 0;
        if (m_y < 0) m_y = 0;
        if (m_x > maxX) m_x = maxX;
        if (m_y > maxY) m_y = maxY;
    }

    double m_x = 0, m_y = 0, m_zoom = 1.0;
    double m_mapW = 0, m_mapH = 0, m_screenW = 0, m_screenH = 0;
};
```

```
   ★ 카메라 클램프

   맵 밖으로 나가면 빈 공간이 보인다
   → 맵 경계 안으로 제한한다

   단, 맵이 화면보다 작으면 클램프 값이 음수가 된다
   → 0으로 보정
```

### 3-6. 줌

**왜 필요한가** — 큰 맵을 한눈에 보거나 세밀하게 편집한다.

```cpp
    void SetZoom(double zoom, double focusScreenX, double focusScreenY)
    {
        if (zoom < 0.25) zoom = 0.25;
        if (zoom > 4.0)  zoom = 4.0;

        // 줌 전 마우스 위치의 월드 좌표
        double wx = focusScreenX / m_zoom + m_x;
        double wy = focusScreenY / m_zoom + m_y;

        m_zoom = zoom;

        // 줌 후에도 같은 월드 좌표가 마우스 아래 오도록 카메라 조정
        m_x = wx - focusScreenX / m_zoom;
        m_y = wy - focusScreenY / m_zoom;

        Clamp();
    }
```

```
   ★ "마우스 위치를 중심으로 줌"

   단순히 zoom 만 바꾸면 화면 왼쪽 위 기준으로 확대된다
   → 보던 곳이 밖으로 나가 버린다

   마우스 아래의 월드 좌표를 고정하면 자연스럽다
   (모든 지도·이미지 편집 도구가 이렇게 한다)
```

### 3-7. 보이는 영역만 그리기

**왜 필요한가** — 64×48 = 3072 타일을 전부 그리면 느리다.

```cpp
void TileMapRenderer::Render(Renderer& r, const TileMap& map, const Camera2D& cam)
{
    double zoom = cam.GetZoom();

    // 화면에 보이는 타일 범위 계산
    int startCol = (int)floor(cam.GetX() / map.GetTileW());
    int startRow = (int)floor(cam.GetY() / map.GetTileH());

    int visCols = (int)ceil(r.GetWidth()  / zoom / map.GetTileW()) + 1;
    int visRows = (int)ceil(r.GetHeight() / zoom / map.GetTileH()) + 1;

    int endCol = startCol + visCols;
    int endRow = startRow + visRows;

    // 범위 클램프
    if (startCol < 0) startCol = 0;
    if (startRow < 0) startRow = 0;
    if (endCol > map.GetCols()) endCol = map.GetCols();
    if (endRow > map.GetRows()) endRow = map.GetRows();

    for (int row = startRow; row < endRow; row++)
    {
        for (int col = startCol; col < endCol; col++)
        {
            const Tile* t = map.At(col, row);
            if (!t || t->tileIndex < 0) continue;

            double wx, wy;
            map.TileToWorld(col, row, &wx, &wy);

            double sx, sy;
            cam.WorldToScreen(wx, wy, &sx, &sy);

            DrawTile(r, t->tileIndex, (int)sx, (int)sy, zoom);
        }
    }
}
```

```
   전체 그리기:   64 × 48 = 3,072 타일
   보이는 것만:   26 × 20 =   520 타일      ← 약 1/6

   ★ +1 을 하는 이유
     화면 경계에 걸친 타일도 그려야 잘리지 않는다
```

### 3-8. 격자 그리기

**왜 필요한가** — 타일 경계가 보여야 편집할 수 있다.

```cpp
void DrawGrid(Renderer& r, const TileMap& map, const Camera2D& cam)
{
    if (!g_showGrid) return;

    double zoom = cam.GetZoom();
    double tw = map.GetTileW() * zoom;
    double th = map.GetTileH() * zoom;

    if (tw < 4.0) return;                      // ★ 너무 작으면 안 그린다

    // 첫 세로선의 화면 x
    double firstX = -fmod(cam.GetX() * zoom, tw);
    double firstY = -fmod(cam.GetY() * zoom, th);

    COLORREF c = RGB(60, 60, 80);

    for (double x = firstX; x < r.GetWidth(); x += tw)
        r.DrawLine((int)x, 0, (int)x, r.GetHeight(), c);

    for (double y = firstY; y < r.GetHeight(); y += th)
        r.DrawLine(0, (int)y, r.GetWidth(), (int)y, c);
}
```

```
   ★ 줌 아웃 시 격자를 안 그린다

   타일이 2픽셀이면 격자선이 화면을 뒤덮는다
   → 4픽셀 미만이면 생략
```

```cpp
bool TileMap::Create(int cols, int rows, int tileW, int tileH)
{
    Release();

    if (cols <= 0 || rows <= 0) return false;
    if (cols > 512 || rows > 512) return false;      // 상한

    m_cols = cols; m_rows = rows;
    m_tileW = tileW; m_tileH = tileH;

    int count = cols * rows;
    m_tiles = new Tile[count];

    for (int i = 0; i < count; i++)
    {
        m_tiles[i].tileIndex = -1;             // 비어 있음
        m_tiles[i].attribute = 0;
    }

    DebugLog("[TileMap] 생성 %dx%d (타일 %dx%d, %.1f KB)\n",
             cols, rows, tileW, tileH, count * sizeof(Tile) / 1024.0);

    return true;
}
```

### Step 3 — 좌표 변환 함수

3-3절의 네 함수를 구현한다.

**검증 테스트를 먼저 만든다.**

```cpp
void TestCoordConversion()
{
    TileMap map;
    map.Create(64, 48, 32, 32);

    Camera2D cam;
    cam.SetPosition(128, 64);

    struct TestCase { double sx, sy; int expCol, expRow; };

    TestCase cases[] = {
        {   0,   0,  4, 2 },                   // (0+128)/32=4, (0+64)/32=2
        { 367, 158, 15, 6 },                   // (367+128)/32=15, (158+64)/32=6
        {  31,  31,  4, 2 },
        {  32,  32,  5, 3 },
    };

    for (auto& c : cases)
    {
        double wx, wy; int col, row;
        cam.ScreenToWorld(c.sx, c.sy, &wx, &wy);
        map.WorldToTile(wx, wy, &col, &row);

        bool ok = (col == c.expCol && row == c.expRow);

                 ok ? "OK  " : "FAIL", c.sx, c.sy, col, row, c.expCol, c.expRow);
    }
}
```

```cpp
void MapToolScene::RenderTiles(Renderer& r)
{
    int startCol, startRow, endCol, endRow;
    CalcVisibleRange(&startCol, &startRow, &endCol, &endRow);

    m_drawnTiles = 0;

    for (int row = startRow; row < endRow; row++)
    {
        for (int col = startCol; col < endCol; col++)
        {
            const Tile* t = m_map.At(col, row);
            if (!t) continue;

            double sx, sy;
            TileToScreen(col, row, &sx, &sy);

            double size = m_map.GetTileW() * m_camera.GetZoom();

            if (t->tileIndex < 0)
            {
                // 빈 타일 (체커보드)
                COLORREF c = ((col + row) % 2 == 0)
                           ? RGB(30, 30, 38) : RGB(36, 36, 44);
                r.DrawRect((int)sx, (int)sy, (int)size, (int)size, c);
            }
            else
            {
                m_tileSet.Draw(r, t->tileIndex, (int)sx, (int)sy, (int)size);
            }

            m_drawnTiles++;
        }
    }
}
```

### Step 12 — 맵 크기 변경

```cpp
void MapToolScene::ResizeMap(int newCols, int newRows)
{
    TileMap newMap;
    if (!newMap.Create(newCols, newRows, m_map.GetTileW(), m_map.GetTileH()))
        return;

    // 기존 내용 복사
    int copyC = min(newCols, m_map.GetCols());
    int copyR = min(newRows, m_map.GetRows());

    for (int r = 0; r < copyR; r++)
        for (int c = 0; c < copyC; c++)
            *newMap.At(c, r) = *m_map.At(c, r);

    m_map = std::move(newMap);                 // 또는 수동 교체

    m_camera.SetBounds(m_map.GetPixelWidth(), m_map.GetPixelHeight(),
                       m_core->GetWidth(), m_core->GetHeight());
}
```

**✅ 여기까지 실행하면** — 맵 크기를 바꿔도 기존 내용이 유지된다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 커서가 어긋남 | 카메라 오프셋 미반영 | `ScreenToWorld` 확인 |
| 스크롤 후 어긋남 | 변환 순서 오류 | 화면 → 월드 → 타일 순서 |
| 줌 후 어긋남 | 줌 나눗셈 누락 | `sx / zoom + camX` |
| 맵 밖에서 한 칸 어긋남 | 정수 나눗셈 | **`floor`** |
| 줌하면 보던 곳이 사라짐 | 마우스 중심 줌 미구현 | 3-6절 |
| 격자가 화면을 뒤덮음 | 줌 아웃 시 미처리 | 타일 크기 < 4px면 생략 |
| 프레임 저하 | 전체 타일 그리기 | 보이는 영역만 |
| 화면 경계 타일이 잘림 | 범위 +1 누락 | `visCols + 1` |
| 카메라가 맵 밖으로 | 클램프 누락 | `SetBounds` + `Clamp` |
| 휠 좌표가 이상함 | 화면 좌표로 옴 | `ScreenToClient` 변환 |

|---|---|
| 툴/게임 분리 | 공유하는 것은 **파일 포맷**뿐 |
