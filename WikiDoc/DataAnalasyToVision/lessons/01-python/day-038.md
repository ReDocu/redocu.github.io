## ② 왜 필요한가

어제 만든 게임을 3분 해 보면 이런 느낌입니다.

> "적이 계속 똑같이 내려온다. 5분 하면 지루하다."

**게임이 재미있어지는 요소는 '변화'입니다.**

| 없을 때 | 있을 때 |
|---|---|
| 적이 한 종류 | 적마다 다른 대응이 필요 |
| 난이도가 일정 | 갈수록 긴장감이 오름 |
| 목표가 없음 | 보스를 잡으면 클리어 |
| 맞아도 밋밋 | 터지고 흔들려서 타격감 |

오늘은 **Should 8개**를 구현합니다. 다만 시간이 부족하면 **우선순위 순으로** 진행합니다.

```
S1 적 3종류 → S2 스테이지 → S5 파티클 → S6 흔들림
→ S4 아이템 → S7 콤보 → S8 일시정지 → S3 보스
```

## ③ 개념 설명

### 적 종류 설계 — 서로 다른 대응을 요구할 것

**나쁜 설계** — 숫자만 다름

```
기본:  HP 1, 속도 2, 점수 10
적2:   HP 2, 속도 3, 점수 20      ← 그냥 조금 센 적
적3:   HP 3, 속도 4, 점수 30
```

**좋은 설계** — 플레이 방식이 달라짐

| 적 | 특성 | 플레이어의 대응 |
|---|---|---|
| 기본 | 직진, 약함 | 무시하고 지나가도 됨 |
| 고속 | 매우 빠름, 약함 | **먼저 처리**해야 함 |
| 탱커 | 느림, HP 5 | 계속 쏘거나 **피해야** 함 |
| 지그재그 | 좌우 왕복 | **예측 사격** 필요 |
| 추적 | 플레이어를 따라옴 | **계속 움직여야** 함 |

> **"이 적이 있으면 플레이어가 무엇을 다르게 해야 하나?"** 를 물어보세요.
> 답이 없으면 그 적은 필요 없습니다.

### 난이도 곡선

```
난이도
  │                                    ╱ 보스
  │                              ╱────
  │                       ╱─────
  │                ╱─────
  │         ╱─────
  │  ╱─────
  └──────────────────────────────────────► 시간
     1     2     3     4     5 스테이지
```

**조절할 수 있는 축 4가지**

| 축 | 조절 방법 | 주의 |
|---|---|---|
| 빈도 | 스폰 간격 단축 | 너무 빠르면 화면이 가득 참 |
| 속도 | 적 속도 배율 | 너무 빠르면 반응 불가 |
| 종류 | 강한 적 비중 증가 | 갑자기 바뀌면 당황 |
| 체력 | 적 HP 증가 | 총알만 많이 쏘게 됨 (지루) |

> **여러 축을 조금씩** 올리는 것이 부드러운 곡선을 만듭니다. ([Day 023](day-023.md))

### 보스 패턴 설계

보스는 **일반 적을 여러 마리 놓은 것과 달라야** 합니다.

```python
class Boss(Enemy):
    HP = 100
    PATTERNS = ["직선탄", "확산탄", "돌진"]

    def update(self):
        self.pattern_timer += 1

        # 5초마다 패턴 변경
        if self.pattern_timer >= 300:
            self.pattern_timer = 0
            self.pattern_index = (self.pattern_index + 1) % len(self.PATTERNS)

        # HP 가 절반 이하면 2단계 (더 빠르게)
        if self.hp < self.max_hp * 0.5:
            self.phase = 2
```

**보스 설계 원칙 3가지**

| 원칙 | 이유 |
|---|---|
| **패턴이 반복된다** | 플레이어가 학습해 대응할 수 있어야 함 |
| **패턴 사이에 틈이 있다** | 공격할 기회를 줘야 함 |
| **HP 바가 보인다** | 진행 상황을 알아야 포기하지 않음 |

```python
"""적 — 종류별 특성을 클래스 변수로 정의합니다."""

import math
import random

import pygame

from .base import Entity
from ..surfaces import make_enemy
from ..settings import (SCREEN_WIDTH, ENEMY_SIZE, ENEMY_SPEED, ENEMY_HP,
                        ENEMY_SCORE, COLOR_ENEMY, COLOR_HP, COLOR_GRAY)


class Enemy(Entity):
    """적의 부모 클래스."""

    HP = ENEMY_HP
    SPEED = ENEMY_SPEED
    SCORE = ENEMY_SCORE
    SIZE = ENEMY_SIZE
    COLOR = COLOR_ENEMY
    NAME = "기본"

    def __init__(self, x, y, speed_scale=1.0):
        super().__init__(x, y, make_enemy(self.SIZE, self.COLOR))
        self.hp = self.HP
        self.max_hp = self.HP
        self.radius = self.SIZE // 2
        self.speed = self.SPEED * speed_scale

    def move(self):
        self.pos_y += self.speed

    def update(self):
        self.move()
        self.sync_rect()
        self.kill_if_out()

    def take_damage(self, amount):
        self.hp -= amount
        if self.hp > 0:
            return False
        self.kill()
        return True

    def draw_hp_bar(self, surface):
        if self.max_hp <= 1:
            return
        w = self.rect.width
        x, y = self.rect.left, self.rect.top - 8
        pygame.draw.rect(surface, COLOR_GRAY, (x, y, w, 5))
        pygame.draw.rect(surface, COLOR_HP,
                         (x, y, int(w * self.hp / self.max_hp), 5))

    @classmethod
    def spawn(cls, speed_scale=1.0):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE, speed_scale)


class FastEnemy(Enemy):
    """빠르지만 약함 — 먼저 처리해야 함."""
    HP = 1
    SPEED = 5.5
    SCORE = 25
    SIZE = 28
    COLOR = (241, 196, 15)
    NAME = "고속"


class TankEnemy(Enemy):
    """느리고 튼튼함 — 계속 쏘거나 피해야 함."""
    HP = 5
    SPEED = 1.0
    SCORE = 60
    SIZE = 54
    COLOR = (155, 89, 182)
    NAME = "탱커"


class ZigzagEnemy(Enemy):
    """좌우로 왕복 — 예측 사격이 필요함."""
    HP = 2
    SPEED = 2.2
    SCORE = 40
    SIZE = 38
    COLOR = (46, 204, 113)
    NAME = "지그재그"

    def __init__(self, x, y, speed_scale=1.0):
        super().__init__(x, y, speed_scale)
        self.vel_x = random.choice([-3.5, 3.5])

    def move(self):
        self.pos_y += self.speed
        self.pos_x += self.vel_x

        half = self.SIZE / 2
        if self.pos_x <= half:
            self.pos_x, self.vel_x = half, abs(self.vel_x)
        elif self.pos_x >= SCREEN_WIDTH - half:
            self.pos_x, self.vel_x = SCREEN_WIDTH - half, -abs(self.vel_x)


# ── 스테이지별 등장 확률 ──
ENEMY_TYPES = [Enemy, FastEnemy, ZigzagEnemy, TankEnemy]

STAGE_WEIGHTS = {
    1: [70, 20, 10,  0],
    2: [55, 25, 15,  5],
    3: [40, 25, 20, 15],
    4: [30, 25, 25, 20],
    5: [20, 25, 30, 25],
}


def pick_enemy_class(stage):
    """스테이지에 맞는 적 종류를 무작위로 고릅니다."""
    weights = STAGE_WEIGHTS.get(min(stage, 5), STAGE_WEIGHTS[5])
    return random.choices(ENEMY_TYPES, weights=weights, k=1)[0]
```

```python
"""스테이지 진행과 난이도 관리."""

from .settings import FPS

STAGE_DURATION = 30 * FPS          # 30초
MAX_STAGE = 5

BASE_SPAWN_INTERVAL = 60
MIN_SPAWN_INTERVAL = 22


class StageManager:
    """스테이지 진행과 난이도를 관리합니다."""

    def __init__(self):
        self.stage = 1
        self.frames = 0
        self.cleared = False

    def update(self):
        """프레임을 진행합니다. 스테이지가 오르면 True."""
        if self.cleared:
            return False

        self.frames += 1

        if self.frames < STAGE_DURATION:
            return False

        self.frames = 0

        if self.stage >= MAX_STAGE:
            self.cleared = True
            return False

        self.stage += 1
        return True

    @property
    def spawn_interval(self):
        """스테이지가 오를수록 짧아집니다."""
        return max(BASE_SPAWN_INTERVAL - (self.stage - 1) * 9,
                   MIN_SPAWN_INTERVAL)

    @property
    def speed_scale(self):
        """스테이지당 8% 씩 빨라집니다."""
        return 1.0 + (self.stage - 1) * 0.08

    @property
    def progress(self):
        """현재 스테이지 진행률 (0.0 ~ 1.0)."""
        return min(self.frames / STAGE_DURATION, 1.0)

    @property
    def is_boss_stage(self):
        return self.stage >= MAX_STAGE
```

```python
"""파티클 이펙트."""

import math
import random

import pygame

from ..settings import MAX_PARTICLES


class Particle(pygame.sprite.Sprite):
    """수명이 있는 작은 조각."""

    def __init__(self, x, y, color, speed=5.0, life=35, size=6, gravity=0.12):
        super().__init__()
        angle = random.uniform(0, math.tau)
        spd = random.uniform(speed * 0.3, speed)

        self.vel_x = math.cos(angle) * spd
        self.vel_y = math.sin(angle) * spd
        self.pos_x, self.pos_y = float(x), float(y)

        self.life = life
        self.max_life = life
        self.base_size = size
        self.color = color
        self.gravity = gravity

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        self.rect = self.image.get_rect(center=(x, y))
        self._redraw()

    def _redraw(self):
        ratio = max(self.life / self.max_life, 0)
        size = max(int(self.base_size * ratio), 1)
        alpha = int(255 * ratio)

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (*self.color, alpha), (size, size), size)
        self.rect = self.image.get_rect(center=self.rect.center)

    def update(self):
        self.life -= 1
        if self.life <= 0:
            self.kill()
            return

        self.vel_y += self.gravity
        self.vel_x *= 0.98
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self._redraw()


def make_explosion(x, y, group, color=(231, 76, 60), count=20, power=6.0):
    """폭발 파티클을 만듭니다. 개수 상한을 지킵니다."""
    made = 0
    for _ in range(count):
        if len(group) >= MAX_PARTICLES:
            break
        group.add(Particle(x, y, color, speed=power,
                           life=random.randint(25, 45),
                           size=random.randint(4, 9)))
        made += 1
    return made
```

```python
"""화면 흔들림."""

import random


class ScreenShake:
    """흔들림 강도와 지속 시간을 관리합니다."""

    def __init__(self):
        self.timer = 0
        self.power = 0

    def shake(self, power=8, duration=12):
        """더 강한 흔들림이 요청되면 덮어씁니다."""
        if power >= self.power:
            self.power = power
            self.timer = duration

    def update(self):
        if self.timer > 0:
            self.timer -= 1
        else:
            self.power = 0

    @property
    def offset(self):
        if self.timer <= 0:
            return 0, 0
        return (random.randint(-self.power, self.power),
                random.randint(-self.power, self.power))
```

### Step 3. 보스와 아이템 (오늘의 종합 예제)

**`game/entities/boss.py`**

```python
"""보스 — 패턴 공격을 하는 대형 적."""

import math

import pygame

from .enemy import Enemy
from .bullet import Bullet
from ..surfaces import make_spike
from ..settings import SCREEN_WIDTH, COLOR_GRAY, COLOR_ENEMY, COLOR_TEXT


class EnemyBullet(Bullet):
    """아래로 날아가는 적 총알."""

    SPEED = 5.0
    DAMAGE = 1

    def __init__(self, x, y, vel_x=0.0):
        super().__init__(x, y, vel_x)
        self.vel_y = abs(self.SPEED)          # 아래로
        self.image = pygame.Surface((10, 10), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (255, 120, 80), (5, 5), 5)
        self.rect = self.image.get_rect(center=(x, y))


class Boss(Enemy):
    """5스테이지 보스."""

    HP = 120
    SPEED = 0.0
    SCORE = 2000
    SIZE = 130
    COLOR = (192, 57, 43)
    NAME = "보스"

    PATTERN_DURATION = 240        # 4초마다 패턴 변경
    ENTRY_Y = 130                 # 등장 후 머무는 높이

    def __init__(self, x, y):
        super().__init__(x, y)
        self.image = make_spike(self.SIZE, self.COLOR)
        self.rect = self.image.get_rect(center=(x, y))

        self.pattern = 0
        self.pattern_timer = 0
        self.shoot_timer = 0
        self.move_dir = 1
        self.entering = True
        self.phase = 1

    # ── 이동 ──
    def move(self):
        if self.entering:
            self.pos_y += 2.0
            if self.pos_y >= Boss.ENTRY_Y:
                self.pos_y = Boss.ENTRY_Y
                self.entering = False
            return

        # 좌우 왕복
        speed = 1.5 if self.phase == 1 else 2.8
        self.pos_x += self.move_dir * speed

        half = self.SIZE / 2
        if self.pos_x <= half:
            self.pos_x, self.move_dir = half, 1
        elif self.pos_x >= SCREEN_WIDTH - half:
            self.pos_x, self.move_dir = SCREEN_WIDTH - half, -1

    # ── 공격 패턴 ──
    def attack(self):
        """이번 프레임에 발사할 총알 리스트를 반환합니다."""
        if self.entering:
            return []

        self.shoot_timer -= 1
        if self.shoot_timer > 0:
            return []

        cx, bottom = self.rect.centerx, self.rect.bottom

        if self.pattern == 0:                     # 직선 3발
            self.shoot_timer = 40 if self.phase == 1 else 25
            return [EnemyBullet(cx + dx, bottom) for dx in (-40, 0, 40)]

        if self.pattern == 1:                     # 확산 5발
            self.shoot_timer = 55 if self.phase == 1 else 35
            return [EnemyBullet(cx, bottom, vel_x=offset * 1.8)
                    for offset in range(-2, 3)]

        # 패턴 2 — 원형 8발
        self.shoot_timer = 75 if self.phase == 1 else 50
        bullets = []
        for i in range(8):
            angle = math.tau * i / 8
            b = EnemyBullet(cx, self.rect.centery)
            b.vel_x = math.cos(angle) * 3.5
            b.vel_y = abs(math.sin(angle) * 3.5) + 1.0     # 아래로만
            bullets.append(b)
        return bullets

    def update(self):
        self.move()
        self.sync_rect()

        # 패턴 전환
        self.pattern_timer += 1
        if self.pattern_timer >= Boss.PATTERN_DURATION:
            self.pattern_timer = 0
            self.pattern = (self.pattern + 1) % 3

        # 2단계 진입 (HP 절반)
```
