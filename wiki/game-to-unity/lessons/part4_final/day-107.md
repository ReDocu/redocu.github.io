## 3. 개념

### 3-1. 서브 시스템의 유형

**왜 필요한가** — GDD에서 정한 것을 확인한다.

| 유형 | 예 | 핵심 루프와의 연결 |
|---|---|---|
| **성장** | 레벨, 스탯 | 처치 → 성장 → 더 잘 처치 |
| **자원** | 골드, 마나 | 처치 → 자원 → 강화 |
| **선택** | 무기, 능력 | 클리어 → 선택 → 다른 플레이 |
| **인벤토리** | 아이템 | 획득 → 관리 → 사용 |
| **스킬** | 액티브/패시브 | 조합 → 전략 |
| **건설** | 타워, 기지 | 자원 → 건설 → 방어 |

```
   ★ 우리 게임의 서브 시스템

   GDD: "무기를 버려야 다음 층으로"
   → 선택 시스템  ★
```

```
   ★ 한 개만 만든다

   4주에 서브 시스템 2개 이상은 위험
   → 하나를 깊게
```

### 3-2. 루프 연결 검증

**왜 필요한가** — 겉도는지 판단한다.

```
   ★ 검증 질문 5개

   ① 이 시스템을 거치지 않고 클리어할 수 있나?
      → 있다면 겉돈다

   ② 플레이어가 매 루프마다 이것을 생각하나?
      → 아니면 깊이가 없다

   ③ 선택에 트레이드오프가 있나?
      → 없으면 최적해 하나만 쓰인다

   ④ 이 시스템 때문에 플레이가 달라지나?
      → 아니면 장식이다

   ⑤ 한 문장으로 재미를 설명할 수 있나?
      → 못 하면 제외한다
```

```
   ★ 우리 게임의 답

   ① 무기 없이는 공격 불가 → 필수
   ② 층마다 선택 → 매 루프
   ③ 데미지 vs 속도 vs 사거리 → 트레이드오프
   ④ 근접/원거리로 플레이가 완전히 달라짐
   ⑤ "지금 무기를 버릴 만큼 저게 좋은가?"의 갈등  ★

   → 통과
```

### 3-3. 트레이드오프 설계

**왜 필요한가** — 선택이 의미를 가지려면.

```
   ⚠️ 나쁜 선택지

   무기 A: 데미지 10
   무기 B: 데미지 15
   무기 C: 데미지 20

   → 항상 C. 선택이 아니다
```

```
   ★ 좋은 선택지

   무기 A: 데미지 12, 속도 0.35  → DPS 34, 근접, 안전
   무기 B: 데미지 28, 속도 1.00  → DPS 28, 느림, 광역
   무기 C: 데미지  9, 속도 0.30  → DPS 30, 원거리, 약함

   → 상황에 따라 다르다
```

```
   ★ 트레이드오프 축

   ① 데미지 ↔ 속도
   ② 사거리 ↔ 위력
   ③ 안정성 ↔ 폭발력
   ④ 즉시 효과 ↔ 지속 효과
   ⑤ 자기 강화 ↔ 적 약화
```

```
   ★ DPS를 비슷하게 맞춘다

   DPS 30 근처로 통일
   → 차이는 "사용감"에서 나온다
   → 밸런싱이 쉬워진다
```

### 3-4. 무기 데이터

**왜 필요한가** — Day 78의 패턴.

namespace OneFloor.Data
{
    public enum WeaponType { Melee, Ranged, Heavy }

    [CreateAssetMenu(fileName = "Weapon_", menuName = "OneFloor/Weapon Data")]
    public class WeaponData : ScriptableObject
    {
        [Header("기본")]
        public string id;
        public string displayName;
        public Sprite icon;
        public GameObject modelPrefab;
        public WeaponType type = WeaponType.Melee;

        [Header("전투")]
        public int damage = 15;
        public float attackInterval = 0.5f;

        [Header("판정")]
        public Vector3 hitboxOffset = new Vector3(0, 1f, 1.2f);
        public Vector3 hitboxSize = new Vector3(1.6f, 1.5f, 2f);
        public float startupTime = 0.12f;
        public float activeTime = 0.10f;
        public float recoveryTime = 0.16f;

        [Header("원거리")]
        public bool isRanged;
        public string projectilePoolKey;
        public float projectileSpeed = 20f;
        public float range = 15f;

        [Header("이동")]
        [Range(0f, 1f)] public float attackMoveMultiplier = 0.3f;

        [Header("설명")]
        [TextArea(2, 4)] public string description;

        // ─── 계산 ───

        public float Dps => damage / Mathf.Max(attackInterval, 0.01f);
        public float TotalActionTime => startupTime + activeTime + recoveryTime;

        public string TypeLabel => type switch
        {
            WeaponType.Melee  => "근접",
            WeaponType.Ranged => "원거리",
            WeaponType.Heavy  => "광역",
            _ => ""
        };

        private void OnValidate()
        {
            if (string.IsNullOrEmpty(id)) id = name.Replace("Weapon_", "").ToLower();

            // ★ 공격 간격은 액션 시간보다 짧을 수 없다
            if (attackInterval < TotalActionTime)
                attackInterval = TotalActionTime;
        }
    }
}

### 3-5. 무기 장착 시스템

**왜 필요한가** — 데이터를 실제 동작으로.

```csharp
namespace OneFloor.Combat
{
    public class WeaponHolder : MonoBehaviour
    {
        [SerializeField] private Transform weaponSocket;
        [SerializeField] private Hitbox hitbox;

        private WeaponData current;
        private GameObject currentModel;

        public WeaponData Current => current;
        public bool HasWeapon => current != null;

        public event System.Action<WeaponData, WeaponData> OnWeaponChanged;

        public void Equip(WeaponData data)
        {
            WeaponData prev = current;
            current = data;

            // ★ 모델 교체
            if (currentModel != null) Destroy(currentModel);

            if (data != null && data.modelPrefab != null)
            {
                currentModel = Instantiate(data.modelPrefab, weaponSocket);
                currentModel.transform.localPosition = Vector3.zero;
                currentModel.transform.localRotation = Quaternion.identity;
            }

            // ★ 히트박스 설정
            if (data != null)
                hitbox.Configure(data.hitboxOffset, data.hitboxSize,
                                 data.damage, data.type);

            OnWeaponChanged?.Invoke(prev, current);

            DebugUtil.Log($"[무기] {prev?.displayName ?? "없음"} → " +
                          $"{data?.displayName ?? "없음"}");
        }

        public void Unequip() => Equip(null);
    }
}
```

    // PlayerCombat 수정
    private IEnumerator AttackRoutine()
    {
        WeaponData w = weaponHolder.Current;
        if (w == null) yield break;

        IsAttacking = true;

        yield return new WaitForSeconds(w.startupTime);

        if (w.isRanged) FireProjectile(w);
        else            { hitbox.Activate(); }

        yield return new WaitForSeconds(w.activeTime);

        if (!w.isRanged) hitbox.Deactivate();

        yield return new WaitForSeconds(w.recoveryTime);

        IsAttacking = false;

        // ★ 공격 간격 (액션 시간을 뺀 나머지)
        float remaining = w.attackInterval - w.TotalActionTime;
        if (remaining > 0) yield return new WaitForSeconds(remaining);

        canAttack = true;
    }

```csharp
namespace OneFloor.Combat
{
    public class Projectile : MonoBehaviour, IPoolable
    {
        [SerializeField] private LayerMask targetLayer;
        [SerializeField] private LayerMask obstacleLayer;
        [SerializeField] private TrailRenderer trail;

        private Vector3 direction;
        private float speed;
        private int damage;
        private float remainingRange;

        private PooledObject pooled;

        private void Awake() { pooled = GetComponent<PooledObject>(); }

        public void Launch(Vector3 dir, float spd, int dmg, float range)
        {
            direction = dir.normalized;
            speed = spd;
            damage = dmg;
            remainingRange = range;
        }

        public void Tick(float dt)
        {
            float step = speed * dt;

            // ★ 이동 분할로 터널링 방지 (Day 67·73)
            if (Physics.SphereCast(transform.position, 0.15f, direction,
                                   out RaycastHit hit, step,
                                   targetLayer | obstacleLayer))
            {
                Impact(hit);
                return;
            }

            transform.position += direction * step;
            remainingRange -= step;

            if (remainingRange <= 0) Despawn();
        }

        private void Impact(RaycastHit hit)
        {
            IDamageable target = hit.collider.GetComponentInParent<IDamageable>();

            if (target != null && target.IsAlive)
            {
                target.TakeDamage(new DamageInfo
                {
                    amount = damage,
                    knockback = 2f,
                    direction = direction,
                    hitPoint = hit.point,
                });
            }

            PoolManager.Instance.Get("hit_effect", hit.point,
                                     Quaternion.LookRotation(-direction));

            Despawn();
        }

        private void Despawn()
        {
            trail?.Clear();                    // ★ Day 88
            pooled.ReturnToPool();
        }

        public void OnSpawn() { trail?.Clear(); }
        public void OnDespawn() { }
    }
}
```

```
   ★ SphereCast를 쓰는 이유

   Raycast는 얇아서 놓칠 수 있다
   → 반경을 주면 확실하다
```

### 3-8. 선택 UI

```csharp
namespace OneFloor.UI
{
    public class WeaponChoiceUI : MonoBehaviour
    {
        [SerializeField] private GameObject panel;
        [SerializeField] private WeaponCardUI[] cards;
        [SerializeField] private WeaponCardUI currentCard;
        [SerializeField] private TextMeshProUGUI titleText;

        private WeaponData[] choices;
        private System.Action<WeaponData> onSelected;

        private void Start()
        {
            for (int i = 0; i < cards.Length; i++)
            {
                int index = i;
                cards[i].Button.onClick.AddListener(() => Select(index));
            }

            panel.SetActive(false);
        }

        public void Show(WeaponData[] options, WeaponData current,
                         System.Action<WeaponData> callback)
        {
            choices = options;
            onSelected = callback;

            titleText.text = current != null
                ? "무기를 선택하세요 (현재 무기는 버려집니다)"
                : "무기를 선택하세요";

            for (int i = 0; i < cards.Length; i++)
            {
                bool active = i < options.Length;
                cards[i].gameObject.SetActive(active);

                if (active) cards[i].Setup(options[i]);
            }

            currentCard.gameObject.SetActive(current != null);
            if (current != null) currentCard.Setup(current);

            panel.SetActive(true);

            // ★ 선택 중에는 시간 정지
            Time.timeScale = 0f;
        }

        private void Select(int index)
        {
            if (choices == null || index >= choices.Length) return;

            WeaponData selected = choices[index];

            panel.SetActive(false);
            Time.timeScale = 1f;

            onSelected?.Invoke(selected);
            onSelected = null;
        }
    }
}
```

### 3-9. 선택 후보 생성

**왜 필요한가** — 매번 다른 선택지.

```csharp
    private WeaponData[] GenerateChoices(int count)
    {
        List<WeaponData> pool = new List<WeaponData>(database.weapons);

        // ★ 현재 무기는 제외
        if (weaponHolder.Current != null) pool.Remove(weaponHolder.Current);

        // ★ Fisher-Yates 셔플 (Day 78)
        for (int i = pool.Count - 1; i > 0; i--)
        {
            int j = Random.Range(0, i + 1);
            (pool[i], pool[j]) = (pool[j], pool[i]);
        }

        int take = Mathf.Min(count, pool.Count);
        return pool.GetRange(0, take).ToArray();
    }
```

```
   ★ 현재 무기를 제외하는 이유

   "지금 든 것과 같은 것"이 나오면
   선택의 의미가 없다
```

```
   ★ 가중 랜덤 (선택)

   희귀 무기는 낮은 확률로
   → 후반 층에서 확률 증가
```

```csharp
    private WeaponData PickWeighted(List<WeaponData> pool, int floor)
    {
        float total = 0;
        foreach (WeaponData w in pool) total += GetWeight(w, floor);

        float r = Random.value * total;

        foreach (WeaponData w in pool)
        {
            r -= GetWeight(w, floor);
            if (r <= 0) return w;
        }

        return pool[pool.Count - 1];
    }
```

    // GameManager
    public int Gold { get; private set; }

    public event System.Action<int> OnGoldChanged;

    public void AddGold(int amount)
    {
        if (amount <= 0) return;

        Gold += amount;
        OnGoldChanged?.Invoke(Gold);
    }

    public bool TrySpendGold(int amount)
    {
        if (Gold < amount) return false;

        Gold -= amount;
        OnGoldChanged?.Invoke(Gold);
        return true;
    }

    private IEnumerator FloorClearRoutine(FloorData floor)
    {
        yield return new WaitForSeconds(0.8f);

        // ★ 마지막 층이면 바로 종료
        if (floorManager.CurrentFloorIndex + 1 >= database.FloorCount)
        {
            EndGame(true);
            yield break;

        {

            selected = true;
        });

        while (!selected) yield return null;    // ★ 선택 대기

        yield return new WaitForSecondsRealtime(0.3f);

        floorManager.StartFloor(floorManager.CurrentFloorIndex + 1);
    }

    private IEnumerator ShakeRoutine(RectTransform target)
    {
        Vector2 origin = target.anchoredPosition;
        float t = 0;

        while (t < 0.25f)
        {
            t += Time.unscaledDeltaTime;       // ★ timeScale 0
            float decay = 1f - (t / 0.25f);
            target.anchoredPosition = origin +
                new Vector2(Mathf.Sin(t * 60f) * 10f * decay, 0);
            yield return null;
        }

        target.anchoredPosition = origin;
    }
