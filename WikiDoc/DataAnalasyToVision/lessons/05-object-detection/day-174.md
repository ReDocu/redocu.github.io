### 사이트맵 — 화면 사이의 이동

화면 목록을 정했으면 **어떻게 오가는지**를 그립니다.
실제 흐름도는 ④ Step 1 에서 그대로 문서로 만듭니다.

**★ 화면 사이의 이동 규칙 3가지**

```
① 모든 화면에서 홈(라이브)으로 1클릭에 갈 수 있다
   → base.html 의 브랜드 로고

② 목록 → 상세 → 목록 이 끊기지 않는다
   → 상세 페이지 맨 위에 "← 목록으로" (★ 필터 유지)

③ ★ 어디서든 최대 2클릭이면 원하는 화면
   → 네비게이션 4개 고정
```

> ⚠️ **상세 페이지에서 "← 목록으로"를 누르면 필터가 풀리는 것**이 가장 흔한 UX 사고입니다.
> `/events?type=no_helmet&page=3` 에서 상세로 들어갔다가 돌아왔더니 `/events` 1페이지…
> **쿼리스트링을 상세 페이지까지 들고 가야 합니다.**

**필터 4종**

|---|---|---|

```
★ 필터 조건을 만드는 코드는 ★ 한 곳에만 있어야 합니다.

   목록      SELECT * FROM events WHERE <조건> ORDER BY ts DESC LIMIT ?
   총 건수   SELECT COUNT(*) FROM events WHERE <조건>
```

**페이지네이션 — OFFSET vs 키셋**

| 방식 | SQL | 장점 | 단점 |
|---|---|---|---|
| **OFFSET** | `LIMIT 20 OFFSET 380` | 페이지 번호 가능 | 뒤로 갈수록 느림 |
| 키셋(커서) | `WHERE ts < ? LIMIT 20` | 항상 빠름 | 페이지 번호 불가 |

```
20,000건에서 마지막 페이지
   OFFSET 19980  →  ★ 앞의 19,980행을 세고 버림 → 96ms
   키셋          →  인덱스 진입 → 2ms

우리 선택: OFFSET — 시연 데이터는 수백~수천 건이고, 심사위원은
"1 2 3 … 마지막" 페이지 번호를 보고 싶어 합니다.
(인덱스가 있으면 5,000건까지는 10ms 안쪽입니다)
```

> ⚠️ **`page` 파라미터를 검증하지 않으면 사고가 납니다.**
> `?page=-1` → `OFFSET -20` → SQLite 오류(500)
> `?page=99999999` → 빈 목록인데 "0건" 메시지가 없으면 **화면이 텅 빈 채로 끝납니다.**
> `page = max(1, min(page, total_pages))` 로 **가둬 두세요.**

### 실시간 갱신 — 폴링 vs SSE

```
문제
  파이가 새 이벤트를 보냈는데
  ★ 브라우저는 모릅니다. 새로고침해야 보입니다.

  발표 중 "F5 한 번 누를게요" → ★ 감점
```

| | **폴링** | **SSE** | WebSocket |
|---|---|---|---|
| 구현량 | **15줄** | 40줄 | 100줄+ (라이브러리) |
| 서버 부하 | 3초마다 요청 | 연결 유지 | 연결 유지 |
| 지연 | 0~3초 | 즉시 | 즉시 |
| 개발 서버 | 문제 없음 | 스레드 점유 | 별도 서버 필요 |
| 프록시·방화벽 | 통과 | 가끔 막힘 | 자주 막힘 |
| 끊겼을 때 | 다음 요청이 알아서 복구 | 재연결 로직 필요 | 재연결 로직 필요 |
| 우아함 | 낮음 | 높음 | 높음 |
| **6일 남았을 때** | **선택** | 여유 있으면 | ✗ |

```
★ 우리 선택: 폴링 3초

  · 이벤트는 분당 1~2건입니다. 3초 지연은 아무도 모릅니다.
  · MJPEG 스트림이 이미 연결을 하나 잡고 있습니다.
    여기에 SSE 를 더하면 ★ 개발 서버 스레드가 부족해집니다.
  · 폴링은 ★ 실패해도 다음 번에 복구됩니다.
```

**폴링을 제대로 만드는 4가지**

- ① **탭이 숨겨져 있으면 쉰다** — `if (document.hidden) return;` (배터리 · 서버 부하)
- ② **실패하면 간격을 늘린다** — `interval = Math.min(interval * 2, 30000)` (폭주 방지)
- ③ **성공하면 원래대로** — `interval = BASE_INTERVAL`
- ④ **마지막으로 본 ID 이후만 다시 그린다** — 전체 재조회 ✗

구현은 ④ Step 4 의 `live.js` 에 ★ ①②③④ 로 표시해 두었습니다.

> ⚠️ **`setInterval` 로 폴링하면 응답이 늦을 때 요청이 쌓입니다.**
> 3초 간격인데 응답이 5초 걸리면 요청이 **계속 겹칩니다.**
> **`setTimeout` 재귀**로 "응답을 받은 뒤 3초"가 되게 하세요.

### 성능 — 이벤트가 수천 건일 때

```
시연 전날 밤, 파이를 켜 두고 잤습니다.
아침에 접속했더니
   /events   ★ 8.4초
   /stats    ★ 12초
   목록 이미지가 ★ 하나씩 뜸
```

**원인 3가지와 대응**

| 원인 | 증상 | 대응 | 효과 |
|---|---|---|---|
| 인덱스 없음 | 정렬·필터가 전체 스캔 | 인덱스 5개 | 310ms → 4ms |
| 전체 조회 | `SELECT *` 후 파이썬에서 자름 | `LIMIT`/`OFFSET` | 1.8s → 6ms |
| 원본 이미지 | 목록에 1920×1080 JPEG 20장 | 썸네일 320px | 8.4MB → 240KB |

```
썸네일 계산

   원본   1920×1080 JPEG q92   →  평균 420KB
   목록 20장                    →  ★ 8.4MB
   교내 Wi-Fi 20Mbps            →  ★ 3.4초

   썸네일 320×180 JPEG q80      →  평균 12KB
   목록 20장                    →  ★ 240KB  →  0.1초
```

썸네일은 **이벤트를 받는 순간에** 만듭니다. 나중에 만들려면 원본 수천 장을 다시
돌려야 하고, 발표 전날에는 그럴 시간이 없습니다. 구현은 ④ Step 4 의 `make_thumb()` 입니다.

```python
def normalize_ts(raw) -> str:
    """★ 어떤 형식이 와도 'YYYY-MM-DDTHH:MM:SS' 로컬시각으로 통일

    파이가 '+09:00' 이나 'Z' 를 붙여 보내면 SQLite 의
    strftime('%H', ts) 가 ★ NULL 을 돌려줍니다 → 통계가 전부 0.
    """
    if raw is None:
        return datetime.now().strftime(TS_FMT)
    if isinstance(raw, (int, float)):
        return datetime.fromtimestamp(raw).strftime(TS_FMT)
    s = str(raw).strip().replace(" ", "T")
    if s.endswith("Z"):
        s = s[:-1] + "+00:00"
    try:
        dt = datetime.fromisoformat(s)
    except ValueError:
        return datetime.now().strftime(TS_FMT)
    if dt.tzinfo is not None:
        dt = dt.astimezone().replace(tzinfo=None)   # ★ 로컬로 바꾼 뒤 tz 제거
    return dt.strftime(TS_FMT)
```

```python
        conn.row_factory = sqlite3.Row
        conn.execute("PRAGMA journal_mode=WAL")     # 읽기·쓰기 동시

    conn = g.pop("db", None)

        conn.close()


def migrate(db_path: str) -> list:
    """★ user_version 기준으로 아직 적용 안 된 .sql 만 실행"""
    Path(db_path).parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(db_path)
    applied = []
    try:
        version = conn.execute("PRAGMA user_version").fetchone()[0]
        for path in sorted(MIGRATIONS_DIR.glob("*.sql")):
            try:
                num = int(path.name.split("_", 1)[0])
            except ValueError:
                continue
            if num <= version:
                continue
            conn.executescript(path.read_text(encoding="utf-8"))
            conn.execute(f"PRAGMA user_version = {num}")
            conn.commit()
            applied.append(path.name)
        return applied
    except sqlite3.Error:
        conn.rollback()
        logger.exception("★ 마이그레이션 실패 — 백업본으로 되돌리세요")
        raise
    finally:
        conn.close()


def device_status(last_seen, online_sec=30, stale_sec=300) -> str:
    """★ 저장하지 않고 읽을 때 계산 — 갱신을 잊을 수 없습니다"""
    if not last_seen:
        return "unknown"
    try:
        gap = (datetime.now() - datetime.fromisoformat(last_seen)).total_seconds()
    except ValueError:
        return "unknown"
    return "online" if gap <= online_sec else (
        "stale" if gap <= stale_sec else "offline")
```

```python
"""web/stream_proxy.py — 파이 MJPEG 를 1개 당겨 N명에게 뿌린다"""
import logging
import threading
import time

import cv2
import numpy as np
import requests

logger = logging.getLogger(__name__)
SOI, EOI = b"\xff\xd8", b"\xff\xd9"          # JPEG 시작 · 끝
MAX_BUFFER = 4 * 1024 * 1024


class StreamProxy:
    def __init__(self, source_url, timeout=5.0, reconnect_sec=3.0,
                 offline_after=3.0):
        self.url, self.timeout = source_url, timeout
        self.reconnect_sec, self.offline_after = reconnect_sec, offline_after
        self._frame, self._frame_ts = None, 0.0
        self._lock, self._stop = threading.Lock(), threading.Event()
        self._thread = None
        self._count, self._fps, self._win_t0, self._win_n = 0, 0.0, time.time(), 0
        self._error, self._placeholder = None, None

    def start(self):
        if self._thread and self._thread.is_alive():
            return
        self._stop.clear()
        self._thread = threading.Thread(target=self._reader, daemon=True)
        self._thread.start()
        logger.info("스트림 프록시 시작: %s", self.url)

    def stop(self):
        self._stop.set()

    def _reader(self):
        while not self._stop.is_set():
            try:
                with requests.get(self.url, stream=True,
                                  timeout=self.timeout) as r:
                    r.raise_for_status()
                    self._error = None
                    buf = bytearray()
                    for chunk in r.iter_content(chunk_size=8192):
                        if self._stop.is_set():
                            return
                        if not chunk:
                            continue
                        buf.extend(chunk)
                        if len(buf) > MAX_BUFFER:      # 경계를 못 찾는 경우
                            buf.clear()
                            continue
                        self._extract(buf)
            except requests.RequestException as e:
                self._error = str(e)
                logger.warning("스트림 연결 실패: %s", e)
            self._stop.wait(self.reconnect_sec)         # ★ 무한 재연결

    def _extract(self, buf: bytearray):
        while True:
            s = buf.find(SOI)
            if s < 0:
                buf.clear()
                return
            e = buf.find(EOI, s + 2)
            if e < 0:
                if s > 0:
                    del buf[:s]                         # 앞쪽 쓰레기 제거
                return
            frame = bytes(buf[s:e + 2])
            del buf[:e + 2]
            now = time.time()
            with self._lock:
                self._frame, self._frame_ts = frame, now
                self._count += 1
                self._win_n += 1
                if now - self._win_t0 >= 2.0:
                    self._fps = self._win_n / (now - self._win_t0)
                    self._win_t0, self._win_n = now, 0

    def latest(self):
        with self._lock:
            return self._frame, self._frame_ts

    @property
    def connected(self) -> bool:
        _, ts = self.latest()
        return ts > 0 and (time.time() - ts) <= self.offline_after

    def status(self) -> dict:
        _, ts = self.latest()
        return {"connected": self.connected, "fps": round(self._fps, 1),
                "frames": self._count, "source": self.url,
                "last_frame_age": round(time.time() - ts, 2) if ts else None,
                "error": self._error}

    def offline_frame(self) -> bytes:
        """★ 파이가 없을 때의 대체 프레임 (스트림을 끊지 않는다)

        ⚠ cv2.putText 는 한글을 못 그립니다(????). 도형만 그리고
          안내 문구는 HTML 오버레이로 띄웁니다.
        """
        if self._placeholder is None:
            img = np.full((360, 640, 3), 22, np.uint8)
            cv2.rectangle(img, (250, 140), (390, 235), (70, 75, 90), 2)
            cv2.circle(img, (320, 190), 34, (70, 75, 90), 2)
            cv2.line(img, (250, 140), (390, 235), (70, 75, 90), 2)
            ok, enc = cv2.imencode(".jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 70])
            self._placeholder = enc.tobytes() if ok else b""
        return self._placeholder

    def mjpeg(self, fps: int = 12):
        """★ multipart/x-mixed-replace 제너레이터"""
        interval = 1.0 / max(1, fps)
        while True:
            frame, ts = self.latest()
            if frame is None or (time.time() - ts) > self.offline_after:
                frame = self.offline_frame()
            yield (b"--frame\r\nContent-Type: image/jpeg\r\nContent-Length: "
                   + str(len(frame)).encode() + b"\r\n\r\n" + frame + b"\r\n")
            time.sleep(interval)
```

```javascript
(function () {
  const C = window.LIVE, BASE = C.ms;
  let interval = BASE, lastId = null, timer = null;
  const $ = (id) => document.getElementById(id);
  const SEV = { alert: ['경보', '▲'], warn: ['주의', '◆'], info: ['정보', '●'] };

  function row(e) {
    const [t, m] = SEV[e.severity] || SEV.info;
    return `<tr class="row-link is-new" data-href="${C.base}${e.id}">
      <td data-label="시각">${e.ts_hm}</td>
      <td data-label="종류"><span class="ev-mark">${e.mark}</span> ${e.label}</td>

      <td data-label="구역">${e.roi_name || '-'}</td>
      <td data-label="대상">${e.top_label} ${e.count}</td>
      <td data-label="알림">${e.notified ? '발송' : '-'}</td></tr>`;
  }

  function bind() {
    document.querySelectorAll('#recent-body .row-link').forEach(
      (tr) => { tr.onclick = () => { location.href = tr.dataset.href; }; });
  }

  function render(d) {
    $('state-card').className = 'card state-card state-' + d.state.code;
    $('state-mark').textContent = d.state.mark;
    $('state-text').textContent = d.state.label;
    $('state-sub').textContent = d.last_sub;
    $('live-dot').className = 'live-dot ' + (d.stream.connected ? 'on' : 'off');
    $('live-label').textContent = d.stream.connected ? 'LIVE' : '연결 끊김';
    $('meta-fps').textContent = d.stream.fps + ' FPS';
    $('video-overlay').classList.toggle('show', !d.stream.connected);
    $('kpi-total').innerHTML = d.today.total + '<small>건</small>';
    $('kpi-alert').innerHTML = d.today.alerts + '<small>건</small>';
    $('live-clock').textContent = d.clock;
    if (d.latest_id !== lastId && d.recent.length) {   // 새 이벤트일 때만
      lastId = d.latest_id;
      $('recent-body').innerHTML = d.recent.map(row).join('');
      bind();
    }
  }

  async function poll() {
    if (document.hidden) return schedule();            // ① 숨은 탭은 쉰다
    try {
      const r = await fetch(C.url, { cache: 'no-store' });
      if (!r.ok) throw new Error('HTTP ' + r.status);
      render(await r.json());
      interval = BASE;                                 // ③ 성공 → 원래대로
      document.body.classList.remove('is-disconnected');
    } catch (e) {
      interval = Math.min(interval * 2, 30000);        // ② 실패 → 백오프
      document.body.classList.add('is-disconnected');
    }
    schedule();
  }

  // ★ ④ setInterval 이 아니라 setTimeout 재귀 — 요청이 겹치지 않음
  function schedule() { clearTimeout(timer); timer = setTimeout(poll, interval); }

  document.addEventListener('visibilitychange', () => {
    if (!document.hidden) { interval = BASE; poll(); }
  });
  const img = $('stream');
  if (img) img.addEventListener('error', () => setTimeout(() => {
    img.src = img.src.split('?')[0] + '?t=' + Date.now(); }, 3000));
  bind(); poll();
})();
```

```python
import csv

LIST_COLS = ("id, ts, device_id, event_type, severity, roi_name, dwell_sec, "
             "top_class, top_conf, count, thumb_name, notified")


def build_filters(args):
    """★ 필터를 만드는 곳은 여기 하나뿐 — 목록·건수·CSV·통계가 공유"""
    where, params = [], []
    f = {k: (args.get(k) or "").strip()
         for k in ("from", "to", "type", "sev", "device")}
    if f["from"]:
        where.append("ts >= ?"); params.append(f["from"] + "T00:00:00")
    if f["to"]:
        where.append("ts <= ?"); params.append(f["to"] + "T23:59:59")
    if f["type"] in models.EVENT_TYPES:              # 화이트리스트 검증
        where.append("event_type = ?"); params.append(f["type"])
    else:
        f["type"] = ""
    if f["sev"] in models.SEVERITIES:
        where.append("severity = ?"); params.append(f["sev"])
    else:
        f["sev"] = ""
    if f["device"]:
        where.append("device_id = ?"); params.append(f["device"])
    f["active"] = sum(1 for v in f.values() if v)
    return (" AND ".join(where) or "1=1"), params, f


def page_numbers(page, pages, span=2):
    """1 … 4 5 [6] 7 8 … 20   (… 는 None)"""
    if pages <= 1:
        return [1]
    nums = {1, pages, *range(max(1, page - span), min(pages, page + span) + 1)}
    out, prev = [], 0
    for n in sorted(nums):
        if prev and n - prev > 1:
            out.append(None)
        out.append(n); prev = n
    return out


@bp.get("/")
def event_list():
    db = get_db()
    where, params, f = build_filters(request.args)
    total = db.execute(f"SELECT COUNT(*) FROM events WHERE {where}",
                       params).fetchone()[0]
    per = current_app.config["PAGE_SIZE"]
    pages = max(1, math.ceil(total / per))
    # ★ page 를 1..pages 로 가둔다 (?page=-1 → 500 방지)
    page = min(max(1, request.args.get("page", type=int, default=1)), pages)
    rows = db.execute(
        f"SELECT {LIST_COLS} FROM events WHERE {where} "
        f"ORDER BY ts DESC, id DESC LIMIT ? OFFSET ?",   # ★ id 를 함께 정렬
        (*params, per, (page - 1) * per)).fetchall()
    return render_template(
        "events.html", active_page="events", events=rows, filters=f,
        devices=db.execute("SELECT device_id, name FROM devices").fetchall(),
        total=total, page=page, pages=pages,
        page_nums=page_numbers(page, pages), query=request.args.to_dict())


@bp.get("/<int:event_id>")
def detail(event_id):
    db = get_db()
    e = db.execute("SELECT * FROM events WHERE id = ?", (event_id,)).fetchone()
    if e is None:
        abort(404, description=f"이벤트 {event_id} 를 찾을 수 없습니다")

    def load(col):
        try:
            return json.loads(e[col]) if e[col] else None
        except (json.JSONDecodeError, TypeError):
            return None                     # 깨진 JSON 으로 500 을 내지 않음

    prev = db.execute("SELECT id FROM events WHERE id < ? ORDER BY id DESC "
                      "LIMIT 1", (event_id,)).fetchone()
    nxt = db.execute("SELECT id FROM events WHERE id > ? ORDER BY id "
                     "LIMIT 1", (event_id,)).fetchone()
    return render_template(
        "event_detail.html", active_page="events", e=e,
        counts=load("counts_json") or {},
        detections=load("detections_json") or [],
        prev_id=prev["id"] if prev else None,
        next_id=nxt["id"] if nxt else None,
        back=request.args.to_dict())        # 목록으로 돌아갈 때 필터 유지
```

```python
"""web/blueprints/stats.py — ★ 차트 라이브러리 없음"""
from datetime import date, datetime, timedelta

from flask import Blueprint, current_app, render_template, request

from .. import models
from .events import build_filters
from ..db import get_db

bp = Blueprint("stats", __name__)
DOW = ["일", "월", "화", "수", "목", "금", "토"]


def collect(days, where, params):
    db = get_db()
    since = (datetime.now() - timedelta(days=days - 1)).strftime("%Y-%m-%dT00:00:00")
    p, cond = [*params, since], f"{where} AND ts >= ?"

    total = db.execute(f"SELECT COUNT(*) FROM events WHERE {cond}", p).fetchone()[0]
    alerts = db.execute(f"SELECT COUNT(*) FROM events WHERE {cond} "
                        f"AND severity='alert'", p).fetchone()[0]

    # ① 시간대 × 요일 히트맵
    grid, peak = [[0] * 24 for _ in range(7)], 0
    for r in db.execute(
            f"SELECT CAST(strftime('%w', ts) AS INTEGER) d,"
            f" CAST(strftime('%H', ts) AS INTEGER) h, COUNT(*) n"
            f" FROM events WHERE {cond} GROUP BY d, h", p):
        if r["d"] is None or r["h"] is None:      # ts 형식이 깨진 행
            continue
        grid[r["d"]][r["h"]] = r["n"]
        peak = max(peak, r["n"])

    # ② 일별 추이 — 빈 날짜를 0으로 채운다
    got = {r["d"]: r["n"] for r in db.execute(
        f"SELECT substr(ts,1,10) d, COUNT(*) n FROM events WHERE {cond} "
        f"GROUP BY d", p)}
    daily = [{"d": (date.today() - timedelta(days=days - 1 - i)).isoformat()}
             for i in range(days)]
    for x in daily:
        x["n"] = got.get(x["d"], 0)

    # ③ 종류 분포
    by_type = [{"label": models.event_label(r["event_type"]), "n": r["n"],
                "sev": models.event_severity(r["event_type"])}
               for r in db.execute(
                   f"SELECT event_type, COUNT(*) n FROM events WHERE {cond} "
                   f"GROUP BY event_type ORDER BY n DESC", p)]

    hours = [sum(grid[d][h] for d in range(7)) for h in range(24)]
    return {"total": total, "alerts": alerts, "grid": grid, "peak": peak,
            "daily": daily, "by_type": by_type, "dow": DOW, "days": days,
            "busiest": hours.index(max(hours)) if total else None,
            "avg_per_day": round(total / days, 1) if days else 0}


def sparkline(daily, w=620, h=140, pad=24):
    """★ SVG 좌표는 파이썬에서 계산 — 템플릿은 그리기만"""
    n = len(daily)
    ymax = max([d["n"] for d in daily] or [0]) or 1      # ★ 0 나눗셈 방지
    step = (w - pad * 2) / max(1, n - 1)
    pts = [{"x": round(pad + step * i, 1),
            "y": round(h - pad - (h - pad * 2) * d["n"] / ymax, 1),
            "d": d["d"], "n": d["n"], "md": d["d"][5:]}
           for i, d in enumerate(daily)]
    line = " ".join(f"{p['x']},{p['y']}" for p in pts)
    return {"pts": pts, "line": line, "ymax": ymax, "w": w, "h": h, "pad": pad,
            "area": f"{pad},{h-pad} {line} {pad + step*(n-1)},{h-pad}"}


@bp.get("/")
def index():
    days = min(max(request.args.get("days", type=int, default=7), 1),
               current_app.config["STATS_DAYS"])
    where, params, f = build_filters(request.args)
    data = collect(days, where, params)
    return render_template("stats.html", active_page="stats", filters=f,
                           chart=sparkline(data["daily"]), **data)
```

```python
"""tools/smoke_check.py — 모든 화면이 살아 있는지 30초에 확인

  python tools/smoke_check.py http://127.0.0.1:5000
"""
import sys
import time

import requests

BASE = sys.argv[1] if len(sys.argv) > 1 else "http://127.0.0.1:5000"
CASES = [                       # (경로, 기대 상태, 반드시 있어야 하는 문자열)
    ("/", 200, "실시간 모니터링"), ("/events", 200, "이벤트 이력"),
    ("/events?type=no_helmet", 200, "안전모 미착용"),
    ("/events?page=-1", 200, "이벤트 이력"),
    ("/events?type=DROP", 200, "이벤트 이력"),
    ("/events/1", 200, "이벤트 정보"),
    ("/events/999999", 404, "찾을 수 없습니다"),
    ("/events/export.csv", 200, ""), ("/stats", 200, "히트맵"),
    ("/stats?days=999", 200, "히트맵"), ("/demo", 200, "검출"),
    ("/api/state", 200, "latest_id"), ("/api/health", 200, '"ok"'),
    ("/api/nope", 404, "not_found"), ("/nope", 404, "404"),
]
BAD = ["Traceback", "Werkzeug", "lorem", "no_helmet<", "None건"]

print(f"{'경로':<28}{'상태':>6}{'ms':>8}  결과")
failed = 0
for path, want, needle in CASES:
    t0 = time.perf_counter()
    try:
        r = requests.get(BASE + path, timeout=10)
    except requests.RequestException as e:
        print(f"{path:<28}{'---':>6}{'---':>8}  ✗ {e}"); failed += 1; continue
    ms, body, msgs = (time.perf_counter() - t0) * 1000, r.text, []
    if r.status_code != want:
        msgs.append(f"상태 {r.status_code} (기대 {want})")
    if needle and needle not in body:
        msgs.append(f"'{needle}' 없음")
    msgs += [f"금지어 '{w}'" for w in BAD if w in body]   # ★ 영어·디버그 잔재
    if ms > 1000:
        msgs.append(f"★ 느림 {ms:.0f}ms")
    failed += 0 if not msgs else 1
    print(f"{path:<28}{r.status_code:>6}{ms:>8.0f}  "
          f"{'✓' if not msgs else '✗ ' + ' · '.join(msgs)}")
print(f"{len(CASES) - failed}/{len(CASES)} 통과")
sys.exit(1 if failed else 0)
```

```python
@bp.get("/")
def event_list():
    db = get_db()
    where, params, f = build_filters(request.args)          # ★ ③

    total = db.execute(f"SELECT COUNT(*) FROM events WHERE {where}",
                       params).fetchone()[0]
    per = current_app.config["PAGE_SIZE"]
    pages = max(1, math.ceil(total / per))
    page = min(max(1, request.args.get("page", type=int, default=1)), pages)  # ★ ⑤

    rows = db.execute(                                       # ★ ① ②
        f"SELECT {LIST_COLS} FROM events WHERE {where} "
        f"ORDER BY ts DESC, id DESC LIMIT ? OFFSET ?",
        (*params, per, (page - 1) * per)).fetchall()

    return render_template("events.html", events=rows, total=total,
                           page=page, pages=pages, filters=f)
```

```javascript
const BASE = 3000;
let interval = BASE, lastId = null, timer = null;

async function poll() {
  if (document.hidden) return schedule();          // ★ ⑤
  try {
    const r = await fetch('/api/state', { cache: 'no-store' });
    if (!r.ok) throw new Error('HTTP ' + r.status); // ③
    const data = await r.json();
    if (data.latest_id !== lastId) {               // ④
      lastId = data.latest_id;
      document.getElementById('recent-body').innerHTML =
        data.recent.map(rowHtml).join('');
    }
    interval = BASE;
  } catch (e) {
    interval = Math.min(interval * 2, 30000);      // ③ 백오프
    document.body.classList.add('is-disconnected');
  }
  schedule();
}

function schedule() {                              // ②
  clearTimeout(timer);
  timer = setTimeout(poll, interval);
}

document.addEventListener('visibilitychange', () => {
  if (!document.hidden) { interval = BASE; poll(); }
});
poll();
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 순서 | **시연 동선 → 사이트맵 → 화면 → DB → 코드** |
| 범위 | 필수 **4화면** + 보험 1개. 나머지는 "만들지 않는다"고 **적는다** |
| 재사용 | W32–33 산출물 3,000줄 그대로 · 새로 쓰는 건 1,000줄 |
| 앱 구조 | `create_app` + Blueprint 5개 · 설정 3종(dev/**demo**/prod) |
| 모델 | **싱글턴 + 지연 로딩** — 검출은 파이가 함 |
| 스트림 | **서버 프록시** — 1개 당겨 N명에게. 파이 IP 노출 ✗ |
| 끊김 | 대체 프레임 + **HTML 오버레이** (깨진 아이콘 ✗) |
| DB | 컬럼 9개 확장 · **user_version 마이그레이션** |
| 시각 | **`normalize_ts`** — `+09:00` 이 붙으면 통계가 전부 0 |
| 필터 | **`build_filters` 한 곳** — 목록·건수·CSV·통계가 공유 |
| 페이지 | OFFSET + `page` 를 1..pages 로 **가둔다** |
| 정렬 | `ORDER BY ts DESC, **id DESC**` — 중복/누락 방지 |
| 차트 | **CDN 없이** CSS Grid 히트맵 · SVG 라인 · CSS 막대 |
| 위계 | 가장 중요한 숫자를 **가장 크게**(44px) |
| 상태색 | 정상/주의/경보 3단계 · **색 + 기호 + 글자** |
| 감점 | 정렬 · **영어** · 시간 형식 · **0건** — 5분이면 고침 |
| 모바일 | `data-label` 로 **표→카드** · 터치 44px · 입력 16px |
| 갱신 | **폴링 3초** — `setTimeout` 재귀 + hidden + 백오프 |
| 성능 | 인덱스 · LIMIT · 필요한 컬럼만 · **썸네일** (8.4s→0.09s) |
| 협업 | `base.html` 은 한 명만 · CSS 분리 · **DB 커밋 금지** |

**오늘 반드시 기억할 세 가지**

> ① **화면을 4개로 줄이세요.** 10개를 시작한 팀은 2개를 완성하고, 4개를 정한 팀은 4개를 완성합니다. 심사는 개수가 아니라 **클릭했을 때 제대로 나오는가**를 봅니다.
> ② **시연 동선을 먼저 쓰세요.** 클릭 5번 안에 핵심이 보여야 합니다. 동선이 곧 오늘의 요구사항 명세서이고, Day 180 의 발표 대본입니다.
> ③ **DB 를 비우고 파이를 끄고 전 화면을 돌아보세요.** 그때 나오는 화면이 발표 당일 아침에 나올 화면입니다. 빈 상태·로딩·에러를 채우는 30분이 완성도 점수를 만듭니다.
