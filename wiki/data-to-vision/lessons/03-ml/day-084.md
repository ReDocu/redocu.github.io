## ③ 개념 설명

### 기울기 (Gradient)

**기울기 = 그 지점에서 함수가 얼마나 가파른가 + 어느 방향으로 올라가는가**

```
f(w) = w²  의 기울기(미분) = 2w

w = 3  →  기울기 +6   (오른쪽으로 갈수록 올라감)
w = -3 →  기울기 -6   (왼쪽으로 갈수록 올라감)
w = 0  →  기울기  0   (평평. 최솟값)
```

```
f(w)
  9│●                    ●
   │ ╲                  ╱
  4│  ╲                ╱
   │   ╲              ╱
  1│    ╲            ╱
  0│     ╲__________╱
   └──────────────────── w
   -3  -2  -1  0  1  2  3
        ↑           ↑
    기울기 -        기울기 +
    (오른쪽으로)   (왼쪽으로)
```

**기울기의 반대 방향으로 가면 내려갑니다.**

### 경사하강법 갱신식

```
w ← w - lr × ∂L/∂w
    │    │      │
    │    │      └─ 기울기 (손실이 커지는 방향)
    │    └──────── 학습률 (한 걸음 크기)
    └───────────── 마이너스 (반대 방향으로 = 내려감)
```

**손으로 따라가 봅시다.** `f(w) = w²`, 시작 `w = 3`, `lr = 0.1`

| 단계 | w | f(w) | 기울기 2w | 갱신 계산 | 새 w |
|---|---|---|---|---|---|
| 0 | 3.000 | 9.000 | 6.000 | 3 - 0.1×6 | 2.400 |
| 1 | 2.400 | 5.760 | 4.800 | 2.4 - 0.1×4.8 | 1.920 |
| 2 | 1.920 | 3.686 | 3.840 | 1.92 - 0.1×3.84 | 1.536 |
| 3 | 1.536 | 2.359 | 3.072 | — | 1.229 |
| ... | ... | ... | ... | ... | ... |
| 30 | 0.005 | 0.000 | 0.009 | — | 0.004 |

**최솟값 w=0으로 수렴합니다.**

> **최솟값에 가까워질수록 기울기가 작아져 걸음도 자동으로 작아집니다.**
> 학습률을 줄이지 않아도 부드럽게 착지합니다. 경사하강법의 좋은 성질입니다.

### 학습률 (Learning Rate) — 가장 중요한 하이퍼파라미터

| lr | 현상 | 그림 |
|---|---|---|
| **너무 작음** (0.0001) | 수렴이 매우 느림. 지역 최솟값에 갇힘 | `→→→→→→→→` 찔끔찔끔 |
| **적당함** (0.01~0.1) | 안정적으로 수렴 | `→ → → 🏁` |
| **너무 큼** (1.0) | 진동하거나 **발산** | `→←→←→←` 또는 `→→→💥` |

```
lr 작음                lr 적당                lr 큼
  ╲                     ╲                    ╲    ╱
   ╲....                 ╲                    ╲  ╱
    ╲....                 ╲___                 ╲╱  ← 튕겨 나감
     ╲___                                      ╱╲
   (100번 필요)         (10번이면 도착)        (영원히 못 도착)
```

**발산하는 조건** — `f(w) = w²` 에서 `lr > 1.0` 이면 발산합니다.

```
lr = 1.1, w = 3
  w ← 3 - 1.1×6 = -3.6      ← 반대편으로 더 멀리
  w ← -3.6 - 1.1×(-7.2) = 4.32
  w ← 4.32 - 1.1×8.64 = -5.18
  ...  점점 커짐 → 발산
```

> **학습 중 손실이 `nan` 이 되면 학습률부터 낮추세요.**
> 손실이 발산 → 가중치가 `inf` → 계산 결과가 `nan` 이 됩니다.

**권장 시작값**

| 옵티마이저 | 권장 lr |
|---|---|
| SGD | 0.01 ~ 0.1 |
| **Adam** | **0.001** (기본값) |
| 전이학습 미세조정 ([Day 099](day-099.md)) | **0.00001 ~ 0.0001** |

### 지역 최솟값과 안장점

```
손실
  │╲          ╱╲
  │ ╲        ╱  ╲
  │  ╲__╱╲__╱    ╲___
  │   지역        전역
  │   최솟값      최솟값
  └────────────────────── w
```

**경사하강법은 지역 최솟값에 갇힐 수 있습니다.**

> **그런데 실무에서는 큰 문제가 아닙니다.**
> 파라미터가 수백만 개인 고차원 공간에서는 **모든 방향으로 올라가는 지점(지역 최솟값)이 매우 드뭅니다.**
> 대부분은 **안장점**(일부 방향은 올라가고 일부는 내려감)이고, 여기는 빠져나올 수 있습니다.
> 모멘텀·Adam이 이것을 도와줍니다.

### 역전파 (Backpropagation)

**문제** — 은닉층 가중치가 손실에 어떤 영향을 주는지 어떻게 아는가?

```
w1 → h → w2 → ŷ → 손실

w2가 손실에 주는 영향: 바로 옆이라 계산이 쉬움
w1이 손실에 주는 영향: h를 거쳐서 간접적으로... 어떻게?
```

**답 — 연쇄법칙(chain rule)**

```
∂L      ∂L     ∂ŷ     ∂h
──── = ──── × ──── × ────
∂w1     ∂ŷ     ∂h     ∂w1
```

**곱셈으로 이어 붙입니다.**

```
순전파 →  x → [층1] → h → [층2] → ŷ → L
역전파 ←  ∂L/∂x ← [층1] ← ∂L/∂h ← [층2] ← ∂L/∂ŷ ← L
```

**직관** — "네가 얼마나 잘못했는지" 를 출력에서 입력 쪽으로 되짚어 갑니다.

| 단계 | 하는 일 |
|---|---|
| 1. 순전파 | 예측을 만든다 |
| 2. 손실 계산 | 얼마나 틀렸는지 잰다 |
| 3. **역전파** | 각 가중치가 오차에 얼마나 기여했는지 계산 |
| 4. 갱신 | 기여한 만큼 반대로 조정 |

> **[Day 082](day-082.md)의 기울기 소실이 여기서 일어납니다.**
> 역전파는 층마다 미분값을 **곱해** 나갑니다. Sigmoid의 미분 최댓값이 0.25이므로,
> 10층이면 `0.25^10 ≈ 0.000001` 이 됩니다.
>
> **오늘 배운 연쇄법칙이 그 곱셈의 정체입니다.**

**직접 구현할 필요는 없습니다.**

```python
# TensorFlow/PyTorch가 자동으로 해 줍니다 (자동 미분)
loss.backward()      # PyTorch
tape.gradient(...)   # TensorFlow
```

> **개념만 알면 됩니다.** "오차를 뒤로 곱해 가며 전달한다" — 이 한 문장이면 충분합니다.
> 다만 실습 Step 4에서 2층 신경망의 역전파를 직접 구현해 봅니다. 한 번 해 두면 감이 완전히 다릅니다.

### 에폭 / 배치 / 반복 — 정확히 구분하기

```
데이터 1000건, batch_size = 100

1 배치      = 100건을 한 번에 처리
1 반복(iteration) = 배치 하나로 가중치를 1번 갱신
1 에폭      = 전체 1000건을 다 본 것 = 10 반복
10 에폭     = 전체를 10번 반복 = 100 반복 = 가중치 100번 갱신
```

| 용어 | 정의 | 예 (1000건, batch 100) |
|---|---|---|
| **배치 크기** | 한 번에 처리하는 샘플 수 | 100 |
| **반복(iteration)** | 가중치 갱신 1회 | — |
| **에폭(epoch)** | 전체 데이터 1회 통과 | 10 반복 |
| **스텝(step)** | 반복과 같은 말 | — |

```
반복 수 = ceil(데이터 수 / 배치 크기) × 에폭 수
```

### 배치 크기의 세 가지 방식

| 방식 | 배치 크기 | 특징 |
|---|---|---|
| **배치 경사하강법** | 전체 | 정확한 기울기. **느리고 메모리 폭발** |
| **확률적 경사하강법 (SGD)** | 1 | 빠르지만 매우 불안정 |
| **미니배치 SGD** | 16~512 | **실무 표준** |

```
손실
  │  배치GD (매끄럽게)      SGD (요동)        미니배치 (적당)
  │    ╲___                ╲∿∿∿                ╲~~~
  │        ╲___               ∿∿∿∿                 ~~~~
  └────────────────────────────────────────────────────
```

**배치 크기의 영향**

| 배치 크기 | 장점 | 단점 |
|---|---|---|
| 작음 (8~32) | 일반화 성능이 좋은 경향 · 메모리 적음 | 느림 · 기울기가 튐 |
| 큼 (256~1024) | GPU 효율 좋음 · 안정적 | 메모리 많이 씀 · **일반화가 나빠질 수 있음** |

> **기본값 32로 시작하세요.** GPU 메모리가 부족하면 줄이고, 학습이 너무 느리면 늘립니다.
> [Day 090](day-090.md)의 CIFAR-10 실습에서 배치 크기를 직접 조절하게 됩니다.

### 옵티마이저

**SGD** — 기본형

```
w ← w - lr × g
```

**SGD + 모멘텀** — 관성을 추가

```
v ← β·v + g          (이전 방향을 기억)
w ← w - lr × v
```

```
모멘텀 없음: 좁은 골짜기에서 지그재그
모멘텀 있음: 관성으로 골짜기를 따라 쭉 미끄러짐
```

**Adam** — 적응형 학습률 + 모멘텀

```
파라미터마다 학습률을 자동 조절
  자주 크게 변하는 파라미터 → 학습률 작게
  거의 안 변하는 파라미터   → 학습률 크게
```

| 옵티마이저 | 특징 | 언제 |
|---|---|---|
| SGD | 단순. 튜닝 필요 | 이론 학습 |
| SGD + momentum | 안정적 | 이미지 분류에서 여전히 강함 |
| **Adam** | **거의 튜닝 없이 잘 됨** | **기본 선택** |
| AdamW | Adam + 개선된 규제 | Transformer |
| RMSprop | Adam의 전신 | RNN |

> **"일단 Adam(lr=0.001)으로 시작한다"** 가 실무 표준입니다.
> 성능을 마지막 1%까지 짜내야 할 때 SGD+momentum을 튜닝해 봅니다.

## ④ 단계별 실습

### Step 1. 1차원 함수의 최솟값 찾기

```python
import matplotlib.pyplot as plt
import numpy as np


def f(w):
    return w ** 2


def grad(w):
    return 2 * w


def gradient_descent(start, lr, steps=30):
    """경사하강법 경로를 기록하며 실행"""
    w = start
    history = [w]
    for _ in range(steps):
        g = grad(w)
        w = w - lr * g
        history.append(w)
        if abs(w) > 1e10:      # 발산
            break
    return np.array(history)


print("=" * 70)
print("f(w) = w², 시작점 w=3, 학습률 0.1")
print("=" * 70)
print(f"{'step':>6}{'w':>12}{'f(w)':>12}{'기울기 2w':>14}{'갱신식':>22}")
print("-" * 70)

w = 3.0
lr = 0.1
for step in range(8):
    g = grad(w)
    new_w = w - lr * g
    print(f"{step:>6}{w:>12.4f}{f(w):>12.4f}{g:>14.4f}"
          f"{f'{w:.3f} - {lr}×{g:.3f}':>22}")
    w = new_w

print("-" * 70)
print(f"8단계 후: w = {w:.6f},  f(w) = {f(w):.8f}")
print("최솟값 w=0 으로 수렴 중입니다.")
print("=" * 70)

# ── 학습률별 비교 ──
print("\n" + "=" * 70)
print("학습률에 따른 결과 (30 스텝)")
print("=" * 70)
print(f"{'학습률':>10}{'최종 w':>16}{'최종 f(w)':>16}{'판정':>16}")
print("-" * 70)

for lr in [0.001, 0.01, 0.1, 0.5, 0.9, 1.0, 1.01, 1.1]:
    h = gradient_descent(3.0, lr, steps=30)
    final_w = h[-1]
    if abs(final_w) > 1e6:
        verdict = "발산 💥"
        final_str, fval_str = "inf", "inf"
    elif abs(final_w) < 0.01:
        verdict = "수렴 ✓"
        final_str, fval_str = f"{final_w:.6f}", f"{f(final_w):.8f}"
    elif abs(final_w) > 2.5:
        verdict = "거의 안 움직임"
        final_str, fval_str = f"{final_w:.6f}", f"{f(final_w):.6f}"
    else:
        verdict = "느리게 수렴 중"
        final_str, fval_str = f"{final_w:.6f}", f"{f(final_w):.6f}"
    print(f"{lr:>10.3f}{final_str:>16}{fval_str:>16}{verdict:>16}")

print("=" * 70)
print("lr = 1.0 : 3 → -3 → 3 → -3 …  영원히 진동 (수렴도 발산도 아님)")
print("lr > 1.0 : 진폭이 커지며 발산")
print("=" * 70)
```

import matplotlib.pyplot as plt

def loss_2d(w1, w2):
    """길쭉한 골짜기 — 스케일링을 안 했을 때의 모습"""
    return 0.5 * w1 ** 2 + 8.0 * w2 ** 2


def grad_2d(w1, w2):
    return np.array([1.0 * w1, 16.0 * w2])


def run_2d(start, lr, steps=40, momentum=0.0):
    w = np.array(start, dtype=float)
    v = np.zeros(2)
    hist = [w.copy()]

        g = grad_2d(*w)
        v = momentum * v + g
        w = w - lr * v
        hist.append(w.copy())
        if np.abs(w).max() > 1e6:
            break
    return np.array(hist)

### Step 4. 역전파 직접 구현 — 2층 신경망 학습

```python
import matplotlib.pyplot as plt
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

np.set_printoptions(precision=4, suppress=True)


def relu(z):
    return np.maximum(0, z)


def relu_grad(z):
    return (z > 0).astype(float)


def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))


class TwoLayerNet:
    """순전파 + 역전파를 직접 구현한 2층 신경망"""

    def __init__(self, n_in, n_hidden, n_out=1, seed=42):
        rng = np.random.default_rng(seed)
        self.W1 = rng.normal(0, np.sqrt(2 / n_in), (n_in, n_hidden))
        self.b1 = np.zeros(n_hidden)
        self.W2 = rng.normal(0, np.sqrt(2 / n_hidden), (n_hidden, n_out))
        self.b2 = np.zeros(n_out)

    # ── 순전파 (Day 083) ──
    def forward(self, X):
        self.X = X
        self.Z1 = X @ self.W1 + self.b1
        self.A1 = relu(self.Z1)
        self.Z2 = self.A1 @ self.W2 + self.b2
        self.A2 = sigmoid(self.Z2)
        return self.A2

    def loss(self, y):
        eps = 1e-7
        p = np.clip(self.A2.ravel(), eps, 1 - eps)
        return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

    # ── 역전파 ──
    def backward(self, y):
        m = len(y)
        y = y.reshape(-1, 1)

        # 출력층: sigmoid + BCE 조합은 미분이 (예측 - 정답) 으로 간단해짐
        dZ2 = (self.A2 - y) / m                     # (m, 1)
        dW2 = self.A1.T @ dZ2                       # (h, 1)
        db2 = dZ2.sum(axis=0)                       # (1,)

        # 은닉층으로 오차 전달 (연쇄법칙)
        dA1 = dZ2 @ self.W2.T                       # (m, h)
        dZ1 = dA1 * relu_grad(self.Z1)              # ReLU 미분 곱하기
        dW1 = self.X.T @ dZ1                        # (n_in, h)
        db1 = dZ1.sum(axis=0)                       # (h,)

        return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}

    def update(self, grads, lr):
        self.W1 -= lr * grads["W1"]
        self.b1 -= lr * grads["b1"]
        self.W2 -= lr * grads["W2"]
        self.b2 -= lr * grads["b2"]

    def fit(self, X, y, X_val=None, y_val=None, epochs=200, lr=0.1, verbose=True):
        history = []
        for ep in range(1, epochs + 1):
            self.forward(X)
            loss = self.loss(y)
            acc = ((self.A2.ravel() >= 0.5).astype(int) == y).mean()

            rec = {"epoch": ep, "loss": loss, "acc": acc}
            if X_val is not None:
                val_p = self.forward(X_val).ravel()
                eps = 1e-7
                vp = np.clip(val_p, eps, 1 - eps)
                rec["val_loss"] = -np.mean(y_val * np.log(vp) + (1 - y_val) * np.log(1 - vp))
                rec["val_acc"] = ((val_p >= 0.5).astype(int) == y_val).mean()
                self.forward(X)     # 역전파용으로 학습셋 상태 복원

            history.append(rec)

            grads = self.backward(y)
            self.update(grads, lr)

            if verbose and (ep <= 3 or ep % 50 == 0):
                extra = f"  val_loss {rec.get('val_loss', 0):.4f}" if X_val is not None else ""
                print(f"  epoch {ep:>4}: loss {loss:.4f}  acc {acc:.4f}{extra}")
        return history

print("=" * 70)

최대 상대오차: 3.07e-11   ✓ 역전파 구현이 맞습니다
======================================================================
```

**우리가 만든 신경망이 학습을 했습니다.**

```
epoch   1: 정확도 0.489    ← 무작위 찍기 수준
epoch 300: 정확도 0.956    ← 제대로 배움
```

**그리고 역전파가 맞다는 것을 수치미분으로 검증했습니다.**

> **기울기 검증(gradient checking)은 역전파를 직접 구현할 때의 필수 절차입니다.**
> 상대오차가 `1e-7` 이하면 정상, `1e-3` 이상이면 버그입니다.
>
> **`dZ2 = (A2 - y) / m` 이 이렇게 간단한 이유** — sigmoid와 BCE의 미분이 서로 상쇄됩니다.
> 이것이 [Day 083](day-083.md)에서 "분류에 크로스엔트로피를 쓰는" 수학적 이유입니다.

### Step 5. 학습률과 배치 크기 실험

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler


def relu(z):
    return np.maximum(0, z)


def relu_grad(z):
    return (z > 0).astype(float)


def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))


class Net:
    def __init__(self, n_in, n_h, seed=42):
        rng = np.random.default_rng(seed)
        self.W1 = rng.normal(0, np.sqrt(2 / n_in), (n_in, n_h))
        self.b1 = np.zeros(n_h)
        self.W2 = rng.normal(0, np.sqrt(2 / n_h), (n_h, 1))
        self.b2 = np.zeros(1)

    def forward(self, X):
        self.X = X
        self.Z1 = X @ self.W1 + self.b1
        self.A1 = relu(self.Z1)
        self.Z2 = self.A1 @ self.W2 + self.b2
        self.A2 = sigmoid(self.Z2)
        return self.A2

    def loss(self, y):
        p = np.clip(self.A2.ravel(), 1e-7, 1 - 1e-7)
        return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

    def step(self, y, lr):
        m = len(y)
        yy = y.reshape(-1, 1)
        dZ2 = (self.A2 - yy) / m
        dW2 = self.A1.T @ dZ2
        db2 = dZ2.sum(axis=0)
        dZ1 = (dZ2 @ self.W2.T) * relu_grad(self.Z1)
        dW1 = self.X.T @ dZ1
        db1 = dZ1.sum(axis=0)
        self.W1 -= lr * dW1
        self.b1 -= lr * db1
        self.W2 -= lr * dW2
        self.b2 -= lr * db2


def train(X, y, X_val, y_val, lr, batch_size, epochs=60, seed=42):
    net = Net(X.shape[1], 16, seed=seed)
    rng = np.random.default_rng(0)
    n = len(y)
    hist = []

    for ep in range(epochs):
        idx = rng.permutation(n)
        for start in range(0, n, batch_size):
            b = idx[start:start + batch_size]
            net.forward(X[b])
            net.step(y[b], lr)

        net.forward(X)
        tr_loss = net.loss(y)
        tr_acc = ((net.A2.ravel() >= 0.5).astype(int) == y).mean()
        net.forward(X_val)
        va_acc = ((net.A2.ravel() >= 0.5).astype(int) == y_val).mean()
        hist.append({"epoch": ep + 1, "loss": tr_loss,
                     "acc": tr_acc, "val_acc": va_acc})
    return net, hist


X, y = make_moons(n_samples=1000, noise=0.2, random_state=42)

    X, y, test_size=0.3, random_state=42, stratify=y
)

### Step 6. 옵티마이저 비교

```python
import matplotlib.pyplot as plt
import numpy as np


def loss_fn(w):
    """비스코스한 골짜기 — Rosenbrock 유사"""
    w1, w2 = w
    return 0.5 * w1 ** 2 + 12.0 * w2 ** 2


def grad_fn(w):
    w1, w2 = w
    return np.array([w1, 24.0 * w2])


def sgd(start, lr, steps):
    w, hist = np.array(start, float), [np.array(start, float)]
    for _ in range(steps):
        w = w - lr * grad_fn(w)
        hist.append(w.copy())
    return np.array(hist)


def momentum(start, lr, steps, beta=0.9):
    w, v = np.array(start, float), np.zeros(2)
    hist = [w.copy()]
    for _ in range(steps):
        v = beta * v + grad_fn(w)
        w = w - lr * v
        hist.append(w.copy())
    return np.array(hist)


def rmsprop(start, lr, steps, beta=0.9, eps=1e-8):
    w, s = np.array(start, float), np.zeros(2)
    hist = [w.copy()]
    for _ in range(steps):
        g = grad_fn(w)
        s = beta * s + (1 - beta) * g ** 2
        w = w - lr * g / (np.sqrt(s) + eps)
        hist.append(w.copy())
    return np.array(hist)


def adam(start, lr, steps, b1=0.9, b2=0.999, eps=1e-8):
    w = np.array(start, float)
    m, v = np.zeros(2), np.zeros(2)
    hist = [w.copy()]
    for t in range(1, steps + 1):
        g = grad_fn(w)
        m = b1 * m + (1 - b1) * g
        v = b2 * v + (1 - b2) * g ** 2
        m_hat = m / (1 - b1 ** t)
        v_hat = v / (1 - b2 ** t)
        w = w - lr * m_hat / (np.sqrt(v_hat) + eps)
        hist.append(w.copy())
    return np.array(hist)


START = [-4.0, 2.0]
STEPS = 60

optimizers = [
    ("SGD (lr=0.04)", sgd(START, 0.04, STEPS), "#1f77b4"),
    ("Momentum (lr=0.04, β=0.9)", momentum(START, 0.04, STEPS), "#ff7f0e"),
    ("RMSprop (lr=0.15)", rmsprop(START, 0.15, STEPS), "#2ca02c"),
    ("Adam (lr=0.3)", adam(START, 0.3, STEPS), "#d62728"),
]

print("-" * 74)
for name, hist, _ in optimizers:
    print(f"{name:<30}{loss_fn(hist[-1]):>16.8f}{loss_fn(hist[10]):>16.6f}")
print("=" * 74)

w1 = np.linspace(-5, 5, 300)
w2 = np.linspace(-2.5, 2.5, 300)
W1, W2 = np.meshgrid(w1, w2)

fig, axes = plt.subplots(1, 2, figsize=(15, 5.5))

for name, hist, color in optimizers:
    ax.plot(hist[:, 0], hist[:, 1], "o-", markersize=3, linewidth=1.6,
            label=name, color=color, alpha=0.85)
ax.scatter([START[0]], [START[1]], s=120, c="green", zorder=5, marker="s")

## ⑥ 확인 문제

**1.** `f(w) = (w - 4)²` 를 `w = 0` 에서 시작해 경사하강법으로 최소화합니다.
① 기울기 공식을 쓰세요.
② lr = 0.1일 때 5스텝을 손으로 계산하세요.
③ 발산하는 학습률의 범위를 구하세요.

<details>
<summary>답 보기</summary>

**① 기울기**

```
f(w) = (w - 4)²
f'(w) = 2(w - 4)
```

**② lr = 0.1, w₀ = 0**

| 스텝 | w | f(w) | 기울기 2(w-4) | 갱신 | 새 w |
|---|---|---|---|---|---|
| 0 | 0.000 | 16.000 | -8.000 | 0 - 0.1×(-8) | **0.800** |
| 1 | 0.800 | 10.240 | -6.400 | 0.8 + 0.64 | **1.440** |
| 2 | 1.440 | 6.554 | -5.120 | 1.44 + 0.512 | **1.952** |
| 3 | 1.952 | 4.194 | -4.096 | 1.952 + 0.410 | **2.362** |
| 4 | 2.362 | 2.684 | -3.277 | 2.362 + 0.328 | **2.689** |
| 5 | 2.689 | 1.718 | — | — | — |

**최솟값 w=4로 접근 중입니다.**

**③ 발산 조건**

```
w_{t+1} = w_t - lr × 2(w_t - 4)

오차를 e = w - 4 로 두면
  e_{t+1} = e_t - 2·lr·e_t = (1 - 2·lr)·e_t

|1 - 2·lr| < 1  이어야 수렴
→ -1 < 1 - 2lr < 1
→ 0 < lr < 1
```

| lr | 판정 |
|---|---|
| 0 < lr < 0.5 | 수렴 (단조 접근) |
| lr = 0.5 | **1스텝에 도달** (최적) |
| 0.5 < lr < 1 | 수렴 (진동하며) |
| **lr = 1** | **영원히 진동** |
| **lr > 1** | **발산** |

**검산**

```python
import numpy as np


def f(w):
    return (w - 4) ** 2


def grad(w):
    return 2 * (w - 4)


print(f"{'lr':>8}{'20스텝 후 w':>16}{'f(w)':>16}{'판정':>12}")
print("-" * 52)
for lr in [0.1, 0.3, 0.5, 0.7, 0.99, 1.0, 1.01, 1.5]:
    w = 0.0
    for _ in range(20):
        w = w - lr * grad(w)
        if abs(w) > 1e10:
            break
    if abs(w) > 1e6:
        print(f"{lr:>8.2f}{'inf':>16}{'inf':>16}{'발산':>12}")
    else:
        v = "수렴" if abs(w - 4) < 0.01 else "진동/느림"
        print(f"{lr:>8.2f}{w:>16.6f}{f(w):>16.8f}{v:>12}")
```

③ 발산 / 진동 / 수렴 / 너무 느림 구간을 판정하는 **자동 진단 함수** 작성

from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.datasets import make_circles
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler


def relu(z):
    return np.maximum(0, z)


def relu_grad(z):
    return (z > 0).astype(float)


def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))


class Net:
    """SGD / Momentum / Adam 을 모두 지원하는 2층 신경망"""

    def __init__(self, n_in, n_h, optimizer="sgd", seed=42):
        rng = np.random.default_rng(seed)
        self.W1 = rng.normal(0, np.sqrt(2 / n_in), (n_in, n_h))
        self.b1 = np.zeros(n_h)
        self.W2 = rng.normal(0, np.sqrt(2 / n_h), (n_h, 1))
        self.b2 = np.zeros(1)
        self.optimizer = optimizer
        self.t = 0
        self._m = {k: np.zeros_like(getattr(self, k)) for k in ["W1", "b1", "W2", "b2"]}
        self._v = {k: np.zeros_like(getattr(self, k)) for k in ["W1", "b1", "W2", "b2"]}

    def forward(self, X):
        self.X = X
        self.Z1 = X @ self.W1 + self.b1
        self.A1 = relu(self.Z1)
        self.Z2 = self.A1 @ self.W2 + self.b2
        self.A2 = sigmoid(self.Z2)
        return self.A2

    def loss(self, y):
        p = np.clip(self.A2.ravel(), 1e-7, 1 - 1e-7)
        return float(-np.mean(y * np.log(p) + (1 - y) * np.log(1 - p)))

    def backward(self, y):
        m = len(y)
        yy = y.reshape(-1, 1)
        dZ2 = (self.A2 - yy) / m
        dW2 = self.A1.T @ dZ2
        db2 = dZ2.sum(axis=0)
        dZ1 = (dZ2 @ self.W2.T) * relu_grad(self.Z1)
        return {"W1": self.X.T @ dZ1, "b1": dZ1.sum(axis=0),
                "W2": dW2, "b2": db2}

    def update(self, g, lr):
        self.t += 1
        for k in ["W1", "b1", "W2", "b2"]:
            p = getattr(self, k)
            if self.optimizer == "sgd":
                p -= lr * g[k]
            elif self.optimizer == "momentum":
                self._m[k] = 0.9 * self._m[k] + g[k]
                p -= lr * self._m[k]
            elif self.optimizer == "adam":
                self._m[k] = 0.9 * self._m[k] + 0.1 * g[k]
                self._v[k] = 0.999 * self._v[k] + 0.001 * g[k] ** 2
                mh = self._m[k] / (1 - 0.9 ** self.t)
                vh = self._v[k] / (1 - 0.999 ** self.t)
                p -= lr * mh / (np.sqrt(vh) + 1e-8)


def train(X, y, Xv, yv, lr, batch_size, epochs=80, optimizer="sgd", seed=42):
    net = Net(X.shape[1], 24, optimizer=optimizer, seed=seed)
    rng = np.random.default_rng(0)
    n, losses, val_accs = len(y), [], []

    for _ in range(epochs):
        idx = rng.permutation(n)
        for s in range(0, n, batch_size):
            b = idx[s:s + batch_size]
            net.forward(X[b])
            net.update(net.backward(y[b]), lr)

        net.forward(X)
        losses.append(net.loss(y))
        net.forward(Xv)
        val_accs.append(float(((net.A2.ravel() >= 0.5).astype(int) == yv).mean()))

    return net, np.array(losses), np.array(val_accs)


# ── ③ 자동 진단 ──
def diagnose(losses, baseline=np.log(2)):
    if not np.isfinite(losses).all() or losses[-1] > 100:
        return "발산 💥"
    if losses[-1] > baseline * 0.98:
        return "학습 안 됨"
    diffs = np.diff(losses)
    up_ratio = (diffs > 0).mean()
    if up_ratio > 0.30:
        return "진동 〰️"
    improve = (losses[0] - losses[-1]) / max(losses[0], 1e-9)
    if improve < 0.15:
        return "너무 느림 🐢"
    if losses[-1] < 0.15:
        return "잘 수렴 ✓"
    return "수렴 중"

**추가로 확인된 것 5가지**

**① 학습률의 "좋은 구간"은 대략 한 자릿수 폭입니다.**

```
0.0001 ~ 0.01  : 너무 느림
0.1 ~ 0.5      : ★ 좋음
1.0            : 진동
3.0 이상       : 발산
```

**로그 스케일로 탐색하세요.** 0.1씩 더하는 게 아니라 **10배씩 곱하며** 찾습니다.

**② 배치 크기와 학습률은 함께 움직입니다.**

```
batch=8   → lr 0.05~0.1 이 최적,  lr 1.0에서 발산
batch=512 → lr 0.5~1.0 이 최적,  lr 0.01은 너무 느림
```

**배치가 커지면 학습률도 키워야 합니다.** 큰 배치는 기울기가 평균화되어 안정적이기 때문입니다.

**③ 손실 증가율이 좋은 진단 지표입니다.**

```
증가율 < 10%   : 안정적
증가율 15~25%  : 정상 (미니배치는 원래 조금 흔들림)
증가율 > 35%   : 진동. lr을 낮출 것
```

**④ 총 반복 수가 실질 학습량입니다.**

```
lr=0.01, batch=512 → 반복 1,360회  → val_acc 0.511
lr=0.01, batch=8   → 반복 84,000회 → val_acc 0.908
```

**같은 에폭(80)인데 정확도가 0.4나 차이 납니다.**

**⑤ Adam이 SGD보다 초반 수렴이 훨씬 빠릅니다.**

```
10에폭 시점 손실
  SGD(0.1)      : 0.4128
  Momentum(0.05): 0.1214
  Adam(0.001)   : 0.1128
```

> **다만 최종 성능은 셋 다 0.96~0.98로 큰 차이가 없습니다.**
> **Adam의 진짜 장점은 "튜닝 없이도 잘 된다"** 는 것입니다.
> SGD는 lr을 0.01에서 0.5까지 옮겨야 최적을 찾았지만, Adam은 기본값이 이미 최적이었습니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 학습 | 손실을 줄이는 가중치를 **찾는 것** |
| 기울기 | 손실이 **커지는** 방향과 가파름 |
| 경사하강법 | `w ← w - lr × ∂L/∂w`. **기울기 반대로** |
| 학습률 | **가장 중요한 하이퍼파라미터.** 로그 스케일로 탐색 |
| lr 너무 작음 | 학습이 안 됨. 손실이 기준선 근처 |
| lr 너무 큼 | **진동 또는 발산** (`nan`) |
| 역전파 | **연쇄법칙**으로 오차를 뒤로 전달. 층마다 **곱셈** |
| 기울기 소실 | 그 곱셈이 0.25^n 이 되는 것 ([Day 082](day-082.md)) |
| 에폭 | 전체 데이터 1회 통과 |
| 반복 | 가중치 갱신 1회. **실질 학습량은 반복 수** |
| 배치 크기 | 기본 32. **크면 lr도 키워야** |
| SGD | 단순. 튜닝 필요 |
| **Adam** | **파라미터별 적응형 lr. 기본 선택 (lr=0.001)** |
| nan 대처 | **학습률부터 1/10로** |
| 기울기 검증 | 직접 구현 시 **수치미분과 대조 필수** |

**오늘 반드시 기억할 세 가지**
> ① **학습률은 로그 스케일로 탐색하세요.** 0.001 → 0.01 → 0.1 → 1.0. 좋은 구간은 좁습니다.
> ② **에폭 수가 아니라 반복 수가 학습량입니다.** 배치가 크면 같은 에폭이라도 훨씬 덜 학습합니다.
> ③ **손실이 `nan` 이면 학습률, 손실이 안 줄면 학습률 또는 구조.** 진단 순서를 외우세요.

**과제** — 학습률 실험 기록표를 작성하세요.

**필수 포함 항목**

| 항목 | 내용 |
|---|---|
| 1 | 학습률 **7단계 이상** (로그 스케일로: 0.0001 ~ 10) |
| 2 | 각 학습률의 **손실 곡선을 겹쳐 그린 그래프** (로그 y축) |
| 3 | **자동 진단 함수** — 발산 / 진동 / 수렴 / 너무 느림을 판정하는 기준과 코드 |
| 4 | 배치 크기 4종 추가 → **lr × batch 히트맵** |
| 5 | 옵티마이저 3종(SGD / Momentum / Adam) 비교, **각각 최적 lr로** |
| 6 | 실험 기록표 (번호 / 설정 / 초기손실 / 최종손실 / val_acc / 진단 / 관찰 / 다음 시도) |
| 7 | **결론** — 권장 설정과 근거, 그리고 왜 그 학습률 구간이 좋은지 설명 |
