## 2. 막히는 상황

어제 만든 RPG를 다시 보자.

```c
    // 몬스터 1
    printf("[1/3] %s 등장!\n", monsters[0].name);
    PrintStatus(monsters[0]);
    // ... 전투 처리 30줄 ...

    // 몬스터 2
    printf("[2/3] %s 등장!\n", monsters[1].name);
    PrintStatus(monsters[1]);
    // ... 전투 처리 30줄 (똑같은 코드) ...

    // 몬스터 3
    printf("[3/3] %s 등장!\n", monsters[2].name);
    PrintStatus(monsters[2]);
    // ... 전투 처리 30줄 (또 똑같은 코드) ...
```

그리고 전투가 한 번 끝나면 **프로그램이 종료된다.** "다시 하기"가 없다.

```
   지금:   시작 ─▶ 코드 ─▶ 코드 ─▶ 코드 ─▶ 끝
                    (한 번 지나가면 끝)

   필요:   시작 ─▶ ┌─▶ 코드 ─┐ ─▶ 끝
                    └────────┘
                    (조건이 만족될 때까지 계속 돈다)
```

> **같은 일을 반복시키는 방법이 필요하다.** → **반복문**
> 그리고 이 반복문이 앞으로 만들 모든 게임의 **게임 루프**가 된다.

## 3. 개념

### 3-1. `while` — 조건이 참인 동안 반복

**왜 필요한가** — "몇 번인지는 모르지만 조건이 유지되는 동안" 반복해야 할 때.

```c
while (조건)
{
    // 조건이 참인 동안 계속 실행
}
```

```
        ┌──────────────┐
        │   조건 검사   │◀───────┐
        └───┬──────┬───┘        │
       참   │      │  거짓       │
            ▼      ▼            │
      ┌─────────┐  루프 탈출     │
      │  본문   │───────────────┘
      └─────────┘
```

```c
int hp = 100;

while (hp > 0)              // hp가 0보다 큰 동안
{
    printf("HP: %d\n", hp);
    hp -= 30;               // ★ 조건을 바꾸는 코드가 반드시 있어야 한다
}
// 출력: 100, 70, 40, 10
```

> ### ⚠️ 조건을 바꾸는 코드가 없으면 영원히 돈다
>
> ```c
> while (hp > 0)
> {
>     printf("HP: %d\n", hp);     // hp를 안 바꾼다 → 무한 루프!
> }
> ```
>
> **무한 루프에 빠졌을 때 탈출** — 콘솔 창에서 **`Ctrl + C`**, 또는 Visual Studio의 **중지(■)** 버튼.

### 3-2. `for` — 횟수가 정해진 반복

**왜 필요한가** — "3번 반복", "배열 요소 전부 순회"처럼 횟수가 명확할 때.

```c
for (초기화; 조건; 증감)
{
    // 본문
}
```

```
   for (int i = 0; i < 3; i++)
         └──┬──┘  └──┬──┘  └┬┘
            │        │      └── ③ 본문 실행 후 매번
            │        └───────── ② 매 회 시작 전 검사
            └────────────────── ① 딱 한 번만

   실행 순서:  ① → ② → 본문 → ③ → ② → 본문 → ③ → ② → (거짓) → 끝
```

```c
for (int i = 0; i < 3; i++)
{
    printf("[%d/3] %s 등장!\n", i + 1, monsters[i].name);
}
// [1/3] 슬라임 등장!
// [2/3] 고블린 등장!
// [3/3] 드래곤 등장!
```

**어제 90줄이 이 3줄로 줄어든다.**

**반복 횟수 세는 법** — `i`는 관례적으로 0부터 시작한다 (배열 인덱스가 0부터라서).

| 표기 | 반복 횟수 | `i` 값 |
|---|:--:|---|
| `for (i = 0; i < 3; i++)` | 3번 | 0, 1, 2 |
| `for (i = 1; i <= 3; i++)` | 3번 | 1, 2, 3 |
| `for (i = 0; i <= 3; i++)` | **4번** | 0, 1, 2, 3 ← 실수 주의 |

### 3-3. `do-while` — 일단 한 번은 실행

**왜 필요한가** — "메뉴를 보여주고 → 입력받고 → 잘못됐으면 다시" 같은 흐름.

```c
do
{
    // 최소 한 번은 실행된다
} while (조건);          // ★ 세미콜론 필수
```

```
      ┌─────────┐
      │  본문   │◀───────┐
      └────┬────┘        │
           ▼             │
      ┌──────────┐  참   │
      │ 조건 검사 │──────┘
      └────┬─────┘
        거짓 │
           ▼
         탈출

   ★ while 과 달리 본문이 먼저 실행된다
```

```c
int choice;

do
{
    printf("선택 (1~3): ");
    scanf_s("%d", &choice);
} while (choice < 1 || choice > 3);      // 범위 밖이면 다시 입력
```

**세 반복문 비교**

| 반복문 | 언제 쓰나 | 본문 최소 실행 |
|---|---|:--:|
| `while` | 조건이 유지되는 동안 (횟수 모름) | 0번 |
| `for` | 횟수가 정해짐, 배열 순회 | 0번 |
| `do-while` | 일단 한 번은 해야 함 (메뉴, 재입력) | **1번** |

> 셋은 서로 바꿔 쓸 수 있다. **가장 의도가 잘 드러나는 것**을 고른다.

### 3-4. 중첩 반복문

**왜 필요한가** — 2차원을 다루려면 반복이 두 겹 필요하다. 미로 맵(Day 12)이 바로 이것이다.

```c
for (int y = 0; y < 3; y++)          // 바깥: 세로
{
    for (int x = 0; x < 5; x++)      // 안쪽: 가로
    {
        printf("*");
    }
    printf("\n");                    // 한 줄 끝나면 줄바꿈
}
```

```
   실행 순서

   y=0 →  x=0,1,2,3,4  →  줄바꿈       *****
   y=1 →  x=0,1,2,3,4  →  줄바꿈       *****
   y=2 →  x=0,1,2,3,4  →  줄바꿈       *****

   ★ 안쪽 루프가 다 돌아야 바깥 루프가 한 칸 나아간다
   ★ 총 실행 횟수 = 3 × 5 = 15번
```

**체력 바 그리기** — Day 5에서 미리 쓴 그 코드

```c
void PrintHpBar(int hp, int maxHp)
{
    int filled = hp * 10 / maxHp;

    printf("[");
    for (int i = 0; i < 10; i++)
        printf("%c", i < filled ? '#' : '-');
    printf("]");
}
// [#######---]
```

### 3-5. 게임 루프의 원형

**왜 필요한가** — 오늘 만드는 이 구조가 24주 내내 모습만 바뀌며 계속 나온다.

```
   ┌───────────────────────────────────────────────┐
   │  while (게임이 끝나지 않았다)                   │
   │    ├─ 화면 출력      "지금 상황은 이렇다"       │
   │    ├─ 입력 받기      "무엇을 하겠는가"          │
   │    ├─ 처리           "그 결과 이렇게 된다"      │
   │    └─ 종료 조건 확인  "끝났나?"                 │
   └───────────────────────────────────────────────┘
```

**이것이 나중에 어떻게 변하는지 미리 보기**

| 시점 | 형태 |
|---|---|
| **오늘 (Day 6)** | 입력을 **기다리는** 루프. 안 누르면 멈춰 있다 |
| Day 21 (알카노이드) | 입력을 **안 기다리는** 루프. `Sleep(16)`으로 초당 60회 |
| Day 38 (WINAPI) | `PeekMessage` + 델타 타임. 진짜 게임 루프 |
| Day 72 (Unity) | `Update()` — 엔진이 대신 돌려준다 |

> 오늘 만드는 루프와 Unity의 `Update()`는 **같은 것**이다. 형태만 다르다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 무한 루프에서 못 나옴 | 조건을 바꾸는 코드 없음 | `timeLeft--` 같은 코드 추가. 탈출은 `Ctrl + C` |
| 본문이 한 번도 실행 안 됨 | `while (조건);` — **조건 뒤 세미콜론** | 세미콜론 제거 |
| `for`가 한 번만 돎 | `for (i=0; i<3; i++);` — 세미콜론 | 제거 |
| 반복 횟수가 하나 많음/적음 | `<` 와 `<=` 혼동 | 0부터면 `<`, 1부터면 `<=` |
| 중첩 루프에서 줄바꿈이 안 됨 | `printf("\n")` 위치 | 안쪽 루프 **밖**, 바깥 루프 **안** |
| `i`가 루프 밖에서 안 보임 | `for (int i = ...)` 의 `i`는 루프 안에서만 유효 | 밖에서 쓰려면 루프 위에서 선언 |
| 화면이 너무 빨리 흘러감 | 출력이 많은 무한 루프 | 조건 확인. 필요하면 일시정지 추가 |
| 루프 안 변수가 매번 초기화됨 | 루프 안에서 선언 | 유지하려면 루프 **밖**에서 선언 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| `while` | 조건이 참인 동안 반복. **조건을 바꾸는 코드 필수** |
| `for` | 횟수가 정해진 반복. `초기화; 조건; 증감` |
| `do-while` | 일단 한 번은 실행. 메뉴·재입력에 적합 |
| 무한 루프 | `while(1)`. 게임 루프의 기본형. 탈출은 `Ctrl+C` |
| 중첩 반복문 | 2차원을 다룬다. 안쪽이 다 돌아야 바깥이 한 칸 |
| **게임 루프** | 출력 → 입력 → 처리 → 종료 확인의 반복 |

### 직접 해보기

| 난이도 | 과제 | 힌트 |
|:--:|---|---|
| ★ | 구구단 2단~9단을 중첩 `for`로 출력 | 바깥 `dan`, 안쪽 `i` |
| ★★ | 어제 RPG의 전투 전체를 `while`로 감싸 3판 2선승 만들기 | 승수를 세는 변수 필요 |
| ★★★ | 피라미드 모양 별 찍기 (`   *` / `  ***` / ` *****`) | 공백 루프 + 별 루프 두 개를 한 줄에 |
