## 3. 개념

### 3-1. 각도 단위 — 도와 라디안

**왜 필요한가** — `<cmath>`의 삼각함수는 라디안을 쓴다.

```
   도(degree)      한 바퀴 = 360도       사람이 쓰기 편하다
   라디안(radian)  한 바퀴 = 2π ≈ 6.283  수학·프로그래밍에서 쓴다
```

```
   변환

   라디안 = 도 × π / 180
   도     = 라디안 × 180 / π
```

| 도 | 라디안 | 비고 |
|:--:|:--:|---|
| 0° | 0 | |
| 30° | 0.5236 | π/6 |
| 45° | 0.7854 | π/4 |
| 60° | 1.0472 | π/3 |
| **90°** | **1.5708** | **π/2** |
| 180° | 3.1416 | π |
| 360° | 6.2832 | 2π |

```cpp
const double PI = 3.14159265358979323846;

inline double DegToRad(double deg) { return deg * PI / 180.0; }
inline double RadToDeg(double rad) { return rad * 180.0 / PI; }
```

```
   ★ 흔한 실수

   cos(45)      →  45 라디안 = 약 2578도  →  엉뚱한 값
   cos(DegToRad(45))  →  올바름
```

> **UI에는 도(degree)로 표시하고, 계산은 라디안으로 한다.**

### 3-2. `cos`과 `sin` — 방향을 좌표로

**왜 필요한가** — 오늘의 핵심.

```
   단위원 (반지름 1)

              90°
               │
               │(0, 1)
               │
   180° ───────┼─────── 0°
        (-1,0) │  (1,0)
               │
               │(0,-1)
              270°

   각도 θ 인 점의 좌표

   x = cos(θ)
   y = sin(θ)
```

| θ | cos(θ) | sin(θ) | 방향 |
|:--:|:--:|:--:|---|
| 0° | 1.000 | 0.000 | 오른쪽 |
| 30° | 0.866 | 0.500 | 오른쪽 위 |
| 45° | 0.707 | 0.707 | 대각선 |
| 60° | 0.500 | 0.866 | 위쪽에 가깝게 |
| 90° | 0.000 | 1.000 | 위 |
| 135° | -0.707 | 0.707 | 왼쪽 위 |
| 180° | -1.000 | 0.000 | 왼쪽 |

```
   ★ 외우는 법

   cos = x 성분 (가로)
   sin = y 성분 (세로)

   0도에서 cos=1, sin=0  →  오른쪽을 향한다
```

### 3-3. ⚠️ 화면 y축 반전

**왜 필요한가** — 이걸 놓치면 위로 쏘려는데 아래로 날아간다.

```
   수학 좌표계                  화면 좌표계

        y↑                       (0,0)─────▶ x
         │                         │
         │  45°                    │  ╲
         │ ╱                       │    ╲  45°
   ──────┼──────▶ x                │      ╲
         │                         ▼ y

   sin(45°) = +0.707             화면에서 +y 는 아래
   → 위로 간다                    → sin 을 그대로 쓰면 아래로 간다  ✘
```

```
   ★ 해결: y 성분에 음수

   vx =  cos(θ) × P
   vy = -sin(θ) × P        ★ 부호 반전
```

```
   검증

   θ = 90° (위로 쏘기)
     vx =  cos(90°) × 78 =   0
     vy = -sin(90°) × 78 = -78     ← 음수 = 화면에서 위  ✔

   θ = 0° (오른쪽)
     vx =  cos(0°) × 78 = +78      ← 오른쪽  ✔
     vy = -sin(0°) × 78 =   0
```

```
                90° (vy 최대 음수)
                 ↑
    135° ╲       │       ╱ 45°
           ╲     │     ╱
             ╲   │   ╱
   180° ───────▲───────── 0°
              포대

   ★ 포격 게임에서는 0° ~ 180° 만 쓴다 (위쪽 반원)
```

### 3-4. 발사 벡터 계산

**왜 필요한가** — 2절의 문제를 해결하는 코드.

```cpp
struct Vector2
{
    double x, y;
};

Vector2 CalcLaunchVelocity(double angleDeg, double power)
{
    double rad = DegToRad(angleDeg);

    Vector2 v;
    v.x =  cos(rad) * power;
    v.y = -sin(rad) * power;                   // ★ y축 반전

    return v;
}
```

```cpp
    // 사용
    Vector2 vel = CalcLaunchVelocity(45.0, 78.0);
    // vel.x = 55.15,  vel.y = -55.15

    shell->Launch(cannonX, cannonY, vel.x, vel.y);
```

**방향 반전 (왼쪽 포대)**

```cpp
    if (m_facingLeft)
        v.x = -v.x;                            // x만 뒤집는다
```

```
   각도 45도, 오른쪽 향함     각도 45도, 왼쪽 향함

        ╱                              ╲
      ╱                                  ╲
    ▲                                      ▲

   vx = +55                          vx = -55
   vy = -55                          vy = -55    (같다)
```

### 3-6. 각도 조절

```cpp
void Cannon::Update(double dt)
{
    Input& in = m_core->GetInput();

    double speed = ANGLE_SPEED;                // 초당 45도

    if (in.IsKeyPress(VK_SHIFT)) speed *= 0.25;   // ★ 미세 조정
```

### 3-7. 힘 충전

**왜 필요한가** — 각도와 함께 사거리를 결정하는 두 번째 변수.

```cpp
void Cannon::UpdatePower(double dt)
{
    Input& in = m_core->GetInput();

    if (in.IsKeyDown(VK_SPACE))
    {
        m_charging = true;
        m_power = MIN_POWER;
        m_chargeDir = 1;
    }

    if (m_charging && in.IsKeyPress(VK_SPACE))
    {
        m_power += CHARGE_SPEED * m_chargeDir * dt;

        // 최대치에서 되돌아온다 (선택)
        if (m_power >= MAX_POWER) { m_power = MAX_POWER; m_chargeDir = -1; }
        if (m_power <= MIN_POWER) { m_power = MIN_POWER; m_chargeDir = +1; }
    }

    if (m_charging && in.IsKeyUp(VK_SPACE))
    {
        Fire();
        m_charging = false;
    }
}
```

```
   ★ 두 가지 충전 방식

   ① 최대치에서 멈춤       →  누르고 있으면 항상 최대. 쉽다
   ② 최대치에서 되돌아옴   →  타이밍 필요. 긴장감  ★

   포트리스는 ②를 쓴다
```

```

   [████████████████░░░░]  power 80
```

### 3-8. 발사 방향 미리보기

**왜 필요한가** — 어디로 갈지 감이 와야 조준할 수 있다.

**방법 1 — 직선 (단순)**

```cpp
void RenderAimLine(Renderer& r, double x, double y,
                   double angleDeg, double power, bool facingLeft)
{
    Vector2 v = CalcLaunchVelocity(angleDeg, power);
    if (facingLeft) v.x = -v.x;

    double len = power * 1.5;                  // 힘에 비례한 길이

    double nx = v.x / power;                   // 정규화
    double ny = v.y / power;

    // 점선
    for (int i = 0; i < 12; i++)
    {
        double t = i / 12.0;
        int px = (int)(x + nx * len * t);
        int py = (int)(y + ny * len * t);

        r.DrawCircle(px, py, 2, RGB(255, 240, 120));
    }
}
```

**방법 2 — 실제 궤적 시뮬레이션 (내일)**

```

   내일 중력을 넣으면 포물선 미리보기로 바꾼다
```

### 3-9. 사거리 감각

**왜 필요한가** — 각도와 힘이 사거리에 어떻게 영향을 주는지 안다.

```
   물리 공식 (중력 g, 초기 속도 v, 각도 θ)

   사거리 R = v² × sin(2θ) / g

   ★ sin(2θ) 가 최대가 되는 것은 2θ = 90°  →  θ = 45°
   ★ 45도에서 사거리가 최대다
```

| 각도 | sin(2θ) | 상대 사거리 |
|:--:|:--:|:--:|
| 15° | 0.500 | 50% |
| 30° | 0.866 | 87% |
| **45°** | **1.000** | **100%** |
| 60° | 0.866 | 87% |
| 75° | 0.500 | 50% |

```
   ★ 30도와 60도의 사거리가 같다

   30도:  낮고 빠르게 (저탄도)
   60도:  높고 느리게 (곡사)

   → 장애물이 있으면 60도로 넘긴다
```

> **이 성질이 포격 게임의 전략을 만든다.** 내일 중력을 넣으면 확인할 수 있다.

```cpp
// Engine/MathUtil.h
#pragma once
#include <cmath>

const double PI = 3.14159265358979323846;

inline double DegToRad(double deg) { return deg * PI / 180.0; }
inline double RadToDeg(double rad) { return rad * 180.0 / PI; }

inline double Clamp(double v, double lo, double hi)
{
    return (v < lo) ? lo : (v > hi) ? hi : v;
}

struct Vector2
{
    double x, y;

    double Length() const { return sqrt(x*x + y*y); }

    void Normalize()
    {
        double len = Length();
        if (len > 0.0001) { x /= len; y /= len; }
    }
};
```

**검증 테스트**

```cpp
void TestAngleConversion()
{
    struct Case { double deg; double expCos, expSin; };

    Case cases[] = {
        {   0,  1.000,  0.000 },
        {  30,  0.866,  0.500 },
        {  45,  0.707,  0.707 },
        {  60,  0.500,  0.866 },
        {  90,  0.000,  1.000 },
        { 180, -1.000,  0.000 },
    };

    for (auto& c : cases)
    {
        double rad = DegToRad(c.deg);
        double cs = cos(rad), sn = sin(rad);

        bool ok = (fabs(cs - c.expCos) < 0.01) && (fabs(sn - c.expSin) < 0.01);

        DebugLog("%s  %5.0f°  cos=%+.3f sin=%+.3f\n",
                 ok ? "OK  " : "FAIL", c.deg, cs, sn);
    }
}
```

```cpp
                m_trail[m_trailCount].y = m_y;

            else
            {
                for (int i = 0; i < TRAIL_MAX - 1; i++)
                    m_trail[i] = m_trail[i + 1];
                m_trail[TRAIL_MAX-1] = { m_x, m_y };

    {

            r.DrawCircle((int)m_trail[i].x, (int)m_trail[i].y, 1, RGB(b, b, b));
        }

        // 포탄
        r.DrawCircle((int)m_x, (int)m_y, 5, RGB(60, 60, 70));
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 방향이 완전히 이상함 | 도를 라디안으로 안 바꿈 | `DegToRad` |
| 위아래가 반대 | y축 반전 누락 | `vy = -sin(θ) × P` |
| 포신이 반대로 돎 | 회전 기준점 오류 | 포대 중심 기준 |
| 왼쪽 향할 때 이상 | `vy`도 반전 | **`vx`만** 반전 |
| 포탄이 포대 안에서 나옴 | 포신 끝 계산 누락 | `muzzle` 좌표 |
| 각도가 계속 돎 | 범위 제한 없음 | 0~180 클램프 |
| 힘이 안 멈춤 | 최대치 처리 | `MAX_POWER` 검사 |
| 조준선이 짧음/김 | 길이 계산 | 힘에 비례 |
| `cos`/`sin` 오류 | `<cmath>` 누락 | 포함 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| 도 vs 라디안 | `<cmath>`는 **라디안**. UI는 도로 표시 |
| **`cos` = x, `sin` = y** | 단위원 위의 점 좌표 |
| **y축 반전** | 화면은 y가 아래로. `vy = -sin(θ) × P` |
| 발사 벡터 | `vx = cos(θ)×P`, `vy = -sin(θ)×P` |
| 포신 회전 | 극좌표 → 직교좌표 변환 |
| 방향 반전 | **`vx`만** 뒤집는다 |
| 미세 조정 | Shift로 느리게. 포격 게임 필수 |
| 힘 충전 | 최대치에서 되돌아오면 긴장감 |
| 45도 최대 사거리 | `R = v²sin(2θ)/g` |
