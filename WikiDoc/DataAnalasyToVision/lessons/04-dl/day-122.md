## ③ 개념 설명

### K-Fold 교차검증

```python
from sklearn.model_selection import KFold

cv = KFold(n_splits=5, shuffle=True, random_state=42)
```

| 파라미터 | 의미 |
|---|---|
| `n_splits` | 폴드 수 (K) |
| **`shuffle`** | 나누기 전에 섞을지. **True 권장** |
| `random_state` | `shuffle=True` 일 때 필수 |

> ⚠️ **`shuffle=False`(기본값)면 데이터 순서대로 자릅니다.**
> 데이터가 정렬되어 있으면 각 폴드가 편향됩니다.
> **시계열이 아니라면 `shuffle=True` 를 쓰세요.**

### K를 몇으로 할 것인가

| K | 학습 비율 | 특징 | 언제 |
|---|---|---|---|
| 3 | 67% | 빠름. 추정 불안정 | 매우 느린 모델 |
| **5** | **80%** | **표준** | **대부분** |
| 10 | 90% | 안정적. 2배 느림 | 데이터가 적을 때 |
| n (LOO) | (n-1)/n | 최대 활용. 매우 느림 | 데이터가 극히 적을 때 |

**K가 클수록**

```
장점: 학습 데이터가 많아짐 → 추정 편향(bias) 감소
단점: 폴드 간 학습셋이 비슷해짐 → 추정 분산(variance) 증가, K배 느림
```

> **K=5가 대부분의 경우 최선입니다.**
> 데이터가 1,000행 미만이면 K=10을 검토하세요.

### 회귀에서의 계층 분할 교차검증

**분류에는 `StratifiedKFold` 가 있습니다. 회귀에는 없습니다.**

```python
# 타깃을 구간화한 뒤 StratifiedKFold 사용
from sklearn.model_selection import StratifiedKFold

y_bins = pd.qcut(y, q=10, labels=False, duplicates="drop")
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

for tr, va in cv.split(X, y_bins):     # ★ y가 아니라 y_bins로 분할
    ...
```

**직접 쓸 수 있는 함수로 만들어 두면 편합니다.**

```python
def stratified_kfold_regression(X, y, n_splits=5, q=10, random_state=42):
    y_bins = pd.qcut(pd.Series(y), q=q, labels=False, duplicates="drop")
    cv = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=random_state)
    return list(cv.split(X, y_bins))
```

### `cross_val_score` vs `cross_validate`

```python
from sklearn.model_selection import cross_val_score, cross_validate

# 단일 지표
scores = cross_val_score(pipe, X, y, cv=cv, scoring="neg_mean_absolute_error")

# 여러 지표 + 학습 점수 + 시간
res = cross_validate(pipe, X, y, cv=cv,
                     scoring=["neg_mean_absolute_error", "neg_root_mean_squared_error", "r2"],
                     return_train_score=True, return_estimator=True, n_jobs=-1)
```

| 반환 키 | 내용 |
|---|---|
| `test_<지표>` | 각 폴드의 검증 점수 |
| `train_<지표>` | 각 폴드의 학습 점수 (`return_train_score=True`) |
| `fit_time` / `score_time` | 시간 |
| `estimator` | 각 폴드의 학습된 모델 (`return_estimator=True`) |

> **`cross_validate` 를 기본으로 쓰세요.** 학습 점수까지 나와야 [Day 117](day-117.md)의 격차 진단이 됩니다.

### ⚠️ `scoring` 의 부호 규칙

**sklearn은 "클수록 좋다"로 통일합니다.**

```python
scoring="neg_mean_absolute_error"      # MAE에 음수를 붙임
scores = cross_val_score(...)          # [-0.31, -0.29, -0.33, ...]
mae = -scores.mean()                   # ★ 부호를 되돌려야 함
```

| 지표 | `scoring` 문자열 | 부호 |
|---|---|---|
| MAE | `"neg_mean_absolute_error"` | **음수** |
| MSE | `"neg_mean_squared_error"` | **음수** |
| RMSE | `"neg_root_mean_squared_error"` | **음수** |
| MAPE | `"neg_mean_absolute_percentage_error"` | **음수** |
| R² | `"r2"` | 양수 |

**사용자 정의 지표**

```python
from sklearn.metrics import make_scorer

def wape(y, p):
    return np.sum(np.abs(y - p)) / np.sum(np.abs(y)) * 100

wape_scorer = make_scorer(wape, greater_is_better=False)
```

### 평균과 표준편차를 함께

```python
print(f"{-scores.mean():.4f} ± {scores.std():.4f}")
```

**표준편차가 말해 주는 것**

| 표준편차 | 의미 |
|---|---|
| 작음 (평균의 5% 미만) | 안정적. 데이터가 균질 |
| 중간 (5~15%) | 보통 |
| **큼 (15% 초과)** | **데이터가 작거나 이질적.** 추정을 못 믿음 |

**두 모델 비교**

```
모델 A: 0.3061 ± 0.0041
모델 B: 0.3195 ± 0.0184

차이 0.0134
B의 표준편차 0.0184 > 차이
→ 단순 비교로는 구분 불가
```

> **[Day 120](day-120.md)의 쌍체 비교를 교차검증에도 적용하세요.**
> **같은 폴드에서의 차이**를 보면 훨씬 민감합니다.

### 반복 교차검증 (Repeated K-Fold)

```python
from sklearn.model_selection import RepeatedKFold

cv = RepeatedKFold(n_splits=5, n_repeats=3, random_state=42)
# 5-fold를 서로 다른 분할로 3번 → 총 15개 점수
```

| 방법 | 점수 수 | 시간 |
|---|---|---|
| 5-Fold | 5 | 1× |
| 10-Fold | 10 | 2× |
| **5-Fold × 3회 반복** | **15** | **3×** |
| 5-Fold × 10회 반복 | 50 | 10× |

**반복이 K를 늘리는 것보다 나은 경우가 많습니다.**

```
10-Fold : 학습셋 90%. 폴드 간 학습셋이 매우 비슷 → 점수들이 상관됨
5-Fold×2: 분할 자체가 다름 → 더 독립적인 정보
```

### ★ 교차검증 안에서 전처리하기

```python
# ✗ 누수
X_scaled = StandardScaler().fit_transform(X)
cross_val_score(model, X_scaled, y, cv=5)
```

```
전체 데이터로 스케일러를 fit
→ 각 폴드의 "검증 부분" 통계가 이미 들어감
→ 점수가 낙관적으로 부풀려짐
```

```python
# ✓ 안전
pipe = make_pipeline(StandardScaler(), model)
cross_val_score(pipe, X, y, cv=5)
```

```
폴드마다 학습 부분으로만 스케일러를 새로 fit
→ 누수 없음
```

**전처리 종류별 부풀림 정도** ([Day 114](day-114.md) Step 6 재확인)

| 전처리 | 홀드아웃 부풀림 | 교차검증 부풀림 |
|---|---|---|
| `StandardScaler` | ~0% | ~0% |
| `MinMaxScaler` | 0.1% | 작음 |
| 이상치 절단 | 0.6% | 작음 |
| **`TargetEncoder`** | **큼** | **매우 큼** |
| **`SelectKBest`** | **9.5%** | **매우 큼** |
| **SMOTE / 증강** | 매우 큼 | **매우 큼** |

> **교차검증에서는 부풀림이 더 커집니다.**
> 각 폴드의 검증 부분이 **여러 번** 학습에 관여하기 때문입니다.

### 딥러닝에서의 현실적 타협

```
신경망 학습 30초 × 5 폴드 = 150초
하이퍼파라미터 20조합 × 150초 = 50분
seed 3회 반복 × 50분 = 2.5시간
```

**대형 모델이면 며칠이 됩니다.**

| 타협안 | 설명 | 언제 |
|---|---|---|
| **홀드아웃으로 탐색 → 최종 후보만 CV** | 가장 실용적 | **기본** |
| K를 3으로 | 40% 절약 | 시간이 매우 부족 |
| 데이터 부분집합으로 탐색 | 빠른 스크리닝 | 조합이 매우 많을 때 |
| **에폭 수를 줄여 탐색** | 순위만 보면 됨 | 학습률·구조 탐색 |
| seed 반복으로 대체 | 홀드아웃 × seed 5 | CV보다 싸고 비슷한 효과 |

> **이 과정에서는 "홀드아웃으로 탐색 → 최종 3후보만 CV"를 표준으로 씁니다.**
> [Day 130](day-130.md)에서 그대로 적용합니다.

### 교차검증으로 최종 모델 만들기

**교차검증은 성능을 "추정"할 뿐, 모델을 만들지 않습니다.**

```
5-Fold → 5개의 모델이 생김
→ 어느 것을 배포할 것인가?
```

**세 가지 선택지**

| 방법 | 설명 | 권장 |
|---|---|---|
| **전체 데이터로 재학습** | CV로 설정만 정하고 다시 학습 | **✓ 표준** |
| 5개 모델의 앙상블 | 예측을 평균 | 성능 조금 좋음. 5배 무거움 |
| 최고 폴드의 모델 | 한 폴드만 선택 | ✗ **비권장** (운) |

```python
# ① CV로 하이퍼파라미터 결정
scores = cross_validate(pipe, X_dev, y_dev, cv=cv)

# ② 전체 개발 데이터로 재학습
final = pipe.fit(X_dev, y_dev)

# ③ 테스트셋 1회 평가 (Day 125)
```

## ④ 단계별 실습

### Step 1. 홀드아웃의 한계 재확인

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_california_housing
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import KFold, train_test_split

SEED = 42
np.random.seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

y_bins = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)

print("=" * 88)
print("홀드아웃 vs 교차검증 — 추정의 안정성")
print("=" * 88)

sizes = [400, 1500, 5000, len(X_dev)]
rows = []

for n in sizes:
    idx = np.random.default_rng(0).choice(len(X_dev), size=n, replace=False)
    Xs, ys = X_dev.iloc[idx], y_dev.iloc[idx]

    # ── 홀드아웃 20회 ──
    hold = []
    for s in range(20):
        Xtr, Xva, ytr, yva = train_test_split(Xs, ys, test_size=0.25, random_state=s)
        m = HistGradientBoostingRegressor(max_iter=200, random_state=SEED).fit(Xtr, ytr)
        hold.append(mean_absolute_error(yva, m.predict(Xva)))

    # ── 5-Fold CV 4회 (분할 seed 4개) ──
    cvs = []
    for s in range(4):
        cv = KFold(n_splits=5, shuffle=True, random_state=s)
        fold = []
        for tr, va in cv.split(Xs):
            m = HistGradientBoostingRegressor(max_iter=200,
                                              random_state=SEED).fit(Xs.iloc[tr], ys.iloc[tr])
            fold.append(mean_absolute_error(ys.iloc[va], m.predict(Xs.iloc[va])))
        cvs.append(np.mean(fold))

    hold, cvs = np.array(hold), np.array(cvs)
    rows.append({
        "샘플 수": n,
        "홀드아웃 평균": round(hold.mean(), 4),
        "홀드아웃 표준편차": round(hold.std(), 4),
        "홀드아웃 변동폭": round(hold.max() - hold.min(), 4),
        "CV 평균": round(cvs.mean(), 4),
        "CV 표준편차": round(cvs.std(), 4),
        "CV 변동폭": round(cvs.max() - cvs.min(), 4),
        "표준편차 비": round(cvs.std() / max(hold.std(), 1e-12), 3),
    })

res = pd.DataFrame(rows)
print(res.to_string(index=False))
print("=" * 88)
print("★ 'CV 표준편차'는 분할 seed를 바꿨을 때 CV 평균이 얼마나 흔들리는가입니다.")
print("  홀드아웃 표준편차의 30~45% 수준으로 훨씬 안정적입니다.")

for _, r in res.iterrows():
    print(f"\n  샘플 {int(r['샘플 수']):>6,}행")
    print(f"    홀드아웃 : {r['홀드아웃 평균']:.4f} ± {r['홀드아웃 표준편차']:.4f}  "
          f"(변동폭 {r['홀드아웃 변동폭']:.4f})")
    print(f"    5-Fold CV: {r['CV 평균']:.4f} ± {r['CV 표준편차']:.4f}  "
          f"(변동폭 {r['CV 변동폭']:.4f})")
    print(f"    → 추정 안정성 {1/r['표준편차 비']:.1f}배 향상")

# ── 그래프 ──
fig, axes = plt.subplots(1, 2, figsize=(15, 5.5))

ax = axes[0]
ax.plot(res["샘플 수"], res["홀드아웃 표준편차"], "o-", linewidth=2.5,
        markersize=9, label="holdout")
ax.plot(res["샘플 수"], res["CV 표준편차"], "s-", linewidth=2.5,
        markersize=9, label="5-fold CV")
ax.set_xscale("log"); ax.set_yscale("log")
ax.set_xlabel("samples (log)"); ax.set_ylabel("std of MAE estimate (log)")
```

```python
import numpy as np
import pandas as pd
from sklearn.compose import TransformedTargetRegressor
from sklearn.ensemble import HistGradientBoostingRegressor, RandomForestRegressor
from sklearn.linear_model import RidgeCV
from sklearn.metrics import make_scorer
from sklearn.model_selection import KFold, StratifiedKFold, cross_validate
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

SEED = 42


def wape(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.sum(np.abs(y - p)) / np.sum(np.abs(y)) * 100)


SCORING = {
    "MAE": "neg_mean_absolute_error",
    "RMSE": "neg_root_mean_squared_error",
    "R2": "r2",
    "MAPE": "neg_mean_absolute_percentage_error",
    "WAPE": make_scorer(wape, greater_is_better=False),
}


def stratified_cv_regression(y, n_splits=5, q=10, random_state=SEED):
    """회귀용 계층 교차검증 — 타깃 구간으로 stratify"""
    yb = pd.qcut(pd.Series(np.asarray(y)), q=q, labels=False, duplicates="drop")
    skf = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=random_state)
    return list(skf.split(np.zeros(len(yb)), yb))


CANDIDATES = {
    "릿지": TransformedTargetRegressor(
        regressor=Pipeline([("sc", StandardScaler()),
                            ("m", RidgeCV(alphas=np.logspace(-3, 3, 30)))]),
        func=np.log1p, inverse_func=np.expm1),
    "랜덤포레스트": TransformedTargetRegressor(
        regressor=RandomForestRegressor(n_estimators=300, random_state=SEED, n_jobs=-1),
        func=np.log1p, inverse_func=np.expm1),
    "HistGB": TransformedTargetRegressor(
        regressor=HistGradientBoostingRegressor(max_iter=300, random_state=SEED),
        func=np.log1p, inverse_func=np.expm1),
}

cv_splits = stratified_cv_regression(y_dev, n_splits=5)

print("=" * 108)
print("5-Fold 교차검증 (계층 분할) — 여러 지표 동시 평가")
print("=" * 108)

all_fold_scores = {}
rows = []
for name, model in CANDIDATES.items():
    res = cross_validate(model, X_dev, y_dev, cv=cv_splits, scoring=SCORING,
                         return_train_score=True, n_jobs=-1)
    all_fold_scores[name] = {k: -res[f"test_{k}"] if k != "R2" else res["test_R2"]
                             for k in SCORING}

    row = {"모델": name}
    for k in SCORING:
        sign = 1 if k == "R2" else -1
        v = sign * res[f"test_{k}"]
        row[f"{k}"] = f"{v.mean():.4f} ± {v.std():.4f}"
    tr_mae = -res["train_MAE"]
    te_mae = -res["test_MAE"]
    row["격차"] = round(float(te_mae.mean() - tr_mae.mean()), 4)
    row["학습(s)"] = round(float(res["fit_time"].mean()), 2)
    row["총 시간(s)"] = round(float(res["fit_time"].sum() + res["score_time"].sum()), 2)
    rows.append(row)

print(pd.DataFrame(rows).to_string(index=False))
print("=" * 108)

# ── 폴드별 상세 ──
print("\n[폴드별 MAE]")
fold_df = pd.DataFrame({name: s["MAE"] for name, s in all_fold_scores.items()})
fold_df.index = [f"Fold {i+1}" for i in range(len(fold_df))]
fold_df.loc["평균"] = fold_df.mean()
fold_df.loc["표준편차"] = fold_df.iloc[:-1].std()
fold_df.loc["변동률(%)"] = fold_df.loc["표준편차"] / fold_df.loc["평균"] * 100
print(fold_df.round(4).to_string())

print("\n★ 폴드별로 성능이 다릅니다. 어느 폴드가 유독 어렵다면")
print("  그 폴드에 무엇이 들어 있는지 확인할 가치가 있습니다.")

# ── 부호 규칙 확인 ──
print("\n" + "=" * 72)
print("⚠ scoring 부호 규칙")
print("=" * 72)
demo = cross_validate(CANDIDATES["HistGB"], X_dev, y_dev, cv=cv_splits[:2],
                      scoring="neg_mean_absolute_error")
print(f"  cross_validate 원본 : {demo['test_score'].round(4)}")
print(f"  부호를 되돌린 값     : {(-demo['test_score']).round(4)}")
print("  ★ 'neg_' 로 시작하는 scoring은 반드시 부호를 되돌려야 합니다.")
print("=" * 72)
```

```python
import time

import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import KFold, train_test_split
from sklearn.preprocessing import StandardScaler

SEED = 42


def train_nn_fold(Xtr, ytr, Xva, yva, epochs=200, units=(128, 64, 32),
                  lr=3e-4, seed=SEED):
    sc = StandardScaler().fit(Xtr)
    tf.random.set_seed(seed)
    m = keras.Sequential([layers.Input(shape=(Xtr.shape[1],))])
    for u in units:
        m.add(layers.Dense(u, activation="relu"))
        m.add(layers.Dropout(0.2))
    m.add(layers.Dense(1))
    m.compile(optimizer=keras.optimizers.Adam(lr), loss="mse", metrics=["mae"])
    es = keras.callbacks.EarlyStopping(monitor="val_loss", patience=20,
                                       restore_best_weights=True)
    m.fit(sc.transform(Xtr), np.log1p(ytr),
          validation_data=(sc.transform(Xva), np.log1p(yva)),
          epochs=epochs, batch_size=64, callbacks=[es], verbose=0)
    return mean_absolute_error(yva, np.expm1(m.predict(sc.transform(Xva), verbose=0).ravel()))
```

### Step 7. 오늘의 종합 — 교차검증 비교표

```python
from pathlib import Path

import numpy as np
import pandas as pd
from itertools import combinations
from sklearn.base import clone
from sklearn.metrics import (mean_absolute_error, mean_absolute_percentage_error,
                             mean_squared_error, r2_score)
from sklearn.model_selection import RepeatedStratifiedKFold, StratifiedKFold

SEED = 42
ROOT = Path("dl_course/day122")
ROOT.mkdir(parents=True, exist_ok=True)


def cv_compare(models, X, y, n_splits=5, n_repeats=3, q=10, random_state=SEED):
    """모델들을 같은 폴드에서 평가하고 쌍체 비교까지"""
    yb = pd.qcut(pd.Series(np.asarray(y)), q=q, labels=False, duplicates="drop")
    rskf = RepeatedStratifiedKFold(n_splits=n_splits, n_repeats=n_repeats,
                                   random_state=random_state)
    splits = list(rskf.split(np.zeros(len(yb)), yb))

    metrics = {}
    for name in models:
        metrics[name] = {"MAE": [], "RMSE": [], "R2": [], "MAPE": [],
                         "train_MAE": []}

    for tr, va in splits:
        Xtr, Xva = X.iloc[tr], X.iloc[va]
        ytr, yva = y.iloc[tr], y.iloc[va]
        for name, model in models.items():
            m = clone(model).fit(Xtr, ytr)
            p = m.predict(Xva)
            ptr = m.predict(Xtr)
            metrics[name]["MAE"].append(mean_absolute_error(yva, p))
            metrics[name]["RMSE"].append(float(np.sqrt(mean_squared_error(yva, p))))
            metrics[name]["R2"].append(r2_score(yva, p))
            metrics[name]["MAPE"].append(
                mean_absolute_percentage_error(yva, p) * 100)
            metrics[name]["train_MAE"].append(mean_absolute_error(ytr, ptr))

    # ── 요약표 ──
    rows = []
    for name in models:
        m = metrics[name]
        row = {"모델": name, "폴드 수": len(splits)}
        for k in ["MAE", "RMSE", "R2", "MAPE"]:
            v = np.array(m[k])
            row[k] = f"{v.mean():.4f} ± {v.std(ddof=1):.4f}"
            row[f"{k}_평균"] = round(float(v.mean()), 5)
            row[f"{k}_표준오차"] = round(float(v.std(ddof=1) / np.sqrt(len(v))), 5)
        row["격차"] = round(float(np.mean(m["MAE"]) - np.mean(m["train_MAE"])), 4)
        row["변동률(%)"] = round(float(np.std(m["MAE"], ddof=1) /
                                    np.mean(m["MAE"]) * 100), 2)
        rows.append(row)
    summary = pd.DataFrame(rows)

    # ── 쌍체 비교 ──
    pairs = []
    for a, b in combinations(models, 2):
        da = np.array(metrics[a]["MAE"])
        db = np.array(metrics[b]["MAE"])
        diff = da - db
        se = diff.std(ddof=1) / np.sqrt(len(diff))
        t = abs(diff.mean()) / se if se > 0 else np.inf
        pairs.append({
            "A": a, "B": b,
            "평균차이": round(float(diff.mean()), 5),
            "표준오차": round(float(se), 5),
            "t비": round(float(t), 2),
            "A승률(%)": round(float((diff < 0).mean() * 100), 1),
            "판정": "★ 유의미" if t > 3 else "경계" if t > 2 else "동등",
        })
    return summary, pd.DataFrame(pairs), metrics


summary, pairs, raw = cv_compare(CANDIDATES, X_dev, y_dev,

show_cols = ["모델", "폴드 수", "MAE", "RMSE", "R2", "MAPE", "격차", "변동률(%)"]
```

**고친 코드**

```python
import numpy as np
import pandas as pd
from itertools import combinations
from sklearn.base import clone
from sklearn.ensemble import RandomForestRegressor
from sklearn.feature_selection import SelectKBest, f_regression
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import (RepeatedStratifiedKFold, train_test_split)
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

SEED = 42

# ═══ 수정 3: 테스트셋 분리 (CV에는 개발 데이터만) ═══
y_bins_all = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test = train_test_split(
    X_all, y_all, test_size=0.2, random_state=SEED, stratify=y_bins_all)

# ═══ 수정 1·2: 전처리를 Pipeline 안으로 ═══
def make_pipe(model):
    return Pipeline([
        ("scale", StandardScaler()),
        ("select", SelectKBest(f_regression, k=20)),
        ("model", model),
    ])

models = {
    "Ridge": make_pipe(RidgeCV(alphas=np.logspace(-3, 3, 30))),
    "RF": make_pipe(RandomForestRegressor(n_estimators=300,
                                          random_state=SEED, n_jobs=-1)),   # 수정 8
}

# ═══ 수정 4·5·9: 계층 분할 + shuffle + 폴드 재사용 ═══
y_bins = pd.qcut(y_dev, q=10, labels=False, duplicates="drop")
rskf = RepeatedStratifiedKFold(n_splits=5, n_repeats=3, random_state=SEED)
splits = list(rskf.split(np.zeros(len(y_bins)), y_bins))     # ★ 한 번 만들어 재사용

# ═══ 수정 6·7·11: 부호·표준편차·쌍체 비교 ═══
fold_scores = {name: [] for name in models}

for tr, va in splits:
    Xtr, Xva = X_dev.iloc[tr], X_dev.iloc[va]
    ytr, yva = y_dev.iloc[tr], y_dev.iloc[va]
    for name, pipe in models.items():
        m = clone(pipe).fit(Xtr, ytr)
        fold_scores[name].append(mean_absolute_error(yva, m.predict(Xva)))

print("=" * 76)
print(f"교차검증 결과 — 5-Fold × 3회 = {len(splits)} 폴드 (계층 분할)")
print("=" * 76)
for name, s in fold_scores.items():
    s = np.array(s)
    print(f"  {name:<8} MAE {s.mean():.4f} ± {s.std(ddof=1):.4f}   "
          f"(표준오차 {s.std(ddof=1)/np.sqrt(len(s)):.5f})")
print("-" * 76)

# ═══ 수정 11: 쌍체 비교로 판정 ═══
for a, b in combinations(models, 2):
    diff = np.array(fold_scores[a]) - np.array(fold_scores[b])
    se = diff.std(ddof=1) / np.sqrt(len(diff))
    t = abs(diff.mean()) / se if se > 0 else np.inf
    win_a = (diff < 0).mean() * 100
    verdict = "★ 유의미" if t > 3 else "경계" if t > 2 else "동등"
    print(f"  {a} vs {b}: 차이 {diff.mean():+.4f} ± {diff.std(ddof=1):.4f}  "
          f"t={t:.2f}  {a} 승률 {win_a:.0f}%  → {verdict}")
print("=" * 76)

# ── 결론 ──
means = {n: np.mean(s) for n, s in fold_scores.items()}
best = min(means, key=means.get)
second = sorted(means, key=means.get)[1]
diff = np.array(fold_scores[best]) - np.array(fold_scores[second])
t = abs(diff.mean()) / (diff.std(ddof=1) / np.sqrt(len(diff)))

if t > 3:
    print(f"\n결론: {best}가 통계적으로 유의미하게 낫습니다 (t={t:.2f}).")
else:
    print(f"\n결론: 두 모델은 동등합니다 (t={t:.2f}).")
    print("      다른 기준(속도·해석성·단순성)으로 결정하세요. (Day 120)")

print("\n★ 테스트셋은 아직 열지 않았습니다. (Day 125에서 1회)")
```

| `neg_` scoring | **부호를 되돌려야 함** |
