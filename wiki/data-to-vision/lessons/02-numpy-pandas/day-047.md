## ② 왜 필요한가

**데이터를 받으면 가장 먼저 해야 할 일이 있습니다.**

```python
df = pd.read_csv("data.csv")
df.head()          # 이것만 보고 분석을 시작하면 안 됩니다
```

`head()` 는 앞 5행만 보여 줍니다. **그 아래에 무엇이 있는지 모릅니다.**

| 확인 안 하면 | 나중에 생기는 일 |
|---|---|
| 결측치 | 평균이 이상하게 나옴 |
| 자료형 | 숫자인 줄 알았는데 문자열 |
| 중복 | 같은 데이터를 두 번 셈 |
| 이상치 | 평균이 왜곡됨 |
| 고유값 개수 | 범주형인지 연속형인지 판단 불가 |

**"첫 5분 루틴"** 을 만들어 두면 이런 사고를 막을 수 있습니다.

그리고 **`loc` / `iloc`** 은 pandas 에서 가장 헷갈리는 부분입니다.
둘을 혼동하면 **에러 없이 엉뚱한 행을 가져옵니다.**

## ③ 개념 설명

### 첫 5분 루틴

```python
df.shape           # ① 크기
df.head()          # ② 앞 5행
df.tail()          # ③ 뒤 5행 (합계 행 같은 게 있나)
df.info()          # ④ 자료형 + 결측 + 메모리
df.describe()      # ⑤ 수치형 기초 통계
df.isna().sum()    # ⑥ 열별 결측 개수
df.nunique()       # ⑦ 열별 고유값 개수
df.duplicated().sum()  # ⑧ 중복 행 개수
```

**각각이 알려 주는 것**

| 함수 | 확인할 것 |
|---|---|
| `shape` | 데이터가 예상한 크기인가 |
| `head/tail` | 헤더가 제대로 읽혔나, 이상한 행이 있나 |
| `info` | **숫자여야 할 열이 `object` 는 아닌가** |
| `describe` | 최솟값이 음수는 아닌가, 최댓값이 비현실적이지 않은가 |
| `isna().sum()` | 어느 열에 결측이 몰려 있나 |
| `nunique` | 고유값 1개(쓸모없음) 또는 전부 다름(ID) |
| `duplicated` | 수집 과정에서 중복이 생겼나 |

**읽는 법**

| 신호 | 의심할 것 |
|---|---|
| `count` 가 행 수보다 작음 | 결측 |
| `mean` ≫ `50%` | 오른쪽 꼬리 (이상치) |
| `min` 이 음수인데 나이·가격 | 잘못된 값 |
| `max` 가 비현실적 | 이상치 또는 단위 오류 |
| `std` 가 0 | 모든 값이 같음 (쓸모없는 열) |

### 열 선택

```python
df["score"]                    # Series
df[["score"]]                  # DataFrame (대괄호 2개!)
df[["name", "score"]]          # 여러 열 → DataFrame
```

| 표기 | 결과 | 언제 |
|---|---|---|
| `df["a"]` | **Series** (1차원) | 값 계산 |
| `df[["a"]]` | **DataFrame** (2차원) | 표 유지 |
| `df[["a","b"]]` | DataFrame | 여러 열 |

> **머신러닝에서 중요합니다.** 입력 `X` 는 2차원이어야 하므로 `df[["feature"]]` 를 씁니다.
> `df["feature"]` 는 1차원이라 에러가 납니다.

### 행 선택 — loc vs iloc

**이것이 오늘의 핵심입니다.**

| | `loc` | `iloc` |
|---|---|---|
| 기준 | **레이블(이름)** | **위치(정수)** |
| 끝 포함 | ✅ **포함** | ❌ 미포함 |
| 예 | `df.loc["a":"c"]` | `df.iloc[0:3]` |

```python
df = pd.DataFrame(
    {"score": [85, 92, 78]},
    index=["홍길동", "김철수", "이영희"],
)

df.loc["김철수"]         # 92
df.iloc[1]               # 92     같은 결과, 다른 방식

df.loc["홍길동":"이영희"]  # 3행 (끝 포함!)
df.iloc[0:2]             # 2행 (끝 미포함)
```

**행과 열을 동시에**

```python
df.loc[행_레이블, 열_이름]
df.iloc[행_위치, 열_위치]
```

```python
df.loc["김철수", "score"]        # 92
df.iloc[1, 0]                    # 92

df.loc[:, "score"]               # 모든 행의 score 열
df.iloc[:, 0]                    # 모든 행의 0번 열

df.loc[["홍길동", "이영희"], ["score"]]
df.iloc[[0, 2], [0]]
```

### 인덱스가 정수일 때 — 가장 헷갈리는 경우

```python
df = pd.DataFrame(
    {"score": [85, 92, 78]},
    index=[10, 20, 30],          # 인덱스가 정수!
)

df.loc[10]        # 85     인덱스 '10' 인 행
df.iloc[10]       # IndexError!  10번째 위치가 없음

df.loc[0]         # KeyError!    인덱스 '0' 이 없음
df.iloc[0]        # 85     0번째 위치
```

> ⚠️ **필터링 후 인덱스가 뒤죽박죽일 때 특히 위험합니다.**
> ```python
> filtered = df[df["score"] > 80]      # 인덱스가 0, 3, 7, 12... 처럼 남음
> filtered.iloc[0]                      # 첫 번째 행  ✅
> filtered.loc[0]                       # 인덱스 0인 행 — 없으면 KeyError
> ```
> **필터링 후에는 `reset_index(drop=True)`** 를 습관적으로 쓰면 헷갈리지 않습니다.

### 값 하나만 빠르게 — at / iat

```python
df.at["김철수", "score"]      # loc 의 단일 값 버전 (더 빠름)
df.iat[1, 0]                  # iloc 의 단일 값 버전
```

> 반복문 안에서 값 하나씩 접근할 때만 의미가 있습니다. 평소엔 `loc`/`iloc` 로 충분합니다.

### 유용한 조회 함수

```python
df.head(10)              # 앞 10행
df.tail(3)               # 뒤 3행
df.sample(5)             # 무작위 5행
df.sample(5, random_state=42)   # 재현 가능

df["stage"].value_counts(normalize=True)  # 비율
df["name"].unique()                      # 고유값 목록
df["name"].nunique()                     # 고유값 개수

df.columns.tolist()      # 열 이름 리스트
df.dtypes                # 열별 자료형
df.memory_usage(deep=True).sum()   # 메모리
```

```python
import numpy as np
import pandas as pd

# ── 실습용 데이터 (일부러 문제를 넣음) ──
rng = np.random.default_rng(42)
n = 300

df = pd.DataFrame({
    "id": np.arange(1, n + 1),
    "name": rng.choice(["홍길동", "김철수", "이영희", "박민수", "최지우"], n),
    "region": rng.choice(["서울", "부산", "대구", "인천"], n, p=[.4, .25, .2, .15]),
    "score": rng.integers(40, 101, n).astype(float),
    "price": [f"{v:,}" for v in rng.integers(1000, 50000, n)],   # 문자열!
    "date": pd.Timestamp("2026-01-01") + pd.to_timedelta(rng.integers(0, 180, n), unit="D"),
    "grade": "A",                                                 # 전부 같은 값
})

# 결측 넣기
df.loc[rng.choice(n, 15, replace=False), "score"] = np.nan
# 중복 행 넣기
df = pd.concat([df, df.iloc[:5]], ignore_index=True)
# 이상치 넣기
df.loc[0, "score"] = 9999

print("=" * 70)
print("                  첫 5분 루틴")
print("=" * 70)

# ── ① shape ──
print(f"\n① shape: {df.shape}   (행 {df.shape[0]:,}, 열 {df.shape[1]})")

# ── ② head ──
print(f"\n② head(3)")
print(df.head(3).to_string(index=False))

# ── ③ tail ──
print(f"\n③ tail(3)")
print(df.tail(3).to_string(index=False))

# ── ④ info ──
print(f"\n④ info()")
df.info()

# ── ⑤ describe ──
print(f"\n⑤ describe() — 수치형")
print(df.describe().round(1).to_string())

print(f"\n   describe(include='object') — 문자열")
print(df.describe(include="object").to_string())

# ── ⑥ 결측 ──
print(f"\n⑥ 결측치")
na = pd.DataFrame({
    "결측 수": df.isna().sum(),
    "비율(%)": (df.isna().mean() * 100).round(1),
})
print(na[na["결측 수"] > 0].to_string())
print(f"   결측이 있는 행: {df.isna().any(axis=1).sum()}건")

# ── ⑦ 고유값 ──
print(f"\n⑦ 고유값 개수")
uniq = pd.DataFrame({
    "고유값": df.nunique(),
    "dtype": df.dtypes.astype(str),
})
print(uniq.to_string())
print(f"   ⚠ 'grade' 는 고유값이 1개 — 정보가 없는 열입니다")
print(f"   ⚠ 'id' 는 고유값이 행 수와 같음 — 식별자입니다")

# ── ⑧ 중복 ──
print(f"\n⑧ 중복")
print(f"   완전 중복 행: {df.duplicated().sum()}건")
print(f"   id 중복:      {df.duplicated(subset=['id']).sum()}건")

# ── ⑨ 발견한 문제 정리 ──
print("\n" + "=" * 70)
print("[발견한 문제]")
print("  1. score 에 결측 15건 (5.0%)")
print("  2. score 최댓값 9999 — 이상치")
print("  3. price 가 object — '1,234' 형태 문자열")
print("  4. grade 는 고유값 1개 — 삭제 대상")
```

### Step 2. loc 과 iloc 완전 정복

```python
import pandas as pd

df = pd.DataFrame({
    "score": [85, 92, 78, 88, 95],
    "stage": [3, 5, 2, 4, 5],
}, index=["홍길동", "김철수", "이영희", "박민수", "최지우"])

print("=" * 60)
print("                loc vs iloc")
print("=" * 60)
print(f"\n{df.to_string()}")

# ── 단일 행 ──
print(f"\n[단일 행]")
print(f"  df.loc['김철수']   → score={df.loc['김철수', 'score']}, "
      f"stage={df.loc['김철수', 'stage']}")
print(f"  df.iloc[1]        → score={df.iloc[1, 0]}, stage={df.iloc[1, 1]}")
print(f"  같은 행입니다 (김철수는 1번째 위치)")

# ── 슬라이싱 — 끝 포함 여부가 다름! ──
print(f"\n[슬라이싱 — 결정적 차이]")
print(f"  df.loc['홍길동':'이영희']  → {len(df.loc['홍길동':'이영희'])}행 (끝 포함)")
print(df.loc["홍길동":"이영희"].to_string())

print(f"\n  df.iloc[0:2]              → {len(df.iloc[0:2])}행 (끝 미포함)")
print(df.iloc[0:2].to_string())

# ── 행 + 열 ──
print(f"\n[행 + 열 동시 선택]")
print(f"  df.loc['김철수':'박민수', 'score']")
print(df.loc["김철수":"박민수", "score"].to_string())

print(f"\n  df.iloc[1:4, 0]")
print(df.iloc[1:4, 0].to_string())

# ── 리스트로 선택 ──
print(f"\n[리스트로 선택]")
print(f"  df.loc[['홍길동','최지우'], ['score']]")
print(df.loc[["홍길동", "최지우"], ["score"]].to_string())

print(f"\n  df.iloc[[0, 4], [0]]")
print(df.iloc[[0, 4], [0]].to_string())

# ══════════ 정수 인덱스의 함정 ══════════
print("\n" + "=" * 60)
print("        정수 인덱스일 때의 함정")
print("=" * 60)

df2 = pd.DataFrame({"score": [85, 92, 78]}, index=[10, 20, 30])
print(f"\n{df2.to_string()}")

print(f"\n  df2.loc[10]  = {df2.loc[10, 'score']}   ← 인덱스가 10인 행")
print(f"  df2.iloc[0]  = {df2.iloc[0, 'score' == 'score']}   ← 0번째 위치")

for expr, func in [("df2.loc[0]", lambda: df2.loc[0]),
                   ("df2.iloc[10]", lambda: df2.iloc[10])]:
    try:
        func()
    except (KeyError, IndexError) as e:
        print(f"  {expr:<14} → {type(e).__name__}: 인덱스/위치 {e}"[:70])

# ══════════ 필터링 후 인덱스 문제 ══════════
print("\n" + "=" * 60)
```

```python
import pandas as pd


def explore(df, name="데이터", max_categories=8):
    """
    DataFrame 을 한 번에 진단합니다.

    확인 항목: 크기 · 자료형 · 결측 · 고유값 · 중복 · 통계 · 범주 분포 · 경고
    """
    line = "=" * 78

    print(line)
    print(f"  {name} 진단")
    print(line)

    # ── ① 크기 ──
    print(f"\n[크기]")
    print(f"  행 {df.shape[0]:,} × 열 {df.shape[1]}")
    print(f"  메모리 {df.memory_usage(deep=True).sum() / 1024**2:.2f} MB")

    # ── ② 열 요약 ──
    print(f"\n[열 요약]")
    summary = pd.DataFrame({
        "dtype": df.dtypes.astype(str),
        "결측": df.isna().sum(),
        "결측%": (df.isna().mean() * 100).round(1),
        "고유값": df.nunique(),
        "예시": [
            df[c].dropna().iloc[0] if df[c].notna().any() else "-"
            for c in df.columns
        ],
    })
    print(summary.to_string())

    # ── ③ 중복 ──
    dup = df.duplicated().sum()
    print(f"\n[중복] 완전 중복 행 {dup}건 ({dup / len(df) * 100:.1f}%)")

    # ── ④ 수치형 통계 ──
    num = df.select_dtypes(include="number")
    if not num.empty:
        print(f"\n[수치형 통계]")
        print(num.describe().round(2).to_string())

    # ── ⑤ 범주형 분포 ──
    cat = df.select_dtypes(include=["object", "category"])
    if not cat.empty:
        print(f"\n[범주형 분포]")
        for col in cat.columns:
            n_uniq = df[col].nunique()
            print(f"\n  {col}  (고유값 {n_uniq}개)")

            if n_uniq > 50:
                print(f"    고유값이 많아 생략 (예: {df[col].dropna().iloc[0]})")
                continue

            vc = df[col].value_counts(dropna=False).head(max_categories)
            for value, count in vc.items():
                bar = "■" * max(int(count / vc.max() * 22), 0)
                label = "(결측)" if pd.isna(value) else str(value)
                print(f"    {label:<14}{bar:<24}{count:>6,} ({count/len(df)*100:>5.1f}%)")

            if n_uniq > max_categories:
                print(f"    ... 외 {n_uniq - max_categories}개")

    # ── ⑥ 자동 경고 ──
    warnings = []

    for col in df.columns:
        na_pct = df[col].isna().mean() * 100
        if na_pct > 50:
            warnings.append(f"'{col}' 결측 {na_pct:.0f}% — 삭제 검토")
        elif na_pct > 0:
            warnings.append(f"'{col}' 결측 {na_pct:.1f}% — 처리 필요")

        if df[col].nunique() == 1:
            warnings.append(f"'{col}' 고유값 1개 — 정보 없음, 삭제 대상")

        if df[col].nunique() == len(df) and df[col].dtype != "object":
            warnings.append(f"'{col}' 모든 값이 다름 — 식별자(ID)로 보임")

    if dup > 0:
        warnings.append(f"완전 중복 행 {dup}건 — drop_duplicates() 검토")

    # 숫자여야 할 것 같은 object 열
    for col in df.select_dtypes(include="object").columns:
        sample = df[col].dropna().astype(str).head(50)
        if sample.str.replace(r"[,\s원%]", "", regex=True).str.match(
                r"^-?\d+\.?\d*$").mean() > 0.8:
            warnings.append(f"'{col}' 이 문자열이지만 숫자로 보임 — 변환 검토")

    # 이상치 의심 (평균과 중앙값 차이)
    for col in num.columns:
        m, med = df[col].mean(), df[col].median()
        if med != 0 and abs(m - med) / abs(med) > 0.5:
            warnings.append(f"'{col}' 평균({m:,.0f})과 중앙값({med:,.0f}) 차이 큼 — 이상치 의심")

    print(f"\n[자동 경고] {len(warnings)}건")
    if warnings:
        for w in warnings:
            print(f"  ⚠ {w}")
    else:
        print(f"  발견된 문제 없음")

    print("\n" + line)
    return summary


# ══════════ 사용 ══════════
if __name__ == "__main__":
    import numpy as np

    rng = np.random.default_rng(42)
    n = 200

    test = pd.DataFrame({
        "id": range(1, n + 1),
        "name": rng.choice(["A", "B", "C"], n),
        "price": [f"{v:,}원" for v in rng.integers(1000, 99999, n)],
        "score": rng.integers(0, 101, n).astype(float),
        "grade": "표준",
        "note": [None] * n,
    })
    test.loc[rng.choice(n, 30, replace=False), "score"] = np.nan
    test.loc[0, "score"] = 99999
    test = pd.concat([test, test.iloc[:3]], ignore_index=True)

    explore(test, "테스트 데이터")
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 첫 5분 루틴 | `shape` → `head/tail` → **`info`** → `describe` → `isna().sum()` → `nunique` → `duplicated` |
| `info()` | 결측·자료형 확인 — **숫자가 `object` 면 문제** |
| `describe()` | **`mean` 과 `50%` 차이**가 크면 이상치 |
| 열 선택 | `df["a"]` Series · **`df[["a"]]` DataFrame** |
| **`loc`** | 레이블 기준 · **끝 포함** |
| **`iloc`** | 위치 기준 · 끝 미포함 |
| 필터링 후 | **`reset_index(drop=True)`** 습관화 |
| `value_counts()` | 범주 분포 · `dropna=False` 로 결측 포함 |
| 자료형별 선택 | `select_dtypes(include="number")` |

**오늘 반드시 기억할 세 가지**
> ① `head()` 만 보고 시작하지 마세요. **`info()` 와 `describe()` 를 반드시** 확인합니다.
> ② **`loc` 은 레이블·끝 포함, `iloc` 은 위치·끝 미포함**입니다.
> ③ 필터링·정렬 후에는 **`reset_index(drop=True)`**.
