## 자주 나오는 질문

| 질문 | 답 |
|---|---|
| 노트북(.ipynb)으로 하면 안 되나요? | 탐색은 노트북으로 해도 됩니다. 단 **제출물은 항상 스크립트·패키지**입니다. 서비스는 노트북으로 배포할 수 없기 때문입니다. |
| 크롤링하다 차단당했어요 | 요청 간격 없이 반복 호출했을 가능성이 큽니다. 간격·User-Agent·robots.txt 준수는 기능이 아니라 필수 요건입니다 ([Day 018](day-018.md)). |
| 판다스가 메모리 에러를 냅니다 | 파일 전체를 한 번에 읽고 있기 때문입니다. chunksize와 dtype 최적화부터 적용하세요 ([Day 026](day-026.md)). |
| Git 명령이 아직 헷갈립니다 | 이 과정에서는 add/commit/push만 매일 반복하면 됩니다. 원리는 W22([Day 106](../05-infra-mlops/day-106.md))에서 정리합니다. |
