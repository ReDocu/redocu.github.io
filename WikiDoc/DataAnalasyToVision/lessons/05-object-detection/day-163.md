## ③ 개념 설명

### 웹에서 실시간 영상을 보여주는 5가지 방법

브라우저는 원래 **문서를 한 번 받고 끝나는** 구조입니다. 영상처럼 **끝나지 않는 데이터**를 보내려면 별도의 방법이 필요합니다.

| # | 방식 | 지연 | 대역폭 | 구현 난이도 | 브라우저 지원 | 서버 라이브러리 |
|---|---|---|---|---|---|---|
| ① | **MJPEG multipart** | **0.1~0.3 s** | **큼** (10~30 Mbps) | **매우 낮음** | 전부 (`<img>`) | **불필요** |
| ② | HLS | 6~30 s | 작음 (2~5 Mbps) | 높음 | Safari 기본 / hls.js | ffmpeg |
| ③ | **WebRTC** | **0.05~0.2 s** | **작음** | **매우 높음** | 전부 (JS 필요) | aiortc · SFU |
| ④ | WebSocket + base64 | 0.1~0.4 s | 큼 (+33%) | 중간 | 전부 (JS 필요) | flask-sock |
| ⑤ | 주기적 폴링 | 0.5~2 s | 중간 | 매우 낮음 | 전부 | 불필요 |

**① MJPEG — 한 연결로 JPEG 을 계속 밀어 넣기**

```
브라우저                              서버
   │  GET /video_feed                  │
   │──────────────────────────────────>│
   │  200 · Content-Type: multipart/    │  cap.read() → 추론 → imencode
   │        x-mixed-replace;boundary=…  │
   │<──────────────────────────────────│
   │  --frame  JPEG#1 (95 KB)          │  ★ <img> 가 화면을 교체
   │<──────────────────────────────────│
   │  --frame  JPEG#2 (94 KB)          │     또 교체
   │<──────────────────────────────────│
   │           탭을 닫을 때까지 계속     │

★ 브라우저 쪽 코드는 <img src="/video_feed"> 한 줄. JS 도 필요 없습니다.
```

**② HLS** — 영상을 6초짜리 조각(`.ts`)과 목차(`.m3u8`)로 만들어 내려받습니다. CDN·화질 자동 조절·수만 명 동시 시청이 되지만, **조각이 완성돼야 보낼 수 있어 최소 3조각 = 약 18초 지연**입니다. 유튜브 라이브가 이 방식이고, **CCTV 에는 부적합**합니다.

**③ WebRTC** — 브라우저끼리 P2P(UDP)로 직결합니다. **지연 50~200 ms 로 가장 빠르고** H.264 압축으로 대역폭도 최소입니다. 대신 **시그널링 서버(SDP)·ICE/STUN/TURN·코덱 협상**이 필요합니다. 회사 제품이면 정답이지만 **5일짜리 수업에서 만들 것은 아닙니다.**

**④ WebSocket + base64** — `ws.send(base64.b64encode(buf).decode())` 로 보내고 클라이언트가 `img.src = "data:image/jpeg;base64," + e.data` 로 그립니다. 양방향이 되지만 **base64 는 3바이트를 4문자로 바꿔 크기가 33% 늘어납니다**(95 KB → 127 KB). 라이브러리와 JS 가 필수입니다.

**⑤ 주기적 폴링** — `setInterval(() => img.src = "/snapshot?t=" + Date.now(), 500)`. 10줄이면 되고 서버가 상태를 안 가집니다. **갱신이 느려도 되는 화면**([Day 164](day-164.md)의 최근 이벤트 썸네일)에는 지금도 씁니다.

### ★ 왜 우리는 MJPEG 인가

| 조건 | MJPEG | HLS | WebRTC | WS | 폴링 |
|---|---|---|---|---|---|
| 지연 1초 이내 | ✓ | ✗ | ✓ | ✓ | △ |
| 추가 라이브러리 없음 | ✓ | ✗ | ✗ | ✗ | ✓ |
| JS 없이 동작 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 로컬망 대역폭 | ✓ | ✓ | ✓ | △ | ✓ |
| 서버 코드 20줄 | ✓ | ✗ | ✗ | △ | ✓ |
| **합계** | **5/5** | 1/5 | 2/5 | 2/5 | 3/5 |

우리의 제약은 **수업 시간 안에 동작 · 로컬망 전용([Day 154](day-154.md)) · 지연 1초 이내 · 오디오 불필요 · 시청자 3~5명** 입니다. MJPEG 이 정확히 여기에 맞습니다.

**★ 단점도 정확히 알아야 합니다**

```
① ★ 대역폭이 큽니다 — 프레임 간 압축이 없습니다 (I-프레임만)
   720p/q80/15 FPS = ★ 11.4 Mbps   (H.264 라면 같은 화질이 2 Mbps)
② ★ 오디오를 섞을 수 없습니다
③    연결 하나당 스트림 하나
   브라우저는 같은 호스트에 동시 연결 6개 (HTTP/1.1)
④    시크·일시정지 불가 — "라이브" 그 자체
⑤    서버가 상태를 가집니다 — 연결마다 제너레이터가 살아 있음
```

> ⚠️ **③은 실제로 자주 겪습니다.** 카메라 4대 화면 + 썸네일 2개면 6개를 다 씁니다.
> 그러면 **CSS/JS 가 로드되지 않아 페이지가 반쯤 깨진 채로 멈춥니다.**
> 대응: **서버가 4분할 합성한 단일 스트림**, 또는 HTTP/2.

### `multipart/x-mixed-replace` 프로토콜 해부

이 헤더 하나가 브라우저에게 **"다음 조각으로 화면을 교체해라"** 라고 말합니다. 1995년 넷스케이프가 만든 기능이지만 지금도 모든 브라우저가 지원합니다.

```
HTTP/1.1 200 OK\r\n
Content-Type: multipart/x-mixed-replace; boundary=frame\r\n   ← ★ 경계 선언
Cache-Control: no-cache, no-store\r\n
\r\n                                                          ← 헤더 끝
                                      ↓ 여기부터 본문이 무한히 이어집니다
--frame\r\n                                                   ← ★ 경계 (-- 두 개)
Content-Type: image/jpeg\r\n
Content-Length: 97382\r\n
\r\n
\xff\xd8\xff\xe0\x00\x10JFIF ....(97,382 바이트)....\xff\xd9
\r\n                                                          ←    파트 끝 개행
--frame\r\n                                                   ← 다음 파트
Content-Type: image/jpeg\r\n
Content-Length: 96911\r\n
\r\n
\xff\xd8\xff\xe0 ....(96,911 바이트)....\xff\xd9
\r\n
--frame\r\n
   ...     끝없이 반복  ...
```

| 요소 | 값 | 필수 | 틀리면 |
|---|---|---|---|
| `Content-Type` | `multipart/x-mixed-replace; boundary=frame` | 필수 | 다운로드되거나 첫 장만 |
| 경계선 | `--` + boundary + `\r\n` | 필수 | 파싱 실패 → 검은 화면 |
| 파트 헤더 | `Content-Type: image/jpeg` | 필수 | 종류를 모름 |
| `Content-Length` | 바이트 수 | 권장 | 경계 탐색으로 처리 (느림·오탐) |
| 헤더-본문 구분 | 빈 줄 `\r\n` | 필수 | 헤더가 이미지에 섞임 |
| 파트 끝 | `\r\n` | 필수 | 다음 경계를 못 찾음 |

```python
def make_part(jpeg: bytes, boundary: bytes = b"frame") -> bytes:
    """★ multipart 한 조각을 바이트로 조립"""
    return (b"--" + boundary + b"\r\n"
            b"Content-Type: image/jpeg\r\n"
            b"Content-Length: " + str(len(jpeg)).encode() + b"\r\n"
            b"\r\n" + jpeg + b"\r\n")
```

> ⚠️ **`\n` 이 아니라 `\r\n` 입니다.** HTTP 의 줄바꿈은 CRLF 입니다.
> `\n` 만 쓰면 크롬은 관대하게 넘어가지만 **사파리·안드로이드 웹뷰에서 화면이 안 나옵니다.**
> 또한 boundary 문자열이 JPEG 안에 우연히 들어갈 수 있는데,
> **`Content-Length` 를 붙이면** 브라우저가 길이만큼만 읽으므로 그 문제가 사라집니다.

```
★ 브라우저의 처리
  ① <img> 가 GET /video_feed → ② Content-Type 확인
  ③ 파트를 완전히 받으면 → 디코딩 → 화면 교체 →    이전 것 폐기
  ④ ②로 (무한)

★ 이전 프레임을 쌓지 않습니다 (replace 의 의미)
★ 브라우저가 느리면 프레임을 스스로 버립니다 (TCP 흐름 제어)
```

### 제너레이터와 `Response`

Flask 에서 **끝나지 않는 응답**을 만드는 방법은 **제너레이터를 `Response` 에 넣는 것**입니다.

```python
@app.route("/hello")
def hello():
    return "안녕하세요"          # ★ 응답 완성 → 연결 종료


def gen_forever():
    while True:                 # 끝나지 않음
        yield b"--frame\r\n..."
        time.sleep(0.03)

@app.route("/video_feed")
def video_feed():
    return Response(gen_forever(),
                    mimetype="multipart/x-mixed-replace; boundary=frame")
```

```
[요청 도착]
   │ video_feed() 호출
   │   → gen_forever() 를 ★ 호출만 함 (아직 한 줄도 실행 안 됨)
   │   → 제너레이터 ★ 객체 생성 → Response 반환
   │   → ★ video_feed 함수는 여기서 끝납니다
   ↓
[WSGI 서버가 헤더 전송 후 제너레이터를 for 로 돌기 시작]
   │   next() → yield 까지 실행 → 바이트를 소켓에 write → 반복
   ↓
[클라이언트가 탭을 닫음]
   │   소켓 write 실패 → 서버가 gen.close()
   │   → yield 지점에서 GeneratorExit 발생
   ↓
[finally 로 정리]
```

| 상황 | 무슨 일이 일어나는가 |
|---|---|
| `return` / 함수 끝 | `StopIteration` → 정상 종료 |
| 탭 닫기 | 소켓 끊김 → `gen.close()` → **`GeneratorExit`** |
| 새로고침 | 이전 연결 종료 + 새 연결 (잠깐 2개 공존) |
| 서버 예외 | 응답 중간에 끊김 |
| `Ctrl+C` | 데몬 스레드는 정리 없이 죽음 → `atexit` 필요 |

```python
def gen(subscriber):
    try:
        while True:
            yield make_part(subscriber.get())
    except GeneratorExit:
        app.logger.info("스트림 종료 (클라이언트 이탈)")
        raise                                # ★ 다시 올려야 정상 종료
    finally:
        hub.unsubscribe(subscriber)          # 반드시 실행됨
```

```
★ 이걸 안 하면
  탭을 10번 열었다 닫으면 → 구독자 목록에 ★ 죽은 구독자 10개
  → 허브가 계속 그들에게 프레임을 보냄 →    메모리 누수 + CPU 낭비
```

> ⚠️ **`except GeneratorExit:` 안에서 `yield` 하면 `RuntimeError` 입니다.**
> `generator ignored GeneratorExit`. 정리만 하고 **`raise`** 하세요.

**★ `request` 는 제너레이터 안에서 쓸 수 없습니다**

```python
@app.route("/video_feed")
def video_feed():
    skip = request.args.get("skip", type=int, default=1)   # ★ 여기서 읽고
    return Response(gen(skip), mimetype=MIME)              # 인자로 전달
```

```
★ 이유
  video_feed() 가 반환하는 순간 ★ 요청 컨텍스트가 사라집니다
```

```python
class LatestFrameCapture:
    """★ 별도 스레드로 계속 읽어 최신 프레임만 유지"""

    def __init__(self, source, width=None, height=None):
        self.cap = cv2.VideoCapture(source)
        self.cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
        if width:
            self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, width)
        if height:
            self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)
        self._frame = None
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self._t = threading.Thread(target=self._reader, daemon=True)
        self._t.start()

    def _reader(self):
        while not self._stop.is_set():
            ok, f = self.cap.read()
            if not ok:
                time.sleep(0.01)
                continue
            with self._lock:
                self._frame = f            # 항상 덮어씀

    def read(self):
        with self._lock:
            return None if self._frame is None else self._frame.copy()

    def release(self):
        self._stop.set()
        self._t.join(timeout=1)
        self.cap.release()
```

```python
class FpsMeter:
    """★ 최근 N회의 간격으로 FPS 를 계산 (이동평균)"""

    def __init__(self, window=30):
        self.times = deque(maxlen=window)      # 자동으로 오래된 것 버림
        self.last = None

    def tick(self):
        now = time.perf_counter()
        if self.last is not None:
            self.times.append(now - self.last)
        self.last = now

    @property
    def fps(self):
        if not self.times:
            return 0.0
        avg = sum(self.times) / len(self.times)
        return 1.0 / avg if avg > 0 else 0.0
```

### Step 1. `web/services/stream_service.py` — 단일 캡처 + 구독자 관리

```python
"""web/services/stream_service.py — 실시간 스트리밍 허브

  [캡처 스레드]  cap.read() 를 카메라 속도로 계속 → 최신 프레임만 유지
        ↓
  [추론 스레드]  최신 프레임 → predict → draw → imencode (각 1회)
        ↓
  [구독자들]     각자 maxsize=1 큐로 최신 JPEG 을 받음

   소스 하나당 허브 하나. 접속이 몇 개든 카메라·추론·인코딩은 각 1회.
"""
from __future__ import annotations

import atexit, logging, queue, sys, threading, time
from collections import deque
from pathlib import Path

import cv2
import numpy as np

log = logging.getLogger(__name__)
FONT = cv2.FONT_HERSHEY_SIMPLEX

DEFAULTS = {
    "width": 1280, "height": 720, "cap_fps": 30, "jpeg_quality": 80,
    "skip": 1,              # N프레임 건너뛰고 추론 (0 = 매 프레임)
    "imgsz": 640,           # 추론 해상도
    "conf": 0.45, "iou": 0.70, "draw": True,
    "loop": True,           # 파일일 때 반복 재생
    "idle_timeout": 30.0,   # 구독자 0명이 이만큼 지속되면 카메라 닫기
}


class Meter:
    """★ 이동평균 — FPS(tick) 와 구간시간(add) 둘 다"""

    def __init__(self, window=30):
        self._v = deque(maxlen=window)
        self._last = None

    def tick(self):
        now = time.perf_counter()
        if self._last is not None:
            self._v.append(now - self._last)
        self._last = now

    def add(self, ms):
        self._v.append(ms)

    def reset(self):
        self._v.clear()
        self._last = None

    @property
    def fps(self):
        avg = sum(self._v) / len(self._v) if self._v else 0
        return round(1.0 / avg, 1) if avg > 1e-9 else 0.0

    @property
    def ms(self):
        return round(sum(self._v) / len(self._v), 1) if self._v else 0.0


def pick_backend(source):
    """★ 플랫폼별 백엔드 자동 선택"""
    if isinstance(source, int):
        if sys.platform.startswith("win"):
            return cv2.CAP_DSHOW          # open 빠름 · set 잘 먹음
        if sys.platform.startswith("linux"):
            return cv2.CAP_V4L2           # Linux · 라즈베리파이
        return cv2.CAP_ANY
    return cv2.CAP_FFMPEG                 # 파일 · RTSP


class LatestFrameCapture:
    """★ 별도 스레드로 계속 읽어 최신 프레임만 유지 ([Day 153](day-153.md))

    카메라 — 버퍼 지연을 없앤다 / 파일 — 원본 FPS 로 페이싱하고 반복 재생
    """

    def __init__(self, source, width=None, height=None, fps=None, loop=True):
        self.source = source
        self.is_file = not isinstance(source, int)
        self.loop = loop and self.is_file
        self.backend = pick_backend(source)
        self.cap = cv2.VideoCapture(source, self.backend)
        if not self.cap.isOpened():
            raise RuntimeError(f"영상 소스를 열 수 없습니다: {source!r}")

        if not self.is_file:
            # 순서 중요: FOURCC → 해상도 → FPS → 버퍼
            self.cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*"MJPG"))
            if width:
                self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, width)
            if height:
                self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)
            if fps:
                self.cap.set(cv2.CAP_PROP_FPS, fps)
        self.cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)   # 백엔드가 무시할 수 있음

        # 요청과 실제가 다를 수 있으므로 되읽는다
        self.width = int(self.cap.get(cv2.CAP_PROP_FRAME_WIDTH))
        self.height = int(self.cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
        self.src_fps = float(self.cap.get(cv2.CAP_PROP_FPS)) or 30.0
        if not 1.0 <= self.src_fps <= 240.0:
            self.src_fps = 30.0
        self.total_frames = int(self.cap.get(cv2.CAP_PROP_FRAME_COUNT))

        self._frame, self._frame_id, self._err = None, 0, None
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self.meter = Meter(30)
        self._t = threading.Thread(target=self._reader, daemon=True,
                                   name=f"cap-{source}")
        self._t.start()

        deadline = time.perf_counter() + 3.0       # 첫 프레임을 기다린다
        while self._frame is None and time.perf_counter() < deadline:
            if self._err:
                raise RuntimeError(f"캡처 실패: {self._err}")
            time.sleep(0.01)
        if self._frame is None:
            self.release()
            raise RuntimeError(f"첫 프레임을 받지 못했습니다: {source!r}")
        log.info("캡처 시작 source=%r %dx%d @%.1f FPS",
                 source, self.width, self.height, self.src_fps)

    def _rewind(self):
        """파일을 처음으로 — 시크 실패 시 재열기"""
        try:
            if self.cap.set(cv2.CAP_PROP_POS_FRAMES, 0) and self.cap.read()[0]:
                self.cap.set(cv2.CAP_PROP_POS_FRAMES, 0)
                return True
        except cv2.error:
            pass
        log.info("시크 실패 — 파일을 다시 엽니다")
        self.cap.release()
        self.cap = cv2.VideoCapture(self.source, self.backend)
        return self.cap.isOpened()

    def _reader(self):
        interval = 1.0 / self.src_fps if self.is_file else 0.0
        next_t, fails = time.perf_counter(), 0
        while not self._stop.is_set():
            ok, f = self.cap.read()
            if not ok:
                if self.is_file:
                    if self.loop and self._rewind():
                        next_t = time.perf_counter()
                        continue
                    self._err = "end_of_file"
                    break
                fails += 1                      # 카메라는 일시적 실패 가능
                if fails > 150:                 # 약 5초
                    self._err = "camera_lost"
                    log.error("카메라 연결이 끊겼습니다")
                    break
                time.sleep(0.03)
                continue

            fails = 0
            with self._lock:
                self._frame = f                 # 항상 덮어씀
                self._frame_id += 1
            self.meter.tick()

            if self.is_file:                    # 원본 속도로 페이싱 (누적 보정)
                next_t += interval
                sleep = next_t - time.perf_counter()
                if sleep > 0:
                    time.sleep(sleep)
                elif sleep < -0.5:              # 너무 밀리면 리셋
                    next_t = time.perf_counter()

    def read(self):
        """(프레임 복사본, 프레임 번호)"""
        with self._lock:
            if self._frame is None:
                return None, 0
            return self._frame.copy(), self._frame_id      # 복사 필수

    @property
    def alive(self):
        return self._t.is_alive() and self._err is None

    @property
    def error(self):
        return self._err

    def release(self):
        self._stop.set()
        if self._t.is_alive():
            self._t.join(timeout=1.5)
        try:
            self.cap.release()
        except Exception:
            pass
        log.info("캡처 해제 source=%r", self.source)

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.release()
        return False


class Subscriber:
    """구독자 하나 — 최신 JPEG 1장만 담는 큐"""

    __slots__ = ("q", "sid", "sent", "dropped")

    def __init__(self, sid):
        self.q = queue.Queue(maxsize=1)
        self.sid = sid
        self.sent = self.dropped = 0

    def offer(self, item):
        """논블로킹 — 이전 것이 남아 있으면 버리고 새 것을 넣는다"""
        try:
            self.q.put_nowait(item)
        except queue.Full:
            try:
                self.q.get_nowait()             # 오래된 것 폐기
                self.dropped += 1
            except queue.Empty:
                pass
            try:
                self.q.put_nowait(item)
            except queue.Full:
                self.dropped += 1

    def get(self, timeout=5.0):
        try:
            item = self.q.get(timeout=timeout)
            self.sent += 1
            return item
        except queue.Empty:
            return None

    def __init__(self, source, **opts):
        self.source = source
        self.opts = {**DEFAULTS,
                     **{k: v for k, v in opts.items() if v is not None}}
        self._detector = self.cam = None
        self._subs = {}
        self._sub_lock = threading.Lock()
        self._state_lock = threading.Lock()
        self._latest = None                     # (jpeg, ts)
        self._latest_result = None
        self._seq = 0
        self._error = None
        self._stop = threading.Event()
        self._wake = threading.Event()          # 구독자 생기면 깨움
        self._last_active = time.time()

        self.cap_fps, self.inf_fps, self.out_fps = Meter(30), Meter(15), Meter(30)
        self.infer_ms, self.encode_ms, self.total_ms = Meter(15), Meter(30), Meter(30)

        self._worker = threading.Thread(target=self._loop, daemon=True,
                                        name=f"hub-{source}")
        self._worker.start()

    def _get_detector(self):
        """모델은 앱 전체에서 1회만 로드 (Day 161 의 싱글턴 재사용)"""
        if self._detector is None:
            from services.detector_service import get_shared_detector
            self._detector = get_shared_detector()
        return self._detector

    def subscribe(self, sid):
        sub = Subscriber(sid)
        with self._sub_lock:
            self._subs[sid] = sub
        self._last_active = time.time()
        self._wake.set()                        # 유휴였다면 깨움
        log.info("구독 시작 sid=%s source=%r (총 %d명)",
                 sid, self.source, len(self._subs))
        if self._latest is not None:            # 첫 화면을 빨리 띄운다
            sub.offer(self._latest)
        return sub

    def unsubscribe(self, sid):
        with self._sub_lock:
            sub = self._subs.pop(sid, None)
        if sub:
            log.info("구독 종료 sid=%s (전송 %d · 폐기 %d · 남은 %d명)",
                     sid, sub.sent, sub.dropped, len(self._subs))

    @property
    def subscriber_count(self):
        with self._sub_lock:
            return len(self._subs)

    def update(self, **opts):
        """실행 중 설정 변경 (해상도는 재시작이 필요하므로 제외)"""
        changed = {}
        with self._state_lock:
            for k, v in opts.items():
                if v is None or k not in DEFAULTS:
                    continue
                if k in ("width", "height", "cap_fps"):
                    continue
                if self.opts[k] != v:
                    self.opts[k] = v
                    changed[k] = v
        if changed:
            self.inf_fps.reset()
            self.out_fps.reset()
            log.info("설정 변경 %r → %s", self.source, changed)
        return changed

    def _ensure_camera(self):
        if self.cam is not None and self.cam.alive:
            return True
        if self.cam is not None:
            self.cam.release()
            self.cam = None
        try:
            self.cam = LatestFrameCapture(
                self.source, width=self.opts["width"],
                height=self.opts["height"], fps=self.opts["cap_fps"],
                loop=self.opts["loop"])
            self._error = None
            return True
        except Exception as e:                  # noqa: BLE001
            self._error = str(e)
            log.error("캡처 열기 실패 %r: %s", self.source, e)
            return False

    def _loop(self):
        last_frame_id, counter, last_result = -1, 0, None

        while not self._stop.is_set():
            # ── ① 구독자가 없으면 쉰다 ──
            if self.subscriber_count == 0:
                idle = time.time() - self._last_active
                if self.cam is not None and idle > self.opts["idle_timeout"]:
                    log.info("유휴 %ds — 카메라를 닫습니다 %r",
                             int(idle), self.source)
                    self.cam.release()
                    self.cam = None
                self._wake.clear()
                self._wake.wait(timeout=0.5)    # 추론 중단 (CPU 절약)
                continue
            self._last_active = time.time()

            # ── ② 카메라 확보 ──
            if not self._ensure_camera():
                self._broadcast_error(self._error or "카메라를 열 수 없습니다")
                time.sleep(2.0)
                continue

            # ── ③ 최신 프레임 ──
            frame, frame_id = self.cam.read()
            if frame is None or frame_id == last_frame_id:
                if frame is None and not self.cam.alive:
                    self._error = self.cam.error
                    self.cam.release()
                    self.cam = None
                time.sleep(0.003)
                continue
            last_frame_id = frame_id
            self.cap_fps.tick()
            t_start = time.perf_counter()
            with self._state_lock:
                o = dict(self.opts)

            # ── ④ 추론 (스킵 적용) ──
            do_infer = counter % (o["skip"] + 1) == 0
            counter += 1
            if do_infer:
                t0 = time.perf_counter()
                try:
                    last_result = self._get_detector().predict(
                        frame, conf=o["conf"], iou=o["iou"], imgsz=o["imgsz"])
                except Exception as e:          # noqa: BLE001
                    log.exception("추론 실패")
                    last_result = {"count": 0, "detections": [],
                                   "error": type(e).__name__}
                self.infer_ms.add((time.perf_counter() - t0) * 1000)
                self.inf_fps.tick()

            # ── ⑤ 그리기 ──
            out = frame
            if o["draw"] and last_result:
                try:
                    out = self._get_detector().draw(frame, last_result)
                except Exception:
                    log.exception("그리기 실패")
                    out = frame
            out = self._overlay(out, last_result, o, reused=not do_infer)

            # ── ⑥ 인코딩 (딱 1회) ──
            t0 = time.perf_counter()
            ok, buf = cv2.imencode(
                ".jpg", out,
                [int(cv2.IMWRITE_JPEG_QUALITY), int(o["jpeg_quality"])])
            if not ok:
                log.warning("JPEG 인코딩 실패")
                continue
            self.encode_ms.add((time.perf_counter() - t0) * 1000)

            # ── ⑦ 브로드캐스트 ──
            self._latest = (buf.tobytes(), time.time())
            self._latest_result = last_result
            self._seq += 1
            self._broadcast(self._latest)
            self.out_fps.tick()
            self.total_ms.add((time.perf_counter() - t_start) * 1000)

    def _broadcast(self, item):
        with self._sub_lock:
            subs = list(self._subs.values())
        for s in subs:
            s.offer(item)                       # 논블로킹

    def _broadcast_error(self, message):
        """카메라가 없을 때 안내 이미지를 보낸다"""
        img = np.full((360, 640, 3), 30, np.uint8)
        cv2.putText(img, "NO SIGNAL", (200, 160), FONT, 1.1,
                    (90, 96, 110), 2, cv2.LINE_AA)
        cv2.putText(img, message[:52], (30, 210), FONT, 0.5,
                    (140, 146, 160), 1, cv2.LINE_AA)
        ok, buf = cv2.imencode(".jpg", img,
                               [int(cv2.IMWRITE_JPEG_QUALITY), 70])
        if ok:
            self._latest = (buf.tobytes(), time.time())
            self._broadcast(self._latest)

    def _overlay(self, img, result, o, reused=False):
        """FPS · 검출 수 · 시각을 화면에 새긴다"""
        h, w = img.shape[:2]
        lines = [
            f"CAP {self.cap_fps.fps:5.1f}  INF {self.inf_fps.fps:5.1f}"
            f"  OUT {self.out_fps.fps:5.1f} fps",
            f"infer {self.infer_ms.ms:5.1f}ms  enc {self.encode_ms.ms:4.1f}ms"
            f"  imgsz {o['imgsz']}  skip {o['skip']}",
            f"objects {(result or {}).get('count', 0)}"
            f"{'  (reused)' if reused else ''}"
            f"   viewers {self.subscriber_count}",
        ]
        panel = img[0:16 + 18 * len(lines), 0:min(w, 430)]
        cv2.addWeighted(panel, 0.35, np.zeros_like(panel), 0.65, 0, panel)
        for i, text in enumerate(lines):
            cv2.putText(img, text, (8, 22 + i * 18), FONT, 0.45,
                        (235, 240, 245), 1, cv2.LINE_AA)
        # 지연 측정용 타임스탬프 (Step 5)
        stamp = time.strftime("%H:%M:%S") + f".{int(time.time() % 1 * 1000):03d}"
        cv2.putText(img, stamp, (w - 150, h - 12), FONT, 0.5,
                    (0, 220, 255), 1, cv2.LINE_AA)
        return img

    def stats(self):
        cam = self.cam
        return {
            "source": str(self.source), "error": self._error,
            "alive": bool(cam and cam.alive), "seq": self._seq,
            "resolution": f"{cam.width}x{cam.height}" if cam else None,
            "fps": {"capture": self.cap_fps.fps, "infer": self.inf_fps.fps,
                    "output": self.out_fps.fps},
            "ms": {"infer": self.infer_ms.ms, "encode": self.encode_ms.ms,
                   "total": self.total_ms.ms},
            "options": dict(self.opts),
            "subscribers": self.subscriber_count,
            "objects": (self._latest_result or {}).get("count", 0),
            "counts_by_class": (self._latest_result or {}).get(
                "counts_by_class", {}),
        }

    def snapshot(self):
        """현재 프레임 JPEG 1장 (폴링·썸네일용)"""
        return self._latest[0] if self._latest else None

    def close(self):
        self._stop.set()
        self._wake.set()
        if self._worker.is_alive():
            self._worker.join(timeout=2.0)
        if self.cam:
            self.cam.release()
            self.cam = None
        log.info("허브 종료 %r", self.source)


# ────────────────────────── 레지스트리 ──────────────────────────

_hubs: dict[str, StreamHub] = {}
_hubs_lock = threading.Lock()


def _key(source):
    return f"{type(source).__name__}:{source}"


def get_hub(source=0, **opts) -> StreamHub:
    """소스별 싱글턴 — 몇 명이 요청해도 허브는 하나"""
    k = _key(source)
    with _hubs_lock:
        hub = _hubs.get(k)
        if hub is None or hub._stop.is_set():
            hub = StreamHub(source, **opts)
            _hubs[k] = hub
            log.info("허브 생성 %s (총 %d개)", k, len(_hubs))
    return hub


def list_hubs():
    with _hubs_lock:
        return [h.stats() for h in _hubs.values()]


def close_hub(source):
    with _hubs_lock:
        hub = _hubs.pop(_key(source), None)
    if hub:
        hub.close()
        return True
    return False


def shutdown_all():
    """프로세스 종료 시 모든 카메라를 해제"""
    with _hubs_lock:
        hubs = list(_hubs.values())
        _hubs.clear()
    for h in hubs:
        try:
            h.close()
        except Exception:
            log.exception("허브 종료 실패")


atexit.register(shutdown_all)                   # 최후의 보루


def resolve_source(raw, allowed_dir: Path | None = None):
    """문자열 → 카메라 인덱스 또는 파일 경로

       임의 경로 접근을 막기 위해 allowed_dir 아래로 제한한다
    """
    if raw is None or raw == "":
        return 0
    if isinstance(raw, int):
        return raw
    s = str(raw).strip()
    if s.isdigit():
        return int(s)
    if s.startswith(("rtsp://", "http://", "https://")):
        return s
    if allowed_dir is None:
        raise ValueError(f"알 수 없는 소스: {s}")
    p = (Path(allowed_dir) / s).resolve()
    if Path(allowed_dir).resolve() not in p.parents:
        raise ValueError("허용되지 않은 경로입니다")      # 경로 조작 차단
    if not p.exists():
        raise ValueError(f"파일이 없습니다: {s}")
    return str(p)
```

```python
def make_part(jpeg: bytes, frame_time: float | None = None) -> bytes:
    """★ multipart 한 조각 — CRLF · Content-Length 필수

    frame_time 은 지연 측정용 커스텀 헤더 (브라우저는 무시한다)
    """
    extra = (b"X-Frame-Time: " + f"{frame_time:.6f}".encode() + b"\r\n"
             if frame_time is not None else b"")
    return (b"--" + BOUNDARY + b"\r\n"
            b"Content-Type: image/jpeg\r\n"
            b"Content-Length: " + str(len(jpeg)).encode() + b"\r\n"
            + extra + b"\r\n" + jpeg + b"\r\n")


def mjpeg_generator(hub, sid, logger):
    """★ 구독자 큐에서 최신 JPEG 을 꺼내 계속 내보낸다

    · 클라이언트가 탭을 닫으면 GeneratorExit 이 발생한다
    · finally 에서 반드시 구독을 해지한다
    """
    sub = hub.subscribe(sid)
    empty = 0
    try:
        while True:
            item = sub.get(timeout=5.0)
            if item is None:
                empty += 1
                logger.warning("스트림 프레임 없음 sid=%s (%d회)", sid, empty)
                if empty >= 3:                  # 15초 무응답 → 종료
                    break
                continue
            empty = 0
            yield make_part(item[0], item[1])
    except GeneratorExit:
        logger.info("스트림 종료(클라이언트 이탈) sid=%s", sid)
        raise                                   # 다시 올려야 정상 종료
    except (BrokenPipeError, ConnectionResetError):
        logger.info("스트림 종료(연결 끊김) sid=%s", sid)
    except Exception:
        logger.exception("스트림 오류 sid=%s", sid)
    finally:
        hub.unsubscribe(sid)                    # 반드시 실행


def video_dir():
    return Path(current_app.root_path) / current_app.config.get(
        "VIDEO_DIR", "static/videos")


def read_options():
    """★ 쿼리 파라미터를 안전하게 (요청 컨텍스트 안에서!) 읽는다"""
    a = request.args

    def clamp(v, lo, hi):
        return None if v is None else max(lo, min(hi, v))

    imgsz = a.get("imgsz", type=int)
    return {
        "skip": clamp(a.get("skip", type=int), 0, 15),
        "imgsz": imgsz if imgsz in (320, 416, 512, 640, 960) else None,
        "jpeg_quality": clamp(a.get("q", type=int), 30, 95),
        "conf": clamp(a.get("conf", type=float), 0.05, 0.95),
        "iou": clamp(a.get("iou", type=float), 0.1, 0.95),
        "draw": (a.get("draw") != "0") if "draw" in a else None,
        "width": clamp(a.get("w", type=int), 320, 1920),
        "height": clamp(a.get("h", type=int), 240, 1080),
    }


def hub_from_request():
    """쿼리의 source 로 허브를 찾거나 만든다"""
    try:
        source = resolve_source(request.args.get("source"), video_dir())
    except ValueError as e:
        abort(400, description=str(e))
    opts = {k: v for k, v in read_options().items() if v is not None}
    hub = get_hub(source, **opts)
    hub.update(**opts)                          # 이미 있던 허브면 설정 갱신
    return hub

    data = request.get_json(silent=True) or request.form
    hub = hub_from_request()

                              ("jpeg_quality", int, 30, 95),
                              ("conf", float, 0.05, 0.95),
                              ("iou", float, 0.1, 0.95)]:
        if key in data:
            try:
                payload[key] = max(lo, min(hi, cast(data[key])))
            except (TypeError, ValueError):
                return jsonify({"error": "invalid_parameter", "field": key,
                                "got": data[key]}), 400
    if "draw" in data:
        payload["draw"] = str(data["draw"]).lower() not in ("0", "false")
    return jsonify({"ok": True, "changed": hub.update(**payload),
                    "options": hub.stats()["options"]})
```

### Step 5. 지연 측정 — 화면에 타임스탬프를 찍어 왕복 지연 재기

```
★ 원리 — 서버가 프레임에 ★ 지금 시각을 찍어 보냅니다
        (오버레이 우하단 + X-Frame-Time 헤더). 받은 시각과의 차이 = 전체 지연

  [서버] t0 = 14:22:09.412 → 추론 → 인코딩 → 전송
  [브라우저] 화면에 "14:22:09.412" · 실제 지금 14:22:09.524 →    112 ms
```

**컴퓨터 시계를 옆에 띄우고 스마트폰으로 사진을 찍으면** 눈으로도 잴 수 있습니다.

```python
"""web/tools/measure_latency.py — MJPEG 스트림을 직접 구독해 지연을 잰다"""
import argparse, statistics, time

import requests

BOUNDARY = b"--frame"


def parse_stream(url, count=100):
    """★ multipart 스트림을 직접 파싱한다"""
    lags, sizes, gaps, last_t, buf = [], [], [], None, b""
    with requests.get(url, stream=True, timeout=10) as r:
        r.raise_for_status()
        print("Content-Type:", r.headers.get("Content-Type"))
        assert "multipart/x-mixed-replace" in r.headers.get("Content-Type", "")
        for chunk in r.iter_content(chunk_size=8192):
            buf += chunk
            while True:
                s = buf.find(BOUNDARY)
                he = buf.find(b"\r\n\r\n", s) if s >= 0 else -1
                if s < 0 or he < 0:
                    break
                length = sent_at = None
                for line in buf[s:he].decode("latin-1").split("\r\n"):
                    low = line.lower()
                    if low.startswith("content-length:"):
                        length = int(line.split(":", 1)[1])
                    elif low.startswith("x-frame-time:"):    # ★ 서버가 준 시각
                        sent_at = float(line.split(":", 1)[1])
                if length is None or len(buf) < he + 4 + length:
                    break
                now = time.time()
                if sent_at is not None:
                    lags.append((now - sent_at) * 1000)
                sizes.append(length)
                if last_t is not None:
                    gaps.append((now - last_t) * 1000)
                last_t = now
                buf = buf[he + 4 + length:]
                if len(sizes) >= count:
                    return lags, sizes, gaps
    return lags, sizes, gaps


def report(lags, sizes, gaps):
    fps = 1000 / statistics.mean(gaps)
    print(f"수신 {len(sizes)}프레임 · 평균 {statistics.mean(sizes)/1024:.1f} KB")
    print(f"★ 수신 FPS {fps:.1f} (간격 {statistics.mean(gaps):.1f} ms) · "
          f"대역폭 {statistics.mean(sizes)*fps*8/1e6:.1f} Mbps")
    if lags:
        srt = sorted(lags)
        print(f"지연 평균 {statistics.mean(lags):.1f} ms · "
              f"중앙값 {statistics.median(lags):.1f} ms · "
              f"최소/최대 {min(lags):.1f}/{max(lags):.1f} ms · "
              f"p95 {srt[int(len(srt)*0.95)]:.1f} ms")


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--url",
                    default="http://127.0.0.1:5000/video_feed?source=0")
    ap.add_argument("--count", type=int, default=100)
    a = ap.parse_args()
    report(*parse_stream(a.url, a.count))
```

```
① 캡처 FPS 가 ★ 항상 30 → 캡처 스레드가 추론과 ★ 완전히 분리되었다는 증거
   여기가 떨어지면 스레드 분리가 안 된 것입니다
② skip=0 일 때만 추론 FPS = 전송 FPS
③ skip ↑ → 전송 ↑ · 추론 ↓ — 벌어지는 만큼 "재사용된 박스"를 보는 것
④ imgsz 320 은 640 보다 3.7배 빠름 (18.6 vs 68.2 ms) — 단 작은 객체를 놓침
⑤ 전송 FPS 는 30 을 못 넘습니다 (캡처가 30 이므로)
⑥    대역폭은 skip 이 클수록 커집니다 — "부하는 줄었는데 네트워크는 늘어난다"
```

|---|---|---|
| 개발 PC · 유선 | **skip=1 · imgsz=640** | 전송 21.8 · 검출 정확 |

| Wi-Fi 가 느림 | skip=1 · 표시 960×540 | 대역폭 17 → 10 Mbps |
| 라즈베리파이 | — | [Day 168](day-168.md)에서 따로 |

> ⚠️ **이 숫자는 PC(4코어 CPU · yolo11n · PyTorch) 기준입니다.**
> 라즈베리파이 5 는 추론이 **3.4~4.2배 느립니다**([Day 153](day-153.md) 추정).
> 640 이면 **232 ms → 4.3 FPS**. 파이는 **NCNN + 416 + skip=2** 가 출발점입니다.

### ★ `Content-Type` 을 `image/jpeg` 로 씀


### 수정본 — 12개를 모두 반영한 최소 구현

```python
"""fixed_stream.py — 12개 문제를 모두 고친 최소 구현"""
import atexit, logging, sys, threading, time, uuid

import cv2
from flask import Flask, Response, request
from ultralytics import YOLO

logging.basicConfig(level=logging.INFO)                       # ★ 12
log = logging.getLogger(__name__)
app = Flask(__name__)

MODEL = YOLO("best.pt")                                       # ★ 2: 1회만
_cap, _lock = None, threading.Lock()
_frame, _frame_id = None, 0
_stop = threading.Event()


def ensure_camera():                                          # ★ 1: 1회만
    global _cap
    with _lock:
        if _cap is None or not _cap.isOpened():
            backend = (cv2.CAP_DSHOW if sys.platform.startswith("win")
                       else cv2.CAP_ANY)
            cap = cv2.VideoCapture(0, backend)
            cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*"MJPG"))
            cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
            cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)
            cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
            if not cap.isOpened():
                return False
            _cap = cap
            log.info("카메라 열기 성공")
    return True


def _reader():             # 5: 캡처 스레드가 최신만 유지 → 버퍼 지연 0
    global _frame, _frame_id
    while not _stop.is_set():
        if not ensure_camera():
            time.sleep(1.0)
            continue
        ok, f = _cap.read()
        if not ok:                                            # 4
            time.sleep(0.03)
            continue
        _frame, _frame_id = f, _frame_id + 1


threading.Thread(target=_reader, daemon=True).start()


def gen(sid, skip, imgsz, quality):
    last_id, last_res, counter = -1, None, 0
    log.info("스트림 시작 sid=%s", sid)
    try:
        while True:
            if _frame is None or _frame_id == last_id:
                time.sleep(0.003)
                continue
            last_id = _frame_id
            frame = _frame.copy()                  # tearing 방지
            if counter % (skip + 1) == 0:          # 5: 프레임 스킵
                last_res = MODEL.predict(frame, imgsz=imgsz, verbose=False)[0]
            counter += 1
            out = last_res.plot(img=frame) if last_res is not None else frame
            ok, buf = cv2.imencode(".jpg", out,    # 11: 품질 지정
                                   [int(cv2.IMWRITE_JPEG_QUALITY), quality])
            if not ok:
                continue
            jpeg = buf.tobytes()
            yield (b"--frame\r\n"                              # 3: CRLF
                   b"Content-Type: image/jpeg\r\n"
                   b"Content-Length: " + str(len(jpeg)).encode() + b"\r\n"
                   b"\r\n" + jpeg + b"\r\n")
    except GeneratorExit:                                      # 6
        log.info("스트림 종료(이탈) sid=%s", sid)
        raise
    except Exception:
        log.exception("스트림 오류 sid=%s", sid)


@app.route("/video_feed")
def video_feed():
    skip = max(0, min(8, request.args.get("skip", type=int, default=1)))
    imgsz = request.args.get("imgsz", type=int, default=640)
    if imgsz not in (320, 416, 640, 960):                      # 9
        imgsz = 640
    quality = max(30, min(95, request.args.get("q", type=int, default=80)))
    resp = Response(gen(uuid.uuid4().hex[:8], skip, imgsz, quality),
                    mimetype="multipart/x-mixed-replace; boundary=frame")
    resp.headers["Cache-Control"] = "no-cache, no-store"       # 10
    resp.headers["X-Accel-Buffering"] = "no"
    return resp


@atexit.register                                               # 1: 해제
def shutdown():
    _stop.set()
    if _cap is not None:
        _cap.release()
        log.info("카메라 해제")


if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000,                         # 7, 8
            threaded=True, debug=True, use_reloader=False)
```

### (가) 전송 ↑ · 추론 ↓

| 헤더 | `multipart/x-mixed-replace; boundary=frame` |
| 파트 구조 | `--frame` + `Content-Type` + **`Content-Length`** + 빈 줄 + JPEG + `\r\n` |
| 줄바꿈 | **`\r\n`** (CRLF). `\n` 은 사파리·모바일에서 실패 |
| 브라우저 코드 | **`<img src="/video_feed">`** 한 줄 |
| 제너레이터 | `Response(gen(), mimetype=...)` — **끝나지 않는 응답** |
| 종료 신호 | **`GeneratorExit`** — `finally` 에서 구독 해지 |
| 요청 컨텍스트 | 제너레이터 안에서 `request` ✗ → **미리 뽑아 인자로** |
| 백엔드 | Windows **`CAP_DSHOW`** · Linux `CAP_V4L2` · 파일 `CAP_FFMPEG` |
| `cap.set` | **요청일 뿐** — `cap.get()` 으로 되읽어 확인 |
| FOURCC | **`MJPG`** — 안 바꾸면 720p 에서 5 FPS |
| 버퍼 지연 | 3초 → **`LatestFrameCapture` 로 0.12초** |
| `read()` | **`.copy()`** 필수 — 안 하면 화면 찢어짐 |
| JPEG 품질 | **80** — 95 KB · 6 ms · 11.4 Mbps |
| 프레임 스킵 | **skip=1** — 전송 21.8 · CPU 71% · 지연 33 ms |
| 추론 해상도 | 표시와 **분리** — 640 기준, 320 은 3.7배 빠름 |
| FPS 3종 | **캡처 / 추론 / 전송** — 서로 다른 값. 이동평균 30 |
| 다중 접속 | **단일 캡처 + 단일 추론 + 브로드캐스트** |
| 구독자 큐 | `maxsize=1` · **`put_nowait`** (블로킹 금지) |
| 3탭 CPU | 245% → **102%** |
| 유휴 | 구독자 0명 → **추론 중단 (CPU 2%)** |
| 개발 서버 | `threaded=True` + **`use_reloader=False`** |
| 운영 서버 | `-w 1 --threads 8` ([Day 165](day-165.md)) |
| 파일 스트리밍 | **누적 보정 페이싱** · `POS_FRAMES=0` 로 반복 |
| 자원 해제 | `finally` + `__exit__` + **`atexit`** |

**오늘 반드시 기억할 세 가지**
> ① **버퍼 지연은 별도 캡처 스레드로만 확실히 해결됩니다.** `BUFFERSIZE=1` 은 백엔드가 무시하고, `grab()` 반복은 부하에 따라 달라집니다. 3초가 **0.12초**가 됩니다.
> ② **추론과 인코딩은 접속 수와 무관하게 한 번만 합니다.** 단일 캡처 + 브로드캐스트로 3탭 CPU 가 **245% → 102%** 가 됩니다.
> ③ **`finally` 에서 구독을 해지하세요.** `GeneratorExit` 을 처리하지 않으면 탭을 닫아도 유령 구독자가 남아 CPU 와 메모리를 계속 먹습니다.
