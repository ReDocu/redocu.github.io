## ① 학습 목표

이 강을 마치면 다음을 할 수 있습니다.

- 모의고사 전 문항의 풀이 근거와 **대표 오답의 원인을 설명할 수 있다**
- 과정 전체의 최빈출 암기 항목을 **스피드 런으로 재현할 수 있다**
- [시험 직전 7일 계획(A6)](../appendix/A6-final-7days.md)을 **자신의 빨간 칸에 맞게 개인화할 수 있다**
- 수료 체크리스트로 남은 할 일을 **확정할 수 있다**

## ② 왜 필요한가

**마지막 강의 목적은 새로 배우는 것이 아니라, 가진 것을 시험일까지 유지·배달하는 것입니다.** 모의고사 해설은 "왜 맞았는지"까지 확인하는 자리입니다 — 찍어서 맞은 문제는 시험장에서 다시 틀립니다. 그리고 남은 기간의 성패는 계획의 정밀함이 아니라 **매일 반복 가능한 단순함**에 달려 있습니다. A6 계획이 단순한 이유입니다.

## ③ 개념 설명

### 3-1. 모의고사 상세 해설 — 대표 오답 중심

[15강 정답표](lesson-15.md)를 옆에 두고, 문항별 **대표 오답과 그 원인**을 확인합니다. (자신의 오답과 대조하며 읽기)

| 번호 | 정답 | 대표 오답 | 오답 원인 |
|---|---|---|---|
| 1 | `1 3 3.3` | `1 3 3.333333` | `%.1f`의 자리 지정을 무시 — 포맷도 문제의 일부 |
| 2 | `3` | `2` | 17을 안 세거나 훑다 누락 — 배열 끝까지 표로 |
| 3 | `70` | `50` | *(p−2)를 "두 칸 앞 = a[2]=30"으로 — p는 a[3]이므로 a[1] |
| 4 | `10` / 자리 숫자 합 | `24` / 팩토리얼 | `%`와 `/10`의 조합을 곱으로 착각 — 연산자부터 확인 |
| 5 | `36` | `60` | 3의 배수 또는 2의 배수(OR)로 읽음 — `&&`는 둘 다 |
| 6 | `원3원` | `원3도형` | 마지막 `s.draw()`를 타입(Shape) 기준으로 — 실행은 객체 기준 |
| 7 | `FORMI` | `FORI` 등 | substring 끝 미포함을 잘못 적용 — (2,6)은 인덱스 2~5 |
| 8 | `[2, 4, 6] 6` | `2 4 6 6` | 리스트 출력 형식(대괄호·쉼표) 탈락 |
| 9 | `2` | `3` | 70도 포함 — `>= 80` 경계 확인 |
| 10 | `n - 1` | `n` | 축소 없는 재귀 = 무한 호출 |
| 11 | (15강 참조) | ORDER BY 누락 | "오름차순으로"가 요구 키워드 |
| 12 | `C1 \| 95` | C1·C2 포함 2행 | HAVING 조건을 85로 잘못 계산 — MAX(C2)=85 < 90 |
| 13 | `IN` | `=` | 다중행 서브쿼리에 단일행 연산자 |
| 14 | `DROP` | `DELETE` | 열 삭제는 DDL(ALTER … DROP), DELETE는 행 |
| 15 | `SAVEPOINT` | ROLLBACK | "중간 지점 표시"가 열쇠말 — 되돌리기 자체는 ROLLBACK TO |
| 16 | 기능적 응집도 | 우연적 | "바람직한 = 높은" 방향 착오 |
| 17 | 경계값 분석 | 동등 분할 | "경계(양 끝)"가 열쇠말 |
| 18 | SQL 인젝션 | XSS | 삽입 대상이 스크립트(브라우저)면 XSS, 질의문(DB)이면 인젝션 |
| 19 | 전송 계층 | 네트워크 계층 | TCP=4계층 — IP(3계층)와 묶어 암기 |
| 20 | `4회` | `6회` | 적중(A·B)을 부재로 셈 |

### 3-2. 최종 암기 스피드 런 — 30항목

시험 전날 밤과 당일 아침에 이 목록만 돌립니다. 3초 안에 안 나오면 해당 강으로.

**코드 (1~10)** — ①C·Java 정수 `/`는 몫, Python `/`는 실수·`//`가 몫 ②후위 `a++`는 쓰고 증가 ③`"A"+1+2`는 `A12`, `1+2+"A"`는 `3A` ④switch는 break까지 연쇄 ⑤`range(1,n)`은 n 미포함 ⑥Java 문자열 내용 비교는 equals ⑦`*(p+i)`≡`p[i]`, `p++`는 이동 ⑧값 전달은 원본 불변, 주소 전달 3부품(&a/int *x/*x) ⑨자식 생성 시 부모 생성자 먼저, 실행 메서드는 객체 기준 ⑩finally는 항상, 튜플은 불변, `[::-1]`은 역순

**SQL·DB (11~20)** — ⑪`= NULL` 금지, IS NULL ⑫BETWEEN 양 끝 포함 ⑬COUNT(*)만 NULL 포함, AVG 분모는 COUNT(열) ⑭행 조건 WHERE·그룹 조건 HAVING, 실행 순서 F-W-G-H-S-O ⑮INNER는 짝만·LEFT는 왼쪽 전원+NULL ⑯LEFT+개수는 COUNT(오른쪽 열) ⑰다중행 서브쿼리는 IN/EXISTS, NOT IN은 NULL 함정 ⑱UNION 중복 제거·ALL 유지 ⑲TRUNCATE는 DDL·ROLLBACK 불가, GRANT TO·REVOKE FROM ⑳ACID·도부이결·σ=WHERE·π=SELECT절

**이론 (21~30)** — ㉑기능(동작) vs 비기능(품질·숫자) ㉒유스케이스·시퀀스=행위, 클래스=구조 ㉓싱글턴(하나)·옵서버(통지)·어댑터(변환)·퍼사드(창구)·스트래티지(알고리즘 교체) ㉔블랙박스=명세(동등 분할·경계값), 화이트박스=구조(커버리지) ㉕하향식-스텁, 상향식-드라이버 ㉖결합도 자스제외공내(낮→높), 응집도 기순통절시논우(높→낮) ㉗IP=3계층 패킷, TCP/UDP=4계층 세그먼트 ㉘대칭(AES·SEED)/비대칭(RSA)/해시(SHA·단방향) ㉙스니핑=도청, 스푸핑=위장, 인젝션=DB, XSS=스크립트 ㉚HRN=(대기+서비스)÷서비스, LRU=가장 오래 미사용, 교착 4조건 상점비환

(부록 [A5 자주 틀리는 함정 30](../appendix/A5-top30-traps.md)은 이 목록의 "틀리는 방식" 버전입니다 — 짝으로 회독하세요.)

## ④ 단계별 실습

### Step 1. 🔁 최종 복습 퀴즈 (전 범위 무작위 · 5문항)

1. Python: `print(7 // 2 + 7 % 2)` 의 출력은?
2. SQL: 실행 순서에서 HAVING 바로 앞 단계는?
3. Java: `Parent p = new Child();`에서 Child 고유 메서드를 p로 호출하면?
4. 이론: "결정자가 모두 후보키"인 정규형은?
5. 이론: IPv4와 IPv6의 주소 비트 수는?

<details>
<summary>정답</summary>

1. `4` (3+1) 2. GROUP BY 3. 컴파일 에러 (호출 가능 여부는 변수 타입 기준) 4. BCNF 5. 32비트 / 128비트

</details>

### Step 2. 해설 정독과 오답 대조 (60분)

3-1 표를 문항 순서로 함께 읽습니다. 각자 자신의 오답 문항에서 ①내 오답이 대표 오답과 같은가 ②원인 유형(개념/절차/형식)이 14강 매트릭스의 판정과 일치하는가를 확인하고, 다르면 매트릭스를 갱신합니다. **맞힌 문항도 근거를 말로 설명**할 수 있는지 옆 사람과 1문항씩 교차 점검합니다.

### Step 3. 스피드 런 실측 (20분)

3-2의 30항목을 ①혼자 1회전(체크) ②짝과 문답 1회전 ③막힌 항목만 3회전. 막힌 항목은 A6 계획의 "매일 아침 5분" 슬롯에 등록합니다.

### Step 4. 7일 계획 개인화 (20분)

[A6 양식](../appendix/A6-final-7days.md)을 열고 ①14강 매트릭스의 빨간 칸을 D-6·D-4의 집중 슬롯에 배치 ②모의고사 실점 문항의 재풀이를 D-5에 배치 ③막힌 스피드 런 항목을 매일 아침 슬롯에 기입합니다.

### Step 5. 수료 점검 (10분)

[로드맵 7절](../../curriculum/README.md)의 수료 체크리스트를 확인합니다: 모의고사 60점(미달 시 재응시 일정 약속) / 오답노트 완성 / A4 체크리스트 자가 점검 / A6 계획 확정. ⚠️ 시험 일정 최종 확인: 2026년 3회 실기 2026.10.24.~11.13. 시행, 본인 시험일·시험장은 수험표 기준(Q-net).

## ⑥ 확인 문제

1. [해설 이해] 6번 문항에서 `s.draw()`가 "원"을 출력하는 근거 규칙과, 반대로 `s.draw(3)`이 불가능한 근거 규칙을 각각 쓰시오.
2. [계획] 나의 A6 계획에서 D-6과 매일 아침 슬롯에 무엇을 배치했는지 쓰시오. (자기 답)
3. [최종] 시험 당일 지참물과 금지물을 각각 두 가지 이상 쓰시오.

<details>
<summary>정답과 해설</summary>

1. "원": **실행 메서드는 실제 객체(Circle) 기준** (오버라이딩된 것). `s.draw(3)` 불가: **호출 가능 여부는 변수 타입(Shape) 기준** — Shape에 draw(int)가 없음. 한 문항에 다형성의 두 규칙이 모두 들어 있는 이유를 설명할 수 있으면 완성입니다.
2. (자기 답 — 빨간 칸 집중 슬롯과 막힌 스피드 런 항목이 들어 있어야 합니다)
3. 지참: 신분증, 수험표, 검은색 필기구 / 금지: 계산기, 스마트워치 등 전자기기.

</details>
