### matplotlib 의 구조

```
Figure  (그림 전체 = 도화지)
 └── Axes  (하나의 좌표계 = 그래프 하나)   ⭐ 실제로 그리는 곳
      ├── Axis   (x축, y축)
      ├── Line2D, Bar, Scatter …  (Artist = 그려지는 것들)
      ├── Title, Legend
      └── Ticks, Labels
```

| 용어 | 의미 | 헷갈림 주의 |
|---|---|---|
| **Figure** | 전체 그림. 저장 단위 | |
| **Axes** | 그래프 하나 (축이 있는 영역) | **"축"이 아닙니다** |
| **Axis** | x축 또는 y축 | `Axes` 와 철자가 비슷 |

> ⚠️ **`Axes` 는 "축"이 아니라 "그래프 한 칸"입니다.**
> 한 Figure 에 Axes 를 여러 개 넣으면 여러 그래프가 됩니다. ([Day 064](day-064.md))

### 두 가지 사용법

**① pyplot 방식 (상태 기반)**

```python
plt.plot(x, y)
plt.title("제목")
plt.xlabel("월")
plt.show()
```

**② 객체지향 방식 (권장)** ⭐

```python
fig, ax = plt.subplots(figsize=(10, 6))

ax.plot(x, y)
ax.set_title("제목")
ax.set_xlabel("월")

plt.show()
```

| | pyplot | 객체지향 |
|---|---|---|
| 대상 | **"현재 그래프"** (암묵적) | `ax` 명시 |
| 여러 그래프 | 헷갈림 | **명확** |
| 함수로 분리 | 어려움 | **쉬움** |
| 권장 | 빠른 확인용 | **✅ 실제 작업** |

```python
def draw_sales(ax, data):
    """어디에 그릴지 ax 로 받으면 재사용이 쉽습니다."""
    ax.plot(data.index, data.values)
    return ax
```

> **처음부터 `fig, ax = plt.subplots()` 로 시작하는 습관**을 들이세요.
> 나중에 서브플롯을 만들 때 코드를 거의 안 고쳐도 됩니다.

```python
import matplotlib.pyplot as plt
import platform

if platform.system() == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"       # 맑은 고딕
elif platform.system() == "Darwin":                      # macOS
    plt.rcParams["font.family"] = "AppleGothic"
else:                                                    # Linux
    plt.rcParams["font.family"] = "NanumGothic"

plt.rcParams["axes.unicode_minus"] = False               # ⭐ 필수
```

> ⚠️ **`axes.unicode_minus = False` 를 빼먹지 마세요.**
> 한글 폰트에는 유니코드 마이너스(`−`, U+2212)가 없는 경우가 많아
> **음수 눈금이 `□` 로 깨집니다.**
> 이 설정은 일반 하이픈(`-`)을 쓰게 합니다.

**설치된 한글 폰트 찾기**

**`legend` 위치**

| `loc` | 위치 |
|---|---|
| `"best"` | 자동 (기본) |
| `"upper left"` `"upper right"` | 위 |
| `"lower left"` `"lower right"` | 아래 |
| `bbox_to_anchor=(1.02, 1)` | **그래프 바깥** |

> ⚠️ **`ax.legend()` 를 호출해야 범례가 나옵니다.**
> `label=` 만 쓰고 `legend()` 를 안 부르면 아무것도 안 보입니다.

## ④ 단계별 실습

### Step 1. 환경 설정과 확인

```python
"""matplotlib 한글 설정 — 모든 노트북 맨 위에 넣습니다."""

import platform
from pathlib import Path

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from matplotlib import font_manager

OUT = Path("output")
OUT.mkdir(exist_ok=True)


def setup_korean_font(style="seaborn-v0_8-whitegrid", verbose=True):
    """한글 폰트를 설정합니다. 반환: 적용된 폰트 이름"""
    if style:
        plt.style.use(style)              # ⭐ 스타일을 먼저

    system = platform.system()
    candidates = {
        "Windows": ["Malgun Gothic", "NanumGothic", "Gulim", "Batang"],
        "Darwin": ["AppleGothic", "NanumGothic", "Apple SD Gothic Neo"],
        "Linux": ["NanumGothic", "NanumBarunGothic", "UnDotum"],
    }.get(system, ["NanumGothic"])

    installed = {f.name for f in font_manager.fontManager.ttflist}
    chosen = next((f for f in candidates if f in installed), None)

    if chosen:
        plt.rcParams["font.family"] = chosen
    else:
        if verbose:
            print(f"⚠ 한글 폰트를 찾지 못했습니다 ({system})")
            print(f"  후보: {candidates}")
            print(f"  설치: https://hangeul.naver.com/font (나눔고딕)")

    plt.rcParams["axes.unicode_minus"] = False        # ⭐ 필수
    plt.rcParams["figure.figsize"] = (10, 6)
    plt.rcParams["figure.dpi"] = 100
    plt.rcParams["savefig.dpi"] = 150
    plt.rcParams["savefig.bbox"] = "tight"
    plt.rcParams["savefig.facecolor"] = "white"
    plt.rcParams["font.size"] = 11
    plt.rcParams["axes.titlesize"] = 14
    plt.rcParams["axes.labelsize"] = 11

    if verbose:
        print(f"[설정 완료]")
        print(f"  OS          : {system}")
        print(f"  폰트        : {plt.rcParams['font.family'][0]}")
        print(f"  마이너스    : {plt.rcParams['axes.unicode_minus']}")
        print(f"  matplotlib  : {mpl.__version__}")

    return chosen


# ══════════ 실행 ══════════
print("=" * 70)
print("                  matplotlib 환경 설정")
print("=" * 70)
print()

font = setup_korean_font()

# ── 설치된 한글 폰트 목록 ──
installed = {f.name for f in font_manager.fontManager.ttflist}
korean = sorted(f for f in installed
                if any(k in f for k in ("Gothic", "Nanum", "Malgun",
                                        "Batang", "Gulim", "Dotum", "Myeongjo")))

print(f"\n[사용 가능한 한글 폰트] {len(korean)}개")
for f in korean[:8]:
    mark = "★" if f == font else " "
    print(f"  {mark} {f}")

# ── 테스트 그래프 ──
fig, ax = plt.subplots(figsize=(8, 4))

x = np.linspace(-3, 3, 100)
ax.plot(x, x ** 3 - 3 * x, color="#2563eb", linewidth=2)
ax.axhline(0, color="gray", linewidth=0.8)
ax.axvline(0, color="gray", linewidth=0.8)

ax.set_title("한글 폰트 테스트 — 음수 눈금 확인")
ax.set_xlabel("입력값 (음수 포함)")
ax.set_ylabel("결과값")

fig.savefig(OUT / "font_test.png")
plt.close(fig)

print(f"\n[테스트 그래프] output/font_test.png 저장")
print(f"  확인할 것:")
print(f"    ① 제목·축 라벨의 한글이 □ 없이 보이는가")
print(f"    ② x축의 음수 눈금이 -3, -2, -1 로 보이는가 (□ 아님)")

print("\n" + "=" * 70)
```

> **눈여겨볼 점 7가지**
> - **`ylim=(0, ...)`** — y축을 0부터 시작합니다. 안 그러면 **차이가 과장**됩니다. ([Day 062](day-062.md))
> - **`zorder`** — 숫자가 클수록 위에 그려집니다. 실적선이 목표선 위로 오게 했습니다.
> - **`fill_between(where=...)`** — 조건을 만족하는 구간만 색칠합니다.
> - **`annotate`** — 화살표로 특정 지점을 가리킵니다. `xy` 는 가리킬 점, `xytext` 는 글자 위치.
> - **`transform=ax.transAxes`** — 좌표를 **0~1 비율**로 지정합니다. 데이터 범위가 바뀌어도 위치 고정.
> - **`markerfacecolor="white"`** — 마커 속을 비워 선이 가려지지 않게 합니다.
> - **요약 문장을 그래프 안에** 넣었습니다. 그래프 혼자서도 말이 되게 만드는 방법입니다.

| **스타일 → 폰트 순서** | 스타일이 rcParams 를 덮어씀 |

| **저장 → 표시 순서** | `show()` 가 Figure 를 비움 |
| **`close()` 로 정리** | 반복 생성 시 메모리 |

> **③번이 핵심 판단입니다.**
> "한 그래프에 여러 선"과 "여러 그래프"는 **완전히 다른 의도**입니다.

> - 지역**별 보고서** → 따로 저장
>
> 원래 코드는 둘 중 무엇을 원했는지 알 수 없습니다. **의도를 먼저 정하세요.**

```python
def find_korean_font(verbose=True):
    """

    반환: (폰트명 or None, 탐색 로그 리스트)

    system = platform.system()
    log = []

    installed = {f.name for f in font_manager.fontManager.ttflist}

    # ── ① OS별 후보 ──
    for name in FONT_CANDIDATES.get(system, []):
        if name in installed:
            log.append(f"✓ 후보에서 발견: {name}")
            return name, log
        log.append(f"✗ 없음: {name}")

    # ── ② 이름에 한글 폰트 키워드가 있는 것 ──
    keywords = ("Gothic", "Nanum", "Malgun", "Batang",
                "Gulim", "Dotum", "Myeongjo", "CJK", "KR")
    found = sorted(f for f in installed if any(k in f for k in keywords))

    if found:
        log.append(f"✓ 키워드 검색으로 발견: {found[0]} (총 {len(found)}개)")
        return found[0], log

    log.append("✗ 키워드 검색 실패")

    # ── ③ 파일 경로로 직접 등록 ──
    for path in FONT_FILE_HINTS:
        if Path(path).exists():
            try:
                font_manager.fontManager.addfont(path)
                name = font_manager.FontProperties(fname=path).get_name()
                log.append(f"✓ 파일에서 등록: {path} → {name}")
                return name, log
            except Exception as e:
                log.append(f"✗ 등록 실패 {path}: {type(e).__name__}")

    log.append("✗ 모든 방법 실패")
    return None, log
```

```python
"""그래프 완성도 검사."""

import matplotlib.pyplot as plt
import numpy as np


def check_figure(fig, strict=False, verbose=True):
    """
    Figure 의 완성도를 검사합니다.

    strict : True 면 권장 항목도 오류로 취급
    반환: dict(score, issues)
    """
    issues = []
    axes = fig.get_axes()

    line = "=" * 72

    if verbose:
        print(line)
        print("                     그래프 완성도 검사")
        print(line)
        print(f"\n  Figure: {fig.get_size_inches()[0]:.1f} × "
              f"{fig.get_size_inches()[1]:.1f} inch, "
              f"dpi={fig.get_dpi():.0f}, Axes {len(axes)}개")

    if not axes:
        issues.append(("필수", "Axes 가 없음 — 아무것도 그려지지 않음"))
        return {"score": 0, "issues": issues}

    for i, ax in enumerate(axes):
        label = f"Axes[{i}]" if len(axes) > 1 else "Axes"
        ax_issues = []

        # ── ① 제목 ──
        has_title = bool(ax.get_title().strip())
        has_suptitle = bool(fig._suptitle and fig._suptitle.get_text().strip())

        if not has_title and not has_suptitle:
            ax_issues.append(("필수", "제목 없음 — set_title()"))

        # ── ② 축 라벨 ──
        if not ax.get_xlabel().strip():
            ax_issues.append(("필수", "x축 라벨 없음 — set_xlabel()"))
        if not ax.get_ylabel().strip():
            ax_issues.append(("필수", "y축 라벨 없음 — set_ylabel()"))

        # ── ③ 단위 표기 ──
        for axis_name, text in (("x", ax.get_xlabel()), ("y", ax.get_ylabel())):
            if text and not any(u in text for u in
                                ("(", "[", "%", "원", "명", "건", "개", "℃")):
                ax_issues.append(("권장",
                                  f"{axis_name}축 라벨에 단위 없음: '{text}'"))

        # ── ④ 범례 ──
        n_series = len(ax.get_lines()) + len(ax.containers)
        has_legend = ax.get_legend() is not None

        labeled = [ln for ln in ax.get_lines()
                   if ln.get_label() and not ln.get_label().startswith("_")]

        if n_series > 1 and not has_legend:
            ax_issues.append(("필수", f"계열 {n_series}개인데 범례 없음 — legend()"))
        elif labeled and not has_legend:
            ax_issues.append(("권장", "label 을 지정했는데 legend() 미호출"))

        # ── ⑤ y축 시작점 ──
        ymin, ymax = ax.get_ylim()
        has_bars = len(ax.containers) > 0

        if has_bars and ymin > 0:
            ax_issues.append(("필수",
                              f"막대그래프인데 y축이 {ymin:,.0f} 부터 시작 "
                              f"— 차이가 과장됨"))
        elif ymin > 0 and ymin / max(abs(ymax), 1) > 0.3:
            ax_issues.append(("권장",
                              f"y축이 {ymin:,.0f} 부터 시작 — "
                              f"0부터 시작하거나 명시적으로 표시"))

        # ── ⑥ 데이터 존재 ──
        if n_series == 0 and not ax.collections and not ax.images:
            ax_issues.append(("필수", "데이터가 그려지지 않음"))

        # ── ⑦ 눈금 과밀 ──
        n_xticks = len(ax.get_xticks())
        if n_xticks > 25:
            ax_issues.append(("권장",
                              f"x축 눈금 {n_xticks}개 — 겹칠 수 있음 "
                              f"(회전 또는 개수 축소)"))

        # ── ⑧ 격자 ──
        grid_on = any(gl.get_visible() for gl in ax.get_xgridlines()[:1] or [])
        if not grid_on and not has_bars:
            ax_issues.append(("권장", "격자 없음 — grid(alpha=0.3) 권장"))

        # ── ⑨ 눈금 라벨 길이 ──
        long_labels = [t.get_text() for t in ax.get_xticklabels()
                       if len(t.get_text()) > 8]
        if len(long_labels) > 3:
            rot = ax.get_xticklabels()[0].get_rotation() if ax.get_xticklabels() else 0
            if rot == 0:
                ax_issues.append(("권장",
                                  f"긴 x축 라벨 {len(long_labels)}개인데 회전 없음"))

        if verbose:
            mark = "✓" if not any(l == "필수" for l, _ in ax_issues) else "✗"
            print(f"\n  [{label}] {mark}")
            print(f"    제목   : {ax.get_title()[:40] or '(없음)'}")
            print(f"    x축    : {ax.get_xlabel() or '(없음)'}")
            print(f"    y축    : {ax.get_ylabel() or '(없음)'}")
            print(f"    계열   : {n_series}개  범례: {'있음' if has_legend else '없음'}")
            print(f"    y범위  : {ymin:,.1f} ~ {ymax:,.1f}")

            for level, msg in ax_issues:
                icon = "🔴" if level == "필수" else "🟡"
                print(f"    {icon} {msg}")

            if not ax_issues:
                print(f"    문제 없음")

        issues += [(l, f"{label}: {m}") for l, m in ax_issues]

    # ══════════ 점수 ══════════
    required = sum(1 for l, _ in issues if l == "필수")
    recommended = sum(1 for l, _ in issues if l == "권장")

    score = max(0, 100 - required * 20 - recommended * 5)

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 발표 가능" if score >= 85
                 else "🟡 보완 필요" if score >= 60
                 else "❌ 재작업")
        print(f"  완성도: {score}점 / 100   {grade}")
        print(f"  (필수 누락 {required}건 × -20, 권장 {recommended}건 × -5)")
        print(line)

        if score < 100:
            print(f"\n  [체크리스트]")
            for item in ["제목이 '무엇을' 보여 주는지 말하는가",
                         "축 라벨에 단위가 있는가",
                         "계열이 2개 이상이면 범례가 있는가",
                         "막대그래프의 y축이 0부터인가",
                         "눈금이 겹치지 않는가"]:
                print(f"    □ {item}")
            print(line)

    return {"score": score, "issues": issues,
            "passed": required == 0 and (not strict or recommended == 0)}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    # ── 나쁜 그래프 ──

    check_figure(fig)
    plt.close(fig)

    # ── 좋은 그래프 ──
    fig, ax = plt.subplots(figsize=(9, 5))
    x = np.arange(1, 13)
    ax.plot(x, [4231, 3980, 5120, 4890, 5340, 4210,
                3120, 2890, 4560, 6120, 7340, 8920],
            marker="o", label="2026년")
    ax.set_title("월별 매출 추이")
    ax.set_xlabel("월")
    ax.set_ylabel("매출 (만원)")
    ax.set_ylim(0, None)
    ax.set_xticks(x)
    ax.legend()
    ax.grid(True, alpha=0.3)

    print("\n\n>>> 좋은 그래프\n")
    check_figure(fig)
    plt.close(fig)
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 구조 | **Figure**(도화지) > **Axes**(그래프 한 칸) > Artist |
| 방식 | **`fig, ax = plt.subplots()`** 객체지향 권장 |
| **한글 폰트** | `rcParams["font.family"] = "Malgun Gothic"` |
| **마이너스** | **`rcParams["axes.unicode_minus"] = False`** ⭐ |
| 순서 | **스타일 먼저 → 폰트 나중** |
| 선 꾸미기 | `color` `linestyle` `linewidth` `marker` `alpha` `label` |
| 축 | `set_title` `set_xlabel` `set_ylabel` `set_xticks` `set_ylim` |
| **y축** | **`set_ylim(0, None)`** — 막대는 반드시 0부터 |
| 범례 | `label=` + **`ax.legend()`** 둘 다 필요 |
| 눈금 서식 | `FuncFormatter(lambda v, p: f"{v:,.0f}")` |
| 강조 | `annotate`(화살표) · `fill_between`(구간) · `axhline` |
| 저장 | `savefig(dpi=150, bbox_inches="tight", facecolor="white")` |
| 정리 | **`plt.close(fig)`** — 반복 생성 시 필수 |

**오늘 반드시 기억할 세 가지**
> ① **`axes.unicode_minus = False` 를 빼먹지 마세요.** 음수 눈금이 `□` 로 깨집니다.
> ② **`fig, ax = plt.subplots()` 로 시작하세요.** 서브플롯으로 확장할 때 코드를 안 고쳐도 됩니다.
> ③ **`savefig` 를 `show` 보다 먼저.** 순서가 바뀌면 빈 이미지가 저장됩니다.
