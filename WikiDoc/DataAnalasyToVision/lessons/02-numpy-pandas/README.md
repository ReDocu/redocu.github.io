
### 첫 실습 데이터는 여러분이 만든 게임입니다

대단원 01에서 만든 `game.db` 에 플레이 기록이 쌓여 있습니다.

```python
import pandas as pd
import sqlite3

conn = sqlite3.connect("game.db")
df = pd.read_sql("SELECT * FROM scores", conn)

df.groupby("stage")["score"].mean().plot(kind="bar")
```

**"어느 스테이지에서 가장 많이 죽는가?"** 같은 질문에 그래프로 답하게 됩니다.
