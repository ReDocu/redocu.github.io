이 강을 마치면 다음을 할 수 있습니다.

- 전위(`++a`)·후위(`a++`) 증감 연산자가 섞인 코드를 추적표로 **계산할 수 있다**

- 세 언어의 조건문 문법 차이(`elif`, switch 유무, 논리값 표기)를 **구분할 수 있다**

## ② 왜 필요한가

**모든 코드 문제의 절반은 결국 수식 계산입니다.** 반복문·배열·포인터가 아무리 복잡해도, 그 안의 한 줄은 `s += i * 2` 같은 수식이고, 우선순위를 하나만 잘못 알아도 뒤의 추적이 전부 어긋납니다. 특히 **증감 연산자**는 "먼저 쓰고 나중에 증가(`a++`)"와 "먼저 증가하고 쓰기(`++a`)"의 한 글자 차이로 답이 갈리는, 실기 단골 소재입니다.

조건문에서는 **switch의 fall-through(연쇄 실행)** 가 대표 함정입니다. `break`가 없으면 일치한 case부터 아래로 계속 실행된다는 사실을 모르면, 오류 찾기 유형에서 "문법 에러가 없는데 결과가 이상한" 코드를 설명하지 못합니다.

**시험에서의 중요도와 출제 형태** — 결과 예측(증감·삼항·비트 계산), 빈칸 채우기(조건식·연산자 넣기), 오류 찾기(`=` vs `==`, break 누락) 세 유형 모두로 출제됩니다. 이 강의 내용은 단독 문제로도 나오고, 이후 모든 코드 문제의 부품으로도 나옵니다.

## ③ 개념 설명

### 3-1. 연산자 종류 한눈에

| 분류 | 연산자 | 세 언어 차이 |
|---|---|---|
| 산술 | `+ - * / %` | 나눗셈 규칙은 [02강](../01-foundation/lesson-02.md) 표 — Python만 `//`(몫)·`**`(거듭제곱) 보유 |
| 증감 | `++` `--` | **C·Java만 있음** — Python은 `a += 1`로 대신 |
| 비교 | `< <= > >= == !=` | 공통. 결과 표기가 다름(아래 📌) |
| 논리 | C·Java: `&& \|\| !` / Python: `and or not` | 의미는 같고 표기만 다름 |
| 비트 | `& \| ^ ~ << >>` | 세 언어 공통 (2진수 자리끼리 연산) |
| 삼항 | C·Java: `조건 ? 참 : 거짓` / Python: `참 if 조건 else 거짓` | **어순이 다름** — Python은 참값이 앞 |
| 대입 | `= += -= *= /= %=` | 공통 |

📌 **반드시 암기 — 논리·비교 결과의 표기**: 같은 참이라도 **C는 `1`, Java는 `true`, Python은 `True`** 로 출력됩니다(거짓은 `0` / `false` / `False`). 필답형에서 `1`을 `true`로 쓰면 감점 위험이 있는 **언어별 답안 표기 함정**입니다.

### 3-2. 연산자 우선순위

📌 **반드시 암기 — 시험용 우선순위 사다리** (위가 먼저)

| 순위 | 연산자 | 기억법 |
|---|---|---|
| 1 | `( )` 괄호 | 괄호가 왕 |
| 2 | 단항: `!` `~` `++` `--` 부호 `-` | 붙어 있는 것 먼저 |
| 3 | `* / %` → `+ -` | 곱셈 나눗셈이 덧셈보다 먼저 |
| 4 | 시프트 `<<` `>>` | |
| 5 | 비교 `< <= > >=` → `== !=` | 크기 비교가 같음 비교보다 먼저 |
| 6 | 비트 `&` → `^` → `\|` | |
| 7 | 논리 `&&` → `\|\|` | AND가 OR보다 먼저 |
| 8 | 삼항 `?:` | |
| 9 | 대입 `=` `+=` … | 대입이 꼴찌 — 항상 마지막 |
| — | 같은 순위끼리 | 왼쪽 → 오른쪽 (대입·단항 제외) |

- 예: `2 + 3 * 4 > 10 && 10 % 3 == 1` → `2+12=14` → `14 > 10` 참 → `10%3=1`, `1 == 1` 참 → 참 AND 참 = **참** (C는 `1`, Java는 `true`).
- **대입이 꼴찌**라는 사실이 복합 대입의 함정을 만듭니다: `a *= 2 + 3`은 `a = a * (2 + 3)` — 오른쪽 전체를 먼저 계산합니다.

### 3-3. 증감 연산자 — 전위 vs 후위

⚖️ **혼동 비교 (최빈출)**

| 구분 | 의미 | `a = 5`일 때 `b = ?` | 실행 후 a |
|---|---|---|---|
| 후위 `b = a++;` | **현재값을 먼저 사용**하고 나서 1 증가 | b = 5 | 6 |
| 전위 `b = ++a;` | **1 증가부터 하고** 그 값을 사용 | b = 6 | 6 |

추적표에 쓸 때는 "후위 = 쓰고 증가, 전위 = 증가하고 쓰기"로 소리 내어 읽으면서 **a의 최종값과 식에 쓰인 값을 분리해 기록**하는 것이 요령입니다.

### 3-4. 비트 연산 — 2진수로 바꿔서 자리끼리

| 연산 | 뜻 | `6(110)`과 `3(011)`의 예 |
|---|---|---|
| `&` AND | 둘 다 1일 때만 1 | `110 & 011 = 010` → **2** |
| `\|` OR | 하나라도 1이면 1 | `110 \| 011 = 111` → **7** |
| `^` XOR | 서로 다를 때만 1 | `110 ^ 011 = 101` → **5** |
| `<<` 왼쪽 시프트 | 한 칸마다 ×2 | `6 << 1` = **12** |
| `>>` 오른쪽 시프트 | 한 칸마다 ÷2 (몫) | `6 >> 1` = **3** |

⚖️ **혼동 주의 — `&` vs `&&`**: `6 && 3`은 논리 연산(둘 다 참이므로 `1`), `6 & 3`은 비트 연산(`2`)입니다. 기호 하나 차이로 값이 달라지는 오류 찾기 단골입니다.

### 3-5. 조건문 3언어 비교

| 구조 | C | Java | Python |
|---|---|---|---|
| 기본 | `if (조건) { } else { }` — 조건에 괄호 필수 | C와 동일 | `if 조건:` — 괄호 대신 **콜론 + 들여쓰기** |
| 다중 분기 | `else if` | `else if` | **`elif`** (붙여 씀) |
| switch | `switch (n) { case 1: ... break; default: }` | C와 동일 (문자열도 가능) | **없음** — if/elif로 대신 (Python 3.10+의 match~case는 시험 대비 범위에서 제외) |

📌 **반드시 암기 — switch의 fall-through**: case가 일치하면 그 지점부터 실행을 시작하고, **`break`를 만날 때까지 아래 case까지 계속 실행**합니다. `default`는 일치하는 case가 없을 때 실행됩니다.

⚖️ **혼동 비교 — 이 강의 3대 혼동**

| 혼동 | 구분 |
|---|---|
| `=` vs `==` | `=`는 대입, `==`는 비교. `if (a = 5)`는 C에서 "5를 대입하고 그 값 5(참)"로 평가되어 **항상 참**이 되는 논리 오류 (Java·Python은 컴파일/문법 에러 — ⑤ 참고) |
| `0 < a < 10` 연쇄 비교 | **C·Java에서는 의도대로 동작하지 않음** — `(0 < a)`의 결과 0 또는 1과 10을 비교해 사실상 항상 참. **Python만 연쇄 비교를 지원** (`0 < a < 10`이 수학처럼 동작). 언어 차이 오답 포인트 |
| 삼항 어순 | C·Java `조건 ? 참 : 거짓` / Python `참 if 조건 else 거짓` — Python은 참값이 문장 맨 앞 |

### Step 2. 증감 연산자 추적

**언어: C · 난이도: 🟡 기본 · 학습 개념: 전위/후위 증감**

```c
#include <stdio.h>
int main(void) {
    int a = 5, b, c;
    b = a++;
    c = ++a;
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```

| 실행한 줄 | a | b | c | 설명 |
|---|---|---|---|---|
| `int a = 5, b, c;` | 5 | ? | ? | |
| `b = a++;` | 6 | 5 | ? | 후위: 현재값 5를 b에 **먼저 주고** a는 6으로 |
| `c = ++a;` | 7 | 5 | 7 | 전위: a를 7로 **먼저 올리고** 그 값을 c에 |

```
$ gcc inc.c -o inc && ./inc
7 5 7
```

- ⚠️ 한 문장 안에서 같은 변수를 두 번 이상 증감하는 코드(예: `a++ + ++a`)는 C에서 결과가 보장되지 않는 잘못된 코드라 시험에도 적합하지 않습니다. 본 과정은 항상 문장을 나눈 형태로 훈련합니다.

### Step 3. 우선순위와 복합 대입의 함정

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 우선순위, 복합 대입, 논리값 표기**

```java
public class Op {
    public static void main(String[] args) {
        int a = 4;
        a *= 2 + 3;
        System.out.println(a);
        System.out.println(3 + 4 * 2);
        System.out.println(10 > 3 + 8);
        System.out.println(2 + 3 * 4 > 10 && 10 % 3 == 1);
    }
}
```

```
$ javac Op.java && java Op
20
11
false
true
```

계산 순서 해설 — ①`a *= 2 + 3`: 오른쪽 전체 `2+3=5`를 먼저 → `4*5=20` (`4*2+3=11`이 대표 오답). ②곱셈 먼저 `3+8=11`. ③`3+8=11`을 먼저 계산 후 `10 > 11` → `false`. ④3-2절의 예와 동일 → `true`. 같은 코드를 C로 짜면 ③④가 `0`, `1`로 출력됩니다(📌 표기 차이).

### Step 4. 비트 연산 계산

**언어: C · 난이도: 🟡 기본 · 학습 개념: 비트 AND/OR/XOR/시프트**

```c
#include <stdio.h>
int main(void) {
    int a = 6, b = 3;
    printf("%d %d %d\n", a & b, a | b, a ^ b);
    printf("%d %d\n", a << 1, a >> 1);
    return 0;
}
```

```
$ gcc bit.c -o bit && ./bit
2 7 5
12 3
```

풀이 절차: ①두 수를 2진수로 변환(6=110, 3=011) → ②자리끼리 연산(3-4절 표) → ③10진수로 복원. 시프트는 변환 없이 "왼쪽 = ×2, 오른쪽 = ÷2의 몫"으로 바로 계산해도 됩니다.

### Step 5. 조건문 — 같은 문제, 세 가지 문법

성적 85점의 등급(90 이상 A, 80 이상 B, 그 외 C)을 구합니다.

**언어: Python · 난이도: 🟢 입문 · 학습 개념: if/elif/else**

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
print(grade)
```

```
$ python grade.py
B
```

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 중첩 삼항 연산자**

```java
public class Grade {
    public static void main(String[] args) {
        int score = 85;
        String grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";
        System.out.println(grade);
    }
}
```

```
$ javac Grade.java && java Grade
B
```

실행 원리: 첫 조건 `85 >= 90` 거짓 → 거짓 자리의 **두 번째 삼항**으로 넘어감 → `85 >= 80` 참 → `"B"`. 조건을 위에서부터 차례로 거른다는 점에서 if/elif와 같은 구조입니다.

**언어: C · 난이도: 🟡 기본 · 학습 개념: switch fall-through**

```c
#include <stdio.h>
int main(void) {
    int n = 2;
    switch (n) {
        case 1: printf("A");
        case 2: printf("B");
        case 3: printf("C");
            break;
        default: printf("D");
    }
    return 0;
}
```

```
$ gcc sw.c -o sw && ./sw
BC
```

실행 원리: `n=2`이므로 `case 2`부터 시작해 `B` 출력 → **break가 없어 그대로 아래로 흘러** `case 3`의 `C`까지 출력 → break를 만나 종료. `default`는 실행되지 않습니다. "왜 A는 안 나오는가(시작점은 일치한 case)"와 "왜 C까지 나오는가(fall-through)"를 함께 설명할 수 있어야 합니다.

| `&&` 자리에 `&`를 씀 | C·Java | 논리 AND와 비트 AND 혼동 — `6 && 3`=1, `6 & 3`=2 | 조건 판정은 `&&`, 2진수 계산은 `&` |

| `error: expected expression before ':' token` | C | 삼항 연산자에서 참/거짓 값 하나를 빠뜨림 | `조건 ? 참값 : 거짓값` 세 부분을 모두 채운다 |

## ⑥ 확인 문제

1. [결과 예측] 다음 C 코드의 출력을 쓰시오.
   ```c
   int a = 3, b;
   b = a++ * 2;
   b = b + ++a;
   printf("%d %d", a, b);
   ```
2. [빈칸] 출력이 `짝수`가 되도록 빈칸에 연산자를 쓰시오.
   ```java
   int n = 8;
   System.out.println(n % 2 ___ 0 ? "짝수" : "홀수");
   ```
3. [오류 찾기] 다음 C 코드는 `n`이 1이면 `합격`만 출력하려는 의도로 작성되었다. 실제 출력과, 의도대로 고치는 방법을 쓰시오.
   ```c
   int n = 1;
   switch (n) {
       case 1: printf("합격");
       case 2: printf("불합격");
   }
   ```

<details>
<summary>정답과 해설</summary>

1. **`5 11`** — 추적: `b = a++ * 2` → 후위이므로 3을 사용해 b=6, a=4 / `b = b + ++a` → 전위이므로 a를 5로 올린 뒤 b=6+5=11.
   - 대표 오답: `5 13` — 첫 줄을 전위처럼 4×2=8로 계산한 경우. 후위는 "쓰고 나서 증가"입니다.
2. **`==`** — `8 % 2`는 0이고, `0 == 0`이 참이어야 "짝수"가 출력됩니다.
   - 대표 오답: `=` — 대입 연산자는 조건이 될 수 없어 Java에서는 컴파일 에러가 납니다(⑤ 둘째 행).
3. 실제 출력은 **`합격불합격`** — `case 1`에 break가 없어 `case 2`까지 흘러 내려갑니다(fall-through). 수정: `printf("합격");` 뒤에 **`break;`** 추가.
   - 오답 원인: "case 2 조건이 거짓이니 실행 안 된다"고 생각하는 것 — switch는 **시작점만 고르고, 멈춤은 break가** 담당합니다.

</details>

## 마무리

**오늘의 요약** — 우선순위 사다리(괄호 > 단항 > 산술 > 시프트 > 비교 > 비트 > 논리 > 삼항 > 대입)에서 대입이 꼴찌라는 것이 복합 대입 함정(`a *= 2+3` = 20)의 정체입니다. 증감은 "후위 = 쓰고 증가, 전위 = 증가하고 쓰기", 비트는 2진수 변환 후 자리끼리, switch는 "시작점은 case, 멈춤은 break"입니다. 논리값 표기(C `1` / Java `true` / Python `True`)는 답안 작성 함정입니다.

**복습 체크리스트**

- [ ] 우선순위 사다리를 안 보고 재현할 수 있다
- [ ] Step 2 추적표(`7 5 7`)를 안 보고 다시 만들 수 있다
- [ ] `6 & 3`, `6 | 3`, `6 ^ 3`, `6 << 1`을 즉답할 수 있다
- [ ] switch에서 break를 뺐을 때의 출력을 설명할 수 있다
- [ ] 세 언어의 삼항 연산자 어순 차이를 말할 수 있다

**과제** — ① `a = 7`로 바꾼 Step 2 추적표 만들기(예상 출력까지), ② `9 & 5`, `9 | 5`, `9 ^ 5`를 2진수 변환 과정과 함께 계산, ③ Step 5의 switch에서 `n = 4`일 때의 출력을 예측하고 온라인 컴파일러로 검증. (형성평가는 04강 과제에 통합)

**다음 강 예고** — 04강은 반복문(for·while·do-while)과 배열·문자열입니다. 중첩 반복 추적표가 이 과정 전체에서 가장 중요한 손 기술이며, 2주차 형성평가 10문항이 과제로 나갑니다.
