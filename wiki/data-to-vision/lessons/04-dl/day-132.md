## 2부 · 예측 vs 실제 산점도

### [Day 118](day-118.md)의 핵심 그래프입니다

```
x축: 실제값
y축: 예측값
대각선 y=x: 완벽한 예측
```

### ★ 회귀선의 기울기를 반드시 그립니다

```
기울기 1.0 → 편향 없음
기울기 0.7 → 극단값을 30% 덜 반영
기울기 0.5 → 심각한 평균 회귀
```

**우리 모델은 0.71입니다.**

### 점이 많으면 겹칩니다

| 데이터 크기 | 방법 |
|---|---|
| < 500 | 산점도 + `alpha=0.6` |
| 500 ~ 5,000 | 산점도 + `alpha=0.3` + 색상 밀도 |
| > 5,000 | **`hexbin`** 또는 2D 히스토그램 |

```python
ax.hexbin(y_true, y_pred, gridsize=40, cmap="Blues", mincnt=1)
```

## 3부 · 잔차 플롯

### ★ x축은 **예측값**입니다

```
✗ x축 = 실제값
   → 잔차와 실제값은 구조적으로 상관됨. 항상 우하향 패턴이 나타남

✓ x축 = 예측값
   → 패턴이 있으면 진짜 문제
```

**[Day 118](day-118.md)에서 강조한 내용입니다.**

### 읽는 법

| 패턴 | 의미 |
|---|---|
| 무작위 띠 | ✓ 정상 |
| **깔때기 (▷ 모양)** | 이분산 — 큰 값에서 오차 큼 |
| 곡선 | 비선형 관계 누락 |
| 계단/줄무늬 | 이산 타깃 (우리 경우) |

### 우리 타깃은 이산값입니다

```
할인율: 10, 15, 20, 25, 30, 33, 40, 50, ... 90

→ 잔차 플롯에 ★ 수평 줄무늬가 나타납니다
→ 이것은 정상입니다. 오해하지 마세요
```

## 5부 · 특성 중요도

### 3가지 방법 — 답이 다릅니다

| 방법 | 계산 | 장점 | 단점 |
|---|---|---|---|
| **내장 중요도** | 분할 이득 합 | 빠름 | 고카디널리티 편향 |
| **순열 중요도** | 섞었을 때 성능 하락 | 모델 무관 | 상관 특성 과소평가 |
| **그룹 순열** | 그룹을 함께 섞음 | ★ 상관 보정 | 그룹 정의 필요 |

**[Day 129](day-129.md)에서 그룹 순열이 개별 합의 3.0배임을 확인했습니다.**

### 시각화 규칙

```
① 상위 15~20개만
② 가로 막대 (라벨이 길어서)
③ 오차 막대 (순열은 반복 측정하므로)
④ 큰 값이 위로
```

## 6부 · SHAP (선택)

### 무엇인가

```
게임 이론의 Shapley 값
"이 예측이 평균에서 벗어난 정도를 각 특성에 공정하게 배분"
```

### 순열 중요도와의 차이

| | 순열 중요도 | SHAP |
|---|---|---|
| 범위 | 전역 (모델 전체) | **전역 + 개별 예측** |
| 부호 | 없음 (크기만) | **있음 (+/−)** |
| 비용 | 낮음 | 높음 (트리는 빠름) |

### 개별 예측 설명이 강점입니다

```
"이 게임의 예측 할인율 34%는
  · 출시 후 2,184일 경과   → +12%p
  · 최근 할인 이력 45%     → +8%p
  · 리뷰 8,412개           → -3%p
  · 정가 44,000원          → +2%p
  평균 22% + 19% = 41%..."
```

> ⚠️ **SHAP은 "이 특성 때문에 이렇게 됐다"는 인과가 아닙니다.**
> **"모델이 이 특성을 이렇게 썼다"는 설명일 뿐입니다.**

### Step 4. 그림 2 — 학습 곡선

```python
import matplotlib.pyplot as plt
import numpy as np
from sklearn.base import clone
from sklearn.model_selection import learning_curve

fig, axes = plt.subplots(1, 2, figsize=(17, 6))

# ── (a) 부스팅 반복별 손실 (Day 116) ──
ax = axes[0]
hgb = model.named_steps["m"]
train_loss = -np.asarray(hgb.train_score_)
val_loss = -np.asarray(hgb.validation_score_)
ep = np.arange(1, len(train_loss) + 1)
ax.plot(ep, train_loss, lw=2.2, label="학습", color=CB[0])
ax.plot(ep, val_loss, lw=2.2, label="내부 검증", color=CB[1])
best = int(np.argmin(val_loss)) + 1
ax.axvline(best, color=OK, ls="--", lw=2, label=f"최적 {best}회")
ax.axvspan(best, len(ep), alpha=0.10, color=BAD)
ax.set_xlabel("부스팅 반복")
ax.set_ylabel("손실 (음의 로그우도)")
ax.set_title("(a) 학습 곡선 — 조기 종료 지점")
ax.legend()

pos = best / len(ep) * 100
gap = (val_loss[best-1] - train_loss[best-1]) / abs(train_loss[best-1]) * 100
ax.text(0.98, 0.06, f"최적 위치 {pos:.0f}%\n격차 {gap:+.1f}%",
        transform=ax.transAxes, ha="right", fontsize=12,
        bbox=dict(boxstyle="round", fc="white", ec="gray", alpha=0.9))

# ── (b) 데이터 크기별 학습 곡선 ──
ax = axes[1]
sizes, tr_s, va_s = learning_curve(
    clone(model), X_dev, y_dev,
    train_sizes=np.linspace(0.15, 1.0, 8), cv=4,
    scoring="neg_mean_absolute_error", n_jobs=-1, random_state=SEED)
tr_m, va_m = -tr_s.mean(1), -va_s.mean(1)
ax.plot(sizes, tr_m, "o-", lw=2.2, ms=8, label="학습", color=CB[0])
ax.fill_between(sizes, -tr_s.max(1), -tr_s.min(1), alpha=0.15, color=CB[0])
ax.plot(sizes, va_m, "s-", lw=2.2, ms=8, label="검증", color=CB[1])
ax.fill_between(sizes, -va_s.max(1), -va_s.min(1), alpha=0.15, color=CB[1])
ax.axhline(BASE_MAE_RULE, color=BAD, ls="--", lw=2, label="규칙 베이스라인")
ax.set_xlabel("학습 데이터 크기 (건)")
ax.set_ylabel("MAE (%p)")
ax.set_title("(b) 데이터 크기별 성능 — 더 모으면 좋아지는가")
ax.legend()

slope = (va_m[-1] - va_m[-3]) / (sizes[-1] - sizes[-3]) * 1000
```

```python
    ax.axvline(0, color="black", lw=2)
    ax.set_yticks(range(len(top)))
    ax.set_yticklabels(top["특성"], fontsize=11)
    ax.set_xlabel("SHAP 값 (예측에 대한 기여, %p)")
    ax.set_title(f"최악 오차 사례: {row['name']}\n"
                 f"실제 {row['실제']:.0f}%  예측 {row['예측']:.1f}%  "
                 f"오차 {row['오차']:+.1f}%p")
    fig.tight_layout()
    save(fig, "fig08_shap_worst",
         "최악 사례에서도 모델은 평균 근처를 가리켰다 — 극단값 신호가 데이터에 없음")
    plt.show()

    print(f"\n[{row['name']} 예측 분해]")
    print(f"  기준값(평균)   : {explainer.expected_value:>8.2f}%")
    for _, r in top.iloc[::-1].head(6).iterrows():
        print(f"  {r['특성'][:28]:<30}{r['SHAP']:>+8.2f}%p")
    print(f"  {'…나머지':<30}{sv[worst].sum() - top['SHAP'].sum():>+8.2f}%p")
    print(f"  {'─'*38}")
    print(f"  {'최종 예측':<30}{explainer.expected_value + sv[worst].sum():>8.2f}%")
    print(f"  {'실제':<30}{row['실제']:>8.0f}%")
```

## ⑤ 자주 하는 실수

### 잔차 플롯의 x축을 실제값으로

```
✗ ax.scatter(y_true, resid)
✓ ax.scatter(y_pred, resid)
```

**실제값을 쓰면 없는 문제가 보이고 있는 문제가 숨습니다.**

### `axes.unicode_minus` 를 안 끔

```
y축: □5, □10, 0, 5, 10
```

### 막대그래프에 n을 안 씀

```
"76~90% 구간이 MAE 38!"
n = 18 입니다
```

### 기준선이 없음

```
막대 6개만 있으면 "높다/낮다"를 판단할 기준이 없습니다
```

### 그래프를 20장 만듦

```
보고서 8장 + 부록 5장이면 충분합니다
```

**각 그래프가 어떤 문장을 뒷받침하는지 못 말하면 빼세요.**

### 발표용인데 폰트가 10pt

```
뒷자리에서 안 보입니다. 14pt 이상.
```

