## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 실험이 10개를 넘으면 기억으로 관리할 수 없다는 것을 이해하고, **기록 체계**를 세울 수 있다.
- **실험 기록표 표준 양식**을 만들고, 실험마다 자동으로 한 줄이 추가되게 할 수 있다.
- TensorBoard를 연동해 스칼라·그래프·하이퍼파라미터를 비교할 수 있다.
- `CSVLogger` 로 학습 로그를 남기고 나중에 복원할 수 있다.
- **모델·전처리기·설정·지표를 한 세트로 저장**해 재현 가능하게 만들 수 있다.
- 기록표에서 **무엇이 성능에 기여했는지** 분석할 수 있다.

## ② 왜 필요한가

### 3주 뒤에 이 질문에 답해야 합니다

```
심사자: "Dropout을 0.2로 정한 근거가 무엇인가요?"
학생:   "...여러 개 해 봤는데 그게 제일 좋았습니다."
심사자: "얼마나 좋았나요?"
학생:   "...기억이 안 납니다."
```

**실험을 안 한 것이 아니라 기록을 안 한 것입니다.**

[Day 135](day-135.md) 발표에서 반드시 나오는 질문입니다.
**기록표 한 장이면 30초에 답할 수 있습니다.**

### 실험 10개를 넘으면 머리로 관리가 안 됩니다

```
실험 1~5:   기억 가능
실험 6~15:  "그게 몇 번이었더라?"
실험 16~:   완전히 뒤섞임
```

**[Day 130](day-130.md) 프로젝트에서 "누적 10회 이상"이 요구 조건입니다.**
**실제로는 20~30회를 하게 됩니다.**

### 기록이 없으면 같은 실험을 반복합니다

```
월요일: lr=1e-2 시도 → 나빴음
목요일: "lr을 좀 올려 볼까?" → lr=1e-2 다시 시도 → 나빴음
```

**시간을 두 번 씁니다.** 프로젝트 5일 중 하루를 이렇게 날립니다.

### 그리고 무엇이 효과였는지 모릅니다

```
실험 1: MAE 5,200
실험 2: 구조 바꾸고 + 로그 변환하고 + lr 바꿈 → MAE 4,100
```

**21% 개선했는데 셋 중 무엇 때문인지 모릅니다.**

**기록표가 있으면**

```
E01  기준선                    5,200
E02  E01 + 로그 변환            4,600   (-11.5%)  ← 로그 변환이 주역
E03  E02 + 구조 128-64-32      4,480   ( -2.6%)
E04  E03 + lr 3e-4             4,100   ( -8.5%)  ← 학습률도 큼
```

**한 번에 하나씩 바꾸고 기록하면 기여도가 보입니다.**

```
① 실험 기록표 표준 양식
② 실험을 돌리면 자동으로 한 줄이 추가되는 함수
```

## ③ 개념 설명

### 실험 기록표 표준 양식

**[README](README.md)에서 제시한 양식을 확장합니다.**

| 그룹 | 열 | 설명 |
|---|---|---|
| **식별** | `exp_id` | E001, E002... 고유 번호 |
| | `timestamp` | 실행 시각 |
| | `parent` | 어떤 실험에서 파생됐는가 |
| **데이터** | `data_version` | v1, v2... 데이터가 바뀌면 증가 |
| | `n_train` / `n_val` | 샘플 수 |
| | `split_seed` | 분할 seed |
| **전처리** | `preprocess` | 요약 문자열 |
| | `target_transform` | none / log1p / ... |
| **모델** | `model_type` | ridge / hgb / nn |
| | `architecture` | 128-64-32 |
| | `n_params` | 파라미터 수 |
| **하이퍼파라미터** | `lr` / `batch_size` / `dropout` / ... | |
| **결과** | `train_mae` / `val_mae` / `val_rmse` / `val_r2` | |
| | `best_epoch` / `n_epochs` | |
| | `train_time_s` | 학습 시간 |
| **진단** | `gap` / `curve_diagnosis` | [Day 117](day-117.md) |
| | `worst_bin_mae` | [Day 118](day-118.md) |
| **★ 판단** | **`observation`** | **무엇을 봤는가** |
| | **`next_action`** | **다음에 무엇을 할 것인가** |
| **산출물** | `model_path` / `log_path` / `figure_path` | |

> **`observation` 과 `next_action` 이 없으면 기록이 아니라 로그입니다.**
> [Day 079](../03-ml/day-079.md)에서 이미 강조한 내용입니다.

### 한 번에 하나씩 — `parent` 열의 역할

```
E01 (기준선)
 ├─ E02: E01 + 로그 변환
 │   ├─ E04: E02 + 구조 변경
 │   └─ E05: E02 + Dropout
 └─ E03: E01 + 구조 변경
```

**`parent` 를 기록하면 각 변경의 순수 효과를 계산할 수 있습니다.**

```python
효과 = 부모의 val_mae - 자식의 val_mae
```

### `data_version` 이 중요한 이유

```
E01~E05: 원본 데이터 (v1)
E06:     이상치 제거 후 (v2)      ← 여기서 MAE가 크게 떨어짐
E07~E10: v2 계속 사용
```

**v1과 v2의 성능은 직접 비교할 수 없습니다.** 데이터가 다르니까요.
**기록에 버전이 없으면 "E06에서 무엇이 좋아졌나"를 오해합니다.**

```python
HP_UNITS = hp.HParam("units", hp.Discrete([32, 64, 128]))

with tf.summary.create_file_writer(f"logs/hparam/{run}").as_default():

```

### TensorBoard vs CSV 기록표

| | TensorBoard | CSV 기록표 |
|---|---|---|
| 곡선 비교 | **최고** | 별도 코드 필요 |
| 하이퍼파라미터 표 | 좋음 (HPARAMS) | **좋음** |
| **관찰·다음 시도 기록** | **불가** | **가능** ★ |
| 보고서에 붙이기 | 스크린샷 | **표 그대로** |
| 오프라인 공유 | 로그 폴더 전체 | **파일 1개** |
| 정렬·필터·계산 | 제한적 | **자유** |

> **둘 다 씁니다.**
> **곡선은 TensorBoard, 판단은 CSV 기록표.**
> 이 과정에서는 **CSV 기록표를 주로** 쓰고 TensorBoard를 보조로 씁니다.

### Step 1. 실험 추적기 만들기

```python
import hashlib
import json
import time
from pathlib import Path

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.datasets import fetch_california_housing
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

SEED = 42
np.random.seed(SEED)
tf.random.set_seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

ROOT = Path("dl_course/tracking")
for sub in ["experiments", "logs", "figures"]:
    (ROOT / sub).mkdir(parents=True, exist_ok=True)


class ExperimentTracker:
    """실험을 돌리면 자동으로 기록표에 한 줄이 추가되는 추적기"""

    COLUMNS = [
        "exp_id", "timestamp", "parent", "data_version", "n_train", "n_val",
        "split_seed", "preprocess", "target_transform", "model_type",
        "architecture", "n_params", "lr", "batch_size", "dropout", "l2",
        "n_epochs", "best_epoch", "train_time_s",
        "train_mae", "val_mae", "val_rmse", "val_r2", "gap",
        "curve_diagnosis", "worst_bin_mae", "worst_bin_rate",
        "observation", "next_action", "artifact_dir",
    ]

    def __init__(self, root, name="experiments"):
        self.root = Path(root)
        self.csv_path = self.root / f"{name}.csv"
        if self.csv_path.exists():
            self.df = pd.read_csv(self.csv_path)
        else:
            self.df = pd.DataFrame(columns=self.COLUMNS)

    def next_id(self):
        return f"E{len(self.df) + 1:03d}"

    def log(self, **kwargs):
        """실험 결과 한 줄 추가"""
        row = {c: kwargs.get(c) for c in self.COLUMNS}
        row["exp_id"] = row["exp_id"] or self.next_id()
        row["timestamp"] = row["timestamp"] or time.strftime("%Y-%m-%d %H:%M:%S")
        self.df = pd.concat([self.df, pd.DataFrame([row])], ignore_index=True)
        self.save()
        return row["exp_id"]

    def save(self):
        self.csv_path.parent.mkdir(parents=True, exist_ok=True)
        self.df.to_csv(self.csv_path, index=False, encoding="utf-8-sig")

    def annotate(self, exp_id, observation=None, next_action=None):
        """나중에 관찰·다음 시도를 채워 넣기"""
        idx = self.df.index[self.df["exp_id"] == exp_id]
        if len(idx) == 0:
            raise KeyError(exp_id)
        if observation is not None:
            self.df.loc[idx, "observation"] = observation
        if next_action is not None:
            self.df.loc[idx, "next_action"] = next_action
        self.save()

    def view(self, cols=None, sort_by="val_mae", top=None):
        cols = cols or ["exp_id", "parent", "data_version", "architecture",
                        "lr", "dropout", "target_transform",
                        "val_mae", "gap", "curve_diagnosis"]
        d = self.df[cols].sort_values(sort_by)
        return d.head(top) if top else d

    def lineage(self, exp_id):
        """조상 계보 추적"""
        chain = []
        cur = exp_id
        while cur and not pd.isna(cur):
            r = self.df[self.df["exp_id"] == cur]
            if r.empty:
                break
            chain.append(cur)
            cur = r.iloc[0]["parent"]
        return list(reversed(chain))

    def effect(self, exp_id):
        """부모 대비 효과"""
        r = self.df[self.df["exp_id"] == exp_id]
        if r.empty or pd.isna(r.iloc[0]["parent"]):
            return None
        p = self.df[self.df["exp_id"] == r.iloc[0]["parent"]]
        if p.empty:
            return None
        before, after = p.iloc[0]["val_mae"], r.iloc[0]["val_mae"]
        return {"exp_id": exp_id, "parent": r.iloc[0]["parent"],
                "before": before, "after": after,
                "delta": round(after - before, 4),
                "개선율(%)": round((before - after) / before * 100, 2)}


tracker = ExperimentTracker(ROOT)
print("=" * 72)
print("실험 추적기 초기화")
print("=" * 72)
print(f"기록 파일 : {tracker.csv_path}")
print(f"기존 실험 : {len(tracker.df)}건")
print(f"열 개수   : {len(tracker.COLUMNS)}")
print("\n[열 목록]")
for i in range(0, len(tracker.COLUMNS), 5):
    print("  " + "  ".join(f"{c:<18}" for c in tracker.COLUMNS[i:i+5]))
print("=" * 72)
```

### Step 2. 실험 실행 함수 — 자동 기록

```python
import hashlib
import json
import time
from pathlib import Path

import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers, regularizers
from tensorflow.keras.callbacks import (CSVLogger, EarlyStopping,
                                        ModelCheckpoint, ReduceLROnPlateau,
                                        TensorBoard)

# ── 데이터 준비 ──
raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

y_bins = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)


def data_hash(*frames):
    h = hashlib.md5()
    for f in frames:
        h.update(pd.util.hash_pandas_object(f, index=True).values.tobytes())
    return h.hexdigest()[:12]


def run_experiment(tracker, *, parent=None, data_version="v1",
                   units=(64, 32), dropout=0.0, l2=0.0, lr=1e-3,
                   batch_size=64, epochs=300, scaler="standard",
                   target_transform="none", use_tensorboard=True,
                   observation=None, next_action=None,
                   Xtr_raw=X_train, ytr=y_train, Xva_raw=X_val, yva=y_val):
    """실험 하나를 실행하고 아티팩트를 저장하고 기록표에 한 줄 추가"""
    exp_id = tracker.next_id()
    art = tracker.root / "experiments" / exp_id
    art.mkdir(parents=True, exist_ok=True)

    # ── 전처리 ──
    from sklearn.preprocessing import MinMaxScaler, RobustScaler, StandardScaler
    sc_map = {"standard": StandardScaler, "robust": RobustScaler,
              "minmax": MinMaxScaler}
    sc = sc_map[scaler]().fit(Xtr_raw)
    Xtr, Xva = sc.transform(Xtr_raw), sc.transform(Xva_raw)

    if target_transform == "log1p":
        ytr_fit, yva_fit = np.log1p(ytr), np.log1p(yva)
    else:
        ytr_fit, yva_fit = ytr, yva

    # ── 모델 ──
    tf.random.set_seed(SEED)
    m = keras.Sequential([layers.Input(shape=(Xtr.shape[1],))])
    for u in units:
        m.add(layers.Dense(u, activation="relu",
                           kernel_regularizer=regularizers.l2(l2) if l2 else None))
        if dropout > 0:
            m.add(layers.Dropout(dropout))
    m.add(layers.Dense(1))
    m.compile(optimizer=keras.optimizers.Adam(lr), loss="mse", metrics=["mae"])

    # ── 콜백 ──
    cbs = [
        CSVLogger(art / "history.csv"),
        EarlyStopping(monitor="val_loss", patience=25,
                      restore_best_weights=True, verbose=0),
        ReduceLROnPlateau(monitor="val_loss", factor=0.5, patience=10,
                          min_lr=1e-6, verbose=0),
        ModelCheckpoint(art / "model.keras", monitor="val_loss",
                        save_best_only=True, verbose=0),
    ]
    if use_tensorboard:
        cbs.append(TensorBoard(log_dir=str(tracker.root / "logs" / exp_id),
                               histogram_freq=0))

    t0 = time.perf_counter()
    h = m.fit(Xtr, ytr_fit, validation_data=(Xva, yva_fit),
              epochs=epochs, batch_size=batch_size, callbacks=cbs, verbose=0)
    train_time = time.perf_counter() - t0

    # ── 평가 (원래 공간에서) ──
    def to_orig(p):
        return np.expm1(p) if target_transform == "log1p" else p

    pred_tr = to_orig(m.predict(Xtr, verbose=0).ravel())
    pred_va = to_orig(m.predict(Xva, verbose=0).ravel())

    train_mae = mean_absolute_error(ytr, pred_tr)
    val_mae = mean_absolute_error(yva, pred_va)
    val_rmse = float(np.sqrt(mean_squared_error(yva, pred_va)))
    val_r2 = r2_score(yva, pred_va)

    # ── 곡선 진단 (Day 117) ──
    tr_l = np.asarray(h.history["loss"], dtype=float)
    va_l = np.asarray(h.history["val_loss"], dtype=float)
    best_ep = int(np.argmin(va_l)) + 1
    n_ep = len(tr_l)
    gap = float(va_l[-1] - tr_l[-1])
    osc = float(np.abs(np.diff(tr_l)).mean() / tr_l.mean())

    diag = []
    if osc > 0.05:
        diag.append("진동")
    if gap > 0.05:
        diag.append("과적합")
    if gap < -0.02:
        diag.append("val<train")
    if best_ep / n_ep > 0.9:
        diag.append("에폭부족")
    if best_ep / n_ep < 0.2:
        diag.append("조기최적")
    curve_diag = "·".join(diag) if diag else "안정"

    # ── 구간별 (Day 118) ──
    bins = pd.qcut(pd.Series(np.asarray(yva)), q=6, duplicates="drop")
    t = pd.DataFrame({"actual": np.asarray(yva), "abs_err": np.abs(np.asarray(yva) - pred_va),
                      "bin": bins})
    g = t.groupby("bin", observed=True).agg(mae=("abs_err", "mean"),
                                            am=("actual", "mean"))
    worst_bin_mae = float(g["mae"].max())
    worst_bin_rate = float((g["mae"] / g["am"]).max() * 100)

    # ── 아티팩트 저장 ──
    import joblib
    joblib.dump(sc, art / "preprocessor.joblib")

    config = {
        "exp_id": exp_id, "parent": parent,
        "timestamp": time.strftime("%Y-%m-%d %H:%M:%S"),
        "seed": SEED, "data_version": data_version,
        "data_hash": data_hash(Xtr_raw, pd.Series(ytr)),
        "library_versions": {"tensorflow": tf.__version__,
                             "numpy": np.__version__, "pandas": pd.__version__},
        "preprocess": {"scaler": scaler, "target_transform": target_transform},
        "model": {"type": "nn", "units": list(units),
                  "dropout": dropout, "l2": l2, "n_params": int(m.count_params())},
        "training": {"lr": lr, "batch_size": batch_size, "epochs": epochs},
    }
    (art / "config.json").write_text(json.dumps(config, indent=2, ensure_ascii=False),
                                     encoding="utf-8")

    metrics = {"train_mae": round(train_mae, 4), "val_mae": round(val_mae, 4),
               "val_rmse": round(val_rmse, 4), "val_r2": round(val_r2, 4),
               "best_epoch": best_ep, "n_epochs": n_ep,
               "train_time_s": round(train_time, 1),
               "gap": round(gap, 4), "curve_diagnosis": curve_diag,
               "worst_bin_mae": round(worst_bin_mae, 4),
               "worst_bin_rate": round(worst_bin_rate, 2)}
    (art / "metrics.json").write_text(json.dumps(metrics, indent=2, ensure_ascii=False),
                                      encoding="utf-8")

    # ── 곡선 그림 ──
    fig, ax = plt.subplots(1, 2, figsize=(13, 4.6))
    ep = np.arange(1, n_ep + 1)
    ax[0].plot(ep, tr_l, label="train"); ax[0].plot(ep, va_l, label="val")
    ax[0].axvline(best_ep, color="green", ls="--", label=f"best {best_ep}")
    ax[0].set_xlabel("epoch"); ax[0].set_ylabel("loss")
    ax[0].set_title(f"{exp_id} loss"); ax[0].legend(fontsize=8)
    ax[1].scatter(yva, pred_va, s=4, alpha=0.15)
    lo, hi = float(np.min(yva)), float(np.max(yva))
    ax[1].plot([lo, hi], [lo, hi], "r--")
    ax[1].set_xlabel("actual"); ax[1].set_ylabel("pred")
    ax[1].set_title(f"{exp_id} val MAE {val_mae:.4f}")
    fig.tight_layout()
    fig.savefig(art / "curve.png", dpi=100, bbox_inches="tight")
    plt.close(fig)

    # ── 기록표에 한 줄 ──
    tracker.log(
        exp_id=exp_id, parent=parent, data_version=data_version,
        n_train=len(Xtr_raw), n_val=len(Xva_raw), split_seed=SEED,
        preprocess=f"{scaler}", target_transform=target_transform,
        model_type="nn", architecture="-".join(map(str, units)) or "linear",
        n_params=int(m.count_params()), lr=lr, batch_size=batch_size,
        dropout=dropout, l2=l2, **metrics,
        observation=observation, next_action=next_action,
        artifact_dir=str(art),
    )
    return exp_id, m, h, metrics
```

```python
def verify_artifact(art_dir, X_val, y_val, tolerance=1e-3):
    """저장된 아티팩트만으로 기록된 성능이 재현되는가"""
    checks = []
    art = Path(art_dir)

    # 필수 파일
    for f in ["config.json", "metrics.json", "model.keras", "preprocessor.joblib"]:
        checks.append((f"파일 {f}", (art / f).exists()))

    if not all(ok for _, ok in checks):
        return checks

    config = json.loads((art / "config.json").read_text(encoding="utf-8"))
    metrics = json.loads((art / "metrics.json").read_text(encoding="utf-8"))

    # 버전
    for lib, ver in config.get("library_versions", {}).items():
        cur = {"tensorflow": tf.__version__, "numpy": np.__version__,
               "pandas": pd.__version__}.get(lib)
        checks.append((f"버전 {lib}", ver == cur))

    # 재현
    m = tf.keras.models.load_model(art / "model.keras")
    sc = joblib.load(art / "preprocessor.joblib")
    p = m.predict(sc.transform(X_val), verbose=0).ravel()
    if config["preprocess"]["target_transform"] == "log1p":
        p = np.expm1(p)
    repro = mean_absolute_error(y_val, p)
    checks.append(("성능 재현", abs(repro - metrics["val_mae"]) < tolerance))

    return checks
```

```
  ★ 실패한 시도 5건도 기록에 남아 있음
```

**채점 기준**

| 항목 | 배점 | 감점 |
|---|---|---|
| ① 표준 양식 (20열+) | 10 | **`observation`/`next_action` 없으면 -8** |
| ② 자동 기록 함수 | 15 | 손으로 기록하면 -10 |
| ③ **실험 12회, 한 번에 하나씩** | **20** | **한 번에 여러 개 바꾼 실험당 -3** |
| ④ 기여도 분석 | 15 | `parent` 없으면 0점 |
| ⑤ 계보 + 전체 개선율 | 10 | — |
| ⑥ TensorBoard | 10 | 실험별 디렉터리 분리 안 하면 -5 |
| ⑦ **아티팩트 재현 검증** | **15** | **전처리기 저장 없으면 -10** |
| ⑧ 발표용 요약표 | 5 | — |

> **③에서 "한 번에 하나씩"을 지키지 않으면 ④가 무의미해집니다.**
> **실험 설계 자체가 이 과제의 핵심입니다.**
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 왜 기록하는가 | **실험 10개 넘으면 기억으로 불가.** 3주 뒤 질문에 답해야 함 |
| 기록표 핵심 열 | 식별 · 데이터 · 전처리 · 모델 · 하이퍼파라미터 · 결과 · 진단 · **판단** |
| **`observation`** | **무엇을 봤는가.** 없으면 로그이지 기록이 아님 |
| **`next_action`** | **다음에 무엇을 할 것인가** |
| **`parent`** | 어디서 파생됐는가. **기여도 계산의 전제** |
| `data_version` | 데이터가 바뀌면 증가. **버전이 다르면 직접 비교 불가** |
| 한 번에 하나씩 | 여러 개 바꾸면 원인을 모름 |
| 자동 기록 | **실험 함수 안에서.** 손으로 하면 반드시 빠뜨림 |
| 매 실험마다 저장 | 루프 끝이 아니라 **안에서** CSV 저장 |
| TensorBoard | **곡선 비교 최고.** 실험별 디렉터리 분리 필수 |
| HPARAMS | 하이퍼파라미터 × 성능 표·평행좌표 |
| CSV vs TB | **곡선은 TB, 판단은 CSV** |
| 아티팩트 한 세트 | config · model · **preprocessor** · history · metrics · figure · notes |
| **전처리기 저장** | **없으면 재현 불가.** 가장 흔한 실수 |
| 재현 검증 | 저장된 것만으로 기록된 성능이 나오는가 |
| 실패 기록 | **실패도 정보.** 보고서의 "실패한 시도" 절 |

**오늘 반드시 기억할 세 가지**
> ① **실험 함수 안에서 자동으로 기록하세요.** 손으로 적으면 반드시 빠뜨립니다.
> ② **`parent` 와 `한 번에 하나씩`이 기여도 분석의 전제입니다.**
> ③ **전처리기를 반드시 함께 저장하세요.** 모델만 있으면 재현이 불가능합니다.

**과제** — 실험 기록표 템플릿을 만드세요.

**필수 포함 항목**

| 항목 | 내용 |
|---|---|
| 1 | **기록표 표준 양식** — 열 20개 이상. `observation`·`next_action`·`parent` 필수 |
| 2 | **실험 자동 기록 함수** — 학습 + 평가 + 진단 + 아티팩트 저장 + 기록 한 줄 |
| 3 | **실험 12회 이상** — 라운드별로 **한 번에 하나씩** 변경 |
| 4 | 각 실험의 **관찰과 다음 시도**를 실제로 채울 것 |
| 5 | **부모 대비 기여도 표** — 변경 내용 자동 추출 포함 |
| 6 | **변경 범주별 평균 기여도** (전처리/구조/규제/학습률 등) |
| 7 | 최고 실험의 **계보와 전체 개선율** |
| 8 | **TensorBoard 연동** — 실험별 디렉터리 + HPARAMS |
| 9 | **아티팩트 재현 검증** — 전체 실험에 대해 통과 여부 표 |
| 10 | **발표용 요약표** — 성능 여정 + 실패한 시도 |

**주의**
- 3번에서 **한 번에 여러 개를 바꾸면** 5번의 기여도 분석이 무의미해집니다.
- 4번을 나중에 몰아서 쓰면 기억이 안 납니다. **실험 직후에** 쓰세요.
- 9번에서 **전처리기를 저장 안 했다면 큰 감점**입니다.
- 10번의 "실패한 시도"를 빠뜨리지 마세요. [Day 134](day-134.md) 보고서의 필수 항목입니다.
