## ③ 개념 설명

### 변환별 박스 좌표 계산

**① 좌우 반전 (horizontal flip)**

```
이미지 너비 W

  픽셀:      x' = W - x
  VOC:       x1' = W - x2      ★ min/max가 뒤바뀜
             x2' = W - x1
             y는 그대로

  YOLO:      cx' = 1 - cx      ★ 이것만 하면 됨
             나머지 그대로
```

```
  원본                       반전
  ┌────────────┐            ┌────────────┐
  │  ┌──┐      │            │      ┌──┐  │
  │  │  │      │            │      │  │  │
  │  └──┘      │            │      └──┘  │
  └────────────┘            └────────────┘
   x1=100 x2=200             x1'=W-200  x2'=W-100
   (W=500)                   x1'=300    x2'=400
```

> **★ YOLO 형식이 압도적으로 간단합니다.** `cx = 1 - cx` 한 줄.
> 중심 기준 + 정규화의 이점이 여기서 드러납니다.

**② 상하 반전 (vertical flip)**

```
  YOLO:  cy' = 1 - cy
```

```
⚠️ CCTV에서는 쓰지 마세요.
   사람이 거꾸로 매달린 데이터는 실제로 없습니다.
   → 있지도 않은 상황을 배우게 만듭니다
```

**③ 이동 (translate)**

```
  픽셀:  x' = x + dx,  y' = y + dy
  YOLO:  cx' = cx + dx/W,  cy' = cy + dy/H

★ 이동하면 박스가 화면 밖으로 나갈 수 있음 → 잘린 박스 처리 필요
```

**④ 크기 조정 (scale)**

```
  YOLO 정규화 좌표는 ★ 전체 이미지를 같은 비율로 리사이즈하면 변하지 않음
  → 이것이 정규화의 최대 이점 (Day 136)

  단, 이미지 일부만 확대(zoom)하면 크롭이므로 아래 ⑤
```

**⑤ 크롭 (crop)**

```
  크롭 영역 (cx1, cy1, cx2, cy2)

  새 좌표 = 원래 좌표 - 크롭 시작점
    x1' = x1 - cx1
    y1' = y1 - cy1

  그다음 크롭 영역 밖을 잘라냄
    x1' = max(0, x1')
    x2' = min(crop_w, x2')

  ★ 잘린 뒤 남은 면적이 너무 작으면 박스를 버림
```

**⑥ 회전 (rotate)**

```
★ 가장 복잡합니다

  축 정렬 박스를 회전하면 더 이상 축 정렬이 아님
  → 회전된 네 꼭짓점을 감싸는 새 박스를 계산
  → ★ 박스가 원래보다 커짐
```

```
   원본 박스        15도 회전         새 축정렬 박스
   ┌──────┐          ╱‾‾‾╲            ┌────────┐
   │ 🐕   │    →    ╱ 🐕  ╲     →     │ ╱‾‾‾╲  │  ← 여백 포함
   └──────┘         ╲____╱             │╲____╱ │
                                       └────────┘
```

**회전 각도별 박스 팽창률**

| 각도 | 박스 면적 증가 (정사각형 기준) |
|---|---|
| 5° | +9% |
| 10° | +18% |
| **15°** | **+28%** |
| 30° | +58% |
| 45° | +100% |

> ⚠️ **검출에서 회전은 15도 이내로 제한하세요.**
> 그 이상이면 박스에 배경이 너무 많이 들어가 **라벨 품질이 나빠집니다.**
> [Day 138](day-138.md)에서 "박스를 여유 있게 치면 안 된다"고 배운 것을, 증강이 대신 저지르는 셈입니다.

### 잘린 박스 처리 기준

크롭·이동·회전 후 박스가 화면 밖으로 나갔을 때 **버릴지 남길지** 정해야 합니다.

**기준 3가지**

```
① 면적 비율 (visibility)
     남은 면적 / 원래 면적 ≥ 0.3  →  유지

② 절대 크기
     남은 박스의 짧은 변 ≥ 24px  →  유지

③ 둘 다
     ★ 권장
```

**Albumentations 의 파라미터**

```python
A.BboxParams(
    format="yolo",
    label_fields=["class_labels"],
    min_visibility=0.3,      # ★ 면적 30% 미만 남으면 버림
    min_area=576,            # ★ 24×24 = 576 픽셀 미만이면 버림
)
```

```
min_visibility 를 너무 높이면 (0.8)
  → 가장자리 객체가 다 사라짐
  → 실제 CCTV에서 가장자리 검출을 못 하게 됨

너무 낮추면 (0.05)
  → 손가락만 남은 박스가 "사람" 라벨로 남음
  → ★ 라벨 오염

권장: min_visibility=0.3 ~ 0.4
```

### ★ Mosaic — YOLO의 대표 증강

```
이미지 4장을 한 장으로 합칩니다

  ┌────────┬────────┐
  │  img1  │  img2  │      · 각 이미지에서 무작위 영역을 가져옴
  │   🐕   │   👤   │      · 박스도 함께 이동
  ├────────┼────────┤      · 경계에서 잘린 박스는 규칙대로 처리
  │  img3  │  img4  │
  │   🚗   │  (빈)  │
  └────────┴────────┘
```

**Mosaic의 효과**

| 효과 | 설명 |
|---|---|
| **작은 객체 학습** | 4장을 합치므로 각 객체가 작아짐 → 소형 객체에 강해짐 |
| **배치 다양성** | 한 장에 여러 상황이 섞임 |
| **배경 다양성** | 서로 다른 배경이 인접 |
| **정규화 효과** | 과적합 감소 |

```
★ 그런데 부작용도 있습니다

  · 실제로는 없는 부자연스러운 장면을 학습
  · 마지막 에폭까지 켜 두면 실제 분포와 멀어짐

→ Ultralytics는 ★ close_mosaic=10 으로
  마지막 10에폭에서 Mosaic을 끕니다 (기본 동작)
```

**MixUp — 두 이미지를 반투명하게 겹침**

```
result = 0.5 × img1 + 0.5 × img2
박스는 ★ 둘 다 유지
```

```
검출에서는 효과가 제한적입니다
· 겹쳐서 흐릿해진 객체의 라벨이 그대로 남음
· 기본값 0.0 (꺼짐)
→ ★ 우리는 쓰지 않습니다
```

**Copy-Paste — 객체를 오려 붙이기**

```
다른 이미지의 객체를 잘라내 현재 이미지에 붙임
→ ★ 희소 클래스를 늘리는 데 매우 효과적

단, 분할 마스크가 있어야 자연스럽습니다
(박스만 있으면 사각형이 붙어 티가 남)
```

### ★ CCTV 특화 증강

우리 프로젝트의 실제 운영 조건을 데이터에 미리 넣습니다.

| 상황 | 증강 | 파라미터 |
|---|---|---|
| **야간 · 저조도** | 밝기 감소 + 노이즈 | `RandomBrightnessContrast(-0.5, -0.2)` + `GaussNoise` |
| **적외선(IR) 야간** | 그레이스케일 + 대비 | `ToGray` + `CLAHE` |
| **모션 블러** | 움직이는 사람 | `MotionBlur(blur_limit=(5, 15))` |
| **역광** | 창문·조명 | `RandomSunFlare` 또는 밝기 그라디언트 |
| **비 · 눈** | 실외 카메라 | `RandomRain` · `RandomSnow` |
| **안개** | 새벽 | `RandomFog` |
| **카메라 노이즈** | 저가 센서 | `ISONoise` · `GaussNoise` |
| **JPEG 압축** | 전송 손실 | `ImageCompression(quality=(40, 80))` |
| **렌즈 흐림** | 초점 안 맞음 | `Defocus` · `GaussianBlur` |

> **★ 무엇을 넣을지는 "실제로 발생하는가"가 정합니다.**
> 실내 현관 카메라에 `RandomSnow` 를 넣으면 **없는 상황을 배우는** 것입니다.

## ④ 단계별 실습

### Step 1. 좌표 변환 직접 구현 — 원리 이해

```python
"""aug_manual.py — 증강 시 박스 좌표 변환 (원리 학습용)"""
import cv2
import numpy as np

import bbox_utils as B


def hflip(img, yolo_boxes):
    """좌우 반전 — YOLO 좌표는 cx만 바뀜"""
    out = cv2.flip(img, 1)
    boxes = [(cid, 1.0 - cx, cy, w, h) for cid, cx, cy, w, h in yolo_boxes]
    return out, boxes


def translate(img, yolo_boxes, dx_ratio, dy_ratio,
              min_visibility=0.3, border=(114, 114, 114)):
    """이동 — 화면 밖으로 나간 박스 처리 포함"""
    h, w = img.shape[:2]
    dx, dy = int(w * dx_ratio), int(h * dy_ratio)
    M = np.float32([[1, 0, dx], [0, 1, dy]])
    out = cv2.warpAffine(img, M, (w, h), borderValue=border)

    boxes = []
    for cid, cx, cy, bw, bh in yolo_boxes:
        x1, y1, x2, y2 = B.yolo_to_voc((cx, cy, bw, bh), w, h)
        x1, x2 = x1 + dx, x2 + dx
        y1, y2 = y1 + dy, y2 + dy
        orig_area = (x2 - x1) * (y2 - y1)

        cx1, cy1, cx2, cy2 = B.clip_voc((x1, y1, x2, y2), w, h)
        new_area = max(0, cx2 - cx1) * max(0, cy2 - cy1)
        if orig_area <= 0 or new_area / orig_area < min_visibility:
            continue                                    # ★ 너무 잘리면 버림
        boxes.append((cid, *B.voc_to_yolo((cx1, cy1, cx2, cy2), w, h)))
    return out, boxes


def crop(img, yolo_boxes, x1r, y1r, x2r, y2r, min_visibility=0.3):
    """비율로 지정한 영역 크롭"""
    h, w = img.shape[:2]
    cx1, cy1 = int(w * x1r), int(h * y1r)
    cx2, cy2 = int(w * x2r), int(h * y2r)
    out = img[cy1:cy2, cx1:cx2]
    nw, nh = cx2 - cx1, cy2 - cy1

    boxes = []
    for cid, cx, cy, bw, bh in yolo_boxes:
        x1, y1, x2, y2 = B.yolo_to_voc((cx, cy, bw, bh), w, h)
        orig_area = (x2 - x1) * (y2 - y1)
        nx1, ny1 = max(x1 - cx1, 0), max(y1 - cy1, 0)
        nx2, ny2 = min(x2 - cx1, nw), min(y2 - cy1, nh)
        new_area = max(0, nx2 - nx1) * max(0, ny2 - ny1)
        if orig_area <= 0 or new_area / orig_area < min_visibility:
            continue
        boxes.append((cid, *B.voc_to_yolo((nx1, ny1, nx2, ny2), nw, nh)))
    return out, boxes


def rotate(img, yolo_boxes, angle, min_visibility=0.3, border=(114, 114, 114)):
    """회전 — ★ 네 꼭짓점을 회전한 뒤 감싸는 새 박스를 만듦"""
    h, w = img.shape[:2]
    M = cv2.getRotationMatrix2D((w / 2, h / 2), angle, 1.0)
    out = cv2.warpAffine(img, M, (w, h), borderValue=border)

    boxes = []
    for cid, cx, cy, bw, bh in yolo_boxes:
        x1, y1, x2, y2 = B.yolo_to_voc((cx, cy, bw, bh), w, h)
        orig_area = (x2 - x1) * (y2 - y1)

        # 네 꼭짓점을 회전
        pts = np.array([[x1, y1], [x2, y1], [x2, y2], [x1, y2]], dtype=np.float32)
        pts = np.hstack([pts, np.ones((4, 1), dtype=np.float32)])
        rot = (M @ pts.T).T                                # (4, 2)

        nx1, ny1 = rot[:, 0].min(), rot[:, 1].min()
        nx2, ny2 = rot[:, 0].max(), rot[:, 1].max()
        nx1, ny1, nx2, ny2 = B.clip_voc((nx1, ny1, nx2, ny2), w, h)
        new_area = max(0, nx2 - nx1) * max(0, ny2 - ny1)
        if orig_area <= 0 or new_area / orig_area < min_visibility:
            continue
        boxes.append((cid, *B.voc_to_yolo((nx1, ny1, nx2, ny2), w, h)))
    return out, boxes
```

```python
"""augment_dataset.py — 오프라인 증강 실행"""
from pathlib import Path

import cv2
import numpy as np

from aug_pipeline import PIPELINES

IMG_EXTS = (".jpg", ".jpeg", ".png")


def load_yolo(txt):
    if not Path(txt).exists():
        return [], []
    boxes, labels = [], []
    for line in Path(txt).read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        p = line.split()
        labels.append(int(p[0]))
        boxes.append([float(v) for v in p[1:5]])
    return boxes, labels


def save_yolo(txt, boxes, labels):
    Path(txt).parent.mkdir(parents=True, exist_ok=True)
    body = "\n".join(f"{c} {b[0]:.6f} {b[1]:.6f} {b[2]:.6f} {b[3]:.6f}"
                     for b, c in zip(boxes, labels))
    Path(txt).write_text(body + ("\n" if body else ""), encoding="utf-8")


def augment_dataset(img_dir, lbl_dir, out_img, out_lbl, plan, seed=42):
    """plan: {'night': 2, 'degraded': 1, ...} — 파이프라인별 생성 배수"""
    img_dir, lbl_dir = Path(img_dir), Path(lbl_dir)
    out_img, out_lbl = Path(out_img), Path(out_lbl)
    out_img.mkdir(parents=True, exist_ok=True)
    out_lbl.mkdir(parents=True, exist_ok=True)

    import random
    random.seed(seed)
    np.random.seed(seed)

    stats = {k: {"images": 0, "boxes": 0, "dropped": 0} for k in plan}

    for p in sorted(img_dir.iterdir()):
        if p.suffix.lower() not in IMG_EXTS:
            continue
        img = cv2.imread(str(p))
        if img is None:
            continue
        boxes, labels = load_yolo(lbl_dir / (p.stem + ".txt"))

        for name, times in plan.items():
            tf = PIPELINES[name]
            for k in range(times):
                res = tf(image=img, bboxes=boxes, class_labels=labels)
                aug_img = res["image"]
                aug_boxes = [list(b) for b in res["bboxes"]]
                aug_labels = list(res["class_labels"])

                stem = f"{p.stem}_{name}{k}"
                cv2.imwrite(str(out_img / f"{stem}.jpg"), aug_img,
                            [cv2.IMWRITE_JPEG_QUALITY, 92])
                save_yolo(out_lbl / f"{stem}.txt", aug_boxes, aug_labels)

                stats[name]["images"] += 1
                stats[name]["boxes"] += len(aug_boxes)
                stats[name]["dropped"] += len(boxes) - len(aug_boxes)

    return stats


ROOT = Path("C:/vision/datasets/cctv")
```

```python
    """사전학습 모델이 사람을 찾을 수 있는가 = 사람 눈에도 보이는가의 대리 지표"""
```

### ① 원인

**원인 1 — `VerticalFlip(p=0.5)` ★★ 가장 심각**

```
CCTV 데이터에 거꾸로 뒤집힌 사람이 절반

실제로는 절대 없는 상황
→ 모델의 용량 절반을 쓸모없는 패턴에 소모
→ 정상 자세 학습이 오히려 약해짐
```

**원인 2 — `Rotate(limit=45)`**

```
45도 회전 시 박스 면적 +100%

  실제 사람      박스 안 내용
  ┌──────┐      사람 50% + 배경 50%
  │  👤  │  →   ★ 모델이 배경도 사람이라고 배움
  └──────┘

+ 회전 후 모서리에 회색 여백이 생김
  → 여백까지 박스에 들어감
```

**원인 3 — `brightness_limit=(-0.8, 0.8)` ★★**

```
-0.8: 거의 검은 화면 → 물체가 안 보임
+0.8: 거의 흰 화면   → 물체가 안 보임

p=0.9 이므로 90%의 이미지가 극단적 밝기
→ ★ 라벨은 있는데 볼 것이 없는 이미지가 대량 생성
→ "아무것도 없는 곳에 사람이 있다"를 학습
```

**원인 4 — `Blur(blur_limit=25)`**

```
25픽셀 블러는 형체가 완전히 뭉개지는 수준
p=0.7 → 70%가 심하게 흐릿

★ 게다가 Blur 는 균등 블러라 비현실적
  실제 CCTV의 흐림은 MotionBlur(방향성) 또는 Defocus(원형)
```

**원인 5 — `min_visibility=0.1`**

```
면적 10%만 남아도 유지
→ 45도 회전 + 이동으로 손끝만 남은 박스가 "사람" 라벨로 생존
→ ★ 라벨 오염
```

**원인 6 — 증강 배수 6배가 과함**

```
360 → 2,160 (6배)

원본 대비 증강본이 5/6 = 83%
→ 학습 데이터의 대부분이 인공적으로 왜곡된 이미지
→ 실제 분포와 멀어짐
```

**원인 7 — 증강 강도 검증을 안 함**

```
Step 6의 강도 점검을 했다면
brightness -0.8 에서 검출률이 5% 수준인 것이 즉시 드러났을 것
```

### ② 야간 IR 모드 시뮬레이션

**IR 영상의 특징 4가지**

```
① 흑백 (컬러 정보 없음)
② 근적외선 반사율에 따른 밝기 — 옷 색깔과 무관
③ IR LED 조명이 중앙에 집중 → ★ 가장자리가 어두움 (비네팅)
④ 센서 노이즈가 크고, 근거리 물체가 과다 노출
```

**구현**

```python
import albumentations as A
import cv2
import numpy as np


class IRVignette(A.ImageOnlyTransform):
    """IR LED 조명 특성 — 중앙이 밝고 가장자리가 어두움"""

    def __init__(self, strength=(0.35, 0.7), always_apply=False, p=1.0):
        super().__init__(p=p)
        self.strength = strength

    def apply(self, img, **params):
        h, w = img.shape[:2]
        s = np.random.uniform(*self.strength)
        yy, xx = np.mgrid[0:h, 0:w]
        cx, cy = w / 2, h / 2
        r = np.sqrt(((xx - cx) / cx) ** 2 + ((yy - cy) / cy) ** 2)
        mask = np.clip(1.0 - s * (r / np.sqrt(2)) ** 2, 0.15, 1.0)
        if img.ndim == 3:
            mask = mask[:, :, None]
        return np.clip(img.astype(np.float32) * mask, 0, 255).astype(np.uint8)


IR_NIGHT = A.Compose([
    A.HorizontalFlip(p=0.5),

    # ① 흑백화 — IR 은 컬러 정보가 없음
    A.ToGray(p=1.0),

    # ② 옷 색깔과 무관한 밝기 → 대비를 올려 재질감 강조
    A.CLAHE(clip_limit=(2.0, 4.0), tile_grid_size=(8, 8), p=0.8),

    # ③ IR LED 비네팅
    IRVignette(strength=(0.35, 0.70), p=0.9),

    # ④ 센서 노이즈
    A.GaussNoise(std_range=(0.05, 0.14), p=0.85),
    A.ISONoise(color_shift=(0.0, 0.02), intensity=(0.2, 0.6), p=0.6),

    # 전반적 어두움
    A.RandomBrightnessContrast(brightness_limit=(-0.30, -0.05),
                               contrast_limit=(0.05, 0.30), p=1.0),

    # 저가 카메라 압축
    A.ImageCompression(quality_range=(35, 70), p=0.5),
], bbox_params=BBOX_PARAMS)
```

**★ 시뮬레이션의 한계를 인정하기**

```
증강으로 만든 IR ≠ 진짜 IR

  진짜 IR 은 물질의 근적외선 반사율에 따라 밝기가 결정됨
  검은 옷이 IR 에서는 밝게 보이는 경우도 있음
  → 증강으로는 재현 불가

★ 결론
  증강은 "없는 것보다 낫다" 수준
  W34 라즈베리파이 실습 때 ★ 진짜 야간 영상을 반드시 수집합니다
  (Day 167 야간 촬영 테스트)
```

**검증 방법**

```
진짜 IR 영상 20장을 확보한 뒤
  ① 증강 IR 로만 학습한 모델을 진짜 IR 로 평가
  ② 얼마나 되는지 측정
  → 이것이 시뮬레이션의 실효성 증거
```

### ③ "센서등 3초 지연"이 만드는 특수 상황

**★ 이것이 이 환경의 가장 어려운 문제입니다.**


| `backlight` | 0.5 | 아침·저녁 역광 |
| `degraded` | 0.5 | 압축·블러 |
| **합계** | **4.5배** | |

```
원본 450장 → 증강 후 약 2,475장
```

> **★ 이 표가 "증강 계획서"입니다.**
> 각 줄에 **"어떤 실제 상황에 대응하는가"** 가 적혀 있어야 합니다.
> 이유 없는 증강은 넣지 마세요.

</details>

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 검출 증강의 차이 | ★ **박스 좌표도 함께 변해야 함** |
| 안 바꾸면 | 에러 없이 **반대로 학습됨** |
| 좌우 반전 | YOLO: **`cx = 1 - cx`** 한 줄 |
| 상하 반전 | ★ **CCTV에서는 쓰지 않음** |
| 이동 | `cx += dx/W` · 화면 밖 처리 필요 |
| 크롭 | 좌표 이동 후 클립 · **상대 크기가 커짐** |
| 회전 | 네 꼭짓점 회전 → 감싸는 새 박스 · **박스 팽창** |
| 회전 각도 | ★ **15도 이내** (면적 +28%) |
| 잘린 박스 | `min_visibility` **0.3~0.4** · `min_area` 24×24 |
| 제거율 목표 | **10% 이내** |
| Mosaic | 4장 합성 · **소형 객체에 강해짐** · `close_mosaic=10` |
| MixUp | 검출에서 효과 제한적 · **0 유지** |
| YOLO 내장 | `hsv_v` `fliplr` `mosaic` 이 핵심 |
| CCTV 특화 | **야간 · IR · 모션 블러 · 역광 · 압축** |
| 증강 선택 기준 | ★ **"실제로 발생하는가"** |
| 오프라인 | 특화 조건 · 확인 가능 |
| 온라인 | 기하·색상 · 매 에폭 다름 |
| ★ 절대 금지 | **증강본을 val에 넣기** |
| 강도 기준 | 원본 대비 검출률 **55% 이상** |
| 필수 절차 | ★ **생성 직후 시각 검증** |
| 최종 검증 | ★ **A/B 학습 비교** |

**오늘 반드시 기억할 세 가지**
> ① **이미지를 뒤집으면 박스도 뒤집어야 합니다.** 안 하면 에러 없이 반대로 학습됩니다.
> ② **증강본은 절대 val에 넣지 마세요.** 원본과 증강본이 train/val로 갈리면 누수입니다.
> ③ **증강 결과를 반드시 그려서 보세요.** 2분이면 됩니다. 안 보면 2시간을 날립니다.
