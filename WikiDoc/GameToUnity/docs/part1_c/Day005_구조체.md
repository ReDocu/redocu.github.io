## 2. 막히는 상황

어제 마지막 예고대로 몬스터를 세 마리로 늘려 보자.

```c
int slimeHp = 30,  slimeAtk = 8,  slimeDef = 3;
int goblinHp = 60, goblinAtk = 15, goblinDef = 6;
int dragonHp = 200, dragonAtk = 30, dragonDef = 12;
```

변수가 **아홉 개**가 됐다. 여기에 이름, 경험치, 골드까지 붙이면 열여덟 개다.
그리고 함수는 이렇게 된다.

```c
int Battle(int heroHp, int heroAtk, int heroDef,
           int monHp, int monAtk, int monDef, ...)   // 매개변수 지옥
```

```
   지금:   흩어진 변수들
           slimeHp   goblinHp   dragonHp
           slimeAtk  goblinAtk  dragonAtk      ← 어느 게 한 세트인지
           slimeDef  goblinDef  dragonDef         코드만 봐서는 모른다

   필요:   한 캐릭터 = 한 덩어리
           ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
           │ 슬라임        │  │ 고블린        │  │ 드래곤        │
           │  hp  30      │  │  hp  60      │  │  hp  200     │
           │  atk  8      │  │  atk 15      │  │  atk  30     │
           │  def  3      │  │  def  6      │  │  def  12     │
           └──────────────┘  └──────────────┘  └──────────────┘
```

> **관련된 값들을 하나로 묶는 방법이 필요하다.** → **구조체**

## 3. 개념

### 3-1. `struct` — 나만의 자료형 만들기

**왜 필요한가** — `int`, `float`은 값 하나만 담는다. 캐릭터는 값 여러 개가 한 세트다.

```c
struct Character
{
    char name[20];      // 이름
    int  hp;            // 현재 체력
    int  maxHp;         // 최대 체력
    int  atk;           // 공격력
    int  def;           // 방어력
};                      // ★ 세미콜론을 빼먹지 않는다
```

```
   struct Character 는 "설계도"다. 실제 그릇은 아직 없다.

   ┌─────────── struct Character (설계도) ──────────┐
   │  name[20]  │  hp  │ maxHp │  atk  │  def      │
   │  20바이트   │  4   │   4   │   4   │   4       │  = 36바이트
   └───────────────────────────────────────────────┘

   struct Character hero;    ← 이때 실제 메모리 36바이트가 잡힌다
   struct Character slime;   ← 또 36바이트
```

**변수 선언과 초기화**

```c
struct Character hero;                                    // 선언만
struct Character slime = { "슬라임", 30, 30, 8, 3 };      // 선언 + 초기화
```

> **초기화 값의 순서는 멤버 선언 순서와 정확히 같아야 한다.**
> `{ "슬라임", 30, 30, 8, 3 }` 에서 30이 두 개인 건 `hp`와 `maxHp`다. 순서가 어긋나면
> 공격력이 체력 자리에 들어가고, 컴파일은 되지만 게임이 이상해진다.

### 3-2. 멤버 접근 — 점 연산자 `.`

**왜 필요한가** — 덩어리 안에서 원하는 값 하나를 꺼내 쓰기 위해서.

```c
struct Character slime = { "슬라임", 30, 30, 8, 3 };

printf("%s의 HP: %d\n", slime.name, slime.hp);    // 읽기

slime.hp -= 10;                                    // 쓰기
slime.hp = 0;
```

```
   slime.hp
     ▲    ▲
     │    └── 어느 멤버를
     └─────── 어느 구조체 변수의
```

### 3-3. `typedef` — `struct`를 매번 쓰지 않기

**왜 필요한가** — `struct Character hero;` 에서 `struct`가 계속 붙는 게 번거롭다.

```c
typedef struct
{
    char name[20];
    int  hp;
    int  maxHp;
    int  atk;
    int  def;
} Character;              // ← 여기가 새 자료형 이름

// 이제 이렇게 쓴다
Character hero  = { "용사",   100, 100, 20, 5 };
Character slime = { "슬라임",  30,  30,  8, 3 };
```

| 방식 | 선언 |
|---|---|
| `struct` | `struct Character hero;` |
| `typedef` | `Character hero;` ← **이걸 쓴다** |

### 3-4. 구조체를 함수에 넘기기

**왜 필요한가** — 매개변수 6개가 1개로 줄어든다.

```c
// Day 4:  매개변수 지옥
int CalcDamage(int atkHp, int atkAtk, int atkDef,
               int defHp, int defAtk, int defDef);

// 오늘:  깔끔
int CalcDamage(Character attacker, Character defender)
{
    int damage = attacker.atk - defender.def;
    if (damage < 1) damage = 1;
    return damage;
}

// 사용
int dmg = CalcDamage(hero, slime);
```

> ### ⚠️ 구조체도 **값으로 복사**되어 넘어간다 (Day 4의 그 벽)
>
> ```c
> void Damage(Character c, int amount)
> {
>     c.hp -= amount;              // 사본의 hp만 줄어든다
> }
>
> Damage(slime, 10);
> printf("%d\n", slime.hp);        // 30 — 안 바뀐다!
> ```
>
> ```
>   main 의 slime            Damage 의 c
>   ┌────────────┐  통째로   ┌────────────┐
>   │ hp    30   │ ────────▶ │ hp    30   │
>   │ atk    8   │  36바이트 │ atk    8   │
>   │ def    3   │  복사     │ def    3   │
>   └────────────┘           └────────────┘
>        ▲                        │ -10
>        │                        ▼
>        └── 그대로              hp 20  ← 사본만. 함수 끝나면 사라짐
> ```
>
> **오늘의 해결책** — 구조체째로 `return` 받는다.
>
> ```c
> Character ApplyDamage(Character c, int amount)
> {
>     c.hp -= amount;
>     if (c.hp < 0) c.hp = 0;
>     return c;                     // 바뀐 구조체를 통째로 돌려준다
> }
>
> slime = ApplyDamage(slime, 10);   // 받아서 다시 넣는다  ✔
> ```
>
> 근본적인 해결(주소를 넘기기)은 **Day 18 포인터**에서 한다.
> 그때 `ApplyDamage(&slime, 10);` 한 줄로 끝나는 것을 보게 된다.

### 3-5. 구조체 배열 — 몬스터 목록

**왜 필요한가** — 몬스터가 셋이면 변수 셋. 열이면 열. 이걸 하나로 묶는다.

```c
Character monsters[3] = {
    { "슬라임",  30,  30,  8,  3 },
    { "고블린",  60,  60, 15,  6 },
    { "드래곤", 200, 200, 30, 12 }
};

// 접근
printf("%s\n", monsters[0].name);      // 슬라임
monsters[1].hp -= 10;                  // 고블린 HP 감소
```

```
   monsters[0]        monsters[1]        monsters[2]
   ┌────────────┐     ┌────────────┐     ┌────────────┐
   │ 슬라임      │     │ 고블린      │     │ 드래곤      │
   │ hp     30  │     │ hp     60  │     │ hp    200  │
   │ atk     8  │     │ atk    15  │     │ atk    30  │
   │ def     3  │     │ def     6  │     │ def    12  │
   └────────────┘     └────────────┘     └────────────┘
```

> **배열은 내일(Day 11)에 본격적으로 배운다.** 오늘은 "이렇게 묶을 수 있다"는 것만 맛본다.
> 몬스터를 한 마리 추가하려면 **줄 하나만 추가**하면 된다는 것을 확인하는 게 목적이다.

### 3-6. 문자열 멤버 다루기 — 주의점

**왜 필요한가** — C의 문자열은 배열이라 대입이 안 된다. 오늘 반드시 부딪힌다.

```c
Character c;

c.name = "슬라임";              // ✘ 오류! 배열에는 = 로 대입 불가

strcpy_s(c.name, 20, "슬라임"); // ✔ 복사 함수 사용 (<string.h>)

Character c2 = { "슬라임", ... };  // ✔ 초기화 시점에는 가능
```

```
   char name[20];

   ┌───┬───┬───┬───┬───┬───┬─── ... ───┐
   │ 슬 │ 라 │ 임 │ \0│   │   │           │   ← \0(널 문자)로 끝을 표시
   └───┴───┴───┴───┴───┴───┴─── ... ───┘

   '\0'까지가 문자열이다. 이게 없으면 어디서 끝나는지 몰라 쓰레기가 딸려 나온다.
```

## 4. 따라 만들기

### Step 1 — 구조체 정의하고 용사 만들기

```c
#include <stdio.h>

typedef struct              // ← 추가
{
    char name[20];
    int  hp;
    int  maxHp;
    int  atk;
    int  def;
} Character;

void PrintStatus(Character c);

int main(void)
{
    Character hero = { "용사", 100, 100, 20, 5 };   // ← 변수 5개가 1개로

    PrintStatus(hero);

    return 0;
}

void PrintStatus(Character c)                       // ← 매개변수 1개
{
    printf("  %-8s HP %3d/%3d  ATK %2d  DEF %2d\n",
           c.name, c.hp, c.maxHp, c.atk, c.def);
}
```

**✅ 여기까지 실행하면** — `용사     HP 100/100  ATK 20  DEF  5` 한 줄이 출력된다.

### Step 2 — 몬스터 추가하고 데미지 계산

```c
int CalcDamage(Character attacker, Character defender);   // ← 원형 추가

int main(void)
{
    Character hero  = { "용사",   100, 100, 20, 5 };
    Character slime = { "슬라임",  30,  30,  8, 3 };      // ← 추가

    PrintStatus(hero);
    PrintStatus(slime);                                   // ← 같은 함수 재사용!

    int dmg = CalcDamage(hero, slime);                    // ← 추가
    printf("\n예상 데미지: %d\n", dmg);

    return 0;
}

int CalcDamage(Character attacker, Character defender)    // ← 추가
{
    int damage = attacker.atk - defender.def;
    if (damage < 1) damage = 1;
    return damage;
}
```

**✅ 여기까지 실행하면** — 용사와 슬라임 상태가 같은 형식으로 두 줄 출력되고, 예상 데미지 `17`이 나온다.

### Step 3 — 데미지 적용 (구조체 반환)

```c
Character ApplyDamage(Character c, int damage)     // ← 구조체를 돌려준다
{
    c.hp -= damage;
    if (c.hp < 0) c.hp = 0;
    return c;
}
```

```c
    int dmg = CalcDamage(hero, slime);
    slime = ApplyDamage(slime, dmg);               // ← 받아서 다시 넣기

    printf("\n용사의 공격!  %s에게 %d 데미지\n", slime.name, dmg);
    PrintStatus(slime);
```

**✅ 여기까지 실행하면** — 슬라임 HP가 `30` → `13`으로 실제로 줄어든 상태가 출력된다.

### Step 4 — 체력 바 함수

```c
void PrintHpBar(Character c)
{
    int ratio = c.hp * 10 / c.maxHp;      // 0~10칸

    printf("  [");
    for (int i = 0; i < 10; i++)          // 반복문은 내일 배우지만 미리 사용
        printf("%c", i < ratio ? '#' : '-');
    printf("] ");

    int percent = c.hp * 100 / c.maxHp;
    if (percent <= 0)       printf("전투불능\n");
    else if (percent <= 30) printf("위험\n");
    else if (percent <= 60) printf("주의\n");
    else                    printf("여유\n");
}
```

**✅ 여기까지 실행하면** — `[####------] 위험` 처럼 체력 바가 표시된다.

### Step 5 — 몬스터 배열과 순차 전투

```c
int main(void)
{
    Character hero = { "용사", 100, 100, 20, 5 };

    Character monsters[3] = {                       // ← 추가
        { "슬라임",  30,  30,  8,  3 },
        { "고블린",  60,  60, 15,  6 },
        { "드래곤", 200, 200, 30, 12 }
    };

    int turnCount = 0;

    printf("=====================================\n");
    printf("        영웅은 절차적\n");
    printf("=====================================\n");

    // 몬스터 0번과 전투 (반복문은 내일. 오늘은 인덱스를 직접 씀)
    printf("\n[1/3]  %s  등장!\n\n", monsters[0].name);
    PrintStatus(hero);
    PrintStatus(monsters[0]);

    // ... 전투 처리 ...

    return 0;

```

**✅ 여기까지 실행하면** — 몬스터 배열의 0번 정보가 정상 출력된다.
`monsters[1]`, `monsters[2]`로 바꾸면 다른 몬스터가 나온다.

### Step 6 — 한 턴 전투 함수로 묶기

```c
// 한 턴을 처리하고, 바뀐 몬스터 상태를 돌려준다
Character BattleTurn(Character hero, Character monster, int choice)
{
    if (choice == 1)
    {
        int dmg = CalcDamage(hero, monster);
        monster = ApplyDamage(monster, dmg);
        printf("\n%s의 공격!  %s에게 %d 데미지\n", hero.name, monster.name, dmg);
        PrintHpBar(monster);
    }
    else if (choice == 2)
    {
        printf("\n%s는 방어 태세를 취했다.\n", hero.name);
    }

    return monster;
}
```

> 여기서 한계가 드러난다. **이 함수는 용사의 HP도 깎아야 하는데, 반환값은 하나뿐이다.**
> 지금은 몬스터만 돌려주고 용사 반격은 `main`에서 따로 처리한다.
> **Day 18에서 포인터를 배우면 둘 다 한 번에 처리할 수 있다.**

**✅ 여기까지 실행하면** — 한 턴 전투가 함수 호출 한 줄로 처리된다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `error C2143: 구문 오류 ';'` | 구조체 정의 끝 **세미콜론 누락** | `};` 로 닫는다 |
| 능력치가 뒤죽박죽 | 초기화 순서가 멤버 선언 순서와 다름 | 순서를 정확히 맞춘다 |
| `c.name = "이름"` 오류 | 배열에는 `=` 대입 불가 | `strcpy_s(c.name, 20, "이름")` |
| 함수에서 바꾼 HP가 안 남음 | 구조체도 **값 복사** | `return`으로 받거나 → Day 18 |
| 이름 출력이 깨짐 | `char name[20]`에 20자 이상 넣음 | 널 문자 자리까지 고려해 크기 확보 |
| `sizeof(Character)`가 예상과 다름 | 구조체 **패딩**(정렬) | 정상. 지금은 신경 쓰지 않아도 된다 |
| `monsters[3]`에 접근하면 이상함 | 인덱스는 **0, 1, 2** | 범위 확인 (Day 11에서 자세히) |
| 반환값 하나로 둘을 못 바꿈 | C 함수는 값을 하나만 반환 | 지금은 나눠 처리. **Day 18에서 해결** |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| `struct` | 관련된 값들을 묶어 **나만의 자료형**을 만든다 |
| 멤버 접근 | `변수.멤버` — 점 연산자 |
| `typedef` | `struct` 없이 짧게 쓰기 |
| 구조체 매개변수 | 매개변수 6개 → 1개. 단, **값 복사**라 원본은 안 바뀐다 |
| 구조체 반환 | `c = Func(c);` 로 바뀐 값을 받아온다 |
| 구조체 배열 | 같은 종류를 여러 개. 추가 = 줄 하나 |
| 문자열 멤버 | `char name[20]`. `=` 대입 불가, `strcpy_s` 사용 |
