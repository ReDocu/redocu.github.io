## ② 왜 필요한가

### 어제 확인한 것 — 사전학습 모델은 우리 대상을 모릅니다

```
안전모        → COCO에 없음
택배 상자      → COCO에 없음
쓰러진 사람    → COCO에 없음 (person 으로는 잡히지만 "쓰러짐"은 모름)
번호판        → COCO에 없음
```

**모델에게 가르치려면 정답을 만들어 줘야 합니다.**
분류에서는 사진을 폴더에 나눠 넣는 것이 정답 만들기였습니다.

```
대단원 03 (분류)
  dogs/  photo1.jpg  photo2.jpg ...     ← 폴더에 넣으면 끝
  wolves/ photo3.jpg ...

대단원 05 (검출)
  photo1.jpg  →  박스를 손으로 그린다  →  photo1.txt
  photo2.jpg  →  박스를 손으로 그린다  →  photo2.txt
  ... 500번 반복
```

**한 장에 20~40초. 500장이면 3~6시간입니다.**

### ★ "라벨링이 성능의 80%"라는 말의 의미

과장이 아닙니다. 실제로 이런 일이 벌어집니다.

**사례 1 — 박스를 여유 있게 친 경우**

```
   ✓ 딱 맞게              ✗ 여유 있게
  ┌────────┐            ┌──────────────┐
  │████████│            │              │
  │████████│            │   ████████   │  ← 배경이 40%
  └────────┘            │   ████████   │
                        └──────────────┘

결과: 모델이 "사람 + 주변 배경"을 사람이라고 배움
     → 배경이 다른 곳에서 못 찾음
     → 박스가 항상 실제보다 크게 나옴
```

**사례 2 — 기준이 흔들린 경우**

```
1일차 오전: 반쯤 가려진 사람도 라벨링함
1일차 오후: 귀찮아서 안 함
2일차:     다시 함

결과: 모델에게 "같은 상황인데 어떨 땐 정답, 어떨 땐 오답"
     → 모델이 애매한 경우에 낮은 conf 를 냄
     → 그 구간에서 성능이 무너짐
```

**사례 3 — 놓친 객체(라벨 누락)**

```
사진에 사람 5명인데 4명만 라벨링

모델이 5번째 사람을 찾아냄
  → 정답에 없으므로 "오답(FP)"으로 처리됨
  → 모델은 "저건 사람이 아니다"라고 배움
  → ★ 정확히 반대로 학습됩니다
```

> ⚠️ **라벨 누락은 단순히 "덜 배우는" 것이 아닙니다.**
> **틀린 것을 배웁니다.** 이것이 검출에서 라벨 품질이 결정적인 이유입니다.

### 숫자로 보는 라벨 품질의 영향

같은 500장 데이터셋, 같은 모델, 라벨 품질만 다르게 학습한 결과입니다.

| 라벨 조건 | mAP50 | 관찰 |
|---|---|---|
| 정확한 라벨 | **0.81** | 기준 |
| 박스를 10% 여유 있게 | 0.74 | 예측 박스가 항상 커짐 |
| 10% 라벨 누락 | 0.68 | 특정 상황에서 미검출 급증 |
| 작업자 2명이 다른 기준 | 0.63 | **가장 큰 하락** |
| 위 세 가지 전부 | 0.44 | 사실상 실패 |

```
모델을 n → s 로 키워 얻는 개선     +0.04
라벨을 제대로 만들어 얻는 개선     +0.37   ★ 9배
```

> **"모델을 바꿔서 성능을 올리자"는 유혹을 먼저 이겨야 합니다.**
> [Day 150](day-150.md)에서 성능 개선 점검 순서를 배울 때, **1순위가 라벨 품질**인 이유가 이것입니다.

### ★ 박스를 치는 5원칙

이 5개를 오늘 몸에 익힙니다. **팀 전체가 같은 원칙을 써야 합니다.**

**원칙 1 — 대상에 딱 맞게 (tight box)**

```
✓ 객체의 최외곽 픽셀에 정확히 접하게
✗ 여유 공간 금지
✗ 객체 일부를 자르는 것도 금지

  머리카락 끝, 발끝, 손가락 끝까지 포함
```

**원칙 2 — 보이는 것만 (visible extent)**

```
가려진 부분은 상상해서 그리지 않습니다

  ┌──────┐          ┌──────┐
  │  👤  │          │  👤  │
  │ ████ │  차에 가림 │ ████ │  ← 여기까지만
  └──────┘          └──────┘
  │ ░░░░ │          (아래는 안 그림)
  └──────┘
  ✗ 추정해서 그림    ✓ 보이는 것만
```

> **★ 이 원칙은 팀마다 다르게 정할 수 있습니다.**
> "가려진 부분까지 추정(amodal)"을 쓰는 데이터셋도 있습니다.
> **중요한 것은 하나를 정하고 끝까지 지키는 것입니다.** ([Day 142](day-142.md)에서 팀 기준 확정)

**원칙 3 — 잘린 객체도 라벨링 (truncation)**

```
화면 밖으로 나간 객체

  ┌─────────────┐
 ██│             │      ← 왼쪽 절반이 화면 밖
 ██│             │
  └─────────────┘

  ✓ 화면 안에 보이는 부분만 박스로 감싼다
  ✓ 이미지 경계에 딱 붙인다 (x1 = 0)
  ✗ 화면 밖까지 좌표를 늘리지 않는다 (음수 금지)
```

**원칙 4 — 최소 크기 기준을 정한다**

```
너무 작은 객체는 라벨링하지 않습니다

  기준 예시:  가로 또는 세로가 이미지의 1% 미만이면 제외
             (640px 이미지 → 6px 미만)

  또는 절대값:  10 × 10 픽셀 미만 제외
```

**왜 제외하는가**

```
① 사람도 그게 뭔지 확신할 수 없음  → 라벨이 부정확
② 모델이 학습하기 매우 어려움      → 노이즈가 됨
③ 실무에서도 그 크기는 쓸모없음    → 얼굴 인식 불가 등
```

**원칙 5 — 애매하면 표시해 두고 넘어간다**

```
판단이 안 서는 사진에서 5분씩 고민하지 마세요

  ① 일단 자기 판단으로 라벨링
  ② 파일명을 메모장에 적어 둠      ← ★
  ③ 100장 끝나고 팀 토론으로 기준 확정
  ④ 표시해 둔 것만 다시 수정
```

> **혼자 오래 고민하면 그날의 컨디션에 따라 기준이 흔들립니다.**
> **모아서 한 번에 결정하는 것이 일관성을 지키는 유일한 방법입니다.**

def extract_frames(video, out_dir, every_n=15, limit=None, prefix="frm"):
    """영상에서 N프레임마다 1장씩 추출"""
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    cap = cv2.VideoCapture(str(video))
    if not cap.isOpened():
        raise RuntimeError(f"열 수 없음: {video}")

    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    fps = cap.get(cv2.CAP_PROP_FPS) or 30
    saved, idx = 0, 0
    while True:
        ok, frame = cap.read()
        if not ok:
            break
        if idx % every_n == 0:
            cv2.imwrite(str(out_dir / f"{prefix}_{saved:04d}.jpg"), frame)
            saved += 1
            if limit and saved >= limit:
                break
        idx += 1
    cap.release()
    return {"원본 프레임": total, "FPS": round(fps, 1),
            "추출 간격": f"{every_n}프레임 ({every_n/fps:.1f}초)",
            "저장": saved}

def make_contact_sheet(image_dir, label_dir, out_path,

    """라벨을 그린 축소 이미지를 격자로 붙여 한 장으로 — ★ 빠른 검수용"""

### Step 6. 교차 검수 — 두 사람이 같은 사진을 라벨링

**오늘의 하이라이트입니다.** 각자 라벨링한 것을 겹쳐 봅니다.

```python
from pathlib import Path

import cv2
import numpy as np

import bbox_utils as B

ROOT = Path("C:/vision/day138")


def iou(box_a, box_b):
    """VOC 좌표 두 개의 IoU — Day 148에서 정식으로 다룹니다"""
    ax1, ay1, ax2, ay2 = box_a
    bx1, by1, bx2, by2 = box_b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw, ih = max(0, ix2 - ix1), max(0, iy2 - iy1)
    inter = iw * ih
    area_a = max(0, ax2 - ax1) * max(0, ay2 - ay1)
    area_b = max(0, bx2 - bx1) * max(0, by2 - by1)
    union = area_a + area_b - inter
    return inter / union if union > 0 else 0.0


def load_voc(txt, w, h):
    if not Path(txt).exists():
        return []
    out = []
    for line in Path(txt).read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        parts = line.split()
        out.append(B.yolo_to_voc(tuple(float(v) for v in parts[1:5]), w, h))
    return out


def compare_labelers(image_dir, dir_a, dir_b, out_dir, thr=0.5):
    """두 작업자의 라벨을 비교하고 시각화"""
    image_dir, out_dir = Path(image_dir), Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    rows = []

    for p in sorted(image_dir.glob("*.jpg")):
        img = cv2.imread(str(p))
        if img is None:
            continue
        h, w = img.shape[:2]
        A = load_voc(Path(dir_a) / (p.stem + ".txt"), w, h)
        Bx = load_voc(Path(dir_b) / (p.stem + ".txt"), w, h)

        used, matched, ious = set(), 0, []
        for a in A:
            best, best_j = 0, -1
            for j, b in enumerate(Bx):
                if j in used:
                    continue
                v = iou(a, b)
                if v > best:
                    best, best_j = v, j
            if best >= thr:
                used.add(best_j)
                matched += 1
                ious.append(best)

        rows.append({
            "file": p.stem, "A": len(A), "B": len(Bx), "일치": matched,
            "A만": len(A) - matched, "B만": len(Bx) - matched,
            "평균IoU": round(float(np.mean(ious)), 3) if ious else 0.0,
        })

        for box in A:
            x1, y1, x2, y2 = B.to_int(box)
            cv2.rectangle(img, (x1, y1), (x2, y2), (60, 220, 60), 2)      # A: 초록
        for box in Bx:
            x1, y1, x2, y2 = B.to_int(box)
            cv2.rectangle(img, (x1, y1), (x2, y2), (60, 120, 255), 2)     # B: 주황
        cv2.putText(img, "A(green) vs B(orange)", (10, 26),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 0, 0), 3, cv2.LINE_AA)
        cv2.putText(img, "A(green) vs B(orange)", (10, 26),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (255, 255, 255), 1, cv2.LINE_AA)
        cv2.imwrite(str(out_dir / p.name), img)

    return rows

### Step 7. 라벨 파일 무결성 검사

```python
from pathlib import Path

import cv2

ROOT = Path("C:/vision/day138")


def audit_labels(image_dir, label_dir, class_file):
    image_dir, label_dir = Path(image_dir), Path(label_dir)
    classes = Path(class_file).read_text(encoding="utf-8").split()
    problems = []

    imgs = {p.stem: p for p in image_dir.glob("*.jpg")}
    lbls = {p.stem: p for p in label_dir.glob("*.txt") if p.stem != "classes"}

    for stem in sorted(set(imgs) - set(lbls)):
        problems.append((stem, "INFO", "라벨 파일 없음 (배경 이미지면 정상)"))
    for stem in sorted(set(lbls) - set(imgs)):
        problems.append((stem, "ERROR", "이미지 없는 라벨 (고아 파일)"))

    for stem, txt in sorted(lbls.items()):
        if stem not in imgs:
            continue
        for ln, line in enumerate(txt.read_text(encoding="utf-8").splitlines(), 1):
            s = line.strip()
            if not s:
                continue
            parts = s.split()
            if len(parts) != 5:
                problems.append((stem, "ERROR", f"{ln}행: 값 {len(parts)}개 (5개여야 함)"))
                continue
            try:
                cid = int(parts[0])
                vals = [float(v) for v in parts[1:]]
            except ValueError:
                problems.append((stem, "ERROR", f"{ln}행: 숫자로 변환 불가"))
                continue
            if not 0 <= cid < len(classes):
                problems.append((stem, "ERROR", f"{ln}행: 클래스 id {cid} 범위 밖"))
            if not all(0 <= v <= 1 for v in vals):
                problems.append((stem, "ERROR", f"{ln}행: 0~1 범위 밖 {vals}"))
            cx, cy, bw, bh = vals
            if bw <= 0 or bh <= 0:
                problems.append((stem, "ERROR", f"{ln}행: 크기 0 이하"))
            elif bw < 0.01 or bh < 0.01:
                problems.append((stem, "WARN", f"{ln}행: 아주 작은 박스 {bw:.4f}×{bh:.4f}"))
            if cx - bw / 2 < -1e-6 or cx + bw / 2 > 1 + 1e-6 \
               or cy - bh / 2 < -1e-6 or cy + bh / 2 > 1 + 1e-6:
                problems.append((stem, "WARN", f"{ln}행: 박스가 이미지 경계를 벗어남"))

    return problems


problems = audit_labels(ROOT / "images", ROOT / "labels", ROOT / "classes.txt")

print("=" * 88)
print("라벨 무결성 검사")
print("=" * 88)
levels = {"ERROR": 0, "WARN": 0, "INFO": 0}
for _, lv, _ in problems:
    levels[lv] += 1
print(f"  ERROR {levels['ERROR']}건   WARN {levels['WARN']}건   INFO {levels['INFO']}건")
print("-" * 88)
for stem, lv, msg in problems[:20]:
    mark = {"ERROR": "✗", "WARN": "⚠", "INFO": "·"}[lv]
    print(f"  {mark} [{lv:<5}] {stem:<20}{msg}")
if len(problems) > 20:
    print(f"  ... 외 {len(problems)-20}건")
print("-" * 88)
print("  " + ("✓ 학습에 쓸 수 있습니다" if levels["ERROR"] == 0
              else "★ ERROR 를 먼저 해결하세요"))

### ② 클래스별 적용 가능성

| bicycle / motorcycle | 있음 · 혼동 있음 | △ 클래스 오지정 주의 |

### ③ 절차 설계

```
[0단계] 적용 여부 판단 — 표본 30장으로 측정
  · 사전학습 모델로 30장 자동 라벨
  · 사람이 처음부터 라벨링한 것과 비교 (Step 6의 compare_labelers)
  · 일치율 90% 이상 · IoU 0.85 이상  →  진행
  · 미달  →  수동으로 결정

[1단계] 보수적 임계값으로 생성
  · conf = 0.5 (기본 0.25보다 높게)
  · 이유: 애매한 것은 아예 안 붙이는 게 낫다
  ·      없는 박스는 사람이 추가하지만, 있는 박스는 잘 안 지운다

[2단계] ★ conf 를 파일에 함께 기록 (검수용)
  · 별도 CSV 에 파일명 · conf 목록 저장
  · conf 0.5~0.7 인 것을 우선 검수 대상으로 표시

[3단계] 사람 검수 — ★ 순서를 바꿔서
  · 자동 라벨을 그대로 보지 말고,
  · ★ 먼저 원본 이미지만 보고 "몇 명인가"를 세고
  · 그다음 자동 라벨을 열어 개수를 대조
  → 확증 편향 방지

[4단계] ★ 모델이 약한 구간은 전량 수동
  · 야간 · 저조도 사진
  · 작은 객체가 많은 사진
  · 가림이 심한 사진
  → 이 사진들은 자동 라벨을 아예 지우고 처음부터

[5단계] 검증
  · 자동 구간 / 수동 구간을 나눠 통계 비교

     · 10장마다 검수 시트를 뽑아 확인

2. 짝과 같은 이미지 20장을 각자 라벨링하고 교차 검수합니다
     · 일치율과 평균 IoU 측정
     · 불일치 전건을 열어 보고 원인 분류

3. 판단 기준 4가지를 합의해 문서로 남깁니다
     · 각 기준마다 ★ 예시 이미지 2장 (포함 1 / 제외 1)

4. 무결성 검사를 통과시킵니다 (ERROR 0건)
```

**제출물**

- [ ] `labels/` 폴더 (`.txt` 100개 이하 + `classes.txt`)
- [ ] 검수 시트 이미지 5장 이상
- [ ] 교차 검수 결과표 + 불일치 원인 분류
- [ ] ★ **기준 합의 메모** (예시 이미지 포함)
- [ ] 속도 기록 (처음 10장 / 마지막 10장)
- [ ] 무결성 검사 실행 결과 (ERROR 0)

**체크리스트**

- [ ] 저장 포맷이 **YOLO** 로 되어 있다
- [ ] Save Dir 이 `labels/` 로 분리되어 있다
- [ ] Auto Save mode 를 켰다
- [ ] `W` `D` `A` 를 보지 않고 누를 수 있다
- [ ] 작은 객체는 **확대해서** 작업했다
- [ ] 박스가 대상에 **딱 맞다** (여유 없음)
- [ ] 잘린 객체를 **보이는 부분만** 쳤다
- [ ] 애매한 사례를 **메모해 두고** 나중에 토론했다
- [ ] 10장마다 **검수 시트**로 확인했다
- [ ] 짝과 **교차 검수**를 했다
- [ ] 불일치 원인을 **기준으로 환원**해 합의했다
- [ ] 마지막 10장이 **20초/장 이내**다
- [ ] 작업 경로에 한글·공백이 없다
