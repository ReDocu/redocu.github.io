```
   ★ 알파까지의 상태

   → 하지만 층 6개, 적 3종 "회색 캡슐"

## 3. 개념

### 3-1. 콘텐츠와 기능의 구분

**왜 필요한가** — Feature Freeze 아래에서 무엇이 허용되는지.

| | 콘텐츠 (허용) | 기능 (금지) |
|---|---|---|
| 예 | 층 2개 추가 | 새 층 유형 |
| 예 | 적 종류 추가 (기존 AI) | 새 AI 패턴 |
| 예 | 무기 추가 (기존 타입) | 새 무기 타입 |
| 작업 | 데이터 + 애셋 | 코드 |
| 리스크 | 낮음 | 높음 |

```
   ★ 판단 기준

   "코드를 고쳐야 하나?"
   → 고쳐야 하면 기능. 금지
   → 데이터만이면 콘텐츠. 허용
```

```
   ⚠️ 회색 지대

   "새 적을 추가하는데 그 적은 원거리 공격을 한다"
   → 원거리 AI가 없으면 기능
   → 있으면 콘텐츠
```

```
   ★ 예외

   Day 110에 W23으로 이관한 항목
   (회피 무적 이펙트 등)
   → 연출이므로 허용
```

### 3-2. 데이터 추가 검증

   ② 데이터베이스 수집

```

### 3-3. 분량 계산

**왜 필요한가** — 목표치를 정한다.

```
   ★ 플레이 시간 = 층 수 × 층당 시간
```

| 요소 | 값 |
|---|---|
| 층당 적 수 | 3~7 |
| 적 1마리 처치 | 3~5초 |
| 층당 전투 | 15~30초 |
| 층 전환 + 무기 선택 | 10초 |
| **층당 합계** | **25~40초** |
| 층 8개 | **3:20 ~ 5:20** |
| 보스 | +1:30 |
| **총계** | **5~7분** |

```
   ★ 목표별 층 수

   3분:   5층
   5분:   8층  ★
   10분:  15층
```

```
   ⚠️ 층을 늘리는 것만으로는 지루하다

   ① 적 구성 변화
   ② 난이도 곡선
   ③ 무기 선택의 다양성
   → 이 셋이 반복을 견디게 한다
```
