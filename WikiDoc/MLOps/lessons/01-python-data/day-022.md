## ③ 개념 설명

### Series — 이름표가 붙은 1차원 배열

```python
import pandas as pd

s = pd.Series([31, 45, 28], index=["중구", "종로", "용산"], name="pm10")
```

```
중구    31
종로    45
용산    28
Name: pm10, dtype: int64
```

| 구성 | 뜻 |
|---|---|
| **values** | 실제 값 (NumPy 배열) |
| **index** | 각 값의 이름표 |
| **name** | Series 자체의 이름 (DataFrame의 컬럼명이 됨) |
| **dtype** | 자료형 |

**NumPy 배열 + 인덱스 = Series** 라고 생각하면 됩니다.

### DataFrame — 2차원 표

```python
df = pd.DataFrame({
    "station": ["중구", "종로", "용산"],
    "pm10": [31, 45, 28],
    "pm25": [18, 22, 15],
})
```

```
  station  pm10  pm25
0      중구    31    18
1      종로    45    22
2      용산    28    15
```

```
        컬럼(columns) →
인덱스   station  pm10  pm25
(index) ┌─────────────────────┐
   0    │  중구     31    18  │
   1    │  종로     45    22  │  ← 각 열이 Series
   2    │  용산     28    15  │
        └─────────────────────┘
```

**DataFrame = 인덱스를 공유하는 Series들의 모음**입니다.

### 만드는 방법

```python
# 1) 딕셔너리 (컬럼 단위)  ← 가장 흔함
pd.DataFrame({"a": [1, 2], "b": [3, 4]})

# 2) 리스트 안의 딕셔너리 (행 단위)  ← 수집 결과
pd.DataFrame([{"a": 1, "b": 3}, {"a": 2, "b": 4}])

# 3) 2차원 리스트 + 컬럼명
pd.DataFrame([[1, 3], [2, 4]], columns=["a", "b"])

# 4) NumPy 배열
pd.DataFrame(arr, columns=["a", "b"])
```

**2번이 [Day 020](day-020.md)의 수집 결과를 바로 넣는 방법입니다.**

### 읽기·쓰기

```python
# CSV
df = pd.read_csv("data.csv", encoding="utf-8")
df.to_csv("out.csv", index=False, encoding="utf-8-sig")

# JSON
df = pd.read_json("data.json")
df.to_json("out.json", orient="records", force_ascii=False, indent=2)

# Excel (openpyxl 필요)
df = pd.read_excel("data.xlsx", sheet_name="Sheet1")

# Parquet (Day 027)
df = pd.read_parquet("data.parquet")
```

**`read_csv` 의 중요 옵션**

| 옵션 | 뜻 |
|---|---|
| `encoding="utf-8"` | 인코딩 (한국 공공 CSV는 `cp949` 인 경우도) |
| `dtype={"code": str}` | 타입 지정 — **`00123` 이 `123` 되는 것 방지** |
| `parse_dates=["date"]` | 날짜 컬럼 파싱 |
| `na_values=["-", "N/A"]` | 결측으로 취급할 값 |
| `usecols=["a", "b"]` | 필요한 컬럼만 (메모리 절약) |
| `nrows=1000` | 앞 N행만 (탐색용) |
| `thousands=","` | `1,234` 를 숫자로 |
| `index_col=0` | 첫 컬럼을 인덱스로 |

> **`to_csv(index=False)` 를 꼭 넣으세요.** 안 넣으면 `0,1,2...` 컬럼이 하나 더 생깁니다.
> **Excel에서 열 거면 `encoding="utf-8-sig"`** 를 쓰세요. BOM이 없으면 한글이 깨집니다.

### loc vs iloc

| | `loc` | `iloc` |
|---|---|---|
| 기준 | **이름(라벨)** | **위치(정수)** |
| 슬라이싱 끝 | **포함** | 미포함 |
| 예 | `df.loc[0, "pm10"]` | `df.iloc[0, 1]` |

```python
df.loc[0]                       # 인덱스가 0인 행
df.loc[0:2]                     # 0,1,2 — 끝 포함!
df.loc[:, "pm10"]               # 모든 행, pm10 열
df.loc[0:2, ["station", "pm10"]]
df.loc[df["pm10"] > 40, "station"]     # 조건 + 컬럼  ⭐

df.iloc[0]                      # 첫 번째 행
df.iloc[0:2]                    # 0,1 — 끝 미포함
df.iloc[:, 1]                   # 두 번째 열
df.iloc[-1]                     # 마지막 행
df.iloc[[0, 2], [1, 2]]
```

**`loc` 의 슬라이싱이 끝을 포함하는 것**이 파이썬 관례와 달라 헷갈립니다.
`loc` 은 "이름으로 찾는 것"이라 "A부터 B까지"가 자연스럽기 때문입니다.

### 조건 필터

```python
df[df["pm10"] > 40]                            # 기본
df[(df["pm10"] > 40) & (df["pm25"] < 30)]      # & | ~ + 괄호
df[df["station"].isin(["중구", "종로"])]         # 목록에 포함
df[df["pm10"].between(20, 50)]                 # 범위 (양끝 포함)
df[df["station"].str.contains("구")]            # 문자열 포함
df[df["pm10"].isna()]                          # 결측인 행
df[df["pm10"].notna()]                         # 결측이 아닌 행
```

**NumPy와 같습니다.** `and`/`or` 대신 `&`/`|`, 괄호 필수 ([Day 021](day-021.md)).

**`query()` 로 더 읽기 좋게 쓸 수도 있습니다.**

```python
df.query("pm10 > 40 and pm25 < 30")
df.query("station in ['중구', '종로']")
threshold = 40
df.query("pm10 > @threshold")          # @ 로 파이썬 변수 참조
```

### 새 컬럼 만들기

```python
df["total"] = df["pm10"] + df["pm25"]              # 벡터 연산
df["grade"] = np.where(df["pm10"] > 80, "나쁨", "좋음")
df["ratio"] = df["pm25"] / df["pm10"]

# assign — 원본을 안 바꾸고 새 DataFrame
df2 = df.assign(total=df["pm10"] + df["pm25"])

# 여러 조건
conditions = [df["pm10"] > 150, df["pm10"] > 80, df["pm10"] > 30]
choices = ["매우나쁨", "나쁨", "보통"]
df["grade"] = np.select(conditions, choices, default="좋음")
```

> **`for` 문으로 행마다 계산하지 마세요.** 100배 느립니다.
> 컬럼 단위 벡터 연산이 Pandas의 핵심입니다.

### 정렬

```python
df.sort_values("pm10")                              # 오름차순
df.sort_values("pm10", ascending=False)             # 내림차순
df.sort_values(["station", "pm10"])                 # 여러 기준
df.sort_index()                                     # 인덱스 기준
df.nlargest(5, "pm10")                              # 상위 5개  ⭐
df.nsmallest(5, "pm10")
```

**`nlargest` 는 `sort_values().head()` 보다 빠릅니다.** 전체를 정렬하지 않기 때문입니다.

### 인덱스 다루기

```python
df.set_index("station")            # 컬럼을 인덱스로
df.reset_index()                   # 인덱스를 컬럼으로 되돌림
df.reset_index(drop=True)          # 기존 인덱스를 버림  ⭐
```

> **필터링 후에는 `reset_index(drop=True)`** 를 하세요.
> 안 하면 인덱스가 `0, 3, 7, 12...` 처럼 띄엄띄엄 남아 나중에 혼란스럽습니다.

### Step 2. 실습 데이터 만들기

`make_data.py` 를 만듭니다. **일부러 지저분한 데이터를 만듭니다.**

```python
"""실습용 데이터 생성 — 실제 공공데이터처럼 지저분하게."""

from pathlib import Path

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
OUT = Path("data")
OUT.mkdir(exist_ok=True)

STATIONS = ["중구", "종로구", "용산구", "성동구", "광진구", "동대문구", "중랑구",
            "성북구", "강북구", "도봉구", "노원구", "은평구", "서대문구", "마포구",
            "양천구", "강서구", "구로구", "금천구", "영등포구", "동작구",
            "관악구", "서초구", "강남구", "송파구", "강동구"]

DATES = pd.date_range("2026-08-01", "2026-08-12", freq="D")

rows = []
for date in DATES:
    for station in STATIONS:
        base = rng.integers(15, 70)
        rows.append({
            "측정일시": date.strftime("%Y-%m-%d"),
            "측정소명": station,
            "미세먼지": base,
            "초미세먼지": int(base * rng.uniform(0.4, 0.7)),
            "오존": round(rng.uniform(0.01, 0.09), 3),
            "통합지수": int(base * rng.uniform(1.2, 1.8)),
        })

df = pd.DataFrame(rows)

# --- 일부러 문제를 심습니다 ---

# 1) 결측 (5%) — '-' 로 표시
idx = rng.choice(len(df), size=int(len(df) * 0.05), replace=False)
df.loc[idx, "미세먼지"] = "-"

idx2 = rng.choice(len(df), size=int(len(df) * 0.03), replace=False)
df.loc[idx2, "초미세먼지"] = ""

# 2) 이상치 (측정 장비 오류)
idx3 = rng.choice(len(df), size=8, replace=False)
df.loc[idx3, "미세먼지"] = rng.integers(800, 1200, size=8)

# 3) 중복 행
df = pd.concat([df, df.sample(12, random_state=1)], ignore_index=True)

# 4) 측정소명에 공백
idx4 = rng.choice(len(df), size=20, replace=False)
df.loc[idx4, "측정소명"] = " " + df.loc[idx4, "측정소명"] + " "

# 5) 천 단위 쉼표가 든 컬럼 추가
df["누적측정건수"] = [f"{n:,}" for n in rng.integers(1000, 99999, len(df))]

df = df.sample(frac=1, random_state=7).reset_index(drop=True)   # 섞기

path = OUT / "air_quality_raw.csv"
df.to_csv(path, index=False, encoding="utf-8-sig")

print(f"생성 완료: {path}")
print(f"  {len(df):,}행 × {len(df.columns)}열")
print(f"  크기: {path.stat().st_size:,} bytes")
print(f"\n앞 5행:")
print(df.head())
```

```python
import pandas as pd
```

```python
df = pd.read_csv(
```

```python
print("     → Day 027 에서 Parquet 을 배웁니다 (타입 보존 + 압축)")

print("\n--- 조건에 맞는 것만 저장 ---")
bad_days = df[df["미세먼지"] > 80]
bad_path2 = OUT / "air_bad_days.csv"
bad_days.to_csv(bad_path2, index=False, encoding="utf-8-sig")
print(f"  {bad_path2} — {len(bad_days)}건")

print("\n--- 컬럼 순서·이름 정리 후 저장 ---")
report = (df
          .loc[df["미세먼지"].notna(), ["측정일시", "측정소명", "미세먼지", "초미세먼지"]]
          .rename(columns={"측정일시": "date", "측정소명": "station",
                           "미세먼지": "pm10", "초미세먼지": "pm25"})
          .sort_values(["date", "station"])
          .reset_index(drop=True))
report_path = OUT / "air_report.csv"
report.to_csv(report_path, index=False, encoding="utf-8-sig")
print(f"  {report_path}")
print(report.head())
```

**1.** `df["pm10"]` 과 `df[["pm10"]]` 의 차이는 무엇이고, 각각 언제 쓰나요?

<details>
<summary>답 보기</summary>

| | `df["pm10"]` | `df[["pm10"]]` |
|---|---|---|
| 타입 | **Series** (1차원) | **DataFrame** (2차원) |
| shape | `(300,)` | `(300, 1)` |
| 출력 | 값들이 세로로 | 표 형태 |

```python
df["pm10"]
# 0    31.0
# 1    45.0
# Name: pm10, dtype: float64

df[["pm10"]]
#    pm10
# 0  31.0
# 1  45.0
```

**언제 Series를 쓰나**

```python
df["pm10"].mean()                    # 집계
df["pm10"] > 50                      # 조건 마스크
df["total"] = df["pm10"] + df["pm25"]   # 새 컬럼 만들기
df["pm10"].value_counts()
```

**대부분의 계산은 Series로 합니다.**

**언제 DataFrame이 필요한가**

```python
# 1) 여러 컬럼 선택 — 자연스럽게 대괄호 두 겹
df[["station", "pm10", "pm25"]]

# 2) 표 형태를 유지해야 할 때
df[["pm10"]].to_csv("out.csv")       # 컬럼명이 헤더로 저장됨

# 3) sklearn — X 는 반드시 2차원 (W11)
X = df[["pm10"]]                     # (300, 1)  ✅
X = df["pm10"]                       # (300,)    ❌ 에러
```

**3번이 실무에서 가장 자주 걸립니다.**

```

Reshape your data either using array.reshape(-1, 1) ...
```

특성이 하나뿐인 모델을 만들 때 `df["pm10"]` 을 넘기면 이 에러가 납니다.

| 목적 | 코드 |
|---|---|
| 특성 (X) | `df[["a", "b"]]` — **항상 대괄호 두 겹** |
| 정답 (y) | `df["target"]` — 1차원 |

[Day 021](day-021.md)의 `reshape(-1, 1)` 과 같은 이야기입니다.
NumPy의 `(3,)` vs `(3,1)` 이 Pandas에서는 Series vs DataFrame으로 나타납니다.

**2.** 아래 코드는 `SettingWithCopyWarning` 을 냅니다. 왜 위험하고 어떻게 고쳐야 하나요?

```python
high = df[df["pm10"] > 100]
high["grade"] = "매우나쁨"
```

<details>
<summary>답 보기</summary>

**문제: 값이 원본에 반영될지 안 될지 예측할 수 없습니다.**

`df[조건]` 은 상황에 따라 **뷰일 수도 복사일 수도** 있습니다.
Pandas 내부 구현(메모리 배치·dtype)에 따라 달라지며, 버전이 바뀌면 또 달라집니다.

| 만약 뷰라면 | 만약 복사라면 |
|---|---|
| `df` 원본도 바뀜 | `df` 는 그대로, `high` 만 바뀜 |

**의도가 어느 쪽이든 코드가 그것을 표현하지 못합니다.**
그래서 Pandas가 경고를 냅니다.

```
SettingWithCopyWarning:
A value is trying to be set on a copy of a slice from a DataFrame.
Try using .loc[row_indexer, col_indexer] = value instead
```

**실제로 벌어지는 사고**

```python
train = df[df["date"] < "2026-08-10"]
train["pm10"] = train["pm10"].fillna(0)      # 경고

# 나중에
print(df["pm10"].isna().sum())      # 15? 0? — 알 수 없음
```

전처리 결과가 원본에 반영됐는지 아닌지 몰라서
**같은 코드를 두 번 실행하면 결과가 달라지는** 상황이 생깁니다.
재현성이 깨집니다.

**해결 1 — 원본을 바꾸려면 `.loc` 으로 한 번에**

```python
df.loc[df["pm10"] > 100, "grade"] = "매우나쁨"
```

**한 번의 인덱싱**으로 행과 열을 동시에 지정하므로 모호함이 없습니다.

**해결 2 — 사본을 쓰려면 명시적으로**

```python
high = df[df["pm10"] > 100].copy()
high["grade"] = "매우나쁨"
```

`.copy()` 를 쓰면 **"원본과 무관한 새 데이터"** 라는 의도가 코드에 드러납니다.

**판단 기준**

| 목적 | 방법 |
|---|---|
| 원본의 일부를 수정 | `df.loc[조건, "컬럼"] = 값` |
| 별도로 분석할 부분집합 | `subset = df[조건].copy()` |
| 새 DataFrame을 만들며 컬럼 추가 | `df.assign(새컬럼=...)` |

**같은 원리가 NumPy에도 있습니다** ([Day 021](day-021.md)).
슬라이싱이 뷰인지 복사인지 헷갈리는 문제와 뿌리가 같습니다.

Pandas 3.0에서는 Copy-on-Write가 기본이 되어 **항상 복사처럼 동작**하게 바뀝니다.
그래도 `.loc` 을 쓰는 습관은 유지하세요. 의도가 명확해집니다.
</details>

**3.** 공공데이터 CSV를 읽었더니 `df.info()` 에서 숫자여야 할 컬럼이 `object` 로 나옵니다. 원인을 어떻게 찾고 해결하나요?

<details>
<summary>답 보기</summary>

**원인 찾기 — 숫자로 변환되지 않는 값을 직접 봅니다.**

```python
# 1) 변환을 시도해 실패하는 것만 골라내기
converted = pd.to_numeric(df["미세먼지"], errors="coerce")
bad = df.loc[converted.isna() & df["미세먼지"].notna(), "미세먼지"]

print(f"변환 실패 {len(bad)}건")
print(bad.value_counts().head(20))
```

```
변환 실패 24건
-        15
         6
N/A       2
측정중단     1
Name: 미세먼지, dtype: int64
```

**범인이 바로 드러납니다.**

**흔한 원인 목록**

| 값 | 의미 | 처리 |
|---|---|---|
| `-`, `–`, `—` | 결측 표시 | `na_values` |
| `""`, `" "` | 빈 값 | `na_values` |
| `N/A`, `없음`, `미측정` | 결측 | `na_values` |
| `1,234` | 천 단위 쉼표 | `thousands=","` |
| `12.5%` | 백분율 | 직접 제거 후 변환 |
| `1,234원` | 단위 포함 | `.str.replace()` |
| `1.2E+05` | 지수 표기 | 대개 자동 인식 |

**해결 1 — 읽을 때 옵션으로 (권장)**

```python
df = pd.read_csv(
    path,
    encoding="utf-8-sig",
    na_values=["-", "", " ", "N/A", "없음", "측정중단"],
    thousands=",",
)
```

**가장 깔끔합니다.** 정제 코드를 따로 쓸 필요가 없습니다.

**해결 2 — 이미 읽었다면 변환**

```python
df["미세먼지"] = pd.to_numeric(df["미세먼지"], errors="coerce")
```

`errors="coerce"` 는 **변환 실패를 `NaN` 으로** 만듭니다.
`errors="raise"`(기본)는 예외를 던지고, `errors="ignore"` 는 원본을 그대로 둡니다.

**해결 3 — 복잡한 형태는 문자열 처리 후 변환**

```python
df["금액"] = (df["금액"]
              .str.replace(",", "", regex=False)
              .str.replace("원", "", regex=False)
              .str.strip()
              .pipe(pd.to_numeric, errors="coerce"))
```

**변환 후 반드시 검증하세요**

```python
before = df["미세먼지"].notna().sum()
df["미세먼지"] = pd.to_numeric(df["미세먼지"], errors="coerce")
after = df["미세먼지"].notna().sum()

print(f"변환으로 결측이 된 값: {before - after}건")
if (before - after) / before > 0.1:
    raise ValueError("10% 이상이 변환에 실패했습니다. 원인을 확인하세요.")
```

**`errors="coerce"` 는 조용히 데이터를 버립니다.**
얼마나 버렸는지 반드시 확인해야 합니다.
W09 [Day 044](../02-sql-pipeline/day-044.md)의 데이터 품질 검증이 이 작업을 자동화합니다.

**왜 이게 중요한가**

`object` 타입이면 이후 모든 것이 안 됩니다.
- 집계 불가 (`mean()` 에서 `TypeError`)
- 비교 불가 (`> 50` 이 사전 순 비교가 됨)
- 메모리 낭비 (문자열은 숫자보다 4~8배)
- sklearn에 넣을 수 없음

**받은 데이터의 `df.info()` 를 가장 먼저 보는 이유**입니다.
</details>

## 오늘의 정리

| 항목 | 문법 |
|---|---|
| 구조 | Series(1차원) · DataFrame(2차원) · 인덱스 + 컬럼 + 값 |
| 만들기 | `pd.DataFrame({컬럼: 리스트})` · `pd.DataFrame([{행}, {행}])` |
| 읽기 | `read_csv(encoding=, na_values=, thousands=, parse_dates=, dtype=, usecols=)` |
| 쓰기 | `to_csv(path, index=False, encoding="utf-8-sig")` |
| 탐색 | **`df.info()`** ⭐ · `head()` · `describe()` · `sample()` |
| 컬럼 | `df["a"]` Series · `df[["a","b"]]` DataFrame |
| 위치 | `loc` 이름(끝 포함) · `iloc` 위치(끝 미포함) |
| 필터 | `df[(조건1) & (조건2)]` · `isin` · `between` · `str.contains` · `query` |
| 새 컬럼 | `df["c"] = df["a"] + df["b"]` · `np.where` · `np.select` |
| 정렬 | `sort_values()` · **`nlargest(5, "col")`** |
| 인덱스 | 필터 후 `reset_index(drop=True)` |
| 집계 | `value_counts()` · `unique()` · `nunique()` · `isna().sum()` |
| **금기** | `and`/`or` · 행 반복문 · `df.컬럼` · `index=False` 누락 |
| 경고 | `SettingWithCopyWarning` → `.loc` 또는 `.copy()` |
