## ③ 개념 설명

### 이미지 = 숫자 배열

**흑백 이미지** — 2차원

```
(높이, 너비)

[[  0,  50, 100],
 [150, 200, 255],
 [ 30,  80, 120]]

0 = 검정, 255 = 흰색
```

**컬러 이미지** — 3차원

```
(높이, 너비, 3)

각 픽셀이 [R, G, B] 세 값을 가짐

[[[255,   0,   0], [  0, 255,   0]],     ← 빨강, 초록
 [[  0,   0, 255], [255, 255, 255]]]     ← 파랑, 흰색
```

| shape | 뜻 | 예 |
|---|---|---|
| `(480, 640)` | 흑백 480×640 | 그레이스케일 사진 |
| `(480, 640, 3)` | 컬러 480×640 | 일반 사진 (RGB) |
| `(480, 640, 4)` | 투명도 포함 | PNG (RGBA) |
| `(100, 224, 224, 3)` | **이미지 100장** | 학습 배치 |

> **주의 — `(높이, 너비)` 순서입니다.** 우리는 "가로×세로"로 말하지만 배열은 반대입니다.
> 1920×1080 사진의 shape 은 `(1080, 1920, 3)` 입니다.

### dtype 은 uint8

```python
img.dtype        # uint8 — 0~255 정수
```

**`uint8` 의 함정 세 가지**

```python
img = np.array([200, 250], dtype=np.uint8)

img + 100        # [ 44  94]   ← 255를 넘어 순환!
img - 250        # [206   0]   ← 0 아래로 내려가 순환
img * 2          # [144 244]   ← 넘침
```

**해결 — 계산 전에 `float` 로 바꾸고, 끝나면 `clip` 후 되돌립니다.**

```python
result = np.clip(img.astype(np.int16) + 100, 0, 255).astype(np.uint8)
# [255 255]
```

| 상황 | 처리 |
|---|---|
| 밝기 조절 | `int16`/`float` 로 변환 → 계산 → `clip(0,255)` → `uint8` |
| 정규화 | `float32` 로 변환 후 `/255.0` |
| 저장·표시 | 반드시 `uint8` 로 되돌림 |

### 흑백 변환

**방법 ① 단순 평균**

```python
gray = img.mean(axis=2)                  # (H, W, 3) → (H, W)
```

**방법 ② 가중 평균 (사람 눈에 자연스러움)**

```python
gray = img[:,:,0] * 0.299 + img[:,:,1] * 0.587 + img[:,:,2] * 0.114
```

또는 행렬 곱으로:

```python
weights = np.array([0.299, 0.587, 0.114])
gray = img @ weights                      # (H,W,3) @ (3,) → (H,W)
```

> **왜 초록에 가중치가 큰가** — 사람 눈은 초록에 가장 민감합니다.
> 단순 평균으로 하면 초록 잎이 어둡게, 파란 하늘이 밝게 나와 부자연스럽습니다.

### 기본 변환

```python
img[::-1]              # 상하 반전
img[:, ::-1]           # 좌우 반전
img[100:300, 50:250]   # 자르기 (crop)
img[::2, ::2]          # 절반 크기로 (다운샘플링)
255 - img              # 색 반전 (네거티브)
img.transpose(1, 0, 2) # 90도 회전 (전치)
```

> **전부 슬라이싱과 산술 연산입니다.** 이미지 라이브러리 없이도 됩니다.

### 밝기·대비 조절

```python
# 밝기 — 더하기
bright = np.clip(img.astype(np.int16) + 50, 0, 255).astype(np.uint8)

# 대비 — 곱하기 (중앙값 기준)
contrast = np.clip((img.astype(np.float32) - 128) * 1.5 + 128, 0, 255).astype(np.uint8)

# 감마 보정
gamma = 0.5
corrected = np.clip(((img / 255.0) ** gamma) * 255, 0, 255).astype(np.uint8)
```

### 합성곱(convolution) — CNN 의 핵심

**작은 필터(커널)를 이미지 위에서 미끄러뜨리며 계산**합니다.

```
이미지 일부        필터(3×3)         결과
┌─────────┐      ┌─────────┐
│ 1  2  3 │      │ 0 -1  0 │
│ 4  5  6 │  ×   │-1  5 -1 │  →   1*0 + 2*(-1) + 3*0
│ 7  8  9 │      │ 0 -1  0 │      + 4*(-1) + 5*5 + 6*(-1)
└─────────┘      └─────────┘      + 7*0 + 8*(-1) + 9*0
                                   = -2-4+25-6-8 = 5
```

**대표적인 필터**

| 필터 | 커널 | 효과 |
|---|---|---|
| 블러 | 전부 `1/9` | 흐리게 |
| 샤픈 | 가운데 5, 상하좌우 -1 | 선명하게 |
| 엣지 (수직) | `[[-1,0,1],[-2,0,2],[-1,0,1]]` | 세로선 검출 |
| 엣지 (수평) | `[[-1,-2,-1],[0,0,0],[1,2,1]]` | 가로선 검출 |

> **CNN 이 하는 일** — 이 필터의 숫자를 **사람이 정하지 않고 학습으로 찾습니다.**
> "고양이를 찾으려면 어떤 필터가 필요한가"를 데이터에서 배우는 것입니다.

```python
def make_sample_image(size=200):
    """샘플 컬러 이미지를 만듭니다."""
    img = np.zeros((size, size, 3), dtype=np.uint8)

    # 그라데이션 배경
    for y in range(size):
        img[y, :, 2] = int(255 * y / size)          # 파랑이 아래로 진해짐

    img[circle] = [240, 200, 60]

    for i in range(size):
        if 0 <= i < size and 0 <= size - 1 - i < size:
            img[size - 1 - i, i] = [255, 255, 255]

    return img
```

### Step 3. 이미지 변환 — 슬라이싱과 산술 연산만으로

```python
import numpy as np
import matplotlib.pyplot as plt

img = make_sample_image()

# ══════════ 변환 함수들 ══════════

def flip_vertical(im):
    """상하 반전."""
    return im[::-1]


def flip_horizontal(im):
    """좌우 반전."""
    return im[:, ::-1]


def crop_center(im, ratio=0.5):
    """가운데를 잘라냅니다."""
    h, w = im.shape[:2]
    ch, cw = int(h * ratio), int(w * ratio)
    top, left = (h - ch) // 2, (w - cw) // 2
    return im[top:top + ch, left:left + cw]


def downsample(im, factor=2):
    """factor 배로 축소합니다 (단순 샘플링)."""
    return im[::factor, ::factor]


def invert(im):
    """색 반전 (네거티브)."""
    return 255 - im


def adjust_brightness(im, delta):
    """밝기를 조절합니다. uint8 오버플로를 막습니다."""
    return np.clip(im.astype(np.int16) + delta, 0, 255).astype(np.uint8)


def adjust_contrast(im, factor):
    """대비를 조절합니다. 128 을 기준으로 늘리거나 줄입니다."""
    return np.clip((im.astype(np.float32) - 128) * factor + 128,
                   0, 255).astype(np.uint8)


def adjust_gamma(im, gamma):
    """감마 보정. gamma < 1 이면 밝아집니다."""
    return np.clip(((im / 255.0) ** gamma) * 255, 0, 255).astype(np.uint8)


def posterize(im, levels=4):
    """색 단계를 줄입니다 (포스터 효과)."""
    step = 256 // levels
    return ((im // step) * step).astype(np.uint8)


# ══════════ 시각화 ══════════
transforms = [
    (img, "원본"),
    (flip_vertical(img), "상하 반전  im[::-1]"),
    (flip_horizontal(img), "좌우 반전  im[:, ::-1]"),
    (crop_center(img), "가운데 자르기"),
    (downsample(img, 4), f"1/4 축소  im[::4, ::4]"),
    (invert(img), "색 반전  255 - im"),
    (adjust_brightness(img, 70), "밝게  +70"),
    (adjust_brightness(img, -70), "어둡게  -70"),
    (adjust_contrast(img, 1.8), "대비 ↑  ×1.8"),
    (adjust_contrast(img, 0.4), "대비 ↓  ×0.4"),
    (adjust_gamma(img, 0.5), "감마 0.5"),
    (posterize(img, 3), "포스터 3단계"),
]

fig, axes = plt.subplots(3, 4, figsize=(13, 10))

for ax, (data, title) in zip(axes.flat, transforms):
    ax.imshow(data)
    ax.set_title(f"{title}\n{data.shape}", fontsize=9)
    ax.axis("off")

plt.tight_layout()
plt.show()

# ── uint8 오버플로 확인 ──
print("=" * 56)
print("            uint8 오버플로 실험")
print("=" * 56)

test = np.array([[200, 250]], dtype=np.uint8)
print(f"\n원본 (uint8): {test[0]}")
print(f"  + 100 (잘못):  {(test + 100)[0]}   ← 255를 넘어 순환!")
print(f"  + 100 (올바름): {adjust_brightness(test, 100)[0]}")

test2 = np.array([[50, 20]], dtype=np.uint8)
print(f"\n원본 (uint8): {test2[0]}")
print(f"  - 100 (잘못):  {(test2 - 100)[0]}   ← 0 아래로 순환!")
print(f"  - 100 (올바름): {adjust_brightness(test2, -100)[0]}")
print("=" * 56)
```

### Step 4. 합성곱 직접 구현 — CNN 맛보기 (오늘의 종합 예제)

```python
import numpy as np
import matplotlib.pyplot as plt


def convolve2d(image, kernel):
    """
    2차원 합성곱을 직접 구현합니다.

    image  : (H, W) 흑백 이미지
    kernel : (kh, kw) 필터
    반환    : (H-kh+1, W-kw+1) 결과
    """
    kh, kw = kernel.shape
    h, w = image.shape
    out_h, out_w = h - kh + 1, w - kw + 1

    output = np.zeros((out_h, out_w), dtype=np.float32)

    for y in range(out_h):
        for x in range(out_w):
            region = image[y:y + kh, x:x + kw]      # 커널 크기만큼 잘라서
            output[y, x] = np.sum(region * kernel)   # 곱하고 더함

    return output


def to_uint8(arr):
    """결과를 0~255 uint8 로 정규화합니다."""
    return np.clip(arr, 0, 255).astype(np.uint8)


# ══════════ 필터 정의 ══════════
KERNELS = {
    "원본 (Identity)": np.array([
```

**2.** 이미지를 4등분해 각 사분면에 다른 효과(원본 / 흑백 / 색반전 / 밝기↑)를 적용한 이미지를 만드세요.

<details>
<summary>답 보기</summary>

```python
import numpy as np
import matplotlib.pyplot as plt


def make_quadrant_effect(img):
    """이미지를 4등분해 각 사분면에 다른 효과를 적용합니다."""
    result = img.copy()                    # 원본 보존
    h, w = img.shape[:2]
    mh, mw = h // 2, w // 2

    # ① 좌상단 — 원본 (그대로 둠)

    # ② 우상단 — 흑백
    region = img[:mh, mw:]
    gray = (region @ np.array([0.299, 0.587, 0.114])).astype(np.uint8)
    result[:mh, mw:] = np.stack([gray] * 3, axis=2)      # 3채널로 되돌림

    # ③ 좌하단 — 색 반전
    result[mh:, :mw] = 255 - img[mh:, :mw]

    # ④ 우하단 — 밝기 +80
    result[mh:, mw:] = np.clip(
        img[mh:, mw:].astype(np.int16) + 80, 0, 255
    ).astype(np.uint8)

    return result


img = make_sample_image(200)
quad = make_quadrant_effect(img)

print(f"원본 shape: {img.shape}, dtype: {img.dtype}")
print(f"결과 shape: {quad.shape}, dtype: {quad.dtype}")
print(f"원본이 보존되었는가? {not np.array_equal(img, quad)}")

fig, axes = plt.subplots(1, 2, figsize=(9, 4.5))

axes[0].imshow(img)
axes[0].set_title("원본")
axes[0].axis("off")

axes[1].imshow(quad)
axes[1].set_title("4분면 효과\n(원본 / 흑백 / 색반전 / 밝기↑)")
axes[1].axis("off")

# 사분면 경계선
h, w = img.shape[:2]
axes[1].axhline(h // 2, color="white", linewidth=1.5)
axes[1].axvline(w // 2, color="white", linewidth=1.5)

plt.tight_layout()
plt.show()
```

**포인트 5가지**

- **`img.copy()`** 로 시작합니다. 안 하면 원본이 훼손됩니다. ([Day 042](day-042.md))
- **흑백은 2차원이 되므로** `np.stack([gray]*3, axis=2)` 로 3채널로 되돌려야 대입됩니다.
  안 하면 shape 불일치 에러가 납니다.
- **`axis=2`** 가 중요합니다. `np.stack([gray]*3)` 만 쓰면 `(3, H, W)` 가 되어 틀립니다.
- 밝기 조절은 `int16` 변환 → `clip` → `uint8` 순서를 지킵니다.
- 홀수 크기 이미지도 동작합니다. `//` 로 나눠 나머지는 우하단에 포함됩니다.

**응용 — 함수로 일반화**

```python
def apply_by_quadrant(img, funcs):
    """4개 함수를 각 사분면에 적용합니다."""
    result = img.copy()
    h, w = img.shape[:2]
    mh, mw = h // 2, w // 2

    regions = [
        (slice(None, mh), slice(None, mw)),      # 좌상
        (slice(None, mh), slice(mw, None)),      # 우상
        (slice(mh, None), slice(None, mw)),      # 좌하
        (slice(mh, None), slice(mw, None)),      # 우하
    ]

    for (ys, xs), func in zip(regions, funcs):
        result[ys, xs] = func(img[ys, xs])

    return result


to_gray_3ch = lambda r: np.stack(
    [(r @ np.array([0.299, 0.587, 0.114])).astype(np.uint8)] * 3, axis=2)

quad2 = apply_by_quadrant(img, [
    lambda r: r,
    to_gray_3ch,
    lambda r: 255 - r,
    lambda r: np.clip(r.astype(np.int16) + 80, 0, 255).astype(np.uint8),
])
```
</details>

**문제 3가지**

**① `img + 100` — uint8 오버플로**

`uint8` 은 0~255 입니다. 200 + 100 = 300 인데 담을 수 없어 **순환**해서 44가 됩니다.

```python
np.array([200], dtype=np.uint8) + 100      # [44]
```

**증상** — 밝은 부분이 오히려 검게 나옵니다.

**② `img * 2` — 같은 오버플로**

150 × 2 = 300 → 44. 대비가 오르는 게 아니라 색이 뒤죽박죽이 됩니다.

**③ `img.sum(axis=2)` — 범위 초과**

RGB 를 **더하면** 최대 255×3 = 765 입니다.
`uint8` 범위를 넘고, `imshow` 도 0~255 를 기대하므로 표시가 깨집니다.

**추가 문제 ④ — `cmap="gray"` 누락**

2차원 배열을 그냥 `imshow` 하면 노랑·보라 컬러맵으로 나옵니다.

```python
import matplotlib.pyplot as plt

plt.rc("font", family="Malgun Gothic")
plt.rc("axes", unicode_minus=False)

def adjust_brightness(im, delta):
    """밝기 조절 — 오버플로 방지."""
    return np.clip(im.astype(np.int16) + delta, 0, 255).astype(np.uint8)


def adjust_contrast(im, factor):
    """대비 조절 — 128 기준으로 늘림."""
    return np.clip((im.astype(np.float32) - 128) * factor + 128,
                   0, 255).astype(np.uint8)


def to_gray(im):
    """흑백 변환 — 가중 평균 (합이 1이므로 범위 유지)."""
    return (im @ np.array([0.299, 0.587, 0.114])).astype(np.uint8)


bright = adjust_brightness(img, 100)
contrast = adjust_contrast(img, 2.0)
gray = to_gray(img)

print("=" * 50)

print("-" * 50)

    print(f"{name:<16}{str(arr.dtype):<10}{arr.min():>6}{arr.max():>6}")

print(f"  img + 100        범위 {wrong_bright.min():>4} ~ {wrong_bright.max():>4}  ← 순환")
print(f"  img.sum(axis=2)  범위 {wrong_gray.min():>4} ~ {wrong_gray.max():>4}  ← 765까지")
print("=" * 50)

# ── 시각화 ──
fig, axes = plt.subplots(2, 4, figsize=(14, 7))

correct = [(img, "원본"), (bright, "밝기 +100 (올바름)"),
           (contrast, "대비 ×2 (올바름)"), (gray, "흑백 (올바름)")]
wrong = [(img, "원본"), (wrong_bright, "img + 100 (틀림)"),
```

> **이미지 처리 3원칙**
>
> ① **계산 전에 `float` 또는 `int16` 으로 변환**
> ② **계산 후 `np.clip(..., 0, 255)`**
> ③ **표시·저장 전에 `astype(np.uint8)`**
>
> 흑백 변환에 **가중 평균(합이 1)** 을 쓰면 자동으로 범위가 유지됩니다.
> `sum` 은 3배가 되므로 `mean` 이나 가중 평균을 쓰세요.
>
> 이 원칙은 대단원 03의 이미지 증강([Day 094](../03-ml/day-094.md))에서 그대로 적용됩니다.
</details>

## 오늘의 정리 · W09 총정리

| 개념 | 핵심 |
|---|---|
| 이미지 shape | **`(높이, 너비, 채널)`** — 가로세로 순서 아님 |
| dtype | `uint8` (0~255) · **오버플로 주의** |
| 안전한 계산 | `float`/`int16` 변환 → 계산 → `clip(0,255)` → `uint8` |

| 표시 | 흑백은 **`cmap="gray"`** 필수 |
| OpenCV | **BGR 순서** — `cvtColor` 로 변환 |
| 합성곱 | 커널을 미끄러뜨리며 곱하고 더함 · **CNN의 핵심** |

### 다음 주 예고 — Pandas

지금까지 이렇게 썼습니다.

```python
SCORE, KILLS, SHOTS = 0, 1, 2          # 열 번호를 상수로 관리
data[:, SCORE].mean()
data[data[:, STAGE] == 3][:, SCORE].mean()
```

**열을 번호로 관리하는 것이 불편합니다.**

[W10](day-046.md)에서 **pandas** 를 배우면 이렇게 바뀝니다.

```python
df["score"].mean()
df[df["stage"] == 3]["score"].mean()
df.groupby("stage")["score"].mean()          # 한 줄!
```

**pandas 는 numpy 위에 "이름"을 붙인 것**입니다. 오늘까지 배운 것이 전부 그 밑에서 돕니다.
