## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- HTML 을 파이썬 문자열로 쓰는 것의 문제 4가지를 설명할 수 있다.
- **Jinja2** 템플릿에서 변수 `{{ }}` · 반복 `{% for %}` · 조건 `{% if %}` 을 쓸 수 있다.
- **`render_template`** 로 템플릿에 데이터를 넘길 수 있다.
- **템플릿 상속**(`base.html` + `block`)으로 공통 레이아웃을 만들 수 있다.
- **`static/`** 폴더와 **`url_for`** 로 CSS·이미지를 연결할 수 있다.
- **필터**(`length` `round` `default` 등)와 커스텀 필터를 쓸 수 있다.
- Jinja2 의 **자동 이스케이프**가 무엇을 막아 주는지 안다.

## ② 왜 필요한가

### 어제 코드의 4가지 문제

```python
@app.route("/events")
def events():
    rows = "".join(
        f"<tr><td>{e['id']}</td><td>{e['ts']}</td>"
        f"<td>{e['type']}</td><td>{e['conf']:.2f}</td></tr>"
        for e in EVENTS)
    return f"<h2>이벤트 {len(EVENTS)}건</h2><table>{rows}</table>"
```

**문제 1 — 편집기 지원이 없습니다**

```
파이썬 문자열 안의 HTML
  · 문법 강조 없음
  · 자동 완성 없음
  · 태그 짝 확인 없음
  · ★ 오타를 찾기 어려움
```

**문제 2 — 역할이 섞입니다**

```
디자인을 바꾸려면 → ★ 파이썬 코드를 수정
백엔드 담당자와 프론트 담당자가 ★ 같은 파일을 건드림
```

**문제 3 — 반복·조건이 지저분합니다**

```python
# 조건이 들어가면
rows += ("<td class='high'>" if e['conf'] > 0.9 else "<td>") + ...
# ★ 읽을 수가 없습니다
```

**★ 문제 4 — XSS 취약점**

```python
name = request.args.get("name")
return f"<h1>안녕하세요, {name}님</h1>"
```

```
공격자가 이렇게 접속하면
  /hello?name=<script>alert(document.cookie)</script>

→ ★ 그 스크립트가 브라우저에서 실행됩니다
→ 세션 탈취 · 페이지 변조
```

> **★ Jinja2 는 이것을 자동으로 막아 줍니다.**
> 오늘 배우는 것 중 가장 중요한 이유입니다.

## ③ 개념 설명

### Jinja2 란

```
파이썬 진영의 대표 템플릿 엔진
Flask 에 기본 내장 (별도 설치 불필요)

  템플릿 (HTML + 문법)  +  데이터 (파이썬 객체)
                ↓
            완성된 HTML
```

**세 가지 구분자**

| 구분자 | 용도 | 예 |
|---|---|---|
| `{{ }}` | **값 출력** | `{{ event.id }}` |
| `{% %}` | **문장** (제어) | `{% for e in events %}` |
| `{# #}` | **주석** (출력 안 됨) | `{# 여기는 메모 #}` |

### 변수 출력

```html
<h1>{{ title }}</h1>
<p>총 {{ events|length }}건</p>

<!-- 딕셔너리 -->
{{ event.id }}          <!-- 또는 -->
{{ event['id'] }}

<!-- 중첩 -->
{{ event.box.x1 }}
{{ result.counts_by_class.person }}

<!-- 없는 키 → ★ 예외가 아니라 빈 문자열 -->
{{ event.nonexistent }}
```

> **★ Jinja2 는 없는 키에 관대합니다.**
> ```
> 파이썬:  event['none']  →  KeyError
> Jinja2:  {{ event.none }}  →  빈 문자열
> ```
> 편리하지만 **오타를 못 찾는 원인**이 되기도 합니다.

### 반복

```html
<table>
  <tr><th>ID</th><th>시각</th><th>종류</th></tr>
  {% for e in events %}
  <tr>
    <td>{{ e.id }}</td>
    <td>{{ e.ts }}</td>
    <td>{{ e.type }}</td>
  </tr>
  {% endfor %}
</table>
```

**★ `loop` 변수**

```html
{% for e in events %}
  <tr class="{{ 'odd' if loop.index is odd else 'even' }}">
    <td>{{ loop.index }}</td>       <!-- 1부터 -->
    <td>{{ loop.index0 }}</td>      <!-- 0부터 -->
    <td>{{ loop.revindex }}</td>    <!-- 뒤에서부터 -->
    <td>{{ e.id }}</td>
  </tr>
  {% if loop.first %}<!-- 첫 항목 -->{% endif %}
  {% if loop.last %}<!-- 마지막 항목 -->{% endif %}
{% endfor %}
```

**★ `else` — 비어 있을 때**

```html
{% for e in events %}
  <tr>...</tr>
{% else %}
  <tr><td colspan="3">이벤트가 없습니다</td></tr>
{% endfor %}
```

```
★ 파이썬의 for-else 와 다릅니다
  파이썬: break 없이 끝나면 실행
  Jinja2: ★ 리스트가 비어 있으면 실행
```

### 조건

```html
{% if event.conf >= 0.9 %}
  <span class="badge high">높음</span>
{% elif event.conf >= 0.7 %}
  <span class="badge mid">보통</span>
{% else %}
  <span class="badge low">낮음</span>
{% endif %}

<!-- 인라인 (삼항) -->
<td class="{{ 'danger' if e.conf < 0.5 else '' }}">{{ e.conf }}</td>

<!-- 존재 확인 -->
{% if events %}
  <p>{{ events|length }}건</p>
{% endif %}

{% if snapshot_url is defined and snapshot_url %}
  <img src="{{ snapshot_url }}">
{% endif %}
```

### 필터

```html
{{ events|length }}                 <!-- 개수 -->
{{ conf|round(2) }}                 <!-- 반올림 -->
{{ name|upper }}                    <!-- 대문자 -->
{{ text|truncate(50) }}             <!-- 자르기 -->
{{ value|default('없음') }}          <!-- ★ 기본값 -->
{{ items|join(', ') }}              <!-- 연결 -->
{{ nums|sum }}                      <!-- 합계 -->
{{ nums|max }}  {{ nums|min }}
{{ events|sort(attribute='ts') }}   <!-- 정렬 -->
{{ events|selectattr('type', 'equalto', 'person')|list }}
{{ data|tojson }}                   <!-- ★ JSON 문자열로 -->
{{ html|safe }}                     <!-- ★ 이스케이프 안 함 (주의!) -->
```

**★ 필터 체이닝**

```html
{{ events|selectattr('conf', '>', 0.8)|list|length }}
{{ conf|round(3)|float }}
```

### ★ 자동 이스케이프 — XSS 방어

```python
name = "<script>alert(1)</script>"
```

```html
<!-- Jinja2 -->
<h1>안녕, {{ name }}</h1>
```

```html
<!-- 실제 출력 — ★ 태그가 문자로 변환됨 -->
<h1>안녕, &lt;script&gt;alert(1)&lt;/script&gt;</h1>
```

```
화면에는 "<script>alert(1)</script>" 라는 ★ 글자가 보일 뿐
스크립트가 실행되지 않습니다
```

**변환 규칙**

| 원본 | 변환 |
|---|---|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&#34;` |
| `'` | `&#39;` |

> ⚠️ **`|safe` 는 이 보호를 끕니다.**
> ```html
> {{ user_input|safe }}     <!-- ★ 위험! -->
> ```
> **여러분이 직접 만든 HTML 에만 쓰세요.**
> 사용자 입력에는 절대 쓰지 마세요.

### `render_template`

### ★ 템플릿 상속

**공통 레이아웃을 한 번만 씁니다.**

```html
<!-- templates/base.html -->
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>{% block title %}CCTV{% endblock %}</title>
  <link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
  {% block head %}{% endblock %}
</head>
<body>
  <header>
    <h1><a href="{{ url_for('index') }}">CCTV 검출 시스템</a></h1>
    <nav>
      <a href="{{ url_for('index') }}">홈</a>
      <a href="{{ url_for('events') }}">이력</a>
      <a href="{{ url_for('stats') }}">통계</a>
    </nav>
  </header>

  <main>
    {% block content %}{% endblock %}   <!-- ★ 각 페이지가 채움 -->
  </main>

  <footer>
    <p>3조 · {{ now.strftime('%Y-%m-%d %H:%M') }}</p>
  </footer>

  {% block scripts %}{% endblock %}
</body>
</html>
```

```html
<!-- templates/events.html -->
{% extends "base.html" %}          <!-- ★ 첫 줄 -->

{% block title %}이벤트 목록 · CCTV{% endblock %}

{% block content %}
  <h2>이벤트 {{ events|length }}건</h2>
  <table>
    {% for e in events %}
    <tr><td>{{ e.id }}</td><td>{{ e.type }}</td></tr>
    {% endfor %}
  </table>
{% endblock %}
```

**★ 상속의 규칙**

```
① {% extends %} 는 ★ 템플릿의 첫 줄
② 자식은 block 안의 내용만 정의
③ block 밖에 쓴 내용은 ★ 무시됨
④ block 이름은 유일해야
⑤ super() 로 부모 내용을 포함 가능
```

```html
{% block content %}
  {{ super() }}          <!-- ★ 부모의 block 내용 -->
  <p>추가 내용</p>
{% endblock %}
```

### `url_for` — 절대 하드코딩하지 마세요

```html
<!-- ✗ -->
<a href="/events">이력</a>
<link rel="stylesheet" href="/static/css/style.css">

<!-- ✓ -->
<a href="{{ url_for('events') }}">이력</a>
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
```

**왜 `url_for` 인가**

```
① 라우트 경로가 바뀌어도 ★ 템플릿을 안 고쳐도 됨
     @app.route("/events")      →  @app.route("/history")
     url_for('events') 는 그대로

② Blueprint · 서브 경로에서 자동 처리 (Day 160)

③ ★ static 파일에 캐시 버스터를 붙일 수 있음
     /static/css/style.css?v=1705294822
```

**인자 전달**

```html
<a href="{{ url_for('event_detail', event_id=e.id) }}">보기</a>
<!-- → /events/42 -->

<a href="{{ url_for('events', type='person', page=2) }}">사람 2페이지</a>
<!-- → /events?type=person&page=2 -->
```

### 커스텀 필터

```python
@app.template_filter("conf_badge")
def conf_badge(value):
    """신뢰도를 등급 문자열로"""
    if value >= 0.9:
        return "높음"
    if value >= 0.7:
        return "보통"
    return "낮음"


@app.template_filter("dt")
def format_datetime(value, fmt="%Y-%m-%d %H:%M"):
    """ISO 문자열 → 보기 좋은 형식"""
    from datetime import datetime
    if isinstance(value, str):
        value = datetime.fromisoformat(value)
    return value.strftime(fmt)


@app.template_filter("filesize")
def filesize(num):
    for unit in ("B", "KB", "MB", "GB"):
        if abs(num) < 1024:
            return f"{num:.1f} {unit}"
        num /= 1024
    return f"{num:.1f} TB"
```

```html
<td>{{ e.conf|conf_badge }}</td>
<td>{{ e.ts|dt }}</td>
<td>{{ e.ts|dt('%H:%M:%S') }}</td>
<td>{{ size|filesize }}</td>
```

### `macro` — 함수 같은 재사용

```html

    <div class="fill" style="width:{{ (value * 100)|round(0) }}%"></div>
    <span>{{ (value * 100)|round(1) }}%</span>

```python
"""web/app.py — 템플릿 적용"""
import logging
from datetime import datetime, date

from flask import Flask, abort, jsonify, render_template, request

app = Flask(__name__)
logging.basicConfig(level=logging.INFO)

APP_NAME = "CCTV 검출 시스템"
VERSION = "1.0"

EVENTS = [
    {"id": 1, "ts": "2026-01-15T09:12:04", "type": "person", "count": 1,
     "conf": 0.91, "snapshot": None,
     "detections": [
         {"class": "person", "conf": 0.912,
          "box": {"x1": 412.3, "y1": 188.7, "x2": 561.0, "y2": 604.2},
          "size": {"w": 148.7, "h": 415.5}}]},
    {"id": 2, "ts": "2026-01-15T09:48:31", "type": "person", "count": 2,
     "conf": 0.87, "snapshot": None, "detections": []},
    {"id": 3, "ts": "2026-01-15T14:02:19", "type": "box", "count": 1,
     "conf": 0.78, "snapshot": None, "detections": []},
    {"id": 4, "ts": "2026-01-15T18:30:55", "type": "person", "count": 1,
     "conf": 0.94, "snapshot": None, "detections": []},
    {"id": 5, "ts": "2026-01-16T07:21:40", "type": "box", "count": 2,
     "conf": 0.82, "snapshot": None, "detections": []},
]

ALL_TYPES = ("person", "box")


# ────────────────────── 컨텍스트 · 필터 ──────────────────────

@app.context_processor
def inject_globals():
    """★ 모든 템플릿에서 사용 가능"""
    return {"app_name": APP_NAME, "version": VERSION, "now": datetime.now()}


@app.template_filter("dt")
def format_dt(value, fmt="%Y-%m-%d %H:%M"):
    if isinstance(value, str):
        try:
            value = datetime.fromisoformat(value)
        except ValueError:
            return value
    return value.strftime(fmt)


@app.template_filter("conf_label")
def conf_label(value):
    return "높음" if value >= 0.9 else ("보통" if value >= 0.7 else "낮음")


# ────────────────────────── 페이지 ──────────────────────────

@app.route("/")
def index():
    by_type = {}
    for e in EVENTS:
        by_type[e["type"]] = by_type.get(e["type"], 0) + 1
    today = date.today().isoformat()
    return render_template(
        "index.html",
        active_page="index",
        total=len(EVENTS),
        today_count=sum(1 for e in EVENTS if e["ts"].startswith(today)),
        by_type=by_type,
        recent=sorted(EVENTS, key=lambda e: e["ts"], reverse=True)[:5],
    )


@app.route("/events")
def events():
    e_type = request.args.get("type") or ""
    min_conf = request.args.get("min_conf", type=float, default=0.0)

    if e_type and e_type not in ALL_TYPES:
        e_type = ""
    min_conf = max(0.0, min(1.0, min_conf))

    result = [e for e in EVENTS
              if (not e_type or e["type"] == e_type)
              and e["conf"] >= min_conf]
    result.sort(key=lambda e: e["ts"], reverse=True)

    return render_template(
        "events.html",
        active_page="events",
        events=result,
        all_types=ALL_TYPES,
        filters={"type": e_type, "min_conf": min_conf},
    )


@app.route("/events/<int:event_id>")
def event_detail(event_id):
    event = next((e for e in EVENTS if e["id"] == event_id), None)
    if event is None:
        abort(404, description=f"이벤트 {event_id} 를 찾을 수 없습니다")
    return render_template("event_detail.html",
                           active_page="events", event=event)


@app.route("/stats")
def stats():
    by_type, by_day = {}, {}
    for e in EVENTS:
        by_type[e["type"]] = by_type.get(e["type"], 0) + 1
        d = e["ts"][:10]
        by_day[d] = by_day.get(d, 0) + 1
    confs = [e["conf"] for e in EVENTS]
    return render_template(
        "stats.html", active_page="stats",
        total=len(EVENTS), by_type=by_type,
        by_day=sorted(by_day.items()),
        conf_avg=round(sum(confs) / len(confs), 3) if confs else 0,
        conf_min=min(confs) if confs else 0,
        conf_max=max(confs) if confs else 0,
    )


@app.route("/upload")
def upload():
    """Day 159 에서 구현"""
    return render_template("upload.html", active_page="upload")


# ────────────────────────── 에러 ──────────────────────────

@app.errorhandler(404)
def not_found(e):
    if request.path.startswith("/api/"):
        return jsonify({"error": "not_found", "path": request.path}), 404
    return render_template("errors/404.html",
                           message=getattr(e, "description", "")), 404


@app.errorhandler(500)
def server_error(e):
    app.logger.exception("서버 오류")
    if request.path.startswith("/api/"):
        return jsonify({"error": "internal_error"}), 500
    return render_template("errors/500.html"), 500


if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000, debug=True)

### C — 상속 없이 페이지마다 전체 HTML

**✗ 절대 하지 마세요**

**이유 1 — 수정 지옥**

```
페이지 9개 × 전체 HTML

  네비게이션에 메뉴 하나 추가
  → ★ 9개 파일을 전부 수정
  → 하나 빠뜨리면 그 페이지만 메뉴가 다름

  CSS 파일명 변경
  → 9개 파일 수정

  푸터에 버전 표시 추가
  → 9개 파일 수정
```

**이유 2 — 일관성 붕괴**

```
페이지마다 조금씩 다른 헤더
→ 사용자가 "다른 사이트인가?" 혼란
→ ★ 발표에서 완성도가 떨어져 보임
```

**이유 3 — 실제로는 상속이 더 쉬움**

```html
<!-- 상속 없음 — 매번 이만큼 -->
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="...">
  <title>이벤트</title>
  <link rel="stylesheet" href="...">
</head>
<body>
  <header>... 20줄 ...</header>
  <main>
    <h2>이벤트</h2>      ← ★ 실제 내용은 이것뿐
  </main>
  <footer>... 5줄 ...</footer>
</body>
</html>
```

```html
<!-- 상속 — 4줄 -->
{% extends "base.html" %}
{% block title %}이벤트{% endblock %}
{% block content %}<h2>이벤트</h2>{% endblock %}
```

**★ C 에게 해 줄 조언**

```
"헷갈리는 건 처음뿐입니다. 규칙이 3개뿐이에요.

  ① {% extends %} 를 ★ 첫 줄에
  ② {% block %} 안에만 내용을 씀
  ③ block 이름은 base.html 에 있는 것과 같게

  오늘 base.html 을 한 번 만들면
  ★ W36까지 다시 안 만듭니다."
```

**★ 이해를 돕는 비유**

```
상속 = 파이썬 클래스 상속과 같은 개념

  class BasePage:
      def render(self):
          return header() + self.content() + footer()

      def content(self):        # ★ block
          return ""

  class EventsPage(BasePage):   # ★ extends
      def content(self):        # ★ block 재정의
          return "<h2>이벤트</h2>"

★ 대단원 01 [Day 016~025] 에서 배운 그것입니다
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 문자열 HTML 문제 | 편집기 지원 ✗ · 역할 혼재 · 반복 지저분 · ★ **XSS** |
| `{{ }}` | 값 출력 |
| `{% %}` | 문장 (제어) |
| `{# #}` | 주석 |
| 없는 키 | ★ **예외 아니라 빈 문자열** |
| `loop` | `index` `index0` `first` `last` `revindex` |
| `for-else` | ★ **리스트가 비었을 때** |
| 필터 | `length` `round` `default` `join` `tojson` |
| ★ 자동 이스케이프 | **XSS 를 자동으로 막아 줌** |
| `\|safe` | ★ **사용자 입력에 절대 금지** |
| `render_template` | `templates/` 에서 찾음 |
| ★ 상속 | `{% extends %}` **첫 줄** + `{% block %}` |
| block 밖 | ★ **무시됨** |
| `super()` | 부모 block 내용 포함 |
| **`url_for`** | ★ **경로 하드코딩 금지** |
| `static` | `url_for('static', filename=...)` |
| 컨텍스트 프로세서 | 모든 템플릿 공통 변수 |
| 커스텀 필터 | `@app.template_filter` |
| `include` | 조각 재사용 (`_이름.html`) |
| `macro` | 함수처럼 재사용 |
| 딕셔너리 `items` | ★ **`data['items']`** 로 접근 |
| 역할 분담 | 로직=파이썬 · **표현=템플릿** |

**오늘 반드시 기억할 세 가지**
> ① **`{% extends %}` 는 첫 줄, 내용은 `{% block %}` 안에.** 밖에 쓰면 무시됩니다.
> ② **경로를 하드코딩하지 말고 `url_for` 를 쓰세요.** 라우트가 바뀌어도 템플릿을 안 고칩니다.
> ③ **`|safe` 를 사용자 입력에 쓰지 마세요.** Jinja2 의 자동 이스케이프가 XSS를 막아 주고 있습니다.

     · ★ url_for 로 모든 링크

     · 최소 2곳에서 쓰이는 조각

     · ★ url_for('static', ...)
     · 모바일에서 표가 가로 스크롤되게
