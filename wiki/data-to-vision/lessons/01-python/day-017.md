## ② 왜 필요한가

어제 만든 `Character` 클래스로 여러 직업을 만들어 봅시다.

```python
class Warrior:
    def __init__(self, name):
        self.name = name
        self.hp = 150
        self.attack = 20

    def is_alive(self):
        return self.hp > 0

    def take_damage(self, amount):
        self.hp = max(self.hp - amount, 0)

    def special(self):
        print("강타!")


class Mage:
    def __init__(self, name):
        self.name = name
        self.hp = 80
        self.attack = 30

    def is_alive(self):          # ← 똑같은 코드
        return self.hp > 0

    def take_damage(self, amount):   # ← 또 똑같은 코드
        self.hp = max(self.hp - amount, 0)

    def special(self):
        print("파이어볼!")
```

`is_alive` 와 `take_damage` 가 **완전히 같습니다.** 직업이 5개면 5번 복사해야 하고,
체력 계산 규칙을 바꾸려면 5곳을 모두 고쳐야 합니다.

**상속은 공통된 부분을 부모 클래스에 한 번만 쓰고, 자식들이 물려받는 것**입니다.

```python
class Character:                  # 부모 — 공통 기능
    def is_alive(self): ...
    def take_damage(self, amount): ...

class Warrior(Character):         # 자식 — 다른 부분만
    def special(self):
        print("강타!")

class Mage(Character):
    def special(self):
        print("파이어볼!")
```

W05에서 적을 여러 종류(`FastEnemy`, `TankEnemy`, `BossEnemy`) 만들 때 이 구조를 씁니다.
그리고 pygame의 `Sprite` 클래스를 상속받는 것이 게임 개발의 기본 패턴입니다.

## ③ 개념 설명

### 상속의 기본

```python
class 자식클래스(부모클래스):
    ...
```

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def breathe(self):
        print(f"{self.name}이(가) 숨을 쉰다")


class Dog(Animal):           # Animal 을 상속
    def bark(self):
        print("멍멍!")


d = Dog("바둑이")
d.breathe()        # 부모의 메서드 사용 가능
d.bark()           # 자신의 메서드
print(d.name)      # 부모의 __init__ 이 만든 속성
```

실행 결과:

```
바둑이이(가) 숨을 쉰다
멍멍!
바둑이
```

| 용어 | 다른 이름 |
|---|---|
| **부모 클래스** | 상위 클래스, 슈퍼 클래스, base class |
| **자식 클래스** | 하위 클래스, 서브 클래스, derived class |

> **상속 관계는 "is-a" 로 확인합니다.**
> "개는 동물이다(Dog **is a** Animal)" → 상속이 맞습니다.
> "자동차는 엔진이다"? 아닙니다. 자동차는 엔진을 **가집니다**(has-a) → 상속이 아니라 컴포지션입니다. ([Day 018](day-018.md))

### `super()` — 부모의 기능 호출하기

자식이 `__init__` 을 새로 정의하면, **부모의 `__init__` 은 실행되지 않습니다.**

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        self.breed = breed          # 부모 __init__ 을 안 부름


d = Dog("바둑이", "진돗개")
print(d.name)                       # AttributeError!
```

**해결 — `super().__init__()` 으로 부모를 먼저 호출합니다.**

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)      # 부모의 __init__ 실행
        self.breed = breed          # 자기 것 추가


d = Dog("바둑이", "진돗개")
print(d.name, d.breed)              # 바둑이 진돗개
```

> **순서가 중요합니다.** `super().__init__()` 을 **맨 위**에 두세요.
> 부모가 만든 속성을 자식이 바로 쓸 수 있게 됩니다.

### 메서드 오버라이딩 — 부모 기능을 덮어쓰기

자식이 부모와 **같은 이름의 메서드**를 정의하면, 자식 것이 우선합니다.

```python
class Animal:
    def speak(self):
        print("...")


class Dog(Animal):
    def speak(self):                # 오버라이딩
        print("멍멍!")


class Cat(Animal):
    def speak(self):
        print("야옹~")


Animal().speak()     # ...
Dog().speak()        # 멍멍!
Cat().speak()        # 야옹~
```

**부모 기능을 덮어쓰되 함께 쓰고 싶을 때도 `super()` 를 씁니다.**

```python
class Character:
    def take_damage(self, amount):
        self.hp -= amount
        print(f"{amount}의 피해")


class Knight(Character):
    def take_damage(self, amount):
        reduced = amount // 2                 # 방어 특성: 피해 절반
        print("방패로 막았다!")
        super().take_damage(reduced)          # 부모 기능 실행
```

### 다형성 — 같은 이름, 다른 동작

**여러 종류의 객체를 같은 방식으로 다룰 수 있는 성질**입니다.

```python
animals = [Dog(), Cat(), Dog(), Animal()]

for a in animals:
    a.speak()          # 각자 자기 방식대로 짖는다
```

실행 결과:

```
멍멍!
야옹~
멍멍!
...
```

> **이것이 상속의 진짜 가치입니다.**
> 리스트에 `Dog` 인지 `Cat` 인지 신경 쓰지 않고 담을 수 있고, `speak()` 만 부르면 알아서 각자 동작합니다.
>
> W05에서 여러 종류의 적을 하나의 리스트에 담고 `for e in enemies: e.update()` 라고만 쓰게 됩니다.
> 적 종류를 새로 추가해도 이 코드는 **한 글자도 안 바뀝니다.**

### isinstance() — 종류 확인하기

```python
d = Dog("바둑이")

print(isinstance(d, Dog))         # True
print(isinstance(d, Animal))      # True  ← 부모 타입으로도 True!
print(isinstance(d, Cat))         # False

print(type(d) == Dog)             # True
print(type(d) == Animal)          # False ← type 은 정확히 일치할 때만
```

> **`isinstance` 를 쓰세요.** `type() ==` 은 상속 관계를 무시합니다.
> 다만 `isinstance` 검사를 남발하는 것은 좋지 않습니다. 다형성으로 해결할 수 있으면 그쪽이 낫습니다.

### 클래스 변수 vs 인스턴스 변수

```python
class Player:
    species = "인간"          # 클래스 변수 — 모두 공유
    count = 0                 # 생성된 객체 수를 셈

    def __init__(self, name):
        self.name = name      # 인스턴스 변수 — 객체마다
        Player.count += 1     # 클래스 변수 수정은 클래스 이름으로


p1 = Player("홍길동")
p2 = Player("김철수")

print(p1.species, p2.species)     # 인간 인간
print(Player.count)               # 2
print(p1.name, p2.name)           # 홍길동 김철수
```

| | 클래스 변수 | 인스턴스 변수 |
|---|---|---|
| 정의 위치 | `class` 바로 아래 | `__init__` 안에 `self.` |
| 소유 | 클래스 (모두 공유) | 객체마다 따로 |
| 접근 | `Player.count` 또는 `p1.count` | `p1.name` |
| 수정 | **`Player.count = ...`** | `p1.name = ...` |
| 용도 | 상수, 공통 설정, 카운터 | 객체별 상태 |

> ⚠️ **클래스 변수에 리스트를 두지 마세요.** ([Day 016](day-016.md) 확인 문제 3번)
> 숫자·문자열 같은 **변하지 않는 값**만 두는 것이 안전합니다.

> ⚠️ **`self.count += 1` 은 클래스 변수를 수정하지 않습니다.**
> ```python
> def __init__(self):
>     self.count += 1        # 클래스 변수를 읽어 +1 한 값을 '인스턴스 변수'로 새로 만듦
> ```
> 클래스 변수를 바꾸려면 반드시 `Player.count += 1` 처럼 **클래스 이름**으로 접근하세요.

## ④ 단계별 실습

### Step 1. 상속 기본 익히기

`inheritance.py` 를 만들어 실행합니다.

```python
class Animal:
    """모든 동물의 부모 클래스."""

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def eat(self):
        print(f"{self.name}이(가) 밥을 먹는다")

    def speak(self):
        print(f"{self.name}: ...")

    def info(self):
        print(f"[{self.__class__.__name__}] {self.name}, {self.age}살")


class Dog(Animal):
    """개."""

    def __init__(self, name, age, breed):
        super().__init__(name, age)        # 부모 초기화 먼저
        self.breed = breed

    def speak(self):                       # 오버라이딩
        print(f"{self.name}: 멍멍!")

    def fetch(self):                       # 자기만의 메서드
        print(f"{self.name}이(가) 공을 물어온다")


class Cat(Animal):
    """고양이."""

    def speak(self):
        print(f"{self.name}: 야옹~")

    def scratch(self):
        print(f"{self.name}이(가) 발톱을 세운다")


# ── 실행 ──
animals = [
    Dog("바둑이", 3, "진돗개"),
    Cat("나비", 2),
    Dog("초코", 5, "푸들"),
]

print("=" * 40)
for a in animals:
    a.info()
    a.eat()          # 부모에게 물려받은 기능
    a.speak()        # 각자 다르게 동작 (다형성)

    # 종류별 특수 기능
    if isinstance(a, Dog):
        a.fetch()
    elif isinstance(a, Cat):
        a.scratch()

    print("-" * 40)
```

### Step 2. RPG 직업 시스템

```python
import random


class Character:
    """모든 캐릭터의 부모 클래스."""

    def __init__(self, name, hp, attack, defense):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
        self.defense = defense
        self.level = 1

    def is_alive(self):
        return self.hp > 0

    def take_damage(self, amount):
        """피해를 입습니다. 실제로 받은 피해를 반환합니다."""
        actual = max(amount - self.defense // 3, 1)
        self.hp = max(self.hp - actual, 0)
        return actual

    def heal(self, amount):
        before = self.hp
        self.hp = min(self.hp + amount, self.max_hp)
        return self.hp - before

    def basic_attack(self, target):
        """기본 공격. 모든 직업이 공통으로 가집니다."""
        damage = int(self.attack * random.uniform(0.9, 1.1))
        actual = target.take_damage(damage)
        print(f"  {self.name}의 공격 → {target.name} {actual} 피해")
        return actual

    def special(self, target):
        """특수 공격. 자식이 각자 구현합니다."""
        print(f"  {self.name}은(는) 특수 능력이 없다.")
        return 0

    def get_class_name(self):
        return self.__class__.__name__

    def show(self, width=12):
        filled = int(width * self.hp / self.max_hp)
        bar = "█" * filled + "░" * (width - filled)
        print(f"  {self.name:<8}({self.get_class_name():<7}) [{bar}] {self.hp:>3}/{self.max_hp}")


class Warrior(Character):
    """전사 — 체력이 높고 방어가 좋다."""

    def __init__(self, name):
        super().__init__(name, hp=180, attack=18, defense=12)
        self.rage = 0                       # 전사만의 자원

    def take_damage(self, amount):
        """피해를 받으면 분노가 쌓입니다."""
        actual = super().take_damage(amount)     # 부모 기능 사용
        self.rage = min(self.rage + actual // 2, 100)
        return actual

    def special(self, target):
        """강타 — 분노를 소모해 큰 피해."""
        if self.rage < 30:
            print(f"  {self.name}: 분노가 부족하다! (현재 {self.rage}/30)")
            return 0

        self.rage -= 30
        damage = int(self.attack * 2.5)
        actual = target.take_damage(damage)
        print(f"  ⚔ {self.name}의 강타! → {target.name} {actual} 피해 (분노 {self.rage})")
        return actual


class Mage(Character):
    """마법사 — 공격력이 높지만 약하다."""

    def __init__(self, name):
        super().__init__(name, hp=100, attack=28, defense=4)
        self.mp = 60

    def special(self, target):
        """파이어볼 — 마나를 소모해 강력한 마법."""
        if self.mp < 20:
            print(f"  {self.name}: 마나가 부족하다! (현재 {self.mp}/20)")
            return 0

        self.mp -= 20
        damage = int(self.attack * 2.0)
        actual = target.take_damage(damage)
        print(f"  🔥 {self.name}의 파이어볼! → {target.name} {actual} 피해 (MP {self.mp})")
        return actual


class Priest(Character):
    """사제 — 회복 능력이 있다."""

    def __init__(self, name):
        super().__init__(name, hp=120, attack=12, defense=8)
        self.mp = 80

    def special(self, target):
        """치유 — 자기 자신을 회복합니다. (target 은 무시)"""
        if self.mp < 25:
            print(f"  {self.name}: 마나가 부족하다! (현재 {self.mp}/25)")
            return 0

        self.mp -= 25
        healed = self.heal(50)
        print(f"  ✚ {self.name}의 치유! HP +{healed} (MP {self.mp})")
        return 0


# ── 실행 ──
party = [Warrior("아서"), Mage("멀린"), Priest("루나")]
boss = Character("드래곤", 400, 30, 15)

print("=" * 52)
print("               보스전 시작!")
print("=" * 52)

turn = 1
while boss.is_alive() and any(c.is_alive() for c in party) and turn <= 12:
    print(f"\n--- {turn}턴 ---")

    # 파티 공격 (다형성! 직업을 몰라도 됨)
    for c in party:
        if not c.is_alive():
            continue

        if turn % 2 == 0:
            c.special(boss)          # 짝수 턴엔 특수 공격
        else:
            c.basic_attack(boss)

        if not boss.is_alive():
            break

    if not boss.is_alive():
        break

    # 보스 반격 — 살아 있는 아무나
    alive = [c for c in party if c.is_alive()]
    if alive:
        boss.basic_attack(random.choice(alive))

    print()
    for c in party:
        c.show()
    boss.show()

    turn += 1

print("\n" + "=" * 52)
if not boss.is_alive():
    print(f"  🎉 승리! {turn}턴 만에 드래곤을 물리쳤습니다.")
else:
    print("  패배… 파티가 전멸했습니다.")
print("=" * 52)
```

> **이 코드의 핵심은 `for c in party:` 입니다.**
> 파티에 무엇이 들어 있든 `c.basic_attack(boss)` 와 `c.special(boss)` 만 부르면 됩니다.
> **새 직업(`Archer`, `Rogue`)을 추가해도 이 반복문은 바뀌지 않습니다.**

### Step 3. 클래스 변수 활용하기

```python
class Monster:
    """몬스터. 생성 개수와 처치 개수를 클래스 변수로 추적합니다."""

    total_created = 0          # 클래스 변수 — 전체에서 공유
    total_killed = 0

    BASE_EXP = 10              # 상수 (대문자)

    def __init__(self, name, hp, level=1):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.level = level

        Monster.total_created += 1          # 클래스 이름으로 접근
        self.id = Monster.total_created     # 고유 번호 부여

    def get_exp(self):
        """처치 시 주는 경험치."""
        return Monster.BASE_EXP * self.level

    def take_damage(self, amount):
        self.hp = max(self.hp - amount, 0)

        if self.hp == 0:
            Monster.total_killed += 1
            print(f"  #{self.id} {self.name} 처치! (+{self.get_exp()} EXP)")
            return True

        return False

    @classmethod
    def show_stats(cls):
        """클래스 전체 통계를 출력합니다."""
        alive = cls.total_created - cls.total_killed
        print(f"\n[통계] 생성 {cls.total_created} / 처치 {cls.total_killed} / 생존 {alive}")


class Boss(Monster):
    """보스 몬스터 — 경험치가 10배."""

    def get_exp(self):
        return super().get_exp() * 10


# ── 실행 ──
monsters = [
    Monster("슬라임", 30),
    Monster("고블린", 60, level=2),
    Monster("오크", 100, level=3),
    Boss("드래곤", 300, level=10),
]

print("=" * 44)
for m in monsters:
    print(f"  #{m.id} {m.name:<8} Lv.{m.level:<3} HP {m.max_hp:<4} EXP {m.get_exp()}")
print("=" * 44)

Monster.show_stats()

print("\n[전투]")
monsters[0].take_damage(50)
monsters[1].take_damage(30)
monsters[3].take_damage(500)

Monster.show_stats()
```

> **눈여겨볼 점 3가지**
> - `Monster.total_created += 1` — **클래스 이름**으로 접근해야 클래스 변수가 실제로 바뀝니다.
> - `@classmethod` 는 "객체가 아니라 클래스에 속한 메서드"입니다. 첫 인자가 `self` 가 아니라 `cls`(클래스 자신)입니다. `Monster.show_stats()` 처럼 객체 없이 부를 수 있습니다.
> - `Boss.get_exp()` 가 `super().get_exp() * 10` — 부모 계산을 재사용하면서 10배만 곱합니다. 부모의 공식이 바뀌어도 자동으로 반영됩니다.

### Step 4. 도형 클래스 계층 (오늘의 종합 예제)

```python
import math


class Shape:
    """모든 도형의 부모 클래스."""

    count = 0

    def __init__(self, name):
        self.name = name
        Shape.count += 1

    def get_area(self):
        """넓이. 자식이 반드시 구현해야 합니다."""
        raise NotImplementedError(f"{self.__class__.__name__} 는 get_area 를 구현해야 합니다")

    def get_perimeter(self):
        """둘레. 자식이 반드시 구현해야 합니다."""
        raise NotImplementedError(f"{self.__class__.__name__} 는 get_perimeter 를 구현해야 합니다")

    def describe(self):
        """공통 출력 형식."""
        return f"{self.name:<10} 넓이 {self.get_area():>8.2f}  둘레 {self.get_perimeter():>8.2f}"


class Rectangle(Shape):
    """직사각형."""

    def __init__(self, width, height):
        super().__init__("직사각형")
        self.width = width
        self.height = height

    def get_area(self):
        return self.width * self.height

    def get_perimeter(self):
        return 2 * (self.width + self.height)


class Square(Rectangle):
    """정사각형 — 직사각형의 특수한 경우."""

    def __init__(self, side):
        super().__init__(side, side)        # 가로=세로
        self.name = "정사각형"


class Circle(Shape):
    """원."""

    def __init__(self, radius):
        super().__init__("원")
        self.radius = radius

    def get_area(self):
        return math.pi * self.radius ** 2

    def get_perimeter(self):
        return 2 * math.pi * self.radius


class Triangle(Shape):
    """세 변의 길이로 만드는 삼각형."""

    def __init__(self, a, b, c):
        if a + b <= c or b + c <= a or a + c <= b:
            raise ValueError("삼각형이 될 수 없는 변의 길이입니다")

        super().__init__("삼각형")
        self.a = a
        self.b = b
        self.c = c

    def get_perimeter(self):
        return self.a + self.b + self.c

    def get_area(self):
        """헤론의 공식."""
        s = self.get_perimeter() / 2
        return math.sqrt(s * (s - self.a) * (s - self.b) * (s - self.c))


class Unknown(Shape):
    """넓이를 구현하지 않은 도형 (에러 확인용)."""
    pass


# ── 실행 ──
shapes = [
    Rectangle(4, 6),
    Square(5),
    Circle(3),
    Triangle(3, 4, 5),
]

print("=" * 46)
print("                  도형 목록")
print("=" * 46)

for s in shapes:
    print("  " + s.describe())          # 다형성 — 각자 자기 공식으로 계산

print("-" * 46)
total_area = sum(s.get_area() for s in shapes)
print(f"  전체 넓이 합계: {total_area:.2f}")
print(f"  생성된 도형 수: {Shape.count}")

largest = max(shapes, key=lambda s: s.get_area())
print(f"  가장 넓은 도형: {largest.name} ({largest.get_area():.2f})")
print("=" * 46)

# 상속 관계 확인
sq = Square(5)
print(f"\nSquare 는 Rectangle 인가? {isinstance(sq, Rectangle)}")
print(f"Square 는 Shape 인가?     {isinstance(sq, Shape)}")
print(f"Square 는 Circle 인가?    {isinstance(sq, Circle)}")

# 구현하지 않은 경우
print()
try:
    Unknown("미지의 도형").get_area()
except NotImplementedError as e:
    print(f"오류: {e}")
```

> - `Triangle.__init__` 에서 유효성 검사 후 `super().__init__()` 을 호출합니다. **잘못된 객체는 아예 만들어지지 않습니다.**

### is-a 관계가 아닌데 상속을 씀

```python
class Engine:
    def start(self): ...

class Car(Engine):        # ❌ 자동차는 엔진이 아니다
    pass
```

**해결** — 컴포지션(가지고 있는 관계)으로 바꿉니다.

```python
class Car:
    def __init__(self):

    def start(self):
        self.engine.start()
```

> **판단법** — "A는 B다" 가 자연스러우면 상속, "A는 B를 가진다" 가 자연스러우면 컴포지션.

**3.** 아래 코드에서 `Boss` 의 체력이 예상과 다르게 동작합니다. 원인과 해결책을 쓰세요.

```python
        self.name = name
        self.hp = hp
        self.max_hp = hp

    def take_damage(self, amount):
        self.hp = max(self.hp - amount, 0)
        print(f"{self.name} HP {self.hp}/{self.max_hp}")

            self.shield -= absorbed
            amount -= absorbed
            print(f"보호막이 {absorbed} 흡수! (남은 보호막 {self.shield})")
```

```python
    def __init__(self, name, hp, shield):
        super().__init__(name, hp)      # ← 부모 초기화를 맨 위에
        self.shield = shield

    def take_damage(self, amount):
        if self.shield > 0:
            absorbed = min(self.shield, amount)
            self.shield -= absorbed
            amount -= absorbed
            print(f"보호막이 {absorbed} 흡수! (남은 보호막 {self.shield})")
        super().take_damage(amount)


boss = Boss("드래곤", 300, 100)
boss.take_damage(150)
boss.take_damage(80)
```

실행 결과:

```
보호막이 100 흡수! (남은 보호막 0)
드래곤 HP 250/300
드래곤 HP 170/300
```

> **교훈** — 자식이 `__init__` 을 정의하는 순간, **`super().__init__()` 호출은 자식의 책임**이 됩니다.
> 그리고 **맨 첫 줄에** 두세요. 부모가 만든 속성을 이후 코드에서 바로 쓸 수 있습니다.
>
> 이 실수는 W05에서 `pygame.sprite.Sprite` 를 상속할 때 특히 자주 납니다.
> `super().__init__()` 을 빠뜨리면 스프라이트 그룹에 넣는 순간 에러가 납니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 상속 | `class 자식(부모):` — 공통 기능을 물려받음 |
| 관계 확인 | **"A는 B다"(is-a)** 면 상속 |
| `super().__init__()` | 부모 초기화. 자식이 `__init__` 을 쓰면 **필수**, **맨 위에** |
| 오버라이딩 | 같은 이름으로 다시 정의 → 자식 것이 우선 |
| `super().메서드()` | 부모 기능을 쓰면서 확장 |
| 다형성 | 여러 종류를 한 리스트에 담고 같은 메서드로 처리 |
| `isinstance(x, 클래스)` | 부모 타입으로도 `True` (`type() ==` 보다 권장) |
| 클래스 변수 | `class` 아래 · 모두 공유 · 수정은 **`클래스명.변수`** |
| `@classmethod` | 첫 인자가 `cls` · 객체 없이 호출 가능 |
| `raise NotImplementedError` | 자식이 반드시 구현하게 강제 |

**오늘 반드시 기억할 두 가지**
> ① 자식이 `__init__` 을 정의하면 **`super().__init__()` 을 맨 위에서 호출**하세요.
> ② 클래스 변수는 `self.변수 += 1` 이 아니라 **`클래스명.변수 += 1`** 로 수정합니다.
