## ③ 개념 설명

### 클라이언트-서버 구조

```
┌──────────────┐                      ┌──────────────┐
│   클라이언트   │  ① 요청 (Request)    │    서버       │
│  (브라우저)   │ ───────────────────→ │  (Flask)     │
│              │                      │              │
│              │  ② 응답 (Response)   │  파이썬 함수  │
│              │ ←─────────────────── │  실행         │
└──────────────┘                      └──────────────┘
```

**핵심 — 서버는 "요청을 기다리는 프로그램"입니다**

```python
# 일반 스크립트
print("안녕")        # 실행 → 끝

# 서버
app.run()            # ★ 실행 → 계속 기다림 → 요청이 오면 응답
```

### 요청(Request)의 구성

```
GET /api/detect?conf=0.5&model=n HTTP/1.1
Host: 192.168.0.10:5000
User-Agent: Mozilla/5.0 ...
Accept: application/json

│    │                              │
│    │                              └─ 프로토콜 버전
│    └─ 경로 + 쿼리 문자열
└─ 메서드
```

| 요소 | 의미 | Flask 에서 |
|---|---|---|
| **메서드** | 무엇을 하려는가 | `methods=["GET", "POST"]` |
| **경로** | 어떤 자원인가 | `@app.route("/api/detect")` |
| **쿼리** | 조건·옵션 | `request.args` |
| **헤더** | 부가 정보 | `request.headers` |
| **본문** | 보내는 데이터 | `request.form` · `request.files` |

### HTTP 메서드

| 메서드 | 의미 | 예 | 우리 프로젝트 |
|---|---|---|---|
| **GET** | 조회 (데이터 안 바꿈) | 페이지 열기 | 이력 조회 |
| **POST** | 생성·전송 | 폼 제출 · **파일 업로드** | ★ 이미지 업로드 |
| PUT | 전체 수정 | | |
| PATCH | 부분 수정 | | |
| DELETE | 삭제 | | 이력 삭제 |

```
★ GET vs POST 의 결정적 차이

  GET   · 데이터가 ★ URL 에 노출
        · 브라우저 기록·북마크에 남음
        · 길이 제한 (약 2,000자)
        · ★ 파일 전송 불가
        · 새로고침해도 안전

  POST  · 데이터가 본문에
        · 길이 제한 사실상 없음
        · ★ 파일 전송 가능
        · 새로고침 시 재전송 경고
```

### 응답(Response)과 상태 코드

```
HTTP/1.1 200 OK
Content-Type: application/json

{"count": 3, "detections": [...]}
```

| 코드 | 의미 | 언제 쓰나 |
|---|---|---|
| **200 OK** | 성공 | 일반 조회 |
| **201 Created** | 생성 성공 | 이벤트 등록 |
| 204 No Content | 성공, 반환값 없음 | 삭제 |
| **302 Found** | 리다이렉트 | 폼 제출 후 이동 |
| **400 Bad Request** | ★ **클라이언트 잘못** | 파라미터 오류 |
| 401 Unauthorized | 인증 필요 | 로그인 |
| 403 Forbidden | 권한 없음 | |
| **404 Not Found** | 없는 경로·자원 | |
| 405 Method Not Allowed | GET 만 되는데 POST | |
| **413 Payload Too Large** | 파일이 너무 큼 | ★ 업로드 제한 |
| **500 Internal Server Error** | ★ **서버 잘못** | 예외 발생 |

> **★ 400 과 500 의 구분이 중요합니다.**
> ```
> 클라이언트가 잘못 보냄     →  400  "당신 요청이 이상합니다"
> 서버 코드에서 예외 발생     →  500  "저희 잘못입니다"
>
> 전부 500 으로 주면
> → 사용자가 "서버가 고장났나" 오해
> → 개발자도 원인을 못 찾음
> ```

### URL 의 구성

```
http://192.168.0.10:5000/api/events?date=2026-01-15&type=person#top
 │       │              │    │            │                      │
 │       │              │    │            │                      └─ 프래그먼트
 │       │              │    │            └─ 쿼리 문자열
 │       │              │    └─ 경로 (path)
 │       │              └─ ★ 포트
 │       └─ 호스트 (IP 또는 도메인)
 └─ 스킴 (프로토콜)
```

**★ 포트 — 가장 헷갈리는 개념**

```
한 컴퓨터에 여러 서버가 동시에 돌 수 있습니다
→ 어느 프로그램에 보낼지 구분하는 번호가 포트

  80    HTTP  (생략 가능)
  443   HTTPS (생략 가능)
  5000  ★ Flask 기본
  8000  Django 기본
  3306  MySQL
  22    SSH
```

```
http://192.168.0.10        →  포트 80 (생략됨)
http://192.168.0.10:5000   →  ★ 포트 5000
```

### `localhost` vs `0.0.0.0`

```python
app.run(host="127.0.0.1")    # 기본. ★ 내 PC 에서만 접속 가능
app.run(host="0.0.0.0")      # ★ 다른 기기에서도 접속 가능
```

```
127.0.0.1 = localhost = "나 자신"

  · 휴대폰에서 안 됨

0.0.0.0 = "모든 네트워크 인터페이스"
  · 같은 Wi-Fi 의 다른 기기에서 접속 가능
  · ★ Day 165 에서 휴대폰으로 접속할 때 필수
```

### 프레임워크란

**프레임워크가 없다면**

```python
import socket

s = socket.socket()
s.bind(("0.0.0.0", 5000))
s.listen()
while True:
    conn, addr = s.accept()
    data = conn.recv(4096).decode()
    # ★ HTTP 요청을 직접 파싱해야 함
    # 메서드? 경로? 헤더? 쿼리?
    # 그리고 응답도 직접 만들어야 함
    conn.send(b"HTTP/1.1 200 OK\r\nContent-Type: text/html\r\n\r\n<h1>Hi</h1>")
    conn.close()
```

**Flask 를 쓰면**

```python
from flask import Flask
app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>Hi</h1>"

app.run()
```

**프레임워크가 대신해 주는 것**

```
· HTTP 요청 파싱
· 라우팅 (경로 → 함수 연결)
· 응답 생성 (헤더 · 상태 코드)
· 쿼리·폼·파일 파싱
· 세션·쿠키
· 템플릿 렌더링
· 에러 처리
· 개발 서버 · 자동 재시작
```

### Flask vs Django

| | **Flask** | Django |
|---|---|---|
| 철학 | **마이크로** — 필요한 것만 | 풀스택 — 다 들어 있음 |
| 코드량 (Hello World) | **5줄** | 여러 파일 |
| 학습 곡선 | **완만** | 가파름 |
| ORM | 없음 (SQLAlchemy 선택) | 내장 |
| 관리자 페이지 | 없음 | **내장** |
| 인증 | 없음 (확장) | 내장 |
| 구조 강제 | 없음 (자유) | 강함 |
| **AI 모델 서빙** | ★ **적합** | 가능하지만 무거움 |
| 대규모 서비스 | 설계 필요 | **유리** |

**★ 우리가 Flask 를 고르는 이유**

```
① 5일 안에 배워야 함 (W32)
   → Django 는 ORM·마이그레이션·앱 구조만 5일

② ★ 모델 서빙이 목적
   → 우리에게 필요한 건 "요청 → 추론 → 응답"
   → 관리자 페이지·인증·ORM 이 필요 없음

③ 라즈베리파이에서도 돌아야 함
   → Flask 는 가벼움 (메모리 30MB vs Django 80MB)

④ detector.py 를 그대로 쓰기 쉬움
   → 전역 변수 하나면 끝 (Day 161)
```

### 첫 앱의 구조

```python
from flask import Flask          # ① 임포트

app = Flask(__name__)            # ② 앱 객체 생성

@app.route("/")                  # ③ 라우트 등록 (데코레이터)
def home():                      # ④ 뷰 함수
    return "안녕하세요"            # ⑤ 응답

if __name__ == "__main__":
    app.run(debug=True)          # ⑥ 서버 실행
```

**`__name__` 이 왜 필요한가**

```
Flask 가 이 값으로
  · 템플릿 폴더 (templates/)
  · 정적 파일 폴더 (static/)
를 어디서 찾을지 결정합니다

  app.py 를 직접 실행   → __name__ == "__main__"
  다른 모듈이 import   → __name__ == "app"

★ 그냥 __name__ 을 쓰면 됩니다
```

### Step 2. 라우트 여러 개

```python
"""app.py — 라우트 여러 개"""
from datetime import datetime

from flask import Flask

app = Flask(__name__)

# ── 가짜 데이터 (Day 164에서 SQLite로 교체) ──
EVENTS = [
    {"id": 1, "ts": "2026-01-15T09:12:04", "type": "person",
     "count": 1, "conf": 0.91},
    {"id": 2, "ts": "2026-01-15T09:48:31", "type": "person",
     "count": 2, "conf": 0.87},
    {"id": 3, "ts": "2026-01-15T14:02:19", "type": "box",
     "count": 1, "conf": 0.78},
    {"id": 4, "ts": "2026-01-15T18:30:55", "type": "person",
     "count": 1, "conf": 0.94},
]


@app.route("/")
def home():
    return """
    <h1>CCTV 검출 서버</h1>
    <ul>
      <li><a href="/status">서버 상태</a></li>
      <li><a href="/events">이벤트 목록</a></li>
      <li><a href="/api/health">헬스체크 (JSON)</a></li>
      <li><a href="/api/events">이벤트 API (JSON)</a></li>
    </ul>
    """


@app.route("/status")
def status():
    return f"""
    <h2>서버 상태</h2>
    <p>현재 시각: {datetime.now():%Y-%m-%d %H:%M:%S}</p>
    <p>등록된 이벤트: {len(EVENTS)}건</p>
    <p><a href="/">← 홈</a></p>
    """


@app.route("/events")
def events():
    rows = "".join(
        f"<tr><td>{e['id']}</td><td>{e['ts']}</td>"
        f"<td>{e['type']}</td><td>{e['count']}</td>"
        f"<td>{e['conf']:.2f}</td>"
        f"<td><a href='/events/{e['id']}'>보기</a></td></tr>"
        for e in EVENTS)
    return f"""
    <h2>이벤트 목록</h2>
    <table border="1" cellpadding="6">
      <tr><th>ID</th><th>시각</th><th>종류</th>
          <th>개수</th><th>신뢰도</th><th></th></tr>
      {rows}

```python
from flask import jsonify


@app.route("/api/health")
def api_health():
    """헬스체크 — 서버가 살아 있는가"""
    return jsonify({
        "status": "ok",
        "time": datetime.now().isoformat(timespec="seconds"),

    })


@app.route("/api/events")
def api_events():
    """이벤트 목록 API

    쿼리:
        type: person | box
        min_conf: 0.0~1.0
        limit: 최대 개수
    """
    e_type = request.args.get("type")
    min_conf = request.args.get("min_conf", type=float, default=0.0)
    limit = request.args.get("limit", type=int, default=100)

    # ── ★ 입력 검증 ──
    if e_type and e_type not in ("person", "box"):
        return jsonify({
            "error": f"알 수 없는 type: {e_type}",
            "allowed": ["person", "box"],
        }), 400                                    # ★ 클라이언트 잘못

    if not 0.0 <= min_conf <= 1.0:
        return jsonify({"error": "min_conf 는 0~1 이어야 합니다"}), 400

    if limit < 1 or limit > 1000:
        return jsonify({"error": "limit 은 1~1000 이어야 합니다"}), 400

    results = [e for e in EVENTS
               if (not e_type or e["type"] == e_type)
               and e["conf"] >= min_conf][:limit]

    return jsonify({
        "query": {"type": e_type, "min_conf": min_conf, "limit": limit},
        "total": len(results),
        "items": results,
    })


@app.route("/api/events/<int:event_id>")
def api_event_detail(event_id):
    event = next((e for e in EVENTS if e["id"] == event_id), None)
    if event is None:
        return jsonify({"error": "not found", "id": event_id}), 404
    return jsonify(event)


@app.route("/api/stats")
def api_stats():
    """클래스별 집계"""
    by_type = {}
    for e in EVENTS:
        by_type[e["type"]] = by_type.get(e["type"], 0) + 1
    confs = [e["conf"] for e in EVENTS]
    return jsonify({
        "total": len(EVENTS),
        "by_type": by_type,
        "conf": {
            "min": min(confs) if confs else None,
            "max": max(confs) if confs else None,
            "avg": round(sum(confs) / len(confs), 4) if confs else None,
        },
    })

### 라우트

```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

ALLOWED_CLASSES = ("person", "box")


@app.route("/api/events/<int:event_id>/detections")
def api_event_detections(event_id):
    """특정 이벤트의 검출 목록

    쿼리:
        min_conf: 최소 신뢰도 (0~1)
        class:    클래스 필터 (여러 개 가능)
    """
    # ── 경로 변수 ──
    event = next((e for e in EVENTS if e["id"] == event_id), None)
    if event is None:
        return jsonify({"error": "event not found", "id": event_id}), 404

    # ── 쿼리 파라미터 ──
    min_conf = request.args.get("min_conf", type=float, default=0.0)
    classes = request.args.getlist("class")          # ★ 여러 개

    # ── 검증 ──
    if not 0.0 <= min_conf <= 1.0:
        return jsonify({"error": "min_conf 는 0~1 이어야 합니다",
                        "got": min_conf}), 400

    unknown = [c for c in classes if c not in ALLOWED_CLASSES]
    if unknown:
        return jsonify({"error": "알 수 없는 class",
                        "unknown": unknown,
                        "allowed": list(ALLOWED_CLASSES)}), 400

    # ── 필터링 ──
    dets = event.get("detections", [])
    if classes:
        dets = [d for d in dets if d["class"] in classes]
    dets = [d for d in dets if d["conf"] >= min_conf]

    return jsonify({
        "event_id": event_id,
        "query": {"min_conf": min_conf, "classes": classes or "all"},
        "total": len(dets),
        "detections": dets,
    })
```

| **200** | 조회·처리 성공 | `GET /api/events` |
| **201** | ★ 새 자원 생성 | `POST /api/events` 신규 |
| 204 | 삭제 성공 (본문 없음) | `DELETE /api/events/<id>` |
| **400** | ★ 요청 형식·값 오류 | conf=5, 잘못된 확장자 |
| 401 | 인증 필요 | (인증 도입 시) |
| 404 | 자원 없음 | `GET /api/events/999` |
| 405 | 메서드 불일치 | GET 만 되는데 POST |
| **413** | ★ 파일이 너무 큼 | 20MB 업로드 |
| 415 | 지원 안 하는 미디어 타입 | |
| 422 | 형식은 맞는데 의미가 틀림 | (400 으로 통합 가능) |
| 429 | 요청이 너무 잦음 | (Rate limit 도입 시) |
| **500** | ★ 서버 내부 오류 | 예외 발생 |
| 503 | 일시적 이용 불가 | 모델 로딩 중 |

**★ 오류 응답 형식을 통일합니다**

```json
{
  "error": "invalid_parameter",       // ★ 기계가 읽는 코드
  "message": "conf 는 0~1 이어야 합니다",  // 사람이 읽는 설명
  "field": "conf",                     // 어느 필드
  "got": 5.0,                          // 받은 값
  "expected": "0.0 ~ 1.0"              // 기대값
}
```

```python
def error(code, message, status=400, **extra):
    """★ 오류 응답 헬퍼 — 형식 통일"""
    body = {"error": code, "message": message}
    body.update(extra)
    return jsonify(body), status


# 사용
return error("invalid_parameter", "conf 는 0~1 이어야 합니다",
             400, field="conf", got=conf, expected="0.0 ~ 1.0")

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 서버란 | ★ **요청을 기다리는 프로그램** |
| 요청 구성 | 메서드 · 경로 · 쿼리 · 헤더 · 본문 |
| GET | 조회 · URL 노출 · **파일 불가** |
| POST | 생성 · 본문 · **파일 가능** |
| 포트 | 한 PC 의 **여러 서버를 구분** |
| `127.0.0.1` | 내 PC 에서만 |
| **`0.0.0.0`** | ★ **다른 기기도 접속** |
| 프레임워크 | HTTP 파싱 · 라우팅 · 응답 생성을 대신 |
| Flask 선택 | **가볍고 · 배우기 쉽고 · 모델 서빙에 적합** |
| `@app.route` | 경로 → 함수 연결 (데코레이터) |
| 함수 이름 | ★ **endpoint 이므로 유일해야** |
| 동적 URL | `<int:id>` — ★ **타입 지정하면 자동 검증** |
| `path` 변환기 | 슬래시 포함 경로 |
| `request.args` | 쿼리 파라미터 |
| ★ `type=int` | 변환 실패 시 예외 대신 None |
| `getlist` | ★ **같은 키 여러 개** |
| `jsonify` | ★ **Content-Type 자동 설정** |
| 400 vs 500 | ★ **클라이언트 잘못 vs 서버 잘못** |
| 에러 핸들러 | API 는 JSON · 페이지는 HTML |
| `debug=True` | 자동 재시작 + 상세 오류 |
| ★ 위험 조합 | **`0.0.0.0` + `debug=True`** |
| 한글 | `<meta charset="utf-8">` |

**오늘 반드시 기억할 세 가지**
> ① **뷰 함수 이름은 endpoint 입니다.** 중복되면 서버가 아예 시작되지 않습니다.
> ② **`request.args.get("n", type=int)` 를 쓰세요.** `int()` 로 변환하면 500 오류가 납니다.
> ③ **`0.0.0.0` + `debug=True` 는 절대 금지입니다.** 같은 네트워크의 누구나 코드를 실행할 수 있습니다.
