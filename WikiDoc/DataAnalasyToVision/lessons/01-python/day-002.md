## ② 왜 필요한가

Day 001에서 만든 프로그램을 다시 봅시다.

```python
print("안녕하세요, 파이썬!")
```

이 프로그램은 몇 번을 실행해도 똑같은 말만 합니다. 사람 이름을 넣어 인사하고 싶다면 어떻게 할까요?
이름이 바뀔 때마다 코드를 고칠 수는 없습니다.

**변수는 "값을 담아 두는 이름표"** 입니다. 값이 바뀌어도 코드는 그대로 둘 수 있습니다.

```python
name = "홍길동"          # 이름표를 붙여 두면
print(name + "님 환영합니다")   # 코드는 이름표만 쓰면 됩니다
```

그리고 값에는 **종류**가 있습니다. 숫자 `10` 과 글자 `"10"` 은 겉보기엔 같지만 컴퓨터에겐 완전히 다릅니다.

```python
10 + 10       # 20   ← 숫자끼리는 더하기
"10" + "10"   # "1010"  ← 글자끼리는 이어붙이기
```

이 차이를 모르면 **오늘 배울 내용 중 가장 자주 나는 에러**를 만나게 됩니다.
`input()` 으로 나이를 입력받아 1을 더하려는데 계속 실패하는 이유가 바로 이것입니다.

## ③ 개념 설명

### 변수 — 값을 담는 상자

```python
age = 20
```

이 한 줄을 읽는 방법은 **"age 라는 이름의 상자에 20을 넣는다"** 입니다.
`=` 는 "같다"가 아니라 **"넣는다(대입한다)"** 라는 뜻입니다. 수학의 등호와 다릅니다.

```
   age  ┌──────┐
  ─────>│  20  │
        └──────┘
```

값은 언제든 바꿀 수 있습니다. 새 값을 넣으면 이전 값은 사라집니다.

```python
age = 20
age = 21     # 이제 age는 21. 20은 사라짐
```

### 변수 이름 규칙

| 규칙 | 예 |
|---|---|
| 영문자·숫자·밑줄(`_`)만 사용 | `user_name` ✅ |
| 숫자로 시작할 수 없음 | `2nd_player` ❌ → `player2` ✅ |
| 공백 불가 | `user name` ❌ → `user_name` ✅ |
| 대소문자 구분 | `Age` 와 `age` 는 서로 다른 변수 |
| 예약어 사용 불가 | `print`, `if`, `for`, `class` 등 ❌ |

> **관례** — 파이썬에서는 소문자와 밑줄로 씁니다(`snake_case`). `userName` 보다 `user_name` 을 씁니다.
> **좋은 이름** — `a`, `b`, `tmp` 대신 `score`, `player_name`, `total_price` 처럼 뜻이 보이는 이름을 쓰세요. 한 달 뒤의 내가 고마워합니다.

### 네 가지 기본 자료형

| 자료형 | 이름 | 예 | 설명 |
|---|---|---|---|
| `int` | 정수 | `10`, `-3`, `0` | 소수점이 없는 숫자 |
| `float` | 실수 | `3.14`, `-0.5`, `2.0` | 소수점이 있는 숫자 |
| `str` | 문자열 | `"안녕"`, `'10'` | 따옴표로 감싼 글자. 따옴표가 있으면 무조건 문자열 |
| `bool` | 불리언 | `True`, `False` | 참/거짓. 첫 글자는 반드시 대문자 |

값의 자료형은 `type()` 으로 확인합니다.

```python
print(type(10))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("10"))    # <class 'str'>
print(type(True))    # <class 'bool'>
```

### 형변환 — 자료형 바꾸기

| 함수 | 하는 일 | 예 |
|---|---|---|
| `int(x)` | 정수로 | `int("25")` → `25` |
| `float(x)` | 실수로 | `float("3.5")` → `3.5` |
| `str(x)` | 문자열로 | `str(25)` → `"25"` |
| `bool(x)` | 불리언으로 | `bool(0)` → `False` |

> **주의** — `int("3.5")` 는 에러입니다. 문자열 `"3.5"` 는 정수 모양이 아니기 때문입니다.
> `int(float("3.5"))` 처럼 두 단계로 바꾸거나, `int(3.5)` 처럼 숫자에서 변환해야 합니다. (소수점 이하는 버려져 `3` 이 됩니다)

### input() — 사용자에게 물어보기

```python
name = input("이름을 입력하세요: ")
```

`input()` 은 사용자가 키보드로 입력한 값을 받아 옵니다. 그런데 **아주 중요한 규칙**이 하나 있습니다.

> ⚠️ **`input()` 의 결과는 언제나 문자열(`str`) 입니다.**
> 사용자가 숫자 `25` 를 입력해도 파이썬은 문자열 `"25"` 로 받습니다.

그래서 계산에 쓰려면 반드시 `int()` 나 `float()` 로 바꿔야 합니다.

### f-string — 문자열 안에 값 끼워 넣기

문자열과 변수를 합칠 때, `+` 로 이어붙이면 형변환이 번거롭습니다.

```python
age = 25
print("나이: " + str(age) + "살")     # 매번 str() 을 써야 함
```

**f-string** 을 쓰면 훨씬 간단합니다. 따옴표 앞에 `f` 를 붙이고, 값을 넣을 자리에 `{변수명}` 을 씁니다.

```python
age = 25
print(f"나이: {age}살")               # 훨씬 읽기 쉬움
```

중괄호 안에는 계산식도 넣을 수 있습니다.

```python
print(f"내년에는 {age + 1}살입니다")
```

소수점 자릿수도 지정할 수 있습니다. `:.2f` 는 "소수점 아래 2자리까지" 라는 뜻입니다.

```python
pi = 3.14159
print(f"원주율은 약 {pi:.2f} 입니다")   # 원주율은 약 3.14 입니다
```

## ④ 단계별 실습

### Step 1. 변수 만들고 확인하기

`variables.py` 파일을 만들어 아래를 입력하고 실행합니다.

```python
# 변수에 값을 담습니다
name = "홍길동"
age = 25
height = 175.5
is_student = True

# 값과 자료형을 함께 출력합니다
print(name, type(name))
print(age, type(age))
print(height, type(height))
print(is_student, type(is_student))
```

실행 결과:

```
홍길동 <class 'str'>
25 <class 'int'>
175.5 <class 'float'>
True <class 'bool'>
```

### Step 2. 형변환 실험하기

```python
# 문자열 "10" 과 숫자 10 은 다릅니다
a = "10"
b = 10

print(a + a)          # 문자열 이어붙이기
print(b + b)          # 숫자 더하기
print(int(a) + b)     # 문자열을 숫자로 바꾼 뒤 더하기
print(a + str(b))     # 숫자를 문자열로 바꾼 뒤 이어붙이기

# 실수를 정수로 바꾸면 소수점 이하는 버려집니다
print(int(3.9))
print(float(3))
```

실행 결과:

```
1010
20
20
1010
3
3.0
```

> `int(3.9)` 가 `4` 가 아니라 `3` 인 점에 주의하세요. 반올림이 아니라 **버림**입니다.
> 반올림이 필요하면 `round(3.9)` 를 씁니다.

### Step 3. 입력받아 계산하기

```python
# input() 으로 받은 값은 항상 문자열이므로 int() 로 바꿔 줍니다
age = int(input("나이를 입력하세요: "))

# 계산해서 f-string 으로 출력합니다
print(f"내년이면 {age + 1}살이 되시는군요.")
print(f"10년 뒤에는 {age + 10}살입니다.")
```

실행 결과 (`25` 를 입력한 경우):

```
나이를 입력하세요: 25
내년이면 26살이 되시는군요.
10년 뒤에는 35살입니다.
```

### Step 4. 단위 변환기 만들기

```python
# 센티미터를 인치로 바꾸는 프로그램
# 1인치 = 2.54cm

cm = float(input("길이를 cm 단위로 입력하세요: "))
inch = cm / 2.54

print(f"{cm}cm 는 {inch:.2f}인치 입니다.")
```

실행 결과:

```
길이를 cm 단위로 입력하세요: 175
175.0cm 는 68.90인치 입니다.
```

> 키처럼 소수점이 있을 수 있는 값은 `int()` 가 아니라 `float()` 로 받습니다.
> `int(input())` 에 `175.5` 를 입력하면 에러가 납니다.

### Step 5. BMI 계산기 (오늘의 종합 예제)

```python
# BMI(체질량지수) = 몸무게(kg) / 키(m)의 제곱

print("=== BMI 계산기 ===")

name = input("이름: ")
weight = float(input("몸무게(kg): "))
height_cm = float(input("키(cm): "))

# cm 를 m 로 바꿉니다
height_m = height_cm / 100

# ** 는 거듭제곱 연산자입니다 (height_m ** 2 = 키의 제곱)
bmi = weight / (height_m ** 2)

print()
print(f"{name}님의 BMI는 {bmi:.1f} 입니다.")
print(f"(키 {height_cm}cm, 몸무게 {weight}kg 기준)")
```

실행 결과:

```
=== BMI 계산기 ===
이름: 홍길동
몸무게(kg): 70
키(cm): 175

홍길동님의 BMI는 22.9 입니다.
(키 175.0cm, 몸무게 70.0kg 기준)
```

> 아무것도 없는 `print()` 는 빈 줄 하나를 출력합니다. 결과를 보기 좋게 나눌 때 씁니다.
> BMI 값에 따라 "정상 / 과체중" 을 판정하는 기능은 [Day 004 조건문](day-004.md)에서 붙입니다.

## ⑤ 자주 하는 실수

### `TypeError: can only concatenate str (not "int") to str`

```python
age = 25
print("나이: " + age)
```

```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    print("나이: " + age)
TypeError: can only concatenate str (not "int") to str
```

**원인** — 문자열과 숫자는 `+` 로 합칠 수 없습니다. "글자에 글자만 이어붙일 수 있다"는 뜻입니다.
**해결** — `str(age)` 로 바꾸거나, 더 간단하게 f-string 을 씁니다.

```python
print("나이: " + str(age))    # 방법 1
print(f"나이: {age}")          # 방법 2 (권장)
```

### `TypeError: unsupported operand type(s) for +: 'int' and 'str'`

```python
age = input("나이: ")   # int() 를 빠뜨렸습니다
print(age + 1)
```

```
TypeError: unsupported operand type(s) for +: 'str' and 'int'
```

**원인** — `input()` 의 결과는 문자열입니다. 문자열에 숫자를 더할 수 없습니다.
**해결** — 입력받는 순간 형변환합니다.

```python
age = int(input("나이: "))
```

### `ValueError: invalid literal for int() with base 10: '3.5'`

```python
height = int(input("키: "))   # 사용자가 175.5 를 입력
```

```
ValueError: invalid literal for int() with base 10: '175.5'
```

**원인** — `int()` 는 소수점이 들어간 문자열을 처리하지 못합니다.
**해결** — 소수가 들어올 수 있는 값은 `float()` 로 받습니다.

### `NameError: name 'Age' is not defined`

```python
age = 25
print(Age)
```

```
NameError: name 'Age' is not defined
```

**원인** — 파이썬은 대소문자를 구분합니다. `age` 와 `Age` 는 다른 변수입니다.
**해결** — 철자와 대소문자를 정확히 맞춥니다. 변수를 만들기 전에 쓴 경우에도 같은 에러가 납니다.

### `SyntaxError: invalid syntax` — 예약어를 변수로 쓴 경우

```python
class = "3학년 2반"
```

```
SyntaxError: invalid syntax
```

**원인** — `class` 는 파이썬이 이미 쓰고 있는 예약어입니다.
**해결** — `class_name`, `classroom` 처럼 다른 이름을 씁니다. VS Code에서 예약어는 색이 다르게 표시되니 참고하세요.

## ⑥ 확인 문제

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
a = "5"
b = 3
print(a * b)
```

<details>
<summary>답 보기</summary>

```
555
```

문자열에 숫자를 곱하면 **그 횟수만큼 반복**됩니다. `"5" * 3` 은 `"555"` 입니다.
숫자 계산인 `15` 를 원했다면 `int(a) * b` 로 써야 합니다.
</details>

**2.** 사용자에게 두 과목 점수를 입력받아 평균을 소수점 첫째 자리까지 출력하는 프로그램을 작성하세요.

<details>
<summary>답 보기</summary>

```python
korean = int(input("국어 점수: "))
english = int(input("영어 점수: "))

average = (korean + english) / 2

print(f"평균은 {average:.1f}점 입니다.")
```

실행 결과:

```
국어 점수: 85
영어 점수: 90
평균은 87.5점 입니다.
```

**포인트 3가지**
- `input()` 결과를 `int()` 로 감싸야 계산할 수 있습니다.
- 나눗셈 `/` 의 결과는 나누어떨어져도 항상 `float` 입니다. (`4 / 2` → `2.0`)
- `:.1f` 로 소수점 자리를 지정합니다.
</details>

**3.** `int(input())` 대신 `float(input())` 을 써야 하는 경우는 언제인가요? 예를 들어 설명하세요.

<details>
<summary>답 보기</summary>

**소수점이 들어올 수 있는 값**을 받을 때입니다.

- 키(175.5cm), 몸무게(68.3kg), 온도(36.5도), 가격(1500.50원), 평점(4.7)

이런 값에 `int()` 를 쓰면 사용자가 `175.5` 를 입력하는 순간 `ValueError` 로 프로그램이 죽습니다.
반대로 나이·개수·인원수처럼 소수가 나올 수 없는 값은 `int()` 가 적절합니다.

> 판단 기준 — "이 값에 0.5가 들어갈 수 있는가?" 를 스스로 물어보세요.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 변수 | `이름 = 값` · `=` 는 "넣는다"는 뜻 |
| 자료형 | `int` 정수 · `float` 실수 · `str` 문자열 · `bool` 참/거짓 |
| 확인 | `type(값)` |
| 형변환 | `int()` `float()` `str()` `bool()` |
| 입력 | `input()` → **결과는 항상 문자열** |
| 출력 서식 | `f"{변수}"` · 소수점은 `f"{값:.2f}"` |

**오늘 반드시 기억할 한 가지**
> `input()` 으로 받은 값을 계산에 쓰려면 **반드시 `int()` 또는 `float()` 로 바꿔야 합니다.**

**과제** — 물건 가격과 낸 돈을 입력받아 거스름돈을 출력하는 프로그램(`change.py`)을 만드세요.
