### ndarray 만들기

```python
import numpy as np

a = np.array([1, 2, 3, 4, 5])                # 리스트에서
b = np.array([[1, 2, 3], [4, 5, 6]])          # 2차원

np.zeros(5)                # [0. 0. 0. 0. 0.]
np.zeros((2, 3))           # 2행 3열 0으로 채움
np.ones((2, 3))            # 1로 채움
np.full((2, 3), 7)         # 7로 채움
np.eye(3)                  # 3×3 단위행렬
np.empty((2, 2))           # 초기화 안 함 (쓰레기값, 빠름)

np.arange(5)               # [0 1 2 3 4]        — range 와 같음
np.arange(1, 10, 2)        # [1 3 5 7 9]
np.linspace(0, 1, 5)       # [0. 0.25 0.5 0.75 1.]  — 구간을 n등분
```

> **`arange` vs `linspace`**
> - `arange(시작, 끝, **간격**)` — 간격을 지정. 끝은 포함 안 됨
> - `linspace(시작, 끝, **개수**)` — 개수를 지정. **끝을 포함**
>
> 그래프의 x축을 만들 때는 `linspace` 가 편합니다.

### 배열의 속성

```python
arr = np.array([[1, 2, 3], [4, 5, 6]])

arr.shape       # (2, 3)      모양 (행, 열)
arr.ndim        # 2           차원 수
arr.size        # 6           전체 요소 개수
arr.dtype       # int64       요소의 자료형
arr.itemsize    # 8           요소 하나의 바이트
arr.nbytes      # 48          전체 바이트
```

**`shape` 이 가장 중요합니다.** 앞으로 에러의 절반은 shape 불일치입니다.

```
1차원  (5,)          [1 2 3 4 5]
2차원  (2, 3)        [[1 2 3]
                      [4 5 6]]
3차원  (2, 3, 4)     이미지 (높이, 너비, 채널)
```

### dtype — 자료형

| dtype | 설명 | 쓰는 곳 |
|---|---|---|
| `int8` / `int32` / `int64` | 정수 | 개수, 인덱스 |
| `float32` / `float64` | 실수 | 대부분의 계산 |
| `bool` | 참/거짓 | 마스킹 ([Day 044](day-044.md)) |
| `uint8` | 0~255 정수 | **이미지 픽셀** ([Day 045](day-045.md)) |

```python
np.array([1, 2, 3])                      # int64
np.array([1.0, 2, 3])                    # float64  — 하나만 실수여도 전부 실수
np.array([1, 2, 3], dtype=np.float32)    # 명시적 지정
arr.astype(np.int32)                      # 변환
```

> ⚠️ **ndarray 는 하나의 dtype 만 가집니다.** 리스트와 결정적으로 다른 점입니다.
> ```python
> np.array([1, "a", 3.0])       # 전부 문자열로 통일됨
> # array(['1', 'a', '3.0'], dtype='<U32')
> ```

### 리스트 vs ndarray

| | 리스트 | ndarray |
|---|---|---|
| 자료형 | 섞어도 됨 | **하나만** |
| 크기 변경 | 자유 (`append`) | 고정 (변경 시 새로 만듦) |
| 요소별 연산 | 반복문 필요 | **자동** |
| `a + b` | 이어붙이기 | **요소별 덧셈** |
| `a * 3` | 3번 반복 | **각 요소에 3 곱하기** |
| 속도 | 느림 | **빠름** (C로 구현) |
| 메모리 | 많음 | 적음 |

```python
lst = [1, 2, 3]
arr = np.array([1, 2, 3])

lst + lst          # [1, 2, 3, 1, 2, 3]     이어붙이기
arr + arr          # array([2, 4, 6])       요소별 덧셈

lst * 3            # [1,2,3,1,2,3,1,2,3]    반복
arr * 3            # array([3, 6, 9])       각 요소에 곱하기
```

> **이 차이를 헷갈리는 것이 numpy 입문의 첫 관문입니다.**
> `+` 와 `*` 의 동작이 완전히 다릅니다.

### 벡터화 — numpy 가 빠른 이유

```python
# 파이썬 반복문 — 요소마다 파이썬 인터프리터가 개입
result = []
for x in data:
    result.append(x * 2)

# 벡터화 — C 로 구현된 루프가 한 번에 처리
result = data * 2
```

| 이유 | 설명 |
|---|---|
| **C 구현** | 반복이 파이썬이 아니라 C 에서 돔 |
| **연속 메모리** | 요소가 메모리에 붙어 있어 캐시 효율이 좋음 |
| **타입 고정** | 매번 자료형을 확인할 필요 없음 |
| **SIMD** | CPU가 여러 값을 동시에 계산 |

> **원칙 — numpy 배열에는 `for` 문을 쓰지 않습니다.**
> 반복문을 쓰고 싶어지면 "벡터화할 방법이 없나"를 먼저 생각하세요.

### Step 4. 속도 비교 — numpy 를 쓰는 이유

```python
import numpy as np
import time

SIZE = 3_000_000

py_list = list(range(SIZE))
np_array = np.arange(SIZE)


def measure(label, func):
    start = time.perf_counter()
    result = func()
    elapsed = time.perf_counter() - start
    return label, elapsed, result


print("=" * 62)
print(f"        데이터 {SIZE:,}개 처리 속도 비교")
print("=" * 62)

tests = [
    ("① 각 요소에 2 곱하기",
     lambda: [x * 2 for x in py_list],
     lambda: np_array * 2),

    ("② 전체 합계",
     lambda: sum(py_list),
     lambda: np_array.sum()),

    ("③ 각 요소 제곱",
     lambda: [x ** 2 for x in py_list],
     lambda: np_array ** 2),

    ("④ 최댓값",
     lambda: max(py_list),
     lambda: np_array.max()),
]

for label, py_func, np_func in tests:
    _, py_time, _ = measure("py", py_func)
    _, np_time, _ = measure("np", np_func)

    ratio = py_time / np_time if np_time > 0 else float("inf")

    print(f"\n{label}")
    print(f"  파이썬 리스트 : {py_time:>8.4f}초")
    print(f"  numpy 배열    : {np_time:>8.4f}초")
    print(f"  → numpy 가 약 {ratio:>5.0f}배 빠름")

print("\n" + "=" * 62)

# 메모리 비교
import sys
print(f"메모리 사용량 (1만 개 기준)")
small_list = list(range(10_000))
small_array = np.arange(10_000)
print(f"  리스트  : {sys.getsizeof(small_list) / 1024:>8.1f} KB (+ 각 int 객체)")
print(f"  ndarray : {small_array.nbytes / 1024:>8.1f} KB")
print("=" * 62)
```

### Step 5. 게임 데이터 분석 맛보기 (오늘의 종합 예제)

대단원 01에서 만든 `game.db` 의 데이터로 첫 분석을 해 봅니다.
(DB가 없으면 아래 코드가 샘플 데이터를 만듭니다)

```python
import sqlite3
from pathlib import Path

import numpy as np

DB_PATH = Path("game.db")


def load_scores():
    """게임 DB에서 점수를 읽어 ndarray 로 반환합니다.
    DB가 없으면 샘플 데이터를 만듭니다."""
    if DB_PATH.exists():
        conn = sqlite3.connect(DB_PATH)
        rows = conn.execute(
            "SELECT score, kills, shots, hits, play_seconds, stage FROM scores"
        ).fetchall()
        conn.close()

        if rows:
            print(f"game.db 에서 {len(rows)}건을 불러왔습니다.\n")
            return np.array(rows, dtype=np.float64)

    # 샘플 데이터 생성
    print("game.db 가 없어 샘플 데이터 200건을 만듭니다.\n")
    rng = np.random.default_rng(42)
    n = 200

    stage = rng.integers(1, 6, n)
    kills = (stage * 30 + rng.normal(0, 15, n)).clip(5, None)
    shots = (kills * rng.uniform(1.5, 4.0, n)).clip(10, None)
    hits = (kills * rng.uniform(1.0, 1.6, n)).clip(1, None)
    hits = np.minimum(hits, shots)
    score = (kills * 100 + stage * 500 + rng.normal(0, 800, n)).clip(0, None)
    play = (stage * 40 + rng.normal(0, 20, n)).clip(10, None)

    return np.column_stack([score, kills, shots, hits, play, stage])
```

### `arr + arr` 를 이어붙이기로 착각

```python
arr = np.array([1, 2, 3])          # int64
```

**원인** — `int64` 배열에 실수를 넣으면 잘립니다.

```python
arr = np.array([1, 2, 3], dtype=np.float64)
```

### 배열에 `append` 를 반복 사용

```python
arr = np.array([])
for i in range(10000):
    arr = np.append(arr, i)         # 매번 새 배열을 만듦 — 매우 느림
```

**원인** — ndarray 는 크기가 고정입니다. `append` 는 **전체를 복사해 새 배열**을 만듭니다.
**해결** — 리스트에 모았다가 마지막에 변환하거나, 크기를 미리 잡습니다.

```python
# 방법 1
result = [i for i in range(10000)]
arr = np.array(result)

# 방법 2 — 크기를 알 때
arr = np.zeros(10000)
for i in range(10000):
    arr[i] = i

# 방법 3 — 벡터화 (가장 좋음)
arr = np.arange(10000)
```

### numpy 배열에 `for` 문을 씀

```python
result = []
for x in arr:
    result.append(x * 2)
```

**해결** — `arr * 2`. **numpy 를 쓰면서 반복문을 쓰면 numpy 의 장점이 사라집니다.**

### `linspace` 와 `arange` 를 헷갈림

```python
np.arange(0, 1, 5)          # array([0])   — 간격이 5라 0 하나뿐
np.linspace(0, 1, 5)        # array([0., 0.25, 0.5, 0.75, 1.])
```

**해결** — 세 번째 인자가 `arange` 는 **간격**, `linspace` 는 **개수**입니다.

**개선의 핵심 3가지**

| 파이썬 | numpy | 설명 |
|---|---|---|

| `sum(result)` | `filtered.sum()` | numpy 집계 함수 |

```python
squared = np_data ** 2
total = squared[squared >= 1000].sum()
```

> ```python
> small = np.array([10, 50, 100])
> print(small ** 2)              # [ 100 2500 10000]
> print(small ** 2 >= 1000)      # [False  True  True]   ← 불리언 배열!
> print((small ** 2)[small ** 2 >= 1000])   # [ 2500 10000]
> ```
> **불리언 배열로 골라내는 것**이 numpy 필터링의 핵심입니다. [Day 044](day-044.md)에서 자세히 배웁니다.
