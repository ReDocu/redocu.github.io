## ③ 개념 설명

### 클래스와 객체 — 붕어빵 틀과 붕어빵

| 용어 | 뜻 | 비유 |
|---|---|---|
| **클래스(class)** | 설계도 | 붕어빵 **틀** |
| **객체(object) / 인스턴스(instance)** | 설계도로 만든 실물 | 구워 낸 **붕어빵** |
| **속성(attribute)** | 객체가 가진 데이터 | 팥 / 슈크림 |
| **메서드(method)** | 객체가 하는 동작 | 먹기 / 데우기 |

```
   [Player 클래스]              설계도 하나
         │
    ┌────┼────┐
    ▼    ▼    ▼
  홍길동 김철수 이영희           객체 여러 개 (각자 다른 값)
```

### 가장 간단한 클래스

```python
class Player:
    pass          # 아직 아무 내용 없음


p1 = Player()     # 객체 생성 (괄호를 붙임)
p2 = Player()

print(type(p1))   # <class '__main__.Player'>
print(p1 is p2)   # False — 서로 다른 객체
```

> **클래스 이름은 대문자로 시작**합니다(`PascalCase`). `Player`, `EnemyShip`, `GameManager`.
> 변수·함수는 소문자(`snake_case`)이므로, 이름만 보고도 클래스인지 알 수 있습니다.

### `__init__` — 객체를 만들 때 실행되는 함수

```python
class Player:
    def __init__(self, name, hp=100):
        self.name = name          # 속성 설정
        self.hp = hp
        self.max_hp = hp


p = Player("홍길동", 120)

print(p.name)      # 홍길동
print(p.hp)        # 120
print(p.max_hp)    # 120
```

**`__init__` 은 생성자(constructor)** 라고 부릅니다.
`Player("홍길동", 120)` 이라고 쓰면 파이썬이 자동으로 `__init__` 을 호출합니다.

```
Player("홍길동", 120)
    ↓
① 빈 객체를 만든다
② __init__(빈_객체, "홍길동", 120) 을 호출한다
③ self.name = "홍길동", self.hp = 120 이 설정된다
④ 완성된 객체를 돌려준다
```

> **`__` (밑줄 두 개)로 시작하고 끝나는 이름**은 파이썬이 특별하게 취급하는 이름입니다.
> **매직 메서드** 또는 **던더(dunder, double underscore) 메서드**라고 부릅니다. [Day 018](day-018.md)에서 더 배웁니다.

### `self` 의 정체

`self` 는 **지금 이 메서드를 호출한 객체 자신**을 가리킵니다.

```python
class Player:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"저는 {self.name} 입니다")


p1 = Player("홍길동")
p2 = Player("김철수")

p1.say_hello()      # 저는 홍길동 입니다
p2.say_hello()      # 저는 김철수 입니다
```

`p1.say_hello()` 를 호출하면 파이썬이 내부적으로 이렇게 실행합니다.

```
p1.say_hello()
    ↓ 파이썬이 자동 변환
Player.say_hello(p1)      ← p1 이 self 로 들어감
```

**그래서 정의할 때는 `self` 를 쓰고, 호출할 때는 안 씁니다.**

```python
def say_hello(self):        # 정의: self 있음
    ...

p1.say_hello()              # 호출: self 없음 (자동으로 들어감)
```

> **`self` 라는 이름은 규칙이 아니라 관례**입니다. `me` 나 `this` 로 써도 동작하지만, 모든 파이썬 코드가 `self` 를 쓰므로 반드시 따르세요.

### 인스턴스 변수 — 객체마다 다른 값

`self.이름 = 값` 으로 만든 것을 **인스턴스 변수**(속성)라고 합니다. **객체마다 따로 존재합니다.**

```python
p1 = Player("홍길동")
p2 = Player("김철수")

p1.hp = 50           # p1 만 바뀜

print(p1.hp)         # 50
print(p2.hp)         # 100
```

> 객체 밖에서도 속성을 새로 추가할 수 있습니다. 편리하지만 오타를 막지 못하므로, **`__init__` 에서 모든 속성을 정의하는 것**이 좋은 습관입니다.

### 메서드 — 객체가 하는 일

```python
class Player:
    def __init__(self, name, hp=100):
        self.name = name
        self.hp = hp
        self.max_hp = hp

    def take_damage(self, amount):
        """피해를 입습니다."""
        self.hp -= amount
        if self.hp < 0:
            self.hp = 0
        print(f"{self.name}이(가) {amount}의 피해를 입었다. (HP {self.hp})")

    def heal(self, amount):
        """회복합니다."""
        before = self.hp
        self.hp += amount
        if self.hp > self.max_hp:
            self.hp = self.max_hp
        print(f"{self.name} 회복! HP {before} → {self.hp}")

    def is_alive(self):
        """살아 있는지 반환합니다."""
        return self.hp > 0


p = Player("홍길동", 120)
p.take_damage(50)
p.heal(30)
print(p.is_alive())
```

실행 결과:

```
홍길동이(가) 50의 피해를 입었다. (HP 70)
홍길동 회복! HP 70 → 100
True
```

> **딕셔너리 방식과 비교해 보세요.**
> ```python
> # 딕셔너리: 함수에 매번 넘겨야 함
> player = heal(player, 30)
>
> # 클래스: 객체가 자기 일을 함
> player.heal(30)
> ```
> `heal` 이 `self.hp` 와 `self.max_hp` 를 이미 알고 있으므로 인자가 하나로 줄었습니다.

### 함수 vs 메서드

| | 함수 (function) | 메서드 (method) |
|---|---|---|
| 정의 위치 | 파일 아무 데나 | 클래스 안 |
| 호출 | `heal(player, 30)` | `player.heal(30)` |
| 첫 인자 | 직접 넘김 | `self` 로 자동 전달 |

`.strip()`, `.append()`, `.get()` — 지금까지 써 온 모든 "점 찍고 부르는 것"이 사실 메서드였습니다.
문자열도 리스트도 전부 클래스로 만들어져 있습니다.

```python
print(type("hello"))     # <class 'str'>
print(type([1, 2]))      # <class 'list'>
print(type({}))          # <class 'dict'>
```

### Step 1. 첫 클래스 만들기

`classes.py` 를 만들어 실행합니다.

```python
class Student:
    """학생 한 명을 나타냅니다."""

    def __init__(self, name, korean, english, math):
        self.name = name
        self.korean = korean
        self.english = english
        self.math = math

    def get_total(self):
        """총점을 반환합니다."""
        return self.korean + self.english + self.math

    def get_average(self):
        """평균을 반환합니다."""
        return self.get_total() / 3          # 다른 메서드 호출도 self 로

    def get_grade(self):
        """학점을 반환합니다."""
        avg = self.get_average()
        if avg >= 90:
            return "A"
        elif avg >= 80:
            return "B"
        elif avg >= 70:
            return "C"
        elif avg >= 60:
            return "D"
        return "F"

    def show(self):
        """성적을 출력합니다."""
        print(f"{self.name:<8} 국{self.korean:>4} 영{self.english:>4} 수{self.math:>4}"
              f" | 총점 {self.get_total():>3} 평균 {self.get_average():>5.1f} {self.get_grade()}학점")


# ── 객체 만들기 ──
s1 = Student("홍길동", 85, 90, 78)
s2 = Student("김철수", 92, 88, 95)
s3 = Student("이영희", 70, 75, 82)

print("=" * 60)
s1.show()
s2.show()
s3.show()
print("=" * 60)

# 리스트에 담아 한꺼번에 다루기
students = [s1, s2, s3]

top = max(students, key=lambda s: s.get_total())
print(f"1등: {top.name} ({top.get_total()}점)")

class_avg = sum(s.get_average() for s in students) / len(students)
print(f"학급 평균: {class_avg:.1f}점")
```

### Step 2. 은행 계좌 클래스

```python
class BankAccount:
    """은행 계좌를 나타냅니다."""

    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        self.history = []                    # 거래 내역 (리스트)

    def deposit(self, amount):
        """입금합니다. 성공하면 True."""
        if amount <= 0:
            print("→ 0원보다 큰 금액을 입금해 주세요.")
            return False

        self.balance += amount
        self.history.append(("입금", amount, self.balance))
        print(f"→ {amount:,}원 입금. 잔액 {self.balance:,}원")
        return True

    def withdraw(self, amount):
        """출금합니다. 성공하면 True."""
        if amount <= 0:
            print("→ 0원보다 큰 금액을 출금해 주세요.")
            return False

        if amount > self.balance:
            print(f"→ 잔액이 부족합니다. (현재 {self.balance:,}원)")
            return False

        self.balance -= amount
        self.history.append(("출금", amount, self.balance))
        print(f"→ {amount:,}원 출금. 잔액 {self.balance:,}원")
        return True

    def transfer(self, target, amount):
        """다른 계좌로 이체합니다."""
        print(f"[{self.owner} → {target.owner}] {amount:,}원 이체 시도")

        if self.withdraw(amount):
            target.deposit(amount)
            print("→ 이체 완료")
            return True

        print("→ 이체 실패")
        return False

    def show_history(self):
        """거래 내역을 출력합니다."""
        print(f"\n[{self.owner}님의 거래 내역]")

        if not self.history:
            print("  (내역 없음)")
            return

        for i, (kind, amount, balance) in enumerate(self.history, start=1):
            sign = "+" if kind == "입금" else "-"
            print(f"  {i}. {kind} {sign}{amount:>8,}원  → 잔액 {balance:>9,}원")


# ── 실행 ──
account1 = BankAccount("홍길동", 100_000)
account2 = BankAccount("김철수")

account1.deposit(50_000)
account1.withdraw(30_000)
account1.withdraw(500_000)

print()
account1.transfer(account2, 70_000)

account1.show_history()
account2.show_history()
```

실행 결과:

```
→ 50,000원 입금. 잔액 150,000원
→ 30,000원 출금. 잔액 120,000원
→ 잔액이 부족합니다. (현재 120,000원)

[홍길동 → 김철수] 70,000원 이체 시도
→ 70,000원 출금. 잔액 50,000원
→ 70,000원 입금. 잔액 70,000원
→ 이체 완료

[홍길동님의 거래 내역]
  1. 입금 +  50,000원  → 잔액   150,000원
  2. 출금 -  30,000원  → 잔액   120,000원
  3. 출금 -  70,000원  → 잔액    50,000원

[김철수님의 거래 내역]
  1. 입금 +  70,000원  → 잔액    70,000원
```

> **눈여겨볼 점 3가지**
> - `transfer(self, target, amount)` — **다른 객체를 인자로 받습니다.** `target.deposit(amount)` 처럼 상대 객체의 메서드를 부를 수 있습니다.
> - `if self.withdraw(amount):` — 메서드가 `True`/`False` 를 반환하므로 그대로 조건문에 쓸 수 있습니다. 출금이 실패하면 입금도 안 됩니다.
> - `self.history` 가 리스트이므로, 객체마다 자기 내역을 따로 갖습니다.

### Step 3. 몬스터 클래스 (RPG 재작성)

Day 010의 RPG를 클래스로 다시 만듭니다.

```python
import random


class Character:
    """전투에 참여하는 캐릭터를 나타냅니다."""

    def __init__(self, name, hp, attack, defense):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
        self.defense = defense

    def is_alive(self):
        """살아 있으면 True."""
        return self.hp > 0

    def take_damage(self, amount):
        """피해를 입습니다."""
        self.hp -= amount
        if self.hp < 0:
            self.hp = 0

    def heal(self, amount):
        """회복합니다. 실제로 회복된 양을 반환합니다."""
        before = self.hp
        self.hp = min(self.hp + amount, self.max_hp)
        return self.hp - before

    def attack_target(self, target, critical_rate=0.15):
        """대상을 공격합니다."""
        base = max(self.attack - target.defense // 2, 1)
        damage = int(base * random.uniform(0.85, 1.15))

        is_crit = random.random() < critical_rate
        if is_crit:
            damage *= 2

        target.take_damage(damage)

        mark = "  치명타!" if is_crit else ""
        print(f"  {self.name}의 공격! {target.name}에게 {damage}의 피해{mark}")
        return damage

    def show_hp(self, width=15):
        """체력 바를 출력합니다."""
        filled = int(width * self.hp / self.max_hp)
        bar = "█" * filled + "░" * (width - filled)
        print(f"  {self.name:<10} [{bar}] {self.hp:>3}/{self.max_hp}")


# ── 전투 ──
player = Character("용사", 120, 18, 6)
enemy = Character("고블린", 90, 14, 4)

print("=" * 44)
print("             전투 시작!")
print("=" * 44)

turn = 1
while player.is_alive() and enemy.is_alive():
    print(f"\n--- {turn}턴 ---")

    player.attack_target(enemy)
    if not enemy.is_alive():
        break

    enemy.attack_target(player)

    print()
    player.show_hp()
    enemy.show_hp()

    turn += 1

print("\n" + "=" * 44)
if player.is_alive():
    print(f"  승리! {enemy.name}을(를) 물리쳤습니다. ({turn}턴)")
else:
    print(f"  패배… {player.name}이(가) 쓰러졌습니다.")
print("=" * 44)
```

> | 공격 | `calculate_damage(15, 4, ...)` | `player.attack_target(enemy)` |
> | 체력 갱신 | `enemy_hp -= dmg` (직접 조작) | `target.take_damage(dmg)` (객체가 처리) |
> | 몬스터 추가 | 변수를 또 만들어야 함 | `Character(...)` 한 줄 |
>
> **가장 큰 차이는 "누가 책임지는가"입니다.** 체력이 0 밑으로 안 내려가게 막는 일을 `Character` 가 스스로 합니다.
> 호출하는 쪽은 그 규칙을 몰라도 됩니다.

### Step 4. 여러 객체를 리스트로 관리하기 (오늘의 종합 예제)

```python
import random


class Monster:
    """몬스터를 나타냅니다."""

    def __init__(self, name, hp, attack, exp):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
        self.exp = exp

    def is_alive(self):
        return self.hp > 0

    def take_damage(self, amount):
        self.hp = max(self.hp - amount, 0)

    def get_status(self):
        """상태를 문자열로 반환합니다."""
        state = "생존" if self.is_alive() else "처치"
        return f"{self.name:<8} HP {self.hp:>3}/{self.max_hp:<3} 공격 {self.attack:>2} EXP {self.exp:>3} [{state}]"


class Party:
    """몬스터 무리를 관리합니다."""

    def __init__(self):
        self.monsters = []

    def add(self, monster):
        """몬스터를 추가합니다."""
        self.monsters.append(monster)

    def get_alive(self):
        """살아 있는 몬스터 목록을 반환합니다."""
        return [m for m in self.monsters if m.is_alive()]

    def attack_random(self, damage):
        """살아 있는 몬스터 중 하나를 무작위로 공격합니다."""
        alive = self.get_alive()

        if not alive:
            print("  공격할 대상이 없습니다.")
            return None

        target = random.choice(alive)
        target.take_damage(damage)
        print(f"  {target.name}에게 {damage}의 피해! (HP {target.hp}/{target.max_hp})")

        if not target.is_alive():
            print(f"  → {target.name} 처치! EXP +{target.exp}")
            return target.exp

        return 0

    def is_all_dead(self):
        """전멸했으면 True."""
        return len(self.get_alive()) == 0

    def get_total_exp(self):
        """처치한 몬스터의 총 경험치를 반환합니다."""
        return sum(m.exp for m in self.monsters if not m.is_alive())

    def show(self):
        """전체 상태를 출력합니다."""
        print("\n" + "─" * 52)
        for i, m in enumerate(self.monsters, start=1):
            print(f"  {i}. {m.get_status()}")
        print("─" * 52)
        print(f"  생존 {len(self.get_alive())}마리 / 전체 {len(self.monsters)}마리")


# ── 실행 ──
party = Party()
party.add(Monster("슬라임", 30, 5, 3))
party.add(Monster("고블린", 60, 12, 15))
party.add(Monster("오크", 100, 20, 40))
party.add(Monster("트롤", 140, 26, 80))

print("=" * 52)
print("                 몬스터 무리 등장!")
print("=" * 52)
party.show()

total_exp = 0
turn = 1

while not party.is_all_dead() and turn <= 15:
    print(f"\n--- {turn}턴 ---")
    damage = random.randint(20, 45)
    gained = party.attack_random(damage)

    if gained:
        total_exp += gained

    turn += 1

party.show()

print("\n" + "=" * 52)
if party.is_all_dead():
    print(f"  전멸! 획득 경험치 {total_exp}")
else:
    print(f"  시간 초과. 획득 경험치 {total_exp}")
print("=" * 52)
```

실행 결과 (일부):

```
====================================================
                 몬스터 무리 등장!
====================================================

────────────────────────────────────────────────────
  1. 슬라임      HP  30/30  공격  5 EXP   3 [생존]
  2. 고블린      HP  60/60  공격 12 EXP  15 [생존]
  3. 오크       HP 100/100 공격 20 EXP  40 [생존]
  4. 트롤       HP 140/140 공격 26 EXP  80 [생존]
────────────────────────────────────────────────────
  생존 4마리 / 전체 4마리

--- 1턴 ---
  오크에게 38의 피해! (HP 62/100)

--- 2턴 ---
  슬라임에게 27의 피해! (HP 3/30)

--- 3턴 ---
  슬라임에게 44의 피해! (HP 0/30)
  → 슬라임 처치! EXP +3
...
```

> **눈여겨볼 점 4가지**
> - **클래스 안에 클래스의 객체를 담았습니다.** `Party` 가 `Monster` 객체들의 리스트를 가집니다. 이런 관계를 **컴포지션(composition)** 이라고 하며 [Day 018](day-018.md)에서 자세히 배웁니다.
> - `[m for m in self.monsters if m.is_alive()]` — 객체 리스트에 컴프리헨션을 쓰면 조건 검색이 한 줄입니다.
> - `random.choice(alive)` — 객체 리스트에서도 무작위 선택이 그대로 됩니다.
> - **몬스터를 100마리로 늘려도 코드는 그대로입니다.** `party.add(...)` 를 반복하기만 하면 됩니다. 이것이 클래스의 힘입니다.

## ⑤ 자주 하는 실수

### `self` 를 빠뜨림 (정의할 때)

```python
class Player:
    def say_hello():          # self 없음
        print("안녕")

p = Player()
p.say_hello()
```

```
TypeError: Player.say_hello() takes 0 positional arguments but 1 was given
```

**원인** — `p.say_hello()` 는 내부적으로 `Player.say_hello(p)` 가 되어 인자 1개를 넘깁니다. 그런데 받을 자리가 없습니다.
**해결** — `def say_hello(self):`

> 이 에러 메시지("0개를 받는데 1개가 왔다")를 보면 **거의 항상 `self` 누락**입니다.

### 메서드 안에서 `self.` 를 빠뜨림

```python
class Player:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"저는 {name} 입니다")     # self. 없음
```

```
NameError: name 'name' is not defined
```

**원인** — `name` 은 지역변수가 아닙니다. 객체의 속성이므로 `self.name` 이라고 써야 합니다.
**해결** — `print(f"저는 {self.name} 입니다")`

### `__init__` 에서 `self.` 를 빠뜨림

```python
class Player:
    def __init__(self, name):
        name = name          # 지역변수에 대입할 뿐, 속성이 안 만들어짐

p = Player("홍길동")
print(p.name)
```

```
AttributeError: 'Player' object has no attribute 'name'
```

**해결** — `self.name = name`

### 객체를 만들 때 괄호를 빠뜨림

```python
p = Player          # 괄호 없음
print(p.name)
```

```
AttributeError: type object 'Player' has no attribute 'name'
```

**원인** — `Player` 는 클래스 자체, `Player()` 가 객체입니다.
**해결** — `p = Player("홍길동")`

> 에러 메시지에 **`type object`** 가 나오면 클래스를 객체로 착각한 것입니다.

### 클래스 이름과 객체 이름을 같게 씀

```python
class Player:
    ...

Player = Player("홍길동")     # 클래스를 덮어씀!
p2 = Player("김철수")          # TypeError
```

**해결** — 클래스는 `Player`, 객체는 `player` 처럼 대소문자로 구분합니다.

### 메서드 안에서 다른 메서드를 `self.` 없이 호출

```python
class Student:
    def get_total(self):
        return 100

    def get_average(self):
        return get_total() / 3        # self. 없음
```

```
NameError: name 'get_total' is not defined
```

**해결** — `return self.get_total() / 3`

### 모든 객체가 같은 리스트를 공유

```python
class Player:
    items = []                       # 클래스 변수 (공유됨!)

    def add_item(self, item):
        self.items.append(item)

p1 = Player()
p2 = Player()
p1.add_item("검")

print(p2.items)      # ['검']  ← p2 도 갖고 있다!
```

**원인** — `class` 바로 아래에 쓴 변수는 **모든 객체가 공유하는 클래스 변수**입니다.
**해결** — `__init__` 안에서 만듭니다.

```python
class Player:
    def __init__(self):
        self.items = []              # 객체마다 새 리스트
```

> Day 009의 "기본값에 리스트를 쓰지 마라" 와 같은 원리입니다.
> 클래스 변수의 올바른 사용법은 [Day 017](day-017.md)에서 다룹니다.

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
class Counter:
    def __init__(self):
        self.count = 0

    def increase(self, n=1):
        self.count += n
        return self.count


a = Counter()
b = Counter()

a.increase()
a.increase(5)
b.increase(10)

print(a.count, b.count)
```

<summary>답 보기</summary>

```
6 10
```

- `a` 와 `b` 는 서로 다른 객체이므로 `count` 도 각자 따로 갖습니다.
- `a` : 0 → 1 → 6
- `b` : 0 → 10

**핵심** — `__init__` 안에서 `self.` 로 만든 속성은 **객체마다 독립적**입니다.

**2.** `Rectangle`(직사각형) 클래스를 만드세요. 가로·세로를 받아 넓이·둘레를 계산하고, 정사각형인지 판별하며, 크기를 배로 늘리는 기능이 있어야 합니다.

<details>
<summary>답 보기</summary>

```python
class Rectangle:
    """직사각형을 나타냅니다."""

    def __init__(self, width, height):
        if width <= 0 or height <= 0:
            raise ValueError("가로와 세로는 0보다 커야 합니다")
        self.width = width
        self.height = height

    def get_area(self):
        """넓이를 반환합니다."""
        return self.width * self.height

    def get_perimeter(self):
        """둘레를 반환합니다."""
        return 2 * (self.width + self.height)

    def is_square(self):
        """정사각형이면 True."""
        return self.width == self.height

    def scale(self, factor):
        """크기를 factor 배로 늘립니다."""
        self.width *= factor
        self.height *= factor

    def show(self):
        """정보를 출력합니다."""
        shape = "정사각형" if self.is_square() else "직사각형"
        print(f"{shape} {self.width}x{self.height}"
              f" | 넓이 {self.get_area()} 둘레 {self.get_perimeter()}")


# ── 사용 ──
r1 = Rectangle(4, 6)
r2 = Rectangle(5, 5)

r1.show()
r2.show()

print("\n[r1 을 2배로]")
r1.scale(2)
r1.show()

# 잘못된 입력
try:
    r3 = Rectangle(-1, 5)
except ValueError as e:
    print(f"\n오류: {e}")
```

실행 결과:

```
직사각형 4x6 | 넓이 24 둘레 20
정사각형 5x5 | 넓이 25 둘레 20

[r1 을 2배로]
직사각형 8x12 | 넓이 96 둘레 40

오류: 가로와 세로는 0보다 커야 합니다
```

**포인트 3가지**
- `__init__` 에서 **`raise` 로 잘못된 값을 막습니다.** 객체가 만들어지는 순간부터 항상 유효한 상태를 보장합니다.
- `is_square()` 처럼 참/거짓을 반환하는 메서드는 `is_` 로 시작합니다.
- `scale()` 은 자기 속성을 바꾸고 아무것도 반환하지 않습니다. 반대로 `get_area()` 는 계산만 하고 상태를 바꾸지 않습니다. **"상태를 바꾸는 메서드"와 "값을 돌려주는 메서드"를 구분**하는 것이 좋은 설계입니다.
</details>

**3.** 아래 코드에서 두 플레이어가 아이템을 공유하는 버그가 있습니다. 원인과 해결책을 쓰세요.

```python
class Player:
    inventory = []

    def __init__(self, name):
        self.name = name

    def pick_up(self, item):
        self.inventory.append(item)
        print(f"{self.name}이(가) {item}을(를) 주웠다. → {self.inventory}")


p1 = Player("홍길동")
p2 = Player("김철수")

p1.pick_up("검")
p2.pick_up("방패")
```

<details>
<summary>답 보기</summary>

**실제 출력**

```
홍길동이(가) 검을(를) 주웠다. → ['검']
김철수이(가) 방패을(를) 주웠다. → ['검', '방패']
```

김철수가 홍길동의 검까지 갖고 있습니다.

**원인** — `inventory = []` 를 `class` 바로 아래에 썼습니다. 이건 **클래스 변수**로, **모든 객체가 하나를 공유**합니다.

```
        ┌──────────────────┐
Player  │ inventory = []   │   클래스에 딱 하나
        └──────────────────┘
              ▲       ▲
              │       │
            p1       p2        둘 다 같은 리스트를 봄
```

`self.inventory.append(...)` 는 새 리스트를 만드는 게 아니라 **공유된 그 리스트를 수정**하므로 둘 다 영향을 받습니다.

**해결 — `__init__` 안에서 만듭니다.**

```python
class Player:
    def __init__(self, name):
        self.name = name
        self.inventory = []          # 객체마다 새 리스트

    def pick_up(self, item):
        self.inventory.append(item)
        print(f"{self.name}이(가) {item}을(를) 주웠다. → {self.inventory}")


p1 = Player("홍길동")
p2 = Player("김철수")

p1.pick_up("검")
p2.pick_up("방패")
```

실행 결과:

```
홍길동이(가) 검을(를) 주웠다. → ['검']
김철수이(가) 방패을(를) 주웠다. → ['방패']
```

> **규칙** — 객체마다 달라야 하는 값은 **반드시 `__init__` 안에서 `self.` 로** 만드세요.
> 클래스 변수는 "모든 객체가 공유해야 하는 값"(예: 생성된 객체 수, 공통 설정)에만 씁니다. [Day 017](day-017.md)에서 다룹니다.
>
> 이 함정은 Day 009의 "기본값에 리스트 금지", Day 011의 "`b = a` 는 복사가 아님" 과 **같은 뿌리**입니다.
> **변경 가능한 값을 공유하면 문제가 생긴다** — 파이썬을 관통하는 원칙입니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 클래스 | 설계도. `class Player:` — **대문자로 시작** |
| 객체 | 실물. `p = Player("홍길동")` — **괄호 필수** |
| `__init__` | 객체를 만들 때 자동 실행. 속성을 여기서 전부 정의 |
| `self` | 이 메서드를 호출한 **객체 자신** |
| 정의 vs 호출 | 정의엔 `self` 있음 / 호출엔 없음 (자동 전달) |
| 속성 | `self.이름 = 값` — 객체마다 따로 |
| 메서드 | 클래스 안의 함수. 안에서 다른 메서드는 `self.메서드()` |
| 금지 | **`class` 바로 아래에 리스트를 만들지 말 것** |

**오늘 반드시 기억할 두 가지**
> ① `self` 는 "이 객체 자신"입니다. 속성과 메서드 앞에는 항상 `self.` 를 붙이세요.
> ② 객체마다 달라야 하는 값은 **반드시 `__init__` 안에서** 만드세요.
