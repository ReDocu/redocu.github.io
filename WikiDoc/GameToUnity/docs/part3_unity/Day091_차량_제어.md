### 3-2. 왜 옆 속도 감쇠가 핵심인가

**왜 필요한가** — 이것 하나가 "차 느낌"을 만든다.

```
   ★ 자동차 바퀴의 성질

   앞뒤로는 잘 구른다 (마찰 작음)
   좌우로는 잘 안 미끄러진다 (마찰 큼)
```

```
   속도 벡터를 로컬 좌표로 분해

        차 진행 방향 (forward)
              ↑
              │  ╱ 실제 속도
              │ ╱
              │╱
              ●───────▶ 옆 방향 (right)

   forward 성분:  그대로 유지
   right 성분:    감쇠시킨다   ★
```

```csharp
    Vector3 localVel = transform.InverseTransformDirection(rb.linearVelocity);

    // ★ 옆 속도를 줄인다
    localVel.x *= gripFactor;                  // 0.9 = 잘 잡힌다, 0.99 = 미끄럽다

    rb.linearVelocity = transform.TransformDirection(localVel);
```

```
   ★ gripFactor 하나로 주행감이 결정된다

   0.80  →  레일 위를 달리는 느낌 (미끄러지지 않음)
   0.90  →  일반 자동차  ★
   0.97  →  빙판, 드리프트
   1.00  →  우주선 (전혀 안 잡힌다)
```

```
   ⚠️ 프레임 독립성

   localVel.x *= 0.9;                          ← 프레임률에 따라 다르다

   localVel.x *= Mathf.Pow(grip, dt * 60f);    ← 보정
   또는 FixedUpdate에서만 실행 (고정 간격)  ★
```

### 3-4. 전진력

**왜 필요한가** — 가속의 기본.

```csharp
    private void ApplyDrive(float input, float dt)
    {
        // ★ 접지 상태에서만
        if (groundedWheels == 0) return;

        // 현재 전방 속도
        float forwardSpeed = Vector3.Dot(rb.linearVelocity, transform.forward);

        // ★ 속도에 따른 가속력 곡선
        float speedRatio = Mathf.Abs(forwardSpeed) / maxSpeed;
        float powerFactor = accelerationCurve.Evaluate(speedRatio);

        Vector3 force = transform.forward * input * enginePower * powerFactor;

        rb.AddForce(force, ForceMode.Acceleration);
    }
```

```
   ★ Vector3.Dot(속도, forward)

   속도의 "앞 방향 성분"
   → 양수면 전진 중, 음수면 후진 중
```

```
   ★ 가속 곡선 (AnimationCurve)

   가속력 ↑
      1.0 │████
          │    ████
          │        ████
      0.0 │            ████
          └────────────────▶ 속도 비율
          0              1.0

   → 저속에서 잘 가속, 고속에서 둔해진다
   → 자연스러운 최고 속도 제한
```

```
   ⚠️ ForceMode 선택 (Day 73)

   Acceleration:  질량 무시. 튜닝이 쉽다  ★
```

### 3-5. 조향

**왜 필요한가** — 회전.

```csharp
    private void ApplySteering(float input, float dt)
    {
        float forwardSpeed = Vector3.Dot(rb.linearVelocity, transform.forward);

        // ★ ① 속도가 없으면 조향도 없다
        float speedFactor = Mathf.Clamp01(Mathf.Abs(forwardSpeed) / steerSpeedThreshold);

        // ★ ② 고속에서 조향 감도 감소
        float sensitivity = steerSensitivityCurve.Evaluate(
            Mathf.Abs(forwardSpeed) / maxSpeed);

        // ★ ③ 조향각 보간 (즉각적이지 않게)
        float targetSteer = input * maxSteerAngle * sensitivity;
        currentSteerAngle = Mathf.MoveTowards(
            currentSteerAngle, targetSteer, steerSpeed * dt);

        // ★ ④ 후진 시 조향 반대
        float dir = forwardSpeed >= 0 ? 1f : -1f;

        float yaw = currentSteerAngle * speedFactor * dir * turnRate * dt;

        rb.MoveRotation(rb.rotation * Quaternion.Euler(0, yaw, 0));
    }
```

```
   ★ ① 정지 시 조향 금지

   실제 차는 멈춰 있으면 핸들을 꺾어도 안 돈다
   → speedFactor로 구현
```

```
   ★ ② 고속 조향 감소

   조향 감도 ↑
      1.0 │████
          │    ███
          │       ███
      0.3 │          ██████
          └─────────────────▶ 속도
          0               최대

   → 고속에서 회전 반경이 커진다
   → 안정감이 생긴다
```

```
   ⚠️ 이 곡선이 없으면

   고속에서 핸들을 살짝만 꺾어도 급회전
   → 조작이 매우 불안정하다
```

```
   ★ ④ 후진 조향 반대

   후진 중 핸들을 오른쪽으로 꺾으면
   차 뒤쪽이 오른쪽으로 간다
   → 앞쪽은 왼쪽으로
```

### 3-7. 접지 판정

**왜 필요한가** — 공중에서는 가속·조향이 안 돼야 한다.

```csharp
    [System.Serializable]
    public class WheelPoint
    {
        public Transform anchor;               // 바퀴 위치
        public Transform visual;               // 바퀴 메시
        public bool isSteering;                // 조향 바퀴인가
        public bool isDriving;                 // 구동 바퀴인가

        [HideInInspector] public bool grounded;
        [HideInInspector] public float compression;   // 서스펜션 압축량
    }

    private void CheckGround()
    {
        groundedWheels = 0;

        foreach (WheelPoint w in wheels)
        {
            Vector3 origin = w.anchor.position;

            w.grounded = Physics.Raycast(origin, -transform.up,
                                          out RaycastHit hit,
                                          wheelRadius + groundCheckExtra,
                                          groundLayer);

            if (w.grounded)
            {
                groundedWheels++;
                w.compression = 1f - (hit.distance / (wheelRadius + groundCheckExtra));
                lastGroundNormal = hit.normal;
            }
            else
            {
                w.compression = 0;
            }
        }
    }
```

```
   ★ 바퀴 4개를 각각 검사

   4/4  →  완전 접지
   2/4  →  한쪽이 떴다 (점프대, 경사)
   0/4  →  공중
```

```
   ⚠️ Raycast 시작점

   바퀴 중심에서 아래로
   → 차체에 맞지 않게 Layer를 분리하거나
   → origin을 바퀴 위쪽에서 시작
```

### 3-8. 간이 서스펜션

**왜 필요한가** — 차체가 지면에 파묻히지 않게.

```csharp
    private void ApplySuspension()
    {
        foreach (WheelPoint w in wheels)
        {
            Vector3 origin = w.anchor.position;

            if (!Physics.Raycast(origin, -transform.up, out RaycastHit hit,
                                 suspensionRestLength + wheelRadius, groundLayer))
                continue;

            // ★ 압축량
            float currentLength = hit.distance - wheelRadius;
            float compression = suspensionRestLength - currentLength;

            // ★ 스프링 힘 (후크의 법칙)
            float springForce = compression * suspensionStrength;

            // ★ 감쇠 (진동 억제)
            float velocity = Vector3.Dot(
                rb.GetPointVelocity(origin), transform.up);
            float damperForce = -velocity * suspensionDamper;

            Vector3 force = transform.up * (springForce + damperForce);

            rb.AddForceAtPosition(force, origin);
        }
    }
```

```
   ★ 후크의 법칙

   F = -k × x

   k = 스프링 상수 (강도)
   x = 압축량
```

```
   ★ 감쇠(Damper)가 없으면

   차가 계속 위아래로 통통 튄다
   → 감쇠는 속도에 반대되는 힘
```

```
   ⚠️ 아케이드 방식에서는 생략해도 된다

   Rigidbody의 Collider와 물리에 맡기고
   시각적 바퀴만 애니메이션
   → 오늘은 간단히 간다
```

### 3-10. 드리프트

**왜 필요한가** — 아케이드 레이싱의 꽃.

```csharp
    private void UpdateDrift(bool handbrake, float dt)
    {
        // ★ 핸드브레이크 시 그립 감소
        float targetGrip = handbrake ? driftGrip : normalGrip;

        currentGrip = Mathf.MoveTowards(currentGrip, targetGrip,
                                        gripChangeSpeed * dt);

        // ★ 옆 속도 감쇠
        Vector3 localVel = transform.InverseTransformDirection(rb.linearVelocity);

        localVel.x *= currentGrip;

        rb.linearVelocity = transform.TransformDirection(localVel);

        // ★ 드리프트 각도 계산
        Vector3 flatVel = rb.linearVelocity;
        flatVel.y = 0;

        if (flatVel.sqrMagnitude > 1f)
        {
            driftAngle = Vector3.SignedAngle(
                transform.forward, flatVel.normalized, transform.up);
        }
        else
        {
            driftAngle = 0;
        }

        IsDrifting = Mathf.Abs(driftAngle) > driftAngleThreshold
                     && flatVel.magnitude > driftSpeedThreshold;
    }
```

```
   ★ 드리프트 각도

   차의 forward와 실제 이동 방향의 각도 차이

        forward
          ↑
          │  ╱ 실제 이동
          │ ╱
          │╱ ← 이 각도가 드리프트 각도
          ●

   0도    직진
   15도   가벼운 슬라이드
   30도+  본격 드리프트
   80도+  스핀
```

```
   ★ Vector3.SignedAngle

   두 벡터 사이 각도를 부호와 함께 (-180 ~ 180)
   → 왼쪽/오른쪽 구분
```

```
   ★ 핸드브레이크 시 뒷바퀴만 그립 감소

   더 사실적이려면 앞뒤를 분리한다
   → 아케이드에서는 전체 그립 하나로 충분
```

### 3-11. 바퀴 시각화

**왜 필요한가** — 굴러가야 차처럼 보인다.

```csharp
    private void UpdateWheelVisuals(float dt)
    {
        float forwardSpeed = Vector3.Dot(rb.linearVelocity, transform.forward);

        // ★ 굴러가는 각속도 = 속도 / 반지름
        float rotationSpeed = (forwardSpeed / wheelRadius) * Mathf.Rad2Deg;

        wheelSpin += rotationSpeed * dt;

        foreach (WheelPoint w in wheels)
        {
            if (w.visual == null) continue;

            // ★ 조향 바퀴는 좌우로도 꺾인다
            float steer = w.isSteering ? currentSteerAngle : 0f;

            w.visual.localRotation =
                Quaternion.Euler(wheelSpin, steer, 0);
        }
    }
```

```
   ★ 각속도 계산

   바퀴 반지름 0.35m, 속도 20 m/s

   각속도 = 20 / 0.35 = 57.1 rad/s
          = 57.1 × 57.3 = 3,273 도/초
```

```
   ⚠️ 바퀴 메시의 축 방향

   모델에 따라 x, y, z 중 어느 축이 회전축인지 다르다
   → Euler(spin, steer, 0) 순서를 조정해야 할 수 있다

   ★ 확인 방법
   Play 중 바퀴를 선택해 Rotation을 직접 바꿔 본다
```

### Step 5 — 전진력

3-4절의 `ApplyDrive`를 구현한다.

```csharp
    private void ApplyDrive(float dt)
    {
        if (groundedWheels == 0) return;
        if (Mathf.Abs(inputThrottle) < 0.01f) return;

        float fwd = ForwardSpeed;

        // ★ 후진 여부
        bool reversing = inputThrottle < 0;
        float limit = reversing ? reverseMaxSpeed : maxSpeed;

        float speedRatio = Mathf.Clamp01(Mathf.Abs(fwd) / limit);
        float power = accelerationCurve.Evaluate(speedRatio);

        // ★ 접지 바퀴 비율만큼
        float traction = groundedWheels / (float)wheels.Length;

        Vector3 force = transform.forward
                        * inputThrottle * enginePower * power * traction;

        rb.AddForce(force, ForceMode.Acceleration);
    }
```

**✅ 여기까지 실행하면** — W로 앞으로 나간다. 하지만 조향이 없다.

### Step 6 — 브레이크

```csharp
    private void ApplyBrake(float dt)
    {
        float fwd = ForwardSpeed;

        // ★ 진행 방향과 반대로 입력 = 브레이크
        bool braking = (fwd > 1f && inputThrottle < -0.1f)
                    || (fwd < -1f && inputThrottle > 0.1f);

        if (braking)
        {
            Vector3 brake = -transform.forward * Mathf.Sign(fwd) * brakePower;
            rb.AddForce(brake, ForceMode.Acceleration);
            return;
        }

        // ★ 엔진 브레이크 (입력이 없을 때 감속)
        if (Mathf.Abs(inputThrottle) < 0.01f && Mathf.Abs(fwd) > 0.1f)
        {
            Vector3 drag = -transform.forward * Mathf.Sign(fwd) * engineBrake;
            rb.AddForce(drag, ForceMode.Acceleration);
        }
    }
```

**✅ 여기까지 실행하면** — S로 감속하고, 손을 떼면 서서히 멈춘다.

### Step 7 — 조향

3-5절의 `ApplySteering`을 구현한다.

```csharp
    private void ApplySteering(float dt)
    {
        float fwd = ForwardSpeed;

        // ★ 조향각 보간
        float sensitivity = steerSensitivityCurve.Evaluate(
            Mathf.Clamp01(Mathf.Abs(fwd) / maxSpeed));

        float targetSteer = inputSteer * maxSteerAngle * sensitivity;

        currentSteerAngle = Mathf.MoveTowards(
            currentSteerAngle, targetSteer, steerSpeed * dt);

        if (groundedWheels == 0) return;

        // ★ 속도가 있어야 회전
        float speedFactor = Mathf.Clamp01(Mathf.Abs(fwd) / steerSpeedThreshold);

        float dir = fwd >= 0 ? 1f : -1f;

        float yaw = currentSteerAngle * speedFactor * dir * turnRate * dt;

        rb.MoveRotation(rb.rotation * Quaternion.Euler(0, yaw, 0));
    }
```

**✅ 여기까지 실행하면**

```
   ★ 달리면서 A/D로 방향을 바꾼다
   ★ 멈춰 있으면 안 돈다
   ⚠️ 하지만 계속 옆으로 미끄러진다
```

### Step 9 — 그립 (핵심)

3-2절과 3-10절의 `ApplyGrip`을 구현한다.

```csharp
    private void ApplyGrip(float dt)
    {
        if (groundedWheels == 0) return;

        float targetGrip = inputHandbrake ? driftGrip : normalGrip;

        currentGrip = Mathf.MoveTowards(currentGrip, targetGrip,
                                        gripChangeSpeed * dt);

        // ★ 로컬 속도 분해
        Vector3 localVel = transform.InverseTransformDirection(rb.linearVelocity);

        // ★ 옆 속도 감쇠 — 이 한 줄이 핵심
        localVel.x *= currentGrip;

        rb.linearVelocity = transform.TransformDirection(localVel);

        // 드리프트 각도
        Vector3 flat = rb.linearVelocity;
        flat.y = 0;

        DriftAngle = flat.sqrMagnitude > 1f
            ? Vector3.SignedAngle(transform.forward, flat.normalized, transform.up)
            : 0f;

        IsDrifting = Mathf.Abs(DriftAngle) > driftAngleThreshold
                     && flat.magnitude > driftSpeedThreshold;
    }
```

```
   ③ Space를 누르면 크게 미끄러진다
```

```csharp
    private void UpdateWheelVisuals(float dt)
    {

        float spinSpeed = (fwd / wheelRadius) * Mathf.Rad2Deg;

        // 각도 오버플로 방지

        }
    }
```

- [ ] **고속에서 조향 감도가 줄어든다**
- [ ] 감도 곡선이 없으면 불안정하다는 것을 확인했다
- [ ] 무게중심을 낮춰 전복을 막았다
- [ ] 다운포스로 점프 높이가 조절된다
- [ ] 바퀴가 속도에 맞춰 굴러간다
- [ ] 앞바퀴가 조향 방향으로 꺾인다
- [ ] Physics Material로 벽 붙음을 해결했다
- [ ] R로 리셋되고 뒤집히면 자동 복구된다

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **차가 뒤집힘** | 무게중심 높음 | `centerOfMass` 낮추기 |
| 차가 안 기움 | 무게중심 과하게 낮음 | 조정 |
| **계속 미끄러짐** | 옆 속도 감쇠 없음 | `localVel.x *= grip` |
| 전혀 안 미끄러짐 | grip 너무 낮음 | 0.9 근처로 |
| 제자리에서 회전 | 속도 검사 없음 | `speedFactor` |
| 고속에서 팽이 | 감도 곡선 없음 | `steerSensitivityCurve` |
| 조향이 즉각적 | 보간 없음 | `MoveTowards` |
| 벽에 붙어 안 떨어짐 | 마찰 높음 | Physics Material 0.2 |
| 벽을 뚫음 | `transform` 이동 | Rigidbody 사용 |
| 벽을 뚫음 | 고속 + Discrete | Continuous |
| 낙하 속도까지 제한 | `magnitude` 제한 | 로컬 z만 |
| 바퀴 축이 이상 | Euler 순서 | 순서 변경 또는 부모 분리 |
| 리셋 후 튀어나감 | velocity 미초기화 | 0으로 |
| 프레임률에 따라 다름 | Update에서 물리 | FixedUpdate |
| 통통 튐 | 서스펜션 감쇠 없음 | Damper 추가 또는 생략 |
