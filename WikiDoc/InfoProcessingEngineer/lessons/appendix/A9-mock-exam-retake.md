## 문제

**A. 코드 (1~10번)**

1. [C·결과 예측] 다음 코드의 출력을 쓰시오.
   ```c
   int a = 7, b = 2;
   printf("%d %d", a / b + a % b, a * b % 3);
   ```
2. [C·결과 예측] 다음 코드의 출력을 쓰시오.
   ```c
   int i, s = 0;
   for (i = 1; i <= 30; i *= 2) s += i;
   printf("%d", s);
   ```
3. [C·결과 예측] 다음 코드의 출력을 쓰시오.
   ```c
   int a[] = {5, 10, 15, 20};
   int *p = a;
   *(p + 1) = *(p + 3) - *p;
   printf("%d", a[1]);
   ```
4. [C·코드 해석] 다음 함수에서 `f(24, 18)`의 반환값과, 이 함수가 구하는 것을 한 문장으로 쓰시오.
   ```c
   int f(int a, int b) {
       if (b == 0) return a;
       return f(b, a % b);
   }
   ```
5. [Java·결과 예측] 다음 코드의 출력을 쓰시오.
   ```java
   int[] a = {3, 1, 4, 1, 5, 9};
   int max = a[0], min = a[0];
   for (int i = 1; i < a.length; i++) {
       if (a[i] > max) max = a[i];
       if (a[i] < min) min = a[i];
   }
   System.out.println(max - min);
   ```
6. [Java·결과 예측] 다음 코드의 출력을 쓰시오.
   ```java
   int s = 0;
   for (int i = 3; i >= 0; i--) {
       try {
           s += 12 / i;
       } catch (ArithmeticException e) {
           s += 1;
       }
   }
   System.out.println(s);
   ```
7. [Java·결과 예측] 다음 코드의 출력을 쓰시오.
   ```java
   String s = "PROCESS";
   System.out.println(s.indexOf('S') + s.length());
   ```
8. [Python·결과 예측] 다음 코드의 출력을 쓰시오.
   ```python
   d = {"a": 3, "b": 7, "c": 5}
   m = "a"
   for k in d:
       if d[k] > d[m]:
           m = k
   print(m, d[m])
   ```
9. [Python·결과 예측] 다음 코드의 출력을 쓰시오.
   ```python
   s = "LEVEL"
   print(s == s[::-1])
   ```
10. [Python·빈칸] 출력이 `3`이 되도록 빈칸에 연산자를 쓰시오.
    ```python
    a = [4, 7, 10, 13, 16]
    cnt = 0
    for x in a:
        if x % 2 ____ 0:
            cnt += 1
    print(cnt)
    ```

**B. SQL (11~15번)**

11. [작성] 학과명이 '컴퓨터공학'인 학과에 소속된 학생의 이름을 JOIN을 사용해 조회하는 SQL을 쓰시오.
12. [결과 예측] 다음 SQL의 결과(행 포함)를 쓰시오.
    ```sql
    SELECT 학년, COUNT(*)
    FROM   STUDENT
    GROUP BY 학년
    HAVING COUNT(*) >= 2;
    ```
13. [빈칸] 학번 1002 학생의 학년을 3으로 변경한다. → `______ STUDENT SET 학년 = 3 WHERE 학번 = 1002;`
14. [결과 예측] `SELECT COUNT(*) FROM ENROLL WHERE 성적 IS NOT NULL AND 성적 < 85;` 의 결과값은?
15. [작성] 관계대수식 **π 이름 (σ 학년=1 (STUDENT))** 을 SQL로 옮겨 쓰시오.

**C. 이론 (16~20번)**

16. [단답] 상대 모듈의 동작을 지시하는 플래그(제어 요소)를 전달할 때 발생하는 결합도를 쓰시오.
17. [단답] 원본 객체를 복제(clone)하는 방식으로 새 객체를 생성하는 GoF 생성 패턴을 쓰시오.
18. [단답] 네트워크 침입을 탐지하여 관리자에게 알리는 역할까지 수행하는 보안 솔루션을 영문 약어로 쓰시오.
19. [계산] HRN 스케줄링에서 다음 두 작업의 우선순위 값을 각각 구하고 먼저 실행될 작업을 쓰시오. → A: 대기 9, 서비스 3 / B: 대기 10, 서비스 5
20. [단답] 트랜잭션이 완료(COMMIT)되면 그 결과가 시스템 장애가 발생해도 영구적으로 반영되는 ACID 성질을 쓰시오.
