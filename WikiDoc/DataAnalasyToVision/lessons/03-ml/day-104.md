| 질문 | 답할 수 있는가 |
|---|---|
| 90장 중 몇 장 틀렸나 | 10장 |
| **어느 방향으로 틀렸나** | 혼동행렬 |
| 0.88은 얼마나 정확한 숫자인가 | **신뢰구간** |
| 왜 틀렸나 | **오분류 전수 확인** |
| 동물을 보고 맞힌 건가 | **Grad-CAM · 마스킹** ★ |
| 실제로 쓸 수 있나 | 임계값 설계 |

**오늘 이 여섯 개에 전부 답합니다.**

### 그리고 결정적 실험 하나

[Day 100](day-100.md)에서 Grad-CAM을 배웠습니다. 하지만 Grad-CAM은 **정황 증거**입니다.

```
"히트맵이 동물 쪽에 있으니 동물을 본 것 같다"
→ "같다"입니다. 증명이 아닙니다.
```

**오늘 결정적 증거를 만듭니다.**

```
① 동물을 가린다  → 정확도가 얼마나 떨어지는가
② 배경을 가린다  → 정확도가 얼마나 떨어지는가

동물 가림 시 크게 떨어지고 배경 가림 시 유지되면
→ 모델은 동물을 보고 있습니다.  ★ 이건 증명입니다
```

## 2부 · 결과에 신뢰구간을 붙입니다

### 90장에서 0.8842는 얼마나 믿을 수 있는가

```
90장 중 80장 정답 → 0.8889
1장이 뒤집히면    → 0.8778 또는 0.9000

1장 = 1.1%p
```

**0.88과 0.90의 차이는 2장입니다.** 그런 차이로 순위를 매기면 안 됩니다.

### Wilson 신뢰구간

**표본이 작을 때 쓰는 비율 신뢰구간입니다.**

```
n = 90, 정확도 0.8889
95% 신뢰구간 ≈ [0.805, 0.938]
```

**해석**

> "이 모델의 진짜 정확도는 80.5%~93.8% 사이일 가능성이 95%다."

| 표본 크기 | 0.89의 95% 구간 폭 |
|---|---|
| 30장 | ±0.11 |
| **90장** | **±0.07** |
| 300장 | ±0.035 |
| 1000장 | ±0.02 |

> **"정확도 0.8842"보다 "0.88 (95% CI 0.81–0.94)"이 정직한 보고입니다.**
> 발표에서 이렇게 쓰면 심사자가 "이 팀은 통계를 안다"고 판단합니다.

### 두 모델 비교에 쓰기

```
모델 A  0.8889  CI [0.805, 0.938]
모델 B  0.9111  CI [0.833, 0.954]

구간이 크게 겹침 → 차이가 있다고 말할 수 없음
```

## 3부 · 편향 검증 3종

### ① 배경 교차 테스트 — 분포가 바뀌면

```
counter 셋 61장으로 평가
하락폭 = test 정확도 − counter 정확도
```

| 하락폭 | 판정 |
|---|---|
| ≤ 0.05 | 배경 의존 거의 없음 |
| 0.05 ~ 0.10 | 약간 있음 (허용) |
| 0.10 ~ 0.20 | 있음 |
| > 0.20 | **심각** |

### ② Grad-CAM 가장자리 집중도 — 어디를 보는가

```
히트맵에서 이미지 가장자리 20% 영역이 차지하는 비중
```

| 값 | 판정 ([Day 100](day-100.md) 기준) |
|---|---|
| < 0.25 | 중앙(대상)을 봄 |
| 0.25 ~ 0.35 | 보통 |
| > 0.45 | **배경 의존 의심** |

> **정황 증거입니다.** 대상이 화면 가장자리에 있을 수도 있습니다.

### ③ ★ 마스킹 실험 — 결정적 증거

**같은 이미지를 두 가지로 가리고 성능을 비교합니다.**

```
원본        : 정확도 0.89
중앙 가림   : 동물이 주로 있는 중앙 40% 영역을 회색으로  → ?
가장자리 가림: 배경이 주로 있는 테두리 영역을 회색으로   → ?
```

**해석표**

| 중앙 가림 | 가장자리 가림 | 결론 |
|---|---|---|
| **크게 하락** | 유지 | **✅ 동물을 보고 있다** |
| 유지 | **크게 하락** | **🔴 배경을 보고 있다** |
| 둘 다 하락 | | 둘 다 활용 (정상) |
| 둘 다 유지 | | 다른 단서 사용 — 조사 필요 |

```
편향 모델 예시
  원본 0.92 → 중앙 가림 0.88 (−0.04) → 가장자리 가림 0.54 (−0.38)
  = 동물을 지워도 멀쩡하고, 배경을 지우면 무너진다
```

> **이것이 "모델이 무엇을 보는가"에 대한 실험적 증명입니다.**
> Grad-CAM은 "어디를 보는 것 같다", 마스킹은 **"어디가 없으면 못 한다"** 를 말합니다.

### Step 1. 개봉 전 점검 — 아직 테스트셋을 열지 않습니다

```python
"""
Day 104 Step 1 — 테스트셋 개봉 전 체크리스트
여기서는 테스트 이미지의 '파일 목록'만 보고, 예측은 하지 않습니다.
"""
import json
from pathlib import Path

import numpy as np
import pandas as pd
from PIL import Image
from tensorflow import keras

PROJ = Path("/content/drive/MyDrive/ml_course/project_wolf")
SPLIT, COUNTER = PROJ / "data" / "split", PROJ / "data" / "counter"
MODEL_DIR = PROJ / "models"
CLASSES = ["husky", "wolf"]

choice = json.loads((MODEL_DIR / "final_choice.json").read_text(encoding="utf-8"))
MODEL_PATH = MODEL_DIR / f"{choice['name']}.keras"

line = "=" * 76
print(line)
print("테스트셋 개봉 전 체크리스트")
print(line)

checks = []


def check(item, ok, detail=""):
    checks.append({"항목": item, "통과": bool(ok), "상세": detail})


# ── ① 최종 모델 ──
check("최종 모델 파일 존재", MODEL_PATH.exists(), MODEL_PATH.name)
check("선정 근거 기록", "selection_rule" in choice,
      choice.get("selection_rule", "")[:40])
check("선정 시점 고정", choice.get("frozen_at") == "Day 103 종료",
      choice.get("frozen_at", ""))

# ── ② 전처리·클래스 순서 ──
model = keras.models.load_model(MODEL_PATH, compile=False)
in_shape = tuple(model.input_shape[1:3])
check("입력 크기 일치 (224,224)", in_shape == (224, 224), str(in_shape))
check("출력이 sigmoid 1개", model.output_shape[-1] == 1,
      str(model.output_shape))

train_classes = sorted(d.name for d in (SPLIT / "train").iterdir() if d.is_dir())
test_classes = sorted(d.name for d in (SPLIT / "test").iterdir() if d.is_dir())
check("클래스 순서 동일", train_classes == test_classes == CLASSES,
      f"{train_classes}")

# ── ③ 누수 최종 점검 ──
def dhash(path, hash_size=8):
    img = Image.open(path).convert("L").resize(
        (hash_size + 1, hash_size), Image.LANCZOS)
    a = np.array(img, dtype=int)
    return (a[:, 1:] > a[:, :-1]).flatten()


def collect(root):
    return [f for cls in CLASSES for f in sorted((root / cls).glob("*.jpg"))]


train_files = collect(SPLIT / "train") + collect(SPLIT / "val")
test_files = collect(SPLIT / "test")
counter_files = collect(COUNTER)

h_train = np.array([dhash(f) for f in train_files])
h_test = np.array([dhash(f) for f in test_files])
h_counter = np.array([dhash(f) for f in counter_files])


def min_distance(A, B):
    """A의 각 행에 대해 B와의 최소 해밍 거리"""
    return np.array([np.min(np.sum(A[i] != B, axis=1)) for i in range(len(A))])


d_test = min_distance(h_test, h_train)
d_counter = min_distance(h_counter, h_train)

check("test-train 중복 없음 (dhash > 5)", d_test.min() > 5,
      f"최소 거리 {d_test.min()}")
check("counter-train 중복 없음", d_counter.min() > 5,
      f"최소 거리 {d_counter.min()}")
check("test 파일명 중복 없음",
      len(set(f.name for f in test_files) &
          set(f.name for f in train_files)) == 0, "")

# ── ④ 개수 ──
check("test 90장 내외", 80 <= len(test_files) <= 110, f"{len(test_files)}장")
check("counter 60장 내외", 50 <= len(counter_files) <= 80,
      f"{len(counter_files)}장")

# ── 결과 ──
df = pd.DataFrame(checks)
print(f"\n{'항목':<32}{'판정':>6}   상세")
print("-" * 76)
for _, r in df.iterrows():
    print(f"{r['항목']:<32}{'✓' if r['통과'] else '✗':>6}   {r['상세']}")
print("-" * 76)

ok = df["통과"].all()
print(f"\n{'✅ 개봉 가능' if ok else '🔴 개봉 불가 — 위 ✗ 항목을 먼저 해결하세요'}")
print(line)

if ok:
    print(f"""
  [최종 확인 — 팀 전원 구두 동의]

    · 모델      : {choice['name']}  (실험 #{choice['experiment_no']})
    · 선정 근거 : {choice['selection_rule']}
    · val       : {choice['val_acc']:.4f}

    ★ 결과가 목표에 미달해도 모델을 바꾸지 않는다.
      미달이면 "왜 미달했는가"를 분석해서 발표한다.

  동의하면 Step 2로 진행합니다.
""")
```

### Step 2. 테스트셋 1회 평가 — 개봉

```python
def wilson(k, n, z=1.96):
    """Wilson 신뢰구간 — 표본이 작을 때 쓰는 비율 구간"""
    if n == 0:
        return 0.0, 0.0
    p = k / n
    d = 1 + z ** 2 / n
    center = (p + z ** 2 / (2 * n)) / d
    half = z * np.sqrt(p * (1 - p) / n + z ** 2 / (4 * n ** 2)) / d
    return max(0.0, center - half), min(1.0, center + half)


def make_ds(root):
```

### Step 4. Grad-CAM — 어디를 보는가

```python
"""
Day 104 Step 4 — Grad-CAM + 가장자리 집중도
Day 100의 코드를 프로젝트 모델에 적용합니다.
"""
from pathlib import Path

import matplotlib.cm as cm_module
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from PIL import Image
from tensorflow import keras


def find_last_conv(model):
    """마지막 Conv 층 (백본이 중첩된 경우 포함) — Day 100"""
    for layer in reversed(model.layers):
        if isinstance(layer, keras.Model):
            for sub in reversed(layer.layers):
                if len(sub.output.shape) == 4:
                    return layer.name, sub.name
        if len(getattr(layer, "output", tf.constant(0)).shape) == 4:
            return None, layer.name
    raise ValueError("Conv 층 없음")


OUTER, INNER = find_last_conv(model)
print(f"대상 Conv 층: {INNER}" + (f"  (in {OUTER})" if OUTER else ""))

if OUTER:
    backbone = model.get_layer(OUTER)
    grad_model = keras.Model(model.inputs,
                             [backbone.get_layer(INNER).output, model.output])
else:
    grad_model = keras.Model(model.inputs,
                             [model.get_layer(INNER).output, model.output])


def gradcam(img_array):
    with tf.GradientTape() as tape:
        conv_out, preds = grad_model(img_array, training=False)
        channel = preds[:, 0]
    grads = tape.gradient(channel, conv_out)
    weights = tf.reduce_mean(grads, axis=(0, 1, 2))
    hm = tf.reduce_sum(conv_out[0] * weights, axis=-1)
    hm = tf.maximum(hm, 0)
    denom = tf.reduce_max(hm)
    return (hm / denom).numpy() if denom > 0 else hm.numpy()


def edge_focus(hm, ratio=0.2):
    """가장자리 집중도 — 테두리 20% 영역이 차지하는 비중"""
    h, w = hm.shape
    b_h, b_w = max(1, int(h * ratio)), max(1, int(w * ratio))
    edge = (hm[:b_h].sum() + hm[-b_h:].sum() +
            hm[:, :b_w].sum() + hm[:, -b_w:].sum())
    return float(edge / max(hm.sum(), 1e-9))


def load_array(path):
    img = Image.open(path).convert("RGB").resize(IMG_SIZE)
    return np.array(img, dtype="float32")[np.newaxis]


def overlay(img_pil, hm, alpha=0.45):
    base = np.array(img_pil.convert("RGB").resize(IMG_SIZE))
```

```python
def mask_center(arr, ratio=0.5):
    """중앙 사각 영역을 회색으로 (대상 제거)"""
    out = arr.copy()
    h, w = out.shape[1:3]
    ch, cw = int(h * ratio / 2), int(w * ratio / 2)
    out[:, h // 2 - ch:h // 2 + ch, w // 2 - cw:w // 2 + cw, :] = GRAY
    return out


def mask_border(arr, ratio=0.25):
    """테두리를 회색으로 (배경 제거)"""
    out = arr.copy()
    h, w = out.shape[1:3]
    bh, bw = int(h * ratio), int(w * ratio)
    out[:, :bh, :, :] = GRAY

    return out
```

```markdown
**2. 배경 태그 세분 층화 — 눈/비눈 → 눈/숲/실내/풀밭** (효과: counter +0.03 예상, 비용: 1일)

근거: 데이터 카드 6절 "잔여 위험"에 기록한 대로, 눈 외 배경은 층화하지 않았다.
클래스×배경 표에서 wolf/other 0.8750 < husky/other 0.9200으로
비눈 배경 안에서도 차이가 남아 있다.

**3. 오분류 유형 C(드문 자세) 데이터 보강** (효과: +0.02~0.04, 비용: 1일)

근거: 오분류 11장 중 4장이 유형 C(웅크림·측면·뛰는 자세).
학습 데이터의 자세 분포를 확인한 결과 정면·측면 정지 자세가 78%.

**4. 확신도 임계값 운영 — 0.90 미만은 사람 검토** (효과: 오류 11 → 3건, 비용: 없음)

근거: 확신도 0.90 이상 구간(38장)의 정확도는 0.9737.
0.90 미만 57장을 사람이 보면 자동 처리분의 오류가 1건으로 줄어든다.
Day 100에서 만든 `Predictor.certain` 플래그를 그대로 쓸 수 있다.

### 하지 않을 것

**① 백본 교체 (EfficientNetB0, ResNet50)**
실험 10에서 EfficientNetB0를 시도했으나 val 0.9053으로 동일,
학습 시간은 1571초로 1.5배. seed 표준편차(0.0086) 안의 차이라 동점.
더 큰 백본은 445장 데이터에서 과적합 위험만 커진다.

**② 하이퍼파라미터 추가 탐색**
실험을 14회 수행했다. 검증셋 95장에서 20회를 넘기면
val에 대한 과적합으로 테스트 성능이 오히려 떨어질 수 있다.
현재의 성능 병목은 하이퍼파라미터가 아니라 데이터 다양성이다.

**③ 증강 강도 추가 상향**
exp9에서 이미 val이 exp8 대비 −0.011로 하락 추세.
증강을 더 강하게 하면 counter는 오를 수 있으나
주 성능이 기준 A(0.85) 아래로 내려갈 위험이 있다.
```
