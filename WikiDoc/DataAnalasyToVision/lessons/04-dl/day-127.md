## 1부 · 타깃 분석 — 할인율의 특성

### 할인율은 California Housing과 다릅니다

| | 주택가격 | **할인율** |
|---|---|---|
| 범위 | 0.15 ~ 5.0 (33배) | **0 ~ 90 (제한)** |
| 왜도 | 0.98 (오른쪽 꼬리) | **약 0.4 (완만)** |
| 연속성 | 연속 | **★ 이산** (10/20/25/30/33...) |
| 0의 존재 | 없음 | **있음 (5.8%)** |
| 상한 | 5.0 절단 | **90% 자연 상한** |

**[Day 111](day-111.md)의 판정 순서를 적용하면**

```
① 왜도 0.4 → |왜도| < 0.5 → 변환 불필요
② 0이 있음 → log 불가, log1p는 가능하지만 필요 없음
③ 상한 90% → 예측값 clip 필요
```

> **결론 — 할인율은 로그 변환이 필요 없습니다.**
> **[Day 111](day-111.md)에서 "왜도가 작으면 변환하지 마라"고 한 그 경우입니다.**

### 그런데 이산적이라는 것이 문제입니다

```
스팀 할인율: 0, 10, 15, 20, 25, 30, 33, 35, 40, 45, 50, ..., 90
19개 값에 3,200건이 몰려 있음
```

**세 가지 접근**

| 접근 | 방법 | 장단점 |
|---|---|---|
| **A. 연속 회귀** | 그대로 회귀 | 간단. 예측값이 33.7% 같은 값 |
| **B. 회귀 + 반올림** | 예측 후 가장 가까운 단계로 | **사용자 체감 좋음** |
| C. 순서형 분류 | 19개 클래스 | 복잡. 순서 정보 활용 어려움 |

> **권장: B.** 회귀로 학습하고, **예측 함수에서 반올림**합니다. ([Day 133](day-133.md))
> 평가는 반올림 전후를 모두 보고합니다.

### 0% 할인 처리 — [Day 126](day-126.md)의 결정 확인

```
문제 정의서: "할인율 0% (세일 미포함)" 제외
```

**제외하는 이유**

```
0%는 "할인을 안 한 것"이지 "0% 할인한 것"이 아닙니다.
다른 종류의 사건입니다. (Day 111 확인문제 1의 (a))
```

**제외 시 확인할 것**

```
① 제외 후 행 수가 충분한가
② 제외된 행에 편향이 있는가 (신작만 0%인가?)
③ 보고서에 명시했는가
```

## 2부 · 중복·결측 처리

### 중복 — 무엇이 "같은 것"인가

| 기준 | 의미 | 처리 |
|---|---|---|
| **완전 중복** | 모든 열이 동일 | 제거 |
| **`app_id` 중복** | 같은 게임 | 제거 (수집 오류) |
| **게임명 중복** | 리마스터·에디션 | **판단 필요** |
| 개발사 중복 | 같은 개발사의 다른 게임 | 유지 (그룹 분할 검토) |

**게임명 중복의 예**

```
"Game X"              app_id 12345
"Game X - Remastered" app_id 67890
→ 다른 게임인가 같은 게임인가?
→ 도메인 판단. 대개 다른 게임으로 취급
```

> **`app_id` 중복은 수집 과정의 오류입니다.** 반드시 제거하세요.
> **개발사 중복은 [Day 109](day-109.md)의 그룹 누수 후보입니다.** [Day 128](day-128.md)에서 다룹니다.

### 결측 — 왜 비었는가

| 결측 유형 | 예 | 처리 |
|---|---|---|
| **MCAR** (완전 무작위) | 수집 실패 | 중앙값 대체 |
| **MAR** (조건부 무작위) | 신작이라 리뷰 없음 | **조건부 대체 + 플래그** |
| **MNAR** (비무작위) | 점수가 낮아서 미공개 | **★ 플래그가 정보** |

**스팀 데이터의 결측**

```
metacritic 72% 결측
  → 메타크리틱은 일정 규모 이상 게임만 평가
  → "평가 없음" 자체가 정보 (인디·소규모)
  → ★ MNAR. 플래그를 만들어야 함

positive_ratio 5.9% 결측
  → 리뷰가 너무 적어 비율 계산 불가
  → MAR. 리뷰 수와 연관
```

**처리 방침**

```python
# ① 결측 자체를 특성으로
df["has_metacritic"] = df["metacritic"].notna().astype(int)

# ② 그다음 대체
df["metacritic"] = df["metacritic"].fillna(df["metacritic"].median())
```

> ⚠️ **결측률 72%인 열을 그냥 버리면 정보를 잃습니다.**
> **`has_metacritic` 플래그가 "메이저 게임인가"를 나타낼 수 있습니다.**

## 5부 · 파생 변수 설계

### 파생 변수의 4가지 유형

| 유형 | 예 | 근거 |
|---|---|---|
| **① 시간** | 출시경과일, 출시 연도, 출시 월 | 오래될수록 할인율↑ |
| **② 변환** | log(리뷰수), sqrt(정가) | 왜도 완화 |
| **③ 비율·조합** | 리뷰당 도전과제, 언어당 가격 | 도메인 지식 |
| **④ 집계** | 개발사의 게임 수, 장르 평균가 | ★ 누수 주의 |

### ① 시간 파생 변수

```python
df["release_dt"] = pd.to_datetime(df["release_date"], errors="coerce")
REFERENCE = pd.Timestamp("2024-12-20")     # ★ 세일 시작일

df["days_since_release"] = (REFERENCE - df["release_dt"]).dt.days
df["years_since_release"] = df["days_since_release"] / 365.25
df["release_year"] = df["release_dt"].dt.year
df["release_month"] = df["release_dt"].dt.month
df["release_quarter"] = df["release_dt"].dt.quarter
```

**순환 변수 처리** ([Day 113](day-113.md))

```python
df["month_sin"] = np.sin(2 * np.pi * df["release_month"] / 12)
df["month_cos"] = np.cos(2 * np.pi * df["release_month"] / 12)
```

> ⚠️ **`REFERENCE` 를 "오늘"로 하면 안 됩니다.**
> **예측 시점(세일 시작일)으로 고정해야 재현이 됩니다.**

### ② 변환 파생 변수

```python
df["log_price"] = np.log1p(df["initial_price"])
df["log_reviews"] = np.log1p(df["review_count"])
df["log_days"] = np.log1p(df["days_since_release"])
```

### ③ 비율·조합 파생 변수

```python
# 리뷰 밀도 — 출시 후 하루당 리뷰 수
df["reviews_per_day"] = df["review_count"] / df["days_since_release"].clip(lower=1)

# 가격 대비 콘텐츠
df["price_per_achievement"] = df["initial_price"] / df["achievements"].clip(lower=1)

# 언어 지원 폭 (글로벌 게임인가)
df["is_global"] = (df["n_languages"] >= 10).astype(int)

# 인디 추정 (개발사 = 퍼블리셔)
df["is_self_published"] = (df["developer"] == df["publisher"]).astype(int)
```

**근거를 댈 수 있어야 합니다.**

```
reviews_per_day 가 높다 = 인기 게임 = 할인을 덜 함
is_self_published = 인디 = 할인 정책이 다를 수 있음
```

### ④ 집계 파생 변수 — ★ 누수 주의

```python
# ✗ 전체 데이터로 집계 (누수)
df["dev_game_count"] = df.groupby("developer")["app_id"].transform("count")
df["dev_mean_discount"] = df.groupby("developer")["discount_percent"].transform("mean")
```

**두 번째는 타깃을 쓰므로 명백한 누수입니다.** ([Day 113](day-113.md))

**올바른 방법**

| 집계 | 누수 여부 | 처리 |
|---|---|---|
| 개발사의 **게임 수** | 타깃 무관 | 전체로 계산 가능 (단, 분할 후 권장) |
| 개발사의 **평균 할인율** | **★ 타깃 사용** | `TargetEncoder(cv=5)` 를 Pipeline 안에서 |
| 장르별 **평균 정가** | 타깃 무관 | 계산 가능 |

> **타깃을 쓰는 집계는 반드시 `Pipeline` 안에서.** ([Day 115](day-115.md), [Day 122](day-122.md))

### 파생 변수 검증

```
만든 뒤 반드시 확인:
  □ 결측이 생기지 않았는가 (0으로 나누기 등)
  □ inf 가 생기지 않았는가
  □ 타깃과의 상관이 0.95를 넘지 않는가 (누수 신호)
  □ 도메인 근거를 한 줄로 쓸 수 있는가
```

### Step 1. 데이터 로드와 정제

```python
import json
from pathlib import Path

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

pd.set_option("display.width", 200)
plt.rcParams["figure.figsize"] = (10, 5)

RAW = ROOT / "data" / "raw"
PROC = ROOT / "data" / "processed"
PROC.mkdir(parents=True, exist_ok=True)

# ── 원본 로드 (복사본으로 작업) ──
raw_files = sorted(RAW.glob("steam_raw_*.csv"))
raw_path = raw_files[-1]
df0 = pd.read_csv(raw_path)
df = df0.copy()

TARGET = "discount_percent"
REFERENCE = pd.Timestamp("2024-12-20")     # ★ 예측 시점 = 세일 시작일

print("=" * 84)

print("=" * 84)
print(f"  {df.shape[0]:,}행 × {df.shape[1]}열")
print("=" * 84)

# ── 정제 로그 ──
clean_log = []


def log_step(name, before, after, note=""):
    clean_log.append({"단계": name, "이전": before, "이후": after,
                      "제거": before - after,
                      "비율(%)": round((before - after) / before * 100, 2),
                      "비고": note})
    print(f"  {name:<28}{before:>7,} → {after:>7,}  "
          f"(-{before-after:,}, {(before-after)/before*100:.2f}%)  {note}")


print("\n[정제 단계]")
n0 = len(df)

# ① 완전 중복
df = df.drop_duplicates()
log_step("① 완전 중복 제거", n0, len(df))

# ② app_id 중복 (수집 오류)
n = len(df)
df = df.drop_duplicates(subset=["app_id"], keep="first")
log_step("② app_id 중복 제거", n, len(df), "수집 오류")
```

```python
    df[name] = series
    s = df[name]
    n_nan = int(s.isna().sum())
    n_inf = int(np.isinf(s.replace([np.inf, -np.inf], np.nan).isna().sum())

    warn = []
    if n_nan:
        warn.append(f"NaN {n_nan}")
    if n_inf:
        warn.append(f"inf {n_inf}")
    if abs(corr) > 0.95:
```
