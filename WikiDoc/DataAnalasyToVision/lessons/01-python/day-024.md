## ② 왜 필요한가

지금까지 만든 것을 모아 보면 이렇습니다.

- 플레이어가 움직인다 ✅ ([Day 021](day-021.md))
- 총알이 나간다 ✅ ([Day 022](day-022.md))
- 적이 내려온다 ✅ ([Day 023](day-023.md))

**그런데 총알이 적을 통과합니다.** 서로 아무 상관이 없습니다.

**충돌 판정이 게임의 규칙을 만듭니다.**

```
총알 ↔ 적      → 적이 죽고 점수 획득
적   ↔ 플레이어 → 플레이어가 피해를 입음
아이템 ↔ 플레이어 → 회복·파워업
```

오늘 이 연결을 만들면 **드디어 게임이 됩니다.**

## ③ 개념 설명

### 충돌 판정의 원리 — 사각형 겹침

pygame의 기본 충돌은 **두 사각형이 겹치는가**를 봅니다.

```
겹치지 않음                    겹침
┌────┐                      ┌────┐
│ A  │  ┌────┐              │ A ┌┼───┐
└────┘  │ B  │              └───┼┘ B │
        └────┘                  └────┘
```

**겹치는 조건 (네 가지가 모두 참)**

```
A.right  > B.left
A.left   < B.right
A.bottom > B.top
A.top    < B.bottom
```

pygame이 이 계산을 대신해 줍니다.

```python
if rect_a.colliderect(rect_b):
    print("충돌!")
```

### Rect 충돌 메서드

| 메서드 | 하는 일 | 반환 |
|---|---|---|
| `rect.colliderect(other)` | 다른 Rect와 겹치나 | bool |
| `rect.collidepoint(x, y)` | 이 점이 안에 있나 | bool |
| `rect.collidelist(리스트)` | 리스트 중 첫 충돌 인덱스 | int (없으면 -1) |
| `rect.collidelistall(리스트)` | 충돌한 모든 인덱스 | list |

```python
# 마우스 클릭이 버튼 위인지 확인
if button_rect.collidepoint(pygame.mouse.get_pos()):
    print("버튼 클릭!")
```

### 스프라이트 충돌 — 하나 대 그룹

```python
pygame.sprite.spritecollide(스프라이트, 그룹, dokill, collided=None)
```

**충돌한 스프라이트들의 리스트**를 반환합니다.

```python
# 플레이어가 아이템에 닿으면 아이템 제거
hits = pygame.sprite.spritecollide(player, items, True)
for item in hits:
    player.score += 10

# 플레이어가 적에 닿아도 적은 안 사라짐
hits = pygame.sprite.spritecollide(player, enemies, False)
if hits:
    player.take_damage(20)
```

| `dokill` | 의미 |
|---|---|
| `True` | 충돌한 **그룹 쪽** 스프라이트를 `kill()` |
| `False` | 그대로 둠 |

### 스프라이트 충돌 — 그룹 대 그룹

```python
pygame.sprite.groupcollide(그룹A, 그룹B, dokillA, dokillB)
```

**딕셔너리**를 반환합니다. `{A의 스프라이트: [충돌한 B의 스프라이트들]}`

```python
# 총알이 적을 맞히면 둘 다 제거
hits = pygame.sprite.groupcollide(bullets, enemies, True, True)

for bullet, enemy_list in hits.items():
    for enemy in enemy_list:
        score += enemy.SCORE
```

**체력이 있는 적이라면 `dokillB=False` 로 두고 직접 처리합니다.**

```python
hits = pygame.sprite.groupcollide(bullets, enemies, True, False)

for bullet, enemy_list in hits.items():
    for enemy in enemy_list:
        if enemy.take_damage(bullet.damage):    # 죽었으면 True
            score += enemy.SCORE
```

### 원형 충돌 — 더 정확한 판정

사각형 판정은 둥근 객체에서 **모서리가 안 닿았는데 충돌**로 판정됩니다.

```
   ┌─────┐
   │ ●   │  ← 실제로는 안 닿았는데
   └───┬─┘     사각형은 겹침
       │ ●
```

**해결 — `collide_circle` 을 씁니다.**

```python
# 스프라이트에 radius 속성이 있으면 그것을 사용
self.radius = self.rect.width // 2

hits = pygame.sprite.spritecollide(player, enemies, False,
                                   pygame.sprite.collide_circle)
```

| 판정 함수 | 특징 |
|---|---|
| (기본) | 사각형. 빠름 |
| `collide_circle` | 원. `radius` 속성 필요 |
| `collide_mask` | 픽셀 단위. 가장 정확하지만 느림 |
| `collide_rect_ratio(0.7)` | 사각형을 70%로 줄여 판정 |

> **실무 요령** — 슈팅게임에서는 `collide_rect_ratio(0.7)` 정도가 무난합니다.
> 플레이어의 판정 범위를 실제 그림보다 작게 하면 "억울한 죽음"이 줄어 체감이 좋아집니다.

### 점수·목숨 관리

```python
class GameStats:
    """게임 전체 상태를 담당합니다."""

    def __init__(self, lives=3):
        self.score = 0
        self.lives = lives
        self.max_lives = lives
        self.kills = 0
        self.high_score = 0

    def add_score(self, amount):
        self.score += amount
        self.high_score = max(self.high_score, self.score)

    def lose_life(self):
        """목숨을 하나 잃습니다. 게임 오버면 True."""
        self.lives -= 1
        return self.lives <= 0

    @property
    def is_game_over(self):
        return self.lives <= 0
```

> **게임 상태를 클래스로 묶는 이유** — 점수·목숨·킬 수가 전역변수로 흩어지면 어디서 바뀌는지 추적이 안 됩니다.
> 하나의 객체에 모아 두면 저장·불러오기도 쉽습니다. ([Day 035](day-035.md)의 랭킹)

### HUD 그리기

**HUD(Head-Up Display)** 는 게임 화면 위에 겹쳐 표시하는 정보입니다.

```python
def draw_hud(surface, stats, player, font):
    # 점수 (왼쪽 위)
    surface.blit(font.render(f"SCORE {stats.score:>7,}", True, WHITE), (12, 10))

    # 목숨 (오른쪽 위) — 아이콘으로 표시
    for i in range(stats.lives):
        x = SCREEN_WIDTH - 30 - i * 26
        pygame.draw.circle(surface, RED, (x, 20), 8)

    # 체력 바 (왼쪽 아래)
    ratio = player.hp / player.max_hp
    pygame.draw.rect(surface, GRAY, (12, SCREEN_HEIGHT - 32, 200, 18))
    pygame.draw.rect(surface, GREEN if ratio > 0.3 else RED,
                     (12, SCREEN_HEIGHT - 32, int(200 * ratio), 18))
    pygame.draw.rect(surface, WHITE, (12, SCREEN_HEIGHT - 32, 200, 18), 2)
```

> **HUD 는 `Group.draw()` 다음에** 그려야 합니다. 그래야 게임 객체 위에 겹쳐 보입니다.
> 그리기 순서 = 화면에 쌓이는 순서입니다.

### 충돌 처리 순서

```python
# ① 총알 ↔ 적
# ② 플레이어 ↔ 적
# ③ 플레이어 ↔ 아이템
```

> **순서가 중요합니다.** ②를 먼저 하면, 이번 프레임에 총알로 죽을 적에게도 피해를 입습니다.
> **"공격이 먼저, 피격이 나중"** 이 플레이어에게 유리하고 자연스럽습니다.

## ④ 단계별 실습

### Step 1. 기본 충돌 판정

`collision_v1.py` 를 만들어 실행합니다.

```python
import pygame

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

BG = (18, 20, 30)
WHITE = (240, 240, 240)
BLUE = (52, 152, 219)
RED = (231, 76, 60)
GREEN = (46, 204, 113)

pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 024 - 충돌 판정 이해")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

# 마우스를 따라다니는 사각형
player_rect = pygame.Rect(0, 0, 80, 80)

# 고정된 사각형들
targets = [
    pygame.Rect(150, 150, 100, 100),
    pygame.Rect(400, 200, 120, 80),
    pygame.Rect(600, 380, 90, 140),
]

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    player_rect.center = pygame.mouse.get_pos()

    # 충돌 검사
    hit_indices = player_rect.collidelistall(targets)

    screen.fill(BG)

    for i, t in enumerate(targets):
        color = RED if i in hit_indices else GREEN
        pygame.draw.rect(screen, color, t, 4)
        screen.blit(font.render(f"#{i}", True, WHITE), (t.x + 6, t.y + 6))

    pygame.draw.rect(screen, BLUE, player_rect, 3)

    # 겹침 조건을 눈으로 확인
    if targets:
        t = targets[0]
        conds = [
            f"player.right({player_rect.right}) > target.left({t.left}) : "
            f"{player_rect.right > t.left}",
            f"player.left({player_rect.left}) < target.right({t.right}) : "
            f"{player_rect.left < t.right}",
            f"player.bottom({player_rect.bottom}) > target.top({t.top}) : "
            f"{player_rect.bottom > t.top}",
            f"player.top({player_rect.top}) < target.bottom({t.bottom}) : "
            f"{player_rect.top < t.bottom}",
            "",
            f"→ colliderect = {player_rect.colliderect(t)}   (#0 기준)",
            f"현재 충돌 중인 사각형: {hit_indices}",
        ]
        for i, line in enumerate(conds):
            screen.blit(font.render(line, True, WHITE), (12, SCREEN_HEIGHT - 170 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

**마우스를 움직이며 네 조건이 어떻게 바뀌는지 보세요.** 네 개가 전부 `True` 일 때만 충돌입니다.

### Step 2. 총알 ↔ 적 충돌

```python
import pygame
import random

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

BG = (18, 20, 30)
WHITE = (240, 240, 240)
GRAY = (60, 62, 75)
GREEN = (46, 204, 113)
RED = (231, 76, 60)
YELLOW = (241, 196, 15)


# ══════════ Surface ══════════
def make_ship(size, color):
    s = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(s, color, [(size // 2, 0), (size, size),
                                   (size // 2, size * 0.78), (0, size)])
    pygame.draw.circle(s, YELLOW, (size // 2, size // 2), size // 7)
    return s


def make_circle(size, color):
    s = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(s, color, (size // 2, size // 2), size // 2)
    pygame.draw.circle(s, (20, 20, 30), (size // 3, size // 3), size // 10)
    pygame.draw.circle(s, (20, 20, 30), (size * 2 // 3, size // 3), size // 10)
    return s


# ══════════ 클래스 ══════════
class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y, damage=1):
        super().__init__()
        self.image = pygame.Surface((6, 18), pygame.SRCALPHA)
        pygame.draw.rect(self.image, YELLOW, (0, 0, 6, 18), border_radius=3)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.damage = damage

    def update(self):
        self.pos_y -= 12
        self.rect.centery = int(self.pos_y)
        if self.rect.bottom < 0:
            self.kill()


class Enemy(pygame.sprite.Sprite):
    HP = 1
    SPEED = 2.0
    SCORE = 10
    SIZE = 36
    COLOR = RED

    def __init__(self, x, y):
        super().__init__()
        self.image = make_circle(self.SIZE, self.COLOR)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)
        self.hp = self.HP
        self.max_hp = self.HP
        self.radius = self.SIZE // 2          # 원형 충돌용

    def update(self):
        self.pos_y += self.SPEED
        self.rect.centery = int(self.pos_y)
        if self.rect.top > SCREEN_HEIGHT:
            self.kill()

    def take_damage(self, amount):
        """피해를 입습니다. 죽으면 True."""
        self.hp -= amount
        if self.hp <= 0:
            self.kill()
            return True
        return False

    def draw_hp_bar(self, surface):
        if self.max_hp <= 1:
            return
        w = self.rect.width
        pygame.draw.rect(surface, GRAY, (self.rect.left, self.rect.top - 8, w, 5))
        pygame.draw.rect(surface, GREEN,
                         (self.rect.left, self.rect.top - 8,
                          int(w * self.hp / self.max_hp), 5))

    @classmethod
    def spawn(cls):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)


class TankEnemy(Enemy):
    HP = 5
    SPEED = 1.0
    SCORE = 50
    SIZE = 54
    COLOR = (155, 89, 182)


class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = make_ship(44, (52, 152, 219))
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.shoot_timer = 0

    def shoot(self):
        if self.shoot_timer > 0:
            return None
        self.shoot_timer = 10
        return Bullet(self.rect.centerx, self.rect.top)

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT]:
            dx -= 1
        if keys[pygame.K_RIGHT]:
            dx += 1
        if keys[pygame.K_UP]:
            dy -= 1
        if keys[pygame.K_DOWN]:
            dy += 1
        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length
        self.pos_x += dx * 6
        self.pos_y += dy * 6

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 024 - 총알과 적 충돌")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 70)
all_sprites = pygame.sprite.Group(player)
bullets = pygame.sprite.Group()
enemies = pygame.sprite.Group()

score = 0
kills = 0
shots = 0
hits = 0
spawn_timer = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # ── 스폰 ──
    spawn_timer += 1
    if spawn_timer >= 45:
        spawn_timer = 0
        cls = TankEnemy if random.random() < 0.25 else Enemy
        e = cls.spawn()
        all_sprites.add(e)
        enemies.add(e)

    # ── 입력 ──
    keys = pygame.key.get_pressed()
    player.handle_input(keys)

    if keys[pygame.K_SPACE]:
        b = player.shoot()
        if b:
            all_sprites.add(b)
            bullets.add(b)
            shots += 1

    all_sprites.update()

    # ── 충돌: 총알 ↔ 적 ──
    # 총알은 사라지고(True), 적은 체력 처리를 위해 남긴다(False)
    collisions = pygame.sprite.groupcollide(bullets, enemies, True, False)

    for bullet, enemy_list in collisions.items():
        hits += 1
        for enemy in enemy_list:
            if enemy.take_damage(bullet.damage):
                score += enemy.SCORE
                kills += 1

    # ── 그리기 ──
    screen.fill(BG)
    all_sprites.draw(screen)

    for e in enemies:
        e.draw_hp_bar(screen)

    accuracy = (hits / shots * 100) if shots else 0
    info = [
        f"점수: {score:,}",
        f"처치: {kills}마리",
        f"발사 {shots} / 명중 {hits}  (명중률 {accuracy:.1f}%)",
        f"화면: 총알 {len(bullets)} · 적 {len(enemies)}",
        "",
        "SPACE=발사   방향키=이동",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, WHITE), (12, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
print(f"최종 점수 {score:,} · 처치 {kills}마리")
```

> **`groupcollide(bullets, enemies, True, False)`** 의 인자 순서를 기억하세요.
> `dokillA=True` (총알은 맞으면 사라짐) / `dokillB=False` (적은 체력이 있으므로 직접 처리).
>
> **보라색 탱커는 총알 5발**을 맞아야 죽습니다. 체력 바가 줄어드는 것을 확인하세요.

### Step 3. 완성된 게임 시스템 (오늘의 종합 예제)

Step 2에 플레이어 피격·목숨·아이템·HUD를 추가합니다.
(`Bullet`, `Enemy`, `TankEnemy`, `make_ship`, `make_circle` 은 Step 2와 동일하게 사용합니다)

```python
INVINCIBLE_FRAMES = 90


class GameStats:
    """점수·목숨·통계를 관리합니다."""

    def __init__(self, lives=3):
        self.score = 0
        self.lives = lives
        self.max_lives = lives
        self.kills = 0
        self.shots = 0
        self.hits = 0
        self.combo = 0
        self.max_combo = 0

    def add_kill(self, enemy):
        self.kills += 1
        self.combo += 1
        self.max_combo = max(self.max_combo, self.combo)
        # 콤보 보너스 — 10콤보마다 배율 증가
        multiplier = 1 + self.combo // 10
        self.score += enemy.SCORE * multiplier

    def reset_combo(self):
        self.combo = 0

    def lose_life(self):
        """목숨을 잃습니다. 게임 오버면 True."""
        self.lives -= 1
        self.reset_combo()
        return self.lives <= 0

    @property
    def accuracy(self):
        return (self.hits / self.shots * 100) if self.shots else 0.0

    @property
    def is_game_over(self):
        return self.lives <= 0


class HealItem(pygame.sprite.Sprite):
    """먹으면 체력을 회복하는 아이템."""

    SIZE = 26
    HEAL = 30

    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((self.SIZE, self.SIZE), pygame.SRCALPHA)

                           (self.SIZE // 2, self.SIZE // 2), self.SIZE // 2)

        self.rect = self.image.get_rect(center=(x, y))
        self.pos_y = float(y)

    def update(self):
        self.pos_y += 1.6
        self.rect.centery = int(self.pos_y)
        if self.rect.top > SCREEN_HEIGHT:
            self.kill()

    @classmethod
    def spawn(cls):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)


class Player(pygame.sprite.Sprite):
    MAX_HP = 100

    def __init__(self, x, y):
        super().__init__()
        self.image_normal = make_ship(44, (52, 152, 219))
        self.image_hit = make_ship(44, RED)
        self.image = self.image_normal
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)

        self._hp = Player.MAX_HP
        self.max_hp = Player.MAX_HP
        self.invincible_timer = 0
        self.shoot_timer = 0
        self.radius = 16                     # 실제 그림보다 작게 (관대한 판정)

    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, min(value, self.max_hp))

    @property
    def is_invincible(self):
        return self.invincible_timer > 0

    def take_damage(self, amount):
        if self.is_invincible:
            return False
        self.hp -= amount
        self.invincible_timer = INVINCIBLE_FRAMES
        return True

    def revive(self):
        """목숨을 잃은 뒤 부활합니다."""
        self.hp = self.max_hp
        self.invincible_timer = INVINCIBLE_FRAMES * 2
        self.pos_x = float(SCREEN_WIDTH // 2)
        self.pos_y = float(SCREEN_HEIGHT - 70)

    def shoot(self):
        if self.shoot_timer > 0:
            return None
        self.shoot_timer = 10
        return Bullet(self.rect.centerx, self.rect.top)

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT]:
            dx -= 1
        if keys[pygame.K_RIGHT]:
            dx += 1
        if keys[pygame.K_UP]:
            dy -= 1
        if keys[pygame.K_DOWN]:
            dy += 1
        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length
        self.pos_x += dx * 6
        self.pos_y += dy * 6

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1
        if self.invincible_timer > 0:
            self.invincible_timer -= 1

        self.image = (self.image_hit
                      if self.is_invincible and (self.invincible_timer // 6) % 2 == 0
                      else self.image_normal)

        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)
```

## ⑤ 자주 하는 실수

### `groupcollide` 반환값을 리스트로 착각

```python
hits = pygame.sprite.groupcollide(bullets, enemies, True, True)
for enemy in hits:
    score += enemy.SCORE          # enemy 가 아니라 bullet 임!
```

**원인** — `groupcollide` 는 **딕셔너리**를 반환합니다. `{A스프라이트: [B스프라이트들]}`
`for x in 딕셔너리` 는 **키**(= A그룹의 스프라이트)를 꺼냅니다.

**해결**

```python
for bullet, enemy_list in hits.items():
    for enemy in enemy_list:
        score += enemy.SCORE
```

### `dokill` 인자 순서를 헷갈림

```python
pygame.sprite.groupcollide(bullets, enemies, False, True)
# 총알이 안 사라지고 적만 사라짐 → 총알 하나가 여러 적을 뚫음
```

**해결** — `groupcollide(A, B, dokillA, dokillB)` 순서를 기억하세요.
관통 총알을 의도한 게 아니라면 `(True, ...)` 입니다.

### 체력 있는 적을 `dokill=True` 로 처리

```python
hits = pygame.sprite.groupcollide(bullets, enemies, True, True)
```

**증상** — HP 5짜리 탱커도 **총알 한 발에 죽습니다.**
**해결** — `dokillB=False` 로 두고 `take_damage()` 로 직접 처리합니다.

### 충돌 순서를 반대로

```python
# ① 플레이어 ↔ 적
# ② 총알 ↔ 적
```

**증상** — 총알로 죽일 적에게도 피해를 입습니다. 억울한 느낌이 듭니다.
**해결** — 공격을 먼저 처리합니다.

### 무적 시간 없이 피해 처리

```python
if pygame.sprite.spritecollide(player, enemies, False):
    player.hp -= 25          # 1초에 60번!
```

**해결** — `take_damage()` 안에서 무적 타이머를 확인합니다. ([Day 021](day-021.md))

### `collide_circle` 을 쓰는데 `radius` 가 없음

```python
pygame.sprite.spritecollide(player, enemies, False, pygame.sprite.collide_circle)
```

```
AttributeError: 'Enemy' object has no attribute 'radius'
```

**해결** — 두 쪽 모두 `self.radius` 를 정의해야 합니다.

> `radius` 가 없으면 pygame이 `rect` 에서 자동 계산하기도 하지만, 명시하는 편이 안전하고 조절도 쉽습니다.

### HUD를 `Group.draw()` 앞에 그림

```python
draw_hud(screen, ...)

```

**해결** — 그리기 순서는 **배경 → 게임 객체 → HUD → 오버레이** 입니다.


**증상** — 게임 오버 화면 뒤에서 적이 계속 내려오고 스폰됩니다.

```python
class PierceBullet(Bullet):
    """최대 3마리를 관통하는 총알."""

    MAX_PIERCE = 3

    def __init__(self, x, y, damage=1):
        super().__init__(x, y, damage)
        self.image = pygame.Surface((10, 24), pygame.SRCALPHA)
        pygame.draw.rect(self.image, (155, 89, 182), (0, 0, 10, 24), border_radius=4)
        self.rect = self.image.get_rect(center=(x, y))
        self.pierce_left = PierceBullet.MAX_PIERCE
        self.hit_enemies = set()          # 같은 적을 두 번 맞히지 않게

    def on_hit(self, enemy):
        """적을 맞혔을 때 호출합니다. 관통이 끝나면 kill()."""
        if id(enemy) in self.hit_enemies:
            return False                  # 이미 맞힌 적

        self.hit_enemies.add(id(enemy))
        self.pierce_left -= 1

        if self.pierce_left <= 0:
            self.kill()

        return True
```

- `isinstance` 로 종류를 나눴지만, **더 좋은 설계는 부모 `Bullet` 에도 `on_hit()` 을 두고 오버라이딩**하는 것입니다.

```python
INVINCIBLE_FRAMES = 90          # 1.5초


class Player(pygame.sprite.Sprite):
    def __init__(self, ...):
        ...
        self.invincible_timer = 0

    @property
    def is_invincible(self):
        return self.invincible_timer > 0

    def take_damage(self, amount):
        """무적 중이면 무시하고 False 를 반환합니다."""
        if self.is_invincible:
            return False

        self.hp -= amount
        self.invincible_timer = INVINCIBLE_FRAMES
        return True

    def revive(self):
        """부활 — 더 긴 무적을 줍니다."""
        self.hp = self.max_hp
        self.invincible_timer = INVINCIBLE_FRAMES * 2
        self.pos_x = float(SCREEN_WIDTH // 2)
        self.pos_y = float(SCREEN_HEIGHT - 70)

    def update(self):
        if self.invincible_timer > 0:
            self.invincible_timer -= 1
        ...


# ── 게임 루프에서 ──
hit = pygame.sprite.spritecollide(player, enemies, False)

        else:
```

**추가로 고려할 것 세 가지**

| 항목 | 이유 |
|---|---|
| **부활 시 무적을 더 길게** | 부활 지점에 적이 있으면 즉사 반복 |
| **부활 시 위치 초기화** | 적 무리 한가운데서 부활하면 불공평 |
| **깜빡임 표시** | 무적 상태임을 플레이어가 알아야 함 |

> **교훈** — **매 프레임 실행되는 코드에서 상태를 바꿀 때는 반드시 "얼마나 자주 일어나야 하는가"를 생각하세요.**
> 총알 발사(쿨타임), 적 스폰(간격), 피격(무적) — 전부 같은 문제이고 같은 해법(타이머)입니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 원리 | 네 조건이 모두 참일 때 사각형 겹침 |
| `colliderect` | Rect 대 Rect |
| `collidepoint` | 점이 안에 있나 (버튼 클릭) |
| `spritecollide(s, group, dokill)` | 하나 대 그룹 → **리스트** |
| `groupcollide(A, B, killA, killB)` | 그룹 대 그룹 → **딕셔너리** |
| 체력 있는 적 | `dokillB=False` + `take_damage()` |
| `collide_circle` | 원형 판정. `radius` 속성 필요 |
| 판정 관대하게 | `radius` 를 그림보다 작게 |
| 충돌 순서 | ① 총알↔적 ② 플레이어↔적 ③ 아이템 |
| 그리기 순서 | 배경 → 객체 → HUD → 오버레이 |

**오늘 반드시 기억할 세 가지**
> ① `groupcollide` 는 **딕셔너리**를 반환합니다. `for a, b_list in hits.items():`
> ② 체력이 있는 적은 `dokill=False` 로 두고 직접 처리하세요.
> ③ 매 프레임 일어나는 피해에는 **반드시 무적 시간**이 필요합니다.
