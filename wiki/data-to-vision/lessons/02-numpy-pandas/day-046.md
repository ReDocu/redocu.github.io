## ② 왜 필요한가

어제까지 numpy 로 데이터를 다뤘습니다. 그런데 불편한 점이 있었습니다.

```python
SCORE, KILLS, SHOTS, HITS = 0, 1, 2, 3          # 열 번호를 외워야 함
data[:, SCORE].mean()
data[data[:, STAGE] == 3][:, SCORE].mean()      # 읽기 어려움
```

**문제 4가지**

| 문제 | 설명 |
|---|---|
| 열 이름이 없음 | `data[:, 2]` 가 무슨 열인지 코드만 봐서는 모름 |
| 자료형이 하나 | 이름(문자열)과 점수(정수)를 한 배열에 못 담음 |
| 결측치 처리 없음 | 빈 값을 표현할 방법이 마땅치 않음 |
| CSV 읽기가 번거로움 | 헤더 처리, 자료형 변환을 직접 해야 함 |

**pandas 는 이 넷을 전부 해결합니다.**

```python
df["score"].mean()
df[df["stage"] == 3]["score"].mean()
df.groupby("stage")["score"].mean()      # 한 줄!
```

> **pandas 는 numpy 위에 "이름"과 "자료형 혼합"을 얹은 것**입니다.
> 내부는 여전히 numpy 배열이라, 어제까지 배운 것이 전부 그대로 쓰입니다.

**앞으로 pandas 를 쓰지 않는 날이 없습니다.**
데이터 수집(W11) → 전처리(W12) → 시각화(W13) → 머신러닝(대단원 03·04) 전부 DataFrame 이 중심입니다.

## ③ 개념 설명

### Series — 1차원 (값 + 인덱스)

```python
import pandas as pd

s = pd.Series([85, 92, 78], index=["국어", "영어", "수학"])
```

```
국어    85
영어    92
수학    78
dtype: int64
```

| 구성 | 설명 |
|---|---|
| **값(values)** | numpy 배열 |
| **인덱스(index)** | 각 값의 이름표. 지정 안 하면 0, 1, 2… |
| **이름(name)** | Series 자체의 이름 (선택) |

```python
s.values         # array([85, 92, 78])   ← numpy 배열!
s.index          # Index(['국어', '영어', '수학'])
s["영어"]         # 92     이름으로 접근
s[1]             # 92     위치로도 접근 (비권장)
s.mean()         # 85.0
```

> **Series 는 "이름표가 붙은 numpy 배열"** 입니다.
> numpy 의 모든 연산이 그대로 됩니다. `s * 1.1`, `s[s > 80]` 전부 동작합니다.

### DataFrame — 2차원 (표)

**Series 여러 개를 열로 붙인 것**입니다.

```
        index    name   score  stage
          0      홍길동    85      3
          1      김철수    92      5
          2      이영희    78      2
                  ↑        ↑      ↑
              Series   Series  Series
```

```python
df = pd.DataFrame({
    "name": ["홍길동", "김철수", "이영희"],
    "score": [85, 92, 78],
    "stage": [3, 5, 2],
})
```

| 속성 | 설명 |
|---|---|
| `df.shape` | `(행, 열)` |
| `df.columns` | 열 이름 목록 |
| `df.index` | 행 인덱스 |
| `df.dtypes` | 열별 자료형 |
| `df.values` | numpy 2차원 배열 |

**열마다 자료형이 다를 수 있습니다.** numpy 와의 결정적 차이입니다.

```python
df.dtypes
# name     object     ← 문자열
# score     int64
# stage     int64
```

> **`object`** 는 pandas 에서 문자열(또는 혼합 타입)을 뜻합니다.

### DataFrame 만드는 방법 5가지

```python
# ① 딕셔너리 (가장 흔함) — 키가 열 이름
pd.DataFrame({"name": ["A", "B"], "score": [85, 92]})

# ② 딕셔너리 리스트 — 각 딕셔너리가 한 행
pd.DataFrame([
    {"name": "A", "score": 85},
    {"name": "B", "score": 92},
])

# ③ 2차원 리스트 + 열 이름
pd.DataFrame([["A", 85], ["B", 92]], columns=["name", "score"])

# ④ numpy 배열
pd.DataFrame(np.random.rand(3, 4), columns=list("ABCD"))

# ⑤ Series 여러 개
pd.DataFrame({"score": s1, "rank": s2})
```

> **②번(딕셔너리 리스트)이 실전에서 중요합니다.**
> JSON API 응답, 크롤링 결과가 정확히 이 형태입니다. ([Day 052](day-052.md), [Day 055](day-055.md))
> ```python
> results = [{"title": "...", "price": 1000}, ...]
> df = pd.DataFrame(results)          # 바로 표가 됨
> ```

### 파일 읽기

```python
pd.read_csv("data.csv")
pd.read_excel("data.xlsx")
pd.read_json("data.json")
pd.read_sql("SELECT * FROM scores", conn)
pd.read_html("https://...")[0]          # 웹페이지의 표
pd.read_clipboard()                      # 클립보드 (엑셀에서 복사)
```

**`read_csv` 주요 옵션**

| 옵션 | 설명 |
|---|---|
| `encoding="utf-8"` / `"cp949"` | **인코딩** |
| `sep=","` / `"\t"` | 구분자 |
| `header=0` / `None` | 헤더 행 위치 |
| `names=[...]` | 열 이름 직접 지정 |
| `index_col=0` | 특정 열을 인덱스로 |
| `usecols=["a","b"]` | 필요한 열만 |
| `nrows=1000` | 앞 n행만 (대용량 탐색) |
| `skiprows=3` | 앞 n행 건너뛰기 |
| `na_values=["없음","-"]` | 결측으로 볼 값 |
| `dtype={"code": str}` | 자료형 지정 |
| `parse_dates=["date"]` | 날짜로 변환 |
| `thousands=","` | 천 단위 구분 기호 제거 |

### 인코딩 — 한글 깨짐의 원인

| 인코딩 | 쓰는 곳 |
|---|---|
| `utf-8` | 국제 표준. 대부분의 웹·프로그램 |
| `utf-8-sig` | UTF-8 + BOM. **엑셀에서 저장한 CSV** |
| `cp949` / `euc-kr` | **한국 공공기관 데이터**, 옛 Windows |

**증상별 진단**

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xb0
→ cp949 파일을 utf-8 로 읽으려 함 → encoding="cp949"

첫 열 이름이 "ï»¿이름" 처럼 보임
→ BOM 이 붙은 파일 → encoding="utf-8-sig"

한글이 "ë°ì´í°" 처럼 깨짐
→ utf-8 파일을 cp949 로 읽음 → encoding="utf-8"
```

**안전한 읽기 함수**

```python
def read_csv_safe(path, **kwargs):
    """여러 인코딩을 순서대로 시도합니다."""
    for enc in ("utf-8-sig", "utf-8", "cp949", "euc-kr"):
        try:
            df = pd.read_csv(path, encoding=enc, **kwargs)
            print(f"[안내] '{enc}' 로 읽었습니다.")
            return df
        except UnicodeDecodeError:
            continue
    raise ValueError(f"인코딩을 찾을 수 없습니다: {path}")
```

### 파일 쓰기

```python
df.to_csv("out.csv", index=False, encoding="utf-8-sig")
df.to_excel("out.xlsx", index=False, sheet_name="결과")
df.to_json("out.json", orient="records", force_ascii=False, indent=2)
df.to_sql("scores", conn, if_exists="replace", index=False)
```

| 옵션 | 이유 |
|---|---|
| **`index=False`** | 인덱스를 열로 저장하지 않음 (안 쓰면 `Unnamed: 0` 열이 생김) |
| **`encoding="utf-8-sig"`** | **엑셀에서 한글이 안 깨짐** |
| `force_ascii=False` | JSON 에서 한글을 그대로 |

> **저장할 때는 `index=False` 와 `encoding="utf-8-sig"` 를 습관적으로 쓰세요.**
> 이 둘을 빠뜨려서 생기는 문제가 정말 많습니다.

### 인덱스

```python
df.index                              # 현재 인덱스
df.set_index("name")                  # 열을 인덱스로
df.reset_index()                      # 인덱스를 열로 되돌림
df.reset_index(drop=True)             # 인덱스를 버리고 0부터 다시
```

> **인덱스를 언제 쓰나** — 시계열 데이터(날짜를 인덱스로)나 조회가 잦은 키가 있을 때.
> 일반적인 분석에서는 **기본 정수 인덱스로 두는 편이 단순**합니다.

### Step 2. CSV 읽고 쓰기 — 인코딩 문제 해결

```python
from pathlib import Path

import pandas as pd

DATA_DIR = Path("data")
DATA_DIR.mkdir(exist_ok=True)

df = pd.DataFrame({
    "이름": ["홍길동", "김철수", "이영희", "박민수"],
    "부서": ["개발팀", "영업팀", "개발팀", "인사팀"],
    "점수": [85, 92, 78, 88],
    "입사일": ["2020-03-15", "2019-07-01", "2021-01-10", "2018-11-20"],
})

print("=" * 62)
print("              CSV 인코딩 실험")
print("=" * 62)
print(f"\n원본 데이터")
print(df)

# ── 여러 인코딩으로 저장 ──
files = {
    "utf-8-sig": DATA_DIR / "test_utf8sig.csv",     # 엑셀 호환 (권장)
    "utf-8":     DATA_DIR / "test_utf8.csv",
    "cp949":     DATA_DIR / "test_cp949.csv",       # 옛 Windows·공공데이터
}

print(f"\n[저장]")
for enc, path in files.items():
    df.to_csv(path, index=False, encoding=enc)
    print(f"  {enc:<12} → {path.name:<22} {path.stat().st_size:>4} bytes")


# ── 안전하게 읽는 함수 ──
def read_csv_safe(path, verbose=True, **kwargs):
    """여러 인코딩을 순서대로 시도해 읽습니다."""
    encodings = ("utf-8-sig", "utf-8", "cp949", "euc-kr")

    for enc in encodings:
        try:
            result = pd.read_csv(path, encoding=enc, **kwargs)
            if verbose:
                print(f"  ✓ '{enc}' 로 성공")
            return result
        except UnicodeDecodeError:
            if verbose:
                print(f"  ✗ '{enc}' 실패")
            continue

    raise ValueError(f"인코딩을 찾을 수 없습니다: {path}")


print(f"\n[읽기 — 자동 감지]")
for enc, path in files.items():
    print(f"\n  {path.name}:")
    loaded = read_csv_safe(path)
    print(f"    열 이름: {list(loaded.columns)}")


# ── 잘못된 인코딩으로 읽으면 ──
print(f"\n[잘못된 인코딩으로 읽으면]")

try:
    pd.read_csv(files["cp949"], encoding="utf-8")
except UnicodeDecodeError as e:
    print(f"  cp949 파일을 utf-8 로:")
    print(f"    UnicodeDecodeError: {str(e)[:70]}...")
    print(f"    → encoding='cp949' 로 해결")

broken = pd.read_csv(files["utf-8"], encoding="cp949", encoding_errors="replace")
print(f"\n  utf-8 파일을 cp949 로 (강제):")
print(f"    열 이름: {list(broken.columns)}   ← 깨짐")


# ── index=False 를 빠뜨리면 ──
print(f"\n[index=False 실험]")

with_index = DATA_DIR / "with_index.csv"
df.to_csv(with_index, encoding="utf-8-sig")              # index=False 없음

loaded = pd.read_csv(with_index, encoding="utf-8-sig")
print(f"  index=False 없이 저장 → 열: {list(loaded.columns)}")
print(f"    ← 'Unnamed: 0' 이라는 쓸모없는 열이 생김")

without_index = DATA_DIR / "without_index.csv"
df.to_csv(without_index, index=False, encoding="utf-8-sig")
loaded2 = pd.read_csv(without_index, encoding="utf-8-sig")
print(f"  index=False 로 저장   → 열: {list(loaded2.columns)}   ✓")


# ── 유용한 옵션들 ──
print(f"\n[읽기 옵션 활용]")

partial = pd.read_csv(without_index, encoding="utf-8-sig",
                      usecols=["이름", "점수"], nrows=2)
print(f"  usecols + nrows:")
print(partial.to_string(index=False))

with_dates = pd.read_csv(without_index, encoding="utf-8-sig",
                         parse_dates=["입사일"])
print(f"\n  parse_dates 사용:")
print(f"    입사일 dtype = {with_dates['입사일'].dtype}   ← datetime 으로!")
print(f"    2020년 이후 입사: {(with_dates['입사일'].dt.year >= 2020).sum()}명")

# ── 정리 ──
```

**해결 — 인코딩을 자동 감지하는 함수**

```python
from pathlib import Path

import pandas as pd

ENCODINGS = ("utf-8-sig", "utf-8", "cp949", "euc-kr", "latin1")


def read_csv_safe(path, verbose=True, **kwargs):
    """
    여러 인코딩을 순서대로 시도해 CSV 를 읽습니다.

    path    : 파일 경로
    verbose : 시도 과정 출력 여부
    kwargs  : pd.read_csv 에 그대로 전달
    """
    path = Path(path)

    if not path.exists():
        raise FileNotFoundError(f"파일이 없습니다: {path}")

    errors = []

    for enc in ENCODINGS:
        try:
            df = pd.read_csv(path, encoding=enc, **kwargs)

            # 깨진 문자가 많으면 잘못된 인코딩일 가능성
            if _looks_broken(df):
                errors.append(f"{enc}: 문자가 깨진 것으로 보임")
                continue

            if verbose:
                print(f"[안내] '{enc}' 인코딩으로 읽었습니다. "
                      f"({len(df)}행 × {len(df.columns)}열)")
            return df

        except UnicodeDecodeError as e:
            errors.append(f"{enc}: {str(e)[:50]}")
        except Exception as e:
            errors.append(f"{enc}: {type(e).__name__}")

    raise ValueError(
        f"'{path.name}' 을 읽을 수 없습니다.\n  " + "\n  ".join(errors)
    )


def _looks_broken(df, threshold=0.3):
    """열 이름에 깨진 문자가 많으면 True."""
    cols = "".join(str(c) for c in df.columns)
    if not cols:
        return False

    # 한글·영문·숫자·일반 기호가 아닌 문자의 비율
    weird = sum(1 for ch in cols
                if not (ch.isalnum() or ch.isspace() or ch in "_-()[]/.,%"))
    return weird / len(cols) > threshold


# ══════════ 사용 ══════════
if __name__ == "__main__":
    # 테스트 파일 만들기
    Path("data").mkdir(exist_ok=True)
    sample = pd.DataFrame({
        "지역명": ["서울특별시", "부산광역시", "대구광역시"],
        "인구수": [9411440, 3349016, 2385412],
        "면적": [605.2, 770.1, 883.5],
    })

        df = read_csv_safe(p)

    # 옵션과 함께 사용
    print(f"\n[옵션 전달]")
    df = read_csv_safe(p_cp949, usecols=["지역명", "인구수"], verbose=False)
    print(df.to_string(index=False))

    # 실제 공공데이터에 유용한 옵션 조합

        path,
        thousands=",",                    # 1,234,567 → 1234567
        na_values=["-", "없음", "해당없음", "N/A", ""],
        dtype={"우편번호": str,             # 앞자리 0 보존

        parse_dates=["기준일자"],

    for p in (p_cp949, p_utf8):
```

**3.** 아래 코드에 문제가 4가지 있습니다. 찾아서 고치세요.

```python
import pandas as pd

df = pd.read_csv("sales.csv")

df.total = df.price * df.quantity

top = df[df.total > 100000]
top["grade"] = "VIP"

df.to_csv("result.csv")
```

<details>
<summary>답 보기</summary>

**문제 4가지**

**① `encoding` 미지정**

한글 CSV 면 `UnicodeDecodeError` 가 나거나 깨집니다.

**② `df.total = ...` 로 새 열을 만들 수 없음**

`df.속성 = 값` 은 **DataFrame 의 속성**을 만들 뿐, 열이 생기지 않습니다.

```python
df.total = df.price * df.quantity
print(df.columns)          # total 이 없음!
print("total" in df)       # False
```

파이썬은 경고도 없이 통과시켜 발견이 늦습니다.

**③ `SettingWithCopyWarning`**

```python
top = df[df.total > 100000]      # 복사본인지 뷰인지 모호
top["grade"] = "VIP"             # 경고 발생
```

**④ `index=False` 와 `encoding` 미지정**

`Unnamed: 0` 열이 생기고, 엑셀에서 한글이 깨집니다.

**추가 문제 ⑤ — `df.price` 접근 방식**

동작은 하지만, 열 이름에 공백이 있거나 메서드 이름과 겹치면 실패합니다.

**해결**

```python
from pathlib import Path

import pandas as pd

# ── ① 인코딩 명시 + 유용한 옵션 ──
df = pd.read_csv(
    "sales.csv",
    encoding="utf-8-sig",              # 안 되면 cp949
    thousands=",",                     # "1,200" → 1200
    na_values=["-", "없음", "N/A"],
)

# ── ② 대괄호로 새 열 생성 ──
df["total"] = df["price"] * df["quantity"]

# ── ③ 명시적 복사 ──
top = df[df["total"] > 100_000].copy()
top["grade"] = "VIP"

# ── ④ index=False + encoding ──
df.to_csv("result.csv", index=False, encoding="utf-8-sig")
top.to_csv("vip.csv", index=False, encoding="utf-8-sig")

print(f"전체 {len(df)}건, VIP {len(top)}건")
```

**②번을 직접 확인해 보세요**

```python
import pandas as pd

df = pd.DataFrame({"price": [100, 200], "quantity": [3, 5]})

# 잘못된 방식
df.total = df["price"] * df["quantity"]
print(f"df.total       = {list(df.total)}   ← 값은 있음")
print(f"'total' in df  = {'total' in df}   ← 하지만 열이 아님!")
print(f"df.columns     = {list(df.columns)}")
print(f"df.to_csv 하면 total 이 저장되지 않습니다")

# 올바른 방식
df["total"] = df["price"] * df["quantity"]
print(f"\ndf['total'] 로 만들면")

print(f"df.columns     = {list(df.columns)}")
```

> **결론 — pandas 4가지 습관**
>
> ① 읽기: `encoding` 을 **항상 명시**
> ② 열 접근·생성: **`df["col"]`** (점 표기 금지)
> ③ 필터링 후 수정: **`.copy()`**
> ④ 저장: **`index=False, encoding="utf-8-sig"`**
>
> 이 4가지만 지켜도 pandas 관련 문제의 절반이 사라집니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| Series | 1차원 — **값 + 인덱스** · 내부는 numpy 배열 |
| DataFrame | 2차원 표 — Series 여러 개 · **열마다 dtype 다름** |
| 생성 | 딕셔너리(열 중심) · **딕셔너리 리스트**(행 중심, API/크롤링) |
| 읽기 | `pd.read_csv/excel/json/sql/html` |
| **인코딩** | `utf-8-sig`(엑셀) · **`cp949`(공공데이터)** |
| 저장 | **`index=False, encoding="utf-8-sig"`** |
| 열 접근 | **`df["col"]`** — `df.col` 은 새 열 생성 불가 |
| 필터 후 수정 | **`.copy()`** — `SettingWithCopyWarning` 방지 |
| 자료형 유지 | `dtype={"우편번호": str}` — 앞자리 0 보존 |

**오늘 반드시 기억할 세 가지**
> ① 공공데이터 CSV 는 대부분 **`cp949`**, 엑셀 호환 저장은 **`utf-8-sig`**.
> ② 새 열은 **`df["col"] = ...`** — `df.col = ...` 은 열이 안 생깁니다.
> ③ 저장할 때 **`index=False`** 를 빠뜨리면 `Unnamed: 0` 이 생깁니다.
