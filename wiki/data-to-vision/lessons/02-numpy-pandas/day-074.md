## ③ 개념 설명

## 1부 · 발표용 그래프 5종

### 발표 그래프의 조건

| | EDA 그래프 | **발표 그래프** |
|---|---|---|
| 목적 | 내가 이해하려고 | **남을 이해시키려고** |
| 개수 | 많이 | **5~7개** |
| 설명 | 없어도 됨 | **제목이 결론** |
| 완성도 | 대충 | **완성** |

### 제목이 결론이어야 합니다

```
❌ "카테고리별 분포"          ← 무엇을 그렸는지
✅ "역세권의 54%가 음식점"     ← 무엇을 알게 됐는지
```

> **발표에서 그래프를 띄우고 "보시면 아시겠지만..."이라고 시작하면 안 됩니다.**
> **제목만 읽어도 요점이 전달**돼야 합니다.

### 5종 구성 — 이야기 순서로

```
① 데이터 개요      "이런 데이터를 모았습니다"
② 핵심 발견 1      "역세권은 음식점 편중입니다"
③ 핵심 발견 2      "무료 비율이 카테고리마다 다릅니다"
④ 설계 근거        "그래서 이 기준으로 정했습니다"
⑤ 결과            "이렇게 추천됩니다"
```

> **그래프 순서가 곧 발표 순서**입니다.
> 발표 대본을 먼저 쓰고 그래프를 배치하는 편이 빠릅니다.

## 2부 · 지도 2종

| 지도 | 목적 | 구성 |
|---|---|---|
| **전체 분포** | "이런 데이터입니다" | 클러스터 + 히트맵 + 역 |
| **추천 결과** | "이렇게 추천됩니다" | 순위 마커 + 도보권 + 경로 |

```python
# 레이어로 켜고 끄기
folium.LayerControl(collapsed=False).add_to(m)
```

> **발표 중에는 레이어를 하나씩 켜면서 설명**하면 효과적입니다.
> "전체는 이렇고... 역 주변만 보면... 추천 결과는 여기입니다"

## 3부 · 추천 구현

### 어제 설계대로 구현

```python
design = json.loads(Path("docs/recommend_design.json").read_text())

WEIGHTS = {k: v["가중치"] for k, v in design["지표"].items()}
DIVERSITY = design["다양성"]["강도"]
```

> **설계 문서를 코드가 읽게 하면** 설계와 구현이 어긋나지 않습니다.

### 결측 지표 처리 — 어제 남긴 숙제

```
is_free 채움률 62% → 38%가 가성비 점수를 못 받음
```

| 방법 | 효과 |
|---|---|
| `fillna(0)` | 결측이 **불리해짐** ❌ |
| **`fillna(0.5)`** | **중립** ✅ |
| 가중치 재분배 | 결측인 행만 다른 지표 비중을 높임 |

```python
# 중립값으로 채우고 플래그 유지
score_value = df["is_free"].astype(float).fillna(0.5)
```

### 검증 3가지

```
① 결과가 조건을 지키는가     필터 위반 0건
② 다양성이 확보되는가        카테고리 종류 / k
③ 상위권이 납득되는가        눈으로 확인 ⭐
```

> **③번을 반드시 하세요.**
> 1위가 이상한 곳이면 **점수 설계가 잘못된 것**입니다.
> 숫자가 맞아도 사람이 보기에 이상하면 그건 틀린 겁니다.

### Step 1. 발표용 그래프 5종

```python
"""output/figures/ — 발표용 그래프."""

import json
import platform
from pathlib import Path

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                              else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

FIG_DIR = Path("output/figures")
FIG_DIR.mkdir(parents=True, exist_ok=True)

OKABE = ["#0072B2", "#E69F00", "#009E73", "#CC79A7", "#56B4E9", "#D55E00"]
GRAY = "#cbd5e1"

df = pd.read_parquet("data/processed/analysis_table.parquet")
design = json.loads(Path("docs/recommend_design.json").read_text(encoding="utf-8"))

WALK_LIMIT = 20
SOURCE_NOTE = f"데이터: TourAPI · n={len(df):,}건 · 수집 2026-08-09"


def clean(ax, grid="y"):
    for s in ("top", "right"):
        ax.spines[s].set_visible(False)
    ax.tick_params(length=0)
    ax.grid(True, axis=grid, alpha=0.25, linestyle="--")
    ax.set_axisbelow(True)
    return ax


def save(fig, name, note=SOURCE_NOTE):
    fig.text(0.99, 0.005, note, ha="right", fontsize=9, color="#94a3b8")
    path = FIG_DIR / name
    fig.savefig(path, dpi=150, bbox_inches="tight", facecolor="white")
    plt.close(fig)
    return path


print("=" * 78)
print("                     발표용 그래프 제작")
print("=" * 78)

# ══════════════════════════════════════════
#  ① 데이터 개요
# ══════════════════════════════════════════
fig, axes = plt.subplots(1, 3, figsize=(17, 4.8), layout="constrained")

# 카테고리
ax = axes[0]
cat = df["category"].value_counts().sort_values()
ax.barh(cat.index, cat.values, color=OKABE[0])
for i, v in enumerate(cat.values):
    ax.text(v + 12, i, f"{v:,}", va="center", fontsize=9)
ax.set_title("카테고리 구성", loc="left", fontweight="bold")
ax.set_xlabel("개수 (곳)")
clean(ax, grid="x")

# 요금 정보 확보
ax = axes[1]
conf = df["fee_confidence"].value_counts()
LABEL = {"exact": "숫자 명시", "free": "무료 명시", "unknown": "정보 없음"}
colors = {"숫자 명시": OKABE[2], "무료 명시": OKABE[0], "정보 없음": GRAY}
labels = [LABEL.get(c, c) for c in conf.index]
bars = ax.bar(labels, conf.values,
              color=[colors.get(l, OKABE[0]) for l in labels],
              edgecolor="white")
for bar, v in zip(bars, conf.values):
    ax.text(bar.get_x() + bar.get_width()/2, v + 14,
            f"{v:,}\n{v/len(df)*100:.0f}%", ha="center", fontsize=9)
ax.set_title("요금 정보 확보 수준", loc="left", fontweight="bold")
ax.set_ylabel("개수 (곳)")
ax.set_ylim(0, conf.max() * 1.28)
clean(ax)

# 도보 시간
ax = axes[2]
walk = df["walk_min"].dropna()
ax.hist(walk[walk <= 120], bins=40, color=OKABE[0],
        edgecolor="white", linewidth=0.5)
ax.axvline(WALK_LIMIT, color=OKABE[5], linestyle="--", linewidth=2,
           label=f"{WALK_LIMIT}분 ({(walk<=WALK_LIMIT).mean()*100:.0f}%)")
ax.set_title("최근접 역까지 도보 시간", loc="left", fontweight="bold")
ax.set_xlabel("도보 시간 (분)")
ax.set_ylabel("개수")
ax.legend(fontsize=9)
clean(ax)

fig.suptitle(f"① 부산 관광지 {len(df):,}곳 — "
             f"요금 정보는 62%, 도보 20분 이내는 29%",
             fontsize=15, fontweight="bold")
p1 = save(fig, "fig1_overview.png")
print(f"\n  ✓ {p1.name}")

# ══════════════════════════════════════════
#  ② 핵심 발견 1 — 역세권 편중
# ══════════════════════════════════════════
near = df[df["walk_min"] <= WALK_LIMIT]

cat_all = df["category"].value_counts(normalize=True) * 100
cat_near = near["category"].value_counts(normalize=True) * 100
comp = pd.DataFrame({"전체": cat_all, "역세권": cat_near}).fillna(0)
comp["차이"] = comp["역세권"] - comp["전체"]
comp = comp.sort_values("차이", ascending=False)

fig, axes = plt.subplots(1, 2, figsize=(14, 5.2), layout="constrained")

ax = axes[0]
x = np.arange(len(comp))
w = 0.38
ax.bar(x - w/2, comp["전체"], w, label="전체", color=GRAY, edgecolor="white")
ax.bar(x + w/2, comp["역세권"], w, label=f"도보 {WALK_LIMIT}분 이내",
       color=OKABE[0], edgecolor="white")
ax.set_xticks(x)
ax.set_xticklabels(comp.index, rotation=15, ha="right")
ax.set_title("카테고리 구성 비교", loc="left", fontweight="bold")
ax.set_ylabel("비중 (%)")
ax.legend(fontsize=9)
clean(ax)

ax = axes[1]
colors = [OKABE[0] if v > 0 else OKABE[5] for v in comp["차이"]]
bars = ax.barh(comp.index, comp["차이"], color=colors)
ax.axvline(0, color="#334155", linewidth=1.2)
for bar, v in zip(bars, comp["차이"]):
    offset = 0.6 if v > 0 else -0.6
    ax.text(v + offset, bar.get_y() + bar.get_height()/2,
            f"{v:+.1f}%p", va="center",
            ha="left" if v > 0 else "right", fontsize=9)
ax.set_title("역세권 편중 정도", loc="left", fontweight="bold")
ax.set_xlabel("역세권 비중 − 전체 비중 (%p)")
ax.set_xlim(comp["차이"].min() - 5, comp["차이"].max() + 5)
clean(ax, grid="x")

top = comp.index[0]
fig.suptitle(f"② 역세권의 {comp['역세권'].iloc[0]:.0f}%가 {top} — "
             f"접근성만으로 추천하면 식당 목록이 된다",
             fontsize=15, fontweight="bold")
p2 = save(fig, "fig2_accessibility.png")
print(f"  ✓ {p2.name}")

# ══════════════════════════════════════════
#  ③ 핵심 발견 2 — 카테고리별 무료율
# ══════════════════════════════════════════
known = df[df["is_free"].notna()].copy()
known["is_free"] = known["is_free"].astype(bool)

free_stat = known.groupby("category").agg(
    전체=("id", "count"), 무료=("is_free", "sum"))
free_stat["무료율"] = free_stat["무료"] / free_stat["전체"] * 100
free_stat = free_stat.sort_values("무료율")

fig, axes = plt.subplots(1, 2, figsize=(14, 5.2), layout="constrained")

ax = axes[0]
bars = ax.barh(free_stat.index, free_stat["무료율"],
               color=[OKABE[i % len(OKABE)] for i in range(len(free_stat))])
for bar, (v, n) in zip(bars, zip(free_stat["무료율"], free_stat["전체"])):
    ax.text(v + 1.5, bar.get_y() + bar.get_height()/2,
            f"{v:.0f}%  (n={n})", va="center", fontsize=9)
ax.set_title("카테고리별 무료 비율", loc="left", fontweight="bold")
ax.set_xlabel("무료 비율 (%)")
ax.set_xlim(0, 118)
clean(ax, grid="x")

ax = axes[1]
sns.boxplot(data=df[df["price"].notna() & (df["price"] > 0)],
            x="category", y="price", color=OKABE[0], ax=ax,
            showfliers=False,
            order=[c for c in free_stat.index
                   if c in df["category"].unique()])
ax.set_title("유료 시설의 가격 분포 (n=198)", loc="left", fontweight="bold")
ax.set_xlabel("")
ax.set_ylabel("입장료 (원)")
ax.yaxis.set_major_formatter(
    mpl.ticker.FuncFormatter(lambda v, p: f"{v:,.0f}"))
plt.setp(ax.get_xticklabels(), rotation=15, ha="right")
clean(ax)

fig.suptitle(f"③ 무료 비율이 카테고리마다 "
             f"{free_stat['무료율'].max()-free_stat['무료율'].min():.0f}%p 차이 — "
             f"가격 대신 '무료 여부'를 지표로",
             fontsize=15, fontweight="bold")
p3 = save(fig, "fig3_category.png")
print(f"  ✓ {p3.name}")

# ══════════════════════════════════════════
#  ④ 설계 근거 — 기준 결정
# ══════════════════════════════════════════
fig, axes = plt.subplots(1, 3, figsize=(17, 4.8), layout="constrained")

# 도보 기준별 후보 수
ax = axes[0]
minutes = [10, 15, 20, 25, 30, 45]
counts = [int((walk <= m).sum()) for m in minutes]
colors = [OKABE[0] if m == WALK_LIMIT else GRAY for m in minutes]
bars = ax.bar([f"{m}분" for m in minutes], counts, color=colors,
              edgecolor="white")
for bar, v in zip(bars, counts):
    ax.text(bar.get_x() + bar.get_width()/2, v + 16,
            f"{v:,}\n{v/len(df)*100:.0f}%", ha="center", fontsize=8)
ax.axhline(100, color=OKABE[5], linestyle=":", linewidth=1.5,

ax.set_ylim(0, max(counts) * 1.25)
ax.legend(fontsize=8)
clean(ax)

# 상관 히트맵
ax = axes[1]
corr_cols = [c for c in ("walk_min", "info_score", "price")
             if c in df.columns]
corr = df[corr_cols].corr()
mask = np.triu(np.ones_like(corr, dtype=bool))
sns.heatmap(corr, mask=mask, annot=True, fmt=".2f", cmap="RdBu_r",
            center=0, vmin=-1, vmax=1, square=True, linewidths=0.6,
            cbar_kws={"label": "r", "shrink": 0.7}, ax=ax)
ax.set_title("지표 간 상관 (독립성 확인)", loc="left", fontweight="bold")

# 가중치
ax = axes[2]
weights = {k: v["가중치"] for k, v in design["지표"].items()}

ax.set_xlabel("가중치")

clean(ax, grid="x")

fig.suptitle("④ 도보 20분·독립 지표 3종·다양성 보정 — 설계 근거",

```python
"""src/recommend.py — 어제 설계대로 구현."""

import json
from dataclasses import dataclass, field
from pathlib import Path

import numpy as np
import pandas as pd

DESIGN = json.loads(Path("docs/recommend_design.json")
                    .read_text(encoding="utf-8"))

WEIGHTS = {k: v["가중치"] for k, v in DESIGN["지표"].items()}
DIVERSITY = DESIGN["다양성"]["강도"]
WALK_LIMIT = 20

EARTH_R = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))
    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlng/2)**2
    return 2 * EARTH_R * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


def recommend(df, categories=None, walk_limit=WALK_LIMIT,
              free_only=False, origin=None, max_km=None,
              k=5, diversity=DIVERSITY, weights=None, verbose=False):
    """
    부산 관광지를 추천합니다. (Day 073 설계 기준)

    반환: DataFrame(rank, score, reason, ...) — 비어 있을 수 있음
    """
    weights = weights or WEIGHTS
    total = sum(weights.values())
    weights = {k_: v / total for k_, v in weights.items()}

    relaxations = []

    # ══════════ 필터 ══════════
    def build(walk=walk_limit, use_cat=True, use_free=True):
        pool = df[df["lat"].notna() & df["lng"].notna()].copy()

        if categories and use_cat:
            pool = pool[pool["category"].isin(categories)]

        if free_only and use_free:
            pool = pool[pool["is_free"] == True]        # noqa: E712

        if walk is not None:
            pool = pool[pool["walk_min"] <= walk]

        if origin is not None:
            pool["_distance"] = haversine(origin[0], origin[1],
                                          pool["lat"], pool["lng"])
            if max_km:
                pool = pool[pool["_distance"] <= max_km]

        return pool

    pool = build()

    # ══════════ 완화 ══════════
    RELAX = [
        (dict(walk=30), "도보 30분 완화"),
        (dict(walk=45), "도보 45분 완화"),
        (dict(walk=45, use_free=False), "무료 조건 해제"),
        (dict(walk=45, use_free=False, use_cat=False), "카테고리 해제"),
    ]

    for kwargs, label in RELAX:
        if len(pool) >= k:
            break
        wider = build(**kwargs)
        if len(wider) > len(pool):
            pool, _ = wider, relaxations.append(label)

    if pool.empty:
        return pd.DataFrame()

    # ══════════ 점수 ══════════
    pool = pool.copy()

    # ① 접근성 — 가까울수록 좋음
    pool["_s_accessibility"] = 1 - pool["walk_min"].rank(pct=True)

    # ② 가성비 — 무료가 좋음. 결측은 중립(0.5) ⭐
    pool["_s_value"] = pool["is_free"].astype("float").fillna(0.5)

    # ③ 정보 충실도
    pool["_s_info"] = pool["info_score"].rank(pct=True)

    # ④ 다양성 보너스 — 희소 카테고리에 가점
    cat_share = pool["category"].map(
        pool["category"].value_counts(normalize=True))
    pool["_s_diversity_bonus"] = 1 - cat_share.rank(pct=True)

    pool["score"] = sum(pool[f"_s_{key}"] * w for key, w in weights.items()
                        if f"_s_{key}" in pool.columns)

    # ══════════ MMR ══════════
    if diversity > 0 and len(pool) > k:
        selected, remaining = [], pool.sort_values("score", ascending=False)

        while len(selected) < k and len(remaining):
            if not selected:
                pick = remaining.index[0]
            else:
                used = {pool.loc[i, "category"] for i in selected}
                penalty = remaining["category"].isin(used).astype(float)
                pick = ((1 - diversity) * remaining["score"]
                        - diversity * penalty * 0.35).idxmax()
            selected.append(pick)
            remaining = remaining.drop(pick)

        items = pool.loc[selected].copy()
    else:
        items = pool.nlargest(k, "score").copy()

    # ══════════ 이유 ══════════
    LABEL = {"accessibility": "역에서 가까움", "value": "무료",
             "info": "정보 충실", "diversity_bonus": "희소 카테고리"}

    def reason(row):
        contrib = {key: row.get(f"_s_{key}", 0) * w
                   for key, w in weights.items()}
        top2 = sorted(contrib, key=contrib.get, reverse=True)[:2]

        parts = []
        for key in top2:
            if key == "accessibility":
                parts.append(f"도보 {row['walk_min']:.0f}분")
            elif key == "value":
                parts.append("무료" if row.get("is_free") is True
                             else "요금 정보 없음")
            else:
                parts.append(LABEL.get(key, key))
        return " · ".join(parts)

    items["reason"] = items.apply(reason, axis=1)
    items["rank"] = range(1, len(items) + 1)
    items["relaxed"] = ", ".join(relaxations)
    items["pool_size"] = len(pool)

    if verbose:
        print(f"  후보 {len(pool)}곳 → 추천 {len(items)}곳"
              + (f" (완화: {', '.join(relaxations)})" if relaxations else ""))

    return items

def validate_recommendation(df, recommend_fn, k=5, verbose=True):
    """추천 결과가 설계를 지키는지 검증합니다."""
    SCENARIOS = [
        ("기본", dict()),

        ("관광지·문화시설", dict(categories=["관광지", "문화시설"])),
        ("도보 10분", dict(walk_limit=10)),
        ("부산역 3km", dict(origin=(35.1152, 129.0423), max_km=3)),
        ("까다로움", dict(categories=["레포츠"], free_only=True,
                          walk_limit=10)),
    ]

    results, issues = [], []

    if verbose:
        print("=" * 82)
        print("                        추천 결과 검증")
        print("=" * 82)
        print(f"\n  {'시나리오':<20}{'후보':>7}{'추천':>6}{'카테고리':>9}"
              f"{'다양성':>8}{'완화':>6}")
        print("  " + "-" * 60)

    for label, params in SCENARIOS:
        r = recommend_fn(df, k=k, **params)

        if r.empty:
            issues.append(("치명", f"'{label}' 결과 0건"))
            if verbose:
                print(f"  {label:<20}{'-':>7}{'0':>6}{'-':>9}{'-':>8}{'-':>6}")
            continue

        n_cat = r["category"].nunique()
        div = n_cat / len(r)
        relaxed = bool(r["relaxed"].iloc[0])

        results.append({"시나리오": label, "후보": r["pool_size"].iloc[0],
                        "추천": len(r), "카테고리": n_cat,
                        "다양성": round(div, 2), "완화": relaxed})

        if verbose:
            print(f"  {label:<20}{r['pool_size'].iloc[0]:>7,}{len(r):>6}"
                  f"{n_cat:>9}{div:>8.2f}{'✓' if relaxed else '-':>6}")

        # ── 조건 준수 검증 ──
        if not relaxed:
            if params.get("categories"):
                bad = ~r["category"].isin(params["categories"])
                if bad.any():
                    issues.append(("치명", f"'{label}' 카테고리 조건 위반 "
                                           f"{bad.sum()}건"))

            if params.get("free_only"):
                bad = r["is_free"] != True                # noqa: E712
                if bad.any():
                    issues.append(("치명", f"'{label}' 무료 조건 위반 "
                                           f"{bad.sum()}건"))

            walk_lim = params.get("walk_limit", WALK_LIMIT)
            bad = r["walk_min"] > walk_lim
            if bad.any():
                issues.append(("치명", f"'{label}' 도보 조건 위반 {bad.sum()}건"))

        # ── 결과 무결성 ──
        if not r["score"].is_monotonic_decreasing:
            issues.append(("치명", f"'{label}' 점수가 내림차순이 아님"))
        if r["id"].duplicated().any():
            issues.append(("치명", f"'{label}' 중복 항목"))
        if div < 0.6 and len(r) >= 3:
            issues.append(("경고", f"'{label}' 다양성 {div:.2f} — "
                                   f"카테고리 편중"))

    # ══════════ 상세 출력 ══════════
    if verbose:
        print(f"\n{'━' * 82}")
        print("  [기본 시나리오 상세]")
        print("━" * 82)

        r = recommend_fn(df, k=k)

        print(f"\n  {'#':<3}{'이름':<22}{'분류':<9}{'도보':>7}"
              f"{'요금':>10}{'점수':>8}")
        print("  " + "-" * 62)
        for _, row in r.iterrows():
            fee = ("무료" if row.get("is_free") is True
                   else ("정보없음" if pd.isna(row.get("is_free"))
                         else f"{row.get('price', 0):,.0f}원"))
            print(f"  {row['rank']:<3}{str(row['name'])[:20]:<22}"
                  f"{row['category']:<9}{row['walk_min']:>6.0f}분"
                  f"{fee:>10}{row['score']:>8.3f}")

        print(f"\n  [추천 이유]")
        for _, row in r.iterrows():
            print(f"    {row['rank']}. {row['name'][:22]} — {row['reason']}")

        # ── 눈으로 확인 ──
        print(f"\n  [👀 눈으로 확인]")
        print(f"    · 1위가 납득되는 곳인가?")
        print(f"    · 5곳이 서로 다른 성격인가? "
              f"(카테고리 {r['category'].nunique()}종)")
        print(f"    · 실제로 갈 만한 곳인가?")

        # ── 판정 ──
        fatal = sum(1 for l, _ in issues if l == "치명")

        print(f"\n{'=' * 82}")

              f"   (치명 {fatal} · 경고 {len(issues)-fatal})")
        print("=" * 82)

            print(f"  {'🔴' if level == '치명' else '🟡'} {msg}")

        print("=" * 82)

    return {"passed": all(l != "치명" for l, _ in issues),
            "issues": issues, "results": pd.DataFrame(results)}

## 1. 질문

> **부산을 처음 방문하는 20대 뚜벅이(대중교통 이용자)에게,

**왜 이 질문인가**

- 접근성 + 가성비를 결합한 추천은 흔하지 않다

**세부 질문 3가지**

| # | 질문 | 답 |
|---|---|---|
| 1 | 역세권 관광지는 어떤 성격인가? | **음식점에 편중** (54.3%) |
| 2 | 요금 정보로 가성비를 판단할 수 있나? | **가격은 13.5%뿐, 무료 여부는 61.8%** |
| 3 | 접근성과 시설 품질은 관련이 있나? | **거의 무관** (r=-0.08) |

### 3-1. 전처리

`src/preprocess.py` 의 `preprocess()` 함수 (7단계, 멱등성 확인 완료)

| 단계 | 처리 | 근거 |
|---|---|---|
| 문자열 정제 | 유니코드 NFC · 보이지 않는 문자 제거 | 크롤링 데이터 관행 |
| **요금 파싱** | 텍스트 → (가격, 무료여부, 신뢰도) | 채움률 13.5% → 61.8% |
| 중복 제거 | `id` + (이름+좌표 반올림) | 52건 제거 |
| 이상치 | 한반도 좌표 범위 위반 → NaN | 5건 |
| 결측 | **채우지 않고 플래그** | "정보 없음" ≠ "무료" |
| 파생 | 도보 시간 = 거리 ÷ 4km/h × 60 | 성인 평균 보행 속도 |

- 숙박·축제 카테고리 (당일 방문 대상이 아님)
- 좌표 결측 3건
- `station_km` (도보 시간과 파생 관계, r=1.00)

### 3-2. 추천 점수

| 지표 | 가중치 | 원천 | 근거 |
|---|---|---|---|
| 접근성 | **0.40** | 도보 시간 (역순위) | 프로젝트의 차별점. '뚜벅이'가 타깃 |
| 가성비 | **0.30** | 무료 여부 | 가격 채움률 13.5%로 사용 불가 |
| 정보 충실도 | **0.20** | 이미지·전화 보유 | 평점 데이터 없어 대체 |
| 다양성 보너스 | **0.10** | 카테고리 희소성 | 역세권 음식점 54.3% 편중 상쇄 |

**정규화** — 순위 기반(`rank(pct=True)`).
도보 시간의 왜도가 크고, Min-Max 는 극단값에 취약하기 때문.

**결측 처리** — `is_free` 결측(38%)은 **중립값 0.5** 로 처리.
0으로 채우면 정보가 없다는 이유로 불이익을 받게 된다.

**다양성** — MMR(강도 0.4). 이미 뽑힌 카테고리에 감점.

**1.** 오늘 만든 산출물이 발표에 쓸 수 있는 상태인지 점검하세요.

```python
"""발표 산출물 최종 점검."""

import re
from pathlib import Path

import matplotlib.pyplot as plt
import pandas as pd


def audit_deliverables(fig_dir="output/figures", map_dir="output/maps",
                       report="output/report.md", verbose=True):
    """발표 산출물의 완성도를 점검합니다."""
    issues = []
    line = "=" * 80

    if verbose:
        print(line)
        print("                      발표 산출물 최종 점검")
        print(line)

    # ══════════ ① 그래프 ══════════
    figs = sorted(Path(fig_dir).glob("*.png")) if Path(fig_dir).exists() else []

    if verbose:
        print(f"\n[① 그래프]  {len(figs)}개")
        print(f"  {'파일':<30}{'크기':>10}{'해상도':>14}  판정")
        print("  " + "-" * 62)

    for p in figs:
        size_kb = p.stat().st_size / 1024

        try:
            img = plt.imread(p)
            h, w = img.shape[:2]
            res = f"{w}×{h}"
            ok_res = w >= 1200
        except Exception:
            res, ok_res = "?", False

        mark = "✓" if (size_kb > 30 and ok_res) else "⚠"

        if verbose:
            print(f"  {mark} {p.name:<28}{size_kb:>8,.0f}KB{res:>14}")

        if size_kb < 30:
            issues.append(("경고", f"{p.name} 파일이 작음 — 내용 확인"))
        if not ok_res:
            issues.append(("경고", f"{p.name} 해상도 부족 — dpi=150 이상"))

    if len(figs) < 5:
        issues.append(("치명", f"그래프 {len(figs)}개 — 5개 이상 필요"))

    # ══════════ ② 지도 ══════════
    maps = sorted(Path(map_dir).glob("*.html")) if Path(map_dir).exists() else []

    if verbose:
        print(f"\n[② 지도]  {len(maps)}개")
        print(f"  {'파일':<30}{'크기':>10}{'마커':>8}{'요소':>18}")
        print("  " + "-" * 66)

    for p in maps:
        size_kb = p.stat().st_size / 1024
        html = p.read_text(encoding="utf-8")

        markers = (len(re.findall(r"L\.marker\(", html))
                   + len(re.findall(r"L\.circleMarker\(", html)))

        elements = []
        if "bindTooltip" in html:
            elements.append("툴팁")
        if "bindPopup" in html:
            elements.append("팝업")
        if "L.control.layers" in html:
            elements.append("레이어")
        if "position:fixed" in html or "position: fixed" in html:
            elements.append("배너")

        mark = "✓" if size_kb < 3000 and markers > 0 else "⚠"

        if verbose:
            print(f"  {mark} {p.name:<28}{size_kb:>8,.0f}KB{markers:>8,}"
                  f"{'·'.join(elements):>18}")

        if size_kb > 3000:
            issues.append(("경고", f"{p.name} {size_kb/1024:.1f}MB — "
                                   f"열기 느림. 클러스터 검토"))
        if markers == 0:
            issues.append(("치명", f"{p.name} 마커 없음"))
        if "bindTooltip" not in html:
            issues.append(("경고", f"{p.name} 툴팁 없음"))

    if len(maps) < 1:
        issues.append(("치명", "지도가 없음"))

    # ══════════ ③ 보고서 ══════════
    report_path = Path(report)

    if verbose:
        print(f"\n[③ 보고서]")

    if not report_path.exists():
        issues.append(("치명", "보고서 파일 없음"))
        if verbose:
            print(f"  ✗ {report} 없음")
    else:
        text = report_path.read_text(encoding="utf-8")

        SECTIONS = {
            "질문": r"##\s*\d*\.?\s*질문",
            "데이터": r"##\s*\d*\.?\s*데이터",
            "방법": r"##\s*\d*\.?\s*방법",
            "결과": r"##\s*\d*\.?\s*결과",
            "한계": r"##\s*\d*\.?\s*한계",
        }

        if verbose:
            print(f"  분량: {len(text.splitlines())}줄 · {len(text):,}자")
            print(f"  섹션:")

        for name, pattern in SECTIONS.items():
            found = bool(re.search(pattern, text))
            if verbose:
                print(f"    {'✓' if found else '✗'} {name}")
            if not found:
                issues.append(("치명", f"보고서에 '{name}' 섹션 없음"))

        # 그래프 참조
        refs = re.findall(r"!\[.*?\]\((.*?)\)", text)
        broken = [r for r in refs
                  if not (report_path.parent / r).exists()]

        if verbose:
            print(f"  그래프 참조: {len(refs)}개"
                  + (f" (깨진 링크 {len(broken)}개)" if broken else ""))

        if len(refs) < 3:
            issues.append(("경고", f"보고서에 그래프 {len(refs)}개만 참조"))
        if broken:
            issues.append(("치명", f"깨진 이미지 링크 {len(broken)}개: "
                                   f"{broken[:2]}"))

        # 발견 개수
        findings = len(re.findall(r"###\s*발견", text))
        if verbose:
            print(f"  발견: {findings}개")
        if findings < 3:
            issues.append(("경고", f"발견 {findings}개 — 3개 이상 권장"))

        # 한계 개수
        limit_section = re.split(r"##\s*\d*\.?\s*한계", text)
        if len(limit_section) > 1:
            n_limits = len(re.findall(r"^\|\s*\d+\s*\|",
                                      limit_section[1], re.M))
            n_limits = max(n_limits,
                           len(re.findall(r"^[-*]\s", limit_section[1], re.M)))
            if verbose:
                print(f"  한계: {n_limits}개")
            if n_limits < 3:
                issues.append(("경고", f"한계 {n_limits}개 — 3개 이상 권장"))

        # 숫자 근거
        numbers = len(re.findall(r"\d[\d,.]*\s*(?:%|건|곳|분|원|배|%p)", text))
        if verbose:
            print(f"  숫자 근거: {numbers}개")
        if numbers < 15:
            issues.append(("경고", f"숫자 근거 {numbers}개 — "
                                   f"정성적 서술이 많음"))

    # ══════════ ④ 결과 데이터 ══════════
    result_csv = Path("output/recommend_result.csv")

    if verbose:
        print(f"\n[④ 추천 결과]")

    if result_csv.exists():
        r = pd.read_csv(result_csv)
        if verbose:
            print(f"  ✓ {result_csv.name} — {len(r)}건")
            print(f"    카테고리 {r['category'].nunique()}종 "
                  f"(다양성 {r['category'].nunique()/len(r):.2f})")
    else:
        issues.append(("경고", "추천 결과 CSV 없음"))
        if verbose:
            print(f"  ✗ 없음")

    # ══════════ 결과 ══════════
    fatal = sum(1 for l, _ in issues if l == "치명")
    warn = sum(1 for l, _ in issues if l == "경고")
    score = max(0, 100 - fatal * 20 - warn * 6)

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 발표 준비 완료" if score >= 85
                 else "🟡 보완 필요" if score >= 65 else "❌ 미완성")
        print(f"  완성도: {score}점 / 100   {grade}")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} {msg}")

        if not issues:
            print("  문제 없음")

        print(f"\n  [내일(발표) 전 확인]")
        for item in [
            "지도 HTML 을 브라우저에서 실제로 열어 봤는가",
            "그래프의 한글이 깨지지 않는가",
            "추천 1위가 납득되는 곳인가 (검색해 봤는가)",
            "보고서의 이미지 링크가 전부 살아 있는가",
            "발표 시간(10분) 안에 다 설명할 수 있는가",
            "예상 질문 3개에 답할 준비가 됐는가",
        ]:
            print(f"    □ {item}")

        print(line)

    return {"score": score, "issues": issues}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    audit_deliverables()
