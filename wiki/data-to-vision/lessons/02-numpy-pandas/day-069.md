## ② 왜 필요한가

지금까지 이런 것들을 알아냈습니다.

```
· 무료 관광지의 평점이 0.14점 높다
· 8월에 방문객이 12월의 2.6배
· 제주가 인구 대비 관광지가 가장 많다
```

**그런데 사용자는 이렇게 묻습니다.**

```
"20대 커플이 부산에서 5만원 예산으로 갈 만한 곳 5개만 추천해 줘"
```

**분석 결과와 추천 사이에는 큰 간극이 있습니다.**

| | 분석 | 추천 |
|---|---|---|
| 출력 | "A가 B보다 높다" | **"이거 5개 가세요"** |
| 대상 | 전체 | **이 사용자** |
| 형태 | 통계·그래프 | **정렬된 목록** |
| 판단 | 사람이 함 | **시스템이 함** |

**추천은 결국 "점수를 매겨 정렬하는 일"** 입니다.

```
후보 3,000곳
   ↓ ① 조건 필터 (부산, 5만원 이하)  →  180곳
   ↓ ② 점수 계산 (평점·인기·가성비)   →  점수 부여
   ↓ ③ 정렬 후 상위 5개              →  추천 목록
```

> **오늘의 핵심 질문 두 가지**
> - **"무엇을 점수에 넣을 것인가"** (지표 선택)
> - **"각각을 얼마나 반영할 것인가"** (가중치)
>
> 이 두 가지에 **근거를 댈 수 있어야** 추천 시스템입니다.
> 근거 없이 숫자를 곱하면 그냥 임의의 정렬입니다.

## 1부 · 점수화

### 왜 정규화가 먼저인가

```
평점    : 1 ~ 5          (범위 4)
방문객  : 100 ~ 300,000  (범위 299,900)
가격    : 0 ~ 50,000     (범위 50,000)
```

**그냥 더하면 방문객이 전부를 결정합니다.**

```python
score = rating + visitors + price       # ❌ 방문객 하나로 순위가 결정됨
```

**같은 눈금으로 맞춘 뒤에 더해야 합니다.**

### 정규화 4가지

**① Min-Max — 0~1 로 압축**

```python
def minmax(s):
    span = s.max() - s.min()
    return (s - s.min()) / span if span else pd.Series(0.5, index=s.index)
```

```
[1, 2, 3, 100]  →  [0.00, 0.01, 0.02, 1.00]
```

| 장점 | 단점 |
|---|---|
| 직관적 (0~1) | **극단값 하나가 나머지를 뭉갬** |

**② Z-score — 평균 0, 표준편차 1**

```python
def zscore(s):
    return (s - s.mean()) / s.std() if s.std() else pd.Series(0.0, index=s.index)
```

| 장점 | 단점 |
|---|---|
| 분포를 반영 | 범위가 정해지지 않음 · 극단값에 약함 |

**③ 순위 기반 — 가장 안정적** ⭐

```python
def rank_norm(s):
    return s.rank(pct=True)          # 백분위 (0~1)
```

```
[1, 2, 3, 100]  →  [0.25, 0.50, 0.75, 1.00]
```

| 장점 | 단점 |
|---|---|
| **극단값에 완전히 강함** | 실제 값 차이가 사라짐 |

**④ 로버스트 — 백분위로 자른 뒤 Min-Max**

```python
def robust(s, lo=0.05, hi=0.95):
    a, b = s.quantile(lo), s.quantile(hi)
    return ((s.clip(a, b) - a) / (b - a)) if b > a else pd.Series(0.5, index=s.index)
```

| 방법 | 극단값 | 값 차이 보존 | 추천 |
|---|---|---|---|
| Min-Max | ❌ 약함 | ✅ | 분포가 고를 때 |
| Z-score | ❌ 약함 | ✅ | 정규분포일 때 |
| **순위** | ✅ **강함** | ❌ | **기본값** ⭐ |
| 로버스트 | ✅ 강함 | △ | 값 차이도 중요할 때 |

> **치우친 데이터(방문객·가격)에는 순위 기반**을 쓰세요. ([Day 057](day-057.md))

### 평점의 함정 — 리뷰 수 보정

```
A: 평점 5.0 (리뷰 1개)      ← 정말 최고인가?
B: 평점 4.5 (리뷰 1,000개)  ← 이쪽이 믿을 만함
```

**베이지안 평균**으로 보정합니다.

```python
def bayesian_rating(rating, count, m=50):
    """
    m : 신뢰를 얻는 데 필요한 리뷰 수 (사전 강도)
    """
    C = rating.mean()                    # 전체 평균
    return (count / (count + m)) * rating + (m / (count + m)) * C
```

```
리뷰 1개,   평점 5.0  →  4.02   (전체 평균 쪽으로 끌려감)
리뷰 1,000개, 평점 4.5  →  4.48   (거의 그대로)
```

> **`m` 은 "이 정도 리뷰가 쌓이면 믿는다"는 기준**입니다.
> 리뷰가 적은 곳은 전체 평균으로 끌어당겨집니다.

## 2부 · 필터와 랭킹

### 하드 조건 vs 소프트 조건

| | 하드(필터) | 소프트(점수) |
|---|---|---|

### 다양성 문제

```
추천 결과 TOP 5
1. 해운대 해수욕장   (자연)
2. 광안리 해수욕장   (자연)
3. 송정 해수욕장     (자연)
4. 다대포 해수욕장   (자연)
5. 송도 해수욕장     (자연)
```

**점수만으로 뽑으면 비슷한 것만 나옵니다.**

**MMR (Maximal Marginal Relevance)** — 점수와 다양성을 함께 봅니다.

```python
def mmr_select(df, k=5, lambda_=0.7, diversity_col="category"):
    """
    lambda_ : 1에 가까울수록 점수 중시, 0에 가까울수록 다양성 중시
    """
    selected = []
    pool = df.sort_values("score", ascending=False).copy()

    while len(selected) < k and len(pool):
        if not selected:
            pick = pool.index[0]
        else:
            chosen_cats = {df.loc[i, diversity_col] for i in selected}

            # 이미 뽑힌 카테고리면 감점
            penalty = pool[diversity_col].isin(chosen_cats).astype(float)
            mmr = lambda_ * pool["score"] - (1 - lambda_) * penalty

            pick = mmr.idxmax()

        selected.append(pick)
        pool = pool.drop(pick)

    return df.loc[selected]
```

## 3부 · 콘텐츠 기반 추천

**"이거랑 비슷한 곳"** 을 찾는 방식입니다.

### 자카드 유사도 — 집합 비교

```python
def jaccard(a, b):
    """두 집합의 유사도 (0~1)."""
    a, b = set(a), set(b)
    union = a | b
    return len(a & b) / len(union) if union else 0.0
```

```
A 태그: {자연, 바다, 산책}
B 태그: {자연, 바다, 야경}

교집합 2 / 합집합 4 = 0.5
```

### 코사인 유사도 — 벡터 비교

```python
import numpy as np

def cosine(a, b):
    """두 벡터의 각도 유사도 (0~1)."""
    na, nb = np.linalg.norm(a), np.linalg.norm(b)
    return float(a @ b / (na * nb)) if na and nb else 0.0
```

**특성 벡터 만들기**

## 4부 · 추천 검증

**"추천이 잘 되는가"를 어떻게 아나요?**

| 지표 | 의미 | 계산 |
|---|---|---|
| **커버리지** | 전체 중 몇 %가 추천될 수 있나 | 추천된 고유 항목 / 전체 |
| **다양성** | 결과가 얼마나 다양한가 | 카테고리 고유 수 / k |
| **인기 편향** | 유명한 것만 나오나 | 추천의 평균 인기 백분위 |
| **안정성** | 가중치를 바꾸면 결과가 뒤집히나 | 순위 상관 |
| **충족률** | 조건을 만족하는 결과가 나오나 | 0건 발생률 |

```python
def evaluate(recommend_fn, test_queries, df, k=5):
    recommended = set()
    diversities, popularities, empties = [], [], 0

    for q in test_queries:
        result = recommend_fn(df, **q, k=k)

        if result.empty:
            empties += 1
            continue

        recommended |= set(result["id"])
        diversities.append(result["category"].nunique() / len(result))
        popularities.append(result["_pop_pct"].mean())

    return {
        "커버리지": len(recommended) / len(df),
        "다양성": np.mean(diversities),
        "인기편향": np.mean(popularities),
        "결과없음": empties / len(test_queries),
    }
```

## ④ 단계별 실습

### Step 1. 정규화 방법 비교

```python
"""정규화 방법에 따라 순위가 어떻게 달라지나."""

from pathlib import Path

import numpy as np
import pandas as pd

OUT = Path("output")
OUT.mkdir(exist_ok=True)

# ── 실습 데이터 ──
rng = np.random.default_rng(42)
N = 800

SIDOS = ["서울특별시", "부산광역시", "제주특별자치도", "강원특별자치도",
         "경기도", "경상북도"]
CATEGORIES = ["자연", "역사", "체험", "쇼핑", "음식"]

df = pd.DataFrame({
    "id": range(1, N + 1),
    "name": [f"관광지{i:04d}" for i in range(1, N + 1)],
    "sido": rng.choice(SIDOS, N, p=[0.24, 0.16, 0.16, 0.14, 0.20, 0.10]),
    "category": rng.choice(CATEGORIES, N, p=[0.30, 0.24, 0.20, 0.14, 0.12]),
    "price": np.where(rng.random(N) < 0.25, 0,
                      rng.lognormal(8.6, 0.62, N).round(-2)),
    "visitors": rng.lognormal(8.4, 1.3, N).round(),
    "review_count": rng.negative_binomial(2, 0.02, N),
    "lat": rng.uniform(33.3, 38.3, N),
    "lng": rng.uniform(126.3, 129.4, N),
})

df["rating"] = np.clip(
    rng.normal(4.0, 0.5, N) + np.log1p(df["review_count"]) / 60, 1, 5).round(1)


# ══════════ 정규화 함수 ══════════

def minmax(s):
    span = s.max() - s.min()
    return (s - s.min()) / span if span else pd.Series(0.5, index=s.index)


def zscore(s):
    sd = s.std()
    return (s - s.mean()) / sd if sd else pd.Series(0.0, index=s.index)


def rank_norm(s):
    return s.rank(pct=True)


def robust(s, lo=0.05, hi=0.95):
    a, b = s.quantile(lo), s.quantile(hi)
    return (s.clip(a, b) - a) / (b - a) if b > a else pd.Series(0.5, index=s.index)


METHODS = {"minmax": minmax, "zscore": zscore,
           "rank": rank_norm, "robust": robust}

print("=" * 80)
print("                     정규화 방법 비교")
print("=" * 80)

col = "visitors"
s = df[col]

print(f"\n[원본: {col}]")
print(f"  최소 {s.min():,.0f} · 중앙값 {s.median():,.0f} · "
      f"최대 {s.max():,.0f}")
print(f"  왜도 {s.skew():.2f}  (심하게 치우침)")

print(f"\n[정규화 결과 분포]")
print(f"  {'방법':<10}{'최소':>9}{'25%':>9}{'중앙값':>9}"
      f"{'75%':>9}{'최대':>9}{'표준편차':>10}")
print("  " + "-" * 66)

normalized = {}
for name, fn in METHODS.items():
    v = fn(s)
    normalized[name] = v
    q = v.quantile([0, .25, .5, .75, 1])
    print(f"  {name:<10}{q[0]:>9.3f}{q[0.25]:>9.3f}{q[0.5]:>9.3f}"
          f"{q[0.75]:>9.3f}{q[1]:>9.3f}{v.std():>10.3f}")

print(f"\n[⚠ Min-Max 의 문제]")
mm = normalized["minmax"]
print(f"  0.1 미만에 몰린 비율: {(mm < 0.1).mean()*100:.1f}%")
print(f"  → 극단값 하나 때문에 대부분이 0 근처에 뭉침")
print(f"    이 상태로 가중합하면 이 지표가 사실상 무시됨")

print(f"\n[✅ 순위 기반]")
rk = normalized["rank"]
print(f"  0.1 미만에 몰린 비율: {(rk < 0.1).mean()*100:.1f}%")
print(f"  → 균등하게 퍼짐. 극단값이 있어도 안정적")

# ── 정규화 방법에 따른 TOP 5 변화 ──
print(f"\n[정규화 방법에 따른 TOP 5 변화]")

WEIGHTS = {"rating": 0.4, "visitors": 0.35, "price": 0.25}

results = {}
for name, fn in METHODS.items():
    work = df.copy()
    work["_score"] = (
        WEIGHTS["rating"] * fn(work["rating"])
        + WEIGHTS["visitors"] * fn(work["visitors"])
        + WEIGHTS["price"] * (1 - fn(work["price"]))       # 쌀수록 좋음
    )
    results[name] = work.nlargest(5, "_score")["id"].tolist()

print(f"  {'방법':<10}{'TOP 5 id'}")
print("  " + "-" * 50)
for name, ids in results.items():
    print(f"  {name:<10}{ids}")

base = set(results["rank"])
print(f"\n  [순위 기반 대비 겹침]")
for name, ids in results.items():
    overlap = len(base & set(ids))
    print(f"  {name:<10}{overlap}/5 겹침")

print(f"\n  → 정규화 방법만 바꿔도 추천 결과가 달라집니다")
print(f"    '어떤 정규화를 왜 썼는지'를 설계서에 남기세요")

print("\n" + "=" * 80)
```

### Step 2. 추천 함수 만들기 (오늘의 종합 예제)

```python
"""사용자 선호 → 추천 TOP N."""

import numpy as np
import pandas as pd

EARTH_R = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))
    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlng/2)**2
    return 2 * EARTH_R * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


def bayesian_rating(rating, count, m=50):
    """리뷰 수를 반영한 보정 평점."""
    C = rating.mean()
    return (count / (count + m)) * rating + (m / (count + m)) * C


# ══════════ 기본 가중치 — 근거 포함 ══════════
DEFAULT_WEIGHTS = {
    "rating":    (0.35, "만족도가 재방문·추천의 핵심 지표"),
    "popularity":(0.20, "검증된 곳이라는 신호. 단, 편향 방지를 위해 낮게"),
    "value":     (0.25, "예산 제약이 있는 사용자에게 가성비가 중요"),
    "distance":  (0.20, "이동 시간이 만족도에 직접 영향"),
}


def prepare_scores(df, m_prior=50):
    """추천에 쓸 점수 컬럼을 미리 계산합니다. (한 번만)"""
    out = df.copy()

    # ── 보정 평점 ──
    out["_rating_adj"] = bayesian_rating(out["rating"],
                                          out["review_count"], m=m_prior)

    # ── 순위 정규화 (치우친 지표에 안전) ──
    out["_s_rating"] = out["_rating_adj"].rank(pct=True)
    out["_s_popularity"] = np.log1p(out["visitors"]).rank(pct=True)
    out["_pop_pct"] = out["visitors"].rank(pct=True)      # 편향 측정용

    return out


def recommend(df, region=None, categories=None, budget=None,
              origin=None, max_distance_km=None,
              weights=None, k=5, diversity=0.0,
              relax=True, verbose=False):
    """
    조건에 맞는 관광지를 추천합니다.

    region          : 시도명 (하드 필터)
    categories      : 카테고리 목록 (하드 필터)
    budget          : 1인 예산 상한 (하드 필터)
    origin          : (lat, lng) 출발지 — 거리 점수용
    max_distance_km : 최대 거리 (하드 필터)
    weights         : {지표: 가중치}
    diversity       : 0~1. 클수록 카테고리 다양성 중시
    relax           : 결과가 부족하면 조건을 완화

    반환: DataFrame (score, 각 지표 점수, 완화 여부 포함)
    """
    weights = weights or {k: v[0] for k, v in DEFAULT_WEIGHTS.items()}
    total_w = sum(weights.values())
    weights = {k: v / total_w for k, v in weights.items()}      # 합 1.0

    relaxations = []

    # ══════════ ① 하드 필터 ══════════
    def apply_filters(budget_mult=1.0, distance_mult=1.0,
                      use_region=True, use_category=True):
        pool = df.copy()

        if region and use_region:
            pool = pool[pool["sido"] == region]

        if categories and use_category:
            pool = pool[pool["category"].isin(categories)]

        if budget is not None:
            pool = pool[pool["price"] <= budget * budget_mult]

        if origin is not None:
            pool = pool.assign(
                _distance=haversine(origin[0], origin[1],
                                    pool["lat"], pool["lng"]))
            if max_distance_km:
                pool = pool[pool["_distance"] <= max_distance_km * distance_mult]

        return pool

    pool = apply_filters()

    # ══════════ ② 완화 전략 ══════════
    if relax and len(pool) < k:
        RELAX_STEPS = [
            ({"budget_mult": 1.2}, "예산 20% 완화"),
            ({"budget_mult": 1.5}, "예산 50% 완화"),
            ({"distance_mult": 1.5}, "거리 50% 완화"),
            ({"use_category": False}, "카테고리 조건 해제"),
            ({"budget_mult": 2.0, "distance_mult": 2.0,
              "use_category": False}, "예산·거리·카테고리 대폭 완화"),
        ]

        for kwargs, label in RELAX_STEPS:
            if len(pool) >= k:
                break
            candidate = apply_filters(**kwargs)
            if len(candidate) > len(pool):
                pool = candidate
                relaxations.append(label)

    if pool.empty:
        return pd.DataFrame()

    # ══════════ ③ 점수 계산 ══════════
    pool = pool.copy()

    # 가성비: 가격이 낮을수록 높은 점수 (풀 안에서 재계산)
    pool["_s_value"] = 1 - pool["price"].rank(pct=True)

    # 거리: 가까울수록 높은 점수
    if "_distance" in pool.columns:
        pool["_s_distance"] = 1 - pool["_distance"].rank(pct=True)
    else:
        pool["_s_distance"] = 0.5

    pool["score"] = sum(pool[f"_s_{key}"] * w
                        for key, w in weights.items()
                        if f"_s_{key}" in pool.columns)

    # ══════════ ④ 다양성 (MMR) ══════════
    if diversity > 0 and len(pool) > k:
        lambda_ = 1 - diversity
        selected = []
        remaining = pool.sort_values("score", ascending=False).copy()

        while len(selected) < k and len(remaining):
            if not selected:
                pick = remaining.index[0]
            else:
                used = {pool.loc[i, "category"] for i in selected}
                penalty = remaining["category"].isin(used).astype(float)
                mmr = (1 - lambda_) * remaining["score"] - lambda_ * penalty * 0.3
                pick = mmr.idxmax()

            selected.append(pick)
            remaining = remaining.drop(pick)

        result = pool.loc[selected]
    else:
        result = pool.nlargest(k, "score")

    result = result.copy()
    result["rank"] = range(1, len(result) + 1)
    result["relaxed"] = ", ".join(relaxations) if relaxations else ""
    result["pool_size"] = len(pool)

    if verbose:
        print(f"  후보 {len(pool)}곳 → 추천 {len(result)}곳"
              f"{f' (완화: {", ".join(relaxations)})' if relaxations else ''}")

    return result


def explain(row, weights=None):
    """추천 이유를 문장으로 만듭니다."""
    weights = weights or {k: v[0] for k, v in DEFAULT_WEIGHTS.items()}

    parts = []
    contributions = {}

    for key, w in weights.items():
        col = f"_s_{key}"
        if col in row.index:
            contributions[key] = row[col] * w / sum(weights.values())

    top2 = sorted(contributions, key=contributions.get, reverse=True)[:2]

    LABEL = {"rating": "높은 평점", "popularity": "많은 방문객",
             "value": "좋은 가성비", "distance": "가까운 거리"}

    for key in top2:
        pct = row.get(f"_s_{key}", 0) * 100
        parts.append(f"{LABEL.get(key, key)}(상위 {100-pct:.0f}%)")

    return " · ".join(parts)


# ══════════ 실행 ══════════
scored = prepare_scores(df)

print("=" * 84)
print("                          추천 시스템")
print("=" * 84)

print(f"\n[가중치 설계 근거]")
print(f"  {'지표':<14}{'가중치':>8}  근거")
print("  " + "-" * 74)
for key, (w, reason) in DEFAULT_WEIGHTS.items():
    print(f"  {key:<14}{w:>8.2f}  {reason}")
print(f"  {'합계':<14}{sum(v[0] for v in DEFAULT_WEIGHTS.values()):>8.2f}")

# ══════════ 시나리오 ══════════

> **눈여겨볼 점 8가지**
> - **가중치 근거를 표로 명시** — "왜 평점이 0.35인가"에 답할 수 있어야 합니다.
> - **가중치 합을 1.0 으로 정규화** — 사용자가 임의 값을 넣어도 점수가 0~1 범위입니다.
> - **베이지안 평점** — 리뷰 1개짜리 5.0점이 1등이 되는 것을 막습니다.
> - **가성비·거리는 풀 안에서 재계산** — 전체 기준이 아니라 **후보 중 상대 순위**여야 의미가 있습니다.
> - **완화 단계를 순차 적용** — 예산 → 거리 → 카테고리 순으로, **덜 중요한 것부터** 풉니다.
> - **완화 사실을 결과에 표시** — 사용자가 "왜 쇼핑이 아닌 게 나왔지?"를 알 수 있습니다.
> - **추천 이유 생성** — 기여도가 높은 지표 2개를 뽑아 문장으로 만듭니다.
> - **`prepare_scores` 를 분리** — 전체 기준 점수는 **한 번만** 계산합니다.

### Step 3. 가중치 민감도와 검증

```python
"""가중치를 바꾸면 결과가 얼마나 달라지나."""

from itertools import product

import numpy as np
import pandas as pd

print("=" * 82)

    """추천기의 품질을 여러 지표로 평가합니다."""
    recommended_ids = set()
    diversities, popularities, scores = [], [], []
    empty, relaxed = 0, 0

    for q in queries:
        result = recommend(df, **q, weights=weights, k=k, diversity=diversity)

        if result.empty:
            empty += 1
            continue

        recommended_ids |= set(result["id"])
        diversities.append(result["category"].nunique() / len(result))
        popularities.append(result["_pop_pct"].mean())
        scores.append(result["score"].mean())

        if result["relaxed"].iloc[0]:
            relaxed += 1

    return {
        "커버리지": len(recommended_ids) / len(df),
        "다양성": np.mean(diversities) if diversities else 0,
        "인기편향": np.mean(popularities) if popularities else 0,
        "평균점수": np.mean(scores) if scores else 0,
        "결과없음": empty / len(queries),
        "완화발생": relaxed / len(queries),
    }

## ⑤ 자주 하는 실수

### 정규화 없이 가중합

```python
score = rating * 0.4 + visitors * 0.35     # 방문객이 전부 결정
```

**해결** — 모든 지표를 같은 눈금(0~1)으로 맞춥니다.

### 치우친 지표에 Min-Max

91%가 0.1 미만이 되어 **가중치가 무의미**해집니다.

**해결** — 순위 기반(`rank(pct=True)`)

### 방향을 안 맞춤

```python
score = ... + minmax(df["price"]) * 0.25    # 비쌀수록 점수가 높아짐
```

**해결** — `1 - minmax(df["price"])`

### 리뷰 수 무시

리뷰 1개 5.0점이 1등이 됩니다.

**해결** — 베이지안 평균

### 가중치 근거 없음

```python
WEIGHTS = {"rating": 0.4, "price": 0.3, "distance": 0.3}   # 왜?
```

**해결** — 각 가중치에 **한 문장씩** 근거를 답니다.

### 하드 필터가 너무 강함

결과가 0건인데 아무 안내가 없습니다.

**해결** — 완화 전략 + 완화 사실 표시

### 다양성 무시

**해결** — MMR 또는 카테고리별 최대 개수 제한

### 인기 편향 방치

유명한 곳만 추천되면 **추천의 가치가 없습니다.**

**해결** — 인기 가중치를 낮추고, 커버리지를 측정합니다.

### 전체 기준으로 상대 점수 계산

```python
df["_s_value"] = 1 - df["price"].rank(pct=True)     # 전체 3,000곳 기준

**해결** — 필터링 후 풀 안에서 재계산

### 추천 이유를 안 보여 줌

**해결** — 기여도 상위 지표를 문장으로 만듭니다.

### 검증 없이 배포

```python
"""근거 있는 추천 함수."""

import numpy as np
import pandas as pd

# ── 가중치와 근거 ──                                    ⑧
WEIGHTS = {
    "rating":     (0.40, "만족도가 추천의 1차 목표"),
    "popularity": (0.20, "검증 신호. 인기 편향 방지를 위해 낮게"),
    "value":      (0.40, "예산 제약이 명시된 질의이므로 높게"),
}


def bayesian_rating(rating, count, m=50):               # ③
    C = rating.mean()
    return (count / (count + m)) * rating + (m / (count + m)) * C


def recommend(df, region=None, budget=None, k=5,
              weights=None, diversity=0.3, relax=True):
    """
    조건에 맞는 관광지를 추천합니다.

    반환: DataFrame(rank, score, reason, ...) — 비어 있을 수 있음
    """
    weights = weights or {k: v[0] for k, v in WEIGHTS.items()}
    total = sum(weights.values())
    weights = {k: v / total for k, v in weights.items()}

    relaxations = []

    # ── ① 필터 ──
    def filter_pool(budget_mult=1.0, use_region=True):
        pool = df
        if region and use_region:
            pool = pool[pool["sido"] == region]
        if budget is not None:
            pool = pool[pool["price"] <= budget * budget_mult]
        return pool.copy()                               # ④ 명시적 복사

    pool = filter_pool()

    # ── ② 완화 ──                                       ⑤
    if relax and len(pool) < k:
        for mult, label in [(1.3, "예산 30% 완화"),
                            (2.0, "예산 100% 완화")]:
            if len(pool) >= k:
                break
            wider = filter_pool(budget_mult=mult)
            if len(wider) > len(pool):
                pool, _ = wider, relaxations.append(label)

        if len(pool) < k and region:
            wider = filter_pool(budget_mult=2.0, use_region=False)
            if len(wider) > len(pool):
                pool = wider
                relaxations.append("지역 조건 해제")

    if pool.empty:                                       # ⑤
        return pd.DataFrame(columns=list(df.columns) + ["score", "reason"])

    # ── ③ 점수 (풀 안에서 정규화) ──                     ①②
    pool["_adj_rating"] = bayesian_rating(pool["rating"],
                                          pool.get("review_count", 0))

    pool["_s_rating"] = pool["_adj_rating"].rank(pct=True)
    pool["_s_popularity"] = np.log1p(pool["visitors"]).rank(pct=True)
    pool["_s_value"] = 1 - pool["price"].rank(pct=True)   # ② 방향 반전

    pool["score"] = sum(pool[f"_s_{key}"] * w for key, w in weights.items())

    # ── ④ 다양성 (MMR) ──                                ⑥
    if diversity > 0 and "category" in pool.columns and len(pool) > k:
        selected, remaining = [], pool.sort_values("score", ascending=False)

        while len(selected) < k and len(remaining):
            if not selected:
                pick = remaining.index[0]
            else:
                used = {pool.loc[i, "category"] for i in selected}
                penalty = remaining["category"].isin(used).astype(float)
                pick = ((1 - diversity) * remaining["score"]
                        - diversity * penalty * 0.3).idxmax()

            selected.append(pick)
            remaining = remaining.drop(pick)

        result = pool.loc[selected].copy()
    else:
        result = pool.nlargest(k, "score").copy()

    # ── ⑤ 추천 이유 ──                                   ⑦
    LABEL = {"rating": "높은 평점", "popularity": "많은 방문객",
             "value": "좋은 가성비"}

    def reason(row):
        contrib = {key: row[f"_s_{key}"] * w for key, w in weights.items()}
        top2 = sorted(contrib, key=contrib.get, reverse=True)[:2]
        return " · ".join(
            f"{LABEL[key]}(상위 {(1-row[f'_s_{key}'])*100:.0f}%)"
            for key in top2)

    result["reason"] = result.apply(reason, axis=1)
    result["rank"] = range(1, len(result) + 1)
    result["relaxed"] = ", ".join(relaxations)
    result["pool_size"] = len(pool)

    return result


# ── 사용 ──
r = recommend(df, region="부산광역시", budget=50000, k=5)

import numpy as np
import pandas as pd
from scipy.stats import spearmanr


def audit_recommender(df, recommend_fn, queries, k=5,
                      weights=None, verbose=True):
    """
    추천기를 6개 축으로 진단합니다.

    반환: dict(scores, issues, details)
    """
    issues = []
    all_recommended = []
    diversities, pop_pcts, empties, relaxed = [], [], 0, 0
    item_counts = {}

    # ══════════ 실행 ══════════
    for q in queries:
        result = recommend_fn(df, **q, k=k, weights=weights)

        if result is None or result.empty:
            empties += 1
            continue

        if result.get("relaxed") is not None and result["relaxed"].iloc[0]:
            relaxed += 1

        ids = result["id"].tolist()
        all_recommended += ids

        for i in ids:
            item_counts[i] = item_counts.get(i, 0) + 1

        if "category" in result.columns:
            diversities.append(result["category"].nunique() / len(result))

        if "_pop_pct" in result.columns:
            pop_pcts.append(result["_pop_pct"].mean())

    n_queries = len(queries)
    unique_items = set(all_recommended)

    # ══════════ 지표 계산 ══════════
    coverage = len(unique_items) / len(df)
    diversity = np.mean(diversities) if diversities else 0
    pop_bias = np.mean(pop_pcts) if pop_pcts else 0.5
    empty_rate = empties / n_queries
    relax_rate = relaxed / n_queries

    # 집중도 (지니 계수 근사) — 소수 항목에 추천이 몰리는가
    if item_counts:
        counts = np.sort(np.array(list(item_counts.values())))
        n = len(counts)
        gini = ((2 * np.arange(1, n + 1) - n - 1) * counts).sum() / (n * counts.sum())
    else:
        gini = 0

    # ══════════ 안정성 (가중치 민감도) ══════════
    stability = None
    if weights and len(queries) >= 5:
        overlaps = []
        for q in queries[:20]:
            base = recommend_fn(df, **q, k=k, weights=weights)
            if base.empty:
                continue

            perturbed = {kk: v * (1.15 if i % 2 else 0.85)
                         for i, (kk, v) in enumerate(weights.items())}
            alt = recommend_fn(df, **q, k=k, weights=perturbed)

            if not alt.empty:
                overlaps.append(
                    len(set(base["id"]) & set(alt["id"])) / k)

        stability = np.mean(overlaps) if overlaps else None

    # ══════════ 판정 ══════════
    CRITERIA = [
        ("커버리지", coverage, 0.20, "높을수록", 
         "낮으면 소수 항목만 반복 추천"),
        ("다양성", diversity, 0.60, "높을수록",
         "낮으면 같은 카테고리만 나옴"),
        ("인기편향", pop_bias, 0.70, "낮을수록",
         "높으면 유명한 곳만 추천"),
        ("결과없음", empty_rate, 0.05, "낮을수록",
         "높으면 필터가 과도"),
        ("완화발생", relax_rate, 0.25, "낮을수록",
         "높으면 조건 설계 재검토"),
        ("집중도(지니)", gini, 0.60, "낮을수록",
         "높으면 특정 항목에 추천 집중"),
    ]

    if stability is not None:
        CRITERIA.append(
            ("안정성", stability, 0.60, "높을수록",
             "낮으면 가중치에 과민 · 1.0이면 가중치 무의미"))

    for name, value, threshold, direction, meaning in CRITERIA:
        if direction == "높을수록":
            ok = value >= threshold
        else:
            ok = value <= threshold

        if not ok:
            level = "치명" if name in ("결과없음",) else "경고"
            issues.append((level,
                           f"{name} {value:.2f} "
                           f"({'≥' if direction=='높을수록' else '≤'} "
                           f"{threshold} 권장) — {meaning}"))

    if stability is not None and stability > 0.95:
        issues.append(("경고",
                       f"안정성 {stability:.2f} — 가중치를 바꿔도 결과가 같음. "
                       f"가중치 설계가 무의미할 수 있음"))

    # ══════════ 출력 ══════════
    if verbose:
        line = "=" * 82
        print(line)
        print("                      추천 시스템 진단")
        print(line)

        print(f"\n[실행]  질의 {n_queries}건 · k={k}")
        print(f"  전체 항목    : {len(df):,}개")
        print(f"  추천된 항목  : {len(unique_items):,}개")
        print(f"  총 추천 횟수 : {len(all_recommended):,}회")

        print(f"\n[지표]")
        print(f"  {'지표':<16}{'값':>8}{'기준':>10}{'방향':>10}  판정")
        print("  " + "-" * 60)

        for name, value, threshold, direction, _ in CRITERIA:
            ok = (value >= threshold if direction == "높을수록"
                  else value <= threshold)
            mark = "✓" if ok else "✗"
            print(f"  {name:<16}{value:>8.2f}{threshold:>10.2f}"
                  f"{direction:>10}  {mark}")

        # ── 가장 많이 추천된 항목 ──
        if item_counts:
            top_items = sorted(item_counts.items(),
                               key=lambda t: t[1], reverse=True)[:5]

            print(f"\n[가장 많이 추천된 항목]")
            for item_id, cnt in top_items:
                row = df[df["id"] == item_id]
                name = row["name"].iloc[0] if len(row) else str(item_id)
                pct = cnt / n_queries * 100
                bar = "■" * int(pct / 2)
                print(f"  {name:<14}{cnt:>4}회 ({pct:>5.1f}%)  {bar}")

            if top_items[0][1] / n_queries > 0.5:
                issues.append(("경고",
                               f"'{top_items[0][0]}' 이 질의의 "
                               f"{top_items[0][1]/n_queries*100:.0f}%에 등장 "
                               f"— 과도한 집중"))

        # ── 추천되지 못한 항목 분석 ──
        never = df[~df["id"].isin(unique_items)]

        if len(never):
            print(f"\n[한 번도 추천되지 않은 항목]  "
                  f"{len(never):,}개 ({len(never)/len(df)*100:.1f}%)")

            for col in ("category", "sido"):
                if col not in df.columns:
                    continue
                rate = (never[col].value_counts() /
                        df[col].value_counts()).sort_values(ascending=False)
                worst = rate.head(3)
                print(f"  {col} 별 미추천 비율:")
                for cat, r in worst.items():
                    print(f"    {cat:<16}{r*100:>5.1f}%")

        # ── 결과 ──
        fatal = sum(1 for l, _ in issues if l == "치명")
        warn = sum(1 for l, _ in issues if l == "경고")
        score = max(0, 100 - fatal * 25 - warn * 10)

        print(f"\n{line}")
        grade = ("✅ 양호" if score >= 80
                 else "🟡 개선 필요" if score >= 55 else "❌ 재설계")
        print(f"  종합: {score}점 / 100   {grade}")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} {msg}")

        if not issues:
            print("  문제 없음")

        # ── 개선 제안 ──
        print(f"\n[개선 제안]")
        suggestions = []

        if coverage < 0.20:
            suggestions.append("다양성(MMR) 파라미터를 높여 커버리지 개선")
        if diversity < 0.60:
            suggestions.append("MMR diversity 를 0.3~0.6 으로 설정")
        if pop_bias > 0.70:
            suggestions.append("popularity 가중치를 낮추거나 로그 변환 강화")
        if empty_rate > 0.05:
            suggestions.append("완화 전략 추가 또는 하드 필터 완화")
        if gini > 0.60:
            suggestions.append("이미 추천된 항목에 감점을 주는 로직 추가")

        for s in suggestions or ["현재 설정 유지"]:
            print(f"  · {s}")

        print(line)

    return {"coverage": coverage, "diversity": diversity,
            "pop_bias": pop_bias, "empty_rate": empty_rate,
            "gini": gini, "stability": stability, "issues": issues}

# 추천 함수 설계서

> 작성일 2026-08-08 · 작성자 (이름) · 버전 v1.0

---

## 1. 목적과 사용자

### 1-1. 해결하려는 문제
여행 계획 단계의 사용자가 "어디를 갈지" 결정하는 데 드는 탐색 비용을 줄인다.
전국 3,000곳 중 조건에 맞는 5곳을 근거와 함께 제시한다.

### 1-2. 대상 사용자
- 목적지 지역은 정했으나 세부 장소를 못 정한 사용자
- 예산 제약이 있는 사용자
- 특정 카테고리(자연/역사 등)에 관심이 있는 사용자

### 1-3. 성공 기준
| 지표 | 목표 |
|---|---|
| 커버리지 | ≥ 25% |
| 다양성 | ≥ 0.60 |
| 인기편향 | ≤ 0.70 |
| 결과없음 비율 | ≤ 5% |

---

## 2. 입력

| 파라미터 | 타입 | 필수 | 성격 | 설명 |
|---|---|---|---|---|
| `region` | str | ❌ | **하드** | 시도명. 미지정 시 전국 |
| `categories` | list | ❌ | **하드** | 카테고리 목록 |
| `budget` | int | ❌ | **하드** | 1인 예산 상한(원) |
| `origin` | tuple | ❌ | 소프트 | 출발지 (위도, 경도) |
| `max_distance_km` | float | ❌ | **하드** | 최대 거리 |
| `weights` | dict | ❌ | 설정 | 지표별 가중치 |
| `k` | int | ✅ | 설정 | 추천 개수 (기본 5) |
| `diversity` | float | ❌ | 설정 | 0~1. 다양성 강도 |

---

## 3. 점수 설계

### 3-1. 지표와 가중치

| 지표 | 가중치 | 원천 데이터 | 정규화 | 근거 |
|---|---|---|---|---|
| `rating` | **0.35** | 평점 + 리뷰 수 | 순위(pct) | 만족도가 추천의 1차 목표. 재방문·구전에 직결 |
| `popularity` | **0.20** | 방문객 수 | log → 순위 | 검증된 곳이라는 신호. 단, 인기 편향을 막기 위해 의도적으로 낮게 설정 |
| `value` | **0.25** | 가격 (역방향) | 순위(pct) | 예산이 명시적 입력이므로 가성비를 실질 반영 |
| `distance` | **0.20** | 하버사인 거리 (역방향) | 순위(pct) | 이동 시간이 실제 만족도에 영향. 단, 좋은 곳이면 멀어도 감수 |

**합계 1.00** (입력 가중치는 합이 1이 되도록 자동 정규화)

### 3-2. 정규화 방법 선택 근거

**순위 기반(`rank(pct=True)`)을 채택.**

| 방법 | 검토 결과 |
|---|---|
| Min-Max | ❌ 방문객 데이터의 91%가 0.1 미만에 뭉쳐 가중치가 무의미해짐 |
| Z-score | ❌ 왜도 8.42 로 정규분포 가정 불성립 |
| **순위** | ✅ 극단값에 완전히 강함. 분포와 무관하게 균등 |
| 로버스트 | △ 대안 가능하나 백분위 임계값을 추가로 정해야 함 |

### 3-3. 평점 보정

베이지안 평균 적용. `m = 50` (리뷰 50개면 자체 평점을 신뢰).

```
adj = (n/(n+50)) × rating + (50/(n+50)) × 전체평균
```

**근거** — 리뷰 1개짜리 5.0점이 리뷰 1,000개짜리 4.5점보다 위로 오는 것을 방지.

### 3-4. 상대 점수의 기준

`value`, `distance` 는 **필터링 후 후보 풀 안에서** 재계산한다.

**근거** — "부산 47곳 중 저렴한가"를 물어야지 "전국 3,000곳 중 저렴한가"는
사용자의 질문이 아니다.

---

## 4. 필터와 완화

### 4-1. 하드 필터
`region`, `categories`, `budget`, `max_distance_km`

### 4-2. 완화 순서

결과가 `k` 개 미만이면 아래 순서로 완화한다.

| 순서 | 완화 | 근거 |
|---|---|---|
| 1 | 예산 +20% | 예산은 대개 근사치. 소폭 초과는 수용 가능 |
| 2 | 예산 +50% | |
| 3 | 거리 +50% | 이동은 감수 가능한 제약 |
| 4 | 카테고리 해제 | 취향은 넓힐 수 있음 |
| 5 | 예산·거리·카테고리 대폭 완화 | 마지막 수단 |

**지역(`region`)은 완화하지 않는다.** — "부산 여행"인데 서울을 추천하면 무의미.

### 4-3. 완화 고지
완화가 발생하면 결과에 `relaxed` 필드로 명시하고 UI에 표시한다.

---

## 5. 다양성

MMR(Maximal Marginal Relevance) 적용.

```
MMR = (1-λ) × score - λ × 0.3 × [이미 뽑힌 카테고리인가]
```

**기본값 `diversity = 0.3`**

**근거** — 실험 결과 다양성 0.3 에서 다양성 0.58→0.74, 커버리지 28.4%→31.2%로
개선되면서 평균 점수 하락은 3% 이내였다.

---

## 6. 출력

| 필드 | 설명 |
|---|---|
| `rank` | 1~k |
| `score` | 0~1 종합 점수 |
| `reason` | 기여도 상위 2개 지표 문장 |
| `relaxed` | 완화 내역 (없으면 빈 문자열) |
| `pool_size` | 필터 후 후보 수 |
| `_s_*` | 지표별 정규화 점수 (디버깅용) |

**추천 이유 예시**
> "높은 평점(상위 4%) · 좋은 가성비(상위 8%)"

## 7. 알려진 한계

| # | 한계 | 영향 | 대응 |
|---|---|---|---|
| 1 | **개인화 없음** | 모든 사용자가 같은 조건이면 같은 결과 | 사용자 행동 로그 확보 후 협업 필터링 검토 |
| 2 | **콜드스타트** | 리뷰가 없는 신규 항목은 전체 평균으로 수렴 | 신규 항목 부스트 로직 검토 |
| 3 | **계절성 미반영** | 겨울에 해수욕장이 추천될 수 있음 | 월별 방문객 데이터로 계절 가중치 추가 |
| 4 | **동반자 유형 미반영** | 커플/가족/혼자를 구분 못 함 | 태그 데이터 확보 필요 |
| 5 | **평점 변별력 낮음** | 전체가 4.0 부근에 몰림 | 평점 분산·리뷰 텍스트 분석 검토 |
| 6 | **거리는 직선거리** | 실제 이동 시간과 다름 | 경로 API 연동 검토 |

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 추천의 본질 | **필터 → 점수 → 정렬** |
| 정규화 필요성 | 범위가 다르면 **큰 지표가 전부 결정** |
| **정규화 방법** | 치우친 데이터는 **순위 기반(`rank(pct=True)`)** ⭐ |
| 방향 통일 | 가격·거리는 **`1 - 정규화`** |
| 가중합 | 합을 **1.0** 으로 → 점수가 0~1 |
| **평점 보정** | **베이지안 평균** — 리뷰 1개 5.0점 방지 |
| 하드/소프트 | 필터 = 반드시 · 점수 = 좋으면 |
| **완화 전략** | 0건 대신 완화 + **완화 사실 표시** |
| **상대 점수** | **후보 풀 안에서** 재계산 |
| 다양성 | **MMR** — 같은 카테고리에 감점 |
| 인기 편향 | 로그 변환 + 가중치 낮추기 |
| **검증** | 커버리지·다양성·인기편향·**안정성** |

**오늘 반드시 기억할 세 가지**
> ① **정규화 없이 가중합하지 마세요.** 방문객이 평점보다 6만 배 커서 가중치가 무의미해집니다.
> ② **가중치마다 근거를 한 문장씩 쓰세요.** 근거 없는 숫자는 임의의 정렬입니다.
> ③ **추천되지 않는 항목을 확인하세요.** 80%가 한 번도 안 나온다면 추천이 아니라 인기 순위입니다.

**과제**
① **추천 함수 설계서** 작성 — 가중치 근거·정규화 선택·완화 순서·한계 포함
② `recommend()` 함수 구현 — 필터·점수·다양성·완화·이유 생성
③ **가중치 프로필 3종** 이상으로 TOP 5 비교표 작성
④ 테스트 질의 30건 이상으로 **커버리지·다양성·인기편향** 측정
⑤ 미추천 항목 비율을 카테고리·지역별로 분석하고 개선안 제시
