## ③ 개념 설명

### HTML의 구조

HTML은 **태그로 감싼 트리**입니다.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>뉴스 목록</title>
  </head>
  <body>
    <div class="container">
      <h1 id="page-title">오늘의 뉴스</h1>
      <ul class="news-list">
        <li class="news-item">
          <a href="/news/1" class="title">첫 번째 기사</a>
          <span class="date">2026-08-12</span>
        </li>
      </ul>
    </div>
  </body>
</html>
```

**트리로 그리면:**

```
html
├── head
│   └── title  "뉴스 목록"
└── body
    └── div.container
        ├── h1#page-title  "오늘의 뉴스"
        └── ul.news-list
            └── li.news-item
                ├── a.title  href="/news/1"  "첫 번째 기사"
                └── span.date  "2026-08-12"
```

### 태그와 속성

```html
<a href="/news/1" class="title" id="first" data-id="1">첫 번째 기사</a>
└┬┘ └──────┬─────────────────────────────────────────┘ └────┬────┘└┬┘
태그          속성(attribute)                             텍스트   닫는 태그
```

| 속성 | 뜻 | 크롤링에서 |
|---|---|---|
| `class` | 스타일 분류. **여러 요소가 공유** | 목록을 뽑을 때 |
| `id` | **문서에서 유일** | 특정 요소 하나 |
| `href` | 링크 주소 | URL 수집 |
| `src` | 이미지·스크립트 경로 | 이미지 수집 |
| `data-*` | 개발자 정의 데이터 | **숨은 보물** (id 등이 들어 있음) |

### 자주 만나는 태그

| 태그 | 뜻 |
|---|---|
| `<div>` | 구역 (의미 없음, 묶기용) |
| `<span>` | 인라인 구역 |
| `<a>` | 링크 |
| `<ul>` `<ol>` `<li>` | 목록 |
| `<table>` `<thead>` `<tbody>` `<tr>` `<th>` `<td>` | 표 |
| `<h1>`~`<h6>` | 제목 |
| `<p>` | 문단 |
| `<img>` | 이미지 |

### BeautifulSoup 기본

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")
```

| 파서 | 설치 | 특징 |
|---|---|---|
| `"html.parser"` | 내장 | 별도 설치 불필요. **기본으로 쓰세요** |
| `"lxml"` | `pip install lxml` | 빠름 |
| `"html5lib"` | `pip install html5lib` | 깨진 HTML에 관대, 느림 |

### 요소 찾기 — 두 갈래

| 방식 | 메서드 | 특징 |
|---|---|---|
| **CSS 선택자** | `select()` · `select_one()` | 브라우저에서 그대로 복사 가능 ⭐ |
| find 계열 | `find()` · `find_all()` | 파이썬스럽고 조건이 복잡할 때 유리 |

**둘 다 알아야 하지만, `select()` 를 먼저 익히세요.** 개발자 도구에서 바로 복사할 수 있습니다.

### CSS 선택자

| 선택자 | 뜻 | 예 |
|---|---|---|
| `태그` | 태그 이름 | `a`, `div`, `li` |
| `.클래스` | class 값 | `.news-item` |
| `#아이디` | id 값 | `#page-title` |
| `A B` | A **안의** B (후손) | `div a` |
| `A > B` | A의 **직계 자식** B | `ul > li` |
| `A, B` | A 또는 B | `h1, h2` |
| `[속성]` | 속성이 있는 것 | `a[href]` |
| `[속성="값"]` | 속성이 정확히 그 값 | `a[target="_blank"]` |
| `[속성^="값"]` | ~로 시작 | `a[href^="/news"]` |
| `[속성$="값"]` | ~로 끝남 | `a[href$=".pdf"]` |
| `[속성*="값"]` | ~를 포함 | `a[href*="news"]` |
| `:nth-child(n)` | n번째 자식 | `li:nth-child(2)` |
| `:not(선택자)` | 제외 | `li:not(.ad)` |

**조합해서 씁니다.**

```python
soup.select("ul.news-list > li.news-item a.title")
```

> "`news-list` 클래스인 `ul` 의 직계 자식 중 `news-item` 클래스인 `li` 안에 있는 `title` 클래스인 `a`"

### 텍스트와 속성 꺼내기

```python
element = soup.select_one("a.title")

element.text                    # '첫 번째 기사'
element.get_text()              # 같음
element.get_text(strip=True)    # 앞뒤 공백 제거 ⭐
element["href"]                 # '/news/1'   ← 없으면 KeyError
element.get("href")             # 같음, 없으면 None ⭐
element.get("href", "")         # 기본값 지정
element.attrs                   # {'href': '/news/1', 'class': ['title']}
element.name                    # 'a'
```

> **`.get()` 을 쓰세요.** 속성이 없는 요소가 섞여 있으면 `[]` 는 `KeyError` 로 죽습니다.
> [Day 008](day-008.md)의 딕셔너리와 같은 원리입니다.
>
> **`class` 는 리스트로 나옵니다.** `class="a b c"` 는 `['a', 'b', 'c']` 입니다.

### `.text` 의 함정

```html
<li class="news-item">
  <a class="title">기사 제목</a>
  <span class="date">2026-08-12</span>
</li>
```

```python
li = soup.select_one("li.news-item")
li.text
# '\n  기사 제목\n  2026-08-12\n'      ← 자식들의 텍스트가 전부 합쳐짐
```

**`.text` 는 후손의 모든 텍스트를 이어붙입니다.** 원하는 것만 뽑으려면 정확히 지목해야 합니다.

```python
li.select_one("a.title").get_text(strip=True)      # '기사 제목'
```

구분자를 넣어 나눌 수도 있습니다.

```python
li.get_text(separator=" | ", strip=True)      # '기사 제목 | 2026-08-12'
```

### find 계열

```python
soup.find("a")                                   # 첫 번째 a
soup.find_all("a")                               # 모든 a
soup.find("div", class_="container")              # class 는 예약어라 class_
soup.find("h1", id="page-title")
soup.find_all("a", href=True)                    # href 속성이 있는 것만
soup.find_all("a", limit=5)                      # 개수 제한
soup.find_all(["h1", "h2"])                      # 여러 태그
soup.find("a", attrs={"data-id": "1"})           # 하이픈 있는 속성
```

**정규식과 함수도 씁니다.**

```python
import re
soup.find_all("a", href=re.compile(r"^/news/\d+$"))
soup.find_all(lambda tag: tag.name == "li" and len(tag.get("class", [])) > 1)
```

### 트리 이동

```python
element.parent            # 부모
element.parents           # 조상 전부 (제너레이터)
element.children          # 직계 자식
element.descendants       # 모든 후손
element.next_sibling      # 다음 형제 (공백 텍스트일 수 있음!)
element.find_next_sibling("span")     # 다음 형제 중 span  ⭐
element.find_previous_sibling("a")
```

> **`next_sibling` 은 조심하세요.** HTML의 줄바꿈·들여쓰기도 텍스트 노드로 취급되어
> 대개 `'\n  '` 같은 공백이 나옵니다. `find_next_sibling("태그")` 를 쓰세요.

### 표 파싱

```html
<table>
  <thead>
    <tr><th>역명</th><th>승차</th><th>하차</th></tr>
  </thead>
  <tbody>
    <tr><td>강남</td><td>48,293</td><td>47,108</td></tr>
    <tr><td>홍대입구</td><td>51,042</td><td>49,873</td></tr>
  </tbody>
</table>
```

```python
table = soup.select_one("table")
headers = [th.get_text(strip=True) for th in table.select("thead th")]

rows = []
for tr in table.select("tbody tr"):
    cells = [td.get_text(strip=True) for td in tr.select("td")]
    rows.append(dict(zip(headers, cells)))
```

`zip(headers, cells)` 이 `[('역명','강남'), ('승차','48,293'), ...]` 을 만들고,
`dict()` 이 딕셔너리로 바꿉니다.

### 상대 URL을 절대 URL로

```html
<a href="/news/1">기사</a>
```

`/news/1` 만으로는 요청할 수 없습니다.

```python
from urllib.parse import urljoin

base = "https://news.example.com/list?page=1"
urljoin(base, "/news/1")          # 'https://news.example.com/news/1'
urljoin(base, "detail/5")         # 'https://news.example.com/detail/5'
urljoin(base, "https://other.com/x")   # 'https://other.com/x'  (절대면 그대로)
```

**직접 문자열을 이어붙이지 마세요.** `base + href` 는 슬래시 중복·누락으로 깨집니다.

### 개발자 도구로 선택자 찾기

**실무에서 가장 많이 쓰는 방법입니다.**

1. 브라우저에서 페이지를 엽니다.
2. 원하는 요소에 **마우스 오른쪽 → 검사** (`F12`)
3. 하이라이트된 HTML에서 **오른쪽 클릭 → Copy → Copy selector**
4. 붙여넣으면 선택자가 나옵니다.

```
#container > div.news-wrap > ul > li:nth-child(1) > a.title
```

> **그대로 쓰지 마세요.** `nth-child(1)` 이 들어 있어 **첫 번째만** 잡습니다.
> 여러 개를 뽑으려면 그 부분을 지웁니다.
>
> ```python
> soup.select("#container ul li a.title")      # 전부
> ```
>
> 그리고 `div.news-wrap > ul >` 처럼 긴 경로는 **사이트가 조금만 바뀌어도 깨집니다.**
> **의미 있는 클래스 하나**로 짧게 잡는 것이 오래 갑니다.

### JavaScript로 그려지는 페이지

```python
r = requests.get(url)
soup = BeautifulSoup(r.text, "html.parser")
soup.select(".product")      # []  ← 아무것도 안 나옴
```

**원인** — `requests` 는 **서버가 보낸 HTML 원본**만 받습니다.
브라우저는 그걸 받은 뒤 JavaScript를 실행해 내용을 채우지만, `requests` 는 실행하지 않습니다.

**확인 방법**

```python
print(r.text[:2000])          # 원본에 데이터가 있는가?
```

또는 브라우저에서 **오른쪽 클릭 → 페이지 소스 보기** (개발자 도구가 아니라!).
거기 없으면 JavaScript로 그려지는 것입니다.

**대응 순서**

| 순서 | 방법 | 난이도 |
|---|---|---|
| 1 | **숨은 API 찾기** — 개발자 도구 Network 탭에서 XHR 확인 | 쉬움 ⭐ |
| 2 | 페이지 소스의 `<script>` 안 JSON 데이터 파싱 | 중간 |
| 3 | Selenium·Playwright로 브라우저 자동화 | 어려움·느림 |

**대부분 1번으로 해결됩니다.** 화면을 채우는 데이터는 어차피 어딘가에서 JSON으로 옵니다.
그 API를 직접 부르면 HTML 파싱보다 **훨씬 빠르고 안정적**입니다.

```python
from bs4 import BeautifulSoup

HTML = """
<!DOCTYPE html>
<html>
<head><title>뉴스 목록</title></head>
<body>
  <div class="container">
    <h1 id="page-title">오늘의 뉴스</h1>
    <ul class="news-list">
      <li class="news-item">
        <a href="/news/1" class="title" data-id="1">AI 반도체 수출 증가</a>
        <span class="date">2026-08-12</span>
        <span class="category">경제</span>
      </li>
      <li class="news-item featured">
        <a href="/news/2" class="title" data-id="2">MLOps 도입 기업 확대</a>
        <span class="date">2026-08-11</span>
        <span class="category">IT</span>
      </li>
      <li class="news-item ad">
        <a href="https://ad.example.com" class="title">광고입니다</a>
      </li>
    </ul>
  </div>
</body>
</html>
"""

soup = BeautifulSoup(HTML, "html.parser")

print("--- 기본 접근 ---")
print(f"  title 태그   : {soup.title.text}")
print(f"  h1 텍스트    : {soup.select_one('#page-title').get_text(strip=True)}")
print(f"  li 개수      : {len(soup.select('li.news-item'))}")

print("\n--- 첫 번째 기사 ---")
first = soup.select_one("li.news-item a.title")
print(f"  텍스트  : {first.get_text(strip=True)}")
print(f"  href    : {first.get('href')}")
print(f"  data-id : {first.get('data-id')}")
print(f"  class   : {first.get('class')}   ← 리스트입니다")
print(f"  속성 전체: {first.attrs}")

print("\n--- 없는 속성 접근 비교 ---")
ad_link = soup.select("li.news-item a.title")[2]
print(f"  get     : {ad_link.get('data-id', '(없음)')}")
try:
    print(f"  []      : {ad_link['data-id']}")
except KeyError as e:
    print(f"  []      : KeyError {e} — 프로그램이 죽습니다")

print("\n--- .text 의 함정 ---")
li = soup.select_one("li.news-item")
print(f"  li.text        : {li.text!r}")
print(f"  strip=True     : {li.get_text(strip=True)!r}")
print(f"  separator 사용  : {li.get_text(separator=' | ', strip=True)!r}")
print(f"  정확히 지목     : {li.select_one('a.title').get_text(strip=True)!r}")
```

실행 결과:

```
--- 기본 접근 ---
  title 태그   : 뉴스 목록
  h1 텍스트    : 오늘의 뉴스
  li 개수      : 3

--- 첫 번째 기사 ---
  텍스트  : AI 반도체 수출 증가
  href    : /news/1
  data-id : 1
  class   : ['title']   ← 리스트입니다
  속성 전체: {'href': '/news/1', 'class': ['title'], 'data-id': '1'}

--- 없는 속성 접근 비교 ---
  get     : (없음)
  []      : KeyError 'data-id' — 프로그램이 죽습니다

--- .text 의 함정 ---
  li.text        : '\n        AI 반도체 수출 증가\n        2026-08-12\n        경제\n      '
  strip=True     : 'AI 반도체 수출 증가2026-08-12경제'
  separator 사용  : 'AI 반도체 수출 증가 | 2026-08-12 | 경제'
  정확히 지목     : 'AI 반도체 수출 증가'
```

> **`strip=True` 만으로는 부족합니다.** 자식들의 텍스트가 붙어 나옵니다.
> **원하는 요소를 정확히 지목**하는 것이 정답입니다.

def parse_int(text: str | None) -> int | None:
    """'1,204' → 1204. 실패하면 None."""
    if not text:
        return None
    cleaned = text.strip().replace(",", "")
    return int(cleaned) if cleaned.isdigit() else None


def text_of(element, selector: str, default: str = "") -> str:
    """선택자에 해당하는 요소의 텍스트. 없으면 기본값."""
    found = element.select_one(selector)
    return found.get_text(strip=True) if found else default


def parse_item(li, base_url: str) -> dict | None:
    """li 하나를 레코드로 변환합니다. 광고나 불량이면 None."""
    classes = li.get("class", [])
    if "ad" in classes:
        return None                                  # 광고 제외

    link = li.select_one("a.title")
    if link is None:
        return None                                  # 링크가 없으면 기사가 아님

    href = link.get("href", "")
    if not href.startswith("/news"):
        return None                                  # 외부 링크 제외

    return {
        "id": parse_int(link.get("data-id")),
        "title": link.get_text(strip=True),
        "url": urljoin(base_url, href),
        "date": text_of(li, "span.date"),
        "category": text_of(li, "span.category", "미분류"),
        "views": parse_int(text_of(li, "span.views")) or 0,
        "featured": "featured" in classes,
    }

records = []
skipped = 0

for li in soup.select("li.news-item"):

        continue
    records.append(record)

def parse_int(text: str) -> int | None:

def parse_table(table) -> tuple[list[str], list[dict]]:
    """표를 (헤더, 레코드 목록)으로 변환합니다."""
    headers = [th.get_text(strip=True) for th in table.select("thead th")]

    # thead 가 없는 표도 있습니다 — 첫 행을 헤더로
    if not headers:
        first_row = table.select_one("tr")
        headers = [c.get_text(strip=True) for c in first_row.select("th, td")]

    rows = []
    for tr in table.select("tbody tr"):
        cells = [td.get_text(strip=True) for td in tr.select("td")]
        if len(cells) != len(headers):
            print(f"  ⚠ 칸 수 불일치 ({len(cells)} vs {len(headers)}) — 건너뜀: {cells}")
            continue
        rows.append(dict(zip(headers, cells)))

    return headers, rows

```python
"""연습용 HTML 서버."""

from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

ARTICLES = [
    {"id": i, "title": f"기사 제목 {i} — MLOps 관련 소식",
     "date": f"2026-08-{12 - (i - 1) // 5:02d}",
     "category": ["경제", "IT", "정책"][i % 3],
     "views": 1000 + i * 137}
    for i in range(1, 26)
]
PAGE_SIZE = 5


def render_list(page: int) -> str:
    start = (page - 1) * PAGE_SIZE
    items = ARTICLES[start:start + PAGE_SIZE]
    total_pages = (len(ARTICLES) + PAGE_SIZE - 1) // PAGE_SIZE

    rows = "\n".join(
        f'''    <li class="news-item{' featured' if a['id'] % 7 == 0 else ''}">
      <a href="/news/{a['id']}" class="title" data-id="{a['id']}">{a['title']}</a>
      <span class="date">{a['date']}</span>
      <span class="category">{a['category']}</span>
      <span class="views">{a['views']:,}</span>
    </li>'''
        for a in items
    )

    pager = " ".join(
        f'<a href="/list?page={p}" class="page{" current" if p == page else ""}">{p}</a>'
        for p in range(1, total_pages + 1)
    )

    return f"""<!DOCTYPE html>
<html lang="ko">
<head><meta charset="utf-8"><title>뉴스 목록 - {page}페이지</title></head>
<body>
  <div id="main">
    <h1>뉴스 목록</h1>
    <p class="meta">전체 {len(ARTICLES)}건 · {page}/{total_pages} 페이지</p>
    <ul class="news-list">
{rows}
    </ul>
    <li class="news-item ad"><a href="https://ad.example.com" class="title">광고</a></li>
    <div class="pagination">{pager}</div>
  </div>
</body>
</html>"""


class Handler(BaseHTTPRequestHandler):
    def log_message(self, fmt, *args):
        print(f"  [server] {fmt % args}")

    def do_GET(self):
        parsed = urlparse(self.path)
        query = parse_qs(parsed.query)

        if parsed.path == "/list":
            page = int(query.get("page", ["1"])[0])
            body = render_list(page).encode("utf-8")
            code = 200
        else:
            body = b"<html><body><h1>404</h1></body></html>"
            code = 404

        self.send_response(code)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)


if __name__ == "__main__":
    print("http://127.0.0.1:8001/list?page=1")
    print("종료하려면 Ctrl+C\n")
    HTTPServer(("127.0.0.1", 8001), Handler).serve_forever()

"""로컬 연습 서버에서 뉴스 목록을 수집합니다."""

import csv
from pathlib import Path
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

BASE = "http://127.0.0.1:8001"
LIST_URL = f"{BASE}/list"


def parse_int(text: str | None) -> int:
    if not text:
        return 0
    cleaned = text.strip().replace(",", "")
    return int(cleaned) if cleaned.isdigit() else 0


def text_of(element, selector: str, default: str = "") -> str:
    found = element.select_one(selector)
    return found.get_text(strip=True) if found else default


def parse_page(html: str, page_url: str) -> list[dict]:
    soup = BeautifulSoup(html, "html.parser")
    records = []

    for li in soup.select("li.news-item:not(.ad)"):
        link = li.select_one("a.title")
        if link is None:
            continue
        href = link.get("href", "")
        if not href.startswith("/news"):
            continue

        records.append({
            "id": parse_int(link.get("data-id")),
            "title": link.get_text(strip=True),
            "url": urljoin(page_url, href),
            "date": text_of(li, "span.date"),
            "category": text_of(li, "span.category", "미분류"),
            "views": parse_int(text_of(li, "span.views")),
        })
    return records


with requests.Session() as session:
    session.headers.update({"User-Agent": "MLOps-Study/1.0 (교육용 실습)"})

    url = f"{LIST_URL}?page=1"
    r = session.get(url, timeout=10)
    r.raise_for_status()

    soup = BeautifulSoup(r.text, "html.parser")
    print(f"제목  : {soup.title.get_text(strip=True)}")
    print(f"메타  : {text_of(soup, 'p.meta')}")
    print(f"페이지: {[a.get_text(strip=True) for a in soup.select('.pagination a')]}")

    records = parse_page(r.text, url)

print(f"\n{len(records)}건 추출\n")
print(f"{'ID':>3} {'제목':<34}{'날짜':<12}{'분류':<8}{'조회':>8}")
print("-" * 70)
for rec in records:
    print(f"{rec['id']:>3} {rec['title']:<34}{rec['date']:<12}{rec['category']:<8}{rec['views']:>8,}")

# 저장
out = Path("data")
out.mkdir(exist_ok=True)
csv_path = out / "news.csv"
with csv_path.open("w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=list(records[0].keys()))
    writer.writeheader()
    writer.writerows(records)
print(f"\n저장: {csv_path}")

import requests
from bs4 import BeautifulSoup

URL = "http://127.0.0.1:8001/list?page=1"

r = requests.get(URL, timeout=10)
soup = BeautifulSoup(r.text, "html.parser")

BAD = "div.article-list > ul.items li.entry a.headline"

print(f"시도한 선택자: {BAD}")
print(f"결과: {len(soup.select(BAD))}개\n")

print("=== 진단 1) 응답 자체를 확인 ===")
print(f"  상태 코드    : {r.status_code}")
print(f"  Content-Type : {r.headers.get('Content-Type')}")
print(f"  본문 길이    : {len(r.text):,}자")
print(f"  본문 앞 120자: {r.text[:120]!r}")

print("\n=== 진단 2) 선택자를 앞에서부터 하나씩 줄여 보기 ===")
parts = BAD.split()
for i in range(1, len(parts) + 1):
    partial = " ".join(parts[:i])
    count = len(soup.select(partial))
    mark = "✓" if count else "✗  ← 여기서 끊김"
    print(f"  {mark} {partial:<48} {count}개")

print("\n=== 진단 3) 실제로 있는 클래스 확인 ===")
from collections import Counter

classes = Counter()
for tag in soup.find_all(class_=True):
    for c in tag.get("class", []):
        classes[c] += 1

print("  많이 쓰인 클래스 (상위 10)")
for name, count in classes.most_common(10):
    print(f"    .{name:<20} {count}회")

print("\n=== 진단 4) 태그 분포 ===")
tags = Counter(tag.name for tag in soup.find_all())
for name, count in tags.most_common(8):
    print(f"    <{name}>{'':<12} {count}개")

print("\n=== 진단 5) 원본 HTML 일부 저장 ===")
from pathlib import Path
Path("debug.html").write_text(soup.prettify(), encoding="utf-8")
print("  debug.html 에 저장했습니다. 브라우저로 열어 확인하세요.")

print("\n=== 결론: 올바른 선택자 ===")
GOOD = "ul.news-list li.news-item a.title"
found = soup.select(GOOD)
print(f"  {GOOD} → {len(found)}개")
for a in found[:3]:
    print(f"    {a.get_text(strip=True)}")
```

## ⑥ 확인 문제

**1.** `select_one()` 과 `select()` 의 차이는 무엇이고, 각각 결과가 없을 때 어떻게 되나요? 안전하게 쓰는 방법을 코드로 보이세요.

<details>
<summary>답 보기</summary>

| | `select_one(선택자)` | `select(선택자)` |
|---|---|---|
| 반환 | 첫 번째 요소 하나 | 리스트 |
| 못 찾으면 | **`None`** | **빈 리스트 `[]`** |
| 위험 | `None.get_text()` → `AttributeError` | 반복문이 그냥 안 돌아 **조용히 0건** |

**`select_one` 의 위험**

```python
title = soup.select_one("h1.title").get_text()
# AttributeError: 'NoneType' object has no attribute 'get_text'
```

프로그램이 **즉시 죽습니다.** 1만 건 수집 중 하나에서 나면 나머지도 다 날아갑니다.

**`select` 의 위험 (더 무서움)**

```python
for item in soup.select("li.news-itemm"):     # 오타
    records.append(parse(item))
# 에러 없음. records 가 비어 있을 뿐.
```

**에러가 안 납니다.** "오늘은 기사가 없나 보다" 하고 넘어가고,
일주일 뒤에 데이터가 하나도 안 쌓인 걸 발견합니다. **조용한 실패**입니다.

**안전하게 쓰는 방법**

```python
def text_of(root, selector: str, default: str = "") -> str:
    """선택자에 해당하는 텍스트. 없으면 기본값."""
    found = root.select_one(selector)
    return found.get_text(strip=True) if found else default


def attr_of(root, selector: str, name: str, default: str = "") -> str:
    found = root.select_one(selector)
    return found.get(name, default) if found else default


# 사용
title = text_of(li, "a.title")
url = attr_of(li, "a.title", "href")
```

**`select` 의 조용한 실패는 검증으로 막습니다.**

```python
items = soup.select("li.news-item")
if not items:
    logger.error("항목을 하나도 못 찾음 — 선택자를 확인하세요. URL=%s", url)
    raise ValueError("선택자가 아무것도 매칭하지 않음")
```

**"0건이면 실패로 간주"** 하는 것이 수집기의 기본 방어입니다.
사이트 구조가 바뀌면 즉시 알아챌 수 있습니다.

W09 [Day 044](../02-sql-pipeline/day-044.md)의 데이터 품질 검증에서 이 원리를 체계화합니다.
"어제는 500건이 들어왔는데 오늘 0건"이면 파이프라인을 멈추고 알림을 보냅니다.
</details>

**2.** `requests` 로 받은 HTML에는 데이터가 없는데 브라우저에서는 보입니다. 원인이 무엇이고, 어떤 순서로 대응해야 하나요?

<details>
<summary>답 보기</summary>

**원인: JavaScript로 그려지는 페이지**

```
서버  ──▶  빈 껍데기 HTML  ──▶  브라우저
                                  │
                                  ├─ JavaScript 실행
                                  ├─ API 호출 (fetch/XHR)
                                  └─ 화면에 데이터 채움
```

`requests` 는 **첫 단계의 HTML만** 받습니다. JavaScript를 실행하지 않습니다.

**확인 방법**

브라우저에서 `Ctrl+U` (페이지 소스 보기) — **개발자 도구가 아닙니다.**
개발자 도구(`F12`)는 JavaScript 실행 **후**의 상태를 보여 주므로 착각하기 쉽습니다.

```python
print("찾는 데이터" in r.text)      # False 면 JS 렌더링
```

**대응 순서**

**① 숨은 API 찾기 (가장 좋음)** ⭐

개발자 도구 → **Network 탭** → **Fetch/XHR** 필터 → 페이지 새로고침.

화면을 채우는 JSON 요청이 보입니다. URL을 복사해 직접 부르세요.

```python
r = requests.get("https://site.com/api/v1/articles",
                 params={"page": 1}, timeout=10)
data = r.json()
```

| 장점 | |
|---|---|
| HTML 파싱 불필요 | JSON을 바로 딕셔너리로 |
| **빠름** | 필요한 데이터만 |
| **안정적** | 화면 디자인이 바뀌어도 API는 유지 |
| 페이지네이션이 명확 | `totalCount`, `page` 등이 응답에 |

**대부분 여기서 해결됩니다.** 화면에 보이는 데이터는 어차피 어딘가에서 옵니다.

**② `<script>` 안의 데이터 파싱**

```html
<script id="__NEXT_DATA__" type="application/json">
{"props":{"articles":[...]}}
</script>
```

Next.js·Nuxt 같은 프레임워크는 초기 데이터를 HTML에 심어 둡니다.

```python
import json
script = soup.select_one("script#__NEXT_DATA__")
data = json.loads(script.string)
articles = data["props"]["pageProps"]["articles"]
```

from playwright.sync_api import sync_playwright

| 불안정 | 대기 시간 조절이 까다로움 |

**3.** 아래 두 선택자 중 어느 쪽이 더 좋고, 왜인가요?

```python
# A — 개발자 도구에서 복사한 것
soup.select("#wrap > div.content > div.list-area > ul > li:nth-child(1) > a.tit")

# B
soup.select("ul.news-list a.title")
```

<details>
<summary>답 보기</summary>

**B가 훨씬 좋습니다.** 세 가지 이유가 있습니다.

**① A는 첫 번째 하나만 잡습니다**

`li:nth-child(1)` 때문에 목록 전체가 아니라 첫 항목만 나옵니다.
개발자 도구의 "Copy selector"는 **클릭한 그 요소 하나를 특정**하도록 만들어 주기 때문입니다.
목록 수집이 목적이라면 이 부분을 지워야 합니다.

**② A는 사이트가 조금만 바뀌어도 깨집니다**

```
#wrap > div.content > div.list-area > ul > li > a.tit
        └─ 이 중 하나만 바뀌어도 전부 실패
```

- 디자이너가 `div.content` 를 `<section>` 으로 바꾸면 → 실패
- 광고 배너용 `<div>` 가 하나 끼면 → 실패
- 반응형 레이아웃으로 구조가 바뀌면 → 실패

**웹사이트는 자주 바뀝니다.** 경로가 길수록 깨질 확률이 곱해집니다.

B는 `ul.news-list` 와 `a.title` 두 개만 유지되면 됩니다.
그리고 **의미를 담은 클래스는 잘 안 바뀝니다.** 디자인이 바뀌어도 "뉴스 목록"이라는 개념은 남습니다.

**③ A는 읽을 수 없습니다**

```python
# 3개월 뒤의 나: 이게 뭘 잡는 거였지?
soup.select("#wrap > div.content > div.list-area > ul > li:nth-child(1) > a.tit")

# 한눈에 이해됨
soup.select("ul.news-list a.title")
```

**좋은 선택자를 고르는 기준**

| 우선순위 | 근거 | 안정성 |
|---|---|---|
| 1 | `id` (`#article-list`) | 매우 높음 |
| 2 | **의미 있는 클래스** (`.news-list`, `.product-item`) | 높음 ⭐ |
| 3 | `data-*` 속성 (`[data-testid="item"]`) | 높음 |
| 4 | 태그 + 속성 (`a[href^="/news/"]`) | 중간 |
| 5 | 위치 (`nth-child`, `> div > div`) | **낮음** ❌ |

**피해야 할 것**

```python
# 자동 생성된 클래스 — 빌드할 때마다 바뀜
soup.select(".css-1x2y3z4")
soup.select(".sc-bdVaJa")

# 스타일용 클래스 — 디자인 바뀌면 사라짐
soup.select(".mt-4.text-lg.font-bold")
```

**실무 요령**

개발자 도구에서 복사한 뒤 **뒤에서부터 지워 가며** 가장 짧게 만듭니다.

```python
"#wrap > div.content > div.list-area > ul.news-list > li.news-item > a.title"
"div.list-area > ul.news-list > li.news-item > a.title"
"ul.news-list > li.news-item > a.title"
"ul.news-list a.title"            # ← 여기까지 줄여도 같은 결과
```

Step 6의 진단 스크립트가 이 작업을 도와줍니다.

## 오늘의 정리

| 항목 | 문법 |
|---|---|
| 파싱 | `BeautifulSoup(html, "html.parser")` |
| 선택 (CSS) | `select(선택자)` 리스트 · `select_one(선택자)` 하나 또는 `None` |
| 선택 (find) | `find("div", class_="x")` · `find_all("a", href=True)` |
| 텍스트 | `get_text(strip=True)` — `.text` 는 후손 전부 |
| 속성 | `.get("href", "")` — `[]` 는 `KeyError` |
| class | **리스트**로 나옴 · `"x" in tag.get("class", [])` |
| 클래스/ID | `.클래스` · `#아이디` |
| 관계 | `A B` 후손 · `A > B` 직계 자식 |
| 속성 조건 | `[href^="/news"]` 시작 · `[href$=".pdf"]` 끝 · `[href*="x"]` 포함 |
| 제외 | `:not(.ad)` |
| 표 | `dict(zip(headers, cells))` |
| URL 변환 | `urljoin(base, href)` — 직접 이어붙이기 금지 |
| 트리 이동 | `find_next_sibling("span")` — `next_sibling` 은 공백일 수 있음 |
| 진단 | 선택자를 앞에서부터 줄여 가며 어디서 0이 되는지 |
| JS 렌더링 | Network 탭에서 **숨은 API 찾기** → script 파싱 → 브라우저 자동화 |
