### 증강이 하는 일

```
원본 늑대 사진 1장
     ↓
좌우 반전, 15° 회전, 살짝 확대, 밝기 조절
     ↓
"조금씩 다른" 늑대 사진 수십 장
```

**모델 입장에서는 매번 새로운 이미지입니다.**

```
증강 없음: 같은 280장을 20번 봄 → 외움
증강 있음: 매 에폭 다른 280장   → 규칙을 배워야 함
```

## ③ 개념 설명

### 증강의 원리

```
모델이 배워야 할 것: "늑대의 형태"
모델이 배우기 쉬운 것: "이 사진의 픽셀 배치"

증강으로 픽셀 배치를 계속 바꾸면
→ 픽셀을 외울 수 없음
→ 변하지 않는 것(형태)을 배울 수밖에 없음
```

**규제(regularization)의 일종입니다.** Dropout과 같은 역할을 합니다.

| 방법 | 하는 일 |
|---|---|
| Dropout | 뉴런을 무작위로 끔 → 특정 뉴런에 의존 못 함 |
| **증강** | **입력을 무작위로 변형** → 특정 픽셀에 의존 못 함 |
| L2 규제 | 가중치를 작게 → 극단적 규칙 방지 |

### 기하 변환

| 변환 | Keras 레이어 | 효과 |
|---|---|---|
| **좌우 반전** | `RandomFlip("horizontal")` | 가장 안전하고 효과적 |
| 상하 반전 | `RandomFlip("vertical")` | **주의** — 의미가 바뀔 수 있음 |
| **회전** | `RandomRotation(0.1)` | ±36° (0.1 = 10% of 360°) |
| **이동** | `RandomTranslation(0.1, 0.1)` | 가로·세로 ±10% |
| **확대/축소** | `RandomZoom(0.1)` | ±10% |
| 전단 | `RandomShear` (TF 2.16+) | 기울이기 |
| **크롭** | `RandomCrop(h, w)` | 무작위 위치 자르기 |

**빈 공간 처리** — 회전·이동하면 모서리에 빈 공간이 생깁니다.

```python
layers.RandomRotation(0.1, fill_mode="reflect")     # 기본값
```

| `fill_mode` | 채우는 방식 |
|---|---|
| `"reflect"` | 거울처럼 반사 (기본값) |
| `"constant"` | 지정한 값 (`fill_value=0`) |
| `"nearest"` | 가장자리 픽셀 복제 |
| `"wrap"` | 반대편에서 이어 붙임 |

### 색 변환

| 변환 | Keras 레이어 | 효과 |
|---|---|---|
| **밝기** | `RandomBrightness(0.2)` | ±20% |
| **대비** | `RandomContrast(0.2)` | ±20% |
| 채도 | `tf.image.random_saturation` | 색의 진하기 |
| 색조 | `tf.image.random_hue` | **주의** — 색이 중요하면 금지 |
| 노이즈 | `GaussianNoise(0.05)` | 잡음 추가 |

> ⚠️ **색 변환은 신중하게.**
> - 잘 익은 토마토(빨강) vs 덜 익은 토마토(초록) → **색조 변환 금지**
> - 늑대 vs 허스키 → 색이 판단 근거일 수 있음. 약하게만

### ★ 증강은 학습셋에만

```
학습셋   : 증강 O    ← 매 에폭 다르게
검증셋   : 증강 X    ← 일관된 평가
테스트셋 : 증강 X    ← 실제 데이터 그대로
```

**왜 검증셋에 증강하면 안 되는가**

| 이유 | 설명 |
|---|---|
| **평가가 매번 달라짐** | 에폭마다 다른 이미지 → 비교 불가 |
| 실제 상황과 다름 | 실제 입력은 증강되지 않음 |
| 모델 선택이 왜곡됨 | 증강된 이미지에 강한 모델을 고르게 됨 |

**Keras 증강 레이어는 자동으로 처리합니다.**

```python
model = keras.Sequential([
    layers.RandomFlip("horizontal"),      # 학습 시에만 동작
    layers.RandomRotation(0.1),           # 추론 시 자동 비활성화
    ...
])
```

**`Dropout` 과 같은 방식**입니다. `training=True` 일 때만 동작합니다.

### 증강 적용 위치 3가지

**① 모델에 포함 (권장)**

```python
model = keras.Sequential([
    layers.Input(shape=(224, 224, 3)),
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.1),
    layers.Rescaling(1./255),
    layers.Conv2D(...),
])
```

| 장점 | 단점 |
|---|---|
| GPU에서 실행 (빠름) | 모델 파일에 증강 층이 포함됨 |
| 추론 시 자동 비활성화 | — |
| 코드가 단순 | — |

**② `tf.data` 파이프라인에서**

```python
augment = keras.Sequential([
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.1),
])
train_ds = train_ds.map(lambda x, y: (augment(x, training=True), y),
                        num_parallel_calls=AUTOTUNE)
```

| 장점 | 단점 |
|---|---|
| 모델과 분리 | `training=True` 를 직접 지정해야 함 |
| CPU 병렬 처리 가능 | 검증셋에 실수로 적용할 위험 |

**③ `ImageDataGenerator` (레거시)**

```python
datagen = ImageDataGenerator(rotation_range=20, horizontal_flip=True, ...)
train_gen = datagen.flow_from_directory("data/train", ...)
```

| 장점 | 단점 |
|---|---|
| 오래된 코드가 많음 | **CPU에서 실행 (느림)** |
| 사용법이 직관적 | **더 이상 권장되지 않음** |

> **신규 코드는 Keras 증강 레이어를 쓰세요.**
> `ImageDataGenerator` 는 TF 2.x 후반부터 deprecated입니다.
> 인터넷의 오래된 예제를 볼 때 구분할 수 있어야 합니다.

### 증강 강도 조절

```python
# 약함
layers.RandomFlip("horizontal"),
layers.RandomRotation(0.05),          # ±18°

# 보통 (권장 시작점)
layers.RandomFlip("horizontal"),
layers.RandomRotation(0.1),           # ±36°
layers.RandomZoom(0.1),
layers.RandomTranslation(0.1, 0.1),

# 강함
layers.RandomFlip("horizontal"),
layers.RandomRotation(0.2),           # ±72°
layers.RandomZoom(0.2),
layers.RandomTranslation(0.2, 0.2),
layers.RandomContrast(0.3),
layers.RandomBrightness(0.3),
```

**너무 강하면**

```
원본을 알아볼 수 없을 정도로 변형
→ 모델이 배울 것이 없어짐
→ 학습 손실도 안 내려감 (과소적합)
```

> **[Day 095](day-095.md)에서 적정선을 실험으로 찾습니다.**

### 증강의 부수 효과

| 효과 | 설명 |
|---|---|
| **에폭당 시간 증가** | 매번 변환 계산 |
| **수렴이 느려짐** | 더 많은 에폭 필요 |
| 학습 정확도 하락 | 문제가 어려워지므로 **정상** |
| **검증 정확도 상승** | 목표 |

```
증강 없음: train 0.99, val 0.71    격차 0.28
증강 있음: train 0.88, val 0.85    격차 0.03
```

**학습 정확도가 낮아지는 것이 정상입니다.** 격차를 보세요.

### Step 1. 증강 레이어 하나씩 확인

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X, y), _ = keras.datasets.cifar10.load_data()

           "dog", "frog", "horse", "ship", "truck"]

# 큰 이미지로 확대해 변환 효과를 잘 보이게
img = tf.image.resize(X[7:8].astype("float32"), (128, 128))

AUGS = {
    "original": None,
    "RandomFlip(h)": layers.RandomFlip("horizontal"),
    "RandomFlip(v)": layers.RandomFlip("vertical"),
    "RandomRotation(0.1)": layers.RandomRotation(0.1),
    "RandomRotation(0.3)": layers.RandomRotation(0.3),
    "RandomZoom(0.2)": layers.RandomZoom(0.2),
    "RandomTranslation(.2,.2)": layers.RandomTranslation(0.2, 0.2),
    "RandomContrast(0.5)": layers.RandomContrast(0.5),
    "RandomBrightness(0.3)": layers.RandomBrightness(0.3, value_range=(0, 255)),
    "GaussianNoise(20)": layers.GaussianNoise(20),
}

print("=" * 70)
print(f"증강 레이어별 효과 — 원본: {CLASSES[int(y[7])]}")
print("=" * 70)

fig, axes = plt.subplots(2, 5, figsize=(17, 7))
for ax, (name, layer) in zip(axes.ravel(), AUGS.items()):
    if layer is None:
        out = img
    else:
        out = layer(img, training=True)
    ax.imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
    ax.set_title(name, fontsize=10)
    ax.axis("off")

fig.suptitle("Each augmentation layer (one sample)", fontsize=14)
fig.tight_layout()
plt.show()

fig.tight_layout()
plt.show()

# ── 파라미터 수 확인 ──
```

### Step 2. training=True / False 차이 확인

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)
(X, y), _ = keras.datasets.cifar10.load_data()
img = tf.image.resize(X[7:8].astype("float32"), (128, 128))

aug = keras.Sequential([
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.2),
    layers.RandomZoom(0.2),
], name="augment")

print("=" * 70)
print("training=True 와 training=False 의 차이")
print("=" * 70)

fig, axes = plt.subplots(2, 6, figsize=(17, 6))

for i in range(6):
    out = aug(img, training=True)
    axes[0, i].imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
    axes[0, i].set_title(f"training=True #{i+1}", fontsize=9)
    axes[0, i].axis("off")

for i in range(6):
    out = aug(img, training=False)
    axes[1, i].imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
    axes[1, i].set_title(f"training=False #{i+1}", fontsize=9)
    axes[1, i].axis("off")

fig.suptitle("Top: augmented (all different)  |  Bottom: unchanged (identical)",
             fontsize=13)
fig.tight_layout()
plt.show()

# ── 수치로 확인 ──
train_outs = [aug(img, training=True).numpy() for _ in range(5)]
eval_outs = [aug(img, training=False).numpy() for _ in range(5)]

print("training=True — 5회 실행 결과가 서로 다른가")
for i in range(4):
    diff = np.abs(train_outs[i] - train_outs[i + 1]).mean()
    print(f"  #{i+1} vs #{i+2}: 평균 차이 {diff:.4f}")

print("\ntraining=False — 5회 실행 결과가 같은가")
for i in range(4):
    diff = np.abs(eval_outs[i] - eval_outs[i + 1]).mean()
    print(f"  #{i+1} vs #{i+2}: 평균 차이 {diff:.4f}")

print(f"\n원본과 training=False 결과가 같은가: "
      f"{np.allclose(img.numpy(), eval_outs[0])}")

print("\n" + "=" * 70)
print("★ 이것이 증강 레이어를 모델에 넣어도 되는 이유입니다")
print("=" * 70)
print("  model.fit()   → training=True  → 증강 적용")
print("  model.evaluate() → training=False → 증강 없음")
print("  model.predict()  → training=False → 증강 없음")
print()
print("  Dropout과 정확히 같은 방식입니다. (Day 096)")
print("=" * 70)


# ── 모델에 넣었을 때 실제 동작 확인 ──
model = keras.Sequential([
    layers.Input(shape=(32, 32, 3)),
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.2),
    layers.Rescaling(1.0 / 255),
    layers.GlobalAveragePooling2D(),          # 단순 확인용
])

x = X[:4].astype("float32")
print("\n모델에 증강 층을 넣었을 때")
print("  predict() 를 3번 호출:")
```

```python
y_full, y_test = y_full.ravel(), y_test.ravel()
X_train = X_full[5000:].astype("float32")
X_val = X_full[:5000].astype("float32")
X_test = X_test.astype("float32")
y_train, y_val = y_full[5000:], y_full[:5000]


def make_augment(level):
    if level == "none":
        return []
    if level == "light":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.05)]
    if level == "medium":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.1),
                layers.RandomZoom(0.1),
                layers.RandomTranslation(0.1, 0.1)]
    if level == "strong":
        return [layers.RandomFlip("horizontal"),
                layers.RandomRotation(0.2),
                layers.RandomZoom(0.2),
                layers.RandomTranslation(0.2, 0.2),
                layers.RandomContrast(0.3),
                layers.RandomBrightness(0.2, value_range=(0, 255))]

    L = [layers.Input(shape=(32, 32, 3))]
    L += make_augment(level)                     # ★ 증강을 모델 맨 앞에
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),

        layers.Activation("relu"),
        layers.Conv2D(64, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),

        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),

        layers.Flatten(), layers.Dropout(0.4),
        layers.Dense(128, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ]
    return keras.Sequential(L)
```

### Step 5. 소량 데이터에서의 효과

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()

# 2클래스 (cat vs dog) 소량 데이터
CAT, DOG = 3, 5
rng = np.random.default_rng(42)


def make_subset(X, y, n_per_class, seed):
    r = np.random.default_rng(seed)
    idx = np.concatenate([
        r.permutation(np.where(y == CAT)[0])[:n_per_class],
        r.permutation(np.where(y == DOG)[0])[:n_per_class]])
    idx = r.permutation(idx)
    return X[idx].astype("float32"), (y[idx] == DOG).astype("int32")


X_te, y_te = make_subset(X_test, y_test, 800, 99)


def build(augment=True):
    L = [layers.Input(shape=(32, 32, 3))]
    if augment:
        L += [layers.RandomFlip("horizontal"),
              layers.RandomRotation(0.1),
              layers.RandomZoom(0.1),
              layers.RandomTranslation(0.1, 0.1)]
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(128, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.GlobalAveragePooling2D(),
        layers.Dropout(0.4),
        layers.Dense(64, activation="relu"),
        layers.Dense(1, activation="sigmoid"),
    ]
    return keras.Sequential(L)


sizes = [50, 100, 200, 500, 1000, 2000]
rows = []

print("=" * 78)
print("데이터 양에 따른 증강 효과 (cat vs dog)")
print("=" * 78)
print(f"{'클래스당':>10}{'전체':>8}{'증강 없음':>12}{'증강 있음':>12}"
      f"{'개선':>10}{'개선율':>10}")
print("-" * 78)

for n in sizes:
    X_tr, y_tr = make_subset(X_full[5000:], y_full[5000:], n, 1)
    X_va, y_va = make_subset(X_full[:5000], y_full[:5000], max(n // 5, 20), 2)

    accs = {}
    for aug in [False, True]:
        tf.random.set_seed(42)
        m = build(aug)
        m.compile(optimizer="adam", loss="binary_crossentropy",
                  metrics=["accuracy"])
        epochs = 60 if aug else 40         # 증강 시 더 오래
        m.fit(X_tr, y_tr, epochs=epochs, batch_size=32,
              validation_data=(X_va, y_va), verbose=0)
        _, acc = m.evaluate(X_te, y_te, verbose=0)
        accs[aug] = acc

    gain = accs[True] - accs[False]
    rel = gain / max(accs[False] - 0.5, 1e-6)      # 무작위 대비 개선율
    rows.append({"클래스당": n, "전체": n * 2,
                 "증강없음": round(accs[False], 4),
                 "증강있음": round(accs[True], 4),
                 "개선": round(gain, 4)})
    print(f"{n:>10}{n*2:>8}{accs[False]:>12.4f}{accs[True]:>12.4f}"
          f"{gain:>+10.4f}{rel:>9.1%}")

df = pd.DataFrame(rows)
print("=" * 78)
```

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()
X_train = X_full[5000:].astype("float32")
X_val = X_full[:5000].astype("float32")
X_test = X_test.astype("float32")
y_train, y_val = y_full[5000:], y_full[:5000]

# ══════════════════════════════════════════
# 증강 조합 3세트
# ══════════════════════════════════════════
SETS = {
    "A. 기하 변환만": [
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.1),
        layers.RandomZoom(0.1),
        layers.RandomTranslation(0.1, 0.1),
    ],
    "B. 색 변환만": [
        layers.RandomContrast(0.3),
        layers.RandomBrightness(0.2, value_range=(0, 255)),
        layers.GaussianNoise(10),
    ],
    "C. 기하 + 색 (조합)": [
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.1),
        layers.RandomZoom(0.1),
        layers.RandomTranslation(0.1, 0.1),
        layers.RandomContrast(0.2),
        layers.RandomBrightness(0.15, value_range=(0, 255)),
    ],
}


def build(aug_layers):
    L = [layers.Input(shape=(32, 32, 3))] + list(aug_layers)
    L += [
        layers.Rescaling(1.0 / 255),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.Conv2D(32, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Conv2D(64, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.Conv2D(64, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Conv2D(128, 3, padding="same"), layers.BatchNormalization(),
        layers.Activation("relu"),
        layers.MaxPooling2D(2), layers.Dropout(0.25),
        layers.Flatten(), layers.Dropout(0.4),
        layers.Dense(128, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ]
    return keras.Sequential(L)


# ── 각 세트의 증강 결과 시각화 ──

           "dog", "frog", "horse", "ship", "truck"]

    aug = keras.Sequential(aug_layers)
    axes[row, 0].imshow(sample[0].numpy().astype("uint8"))
    axes[row, 0].set_title("original", fontsize=8.5)
    axes[row, 0].axis("off")
    for col in range(1, 7):
        out = aug(sample, training=True)
        axes[row, col].imshow(np.clip(out[0].numpy(), 0, 255).astype("uint8"))
        axes[row, col].set_title(name.split(".")[0], fontsize=8.5)
        axes[row, col].axis("off")
fig.suptitle("Three augmentation sets", fontsize=14)
fig.tight_layout()
plt.show()

# ── 성능 비교 ──
EPOCHS = 40
rows, histories = [], {}

print("=" * 70)
print(f"증강 조합 비교 — {EPOCHS}에폭")
print("=" * 70)

# 베이스라인
tf.random.set_seed(42)
m = build([])
m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
          metrics=["accuracy"])
t0 = time.time()
h = m.fit(X_train, y_train, epochs=EPOCHS, batch_size=128,
          validation_data=(X_val, y_val), verbose=0).history
_, acc = m.evaluate(X_test, y_test, verbose=0)
rows.append({"조합": "증강 없음", "train": round(h["accuracy"][-1], 4),
             "test": round(acc, 4),
             "격차": round(h["accuracy"][-1] - acc, 4),
             "최적에폭": int(np.argmin(h["val_loss"])) + 1,
             "시간(s)": round(time.time() - t0, 1)})
histories["증강 없음"] = h
print(f"{'증강 없음':<20} test {acc:.4f}")

for name, aug_layers in SETS.items():
    tf.random.set_seed(42)
    m = build(aug_layers)
    m.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
    t0 = time.time()
    h = m.fit(X_train, y_train, epochs=EPOCHS, batch_size=128,
              validation_data=(X_val, y_val), verbose=0).history
    elapsed = time.time() - t0
    _, acc = m.evaluate(X_test, y_test, verbose=0)
    rows.append({"조합": name, "train": round(h["accuracy"][-1], 4),
                 "test": round(acc, 4),
                 "격차": round(h["accuracy"][-1] - acc, 4),
                 "최적에폭": int(np.argmin(h["val_loss"])) + 1,
                 "시간(s)": round(elapsed, 1)})
    histories[name] = h
    print(f"{name:<20} test {acc:.4f}")

df = pd.DataFrame(rows)
df["관찰"] = [
    "격차 0.18. 14에폭부터 과적합",
    "가장 큰 개선. 위치·크기 변화에 강해짐",
    "개선폭 작음. CIFAR는 색보다 형태가 중요",

print("\n" + "=" * 110)
print("증강 조합 실험 기록표")
print("=" * 110)
print(df.to_string(index=False))
print("=" * 110)

best = df.loc[df["test"].idxmax()]
print(f"\n최고: {best['조합']} → test {best['test']:.4f}")
print(f"\n결론")
print(f"  기하 변환이 핵심입니다 (+{df.iloc[1]['test'] - df.iloc[0]['test']:.4f})")
print(f"  색 변환 단독은 효과가 작습니다 (+{df.iloc[2]['test'] - df.iloc[0]['test']:.4f})")

print()
print("  ※ 데이터 성격에 따라 다릅니다.")

# ── 그래프 ──
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

ax = axes[0]
for name in histories:
    ax.plot(histories[name]["val_accuracy"], linewidth=2, label=name)
ax.set_xlabel("epoch"); ax.set_ylabel("val accuracy")
ax.set_title("Validation accuracy")
ax.legend(fontsize=8.5); ax.grid(alpha=0.3)

ax = axes[1]

ax.bar(x - 0.2, df["train"], 0.4, label="train")

ax.legend(); ax.grid(alpha=0.3, axis="y")

fig.tight_layout()
plt.show()

OUT = Path("/content/drive/MyDrive/ml_course/experiments")

df.to_csv(OUT / "day094_aug_sets.csv", index=False, encoding="utf-8-sig")
```

### 검증셋·테스트셋에도 증강을 적용


**증상** — 검증 정확도가 에폭마다 크게 흔들립니다.

**해결** — 증강은 학습셋에만.

> **증강 레이어를 모델에 넣으면 이 실수가 원천 차단됩니다.**
> `evaluate` / `predict` 는 `training=False` 로 실행되기 때문입니다.

### `training=True` 를 빼먹음

```python

```

**`tf.data` 파이프라인에서는 명시해야 합니다.**

```python
train_ds = train_ds.map(lambda x, y: (augment(x, training=True), y))      # ✓
```

**확인 방법** — 증강된 이미지를 시각화해서 실제로 변하는지 보세요.

| 1 | **정규화가 증강 앞에** | `RandomBrightness` 의 `value_range` 불일치 |
| 2 | **`value_range` 미지정** | 0~1 데이터에 0~255 기준 적용 → 거의 무효 |
| 3 | **`RandomRotation(0.5)`** | ±180°. 너무 강함 |
| 4 | **`training=True` 누락** | **증강이 아예 안 됨** |
| 5 | **검증셋에도 증강** | 평가가 매 에폭 달라짐 |
| 6 | **정규화 중복** | `augment` 와 모델에서 각각 → 0~0.004 |

**고친 코드 (방법 1 — 모델에 증강 내장, 권장)**

```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

AUTOTUNE = tf.data.AUTOTUNE

train_ds = keras.utils.image_dataset_from_directory(
    "data/train", image_size=(224, 224), batch_size=32, shuffle=True, seed=42)
val_ds = keras.utils.image_dataset_from_directory(
    "data/val", image_size=(224, 224), batch_size=32, shuffle=False)

train_ds = train_ds.cache().prefetch(AUTOTUNE)      # ★ .map() 제거
val_ds = val_ds.cache().prefetch(AUTOTUNE)          # ★ 증강 없음

model = keras.Sequential([
    layers.Input(shape=(224, 224, 3)),

    # ★ 증강을 모델 맨 앞에 (training=True일 때만 동작)
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.1),                     # ③ 0.5 → 0.1
    layers.RandomZoom(0.1),
    layers.RandomBrightness(0.2, value_range=(0, 255)),   # ②

    layers.Rescaling(1.0 / 255),                    # ① 증강 뒤에, ⑥ 한 번만

    layers.Conv2D(32, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),
    layers.Conv2D(64, 3, padding="same", activation="relu"),
    layers.MaxPooling2D(2),
    layers.GlobalAveragePooling2D(),
    layers.Dense(2, activation="softmax"),
])

model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.fit(train_ds, validation_data=val_ds, epochs=50)      # 증강 시 에폭 증가
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 증강의 원리 | **같은 대상을 다르게 보여주기** → 픽셀을 못 외움 |
| 규제의 일종 | Dropout과 같은 역할 |
| 기하 변환 | Flip · Rotation · Zoom · Translation · Crop |
| 색 변환 | Brightness · Contrast · Saturation · Noise |
| **가장 효과적** | **좌우 반전 + 회전 + 확대 + 이동** |
| 파라미터 | 증강 레이어는 **0개** |
| **★ 학습셋에만** | 검증·테스트에 적용 금지 |
| `training=True` | 학습 시에만 동작. **모델에 넣으면 자동** |
| 적용 위치 | **모델 맨 앞** (권장) / tf.data / ImageDataGenerator(레거시) |
| 정규화 순서 | **증강 먼저, 정규화 나중** |
| `value_range` | `RandomBrightness` 에 **반드시 지정** |
| 강도 시작점 | `RandomRotation(0.1)`, `RandomZoom(0.1)` |
| 너무 강하면 | **train < test** → 과소적합 |
| 부수 효과 | 학습 정확도 하락(정상) · **최적 에폭 증가** · 시간 증가 |
| 효과 크기 | CIFAR +6.4%p · 소량 데이터 +10%p |
| **데이터가 적을수록** | **효과가 큼** |
| 확인 습관 | **증강 이미지 9장을 눈으로** |

> ③ **증강하면 에폭을 2~3배 늘리세요.** 최적 에폭이 14 → 39로 늘어납니다.
