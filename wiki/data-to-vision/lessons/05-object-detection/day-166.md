이 레슨을 마치면 이렇게 할 수 있습니다.

- 라즈베리파이의 **모델 · RAM · 전원 · 냉각 · 저장장치**를 프로젝트 요구에 맞게 고를 수 있다.
- Imager 로 **초기 설정을 주입해** OS 를 굽고, 모니터 없이 첫 부팅을 성공시킬 수 있다.
- **고정 IP · DHCP 예약 · mDNS** 로 접속 주소를 고정할 수 있다.
- **SSH 키 인증**을 설정하고 비밀번호 인증을 끌 수 있으며, `~/.ssh/config` 로 별칭을 만들 수 있다.
- **필수 리눅스 명령**과 **파일 권한**(`rwx` · `chmod` · `video` 그룹)을 다룰 수 있다.
- **파이썬 가상환경**을 만들고 **`externally-managed-environment`** 오류를 해결할 수 있다.
- `rsync` · **VS Code Remote-SSH** 로 노트북과 파이 사이에서 코드를 옮기며 작업할 수 있다.
- **SD 카드 백업**과 **안전 종료**로 하루 작업을 잃지 않을 수 있다.

## ② 왜 필요한가

### 어제까지 만든 웹은 노트북 안에서만 돕니다

[Day 165](day-165.md)에서 우리는 waitress 로 Flask 앱을 띄우고, 옆자리 사람의 휴대폰으로 접속해 검출을 실행했습니다. 그런데 **그 서버는 여러분의 노트북**입니다.

```
지금 상태
  [노트북]  ← 웹 서버 + 모델 + 웹캠
     └─ 수업이 끝나면 ★ 가방에 들어갑니다
```

CCTV 는 정의상 **자리를 지키는 장치**입니다. 노트북으로는 아래를 만족할 수 없습니다.

| 요구 | 노트북 | 이유 |
|---|---|---|
| 24시간 무인 가동 | ✗ | 가지고 다녀야 함 · 뚜껑 닫으면 절전 |
| 현관·창고에 설치 | ✗ | 크기 · 도난 · 미관 |
| 전기요금 | △ | 아이들 **15~25W**, 추론 중 **45~65W** |
| 카메라 위치 | ✗ | 내장 웹캠은 화면 방향에 고정 |
| 고장 시 피해 | ✗ | **개인 노트북이 죽으면 과제도 같이 죽음** |

```
★ 24시간 × 30일 전력량
  노트북 (평균 40W)   28.8 kWh
  라즈베리파이 5      5.0 kWh      (1/5.7)
  Pi Zero 2 W          1.4 kWh

★ 전력만의 문제가 아니라 "놓아둘 수 있느냐"의 문제입니다.
```

### 왜 클라우드가 아니라 현장인가

"영상을 서버로 보내서 좋은 GPU 로 돌리면 되지 않나요?" 라는 질문이 반드시 나옵니다. [Day 154](day-154.md)에서 **⑤ 서버 추론안을 기각**했던 이유를 숫자로 다시 봅니다.

```
1080p 15FPS 영상을 24시간 서버로 보내면
  H.264 4 Mbps × 86,400s = 43,200 MB = ★ 하루 43 GB (한 달 1.3 TB)
  · 가정용 업로드 회선을 종일 점유
  · 카메라 3대면 하루 129 GB
  · 그 영상 안에는 사람 얼굴이 들어 있습니다

엣지에서 처리하면 (검출 이벤트만 전송)
  이벤트 JSON 0.5KB + 스냅샷 JPEG 120KB, 하루 200건
  → ★ 24 MB / 일        43,200MB → 24MB : 1,800배 감소
```

```
싱글보드 컴퓨터 = 카드 한 장 위에 컴퓨터 전체

  신용카드 크기 (85 × 56 mm)
```

| 구분 | 데스크톱 PC | **싱글보드 컴퓨터** | 마이크로컨트롤러 |
|---|---|---|---|
| 예 | 일반 PC | **라즈베리파이** | 아두이노 · ESP32 |
| OS | Windows·Linux | **리눅스** | 없음(펌웨어) |
| RAM | 8~64 GB | 0.5~16 GB | 수십 KB |
| 딥러닝 추론 | ◎ | **△ (경량 모델만)** | ✗ |
| 소비 전력 | 100~500 W | **3~12 W** | 0.05~0.5 W |
| 가격 | 80만~ | 3만~15만 | 5천~2만 |

```
★ 우리가 라즈베리파이를 쓰는 이유
  ① 리눅스가 돌아갑니다 → 파이썬·OpenCV·YOLO 가 그대로 동작
  ② 카메라 인터페이스(CSI)가 있습니다
  ③ 자료가 압도적으로 많습니다 → 막혔을 때 검색이 됩니다
  ④ 전력이 낮아 24시간 켜 둘 수 있습니다
```

**엣지 컴퓨팅 — 계산을 데이터가 생기는 곳에서**

```
클라우드   [센서] ──원본 전부──→ [클라우드] ──결과──→ [사용자]
                   ↑ 대역폭·지연·개인정보·인터넷 의존

엣지       [센서 + 계산] ──결과만──→ [클라우드]
                ★ 원본은 현장에 남습니다
```

| 이유 | 설명 | 우리 프로젝트에서 |
|---|---|---|
| **지연** | 왕복 네트워크가 빠짐 | 감지 → 알림까지 1초 이내 |
| **대역폭** | 원본 영상을 안 보냄 | 하루 43 GB → **24 MB** |
| **개인정보** | 얼굴이 밖으로 안 나감 | 현관 영상을 외부에 저장하지 않음 |
| **오프라인** | 인터넷이 끊겨도 동작 | 공유기가 죽어도 로컬 DB 에 기록 |

```
★ 지연 비교 (사람이 지나간 순간 → 알림)
  서버 추론  캡처20 + 인코딩15 + 업로드180 + 추론25 + 발송300 = 540ms
             (Wi-Fi 가 나쁘면 2~5초)
  엣지 추론  캡처20 + 추론260(NCNN640) + 발송300 = 580ms
             (네트워크가 느려도 추론 시간은 그대로)

★ 핵심은 "평균"이 아니라 "최악"입니다.
```

```
★ 엣지의 단점도 분명합니다
  ① 연산 성능이 낮음   PyTorch 원본 YOLO11n → 파이에서 ★ 1.9 FPS (Day 153)
                       → 그래서 NCNN 변환이 필수였습니다
  ② 메모리가 작음      8GB 가 최대. 학습 불가, 추론 전용
  ③ 관리 대상이 늘어남  기기 10대 = 업데이트 10번 → Day 170 에서 자동화
  ④ 물리적으로 고장남   SD 수명 · 정전 · 습기 · 먼지
```

> ⚠️ **엣지는 "클라우드보다 좋다"가 아니라 "다른 트레이드오프"입니다.**
> [Day 154](day-154.md)에서 **하이브리드**를 고른 이유가 이것입니다.

### ★ 전원 — 가장 많이 실수하는 곳

```
Raspberry Pi 5 전원 요구  ★ 5V / 5A (25W) USB-C PD
  · 공식 27W 어댑터 권장. PD 협상으로 5A 를 끌어옵니다
  · 5V/3A 를 쓰면 부팅은 되지만
    → USB 포트 출력이 600mA 로 제한되고 부하 시 언더볼티지
```

> ⚠️ **휴대폰 충전기를 쓰지 마세요.**
> "5V 2A" 표기가 있어도 케이블 저항 때문에 **부하 상태에서 4.7V 로 떨어집니다.**
> 이게 오늘 실습에서 나오는 **원인 불명 오류 1순위**입니다.

| 증상 | 설명 |
|---|---|
| 화면 우측 상단 **번개 ⚡** | 언더볼티지 경고 |
| `Undervoltage detected!` | `journalctl`·`dmesg` 에 반복 |
| USB 장치가 갑자기 사라짐 | **웹캠 인식 끊김** (Day 167 에서 치명적) |
| 재부팅 반복 | 부하가 걸리는 순간 리셋 |
| SD 파일시스템 손상 | 쓰기 중 전압 강하 |
| FPS 가 들쭉날쭉 | ARM 주파수 캡핑 |

```bash
vcgencmd get_throttled
```

```
throttled=0x0        ← ★ 정상
```

```
★ 비트 해석
  0x1     현재 언더볼티지     0x8      현재 소프트 온도제한(80°C)
  0x2     현재 주파수 캡핑    0x10000  부팅 후 언더볼티지 발생함
  0x4     현재 스로틀링 중    0x40000  부팅 후 스로틀링 발생함

예) throttled=0x50000 = 0x10000 + 0x40000
    → ★ "언더볼티지가 있었고 스로틀링도 있었다" → 전원부터 교체
```

### 발열과 스로틀링

|---|---|---|

```
Windows — Win32DiskImager
  ① SD 를 노트북에 꽂기 ② Image File 경로 지정
  ③ Device 에서 SD 드라이브 선택 ★ 반드시 확인
  ④ [Read] 클릭 — Write 가 아닙니다!      ⑤ 64GB 기준 20~35분
```

```bash
lsblk                                    # ★ 장치 확인 (반드시)
sudo dd if=/dev/mmcblk0 of=~/backup/cctv-pi-01_2026-08-10.img \
     bs=4M status=progress conv=fsync
gzip -9 ~/backup/cctv-pi-01_2026-08-10.img       # 64GB → 약 2.8GB
```

```
mmcblk0     179:0    0  59.5G  0 disk          ← ★ SD 카드
├─mmcblk0p1 179:1    0   512M  0 part
└─mmcblk0p2 179:2    0    59G  0 part
```

> ⚠️ **`dd` 는 `if` 와 `of` 를 바꿔 쓰면 되돌릴 수 없습니다.**
> `if`=읽을 곳, `of`=쓸 곳. 반대로 쓰면 **노트북 디스크를 SD 내용으로 덮어씁니다.**
> 별명이 "disk destroyer" 인 이유입니다. **`lsblk` 로 두 번 확인하세요.**

### Step 8. 시스템 정보 수집 스크립트 `sysinfo.py`

**`~/cctv_project/src/sysinfo.py`**

```python
"""sysinfo.py — 라즈베리파이 기기 정보 수집

노트북에서:  ssh pi1 "python ~/cctv_project/src/sysinfo.py --json"
파이에서:    python src/sysinfo.py
"""
from __future__ import annotations

import argparse
import json
import platform
import re
import shutil
import socket
import subprocess
from datetime import datetime, timezone
from pathlib import Path


def run(cmd: str, default: str = "") -> str:
    """셸 명령을 실행하고 표준출력을 반환 — 실패하면 default"""
    try:
        out = subprocess.run(cmd, shell=True, capture_output=True,
                             text=True, timeout=5)
        return out.stdout.strip() if out.returncode == 0 else default
    except Exception:
        return default


def read_text(path: str, default: str = "") -> str:
    try:
        return Path(path).read_text(errors="ignore").strip()
    except Exception:
        return default


def get_model() -> str:
    """라즈베리파이 모델명 — /proc/device-tree/model"""
    # ★ 널 바이트가 붙어 있으므로 제거
    return read_text("/proc/device-tree/model", "unknown").replace("\x00", "")


def get_os() -> dict:
    pretty = ""
    for line in read_text("/etc/os-release").splitlines():
        if line.startswith("PRETTY_NAME="):
            pretty = line.split("=", 1)[1].strip('"')
    return {
        "name": pretty or platform.platform(),
        "kernel": platform.release(),
        "arch": platform.machine(),          # ★ aarch64 여야 함
        "python": platform.python_version(),
    }


def get_cpu() -> dict:
    cpuinfo = read_text("/proc/cpuinfo")
    cores = cpuinfo.count("processor\t:")
    freq_hz = run("vcgencmd measure_clock arm")
    m = re.search(r"=(\d+)", freq_hz)
    cur_mhz = int(m.group(1)) / 1e6 if m else None

    max_khz = read_text("/sys/devices/system/cpu/cpu0/cpufreq/"
                        "scaling_max_freq", "0")
    return {
        "cores": cores,
        "model": next((l.split(":", 1)[1].strip()
                       for l in cpuinfo.splitlines()
                       if l.startswith("Model")), ""),
        "current_mhz": round(cur_mhz, 1) if cur_mhz else None,
        "max_mhz": round(int(max_khz) / 1000, 1) if max_khz.isdigit() else None,
    }


def get_memory() -> dict:
    """/proc/meminfo 파싱 — MB 단위"""
    info = {}
    for line in read_text("/proc/meminfo").splitlines():
        key, _, val = line.partition(":")
        num = val.strip().split()
        if num and num[0].isdigit():
            info[key] = int(num[0])          # kB
    total = info.get("MemTotal", 0) / 1024
    avail = info.get("MemAvailable", 0) / 1024
    swap = info.get("SwapTotal", 0) / 1024
    return {
        "total_mb": round(total),
        "available_mb": round(avail),
        "used_pct": round((1 - avail / total) * 100, 1) if total else None,
        "swap_mb": round(swap),
    }


def get_thermal() -> dict:
    """온도 · 스로틀링 — CCTV 는 24시간 돌기 때문에 중요"""
    temp_raw = run("vcgencmd measure_temp")           # temp=47.2'C
    m = re.search(r"([\d.]+)", temp_raw)
    temp = float(m.group(1)) if m else None
    if temp is None:                                   # 대체 경로
        z = read_text("/sys/class/thermal/thermal_zone0/temp", "")
        temp = round(int(z) / 1000, 1) if z.isdigit() else None

    th_raw = run("vcgencmd get_throttled")             # throttled=0x0
    m2 = re.search(r"0x([0-9a-fA-F]+)", th_raw)
    bits = int(m2.group(1), 16) if m2 else 0
    flags = {
        "under_voltage_now": bool(bits & 0x1),
        "throttled_now": bool(bits & 0x4),
        "soft_temp_limit_now": bool(bits & 0x8),
        "under_voltage_occurred": bool(bits & 0x10000),   # ★ 발생 이력
        "throttling_occurred": bool(bits & 0x40000),      # ★ 발생 이력
    }
    return {"temp_c": temp, "throttled_hex": f"0x{bits:x}", "flags": flags}


def get_disk() -> dict:
    total, used, free = shutil.disk_usage("/")
    return {
        "total_gb": round(total / 1024**3, 1),
        "used_gb": round(used / 1024**3, 1),
        "free_gb": round(free / 1024**3, 1),
        "used_pct": round(used / total * 100, 1),
    }


def get_network() -> dict:
    ips = run("hostname -I").split()
    return {
        "hostname": socket.gethostname(),
        "ips": ips,
        "eth_mac": run("cat /sys/class/net/eth0/address"),
        "wifi_ssid": run("iwgetid -r"),
    }


def get_camera() -> dict:
    """Day 167 준비 — 카메라가 보이는지만 확인"""
    csi = run("rpicam-hello --list-cameras 2>/dev/null") or \
          run("libcamera-hello --list-cameras 2>/dev/null")
    usb = run("ls /dev/video* 2>/dev/null")
    return {
        "csi_detected": "Available cameras" in csi,
        "video_devices": usb.split() if usb else [],
    }


def collect() -> dict:
    return {
        "collected_at": datetime.now(timezone.utc)
                        .astimezone().isoformat(timespec="seconds"),
        "model": get_model(),
        "os": get_os(),
        "cpu": get_cpu(),
        "memory": get_memory(),
        "thermal": get_thermal(),
        "disk": get_disk(),
        "network": get_network(),
        "camera": get_camera(),
        "uptime": run("uptime -p"),
    }


def print_table(d: dict) -> None:
    t = d["thermal"]
    warn = []
    if d["os"]["arch"] != "aarch64":
        warn.append("32-bit OS 입니다 — SD 를 다시 구우세요")
    if t["flags"]["under_voltage_occurred"]:
        warn.append("언더볼티지 발생 이력 — 전원 어댑터를 교체하세요")
    if t["flags"]["throttling_occurred"]:
        warn.append("스로틀링 발생 이력 — 냉각을 보강하세요")
    if t["temp_c"] and t["temp_c"] >= 75:
        warn.append(f"온도가 높습니다 ({t['temp_c']}°C)")
    if d["disk"]["used_pct"] >= 85:
        warn.append("디스크 사용률 85% 초과")

    rows = [
        ("모델", d["model"]),
        ("호스트명", d["network"]["hostname"]),
        ("IP", " / ".join(d["network"]["ips"]) or "-"),
```
