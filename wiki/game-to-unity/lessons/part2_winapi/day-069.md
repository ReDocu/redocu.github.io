## 3. 개념

### 3-1. 바람 — 수평 가속도

**왜 필요한가** — 중력이 세로 가속도라면, 바람은 가로 가속도다.

```cpp
void Shell::Update(double dt)
{
    m_vy += GRAVITY * dt;
    m_vx += m_wind * dt;                       // ★ 바람
    m_x += m_vx * dt;
    m_y += m_vy * dt;
}
```

```
   ★ 중력과 완전히 같은 구조

   중력:  vy += g    * dt      세로로 민다
   바람:  vx += wind * dt      가로로 민다
```

```
   바람 없음                바람 오른쪽

      ·  ·  ·                    ·  ·  ·  ·
   ·           ·             ·              ·  ·
  ▲             ▼          ▲                     ▼
                                          ↑ 더 멀리
```

**바람 세기와 사거리 변화**

| 바람 | 45°/힘300 사거리 | 차이 |
|:--:|:--:|:--:|
| -20 (왼쪽) | 197 px | -28 |
| -10 | 211 px | -14 |
| **0** | **225 px** | — |
| +10 | 239 px | +14 |
| +20 | 253 px | +28 |

```
   ★ 대략 선형이다

   보정량 ≈ 바람 × 비행시간² / 2

   비행 시간이 길수록 (= 높이 쏠수록) 영향이 크다
```

### 3-2. ⚠️ 바람은 속도가 아니라 가속도

**왜 필요한가** — 흔한 오해다.

```cpp
    // ✗ 틀림: 속도에 더하기
    m_x += (m_vx + m_wind) * dt;
```

```
   문제

   비행 시간과 무관하게 일정한 영향
   → 짧게 쏘나 길게 쏘나 같은 만큼 밀린다
   → 현실감이 없다
```

```cpp
    // ✔ 맞음: 가속도
    m_vx += m_wind * dt;
    m_x  += m_vx * dt;
```

```
   ★ 가속도라서 시간의 제곱으로 누적된다

   Δx = ½ × wind × t²

   t=1초, wind=20  →  10 px
   t=2초, wind=20  →  40 px    ← 4배
   t=3초, wind=20  →  90 px    ← 9배
```

```
   전략이 생긴다

   "바람이 강하다  →  낮게 빠르게 쏜다 (비행 시간 단축)"
```

### 3-3. 바람 표시

**왜 필요한가** — 방향과 세기를 한눈에 알아야 한다.

```cpp
void RenderWind(Renderer& r, double wind, int cx, int cy)
{
    int strength = (int)fabs(wind);

    if (strength < 1)
    {
        r.DrawText(cx - 20, cy, RGB(180,180,180), "무풍");
        return;
    }

    bool left = (wind < 0);

    // 세기에 비례한 화살표 개수 (최대 5개)
    int arrows = strength / 4 + 1;
    if (arrows > 5) arrows = 5;

    // 세기에 따른 색
    COLORREF col = RGB(120, 200, 255);
    if (strength >= 12) col = RGB(255, 200, 100);
    if (strength >= 20) col = RGB(255, 110, 110);

    char buf[64];
    int len = 0;

    for (int i = 0; i < arrows; i++)
        len += sprintf(buf + len, left ? "◀" : "▶");

    sprintf(buf + len, " %d", strength);

    r.DrawText(cx, cy, col, buf);
}
```

```
   바람 표시 예

   ◀◀◀ 14        왼쪽으로 강하게
   ▶ 3           오른쪽으로 약하게
   무풍           없음
```

```
   ★ 색으로 위험도를 알린다

   파랑  (0~11)   약함
   주황  (12~19)  보통
   빨강  (20+)    강함
```

### 3-7. 바람 생성

**왜 필요한가** — 매 턴 달라져야 한다. 하지만 너무 극단적이면 안 된다.

```cpp
void FortressScene::GenerateWind()
{
    // -MAX ~ +MAX
    int range = MAX_WIND * 2 + 1;
    m_wind = (double)(rand() % range - MAX_WIND);

    // ★ 이전 바람과 너무 다르면 완화 (선택)
    if (m_smoothWind)
    {
        double diff = m_wind - m_prevWind;
        if (fabs(diff) > MAX_WIND)
            m_wind = m_prevWind + (diff > 0 ? MAX_WIND : -MAX_WIND);
    }

    m_prevWind = m_wind;
}
```

```

   턴1:  +18          턴1:  +18

   턴3:  +5           턴3:  -4
```

### 3-8. 명중 판정

**왜 필요한가** — 탱크에 맞았는지 확인한다.

```cpp
void Shell::OnImpact(double x, double y)
{
    int radius = WEAPONS[m_weapon].radius;
    int maxDmg = WEAPONS[m_weapon].damage;

    m_terrain->Destroy((int)x, (int)y, radius);
    m_explosions->Spawn(x, y, radius * 1.5);
    m_smoke->Spawn(x, y);
    m_camera->Shake(radius * 0.2, 0.25);

    // ★ 범위 내 탱크에 피해
    for (int i = 0; i < 2; i++)
    {
        Tank& t = m_scene->GetTank(i);
        if (!t.IsAlive()) continue;

        double dx = t.GetX() - x;
        double dy = t.GetY() - y;
        double dist = sqrt(dx*dx + dy*dy);

        if (dist > radius) continue;

        // ★ 중심에 가까울수록 큰 피해
        double ratio = 1.0 - (dist / radius);
        int dmg = (int)(maxDmg * ratio);
        if (dmg < 1) dmg = 1;

        t.TakeDamage(dmg);

        DebugLog("[명중] P%d, 거리 %.0f, 피해 %d\n", i+1, dist, dmg);
    }
}
```

```
   거리별 피해 (반경 30, 최대 25)

   거리  0   →  25   직격
   거리 10   →  16
   거리 20   →   8
   거리 29   →   1   스침
   거리 31   →   0   빗나감
```

```
   ★ 자기 자신도 맞는다
```

### 3-9. HP 게이지

**왜 필요한가** — Day 48의 지연 게이지를 재사용한다.

```cpp
class HpGauge
{
public:
    void Set(int hp, int maxHp)
    {
        m_target = (double)hp / maxHp;
        if (m_current < m_target) m_current = m_target;   // 회복은 즉시
    }

    void Update(double dt)
    {
        if (m_delay > 0) { m_delay -= dt; return; }

        if (m_current > m_target)
        {
            m_current -= dt * 0.5;
            if (m_current < m_target) m_current = m_target;
        }
    }

    void OnDamage() { m_delay = 0.4; }

    void Render(Renderer& r, int x, int y, int w, int h, bool rightAlign)
    {
        r.DrawRect(x, y, w, h, RGB(40, 40, 40));

        int redW = (int)(w * m_current);
        int curW = (int)(w * m_target);

        if (rightAlign)
        {
            r.DrawRect(x + w - redW, y, redW, h, RGB(200, 60, 60));
            r.DrawRect(x + w - curW, y, curW, h, RGB(90, 200, 90));
        }
        else
        {
            r.DrawRect(x, y, redW, h, RGB(200, 60, 60));
            r.DrawRect(x, y, curW, h, RGB(90, 200, 90));
        }
    }

private:
    double m_current = 1.0, m_target = 1.0, m_delay = 0;
};
```

```cpp
void FortressScene::UpdateAI(double dt)
{
    m_aiThinkTime += dt;
    if (m_aiThinkTime < 1.2) return;           // ★ 생각하는 척

    Tank& me = m_tanks[m_currentPlayer];
    Tank& enemy = m_tanks[1 - m_currentPlayer];

    // 이전 명중 정보로 보정
    double bestAngle = 45, bestPower = 50;
    double bestErr = 1e9;

    // ★ 여러 조합을 시뮬레이션해서 가장 가까운 것을 고른다
    for (int a = 20; a <= 75; a += 3)
    {
        for (int p = 30; p <= 100; p += 5)
        {
            Vector2 v = CalcLaunchVelocity(a, p * POWER_SCALE);
            if (me.GetX() > enemy.GetX()) v.x = -v.x;

            int landX = SimulateLanding(me.GetMuzzleX(), me.GetMuzzleY(),
                                        v.x, v.y, m_wind);

            double err = fabs(landX - enemy.GetX());

            if (err < bestErr) { bestErr = err; bestAngle = a; bestPower = p; }
        }
    }

    // ★ 난이도에 따라 오차를 섞는다
    double miss = AI_MISS[m_difficulty];
    bestAngle += (rand() % 200 - 100) * 0.01 * miss;
    bestPower += (rand() % 200 - 100) * 0.01 * miss;

    me.SetAngle(bestAngle);
    me.SetPower(bestPower);

    Fire();
    m_aiThinkTime = 0;
}
```

```cpp
void Camera::FollowSmooth(double tx, double ty, double t)
{
    if (t > 1) t = 1;

    m_x += (tx - m_viewW * 0.5 - m_x) * t;
    m_y += (ty - m_viewH * 0.5 - m_y) * t;

    Clamp();
}
```


```cpp
void FortressScene::UpdateAim(double dt)
{
    m_turnTime -= dt;

    if (m_turnTime <= 0) { Fire(); return; }

    if (m_isAI[m_currentPlayer]) { UpdateAI(dt); return; }

    Tank& t = m_tanks[m_currentPlayer];
    Input& in = m_core->GetInput();

    double step = in.IsKeyPress(VK_SHIFT) ? 0.2 : 1.0;

    if (in.IsKeyPress(VK_LEFT))  t.SetAngle(t.GetAngle() + step * dt * 60);
    if (in.IsKeyPress(VK_RIGHT)) t.SetAngle(t.GetAngle() - step * dt * 60);
    if (in.IsKeyPress(VK_UP))    t.SetPower(t.GetPower() + 30 * dt);
    if (in.IsKeyPress(VK_DOWN))  t.SetPower(t.GetPower() - 30 * dt);

    if (in.IsKeyDown(VK_SPACE))  Fire();
}
```

```cpp
int FortressScene::SimulateLanding(double x, double y,
                                   double vx, double vy, double wind)
{
    const double STEP = 1.0 / 30.0;            // ★ AI는 거친 스텝으로 충분
    const int MAX_STEPS = 300;

    for (int i = 0; i < MAX_STEPS; i++)
    {
        vy += GRAVITY * STEP;
        vx += wind * STEP;
        x  += vx * STEP;
        y  += vy * STEP;

        if (x < 0 || x >= m_terrain->GetWidth()) return -9999;

        if (y >= m_terrain->GetHeightAt((int)x)) return (int)x;
    }

    return -9999;
}
```
