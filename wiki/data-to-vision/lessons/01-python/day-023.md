## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 일정 간격으로 적을 자동 생성(스폰)할 수 있다.
- 직선·사인파·추적 등 여러 이동 패턴을 구현할 수 있다.
- 상속으로 적 종류를 확장하고, 난이도를 시간에 따라 올릴 수 있다.

## ② 왜 필요한가

지금 게임에는 **쏠 대상이 없습니다.** 적이 있어야 게임이 됩니다.

그런데 적은 총알보다 복잡합니다.

| | 총알 | 적 |
|---|---|---|
| 생성 시점 | 플레이어가 누를 때 | **스스로, 일정 간격으로** |
| 이동 | 직선 하나 | 직선·곡선·추적 등 여러 종류 |
| 상태 | 없음 | 체력·점수·공격 |
| 종류 | 무기별 | 여러 종류가 **동시에** 등장 |

여기서 **[Day 017](day-017.md)의 상속과 다형성**이 진가를 발휘합니다.
적 종류가 10개여도 게임 루프는 `enemies.update()` 한 줄입니다.

그리고 **난이도 곡선**을 오늘 배웁니다.
"처음엔 쉽고 갈수록 어려워진다"는 것이 게임을 재미있게 만드는 핵심 설계입니다.

## ③ 개념 설명

### 스폰 — 타이머로 자동 생성

```python
class SpawnManager:
    def __init__(self, interval=90):
        self.timer = 0
        self.interval = interval        # 프레임 단위 (90 = 1.5초)

    def update(self):
        """스폰할 때가 되면 True 를 반환합니다."""
        self.timer += 1
        if self.timer >= self.interval:
            self.timer = 0
            return True
        return False
```

**게임 루프에서**

```python
if spawner.update():
    enemy = Enemy.spawn_random()
    all_sprites.add(enemy)
    enemies.add(enemy)
```

> [Day 022](day-022.md)의 쿨타임과 **같은 구조**입니다. 타이머 3종 세트(설정·감소·확인)를 기억하세요.
> 여기서는 증가 후 비교하는 방식으로 썼습니다. 어느 쪽이든 동작합니다.

### 이동 패턴 4가지

```python
# ① 직선 — 가장 단순
self.pos_y += self.speed

# ② 지그재그 — 좌우로 왕복
self.pos_x += self.vel_x
if self.rect.left <= 0 or self.rect.right >= SCREEN_WIDTH:
    self.vel_x = -self.vel_x

# ③ 사인파 — 부드러운 물결
self.timer += 1
self.pos_x = self.start_x + math.sin(self.timer * 0.05) * self.amplitude

# ④ 추적 — 플레이어를 따라감
dx = target.rect.centerx - self.rect.centerx
dy = target.rect.centery - self.rect.centery
distance = (dx**2 + dy**2) ** 0.5
if distance > 0:
    self.pos_x += dx / distance * self.speed
    self.pos_y += dy / distance * self.speed
```

> ④의 **정규화**는 [Day 020](day-020.md)의 마우스 추적과 완전히 같은 계산입니다.
> `dx / distance` 로 방향만 뽑고, 속도를 곱합니다.

### 적 계층 설계

```python
class Enemy(pygame.sprite.Sprite):
    """모든 적의 부모."""
    HP = 1
    SPEED = 2.0
    SCORE = 10
    SIZE = 36
    COLOR = (231, 76, 60)

    def __init__(self, x, y):
        super().__init__()
        self.image = self.make_surface()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.hp = self.HP
        self.max_hp = self.HP

    def make_surface(self):
        """자식이 오버라이딩해 모양을 바꿉니다."""
        surf = pygame.Surface((self.SIZE, self.SIZE), pygame.SRCALPHA)
        pygame.draw.circle(surf, self.COLOR,
                           (self.SIZE // 2, self.SIZE // 2), self.SIZE // 2)
        return surf

    def move(self):
        """이동 로직. 자식이 오버라이딩합니다."""
        self.pos_y += self.SPEED

    def update(self):
        self.move()
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        if self.rect.top > SCREEN_HEIGHT:
            self.kill()

    def take_damage(self, amount):
        """피해를 입습니다. 죽으면 True."""
        self.hp -= amount
        if self.hp <= 0:
            self.kill()
            return True
        return False
```

**자식은 값과 `move()` 만 바꾸면 됩니다.**

```python
class FastEnemy(Enemy):
    HP = 1
    SPEED = 5.0
    SCORE = 20
    COLOR = (241, 196, 15)


class TankEnemy(Enemy):
    HP = 5
    SPEED = 1.0
    SCORE = 50
    SIZE = 54
    COLOR = (155, 89, 182)


class ZigzagEnemy(Enemy):
    SPEED = 2.5
    SCORE = 30
    COLOR = (46, 204, 113)

    def __init__(self, x, y):
        super().__init__(x, y)
        self.vel_x = 3.0

    def move(self):
        self.pos_y += self.SPEED
        self.pos_x += self.vel_x
        if self.pos_x <= self.SIZE // 2 or self.pos_x >= SCREEN_WIDTH - self.SIZE // 2:
            self.vel_x = -self.vel_x
            self.pos_x = max(self.SIZE // 2,
                             min(self.pos_x, SCREEN_WIDTH - self.SIZE // 2))
```

> **`move()` 만 오버라이딩**하고 `update()` 는 부모 것을 그대로 씁니다.
> 위치 반영·화면 밖 제거 같은 공통 처리를 한 곳에서 관리할 수 있습니다.
> 이런 구조를 **템플릿 메서드 패턴**이라고 합니다.

### 무작위 스폰

```python
@classmethod
def spawn_top(cls, margin=None):
    """화면 위쪽 무작위 위치에서 생성합니다."""
    if margin is None:
        margin = cls.SIZE
    x = random.randint(margin, SCREEN_WIDTH - margin)
    y = -cls.SIZE                     # 화면 위 밖에서 시작
    return cls(x, y)
```

> `cls` 를 쓰면 **자식 클래스에서 호출해도 그 자식 객체가 만들어집니다.**
> `FastEnemy.spawn_top()` → `FastEnemy` 객체. `@classmethod` 의 장점입니다. ([Day 017](day-017.md))

### 가중치 무작위 선택

적 종류마다 등장 확률을 다르게 하려면:

```python
ENEMY_TYPES = [Enemy, FastEnemy, ZigzagEnemy, TankEnemy]
WEIGHTS =     [50,    25,        18,          7]        # 합이 100일 필요는 없음

enemy_class = random.choices(ENEMY_TYPES, weights=WEIGHTS, k=1)[0]
enemy = enemy_class.spawn_top()
```

> `random.choices()` 는 **리스트를 반환**하므로 `[0]` 으로 꺼냅니다.
> `random.choice()`(s 없음)와 헷갈리지 마세요.

### 난이도 곡선

```python
class DifficultyManager:
    def __init__(self):
        self.elapsed = 0                 # 프레임
        self.level = 1

    def update(self):
        self.elapsed += 1
        # 20초마다 레벨 상승 (최대 10)
        new_level = min(1 + self.elapsed // (20 * FPS), 10)
        leveled_up = new_level > self.level
        self.level = new_level
        return leveled_up

    @property
    def spawn_interval(self):
        """레벨이 오를수록 스폰 간격이 짧아집니다. 최소 20프레임."""
        return max(90 - (self.level - 1) * 8, 20)

    @property
    def speed_multiplier(self):
        """레벨당 8%씩 빨라집니다."""
        return 1.0 + (self.level - 1) * 0.08

    @property
    def weights(self):
        """레벨이 오를수록 강한 적의 비중이 커집니다."""
        lv = self.level
        return [
            max(50 - lv * 4, 10),      # Enemy
            20 + lv,                    # FastEnemy
            10 + lv * 2,                # ZigzagEnemy
            max(lv * 3 - 5, 0),         # TankEnemy
        ]
```

> **난이도 설계의 원칙** — 여러 축을 조금씩 올립니다.
> 스폰 속도만 급격히 올리면 화면이 적으로 가득 차 재미가 없어집니다.
> 속도·빈도·종류를 **함께 조금씩** 올리는 것이 좋은 곡선입니다.

### Step 1. 적 스폰과 기본 이동

`enemy_v1.py` 를 만들어 실행합니다.

```python
import pygame
import random

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)


class Enemy(pygame.sprite.Sprite):
    """아래로 내려오는 기본 적."""

    HP = 1
    SPEED = 2.0
    SCORE = 10
    SIZE = 36
    COLOR = (231, 76, 60)

    def __init__(self, x, y):
        super().__init__()
        self.image = self.make_surface()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.hp = self.HP
        self.max_hp = self.HP

    def make_surface(self):
        size = self.SIZE
        surf = pygame.Surface((size, size), pygame.SRCALPHA)
        pygame.draw.circle(surf, self.COLOR, (size // 2, size // 2), size // 2)
        pygame.draw.circle(surf, (255, 255, 255), (size // 3, size // 3), size // 9)
        pygame.draw.circle(surf, (255, 255, 255), (size * 2 // 3, size // 3), size // 9)
        return surf

    def move(self):
        """자식이 오버라이딩할 이동 로직."""
        self.pos_y += self.SPEED

    def update(self):
        self.move()
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        if self.rect.top > SCREEN_HEIGHT:
            self.kill()

    def take_damage(self, amount=1):
        self.hp -= amount
        if self.hp <= 0:
            self.kill()
            return True
        return False

    @classmethod
    def spawn_top(cls):
        """화면 위쪽 무작위 위치에서 생성합니다."""
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)


class SpawnManager:
    """일정 간격으로 스폰 신호를 냅니다."""

    def __init__(self, interval=90):
        self.timer = 0
        self.interval = interval
        self.spawn_count = 0

    def update(self):
        self.timer += 1
        if self.timer >= self.interval:
            self.timer = 0
            self.spawn_count += 1
            return True
        return False


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 023 - 적 스폰")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 18)

all_sprites = pygame.sprite.Group()
enemies = pygame.sprite.Group()
spawner = SpawnManager(interval=60)

escaped = 0          # 화면 아래로 빠져나간 적 수

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_UP:
                spawner.interval = max(spawner.interval - 10, 10)
            elif event.key == pygame.K_DOWN:
                spawner.interval = min(spawner.interval + 10, 180)

    # 스폰
    if spawner.update():
        e = Enemy.spawn_top()
        all_sprites.add(e)
        enemies.add(e)

    # 갱신 전 개수를 기억해 두면 몇 마리가 빠져나갔는지 알 수 있습니다
    before = len(enemies)
    all_sprites.update()
    escaped += before - len(enemies)

    screen.fill(COLOR_BG)
    all_sprites.draw(screen)

    info = [
        f"화면의 적: {len(enemies)}마리",
        f"생성 누적: {spawner.spawn_count}마리",
        f"놓친 적: {escaped}마리",
        f"스폰 간격: {spawner.interval}프레임 ({spawner.interval / FPS:.2f}초)",
        "",
        "↑↓ = 스폰 간격 조절   ESC = 종료",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> `↑` 를 여러 번 눌러 스폰 간격을 10프레임까지 줄여 보세요. 화면이 적으로 가득 찹니다.
> **난이도 조절이 얼마나 민감한지** 체감할 수 있습니다.

### Step 2. 적 종류 확장 — 상속과 다형성

```python
import pygame
import random
import math

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

COLOR_BG = (18, 20, 30)
COLOR_TEXT = (240, 240, 240)


class Enemy(pygame.sprite.Sprite):
    """적의 부모 클래스."""

    HP = 1
    SPEED = 2.0
    SCORE = 10
    SIZE = 36
    COLOR = (231, 76, 60)
    NAME = "기본"

    def __init__(self, x, y):
        super().__init__()
        self.image = self.make_surface()
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.hp = self.HP
        self.max_hp = self.HP

    def make_surface(self):
        size = self.SIZE
        surf = pygame.Surface((size, size), pygame.SRCALPHA)
        pygame.draw.circle(surf, self.COLOR, (size // 2, size // 2), size // 2)
        pygame.draw.circle(surf, (20, 20, 30), (size // 3, size // 3), size // 10)
        pygame.draw.circle(surf, (20, 20, 30), (size * 2 // 3, size // 3), size // 10)
        return surf

    def move(self):
        self.pos_y += self.SPEED

    def update(self):
        self.move()
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        if self.rect.top > SCREEN_HEIGHT:
            self.kill()

    def take_damage(self, amount=1):
        self.hp -= amount
        if self.hp <= 0:
            self.kill()
            return True
        return False

    def draw_hp_bar(self, surface):
        """체력이 2 이상인 적만 체력 바를 표시합니다."""
        if self.max_hp <= 1:
            return
        w = self.rect.width
        ratio = self.hp / self.max_hp
        x, y = self.rect.left, self.rect.top - 8
        pygame.draw.rect(surface, (60, 62, 75), (x, y, w, 5))
        pygame.draw.rect(surface, (46, 204, 113), (x, y, int(w * ratio), 5))

    @classmethod
    def spawn_top(cls):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)


class FastEnemy(Enemy):
    """빠르지만 약한 적."""
    HP = 1
    SPEED = 5.5
    SCORE = 20
    SIZE = 28
    COLOR = (241, 196, 15)
    NAME = "고속"


class TankEnemy(Enemy):
    """느리지만 튼튼한 적."""
    HP = 6
    SPEED = 1.0
    SCORE = 60
    SIZE = 56
    COLOR = (155, 89, 182)
    NAME = "탱커"


class ZigzagEnemy(Enemy):
    """좌우로 왕복하며 내려오는 적."""
    HP = 2
    SPEED = 2.2
    SCORE = 35
    SIZE = 38
    COLOR = (46, 204, 113)
    NAME = "지그재그"

    def __init__(self, x, y):
        super().__init__(x, y)
        self.vel_x = random.choice([-3.5, 3.5])

    def move(self):
        self.pos_y += self.SPEED
        self.pos_x += self.vel_x

        half = self.SIZE / 2
        if self.pos_x <= half:
            self.pos_x, self.vel_x = half, abs(self.vel_x)
        elif self.pos_x >= SCREEN_WIDTH - half:
            self.pos_x, self.vel_x = SCREEN_WIDTH - half, -abs(self.vel_x)


class WaveEnemy(Enemy):
    """사인파로 부드럽게 흔들리며 내려오는 적."""
    HP = 2
    SPEED = 2.0
    SCORE = 40
    SIZE = 34
    COLOR = (26, 188, 156)
    NAME = "물결"

    def __init__(self, x, y):
        super().__init__(x, y)
        self.start_x = float(x)
        self.timer = 0
        self.amplitude = random.uniform(50, 110)

    def move(self):
        self.timer += 1
        self.pos_y += self.SPEED
        self.pos_x = self.start_x + math.sin(self.timer * 0.05) * self.amplitude

        half = self.SIZE / 2
        self.pos_x = max(half, min(self.pos_x, SCREEN_WIDTH - half))


class ChaserEnemy(Enemy):
    """플레이어를 추적하는 적."""
    HP = 3
    SPEED = 2.6
    SCORE = 50
    SIZE = 40
    COLOR = (230, 126, 34)
    NAME = "추적"

    def __init__(self, x, y, target=None):
        super().__init__(x, y)
        self.target = target

    def move(self):
        if self.target is None or not self.target.alive():
            self.pos_y += self.SPEED
            return

        dx = self.target.rect.centerx - self.pos_x
        dy = self.target.rect.centery - self.pos_y
        distance = (dx ** 2 + dy ** 2) ** 0.5

        if distance > 1:
            # 정규화 후 속도만큼 이동 (Day 020 의 마우스 추적과 동일)
            self.pos_x += dx / distance * self.SPEED
            self.pos_y += dy / distance * self.SPEED

    @classmethod
    def spawn_top(cls, target=None):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE, target)


class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((44, 44), pygame.SRCALPHA)
        pygame.draw.polygon(self.image, (52, 152, 219),
                            [(22, 0), (44, 44), (22, 34), (0, 44)])
        pygame.draw.circle(self.image, (241, 196, 15), (22, 22), 6)
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x, self.pos_y = float(x), float(y)
        self.speed = 6

    def handle_input(self, keys):
        dx = dy = 0
        if keys[pygame.K_LEFT]:
            dx -= 1
        if keys[pygame.K_RIGHT]:
            dx += 1
        if keys[pygame.K_UP]:
            dy -= 1
        if keys[pygame.K_DOWN]:
            dy += 1
        length = (dx ** 2 + dy ** 2) ** 0.5
        if length > 0:
            dx, dy = dx / length, dy / length
        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.pos_x, self.pos_y = float(self.rect.centerx), float(self.rect.centery)


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 023 - 적 종류")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 17)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 70)
all_sprites = pygame.sprite.Group(player)
enemies = pygame.sprite.Group()

ENEMY_TYPES = [Enemy, FastEnemy, ZigzagEnemy, WaveEnemy, TankEnemy, ChaserEnemy]
WEIGHTS = [35, 20, 15, 12, 10, 8]

spawn_timer = 0
SPAWN_INTERVAL = 45
spawn_stats = {t.NAME: 0 for t in ENEMY_TYPES}


def spawn_enemy():
    cls = random.choices(ENEMY_TYPES, weights=WEIGHTS, k=1)[0]

    # ChaserEnemy 만 target 인자가 필요합니다
    if cls is ChaserEnemy:
        e = cls.spawn_top(player)
    else:
        e = cls.spawn_top()

    spawn_stats[cls.NAME] += 1
    return e


running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_c:
                enemies.empty()

    spawn_timer += 1
    if spawn_timer >= SPAWN_INTERVAL:
        spawn_timer = 0
        e = spawn_enemy()
        all_sprites.add(e)
        enemies.add(e)

    keys = pygame.key.get_pressed()
    player.handle_input(keys)
    all_sprites.update()               # 종류를 몰라도 한 줄!

    screen.fill(COLOR_BG)
    all_sprites.draw(screen)

    for e in enemies:
        e.draw_hp_bar(screen)

    lines = [f"화면의 적: {len(enemies)}마리", ""]
    lines += [f"{name:<8} {count}마리" for name, count in spawn_stats.items()]
    lines += ["", "이동=방향키   C=적 전부 제거"]

    for i, line in enumerate(lines):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 21))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 5가지**
> - **`all_sprites.update()` 한 줄**로 6종류의 적이 각자 다르게 움직입니다. 다형성의 힘입니다.
> - `move()` 만 오버라이딩하고 `update()` 는 부모 것을 씁니다. 위치 반영·화면 밖 제거를 한 곳에서 관리합니다.
> - `ChaserEnemy` 만 `target` 인자가 필요해 `spawn_top()` 을 오버라이딩했습니다.
> - `self.target.alive()` — pygame `Sprite` 의 메서드로, 어떤 그룹에라도 속해 있으면 `True` 입니다. 플레이어가 사라졌을 때를 대비한 방어 코드입니다.
> - `draw_hp_bar` 는 `Group.draw()` 가 처리하지 않으므로 **따로 반복문을 돌립니다.** `image`/`rect` 외의 것을 그릴 때는 이렇게 합니다.

### Step 3. 난이도 곡선 (오늘의 종합 예제)

Step 2의 클래스 정의를 그대로 쓰고, 스폰 부분만 교체합니다.

```python
class DifficultyManager:
    """시간에 따라 난이도를 올립니다."""

    LEVEL_UP_SECONDS = 15
    MAX_LEVEL = 10

    def __init__(self):
        self.frames = 0
        self.level = 1

    def update(self):
        """레벨이 올랐으면 True."""
        self.frames += 1
        new_level = min(1 + self.frames // (DifficultyManager.LEVEL_UP_SECONDS * FPS),
                        DifficultyManager.MAX_LEVEL)
        leveled = new_level > self.level
        self.level = new_level
        return leveled

    @property
    def seconds(self):
        return self.frames // FPS

    @property
    def spawn_interval(self):
        """레벨당 7프레임씩 짧아지고 최소 18프레임."""
        return max(80 - (self.level - 1) * 7, 18)

    @property
    def speed_scale(self):
        """레벨당 6% 씩 빨라집니다."""
        return 1.0 + (self.level - 1) * 0.06

    @property
    def weights(self):
        """레벨이 오를수록 강한 적의 비중이 커집니다."""
        lv = self.level
        return [
            max(40 - lv * 3, 8),      # Enemy
            18 + lv,                   # FastEnemy
            10 + lv,                   # ZigzagEnemy
            8 + lv,                    # WaveEnemy
            max(lv * 2 - 2, 0),        # TankEnemy
            max(lv * 3 - 6, 0),        # ChaserEnemy
        ]

    def next_class(self, types):
        return random.choices(types, weights=self.weights, k=1)[0]


# ══════════ 실행 ══════════
pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 023 - 난이도 곡선")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 17)
big_font = pygame.font.SysFont("malgungothic", 34)

player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 70)
all_sprites = pygame.sprite.Group(player)
enemies = pygame.sprite.Group()

ENEMY_TYPES = [Enemy, FastEnemy, ZigzagEnemy, WaveEnemy, TankEnemy, ChaserEnemy]

difficulty = DifficultyManager()
spawn_timer = 0
level_up_flash = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # ── 난이도 갱신 ──
    if difficulty.update():
        level_up_flash = 90            # 1.5초간 표시

    if level_up_flash > 0:
        level_up_flash -= 1

    # ── 스폰 ──
    spawn_timer += 1
    if spawn_timer >= difficulty.spawn_interval:
        spawn_timer = 0
        cls = difficulty.next_class(ENEMY_TYPES)

        e = cls.spawn_top(player) if cls is ChaserEnemy else cls.spawn_top()

        # 난이도에 따라 속도 배율 적용 — 인스턴스 변수로 덮어씀
        e.speed_scale = difficulty.speed_scale
        all_sprites.add(e)
        enemies.add(e)

    keys = pygame.key.get_pressed()
    player.handle_input(keys)

    # 속도 배율 적용 — 각 적의 pos 를 추가로 이동
    all_sprites.update()
    for e in enemies:
        extra = getattr(e, "speed_scale", 1.0) - 1.0
        if extra > 0:
            e.pos_y += e.SPEED * extra
            e.rect.centery = int(e.pos_y)

    # ── 그리기 ──
    screen.fill(COLOR_BG)
    all_sprites.draw(screen)
    for e in enemies:
        e.draw_hp_bar(screen)

    # 종류별 현재 개수 집계 (Day 013 의 딕셔너리 누적)
    counts = {}
    for e in enemies:
        counts[e.NAME] = counts.get(e.NAME, 0) + 1

    lines = [
        f"레벨 {difficulty.level} / {DifficultyManager.MAX_LEVEL}"
        f"   경과 {difficulty.seconds}초",
        f"스폰 간격 {difficulty.spawn_interval}프레임"
        f"   속도 x{difficulty.speed_scale:.2f}",
        f"화면의 적 {len(enemies)}마리",
        "",
    ]
    lines += [f"  {name}: {c}" for name, c in sorted(counts.items())]

    for i, line in enumerate(lines):
        screen.blit(font.render(line, True, COLOR_TEXT), (10, 10 + i * 21))

    if level_up_flash > 0:
        msg = big_font.render(f"LEVEL {difficulty.level}!", True, (241, 196, 15))
        screen.blit(msg, msg.get_rect(center=(SCREEN_WIDTH // 2, 100)))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 4가지**
> - `DifficultyManager` 가 난이도 관련 계산을 **전부 책임집니다.** 게임 루프는 값을 가져다 쓰기만 합니다.
> - `@property` 로 계산 값을 노출하니 `difficulty.spawn_interval` 처럼 속성처럼 읽힙니다. ([Day 018](day-018.md))
> - `getattr(e, "speed_scale", 1.0)` — 속성이 없어도 기본값 `1.0` 을 돌려줍니다. 방어적 코드입니다.
> - 레벨업 표시를 **플래시 타이머**로 처리했습니다. 총알 쿨타임·무적 시간과 같은 패턴입니다.

## ⑤ 자주 하는 실수

### 스폰 위치가 화면 안이라 갑자기 튀어나옴

```python
y = 0                  # 화면 맨 위 = 이미 보이는 위치
```

**해결** — 화면 **밖에서** 시작합니다. `y = -cls.SIZE`

### 화면 아래로 나간 적을 안 지움

**증상** — [Day 022](day-022.md)의 총알과 똑같습니다. 시간이 지날수록 FPS 급락.
**해결** — `update()` 에서 `if self.rect.top > SCREEN_HEIGHT: self.kill()`

> **주의** — 지그재그·물결 적은 좌우로도 움직입니다. 필요하면 네 방향을 모두 확인하세요.

### 추적 적이 목표에 도달하면 떨림

```python
self.pos_x += dx / distance * self.SPEED
```

`distance` 가 0에 가까우면 `dx / distance` 가 폭발합니다.

**해결** — 최소 거리를 둡니다.

```python
if distance > 1:
    self.pos_x += dx / distance * self.SPEED
    self.pos_y += dy / distance * self.SPEED
```

### `ZeroDivisionError` — 정확히 겹쳤을 때

```python
distance = (dx**2 + dy**2) ** 0.5      # 0 이 될 수 있음
self.pos_x += dx / distance * SPEED
```

**해결** — 위와 같이 `if distance > 1:` 로 감쌉니다.

### `random.choices` 와 `random.choice` 혼동

```python
cls = random.choices(TYPES, weights=W, k=1)      # 리스트가 반환됨
e = cls.spawn_top()                               # AttributeError!
```

**해결** — `[0]` 으로 꺼냅니다. `cls = random.choices(...)[0]`

### 자식 클래스에서 클래스 변수를 인스턴스에서 수정

```python
class FastEnemy(Enemy):
    SPEED = 5.0

    def boost(self):
        self.SPEED *= 2          # 이 객체만 인스턴스 변수가 생김
```

동작은 하지만 의도가 불명확합니다. **속도를 개별로 바꾸려면 `__init__` 에서 인스턴스 변수를 만드세요.**

```python
def __init__(self, x, y):
    super().__init__(x, y)
    self.speed = self.SPEED      # 클래스 상수를 인스턴스 값으로 복사
```

### 스폰 간격을 0 이하로 만듦

```python
interval = 90 - level * 10       # level=10 이면 -10
```

**증상** — 매 프레임 스폰되어 화면이 즉시 가득 찹니다.
**해결** — `max(..., 최소값)` 으로 하한을 둡니다.

### 난이도를 한 축만 급격히 올림

```python
self.spawn_interval = max(90 - level * 30, 5)     # 3레벨이면 이미 최소
```

**해결** — 속도·빈도·종류를 **각각 조금씩** 올립니다. 곡선이 부드러워야 재미있습니다.

## ⑥ 확인 문제

**1.** `Enemy` 의 `update()` 를 자식이 오버라이딩하지 않고 `move()` 만 오버라이딩하게 설계한 이유는 무엇일까요?

<details>
<summary>답 보기</summary>

**공통 처리를 한 곳에서 관리하기 위해서**입니다.

`update()` 에는 모든 적에게 필요한 처리가 들어 있습니다.

```python
def update(self):
    self.move()                                       # 자식마다 다름
    self.rect.center = (int(self.pos_x), int(self.pos_y))   # 공통
    if self.rect.top > SCREEN_HEIGHT:                 # 공통
        self.kill()
```

**만약 자식이 `update()` 를 통째로 오버라이딩한다면**
- 적 종류 6개면 위치 반영 코드가 6번 중복됩니다.
- 화면 밖 제거 조건을 바꾸려면 6곳을 고쳐야 합니다.
- 하나를 빠뜨리면 그 적만 안 지워지는 버그가 납니다.

**`move()` 만 나누면**
- 자식은 "어떻게 움직이는가"만 신경 쓰면 됩니다.
- 나중에 "화면 밖 5초 뒤 제거" 같은 규칙을 넣어도 부모만 고치면 전부 반영됩니다.

> 이 설계를 **템플릿 메서드 패턴**이라고 합니다.
> **"흐름은 부모가 정하고, 세부는 자식이 채운다"** 는 구조입니다.
> [Day 017](day-017.md)의 `Shape.describe()` 가 `self.get_area()` 를 부른 것과 같은 원리입니다.
</details>

**2.** 화면 아래에서 위로 올라오는 `RisingEnemy` 를 만드세요. 화면 위로 나가면 제거됩니다.

<details>
<summary>답 보기</summary>

```python
class RisingEnemy(Enemy):
    """아래에서 위로 올라오는 적."""

    HP = 2
    SPEED = 3.0
    SCORE = 45
    SIZE = 36
    COLOR = (52, 73, 94)
    NAME = "상승"

    def move(self):
        self.pos_y -= self.SPEED          # 위로 (y 감소)

        self.move()
        self.rect.center = (int(self.pos_x), int(self.pos_y))

        if self.rect.bottom < 0:          # 화면 위로 나가면 제거
            self.kill()

    @classmethod
    def spawn_top(cls):
```

**더 나은 설계 — 부모를 유연하게 만들기**

`update()` 를 중복하지 않으려면, 애초에 부모가 방향을 고려하도록 만들면 됩니다.

```python
class Enemy(pygame.sprite.Sprite):
    ...
    def update(self):
        self.move()
        self.rect.center = (int(self.pos_x), int(self.pos_y))
        if self.is_out_of_screen():
            self.kill()

    def is_out_of_screen(self):
        """화면 밖 판정. 자식이 오버라이딩할 수 있습니다."""
        return (self.rect.top > SCREEN_HEIGHT or self.rect.bottom < 0
                or self.rect.right < 0 or self.rect.left > SCREEN_WIDTH)
```

```python
class RisingEnemy(Enemy):
```

**포인트 3가지**
- 처음 설계할 때 **네 방향을 모두 검사**하게 해 두면 확장이 쉬워집니다.
- 클래스 메서드 이름을 `spawn_top` 으로 통일하면, 호출하는 쪽이 종류를 몰라도 됩니다. **인터페이스 통일**입니다.
- 이름이 실제 동작과 안 맞으면(`spawn_top` 인데 아래에서 생성) `spawn()` 처럼 중립적인 이름으로 바꾸는 편이 좋습니다.

**3.** 아래 추적 적은 플레이어에게 도달하면 격렬하게 떨립니다. 원인과 해결책을 쓰세요.

```python
class ChaserEnemy(Enemy):
    SPEED = 3.0

    def __init__(self, x, y, target):
        super().__init__(x, y)
        self.target = target

    def move(self):
        dx = self.target.rect.centerx - self.pos_x
        dy = self.target.rect.centery - self.pos_y
        distance = (dx ** 2 + dy ** 2) ** 0.5

        self.pos_x += dx / distance * self.SPEED
        self.pos_y += dy / distance * self.SPEED
```

<details>
<summary>답 보기</summary>

**원인 두 가지**

**① 목표를 지나쳐 버립니다.**

거리가 `1` 이고 속도가 `3` 이면, 3픽셀을 이동해 목표를 2픽셀 **지나칩니다.**
다음 프레임에는 반대 방향으로 3픽셀 이동해 다시 지나칩니다. 무한 왕복 = 떨림입니다.

```
프레임 1: 거리 1  → 3 이동 → 반대편 2 위치
프레임 2: 거리 2  → 3 이동 → 반대편 1 위치
프레임 3: 거리 1  → 3 이동 → ... 영원히
```

**② `ZeroDivisionError` 위험**

적이 플레이어와 정확히 같은 좌표에 있으면 `distance = 0` 이 되어 프로그램이 죽습니다.

```
ZeroDivisionError: float division by zero
```

**해결**

```python
def move(self):
    if self.target is None or not self.target.alive():
        self.pos_y += self.SPEED          # 목표가 없으면 그냥 아래로
        return

    dx = self.target.rect.centerx - self.pos_x
    dy = self.target.rect.centery - self.pos_y
    distance = (dx ** 2 + dy ** 2) ** 0.5

    # 남은 거리가 속도보다 작으면 정확히 목표 지점으로
    if distance <= self.SPEED:
        self.pos_x = float(self.target.rect.centerx)
        self.pos_y = float(self.target.rect.centery)
        return

    self.pos_x += dx / distance * self.SPEED
    self.pos_y += dy / distance * self.SPEED
```

**핵심은 `if distance <= self.SPEED:` 입니다.**
"이번 프레임에 도달할 수 있으면 정확히 그 자리로 이동한다" — 지나칠 일도, 0으로 나눌 일도 없습니다.

> **교훈** — **한 걸음에 목표를 지나칠 수 있는 상황**을 항상 고려하세요.
> 이 문제는 [Day 020](day-020.md)의 마우스 추적에서 `if distance > SPEED:` 를 썼던 것과 같습니다.
>
> 같은 원리가 [Day 019](day-019.md)의 벽 반사, [Day 021](day-021.md)의 경계 처리에도 적용됩니다.
> **"경계를 넘어갔으면 정확히 경계로 되돌린다"** 가 공통 해법입니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 스폰 | 타이머로 일정 간격 자동 생성 · 화면 **밖**에서 시작 |
| 이동 패턴 | 직선 / 지그재그 / 사인파 / 추적 |
| 추적 | 방향 **정규화** 후 속도 곱하기 · `distance <= SPEED` 처리 필수 |
| 계층 설계 | 부모가 `update()` 흐름, 자식이 `move()` 세부 |
| 특성 정의 | 클래스 변수(`HP` `SPEED` `SCORE` `COLOR`)로 |
| `@classmethod` | `cls` 를 쓰면 자식에서 호출 시 자식 객체 생성 |
| 가중치 선택 | `random.choices(types, weights=w, k=1)[0]` |
| 난이도 | 속도·빈도·종류를 **함께 조금씩** · 하한/상한 필수 |

**오늘 반드시 기억할 세 가지**
> ① 자식은 `move()` 만 바꾸고 `update()` 는 부모에게 맡기세요.
> ② 추적 로직에는 **`distance` 가 0이거나 속도보다 작을 때** 처리가 반드시 필요합니다.
> ③ 난이도는 **여러 축을 조금씩** 올려야 곡선이 부드럽습니다.
