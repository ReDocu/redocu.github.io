## 1. 오늘 만드는 것

**카드를 끌어다 놓으면 효과가 발동하고 턴이 넘어간다.**

```
   ┌────────────────────────────────────────────────────────┐
   │  TURN 4      마나 ⚡⚡⚡⚡○      상대 HP ████████░ 23  │
   │                                                        │
   │      ┌──────── 필드 (드롭 영역) ────────┐               │
   │      │                                  │               │
   │      │            ▣                     │  ← 드래그 중  │
   │      │         화염구                    │     반투명    │
   │      │          ╲ ╱                     │               │
   │      └───────────┼──────────────────────┘               │
   │                  │  드롭 가능 → 초록 테두리              │
   │      ╱▣  ▣    ▣  ▣╲                                    │
   │     강타 치유 ▨방패 통찰      ▨ = 마나 부족 (붉음)      │
   │                                                        │
   │                                    [ 턴 종료 ]          │
   └────────────────────────────────────────────────────────┘
```

**조작** — 손패의 카드를 마우스로 끌어 필드에 놓으면 효과가 발동한다. 필드 밖에 놓으면 원래 자리로 돌아간다.

## 3. 개념

### 3-1. Unity 이벤트 시스템

**왜 필요한가** — 마우스 입력을 UI가 받는 구조.

```
   마우스 클릭
        ↓
   EventSystem
        ↓
   Graphic Raycaster (Canvas에 있음)
        ↓
   Raycast Target이 켜진 Graphic 중 가장 위의 것
        ↓
   그 오브젝트의 인터페이스 호출
```

```
   ★ 필요한 것 3가지

   ① 씬에 EventSystem
   ② Canvas에 Graphic Raycaster
   ③ 대상 오브젝트에 Raycast Target ✔ 인 Graphic
```

```
   ⚠️ 3D 오브젝트를 클릭하려면

   Physics Raycaster를 카메라에 붙인다
   → Collider가 있는 오브젝트가 이벤트를 받는다
```

### 3-7. 드롭 영역

**왜 필요한가** — 받는 쪽의 처리.

```csharp
using UnityEngine;
using UnityEngine.EventSystems;

public class DropZone : MonoBehaviour,
    IDropHandler, IPointerEnterHandler, IPointerExitHandler
{
    [SerializeField] private Image highlight;
    [SerializeField] private Color validColor = new Color(0.3f, 1f, 0.3f, 0.3f);
    [SerializeField] private Color invalidColor = new Color(1f, 0.3f, 0.3f, 0.3f);

    public void OnPointerEnter(PointerEventData e)
    {
        // ★ 드래그 중일 때만 강조
        CardDragHandler drag = e.pointerDrag?.GetComponent<CardDragHandler>();
        if (drag == null) return;

        bool ok = GameManager.Instance.CanPlay(drag.View.Instance);

        highlight.enabled = true;
        highlight.color = ok ? validColor : invalidColor;
    }

    public void OnPointerExit(PointerEventData e)
    {
        highlight.enabled = false;
    }

    public void OnDrop(PointerEventData e)
    {
        highlight.enabled = false;

        CardDragHandler drag = e.pointerDrag?.GetComponent<CardDragHandler>();
        if (drag == null) return;

        bool played = GameManager.Instance.TryPlayCard(drag.View.Instance);

        drag.NotifyDropResult(played);         // ★ 성공 여부를 알려준다
    }
}
```

```
   ★ 실행 순서

   OnEndDrag (드래그한 쪽)
   OnDrop    (받는 쪽)

   ⚠️ OnDrop이 OnEndDrag보다 먼저 불린다!
```

```
   정확한 순서

   1. OnDrop      (드롭 대상)
   2. OnEndDrag   (드래그한 오브젝트)

   → OnEndDrag에서 "드롭됐는지"를 알려면
     OnDrop에서 플래그를 세워 둔다
```

### 3-8. 드롭 실패 처리

**왜 필요한가** — 원위치 복귀.

```csharp
    private bool dropHandled;

    public void NotifyDropResult(bool success)
    {
        dropHandled = true;
        dropSuccess = success;
    }

    public void OnEndDrag(PointerEventData e)
    {
        canvasGroup.blocksRaycasts = true;
        canvasGroup.alpha = 1f;

        if (dropHandled && dropSuccess)
        {
            // 성공 — 카드가 사라지는 연출은 GameManager가 처리
            dropHandled = false;
            return;
        }

        // ★ 실패 — 원위치로 부드럽게
        rt.SetParent(originalParent, true);
        rt.SetSiblingIndex(originalIndex);

        StartCoroutine(ReturnToHand());

        dropHandled = false;
    }

    private IEnumerator ReturnToHand()
    {
        Vector2 from = rt.anchoredPosition;
        float t = 0;

        while (t < 0.2f)
        {
            t += Time.deltaTime;
            // HandLayout이 목표 위치를 계속 갱신하므로
            // 여기서는 스케일·회전만 복구
            rt.localScale = Vector3.Lerp(rt.localScale, Vector3.one, t / 0.2f);
            yield return null;
        }

        rt.localScale = Vector3.one;
    }
```

```
   ★ HandLayout이 매 프레임 Lerp로 위치를 잡으므로
     부모만 되돌리면 알아서 제자리로 간다 (Day 77)
```

```csharp
public class TargetArrow : MonoBehaviour
{
    [SerializeField] private RectTransform[] segments;   // 점 여러 개
    [SerializeField] private RectTransform head;

    public void Show(Vector2 from, Vector2 to)
    {
        gameObject.SetActive(true);

        int n = segments.Length;

        // ★ 2차 베지에 곡선
        Vector2 control = (from + to) * 0.5f + Vector2.up * 120f;

        for (int i = 0; i < n; i++)
        {
            float t = (i + 1) / (float)(n + 1);

            Vector2 p = Bezier(from, control, to, t);
            segments[i].anchoredPosition = p;

            // 크기를 점점 키운다
            segments[i].localScale = Vector3.one * (0.4f + t * 0.6f);
        }

        head.anchoredPosition = to;

        // ★ 화살촉 회전
        Vector2 dir = to - Bezier(from, control, to, 0.9f);
        head.localRotation = Quaternion.Euler(0, 0,
            Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg - 90f);
    }

    private Vector2 Bezier(Vector2 p0, Vector2 p1, Vector2 p2, float t)
    {
        float u = 1 - t;
        return u * u * p0 + 2 * u * t * p1 + t * t * p2;
    }
}
```

```
   ★ 2차 베지에 곡선

   B(t) = (1-t)²P₀ + 2(1-t)tP₁ + t²P₂

   P₀ = 시작, P₁ = 제어점, P₂ = 끝
```

```
   ★ Mathf.Atan2 — Day 66의 역함수

   Day 66:  각도 → 벡터  (cos, sin)
   지금:    벡터 → 각도  (atan2)
```

### 3-11. 코루틴 연출 (외부 라이브러리 없이)

**왜 필요한가** — 카드가 뿅 사라지면 재미없다.

```csharp
public static class UITween
{
    public static IEnumerator Move(RectTransform rt, Vector2 to,
                                   float duration, AnimationCurve curve = null)
    {
        Vector2 from = rt.anchoredPosition;
        float t = 0;

        while (t < duration)
        {
            t += Time.deltaTime;
            float p = Mathf.Clamp01(t / duration);
            if (curve != null) p = curve.Evaluate(p);

            rt.anchoredPosition = Vector2.Lerp(from, to, p);
            yield return null;
        }

        rt.anchoredPosition = to;
    }

    public static IEnumerator Scale(Transform tr, Vector3 to, float duration)
    {
        Vector3 from = tr.localScale;
        float t = 0;

        while (t < duration)
        {
            t += Time.deltaTime;
            tr.localScale = Vector3.Lerp(from, to, EaseOutBack(t / duration));
            yield return null;
        }

        tr.localScale = to;
    }

    public static IEnumerator Fade(CanvasGroup g, float to, float duration)
    {
        float from = g.alpha;
        float t = 0;

        while (t < duration)
        {
            t += Time.deltaTime;
            g.alpha = Mathf.Lerp(from, to, t / duration);
            yield return null;
        }

        g.alpha = to;
    }

    // ─── 이징 함수 ───

    public static float EaseOutQuad(float t) => 1 - (1 - t) * (1 - t);

    public static float EaseOutBack(float t)
    {
        const float c1 = 1.70158f, c3 = c1 + 1;
        return 1 + c3 * Mathf.Pow(t - 1, 3) + c1 * Mathf.Pow(t - 1, 2);
    }

    public static float EaseInOutCubic(float t)
        => t < 0.5f ? 4 * t * t * t : 1 - Mathf.Pow(-2 * t + 2, 3) / 2;
}
```

```
   ★ 이징 곡선

   Linear        ────────────      기계적
   EaseOutQuad   ──────╱‾‾‾‾‾      빠르게 시작, 부드럽게 도착 ★
   EaseOutBack   ─────╱‾╲‾‾‾       살짝 지나쳤다 돌아옴 (탄력)
   EaseInOutCubic ──╱‾‾‾╲──        느리게-빠르게-느리게
```

```
   ★ 연출의 기본 규칙

   ① 등장은 EaseOutBack (탄력)
   ② 이동은 EaseOutQuad (자연스러움)
   ③ 사라짐은 빠르게 (0.15초 이내)
   ④ 0.3초를 넘으면 답답하다
```

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.EventSystems;

[RequireComponent(typeof(CanvasGroup))]
public class CardDragHandler : MonoBehaviour,
    IBeginDragHandler, IDragHandler, IEndDragHandler, IPointerClickHandler
{
    [SerializeField] private float dragScale = 1.1f;
    [SerializeField] private float dragAlpha = 0.8f;

    private RectTransform rt;
    private CanvasGroup group;
    private CardView view;

    private Canvas canvas;
    private RectTransform canvasRect;
    private RectTransform dragLayer;

    private Transform originalParent;
    private int originalIndex;
    private Vector2 grabOffset;

    private bool dropHandled;
    private bool dropSuccess;

    public CardView View => view;
    public bool IsDragging { get; private set; }

    void Awake()
    {
        rt = GetComponent<RectTransform>();
        group = GetComponent<CanvasGroup>();
        view = GetComponent<CardView>();
    }

    public void Init(Canvas c, RectTransform layer)
    {
        canvas = c;
        canvasRect = c.GetComponent<RectTransform>();
        dragLayer = layer;
    }

    // ─── 드래그 ───

    public void OnBeginDrag(PointerEventData e)
    {
        if (!GameManager.Instance.IsPlayerTurn) return;

        IsDragging = true;
        dropHandled = false;
        dropSuccess = false;

        originalParent = rt.parent;
        originalIndex = rt.GetSiblingIndex();

        // ★ 잡은 지점 오프셋 계산
        Vector2 local = ScreenToLocal(e.position);
        grabOffset = rt.anchoredPosition - local;

        rt.SetParent(dragLayer, true);         // ★ 최상위로
        rt.SetAsLastSibling();

        group.blocksRaycasts = false;          // ★ 레이캐스트 통과
        group.alpha = dragAlpha;

        rt.localScale = Vector3.one * dragScale;
        rt.localRotation = Quaternion.identity;
    }

    public void OnDrag(PointerEventData e)
    {
        if (!IsDragging) return;

        Vector2 local = ScreenToLocal(e.position);
        rt.anchoredPosition = local + grabOffset;
    }

    public void OnEndDrag(PointerEventData e)
    {
        if (!IsDragging) return;

        IsDragging = false;

        group.blocksRaycasts = true;
        group.alpha = 1f;

        if (dropHandled && dropSuccess)
        {
            dropHandled = false;
            return;                            // GameManager가 처리
        }

        // ★ 원위치
        rt.SetParent(originalParent, true);
        rt.SetSiblingIndex(originalIndex);
        rt.localScale = Vector3.one;

        dropHandled = false;
    }

    public void NotifyDropResult(bool success)
    {
        dropHandled = true;
        dropSuccess = success;
    }

    // ─── 클릭 ───

    public void OnPointerClick(PointerEventData e)
    {
        if (IsDragging) return;
        CardZoom.Instance?.Show(view.Instance);
    }

    // ─── 유틸 ───

    private Vector2 ScreenToLocal(Vector2 screen)
    {
        Camera cam = canvas.renderMode == RenderMode.ScreenSpaceOverlay
                     ? null : canvas.worldCamera;

        RectTransformUtility.ScreenPointToLocalPointInRectangle(
            canvasRect, screen, cam, out Vector2 local);

        return local;
    }
}
```

```csharp
    private IEnumerator ShakeRoutine(RectTransform target)
    {
        Vector2 origin = target.anchoredPosition;
        float t = 0;
        const float DUR = 0.25f;
        const float AMP = 12f;

        while (t < DUR)
        {
            t += Time.deltaTime;

            float decay = 1f - (t / DUR);
            float offset = Mathf.Sin(t * 60f) * AMP * decay;

            target.anchoredPosition = origin + new Vector2(offset, 0);
            yield return null;
        }

        target.anchoredPosition = origin;
    }
```

```csharp
    private void SpawnDamageNumber(Vector2 pos, int amount)
    {
        GameObject go = PoolManager.Instance.Get("damage_number",
                                                 Vector3.zero, Quaternion.identity);
        if (go == null) return;

        go.transform.SetParent(effectLayer, false);

        RectTransform r = go.GetComponent<RectTransform>();
        r.anchoredPosition = pos + new Vector2(Random.Range(-30f, 30f), 20f);

        go.GetComponent<TextMeshProUGUI>().text = $"-{amount}";

    private IEnumerator FloatAndFade(GameObject go, RectTransform r)
    {
        CanvasGroup g = go.GetComponent<CanvasGroup>();
        Vector2 from = r.anchoredPosition;
        float t = 0;

        while (t < 0.8f)
        {
            t += Time.deltaTime;
            float p = t / 0.8f;

            r.anchoredPosition = from + Vector2.up * (p * 80f);
            g.alpha = 1f - p * p;              // ★ 나중에 빠르게 사라짐

            yield return null;
        }

        PoolManager.Instance.Return(go);       // ★ Day 74의 풀
    }
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **드래그가 안 잡힘** | EventSystem 없음 | UI → EventSystem |
| 드래그가 안 잡힘 | Graphic Raycaster 없음 | Canvas에 추가 |
| 드래그가 안 잡힘 | Raycast Target ✗ | 체크 |
| 드래그가 안 잡힘 | `IDragHandler` 미구현 | 3개 함께 구현 |
| **OnDrop이 안 불림** | `blocksRaycasts` | 드래그 중 false |
| OnDrop이 안 불림 | 드롭 영역 Raycast Target ✗ | 체크 |
| 카드가 다른 UI에 가림 | 부모 그대로 | DragLayer + `SetAsLastSibling` |
| 드롭 위치가 어긋남 | 좌표 변환 누락 | `ScreenPointToLocalPointInRectangle` |
| 해상도에 따라 어긋남 | `delta` 직접 사용 | 좌표 변환 또는 `scaleFactor` 나누기 |
| 카드가 마우스 중앙에 붙음 | grabOffset 없음 | 시작 시 오프셋 저장 |
| OnEndDrag가 먼저 실행됨 | 순서 오해 | OnDrop이 먼저 |
| 클릭이 안 됨 | Drag Threshold 0 | 10 정도로 |
| 연출이 끊김 | 오브젝트 파괴 | 연출 후 Destroy |
| 연출이 겹침 | 코루틴 중복 | `StopCoroutine` 후 시작 |
| 화살표가 안 돌아감 | 각도 계산 | `Atan2 * Rad2Deg - 90` |
| 데미지 숫자가 안 사라짐 | 풀 반납 누락 | `Return` 호출 |
