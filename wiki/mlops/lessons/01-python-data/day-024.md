## ② 왜 필요한가

정제된 데이터로 **질문에 답해야** 합니다.

```
"미세먼지가 가장 나쁜 지역은?"           → groupby
"주말과 평일이 다른가?"                  → groupby + 파생 컬럼
"기온이 높으면 오존도 높은가?"            → merge + 산점도
"지역 × 요일별 평균을 표로 보고 싶다"      → pivot_table
"12일간 추이를 한눈에"                   → 선 그래프
```

그리고 **오늘 배우는 것이 SQL의 예고편**입니다.

| Pandas | SQL (W07–W08) |
|---|---|
| `df.merge(other, on="id")` | `JOIN` |
| `df.groupby("g").mean()` | `GROUP BY` |
| `df[df["x"] > 5]` | `WHERE` |
| `df.groupby("g").filter(...)` | `HAVING` |
| `pivot_table` | `CASE WHEN` + `GROUP BY` |

## ③ 개념 설명

### merge — 키로 결합

```python
pd.merge(left, right, on="key", how="inner")
df.merge(other, on="key")            # 메서드 형태 (같음)
```

| `how` | 남는 행 | SQL |
|---|---|---|
| `"inner"` (기본) | **양쪽에 다 있는 것만** | `INNER JOIN` |
| `"left"` | 왼쪽 전부 + 매칭되는 오른쪽 | `LEFT JOIN` |
| `"right"` | 오른쪽 전부 | `RIGHT JOIN` |
| `"outer"` | 양쪽 전부 | `FULL OUTER JOIN` |

```
left            right           inner        left
 A  1            A  x            A 1 x        A 1 x
 B  2            B  y            B 2 y        B 2 y
 C  3            D  z                          C 3 NaN
```

**컬럼 이름이 다를 때**

```python
df.merge(other, left_on="station", right_on="station_name")
df.merge(other, left_index=True, right_on="id")
```

**같은 이름 컬럼이 양쪽에 있으면 접미사가 붙습니다.**

```python
df.merge(other, on="id", suffixes=("_left", "_right"))
```

### merge의 함정 — 행이 늘어난다

**1:N 관계를 1:1로 착각하면 행이 폭증합니다.**

```
주문(3행)          고객(1행, 중복 있음)
 order_id cust      cust  name
   1       A          A    홍길동
   2       A          A    홍길동      ← 중복!
   3       B          B    김철수

merge 결과: 5행 (1번 주문이 2번 매칭됨)
```

**항상 확인하세요.**

```python
print(f"merge 전: {len(df)}행")
merged = df.merge(other, on="key")
print(f"merge 후: {len(merged)}행")

# 키가 유일한지 미리 확인
assert other["key"].is_unique, "오른쪽 키에 중복이 있습니다"

# validate 옵션으로 강제
df.merge(other, on="key", validate="many_to_one")   # 위반하면 에러
```

| `validate` | 뜻 |
|---|---|
| `"one_to_one"` | 양쪽 다 유일 |
| `"one_to_many"` | 왼쪽만 유일 |
| `"many_to_one"` | **오른쪽만 유일** ⭐ 가장 흔한 경우 |
| `"many_to_many"` | 검사 안 함 |

**`indicator=True` 로 매칭 결과를 확인할 수 있습니다.**

```python
merged = df.merge(other, on="key", how="outer", indicator=True)
merged["_merge"].value_counts()
# both          280
# left_only      20    ← 오른쪽에 없는 키
# right_only      5
```

### concat — 단순히 이어붙이기

```python
pd.concat([df1, df2])                       # 세로 (행 추가)
pd.concat([df1, df2], ignore_index=True)    # 인덱스 재부여  ⭐
pd.concat([df1, df2], axis=1)               # 가로 (열 추가)
```

**merge vs concat**

| | merge | concat |
|---|---|---|
| 기준 | **키(값)** | 위치·인덱스 |
| 용도 | 다른 정보를 붙임 | 같은 구조를 이어붙임 |
| 예 | 주문 + 고객정보 | 1월 데이터 + 2월 데이터 |

### groupby — 그룹별 집계

```python
df.groupby("station")["pm10"].mean()
df.groupby(["station", "date"])["pm10"].mean()
```

**동작 원리 — Split-Apply-Combine**

```
    Split              Apply           Combine
  ┌────────┐        ┌────────┐       ┌────────┐
  │ A: 1,3 │  ───▶  │ mean=2 │  ───▶ │ A: 2   │
  │ B: 5,7 │        │ mean=6 │       │ B: 6   │
  └────────┘        └────────┘       └────────┘
```

**여러 통계를 한 번에 — `agg`**

```python
df.groupby("station")["pm10"].agg(["mean", "median", "std", "count", "min", "max"])

# 컬럼마다 다른 통계
df.groupby("station").agg({
    "pm10": ["mean", "max"],
    "pm25": "mean",
    "date": "nunique",
})

# 이름 지정 (권장) ⭐
df.groupby("station").agg(
    평균=("pm10", "mean"),
    최대=("pm10", "max"),
    측정일수=("date", "nunique"),
    결측=("pm10", lambda s: s.isna().sum()),
)
```

**마지막 형태(named aggregation)를 쓰세요.** 컬럼 이름이 깔끔하게 나옵니다.

**`as_index=False` 로 인덱스 대신 컬럼으로**

```python
df.groupby("station", as_index=False)["pm10"].mean()
# 또는
df.groupby("station")["pm10"].mean().reset_index()
```

### transform — 그룹 통계를 원래 크기로

```python
df.groupby("station")["pm10"].mean()          # 25행 (그룹 수)
df.groupby("station")["pm10"].transform("mean")   # 300행 (원본 크기)  ⭐
```

**원본에 그룹 통계를 붙일 때 씁니다.**

```python
df["측정소평균"] = df.groupby("station")["pm10"].transform("mean")
df["편차"] = df["pm10"] - df["측정소평균"]

# 결측 대치 ([Day 023](day-023.md))
df["pm10"] = df.groupby("station")["pm10"].transform(lambda s: s.fillna(s.median()))
```

### filter — 그룹 단위로 걸러내기

```python
# 측정일수가 10일 이상인 측정소의 행만
df.groupby("station").filter(lambda g: len(g) >= 10)

# 평균이 40 넘는 그룹만
df.groupby("station").filter(lambda g: g["pm10"].mean() > 40)
```

**SQL의 `HAVING` 에 해당합니다.**

### pivot_table — 2차원 요약표

```python
df.pivot_table(
    index="station",        # 행
    columns="weekday",      # 열
    values="pm10",          # 값
    aggfunc="mean",         # 집계 방법
    fill_value=0,           # 빈 칸 채우기
    margins=True,           # 합계 행/열 추가
)
```

```
weekday        Mon    Tue    Wed    All
station
강남구          41.2   38.5   44.1   41.3
서초구          39.8   42.1   40.2   40.7
All            40.5   40.3   42.2   41.0
```

**`pivot` vs `pivot_table`**

| | `pivot` | `pivot_table` |
|---|---|---|
| 중복 키 | 에러 | **집계** |
| aggfunc | 없음 | 지정 가능 |
| 실무 | 거의 안 씀 | ⭐ |

### crosstab — 빈도 교차표

```python
pd.crosstab(df["station"], df["grade"])
pd.crosstab(df["station"], df["grade"], normalize="index")   # 행 비율
```

### 질문에 맞는 차트 고르기

| 질문 | 차트 | 코드 |
|---|---|---|
| **분포**가 어떤가 | 히스토그램 · 박스플롯 | `ax.hist()` · `ax.boxplot()` |
| **시간에 따라** 어떻게 변하나 | 선 그래프 | `ax.plot()` |
| 항목끼리 **비교** | 막대 그래프 | `ax.bar()` · `ax.barh()` |
| 두 변수의 **관계** | 산점도 | `ax.scatter()` |
| **구성 비율** | 막대(누적) · 파이 | `ax.bar(bottom=)` |
| **여러 그룹의 분포** | 박스플롯 · 바이올린 | `ax.boxplot()` |

> **파이 차트는 되도록 피하세요.** 사람은 각도를 정확히 비교하지 못합니다.
> 항목이 3개 이하이거나 "과반인가"만 볼 때가 아니면 **가로 막대**가 낫습니다.

### Step 1. 준비 — 결합할 데이터 만들기

```python
"""병합 실습용 보조 데이터 생성."""

from pathlib import Path

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
OUT = Path("data")

# --- 1) 측정소 정보 (마스터 테이블) ---
stations = ["중구", "종로구", "용산구", "성동구", "광진구", "동대문구", "중랑구",
            "성북구", "강북구", "도봉구", "노원구", "은평구", "서대문구", "마포구",
            "양천구", "강서구", "구로구", "금천구", "영등포구", "동작구",
            "관악구", "서초구", "강남구", "송파구", "강동구"]

REGION = {
    "도심": ["중구", "종로구", "용산구"],
    "동북": ["성동구", "광진구", "동대문구", "중랑구", "성북구", "강북구",
            "도봉구", "노원구"],
    "서북": ["은평구", "서대문구", "마포구"],
    "서남": ["양천구", "강서구", "구로구", "금천구", "영등포구", "동작구", "관악구"],
    "동남": ["서초구", "강남구", "송파구", "강동구"],
}
region_of = {s: r for r, ss in REGION.items() for s in ss}

station_info = pd.DataFrame({
    "측정소명": stations,
    "권역": [region_of[s] for s in stations],
    "인구수": rng.integers(150_000, 700_000, len(stations)),
    "면적": rng.uniform(10, 47, len(stations)).round(1),
    "도로율": rng.uniform(0.08, 0.28, len(stations)).round(3),
})
station_info["인구밀도"] = (station_info["인구수"] / station_info["면적"]).round(0)

# 일부러 한 곳을 빼서 left join 을 연습합니다
station_info = station_info[station_info["측정소명"] != "금천구"].reset_index(drop=True)

station_info.to_csv(OUT / "station_info.csv", index=False, encoding="utf-8-sig")
print(f"측정소 정보: {len(station_info)}개 (금천구 누락)")

# --- 2) 날씨 데이터 ---
dates = pd.date_range("2026-08-01", "2026-08-12", freq="D")
weather = pd.DataFrame({
    "측정일시": dates,
    "평균기온": rng.uniform(24, 33, len(dates)).round(1),
    "강수량": np.where(rng.random(len(dates)) < 0.3,
                     rng.uniform(1, 45, len(dates)).round(1), 0.0),
    "평균풍속": rng.uniform(0.8, 4.2, len(dates)).round(1),
    "평균습도": rng.integers(45, 88, len(dates)),
})
weather.to_csv(OUT / "weather.csv", index=False, encoding="utf-8-sig")
print(f"날씨 데이터: {len(weather)}일")

print("\n측정소 정보 앞 5행:")
print(station_info.head().to_string(index=False))
print("\n날씨 데이터:")
print(weather.to_string(index=False))
```

### Step 2. merge — 조인 종류 비교

`merge_demo.py` 를 만듭니다.

```python
import pandas as pd

pd.set_option("display.width", 140)

air = pd.read_csv("data/air_cleaned.csv", encoding="utf-8-sig",
                  parse_dates=["측정일시"])
station = pd.read_csv("data/station_info.csv", encoding="utf-8-sig")
weather = pd.read_csv("data/weather.csv", encoding="utf-8-sig",
                      parse_dates=["측정일시"])

print(f"대기질  : {len(air)}행, 측정소 {air['측정소명'].nunique()}개")
print(f"측정소  : {len(station)}행")
print(f"날씨    : {len(weather)}행\n")

print("=" * 72)
print("조인 종류 비교")
print("=" * 72)

for how in ["inner", "left", "right", "outer"]:
    merged = air.merge(station, on="측정소명", how=how)
    na_count = merged["권역"].isna().sum()
    print(f"  {how:<7}: {len(merged):>4}행   권역 결측 {na_count:>3}건")

print("""
  inner  : 양쪽에 다 있는 것만 → 금천구 12건이 사라짐
  left   : 대기질 전부 유지 → 금천구는 권역이 NaN
  right  : 측정소 정보 전부 유지
  outer  : 양쪽 전부
""")

print("=" * 72)
print("indicator 로 매칭 결과 확인")
print("=" * 72)
checked = air.merge(station, on="측정소명", how="outer", indicator=True)
print(checked["_merge"].value_counts().to_string())

missing = checked[checked["_merge"] == "left_only"]["측정소명"].unique()
print(f"\n  측정소 정보가 없는 곳: {list(missing)}")

print("\n" + "=" * 72)
print("validate 로 관계 강제")
print("=" * 72)
print(f"  측정소명이 유일한가: {station['측정소명'].is_unique}")

try:
    air.merge(station, on="측정소명", how="left", validate="many_to_one")
    print("  ✓ many_to_one 검증 통과 (오른쪽 키가 유일)")
except Exception as e:
    print(f"  ✗ {e}")

# 일부러 중복을 만들어 실패를 확인
dup_station = pd.concat([station, station.head(1)], ignore_index=True)
try:
    air.merge(dup_station, on="측정소명", how="left", validate="many_to_one")
    print("  ✗ 중복이 있는데 통과했습니다 (문제)")
except Exception as e:
    print(f"  ✓ 중복 감지: {type(e).__name__}")

print("\n" + "=" * 72)
print("행 수 검증 — merge 로 데이터가 늘어나지 않았는가")
print("=" * 72)
before = len(air)
df = air.merge(station, on="측정소명", how="left", validate="many_to_one")
after = len(df)
print(f"  merge 전: {before}행")
print(f"  merge 후: {after}행")
print(f"  {'✓ 행 수 유지' if before == after else '⚠ 행 수 변화 — 1:N 관계 확인 필요'}")

print("\n" + "=" * 72)
print("두 번째 merge — 날씨 결합")
print("=" * 72)
df = df.merge(weather, on="측정일시", how="left", validate="many_to_one")
print(f"  최종: {df.shape}")
print(f"  컬럼: {list(df.columns)}")

print("\n앞 3행:")
print(df[["측정일시", "측정소명", "권역", "미세먼지", "평균기온", "강수량"]].head(3).to_string(index=False))

df.to_csv("data/air_merged.csv", index=False, encoding="utf-8-sig")
print(f"\n저장: data/air_merged.csv")
```

pd.set_option("display.width", 140)

print("=" * 72)
by_station = df.groupby("측정소명")["미세먼지"].mean().sort_values(ascending=False)
print(f"  미세먼지 평균 상위 5:")
for station, value in by_station.head(5).items():

    print(f"    {station:<8}{value:>7.1f}  {bar}")

print("\n" + "=" * 72)
print("2) 여러 통계 한 번에 — agg")
print("=" * 72)
stats = df.groupby("권역").agg(
    측정소수=("측정소명", "nunique"),
    관측수=("미세먼지", "count"),
    평균=("미세먼지", "mean"),
    중앙값=("미세먼지", "median"),
    표준편차=("미세먼지", "std"),
    최대=("미세먼지", "max"),
).round(2).sort_values("평균", ascending=False)
print(stats.to_string())

print("\n" + "=" * 72)
print("3) 여러 컬럼 그룹")
print("=" * 72)
by_region_weekday = (df.groupby(["권역", "주말"])["미세먼지"]
                       .mean().round(1).unstack())
by_region_weekday.columns = ["평일", "주말"]
by_region_weekday["차이"] = (by_region_weekday["주말"] - by_region_weekday["평일"]).round(1)

df["평균대비"] = (df["미세먼지"] - df["측정소평균"]).round(1)

      .to_string(index=False))

print("\n" + "=" * 72)
print("6) apply — 그룹마다 임의 처리")
print("=" * 72)
def summarize(g):
    return pd.Series({
        "최고일": g.loc[g["미세먼지"].idxmax(), "측정일시"].strftime("%m-%d"),
        "최고값": g["미세먼지"].max(),
        "최저일": g.loc[g["미세먼지"].idxmin(), "측정일시"].strftime("%m-%d"),
        "최저값": g["미세먼지"].min(),
        "변동폭": g["미세먼지"].max() - g["미세먼지"].min(),
    })

result = df.groupby("권역").apply(summarize, include_groups=False)

print("7) 날짜별 추이")

).round(1)

print("=" * 90)
multi = df.pivot_table(
    index="권역",
    values=["미세먼지", "초미세먼지"],

## ⑤ 자주 하는 실수

### merge 후 행이 늘어남

```python
print(len(df))        # 300
merged = df.merge(other, on="key")
print(len(merged))    # 1,200!
```

**원인** — 오른쪽 테이블의 키에 중복이 있어 **1:N 조인**이 됐습니다.
**해결** —

```python
# 1) 미리 확인
assert other["key"].is_unique, f"중복: {other['key'].duplicated().sum()}건"

# 2) validate 로 강제
df.merge(other, on="key", validate="many_to_one")

# 3) 오른쪽을 미리 유일하게
other = other.drop_duplicates("key")
```

**merge 전후 행 수를 항상 출력하세요.**

### `inner` 로 데이터가 조용히 사라짐

```python
merged = df.merge(other, on="station")      # 기본값이 inner
print(len(merged))      # 288 (원래 300)
```

**원인** — 오른쪽에 없는 키의 행이 버려졌습니다. **에러가 안 납니다.**
**해결** — `how="left"` 를 기본으로 쓰고, 결측을 확인하세요.

```python
merged = df.merge(other, on="station", how="left", indicator=True)
print(merged["_merge"].value_counts())
```

**"왼쪽 데이터는 모두 유지"가 대부분의 경우 안전합니다.**

### 키 타입이 달라 매칭이 안 됨

```python
left["id"]      # int64
right["id"]     # object ("1", "2")
merged = left.merge(right, on="id")      # 0행!
```

**원인** — `1` 과 `"1"` 은 다릅니다.
**해결** — 타입을 맞추세요.

```python
right["id"] = right["id"].astype(int)
# 또는
left["id"] = left["id"].astype(str)
```

**문자열 키는 공백도 확인하세요.**

```python
df["station"] = df["station"].str.strip()
```

### `groupby` 결과가 Series라 컬럼 접근이 안 됨

```python
result = df.groupby("station")["pm10"].mean()
result["station"]      # KeyError
```

**원인** — 그룹 키가 **인덱스**가 됐습니다.
**해결** —

```python
result = df.groupby("station", as_index=False)["pm10"].mean()
# 또는
result = df.groupby("station")["pm10"].mean().reset_index()
```

### `agg` 결과 컬럼명이 복잡함

```python
df.groupby("g").agg({"x": ["mean", "max"]})
# MultiIndex 컬럼: ('x', 'mean'), ('x', 'max')
df["x_mean"]      # KeyError
```

**해결** — named aggregation을 쓰세요.

```python
df.groupby("g").agg(
    x_mean=("x", "mean"),
    x_max=("x", "max"),
)
```

**깔끔한 단일 레벨 컬럼**이 나옵니다.

### `groupby` 가 결측 그룹을 버림

```python
df.groupby("category")["x"].mean()      # category 가 NaN 인 행은 제외됨
```

**해결** — `dropna=False` 를 주세요.

```python
df.groupby("category", dropna=False)["x"].mean()
```

**Pandas 1.1+ 부터 지원합니다.** 결측 그룹도 중요한 정보일 수 있습니다.

### `transform` 과 `agg` 를 혼동

```python
df["평균"] = df.groupby("g")["x"].mean()      # 길이가 안 맞아 NaN 투성이
```

**원인** — `mean()` 은 그룹 수만큼, 원본은 전체 행 수입니다.
**해결** — `transform` 을 쓰세요.

```python
df["평균"] = df.groupby("g")["x"].transform("mean")
```

| 목적 | 메서드 | 결과 크기 |
|---|---|---|
| 요약표 만들기 | `agg` / `mean` | 그룹 수 |
| 원본에 컬럼 추가 | **`transform`** | 원본 크기 |
| 그룹 단위 필터 | `filter` | 조건 만족 그룹의 행 |

**1.** `merge` 후 행 수가 300에서 1,200으로 늘었습니다. 원인이 무엇이고 어떻게 진단·해결하나요?

<details>
<summary>답 보기</summary>

**원인: 오른쪽 테이블의 키에 중복이 있습니다 (1:N 또는 N:N 조인).**

```
왼쪽(300행)              오른쪽(중복 있음)
 station  pm10            station  region
 강남구     41              강남구     동남
 강남구     38              강남구     동남      ← 중복!
                           강남구     동남      ← 중복!

→ 왼쪽 각 행이 오른쪽 3행과 매칭 → 900행
```

**진단**

```python
# 1) 양쪽 키의 유일성 확인
print(f"왼쪽 키 유일: {left['station'].is_unique}")
print(f"오른쪽 키 유일: {right['station'].is_unique}")

# 2) 중복 키가 무엇인지
dups = right[right.duplicated("station", keep=False)]
print(dups.sort_values("station"))

# 3) 중복 개수
print(right["station"].value_counts().head())
```

**해결 방법 4가지**

**① 오른쪽을 유일하게 만들기 (가장 흔함)**

```python
right_unique = right.drop_duplicates("station")
merged = left.merge(right_unique, on="station", how="left")
```

**어느 것을 남길지 규칙이 필요합니다.**

```python
# 최신 것
right_unique = right.sort_values("updated_at").drop_duplicates("station", keep="last")

# 집계해서 하나로
right_unique = right.groupby("station", as_index=False).agg({"population": "sum"})
```

**② `validate` 로 사전에 막기**

```python
merged = left.merge(right, on="station", how="left", validate="many_to_one")
# MergeError: Merge keys are not unique in right dataset
```

**merge를 쓸 때 항상 `validate` 를 붙이는 습관**을 들이세요.
의도한 관계가 코드에 드러나고, 위반하면 즉시 에러가 납니다.

**③ 키를 더 구체적으로**

중복이 진짜가 아니라 **키가 부족한** 경우가 많습니다.

```python
# 측정소명만으로는 유일하지 않고, 날짜까지 있어야 유일하다면
merged = left.merge(right, on=["station", "date"], how="left")
```

**④ 의도된 1:N 이라면 그대로 두되 인지하기**

주문 → 주문상세처럼 **원래 1:N인 관계**도 있습니다.
그럴 때는 행이 느는 것이 정상이고, **이후 집계에서 중복 계산에 주의**해야 합니다.

```python
# 주문 금액이 상세 행마다 반복되므로
merged.groupby("order_id")["order_amount"].first().sum()      # ✅
merged["order_amount"].sum()                                   # ❌ 중복 합산
```

**예방 습관**

```python
def safe_merge(left, right, **kwargs):
    before = len(left)
    result = left.merge(right, **kwargs)
    after = len(result)
    if after != before:
        print(f"⚠ merge 로 행 수 변화: {before} → {after}")
    return result
```

W07 [Day 034](../02-sql-pipeline/day-034.md)의 **"조인 키와 중복 함정"** 이 같은 주제입니다.
SQL에서도 똑같이 벌어집니다.

**2.** `groupby().mean()` 과 `groupby().transform("mean")` 의 차이는 무엇이고, 각각 언제 쓰나요?

<details>
<summary>답 보기</summary>

| | `agg` / `mean()` | `transform("mean")` |
|---|---|---|
| 결과 크기 | **그룹 수** | **원본 행 수** |
| 인덱스 | 그룹 키 | 원본 인덱스 |
| 용도 | 요약표 | 원본에 컬럼 추가 |

```python
df = pd.DataFrame({"g": ["a", "a", "b", "b", "b"], "x": [1, 3, 10, 20, 30]})

df.groupby("g")["x"].mean()
# g
# a     2.0
# b    20.0          ← 2행

df.groupby("g")["x"].transform("mean")
# 0     2.0
# 1     2.0
# 2    20.0
# 3    20.0
# 4    20.0          ← 5행 (원본과 같음)
```

**`mean()` 을 쓸 때 — 요약표**

```python
summary = df.groupby("station").agg(
    평균=("pm10", "mean"),
    최대=("pm10", "max"),
    측정일수=("date", "nunique"),
)
```

보고서·차트에 넣을 **25행짜리 요약**을 만듭니다.

**`transform` 을 쓸 때 — 원본에 붙이기**

```python
# 1) 그룹 평균 대비 편차
df["측정소평균"] = df.groupby("station")["pm10"].transform("mean")
df["편차"] = df["pm10"] - df["측정소평균"]

# 2) 그룹별 결측 대치 (Day 023)
df["pm10"] = df.groupby("station")["pm10"].transform(lambda s: s.fillna(s.median()))

# 3) 그룹 내 순위
df["순위"] = df.groupby("date")["pm10"].rank(ascending=False)

# 4) 그룹 내 정규화
df["z"] = df.groupby("station")["pm10"].transform(lambda s: (s - s.mean()) / s.std())
```

**전부 "원본 각 행에 그룹 정보를 붙이는" 작업입니다.**

**틀린 예 — 크기가 안 맞음**

```python
df["평균"] = df.groupby("g")["x"].mean()
```

```
     g   x   평균
0    a   1   NaN
1    a   3   NaN
2    b  10   NaN
```

`mean()` 결과의 인덱스는 `["a", "b"]` 인데 `df` 의 인덱스는 `[0,1,2,3,4]` 입니다.
**인덱스가 안 맞아 전부 `NaN`** 이 됩니다. 에러가 안 나서 더 위험합니다.

**merge로도 할 수 있지만 `transform` 이 간결합니다**

```python
# merge 버전 — 장황
means = df.groupby("g", as_index=False)["x"].mean().rename(columns={"x": "평균"})
df = df.merge(means, on="g")

# transform 버전 — 한 줄
df["평균"] = df.groupby("g")["x"].transform("mean")
```

**세 번째 형제 — `filter`**

```python
df.groupby("g").filter(lambda grp: len(grp) >= 10)
```

**그룹 단위 조건을 만족하는 그룹의 행 전체**를 남깁니다. SQL의 `HAVING` 입니다.

| 목적 | 메서드 | 결과 |
|---|---|---|
| 요약 | `agg` | 그룹당 1행 |
| 원본 확장 | **`transform`** | 원본 그대로 |
| 그룹 선별 | `filter` | 조건 만족 그룹의 모든 행 |
| 임의 처리 | `apply` | 반환에 따라 다름 |

이 구분이 **특성 엔지니어링**([Day 064](../03-machine-learning/day-064.md))에서 핵심이 됩니다.
"이 사용자의 평균 구매액 대비 이번 구매액"같은 특성을 만들 때 `transform` 을 씁니다.

**MP1의 "시각화 3종" 요구사항**을 채울 때 이 체크리스트를 쓰세요.

## 오늘의 정리

| 항목 | 문법 |
|---|---|
| 결합 | `df.merge(other, on="key", how="left", validate="many_to_one")` |
| 조인 종류 | `inner`(교집합) · **`left`**(왼쪽 유지) · `outer`(합집합) |
| 매칭 확인 | `indicator=True` → `_merge` 컬럼 |
| 이어붙이기 | `pd.concat([df1, df2], ignore_index=True)` |
| 그룹 집계 | `groupby("g").agg(이름=("컬럼", "함수"))` ⭐ |
| 원본 확장 | `groupby("g")["x"].transform("mean")` |
| 그룹 필터 | `groupby("g").filter(lambda g: 조건)` — SQL `HAVING` |
| 인덱스 | `as_index=False` 또는 `reset_index()` |
| 결측 그룹 | `dropna=False` |
| 요약표 | `pivot_table(index=, columns=, values=, aggfunc=, margins=True)` |
| 교차표 | `pd.crosstab(a, b, normalize="index")` |
| 형태 변환 | `unstack()` 넓게 · `stack()` 길게 |
| 한글 폰트 | `plt.rcParams["font.family"]` + `axes.unicode_minus = False` |
| 차트 선택 | 분포=히스토그램/박스 · 추이=선 · 비교=막대 · 관계=산점도 |
| 저장 | `plt.savefig(path, bbox_inches="tight")` + `plt.close()` |
| **금기** | merge 후 행 수 미확인 · `inner` 기본값 방치 · 파이 차트 남용 |

**과제** — 정제한 데이터로 분석 리포트를 만드세요.
① 보조 데이터(지역 정보·날씨 등)를 **최소 2개 결합** — `validate` 와 행 수 검증 포함
② `groupby` 로 **3가지 이상의 질문에 답하는 집계표** (named aggregation 사용)
③ `pivot_table` 로 2차원 요약표 1개
④ `transform` 으로 파생 컬럼 2개 이상 (그룹 평균 대비 편차 등)
⑤ 차트 **4종** (분포·추이·비교·관계) — 제목이 질문에 답하는 문장이어야 함
⑥ 상관계수를 계산하되 **인과로 해석하지 않도록 주의 문구** 포함
⑦ `docs/analysis.md` 에 "질문 → 근거(표·차트) → 결론" 구조로 정리
