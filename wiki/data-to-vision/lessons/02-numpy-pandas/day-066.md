## 1부 · 좌표

### 위도와 경도

```
        북위 90°
           │
    ───────┼───────  적도 (위도 0°)
           │
        남위 90°

    서경 180° ── 본초자오선(0°) ── 동경 180°
```

| | 위도 (Latitude) | 경도 (Longitude) |
|---|---|---|
| 기준 | 적도 | 본초자오선 |
| 범위 | -90 ~ 90 | -180 ~ 180 |
| 방향 | **남북** (세로) | **동서** (가로) |
| 그래프에서 | **y축** | **x축** |
| 약자 | `lat`, `y` | `lng`/`lon`, `x` |
| **한국 범위** | **33 ~ 39** | **124 ~ 132** |

```
한국의 대략적 위치

  39 ┤                    ● 백두산 부근(경계)
     │
  37 ┤        ● 서울 (37.57, 126.98)
     │
  35 ┤        ● 부산 (35.18, 129.08)
     │
  33 ┤   ● 제주 (33.50, 126.53)
     └──┬──────┬──────┬──────┬──
       124    126    128    130
```

### ⚠️ 순서 문제 — 가장 흔한 사고

**라이브러리마다 순서가 다릅니다.**

| 대상 | 순서 |
|---|---|
| **folium** | `[위도, 경도]` = `[lat, lng]` ⭐ |
| **GeoJSON** | `[경도, 위도]` = `[lng, lat]` ⚠️ |
| 카카오 API | `x`=경도, `y`=위도 |
| 구글 지도 | `lat, lng` |
| matplotlib scatter | `x`=경도, `y`=위도 |

```python
# folium
folium.Marker([37.5665, 126.9780])          # 서울 ✅
folium.Marker([126.9780, 37.5665])          # 남극 근처 ❌

# GeoJSON
{"coordinates": [126.9780, 37.5665]}        # 서울 ✅ (경도 먼저!)
```

> **판별법 — 한국이면 위도는 30대, 경도는 120대입니다.**
> ```python
> if 33 <= a <= 39 and 124 <= b <= 132:
>     lat, lng = a, b          # a가 위도
> elif 33 <= b <= 39 and 124 <= a <= 132:
>     lat, lng = b, a          # 뒤바뀜!
> ```

### 좌표계 — WGS84 와 국내 좌표계

| 좌표계 | EPSG | 단위 | 쓰는 곳 |
|---|---|---|---|
| **WGS84** | **4326** | 도(°) | **GPS·웹지도 표준** ⭐ |
| UTM-K | 5179 | 미터 | 국토지리정보원 |
| TM 중부원점 | 5186 | 미터 | 국내 지적도 |
| Bessel TM | 2097 | 미터 | 구 좌표계 |

```
WGS84         :  37.5665,  126.9780         ← 도 단위
UTM-K         :  953,000,  1,952,000        ← 미터 단위 (값이 큼!)
```

> **값이 6자리 이상이면 WGS84 가 아닙니다.**
> 공공데이터에는 국내 좌표계가 섞여 있습니다.
>
> ```python
> # 변환이 필요하면
> # pip install pyproj
> from pyproj import Transformer
>
> tf = Transformer.from_crs("EPSG:5186", "EPSG:4326", always_xy=True)
> lng, lat = tf.transform(x, y)
> ```

### 1도는 몇 km 인가

```
위도 1도  ≈  111 km          (어디서나 거의 같음)
경도 1도  ≈  111 × cos(위도) km

  적도  (0°)   : 111 km
  서울  (37.5°): 111 × cos(37.5°) ≈ 88 km
  북극 (90°)   : 0 km
```

> **경도 간격은 위도에 따라 달라집니다.**
> 그래서 **단순 유클리드 거리는 틀립니다.**
> ```python
> np.sqrt((lat1-lat2)**2 + (lng1-lng2)**2)     # ❌
> ```

### 하버사인 공식 — 구면 거리

```python
import numpy as np

EARTH_RADIUS_KM = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    """두 지점 간 거리를 km 로 반환합니다."""
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))

    dlat = lat2 - lat1
    dlng = lng2 - lng1

    a = (np.sin(dlat / 2) ** 2
         + np.cos(lat1) * np.cos(lat2) * np.sin(dlng / 2) ** 2)

    return 2 * EARTH_RADIUS_KM * np.arcsin(np.sqrt(a))
```

**배열에도 그대로 동작합니다 (벡터화)**

```python
df["distance_km"] = haversine(37.5665, 126.9780, df["lat"], df["lng"])
```

| 방법 | 오차 | 속도 |
|---|---|---|
| 유클리드 | **매우 큼** | 빠름 |
| **하버사인** | 0.5% 이내 | **빠름** ⭐ |
| Vincenty (타원체) | 0.001% | 느림 |

> **국내 거리 계산에는 하버사인으로 충분합니다.**

**빠른 근사 — 사각형 필터**

```python
# 반경 5km 안의 후보만 먼저 추리기 (하버사인 계산량 절약)
lat_margin = 5 / 111
lng_margin = 5 / (111 * np.cos(np.radians(center_lat)))

candidates = df[
    df["lat"].between(center_lat - lat_margin, center_lat + lat_margin) &
    df["lng"].between(center_lng - lng_margin, center_lng + lng_margin)
]

candidates["dist"] = haversine(center_lat, center_lng,
                               candidates["lat"], candidates["lng"])
result = candidates[candidates["dist"] <= 5]
```

### 지오코딩이 실패하는 이유

| 원인 | 예 | 대응 |
|---|---|---|
| 주소가 불완전 | `"종로구"` | 시도명 추가 |
| 옛 주소 | 폐지된 지번 | 도로명으로 변환 |
| 상세주소 포함 | `"... 3층 301호"` | **꼬리 제거** ⭐ |
| 오타 | `"서울특벌시"` | 정규화 ([Day 058](day-058.md)) |
| 건물명만 | `"롯데타워"` | **키워드 검색**으로 전환 |
| 신규 주소 | 최근 개발지 | 어쩔 수 없음 |

**전처리로 성공률을 올립니다**

```python
import re

def clean_address(addr):
    """지오코딩 성공률을 높이는 주소 정제."""
    if not addr:
        return ""

    s = str(addr).strip()

    # 괄호 안 제거: "사직로 161 (세종로)" → "사직로 161"
    s = re.sub(r"\([^)]*\)", " ", s)

    # 층·호·동 제거: "... 3층 301호" → "..."
    s = re.sub(r"\s*[\dB]+\s*층.*$", "", s)
    s = re.sub(r"\s*\d+\s*호.*$", "", s)

    # 우편번호 제거
    s = re.sub(r"\b\d{5}\b", "", s)

    # 연속 공백
    s = re.sub(r"\s+", " ", s).strip()

    return s
```

**단계적 폴백 — 짧게 잘라 가며 재시도**

```
"서울특별시 종로구 사직로 161 경복궁"   실패
       ↓ 뒤 한 토막 제거
"서울특별시 종로구 사직로 161"          성공 ✅
```

### Step 1. 좌표 검증

```python
"""좌표 데이터의 타당성을 검증합니다."""

import platform
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                              else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

OUT = Path("output")
OUT.mkdir(exist_ok=True)

KOREA_BOUNDS = {"lat": (33.0, 39.0), "lng": (124.0, 132.0)}

LANDMARKS = {
    "서울시청": (37.5665, 126.9780),
    "부산역": (35.1152, 129.0423),
    "제주공항": (33.5070, 126.4930),
    "강릉역": (37.7640, 128.8961),
    "대전역": (36.3316, 127.4342),
}

# ── 문제가 섞인 좌표 데이터 ──
rng = np.random.default_rng(42)
N = 200

df = pd.DataFrame({
    "id": range(1, N + 1),
    "name": [f"관광지{i:03d}" for i in range(1, N + 1)],
    "sido": rng.choice(["서울특별시", "부산광역시", "제주특별자치도"], N),
    "lat": rng.uniform(33.2, 38.5, N).round(6),
    "lng": rng.uniform(126.0, 129.5, N).round(6),
})

# 문제 심기
df.loc[0:2, ["lat", "lng"]] = [[126.98, 37.57],           # 순서 뒤바뀜
                                [129.04, 35.12],
                                [126.49, 33.51]]
df.loc[3:4, ["lat", "lng"]] = 0.0                          # (0,0)
df.loc[5, ["lat", "lng"]] = [953000, 1952000]              # UTM-K
df.loc[6, "lat"] = np.nan                                  # 결측
df.loc[7, ["lat", "lng"]] = [51.5074, -0.1278]             # 런던 (범위 밖)


def validate_coords(df, lat_col="lat", lng_col="lng", verbose=True):
    """좌표 타당성을 검증하고 문제 유형을 분류합니다."""
    out = df.copy()
    lat, lng = out[lat_col], out[lng_col]

    LAT_MIN, LAT_MAX = KOREA_BOUNDS["lat"]
    LNG_MIN, LNG_MAX = KOREA_BOUNDS["lng"]

    out["_issue"] = ""

    # ① 결측
    out.loc[lat.isna() | lng.isna(), "_issue"] = "결측"

    # ② (0, 0)
    out.loc[(lat == 0) & (lng == 0), "_issue"] = "(0,0) — 지오코딩 실패"

    # ③ 값이 너무 큼 → 다른 좌표계
    out.loc[(lat.abs() > 1000) | (lng.abs() > 1000), "_issue"] = \
        "값이 큼 — 국내 좌표계(UTM-K/TM) 의심"

    # ④ 순서 뒤바뀜
    swapped = (lat.between(LNG_MIN, LNG_MAX)
               & lng.between(LAT_MIN, LAT_MAX)
               & ~lat.between(LAT_MIN, LAT_MAX))
    out.loc[swapped & (out["_issue"] == ""), "_issue"] = "위경도 뒤바뀜"

    # ⑤ 범위 밖
    out_of_range = ~(lat.between(LAT_MIN, LAT_MAX)
                     & lng.between(LNG_MIN, LNG_MAX))
    out.loc[out_of_range & (out["_issue"] == ""), "_issue"] = "한반도 범위 밖"

    out["_valid"] = out["_issue"] == ""

    if verbose:
        print("=" * 76)
        print("                     좌표 검증")
        print("=" * 76)

        print(f"\n[요약]  전체 {len(out):,}건")
        print(f"  정상   : {out['_valid'].sum():,}건 "
              f"({out['_valid'].mean()*100:.1f}%)")
        print(f"  문제   : {(~out['_valid']).sum():,}건")

        problems = out[~out["_valid"]]["_issue"].value_counts()

        if len(problems):
            print(f"\n[문제 유형]")
            for issue, n in problems.items():
                print(f"  {issue:<36}{n:>5}건")

            print(f"\n[문제 사례]")
            print(f"  {'id':<5}{'이름':<12}{'lat':>14}{'lng':>14}  문제")
            print("  " + "-" * 62)
            for _, r in out[~out["_valid"]].head(8).iterrows():
                lat_s = f"{r[lat_col]:,.4f}" if pd.notna(r[lat_col]) else "NaN"
                lng_s = f"{r[lng_col]:,.4f}" if pd.notna(r[lng_col]) else "NaN"
                print(f"  {r['id']:<5}{r['name']:<12}{lat_s:>14}{lng_s:>14}  "
                      f"{r['_issue']}")

        print(f"\n[정상 좌표 범위]")
        valid = out[out["_valid"]]
        print(f"  위도 : {valid[lat_col].min():.4f} ~ {valid[lat_col].max():.4f}")
        print(f"  경도 : {valid[lng_col].min():.4f} ~ {valid[lng_col].max():.4f}")

        print("\n" + "=" * 76)

    return out


checked = validate_coords(df)

# ── 자동 수정 시도 ──

"""하버사인 거리 계산과 반경 필터."""

EARTH_RADIUS_KM = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    """두 지점 간 거리(km). 배열도 가능."""
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))

    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = (np.sin(dlat / 2) ** 2
         + np.cos(lat1) * np.cos(lat2) * np.sin(dlng / 2) ** 2)

    return 2 * EARTH_RADIUS_KM * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


def euclidean_deg(lat1, lng1, lat2, lng2):
    """❌ 잘못된 방법 — 도 단위 유클리드 거리."""
    return np.sqrt((lat1 - lat2) ** 2 + (lng1 - lng2) ** 2)


def within_radius(df, center, radius_km, lat_col="lat", lng_col="lng"):
    """
    중심점 반경 안의 행을 반환합니다. (사각형 사전 필터 + 하버사인)
    """
    c_lat, c_lng = center

    lat_margin = radius_km / 111.0
    lng_margin = radius_km / (111.0 * np.cos(np.radians(c_lat)))

    # ① 사각형으로 후보 추리기 (빠름)
    box = df[
        df[lat_col].between(c_lat - lat_margin, c_lat + lat_margin)
        & df[lng_col].between(c_lng - lng_margin, c_lng + lng_margin)
    ].copy()

    if box.empty:
        return box.assign(distance_km=[])

    # ② 정확한 거리 계산
    box["distance_km"] = haversine(c_lat, c_lng, box[lat_col], box[lng_col])

    return (box[box["distance_km"] <= radius_km]
            .sort_values("distance_km")
            .reset_index(drop=True))

### Step 3. 지오코딩 파이프라인 (오늘의 종합 예제)

```python
"""주소 100건을 좌표로 — 캐시·재시도·검증 포함."""

import json
import logging
import os
import re
import time
from pathlib import Path

import numpy as np
import pandas as pd
import requests
from dotenv import load_dotenv

load_dotenv()

KAKAO_KEY = os.getenv("KAKAO_REST_KEY")

ADDR_URL = "https://dapi.kakao.com/v2/local/search/address.json"
KEYWORD_URL = "https://dapi.kakao.com/v2/local/search/keyword.json"

CACHE_PATH = Path("data/cache/geocode.json")
CACHE_PATH.parent.mkdir(parents=True, exist_ok=True)

DELAY = 0.12                    # 초당 8회 정도
TIMEOUT = 10
RETRIES = 2

logging.basicConfig(level=logging.INFO, format="%(message)s")
log = logging.getLogger("geocode")


# ══════════ 주소 정제 ══════════

def clean_address(addr):
    """지오코딩 성공률을 높이는 주소 정제."""
    if not addr or pd.isna(addr):
        return ""

    s = str(addr).strip()
    s = re.sub(r"\([^)]*\)", " ", s)                 # 괄호
    s = re.sub(r"\s*[\dB]+\s*층.*$", "", s)          # 층
    s = re.sub(r"\s*\d+\s*호(?:\s|$).*$", "", s)     # 호
    s = re.sub(r"\b\d{5}\b", " ", s)                 # 우편번호
    s = re.sub(r"\s+", " ", s).strip()

    return s


def address_variants(addr):
    """실패 시 시도할 주소 변형들을 생성합니다."""
    base = clean_address(addr)
    if not base:
        return []

    variants = [base]

    tokens = base.split()

    # 뒤에서부터 한 토막씩 줄이기
    for cut in range(1, min(3, len(tokens))):
        shorter = " ".join(tokens[:-cut])
        if len(shorter.split()) >= 2:
            variants.append(shorter)

    # 시도+시군구만
    if len(tokens) >= 2:
        variants.append(" ".join(tokens[:2]))

    seen = set()
    return [v for v in variants if not (v in seen or seen.add(v))]


# ══════════ 캐시 ══════════

def load_cache():
    if CACHE_PATH.exists():
        try:
            return json.loads(CACHE_PATH.read_text(encoding="utf-8"))
        except json.JSONDecodeError:
            log.warning("캐시 손상 — 새로 시작")
    return {}


def save_cache(cache):
    tmp = CACHE_PATH.with_suffix(".tmp")
    tmp.write_text(json.dumps(cache, ensure_ascii=False, indent=1),
                   encoding="utf-8")
    tmp.replace(CACHE_PATH)


# ══════════ 호출 ══════════

_session = requests.Session()
_last_call = [0.0]


def _call(url, query):
    """API 를 호출합니다. 실패하면 None."""
    if not KAKAO_KEY:
        raise SystemExit("KAKAO_REST_KEY 가 없습니다 (.env 확인)")

    for attempt in range(RETRIES + 1):
        gap = time.perf_counter() - _last_call[0]
        if gap < DELAY:
            time.sleep(DELAY - gap)
        _last_call[0] = time.perf_counter()

        try:
            res = _session.get(url, params={"query": query, "size": 1},
                               headers={"Authorization": f"KakaoAK {KAKAO_KEY}"},
                               timeout=TIMEOUT)
        except requests.RequestException as e:
            log.warning(f"  {type(e).__name__} — 재시도 {attempt+1}")
            time.sleep(2 ** attempt)
            continue

        if res.status_code in (401, 403):
            raise SystemExit(f"인증 실패 (HTTP {res.status_code}) — 키 확인")

        if res.status_code == 429:
            raise SystemExit("일일 한도 초과 — 중단")

        if not res.ok:
            time.sleep(2 ** attempt)
            continue

        return res.json()

    return None


def geocode_one(addr, use_keyword=True):
    """
    주소 하나를 좌표로 변환합니다.

    반환: dict(lat, lng, matched, method, sido) 또는 None
    """
    for i, variant in enumerate(address_variants(addr)):
        data = _call(ADDR_URL, variant)

        if data and data.get("documents"):
            d = data["documents"][0]
            addr_info = d.get("address") or d.get("road_address") or {}

            return {
                "lat": float(d["y"]),                  # ⚠ y=위도
                "lng": float(d["x"]),                  # ⚠ x=경도
                "matched": d.get("address_name", variant),
                "method": "address" if i == 0 else f"address(축약{i})",
                "sido": addr_info.get("region_1depth_name", ""),
                "sigungu": addr_info.get("region_2depth_name", ""),
            }

    # ── 주소로 안 되면 키워드 검색 ──
    if use_keyword:
        base = clean_address(addr)
        data = _call(KEYWORD_URL, base)

        if data and data.get("documents"):
            d = data["documents"][0]
            return {
                "lat": float(d["y"]),
                "lng": float(d["x"]),
                "matched": d.get("place_name", "") + " / " +
                           d.get("address_name", ""),
                "method": "keyword",
                "sido": d.get("address_name", "").split()[0]
                        if d.get("address_name") else "",
                "sigungu": "",
            }

    return None


def geocode_dataframe(df, addr_col="address", sido_col=None, verbose=True):
    """
    DataFrame 의 주소 열을 좌표로 변환합니다.

    반환: (좌표가 추가된 df, 실패 df)
    """
    cache = load_cache()
    results, failures = [], []

    total = len(df)
    cache_hits = 0

    if verbose:
        log.info(f"지오코딩 시작 — {total}건 (캐시 {len(cache)}건 보유)")

    for i, row in df.iterrows():
        addr = row[addr_col]
        key = clean_address(addr)

        if not key:
            failures.append({"index": i, "address": addr, "reason": "빈 주소"})
            results.append({})
            continue

        # ── 캐시 ──
        if key in cache:
            cache_hits += 1
            results.append(cache[key] or {})
            if cache[key] is None:
                failures.append({"index": i, "address": addr,
                                 "reason": "캐시된 실패"})
            continue

        # ── 호출 ──
        try:
            result = geocode_one(addr)
        except SystemExit:
            raise
        except Exception as e:
            result = None
            log.warning(f"  [{i}] {type(e).__name__}: {e}")

        cache[key] = result
        results.append(result or {})

        if result is None:
            failures.append({"index": i, "address": addr,
                             "reason": "변환 실패"})

        if (i + 1) % 25 == 0:
            save_cache(cache)
            done = i + 1
            ok = done - len(failures)
            if verbose:
                log.info(f"  {done}/{total} — 성공 {ok} · "
                         f"실패 {len(failures)} · 캐시 {cache_hits}")

    save_cache(cache)

    geo = pd.DataFrame(results, index=df.index)
    out = df.copy()

    for col in ("lat", "lng", "matched", "method", "sido", "sigungu"):
        out[f"geo_{col}" if col in ("sido", "sigungu") else col] = geo.get(col)

    out["lat"] = pd.to_numeric(out["lat"], errors="coerce")
    out["lng"] = pd.to_numeric(out["lng"], errors="coerce")

    # ── 검증 ──
    out["coord_valid"] = (out["lat"].between(33, 39)
                          & out["lng"].between(124, 132))

    if sido_col and sido_col in out.columns:
        norm = lambda s: (s.astype(str).str.replace(
            r"(특별시|광역시|특별자치시|특별자치도|도)$", "", regex=True).str[:2])
        out["sido_match"] = norm(out[sido_col]) == norm(out["geo_sido"])
    else:
        out["sido_match"] = True

    if verbose:
        ok = out["lat"].notna().sum()
        log.info(f"\n지오코딩 완료 — 성공 {ok}/{total} "

```python
"""지오코딩 결과 품질 평가."""

import re

import numpy as np
import pandas as pd


def grade_geocoding(df, addr_col="address", sido_col=None,
                    lat_col="lat", lng_col="lng",
                    matched_col="matched", method_col="method",
                    verbose=True):
    """
    지오코딩 결과를 A~F 등급으로 평가합니다.

    A: 도로명 완전 매칭   B: 축약 매칭   C: 키워드 매칭
    D: 시도만 일치        F: 실패 또는 오매칭
    """
    out = df.copy()
    n = len(out)

    def norm_sido(s):
        return (pd.Series(s).astype(str)
                .str.replace(r"(특별시|광역시|특별자치시|특별자치도|도)$",
                             "", regex=True)
                .str[:2])

    # ── 기본 판정 ──
    has_coord = out[lat_col].notna() & out[lng_col].notna()
    in_korea = out[lat_col].between(33, 39) & out[lng_col].between(124, 132)

    method = out.get(method_col, pd.Series("", index=out.index)).fillna("")

    sido_ok = pd.Series(True, index=out.index)
    if sido_col and sido_col in out.columns and "geo_sido" in out.columns:
        sido_ok = norm_sido(out[sido_col]) == norm_sido(out["geo_sido"])

    # ── 주소 유사도 (매칭된 주소가 원본과 얼마나 겹치는가) ──
    def token_overlap(a, b):
        if pd.isna(a) or pd.isna(b):
            return 0.0
        ta = set(re.findall(r"[가-힣0-9]+", str(a)))
        tb = set(re.findall(r"[가-힣0-9]+", str(b)))
        if not ta or not tb:
            return 0.0
        return len(ta & tb) / len(ta)

    if matched_col in out.columns:
        out["_overlap"] = [token_overlap(a, m) for a, m
                           in zip(out[addr_col], out[matched_col])]
    else:
        out["_overlap"] = np.nan

    # ── 등급 ──
    grade = pd.Series("F", index=out.index)

    grade[has_coord & in_korea & sido_ok
          & method.str.startswith("address")
          & (out["_overlap"] >= 0.6)] = "A"

    grade[(grade == "F") & has_coord & in_korea & sido_ok
          & method.str.startswith("address")] = "B"

    grade[(grade == "F") & has_coord & in_korea & sido_ok
          & method.str.contains("keyword")] = "C"

    grade[(grade == "F") & has_coord & in_korea] = "D"

    out["geo_grade"] = pd.Categorical(grade, ["A", "B", "C", "D", "F"],
                                      ordered=True)

```python
"""좌표 기반 공간 분석 도구."""

import numpy as np
import pandas as pd

EARTH_R = 6371.0088


def haversine(lat1, lng1, lat2, lng2):
    lat1, lng1, lat2, lng2 = map(np.radians, (lat1, lng1, lat2, lng2))
    dlat, dlng = lat2 - lat1, lng2 - lng1
    a = (np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlng/2)**2)
    return 2 * EARTH_R * np.arcsin(np.sqrt(np.clip(a, 0, 1)))


class SpatialIndex:
    """
    좌표 데이터의 공간 질의를 지원합니다.

    - within(center, km)        반경 검색
    - nearest(point, k)         최근접 k개
    - density(km)               각 지점의 주변 밀도
    - pairs_within(km)          가까운 쌍 찾기
    """

    def __init__(self, df, lat_col="lat", lng_col="lng", name_col=None):
        valid = df[lat_col].between(33, 39) & df[lng_col].between(124, 132)

        self.df = df[valid].reset_index(drop=True).copy()
        self.dropped = (~valid).sum()
        self.lat_col, self.lng_col = lat_col, lng_col
        self.name_col = name_col or df.columns[0]

        self.lat = self.df[lat_col].to_numpy()
        self.lng = self.df[lng_col].to_numpy()

        if self.dropped:
            print(f"⚠ 좌표가 유효하지 않은 {self.dropped}건 제외")

    # ══════════ 반경 검색 ══════════
    def within(self, center, radius_km, sort=True):
        """중심점 반경 안의 행."""
        c_lat, c_lng = center

        lat_m = radius_km / 111.0
        lng_m = radius_km / (111.0 * np.cos(np.radians(c_lat)))

        box = ((np.abs(self.lat - c_lat) <= lat_m)
               & (np.abs(self.lng - c_lng) <= lng_m))

        if not box.any():
            return self.df.iloc[[]].assign(distance_km=pd.Series(dtype=float))

        idx = np.where(box)[0]
        dist = haversine(c_lat, c_lng, self.lat[idx], self.lng[idx])

        keep = idx[dist <= radius_km]
        result = self.df.iloc[keep].copy()
        result["distance_km"] = dist[dist <= radius_km].round(3)

        return result.sort_values("distance_km") if sort else result

    # ══════════ 최근접 k개 ══════════
    def nearest(self, point, k=5, exclude_self=False):
        """가장 가까운 k개."""
        lat, lng = point
        dist = haversine(lat, lng, self.lat, self.lng)

        if exclude_self:
            dist = np.where(dist < 1e-6, np.inf, dist)

        idx = np.argsort(dist)[:k]

        result = self.df.iloc[idx].copy()
        result["distance_km"] = dist[idx].round(3)
        return result

    # ══════════ 밀도 ══════════
    def density(self, radius_km=5.0):
        """각 지점 반경 안의 다른 지점 개수."""
        n = len(self.df)
        counts = np.zeros(n, dtype=int)

        lat_m = radius_km / 111.0

        for i in range(n):
            lng_m = radius_km / (111.0 * np.cos(np.radians(self.lat[i])))
            box = ((np.abs(self.lat - self.lat[i]) <= lat_m)
                   & (np.abs(self.lng - self.lng[i]) <= lng_m))
            idx = np.where(box)[0]

            if len(idx) <= 1:
                continue

            d = haversine(self.lat[i], self.lng[i], self.lat[idx], self.lng[idx])
            counts[i] = int(((d <= radius_km) & (d > 1e-6)).sum())

        out = self.df.copy()
        out[f"neighbors_{radius_km:g}km"] = counts
        return out

    # ══════════ 가까운 쌍 ══════════
    def pairs_within(self, km=1.0, max_pairs=50):
        """서로 km 이내인 쌍 (중복 후보 탐지에 유용)."""
        pairs = []
        n = len(self.df)
        lat_m = km / 111.0

        for i in range(n):
            lng_m = km / (111.0 * np.cos(np.radians(self.lat[i])))
            cand = np.where(
                (np.arange(n) > i)
                & (np.abs(self.lat - self.lat[i]) <= lat_m)
                & (np.abs(self.lng - self.lng[i]) <= lng_m))[0]

            if len(cand) == 0:
                continue

            d = haversine(self.lat[i], self.lng[i],
                          self.lat[cand], self.lng[cand])

            for j, dist in zip(cand[d <= km], d[d <= km]):
                pairs.append({
                    "A": self.df.iloc[i][self.name_col],
                    "B": self.df.iloc[j][self.name_col],
                    "distance_km": round(float(dist), 3),
                })

            if len(pairs) >= max_pairs:
                break

        return (pd.DataFrame(pairs).sort_values("distance_km")
                .reset_index(drop=True) if pairs else pd.DataFrame())

    # ══════════ 요약 ══════════
    def report(self, radius_km=5.0):
        print("=" * 78)
        print("                      공간 분석 리포트")
        print("=" * 78)

        n = len(self.df)
        print(f"\n[대상] {n:,}개 지점 (제외 {self.dropped}건)")

        print(f"\n[좌표 범위]")
        print(f"  위도 : {self.lat.min():.4f} ~ {self.lat.max():.4f}  "
              f"({(self.lat.max()-self.lat.min())*111:.0f}km)")
        print(f"  경도 : {self.lng.min():.4f} ~ {self.lng.max():.4f}  "
              f"({(self.lng.max()-self.lng.min())*111*np.cos(np.radians(self.lat.mean())):.0f}km)")

        center = (self.lat.mean(), self.lng.mean())
        print(f"  중심 : ({center[0]:.4f}, {center[1]:.4f})")

        # ── 밀도 ──
        dense = self.density(radius_km)
        col = f"neighbors_{radius_km:g}km"

        print(f"\n[밀도 — 반경 {radius_km}km 내 이웃 수]")
        print(f"  평균   : {dense[col].mean():.1f}개")
        print(f"  중앙값 : {dense[col].median():.0f}개")
        print(f"  최대   : {dense[col].max()}개")
        print(f"  고립(이웃 0) : {(dense[col] == 0).sum()}개 "
              f"({(dense[col] == 0).mean()*100:.1f}%)")

        print(f"\n  [밀집 상위 5]")
        top = dense.nlargest(5, col)
        for _, r in top.iterrows():
            print(f"    {str(r[self.name_col])[:20]:<22}{r[col]:>4}개 "
                  f"({r[self.lat_col]:.3f}, {r[self.lng_col]:.3f})")

        # ── 밀도 분포 ──
        print(f"\n  [밀도 분포]")
        bins = [0, 1, 3, 6, 11, 21, np.inf]
        labels = ["0(고립)", "1-2", "3-5", "6-10", "11-20", "21+"]
        binned = pd.cut(dense[col], bins=bins, labels=labels, right=False)
        counts = binned.value_counts().reindex(labels)

        top_c = counts.max()
        for label, cnt in counts.items():
            bar = "■" * int(cnt / top_c * 24) if top_c else ""
            print(f"    {label:<10}{cnt:>5}  {bar}")

        # ── 가까운 쌍 ──
        pairs = self.pairs_within(0.5)

        print(f"\n[500m 이내 쌍]  {len(pairs)}건")
        if len(pairs):
            print(f"  ⚠ 중복 데이터일 가능성 — 확인 권장")
            print(pairs.head(5).to_string(index=False))

        print("\n" + "=" * 78)
        return dense

**공간 분석 4가지 기능**

| 기능 | 용도 |
|---|---|
| `within()` | **"반경 5km 안"** 필터 — 추천 시스템의 핵심 |
| `nearest()` | 최근접 k개 — "가장 가까운 관광지" |
| `density()` | 밀집도 — **관광 클러스터 발견** ⭐ |
| `pairs_within()` | **중복 데이터 탐지** ⭐ |

> **`pairs_within()` 의 활용이 의외로 중요합니다.**
>
> 500m 이내에 두 개가 있다면 **같은 곳이 두 번 등록**됐을 수 있습니다.
> ```
> "경복궁"      (37.5760, 126.9769)
> "경복궁 근정전" (37.5765, 126.9772)     ← 55m 차이
> ```
> [Day 057](day-057.md)의 중복 제거를 **이름이 아니라 좌표로** 하는 것입니다.
>
> **`density()` 도 발견을 만들어 냅니다.**
> 위 결과에서 **32%가 반경 10km 안에 이웃이 없습니다.**
> 관광지가 몇몇 지역에 몰려 있고 나머지는 흩어져 있다는 뜻입니다.
> 이건 [Day 068](day-068.md)의 **클러스터 지도**로 시각화하면 확실히 보입니다.
>
> **성능 참고** — `density()` 는 O(n²)에 가깝습니다.
> 1만 건이 넘으면 `scipy.spatial.cKDTree` 나 `sklearn.neighbors.BallTree`
> (`metric="haversine"`)를 쓰세요.

| **카카오** | **`y`=위도, `x`=경도** |
| 좌표계 | WGS84(EPSG:4326) · 값이 크면 **국내 좌표계** |
| 1도 | 위도 111km · 경도 **111×cos(위도)** km |
| **거리** | **하버사인** (유클리드는 최대 33% 오차) |
| 반경 필터 | 사각형 사전 필터 → 하버사인 |
| 지오코딩 | 카카오 로컬 (일 10만회) |
| 주소 정제 | 괄호·층·호·우편번호 제거 |
| 폴백 | 축약 재시도 → **키워드 검색** |
| **캐시** | 성공·**실패 모두** 저장 |
| **검증** | 범위 · 순서 뒤바뀜 · (0,0) · **시도 대조** |

**오늘 반드시 기억할 세 가지**
> ① **카카오는 `y`가 위도, `x`가 경도입니다.** 반대로 쓰면 에러 없이 모든 좌표가 뒤바뀝니다.
> ② **유클리드 거리를 쓰지 마세요.** 서울↔강릉이 165km인데 220km로 나옵니다.
> ③ **지오코딩 결과를 검증하세요.** API는 틀린 좌표도 자신 있게 반환합니다.

**과제**
① 카카오 개발자 가입 + REST API 키 발급 → `.env` 에 저장
② 프로젝트 데이터의 **주소 100건 이상을 좌표로 변환** (캐시 포함)
③ **실패 건 로그**를 CSV 로 남기고, 실패 원인 유형별로 정리
④ 좌표 **검증 결과**(범위·순서·시도 일치)를 표로 제출
⑤ 특정 지점 **반경 5km 이내** 필터링 결과 + 하버사인/유클리드 오차 비교
