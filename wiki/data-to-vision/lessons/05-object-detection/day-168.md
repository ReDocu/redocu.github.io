## ③ 개념 설명

### 라즈베리파이 5 는 어떤 기계인가

우리가 [Day 166](day-166.md)에서 세팅한 기계의 정체를 먼저 확인합니다.

```bash
pi@cctv-01:~ $ cat /proc/device-tree/model
Raspberry Pi 5 Model B Rev 1.0

pi@cctv-01:~ $ uname -m
aarch64

pi@cctv-01:~ $ lscpu
Architecture:            aarch64
CPU(s):                  4
Vendor ID:               ARM
  Model name:            Cortex-A76
    Thread(s) per core:  1
    CPU max MHz:         2400.0000
    CPU min MHz:         1500.0000
    Flags:               fp asimd evtstrm aes pmull sha1 sha2 crc32
                         atomics fphp asimdhp cpuid asimdrdm lrcpc
                         dcpop asimddp
Caches (sum of all):
  L1d: 256 KiB (4)   L2: 2 MiB (4)   L3: 2 MiB (1)
```

**★ `Flags` 를 읽는 법**

| 플래그 | 의미 | 우리에게 왜 중요한가 |
|---|---|---|
| `asimd` | **NEON** (128비트 SIMD) | 추론 속도의 핵심. 없으면 NCNN 이 무의미 |
| `asimdhp` | NEON 반정밀도(FP16) | NCNN FP16 모델이 빨라지는 이유 |
| `asimddp` | **DotProduct** 명령 | INT8 양자화 가속에 필요 |
| `aes` `sha2` | 암호 가속 | HTTPS 전송(Day 169)에서 유용 |
| (없음) `sve` | Scalable Vector Ext. | **Pi 5 에는 없습니다.** 서버 ARM 에만 |

```
확인 순서
  ① uname -m 이 aarch64 인가            → 64비트인가
  ② Flags 에 asimd 가 있는가            → NEON 이 있는가
  ③ Flags 에 asimddp 가 있는가          → INT8 가속이 되는가

  Pi 4 는 ① aarch64(64비트 OS일 때) ② asimd ✓ ③ asimddp ✗
  Pi 5 는 ① ② ③ 전부 ✓
```

### ★ "20배 느리다"는 어디서 오는가

먼저 그 "20배"라는 말 자체를 의심해야 합니다.

```
무엇과 무엇을 비교하느냐에 따라 3.6배도 되고 52배도 됩니다

  RTX 3060 GPU      vs  Pi 5 (NCNN)     →  52배
  노트북 CPU PyTorch vs  Pi 5 PyTorch    →  6.4배
  노트북 CPU NCNN    vs  Pi 5 NCNN       →  3.6배

  "20배"는 이 사이 어딘가의 뭉뚱그린 숫자입니다
  ★ 조건 없는 배율은 Day 153 의 "조건 없는 FPS"와 같은 잘못입니다
```

**항목별 사양 비교**

| 항목 | 노트북 (i7-11800H) | 라즈베리파이 5 | 배율 |
|---|---|---|---|
| 아키텍처 | x86-64 (Tiger Lake) | ARMv8.2-A (Cortex-A76) | — |
| 코어 / 스레드 | 8C / 16T | **4C / 4T** | 2.0× |
| 기본 클럭 | 2.3 GHz | 2.4 GHz | 0.96× |
| 지속 부하 클럭 | ~3.6 GHz | **2.4 GHz** | 1.5× |
| **벡터 명령 폭** | **AVX2 256비트** | **NEON 128비트** | 2.0× |
| L1d / L2 / L3 | 384KB / 10MB / 24MB | 256KB / 2MB / **2MB** | 3~12× |
| 메모리 | DDR4-3200 듀얼 **51.2 GB/s** | LPDDR4X 32비트 **~17 GB/s** | 3.0× |
| 메모리 실측 대역폭 | ~34 GB/s | ~9.6 GB/s | 3.5× |
| GPU 가속 | RTX 3060 (CUDA) | **VideoCore VII — 추론용 아님** | ∞ |
| 열 설계 전력 | 45 W (+GPU 80W) | **피크 12 W** | 3.8× |
| 스토리지 | NVMe SSD 3,500 MB/s | microSD (A2) ~90 MB/s | 39× |

**★ PyTorch 640 이 6.4배 느린 이유의 분해**

```
노트북 68.4 ms  →  파이 441.3 ms   (6.45배)

  ① 코어 수         8 물리코어 → 4        ×1.8
                     (하이퍼스레딩은 추론에 거의 도움 안 됨)
  ② 지속 클럭       3.6 GHz → 2.4 GHz     ×1.5
  ③ 벡터 폭        AVX2 256b → NEON 128b ×1.9  (IPC 차이 포함)
  ④ 메모리 대역폭   34 → 9.6 GB/s          ×1.25 (합성곱은 대역폭에 민감)
  ─────────────────────────────────────────
     1.8 × 1.5 × 1.9 × 1.25 = ★ 6.41배      ✓ 실측 6.45배
```

**그런데 NCNN 은 3.6배밖에 안 느립니다**

```
노트북 38.4 ms  →  파이 138.2 ms   (3.60배)

  같은 하드웨어 차이인데 왜 배율이 다른가?
  ★ 소프트웨어 최적화의 방향이 다르기 때문입니다

  PyTorch   x86 에서 oneDNN/MKL 로 극도로 최적화됨
            ARM 에서는 일반적인 커널 사용 → x86 쪽이 유리한 비교

  NCNN      ARM NEON 을 손으로 최적화한 엔진
            x86 에서는 SSE/AVX 를 부분적으로만 사용 → ARM 쪽 손해가 적음

  결론: "하드웨어가 N배 느리다"는 문장은 성립하지 않습니다
        "이 소프트웨어에서 N배 느리다"만 성립합니다
```

> ⚠️ **[Day 153](day-153.md)의 오류가 여기서 시작됩니다.**
> `PI_FACTOR` 를 형식별로 3.4 / 3.9 / 4.2 로 나눈 것까지는 옳았습니다.
> 그런데 그 값들이 **전부 문헌에서 가져온 추측**이었고,
> **PyTorch 만 실제로는 6.4 였습니다.** 뒤에서 오차를 정량화합니다.

### ★ 아키텍처 확인 — 32비트 OS 를 깔았을 때 벌어지는 일

**모든 문제의 90%가 여기서 시작합니다.**

```bash
# ★ 파이에 접속하면 제일 먼저 이것부터
pi@cctv-01:~ $ uname -m
aarch64                # ✓ 64비트

pi@cctv-02:~ $ uname -m
armv7l                 # 32비트 — 오늘 하루가 날아갑니다
```

| | `aarch64` (64비트) | `armv7l` (32비트) |
|---|---|---|
| Raspberry Pi Imager 표기 | Raspberry Pi OS (64-bit) | Raspberry Pi OS (**Legacy**, 32-bit) |
| `torch` wheel | ✓ PyPI 에 있음 | **없음 → 소스 빌드** |
| `ncnn` wheel | ✓ PyPI 에 있음 | **없음 → 소스 빌드** |
| `onnxruntime` wheel | ✓ PyPI 에 있음 | **없음** |
| `tflite-runtime` | ✓ | 구버전만 |
| `opencv-python` | ✓ (piwheels) | ✓ (piwheels) |
| 프로세스 메모리 한도 | 사실상 무제한 | **3 GB** |
| NEON FP16 명령 | ✓ | 부분적 |
| 성능 (같은 하드웨어) | 기준 | **10~20% 느림** |

```
왜 아직도 32비트를 까는 사람이 있는가
  · Imager 의 "Raspberry Pi OS (Legacy)" 를 무심코 선택
  · 오래된 블로그를 따라함 (2021년까지는 32비트가 기본이었음)
  · Pi Zero / Pi 1 / Pi 2 용 이미지를 재사용

확인 없이 진행하면 pip install ncnn 에서
"Building wheel for ncnn (pyproject.toml) ..." 가 뜨고
★ 40분 뒤 cmake 오류로 실패합니다
```

**32비트를 깔았다면 — 되돌리는 방법은 재설치뿐입니다.**
`apt` 로 64비트 "업그레이드"는 불가능하고, 커널만 64비트로 바꾸는 편법(`arm_64bit=1`)은
유저스페이스가 32비트라 파이썬 패키지 문제가 그대로 남습니다.
**→ SD 카드를 다시 굽습니다 (Day 166 절차, 약 12분).**

### ★ 패키지 설치의 함정 — pip 가 소스 빌드로 넘어가는 순간

```
pip install 은 두 가지 방식으로 동작합니다

  ① wheel (.whl)    미리 빌드된 이진 파일. 압축 풀면 끝. 수십 초
  ② sdist (.tar.gz) 소스 코드. 내 기계에서 컴파일. 수십 분~수 시간

  ★ pip 는 wheel 이 없으면 아무 경고 없이 ②로 넘어갑니다
```

**소스 빌드로 넘어갔음을 알아채는 신호**

```
✓ wheel 을 받는 정상 출력
  Downloading ncnn-1.0.20240410-cp311-cp311-manylinux_2_17_aarch64.whl (8.4 MB)
                                    └─ 파이썬 버전 ─┘ └── 아키텍처 ──┘

✗ 소스 빌드로 넘어간 출력
  Downloading ncnn-1.0.20240410.tar.gz (2.1 MB)      ← ★ .tar.gz
  Installing build dependencies ... done              ← 이 줄
  Getting requirements to build wheel ... done
  Building wheel for ncnn (pyproject.toml) ...        ← 여기서 멈춘 듯 보임
                                             |        ← 커서가 40분간 회전
```

> ⚠️ **`Building wheel for ... ` 이 30초 이상 지속되면 Ctrl+C 를 누르세요.**
> 그대로 두면 몇 시간이 지나갑니다. **원인부터 확인하는 것이 빠릅니다.**

**소스 빌드가 시작되는 세 가지 원인**

```
① 아키텍처에 wheel 이 없다
     armv7l · 또는 아주 새로운 패키지

② ★ 파이썬 버전이 안 맞는다
     wheel 이름의 cp311 은 Python 3.11 전용입니다
     pyenv 로 3.12 를 깔았다면 → cp312 wheel 이 없으면 소스 빌드

③ 빌드 격리 환경에서 의존성이 꼬였다
     pip install --no-build-isolation 로 우회 가능한 경우가 있음
```

### piwheels — 라즈베리파이 전용 패키지 저장소

```
piwheels.org
```

### ★ 변환 모델이 왜 빠른가

[Day 153](day-153.md)에서 "NCNN 은 ARM 최적화라 빠릅니다"라고만 하고 넘어갔습니다.
**오늘 그 안을 열어봅니다.**

```
같은 가중치, 같은 연산인데 2~3배 빨라지는 이유는 셋입니다

  ① 연산자 융합 (operator fusion)
  ② 메모리 레이아웃 재배치
  ③ 아키텍처 전용 커널 (ARM NEON)
```

**① 연산자 융합**

```
학습 그래프 (PyTorch)
  Conv → BatchNorm → SiLU        ← 3개의 독립 연산
    │       │          │
   메모리   메모리     메모리      ← ★ 중간 결과를 3번 쓰고 3번 읽음

변환 후 (NCNN)
  ConvBNSiLU  →  메모리          ← 1개의 융합 연산 · 메모리 1번
```

**② 메모리 레이아웃**

```
PyTorch 기본   NCHW  (배치, 채널, 높이, 너비)
NCNN 내부      채널을 4개(FP32) 또는 8개(FP16) 단위로 묶어 정렬

  왜?  NEON 레지스터가 128비트 = FP32 4개 = FP16 8개
       ★ 채널을 그 단위로 놓아야 한 명령으로 처리됨

  레이아웃이 안 맞으면 매번 재배치(permute) → 그것만으로 20~30% 손해
```

**③ ARM NEON 전용 커널**

```
합성곱 3×3 을 계산하는 방법

  일반 구현        for 루프 9번 × 채널 수
  im2col + GEMM    행렬곱으로 변환 (BLAS 호출)
  Winograd F(2,2)  곱셈 횟수를 9 → 4 로 줄임
  NEON 직접 작성   어셈블리 수준에서 파이프라인 최적화

NCNN 은 커널 크기 · 채널 수 · stride 조합마다
★ 손으로 작성한 NEON 어셈블리를 갖고 있습니다
```

| 최적화 | 640 추론(ms) | 누적 효과 |
|---|---|---|
| PyTorch 원본 (ARM 일반 커널) | 441.3 | 기준 |
| → ONNX Runtime (융합 + 레이아웃) | 186.4 | 2.37× |
| → TFLite + XNNPACK (NEON 커널) | 212.7 | 2.07× |
| → **NCNN FP16 (전용 커널 + FP16)** | **138.2** | **3.19×** |

### NCNN · ONNX Runtime · TFLite — 무엇이 다른가

| | **NCNN** | **ONNX Runtime** | **TFLite** |
|---|---|---|---|
| 만든 곳 | Tencent | Microsoft | Google |
| 주 대상 | 모바일 · 임베디드 | 서버 · 데스크톱 · 엣지 | Android · MCU |
| 파일 | `.param` + `.bin` | `.onnx` (단일) | `.tflite` (단일) |
| 파이 wheel 크기 | **8.4 MB** | 41 MB | **3.1 MB** (`tflite-runtime`) |
| 의존성 | 없음 | protobuf 등 | 없음 |
| ARM NEON | **손 최적화 어셈블리** | 일반 + 일부 최적화 | XNNPACK (NEON) |
| FP16 | 기본 지원 | 제한적 (CPU) | 지원 |
| INT8 | 지원 (수동 설정) | QDQ 방식 | **가장 성숙** |
| 640 실측 (Pi5) | **138.2 ms** | 186.4 ms | 212.7 ms |
| RSS | **262 MB** | 331 MB | 288 MB |
| 로드 시간 | **0.38초** | 0.71초 | 0.44초 |
| 후처리 | **직접 작성** | 직접 작성 | 직접 작성 |
| 디버깅 난이도 | 높음 (오류 메시지 빈약) | 낮음 | 중간 |

```
선택 기준

  속도가 최우선 · ARM 전용        → NCNN
  여러 플랫폼에 같은 파일 배포     → ONNX
  INT8 을 제대로 쓰고 싶다        → TFLite
  디버깅 편의 · 팀 숙련도 낮음     → ONNX (오류 메시지가 친절)
```

> ⚠️ **★ OpenVINO 는 여기 없습니다.**
> [Day 153](day-153.md)에서 노트북 최고 성능(28.2 ms)을 낸 형식이지만
> **Intel 전용이라 ARM 에서는 설치조차 안 됩니다.**
> ```
> pi@cctv-01:~ $ pip install openvino
> ERROR: No matching distribution found for openvino
> ```
> **"노트북에서 제일 빠른 것"과 "파이에서 제일 빠른 것"은 다릅니다.**

**② NCNN — 직접 (경로 B) — 오늘 운영에 쓰는 경로**

```python
import ncnn

net = ncnn.Net()
net.opt.use_vulkan_compute = False      # ★ GPU 안 씀 (더 느림)
net.opt.num_threads = 4                 # 스레드 수
net.opt.use_fp16_packed = True          # FP16 패킹
net.opt.use_fp16_storage = True
net.opt.use_fp16_arithmetic = True      # FP16 연산 (asimdhp 필요)

net.load_param("models/export/best_ncnn_640_fp16/model.ncnn.param")
net.load_model("models/export/best_ncnn_640_fp16/model.ncnn.bin")

ex = net.create_extractor()
ex.input("in0", mat_in)                 # 입력 블롭 이름
ret, mat_out = ex.extract("out0")       # 출력 블롭 이름
```

**③ ONNX Runtime · ④ TFLite — 둘 다 한 줄로 끝납니다**

```python
import onnxruntime as ort
so = ort.SessionOptions()
so.intra_op_num_threads = 4              # 연산 내부 병렬 (파이에서 이것만 의미 있음)
sess = ort.InferenceSession("models/export/best_onnx_640.onnx", sess_options=so,
                            providers=["CPUExecutionProvider"])  # 파이에는 이것뿐
print(sess.get_inputs()[0].shape)        # [1, 3, 640, 640]  NCHW

from tflite_runtime.interpreter import Interpreter   # tensorflow 아님 (3.1 MB)
itp = Interpreter(model_path="models/export/best_float32.tflite", num_threads=4)
itp.allocate_tensors()
print(itp.get_input_details()[0]["shape"])   # [1 640 640 3]  ★ NHWC
```

> ⚠️ **★ TFLite 만 NHWC 입니다.**
> ONNX · NCNN 은 `(1, 3, 640, 640)` — 채널이 앞.
> TFLite 는 `(1, 640, 640, 3)` — 채널이 뒤.
> **`transpose` 를 빼먹으면 오류 없이 쓰레기 결과가 나옵니다.**

### ★ 변환 모델의 전처리 · 후처리 함정

**오늘 가장 많은 시간을 잡아먹는 부분입니다.**

```
ultralytics 로 .pt 를 돌릴 때
  model.predict(img) 한 줄이면
  ★ letterbox · 색순서 · 정규화 · NMS · 좌표 역변환이 전부 자동입니다

변환 모델을 직접 돌리면
  ★ 그 다섯 가지를 내가 똑같이 재현해야 합니다
  ★ 하나라도 틀리면 "동작은 하는데 결과가 이상"합니다
```

### Step 3. `bench.py` — 형식 × 해상도 × 스레드 벤치마크

```python
"""bench.py — 라즈베리파이 온디바이스 벤치마크
사용:
  python bench.py --all
  python bench.py --format ncnn --imgsz 640 --threads 1,2,3,4,5,8
  python bench.py --format ncnn --imgsz 640 --duration 1800   # 발열 테스트
"""
import argparse
import csv
import json
import platform
import re
import subprocess
import time
from datetime import datetime
from pathlib import Path

import cv2
import numpy as np
import psutil

ROOT = Path.home() / "cctv"
EXPORT = ROOT / "models" / "export"
SAMPLE = ROOT / "tests" / "data" / "sample.jpg"
OUT = ROOT / "reports"
OUT.mkdir(parents=True, exist_ok=True)

# ══════════════════════════════════════════════════════════
#  하드웨어 상태 읽기
# ══════════════════════════════════════════════════════════
def vcgencmd(arg: str) -> str:
    try:
        return subprocess.run(["vcgencmd"] + arg.split(),
                              capture_output=True, text=True,
                              timeout=3).stdout.strip()
    except Exception:
        return ""

def read_temp() -> float:
    """SoC 온도 (°C)"""
    out = vcgencmd("measure_temp")            # temp=61.7'C
    m = re.search(r"([\d.]+)", out)
    if m:
        return float(m.group(1))
    # ★ vcgencmd 가 없는 환경 대비
    p = Path("/sys/class/thermal/thermal_zone0/temp")
    return int(p.read_text()) / 1000 if p.exists() else float("nan")

def read_clock_mhz() -> float:
    """현재 ARM 클럭 (MHz)"""
    out = vcgencmd("measure_clock arm")        # frequency(0)=2400000000
    m = re.search(r"=(\d+)", out)
    if m:
        return int(m.group(1)) / 1e6
    p = Path("/sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq")
    return int(p.read_text()) / 1000 if p.exists() else float("nan")

def read_throttled() -> int:
    out = vcgencmd("get_throttled")            # throttled=0x0
    m = re.search(r"0x([0-9a-fA-F]+)", out)
    return int(m.group(1), 16) if m else 0

def parse_throttled(value: int) -> dict:
    return {
        "under_voltage_now":  bool(value & 0x1),
        "freq_capped_now":    bool(value & 0x2),
        "throttled_now":      bool(value & 0x4),
        "soft_temp_now":      bool(value & 0x8),
        "under_voltage_ever": bool(value & 0x10000),
        "freq_capped_ever":   bool(value & 0x20000),
        "throttled_ever":     bool(value & 0x40000),
        "soft_temp_ever":     bool(value & 0x80000),
    }

def throttle_flags(value: int) -> str:
    """사람이 읽는 요약"""
    d = parse_throttled(value)
    now = [k[:-4] for k, v in d.items() if k.endswith("_now") and v]
    return ",".join(now) if now else "정상"

# ══════════════════════════════════════════════════════════
#  전처리 — 모든 형식이 같은 입력을 받도록
# ══════════════════════════════════════════════════════════
def letterbox(img, size, pad_value=114):
    """★ 비율 유지 + 114 패딩. ultralytics 와 동일하게"""
    h, w = img.shape[:2]
    r = min(size / h, size / w)
    nh, nw = int(round(h * r)), int(round(w * r))
    resized = cv2.resize(img, (nw, nh), interpolation=cv2.INTER_LINEAR)
    canvas = np.full((size, size, 3), pad_value, dtype=np.uint8)
    top, left = (size - nh) // 2, (size - nw) // 2
    canvas[top:top + nh, left:left + nw] = resized
    return canvas, r, left, top

def to_nchw(canvas):
    """BGR uint8 (H,W,3) → RGB float32 (1,3,H,W) 0~1"""
    rgb = cv2.cvtColor(canvas, cv2.COLOR_BGR2RGB)
    x = rgb.astype(np.float32) / 255.0
    x = np.transpose(x, (2, 0, 1))[None]
    return np.ascontiguousarray(x)

def to_nhwc(canvas):
    """★ TFLite 용 — 채널이 뒤"""
    rgb = cv2.cvtColor(canvas, cv2.COLOR_BGR2RGB)
    x = rgb.astype(np.float32) / 255.0
    return np.ascontiguousarray(x[None])

# ══════════════════════════════════════════════════════════
#  엔진 래퍼 — 네 형식을 같은 인터페이스로
# ══════════════════════════════════════════════════════════
class EngineNCNN:
    name = "ncnn"

    def __init__(self, imgsz, threads):
        import ncnn
        self.imgsz, self.ncnn = imgsz, ncnn
        self.net = ncnn.Net()
        self.net.opt.use_vulkan_compute = False
        self.net.opt.num_threads = threads
        self.net.opt.use_fp16_packed = True
        self.net.opt.use_fp16_storage = True
        self.net.opt.use_fp16_arithmetic = True
        d = EXPORT / f"best_ncnn_{imgsz}_fp16"
        self.net.load_param(str(d / "model.ncnn.param"))
        self.net.load_model(str(d / "model.ncnn.bin"))

    def infer(self, canvas):
        mat = self.ncnn.Mat.from_pixels(
            canvas, self.ncnn.Mat.PixelType.PIXEL_BGR2RGB,
            self.imgsz, self.imgsz)
        mat.substract_mean_normalize([], [1 / 255.0] * 3)   # 0~1
        ex = self.net.create_extractor()
        ex.input("in0", mat)
        ret, out = ex.extract("out0")
        return np.array(out)

class EngineONNX:
    name = "onnx"

    def __init__(self, imgsz, threads):
        import onnxruntime as ort
        so = ort.SessionOptions()
        so.intra_op_num_threads = threads
        so.inter_op_num_threads = 1
        so.graph_optimization_level = ort.GraphOptimizationLevel.ORT_ENABLE_ALL
        self.sess = ort.InferenceSession(
            str(EXPORT / f"best_onnx_{imgsz}.onnx"),
            sess_options=so, providers=["CPUExecutionProvider"])
        self.iname = self.sess.get_inputs()[0].name

    def infer(self, canvas):
        return self.sess.run(None, {self.iname: to_nchw(canvas)})[0]

class EngineTFLite:
    name = "tflite"

    def __init__(self, imgsz, threads):
        from tflite_runtime.interpreter import Interpreter
        self.itp = Interpreter(
            model_path=str(EXPORT / f"best_{imgsz}_float32.tflite"),
            num_threads=threads)
        self.itp.allocate_tensors()
        self.i = self.itp.get_input_details()[0]
        self.o = self.itp.get_output_details()[0]

    def infer(self, canvas):
        self.itp.set_tensor(self.i["index"], to_nhwc(canvas))   # NHWC
        self.itp.invoke()
        return self.itp.get_tensor(self.o["index"])

class EnginePyTorch:
    name = "pytorch"

    def __init__(self, imgsz, threads):
        import torch
        from ultralytics import YOLO
        torch.set_num_threads(threads)
        self.imgsz = imgsz
        self.m = YOLO(str(EXPORT / "best.pt"), task="detect")

    def infer(self, canvas):
        r = self.m.predict(canvas, imgsz=self.imgsz, device="cpu",
                           verbose=False)[0]
        return r.boxes.data.cpu().numpy()

ENGINES = {"ncnn": EngineNCNN, "onnx": EngineONNX,
           "tflite": EngineTFLite, "pytorch": EnginePyTorch}

# ══════════════════════════════════════════════════════════
#  측정
# ══════════════════════════════════════════════════════════
def measure(fmt, imgsz, threads, warmup=20, runs=100, img=None):
    """★ 워밍업 → 온도 안정 → 측정"""
    img = img if img is not None else cv2.imread(str(SAMPLE))
    canvas, _, _, _ = letterbox(img, imgsz)

    eng = ENGINES[fmt](imgsz, threads)
    proc = psutil.Process()

    # ① 워밍업 (파이는 20회)
    for _ in range(warmup):
        eng.infer(canvas)

    # ② 온도 안정화 — 3초간 계속 돌림
    t_end = time.perf_counter() + 3.0
    while time.perf_counter() < t_end:
        eng.infer(canvas)

    # ③ 측정
    proc.cpu_percent(None)               # 기준점 리셋
    times = []
    t_start = time.perf_counter()
    for _ in range(runs):
        t0 = time.perf_counter()
        eng.infer(canvas)
        times.append(time.perf_counter() - t0)
    wall = time.perf_counter() - t_start

    t = np.array(times) * 1000
    return {
        "형식": fmt, "imgsz": imgsz, "threads": threads,
        "median_ms": round(float(np.median(t)), 1),
        "mean_ms": round(float(t.mean()), 1),
        "std_ms": round(float(t.std()), 1),
        "p95_ms": round(float(np.percentile(t, 95)), 1),
        "max_ms": round(float(t.max()), 1),
        "fps": round(1000 / float(np.median(t)), 2),
        "cpu_pct": round(proc.cpu_percent(None), 0),
        "rss_mb": round(proc.memory_info().rss / 1024**2, 0),
        "temp_c": round(read_temp(), 1),
        "clock_mhz": round(read_clock_mhz(), 0),
        "throttled": hex(read_throttled()),
        "throttle_flags": throttle_flags(read_throttled()),
        "wall_s": round(wall, 1),
    }

def soak(fmt, imgsz, threads, duration=1800, interval=60):
    """★ 발열 테스트 — duration 초 동안 계속 돌리며 interval 마다 기록"""
    img = cv2.imread(str(SAMPLE))
    canvas, _, _, _ = letterbox(img, imgsz)
    eng = ENGINES[fmt](imgsz, threads)
    for _ in range(20):
        eng.infer(canvas)

    rows, t_start, next_log = [], time.perf_counter(), 0.0
    window = []
    while (elapsed := time.perf_counter() - t_start) < duration:
        t0 = time.perf_counter()
        eng.infer(canvas)
        window.append(time.perf_counter() - t0)
        if elapsed >= next_log:
            med = float(np.median(window)) * 1000 if window else float("nan")
            th = read_throttled()
            rows.append({
                "min": round(elapsed / 60, 1),
                "temp_c": round(read_temp(), 1),
                "clock_mhz": round(read_clock_mhz(), 0),
                "median_ms": round(med, 1),
                "fps": round(1000 / med, 2),
                "throttled": hex(th),
                "flags": throttle_flags(th),
            })
            print(f"  {rows[-1]['min']:>5.1f}분  {rows[-1]['temp_c']:>5.1f}°C  "
                  f"{rows[-1]['clock_mhz']:>6.0f}MHz  "
                  f"{rows[-1]['fps']:>5.2f} FPS  {rows[-1]['flags']}")
            window.clear()
            next_log += interval
    return rows

def save(rows, name):
    if not rows:
        return
    p = OUT / f"{name}_{datetime.now():%Y%m%d_%H%M}.csv"
    with p.open("w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=list(rows[0].keys()))
        w.writeheader()
        w.writerows(rows)
    print(f"\n  저장: {p}")

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--all", action="store_true")
    ap.add_argument("--format", default="ncnn")
    ap.add_argument("--imgsz", default="640")
    ap.add_argument("--threads", default="4")
    ap.add_argument("--runs", type=int, default=100)
    ap.add_argument("--duration", type=int, default=0)
    ap.add_argument("--interval", type=int, default=60)
    a = ap.parse_args()

    print("=" * 104)
    print(f"라즈베리파이 벤치마크 — {platform.machine()} · "
          f"{psutil.cpu_count()}코어 · 시작 {read_temp():.1f}°C · "
          f"throttled={hex(read_throttled())}")
    print("=" * 104)

    if a.duration:
        rows = soak(a.format, int(a.imgsz), int(a.threads),
                    a.duration, a.interval)
        save(rows, f"soak_{a.format}_{a.imgsz}")
        return

    fmts = list(ENGINES) if a.all else a.format.split(",")
    sizes = [320, 416, 480, 640] if a.all else [int(s) for s in a.imgsz.split(",")]
    thrs = [int(t) for t in a.threads.split(",")]

    rows = []
    hdr = (f"{'형식':<9}{'imgsz':>6}{'thr':>5}{'중앙(ms)':>10}{'p95':>9}"
           f"{'FPS':>8}{'CPU%':>7}{'RSS':>7}{'온도':>7}{'클럭':>8}  상태")
    print(hdr)
    print("-" * 104)
    for f in fmts:
        for s in sizes:
            for t in thrs:
                try:
                    r = measure(f, s, t, runs=a.runs)
                except Exception as e:
                    print(f"{f:<9}{s:>6}{t:>5}   ✗ {type(e).__name__}: {e}")
                    continue
                rows.append(r)
                mark = "★" if r["fps"] >= 3.0 else " "
                print(f"{r['형식']:<9}{r['imgsz']:>6}{r['threads']:>5}"
                      f"{r['median_ms']:>10.1f}{r['p95_ms']:>9.1f}"
                      f"{r['fps']:>7.2f}{mark}{r['cpu_pct']:>7.0f}"
                      f"{r['rss_mb']:>7.0f}{r['temp_c']:>7.1f}"
                      f"{r['clock_mhz']:>8.0f}  {r['throttle_flags']}")
    print("=" * 104)
    save(rows, "bench")

if __name__ == "__main__":
    main()
```

```python
"""verify_match.py — 같은 이미지에서 원본과 변환 모델의 박스가 같은가"""
import json
from pathlib import Path

import cv2
import numpy as np

from bench import ENGINES, letterbox      # ★ Step 3 의 코드 재사용
from nms_util import nms                  # Day 149 의 클래스 무관 NMS 그대로

ROOT = Path.home() / "cctv"
IMAGES = sorted((ROOT / "tests" / "data" / "verify").glob("*.jpg"))[:20]
NC, IMGSZ, CONF, IOU_NMS = 3, 640, 0.25, 0.45
NAMES = ["person", "helmet", "box"]

def decode(raw, r, left, top):
    """★ 원시 출력 → 최종 박스. 형식별 레이아웃 차이를 흡수"""
    arr = np.squeeze(raw)
    if arr.shape[0] == 4 + NC:          # (7, 8400) → (8400, 7)
        arr = arr.T
    xywh, cls = arr[:, :4], arr[:, 4:4 + NC]
    conf = cls.max(1)
    m = conf >= CONF
    xywh, conf, cid = xywh[m], conf[m], cls[m].argmax(1)
    if not len(xywh):
        return np.zeros((0, 6), np.float32)
    xy, wh = xywh[:, :2], xywh[:, 2:]
    boxes = np.concatenate([xy - wh / 2, xy + wh / 2], 1)
    keep = nms(boxes, conf, IOU_NMS)
    boxes, conf, cid = boxes[keep], conf[keep], cid[keep]
    # letterbox 역변환 — 이것을 빼먹으면 박스가 어긋납니다
    boxes[:, [0, 2]] = (boxes[:, [0, 2]] - left) / r
    boxes[:, [1, 3]] = (boxes[:, [1, 3]] - top) / r
    return np.concatenate([boxes, conf[:, None], cid[:, None]], 1)

def iou(a, b):
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    ua = (a[2] - a[0]) * (a[3] - a[1]) + (b[2] - b[0]) * (b[3] - b[1]) - inter
    return inter / (ua + 1e-9)

def match(ref, got):
    """★ 그리디 매칭 — 참조 박스마다 가장 겹치는 것을 찾음"""
    used, ious, cls_bad = set(), [], 0
    for rb in ref:
        best, bi = 0.0, -1
        for j, gb in enumerate(got):
            if j in used:
                continue
            v = iou(rb[:4], gb[:4])
            if v > best:
                best, bi = v, j
        if bi >= 0:
            used.add(bi)
            ious.append(best)
            if int(rb[5]) != int(got[bi][5]):
                cls_bad += 1
        else:
            ious.append(0.0)
    return ious, cls_bad

# ── ① 기준: PyTorch 원본 ──
ref_eng = ENGINES["pytorch"](IMGSZ, 4)
refs = {}
for p in IMAGES:
    img = cv2.imread(str(p))
    canvas, r, left, top = letterbox(img, IMGSZ)
    out = ref_eng.infer(canvas)           # (N,6) x1y1x2y2 conf cls (원본 좌표)
    refs[p.name] = np.asarray(out, np.float32)

# ── ② 비교 대상 ──
rows = []
for fmt in ["onnx", "tflite", "ncnn"]:
    eng = ENGINES[fmt](IMGSZ, 4)
    n_ok, all_iou, all_dconf, n_cls = 0, [], [], 0
    for p in IMAGES:
        img = cv2.imread(str(p))
        canvas, r, left, top = letterbox(img, IMGSZ)
        got = decode(eng.infer(canvas), r, left, top)
        ref = refs[p.name]
        if len(got) == len(ref):
            n_ok += 1
        ious, bad = match(ref, got)
        all_iou += ious
        n_cls += bad
        for k, rb in enumerate(ref):
            if k < len(got):
                all_dconf.append(abs(rb[4] - got[k][4]))
    rows.append({
        "형식": fmt,
        "검출수 일치": f"{n_ok}/{len(IMAGES)}",
        "평균 IoU": round(float(np.mean(all_iou)), 4),
        "최소 IoU": round(float(np.min(all_iou)), 4),
        "평균 Δconf": round(float(np.mean(all_dconf)), 4),
        "클래스 불일치": n_cls,
    })

print("=" * 92)
print(f"변환 모델 결과 일치 검증 — PyTorch 원본 기준 · {len(IMAGES)}장 · conf {CONF}")
print("=" * 92)
print(f"{'형식':<10}{'검출수 일치':<14}{'평균 IoU':>10}{'최소 IoU':>10}"
      f"{'평균 Δconf':>12}{'클래스 불일치':>14}   판정")
print("-" * 92)
for r in rows:
    v = ("✓ 동일" if r["평균 IoU"] >= 0.99 and r["클래스 불일치"] == 0
         else "△ 확인" if r["평균 IoU"] >= 0.95 else "★ 불일치")
    print(f"{r['형식']:<10}{r['검출수 일치']:<14}{r['평균 IoU']:>10.4f}"
          f"{r['최소 IoU']:>10.4f}{r['평균 Δconf']:>12.4f}"
          f"{r['클래스 불일치']:>14}   {v}")
print("=" * 92)
```

### Step 7. 프레임 스킵 / 움직임 게이팅 적용 전후

```python
"""gating.py — 부하 저감 전략 비교 (10분 실측)"""
import time

import cv2

IMGSZ, THREADS, DURATION = 640, 4, 600
GATE_THRESH, GATE_RATIO, MAX_IDLE, HOLD = 25, 0.006, 5.0, 3.0

class MotionGate:
    """★ 프레임 차분 게이트 — 비용 약 2.1 ms"""

    def __init__(self):
        self.prev = None
        self.last_fire = 0.0
        self.last_hit = 0.0

    def open(self, frame) -> tuple:
        now = time.perf_counter()
        small = cv2.resize(frame, (160, 120))                 # ★ 1/32
        gray = cv2.GaussianBlur(cv2.cvtColor(small, cv2.COLOR_BGR2GRAY),
                                (5, 5), 0)
        if self.prev is None:
            self.prev, self.last_fire = gray, now
            return True, "init"
        diff = cv2.absdiff(self.prev, gray)
        self.prev = gray
        _, mask = cv2.threshold(diff, GATE_THRESH, 255, cv2.THRESH_BINARY)
        ratio = float((mask > 0).mean())
        if now - self.last_hit < HOLD:                        # 검출 직후 홀드
            self.last_fire = now
            return True, "hold"
        if ratio > GATE_RATIO:                                # 움직임
            self.last_fire = now
            return True, "motion"
        if now - self.last_fire >= MAX_IDLE:                  # 강제 주기
            self.last_fire = now
            return True, "idle"
        return False, "skip"
```

```python
def to_nchw_slow(canvas):
    rgb = cv2.cvtColor(canvas, cv2.COLOR_BGR2RGB)
    x = rgb.astype(np.float32) / 255.0          # ★ 1.2M 원소 훑기 ①
    x = np.transpose(x, (2, 0, 1))[None]        # 1.2M 원소 훑기 ②

# ✓ 8.1 ms — NCNN 이 NEON 으로 한 번에
def to_ncnn_fast(canvas, imgsz, ncnn):
    mat = ncnn.Mat.from_pixels(canvas, ncnn.Mat.PixelType.PIXEL_BGR2RGB,
                               imgsz, imgsz)     # 색변환 + 레이아웃
    mat.substract_mean_normalize([], [1 / 255.0] * 3)   # 정규화까지 NEON

```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 첫 명령 | **`uname -m`** → `aarch64` 가 아니면 재설치 |
| 32비트 | wheel 없음 → **소스 빌드 4시간 후 실패** |
| 소스 빌드 신호 | **`Building wheel for ...`** → 30초 넘으면 중단 |
| piwheels | Pi OS 에 이미 설정 · **파이썬 버전이 맞아야** |
| opencv | **headless** (62 MB) · apt 판은 `--system-site-packages` |
| 최소 설치 | **`numpy` + `opencv-python-headless` + `ncnn`** = 3분 20초 / 92 MB |
| ultralytics | **1.24 GB · RSS 604 MB · import 4.8초** |
| 형식 순위 (Pi5 640) | **NCNN 138 ms** < ONNX 186 < TFLite 213 < PyTorch 441 |
| 왜 빠른가 | **연산자 융합 · 레이아웃 · NEON 커널** |
| 해상도 | 640 채택 (mAP 0.821) · 480 은 **Recall -0.078** |
| 스레드 | **4가 최적** · 5 이상은 손해 (효율 81.9%) |
| 전처리 함정 | **letterbox + 패딩 114 + BGR→RGB + /255** |
| 결과 대조 | 원본과 **IoU ≥ 0.95** · 안 하면 조용히 틀림 |
| INT8 | 10.33 FPS 이나 **mAP -0.0228 (1.06σ)** → 미채택 |
| FPS 측정 | 워밍업 **20회** + 3초 안정화 + **중앙값 · p95** |
| 스로틀링 | 80°C 소프트 · 85°C 하드 → **-37.1%** |
| `get_throttled` | `0x1` 저전압 · `0x8` 온도 · **`0x50005` = 전원 문제** |
| 밀폐 케이스 | 맨보드보다 나쁨 (**-43.6%**) |
| 전원 | 5V/3A → **1.5 GHz 고정 · -41.9%** (온도는 55°C) |
| 파이프라인 | 순수 추론 138 ms → **실제 183~195 ms** |
| 움직임 게이팅 | 평균 CPU **389 → 62%** · 온도 **61 → 47°C** |
| 스왑 | SD 스왑 발생 시 **138 → 1,840 ms** |
| 최종 | **NCNN 640 · 4스레드 · 5.47 FPS · 여유 82%** |
| 추정 vs 실측 | 숫자는 +2.1%, **근거는 전부 달랐음** |
