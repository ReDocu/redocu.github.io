## 단원 개요

### 이 단원을 마치면

- 지도 학습의 흐름(데이터 분리 → 학습 → 예측 → 평가)을 스스로 설계할 수 있다.

- CNN의 합성곱·풀링이 무엇을 하는지 **손으로 계산할 수 있다.**
- 이미지 데이터셋을 직접 만들고 가공·증강해 **분류 모델을 학습시킬 수 있다.**

## 이 단원에서 자주 나오는 질문

| 질문 | 답 |
|---|---|
| 정확도가 100%가 나왔습니다 | 데이터 누수를 의심하세요. 같은 이미지가 학습셋과 테스트셋에 모두 들어갔거나, 분할 전에 증강했을 가능성이 큽니다. |
| 학습이 전혀 안 됩니다 (loss가 안 줄어듦) | 정규화 누락, 학습률 과다, 출력층 활성화 함수/손실 함수 불일치를 순서대로 확인하세요. |
| `val_accuracy`가 학습 정확도보다 계속 높습니다 | Dropout이 학습 시에만 적용되기 때문에 초반에 나타날 수 있는 정상 현상입니다. 계속되면 검증셋이 너무 쉽거나 작은 것입니다. |
| Colab이 자꾸 끊깁니다 | `ModelCheckpoint`로 매 에폭 드라이브에 저장하고, 재시작 시 이어서 학습하세요. |
| 이미지 색이 이상하게 나옵니다 | OpenCV는 BGR로 읽습니다. `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`가 필요합니다. |
| 전이학습인데 성능이 더 나쁩니다 | 해당 모델 전용 `preprocess_input`을 쓰지 않았거나, 미세조정 학습률이 너무 높아 사전학습 가중치가 망가진 경우입니다. |
