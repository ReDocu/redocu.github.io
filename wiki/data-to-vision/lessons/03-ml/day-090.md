
**그런데 MNIST는 이런 데이터입니다.**

| 특성 | MNIST |
|---|---|

| 배경 | **완전한 검정** |

**실제 사진은 하나도 해당되지 않습니다.**

### CIFAR-10 — 진짜 사진

```
32×32 컬러 사진 6만 장, 10개 클래스
비행기 / 자동차 / 새 / 고양이 / 사슴 / 개 / 개구리 / 말 / 배 / 트럭
```

| 특성 | CIFAR-10 |
|---|---|
| 색상 | **컬러 (3채널)** |
| 배경 | **하늘, 풀밭, 도로 등 다양** |
| 대상 위치 | **제각각** |
| 크기 | **제각각** |
| 각도 | **정면, 측면, 뒤** |
| 클래스 간 차이 | **고양이 vs 개는 사람도 헷갈림** |

**정확도가 어떻게 되는지 봅시다.**

| 데이터 | 같은 CNN 구조로 |
|---|---|
| MNIST | 99.3% |
| **CIFAR-10** | **약 72%** |

**27%p나 떨어집니다.** 이것이 실제 이미지 분류의 난이도입니다.

## ③ 개념 설명

### CIFAR-10 데이터셋

```
학습셋 50,000장 (클래스당 5,000장)
테스트셋 10,000장 (클래스당 1,000장)
크기 32×32×3
```

| 번호 | 클래스 | 번호 | 클래스 |
|---|---|---|---|
| 0 | airplane (비행기) | 5 | dog (개) |
| 1 | automobile (자동차) | 6 | frog (개구리) |
| 2 | bird (새) | 7 | horse (말) |
| 3 | cat (고양이) | 8 | ship (배) |
| 4 | deer (사슴) | 9 | truck (트럭) |

**헷갈리기 쉬운 쌍**

```
자동차 ↔ 트럭      (둘 다 바퀴 달린 탈것)
고양이 ↔ 개        (둘 다 네 발 동물, 털)
새 ↔ 비행기        (둘 다 하늘, 날개 모양)
사슴 ↔ 말          (둘 다 네 발, 갈색)
```

> **사람의 정확도도 약 94%입니다.** 32×32는 사람에게도 작습니다.
> **CNN이 90%를 넘으면 상당히 좋은 것**입니다.

### 컬러 이미지의 차이

**① 입력 채널이 3배**

```
MNIST  : (28, 28, 1)  →  Conv2D(32,3) 파라미터 320
CIFAR  : (32, 32, 3)  →  Conv2D(32,3) 파라미터 896     (2.8배)
```

**② 색 정보가 중요할 수도, 방해가 될 수도**

```
도움: 개구리는 초록, 비행기는 파란 하늘 배경
방해: "초록 배경 = 개구리"라고 학습하면 편향
```

> ⚠️ **이것이 [Day 101](day-101.md)의 배경 편향 문제입니다.**
> 늑대는 눈밭, 허스키는 실내 사진이 많으면 모델이 **배경을 보고 판단**합니다.

**③ 채널별로 다른 정보**

```
R 채널: 빨간 계열 밝기
G 채널: 초록 계열 밝기
B 채널: 파란 계열 밝기
```

**첫 Conv 층의 필터도 3채널입니다.** 색 조합 패턴을 학습합니다.

### 학습 시간과 GPU

**CNN이 느린 이유**

```
Conv2D(32, 3) on (32,32,3)
  = 32×32 위치 × 32필터 × (3×3×3) 곱셈
  = 1,024 × 32 × 27 = 884,736번 곱셈    (한 장당, 한 층에서)

배치 128 × 층 6개 × 반복 391회 × 에폭 30
  = 수백억 번의 곱셈
```

| 연산 | CPU | GPU |
|---|---|---|
| 방식 | 순차적, 코어 8~16개 | **병렬, 코어 수천 개** |
| 행렬 곱 | 느림 | **매우 빠름** |
| CIFAR CNN 에폭 | 60~120초 | **3~8초** |

**GPU 확인**


### 학습 곡선 판독 (복습 + 심화)

```
정확도
1.0│      ●━━━●━━━●━━━●  train
   │    ╱
0.8│  ╱  ○━━○
   │╱  ╱     ╲○━━━○━━━○  validation
0.6│  ╱
   └──────────────────── epoch
        ↑        ↑
     최적 지점   과적합
```

| 신호 | 진단 | 대응 |
|---|---|---|
| train↑ val↑ 함께 | 정상 학습 중 | 계속 |
| train↑ val 정체 | 과적합 시작 | 규제 추가 |
| **train↑ val↓** | **명백한 과적합** | 조기 종료·증강 |
| 둘 다 낮음 | 과소적합 | 모델 키우기 |
| val이 심하게 진동 | 학습률 과다 or 검증셋 작음 | lr↓ |

> **`val_loss` 가 `val_accuracy` 보다 먼저 신호를 줍니다.** ([Day 085](day-085.md))
> 정확도는 유지되는데 손실만 오르는 시점이 과적합의 시작입니다.

### 실험 기록표 — 오늘의 핵심

```
| 번호 | 바꾼 것 | 설정 | 파라미터 | train | val | 격차 | 시간 | 관찰 | 다음 시도 |
```

**좋은 기록의 조건**

| 조건 | 설명 |
|---|---|
| **한 번에 하나만 바꾼다** | 두 개를 바꾸면 원인을 알 수 없음 |
| **조건을 고정한다** | seed, 에폭, 배치를 동일하게 |
| **관찰을 문장으로 쓴다** | 숫자만 있으면 로그, 해석이 있어야 기록 |
| **다음 시도를 적는다** | 왜 그다음을 하려는지 |

> **[Day 103](day-103.md) 프로젝트에서 6회 이상의 실험 기록이 필수 산출물입니다.**

### Step 2. 베이스라인 모델과 GPU 속도 측정

```python
import time

import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_train_full, y_train_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_train_full, y_test = y_train_full.ravel(), y_test.ravel()

X_train_full = X_train_full.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0

X_val, y_val = X_train_full[:5000], y_train_full[:5000]
X_train, y_train = X_train_full[5000:], y_train_full[5000:]

print(f"학습 {X_train.shape}, 검증 {X_val.shape}, 테스트 {X_test.shape}")

# ── 베이스라인 ──
def build_baseline():
    return keras.Sequential([
        layers.Input(shape=(32, 32, 3)),
        layers.Conv2D(32, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Conv2D(64, 3, padding="same", activation="relu"),
        layers.MaxPooling2D(2),
        layers.Flatten(),
        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),
    ], name="baseline")


model = build_baseline()
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.summary()

print("\nshape 흐름")
print("  32×32×3 → Conv(32) 32×32×32 → Pool 16×16×32")
print("          → Conv(64) 16×16×64 → Pool  8× 8×64")
print("          → Flatten 4096 → Dense(64) → Dense(10)")

# ── 학습 + 시간 측정 ──
print("\n" + "=" * 66)
print("베이스라인 학습")
print("=" * 66)

t0 = time.time()
history = model.fit(X_train, y_train, epochs=20, batch_size=128,
                    validation_data=(X_val, y_val), verbose=2)
train_time = time.time() - t0

_, test_acc = model.evaluate(X_test, y_test, verbose=0)
h = history.history

print("\n" + "=" * 66)
print(f"학습 시간   : {train_time:.1f}초 ({train_time/20:.1f}초/에폭)")
print(f"학습셋 정확도: {h['accuracy'][-1]:.4f}")
print(f"검증셋 정확도: {h['val_accuracy'][-1]:.4f}")
print(f"테스트 정확도: {test_acc:.4f}")
print(f"격차        : {h['accuracy'][-1] - test_acc:+.4f}")
print()
best_ep = int(np.argmin(h["val_loss"])) + 1
print(f"val_loss 최소 에폭: {best_ep}  (그 이후는 과적합)")
```

```python
import time

import matplotlib.pyplot as plt

from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()
X_full = X_full.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
X_val, y_val = X_full[:5000], y_full[:5000]
X_train, y_train = X_full[5000:], y_full[5000:]

EPOCHS = 25
BATCH = 128


def make(name, blocks, kernel=3, double=False, head="flatten",
         dense=64, dropout=0.0, bn=False):
    L = [layers.Input(shape=(32, 32, 3))]
    for f in blocks:
        L.append(layers.Conv2D(f, kernel, padding="same",
                               activation=None if bn else "relu"))
        if bn:
            L += [layers.BatchNormalization(), layers.Activation("relu")]
        if double:
            L.append(layers.Conv2D(f, kernel, padding="same",
                                   activation=None if bn else "relu"))
            if bn:
                L += [layers.BatchNormalization(), layers.Activation("relu")]
        L.append(layers.MaxPooling2D(2))
        if dropout:
            L.append(layers.Dropout(dropout))
    L.append(layers.Flatten() if head == "flatten"
             else layers.GlobalAveragePooling2D())
    if dropout:
        L.append(layers.Dropout(min(dropout * 1.5, 0.5)))
    if dense:
        L.append(layers.Dense(dense, activation="relu"))
    L.append(layers.Dense(10, activation="softmax"))
    return keras.Sequential(L, name=name)

]
```

```python
    if s.max() == s.min():

    return z if higher_better else 1 - z
```

```
train_acc 0.9471,  val_acc 0.6852,  test_acc 0.6821
```

<details>
<summary>답 보기</summary>

**진단 — 심각한 과적합**

[Day 079](day-079.md)의 진단 순서 적용:

```
① train 성능이 낮은가?  → 아니오 (0.947)
② 격차가 큰가?          → 예 (0.265) ★★★
③ CV 표준편차가 큰가?    → (단일 분할이라 확인 못 함)

→ 명백한 과적합
```

**추가 진단**

| 관찰 | 의미 |
|---|---|
| val_loss가 7에폭부터 상승 | 7에폭 이후는 외우기만 함 |
| Dense가 파라미터의 93% | **모델 용량이 분류부에 몰려 있음** |
| Conv 층은 19,392개뿐 | 특징 추출이 약함 |

**개선 방향 (우선순위 순)**

**① 규제 추가 — Dropout (효과 큼, 비용 없음)**

```python
layers.MaxPooling2D(2),
layers.Dropout(0.25),      # 각 블록 뒤
...
layers.Flatten(),
layers.Dropout(0.4),       # 분류부 앞
```

**근거** — Step 3의 #5→#6에서 격차 0.21 → 0.08, 정확도 +2.7%p.
**비용이 없고(파라미터 0) 효과가 가장 큽니다.**

**② 구조 개선 — Conv 2개씩 + 블록 추가**

```python
[Conv(32) → Conv(32) → Pool] → [Conv(64) → Conv(64) → Pool] → [Conv(128) → Conv(128) → Pool]
```

**근거** — Step 3의 #1→#5에서 +8.3%p.
Conv 파라미터를 늘려 **특징 추출을 강화**하고, Flatten 크기를 줄여 Dense 비중을 낮춥니다.

```
변경 전: Flatten 4,096 → Dense(64) = 262,208개 (93%)
변경 후: Flatten 2,048 → Dense(64) = 131,136개 (24%)
```

**③ 데이터 증강 (효과 크지만 [Day 094](day-094.md) 이후)**

```python
layers.RandomFlip("horizontal"),
layers.RandomRotation(0.1),
layers.RandomZoom(0.1),
```

**근거** — 과적합의 근본 원인은 **데이터 부족**입니다.
45,000장으로 55만 파라미터를 학습하면 외우게 됩니다.
증강은 데이터를 사실상 늘리는 효과가 있습니다.

**우선순위 근거**

```python
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(X_full, y_full), (X_test, y_test) = keras.datasets.cifar10.load_data()
y_full, y_test = y_full.ravel(), y_test.ravel()
X_full = X_full.astype("float32") / 255.0
X_test_n = X_test.astype("float32") / 255.0
X_val, y_val = X_full[:5000], y_full[:5000]
X_train, y_train = X_full[5000:], y_full[5000:]

EPOCHS, BATCH, SEED = 25, 128, 42


def build(blocks=(32, 64), kernel=3, double=False, dropout=0.0,
          bn=False, head="flatten", dense=64, lr=0.001):
    L = [layers.Input(shape=(32, 32, 3))]
    for f in blocks:
        for _ in range(2 if double else 1):
            L.append(layers.Conv2D(f, kernel, padding="same",
                                   activation=None if bn else "relu"))
            if bn:
                L += [layers.BatchNormalization(), layers.Activation("relu")]
        L.append(layers.MaxPooling2D(2))
        if dropout:
            L.append(layers.Dropout(dropout))
    L.append(layers.Flatten() if head == "flatten"
             else layers.GlobalAveragePooling2D())
    if dropout:
        L.append(layers.Dropout(min(dropout * 1.6, 0.5)))
    if dense:
        L.append(layers.Dense(dense, activation="relu"))
    L.append(layers.Dense(10, activation="softmax"))
    m = keras.Sequential(L)
    m.compile(optimizer=keras.optimizers.Adam(learning_rate=lr),
              loss="sparse_categorical_crossentropy", metrics=["accuracy"])
    return m


# ── 실험 정의: 한 번에 하나씩만 변경 ──
실험들 = [
    ("#1", "베이스라인 (32,64)",       dict()),
    ("#2", "블록 3개 (32,64,128)",     dict(blocks=(32, 64, 128))),
    ("#3", "블록 4개 (32,64,128,256)", dict(blocks=(32, 64, 128, 256))),
    ("#4", "#2 + 필터 2배",            dict(blocks=(64, 128, 256))),
    ("#5", "#2 + 커널 5×5",            dict(blocks=(32, 64, 128), kernel=5)),
    ("#6", "#2 + Conv 2개씩",          dict(blocks=(32, 64, 128), double=True)),
    ("#7", "#6 + Dropout 0.25",        dict(blocks=(32, 64, 128), double=True,
                                            dropout=0.25)),
    ("#8", "#7 + BatchNorm",           dict(blocks=(32, 64, 128), double=True,
                                            dropout=0.25, bn=True)),
    ("#9", "#8 + GAP",                 dict(blocks=(32, 64, 128), double=True,
                                            dropout=0.25, bn=True, head="gap")),
    ("#10", "#8 + lr 0.0005",          dict(blocks=(32, 64, 128), double=True,
                                            dropout=0.25, bn=True, lr=0.0005)),
]

rows, histories = [], {}

for num, desc, kw in 실험들:
    tf.random.set_seed(SEED)
    m = build(**kw)
    t0 = time.time()
    hist = m.fit(X_train, y_train, epochs=EPOCHS, batch_size=BATCH,
                 validation_data=(X_val, y_val), verbose=0)
    elapsed = time.time() - t0
    _, test_acc = m.evaluate(X_test_n, y_test, verbose=0)
    h = hist.history

    rows.append({
        "번호": num, "바꾼_것": desc,
        "파라미터": m.count_params(),
        "train": round(h["accuracy"][-1], 4),
        "val": round(h["val_accuracy"][-1], 4),
        "test": round(test_acc, 4),
        "격차": round(h["accuracy"][-1] - test_acc, 4),
        "val_최고": round(max(h["val_accuracy"]), 4),
        "최적에폭": int(np.argmin(h["val_loss"])) + 1,
        "시간(s)": round(elapsed, 1),
    })
    histories[num] = h
    print(f"{num:<5}{desc:<26} test {test_acc:.4f}  격차 {h['accuracy'][-1]-test_acc:+.4f}")

df = pd.DataFrame(rows)

# ── ④ 관찰과 다음 시도 (사람이 작성) ──
df["관찰"] = [
    "격차 0.27. 심각한 과적합. Dense가 파라미터 93%",
    "블록 추가로 +4%p. Flatten 크기 축소로 Dense 비중 감소",
    "블록 4개는 2×2까지 축소되어 정보 손실. #2보다 나쁨",
    "파라미터 4배인데 +0.7%p. 수확 체감 확인",
    "5×5는 파라미터만 늘고 3×3보다 못함 (Day 087 결론과 일치)",
    "VGG 스타일로 +4.3%p. 구조 변경 중 가장 효과적",
    "Dropout으로 격차 0.21→0.08. 성능도 +2.7%p ★",
    "BatchNorm으로 +2.1%p. 최적 에폭이 24로 늦춰짐(더 오래 학습 가능)",
    "GAP으로 파라미터 38% 감소, 성능은 -0.5%p. 격차 최소",
    "학습률 절반으로 안정적이나 25에폭으로는 부족",
]
df["다음_시도"] = [
    "블록 추가", "블록 더 추가", "블록 3개로 복귀", "필터 원복",
    "커널 3×3 복귀", "Dropout 추가", "BatchNorm 추가", "GAP 시도",
    "학습률 조정", "★ 에폭 늘리기 + 데이터 증강 (Day 094)",
]

print("\n" + "=" * 120)
print("④ 실험 기록표 — CIFAR-10, 25에폭, batch 128, seed 42")
print("=" * 120)
print(df.to_string(index=False))
print("=" * 120)

# ── ⑤ 다기준 평가 ──
def norm(s, higher=True):
    if s.max() == s.min():
        return pd.Series(1.0, index=s.index)
    z = (s - s.min()) / (s.max() - s.min())
    return z if higher else 1 - z


W = {"정확도": 0.45, "일반화": 0.25, "효율": 0.20, "속도": 0.10}
sc = pd.DataFrame({
    "번호": df["번호"], "바꾼_것": df["바꾼_것"],
    "정확도": norm(df["test"]).round(3),
    "일반화": norm(df["격차"], False).round(3),
    "효율": norm(np.log10(df["파라미터"]), False).round(3),
    "속도": norm(df["시간(s)"], False).round(3),
})
sc["종합"] = sum(sc[k] * w for k, w in W.items()).round(4)
sc = sc.sort_values("종합", ascending=False)

print("\n⑤ 다기준 평가")
print(f"가중치: {W}")
print(sc.to_string(index=False))

winner = sc.iloc[0]["번호"]
wrow = df[df["번호"] == winner].iloc[0]
print(f"\n★ 선정: {winner} {wrow['바꾼_것']}")

# ── ③ 그래프 ──
fig, axes = plt.subplots(2, 2, figsize=(15, 10))

ax = axes[0, 0]
for n in ["#1", "#2", "#6", "#8"]:
    ax.plot(histories[n]["val_accuracy"], linewidth=2, label=n)
ax.set_xlabel("epoch"); ax.set_ylabel("val accuracy")
ax.set_title("③ Validation accuracy (structural changes)")
ax.legend(); ax.grid(alpha=0.3)

ax = axes[0, 1]
for n in ["#6", "#7", "#8", "#9"]:
    ax.plot(histories[n]["val_loss"], linewidth=2, label=n)
ax.set_xlabel("epoch"); ax.set_ylabel("val loss")
ax.set_title("③ Validation loss (regularization)")
ax.legend(); ax.grid(alpha=0.3)

ax = axes[1, 0]
x = np.arange(len(df))
ax.bar(x - 0.2, df["train"], 0.4, label="train")
ax.bar(x + 0.2, df["test"], 0.4, label="test")
ax.set_xticks(x); ax.set_xticklabels(df["번호"], fontsize=8)
ax.set_ylabel("accuracy"); ax.set_title("④ Train vs Test")
ax.legend(); ax.grid(alpha=0.3, axis="y")

ax = axes[1, 1]
s = ax.scatter(df["파라미터"], df["test"], s=150, c=df["격차"], cmap="RdYlGn_r")
for _, r in df.iterrows():
    ax.annotate(r["번호"], (r["파라미터"], r["test"]),
                xytext=(6, 4), textcoords="offset points", fontsize=8.5)
ax.set_xscale("log"); ax.set_xlabel("parameters (log)")
ax.set_ylabel("test accuracy"); ax.set_title("⑤ Parameters vs accuracy")
fig.colorbar(s, ax=ax, label="gap")
ax.grid(alpha=0.3)

fig.tight_layout(); plt.show()

OUT = Path("/content/drive/MyDrive/ml_course/experiments")
OUT.mkdir(parents=True, exist_ok=True)
df.to_csv(OUT / "day090_full_experiments.csv", index=False, encoding="utf-8-sig")
sc.to_csv(OUT / "day090_scoring.csv", index=False, encoding="utf-8-sig")
print(f"\n저장 완료: {OUT}")
```
