### 1부 · 예외 처리

#### 실패 지점을 먼저 목록화합니다

**막연히 `try/except` 를 붙이는 것이 아니라, 실패할 수 있는 지점을 전부 적어 놓고 각각 어떻게 할지 정합니다.**

| # | 실패 지점 | 증상 | 지금 | 오늘의 대응 |
|---|---|---|---|---|
| 1 | 잘못된 파일 업로드 | `UploadError` | 해결됨 | 유지 ([Day 159](day-159.md)) |
| 2 | 손상 이미지 | `imdecode` → `None` | 해결됨 | 유지 |
| 3 | **카메라 없음** | `isOpened()` False | 500 | 503 + 안내 프레임 |
| 4 | **카메라 뽑힘** | `read()` → `False` | 스트림 영구 정지 | 재연결 루프 |
| 5 | 손상 프레임 | `imencode` 예외 | 스트림 종료 | 프레임 스킵 |
| 6 | 추론 실패 | `RuntimeError` | 500 HTML | 500 JSON + 로그 |
| 7 | 모델 로드 실패 | `FileNotFoundError` | 앱 죽음 | CRITICAL + 중단 |

| 9 | 메모리 부족 | `MemoryError` | 프로세스 죽음 | 픽셀 상한 |
| 10 | **DB 잠김** | `OperationalError` | 500 | WAL + `busy_timeout` |

> ⚠️ **삼키더라도 절대 조용히 삼키지 마세요.**

#### ★ 스트리밍 루프 — 한 프레임 실패로 죽으면 안 됩니다

```python
# Day 163 의 코드 (문제)
while True:
    ok, frame = cap.read()
    if not ok:
        break                              # ① 카메라가 뽑히면 영원히 끝
    result = detector.predict_image(frame) # ③ 추론 예외 → 제너레이터 종료
    ok, buf = cv2.imencode(".jpg", frame)  # ② 인코딩 예외 → 제너레이터 종료
```

**셋 다 "한 프레임의 문제"인데 "전체가 죽습니다."**

```
┌────────────────────────────────────────┐
│ while True:                            │
│   try:                                 │
│     frame  = camera.read()  ← 재연결    │
│     result = infer(frame)              │
│     jpg    = encode(frame)             │
│     fail_streak = 0     ★ 성공 리셋     │
│   except Exception:                    │
│     fail_streak += 1                   │
│     log.warning(...)                   │
│     if fail_streak >= MAX: break       │
│     jpg = placeholder("일시 오류")       │
│   yield jpg                            │
└────────────────────────────────────────┘

프레임 단위 try   한 프레임 실패는 건너뜀
연속 실패 카운터  정말 죽었으면 무한 루프를 멈춤
성공하면 0 리셋   산발적 실패는 누적되지 않음

★ 왜 "연속" 인가
  누적 카운터는 3일 돌면 산발적 실패만으로 상한에 도달 → 멀쩡한 스트림이 중단됨
  연속 카운터는 "지금 이 순간 정말 고장났는가" 를 봅니다
```

#### ★ 재시도 — 지수 백오프

```
카메라가 뽑혔습니다. 언제 다시 시도할까요?
  ✗ 즉시 반복      CPU 100% · 로그 초당 3만 줄
  ✗ 고정 1초       30분에 1,800번 시도 → 시끄러움
  ✓ 지수 백오프    0.5 → 1 → 2 → 4 → 8 → 16 → 30 → 30 ...
```

| 누적 대기 | 고정 1초 | 지수 백오프(상한 30초) |
|---|---|---|
| 3회차 | 3s | 3.5s |
| 5회차 | 5s | 15.5s |
| 30분간 시도 | **1,800회** | **65회** |
| 최악 복구 지연 | 1초 | 30초 |

구현은 **④ Step 4 `backoff_delay()`** 입니다. 여기에 **지터(±20%)** 를 섞습니다.
카메라 4대가 동시에 끊기면 백오프만으로는 **네 대가 같은 시각에 재시도**해 또 같이 실패하기 때문입니다.

| 재시도한다 | 재시도하지 않는다 |
|---|---|
| 네트워크 타임아웃 · 카메라 일시 끊김 | 잘못된 파일 형식 · 장치가 아예 없음 |
| `database is locked` | `no such table` |
| HTTP 502 · 503 · 504 | HTTP 400 · 401 · 404 |

> ⚠️ **재시도하면 안 되는 예외가 있습니다.**
> `FileNotFoundError`(모델 없음)와 `400`(요청이 잘못됨)은 **몇 번을 다시 해도 똑같이 실패합니다.**

#### Flask 의 예외 처리 계층

```
요청
 ├─▶ before_request        ← 요청 ID 부여
 ├─▶ 뷰 함수 ── 예외 발생 ──┐
 ├─▶ after_request         │  ← ★ 예외가 나면 실행 안 됨!
 │   ┌─────────────────────▼─────┐
 │   │ errorhandler(그 타입)      │
 │   │ 없으면 errorhandler(Exc)  │
 │   │ 그것도 없으면 500          │
 │   └─────────────────────┬─────┘
 └─▶ teardown_request(exc) ←  예외가 나도 반드시 실행
       커넥션 반납 · 임시 파일 정리 · 요청 ID 초기화
```

| 훅 | 예외에도 실행? | 용도 |
|---|---|---|
| `before_request` | — | 요청 ID · 시작 시각 |
| `after_request` | ✗ **안 됨** | 응답 헤더 · 접근 로그 |
| `teardown_request` | ✓ **항상** | 커넥션 반납 · 정리 |
| `errorhandler(code)` | — | 404 · 413 · 500 |
| `errorhandler(Exception)` | — | 마지막 그물 |

등록 코드는 **④ Step 4 `errors.py`**, `teardown` 등록은 **④ Step 1 `db.init_app`** 입니다.
**`teardown` 안에서 예외를 던지면 자원 반납이 끊겨 커넥션이 샙니다. 전부 `try/except` 로 감싸세요.**

> ⚠️ **`errorhandler(Exception)` 만 등록하면 404 도 여기로 옵니다.**
> `HTTPException` 핸들러를 **함께** 등록해야 404 가 500 이 되지 않습니다.

> ⚠️ **`TESTING=True` 이면 `PROPAGATE_EXCEPTIONS` 가 켜져 예외가 그대로 올라옵니다.**
> **오류 응답을 테스트할 때는 `app.config["PROPAGATE_EXCEPTIONS"] = False`** 를 지정하세요.

#### 디스크 가득 — 가장 자주 겪는 운영 장애

```
증상
  · cv2.imwrite() 가 False 반환 (예외 아님! ★ 조용히 실패)
  · OSError: [Errno 28] No space left on device
  · sqlite3.OperationalError: database or disk is full
  · 로그 파일도 못 씀 → 기록조차 안 남음

대응 3단계
  ① 예방  저장 직전 shutil.disk_usage() 확인 → 부족하면 507
  ② 완화  여유 15% 미만이면 오래된 파일 자동 정리
  ③ 경보  여유 5% 미만이면 CRITICAL + 알림 · 로그용 공간은 따로 확보
```

> ⚠️ **`cv2.imwrite()` 는 실패해도 예외 없이 `False` 를 반환합니다.**
> 반환값을 확인하지 않으면 **"저장했다고 생각했는데 파일이 없는"** 상태가 됩니다.

#### `print` 를 왜 버리는가

| 항목 | `print` | `logging` |
|---|---|---|
| 시각·레벨·출처 | ✗ 직접 | ✓ 포매터가 자동 |
| 출력 위치 | ✗ 코드 수정 | 핸들러 교체 |
| **파일 회전** | ✗ 무한히 커짐 | `RotatingFileHandler` |
| 예외 스택 | 직접 `print_exc()` | `logger.exception()` |
| 운영에서 끄기 | ✗ 코드 삭제 | 레벨만 올림 |
| 성능 | 항상 문자열 생성 | 레벨 미달이면 안 만듦 |
| 버퍼링 | 죽으면 유실 | 핸들러가 flush |
| 구조화·다중 목적지 | ✗ | 포매터·핸들러 교체 |

측정 (10만 회 · 로거는 INFO 라 DEBUG 는 출력 안 됨)

| 호출 방식 | 시간 | 배율 |
|---|---|---|
| `print(f"...")` | 4.82s | — |
| `logger.debug(f"...")` | 0.31s | 15.5× |
| `logger.debug("%s", x)` | **0.06s** | **80×** |

> ⚠️ **`logger.debug(f"...")` 는 반쪽짜리입니다.**
> f-string 은 **호출 전에** 만들어지므로 레벨이 꺼져 있어도 조립 비용을 냅니다.
> **`logger.debug("값=%s", value)` 형태를 쓰세요.**

#### `logging` 의 4가지 구성 요소

```
 Logger    "cctv.web.detect"  ← 코드가 부르는 것 (레벨 검사 · 상위로 전파)
   ▼
 Filter    ★ 레코드에 정보 추가 (요청 ID!)
   ▼
 Handler   어디로 — Stream · RotatingFile · TimedRotatingFile · SMTP
   ▼
 Formatter 어떤 모양으로 — 텍스트 / JSON
   ▼  출력

 Logger 는 모듈마다 하나, Handler 는 로거 하나에 여러 개,
 Formatter 는 핸들러마다 하나, Filter 는 로거·핸들러 양쪽에 답니다.
```

#### ★ 계층 이름 — 로거 이름이 곧 구조입니다

```
cctv                    ← 루트 (우리 앱)
 ├─ cctv.web            ← .detect · .stream · .events · .api · .access
 ├─ cctv.db             ├─ cctv.detector    (추론)
```

#### 로그 레벨 선택 기준

| 레벨 | 언제 | 우리 프로젝트의 예 | 운영 |
|---|---|---|---|
| **DEBUG** | 흐름 추적 | `프레임 1274 conf=0.51 3건` | ✗ |
| **INFO** | **정상이고 의미 있는 사건** | `앱 시작`, `카메라 연결`, `검출 3건 82ms` | ✓ |
| **WARNING** | **비정상이지만 처리했음** | `프레임 실패(연속 1)`, `디스크 여유 12%` | ✓ |
| **ERROR** | **기능 하나가 실패** | `추론 예외`, `DB 쓰기 실패` | ✓ + 집계 |
| **CRITICAL** | **전체를 못 씀** | `모델 로드 실패`, `디스크 여유 0` | ✓ + 알림 |

```
★ 헷갈리는 경계
  잘못된 파일 업로드   → INFO (400 을 정확히 반환했으니 시스템은 정상)
                       같은 IP 가 반복하면 → WARNING (공격 시도)
  프레임 1장 실패      → 연속 3회부터 WARNING, 그 전에는 DEBUG
  추론 500ms(평소 80)  → WARNING (느려짐은 장애의 전조)
  404                 → INFO. 우리 잘못이 아님
```

> ⚠️ **ERROR 를 남발하면 ERROR 를 아무도 안 봅니다.**
> "ERROR 가 하루 3,000줄" 인 시스템은 **로그가 없는 시스템과 같습니다.**

#### 로그 파일이 디스크를 채웁니다 — 회전

```
★ 계산
  30 FPS × INFO 한 줄 120B = 3,600 B/s = 310 MB/일 = 9.3 GB/월
  라즈베리파이 microSD 32GB → 3개월이면 로그만으로 가득 참

RotatingFileHandler(maxBytes=10MB, backupCount=5)
  app.log · app.log.1 ... app.log.5   → 최대 60MB 로 고정
TimedRotatingFileHandler(when="midnight", backupCount=14)
  suffix="%Y-%m-%d" → app.jsonl.2026-08-10 처럼 날짜로 찾을 수 있음
```

| | `Rotating` (크기) | `Timed` (시간) |
|---|---|---|
| 최대 용량 | **예측 가능** | 예측 불가 |
| 날짜로 찾기 | ✗ 어려움 | 쉬움 |
| 폭주 시 | 잘 견딤 | 하루치가 10GB 가 될 수도 |
| 우리 선택 | `app.log` · `error.log` | `app.jsonl` |

> ⚠️ **여러 프로세스가 같은 파일에 회전을 걸면 깨집니다.**
> `gunicorn -w 4` 면 회전 시점에 **서로 파일을 갈아엎습니다.**
> 워커마다 다른 파일명을 쓰거나 표준출력으로 내보내고 `logrotate` 에 맡기세요([Day 165](day-165.md)).

#### GIL — 파이썬 스레드의 진실

```
Day 163 의 스트리밍은 ★ 요청 하나가 영원히 끝나지 않습니다
  threaded=False 면 워커가 스트림에 묶여 /events 가 영원히 로딩 중
  두 명이 /live 를 열면 카메라 하나를 두 스레드가 read() → 프레임이 섞임

GIL — 한 순간에 파이썬 바이트코드를 실행하는 스레드는 단 하나
  ┌───────────────────────────────────┐
  │ 스레드 A  ████░░░░████░░░░████     │
  │ 스레드 B  ░░░░████░░░░████░░░░     │
  │           ★ 번갈아 실행 (동시가 아님)│
  └───────────────────────────────────┘
  → CPU 를 쓰는 순수 파이썬은 스레드를 늘려도 안 빨라집니다

그런데 다음 동안에는 GIL 이 풀립니다
  · I/O 대기 (파일 · 네트워크 · sleep)
  · C 확장이 "파이썬 객체 안 건드립니다" 라고 선언한 구간
      NumPy · OpenCV imencode/resize · PyTorch/ONNX/NCNN 추론 · SQLite 파일 I/O
```

#### 공유 자원 목록과 보호 방법

| 자원 | 위험 | 보호 |
|---|---|---|
| **모델 객체** | 동시 `predict` 시 버퍼 충돌 | 세마포어로 동시 추론 수 제한 |
| **카메라** | 두 스레드가 `read()` → 섞임 | 캡처 스레드 1개 + 최신 프레임 공유 |
| **DB 커넥션** | 트랜잭션 뒤섞임 | 스레드마다 별도 커넥션 |
| **카운터** | `+=` 가 원자적이지 않음 | `Lock` · `itertools.count` |
| **딕셔너리 캐시** | 반복 중 변경 → `RuntimeError` | `Lock` · 복사 후 순회 |
| **파일 쓰기** | 같은 경로 동시 쓰기 | UUID 파일명 (Day 159) |
| **로그 파일** | 회전 시 충돌 | `logging` 내부 락 |
| 모듈 전역 변수 | 요청 간 뒤섞임 | ★ 쓰지 말 것 |

```python
# ★ i += 1 은 원자적이지 않습니다 — 읽고·더하고·저장하는 사이에 끼어듭니다
with lock:
    counter += 1


_infer_sem = threading.BoundedSemaphore(2)      # ★ 동시 추론 2건까지


def infer_guarded(detector, img, **kw):
    if not _infer_sem.acquire(timeout=10.0):
        raise TimeoutError("추론 대기열이 가득 찼습니다")
    try:
        return detector.predict_image(img, **kw)
    finally:
        _infer_sem.release()                    # finally 필수
```

```
★ 왜 무제한이면 안 되는가
  동시 20건 × 640×640 × 중간 텐서 → 메모리 폭증 → OOM → 프로세스 종료
  세마포어 2개면 3번째부터 줄을 섭니다 (즉시 거부가 아니라 대기)
  → 10초를 넘으면 503 (백프레셔)

락 고르기
  Lock 기본(같은 스레드가 두 번 잡으면 데드락) · RLock 재진입 · Event 종료 신호
  Semaphore(n) 동시 n개(BoundedSemaphore 가 안전) · queue.Queue 스레드 안전 큐
```

> ⚠️ **`acquire()` 뒤에 `finally: release()` 가 없으면 데드락입니다.**
> **`with lock:` 을 쓰세요.** 예외가 나도 반드시 풀립니다.

| 방식 | 안전 | 성능 | 권장 |
|---|---|---|---|

> `teardown_request` 에서 닫거나 **고정 스레드 풀**(`waitress`)을 쓰세요.

```
두 번째 벽 — sqlite3.OperationalError: database is locked

★ 진짜 원인은 "SQLite 가 동시성을 못 한다" 가 아닙니다
  ① 기본 저널 모드(DELETE)에서는 쓰기 하나가 읽기까지 전부 막습니다
  ② busy_timeout 기본값이 0 → 잠겨 있으면 기다리지 않고 즉시 예외
  ③ 트랜잭션을 열어 놓고 커밋을 안 함 → 락을 계속 쥠 (Day 034)
  ④ 커서를 다 소비하지 않음 → 읽기 락 유지
  ⑤ 긴 트랜잭션 안에서 무거운 작업 (BEGIN → 추론 300ms → INSERT → COMMIT)

해결 — WAL 모드
  DELETE (기본)                  WAL
  쓰기 중에는 읽기도 막힘         읽기·쓰기 동시 가능 (읽는 쪽은 예전 스냅샷)
  cctv.db + db-journal          cctv.db + db-wal + db-shm  ← 파일 2개 추가
  커밋 = 원본 파일 수정          커밋 = WAL 에 덧붙이기 (빠름)
  단, 쓰기는 여전히 한 번에 하나입니다 (writer 는 단일)
```

| PRAGMA | 범위 | 기본값 | 우리 값 |
|---|---|---|---|
| `journal_mode` | **DB 파일(영구)** | `delete` | `wal` |
| `busy_timeout` | 커넥션 | **0** | `5000` |
| `synchronous` | 커넥션 | `FULL` | `NORMAL` |
| `foreign_keys` | 커넥션 | **OFF** | `ON` |
| `cache_size` | 커넥션 | 2MB | 8MB |

**실측 — 20개 스레드가 동시에 INSERT (각 50건)**

| 설정 | 성공 | `database is locked` | 총 소요 | 최대 대기 |
|---|---|---|---|---|
| DELETE, timeout 0 | 12/20 | **8스레드 실패** | 0.9s | — |
| DELETE, timeout 5000 | 20/20 | 0 | 6.4s | 1.92s |
| **WAL, timeout 5000** | 20/20 | 0 | **1.1s** | **0.11s** |
| WAL + 배치 | 20/20 | 0 | **0.28s** | 0.03s |

★ 읽기까지 섞으면 차이가 더 큽니다. 쓰기 1 + 읽기 10 동시일 때
DELETE 는 읽기가 평균 **340ms** 기다리고 WAL 은 평균 **1.8ms** 에 응답합니다.

> ⚠️ **`journal_mode` 를 빼면 나머지가 다 무의미하고, `busy_timeout` 은 커넥션마다 다시 설정해야 합니다.**
> **커넥션을 여는 함수 하나에 전부 몰아넣으세요**(④ Step 1 `_apply_pragmas`).

> ⚠️ **WAL 은 네트워크 파일시스템(NFS·SMB)에서 동작하지 않습니다.** 공유 메모리(`-shm`)를 쓰기 때문입니다.
> 또 읽기 트랜잭션이 오래 열려 있으면 WAL 파일이 커지므로 주기적으로
> `PRAGMA wal_checkpoint(TRUNCATE)` 를 실행하세요.

```python
# ✗ 트랜잭션 안에서 무거운 작업
with session(write=True) as conn:
```

#### ★ 페이지네이션 — `LIMIT/OFFSET` 의 두 가지 문제

```

① 뒤로 갈수록 느려집니다 — 19,980행을 실제로 읽고 버린 뒤 20행을 반환합니다

     2페이지 : OFFSET 20 → E83 E82 E81 ...  ← 이미 본 행을 다시 봄
```

```sql
-- ★ 키셋(커서) 페이지네이션 — 마지막 행의 값을 커서로 씁니다
SELECT * FROM events
WHERE (ts_epoch < :last_ts)
   OR (ts_epoch = :last_ts AND id < :last_id)     -- 동점 처리
ORDER BY ts_epoch DESC, id DESC
LIMIT 20;
```

```

  → 단, N페이지로 바로 점프하거나 총 페이지 수를 보여줄 수 없고
     정렬 기준이 반드시 고유해야 합니다 (동점 tie-breaker 필수)

  · /events             페이지 번호 UI (OFFSET) — 상한 page ≤ 500
  · /api/events?cursor= 키셋 — 파이·모바일·무한 스크롤용
```

#### 총 개수 세기의 비용

```
★ 필터가 걸린 COUNT 는 조건에 맞는 행을 전부 세어야 합니다
  COUNT(*) 전체 11ms · 날짜 필터 14ms · 클래스 EXISTS 88ms · 목록 20건 1.7ms
  → 개수 세기가 목록 조회보다 50배 비쌉니다
```

| 대안 | 방법 | 정확도 | 비용 |
|---|---|---|---|
| 그냥 센다 | `COUNT(*)` | 정확 | 비쌈 |
| **다음 페이지만 확인** | `LIMIT 21` → 21건이면 "다음 있음" | 개수는 모름 | 공짜 |
| 상한을 둔 개수 | `COUNT(*) FROM (SELECT 1 ... LIMIT 1000)` | 근사 | 저렴 |
| 캐시 | 60초 캐시 | 약간 오래됨 | 저렴 |

★ 필터가 없으면 캐시된 전체 개수, 있으면 **상한 1,000 을 둔 근사("1,000+ 건")**,
항상 `LIMIT+1` 로 "다음 페이지 있음" 을 판정합니다.
사용자는 "정확히 40,213건" 이 아니라 **"다음 페이지가 있나"** 만 궁금해합니다.

`style="height:{{ 비율 }}%"`. **서버는 최댓값 대비 비율만 계산해 줍니다.**

**② 시간대 히트맵** — `grid-template-columns:32px repeat(24,1fr)` 로 168칸을 깔고

#### 정리 정책 — DB 와 파일의 정합성

Day 159 의 `cleanup_old_files()` 는 **파일만** 지웠습니다. 이제 **둘을 함께** 지워야 하고
**순서가 중요합니다.**

```
방법 A — 파일 먼저, DB 나중
  중단되면 레코드가 남음 → ★ 고아 레코드 → 목록에 깨진 이미지 → 화면이 망가짐
방법 B — DB 먼저, 파일 나중      ← ★ 우리 선택
  중단되면 파일이 남음 → 고아 파일 → 화면은 멀쩡, 디스크만 좀 씀 → 청소 가능

원칙: 중단되었을 때 덜 아픈 쪽으로 순서를 정합니다
```

| | 고아 파일 | 고아 레코드 |
|---|---|---|
| 증상 | 디스크만 낭비 | 목록에 깨진 이미지 |
| 사용자 영향 | 없음 | **있음** |
| 복구 | 청소 스크립트 | 레코드 삭제 or 대체 표시 |
| 위험도 | 낮음 | **높음** |

```
★ 경쟁 조건 — 방금 만들어진 파일
  10:00:00.100  /detect 가 result_a3f9.jpg 를 씀
  10:00:00.150  청소 스크립트가 파일 목록을 읽음
  10:00:00.180  /detect 가 DB 에 INSERT + COMMIT
  10:00:00.200  청소: "DB 에 없는 파일이네" → 삭제 → 방금 만든 결과가 사라집니다

해결 — 유예 시간(grace period)
  "수정 시각이 1시간 이내인 파일은 건드리지 않는다"
  → 진행 중인 요청과 겹칠 수 없습니다. 1시간 늦게 지워질 뿐 아무 문제 없습니다
```

| 대상 | 보관 | 근거 |
|---|---|---|
| 업로드 원본 / 결과 이미지 | 3일 / 7일 | 결과가 있으면 원본은 덜 필요 / 확인 기간 |
| 이벤트 스냅샷 | 30일 | 사고 조사 기간 |
| `events` · `detections` | 90일 | 통계용. 행 하나 200바이트 |
| `app.log` / `app.jsonl` | 60MB 고정 / 14일 | 회전 / 집계용 |

★ **레코드는 오래, 파일은 짧게.** 이벤트 10만 건은 약 22MB 지만 결과 이미지 10만 장은 24GB 입니다.
화면에서는 "이미지 보관 기간이 지났습니다" 로 표시합니다.

> ⚠️ **개인정보(얼굴)가 담긴 이미지의 보관 기간은 짧을수록 좋습니다.**

### Step 1. `web/db.py` — 커넥션 관리 · WAL · 마이그레이션

```python
"""web/db.py — SQLite 커넥션 관리 · WAL · 스키마 마이그레이션

설계
  · 스레드마다 커넥션 (threading.local)
  · 커넥션을 열 때 PRAGMA 를 한 곳에서 전부 적용
  · user_version 으로 마이그레이션
  · session(write=True) 컨텍스트 매니저로 커밋/롤백 자동화
"""
from __future__ import annotations

import logging
import sqlite3
import threading
import time
from contextlib import contextmanager
from pathlib import Path

logger = logging.getLogger("cctv.db")

_local = threading.local()          # ★ 스레드별 커넥션 보관소
_write_lock = threading.RLock()     # ★ 프로세스 내 쓰기 직렬화
_state = {"path": None, "timeout": 5.0}

# ────────────────────────── 스키마 ──────────────────────────

MIGRATIONS: dict[int, list[str]] = {
    1: [
        """CREATE TABLE IF NOT EXISTS events (
               id          INTEGER PRIMARY KEY AUTOINCREMENT,
               event_uid   TEXT    NOT NULL UNIQUE,
               ts          TEXT    NOT NULL,
               ts_epoch    REAL    NOT NULL,
               source      TEXT    NOT NULL,
               device_id   TEXT,
               image_path  TEXT,
               result_path TEXT,
               width       INTEGER NOT NULL DEFAULT 0,
               height      INTEGER NOT NULL DEFAULT 0,
               det_count   INTEGER NOT NULL DEFAULT 0,
               top_class   TEXT,
               max_conf    REAL    NOT NULL DEFAULT 0,
               counts_json TEXT    NOT NULL DEFAULT '{}',
               infer_ms    REAL    NOT NULL DEFAULT 0,
               total_ms    REAL    NOT NULL DEFAULT 0,
               model_name  TEXT,
               conf_thres  REAL,
               iou_thres   REAL,
               created_at  TEXT    NOT NULL
                           DEFAULT (datetime('now','localtime'))
           )""",
        """CREATE TABLE IF NOT EXISTS detections (
               id         INTEGER PRIMARY KEY AUTOINCREMENT,
               event_id   INTEGER NOT NULL
                          REFERENCES events(id) ON DELETE CASCADE,
               class_id   INTEGER NOT NULL,
               class_name TEXT    NOT NULL,
               conf       REAL    NOT NULL,
               x1 REAL NOT NULL, y1 REAL NOT NULL,
               x2 REAL NOT NULL, y2 REAL NOT NULL
           )""",
        "CREATE INDEX IF NOT EXISTS idx_events_ts "
        "ON events(ts_epoch DESC)",
        "CREATE INDEX IF NOT EXISTS idx_events_class_ts "
        "ON events(top_class, ts_epoch DESC)",
        "CREATE INDEX IF NOT EXISTS idx_det_event "
        "ON detections(event_id)",
        "CREATE INDEX IF NOT EXISTS idx_det_class_conf "
        "ON detections(class_name, conf)",
    ],
    2: [
        "ALTER TABLE events ADD COLUMN thumb_path TEXT",
        "CREATE INDEX IF NOT EXISTS idx_events_source_ts "
        "ON events(source, ts_epoch DESC)",
    ],
    3: [
        # Day 170 알림 발송 여부
        "ALTER TABLE events ADD COLUMN notified INTEGER NOT NULL DEFAULT 0",
    ],
}
TARGET_VERSION = max(MIGRATIONS)


# ────────────────────────── 커넥션 ──────────────────────────

def _apply_pragmas(conn: sqlite3.Connection) -> None:
    """★ 커넥션을 열 때마다 반드시 적용"""
    conn.execute("PRAGMA journal_mode = WAL")       # ★ DB 파일에 영구 기록
    conn.execute("PRAGMA busy_timeout = 5000")      # ★ 커넥션마다
    conn.execute("PRAGMA synchronous  = NORMAL")
    conn.execute("PRAGMA foreign_keys = ON")        # ★ 기본이 OFF!
    conn.execute("PRAGMA cache_size   = -8000")     # 8MB


def _connect() -> sqlite3.Connection:
    if _state["path"] is None:
        raise RuntimeError("db.init_app() 을 먼저 호출하세요")
    conn = sqlite3.connect(_state["path"], timeout=_state["timeout"])
    conn.row_factory = sqlite3.Row                  # ★ 이름으로 접근
    _apply_pragmas(conn)
    return conn


def get_conn() -> sqlite3.Connection:
    """★ 이 스레드 전용 커넥션 (없으면 생성)"""
    conn = getattr(_local, "conn", None)
    if conn is None:
        conn = _connect()
        _local.conn = conn
        logger.debug("커넥션 생성 thread=%s", threading.current_thread().name)
    return conn


def close_conn(exc=None) -> None:
    """teardown 에서 호출 — ★ 여기서 예외를 던지면 안 됨"""
    conn = getattr(_local, "conn", None)
    if conn is None:
        return
    _local.conn = None
    try:
        if exc is not None:
            conn.rollback()
        conn.close()
    except Exception:
        logger.warning("커넥션 정리 실패", exc_info=True)


@contextmanager
def session(write: bool = False):
    """★ 트랜잭션 컨텍스트 — Day 034 의 session() 을 스레드 대응으로 확장

    with session() as conn:              읽기
    with session(write=True) as conn:    쓰기 (자동 커밋/롤백)
    """
    conn = get_conn()
    if write:
        _write_lock.acquire()
    t0 = time.perf_counter()
    try:
        yield conn
        if write:
            conn.commit()
    except Exception:
        if write:
            try:
                conn.rollback()
            except Exception:
                logger.error("롤백 실패", exc_info=True)
        raise
    finally:
        if write:
            _write_lock.release()
        dt = (time.perf_counter() - t0) * 1000
        if dt > 200:                                # ★ 느린 트랜잭션 경고
            logger.warning("느린 트랜잭션 %.0fms (write=%s)", dt, write)


# ────────────────────────── 마이그레이션 ──────────────────────────

def migrate(conn: sqlite3.Connection) -> int:
    """★ user_version 기준으로 필요한 단계만 적용. 몇 번 실행해도 안전."""
    current = conn.execute("PRAGMA user_version").fetchone()[0]
    if current > TARGET_VERSION:
        raise RuntimeError(
            f"DB 스키마 버전이 코드보다 높습니다 "
            f"(DB={current}, 코드={TARGET_VERSION}). 코드를 갱신하세요.")
    if current == TARGET_VERSION:
        logger.debug("스키마 최신 (v%d)", current)
        return current

    for v in range(current + 1, TARGET_VERSION + 1):
        stmts = MIGRATIONS[v]
        logger.info("마이그레이션 v%d → v%d (%d문)", v - 1, v, len(stmts))
        try:
            for s in stmts:
                conn.execute(s)
            # ★ PRAGMA 는 바인딩 불가 — v 는 우리가 만든 정수라 안전
            conn.execute(f"PRAGMA user_version = {int(v)}")
            conn.commit()
        except Exception:
            conn.rollback()
            logger.critical("마이그레이션 v%d 실패 — 앱을 시작하지 않습니다", v)
            raise                                   # ★ 전파 (삼키면 안 됨)
    logger.info("스키마 v%d 준비 완료", TARGET_VERSION)
    return TARGET_VERSION


def init_app(app) -> None:
    """★ 앱 시작 시 1회 — 경로 설정 · 마이그레이션 · teardown 등록"""
    path = Path(app.config["DB_PATH"])
    path.parent.mkdir(parents=True, exist_ok=True)
    _state["path"] = str(path)
    _state["timeout"] = app.config.get("DB_TIMEOUT", 5.0)

    conn = _connect()
    try:
        mode = conn.execute("PRAGMA journal_mode").fetchone()[0]
        logger.info("DB 열기 %s (journal_mode=%s)", path, mode)
        if mode.lower() != "wal":
            logger.warning("WAL 모드가 아닙니다: %s "
                           "(네트워크 드라이브인지 확인하세요)", mode)
        migrate(conn)
    finally:
        conn.close()

    app.teardown_request(lambda exc: close_conn(exc))


def checkpoint() -> dict:
    """★ WAL 파일을 본체에 반영하고 잘라냄 (주기 작업용)"""
    with session(write=True) as conn:
        busy, log, ckpt = conn.execute(
            "PRAGMA wal_checkpoint(TRUNCATE)").fetchone()
    return {"busy": busy, "wal_pages": log, "checkpointed": ckpt}


def stats() -> dict:
    """DB 크기·행 수 요약"""
    p = Path(_state["path"])
    with session() as conn:
        ev = conn.execute("SELECT COUNT(*) FROM events").fetchone()[0]
        dt = conn.execute("SELECT COUNT(*) FROM detections").fetchone()[0]
        ver = conn.execute("PRAGMA user_version").fetchone()[0]
    wal = p.with_name(p.name + "-wal")
    return {
        "path": str(p), "schema_version": ver,
        "events": ev, "detections": dt,
        "db_mb": round(p.stat().st_size / 1024 / 1024, 2) if p.exists() else 0,
        "wal_mb": round(wal.stat().st_size / 1024 / 1024, 2)
                  if wal.exists() else 0,
    }
```

### Step 2. `web/models/event.py` — 저장 · 조회 · 집계

```python
"""web/models/event.py — 검출 이벤트 저장·조회·집계

★ 원칙
  · Detector 의 결과 dict 를 그대로 받는다
  · 기록 실패는 예외를 던지지 않는다 (None 반환 + WARNING)
  · 반환은 전부 dict (sqlite3.Row 를 밖으로 내보내지 않음)
"""
from __future__ import annotations

import json
import logging
import sqlite3
import uuid
from datetime import datetime, timedelta

from .. import db

logger = logging.getLogger("cctv.db.event")

SOURCES = ("upload", "stream", "api", "pi")


# ────────────────────────── 유틸 ──────────────────────────

def _row_to_dict(row: sqlite3.Row) -> dict:
    d = dict(row)
    if "counts_json" in d:
        try:
            d["counts"] = json.loads(d.pop("counts_json") or "{}")
        except json.JSONDecodeError:
            d["counts"] = {}
    return d


def day_start_epoch(day: str) -> float:
    """'2026-08-11' → 그날 00:00 의 epoch"""
    return datetime.strptime(day, "%Y-%m-%d").timestamp()


def day_end_epoch(day: str) -> float:
    """'2026-08-11' → ★ 다음날 00:00 의 epoch (경계 오류 방지)"""
    return (datetime.strptime(day, "%Y-%m-%d")
            + timedelta(days=1)).timestamp()


# ────────────────────────── 저장 ──────────────────────────

def record_event(*, source: str, result: dict,
                 image_path: str | None = None,
                 result_path: str | None = None,
                 thumb_path: str | None = None,
                 device_id: str | None = None,
                 event_uid: str | None = None,
                 ts: datetime | None = None) -> int | None:
    """★ 검출 결과를 events + detections 에 기록.

    Returns:
        event id (신규) · 기존 id (중복 uid) · None (실패)
    """
    if source not in SOURCES:
        logger.warning("알 수 없는 source=%r — 그대로 기록합니다", source)

    now = ts or datetime.now()
    uid = event_uid or uuid.uuid4().hex
    dets = result.get("detections") or []
    counts = result.get("counts_by_class") or {}
    top = max(dets, key=lambda d: d.get("conf", 0), default=None)
    timing = result.get("timing_ms") or {}
    model = result.get("model") or {}
    image = result.get("image") or {}

    row = (uid, now.isoformat(timespec="seconds"), now.timestamp(),
           source, device_id, image_path, result_path, thumb_path,
           int(image.get("width", 0)), int(image.get("height", 0)),
           len(dets),
           top["class_name"] if top else None,
           float(top["conf"]) if top else 0.0,
           json.dumps(counts, ensure_ascii=False),
           float(timing.get("infer", 0.0)), float(timing.get("total", 0.0)),
           model.get("name"), model.get("conf"), model.get("iou"))

    try:
        with db.session(write=True) as conn:
            cur = conn.execute(
                """INSERT OR IGNORE INTO events
                   (event_uid, ts, ts_epoch, source, device_id,
                    image_path, result_path, thumb_path, width, height,
                    det_count, top_class, max_conf, counts_json,
                    infer_ms, total_ms, model_name, conf_thres, iou_thres)
                   VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)""", row)
            if cur.rowcount == 0:                   # ★ 멱등 — 이미 있음
                existing = conn.execute(
                    "SELECT id FROM events WHERE event_uid = ?",
                    (uid,)).fetchone()
                logger.info("중복 이벤트 uid=%s → id=%s",
                            uid, existing["id"] if existing else None)
                return existing["id"] if existing else None

            event_id = cur.lastrowid
            if dets:
                conn.executemany(
                    """INSERT INTO detections
                       (event_id, class_id, class_name, conf, x1,y1,x2,y2)
                       VALUES (?,?,?,?,?,?,?,?)""",
                    [(event_id, int(d.get("class_id", -1)),
                      str(d.get("class_name", "?")), float(d.get("conf", 0)),
                      *[float(v) for v in d.get("box", [0, 0, 0, 0])])
                     for d in dets])
        logger.info("이벤트 기록 id=%d source=%s 검출 %d건 %.0fms",
                    event_id, source, len(dets), timing.get("total", 0.0))
        return event_id
    except Exception:
        # ★ 기록 실패로 검출 응답까지 막지 않습니다
        logger.error("이벤트 기록 실패 uid=%s source=%s", uid, source,
                     exc_info=True)
        return None


# ────────────────────────── 조회 ──────────────────────────

def _build_where(date_from=None, date_to=None, cls=None,
                 min_conf=None, source=None) -> tuple[str, list]:
    where, params = ["1=1"], []
    if date_from:
        where.append("e.ts_epoch >= ?"); params.append(day_start_epoch(date_from))
    if date_to:
        where.append("e.ts_epoch < ?");  params.append(day_end_epoch(date_to))
    if source:
        where.append("e.source = ?");    params.append(source)
    if cls:
        # ★ EXISTS 가 JOIN+DISTINCT 보다 빠릅니다
        sub = ("EXISTS (SELECT 1 FROM detections d "
               "WHERE d.event_id = e.id AND d.class_name = ?")
        params.append(cls)
        if min_conf:
            sub += " AND d.conf >= ?"; params.append(float(min_conf))
        where.append(sub + ")")
    elif min_conf:
        where.append("e.max_conf >= ?"); params.append(float(min_conf))
    return " AND ".join(where), params


def list_events(*, page=1, per_page=20, **filters) -> dict:
    """★ 페이지 번호 방식 (OFFSET). page 는 500 으로 상한."""
    page = max(1, min(int(page), 500))              # ★ 깊은 OFFSET 차단
    per_page = max(1, min(int(per_page), 100))
    where, params = _build_where(**filters)
    offset = (page - 1) * per_page

    with db.session() as conn:
        rows = conn.execute(
            f"""SELECT e.* FROM events e WHERE {where}
                ORDER BY e.ts_epoch DESC, e.id DESC
                LIMIT ? OFFSET ?""",
            params + [per_page + 1, offset]).fetchall()   # ★ +1 로 다음 확인
        has_next = len(rows) > per_page
        rows = rows[:per_page]
        total = conn.execute(
            f"""SELECT COUNT(*) FROM (SELECT 1 FROM events e
                WHERE {where} LIMIT 1001)""", params).fetchone()[0]

    return {"items": [_row_to_dict(r) for r in rows],
            "page": page, "per_page": per_page,
            "has_next": has_next, "has_prev": page > 1,
            "total": total, "total_capped": total > 1000}


def list_events_keyset(*, cursor=None, limit=20, **filters) -> dict:
    """★ 키셋 페이지네이션 — 몇 페이지든 같은 속도"""
    limit = max(1, min(int(limit), 100))
    where, params = _build_where(**filters)
    if cursor:
        try:
            ts_s, id_s = cursor.split("_")
            where += " AND (e.ts_epoch < ? OR (e.ts_epoch = ? AND e.id < ?))"
            params += [float(ts_s), float(ts_s), int(id_s)]
        except (ValueError, AttributeError):
            raise ValueError(f"잘못된 커서: {cursor!r}")

    with db.session() as conn:
        rows = conn.execute(
            f"""SELECT e.* FROM events e WHERE {where}
                ORDER BY e.ts_epoch DESC, e.id DESC LIMIT ?""",
            params + [limit + 1]).fetchall()

    has_next = len(rows) > limit
    rows = rows[:limit]
    next_cursor = (f"{rows[-1]['ts_epoch']}_{rows[-1]['id']}"
                   if rows and has_next else None)
    return {"items": [_row_to_dict(r) for r in rows],
            "next_cursor": next_cursor, "has_next": has_next}


def get_event(event_id: int) -> dict | None:

def daily_counts(days: int = 14, **filters) -> list[dict]:
    """★ 일별 검출 건수 — 데이터가 없는 날도 0 으로 채움"""
    end = datetime.now().replace(hour=0, minute=0, second=0, microsecond=0)
    start = end - timedelta(days=days - 1)
    where, params = _build_where(**filters)
    with db.session() as conn:
        rows = conn.execute(
            f"""SELECT date(e.ts) AS day, COUNT(*) AS n,
                       SUM(e.det_count) AS dets
                FROM events e
                WHERE {where} AND e.ts_epoch >= ?
                GROUP BY day ORDER BY day""",
            params + [start.timestamp()]).fetchall()
    found = {r["day"]: (r["n"], r["dets"] or 0) for r in rows}
    out = []
    for i in range(days):
        d = (start + timedelta(days=i)).strftime("%Y-%m-%d")
        n, dets = found.get(d, (0, 0))
        out.append({"day": d, "n": n, "dets": dets})
    return out


def hourly_heatmap(days: int = 14, **filters) -> dict:
    """★ 요일(0=일) × 시(0~23) 격자"""
    since = (datetime.now() - timedelta(days=days)).timestamp()
    where, params = _build_where(**filters)
    with db.session() as conn:
        rows = conn.execute(
            f"""SELECT CAST(strftime('%w', e.ts) AS INTEGER) AS dow,
                       CAST(strftime('%H', e.ts) AS INTEGER) AS hour,
                       COUNT(*) AS n
                FROM events e WHERE {where} AND e.ts_epoch >= ?
                GROUP BY dow, hour""",
            params + [since]).fetchall()
    grid = [[0] * 24 for _ in range(7)]
    for r in rows:
        grid[r["dow"]][r["hour"]] = r["n"]
    peak = max((max(row) for row in grid), default=0)
    return {"grid": grid, "peak": peak, "days": days}


def class_summary(**filters) -> list[dict]:
    """클래스별 건수·평균 신뢰도"""
    where, params = _build_where(**filters)
    with db.session() as conn:
        rows = conn.execute(
            f"""SELECT d.class_name, COUNT(*) AS n,
                       ROUND(AVG(d.conf), 3) AS avg_conf,
                       ROUND(MAX(d.conf), 3) AS max_conf
                FROM detections d JOIN events e ON e.id = d.event_id
                WHERE {where}
                GROUP BY d.class_name ORDER BY n DESC""", params).fetchall()
    total = sum(r["n"] for r in rows) or 1
    return [{**dict(r), "ratio": round(r["n"] / total, 4)} for r in rows]


def perf_summary(days: int = 7) -> dict:

    return dict(row)
```

```python
from __future__ import annotations

import contextvars
import json
import logging
import logging.handlers

import uuid
from pathlib import Path

from flask import g, request

# ★ 스레드·요청 어디서든 읽히는 요청 ID
request_id_var = contextvars.ContextVar("request_id", default="-")

_SKIP_PATHS = ("/static/", "/favicon.ico")
_QUIET_LOGGERS = {
    "werkzeug": logging.WARNING,
    "urllib3": logging.WARNING,
    "PIL": logging.WARNING,
    "matplotlib": logging.WARNING,
    "ultralytics": logging.WARNING,
}

# LogRecord 기본 속성 — JSON 에 중복으로 넣지 않기 위한 목록
_STD = set(vars(logging.LogRecord("", 0, "", 0, "", (), None)).keys()) | {
    "message", "asctime", "taskName"}


class RequestIdFilter(logging.Filter):
    """★ 모든 레코드에 request_id 를 주입"""

    def filter(self, record):
        if not hasattr(record, "request_id"):
            record.request_id = request_id_var.get()
        return True                                  # ★ 반드시 True


class JsonFormatter(logging.Formatter):
    """★ 한 줄 = JSON 하나 (JSON Lines)"""

    def format(self, record):
        out = {
            "ts": time.strftime("%Y-%m-%dT%H:%M:%S",
                                time.localtime(record.created))
                  + f".{int(record.msecs):03d}",
            "level": record.levelname,
            "logger": record.name,
            "msg": record.getMessage(),
            "request_id": getattr(record, "request_id", "-"),
            "thread": record.threadName,
        }
        if record.exc_info:
            out["exc"] = self.formatException(record.exc_info)
        # ★ extra 로 넘어온 사용자 필드를 그대로 붙임
        for k, v in record.__dict__.items():
            if k not in _STD and k not in out:
                try:
                    json.dumps(v)
                    out[k] = v
                except (TypeError, ValueError):
                    out[k] = repr(v)
        return json.dumps(out, ensure_ascii=False)


def setup_logging(app) -> None:
    """★ 앱 시작 시 1회. basicConfig 는 쓰지 않습니다."""
    log_dir = Path(app.config.get("LOG_DIR", "logs"))

    text_fmt = logging.Formatter(

    fh = logging.handlers.RotatingFileHandler(

    fh.setFormatter(text_fmt)
    fh.addFilter(rid_filter)
    root.addHandler(fh)

        backupCount=3, encoding="utf-8")
    eh.setLevel(logging.ERROR)
    eh.setFormatter(text_fmt)
    eh.addFilter(rid_filter)
    root.addHandler(eh)

    # ④ ★ 구조화 로그 (날짜 회전 — 집계용)

    jh.setLevel(logging.INFO)
    jh.setFormatter(JsonFormatter())
    jh.addFilter(rid_filter)
    root.addHandler(jh)

    app.logger.propagate = False
    for h in root.handlers:
        app.logger.addHandler(h)
    app.logger.setLevel(level)

    # ⑥ ★ 시끄러운 외부 로거 잠재우기
    for name, lv in _QUIET_LOGGERS.items():

    logging.getLogger("cctv").info(
        "로깅 시작 level=%s dir=%s handlers=%d",
        logging.getLevelName(level), log_dir, len(root.handlers))


def install_request_id(app) -> None:
    """★ 요청 ID 미들웨어 — before/after/teardown"""
    access = logging.getLogger("cctv.web.access")

    @app.before_request
    def _begin():
        rid = (request.headers.get("X-Request-ID")
               or uuid.uuid4().hex[:6])
        rid = "".join(c for c in rid if c.isalnum() or c in "-_")[:32] or "-"
        g.request_id = rid
        g.t0 = time.perf_counter()
        request_id_var.set(rid)

    @app.after_request
    def _end(resp):
        rid = g.get("request_id", "-")
        resp.headers["X-Request-ID"] = rid           # ★ 사용자에게 되돌려 줌
        if request.path.startswith(_SKIP_PATHS):     # ★ 정적 파일 제외
            return resp
        if request.path == "/video_feed":            # ★ 스트림은 한 줄만
            return resp
        dt = (time.perf_counter() - g.get("t0", time.perf_counter())) * 1000
        access.info("%s %s → %d", request.method, request.path,
                    resp.status_code,
                    extra={"http_method": request.method,
                           "http_path": request.path,
                           "http_status": resp.status_code,
                           "duration_ms": round(dt, 1),
                           "remote": request.remote_addr})
        if dt > 2000:                                # ★ 느린 요청 경고
            access.warning("느린 요청 %.0fms %s %s",
                           dt, request.method, request.path)
        return resp

    @app.teardown_request
    def _teardown(exc):
        request_id_var.set("-")
```

```python
"""web/resilience.py — 재시도 · 카메라 재연결 · 디스크 보호"""
from __future__ import annotations

import functools
import logging
import random
import shutil
import threading
import time

import cv2
import numpy as np

logger = logging.getLogger("cctv.resilience")


class StorageFullError(Exception):
    """디스크 여유 공간 부족 → HTTP 507"""


class CameraUnavailable(Exception):
    """카메라를 열 수 없음 → HTTP 503"""


# ────────────────────────── 재시도 ──────────────────────────

def backoff_delay(attempt: int, base=0.5, factor=2.0,
                  cap=30.0, jitter=0.2) -> float:
    """★ 지수 백오프 + 지터"""
    delay = min(base * (factor ** attempt), cap)
    return max(0.05, delay * (1.0 + random.uniform(-jitter, jitter)))


def retry(times=3, base=0.2, cap=5.0,
          exceptions=(Exception,), log=logger):
    """★ 일시적 실패에만 사용. 400 류에는 쓰지 마세요."""
    def deco(fn):
        @functools.wraps(fn)
        def wrapper(*args, **kw):
            last = None
            for i in range(times):
                try:
                    return fn(*args, **kw)
                except exceptions as e:
                    last = e
                    if i == times - 1:
                        break
                    d = backoff_delay(i, base=base, cap=cap)
                    log.warning("%s 실패(%d/%d) %.2fs 후 재시도: %s",
                                fn.__name__, i + 1, times, d, e)
                    time.sleep(d)
            log.error("%s 최종 실패 (%d회)", fn.__name__, times)
            raise last
        return wrapper
    return deco


# ────────────────────────── 디스크 ──────────────────────────

def disk_report(path) -> dict:
    total, used, free = shutil.disk_usage(path)
    return {"total_gb": round(total / 1024**3, 1),
            "free_gb": round(free / 1024**3, 2),
            "free_mb": round(free / 1024**2, 1),
            "used_pct": round(used / total * 100, 1)}


def ensure_free_space(path, need_mb=200) -> dict:
    """★ 저장 직전에 호출. 부족하면 StorageFullError"""
    rep = disk_report(path)
    if rep["free_mb"] < need_mb:
        logger.critical("디스크 여유 부족 %sMB (필요 %sMB) — 저장 거부",
                        rep["free_mb"], need_mb,
                        extra={"free_mb": rep["free_mb"],
                               "used_pct": rep["used_pct"]})
        raise StorageFullError(
            f"저장 공간이 부족합니다 (여유 {rep['free_mb']:.0f}MB)")
    if rep["used_pct"] >= 85:
        logger.warning("디스크 사용률 %.1f%% — 정리가 필요합니다",
                       rep["used_pct"], extra={"used_pct": rep["used_pct"]})
    return rep


# ────────────────────────── 카메라 ──────────────────────────

def placeholder_frame(text, w=640, h=480, color=(40, 40, 46)) -> np.ndarray:
    """★ 카메라가 없는 동안 보여줄 안내 프레임"""
    img = np.full((h, w, 3), color, np.uint8)
    cv2.putText(img, text, (30, h // 2),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (230, 230, 235), 2,
                cv2.LINE_AA)
    cv2.putText(img, time.strftime("%Y-%m-%d %H:%M:%S"),
                (30, h // 2 + 40), cv2.FONT_HERSHEY_SIMPLEX, 0.55,
                (150, 150, 160), 1, cv2.LINE_AA)
    return img


class ResilientCamera:
    """★ 끊겨도 스스로 다시 붙는 카메라

    · 캡처 스레드 1개가 최신 프레임만 유지 (Day 153 LatestFrameCapture 확장)
    · 실패하면 지수 백오프로 재연결
    · read() 는 절대 예외를 던지지 않는다 → (frame, ok) 반환
    """

    def __init__(self, src=0, width=1280, height=720, fps=30,
                 max_backoff=30.0):
        self.src, self.width, self.height, self.fps = src, width, height, fps
        self.max_backoff = max_backoff
        self._cap = None
        self._frame = None
        self._ok = False
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self.attempts = 0
        self.reconnects = 0
        self.frames = 0
        self._thread = threading.Thread(target=self._loop, daemon=True,
                                        name="camera-capture")
        self._thread.start()

    # ---- 내부 ----
    def _open(self) -> bool:
        try:
            cap = cv2.VideoCapture(self.src)
            if not cap.isOpened():
                cap.release()
                return False
            cap.set(cv2.CAP_PROP_FRAME_WIDTH, self.width)
            cap.set(cv2.CAP_PROP_FRAME_HEIGHT, self.height)
            cap.set(cv2.CAP_PROP_FPS, self.fps)
            cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)      # ★ 최신 프레임 우선
            self._cap = cap
            return True
        except Exception:
            logger.warning("카메라 열기 예외 src=%s", self.src, exc_info=True)
            return False

    def _release(self):
        if self._cap is not None:
            try:
                self._cap.release()
            except Exception:
                pass
            self._cap = None

    def _loop(self):
        while not self._stop.is_set():
            if self._cap is None:
                if self._open():
                    if self.attempts:
                        self.reconnects += 1
                        logger.info("카메라 재연결 성공 src=%s (시도 %d회)",
                                    self.src, self.attempts,
                                    extra={"src": str(self.src),
                                           "attempts": self.attempts})
                    else:
                        logger.info("카메라 연결 src=%s", self.src)
                    self.attempts = 0
                    with self._lock:
                        self._ok = True
                    continue
                d = backoff_delay(self.attempts, cap=self.max_backoff)
                self.attempts += 1
                with self._lock:
                    self._ok = False
                if self.attempts <= 3 or self.attempts % 10 == 0:
                    logger.warning("카메라 연결 실패 — %.1fs 후 재시도",
                                   d, extra={"src": str(self.src),
                                             "attempt": self.attempts,
                                             "backoff_s": round(d, 2)})
                self._stop.wait(d)
                continue

            try:
                ok, frame = self._cap.read()
            except Exception:
                logger.warning("read() 예외 — 카메라를 다시 엽니다",
                               exc_info=True)
                ok, frame = False, None

            if not ok or frame is None:
                logger.warning("프레임 수신 실패 — 카메라를 다시 엽니다")
                self._release()
                continue

            with self._lock:
                self._frame = frame
                self._ok = True
            self.frames += 1

    # ---- 공개 ----
    def read(self):
        """★ 예외를 던지지 않습니다. (frame, ok)"""
        with self._lock:
            if self._frame is None:
                return placeholder_frame("카메라를 찾는 중..."), False
            return self._frame.copy(), self._ok

    @property
    def available(self) -> bool:
        with self._lock:
            return self._ok and self._frame is not None

    def status(self) -> dict:
        return {"src": str(self.src), "available": self.available,
                "frames": self.frames, "reconnects": self.reconnects,
                "attempts": self.attempts}

    def stop(self):
        self._stop.set()
        self._thread.join(timeout=2.0)
        self._release()
```

**스트리밍 제너레이터 — 프레임 단위 try + 연속 실패 카운터**

Day 163 `stream.py` 에서 **`gen_frames` 만 갈아 끼웁니다.**
`_encode` · `_part` · `_draw` 와 `/video_feed` · `/live` 라우트는 그대로 둡니다.

```python
"""web/blueprints/stream.py — 프레임 루프 개정"""
MAX_FAIL_STREAK = 5          # ★ 연속 실패 상한
RECORD_COOLDOWN = 10.0       # ★ 같은 클래스 재기록 최소 간격(초)


def gen_frames(camera, detector, skip=2, conf=0.45):
    fail_streak = 0
    idx = 0
    last_result = None
    last_record = {}
    while True:
        try:
            frame, ok = camera.read()
            if not ok:
                # ★ 카메라가 없어도 스트림은 유지 (안내 프레임)
                yield _part(_encode(frame))
                time.sleep(0.5)
                continue

            idx += 1
            if idx % skip == 0:
                last_result = detector.predict_image(frame, conf=conf)
                _maybe_record(last_result, frame, last_record)
            jpg = _encode(_draw(frame, last_result))
            fail_streak = 0                     # 성공하면 리셋
            yield _part(jpg)

        except GeneratorExit:                   # 브라우저가 끊음 — 정상
            logger.info("스트림 종료 (클라이언트 연결 해제) 프레임=%d", idx)
            return
        except Exception:
            fail_streak += 1
            logger.warning("프레임 처리 실패 (연속 %d/%d)",
                           fail_streak, MAX_FAIL_STREAK, exc_info=True,
                           extra={"fail_streak": fail_streak})
            if fail_streak >= MAX_FAIL_STREAK:
                logger.error("연속 실패 %d회 — 스트림을 중단합니다", fail_streak)
                yield _part(_encode(placeholder_frame("스트림 오류 — 새로고침")))
                return
            yield _part(_encode(placeholder_frame("일시 오류, 복구 중...")))
            time.sleep(0.3)


def _maybe_record(result, frame, last_record):
    """★ 쿨다운 — 30 FPS 를 그대로 기록하면 하루 259만 행"""
    if not result or not result.get("detections"):
        return
    now = time.time()
    cls = max(result["detections"], key=lambda d: d["conf"])["class_name"]
    if now - last_record.get(cls, 0) < RECORD_COOLDOWN:
        return
    last_record[cls] = now
    try:
        event_model.record_event(source="stream", result=result)
    except Exception:
        logger.warning("스트림 이벤트 기록 실패", exc_info=True)
```

```python
def _respond(code, error, message):
    g.error_logged = True
    if _is_api():
        return jsonify({"error": error, "message": message,
                        "request_id": g.get("request_id")}), code

def register_error_handlers(app):
    @app.errorhandler(StorageFullError)
    def _storage(e):
        return _respond(507, "insufficient_storage", str(e))

    @app.errorhandler(CameraUnavailable)
    def _camera(e):
        logger.warning("카메라 사용 불가: %s", e)
        return _respond(503, "camera_unavailable", "카메라를 사용할 수 없습니다")

    @app.errorhandler(HTTPException)              # ★ 404 · 413 등
    def _http(e):
        if _is_api():
            return jsonify({"error": e.name.lower().replace(" ", "_"),
                            "message": e.description,
                            "request_id": g.get("request_id")}), e.code
        try:
            return render_template(f"errors/{e.code}.html", error=e), e.code
        except Exception:
            return render_template("errors/generic.html", code=e.code,
                                   message=e.description), e.code

    @app.errorhandler(Exception)                  # ★ 마지막 그물
    def _unexpected(e):
        logger.exception("처리되지 않은 예외: %r", e)
        g.error_logged = True
        if _is_api():
            return jsonify({"error": "internal_error",
```

### Step 7. 고아 파일 · 고아 레코드 탐지

```python
"""web/tools/check_orphans.py — DB 와 파일의 정합성 점검

사용법
  python -m web.tools.check_orphans              # 점검만
  python -m web.tools.check_orphans --fix        # 고아 파일 삭제
  python -m web.tools.check_orphans --days 7 --fix   # + 만료 정리
"""
from __future__ import annotations

import logging
import time
from pathlib import Path

from web.models import event as event_model

logger = logging.getLogger("cctv.tools.orphans")

GRACE_SEC = 3600            # ★ 1시간 이내에 만들어진 파일은 건드리지 않음
SCAN_DIRS = ("uploads", "results", "snapshots", "thumbs")


def scan(static_root: Path) -> dict:
    """DB 참조 목록과 디스크를 대조해 양쪽 고아를 찾는다"""
    referenced = event_model.all_referenced_paths()
    now = time.time()

    files_on_disk, orphan_files, skipped = set(), [], 0
    for sub in SCAN_DIRS:
        d = static_root / sub
        if not d.exists():
            continue
        for p in d.rglob("*"):
            if not p.is_file():
                continue
            rel = p.relative_to(static_root).as_posix()
            files_on_disk.add(rel)
            if rel in referenced:
                continue
            if now - p.stat().st_mtime < GRACE_SEC:   # ★ 경쟁 조건 방지
                skipped += 1
                continue
            orphan_files.append((rel, p.stat().st_size))

    return {
        "referenced": len(referenced),
        "on_disk": len(files_on_disk),
        "orphan_files": orphan_files,
        "orphan_files_mb": round(
            sum(s for _, s in orphan_files) / 1024 / 1024, 2),
        "orphan_records": sorted(referenced - files_on_disk),
        "skipped_recent": skipped,
    }


def purge_expired(static_root: Path, days: int) -> tuple[int, int]:
    """★ DB 를 먼저 지우고 파일을 나중에 지웁니다 (중단돼도 고아 파일만 남음)"""
    expired = event_model.find_expired(days)
    paths = [v for r in expired
             for v in (r["image_path"], r["result_path"], r["thumb_path"]) if v]
    event_model.delete_events([r["id"] for r in expired])       # ① DB 먼저
    removed = 0
    for rel in paths:                                           # ② 파일 나중
        p = static_root / rel
        try:
            if p.exists():
                p.unlink()
                removed += 1
        except OSError:
            logger.warning("파일 삭제 실패: %s", p)
    return len(expired), removed
```

```
     · 일별 막대 그래프 · 시간대 히트맵 · 클래스별 요약
     · ★ 외부 라이브러리 없이 CSS 만으로

9. 정리 정책을 구현합니다.
     · DB 먼저, 파일 나중 · 고아 파일·레코드 탐지 · 유예 시간 1시간

10. 장애 주입 테스트를 8가지 이상 수행하고 결과표를 만듭니다.
     · 카메라 뽑기 · 디스크 채우기 · DB 잠그기 필수
```

**제출물**

- [ ] `web/db.py` (WAL · 마이그레이션 · 스레드별 커넥션)
- [ ] `web/models/event.py` (저장 · 조회 · 집계)
- [ ] `web/logging_config.py` (회전 · JSON · 요청 ID)
- [ ] `web/resilience.py` (백오프 · 재연결 · 디스크)
- [ ] ★ **`/events` 이력 페이지** (필터 + 페이지네이션)
- [ ] ★ **`/stats` 통계 페이지** (CSS 그래프)
- [ ] 고아 탐지 스크립트 실행 결과
- [ ] ★ **장애 주입 결과표** (8가지 이상)
- [ ] ★ **안정성 테스트 20개 이상** (전부 통과)
- [ ] `logs/app.jsonl` 하루치 + 집계 결과

**체크리스트**

- [ ] 실패 지점 목록을 **문서로** 만들었다
- [ ] **스트리밍이 프레임 단위 try** 로 감싸져 있고 **연속 실패 카운터**가 성공 시 리셋된다
- [ ] 카메라를 뽑았다 꽂으면 **자동으로 복구**된다 (지수 백오프 + 지터)
- [ ] `except Exception: pass` 와 `print` 가 **한 곳도 없다**
- [ ] 로거 이름이 **계층 구조**다 (`cctv.*`)
- [ ] **로그 파일이 회전**하고 상한이 예측 가능하다
- [ ] **JSON 구조화 로그**가 있다
- [ ] **요청 ID** 가 로그에 있고 응답 헤더로 돌아온다
- [ ] 운영에서 `werkzeug` 접근 로그를 껐다
- [ ] `journal_mode` 가 **WAL** 이고 `busy_timeout` 이 설정되어 있다
- [ ] `foreign_keys` 를 **ON** 으로 켰다
- [ ] 커넥션이 **스레드마다** 있고 `teardown` 에서 닫힌다
- [ ] 트랜잭션 안에 **추론·파일 I/O 가 없다**
- [ ] `user_version` 마이그레이션이 **두 번 실행해도 안전**하다
- [ ] 인덱스가 있고 `EXPLAIN QUERY PLAN` 에 `SEARCH` 가 나온다
- [ ] 날짜 끝을 **다음날 0시 미만**으로 비교하고 `OFFSET` 에 **상한**이 있다
- [ ] **이력 기록 실패가 검출 응답을 막지 않는다**
- [ ] 디스크 여유를 **저장 전에** 확인한다
- [ ] 정리가 **DB 먼저, 파일 나중** 순서이고 **유예 시간**이 있다
- [ ] 장애를 **일부러 일으켜 보았다**
