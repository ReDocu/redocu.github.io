## ③ 개념 설명

### ★ 통합이 어려운 이유 — "제 컴퓨터에서는 됩니다"

```
개발 중                              통합 시
┌─────────────┐                    ┌─────────────┐
│  내 노트북  │                    │  내 노트북  │
│  내 파이썬  │  ← 여기서만 검증   │  팀원 노트북│
│  내 경로    │                    │ 라즈베리파이│
│  내 데이터  │                    │  서버       │
└─────────────┘                    └─────────────┘
                                    ★ 4개 환경의 교집합에서만 동작
```

**★ 소프트웨어는 "동작한다"가 아니라 "어떤 환경에서 동작한다"입니다.**

각자 개발할 때는 환경이 **하나**였습니다. 통합하면 환경이 **네 개**가 되고,
네 환경이 조금씩 다른 지점마다 버그가 하나씩 생깁니다.

```
버그 개수 ≈ (환경 차이의 수) × (경계면의 수)

  우리 프로젝트
    환경 차이   : 파이썬 버전 · 패키지 버전 · OS · 경로 구분자 · 시각대
    경계면      : 웹↔모델 · 파이↔모델 · 파이↔서버 · 서버↔DB · 서버↔웹
    ★ 5 × 5 = 25개의 잠재 지점
```

### 통합 실패의 전형적 원인 8가지

| # | 원인 | 증상 | 언제 터지나 | 점검 방법 |
|---|---|---|---|---|
| 1 | **경로 가정** | `FileNotFoundError` · 검출 0건 | 다른 폴더에서 실행할 때 | 절대경로 출력 |
| 2 | **파이썬·패키지 버전** | `ImportError` · 결과 미세 차이 | 다른 PC 에서 | `pip freeze` 대조 |
| 3 | **클래스 ID 순서** | **라벨이 뒤바뀜** | 클래스를 추가·정렬한 뒤 | ID→이름 표 대조 |
| 4 | **좌표 형식** | 박스가 엉뚱한 곳에 | 모듈 간 전달 시 | 그려서 눈으로 |
| 5 | **시각대(timezone)** | 이벤트가 9시간 뒤에 뜸 | 파이↔서버 연결 시 | ISO 문자열 확인 |
| 6 | **인코딩** | 한글 깨짐 · `UnicodeDecodeError` | Windows↔Linux | `encoding="utf-8"` 명시 |
| 7 | **대소문자** | `IMG_001.JPG` 를 못 찾음 | Windows↔Linux | 소문자 통일 |
| 8 | **상대경로** | 실행 위치에 따라 결과가 다름 | systemd·cron 실행 시 | `Path(__file__)` 기준 |

**원인 1 — 경로 가정**

```python

det = Detector("models/best.pt")

# ✓ 파일 위치 기준 — ★ 어디서 실행해도 같음
ROOT = Path(__file__).resolve().parents[1]
det = Detector(ROOT / "models/best.pt")
```

```
★ systemd 로 실행하면 작업 디렉터리가 / 입니다
   상대경로는 전부 깨집니다 ([Day 170](day-170.md)에서 이미 겪은 문제)
```

**원인 2 — 파이썬·패키지 버전**

```
실제 사례 — numpy 2.x 문제
  파이 numpy 2.1.3 (apt 최신) · 서버 numpy 1.26.4 (requirements 고정)
  cv2 가 numpy 2.x 로 빌드되지 않았으면 ★ import 자체가 실패합니다

  AttributeError: _ARRAY_API not found
  A module that was compiled using NumPy 1.x cannot be run in NumPy 2.x
```

> ⚠️ **패키지 버전은 "최신"이 아니라 "같은 것"이 중요합니다.**
> 오늘 `requirements.lock` 을 만들어 네 환경을 맞춥니다.

**원인 4 — 좌표 형식**

```
모듈 A: [x1,y1,x2,y2] 픽셀  ↔  모듈 B: [cx,cy,w,h] 정규화
→ ★ 예외 없이 조용히 틀립니다
→ 박스가 왼쪽 위 구석에 아주 작게 그려지면 이 문제입니다
```

**원인 5 — 시각대**

```python
# 파이 (Raspberry Pi OS 는 초기 설정이 UTC 인 경우가 많습니다)
datetime.now().isoformat()      # '2026-08-11T05:30:22'  ★ 실제로는 14:30
# 서버 (KST)

# 웹의 '오늘' 필터 → 밤 이벤트가 새벽으로 밀리고, 자정 근처는 아예 사라집니다

# 해결 — 타임존을 붙여서 보냅니다
KST = timezone(timedelta(hours=9))
ts = datetime.now(KST).isoformat(timespec="seconds")
# → '2026-08-11T14:30:22+09:00'  ★ 오프셋 포함
```

### ★ 원인 ③ 을 따로 봅니다 — 클래스 ID 순서 불일치

**오늘 가장 많이 터지고, 가장 늦게 발견되는 버그입니다.**

```
data.yaml (Day 172 최종)
  names:
    0: person
    1: helmet
    2: box

웹 담당이 Day 174 에 만든 화면
  CLASS_LABELS = ['box', 'helmet', 'person']    ← ★ 알파벳 순으로 정렬함
  label = CLASS_LABELS[det['class_id']]

결과
  모델이 class_id=0 (person) 을 주면
  → 웹은 CLASS_LABELS[0] = 'box' 라고 표시
  → ★ 사람이 지나갔는데 "상자 감지"
```

**왜 늦게 발견되는가**

```
① 예외가 안 납니다. 인덱스가 유효하니까요.
② 검출 개수도 맞습니다.
③ ★ 이름만 틀립니다.
④ 개발자는 "박스가 잘 그려졌네" 하고 넘어갑니다.
⑤ 발표 때 심사위원이 "저건 사람 아닌가요?" 하고 물어봅니다.
```

**★ 이 버그가 생기는 세 가지 경로**

| 경로 | 상황 |
|---|---|
| ① 정렬 | 누군가 클래스 목록을 **알파벳 순으로 정렬**했다 |
| ② 추가 | 클래스를 추가하면서 **중간에 끼워 넣었다** (`['person','forklift','helmet','box']`) |
| ③ 하드코딩 | 웹·파이가 **자기만의 목록을 따로 들고 있다** |

**★ 해결 원칙 — 이름의 출처는 하나뿐이다**

```
        ┌──────────────────┐
        │   data.yaml      │  ★ 단 하나의 진실
        │   names:         │
        └────────┬─────────┘
                 │ 학습 시 모델에 구워짐
                 ▼
        ┌──────────────────┐
        │  best.pt         │
        │  model.names     │  ★ 여기서 읽는다
        └────────┬─────────┘
                 │ detector.py 가 이름까지 넣어서 반환
                 ▼
   ┌──────────────────────────────────┐
   │  웹  ·  파이  ·  알림            │
   │  이름 사용 · ★ ID→이름 변환 금지 │
   └──────────────────────────────────┘
```

```python
# ✗ 각자 목록을 들고 있음
CLASS_LABELS = ['box', 'helmet', 'person']
name = CLASS_LABELS[det['class_id']]

# ✓ 응답에 들어 있는 이름을 그대로 씀
name = det['class_name']
```

> ⚠️ **`class_id` 로 무언가를 판단하는 코드는 전부 위험합니다.**
> `if cid == 0:` 대신 `if name == "person":` 을 쓰세요.
> ID 는 재학습 한 번에 바뀔 수 있지만 이름은 안 바뀝니다.

### 인터페이스 계약을 실제 데이터로 검증한다

[Day 154](day-154.md)에 만들고 [Day 169](day-169.md)에서 파이–서버 구간을 추가한
`docs/INTERFACES.md` 가 오늘의 기준 문서입니다.

```
docs/INTERFACES.md — 계약 목록

  I-01  detector.predict_image()  →  표준 응답 dict
  I-02  configs/inference.yaml    →  프로파일 구조
  I-03  events 테이블 스키마      →  SQLite
  I-04  POST /api/events          →  파이 → 서버 (멱등)
  I-05  GET  /api/events          →  웹 → 서버 조회
  I-06  스냅샷 파일명 규칙        →  YYYY/MM/DD/<uuid>.jpg
  I-07  알림 메시지 형식          →  텔레그램
```

**★ 계약서는 읽는 문서가 아니라 검증하는 문서입니다.**
읽기만 하면 각자 "네, 그렇게 만들었습니다" 하고 서로 다르게 이해합니다.
실제 데이터로 I-04 를 검증하면 `event.ts` 에 오프셋이 없다는 것이 그 자리에서 드러납니다.

**계약 위반의 3가지 형태**

| 형태 | 예 | 잡는 법 |
|---|---|---|
| **필드 누락** | `class_name` 이 없음 | 필수 키 검사 |
| **타입 불일치** | `conf` 가 문자열 `"0.83"` | 타입 검사 |
| **의미 불일치** | `ts` 는 있는데 UTC | **값 범위·형식 검사** |

```
★ 셋 중 ③번이 가장 무섭습니다
  필드도 있고 타입도 맞는데 ★ 뜻이 다릅니다
  → 스키마 검증에서 "값의 규칙"까지 확인해야 잡힙니다
```

**우리가 쓸 검증기는 의존성 없이 직접 만듭니다.**

`jsonschema` 같은 패키지를 써도 되지만, 파이에 패키지를 하나 더 올리는 것보다
**의존성 없는 검증 함수 하나**가 통합에는 유리합니다. Step 5 에서 만듭니다.

### ★ 임계값 튜닝 ① — `conf` 를 정하는 두 가지 방법

```
방법 A — 검증셋 PR 곡선에서 고르기
  · 라벨이 있으니 P/R/F1 을 정확히 계산할 수 있다
  · ★ 빠르고 재현 가능
  · 단, ★ 검증셋 분포에서만 맞다

방법 B — 현장 프레임(무라벨)으로 고르기
  · 실제 설치 화면 30분 영상을 돌려 본다
  · 오탐이 몇 번 뜨는지 ★ 눈으로 센다
  · 느리지만 진짜 운영 조건
```

**★ 둘 다 합니다. 순서가 있습니다.**

```
① 방법 A 로 후보를 3개로 좁힌다      (0.25 / 0.35 / 0.45)
② 방법 B 로 후보 3개를 현장 영상에 돌린다
③ 성공 기준(오탐 ≤ 5건/일)을 통과하는 것 중 재현율이 가장 높은 값
```

**지표 선택 — F1 이 항상 답은 아닙니다**

| 지표 | 식 | 무엇을 중시하나 | 우리 용도 |
|---|---|---|---|
| Precision | TP/(TP+FP) | 오탐 없음 | 카운팅 |
| Recall | TP/(TP+FN) | 놓치지 않음 | 침입 감지 |
| **F1** | 2PR/(P+R) | 균형 | 기본값 |
| **F2** | 5PR/(4P+R) | **재현율 2배 가중** | 침입 감지 |
| **F0.5** | 1.25PR/(0.25P+R) | **정밀도 2배 가중** | 방문객 카운팅 |

```
★ β 의 의미
  F_β 에서 β 는 "재현율을 정밀도보다 몇 배 중요하게 볼 것인가"입니다

  β = 2   → 재현율이 2배 중요  (놓치면 큰일)
  β = 1   → 같음
  β = 0.5 → 정밀도가 2배 중요  (틀리면 큰일)
```

### ★ 임계값 튜닝 ② — 주제가 최적점을 정한다

**같은 모델, 같은 데이터인데 팀마다 답이 다릅니다.**

| | 주제 A — 야간 무단 침입 감지 | 주제 B — 매장 방문객 카운팅 |
|---|---|---|
| 놓치면 | 침입자가 그냥 들어옵니다. 시스템 존재 이유 상실 | 숫자가 조금 적게 나옵니다. 추세는 유지 |
| 오탐이면 | 관리자가 스냅샷 한 장 더 봅니다. 귀찮을 뿐 | 없는 손님이 세어집니다. 통계가 통째로 거짓 |
| 결론 | **재현율 우선 → conf 0.25~0.30** | **정밀도 우선 → conf 0.50~0.60** |
| 지표 · 제약 | F2 · 야간 오탐 ≤ 5건/일 | F0.5 · 과다 카운트 ≤ 3% |

**[Day 171](day-171.md) 성공 기준과 연결됩니다**

| 팀 주제 | Day 171 성공 기준 | 오늘 정할 값 |
|---|---|---|
| 무단 침입 감지 | 침입 놓침 0건 · 오탐 ≤ 5건/일 | conf **0.30** · F2 최대화 |
| 방문객 카운팅 | 실제 대비 오차 ≤ ±5% | conf **0.50** · F0.5 최대화 |
| 안전모 미착용 | 미착용 놓침 ≤ 1건/일 | conf **0.35** (helmet 만 별도) |
| 반려동물 이상행동 | 오알림 ≤ 2건/일 | conf **0.45** + 체류시간 조건 |
| 화재·연기 조기 감지 | 놓침 0건 (오탐 감수) | conf **0.20** + 2차 확인 |

> ⚠️ **"우리는 정확한 게 좋으니 conf 를 높이겠습니다"는 근거가 아닙니다.**
> "우리 주제에서는 미검출이 오탐보다 N배 비싸다" 가 근거입니다.
> **비용의 비대칭**을 문장으로 쓸 수 있어야 임계값을 정할 수 있습니다.

**★ 클래스마다 다른 임계값을 줄 수도 있습니다**

```python
# 클래스별 임계값 — 모델 conf 는 낮게 두고 후처리에서 거른다
CLASS_CONF = {"person": 0.30, "helmet": 0.40, "box": 0.50}

res = det.predict_image(frame, conf=0.25)          # ★ 가장 낮은 값으로 한 번
dets = [d for d in res["detections"]
        if d["conf"] >= CLASS_CONF.get(d["class_name"], 0.25)]
```

```
★ 왜 이렇게 하는가
  모델을 여러 번 돌리지 않고 한 번만 돌립니다
  → 파이에서 ★ 속도 손해가 없습니다
```

### 임계값 튜닝 ③ — `iou`(NMS) 조정

```
NMS 는 "겹친 박스 중 점수 낮은 것을 지우는" 후처리입니다

  두 박스의 IoU > iou 임계값  →  ★ 낮은 쪽을 지운다

  iou 낮게 (0.45)  →  잘 지운다  →  중복 없음 · ★ 겹친 사람 놓침
  iou 높게 (0.80)  →  덜 지운다  →  겹친 사람 살림 · ★ 중복 박스
```

```
  창고 입구를 두 사람이 붙어서 지나가는 장면

  iou = 0.45                       iou = 0.70
  ┌──────────────┐                 ┌──────────────┐
  │   ┌────┐     │                 │  ┌────┐      │
  │   │사람2명│  │                 │ │사람││사람│ │
  │   └────┘     │                 │  └───┘└────┘ │
  │  ★ 1명만 검출│                 │  ★ 2명 검출  │
  └──────────────┘                 └──────────────┘
```

**우리 현장 영상 30분으로 측정한 결과**

| iou | 1인에 박스 2개 이상(중복) | 붙은 2인 중 1명 소실 | 판정 |
|---|---|---|---|
| 0.45 | 0건 | **11건** | ✗ 침입자를 놓침 |
| 0.50 | 0건 | 8건 | ✗ |
| 0.60 | 1건 | 3건 | 후보 |
| **0.70** | 4건 | **1건** | **침입 감지 채택** |
| 0.80 | 12건 | 0건 | ✗ 중복 과다 |

```
★ 주제별 판단이 여기서도 갈립니다

  침입 감지     : 중복 박스는 무해 (있다/없다만 판단) → ★ iou 0.70
  방문객 카운팅 : 중복 박스 = 과다 카운트             → ★ iou 0.55
```

> ⚠️ **`iou` 를 만지기 전에 `conf` 를 먼저 정하세요.**
> `conf` 를 바꾸면 후보 박스 수가 바뀌고, NMS 결과도 통째로 바뀝니다.
> **순서: conf → iou → max_det.**

책상 위 (지금까지)                실제 설치 (오늘부터)
  · 높이 0.75m                     · 높이 ★ 2.6m

**설치 시 결정할 것**

| 항목 | 결정 기준 | 우리 값 |
|---|---|---|
| 높이 | 얼굴이 정면으로 안 나오게(개인정보) · 가림 최소화 | 2.6m |
| 각도 | 관심 영역이 화면 중앙 60%에 들어오게 | 아래로 25° |

### Step 4. `tune_threshold.py` — 임계값 스윕

```python
"""tools/tune_threshold.py — conf 스윕으로 임계값을 결정한다

사용: python tools/tune_threshold.py --profile server --class person
      python tools/tune_threshold.py --profile pi --class person
"""
from __future__ import annotations

import argparse
import csv
import sys
from pathlib import Path

import cv2
import numpy as np

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "src"))
sys.path.insert(0, str(ROOT / "tools"))

from detector import get_detector, reset_detector          # noqa: E402
from config import class_names                             # noqa: E402
from detmatch import load_yolo_labels, match_one, prf      # noqa: E402

IMG_DIR = ROOT / "data/holdout_site/images"
LBL_DIR = ROOT / "data/holdout_site/labels"
OUT_DIR = ROOT / "experiments"
GRID = [0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40,
        0.45, 0.50, 0.55, 0.60, 0.65, 0.70]


def collect(det, target_id: int, iou_nms: float):
    """★ 가장 낮은 conf 로 ★ 한 번만 추론하고 결과를 재사용한다

    conf 를 13번 바꿔 13번 추론하면 60장 × 13 = 780회입니다.
    낮은 conf 로 한 번 뽑아 두고 파이썬에서 걸러내면 ★ 60회로 끝납니다.
    """
    cache = []
    for p in sorted(q for q in IMG_DIR.iterdir()
                    if q.suffix.lower() in (".jpg", ".jpeg", ".png")):
        img = cv2.imdecode(np.fromfile(str(p), np.uint8), cv2.IMREAD_COLOR)
        if img is None:
            raise ValueError(f"읽을 수 없습니다: {p}")     # 한글 경로 대응
        h, w = img.shape[:2]
        res = det.predict_image(img, conf=min(GRID), iou=iou_nms)
        preds = [{"class_id": d["class_id"], "conf": d["conf"],
                  "box": [d["box"]["x1"], d["box"]["y1"],
                          d["box"]["x2"], d["box"]["y2"]]}
                 for d in res["detections"] if d["class_id"] == target_id]
        gts = [g for g in load_yolo_labels(LBL_DIR / f"{p.stem}.txt", w, h)
               if g["class_id"] == target_id]
        cache.append((preds, gts))
    return cache


def sweep(cache) -> list[dict]:
    rows = []
    for conf in GRID:
        tot = [0, 0, 0]
        for preds, gts in cache:
            kept = [p for p in preds if p["conf"] >= conf]
            for i, v in enumerate(match_one(kept, gts, 0.5)):
                tot[i] += v
        m = prf(*tot)
        m["conf"] = conf
        rows.append(m)
    return rows


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--profile", default="server")
    ap.add_argument("--class", dest="cls", default="person")
    ap.add_argument("--iou", type=float, default=0.70)
    args = ap.parse_args()

    inv = {v: k for k, v in class_names().items()}
    if args.cls not in inv:
        raise SystemExit(f"클래스 '{args.cls}' 없음. 가능: {list(inv)}")
    target_id = inv[args.cls]

    reset_detector()
    det = get_detector(profile=args.profile)
    cache = collect(det, target_id, args.iou)
    total_gt = sum(len(g) for _, g in cache)

    print(f"프로파일 {args.profile} · 가중치 {Path(det.weights).name}")
    print(f"대상 {target_id}:{args.cls} · NMS iou={args.iou}")
    print(f"홀드아웃 {len(cache)}장 · 정답 {args.cls} {total_gt}개\n")

    rows = sweep(cache)
    b1 = max(rows, key=lambda r: r["f1"])["conf"]
    b2 = max(rows, key=lambda r: r["f2"])["conf"]
    b05 = max(rows, key=lambda r: r["f05"])["conf"]

    print("=" * 92)
    print(f"{'conf':>6}{'TP':>7}{'FP':>7}{'FN':>7}{'Precision':>12}"
          f"{'Recall':>10}{'F1':>9}{'F2(재현)':>11}{'F0.5(정밀)':>13}")
    print("-" * 92)
    for r in rows:
        mark = ("" + (" F2" if r["conf"] == b2 else "")
                + (" F1" if r["conf"] == b1 else "")
                + (" F0.5" if r["conf"] == b05 else ""))
        print(f"{r['conf']:>6.2f}{r['tp']:>7}{r['fp']:>7}{r['fn']:>7}"
              f"{r['precision']:>12.3f}{r['recall']:>10.3f}{r['f1']:>9.3f}"
              f"{r['f2']:>11.3f}{r['f05']:>13.3f}{mark}")
    print("=" * 92)
    print(f"\nF1  최대 conf = {b1:.2f}   (균형)")
    print(f"F2  최대 conf = {b2:.2f}   (재현율 우선 — 침입 감지)")
    print(f"F0.5 최대 conf = {b05:.2f}  (정밀도 우선 — 카운팅)")

    OUT_DIR.mkdir(parents=True, exist_ok=True)
    out = OUT_DIR / f"threshold_{args.profile}_{args.cls}.csv"
    with out.open("w", encoding="utf-8", newline="") as f:
        w = csv.DictWriter(f, fieldnames=list(rows[0]))
        w.writeheader()
        w.writerows(rows)
    print(f"\n저장: {out}")


if __name__ == "__main__":
    main()
```

```python
    # ────────────────── ★ 정식 이름: predict_image ──────────────────

    def predict_image(self, source, conf=None, iou=None,
                      classes=None) -> dict:
        """단일 이미지 검출 → ★ 동결된 표준 응답 dict (스키마 v1.1)

        source : str | Path | np.ndarray(BGR) | bytes | PIL.Image
        예외   : FileNotFoundError · ValueError · TypeError
        ★ 검출 0개는 예외가 아니라 count=0 인 정상 응답입니다.
        """
        t0 = time.perf_counter()
        img = self._load_image(source)
        t1 = time.perf_counter()

        use_conf = self.conf if conf is None else float(conf)
        use_iou = self.iou if iou is None else float(iou)

        r = self.model.predict(
            img, conf=use_conf, iou=use_iou,
            classes=self.classes if classes is None else list(classes),
            imgsz=self.imgsz, max_det=self.max_det,
            device=self.device, half=self.half, verbose=False)[0]
        t2 = time.perf_counter()

        h, w = img.shape[:2]
        dets = self._to_records(r, w, h)
        t3 = time.perf_counter()

        counts: dict[str, int] = {}
        for d in dets:
            counts[d["class_name"]] = counts.get(d["class_name"], 0) + 1

        return {
            "version": RESPONSE_VERSION,
            "module_version": MODULE_VERSION,
            "image": {"width": int(w), "height": int(h)},
            "model": {"weights": Path(self.weights).name,
                      "model_version": self.model_version,   # MODEL.json
                      "profile": self.profile,               # server | pi
                      "conf": round(use_conf, 4),
                      "iou": round(use_iou, 4),
                      "imgsz": int(self.imgsz)},
            "timing_ms": {"preprocess": round((t1 - t0) * 1000, 2),
                          "inference": round((t2 - t1) * 1000, 2),
                          "postprocess": round((t3 - t2) * 1000, 2),
                          "total": round((t3 - t0) * 1000, 2)},
            "count": len(dets),
            "counts_by_class": counts,
            "detections": dets,
        }

    # 하위호환 별칭 — 기존 코드가 안 깨지도록 남깁니다 (문서에서는 제거)
    def predict(self, source, conf=None, iou=None, classes=None) -> dict:
        return self.predict_image(source, conf=conf, iou=iou, classes=classes)

    def _to_records(self, result, w: int, h: int) -> list[dict]:
        """class 와 class_name 을 둘 다 넣습니다 (v1.1)"""
        out = []
        names = self.model.names
        for b in result.boxes:
            cid = int(b.cls)
            name = str(names[cid])                    # 모델이 가진 이름
            x1, y1, x2, y2 = (float(v) for v in b.xyxy[0].tolist())
            cx, cy, bw, bh = (float(v) for v in b.xywhn[0].tolist())
            pw, ph = x2 - x1, y2 - y1
            out.append({
                "class_id": cid,
                "class": name,                        # 하위호환 (v1.0)
                "class_name": name,                   # 정식 (v1.1)
                "conf": round(float(b.conf), 4),
                "box": {"x1": round(x1, 1), "y1": round(y1, 1),
                        "x2": round(x2, 1), "y2": round(y2, 1)},
                "box_norm": {"cx": round(cx, 6), "cy": round(cy, 6),
                             "w": round(bw, 6), "h": round(bh, 6)},
                "size": {"w": round(pw, 1), "h": round(ph, 1),
                         "area_ratio": round(pw * ph / (w * h) * 100, 3)},
            })
        out.sort(key=lambda d: -d["conf"])
        return out
```

```python
"""src/detector_schema.py — 응답 스키마 v1.1 검증"""
from __future__ import annotations

SCHEMA_VERSION = "1.1"

TOP = {"version": str, "module_version": str, "image": dict, "model": dict,
       "timing_ms": dict, "count": int, "counts_by_class": dict,
       "detections": list}
IMAGE = {"width": int, "height": int}
MODEL = {"weights": str, "model_version": str, "profile": str,
         "conf": float, "iou": float, "imgsz": int}
TIMING = {"preprocess": float, "inference": float,
          "postprocess": float, "total": float}
DET = {"class_id": int, "class": str, "class_name": str, "conf": float,
       "box": dict, "box_norm": dict, "size": dict}


class SchemaError(Exception):
    """★ 계약 위반 — 어디가 틀렸는지 경로까지 담는다"""


def _need(d, key, typ, where):
    if key not in d:
        raise SchemaError(f"{where}.{key} 누락")
    v = d[key]
    if typ is float and isinstance(v, int) and not isinstance(v, bool):
        return float(v)                        # ★ int 는 float 로 허용
    if isinstance(v, bool) or not isinstance(v, typ):
        raise SchemaError(f"{where}.{key} 타입 불일치 — {typ.__name__} 기대, "
                          f"{type(v).__name__} 받음 (값: {v!r})")
    return v


def validate_response(res: dict, strict_version: bool = True) -> None:
    """★ 위반이 있으면 SchemaError. 정상이면 조용히 반환."""
    if not isinstance(res, dict):
        raise SchemaError(f"응답이 dict 가 아닙니다: {type(res).__name__}")
    for k, t in TOP.items():
        _need(res, k, t, "response")
    if strict_version and res["version"] != SCHEMA_VERSION:
        raise SchemaError(f"스키마 버전 불일치 — {SCHEMA_VERSION} 기대, "
                          f"{res['version']} 받음")

    for src, spec, where in ((res["image"], IMAGE, "image"),
                             (res["model"], MODEL, "model"),
                             (res["timing_ms"], TIMING, "timing_ms")):
        for k, t in spec.items():
            _need(src, k, t, where)

    if res["model"]["profile"] not in ("server", "pi"):
        raise SchemaError(f"model.profile 값 오류: {res['model']['profile']}")
    if res["count"] < 0:
        raise SchemaError(f"count 음수: {res['count']}")
    if res["count"] != len(res["detections"]):
        raise SchemaError(f"count({res['count']}) 와 "
                          f"detections({len(res['detections'])}) 불일치")
    if sum(res["counts_by_class"].values()) != res["count"]:
        raise SchemaError("counts_by_class 합이 count 와 다릅니다")

    W, H = res["image"]["width"], res["image"]["height"]
    for i, d in enumerate(res["detections"]):
        where = f"detections[{i}]"
        for k, t in DET.items():
            _need(d, k, t, where)
        if d["class"] != d["class_name"]:
            raise SchemaError(f"{where}: class 와 class_name 이 다릅니다")
        if not 0.0 <= d["conf"] <= 1.0:
            raise SchemaError(f"{where}.conf 범위 오류: {d['conf']}")
        b = d["box"]
        for k in ("x1", "y1", "x2", "y2"):
            _need(b, k, float, f"{where}.box")
        if b["x2"] <= b["x1"] or b["y2"] <= b["y1"]:
            raise SchemaError(f"{where}.box 좌표 역전: {b}")
        if b["x1"] < -1 or b["y1"] < -1 or b["x2"] > W + 1 or b["y2"] > H + 1:
            raise SchemaError(f"{where}.box 가 이미지({W}×{H}) 밖: {b}")

    confs = [d["conf"] for d in res["detections"]]
    if confs != sorted(confs, reverse=True):
        raise SchemaError("detections 가 신뢰도 내림차순이 아닙니다")


def check(res: dict) -> tuple[bool, str]:
    """예외 대신 (ok, message) 로 받고 싶을 때"""
    try:
        validate_response(res)
        return True, "ok"
    except SchemaError as e:
        return False, str(e)
```

### 방문객 카운팅 — 지표는 **F0.5**

```
비용의 비대칭
  놓침(FN) → 숫자가 조금 적게 나옴. ★ 추세는 유지
  오탐(FP) → ★ 없는 손님이 세어짐. 통계가 거짓이 되고
             사장이 그 숫자로 인력을 배치합니다
  → 정밀도가 2배 중요 → ★ F0.5 최대 = conf 0.45
```

**★ 그런데 검산을 해야 합니다 (하루 200명 매장)**

| conf | 집계 | 오차 |
|---|---|---|
| 0.25 | TP 189 + FP 25 = **214** | +7.0% |
| **0.35** | TP 183 + FP 12 = **195** | **-2.5%** |
| 0.45 | TP 172 + FP 5 = **177** | -11.5% |

```
★ 성공 기준이 "오차 ±5%" 라면 F0.5 최대(0.45)가 아니라 ★ 0.35 를 골라야 합니다
  → 지표 최대값이 아니라 ★ 성공 기준이 최종 판단자입니다
```

**추가 조치** — `iou` 0.55(중복 억제) · 추적 도입(같은 사람 1명으로) · 통과선 방식.

```
★ 추적이 없으면 한 사람이 여러 프레임에 나와 ★ 수십 번 세어집니다
```

### 무단 침입 감지 — 지표는 **F2**

```
  놓침(FN) → ★ 침입자가 그냥 들어옴. 시스템 존재 이유 상실
  오탐(FP) → 스냅샷 한 장 더 봄. 귀찮을 뿐
  → F2 최대 = conf 0.25

★ 단, 오탐 제약(≤5건/일)을 함께 봅니다
  0.25 → 112건/일 ✗ → 0.30 으로 올리고 ROI·2연속·최소면적 추가
  → 오탐 3건/일 · 놓침 0건
```

### ★ 같은 표, 다른 답

| 추가 장치 | 추적 · 통과선 | ROI · 연속 프레임 · 쿨다운 |
| 최악의 사고 | 통계가 거짓 | 침입을 놓침 |

| 현장 홀드아웃 | 학습에 안 쓴 60장. **다시 학습에 넣지 말 것** |

| `conf` | 홀드아웃 스윕 → 현장 영상 2차 확인 → **0.30** |
| 지표 선택 | 침입=**F2**(재현) · 카운팅=**F0.5**(정밀) |
| 오탐의 단위 | 프레임 FP ≠ **이벤트 오탐** (쿨다운·연속 적용 후) |
| `iou` | 침입 **0.70**(겹침 보존) · 카운팅 **0.55**(중복 억제) |
| NCNN | 점수 분포 **-0.045** → pi conf **0.25** |
| 스키마 동결 | 추가만 허용 · 삭제·개명 금지 · **회귀 테스트로 강제** · `predict_image()` 정식 |
| 도메인 갭 | **각도 조정이 재학습보다 싸다** (30분 vs 4시간) |
| 전 구간 | CP1~CP9 · **이분 탐색으로 구간을 좁힌다** |
| 지연 예산 | 평균 **7.6초** · 최악 15.9초 (목표 10초) |
| 통합 빌드 | `build-v1` 태그 · `BUILD.md` · 돌아올 지점 |
| 테스트 계획 | 정상 · 경계 · **장애** · 부하 **오늘 만든다** |
| 중간 점검 | **안 된 것을 말하는 자리.** 숫자 · 조건 · 원인 · 조치 · 판단 시점 |
| Plan B | **무엇을 버릴지 오늘 정한다** |

**오늘 반드시 기억할 세 가지**
> ① **클래스 이름의 출처는 하나뿐입니다.** `class_id` 로 라벨을 만들지 말고 응답의 `class_name` 을 쓰세요. 이 버그는 예외가 안 나고 발표 때 들킵니다.
> ② **임계값은 모델의 속성이 아니라 문제의 속성입니다.** 침입 감지는 F2, 카운팅은 F0.5. 그리고 변환 모델(NCNN)은 반드시 다시 잡아야 합니다.
> ③ **중간 점검은 안 된 것을 말하는 자리입니다.** 숨기면 도움도, 다른 팀의 경험도, 남은 5일도 잃습니다.
