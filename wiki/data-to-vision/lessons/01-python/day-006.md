## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- `while` 로 조건이 참인 동안 같은 코드를 반복 실행할 수 있다.
- `break` 와 `continue` 로 반복의 흐름을 제어할 수 있다.
- 무한 루프가 왜 생기는지 알고, 빠졌을 때 빠져나올 수 있다.

## ② 왜 필요한가

어제 만든 숫자 맞추기 게임을 다시 봅시다. 기회가 **딱 한 번**이었습니다.

```python
guess = int(input("숫자: "))
if guess == answer:
    print("정답!")
```

기회를 5번 주려면 어떻게 할까요? 이렇게 복사·붙여넣기 할 수는 없습니다.

```python
guess = int(input("숫자: "))   # 1번째
if guess == answer: ...
guess = int(input("숫자: "))   # 2번째  ← 똑같은 코드
if guess == answer: ...
guess = int(input("숫자: "))   # 3번째  ← 또 똑같은 코드
...
```

**같은 코드가 반복된다면 반복문을 쓸 때입니다.**

| 반복이 필요한 상황 | 예 |
|---|---|
| 정답을 맞힐 때까지 | 숫자 맞추기, 로그인 재시도 |
| 사용자가 종료를 선택할 때까지 | ATM 메뉴, 주문 프로그램 |
| 게임이 끝날 때까지 | pygame의 게임 루프 (W04) |
| 조건을 만족할 때까지 | 목표 정확도에 도달할 때까지 학습 (대단원 03) |

특히 W04에서 배울 **게임 루프**는 통째로 `while` 문입니다. 오늘 배우는 것이 그 뼈대입니다.

## ③ 개념 설명

### while — 조건이 참인 동안 반복

```python
while 조건:
    반복할 코드
```

읽는 법: **"조건이 참인 동안, 아래 코드를 계속 실행하라"**

```python
count = 1

while count <= 3:
    print(f"{count}번째 실행")
    count += 1        # ← 이게 없으면 무한 루프!

print("반복 끝")
```

실행 결과:

```
1번째 실행
2번째 실행
3번째 실행
반복 끝
```

### 동작 순서 따라가기

```
count = 1

  ① 조건 검사: 1 <= 3 ?  참 → 블록 실행
       "1번째 실행" 출력, count = 2
  ② 조건 검사: 2 <= 3 ?  참 → 블록 실행
       "2번째 실행" 출력, count = 3
  ③ 조건 검사: 3 <= 3 ?  참 → 블록 실행
       "3번째 실행" 출력, count = 4
  ④ 조건 검사: 4 <= 3 ?  거짓 → 반복 종료
       "반복 끝" 출력
```

> **핵심** — 조건은 **매 반복 시작 전에** 검사합니다. 블록 중간에 조건이 거짓이 돼도 그 회차는 끝까지 실행됩니다.

### while 문의 세 가지 필수 요소

무한 루프에 빠지지 않으려면 이 셋이 모두 있어야 합니다.

```python
count = 1              # ① 시작값 (초기화)
while count <= 3:      # ② 종료 조건
    print(count)
    count += 1         # ③ 값 변화 (조건에 가까워지기)
```

셋 중 **③이 빠지는 것이 압도적으로 흔한 실수**입니다.

```python
count = 1
while count <= 3:
    print(count)       # count 가 영원히 1 → 무한 루프
```

### 무한 루프와 탈출

무한 루프에 빠지면 화면에 출력이 끝없이 쏟아집니다.

**탈출 방법: 터미널에서 `Ctrl + C`**

```
1
1
1
...
^C
Traceback (most recent call last):
KeyboardInterrupt
```

`KeyboardInterrupt` 는 에러가 아니라 "사용자가 중단했다"는 알림입니다.

> **무한 루프가 항상 나쁜 건 아닙니다.** `while True:` 로 일부러 무한 루프를 만들고 `break` 로 빠져나오는 방식은 아주 흔한 패턴입니다. (아래 참고)

### break — 반복을 즉시 끝내기

```python
count = 1

while count <= 100:
    if count == 4:
        break              # 반복문을 즉시 탈출
    print(count)
    count += 1

print("종료")
```

실행 결과:

```
1
2
3
종료
```

### continue — 이번 회차만 건너뛰기

```python
count = 0

while count < 5:
    count += 1
    if count == 3:
        continue           # 아래 코드를 건너뛰고 다음 반복으로
    print(count)
```

실행 결과:

```
1
2
4
5
```

`3` 만 빠졌습니다. `continue` 를 만나면 그 아래 코드를 실행하지 않고 조건 검사로 돌아갑니다.

> ⚠️ **`continue` 의 함정** — 값 증가를 `continue` 아래에 두면 무한 루프가 됩니다.
> ```python
> count = 0
> while count < 5:
>     if count == 3:
>         continue      # count 가 3에서 멈춤 → 무한 루프!
>     print(count)
>     count += 1
> ```
> `continue` 를 쓸 때는 **값 증가를 `continue` 위에** 두세요.

### break vs continue

| | 하는 일 | 비유 |
|---|---|---|
| `break` | 반복문 전체를 끝냄 | 영화관에서 나가기 |
| `continue` | 이번 회차만 건너뜀 | 이 장면만 건너뛰기 |

### while True + break — 가장 많이 쓰는 패턴

"몇 번 반복할지 모르지만, 특정 조건이 되면 끝내고 싶을 때" 쓰는 관용구입니다.

```python
while True:                          # 일부러 무한 루프
    answer = input("계속할까요? (y/n): ").strip().lower()
    if answer == "n":
        break                        # n 을 입력하면 탈출
    print("계속합니다!")

print("프로그램을 종료합니다.")
```

실행 결과:

```
계속할까요? (y/n): y
계속합니다!
계속할까요? (y/n): y
계속합니다!
계속할까요? (y/n): n
프로그램을 종료합니다.
```

> **왜 이 패턴을 쓰는가** — 종료 조건이 반복 **중간**에 있을 때 `while` 조건에 넣기 어렵기 때문입니다.
> 위 예에서 `answer` 는 반복 안에서 만들어지므로, `while answer != "n":` 으로 쓰려면 반복 전에 `answer` 를 미리 정의해야 해서 번거롭습니다.

### while ~ else (참고)

반복이 `break` 없이 정상적으로 끝났을 때만 `else` 가 실행됩니다.

```python
count = 1
while count <= 3:
    print(count)
    count += 1
else:
    print("정상 종료")     # break 로 끝났다면 실행 안 됨
```

> 자주 쓰이지는 않지만, "끝까지 다 돌았는가"를 확인할 때 유용합니다.

### Step 2. 누적 합계 구하기

```python
# 1부터 100까지 더하기
total = 0
num = 1

while num <= 100:
    total += num      # total = total + num

print(f"1부터 100까지의 합: {total}")
```

**응용 — 사용자가 0을 입력할 때까지 계속 더하기**

```python
total = 0
count = 0

print("숫자를 입력하세요. (0을 입력하면 종료)")

while True:
    num = int(input("> "))

    if num == 0:
        break

    total += num
    count += 1

if count == 0:
    print("입력된 숫자가 없습니다.")
else:
    print(f"{count}개의 합계: {total}")
    print(f"평균: {total / count:.2f}")
```


> 나눗셈 앞에서는 **항상 0인지 확인하는 습관**을 들이세요.

### Step 3. 숫자 맞추기 게임 완성판

Day 005의 게임에 반복을 넣어 제대로 된 게임으로 만듭니다.

```python
import random

answer = random.randint(1, 100)
tries = 0
MAX_TRIES = 7

print("=" * 34)
print("      숫자 맞추기 게임")
print("=" * 34)
print(f"1~100 사이의 숫자를 맞춰 보세요. (기회 {MAX_TRIES}번)")

while tries < MAX_TRIES:
    guess = int(input(f"[{tries + 1}/{MAX_TRIES}] 숫자: "))

    # 잘못된 범위는 기회를 소모하지 않습니다
    if guess < 1 or guess > 100:
        print("  1~100 사이로 입력해 주세요.")
        continue

    tries += 1

    if guess == answer:
        print(f"  정답입니다! {tries}번 만에 맞추셨습니다.")
        break
    elif guess < answer:
        print("  더 큰 수입니다. ↑")
    else:
        print("  더 작은 수입니다. ↓")
else:
    # break 없이 반복이 끝났다 = 기회를 다 썼다
    print(f"기회를 모두 사용했습니다. 정답은 {answer} 였습니다.")

print("=" * 34)
```

실행 결과:

```
==================================
      숫자 맞추기 게임
==================================
1~100 사이의 숫자를 맞춰 보세요. (기회 7번)
[1/7] 숫자: 50
  더 작은 수입니다. ↓
[2/7] 숫자: 25
  더 큰 수입니다. ↑
[3/7] 숫자: 37
  더 작은 수입니다. ↓
[4/7] 숫자: 31
  정답입니다! 4번 만에 맞추셨습니다.
==================================
```

> **눈여겨볼 점 3가지**
> - `continue` 가 `tries += 1` **위에** 있습니다. 잘못된 입력은 기회를 깎지 않습니다.
> - `while ~ else` 로 "기회를 다 쓴 경우"를 처리했습니다. 정답을 맞히면 `break` 때문에 `else` 가 실행되지 않습니다.
> - `MAX_TRIES` 를 상수로 빼 두면 난이도 조절이 한 줄로 끝납니다.

### Step 4. ATM 메뉴 프로그램 (오늘의 종합 예제)

```python
balance = 100_000      # 시작 잔액

print("=" * 34)
print("        MBC 은행 ATM")
print("=" * 34)

while True:
    print()
    print("1. 잔액 조회")
    print("2. 입금")
    print("3. 출금")
    print("4. 종료")

    menu = input("메뉴 선택: ").strip()

    if menu == "1":
        print(f"→ 현재 잔액은 {balance:,}원 입니다.")

    elif menu == "2":
        amount = int(input("입금액: "))
        if amount <= 0:
            print("→ 0원보다 큰 금액을 입력해 주세요.")
        else:
            balance += amount
            print(f"→ {amount:,}원 입금 완료. 잔액 {balance:,}원")

    elif menu == "3":
        amount = int(input("출금액: "))
        if amount <= 0:
            print("→ 0원보다 큰 금액을 입력해 주세요.")
        elif amount > balance:
            print(f"→ 잔액이 부족합니다. (현재 {balance:,}원)")
        else:
            balance -= amount
            print(f"→ {amount:,}원 출금 완료. 잔액 {balance:,}원")

    elif menu == "4":
        print("→ 이용해 주셔서 감사합니다.")
        break

    else:
        print("→ 1~4 중에서 선택해 주세요.")

print("=" * 34)
```

## ⑤ 자주 하는 실수

### 무한 루프 — 값을 바꾸는 코드를 빠뜨림

```python
count = 1
while count <= 3:
    print(count)
    # count += 1 을 안 씀
```

```
1
1
1
1
... (끝없이)
```

**원인** — `count` 가 영원히 1이므로 조건이 계속 참입니다.
**해결** — `Ctrl + C` 로 중단하고, 반복 안에서 조건에 관련된 값을 바꾸는 코드가 있는지 확인합니다.

> **점검 습관** — `while` 을 쓰면 곧바로 **"이 조건이 언젠가 거짓이 되는가?"** 를 스스로 물어보세요.

### continue 위치 때문에 생기는 무한 루프

```python
num = 0
while num < 5:
    if num == 3:
        continue      # num 이 3에서 멈춤
    print(num)
    num += 1
```

**원인** — `num == 3` 일 때 `continue` 로 건너뛰는데, `num += 1` 이 그 아래 있어 값이 바뀌지 않습니다.
**해결** — 값 변경 코드를 `continue` **위로** 옮깁니다.

```python
num = 0
while num < 5:
    num += 1          # 먼저 증가
    if num == 3:
        continue
    print(num)
```

### `while` 조건에 `=` 를 씀

```python
while count = 3:
```

```
SyntaxError: invalid syntax
```

**원인** — 비교는 `==` 입니다. `=` 는 대입입니다.
**해결** — `while count == 3:`

### break 가 if 안에 있지 않아 첫 회차에 끝남

```python
while True:
    answer = input("계속? (y/n): ")
    break                # 조건 없이 무조건 탈출
    print("계속합니다")   # 영원히 실행 안 됨
```

**원인** — `break` 를 조건 없이 썼습니다. 항상 한 번만 돌고 끝납니다.
**해결** — `if` 안에 넣습니다. 그리고 `break` 아래 코드는 실행되지 않으니 순서에 주의하세요.

### 반복 안에서 만든 변수를 반복 밖에서 씀

```python
while count < 3:
    result = count * 2
    count += 1

print(result)      # count 가 처음부터 3 이상이었다면 NameError
```

**원인** — 반복이 한 번도 실행되지 않으면 `result` 는 만들어지지 않습니다.
**해결** — 반복 전에 기본값을 정해 둡니다. (`result = None` 또는 `result = 0`)

## ⑥ 확인 문제

**1.** 아래 코드의 출력 결과는 무엇일까요?

```python
i = 0
while i < 5:
    i += 1
    if i % 2 == 0:
        continue
    print(i, end=" ")
```

<details>
<summary>답 보기</summary>

```
1 3 5
```

`i` 를 먼저 1 증가시킨 뒤, 짝수면 `continue` 로 건너뜁니다. 따라서 홀수만 출력됩니다.

> `print(i, end=" ")` 의 `end=" "` 는 "줄바꿈 대신 공백을 넣으라"는 뜻입니다. 기본값은 `end="\n"`(줄바꿈)입니다.
</details>

**2.** 사용자에게 비밀번호를 최대 3번까지 입력받고, 맞으면 "로그인 성공", 3번 다 틀리면 "계정이 잠겼습니다"를 출력하는 프로그램을 작성하세요. (정답은 `mbc1234`)

<details>
<summary>답 보기</summary>

```python
PASSWORD = "mbc1234"
MAX_TRY = 3
tries = 0

while tries < MAX_TRY:
    pw = input(f"비밀번호 ({tries + 1}/{MAX_TRY}): ").strip()
    tries += 1

    if pw == PASSWORD:
        print("로그인 성공!")
        break
    else:
        remain = MAX_TRY - tries
        if remain > 0:
            print(f"틀렸습니다. {remain}번 남았습니다.")
else:
    print("계정이 잠겼습니다.")
```

실행 결과:

```
비밀번호 (1/3): 1234
틀렸습니다. 2번 남았습니다.
비밀번호 (2/3): abcd
틀렸습니다. 1번 남았습니다.
비밀번호 (3/3): mbc1234
로그인 성공!
```

**포인트 3가지**
- `while ~ else` 로 "다 틀린 경우"를 깔끔하게 처리합니다.
- 마지막 시도에서 틀렸을 때 "0번 남았습니다"가 나오지 않도록 `remain > 0` 을 확인합니다.
- `PASSWORD`, `MAX_TRY` 를 상수로 빼면 나중에 값을 바꾸기 쉽습니다.
</details>

**3.** 아래 코드는 **1부터 홀수만 더해서 합이 100을 넘으면 멈추는** 프로그램을 의도했습니다. 그런데 실행하면 무한 루프에 빠집니다. 원인을 찾고 고치세요.

```python
total = 0
num = 1

while total < 100:
    if num % 2 == 0:
        continue
    total += num
    num += 1

print(total)
```

<details>
<summary>답 보기</summary>

**원인** — `num` 이 짝수가 되는 순간 `continue` 로 아래 코드를 전부 건너뜁니다.
그런데 `num` 을 증가시키는 `num += 1` 이 그 아래에 있으므로, `num` 은 영원히 2에 머무릅니다.
`total` 도 더 이상 늘어나지 않으니 조건 `total < 100` 이 영원히 참입니다.

동작을 따라가 보면 이렇습니다.

```
1회차: num=1 (홀수) → total=1, num=2
2회차: num=2 (짝수) → continue          ← num 그대로 2
3회차: num=2 (짝수) → continue          ← 영원히 반복
```

**해결** — `continue` 로 건너뛰더라도 값이 변하도록, 증가 코드를 `continue` **위로** 옮깁니다.

```python
total = 0
num = 1

while total < 100:
    if num % 2 == 0:
        num += 1          # 짝수여도 다음 숫자로 넘어가게
        continue
    total += num
    num += 1

print(total)              # 121  (1+3+5+...+21)
```

**교훈** — `continue` 를 쓸 때는 **"건너뛰어도 조건에 관련된 값이 계속 변하는가"** 를 반드시 확인하세요.
확신이 안 서면 반복 안에 `print(f"[디버그] num={num}, total={total}")` 를 넣고 `Ctrl+C` 로 몇 회차만 눈으로 확인하는 것이 가장 빠릅니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| `while 조건:` | 조건이 참인 동안 반복. 조건은 **매 회차 시작 전** 검사 |
| 필수 3요소 | ① 시작값 ② 종료 조건 ③ **값 변화** |
| `break` | 반복문 전체 탈출 |
| `continue` | 이번 회차만 건너뛰기. **값 변경은 `continue` 위에** |
| `while True` + `break` | 종료 조건이 반복 중간에 있을 때의 표준 패턴 |
| `while ~ else` | `break` 없이 끝났을 때만 `else` 실행 |
| 무한 루프 탈출 | 터미널에서 `Ctrl + C` |

**오늘 반드시 기억할 한 가지**
> `while` 을 쓰면 곧바로 **"이 조건이 언젠가 거짓이 되는가?"** 를 확인하세요.
