## ① 학습 목표

이 강을 마치면 다음을 할 수 있습니다.

- 지금까지의 채점 데이터를 **영역×유형 진단 매트릭스로 정리할 수 있다**
- 정답률이 낮은 칸 2~3개를 **개인 보완 목표로 확정할 수 있다**
- 자신의 취약 트랙(코드/SQL/이론) 보완 세트를 **풀고 재채점할 수 있다**
- 시험 접수·준비물 상태를 **점검표로 확인할 수 있다**

## ② 왜 필요한가

**"열심히"는 전략이 아닙니다.** 남은 기간은 2주 — 전 범위를 다시 볼 시간은 없고, 그럴 필요도 없습니다. 6주간 쌓인 데이터(진단평가·중간평가·형성평가 6회·통합 세트)는 이미 여러분의 약점을 알고 있습니다. 오늘은 그 데이터를 표 하나로 모아 **"어느 칸에서 몇 점이 새는지"** 를 눈으로 확인하고, 남은 시간 전부를 그 칸에 붓는 날입니다.

감(느낌)과 데이터는 자주 다릅니다 — "포인터가 무섭다"는 학생의 실제 최다 실점이 SQL의 형식 감점인 경우가 흔합니다. 무서운 것과 틀리는 것은 다르며, 점수를 만드는 건 후자의 교정입니다.

**시험에서의 중요도와 출제 형태** — 이 강은 출제 범위가 아니라 **점수 설계** 시간입니다. 부가로, 실기 원서접수는 놓치면 과정 전체가 무의미해지는 단 하나의 행정 절차라 오늘 함께 점검합니다.

### 3-1. 진단 매트릭스 — 영역 × 유형

지금까지의 모든 평가에서 **문항 단위**로 집계해 채웁니다. 칸 = "맞힌 수 / 푼 수".

| 영역 \ 유형 | 결과 예측 | 빈칸 | 오류 찾기 | 작성·해석 | 단답 | 영역 정답률 |
|---|---|---|---|---|---|---|
| C | / | / | / | / | — | % |
| Java | / | / | / | / | — | % |
| Python | / | / | / | / | — | % |
| SQL | / | / | / | / | — | % |
| DB 이론 (키·정규화·트랜잭션) | — | / | — | / | / | % |
| SW 공학 (테스트·패턴·결합도) | — | — | — | / | / | % |
| 네트워크·보안·OS | / (계산) | — | — | / | / | % |

**읽는 법** — ①정답률 60% 미만 칸이 **빨간 칸** ②빨간 칸 중 출제 비중이 큰 것(코드·SQL 계열)이 우선 ③한 영역의 가로줄 전체가 낮으면 개념 구멍, 특정 유형의 세로줄이 낮으면 절차·형식 문제([13강 오답 유형화](lesson-13.md)와 연결)입니다.

### Step 2. 진단 매트릭스 작성 (30분)

재료: 진단평가(01강), 중간평가(08강), 형성평가 1~6주차, 통합 세트(13강)의 채점 기록 + 오답노트. 절차: ①문항별로 영역·유형을 판정해 매트릭스에 가산 ②칸별 정답률 계산 ③빨간 칸(60% 미만)에 표시 ④3-2 규칙으로 트랙 결정. **강사 확인**: 매트릭스와 본인이 느끼는 취약 영역이 다르면 그 차이 자체를 기록해 둡니다(대개 데이터가 맞습니다).

### Step 3. 트랙별 보완 세트 (택1 · 30분)

**A. 코드 취약 트랙**

1. [C] 다음 코드의 출력을 쓰시오.
   ```c
   int a = 6, b = 4;
   int *p = &a, *q = &b;
   *p = *p + *q;
   printf("%d %d", a, *q);
   ```
2. [Java] 다음 코드의 출력을 쓰시오.
   ```java
   int s = 0;
   for (int i = 10; i > 0; i -= 3) s += i;
   System.out.println(s);
   ```
3. [Python] 다음 코드의 출력을 쓰시오.
   ```python
   s = "ALGORITHM"
   print(s[::3])
   ```

**B. SQL 취약 트랙** (예제 스키마 기준)

1. [작성] 과목별 평균 성적이 82 이상인 과목코드와 평균을 조회하시오.
2. [결과 예측] `SELECT COUNT(DISTINCT 학번) FROM ENROLL;` 의 값은?
3. [빈칸] 수강 기록이 하나도 없는 과목명을 조회한다.
   ```sql
   SELECT 과목명 FROM COURSE
   WHERE 과목코드 NOT IN (SELECT ________ FROM ENROLL);
   ```

**C. 이론 취약 트랙**

1. [단답] "서브시스템의 복잡한 기능들을 하나의 단순한 창구로 제공하는 구조 패턴"은?
2. [계산] 참조열 `2, 3, 2, 1, 5, 2` · 프레임 3 · LRU의 페이지 부재 횟수는?
3. [단답] 트랜잭션의 성질 중 "실행 중인 트랜잭션의 중간 결과에 다른 트랜잭션이 접근할 수 없다"는 성질은?

<summary>보완 세트 정답</summary>

| 트랙 | 번호 | 정답 | 해설 |
|---|---|---|---|
| A | 1 | `10 4` | *p로 a를 6+4=10으로 변경, b는 그대로 |
| A | 2 | `22` | i=10,7,4,1 → 10+7+4+1 |

## ⑥ 확인 문제

1. [판정] 매트릭스에서 "Java 행 전체가 50%, 다른 행은 75% 이상"인 학생과 "모든 행이 65% 안팎, 형식 감점이 오답의 절반"인 학생의 처방이 어떻게 다른지 각각 쓰시오.
2. [계산] 보완 세트 A-2에서 반복 변수 i가 가지는 값을 순서대로 모두 쓰시오.
3. [단답] 실기 시험장에 가져갈 수 있는 것을 다음에서 모두 고르시오. → (ㄱ) 신분증 (ㄴ) 공학용 계산기 (ㄷ) 검은색 볼펜 (ㄹ) 스마트워치

<details>
<summary>정답과 해설</summary>

1. 전자는 **개념 구멍**(Java 재학습 — 06강 중심 + 04강 Java 예제), 후자는 **형식 교정**(13강 답안 규칙으로 기존 오답 재채점). 같은 "점수 부족"이라도 처방이 다른 것이 진단의 이유입니다.
2. **10, 7, 4, 1** — `i > 0`이므로 1까지 실행되고, 다음 −2는 조건 탈락.
3. **(ㄱ), (ㄷ)** — 계산기·전자기기는 반입 불가입니다.

## 마무리

**오늘의 요약** — 6주의 채점 데이터를 영역×유형 매트릭스로 모으면 새는 칸이 보입니다. 처방은 칸의 위치(트랙)와 원인 유형(개념/절차/형식)으로 결정하고, 남은 2주는 빨간 칸 2~3개에 집중합니다. 보완은 새 문제보다 기존 오답 재풀이가 본체입니다. 접수는 오늘 확인 완료가 원칙입니다.

**복습 체크리스트**

- [ ] 내 매트릭스가 완성되었고 빨간 칸을 안다
- [ ] 빨간 칸 상위 2~3개의 원인 유형을 판정했다
- [ ] Step 4 보완 계획표를 채웠다
- [ ] 원서접수 상태를 확인했다 (⚠️ 일정은 Q-net 기준)

**과제 — 7주차 형성평가 (10문항, 15강 직전 최종 점검용)**

1. C: `int a = 9; printf("%d", a / 2 * 2);` 의 출력은?
2. Java: `System.out.println(10 > 3 ? "A" : "B");` 의 출력은?
3. Python: `print(len("DATABASE"[2:6]))` 의 출력은?
4. SQL: 과목코드별 인원을 구하는 질의의 빈칸은? → `SELECT 과목코드, COUNT(*) FROM ENROLL ______ 과목코드;`
5. SQL: `SELECT 이름 FROM STUDENT WHERE 학년 = 2 OR 학년 = 3;` 을 IN으로 바꿔 쓰시오.
6. 이론: 기본키가 가져야 하는 두 성질은?
7. 이론: "모든 결정자가 후보키"인 정규형은?
8. 이론: TCP와 UDP 중 비연결형은?
9. 이론: 삽입·갱신·삭제 이상을 통틀어 무엇이라 하는가?
10. 전략: 150분 시험에서 1차 풀이 전에 해야 할 5분짜리 활동은?
