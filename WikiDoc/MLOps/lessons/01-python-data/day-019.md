## ③ 개념 설명

### 공공데이터포털

| 항목 | 내용 |
|---|---|
| 주소 | <https://www.data.go.kr> |
| 가입 | 무료 (회원가입 → 활용신청 → 즉시 또는 1~2일 승인) |
| 인증 | 서비스 키(serviceKey)를 쿼리 파라미터로 전달 |
| 형식 | JSON 또는 XML (대부분 `_type=json` 으로 선택) |
| 제한 | 개발계정 일 1,000회 정도 (API마다 다름) |

**키 두 종류가 발급됩니다.**

| 종류 | 형태 | 언제 |
|---|---|---|
| **Encoding** | `%2B` 같은 인코딩 문자 포함 | URL에 직접 붙일 때 |
| **Decoding** | 원본 (`+`, `/`, `=` 포함) | **`params=` 에 넘길 때** ⭐ |

> **`requests` 의 `params=` 를 쓸 때는 Decoding 키를 쓰세요.**
> `requests` 가 자동으로 인코딩하므로, Encoding 키를 넣으면 **이중 인코딩**되어 인증이 실패합니다.
> 이것이 초보자가 가장 많이 겪는 함정입니다.

### 페이징 파라미터

공공데이터 API의 표준 파라미터입니다.

| 파라미터 | 뜻 |
|---|---|
| `pageNo` | 페이지 번호 (1부터) |
| `numOfRows` | 한 페이지에 받을 개수 |
| `serviceKey` | 인증키 |
| `_type` | 응답 형식 (`json` / `xml`) |
| `resultType` | (API에 따라) 응답 형식 |

**전체를 받으려면**

```python
total_count = 첫 응답에서 확인
total_pages = ceil(total_count / num_of_rows)

for page in range(1, total_pages + 1):
    fetch(page)
```

**또는 빈 응답까지**

```python
for page in range(1, MAX_PAGES + 1):
    items = fetch(page)
    if not items:
        break
```

**두 방법을 함께** 쓰는 것이 안전합니다. `totalCount` 가 틀린 API도 있습니다.

### 두 겹의 오류 — HTTP vs 애플리케이션

**공공데이터 API의 가장 큰 함정입니다.**

```python
r = requests.get(url, params=params)
print(r.status_code)      # 200  ← HTTP는 성공
print(r.json())
```

```json
{
  "response": {
    "header": {
      "resultCode": "30",
      "resultMsg": "SERVICE_KEY_IS_NOT_REGISTERED_ERROR"
    }
  }
}
```

**HTTP 200인데 실제로는 실패입니다.**

| 레벨 | 확인 방법 |
|---|---|
| HTTP | `r.raise_for_status()` |
| **애플리케이션** | 응답 본문의 `resultCode` |

**두 겹 모두 확인해야 합니다.**

```python
r.raise_for_status()                                   # 1차
data = r.json()
code = data.get("response", {}).get("header", {}).get("resultCode")
if code != "00":
    msg = data.get("response", {}).get("header", {}).get("resultMsg", "")
    raise CollectorError(f"API 오류 {code}: {msg}")     # 2차
```

**주요 resultCode**

| 코드 | 뜻 | 재시도? |
|---|---|---|
| `00` | 정상 | — |
| `01` | 애플리케이션 에러 | 가능 |
| `03` | 데이터 없음 | ❌ (종료 신호) |
| `04` | HTTP 에러 | 가능 |
| `05` | 서비스 연결 실패 | 가능 |
| `20` | 서비스 접근 거부 | ❌ 권한 문제 |
| `22` | **호출 횟수 초과** | ❌ 내일 다시 |
| `30` | **등록되지 않은 서비스키** | ❌ 키 확인 |
| `31` | 활용 기간 만료 | ❌ 갱신 필요 |
| `32` | 등록되지 않은 IP | ❌ 설정 확인 |

### Step 3. 첫 API 호출

`first_api_call.py` 를 만듭니다. 에어코리아 API 예시입니다.

```python
"""공공데이터 API 첫 호출."""

import os

import requests
from dotenv import load_dotenv

load_dotenv()

API_KEY = os.environ["PUBLIC_DATA_KEY"]
URL = ("http://apis.data.go.kr/B552584/ArpltnInforInqireSvc"
       "/getCtprvnRltmMesureDnsty")

params = {
    "serviceKey": API_KEY,          # Decoding 키를 그대로
    "returnType": "json",
    "numOfRows": 5,
    "pageNo": 1,
    "sidoName": "서울",
    "ver": "1.0",
}

r = requests.get(URL, params=params, timeout=10)

print(f"상태 코드    : {r.status_code}")
print(f"Content-Type : {r.headers.get('Content-Type')}")
print(f"소요 시간    : {r.elapsed.total_seconds():.2f}초")

# 1차: HTTP 확인
r.raise_for_status()

# XML 이 오면 대개 오류입니다
if "xml" in r.headers.get("Content-Type", "").lower():
    print("\n⚠ XML 응답 (대개 오류):")
    print(r.text[:400])
    raise SystemExit(1)

data = r.json()

# 2차: 애플리케이션 레벨 확인
header = data.get("response", {}).get("header", {})
code = header.get("resultCode")
msg = header.get("resultMsg")

print(f"\nresultCode   : {code}")
print(f"resultMsg    : {msg}")

if code != "00":
    print(f"\n✗ API 오류입니다. 키 등록·활용 기간·호출 한도를 확인하세요.")
    raise SystemExit(1)

body = data["response"]["body"]
print(f"\n전체 {body['totalCount']:,}건 중 {len(body['items'])}건 수신 "
      f"(페이지 {body['pageNo']}, 페이지당 {body['numOfRows']}건)")

print(f"\n{'측정소':<12}{'측정일시':<18}{'PM10':>6}{'PM2.5':>7}{'통합지수':>8}")
print("-" * 54)
for item in body["items"]:
    print(f"{item.get('stationName', '-'):<12}"
          f"{item.get('dataTime', '-'):<18}"
          f"{item.get('pm10Value', '-'):>6}"
          f"{item.get('pm25Value', '-'):>7}"
          f"{item.get('khaiValue', '-'):>8}")
```

### Step 4. 수집기 클래스

`collector.py` 를 만듭니다. **오늘의 핵심 산출물입니다.**

```python
"""공공데이터 API 수집기."""

import json
import logging
import math
import os
import random
import time
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path
from typing import Any

import requests

logger = logging.getLogger(__name__)


# ===================== 예외 =====================

class CollectorError(Exception):
    """수집 실패."""


class AuthError(CollectorError):
    """인증 실패 — 재시도해도 소용없음."""


class QuotaExceeded(CollectorError):
    """호출 한도 초과 — 오늘은 그만."""


class NoMoreData(CollectorError):
    """더 이상 데이터가 없음 — 정상 종료 신호."""


# ===================== 설정 =====================

@dataclass(frozen=True)
class CollectorConfig:
    """수집기 설정. 만들어진 뒤 바뀌지 않습니다."""

    num_of_rows: int = 100
    max_pages: int = 100
    max_attempts: int = 3
    timeout: float = 15.0
    min_interval: float = 0.5
    base_delay: float = 1.0
    max_delay: float = 30.0
    user_agent: str = "MLOpsStudyCollector/1.0 (교육용; hong@example.com)"

    def __post_init__(self) -> None:
        if self.num_of_rows < 1:
            raise ValueError("num_of_rows 는 1 이상이어야 합니다")
        if self.max_attempts < 1:
            raise ValueError("max_attempts 는 1 이상이어야 합니다")


@dataclass
class CollectStats:
    requests_made: int = 0
    pages_fetched: int = 0
    items_collected: int = 0
    retries: int = 0
    failures: int = 0
    total_wait: float = 0.0
    elapsed: float = 0.0

    def as_dict(self) -> dict[str, Any]:
        return {
            "requests": self.requests_made,
            "pages": self.pages_fetched,
            "items": self.items_collected,
            "retries": self.retries,
            "failures": self.failures,
            "wait_seconds": round(self.total_wait, 2),
            "elapsed_seconds": round(self.elapsed, 2),
        }


# ===================== 수집기 =====================

class BaseCollector(ABC):
    """수집기 공통 부모.

    자식은 build_params() 와 extract_items() 만 구현하면 됩니다.
    페이징·재시도·간격 제어·통계는 부모가 처리합니다.
    """

    RETRYABLE_STATUS = {408, 429, 500, 502, 503, 504}

    def __init__(self, name: str, base_url: str,
                 config: CollectorConfig | None = None):
        self.name = name
        self.base_url = base_url
        self.config = config or CollectorConfig()
        self.stats = CollectStats()

        self.session = requests.Session()
        self.session.headers.update({"User-Agent": self.config.user_agent})

        self.records: list[dict] = []
        self.failures: list[dict] = []
        self._last_request = 0.0

    # ---------- 자식이 구현 ----------

    @abstractmethod
    def build_params(self, page: int, **kwargs) -> dict[str, Any]:
        """페이지 번호로 요청 파라미터를 만듭니다."""

    @abstractmethod
    def extract_items(self, payload: dict) -> tuple[list[dict], int]:
        """응답에서 (항목 목록, 전체 개수)를 꺼냅니다.

        Raises:
            AuthError / QuotaExceeded / NoMoreData / CollectorError
        """

    def transform(self, item: dict) -> dict | None:
        """항목 하나를 저장용 레코드로 변환합니다. None 이면 버립니다."""
        return item

    # ---------- 공통 로직 ----------

    def _wait(self) -> None:
        elapsed = time.monotonic() - self._last_request
        interval = self.config.min_interval
        if self._last_request > 0 and elapsed < interval:
            waited = interval - elapsed
            time.sleep(waited)
            self.stats.total_wait += waited
        self._last_request = time.monotonic()

    def _backoff(self, attempt: int) -> float:
        delay = min(self.config.base_delay * (2 ** (attempt - 1)),
                    self.config.max_delay)
        return delay * (0.5 + random.random())

    def _request(self, params: dict) -> dict:
        """재시도를 포함한 요청. 성공하면 파싱된 JSON."""
        last_error: Exception | None = None

        for attempt in range(1, self.config.max_attempts + 1):
            self._wait()
            self.stats.requests_made += 1

            try:
                r = self.session.get(self.base_url, params=params,
                                     timeout=self.config.timeout)
            except (requests.Timeout, requests.ConnectionError) as e:
                last_error = e
                if attempt < self.config.max_attempts:
                    delay = self._backoff(attempt)
                    logger.warning("[%s] 네트워크 오류 %s (%d/%d) — %.1f초 후 재시도",
                                   self.name, type(e).__name__, attempt,
                                   self.config.max_attempts, delay)
                    self.stats.retries += 1
                    time.sleep(delay)
                    continue
                raise CollectorError(f"네트워크 오류: {e}") from e

            if r.status_code in self.RETRYABLE_STATUS:
                last_error = CollectorError(f"HTTP {r.status_code}")
                if attempt < self.config.max_attempts:
                    retry_after = r.headers.get("Retry-After", "")
                    delay = (float(retry_after) if retry_after.isdigit()
                             else self._backoff(attempt))
                    logger.warning("[%s] HTTP %d (%d/%d) — %.1f초 후 재시도",
                                   self.name, r.status_code, attempt,
                                   self.config.max_attempts, delay)
                    self.stats.retries += 1
                    time.sleep(delay)
                    continue
                raise CollectorError(f"HTTP {r.status_code} (최대 재시도 도달)")

            if not r.ok:
                raise CollectorError(f"HTTP {r.status_code} — 재시도 불가")

            content_type = r.headers.get("Content-Type", "").lower()
            if "xml" in content_type:
                logger.error("[%s] XML 응답 (대개 오류): %s", self.name, r.text[:200])
                raise CollectorError("XML 응답 — 요청 파라미터나 키를 확인하세요")

            try:
                return r.json()
            except ValueError as e:
                logger.error("[%s] JSON 파싱 실패. 본문: %s", self.name, r.text[:200])
                raise CollectorError(f"JSON 파싱 실패: {e}") from e

        raise CollectorError(f"알 수 없는 실패: {last_error}")

    def collect(self, **kwargs) -> list[dict]:
        """페이징을 따라 전체를 수집합니다."""
        start = time.monotonic()
        logger.info("[%s] 수집 시작", self.name)

        total_pages: int | None = None

        for page in range(1, self.config.max_pages + 1):
            params = self.build_params(page, **kwargs)

            try:
                payload = self._request(params)
                items, total_count = self.extract_items(payload)
            except NoMoreData:
                logger.info("[%s] %d페이지 — 데이터 없음, 정상 종료", self.name, page)
                break
            except (AuthError, QuotaExceeded) as e:
                logger.error("[%s] 치명적 오류로 중단: %s", self.name, e)
                raise
            except CollectorError as e:
                logger.error("[%s] %d페이지 실패: %s", self.name, page, e)
                self.stats.failures += 1
                self.failures.append({"page": page, "reason": str(e)})
                continue

            if not items:
                logger.info("[%s] %d페이지가 비어 있습니다 — 종료", self.name, page)
                break

            if total_pages is None and total_count:
                total_pages = math.ceil(total_count / self.config.num_of_rows)
                logger.info("[%s] 전체 %,d건 / %d페이지", self.name,
                            total_count, total_pages)

            added = 0
            for item in items:
                record = self.transform(item)
                if record is not None:
                    self.records.append(record)
                    added += 1

            self.stats.pages_fetched += 1
            self.stats.items_collected += added
            logger.info("[%s] %d페이지 — %d건 (누적 %d건)",
                        self.name, page, added, len(self.records))

            if total_pages and page >= total_pages:
                logger.info("[%s] 마지막 페이지 도달", self.name)
                break
        else:
            logger.warning("[%s] 최대 페이지(%d) 도달 — 데이터가 더 있을 수 있습니다",
                           self.name, self.config.max_pages)

        self.stats.elapsed = time.monotonic() - start
        logger.info("[%s] 수집 완료 — %d건 (%.1f초)",
                    self.name, len(self.records), self.stats.elapsed)
        return self.records

    # ---------- 저장·리포트 ----------

    def save(self, out_dir: Path = Path("data")) -> dict[str, Path]:
        out_dir.mkdir(parents=True, exist_ok=True)
        stamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        paths = {}

        json_path = out_dir / f"{self.name}_{stamp}.json"
        json_path.write_text(
            json.dumps(self.records, ensure_ascii=False, indent=2),
            encoding="utf-8")
        paths["json"] = json_path

        if self.records:
            import csv
            csv_path = out_dir / f"{self.name}_{stamp}.csv"
            fields = list(self.records[0].keys())
            with csv_path.open("w", encoding="utf-8", newline="") as f:
                writer = csv.DictWriter(f, fieldnames=fields, extrasaction="ignore")
                writer.writeheader()
                writer.writerows(self.records)
            paths["csv"] = csv_path

        if self.failures:
            fail_path = out_dir / f"{self.name}_{stamp}_failed.json"
            fail_path.write_text(
                json.dumps(self.failures, ensure_ascii=False, indent=2),
                encoding="utf-8")
            paths["failed"] = fail_path

        meta_path = out_dir / f"{self.name}_{stamp}_meta.json"
        meta_path.write_text(json.dumps({
            "collector": self.name,
            "collected_at": datetime.now().isoformat(),
            "record_count": len(self.records),
            "stats": self.stats.as_dict(),
        }, ensure_ascii=False, indent=2), encoding="utf-8")
        paths["meta"] = meta_path

        return paths

    def report(self) -> None:
        s = self.stats
        print(f"\n{'=' * 52}")
        print(f"수집 리포트 — {self.name}")
        print("=" * 52)
        print(f"  요청 수         : {s.requests_made}회")
        print(f"  페이지          : {s.pages_fetched}개")
        print(f"  수집 항목       : {s.items_collected:,}건")
        print(f"  재시도          : {s.retries}회")
        print(f"  실패 페이지     : {s.failures}개")
        print(f"  대기 시간       : {s.total_wait:.1f}초")
        print(f"  총 소요         : {s.elapsed:.1f}초")
        if s.elapsed:
            print(f"  처리 속도       : {s.items_collected / s.elapsed:.1f}건/초")
        if self.failures:
            print("\n  [실패 상세]")
            for f in self.failures[:5]:
                print(f"    {f['page']}페이지: {f['reason']}")

    def __repr__(self) -> str:
        return f"{type(self).__name__}(name={self.name!r}, records={len(self.records)})"

class PublicDataCollector(BaseCollector):
    """공공데이터포털(data.go.kr) 표준 응답 형식 수집기."""

    RESULT_MESSAGES = {
        "00": "정상",
        "01": "애플리케이션 에러",
        "03": "데이터 없음",
        "20": "서비스 접근 거부",
        "22": "호출 횟수 초과",
        "30": "등록되지 않은 서비스키",
        "31": "활용 기간 만료",
        "32": "등록되지 않은 IP",
    }

    def __init__(self, name: str, base_url: str, service_key: str,
                 extra_params: dict | None = None,
                 config: CollectorConfig | None = None):
        super().__init__(name, base_url, config)
        if not service_key:
            raise AuthError("서비스 키가 비어 있습니다. .env 를 확인하세요.")
        self.service_key = service_key
        self.extra_params = extra_params or {}

    def build_params(self, page: int, **kwargs) -> dict[str, Any]:
        params = {
            "serviceKey": self.service_key,
            "pageNo": page,
            "numOfRows": self.config.num_of_rows,
            "returnType": "json",
            "_type": "json",
        }
        params.update(self.extra_params)
        params.update(kwargs)
        return params

    def extract_items(self, payload: dict) -> tuple[list[dict], int]:
        response = payload.get("response", {})
        header = response.get("header", {})
        code = str(header.get("resultCode", ""))
        msg = header.get("resultMsg", "")

        if code == "03":
            raise NoMoreData(msg)
        if code in ("30", "31", "32", "20"):
            raise AuthError(f"[{code}] {self.RESULT_MESSAGES.get(code, msg)}")
        if code == "22":
            raise QuotaExceeded(f"[{code}] {self.RESULT_MESSAGES.get(code, msg)}")
        if code != "00":
            raise CollectorError(f"[{code}] {self.RESULT_MESSAGES.get(code, msg)}")

        body = response.get("body", {})
        items = body.get("items", [])

        # items 가 {"item": [...]} 형태인 API도 있습니다
        if isinstance(items, dict):
            items = items.get("item", [])
        # 단건이면 리스트가 아니라 딕셔너리로 옵니다
        if isinstance(items, dict):
            items = [items]
        if not isinstance(items, list):
            items = []

        return items, int(body.get("totalCount", 0) or 0)
```

```python
import json
import random
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

VALID_KEY = "test-key-1234"

STATIONS = [f"측정소{i:02d}" for i in range(1, 121)]      # 120개


class Handler(BaseHTTPRequestHandler):
    def log_message(self, fmt, *args):
        print(f"  [server] {fmt % args}")

    def _send(self, payload, code=200):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", "application/json;charset=UTF-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def _envelope(self, result_code, msg, body=None):
        return {"response": {
            "header": {"resultCode": result_code, "resultMsg": msg},
            "body": body or {},
        }}

    def do_GET(self):
        parsed = urlparse(self.path)
        q = parse_qs(parsed.query)

        key = q.get("serviceKey", [""])[0]
        page = int(q.get("pageNo", ["1"])[0])
        rows = int(q.get("numOfRows", ["10"])[0])

        # 인증 확인
        if not key:
            self._send(self._envelope("30", "SERVICE_KEY_IS_NOT_REGISTERED_ERROR"))
            return
        if key != VALID_KEY:
            self._send(self._envelope("30", "SERVICE_KEY_IS_NOT_REGISTERED_ERROR"))
            return

        # 10% 확률로 503 — 재시도 연습
        if random.random() < 0.10:
            self._send({"error": "Service Unavailable"}, code=503)
            return

        start = (page - 1) * rows
        chunk = STATIONS[start:start + rows]

        if not chunk:
            self._send(self._envelope("03", "NODATA_ERROR"))
            return

        items = []
        for name in chunk:
            items.append({
                "stationName": name,
                "dataTime": "2026-08-12 18:00",
                # 5% 확률로 결측 — 정제 연습
                "pm10Value": "-" if random.random() < 0.05 else str(random.randint(10, 90)),
                "pm25Value": str(random.randint(5, 50)),
                "khaiValue": str(random.randint(30, 120)),
            })

        self._send(self._envelope("00", "NORMAL_CODE", {
            "totalCount": len(STATIONS),
            "pageNo": page,
            "numOfRows": rows,
            "items": items,
        }))
```

**새 API 추가 예시 — 서울열린데이터광장**

응답 형식이 완전히 다릅니다.

```json
{"CardSubwayStatsNew": {
    "list_total_count": 620,
    "RESULT": {"CODE": "INFO-000", "MESSAGE": "정상 처리되었습니다"},
    "row": [{"SUB_STA_NM": "강남", "RIDE_PASGR_NUM": 48293}]
}}
```

**그래도 두 메서드만 쓰면 됩니다.**

```python
class SeoulOpenDataCollector(BaseCollector):
    def build_params(self, page: int, **kwargs) -> dict:
        # 서울시 API는 URL 경로에 파라미터를 넣습니다
        start = (page - 1) * self.config.num_of_rows + 1
        end = page * self.config.num_of_rows
        self.base_url = f"{self.root}/{self.key}/json/{self.service}/{start}/{end}/"
        return {}

    def extract_items(self, payload: dict) -> tuple[list[dict], int]:
        root = payload.get(self.service, {})
        result = root.get("RESULT", {})
        code = result.get("CODE", "")

        if code == "INFO-200":
            raise NoMoreData("해당하는 데이터가 없습니다")
        if code.startswith("ERROR-3"):
            raise AuthError(result.get("MESSAGE", ""))
        if not code.startswith("INFO-000"):
            raise CollectorError(f"[{code}] {result.get('MESSAGE', '')}")

        return root.get("row", []), int(root.get("list_total_count", 0))
```

**약 20줄로 새 API가 추가됩니다.**
재시도·간격·통계·저장은 **한 줄도 다시 쓰지 않습니다.**

**만약 상속을 안 썼다면**

| 상황 | 결과 |
|---|---|
| 재시도를 3회 → 5회로 변경 | **모든 수집기 파일**을 수정 |
| 지수 백오프에 지터 추가 | 복붙된 코드 전부 수정 |
| 통계에 항목 추가 | 전부 수정 |
| 버그 발견 | 한 곳만 고치고 나머지를 놓침 |

복붙된 코드는 시간이 지나며 **조금씩 달라집니다.**
"API 수집기는 되는데 서울 수집기만 재시도가 안 되네" 같은 버그가 생깁니다.

**추상 메서드(`@abstractmethod`)를 쓴 이유**

구현을 빠뜨리면 **객체를 만들 수조차 없습니다.**

```python
class BrokenCollector(BaseCollector):
    pass

BrokenCollector("x", "url")
# TypeError: Can't instantiate abstract class BrokenCollector
#            with abstract methods build_params, extract_items
```

**"이 인터페이스를 지켜라"가 코드로 강제됩니다.** 문서로만 적어 두면 지켜지지 않습니다.

**같은 구조가 계속 나옵니다.**

- W16 [Day 079](../04-deep-learning-serving/day-079.md) — PyTorch `Dataset` (`__len__`·`__getitem__` 만 구현)
