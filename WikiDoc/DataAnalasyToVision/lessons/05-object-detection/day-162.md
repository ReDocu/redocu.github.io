## ③ 개념 설명

### 결과 이미지를 왜 따로 저장하는가

가장 쉬운 방법은 **원본에 박스를 그려 덮어쓰는 것**입니다. 절대 하면 안 됩니다.

```python
# ✗ 절대 금지
img = cv2.imread(upload_path)
draw_boxes(img, detections)
cv2.imwrite(upload_path, img)          # ★ 원본이 사라짐
```

```
★ 원본을 잃으면 못 하는 일

  ① 재처리        모델 v1.2 → v1.3 비교를 ★ 할 수 없음
  ② 임계값 변경    conf 0.45 로 구운 그림에서 ★ 0.30 결과를 못 만듦
  ③ 하드 네거티브  오검출 이미지를 학습에 되돌려야 하는데 ★ 박스가 그려져 있음
  ④ 개인정보 삭제  원본만 지우면 ★ 결과에 얼굴이 그대로 남음
  ⑤ 증거 가치      CCTV 이벤트는 ★ 원본이 있어야 신뢰됩니다
```

**★ 원칙 — 원본은 읽기 전용, 결과는 언제든 다시 만들 수 있는 파생물**

```
static/uploads/up_<uuid>.jpg      ★ 원본 — 절대 수정 금지
static/results/res_<uuid>.jpg     ★ 결과 — 지워도 재생성 가능
instance/results/<rid>.json       ★ 메타 — 이것만 있으면 결과 복원 가능

  원본 + 메타(JSON) ──[draw.py]──> 결과 이미지
  → ★ 디스크가 부족하면 결과 이미지부터 지웁니다
```

### 박스를 그리는 규칙

```
그리는 순서 (★ 순서가 중요)
  ① 박스 테두리  rectangle
  ② 라벨 배경    rectangle(filled)     ← ★ 건너뛰면 밝은 배경에서 글자가 안 보임
  ③ 라벨 텍스트  putText
```

**두께와 글자 크기는 이미지 크기에 비례해야 합니다.**
고정 `2px` 는 4032×3024 사진에서 실오라기가 되고 글자 `0.5` 는 읽히지 않습니다.
**짧은 변 / 400** 을 두께로, **짧은 변 / 1400** 을 글자 크기로 씁니다(Step 1 `auto_scale`).

| 이미지 | 짧은 변 | 선 두께 | 글자 크기 | 라벨 높이 |
|---|---|---|---|---|
| 640×480 | 480 | 2 px | 0.45 | 18 px |
| 1280×720 | 720 | 2 px | 0.51 | 20 px |
| 1920×1080 | 1080 | 3 px | 0.77 | 28 px |
| 4032×3024 | 3024 | 8 px | 2.16 | 72 px |

**라벨이 이미지 밖으로 나가는 경우**

```
    ┌─────────────────────────  y=0
    │ ▓▓ person 0.91 ▓▓        ← ★ 라벨이 y=-28 → 잘림
    │ ┌──────────┐
```

위쪽이 모자라면 **박스 내부 상단**으로 내리고, 오른쪽으로 넘치면
`lx1 = max(0, min(x1, W - label_w))` 로 당깁니다(Step 1 `draw_label`).

> ⚠️ **모델은 이미지 경계를 넘는 박스를 냅니다** (1920px 이미지에서 `x2 = 1934`).
> `cv2.rectangle` 은 알아서 자르지만 **면적·비율 계산이 틀어집니다.**
> 반드시 클리핑하세요 — `x1 = max(0, min(x1, w - 1))`.

### 클래스 색상 설계

| 클래스 | CSS 변수 | HEX | RGB | OpenCV BGR | 선 스타일 |
|---|---|---|---|---|---|
| `person` | `--cls-person` (= `--ok`) | `#10b981` | (16,185,129) | **(129,185,16)** | 실선 |
| `helmet` | `--cls-helmet` (= `--accent`) | `#f59e0b` | (245,158,11) | **(11,158,245)** | 파선 |
| `box` | `--cls-box` (= `--info`) | `#38bdf8` | (56,189,248) | **(248,189,56)** | 점선 |

> ⚠️ **OpenCV 는 BGR 입니다.** `#10b981` 을 `(16,185,129)` 로 넣으면
> **초록이 아니라 청록**이 나옵니다. 변환 함수를 만들어 두세요.

변환은 Step 1 의 `hex_to_bgr` 하나로 통일합니다.

**색만으로 구분하면 안 되는 이유**

```
한국 남성의 약 5.9% 가 색각 이상 (적록 색약이 대부분)
  person #10b981(초록)  ┐
  helmet #f59e0b(주황)  ┘  ★ 적록 색약에게는 거의 같은 색

  ③ 표에는 색 배지 + ★ 글자      ④ 범례 제공

     실선 ────────────  person
     파선 ── ── ── ──   helmet      ★ 흑백 인쇄해도 구분됩니다
     점선 · · · · · ·   box
```

### ★ 좌표계 — 오늘 가장 많이 틀리는 부분

```
모델이 주는 좌표는 ★ 원본 픽셀 기준입니다

  원본 1920×1080, 박스 [412, 233, 588, 701]
  브라우저 표시 720×405   ← CSS max-width:100% 때문에 축소
  그대로 그리면 x=412 는 720px 화면의 ★ 57% 지점 (실제는 21%)
  → ★ 박스가 오른쪽 아래로 밀림
```

| JS 속성 | 의미 | 예 |
|---|---|---|
| `img.naturalWidth` | **원본 픽셀 폭** | 1920 |
| `img.naturalHeight` | **원본 픽셀 높이** | 1080 |
| `img.clientWidth` | 화면 표시 폭 | 720 |
| `img.getBoundingClientRect()` | 위치 + 크기(소수점) | `{x,y,width,height}` |

```javascript
const sx = img.clientWidth / img.naturalWidth;     // 720 / 1920 = 0.375
const left  = x1 * sx;
const width = (x2 - x1) * sx;
```

**★ `object-fit: contain` 이면 여백(letterbox)까지 더해야 합니다**

```
컨테이너 720×540 에 1920×1080 을 contain 으로 넣으면
  ┌──────────────────────┐  ← 720×540
  │░░░░░░░░░░░░░░░░░░░░░░│     ★ 위아래 여백 67.5px
  │██████████████████████│  ← 720×405 (실제 이미지)
  │░░░░░░░░░░░░░░░░░░░░░░│
  └──────────────────────┘
  offsetY 를 안 더하면 ★ 박스가 67.5px 위로 올라갑니다
```

```javascript
  const cw = img.clientWidth, ch = img.clientHeight;
  const nw = img.naturalWidth, nh = img.naturalHeight;
  if (!nw || !nh) return null;                     // ★ 아직 로드 전
  const scale = Math.min(cw / nw, ch / nh);
  return { scale,
           offsetX: (cw - nw * scale) / 2,         // ★ 좌우 여백
           offsetY: (ch - nh * scale) / 2 };
}
```

**★ 그런데 SVG 를 쓰면 이 계산이 전부 필요 없습니다**

```html
<svg viewBox="0 0 1920 1080" preserveAspectRatio="xMidYMid meet">
  <rect x="412" y="233" width="176" height="468"/>
</svg>
```

```
★ viewBox 를 원본 크기로 두면 브라우저가 축소·여백까지 알아서 맞춥니다
  · 창 크기가 바뀌어도 ★ 다시 계산할 필요 없음
  · 좌표를 ★ 모델이 준 그대로 사용
  · 확대해도 ★ 선이 깨지지 않음 (벡터)
  · preserveAspectRatio 가 object-fit:contain 과 ★ 정확히 같은 규칙
```

> ⚠️ **단, `<img>` 와 `<svg>` 의 박스 크기가 정확히 같아야 합니다.**
> `position:absolute; inset:0;` 로 겹치고 둘 다 같은 `object-fit` 규칙을 쓰세요.

### 클래스별 개수 요약

```
    person  ███████████████████░░░░░░░░  3
    helmet  ████████████░░░░░░░░░░░░░░░  2
    box     ████████████░░░░░░░░░░░░░░░  2

★ CSS 만으로 만듭니다 (차트 라이브러리 금지)
  막대 = <div> 의 width: NN%  ·  비율 = count / max_count * 100
```

> ⚠️ **`max` 기준을 정해야 합니다.**
> **합계** 기준이면 막대가 다 짧아 보이고, **최댓값** 기준이면 1등이 항상 100% 입니다.
> ★ 우리는 **최댓값 기준 + 숫자 병기**. 숫자가 진실이고 막대는 보조입니다.

**안전모 착용률** = `helmet 수 / person 수`.
person 3 · helmet 2 → **66.7%**(1명 미착용 의심) · person 3 · helmet 4 → **133%**(오검출 의심).

> ⚠️ **이것은 "추정"입니다.** 헬멧이 사람 머리 위에 있는지 검사하지 않았습니다
> (그건 [Day 170](day-170.md) ROI·IoU 로직). 화면에는 **"참고값"** 이라고 명시하세요.

### ★ 신뢰도 임계값 슬라이더 — 두 가지 방식

```
방식 ① 서버 재추론
  슬라이더 이동 → POST /api/detect (conf=0.55) → 모델 재실행 → 새 결과

방식 ② ★ 클라이언트 필터링
  업로드 시 ★ 한 번만 conf=0.05 로 추론 → 후보 전량을 브라우저로
  → 슬라이더 이동 시 ★ JS 가 걸러서 표시
```

| 항목 | ① 서버 재추론 | ② 클라이언트 필터링 |
|---|---|---|
| 반응 시간 | 60~900 ms + 왕복 | **0~2 ms** |
| 슬라이더 드래그 | 요청 폭주 | 요청 없음 |
| 서버 CPU | 이동마다 100% | 최초 1회 |
| 정확도(conf) | 정확 | **동일** (아래 증명) |
| `iou`(NMS) 변경 | 가능 | **불가** |
| 페이로드 | 작음 | 큼 (후보 전량) |

**왜 ②가 UX 상 옳은가 — 숫자로**

```
0.05 → 0.95 를 step=0.05 로 드래그하면 ★ 이벤트가 18번 발생합니다

  ① 서버 재추론       18 × (추론 62ms + 왕복 15ms + 렌더 8ms) = 1,530 ms
       디바운스 300ms → 손을 뗀 뒤 0.3초 대기 / 없으면 요청 18개 경쟁
  ② 클라이언트 필터링  18 × (filter 0.03ms + DOM 갱신 1.2ms) = ★ 22 ms
       손가락을 따라 즉시 반응 · 순서 뒤집힘 자체가 불가능
```

> ⚠️ **①의 "응답 순서 뒤집힘"은 실제로 자주 겪는 버그입니다.**
> A(conf=0.55)와 B(conf=0.95)를 연달아 보냈는데 **B 가 먼저, A 가 나중에** 오면
> 화면은 B 로 갔다가 **A 로 되돌아갑니다.** 막으려면 요청마다 시퀀스 번호를 붙여
> 최신 것만 반영하는 코드를 또 짜야 합니다. **②에는 이 문제가 없습니다.**

**★ conf 필터가 "동일"한 이유 — NMS 를 다시 보면**

```
NMS 알고리즘 (Day 149)
  1. 신뢰도 내림차순 정렬   2. 맨 위 박스 채택
  3. IoU > 임계값인 나머지 제거   4. 반복

★ 핵심 관찰
  conf 0.45 이상인 박스 X 를 억제할 수 있는 것은
  ★ X 보다 신뢰도가 높은 박스뿐입니다.
  conf 0.05 짜리는 X 보다 항상 뒤에 처리되므로 ★ X 를 억제하지 못합니다.

  → conf=0.05 로 NMS 한 뒤 0.45 이상만 고른 집합
  =  conf=0.45 로 NMS 한 집합            ★ 완전히 동일
```

**★ 그러나 다시 못 하는 것이 있습니다**

| 파라미터 | 클라이언트에서 | 이유 |
|---|---|---|
| `conf` | **가능** | 위 증명 |
| `iou` (NMS) | **불가** | 억제된 박스는 **애초에 응답에 없음** |
| `agnostic_nms` | **불가** | 클래스 간 억제 규칙이 추론 시 확정 |
| `max_det` | **부분 불가** | 상한에서 잘린 것은 복구 불가 |
| `imgsz` | **불가** | 전처리 단계 |
| 클래스 표시 | 가능 | `agnostic_nms=False` 면 클래스 간 억제 없음 |

```
★ "NMS 를 다시 못 한다" 는 뜻
  iou=0.70 으로 이미 지워진 박스는 ★ 브라우저에 없습니다.
  "겹친 사람을 더 살리고 싶다" 며 iou 를 0.9 로 올리려면 ★ 서버 재추론뿐입니다.

★ 그래서 둘을 섞습니다
  ┌───────────────────────────────────────────┐
  │  신뢰도  ●────────────  0.45    ★ 즉시     │
  │  표시    ☑person ☑helmet ☑box  ★ 즉시     │
  │  ────────────────────────────────────────  │
  │  NMS IoU ●──────  0.70                    │
  │            [ 이 설정으로 다시 검출 ]  ★ 서버 │
  └───────────────────────────────────────────┘
```

> ⚠️ **`raw_conf` 를 너무 낮추지 마세요.** `0.001` 로 뽑으면 후보가 수천 개라
> JSON 이 수백 KB, 후처리가 10배 느려지고 `max_det=300` 에 걸려 **오히려 잘립니다.**
> ★ **0.05 가 실무 기본값**입니다.

| `raw_conf` | 후보 수 | JSON 크기 | 후처리 | 슬라이더 하한 |
|---|---|---|---|---|
| 0.45 | 7 | 1.4 KB | 2.6 ms | 0.45 (못 내림) |
| **0.05** | **41** | **7.8 KB** | **4.2 ms** | **0.05** |
| 0.01 | 168 | 31 KB | 9.8 ms | 0.01 |
| 0.001 | 300 (잘림) | 56 KB | 24.1 ms | 신뢰 불가 |

### 결과 없음(0건) 처리

```
✗ "검출 결과: 0건"  → 사용자: "왜?"

  │  ⌕  검출된 객체가 없습니다                     │

핵심 — raw_conf=0.05 로 뽑아 뒀으므로 임계값 미만 후보를 이미 알고 있습니다.
```

| 상황 | 안내 | 행동 버튼 |
|---|---|---|
| 후보 있음(0.05~conf) | "임계값을 낮추면 N건" | **임계값 낮추기**(즉시) |

| 클래스 필터 중 | "person 만 보는 중" | **전체 보기** |
| 이미지가 작음(<640px) | "해상도가 낮습니다" | 원본 크기로 재업로드 |
| 어두움(평균 밝기<40) | "너무 어둡습니다" | — |

> ⚠️ **0건은 오류가 아닙니다.** HTTP 상태 코드는 반드시 **200** 입니다.
> "찾지 못함"과 "요청이 잘못됨"은 다릅니다. 404 를 주면 클라이언트가
> **재시도 로직을 잘못 태웁니다.**

| 500 | `internal_error` · `save_failed` | 예상 못 한 예외 | 가능 |
| **503** | `model_not_ready` | 워밍업 중 | **가능** |

```

  모델 로드는 2.4초 걸립니다. 앱이 막 뜬 직후 요청이 오면 모델이 없습니다.
```

### Step 1. 결과 이미지 렌더러 `utils/draw.py`

```python
"""web/utils/draw.py — 검출 결과를 이미지에 그린다

★ 원본을 절대 수정하지 않습니다 (항상 복사본).
★ 선 두께·글자 크기는 이미지 크기에 비례합니다.
★ 클래스는 색 + 선 스타일 + 글자 세 가지로 구분합니다.
"""
from __future__ import annotations

import cv2
import numpy as np

# 클래스 색 — static/css/style.css 의 --cls-* 와 동일해야 합니다
CLASS_HEX = {"person": "#10b981", "helmet": "#f59e0b", "box": "#38bdf8"}
CLASS_STYLE = {"person": "solid", "helmet": "dashed", "box": "dotted"}
DEFAULT_HEX = "#9aa3b2"
FONT = cv2.FONT_HERSHEY_SIMPLEX
TEXT_BGR = (17, 17, 17)


def hex_to_bgr(h: str) -> tuple[int, int, int]:
    """'#10b981' → (129, 185, 16)   OpenCV 는 BGR"""
    h = h.lstrip("#")
    if len(h) == 3:
        h = "".join(c * 2 for c in h)
    return (int(h[4:6], 16), int(h[2:4], 16), int(h[0:2], 16))


def class_bgr(name: str):
    return hex_to_bgr(CLASS_HEX.get(name, DEFAULT_HEX))


def auto_scale(h: int, w: int) -> tuple[int, float]:
    """짧은 변 기준 — 480→(2,0.45) 1080→(3,0.77) 3024→(8,2.16)"""
    base = min(h, w)
    return max(2, int(round(base / 400))), max(0.45, base / 1400)


def clip_box(box, w: int, h: int) -> tuple[int, int, int, int]:
    """이미지 밖으로 나간 좌표를 잘라낸다 (면적 계산이 틀어지는 것 방지)"""
    x1, y1, x2, y2 = (int(round(v)) for v in box)
    x1, x2 = sorted((max(0, min(x1, w - 1)), max(0, min(x2, w - 1))))
    y1, y2 = sorted((max(0, min(y1, h - 1)), max(0, min(y2, h - 1))))
    return x1, y1, x2, y2


def resize_long_side(img: np.ndarray, size: int) -> np.ndarray:
    """긴 변을 size 로 (확대는 하지 않음)"""
    h, w = img.shape[:2]
    if max(h, w) <= size:
        return img.copy()
    s = size / max(h, w)
    return cv2.resize(img, (int(w * s), int(h * s)), interpolation=cv2.INTER_AREA)


def _dashed_line(img, p1, p2, color, thick, dash, gap):
    """OpenCV 에는 파선 함수가 없어 직접 만듭니다"""
    (x1, y1), (x2, y2) = p1, p2
    dist = int(round(float(np.hypot(x2 - x1, y2 - y1))))
    if dist == 0:
        return
    for i in range(0, dist, max(2, dash + gap)):
        s, e = i / dist, min(i + dash, dist) / dist
        cv2.line(img,
                 (int(x1 + (x2 - x1) * s), int(y1 + (y2 - y1) * s)),
                 (int(x1 + (x2 - x1) * e), int(y1 + (y2 - y1) * e)),
                 color, thick, cv2.LINE_AA)


def draw_rect(img, p1, p2, color, thick, style="solid"):
    """실선 / 파선 / 점선 사각형 — 색맹 대응"""
    if style == "solid":
        cv2.rectangle(img, p1, p2, color, thick, cv2.LINE_AA)
        return
    unit = max(4, thick * 3)
    dash, gap = (unit * 3, unit * 2) if style == "dashed" else (thick, unit * 2)
    (x1, y1), (x2, y2) = p1, p2
    for a, b in (((x1, y1), (x2, y1)), ((x2, y1), (x2, y2)),
                 ((x2, y2), (x1, y2)), ((x1, y2), (x1, y1))):
        _dashed_line(img, a, b, color, thick, dash, gap)


def draw_label(img, text, x, y, color, font_scale, thick):
    """이미지 밖으로 나가지 않게 위치를 보정한 라벨"""
    h, w = img.shape[:2]
    tw, th = cv2.getTextSize(text, FONT, font_scale, thick)[0]
    px, py = max(4, int(font_scale * 8)), max(3, int(font_scale * 6))
    bw, bh = tw + px * 2, th + py * 2

    lx1 = max(0, min(x, w - bw))                       # 오른쪽 넘침 보정
    ly1 = y if (y - bh < 0) else y - bh                # 위쪽 넘침 보정
    ly1 = max(0, min(ly1, h - bh))

    cv2.rectangle(img, (lx1, ly1), (lx1 + bw, ly1 + bh), color, -1, cv2.LINE_AA)
    cv2.putText(img, text, (lx1 + px, ly1 + bh - py),
                FONT, font_scale, TEXT_BGR, thick, cv2.LINE_AA)


def label_mode(n: int, label_limit=50, box_limit=150) -> str:
    """개수에 따라 라벨을 자동으로 줄인다"""
    if n > box_limit:
        return "none"
    return "index" if n > label_limit else "full"


def draw_detections(img: np.ndarray, detections: list[dict], *,
                    conf: float = 0.0, visible: set[str] | None = None,
                    label_limit: int = 50, box_limit: int = 150) -> np.ndarray:
    """★ 검출 결과를 그린 새 이미지를 반환 (원본 불변)"""
    out = img.copy()                                   # 원본 보호
    h, w = out.shape[:2]
    thick, fs = auto_scale(h, w)

    items = [d for d in detections
             if d.get("conf", 0) >= conf
             and (visible is None or d.get("class_name") in visible)]
    items.sort(key=lambda d: d.get("conf", 0), reverse=True)
    items = items[:box_limit]                          # 상한
    mode = label_mode(len(items), label_limit, box_limit)

    for i, d in enumerate(items):
        name = d.get("class_name", "?")
        color = class_bgr(name)
        x1, y1, x2, y2 = clip_box(d["box"], w, h)
        draw_rect(out, (x1, y1), (x2, y2), color, thick,
                  CLASS_STYLE.get(name, "solid"))
        if mode == "full":
            draw_label(out, f"{i+1} {name} {d['conf']:.2f}",
                       x1, y1, color, fs, max(1, thick - 1))
        elif mode == "index":
            draw_label(out, str(i + 1), x1, y1, color, fs, max(1, thick - 1))
    return out


def draw_empty_notice(img: np.ndarray, text="NO DETECTION") -> np.ndarray:
    """0건일 때도 결과 이미지를 만든다 (갤러리 썸네일용)"""
    out = img.copy()
    h, w = out.shape[:2]
    thick, fs = auto_scale(h, w)
    tw, th = cv2.getTextSize(text, FONT, fs, thick)[0]
    x, y, pad = (w - tw) // 2, (h + th) // 2, int(14 * fs / 0.77)
    ov = out.copy()
    cv2.rectangle(ov, (x - pad, y - th - pad), (x + tw + pad, y + pad),
                  (24, 26, 33), -1)
    cv2.addWeighted(ov, 0.75, out, 0.25, 0, out)
    cv2.putText(out, text, (x, y), FONT, fs, (154, 163, 178), thick, cv2.LINE_AA)
    return out
```

```python
"""web/utils/results.py — 검출 결과 가공

★ 여기의 filter_detections 와 static/js/filter.js 의 필터는 ★ 동일 규칙입니다.
   Step 8 의 pytest 로 등가성을 검증합니다.
"""
from __future__ import annotations

import csv
import io

CLASS_ORDER = ["person", "helmet", "box"]


def enrich(detections: list[dict], W: int, H: int) -> list[dict]:
    """★ 화면·API 에 필요한 파생 값을 채운다"""
    total = max(1, W * H)
    out = []
    for i, d in enumerate(detections):
        x1, y1, x2, y2 = (int(round(v)) for v in d["box"])
        cx1, cy1 = max(0, min(x1, W)), max(0, min(y1, H))
        cx2, cy2 = max(0, min(x2, W)), max(0, min(y2, H))
        w, h = max(0, cx2 - cx1), max(0, cy2 - cy1)
        out.append({
            "id": i, "class_id": int(d["class_id"]),
            "class_name": d["class_name"], "conf": round(float(d["conf"]), 3),
            "box": [cx1, cy1, cx2, cy2],
            # ★ YOLO 형식 (중심점 정규화) — Day 136
            "box_norm": [round((cx1 + cx2) / 2 / W, 4),
                         round((cy1 + cy2) / 2 / H, 4),
                         round(w / W, 4), round(h / H, 4)],
            "size": {"w": w, "h": h, "area": w * h,
                     "area_pct": round(w * h / total * 100, 2)},
            "clipped": (x1, y1, x2, y2) != (cx1, cy1, cx2, cy2),
        })
    return out


def filter_detections(dets: list[dict], conf: float,
                      classes: list[str] | None = None) -> list[dict]:
    """★ 표시 임계값·클래스로 거른다 (JS 와 동일 규칙)"""
    out = [d for d in dets if d["conf"] >= conf]
    if classes:
        allowed = set(classes)
        out = [d for d in out if d["class_name"] in allowed]
    return sorted(out, key=lambda d: d["conf"], reverse=True)


def counts_by_class(dets: list[dict]) -> dict[str, int]:
    """★ 0인 클래스는 넣지 않는다"""
    c: dict[str, int] = {}
    for d in dets:
        c[d["class_name"]] = c.get(d["class_name"], 0) + 1
    ordered = {k: c[k] for k in CLASS_ORDER if k in c}
    ordered.update({k: v for k, v in c.items() if k not in CLASS_ORDER})
    return ordered


def summarize(dets: list[dict], W: int, H: int) -> dict:
    counts = counts_by_class(dets)
    person, helmet = counts.get("person", 0), counts.get("helmet", 0)
    confs = [d["conf"] for d in dets]
    return {
        "count": len(dets), "counts_by_class": counts,
        "max_count": max(counts.values()) if counts else 0,
        "max_conf": round(max(confs), 3) if confs else 0.0,
        "avg_conf": round(sum(confs) / len(confs), 3) if confs else 0.0,
        "coverage_pct": round(sum(d["size"]["area"] for d in dets)
                              / max(1, W * H) * 100, 2),
        # ★ 참고값 — 헬멧이 사람 머리에 있는지는 검사하지 않음
        "helmet_rate": round(helmet / person * 100, 1) if person else None,
        "helmet_rate_suspicious": bool(person and helmet > person),
    }


def alt_text(dets: list[dict]) -> str:
    """★ 화면낭독기용 대체 텍스트"""
    if not dets:
        return "검출 결과 이미지 — 검출된 객체가 없습니다"
    parts = [f"{k} {v}건" for k, v in counts_by_class(dets).items()]
    return "검출 결과 이미지 — " + ", ".join(parts) + "이 표시됨"


def to_csv(dets: list[dict]) -> str:
    buf = io.StringIO()
    w = csv.writer(buf, lineterminator="\n")
    w.writerow(["no", "class", "conf", "x1", "y1", "x2", "y2",
                "w", "h", "area", "area_pct"])
    for i, d in enumerate(dets, 1):
        b, s = d["box"], d["size"]
        w.writerow([i, d["class_name"], d["conf"], *b,
                    s["w"], s["h"], s["area"], s["area_pct"]])
    return buf.getvalue()
```

```python
"""web/services/detection.py — ★ HTML 과 API 의 공통 진입점"""
from __future__ import annotations

import json
import time
import uuid
from datetime import datetime
from pathlib import Path

from services.model import get_model, MODEL_INFO          # ★ Day 161
from upload_utils import save_bytes, save_image
from utils.draw import draw_detections, draw_empty_notice, resize_long_side
from utils.results import enrich, filter_detections, summarize, alt_text

RAW_CONF = 0.05          # ★ 항상 이 값으로 추론 — 클라이언트 필터링의 전제
API_VERSION = "1.1"
JPEG_Q, THUMB_Q = 85, 80


def analyze(img, data: bytes, meta: dict, *, conf=0.45, iou=0.70, classes=None,
            upload_dir: Path, result_dir: Path, meta_dir: Path,
            save=True, draw=True) -> dict:
    """검출 → 가공 → 저장. 그대로 JSON 으로 쓸 수 있는 record 를 돌려준다."""
    t0 = time.perf_counter()
    h, w = img.shape[:2]

    raw = get_model().predict_image(img, conf=RAW_CONF, iou=iou, classes=classes)
    dets_all = enrich(raw["detections"], w, h)           # ★ 후보 전량
    view = filter_detections(dets_all, conf)             # ★ 표시분

    up_name = res_name = th_name = None
    t_draw = 0.0
    if save:
        up_name = save_bytes(data, upload_dir, meta["ext"],
                             prefix="up_")["stored_name"]
    if draw:
        td = time.perf_counter()
        canvas = draw_detections(img, view, conf=conf) if view \
            else draw_empty_notice(img)
        t_draw = (time.perf_counter() - td) * 1000
        if save:
            res_name = save_image(canvas, result_dir, ".jpg", prefix="res_",
                                  quality=JPEG_Q)["stored_name"]
            th_name = save_image(resize_long_side(canvas, 400), result_dir,
                                 ".jpg", prefix="th_",
                                 quality=THUMB_Q)["stored_name"]

    t = raw["timing_ms"]
    rid = uuid.uuid4().hex[:12]
    record = {
        "rid": rid, "api_version": API_VERSION,
        "created_at": datetime.now().isoformat(timespec="seconds"),
        "upload": {**meta, "stored_name": up_name},
        "result_image": res_name, "thumb_image": th_name,
        "image": {"width": w, "height": h, "megapixels": round(w * h / 1e6, 2),
                  "exif_rotated": meta.get("exif_rotated", False)},
        "model": MODEL_INFO,
        "params": {"conf": conf, "raw_conf": RAW_CONF, "iou": iou,
                   "classes": classes, "max_det": MODEL_INFO.get("max_det", 300)},
        "timing_ms": {"preprocess": round(t.get("preprocess", 0), 1),
                      "inference": round(t.get("inference", 0), 1),
                      "postprocess": round(t.get("postprocess", 0), 1),
                      "draw": round(t_draw, 1),
                      "total": round((time.perf_counter() - t0) * 1000, 1)},
        "count": len(view), "raw_count": len(dets_all),
        "truncated": len(dets_all) >= MODEL_INFO.get("max_det", 300),
        "summary": summarize(view, w, h), "alt_text": alt_text(view),
        "detections_all": dets_all,      # ★ 전량 보관 — 클라이언트 필터의 재료
    }
    if save:
        meta_dir.mkdir(parents=True, exist_ok=True)
        (meta_dir / f"{rid}.json").write_text(
            json.dumps(record, ensure_ascii=False, indent=2), encoding="utf-8")
    return record
```

```python
"""web/blueprints/detect.py — 결과 페이지 (Day 160 Blueprint 구조)"""
import json

from flask import (Blueprint, Response, abort, current_app, jsonify,
                   render_template, request, url_for)

bp = Blueprint("detect", __name__)


def load_record(rid: str) -> dict:
    """★ 경로 조작 방어 — rid 는 12자리 영숫자만"""
    if not rid.isalnum() or len(rid) != 12:
        abort(404)
    path = current_app.config["META_DIR"] / f"{rid}.json"
    if not path.exists():
        abort(404, description="결과를 찾을 수 없습니다")
    return json.loads(path.read_text(encoding="utf-8"))


@bp.get("/result/<rid>")
def show_result(rid):
    rec = load_record(rid)
    conf = rec["params"]["conf"]
    return render_template(
        "result.html", active_page="upload", record=rec,
        detections=filter_detections(rec["detections_all"], conf),
        detections_all=rec["detections_all"],       # ★ JS 로 넘길 전량
        summary=rec["summary"], conf=conf, raw_conf=rec["params"]["raw_conf"],
        original_url=url_for("static",
                             filename=f"uploads/{rec['upload']['stored_name']}"),
        result_url=(url_for("static", filename=f"results/{rec['result_image']}")
                    if rec["result_image"] else None))


@bp.get("/result/<rid>.csv")
def result_csv(rid):
    rec = load_record(rid)
    conf = request.args.get("conf", type=float, default=rec["params"]["conf"])
    rows = filter_detections(rec["detections_all"], conf)
    return Response("﻿" + to_csv(rows),          # ★ BOM — 엑셀 한글 보호
                    mimetype="text/csv; charset=utf-8",
                    headers={"Content-Disposition":
                             f'attachment; filename="detections_{rid}.csv"'})


@bp.get("/result/<rid>.json")
def result_json(rid):
    return jsonify(load_record(rid))
```

### Step 3. SVG 오버레이 + 표 연동 `static/js/result.js`

```javascript
/* static/js/result.js — 결과 화면 (Day 162)
 *   · SVG 오버레이 생성 (viewBox = 원본 픽셀)  · 표 ↔ 박스 양방향 강조
 *   · 뷰 모드 전환  · 라이트박스(라이브러리 없이)
 *   window.ResultView 를 노출합니다 — filter.js 가 render() 를 부릅니다.
 */
(function () {
  'use strict';
  const NS = 'http://www.w3.org/2000/svg';
  const DASH = { person: null, helmet: '18 10', box: '3 10' };  // 색맹 대응
  const FONT_PX = 13;                        // 화면에서 보일 글자 크기

  const meta = window.RESULT_META || {};
  const dataEl = document.getElementById('det-data');
  const ALL = dataEl ? JSON.parse(dataEl.textContent) : [];

  const viewer = document.getElementById('viewer');
  const imgBase = document.getElementById('img-base');
  const overlay = document.getElementById('overlay');
  const tbody = document.getElementById('det-tbody');
  const ROW_LIMIT = 50;
  let current = [], showAllRows = false;

  const esc = s => String(s).replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));

  /* ══ ★ 좌표계 — naturalWidth 로 배율을 역산해 글자 크기를 맞춘다 ══ */
  function syncScale(svg, img) {
    if (!img || !img.naturalWidth) return;          // 로드 전엔 0
    const scale = img.getBoundingClientRect().width / img.naturalWidth;
    if (!scale) return;
    svg.style.setProperty('--fs', (FONT_PX / scale) + 'px');
    svg.style.setProperty('--pad', String(4 / scale));
  }

  function labelMode(n) {
    if (n > (meta.boxLimit || 150)) return 'none';
    return n > (meta.labelLimit || 50) ? 'index' : 'full';
  }

  function makeNode(d, i, mode) {
    const [x1, y1, x2, y2] = d.box;
    const color = `var(--cls-${d.class_name}, var(--muted))`;
    const g = document.createElementNS(NS, 'g');
    g.setAttribute('class', 'det');
    g.dataset.det = d.id;

    const rect = document.createElementNS(NS, 'rect');
    rect.setAttribute('class', 'box');
    rect.setAttribute('x', x1); rect.setAttribute('y', y1);
    rect.setAttribute('width', Math.max(1, x2 - x1));
    rect.setAttribute('height', Math.max(1, y2 - y1));
    rect.setAttribute('stroke', color);
    if (DASH[d.class_name]) rect.setAttribute('stroke-dasharray', DASH[d.class_name]);
    g.appendChild(rect);

    if (mode !== 'none') {
      const bg = document.createElementNS(NS, 'rect');
      bg.setAttribute('class', 'labelbg');
      bg.setAttribute('fill', color);
      const t = document.createElementNS(NS, 'text');
      t.setAttribute('class', 'label');
      t.textContent = mode === 'full'
        ? `${i + 1} ${d.class_name} ${d.conf.toFixed(2)}` : String(i + 1);
      g.appendChild(bg); g.appendChild(t);
      g.dataset.fix = '1';                     // 다음 프레임에 위치 보정
    }

    const title = document.createElementNS(NS, 'title');
    title.textContent = `${d.class_name} ${(d.conf * 100).toFixed(1)}% ` +
      `(${d.size.w}×${d.size.h}, 화면의 ${d.size.area_pct}%)`;
    g.appendChild(title);
    return g;
  }

  function fixLabels(svg) {
    /* getBBox 는 렌더 후에만 정확합니다 */
    const pad = parseFloat(svg.style.getPropertyValue('--pad')) || 4;
    const W = meta.imageWidth, H = meta.imageHeight;
    svg.querySelectorAll('g.det[data-fix]').forEach(g => {
      const t = g.querySelector('text.label'), bg = g.querySelector('rect.labelbg');
      const box = g.querySelector('rect.box');
      let bb; try { bb = t.getBBox(); } catch (e) { return; }
      const bw = bb.width + pad * 2, bh = bb.height + pad * 2;
      const bx = parseFloat(box.getAttribute('x')), by = parseFloat(box.getAttribute('y'));
      const lx = Math.max(0, Math.min(bx, W - bw));          // 오른쪽 보정
      let ly = (by - bh < 0) ? by : by - bh;                 // 위쪽 보정
      ly = Math.max(0, Math.min(ly, H - bh));
      bg.setAttribute('x', lx); bg.setAttribute('y', ly);
      bg.setAttribute('width', bw); bg.setAttribute('height', bh);
      t.setAttribute('x', lx + pad);
      t.setAttribute('y', ly + bh - pad - bb.height * 0.18);
      delete g.dataset.fix;
    });
  }

  function renderOverlay(svg, img, list) {
    svg.textContent = '';
    const mode = labelMode(list.length);
    list.slice(0, meta.boxLimit || 150)
        .forEach((d, i) => svg.appendChild(makeNode(d, i, mode)));
    syncScale(svg, img);
    requestAnimationFrame(() => fixLabels(svg));
  }

  /* ══ 표 ══ */
  function rowHtml(d, i) {
    const b = d.box, s = d.size, pct = d.conf * 100;
    return `<tr data-det="${d.id}" tabindex="0"><td>${i + 1}</td>` +
      `<td><span class="badge badge-${esc(d.class_name)}">${esc(d.class_name)}</span></td>` +
      `<td><div class="bar"><div class="fill" style="width:${pct.toFixed(0)}%"></div>` +
      `<span>${pct.toFixed(1)}%</span></div></td>` +
      `<td>${b[0]}</td><td>${b[1]}</td><td>${b[2]}</td><td>${b[3]}</td>` +
      `<td>${s.w}×${s.h}</td><td>${s.area.toLocaleString()}</td>` +
      `<td>${s.area_pct}%</td></tr>`;
  }

  function renderTable(list) {
    const note = document.getElementById('table-note');
    if (!list.length) {
      tbody.innerHTML = '<tr><td colspan="10" class="empty">검출된 객체가 없습니다</td></tr>';
      note.textContent = ''; return;
    }
    tbody.innerHTML = (showAllRows ? list : list.slice(0, ROW_LIMIT))
      .map(rowHtml).join('');
    if (list.length > ROW_LIMIT && !showAllRows) {
      note.innerHTML = `총 <b>${list.length}</b>건 중 ${ROW_LIMIT}건 표시 · ` +
```

```python
    return resp


def err(request_id, code, message, status=400, *,

def parse_classes(raw):
    """'person,box' 또는 '0,2' → ([0,2], None) / (None, 오류메시지)"""
    if not raw:
        return None, None
    ids = []
    for tok in (t.strip() for t in raw.split(",")):
        if not tok:
            continue
        if tok.isdigit() and 0 <= int(tok) < len(CLASS_NAMES):
            ids.append(int(tok))
        elif tok in CLASS_NAMES:
            ids.append(CLASS_NAMES.index(tok))
        else:
            return None, (f"알 수 없는 클래스: {tok} "
                          f"(허용: {', '.join(CLASS_NAMES)})")
    return (sorted(set(ids)) or None), None
```

```python
"""tools/api_client.py — 라즈베리파이·배치에서 쓰는 최소 클라이언트"""
import requests

BASE = "http://127.0.0.1:5000"


def detect(path, conf=0.45, timeout=30.0) -> dict:
    with open(path, "rb") as f:
        r = requests.post(f"{BASE}/api/detect", data={"conf": conf},
                          files={"image": (path, f, "image/jpeg")},
                          timeout=timeout)
    if r.status_code == 503:                          # ★ 재시도할 가치가 있음
        raise RuntimeError(f"모델 준비 중 — {r.headers.get('Retry-After', 3)}초 후")
    body = r.json()
    if not body.get("ok"):
        raise RuntimeError(f"[{r.status_code}] {body['error']}: {body['message']}")
    if body["api_version"].split(".")[0] != "1":      # ★ MAJOR 가 다르면 중단
        raise RuntimeError(f"API 메이저 버전이 다릅니다: {body['api_version']}")
    return body


if __name__ == "__main__":
    res = detect("samples/site_01.jpg")

          f"{res['timing_ms']['total']}ms  {res['counts_by_class']}  "
          f"{BASE}{res['page_url']}")
```

```javascript
/* static/js/api-demo.js — 브라우저에서 직접 호출 */
async function detectImage(file, opts = {}) {
  const fd = new FormData();
  fd.append('image', file);
  fd.append('conf', opts.conf ?? 0.45);
  if (opts.classes) fd.append('classes', opts.classes.join(','));

  const ctrl = new AbortController();               // ★ fetch 는 기본 타임아웃이 없음
  const timer = setTimeout(() => ctrl.abort(), 30000);
  let res;
  try {
    res = await fetch('/api/detect', { method: 'POST', body: fd,
                                       signal: ctrl.signal });
    // ★ Content-Type 을 직접 넣지 말 것 — boundary 가 빠집니다
  } catch (e) {
    throw new Error(e.name === 'AbortError' ? '시간이 초과되었습니다'
                                            : '네트워크 오류: ' + e.message);
  } finally { clearTimeout(timer); }

  const body = await res.json();
  if (res.status === 503)
    throw new Error(`모델 준비 중 — ${res.headers.get('Retry-After') || 3}초 후 재시도`);
  if (!body.ok) throw new Error(`[${body.error}] ${body.message}`);
  return body;
}
```

> ⚠️ **`fetch` 에 `Content-Type` 헤더를 직접 넣지 마세요.**
> `FormData` 를 보낼 때 브라우저가 **`boundary` 를 포함한 헤더를 자동 생성**합니다.
> 직접 `'multipart/form-data'` 를 넣으면 boundary 가 빠져
> **서버가 파일을 파싱하지 못합니다** — `no_file` 오류의 흔한 원인입니다.

| | `curl` | `requests` | `fetch` |
|---|---|---|---|
| 용도 | 빠른 확인·디버깅 | 파이·배치·테스트 | 웹 화면 |
| 파일 | `-F "image=@f.jpg"` | `files={"image": f}` | `FormData.append` |
| 타임아웃 | `--max-time` | `timeout=` | `AbortController` |
| 재시도 | 쉘 반복 | `Session` + 백오프 | 직접 구현 |

```python
"""web/utils/storage.py — ★ 단계별 디스크 정리"""
TIERS = [  # (설명, 폴더키, 접두사, 기본 보존일, 재생성 가능)
    ("썸네일", "results", "th_", 7, True),
    ("결과 이미지", "results", "res_", 7, True),
    ("메타 JSON", "meta", "", 90, False),
    ("원본", "uploads", "up_", 30, False),
]


def sweep(dirs, days_map, dry_run=False):
    """TIERS 를 돌며 보존일이 지난 파일을 지우고 결과를 보고한다"""
    report = []
    for label, key, prefix, default_days, regen in TIERS:
        d, days = Path(dirs[key]), days_map.get(label, default_days)
        cutoff = (datetime.now() - timedelta(days=days)).timestamp()
        deleted = freed = 0
        for p in d.glob(f"{prefix}*") if d.exists() else []:
            if p.is_file() and p.stat().st_mtime < cutoff:
                freed += p.stat().st_size
                if not dry_run:
                    p.unlink(missing_ok=True)
                deleted += 1
        report.append({"label": label, "days": days, "deleted": deleted,
                       "freed_mb": round(freed / 1024 / 1024, 2),
                       "regenerable": regen})
    return report
```

`emergency_cleanup(dirs, target_pct=80)` 은 이 `sweep` 을 **1단계 기본 → 2단계
파생물 3일 → 3단계 파생물 전부 → 4단계 원본 단축** 순으로 부르되, ★ 목표
사용률에 닿는 즉시 멈춥니다. 그리고 `regenerate_result(rid)` 는 메타 JSON 의
`detections_all` 과 원본으로 `draw_detections` 를 다시 돌려 결과 이미지를
되살립니다 — ★ 원본이 없을 때만 실패합니다.

```
2단계 파생물 3일  84.6% → 71.4%   (썸네일 401개 11MB · 결과 401개 95MB)
★ 목표 달성 — 3·4단계는 실행되지 않음. 잃은 것은 ★ 재생성 가능한 파생물뿐.
```

| 항목 | 핵심 |
|---|---|
| 원본 보존 | 결과는 **별도 폴더** · 원본은 **읽기 전용** |
| 파생물 | 원본 + 메타 JSON → **결과 이미지 재생성 가능** |
| 보존 정책 | 결과 7일 · 원본 30일 · **메타 90일** |
| JPEG 품질 | 결과 **85** · 썸네일 80 · 라벨 글자가 먼저 뭉개짐 |
| 선 두께·글자 | **짧은 변 / 400**, `/ 1400` 로 자동 비례 |
| 색 | **OpenCV 는 BGR** · `hex_to_bgr` |
| 색맹 대응 | 색 + **글자** + **선 스타일**(실선/파선/점선) |
| 좌표계 | 모델 = **원본 픽셀** · 화면 = 축소됨 |
| 해결책 | **SVG `viewBox="0 0 W H"`** → 변환 코드 불필요 |
| 직접 계산 시 | `naturalWidth` · **contain 여백(offset)** |
| `naturalWidth` | **로드 전엔 0** → `load` 이벤트 + 방어 |
| 오버레이 | 굽기(다운로드) + **SVG(대화형)** 병행 |
| 표 ↔ 박스 | **`data-det`** + 이벤트 위임 + `focusin` |
| conf 슬라이더 | **클라이언트 필터링** — 서버 재추론과 **결과 동일** |
| 못 하는 것 | **iou(NMS)** · `agnostic_nms` · `max_det` · `imgsz` |
| `raw_conf` | **0.05** — 너무 낮추면 후보 폭증·max_det 절단 |
| 슬라이더 `min` | **`raw_conf` 로 고정** |
| 0건 | 상태 **200** · **후보 기반 원인 안내** |
| 다수 검출 | 라벨 모드 자동 전환(전체 → 번호 → 없음) |
| API | **`api_version`** · 에러 형식 통일 · **503 + `Retry-After`** |
| 공통 서비스 | HTML 과 API 가 **같은 `analyze()`** 를 쓴다 |

**오늘 반드시 기억할 세 가지**

> ③ **conf 슬라이더는 클라이언트에서 거르세요.** 결과는 서버 재추론과 완전히 같고 반응은 70배 빠릅니다. 다만 **iou 는 서버가 다시 해야 합니다.**
