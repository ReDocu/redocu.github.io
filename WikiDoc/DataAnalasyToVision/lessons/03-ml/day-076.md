## ② 왜 필요한가

### if문으로 고양이를 판별해 보세요

여러분은 지금까지 규칙을 직접 썼습니다. 이번에도 그렇게 해 봅시다.

```python
def is_cat(image):
    if 귀가_뾰족하다(image) and 수염이_있다(image):
        return True
    return False
```

여기서 막힙니다. **`귀가_뾰족하다()` 를 어떻게 구현합니까?**

```python
def 귀가_뾰족하다(image):
    # 픽셀 배열에서 '귀'를 어떻게 찾지?
    # 귀가 접힌 고양이는? 옆모습이면? 새끼 고양이는?
    # 뒤에서 찍었으면 귀가 안 보이는데?
    ...
```

**규칙을 다 적을 수 없습니다.** 조건을 100개 붙여도 101번째 예외가 나옵니다.

### 그런데 사람은 0.1초 만에 압니다

세 살짜리도 고양이를 압니다. 규칙을 배운 적이 없는데도요.
**고양이를 수천 번 봤기 때문입니다.**

머신러닝은 이 방식을 흉내 냅니다.

```
[규칙 기반]   규칙(if문)  +  입력  →  프로그램  →  답
[머신러닝]    입력  +  답            →  프로그램  →  규칙
```

**입력과 답을 잔뜩 주면, 규칙을 프로그램이 찾아냅니다.**
찾아낸 규칙을 **모델(model)** 이라고 부릅니다.

### 대단원 02와의 연결

여행지 추천 프로젝트에서 이런 코드를 썼습니다. ([Day 069](../02-numpy-pandas/day-069.md))

```python
df["점수"] = (df["평점"] * 0.4 + df["리뷰수_정규화"] * 0.3 + df["접근성"] * 0.3)
```

**0.4 / 0.3 / 0.3 을 누가 정했습니까?** 여러분이 정했습니다. 근거는 "그럴듯해서"였습니다.

머신러닝은 이 가중치를 데이터에서 **찾아냅니다.**
"사람들이 실제로 많이 간 여행지" 데이터를 주면, 평점이 리뷰수보다 몇 배 중요한지 모델이 계산합니다.

| | 대단원 02 | 대단원 03 |
|---|---|---|
| 가중치 0.4, 0.3, 0.3 | **내가 정한다** | **데이터에서 학습한다** |
| 근거 | 직관 | 실제 결과와의 오차 최소화 |
| 새 데이터 | 다시 손으로 조정 | 다시 학습시키면 됨 |

### 규칙 기반이 더 나은 경우도 있습니다

**머신러닝이 만능이 아닙니다.** 이런 문제는 if문이 정답입니다.

| 문제 | 어느 쪽 | 이유 |
|---|---|---|
| 주민번호 형식이 맞는가 | **규칙** | 규칙이 명확하고 예외가 없음 |
| 부가세 계산 | **규칙** | 정답이 법으로 정해져 있음 |
| 로그인 비밀번호 일치 | **규칙** | 정확히 같아야 함 |
| 이 사진이 고양이인가 | **ML** | 규칙을 적을 수 없음 |
| 이 리뷰가 긍정인가 | **ML** | 표현이 무한히 다양함 |
| 내일 이 상품이 몇 개 팔릴까 | **ML** | 변수가 너무 많음 |

> **판단 기준** — "규칙을 문장으로 적을 수 있는가?"
> 적을 수 있으면 규칙 기반이 더 빠르고 정확하고 설명 가능합니다.
> 적을 수 없거나, 적으려니 예외가 끝없이 나오면 그때 머신러닝입니다.

## ③ 개념 설명

### 머신러닝의 정의

> **머신러닝** — 명시적으로 프로그래밍하지 않고, 데이터로부터 규칙(패턴)을 학습하는 것

교과서적 정의는 톰 미첼(1997)의 것이 유명합니다.

> 어떤 **작업 T**에 대해 **성능 P**로 측정했을 때,
> **경험 E**로 인해 성능이 향상된다면 그 프로그램은 학습한다고 말한다.

스팸 필터에 대입하면 이렇습니다.

| 기호 | 의미 | 스팸 필터의 경우 |
|---|---|---|
| **T** (Task) | 하려는 일 | 메일이 스팸인지 판별 |
| **E** (Experience) | 학습 데이터 | 사용자가 "스팸 신고"한 메일들 |
| **P** (Performance) | 성능 지표 | 정확히 분류한 비율 |

**세 가지를 정하지 않으면 머신러닝을 시작할 수 없습니다.**
특히 **P**를 대충 정하면 프로젝트 전체가 흔들립니다. ([Day 080](day-080.md))

### 학습의 세 가지 종류

| 종류 | 정답(라벨)이 | 하는 일 | 예시 |
|---|---|---|---|
| **지도 학습** | **있음** | 입력 → 정답 매핑을 배움 | 스팸 분류, 집값 예측, 고양이 판별 |
| **비지도 학습** | 없음 | 데이터 구조를 스스로 찾음 | 고객 군집화, 이상 탐지, 차원 축소 |
| **강화 학습** | 없음 (보상만) | 시행착오로 전략을 배움 | 게임 AI, 로봇 제어, 자율주행 |

**이 과정에서 다루는 것은 거의 전부 지도 학습입니다.**
대단원 05의 Object Detection도 "이 박스 안은 사람"이라는 정답을 주고 배우는 지도 학습입니다.

> **라벨(label)** — 각 데이터에 붙은 정답.
> 고양이 사진 파일에 "cat"이라고 적어 두는 그 작업이 **라벨링**입니다.
> [Day 092](day-092.md)에서 직접 하고, 대단원 05에서는 박스 좌표까지 라벨링합니다.

### 지도 학습의 두 갈래 — 분류와 회귀

| | 분류 (Classification) | 회귀 (Regression) |
|---|---|---|
| 예측하는 것 | **범주** (정해진 종류 중 하나) | **숫자** (연속된 값) |
| 출력 예 | 고양이 / 개 / 새 | 32.5만 원 |
| 질문 형태 | "무엇인가?" | "얼마인가?" |
| 지표 | 정확도, F1 | MAE, RMSE |
| 이 과정의 예 | 늑대 vs 허스키 (대단원 03) | 스팀 가격 예측 (대단원 04) |

**구분 요령** — 출력값 사이에 **크기 순서가 의미 있으면 회귀**입니다.

```
고양이(0) / 개(1) / 새(2)   → 개가 고양이보다 1만큼 크다? 말이 안 됨 → 분류
평점 1 / 2 / 3 / 4 / 5      → 4가 2보다 크다. 의미 있음 → 회귀로 볼 수도 있음
```

> **애매한 경우가 실제로 있습니다.** 별점 예측은 분류로도, 회귀로도 풉니다.
> "3점을 1점으로 틀린 것"과 "3점을 4점으로 틀린 것"의 벌점을 다르게 주고 싶다면 **회귀**입니다.

### 필수 용어 8개

앞으로 매일 나옵니다. 오늘 확실히 잡고 가세요.

| 용어 | 영어 | 의미 | 표에서의 위치 |
|---|---|---|---|
| **샘플** | sample / instance | 데이터 한 건 | **행** 하나 |
| **특성** | feature | 예측에 쓰는 입력값 | **열** (정답 제외) |
| **라벨** | label / target | 맞혀야 할 정답 | **열** (정답) |
| **모델** | model | 학습으로 얻은 규칙 덩어리 | — |
| **학습** | training / fit | 데이터로 모델을 만드는 과정 | — |
| **예측** | prediction / inference | 학습된 모델로 답을 내는 것 | — |
| **가중치** | weight | 모델이 학습한 숫자들 | — |
| **에폭** | epoch | 전체 데이터를 1번 다 본 것 | — |

표로 보면 한눈에 들어옵니다.

```
        ┌──── 특성 (X) ────┐   ┌─ 라벨 (y) ─┐
        꽃받침길이  꽃잎길이  꽃잎너비    품종
샘플1 →    5.1       1.4      0.2      setosa
샘플2 →    4.9       1.4      0.2      setosa
샘플3 →    7.0       4.7      1.4      versicolor
샘플4 →    6.3       6.0      2.5      virginica
```

> **관례** — 특성은 대문자 `X`, 라벨은 소문자 `y` 로 씁니다.
> 대문자는 2차원(행렬), 소문자는 1차원(벡터)이라는 수학 관례에서 왔습니다.
> scikit-learn 문서 전체가 이 표기를 씁니다.


### Step 7. 오늘의 종합 — 규칙 기반 vs 머신러닝 직접 비교

**규칙을 손으로 써서 iris를 분류해 보고**, 그 다음 모델과 비교합니다.

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.neighbors import KNeighborsClassifier

iris = load_iris()
X, y = iris.data, iris.target
PETAL_LEN, PETAL_WID = 2, 3


# ── ① 사람이 쓴 규칙 ──
def rule_based(sample):
    """Step 4의 품종별 평균표를 보고 손으로 만든 규칙"""
    petal_len = sample[PETAL_LEN]
    petal_wid = sample[PETAL_WID]

    if petal_len < 2.5:
        return 0                      # setosa
    if petal_wid < 1.75:
        return 1                      # versicolor
    return 2                          # virginica


rule_pred = np.array([rule_based(s) for s in X])
rule_acc = (rule_pred == y).mean()


# ── ② 머신러닝 모델 ──
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X, y)
ml_pred = model.predict(X)
ml_acc = (ml_pred == y).mean()


# ── 비교 ──
print("=" * 62)
print("규칙 기반 vs 머신러닝 — iris 150건 전체")
print("=" * 62)
print(f"{'방식':<20}{'정확도':>10}{'맞힌 개수':>12}{'코드 줄 수':>12}")
print("-" * 62)
print(f"{'① 사람이 쓴 규칙':<19}{rule_acc:>10.2%}{(rule_pred == y).sum():>10}건{'8줄':>11}")
print(f"{'② KNN 모델':<20}{ml_acc:>10.2%}{(ml_pred == y).sum():>10}건{'3줄':>11}")
print("-" * 62)

# 규칙이 틀린 샘플들
wrong = np.where(rule_pred != y)[0]
print(f"\n규칙이 틀린 샘플 {len(wrong)}건:")
for i in wrong[:6]:
    print(f"  #{i:<4} petal=({X[i, PETAL_LEN]:.1f}, {X[i, PETAL_WID]:.1f})  "
          f"정답={iris.target_names[y[i]]:<11} 예측={iris.target_names[rule_pred[i]]}")

print("\n" + "=" * 62)
print("규칙을 더 고치면 정확도를 올릴 수 있습니다.")
print("문제는 특성이 4개가 아니라 4096개일 때입니다. (8×8 이미지가 64개,")
print("64×64 컬러 이미지는 12,288개) — 규칙을 손으로 쓸 수 없습니다.")
print("=" * 62)
```

**3.** `load_wine()` 데이터셋을 불러와 아래를 수행하는 코드를 작성하세요.
① 샘플 수·특성 수·클래스 수 출력 ② 클래스별 개수와 균형 여부 판단 ③ DataFrame으로 변환해 클래스별 평균 비교 ④ 클래스를 가장 잘 구분할 것 같은 특성 2개를 고르고 그 근거를 산점도로 제시

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.datasets import load_wine

wine = load_wine()
X, y = wine.data, wine.target

# ── ① 기본 구조 ──
print("=" * 66)
print("wine 데이터셋 — 와인 품종 분류")
print("=" * 66)
print(f"샘플 수   : {X.shape[0]}건")
print(f"특성 수   : {X.shape[1]}개")
print(f"클래스 수 : {len(wine.target_names)}개 → {list(wine.target_names)}")
print(f"결측치    : {np.isnan(X).sum()}개")

# ── ② 클래스 분포 ──
unique, counts = np.unique(y, return_counts=True)
print("\n[클래스 분포]")
for cls, cnt in zip(unique, counts):
    ratio = cnt / len(y)
    print(f"  {wine.target_names[cls]:<10} {cnt:>3}건 ({ratio:>5.1%})  {'█' * (cnt // 2)}")

imbalance = counts.max() / counts.min()
print(f"\n  최다/최소 비율 = {imbalance:.2f}배", end="  ")
print("→ 균형 잡힌 편" if imbalance < 1.5 else "→ 불균형 주의")

# ── ③ 클래스별 평균 ──
df = pd.DataFrame(X, columns=wine.feature_names)
df["target"] = pd.Categorical.from_codes(y, wine.target_names)

means = df.groupby("target", observed=True).mean()

# 클래스 간 차이가 큰 특성 찾기 — (최대-최소)/전체표준편차
spread = ((means.max() - means.min()) / df[wine.feature_names].std()).sort_values(ascending=False)

print("\n[클래스를 잘 가르는 특성 TOP 5]")
print(f"  {'특성':<24}{'분리력':>8}")
print("  " + "-" * 32)
for name, score in spread.head(5).items():
    print(f"  {name:<24}{score:>8.2f}")

print("\n[분리력이 낮은 특성 TOP 3]")
for name, score in spread.tail(3).items():
    print(f"  {name:<24}{score:>8.2f}")

# ── ④ 상위 2개 특성으로 산점도 ──
f1, f2 = spread.index[0], spread.index[1]
print(f"\n선택한 특성: {f1}, {f2}")

fig, axes = plt.subplots(1, 2, figsize=(13, 5))

# 좋은 특성 2개
for name in wine.target_names:
    sub = df[df["target"] == name]
    axes[0].scatter(sub[f1], sub[f2], label=name, s=55, alpha=0.75)
axes[0].set_xlabel(f1)
axes[0].set_ylabel(f2)
axes[0].set_title(f"GOOD: {f1} vs {f2}")
axes[0].legend()

# 나쁜 특성 2개 (대조군)
b1, b2 = spread.index[-1], spread.index[-2]
for name in wine.target_names:
    sub = df[df["target"] == name]
    axes[1].scatter(sub[b1], sub[b2], label=name, s=55, alpha=0.75)
axes[1].set_xlabel(b1)
axes[1].set_ylabel(b2)
axes[1].set_title(f"BAD: {b1} vs {b2}")
axes[1].legend()

fig.tight_layout()
plt.show()
print("=" * 66)
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 머신러닝 | 규칙을 사람이 쓰지 않고 **데이터에서 찾아냄** |
| 언제 쓰나 | **규칙을 문장으로 적을 수 없을 때**. 적을 수 있으면 if문이 정답 |
| 지도 학습 | 정답(라벨)이 있음. 이 과정의 대부분 |
| 분류 vs 회귀 | 범주를 맞히면 분류, **숫자**를 맞히면 회귀 |
| X와 y | `X` = 특성(**2차원**), `y` = 라벨(**1차원**) |
| 파이프라인 | 문제정의 → 수집 → **분리** → 전처리 → 학습 → 평가 → 배포 |
| 순서 주의 | **분리가 전처리보다 먼저** (데이터 누수 방지) |
| ID 열 | 학번·이름 같은 고유값은 **특성에서 제외** |
| Colab | GPU 무료 · `/content/` 는 **사라짐** → 드라이브에 저장 |

**오늘 반드시 기억할 세 가지**
> ① **규칙을 적을 수 있으면 머신러닝을 쓰지 마세요.** 도구를 고르는 것이 먼저입니다.
> ② **`X` 는 2차원, `y` 는 1차원**입니다. shape 에러의 대부분이 여기서 납니다.
> ③ **학습에 쓴 데이터로 평가하면 안 됩니다.** 오늘 Step 7이 저지른 잘못입니다. 내일 바로잡습니다.
