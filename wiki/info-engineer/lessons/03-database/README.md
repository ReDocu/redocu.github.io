## 이 문서들을 읽는 법

모든 본문은 같은 자리에서 같은 종류의 내용을 찾을 수 있도록 6블록 + 마무리로 고정되어 있습니다.

| 블록 | 내용 | 규칙 |
|---|---|---|
| ① 학습 목표 | 마치면 할 수 있게 되는 것 | 행동 동사로 3~5개 |
| ② 왜 필요한가 | 이 개념이 없으면 무엇이 안 되는지 + 시험에서의 중요도·출제 형태 | 실패 상황·비유로 동기 부여 |
| ③ 개념 설명 | 용어와 원리 + 반드시 암기할 내용(📌) + 혼동 비교(⚖️) | 표·그림 위주, 용어 첫 등장 시 풀어쓰기 |
| ④ 단계별 실습 | Step 1(🔁 복습 퀴즈) → N | SQL + 실제 실행 결과 표, 실행 원리·대표 오답 포함 |
| ⑤ 자주 하는 실수 | 에러 원문 + 원인 + 해결 | Ctrl+F로 검색되게 에러 메시지 원문 포함 |
| ⑥ 확인 문제 | 시험형 변형 문제 3문항 | 답·해설·대표 오답은 `<details>`로 접어 둠 |
| 마무리 | 요약 → 복습 체크리스트 → 과제·다음 강 예고 | 과제에는 형성평가 포함 (주 2번째 강 = 08·10강) |

**SQL 블록 규칙**

- `$` 로 시작하는 줄 = 입력(명령), 그 아래 줄 = 실제 출력입니다.
- 모든 SQL 문제는 **사용 테이블 → 정답 쿼리 → 예상 결과(표) → 실행 원리** 순서로 제시하고, 가능한 경우 대표 오답 쿼리와 오답 이유를 함께 보입니다.
- 기준 문법은 **표준 SQL**이며, DBMS(Oracle·MySQL·SQLite 등)별로 갈리는 문법은 본문에서 ⚖️로 구분 표기합니다. 실습 검증 도구는 SQLite입니다.
- 이 단원의 모든 예제·평가는 07강에서 정의하는 **공용 예제 스키마**(DEPT·STUDENT·COURSE·ENROLL)를 재사용합니다.
