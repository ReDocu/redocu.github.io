## ② 왜 필요한가

코드는 **쓰는 시간보다 읽는 시간이 훨씬 깁니다.**

```
작성:  1시간
읽기:  본인 10회 + 팀원 5회 + 3개월 뒤의 나 3회 = 18회
```

그런데 우리는 **쓸 때만 신경 쓰고 읽을 때를 생각하지 않습니다.**

```python
def f(l, n):
    r = []
    for i in l:
        if i[1] > n:
            r.append(i[0])
    return r
```

이 함수가 무엇을 하는지 알겠습니까? 3개월 뒤의 나도 모릅니다.

```python
def get_names_above_score(students, min_score):
    """최소 점수를 넘는 학생의 이름 목록을 반환합니다."""
    return [name for name, score in students if score > min_score]
```

**같은 동작인데 주석 없이도 읽힙니다.**

오늘 배우는 것은 **문법이 아니라 습관**입니다.
그리고 이 습관이 W08 프로젝트에서, 대단원 05 팀 프로젝트에서 결정적인 차이를 만듭니다.

## ③ 개념 설명

### 코드 냄새 (code smell)

**"동작은 하지만 뭔가 잘못됐다"는 신호**입니다.

| 냄새 | 증상 | 해결 |
|---|---|---|
| **긴 함수** | 20줄 초과 | 작은 함수로 분리 |
| **긴 매개변수 목록** | 4개 초과 | 객체나 딕셔너리로 묶기 |
| **중복 코드** | 같은 코드가 두 번 | 함수로 추출 |
| **매직 넘버** | `if x > 45:` | 상수로 |
| **깊은 중첩** | `if` 안의 `for` 안의 `if` | 가드 절, 함수 추출 |
| **의미 없는 이름** | `a`, `tmp`, `data2` | 뜻이 보이는 이름 |
| **거대한 클래스** | 300줄 초과 | 책임 분리 |
| **주석으로 설명하는 코드** | 주석 없이는 못 읽음 | 코드 자체를 명확히 |

### 개선 기법 ① 함수 추출

```python
# 냄새 — 한 함수가 너무 많은 일을 함
def process_game_over(player, stats, screen, font):
    # 점수 계산
    final_score = stats.score
    if stats.max_combo > 20:
        final_score = int(final_score * 1.5)
    if stats.accuracy > 80:
        final_score += 1000

    # 랭킹 저장
    entries = load_ranking()
    entries.append({"name": player.name, "score": final_score})
    entries.sort(key=lambda e: e["score"], reverse=True)
    save_ranking(entries[:10])

    # 화면 출력
    screen.fill((0, 0, 0))
    text = font.render(f"GAME OVER - {final_score}", True, (255, 255, 255))
    screen.blit(text, (300, 250))
```

```python
# 개선 — 역할별로 분리
def calculate_final_score(stats):
    """보너스를 반영한 최종 점수를 반환합니다."""
    score = stats.score
    if stats.max_combo > COMBO_BONUS_THRESHOLD:
        score = int(score * COMBO_BONUS_MULTIPLIER)
    if stats.accuracy > ACCURACY_BONUS_THRESHOLD:
        score += ACCURACY_BONUS
    return score


def save_to_ranking(name, score):
    """랭킹에 저장하고 순위를 반환합니다."""
    entries = load_ranking()
    entries.append({"name": name, "score": score})
    entries.sort(key=lambda e: e["score"], reverse=True)
    save_ranking(entries[:MAX_RANKING])
    return next((i for i, e in enumerate(entries[:MAX_RANKING], 1)
                 if e["name"] == name and e["score"] == score), None)


def draw_game_over(screen, font, score, rank):
    """게임 오버 화면을 그립니다."""
    ...


def process_game_over(player, stats, screen, font):
    """게임 오버 처리 — 각 단계를 순서대로 호출합니다."""
    final_score = calculate_final_score(stats)
    rank = save_to_ranking(player.name, final_score)
    draw_game_over(screen, font, final_score, rank)
```

> **함수 이름만 읽어도 흐름이 보입니다.** 이것이 좋은 분리입니다.
> 그리고 `calculate_final_score` 는 **화면 없이 테스트할 수 있습니다.**

### 이름 짓기 원칙

| 원칙 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 줄임말 금지 | `usr`, `cnt`, `tmp` | `user`, `count`, `temp_file` |
| 뜻이 보이게 | `data`, `info`, `list1` | `student_scores`, `enemy_list` |
| 불리언은 `is_`/`has_`/`can_` | `alive`, `ticket` | `is_alive`, `has_ticket` |
| 함수는 동사로 | `score()`, `data()` | `get_score()`, `load_data()` |
| 상수는 대문자 | `maxHp` | `MAX_HP` |
| 클래스는 PascalCase | `player_class` | `Player` |
| 단수/복수 구분 | `enemy = [...]` | `enemies = [...]` |

**함수 이름 접두어 관례**

| 접두어 | 하는 일 |
|---|---|
| `get_` | 값을 반환 (부작용 없음) |
| `set_` | 값을 설정 |
| `is_` / `has_` / `can_` | True/False 반환 |
| `load_` / `save_` | 파일·DB 읽고 쓰기 |
| `create_` / `make_` | 새 객체 생성 |
| `update_` | 상태 갱신 |
| `draw_` / `render_` | 화면 출력 |
| `handle_` / `process_` | 이벤트·데이터 처리 |
| `calculate_` / `compute_` | 계산 |
| `validate_` / `check_` | 검증 |

**개선 후 — `good_code.py`**

```python
"""학생 성적 관리 — 저장, 추가, 조회."""

import json
from pathlib import Path

# ══════════ 상수 ══════════
SUBJECTS = ("국어", "영어", "수학")
MIN_SCORE = 0
MAX_SCORE = 100

GRADE_CUTOFFS = (
    (90, "A"),
    (80, "B"),
    (70, "C"),
    (60, "D"),
)
DEFAULT_GRADE = "F"


# ══════════ 저장·불러오기 ══════════

def load_students(filepath):
    """학생 데이터를 불러옵니다. 파일이 없거나 손상되면 빈 딕셔너리."""
    path = Path(filepath)

    if not path.exists():
        return {}

    try:
        return json.loads(path.read_text(encoding="utf-8"))
    except json.JSONDecodeError:
        print(f"[경고] '{path.name}' 이(가) 손상되었습니다.")
        return {}
    except OSError as e:
        print(f"[경고] 파일을 읽을 수 없습니다: {e}")
        return {}


def save_students(students, filepath):
    """학생 데이터를 저장합니다. 성공하면 True."""
    try:
        Path(filepath).write_text(
            json.dumps(students, ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        return True
    except OSError as e:
        print(f"[경고] 저장 실패: {e}")
        return False


# ══════════ 검증 ══════════

def is_valid_score(score):
    """점수가 유효 범위인지 확인합니다."""
    return MIN_SCORE <= score <= MAX_SCORE


def is_valid_name(name):
    """이름이 유효한지 확인합니다."""
    return isinstance(name, str) and bool(name.strip())


# ══════════ 데이터 조작 ══════════

def add_student(students, name, scores):
    """
    학생을 추가합니다. 성공하면 True.

    scores: {"국어": 85, "영어": 90, "수학": 78} 형태
    """
    if students is None or not is_valid_name(name):
        return False

    if set(scores.keys()) != set(SUBJECTS):
        return False

    if not all(is_valid_score(s) for s in scores.values()):
        return False

    students[name.strip()] = dict(scores)
    return True


# ══════════ 계산 ══════════

def get_total(scores):
    """총점을 반환합니다."""
    return sum(scores.values())


def get_average(scores):
    """평균을 반환합니다. 과목이 없으면 0."""
    return get_total(scores) / len(scores) if scores else 0.0


def get_grade(average):
    """평균에 해당하는 학점을 반환합니다."""
    for cutoff, letter in GRADE_CUTOFFS:
        if average >= cutoff:
            return letter
    return DEFAULT_GRADE


def get_ranking(students):
    """총점 순으로 정렬된 성적 목록을 반환합니다."""
    results = []

    for name, scores in students.items():
        average = get_average(scores)
        results.append({
            "name": name,
            "total": get_total(scores),
            "average": average,
            "grade": get_grade(average),
        })

    results.sort(key=lambda r: r["total"], reverse=True)
    return results


# ══════════ 자체 테스트 ══════════

if __name__ == "__main__":
    students = {}

    assert add_student(students, "홍길동", {"국어": 85, "영어": 90, "수학": 78})
    assert add_student(students, "김철수", {"국어": 92, "영어": 88, "수학": 95})
    assert not add_student(students, "", {"국어": 80, "영어": 80, "수학": 80})
    assert not add_student(students, "박민수", {"국어": 150, "영어": 80, "수학": 80})
    assert not add_student(students, "이영희", {"국어": 80})     # 과목 부족

    print("=" * 52)
    print(f"{'순위':<5}{'이름':<12}{'총점':>8}{'평균':>9}{'학점':>6}")
    print("-" * 52)

    for rank, r in enumerate(get_ranking(students), start=1):
        print(f"{rank:<5}{r['name']:<12}{r['total']:>8}"
              f"{r['average']:>9.1f}{r['grade']:>6}")

    print("=" * 52)
    print("모든 테스트 통과!")
```

| 중첩 | 6단계 `if` | 가드 절 3줄 |
| 예외 처리 | `except:` (모두 삼킴) | `JSONDecodeError`, `OSError` 명시 |
| 매직 넘버 | `0`, `100`, `90`, `80`… | 상수로 분리 |

import pygame

from ..surfaces import make_enemy
from ..settings import (SCREEN_WIDTH,
                        ENEMY_SIZE, ENEMY_SPEED, ENEMY_HP, ENEMY_SCORE, COLOR_ENEMY,
                        TANK_SIZE, TANK_SPEED, TANK_HP, TANK_SCORE, COLOR_ENEMY_TANK,

class Enemy(Entity):
    """기본 적. 아래로 직진합니다."""

    HP = ENEMY_HP
    SPEED = ENEMY_SPEED
    SCORE = ENEMY_SCORE
    SIZE = ENEMY_SIZE
    COLOR = COLOR_ENEMY
    NAME = "기본"

    def __init__(self, x, y):
        super().__init__(x, y, make_enemy(self.SIZE, self.COLOR))
        self.hp = self.HP
        self.max_hp = self.HP
        self.radius = self.SIZE // 2

    def move(self):
        """이동 로직. 자식이 오버라이딩합니다."""
        self.pos_y += self.SPEED

    def update(self):
        self.move()
        self.sync_rect()
        self.kill_if_out()

    def take_damage(self, amount):
        """피해를 입습니다. 죽으면 True."""
        self.hp -= amount
        if self.hp > 0:
            return False

        self.kill()
        return True

    @classmethod
    def spawn(cls):
        """화면 위쪽 무작위 위치에서 생성합니다."""
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)


class TankEnemy(Enemy):
    """느리고 튼튼한 적."""

    SPEED = TANK_SPEED
    SCORE = TANK_SCORE

    COLOR = COLOR_ENEMY_TANK

class FastEnemy(Enemy):

| 항목 | 전 | 후 |

**발견한 냄새 6가지**

| # | 냄새 | 설명 |
|---|---|---|
| 1 | 의미 없는 이름 | `calc`, `a~e`, `x` — 무엇인지 알 수 없음 |
| 2 | 매개변수 5개 | 4개를 초과 |
| 3 | 깊은 중첩 | `if` 4단계 |
| 4 | 매직 넘버 | `100`, `0.9`, `1000`, `2000`, `3000` |

| 6 | `elif` 사슬 | 딕셔너리로 대체 가능 |

**개선 후**

```python
# ── 상수 ──
BULK_DISCOUNT_THRESHOLD = 100      # 이 금액을 넘으면 할인
BULK_DISCOUNT_RATE = 0.9           # 10% 할인

TIER_BONUS = {
    1: 1000,      # 실버
    2: 2000,      # 골드
    3: 3000,      # 플래티넘
}


def calculate_order_amount(unit_price, quantity, is_member, tier, shipping_fee):
    """
    주문 금액을 계산합니다.

    unit_price:   단가 (None 이면 계산 불가)
    quantity:     수량 (0 이하면 계산 불가)
    is_member:    회원 여부 (비회원은 할인·보너스 없음)
    tier:         회원 등급 (1~3, 그 외는 보너스 없음)
    shipping_fee: 배송비

    계산 불가한 경우 0 을 반환합니다.
    """
    # 가드 절 — 잘못된 경우를 먼저 걸러 냄
    if unit_price is None or quantity <= 0 or not is_member:
        return 0

    amount = unit_price * quantity

    # 대량 구매 할인
    if amount > BULK_DISCOUNT_THRESHOLD:
        amount *= BULK_DISCOUNT_RATE

    # 등급 보너스 — 딕셔너리로 elif 사슬 제거
    amount += TIER_BONUS.get(tier, 0)

    return amount + shipping_fee
```

**개선 사항 6가지**
- 이름을 뜻이 보이게 바꿨습니다.
- **가드 절**로 중첩 4단계 → 0단계.
- 매직 넘버를 상수로 분리했습니다.
- `if c == True:` → `if not is_member: return 0` (파이썬은 불리언을 직접 씁니다)
- `if a != None:` → `if unit_price is None:` (`None` 비교는 `is` 를 씁니다)
- `elif` 3개 → `TIER_BONUS.get(tier, 0)` 한 줄. **등급이 10개로 늘어도 딕셔너리만 수정**합니다.

**더 개선한다면** — 매개변수 5개를 객체로 묶습니다.

```python
from dataclasses import dataclass


@dataclass
class Order:
    unit_price: float
    quantity: int
    is_member: bool
    tier: int
    shipping_fee: float


def calculate_order_amount(order):
    if order.unit_price is None or order.quantity <= 0 or not order.is_member:
        return 0
    ...
```

> `@dataclass` 는 `__init__`, `__repr__`, `__eq__` 를 자동으로 만들어 주는 표준 라이브러리 기능입니다.

**개선 후**

```python
"""CSV 파일에서 성적을 읽어 분석합니다."""

from pathlib import Path


def load_scores(filepath):
    """
    'name,score' 형식의 파일을 읽어 [(이름, 점수), ...] 를 반환합니다.
    잘못된 줄은 건너뛰고 경고를 출력합니다.
    """
    path = Path(filepath)

    if not path.exists():
        print(f"[경고] 파일이 없습니다: {path}")
        return []

    records = []

    try:
        lines = path.read_text(encoding="utf-8").splitlines()
    except OSError as e:
        print(f"[경고] 파일을 읽을 수 없습니다: {e}")
        return []

    for line_no, line in enumerate(lines, start=1):
        line = line.strip()
        if not line:
            continue

        parts = line.split(",")
        if len(parts) < 2:
            print(f"[경고] {line_no}행 형식 오류: '{line}'")
            continue

        try:
            records.append((parts[0].strip(), int(parts[1])))
        except ValueError:
            print(f"[경고] {line_no}행 점수가 숫자가 아닙니다: '{parts[1]}'")

    return records


def get_average(records):
    """평균 점수를 반환합니다. 데이터가 없으면 0."""
    if not records:
        return 0.0
    return sum(score for _, score in records) / len(records)


def get_above_average(records):
    """평균 이상인 (이름, 점수) 목록을 반환합니다."""
    average = get_average(records)
    return [(name, score) for name, score in records if score > average]


def show_report(records):
    """분석 결과를 출력합니다."""
    if not records:
        print("분석할 데이터가 없습니다.")
        return

    average = get_average(records)

    print(f"\n전체 {len(records)}명 · 평균 {average:.1f}점")
    print("-" * 32)

    above = get_above_average(records)
    for name, score in sorted(above, key=lambda r: r[1], reverse=True):
        print(f"  {name:<12} {score:>3}점  (+{score - average:.1f})")

    print("-" * 32)
    print(f"평균 이상 {len(above)}명 / 전체 {len(records)}명")


if __name__ == "__main__":
    # 테스트 파일 만들기
    Path("scores.csv").write_text(
        "홍길동,85\n김철수,92\n\n이영희,78\n박민수,abc\n최지우\n정수현,90\n",
        encoding="utf-8",
    )

    data = load_scores("scores.csv")
    show_report(data)

    Path("scores.csv").unlink()
```

**실행 결과**

```
[경고] 5행 점수가 숫자가 아닙니다: 'abc'
[경고] 6행 형식 오류: '최지우'

전체 4명 · 평균 86.2점
--------------------------------
  김철수          92점  (+5.8)
  정수현          90점  (+3.8)
--------------------------------
평균 이상 2명 / 전체 4명
```

**핵심 개선 4가지**
- **함수를 4개로 분리** — 읽기(`load_scores`) / 계산(`get_average`, `get_above_average`) / 출력(`show_report`)
- 잘못된 줄이 있어도 **나머지는 계속 처리**하고 몇 행이 문제인지 알려 줍니다.
- 각 함수를 독립적으로 테스트할 수 있습니다. `get_average([("a", 80), ("b", 90)])` 처럼.
- 빈 데이터를 모든 함수가 안전하게 처리합니다.
</details>

**3.** 팀원의 아래 코드에 리뷰 의견을 3개 작성하세요. **좋은 점 1개 + 개선 제안 2개**로, 존중하는 표현을 쓰세요.

```python
class ScoreManager:
    def __init__(self):
        self.scores = []
        self.high_score = 0

    def add(self, score):
        self.scores.append(score)
        if score > self.high_score:
            self.high_score = score

    def get_stats(self):
        return {
            "count": len(self.scores),
            "total": sum(self.scores),
            "average": sum(self.scores) / len(self.scores),
            "max": max(self.scores),
            "min": min(self.scores),
        }
```

<details>
<summary>답 보기</summary>

**리뷰 의견 예시**

> **① 좋은 점**
> `get_stats()` 가 딕셔너리를 반환해서 쓰는 쪽에서 `stats["average"]` 처럼 키로 접근할 수 있는 게 좋았습니다.
> 나중에 항목을 추가해도 기존 코드가 안 깨지겠네요. 저도 이 방식을 참고하겠습니다.
>
> **② 개선 제안 — 빈 리스트 처리**
> `self.scores` 가 비어 있을 때 `get_stats()` 를 부르면 `ZeroDivisionError` 와 `ValueError` 가 날 것 같습니다.
> (`sum([]) / len([])` 와 `max([])`)
>
> 게임 시작 직후 통계 화면을 열면 재현될 수 있어 보입니다. 아래처럼 가드 절을 넣으면 어떨까요?
>
> ```python
> def get_stats(self):
>     if not self.scores:
>         return {"count": 0, "total": 0, "average": 0.0, "max": 0, "min": 0}
>     ...
> ```
>
> **③ 개선 제안 — high_score 를 계산 값으로**
> `high_score` 를 별도 변수로 관리하시는데, `max(self.scores)` 와 같은 값이라 **두 곳에 같은 정보가 저장**되는 상태입니다.
>
> 지금은 `add()` 에서 잘 갱신하고 계셔서 문제없지만, 나중에 점수를 삭제하는 기능이 생기면 어긋날 수 있습니다.
> (`remove()` 를 만들 때 `high_score` 갱신을 잊기 쉬움)
>
> `@property` 로 매번 계산하면 어떨까요?
>
> ```python
> @property
> def high_score(self):
>     return max(self.scores) if self.scores else 0
> ```
>
> 다만 점수가 수만 개가 되면 `max()` 가 매번 도는 게 부담일 수 있어서, 현재 규모에서 어느 쪽이 나을지 의견 듣고 싶습니다.

| 요령 | 예 |
