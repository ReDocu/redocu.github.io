## ③ 개념 설명

### ① 예측 vs 실제 산점도

```
 예측
  │              ╱
  │           ╱ ·:·
  │        ╱ ·:::·
  │     ╱ ·:::·
  │  ╱ ·::·
  │╱·:·
  └────────────────── 실제
     y = x 기준선
```

**점들이 y=x 선 주변에 좁게 모여 있으면 좋은 모델입니다.**

**읽어야 할 패턴 6가지**

| 패턴 | 모습 | 의미 |
|---|---|---|
| **좁은 띠** | y=x 주변에 밀집 | 좋음 |
| **넓게 퍼짐** | 구름 모양 | 성능 나쁨 |
| **기울기 < 1** | 낮은 값은 과대, 높은 값은 과소 예측 | **평균 회귀.** 정보 부족 |
| **오른쪽 위 수직 벽** | 실제는 큰데 예측이 못 따라감 | **타깃 상한 절단** |
| **왼쪽 아래 수평선** | 실제는 작은데 예측이 일정 | **하한 절단** 또는 음수 방지 |
| **부채꼴** | 값이 클수록 퍼짐 | **이분산성** → 로그 변환 |

**기울기 < 1 (평균 회귀)이 가장 흔합니다.**

```
모델이 확신이 없으면 안전하게 평균 쪽으로 예측합니다.
실제 1만 원 → 예측 1.5만 원 (과대)
실제 8만 원 → 예측 6만 원 (과소)
→ 회귀선의 기울기가 1보다 작아짐
```

**진단 방법**

```python
from scipy import stats
slope, intercept, r, p, se = stats.linregress(y_true, y_pred)
print(f"기울기 {slope:.3f}  (1.0에 가까워야 정상)")
```

| 기울기 | 판정 |
|---|---|
| 0.95 ~ 1.05 | 정상 |
| 0.8 ~ 0.95 | 약한 평균 회귀 |
| **< 0.8** | **강한 평균 회귀** — 특성 정보 부족 |
| > 1.05 | 과대 반응 (드묾) |

### ② 잔차 플롯

```
잔차 = 실제 - 예측
```

**x축을 무엇으로 두느냐에 따라 두 종류가 있습니다.**

| x축 | 이름 | 무엇을 보나 |
|---|---|---|
| **예측값** | 잔차 플롯 (기본) | 예측 구간별 편향·분산 |
| 실제값 | — | **쓰지 마세요** (아래 설명) |
| 특성 하나 | 부분 잔차 플롯 | 그 특성의 비선형성 |
| 시간·순서 | — | 시계열 패턴 |

> ⚠️ **x축을 "실제값"으로 두면 안 됩니다.**
> 잔차 = 실제 - 예측 이므로 **실제값과 잔차가 구조적으로 상관**됩니다.
> 완벽한 모델에서도 우하향 패턴이 나타나 오해를 부릅니다.
> **반드시 예측값을 x축에 두세요.**

**정상 잔차 플롯**

```
 잔차
  │  ·  ·   ·  ·  ·   ·
 0├─·──·─·───·──·──·──·──  ← 0 주변에 무작위
  │ ·   ·  ·   ·  ·  ·
  └──────────────────── 예측값
```

| 조건 | 의미 |
|---|---|
| 0 주변에 대칭 | 편향 없음 |
| 폭이 일정 | 등분산 |
| 패턴 없음 | 모델이 구조를 다 잡음 |

**문제 패턴 4가지**

**(a) 곡선 패턴 — 비선형성**

```
 잔차
  │ ·:·           ·:·
 0├───·:·──────·:·────
  │      ·:·:·:·
  └──────────────────── 예측값
```

**모델이 못 잡은 비선형 관계가 남아 있습니다.**
→ 특성 변환(제곱, 로그), 상호작용 항, 더 강한 모델

**(b) 부채꼴 — 이분산성 (heteroscedasticity)**

```
 잔차
  │           ·  ·   ·
  │      ·  ·  ·  ·  ·
 0├──·─·──·──·───·──·──
  │   · ·   ·  ·  ·  ·
  │           ·  ·   ·
  └──────────────────── 예측값
```

**값이 클수록 오차가 커집니다.** 가격 데이터의 전형입니다.
→ **타깃 로그 변환** ([Day 111](day-111.md)), 가중 회귀

**(c) 대각선 벽 — 절단**

```
 잔차
  │      ╱
  │    ╱ ·:·
 0├──╱·:::·──────
  │·:::·
  └──────────────────── 예측값
```

**타깃에 상한/하한이 있는데 모델이 넘지 못합니다.**
→ 데이터 한계. 보고서에 명시

**(d) 한쪽으로 치우침 — 편향**

```
 잔차
  │·:::·:::·:::·:::·
 0├──────────────────
  │
  └──────────────────── 예측값
```

**잔차 평균이 0이 아닙니다.**
→ 로그 변환 되돌리기 편향 ([Day 111](day-111.md)), 타깃 분포 이동

### ③ 잔차 분포

**히스토그램**

| 모습 | 의미 |
|---|---|
| 종 모양, 0 중심 | 정상 |
| **한쪽으로 치우침** | 체계적 편향 |
| **두 개의 봉우리** | 두 집단이 섞여 있음 |
| 꼬리가 두꺼움 | 큰 오차가 자주 발생 |

**Q-Q 플롯** — 잔차가 정규분포인가

```
정규분포면 → 직선
꼬리가 두꺼우면 → S자
```

> **잔차가 정규분포일 필요는 없습니다.** (예측이 목적이면)
> 다만 **정규분포에서 크게 벗어나면 무언가 놓친 구조가 있다는 신호**입니다.

### 오차 top-N 분석

```python
worst = df.assign(err=np.abs(y_val - pred)).nlargest(20, "err")
```

**확인할 것**

| 질문 | 무엇을 알 수 있나 |
|---|---|
| 특정 구간에 몰려 있는가 | 구간별 실패 |
| 특정 범주에 몰려 있는가 | 그 범주의 데이터 부족 |
| **실제 값이 이상한가** | 데이터 오류 ([Day 112](day-112.md)) |
| 특성 값이 극단적인가 | 외삽 문제 |
| **전부 같은 방향인가** | 체계적 편향 |

> **[Day 104](../03-ml/day-104.md)의 "오분류 이미지 전수 확인"과 같은 작업입니다.**
> 분류에서는 이미지를 봤고, 회귀에서는 **원본 행을 봅니다.**

### 구간별 성능표

```python
bins = pd.qcut(y_true, q=5)
df.groupby(bins).agg(건수=..., MAE=..., 편향=...)
```

**반드시 함께 볼 것**

| 열 | 계산 | 의미 |
|---|---|---|
| 건수 | `size` | 표본이 충분한가 |
| **MAE** | `mean(|err|)` | 절대 오차 |
| **오차율** | `MAE / 실제평균` | **사용자 체감** |
| **편향** | `mean(pred - actual)` | 과대/과소 예측 |
| 표준편차 | `std(err)` | 안정성 |

> **"오차율"이 사용자 경험과 가장 가깝습니다.**
> 1만 원짜리의 2,800원 오차(28%)와 8만 원짜리의 4,100원 오차(5%)는 완전히 다릅니다.

### 세 그래프 + 두 표 = 진단 세트

```
그래프 ① 예측 vs 실제      전체 그림
그래프 ② 잔차 플롯          체계적 패턴
그래프 ③ 잔차 분포          오차의 성질
   표 ④ 구간별 성능         어디가 나쁜가
   표 ⑤ 오차 top-N         왜 나쁜가
```

**이 다섯 개가 [Day 132](day-132.md) 프로젝트 결과 시각화의 핵심입니다.**

## ④ 단계별 실습

### Step 0. 준비 — 모델 3개 학습

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.datasets import fetch_california_housing
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

SEED = 42
np.random.seed(SEED)
tf.random.set_seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

y_bins = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)

sc = StandardScaler().fit(X_train)
Xtr, Xva = sc.transform(X_train), sc.transform(X_val)

# ── 모델 3개 ──
preds = {}

ridge = RidgeCV(alphas=np.logspace(-3, 3, 30)).fit(Xtr, y_train)
preds["릿지"] = ridge.predict(Xva)

hgb = HistGradientBoostingRegressor(max_iter=300, random_state=SEED).fit(X_train, y_train)
preds["HistGB"] = hgb.predict(X_val)

tf.random.set_seed(SEED)
nn = keras.Sequential([
    layers.Input(shape=(Xtr.shape[1],)),
    layers.Dense(128, activation="relu"),
    layers.Dense(64, activation="relu"),
    layers.Dense(1),
])
nn.compile(optimizer=keras.optimizers.Adam(1e-3), loss="mse", metrics=["mae"])
nn.fit(Xtr, y_train, validation_data=(Xva, y_val), epochs=200, batch_size=64,
       callbacks=[keras.callbacks.EarlyStopping(monitor="val_loss", patience=20,
                                                restore_best_weights=True)],
       verbose=0)
preds["신경망"] = nn.predict(Xva, verbose=0).ravel()

print("=" * 72)
print("모델 3종 — 숫자만 보면")
print("=" * 72)
print(f"{'모델':<12}{'MAE':>10}{'RMSE':>10}{'R²':>10}")
print("-" * 72)
for name, p in preds.items():
    print(f"{name:<12}{mean_absolute_error(y_val, p):>10.4f}"
          f"{np.sqrt(mean_squared_error(y_val, p)):>10.4f}"
          f"{r2_score(y_val, p):>10.4f}")
print("=" * 72)
print("★ HistGB가 최고입니다. 그런데 '어디서' 틀리는지는 알 수 없습니다.")
```

### Step 1. ★ 예측 vs 실제 산점도

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

fig, axes = plt.subplots(1, 3, figsize=(18, 5.5))

for ax, (name, p) in zip(axes, preds.items()):
    ax.scatter(y_val, p, s=5, alpha=0.15, color="#1f77b4")

    lo = min(y_val.min(), p.min())
    hi = max(y_val.max(), p.max())
    ax.plot([lo, hi], [lo, hi], "r--", linewidth=2, label="perfect (y=x)")

    # ── 회귀선 ──
    slope, intercept, r, _, _ = stats.linregress(y_val, p)
    xs = np.array([lo, hi])
    ax.plot(xs, slope * xs + intercept, "g-", linewidth=2,
            label=f"fit: slope={slope:.3f}")

    ax.set_xlabel("actual"); ax.set_ylabel("predicted")
    ax.set_title(f"{name}\nMAE {mean_absolute_error(y_val, p):.4f}  "
                 f"R² {r2_score(y_val, p):.4f}")
    ax.legend(fontsize=8.5)
    ax.set_xlim(lo, hi); ax.set_ylim(lo, hi)
    ax.set_aspect("equal", adjustable="box")

fig.tight_layout()
plt.show()

# ── 수치로 ──
print("=" * 88)
print("산점도 진단 — 기울기가 1에서 얼마나 벗어나는가")
print("=" * 88)
print(f"{'모델':<12}{'기울기':>10}{'절편':>10}{'상관 r':>10}"
      f"{'상한(5.0) 예측평균':>20}{'판정':>16}")
print("-" * 88)
capped = y_val >= 4.999
for name, p in preds.items():
    slope, intercept, r, _, _ = stats.linregress(y_val, p)
    verdict = ("정상" if slope > 0.95 else
               "약한 평균회귀" if slope > 0.8 else "★ 강한 평균회귀")
    print(f"{name:<12}{slope:>10.4f}{intercept:>10.4f}{r:>10.4f}"
          f"{p[capped.values].mean():>20.4f}{verdict:>16}")
print("-" * 88)
print(f"참고: 실제 5.0인 샘플 {capped.sum()}건 "
      f"({capped.mean()*100:.1f}%)의 예측 평균이 5.0보다 한참 낮습니다")
```

### Step 5. ★ 구간별 성능표

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt


def bin_performance(y_true, pred, q=6, labels=None):
    """타깃 구간별 성능표"""
    y_true = np.asarray(y_true, dtype=float)
    pred = np.asarray(pred, dtype=float)
    err = y_true - pred

    bins = pd.qcut(pd.Series(y_true), q=q, duplicates="drop")
    t = pd.DataFrame({"actual": y_true, "pred": pred,
                      "err": err, "abs_err": np.abs(err), "bin": bins})

    g = t.groupby("bin", observed=True).agg(
        건수=("actual", "size"),
        실제평균=("actual", "mean"),
        예측평균=("pred", "mean"),
        MAE=("abs_err", "mean"),
        RMSE=("err", lambda s: float(np.sqrt((s ** 2).mean()))),
        편향=("err", "mean"),
        오차표준편차=("abs_err", "std"),
    ).round(4)
    g["오차율(%)"] = (g["MAE"] / g["실제평균"] * 100).round(2)
    g["편향방향"] = np.where(g["편향"] > 0.02, "과소예측",
                         np.where(g["편향"] < -0.02, "과대예측", "-"))
    return g


print("=" * 118)
print("구간별 성능 — 전체 MAE가 감추는 것")
print("=" * 118)
for name, p in preds.items():
    g = bin_performance(y_val, p, q=6)
    print(f"\n[{name}]  전체 MAE {mean_absolute_error(y_val, p):.4f}")
    print(g.to_string())
```

### Step 7. 오늘의 종합 — 진단 세트 함수

```python
from pathlib import Path

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

DIAG_MODULE = '''
"""예측 결과 진단 3종 그래프 + 2종 표 (Day 118)"""
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score


def prediction_report(y_true, y_pred, title=None, save_path=None,
                      X=None, top_n=15, q=6, figsize=(19, 10)):
    """예측 진단 3종 그래프 + 구간별 표 + 오차 top-N

    Returns
    -------
    dict : {"metrics", "bins", "worst_abs", "worst_pct", "diagnosis"}
    """
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    resid = y_true - y_pred

    fig, axes = plt.subplots(2, 3, figsize=figsize)

    # ── ① 예측 vs 실제 ──
    ax = axes[0, 0]
    ax.scatter(y_true, y_pred, s=5, alpha=0.15)
    lo, hi = min(y_true.min(), y_pred.min()), max(y_true.max(), y_pred.max())
    ax.plot([lo, hi], [lo, hi], "r--", linewidth=2, label="y=x")
    slope, intercept, r, _, _ = stats.linregress(y_true, y_pred)
    ax.plot([lo, hi], [slope * lo + intercept, slope * hi + intercept],
            "g-", linewidth=2, label=f"fit slope={slope:.3f}")
    ax.set_xlabel("actual"); ax.set_ylabel("predicted")
    ax.set_title("① Predicted vs Actual"); ax.legend(fontsize=8)
    ax.set_aspect("equal", adjustable="box")

    # ── ② 잔차 플롯 ──
    ax = axes[0, 1]
    ax.scatter(y_pred, resid, s=5, alpha=0.15)
    ax.axhline(0, color="red", ls="--", linewidth=2)
    b = pd.qcut(pd.Series(y_pred), q=20, duplicates="drop")
    m = pd.Series(resid).groupby(b.values, observed=True).mean()
    s = pd.Series(resid).groupby(b.values, observed=True).std()
    cs = [iv.mid for iv in m.index]
    ax.plot(cs, m.values, "g-", linewidth=2.5, label="binned mean")
    ax.fill_between(cs, m.values - s.values, m.values + s.values,
                    alpha=0.15, color="green")
    ax.set_xlabel("predicted"); ax.set_ylabel("residual")
    ax.set_title(f"② Residual plot (mean {resid.mean():+.4f})")
    ax.legend(fontsize=8)

    # ── ③ 잔차 분포 ──
    ax = axes[0, 2]
    ax.hist(resid, bins=60, edgecolor="black", alpha=0.75, density=True)
    ax.axvline(0, color="red", ls="--", linewidth=2)
    ax.axvline(resid.mean(), color="green", linewidth=2,
               label=f"mean {resid.mean():+.4f}")
    ax.axvline(np.median(resid), color="orange", linewidth=2,
               label=f"median {np.median(resid):+.4f}")
    xs = np.linspace(resid.min(), resid.max(), 300)
    ax.plot(xs, stats.norm.pdf(xs, resid.mean(), resid.std()), "k-", linewidth=1.6)
    ax.set_xlabel("residual"); ax.set_title(
        f"③ Residual distribution (skew {stats.skew(resid):.2f})")
    ax.legend(fontsize=8)

    # ── ④ 구간별 MAE / 오차율 ──
    bins = pd.qcut(pd.Series(y_true), q=q, duplicates="drop")
    t = pd.DataFrame({"actual": y_true, "pred": y_pred,
                      "err": resid, "abs_err": np.abs(resid), "bin": bins})
    g = t.groupby("bin", observed=True).agg(
        건수=("actual", "size"), 실제평균=("actual", "mean"),
        예측평균=("pred", "mean"), MAE=("abs_err", "mean"),

    ax = axes[1, 0]
    idx = np.arange(len(g))
    ax.bar(idx - 0.2, g["MAE"], 0.4, label="MAE")
    ax2 = ax.twinx()
    ax2.bar(idx + 0.2, g["오차율(%)"], 0.4, color="coral", label="error rate (%)")
    ax.set_xticks(idx)
    ax.set_xticklabels([f"{iv.mid:.2f}" for iv in g.index], rotation=30, fontsize=8)
    ax.set_xlabel("target bin"); ax.set_ylabel("MAE")
    ax2.set_ylabel("error rate (%)", color="coral")
    ax.set_title("④ MAE vs error rate by bin")

    # ── ⑤ 구간별 편향 ──
    ax = axes[1, 1]
    ax.plot([iv.mid for iv in g.index], g["편향"], "o-", linewidth=2.5, markersize=9)
    ax.axhline(0, color="black", ls="--")
    ax.set_xlabel("target bin center"); ax.set_ylabel("bias (actual - pred)")
    ax.set_title("⑤ Bias by bin (regression to the mean?)")

    # ── ⑥ Q-Q ──
    ax = axes[1, 2]
    stats.probplot(resid, dist="norm", plot=ax)
    ax.get_lines()[0].set_markersize(2)
    ax.get_lines()[0].set_alpha(0.3)
    ax.set_title("⑥ Q-Q plot")

    if save_path:

    base = X.copy() if X is not None else pd.DataFrame(index=range(len(y_true)))
    base = base.reset_index(drop=True)
    base["실제"] = y_true; base["예측"] = y_pred
    base["잔차"] = resid; base["절대오차"] = np.abs(resid)
    base["오차율(%)"] = np.abs(resid) / np.maximum(np.abs(y_true), 1e-9) * 100

        "잔차평균": round(float(resid.mean()), 4),
        "잔차중앙값": round(float(np.median(resid)), 4),
        "왜도": round(float(stats.skew(resid)), 3),
        "첨도": round(float(stats.kurtosis(resid)), 3),
        "이분산기울기": round(float(np.polyfit(y_pred, np.abs(resid), 1)[0]), 4),
        "최악구간MAE": round(float(g["MAE"].max()), 4),
        "최악구간오차율": round(float(g["오차율(%)"].max()), 2),
    }

    # ── 자동 진단 ──
    d = []
    if metrics["기울기"] < 0.8:
        d.append(("★ 강한 평균 회귀", "특성 정보 부족. 특성 공학 필요"))
    elif metrics["기울기"] < 0.95:
        d.append(("약한 평균 회귀", "정상 범위. 개선 여지 있음"))
    if abs(metrics["잔차평균"]) > 0.02 * np.abs(y_true).mean():
        d.append(("★ 체계적 편향", "타깃 변환 되돌리기 편향 확인 (Day 111)"))
    if metrics["이분산기울기"] > 0.05:
        d.append(("★ 이분산성", "타깃 로그 변환 검토 (Day 111)"))
    if metrics["왜도"] > 0.5:
        d.append(("잔차 오른쪽 꼬리", "큰 과소 예측 존재. 상한 절단 확인"))
    if metrics["첨도"] > 3:
        d.append(("두꺼운 꼬리", "극단적 실패가 잦음. 오차 top-N 확인"))
    if metrics["최악구간MAE"] > metrics["MAE"] * 1.8:
        d.append(("★ 구간별 편차 큼", f"최악 구간이 전체의 "
                  f"{metrics['최악구간MAE']/metrics['MAE']:.1f}배"))
    if not d:
        d.append(("정상", "체계적 문제 없음"))

    return {"metrics": metrics, "bins": g,
            "worst_abs": base.nlargest(top_n, "절대오차"),
            "worst_pct": base.nlargest(top_n, "오차율(%)"),
            "diagnosis": d, "figure": fig}


def print_report(rep, name="model"):
    print("=" * 84)
    print(f"예측 진단: {name}")
```

```python
ax.plot([lo, hi], [slope*lo+intercept, slope*hi+intercept],
        "g-", linewidth=2, label=f"fit slope={slope:.3f}")
ax.set_xlim(lo, hi); ax.set_ylim(lo, hi)               # ★ 축 범위
ax.set_aspect("equal", adjustable="box")               # ★ 종횡비
ax.set_xlabel("actual"); ax.set_ylabel("predicted")
ax.set_title("① Predicted vs Actual"); ax.legend(fontsize=8)

# ② 잔차 플롯 — ★ x축은 예측값
ax = axes[1]
ax.scatter(pred, resid, s=5, alpha=0.15)               # ★ 수정 4
ax.axhline(0, color="red", ls="--", linewidth=2)
b = pd.qcut(pd.Series(pred), q=20, duplicates="drop")
m = pd.Series(resid).groupby(b.values, observed=True).mean()
ax.plot([iv.mid for iv in m.index], m.values, "g-", linewidth=2.5,
        label="binned mean")
ax.set_xlabel("predicted"); ax.set_ylabel("residual")
ax.set_title("② Residual plot"); ax.legend(fontsize=8)

# ③ 잔차 분포 — ★ 수정 7
ax = axes[2]
ax.hist(resid, bins=60, edgecolor="black", alpha=0.75)
ax.axvline(0, color="red", ls="--", linewidth=2)
ax.axvline(resid.mean(), color="green", linewidth=2, label="mean")
ax.axvline(np.median(resid), color="orange", linewidth=2, label="median")
ax.set_xlabel("residual"); ax.set_title("③ Residual distribution")
ax.legend(fontsize=8)

fig.tight_layout()
fig.savefig("figures/prediction_diag.png", dpi=110, bbox_inches="tight")
plt.show()

# ═══ 수정 5: 오차 top-N 원본 확인 ═══
analysis = X_val.reset_index(drop=True).copy()
analysis["실제"] = y_true
analysis["예측"] = pred
analysis["잔차"] = resid
analysis["절대오차"] = np.abs(resid)
analysis["오차율(%)"] = np.abs(resid) / np.maximum(np.abs(y_true), 1e-9) * 100

print("\n[절대오차 상위 10건]")
print(analysis.nlargest(10, "절대오차").round(3).to_string())

print("\n[오차율 상위 10건 — 다른 샘플들]")
print(analysis.nlargest(10, "오차율(%)").round(3).to_string())

overlap = len(set(analysis.nlargest(10, "절대오차").index) &
              set(analysis.nlargest(10, "오차율(%)").index))
print(f"\n겹침: {overlap}/10건")

# ═══ 수정 6: 구간별 성능 ═══
bins = pd.qcut(pd.Series(y_true), q=6, duplicates="drop")
t = pd.DataFrame({"actual": y_true, "pred": pred,
                  "err": resid, "abs_err": np.abs(resid), "bin": bins})
g = t.groupby("bin", observed=True).agg(
    건수=("actual", "size"), 실제평균=("actual", "mean"),
    MAE=("abs_err", "mean"), 편향=("err", "mean")).round(4)
g["오차율(%)"] = (g["MAE"] / g["실제평균"] * 100).round(2)

print("\n[구간별 성능]")
print(g.to_string())
print(f"\n★ 최악 구간 MAE {g['MAE'].max():.4f} "
      f"(전체 {mean_absolute_error(y_true, pred):.4f}의 "
      f"{g['MAE'].max()/mean_absolute_error(y_true, pred):.1f}배)")
print(f"★ 최악 구간 오차율 {g['오차율(%)'].max():.1f}%")
```

|---|---|
| 잔차 플롯의 x축 | **예측값.** 실제값을 쓰면 구조적 상관 |
| 기울기 진단 | `stats.linregress(y_true, y_pred).slope`. **1.0이 정상** |

| 이분산성 | `polyfit(pred, |resid|, 1)` 기울기 > 0.05 → **로그 변환** |
| 편향 판정 | **평균과 중앙값을 함께.** 평균만 보면 놓침 |
| 오차 top-N | **절대오차 기준과 오차율 기준이 다른 샘플** |
| 구간별 오차율 | `MAE / 실제평균`. **사용자 체감에 가장 가까움** |
| 전체 MAE의 함정 | 최악 구간이 2배 이상 나쁠 수 있음 |
| 원본 확인 | `X_val` 을 붙여서 **행 전체를 출력** |
| 산점도 그리기 | `s=5, alpha=0.15` + 축 범위·종횡비 맞추기 |
| 조치 후 재진단 | **조치는 새 문제를 만들 수 있음** |
