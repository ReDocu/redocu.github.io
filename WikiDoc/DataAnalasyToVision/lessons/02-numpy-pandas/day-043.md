## ③ 개념 설명

### 요소별 연산

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

a + b        # [11 22 33]
a - b        # [-9 -18 -27]
a * b        # [10 40 90]      ← 행렬 곱이 아님!
b / a        # [10. 10. 10.]
b // a       # [10  10  10]
b % a        # [0 0 0]
a ** 2       # [1 4 9]
-a           # [-1 -2 -3]
```

> ⚠️ **`*` 는 요소별 곱입니다.** 행렬 곱은 `@` 또는 `np.dot()` 입니다.
> ```python
> A @ B                # 행렬 곱
> np.dot(A, B)         # 같음
> A * B                # 요소별 곱 (아다마르 곱)
> ```

### 브로드캐스팅 — shape 이 달라도 되는 이유

```python
arr = np.array([1, 2, 3])
arr + 10                              # [11 12 13]
```

`arr` 은 `(3,)`, `10` 은 스칼라인데 어떻게 더해질까요?
numpy 가 **`10` 을 `[10, 10, 10]` 으로 늘려서(broadcast)** 계산합니다.

```
[1 2 3]  +  10
    ↓        ↓ (자동 확장)
[1 2 3]  +  [10 10 10]
    =
[11 12 13]
```

**2차원에서도 동작합니다.**

```python
mat = np.array([[1, 2, 3],
                [4, 5, 6]])           # (2, 3)

mat + np.array([10, 20, 30])          # (3,) 을 각 행에 더함
# [[11 22 33]
#  [14 25 36]]

mat + np.array([[100], [200]])        # (2, 1) 을 각 열에 더함
# [[101 102 103]
#  [204 205 206]]
```

### 브로드캐스팅 규칙

**오른쪽 끝부터 차원을 비교합니다.**

```
① 두 차원이 같거나
② 둘 중 하나가 1이면
→ 호환됩니다. 부족한 차원은 앞에 1을 채웁니다.
```

**예시**

| A shape | B shape | 결과 | 설명 |
|---|---|---|---|
| `(3,)` | 스칼라 | `(3,)` | 스칼라는 항상 OK |
| `(2, 3)` | `(3,)` | `(2, 3)` | B가 각 행에 적용 |
| `(2, 3)` | `(2, 1)` | `(2, 3)` | B가 각 열에 적용 |
| `(2, 3)` | `(2,)` | ❌ | 3 vs 2 — 불일치 |
| `(4, 1)` | `(3,)` | `(4, 3)` | 양쪽이 늘어남 |
| `(2, 3, 4)` | `(3, 4)` | `(2, 3, 4)` | 앞에 1을 채움 |

**시각화**

```
(2, 3)  와  (3,)
  ↓          ↓ 앞에 1을 채움
(2, 3)  와  (1, 3)
  ↓          ↓ 1인 차원을 늘림
(2, 3)  와  (2, 3)   → 호환!
```

```
(2, 3)  와  (2,)
  ↓          ↓
(2, 3)  와  (1, 2)
       3 vs 2  → ❌ 불일치
```

> **`(2,3)` 에 `(2,)` 를 더하려면** `(2, 1)` 로 바꿔야 합니다.
> ```python
> mat + col.reshape(-1, 1)      # 또는 col[:, None]
> ```

### 유니버설 함수 (ufunc)

배열의 각 요소에 적용되는 함수입니다.

```python
arr = np.array([1, 4, 9, 16])

np.sqrt(arr)          # [1. 2. 3. 4.]
np.exp(arr)           # e^x
np.log(arr)           # 자연로그
np.log10(arr)         # 상용로그
np.log1p(arr)         # log(1+x) — 0 근처에서 정확
np.abs([-1, 2, -3])   # [1 2 3]
np.round(3.567, 2)    # 3.57
np.floor(3.7)         # 3.0   내림
np.ceil(3.2)          # 4.0   올림
np.sin(arr)           # 삼각함수
np.clip(arr, 2, 10)   # [2 4 9 10]  범위 제한
```

> **`np.log1p` 가 왜 있나** — `log(0)` 은 `-inf` 입니다.
> 매출 데이터처럼 0이 있는 값에 로그를 씌울 때 `log1p(x) = log(1+x)` 를 씁니다.
> 대단원 04에서 왜도가 큰 데이터를 변환할 때 씁니다.

### 집계 함수

```python
arr = np.array([1, 2, 3, 4, 5])

arr.sum()         # 15
arr.mean()        # 3.0
arr.std()         # 1.414   표준편차
arr.var()         # 2.0     분산
arr.min()         # 1
arr.max()         # 5
arr.argmin()      # 0       최솟값의 인덱스
arr.argmax()      # 4       최댓값의 인덱스
arr.cumsum()      # [1 3 6 10 15]   누적합
arr.prod()        # 120     곱
np.median(arr)    # 3.0     중앙값
np.percentile(arr, 25)   # 2.0   1사분위
```

> **`argmax` 가 중요합니다.** 대단원 03에서 모델이 예측한 확률 중
> **가장 높은 것의 인덱스 = 예측한 클래스**를 뽑을 때 씁니다.
> ```python
> pred = model.predict(x)          # [[0.1, 0.7, 0.2], ...]
> classes = pred.argmax(axis=1)    # [1, ...]
> ```

### axis — 오늘의 핵심

**`axis` 는 "어느 방향으로 접을 것인가" 입니다.**

```
arr = [[1, 2, 3],
       [4, 5, 6]]        shape (2, 3)

axis=0 : 행 방향으로 접음 (세로로 압축) → 열별 결과
         [1, 2, 3]
         [4, 5, 6]
         ↓  ↓  ↓
         [5, 7, 9]       shape (3,)

axis=1 : 열 방향으로 접음 (가로로 압축) → 행별 결과
         [1, 2, 3] →  6
         [4, 5, 6] → 15
                        shape (2,)
```

```python
arr = np.array([[1, 2, 3],
                [4, 5, 6]])

arr.sum()              # 21      전체
arr.sum(axis=0)        # [5 7 9]     열별 합계
arr.sum(axis=1)        # [6 15]      행별 합계
```

**외우는 법 세 가지**

| 방법 | 설명 |
|---|---|
| **"그 축이 사라진다"** | `(2,3)` 에 `axis=0` → `(3,)` — 0번 축이 사라짐 |
| **"그 축을 따라 이동하며 계산"** | `axis=0` 은 행을 따라 내려가며 계산 |
| **shape 으로 확인** | 결과 shape 을 보면 확실합니다 |

```python
print(arr.shape)              # (2, 3)
print(arr.sum(axis=0).shape)  # (3,)   ← 0번(2)이 사라짐
print(arr.sum(axis=1).shape)  # (2,)   ← 1번(3)이 사라짐
```

> ⚠️ **직관과 반대로 느껴집니다.**
> "`axis=0` 은 행이니까 행별 합계 아닌가?" — **아닙니다.**
> `axis=0` 은 **행 방향으로 접어서 열별 결과**를 냅니다.
>
> **"결과의 shape 을 보라"** 가 가장 확실합니다.

**`keepdims` — 차원 유지**

```python
arr.sum(axis=1)                  # shape (2,)
arr.sum(axis=1, keepdims=True)   # shape (2, 1)
```

브로드캐스팅에 쓸 때 유용합니다.

```python
# 각 행을 그 행의 합으로 나누기
arr / arr.sum(axis=1, keepdims=True)      # (2,3) / (2,1) → OK
arr / arr.sum(axis=1)                     # (2,3) / (2,)  → 에러!
```

### 정규화와 표준화

| 방법 | 공식 | 결과 범위 | 쓰는 곳 |
|---|---|---|---|
| **정규화** (Min-Max) | `(x - min) / (max - min)` | 0 ~ 1 | 이미지 픽셀, 범위가 명확한 값 |
| **표준화** (Z-score) | `(x - mean) / std` | 평균 0, 표준편차 1 | 대부분의 머신러닝 |

```python
data = np.array([10, 20, 30, 40, 50], dtype=float)

# 정규화
normalized = (data - data.min()) / (data.max() - data.min())
# [0.   0.25 0.5  0.75 1.  ]

# 표준화
standardized = (data - data.mean()) / data.std()
# [-1.414 -0.707  0.     0.707  1.414]
```

> **왜 필요한가** — 특성마다 범위가 다르면 큰 값이 학습을 지배합니다.
> 나이(20~60)와 연봉(3000만~1억)을 그대로 쓰면 연봉만 보게 됩니다.
> 대단원 03·04에서 `MinMaxScaler`, `StandardScaler` 로 자동화하지만, **원리는 오늘 배운 이 두 줄**입니다.

## ④ 단계별 실습

### Step 1. 브로드캐스팅 이해하기

```python
import numpy as np

print("=" * 60)
print("                브로드캐스팅 규칙")
print("=" * 60)

cases = [
    ("스칼라",       np.array([1, 2, 3]),                    10),
    ("(2,3) + (3,)", np.array([[1,2,3],[4,5,6]]),           np.array([10, 20, 30])),
    ("(2,3) + (2,1)", np.array([[1,2,3],[4,5,6]]),          np.array([[100], [200]])),
    ("(3,1) + (4,)", np.arange(3).reshape(3, 1),            np.arange(4)),
]

for label, a, b in cases:
    result = a + b
    a_shape = getattr(a, "shape", "스칼라")
    b_shape = getattr(b, "shape", "스칼라")

    print(f"\n[{label}]")
    print(f"  A {str(a_shape):<10} + B {str(b_shape):<10} → {result.shape}")
    print(f"  결과:")
    print("   " + str(result).replace("\n", "\n   "))

# 실패 사례
print(f"\n[실패 사례]")
a = np.array([[1, 2, 3], [4, 5, 6]])       # (2, 3)
b = np.array([10, 20])                      # (2,)

try:
    a + b
except ValueError as e:
    print(f"  (2,3) + (2,) → ValueError")
    print(f"    {e}")
    print(f"  이유: 오른쪽 끝부터 비교하면 3 vs 2 → 불일치")

# 해결
fixed = a + b.reshape(-1, 1)
print(f"\n  해결: b.reshape(-1, 1) 로 (2,1) 을 만들면")
print(f"  (2,3) + (2,1) → {fixed.shape}")
print("   " + str(fixed).replace("\n", "\n   "))

print("\n" + "=" * 60)
```

```

  (2,3) + (2,) → ValueError

### Step 2. axis 완전 정복

```python
import numpy as np

# 학생 4명 × 과목 3개
scores = np.array([
    [85, 90, 78],      # 홍길동
    [92, 88, 95],      # 김철수
    [70, 75, 82],      # 이영희
    [60, 55, 68],      # 박민수
])

names = ["홍길동", "김철수", "이영희", "박민수"]
subjects = ["국어", "영어", "수학"]

print("=" * 56)
print("                axis 이해하기")
print("=" * 56)
print(f"\nscores.shape = {scores.shape}   (학생 4명 × 과목 3개)")
print(f"{'':10}{''.join(f'{s:>8}' for s in subjects)}")
for name, row in zip(names, scores):
    print(f"{name:<10}{''.join(f'{v:>8}' for v in row)}")

# ── 전체 집계 ──
print(f"\n[axis 없음 — 전체]")
print(f"  scores.sum()  = {scores.sum()}          shape=스칼라")
print(f"  scores.mean() = {scores.mean():.2f}")

# ── axis=0 : 행 방향으로 접음 → 과목별 ──
print(f"\n[axis=0 — 행 방향으로 접음 → '과목별' 결과]")
print(f"  shape: {scores.shape} → {scores.sum(axis=0).shape}   (0번 축이 사라짐)")
for subject, total, avg in zip(subjects, scores.sum(axis=0), scores.mean(axis=0)):
    print(f"  {subject}  합계 {total:>4}  평균 {avg:>6.1f}")

# ── axis=1 : 열 방향으로 접음 → 학생별 ──
print(f"\n[axis=1 — 열 방향으로 접음 → '학생별' 결과]")
print(f"  shape: {scores.shape} → {scores.sum(axis=1).shape}   (1번 축이 사라짐)")
for name, total, avg in zip(names, scores.sum(axis=1), scores.mean(axis=1)):
    print(f"  {name}  총점 {total:>4}  평균 {avg:>6.1f}")

# ── 다른 집계 함수도 동일 ──
print(f"\n[다른 집계 함수]")
print(f"  과목별 최고점 (axis=0): {scores.max(axis=0)}")
print(f"  학생별 최고점 (axis=1): {scores.max(axis=1)}")
print(f"  과목별 1등 인덱스:      {scores.argmax(axis=0)}"
      f"  → {[names[i] for i in scores.argmax(axis=0)]}")
print(f"  학생별 잘하는 과목:     {scores.argmax(axis=1)}"
      f"  → {[subjects[i] for i in scores.argmax(axis=1)]}")

# ── keepdims ──
print(f"\n[keepdims]")
print(f"  axis=1              → shape {scores.sum(axis=1).shape}")
print(f"  axis=1, keepdims=True → shape {scores.sum(axis=1, keepdims=True).shape}")

print("\n" + "=" * 56)
print("외우는 법: '그 축이 사라진다'")
print("  (4,3) 에 axis=0 → (3,)   0번 축(4)이 사라짐 → 과목별")
print("  (4,3) 에 axis=1 → (4,)   1번 축(3)이 사라짐 → 학생별")
print("=" * 56)
```

### Step 3. 정규화와 표준화 직접 구현

```python
import numpy as np

# 특성마다 범위가 크게 다른 데이터
data = np.array([
    #  나이   연봉(만원)  경력(년)   평점
    [   25,     3500,      1,      4.2],
    [   32,     5200,      6,      3.8],
    [   45,     8900,     18,      4.7],
    [   28,     4100,      3,      4.0],
    [   38,     6800,     12,      4.5],
], dtype=float)

features = ["나이", "연봉", "경력", "평점"]

print("=" * 64)
print("              정규화 / 표준화")
print("=" * 64)

print(f"\n[원본]")
print(f"  {'':8}{''.join(f'{f:>11}' for f in features)}")
for i, row in enumerate(data):
    print(f"  샘플{i+1:<4}{''.join(f'{v:>11,.1f}' for v in row)}")

print(f"\n  {'범위':<8}{''.join(f'{h:>11,.0f}' for h in (data.max(axis=0) - data.min(axis=0)))}")
print(f"  → 연봉의 범위가 5,400 으로 압도적입니다.")
print(f"    이대로 학습하면 모델이 연봉만 보게 됩니다.")


# ══════════ 정규화 (Min-Max) ══════════
def normalize(arr, axis=0):
    """0~1 범위로 정규화합니다."""
    min_vals = arr.min(axis=axis, keepdims=True)
    max_vals = arr.max(axis=axis, keepdims=True)
    ranges = max_vals - min_vals
    ranges[ranges == 0] = 1                      # 0으로 나누기 방지
    return (arr - min_vals) / ranges


normalized = normalize(data)

print(f"\n[정규화 (Min-Max) — 0~1]")
print(f"  {'':8}{''.join(f'{f:>11}' for f in features)}")
for i, row in enumerate(normalized):
    print(f"  샘플{i+1:<4}{''.join(f'{v:>11.3f}' for v in row)}")
print(f"  {'최소':<8}{''.join(f'{v:>11.3f}' for v in normalized.min(axis=0))}")
print(f"  {'최대':<8}{''.join(f'{v:>11.3f}' for v in normalized.max(axis=0))}")


# ══════════ 표준화 (Z-score) ══════════
def standardize(arr, axis=0):
    """평균 0, 표준편차 1 로 표준화합니다."""
    means = arr.mean(axis=axis, keepdims=True)
    stds = arr.std(axis=axis, keepdims=True)
    stds[stds == 0] = 1
    return (arr - means) / stds


standardized = standardize(data)

print(f"\n[표준화 (Z-score) — 평균 0, 표준편차 1]")
print(f"  {'':8}{''.join(f'{f:>11}' for f in features)}")
for i, row in enumerate(standardized):
    print(f"  샘플{i+1:<4}{''.join(f'{v:>11.3f}' for v in row)}")
print(f"  {'평균':<8}{''.join(f'{v:>11.3f}' for v in standardized.mean(axis=0))}")
print(f"  {'표준편차':<8}{''.join(f'{v:>11.3f}' for v in standardized.std(axis=0))}")

print("\n" + "=" * 64)
print("핵심: keepdims=True 로 (1,4) 를 만들어야")
print("      (5,4) / (1,4) 브로드캐스팅이 됩니다.")
print("=" * 64)
```

### Step 4. 게임 데이터 종합 분석 (오늘의 종합 예제)

```python
import numpy as np

rng = np.random.default_rng(42)

# 플레이어 5명 × 게임 6판의 점수
players = ["홍길동", "김철수", "이영희", "박민수", "최지우"]
N_GAMES = 6

scores = (rng.normal(12000, 4000, (5, N_GAMES))
          .clip(1000, 30000).astype(int))

print("=" * 72)
print("              게임 기록 분석 (5명 × 6판)")
print("=" * 72)

# ── 원본 표 ──
header = f"{'플레이어':<10}" + "".join(f"{f'{i+1}판':>9}" for i in range(N_GAMES))
print(f"\n{header}")
print("-" * 72)
for name, row in zip(players, scores):
    print(f"{name:<10}" + "".join(f"{v:>9,}" for v in row))

# ── axis=1 : 플레이어별 ──
print(f"\n[플레이어별 통계 — axis=1]")
print(f"{'플레이어':<10}{'평균':>10}{'최고':>10}{'최저':>10}{'표준편차':>10}{'최고판':>8}")
print("-" * 72)

p_mean = scores.mean(axis=1)
p_max = scores.max(axis=1)
p_min = scores.min(axis=1)
p_std = scores.std(axis=1)
p_best_game = scores.argmax(axis=1) + 1

for i, name in enumerate(players):
    print(f"{name:<10}{p_mean[i]:>10,.0f}{p_max[i]:>10,}{p_min[i]:>10,}"
          f"{p_std[i]:>10,.0f}{p_best_game[i]:>8}")

# ── axis=0 : 판별 ──
print(f"\n[판별 통계 — axis=0]")
print(f"{'':10}" + "".join(f"{f'{i+1}판':>9}" for i in range(N_GAMES)))
print("-" * 72)
print(f"{'평균':<10}" + "".join(f"{v:>9,.0f}" for v in scores.mean(axis=0)))
print(f"{'최고':<10}" + "".join(f"{v:>9,}" for v in scores.max(axis=0)))
print(f"{'1등':<10}" + "".join(f"{players[i][:3]:>9}" for i in scores.argmax(axis=0)))

# ── 전체 ──
print(f"\n[전체]")
print(f"  총 게임 수  {scores.size}판")
print(f"  전체 평균   {scores.mean():>10,.0f}점")
print(f"  전체 최고   {scores.max():>10,}점")
print(f"  전체 표준편차{scores.std():>9,.0f}")

# ── 브로드캐스팅 활용 ①: 각 플레이어의 평균 대비 ──
diff = scores - p_mean[:, None]              # (5,6) - (5,1)
print(f"\n[각 판이 자기 평균보다 얼마나 잘했나]")
print(f"{'플레이어':<10}" + "".join(f"{f'{i+1}판':>9}" for i in range(N_GAMES)))
print("-" * 72)
for name, row in zip(players, diff):
    print(f"{name:<10}" + "".join(f"{v:>+9,.0f}" for v in row))

# ── 브로드캐스팅 활용 ②: 판별 평균 대비 ──
game_mean = scores.mean(axis=0)              # (6,)
relative = scores / game_mean * 100          # (5,6) / (6,) → OK
print(f"\n[각 판의 평균을 100 으로 봤을 때]")
print(f"{'플레이어':<10}" + "".join(f"{f'{i+1}판':>9}" for i in range(N_GAMES)))
print("-" * 72)
for name, row in zip(players, relative):
    print(f"{name:<10}" + "".join(f"{v:>9.0f}" for v in row))

# ── 정규화 ──
normalized = (scores - scores.min()) / (scores.max() - scores.min())
print(f"\n[전체 정규화 0~1]  최소 {normalized.min():.2f}, 최대 {normalized.max():.2f}")

# ── 표준화 (플레이어별) ──
z = (scores - p_mean[:, None]) / (p_std[:, None] + 1e-9)
print(f"\n[플레이어별 표준화]  각 행의 평균 {z.mean(axis=1).round(6)}")

# ── 누적 점수 ──
cumulative = scores.cumsum(axis=1)
print(f"\n[누적 점수 추이]")
print(f"{'플레이어':<10}" + "".join(f"{f'{i+1}판':>10}" for i in range(N_GAMES)))
print("-" * 72)
for name, row in zip(players, cumulative):
    print(f"{name:<10}" + "".join(f"{v:>10,}" for v in row))

print(f"\n최종 1위: {players[cumulative[:, -1].argmax()]} "
      f"({cumulative[:, -1].max():,}점)")
print("=" * 72)

## ⑤ 자주 하는 실수

### `axis=0` 과 `axis=1` 을 반대로 씀

```python
# 학생별 총점을 구하려는데
scores.sum(axis=0)      # 과목별 총점이 나옴!
```

**증상** — **에러가 안 납니다.** 그럴듯한 숫자가 나와서 발견이 늦습니다.
**해결** — 결과 `shape` 을 확인하세요.

```python
print(scores.shape)              # (4, 3)  학생 4명 × 과목 3개
print(scores.sum(axis=1).shape)  # (4,)    ← 학생 수와 같으면 학생별
```

### `ValueError: operands could not be broadcast together`

```python
a = np.zeros((3, 4))
b = np.zeros((3,))
a + b
```

```
ValueError: operands could not be broadcast together with shapes (3,4) (3,)
```

**원인** — 오른쪽 끝부터 비교: `4 vs 3` 불일치.
**해결** — `b.reshape(-1, 1)` 로 `(3,1)` 을 만듭니다.

### `keepdims` 를 빠뜨려 브로드캐스팅 실패

```python
arr = np.arange(12).reshape(3, 4)
arr / arr.sum(axis=1)                     # (3,4) / (3,) → 에러
arr / arr.sum(axis=1, keepdims=True)      # (3,4) / (3,1) → OK
```

### `*` 를 행렬 곱으로 착각

```python
A = np.array([[1, 2], [3, 4]])

A * B        # [[5 12], [21 32]]     요소별 곱

### 정수 나눗셈으로 정규화가 0이 됨

```python
data = np.array([10, 20, 30])            # int64
(data - data.min()) / (data.max() - data.min())
# [0.  0.5 1. ]   ← 이건 괜찮지만

(data - data.min()) // (data.max() - data.min())
# [0 0 1]   ← // 를 쓰면 잘림
```

**주의** — `/` 는 항상 실수를 반환하므로 대부분 안전합니다.
다만 **제자리 연산(`/=`)은 정수 배열에서 에러**가 납니다.

```python
data /= 10
```
```
numpy._core._exceptions._UFuncOutputCastingError:
Cannot cast ufunc 'divide' output from dtype('float64') to dtype('int64')
```

**해결** — `data = data / 10` 또는 처음부터 `dtype=float`.

### 0으로 나누기

```python
data = np.array([5, 5, 5], dtype=float)
(data - data.min()) / (data.max() - data.min())     # 0/0
```
```
RuntimeWarning: invalid value encountered in divide
array([nan, nan, nan])
```

**원인** — 모든 값이 같으면 `max - min = 0`.
**해결** — 분모가 0이면 1로 바꿉니다.

```python
ranges = data.max() - data.min()
if ranges == 0:
    ranges = 1
```

배열 단위로는:

```python
ranges = arr.max(axis=0, keepdims=True) - arr.min(axis=0, keepdims=True)
ranges[ranges == 0] = 1
```

### `std()` 의 기본값이 모집단 표준편차

```python
data = np.array([1, 2, 3, 4, 5])
data.std()         # 1.414   (n 으로 나눔, 모집단)
data.std(ddof=1)   # 1.581   (n-1 로 나눔, 표본)
```

**주의** — pandas 의 `.std()` 는 기본이 **`ddof=1`(표본)** 입니다. **numpy 와 다릅니다.**
같은 데이터인데 값이 다르면 이것을 의심하세요.

## ⑥ 확인 문제

**1.** 아래 배열에서 각 요구사항에 맞는 `axis` 를 고르세요.

```python
sales = np.array([
    #  1월  2월  3월
    [100, 120, 150],     # A지점
    [200, 180, 220],     # B지점
    [ 90, 110, 130],     # C지점
])
```

① 지점별 총 매출 ② 월별 총 매출 ③ 가장 매출이 높은 지점 ④ 각 지점의 최고 매출 월

<details>
<summary>답 보기</summary>

```python
import numpy as np

sales = np.array([[100, 120, 150],
                  [200, 180, 220],
                  [ 90, 110, 130]])

branches = ["A지점", "B지점", "C지점"]
months = ["1월", "2월", "3월"]

# ① 지점별 총 매출 — 각 '행'을 접어야 하므로 axis=1
by_branch = sales.sum(axis=1)
print(f"① 지점별 총 매출 (axis=1): {by_branch}  shape={by_branch.shape}")
for b, v in zip(branches, by_branch):
    print(f"   {b}: {v}")

# ② 월별 총 매출 — 각 '열'을 접어야 하므로 axis=0
by_month = sales.sum(axis=0)
print(f"\n② 월별 총 매출 (axis=0): {by_month}  shape={by_month.shape}")
for m, v in zip(months, by_month):
    print(f"   {m}: {v}")

# ③ 가장 매출이 높은 지점 — 지점별 합계에서 최대
best_idx = sales.sum(axis=1).argmax()
print(f"\n③ 최고 매출 지점: {branches[best_idx]} ({sales.sum(axis=1).max()})")

# ④ 각 지점의 최고 매출 월 — 행마다 최댓값 위치 → axis=1
best_months = sales.argmax(axis=1)
print(f"\n④ 지점별 최고 매출 월 (axis=1): {best_months}")
for b, i in zip(branches, best_months):
    print(f"   {b}: {months[i]} ({sales[branches.index(b), i]})")

**판단 요령**

> **"결과가 몇 개 나와야 하는가?"** 를 먼저 생각하세요.
>
> - 지점별 결과 → 지점이 3개 → 결과 shape `(3,)` → 행이 남아야 함 → **`axis=1`**
> - 월별 결과 → 월이 3개 → 결과 shape `(3,)` → 열이 남아야 함 → **`axis=0`**
>
> 이 예에서는 3×3 이라 둘 다 `(3,)` 이 나와 헷갈립니다.
> **직사각형 데이터로 연습**하면 확실히 구분됩니다. `(4, 3)` 이면 `axis=0` → `(3,)`, `axis=1` → `(4,)`.
</details>

**2.** 5명의 국어·영어·수학 점수가 있습니다. 아래를 브로드캐스팅으로 구현하세요.
① 각 과목의 평균을 0으로 만들기(과목별 중심화) ② 각 학생의 점수를 그 학생 총점 대비 비율로

<details>
<summary>답 보기</summary>

```python
import numpy as np

scores = np.array([
    [85, 90, 78],
    [92, 88, 95],
    [70, 75, 82],
    [60, 55, 68],
    [88, 91, 79],
], dtype=float)

names = ["홍길동", "김철수", "이영희", "박민수", "최지우"]
subjects = ["국어", "영어", "수학"]

print(f"원본 shape: {scores.shape}\n")


# ── ① 과목별 중심화 (각 과목 평균을 0으로) ──
subject_mean = scores.mean(axis=0)                 # (3,)
centered = scores - subject_mean                   # (5,3) - (3,) → OK

print("① 과목별 중심화")
print(f"   과목 평균: {subject_mean.round(1)}")
print(f"   {'':10}{''.join(f'{s:>10}' for s in subjects)}")
for name, row in zip(names, centered):
    print(f"   {name:<10}{''.join(f'{v:>+10.1f}' for v in row)}")
print(f"   {'평균':<10}{''.join(f'{v:>10.1f}' for v in centered.mean(axis=0))}"
      f"   ← 0 이 됨")


# ── ② 학생별 비율 (각 학생 총점 대비) ──
student_total = scores.sum(axis=1, keepdims=True)  # (5,1) ← keepdims 필수!
ratio = scores / student_total * 100               # (5,3) / (5,1) → OK

print(f"\n② 학생별 과목 비중 (%)")
print(f"   {'':10}{''.join(f'{s:>10}' for s in subjects)}{'합계':>10}")
for name, row in zip(names, ratio):
    print(f"   {name:<10}{''.join(f'{v:>10.1f}' for v in row)}{row.sum():>10.1f}")


# ── keepdims 없이 하면? ──
print(f"\n[keepdims 실험]")
print(f"   sum(axis=1)              shape={scores.sum(axis=1).shape}")
print(f"   sum(axis=1, keepdims)    shape={scores.sum(axis=1, keepdims=True).shape}")

try:
    scores / scores.sum(axis=1)
except ValueError as e:
    print(f"   keepdims 없이 나누면 → ValueError")
    print(f"     {e}")
    print(f"   이유: (5,3) / (5,) → 오른쪽 끝 3 vs 5 불일치")
```

**3.** 아래 코드는 이미지 정규화를 시도합니다. 3가지 문제를 찾고 고치세요.

```python
import numpy as np

# 흑백 이미지 3장 (28×28, 0~255)
images = np.random.randint(0, 256, (3, 28, 28), dtype=np.uint8)

# 각 이미지를 0~1 로 정규화
images -= images.min()
images /= images.max()

print(images.min(), images.max())
```

<details>
<summary>답 보기</summary>

**실행하면**

```
numpy._core._exceptions._UFuncOutputCastingError:
Cannot cast ufunc 'divide' output from dtype('float64') to dtype('uint8')
with casting rule 'same_kind'
```

**문제 3가지**

**① dtype 이 `uint8` 인데 실수 나눗셈을 제자리로 시도**

`uint8` 배열에 `/=` 를 쓰면 결과(실수)를 정수 자리에 넣을 수 없어 에러가 납니다.

**② `uint8` 뺄셈에서 언더플로**

에러가 나기 전 `images -= images.min()` 은 실행됩니다.
`uint8` 은 0~255 인데, 만약 `min()` 이 0이 아니라면 일부 값이 음수가 되어 **순환**합니다.
(0 - 5 = 251)

```python
a = np.array([3, 10], dtype=np.uint8)
a -= 5
print(a)          # [254   5]   ← 3-5 가 254 가 됨!
```

**③ 이미지 3장을 하나로 묶어 정규화**

`images.min()` 은 **3장 전체의 최솟값**입니다.
"각 이미지를 정규화"하려면 **이미지마다 따로** 해야 합니다.

**해결**

```python
import numpy as np

rng = np.random.default_rng(42)
images = rng.integers(0, 256, (3, 28, 28), dtype=np.uint8)

print(f"원본 dtype={images.dtype}, shape={images.shape}")
print(f"전체 범위: {images.min()} ~ {images.max()}")


# ── ① 이미지 전체를 같은 기준으로 정규화 (일반적) ──
# 이미지는 0~255 로 범위가 정해져 있으므로 255로 나누는 것이 표준
normalized = images.astype(np.float32) / 255.0

print(f"\n[방법 1] 255 로 나누기 (표준)")
print(f"  dtype={normalized.dtype}, 범위 {normalized.min():.3f} ~ {normalized.max():.3f}")


# ── ② 이미지마다 따로 Min-Max 정규화 ──
imgs = images.astype(np.float32)

# 각 이미지의 min/max — axis=(1,2) 로 높이·너비를 접음
mins = imgs.min(axis=(1, 2), keepdims=True)      # (3, 1, 1)
maxs = imgs.max(axis=(1, 2), keepdims=True)      # (3, 1, 1)
ranges = maxs - mins
ranges[ranges == 0] = 1                           # 0으로 나누기 방지

per_image = (imgs - mins) / ranges

print(f"\n[방법 2] 이미지별 Min-Max 정규화")
print(f"  mins shape={mins.shape}  (이미지마다 하나씩)")
for i in range(3):
    print(f"  이미지{i+1}: 원본 {int(mins[i,0,0])}~{int(maxs[i,0,0])}"
          f"  →  정규화 {per_image[i].min():.1f}~{per_image[i].max():.1f}")


# ── ③ 표준화 (평균 0, 표준편차 1) ──
means = imgs.mean(axis=(1, 2), keepdims=True)
stds = imgs.std(axis=(1, 2), keepdims=True)
stds[stds == 0] = 1

standardized = (imgs - means) / stds

print(f"\n[방법 3] 이미지별 표준화")
for i in range(3):
    print(f"  이미지{i+1}: 평균 {standardized[i].mean():.6f}, "
          f"표준편차 {standardized[i].std():.6f}")
```

실행 결과:

```
원본 dtype=uint8, shape=(3, 28, 28)
전체 범위: 0 ~ 255

[방법 1] 255 로 나누기 (표준)
  dtype=float32, 범위 0.000 ~ 1.000

[방법 2] 이미지별 Min-Max 정규화
  mins shape=(3, 1, 1)  (이미지마다 하나씩)
  이미지1: 원본 0~255  →  정규화 0.0~1.0
  이미지2: 원본 0~255  →  정규화 0.0~1.0
  이미지3: 원본 0~255  →  정규화 0.0~1.0

[방법 3] 이미지별 표준화
  이미지1: 평균 -0.000000, 표준편차 1.000000
  이미지2: 평균 0.000000, 표준편차 1.000000
  이미지3: 평균 -0.000000, 표준편차 1.000000
```

**핵심 3가지**

| 문제 | 해결 |
|---|---|
| `uint8` 제자리 연산 | **먼저 `astype(np.float32)`** 로 변환 |
| 언더플로 | 변환 후 계산하면 음수도 안전 |
| 전체 vs 개별 | `axis=(1, 2)` 로 **이미지마다** 집계 |

> **`axis=(1, 2)`** — 축을 여러 개 지정할 수 있습니다.
> `(3, 28, 28)` 에서 1번(높이)과 2번(너비)을 접으면 `(3,)` 이 남아 **이미지마다 하나씩** 나옵니다.
> `keepdims=True` 를 쓰면 `(3, 1, 1)` 이 되어 브로드캐스팅이 됩니다.
>
> **대단원 03에서 이미지를 다룰 때 정확히 이 코드를 씁니다.**
> 실제로는 `Rescaling(1./255)` 층이 방법 1을 대신해 주지만, 원리는 같습니다.
</details>

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 요소별 연산 | `+ - * /` — **`*` 는 요소별 곱**, 행렬 곱은 `@` |
| 브로드캐스팅 | 오른쪽 끝부터 비교 · 같거나 1이면 OK |
| **`axis=0`** | 행 방향으로 접음 → **열별(과목별) 결과** |
| **`axis=1`** | 열 방향으로 접음 → **행별(학생별) 결과** |
| 외우는 법 | **"그 축이 사라진다"** · 결과 shape 확인 |
| `keepdims=True` | 차원 유지 — 브로드캐스팅에 필수 |
| `argmax` | **값이 아니라 인덱스** |
| 정규화 | `(x - min) / (max - min)` → 0~1 |
| 표준화 | `(x - mean) / std` → 평균 0, 표준편차 1 |
| 주의 | `std()` 기본은 numpy=모집단, pandas=표본 |

**오늘 반드시 기억할 세 가지**
> ① **`axis` 를 헷갈리면 에러 없이 틀린 답이 나옵니다.** 결과 shape 을 항상 확인하세요.
> ② `axis=1` 집계 결과로 나눌 때는 **`keepdims=True`** 가 필수입니다.
> ③ 정규화 전에 **`astype(float)`** 로 바꾸고, **분모가 0인 경우**를 처리하세요.
