## ① 학습 목표

이 강을 마치면 다음을 할 수 있습니다.

- `&`(주소)와 `*`(포인터 선언/역참조)의 두 가지 쓰임을 **구분해 읽을 수 있다**
- 포인터로 배열을 순회하는 코드(`*(p + i)`, `p++`)의 출력을 **그림으로 계산할 수 있다**

- 재귀 함수를 호출 트리를 그려 **정형 절차로 계산할 수 있다**

## ② 왜 필요한가

**포인터는 비전공자가 실기를 포기하는 1번 지점이자, 시험에서는 패턴이 정해져 있는 영역입니다.** 기출 복원 기준으로 C 문제에는 포인터·배열·함수가 거의 매번 등장하지만(비공식 경향), 나오는 패턴은 사실상 세 가지 — ①포인터로 배열 순회, ②주소 전달로 값 바꾸기(swap), ③문자열(char 배열) 다루기 — 뿐입니다. 원리를 "주소가 적힌 쪽지"라는 그림 하나로 잡고 이 세 패턴만 반복하면, 포인터는 오히려 **문제 유형이 예측되는 효자 영역**이 됩니다.

재귀는 "함수가 자신을 다시 부르는" 구조라 눈으로 따라가면 반드시 길을 잃습니다. 하지만 **호출 트리를 그리는 정형 절차**(부를 때 내려가고, return 값으로 올라온다)를 쓰면 감이 아니라 손으로 풀 수 있습니다.

**시험에서의 중요도와 출제 형태** — 결과 예측(포인터 순회·재귀 결과), 빈칸(swap의 `&`·`*` 채우기), 코드 해석(함수가 하는 일 쓰기) 유형으로 출제됩니다. 구조체는 단독 출제보다 "포인터 + 구조체" 조합의 읽기 재료로 나옵니다.

## ③ 개념 설명

### 3-1. 주소와 포인터 — 쪽지 비유

모든 변수는 메모리의 어느 **주소**(번지)에 삽니다. **포인터는 "그 주소를 적어 둔 쪽지"를 담는 변수**입니다.

| 기호 | 이름 | 뜻 | 읽는 법 |
|---|---|---|---|
| `&a` | 주소 연산자 | 변수 a의 주소 | "a의 주소" |
| `int *p` | 포인터 **선언** | 주소를 담는 변수 p를 만듦 | "p는 int를 가리키는 포인터" |
| `*p` | **역참조** (선언문 밖) | p에 적힌 주소로 **찾아가서 그 값** | "p가 가리키는 곳의 값" |

📌 **반드시 암기 — `*`의 두 얼굴**: 선언문 안(`int *p;`)에서는 "포인터를 만든다", 실행문(`*p = 20;`)에서는 "찾아가서 읽고 쓴다". 같은 기호의 다른 역할을 구분하는 것이 포인터 독해의 절반입니다.

```
      a (주소 1000번지)          p
    ┌───────┐              ┌────────┐
    │  10   │   ◀────────  │  1000  │   p = &a  (a의 주소를 쪽지에 적음)
    └───────┘              └────────┘
     *p 로 찾아가면 이 상자 → *p = 20 하면 a가 20으로 바뀜
```

### 3-2. 포인터와 배열 — 사실상 한 몸

📌 **반드시 암기 — 3규칙**

| 규칙 | 내용 |
|---|---|
| 1 | **배열 이름은 첫 요소의 주소**다: `p = arr`은 `p = &arr[0]`과 같다 |
| 2 | `p + i`는 "i **칸**(요소) 뒤의 주소"다 — 바이트가 아니라 자료형 크기 단위로 이동 |
| 3 | 그래서 **`*(p + i)` ≡ `p[i]` ≡ `arr[i]`** — 표기만 다를 뿐 같은 값 |

⚖️ **혼동 비교 — `*p++` vs `(*p)++`**: 후위 `++`가 `*`보다 우선순위가 높아 `*p++`는 "**p를 다음 칸으로** 옮기되, 옮기기 전 칸의 값을 사용"입니다. 값을 올리려면 `(*p)++`처럼 괄호가 필요합니다. 괄호 하나로 "포인터가 움직였는가, 값이 커졌는가"가 갈리는 최상급 함정입니다.

### 3-3. 함수 — 값 전달 vs 주소 전달

⚖️ **혼동 비교 (빈출)**

| 구분 | 값 전달 (call by value) | 주소 전달 (call by reference 방식) |
|---|---|---|
| 넘기는 것 | 값의 **복사본** | 변수의 **주소** |
| 함수 안에서 바꾸면 | 복사본만 바뀜 — **원본 그대로** | 주소로 찾아가 바꿈 — **원본이 바뀜** |
| 형태 | `void f(int x)` / 호출 `f(a)` | `void f(int *x)` / 호출 `f(&a)` |

C는 기본이 값 전달이므로, 함수가 호출한 쪽의 변수를 바꾸려면 **주소를 넘기고(`&a`) 포인터로 받아(`int *x`) 역참조로 씁니다(`*x = ...`)**. 이 세 부품이 swap 빈칸 문제의 정답 후보들입니다.

### 3-4. 재귀 — 호출 트리 정형 절차

**재귀 함수**는 자기 자신을 다시 호출하는 함수입니다. 반드시 ①**종료 조건**(더 안 부르는 경우)과 ②**축소 호출**(더 작은 문제로 다시 부름)로 이루어집니다.

📌 **풀이 절차**: ①호출을 만나면 아래로 가지를 그린다 → ②종료 조건에 닿으면 값을 확정한다 → ③return 값을 타고 **아래에서 위로** 거슬러 계산한다.

### 3-5. 구조체 — 서로 다른 자료형 묶기

**구조체(struct)** 는 관련 있는 값(예: 학번 + 이름)을 한 덩어리로 묶은 사용자 정의 자료형입니다.

| 접근 | 형태 | 언제 |
|---|---|---|
| `.` (점) | `s.no` | 구조체 **변수**로 접근 |
| `->` (화살표) | `p->no` | 구조체 **포인터**로 접근 (`(*p).no`와 동일) |

📌 변수면 점, 포인터면 화살표 — `->`가 곧 "역참조 + 점"의 줄임입니다.

### Step 2. 포인터 기본 — 쪽지로 원격 조작

**언어: C · 난이도: 🟡 기본 · 학습 개념: `&`·`*`, 역참조로 값 변경**

```c
#include <stdio.h>
int main(void) {
    int a = 10;
    int *p = &a;
    *p = 20;
    printf("%d %d\n", a, *p);
    return 0;
}
```

```
$ gcc ptr1.c -o ptr1 && ./ptr1
20 20
```

실행 순서: ①`p = &a` — a의 주소를 쪽지에 적음 → ②`*p = 20` — 쪽지의 주소로 **찾아가서** 20을 씀 → 그 상자가 곧 a이므로 a도 20. **p 자체는 주소일 뿐, 값의 세계에는 `*p`로만 들어갑니다.**

### Step 3. 포인터로 배열 순회

**언어: C · 난이도: 🟡 기본 · 학습 개념: 배열 이름 = 첫 주소, `*(p+i)`, `p++`**

```c
#include <stdio.h>
int main(void) {
    int arr[] = {10, 20, 30, 40};
    int *p = arr;
    printf("%d ", *p);
    printf("%d ", *(p + 2));
    p++;
    printf("%d\n", *p);
    return 0;
}
```

```
arr:  [10]   [20]   [30]   [40]
       ▲             ▲
       p (처음)      p+2          → p++ 후 p는 [20] 칸을 가리킴
```

```
$ gcc ptr2.c -o ptr2 && ./ptr2
10 30 20
```

| 출력 | 계산 | 값 |
|---|---|---|
| `*p` | p는 arr[0]의 주소 | 10 |
| `*(p + 2)` | 2칸 뒤 = arr[2] (p 자체는 안 움직임) | 30 |
| `p++` 후 `*p` | p가 한 칸 이동 → arr[1] | 20 |

`p + 2`는 **주소만 잠깐 계산**한 것이고, `p++`는 **p 자신이 이동**한 것 — "p가 지금 어디를 가리키는가"를 그림에 계속 표시하는 것이 요령입니다.

### Step 4. swap — 값 전달의 실패와 주소 전달의 성공

**언어: C · 난이도: 🟡 기본 · 학습 개념: 값 전달의 한계**

```c
#include <stdio.h>
void swap(int x, int y) {
    int t = x; x = y; y = t;
}
int main(void) {
    int a = 3, b = 7;
    swap(a, b);
    printf("%d %d\n", a, b);
    return 0;
}
```

```
$ gcc swap1.c -o swap1 && ./swap1
3 7
```

**바뀌지 않습니다.** 함수는 a·b의 **복사본** x·y를 받아 복사본끼리만 교환했고, 함수가 끝나면 복사본은 사라집니다. 에러가 없는데 결과가 의도와 다른 — 오류 찾기 유형의 대표 사례입니다.

**언어: C · 난이도: 🔴 심화(핵심 패턴) · 학습 개념: 주소 전달로 원본 교환**

```c
#include <stdio.h>
void swap(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}
int main(void) {
    int a = 3, b = 7;
    swap(&a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

```
$ gcc swap2.c -o swap2 && ./swap2
7 3
```

세 부품이 모두 필요합니다: 호출부의 **`&a, &b`**(주소를 넘김) — 매개변수의 **`int *x`**(주소를 받음) — 본문의 **`*x`**(찾아가서 바꿈). 빈칸 문제는 이 셋 중 하나를 비웁니다.

### Step 5. 재귀 — 호출 트리로 계산

**언어: C · 난이도: 🟡 기본 · 학습 개념: 종료 조건, 호출 트리**

```c
#include <stdio.h>
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
int main(void) {
    printf("%d\n", f(4));
    return 0;
}
```

```
내려가기(호출)                올라오기(return)
f(4) = 4 * f(3)              f(2) = 2 * 1 = 2
  f(3) = 3 * f(2)            f(3) = 3 * 2 = 6
    f(2) = 2 * f(1)          f(4) = 4 * 6 = 24
      f(1) → 종료 조건, 1 확정
```

```
$ gcc fact.c -o fact && ./fact
24
```

🔴 **심화 — 가지가 2개인 재귀**: `int fib(int n) { if (n <= 2) return 1; return fib(n-1) + fib(n-2); }` 일 때 `fib(5)`는? 트리를 그리면 fib(5)=fib(4)+fib(3), fib(4)=fib(3)+fib(2)=2+1=3, fib(3)=fib(2)+fib(1)=1+1=2 → **5**. 가지가 2개라도 절차는 같습니다 — 트리를 끝까지 그린다.

### Step 6. 구조체 — 점과 화살표

**언어: C · 난이도: 🟡 기본 · 학습 개념: struct 정의, `.`과 `->`**

```c
#include <stdio.h>
struct Student {
    int no;
    char name[10];
};
int main(void) {
    struct Student s = {1001, "KIM"};
    struct Student *p = &s;
    printf("%d %s\n", s.no, s.name);
    printf("%d %s\n", p->no, p->name);
    return 0;
}
```

```
$ gcc st.c -o st && ./st
1001 KIM
1001 KIM
```

같은 상자를 변수(`s.no`)로 열든 포인터(`p->no`)로 열든 값은 같습니다. `p->no`는 `(*p).no`의 줄임 표기입니다.

## ⑤ 자주 하는 실수

| 에러/증상 원문 | 원인 | 해결 |
|---|---|---|
| `Segmentation fault (core dumped)` | 초기화하지 않은 포인터를 역참조 (`int *p; *p = 10;`) — 쪽지에 아무 주소나 적힌 상태로 찾아감 | 포인터는 반드시 유효한 주소(`p = &a` 또는 `p = arr`)를 넣은 뒤 사용 |
| `warning: format '%d' expects argument of type 'int', but argument 2 has type 'int *'` | `printf("%d", p)` — 값 대신 포인터(주소)를 출력하려 함 | 값을 원하면 `*p` — `*` 누락은 결과 예측 문제의 단골 함정 |
| `scanf`가 값을 못 받거나 프로그램 비정상 종료 | `scanf("%d", n)` — `&` 누락 | scanf는 **주소**가 필요: `scanf("%d", &n)` (배열 이름은 이미 주소라 & 불필요) |
| 에러 없이 swap이 안 됨 (`3 7` 그대로) | 값 전달로 복사본만 교환 (Step 4 첫 코드) | 주소 전달 3부품(`&a` / `int *x` / `*x`) 확인 |
| 재귀가 끝나지 않고 `Segmentation fault` | 종료 조건 누락 또는 도달 불가 (예: `f(n-1)`이어야 하는데 `f(n)`) | 종료 조건이 실제로 도달되는지 확인 — 오류 찾기 유형 출제 지점 |
| `error: request for member 'no' in something not a structure or union` | 포인터에 점(`p.no`)을 씀 | 포인터는 화살표: `p->no` (변수는 점: `s.no`) |
| `*p++`가 값 증가라고 착각 | 우선순위: 후위 `++`가 먼저 → 포인터가 이동 | 값 증가는 `(*p)++` — ⚖️ 3-2절 비교 참고 |

## ⑥ 확인 문제

1. [결과 예측] 다음 C 코드의 출력을 쓰시오.
   ```c
   int a[] = {2, 4, 6, 8};
   int *p = a + 1;
   printf("%d %d", *p, *(p + 2));
   ```
2. [빈칸] 두 변수의 값이 실제로 교환되도록 호출부의 빈칸을 채우시오.
   ```c
   void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }
   int main(void) {
       int a = 3, b = 7;
       swap(___, ___);
       printf("%d %d", a, b);
       return 0;
   }
   ```
3. [코드 해석] 다음 함수에서 `f(5)`의 반환값을 쓰고, 이 함수가 하는 일을 한 문장으로 쓰시오.
   ```c
   int f(int n) {
       if (n == 0) return 0;
       return n + f(n - 1);
   }
   ```

<details>
<summary>정답과 해설</summary>

1. **`4 8`** — `p = a + 1`이므로 p는 a[1]을 가리킴 → `*p` = 4. `*(p + 2)`는 a[3] = 8.
   - 대표 오답: `4 6` — `p + 2`를 "a[1]에서 한 칸"으로 세는 실수. p 기준 **2칸** 뒤인 a[3]입니다.
2. **`&a`, `&b`** — 매개변수가 포인터(`int *x`)이므로 주소를 넘겨야 합니다. 출력은 `7 3`.
   - 대표 오답: `a, b` — 값 전달이 되어 `int *`에 int를 넣는 타입 경고 + 의도 불일치. `*a`는 a가 포인터가 아니므로 컴파일 에러.
3. 반환값 **`15`** — f(5)=5+f(4)=5+4+3+2+1+0. 하는 일: **1부터 n까지의(정확히는 n부터 0까지 내려가며) 합을 재귀로 구한다.**
   - 대표 오답: `120` — 팩토리얼(곱)과 혼동. 연산자가 `*`가 아니라 `+`임을 먼저 확인하세요.

</details>

## 마무리

**오늘의 요약** — 포인터는 "주소가 적힌 쪽지"입니다. `&`는 주소 얻기, `*`는 선언에서는 포인터 만들기·실행문에서는 찾아가기(역참조)입니다. 배열 이름은 첫 요소의 주소이고 `*(p+i) ≡ p[i] ≡ arr[i]`, `p+i`는 계산일 뿐이고 `p++`는 실제 이동입니다. 함수의 기본은 값 전달(원본 불변)이며 원본을 바꾸려면 `&a → int *x → *x`의 3부품이 필요합니다. 재귀는 호출 트리로 내려갔다가 return으로 올라오며, 구조체는 변수면 `.`, 포인터면 `->`입니다.

**복습 체크리스트**

- [ ] Step 3의 그림(p의 위치 변화)을 안 보고 다시 그릴 수 있다
- [ ] swap의 3부품(`&a` / `int *x` / `*x`)을 각각 왜 쓰는지 설명할 수 있다
- [ ] `*p++`와 `(*p)++`의 차이를 말할 수 있다
- [ ] f(4)=24의 호출 트리를 안 보고 그릴 수 있다
- [ ] `.`과 `->`를 언제 쓰는지 즉답할 수 있다

**과제** — ① `arr = {5, 10, 15, 20}`, `p = arr + 2`일 때 `*p`, `*(p-1)`, `*(p+1)`을 그림과 함께 계산, ② Step 5의 함수를 `n * f(n-2)` (n<=1이면 1)로 바꾼 `f(5)` 계산(호출 트리 필수 — 답 15), ③ 오답노트에 이번 주 틀린 포인터 문제의 "p가 가리키던 위치"를 그림으로 기록. (형성평가는 06강 과제에 통합)

**다음 강 예고** — 06강은 Java 객체지향(상속·오버라이딩·다형성·예외)과 Python 심화(자료형 4종·슬라이싱·함수)입니다. "부모 타입 변수에 자식 객체"가 만드는 출력 반전이 핵심이며, 3주차 형성평가가 과제로 나갑니다.
