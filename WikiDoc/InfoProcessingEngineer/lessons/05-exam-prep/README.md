## 이 문서들을 읽는 법

이 단원은 새 개념이 아니라 **실전 전환** 단원입니다. 본문 구조는 동일한 6블록 + 마무리이되, ④ 단계별 실습의 중심이 문제 세트·진단·모의고사로 바뀝니다.

| 블록 | 이 단원에서의 내용 |
|---|---|
| ① 학습 목표 | 실전 기술(시간 배분·답안 규칙·자기 진단) 중심 |
| ② 왜 필요한가 | "아는 것"과 "점수"의 간극을 메우는 이유 |
| ③ 개념 설명 | 전략·규칙·양식 (시간 배분표, 진단 매트릭스, 답안 작성 규칙) |
| ④ 단계별 실습 | 문제 세트 풀이 → 채점 → 분석의 실전 사이클 |
| ⑤ 자주 하는 실수 | 실전 행동의 실수 (검산 생략, 형식 무시, 시간 배분 실패) |
| ⑥ 확인 문제 | 전략·규칙 점검 3문항 |
| 마무리 | 요약 → 체크리스트 → 과제(개인별 보완·형성평가) |

**평가 규칙**

- 모든 문제는 기출 원문 복제 없는 **변형·창작 문제**이며, SQL은 [07강 공용 예제 스키마](../03-database/lesson-07.md) 기준입니다.
- 채점은 보수적 기준([로드맵 7절](../../curriculum/README.md)): 코드는 출력 완전 일치, SQL은 표준 문법 + 요구 키워드, 이론은 핵심 키워드 포함.
- 채점 결과는 반드시 **취약 진단 매트릭스(14강)** 에 누적 기록합니다.
