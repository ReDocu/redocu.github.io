## 이 단원의 완료 기준

- [ ] 서버 구성을 사용자 데이터/AMI로 재현할 수 있다
- [ ] 자동 확장·자동 복구되는 구조를 만들 수 있다
- [ ] ALB·Route 53·ACM으로 HTTPS 서비스를 제공할 수 있다
- [ ] S3·EBS·EFS·CloudFront를 용도에 맞게 선택하고 근거를 댄다
- [ ] RDS를 프라이빗에 이중화 배치하고 백업·복구·장애 조치를 수행한다
- [ ] 3계층 고가용성 서비스를 혼자 구축하고 비용을 산정한다

> 🏁 **16강 중간 프로젝트**의 요구사항·루브릭은 [커리큘럼 대단원 문서](../../curriculum/02-compute-data.md#16강--중간-프로젝트-평가-루브릭)에 있습니다.
