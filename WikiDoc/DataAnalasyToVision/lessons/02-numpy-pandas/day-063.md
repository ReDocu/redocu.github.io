어제 그린 "카테고리별 가격 분포 비교"를 떠올려 봅시다.

**matplotlib**

```python
order = df.groupby("category")["price"].median().sort_values().index
groups = [df[df["category"] == c]["price"].values for c in order]

bp = ax.boxplot(groups, labels=order, patch_artist=True,
                medianprops=dict(color="#1e293b", linewidth=2),
                flierprops=dict(marker="o", markersize=4, alpha=0.4))

for patch in bp["boxes"]:
    patch.set_facecolor("#93c5fd")
```

**seaborn**

```python
sns.boxplot(data=df, x="category", y="price", ax=ax)
```

**한 줄입니다.** 게다가 여기에 성별까지 나누고 싶다면?

```python
sns.boxplot(data=df, x="category", y="price", hue="season", ax=ax)
```

**`hue=` 한 단어**로 끝납니다. matplotlib 이었다면 반복문과 위치 계산이 필요합니다.

| | matplotlib | seaborn |
|---|---|---|
| 입력 | 배열·리스트 | **DataFrame** ⭐ |
| 그룹 나누기 | 직접 반복문 | **`hue=`** |
| 통계 계산 | 직접 | **자동** (평균·신뢰구간) |
| 세밀한 제어 | **완전** | 제한적 |

> **seaborn 은 matplotlib 위에 얹혀 있습니다.**
> 대체재가 아니라 **단축키**입니다. 세밀한 조정은 여전히 matplotlib 으로 합니다.

### 두 종류의 함수 — 반드시 구분

| | **axes-level** | **figure-level** |
|---|---|---|
| 예 | `scatterplot` `histplot` `boxplot` | `relplot` `displot` `catplot` |
| 반환 | **`Axes`** | **`FacetGrid`** |
| `ax=` 인자 | ✅ 있음 | ❌ 없음 |
| 서브플롯에 넣기 | ✅ 가능 | ❌ 불가 |
| 격자 분할 (`col=`) | ❌ | ✅ 가능 |

```python
# axes-level — 기존 ax 에 그림  ⭐ 주로 이것
fig, ax = plt.subplots()

# figure-level — 스스로 Figure 를 만듦
g = sns.catplot(data=df, x="category", y="price",
                kind="box", col="season", height=4)
```

**`countplot` vs `barplot`**

```python
sns.countplot(data=df, x="category")            # 각 범주의 행 수
sns.barplot(data=df, x="category", y="price")   # 각 범주의 price 평균
```

**`barplot` 의 세로선은 신뢰구간입니다**

```python
sns.barplot(data=df, x="category", y="price", errorbar=("ci", 95))  # 기본
sns.barplot(data=df, x="category", y="price", errorbar="sd")        # 표준편차
sns.barplot(data=df, x="category", y="price", errorbar=None)        # 없음
sns.barplot(data=df, x="category", y="price", estimator="median")   # 중앙값
```

> ⚠️ **seaborn 0.12 부터 `ci=` 는 `errorbar=` 로 바뀌었습니다.**
> ```
> FutureWarning: The `ci` parameter is deprecated. Use `errorbar=('ci', 95)`
> ```

**신뢰구간을 읽는 법**

```
      ┬              ┬
      │              │
  ┌───┴───┐      ┌───┴───┐
  │       │      │       │
  └───┬───┘      └───┬───┘
      │              │
      ┴              ┴
   A: 넓음        B: 좁음
   (표본 적거나    (표본 많거나
    편차 큼)        편차 작음)
```

> **두 막대의 신뢰구간이 겹치면 "차이가 있다"고 말하기 어렵습니다.**
> 막대 높이만 보고 결론 내리지 마세요.

**`boxplot` vs `violinplot`**

```
boxplot                violinplot
  ┬                      ╱╲
┌─┴─┐                   ╱  ╲
│███│                  │    │      ← 분포 모양이 보임
└─┬─┘                   ╲  ╱
  ┴                      ╲╱
"요약 통계"             "분포 전체"
```

> **봉우리가 2개인 분포는 violinplot 에서만 보입니다.** ([Day 062](day-062.md))

### 상관 히트맵 — 오늘의 핵심

```python
corr = df.corr(numeric_only=True)

sns.heatmap(corr,
            annot=True,           # 값 표시 ⭐
            fmt=".2f",            # 소수 2자리
            cmap="RdBu_r",        # 발산형 컬러맵 ⭐
            center=0,             # 0을 중앙(흰색)으로 ⭐
            vmin=-1, vmax=1,
            square=True,
            linewidths=0.5,
            cbar_kws={"label": "상관계수"})
```

> ⚠️ **`center=0` 과 발산형 컬러맵을 반드시 쓰세요.**
> 순차형 컬러맵(`Blues`)을 쓰면 **음의 상관과 무상관을 구분할 수 없습니다.**

**위쪽 삼각형 가리기 (중복 제거)**

```python
import numpy as np

mask = np.triu(np.ones_like(corr, dtype=bool))
sns.heatmap(corr, mask=mask, annot=True, cmap="RdBu_r", center=0)
```

**상관계수 해석**

| \|r\| | 강도 |
|---|---|
| 0.0 ~ 0.2 | 거의 없음 |
| 0.2 ~ 0.4 | 약함 |
| 0.4 ~ 0.6 | 보통 |
| 0.6 ~ 0.8 | 강함 |
| 0.8 ~ 1.0 | 매우 강함 |

> ⚠️ **`corr()` 은 피어슨 상관 — 선형 관계만 잡습니다.**
> ```
> y = x²  (완벽한 관계)  →  r ≈ 0
> ```
> **반드시 산점도로 눈으로 확인**하세요.
>
> 순위 관계를 보려면 `df.corr(method="spearman")` 을 씁니다.

**결정계수 R²**

```
r = 0.6  →  R² = 0.36  →  "36%를 설명"
r = 0.3  →  R² = 0.09  →  "9%를 설명"     ← 생각보다 작음
```

> **`r` 은 제곱해서 보세요.** `r=0.5` 는 절반이 아니라 **25%** 설명입니다.

### `pairplot` — 전체 관계 한눈에

```python
sns.pairplot(df[["price", "rating", "visitors"]])
sns.pairplot(df, vars=["price", "rating"], hue="category",

| 위치 | 내용 |
|---|---|
| 대각선 | 각 변수의 **분포** |
| 나머지 | 두 변수의 **산점도** |

> **5개 이하**로 제한하세요.

## ④ 단계별 실습

### Step 1. matplotlib vs seaborn

```python
"""같은 그래프를 두 방식으로."""

import platform
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

# ⚠ 테마 먼저, 폰트 나중
sns.set_theme(style="whitegrid", palette="deep", font_scale=1.0)
plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                              else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

OUT = Path("output")
OUT.mkdir(exist_ok=True)

# ── 실습 데이터 ──
rng = np.random.default_rng(42)
N = 600

df = pd.DataFrame({
    "category": rng.choice(["자연", "역사", "체험", "쇼핑", "음식"], N,
                           p=[0.28, 0.24, 0.20, 0.16, 0.12]),
    "season": rng.choice(["봄", "여름", "가을", "겨울"], N),
    "price": np.concatenate([np.zeros(120),
                             rng.lognormal(8.5, 0.6, N - 120).round(-2)]),
    "visitors": rng.lognormal(8.3, 1.0, N).round(),
    "review_count": rng.integers(0, 3000, N),
    "month": rng.integers(1, 13, N),
})
df = df.sample(frac=1, random_state=1).reset_index(drop=True)

# 관계 만들기: 가격↑ → 평점 약간↑, 방문객↑ → 리뷰↑
df["rating"] = (rng.normal(3.9, 0.45, N)
                + df["price"] / 55000
                + np.log1p(df["visitors"]) / 40).round(1).clip(1, 5)
df["review_count"] = (df["visitors"] * rng.uniform(0.02, 0.08, N)).round()

print("=" * 78)
print("                matplotlib vs seaborn")
print("=" * 78)

# ══════════ matplotlib 방식 ══════════
fig, axes = plt.subplots(1, 2, figsize=(14, 5.5))

ax = axes[0]
order = df.groupby("category")["price"].median().sort_values().index
groups = [df[df["category"] == c]["price"].values for c in order]

bp = ax.boxplot(groups, labels=order, patch_artist=True,
                medianprops=dict(color="#1e293b", linewidth=2),
                flierprops=dict(marker="o", markersize=4, alpha=0.4))
for patch in bp["boxes"]:
    patch.set_facecolor("#93c5fd")
    patch.set_alpha(0.8)

ax.set_title("matplotlib — 11줄")
ax.set_xlabel("카테고리")
ax.set_ylabel("가격 (원)")

# ══════════ seaborn 방식 ══════════
ax = axes[1]
sns.boxplot(data=df, x="category", y="price", order=order, ax=ax)

ax.set_title("seaborn — 1줄")
ax.set_xlabel("카테고리")
ax.set_ylabel("가격 (원)")

fig.suptitle("같은 그래프, 다른 코드량", fontsize=15, fontweight="bold")
fig.tight_layout()
fig.savefig(OUT / "sns1_compare.png")
plt.close(fig)

print(f"\n[코드량 비교]")
print(f"  matplotlib : 11줄 (그룹 분리 + 색 지정 + 스타일)")
print(f"  seaborn    :  1줄 (data= x= y=)")

# ══════════ hue 를 추가하면 ══════════
fig, axes = plt.subplots(1, 2, figsize=(15, 5.5))

sns.boxplot(data=df, x="category", y="price", ax=axes[0])
axes[0].set_title("hue 없음")

sns.boxplot(data=df, x="category", y="price", hue="season", ax=axes[1])
axes[1].set_title("hue='season' — 한 단어 추가")
axes[1].legend(title="계절", bbox_to_anchor=(1.02, 1), loc="upper left")

for ax in axes:
    ax.set_xlabel("카테고리")
    ax.set_ylabel("가격 (원)")

fig.suptitle("hue — 그룹을 나누는 한 단어", fontsize=15, fontweight="bold")
fig.tight_layout()
fig.savefig(OUT / "sns2_hue.png")
plt.close(fig)

print(f"\n[hue 의 위력]")
print(f"  matplotlib 로 같은 것을 하려면:")
print(f"    - 카테고리 × 계절 = {df['category'].nunique() * df['season'].nunique()}개 그룹 분리")
print(f"    - 각 그룹의 x 위치 계산 (offset)")
print(f"    - 색 매핑 + 범례 수동 생성")
print(f"    → 30줄 이상")
print(f"  seaborn: hue='season' 한 단어")

print("\n" + "=" * 78)
```

### Step 2. 분포와 그룹 비교

```python
"""seaborn 으로 분포를 여러 각도에서 봅니다."""

fig, axes = plt.subplots(2, 3, figsize=(18, 10))

# ── ① countplot — 범주 개수 ──
ax = axes[0, 0]
order = df["category"].value_counts().index
sns.countplot(data=df, y="category", order=order, ax=ax, color="#4c72b0")

for i, v in enumerate(df["category"].value_counts()[order]):
    ax.text(v + 4, i, f"{v}", va="center", fontsize=9)

ax.set_title("① countplot — 카테고리별 개수")
ax.set_xlabel("개수 (곳)")
ax.set_ylabel("")

# ── ② barplot — 평균 + 신뢰구간 ──
ax = axes[0, 1]
sns.barplot(data=df, x="category", y="rating", order=order,
            errorbar=("ci", 95), capsize=0.15, ax=ax, color="#4c72b0")

ax.set_title("② barplot — 평균 평점 (95% 신뢰구간)")
ax.set_xlabel("카테고리")
ax.set_ylabel("평점 (점)")
ax.set_ylim(0, 5)

# ── ③ boxplot vs violinplot ──
ax = axes[0, 2]
sns.violinplot(data=df, x="category", y="price", order=order,
               inner="box", ax=ax, color="#dd8452")

ax.set_title("③ violinplot — 분포 모양까지")
ax.set_xlabel("카테고리")
ax.set_ylabel("가격 (원)")

# ── ④ histplot + kde ──
ax = axes[1, 0]
sns.histplot(data=df, x="rating", bins=25, kde=True, ax=ax, color="#4c72b0")

ax.axvline(df["rating"].mean(), color="#c44e52", linestyle="--",
           label=f"평균 {df['rating'].mean():.2f}")
ax.axvline(df["rating"].median(), color="#55a868", linestyle="-",
           label=f"중앙값 {df['rating'].median():.2f}")

ax.set_title("④ histplot — 평점 분포")
ax.set_xlabel("평점 (점)")

# ══════════ 해석 자동 생성 ══════════
def describe_correlations(corr, threshold=0.2, top_n=6):
    """상관행렬에서 주목할 관계를 문장으로 만듭니다."""
    pairs = []
    cols = corr.columns

    for i, a in enumerate(cols):
        for b in cols[i + 1:]:
            r = corr.loc[a, b]
            if abs(r) >= threshold:
                pairs.append((a, b, r))

    pairs.sort(key=lambda t: abs(t[2]), reverse=True)

    def strength(r):
        a = abs(r)
        return ("매우 강한" if a >= 0.8 else "강한" if a >= 0.6
                else "보통" if a >= 0.4 else "약한" if a >= 0.2 else "거의 없는")

    lines = []
    for a, b, r in pairs[:top_n]:
        direction = "양" if r > 0 else "음"
        lines.append({
            "변수1": a, "변수2": b, "r": round(r, 3),
            "R²": round(r ** 2, 3),
            "강도": f"{strength(r)} {direction}의 상관",
            "해석": (f"{a}이(가) 클수록 {b}도 "
                     f"{'큰' if r > 0 else '작은'} 경향 "
                     f"(변동의 {r**2*100:.0f}% 설명)"),
        })

    return pd.DataFrame(lines)

```python
"""상관 분석 자동 해석 + 함정 탐지."""

import itertools

import numpy as np
import pandas as pd


def analyze_correlations(df, cols=None, threshold=0.2,
                         derived_pairs=None, verbose=True):
    """
    상관을 분석하고 해석 가능한 관계만 걸러냅니다.

    derived_pairs : 계산으로 파생된 변수쌍 [(a, b), ...] — 제외 대상
    """
    cols = cols or df.select_dtypes(include=np.number).columns.tolist()
    derived = {frozenset(p) for p in (derived_pairs or [])}

    pearson = df[cols].corr()
    spearman = df[cols].corr(method="spearman")

    rows = []

    for a, b in itertools.combinations(cols, 2):
        p = pearson.loc[a, b]
        s = spearman.loc[a, b]

        sub = df[[a, b]].dropna()
        n = len(sub)

        if n < 10:
            continue

        # ── 유의성 (근사) ──
        # t = r*sqrt(n-2)/sqrt(1-r^2), |t| > 2 면 대략 유의
        t = abs(p) * np.sqrt(n - 2) / np.sqrt(max(1 - p ** 2, 1e-9))
        significant = t > 2

        flags = []

        # ① 파생 관계
        if frozenset((a, b)) in derived:
            flags.append("파생관계(당연)")

        # ② 비선형
        if abs(s) - abs(p) > 0.15:
            flags.append(f"비선형 의심(ρ-r={abs(s)-abs(p):+.2f})")

        # ③ 표본 부족
        if n < 30:
            flags.append(f"표본 부족(n={n})")

        # ④ 유의하지 않음
        if not significant:
            flags.append("통계적으로 유의하지 않음")

        # ⑤ 이상치 영향 — 상하위 5% 제거 후 재계산
        lo_a, hi_a = sub[a].quantile([0.05, 0.95])
        lo_b, hi_b = sub[b].quantile([0.05, 0.95])
        trimmed = sub[(sub[a].between(lo_a, hi_a)) & (sub[b].between(lo_b, hi_b))]

        if len(trimmed) > 10:
            p_trim = trimmed[a].corr(trimmed[b])
            if abs(p - p_trim) > 0.2:
                flags.append(f"이상치 영향(절단 후 r={p_trim:.2f})")
        else:
            p_trim = np.nan

        if abs(p) < threshold and abs(s) < threshold:
            continue

        rows.append({
            "변수1": a, "변수2": b,
            "n": n,
            "피어슨r": round(p, 3),
            "스피어만ρ": round(s, 3),
            "R²": round(p ** 2, 3),
            "절단후r": round(p_trim, 3) if pd.notna(p_trim) else None,
            "유의": "✓" if significant else "✗",
            "주의": " / ".join(flags) if flags else "-",
        })

    result = pd.DataFrame(rows)
    if not result.empty:
        result = (result.assign(_abs=result["피어슨r"].abs())
                        .sort_values("_abs", ascending=False)
                        .drop(columns="_abs")
                        .reset_index(drop=True))

    if verbose:
        print("=" * 100)
        print("                              상관 분석 리포트")
        print("=" * 100)

        if result.empty:
            print(f"\n  |r| >= {threshold} 인 관계가 없습니다.")
            print("=" * 100)
            return result

        print(f"\n{result.to_string(index=False)}")

        # ── 신뢰할 수 있는 관계만 ──
        clean = result[result["주의"] == "-"]

        print(f"\n{'=' * 100}")
        print(f"[해석 가능한 관계]  {len(clean)}/{len(result)}건")
        print("=" * 100)

        if clean.empty:
            print("\n  ⚠ 모든 관계에 주의사항이 있습니다. 산점도로 직접 확인하세요.")
        else:
            for _, r in clean.iterrows():
                strength = ("매우 강한" if abs(r["피어슨r"]) >= 0.8
                            else "강한" if abs(r["피어슨r"]) >= 0.6
                            else "보통" if abs(r["피어슨r"]) >= 0.4 else "약한")
                direction = "양" if r["피어슨r"] > 0 else "음"

                print(f"\n  · {r['변수1']} ↔ {r['변수2']}")
                print(f"    r={r['피어슨r']:.3f} ({strength} {direction}의 상관), "
                      f"R²={r['R²']:.3f} → 변동의 {r['R²']*100:.0f}% 설명")
                print(f"    ⚠ 상관은 인과가 아닙니다. "
                      f"제3 변수·역인과 가능성을 검토하세요.")

        # ── 주의가 필요한 관계 ──
        risky = result[result["주의"] != "-"]

        if not risky.empty:
            print(f"\n{'=' * 100}")
            print(f"[⚠ 주의가 필요한 관계]  {len(risky)}건")
            print("=" * 100)

            for _, r in risky.iterrows():
                print(f"\n  · {r['변수1']} ↔ {r['변수2']}  (r={r['피어슨r']:.3f})")
                for flag in r["주의"].split(" / "):
                    print(f"    ⚠ {flag}")

        print("\n" + "=" * 100)

    return result


# ══════════ 사용 ══════════
if __name__ == "__main__":
    analyze_correlations(
        df,
        cols=["price", "rating", "visitors", "review_count", "month"],
        derived_pairs=[("visitors", "review_count")],   # 계산으로 만든 관계
    )

>
> 극단값 몇 개가 상관을 통째로 만들어 내는 경우가 있습니다.
>
> ```

>

> 리포트에서는 **명시적으로 제외**하고, 왜 제외했는지 적으세요.

```python
"""상관 분석 → 그래프 + 해석 문장 자동 생성."""

import itertools
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns


def correlation_report(df, cols=None, target=None, out_dir="output",
                       top_n=3, verbose=True):
    """
    상관 분석 리포트를 생성합니다 — 히트맵 + 산점도 + 해석 문장.

    target : 관심 변수 (있으면 이것과의 관계 위주로)
    """
    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)

    cols = cols or df.select_dtypes(include=np.number).columns.tolist()
    data = df[cols].dropna()

    pearson = data.corr()
    spearman = data.corr(method="spearman")

    # ── 관계 목록 ──
    pairs = []
    for a, b in itertools.combinations(cols, 2):
        if target and target not in (a, b):
            continue
        pairs.append({
            "a": a, "b": b,
            "r": pearson.loc[a, b],
            "rho": spearman.loc[a, b],
            "r2": pearson.loc[a, b] ** 2,
        })

    pairs.sort(key=lambda d: abs(d["r"]), reverse=True)
    top = pairs[:top_n]

    # ══════════ 그래프 ══════════
    n_scatter = len(top)
    fig = plt.figure(figsize=(6 + 5 * n_scatter, 5.5))
    gs = fig.add_gridspec(1, 1 + n_scatter, width_ratios=[1.2] + [1] * n_scatter)

    # 히트맵
    ax_heat = fig.add_subplot(gs[0, 0])
    mask = np.triu(np.ones_like(pearson, dtype=bool))
    sns.heatmap(pearson, mask=mask, annot=True, fmt=".2f",
                cmap="RdBu_r", center=0, vmin=-1, vmax=1,
                square=True, linewidths=0.5,
                cbar_kws={"label": "r", "shrink": 0.7}, ax=ax_heat)
    ax_heat.set_title("상관행렬", fontweight="bold")

    # 상위 관계 산점도
    for i, p in enumerate(top):
        ax = fig.add_subplot(gs[0, i + 1])

        sns.regplot(data=data, x=p["a"], y=p["b"],
                    scatter_kws={"alpha": 0.3, "s": 16},
                    line_kws={"color": "#c44e52", "linewidth": 2}, ax=ax)

        ax.set_title(f"{p['a']} vs {p['b']}\nr={p['r']:.3f}  R²={p['r2']:.3f}",
                     fontsize=11)
        ax.set_xlabel(p["a"])
        ax.set_ylabel(p["b"])

        if abs(p["rho"]) - abs(p["r"]) > 0.15:
            ax.text(0.03, 0.95, "⚠ 비선형 의심", transform=ax.transAxes,
                    va="top", fontsize=9,
                    bbox=dict(boxstyle="round", facecolor="#fef3c7"))

    fig.suptitle(f"상관 분석 리포트{f' — {target} 중심' if target else ''}",
                 fontsize=16, fontweight="bold")
    fig.tight_layout()

    path = out / f"corr_report{'_' + target if target else ''}.png"
    fig.savefig(path, dpi=150, bbox_inches="tight", facecolor="white")
    plt.close(fig)

    # ══════════ 해석 문장 ══════════
    def strength(r):
        a = abs(r)
        return ("매우 강한" if a >= 0.8 else "강한" if a >= 0.6
                else "보통 수준의" if a >= 0.4 else "약한" if a >= 0.2
                else "거의 없는")

    sentences = []

    for p in top:
        a, b, r, rho, r2 = p["a"], p["b"], p["r"], p["rho"], p["r2"]
        direction = "양" if r > 0 else "음"
        nonlinear = abs(rho) - abs(r) > 0.15

        s1 = (f"{a}와(과) {b}의 피어슨 상관계수는 r={r:.3f}로 "
              f"{strength(r)} {direction}의 상관을 보이며, "
              f"{b} 변동의 {r2*100:.0f}%를 설명한다.")

        if nonlinear:
            s2 = (f"스피어만 상관이 ρ={rho:.3f}로 피어슨보다 "
                  f"{abs(rho)-abs(r):+.3f} 높아, 두 변수가 직선이 아닌 "
                  f"단조 증가 관계일 가능성이 있다.")
            s3 = (f"{a}에 로그 변환을 적용해 상관을 재계산하고, "
                  f"산점도의 곡선 형태를 육안으로 확인해야 한다.")
        elif r2 < 0.2:
            s2 = (f"다만 설명력이 {r2*100:.0f}%에 그쳐, "
                  f"{b}를 결정하는 주된 요인은 이 데이터에 포함되지 않은 "
                  f"다른 변수일 가능성이 크다.")
            s3 = (f"{b}에 영향을 줄 만한 변수를 추가로 확보하거나, "
                  f"{a}를 구간으로 나눠 그룹별 차이를 확인해야 한다.")
        else:
            s2 = (f"{a}가 {b}에 영향을 주는 것인지, 반대인지, "
                  f"또는 제3의 요인이 둘 다에 작용하는 것인지는 "
                  f"이 데이터만으로 구분할 수 없다.")
            s3 = (f"관련 변수를 통제한 부분상관을 계산하거나, "
                  f"{a}를 인위적으로 변화시킨 실험 데이터가 필요하다.")

        sentences.append({"관계": f"{a} ↔ {b}", "r": round(r, 3),
                          "①관찰": s1, "②맥락": s2, "③다음": s3})

    if verbose:
        print("=" * 92)
        print(f"                        상관 분석 리포트")
        print("=" * 92)

        print(f"\n  대상 : {len(data):,}행 × {len(cols)}열")
        print(f"  변수 : {cols}")
        print(f"  그래프 : {path}")

        print(f"\n[상관행렬]")
        print(pearson.round(3).to_string())

        print(f"\n{'=' * 92}")
        print(f"[해석 — 상위 {len(sentences)}개 관계]")
        print("=" * 92)

        for i, s in enumerate(sentences, 1):
            print(f"\n  {i}. {s['관계']}  (r = {s['r']})")
            print(f"     ① {s['①관찰']}")
            print(f"     ② {s['②맥락']}")
            print(f"     ③ {s['③다음']}")

        print(f"\n{'=' * 92}")
        print("  ⚠ 자동 생성된 문장입니다. 도메인 지식으로 검토·수정하세요.")
        print("=" * 92)

    return {"pearson": pearson, "spearman": spearman,
            "sentences": pd.DataFrame(sentences), "figure": str(path)}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    correlation_report(
        df,
        cols=["price", "rating", "visitors", "review_count"],
        target="rating",
        top_n=3,
    )
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 설정 | **`sns.set_theme()` 먼저 → 한글 폰트 나중** |
| 함수 종류 | **axes-level**(`ax=` 가능) vs **figure-level**(`col=` 가능) |
| 데이터 전달 | **`data=df, x="col", y="col"`** |
| 그룹 나누기 | **`hue=`** 한 단어 |
| 개수 | `countplot` · 평균은 `barplot` |
| 신뢰구간 | **`errorbar=("ci", 95)`** (`ci=` 폐기) |
| 분포 | `histplot(kde=True)` · `violinplot`(모양까지) |
| 관계 | `scatterplot` · **`regplot`**(회귀선) |
| **히트맵** | **`annot=True, cmap="RdBu_r", center=0`** |
| 상관 | `corr(numeric_only=True)` · **`method="spearman"`** 과 비교 |
| **R²** | `r` 을 **제곱**해서 설명력으로 |
| 팔레트 | 범주=`deep` · 순차=`Blues` · **발산=`RdBu_r`** |
| `pairplot` | **5개 변수 이하** · `corner=True` |

**오늘 반드시 기억할 세 가지**
> ① **`sns.set_theme()` 이 한글 폰트를 지웁니다.** 테마 먼저, 폰트 나중.
> ② **히트맵에 `center=0` 과 발산형 컬러맵을 쓰세요.** 안 그러면 음의 상관이 안 보입니다.
> ③ **`r` 은 제곱해서 보세요.** `r=0.4` 는 **16%** 설명입니다. 생각보다 약합니다.

**과제**
① 자기 데이터로 **상관 히트맵** 작성 — `annot`, `center=0`, 아래 삼각형만
② 상위 3개 관계를 **산점도(`regplot`)** 로 그리고 육안 확인
③ **해석 3문장** 작성 — 관찰(숫자) / 맥락(가설) / 다음(확인 방법)
④ 피어슨과 스피어만을 비교해 **비선형 관계 후보** 찾기
⑤ `hue` 를 사용해 그룹별 분포를 비교한 그래프 1개 이상
