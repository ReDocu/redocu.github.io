이 레슨을 마치면 이렇게 할 수 있습니다.

- **`MarkerCluster`** 로 마커가 많은 지도를 다룰 수 있다.
- **`HeatMap`** 으로 밀집도를 표현할 수 있다.

## ② 왜 필요한가

어제 만든 지도에 데이터를 5,000건 넣으면 이렇게 됩니다.

```
① 브라우저가 멈춤 (HTML 20MB)
② 마커가 겹쳐서 아무것도 안 보임
③ "어디가 많은지"를 알 수 없음
```

```
        ●●●●●●●●
      ●●●●●●●●●●●●        ← 검은 덩어리
     ●●●●●●●●●●●●●●
      ●●●●●●●●●●●●
```

**해결 방법이 세 가지 있습니다.**

| 문제 | 해결 | 언제 |
|---|---|---|
| 마커가 너무 많음 | **`MarkerCluster`** | 개별 위치도 봐야 할 때 |
| 밀집도를 보고 싶음 | **`HeatMap`** | 어디가 몰렸는지가 핵심일 때 |
| 지역 단위로 비교 | **`Choropleth`** | 행정구역별 값 비교 |

```
MarkerCluster              HeatMap              Choropleth
    (25)                   ░▒▓█▓▒░              ┌──┬──┐
   ╱    ╲                 ▒▓███▓▒               │▓▓│░░│
 (8)    (12)              ░▒▓█▓▒░               ├──┼──┤
 ● ●    ● ● ●              ░▒░                  │██│▒▒│
                                                └──┴──┘
"묶어서 보여 줌"        "밀집도를 색으로"      "지역별 값"
```

> **세 가지는 답하는 질문이 다릅니다.**
> - 클러스터: **"여기에 몇 개 있고, 각각은 뭐지?"**
> - 히트맵: **"어디가 가장 몰려 있지?"**
> - 단계구분도: **"어느 시도가 많지?"**

## 1부 · MarkerCluster

```python
from folium.plugins import MarkerCluster

cluster = MarkerCluster(name="관광지").add_to(m)

for _, row in df.iterrows():
    folium.Marker([row["lat"], row["lng"]],
                  tooltip=row["name"]).add_to(cluster)
```

**확대하면 자동으로 풀립니다.**

```
줌 7                줌 10               줌 14
  (180)            (42) (65)          ● ● ●
                   (31) (42)          ● ● ● ●
                                       ● ●
```

**옵션**

```python
MarkerCluster(
    name="관광지",
    options={
        "maxClusterRadius": 60,           # 묶는 반경(픽셀). 기본 80
        "disableClusteringAtZoom": 15,    # 이 줌부터 풀림
        "spiderfyOnMaxZoom": True,        # 겹친 것을 방사형으로 펼침
        "showCoverageOnHover": True,      # 마우스 올리면 영역 표시
        "zoomToBoundsOnClick": True,      # 클릭하면 확대
    },
).add_to(m)
```

| 옵션 | 효과 |
|---|---|
| `maxClusterRadius` **작게** | 클러스터가 잘게 쪼개짐 |
| `maxClusterRadius` **크게** | 큰 덩어리로 묶임 |
| `disableClusteringAtZoom` | 상세 확인 지점 지정 |

**`FastMarkerCluster` — 수만 건일 때**

```python
from folium.plugins import FastMarkerCluster

FastMarkerCluster(data=df[["lat", "lng"]].values.tolist()).add_to(m)
```

| | `MarkerCluster` | `FastMarkerCluster` |
|---|---|---|
| 팝업·툴팁 | ✅ 개별 지정 | ❌ (JS 콜백 필요) |
| 속도 | 보통 | **매우 빠름** |
| 권장 건수 | ~5,000 | 5,000~100,000 |

> **팝업이 필요하면 `MarkerCluster`, 개수만 보면 `FastMarkerCluster`** 입니다.

## 2부 · HeatMap

```python
from folium.plugins import HeatMap

points = df[["lat", "lng"]].values.tolist()
HeatMap(points).add_to(m)
```

**가중치 주기 — 세 번째 값**

```python
points = df[["lat", "lng", "visitors"]].values.tolist()
HeatMap(points, name="방문객 밀집도").add_to(m)
```

> ⚠️ **가중치는 반드시 정규화하세요.**
> 방문객이 100 ~ 300,000 이면 **한 점이 전체를 태워** 버립니다.
> ```python
> w = np.log1p(df["visitors"])
> w = (w - w.min()) / (w.max() - w.min())        # 0~1
> points = list(zip(df["lat"], df["lng"], w))
> ```

**주요 옵션**

```python
HeatMap(
    points,
    radius=15,           # 각 점의 영향 반경(픽셀). 기본 25
    blur=12,             # 흐림 정도. 기본 15
    min_opacity=0.25,    # 최소 불투명도
    max_zoom=13,         # 이 줌 이상에서 최대 강도
    gradient={0.2: "#0072B2", 0.5: "#F0E442",
              0.8: "#E69F00", 1.0: "#D55E00"},
).add_to(m)
```

| 옵션 | 크게 하면 | 작게 하면 |
|---|---|---|
| `radius` | 넓게 번짐 | 점처럼 뾰족 |
| `blur` | 부드러움 | 경계가 뚜렷 |

> **어두운 타일(`CartoDB dark_matter`)과 궁합이 좋습니다.**
> 밝은 배경에서는 히트맵 색이 묻힙니다.

**시간에 따른 변화 — `HeatMapWithTime`**

```python
from folium.plugins import HeatMapWithTime

# 월별 데이터를 리스트의 리스트로
data = [df[df["month"] == m][["lat", "lng"]].values.tolist()
        for m in range(1, 13)]

HeatMapWithTime(data, index=[f"{m}월" for m in range(1, 13)],
                auto_play=True).add_to(m)
```

## 3부 · 단계구분도 (Choropleth)

**행정구역을 값에 따라 색칠하는 지도**입니다.

```
┌────────────────┐
│ ░░░░  ▓▓▓▓     │   ░ 적음
│ ░░░░  ▓▓▓▓     │   ▒ 보통
│  ▒▒▒  ████     │   ▓ 많음
│  ▒▒▒  ████     │   █ 매우 많음
└────────────────┘
```

### 준비물 — GeoJSON

**행정구역의 경계선 좌표**가 담긴 파일입니다.

```json
{
  "type": "FeatureCollection",
  "features": [{
    "type": "Feature",
    "properties": {"name": "서울특별시", "code": "11"},
    "geometry": {
      "type": "Polygon",
      "coordinates": [[[126.98, 37.57], [127.01, 37.58], ...]]
    }
  }]
}
```

> ⚠️ **GeoJSON 의 좌표는 `[경도, 위도]` 순서입니다.** ([Day 066](day-066.md))
> folium 마커와 반대라 헷갈립니다.

**어디서 구하나**

| 출처 | 내용 |
|---|---|
| `github.com/southkorea/southkorea-maps` | 시도·시군구 GeoJSON |
| 국가공간정보포털 | 공식 행정구역 (SHP → GeoJSON 변환 필요) |
| GADM | 세계 행정구역 |

```python
import json
import requests

url = ("https://raw.githubusercontent.com/southkorea/southkorea-maps/"
       "master/kostat/2018/json/skorea-provinces-2018-geo.json")

geo = requests.get(url).json()
```

### `Choropleth` 사용

```python
folium.Choropleth(
    geo_data=geo,                        # GeoJSON
    data=stats,                          # DataFrame
    columns=["sido", "count"],           # [키 열, 값 열] ⭐
    key_on="feature.properties.name",    # GeoJSON 의 키 경로 ⭐
    fill_color="YlOrRd",
    fill_opacity=0.7,
    line_opacity=0.3,
    legend_name="관광지 수 (곳)",
    bins=6,
    nan_fill_color="#f0f0f0",
).add_to(m)
```

### ⚠️ `key_on` — 가장 많이 막히는 지점

```
DataFrame 의 "sido" 값   ←→   GeoJSON 의 properties.name 값
      "서울특별시"                     "서울특별시"    ✅ 매칭
      "서울"                          "서울특별시"    ❌ 회색
```

**매칭이 실패해도 에러가 안 납니다. 그냥 회색이 됩니다.**

```python
# ① GeoJSON 의 키 이름 확인
props = geo["features"][0]["properties"]
print(props.keys())                      # dict_keys(['code', 'name', ...])
print(props["name"])                     # '서울특별시'

# ② 양쪽 값 비교
geo_names = {f["properties"]["name"] for f in geo["features"]}
df_names = set(stats["sido"])

print("GeoJSON 에만:", geo_names - df_names)
print("데이터에만  :", df_names - geo_names)
```

```
GeoJSON 에만: {'세종특별자치시', '광주광역시'}
데이터에만  : {'세종', '광주'}       ← 표기 불일치!
```

**해결 — 데이터 쪽을 GeoJSON 에 맞춥니다**

```python
NAME_MAP = {"서울": "서울특별시", "부산": "부산광역시", ...}
stats["sido"] = stats["sido"].replace(NAME_MAP)
```

> **`key_on` 은 `"feature.properties.키이름"` 형식**입니다.
> GeoJSON 마다 키 이름이 다릅니다 (`name`, `NAME_1`, `SIG_KOR_NM`, `adm_nm` …).
> **반드시 먼저 출력해서 확인**하세요.

### 색 구간 (`bins`)

```python
bins=6                                    # 균등 6구간
bins=[0, 50, 100, 200, 500, 1000]         # 직접 지정 ⭐
bins=list(stats["count"].quantile([0, .2, .4, .6, .8, 1]))   # 분위수
```

> ⚠️ **값이 치우쳐 있으면 균등 구간은 무의미합니다.**
> 서울이 1,000이고 나머지가 50~100이면 **서울만 진하고 나머지는 다 흰색**입니다.
> **분위수 기반 구간**을 쓰거나 **로그 변환**하세요.

### `folium.GeoJson` — 더 유연한 방법

`Choropleth` 는 편하지만 **툴팁·팝업 커스터마이징이 제한적**입니다.

```python
# 값을 GeoJSON properties 에 미리 넣기
value_map = stats.set_index("sido")["count"].to_dict()

for f in geo["features"]:
    name = f["properties"]["name"]
    f["properties"]["count"] = value_map.get(name, 0)


def style_fn(feature):
    v = feature["properties"]["count"]
    return {
        "fillColor": get_color(v),
        "color": "white",
        "weight": 1.2,
        "fillOpacity": 0.75,
    }


def highlight_fn(feature):
    return {"weight": 3, "color": "#333", "fillOpacity": 0.9}


folium.GeoJson(
    geo,
    style_function=style_fn,
    highlight_function=highlight_fn,          # 마우스 올리면 강조 ⭐
    tooltip=folium.GeoJsonTooltip(
        fields=["name", "count"],
        aliases=["지역", "관광지 수"],
        localize=True,
        style="background:white; padding:6px; border-radius:4px;",
    ),
).add_to(m)
```

| | `Choropleth` | `GeoJson` |
|---|---|---|
| 코드량 | **짧음** | 김 |
| 범례 | **자동** | 직접 만들어야 |
| 툴팁 | 제한적 | **자유** ⭐ |
| 강조 효과 | ❌ | ✅ |

> **처음엔 `Choropleth`, 다듬을 때 `GeoJson`** 으로 옮기는 흐름이 자연스럽습니다.

## ④ 단계별 실습

### Step 1. 클러스터와 히트맵

```python
"""마커가 많을 때 — 클러스터와 히트맵."""

from pathlib import Path

import folium
import numpy as np
import pandas as pd
from folium.plugins import (FastMarkerCluster, Fullscreen, HeatMap,
                            MarkerCluster, MeasureControl, MiniMap)

OUT = Path("output/maps")
OUT.mkdir(parents=True, exist_ok=True)

SIDO_INFO = {
    "서울특별시": (37.5665, 126.9780, 0.14, 0.20),
    "부산광역시": (35.1796, 129.0756, 0.12, 0.11),
    "인천광역시": (37.4563, 126.7052, 0.13, 0.06),
    "대구광역시": (35.8714, 128.6014, 0.11, 0.05),
    "광주광역시": (35.1595, 126.8526, 0.10, 0.03),
    "대전광역시": (36.3504, 127.3845, 0.10, 0.03),
    "울산광역시": (35.5384, 129.3114, 0.11, 0.02),
    "세종특별자치시": (36.4800, 127.2890, 0.08, 0.01),
    "경기도": (37.4138, 127.5183, 0.45, 0.15),
    "강원특별자치도": (37.8228, 128.1555, 0.55, 0.08),
    "충청북도": (36.8000, 127.7000, 0.35, 0.04),
    "충청남도": (36.5184, 126.8000, 0.40, 0.05),
    "전북특별자치도": (35.7175, 127.1530, 0.35, 0.04),
    "전라남도": (34.8679, 126.9910, 0.45, 0.05),
    "경상북도": (36.4919, 128.8889, 0.55, 0.05),
    "경상남도": (35.4606, 128.2132, 0.45, 0.05),
    "제주특별자치도": (33.4996, 126.5312, 0.20, 0.08),
}

CATEGORIES = ["자연", "역사", "체험", "쇼핑", "음식"]

# ── 실습 데이터 3,000건 ──
rng = np.random.default_rng(42)
N = 3000

sidos = rng.choice(list(SIDO_INFO),
                   size=N,
                   p=np.array([v[3] for v in SIDO_INFO.values()]) /
                     sum(v[3] for v in SIDO_INFO.values()))

rows = []
for i, sido in enumerate(sidos):
    lat0, lng0, spread, _ = SIDO_INFO[sido]
    rows.append({
        "id": 10000 + i,
        "name": f"{sido[:2]}명소{i:04d}",
        "sido": sido,
        "category": rng.choice(CATEGORIES, p=[0.30, 0.24, 0.20, 0.14, 0.12]),
        "lat": lat0 + rng.normal(0, spread * 0.5),
        "lng": lng0 + rng.normal(0, spread * 0.5),
        "rating": round(float(np.clip(rng.normal(4.0, 0.5), 1, 5)), 1),
        "visitors": int(rng.lognormal(8.5, 1.2)),
    })

df = pd.DataFrame(rows)
df = df[df["lat"].between(33, 39) & df["lng"].between(124, 132)].reset_index(drop=True)

CENTER = [36.3, 127.8]

print("=" * 78)
print("                  마커 3,000개 — 세 가지 접근")
print("=" * 78)
print(f"\n[데이터] {len(df):,}건")

# ══════════ ① 그냥 마커 (문제 확인용) ══════════
m_plain = folium.Map(location=CENTER, zoom_start=7, tiles="CartoDB positron")

for _, row in df.head(3000).iterrows():
    folium.CircleMarker(
        [row["lat"], row["lng"]], radius=4,
        color="#0072B2", fill=True, fill_opacity=0.5, weight=1,
    ).add_to(m_plain)

path_plain = OUT / "adv1_plain.html"
m_plain.save(str(path_plain))
size_plain = path_plain.stat().st_size / 1024

# ══════════ ② MarkerCluster ══════════
m_cluster = folium.Map(location=CENTER, zoom_start=7, tiles="CartoDB positron",
                       control_scale=True)

CAT_COLOR = {"자연": "green", "역사": "blue", "체험": "purple",
             "쇼핑": "orange", "음식": "red"}

cluster = MarkerCluster(
    name=f"관광지 ({len(df):,})",
    options={
        "maxClusterRadius": 60,
        "disableClusteringAtZoom": 14,
        "spiderfyOnMaxZoom": True,
        "showCoverageOnHover": True,
    },
).add_to(m_cluster)

for _, row in df.iterrows():
    folium.Marker(
        [row["lat"], row["lng"]],
        tooltip=f"{row['name']} · {row['rating']}점 · "
                f"{row['visitors']:,}명",
        popup=folium.Popup(
            f"<div style='font-family:Malgun Gothic;width:190px'>"
            f"<b style='font-size:13px'>{row['name']}</b><br><br>"
            f"지역 <b>{row['sido']}</b><br>"
            f"분류 {row['category']}<br>"
            f"평점 <b>{row['rating']}</b>점<br>"
            f"방문객 {row['visitors']:,}명</div>", max_width=220),
        icon=folium.Icon(color=CAT_COLOR[row["category"]],
                         icon="info-sign"),
    ).add_to(cluster)

MiniMap(toggle_display=True, position="bottomright").add_to(m_cluster)
Fullscreen().add_to(m_cluster)
MeasureControl(primary_length_unit="kilometers").add_to(m_cluster)
folium.LayerControl().add_to(m_cluster)

path_cluster = OUT / "adv2_cluster.html"
m_cluster.save(str(path_cluster))
size_cluster = path_cluster.stat().st_size / 1024

# ══════════ ③ FastMarkerCluster ══════════
m_fast = folium.Map(location=CENTER, zoom_start=7, tiles="CartoDB positron")

FastMarkerCluster(data=df[["lat", "lng"]].values.tolist(),
                  name="빠른 클러스터").add_to(m_fast)

folium.LayerControl().add_to(m_fast)

path_fast = OUT / "adv3_fastcluster.html"
m_fast.save(str(path_fast))
size_fast = path_fast.stat().st_size / 1024

# ══════════ ④ HeatMap ══════════
m_heat = folium.Map(location=CENTER, zoom_start=7,
                    tiles="CartoDB dark_matter")

# 가중치 정규화 (필수!)
w = np.log1p(df["visitors"])
w = (w - w.min()) / (w.max() - w.min())

heat_points = list(zip(df["lat"], df["lng"], w))

HeatMap(
    heat_points,
    name="방문객 밀집도",
    radius=14, blur=11, min_opacity=0.25, max_zoom=12,
    gradient={0.2: "#0072B2", 0.45: "#56B4E9",
              0.65: "#F0E442", 0.85: "#E69F00", 1.0: "#D55E00"},
).add_to(m_heat)

# 개수만 (가중치 없음) — 비교용
HeatMap(df[["lat", "lng"]].values.tolist(),
        name="관광지 개수 밀집도", radius=14, blur=11,
        min_opacity=0.2, show=False).add_to(m_heat)

folium.LayerControl(collapsed=False).add_to(m_heat)

path_heat = OUT / "adv4_heatmap.html"
m_heat.save(str(path_heat))
```

> - **`geo["features"][0]["properties"]` 를 반드시 먼저 출력**했습니다. 키 이름을 모르면 `key_on` 을 못 씁니다.
> - **좌표가 `[126.977, 37.566]`** — 경도가 먼저입니다. GeoJSON 표준입니다.
> - **키 매칭을 집합 연산으로 검증** — 불일치가 있으면 조용히 회색이 됩니다.

> - **`GeoJsonTooltip`** — `Choropleth` 보다 정보를 풍부하게 담을 수 있습니다.
> - **`highlight_function`** — 마우스를 올리면 테두리가 굵어져 어느 지역인지 확실해집니다.
> - **통합 지도의 레이어 순서** — 단계구분도가 켜져 있고 나머지는 `show=False`.

```python
"""데이터 규모에 맞는 지도 표현 자동 선택."""

from pathlib import Path

import folium
import numpy as np
import pandas as pd
from folium.plugins import FastMarkerCluster, HeatMap, MarkerCluster


def smart_map(df, lat_col="lat", lng_col="lng", name_col="name",
              weight_col=None, color_by=None, mode="auto",
              tiles=None, save_path=None, verbose=True):
    """
    데이터 규모에 맞는 방식으로 지도를 만듭니다.

    mode : 'auto' | 'markers' | 'cluster' | 'fast' | 'heat' | 'hybrid'
    """
    valid = (df[lat_col].between(33, 39) & df[lng_col].between(124, 132))
    work = df[valid].copy()
    dropped = len(df) - len(work)

    if work.empty:
        raise ValueError("유효한 좌표가 없습니다")

    n = len(work)

    # ══════════ 방식 자동 선택 ══════════
    if mode == "auto":
        if n <= 300:
            mode, reason = "markers", f"{n}개 — 개별 마커로 충분"
        elif n <= 3000:
            mode, reason = "cluster", f"{n}개 — 클러스터로 묶되 팝업 유지"
        elif n <= 30000:
            mode, reason = "hybrid", f"{n}개 — 히트맵 + 빠른 클러스터"
        else:
            mode, reason = "heat", f"{n:,}개 — 히트맵만 (개별 표시 불가)"
    else:
        reason = "사용자 지정"

    tiles = tiles or ("CartoDB dark_matter" if mode in ("heat", "hybrid")
                      else "CartoDB positron")

    center = [work[lat_col].mean(), work[lng_col].mean()]
    m = folium.Map(location=center, zoom_start=7, tiles=tiles,
                   control_scale=True)

    # ══════════ 색 ══════════
    PALETTE = ["#0072B2", "#E69F00", "#009E73", "#CC79A7",
               "#56B4E9", "#D55E00", "#F0E442", "#8c8c8c"]

    if color_by and color_by in work.columns:
        cats = sorted(work[color_by].dropna().astype(str).unique())
        cmap = {c: PALETTE[i % len(PALETTE)] for i, c in enumerate(cats)}
        work["_color"] = work[color_by].astype(str).map(cmap)
    else:
        cats, cmap = [], {}
        work["_color"] = PALETTE[0]

    # ══════════ 가중치 ══════════
    if weight_col and weight_col in work.columns:
        w = np.log1p(pd.to_numeric(work[weight_col],
                                   errors="coerce").fillna(0).clip(lower=0))
        span = w.max() - w.min()
        work["_weight"] = (w - w.min()) / span if span > 0 else 0.5
    else:
        work["_weight"] = 0.5

    # ══════════ 렌더링 ══════════
    def add_markers(target, subset, radius=6):
        for _, row in subset.iterrows():
            folium.CircleMarker(
                [float(row[lat_col]), float(row[lng_col])],
                radius=radius,
                tooltip=str(row.get(name_col, "")),
                color=row["_color"], weight=1.4,
                fill=True, fill_color=row["_color"], fill_opacity=0.68,
            ).add_to(target)

    if mode == "markers":
        add_markers(m, work)

    elif mode == "cluster":
        cluster = MarkerCluster(
            name=f"관광지 ({n:,})",
            options={"maxClusterRadius": 60,
                     "disableClusteringAtZoom": 14,
                     "spiderfyOnMaxZoom": True},
        ).add_to(m)
        add_markers(cluster, work)

    elif mode == "fast":
        FastMarkerCluster(
            data=work[[lat_col, lng_col]].values.tolist(),
            name=f"관광지 ({n:,})").add_to(m)

    elif mode == "heat":
        HeatMap(list(zip(work[lat_col], work[lng_col], work["_weight"])),
                name="밀집도", radius=14, blur=11,
                min_opacity=0.25).add_to(m)

    elif mode == "hybrid":
        heat_group = folium.FeatureGroup(name="밀집도 (히트맵)", show=True)
        HeatMap(list(zip(work[lat_col], work[lng_col], work["_weight"])),
                radius=13, blur=10, min_opacity=0.25).add_to(heat_group)
        heat_group.add_to(m)

        FastMarkerCluster(
            data=work[[lat_col, lng_col]].values.tolist(),
            name=f"개별 위치 ({n:,})").add_to(m)

    # ══════════ 범례 ══════════
    if cmap and mode in ("markers", "cluster"):
        items = "".join(
            f'<div style="margin:2px 0"><span style="display:inline-block;'
            f'width:11px;height:11px;background:{c};border-radius:50%;'
            f'margin-right:6px"></span>'
            f'<span style="font-size:11px">{cat}</span></div>'
            for cat, c in cmap.items())

        m.get_root().html.add_child(folium.Element(f"""
        <div style="position:fixed;bottom:24px;left:24px;z-index:9999;
                    background:white;padding:9px 13px;border-radius:6px;
                    box-shadow:0 2px 8px rgba(0,0,0,.2);
                    font-family:'Malgun Gothic',sans-serif">
          <div style="font-weight:bold;font-size:12px;margin-bottom:5px">
            {color_by}</div>{items}
        </div>"""))

    folium.LayerControl(collapsed=False).add_to(m)
    m.fit_bounds([[work[lat_col].min(), work[lng_col].min()],
                  [work[lat_col].max(), work[lng_col].max()]],
                 padding=(30, 30))

    if save_path:
        Path(save_path).parent.mkdir(parents=True, exist_ok=True)
        m.save(str(save_path))
        size_kb = Path(save_path).stat().st_size / 1024
    else:
        size_kb = len(m.get_root().render().encode()) / 1024

    if verbose:
        line = "=" * 74
        print(line)
        print("                    지도 표현 자동 선택")
        print(line)

        print(f"\n  데이터   : {n:,}개"
              f"{f' (무효 좌표 {dropped}건 제외)' if dropped else ''}")
        print(f"  선택 방식 : {mode}")
        print(f"  선택 이유 : {reason}")
        print(f"  타일     : {tiles}")
        print(f"  파일 크기 : {size_kb:,.0f} KB")

        FEATURES = {
            "markers": ("개별 위치 ✓", "팝업/툴팁 ✓", "밀집도 ✗"),
            "cluster": ("개별 위치 ✓", "팝업/툴팁 ✓", "밀집도 △(개수)"),
            "fast": ("개별 위치 ✓", "팝업/툴팁 ✗", "밀집도 △(개수)"),
            "heat": ("개별 위치 ✗", "팝업/툴팁 ✗", "밀집도 ✓"),
            "hybrid": ("개별 위치 ✓", "팝업/툴팁 ✗", "밀집도 ✓"),
        }

        print(f"\n  [이 방식으로 가능한 것]")
        for f in FEATURES[mode]:
            print(f"    · {f}")

        if size_kb > 3000:
            print(f"\n  ⚠ 파일이 {size_kb/1024:.1f}MB — "
                  f"공유가 어려울 수 있습니다")
            print(f"    mode='fast' 또는 'heat' 를 검토하세요")

        print(line)

    return m


# ══════════ 사용 ══════════
if __name__ == "__main__":
    for n in (200, 2000, 3000):
        sample = df.sample(min(n, len(df)), random_state=1)
        print(f"\n>>> {n}개\n")
        smart_map(sample, color_by="category", weight_col="visitors",
                  save_path=f"output/maps/smart_{n}.html")
```

```python
"""GeoJSON 키 매칭 자동 진단."""

import json
import re
from difflib import SequenceMatcher

import pandas as pd


def diagnose_geo_match(geo, df, df_key_col, geo_key=None,
                       auto_fix=True, verbose=True):
    """
    GeoJSON 과 DataFrame 의 키 매칭을 진단하고 매핑을 제안합니다.

    반환: dict(geo_key, mapping, matched, unmatched)
    """
    features = geo["features"]

    # ══════════ ① 키 후보 자동 탐색 ══════════
    props = features[0]["properties"]

    candidates = []
    for k, v in props.items():
        if not isinstance(v, str):
            continue

        all_values = [f["properties"].get(k) for f in features]
        unique = len({v for v in all_values if v})

        # 지역명처럼 보이는가
        korean = sum(1 for v in all_values
                     if isinstance(v, str) and re.search(r"[가-힣]", v))

        candidates.append({
            "키": k,
            "고유값": unique,
            "전체": len(features),
            "고유율": round(unique / len(features), 2),
            "한글포함": korean,
            "예시": str(v)[:20],
        })

    cand_df = pd.DataFrame(candidates).sort_values(
        ["고유율", "한글포함"], ascending=False)

    if geo_key is None:
        best = cand_df[(cand_df["고유율"] == 1.0)
                       & (cand_df["한글포함"] > 0)]
        geo_key = (best["키"].iloc[0] if len(best)
                   else cand_df["키"].iloc[0])

    # ══════════ ② 값 비교 ══════════
    geo_values = [f["properties"].get(geo_key) for f in features]
    geo_set = {v for v in geo_values if v}
    df_set = set(df[df_key_col].dropna().astype(str))

    matched = geo_set & df_set
    only_geo = geo_set - df_set
    only_df = df_set - geo_set

    # ══════════ ③ 매핑 제안 ══════════
    def normalize(s):
        return re.sub(r"(특별시|광역시|특별자치시|특별자치도|도|시|군|구|\s)",
                      "", str(s))

    mapping = {}
    unmapped = []

    for d in sorted(only_df):
        nd = normalize(d)

        # 정규화 후 정확 일치
        exact = [g for g in only_geo if normalize(g) == nd]
        if exact:
            mapping[d] = exact[0]
            continue

        # 포함 관계
        contained = [g for g in only_geo
                     if nd and (nd in normalize(g) or normalize(g) in nd)]
        if contained:
            mapping[d] = min(contained, key=len)
            continue

        # 유사도
        scored = [(g, SequenceMatcher(None, normalize(d), normalize(g)).ratio())
                  for g in only_geo]
        scored.sort(key=lambda t: t[1], reverse=True)

        if scored and scored[0][1] >= 0.6:
            mapping[d] = scored[0][0]
        else:
            unmapped.append(d)

    if verbose:
        line = "=" * 82
        print(line)
        print("                     GeoJSON 키 매칭 진단")
        print(line)

        print(f"\n[① GeoJSON 키 후보]")
        print(cand_df.to_string(index=False))
        print(f"\n  → 선택된 키: '{geo_key}'")

        print(f"\n[② 값 비교]")
        print(f"  GeoJSON 지역 : {len(geo_set)}개")
        print(f"  데이터 지역   : {len(df_set)}개")
        print(f"  일치         : {len(matched)}개 "
              f"({len(matched)/max(len(geo_set),1)*100:.0f}%)")
        print(f"  GeoJSON 에만  : {len(only_geo)}개")
        print(f"  데이터에만    : {len(only_df)}개")

        if only_geo:
            print(f"\n  [GeoJSON 에만 있음 — 지도에서 회색]")
            for g in sorted(only_geo)[:8]:
                print(f"    {g}")

        if mapping:
            print(f"\n[③ 자동 매핑 제안]  {len(mapping)}건")
            print(f"  {'데이터 값':<22}{'→':^5}{'GeoJSON 값':<24}근거")
            print("  " + "-" * 74)

            for d, g in sorted(mapping.items()):
                nd, ng = normalize(d), normalize(g)
                if nd == ng:
                    basis = "정규화 후 일치"
                elif nd in ng or ng in nd:
                    basis = "포함 관계"
                else:
                    ratio = SequenceMatcher(None, nd, ng).ratio()
                    basis = f"유사도 {ratio:.2f}"

                print(f"  {d:<22}{'→':^5}{g:<24}{basis}")

        if unmapped:
            print(f"\n  ⚠ 매핑 실패 {len(unmapped)}건 — 수동 확인 필요")
            for d in unmapped[:8]:
                print(f"    {d}")

        # ── 결과 ──
        after = len(matched) + len(mapping)
        print(f"\n{line}")
        rate = after / max(len(geo_set), 1) * 100

        status = ("✅ 매칭 양호" if rate >= 95
                  else "🟡 일부 누락" if rate >= 80 else "❌ 매칭 실패")
        print(f"  매칭률: {after}/{len(geo_set)} ({rate:.0f}%)   {status}")
        print(line)

        if mapping:
            print(f"\n  [적용 코드]")
            print(f"  NAME_MAP = {json.dumps(mapping, ensure_ascii=False, indent=6)}")
            print(f"  df['{df_key_col}'] = df['{df_key_col}'].replace(NAME_MAP)")
            print(f"  key_on = 'feature.properties.{geo_key}'")
            print(line)

    result = {"geo_key": geo_key, "mapping": mapping,

    if auto_fix and mapping:
```

## 오늘의 정리

| 방식 | 언제 | 핵심 |
|---|---|---|
| **`MarkerCluster`** | ~5,000건, 팝업 필요 | `maxClusterRadius` · `disableClusteringAtZoom` |
| **`FastMarkerCluster`** | 5,000~10만건 | 팝업 불가, **매우 빠름** |
| **`HeatMap`** | 밀집도가 목적 | **가중치 정규화 필수** · 어두운 타일 |
| **`Choropleth`** | 행정구역별 값 | **`key_on` 검증 필수** |
| `folium.GeoJson` | 툴팁·강조 커스터마이징 | `style_function` · `highlight_function` |

**단계구분도 체크리스트**

| # | 확인 |
|---|---|
| ① | `geo["features"][0]["properties"]` 를 **출력**했는가 |
| ② | GeoJSON 값과 데이터 값을 **집합 연산으로 비교**했는가 |
| ③ | 왜도를 보고 **구간(bins)** 을 정했는가 |
| ④ | `legend_name` 에 **단위**를 넣었는가 |
| ⑤ | **인구·면적 대비** 지표도 함께 제시했는가 |
| ⑥ | 회색 지역의 의미를 **명시**했는가 |

**오늘 반드시 기억할 세 가지**
> ① **`key_on` 이 틀리면 에러 없이 회색이 됩니다.** 매칭 검증을 먼저 하세요.
> ② **히트맵 가중치는 반드시 정규화하세요.** 한 점이 전체를 태웁니다.
> ③ **단계구분도는 절대 수와 인구 대비를 함께** 보여 주세요. 순위가 뒤바뀝니다.

**과제**
① 시도별(또는 시군구별) **단계구분도** 완성 — GeoJSON 매칭 검증 과정 포함
② **인구·면적 대비 지표**를 계산해 두 번째 단계구분도 제작
③ **해석 문장 3세트** 작성 (관찰 / 맥락 / 다음 확인)
④ **클러스터 지도**와 **히트맵**을 레이어로 묶은 통합 지도 1개
⑤ 마커 개수에 따른 **파일 크기 비교표** 작성
