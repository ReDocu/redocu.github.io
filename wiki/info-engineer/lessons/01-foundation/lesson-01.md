## ② 왜 필요한가

**시험 구조를 모르고 공부하면 시간의 절반을 잘못 씁니다.** 정보처리기사 실기는 컴퓨터로 코딩하는 시험이 아니라 **종이에 손으로 답을 쓰는 필답형** 시험입니다. 그런데 많은 수험생이 "실기"라는 이름만 보고 IDE에서 코딩 연습을 하거나, 반대로 필기처럼 이론 암기부터 시작합니다. 최근 기출 복원 분석에서는 코드 문제가 전체의 절반 안팎을 차지하는 경향이 확인됩니다(비공식 — 아래 ③ 참고). 즉, **눈으로 코드를 읽고 손으로 결과를 추적하는 능력**이 합격을 좌우합니다.

또한 혼합반에서는 출발점이 서로 다릅니다. 오늘 진단평가는 성적을 매기려는 것이 아니라, **남은 7주 동안 각자 무엇에 시간을 쓸지** 정하는 데이터를 만드는 절차입니다.

**시험에서의 중요도와 출제 형태** — 이 강 자체는 출제 범위가 아니지만, 이후 15개 강 전체의 학습 전략을 결정합니다.

### 3-3. 이 시험을 푸는 기술 — 코드 추적법

코드 추적(trace)이란 **코드를 한 줄씩 실행하는 컴퓨터 역할을 내가 하면서, 변수값의 변화를 표로 적는 것**입니다. 이 과정의 모든 코드 수업은 이 표를 쓰는 훈련입니다.

| 절차 | 내용 |
|---|---|
| 1 | 등장하는 변수를 모두 찾아 표의 열로 만든다 |
| 2 | 한 줄 실행할 때마다 바뀐 값만 새 행에 적는다 |
| 3 | 출력문을 만나면 그 시점의 값으로 출력을 적는다 |
| 4 | 다 풀고 나서 출력 형식(공백·줄바꿈)을 문제의 요구와 대조한다 |

### Step 2. 코드 추적 첫 경험

**언어: Python · 난이도: 🟢 입문 · 학습 개념: 변수, 대입, 추적표**

```python
a = 3
b = a + 2
a = a * b
print(a, b)
```

한 줄씩 컴퓨터가 되어 봅니다. `=`는 "같다"가 아니라 **"오른쪽을 계산해 왼쪽 이름에 저장한다"**는 뜻입니다.

| 실행한 줄 | a | b | 설명 |
|---|---|---|---|
| `a = 3` | 3 | — | a에 3 저장 |
| `b = a + 2` | 3 | 5 | 오른쪽의 a는 현재값 3 → 3+2=5를 b에 저장 |
| `a = a * b` | 15 | 5 | 3×5=15를 **a에 덮어씀** (b는 그대로) |
| `print(a, b)` | 15 | 5 | 출력: `15 5` |

```
$ python trace1.py
15 5
```

계산 순서까지 함께 보면: ③행에서 오른쪽 `a * b`를 **먼저** 계산(3×5=15)한 뒤에 왼쪽 `a`에 저장합니다. "a가 바뀌면 b도 바뀌지 않나?"라는 질문이 나오면 정상입니다 — **대입은 그 순간의 값 복사**이며, b는 다시 대입하기 전까지 5로 유지됩니다.

| 코드를 눈으로만 읽는다 | 눈으로는 "알겠는데" 손으로 쓰면 틀리는 것이 필답형의 함정 | 모든 코드 문제에 추적표를 쓴다 (Step 2 절차) |
| IDE에서만 코딩 연습한다 | 시험장에는 자동완성·실행 버튼이 없다 | 종이 먼저, 컴퓨터는 검증용 |
| 기출 '답'을 암기한다 | 같은 문제는 다시 나오지 않고, 같은 '개념'이 변형되어 나온다 | 오답노트에 답이 아니라 개념과 함정을 기록한다 |
| 진단 점수에 좌절한다 | 진단은 성적이 아니라 시간 배분 데이터 | 트랙 처방에 따라 보강하면 된다 — 8주 뒤가 본 시험 |

## ⑥ 확인 문제

1. [단답] 정보처리기사 실기의 시험 시간과 합격 기준 점수를 쓰시오.
2. [판정] 다음 중 실기 시험에서 **허용되는** 것을 모두 고르시오. → (ㄱ) 컴퓨터로 코드 실행 (ㄴ) 손으로 답안 작성 (ㄷ) 전자계산기 사용
3. [실기 유형] 다음 Python 코드를 추적표로 계산해 출력을 쓰시오.
   ```python
   x = 2
   y = x + 3
   x = y - x
   print(x, y)
   ```

<details>
<summary>정답과 해설</summary>

1. **150분, 60점 이상** (100점 만점).
2. **(ㄴ)** — 필답형이므로 컴퓨터·계산기 모두 사용 불가.
3. **`3 5`** — 추적: x=2 → y=5 → x=5−2=3 (y는 유지).
   - 대표 오답: `2 5` — 셋째 줄의 대입으로 x가 **덮어써진다**는 것을 놓친 경우. 대입문 왼쪽 변수는 항상 새 값으로 바뀝니다.

</details>
