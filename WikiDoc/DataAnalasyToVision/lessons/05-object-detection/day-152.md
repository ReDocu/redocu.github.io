## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- **입력 → 전처리 → 추론 → 후처리 → 출력** 파이프라인을 설계하고 구현할 수 있다.
- **모델을 한 번만 로드**하는 구조를 만들고, 왜 필요한지 숫자로 설명할 수 있다.

## ③ 개념 설명

### 파이프라인 5단계

```
[1] 입력 (Input)
      경로 · numpy 배열 · PIL · bytes · URL
                ↓
[2] 전처리 (Preprocess)
      로드 · 검증 · 형식 통일
                ↓
[3] 추론 (Inference)
      모델 실행 (Ultralytics 내부에서 리사이즈·정규화·NMS)
                ↓
[4] 후처리 (Postprocess)
      좌표 추출 · 필터링 · 표준 형식 변환
                ↓
[5] 출력 (Output)
      list[dict] · JSON
```

**★ 각 단계의 책임을 분리합니다**

| 단계 | 함수 | 책임 |
|---|---|---|
| 입력·전처리 | `_load_image()` | 무엇이 들어와도 numpy BGR 로 |
| 추론 | `predict()` | 모델 실행 |
| 후처리 | `_to_records()` | 표준 dict 로 |
| 그리기 | `draw()` | ★ **추론과 완전히 분리** |

> **★ 그리기를 왜 분리하는가**
> ```
> · 서버 API 는 JSON만 필요 (그림 불필요)
> · 라즈베리파이는 그리기가 CPU 낭비
> · 색·굵기·폰트를 상황마다 다르게
> → ★ predict() 는 데이터만, draw() 는 표현만
> ```

### 모델 로드 전략

**나쁜 방식 — 매번 로드**

```python
def detect(image):
    model = YOLO("model.pt")      # ✗ 1.2초
    return model(image)
```

**좋은 방식 — 클래스 인스턴스에 보관**

```python
class Detector:
    def __init__(self, weights):
        self.model = YOLO(weights)     # ★ 한 번만

    def predict(self, image):
        return self.model(image)       # 여러 번
```

**★ 워밍업 — 첫 추론이 느린 이유**

```
첫 추론    2,400 ms    ← CUDA 커널 컴파일 · 메모리 할당 · 그래프 최적화
두 번째      141 ms
세 번째      139 ms

★ 서버에서는 첫 사용자가 2.4초를 기다립니다
→ 시작할 때 더미 이미지로 미리 한 번 돌립니다
```


### 예외 처리 — 무엇이 잘못될 수 있는가

| 상황 | 발생 위치 | 처리 |
|---|---|---|
| 파일이 없음 | 입력 | `FileNotFoundError` |
| 이미지가 아님 (텍스트 파일) | 로드 | `ValueError` |
| 손상된 이미지 | 로드 | `ValueError` |
| **한글 경로** | 로드 | ★ `np.fromfile` 로 우회 |
| 배열 shape 이 이상 | 검증 | `ValueError` |
| 그레이스케일 | 검증 | ★ 자동 변환 |
| RGBA (알파 채널) | 검증 | ★ 자동 변환 |
| 가중치 파일 없음 | 초기화 | `FileNotFoundError` |
| GPU 메모리 부족 | 추론 | 재시도 또는 CPU 폴백 |
| 검출 0개 | 후처리 | ★ **정상.** 빈 리스트 |

**★ 검출 0개는 예외가 아닙니다**

```python
if not results:
    raise ValueError("검출 실패")     # ✗ 잘못됨

return {"count": 0, "detections": []}   # ✓ 정상 응답
```

### 로깅 — 예외를 삼키지 않기

```python
import logging

logger = logging.getLogger(__name__)

try:
    img = self._load_image(source)
except Exception as e:
    logger.error("이미지 로드 실패: %s (%s)", source, e)
    raise                            # ★ 다시 던짐
```

```
✗ except: pass                   무엇이 실패했는지 영영 모름
✗ except: return None            호출자가 원인을 모름
✓ 로그 남기고 다시 던짐          ← ★ 서버가 판단
```

### 인터페이스 계약

**모듈을 쓰는 사람과의 약속입니다.**

```python
class Detector:
    def __init__(self, weights, conf=0.25, iou=0.7, imgsz=None,
                 device=None, classes=None, max_det=300, warmup=True):
        """모델을 로드한다. 파일이 없으면 FileNotFoundError."""

    def predict(self, source, conf=None, iou=None, classes=None) -> dict:
        """검출한다.

        source: str | Path | np.ndarray(BGR) | PIL.Image | bytes
        반환:   표준 응답 dict (검출 0개여도 정상)
        예외:   FileNotFoundError, ValueError
        """

    def predict_batch(self, sources) -> list[dict]:
        """여러 장. 실패한 항목은 error 필드를 담아 반환."""

    def draw(self, image, response, **style) -> np.ndarray:
        """박스를 그린 새 이미지를 반환한다. 원본은 수정하지 않는다."""

    @property
    def class_names(self) -> dict:
        """{0: 'person', 1: 'box'}"""
```

> **★ 계약을 docstring 에 명시하세요.**
> "원본을 수정하지 않는다" 같은 약속이 없으면
> 호출자가 `image.copy()` 를 매번 해야 할지 몰라 헤맵니다.

## ④ 단계별 실습

### Step 1. `detector.py` — 뼈대

```python
"""src/detector.py — Object Detection 추론 모듈

사용 예:
    from detector import Detector

    det = Detector("models/best.pt", conf=0.45, iou=0.7)
    res = det.predict("photo.jpg")
    print(res["count"], res["counts_by_class"])

    img = det.draw(cv2.imread("photo.jpg"), res)
"""
from __future__ import annotations

import io
import logging
import time
from pathlib import Path
from typing import Any, Iterable

import cv2
import numpy as np

logger = logging.getLogger(__name__)

RESPONSE_VERSION = "1.0"
IMG_EXTS = (".jpg", ".jpeg", ".png", ".bmp", ".webp")

DEFAULT_COLORS = [
    (60, 200, 60), (255, 140, 60), (60, 120, 255), (200, 80, 220),
    (60, 220, 220), (180, 180, 60), (140, 60, 200), (60, 160, 255),
]


class DetectorError(Exception):
    """detector 모듈의 기본 예외"""


class Detector:
    """YOLO 검출 모델 래퍼.

    · 모델을 한 번만 로드하고 재사용한다
    · 입력 형식을 가리지 않는다 (경로 · 배열 · bytes · PIL)
    · 표준 dict 를 반환한다 (JSON 직렬화 가능)
    · 그리기는 predict 와 분리되어 있다
    """

    def __init__(self, weights: str | Path,
                 conf: float = 0.25, iou: float = 0.7,
                 imgsz: int | None = None, device: Any = None,
                 classes: Iterable[int] | None = None,
                 max_det: int = 300, half: bool = False,
                 warmup: bool = True):
        weights = Path(weights)
        if not weights.exists():
            raise FileNotFoundError(f"가중치 파일이 없습니다: {weights}")

        from ultralytics import YOLO      # ★ 지연 import — 모듈 로드 속도

        t0 = time.perf_counter()
        self.model = YOLO(str(weights))
        self.weights = weights
        self.conf = conf
        self.iou = iou
        self.classes = list(classes) if classes is not None else None
        self.max_det = max_det
        self.device = device
        self.half = half

        # 학습 시 imgsz 를 우선 사용
        self.imgsz = imgsz or int(
            getattr(self.model, "overrides", {}).get("imgsz", 640) or 640)

        load_ms = (time.perf_counter() - t0) * 1000
        logger.info("모델 로드 %.0fms — %s (imgsz=%d, %d classes)",
                    load_ms, weights.name, self.imgsz, len(self.model.names))

        if warmup:
            self._warmup()

    # ────────────────────────── 공개 API ──────────────────────────

    @property
    def class_names(self) -> dict[int, str]:
        return dict(self.model.names)

    def predict(self, source, conf=None, iou=None, classes=None) -> dict:
        """단일 이미지 검출 → 표준 응답 dict"""
        t_start = time.perf_counter()

        img = self._load_image(source)
        t_pre = time.perf_counter()

        r = self.model.predict(
            img,
            conf=self.conf if conf is None else conf,
            iou=self.iou if iou is None else iou,
            classes=self.classes if classes is None else list(classes),
            imgsz=self.imgsz, max_det=self.max_det,
            device=self.device, half=self.half,
            verbose=False,
        )[0]
        t_inf = time.perf_counter()

        h, w = img.shape[:2]
        dets = self._to_records(r, w, h)
        t_end = time.perf_counter()

        counts: dict[str, int] = {}
        for d in dets:
            counts[d["class"]] = counts.get(d["class"], 0) + 1

        return {
            "version": RESPONSE_VERSION,
            "image": {"width": w, "height": h},
            "model": {
                "weights": self.weights.name,
                "conf": self.conf if conf is None else conf,
                "iou": self.iou if iou is None else iou,
                "imgsz": self.imgsz,
            },
            "timing_ms": {
                "preprocess": round((t_pre - t_start) * 1000, 2),
                "inference": round((t_inf - t_pre) * 1000, 2),
                "postprocess": round((t_end - t_inf) * 1000, 2),
                "total": round((t_end - t_start) * 1000, 2),
            },
            "count": len(dets),
            "counts_by_class": counts,
            "detections": dets,
        }

    def predict_batch(self, sources, **kw) -> list[dict]:
        """여러 장. 실패해도 전체가 죽지 않는다."""
        out = []
        for s in sources:
            try:
                res = self.predict(s, **kw)
                res["source"] = str(s) if not isinstance(s, np.ndarray) else "<array>"
                out.append(res)
            except Exception as e:                       # ★ 개별 실패 격리
                logger.warning("검출 실패: %s (%s)", s, e)
                out.append({
                    "version": RESPONSE_VERSION,
                    "source": str(s), "error": f"{type(e).__name__}: {e}",
                    "count": 0, "detections": [],
                })
        return out

    # ────────────────────────── 내부 ──────────────────────────

    def _warmup(self):
        dummy = np.zeros((self.imgsz, self.imgsz, 3), dtype=np.uint8)
        t0 = time.perf_counter()
        self.model.predict(dummy, imgsz=self.imgsz, device=self.device,
                           verbose=False)
        logger.info("워밍업 %.0fms", (time.perf_counter() - t0) * 1000)

    @staticmethod
    def _load_image(source) -> np.ndarray:
        """무엇이 들어와도 numpy BGR uint8 로"""
        # ① numpy 배열
        if isinstance(source, np.ndarray):
            img = source
        # ② bytes / bytearray
        elif isinstance(source, (bytes, bytearray)):
            arr = np.frombuffer(source, dtype=np.uint8)
            img = cv2.imdecode(arr, cv2.IMREAD_COLOR)
            if img is None:
                raise ValueError("bytes 를 이미지로 디코딩할 수 없습니다")
        # ③ 파일 경로
        elif isinstance(source, (str, Path)):
            p = Path(source)
            if not p.exists():
                raise FileNotFoundError(f"이미지 파일이 없습니다: {p}")
            # ★ 한글 경로 대응 — cv2.imread 는 비ASCII 경로에서 실패
            arr = np.fromfile(str(p), dtype=np.uint8)
            img = cv2.imdecode(arr, cv2.IMREAD_COLOR)
            if img is None:
                raise ValueError(f"이미지로 읽을 수 없습니다: {p}")
        # ④ PIL
        elif hasattr(source, "convert"):
            img = cv2.cvtColor(np.array(source.convert("RGB")),
                               cv2.COLOR_RGB2BGR)
        else:
            raise TypeError(f"지원하지 않는 입력 형식: {type(source).__name__}")

        # ── 형식 통일 ──
        if img.dtype != np.uint8:
            img = np.clip(img, 0, 255).astype(np.uint8)
        if img.ndim == 2:                                # 그레이스케일
            img = cv2.cvtColor(img, cv2.COLOR_GRAY2BGR)
        elif img.ndim == 3 and img.shape[2] == 4:        # RGBA
            img = cv2.cvtColor(img, cv2.COLOR_BGRA2BGR)
        elif img.ndim != 3 or img.shape[2] != 3:
            raise ValueError(f"이미지 shape 이 올바르지 않습니다: {img.shape}")
        if img.size == 0 or min(img.shape[:2]) < 2:
            raise ValueError(f"이미지가 너무 작습니다: {img.shape}")
        return img

    def _to_records(self, result, w: int, h: int) -> list[dict]:
        out = []
        for b in result.boxes:
            cid = int(b.cls)
            x1, y1, x2, y2 = (float(v) for v in b.xyxy[0].tolist())
            cx, cy, bw, bh = (float(v) for v in b.xywhn[0].tolist())
            pw, ph = x2 - x1, y2 - y1
            out.append({
                "class_id": cid,
                "class": self.model.names[cid],
                "conf": round(float(b.conf), 4),
                "box": {"x1": round(x1, 1), "y1": round(y1, 1),
                        "x2": round(x2, 1), "y2": round(y2, 1)},
                "box_norm": {"cx": round(cx, 6), "cy": round(cy, 6),
                             "w": round(bw, 6), "h": round(bh, 6)},
                "size": {"w": round(pw, 1), "h": round(ph, 1),
                         "area_ratio": round(pw * ph / (w * h) * 100, 3)},
            })
        out.sort(key=lambda d: -d["conf"])               # ★ 신뢰도 순
        return out
```

### Step 2. 그리기 유틸 — 추론과 분리

```python
    # ────────────────────────── 그리기 ──────────────────────────

    def draw(self, image, response, colors=None, thickness=2,
             font_scale=0.5, show_conf=True, show_label=True,
             fill_alpha=0.0, min_conf=None) -> np.ndarray:
        """박스를 그린 ★ 새 이미지를 반환 (원본 수정 안 함)"""
        img = self._load_image(image).copy()
        colors = colors or DEFAULT_COLORS
        h, w = img.shape[:2]

        # 응답의 이미지 크기와 다르면 좌표를 스케일링
        rw = response.get("image", {}).get("width", w)
        rh = response.get("image", {}).get("height", h)
        sx, sy = w / rw, h / rh

        overlay = img.copy() if fill_alpha > 0 else None

        for d in response.get("detections", []):
            if min_conf is not None and d["conf"] < min_conf:
                continue
            color = colors[d["class_id"] % len(colors)]
            b = d["box"]
            x1 = int(round(b["x1"] * sx)); y1 = int(round(b["y1"] * sy))
            x2 = int(round(b["x2"] * sx)); y2 = int(round(b["y2"] * sy))

            if overlay is not None:
                cv2.rectangle(overlay, (x1, y1), (x2, y2), color, -1)
            cv2.rectangle(img, (x1, y1), (x2, y2), color, thickness)

            if show_label:
                text = d["class"]
                if show_conf:
                    text += f" {d['conf']:.2f}"
                self._put_label(img, text, x1, y1, color, font_scale, thickness)

        if overlay is not None:
            img = cv2.addWeighted(overlay, fill_alpha, img, 1 - fill_alpha, 0)
        return img

    @staticmethod
    def _put_label(img, text, x, y, color, scale=0.5, thickness=1):
        """박스 위에 라벨 — 화면 밖으로 나가지 않게"""
        font = cv2.FONT_HERSHEY_SIMPLEX
        (tw, th), base = cv2.getTextSize(text, font, scale, thickness)
        ty = y - 5 if y - th - 8 >= 0 else y + th + 8
        h, w = img.shape[:2]
        x = max(0, min(x, w - tw - 8))
        cv2.rectangle(img, (x, ty - th - 4), (x + tw + 6, ty + base - 2),
                      color, -1)
        cv2.putText(img, text, (x + 3, ty), font, scale,
                    (255, 255, 255), thickness, cv2.LINE_AA)

    def to_yolo_txt(self, response) -> str:
        """응답을 YOLO 라벨 형식 문자열로 (의사 라벨용)"""
        lines = []
        for d in response.get("detections", []):
            n = d["box_norm"]
            lines.append(f"{d['class_id']} {n['cx']:.6f} {n['cy']:.6f} "
                         f"{n['w']:.6f} {n['h']:.6f}")
        return "\n".join(lines) + ("\n" if lines else "")

    def summary(self, response) -> str:
        """'2 persons, 1 box (145ms)' 같은 한 줄 요약"""
        if not response.get("count"):
            return f"검출 없음 ({response.get('timing_ms', {}).get('total', 0):.0f}ms)"
        parts = [f"{v} {k}" for k, v in
                 sorted(response["counts_by_class"].items(), key=lambda x: -x[1])]
        return (", ".join(parts) +
                f" ({response['timing_ms']['total']:.0f}ms)")
```

```python
# ────────────────────────── 모듈 수준 ──────────────────────────

_INSTANCE: Detector | None = None


def get_detector(weights=None, config=None, **kw) -> Detector:
    """앱 전체에서 하나의 인스턴스를 공유한다.

    · weights 를 주면 그것을 사용
    · config(yaml) 를 주면 거기서 읽음
    · 둘 다 없으면 기본 설정 파일
    """
    global _INSTANCE
    if _INSTANCE is not None:
        return _INSTANCE

    if weights is None:
        import yaml
        root = Path(__file__).resolve().parents[1]
        cfg_path = Path(config) if config else root / "configs/inference.yaml"
        cfg = yaml.safe_load(Path(cfg_path).read_text(encoding="utf-8"))
        weights = root / cfg["weights"]
        kw = {**cfg.get("inference", {}), **kw}

    _INSTANCE = Detector(weights, **kw)
    return _INSTANCE


def reset_detector():
    """테스트용 — 인스턴스 해제"""
    global _INSTANCE
    _INSTANCE = None
```

```python
        if args.save:
            out = Path(args.save)
            out.mkdir(parents=True, exist_ok=True)
            cv2.imwrite(str(out / f.name), det.draw(f, res))

                                               encoding="utf-8")

            json.dumps(results, indent=2, ensure_ascii=False), encoding="utf-8")
        print(f"\nJSON 저장: {args.json}")

    total = sum(r.get("count", 0) for r in results)
    ok = sum(1 for r in results if "error" not in r)
    print(f"\n{ok}/{len(files)}장 처리 · 검출 {total}건")


if __name__ == "__main__":
```

```python
"""detector.py — 최소 수정본"""
from __future__ import annotations

import logging
import time
from pathlib import Path

import cv2
import numpy as np

logger = logging.getLogger(__name__)


class Detector:
    def __init__(self, weights, conf=0.25, iou=0.7, imgsz=None,
                 device=None, warmup=True):
        weights = Path(weights)
        if not weights.exists():                              # ★ 2
            raise FileNotFoundError(f"가중치 파일이 없습니다: {weights}")

        from ultralytics import YOLO
        self.model = YOLO(str(weights))
        self.weights = weights
        self.conf, self.iou, self.device = conf, iou, device   # ★ 13
        self.imgsz = imgsz or 640

        if warmup:                                             # ★ 14
            self.model.predict(
                np.zeros((self.imgsz, self.imgsz, 3), np.uint8),
                imgsz=self.imgsz, verbose=False)

    @staticmethod
    def _load(source) -> np.ndarray:                          # ★ 3, 4
        if isinstance(source, np.ndarray):
            img = source
        elif isinstance(source, (bytes, bytearray)):
            img = cv2.imdecode(np.frombuffer(source, np.uint8),
                               cv2.IMREAD_COLOR)
        else:
            p = Path(source)
            if not p.exists():
                raise FileNotFoundError(f"이미지 파일이 없습니다: {p}")
            img = cv2.imdecode(np.fromfile(str(p), np.uint8),   # ★ 한글 경로
                               cv2.IMREAD_COLOR)
        if img is None:
            raise ValueError(f"이미지로 읽을 수 없습니다: {source}")
        if img.ndim == 2:
            img = cv2.cvtColor(img, cv2.COLOR_GRAY2BGR)
        elif img.shape[2] == 4:
            img = cv2.cvtColor(img, cv2.COLOR_BGRA2BGR)
        return img

    def predict(self, source, conf=None, iou=None) -> dict:
        t0 = time.perf_counter()
        img = self._load(source)
        h, w = img.shape[:2]                                   # ★ 10

        r = self.model.predict(                                # ★ 7, 8
            img, conf=conf or self.conf, iou=iou or self.iou,
            imgsz=self.imgsz, device=self.device, verbose=False)[0]

        dets = []
        for b in r.boxes:
            cid = int(b.cls)                                   # ★ 5
            x1, y1, x2, y2 = (float(v) for v in b.xyxy[0].tolist())
            cx, cy, bw, bh = (float(v) for v in b.xywhn[0].tolist())
            dets.append({
                "class_id": cid,
                "class": self.model.names[cid],                # ★ 이름
                "conf": round(float(b.conf), 4),
                "box": {"x1": round(x1, 1), "y1": round(y1, 1),
                        "x2": round(x2, 1), "y2": round(y2, 1)},
                "box_norm": {"cx": round(cx, 6), "cy": round(cy, 6),
                             "w": round(bw, 6), "h": round(bh, 6)},
            })
        dets.sort(key=lambda d: -d["conf"])

        counts = {}
        for d in dets:
            counts[d["class"]] = counts.get(d["class"], 0) + 1

        return {                                               # ★ 11
            "version": "1.0",
            "image": {"width": w, "height": h},
            "timing_ms": {"total": round((time.perf_counter()-t0)*1000, 2)},
            "count": len(dets), "counts_by_class": counts,
            "detections": dets,
        }

    def draw(self, image, response, thickness=2) -> np.ndarray:  # ★ 6
        img = self._load(image).copy()                          # ★ 원본 보호
        h, w = img.shape[:2]
        sx = w / response["image"]["width"]
        sy = h / response["image"]["height"]
        for d in response["detections"]:
            b = d["box"]
            x1 = int(round(b["x1"] * sx)); y1 = int(round(b["y1"] * sy))  # ★ 9
            x2 = int(round(b["x2"] * sx)); y2 = int(round(b["y2"] * sy))
            cv2.rectangle(img, (x1, y1), (x2, y2), (0, 200, 60), thickness)
            cv2.putText(img, f"{d['class']} {d['conf']:.2f}",
                        (x1 + 3, max(y1 - 6, 16)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 200, 60), 2)
        return img
```

```python
"""app.py — Flask 검출 서버"""
import logging
import uuid
from pathlib import Path

from flask import Flask, jsonify, request
from werkzeug.utils import secure_filename

from detector import get_detector

app = Flask(__name__)
app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024      # ★ 16MB 제한

ALLOWED = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}
UPLOAD = Path("uploads")
UPLOAD.mkdir(exist_ok=True)

logging.basicConfig(level=logging.INFO)

# ★ 앱 시작 시 1회 로드 + 워밍업
detector = get_detector()
app.logger.info("모델 준비 완료: %s", detector.weights.name)


@app.route("/health")
def health():
    return jsonify({
        "status": "ok",
        "model": detector.weights.name,
        "classes": detector.class_names,
    })


@app.route("/detect", methods=["POST"])
def detect():
    # ── ① 요청 검증 ──
    if "image" not in request.files:
        return jsonify({"error": "필드 'image' 가 없습니다"}), 400

    f = request.files["image"]
    if not f or not f.filename:
        return jsonify({"error": "파일이 비어 있습니다"}), 400

    ext = Path(secure_filename(f.filename)).suffix.lower()
    if ext not in ALLOWED:
        return jsonify({
            "error": f"지원하지 않는 형식: {ext}",
            "allowed": sorted(ALLOWED),
        }), 400

    # ── ② 파라미터 (선택) ──
    try:
        conf = request.form.get("conf", type=float)
        iou = request.form.get("iou", type=float)
    except (TypeError, ValueError):
        return jsonify({"error": "conf/iou 는 숫자여야 합니다"}), 400

    if conf is not None and not (0 < conf < 1):
        return jsonify({"error": "conf 는 0~1 사이여야 합니다"}), 400

    # ── ③ ★ 메모리에서 바로 처리 (디스크 안 씀) ──
    try:
        data = f.read()
        result = detector.predict(data, conf=conf, iou=iou)
    except ValueError as e:
        app.logger.warning("잘못된 이미지: %s", e)
        return jsonify({"error": f"이미지를 처리할 수 없습니다: {e}"}), 400
    except Exception as e:                                    # ★ 그 외
        app.logger.exception("검출 실패")
        return jsonify({"error": "서버 내부 오류"}), 500       # ★ 상세 노출 안 함

    result["request_id"] = uuid.uuid4().hex[:12]              # ★ 추적용
    return jsonify(result)


@app.route("/detect/image", methods=["POST"])
def detect_image():
    """박스가 그려진 이미지를 반환"""
    import cv2
    from flask import send_file
    import io

    if "image" not in request.files:
        return jsonify({"error": "필드 'image' 가 없습니다"}), 400

    try:
        data = request.files["image"].read()
        result = detector.predict(data)
        img = detector.draw(data, result)
        ok, buf = cv2.imencode(".jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 90])
        if not ok:
            raise RuntimeError("인코딩 실패")
        return send_file(io.BytesIO(buf.tobytes()), mimetype="image/jpeg")
    except ValueError as e:
        return jsonify({"error": str(e)}), 400
    except Exception:
        app.logger.exception("이미지 생성 실패")
        return jsonify({"error": "서버 내부 오류"}), 500


@app.errorhandler(413)
def too_large(e):
    return jsonify({"error": "파일이 너무 큽니다 (최대 16MB)"}), 413


if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, threaded=True)
```

```python
def get_detector(profile=None, **kw):
    """profile: 'pc' | 'pi' | 'server' | None(자동)"""
    if profile is None:
        profile = detect_profile()          # ★ 자동 감지

def detect_profile() -> str:
    """실행 환경 자동 감지"""
    import platform
    import torch

    machine = platform.machine().lower()
    if machine in ("aarch64", "armv7l", "armv6l"):
        return "pi"                          # ★ ARM = 라즈베리파이
    if torch.cuda.is_available():
        return "pc"
    return "cpu"
```

```python
def _resolve_weights(self, weights):
    """형식에 따라 적절한 로딩"""
    p = Path(weights)

    # NCNN 은 폴더 또는 .param
    if p.suffix == ".param" or (p.is_dir() and (p / "model.ncnn.param").exists()):
        logger.info("NCNN 모델 로드")
        return str(p)
    if p.suffix == ".onnx":
        logger.info("ONNX 모델 로드")
        return str(p)
    if p.suffix in (".pt", ".engine", ".tflite"):
        return str(p)

    raise ValueError(f"지원하지 않는 가중치 형식: {p.suffix}")
```

```python
class VideoDetector:
    """영상 전용 래퍼 — 프레임 스킵과 결과 유지"""

    def __init__(self, detector, skip=1, keep_last=True):
        self.det = detector
        self.skip = max(1, skip)
        self.keep_last = keep_last
        self._i = 0
        self._last = None

    def process(self, frame) -> dict:
        """스킵 구간에서는 ★ 직전 결과를 재사용"""
        self._i += 1
        if self._i % self.skip != 0 and self._last is not None and self.keep_last:
            out = dict(self._last)
            out["cached"] = True             # ★ 캐시된 결과임을 표시
            return out
        self._last = self.det.predict(frame)
        self._last["cached"] = False
        return self._last
```

```python
def load_profile(name=None, config=None):
    import yaml
    root = Path(__file__).resolve().parents[1]
    cfg = yaml.safe_load(
        (Path(config) if config else root / "configs/inference.yaml")
        .read_text(encoding="utf-8"))

    if name in (None, "auto"):
        name = cfg.get("default_profile", "auto")
    if name == "auto":
        name = detect_profile()

    profiles = cfg["profiles"]
    if name not in profiles:
        raise KeyError(f"프로파일 '{name}' 없음. 가능: {list(profiles)}")

    p = dict(profiles[name])
    p["weights"] = root / p["weights"]
    p["_profile"] = name
    logger.info("프로파일 '%s' 로드 — %s (imgsz=%d, device=%s)",
                name, Path(p["weights"]).name, p["imgsz"], p["device"])
    return p
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| 파이프라인 5단계 | 입력 → 전처리 → 추론 → 후처리 → 출력 |
| 책임 분리 | `_load_image` · `predict` · `_to_records` · **`draw`** |
| ★ 모델 로드 | **한 번만.** 매번 로드하면 9.5배 느림 |
| 워밍업 | 첫 추론 2.4초 → **시작할 때 미리** |
| 싱글턴 | `get_detector()` — 앱 전체에서 하나 |
| 반환 형식 | ★ **JSON 직렬화 가능** (`float()` `int()`) |
| 필수 필드 | version · image · timing · count · **counts_by_class** |
| 좌표 | **VOC 픽셀 + 정규화** 둘 다 제공 |
| ★ `draw` | **원본 수정 금지** · 좌표 스케일링 지원 |
| 입력 지원 | 경로 · str · **numpy** · bytes · PIL |
| ★ 한글 경로 | `np.fromfile` + `cv2.imdecode` |
| 그레이·RGBA | **자동 변환** |
| ★ 검출 0개 | **정상.** 예외 아님 |
| 배치 | ★ **개별 실패 격리** |
| 예외 처리 | 로그 남기고 **다시 던짐** |

| 경로 | `Path(__file__).parents[N]` 기준 |
| 환경 대응 | ★ **프로파일** (pc/cpu/pi/server) |

| 교차 검증 | ★ 다른 팀 모듈로 인터페이스 확인 |

**오늘 반드시 기억할 세 가지**
> ① **모델은 한 번만 로드하세요.** 요청마다 로드하면 9.5배 느리고 메모리가 터집니다.
> ② **`float()` `int()` 로 감싸세요.** torch 텐서를 그대로 반환하면 Flask에서 JSON 오류가 납니다.
> ③ **`draw()` 는 원본을 수정하면 안 됩니다.** 스트리밍에서 박스가 누적됩니다.
