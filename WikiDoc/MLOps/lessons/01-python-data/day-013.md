## ③ 개념 설명

### 모듈과 패키지

| 용어 | 뜻 |
|---|---|
| **모듈(module)** | 파이썬 파일 하나 (`todo.py`) |
| **패키지(package)** | 모듈을 담은 폴더 (`todoapp/`) |
| **`__init__.py`** | "이 폴더는 패키지입니다"라는 표시 파일 |

```
todoapp/                  ← 패키지
├── __init__.py
├── models.py             ← 모듈
├── storage.py            ← 모듈
└── cli.py                ← 모듈
```

### import 하는 여러 방법

```python
import math                        # 모듈 전체
math.sqrt(16)

from math import sqrt              # 특정 이름만
sqrt(16)

from math import sqrt, pi          # 여러 개
import numpy as np                 # 별명 붙이기
from math import *                 # ❌ 전부 — 쓰지 마세요
```

> **`from x import *` 를 금지하는 이유** — 어떤 이름이 어디서 왔는지 알 수 없어집니다.
> 두 모듈이 같은 이름을 가지면 조용히 덮어씁니다.

### 절대 import vs 상대 import

```python
# 절대 import — 패키지 루트부터 전체 경로
from todoapp.models import Todo

# 상대 import — 현재 위치 기준
from .models import Todo           # 같은 폴더
from ..core import config          # 한 단계 위
```

**절대 import를 기본으로 쓰세요.** 파일을 옮겨도 덜 깨지고, 읽는 사람이 위치를 즉시 압니다.
상대 import는 패키지 내부에서 짧게 쓰고 싶을 때만 제한적으로 씁니다.

### 파이썬이 모듈을 찾는 순서

```python
import mymodule
```

파이썬은 `sys.path` 목록을 **순서대로** 뒤집니다.

```python
import sys
for p in sys.path:
    print(p)
```

```
                                          ← 1. 실행한 스크립트가 있는 폴더 (빈 문자열)
C:\Python312\python312.zip
C:\Python312\Lib
C:\workspace\mlops\venv\Lib\site-packages ← 4. 설치된 패키지들
```

**첫 번째가 현재 폴더**라는 것이 중요합니다. 그래서 이런 사고가 납니다.

```
내 폴더에 random.py 를 만들면
→ import random 이 표준 라이브러리 대신 내 파일을 가져옴
→ AttributeError: module 'random' has no attribute 'randint'
```

**표준 라이브러리·설치 패키지와 같은 이름의 파일을 만들지 마세요.**
(`random.py`, `json.py`, `csv.py`, `email.py`, `test.py` 등)

### `__name__` 과 `if __name__ == "__main__":`

모든 파이썬 파일에는 `__name__` 이라는 변수가 자동으로 들어 있습니다.

| 실행 방법 | `__name__` 값 |
|---|---|
| `python todo.py` 로 **직접 실행** | `"__main__"` |
| 다른 파일에서 `import todo` | `"todo"` (모듈 이름) |

그래서 이렇게 쓰면:

```python
def main():
    ...

if __name__ == "__main__":
    main()
```

| 상황 | 결과 |
|---|---|
| `python todo.py` | `__name__` 이 `"__main__"` → `main()` 실행 ✅ |
| `from todo import add_todo` | `__name__` 이 `"todo"` → `main()` **실행 안 됨** ✅ |

**어제까지의 문제가 이 한 줄로 해결됩니다.**

> 관용적으로 **"if 네임 이즈 메인"** 이라고 읽습니다. 파이썬 코드에서 가장 자주 보게 되는 관용구입니다.

### `python -m` 실행

```bash
$ python todo.py           # 파일을 직접 실행
$ python -m todoapp.cli    # 모듈로 실행
```

**`-m` 을 쓰면 패키지 경로 문제가 사라집니다.**
`python todoapp/cli.py` 로 실행하면 `sys.path[0]` 이 `todoapp/` 이 되어 `from todoapp.models import ...` 가 깨집니다.
`-m` 은 현재 폴더를 기준으로 잡아 줍니다.

패키지에 `__main__.py` 를 두면 더 짧아집니다.

```bash
$ python -m todoapp        # todoapp/__main__.py 실행
```

### src 레이아웃

두 가지 프로젝트 구조가 있습니다.

```
# flat 레이아웃                    # src 레이아웃 ← 권장
myproject/                        myproject/
├── todoapp/                      ├── src/
│   └── models.py                 │   └── todoapp/
├── tests/                        │       └── models.py
└── pyproject.toml                ├── tests/
                                  └── pyproject.toml
```

**왜 `src/` 를 한 겹 더 두는가?**

flat 레이아웃에서는 프로젝트 루트에서 `python` 을 실행하면 `todoapp/` 이 현재 폴더에 있어서
**설치하지 않아도 import가 됩니다.** 언뜻 편해 보이지만 함정이 있습니다.

| 상황 | flat | src |
|---|---|---|
| 로컬에서 테스트 | 폴더가 보여서 통과 | **설치해야 통과** |
| 패키징 후 배포 | 파일이 빠져도 모름 | 빠지면 즉시 발견 |
| 결과 | **"내 PC에선 되는데" 사고** | 설치본 기준으로 검증됨 |

**src 레이아웃은 "설치된 상태로만 테스트하도록" 강제**합니다.
W24에서 Docker 이미지를 만들 때 이 차이가 결정적입니다.

### `pyproject.toml`

프로젝트의 신분증입니다. 이름·버전·의존성·CLI 진입점을 적습니다.

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "todoapp"
version = "0.1.0"
description = "할 일 관리 CLI"
requires-python = ">=3.10"
dependencies = [
    "requests>=2.31",
]

[project.scripts]
todo = "todoapp.cli:main"          # 터미널에서 todo 명령으로 실행

[tool.setuptools.packages.find]
where = ["src"]
```

`[project.scripts]` 가 핵심입니다. 설치하면 터미널에서 이렇게 쓸 수 있습니다.

```bash
$ todo add "장보기"
```

`todoapp.cli` 모듈의 `main` 함수를 부르는 실행 파일이 자동으로 만들어집니다.

### `pip install -e .` — 편집 가능 설치

```bash
$ pip install -e .
```

| | 일반 설치 (`pip install .`) | 편집 가능 설치 (`-e`) |
|---|---|---|
| 동작 | 파일을 복사해 넣음 | **원본을 가리키는 링크**를 만듦 |
| 코드 수정 시 | 다시 설치해야 반영 | **즉시 반영** |
| 용도 | 배포·운영 | **개발 중** |

개발할 때는 항상 `-e` 를 씁니다.

### 순환 참조 (circular import)

두 모듈이 서로를 import하면 생깁니다.

```python
# models.py
from storage import save        # storage를 가져옴

# storage.py
from models import Todo         # models를 가져옴  ← 순환!
```

```
ImportError: cannot import name 'Todo' from partially initialized module 'models'
(most likely due to a circular import)
```

**왜 생기나** — `models.py` 를 읽다가 `storage.py` 로 가고, 거기서 다시 `models.py` 를 찾는데
`models.py` 는 아직 다 읽히지 않은 상태입니다.

**해결 방법 세 가지**

| 방법 | 설명 | 권장도 |
|---|---|---|
| **의존 방향 정리** | 한쪽만 참조하게 구조를 바꿈 | ⭐⭐⭐ |
| 함수 안에서 import | 실행 시점으로 미룸 | ⭐⭐ (임시방편) |
| 공통 부분을 3번째 모듈로 | 양쪽이 그것만 참조 | ⭐⭐⭐ |

**근본 해결은 첫 번째입니다.** 순환 참조는 대개 **설계가 잘못됐다는 신호**입니다.

```
❌ models ⇄ storage           ✅ cli → storage → models
```

**의존은 한 방향으로 흘러야 합니다.** 아래층(models)은 위층(storage)을 몰라야 합니다.

### Step 1. `__name__` 확인하기

`name_demo.py` 를 만듭니다.

```python
print(f"name_demo.py 의 __name__ = {__name__!r}")

    print("  → 직접 실행되었습니다. main 로직을 실행합니다.")

print("--- import 완료 ---")

### Step 3. 순환 참조 재현하고 해결

`circular/` 폴더를 만들고 실험합니다.

`circular/models.py`:

```python
print("models.py 로딩 시작")
from storage import save_all         # ← 순환의 시작


class Todo:
    def __init__(self, title):
        self.title = title

    def save(self):
        save_all([self])


print("models.py 로딩 끝")
```

`circular/storage.py`:

```python
print("storage.py 로딩 시작")
from models import Todo              # ← 순환!


def save_all(todos):
    for t in todos:
        print(f"저장: {t.title}")


def load_all():
    return [Todo("복원된 항목")]


print("storage.py 로딩 끝")
```

`circular/main.py`:

```python
from models import Todo

Todo("테스트").save()
```

실행:

```powershell
$ python circular/main.py
models.py 로딩 시작
storage.py 로딩 시작
Traceback (most recent call last):
  File "circular/main.py", line 1, in <module>
    from models import Todo
  File "circular\models.py", line 2, in <module>
    from storage import save_all
  File "circular\storage.py", line 2, in <module>
    from models import Todo
ImportError: cannot import name 'Todo' from partially initialized module 'models'
(most likely due to a circular import)
```

**로딩 순서를 보세요.** `models` 를 읽다가 `storage` 로 갔고, 거기서 다시 `models` 를 찾는데
`models` 는 아직 `class Todo` 줄까지 못 갔습니다.

**해결 — 의존 방향을 한쪽으로 정리합니다.**

`circular/models.py` (수정):

```python
print("models.py 로딩 시작")
# storage 를 import 하지 않습니다 — 아래층은 위층을 몰라야 합니다


class Todo:
    def __init__(self, title):
        self.title = title


print("models.py 로딩 끝")
```

`circular/storage.py` (그대로):

```python
print("storage.py 로딩 시작")
from models import Todo


def save_all(todos):
    for t in todos:
        print(f"저장: {t.title}")


def load_all():
    return [Todo("복원된 항목")]


print("storage.py 로딩 끝")
```

`circular/main.py` (수정):

```python
from models import Todo
from storage import save_all, load_all

save_all([Todo("테스트")])
print(load_all()[0].title)
```

실행:

```powershell
$ python circular/main.py
models.py 로딩 시작
models.py 로딩 끝
storage.py 로딩 시작
storage.py 로딩 끝
저장: 테스트
복원된 항목
```

> **의존 방향**
> ```
> main  →  storage  →  models
> ```
> 화살표가 한 방향으로만 흐릅니다. `models` 는 자기가 어떻게 저장되는지 **몰라야** 합니다.
> 이 원칙을 지키면 나중에 저장을 JSON에서 DB로 바꿔도 `models` 는 안 바뀝니다 (W09).

### Step 4. 패키지로 재구성

이제 `todo.py` 한 파일을 패키지로 나눕니다. **새 폴더**를 만듭니다.

```
todo-cli/
├── src/
│   └── todoapp/
│       ├── __init__.py
│       ├── models.py         ← Todo 클래스
│       ├── storage.py        ← JSON 저장/불러오기
│       ├── service.py        ← TodoList (로직)
│       ├── cli.py            ← 화면·메뉴
│       └── __main__.py       ← python -m todoapp
├── tests/
├── pyproject.toml
├── README.md
└── .gitignore
```

폴더를 만듭니다.

```powershell

$ cd todo-cli
```

**`src/todoapp/models.py`** — 데이터 (아무것도 import하지 않음)

```python
"""할 일 데이터 모델."""

from dataclasses import dataclass, field, asdict
from datetime import datetime

PRIORITIES = ("높음", "보통", "낮음")


class TodoError(Exception):
    """이 패키지의 기본 예외."""


class ValidationError(TodoError):
    """데이터 검증 실패."""


class NotFoundError(TodoError):
    """항목을 찾지 못함."""


@dataclass(order=True)
class Todo:
    """할 일 하나."""

    id: int
    title: str
    priority: str = "보통"
    tags: list = field(default_factory=list)
    done: bool = False
    created_at: str = field(default_factory=lambda: datetime.now().strftime("%Y-%m-%d %H:%M"))
    completed_at: str | None = None

    def __post_init__(self):
        self.title = self.title.strip()
        if not self.title:
            raise ValidationError("제목은 비워 둘 수 없습니다.")
        if self.priority not in PRIORITIES:
            raise ValidationError(
                f"우선순위는 {' / '.join(PRIORITIES)} 중 하나여야 합니다: {self.priority!r}"
            )
        self.tags = sorted({t.strip() for t in self.tags if t.strip()})

    def complete(self):
        if not self.done:
            self.done = True
            self.completed_at = datetime.now().strftime("%Y-%m-%d %H:%M")
        return self

    def reopen(self):
        self.done = False
        self.completed_at = None
        return self

    def toggle(self):
        return self.reopen() if self.done else self.complete()

    def matches(self, keyword):
        keyword = keyword.strip().lower()
        if not keyword:
            return False
        return keyword in self.title.lower() or any(keyword in t.lower() for t in self.tags)

    def to_dict(self):
        return asdict(self)

    @classmethod
    def from_dict(cls, data):
        return cls(**data)
```

```python
"""JSON 파일 저장·복원."""

import json
from pathlib import Path

from todoapp.models import Todo, ValidationError

DEFAULT_PATH = Path("todos.json")


def save(todos, path=DEFAULT_PATH):
    """할 일 목록을 JSON으로 저장합니다.

    Returns:
        (성공 여부, 에러 메시지 또는 None)
    """
    path = Path(path)
    try:
        path.write_text(
            json.dumps([t.to_dict() for t in todos], ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        return True, None
    except OSError as e:
        return False, f"저장 실패: {e}"


def load(path=DEFAULT_PATH):
    """JSON에서 할 일 목록을 복원합니다.

    Returns:
        (할 일 리스트, 경고 메시지 또는 None)
    """
    path = Path(path)
    if not path.exists():
        return [], None

    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as e:
        return [], f"파일이 손상되었습니다 ({e}). 빈 목록으로 시작합니다."
    except OSError as e:
        return [], f"파일을 읽지 못했습니다 ({e}). 빈 목록으로 시작합니다."

    if not isinstance(data, list):
        return [], "파일 형식이 올바르지 않습니다. 빈 목록으로 시작합니다."

    todos, dropped = [], 0
    for raw in data:
        try:
            todos.append(Todo.from_dict(raw))
        except (TypeError, KeyError, ValidationError):
            dropped += 1

    warning = f"형식이 맞지 않는 항목 {dropped}건을 건너뛰었습니다." if dropped else None
    return todos, warning
```

**`src/todoapp/service.py`** — 로직 (models만 import)

```python
"""할 일 목록 관리 로직."""

from todoapp.models import Todo, NotFoundError


class TodoList:
    """할 일 목록. 파일 입출력과 화면 출력을 하지 않습니다."""

    def __init__(self, items=None):
        self.items = list(items or [])

    def __len__(self):
        return len(self.items)

    def __iter__(self):
        return iter(self.items)

    def next_id(self):
        return max((t.id for t in self.items), default=0) + 1

    def find(self, todo_id):
        for t in self.items:
            if t.id == todo_id:
                return t
        return None

    def get(self, todo_id):
        """찾지 못하면 NotFoundError."""
        todo = self.find(todo_id)
        if todo is None:
            raise NotFoundError(f"{todo_id}번 할 일이 없습니다.")
        return todo

    def add(self, title, priority="보통", tags=None):
        todo = Todo(self.next_id(), title, priority, tags or [])
        self.items.append(todo)
        return todo

    def remove(self, todo_id):
        todo = self.get(todo_id)
        self.items.remove(todo)
        return todo

    def toggle(self, todo_id):
        return self.get(todo_id).toggle()

    def filter(self, status="all"):
        if status == "todo":
            return [t for t in self.items if not t.done]
        if status == "done":
            return [t for t in self.items if t.done]
        return list(self.items)

    def search(self, keyword):
        return [t for t in self.items if t.matches(keyword)]

    def all_tags(self):
        tags = set()
        for t in self.items:
            tags.update(t.tags)
        return tags

    def stats(self):
        total = len(self.items)
        done = sum(1 for t in self.items if t.done)
        by_priority, by_tag = {}, {}
        for t in self.items:
            by_priority[t.priority] = by_priority.get(t.priority, 0) + 1
            for tag in t.tags:
                by_tag[tag] = by_tag.get(tag, 0) + 1
        return {
            "total": total,
            "done": done,
            "todo": total - done,
            "rate": done / total if total else 0.0,
            "by_priority": by_priority,
            "by_tag": by_tag,
        }

    def __repr__(self):
        s = self.stats()
        return f"TodoList(total={s['total']}, done={s['done']})"
```

"""명령행 인터페이스."""

from todoapp.models import PRIORITIES, TodoError
from todoapp.service import TodoList
from todoapp import storage

MARK = {True: "✔", False: " "}
PRIORITY_MARK = {"높음": "!!", "보통": "! ", "낮음": "  "}


def format_todo(t):
    tags = ", ".join(t.tags) if t.tags else "-"
    return (f"  {t.id:>3} [{MARK[t.done]}] {PRIORITY_MARK[t.priority]} "
            f"{t.title:<22}{tags:<18}{t.created_at}")


def show_todos(todos, label="목록"):
    print(f"\n[{label}] {len(todos)}건")
    if not todos:
        print("  항목이 없습니다.")
        return
    for t in todos:
        print(format_todo(t))


def show_stats(todo_list):
    s = todo_list.stats()
    print("\n[통계]")
    if s["total"] == 0:
        print("  등록된 할 일이 없습니다.")
        return
    filled = int(s["rate"] * 20)
    print(f"  전체 {s['total']}건 · 완료 {s['done']}건 · 미완료 {s['todo']}건")
    print(f"  진행률 {'■' * filled}{'□' * (20 - filled)} {s['rate']:.1%}")
    print("\n  [우선순위별]")
    for p in PRIORITIES:
        c = s["by_priority"].get(p, 0)
        print(f"    {p:<5}{c:>3}건 {'■' * c}")


def show_menu():
    print()
    print("=" * 52)
    print("                할 일 관리 CLI")
    print("=" * 52)
    print(" 1. 추가    2. 목록    3. 완료 토글    4. 삭제")
    print(" 5. 검색    6. 통계    0. 저장하고 종료")
    print("-" * 52)


def input_int(prompt):
    raw = input(prompt).strip()
    if not raw:
        return None
    try:
        return int(raw)
    except ValueError:
        print(f"  → '{raw}' 는 숫자가 아닙니다.")
        return None


def main():
    """CLI 진입점."""
    items, warning = storage.load()
    if warning:
        print(f"⚠ {warning}")
    todos = TodoList(items)
    print(f"할 일 {len(todos)}건을 불러왔습니다.")

    while True:
        show_menu()
        choice = input("선택 > ").strip()

        if choice == "0":
            ok, error = storage.save(todos)
            print(f"{len(todos)}건 저장 완료." if ok else f"⚠ {error}")
            break

        elif choice == "1":
            title = input("  제목: ")
            priority = input(f"  우선순위 ({' / '.join(PRIORITIES)}) [엔터=보통]: ").strip() or "보통"
            tags = [t for t in input("  태그 (쉼표 구분): ").split(",")]
            try:
                todo = todos.add(title, priority, tags)
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos)
            print(f"  ✓ {todo.id}번 등록됨")

        elif choice == "2":
            f = input("  1=전체 2=미완료 3=완료 [엔터=전체]: ").strip()
            status = {"2": "todo", "3": "done"}.get(f, "all")
            show_todos(todos.filter(status), {"todo": "미완료", "done": "완료"}.get(status, "전체"))

        elif choice == "3":
            show_todos(todos.filter("todo"), "미완료")
            todo_id = input_int("\n  토글할 ID: ")
            if todo_id is None:
                continue
            try:
                t = todos.toggle(todo_id)
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos)
            print(f"  ✓ {t.id}번 → {'완료' if t.done else '미완료'}")

        elif choice == "4":
            show_todos(todos.filter())
            todo_id = input_int("\n  삭제할 ID: ")
            if todo_id is None:
                continue
            try:
                t = todos.remove(todo_id)
            except TodoError as e:
                print(f"  ✗ {e}")
                continue
            storage.save(todos)
            print(f"  ✓ '{t.title}' 삭제됨")

        elif choice == "5":
            tags = todos.all_tags()
            if tags:
                print(f"\n  사용 중인 태그: {', '.join(sorted(tags))}")
            keyword = input("  검색어: ")
            show_todos(todos.search(keyword), f"'{keyword.strip()}' 검색 결과")

        elif choice == "6":
            show_stats(todos)

        else:
            print("  0에서 6 사이의 숫자를 입력하세요.")


if __name__ == "__main__":
    main()

"""모듈 간 의존 방향을 확인합니다."""

import ast
from pathlib import Path

SRC = Path("src/todoapp")

print("--- 각 모듈이 import 하는 것 ---")
graph = {}
for py in sorted(SRC.glob("*.py")):
    tree = ast.parse(py.read_text(encoding="utf-8"))
    deps = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.ImportFrom) and node.module and node.module.startswith("todoapp"):
            deps.add(node.module.split(".")[-1])
        elif isinstance(node, ast.Import):
            for alias in node.names:
                if alias.name.startswith("todoapp"):
                    deps.add(alias.name.split(".")[-1])
    deps.discard(py.stem)
    graph[py.stem] = sorted(deps)
    print(f"  {py.stem:<12} → {', '.join(sorted(deps)) or '(없음)'}")

print("\n--- 순환 참조 검사 ---")
found = False
for mod, deps in graph.items():
    for dep in deps:
        if mod in graph.get(dep, []):
            print(f"  ⚠ 순환: {mod} ⇄ {dep}")
            found = True
if not found:
    print("  ✓ 순환 참조 없음")
```

실행 결과:

```
--- 각 모듈이 import 하는 것 ---
  __init__     → models, service
  __main__     → cli
  cli          → models, service, storage, todoapp
  models       → (없음)
  service      → models
  storage      → models

--- 순환 참조 검사 ---
  ✓ 순환 참조 없음
```

**의존 그래프**

```
        __main__
           │
          cli
        ╱  │  ╲
 service   │   storage
        ╲  │  ╱
        models          ← 아무것도 의존하지 않음
```

> **`models` 가 맨 아래에서 아무것도 import하지 않는 것**이 핵심입니다.
> 화살표가 위에서 아래로만 흐릅니다. 이 구조가 W19 [Day 093](../04-deep-learning-serving/day-093.md)의
> `router → service → repository` 계층으로 그대로 이어집니다.

### `__init__.py` 를 빼먹음

파이썬 3.3+ 는 `__init__.py` 없이도 동작하지만(네임스페이스 패키지),
**패키징 도구가 폴더를 못 찾는 경우**가 있습니다. **넣으세요.** 빈 파일이어도 됩니다.

---

## ⑥ 확인 문제

**1.** `if __name__ == "__main__":` 이 없으면 어떤 일이 생기나요? 구체적인 시나리오로 설명하세요.

<details>
<summary>답 보기</summary>

**import하는 순간 프로그램이 실행됩니다.**

```python
# todo.py 맨 아래
main()          # if 없이 그냥
```

```python
# test_todo.py
from todo import add_todo       # ← 이 줄에서 CLI가 켜지고 입력을 기다림
```

**구체적 피해**

| 상황 | 결과 |
|---|---|
| 테스트 작성 | pytest가 import하는 순간 CLI가 켜져 **테스트가 멈춤** |
| 라이브러리로 재사용 | 함수 하나 빌리려는데 프로그램 전체가 실행됨 |
| 문서 생성 도구 | import해서 docstring을 읽으려다 프로그램 실행 |
| 다른 모듈에서 import | 의도치 않은 부수효과 |

**원리**

`__name__` 은 파이썬이 자동으로 넣어 주는 변수입니다.

| 실행 방법 | `__name__` |
|---|---|
| `python todo.py` | `"__main__"` |
| `import todo` | `"todo"` |

`if __name__ == "__main__":` 은 **"직접 실행됐을 때만"** 이라는 뜻입니다.

**실무 관례** — 모든 실행 가능한 스크립트는 이렇게 씁니다.

```python
def main():
    ...

if __name__ == "__main__":
    main()
```

W14의 학습 스크립트, W19의 서버 실행 스크립트, W27의 Airflow DAG까지 전부 이 형태입니다.
</details>

**2.** flat 레이아웃 대신 src 레이아웃을 쓰는 이유는 무엇인가요? "내 PC에선 되는데" 문제와 어떤 관계가 있나요?

<details>
<summary>답 보기</summary>

**src 레이아웃은 "설치된 상태로만 테스트하도록" 강제합니다.**

**flat 레이아웃의 함정**

```
myproject/
├── todoapp/          ← 현재 폴더에 그냥 보임
└── tests/
```

프로젝트 루트에서 `python` 을 실행하면 `sys.path[0]` 이 현재 폴더입니다.
그래서 **설치하지 않아도** `import todoapp` 이 됩니다.

문제는 **"현재 폴더에 있는 파일"과 "패키지에 실제로 포함된 파일"이 다를 수 있다는 것**입니다.

| 사고 시나리오 | flat | src |
|---|---|---|
| `pyproject.toml` 에서 서브패키지를 빠뜨림 | 로컬 테스트 **통과** | 설치 후 import 실패로 **즉시 발견** |
| `.gitignore` 로 데이터 파일이 제외됨 | 로컬엔 있어서 통과 | 설치본엔 없어서 발견 |
| `__init__.py` 누락 | 3.3+ 는 동작해서 통과 | 패키징에서 발견 |

**결과: Docker 이미지를 만든 뒤에야 터집니다.**

```dockerfile
COPY . /app
RUN pip install .
CMD ["todo"]
```

```
$ docker run myimage
ModuleNotFoundError: No module named 'todoapp.utils'
```

로컬에서는 3주 동안 잘 돌던 코드가 컨테이너에서 처음 실패합니다.
디버깅이 훨씬 어렵습니다 (로그가 컨테이너 안에 있으니까요).

**src 레이아웃에서는 이런 일이 없습니다.**

```
myproject/
├── src/
│   └── todoapp/      ← 현재 폴더에서 안 보임
└── tests/
```

`pip install -e .` 를 안 하면 `import todoapp` 이 **바로 실패**합니다.
그러니 개발 첫날부터 설치본 기준으로 개발하게 되고, **로컬 = CI = 컨테이너**가 됩니다.

이것이 W24–W26에서 여러분을 구할 결정입니다.
"CI가 로컬에선 되는데 Actions에서 깨져요"의 주요 원인 하나가 여기서 사라집니다.
</details>

**3.** 아래 구조에서 `models.py` 가 `storage.py` 를 import하면 왜 문제인가요? 설계 원칙으로 설명하세요.

```
cli.py  →  service.py  →  models.py
           storage.py  →  models.py
```

<details>
<summary>답 보기</summary>

**① 순환 참조가 발생합니다**

`storage → models` 이미 있는데 `models → storage` 를 추가하면 서로를 참조합니다.

```
ImportError: cannot import name 'Todo' from partially initialized module 'todoapp.models'
```

**② 계층 원칙을 깹니다**

의존은 **한 방향으로만** 흘러야 합니다.

```
     위층 (구체적·바뀌기 쉬움)
        cli
         ↓
   service / storage
         ↓
       models
     아래층 (추상적·안정적)
```

`models` 는 **자기가 어떻게 저장되는지 몰라야** 합니다.

**③ 실질적 피해 — 저장 방식을 못 바꿉니다**

이 과정에서 저장 방식은 계속 바뀝니다.

| 시점 | 저장 |
|---|---|
| Day 013 | JSON 파일 |
| W07 | PostgreSQL |
| W20 | API 응답 |
| W27 | DVC로 버전 관리 |

`models` 가 `storage` 를 모르면, 저장 방식을 바꿔도 `models.py` 는 **한 줄도 안 바뀝니다.**
반대로 의존하면 DB로 바꿀 때 `models` 까지 고쳐야 하고, `models` 를 쓰는 모든 곳이 영향을 받습니다.

**④ 테스트가 어려워집니다**

`models` 를 테스트하는데 파일 시스템이 필요해집니다.

```python
def test_todo_validation():
    Todo(1, "")          # 이것만 확인하고 싶은데
                         # models가 storage를 import하면 파일 관련 준비도 필요
```

**해결 — 의존성 역전**

`models` 가 저장을 호출해야 한다면, **직접 import하지 말고 받아서** 씁니다.

```python
# ❌
class Todo:
    def save(self):
        from todoapp.storage import write     # models가 storage를 앎
        write(self)

# ✅ — 저장은 위층이 담당
todo = todos.add("장보기")
storage.save(todos)                            # cli가 조율
```

**"아래층은 위층을 모른다"** — 이 한 문장이 오늘의 핵심입니다.

같은 원칙이 계속 나옵니다.
- [Day 043](../02-sql-pipeline/day-043.md) — Transform은 DB를 모른다
- [Day 063](../03-machine-learning/day-063.md) — Pipeline은 파일을 모른다
- [Day 093](../04-deep-learning-serving/day-093.md) — service는 HTTP를 모른다
</details>

## 오늘의 정리

| 항목 | 내용 |
|---|---|
| 모듈 / 패키지 | 파일 하나 / 폴더 + `__init__.py` |
| import | 절대 `from todoapp.models import Todo` 우선 · `import *` 금지 |
| 검색 순서 | `sys.path` — **현재 폴더가 맨 앞** (이름 충돌 주의) |
| `__name__` | 직접 실행 `"__main__"` · import 시 모듈 이름 |
| 관용구 | `if __name__ == "__main__": main()` |
| 모듈 실행 | `python -m 패키지.모듈` · `__main__.py` 로 `python -m 패키지` |
| src 레이아웃 | `src/패키지/` — **설치 안 하면 import 안 됨 = 안전** |
| 설정 | `pyproject.toml` — `[project]` · `[project.scripts]` · `packages.find` |
| 개발 설치 | `pip install -e .` — 수정이 즉시 반영 |
| 순환 참조 | 의존을 **한 방향**으로 · 아래층은 위층을 모른다 |
| 계층 | `cli → service/storage → models` |

③ `pip install -e .` 후 `library` 명령으로 실행되는 것 확인
