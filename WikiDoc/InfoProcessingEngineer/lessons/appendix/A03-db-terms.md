# A3 · DB 핵심 용어 비교표

## 1. 릴레이션 용어

| 일상 | 관계형 모델 | 파일 시스템 |
|---|---|---|
| 표 | 릴레이션 | 파일 |
| 행 | 튜플 | 레코드 |
| 열 | 속성 | 필드 |

- **차수** = 열 수 / **카디널리티** = 행 수 / **도메인** = 속성 값의 범위

## 2. 키 5종 (슈퍼 ⊇ 후보 ⊇ 기본)

| 키 | 조건 |
|---|---|
| 슈퍼키 | 유일성만 |
| 후보키 | 유일성 + 최소성 |
| 기본키 | 후보키 중 선정 — NULL·중복 불가 |
| 대체키 | 기본키가 못 된 후보키 |
| 외래키 | 남의 기본키 참조 — **NULL 가능** |

## 3. 무결성 3종

| 무결성 | 규칙 | 위반 시 에러 예 |
|---|---|---|
| 개체 | 기본키 NULL·중복 불가 | UNIQUE constraint failed |
| 참조 | 외래키는 부모에 있는 값 또는 NULL | FOREIGN KEY constraint failed |
| 도메인 | 자료형·범위 내 값 | CHECK constraint failed |

## 4. 혼동 페어 모음

| 페어 | 구분 |
|---|---|
| WHERE vs HAVING | 그룹화 **전 행** vs 그룹화 **후 그룹** (WHERE에 집계 함수 불가) |
| COUNT(*) vs COUNT(열) | NULL **포함** vs **제외** |
| DELETE vs TRUNCATE vs DROP | DML·조건·복구 가능 / DDL·전체·복구 불가 / 구조째 삭제 |
| UNION vs UNION ALL | 중복 제거 vs 유지 |
| IN vs EXISTS | 값이 목록에 있는가 vs 조건 맞는 행이 존재하는가 (상관 서브쿼리) |
| INNER vs OUTER JOIN | 짝 있는 행만 vs 기준 쪽 전원(+NULL) |
| GRANT vs REVOKE | 부여(`TO`) vs 회수(`FROM`) |
| COMMIT vs ROLLBACK | 확정(취소 불가) vs 마지막 COMMIT으로 복귀 |
| 인덱스 vs 뷰 | 검색용 자료구조(갱신 비용↑) vs 가상 테이블(저장 없음, ALTER 불가) |
| 스키마 vs 인스턴스 | 구조(틀) vs 특정 시점의 실제 데이터 |
| = NULL vs IS NULL | 항상 거짓(0행) vs 올바른 NULL 판정 |

## 5. 트랜잭션 ACID

| 성질 | 한 줄 |
|---|---|
| 원자성 (Atomicity) | 전부 실행 또는 전부 취소 |
| 일관성 (Consistency) | 실행 전후 모순 없는 상태 |
| 고립성 (Isolation) | 중간 결과에 다른 트랜잭션 접근 불가 |
| 지속성 (Durability) | COMMIT 결과는 영구 보존 |

## 6. 이상현상·정규화 (도부이결다조)

| 정규형 | 조건 | 판정 열쇠말 |
|---|---|---|
| 1NF | 원자값 (**도**메인) | 한 칸에 값 여러 개 → 위반 |
| 2NF | **부**분 함수 종속 제거 | 복합키의 **일부**가 결정 |
| 3NF | **이**행 함수 종속 제거 | A→B→C **징검다리** |
| BCNF | **결**정자가 모두 후보키 | |
| 4NF/5NF | **다**치 / **조**인 종속 | (이름만 — 저빈출) |

- 이상현상 3종: 삽입·갱신·삭제 이상 — 정규화의 이유

## 7. 관계대수

| 기호 | 이름 | 역할 | SQL 대응 |
|---|---|---|---|
| σ | 셀렉트 | **행** 선택 | **WHERE** |
| π | 프로젝트 | **열** 추출 | **SELECT 절** |
| ⋈ | 조인 | 결합 | JOIN |
| ÷ | 디비전 | "모두 가진" 튜플 | — |
| ∪ ∩ − × | 합·교·차·곱 | 집합 | UNION 등 |

⚠️ σ ≠ SQL의 SELECT 절 — σ는 WHERE, π가 SELECT 절.
