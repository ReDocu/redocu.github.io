## 1. 단원 개요

**이 단원을 마치면**

- [ ] 연산자·조건문·반복문이 섞인 15줄 내외 코드를 세 언어 모두 **추적표로 계산할 수 있다**
- [ ] 배열·문자열 인덱싱과 순회 코드의 출력을 **예측할 수 있다**
- [ ] C의 포인터·배열 관계, 함수 호출(값 전달/주소 전달)을 **해석할 수 있다**
- [ ] Java의 상속·오버라이딩·예외 처리 코드의 실행 순서를 **설명할 수 있다**
- [ ] Python의 자료형(리스트·튜플·딕셔너리·집합)·슬라이싱·함수 코드를 **읽을 수 있다**
- [ ] 언어별 문법 차이로 생기는 대표 오답 포인트를 **구분할 수 있다**

**왜 2주인가** — 코드 문제는 기출 복원 기준 실기 배점의 절반 안팎을 차지하는 최대 영역입니다(비공식 경향 — [로드맵 5-2절](README.md) 참고). 또한 3단원 SQL 학습 중에도, 5단원 실전 기간에도 코드 문제 훈련이 누적 복습으로 계속 이어지므로, '집중 학습 2주 + 이후 5주 반복'으로 설계했습니다. 공통 문법(W02)을 세 언어 동시 비교로 배우고, 언어별 고유 개념(W03)을 분리한 것은 혼합반에서 비전공자의 인지 부담을 낮추기 위함입니다.

**주차 구성**

| 주차 | 강 | 주제 |
|---|---|---|
| W02 | 03–04강 | 세 언어 공통 문법 — 연산자·조건문 / 반복문·배열·문자열 |
| W03 | 05–06강 | 언어별 빈출 심화 — C 포인터·함수 / Java 객체지향 + Python 심화 |

**선행 지식** — [01단원](01-foundation.md): 변수·자료형·출력문·정수/실수 나눗셈.

## 5. 이 단원에서 자주 나오는 질문

| 질문 | 답 |
|---|---|
| 직접 코드를 짜는 문제도 나오나요? | 실기는 필답형이라 긴 코드를 처음부터 작성하는 문제보다 결과 예측·빈칸·오류 찾기 유형이 중심입니다. 그래서 이 단원도 '읽기와 추적' 훈련에 집중합니다. |

| 재귀 함수 문제는 어떻게 준비하나요? | 호출 트리를 그리는 정형 절차를 05강에서 배웁니다. 재귀는 감이 아니라 절차로 푸는 유형입니다. |
