```
발견: 왜도 0.98

  ↓
실험: 변환 전후를 같은 조건에서 비교
  ↓

```

### EDA는 그림 그리기가 아닙니다

많은 사람이 EDA를 이렇게 합니다.

```python
df.hist(figsize=(15, 10))
sns.heatmap(df.corr())
sns.pairplot(df)
# "EDA 완료!"
```

**그림 30개를 그리고 아무 결정도 안 했다면 EDA를 한 것이 아닙니다.**

**EDA의 산출물은 그림이 아니라 "발견 목록"과 "그래서 할 일"입니다.**

| 발견 | 그래서 할 일 |
|---|---|
| 타깃 왜도 0.98 | 로그 변환 실험 → [오늘](day-111.md) |
| AveRooms 최대 141.9 | 이상치 처리 → [Day 112](day-112.md) |

| 위도↔경도 상관 -0.92 | 다중공선성 확인 → [오늘](day-111.md) |

### 회귀 EDA는 분류와 순서가 다릅니다

| | 분류 EDA | 회귀 EDA |
|---|---|---|
| 첫 번째로 보는 것 | **클래스 불균형** | **타깃 분포와 왜도** |
| 특성-타깃 관계 | 클래스별 특성 분포 | **산점도와 상관계수** |
| 문제 신호 | 90:10 불균형 | **오른쪽 꼬리** · 상한 절단 · 0 집중 |
| 대표적 조치 | class_weight, 오버샘플링 | **로그 변환** |

> **"타깃부터 본다"는 회귀 EDA의 제1 원칙입니다.**
> 타깃 분포를 안 보고 특성부터 보는 것은, 목적지를 모르고 지도를 펴는 것과 같습니다.

```
[로그 변환]     신경망 val MAE 0.3204     ← 12% 개선
```

**모델을 하나도 안 바꿨습니다.** 전처리만 바꿨습니다.

## ③ 개념 설명

### 타깃 분포 — 무엇을 보는가

```python
y.describe()
```

| 항목 | 확인할 것 |
|---|---|
| `count` | 결측이 있는가 |
| `mean` vs `50%` | **평균 > 중앙값이면 오른쪽 꼬리** |
| `min` | **0이나 음수가 있는가** (로그 변환 시 중요) |
| `max` | **상한에 몰려 있는가** (절단) |
| `std` | 변동 폭. MAE와 비교할 기준 |

**추가로 반드시 볼 것**

```python
(y == 0).sum()          # 0의 개수
(y < 0).sum()           # 음수 개수
y.value_counts().head() # 특정 값에 몰려 있는가
y.skew()                # 왜도
```

### 왜도 (skewness)

**분포가 한쪽으로 치우친 정도입니다.**

```
왜도 = 0            왜도 > 0 (오른쪽 꼬리)      왜도 < 0 (왼쪽 꼬리)
    ╱▔╲                 ╱▔╲___                    ___╱▔╲
   ╱   ╲               ╱      ▔▔▔──            ──▔▔      ╲
  대칭                평균 > 중앙값              평균 < 중앙값
```

| 왜도 | 판단 | 조치 |
|---|---|---|
| \|왜도\| < 0.5 | 거의 대칭 | 변환 불필요 |
| 0.5 ~ 1.0 | 중간 정도 치우침 | **변환 검토** |
| 1.0 ~ 2.0 | 뚜렷하게 치우침 | **변환 권장** |
| > 2.0 | 심함 | **변환 거의 필수** |

**가격 데이터는 거의 항상 오른쪽 꼬리입니다.**

```
게임 가격:  9,900원이 수천 개  ...  500,000원이 몇 개
집값:       평범한 집이 대부분  ...  대저택이 소수
연봉:       대부분 평범        ...  극소수가 매우 높음
```

**이유** — 가격에는 **하한(0)은 있지만 상한이 없기** 때문입니다.

### 왜 왜도가 문제인가

| 문제 | 설명 |
|---|---|
| **MSE가 큰 값에 끌림** | [Day 106](day-106.md)에서 본 것. 소수의 고가 샘플이 지배 |
| **오차의 의미가 구간마다 다름** | 1만 원짜리의 3천 원 오차와 50만 원짜리의 3천 원 오차 |
| 신경망 학습이 불안정 | 출력 범위가 넓으면 기울기가 들쭉날쭉 |
| **잔차가 부채꼴로 벌어짐** | 이분산성 ([Day 118](day-118.md)) |

**두 번째가 실무적으로 가장 중요합니다.**

```
게임 A: 실제 10,000원  예측 13,000원   오차 3,000원 (30%)   ← 크게 틀림
게임 B: 실제 500,000원 예측 503,000원  오차 3,000원 (0.6%)  ← 거의 정확
```

**MAE는 둘을 똑같이 셉니다.** 그런데 사용자에게는 전혀 다른 경험입니다.

### 로그 변환 — `log1p` 와 `expm1`

```python
import numpy as np

y_log = np.log1p(y)          # log(1 + y)
y_back = np.expm1(y_log)     # exp(y) - 1     ★ 정확히 되돌아감
```

**왜 `log` 가 아니라 `log1p` 인가**

```python
np.log(0)        # -inf    ← 0이 있으면 망함
np.log1p(0)      # 0.0     ← 안전
```

**가격 데이터에는 0이 흔합니다.** (무료 게임, 100% 할인)
**`log1p` 를 기본으로 쓰세요.**

**변환의 효과**

```
원래 값:    100    1,000    10,000    100,000    500,000
log1p:     4.6     6.9      9.2       11.5       13.1
           └─ 간격이 균등해집니다 ─┘
```

**큰 값들이 압축되고, 작은 값들이 펼쳐집니다.**

### 로그 변환의 숨은 의미 — 상대 오차를 최소화합니다

```
log(예측) - log(실제) = log(예측 / 실제)
```

**로그 공간에서의 차이 = 원래 공간에서의 비율입니다.**

| 실제 | 예측 | 절대 오차 | 비율 | 로그 공간 오차 |
|---|---|---|---|---|
| 10,000 | 13,000 | 3,000 | 1.30 | 0.262 |
| 500,000 | 503,000 | 3,000 | 1.006 | 0.006 |

**로그 공간에서 학습하면 "몇 % 틀렸는가"를 최소화합니다.**
가격 예측에서는 대개 이쪽이 사용자 경험과 맞습니다.

> **이것이 로그 변환의 진짜 이유입니다.** "분포를 예쁘게 만든다"가 아닙니다.
> **"오차를 절대값이 아니라 비율로 보겠다"** 는 의사결정입니다.

### ⚠️ 로그 변환의 함정 — 되돌릴 때 편향이 생깁니다

```python
pred_log = model.predict(X)          # 로그 공간의 예측
pred = np.expm1(pred_log)            # 되돌림
```

**이 예측은 원래 공간에서 체계적으로 낮습니다.**

```
로그 공간에서 평균을 맞추면
원래 공간에서는 중앙값(median)을 맞춘 것이 됩니다
     ↓
오른쪽 꼬리 분포에서 중앙값 < 평균
     ↓
과소 예측
```

**보정 방법 (Duan's smearing estimator)**

```python
resid_log = y_train_log - model.predict(X_train)
smear = np.mean(np.exp(resid_log))          # 보정 계수

pred = np.expm1(pred_log) * smear           # 보정 적용
```

> **실무에서는 보정 없이 쓰는 경우도 많습니다.**
> **MAE로 평가한다면 중앙값을 맞추는 것이 오히려 유리**하기 때문입니다.
> 다만 **"평균을 맞춰야 하는" 문제(총매출 예측 등)에서는 반드시 보정하세요.**

### 다른 변환들

| 변환 | 코드 | 언제 |
|---|---|---|
| **log1p** | `np.log1p(y)` | 오른쪽 꼬리. **0 이상** |
| 제곱근 | `np.sqrt(y)` | 약한 치우침. 카운트 데이터 |
| **Box-Cox** | `PowerTransformer(method="box-cox")` | 최적 λ 자동 탐색. **양수만** |
| **Yeo-Johnson** | `PowerTransformer(method="yeo-johnson")` | Box-Cox의 확장. **음수 허용** |
| 역수 | `1 / y` | 극단적 치우침 (드묾) |

```python
from sklearn.preprocessing import PowerTransformer

pt = PowerTransformer(method="yeo-johnson")
y_trans = pt.fit_transform(y.values.reshape(-1, 1)).ravel()
y_back = pt.inverse_transform(y_trans.reshape(-1, 1)).ravel()
```

> **`log1p` 로 시작하세요.** 해석이 쉽고, 되돌리기가 정확하고, 실패가 적습니다.
> Box-Cox/Yeo-Johnson은 λ를 추정하므로 **학습셋으로만 fit** 해야 합니다. ([Day 115](day-115.md))

### 상관계수

```python
df.corr()                          # 피어슨 (선형 관계)
df.corr(method="spearman")         # 스피어만 (순위 = 단조 관계)
```

| | 피어슨 | 스피어만 |
|---|---|---|
| 측정 | **직선** 관계 | **단조** 관계 (증가/감소) |
| 이상치 | 민감 | **강함** |
| 비선형 | 못 잡음 | 단조라면 잡음 |

**두 개를 함께 보세요.**

```
피어슨 0.2, 스피어만 0.7  →  단조인데 비선형. 로그 변환 검토
피어슨 0.7, 스피어만 0.3  →  이상치 몇 개가 상관을 만들고 있음
```

**상관계수가 0이어도 관계가 있을 수 있습니다.**

```
y = x²  (x가 -5~5)
피어슨 상관 ≈ 0        ← 직선 관계가 없어서
그런데 완벽한 관계     ← 산점도를 보면 명확
```

> **상관계수만 보고 특성을 버리면 안 됩니다.** 반드시 **산점도를 함께** 보세요.

### 상관 ≠ 인과

| 사례 | 상관 | 실제 |
|---|---|---|
| 아이스크림 판매 ↔ 익사 사고 | 높음 | **둘 다 여름 때문** (교란 변수) |
| 소방관 수 ↔ 화재 피해액 | 높음 | **큰 화재일수록 둘 다 증가** (역인과) |
| 신발 크기 ↔ 독해력 | 높음 | **나이** (아동 대상 조사 시) |

**모델에는 상관만 있으면 충분합니다.** 예측이 목적이니까요.

**하지만 이렇게 말하면 안 됩니다.**

```
✗ "리뷰 수를 늘리면 가격이 올라갑니다"
✓ "리뷰 수가 많은 게임은 가격이 높은 경향이 있습니다"
```

> **[Day 134](day-134.md) 보고서에서 이 구분이 채점 기준에 들어갑니다.**

### 다중공선성 (multicollinearity)

**특성끼리 강하게 상관된 상태입니다.**

```
Latitude ↔ Longitude : -0.925    (캘리포니아가 대각선으로 길어서)
AveRooms ↔ AveBedrms : +0.848
```

**무엇이 문제인가**

| 모델 | 영향 |
|---|---|
| **선형 회귀** | **계수가 불안정.** 부호가 뒤집히기도 함 |
| 릿지 | **완화됨** (L2 규제가 계수를 나눠 가짐) |
| 라쏘 | 상관 특성 중 **하나만 남김** |
| 트리 | **영향 거의 없음** (중요도가 나뉠 뿐) |
| 신경망 | 영향 작음 |

**예측 성능에는 대개 문제가 없습니다. 해석이 망가집니다.**

**VIF (분산 팽창 계수)로 진단**

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor

vif = [variance_inflation_factor(X.values, i) for i in range(X.shape[1])]
```

| VIF | 판단 |
|---|---|
| 1 | 상관 없음 |
| 1~5 | 보통 |
| **5~10** | **주의** |
| **> 10** | **심각** |

> **VIF가 높다고 무조건 특성을 버리면 안 됩니다.**
> 예측이 목적이면 그냥 둬도 됩니다. **해석이 목적일 때만 처리하세요.**

### 범주형 특성 — 타깃 평균 비교

```python
df.groupby("장르")["가격"].agg(["count", "mean", "median", "std"])
```

**보는 법**

| 확인 | 판단 |
|---|---|
| 범주 간 평균 차이가 큰가 | **크면 유용한 특성** |
| 각 범주의 표본 수 | **10건 미만은 신뢰 불가** |
| 표준편차 | 범주 안에서도 편차가 크면 설명력이 약함 |

```
장르       count    mean     std
──────────────────────────────────
전략         412  28,400   9,200      ← 표본 충분, 평균 높음
RPG          388  31,200   8,800
캐주얼      1,204  12,100   5,400      ← 뚜렷이 낮음. 유용
VR             7  45,000  22,000      ← ★ 표본 7건. 못 믿음
```

> **표본이 적은 범주를 "기타"로 묶는 것**이 [Day 113](day-113.md)의 주제입니다.

## ④ 단계별 실습

### Step 1. 타깃부터 — 한 셀로 끝내는 요약

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_california_housing

SEED = 42
np.random.seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
y = df[TARGET]


def target_report(y, name="target"):
    """회귀 EDA의 첫 셀 — 타깃 요약"""
    print("=" * 70)
    print(f"타깃 '{name}' 요약")
    print("=" * 70)
    print(f"{'개수':<16}{len(y):>14,}")
    print(f"{'결측':<16}{y.isna().sum():>14,}")
    print(f"{'0의 개수':<16}{(y == 0).sum():>14,}  ({(y==0).mean()*100:.2f}%)")
    print(f"{'음수 개수':<16}{(y < 0).sum():>14,}")
    print("-" * 70)
    print(f"{'최소':<16}{y.min():>14.4f}")
    print(f"{'25%':<16}{y.quantile(.25):>14.4f}")
    print(f"{'중앙값':<16}{y.median():>14.4f}")
    print(f"{'평균':<16}{y.mean():>14.4f}   ← 평균 > 중앙값 = 오른쪽 꼬리"
```

```python
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

SEED = 42

X_all = df.drop(columns=[TARGET])

    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)


def score_original_space(y_true, pred):
    """★ 평가는 항상 원래 공간에서. 로그 공간 지표는 비교 불가"""
    return {
        "MAE": round(mean_absolute_error(y_true, pred), 4),
        "RMSE": round(float(np.sqrt(mean_squared_error(y_true, pred))), 4),
        "R²": round(r2_score(y_true, pred), 4),
        "MAPE(%)": round(float(np.mean(np.abs((y_true - pred) / y_true)) * 100), 2),
    }


def run(model_name, make_model, use_log, smearing=False):
    if use_log:
        y_fit = np.log1p(y_train)
    else:
        y_fit = y_train

    if model_name.startswith("신경망"):
        sc = StandardScaler().fit(X_train)
        tf.random.set_seed(SEED)
        m = keras.Sequential([
            layers.Input(shape=(X_train.shape[1],)),
            layers.Dense(128, activation="relu"),
            layers.Dense(64, activation="relu"),
            layers.Dense(1),
        ])
        m.compile(optimizer=keras.optimizers.Adam(1e-3), loss="mse", metrics=["mae"])
        es = keras.callbacks.EarlyStopping(monitor="val_loss", patience=20,
                                           restore_best_weights=True)
        y_val_fit = np.log1p(y_val) if use_log else y_val
        m.fit(sc.transform(X_train), y_fit,
              validation_data=(sc.transform(X_val), y_val_fit),
              epochs=300, batch_size=64, callbacks=[es], verbose=0)
        pred_raw = m.predict(sc.transform(X_val), verbose=0).ravel()
        train_pred_raw = m.predict(sc.transform(X_train), verbose=0).ravel()
    else:
        m = make_model()
        m.fit(X_train, y_fit)
        pred_raw = m.predict(X_val)
        train_pred_raw = m.predict(X_train)

    if use_log:
        pred = np.expm1(pred_raw)
        if smearing:
            smear = float(np.mean(np.exp(np.log1p(y_train) - train_pred_raw)))
            pred = pred * smear
        else:
            smear = 1.0
    else:
        pred = pred_raw
        smear = None

    r = {"모델": model_name,
         "타깃변환": "log1p" + ("+보정" if smearing else "") if use_log else "없음"}
    r.update(score_original_space(y_val, pred))
    r["편향"] = round(float((pred - y_val).mean()), 4)
    if smear is not None:
        r["보정계수"] = round(smear, 4)
    return r


configs = [
    ("릿지",   lambda: make_pipeline(StandardScaler(), RidgeCV(alphas=np.logspace(-3, 3, 30)))),
    ("HistGB", lambda: HistGradientBoostingRegressor(max_iter=300, random_state=SEED)),
    ("신경망",  None),
]

    rows.append(run(name, maker, use_log=True, smearing=True))
```

### Step 5. 다중공선성 진단

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.preprocessing import StandardScaler


def compute_vif(X):
    """VIF = 1 / (1 - R²), R²는 해당 특성을 나머지로 예측했을 때"""
    Xs = StandardScaler().fit_transform(X)
    vifs = []
    for i in range(Xs.shape[1]):
        others = np.delete(Xs, i, axis=1)
        r2 = LinearRegression().fit(others, Xs[:, i]).score(others, Xs[:, i])
        vifs.append(1 / (1 - r2) if r2 < 1 else np.inf)
    return pd.Series(vifs, index=X.columns)


vif = compute_vif(X_train).sort_values(ascending=False)

    bar = "█" * min(int(v), 30)
```

### Step 6. 범주형 특성 — 구간화해서 타깃 평균 비교

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# ── California Housing에는 범주형이 없으므로 만들어 봅니다 ──
work = df.copy()
work["소득구간"] = pd.qcut(work["MedInc"], q=5,
                        labels=["최하위", "하위", "중간", "상위", "최상위"])
work["연식구간"] = pd.cut(work["HouseAge"], bins=[0, 10, 20, 30, 40, 55],
                       labels=["10년미만", "10-20년", "20-30년", "30-40년", "40년이상"])
work["지역"] = np.where(work["Latitude"] > 37.5, "북부",
                      np.where(work["Latitude"] > 35, "중부", "남부"))


def categorical_report(df, cat_col, target_col, min_count=30):
    """범주형 특성이 타깃을 설명하는가"""
    g = df.groupby(cat_col, observed=True)[target_col].agg(
        건수="size", 평균="mean", 중앙값="median", 표준편차="std",
        최소="min", 최대="max").round(4)
    overall = df[target_col].mean()
    g["전체대비"] = (g["평균"] / overall).round(3)
    g["신뢰"] = np.where(g["건수"] < min_count, "★ 표본부족", "")

    print("=" * 88)
    print(f"'{cat_col}' 별 '{target_col}' — 전체 평균 {overall:.4f}")
    print("=" * 88)
    print(g.to_string())
    print("-" * 88)

    spread = g["평균"].max() - g["평균"].min()
    ratio = g["평균"].max() / g["평균"].min()
    # 그룹 간 분산 / 전체 분산 = 설명력 (eta squared 근사)
    grand = df[target_col].mean()
    ss_between = (g["건수"] * (g["평균"] - grand) ** 2).sum()
    ss_total = ((df[target_col] - grand) ** 2).sum()
    eta2 = ss_between / ss_total

    print(f"범주 간 평균 차이   : {spread:.4f}  (최고/최저 비율 {ratio:.2f}배)")
    print(f"설명력 (η²)        : {eta2:.4f}  "
          f"← {'유용한 특성' if eta2 > 0.05 else '설명력 약함'}")
    print("=" * 88)
    return g, eta2


results = {}
for c in ["소득구간", "연식구간", "지역"]:
    g, eta2 = categorical_report(work, c, TARGET)
    results[c] = eta2
    print()

print("=" * 60)
print("범주형 특성 유용성 순위")
print("=" * 60)
for c, e in sorted(results.items(), key=lambda x: -x[1]):
    bar = "█" * int(e * 60)
    print(f"  {c:<10} η² {e:.4f}  {bar}")
print("=" * 60)

# ── 그래프 ──
fig, axes = plt.subplots(1, 3, figsize=(18, 5))
for ax, c in zip(axes, ["소득구간", "연식구간", "지역"]):
    data = [work[work[c] == cat][TARGET].values
            for cat in work[c].cat.categories if hasattr(work[c], "cat")] \
        if hasattr(work[c], "cat") else \
        [work[work[c] == cat][TARGET].values for cat in sorted(work[c].unique())]
    labels = list(work[c].cat.categories) if hasattr(work[c], "cat") else sorted(work[c].unique())
    ax.boxplot(data, labels=labels, showfliers=False)
    ax.axhline(work[TARGET].mean(), color="red", linestyle="--", label="overall mean")
    ax.set_ylabel(TARGET)
    ax.set_title(f"{c} (η²={results[c]:.4f})")
    ax.tick_params(axis="x", rotation=30)
    ax.legend(fontsize=8)
fig.tight_layout()
plt.show()
```

## ⑤ 자주 하는 실수

### `log` 를 쓰다가 `-inf` 를 만듦

```python
np.log(y)          # y에 0이 있으면 -inf
```

```
RuntimeWarning: divide by zero encountered in log
```

**해결** — `np.log1p(y)`. 그리고 되돌릴 때는 `np.expm1()`.

```python
np.log1p(0)        # 0.0    ✓
np.expm1(0)        # 0.0    ✓ 정확히 되돌아감
```

### `log1p` 로 변환하고 `exp` 로 되돌림

```python
y_log = np.log1p(y)
y_back = np.exp(y_log)        # ✗ 전부 1씩 큽니다
y_back = np.expm1(y_log)      # ✓
```

**증상** — 예측값이 전부 1(또는 타깃 단위로 1)만큼 큽니다. 미묘해서 놓치기 쉽습니다.

### 음수가 있는데 로그 변환

```python
np.log1p(-3)       # nan
```

**해결** — `PowerTransformer(method="yeo-johnson")` 또는 값을 이동시킨 뒤 로그.

```python
shift = -y.min() + 1
np.log(y + shift)      # 되돌릴 때 shift를 빼는 것을 잊지 말 것
```

### 로그 공간 지표를 원래 공간 지표와 비교

```python
# 모델 A: 원래 공간 학습 → MAE 0.36
# 모델 B: 로그 공간 학습 → MAE 0.18
# "B가 2배 좋다!"
```

**틀렸습니다.** B의 0.18은 **로그 공간의 MAE**입니다. 단위가 다릅니다.

```python
pred = np.expm1(model.predict(X))        # ★ 되돌린 뒤
mae = mean_absolute_error(y_val, pred)   # ★ 원래 공간에서 계산
```

> **평가는 항상 원래 공간에서.** 이것이 로그 변환에서 가장 흔한 실수입니다.

### 타깃만 변환하고 되돌리는 것을 잊음

```python
model.fit(X_train, np.log1p(y_train))
pred = model.predict(X_test)              # ✗ 로그 공간 값

```

**오류 5개**

| # | 코드 | 문제 |

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import train_test_split

SEED = 42

# ★ 수정 6: 3분할
X_dev, X_test, y_dev, y_test = train_test_split(X, y, test_size=0.2, random_state=SEED)
X_train, X_val, y_train, y_val = train_test_split(X_dev, y_dev, test_size=0.25, random_state=SEED)

# ★ 수정 1: log1p (0 안전)
print(f"타깃 최솟값: {y_train.min()}  0의 개수: {(y_train == 0).sum()}")
assert (y_train >= 0).all(), "음수가 있으면 log1p를 쓸 수 없습니다"

y_train_log = np.log1p(y_train)
y_val_log = np.log1p(y_val)

model = HistGradientBoostingRegressor(random_state=SEED)
model.fit(X_train, y_train_log)

# ── 예측 ──
pred_val_log = model.predict(X_val)
pred_train_log = model.predict(X_train)

# ★ 수정 4: expm1 (log1p의 역함수)
pred_val = np.expm1(pred_val_log)

# ★ 수정 5: 편향 보정 (Duan's smearing)
smear = float(np.mean(np.exp(y_train_log - pred_train_log)))
pred_val_corrected = pred_val * smear

# ★ 수정 2·3: 평가는 원래 공간에서
def report(y_true, pred, tag):
    return {
        "구분": tag,
        "MAE": round(mean_absolute_error(y_true, pred), 4),
        "RMSE": round(float(np.sqrt(mean_squared_error(y_true, pred))), 4),
        "R²": round(r2_score(y_true, pred), 4),
        "편향": round(float((pred - y_true).mean()), 4),
    }

rows = [
    report(y_val, pred_val, "log1p (보정 없음)"),
    report(y_val, pred_val_corrected, "log1p + 보정"),
]

# ★ 수정 7: 변환 없는 모델과 비교
model_raw = HistGradientBoostingRegressor(random_state=SEED).fit(X_train, y_train)
rows.insert(0, report(y_val, model_raw.predict(X_val), "변환 없음 (기준)"))

print("\n" + "=" * 72)
print("원래 공간 성능 비교 — 이것만이 비교 가능한 숫자입니다")
print("=" * 72)
print(pd.DataFrame(rows).to_string(index=False))
print("=" * 72)
print(f"편향 보정 계수: {smear:.4f}")
print(f"보정으로 편향이 {rows[1]['편향']:.4f} → {rows[2]['편향']:.4f} 로 줄었습니다")

# ── 참고: 로그 공간 지표 (다른 모델과 비교 불가) ──
print(f"\n[참고] 로그 공간 MAE: {mean_absolute_error(y_val_log, pred_val_log):.4f}")
print("  ★ 이 숫자는 변환 없는 모델과 비교할 수 없습니다. 단위가 다릅니다.")

# ── 예측 함수로 감싸기 (Day 133 대비) ──
def predict_price(model, X, smear=1.0):
    """로그 공간 모델의 예측을 원래 단위로 반환"""
    return np.expm1(model.predict(X)) * smear

print(f"\n예측 가격 예시: {predict_price(model, X_val[:5], smear).round(2)}")
```

**3.** 여러분의 데이터(또는 공개 회귀 데이터셋)로 **완전한 EDA 노트북**을 만들고, 발견 목록을 작성하세요.

**공통 유틸 (재사용 가능하게 함수로)**

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import StandardScaler


def eda_target(y, name="target"):
    """① 타깃 요약 — 딕셔너리 반환 (발견 목록에 넣기 좋게)"""
    info = {
        "n": len(y), "결측": int(y.isna().sum()),
        "0개수": int((y == 0).sum()), "음수개수": int((y < 0).sum()),
        "min": float(y.min()), "median": float(y.median()),
        "mean": float(y.mean()), "max": float(y.max()),
        "std": float(y.std()), "skew": float(y.skew()),
    }
    if (y >= 0).all():
        info["skew_log1p"] = float(np.log1p(y).skew())
        info["skew_sqrt"] = float(np.sqrt(y).skew())
    vc = y.value_counts()
    info["최빈값"] = float(vc.index[0])
    info["최빈값_비율"] = float(vc.iloc[0] / len(y))
    info["상한절단"] = bool(vc.index[0] == y.max() and vc.iloc[0] > len(y) * 0.01)
    return info


def eda_corr(df, target):
    """④ 피어슨 vs 스피어만"""
    p = df.corr(method="pearson")[target].drop(target)
    s = df.corr(method="spearman")[target].drop(target)
    out = pd.DataFrame({"피어슨": p, "스피어만": s, "차이": s - p})
    out["해석"] = np.where(out["차이"] > 0.1, "비선형·단조",
                        np.where(out["차이"] < -0.1, "이상치 영향 의심", "-"))
    return out.sort_values("스피어만", key=abs, ascending=False).round(4)


def eda_vif(X):
    """⑤ VIF"""
    Xs = StandardScaler().fit_transform(X)
    v = []
    for i in range(Xs.shape[1]):
        others = np.delete(Xs, i, axis=1)
        r2 = LinearRegression().fit(others, Xs[:, i]).score(others, Xs[:, i])
        v.append(1 / (1 - r2) if r2 < 1 else np.inf)
    return pd.Series(v, index=X.columns).sort_values(ascending=False)


def eda_eta2(df, cat_col, target):
    """⑥ 범주형 설명력"""
    g = df.groupby(cat_col, observed=True)[target].agg(["size", "mean"])
    grand = df[target].mean()
    ss_between = (g["size"] * (g["mean"] - grand) ** 2).sum()
    ss_total = ((df[target] - grand) ** 2).sum()
    return float(ss_between / ss_total), g
```

**③ 로그 변환 효과 측정 — 채점의 핵심**

```python
def measure_log_effect(X_train, y_train, X_val, y_val, models):
    """변환 전후를 원래 공간에서 비교"""
    from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

    rows = []
    for name, make in models.items():
        for use_log in [False, True]:
            m = make()
            m.fit(X_train, np.log1p(y_train) if use_log else y_train)
            raw = m.predict(X_val)
            pred = np.expm1(raw) if use_log else raw
            rows.append({
                "모델": name,
                "변환": "log1p" if use_log else "없음",
                "MAE": round(mean_absolute_error(y_val, pred), 4),
                "RMSE": round(float(np.sqrt(mean_squared_error(y_val, pred))), 4),
                "R²": round(r2_score(y_val, pred), 4),
                "MAPE%": round(float(np.mean(np.abs((y_val - pred) / y_val)) * 100), 2),
                "편향": round(float((pred - y_val).mean()), 4),
            })
    res = pd.DataFrame(rows)

    print("=" * 84)
    print("로그 변환 효과 (전부 원래 공간 지표)")
    print("=" * 84)
    print(res.to_string(index=False))
    print("-" * 84)
    for name in models:
        sub = res[res["모델"] == name]
        b, l = sub.iloc[0], sub.iloc[1]
        verdict = "채택" if l["MAE"] < b["MAE"] else "기각"
        print(f"{name:<10} MAE {b['MAE']:.4f} → {l['MAE']:.4f} "
              f"({(b['MAE']-l['MAE'])/b['MAE']*100:+5.1f}%)  "
              f"MAPE {b['MAPE%']:.2f}% → {l['MAPE%']:.2f}%   → {verdict}")
    print("=" * 84)
    return res
```

```python
def make_findings(rows):
    df = pd.DataFrame(rows, columns=["번호", "구분", "발견", "근거", "조치", "결과", "다음"])
    print("=" * 130)
    print("EDA 발견 목록")
    print("=" * 130)
    print(df.to_string(index=False))
    print("=" * 130)
    pending = df[df["결과"].isin(["미정", "", None])]
    if len(pending):
        print("\n[다음 단계로 넘길 항목]")
        for _, r in pending.iterrows():
            print(f"  #{r['번호']} {r['발견']}  →  {r['다음']}")
    return df
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 회귀 EDA 제1원칙 | **타깃부터 본다** |
| EDA의 산출물 | 그래프가 아니라 **발견 목록 (발견/근거/조치/결과/다음)** |
| 왜도 판단 | <0.5 대칭 · 0.5~1 검토 · 1~2 권장 · >2 필수 |
| 평균 > 중앙값 | **오른쪽 꼬리** |
| `log1p` / `expm1` | 0에 안전. **짝을 맞춰 쓰기** |
| 로그 변환의 본질 | 절대 오차가 아니라 **비율 오차**를 최소화 |
| 로그 변환 효과 | 신경망·선형에 큼. **트리에는 거의 없음** |
| 되돌림 편향 | 체계적 **과소 예측**. smearing으로 보정 |
| ★ 평가 공간 | **항상 원래 공간에서.** 로그 공간 지표는 비교 불가 |
| 상한/하한 절단 | 변환으로 해결 불가. **보고서에 한계로 명시** |
| 피어슨 vs 스피어만 | 차이가 크면 **비선형** 또는 **이상치** |
| 상관 ≠ 인과 | 모델은 상관만 쓰지만, **문장은 상관만 말해야** |
| VIF | >10 심각. **예측엔 무해, 해석엔 치명** |
| 다중공선성 대응 | 예측이면 방치 · 해석이면 릿지 또는 특성 제거 |
| η² | 범주형 특성의 설명력. **>0.06이면 유용** |
| 표본 적은 범주 | 30건 미만은 못 믿음 → "기타"로 |

**오늘 반드시 기억할 세 가지**
> ① **타깃 히스토그램을 안 그리고 학습을 시작하지 마세요.**
> ② **로그 변환의 평가는 반드시 원래 공간에서.** 로그 공간 MAE는 다른 모델과 비교 불가입니다.
> ③ **EDA는 그림이 아니라 결정입니다.** 발견 목록에 "조치"와 "결과"가 없으면 EDA가 아닙니다.
