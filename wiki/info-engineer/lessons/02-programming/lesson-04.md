## ① 학습 목표

이 강을 마치면 다음을 할 수 있습니다.

- for·while·do-while의 실행 순서를 구분하고 반복 횟수를 **정확히 셀 수 있다**
- 중첩 반복문을 변수 추적표로 **끝까지 계산할 수 있다**
- break·continue가 있는 반복문의 출력을 **예측할 수 있다**
- 세 언어의 배열(리스트) 선언·인덱스·길이 문법을 **구분해 읽을 수 있다**
- 문자열 길이·부분 추출·비교 함수를 세 언어로 **대응시킬 수 있다**

## ② 왜 필요한가

**실기 코드 문제의 표준 형태가 바로 "반복문 + 배열"입니다.** 배열에 값을 넣고 반복문으로 돌리며 누적·최대·개수를 구하는 코드가 매 회차 변형되어 나옵니다(기출 복원 기반 비공식 경향). 이 유형은 감으로 풀면 반드시 틀립니다 — 반복이 5번인지 6번인지(off-by-one), 인덱스가 0부터인지 1부터인지에서 갈리기 때문입니다. 유일한 안전장치가 **추적표를 끝까지 쓰는 습관**이고, 이 강이 그 습관을 만드는 강입니다.

문자열은 "배열의 특수한 경우"입니다. C는 문자 배열 + 끝표시(`\0`), Java는 String 객체, Python은 슬라이싱이라는 서로 다른 옷을 입고 있지만, **인덱스 0부터 · 끝 인덱스 미포함**이라는 공통 규칙만 잡으면 세 언어가 한 번에 정리됩니다.

**시험에서의 중요도와 출제 형태** — 결과 예측(누적 합·패턴 출력), 코드 해석(종료 시점의 변수값), 빈칸(범위·조건식) 유형의 중심 재료입니다. 05강(포인터로 배열 순회), 06강(리스트 슬라이싱)의 직접적인 선수 내용입니다.

## ③ 개념 설명

### 3-1. 반복문 3형제

| 구조 | C · Java | Python | 검사 시점 |
|---|---|---|---|
| for | `for (초기식; 조건식; 증감식) { }` | `for i in range(...):` — **횟수가 아니라 나열을 순회** | 조건 먼저 |
| while | `while (조건) { }` | `while 조건:` | 조건 먼저 |
| do-while | `do { } while (조건);` | **없음** | **일단 1회 실행 후** 조건 |

📌 **반드시 암기 — C·Java for의 실행 순서**: 초기식(1회) → 조건 검사 → 본문 → 증감식 → 조건 검사 → … 조건이 거짓이면 종료. **종료 직후에도 반복 변수는 살아 있고, 마지막 증감까지 반영된 값**입니다(예: `for (i = 0; i < 5; i++)` 종료 후 `i`는 5). "종료 시점의 i 값"을 묻는 해석 문제가 여기서 나옵니다.

📌 **반드시 암기 — Python range**: `range(끝)` = 0부터 끝-1, `range(시작, 끝)` = 시작부터 **끝-1**, `range(시작, 끝, 간격)`. 끝은 항상 미포함 — `range(1, 5)`는 1,2,3,4의 4회입니다.

⚖️ **혼동 비교 — do-while**: while이 "조건 보고 입장"이라면 do-while은 "일단 입장하고 조건 보고 재입장"입니다. 조건이 처음부터 거짓이어도 **본문이 최소 1회 실행**되는 것이 출제 포인트입니다(④ Step 2).

### 3-2. break와 continue

| 키워드 | 동작 | 비유 |
|---|---|---|
| `break` | 반복문 **전체를 즉시 탈출** (중첩이면 가장 안쪽 하나만) | 퇴장 |
| `continue` | 이번 회차만 건너뛰고 **다음 회차로** | 이번 판 패스 |

### 3-3. 배열 — 같은 이름의 상자 여러 개

| 항목 | C | Java | Python (리스트) |
|---|---|---|---|
| 선언+초기화 | `int a[3] = {1, 2, 3};` | `int[] a = {1, 2, 3};` | `a = [1, 2, 3]` |
| 크기만 선언 | `int a[3];` (쓰레기값) | `int[] a = new int[3];` (0으로 채움) | 해당 없음 (동적) |
| 길이 | (직접 관리) | `a.length` | `len(a)` |
| 요소 추가 | 불가 (크기 고정) | 불가 (크기 고정) | `a.append(4)` |

📌 **반드시 암기**: **인덱스는 0부터** — 길이 n인 배열의 마지막 인덱스는 n−1. `a[n]`에 접근하면 Java·Python은 에러, **C는 에러 없이 엉뚱한 값**을 읽습니다(⑤ 참고).

⚖️ **혼동 주의 — 길이 표기 3종**: C 문자열 `strlen(s)` (함수), Java 배열 `a.length` (괄호 없음), Java 문자열 `s.length()` (괄호 있음), Python은 모두 `len(x)`. Java의 괄호 유무는 오류 찾기 유형의 단골입니다.

### 3-4. 문자열 — 언어별 옷은 달라도 규칙은 하나

| 작업 | C (`<string.h>`) | Java | Python |
|---|---|---|---|
| 길이 | `strlen(s)` | `s.length()` | `len(s)` |
| n번째 문자 | `s[n]` | `s.charAt(n)` | `s[n]` |
| 부분 추출 | (반복문으로 직접) | `s.substring(b, e)` | `s[b:e]` |
| 연결 | `strcat(s1, s2)` | `s1 + s2` | `s1 + s2` |
| 비교 | `strcmp(s1, s2) == 0` | `s1.equals(s2)` | `s1 == s2` |
| 복사 | `strcpy(s1, s2)` | `s1 = s2` | `s1 = s2` |

- **공통 규칙**: 인덱스 0부터, 부분 추출의 **끝 인덱스는 미포함** (`substring(1, 3)`과 `s[1:3]` 모두 인덱스 1·2의 2글자).
- C의 문자열은 **`\0`(널 문자)으로 끝나는 char 배열**입니다. `"KOREA"`는 실제로 6칸(K,O,R,E,A,\0)을 차지하고, 반복문 조건 `s[i] != '\0'`이 "문자열 끝까지"라는 뜻입니다.

⚖️ **혼동 비교 — Java의 문자열 비교 (빈출)**: `==`는 **주소(같은 객체인가)** 비교, `equals()`는 **내용** 비교입니다. 내용이 같아도 `==`가 false일 수 있으므로 Java에서 문자열 내용 비교는 반드시 `equals()`입니다. C에서 `strcmp`는 같을 때 **0**을 반환한다는 것도 함정입니다(같으면 0 = "차이가 0").

### Step 2. while vs do-while — 최소 1회의 차이

**언어: C · 난이도: 🟡 기본 · 학습 개념: do-while의 선실행**

```c
#include <stdio.h>
int main(void) {
    int i = 10;
    do {
        printf("%d ", i);
        i--;
    } while (i > 8);
    printf("/ i=%d\n", i);
    return 0;
}
```

```
$ gcc dw.c -o dw && ./dw
10 9 / i=8
```

| 회차 | 출력 | i (감소 후) | 조건 `i > 8` |
|---|---|---|---|
| 1 (무조건 실행) | 10 | 9 | 참 → 재입장 |
| 2 | 9 | 8 | 거짓 → 종료 |

같은 코드를 `while (i > 8) { ... }`로 바꾸고 `i = 5`로 시작하면: while은 **0회 실행**(출력 없음), do-while은 **1회 실행**(`5` 출력). 이 차이 하나를 묻는 문제가 나옵니다.

### Step 3. 중첩 반복 추적표 — 이 과정의 핵심 손 기술

**언어: C · 난이도: 🟡 기본 · 학습 개념: 중첩 for, 누적 합, 추적표 완주**

```c
#include <stdio.h>
int main(void) {
    int i, j, s = 0;
    for (i = 1; i <= 3; i++) {
        for (j = i; j <= 3; j++) {
            s += j;
        }
    }
    printf("%d\n", s);
    return 0;
}
```

안쪽 반복의 시작값이 `j = i`로 **바깥 변수에 묶여** 있는 것이 핵심입니다. 끝까지 씁니다:

| i | j | s (누적) |
|---|---|---|
| 1 | 1 | 1 |
| 1 | 2 | 3 |
| 1 | 3 | 6 |
| 2 | 2 | 8 |
| 2 | 3 | 11 |
| 3 | 3 | 14 |

```
$ gcc nested.c -o nested && ./nested
14
```

검산 요령: 회차 수 합계(3+2+1=6행)가 표의 행 수와 일치하는지 확인합니다. **중간에 "규칙이 보인다"고 표를 멈추는 것이 실전 오답의 최대 원인**입니다 — 시험에서는 끝까지 씁니다.

### Step 4. break·continue와 패턴 출력

**언어: Python · 난이도: 🟡 기본 · 학습 개념: continue/break의 흐름 제어**

```python
s = 0
for i in range(1, 10):
    if i % 2 == 0:
        continue
    if i > 7:
        break
    s += i
print(s)
```

```
$ python bc.py
16
```

추적: i=1 → s=1 / i=2 짝수 → continue / i=3 → s=4 / i=4 → continue / i=5 → s=9 / i=6 → continue / i=7 → s=16 / i=8 짝수 → **continue가 break 검사보다 먼저** / i=9 → `9 > 7` → break. 최종 `16`. **두 조건문의 순서**가 답을 바꾸는 구조라는 점을 눈여겨보세요.

**언어: Python · 난이도: 🟢 입문 · 학습 개념: 문자열 반복과 중첩 없는 패턴**

```python
for i in range(1, 4):
    print("*" * i)
```

```
$ python star.py
*
**
***
```

같은 패턴을 C·Java는 중첩 for(바깥 = 줄, 안쪽 = 별 개수)로 그립니다. "별 찍기"는 중첩 반복 이해도를 묻는 고전 유형입니다.

### Step 5. 배열 순회 — 최댓값과 건너뛰기 합

**언어: Java · 난이도: 🟡 기본 · 학습 개념: 배열 순회, 최댓값 갱신 패턴**

```java
public class MaxFind {
    public static void main(String[] args) {
        int[] a = {3, 7, 1, 9, 5};
        int max = a[0];
        for (int i = 1; i < a.length; i++) {
            if (a[i] > max) max = a[i];
        }
        System.out.println(max);
    }
}
```

| i | a[i] | 비교 | max |
|---|---|---|---|
| — | — | 초기값 a[0] | 3 |
| 1 | 7 | 7 > 3 참 | 7 |
| 2 | 1 | 1 > 7 거짓 | 7 |
| 3 | 9 | 9 > 7 참 | 9 |
| 4 | 5 | 5 > 9 거짓 | 9 |

```
$ javac MaxFind.java && java MaxFind
9
```

"최댓값 = 첫 요소로 초기화 후 더 크면 갱신"은 빈칸 유형(조건식 `a[i] > max` 또는 초기식 `a[0]`을 비움)의 최빈출 패턴입니다. 최솟값은 부등호만 반대입니다.

**언어: C · 난이도: 🟡 기본 · 학습 개념: 증감식 응용(i += 2)**

```c
#include <stdio.h>
int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int i, s = 0;
    for (i = 0; i < 5; i += 2) s += a[i];
    printf("%d\n", s);
    return 0;
}
```

```
$ gcc stride.c -o stride && ./stride
9
```

i는 0, 2, 4만 밟으므로 `a[0]+a[2]+a[4] = 1+3+5 = 9`. 증감식이 `i++`가 아닐 수 있음을 보여 주는 예입니다.

### Step 6. 문자열 다루기 — 세 언어 나란히

**언어: Python · 난이도: 🟡 기본 · 학습 개념: len, 인덱스(음수 포함), 부분 추출**

```python
s = "ENGINEER"
print(len(s))
print(s[0], s[-1])
print(s[2:6])
```

```
$ python str1.py
8
E R
GINE
```

인덱스 판: E(0) N(1) G(2) I(3) N(4) E(5) E(6) R(7). `s[-1]`은 뒤에서 첫 번째. `s[2:6]`은 2·3·4·5번(끝 6 미포함) → GINE.

**언어: Java · 난이도: 🟡 기본 · 학습 개념: length()·charAt·substring**

```java
public class Str {
    public static void main(String[] args) {
        String s = "HELLO";
        System.out.println(s.length());
        System.out.println(s.charAt(1));
        System.out.println(s.substring(1, 3));
    }
}
```

```
$ javac Str.java && java Str
5
E
EL
```

**언어: C · 난이도: 🟡 기본 · 학습 개념: char 배열, strlen, `\0`**

```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char s[] = "KOREA";
    printf("%d %c\n", (int)strlen(s), s[1]);
    return 0;
}
```

```
$ gcc str2.c -o str2 && ./str2
5 O
```

`strlen`은 `\0` **직전까지** 셉니다(5). 배열의 실제 크기는 `\0` 포함 6칸 — "strlen과 배열 크기가 다른 이유"가 단답으로 출제될 수 있는 지점입니다.

## ⑤ 자주 하는 실수

| 에러/증상 원문 | 언어 | 원인 | 해결 |
|---|---|---|---|
| 프로그램이 멈추지 않고 같은 출력 반복 | 공통 | 무한 루프 — 조건을 바꾸는 증감/갱신 누락 (`while (i < 5)`인데 i를 안 바꿈) | 반복문 3요소(초기·조건·증감)가 다 있는지 확인 — 오류 찾기 유형 단골 |
| `error: expected ';' before ')' token` | C | `for (i = 0, i < 5, i++)` — 구분자를 쉼표로 씀 | for 머리는 **세미콜론 2개**: `for (i = 0; i < 5; i++)` |
| `ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5` | Java | 길이 5 배열의 `a[5]` 접근 — 마지막 인덱스는 4 | 조건을 `i < a.length`로 (`<=`가 흔한 원인) |
| `IndexError: string index out of range` | Python | `s[len(s)]` 등 범위 밖 인덱스 | 마지막 문자는 `s[len(s)-1]` 또는 `s[-1]` |
| 에러 없이 쓰레기값 출력 | C | 범위 밖 `a[5]` 접근 — **C는 검사하지 않음** | Java·Python은 에러, C는 침묵 — 언어 차이 오답 포인트 |
| 반복 횟수가 1회 많거나 적음 | 공통 | `<` vs `<=` 혼동, `range(1, n)`이 n을 포함한다는 착각 | 첫 회차와 마지막 회차를 직접 대입해 세어 본다 |
| `s1 == s2`가 내용이 같은데 false | Java | `==`는 주소 비교 | 내용 비교는 `s1.equals(s2)` — 빈출 함정 |
| `error: 'strlen' undeclared` 또는 `implicit declaration of function 'strlen'` | C | `#include <string.h>` 누락 | 문자열 함수 사용 시 string.h 포함 |

<details>
<summary>정답과 해설</summary>

1. **`6`** — 안쪽 반복 횟수: i=1일 때 0회(`j < 1` 즉시 거짓), i=2일 때 1회, i=3일 때 2회, i=4일 때 3회 → 0+1+2+3=6.
   - 대표 오답: `10` — 안쪽 조건을 `j <= i`로 잘못 읽고 1+2+3+4로 계산한 경우. `<`와 `<=`를 구분하세요.
2. **`101`** — range의 끝은 미포함이므로 100까지 돌리려면 101. (출력은 5050)
   - 대표 오답: `100` — 이러면 99까지의 합 4950이 됩니다. off-by-one의 전형.
3. **`3`** — D·A·T·A·B·A·S·E에서 'A'는 3개. 반복 조건 `s[i] != '\0'`은 "문자열 끝까지"라는 뜻입니다.
   - 대표 오답: `2` — 끝까지 세지 않고 눈으로 훑다 하나를 놓친 경우. 문자마다 인덱스를 적고 세는 것이 안전합니다.

</details>

## 마무리

**오늘의 요약** — for의 실행 순서(초기 1회 → 조건 → 본문 → 증감 → 조건…)와 종료 후에도 남는 반복 변수 값, do-while의 최소 1회 실행, break(탈출)/continue(건너뛰기)를 배웠습니다. 배열·문자열의 공통 규칙은 "인덱스 0부터, 끝 미포함"이고, 길이 표기 3종(`strlen(s)` / `a.length` / `s.length()` / `len(x)`)과 Java의 `==` vs `equals()`가 오늘의 함정입니다.

**복습 체크리스트**

- [ ] Step 3 중첩 추적표(6행, 답 14)를 안 보고 완주할 수 있다
- [ ] `for (i = 0; i < 5; i++)` 종료 후 i 값을 즉답할 수 있다 (5)
- [ ] `range(2, 8, 2)`가 나열하는 값을 즉답할 수 있다 (2, 4, 6)
- [ ] 길이 표기 4종을 언어·대상별로 짝지을 수 있다
- [ ] Java에서 문자열 내용 비교에 쓰는 메서드를 즉답할 수 있다 (equals)

**과제 — 2주차 형성평가 (10문항, 05강 첫 복습 퀴즈와 연동)**
