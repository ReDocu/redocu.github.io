## 3. 개념

### 3-1. `GameObject` — 프레임워크판

**왜 필요한가** — Day 28의 `GameObject`를 WINAPI 환경에 맞게 정리한다.

```cpp
// Engine/GameObject.h
#pragma once
#include "EngineCommon.h"

class Renderer;
class Core;

struct RectF { float x, y, w, h; };

class GameObject
{
public:
    GameObject() = default;
    virtual ~GameObject() = default;                  // ★ 가상 소멸자

    // 하위 클래스가 반드시 구현
    virtual void Update(double dt) = 0;
    virtual void Render(Renderer& renderer) const = 0;

    // 선택적으로 구현
    virtual bool Init(Core* core) { m_core = core; return true; }
    virtual void Release() {}
    virtual void OnCollide(GameObject* other) {}

    // 공통 기능
    void SetPos(double x, double y) { m_x = x; m_y = y; }
    double GetX() const { return m_x; }
    double GetY() const { return m_y; }

    bool IsActive() const  { return m_active; }
    void SetActive(bool a) { m_active = a; }
    void Destroy()         { m_active = false; }

    int  GetLayer() const  { return m_layer; }        // 그리기 순서
    void SetLayer(int l)   { m_layer = l; }

    int  GetTag() const    { return m_tag; }          // 종류 구분
    void SetTag(int t)     { m_tag = t; }

    virtual RectF GetBounds() const
    {
        RectF r = { (float)m_x - 8, (float)m_y - 8, 16, 16 };
        return r;
    }

protected:
    double m_x = 0.0, m_y = 0.0;
    bool   m_active = true;
    int    m_layer = 0;
    int    m_tag = 0;
    Core*  m_core = nullptr;
};
```

**Day 28과 달라진 점**

| 항목 | 이유 |
|---|---|
| `Init(Core*)` 추가 | 화면 크기 등 엔진 정보가 필요하다 |
| `Render(Renderer&)` | HDC 직접 조작 대신 `Renderer` 사용 |
| `GetLayer()` | 그리기 순서 제어 (배경 → 오브젝트 → UI) |
| `GetTag()` | 종류 구분 (충돌 그룹 등) |
| `RectF` | 실수 좌표 기반 충돌 박스 |

### 3-2. `Scene` — 오브젝트 컨테이너

**왜 필요한가** — Day 28의 `ObjectManager`가 프레임워크의 `Scene`이 된다.

```cpp
// Engine/Scene.h
class Scene
{
public:
    virtual ~Scene();

    virtual bool Init(Core* core);
    virtual void Update(double dt);
    virtual void Render(Renderer& renderer);
    virtual void Release();

    // 오브젝트 관리
    GameObject* Add(GameObject* obj);
    void        Clear();
    int         GetCount() const { return m_count; }
    GameObject* Get(int i) const { return (i >= 0 && i < m_count) ? m_objects[i] : nullptr; }
    int         CountByTag(int tag) const;

protected:
    void UpdateAll(double dt);
    void RenderAll(Renderer& renderer);
    void RemoveInactive();

protected:
    static const int MAX_OBJECTS = 4096;

    GameObject* m_objects[MAX_OBJECTS] = { nullptr };
    int         m_count = 0;
    Core*       m_core  = nullptr;
};
```

```cpp
// Engine/Scene.cpp
GameObject* Scene::Add(GameObject* obj)
{
    if (!obj) return nullptr;

    if (m_count >= MAX_OBJECTS)
    {
        DebugLog("Scene: 오브젝트 한계 초과\n");
        delete obj;                                   // ★ 소유권을 받았으니 정리
        return nullptr;
    }

    if (!obj->Init(m_core))
    {
        delete obj;
        return nullptr;
    }

    m_objects[m_count++] = obj;
    return obj;
}

void Scene::UpdateAll(double dt)
{
    for (int i = 0; i < m_count; i++)
        if (m_objects[i]->IsActive())
            m_objects[i]->Update(dt);
}

void Scene::RenderAll(Renderer& renderer)
{
    // 레이어 순서대로 (0 → 높은 값)
    for (int layer = 0; layer <= MAX_LAYER; layer++)
        for (int i = 0; i < m_count; i++)
            if (m_objects[i]->IsActive() && m_objects[i]->GetLayer() == layer)
                m_objects[i]->Render(renderer);
}

void Scene::RemoveInactive()
{
    for (int i = m_count - 1; i >= 0; i--)            // ★ 뒤에서부터 (Day 11)
    {
        if (!m_objects[i]->IsActive())
        {
            m_objects[i]->Release();
            delete m_objects[i];

            m_objects[i] = m_objects[--m_count];      // 마지막 것을 당겨온다
            m_objects[m_count] = nullptr;
        }
    }
}

void Scene::Clear()
{
    for (int i = 0; i < m_count; i++)
    {
        if (m_objects[i]) { m_objects[i]->Release(); delete m_objects[i]; }
        m_objects[i] = nullptr;
    }
    m_count = 0;
}

Scene::~Scene() { Clear(); }
```

> ### ⚠️ 소유권 규칙
>
> ```
>   Scene::Add(new Star())
>          ▲
>          └── 이 순간부터 Scene 이 소유한다
>
>   ★ 규칙
>     ① Add 에 넘긴 포인터는 다른 곳에서 delete 하지 않는다
>     ② Add 가 실패해도 Scene 이 정리한다 (호출자가 신경 안 써도 된다)
>     ③ Scene 이 파괴되면 모든 오브젝트가 함께 파괴된다
> ```
>
> Day 19에서 배운 **"누가 free할 책임인가"** 를 명확히 하는 것이다.

### 3-4. `SceneManager` — 씬 전환

**왜 필요한가** — 타이틀 → 게임 → 결과 흐름 (Day 25의 그것).

```cpp
class SceneManager
{
public:
    void Init(Core* core) { m_core = core; }

    void ChangeScene(Scene* newScene)
    {
        m_nextScene = newScene;                      // ★ 즉시 바꾸지 않는다
    }

    void Update(double dt)
    {
        // 프레임 끝에서 안전하게 교체
        if (m_nextScene)
        {
            if (m_current) { m_current->Release(); delete m_current; }

            m_current = m_nextScene;
            m_nextScene = nullptr;

            m_current->Init(m_core);
        }

        if (m_current) m_current->Update(dt);
    }

    void Render(Renderer& r) { if (m_current) m_current->Render(r); }

    void Release()
    {
        if (m_current)   { m_current->Release();   delete m_current;   m_current = nullptr; }
        if (m_nextScene) { delete m_nextScene; m_nextScene = nullptr; }
    }

private:
    Scene* m_current   = nullptr;
    Scene* m_nextScene = nullptr;
    Core*  m_core      = nullptr;
};
```

> ### ⚠️ 씬 전환을 즉시 하면 크래시한다
>
> ```cpp
>   void GameScene::Update(double dt)
>   {
>       if (게임오버)
>           sceneManager->ChangeScene(new ResultScene());    // 여기서 즉시 delete하면?
>                                                            // → 지금 실행 중인 this 가 사라진다!
>   }
> ```
>
> **다음 프레임에 교체한다.** 예약만 해 두고 안전한 시점에 바꾼다.

### 3-5. 충돌 검사 — 태그 기반

**왜 필요한가** — Day 24의 AABB를 프레임워크에 얹는다.

```cpp
enum Tag
{
    TAG_NONE = 0,
    TAG_PLAYER,
    TAG_ENEMY,
    TAG_PLAYER_BULLET,
    TAG_ENEMY_BULLET,
    TAG_ITEM
};

bool IsOverlap(const RectF& a, const RectF& b)
{
    if (a.x >= b.x + b.w) return false;
    if (a.x + a.w <= b.x) return false;
    if (a.y >= b.y + b.h) return false;
    if (a.y + a.h <= b.y) return false;
    return true;
}

void Scene::CheckCollision(int tagA, int tagB)
{
    for (int i = 0; i < m_count; i++)
    {
        if (!m_objects[i]->IsActive() || m_objects[i]->GetTag() != tagA) continue;

        RectF ra = m_objects[i]->GetBounds();

        for (int j = 0; j < m_count; j++)
        {
            if (i == j) continue;
            if (!m_objects[j]->IsActive() || m_objects[j]->GetTag() != tagB) continue;

            if (IsOverlap(ra, m_objects[j]->GetBounds()))
            {
                m_objects[i]->OnCollide(m_objects[j]);
                m_objects[j]->OnCollide(m_objects[i]);
            }
        }
    }
}
```

```cpp
    // 필요한 조합만 검사 (Day 54의 그룹별 충돌)
    CheckCollision(TAG_PLAYER_BULLET, TAG_ENEMY);
    CheckCollision(TAG_ENEMY_BULLET,  TAG_PLAYER);
    CheckCollision(TAG_PLAYER,        TAG_ITEM);
```

> **`OnCollide`가 가상 함수이므로 각 오브젝트가 알아서 반응한다.**
> `Scene`은 무엇과 무엇이 부딪혔는지 알 필요가 없다.

class Star : public GameObject

class Meteor : public GameObject
{
public:
    bool Init(Core* core) override
    {
        GameObject::Init(core);

        m_x = rand() % core->GetWidth();
        m_y = -10;
        m_vx = -30.0 + rand() % 60;
        m_vy = 100.0 + rand() % 150;
        m_radius = 4 + rand() % 6;

        SetLayer(2);
        SetTag(TAG_ENEMY);
        return true;
    }

    void Update(double dt) override
    {
        m_x += m_vx * dt;
        m_y += m_vy * dt;

        if (m_y > m_core->GetHeight() + 20)
            Destroy();                                // 자동 회수
    }

    void Render(Renderer& r) const override
    {
        r.DrawCircle((int)m_x, (int)m_y, m_radius, RGB(200, 120, 60));
    }

    RectF GetBounds() const override
    {
        RectF rc = { (float)(m_x - m_radius), (float)(m_y - m_radius),
                     (float)(m_radius * 2), (float)(m_radius * 2) };
        return rc;
    }

private:
    double m_vx = 0, m_vy = 0;
    int    m_radius = 5;
};

public:
    void Update(double dt) override { m_angle += 2.0 * dt; }
    void Render(Renderer& r) const override
    {
        // 회전 사각형 (Polygon)
        POINT pts[4];
        for (int i = 0; i < 4; i++)
        {
            double a = m_angle + i * 1.5708;         // 90도씩
            pts[i].x = (LONG)(m_x + cos(a) * 30);
            pts[i].y = (LONG)(m_y + sin(a) * 30);
        }
        r.DrawPolygon(pts, 4, RGB(120, 200, 255));
    }
private:
    double m_angle = 0;
};

class Bouncer : public GameObject      // 벽에 튕기는 공
{
public:
    void Update(double dt) override
    {
        m_x += m_vx * dt;  m_y += m_vy * dt;

        int w = m_core->GetWidth(), h = m_core->GetHeight();

        if (m_x < 20)     { m_x = 20;     m_vx = -m_vx; }
        if (m_x > w - 20) { m_x = w - 20; m_vx = -m_vx; }
        if (m_y < 20)     { m_y = 20;     m_vy = -m_vy; }
        if (m_y > h - 20) { m_y = h - 20; m_vy = -m_vy; }
    }
    void Render(Renderer& r) const override
    { r.DrawCircle((int)m_x, (int)m_y, 20, RGB(255, 100, 100)); }
private:
    double m_vx = 220, m_vy = 170;
};
```

**✅ 여기까지 실행하면** — 별, 운석, 회전 사각형, 튀는 공이 **한 배열에서** 각자 동작한다.

## 5. 전원 코드 리뷰 (필수)

> ### 오늘 오후는 전원 코드 리뷰다
> 1인 5분씩, 아래 항목을 강사가 직접 확인한다.
> **이 프레임워크 위에 앞으로 6주가 얹힌다.** 통과할 때까지 붙잡는다.

### 5-1. 시연 항목

| # | 확인 항목 | 통과 기준 | 어떻게 시연하나 |
|:--:|---|---|---|
| **1** | **더블버퍼링** | 깜빡임 유무를 **토글로 시연** | `D` 키로 ON/OFF, 차이가 명확 |
| **2** | **게임 루프** | 창 드래그 중에도 갱신 지속 | 제목 표시줄을 잡고 흔들기 |
| **3** | **델타 타임** | FPS를 바꿔도 이동 속도 동일 | `V`로 제한 토글, 고정이동 vs 델타이동 비교 |
| **4** | **리소스 해제** | 종료 시 크래시·누수 없음 | 작업 관리자 GDI 개체 확인 |
| **5** | **구조 분리** | `WinMain` 10줄 이내, Engine/Game 분리 | 폴더 구조 + main.cpp |
| **6** | **확장성** | 새 오브젝트 = 클래스 1개 | **즉석에서 새 오브젝트를 추가해 보이기** |

### 5-2. 즉석 확장 테스트 (6번 항목)

**강사가 그 자리에서 요구한다.**

### 5-3. 코드 품질 확인

- [ ] 모든 헤더에 `#pragma once`
- [ ] 멤버 변수가 `private` 또는 `protected`
- [ ] 읽기 전용 함수에 `const`
- [ ] `GameObject`에 **가상 소멸자**
- [ ] `new` 마다 짝이 되는 `delete`
- [ ] GDI 오브젝트 `Create` 마다 `DeleteObject`
- [ ] `Init` 실패 시 정리하고 `false` 반환
- [ ] `Release`가 `Init`의 역순
- [ ] 순회 중 삭제를 뒤에서부터

### 5-4. 미통과 시 대응

```
   ┌──────────────────────────────────────────────────────────┐
   │  미통과 항목이 있으면                                       │
   │                                                           │
   │  ① 그 자리에서 원인을 찾아 수정한다 (강사 지도)            │
   │  ② 시간이 부족하면 강사 배포본을 받아 다음 주를 시작한다    │
   │  ③ 단, 본인 구현은 별도로 완성한다 (보충 과제)             │
   │                                                           │
   │  ★ 진도는 멈추지 않는다. 하지만 넘어가지도 않는다.         │
   └──────────────────────────────────────────────────────────┘
```

**가장 흔한 미통과 원인**

| 항목 | 원인 | 확인할 곳 |
|---|---|---|
| 1. 더블버퍼링 | `WM_ERASEBKGND` 미차단 | `return 1` 확인 |
| 2. 게임 루프 | `WM_ENTERSIZEMOVE` 미처리 | 모달 루프 대응 |
| 3. 델타 타임 | 고정값 이동이 남아 있음 | `* dt` 누락 검색 |
| 4. 해제 | `DeleteDC` 대신 `ReleaseDC` | `Renderer::Release` |
| 5. 구조 | Engine/Game이 한 폴더 | 폴더 분리 |
| 6. 확장성 | `Scene`이 종류별 배열을 씀 | `GameObject*` 배열로 |

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 오브젝트가 안 그려짐 | `Add` 안 함, 또는 `m_active = false` | 등록·활성 확인 |
| 자식 `Update`가 안 불림 | **`virtual` 누락** | 부모에 `virtual` |
| 메모리 누수 | **가상 소멸자 누락** | `virtual ~GameObject()` |
| 순회 중 크래시 | 앞에서부터 삭제 | **뒤에서부터** |
| 이중 해제 | `Scene`과 개별 포인터가 모두 `delete` | 소유권을 `Scene` 하나로 |
| 배경이 캐릭터를 덮음 | 레이어 미설정 | `SetLayer` |
| 씬 전환 시 크래시 | 즉시 `delete` | 다음 프레임에 교체 |
| `Init`이 안 불림 | `Add`에서 호출 누락 | `Scene::Add`에서 `obj->Init(m_core)` |
| 부모 `Init` 미호출 | `GameObject::Init(core)` 누락 | 자식 `Init` 첫 줄에 |
| 전방 선언 오류 | `Renderer` 멤버 함수 호출 | `.cpp`에서 실제 헤더 포함 |
