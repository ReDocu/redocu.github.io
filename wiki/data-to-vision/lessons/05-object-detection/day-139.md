## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- YOLO `.txt` · Pascal VOC `.xml` · COCO `.json` 세 포맷의 **파일 구조**를 읽고 쓸 수 있다.
- 세 포맷 사이를 오가는 **변환 스크립트**를 작성하고, 왕복 검증할 수 있다.

- 변환 결과를 **이미지에 그려 눈으로 검증**하는 절차를 스크립트로 만들 수 있다.
- 남에게 받은 데이터셋을 우리 형식으로 **안전하게 흡수**할 수 있다.

## ② 왜 필요한가

### 어제 만든 100장은 우리 형식입니다. 그런데…

```
우리 데이터   YOLO .txt      100장
공개 데이터   COCO .json     5,000장   ← 섞어 쓰고 싶다
후배가 준 것  VOC .xml       300장     ← 합치고 싶다
평가 도구     COCO .json 만 받음        ← 내보내야 한다
```

**데이터를 늘리는 가장 빠른 방법은 남의 데이터를 합치는 것입니다.**
[Day 145](day-145.md)에서 500장을 만들 때, 전부 직접 찍는 것보다 공개 데이터를 섞는 편이 훨씬 빠릅니다.

그런데 형식이 다 다릅니다. **변환이 안 되면 합칠 수 없습니다.**

### 그리고 어제 포맷을 잘못 저장한 사람이 있습니다

```
labels/
  frm_0000.xml
  frm_0001.xml
  ...  50개
```

좌하단 포맷 버튼을 안 바꾸고 50장을 작업한 경우입니다.
**데이터는 살아 있습니다.** 오늘 스크립트로 5초면 살립니다.

### 변환은 "그냥 숫자 옮기기"가 아닙니다

세 가지 함정이 있습니다.

**함정 1 — 이미지 크기를 모르면 변환이 불가능합니다**

```
YOLO (0.1525, 0.4756, 0.22, 0.56)  →  VOC ?

★ 이미지가 800×450인지 1920×1080인지 모르면 계산 불가
```

VOC `.xml` 에는 `<size>` 가 들어 있지만, **YOLO `.txt` 에는 이미지 크기가 없습니다.**
그래서 YOLO → 다른 포맷 변환은 **원본 이미지가 반드시 있어야 합니다.**

**함정 2 — 클래스 이름과 번호의 대응이 깨집니다**

```
우리 classes.txt      COCO categories
  0 person              1 person
  1 helmet              2 bicycle
  2 box                 3 car
                        ...

★ COCO는 id가 1부터 시작하고 중간에 빈 번호가 있습니다
★ 그냥 숫자를 옮기면 person 이 bicycle 이 됩니다
```

**함정 3 — 파일명 매칭이 조용히 깨집니다**

```
images/frm_0001.JPG        ← 대문자 확장자
labels/frm_0001.txt

Windows 에서는 매칭됨
Linux (Colab) 에서는 ★ 매칭 안 됨
```

> ⚠️ **셋 다 에러가 안 납니다.**
> [Day 136](day-136.md)에서 배운 것과 같습니다. **좌표 관련 사고는 조용히 실패합니다.**
> 오늘 만드는 검증 스크립트가 그래서 필요합니다.

```
1~4교시 (개념)

```

## ③ 개념 설명

### 세 포맷의 파일 구조 비교

| | YOLO | Pascal VOC | COCO |
|---|---|---|---|
| 파일 단위 | **이미지 1장 = txt 1개** | **이미지 1장 = xml 1개** | **데이터셋 전체 = json 1개** |
| 클래스 표현 | **번호** (별도 `classes.txt`) | **이름 문자열** | **번호 + 이름 정의** |
| 이미지 크기 | ✗ 없음 | ✓ `<size>` | ✓ `images[].width/height` |
| 좌표 | 정규화 중심+크기 | 픽셀 두 모서리 | 픽셀 모서리+크기 |
| 파일 수 (1,000장) | 1,001개 | 1,000개 | **1개** |
| 사람이 읽기 | 어려움 | 쉬움 | 보통 |
| 부분 수정 | 쉬움 | 쉬움 | **어려움** (전체 재작성) |

### YOLO `.txt` — 한 줄씩 읽기

```
labels/frm_0042.txt

0 0.152500 0.475556 0.220000 0.560000
0 0.443750 0.522222 0.187500 0.555556
2 0.812500 0.300000 0.075000 0.333333
```

```
0        0.152500   0.475556   0.220000   0.560000
↑          ↑          ↑          ↑          ↑
클래스     중심 x     중심 y     너비       높이
번호      (0~1)      (0~1)      (0~1)      (0~1)

· 공백으로 구분
· 한 줄 = 객체 1개
· 소수점 자리수는 자유 (보통 6자리)
· 줄 순서는 의미 없음
```

**함께 있어야 하는 파일**

```
classes.txt              ← 번호 → 이름 (labelImg가 만듦)
  person                     0
  helmet                     1
  box                        2
```

> **★ `classes.txt` 를 잃어버리면 라벨의 의미를 알 수 없습니다.**
> `0` 이 person 인지 car 인지 알 방법이 없습니다.
> **라벨 폴더와 항상 같이 보관하세요.** 나중에 `data.yaml` 로 대체됩니다([Day 140](day-140.md)).

### Pascal VOC `.xml` — 태그로 읽기

```xml
<annotation>
  <folder>images</folder>
  <filename>frm_0042.jpg</filename>
  <path>C:/vision/day138/images/frm_0042.jpg</path>
  <source><database>Unknown</database></source>
  <size>
    <width>800</width>       ← ★ 이미지 크기가 들어 있음
    <height>450</height>
    <depth>3</depth>
  </size>
  <segmented>0</segmented>

  <object>                   ← 객체 1개당 이 블록 1개
    <name>person</name>      ← ★ 클래스 "이름"
    <pose>Unspecified</pose>
    <truncated>0</truncated> ← 잘렸는가 (0/1)
    <difficult>0</difficult> ← ★ 어려운 샘플 표시
    <bndbox>
      <xmin>34</xmin>
      <ymin>88</ymin>
      <xmax>210</xmax>
      <ymax>340</ymax>
    </bndbox>
  </object>

  <object>
    <name>helmet</name>
    ...
  </object>
</annotation>
```

**주목할 두 태그**

| 태그 | 의미 | 우리의 처리 |
|---|---|---|
| `<truncated>` | 화면 밖으로 잘림 | 정보로만 활용 |
| **`<difficult>`** | 사람도 판단이 어려운 샘플 | ★ **보통 학습에서 제외** |

```
difficult=1 인 객체
  · 아주 작음
  · 심하게 가림
  · 흐릿함

원본 VOC 평가 규칙: difficult 는 채점에서 제외
→ 변환 시 "포함할지" 를 정해야 합니다
```

### COCO `.json` — 3개 배열의 관계

**한 파일에 데이터셋 전체가 들어갑니다.**

```json
{
  "info": {"description": "CCTV dataset", "version": "1.0"},
  "licenses": [],

  "images": [
    {"id": 1, "file_name": "frm_0042.jpg", "width": 800, "height": 450},
    {"id": 2, "file_name": "frm_0043.jpg", "width": 800, "height": 450}
  ],

  "annotations": [
    {"id": 1, "image_id": 1, "category_id": 1,
     "bbox": [34, 88, 176, 252], "area": 44352, "iscrowd": 0},
    {"id": 2, "image_id": 1, "category_id": 3,
     "bbox": [280, 110, 150, 250], "area": 37500, "iscrowd": 0},
    {"id": 3, "image_id": 2, "category_id": 1,
     "bbox": [620, 60, 60, 150], "area": 9000, "iscrowd": 0}
  ],

  "categories": [
    {"id": 1, "name": "person", "supercategory": "none"},
    {"id": 3, "name": "box", "supercategory": "none"}
  ]
}
```

**관계도**

```
  images[]                annotations[]              categories[]
  ┌──────────┐            ┌──────────────┐           ┌────────────┐
  │ id: 1    │◄───────────│ image_id: 1  │           │ id: 1      │
  │ frm_0042 │            │ category_id:1│──────────►│ person     │
  │ 800×450  │            │ bbox: [...]  │           └────────────┘
  └──────────┘            └──────────────┘
                          ┌──────────────┐           ┌────────────┐
  ┌──────────┐            │ image_id: 1  │           │ id: 3      │
  │ id: 2    │◄───────────│ category_id:3│──────────►│ box        │
  │ frm_0043 │            └──────────────┘           └────────────┘
  └──────────┘
```

**꼭 알아야 할 3가지**

| # | 사실 | 왜 중요한가 |
|---|---|---|
| 1 | `bbox` 는 **`[x_min, y_min, w, h]`** | VOC와 혼동 금지 |
| 2 | `category_id` 는 **1부터 시작**하는 경우가 많음 | YOLO는 0부터 → **오프셋 필요** |
| 3 | **id가 연속이 아닐 수 있음** | COCO 원본은 1,2,3,...,11,13,... (12 없음) |

> ⚠️ **원본 COCO 데이터셋의 category_id는 1~90인데 클래스는 80개입니다.**
> 빠진 번호가 있습니다. `category_id - 1` 로 변환하면 **틀립니다.**
> 반드시 `categories` 배열을 읽어 **매핑 딕셔너리**를 만드세요.

**`iscrowd` 도 알아 두세요**

```
iscrowd: 0  →  개별 객체
iscrowd: 1  →  ★ 군중처럼 셀 수 없는 덩어리 (RLE 마스크)

우리는 iscrowd=1 을 검출 학습에서 제외합니다
(박스 하나에 사람 30명이 들어 있으면 학습에 해롭습니다)
```

### 이미지-라벨 매칭 규칙

**YOLO는 파일명(확장자 제외)이 같아야 합니다.**

```
images/train/frm_0042.jpg
labels/train/frm_0042.txt      ← ✓ 매칭
                ↑ stem 이 같음
```

**Ultralytics의 경로 규칙**

```
datasets/cctv/
  images/
    train/  a.jpg  b.jpg
    val/    c.jpg
  labels/
    train/  a.txt  b.txt
    val/    c.txt

★ 규칙: 이미지 경로에서 "/images/" 를 "/labels/" 로 바꾸고
        확장자를 .txt 로 바꾼 위치를 찾습니다
```

```python
# Ultralytics 내부 로직과 동일한 계산
img = "datasets/cctv/images/train/a.jpg"
lbl = img.replace("/images/", "/labels/").rsplit(".", 1)[0] + ".txt"
# → datasets/cctv/labels/train/a.txt
```

> ⚠️ **폴더 이름이 반드시 `images` / `labels` 여야 합니다.**
> `imgs/` `img/` `Images/` 는 안 됩니다. **이 실수가 "0 labels found"의 최다 원인입니다.**

**매칭이 깨지는 5가지 경우**

| # | 경우 | 예 |
|---|---|---|
| 1 | 확장자 대소문자 | `a.JPG` ↔ `a.txt` (Linux에서 실패) |
| 2 | 이름에 공백·특수문자 | `frm 0042.jpg` |
| 3 | **이름에 점(.)이 여러 개** | `img.v2.jpg` → stem이 `img.v2` |
| 4 | 폴더명이 `images`/`labels` 가 아님 | `imgs/` |
| 5 | 라벨만 있고 이미지가 없음 (고아) | 이미지를 지운 뒤 라벨은 남김 |

### ★ 빈 라벨 — 객체가 없는 이미지

**검출 데이터셋에는 "아무것도 없는 사진"이 필요합니다.**

```
왜 필요한가
  · 모델에게 "여기엔 없다"를 가르침
  · 배경의 오검출(FP)을 줄임
  · 실제 CCTV의 대부분 시간은 아무도 없음
```

| 포맷 | 빈 라벨 표현 |
|---|---|
| **YOLO** | `.txt` 파일이 **없거나** 내용이 **빈 파일** — 둘 다 정상 |
| **VOC** | `<object>` 태그가 하나도 없는 `.xml` |
| **COCO** | `images` 에는 있고 `annotations` 에는 해당 `image_id` 가 없음 |

```
★ Ultralytics 는 세 가지를 구분합니다

  라벨 파일 없음   →  배경 이미지로 취급 (정상, 학습에 사용)
  빈 파일         →  배경 이미지로 취급 (정상)
  이미지 없음      →  ★ 경고 후 무시
```

> **권장 비율 — 배경 이미지는 전체의 5~15%**
> 너무 적으면 오검출이 많아지고, 너무 많으면 모델이 "아무것도 없다"에 치우칩니다.
> [Day 141](day-141.md)에서 정식으로 다룹니다.

### 변환 방향별 필요한 것

```
                        이미지 크기가 필요한가?

  VOC  →  COCO          ✗ (xml 안에 있음)
  COCO →  VOC           ✗ (json 안에 있음)
  VOC  →  YOLO          ✗ (xml 안에 있음)
  COCO →  YOLO          ✗ (json 안에 있음)

  ★ YOLO →  VOC         ✓ 원본 이미지 필요
  ★ YOLO →  COCO        ✓ 원본 이미지 필요
```

```
+ 클래스 매핑이 필요한가?

  이름 ↔ 번호 변환이 끼는 모든 방향에서 필요
  → classes.txt 또는 categories 를 반드시 함께 다룸
```

## ④ 단계별 실습

### Step 1. 변환 모듈 뼈대 — `label_convert.py`

```python
"""label_convert.py — 라벨 포맷 변환

지원 방향
    VOC(xml)  ↔  YOLO(txt)
    COCO(json) ↔  YOLO(txt)
    VOC(xml)  →  COCO(json)

전제
    · YOLO 에서 나가는 변환은 원본 이미지가 있어야 함 (크기 필요)
    · 클래스 목록(classes)은 리스트로 전달 — 인덱스가 곧 YOLO 클래스 id
"""
import json
import xml.etree.ElementTree as ET
from pathlib import Path

import cv2

import bbox_utils as B          # Day 136 모듈

IMG_EXTS = (".jpg", ".jpeg", ".png", ".bmp", ".webp")


# ────────────────────────── 공통 ──────────────────────────
def load_classes(path):
    """classes.txt → ['person', 'helmet', ...]"""
    return [l.strip() for l in
            Path(path).read_text(encoding="utf-8").splitlines() if l.strip()]


def find_image(img_dir, stem):
    """확장자를 모르는 이미지 찾기 — ★ 대소문자 무시"""
    img_dir = Path(img_dir)
    for p in img_dir.iterdir():
        if p.stem == stem and p.suffix.lower() in IMG_EXTS:
            return p
    return None


def image_size(path):
    img = cv2.imread(str(path))
    if img is None:
        raise FileNotFoundError(f"이미지를 읽을 수 없음: {path}")
    h, w = img.shape[:2]
    return w, h


def write_yolo(txt_path, rows):
    """rows: [(cls_id, cx, cy, w, h), ...]  — 빈 리스트면 빈 파일 생성"""
    txt_path = Path(txt_path)
    txt_path.parent.mkdir(parents=True, exist_ok=True)
    body = "\n".join(
        f"{c} {cx:.6f} {cy:.6f} {w:.6f} {h:.6f}" for c, cx, cy, w, h in rows)
    txt_path.write_text(body + ("\n" if body else ""), encoding="utf-8")
```

### Step 2. ★ VOC(xml) → YOLO(txt)

```python
def voc_to_yolo_file(xml_path, classes, out_txt,
                     skip_difficult=True, img_dir=None):
    """VOC xml 1개 → YOLO txt 1개.  반환: (변환 수, 경고 목록)"""
    xml_path = Path(xml_path)
    root = ET.parse(xml_path).getroot()
    warns = []

    # ── 이미지 크기 ──
    size = root.find("size")
    w = h = None
    if size is not None:
        try:
            w = int(float(size.findtext("width")))
            h = int(float(size.findtext("height")))
        except (TypeError, ValueError):
            w = h = None
    if not w or not h:                       # ★ size 가 0이거나 없는 xml이 실제로 있음
        if img_dir is None:
            raise ValueError(f"{xml_path.name}: 이미지 크기를 알 수 없음")
        p = find_image(img_dir, xml_path.stem)
        if p is None:
            raise FileNotFoundError(f"{xml_path.stem} 이미지 없음")
        w, h = image_size(p)
        warns.append(f"{xml_path.name}: size 태그 이상 → 이미지에서 읽음 ({w}×{h})")

    rows = []
    for obj in root.findall("object"):
        name = (obj.findtext("name") or "").strip()
        difficult = (obj.findtext("difficult") or "0").strip()
        if skip_difficult and difficult == "1":
            warns.append(f"{xml_path.name}: difficult=1 인 '{name}' 제외")
            continue
        if name not in classes:
            warns.append(f"{xml_path.name}: 미정의 클래스 '{name}' 건너뜀")
            continue

        bb = obj.find("bndbox")
        x1 = float(bb.findtext("xmin"))
        y1 = float(bb.findtext("ymin"))
        x2 = float(bb.findtext("xmax"))
        y2 = float(bb.findtext("ymax"))

        if x2 <= x1 or y2 <= y1:             # ★ 좌표가 뒤집힌 xml
            x1, x2 = min(x1, x2), max(x1, x2)
            y1, y2 = min(y1, y2), max(y1, y2)
            warns.append(f"{xml_path.name}: 좌표 역순 → 교정")

        clipped = B.clip_voc((x1, y1, x2, y2), w, h)
        if clipped != (x1, y1, x2, y2):
            warns.append(f"{xml_path.name}: 경계 초과 → clip")
        if clipped[2] - clipped[0] < 1 or clipped[3] - clipped[1] < 1:
            warns.append(f"{xml_path.name}: 크기 0 박스 제외")
            continue

        cx, cy, bw, bh = B.voc_to_yolo(clipped, w, h)
        rows.append((classes.index(name), cx, cy, bw, bh))

    write_yolo(out_txt, rows)                # ★ 객체 0개여도 빈 파일 생성
    return len(rows), warns


def voc_dir_to_yolo(xml_dir, out_dir, classes,
                    img_dir=None, skip_difficult=True):
    xml_dir, out_dir = Path(xml_dir), Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    total, files, all_warns = 0, 0, []
    for xml in sorted(xml_dir.glob("*.xml")):
        n, warns = voc_to_yolo_file(xml, classes, out_dir / (xml.stem + ".txt"),
                                    skip_difficult, img_dir)
        total += n
        files += 1
        all_warns += warns
    return {"파일": files, "박스": total, "경고": all_warns}
```

```python
def yolo_to_voc_file(txt_path, img_path, classes, out_xml):
    """YOLO txt 1개 → VOC xml 1개 (원본 이미지 필요)"""
    txt_path, img_path, out_xml = Path(txt_path), Path(img_path), Path(out_xml)
    w, h = image_size(img_path)

    ann = ET.Element("annotation")
    ET.SubElement(ann, "folder").text = img_path.parent.name
    ET.SubElement(ann, "filename").text = img_path.name
    ET.SubElement(ann, "path").text = str(img_path.resolve())

    size = ET.SubElement(ann, "size")
    ET.SubElement(size, "width").text = str(w)
    ET.SubElement(size, "height").text = str(h)
    ET.SubElement(size, "depth").text = "3"
    ET.SubElement(ann, "segmented").text = "0"

    n = 0
    if txt_path.exists():
        for line in txt_path.read_text(encoding="utf-8").splitlines():
            if not line.strip():
                continue
            parts = line.split()
            cid = int(parts[0])
            yolo = tuple(float(v) for v in parts[1:5])
            x1, y1, x2, y2 = B.to_int(B.clip_voc(B.yolo_to_voc(yolo, w, h), w, h))

            obj = ET.SubElement(ann, "object")
            ET.SubElement(obj, "name").text = classes[cid]
            ET.SubElement(obj, "pose").text = "Unspecified"
            ET.SubElement(obj, "truncated").text = \
                "1" if (x1 <= 0 or y1 <= 0 or x2 >= w or y2 >= h) else "0"
            ET.SubElement(obj, "difficult").text = "0"
            bb = ET.SubElement(obj, "bndbox")
            for tag, v in zip(("xmin", "ymin", "xmax", "ymax"), (x1, y1, x2, y2)):
                ET.SubElement(bb, tag).text = str(v)
            n += 1

    ET.indent(ann, space="  ")               # Python 3.9+ — 보기 좋게 들여쓰기
    out_xml.parent.mkdir(parents=True, exist_ok=True)
    ET.ElementTree(ann).write(out_xml, encoding="utf-8", xml_declaration=True)
    return n
```

```python
def yolo_dir_to_coco(img_dir, lbl_dir, classes, out_json,
                     info_desc="dataset", start_cat_id=1):
    """YOLO 폴더 전체 → COCO json 1개"""
    img_dir, lbl_dir = Path(img_dir), Path(lbl_dir)
    images, annotations = [], []
    categories = [{"id": start_cat_id + i, "name": n, "supercategory": "none"}
                  for i, n in enumerate(classes)]

    img_id, ann_id = 1, 1
    for p in sorted(img_dir.iterdir()):
        if p.suffix.lower() not in IMG_EXTS:
            continue
        w, h = image_size(p)
        images.append({"id": img_id, "file_name": p.name,
                       "width": w, "height": h})

        txt = lbl_dir / (p.stem + ".txt")
        if txt.exists():
            for line in txt.read_text(encoding="utf-8").splitlines():
                if not line.strip():
                    continue
                parts = line.split()
                cid = int(parts[0])
                yolo = tuple(float(v) for v in parts[1:5])
                x, y, bw, bh = B.yolo_to_coco(yolo, w, h)
                annotations.append({
                    "id": ann_id, "image_id": img_id,
                    "category_id": start_cat_id + cid,
                    "bbox": [round(x, 2), round(y, 2), round(bw, 2), round(bh, 2)],
                    "area": round(bw * bh, 2), "iscrowd": 0,
                })
                ann_id += 1
        img_id += 1

    data = {"info": {"description": info_desc, "version": "1.0"},
            "licenses": [], "images": images,
            "annotations": annotations, "categories": categories}
    Path(out_json).parent.mkdir(parents=True, exist_ok=True)
    Path(out_json).write_text(json.dumps(data, ensure_ascii=False, indent=2),
                              encoding="utf-8")
    return {"images": len(images), "annotations": len(annotations),
            "categories": len(categories)}


def coco_to_yolo_dir(json_path, out_dir, classes=None, skip_crowd=True):
    """COCO json → YOLO txt 여러 개.  classes=None 이면 json 순서를 사용"""
    data = json.loads(Path(json_path).read_text(encoding="utf-8"))
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)

    # ★ category_id 는 연속이 아닐 수 있으므로 반드시 매핑을 만든다
    cats = sorted(data["categories"], key=lambda c: c["id"])
    if classes is None:
        classes = [c["name"] for c in cats]
    cat2idx, unknown = {}, set()
    for c in cats:
        if c["name"] in classes:
            cat2idx[c["id"]] = classes.index(c["name"])
        else:
            unknown.add(c["name"])

    imgs = {im["id"]: im for im in data["images"]}
    per_img = {im_id: [] for im_id in imgs}
    skipped_crowd = 0

    for a in data["annotations"]:
        if skip_crowd and a.get("iscrowd", 0) == 1:
            skipped_crowd += 1
            continue
        if a["category_id"] not in cat2idx:
            continue
        im = imgs[a["image_id"]]
        w, h = im["width"], im["height"]
        x, y, bw, bh = a["bbox"]
        voc = B.clip_voc(B.coco_to_voc((x, y, bw, bh)), w, h)
        if voc[2] - voc[0] < 1 or voc[3] - voc[1] < 1:
            continue
        cx, cy, nw, nh = B.voc_to_yolo(voc, w, h)
        per_img[a["image_id"]].append(
            (cat2idx[a["category_id"]], cx, cy, nw, nh))

    for im_id, rows in per_img.items():
        stem = Path(imgs[im_id]["file_name"]).stem
        write_yolo(out_dir / f"{stem}.txt", rows)      # ★ 빈 것도 파일 생성

    (out_dir / "classes.txt").write_text("\n".join(classes) + "\n",
                                         encoding="utf-8")
    return {"이미지": len(imgs),
            "박스": sum(len(v) for v in per_img.values()),
            "빈 이미지": sum(1 for v in per_img.values() if not v),
            "crowd 제외": skipped_crowd,
            "미사용 클래스": sorted(unknown)}
```

```python
from pathlib import Path

IMG_EXTS = (".jpg", ".jpeg", ".png", ".bmp", ".webp")


def check_matching(img_dir, lbl_dir, verbose=True):
    img_dir, lbl_dir = Path(img_dir), Path(lbl_dir)

    imgs, dup_img = {}, []
    for p in img_dir.iterdir():
        if p.suffix.lower() not in IMG_EXTS:
            continue
        key = p.stem.lower()                       # ★ 대소문자 무시로 비교
        if key in imgs:
            dup_img.append((imgs[key].name, p.name))
        imgs[key] = p

    lbls = {p.stem.lower(): p for p in lbl_dir.glob("*.txt")
            if p.stem != "classes"}

    only_img = sorted(set(imgs) - set(lbls))
    only_lbl = sorted(set(lbls) - set(imgs))

    # ── 위험한 파일명 ──
    risky = []
    for p in imgs.values():
        reasons = []
        if p.suffix != p.suffix.lower():
            reasons.append("확장자 대문자")
        if " " in p.name:
            reasons.append("공백")
        if p.name.count(".") > 1:
            reasons.append("점 여러 개")
        if any(ord(c) > 127 for c in p.name):
            reasons.append("비ASCII(한글 등)")
        if reasons:
            risky.append((p.name, ", ".join(reasons)))

    if verbose:
        print("=" * 88)
        print("이미지 ↔ 라벨 매칭 점검")
        print("=" * 88)
```

```python
import shutil
```

```python
def merge_dataset(src_img, src_lbl, src_classes,
                  dst_img, dst_lbl, dst_classes,
                  prefix="", copy=True):
    """다른 데이터셋을 우리 데이터셋에 합친다 (클래스 이름 기준 재매핑)"""
    src_img, src_lbl = Path(src_img), Path(src_lbl)
    dst_img, dst_lbl = Path(dst_img), Path(dst_lbl)
    dst_img.mkdir(parents=True, exist_ok=True)
    dst_lbl.mkdir(parents=True, exist_ok=True)

    # ★ 이름 → 우리 번호. 없는 클래스는 버림
    mapping, dropped = {}, []
    for i, name in enumerate(src_classes):
        if name in dst_classes:
            mapping[i] = dst_classes.index(name)
        else:
            dropped.append(name)

    n_img, n_box, n_drop = 0, 0, 0
    for p in sorted(src_img.iterdir()):
        if p.suffix.lower() not in LC.IMG_EXTS:
            continue
        new_stem = f"{prefix}{p.stem}"
        target_img = dst_img / f"{new_stem}{p.suffix.lower()}"
        if target_img.exists():
            print(f"  ⚠ 이름 충돌, 건너뜀: {target_img.name}")
            continue
        (shutil.copy2 if copy else shutil.move)(str(p), str(target_img))

        rows = []
        txt = src_lbl / (p.stem + ".txt")
        if txt.exists():
            for line in txt.read_text(encoding="utf-8").splitlines():
                if not line.strip():
                    continue
                parts = line.split()
                cid = int(parts[0])
                if cid not in mapping:
                    n_drop += 1
                    continue
                rows.append((mapping[cid], *(float(v) for v in parts[1:5])))
        LC.write_yolo(dst_lbl / f"{new_stem}.txt", rows)
        n_img += 1
        n_box += len(rows)

    return {"이미지": n_img, "박스": n_box,
            "버린 박스": n_drop, "매핑 없는 클래스": dropped}
```


**버그 8 — 출력 폴더가 없으면 실패**

```python

# ✓

```

**버그 9 — 좌표를 `int()` 로 파싱**

```python

x1 = float(bb.findtext("xmin"))           # ✓
```

일부 도구는 실수 좌표를 저장합니다.

### 수정본

```python
import xml.etree.ElementTree as ET
from pathlib import Path

import bbox_utils as B

CLASSES = ["person", "helmet", "box"]
OUT = Path("labels")
OUT.mkdir(parents=True, exist_ok=True)

warns = []
for xml in sorted(Path("voc").glob("*.xml")):
    root = ET.parse(xml).getroot()

    size = root.find("size")
    try:
        w = int(float(size.findtext("width")))
        h = int(float(size.findtext("height")))
    except (AttributeError, TypeError, ValueError):
        w = h = 0
    if not w or not h:
        warns.append(f"{xml.name}: size 없음 → 건너뜀")
        continue

    lines = []
    for obj in root.findall("object"):
        name = (obj.findtext("name") or "").strip()
        if name not in CLASSES:
            warns.append(f"{xml.name}: 미정의 '{name}'")
            continue
        if (obj.findtext("difficult") or "0").strip() == "1":
            continue

        bb = obj.find("bndbox")
        x1, y1 = float(bb.findtext("xmin")), float(bb.findtext("ymin"))
        x2, y2 = float(bb.findtext("xmax")), float(bb.findtext("ymax"))
        x1, x2 = min(x1, x2), max(x1, x2)
        y1, y2 = min(y1, y2), max(y1, y2)
        x1, y1, x2, y2 = B.clip_voc((x1, y1, x2, y2), w, h)
        if x2 - x1 < 1 or y2 - y1 < 1:
            warns.append(f"{xml.name}: 크기 0 박스")
            continue

        cx, cy, bw, bh = B.voc_to_yolo((x1, y1, x2, y2), w, h)
        lines.append(f"{CLASSES.index(name)} {cx:.6f} {cy:.6f} {bw:.6f} {bh:.6f}")

    (OUT / f"{xml.stem}.txt").write_text(
        "\n".join(lines) + ("\n" if lines else ""), encoding="utf-8")

print(f"완료. 경고 {len(warns)}건")
for w_ in warns[:10]:
    print("  ⚠", w_)
```

> **★ 원래 코드는 "잘 정리된 데이터"에서는 동작합니다.**
> 문제는 남의 데이터가 절대 잘 정리되어 있지 않다는 것입니다.
> **변환 스크립트의 절반은 예외 처리입니다.**

```python
from collections import Counter
from pathlib import Path

def dataset_summary(lbl_dir, classes, group_fn=lambda s: s.split("_")[0]):
    per_class, per_group = Counter(), Counter()
    box_group = Counter()
    for p in Path(lbl_dir).glob("*.txt"):
        if p.stem == "classes":
            continue
        g = group_fn(p.stem)
        per_group[g] += 1
        for line in p.read_text(encoding="utf-8").splitlines():
            if line.strip():
                per_class[classes[int(line.split()[0])]] += 1
                box_group[g] += 1
    return per_class, per_group, box_group

pc, pg, bg = dataset_summary("merged/labels", ["person", "helmet", "box"])
print("클래스별:", dict(pc))
print("출처별 이미지:", dict(pg))
print("출처별 박스:", dict(bg))
for g in pg:
    print(f"  {g}: {bg[g]/pg[g]:.2f} 박스/장")
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| YOLO | 이미지 1장 = txt 1개 · **번호** · 정규화 · 크기 정보 **없음** |
| VOC | 이미지 1장 = xml 1개 · **이름** · 픽셀 · `<size>` 있음 |
| COCO | **전체 = json 1개** · images/annotations/categories 3배열 |
| COCO `bbox` | **`[x, y, w, h]`** — VOC 아님 |
| COCO `category_id` | **1부터 · 불연속** — `-1` 금지, 매핑 필수 |
| `difficult` | VOC 태그. 보통 **학습에서 제외** |
| `iscrowd` | COCO 태그. 1이면 **제외** |
| 크기 필요 | **YOLO에서 나가는 변환**만 원본 이미지 필요 |
| 매칭 규칙 | `/images/` → `/labels/`, 확장자 `.txt`, **stem 일치** |
| 폴더명 | 반드시 **`images` / `labels`** |
| 매칭 위험 | 대소문자 · 공백 · **점 여러 개** · 한글 |
| 빈 라벨 | **정상.** 배경 이미지로 학습에 필요 (5~15%) |
| 병합 시 | **이름 기준 재매핑** · 접두사 · 별칭 표 |
| 버린 박스 | 그 자리를 **배경으로 학습**함 — 확인 필수 |
| 검증 | 왕복 비교 + ★ **나란히 그려 보기** |
| 원칙 | 변환은 **항상 새 폴더로** |

**오늘 반드시 기억할 세 가지**
> ① **클래스는 번호가 아니라 이름으로 매핑하세요.** 번호를 그대로 옮기면 사람이 헬멧이 됩니다.
> ② **빈 라벨 파일을 지우지 마세요.** "객체가 없다"는 것도 정보입니다.
> ③ **변환 후에는 반드시 나란히 그려서 확인하세요.** 개수가 같아도 위치가 다를 수 있습니다.
