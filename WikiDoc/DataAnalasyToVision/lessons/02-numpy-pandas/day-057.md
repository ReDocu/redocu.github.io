## ② 왜 필요한가

어제는 **비어 있는 값**을 다뤘습니다. 오늘은 **잘못된 값**입니다.

```python
df["price"].mean()        # 42,318원
df["price"].max()         # 99,999,999원      ← ?
df["price"].min()         # -5,000원          ← ?
```

**결측과 달리 이상치는 "값이 있습니다."** 그래서 더 위험합니다.

| | 결측 | 이상치 |
|---|---|---|
| 눈에 띄나 | `isna()` 로 즉시 | **숨어 있음** |
| 평균에 미치는 영향 | 제외됨 | **끌려감** |
| 발견 시점 | 전처리 초반 | **분석 결과가 이상할 때** |

```
가격 10개 중 9개가 1만원대, 1개가 1억원

평균    = 1,001만원      ← 아무도 이 가격에 사지 않음
중앙값  = 1.2만원        ← 현실
```

**중복도 마찬가지입니다.**

```python
len(df)                            # 5,096건
df["id"].nunique()                 # 4,102건      ← 994건이 중복!
df.groupby("area").size()          # 서울이 1위 — 정말?
```

같은 관광지가 3번씩 들어 있으면, **"서울에 관광지가 많다"는 결론이 틀립니다.**

> **오늘의 핵심 질문은 "지울 것인가"가 아니라 "왜 이런 값이 있는가"입니다.**
> 원인을 모르고 지우면 **진짜 데이터를 버리게 됩니다.**

## 1부 · 중복

### "중복"의 정의를 먼저 정합니다

```python
df.duplicated()                          # 모든 열이 같은 행
df.duplicated(subset=["id"])             # id 가 같은 행
df.duplicated(subset=["name", "area"])   # 이름+지역이 같은 행
```

**같은 데이터인데 정의에 따라 결과가 완전히 달라집니다.**

| 정의 | 중복 건수 | 의미 |
|---|---|---|
| 전체 열 | 12건 | 완전히 똑같은 행 |
| `id` | 994건 | **같은 관광지가 여러 번** |
| `name` + `area` | 1,208건 | 이름·지역이 겹침 (동명 시설 포함) |
| `name` | 1,455건 | 다른 지역 동명 시설까지 포함 ⚠ |

> **정의를 먼저 정하지 않으면 지울 때마다 결과가 달라집니다.**
> 순서는 이렇습니다.
> 1. **이 데이터에서 "하나의 행"이 뜻하는 것은 무엇인가** (관광지 1곳? 방문 1건?)
> 2. 그것을 유일하게 식별하는 열은 무엇인가 → **그게 키**
> 3. 그 키로 중복을 판정한다

### 탐지

```python
df.duplicated().sum()                    # 개수
df[df.duplicated(keep=False)]            # 중복된 행 전부 보기 (원본 포함)
df[df.duplicated(subset=["id"], keep=False)].sort_values("id")   # 비교하기 좋게

df["id"].value_counts()                  # 몇 번씩 나오는지
df["id"].value_counts()[lambda s: s > 1] # 2번 이상만
```

| `keep` | 의미 |
|---|---|
| `"first"` (기본) | 첫 번째를 원본으로 보고, **나머지를 중복으로 표시** |
| `"last"` | 마지막을 원본으로 |
| `False` | **모두 중복으로 표시** ← 눈으로 비교할 때 |

### 제거

```python
df.drop_duplicates()                                  # 완전 중복
df.drop_duplicates(subset=["id"])                     # 키 기준
df.drop_duplicates(subset=["id"], keep="last")        # 나중 것 유지
df.drop_duplicates(subset=["id"], ignore_index=True)  # 인덱스 재설정
```

**어느 것을 남길지 — 정렬이 답입니다**

```python
# 가장 최근 수정본을 남기고 싶다면
df = (df.sort_values("modified")
        .drop_duplicates(subset=["id"], keep="last"))

# 정보가 가장 많은 행을 남기고 싶다면
df["_filled"] = df.notna().sum(axis=1)
df = (df.sort_values("_filled")
        .drop_duplicates(subset=["id"], keep="last")
        .drop(columns="_filled"))
```

> **`drop_duplicates` 는 "먼저 나온 것"을 남깁니다.**
> 그래서 **정렬을 먼저** 하면 원하는 것을 남길 수 있습니다.

### 중복이 생기는 원인 4가지

| 원인 | 증상 | 대응 |
|---|---|---|
| **수집 반복** | 같은 페이지를 여러 번 요청 | 수집 코드 수정 ([Day 053](day-053.md)) |
| **merge 실수** | 병합 후 행 수가 늘어남 | 병합 키 확인 |
| **여러 소스 통합** | 같은 대상이 소스마다 등장 | 키 매칭 후 통합 |
| **데이터 자체** | 실제로 같은 값이 여러 건 | **제거하면 안 됨** |

**merge 로 인한 행 증식 — 매우 흔합니다**

```python
left  = pd.DataFrame({"id": [1, 2], "name": ["A", "B"]})            # 2행
right = pd.DataFrame({"id": [1, 1, 2], "tag": ["x", "y", "z"]})     # 3행

left.merge(right, on="id")      # 3행!  id=1 이 두 번 매칭
```

```python
# ✅ 병합 전에 확인
print(right["id"].duplicated().sum())      # 1  ← 오른쪽에 중복 있음

# ✅ 병합 후 확인
before = len(left)
merged = left.merge(right, on="id")
print(f"{before} → {len(merged)}")         # 늘어났으면 의심

# ✅ 아예 검증을 강제
merged = left.merge(right, on="id", validate="one_to_one")
```

```
MergeError: Merge keys are not unique in right dataset; not a one-to-one merge
```

> **`validate` 를 쓰세요.** `"one_to_one"` `"one_to_many"` `"many_to_one"` 중
> 기대하는 관계를 명시하면, **틀렸을 때 조용히 늘어나는 대신 에러가 납니다.**

### ⚠️ 제거하면 안 되는 중복

```
주문번호  상품     수량
1001     사과     2
1001     바나나   1
1001     사과     3      ← 중복인가?
```

**같은 주문에서 사과를 두 번 담았을 수 있습니다.**
`drop_duplicates(subset=["주문번호", "상품"])` 로 지우면 **수량 3이 사라집니다.**

| 데이터 성격 | 중복 처리 |
|---|---|
| **마스터 데이터** (관광지 목록, 회원 명부) | 키 중복 = 오류 → 제거 |
| **트랜잭션 데이터** (주문, 방문 로그, 클릭) | **반복이 정상** → 제거 금지 |

> **"이 표의 한 행은 무엇인가"를 답할 수 있어야** 중복을 판단할 수 있습니다.

## 2부 · 이상치

### 이상치란

**다른 값들과 동떨어진 값**입니다. 하지만 종류가 다릅니다.

| 종류 | 예 | 처리 |
|---|---|---|
| **오류값** | 나이 999세, 가격 -5,000원 | **제거 또는 수정** |
| **입력 실수** | 12,000 → 120,000 (0 하나 더) | 규칙으로 보정 검토 |
| **단위 혼재** | 가격이 원/천원 섞임 | 단위 통일 |
| **진짜 극단값** | 경복궁 방문객 500만 명 | **보존** ⭐ |

> ⚠️ **"통계적으로 이상하다"와 "잘못됐다"는 다릅니다.**
> 경복궁은 실제로 방문객이 압도적으로 많습니다. 이건 **사실**입니다.
> 지우면 "서울에서 가장 인기 있는 곳"이라는 **가장 중요한 발견이 사라집니다.**

### 탐지 방법 ① IQR

**사분위수 범위(Interquartile Range)** 를 이용합니다.

```
Q1 (25%)          Q2 (50%, 중앙값)          Q3 (75%)
  │                     │                     │
  ├─────────────────────┼─────────────────────┤
  └──── IQR = Q3 - Q1 ──┘

하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR
```

```python
Q1 = df["price"].quantile(0.25)
Q3 = df["price"].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df["price"] < lower) | (df["price"] > upper)]
```

| 계수 | 범위 | 탐지 강도 |
|---|---|---|
| `1.5` | 표준 (박스플롯 기본) | 보통 |
| `3.0` | 극단값만 | 느슨 |
| `1.0` | 많이 잡힘 | 엄격 |

**장점** — 중앙값과 사분위수 기반이라 **이상치 자체에 영향받지 않습니다.**
**단점** — 분포가 심하게 치우치면 한쪽에만 몰려 잡힙니다.

### 탐지 방법 ② z-score

**평균에서 표준편차 몇 배 떨어져 있는가**를 봅니다.

```
z = (x - 평균) / 표준편차
```

```python
z = (df["price"] - df["price"].mean()) / df["price"].std()
outliers = df[z.abs() > 3]
```

| |z| | 정규분포에서 비율 |
|---|---|
| > 2 | 약 4.6% |
| **> 3** | 약 **0.3%** (표준) |
| > 4 | 약 0.006% |

> ⚠️ **z-score 에는 치명적 약점이 있습니다.**
> **평균과 표준편차 자체가 이상치에 끌려갑니다.**
>
> ```python
> data = [10, 12, 11, 13, 10, 12, 9800]
> # 평균 1409.7, 표준편차 3696.5
> # 9800의 z = 2.27  →  |z| > 3 기준으로 안 잡힘!
> ```
> **이상치가 너무 커서 자기를 못 잡는** 역설이 생깁니다.

### 탐지 방법 ③ Modified z-score (MAD)

**중앙값 기반**이라 이상치에 강합니다.

```
MAD = median(|x - median|)
modified z = 0.6745 × (x - median) / MAD
```

```python
median = df["price"].median()
mad = (df["price"] - median).abs().median()
mz = 0.6745 * (df["price"] - median) / mad

outliers = df[mz.abs() > 3.5]
```

```python
data = [10, 12, 11, 13, 10, 12, 9800]
# median=12, MAD=1
# 9800의 modified z = 6602  →  확실히 잡힘  ✅
```

### 탐지 방법 ④ 백분위수

```python
lower = df["price"].quantile(0.01)
upper = df["price"].quantile(0.99)
```

**항상 정해진 비율(2%)만 잡힙니다.** 이상치가 없어도 2%를 잘라 냅니다.
"상위 1%를 특별 취급"처럼 **비율이 목적일 때** 씁니다.

### 탐지 방법 ⑤ 도메인 규칙 — 가장 확실합니다

```python
RULES = {
    "price":    (0, 1_000_000),      # 가격은 음수 불가
    "rating":   (1, 5),              # 평점 범위
    "age":      (0, 120),
    "lat":      (33, 39),            # 한반도 위도
    "lng":      (124, 132),          # 한반도 경도
    "percent":  (0, 100),
}

for col, (lo, hi) in RULES.items():
    if col in df.columns:
        bad = df[(df[col] < lo) | (df[col] > hi)]
        print(f"{col}: 범위 밖 {len(bad)}건")
```

> **통계 기법보다 도메인 규칙이 우선입니다.**
> 평점 7.5는 통계적으로 안 이상해 보여도 **1~5 범위를 벗어난 명백한 오류**입니다.
> 좌표가 (0, 0)이면 아프리카 서쪽 바다입니다. **지오코딩 실패의 전형적 흔적**입니다.

### 방법 비교

| 방법 | 이상치에 강한가 | 정규분포 가정 | 추천 |
|---|---|---|---|
| **도메인 규칙** | ✅ | 불필요 | **가장 먼저** ⭐ |
| **IQR** | ✅ | 불필요 | **기본값** ⭐ |
| z-score | ❌ | **필요** | 정규분포일 때만 |
| Modified z (MAD) | ✅ | 불필요 | 극단값이 클 때 |
| 백분위수 | ✅ | 불필요 | 비율이 목적일 때 |

> **순서: 도메인 규칙 → IQR → (필요하면) MAD**
> z-score 는 데이터가 정규분포에 가깝다는 걸 **확인한 뒤에만** 씁니다.

### 처리 방법 3가지

**① 제거**

```python
df = df[(df["price"] >= lower) & (df["price"] <= upper)]
```
명백한 오류일 때만.

**② 절단 (Winsorize / Clip)**

```python
df["price"] = df["price"].clip(lower, upper)
df["price"] = df["price"].clip(
    df["price"].quantile(0.01), df["price"].quantile(0.99))
```

**행을 유지한 채 값만 경계로 눌러 줍니다.** 데이터 손실이 없습니다.

```
원본   [10, 12, 11, 9800]
제거   [10, 12, 11]           ← 행이 사라짐
절단   [10, 12, 11, 15]       ← 행 유지, 값만 조정  ✅
```

**③ 보존 + 변환**

```python
df["price_log"] = np.log1p(df["price"])     # log(1+x) — 0도 처리 가능
```

**분포를 압축**해 극단값의 영향을 줄입니다. 원본은 그대로 둡니다.

```
원본     10, 100, 1000, 10000, 1000000
log1p    2.4, 4.6, 6.9, 9.2, 13.8         ← 간격이 고르게
```

### 판단 기준

```
① 도메인 규칙 위반인가?  →  예: 오류값. 제거 또는 수정
② 입력 실수로 설명되나?  →  예: 보정 검토 (단위·자릿수)
③ 소수 몇 건인가?        →  예: 제거해도 영향 적음
④ 그 값이 분석의 핵심인가? → 예: 절대 제거 금지 ⭐
⑤ 모델 성능이 목적인가?  →  예: 절단 또는 로그 변환
```

**제거하면 안 되는 대표 사례**

| 상황 | 이상치가 |
|---|---|
| 부정거래 탐지 | **찾으려는 대상 그 자체** |
| 장애 감지 | 이상 신호가 목표 |
| 인기 콘텐츠 분석 | 상위 1%가 매출 대부분 |
| 블랙프라이데이 매출 | 실제로 일어난 사건 |
| 관광지 추천 | **인기 명소가 곧 추천 대상** |

> **W15 여행지 추천 프로젝트를 생각해 보세요.**
> 방문객 수가 이상치인 곳 = **가장 유명한 관광지**입니다.
> 이걸 지우면 추천 시스템이 무명 관광지만 추천합니다.

### Step 1. 중복 진단과 제거

```python
"""중복을 정의별로 진단하고 제거합니다."""

import numpy as np
import pandas as pd

rng = np.random.default_rng(7)

# ── 실습 데이터 ──
base = pd.DataFrame({
    "id": range(1, 101),
    "name": [f"관광지{i:03d}" for i in range(1, 101)],
    "area": rng.choice(["서울", "부산", "제주"], 100),
    "price": rng.integers(0, 30000, 100),
    "rating": rng.normal(4.0, 0.5, 100).round(1).clip(1, 5),
    "modified": pd.date_range("2026-01-01", periods=100, freq="D"),
})

# ① 완전 중복 8건 (같은 페이지를 두 번 수집)
dup_full = base.sample(8, random_state=1)

# ② 같은 id 인데 내용이 조금 다름 12건 (다른 시점에 수집)
dup_partial = base.sample(12, random_state=2).copy()
dup_partial["rating"] = (dup_partial["rating"] + 0.3).clip(1, 5)
dup_partial["modified"] += pd.Timedelta(days=30)

# ③ 이름은 같은데 다른 지역 5건 (동명 시설 — 중복 아님!)
same_name = base.sample(5, random_state=3).copy()
same_name["id"] = range(200, 205)
same_name["area"] = "강원"

df = pd.concat([base, dup_full, dup_partial, same_name], ignore_index=True)

print("=" * 78)
print("                       중복 진단")
print("=" * 78)

print(f"\n[① 정의별 중복 건수]  전체 {len(df)}행")

import numpy as np
import pandas as pd


def text_boxplot(series, width=60, label=""):
    """텍스트 박스플롯을 그립니다."""
    s = series.dropna()
    if len(s) < 4:
        return

    q1, q2, q3 = s.quantile([0.25, 0.5, 0.75])
    iqr = q3 - q1
    lo_fence, hi_fence = q1 - 1.5 * iqr, q3 + 1.5 * iqr

    inliers = s[(s >= lo_fence) & (s <= hi_fence)]
    whisker_lo, whisker_hi = inliers.min(), inliers.max()

    lo, hi = s.min(), s.max()
    span = hi - lo or 1

    def pos(v):
        return int((v - lo) / span * (width - 1))

    line = [" "] * width

    for i in range(pos(whisker_lo), pos(whisker_hi) + 1):
        line[i] = "-"
    for i in range(pos(q1), pos(q3) + 1):
        line[i] = "█"

    line[pos(q2)] = "┃"
    line[pos(whisker_lo)] = "|"
    line[pos(whisker_hi)] = "|"

    for v in s[(s < lo_fence) | (s > hi_fence)]:
        line[pos(v)] = "●"

    n_out = ((s < lo_fence) | (s > hi_fence)).sum()

    print(f"\n  [{label}]")
    print("  " + "".join(line))
    print(f"  {lo:<,.0f}{' ' * max(0, width - len(f'{lo:,.0f}') - len(f'{hi:,.0f}'))}"
          f"{hi:,.0f}")
    print(f"  Q1={q1:,.0f}  중앙값={q2:,.0f}  Q3={q3:,.0f}  IQR={iqr:,.0f}")
    print(f"  울타리: {lo_fence:,.0f} ~ {hi_fence:,.0f}   "
          f"이상치 {n_out}건 ({n_out / len(s) * 100:.1f}%)")


def text_hist(series, bins=20, width=44, label=""):

    for i, c in enumerate(counts):
        bar = "■" * int(c / top * width)
        print(f"  {edges[i]:>10,.0f} ~ {edges[i + 1]:>10,.0f} │{bar} {c}")

### Step 3. 탐지 방법 비교 (오늘의 종합 예제)

```python
"""4가지 탐지 방법을 비교하고 성격별로 처리합니다."""

import numpy as np
import pandas as pd

DOMAIN_RULES = {
    "price": (0, 10_000_000),
    "rating": (1.0, 5.0),
    "visitors": (0, 50_000_000),
    "lat": (33, 39),
    "lng": (124, 132),
}


def detect_iqr(s, k=1.5):
    q1, q3 = s.quantile([0.25, 0.75])
    iqr = q3 - q1
    lo, hi = q1 - k * iqr, q3 + k * iqr
    return (s < lo) | (s > hi), (lo, hi)


def detect_zscore(s, threshold=3.0):
    std = s.std()
    if not std or np.isnan(std):
        return pd.Series(False, index=s.index), (np.nan, np.nan)
    z = (s - s.mean()) / std
    lo, hi = s.mean() - threshold * std, s.mean() + threshold * std
    return z.abs() > threshold, (lo, hi)


def detect_mad(s, threshold=3.5):
    med = s.median()
    mad = (s - med).abs().median()
    if not mad:
        return pd.Series(False, index=s.index), (np.nan, np.nan)
    mz = 0.6745 * (s - med) / mad
    lo, hi = med - threshold * mad / 0.6745, med + threshold * mad / 0.6745
    return mz.abs() > threshold, (lo, hi)


def detect_domain(s, col):
    if col not in DOMAIN_RULES:
        return pd.Series(False, index=s.index), (np.nan, np.nan)
    lo, hi = DOMAIN_RULES[col]
    return (s < lo) | (s > hi), (lo, hi)


def compare_methods(df, cols):
    """탐지 방법별 결과를 비교합니다."""
    print("=" * 84)
    print("                        탐지 방법 비교")
    print("=" * 84)

    summary = []

    for col in cols:
        s = df[col].dropna()

        results = {
            "도메인": detect_domain(s, col),
            "IQR(1.5)": detect_iqr(s, 1.5),
            "IQR(3.0)": detect_iqr(s, 3.0),
            "z-score(3)": detect_zscore(s, 3.0),
            "MAD(3.5)": detect_mad(s, 3.5),
        }

        print(f"\n[{col}]  n={len(s)}  "
              f"평균={s.mean():,.1f}  중앙값={s.median():,.1f}  "
              f"왜도={s.skew():.2f}")
        print(f"  {'방법':<14}{'탐지':>7}{'비율':>8}   {'하한':>14}{'상한':>16}")
        print("  " + "-" * 62)

        for name, (mask, (lo, hi)) in results.items():
            n = mask.sum()
            pct = n / len(s) * 100
            lo_s = f"{lo:,.1f}" if not np.isnan(lo) else "-"
            hi_s = f"{hi:,.1f}" if not np.isnan(hi) else "-"
            print(f"  {name:<14}{n:>7}{pct:>7.1f}%   {lo_s:>14}{hi_s:>16}")

            summary.append({"열": col, "방법": name, "탐지": n, "비율": round(pct, 1)})

        # ── 실제로 잡힌 값 ──
        iqr_mask = results["IQR(1.5)"][0]
        if iqr_mask.any():
            extreme = s[iqr_mask].sort_values(ascending=False).head(5)
            print(f"  IQR 이 잡은 상위 값: {[f'{v:,.0f}' for v in extreme]}")

    print("\n" + "=" * 84)
    return pd.DataFrame(summary)


compare_methods(df, ["price", "rating", "visitors"])

### 중복 정의 없이 `drop_duplicates()`

```python
df.drop_duplicates()          # 한 글자만 달라도 중복이 아님 → 거의 안 지워짐
```

**해결** — 키를 정하고 `subset` 을 지정합니다.

### `subset` 을 너무 넓게

```python
df.drop_duplicates(subset=["name"])       # 다른 지역 동명 시설이 사라짐
```

**해결** — 유일성이 보장되는 최소 조합을 씁니다. (`name` + `area`, 또는 `id`)

### 정렬 없이 제거

```python
df.drop_duplicates(subset=["id"])         # 어느 것이 남을지 알 수 없음
```

**해결** — `sort_values("modified")` 후 `keep="last"`

### 트랜잭션 데이터에서 중복 제거

```python
orders.drop_duplicates(subset=["order_id", "product"])   # 같은 상품 재구매가 삭제
```

**해결** — **"한 행이 무엇인지"** 를 먼저 답합니다.

### merge 후 행 수를 확인하지 않음

```python

```

**해결**

```python
merged = left.merge(right, on="id", validate="one_to_one")
```

### z-score 를 치우친 분포에 사용

```python
z = (df["price"] - df["price"].mean()) / df["price"].std()
df[z.abs() > 3]                            # 극단값 하나가 자기를 숨김
```

**해결** — **IQR 또는 MAD** 를 씁니다.

### 이상치를 무조건 제거

```python
df = df[(df["visitors"] >= lo) & (df["visitors"] <= hi)]   # 인기 관광지가 전멸
```

**해결** — **오류값**과 **진짜 극단값**을 구분합니다.

### 이상치 제거 후 재확인 안 함

제거하면 평균·표준편차가 바뀌어 **새로운 이상치가 생깁니다.**

```python
# 1차 제거 → 재계산 → 또 이상치 → 또 제거 → ...  무한 반복
```

**해결** — **한 번만** 적용하거나, 반복 횟수를 정합니다.

### 도메인 규칙을 안 쓰고 통계만 사용

평점 7.5는 IQR 상한 5.4를 넘지만, **1~5 범위 위반**이라는 게 더 명확한 근거입니다.

**해결** — **도메인 규칙을 가장 먼저** 적용합니다.

### 0을 이상치로 처리

```python
df = df[df["price"] > 0]                   # 무료 관광지가 전부 삭제
```

**해결** — 0의 의미를 확인합니다.

### 원본을 덮어씀

df["price"] = df["price"].clip(lo, hi)     # 원래 값을 영영 알 수 없음
```

**해결** — `df["price_clipped"]` 로 **새 열**을 만듭니다.

### 결측을 먼저 채우고 이상치 탐지

평균으로 채운 값들이 **정중앙에 몰려** IQR을 좁게 만듭니다.

**해결** — **이상치 처리 → 결측 처리** 순서를 권합니다.

import pandas as pd

DOMAIN_RULES = {                                     # ⑥ 실제 범위

import numpy as np
import pandas as pd


def classify_outliers(df, col, domain_range=None, k=1.5,
                      cluster_min=3, verbose=True):

    이상치를 4가지 성격으로 분류합니다.

    반환: DataFrame(index, value, 유형, 근거, 권장처리)

    if len(s) < 10:
        return pd.DataFrame()

    iqr = q3 - q1
    lo_fence, hi_fence = q1 - k * iqr, q3 + k * iqr

    mad = (s - med).abs().median() or 1
    mz = 0.6745 * (s - med) / mad

            kind = "입력 실수 의심"
            reason = f"중앙값의 약 {factor:,.0f}배 — 자릿수 오류 가능"
            action = f"÷{factor:,.0f} 보정 검토 또는 원본 확인"

        # ── ④ 무리를 이루면 진짜 분포 ──
        else:
            neighbors = ((outliers > value * 0.4) & (outliers < value * 2.5)).sum()

            if neighbors >= cluster_min:
                kind = "진짜 극단값"
                reason = f"비슷한 크기 {neighbors}건 — 꼬리 분포의 일부"
                action = "보존 + 플래그 + 로그 변환"
            elif score > 20:
                kind = "고립 극단값"
                reason = f"modified z={score:,.0f} — 홀로 크게 떨어짐"
                action = "원본 확인 필요 — 확인 전 제거 금지"
            else:
                kind = "경계 이상치"
                reason = f"울타리를 조금 벗어남 (z={score:.1f})"
                action = "보존 (절단 시에만 조정)"

        rows.append({
            "index": idx, "값": value, "유형": kind,
            "중앙값대비": round(value / med, 1) if med else np.nan,
            "근거": reason, "권장처리": action,
        })

    result = pd.DataFrame(rows).sort_values("값", ascending=False)

    if verbose:
        print("=" * 92)
        print(f"                  이상치 분류 — {col}")
        print("=" * 92)
        print(f"\n  n={len(s):,}  중앙값={med:,.1f}  IQR={iqr:,.1f}  "
              f"울타리=[{lo_fence:,.1f} ~ {hi_fence:,.1f}]")
        print(f"  이상치 {len(result)}건 ({len(result) / len(s) * 100:.1f}%)")

        if result.empty:
            print("\n  이상치 없음")
            print("=" * 92)
            return result

        print(f"\n  [유형별 집계]")
        for kind, grp in result.groupby("유형", sort=False):
            icon = {"오류값": "🔴", "입력 실수 의심": "🟠",
                    "고립 극단값": "🟡"}.get(kind, "🟢")
            print(f"    {icon} {kind:<16}{len(grp):>4}건   "
                  f"→ {grp['권장처리'].iloc[0]}")

        print(f"\n  [상세 (상위 8건)]")
        print(f"    {'값':>14}{'배수':>8}  {'유형':<14}근거")
        print("    " + "-" * 78)
        for _, r in result.head(8).iterrows():
            print(f"    {r['값']:>14,.0f}{r['중앙값대비']:>7.1f}x  "
                  f"{r['유형']:<14}{r['근거']}")

        print("\n" + "=" * 92)

    return result


if __name__ == "__main__":
    print(">>> price (오류값이 섞임)\n")

```python
"""중복·이상치 처리 검증."""

import numpy as np
import pandas as pd


def validate_cleaning(before, after, key=None, numeric_cols=None,
                      group_col=None, verbose=True):
    """처리가 데이터를 왜곡하지 않았는지 검증합니다."""
    issues = []
    numeric_cols = numeric_cols or [
        c for c in before.columns
        if c in after.columns and pd.api.types.is_numeric_dtype(before[c])
    ]

    line = "=" * 86

    if verbose:
        print(line)
        print("                        중복·이상치 처리 검증")
        print(line)

    # ══════════ ① 규모 ══════════
    loss = (len(before) - len(after)) / len(before) * 100

    if verbose:
        print(f"\n[① 규모]")
        print(f"  행 : {len(before):,} → {len(after):,}  ({loss:+.1f}%)")

    if loss > 20:
        issues.append(("치명", f"행 손실 {loss:.0f}% — 과도한 제거"))
    elif loss > 10:
        issues.append(("경고", f"행 손실 {loss:.0f}%"))

    # ══════════ ② 키 무결성 ══════════
    if key and key in after.columns:
        dup = after[key].duplicated().sum()

        if verbose:
            print(f"\n[② 키 '{key}']")
            print(f"  중복 : {dup}건 {'✓' if dup == 0 else '✗'}")
            print(f"  고유 : {after[key].nunique():,} / {len(after):,}")

        if dup:
            issues.append(("치명", f"키 중복이 남아 있음 {dup}건"))

    # ══════════ ③ 중심·산포 변화 ══════════
    if verbose and numeric_cols:
        print(f"\n[③ 통계량 변화]")
        print(f"  {'열':<16}{'평균Δ%':>10}{'중앙값Δ%':>11}"
              f"{'표준편차Δ%':>12}{'왜도':>9}{'→':>3}{'왜도':>8}")
        print("  " + "-" * 70)

    for col in numeric_cols:
        b, a = before[col].dropna(), after[col].dropna()

        if len(b) < 2 or len(a) < 2:
            continue

        d_mean = (a.mean() - b.mean()) / abs(b.mean()) * 100 if b.mean() else 0
        d_med = (a.median() - b.median()) / abs(b.median()) * 100 if b.median() else 0
        d_std = (a.std() - b.std()) / b.std() * 100 if b.std() else 0

        if verbose:
            print(f"  {col:<16}{d_mean:>9.1f}%{d_med:>10.1f}%{d_std:>11.1f}%"
                  f"{b.skew():>9.2f}{'→':>3}{a.skew():>8.2f}")

        # 중앙값이 크게 변했다 = 데이터의 중심 자체가 이동
        if abs(d_med) > 10:
            issues.append(("치명", f"'{col}' 중앙값 {d_med:+.1f}% 이동 — 분포 왜곡"))

        # 평균만 크게 변한 건 정상 (이상치 제거 효과)
        elif abs(d_mean) > 30 and abs(d_med) < 5:
            if verbose:
                pass          # 정상 — 아래 해석에서 설명
        elif abs(d_mean) > 50:
            issues.append(("경고", f"'{col}' 평균 {d_mean:+.1f}% 변동"))

    # ══════════ ④ 극단값 소실 확인 ══════════
    if verbose:
        print(f"\n[④ 상위값 보존 확인]")

    for col in numeric_cols:
        b, a = before[col].dropna(), after[col].dropna()

        if len(b) < 10:
            continue

        b_top = b.nlargest(max(1, int(len(b) * 0.01)))
        kept = a[a >= b_top.min()].count()
        rate = kept / len(b_top) * 100 if len(b_top) else 100

        mark = "✓" if rate >= 50 else "⚠"

        if verbose:
            print(f"  {mark} {col:<16}상위 1% {len(b_top)}건 중 "
                  f"{kept}건 유지 ({rate:.0f}%)")

        if rate < 30:
            issues.append(("경고",
                           f"'{col}' 상위 1% 중 {100 - rate:.0f}% 소실 "
                           f"— 극단값을 과도하게 제거"))

    # ══════════ ⑤ 그룹 구성 변화 ══════════
    if group_col and group_col in before.columns and group_col in after.columns:
        b = before[group_col].value_counts(normalize=True) * 100
        a = after[group_col].value_counts(normalize=True) * 100
        diff = (a - b).abs()

        if verbose:
            print(f"\n[⑤ '{group_col}' 구성 변화]")
            for g in b.index:
                d = diff.get(g, 0)
                mark = "⚠" if d > 5 else " "
                print(f" {mark}{str(g):<16}{b.get(g, 0):>7.1f}% → "
                      f"{a.get(g, 0):>6.1f}%  ({d:+.1f}%p)")

        if diff.max() > 5:
            worst = diff.idxmax()
            issues.append(("경고",
                           f"'{group_col}' 의 '{worst}' 비율이 "
                           f"{diff.max():.1f}%p 변동 — 편향 제거 의심"))

    # ══════════ 결과 ══════════
    fatal = [i for i in issues if i[0] == "치명"]
    passed = not fatal

    if verbose:
        print(f"\n{line}")
        print(f"  판정: {'✅ 통과' if passed else '❌ 재검토'}"
              f"   (치명 {len(fatal)} · 경고 {len(issues) - len(fatal)})")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} [{level}] {msg}")

        if not issues:
            print("  문제 없음")

        print(f"\n  [해석 가이드]")
        print(f"    평균만 크게 변함        → 이상치 제거 효과 (정상)")
        print(f"    중앙값까지 크게 변함    → 분포 자체가 바뀜 (위험)")
        print(f"    상위 1% 대량 소실       → 극단값 과잉 제거")
        print(f"    특정 그룹만 줄어듦      → 편향된 제거")
        print(line)

    return {"passed": passed, "issues": issues}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    # 나쁜 처리: 이상치를 전부 제거
    bad = df.copy()
    for col in ["price", "visitors"]:
        q1, q3 = bad[col].quantile([0.25, 0.75])
        iqr = q3 - q1
        bad = bad[(bad[col] >= q1 - 1.5 * iqr) & (bad[col] <= q3 + 1.5 * iqr)]

    print(">>> 이상치를 전부 제거한 경우\n")
    validate_cleaning(df, bad, key="id",
                      numeric_cols=["price", "rating", "visitors"],
                      group_col="category")

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 중복 정의 | **"한 행이 무엇인가"** 를 먼저 답한다 |
| 탐지 | `duplicated(subset=[...], keep=False)` |
| 제거 | **정렬 후** `drop_duplicates(subset=키, keep="last")` |
| merge 증식 | `validate="one_to_one"` 로 강제 검증 |
| 트랜잭션 | **반복이 정상** — 제거 금지 |
| 이상치 종류 | 오류값 / 입력 실수 / 단위 혼재 / **진짜 극단값** |
| **도메인 규칙** | 통계보다 **먼저** — 가장 확실 ⭐ |
| **IQR** | `Q1-1.5×IQR ~ Q3+1.5×IQR` — 기본값 ⭐ |
| z-score | **치우친 분포에 쓰면 실패** (자기를 숨김) |
| MAD | 중앙값 기반 — 극단값이 클 때 |
| 처리 | 제거 / **절단(clip)** / 보존+로그변환 |
| 검증 | **평균만 변화 = 정상 · 중앙값까지 변화 = 위험** |

**오늘 반드시 기억할 세 가지**
> ① **중복은 정의가 곧 결과입니다.** 키를 정하지 않고 지우면 매번 다른 결과가 나옵니다.
> ② **탐지와 제거는 다릅니다.** 이상치를 찾았다고 지우는 게 아니라, 먼저 **왜 그런지**를 묻습니다.
> ③ **처리 후 중앙값을 보세요.** 평균만 바뀌었으면 성공, 중앙값까지 바뀌었으면 과잉 제거입니다.

**과제**
① 수집 데이터의 **중복 키를 정의**하고 근거 작성 — "이 표의 한 행은 무엇인가"
② 정의별 중복 건수 비교표 (전체 / 키 / 이름 등)
③ 이상치를 **IQR · z-score · 도메인 규칙** 세 가지로 탐지하고 결과 비교
④ **"제거하면 안 되는 이상치"** 사례를 자기 데이터에서 1건 이상 찾아 근거 서술
⑤ 처리 전후 `describe()` + 왜도 비교표 제출
