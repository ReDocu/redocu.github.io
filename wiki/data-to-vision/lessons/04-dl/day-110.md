| | 팀 A | 팀 B |
|---|---|---|
| 1 | 데이터 로드 | 데이터 로드 |
| 2 | **모델부터 만들어 봄** | 문제 정의서 작성 |
| 3 | 성능이 안 나와서 특성 추가 | EDA |
| 4 | 스케일링 해 봄 | 베이스라인 확보 |
| 5 | 층을 늘려 봄 | 전처리 파이프라인 |
| 6 | 다시 특성 추가 | 분할 (누수 점검) |
| 7 | "왜 안 되지?" | 모델 비교 → 튜닝 |
| 결과 | **무엇이 효과가 있었는지 모름** | **각 단계의 기여를 알고 있음** |

**팀 A의 문제는 실력이 아니라 순서입니다.**
성능이 올라가도 **왜 올라갔는지 모르면** 다음에 재현할 수 없습니다.

### 재현 불가능한 노트북의 실제 비용

```
"교수님, 어제는 R² 0.72가 나왔는데 오늘 다시 돌리니까 0.61이 나옵니다."
```

**원인 후보**

## ③ 개념 설명

### 표준 절차 10단계

```
① 문제 정의     무엇을 예측하는가 · 성공 기준은 무엇인가
② 데이터 확보    어디서 · 얼마나 · 라이선스
③ EDA          타깃부터 · 결측 · 이상치 · 관계
④ 누수 점검     예측 시점 가용성 · 대리 변수 · 중복
⑤ 분할         ★ 전처리보다 먼저. 그룹/시간 고려
⑥ 전처리       Pipeline으로. 학습셋으로만 fit
⑦ 베이스라인    평균 예측 → 선형 → 트리
⑧ 모델링       신경망 포함 후보군 학습
⑨ 검증·튜닝    검증셋으로만. 실험 기록표
⑩ 최종 평가·해석 테스트셋 1회 · 잔차 분석 · 모델 카드
```

### 각 단계의 산출물과 "어기면 생기는 일"

| 단계 | 산출물 | 어기면 |
|---|---|---|
| ① 문제 정의 | 문제 정의서 (타깃·지표·목표치) | **"성능이 좋다"의 기준이 없어 끝을 못 냄** |
| ② 데이터 확보 | 원본 백업 · 컬럼 정의서 | 나중에 데이터가 바뀌어도 모름 |
| ③ EDA | 그래프 8종 이상 · 발견 목록 | 로그 변환·이상치를 놓침 |
| ④ 누수 점검 | 점검표 (체크박스) | **성능이 부풀려진 채 배포** |
| ⑤ 분할 | 학습/검증/테스트 인덱스 | 누수. [Day 109](day-109.md) 전체 |
| ⑥ 전처리 | `Pipeline` 객체 · `joblib` 파일 | **새 데이터에 같은 처리를 못 함** |
| ⑦ 베이스라인 | 성능표 | **개선폭을 말할 수 없음** |
| ⑧ 모델링 | 학습된 모델들 | — |
| ⑨ 검증·튜닝 | 실험 기록표 | 무엇이 효과였는지 모름 |
| ⑩ 최종 평가 | 최종 성능표 · 모델 카드 | 과대 보고 |

> **①과 ⑦을 건너뛰는 팀이 가장 많습니다.** 둘 다 "빨리 모델을 만들고 싶어서" 생략합니다.
> **그런데 이 둘이 없으면 프로젝트가 끝나지 않습니다.** 언제 멈춰야 할지 모르니까요.

### 순서를 바꿔도 되는 것과 안 되는 것

| 관계 | 바꿔도 되나 |
|---|---|
| ③ EDA ↔ ④ 누수 점검 | **가능** (동시에 해도 됨) |
| **⑤ 분할 → ⑥ 전처리** | **절대 불가** ★ |
| ⑦ 베이스라인 ↔ ⑧ 모델링 | 가능하지만 **⑦을 먼저 하는 것을 권장** |
| ⑨ 튜닝 → ⑩ 최종 평가 | **절대 불가** ★ |
| ③ EDA → ⑤ 분할 | **주의** — EDA로 본 것이 판단에 영향 (아래) |

**③ EDA와 ⑤ 분할의 미묘한 관계**

```
EDA를 전체 데이터로 하면?
→ 테스트셋의 분포를 봤습니다
→ "이상치가 있네" → 그걸 보고 처리 방법을 정함
→ 엄밀히는 아주 약한 누수
```

**실무적 타협**

| 접근 | 설명 |
|---|---|
| **엄격** | 분할부터 하고, EDA는 학습셋으로만 |
| **실용** | 전체로 EDA하되, **처리 파라미터(평균·경계값)는 학습셋으로만** 계산 |

> **이 과정에서는 "실용" 쪽을 씁니다.**
> 데이터의 전반적 성격을 파악하는 것까지 막으면 실무가 불가능합니다.
> **중요한 것은 "숫자가 새어 나가지 않는 것"입니다.**
> 이상치가 있다는 사실을 아는 것과, 이상치 경계를 전체 데이터로 계산하는 것은 다릅니다.

| **③ 실행 순서 보장** | 커널 재시작 후 "위에서부터 전체 실행"이 되는가 |

**① 난수 고정 — 세 군데를 다 잡아야 합니다**

```python
import os, random
import numpy as np
import tensorflow as tf

SEED = 42
os.environ["PYTHONHASHSEED"] = str(SEED)
random.seed(SEED)
np.random.seed(SEED)
tf.random.set_seed(SEED)

# 그리고 함수마다 전달
train_test_split(..., random_state=SEED)
RandomForestRegressor(random_state=SEED)
```

> ⚠️ **seed를 고정해도 GPU에서는 완전히 같은 결과가 안 나올 수 있습니다.**
> cuDNN의 일부 연산이 비결정적이기 때문입니다.
> ```python
> tf.config.experimental.enable_op_determinism()     # 느려지지만 완전 결정적
> ```
> **속도를 크게 희생하므로, 최종 결과 재현이 필요할 때만 켜세요.**

### Step 5. 섹션 6 — 전처리 파이프라인과 모델링

```python
# ═══════════════════════════════════════════════════════════════
# 6. 전처리 + 모델링
# ═══════════════════════════════════════════════════════════════
import time

from sklearn.dummy import DummyRegressor
from sklearn.ensemble import HistGradientBoostingRegressor, RandomForestRegressor
from sklearn.linear_model import LinearRegression, RidgeCV
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.pipeline import Pipeline, make_pipeline
from sklearn.preprocessing import StandardScaler


def score(y_true, pred):
    return {
        "MAE": round(mean_absolute_error(y_true, pred), 4),
        "RMSE": round(float(np.sqrt(mean_squared_error(y_true, pred))), 4),
        "R²": round(r2_score(y_true, pred), 4),
    }


# ── 후보 모델: 스케일링이 필요한 것만 Pipeline에 스케일러 포함 ──
candidates = {
    "B0. 평균 예측":     DummyRegressor(strategy="mean"),
    "B1. 중앙값 예측":   DummyRegressor(strategy="median"),
    "M1. 선형 회귀":     make_pipeline(StandardScaler(), LinearRegression()),
    "M2. 릿지 (CV)":     make_pipeline(StandardScaler(),
                                       RidgeCV(alphas=np.logspace(-3, 3, 30))),
    "M3. 랜덤포레스트":  RandomForestRegressor(n_estimators=300, random_state=SEED, n_jobs=-1),
    "M4. HistGB":       HistGradientBoostingRegressor(max_iter=300, random_state=SEED),
}

rows = []
fitted = {}
for name, model in candidates.items():
    t0 = time.perf_counter()
    model.fit(X_train, y_train)
    fit_t = time.perf_counter() - t0

    r = {"모델": name}
    r.update(score(y_val, model.predict(X_val)))
    r["학습(s)"] = round(fit_t, 3)
    rows.append(r)
    fitted[name] = model

# ── 신경망 (별도 처리: 스케일링 + EarlyStopping) ──
from tensorflow import keras
from tensorflow.keras import layers

nn_scaler = StandardScaler().fit(X_train)
Xtr_s, Xva_s = nn_scaler.transform(X_train), nn_scaler.transform(X_val)

tf.random.set_seed(SEED)
nn = keras.Sequential([
    layers.Input(shape=(X_train.shape[1],)),
    layers.Dense(128, activation="relu"),
    layers.Dense(64, activation="relu"),
    layers.Dense(32, activation="relu"),
    layers.Dense(1),
])
nn.compile(optimizer=keras.optimizers.Adam(1e-3), loss="mse", metrics=["mae"])
es = keras.callbacks.EarlyStopping(monitor="val_loss", patience=20, restore_best_weights=True)

t0 = time.perf_counter()
hist = nn.fit(Xtr_s, y_train, validation_data=(Xva_s, y_val),
              epochs=300, batch_size=64, callbacks=[es], verbose=0)
nn_t = time.perf_counter() - t0

r = {"모델": "M5. 신경망 128-64-32"}
r.update(score(y_val, nn.predict(Xva_s, verbose=0).ravel()))
r["학습(s)"] = round(nn_t, 3)
rows.append(r)

# ── 결과표 ──
res = pd.DataFrame(rows)
base = res.loc[res["모델"] == "B0. 평균 예측", "MAE"].iloc[0]
res["개선율(%)"] = ((base - res["MAE"]) / base * 100).round(1)
res["목표달성"] = np.where(res["MAE"] < 0.40, "✓", "")
res = res.sort_values("MAE").reset_index(drop=True)

print("=" * 92)
print("모델 비교 (검증셋) — 목표: MAE < 0.40")
print("=" * 92)
print(res.to_string(index=False))
print("=" * 92)

best_name = res.iloc[0]["모델"]
print(f"검증 최고: {best_name}  MAE {res.iloc[0]['MAE']:.4f}  "
      f"(베이스라인 대비 {res.iloc[0]['개선율(%)']}% 개선)")
print(f"신경망 학습 에폭: {len(hist.history['loss'])} "
      f"(최적 {int(np.argmin(hist.history['val_loss']))+1})")

res.to_csv(ROOT / "experiments" / "model_comparison.csv", index=False, encoding="utf-8-sig")

# ═══════════════════════════════════════════════════════════
# 5~6. 분할 + 모델링   ★ 442행이므로 교차검증 병행
# ═══════════════════════════════════════════════════════════
from sklearn.dummy import DummyRegressor
from sklearn.ensemble import HistGradientBoostingRegressor, RandomForestRegressor
from sklearn.linear_model import LassoCV, RidgeCV
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import KFold, cross_val_score, train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]
y_bins = pd.qcut(y_all, q=5, labels=False, duplicates="drop")

X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)

print(f"학습 {len(X_train)} / 검증 {len(X_val)} / 테스트 {len(X_test)}")
print("★ 검증셋 88건 — 매우 작음. 교차검증을 함께 봅니다.")

def score(yt, p):
    return {"MAE": round(mean_absolute_error(yt, p), 2),
            "RMSE": round(float(np.sqrt(mean_squared_error(yt, p))), 2),
            "R²": round(r2_score(yt, p), 4)}

alphas = np.logspace(-3, 2, 40)
cands = {
    "B0. 평균":    DummyRegressor(strategy="mean"),
    "M1. 릿지CV":  make_pipeline(StandardScaler(), RidgeCV(alphas=alphas)),
    "M2. 라쏘CV":  make_pipeline(StandardScaler(), LassoCV(alphas=alphas, random_state=SEED, max_iter=10000)),
    "M3. RF":     RandomForestRegressor(n_estimators=300, random_state=SEED, n_jobs=-1),
    "M4. HistGB": HistGradientBoostingRegressor(max_iter=200, random_state=SEED),
}

cv = KFold(n_splits=5, shuffle=True, random_state=SEED)
rows = []
for name, m in cands.items():
    m.fit(X_train, y_train)
    r = {"모델": name, **score(y_val, m.predict(X_val))}
    cvs = -cross_val_score(m, X_dev, y_dev, cv=cv, scoring="neg_mean_absolute_error")
    r["CV_MAE"] = round(cvs.mean(), 2)
    r["CV_std"] = round(cvs.std(), 2)
    rows.append(r)

# 신경망 (Day 107: 264행 → 파라미터 목표 80~800 → [16])
from tensorflow import keras
from tensorflow.keras import layers

sc = StandardScaler().fit(X_train)
tf.random.set_seed(SEED)
nn = keras.Sequential([
    layers.Input(shape=(X_train.shape[1],)),
    layers.Dense(16, activation="relu"),
    layers.Dense(1),
])
nn.compile(optimizer=keras.optimizers.Adam(1e-2), loss="mse", metrics=["mae"])
nn.fit(sc.transform(X_train), y_train,
       validation_data=(sc.transform(X_val), y_val),
       epochs=500, batch_size=16,
       callbacks=[keras.callbacks.EarlyStopping(monitor="val_loss", patience=40,
                                                restore_best_weights=True)],
       verbose=0)
rows.append({"모델": f"M5. 신경망[16] ({nn.count_params()}p)",
             **score(y_val, nn.predict(sc.transform(X_val), verbose=0).ravel()),
             "CV_MAE": None, "CV_std": None})

res = pd.DataFrame(rows)
base = res.loc[0, "MAE"]
res["개선율(%)"] = ((base - res["MAE"]) / base * 100).round(1)
res = res.sort_values("MAE")

print("\n" + "=" * 84)
print("모델 비교 — 검증셋(88건)과 5-fold CV(354건)")
print("=" * 84)
print(res.to_string(index=False))
print("=" * 84)
