## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 500줄짜리 게임 파일을 역할별 모듈로 나눌 수 있다.
- 하드코딩된 숫자를 `settings.py` 상수로 옮길 수 있다.
- 리팩터링 전후의 동작이 같은지 검증할 수 있다.

---

## ② 왜 필요한가

W05에서 만든 슈팅게임(`game.py` 520줄)에서 이런 일이 생깁니다.

> "적 스폰 속도를 조금 늦추고 싶은데… 그 숫자가 어디 있었지?"

`Ctrl+F` 로 `45` 를 검색하면 12군데가 나옵니다. 어느 것이 스폰 간격인지 알 수 없습니다.

**하드코딩된 숫자(매직 넘버)의 문제**

```python
if spawn_timer >= 45:          # 45 가 무엇인가?
    ...
self.shoot_timer = 10          # 10 은?
if self.rect.top > 600:        # 600 은?
```

**상수로 바꾸면**

```python
if spawn_timer >= ENEMY_SPAWN_INTERVAL:
    ...
self.shoot_timer = BULLET_COOLDOWN
if self.rect.top > SCREEN_HEIGHT:
```

**밸런스 조정이 `settings.py` 한 파일에서 끝납니다.**
게임 기획자가 코드를 몰라도 숫자만 바꿔 볼 수 있습니다.

오늘 하는 일은 **새 기능을 만드는 것이 아니라 구조를 바꾸는 것**입니다.
이것을 **리팩터링(refactoring)** 이라고 합니다.

---

## ③ 개념 설명

### 리팩터링의 정의

> **동작은 그대로 두고, 내부 구조만 개선하는 것.**

| | 기능 개발 | 리팩터링 |
|---|---|---|
| 동작 | 바뀜 | **똑같아야 함** |
| 목적 | 새 기능 | 읽기·고치기 쉽게 |
| 검증 | 새 기능이 되는가 | **전과 똑같이 되는가** |

> ⚠️ **리팩터링과 기능 추가를 동시에 하지 마세요.**
> 버그가 생겼을 때 구조 변경 때문인지 새 기능 때문인지 알 수 없습니다.
> **한 번에 하나씩** 하고 그때마다 실행해 확인합니다.

### 무엇을 어디에 둘 것인가

| 파일 | 담는 것 | 판단 기준 |
|---|---|---|
| `settings.py` | 숫자·색·문자열 상수 | 값이 바뀔 수 있는 것 |
| `utils.py` | 게임과 무관한 도우미 | 다른 프로젝트에도 쓸 수 있는가 |
| `entities/` | 화면에 보이는 객체 | Sprite 를 상속하는가 |
| `effects/` | 연출 | 게임 규칙과 무관한가 |
| `scenes/` | 화면 전환·입력 처리 | 상태를 관리하는가 |
| `main.py` | 진입점 | 30줄 이내인가 |

### 상수로 뺄 것과 안 뺄 것

**빼야 할 것**

```python
SCREEN_WIDTH = 800              # 화면 크기
PLAYER_SPEED = 6.0              # 밸런스 값
ENEMY_SPAWN_INTERVAL = 45       # 밸런스 값
COLOR_PLAYER = (52, 152, 219)   # 색
BULLET_COOLDOWN = 10            # 밸런스 값
```

**안 빼도 되는 것**

```python
for i in range(3):              # 반복 횟수 (의미가 자명)
    ...
x // 2                          # 절반 (의미가 자명)
alpha = 255                     # 최댓값 (규격상 고정)
```

> **판단 기준** — **"이 숫자를 바꿀 일이 있는가?"** 와 **"이 숫자가 무슨 뜻인지 이름 없이 알 수 있는가?"**
> 둘 중 하나라도 "아니오"면 상수로 뺍니다.

### 리팩터링 순서

```
① 현재 동작을 기록한다      (실행해서 스크린샷·메모)
② 백업한다                 (git commit 또는 파일 복사)
③ 한 가지만 바꾼다          (예: 상수만 분리)
④ 실행해서 확인한다         (①과 같은가?)
⑤ 커밋한다
⑥ ③으로 돌아간다
```

> **각 단계마다 실행하는 것이 핵심입니다.**
> 10가지를 한꺼번에 바꾸고 실행하면, 어디서 깨졌는지 찾는 데 몇 시간이 걸립니다.

### 의존성 주입 — 모듈이 전역 상태를 모르게 하기

```python
# ❌ 나쁨 — 모듈이 전역변수를 직접 참조
# entities/enemy.py
import main                          # 순환 참조!

class Enemy:
    def update(self):
        if self.rect.colliderect(main.player.rect):
            ...
```

```python
# ✅ 좋음 — 필요한 것을 인자로 받음
class Enemy:
    def update(self, target=None):
        if target and self.rect.colliderect(target.rect):
            ...
```

> `Group.update(*args)` 는 **인자를 그대로 모든 스프라이트에 전달**합니다.
> ```python
> enemies.update(player)      # 모든 적의 update(player) 가 호출됨
> ```

### 리소스 경로 처리

```python
# ❌ 실행 위치에 따라 깨짐

```

```python

"""코드로 Surface(그림)를 만드는 함수 모음."""

import math
import pygame

from .settings import (PLAYER_SIZE, COLOR_PLAYER, COLOR_COCKPIT,
                       BULLET_WIDTH, BULLET_HEIGHT, COLOR_BULLET,
                       ENEMY_SIZE, COLOR_ENEMY, ITEM_SIZE, COLOR_ITEM)


def make_ship(size=PLAYER_SIZE, color=COLOR_PLAYER):
    """우주선 모양."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.polygon(surf, color, [
        (size // 2, 0), (size, size), (size // 2, size * 0.78), (0, size),
    ])
    pygame.draw.circle(surf, COLOR_COCKPIT, (size // 2, size // 2), size // 7)
    return surf


def make_bullet(w=BULLET_WIDTH, h=BULLET_HEIGHT, color=COLOR_BULLET):
    """총알 모양."""
    surf = pygame.Surface((w, h), pygame.SRCALPHA)
    pygame.draw.rect(surf, color, (0, 0, w, h), border_radius=3)
    return surf


def make_enemy(size=ENEMY_SIZE, color=COLOR_ENEMY):
    """적 모양 (눈 달린 원)."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, color, (size // 2, size // 2), size // 2)
    pygame.draw.circle(surf, (20, 20, 30), (size // 3, size // 3), size // 10)
    pygame.draw.circle(surf, (20, 20, 30), (size * 2 // 3, size // 3), size // 10)
    return surf


def make_item(size=ITEM_SIZE, color=COLOR_ITEM):
    """회복 아이템 (십자 표시)."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    pygame.draw.circle(surf, color, (size // 2, size // 2), size // 2)
    pygame.draw.rect(surf, (255, 255, 255), (size // 2 - 2, 6, 4, size - 12))
    pygame.draw.rect(surf, (255, 255, 255), (6, size // 2 - 2, size - 12, 4))
    return surf


def make_spike(size, color):
    """뾰족한 별 모양."""
    surf = pygame.Surface((size, size), pygame.SRCALPHA)
    points = []
    for i in range(8):
        angle = math.tau * i / 8
        r = size / 2 if i % 2 == 0 else size / 4
        points.append((size / 2 + r * math.cos(angle),
                       size / 2 + r * math.sin(angle)))
    pygame.draw.polygon(surf, color, points)
    return surf


def load_image(path, size=None, fallback=None):
    """이미지를 불러옵니다. 실패하면 fallback Surface 를 반환합니다."""
    try:
        img = pygame.image.load(str(path)).convert_alpha()
        if size:
            img = pygame.transform.scale(img, size)
        return img
    except (pygame.error, FileNotFoundError):
        print(f"[경고] 이미지를 불러올 수 없습니다: {path}")
        return fallback if fallback is not None else make_ship()


if __name__ == "__main__":
    # 이 모듈만 실행해 그림을 확인할 수 있습니다
    pygame.init()
    screen = pygame.display.set_mode((520, 200))
    pygame.display.set_caption("surfaces.py 미리보기")
    clock = pygame.time.Clock()

    items = [
        ("ship", make_ship(64)),
        ("bullet", make_bullet(12, 36)),
        ("enemy", make_enemy(56)),
        ("item", make_item(48)),
        ("spike", make_spike(56, (230, 126, 34))),
    ]
    font = pygame.font.SysFont("malgungothic", 14)

    running = True
    while running:
        for e in pygame.event.get():
            if e.type == pygame.QUIT:
                running = False

        screen.fill((25, 27, 38))
        for i, (name, surf) in enumerate(items):
            x = 50 + i * 100
            screen.blit(surf, surf.get_rect(center=(x, 80)))
            label = font.render(name, True, (240, 240, 240))
            screen.blit(label, label.get_rect(center=(x, 140)))

        pygame.display.flip()
        clock.tick(60)

    pygame.quit()
```

**`game/entities/base.py`**

```python
"""모든 게임 객체의 공통 부모."""

import pygame

from ..settings import SCREEN_WIDTH, SCREEN_HEIGHT


class Entity(pygame.sprite.Sprite):
    """float 위치를 관리하는 스프라이트 기반 클래스."""

    def __init__(self, x, y, image):
        super().__init__()
        self.image = image
        self.rect = self.image.get_rect(center=(x, y))
        self.pos_x = float(x)
        self.pos_y = float(y)

    def sync_rect(self):
        self.rect.center = (int(self.pos_x), int(self.pos_y))

    def sync_pos(self):
        self.pos_x = float(self.rect.centerx)
        self.pos_y = float(self.rect.centery)

    def clamp_to_screen(self):
        self.rect.clamp_ip(pygame.Rect(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT))
        self.sync_pos()

    def is_out_of_screen(self, margin=0):
        return (self.rect.bottom < -margin
                or self.rect.top > SCREEN_HEIGHT + margin
                or self.rect.right < -margin
                or self.rect.left > SCREEN_WIDTH + margin)

    def kill_if_out(self, margin=0):
        if self.is_out_of_screen(margin):
            self.kill()
            return True
        return False
```

**`game/entities/player.py`**

```python
"""플레이어."""

from .base import Entity
from .bullet import Bullet
from ..surfaces import make_ship
from ..utils import normalize
from ..settings import (PLAYER_SIZE, PLAYER_SPEED, PLAYER_MAX_HP,
                        PLAYER_INVINCIBLE_FRAMES, PLAYER_REVIVE_INVINCIBLE_FRAMES,
                        PLAYER_RADIUS, BULLET_COOLDOWN,
                        COLOR_PLAYER, COLOR_PLAYER_HIT,
                        SCREEN_WIDTH, SCREEN_HEIGHT)

import pygame


class Player(Entity):
    """조종 가능한 우주선."""

    def __init__(self, x, y):
        self.image_normal = make_ship(PLAYER_SIZE, COLOR_PLAYER)
        self.image_hit = make_ship(PLAYER_SIZE, COLOR_PLAYER_HIT)
        super().__init__(x, y, self.image_normal)

        self.speed = PLAYER_SPEED
        self.max_hp = PLAYER_MAX_HP
        self._hp = PLAYER_MAX_HP
        self.invincible_timer = 0
        self.shoot_timer = 0
        self.radius = PLAYER_RADIUS

    # ── 상태 ──
    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, min(value, self.max_hp))

    @property
    def is_alive(self):
        return self._hp > 0

    @property
    def is_invincible(self):
        return self.invincible_timer > 0

    @property
    def can_shoot(self):
        return self.shoot_timer <= 0

    # ── 동작 ──
    def take_damage(self, amount):
        """피해를 입습니다. 무적이면 False."""
        if self.is_invincible:
            return False
        self.hp -= amount
        self.invincible_timer = PLAYER_INVINCIBLE_FRAMES
        return True

    def heal(self, amount):
        before = self._hp
        self.hp += amount
        return self._hp - before

    def revive(self):
        """부활 — 체력 회복 + 긴 무적 + 위치 초기화."""
        self.hp = self.max_hp
        self.invincible_timer = PLAYER_REVIVE_INVINCIBLE_FRAMES
        self.pos_x = float(SCREEN_WIDTH // 2)
        self.pos_y = float(SCREEN_HEIGHT - 70)

    def shoot(self):
        """총알을 반환합니다. 쿨타임 중이면 None."""
        if not self.can_shoot:
            return None
        self.shoot_timer = BULLET_COOLDOWN
        return Bullet(self.rect.centerx, self.rect.top)

    def handle_input(self, keys):
        """키 상태로 이동합니다."""
        dx = dy = 0
        if keys[pygame.K_LEFT] or keys[pygame.K_a]:
            dx -= 1
        if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
            dx += 1
        if keys[pygame.K_UP] or keys[pygame.K_w]:
            dy -= 1
        if keys[pygame.K_DOWN] or keys[pygame.K_s]:
            dy += 1

        dx, dy = normalize(dx, dy)
        self.pos_x += dx * self.speed
        self.pos_y += dy * self.speed

    def update(self):
        if self.shoot_timer > 0:
            self.shoot_timer -= 1
        if self.invincible_timer > 0:
            self.invincible_timer -= 1

        # 무적 중 깜빡임
        self.image = (self.image_hit
                      if self.is_invincible and (self.invincible_timer // 6) % 2 == 0
                      else self.image_normal)

        self.sync_rect()
        self.clamp_to_screen()
```

class Enemy(Entity):
    """기본 적."""

    HP = ENEMY_HP
    SPEED = ENEMY_SPEED
    SCORE = ENEMY_SCORE
    SIZE = ENEMY_SIZE
    COLOR = COLOR_ENEMY
    NAME = "기본"

        super().__init__(x, y, make_enemy(self.SIZE, self.COLOR))
        self.hp = self.HP
        self.max_hp = self.HP
        self.radius = self.SIZE // 2

    def move(self):
        """이동 로직. 자식이 오버라이딩합니다."""
        self.pos_y += self.SPEED

    def update(self):
        self.move()
        self.sync_rect()
        self.kill_if_out()

    def take_damage(self, amount):
        """피해를 입습니다. 죽으면 True."""
        self.hp -= amount
        if self.hp <= 0:
            self.kill()
            return True
        return False

    @classmethod
    def spawn(cls):
        x = random.randint(cls.SIZE, SCREEN_WIDTH - cls.SIZE)
        return cls(x, -cls.SIZE)

"""게임과 무관한 공통 도우미 함수.

이 모듈은 settings 외에 아무것도 import 하지 않으며,

import pygame

from .settings import FONT_NAME, FONT_SIZE_NORMAL


# ══════════ 수학 ══════════

def clamp(value, low, high):
    """값을 low ~ high 범위로 제한합니다."""
    return max(low, min(value, high))


def normalize(dx, dy):
    """방향 벡터를 정규화합니다. (0,0) 이면 (0.0, 0.0)."""
    length = (dx ** 2 + dy ** 2) ** 0.5
    if length == 0:
        return 0.0, 0.0
    return dx / length, dy / length


def distance(x1, y1, x2, y2):
    """두 점 사이의 거리."""
    return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5


def lerp(a, b, t):
    """선형 보간. t=0 이면 a, t=1 이면 b."""
    return a + (b - a) * clamp(t, 0.0, 1.0)


def move_toward(current, target, step):
    """current 를 target 방향으로 step 만큼 이동. 지나치지 않습니다."""
    if abs(target - current) <= step:
        return target
    return current + step * (1 if target > current else -1)


# ══════════ 폰트·텍스트 ══════════

_font_cache = {}


def make_font(size=FONT_SIZE_NORMAL, name=FONT_NAME):
    """폰트를 만듭니다. 같은 설정은 캐싱해 재사용합니다."""
    key = (name, size)
    if key not in _font_cache:
        _font_cache[key] = pygame.font.SysFont(name, size)
    return _font_cache[key]


def draw_text(surface, text, font, color, pos, center=False):
    """텍스트를 그리고 Rect 를 반환합니다."""
    t = font.render(text, True, color)
    rect = t.get_rect(center=pos) if center else t.get_rect(topleft=pos)
    surface.blit(t, rect)
    return rect


def draw_text_lines(surface, lines, font, color, start_pos, line_height=24):
    """여러 줄을 그립니다."""
    x, y = start_pos
    for i, line in enumerate(lines):
        draw_text(surface, line, font, color, (x, y + i * line_height))


# ══════════ 그리기 ══════════

def draw_bar(surface, x, y, w, h, ratio, color, bg_color, border_color=None):
    """진행 바를 그립니다."""
    ratio = clamp(ratio, 0.0, 1.0)
    pygame.draw.rect(surface, bg_color, (x, y, w, h))
    pygame.draw.rect(surface, color, (x, y, int(w * ratio), h))
    if border_color:
        pygame.draw.rect(surface, border_color, (x, y, w, h), 2)


def draw_overlay(surface, alpha=170, color=(0, 0, 0)):
    """화면 전체에 반투명 막을 씌웁니다."""
    o = pygame.Surface(surface.get_size(), pygame.SRCALPHA)
    o.fill((*color, alpha))
    surface.blit(o, (0, 0))


# ══════════ 문자열 ══════════

def format_time(frames, fps=60):
    """프레임 수를 mm:ss 형태로."""
    total_seconds = frames // fps
    return f"{total_seconds // 60:02d}:{total_seconds % 60:02d}"


def format_number(n):
    """천 단위 콤마."""
    return f"{n:,}"


if __name__ == "__main__":

    assert normalize(0, 0) == (0.0, 0.0)

    assert move_toward(10, 11, 3) == 11        # 지나치지 않음

    assert format_number(1234567) == "1,234,567"

원래 코드는 `self.pos_y += -12` 였습니다. pygame의 y축은 아래로 증가하므로 **음수가 위쪽**입니다.

# settings.py
BULLET_SPEED = 12.0            # 크기만 (항상 양수)

class Bullet(Entity):
    DIRECTION = -1             # -1 = 위, +1 = 아래

        ...


class EnemyBullet(Bullet):

②번이 나은 이유는 **적 총알을 만들 때 상수를 하나 더 만들 필요가 없기** 때문입니다.
`BULLET_SPEED` 는 "빠르기"만 나타내고, 방향은 클래스가 정합니다.

**리팩터링 사고를 막는 방법 세 가지**

| 방법 | 설명 |
|---|---|
| **복사·붙여넣기** | 값을 손으로 다시 치지 말고 복사하세요 |
| **한 번에 하나씩** | 상수 하나 옮기고 실행, 또 하나 옮기고 실행 |
| **주석으로 의미 기록** | `BULLET_SPEED = -12.0  # 음수 = 위쪽` |

> **교훈** — 리팩터링에서 **"조금 더 예뻐 보이게" 하려는 충동이 버그의 원인**입니다.
