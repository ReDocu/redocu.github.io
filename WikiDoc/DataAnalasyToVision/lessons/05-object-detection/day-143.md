## ③ 개념 설명

### 라벨링 가이드 6개 절

| 절 | 내용 | 왜 필요한가 |
|---|---|---|
| **1. 목적과 범위** | 프로젝트 목적 · 데이터 출처 · 촬영 조건 | 왜 이 기준인지 이해 |
| **2. 클래스 정의** | 각 클래스의 **조작적 정의** + 시스템 동작 | 무엇을 칠 것인가 |
| **3. 박스 규칙** | 타이트함 · 가림 · 잘림 · 최소 크기 | 어떻게 칠 것인가 |
| **4. ★ 예시 이미지** | 포함 5 / 제외 5 / 경계 5 | **해석의 여지 제거** |
| **5. 경계 사례 결정표** | 애매 사례와 결정·근거 | 판단이 막힐 때 |
| **6. 작업·검수 절차** | 순서 · 도구 설정 · 검수 주기 · 변경 이력 | 운영 |

### ★ 예시 이미지 카드 — 가이드의 핵심

**한 장에 이렇게 담습니다.**

```
┌──────────────────────────────────────────────┐
│  ✓ 포함  #P-03                                │
│  ┌────────────────────┐                      │
│  │                    │   상황:               │
│  │      [박스]        │     앞사람에 가려     │
│  │                    │     머리+어깨만 보임  │
│  └────────────────────┘                      │
│  근거: 어깨선이 보이면 몸통 시작으로 간주      │
│  규칙: 3.2 가림                               │
└──────────────────────────────────────────────┘
```

**카드에 반드시 들어갈 4가지**

```
① 판정 (✓ 포함 / ✗ 제외 / △ 이미지 제외)
② 박스가 그려진 실제 이미지
③ 상황 한 줄
④ ★ 근거 + 해당 규칙 번호
```

> **★ "근거"가 없으면 카드가 아니라 그림입니다.**
> 비슷하지만 다른 상황을 만났을 때, **근거가 있어야 유추**할 수 있습니다.

### 일관성 측정 — 두 가지 숫자

**① 객체 일치율 — "같은 것을 라벨링했는가"**

```
             A가 친 박스 중 B와 매칭되는 것
일치율 = ─────────────────────────────────────
              (A 박스 수 + B 박스 수) / 2

매칭 기준: 같은 클래스 + IoU ≥ 0.5
```

**② 평균 IoU — "얼마나 비슷하게 쳤는가"**

```
매칭된 박스 쌍들의 IoU 평균
```

**두 숫자가 알려 주는 것이 다릅니다.**

| 일치율 | 평균 IoU | 진단 |
|---|---|---|
| 높음 | 높음 | ✓ 기준 통일됨 |
| **낮음** | 높음 | **무엇을 칠지**가 안 맞음 (누락/과잉) |
| 높음 | **낮음** | **어떻게 칠지**가 안 맞음 (타이트함) |
| 낮음 | 낮음 | 가이드가 거의 없는 상태 |

**목표 수치**

```
일치율   ≥ 95%
평균 IoU ≥ 0.85

★ 3인 이상이면 모든 쌍에 대해 측정하고 최솟값을 봅니다
  A-B 0.94, A-C 0.91, B-C 0.72  →  ★ C가 다른 기준
```

### 3인 이상 측정 — Krippendorff 대신 실용적으로

```
학계에는 Fleiss' kappa, Krippendorff's alpha 같은
다중 작업자 일치도 지표가 있습니다.

★ 검출에서는 잘 안 맞습니다
  · 박스는 범주가 아니라 좌표
  · "객체 개수"가 작업자마다 다름

→ 우리는 ★ 쌍별 일치율/IoU의 최솟값을 씁니다
  단순하고, 문제 있는 사람을 바로 지목합니다
```

### 오라벨 자동 탐지 — 통계적 이상치

[Day 140](day-140.md)의 `dataset_check.py` 는 **형식 오류**를 잡습니다.
오늘은 **형식은 맞는데 이상한 라벨**을 잡습니다.

| 검사 | 원리 | 잡아내는 것 |
|---|---|---|
| **종횡비 이상** | 클래스별 정상 범위 | 사람인데 가로로 긴 박스 |
| **크기 이상치** | 클래스별 면적 분포의 극단값 | 실수로 크게/작게 친 것 |
| **위치 이상** | 화면 상단에 사람 전신? | 좌표 실수 |
| **중복** | IoU ≥ 0.9 | 두 번 친 것 |
| **포함 관계** | 박스 A가 B를 완전히 포함 | 클래스 오지정 의심 |
| **밀도 이상** | 장당 박스 수의 극단값 | 누락 또는 과잉 |

**정상 범위를 어떻게 정하는가**

```
방법 ① 사전 지식
    person 종횡비(w/h) : 0.2 ~ 1.2   (서 있으면 0.4, 앉으면 0.9)

방법 ② ★ 데이터에서 학습
    현재 라벨의 분포를 보고 상위/하위 1%를 이상치로
    → 데이터가 늘면 자동으로 기준이 갱신됨
```

> **★ 방법 ②를 권합니다.**
> 프로젝트마다 정상 범위가 다릅니다. 누워 있는 사람을 검출하는 프로젝트라면
> 종횡비 2.0이 정상입니다. **데이터가 기준을 말하게 하세요.**

### Step 1. 예시 이미지 카드 생성기

```python
"""guide_cards.py — 라벨링 가이드용 예시 이미지 카드 생성"""
from pathlib import Path

import cv2

import bbox_utils as B

COLORS = {"include": (60, 200, 60), "exclude": (60, 60, 240),
          "drop": (60, 160, 240)}
MARKS = {"include": "O  INCLUDE", "exclude": "X  EXCLUDE",
         "drop": "!  DROP IMAGE"}


def make_card(img_path, boxes, verdict, card_id, situation, reason, rule,
              out_path, classes=None, cell_w=760):
    """예시 이미지 카드 1장 생성

    boxes: [(cls_id, voc_box, 'include'/'exclude'), ...]
    verdict: 카드 전체 판정 'include' | 'exclude' | 'drop'
    """
    img = cv2.imread(str(img_path))
    if img is None:
        raise FileNotFoundError(img_path)
    h, w = img.shape[:2]
    scale = cell_w / w
    img = cv2.resize(img, (cell_w, int(h * scale)))

    for cls_id, voc, kind in boxes:
        x1, y1, x2, y2 = B.to_int(tuple(v * scale for v in voc))
        color = COLORS[kind]
        if kind == "exclude":
            # 제외 대상은 점선 느낌으로 — 짧은 선분 반복
            for x in range(x1, x2, 14):
                cv2.line(img, (x, y1), (min(x + 7, x2), y1), color, 2)
                cv2.line(img, (x, y2), (min(x + 7, x2), y2), color, 2)
            for y in range(y1, y2, 14):
                cv2.line(img, (x1, y), (x1, min(y + 7, y2)), color, 2)
                cv2.line(img, (x2, y), (x2, min(y + 7, y2)), color, 2)
        else:
            cv2.rectangle(img, (x1, y1), (x2, y2), color, 3)
        if classes and cls_id is not None:
            cv2.putText(img, classes[cls_id], (x1 + 4, max(y1 - 6, 18)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2, cv2.LINE_AA)

    ih = img.shape[0]
    header, footer = 46, 96
    card = cv2.copyMakeBorder(img, header, footer, 16, 16,
                              cv2.BORDER_CONSTANT, value=(250, 250, 250))

    # 헤더
    cv2.rectangle(card, (0, 0), (card.shape[1], header), COLORS[verdict], -1)
    cv2.putText(card, f"{MARKS[verdict]}   {card_id}", (16, 32),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 2, cv2.LINE_AA)

    # 푸터
    y0 = header + ih + 28
    for i, (label, text) in enumerate([("SITUATION", situation),
                                       ("REASON", reason),
                                       ("RULE", rule)]):
        cv2.putText(card, f"{label}: {text[:74]}", (16, y0 + i * 26),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.55, (40, 40, 40), 1, cv2.LINE_AA)

    Path(out_path).parent.mkdir(parents=True, exist_ok=True)
    cv2.imwrite(str(out_path), card)
    return out_path
```

"""consistency.py — 다중 작업자 일관성 측정"""
from itertools import combinations
from pathlib import Path

import numpy as np

import bbox_utils as B

import cv2


def iou(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw, ih = max(0.0, ix2 - ix1), max(0.0, iy2 - iy1)
    inter = iw * ih
    ua = (ax2-ax1)*(ay2-ay1) + (bx2-bx1)*(by2-by1) - inter
    return inter / ua if ua > 0 else 0.0


def load(lbl_dir, stem, w, h):
    """[(cls_id, voc), ...]"""
    p = Path(lbl_dir) / f"{stem}.txt"
    if not p.exists():
        return []
    out = []
    for line in p.read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        parts = line.split()
        out.append((int(parts[0]),
                    B.yolo_to_voc(tuple(float(v) for v in parts[1:5]), w, h)))
    return out


def match(A, Bx, thr=0.5):
    """헝가리안 대신 탐욕 매칭 — 실용적으로 충분"""
    pairs, used = [], set()
    for i, (ca, ba) in enumerate(A):
        best, bj = 0.0, -1
        for j, (cb, bb) in enumerate(Bx):
            if j in used or ca != cb:
                continue
            v = iou(ba, bb)
            if v > best:
                best, bj = v, j
        if best >= thr:
            used.add(bj)
            pairs.append((i, bj, best))
    return pairs, used


def compare_pair(image_dir, dir_a, dir_b, thr=0.5):
    image_dir = Path(image_dir)
    n_a = n_b = n_m = 0
    ious, per_file = [], []

    for p in sorted(image_dir.glob("*.jpg")):
        img = cv2.imread(str(p))
        if img is None:
            continue
        h, w = img.shape[:2]
        A = load(dir_a, p.stem, w, h)
        Bx = load(dir_b, p.stem, w, h)
        pairs, _ = match(A, Bx, thr)
        n_a += len(A); n_b += len(Bx); n_m += len(pairs)
        ious += [v for _, _, v in pairs]
        per_file.append((p.stem, len(A), len(Bx), len(pairs),
                         np.mean([v for _, _, v in pairs]) if pairs else 0.0))

    denom = (n_a + n_b) / 2 or 1
    return {"A": n_a, "B": n_b, "matched": n_m,
            "agree": n_m / denom,
            "iou": float(np.mean(ious)) if ious else 0.0,
            "files": per_file}


def compare_all(image_dir, worker_dirs, thr=0.5):
    names = list(worker_dirs)
    result = {}
    for a, b in combinations(names, 2):
        result[(a, b)] = compare_pair(image_dir, worker_dirs[a],
                                      worker_dirs[b], thr)
    return result


ROOT = Path("C:/vision/day143")
workers = {
    "A": ROOT / "cross/labels_A",
    "B": ROOT / "cross/labels_B",
    "C": ROOT / "cross/labels_C",
}

for (a, b), r in res.items():

from pathlib import Path

import cv2

OUT.mkdir(parents=True, exist_ok=True)

def collect_disagreements(image_dir, workers, thr=0.5):
    """모든 작업자가 동의하지 않은 박스를 추출"""
    image_dir = Path(image_dir)
    records = []

    for p in sorted(image_dir.glob("*.jpg")):
        img = cv2.imread(str(p))
        if img is None:
            continue
        h, w = img.shape[:2]
        labels = {k: load(v, p.stem, w, h) for k, v in workers.items()}

        # 모든 박스를 한 곳에 모아 클러스터링 (IoU 기반)
        allb = [(k, i, cls, box) for k, lst in labels.items()
                for i, (cls, box) in enumerate(lst)]
        used, clusters = set(), []
        for idx, (k, i, cls, box) in enumerate(allb):
            if idx in used:
                continue
            group = [(k, cls, box)]
            used.add(idx)
            for jdx in range(idx + 1, len(allb)):
                if jdx in used:
                    continue
                k2, _, cls2, box2 = allb[jdx]
                if cls2 == cls and iou(box, box2) >= thr:
                    group.append((k2, cls2, box2))
                    used.add(jdx)
            clusters.append(group)

        for g in clusters:
            voters = {k for k, _, _ in g}
            if len(voters) == len(workers):
                continue                                   # 전원 동의
            records.append({
                "file": p.stem, "cls": CLASSES[g[0][1]],
                "voted": "".join(sorted(voters)),
                "missing": "".join(sorted(set(workers) - voters)),
                "box": g[0][2],
            })

        # 시각화
        if any(r["file"] == p.stem for r in records):
            vis = img.copy()
            for k, lst in labels.items():
                for cls, box in lst:
                    x1, y1, x2, y2 = B.to_int(box)
                    off = {"A": 0, "B": 3, "C": 6}[k]

                        cv2.FONT_HERSHEY_SIMPLEX, 0.7, (255, 255, 255), 1, cv2.LINE_AA)
            cv2.imwrite(str(OUT / p.name), vis)

    return records

                        issues.append((a, "포함 관계",
                                       f"{names.get(b['cls'])} 박스에 {c*100:.0f}% 포함"))

    # ── [3] 장당 박스 수 이상 ──
    counts = np.array([len(v) for v in per_file.values()])
    if len(counts) > 10:
        hi = np.quantile(counts, 0.99)
        for key, rows in per_file.items():
            if len(rows) > hi:
                issues.append((rows[0], "박스 과다",
                               f"{len(rows)}개 (상위 1% 기준 {hi:.0f})"))

    return issues, bounds


def _iou(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw, ih = max(0.0, ix2-ix1), max(0.0, iy2-iy1)
    inter = iw * ih
    ua = (ax2-ax1)*(ay2-ay1) + (bx2-bx1)*(by2-by1) - inter
    return inter / ua if ua > 0 else 0.0


def _contain(inner, outer):
    """inner 가 outer 에 얼마나 포함되는가 (0~1)"""
    ix1, iy1 = max(inner[0], outer[0]), max(inner[1], outer[1])
    ix2, iy2 = min(inner[2], outer[2]), min(inner[3], outer[3])
    iw, ih = max(0.0, ix2-ix1), max(0.0, iy2-iy1)
    a = (inner[2]-inner[0]) * (inner[3]-inner[1])
    return (iw * ih / a) if a > 0 else 0.0

def severity(value, lo, hi):
    """정상 범위에서 얼마나 벗어났는가"""
    if lo <= value <= hi:
        return 0
    span = hi - lo
    if value < lo:
        return (lo - value) / span
    return (value - hi) / span

# HIGH  : 2배 이상 벗어남   → 반드시 확인
# MEDIUM: 0.5~2배          → 시간 되면 확인
# LOW   : 0.5배 미만       → 로그만

from sklearn.cluster import KMeans

def adaptive_bounds(values, max_k=3):
    v = np.array(values).reshape(-1, 1)
    if len(v) < 50:
        return [(np.quantile(v, 0.01), np.quantile(v, 0.99))]
    k = min(max_k, max(1, len(v) // 60))
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(v)
    bounds = []
    for c in range(k):
        sub = v[km.labels_ == c]
        bounds.append((float(np.quantile(sub, 0.02)),
                       float(np.quantile(sub, 0.98))))
    return bounds

# 어느 구간에도 안 들어가면 이상치
def is_outlier(value, bounds, margin=0.15):
    return not any(lo * (1-margin) <= value <= hi * (1+margin)
                   for lo, hi in bounds)

```python
def rule_failure_report(golden_dir, test_dir, image_dir, rule_map):
    """불일치를 규칙 번호별로 집계 — 어떤 규칙이 약한지 지목"""
    from collections import Counter
    fails = Counter()
    # golden 라벨의 각 박스에 규칙 태그를 미리 붙여 둔다
    # 예: cam_0042 L3 → "3.2 가림"
    for stem, line, rule in rule_map:
        if not matched(stem, line, test_dir):
            fails[rule] += 1
    return fails
```

대단원 03의 증강        이 단원의 증강
  이미지만 변형     →   ★ 이미지 + 박스 좌표를 함께 변형

**좌우 반전 하나만 봐도**

```python
# 분류
img = cv2.flip(img, 1)                    # 끝

# 검출
img = cv2.flip(img, 1)
cx = 1.0 - cx                             # ★ 박스도 뒤집어야 함
```

**회전·크롭이면 훨씬 복잡해집니다.**

```
회전하면 박스가 기울어지는데, 우리 박스는 축 정렬이어야 함
→ 회전된 네 꼭짓점을 감싸는 새 박스를 계산
→ ★ 박스가 실제보다 커짐
```

그래서 **Albumentations** 를 씁니다. 그리고 **CCTV 특화 증강**을 만듭니다.

```
야간 · 저조도 · 모션 블러 · 비/눈 · 역광
→ 실제 운영 환경을 데이터에 미리 넣습니다
```

> **★ 증강 결과는 반드시 그려서 확인합니다.**
> 박스가 안 따라가면 **정확히 반대로 학습**됩니다.
