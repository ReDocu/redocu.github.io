### 3-1. 베타 빌드

**왜 필요한가** — 배포 가능한 형태.

```
   ★ 알파(Day 110)와의 차이

   알파:  Development Build, 팀 내부
   베타:  Development Build, 외부 배포  ★

```

```
   ★ 베타에 Development Build를 쓰는 이유

   ① 오류가 화면에 보인다
   ② 프로파일러 연결 가능

```

```

   Development Build: ✔
   Autoconnect Profiler: ✗ (외부 배포)
   Compression: LZ4
   치트: 비활성 (기본값 false)
```

```csharp
    // CheatManager
```

```
   ⚠️ 치트를 켜 두면

   테스터가 실수로 누른다
   → 측정이 무의미해진다
```

### 3-6. 피드백 분류

**왜 필요한가** — 전부 반영할 수 없다.

```
   ★ 4가지로 분류

   ① 버그      명백한 오동작
   ② 밸런스    난이도·수치
   ③ UX        조작·안내·가독성
   ④ 개선 제안 "이게 있으면"
```

```
   ★ 반영 판단 (Day 105)
```

| 조건 | 판단 |
|---|---|
| **여러 명이 같은 지점에서 막힘** | **반영** (설계 문제) |
| 한 명의 취향 의견 | 보류 |
| 5분 이내 수정 + 개선 명확 | 반영 |
| **새 기능이 필요함** | **반영하지 않음** (Feature Freeze) |
| 버그 A·B등급 | 반영 |
| 버그 C·D등급 | 시간 되면 |

```
   ★ 개선 제안은 거의 전부 제외

   "보스 패턴을 늘리면"
   "무기를 더 만들면"
   → 새 콘텐츠. W24에 불가
```

```
   2~3명           →  검토

```

```
   ★ 관찰 기록과 대조

   관찰: 5명 중 4명이 같은 곳에서 20초 정지
   → 관찰을 믿는다
```

## 4. 진행 순서

### Step 1 — 베타 빌드

```
   Build Profiles
   Development Build: ✔
   Autoconnect Profiler: ✗
   Compression: LZ4
   Build → Build/beta_v1/
```

```
   ★ 치트 비활성 확인

   CheatManager의 enableCheats = false
```

```
   ★ 오류 표시는 유지

   ErrorDisplay (Day 110)
   → 테스터가 문제를 알려줄 수 있다
```

**✅ 여기까지 하면** — 베타 빌드.

### Step 2 — 자체 확인

**배포 전에 팀이 먼저 확인한다.**

```
   ★ 최소 확인

   [ ] 실행된다
   [ ] 치트가 안 먹는다
   [ ] 완주 가능하다
   [ ] 다른 PC에서 실행된다
```

```
   ⚠️ 여기서 문제가 나오면 배포하지 않는다

   테스터의 시간은 한 번뿐이다
```

**✅ 여기까지 하면** — 배포 가능.

### Step 3 — 패키징

3-2절의 구조로 압축한다.

```
   OneFloor_Beta_v1.zip
   ├─ (빌드 파일 전체)
   └─ 읽어주세요.txt
```

```
   ★ 파일 크기 확인

   200MB 이하면 전달이 쉽다
   → 크면 Day 96의 최적화 검토
```

**✅ 여기까지 하면** — 배포 준비.

### Step 4 — 테스터 배정

3-3절의 구성으로 6명을 확보한다.

```
   ★ 교차 배정

   우리 팀 게임 → 다른 3팀에서 각 2명
```

```
   ★ 관찰자

   각 테스터마다 팀원 1명
   → 4명 팀이면 2명씩 관찰
```

**✅ 여기까지 하면** — 배정 완료.

### Step 5 — 기록지 준비

3-4절의 항목으로 기록지를 만든다.

```markdown
### 질문지
```

### Step 6 — 플레이 테스트 (1인 15분)

3-5절의 규칙을 지키며 관찰한다.

```
   ★ 절차

   ① 읽어주세요.txt만 주고 실행
   ② 타이머 시작
   ③ 관찰 + 기록 (말하지 않는다)
   ④ 완주 또는 15분 경과 시 종료
   ⑤ 질문지 작성
```

```
   ★ 관찰 기록 예

   테스터 3 (게임 경험 적음)

   0:04  타이틀 조작표 읽음 (8초)
   0:15  시작
```
