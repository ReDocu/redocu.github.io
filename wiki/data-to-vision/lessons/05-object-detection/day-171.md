```

  → ★ 이 네 조각이 다 있어야 요구사항입니다
```

**★ 누가(who) 를 먼저 정합니다**

| 이해관계자 | 무엇을 원하는가 | 시스템에서의 접점 |

| 안전 담당자 | 주간 통계를 보고 싶다 | 웹 `/stats` |
| 작업자 | 감시받는 느낌은 싫다 | 안내판 · 얼굴 미저장 |
| 시스템 운영자 | 손 안 대고 돌았으면 | systemd · 자동 정리 |

### 안 D 의 대가 — 매칭 로직

```
        ┌───────────────┐  ← person 박스 (x1,y1,x2,y2)
        │ ▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← ★ head_zone = 상단 30%
        │ ▓  [helmet] ▓ │     helmet 중심이 여기 있으면 → 착용
        ├───────────────┤     없으면 →    미착용
        │               │
        └───────────────┘
```

```python
# ★ Day 175 에 pi/safety.py 로 들어갑니다
def is_unsafe(person_box, helmets, head_ratio=0.30, min_h=80):
    x1, y1, x2, y2 = person_box
    if (y2 - y1) < min_h:
        return None                       # ★ 너무 멀다 — 판정 보류
    if y1 <= 2:
        return None                       # 상단 잘림 — 판정 보류
    head_bottom = y1 + (y2 - y1) * head_ratio
    for hx1, hy1, hx2, hy2 in helmets:
        cx, cy = (hx1 + hx2) / 2, (hy1 + hy2) / 2
        if x1 <= cx <= x2 and y1 <= cy <= head_bottom:
            return False                  # 착용
    return True                           # 미착용
```

★ **"보류"는 "미착용"이 아닙니다.** 이벤트를 만들지 않습니다.

### ④ 오탐률 목표 — ★ 무엇이 더 나쁜지는 주제마다 다릅니다

```
★ 미검출 (False Negative)  실제 미착용자가 지나갔는데 알림이 안 옴 → Recall 하락
오검출 (False Positive)     아무도 없는데 알림 / 착용자를 미착용으로 → Precision 하락
```

| 주제 | 미검출의 대가 | 오검출의 대가 | 우선 지표 | conf |
|---|---|---|---|---|
| **무단 침입 감지** | 도둑을 놓침 (치명적) | 고양이에 알림 (짜증) | **Recall** | 낮게 0.30 |
| **안전모 미착용** | 사고 발생 (치명적) | 헛걸음 1회 | **Recall** | 낮게 0.35 |
| **방문객 카운팅** | 통계가 낮게 나옴 | 통계가 높게 나옴 | **F1 · 편향 없음** | 중간 0.50 |
| **화재 조기 감지** |재난 | 소방차 헛출동(비용 큼) | Recall + 2단계 확인 | 낮게 + 확인 |
| **주차 빈자리** | 빈자리를 못 봄 | 있다고 했는데 없음 | **Precision** | 높게 0.60 |

```
★ B조의 판단
  "미착용자가 사고를 당하는 것" vs "관리자가 헛걸음 한 번 하는 것"
  → 비교 불가. 미검출이 압도적으로 나쁨 → Recall 우선 · conf 0.35
  → 대신 오탐이 늘어나므로 3초 체류 조건으로 억제

★ 반대 예 — 방문객 카운팅은 편향이 없는 것이 중요합니다
  미검출만 많으면 실제보다 적게, 오검출만 많으면 많게
  둘이 비슷하면 오차가 상쇄되어 추세는 맞습니다
  → conf 를 F1 최대 지점으로 (Day 149 스윕)
```

| 항목 | 목표 | 측정 방법 |
|---|---|---|
| **미착용자 감지율** | **20회 중 18회 이상** | 통과 시나리오 20회 |
| 오탐 알림 | **하루 10건 이하** | 24시간 로그 |
| 착용자 오판 | 20회 중 2회 이하 | 착용 통과 20회 |
| 무인 상태 오탐 | **1시간 0건** | 빈 창고 1시간 |

```
★ "하루 10건" 은 어디서 나온 숫자인가
  [Day 154](day-154.md) P-04 의 알림 피로 기준입니다
  하루 10건 = 1.5시간에 1번 → 관리자가 무시하지 않고 볼 수 있는 최대치
  20건이 넘으면 사람은 알림을 끕니다 → 시스템이 무의미해집니다
```

```python
"""tools/topic_matrix.py — 주제 후보 평가 (Day 171)"""
from pathlib import Path

import pandas as pd

Path("docs").mkdir(exist_ok=True)

OPTS = ["①주차장 차량", "②창고 안전 감시", "③무단 침입"]
ROWS = [
    # (기준, 가중치, ①, ②, ③)
    ("난이도 (배운 기술만으로)",   5, 4, 5, 4),
    ("★ 데이터 확보 (내일 500장)", 5, 3, 5, 5),
    ("라벨링 비용",                3, 4, 3, 5),
    ("검출 난도 (객체 크기)",      4, 4, 4, 4),
    ("시연 가능성 (발표장)",        5, 2, 5, 5),
    ("기존 자산 재사용",            5, 1, 5, 3),
    ("주제의 차별성",              3, 3, 4, 2),
    ("사회적 의미 (발표 설득력)",   3, 2, 5, 3),
]
M = pd.DataFrame(ROWS, columns=["기준", "가중치"] + OPTS)

for o in OPTS:
    M[f"{o}_점"] = M[o] * M["가중치"]

print("=" * 92)
print("주제 후보 평가 매트릭스 (1~5점 × 가중치)")
print("=" * 92)
print(M[["기준", "가중치"] + OPTS].to_string(index=False))
print("-" * 92)
scores = {o: int(M[f"{o}_점"].sum()) for o in OPTS}
maxscore = int(M["가중치"].sum()) * 5
print(f"{'가중 합계':<28}{'':>6}" + "".join(f"{scores[o]:>16}" for o in OPTS))
print(f"{'백분율':<28}{'':>6}" +
      "".join(f"{scores[o] / maxscore * 100:>15.0f}%" for o in OPTS))

# 합계보다 최저 점수가 중요합니다
print("\n[최저 점수 항목 — 여기서 프로젝트가 죽습니다]")
for o in OPTS:
    row = M.loc[M[o].idxmin()]
    print(f"  {o:<18} 최저 {row[o]}점  ←  {row['기준']}")

ranked = sorted(scores.items(), key=lambda x: -x[1])
print("\n[순위]")
for i, (o, s) in enumerate(ranked, 1):
    print(f"  {'★' if i == 1 else ' '} {i}위  {o:<18}"
          f"{s:>4}점 ({s / maxscore * 100:.0f}%)")

gap = ranked[0][1] - ranked[1][1]
print(f"\n  1위와 2위 격차: {gap}점")
print("  → " + ("명확한 우위. 확정합니다." if gap >= 10
                else "△ 근소. 다른 기준으로 판단이 필요합니다."))
print("=" * 92)
M.to_csv("docs/topic_matrix.csv", index=False, encoding="utf-8-sig")
```

```python
"""tools/measure_size.py — 파일럿 이미지에서 객체 크기 측정"""
from pathlib import Path

import cv2
import pandas as pd
from ultralytics import YOLO

model = YOLO("yolo11n.pt")          # ★ 사전학습 — 우리 모델이 아직 없음
rows = []
for p in sorted(Path("data/pilot").glob("*.jpg")):
    img = cv2.imread(str(p))
    if img is None:
        print(f"  ! 읽기 실패: {p.name}")
        continue
    h, w = img.shape[:2]
    res = model.predict(img, conf=0.25, classes=[0], verbose=False)[0]
    for b in res.boxes:
        x1, y1, x2, y2 = b.xyxy[0].tolist()
        bh, bw = y2 - y1, x2 - x1
        rows.append({"file": p.name, "img": f"{w}x{h}",
                     "box_w": round(bw), "box_h": round(bh),
                     "area_%": round(bw * bh / (w * h) * 100, 2),
                     "conf": round(float(b.conf), 2),
                     "판정": "O" if bh >= 80 else "✗ 보류"})

if not rows:
    print("person 이 하나도 검출되지 않았습니다 — 각도·거리를 다시 보세요")
else:
    df = pd.DataFrame(rows)
    print("=" * 84)
    print("파일럿 객체 크기 측정")
    print("=" * 84)
    print(df.to_string(index=False))
    print("-" * 84)
    print(f"  person 검출 {len(df)}건")
    print(f"  박스 높이  최소 {df['box_h'].min()}px · "
          f"중앙 {int(df['box_h'].median())}px · 최대 {df['box_h'].max()}px")
    n_ok = int((df["box_h"] >= 80).sum())
    print(f"  판정 가능(80px 이상) {n_ok}/{len(df)} ({n_ok / len(df) * 100:.0f}%)")
    print("""
```
