## 2. 막히는 상황

어제 코드의 전역 변수를 세어 보자.

```cpp
HDC     g_backDC;         HBITMAP g_backBmp;      HBITMAP g_oldBmp;

bool g_useDoubleBuffer;   HWND g_hWnd;            bool g_hasFocus;
// ... 20개 이상 ...
```

**세 가지 문제가 있다.**

**① 재사용이 안 된다**

```
   다음 주에 격투게임을 만들려면?
   → 이 전역 변수 20개와 함수 15개를 전부 복붙

   그리고 슈팅게임을 만들 때 또 복붙
   맵툴 만들 때 또 복붙
   ...

   ★ 그중 하나에서 버그를 고쳐도 나머지는 그대로다
```

**② 어디까지가 엔진이고 어디부터가 게임인지 모른다**

```
   g_backDC     →  엔진 (모든 게임이 필요)
   g_stars      →  게임 (별 데모만 필요)
   g_freq       →  엔진
   g_starCount  →  게임

   ★ 섞여 있어서 분리해서 가져갈 수가 없다
```

**③ 누구나 아무거나 건드릴 수 있다**

```cpp
   g_backDC = NULL;          // 어디서든 가능 → 크래시
   g_clientW = -100;         // 어디서든 가능 → 백버퍼 파괴
```

```
   지금:   전역 변수 20개 + 함수 15개가 한 파일에

   필요:   ① 엔진과 게임을 분리한다
           ② 클래스로 묶어 감춘다
           ③ 다음 게임에서 Engine 폴더만 복사하면 되게 한다
```

> **재사용 가능한 구조가 필요하다.** → **프레임워크**

### 3-1. 프레임워크란 — 라이브러리와의 차이

```
   │                                                           │
   │  내 코드  ──호출──▶  라이브러리                            │
```

### 3-4. ⚠️ `WndProc`을 멤버 함수로 만들기

**왜 필요한가** — `WndProc`은 C 함수 포인터라 멤버 함수를 바로 못 쓴다.

```cpp
    wc.lpfnWndProc = WndProc;          // ✘ 멤버 함수는 안 된다
```

```
   왜 안 되나?

   일반 함수:  LRESULT WndProc(HWND, UINT, WPARAM, LPARAM)
   멤버 함수:  LRESULT Core::WndProc(HWND, UINT, WPARAM, LPARAM)
                            ▲
                            └── 숨겨진 this 포인터가 하나 더 있다 (Day 27)

   → 시그니처가 다르다
```

**해결 — `static` 함수 + 인스턴스 포인터**

```cpp
// Core.cpp
Core* Core::s_instance = nullptr;

Core::Core() { s_instance = this; }

LRESULT CALLBACK Core::WndProcStatic(HWND hWnd, UINT msg, WPARAM w, LPARAM l)
{
    if (s_instance)
        return s_instance->WndProc(hWnd, msg, w, l);       // ★ 멤버로 전달

    return DefWindowProc(hWnd, msg, w, l);
}

LRESULT Core::WndProc(HWND hWnd, UINT msg, WPARAM w, LPARAM l)
{
    switch (msg)
    {
    case WM_SIZE:
        // 여기서는 m_width 같은 멤버를 쓸 수 있다
        return 0;
    }
    return DefWindowProc(hWnd, msg, w, l);
}
```

```cpp
    wc.lpfnWndProc = Core::WndProcStatic;      // ✔ static 함수는 된다
```

```
   ┌─────────────────────────────────────────────────────────┐
   │  Windows  →  WndProcStatic (static, this 없음)          │
   │                    ↓                                     │
   │              s_instance 를 통해                          │
   │                    ↓                                     │
   │              Core::WndProc (멤버, this 있음)            │
   └─────────────────────────────────────────────────────────┘
```

> **더 정석적인 방법** — `CreateWindow`의 마지막 인자로 `this`를 넘기고
> `WM_NCCREATE`에서 `SetWindowLongPtr(hWnd, GWLP_USERDATA, this)`로 저장한다.
> 창이 여러 개일 때 필요하다. **이 과정에서는 창이 하나이므로 `static` 인스턴스로 충분하다.**

### 3-5. `Timer` 클래스

**왜 필요한가** — 시간 관련 코드를 한곳에 모은다.

```cpp
class Timer
{
public:
    void Init();
    void Update();                       // 매 프레임 호출

    double GetDeltaTime() const { return m_deltaTime; }
    double GetTotalTime() const { return m_totalTime; }
    double GetFps()       const { return m_fps; }
    long long GetFrameCount() const { return m_frameCount; }

    void Reset();                        // dt 폭증 방지용

private:
    LARGE_INTEGER m_freq;
    LARGE_INTEGER m_prevCount;

    double    m_deltaTime  = 0.0;
    double    m_totalTime  = 0.0;
    double    m_fps        = 0.0;
    double    m_fpsTimer   = 0.0;
    int       m_fpsCounter = 0;
    long long m_frameCount = 0;
};
```

```cpp
void Timer::Update()
{
    LARGE_INTEGER now;
    QueryPerformanceCounter(&now);

    m_deltaTime = (double)(now.QuadPart - m_prevCount.QuadPart)
                / (double)m_freq.QuadPart;
    m_prevCount = now;

    if (m_deltaTime > 0.1) m_deltaTime = 0.1;

    m_totalTime += m_deltaTime;
    m_frameCount++;

    m_fpsCounter++;
    m_fpsTimer += m_deltaTime;

    if (m_fpsTimer >= 1.0)
    {
        m_fps = m_fpsCounter / m_fpsTimer;
        m_fpsCounter = 0;
        m_fpsTimer = 0.0;
    }
}
```

### 3-7. `Input` 클래스

**왜 필요한가** — Day 23에서 만든 입력 3상태를 그대로 옮긴다.

```cpp
class Input
{
public:
    void Update();                       // 매 프레임 호출

    bool IsKeyPress(int vk) const { return  m_curr[vk]; }
    bool IsKeyDown (int vk) const { return  m_curr[vk] && !m_prev[vk]; }
    bool IsKeyUp   (int vk) const { return !m_curr[vk] &&  m_prev[vk]; }

    POINT GetMousePos() const { return m_mousePos; }
    void  SetMousePos(int x, int y) { m_mousePos.x = x; m_mousePos.y = y; }

private:
    bool  m_curr[256] = { false };
    bool  m_prev[256] = { false };
    POINT m_mousePos  = { 0, 0 };
};

void Input::Update()
{
    for (int i = 0; i < 256; i++)
    {
        m_prev[i] = m_curr[i];
        m_curr[i] = (GetAsyncKeyState(i) & 0x8000) != 0;
    }
}
```

> **Day 23의 코드를 거의 그대로 옮겼다.**
> 콘솔에서 만든 것이 WINAPI에서도 쓰인다.

### 3-8. `Init` / `Release` 역순 원칙

**왜 필요한가** — 순서를 틀리면 크래시하거나 리소스가 샌다.

```cpp
bool Core::Init(...)
{
    if (!CreateGameWindow(...))       return false;      // ①
    if (!m_renderer.Init(m_hWnd, ...)) return false;     // ②
    m_timer.Init();                                       // ③
    m_input.Update();                                     // ④

    m_scene = new StarScene();                            // ⑤
    if (!m_scene->Init(this)) return false;

    m_running = true;
    return true;
}

void Core::Release()
{
    if (m_scene) { m_scene->Release(); delete m_scene; m_scene = nullptr; }   // ⑤
    // ④ Input은 해제할 것 없음
    // ③ Timer도 없음
    m_renderer.Release();                                                      // ②
    if (m_hWnd) { DestroyWindow(m_hWnd); m_hWnd = nullptr; }                  // ①
}
```

```
   생성:  ① → ② → ③ → ④ → ⑤
   해제:  ⑤ → ④ → ③ → ② → ①      ★ 역순

   ★ 나중에 만든 것이 먼저 만든 것에 의존한다
     Renderer는 hWnd가 필요하다 → hWnd보다 먼저 해제해야 한다
```

> **Day 28의 소멸자 호출 순서(자식 → 부모)와 같은 원리다.**

### 3-9. 실패 처리

**왜 필요한가** — 초기화 중간에 실패하면 이미 만든 것을 정리해야 한다.

```cpp
bool Core::Init(...)
{
    if (!CreateGameWindow(...))
        return false;                              // 아직 만든 게 없다

    if (!m_renderer.Init(m_hWnd, m_width, m_height))
    {
        DestroyWindow(m_hWnd);                     // ★ 창은 정리해야 한다
        m_hWnd = nullptr;
        return false;
    }

    // ...
}
```

**더 간단한 방법 — `Release()` 재사용**

```cpp
bool Core::Init(...)
{
    if (!CreateGameWindow(...)) { Release(); return false; }
    if (!m_renderer.Init(...))  { Release(); return false; }
    if (!m_scene->Init(this))   { Release(); return false; }

    m_running = true;
    return true;
}
```

> **`Release()`가 "아직 안 만들어진 것"에 대해서도 안전해야 한다.**
> `if (m_hWnd)`, `if (m_scene)` 같은 검사를 넣어 둔다.

### Step 4 — `Renderer` 클래스

```cpp
// Renderer.cpp
bool Renderer::Init(HWND hWnd, int width, int height)
{
    m_hWnd   = hWnd;
    m_width  = width;
    m_height = height;

    HDC hdc = ::GetDC(hWnd);

    m_backDC  = CreateCompatibleDC(hdc);
    m_backBmp = CreateCompatibleBitmap(hdc, width, height);

    if (!m_backDC || !m_backBmp)
    {
        ::ReleaseDC(hWnd, hdc);
        Release();
        return false;
    }

    m_oldBmp = (HBITMAP)SelectObject(m_backDC, m_backBmp);

    ::ReleaseDC(hWnd, hdc);
    return true;
}

void Renderer::Release()
{
    if (m_backDC)
    {
        if (m_oldBmp) SelectObject(m_backDC, m_oldBmp);
        if (m_backBmp) DeleteObject(m_backBmp);
        DeleteDC(m_backDC);

        m_backDC  = nullptr;
        m_backBmp = nullptr;
        m_oldBmp  = nullptr;
    }
}

void Renderer::Resize(int width, int height)
{
    if (width <= 0 || height <= 0) return;
    if (width == m_width && height == m_height) return;

    HWND hWnd = m_hWnd;
    Release();
    Init(hWnd, width, height);
}
```

```cpp
void Renderer::DrawCircle(int cx, int cy, int r, COLORREF color, bool fill)
{
    HPEN   pen   = CreatePen(PS_SOLID, 1, color);
    HBRUSH brush = fill ? CreateSolidBrush(color)
                        : (HBRUSH)GetStockObject(NULL_BRUSH);

    HPEN   oldPen   = (HPEN)SelectObject(m_backDC, pen);
    HBRUSH oldBrush = (HBRUSH)SelectObject(m_backDC, brush);

    Ellipse(m_backDC, cx - r, cy - r, cx + r, cy + r);

    SelectObject(m_backDC, oldPen);
    SelectObject(m_backDC, oldBrush);
    DeleteObject(pen);
    if (fill) DeleteObject(brush);       // ★ 스톡 오브젝트는 삭제하지 않는다
}

void Renderer::DrawTextF(int x, int y, COLORREF color, const char* fmt, ...)

    vsprintf_s(buf, sizeof(buf), fmt, args);
    va_end(args);

    SetTextColor(m_backDC, color);
    SetBkMode(m_backDC, TRANSPARENT);
    TextOutA(m_backDC, x, y, buf, (int)strlen(buf));
}
```

### Step 5 — `Core` 클래스 (창 + 루프)

```cpp
// Core.cpp
Core* Core::s_instance = nullptr;

Core::Core()
    : m_hWnd(nullptr), m_hInstance(nullptr)
    , m_width(0), m_height(0)
    , m_running(false), m_hasFocus(true)
    , m_scene(nullptr)
{
    s_instance = this;
}

Core::~Core()
{
    Release();
    s_instance = nullptr;
}

bool Core::Init(HINSTANCE hInstance, const char* title,
                int width, int height, int nCmdShow)
{
    m_hInstance = hInstance;
    m_width  = width;
    m_height = height;

    if (!CreateGameWindow(hInstance, title, width, height, nCmdShow))
    {
        Release();
        return false;
    }

    if (!m_renderer.Init(m_hWnd, width, height))
    {
        Release();
        return false;
    }

    m_timer.Init();
    m_input.Update();

    m_running = true;
    return true;
}

void Core::Run()
{
    MSG msg = { 0 };

    while (m_running)
    {
        LARGE_INTEGER frameStart;
        QueryPerformanceCounter(&frameStart);

        // 메시지
        while (PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE))
        {
            if (msg.message == WM_QUIT) { m_running = false; break; }
            TranslateMessage(&msg);
            DispatchMessage(&msg);
        }
        if (!m_running) break;

        // 게임
        m_timer.Update();
        double dt = m_timer.GetDeltaTime();

        ProcessInput();
        Update(dt);
        Render();

        LimitFrameRate(frameStart);
    }
}

void Core::Release()
{
    if (m_scene) { m_scene->Release(); delete m_scene; m_scene = nullptr; }

    m_renderer.Release();

    if (m_hWnd) { DestroyWindow(m_hWnd); m_hWnd = nullptr; }
}
```

### Step 6 — `WndProc` 연결

```cpp
LRESULT CALLBACK Core::WndProcStatic(HWND hWnd, UINT msg, WPARAM w, LPARAM l)
{
    if (s_instance)
        return s_instance->WndProc(hWnd, msg, w, l);
    return DefWindowProc(hWnd, msg, w, l);
}

LRESULT Core::WndProc(HWND hWnd, UINT msg, WPARAM w, LPARAM l)
{
    switch (msg)
    {
    case WM_SIZE:
        {
            int nw = LOWORD(l);
            int nh = HIWORD(l);
            if (nw > 0 && nh > 0)
            {
                m_width  = nw;
                m_height = nh;
                m_renderer.Resize(nw, nh);
            }
        }
        return 0;

    case WM_MOUSEMOVE:
        m_input.SetMousePos(GET_X_LPARAM(l), GET_Y_LPARAM(l));
        return 0;

    case WM_SETFOCUS:  m_hasFocus = true;  m_timer.Reset(); return 0;
    case WM_KILLFOCUS: m_hasFocus = false; return 0;

    case WM_ENTERSIZEMOVE: SetTimer(hWnd, 100, 16, nullptr); return 0;
    case WM_EXITSIZEMOVE:  KillTimer(hWnd, 100); m_timer.Reset(); return 0;

    case WM_TIMER:
        if (w == 100)
        {
            m_timer.Update();
            Update(m_timer.GetDeltaTime());
            Render();
        }
        return 0;

    case WM_ERASEBKGND:
        return 1;

    case WM_PAINT:
        {
            PAINTSTRUCT ps;
            HDC hdc = BeginPaint(hWnd, &ps);
            m_renderer.PresentTo(hdc);
            EndPaint(hWnd, &ps);
        }
        return 0;

    case WM_DESTROY:
        PostQuitMessage(0);
        return 0;
    }

    return DefWindowProc(hWnd, msg, w, l);
}
```

```cpp
    {
        m_core = core;
        m_x = 100; m_y = 100;
        m_vx = 200; m_vy = 150;
        return true;

    {
        m_x += m_vx * dt;
        m_y += m_vy * dt;

        int w = m_core->GetWidth();
        int h = m_core->GetHeight();

        if (m_x < 20)     { m_x = 20;     m_vx = -m_vx; }

        if (m_y < 20)     { m_y = 20;     m_vy = -m_vy; }
        if (m_y > h - 20) { m_y = h - 20; m_vy = -m_vy; }
    }

    void Render(Renderer& r)
    {
        r.DrawCircle((int)m_x, (int)m_y, 20, RGB(255, 100, 100));
    }

    void Release() {}

private:
    Core*  m_core = nullptr;
    double m_x, m_y, m_vx, m_vy;
};
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `wc.lpfnWndProc = WndProc` 오류 | 멤버 함수는 못 쓴다 | `static` 함수 + `s_instance` |
| `s_instance`가 `nullptr` | 생성자에서 대입 누락 | `Core::Core() { s_instance = this; }` |
| 링크 오류 다수 | `.cpp` 파일이 프로젝트에 없음 | 솔루션 탐색기에 추가 |
| `static` 멤버 링크 오류 | `.cpp`에 정의 누락 | `Core* Core::s_instance = nullptr;` |
| 헤더 순환 참조 | A.h ↔ B.h | **전방 선언** `class Core;` |
| `GetDC` 이름 충돌 | 멤버 함수와 Win32 함수 | `::GetDC(...)` |
| 종료 시 크래시 | 해제 순서 오류 | **역순** 확인 |
| `Release`를 두 번 호출 | 소멸자 + 명시적 호출 | `nullptr` 검사로 안전하게 |
| 창 크기 조절 시 깨짐 | `Resize` 미호출 | `WM_SIZE`에서 호출 |
| 스톡 오브젝트 삭제 | `GetStockObject` 결과를 `DeleteObject` | 삭제하지 않는다 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| **프레임워크** | 프레임워크가 내 코드를 불러 준다 (할리우드 원칙) |
| 엔진/게임 분리 | "다른 게임에서도 쓸까?" → 예면 엔진 |
| `Core` 클래스 | 창 + 게임 루프 + 하위 시스템 관리 |
| **`static` WndProc** | 멤버 함수를 못 쓰므로 `static` + 인스턴스 포인터 |
| `Timer` | 델타 타임, FPS, 총 시간 |
| `Renderer` | 백버퍼 + 편의 함수. **GDI 누수 원천 차단** |
| `Input` | 키 3상태 (Day 23의 코드를 그대로) |
| **역순 해제** | 나중에 만든 것을 먼저 지운다 |
| 실패 처리 | `Release()`를 재사용. 부분 초기화 상태에서도 안전하게 |
