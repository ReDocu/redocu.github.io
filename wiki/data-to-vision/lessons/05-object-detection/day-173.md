## ③ 개념 설명

### 학습 소요 시간 역산

**★ 시간을 모르면 일정을 못 짭니다.** 먼저 계산합니다.

```
epoch 당 = ceil(train장수 / batch) × iter시간 + val시간
전체     = epoch당 × epochs + 초기화·캐싱(2~4분) + 최종 평가·플롯(2~3분)
```

**RTX 3060 6GB · `yolo11n` 실측치** ([Day 146](day-146.md) 측정값 재사용)

| imgsz | batch | iter | 416장 1 epoch | 150 epoch | 총 소요 |
|---|---|---|---|---|---|
| 640 | 16 | 0.28s | 26it → 7.3s + val 5s = **12.3s** | 31분 | 약 36분 |
| **960** | **8** | **0.31s** | 52it → 16.1s + val 8s = **24.1s** | **60분** | **약 67분** |
| 1280 | 4 | 0.33s | 104it → 34.3s + val 13s = **47.3s** | 118분 | 약 125분 |

```
★ 우리 선택 — 960 / batch 8 / 150 epoch → 67분

  왜 1280 이 아닌가   125분 → 오후 재학습 불가. 파이 추론도 Day 153 에서 탈락
  왜 640 이 아닌가    36분으로 빠르지만 우리 데이터는 원거리 사람이 많고
                      Day 150 에서 960 이 small Recall +0.28 이었습니다
```

**★ 5 epoch 만 보고 다시 역산합니다** — GPU 가 다르면 위 표는 통째로 바뀝니다.

```
  5/150  2.31G  1.842  2.104  1.213  ...  [00:24<01:00:12]
                                            │       └─ ★ 남은 예상
                                            └─ epoch 소요
  총 소요 ≈ 24초 × 150 + 6분 = 66분
```

### ★ 설정을 코드에 하드코딩하지 않는 것이 오늘 빛을 발합니다

[Day 151](day-151.md) Step 4 에서 `src/train.py` 를 설정 파일 기반으로 바꿨습니다. **오늘 그 이유가 드러납니다.**

```python
# ✗ train.py 안에 직접
model.train(data="...", epochs=150, imgsz=960, batch=8, hsv_v=0.5, degrees=8.0)
```

```
오후에 hsv_v 를 0.7 로, degrees 를 12 로 올린다면

  → "F01 때 hsv_v 가 얼마였지?" → git diff 를 뒤집니다
  → 커밋을 안 했다면 → ★ 영원히 모릅니다
```

```bash
# ✓ 설정 파일이면 — 두 실험의 차이가 한 방에 나옵니다
diff configs/train_f01.yaml configs/train_f02.yaml
```

| 상황 | 하드코딩 | 설정 파일 |
|---|---|---|
| 재학습 | 코드 수정 → 실행 | `--config` 만 교체 |
| 두 실험 비교 | 기억에 의존 | `diff` |
| Git 이력 | 코드 커밋에 섞임 | 설정 커밋이 곧 실험 로그 |
| 재현 | "그때 뭐였더라" | 파일이 그대로 있음 |

> **★ 이 `diff` 출력이 곧 실험 기록입니다.**
> 비교표의 "무엇을 바꿨나" 열을 기억으로 채우면 반드시 틀립니다. **출력을 그대로 붙여 넣으세요.**

### ★ 500장에서 큰 모델을 쓰면 왜 손해인가

**"데이터가 적으니 모델이라도 좋은 걸 쓰자"는 정확히 반대입니다.**

| 모델 | 파라미터 | 파라미터/객체 | 520장에서 | 학습(960) | 파이 NCNN |

| `yolo11m` | 20.1M | 17,034 : 1 | 확실한 과적합 | 232분 | 0.9 FPS ✗ |

```
★ 배울 것보다 외울 공간이 훨씬 많으면 학습 데이터를 통째로 외웁니다

Day 150 Step 2 에서 이미 확인했습니다
  E01 yolo11n 640  0.8214
  E03 yolo11s 640  0.8402   ← +0.019 = 0.9σ. 노이즈와 구분 불가. 속도만 2.3배 손해
```

**★ 그리고 오늘은 시간이 더 중요합니다**

```
yolo11s 를 고르면 오전 121분 → 11:21 종료 → 오후 148분 → ★ 18:00 에 안 끝납니다
                                            → 하루에 한 바퀴를 못 돕니다
```

> **★ 결론 — 데이터가 적을수록 작은 모델을 쓰고, 남는 시간을 데이터에 씁니다.**

### ★ 미검출 상황 분석 — 오늘의 핵심

**"mAP 가 낮다"는 진단이 아닙니다.** 무엇을 못 봤는지 알아야 고칩니다.

```
Recall 0.688 → "68%만 찾았다" → ★ 그래서 뭘 하지?

실패를 이미지로 뽑아 보면
  26건이 화면 끝의 작은 사람 · 17건이 기둥에 반쯤 가림 · 14건이 역광
  → 무엇을 찍어야 할지 즉시 나옵니다
```

```
분석 파이프라인
  ① val 전체 추론          conf 0.001 — 놓친 것까지 보려고
  ② GT 와 IoU 매칭         IoU 0.5 기준 (Day 148)
  ③ 매칭 안 된 GT → 미검출(FN) · 매칭 안 된 예측 → 오검출(FP)
  ④ 특성 계산              크기 · 밝기 · 겹침 · 종횡비 · 위치
  ⑤ 규칙으로 6유형 자동 분류
  ⑥ ★ 크롭 시트 저장 → 눈으로 확인
  ⑦ 유형별 건수표 → 처방 결정
```

**실패 유형 6종 분류표**

| # | 유형 | 판정 규칙 | 눈으로 보면 |
|---|---|---|---|
| **1** | **작은 객체** | 짧은 변 < 40px | 화면 끝, 멀리 있는 사람 |
| **2** | **가림** | GT 끼리 IoU > 0.3 또는 화면 경계에 잘림 | 기둥·다른 사람에 가림 |
| **3** | **역광·저조도** | 박스 평균 밝기 < 60 또는 > 200 | 실루엣만 · 하얗게 날아감 |
| **4** | **특이 자세·각도** | 종횡비가 클래스 중앙값에서 ±50% 이탈 | 앉음 · 엎드림 · 위에서 봄 |
| **5** | **배경 오인** | (FP) GT 와 겹침 없음 | 소화기 · 안전콘을 helmet 으로 |
| **6** | **클래스 혼동** | IoU ≥ 0.5 인데 클래스가 다름 | 모자 ↔ 안전모 |

### ★ "데이터를 더 넣는다"가 항상 답은 아닙니다

|---|---|---|---|---|---|---|

### ★ 부적절한 증강 3가지 사례

**① 상하 반전 — 말이 안 되는 주제**

```
✗ flipud=0.5

  우리는 고정 CCTV 입니다. 사람이 거꾸로 서 있는 장면은 없습니다
  → 학습 데이터의 절반이 존재하지 않는 상황이 됩니다
  → 실제 분포를 배울 기회를 빼앗깁니다

★ 켜도 되는 주제 — 위성·항공 사진, 현미경 이미지 (방향이 무의미)
```

**② 색 변형 — 색이 곧 신호인 주제**

```
✗ hsv_h=0.5 · hsv_s=0.9

  색이 클래스를 결정하는 주제 — 신호등 · 안전조끼 색 · 과일 숙성도 · 배관 색상 코드
  hsv_h 를 크게 주면 빨간 신호가 초록으로 변형되어 학습됩니다
  → 라벨과 픽셀이 모순 → 모델이 색을 무시하도록 학습됩니다

★ 우리 주제 — helmet 은 노랑·흰색·파랑이 섞여 색으로 구분하지 않습니다
             → hsv_h 0.015 는 안전
             → "노란 안전모만 검출" 이 요구사항이면 hsv_h=0 이어야 합니다
```

**③ 과한 회전·왜곡 — 박스가 망가지는 주제**

```
✗ degrees=45 · shear=10 · perspective=0.001

  YOLO 라벨은 축 정렬 박스(AABB)입니다. 회전하면 다시 감싸느라 팽창합니다

     ┌────┐            ┌──────────┐
     │ ▮  │  45도  →   │   ╱▮╲    │   ★ 면적 1.9배 · 배경이 대량 포함
     │ ▮  │            │  ╱   ╲   │
     └────┘            └──────────┘

  → 모델이 "배경도 사람"이라고 배웁니다 → 오검출 증가

★ 안전 범위 — degrees ≤ 15 · shear = 0 · perspective = 0
```

```
★ 증강 점검 체크리스트
  □ 이 변형이 실제로 일어날 수 있는가       □ 박스가 크게 팽창하지 않는가
  □ 변형 후에도 라벨이 여전히 맞는가        □ 눈으로 확인했는가
  □ 클래스를 결정하는 단서를 지우지 않는가
```

### Step 3. `analyze_failures.py` — FN/FP 추출과 6유형 분류

**★ 오늘의 핵심 스크립트입니다.**

```python
"""src/analyze_failures.py — 검증셋 실패 사례 추출·분류·시각화

  ① val 전체 추론(conf 낮게) → ② GT 와 IoU 매칭 → ③ 특성 계산
  → ④ 6유형 자동 분류 → ⑤ 크롭 시트 저장 → ⑥ CSV·요약
"""
import argparse
import csv
from collections import Counter, defaultdict
from pathlib import Path

import cv2
import numpy as np
import yaml
from ultralytics import YOLO

ROOT = Path(__file__).resolve().parents[1]

SMALL_PX = 40      # 짧은 변이 이 값 미만 → '작은 객체'
DARK, BRIGHT = 60, 200      # 박스 평균 밝기 → '역광·저조도'
OCCL_IOU = 0.30    # GT 끼리 이만큼 겹치면 '가림'
EDGE_PX = 12       # 화면 경계에 붙으면 '잘림' → 가림으로 취급
AR_TOL = 0.50      # 종횡비가 클래스 중앙값 대비 ±50% 이탈 → '특이 자세'
IOU_MATCH = 0.50   # TP 판정 (Day 148 기준)
FP_CONF = 0.25     # 운영 임계값 미만의 예측은 오검출로 세지 않음
HIGH_CONF = 0.60   # 이보다 확신하는 FP 는 라벨 누락을 의심

KINDS = ["작은 객체", "가림", "역광·저조도", "특이 자세",
         "배경 오인", "클래스 혼동", "라벨 누락 의심", "미분류"]
COLORS = {"작은 객체": (0, 200, 255), "가림": (255, 140, 0),
          "역광·저조도": (200, 0, 255), "특이 자세": (0, 255, 200),
          "배경 오인": (0, 0, 255), "클래스 혼동": (255, 0, 120),
          "라벨 누락 의심": (120, 255, 0), "미분류": (160, 160, 160)}


def iou(a, b):
    ix1, iy1 = max(a[0], b[0]), max(a[1], b[1])
    ix2, iy2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0.0, ix2 - ix1) * max(0.0, iy2 - iy1)
    ua = ((a[2]-a[0])*(a[3]-a[1]) + (b[2]-b[0])*(b[3]-b[1]) - inter)
    return inter / ua if ua > 0 else 0.0


def load_gt(txt, w, h):
    p = Path(txt)
    if not p.exists():
        return []
    out = []
    for line in p.read_text(encoding="utf-8").splitlines():
        if line.strip():
            c, cx, cy, bw, bh = (float(v) for v in line.split()[:5])
            out.append((int(c), ((cx-bw/2)*w, (cy-bh/2)*h,
                                 (cx+bw/2)*w, (cy+bh/2)*h)))
    return out


def features(img, box, others, W, H):
    x1, y1, x2, y2 = box
    bw, bh = max(x2 - x1, 1), max(y2 - y1, 1)
    crop = img[max(0, int(y1)):min(H, int(y2)), max(0, int(x1)):min(W, int(x2))]
    return {"short": float(min(bw, bh)),
            "area_pct": float(bw * bh / (W * H) * 100),
            "bright": float(crop.mean()) if crop.size else 0.0,
            "overlap": max([iou(box, o) for o in others], default=0.0),
            "edge": bool(min(x1, y1, W - x2, H - y2) < EDGE_PX),
            "ar": float(bh / bw)}


def classify_fn(f, ar_med):
    """★ 미검출 유형 — 우선순위 순서대로 판정"""
    if f["overlap"] >= OCCL_IOU or f["edge"]:
        return "가림"
    if f["bright"] < DARK or f["bright"] > BRIGHT:
        return "역광·저조도"
    if f["short"] < SMALL_PX:
        return "작은 객체"
    if ar_med > 0 and abs(f["ar"] - ar_med) / ar_med > AR_TOL:
        return "특이 자세"
    return "미분류"


def crop_of(img, box, W, H, pad_ratio=0.45):
    x1, y1, x2, y2 = box
    pad = int(max(x2 - x1, y2 - y1) * pad_ratio) + 8
    c = img[max(0, int(y1)-pad):min(H, int(y2)+pad),
            max(0, int(x1)-pad):min(W, int(x2)+pad)]
    return c if c.size else np.full((180, 180, 3), 35, np.uint8)


def make_sheet(items, path, cols=6, cell=180):
    if not items:
        return None
    cells = []
    for img, kind, tag in items:
        c = cv2.resize(img, (cell, cell))
        cv2.rectangle(c, (0, 0), (cell-1, cell-1), COLORS[kind], 4)
        cv2.rectangle(c, (0, cell-22), (cell, cell), (0, 0, 0), -1)
        cv2.putText(c, tag[:22], (4, cell-7), cv2.FONT_HERSHEY_SIMPLEX,
                    0.42, (255, 255, 255), 1, cv2.LINE_AA)
        cells.append(c)
    while len(cells) % cols:
        cells.append(np.full((cell, cell, 3), 35, np.uint8))
    rows = [cv2.hconcat(cells[i:i+cols]) for i in range(0, len(cells), cols)]
    cv2.imwrite(str(path), cv2.vconcat(rows))
    return path


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--weights", required=True)
    ap.add_argument("--data", required=True)
    ap.add_argument("--split", default="val")
    ap.add_argument("--conf", type=float, default=0.001)
    ap.add_argument("--out", default="docs/failures")
    ap.add_argument("--sheet-limit", type=int, default=36)
    args = ap.parse_args()

    dcfg = yaml.safe_load((ROOT / args.data).read_text(encoding="utf-8"))
    names = dcfg["names"]
    img_dir = Path(dcfg["path"]) / dcfg[args.split]
    lbl_dir = Path(str(img_dir).replace("images", "labels"))
    out = ROOT / args.out
    out.mkdir(parents=True, exist_ok=True)
    model = YOLO(ROOT / args.weights)

    # 클래스별 종횡비 중앙값 (특이 자세 판정 기준)
    ar = defaultdict(list)
    for p in lbl_dir.glob("*.txt"):
        for l in p.read_text(encoding="utf-8").splitlines():
            if l.strip():
                v = l.split()
                ar[int(float(v[0]))].append(float(v[4]) / max(float(v[3]), 1e-6))
    ar_med = {k: float(np.median(v)) for k, v in ar.items()}

    kinds, rows, crops = Counter(), [], defaultdict(list)
    n_gt = n_pred = n_tp = 0
    images = sorted(p for p in img_dir.glob("*.*")
                    if p.suffix.lower() in (".jpg", ".jpeg", ".png"))

    for p in images:
        img = cv2.imread(str(p))
        if img is None:
            print(f"읽기 실패: {p.name}")
            continue
        H, W = img.shape[:2]
        gt = load_gt(lbl_dir / (p.stem + ".txt"), W, H)
        r = model(str(p), conf=args.conf, iou=0.7, verbose=False)[0]
        pred = [(int(b.cls), tuple(float(v) for v in b.xyxy[0].tolist()),
                 float(b.conf)) for b in r.boxes]
        pred.sort(key=lambda x: -x[2])          # conf 내림차순 매칭 (Day 148)
        n_gt += len(gt)
        n_pred += len(pred)

        used_g, used_p, confuse = set(), set(), []

        # ① 같은 클래스 매칭 = TP
        for gi, (gc, gb) in enumerate(gt):
            best, bj = 0.0, -1
            for j, (pc, pb, _) in enumerate(pred):
                if j in used_p or pc != gc:
                    continue
                v = iou(gb, pb)
                if v > best:
                    best, bj = v, j
            if best >= IOU_MATCH:
                used_g.add(gi); used_p.add(bj); n_tp += 1

        # ② 위치는 맞는데 이름이 다름 = 클래스 혼동
        for gi, (gc, gb) in enumerate(gt):
            if gi in used_g:
                continue
            for j, (pc, pb, pconf) in enumerate(pred):
                if j not in used_p and pc != gc and iou(gb, pb) >= IOU_MATCH:
                    used_g.add(gi); used_p.add(j)
                    confuse.append((gi, j, gc, pc, pconf))
                    break

        others = {gi: [b for k, (_, b) in enumerate(gt) if k != gi]
                  for gi in range(len(gt))}

        for gi, j, gc, pc, pconf in confuse:
            f = features(img, gt[gi][1], others[gi], W, H)
            kinds["클래스 혼동"] += 1
            rows.append(dict(file=p.name, fail="혼동", kind="클래스 혼동",
                             cls=names[gc], pred_cls=names[pc],
                             conf=round(pconf, 3), **f))
            crops["클래스 혼동"].append((crop_of(img, gt[gi][1], W, H),
                                        "클래스 혼동", f"{names[gc]}→{names[pc]}"))

        # ③ 미검출 (FN)
        for gi, (gc, gb) in enumerate(gt):
            if gi in used_g:
                continue
            f = features(img, gb, others[gi], W, H)
            kind = classify_fn(f, ar_med.get(gc, 0.0))
            kinds[kind] += 1
            rows.append(dict(file=p.name, fail="미검출", kind=kind,
                             cls=names[gc], pred_cls="", conf=0.0, **f))
            crops[kind].append((crop_of(img, gb, W, H), kind,
                                f"{names[gc]} {int(f['short'])}px"))

        # ④ 오검출 (FP)
        gtb = [b for _, b in gt]
        for j, (pc, pb, pconf) in enumerate(pred):
            if j in used_p or pconf < FP_CONF:
                continue
            f = features(img, pb, gtb, W, H)
            kind = "라벨 누락 의심" if pconf >= HIGH_CONF else "배경 오인"
            kinds[kind] += 1
            rows.append(dict(file=p.name, fail="오검출", kind=kind, cls="",
                             pred_cls=names[pc], conf=round(pconf, 3), **f))
            crops[kind].append((crop_of(img, pb, W, H), kind,
                                f"{names[pc]} {pconf:.2f}"))

    with (out / "failures.csv").open("w", newline="", encoding="utf-8-sig") as f:
        w = csv.DictWriter(f, fieldnames=list(rows[0].keys()))
        w.writeheader(); w.writerows(rows)

    sheets = []
    for kind, items in crops.items():
        pth = make_sheet(items[:args.sheet_limit],
                         out / f"sheet_{kind.replace('·','_')}.jpg")
        if pth:
            sheets.append((kind, len(items), pth))

    total = sum(kinds.values())
    print("=" * 80)
    print(f"실패 분석 — {Path(args.weights).name}  ({args.split} {len(images)}장)")
    print("=" * 80)
    print(f"  정답 {n_gt}개 · 예측 {n_pred}개 · 매칭(TP) {n_tp}개 · "
          f"Recall(IoU0.5) {n_tp/max(n_gt,1):.3f}")
    print("-" * 80)
    print(f"{'유형':<15}{'건수':>7}{'비율':>9}   막대")
    print("-" * 80)
    for k in KINDS:
        n = kinds.get(k, 0)
        if n:
            print(f"{k:<15}{n:>7}{n/max(total,1)*100:>8.1f}%   "
                  f"{'█'*int(n/max(total,1)*50)}")
    print("-" * 80)
    print(f"{'합계':<15}{total:>7}\n\n[시트]")
    for kind, n, pth in sorted(sheets, key=lambda x: -x[1]):
        print(f"  {kind:<15}{n:>4}건  {pth.name}")
    print(f"\n[CSV] {out/'failures.csv'}")
    print("=" * 80)
    print("★ 시트를 열어서 자동 분류가 맞는지 눈으로 확인하세요.")


if __name__ == "__main__":
    main()
```

```python
"""scripts/compare_runs.py — 기준선을 동일 검증셋에서 다시 잽니다"""
import argparse
import subprocess
from pathlib import Path

import yaml
from ultralytics import YOLO

ROOT = Path(__file__).resolve().parents[1]


def evaluate(weights, data, imgsz=960):
    r = YOLO(ROOT / weights).val(data=str(ROOT / data), imgsz=imgsz,
                                 split="val", plots=False, verbose=False)
    per = {int(ci): dict(P=float(r.box.p[i]), R=float(r.box.r[i]),
                         AP50=float(r.box.ap50[i]), AP=float(r.box.ap[i]))
           for i, ci in enumerate(r.box.ap_class_index)}
    return dict(mAP50=float(r.box.map50), mAP50_95=float(r.box.map),
                P=float(r.box.mp), R=float(r.box.mr), per=per)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--a-weights", required=True)
    ap.add_argument("--b-weights", required=True)
    ap.add_argument("--a-data", required=True, help="A 의 원본 데이터 설정")
    ap.add_argument("--eval-data", required=True, help="공통 평가용 설정")
    ap.add_argument("--a-name", default="F01")
    ap.add_argument("--b-name", default="F02")
    ap.add_argument("--a-config", default="configs/train_f01.yaml")
    ap.add_argument("--b-config", default="configs/train_f02.yaml")
    args = ap.parse_args()

    names = yaml.safe_load(
        (ROOT / args.eval_data).read_text(encoding="utf-8"))["names"]
    bar = lambda v: "█" * int(v * 22)               # noqa: E731

    print("=" * 80)
    print(f"실험 비교 — {args.a_name} vs {args.b_name}")
    print("=" * 80)
    print("\n[0] 설정 차이 (★ 이것이 '무엇을 바꿨나' 의 정답입니다)")
    d = subprocess.run(["diff", str(ROOT / args.a_config),
                        str(ROOT / args.b_config)],
                       capture_output=True, text=True, encoding="utf-8")
    for line in (d.stdout or "(동일)").splitlines():
        if line.startswith(("<", ">")):
            print("    " + line)

    a_orig = evaluate(args.a_weights, args.a_data)
    print(f"\n[1] 원본 검증셋 기준 (참고용)  {args.a_name} mAP50 "
          f"{a_orig['mAP50']:.4f}")

    a = evaluate(args.a_weights, args.eval_data)
    b = evaluate(args.b_weights, args.eval_data)
    print(f"\n[2] ★ 공통 검증셋 기준 ({Path(args.eval_data).name})")
    print("-" * 80)
    print(f"{'지표':<11}{args.a_name:>10}{args.b_name:>10}{'차이':>10}"
          f"{'변화율':>10}   막대")
    print("-" * 80)
    for k in ("mAP50", "mAP50_95", "P", "R"):
        dv = b[k] - a[k]
        print(f"{k:<11}{a[k]:>10.4f}{b[k]:>10.4f}{dv:>+10.4f}"
              f"{dv/max(a[k],1e-9)*100:>+9.1f}%   {bar(b[k])}")

    for title, key in (("[3] 클래스별 AP50", "AP50"), ("[4] 클래스별 Recall", "R")):
        print(f"\n{title}")
        print("-" * 80)
        for ci in sorted(names):
            av = a["per"].get(ci, {}).get(key, 0.0)
            bv = b["per"].get(ci, {}).get(key, 0.0)
            print(f"{names[ci]:<11}{av:>10.3f}{bv:>10.3f}{bv-av:>+10.3f}"
                  f"   {bar(bv)}")
    print("=" * 80)


if __name__ == "__main__":
    main()
```
