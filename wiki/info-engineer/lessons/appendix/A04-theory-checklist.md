# A4 · 실기 핵심 이론 체크리스트

> [부록 목차](README.md) · 근거 강: [11](../04-core-theory/lesson-11.md)·[12](../04-core-theory/lesson-12.md)강 (+10강 DB 이론)
> 사용법: "설명→용어" 방향으로 즉답되면 체크. 막히면 근거 강으로. 수료 요건([16강](../05-exam-prep/lesson-16.md))의 자가 점검표입니다.

## SW 공학 (중요도 상)

- [ ] 기능 vs 비기능 요구사항을 사례로 판정 (숫자·품질 단어 = 비기능)
- [ ] 요구사항 개발 절차: 도출→분석→명세→확인
- [ ] UML 구조/행위 분류 + 클래스·유스케이스·시퀀스의 시험 표현
- [ ] UML 관계: 연관·집합(◇)·복합(◆)·일반화(▷)·의존·실체화
- [ ] GoF 3분류 (생성 5: 싱팩추빌프 / 구조 7 / 행위 11)
- [ ] 패턴 8종 설명→용어: 싱글턴·옵서버·어댑터·스트래티지·퍼사드·프로토타입·템플릿 메서드·프록시
- [ ] 테스트 레벨: 단위→통합→시스템→인수 (알파=개발 환경, 베타=사용자 환경)
- [ ] 블랙박스(동등 분할·경계값) vs 화이트박스(커버리지)
- [ ] 커버리지 강도: 구문 < 결정(분기) < 조건 계열 (구문 100% ≠ 분기 100%)
- [ ] 하향식-스텁 / 상향식-드라이버
- [ ] 결합도 6단계 (자스제외공내, 낮→높) + 사례 판정
- [ ] 응집도 7단계 (기순통절시논우, 높→낮) + 사례 판정
- [ ] 팬인(호출받음)/팬아웃(호출함)

## 네트워크 (중요도 상)

- [ ] OSI 7계층 이름 (물데네전세표응) + 데이터 단위 (비트-프레임-패킷-세그먼트)
- [ ] 짝짓기 3핵심: IP=3(패킷·라우터) / TCP·UDP=4(세그먼트) / 스위치·MAC=2(프레임)
- [ ] TCP(연결·신뢰) vs UDP(비연결·속도)
- [ ] 응용 프로토콜: HTTP·FTP·SMTP·DNS·DHCP·SNMP
- [ ] IPv4 32비트 / IPv6 128비트

## 보안 (중요도 상)

- [ ] 보안 3요소: 기밀성·무결성·가용성 (침해 사례 판정)
- [ ] 대칭키(AES·SEED·ARIA·DES) / 비대칭키(RSA·ECC) / 해시(SHA·MD5 — 단방향)
- [ ] 공격 용어 11종 설명→용어 (인젝션·XSS·CSRF·DoS/DDoS·SYN 플러딩·스니핑·스푸핑·피싱/파밍·랜섬웨어·브루트 포스·APT)
- [ ] IDS(탐지) vs IPS(방지), 방화벽, VPN
- [ ] 접근 통제: DAC·MAC·RBAC

## 운영체제 (중요도 중)

- [ ] 프로세스(실행 중인 프로그램) vs 스레드(내부 실행 단위)
- [ ] 상태 전이: 준비↔실행→대기 (할당량 소진/입출력 요청)
- [ ] 스케줄링: 비선점(FCFS·SJF·HRN) / 선점(RR·SRT·다단계)
- [ ] HRN 계산: (대기+서비스)÷서비스 — 큰 값 우선
- [ ] 페이지 교체 계산: FIFO·LRU 표 그리기 (적중도 사용 이력 갱신)
- [ ] 교착상태 4조건 (상점비환) + 해결 4전략 (예방·회피=은행가·발견·회복)
- [ ] 가상기억(페이징=고정/세그먼트=가변), 스래싱, 구역성
