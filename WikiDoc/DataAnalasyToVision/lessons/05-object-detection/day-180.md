### 최종 리허설의 목적은 어제와 다릅니다

[Day 179](day-179.md)의 1회차는 **시간 파악**, 2회차는 **완성도**가 목적이었습니다.
오늘 3회차는 **실제 무대 적응**입니다. 장소가 발표장이고, 장비가 발표용 프로젝터이며,
조치하는 것이 문장이 아니라 **조명·해상도·동선**입니다.

```
★ 3회차의 핵심은 "말 연습" 이 아니라 "환경 확인" 입니다.

  어제까지의 리허설은 우리 자리에서 했습니다.
  발표장은 조명이 다르고, 프로젝터 해상도가 다르고,
  카메라를 놓을 자리와 시연자가 설 자리가 다릅니다.

  ★ 조명이 다르면 검출 결과가 달라집니다. 이것이 3회차의 존재 이유입니다.
```

**3회차에서 반드시 확인할 6가지**

```
① 조명       발표장 조도에서 helmet 이 검출되는가
② 화각       시연자가 카메라 프레임에 들어오는가 (2.8m 하향 20° 재현)
③ 네트워크   파이 ↔ 서버 통신이 발표장 Wi-Fi 에서 되는가
④ 해상도     슬라이드 오른쪽이 잘리지 않는가 (16:9)
⑤ 동선       시연 보조가 움직일 자리가 확보되는가
⑥ 소리       백업 영상을 틀 때 자막이 뒤에서 읽히는가
```

> ⚠️ **발표장 Wi-Fi 는 리허설 때 되던 것이 발표 때 안 됩니다.**
> 사람이 30명 들어오면 대역폭과 AP 접속 수가 달라집니다.
> **휴대폰 핫스팟을 파이와 노트북 양쪽에 미리 등록**해 두고, 실제로 붙여 보세요.
> "필요하면 그때 바꾸면 되죠" 는 무대 위에서 3분을 잡아먹습니다.

### ★ 라이브 시연이 실패하는 8가지 원인

발표장에서 실제로 일어나는 일들입니다. 원인별로 **증상 · 사전 조치 · 현장 대응**을 나눠 둡니다.

| # | 원인 | 증상 | 사전 조치 |
|---|---|---|---|
| 1 | 발표장 Wi-Fi 접속 실패 | 파이가 서버에 못 붙음 · 웹 대시보드 갱신 없음 | 휴대폰 핫스팟 등록 · SSID 고정 |
| 2 | 파이 IP 변경 | 노트북에서 `ssh` · 웹 접속 실패 | mDNS(`safegate.local`) · IP 고정 예약 |
| 3 | 조명 차이 | 검출은 되는데 helmet 이 안 잡힘 | 리허설 3회차에서 conf 재확인 |
| 4 | 카메라 초점·화각 | 대상이 흐리거나 프레임 밖 | 초점 고정 · 바닥에 테이프로 위치 표시 |
| 5 | 노트북 절전·화면보호기 | 시연 중 화면이 꺼짐 | 절전 끄기 · 알림 끄기 · 전원 연결 |
| 6 | 프로젝터 해상도 변경 | 창 크기가 틀어져 대시보드가 잘림 | 1920×1080 고정 · 확장 모드 · 브라우저 확대율 100% |
| 7 | 알림 API 차단 | 텔레그램이 도착하지 않음 | 사내망 차단 대비 · 로컬 알림 화면 병행 |
| 8 | 배터리 방전 | 파이 재부팅 · 노트북 절전 | 멀티탭 · 보조배터리 · 어댑터 2개 |

**각각의 현장 대응 — 30초 안에 판단합니다**

```
1. Wi-Fi 실패   핫스팟 켜기 → 30초 안에 안 붙으면 ★ 2단계로
2. IP 변경      mDNS 접속 → 안 되면 파이 HDMI 를 프로젝터로
3. 조명 차이    conf 를 낮추지 말고 ★ 시연자가 1m 더 가까이
4. 초점·화각    바닥 테이프 위치로 이동. 카메라는 만지지 않음
5. 절전         복구에 20~40초 → ★ 즉시 백업 영상으로
6. 해상도       F11 전체화면 + Ctrl+0 → 그래도 잘리면 스크린샷 슬라이드
7. 알림 차단    "외부 API 가 막혀 있습니다" + ★ 로컬 이벤트 로그로 대체
8. 배터리       전원 먼저. 파이 부팅 40초 동안 ★ 백업 영상
```

> ⚠️ **발표 중에 설정을 바꾸지 마세요.**
> `conf` 를 0.35 → 0.20 으로 낮추면 그 순간 오탐이 쏟아집니다.
> 심사자는 "안 되니까 임계값을 내렸다" 를 정확히 알아봅니다.
> **동작점은 [Day 177](day-177.md)에서 근거를 갖고 정한 값입니다. 무대 위에서 바꾸지 않습니다.**

### ★ 3단계 백업 전략

[Day 177](day-177.md)의 `DEMO_PLAN.md` 에 Plan A~D 를 적어 뒀습니다.
오늘은 그것을 **3단계로 압축**합니다. 단계가 많으면 무대 위에서 판단이 늦어집니다.

```
┌──────────────────────────────────────────────────────────────┐
│  1단계  실물 라이브                                          │
│    파이 카메라 → 검출 → 알림 → 서버 → 웹 대시보드            │
│    조건: 네트워크 O · 조명 O · 장비 O                        │
│    소요: 5:00 (계획대로)                                     │
└──────────────────────────────────────────────────────────────┘
              │ 실패 판정 (30초 규칙)
              ▼
┌──────────────────────────────────────────────────────────────┐
│  2단계  로컬 오프라인                                        │
│    파이 화면을 HDMI 로 직접 투사 · 서버 없이 파이 단독 동작   │
│    또는 노트북에서 영상 파일 입력으로 detector 실행           │
│    조건: 파이가 살아 있음 (네트워크만 죽음)                   │
│    소요: 3:00 (웹 대시보드 구간을 스크린샷으로 대체)          │
└──────────────────────────────────────────────────────────────┘
              │ 실패 판정 (추가 30초)
              ▼
┌──────────────────────────────────────────────────────────────┐
│  3단계  녹화 영상                                            │
│    Day 179 에서 찍은 3분 데모 영상 재생                       │
│    조건: 없음 (노트북만 있으면 됨)                            │
│    소요: 3:00 + 발표자 해설                                  │
└──────────────────────────────────────────────────────────────┘
```

```
단계별 준비물 · 발표 전 확인
  1단계  파이·카메라·삼각대·안전모 2개·멀티탭·핫스팟 → /api/health 응답
  2단계  HDMI 케이블·젠더·파이 모니터 출력 설정      → 파이 화면이 프로젝터에 나오는가
  3단계  backup_demo.mp4(슬라이드에 삽입)·PDF·스크린샷 → ★ 발표 노트북에서 재생 확인
```

```
★ 3단계는 "인터넷도 파이도 없어도" 되어야 합니다.
  영상은 링크가 아니라 슬라이드 파일 안에 삽입(embed)합니다.
  USB 에 pptx · pdf · mp4 · shots/ 를 전부 넣어 갑니다.
```

> ⚠️ **2단계를 건너뛰고 바로 3단계로 가는 팀이 많습니다.**
> 그런데 2단계는 **여전히 실물이 돌아가는 것을 보여줍니다.**
> "서버 연동만 안 될 뿐 검출은 지금 이 자리에서 되고 있습니다" 와
> "영상으로 보여드리겠습니다" 는 심사자에게 완전히 다르게 들립니다.
> **파이 HDMI 출력 한 번 연결해 보는 데 2분이면 됩니다. 오전에 해 두세요.**

### 전환 판단 기준 — 30초 규칙

```
★ 규칙
  ① 예상대로 안 되면 ★ 30초를 셉니다 (조작자가 속으로 셉니다)
  ② 30초 안에 복구되지 않으면 ★ 다음 단계로 내려갑니다
  ③ ★ 한 번 내려간 단계에서 다시 올라오지 않습니다
  ④ "잠시만요" 는 ★ 최대 1회. 두 번째는 전환 신호입니다
```

```
왜 30초인가 — 시연 5분 중 30초는 10% 입니다.
  넘기면 청중이 화면 대신 발표자의 얼굴을 보고, 발표자는 대본을 잃으며,
  ★ 남은 4분으로 3단계 영상(3분)과 해설을 못 넣습니다.

  ★ 30초는 "고칠 수 있는 시간" 이 아니라 "다음 단계로 갈지 정하는 시간" 입니다.
```

**판단 주체를 정해 둡니다**

```python
"""Day 180 최종 리허설 — 3회차 구간 시간 측정
사용법:  python rehearsal_final.py
"""
from __future__ import annotations

import csv
import time
from datetime import datetime
from pathlib import Path

OUT = Path("portfolio/rehearsal_final.csv")

# 구간 이름, 목표 초
SEGMENTS = [
    ("문제", 120),
    ("접근·설계", 180),
    ("라이브 시연", 300),      # ★ 가장 잘 넘치는 구간
    ("결과·한계", 180),
    ("마무리", 120),
]
TOTAL_TARGET = sum(s for _, s in SEGMENTS)      # 900초 = 15분


def run_stopwatch() -> list[dict]:
    """구간마다 Enter 를 눌러 시간을 잰다"""
    print("=" * 72)
    print(f"최종 리허설 — 목표 {TOTAL_TARGET}초 ({TOTAL_TARGET // 60}분)")
    print("각 구간이 끝날 때마다 Enter 를 누르세요. Ctrl+C 로 중단.")
    print("=" * 72)
    input("준비되면 Enter 로 시작합니다... ")

    rows: list[dict] = []
    t0 = time.perf_counter()
    prev = t0
    for name, target in SEGMENTS:
        input(f"  [{name}] 진행 중 — 끝나면 Enter ")
        now = time.perf_counter()
        actual = now - prev
        prev = now
        rows.append({
            "segment": name,
            "target_sec": target,
            "actual_sec": round(actual, 1),
            "diff_sec": round(actual - target, 1),
        })
    total = prev - t0
    rows.append({
        "segment": "합계",
        "target_sec": TOTAL_TARGET,
        "actual_sec": round(total, 1),
        "diff_sec": round(total - TOTAL_TARGET, 1),
    })
    return rows


def save(rows: list[dict]) -> None:
    OUT.parent.mkdir(parents=True, exist_ok=True)
    new = not OUT.exists()
    with OUT.open("a", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=["run_at", "segment", "target_sec",
                                          "actual_sec", "diff_sec"])
        if new:
            w.writeheader()
        stamp = datetime.now().isoformat(timespec="seconds")
        for r in rows:
            w.writerow({"run_at": stamp, **r})


def report(rows: list[dict]) -> None:
    print()
    print("=" * 72)
    print(f"{'구간':<14}{'목표':>8}{'실제':>8}{'차이':>8}   판정")
    print("-" * 72)
    for r in rows:
        d = r["diff_sec"]
        if r["segment"] == "합계":
            print("-" * 72)
        if abs(d) <= 15:
            verdict = "OK"
        elif d > 15:
            verdict = f"초과 {d:+.0f}s  <- 잘라내기"
        else:
            verdict = f"부족 {d:+.0f}s  <- 내용 보강"
        print(f"{r['segment']:<14}{r['target_sec']:>7}s{r['actual_sec']:>7.0f}s"
              f"{d:>+7.0f}s   {verdict}")
    print("=" * 72)

    total = rows[-1]
    if total["actual_sec"] > 930:
        print("판정: 시간 초과. 접근·설계에서 30초를 잘라내세요.")
    elif total["actual_sec"] < 840:
        print("판정: 너무 짧습니다. 결과·한계에 조건별 성능표를 추가하세요.")
    else:
        print("판정: 15분 ±30초 범위입니다. 그대로 갑니다.")


def main() -> None:
    rows = run_stopwatch()
    save(rows)
    report(rows)


if __name__ == "__main__":
    main()
```

### Step 2. 장비·백업 점검 — 자동 확인 스크립트

`portfolio/preflight.py`

```python
"""Day 180 발표 전 사전 점검 — 서버·파이·백업 자산을 한 번에 확인
사용법:
    python preflight.py --pi http://safegate.local:8001 --srv http://127.0.0.1:8000
"""
from __future__ import annotations

import argparse
import json
import shutil
import subprocess
import sys
from pathlib import Path

import requests

ASSETS = [
    ("슬라이드 pptx", "portfolio/media/deck.pptx"),
    ("슬라이드 pdf", "portfolio/media/deck.pdf"),
    ("백업 영상", "portfolio/media/backup_demo.mp4"),
    ("스크린샷 5장", "portfolio/media/shots"),
    ("시연 대본", "portfolio/demo_script.md"),
    ("장비 체크리스트", "portfolio/equipment_check.md"),
]

results: list[tuple[str, bool, str]] = []


def check(name: str, ok: bool, note: str = "") -> None:
    results.append((name, ok, note))
    mark = "OK  " if ok else "FAIL"
    print(f"  [{mark}] {name}  {note}")


def check_http(label: str, url: str, timeout: float = 4.0) -> dict | None:
    """상태 엔드포인트 확인 — 타임아웃 필수 (Day 177)"""
    try:
        r = requests.get(url, timeout=timeout)
    except requests.RequestException as e:
        check(label, False, f"{type(e).__name__}")
        return None
    if r.status_code != 200:
        check(label, False, f"HTTP {r.status_code}")
        return None
    try:
        data = r.json()
    except json.JSONDecodeError:
        check(label, False, "JSON 아님")
        return None
    check(label, True, f"build={data.get('build')} uptime={data.get('uptime_sec', 0):.0f}s")
    return data


def check_assets() -> None:
    for label, rel in ASSETS:
        p = Path(rel)
        if not p.exists():
            check(label, False, "없음")
            continue
        if p.is_dir():
            n = len(list(p.glob("*.png"))) + len(list(p.glob("*.jpg")))
            check(label, n >= 5, f"{n}장")
        else:
            mb = p.stat().st_size / 1024 / 1024
            check(label, mb > 0.01, f"{mb:.1f}MB")


def check_video(path: str) -> None:
    """백업 영상이 실제로 재생 가능한지 ffprobe 로 확인"""
    if shutil.which("ffprobe") is None or not Path(path).exists():
        check("영상 재생 확인", False, "ffprobe 또는 파일 없음")
        return
    cmd = ["ffprobe", "-v", "error", "-show_entries",
           "format=duration", "-of", "json", path]
    out = subprocess.run(cmd, capture_output=True, text=True)
    if out.returncode != 0:
        check("영상 재생 확인", False, "디코딩 실패")
        return
    dur = float(json.loads(out.stdout)["format"]["duration"])
    check("영상 재생 확인", 60 <= dur <= 240, f"{dur:.0f}초")


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--pi", default="http://safegate.local:8001")
    ap.add_argument("--srv", default="http://127.0.0.1:8000")
    args = ap.parse_args()

    print("=" * 72)
    print("발표 전 사전 점검")
    print("=" * 72)

    print("\n[1] 장비")
    pi = check_http("라즈베리파이 /api/health", f"{args.pi}/api/health")
    srv = check_http("서버 /api/health", f"{args.srv}/api/health")

    if pi:
        fps = pi.get("fps", 0)
        check("파이 FPS >= 8", fps >= 8.0, f"{fps:.2f}")
        temp = pi.get("temp_c", 0)
        check("파이 온도 < 75C", temp < 75, f"{temp:.0f}C")
        q = pi.get("queue_pending", 0)
        check("아웃박스 큐 비었음", q == 0, f"{q}건")

    if srv:
        n = srv.get("events_today", 0)
        check("서버 오늘 이벤트 0건", n == 0, f"{n}건 — 발표 전 초기화 필요")

    print("\n[2] 백업 자산")
    check_assets()
    check_video("portfolio/media/backup_demo.mp4")

    print("\n" + "=" * 72)
    fails = [r for r in results if not r[1]]
    print(f"통과 {len(results) - len(fails)}/{len(results)}")
    if fails:
        print("\n조치가 필요한 항목:")
        for name, _, note in fails:
            print(f"  - {name}  ({note})")
        sys.exit(1)
    print("모든 항목 통과. 발표 준비 완료.")


if __name__ == "__main__":
    main()
```

### Step 5. 질의응답 — 10분

**진행 방식**


```python
"""Day 180 상호 평가 집계 — 팀별 평균과 반 전체 약점 도출"""
from __future__ import annotations

import csv
from pathlib import Path

SRC = Path("portfolio/peer_scores.csv")
ITEMS = ["problem", "design", "demo", "honesty", "qa"]
LABEL = {
    "problem": "문제 정의",
    "design": "접근·설계",
    "demo": "시연",
    "honesty": "정직성",
    "qa": "질의응답",
}
MAX_PER_ITEM = 5


def load() -> list[dict]:
    with SRC.open(encoding="utf-8") as f:
        rows = list(csv.DictReader(f))
    out = []
    for r in rows:
        if r["rater_team"] == r["target_team"]:      # 자기 팀 평가는 제외
            continue
        rec = {"target": r["target_team"]}
        for k in ITEMS:
            rec[k] = int(r[k])
        rec["total"] = sum(rec[k] for k in ITEMS)
        out.append(rec)
    return out


def by_team(rows: list[dict]) -> dict[str, dict]:
    teams: dict[str, list[dict]] = {}
    for r in rows:
        teams.setdefault(r["target"], []).append(r)
    result = {}
    for t, rs in teams.items():
        agg = {k: sum(r[k] for r in rs) / len(rs) for k in ITEMS}
        agg["total"] = sum(agg[k] for k in ITEMS)
        agg["n"] = len(rs)
        result[t] = agg
    return result


def main() -> None:
    rows = load()
    teams = by_team(rows)

    print("=" * 76)
    print("팀별 상호 평가 평균 (25점 만점)")
    print("=" * 76)
    header = f"{'팀':<8}" + "".join(f"{LABEL[k]:>10}" for k in ITEMS) + f"{'총점':>10}{'n':>5}"
    print(header)
    print("-" * 76)
    for t, a in sorted(teams.items(), key=lambda x: -x[1]["total"]):
        line = f"{t:<8}" + "".join(f"{a[k]:>10.2f}" for k in ITEMS)
        print(line + f"{a['total']:>10.2f}{a['n']:>5}")

    print()
    print("=" * 76)
    print("항목별 반 전체 평균 — 낮은 순")
    print("=" * 76)
    overall = {k: sum(r[k] for r in rows) / len(rows) for k in ITEMS}
    for k, v in sorted(overall.items(), key=lambda x: x[1]):
        rate = v / MAX_PER_ITEM * 100
        bar = "#" * int(rate / 4)
        print(f"  {LABEL[k]:<10} {v:.2f}/5  {rate:5.1f}%  {bar}")

    weak = min(overall, key=overall.get)
    print()
    print(f"반 전체가 가장 약한 항목: {LABEL[weak]} ({overall[weak]:.2f}/5)")


if __name__ == "__main__":
    main()
```

### Step 8. 과정 완료 조건 점검

`portfolio/check_completion.py`

```python
"""과정 완료 조건 7항목 자동 점검 — 파일 존재 + 실제 응답 확인"""
from __future__ import annotations

import json
import subprocess
from pathlib import Path

import requests

SRV = "http://127.0.0.1:8000"
PI = "http://safegate.local:8001"
report: list[tuple[int, str, bool, str]] = []


def add(no: int, cond: str, ok: bool, note: str) -> None:
    report.append((no, cond, ok, note))


def get(url: str, timeout: float = 4.0):
    try:
        r = requests.get(url, timeout=timeout)
        return r if r.status_code == 200 else None
    except requests.RequestException:
        return None


def mark(b: bool) -> str:
    return "O" if b else "X"


def run_checks() -> None:
    # 1. 데이터셋 + 모델
    imgs = list(Path("data/images").rglob("*.jpg"))
    lbls = list(Path("data/labels").rglob("*.txt"))
    w = Path("models/best.pt")
    add(1, "데이터셋 500장 이상 + 학습 모델 동작",
        len(imgs) >= 500 and len(lbls) > 0 and w.exists(),
        f"이미지 {len(imgs)}장 · 라벨 {len(lbls)}개 · best.pt {mark(w.exists())}")

    # 2. 웹 업로드 + 스트리밍
    up, st = get(f"{SRV}/upload"), get(f"{SRV}/stream")
    add(2, "웹 업로드 검출 + 실시간 스트리밍", bool(up and st),
        f"/upload {mark(bool(up))} · /stream {mark(bool(st))}")

    # 3. 파이 연동
    h = get(f"{PI}/api/health")
    fps = h.json().get("fps", 0) if h else 0
    add(3, "라즈베리파이 카메라 연동", bool(h) and fps > 0, f"fps={fps:.2f}")

    # 4. 이벤트 기록 + 알림
    r = get(f"{SRV}/api/events?limit=1")
    n = len(r.json().get("items", [])) if r else 0
    log = Path("logs/notify.log")
    sent = log.exists() and "sent" in log.read_text(encoding="utf-8", errors="ignore")
    add(4, "이벤트 DB 기록 + 알림 발송", n > 0 and sent,
        f"DB {n}건 · 알림로그 {mark(sent)}")

    # 5. README
    p = Path("README.md")
    text = p.read_text(encoding="utf-8") if p.exists() else ""
    missing = [s for s in ["## 설치", "## 실행", "## 사용법", "## 성능"] if s not in text]
    add(5, "README 만으로 설치·실행 가능", p.exists() and not missing,
        f"{len(text)}자 · 누락 {missing or '없음'}")

    # 6. GitHub — ★ 로그인 없이 요청해야 private 을 걸러낼 수 있다
    rp = Path("portfolio/repos.json")
    repos = json.loads(rp.read_text(encoding="utf-8")) if rp.exists() else []
    cnt = sum(1 for r in repos if get(r["url"], timeout=6.0))
    add(6, "GitHub 5개 프로젝트 정리", cnt >= 5, f"공개 접근 가능 {cnt}/5")

    # 7. 회고문서
    team, mine = Path("docs/RETROSPECTIVE.md"), Path("portfolio/RETRO_180.md")
    add(7, "회고문서 제출", team.exists() and mine.exists(),
        f"팀 {mark(team.exists())} · 개인 {mark(mine.exists())}")


def main() -> None:
    run_checks()
    print("=" * 78)
    print("과정 완료 조건 7항목")

    for no, cond, ok, note in report:
```

```python
"""최종 제출 패키지 생성 — 개인 산출물을 zip 하나로 묶는다"""
from __future__ import annotations

import hashlib
import zipfile
from datetime import datetime
from pathlib import Path

NAME = "hong_gildong"          # 본인 영문 이름으로 변경
OUT = Path(f"submit/{NAME}_day180.zip")

REQUIRED = [
    "portfolio/PORTFOLIO.md",
    "portfolio/resume.md",
    "portfolio/interview_qa.md",
    "portfolio/RETRO_180.md",
    "portfolio/qa_log.md",
    "portfolio/plan_3month.md",
    "portfolio/repos.json",
    "portfolio/rehearsal_final.csv",
    "portfolio/demo_result.md",
]
OPTIONAL = [
    "portfolio/peer_scores.csv",
    "portfolio/equipment_check.md",
]


def sha256(p: Path) -> str:
    """제출 후 '그 파일이 아니었다' 는 분쟁을 막기 위한 지문"""
    return hashlib.sha256(p.read_bytes()).hexdigest()[:12]


def main() -> None:
    missing = [p for p in REQUIRED if not Path(p).exists()]
    if missing:
        print("필수 파일이 없습니다:")
        for m in missing:
            print(f"  - {m}")
        print("\n제출을 중단합니다.")
        return

    OUT.parent.mkdir(parents=True, exist_ok=True)
    manifest: list[str] = []
    with zipfile.ZipFile(OUT, "w", zipfile.ZIP_DEFLATED) as z:
        for rel in REQUIRED + OPTIONAL:
            p = Path(rel)
            if not p.exists():
                continue
            z.write(p, arcname=p.name)
            manifest.append(f"{p.name:<28} {p.stat().st_size:>8,}B  {sha256(p)}")
        info = ("제출자: " + NAME + "\n제출시각: "
                + datetime.now().isoformat(timespec="seconds") + "\n\n"
                + "\n".join(manifest) + "\n")
        z.writestr("MANIFEST.txt", info)

    print("=" * 66)
    print(f"제출 패키지 생성: {OUT}  ({OUT.stat().st_size / 1024:.0f}KB)")
    print("=" * 66)
    print(info)


if __name__ == "__main__":
    main()
```

```
  P: "라벨링 진행률을 확인하는 주기를 정하지 않았습니다.
      3일 뒤에야 목표의 절반뿐인 것을 알았습니다."

```
