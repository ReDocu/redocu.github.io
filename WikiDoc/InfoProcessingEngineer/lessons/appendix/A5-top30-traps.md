# A5 · 자주 틀리는 함정 30

> [부록 목차](README.md) · 사용 시점: 시험 전날 1회독 + 당일 아침. [16강 스피드 런](../05-exam-prep/lesson-16.md)의 "틀리는 방식" 버전.

| # | 함정 | 예 | 정답 포인트 |
|---|---|---|---|
| 1 | 정수 나눗셈 | C·Java `7/2` | `3` (Python `/`만 3.5, `//`가 몫) |
| 2 | 후위 증감 | `b = a++` (a=5) | b=5 — **쓰고 나서** 증가 |
| 3 | 문자열 연결 방향 | `1+2+"A"` vs `"A"+1+2` | `3A` vs `A12` — 왼쪽부터 판정 |
| 4 | 복합 대입 | `a *= 2 + 3` (a=4) | 20 — 오른쪽 전체 먼저 |
| 5 | switch break 누락 | case 일치 후 | break까지 **연쇄 실행** |
| 6 | `&` vs `&&` | `6 & 3` vs `6 && 3` | 2(비트) vs 1(논리) |
| 7 | 연쇄 비교 | C `0 < a < 10` | 항상 참꼴 (Python만 수학처럼) |
| 8 | range 끝 | `range(1, 100)` | 99까지 — 끝 미포함 |
| 9 | off-by-one | `<` vs `<=` | 첫·끝 회차를 직접 대입해 세기 |
| 10 | do-while | 조건이 처음부터 거짓 | 그래도 **1회 실행** |
| 11 | Java 문자열 비교 | `s1 == s2` | 주소 비교 — 내용은 `equals()` |
| 12 | 길이 표기 | length / length() / len | 배열·문자열(Java)·Python 구분 |
| 13 | C 범위 밖 접근 | `a[5]` (길이 5) | **에러 없이** 쓰레기값 (Java·Python은 예외) |
| 14 | `*p++` | 괄호 없음 | 포인터 **이동** — 값 증가는 `(*p)++` |
| 15 | 값 전달 swap | `swap(a, b)` | 원본 불변 — `&a`/`int *x`/`*x` 3부품 |
| 16 | 재귀 연산자 | `n + f(n-1)` vs `n * f(n-1)` | 합(10) vs 팩토리얼(24) — 연산자 먼저 확인 |
| 17 | 생성자 순서 | `new 자식()` | **부모 생성자 먼저** |
| 18 | 다형성 판정 | `부모 p = new 자식()` | 실행=객체 기준, 호출 가능=타입 기준 |
| 19 | 예외 후 코드 | try 안 발생 줄 다음 | 건너뜀 — catch 하나 + finally 항상 |
| 20 | 튜플·sort | `t[0]=1` / `print(a.sort())` | 불변 에러 / None (반환은 sorted) |
| 21 | 슬라이싱 끝 | `s[1:4]` | 인덱스 1·2·3 — 끝 미포함 (substring 동일) |
| 22 | `= NULL` | `WHERE 학과코드 = NULL` | 항상 0행 — `IS NULL` |
| 23 | BETWEEN | `BETWEEN 80 AND 90` | **양 끝 포함** |
| 24 | AVG 분모 | 성적에 NULL 존재 | 분모 = COUNT(열) — NULL 제외 |
| 25 | WHERE vs HAVING | `WHERE AVG(성적) >= 85` | 에러 — 그룹 조건은 HAVING |
| 26 | LEFT JOIN 개수 | `COUNT(*)` | 짝 없는 행도 1 — `COUNT(오른쪽 열)`이 0 |
| 27 | NOT IN + NULL | 서브쿼리에 NULL | 전체 0행 — NOT EXISTS 권장 |
| 28 | TRUNCATE 분류 | "행 삭제니까 DML?" | **DDL** — ROLLBACK 불가 |
| 29 | σ vs π | 관계대수 Select | σ=WHERE(행), π=SELECT 절(열) |
| 30 | 계산 공식 | HRN·LRU | HRN 분자는 대기+**서비스** / LRU는 **적중도 사용**으로 갱신 |

**회독법** — ①번호를 가리고 "예"만 보고 정답 포인트를 말한다 ②막힌 번호를 적는다 ③그 번호만 근거 강으로 돌아가 5분 복습 ([A1](A1-language-comparison.md)~[A3](A3-db-terms.md) 참조).
