## ③ 개념 설명

### 수집 경로 ① 직접 촬영

**가장 중요하고 가장 느립니다.**

```
장점
  ✓ 우리 설치 환경과 동일한 조건
  ✓ 클래스가 정확히 우리가 정한 것
  ✓ 개인정보 문제가 없음 (팀원 동의)

단점
  ✗ 시간이 오래 걸림
  ✗ ★ 다양성 확보가 어려움 (같은 사람, 같은 장소)
```

**★ 촬영 다양성 축 4가지**

| 축 | 변화시킬 것 | 최소 수준 |
|---|---|---|
| **거리** | 가까이 · 중간 · 멀리 | 3단계 |
| **각도** | 정면 · 측면 · 뒷면 · 사선 | 4방향 |
| **조명** | 밝음 · 보통 · 어두움 · 역광 | 3단계 이상 |
| **대상** | 사람 수 · 옷차림 · 자세 | 사람 5명 이상 |

```
조합 수 = 3 × 4 × 3 × 5 = 180가지
→ 각 조합에 2~3장씩 = 400~500장

★ 이렇게 계획하면 500장이 "서로 다른 500장"이 됩니다
```

**촬영 체크리스트**

```
□ 삼각대 또는 고정 거치 (★ 실제 설치와 같은 높이·각도)
□ 해상도 1920×1080 이상
□ 각 조합마다 짧게 여러 번 (긴 영상 1개보다 짧은 영상 여러 개)
□ ★ 촬영 세션마다 파일명에 조건 표시
     cam_A_day_far_01.mp4
□ 배경 이미지용 — 아무도 없는 장면도 촬영
□ ★ 하드 네거티브 — 우산꽂이·코트·캐리어 등
□ 촬영 동의 확인 (팀원 외 인물이 찍히면 제외 또는 동의)
```

### 수집 경로 ② 공개 데이터셋

**COCO에서 person 이미지만 추출하기**

# COCO val2017 (5,000장, 약 780MB) — 수업용으로 적당한 크기
# https://cocodataset.org/#download
#   val2017.zip + annotations_trainval2017.zip

> ⚠️ **공개 데이터를 섞을 때의 3대 주의점**
> ```
> ① 도메인 차이 — COCO는 일반 사진, 우리는 CCTV 시점
>    → 너무 많이 섞으면 오히려 방해
>    → ★ 전체의 20~30% 이내
>
> ② 라벨 기준 차이 — COCO의 person 정의는 우리와 다름
>    → 아주 작은 사람도 라벨링되어 있음
>    → 우리 기준(24px)으로 필터링 필요
>
> ③ 라이선스 — 상업적 사용 조건 확인
>    → 수업/포트폴리오는 대부분 문제없음
> ```

### 수집 경로 ③ 영상 프레임 추출

**추출 간격 정하기**

```
간격이 너무 짧으면  →  중복
간격이 너무 길면    →  놓치는 장면

★ 기준: 장면이 유의미하게 바뀌는 시간
  사람이 걸어서 화면을 가로지르는 시간 ≈ 3~5초
  → ★ 0.5~1초 간격이 적절
```

**그런데 간격만으로는 부족합니다.**

```
빈 복도 7분 → 1초 간격 → 420장의 똑같은 사진

★ 내용 기반 중복 제거가 필요합니다
```

### ★ 중복 프레임 제거 3가지 방법

**방법 ① 프레임 차이 (가장 빠름)**

```python
diff = |frame_t - frame_{t-1}| 의 평균
diff < 임계값  →  거의 같은 장면  →  버림
```

```
장점: 매우 빠름 · 구현 간단
단점: 조명 변화에 민감
```

**방법 ② 지각 해시 (perceptual hash)**

```
이미지를 8×8 흑백으로 축소 → 평균보다 밝으면 1
→ 64비트 해시
→ 해밍 거리가 작으면 유사
```

```
장점: 밝기·압축 변화에 강함
단점: 구도가 같으면 객체가 달라도 비슷하다고 판정
```

**방법 ③ ★ 검출 기반 (우리에게 가장 적합)**

```
사전학습 모델로 객체를 검출하고
  · 객체 수가 바뀌었는가
  · 객체 위치가 크게 이동했는가
→ 바뀐 프레임만 채택
```

```
장점: ★ "의미 있는 변화"를 정확히 포착
      빈 복도 420장 → 1~2장으로 압축
단점: 느림 (프레임마다 추론)
```

**우리 전략 — 2단계**

```
1단계  프레임 차이로 대략 걸러냄 (빠름)
2단계  ★ 검출 기반으로 정밀 선별
```

### Step 2. 영상 → 프레임 추출

```python
"""extract_frames.py — 영상에서 프레임 추출 + 1차 중복 제거"""
from pathlib import Path

import cv2
import numpy as np


def frame_diff_score(a, b, size=(160, 90)):
    """두 프레임의 차이 (0~1) — 작을수록 비슷"""
    ga = cv2.cvtColor(cv2.resize(a, size), cv2.COLOR_BGR2GRAY).astype(np.float32)
    gb = cv2.cvtColor(cv2.resize(b, size), cv2.COLOR_BGR2GRAY).astype(np.float32)
    return float(np.abs(ga - gb).mean() / 255.0)


def extract(video, out_dir, every_sec=0.5, diff_thr=0.012,
            prefix=None, max_frames=None, resize_to=None):
    """N초 간격 추출 + 직전 채택 프레임과 차이가 작으면 건너뜀"""
    video, out_dir = Path(video), Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    prefix = prefix or video.stem

    cap = cv2.VideoCapture(str(video))
    if not cap.isOpened():
        raise RuntimeError(f"열 수 없음: {video}")

    fps = cap.get(cv2.CAP_PROP_FPS) or 30
    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    step = max(1, int(round(fps * every_sec)))

    saved, skipped, idx = 0, 0, 0
    last = None
    while True:
        ok, frame = cap.read()
        if not ok:
            break
        if idx % step == 0:
            if resize_to:
                frame = cv2.resize(frame, resize_to)
            if last is not None and frame_diff_score(last, frame) < diff_thr:
                skipped += 1                          # ★ 거의 같은 장면
            else:
                cv2.imwrite(str(out_dir / f"{prefix}_{saved:04d}.jpg"), frame,
                            [cv2.IMWRITE_JPEG_QUALITY, 94])
                last = frame
                saved += 1
                if max_frames and saved >= max_frames:
                    break
        idx += 1
    cap.release()

    return {"영상": video.name, "총 프레임": total, "FPS": round(fps, 1),
            "간격": f"{every_sec}초", "저장": saved, "중복 제외": skipped,
            "압축률": f"{skipped/(saved+skipped)*100:.0f}%" if saved+skipped else "-"}

```python
"""dedup_detect.py — 검출 결과로 '의미 있는 변화'만 남긴다"""
from pathlib import Path

import numpy as np
from ultralytics import YOLO


def signature(result, grid=8):
    """검출 결과를 비교 가능한 서명으로
    (클래스별 개수, 중심점 격자 히스토그램)"""
    n_by_cls = {}
    heat = np.zeros((grid, grid), dtype=np.float32)
    for b in result.boxes:
        cid = int(b.cls)
        n_by_cls[cid] = n_by_cls.get(cid, 0) + 1
        cx, cy = b.xywhn[0][:2].tolist()
        gx = min(grid - 1, int(cx * grid))
        gy = min(grid - 1, int(cy * grid))
        heat[gy, gx] += 1
    return n_by_cls, heat


def sig_distance(s1, s2):
    """0~1. 클수록 다른 장면"""
    n1, h1 = s1
    n2, h2 = s2
    keys = set(n1) | set(n2)
    count_diff = sum(abs(n1.get(k, 0) - n2.get(k, 0)) for k in keys)
    count_score = min(1.0, count_diff / 3.0)
    denom = max(h1.sum(), h2.sum(), 1)
    pos_score = float(np.abs(h1 - h2).sum() / (2 * denom))
    return 0.6 * count_score + 0.4 * pos_score


def dedup_by_detection(img_dir, out_keep, out_drop, conf=0.35, thr=0.18):
    img_dir = Path(img_dir)
    out_keep, out_drop = Path(out_keep), Path(out_drop)
    out_keep.mkdir(parents=True, exist_ok=True)
    out_drop.mkdir(parents=True, exist_ok=True)

    model = YOLO("yolo11n.pt")
    imgs = sorted(img_dir.glob("*.jpg"))

    import shutil
    kept_sigs, n_keep, n_drop = [], 0, 0
    report = []

    for p in imgs:
        r = model(str(p), conf=conf, verbose=False)[0]
        s = signature(r)

        # 같은 영상(접두사)의 최근 채택본들과만 비교
        prefix = "_".join(p.stem.split("_")[:-1])
        recent = [sg for pf, sg in kept_sigs[-12:] if pf == prefix]
        dist = min((sig_distance(s, sg) for sg in recent), default=1.0)

        if dist >= thr or not recent:
            shutil.copy2(p, out_keep / p.name)
            kept_sigs.append((prefix, s))
            n_keep += 1
            report.append((p.name, len(r.boxes), round(dist, 3), "유지"))
        else:
            shutil.copy2(p, out_drop / p.name)
            n_drop += 1
            report.append((p.name, len(r.boxes), round(dist, 3), "제외"))

    return {"입력": len(imgs), "유지": n_keep, "제외": n_drop}, report

def extract_from_coco(ann_json, img_dir, out_img, out_lbl,
                      target=TARGET, seed=42):
    out_img, out_lbl = Path(out_img), Path(out_lbl)
    out_img.mkdir(parents=True, exist_ok=True)
    out_lbl.mkdir(parents=True, exist_ok=True)

    data = json.loads(Path(ann_json).read_text(encoding="utf-8"))
    cat_by_id = {c["id"]: c["name"] for c in data["categories"]}
    imgs = {im["id"]: im for im in data["images"]}

    per_img = defaultdict(list)
    for a in data["annotations"]:
        if a.get("iscrowd", 0) == 1:
            continue
        name = cat_by_id.get(a["category_id"])
        if name not in COCO_MAP:
            continue
        per_img[a["image_id"]].append((COCO_MAP[name], a["bbox"]))

    import random
    rnd = random.Random(seed)
    candidates = list(per_img.items())
    rnd.shuffle(candidates)

    taken, stats = 0, {"검토": 0, "채택": 0, "소형제외": 0,
                       "개수미달": 0, "군중제외": 0}

    for img_id, anns in candidates:
        stats["검토"] += 1
        if taken >= target:
            break
        im = imgs[img_id]
        w, h = im["width"], im["height"]

        rows = []
        dropped_small = 0
        for cid, (x, y, bw, bh) in anns:
            if min(bw, bh) < MIN_PX:               # ★ 우리 기준 적용
                dropped_small += 1
                continue
            voc = B.clip_voc(B.coco_to_voc((x, y, bw, bh)), w, h)
            if voc[2]-voc[0] < 1 or voc[3]-voc[1] < 1:
                continue
            rows.append((cid, *B.voc_to_yolo(voc, w, h)))

        if len(rows) < MIN_BOXES:
            stats["개수미달"] += 1
            continue
        if len(rows) > MAX_BOXES:
            stats["군중제외"] += 1
            continue
        if dropped_small > len(rows):              # ★ 버린 게 더 많으면 제외
            stats["소형제외"] += 1
            continue

        src = Path(img_dir) / im["file_name"]
        if not src.exists():
            continue
        stem = f"coco_{Path(im['file_name']).stem}"
        shutil.copy2(src, out_img / f"{stem}.jpg")

                      for c, a, b, ww, hh in rows) + "\n", encoding="utf-8")
        taken += 1
        stats["채택"] += 1

    return stats

import shutil

def merge_workers(work_root, out_img, out_lbl, classes,
                  workers=("A", "B", "C", "D")):
    work_root = Path(work_root)
    out_img, out_lbl = Path(out_img), Path(out_lbl)

        if not line.strip():

        if int(line.split()[0]) == REMOVE_ID:
            n_removed += 1
            continue

**대응**: 가져올 때 **우리 기준으로 필터링**.

```

A/cam_0001.jpg  ·  B/cam_0001.jpg

```

**대응**: **담당자 접두사** + 스크립트 병합 + 중복 감지.

### 분할을 무작위로

### ② 더 나은 선택 방법

**★ 4단계 선별**

```
[1단계] 중복 제거 (자동)                    5,400 → 600장
    · 프레임 차이 (diff_thr=0.012)
    · 검출 기반 (thr=0.18)

[2단계] 조건별 균등 할당 (계획)              600 → 목표 배분
    · 영상별로 목표 장수를 미리 정함
      day 영상    → 150장
      dim 영상    → 150장
      dark 영상   → 150장   ★ 짧아도 동일 할당
      배경/네거티브 → 50장
    · 부족한 조건은 추가 촬영 또는 증강으로 보완

[3단계] ★ 난이도 기반 선별 (중요)            할당 안에서 선택
    · 사전학습 모델로 각 프레임을 추론
    · 지표를 계산해 골고루 뽑음
        · 객체 수 (0 / 1~2 / 3~5 / 6+)
        · 평균 박스 크기 (소/중/대)
        · 평균 conf (낮을수록 어려운 장면)
    · ★ conf 낮은 것을 일부러 포함 (하드 케이스)

[4단계] 육안 최종 확인                       500장 확정
    · 검수 시트로 훑기
    · 흐릿·판정 불가 이미지 제외
```

**구현**

```python
from collections import defaultdict
from pathlib import Path

import numpy as np
from ultralytics import YOLO


def profile_frames(img_dir, conf=0.3):
    """각 프레임의 난이도 프로파일"""
    model = YOLO("yolo11n.pt")
    out = []
    for p in sorted(Path(img_dir).glob("*.jpg")):
        r = model(str(p), conf=conf, verbose=False)[0]
        n = len(r.boxes)
        if n:
            areas = [(float(b.xywhn[0][2]) * float(b.xywhn[0][3]))
                     for b in r.boxes]
            confs = [float(b.conf) for b in r.boxes]
            out.append({"path": p, "n": n,
                        "area": float(np.median(areas)),
                        "conf": float(np.mean(confs))})
        else:
            out.append({"path": p, "n": 0, "area": 0.0, "conf": 0.0})
    return out


def stratified_select(profiles, quota, seed=42):
    """조건 × 난이도 층화 선택"""
    import random
    rnd = random.Random(seed)

    def bucket(p):
        n_b = "0" if p["n"] == 0 else ("1-2" if p["n"] <= 2 else
                                       ("3-5" if p["n"] <= 5 else "6+"))
        a_b = "소" if p["area"] < 0.01 else ("중" if p["area"] < 0.06 else "대")
        c_b = "난" if 0 < p["conf"] < 0.55 else "이"       # ★ 어려운 케이스 태그
        return f"{n_b}|{a_b}|{c_b}"

    groups = defaultdict(list)
    for p in profiles:
        groups[bucket(p)].append(p)

    # 각 버킷에서 균등하게, 하드 케이스는 가중
    selected = []
    per = max(1, quota // max(len(groups), 1))
    for key, items in groups.items():
        rnd.shuffle(items)
        take = per * (2 if key.endswith("난") else 1)      # ★ 하드 2배
        selected += items[:min(take, len(items))]

    rnd.shuffle(selected)
    return selected[:quota]
```

```

```python
def build_dataset_balanced(src_img, src_lbl, dst, val_ratio=0.2,
                           group_fn=None, seed=42):
    """배경 이미지와 객체 이미지를 각각 층화 분할"""
    import random
    from collections import defaultdict

    src_img, src_lbl = Path(src_img), Path(src_lbl)
    imgs = sorted(p for p in src_img.iterdir()
                  if p.suffix.lower() in (".jpg", ".jpeg", ".png"))

    # ★ 객체 유무로 먼저 나눔
    with_obj, background = [], []
    for p in imgs:
        t = src_lbl / (p.stem + ".txt")
        has = t.exists() and bool(t.read_text(encoding="utf-8").strip())
        (with_obj if has else background).append(p)

    rnd = random.Random(seed)
    assign = {}

    for pool in (with_obj, background):          # ★ 각각 독립적으로 분할
        groups = defaultdict(list)
        for p in pool:
            groups[group_fn(p.stem) if group_fn else p.stem].append(p)
        keys = sorted(groups)
        rnd.shuffle(keys)

        n_val = int(len(pool) * val_ratio)
        cnt = 0
        for k in keys:
            s = "val" if cnt + len(groups[k]) <= n_val else "train"
            if s == "val":
                cnt += len(groups[k])
            for p in groups[k]:
                assign[p] = s

    return assign
```
