## 2부 · 재현 가능한 전처리 함수

### 함수로 묶는 3가지 원칙

**① 원본을 수정하지 않습니다**

```python
def preprocess(df):
    out = df.copy()          # ⭐ 반드시
    ...
    return out
```

**② 여러 번 실행해도 결과가 같습니다 (멱등성)**

```python
# ❌ 실행할 때마다 줄어듦
df = df[df["price"] < 100000]

# ✅ 몇 번을 돌려도 같음
out = out[out["price"].fillna(0) < 100000]
```

**③ 작은 함수로 나눕니다**

```python
def preprocess(df):
    out = (df.pipe(standardize_columns)
             .pipe(convert_types)
             .pipe(clean_strings)
             .pipe(handle_outliers)
             .pipe(handle_missing)
             .pipe(add_features))
    return out
```

> **`.pipe()` 는 "이 함수에 나를 넣어라"입니다.**
> ```python
> df.pipe(f)          # f(df) 와 같음
> df.pipe(f, a=1)     # f(df, a=1)
> ```
> 체인으로 이으면 **처리 순서가 코드에 그대로 보입니다.**

### 처리 순서 — 왜 이 순서인가

```
① 열 이름 표준화       나머지 코드가 열 이름에 의존하므로 가장 먼저
② 타입 변환            숫자·날짜가 되어야 비교·계산 가능
③ 문자열 정제          공백·표기 통일 (키 매칭 전에 필수)
④ 중복 제거            정제 후에 해야 진짜 중복이 보임
⑤ 이상치 처리          결측보다 먼저 — 오류값이 평균을 오염시키므로
⑥ 결측 처리            이상치가 정리된 뒤의 통계로 대체
⑦ 파생 변수            모든 정제가 끝난 뒤
⑧ 검증                 마지막에 반드시
```

**순서가 중요한 이유 3가지**

| 잘못된 순서 | 결과 |
|---|---|
| 문자열 정제 **후에** 중복 제거 ❌ | `'경복궁'` 과 `'경복궁 '` 이 다른 것으로 남음 |
| 결측 대체 **후에** 이상치 탐지 ❌ | 대체값이 중앙에 몰려 IQR이 좁아짐 |
| 이상치 처리 **후에** 타입 변환 ❌ | 문자열 상태로는 비교 자체가 불가 |

### 처리 이력 남기기

```python
def preprocess(df, verbose=True):
    out = df.copy()
    log = []

    def step(name, func):
        nonlocal out
        before = (len(out), out.shape[1], int(out.isna().sum().sum()))
        out = func(out)
        after = (len(out), out.shape[1], int(out.isna().sum().sum()))

        log.append({
            "단계": name,
            "행": f"{before[0]:,} → {after[0]:,}",
            "열": f"{before[1]} → {after[1]}",
            "결측": f"{before[2]:,} → {after[2]:,}",
        })

    step("열 표준화", standardize_columns)
    step("타입 변환", convert_types)
    ...

    if verbose:
        print(pd.DataFrame(log).to_string(index=False))

    return out, pd.DataFrame(log)
```

### 문제 ① 키 불일치

```
관광지 데이터   "서울특별시 종로구"
인구 데이터     "서울 종로"
날씨 데이터     "종로구"
```

**그대로 `merge` 하면 0건이 매칭됩니다.**

```python
# ✅ 양쪽 다 정규화한 뒤 매칭
def make_key(s):
    return (s.astype(str)
             .str.replace(r"(특별시|광역시|특별자치시|특별자치도|도|시|군|구)$",
                          "", regex=True)
             .str.replace(r"\s+", "", regex=True)
             .str.strip())

spots["_key"] = make_key(spots["sigungu"])
pop["_key"] = make_key(pop["region"])

merged = spots.merge(pop, on="_key", how="left", indicator=True)
```

**매칭 결과를 반드시 확인합니다**

```python
print(merged["_merge"].value_counts())
```

```
both          412        ← 매칭됨
left_only      88        ← ⚠ 관광지는 있는데 인구가 없음
right_only      0
```

```python
# 안 붙은 것들을 눈으로 확인
unmatched = merged[merged["_merge"] == "left_only"]["_key"].unique()
print(unmatched)      # ['세종', '서귀포', ...]  → 매핑 사전에 추가
```

> **`indicator=True` 를 항상 쓰세요.**
> `how="left"` 로 병합하면 **매칭 실패가 `NaN` 으로 조용히 들어갑니다.**
> 나중에 "왜 인구가 결측이지?"로 시간을 날립니다.

> `price` 가 `NaN` 인 것이 **"무료"인지 "정보 없음"인지**에 따라 분석이 완전히 달라집니다.

### 코드로 초안 만들기

```python
def make_data_dictionary(df, meta=None):
    """DataFrame 에서 컬럼 정의서 초안을 생성합니다."""
    meta = meta or {}
    rows = []

    for col in df.columns:
        s = df[col]
        info = meta.get(col, {})

        rows.append({
            "열": col,
            "한글명": info.get("name", ""),
            "타입": str(s.dtype),
            "단위": info.get("unit", ""),
            "결측": int(s.isna().sum()),
            "결측률%": round(s.isna().mean() * 100, 1),
            "고유값": int(s.nunique()),
            "예시": str(s.dropna().iloc[0])[:24] if s.notna().any() else "",
            "최소": s.min() if pd.api.types.is_numeric_dtype(s) else "",
            "최대": s.max() if pd.api.types.is_numeric_dtype(s) else "",
            "출처": info.get("source", ""),
            "결측의미": info.get("na_meaning", ""),
        })

    return pd.DataFrame(rows)
```

**자동 생성되는 것과 사람이 채우는 것을 나눕니다.**

| 자동 | 사람 |
|---|---|
| 타입 · 결측 수 · 고유값 · 범위 · 예시 | **한글명 · 단위 · 출처 · 결측 의미 · 비고** |

```python

# ══════════ 소스 A: 관광지 (API 수집) ══════════

    "price_text": rng.choice(["3,000원", "무료", "5000", "1만원", "-"], n_a),

    "review_cnt": rng.integers(0, 5000, n_b),

# ══════════ 소스 C: 지역 인구 (엑셀, 2024년 기준) ══════════

             "부산 해운대", "부산 수영", "제주 제주", "제주 서귀포"],
    "인구수": [142000, 121000, 218000, 285000, 538000,
               392000, 176000, 492000, 182000],

})

SOURCES = {"A 관광지(API)": source_a, "B 평점(크롤링)": source_b,
           "C 인구(엑셀)": source_c}

print("=" * 80)
print("                     소스별 원본 진단")
print("=" * 80)

for name, src in SOURCES.items():
    print(f"\n[{name}]  {src.shape[0]:,}행 × {src.shape[1]}열")
    print(f"  열: {list(src.columns)}")
    print(f"  타입: {dict(src.dtypes.astype(str))}")
    print(f"  결측: {src.isna().sum().sum()}건")

# ══════════ 통합 가능성 진단 ══════════
print(f"\n{'=' * 80}")

### Step 2. `preprocess.py` — 재현 가능한 전처리 모듈

```python
"""src/preprocess.py — 원본을 넣으면 분석용 테이블이 나옵니다."""

import re
import unicodedata
from pathlib import Path

import numpy as np
import pandas as pd

# ══════════════════════════════════════════
#  설정 — 모든 규칙을 여기 모읍니다
# ══════════════════════════════════════════

RAW_DIR = Path("data/raw")
INTERIM_DIR = Path("data/interim")
PROCESSED_DIR = Path("data/processed")

for d in (INTERIM_DIR, PROCESSED_DIR):
    d.mkdir(parents=True, exist_ok=True)

INVISIBLE = r"[​-‏﻿\xa0　\t\r\n]"

NA_TEXTS = ["", " ", "-", "--", "N/A", "n/a", "없음", "미상", "null", "?"]

# 열 이름 표준화
COLUMN_MAP = {
    "contentid": "id", "spot_id": "id",
    "title": "name", "spot_name": "name",
    "addr1": "address",
    "mapx": "lng", "mapy": "lat",
    "modifiedtime": "modified_at",
    "review_cnt": "review_count",
    "지역": "region", "인구수": "population",
    "면적_km2": "area_km2", "기준연도": "population_year",
}

# 허용 범위 (도메인 규칙)
DOMAIN_RULES = {
    "lat": (33.0, 39.0),
    "lng": (124.0, 132.0),
    "rating": (0.0, 5.0),
    "price": (0, 1_000_000),
    "review_count": (0, 1_000_000),
    "population": (0, 20_000_000),
}

# 가격 등급
PRICE_BINS = [-np.inf, 0, 5_000, 15_000, 30_000, np.inf]
PRICE_LABELS = ["무료", "저가", "중가", "고가", "최고가"]

SIDO_RULES = [
    (r"서울", "서울특별시"), (r"부산", "부산광역시"), (r"대구", "대구광역시"),
    (r"인천", "인천광역시"), (r"광주", "광주광역시"), (r"대전", "대전광역시"),
    (r"울산", "울산광역시"), (r"세종", "세종특별자치시"), (r"경기", "경기도"),
    (r"강원", "강원특별자치도"), (r"충북|충청북", "충청북도"),
    (r"충남|충청남", "충청남도"), (r"전북|전라북", "전북특별자치도"),
    (r"전남|전라남", "전라남도"), (r"경북|경상북", "경상북도"),
    (r"경남|경상남", "경상남도"), (r"제주", "제주특별자치도"),
]

KOREAN_UNITS = {"억": 10**8, "만": 10**4, "천": 10**3}


# ══════════════════════════════════════════
#  단계별 함수 — 각각 df 를 받아 df 를 반환
# ══════════════════════════════════════════

def standardize_columns(df):
    """① 열 이름을 표준으로 통일합니다."""
    out = df.copy()
    out.columns = [c.strip().lower().replace(" ", "_") for c in out.columns]
    out = out.rename(columns={k.lower(): v for k, v in COLUMN_MAP.items()})
    return out


def clean_strings(df):
    """② 문자열을 정제합니다. (공백·유니코드·결측표현)"""
    out = df.copy()

    for col in out.select_dtypes(include=["object", "string"]).columns:
        out[col] = (out[col].astype("string")
                    .map(lambda v: unicodedata.normalize("NFC", v)
                         if isinstance(v, str) else v)
                    .str.replace(INVISIBLE, " ", regex=True)
                    .str.replace(r"\s+", " ", regex=True)
                    .str.strip())
        out[col] = out[col].mask(out[col].isin(NA_TEXTS), pd.NA)

    return out


def parse_price(df, source_col="price_text", target="price"):
    """③ 가격 문자열을 숫자로 바꿉니다. 원본은 보존합니다."""
    out = df.copy()

    if source_col not in out.columns:
        return out

    def convert(v):
        if pd.isna(v):
            return np.nan

        text = str(v)

        if "무료" in text:
            return 0.0

        # 한글 단위 (1만원, 3천원)
        units = re.findall(r"(\d+(?:\.\d+)?)\s*([억만천])", text)
        if units:
            return float(sum(float(n) * KOREAN_UNITS[u] for n, u in units))

        nums = re.findall(r"\d[\d,]*", text)
        return float(nums[0].replace(",", "")) if nums else np.nan

    out[target] = out[source_col].map(convert)
    return out


def convert_types(df):
    """④ 타입을 변환합니다."""
    out = df.copy()

    for col in ("lat", "lng", "rating", "review_count",
                "population", "area_km2", "price"):
        if col in out.columns:
            out[col] = pd.to_numeric(out[col], errors="coerce")

    if "modified_at" in out.columns:
        out["modified_at"] = pd.to_datetime(
            out["modified_at"], format="%Y%m%d%H%M%S", errors="coerce")

    if "collected_at" in out.columns:
        out["collected_at"] = pd.to_datetime(
            out["collected_at"], errors="coerce")

    if "id" in out.columns:
        out["id"] = out["id"].astype("string").str.strip()

    return out


def parse_address(df):
    """⑤ 주소에서 시도·시군구를 추출합니다."""
    out = df.copy()

    if "address" not in out.columns:
        return out

    out["sido"] = pd.NA
    for pattern, standard in SIDO_RULES:
        mask = out["address"].str.contains(pattern, regex=True, na=False)
        out.loc[mask & out["sido"].isna(), "sido"] = standard

    out["sigungu"] = out["address"].str.extract(
        r"([가-힣]+(?:시|군|구))(?:\s|$)", expand=False)

    sido_names = [v for _, v in SIDO_RULES]
    out["sigungu"] = out["sigungu"].mask(out["sigungu"].isin(sido_names))

    return out


def drop_duplicates_by_key(df, key="id", sort_by="modified_at"):
    """⑥ 키 기준 중복을 제거합니다. 최신본을 남깁니다."""
    out = df.copy()

    if key not in out.columns:
        return out

    if sort_by in out.columns:
        out = out.sort_values(sort_by, na_position="first")

    return (out.drop_duplicates(subset=[key], keep="last")
               .reset_index(drop=True))


def handle_outliers(df, rules=None):
    """⑦ 도메인 규칙 위반값을 NaN 으로 바꿉니다. (제거하지 않음)"""
    out = df.copy()
    rules = rules or DOMAIN_RULES

    for col, (lo, hi) in rules.items():
        if col not in out.columns:
            continue

        mask = (out[col] < lo) | (out[col] > hi)
        if mask.any():
            out[f"{col}_was_invalid"] = mask.fillna(False)
            out.loc[mask, col] = np.nan

    return out


def handle_missing(df):
    """⑧ 결측을 처리합니다. 플래그를 먼저 만듭니다."""
    out = df.copy()

    # 플래그 먼저 (채우기 전에!)
    for col in ("price", "rating", "review_count"):
        if col in out.columns and out[col].isna().any():
            out[f"{col}_was_na"] = out[col].isna()

    # 그룹별 중앙값 대체 (그룹이 있을 때만)
    if "rating" in out.columns and "sigungu" in out.columns:
        out["rating"] = out["rating"].fillna(
            out.groupby("sigungu")["rating"].transform("median"))
        out["rating"] = out["rating"].fillna(out["rating"].median())

    if "review_count" in out.columns:
        out["review_count"] = out["review_count"].fillna(0)

    # price 는 채우지 않음 — "정보 없음"과 "무료"는 다르므로
    return out


def add_features(df):
    """⑨ 파생 변수를 만듭니다."""
    out = df.copy()

    if "price" in out.columns:
        out["price_grade"] = pd.cut(out["price"], bins=PRICE_BINS,
                                    labels=PRICE_LABELS)
        out["price_grade"] = out["price_grade"].astype(
            pd.CategoricalDtype(PRICE_LABELS, ordered=True))
        out["is_free"] = out["price"].eq(0)

    if "modified_at" in out.columns:
        d = out["modified_at"].dt
        out["modified_year"] = d.year
        out["modified_month"] = d.month

    if {"population", "area_km2"} <= set(out.columns):
        out["density"] = (out["population"] / out["area_km2"]).round(1)

    if {"rating", "review_count"} <= set(out.columns):
        # 리뷰 수를 반영한 가중 평점 (베이지안 평균)
        m, C = 50, out["rating"].mean()
        v, R = out["review_count"], out["rating"]
        out["weighted_rating"] = ((v / (v + m) * R) + (m / (v + m) * C)).round(2)

    if {"lat", "lng"} <= set(out.columns):
        out["has_coord"] = out[["lat", "lng"]].notna().all(axis=1)

    return out


# ══════════════════════════════════════════
#  파이프라인
# ══════════════════════════════════════════

def preprocess(df, verbose=True, name="데이터"):
    """
    원본 DataFrame 을 분석용으로 정제합니다.

    같은 입력에 대해 항상 같은 결과를 돌려줍니다 (멱등).

    반환: (정제된 df, 처리 이력 df)
    """
    out = df.copy()
    history = []

    steps = [
        ("① 열 표준화", standardize_columns),
        ("② 문자열 정제", clean_strings),
        ("③ 가격 파싱", parse_price),
        ("④ 타입 변환", convert_types),
        ("⑤ 주소 파싱", parse_address),
        ("⑥ 중복 제거", drop_duplicates_by_key),
        ("⑦ 이상치 처리", handle_outliers),
        ("⑧ 결측 처리", handle_missing),
        ("⑨ 파생 변수", add_features),
    ]

    for label, func in steps:
        before = (len(out), out.shape[1], int(out.isna().sum().sum()))
        out = func(out)
        after = (len(out), out.shape[1], int(out.isna().sum().sum()))

        history.append({
            "단계": label,
            "행": f"{before[0]:,}→{after[0]:,}",
            "열": f"{before[1]}→{after[1]}",
            "결측": f"{before[2]:,}→{after[2]:,}",
            "변화": ("행 감소" if after[0] < before[0]
                     else "열 추가" if after[1] > before[1] else "-"),
        })

    hist = pd.DataFrame(history)

    if verbose:
        print(f"\n[{name} 전처리 이력]")
        print(hist.to_string(index=False))

    return out, hist
```

### Step 3. 통합과 검증 (오늘의 종합 예제)

```python
"""3개 소스를 하나의 분석용 테이블로 통합합니다."""

import pandas as pd

print("=" * 84)
print("                       통합 전처리 실행")
print("=" * 84)

# ══════════ ① 소스별 전처리 ══════════
clean_a, hist_a = preprocess(source_a, name="A 관광지")
clean_b, hist_b = preprocess(source_b, name="B 평점")
clean_c, hist_c = preprocess(source_c, name="C 인구")

# ══════════ ② 멱등성 확인 ══════════
print(f"\n[멱등성 검사]  같은 함수를 두 번 돌려도 같은가")

twice, _ = preprocess(clean_a, verbose=False)
same_shape = clean_a.shape == twice.shape

common = [c for c in clean_a.columns if c in twice.columns]
same_values = clean_a[common].equals(twice[common])

print(f"  1회 실행: {clean_a.shape}")
print(f"  2회 실행: {twice.shape}")
print(f"  결과 동일: {'✓' if same_shape and same_values else '✗'}")

# ══════════ ③ 키 정규화 ══════════
print(f"\n[키 정규화]")


def make_region_key(s):
    """지역명을 매칭용 키로 정규화합니다."""
    return (s.astype("string")
             .str.replace(r"(특별시|광역시|특별자치시|특별자치도)", "", regex=True)
             .str.replace(r"(시|군|구|도)$", "", regex=True)
             .str.replace(r"\s+", "", regex=True)
             .str.strip())


clean_a["_region_key"] = make_region_key(clean_a["sigungu"])
clean_c["_region_key"] = make_region_key(
    clean_c["region"].str.split().str[-1])

print(f"  A 키 예시: {clean_a['_region_key'].dropna().unique()[:5].tolist()}")
print(f"  C 키 예시: {clean_c['_region_key'].dropna().unique()[:5].tolist()}")

overlap = set(clean_a["_region_key"].dropna()) & set(clean_c["_region_key"].dropna())
print(f"  겹치는 지역: {len(overlap)}개")

# ══════════ ④ 병합 ══════════
print(f"\n[병합]")

# A + B (관광지 + 평점) — 1:1 이어야 함
merged = clean_a.merge(
    clean_b[["id", "rating", "review_count", "collected_at"]],
    on="id", how="left", indicator="_m_ab", validate="one_to_one")

print(f"\n  A + B  (id 기준, one_to_one)")
print(f"    {len(clean_a)} + {len(clean_b)} → {len(merged)}행")
print(f"    {merged['_m_ab'].value_counts().to_dict()}")

unmatched = (merged["_m_ab"] == "left_only").sum()
print(f"    평점 없는 관광지: {unmatched}건 "
      f"({unmatched / len(merged) * 100:.1f}%)")

# + C (인구) — N:1 이어야 함
merged = merged.merge(
    clean_c[["_region_key", "population", "area_km2",
             "density", "population_year"]],
    on="_region_key", how="left", indicator="_m_c", validate="many_to_one")

print(f"\n  + C  (지역 기준, many_to_one)")
print(f"    {merged['_m_c'].value_counts().to_dict()}")

no_pop = merged[merged["_m_c"] == "left_only"]["_region_key"].dropna().unique()
if len(no_pop):
    print(f"    인구 정보 없는 지역: {list(no_pop)[:6]}")
    print(f"    → 매핑 사전에 추가하거나 데이터 보강 필요")

# ══════════ ⑤ 정리 ══════════
final = merged.drop(columns=[c for c in merged.columns
                             if c.startswith("_m_") or c == "_region_key"])

# 파생 변수 재계산 (병합으로 새 열이 생겼으므로)
final = add_features(final)

COLUMN_ORDER = [
    "id", "name", "sido", "sigungu", "address", "lat", "lng", "has_coord",
    "price", "price_text", "price_grade", "is_free",
    "rating", "weighted_rating", "review_count",
    "population", "area_km2", "density", "population_year",
    "modified_at", "modified_year", "collected_at",
]
final = final[[c for c in COLUMN_ORDER if c in final.columns]
              + [c for c in final.columns if c not in COLUMN_ORDER]]

print(f"\n[최종 테이블]  {final.shape[0]:,}행 × {final.shape[1]}열")

# ══════════ ⑥ 검증 ══════════
print(f"\n{'=' * 84}")
print("[검증]")
print("=" * 84)

checks = []

checks.append(("키 중복", final["id"].duplicated().sum(), 0, "=="))
checks.append(("좌표 결측", final["lat"].isna().sum(),
               len(final) * 0.05, "<="))
checks.append(("이름 결측", final["name"].isna().sum(), 0, "=="))
checks.append(("행 수", len(final), len(source_a), "=="))

for lo_col, (lo, hi) in [("lat", DOMAIN_RULES["lat"]),
                         ("lng", DOMAIN_RULES["lng"]),
                         ("rating", DOMAIN_RULES["rating"])]:
    if lo_col in final.columns:
        bad = ((final[lo_col] < lo) | (final[lo_col] > hi)).sum()
        checks.append((f"{lo_col} 범위 위반", bad, 0, "=="))

print(f"\n  {'검사':<20}{'실제':>10}{'기준':>10}  결과")
print("  " + "-" * 48)

all_pass = True
for label, actual, expected, op in checks:
    ok = (actual == expected) if op == "==" else (actual <= expected)
    all_pass &= ok

> - **처리 이력 표**로 각 단계가 무엇을 했는지 한눈에 보입니다. 행이 줄었는지 열이 늘었는지.

> - **`price` 는 채우지 않았습니다.** "정보 없음"과 "무료"는 다릅니다.
> - **검증을 자동화**했습니다. 조건 하나라도 실패하면 `❌` 가 뜹니다.
> - **interim 은 parquet, processed 는 둘 다** 저장 — 타입 보존과 호환성.

def make_data_dictionary(df, meta=None, title="분석용 테이블"):
    """컬럼 정의서를 생성합니다."""
    meta = meta or {}
    rows = []

    for col in df.columns:
        s = df[col]
        info = meta.get(col, {})
        is_num = pd.api.types.is_numeric_dtype(s)

        rows.append({
            "열": col,
            "한글명": info.get("name", "⚠ 미작성"),
            "타입": str(s.dtype),
            "단위": info.get("unit", ""),
            "결측": int(s.isna().sum()),
            "결측률": f"{s.isna().mean() * 100:.1f}%",
            "고유값": int(s.nunique()),
            "범위": (f"{s.min():,.2f} ~ {s.max():,.2f}"
                     if is_num and s.notna().any() else ""),
            "예시": str(s.dropna().iloc[0])[:20] if s.notna().any() else "",
            "출처": info.get("source", "⚠ 미작성"),
            "결측의미": info.get("na_meaning", "⚠ 미작성"),
            "비고": info.get("note", ""),
        })

    return pd.DataFrame(rows)

import numpy as np
import pandas as pd

RAW = Path("data/raw")
PROCESSED = Path("data/processed")
PROCESSED.mkdir(parents=True, exist_ok=True)

MAX_PRICE = 100_000
KEY = "id"


# ══════════ 단계별 함수 ══════════

def clean_strings(df):
    """문자열 정제 — 가장 먼저 (키 매칭에 영향)."""
    out = df.copy()
    for col in out.select_dtypes(include=["object", "string"]).columns:
        out[col] = (out[col].astype("string")
                    .str.replace(r"[\xa0​]", " ", regex=True)
                    .str.replace(r"\s+", " ", regex=True)
                    .str.strip())
    return out


def convert_types(df):
    """타입 변환 — 원본 보존."""
    out = df.copy()

    if "price" in out.columns and out["price"].dtype == "object":
        out["price_text"] = out["price"]                      # ② 원본 보존
        out["price"] = pd.to_numeric(
            out["price"].str.replace(r"[^\d.]", "", regex=True)
                        .replace("", np.nan),
            errors="coerce")                                   # ⑤

    if "date" in out.columns:
        out["date"] = pd.to_datetime(out["date"], errors="coerce")   # ⑤

    return out


def drop_dups(df, key=KEY):
    """키 기준 중복 제거."""
    out = df.copy()
    if key not in out.columns:
        return out.drop_duplicates()                           # ⑥
    sort_col = "date" if "date" in out.columns else key
    return (out.sort_values(sort_col, na_position="first")
               .drop_duplicates(subset=[key], keep="last")
               .reset_index(drop=True))


def handle_outliers(df):
    """이상치를 제거하지 않고 NaN 으로 — 멱등 보장."""
    out = df.copy()

    if "price" in out.columns:
        mask = out["price"] > MAX_PRICE                        # ③ 멱등
        out["price_was_outlier"] = mask.fillna(False)
        out.loc[mask, "price"] = np.nan

    return out


def add_features(df):
    """파생 변수."""
    out = df.copy()
    if "date" in out.columns:
        out["year"] = out["date"].dt.year
        out["month"] = out["date"].dt.month
    return out


# ══════════ 파이프라인 ══════════

def preprocess(df, verbose=True):
    """원본 → 분석용. 몇 번을 돌려도 같은 결과."""
    out = df.copy()                                            # ②
    history = []

    steps = [                                                  # ① 순서 고정
        ("문자열 정제", clean_strings),
        ("타입 변환", convert_types),
        ("중복 제거", drop_dups),
        ("이상치 처리", handle_outliers),
        ("파생 변수", add_features),
    ]

    for name, func in steps:
        before = (len(out), out.shape[1])
        out = func(out)
        history.append({
            "단계": name,
            "행": f"{before[0]:,}→{len(out):,}",
            "열": f"{before[1]}→{out.shape[1]}",
        })

    hist = pd.DataFrame(history)

    if verbose:
        print(hist.to_string(index=False))

    return out, hist


def validate(df):
    """전처리 결과 검증."""                                     # ⑦
    checks = {
        "행 수 > 0": len(df) > 0,
        "키 중복 없음": (df[KEY].duplicated().sum() == 0
                        if KEY in df.columns else True),
        "이름 결측 없음": (df["name"].isna().sum() == 0
                          if "name" in df.columns else True),
        "가격 범위": (df["price"].dropna() <= MAX_PRICE).all()
                     if "price" in df.columns else True,
    }

    for label, ok in checks.items():
        print(f"  {'✓' if ok else '✗'} {label}")

    return all(checks.values())


# ══════════ 실행 ══════════
if __name__ == "__main__":
    raw = pd.read_csv(RAW / "data.csv")                        # ④ raw 는 읽기만
    print(f"[원본] {raw.shape}")

    clean, hist = preprocess(raw)

    # ③ 멱등성 확인
    twice, _ = preprocess(clean, verbose=False)
    print(f"\n[멱등성] {'✓' if clean.shape == twice.shape else '✗'}")

    print(f"\n[검증]")
    passed = validate(clean)

    if passed:
        clean.to_csv(PROCESSED / "clean.csv",                  # ④ 다른 경로
                     index=False, encoding="utf-8-sig")
        hist.to_csv(PROCESSED / "preprocess_log.csv",
                    index=False, encoding="utf-8-sig")
        print(f"\n[저장] data/processed/clean.csv ({len(clean):,}행)")
    else:
        print(f"\n⛔ 검증 실패 — 저장하지 않습니다")

    병합 전에 문제를 진단합니다.

    반환: dict(safe, expected_rows, issues)
    """

    line = "=" * 80

    lk = left[left_on]

    if verbose:
        print(line)
        print(f"          병합 사전 진단: {left_name} ⨝ {right_name}")
        print(line)

    # ══════════ ① 타입 ══════════
    if verbose:
        print(f"\n[① 키 타입]")
        print(f"  {left_name}.{left_on:<16}{lk.dtype}")
        print(f"  {right_name}.{right_on:<16}{rk.dtype}")

    if lk.dtype != rk.dtype:
        issues.append(("치명", f"키 타입 불일치: {lk.dtype} vs {rk.dtype} "

            print(f"  ✗ 타입이 다릅니다 — astype 으로 맞추세요")

    # ══════════ ② 유일성 ══════════
    l_dup = lk.duplicated().sum()
    r_dup = rk.duplicated().sum()

    if verbose:
        print(f"\n[② 키 유일성]")
        print(f"  {left_name}  : {lk.nunique():,} / {len(lk):,} "
              f"(중복 {l_dup})")
        print(f"  {right_name} : {rk.nunique():,} / {len(rk):,} "
              f"(중복 {r_dup})")

    relation = ("one_to_one" if not l_dup and not r_dup
                else "many_to_one" if l_dup and not r_dup
                else "one_to_many" if not l_dup and r_dup
                else "many_to_many")

    if verbose:
        print(f"  관계      : {relation}")

    if relation == "many_to_many":
        issues.append(("치명", "양쪽 모두 키 중복 — 행이 폭발적으로 증가"))
    elif r_dup:
        expected = len(left) + r_dup

                               f"— 행이 약 {expected:,}개로 증가"))

    # ══════════ ③ 매칭률 ══════════
    lset = set(lk.dropna())
    rset = set(rk.dropna())
    both = lset & rset

    l_rate = len(both) / len(lset) * 100 if lset else 0
    r_rate = len(both) / len(rset) * 100 if rset else 0

    if verbose:
        print(f"\n[③ 매칭률]")
        print(f"  겹치는 키    : {len(both):,}개")
        print(f"  {left_name} 매칭  : {l_rate:.1f}%  "
              f"({len(lset) - len(both):,}개 미매칭)")
        print(f"  {right_name} 매칭 : {r_rate:.1f}%  "
              f"({len(rset) - len(both):,}개 미매칭)")

    if l_rate == 0:
        issues.append(("치명", "매칭되는 키가 하나도 없음 — 키 정규화 필요"))
    elif l_rate < 50:
        issues.append(("경고", f"{left_name} 매칭률 {l_rate:.0f}% — 키 형식 확인"))

    # ── 미매칭 샘플 ──
    if verbose and lset - both:
        sample_l = list(lset - both)[:5]
        sample_r = list(rset - both)[:5]
        print(f"\n  {left_name} 에만 있는 키  : {sample_l}")
        if sample_r:
            print(f"  {right_name} 에만 있는 키 : {sample_r}")

    # ══════════ ④ 정규화하면 나아지나 ══════════
    def normalize(s):
        return (s.astype(str).str.strip().str.lower()
                 .str.replace(r"[\s\-_()]", "", regex=True))

    n_both = set(normalize(lk).dropna()) & set(normalize(rk).dropna())

    if verbose:
        print(f"\n[④ 정규화 효과]")
        print(f"  현재      : {len(both):,}개 매칭")
        print(f"  정규화 후 : {len(n_both):,}개 매칭 "

                               f"— 공백·대소문자 통일 권장"))

    # ══════════ ⑤ 열 이름 충돌 ══════════
    common_cols = (set(left.columns) & set(right.columns)) - {left_on, right_on}

    if verbose:
        print(f"\n[⑤ 열 이름 충돌]")
        if common_cols:
            print(f"  {sorted(common_cols)} → _x, _y 접미사가 붙습니다")
        else:
            print(f"  없음")

    if common_cols:
        issues.append(("경고", f"중복 열 {len(common_cols)}개 — "
                               f"suffixes 지정 또는 사전 정리 권장"))

    # ══════════ ⑥ 단위 의심 ══════════
    num_common = [c for c in common_cols
                  if pd.api.types.is_numeric_dtype(left[c])
                  and pd.api.types.is_numeric_dtype(right[c])]

    if num_common:
        if verbose:
            print(f"\n[⑥ 단위 의심 (같은 이름 숫자 열)]")

        for c in num_common:
            lm, rm = left[c].median(), right[c].median()
            if lm and rm:
                ratio = max(lm, rm) / min(lm, rm)
                mark = "⚠" if ratio > 50 else " "
                if verbose:
                    print(f" {mark}{c:<16}{lm:>14,.2f}{rm:>14,.2f}"
                          f"  {ratio:>8.0f}배")
                if ratio > 50:
                    issues.append(("경고", f"'{c}' 중앙값이 {ratio:.0f}배 차이 "
                                           f"— 단위 불일치 의심"))

    # ══════════ ⑦ 예상 결과 ══════════
    if relation == "one_to_one":
        expected = len(left)
    elif relation == "many_to_one":
        expected = len(left)
    else:
        merge_factor = rk.value_counts().reindex(lk).fillna(1)
        expected = int(merge_factor.sum())

    if verbose:
        print(f"\n[⑦ 예상 결과 (how='left')]")
        print(f"  입력  : {len(left):,}행")
        print(f"  예상  : {expected:,}행")
        print(f"  권장  : validate='{relation}'")

    # ══════════ 결과 ══════════
    fatal = [i for i in issues if i[0] == "치명"]
    safe = not fatal

    if verbose:
        print(f"\n{line}")
        print(f"  판정: {'✅ 병합 가능' if safe else '❌ 병합 전 수정 필요'}")
        print(line)

        for level, msg in issues:
            print(f"  {'🔴' if level == '치명' else '🟡'} [{level}] {msg}")

        if not issues:
            print("  문제 없음")

        print(f"\n  [권장 코드]")
        print(f"  merged = {left_name}.merge(")
        print(f"      {right_name}, left_on='{left_on}', right_on='{right_on}',")
        print(f"      how='left', indicator=True, validate='{relation}')")
        print(f"  print(merged['_merge'].value_counts())")
        print(line)

    return {"safe": safe, "expected_rows": expected,
            "relation": relation, "issues": issues}

"""스키마 기반 검증."""

import numpy as np

# ══════════ 스키마 정의 ══════════
SCHEMA = {
    "id": {
        "dtype": "string", "required": True, "unique": True,
        "nullable": False,
    },
    "name": {
        "dtype": "string", "required": True, "nullable": False,

                    "경기도", "강원특별자치도", "충청북도", "충청남도",
                    "전북특별자치도", "전라남도", "경상북도", "경상남도",
                    "제주특별자치도"],
    },
    "lat": {"dtype": "float", "required": True, "range": (33.0, 39.0),
            "max_na_rate": 0.10},
    "lng": {"dtype": "float", "required": True, "range": (124.0, 132.0),
            "max_na_rate": 0.10},
    "price": {"dtype": "float", "required": False, "range": (0, 1_000_000),
              "max_na_rate": 0.50},
    "rating": {"dtype": "float", "required": False, "range": (0.0, 5.0),
               "max_na_rate": 0.30},
    "review_count": {"dtype": "float", "required": False, "range": (0, None),
                     "max_na_rate": 0.0},
    "modified_at": {"dtype": "datetime", "required": False,
                    "range": ("2000-01-01", "2030-12-31")},
}


def validate_schema(df, schema=SCHEMA, verbose=True):
    """
    DataFrame 이 스키마를 만족하는지 검사합니다.

    반환: dict(passed, errors, warnings)
    """
    errors, warnings_list = [], []
    line = "=" * 82

    if verbose:
        print(line)
        print("                        스키마 검증")
        print(line)
        print(f"\n  대상: {len(df):,}행 × {df.shape[1]}열")

    # ══════════ ① 필수 열 존재 ══════════
    required = [c for c, r in schema.items() if r.get("required")]
    missing = [c for c in required if c not in df.columns]
    extra = [c for c in df.columns if c not in schema]

    if verbose:
        print(f"\n[① 열 존재]")
        print(f"  필수 {len(required)}개 중 {len(required) - len(missing)}개 존재")

    if missing:
        errors.append(f"필수 열 누락: {missing}")
        if verbose:
            print(f"  ✗ 누락: {missing}")

    if verbose and extra:
        print(f"  ℹ 스키마에 없는 열 {len(extra)}개: {extra[:6]}")

    # ══════════ ② 열별 검사 ══════════
    if verbose:
        print(f"\n[② 열별 검사]")
        print(f"  {'열':<16}{'타입':<12}{'결측률':>8}{'범위위반':>10}  결과")
        print("  " + "-" * 60)

    for col, rule in schema.items():
        if col not in df.columns:
            continue

        s = df[col]
        col_errors = []

        # ── 타입 ──
        expected = rule.get("dtype")
        actual = str(s.dtype)

        type_ok = True
        if expected == "float":
            type_ok = pd.api.types.is_numeric_dtype(s)
        elif expected == "string":
            type_ok = (pd.api.types.is_string_dtype(s)
                       or s.dtype == "object")
        elif expected == "datetime":
            type_ok = pd.api.types.is_datetime64_any_dtype(s)

        if not type_ok:
            col_errors.append(f"타입 {actual} (기대: {expected})")

        # ── 결측 ──
        na_rate = s.isna().mean()
        max_na = rule.get("max_na_rate", 1.0)

        if not rule.get("nullable", True) and s.isna().any():
            col_errors.append(f"결측 불가인데 {s.isna().sum()}건")
        elif na_rate > max_na:
            col_errors.append(f"결측률 {na_rate:.1%} > 허용 {max_na:.0%}")

        # ── 유일성 ──
        if rule.get("unique") and s.duplicated().sum():
            col_errors.append(f"중복 {s.duplicated().sum()}건")

        # ── 범위 ──
        violations = 0
        if "range" in rule and type_ok:
            lo, hi = rule["range"]

            if expected == "datetime":
                lo = pd.Timestamp(lo) if lo else None
                hi = pd.Timestamp(hi) if hi else None

            valid = s.dropna()
            if lo is not None:
                violations += (valid < lo).sum()
            if hi is not None:
                violations += (valid > hi).sum()

            if violations:
                col_errors.append(f"범위 위반 {violations}건")

        # ── 허용값 ──
        if "allowed" in rule:
            bad = ~s.dropna().isin(rule["allowed"])
            if bad.any():
                unexpected = s.dropna()[bad].unique()[:3]
                col_errors.append(f"허용 외 값: {list(unexpected)}")

        # ── 길이 ──
        if "max_length" in rule and type_ok and expected == "string":
            too_long = (s.dropna().astype(str).str.len()
                        > rule["max_length"]).sum()
            if too_long:
                col_errors.append(f"길이 초과 {too_long}건")

        if verbose:
            mark = "✓" if not col_errors else "✗"
            print(f"  {col:<16}{actual:<12}{na_rate:>7.1%}"
                  f"{violations:>10}  {mark}")

        for e in col_errors:
            level = errors if rule.get("required") else warnings_list
            level.append(f"'{col}': {e}")

    # ══════════ ③ 행 수준 검사 ══════════
    if verbose:
        print(f"\n[③ 행 수준]")

    if len(df) == 0:
        errors.append("행이 0개")
    else:
        all_na_rows = df.isna().all(axis=1).sum()
        if verbose:
            print(f"  전부 결측인 행: {all_na_rows}건")
        if all_na_rows:
            warnings_list.append(f"전부 결측인 행 {all_na_rows}건")

        if {"lat", "lng"} <= set(df.columns):
            partial = (df["lat"].isna() != df["lng"].isna()).sum()
            if verbose:
                print(f"  좌표 한쪽만 있는 행: {partial}건")
            if partial:
                warnings_list.append(f"좌표 한쪽만 존재 {partial}건")

    # ══════════ 결과 ══════════
    passed = not errors

    if verbose:
        print(f"\n{line}")
        print(f"  판정: {'✅ 통과' if passed else '❌ 실패'}"
              f"   (오류 {len(errors)} · 경고 {len(warnings_list)})")
        print(line)

        for e in errors:
            print(f"  🔴 {e}")
        for w in warnings_list:
            print(f"  🟡 {w}")

        if passed and not warnings_list:
            print("  문제 없음")

        print(line)

    return {"passed": passed, "errors": errors, "warnings": warnings_list}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    print(">>> 정상 데이터\n")
    validate_schema(final)

    print("\n\n>>> 문제 있는 데이터\n")
    broken = final.copy()
    broken.loc[0, "lat"] = 99.9                    # 범위 위반
    broken.loc[1, "name"] = None                   # 결측 불가
    broken.loc[2, "sido"] = "서울시"                # 허용 외
    broken = pd.concat([broken, broken.head(2)])   # 키 중복

    validate_schema(broken)
```

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 폴더 구조 | **`raw`(불변) / `interim` / `processed`** |
| 저장 형식 | 중간은 **Parquet**(타입 보존), 최종은 CSV |
| 함수 원칙 | ① `df.copy()` ② **멱등성** ③ 작게 나누기 |
| 체인 | **`.pipe()`** 로 순서를 코드에 드러내기 |
| **처리 순서** | 열→타입→문자열→중복→**이상치→결측**→파생→검증 |
| 키 불일치 | 양쪽 **정규화 후** 매칭 |
| 병합 검증 | **`validate=`** + **`indicator=True`** |
| 단위 불일치 | 통합 전 소스별 `describe()` 비교 |
| 기준시점 | 컬럼 정의서 + 보고서 한계에 **명시** |
| 컬럼 정의서 | 한글명·**단위**·출처·**결측 의미**·허용 범위 |
| 스키마 검증 | **통과해야 저장** |
| 처리 이력 | 단계별 행·열·결측 변화를 표로 |

**오늘 반드시 기억할 세 가지**
> ① **`raw/` 는 절대 건드리지 마세요.** 수집은 비싸고 파싱은 쌉니다.
> ② **두 번 돌려도 같은 결과여야 합니다.** 아니면 파이프라인이 아니라 그냥 코드입니다.
> ③ **`price` 결측이 "무료"인지 "정보 없음"인지** — 컬럼 정의서에 없으면 아무도 모릅니다.
