## ③ 개념 설명

### 카메라 모듈(CSI) vs USB 웹캠

```
① CSI  [센서] ──리본──→ [파이 CSI 포트] → ★ SoC 내부 ISP → 메모리 (하드웨어)
② USB  [웹캠(센서+ISP+JPEG인코더)] ──USB──→ [파이] → ★ CPU 디코딩 → 메모리
```

**핵심 차이는 "누가 일하는가" 입니다.** CSI 는 전용 하드웨어가, USB 는 CPU 가 일합니다.

| 항목 | **CSI 카메라 모듈** | **USB 웹캠** |
|---|---|---|
| 인터페이스 · 대역폭 | MIPI CSI-2 리본 · 수 Gbps | USB 2.0 · 실효 약 280 Mbps |
| 전송 형식 | RAW (비압축) | MJPEG / YUYV |
| **CPU 부하** | **거의 없음** (ISP) | **있음** (MJPEG 디코딩) |
| 1080p30 CPU | 약 12% | **약 28~35%** |
| 노출·게인 제어 | **완전 제어** | 제한적 (`v4l2-ctl` 일부) |
| 케이블 길이 | **15~30cm** | **3~5m 연장 가능** |
| 야간(IR) | NoIR 모델 있음 | 대부분 IR 차단 필터 고정 |
| 동시 연결 | 파이5=2, 파이4=1 | 여러 대 (대역폭 한도까지) |
| 소프트웨어 | `libcamera` / `picamera2` | V4L2 / OpenCV 표준 |
| PC 에서 테스트 | ✗ (파이에서만) | **가능** (개발 편함) |
| 핫플러그 | ✗ **전원 끄고 연결** | 가능 |

### USB 웹캠의 숨은 비용 — MJPEG 디코딩

USB 웹캠은 **압축된 JPEG 프레임**을 보냅니다. 파이는 **매 프레임 CPU 로** 풀어야 합니다.

| 해상도 | USB: JPEG 디코딩/프레임 | 30 FPS 시 1코어 | CSI: `capture_array()` |
|---|---|---|---|
| 640×480 | 1.6 ms | 4.8% | 0.4 ms |
| 1280×720 | 4.1 ms | 12.3% | 0.9 ms |
| **1920×1080** | **9.3 ms** | **27.9%** | **1.9 ms** |

```
1080p30 기준
  USB : 9.3ms × 30 = 279 ms/초 = 1코어의 28%
  CSI : 1.9ms × 30 =  57 ms/초 = 1코어의  5.7%
  차이 = ★ 파이 5 전체의 약 5.5% → Day 168 NCNN 추론 예산
```

> ⚠️ **"USB 는 그냥 꽂으면 되니 편하다" 는 개발 중에만 맞습니다.**
> 24시간 돌리는 CCTV 에서 **CPU 22%p 는 곧 발열이고 스로틀링**입니다([Day 168](day-168.md)).

### 대역폭 계산 — 왜 YUYV 는 느린가

| 포맷 | 압축 | 프레임 크기(1280×720) | 특징 |
|---|---|---|---|
| **YUYV**(=YUY2) | 없음 | 1,843,200 B (1.76 MB) | 화질 손실 없음 · 디코딩 불필요 |
| **MJPG** | JPEG | 약 60,000 B (60 KB) | 30배 작음 · CPU 디코딩 필요 |

**USB 2.0 실효 대역폭 = 약 35 MB/s (280 Mbps)**

| 해상도 | 포맷 | 30 FPS 필요 대역폭 | USB2 가능? | 카메라가 주는 FPS |
|---|---|---|---|---|
| 640×480 | YUYV | 18.4 MB/s | ✓ | 30 |
| **1280×720** | **YUYV** | **55.3 MB/s** | ✗ 초과 | **10** |
| 1280×720 | MJPG | 1.8 MB/s | ✓ | 30 |
| **1920×1080** | **YUYV** | **124.4 MB/s** | ✗ 크게 초과 | **5** |
| 1920×1080 | MJPG | 4.0 MB/s | ✓ | 30 (저가는 15) |

```
★ 가장 자주 하는 실수
  해상도와 FPS 만 설정 → OpenCV 기본이 YUYV 인 경우가 많음
  → 대역폭 초과 → 카메라가 스스로 10 FPS 로 낮춤
  → 해결: FOURCC 로 MJPG 를 명시

YUYV : 대역폭↑↑ CPU↓   → 저해상도에서만 실용
MJPG : 대역폭↓  CPU↑↑  → 720p 이상에서는 사실상 필수
CSI  : 대역폭○  CPU↓↓  → 둘 다 이김 (대신 케이블이 짧음)
```

### 결정 가이드 — 어떤 상황에 무엇을

| 상황 | 권장 | 이유 |
|---|---|---|
| 파이 바로 옆(30cm 이내) | **CSI** | CPU 여유 · 화질 · 노출 제어 |
| 카메라만 2~5m 떨어짐 | **USB** | 리본은 30cm 가 한계 |
| **야간 감시 필수** | **CSI NoIR** | IR 조명 사용 가능 |
| CPU 여유가 절실 | **CSI** | 1080p 기준 22%p 절약 |
| 카메라 3대 이상 | USB | CSI 포트 수 제한 |
| 노트북에서 먼저 개발 | USB | PC 에서도 그대로 동작 |
| 실외 방수 하우징 필요 | USB (완제품) | CSI 는 직접 제작 |
| 노출·WB 정밀 고정 | **CSI** | `set_controls` 완전 제어 |
| **우리 팀 (현관 감시)** | **CSI 우선, USB 대안** | 파이와 카메라를 한 상자에 |

```
★ 우리 프로젝트의 결론 — 코드는 둘 다 지원 (camera.py 추상화)
   · 팀마다 받은 부품이 다를 수 있음
   · 설치 장소가 정해지면 케이블 길이 때문에 바꿔야 할 수도 있음
   · --source 옵션만 바꾸면 되게
```

### 라즈베리파이 카메라 모듈 계보

| 모델 | 센서 | 화소 | 초점 | 수평화각 | 특징 |
|---|---|---|---|---|---|
| **Camera Module v2** (+NoIR) | IMX219 | 8MP | 고정 | **62.2°** | 가장 흔함 |
| **Camera Module 3** (+NoIR) | IMX708 | 12MP | **AF** | **66°** | HDR · 오토포커스 |
| Module 3 **Wide** | IMX708 | 12MP | AF | **102°** | 좁은 공간용 |
| **HQ Camera** | IMX477 | 12.3MP | 렌즈 교체 | 렌즈에 따름 | C/CS 마운트 |
| Global Shutter | IMX296 | 1.6MP | 렌즈 교체 | 렌즈에 따름 | 고속 이동 물체 |

```
★ NoIR 이란
  일반 : 센서 앞에 IR 차단 필터 → 적외선 조명을 쬐도 아무것도 안 보임
  NoIR : 필터 없음 → 850nm IR 조명이면 캄캄해도 보임
         대신 주간 색감이 붉게 틀어짐
```

> ⚠️ **NoIR 은 "야간에 잘 보이는 카메라" 가 아닙니다.**
> **IR 조명이 있어야** 보입니다. NoIR + 조명 없음 = 일반 카메라보다도 어둡습니다.

### 카메라 연결 — 전원을 끄고, 리본 방향을 맞추고

```
① sudo shutdown -h now  ★ 반드시 종료 (LED 꺼짐 확인)   ② 전원 케이블 분리
③ CSI 커넥터 걸쇠를 들어올림   ④ 리본 삽입(방향 주의)   ⑤ 걸쇠 고정
⑥ 카메라 쪽도 동일   ⑦ 전원 연결 → 부팅
```

> ⚠️ **전원이 켜진 상태에서 CSI 를 꽂으면 모듈이 손상될 수 있습니다.**
> USB 는 핫플러그가 되지만 **CSI 는 안 됩니다.**

```
★ 리본 방향 — 거꾸로 꽂으면 인식되지 않습니다

   ┌──────────────────────┐
   │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← 은색 금속 접점 면
   └──────────────────────┘
   ┌──────────────────────┐
   │                      │  ← 파란색 보강 테이프 면
   └──────────────────────┘

  · 파이 보드 쪽  : 은색 접점이 HDMI 방향 (파란 면이 USB/이더넷 방향)
  · 카메라 모듈 쪽: 은색 접점이 렌즈 반대편(기판 쪽)
  ★ 외우기 어렵다면 "파란 면이 걸쇠 쪽" (파이5·파이4 공통)

커넥터 규격
  파이 4/3 : 15핀 CSI ×1     파이 5 : 22핀 미니 CSI ×2 (cam0/cam1)
  → 파이 5 에 기존 모듈을 쓰려면 15↔22핀 변환 케이블이 필요
```

| 확인 | 방법 | 정상 |
|---|---|---|
| 걸쇠가 완전히 눌림 | 케이블을 살짝 당김 | 빠지지 않음 |
| 리본이 비뚤지 않음 | 양쪽 끝 간격 | 좌우 대칭 |
| 방향이 맞음 | 파란 면 위치 | 위 규칙대로 |
| **렌즈 보호 필름 제거** | 렌즈 표면 확인 | **제거됨** |

> ⚠️ **렌즈 보호 필름을 안 떼서 "초점이 안 맞는다" 로 하루를 보내는 팀이 매년 나옵니다.**
> Camera Module 3 는 투명 필름이라 잘 안 보입니다. **반드시 확인하세요.**

> ⚠️ **★ CSI 카메라의 `/dev/videoN` 을 `cv2.VideoCapture` 로 열면 안 됩니다.**
> `rp1-cfe` · `pispbe` 아래 장치는 **libcamera 파이프라인의 내부 노드**입니다.
> `cv2.VideoCapture(0)` 은 **열리는 척하다가 프레임을 주지 않거나 즉시 실패**합니다.
> **CSI 는 반드시 `picamera2`(libcamera) 로 접근하세요.**

```bash

### 색이 뒤집히는 문제 (RGB / BGR)

```python

**★ `libcamera` 의 포맷 이름은 "거꾸로" 읽습니다**

| `format` 문자열 | `capture_array()` 채널 순서 | 채널 | OpenCV 에 바로? |
|---|---|---|---|
| **`"RGB888"`** | **B, G, R** | 3 | **✓ 그대로** |
| **`"BGR888"`** | **R, G, B** | 3 | ✗ `COLOR_RGB2BGR` |
| `"XRGB8888"` | B, G, R, X | 4 | △ `COLOR_BGRA2BGR` |
| `"XBGR8888"` | R, G, B, X | 4 | ✗ `COLOR_RGBA2BGR` |
| `"YUV420"` | YUV 평면 | — | ✗ `COLOR_YUV420p2BGR` |

```
★ 왜 이름이 반대인가
  libcamera 의 이름은 32비트 워드를 최상위 바이트부터 읽은 것입니다 (리틀엔디언)
  "RGB888" = 워드로는 R,G,B = 메모리 바이트 순서로는 B,G,R
           = numpy 배열의 채널 순서도 B,G,R
  → 결론: OpenCV 를 쓸 거면 format="RGB888" 이 정답
```

> ⚠️ **이 표는 외우지 말고 실험으로 확인하세요.**
> `picamera2` · `libcamera` 버전 조합에 따라 결과가 달라진 이력이 있습니다.
> **★ 빨간 물체를 하나 놓고 찍어 보는 것이 가장 확실합니다** (Step 2).

어떤 포맷이 와도 BGR 3채널로 통일하는 변환은 **Step 3 의 `camera.py`** 에서 `FORMAT_TO_BGR`
매핑 한 줄로 처리합니다. 호출부는 색 순서를 아예 신경 쓰지 않게 됩니다.

```

  YOLO 는 RGB 로 정규화해 학습했고 ultralytics 가 BGR→RGB 변환을 해 줍니다
  · BGR 을 주면 → 내부 변환 → RGB (정상)
  · RGB 를 주면 → 내부 변환 → BGR (색이 반대인 이미지로 추론)

### OpenCV `VideoCapture` 와 `CAP_PROP_FOURCC`

```python
cap = cv2.VideoCapture("/dev/video30", cv2.CAP_V4L2)           # 백엔드 명시
cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*"MJPG"))  # ★ ① FOURCC 먼저
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)                        # ★ ② 해상도
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)
cap.set(cv2.CAP_PROP_FPS, 30)                                  # ③ 마지막
cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)                            # 지연 감소
```

| 백엔드 | 상수 | 특징 |
|---|---|---|
| 자동 | `CAP_ANY` (기본) | 무엇이 선택될지 모름 — FOURCC 가 무시될 수 있음 |
| **V4L2** | `CAP_V4L2` | **리눅스** · FOURCC·컨트롤 지원 |
| GStreamer / FFMPEG | `CAP_GSTREAMER` / `CAP_FFMPEG` | 파이프라인 · 파일·RTSP |

```
★ 순서를 바꾸면
  해상도 먼저 → YUYV 1280×720 설정
  FOURCC 나중 → 드라이버가 포맷을 바꾸며 해상도를 640×480 으로 되돌림
```

```python
def fourcc_str(cap):
    v = int(cap.get(cv2.CAP_PROP_FOURCC))
    return "".join(chr((v >> (8 * i)) & 0xFF) for i in range(4))

print(fourcc_str(cap), cap.get(cv2.CAP_PROP_FPS))   # 정상 MJPG 30.0 / 실패 YUYV 10.0
ok, frame = cap.read(); print(frame.shape)          # ★ 가장 확실한 검증
```

> ⚠️ **`cap.set()` 이 `True` 를 반환해도 적용됐다는 뜻이 아닙니다.**
> **`cap.get()` 으로 되읽고, 더 확실하게는 `frame.shape` 로 확인하세요.**

| 속성 | 의미 | 비고 |
|---|---|---|
| `FRAME_WIDTH/HEIGHT` | 해상도 | 지원 목록에 있는 값만 |
| `FPS` | 프레임레이트 | 자주 무시됨 |
| `FOURCC` | 픽셀 포맷 | 필수 |
| **`BUFFERSIZE`** | 내부 버퍼 | **1** (지연 감소) |
| `AUTO_EXPOSURE` / `EXPOSURE` | 노출 | 1=수동, 3=자동 (드라이버별) |
| `AUTO_WB` / `WB_TEMPERATURE` | 화이트밸런스 | 2800~6500K |

```
★ 버퍼가 왜 문제인가 (Day 153 복습)
  추론 100ms 인데 카메라는 33ms 마다 프레임을 밀어 넣음 → 버퍼에 쌓임
  → cap.read() 가 3초 전 프레임 반환 → "사람이 지나갔는데 3초 뒤 알림"
  해결 ① BUFFERSIZE=1  ② 별도 스레드로 계속 read → 최신 프레임만 보관
       (= Day 153 의 LatestFrameCapture — 오늘 ThreadedCamera 로 재구현)

★ 장치 번호는 바뀝니다 (재부팅·재삽입, CSI 가 있으면 USB 는 video30 대)
  → /dev/v4l/by-id/... 경로를 쓰세요
```

**설정이 무시되는 경우**

| 경우 | 증상 | 확인법 | 해결 |
|---|---|---|---|
| 지원 안 하는 해상도 | 가까운 값으로 대체 | `--list-formats-ext` | 지원 목록에서 선택 |
| FOURCC 미지정 | YUYV 로 열려 FPS 급락 | `fourcc_str(cap)` | MJPG 지정 |
| 백엔드가 `CAP_ANY` | set 이 전부 무시 | — | `CAP_V4L2` |
| set 순서가 틀림 | 해상도가 되돌아감 | `frame.shape` | FOURCC→크기→FPS |
| **조명이 어두움** | **FPS 가 자동 반감** | 노출값 확인 | 조명 추가 |
| USB 허브 공유 | 2대 동시 사용 시 급락 | `lsusb -t` | 다른 포트로 분리 |
| 전력 부족 | 간헐적 끊김 | `dmesg` | 외부 전원 허브 |

> ⚠️ **★ 어두우면 FPS 가 스스로 반토막 납니다.**
> 자동 노출이 노출 시간을 늘리는데, 노출 시간은 프레임 간격보다 길 수 없기 때문입니다.
> ```
> 밝은 실내 exp 16.6ms → 30.0 FPS   어두운 방 exp 66ms → 15.1 FPS
> 야간 exp 99.9ms → 9.9 FPS
> ```
> **CCTV 에서 밤에 FPS 가 떨어지는 첫 번째 이유입니다.**

```

### 노출·화이트밸런스·초점 — 자동 제어가 CCTV 에서 일으키는 문제

| 제어 | 조절 대상 | 자동일 때 |
|---|---|---|
| **AE** (Auto Exposure) | 노출 시간 + 게인 | 밝기가 계속 변함 |
| **AWB** (Auto White Balance) | R/B 채널 이득 | 색이 계속 변함 |
| **AF** (Auto Focus) | 렌즈 위치 | 초점이 왔다 갔다 |

```
① 헤드라이트  밤에 차가 지나감 → AE 가 노출을 1/4 로 → 나머지가 새까맣게
              → 사람이 있어도 검출 불가 → ★ 3~5초에 걸쳐 서서히 복구
② 구름        게인 2.0 → 6.0 → 노이즈 급증 → conf 0.78 → 0.41
              → 이벤트가 켜졌다 꺼졌다 (Day 170 알림 폭탄)
③ AWB 흔들림  빨간 옷이 화면을 채움 → 파란 채널 상승 → 프레임마다 색이 다름
④ AF 헌팅     움직이는 물체를 따라 초점 재조정 → 0.3초 흐림 → 그 프레임 미검출
```

> ⚠️ **★ CCTV 는 "장면이 거의 안 바뀌는" 카메라입니다.**
> 자동 제어는 **장면이 계속 바뀌는 사진기**를 위한 기능이라, 고정 카메라에서는 손해가 큽니다.

```python
# ★ Auto-then-Lock — 자동으로 한 번 재고 그 값으로 못 박는다
from libcamera import controls

picam2.set_controls({"AeEnable": True, "AwbEnable": True})     # ① 자동으로 수렴
picam2.start(); time.sleep(3)

md = picam2.capture_metadata()                                  # ② 그때의 값을 읽는다
print(md["ExposureTime"], md["AnalogueGain"], md["ColourGains"], md.get("Lux"))
# 19998  1.87  (1.79, 1.62)  142.3

picam2.set_controls({                                           # ③ 그 값으로 고정
    "AeEnable": False, "ExposureTime": int(md["ExposureTime"]),
    "AnalogueGain": float(md["AnalogueGain"]),
    "AwbEnable": False, "ColourGains": tuple(md["ColourGains"]),
    "AfMode": controls.AfModeEnum.Manual, "LensPosition": 0.25,   # ≈4m
})
```

| 4,000 | 1/250 | 250 | 없음 | | 1.0 ~ 2.0 | 없음~미미 |
| **16,667** | **1/60** | **60** | 적음 (표준) | | 4.0 | 눈에 보임 |

```

  ExposureTime = 100,000 이면 아무리 설정해도 10 FPS 를 넘을 수 없습니다

### 프라이버시 — 찍어도 되는 범위

[Day 154](day-154.md) `DECISION_154` 를 설치에 반영합니다. 영상은 **로컬망 밖으로 나가지 않고**,

| 항목 | 내용 |
|---|---|
| 촬영 범위 | **타인의 주거·창문이 화면에 들어가지 않게** |
| 공용 공간 | 복도·현관은 관리 주체의 동의 필요 |
| 실습 촬영 | **동의한 팀원만** 피사체로 |
| 학습 데이터 | 얼굴이 식별되는 이미지는 저장소에 올리지 않음 |
| 저장 · 스트림 | 로컬 SD카드 · 외부 클라우드 금지 · **포트포워딩 금지** |
| 표시 | 촬영 중임을 알리는 안내문 부착 |

```python
PRIVACY_ZONES = [(0, 0, 220, 180)]          # (x1, y1, x2, y2)

def apply_privacy_mask(frame):
    """★ 저장·전송 전에 반드시 호출"""
    for x1, y1, x2, y2 in PRIVACY_ZONES:
        frame[y1:y2, x1:x2] = 0
    return frame
```

> ⚠️ **마스킹은 "저장·전송 직전" 에 하세요.**
> 추론 전에 마스킹하면 그 영역의 객체를 못 봅니다. **추론은 원본, 저장은 마스킹본**입니다.

```python
"""pi/camera.py — CSI(picamera2) 와 USB(OpenCV) 를 하나의 인터페이스로

    from camera import open_camera
    with open_camera("auto", 1280, 720, 30) as cam:
        ok, frame = cam.read()        # ★ frame 은 항상 BGR 3채널
"""
from __future__ import annotations

import logging
import threading
import time
from pathlib import Path

import cv2
import numpy as np

logger = logging.getLogger(__name__)

try:                                           # picamera2 는 파이에만 있습니다
    from picamera2 import Picamera2
    from libcamera import controls as libcontrols
    HAS_PICAMERA2, PICAMERA2_ERROR = True, ""
except Exception as _e:
    Picamera2 = libcontrols = None
    HAS_PICAMERA2, PICAMERA2_ERROR = False, str(_e)

# ★ Step 2 실험으로 확정한 매핑 (이름과 실제 순서가 반대)
FORMAT_TO_BGR = {"RGB888": None, "BGR888": cv2.COLOR_RGB2BGR,
                 "XRGB8888": cv2.COLOR_BGRA2BGR, "XBGR8888": cv2.COLOR_RGBA2BGR}


class CameraError(RuntimeError):
    """카메라 열기·읽기 실패"""


class BaseCamera:
    """호출부가 아는 것은 이 인터페이스뿐입니다"""

    kind = "base"

    def __init__(self, width=1280, height=720, fps=30):
        self.req_width, self.req_height = int(width), int(height)
        self.req_fps = float(fps)
        self.width, self.height, self.fps = self.req_width, self.req_height, self.req_fps
        self._started, self._frames, self._t_start = False, 0, 0.0

    def start(self): raise NotImplementedError

    def read(self) -> tuple[bool, np.ndarray | None]:
        """(성공여부, BGR 3채널 배열)"""
        raise NotImplementedError

    def stop(self): raise NotImplementedError

    def close(self): self.stop()

    def controls(self) -> dict: return {}

    def lock_auto(self, settle=2.0) -> dict: return {}

    def info(self) -> dict:
        el = time.perf_counter() - self._t_start if self._t_start else 0
        return {"kind": self.kind,
                "requested": {"width": self.req_width, "height": self.req_height,
                              "fps": self.req_fps},
                "actual": {"width": self.width, "height": self.height,
                           "fps": round(self.fps, 2)},
                "frames_read": self._frames,
                "measured_fps": round(self._frames / el, 2) if el > 0.5 else None}

    def __enter__(self): self.start(); return self

    def __exit__(self, *a): self.close(); return False


class CSICamera(BaseCamera):
    """라즈베리파이 카메라 모듈 (libcamera / picamera2)"""

    kind = "csi"

    def __init__(self, width=1280, height=720, fps=30, camera_num=0,
                 fmt="RGB888", lores=None, hflip=False, vflip=False):
        super().__init__(width, height, fps)
        if not HAS_PICAMERA2:
            raise CameraError(
                f"picamera2 를 사용할 수 없습니다: {PICAMERA2_ERROR}\n"
                "  sudo apt install -y python3-picamera2\n"
                "  python3 -m venv --system-site-packages .venv")
        self.camera_num, self.fmt, self.lores = int(camera_num), fmt, lores
        self.hflip, self.vflip, self._picam = hflip, vflip, None
        self._cvt = FORMAT_TO_BGR.get(fmt.upper())

    def start(self):
        if self._started:
            return self
        self._picam = Picamera2(self.camera_num)
        kw = {"main": {"size": (self.req_width, self.req_height), "format": self.fmt}}
        if self.lores:                              # 추론용 저해상도 동시 스트림
            kw["lores"] = {"size": tuple(self.lores), "format": "YUV420"}
            kw["display"] = None
        dur = int(1_000_000 / self.req_fps)         # FPS 상한을 µs 로
        kw["controls"] = {"FrameDurationLimits": (dur, dur)}
        config = self._picam.create_preview_configuration(**kw)
        if self.hflip or self.vflip:                # 설치 방향에 따른 반전
            from libcamera import Transform
            config["transform"] = Transform(hflip=int(self.hflip), vflip=int(self.vflip))
        self._picam.configure(config)
        self._picam.start()
        cfg = self._picam.camera_configuration()["main"]      # 실제값 되읽기
        self.width, self.height = cfg["size"]
        self._started, self._t_start = True, time.perf_counter()
        logger.info("CSI 카메라 시작 %dx%d fmt=%s (요청 %dx%d)", self.width,
                    self.height, cfg["format"], self.req_width, self.req_height)
        return self

    def read(self):
        if not self._started:
            raise CameraError("start() 를 먼저 호출하세요")
        try:
            frame = self._picam.capture_array("main")
        except Exception as e:
            logger.warning("capture_array 실패: %s", e)
            return False, None
        if frame is None:
            return False, None
        if self._cvt is not None:
            frame = cv2.cvtColor(frame, self._cvt)
        elif frame.ndim == 3 and frame.shape[2] == 4:
            frame = frame[:, :, :3]
        self._frames += 1
        return True, frame

    def read_lores(self):
        """추론용 저해상도 스트림 (lores 설정 시) — CPU 리사이즈 불필요"""
        return True, cv2.cvtColor(self._picam.capture_array("lores"),
                                  cv2.COLOR_YUV420p2BGR)

    def controls(self):
        if not self._started:
            return {}
        try:
            md = self._picam.capture_metadata()
        except Exception:
            return {}
        return {"ExposureTime": md.get("ExposureTime"),
                "AnalogueGain": round(float(md.get("AnalogueGain", 0)), 3),
                "ColourGains": [round(float(v), 3) for v in md.get("ColourGains", (0, 0))],
                "Lux": round(float(md.get("Lux", 0)), 1),
                "FocusFoM": md.get("FocusFoM")}

    def set_controls(self, **kw): self._picam.set_controls(kw)

    def lock_auto(self, settle=2.0):
        """Auto-then-Lock — 자동으로 수렴시킨 뒤 그 값으로 못 박는다"""
        self._picam.set_controls({"AeEnable": True, "AwbEnable": True})
        t0 = time.perf_counter()
        while time.perf_counter() - t0 < settle:
            self._picam.capture_metadata()
        md = self._picam.capture_metadata()
        locked = {"AeEnable": False, "ExposureTime": int(md["ExposureTime"]),
                  "AnalogueGain": float(md["AnalogueGain"]), "AwbEnable": False,
                  "ColourGains": tuple(float(v) for v in md["ColourGains"])}
        self._picam.set_controls(locked)
        logger.info("노출·WB 고정: exp=%dus gain=%.2f wb=(%.2f, %.2f)",
                    locked["ExposureTime"], locked["AnalogueGain"], *locked["ColourGains"])
        return locked

    def lock_focus(self, position=None):
        """오토포커스를 끄고 초점을 고정 (Camera Module 3)"""
        if libcontrols is None:
            return {}
        if position is None:
            self._picam.set_controls({"AfMode": libcontrols.AfModeEnum.Auto})
            try:
                self._picam.autofocus_cycle()
            except Exception as e:
                logger.warning("AF 실패(고정초점 모듈?): %s", e)
                return {}
            position = self._picam.capture_metadata().get("LensPosition", 0.0)
        self._picam.set_controls({"AfMode": libcontrols.AfModeEnum.Manual,
                                  "LensPosition": float(position)})
        logger.info("초점 고정: LensPosition=%.2f (≈%.2fm)", position,
                    (1.0 / position) if position else float("inf"))
        return {"LensPosition": float(position)}

    def stop(self):
        if self._picam is not None:
            try:
                if self._started:
                    self._picam.stop()
            finally:
                self._picam.close()          # 반드시 close — 안 하면 busy
                self._picam = None
        self._started = False


class USBCamera(BaseCamera):
    """USB 웹캠 (V4L2)"""

    kind = "usb"

    def __init__(self, device=0, width=1280, height=720, fps=30,
                 fourcc="MJPG", buffersize=1):
        super().__init__(width, height, fps)
        self.device, self.fourcc, self.buffersize = device, fourcc, buffersize
        self._cap, self.actual_fourcc = None, ""

    @staticmethod
    def _fourcc_str(cap):
        v = int(cap.get(cv2.CAP_PROP_FOURCC))
        return "".join(chr((v >> (8 * i)) & 0xFF) for i in range(4)).strip()

    def start(self):
        if self._started:
            return self
        cap = cv2.VideoCapture(self.device, cv2.CAP_V4L2)       # 백엔드 명시
        if not cap.isOpened():
            raise CameraError(f"카메라를 열 수 없습니다: {self.device}")
        if self.fourcc:                                          # 순서 중요
            cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*self.fourcc))
        cap.set(cv2.CAP_PROP_FRAME_WIDTH, self.req_width)
        cap.set(cv2.CAP_PROP_FRAME_HEIGHT, self.req_height)
        cap.set(cv2.CAP_PROP_FPS, self.req_fps)
        try:
            cap.set(cv2.CAP_PROP_BUFFERSIZE, self.buffersize)    # 지연 감소
        except Exception:
            pass

        ok, frame = cap.read()                     # 실제 프레임으로 검증
        if not ok or frame is None:
            cap.release()
            raise CameraError(f"프레임을 읽을 수 없습니다: {self.device}\n"
                              f"  v4l2-ctl -d {self.device} --list-formats-ext 확인")
        self.height, self.width = frame.shape[:2]
        self.fps = float(cap.get(cv2.CAP_PROP_FPS)) or self.req_fps
        self.actual_fourcc = self._fourcc_str(cap)
        if self.fourcc and self.actual_fourcc != self.fourcc:
            logger.warning("FOURCC 적용 실패: 요청=%s 실제=%s → FPS 하락 가능",
                           self.fourcc, self.actual_fourcc)
        if (self.width, self.height) != (self.req_width, self.req_height):
            logger.warning("해상도 불일치: 요청=%dx%d 실제=%dx%d", self.req_width,
                           self.req_height, self.width, self.height)
        self._cap, self._started, self._t_start = cap, True, time.perf_counter()
        logger.info("USB 카메라 시작 %s %dx%d %s @%.1f", self.device, self.width,
                    self.height, self.actual_fourcc, self.fps)
        return self

    def read(self):
        if not self._started:
            raise CameraError("start() 를 먼저 호출하세요")
        ok, frame = self._cap.read()
        if ok:
            self._frames += 1
        return ok, frame                           # OpenCV 는 이미 BGR

    def info(self):
        d = super().info()
        d["fourcc"] = {"requested": self.fourcc, "actual": self.actual_fourcc}
        d["device"] = str(self.device)
        return d

    def controls(self):
        if not self._started:
            return {}
        return {"AUTO_EXPOSURE": self._cap.get(cv2.CAP_PROP_AUTO_EXPOSURE),
                "EXPOSURE": self._cap.get(cv2.CAP_PROP_EXPOSURE),
                "AUTO_WB": self._cap.get(cv2.CAP_PROP_AUTO_WB)}

    def lock_auto(self, settle=2.0):
        """USB 는 제어 폭이 좁습니다 — 자동 끄기만 시도"""
        time.sleep(settle)
        before = self.controls()
        self._cap.set(cv2.CAP_PROP_AUTO_EXPOSURE, 1)     # 1=Manual (드라이버별)
        self._cap.set(cv2.CAP_PROP_AUTO_WB, 0)
        if before.get("EXPOSURE"):
            self._cap.set(cv2.CAP_PROP_EXPOSURE, before["EXPOSURE"])
        after = self.controls()
        logger.info("USB 자동 제어 끄기: before=%s after=%s", before, after)
        return after

    def stop(self):
        if self._cap is not None:
            self._cap.release()
            self._cap = None
        self._started = False


class ThreadedCamera(BaseCamera):
    """별도 스레드로 계속 읽어 최신 프레임만 보관 (Day 153 LatestFrameCapture)"""

    kind = "threaded"

    def __init__(self, camera: BaseCamera):
        super().__init__(camera.req_width, camera.req_height, camera.req_fps)
        self.cam, self._lock = camera, threading.Lock()
        self._frame, self._thread = None, None
        self._stop_evt = threading.Event()
        self._grabbed = self._dropped = 0

    def start(self):
        self.cam.start()
        self.width, self.height, self.fps = self.cam.width, self.cam.height, self.cam.fps
        self._stop_evt.clear()
        self._thread = threading.Thread(target=self._loop, daemon=True)
        self._thread.start()
        self._started, self._t_start = True, time.perf_counter()
        t0 = time.perf_counter()
        while self._frame is None and time.perf_counter() - t0 < 5:   # 첫 프레임 대기
            time.sleep(0.01)
        return self

    def _loop(self):
        while not self._stop_evt.is_set():
            ok, frame = self.cam.read()
            if not ok:
                time.sleep(0.005)
                continue
            with self._lock:
                if self._frame is not None:
                    self._dropped += 1            # 소비되지 않은 프레임
                self._frame, self._grabbed = frame, self._grabbed + 1

    def read(self):
        with self._lock:
            if self._frame is None:
                return False, None
            frame, self._frame = self._frame, None   # 같은 프레임을 두 번 주지 않음
        self._frames += 1
        return True, frame

    def read_latest(self):
        """소비하지 않고 최신 프레임 복사 (스트리밍용)"""
        with self._lock:
            return (False, None) if self._frame is None else (True, self._frame.copy())

    def info(self):
        d = super().info()
        d.update({"inner": self.cam.info(), "grabbed": self._grabbed,
                  "dropped": self._dropped})
        return d

    def controls(self): return self.cam.controls()

    def lock_auto(self, settle=2.0): return self.cam.lock_auto(settle)

    def stop(self):
        self._stop_evt.set()
        if self._thread is not None:
            self._thread.join(timeout=2)
            self._thread = None
        self.cam.stop()
        self._started = False


def list_usb_devices() -> list[str]:
    """/dev/video* 중 실제로 프레임이 나오는 것만"""
    found = []
    for p in sorted(Path("/dev").glob("video*")):
        cap = cv2.VideoCapture(str(p), cv2.CAP_V4L2)
        try:
            if cap.isOpened() and cap.read()[0]:
                found.append(str(p))
        finally:
            cap.release()
    return found


def has_csi() -> bool:
    if not HAS_PICAMERA2:
        return False
    try:
        return len(Picamera2.global_camera_info()) > 0
    except Exception:
        return False


def open_camera(source="auto", width=1280, height=720, fps=30,
                fourcc="MJPG", threaded=False, **kw) -> BaseCamera:
    """호출부는 이 함수만 알면 됩니다

    source: "auto" | "csi" | "csi:1" | "usb" | "/dev/video30" | 0
    """
    src = source.strip().lower() if isinstance(source, str) else source
    if src == "auto":
        src = "csi" if has_csi() else "usb"
        logger.info("source=auto → %s 선택", src)

    if isinstance(src, str) and src.startswith("csi"):
        num = int(src.split(":")[1]) if ":" in src else 0
        cam = CSICamera(width, height, fps, camera_num=num, **kw)
    elif src == "usb":
        devices = list_usb_devices()
        if not devices:
            raise CameraError("USB 카메라를 찾지 못했습니다 (lsusb · v4l2-ctl 확인)")
        logger.info("USB 후보: %s → %s 사용", devices, devices[0])
        cam = USBCamera(devices[0], width, height, fps, fourcc, **kw)
    else:
        dev = int(src) if (isinstance(src, str) and src.isdigit()) else source
        cam = USBCamera(dev, width, height, fps, fourcc, **kw)
    return ThreadedCamera(cam) if threaded else cam

노트북 브라우저에서 http://<파이IP>:8000/

def draw_overlay(frame, grid):
    """3분할 격자·중앙 십자 — 수평 맞추기와 화각 확인용"""
    if not grid:
        return frame
    out = frame.copy()
    h, w = out.shape[:2]
    for i in (1, 2):
        cv2.line(out, (w*i//3, 0), (w*i//3, h), (0, 220, 255), 1)
        cv2.line(out, (0, h*i//3), (w, h*i//3), (0, 220, 255), 1)
    cv2.line(out, (w//2-20, h//2), (w//2+20, h//2), (0, 0, 255), 2)
    cv2.line(out, (w//2, h//2-20), (w//2, h//2+20), (0, 0, 255), 2)
    return out


def capture_loop():
    """접속 수와 무관하게 JPEG 인코딩은 1회만 한다"""
    cam = STATE["cam"]
    n, t0 = 0, time.perf_counter()
    while not STATE["stop"].is_set():
        ok, frame = cam.read()
        if not ok:
            time.sleep(0.01)
            continue
        shown = draw_overlay(frame, STATE["grid"])
        ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        cv2.putText(shown, ts, (10, 24), cv2.FONT_HERSHEY_SIMPLEX, .6, (0, 0, 0), 3)
        cv2.putText(shown, ts, (10, 24), cv2.FONT_HERSHEY_SIMPLEX, .6, (255, 255, 255), 1)
        ok2, buf = cv2.imencode(".jpg", shown, [cv2.IMWRITE_JPEG_QUALITY, STATE["quality"]])
        if not ok2:
            continue
        with STATE["lock"]:
            STATE["jpeg"], STATE["last_frame"] = buf.tobytes(), frame
            STATE["seq"] += 1
        n += 1
        if n >= 30:
            STATE["fps"], n, t0 = n / (time.perf_counter() - t0), 0, time.perf_counter()


class Handler(BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"

    def log_message(self, fmt, *a): pass          # 요청 로그 끄기

    def do_GET(self):
        if self.path in ("/", "/index.html"):
            self._body(PAGE.encode("utf-8"), "text/html; charset=utf-8")
        elif self.path.startswith("/stream.mjpg"):
            self._stream()
        elif self.path.startswith("/status"):
            cam = STATE["cam"]
            self._json({"kind": cam.kind, "host": socket.gethostname(),
                        "width": cam.width, "height": cam.height,
                        "fps": round(STATE["fps"], 2), "clients": STATE["clients"],
                        "controls": cam.controls()})
        else:
            self.send_error(404)

    def do_POST(self):
        if self.path.startswith("/snapshot"):
            with STATE["lock"]:
                frame = STATE["last_frame"]
            if frame is None:
                return self._json({"ok": False, "error": "no frame"}, 503)
            STATE["shots"].mkdir(parents=True, exist_ok=True)
            p = STATE["shots"] / f"snap_{datetime.now():%Y%m%d_%H%M%S}.jpg"
            cv2.imwrite(str(p), frame, [cv2.IMWRITE_JPEG_QUALITY, 95])
            logger.info("스냅샷 저장: %s", p)
            self._json({"ok": True, "path": str(p)})
        elif self.path.startswith("/grid"):
            STATE["grid"] = not STATE["grid"]
            self._json({"ok": True, "grid": STATE["grid"]})
        elif self.path.startswith("/quality"):
            try:
                STATE["quality"] = max(30, min(95, int(self.path.split("q=")[1])))
            except Exception:
                pass
            self._json({"ok": True, "quality": STATE["quality"]})
        else:
            self.send_error(404)

    def _body(self, data, ctype):
        self.send_response(200)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def _json(self, obj, status=200):
        self.send_response(status)
        data = json.dumps(obj, ensure_ascii=False).encode("utf-8")
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def _stream(self):
        """multipart/x-mixed-replace — MJPEG 스트림"""
        self.send_response(200)
        self.send_header("Cache-Control", "no-cache, private")
        self.send_header("Content-Type", "multipart/x-mixed-replace; boundary=FRAME")
        self.end_headers()
        self.connection.settimeout(3.0)           # 느린 클라이언트 방어
        STATE["clients"] += 1
        last_seq = -1
        try:
            while not STATE["stop"].is_set():
                with STATE["lock"]:
                    data, seq = STATE["jpeg"], STATE["seq"]
                if data is None or seq == last_seq:
                    time.sleep(0.005)             # 새 프레임 대기
                    continue
                last_seq = seq
                self.wfile.write(b"--FRAME\r\n")
                self.send_header("Content-Type", "image/jpeg")
                self.send_header("Content-Length", str(len(data)))
                self.end_headers()
                self.wfile.write(data + b"\r\n")
        except (BrokenPipeError, ConnectionResetError, socket.timeout):
            pass                                  # 탭을 닫았거나 느린 클라
        finally:
            STATE["clients"] -= 1

    try:
        s.connect(("8.8.8.8", 80)); return s.getsockname()[0]

    finally:

    main()

### Step 8. 설치 위치 결정 — 사람 크기를 실측한다

`pi/fov_calc.py` 는 위 두 식만으로 표를 만듭니다. 카메라 프리셋(v2 · Module 3 · Wide · HQ+16mm · 일반 USB)의 수직화각과 캡처 해상도, `--imgsz` 를 받아 **거리별 사람 픽셀 높이**와 **목표 픽셀(기본 64px)을 만족하는 최대 거리**를 계산합니다.

```
scene_h(d) = 2 × d × tan(VFOV / 2)                거리 d 에서 화면이 담는 실제 높이(m)
person_px  = 세로픽셀 × 1.7 / scene_h(d)          캡처 기준 사람 픽셀 높이
모델입력px = person_px × min(imgsz / 가로픽셀, 1)  추론에 실제로 들어가는 크기
```

### Step 9. `capture.py` — 과제 스크립트

`camera.py` 를 그대로 쓰는 **CLI 껍데기**입니다. 새로운 카메라 로직은 없고, 공통 옵션(`--source --width --height --fps --fourcc --lock --focus --warmup --quality`)을 파싱해 `open_camera()` 로 열고 워밍업한 뒤 네 개의 서브커맨드를 실행합니다.

| 서브커맨드 | 하는 일 | `camera.py` 에 없는 부분 |
|---|---|---|
| `probe` | 감지 결과 · `info()` · `controls()` 출력 | 진단용 출력 형식 |
| `still` | 1장 저장 (`--meta` 로 촬영 조건 JSON 동봉) | 메타 JSON 저장 |
| `burst` | `--count` 장을 `--interval` 초 간격으로 저장 | 간격 유지 루프 (Day 172 수집용) |
| `clip` | `--seconds` 초 녹화 | `H264Encoder` / `VideoWriter` 분기 |

> ⚠️ **`clip --encoder picamera2` 만은 `camera.py` 를 거치지 않고 `Picamera2` 를 직접 엽니다.**
> 녹화에는 `create_video_configuration()` 이 필요하기 때문입니다.

for d in result["detections"]:             # ★ 좌표를 원본 기준으로 복원
    d["box"][0] += x1; d["box"][2] += x1
    d["box"][1] += y1; d["box"][3] += y1
```

LOCK_INTERVAL, last = 300, 0            # ★ 5분마다 재고정

def filter_detections(dets, min_px=32, conf_th=0.60):    # ★ 야간 필터
    return [d for d in dets
            if (d["box"][3] - d["box"][1]) >= min_px and d["conf"] >= conf_th]
```

**원인 ④ 광원 자체(헤드라이트·가로등)** — 렌즈 플레어가 밝은 덩어리를 만듭니다.

```python
EXCLUDE_ZONES = [(880, 20, 1080, 160)]       # ★ 가로등 영역을 검출에서 제외

def in_excluded(box):
    cx, cy = (box[0] + box[2]) / 2, (box[1] + box[3]) / 2
    return any(x1 <= cx <= x2 and y1 <= cy <= y2 for x1, y1, x2, y2 in EXCLUDE_ZONES)
```

## 오늘의 정리

| 항목 | 핵심 |
|---|---|
| CSI vs USB | **CPU**(1080p 22%p)와 **케이블 길이**로 결정 |
| USB 의 숨은 비용 | **MJPEG 디코딩** (1080p 9.3 ms/프레임) |
| YUYV | 720p 에서 **10 FPS** — 대역폭 초과 |
| FOURCC | `VideoWriter_fourcc(*"MJPG")` — **9.8 → 29.6 FPS** |
| set 순서 | **FOURCC → 해상도 → FPS** · `get()` 말고 **`frame.shape`** 로 검증 |
| CSI 연결 | **전원 끄고** · 리본 파란 면이 걸쇠 쪽 · 렌즈 필름 제거 |
| 인식 확인 | `rpicam-hello --list-cameras` · `vcgencmd get_camera` 는 무시 |
| CSI 를 OpenCV 로 | **불가** — `picamera2` 필수 |
| 설치 | `apt install python3-picamera2` + `venv --system-site-packages` |
| 색 순서 | `format="RGB888"` → 배열은 **BGR** (이름이 반대) |
| 색 뒤집힘 대가 | **conf -30%** · 검출 누락 |
| configuration | preview / still(12MP·0.7초) / video · **lores 동시 스트림** |
| 요청 ≠ 실제 | **실측 FPS** 를 기록 (워밍업 30프레임) |
| 미리보기 | **MJPEG 서버** — 지연 0.2초 · 브라우저만 있으면 됨 |
| 노출·WB | **Auto-then-Lock** — 밝기 변동 3.3배·색 17배 안정 |

| 야간 | 조명 없음 검출 **0건** / IR 조명 **conf 0.834** |

| 설치 계산 | 사람 px = 세로픽셀 × 1.7 ÷ (2·d·tan(VFOV/2)) |
