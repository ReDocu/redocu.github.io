## ③ 개념 설명

### 이미지의 표현 — (높이, 너비, 채널)

```
흑백 이미지 (28, 28)          또는 (28, 28, 1)
컬러 이미지 (224, 224, 3)     R, G, B 3채널
```

```
컬러 이미지 (2, 3, 3) 예시

     R 채널          G 채널          B 채널
  [[255,   0,  0]  [[  0, 255, 0]  [[  0, 0, 255]
   [128, 128, 128]] [128, 128,128]] [128,128, 128]]

  → 픽셀 (0,0) = (255, 0, 0) = 빨강
  → 픽셀 (1,0) = (128,128,128) = 회색
```

**대단원 02 [Day 045](../02-numpy-pandas/day-045.md)에서 배운 그대로입니다.**

| 표기 | 이름 | 쓰는 곳 |
|---|---|---|
| `(H, W, C)` | **channels_last** | **TensorFlow/Keras 기본** |
| `(C, H, W)` | channels_first | PyTorch |

> **배치를 포함하면 4차원**입니다. `(배치, 높이, 너비, 채널)`
> `(32, 224, 224, 3)` = 224×224 컬러 이미지 32장

### Flatten이 잃는 것

```
원본 3×3 이미지            Flatten 후 (9,)

  [a b c]
  [d e f]      →     [a b c d e f g h i]
  [g h i]

원본에서 a와 d는 위아래로 인접
펼친 후 a는 0번, d는 3번 — 인접하지 않음
```

**Dense 층에게는 이 두 정보가 구별되지 않습니다.**

```python
# Dense 입장에서 이 두 입력은 "그냥 다른 숫자 배열"
[a b c d e f g h i]      # 원본
[a d g b e h c f i]      # 열 우선으로 펼친 것 (전치)
```

**픽셀 순서를 무작위로 섞어도 Dense 모델의 성능은 그대로입니다.**
**정말인지 실습 Step 3에서 확인합니다.**

### 파라미터 폭발 — 숫자로

Dense 층의 파라미터 수 ([Day 083](day-083.md))

```
파라미터 = 입력 노드 × 출력 노드 + 출력 노드
```

| 이미지 | Flatten 크기 | Dense(128) 파라미터 |
|---|---|---|
| 28×28 흑백 (MNIST) | 784 | **100,480** |
| 32×32 컬러 (CIFAR) | 3,072 | **393,344** |
| 64×64 컬러 | 12,288 | 1,572,992 |
| **224×224 컬러** | **150,528** | **19,267,712** |
| 512×512 컬러 | 786,432 | 100,663,424 |

**224×224 이미지에서 첫 층만 1,900만 개**입니다.

**왜 문제인가**

| 이유 | 설명 |
|---|---|
| **메모리** | 1,900만 × 4바이트 = 77MB (첫 층만) |
| **학습 시간** | 파라미터가 많을수록 느림 |
| **과적합** | 데이터 대비 파라미터가 너무 많으면 외움 ([Day 079](day-079.md)) |
| **데이터 요구량** | 경험칙: 파라미터 1개당 샘플 10개 → **1억 9천만 장** 필요 |

### CNN이 해결하는 세 가지

**① 지역성 (Locality) — 가까운 픽셀만 본다**

```
Dense: 픽셀 하나가 다음 층의 모든 노드와 연결
       784 × 128 = 100,352개 연결

CNN:   3×3 영역만 봄
       3 × 3 = 9개 연결 (필터 하나당)
```

**이미지에서 의미 있는 패턴(선, 모서리)은 좁은 영역에 있습니다.**
멀리 떨어진 두 픽셀의 직접적 관계는 거의 없습니다.

**② 가중치 공유 (Weight Sharing) — 같은 필터를 전체에 적용**

```
Dense: 위치마다 다른 가중치
       왼쪽 위의 "세로선 검출기"와 오른쪽 아래의 "세로선 검출기"가 따로 학습됨

CNN:   같은 필터가 이미지 전체를 훑음
       "세로선 검출기" 하나를 학습해 모든 위치에 적용
```

```
필터 하나 = 3×3 = 9개 파라미터 (+ 편향 1)
이 필터가 28×28 이미지 전체를 훑음
→ 위치가 784개여도 파라미터는 여전히 10개
```

**③ 이동 불변성 (Translation Invariance) — 위치가 바뀌어도 인식**

```
Dense: "왼쪽 위에 있는 7"과 "오른쪽 아래에 있는 7"을 따로 배워야 함
CNN:   같은 필터가 어디서든 7의 특징을 찾아냄
```

### 파라미터 수 비교 — 이것이 CNN의 힘

```
입력 28×28×1

[Dense(128)]
  784 × 128 + 128 = 100,480 파라미터

[Conv2D(32, 3×3)]
  (3 × 3 × 1) × 32 + 32 = 320 파라미터
```

**314배 차이입니다.**

| | Dense(128) | Conv2D(32, 3×3) |
|---|---|---|
| 파라미터 | 100,480 | **320** |
| 출력 | (128,) | (26, 26, 32) |
| 공간 정보 | **소실** | **유지** |
| 위치 이동 | 취약 | **강함** |

> **Conv2D의 파라미터 수 공식** ([Day 088](day-088.md)에서 자세히)
> ```
> (커널높이 × 커널너비 × 입력채널) × 필터수 + 필터수
> ```
> **입력 이미지 크기와 무관합니다.** 224×224여도 320개입니다.

### CNN이 항상 나은가?

**아닙니다.** 데이터의 성격에 달렸습니다.

| 데이터 | 적합한 구조 | 이유 |
|---|---|---|
| 이미지 | **CNN** | 공간적 지역성이 있음 |
| 음성·시계열 | RNN, 1D CNN, Transformer | 시간적 순서가 있음 |
| **표 형태 데이터** | **Dense, 트리** | 열 사이에 "인접"이라는 개념이 없음 |
| 텍스트 | Transformer | 순서와 문맥 |

> **표 데이터(나이·연봉·지역)에 CNN을 쓰면 안 됩니다.**
> "나이 열과 연봉 열이 인접하다"는 것은 의미가 없습니다.
> 대단원 04의 스팀 가격 예측이 표 데이터입니다. 거기서는 Dense를 씁니다.

### Step 2. 파라미터 폭발을 숫자로 확인

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def dense_params(input_size, units):
    return input_size * units + units


def conv_params(kernel_h, kernel_w, in_channels, filters):
    return kernel_h * kernel_w * in_channels * filters + filters


이미지들 = [
    ("MNIST 28×28 흑백", 28, 28, 1),
    ("CIFAR 32×32 컬러", 32, 32, 3),
    ("64×64 컬러", 64, 64, 3),
    ("128×128 컬러", 128, 128, 3),
    ("224×224 컬러 (표준)", 224, 224, 3),
    ("512×512 컬러", 512, 512, 3),
    ("Full HD 1920×1080", 1920, 1080, 3),
]

rows = []
for name, h, w, c in 이미지들:
    flat = h * w * c
    d128 = dense_params(flat, 128)
    conv32 = conv_params(3, 3, c, 32)
    rows.append({
        "이미지": name,
        "Flatten_크기": f"{flat:,}",
        "Dense(128)": f"{d128:,}",
        "Dense_메모리": f"{d128 * 4 / 1024 ** 2:.1f} MB",
        "Conv2D(32,3×3)": f"{conv32:,}",
        "비율": f"{d128 / conv32:,.0f}배",
    })

df = pd.DataFrame(rows)

print("=" * 108)
print("파라미터 폭발 — 첫 층만 비교")
print("=" * 108)
print(df.to_string(index=False))
print("=" * 108)

print("\n[핵심 관찰]")
print("  Dense  : 이미지가 커질수록 파라미터가 비례해서 폭증")
print("  Conv2D : 이미지 크기와 무관! 채널 수만 영향")
print()
print("  224×224 컬러에서")
print(f"    Dense(128)     : {dense_params(224*224*3, 128):>12,}개  ({dense_params(224*224*3,128)*4/1024**2:.0f} MB)")
print(f"    Conv2D(32,3×3) : {conv_params(3,3,3,32):>12,}개  "
      f"({conv_params(3,3,3,32)*4/1024:.1f} KB)")

# ── 필요한 데이터 양 추정 ──
print("\n" + "=" * 70)
print("파라미터 대비 필요 데이터량 (경험칙: 파라미터당 샘플 10개)")
print("=" * 70)
print(f"{'모델':<28}{'파라미터':>16}{'필요 샘플 수':>20}")
print("-" * 70)
for name, params in [
    ("MNIST Dense(128)", dense_params(784, 128)),
    ("224×224 Dense(128)", dense_params(224 * 224 * 3, 128)),
    ("224×224 Conv2D(32)", conv_params(3, 3, 3, 32)),
]:
    print(f"{name:<28}{params:>16,}{params * 10:>20,}")
print("-" * 70)
print("ImageNet 전체가 약 1,400만 장입니다.")
print("224×224 Dense 모델의 첫 층만으로 1억 9천만 장이 필요합니다.")
print("=" * 70)

# ── 그래프 ──
sizes = np.array([28, 32, 64, 128, 224, 512])
channels = np.array([1, 3, 3, 3, 3, 3])
dense_p = np.array([dense_params(s * s * c, 128) for s, c in zip(sizes, channels)])
conv_p = np.array([conv_params(3, 3, c, 32) for c in channels])

fig, axes = plt.subplots(1, 2, figsize=(14, 5))
```

### Step 4. 이미지를 이동시키면 어떻게 되는가

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_train, y_train), (X_test, y_test) = keras.datasets.mnist.load_data()
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0


def shift_images(X, dx, dy):
    """이미지를 (dx, dy)만큼 평행이동. 빈 곳은 0으로 채움"""
    shifted = np.zeros_like(X)
    h, w = X.shape[1], X.shape[2]
    for i in range(len(X)):
        src_y0, src_y1 = max(0, -dy), min(h, h - dy)
        src_x0, src_x1 = max(0, -dx), min(w, w - dx)
        dst_y0, dst_y1 = max(0, dy), min(h, h + dy)
        dst_x0, dst_x1 = max(0, dx), min(w, w + dx)
        shifted[i, dst_y0:dst_y1, dst_x0:dst_x1] = X[i, src_y0:src_y1, src_x0:src_x1]
    return shifted


# ── 이동 예시 시각화 ──
fig, axes = plt.subplots(1, 6, figsize=(15, 3))

    ax.imshow(shift_images(X_test[:1], s, 0)[0], cmap="gray_r")
    ax.set_title(f"shift {s}px", fontsize=10)
    ax.axis("off")
fig.suptitle(f"The digit is still '{y_test[0]}' to a human", fontsize=13)
fig.tight_layout()
plt.show()

    return keras.Sequential([
        layers.Input(shape=(28, 28)),
        layers.Flatten(),
        layers.Dense(128, activation="relu"),
        layers.Dense(64, activation="relu"),

        layers.Dense(64, activation="relu"),
        layers.Dense(10, activation="softmax"),

              metrics=["accuracy"])
    Xin = X_train[..., np.newaxis] if ch else X_train
    m.fit(Xin, y_train, epochs=8, batch_size=128, verbose=0)
    models[name] = (m, ch)

# ── 이동량별 평가 ──
shift_range = list(range(0, 9))
results = {"Dense": [], "CNN": []}

print("=" * 74)
print("이미지를 오른쪽으로 n픽셀 이동시켰을 때의 정확도")
print("=" * 74)
print(f"{'이동(px)':>10}{'Dense':>14}{'CNN':>14}{'Dense 하락':>16}{'CNN 하락':>14}")
print("-" * 74)

for s in shift_range:
    Xs = shift_images(X_test, s, 0)
    row = {}
    for name, (m, ch) in models.items():
        Xin = Xs[..., np.newaxis] if ch else Xs
        _, acc = m.evaluate(Xin, y_test, verbose=0)
        results[name].append(acc)
        row[name] = acc

    d_drop = row["Dense"] - results["Dense"][0]
    c_drop = row["CNN"] - results["CNN"][0]
    print(f"{s:>10}{row['Dense']:>14.4f}{row['CNN']:>14.4f}"
          f"{d_drop:>16.4f}{c_drop:>14.4f}")

print(f"  CNN  : {results['CNN'][0]:.4f} → {results['CNN'][4]:.4f}  "
      f"({(results['CNN'][4] - results['CNN'][0]) * 100:+.1f}%p)")
print()
print("사람은 4픽셀 이동한 숫자를 100% 알아봅니다.")
print("Dense는 절반도 못 맞힙니다. '왼쪽 위 픽셀'을 외웠기 때문입니다.")
print("=" * 74)
```

### Step 5. CNN이 무엇을 보는지 미리 보기

```python
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

tf.random.set_seed(42)

(X_train, y_train), (X_test, y_test) = keras.datasets.mnist.load_data()

X_test = (X_test.astype("float32") / 255.0)[..., np.newaxis]

model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),
    layers.Conv2D(8, 3, activation="relu", name="conv1"),
    layers.MaxPooling2D(2),
    layers.Conv2D(16, 3, activation="relu", name="conv2"),
    layers.MaxPooling2D(2),
    layers.Flatten(),
    layers.Dense(10, activation="softmax"),
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.summary()

model.fit(X_train, y_train, epochs=5, batch_size=128, verbose=0)
_, acc = model.evaluate(X_test, y_test, verbose=0)
print(f"\n테스트 정확도: {acc:.4f}  (파라미터 {model.count_params():,}개)")
print("→ Day 085의 Dense 모델(109,386개, 0.9781)보다 파라미터가 훨씬 적습니다.")

W1 = model.get_layer("conv1").get_weights()[0]      # (3, 3, 1, 8)

fig, axes = plt.subplots(1, 8, figsize=(14, 2.2))

    inputs=model.inputs,

sample = X_test[0:1]
```

## ⑤ 자주 하는 실수

### Conv2D에 3차원 입력을 넣음

```python
model = keras.Sequential([
    layers.Input(shape=(28, 28)),          # ✗ 채널 차원 없음
    layers.Conv2D(32, 3),
])
```

```
ValueError: Input 0 of layer "conv2d" is incompatible with the layer:
expected min_ndim=4, found ndim=3
```

**해결** — 채널 차원을 추가하세요.

```python
layers.Input(shape=(28, 28, 1))            # ✓
X_train = X_train[..., np.newaxis]         # (60000,28,28) → (60000,28,28,1)
```

> **Conv2D는 4차원 `(배치, H, W, C)` 을 요구합니다.**
> MNIST는 흑백이라 채널 차원이 없으므로 직접 추가해야 합니다.
> CIFAR-10은 이미 `(50000, 32, 32, 3)` 이라 그대로 씁니다.

### 채널 순서를 헷갈림

```python
X = X.reshape(-1, 1, 28, 28)      # ✗ channels_first (PyTorch 방식)
X = X.reshape(-1, 28, 28, 1)      # ✓ channels_last (Keras 기본)
```

**Keras는 `channels_last` 가 기본**입니다. 인터넷의 PyTorch 코드를 참고할 때 주의하세요.

### Flatten을 CNN 앞에 넣음

```python
model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),
    layers.Flatten(),                       # ✗ 여기서 공간 정보 파괴
    layers.Conv2D(32, 3),                   # 이미 늦음
])
```

**해결** — Flatten은 **Conv/Pool 층을 다 지난 뒤, Dense 앞에** 넣습니다.

```python
Conv2D → MaxPooling → Conv2D → MaxPooling → Flatten → Dense    # ✓
```

### 정규화를 안 함

```python
X_train = X_train                           # 0~255
```

CNN도 정규화가 필요합니다. Dense와 같습니다. ([Day 085](day-085.md))

```python
X_train = X_train.astype("float32") / 255.0
```

> **[Day 093](day-093.md)에서 `Rescaling` 층으로 모델에 내장하는 방법을 배웁니다.**
> 그러면 추론할 때 정규화를 깜빡하는 실수를 막을 수 있습니다.

### 표 데이터에 CNN을 씀

```python
# 나이, 연봉, 지역, 학력 … 열 20개짜리 표 데이터
model = keras.Sequential([
    layers.Reshape((20, 1)),
    layers.Conv1D(32, 3),                   # ✗ 의미 없음
])
```

**원인** — "나이 열과 연봉 열이 인접하다"는 것은 아무 의미가 없습니다.
**해결** — 표 데이터에는 Dense 또는 트리 계열([Day 079](day-079.md)).

> **CNN이 유효한 조건: 인접성이 의미를 갖는 데이터.**
> 이미지(공간), 음성(시간), 텍스트(순서)는 해당됩니다. 표 데이터는 아닙니다.

### 이미지 크기를 줄이지 않고 큰 이미지를 그대로 넣음

```python
layers.Input(shape=(1920, 1080, 3))         # 메모리 폭발
```

**해결** — 표준 크기로 리사이즈합니다. ([Day 091](day-091.md))

|---|---|
| 빠른 실험 | 96×96, 128×128 |
| **일반적** | **224×224** |
| 고해상도 필요 | 384×384, 512×512 |

### CNN이면 무조건 낫다고 생각함

```
CNN 정확도 0.9847  >  Dense 0.9781
```

**MNIST는 CNN이 확실히 낫습니다.** 그런데 항상 그런 것은 아닙니다.

| 상황 | CNN이 나은가 |
|---|---|

**1.** 아래 각 경우의 파라미터 수를 계산하세요.

```
(a) 입력 64×64 흑백 → Flatten → Dense(256)
(b) 입력 64×64 컬러 → Flatten → Dense(256)
(c) 입력 64×64 컬러 → Conv2D(32, 3×3)
(d) 입력 224×224 컬러 → Conv2D(64, 5×5)
(e) (c)의 출력에 Conv2D(64, 3×3) 을 이어 붙였을 때
```

<details>
<summary>답 보기</summary>

**공식**

```
Dense  : 입력 × 출력 + 출력
Conv2D : (커널H × 커널W × 입력채널) × 필터수 + 필터수
```

**(a) 64×64 흑백 → Dense(256)**
```
Flatten 크기 = 64 × 64 × 1 = 4,096
파라미터 = 4,096 × 256 + 256 = 1,048,576 + 256 = 1,048,832
```

**(b) 64×64 컬러 → Dense(256)**
```
Flatten 크기 = 64 × 64 × 3 = 12,288
파라미터 = 12,288 × 256 + 256 = 3,145,728 + 256 = 3,145,984
```

**(c) 64×64 컬러 → Conv2D(32, 3×3)**
```
파라미터 = (3 × 3 × 3) × 32 + 32 = 27 × 32 + 32 = 864 + 32 = 896
```

**(d) 224×224 컬러 → Conv2D(64, 5×5)**
```
파라미터 = (5 × 5 × 3) × 64 + 64 = 75 × 64 + 64 = 4,800 + 64 = 4,864
```

**(e) (c) 출력 → Conv2D(64, 3×3)**
```
(c)의 출력 채널 = 32
파라미터 = (3 × 3 × 32) × 64 + 64 = 288 × 64 + 64 = 18,432 + 64 = 18,496
```

**검산**


**(d) 왜 완전 불변이 아닌가**

```
Conv 층 자체 → 이동 등변(equivariant): 입력이 이동하면 출력도 같이 이동
MaxPooling   → 작은 이동에는 둔감해짐
Flatten+Dense → 다시 위치에 민감해짐
```

**"Conv+Pool 덕분에 어느 정도 강할 뿐"** 입니다. 큰 이동에는 여전히 취약합니다.
**[Day 094](day-094.md)의 데이터 증강**으로 이동된 이미지를 학습에 포함시켜 해결합니다.

**(e) 반례를 만들 수 있는가**

```

  [나이, 연봉, 지역]  ==  [지역, 나이, 연봉]

CNN은 "나이와 연봉이 인접"이라는 (없는) 관계를 학습하려 함
→ 노이즈를 학습. 성능 저하
```

> **예외** — 표 데이터의 열이 **의미 있는 순서**를 가지면 1D CNN이 유효합니다.
> 예: 시간별 센서값(t1, t2, t3, …), 파장별 스펙트럼.
> **"인접성이 의미를 갖는가"가 판단 기준**입니다.

```
파라미터 수 ≠ 연산량
Conv2D는 파라미터가 적지만 연산은 많음
```

```

```

**MaxPooling만 넣었는데 파라미터가 8.5배 줄었습니다.** ([Day 088](day-088.md))

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 이미지 shape | `(H, W, C)` — Keras는 **channels_last** |
| Conv2D 입력 | **4차원** `(배치, H, W, C)`. 흑백은 채널 차원 추가 |
| Flatten | 값은 보존, **공간 구조 소실**. 파라미터 0 |
| Dense 파라미터 | `입력 × 출력 + 출력` — **이미지 크기에 비례** |
| **파라미터 폭발** | 224×224 컬러 → Dense(128) = **1,900만 개** |
| Conv2D 파라미터 | `(kH × kW × C_in) × 필터수 + 필터수` — **이미지 크기 무관** |
| 픽셀 섞기 실험 | Dense는 성능 동일 → **공간 정보를 안 씀** |
| 이동 실험 | 4px 이동 시 Dense 0.53, CNN 0.93 |
| CNN의 3요소 | **지역성 · 가중치 공유 · 이동 불변성** |
| 파라미터 ≠ 연산량 | CNN은 파라미터 적고 **연산은 많음** |
| CNN이 부적합한 곳 | **표 데이터** (인접성이 무의미) |

**오늘 반드시 기억할 세 가지**
> ① **Dense는 이미지를 이미지로 보지 않습니다.** 784개의 독립된 숫자로 볼 뿐입니다.
> ② **Conv2D의 파라미터 공식에 이미지 크기가 없습니다.** 이것이 가중치 공유의 결과입니다.
> ③ **4픽셀 이동에 Dense가 무너집니다.** 실제 사진은 대상 위치가 매번 다릅니다.

**과제** — 파라미터 수 계산 문제 5개

**문제** (전부 손계산 → Keras로 검증 → 과정 서술)

| # | 구조 |
|---|---|
| 1 | `100×100×3` → Flatten → Dense(1024) → Dense(512) → Dense(10) |
| 2 | `100×100×3` → Conv2D(64, 7×7) → Conv2D(128, 3×3) → Conv2D(256, 3×3) |
| 3 | `224×224×3` → Conv2D(64,3) → MaxPool(2) → Conv2D(128,3) → MaxPool(2) → Flatten → Dense(256) → Dense(2) |
| 4 | 위 3번에서 Flatten 대신 `GlobalAveragePooling2D` 를 쓰면? |
| 5 | 늑대 vs 허스키 프로젝트용: `224×224×3` 입력, 2클래스 분류. **파라미터 50만 개 이하**로 구조를 직접 설계 |

**각 문제마다 적을 것**

| 항목 |
|---|
| 층별 출력 shape (직접 계산) |
| 층별 파라미터 수와 계산식 |
| 총 파라미터 수 |
| Keras `summary()` 결과와 대조 |
| **파라미터가 가장 많은 층은 어디이고 왜 그런지** |

**4번과 5번에 대한 추가 서술**
- 4번: Flatten과 GlobalAveragePooling의 파라미터 차이가 왜 나는지, 어느 쪽을 언제 쓸지
- 5번: 설계 근거 — 왜 그 필터 수, 왜 그 층 수인지. 데이터가 600장뿐이라는 점을 고려할 것
