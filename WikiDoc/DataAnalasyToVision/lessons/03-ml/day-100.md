### 0.9667에서 멈출 것인가

[Day 099](day-099.md)에서 400장으로 0.9667을 얻었습니다.

```
테스트 60장 중 2장 오답
```

**"2장 틀렸네" 하고 끝내면 안 됩니다.**

```
그 2장이 왜 틀렸는가?
  - 사람도 헷갈리는 이미지인가
  - 라벨이 잘못됐는가
  - 모델이 엉뚱한 것을 보고 있는가
```

**답에 따라 다음에 할 일이 완전히 달라집니다.**

| 원인 | 다음에 할 일 |
|---|---|
| 사람도 헷갈림 | 개선 여지 없음. 종료 |
| 라벨 오류 | 데이터 정제 |
| **모델이 배경을 봄** | **데이터 재수집 필수** |
| 특정 조건(어두움·측면)에 취약 | 해당 조건 데이터 보강 |

### 정확도가 높아도 쓸 수 없는 모델

### 모델 저장 방식

| 방식 | 저장 내용 | 용량 | 용도 |
|---|---|---|---|
| **`.keras`** | 구조 + 가중치 + 옵티마이저 | 큼 | **기본. 학습 재개 가능** |
| `.weights.h5` | 가중치만 | 1/3 | 구조를 코드로 갖고 있을 때 |
| SavedModel | 구조 + 가중치 + 계산 그래프 | 큼 | TF Serving 배포 |
| **TFLite** | 최적화된 그래프 | **매우 작음** | **모바일·임베디드** |

```python
model.save("model.keras")                          # 전체
model.save_weights("model.weights.h5")             # 가중치만

loaded = keras.models.load_model("model.keras")
model.load_weights("model.weights.h5")             # 구조를 먼저 만들어야 함
```

**TFLite 변환** (대단원 05 예고)

```python
converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]      # INT8 양자화
tflite_model = converter.convert()
Path("model.tflite").write_bytes(tflite_model)
```

### 예측 확률 해석

```python
proba = model.predict(x)      # [[0.87]]  또는 [[0.03, 0.97]]
```

**확률은 "확신도"입니다.**

| 확률 | 해석 |
|---|---|
| 0.99 | 매우 확신 |
| 0.85 | 확신 |
| 0.60 | 약한 확신 |
| **0.50** | **모르겠음** |

**확신도 기반 운영** ([Day 085](day-085.md))

```
확률 ≥ 0.95  →  자동 처리
0.5 ~ 0.95   →  사람 검토
```

> ⚠️ **딥러닝 모델의 확률은 과신하는 경향이 있습니다.**
> 0.99라고 해도 실제 정확도는 0.95일 수 있습니다 (calibration 문제).
> **확률을 절대적으로 믿지 말고 상대적 순위로 쓰세요.**

### ★ 오분류 분석

**틀린 이미지를 직접 봅니다.** 이것이 가장 중요한 디버깅 방법입니다.

**분석 절차**

```
① 틀린 이미지를 전부 나열
② 확신도 순으로 정렬
③ 하나씩 보며 원인을 분류
④ 유형별로 집계
⑤ 가장 많은 유형에 대한 개선안 도출
```

**원인 유형 (체크리스트)**

| 유형 | 설명 | 대응 |
|---|---|---|
| **라벨 오류** | 데이터의 라벨이 틀림 | 데이터 정제 |
| **모호함** | 사람도 판단 불가 | 제외하거나 인정 |
| **드문 자세·각도** | 학습에 없던 형태 | 해당 데이터 보강 |
| **조명·화질** | 어둡거나 흐림 | 증강 강화 또는 데이터 보강 |
| **가려짐** | 대상이 일부만 보임 | 데이터 보강 |
| **배경 혼동** | 배경이 다른 클래스와 유사 | **편향 의심** |
| **작은 대상** | 대상이 화면에서 작음 | 크롭 또는 해상도↑ |

**"확신하며 틀린 것"이 가장 중요합니다.**

```
확률 0.99로 틀림 → 모델이 잘못된 규칙을 확신하고 있음
확률 0.51로 틀림 → 그냥 어려운 샘플
```

### Grad-CAM — 모델이 본 영역

**Gradient-weighted Class Activation Mapping**

```
마지막 Conv 층의 특성맵에
그 클래스에 대한 기울기를 가중치로 곱해 합침
→ "이 예측에 어느 영역이 기여했는가"를 히트맵으로
```

**해석**

```
빨강 = 강하게 기여
파랑 = 거의 기여 안 함
```

**용도**

| 용도 | 설명 |
|---|---|
| **편향 발견** | 배경을 보고 있는가 |
| 오분류 원인 | 엉뚱한 곳을 봤는가 |
| 신뢰도 확보 | 의료·법률 분야에서 설명 요구 |
| 데이터 문제 발견 | 워터마크·로고를 보는가 |

**구현 개요**

```python
grad_model = keras.Model(
    model.inputs,
    [model.get_layer(last_conv_name).output, model.output])

with tf.GradientTape() as tape:
    conv_out, preds = grad_model(img)
    class_channel = preds[:, class_idx]

grads = tape.gradient(class_channel, conv_out)
weights = tf.reduce_mean(grads, axis=(0, 1, 2))
heatmap = tf.reduce_sum(conv_out[0] * weights, axis=-1)
heatmap = tf.maximum(heatmap, 0) / tf.reduce_max(heatmap)
```

> **Grad-CAM은 "왜"를 완전히 설명하지 않습니다.**
> "어디를 봤는가"만 알려 줍니다. 그래도 편향 발견에는 충분히 유용합니다.

### 데이터 편향 발견 사례

**유명한 사례들**

| 사례 | 모델이 실제로 본 것 |
|---|---|
| **늑대 vs 허스키** | **눈밭 배경** |
| 폐렴 X-ray | 병원별 촬영 장비의 워터마크 |
| 피부암 진단 | 의사가 그려 놓은 **자** (크기 측정용) |
| 말 인식 | 사진 하단의 **저작권 워터마크** |
| 탱크 vs 일반 사진 | 촬영 **날씨** (흐림 vs 맑음) |

**공통점** — 모델은 **가장 쉬운 단서**를 학습합니다.

```
"눈밭 판별"이 "늑대 형태 판별"보다 쉬움
→ 데이터에 상관관계가 있으면 쉬운 쪽을 배움
```

## ④ 단계별 실습

### Step 1. 최종 모델 학습과 저장

```python
import json
import time
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.applications.mobilenet_v2 import preprocess_input
from tensorflow.keras.callbacks import (EarlyStopping, ModelCheckpoint,
                                        ReduceLROnPlateau)

AUTOTUNE = tf.data.AUTOTUNE
BASE_DIR = Path("/content/drive/MyDrive/ml_course")
SPLIT = BASE_DIR / "datasets" / "my_dataset" / "split"
MODEL_DIR = BASE_DIR / "models"
OUT = BASE_DIR / "experiments"
for d in [MODEL_DIR, OUT]:
    d.mkdir(parents=True, exist_ok=True)

IMG_SIZE, BATCH, SEED = (224, 224), 32, 42

train_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "train", image_size=IMG_SIZE, batch_size=BATCH,
    shuffle=True, seed=SEED)
val_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "val", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)
test_raw = keras.utils.image_dataset_from_directory(
    SPLIT / "test", image_size=IMG_SIZE, batch_size=BATCH, shuffle=False)

CLASS_NAMES = train_raw.class_names
N = len(CLASS_NAMES)
train_ds = train_raw.cache().prefetch(AUTOTUNE)
val_ds = val_raw.cache().prefetch(AUTOTUNE)
test_ds = test_raw.cache().prefetch(AUTOTUNE)

print(f"클래스: {CLASS_NAMES}")


# ══════════════════════════════════════════
# 지금까지의 기법을 모두 적용한 최종 모델
# ══════════════════════════════════════════
def build_final():
    base = keras.applications.MobileNetV2(
        weights="imagenet", include_top=False, input_shape=(*IMG_SIZE, 3))
    base.trainable = False

    inputs = keras.Input(shape=(*IMG_SIZE, 3), name="image")
    x = layers.RandomFlip("horizontal")(inputs)          # Day 094
    x = layers.RandomRotation(0.1)(x)
    x = layers.RandomZoom(0.1)(x)
    x = preprocess_input(x)                               # Day 098
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D(name="gap")(x)      # Day 088
    x = layers.Dropout(0.3)(x)                            # Day 096
    if N == 2:
        outputs = layers.Dense(1, activation="sigmoid", name="prediction")(x)
        loss = "binary_crossentropy"
    else:
        outputs = layers.Dense(N, activation="softmax", name="prediction")(x)
        loss = "sparse_categorical_crossentropy"
    return keras.Model(inputs, outputs, name="final_model"), base, loss


keras.backend.clear_session()
tf.random.set_seed(SEED)
model, base, loss = build_final()

cbs = lambda tag: [
    ModelCheckpoint(str(MODEL_DIR / f"day100_{tag}.keras"),
                    monitor="val_loss", save_best_only=True, verbose=0),
    EarlyStopping(monitor="val_loss", patience=12,
                  restore_best_weights=True, verbose=1),
    ReduceLROnPlateau(monitor="val_loss", factor=0.5, patience=6,
                      min_lr=1e-8, verbose=0),
]

print("\n" + "=" * 70)
print("[1단계] 특징 추출")
print("=" * 70)
model.compile(optimizer=keras.optimizers.Adam(1e-3), loss=loss,
              metrics=["accuracy"])
h1 = model.fit(train_ds, epochs=50, validation_data=val_ds,
               callbacks=cbs("s1"), verbose=0).history
_, acc1 = model.evaluate(test_ds, verbose=0)
print(f"  test: {acc1:.4f}  ({len(h1['loss'])}에폭)")

print("\n" + "=" * 70)
print("[2단계] 미세조정 (상위 20층, lr 1e-5)")
print("=" * 70)
base.trainable = True
for layer in base.layers[:-20]:
    layer.trainable = False
for layer in base.layers:
    if isinstance(layer, keras.layers.BatchNormalization):
        layer.trainable = False

model.compile(optimizer=keras.optimizers.Adam(1e-5), loss=loss,
              metrics=["accuracy"])
h2 = model.fit(train_ds, epochs=120, initial_epoch=len(h1["loss"]),
               validation_data=val_ds, callbacks=cbs("s2"), verbose=0).history
_, acc_final = model.evaluate(test_ds, verbose=0)
print(f"  test: {acc_final:.4f}  ({acc_final - acc1:+.4f})")


# ══════════════════════════════════════════
# 저장 — 모델 + 메타데이터
# ══════════════════════════════════════════
model_path = MODEL_DIR / "day100_final.keras"
weights_path = MODEL_DIR / "day100_final.weights.h5"
info_path = MODEL_DIR / "day100_final_info.json"

model.save(model_path)
model.save_weights(weights_path)

info = {
    "model_file": model_path.name,
    "class_names": CLASS_NAMES,
    "image_size": list(IMG_SIZE),
    "preprocessing": "mobilenet_v2",
    "output": "sigmoid" if N == 2 else "softmax",
    "threshold": 0.5,
    "test_accuracy": float(acc_final),
    "backbone": "MobileNetV2",
    "n_unfreeze": 20,
    "trained_on": {"train": int(sum(len(y) for _, y in train_raw)),
                   "val": int(sum(len(y) for _, y in val_raw)),
                   "test": int(sum(len(y) for _, y in test_raw))},
}
info_path.write_text(json.dumps(info, indent=2, ensure_ascii=False))

print("\n" + "=" * 70)
print("모델 저장")
print("=" * 70)
print(f"  전체 모델 : {model_path.name}  "
      f"({model_path.stat().st_size / 1024**2:.1f} MB)")
print(f"  가중치만  : {weights_path.name}  "
      f"({weights_path.stat().st_size / 1024**2:.1f} MB)")
print(f"  메타정보  : {info_path.name}")
print()
print(json.dumps(info, indent=2, ensure_ascii=False))

# ── 저장 검증 ──
loaded = keras.models.load_model(model_path)
_, acc_loaded = loaded.evaluate(test_ds, verbose=0)
print(f"\n불러온 모델 정확도: {acc_loaded:.4f}  "
      f"{'일치 ✓' if abs(acc_loaded - acc_final) < 1e-6 else '불일치 ✗'}")

# ── TFLite 변환 (대단원 05 예고) ──
try:
    converter = tf.lite.TFLiteConverter.from_keras_model(model)
    tflite_model = converter.convert()
    tflite_path = MODEL_DIR / "day100_final.tflite"
    tflite_path.write_bytes(tflite_model)

    converter.optimizations = [tf.lite.Optimize.DEFAULT]
    tflite_quant = converter.convert()
    tflite_q_path = MODEL_DIR / "day100_final_quant.tflite"
    tflite_q_path.write_bytes(tflite_quant)

    print(f"\n[TFLite 변환 — 대단원 05 예고]")
    print(f"  Keras     : {model_path.stat().st_size / 1024**2:>6.1f} MB")
    print(f"  TFLite    : {tflite_path.stat().st_size / 1024**2:>6.1f} MB")
    print(f"  TFLite INT8: {tflite_q_path.stat().st_size / 1024**2:>6.1f} MB")
    print("  → 라즈베리파이 배포 시 이 파일을 씁니다")
except Exception as e:
    print(f"\nTFLite 변환 생략: {type(e).__name__}")
```

"""
predict.py — 추론 전용 모듈
대단원 05의 Flask 웹·라즈베리파이 배포에서 그대로 사용

사용:
    from predict import Predictor
    p = Predictor("models/day100_final.keras")
    result = p.predict("new_photo.jpg")
"""
import json
from pathlib import Path

import numpy as np
from PIL import Image, ImageOps
from tensorflow import keras


class Predictor:
    """학습된 모델로 이미지를 분류합니다."""

    def __init__(self, model_path, info_path=None):
        model_path = Path(model_path)
        self.model = keras.models.load_model(model_path)

        # 메타정보 로드
        if info_path is None:
            info_path = model_path.parent / f"{model_path.stem}_info.json"
        if Path(info_path).exists():
            self.info = json.loads(Path(info_path).read_text())
        else:
            raise FileNotFoundError(
                f"메타정보 파일이 없습니다: {info_path}\n"
                "class_names, image_size 정보가 필요합니다")

        self.class_names = self.info["class_names"]
        self.image_size = tuple(self.info["image_size"])
        self.threshold = self.info.get("threshold", 0.5)
        self.is_binary = self.info.get("output") == "sigmoid"

    # ── 전처리 (학습 때와 동일해야 함, Day 091) ──
    def preprocess(self, source):
        """파일 경로 또는 PIL Image → 모델 입력 배열"""
        img = Image.open(source) if isinstance(source, (str, Path)) else source
        img = ImageOps.exif_transpose(img)              # 스마트폰 사진
        img = img.convert("RGB")                         # RGBA 처리
        img = img.resize(self.image_size, Image.BILINEAR)
        return np.array(img, dtype="float32")            # 0~255 그대로
        # ※ 정규화는 모델 안의 preprocess_input이 처리

    # ── 단일 예측 ──
    def predict(self, source, threshold=None):
        t = threshold if threshold is not None else self.threshold
        arr = self.preprocess(source)
        proba = self.model.predict(arr[np.newaxis], verbose=0)[0]

        if self.is_binary:
            p1 = float(proba[0])
            idx = int(p1 > t)
            conf = p1 if idx == 1 else 1 - p1
            probs = {self.class_names[0]: 1 - p1, self.class_names[1]: p1}
        else:
            idx = int(np.argmax(proba))
            conf = float(proba[idx])
            probs = {c: float(p) for c, p in zip(self.class_names, proba)}

        return {
            "class": self.class_names[idx],
            "class_index": idx,
            "confidence": conf,
            "probabilities": probs,
            "certain": conf >= 0.95,
        }

    # ── 배치 예측 ──
    def predict_batch(self, sources, threshold=None):
        arrs = np.stack([self.preprocess(s) for s in sources])
        probas = self.model.predict(arrs, verbose=0)
        results = []
        t = threshold if threshold is not None else self.threshold
        for proba in probas:
            if self.is_binary:
                p1 = float(proba[0])
                idx = int(p1 > t)
                conf = p1 if idx == 1 else 1 - p1
                probs = {self.class_names[0]: 1 - p1, self.class_names[1]: p1}
            else:
                idx = int(np.argmax(proba))
                conf = float(proba[idx])
                probs = {c: float(p) for c, p in zip(self.class_names, proba)}
            results.append({"class": self.class_names[idx],
                            "class_index": idx, "confidence": conf,
                            "probabilities": probs, "certain": conf >= 0.95})
        return results

    def __repr__(self):
        return (f"Predictor(classes={self.class_names}, "
                f"size={self.image_size}, threshold={self.threshold})")

### Step 4. Grad-CAM — 모델이 본 영역

```python
from pathlib import Path

import matplotlib.cm as cm_module
import matplotlib.pyplot as plt
import numpy as np
import tensorflow as tf
from PIL import Image
from tensorflow import keras


def find_last_conv_layer(model):
    """마지막 Conv 층 이름을 찾습니다 (중첩 모델 포함)"""
    for layer in reversed(model.layers):
        if isinstance(layer, keras.Model):          # 백본이 중첩된 경우
            for sub in reversed(layer.layers):
                if len(sub.output.shape) == 4:
                    return layer.name, sub.name
        if len(getattr(layer, "output", tf.constant(0)).shape) == 4:
            return None, layer.name
    raise ValueError("Conv 층을 찾을 수 없습니다")


def make_gradcam_heatmap(img_array, model, class_index=None):
    """
    Grad-CAM 히트맵 생성
    img_array: (1, H, W, 3) 배열 (전처리 전, 0~255)
    """
    outer, inner = find_last_conv_layer(model)

    if outer is not None:
        # 백본이 중첩된 구조 → 백본 내부 층 출력을 꺼냄
        backbone = model.get_layer(outer)
        conv_layer = backbone.get_layer(inner)
        grad_model = keras.Model(
            model.inputs,
            [backbone.get_layer(inner).output, model.output])
    else:
        grad_model = keras.Model(
            model.inputs, [model.get_layer(inner).output, model.output])

    with tf.GradientTape() as tape:
        conv_out, preds = grad_model(img_array, training=False)
        if preds.shape[-1] == 1:
            class_channel = preds[:, 0]
        else:
            idx = class_index if class_index is not None else tf.argmax(preds[0])
            class_channel = preds[:, idx]

    grads = tape.gradient(class_channel, conv_out)
    weights = tf.reduce_mean(grads, axis=(0, 1, 2))
    heatmap = tf.reduce_sum(conv_out[0] * weights, axis=-1)
    heatmap = tf.maximum(heatmap, 0)
    denom = tf.reduce_max(heatmap)
    if denom > 0:
        heatmap = heatmap / denom
    return heatmap.numpy()


def overlay_heatmap(img_pil, heatmap, alpha=0.45):
    """히트맵을 원본 이미지에 겹칩니다"""
    img = np.array(img_pil.convert("RGB").resize(IMG_SIZE))

def full_analysis(predictor, model, split_dir, class_names,

**(e) 자동차 바퀴 — 판단이 갈립니다**

```

  → 둘 다 바퀴가 있음 → 부적절한 단서일 수 있음

"자동차 유무" 분류라면

> **Grad-CAM 판독 체크리스트**

> □ 배경·텍스트·워터마크에 있지 않은가
> □ 클래스를 바꿔 계산하면 다른 곳을 보는가
> □ 여러 이미지에서 일관된 부위를 보는가
> ```

## 오늘의 정리 · W20 총정리

| 개념 | 핵심 |
|---|---|
| 모델 저장 | `.keras` (전체) / `.weights.h5` (가중치) / **TFLite** (배포) |
| **메타정보** | **클래스 이름·크기·전처리·임계값을 JSON으로** |
| 추론 모듈 | 학습 코드와 **분리**. 전처리를 한 함수로 |
| 전처리 일치 | EXIF·RGB·크기·정규화를 학습과 **동일하게** |
| 확률 해석 | 확신도. **과신 경향 주의** |
| 확신도 운영 | 높으면 자동, 낮으면 **사람 검토** |
| **오분류 분석** | **틀린 이미지를 직접 본다.** 가장 중요한 디버깅 |
| 확신하며 틀림 | **잘못된 규칙을 확신** — 가장 위험 |
| 원인 유형 | 라벨오류 / 모호 / 드문자세 / 조명 / 가려짐 / **배경** / 작은대상 |
| **Grad-CAM** | 마지막 Conv 층 + 기울기 → **모델이 본 영역** |
| 전이학습 Grad-CAM | 백본이 **중첩 모델**이라 내부 층 접근 필요 |
| **배경 편향** | 검증 0.98인데 배경 바꾸면 0.28 |
| 편향 지표 | **가장자리 집중도 > 0.45 → 의심** |
| 개선안 순서 | 오분류 분석 → 원인별 대응 → 하이퍼파라미터 |
