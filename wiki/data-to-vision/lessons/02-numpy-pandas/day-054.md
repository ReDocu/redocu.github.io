## ② 왜 필요한가

어제까지의 코드가 갑자기 통하지 않는 순간이 옵니다.

```python
res = requests.get("https://quotes.toscrape.com/js/")
soup = BeautifulSoup(res.text, "html.parser")

print(len(soup.select("div.quote")))     # 0
```

**브라우저에서는 분명히 10개가 보이는데 0개입니다.**

```
브라우저    HTML 받음 → JavaScript 실행 → 데이터 채움 → 화면 표시
requests    HTML 받음 →              (끝)
```

`requests` 는 **HTML 문서만 가져옵니다.** JavaScript 를 실행하지 않습니다.
데이터를 JavaScript 가 나중에 채워 넣는 페이지라면, 받아온 HTML 은 **빈 껍데기**입니다.

오늘은 이 상황을 푸는 두 가지 길을 배웁니다.

| 방법 | 원리 | 속도 | 난이도 |
|---|---|---|---|
| **내부 API 직접 호출** | JavaScript 가 부르는 주소를 내가 부름 | **매우 빠름** | 찾기가 관건 |
| **Selenium** | 진짜 브라우저를 띄워서 조작 | 느림 | 코드는 쉬움 |

> **결론부터 말하면 — 내부 API를 먼저 찾으세요.**
> Selenium 은 최후의 수단입니다. 오늘 실습에서 같은 데이터를 두 방법으로 수집해
> **속도 차이를 직접 확인**하게 됩니다.

## ③ 개념 설명

### 정적 vs 동적 — 판별하는 3가지 방법

**① 페이지 소스 보기** (가장 빠름)

```
브라우저에서 Ctrl + U  → 원본 HTML 이 열림
Ctrl + F 로 화면에 보이던 텍스트를 검색
```

| 결과 | 판정 |
|---|---|
| 검색됨 | **정적** → `requests` 로 충분 |
| 안 됨 | **동적** → 내부 API 또는 Selenium |

> ⚠️ **`F12` 의 Elements 탭이 아니라 `Ctrl+U` 여야 합니다.**
> Elements 탭은 **JavaScript 실행이 끝난 뒤의 결과**를 보여 줍니다.
> 그래서 Elements 에는 있는데 `requests` 로는 안 잡히는 일이 생깁니다.
> **`Ctrl+U` 가 `requests` 가 보는 것과 같습니다.**

**② requests 로 직접 확인**

```python
res = requests.get(url, headers=HEADERS, timeout=10)

if "찾는 텍스트" in res.text:
    print("정적 — requests 로 가능")
else:
    print("동적 — 다른 방법 필요")
```

**③ Network 탭에서 XHR 찾기** (동적일 때 다음 단계)

```
F12 → Network 탭 → Fetch/XHR 필터 → 새로고침(F5)
→ 목록에서 데이터가 들어 있는 요청을 찾음 → Response 탭에서 확인
```

### 도구 선택 순서 — 위에서부터 시도합니다

```
① requests + BeautifulSoup      정적이면 여기서 끝
        ↓ 안 되면
② 내부 API 직접 호출 (XHR)       JSON 이 그대로 옴. 가장 좋음
        ↓ 못 찾으면
③ Selenium                      브라우저를 띄움. 느리지만 확실
```

| | requests | 내부 API | Selenium |
|---|---|---|---|
| 1,000건 수집 시간 | — | **~10초** | ~10분 |
| 메모리 | 수 MB | 수 MB | **수백 MB** |
| 서버 부담 | 낮음 | 낮음 | **높음** |
| 깨질 위험 | 낮음 | 중간 | **높음** (화면 구조 변경) |
| 로그인·클릭 필요 | ❌ | 어려움 | ✅ |

> **Selenium 이 필요한 진짜 상황은 생각보다 적습니다.**
> 로그인 후 화면, 복잡한 클릭 흐름, 내부 API를 도저히 못 찾는 경우 정도입니다.

### Selenium 설치

```powershell
pip install selenium
```

> **Selenium 4.6 부터는 드라이버를 따로 받지 않아도 됩니다.**
> 내장된 **Selenium Manager** 가 설치된 Chrome 버전에 맞는 드라이버를 자동으로 준비합니다.
> (예전 자료에 나오는 `chromedriver.exe` 수동 다운로드나 `webdriver-manager` 패키지는 이제 불필요합니다.)

### 기본 사용법

```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By

options = Options()
options.add_argument("--headless=new")        # 창을 띄우지 않음
options.add_argument("--window-size=1920,1080")
options.add_argument("--disable-gpu")
options.add_argument("--lang=ko_KR")

driver = webdriver.Chrome(options=options)

try:
    driver.get("https://example.com")
    print(driver.title)
finally:
    driver.quit()                              # 반드시 종료
```

**`with` 문으로 쓰면 더 안전합니다.**

```python
with webdriver.Chrome(options=options) as driver:
    driver.get(url)
    ...
# 블록을 벗어나면 자동으로 quit()
```

> ⚠️ **`driver.quit()` 을 빠뜨리면 크롬 프로세스가 계속 살아 있습니다.**
> 반복 실행하면 메모리가 GB 단위로 쌓입니다. `try/finally` 나 `with` 를 꼭 쓰세요.
>
> | 메서드 | 동작 |
> |---|---|
> | `driver.close()` | **현재 탭만** 닫음 |
> | `driver.quit()` | 브라우저 전체 종료 + 드라이버 프로세스 정리 ✅ |

### 요소 찾기 — `By`

```python
from selenium.webdriver.common.by import By

driver.find_element(By.CSS_SELECTOR, "div.quote")      # 하나 (없으면 예외)
driver.find_elements(By.CSS_SELECTOR, "div.quote")     # 리스트 (없으면 [])

driver.find_element(By.ID, "search")
driver.find_element(By.CLASS_NAME, "quote")
driver.find_element(By.TAG_NAME, "h1")
driver.find_element(By.LINK_TEXT, "다음")
driver.find_element(By.XPATH, "//div[@class='quote']")
```

| | `find_element` | `find_elements` |
|---|---|---|
| 없을 때 | **`NoSuchElementException`** | `[]` |
| 존재 확인용 | ❌ | ✅ `if driver.find_elements(...)` |

> **`By.CSS_SELECTOR` 를 기본으로 쓰세요.** BeautifulSoup 의 `select` 와 같은 문법이라
> 어제까지 배운 선택자를 그대로 재사용할 수 있습니다.
>
> ⚠️ **Selenium 3의 `find_element_by_css_selector()` 는 4에서 삭제되었습니다.**
> 옛 자료를 따라 하면 `AttributeError` 가 납니다.

**요소에서 값 꺼내기**

```python
el.text                                   # 화면에 보이는 텍스트 (숨겨진 건 안 나옴)
el.get_attribute("href")                  # 속성
el.get_attribute("textContent")           # 숨겨진 텍스트까지
el.get_attribute("innerHTML")             # 내부 HTML
el.is_displayed()                         # 화면에 보이는가
el.is_enabled()                           # 클릭 가능한가
```

> ⚠️ **`el.text` 는 화면에 보이는 것만 반환합니다.**
> `display:none` 이거나 스크롤 밖에 있으면 빈 문자열이 나옵니다.
> 그럴 땐 `get_attribute("textContent")` 를 쓰세요.

### 대기 — 오늘의 핵심

동적 페이지는 **데이터가 언제 채워질지 모릅니다.** 그래서 기다려야 합니다.

**❌ `time.sleep`**

```python
driver.get(url)
time.sleep(3)                # 3초면 될까? 5초 걸리면? 0.5초면 끝났는데?
```

**❌ 암묵적 대기**

```python
driver.implicitly_wait(10)   # 모든 find_element 에 일괄 적용
```
찾기에는 적용되지만 **"클릭 가능해질 때까지"** 같은 조건은 못 씁니다.
명시적 대기와 섞어 쓰면 대기 시간이 예측 불가능해집니다.

**✅ 명시적 대기**

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 10)

el = wait.until(
    EC.presence_of_element_located((By.CSS_SELECTOR, "div.quote"))
)
```

**조건이 만족되면 즉시 통과, 최대 10초까지만 기다립니다.**

| 조건 | 의미 |
|---|---|
| `presence_of_element_located` | DOM 에 존재 (안 보여도 됨) |
| `visibility_of_element_located` | 화면에 **보임** |
| `element_to_be_clickable` | **클릭 가능** (버튼용) |
| `text_to_be_present_in_element` | 특정 텍스트가 들어옴 |
| `invisibility_of_element_located` | 사라짐 (로딩 스피너용) |
| `presence_of_all_elements_located` | 여러 개 존재 |

```python
# 로딩 스피너가 사라질 때까지
wait.until(EC.invisibility_of_element_located((By.CSS_SELECTOR, ".loading")))

# 결과가 10개 이상 나올 때까지 (사용자 정의 조건)
wait.until(lambda d: len(d.find_elements(By.CSS_SELECTOR, ".item")) >= 10)
```

> **`WebDriverWait` 하나만 제대로 쓰면 Selenium 문제의 80%가 사라집니다.**
> 크롤링이 "가끔 되고 가끔 안 되는" 이유는 거의 다 대기 문제입니다.

### 무한 스크롤 패턴

```python
last_height = driver.execute_script("return document.body.scrollHeight")

for _ in range(MAX_SCROLL):
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(1.0)                       # 로딩 대기

    new_height = driver.execute_script("return document.body.scrollHeight")

    if new_height == last_height:         # 더 안 늘어나면 끝
        break

    last_height = new_height
```

**항목 수로 판정하는 편이 더 정확합니다.**

```python
prev = 0
same_count = 0

while same_count < 2:                     # 2번 연속 안 늘면 종료
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(1.0)

    now = len(driver.find_elements(By.CSS_SELECTOR, "div.quote"))
    same_count = same_count + 1 if now == prev else 0
    prev = now
```

### `page_source` → BeautifulSoup

**Selenium 으로 요소를 하나씩 뽑는 것보다, 완성된 HTML 을 BeautifulSoup 에 넘기는 편이 빠릅니다.**

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(driver.page_source, "html.parser")

for card in soup.select("div.quote"):     # 어제까지 쓰던 코드 그대로
    ...
```

| 방식 | 특징 |
|---|---|
| `driver.find_elements` 반복 | 요소마다 브라우저와 통신 → **느림** |
| `page_source` → BeautifulSoup | 한 번에 문자열로 받아 파싱 → **훨씬 빠름** |

> **Selenium 은 "화면을 완성시키는 데"만 쓰고, 추출은 BeautifulSoup 에 맡기세요.**
> 코드 재사용도 되고 속도도 빠릅니다.

### `StaleElementReferenceException`

```
StaleElementReferenceException: stale element reference:
element is not attached to the page document
```

**원인** — 요소를 찾아 변수에 담아 둔 뒤, 페이지가 다시 그려지면 그 참조는 무효가 됩니다.

```python
items = driver.find_elements(By.CSS_SELECTOR, ".item")

for item in items:
    item.click()                # 클릭 → 페이지 갱신 → 나머지 item 이 전부 무효
```

**해결 — 인덱스로 매번 다시 찾습니다.**

```python
count = len(driver.find_elements(By.CSS_SELECTOR, ".item"))

for i in range(count):
    items = driver.find_elements(By.CSS_SELECTOR, ".item")     # 매번 다시
    items[i].click()
    ...
    driver.back()
```

### 내부 API 찾기 — 가장 좋은 방법

```
F12 → Network → Fetch/XHR → 새로고침 또는 스크롤
→ 요청 목록에서 크기가 크거나 이름에 api/list/search 가 들어간 것을 클릭
→ Response 탭에서 JSON 확인
→ Headers 탭에서 Request URL 복사
```

```python
res = requests.get("https://example.com/api/items",
                   params={"page": 1, "size": 20},
                   headers=HEADERS, timeout=10)

data = res.json()               # 파싱 끝. HTML 파싱 불필요
```

| 장점 | 설명 |
|---|---|
| **압도적으로 빠름** | 브라우저를 안 띄움 |
| **파싱이 필요 없음** | JSON → dict 바로 변환 |
| **깨질 위험이 낮음** | 화면 디자인이 바뀌어도 API는 그대로인 경우가 많음 |
| **데이터가 더 많음** | 화면에 안 보이는 필드까지 들어 있는 경우가 흔함 |

> ⚠️ **내부 API도 수집 윤리는 동일합니다.** ([Day 051](day-051.md))
> 지연을 두고, `robots.txt` 와 이용약관을 확인하고, 인증이 필요한 영역은 건드리지 않습니다.
> "API니까 마음껏 호출해도 된다"가 아닙니다. **오히려 부하가 더 쉽게 걸립니다.**

## ④ 단계별 실습

실습 대상은 `quotes.toscrape.com` 의 **동적 페이지 버전**입니다.

| 경로 | 특징 |
|---|---|
| `/` | 정적 (Day 052에서 사용) |
| `/js/` | JavaScript 가 데이터를 채움 |
| `/scroll` | 무한 스크롤 |
| `/search.aspx` | 선택 상자 + AJAX 검색 |

### Step 1. 정적인가 동적인가

```python
"""같은 데이터를 가진 두 페이지를 requests 로 비교합니다."""

import time

import requests
from bs4 import BeautifulSoup

HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)"
    )
}

TARGETS = {
    "정적 페이지": "https://quotes.toscrape.com/",
    "JS 페이지":  "https://quotes.toscrape.com/js/",
    "스크롤 페이지": "https://quotes.toscrape.com/scroll",
}

print("=" * 72)
print("                  정적 / 동적 판별")
print("=" * 72)

for label, url in TARGETS.items():
    time.sleep(1.0)
    res = requests.get(url, headers=HEADERS, timeout=10)
    soup = BeautifulSoup(res.text, "html.parser")

    quotes = soup.select("div.quote")
    scripts = soup.select("script")

    print(f"\n[{label}]")
    print(f"  URL          : {url}")
    print(f"  HTML 크기    : {len(res.text):,} bytes")
    print(f"  div.quote    : {len(quotes)}개")
    print(f"  script 태그  : {len(scripts)}개")
    print(f"  본문에 'Einstein' 포함: {'Einstein' in res.text}")

    verdict = "정적 ✅ requests 로 수집 가능" if quotes else "동적 ❌ 다른 방법 필요"
    print(f"  판정         : {verdict}")

print("\n" + "=" * 72)
print("  → 브라우저에서는 셋 다 명언이 보입니다.")
print("    하지만 requests 에게는 /js/ 와 /scroll 이 빈 페이지입니다.")
print("=" * 72)
```

```python
"""스크롤해야 더 나오는 페이지를 끝까지 수집합니다."""

import time

import pandas as pd
from bs4 import BeautifulSoup
from selenium.webdriver.common.by import By

URL = "https://quotes.toscrape.com/scroll"
ITEM_SELECTOR = "div.quote"
SCROLL_PAUSE = 1.0
MAX_SCROLL = 30              # 안전장치
PATIENCE = 2                 # 몇 번 연속 안 늘면 종료할지


def scroll_to_end(driver, selector, pause=SCROLL_PAUSE,
                  max_scroll=MAX_SCROLL, patience=PATIENCE):
    """
    항목 수가 더 늘지 않을 때까지 스크롤합니다.

    반환: (최종 항목 수, 스크롤 횟수)
    """
    prev = len(driver.find_elements(By.CSS_SELECTOR, selector))
    same = 0

    print(f"  시작 항목 수: {prev}개")

    for i in range(1, max_scroll + 1):
        driver.execute_script(
            "window.scrollTo(0, document.body.scrollHeight);")
        time.sleep(pause)

        now = len(driver.find_elements(By.CSS_SELECTOR, selector))
        added = now - prev

        if added == 0:
            same += 1
            print(f"  [{i:>2}] {now:>3}개  (변화 없음 {same}/{patience})")
        else:
            same = 0
            print(f"  [{i:>2}] {now:>3}개  (+{added})")

        prev = now

        if same >= patience:               # ← 종료 조건
            print(f"  → {patience}번 연속 변화 없음. 종료합니다")
            return now, i

    print(f"  → 스크롤 상한 {max_scroll}회 도달. 종료합니다")
    return prev, max_scroll


print("=" * 74)

try:

    print(f"\n[스크롤 진행]")
    total, scrolls = scroll_to_end(driver, ITEM_SELECTOR)

    print(f"\n[결과]")
    print(f"  스크롤 {scrolls}회 → 항목 {total}개")
```

```python
"""내부 API 를 직접 호출합니다. Selenium 없이."""

import time

import pandas as pd
import requests

API = "https://quotes.toscrape.com/api/quotes"
HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)"
    )
}
DELAY = 0.5
MAX_PAGES = 20

print("=" * 74)
print("                내부 API 직접 호출 (Selenium 없이)")
print("=" * 74)

t0 = time.perf_counter()

session = requests.Session()
rows = []
page = 1

while page <= MAX_PAGES:
    time.sleep(DELAY)

    res = session.get(API, params={"page": page}, headers=HEADERS, timeout=10)

    if not res.ok:
        print(f"  {page}페이지 HTTP {res.status_code} — 중단")
        break

    data = res.json()
    quotes = data.get("quotes", [])

    if not quotes:
        break

    for q in quotes:
        rows.append({
            "text": q["text"].strip("“”\""),
            "author": q["author"]["name"],
            "author_born": q["author"].get("born_date", ""),
            "goodreads": q["author"].get("goodreads_link", ""),
            "tags": ", ".join(q.get("tags", [])),
        })

    print(f"  page {page:>2} — {len(quotes):>2}건 (누적 {len(rows)}건) "
          f"has_next={data.get('has_next')}")

    if not data.get("has_next"):
        break

    page += 1

session.close()
elapsed = time.perf_counter() - t0

df = pd.DataFrame(rows)

print(f"\n{'=' * 74}")
print(f"[결과] {len(df)}건 · {elapsed:.1f}초")
print("=" * 74)

print(f"\n[Selenium 과 비교]")
print(f"  {'방법':<22}{'건수':>8}{'시간':>10}{'브라우저':>10}")
print("  " + "-" * 52)

print(f"  {'내부 API':<22}{len(df):>8}{f'{elapsed:.1f}초':>10}{'불필요':>10}")

print(f"\n[API 로만 얻을 수 있는 정보]")
print(f"  {df[['author', 'author_born']].drop_duplicates().head(5).to_string(index=False)}")

df.to_csv("data/quotes_api.csv", index=False, encoding="utf-8-sig")
```

```python
import json

    """요소가 없어도 죽지 않게."""
    try:
        return parent.find_element(By.CSS_SELECTOR, selector).text.strip()
    except NoSuchElementException:
        return default

    if cache_path.exists() else {}                        # ⑧ 캐시

    driver.get(URL)
```

```python
"""Selenium 을 쓰기 전에 확인하는 진단 도구."""

import json
import re

import requests
from bs4 import BeautifulSoup

HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                   "AppleWebKit/537.36 (KHTML, like Gecko) "
                   "Chrome/120.0.0.0 Safari/537.36 (educational-purpose)")
}


def diagnose(url, keyword, item_selector=None):
    """
    동적 페이지 대응 방법을 진단합니다.

    keyword       : 화면에서 본 텍스트 (이게 어디 있는지 추적)
    item_selector : 기대하는 항목 선택자
    """
    print("=" * 72)
    print(f"  진단: {url}")
    print("=" * 72)

    res = requests.get(url, headers=HEADERS, timeout=10)
    res.encoding = res.apparent_encoding or "utf-8"
    html = res.text
    soup = BeautifulSoup(html, "html.parser")

    verdict = []

    # ── ① 응답 자체가 정상인가 ──
    print(f"\n[① 응답]")
    print(f"  상태 코드 : {res.status_code}")
    print(f"  Content-Type : {res.headers.get('Content-Type', '?')}")
    print(f"  크기      : {len(html):,} bytes")

    if res.status_code == 403:
        verdict.append("403 — User-Agent 를 바꿔보고, 안 되면 수집 중단")
        print("  ⛔ 403 — 봇 차단. 수집 정책을 먼저 확인하세요")
        return

    if len(html) < 1000:
        verdict.append("응답이 너무 짧음 — 리다이렉트나 차단 페이지 의심")

    # ── ② 선택자가 잡히는가 ──
    if item_selector:
        found = soup.select(item_selector)
        print(f"\n[② 선택자 '{item_selector}']")
        print(f"  발견: {len(found)}개")

        if found:
            print("  ✅ 정적 페이지 — requests 로 충분합니다. Selenium 불필요")
            return

    # ── ③ 키워드가 HTML 어딘가에 있는가 ──
    print(f"\n[③ 키워드 '{keyword}' 위치 추적]")

    if keyword not in html:
        print("  ✗ HTML 에 아예 없음 → 별도 요청으로 받아오는 데이터")
        verdict.append("Network 탭에서 XHR 을 찾으세요 (최우선)")
    else:
        print("  ✓ HTML 안에는 존재함")

        # script 안에 있는가?
        in_script = any(keyword in (s.string or "") for s in soup.select("script"))

        if in_script:
            print("  → <script> 안에 있음!")
            verdict.append("script 태그의 JSON 을 파싱하세요 (Selenium 불필요)")
        else:
            print("  → 본문에 있으나 선택자가 안 맞음")
            verdict.append("선택자를 다시 확인하세요 (Selenium 불필요)")

    # ── ④ script 안의 JSON 후보 찾기 ──
    print(f"\n[④ script 안의 데이터 후보]")
    candidates = []

    for s in soup.select("script"):
        code = s.string or ""

        for pattern in (r"var\s+(\w+)\s*=\s*(\[.*?\]);",
                        r"window\.__\w+__\s*=\s*(\{.*?\});"):
            for m in re.finditer(pattern, code, re.DOTALL):
                raw = m.groups()[-1]
                candidates.append((m.groups()[0] if len(m.groups()) > 1 else "?",
                                   len(raw), raw[:80]))

    if candidates:
        for name, size, preview in candidates[:5]:
            print(f"  · {name:<14}{size:>8,} bytes  {preview}...")
        verdict.append("위 변수를 json.loads 로 파싱하면 Selenium 없이 됩니다")
    else:
        print("  (없음)")

    # ── ⑤ 흔한 API 경로 추측 ──
    print(f"\n[⑤ API 경로 후보 (HTML 에서 발견)]")
    api_paths = sorted(set(re.findall(r'["\'](/(?:api|ajax)/[\w/\-.]+)["\']', html)))

    if api_paths:
        for p in api_paths[:8]:
            print(f"  · {p}")
        verdict.append("위 경로를 requests 로 직접 호출해 보세요")
    else:
        print("  (HTML 에서 못 찾음 — 개발자도구 Network 탭 확인 필요)")

    # ── 결론 ──
    print(f"\n{'=' * 72}")
    print("  권장 순서")
    print("=" * 72)

    for i, v in enumerate(verdict, 1):
        print(f"  {i}. {v}")

    print(f"  {len(verdict) + 1}. 위가 다 안 되면 그때 Selenium")
    print("=" * 72)


if __name__ == "__main__":
    diagnose("https://quotes.toscrape.com/js/", "Einstein", "div.quote")
```

```python
"""Selenium 드라이버 관리 도구."""

import logging
from contextlib import contextmanager
from pathlib import Path

from selenium import webdriver
from selenium.common.exceptions import TimeoutException, WebDriverException
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.support.ui import WebDriverWait

log = logging.getLogger("browser")

SHOT_DIR = Path("data/screenshots")
SHOT_DIR.mkdir(parents=True, exist_ok=True)


class Browser:
    """
    Selenium 드라이버 래퍼.

    with Browser() as b:
        b.open(url)
        b.wait_for(".item")
        soup = b.soup()
    """

    def __init__(self, headless=True, timeout=10, window="1920,1080"):
        self.timeout = timeout
        self._headless = headless
        self._window = window
        self.driver = None
        self.wait = None

    # ══════════ 생명주기 ══════════

    def start(self):
        options = Options()

        if self._headless:
            options.add_argument("--headless=new")

        options.add_argument(f"--window-size={self._window}")
        options.add_argument("--disable-gpu")
        options.add_argument("--no-sandbox")
        options.add_argument("--disable-dev-shm-usage")
        options.add_argument("--lang=ko_KR")
        options.add_argument("--log-level=3")
        options.add_experimental_option("excludeSwitches", ["enable-logging"])

        self.driver = webdriver.Chrome(options=options)
        self.wait = WebDriverWait(self.driver, self.timeout)

        log.info(f"드라이버 시작 (headless={self._headless})")
        return self

    def stop(self):
        if self.driver:
            try:
                self.driver.quit()
                log.info("드라이버 종료")
            except WebDriverException as e:
                log.warning(f"종료 중 오류: {e}")
            finally:
                self.driver = None

    def __enter__(self):
        return self.start()

    def __exit__(self, exc_type, exc, tb):
        if exc_type is not None:                     # 예외 발생 시 증거 남기기
            self.screenshot(f"error_{exc_type.__name__}")
            log.error(f"예외 발생: {exc_type.__name__}: {exc}")

        self.stop()
        return False                                  # 예외를 삼키지 않음

    # ══════════ 동작 ══════════

    def open(self, url, wait_for=None):
        """페이지를 열고, 지정한 요소가 나타날 때까지 기다립니다."""
        self.driver.get(url)

        if wait_for:
            self.wait_for(wait_for)

        return self

    def wait_for(self, selector, condition="presence"):
        """요소를 기다립니다."""
        conditions = {
            "presence": EC.presence_of_element_located,
            "visible": EC.visibility_of_element_located,
            "clickable": EC.element_to_be_clickable,
            "gone": EC.invisibility_of_element_located,
        }
        try:
            return self.wait.until(
                conditions[condition]((By.CSS_SELECTOR, selector)))
        except TimeoutException:
            self.screenshot(f"timeout_{selector.replace('.', '_')[:30]}")
            raise

    def wait_count(self, selector, minimum):
        """요소가 minimum 개 이상 나올 때까지 기다립니다."""
        return self.wait.until(
            lambda d: len(d.find_elements(By.CSS_SELECTOR, selector)) >= minimum)

    def count(self, selector):
        return len(self.driver.find_elements(By.CSS_SELECTOR, selector))

    def exists(self, selector):
        return self.count(selector) > 0

    def click(self, selector, force=False):
        """가려져 있어도 클릭합니다."""
        el = self.wait_for(selector, "clickable" if not force else "presence")

        self.driver.execute_script(
            "arguments[0].scrollIntoView({block:'center'});", el)

        if force:
            self.driver.execute_script("arguments[0].click();", el)
        else:
            el.click()

        return self

    def type(self, selector, text, enter=False):
        from selenium.webdriver.common.keys import Keys

        el = self.wait_for(selector, "visible")
        el.clear()
        el.send_keys(text)

        if enter:
            el.send_keys(Keys.ENTER)

        return self

    def scroll_to_end(self, selector, pause=1.0, max_scroll=30, patience=2):
        """항목이 더 안 늘 때까지 스크롤합니다."""
        import time

        prev, same = self.count(selector), 0

        for i in range(max_scroll):
            self.driver.execute_script(
                "window.scrollTo(0, document.body.scrollHeight);")
            time.sleep(pause)

            now = self.count(selector)
            same = same + 1 if now == prev else 0
            prev = now

            if same >= patience:
                log.info(f"스크롤 {i + 1}회 → {now}개")
                return now

        log.warning(f"스크롤 상한 도달 → {prev}개")
        return prev

    # ══════════ 결과 ══════════

    def soup(self, parser="html.parser"):
        """완성된 HTML 을 BeautifulSoup 으로 반환합니다."""
        from bs4 import BeautifulSoup
        return BeautifulSoup(self.driver.page_source, parser)

    def screenshot(self, name):
        """디버깅용 스크린샷."""
        if not self.driver:
            return None

        path = SHOT_DIR / f"{name}.png"
        try:
            self.driver.save_screenshot(str(path))
            log.info(f"스크린샷: {path}")
            return path
        except WebDriverException:
            return None

    def save_html(self, name):
        """실패 분석용 HTML 저장."""
        path = SHOT_DIR / f"{name}.html"
        path.write_text(self.driver.page_source, encoding="utf-8")
        return path


# ══════════ 사용 ══════════
if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO, format="%(message)s")

    with Browser(headless=True) as b:
        # ── ① JS 페이지 ──
        b.open("https://quotes.toscrape.com/js/", wait_for="div.quote")
        print(f"JS 페이지  : {b.count('div.quote')}개")

        # ── ② 무한 스크롤 ──
        b.open("https://quotes.toscrape.com/scroll", wait_for="div.quote")
        total = b.scroll_to_end("div.quote")
        print(f"스크롤 후  : {total}개")

        # ── ③ 추출 ──
        soup = b.soup()
        quotes = [q.select_one("span.text").get_text(" ", strip=True)
                  for q in soup.select("div.quote")
                  if q.select_one("span.text")]

        print(f"추출       : {len(quotes)}건")
        print(f"첫 명언    : {quotes[0][:60]}...")

        b.screenshot("final")
    # 여기서 자동으로 quit()
```

**설계 포인트 6가지**

| # | 설계 | 이유 |
|---|---|---|
| ① | `__exit__` 에서 **무조건 `stop()`** | 예외가 나도 크롬이 안 남음 |
| ② | **예외 시 스크린샷 자동 저장** | headless 는 화면이 안 보임 — 유일한 단서 |
| ③ | `return False` in `__exit__` | 예외를 삼키지 않음 (삼키면 실패를 못 알아챔) |
| ④ | `wait_for` 가 타임아웃 시 **스크린샷 후 raise** | 왜 못 찾았는지 눈으로 확인 |
| ⑤ | 메서드가 `self` 반환 | `b.open(url).click(".more")` 연결 가능 |
| ⑥ | `soup()` 제공 | 추출은 BeautifulSoup 에 위임 |

> **②번이 실무에서 가장 고맙습니다.**
> headless 로 돌리면 화면이 안 보여서 **"왜 못 찾는지"를 알 수 없습니다.**
> 타임아웃 순간의 스크린샷 한 장이면 대부분 즉시 답이 나옵니다.
> (로그인 화면으로 튕겼거나, 쿠키 배너가 덮고 있거나, 지역 차단 안내가 떠 있거나)
>
> `save_html()` 도 함께 쓰면 **선택자를 다시 짤 때** 브라우저 없이 검토할 수 있습니다.

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 정적/동적 판별 | **`Ctrl+U`** 로 확인 (Elements 탭 ❌) |
| 도구 순서 | requests → **내부 API** → Selenium |
| 설치 | `pip install selenium` (4.6+ 드라이버 자동) |
| 종료 | **`driver.quit()`** · `try/finally` 또는 `with` |
| 요소 찾기 | `find_element(By.CSS_SELECTOR, ...)` · 복수형은 `[]` 반환 |
| **대기** | **`WebDriverWait` + `expected_conditions`** (`time.sleep` ❌) |
| 클릭 실패 | `execute_script("arguments[0].click();", el)` |
| 스크롤 | 항목 수로 판정 + **`patience`** + 상한 |
| 추출 | **`page_source` → BeautifulSoup** |
| Stale 예외 | 인덱스로 **매번 다시 찾기** |
| headless | `--headless=new` + **`--window-size` 필수** |
| 내부 API | F12 → Network → **Fetch/XHR** |

**오늘 반드시 기억할 세 가지**
> ① **Selenium 을 짜기 전에 Network 탭을 5분 보세요.** API 하나로 끝나는 경우가 대부분입니다.
> ② **`time.sleep` 대신 `WebDriverWait`.** "가끔 되는" 크롤러의 원인은 거의 다 대기입니다.
> ③ **`driver.quit()` 을 반드시.** `with` 나 `try/finally` 없이는 크롬이 계속 쌓입니다.

**과제**
① 수집 대상 사이트가 정적인지 동적인지 판별하고 근거 기록
② 동적이라면 **Network 탭에서 XHR을 먼저 찾아보고**, 찾은 과정을 캡처해 정리
③ 동적 페이지 1곳을 실제로 수집 성공시키기 (API 또는 Selenium)
④ 같은 데이터를 두 방법으로 수집해 **소요 시간 비교표** 작성
⑤ `Browser` 클래스를 완성해 재사용 가능하게 정리
