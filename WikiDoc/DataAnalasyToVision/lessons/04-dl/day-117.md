## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 학습 곡선의 **5가지 대표 패턴**을 구분하고, 각각의 원인과 조치를 말할 수 있다.
- 각 패턴을 **일부러 재현**해서 곡선 모양을 직접 만들 수 있다.
- 곡선만 보고 원인을 맞히는 **블라인드 테스트**를 통과할 수 있다.
- 여러 원인이 겹친 복합 패턴을 분해해서 읽을 수 있다.
- **곡선만으로 판단하면 안 되는 경우**를 알고, 무엇을 추가로 확인해야 하는지 안다.
- 진단 → 조치 → 재실험의 순서를 정하고, 한 번에 하나씩 바꿀 수 있다.

**그런데 그 진단 규칙이 어디서 나왔는지는 설명하지 않았습니다.**

```python
if s["최적위치(%)"] > 90:
    notes.append("에폭 부족 가능")
```

**왜 90%입니까? 왜 그것이 "에폭 부족"입니까?**

오늘 그 근거를 **직접 재현해서** 확인합니다.

### 곡선 읽기는 의사의 X-ray 판독과 같습니다

```
증상만 보고 병명을 맞히는 것이 아니라
정상 사진을 수백 장 본 사람이 이상을 알아봅니다
```

**그래서 오늘은 "정상"과 "각 이상"의 사진을 직접 만듭니다.**

| 만들 것 | 방법 |
|---|---|
| ① 과적합 | 큰 모델 + 작은 데이터 |
| ② 과소적합 | 아주 작은 모델 |
| ③ 진동 | 학습률을 크게 |
| ④ 학습 안 됨 | 학습률을 아주 작게 / 스케일링 제거 |
| ⑤ val < train | Dropout을 강하게 |

**한 번 만들어 보면 다음부터는 즉시 알아봅니다.**

### 이 판독이 프로젝트 시간을 좌우합니다

```
[판독 못 하는 경우]
성능이 안 나옴 → 층을 늘려 봄 → 안 됨 → 학습률 바꿔 봄 → 안 됨
→ 특성 추가 → 안 됨 → 데이터를 의심 → ... (3일 소요)

[판독 하는 경우]
성능이 안 나옴 → 곡선을 봄 → "train도 높다 = 과소적합"
→ 모델을 키움 → 해결 (30분)
```

**[Day 130](day-130.md) 프로젝트에서 실험 20회를 해야 합니다.**
**판독을 못 하면 20회를 무작위로 헤매게 됩니다.**

### 그리고 곡선이 답을 안 주는 경우도 압니다

```
곡선은 정상인데 성능이 나쁘다
→ 곡선의 문제가 아니라 데이터·문제 설정의 문제
→ [Day 118](day-118.md)의 잔차 분석으로 넘어가야 함
```

**"곡선으로 알 수 있는 것"과 "알 수 없는 것"의 경계를 아는 것도 오늘의 목표입니다.**

## ③ 개념 설명

### 정상 곡선 — 기준선을 먼저 알아야 합니다

```
 loss
  │╲
  │ ╲___
  │     ╲╲___
  │        ╲╲╲____ train
  │          ╲╲╲╲╲____
  │             ╲╲╲╲╲╲___ val
  └─────────────────────────── epoch
```

| 특징 | 값 |
|---|---|
| 둘 다 내려감 | ✓ |
| 격차가 작고 일정 | 0.01~0.03 |
| 후반에 완만해짐 | ✓ |
| 최적 에폭이 중후반 | 50~90% |
| 진동이 작음 | ✓ |

### ★ 패턴 ① 과적합 (Overfitting)

```
 loss
  │╲
  │ ╲___              ___/‾‾‾  val  ← 올라감
  │     ╲___    ___///
  │         ╲╲╲/
  │          ╲╲╲╲____
  │               ╲╲╲╲╲___ train  ← 계속 내려감
  └─────────────────────────── epoch
              ↑
          최적 지점
```

| 항목 | 값 |
|---|---|
| **train** | 계속 내려감 |
| **val** | 어느 지점부터 **올라감** |
| 격차 | **점점 벌어짐** (> 0.05) |
| 최적 에폭 | 중간 (20~60%) |
| 과적합후퇴 | 크다 (> 0.02) |

**원인**

| 원인 | 확인 방법 |
|---|---|
| 모델이 데이터에 비해 큼 | 파라미터/샘플 비율 ([Day 107](day-107.md)) |
| 데이터가 적음 | 학습 샘플 수 |
| 규제가 없음 | Dropout·L2 여부 |
| 에폭이 너무 많음 | 최적 에폭 위치 |
| **특성이 너무 많음** | 특성 수 / 샘플 수 |

**조치 우선순위**

```
① EarlyStopping(restore_best_weights=True)     ← 즉시. 비용 0
② Dropout 0.2~0.3 추가
③ 모델 축소 (층·노드)
④ L2 규제 (kernel_regularizer)
⑤ 데이터 늘리기                                 ← 가능하면 최선
⑥ 특성 줄이기
```

### ★ 패턴 ② 과소적합 (Underfitting)

```
 loss
  │
  │╲
  │ ╲___
  │     ╲______________________  train
  │      ╲_____________________  val
  │       (둘 다 높은 채 평평)
  └─────────────────────────── epoch
```

| 항목 | 값 |
|---|---|
| **train** | **높은 채 정체** |
| val | train과 비슷하게 높음 |
| **격차** | **매우 작음** (< 0.01) |
| 최적 에폭 | 마지막 근처 |

> ⚠️ **격차가 작아서 "안정적"으로 오해하기 쉽습니다.**
> [Day 079](../03-ml/day-079.md)의 진단 순서를 기억하세요.
> **① train 성능이 낮은가? → 예: 과소적합**
> **격차부터 보면 안 됩니다.**

**"train이 높다"의 기준**

```
베이스라인과 비교하세요.
평균 예측 MAE가 0.91인데 train MAE가 0.75라면 → 과소적합
평균 예측 MAE가 0.91인데 train MAE가 0.28이라면 → 잘 배운 것
```

**원인**

| 원인 | 확인 |
|---|---|
| 모델이 너무 작음 | 파라미터 수 |
| 학습률이 너무 작음 | 곡선이 아직 내려가는 중인가 |
| 에폭이 부족 | 최적 에폭 위치 |
| **규제가 너무 강함** | Dropout 0.5 이상? |
| **특성에 정보가 없음** | 베이스라인 대비 개선폭 |

**조치**

```
① 에폭 늘리기                    ← 곡선이 아직 내려가면
② 모델 키우기 (층·노드)
③ 학습률 올리기
④ 규제 줄이기 (Dropout 0.5 → 0.2)
⑤ 특성 공학                      ← ①~④로 안 되면
```

### ★ 패턴 ③ 심한 진동 (Oscillation)

```
 loss
  │╲  ╱╲    ╱╲
  │ ╲╱  ╲  ╱  ╲  ╱╲
  │      ╲╱    ╲╱  ╲╱╲╱‾╲╱‾  val
  │  ╲___
  │      ╲╲___╲_╱╲__╱╲___  train
  └─────────────────────────── epoch
```

| 항목 | 값 |
|---|---|
| **에폭 간 변동** | **큼** |
| 추세 | 있을 수도, 없을 수도 |
| val이 특히 심함 | ✓ |

**원인**

| 원인 | 특징 |
|---|---|
| **학습률 과다** | **가장 흔함.** train도 진동 |
| 배치 크기가 작음 | 배치마다 기울기가 달라짐 |
| **검증셋이 작음** | val만 진동, train은 부드러움 |
| BatchNorm 없음 | 층이 깊을 때 |
| 데이터에 노이즈 | 진동 폭이 일정 |

**train과 val 중 어느 쪽이 진동하는지가 핵심 단서입니다.**

```
train도 진동  →  학습률 또는 배치 크기 문제
val만 진동    →  검증셋이 작음 (Day 114)
```

**조치**

```
① 학습률 1/3~1/10로
② 배치 크기 2배
③ ReduceLROnPlateau 추가
④ 검증셋 키우기 또는 교차검증 (val만 진동할 때)
⑤ BatchNorm 추가
```

### ★ 패턴 ④ 학습이 아예 안 됨 (Flat)

```
 loss
  │
  │──────────────────────────  train  ← 처음부터 평평
  │──────────────────────────  val
  │
  └─────────────────────────── epoch
```

| 항목 | 값 |
|---|---|
| **손실이 거의 안 줄어듦** | ✓ |
| 첫 에폭부터 평평 | ✓ |
| 또는 `nan` | ✓ |

**원인 (확인 순서대로)**

| 순서 | 원인 | 확인 코드 |
|---|---|---|
| 1 | **스케일링 누락** | `X.max()` 가 수만 이상인가 |
| 2 | **출력층에 활성화** | `Dense(1, activation="sigmoid")` |
| 3 | 학습률이 너무 작음 | `1e-6` 같은 값 |
| 4 | 학습률이 너무 큼 (`nan`) | loss가 폭발하는가 |
| 5 | 타깃에 NaN/inf | `np.isnan(y).sum()` |
| 6 | **라벨이 무작위** | 특성-타깃 상관 확인 |
| 7 | 모델이 너무 작음 | `Dense(1)` 하나뿐? |

> **1번과 2번이 압도적으로 흔합니다.**
> [Day 106](day-106.md) ⑤와 [Day 115](day-115.md) Step 2에서 이미 다뤘습니다.

### ★ 패턴 ⑤ val이 train보다 낮음

```
 loss
  │╲
  │ ╲___
  │     ╲╲___
  │        ╲╲╲____ train
  │      ╲╲╲╲___
  │          ╲╲╲╲╲___ val   ← 아래에 있음
  └─────────────────────────── epoch
```

**대개 정상입니다.** 원인 3가지:

| 원인 | 설명 | 정상? |
|---|---|---|
| **Dropout** | 학습 시 노드를 끄고, 검증 시 전부 켬 | **정상** |
| **측정 시점** | train은 에폭 도중 평균, val은 에폭 끝 | **정상** |
| **검증셋이 쉬움** | 분할이 편향됨 | **문제** |

**구분 방법**

```
격차가 작고(< 0.02) 규제가 있다  →  정상
격차가 크고(> 0.05) 규제가 없다  →  분할 문제. Day 114 확인
```

**분할 문제 확인**

```python
print(f"train 타깃 평균 {y_train.mean():.4f}  표준편차 {y_train.std():.4f}")
print(f"val   타깃 평균 {y_val.mean():.4f}  표준편차 {y_val.std():.4f}")
# 크게 다르면 계층 분할을 하세요 (Day 114)
```

### 패턴 요약표 — 오늘의 핵심

| # | 패턴 | train | val | 격차 | 최적에폭 | 주 원인 | 1순위 조치 |
|---|---|---|---|---|---|---|---|
| ① | **과적합** | ↓ 계속 | **↑ 상승** | **큼↑** | 중간 | 모델 과대 | EarlyStopping |
| ② | **과소적합** | **높은 채 평평** | 비슷 | **작음** | 마지막 | 모델 과소 | 모델 키우기 |
| ③ | **진동** | 들쭉날쭉 | 심함 | 불규칙 | 불규칙 | **학습률 과다** | lr 낮추기 |
| ④ | **평평** | **안 줄어듦** | 동일 | ~0 | 무의미 | **스케일링 누락** | 스케일링 |
| ⑤ | **val < train** | 위 | **아래** | **음수** | 마지막 | Dropout | (정상) |

### 복합 패턴

**실전에서는 여러 개가 겹칩니다.**

| 복합 | 모습 | 조치 순서 |
|---|---|---|
| ③ + ① | 진동하면서 val이 상승 | **lr 먼저** → 그다음 규제 |
| ② + ④ | 조금 내려가다 평평 | 스케일링 확인 → 모델 키우기 |
| ① + ⑤ | Dropout이 있는데도 과적합 | Dropout 강화 |

> **원칙 — 학습률 문제를 먼저 해결하세요.**
> 학습률이 잘못되면 다른 진단이 전부 왜곡됩니다.

### ⚠️ 곡선만으로 판단하면 안 되는 경우

| 상황 | 곡선 | 실제 문제 | 확인해야 할 것 |
|---|---|---|---|
| **데이터 누수** | **완벽하게 정상** | 성능이 부풀려짐 | [Day 109](day-109.md) 점검표 |
| **특정 구간만 실패** | 정상 | 고가 구간에서만 큰 오차 | [Day 118](day-118.md) 잔차 분석 |
| 타깃 자체가 예측 불가 | ② 과소적합처럼 보임 | 특성에 정보가 없음 | 베이스라인 대비 개선폭 |
| **검증셋이 작음** | ③ 진동처럼 보임 | 추정이 불안정 | [Day 114](day-114.md) 변동폭 |
| 분포 변화 | 정상 | 시간에 따라 성능 하락 | 시계열 분할 |
| **잘못된 지표** | 정상 | 지표가 문제와 안 맞음 | [Day 121](day-121.md) |

> **"곡선이 정상인데 성능이 나쁘다"면 곡선의 문제가 아닙니다.**
> **데이터·문제 설정·지표를 의심하세요.**

## ④ 단계별 실습

### Step 0. 공통 준비

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers, regularizers
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

SEED = 42
np.random.seed(SEED)
tf.random.set_seed(SEED)
plt.rcParams["figure.figsize"] = (10, 5)
plt.rcParams["axes.grid"] = True
plt.rcParams["grid.alpha"] = 0.3

raw = fetch_california_housing(as_frame=True)
df = raw.frame.copy()
TARGET = "MedHouseVal"
X_all, y_all = df.drop(columns=[TARGET]), df[TARGET]

y_bins = pd.qcut(y_all, q=10, labels=False, duplicates="drop")
X_dev, X_test, y_dev, y_test, b_dev, _ = train_test_split(
    X_all, y_all, y_bins, test_size=0.2, random_state=SEED, stratify=y_bins)
X_train, X_val, y_train, y_val = train_test_split(
    X_dev, y_dev, test_size=0.25, random_state=SEED, stratify=b_dev)

sc = StandardScaler().fit(X_train)
Xtr, Xva = sc.transform(X_train), sc.transform(X_val)


def make_model(units=(64, 32), dropout=0.0, l2=0.0, lr=1e-3,
               bn=False, n_features=None, seed=SEED):
    tf.random.set_seed(seed)
    n_features = n_features or Xtr.shape[1]
    m = keras.Sequential([layers.Input(shape=(n_features,))])
    for u in units:
        m.add(layers.Dense(u, activation=None,
                           kernel_regularizer=regularizers.l2(l2) if l2 else None))
        if bn:
            m.add(layers.BatchNormalization())
        m.add(layers.Activation("relu"))
        if dropout > 0:
            m.add(layers.Dropout(dropout))
    m.add(layers.Dense(1))
    m.compile(optimizer=keras.optimizers.Adam(lr), loss="mse", metrics=["mae"])
    return m


def curve_stats(h):
    """곡선의 특징을 수치로 — 진단의 근거"""
    tr = np.asarray(h.history["loss"], dtype=float)
    va = np.asarray(h.history["val_loss"], dtype=float)
    n = len(tr)
    best = int(np.argmin(va))

    # 진동: 1차 차분의 표준편차 / 평균 손실
    osc_tr = float(np.abs(np.diff(tr)).mean() / tr.mean())
    osc_va = float(np.abs(np.diff(va)).mean() / va.mean())

    # 개선율: 첫 5에폭 평균 대비 마지막 5에폭 평균
    improve = float((tr[:5].mean() - tr[-5:].mean()) / tr[:5].mean())

    return {
        "에폭": n,
        "최적에폭": best + 1,
        "위치(%)": round((best + 1) / n * 100, 1),
        "train_최종": round(float(tr[-1]), 4),
        "val_최종": round(float(va[-1]), 4),
        "val_최소": round(float(va[best]), 4),
        "격차": round(float(va[-1] - tr[-1]), 4),
        "후퇴": round(float(va[-1] - va[best]), 4),
        "진동_tr": round(osc_tr, 4),
        "진동_va": round(osc_va, 4),
```

### Step 7. 오늘의 종합 — 진단 함수 완성

```python
from pathlib import Path

import numpy as np
import pandas as pd

DIAGNOSE_MODULE = '''
"""학습 곡선 자동 진단 (Day 117)"""
import numpy as np
import pandas as pd


def curve_stats(history, baseline_loss=None):
    """곡선의 특징을 수치로 추출"""
    h = history.history if hasattr(history, "history") else dict(history)
    tr = np.asarray(h["loss"], dtype=float)
    va = np.asarray(h.get("val_loss", h["loss"]), dtype=float)
    n = len(tr)
    finite = np.isfinite(tr) & np.isfinite(va)

    if not finite.any():
        return {"has_nan": True, "에폭": n}

    trf, vaf = tr[finite], va[finite]
    best = int(np.argmin(vaf))

    return {
        "has_nan": not finite.all(),
        "에폭": n,
        "최적에폭": best + 1,
        "위치(%)": round((best + 1) / len(vaf) * 100, 1),
        "train_최종": round(float(trf[-1]), 4),
        "val_최종": round(float(vaf[-1]), 4),
        "val_최소": round(float(vaf[best]), 4),
        "격차": round(float(vaf[-1] - trf[-1]), 4),
        "후퇴": round(float(vaf[-1] - vaf[best]), 4),
        "진동_tr": round(float(np.abs(np.diff(trf)).mean() / trf.mean()), 4),
        "진동_va": round(float(np.abs(np.diff(vaf)).mean() / vaf.mean()), 4),
        "개선율": round(float((trf[:5].mean() - trf[-5:].mean()) / trf[:5].mean()), 4),
        "베이스라인대비": (round(float(trf[-1] / baseline_loss), 3)
                    if baseline_loss else None),
    }


def diagnose_curve(stats, baseline_loss=None, has_regularization=False,
                   val_size=None, train_target_std=None, val_target_std=None):
    """곡선 통계 → 진단 + 조치. Day 117의 5패턴 기준"""
    findings = []

    # ── 패턴 ④: 학습 안 됨 ──
    if stats.get("has_nan"):
        findings.append(("④ 학습 실패 (nan)", "치명",
                         "① 입력 스케일링 확인 ② 학습률 1/10 ③ 타깃 NaN/inf 확인"))
        return findings

    if stats["개선율"] < 0.05:
        findings.append(("④ 학습 거의 안 됨", "치명",
                         "① 학습률 10~100배 ② 출력층 활성화 제거 ③ 라벨 확인"))

    if baseline_loss and stats.get("베이스라인대비", 0) and stats["베이스라인대비"] > 0.95:
        findings.append(("④ 베이스라인 수준", "치명",
                         "평균 예측과 같음. 특성-타깃 관계·라벨을 확인하세요"))

    # ── 패턴 ②: 과소적합 ──
    elif baseline_loss and stats.get("베이스라인대비", 0) and stats["베이스라인대비"] > 0.5:
        findings.append(("② 과소적합", "높음",
                         "① 모델 키우기 ② 학습률 올리기 ③ 규제 줄이기 ④ 특성 공학"))

    # ── 패턴 ③: 진동 ──
    if stats["진동_tr"] > 0.05:
        cause = "학습률 과다" if stats["위치(%)"] < 30 else "배치 크기 작음"
        findings.append((f"③ 진동 ({cause})", "높음",
                         "① 학습률 1/3~1/10 ② 배치 크기 2배 ③ ReduceLROnPlateau"))
    elif stats["진동_va"] / max(stats["진동_tr"], 1e-9) > 5:
        findings.append(("③ val만 진동 (검증셋 작음)", "중간",
                         "① 검증셋 키우기 ② 교차검증 (Day 122)"))

    # ── 패턴 ①: 과적합 ──
    if stats["격차"] > 0.05:
        findings.append(("① 과적합", "높음",
                         "① EarlyStopping ② Dropout 0.2~0.3 ③ 모델 축소 ④ 데이터 늘리기"))
    if stats["후퇴"] > 0.02:
        findings.append(("① 최적 이후 악화", "중간",
                         "EarlyStopping(restore_best_weights=True) 적용"))

    # ── 패턴 ⑤: val < train ──
    if stats["격차"] < -0.02:
        if has_regularization:
            findings.append(("⑤ val < train (정상)", "정보",
                             "Dropout/BN 때문. 조치 불필요"))
        else:
            findings.append(("⑤ val < train (규제 없음)", "높음",
                             "학습셋·검증셋의 타깃 분포를 비교하세요 (Day 114 계층 분할)"))
    if (train_target_std and val_target_std
            and abs(train_target_std - val_target_std) / train_target_std > 0.2):
        findings.append(("⑤ 분할 편향", "높음",
                         f"타깃 표준편차 train {train_target_std:.3f} "
                         f"vs val {val_target_std:.3f}. 계층 분할 적용"))

    # ── 에폭 부족 ──
    if stats["위치(%)"] > 90 and stats["격차"] < 0.03:
        findings.append(("에폭 부족", "중간", "epochs를 2~3배로 늘리기"))

    if not findings:
        findings.append(("정상", "정보", "현 설정 유지. 다른 개선 방향 모색"))
    return findings


def diagnose_report(history, name="model", **kwargs):
    """진단 결과를 사람이 읽는 형태로"""
    s = curve_stats(history, kwargs.get("baseline_loss"))
    fs = diagnose_curve(s, **kwargs)

    print("=" * 78)
    print(f"진단: {name}")
    print("=" * 78)
    for k, v in s.items():
        if v is not None:
            print(f"  {k:<16}{v}")
    print("-" * 78)
    for pattern, level, action in fs:
        mark = {"치명": "🔴", "높음": "🟡", "중간": "🔵", "정보": "⚪"}[level]
        print(f"  {mark} [{pattern}]")
        print(f"      → {action}")
    print("=" * 78)
    return s, fs
'''
```

```
                    └────────┬────────┘
                             ↓
                    nan 이 있는가? ──── 예 ──→ ④ 학습 실패
                             │                 스케일링 / 학습률 / NaN 확인
                            아니오
                             ↓
                  개선율 < 0.05 인가? ── 예 ──→ ④ 학습 안 됨
                             │                 학습률 과소 / 출력층 활성화
                            아니오
                             ↓
              베이스라인대비 > 0.95 인가? ─ 예 ──→ ④ 베이스라인 수준
                             │                    라벨 / 특성 확인
                            아니오
                             ↓
              베이스라인대비 > 0.5 인가? ── 예 ──→ ② 과소적합
                             │                    모델↑ / 학습률↑ / 규제↓
                            아니오
                             ↓
                  진동_tr > 0.05 인가? ── 예 ──→ ③ 진동 (학습률/배치)
                             │                    위치<30 → 학습률
                            아니오                 위치≥30 → 배치
                             ↓
                진동비(va/tr) > 5 인가? ─ 예 ──→ ③ 진동 (검증셋 작음)
                             │                    검증셋↑ / 교차검증
                            아니오
                             ↓
                    격차 > 0.05 인가? ── 예 ──→ ① 과적합
                             │                    EarlyStopping / Dropout / 축소
                            아니오
                             ↓
                    격차 < -0.02 인가? ─ 예 ──→ ⑤ val < train
                             │                    규제 있음 → 정상
                            아니오                 규제 없음 → 분할 확인
                             ↓
                  위치(%) > 90 인가? ─── 예 ──→ 에폭 부족
                             │                    epochs ↑
                            아니오
                             ↓
                        ★ 정상
                   다른 개선 방향 모색
                   (특성 공학 / Day 118 잔차 분석)
```

> **순서가 중요합니다.**
> **④(학습 실패)를 먼저 걸러야 합니다.** 학습이 안 된 상태에서 "과적합" 같은 진단은 무의미합니다.
> **③(진동)을 ①(과적합)보다 먼저** 봐야 합니다. 진동이 심하면 격차 측정 자체가 불안정합니다.

**⑤ 블라인드 테스트 제작 시 주의**

```python
# ✓ 좋은 문제 — 원인이 하나만 뚜렷
("과적합", dict(units=(512, 512), dropout=0.0, lr=1e-3), n_train=600)

# ✗ 나쁜 문제 — 원인이 여러 개 섞임
("???", dict(units=(512, 512), dropout=0.5, lr=5e-2), n_train=300)
   → 과적합 + 규제 + 학습률 과다가 전부 섞여 판별 불가

# ✓ 복합 문제는 별도 섹션으로 (난이도 상)
```

## 오늘의 정리

| 패턴 | 모습 | 결정적 단서 | 1순위 조치 |
|---|---|---|---|
| **① 과적합** | train↓ val↑ | **격차 > 0.05 + 후퇴 큼** | EarlyStopping |
| **② 과소적합** | 둘 다 높은 채 평평 | **베이스라인대비 > 0.5** | 모델 키우기 |
| **③ 진동 (lr)** | 들쭉날쭉 | **진동_tr > 0.05** | 학습률 1/3~1/10 |
| **③ 진동 (검증셋)** | val만 들쭉날쭉 | **진동비 > 5** | 검증셋↑ / 교차검증 |
| **④ 학습 실패** | 평평 or nan | **개선율 < 0.05** | 스케일링 확인 |
| **⑤ val < train** | val이 아래 | **격차 < 0** | 규제 있으면 정상 |

| 원칙 | 내용 |
|---|---|
| 진단 순서 | **④ 학습실패 → ② 과소적합 → ③ 진동 → ① 과적합 → ⑤** |
| [Day 079](../03-ml/day-079.md) 순서 | **① train이 낮은가 → ② 격차가 큰가 → ③ 변동이 큰가** |
| 베이스라인 | **곡선에 수평선을 그으세요.** 없으면 과소적합을 못 봅니다 |
| 진동비 | `진동_va / 진동_tr`. **5 초과면 검증셋 문제** |
| 최근 기울기 | 과소적합의 두 원인 구분 — **아직 내려가나 vs 정체됐나** |
| 복합 패턴 | **학습률 문제를 먼저 해결.** 다른 진단이 왜곡됨 |
| 한 번에 하나 | 여러 개를 동시에 바꾸면 원인을 모름 |
| 곡선의 한계 | **누수·구간별 실패·지표 불일치·정보 부족**은 못 봄 |

**오늘 반드시 기억할 세 가지**
> ① **격차만 보지 마세요.** 베이스라인 대비 train 손실을 먼저 봐야 과소적합을 잡습니다.
> ② **진동은 규제 문제가 아니라 학습률 문제입니다.** Dropout을 넣으면 더 심해집니다.
> ③ **곡선이 정상인데 성능이 나쁘면 곡선의 문제가 아닙니다.** [Day 118](day-118.md)로 넘어가세요.

**과제** — 진단표를 직접 작성하세요.

**필수 포함 항목**

| 항목 | 내용 |
|---|---|
| 1 | **5가지 패턴 전부 재현** — 코드 + 곡선 그림 |
| 2 | 각 패턴의 **수치 특징 표** — 격차/위치/진동_tr/진동_va/개선율/베이스라인대비 + **결정적 단서** |
| 3 | **판별 순서도** — 어떤 순서로 무엇을 확인하는지 (분기 포함) |
| 4 | **자동 진단 함수** — 진단 + **구체적 조치** 반환 |
| 5 | **블라인드 테스트 10문항** 제작 — 곡선만 제시 |
| 6 | **자가 채점 + 오답 분석** — 왜 틀렸는지 |
| 7 | 복합 패턴 사례 2개 이상 — 원인 분해와 조치 순서 |
| 8 | **곡선으로 판단 불가능한 경우 3가지 이상** — 상황 / 곡선 모습 / 실제 문제 / **확인 방법** |
| 9 | 각 패턴의 **조치 후 개선 확인** — 조치 전후 곡선 비교 |
| 10 | 자신의 프로젝트 데이터에 적용한 진단 1건 |

**주의**
- 3번의 순서도가 이 과제의 핵심입니다. **"④ 학습 실패를 먼저 거른다"** 가 들어 있어야 합니다.
