## ② 왜 필요한가

프로그래밍을 배우는 첫 달에 가장 많이 하는 일은 **코드 작성이 아니라 에러 해결**입니다.
그런데 많은 초보자가 에러 메시지가 뜨는 순간 읽지 않고 강사를 부릅니다.

에러 메시지는 **잔소리가 아니라 정확한 안내문**입니다. 거기엔 이미 답의 90%가 들어 있습니다.

```
Traceback (most recent call last):
  File "calc.py", line 5, in <module>
    result = num1 + num2
TypeError: unsupported operand type(s) for +: 'str' and 'int'
```

이 메시지는 이렇게 말하고 있습니다.
> "`calc.py` 파일 **5번째 줄**에서, `str` 과 `int` 를 `+` 로 합치려 했는데 그건 안 됩니다."

오늘 이 읽는 법을 익히면, 남은 175일 동안 스스로 문제를 해결하는 속도가 완전히 달라집니다.

## ③ 개념 설명

### 에러 메시지 구조

파이썬 에러는 **아래에서 위로** 읽습니다. 가장 중요한 정보가 맨 아래에 있습니다.

```
Traceback (most recent call last):        ← ① 에러 추적 시작 알림
  File "calc.py", line 5, in <module>     ← ② 어디서 났나 (파일명, 줄 번호)
    result = num1 + num2                  ← ③ 문제의 코드
TypeError: unsupported operand type(s)... ← ④ 무슨 에러인가 + 이유
```

**읽는 순서: ④ → ② → ③**
"무슨 에러인지" 확인하고 → "몇 번째 줄인지" 보고 → "그 줄을 고친다"

### W01에서 만난 에러 총정리

| 에러 이름 | 뜻 | 대표 원인 | 해결 |
|---|---|---|---|
| `SyntaxError` | 문법 오류 | 콜론 누락, 괄호 안 닫음, 오타 | 표시된 위치의 **바로 앞줄**도 확인 |
| `IndentationError` | 들여쓰기 오류 | 들여쓰기 누락·과다·혼용 | 스페이스 4칸으로 통일 |
| `NameError` | 이름을 모름 | 오타, 정의 전에 사용, 대소문자 | 철자 확인 |
| `TypeError` | 자료형 오류 | 문자열 + 숫자 | `int()` / `str()` 로 변환 |
| `ValueError` | 값이 부적절 | `int("3.5")`, `int("abc")` | `float()` 사용, 입력값 검증 |
| `IndexError` | 인덱스 범위 초과 | `word[6]` (6글자 문자열) | 인덱스는 0부터, 마지막은 `-1` |
| `ZeroDivisionError` | 0으로 나눔 | `10 / 0` | 나누기 전 0인지 확인 |
| `ModuleNotFoundError` | 모듈 없음 | 미설치, 가상환경 미활성화 | `pip install`, `(venv)` 확인 |

> **`SyntaxError` 의 함정** — 파이썬은 문법이 깨진 **다음 줄**을 가리키는 경우가 많습니다.
> 3번 줄에서 에러가 났다고 나오면 **2번 줄**을 먼저 보세요. 괄호나 따옴표를 안 닫은 경우가 대부분입니다.

### print 디버깅

가장 원시적이지만 가장 자주 쓰는 방법입니다. **의심스러운 지점마다 값을 찍어 봅니다.**

```python
score = input("점수: ")
print(f"[디버그] score = {score}, 타입 = {type(score)}")   # ← 확인용

if score >= 60:
    print("합격")
```

실행해 보면 이렇게 나옵니다.

```
점수: 85
[디버그] score = 85, 타입 = <class 'str'>
TypeError: '>=' not supported between instances of 'str' and 'int'
```

`type` 이 `str` 이라는 걸 눈으로 확인하는 순간 원인이 분명해집니다. `int()` 를 빠뜨린 것입니다.

> **요령** — 디버그용 `print` 앞에 `[디버그]` 같은 표시를 붙여 두면 나중에 지울 때 찾기 쉽습니다.

### VS Code 중단점 디버깅

`print` 를 여기저기 넣지 않고도 실행을 멈춰 값을 볼 수 있습니다.

1. 코드 줄 번호 **왼쪽 여백을 클릭**하면 빨간 점(중단점)이 생깁니다.
2. `F5` 를 눌러 디버그 실행합니다. → `Python File` 선택
3. 중단점에서 실행이 멈추고, 왼쪽 **변수(Variables)** 패널에 현재 모든 변수의 값이 보입니다.
4. 상단 버튼으로 한 줄씩 진행합니다.

| 키 | 동작 |
|---|---|
| `F5` | 계속 실행 (다음 중단점까지) |
| `F10` | 한 줄 실행 (Step Over) |
| `F11` | 함수 안으로 들어가기 (Step Into) |
| `Shift+F5` | 디버깅 중지 |

### 에러를 만났을 때의 3단계 절차

```
1. 읽는다     — 맨 아랫줄의 에러 이름과 설명을 읽는다
2. 찾아간다   — line 번호로 이동한다 (없으면 그 앞줄)
3. 확인한다   — 그 줄에 쓰인 변수의 값과 타입을 print 로 찍어 본다
```

이 3단계를 해 보고도 모르겠으면, 그때 질문합니다.
**질문할 때는 "안 돼요" 가 아니라 "이 에러가 났고, 이 줄이고, 값을 찍어 보니 이랬습니다" 라고 말하세요.**

### Step 2. 콘솔 계산기

W01의 내용을 모두 사용해 계산기를 만듭니다.

```python
print("=" * 30)
print("       간단 계산기")
print("=" * 30)

num1 = float(input("첫 번째 숫자: "))
op = input("연산자 (+ - * / // % **): ").strip()
num2 = float(input("두 번째 숫자: "))

print("-" * 30)

if op == "+":
    result = num1 + num2
elif op == "-":
    result = num1 - num2
elif op == "*":
    result = num1 * num2
elif op == "/":
    if num2 == 0:
        result = None
        print("오류: 0으로 나눌 수 없습니다.")
    else:
        result = num1 / num2
elif op == "//":
    result = num1 // num2
elif op == "%":
    result = num1 % num2
elif op == "**":
    result = num1 ** num2
else:
    result = None
    print(f"오류: '{op}' 는 지원하지 않는 연산자입니다.")

# 결과가 정상적으로 계산된 경우에만 출력합니다
if result is not None:
    print(f"{num1} {op} {num2} = {result:.2f}")

print("=" * 30)
```

실행 결과:

```
==============================
       간단 계산기
==============================
첫 번째 숫자: 17
연산자 (+ - * / // % **): /
두 번째 숫자: 5
------------------------------
17.0 / 5.0 = 3.40
==============================
```

```
첫 번째 숫자: 10
연산자 (+ - * / // % **): /
두 번째 숫자: 0
------------------------------
오류: 0으로 나눌 수 없습니다.
==============================
```

> **눈여겨볼 점 3가지**
> - `"=" * 30` — 문자열에 숫자를 곱하면 반복됩니다. 구분선을 만들 때 유용합니다.
> - `result = None` — "아직 결과가 없다"는 뜻의 특별한 값입니다. 마지막에 `is not None` 으로 검사해 오류 상황에서 출력을 건너뜁니다.
> - `is not None` 은 `!= None` 보다 권장되는 표현입니다. `None` 비교는 `is` / `is not` 을 씁니다.

### Step 3. 숫자 맞추기 게임 (조건문 버전)

```python
import random

# 1~100 사이의 정답을 무작위로 정합니다
answer = random.randint(1, 100)

print("=== 숫자 맞추기 ===")
print("1부터 100 사이의 숫자를 맞춰 보세요. (기회 1번)")

guess = int(input("숫자: "))

if guess < 1 or guess > 100:
    print("1~100 사이의 숫자를 입력해 주세요.")
elif guess == answer:
    print(f"정답입니다! {answer} 였습니다. 대단하네요!")
elif guess < answer:
    diff = answer - guess
    if diff <= 5:
        print(f"아깝습니다! 조금 더 큰 수입니다. (정답: {answer})")
    else:
        print(f"더 큰 수입니다. (정답: {answer})")
else:
    diff = guess - answer
    if diff <= 5:
        print(f"아깝습니다! 조금 더 작은 수입니다. (정답: {answer})")
    else:
        print(f"더 작은 수입니다. (정답: {answer})")
```

실행 결과:

```
=== 숫자 맞추기 ===
1부터 100 사이의 숫자를 맞춰 보세요. (기회 1번)
숫자: 42
아깝습니다! 조금 더 큰 수입니다. (정답: 45)
```

> 기회가 한 번뿐이라 게임이라 하기 민망합니다. **여러 번 시도**하게 만들려면 반복문이 필요합니다.
> 내일([Day 006](day-006.md)) `while` 을 배우면 이 게임을 제대로 완성합니다.

### Step 4. 주간 종합 과제 — 회원 등급 판정기

W01의 모든 내용을 사용하는 마무리 과제입니다.

**요구사항**
1. 이름, 나이, 총 구매금액을 입력받는다.
2. 이름은 앞뒤 공백을 제거한다. 비어 있으면 "이름을 입력해 주세요"를 출력하고 종료한다.
3. 구매금액에 따라 등급을 정한다. (10만 미만 `BRONZE` / 10만~50만 `SILVER` / 50만~100만 `GOLD` / 100만 이상 `VIP`)
4. 나이가 65세 이상이거나 19세 미만이면 등급과 무관하게 5% 추가 할인을 준다.
5. 등급별 할인율은 `BRONZE` 0% / `SILVER` 3% / `GOLD` 5% / `VIP` 10%.
6. 최종 할인율과 다음 등급까지 남은 금액을 출력한다.

```python
print("=" * 34)
print("        회원 등급 판정기")
print("=" * 34)

name = input("이름: ").strip()

if not name:
    print("이름을 입력해 주세요.")
else:
    age = int(input("나이: "))
    total = int(input("총 구매금액(원): "))

    # 1) 등급과 기본 할인율 결정
    if total >= 1_000_000:
        grade = "VIP"
        rate = 10
        next_msg = "최고 등급입니다!"
    elif total >= 500_000:
        grade = "GOLD"
        rate = 5
        next_msg = f"VIP까지 {1_000_000 - total:,}원 남았습니다."
    elif total >= 100_000:
        grade = "SILVER"
        rate = 3
        next_msg = f"GOLD까지 {500_000 - total:,}원 남았습니다."
    else:
        grade = "BRONZE"
        rate = 0
        next_msg = f"SILVER까지 {100_000 - total:,}원 남았습니다."

    # 2) 연령 추가 할인
    extra = 5 if (age >= 65 or age < 19) else 0

    total_rate = rate + extra

    print("-" * 34)
    print(f"{name}님 ({age}세)")
    print(f"총 구매금액 : {total:,}원")
    print(f"회원 등급   : {grade}")
    print(f"기본 할인   : {rate}%")
    print(f"연령 할인   : {extra}%")
    print(f"최종 할인율 : {total_rate}%")
    print(f"안내        : {next_msg}")
    print("=" * 34)
```

실행 결과:

```
==================================
        회원 등급 판정기
==================================
이름:  김철수
나이: 68
총 구매금액(원): 620000
----------------------------------
김철수님 (68세)
총 구매금액 : 620,000원
회원 등급   : GOLD
기본 할인   : 5%
연령 할인   : 5%
최종 할인율 : 10%
안내        : VIP까지 380,000원 남았습니다.
==================================
```

> **눈여겨볼 점 3가지**
> - `1_000_000` — 파이썬은 숫자 사이에 밑줄을 넣어 자릿수를 읽기 쉽게 표시할 수 있습니다. 값은 `1000000` 과 같습니다.
> - `if not name:` — 빈 문자열은 거짓으로 취급되므로, `not name` 은 "이름이 비어 있으면" 이라는 뜻이 됩니다.
> - `extra = 5 if (...) else 0` — 삼항 표현식으로 두 줄을 한 줄에 담았습니다.

## ⑤ 자주 하는 실수

### 에러 줄 번호를 그대로 믿고 그 줄만 봅니다

```python
print("첫 번째 숫자를 입력하세요"     # 괄호를 안 닫음
print("두 번째 줄")
```

```
  File "test.py", line 2
    print("두 번째 줄")
    ^^^^^
SyntaxError: '(' was never closed
```

**원인** — 에러는 2번 줄을 가리키지만 실제 문제는 **1번 줄**입니다.
**해결** — `SyntaxError` 가 나면 표시된 줄의 **바로 앞줄**부터 확인하세요. 괄호·따옴표·콜론이 주범입니다.

### `Traceback` 을 안 읽고 코드만 노려봅니다

에러가 났을 때 코드를 아무리 오래 봐도 안 보이는 경우가 많습니다.
**먼저 에러 메시지의 마지막 줄을 소리 내어 읽으세요.** 대부분 거기에 답이 있습니다.

### `result = None` 인데 계산 결과처럼 출력함

```python
if op == "+":
    result = num1 + num2
# else 를 쓰지 않아 result 가 만들어지지 않음
print(result)
```

```
NameError: name 'result' is not defined
```

**원인** — 모든 갈래에서 변수가 만들어지지 않으면, 조건을 타지 않았을 때 그 변수는 존재하지 않습니다.
**해결** — 조건문 **앞에서** 기본값을 미리 정해 둡니다.

```python
result = None      # 미리 기본값 설정
if op == "+":
    result = num1 + num2
```

### 디버그용 print 를 지우지 않고 제출함

과제를 낼 때 `[디버그]` 출력이 그대로 남아 있으면 결과가 지저분해집니다.
제출 전에 `Ctrl+F` 로 `[디버그]` 를 검색해 모두 지우세요.

```python
price = int(input("가격: "))

```

**2.** 아래 코드가 왜 항상 `"불합격"` 을 출력하는지 설명하고 고치세요.

```python
score = input("점수: ")

if score >= "60":
    print("합격")
else:
    print("불합격")
```

<details>
<summary>답 보기</summary>

**문제** — 문자열끼리 비교하고 있습니다. 문자열 비교는 **사전 순서**로 이루어집니다.

```python
print("85" >= "60")    # True   (8 > 6)
print("100" >= "60")   # False! ("1" < "6" 이므로)
```

`"100"` 처럼 세 자리 숫자를 입력하면 첫 글자 `"1"` 과 `"6"` 을 비교해 거짓이 됩니다.
에러가 나지 않아 더 위험합니다.

**해결** — 숫자로 바꿔 비교합니다.

```python
score = int(input("점수: "))

if score >= 60:
    print("합격")
else:
    print("불합격")
```

> **교훈** — 에러가 안 난다고 맞는 코드가 아닙니다. 이런 것을 **논리 오류(logic error)** 라고 하며, 문법 오류보다 찾기 어렵습니다. 여러 값으로 테스트하는 습관이 유일한 방어책입니다.
</details>

**3.** 다음 요구사항을 만족하는 프로그램을 작성하세요.
"삼각형 세 변의 길이를 입력받아, ① 삼각형이 될 수 있는지 판별하고 ② 가능하다면 정삼각형·이등변삼각형·일반삼각형 중 무엇인지 출력한다."
(삼각형 조건: 가장 긴 변이 나머지 두 변의 합보다 짧아야 함)

<details>
<summary>답 보기</summary>

```python
a = float(input("첫 번째 변: "))
b = float(input("두 번째 변: "))
c = float(input("세 번째 변: "))

if a <= 0 or b <= 0 or c <= 0:
    print("변의 길이는 0보다 커야 합니다.")
elif a + b <= c or b + c <= a or a + c <= b:
    print("삼각형을 만들 수 없습니다.")
elif a == b and b == c:
    print("정삼각형입니다.")
elif a == b or b == c or a == c:
    print("이등변삼각형입니다.")
else:
    print("일반삼각형입니다.")
```

실행 결과:

```
첫 번째 변: 5
두 번째 변: 5
세 번째 변: 8
이등변삼각형입니다.
```

**포인트 3가지**
- **어느 변이 가장 긴지 모르므로** 세 조합을 모두 확인합니다. (`a+b<=c`, `b+c<=a`, `a+c<=b`)
- 정삼각형은 이등변삼각형이기도 하므로 **정삼각형을 먼저** 검사해야 합니다. 순서를 바꾸면 정삼각형이 이등변으로 판정됩니다.
- 잘못된 입력(0 이하)을 맨 위에서 먼저 거릅니다.
</details>
