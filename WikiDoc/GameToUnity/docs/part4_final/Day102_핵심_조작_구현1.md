## 3. 개념

### 3-1. 감각을 결정하는 4가지

**왜 필요한가** — 무엇을 조절할지 안다.

```
   ★ 이동 감각의 4요소

   ① 최고 속도       얼마나 빠른가
   ② 가속 시간       0 → 최고속까지 얼마나
   ③ 감속 시간       최고속 → 0까지 얼마나
   ④ 회전 속도       방향 전환이 얼마나 빠른가
```

```
   ★ 이 넷의 조합이 "느낌"을 만든다
```

| 조합 | 느낌 | 예 |
|---|---|---|
| 빠른 가속 + 빠른 감속 | **반응적, 정확** | 플랫포머, 탄막 |
| 느린 가속 + 느린 감속 | 묵직, 관성 | 레이싱, 대형 로봇 |
| 빠른 가속 + 느린 감속 | 미끄러짐 | 빙판, 우주선 |
| 느린 가속 + 빠른 감속 | 답답 | (대부분 나쁘다) |

```
   ⚠️ 마지막 조합은 거의 항상 나쁘다

   "가속은 느린데 놓으면 딱 멈춘다"
   → 반응은 늦고 관성은 없다
```

### 3-2. 가속과 감속을 분리한다

**왜 필요한가** — 하나로 묶으면 튜닝이 안 된다.

```csharp
    // ✗ 하나로
    currentVelocity = Vector3.Lerp(currentVelocity, targetVelocity, smoothing);

    // ✔ 분리
    float rate = (targetSpeed > currentSpeed) ? acceleration : deceleration;

    currentSpeed = Mathf.MoveTowards(currentSpeed, targetSpeed, rate * dt);
```

```
   ★ 왜 분리하나

   "가속은 빠르되 감속은 살짝 미끄러지게"
   → 대부분의 액션 게임이 이렇다
```

```
   ★ MoveTowards vs Lerp

   MoveTowards:  일정한 속도. 정확히 도달  ★ 튜닝이 예측 가능
   Lerp:         남은 거리에 비례. 영원히 근사
```

```csharp
    // ★ 시간으로 지정하면 직관적이다
    [SerializeField] private float accelTime = 0.12f;   // 0 → 최고속
    [SerializeField] private float decelTime = 0.08f;   // 최고속 → 0

    private float Acceleration => maxSpeed / Mathf.Max(accelTime, 0.001f);
    private float Deceleration => maxSpeed / Mathf.Max(decelTime, 0.001f);
```

```
   ★ "0.12초 만에 최고속"

   → 숫자가 의미를 갖는다
   → 팀원과 대화가 된다
```

### 3-3. 입력 처리

**왜 필요한가** — 입력이 감각의 시작.

```csharp
    private Vector2 rawInput;
    private Vector3 moveDir;

    private void ReadInput()
    {
        rawInput.x = Input.GetAxisRaw("Horizontal");
        rawInput.y = Input.GetAxisRaw("Vertical");

        // ★ 데드존
        if (rawInput.sqrMagnitude < deadZone * deadZone)
            rawInput = Vector2.zero;

        // ★ 크기를 1로 제한 (대각선이 빠르지 않게)
        if (rawInput.sqrMagnitude > 1f)
            rawInput.Normalize();
    }
```

```
   ★ GetAxis vs GetAxisRaw

   GetAxis:     키를 떼도 서서히 0으로 (Unity가 보간)
   GetAxisRaw:  즉시 0/±1               ★ 권장

   → 보간은 우리가 직접 한다 (튜닝 가능)
```

```
   ⚠️ GetAxis를 쓰면

   Unity의 보간 + 우리 보간
   → 이중 보간으로 반응이 둔해진다
```

```
   ★ 대각선 문제

   W+D 동시 입력 → (1, 1) → 길이 1.414
   → 대각선이 41% 빠르다

   ★ Normalize로 해결
```

### 3-5. 회전

**왜 필요한가** — 방향 전환의 느낌.

```csharp
    private void UpdateRotation(float dt)
    {
        if (moveDir.sqrMagnitude < 0.01f) return;

        Quaternion target = Quaternion.LookRotation(moveDir);

        transform.rotation = Quaternion.RotateTowards(
            transform.rotation, target, rotationSpeed * dt);
    }
```

```
   ★ RotateTowards vs Slerp

   RotateTowards:  초당 N도. 예측 가능  ★
   Slerp:          비율. 처음엔 빠르고 끝에서 느림
```

```
   ★ 회전 속도 기준

   360 °/s   →  1초에 한 바퀴. 느리다
   720 °/s   →  0.5초. 적당  ★
   1440 °/s  →  0.25초. 즉각적
   무한대    →  즉시 (탑다운 슈터)
```

```
   ★ 이동과 회전의 관계

   ① 회전 후 이동 (전차식)
      → 캐릭터가 향한 방향으로만 간다
      → 방향 전환이 느껴진다

   ② 이동하며 회전 (일반)
      → 입력 방향으로 즉시 가고 몸만 돌아간다  ★ 대부분
```

   입력 버퍼:  착지 직전에 눌러도 착지하면 뛴다

```csharp
    [SerializeField] private float jumpBufferTime = 0.12f;
    [SerializeField] private float coyoteTime = 0.1f;

    private float jumpBufferTimer;
    private float coyoteTimer;

    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space)) jumpBufferTimer = jumpBufferTime;
        else                                 jumpBufferTimer -= Time.deltaTime;
    }

    private void FixedUpdate()
    {
        if (isGrounded) coyoteTimer = coyoteTime;
        else            coyoteTimer -= Time.fixedDeltaTime;

        if (jumpBufferTimer > 0 && coyoteTimer > 0)
        {
            jumpBufferTimer = 0;
            coyoteTimer = 0;
            Jump();
        }
    }
```

### Step 1 — 플레이어 오브젝트

```

   ├─ Visual (Capsule)          ← 회색. 아트는 나중에
   ├─ CameraTarget (빈, y=1.4)
   ├─ Capsule Collider
   ├─ Rigidbody
   │    Mass 1, Drag 0, Freeze Rotation X/Z
   └─ PlayerController
```

```

   우리가 직접 감속을 제어한다
   → Drag가 있으면 튜닝이 꼬인다
```

**✅ 여기까지 하면** — 캡슐이 바닥에 선다.

### Step 2 — 입력

```csharp
using UnityEngine;

namespace OneFloor.Player
{
    [RequireComponent(typeof(Rigidbody))]
    public class PlayerController : MonoBehaviour
    {
        [Header("이동")]
        [SerializeField] private float maxSpeed = 6f;
        [SerializeField] private float accelTime = 0.12f;
        [SerializeField] private float decelTime = 0.08f;
        [SerializeField] private float rotationSpeed = 720f;
        [SerializeField] private float deadZone = 0.1f;

        [Header("참조")]
        [SerializeField] private Transform cameraTransform;
        [SerializeField] private Transform visual;

        private Rigidbody rb;
        private Vector2 rawInput;
        private Vector3 moveDir;
        private float currentSpeed;

        // 디버그용
        public Vector2 RawInput => rawInput;
        public float CurrentSpeed => currentSpeed;

        private float Acceleration => maxSpeed / Mathf.Max(accelTime, 0.001f);
        private float Deceleration => maxSpeed / Mathf.Max(decelTime, 0.001f);

        private void Awake()
        {
            rb = GetComponent<Rigidbody>();

            if (cameraTransform == null && Camera.main != null)
                cameraTransform = Camera.main.transform;
        }

        private void Update()
        {
            ReadInput();
        }

        private void FixedUpdate()
        {
            float dt = Time.fixedDeltaTime;

            UpdateMoveDirection();
            UpdateSpeed(dt);
            ApplyVelocity();
            UpdateRotation(dt);
        }

        private void ReadInput()
        {
            rawInput.x = Input.GetAxisRaw("Horizontal");
            rawInput.y = Input.GetAxisRaw("Vertical");

            if (rawInput.sqrMagnitude < deadZone * deadZone)
                rawInput = Vector2.zero;
            else if (rawInput.sqrMagnitude > 1f)
                rawInput.Normalize();
        }

        private void UpdateMoveDirection()
        {
            if (rawInput.sqrMagnitude < 0.01f) { moveDir = Vector3.zero; return; }

            Vector3 forward = cameraTransform.forward;
            Vector3 right = cameraTransform.right;

            forward.y = 0; forward.Normalize();
            right.y = 0;   right.Normalize();

            moveDir = (forward * rawInput.y + right * rawInput.x).normalized;
        }

        private void UpdateSpeed(float dt)
        {
            float target = moveDir.sqrMagnitude > 0.01f ? maxSpeed : 0f;
            float rate = (target > currentSpeed) ? Acceleration : Deceleration;

            currentSpeed = Mathf.MoveTowards(currentSpeed, target, rate * dt);
        }

        private void ApplyVelocity()
        {
            Vector3 v = moveDir * currentSpeed;
            rb.linearVelocity = new Vector3(v.x, rb.linearVelocity.y, v.z);
        }

        private void UpdateRotation(float dt)
        {
            if (moveDir.sqrMagnitude < 0.01f) return;

            Quaternion target = Quaternion.LookRotation(moveDir);

            transform.rotation = Quaternion.RotateTowards(
                transform.rotation, target, rotationSpeed * dt);
        }
    }
}

### Step 3 — 방향이 멈춰도 유지되는 문제

**입력을 놓으면 `moveDir`이 0이 된다.**

```

```csharp
    private Vector3 lastMoveDir;

    private void UpdateMoveDirection()
    {
        if (rawInput.sqrMagnitude < 0.01f)
        {
            moveDir = Vector3.zero;
            return;
        }

        // ... 계산 ...

        lastMoveDir = moveDir;                 // ★ 마지막 방향 기억
    }

    private void ApplyVelocity()
    {
        // ★ 입력이 없어도 마지막 방향으로 감속
        Vector3 dir = moveDir.sqrMagnitude > 0.01f ? moveDir : lastMoveDir;

        Vector3 v = dir * currentSpeed;
        rb.linearVelocity = new Vector3(v.x, rb.linearVelocity.y, v.z);
    }
```

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **답답하다** | accelTime 과다 | 0.1 이하로 |
| 답답하다 | 카메라 Damping | 0.2 이하로 |
| 답답하다 | 애니 Transition | 0.1 이하로 |
| 미끄러진다 | decelTime 과다 | 줄이기 |
| 대각선이 빠름 | Normalize 누락 | 추가 |
| 이동 방향이 이상 | 월드 기준 | 카메라 forward 변환 |
| 캐릭터가 땅으로 | `forward.y` 미제거 | y=0 후 정규화 |
| 갑자기 멈춤 | 방향 소실 | `lastMoveDir` |
| 중력이 안 먹음 | velocity 통째 대입 | y 보존 |
| 무한 점프 | 접지 판정 없음 | SphereCast |
| 넘어짐 | 회전 미고정 | Freeze Rotation X/Z |
| 빌드에서 다름 | 프레임률 차이 | FixedUpdate 사용 |
| 발이 미끄러짐 | 애니 속도 불일치 | Compute Thresholds (Day 83) |
