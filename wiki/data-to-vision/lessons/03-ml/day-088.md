```

**[Day 086](day-086.md)에서 봤던 파라미터 폭발이 다시 생깁니다.**

## ③ 개념 설명

### 풀링 (Pooling)

**작은 영역을 대표값 하나로 줄이는 연산입니다.**

```
        입력 (4×4)                MaxPooling(2×2)
   [1  3 | 2  4]                     [3  4]
   [2  1 | 0  1]        →            [6  8]
   ────────────
   [5  6 | 7  8]
   [1  2 | 3  4]
```

**2×2 영역마다 최댓값 하나**를 뽑습니다. 크기가 절반이 됩니다.

| 종류 | 하는 일 | 언제 |
|---|---|---|
| **MaxPooling** | 최댓값 | **기본 선택** |
| **AveragePooling** | 평균 | 부드러운 특징 |
| **GlobalAveragePooling** | 채널별 전체 평균 | Flatten 대체 |
| GlobalMaxPooling | 채널별 전체 최댓값 | 드묾 |

### MaxPooling vs AveragePooling

```
입력 영역
[1  8]
[2  3]

MaxPooling     → 8      "가장 강한 신호"
AveragePooling → 3.5    "평균적인 신호"
```

| | MaxPooling | AveragePooling |
|---|---|---|
| 강조 | **가장 두드러진 특징** | 전체적 경향 |
| 노이즈 | 이상값에 민감 | 완화됨 |
| 엣지 보존 | **좋음** | 흐려짐 |
| 주 용도 | **중간 층** | 마지막 층(Global) |

> **왜 Max가 기본인가** — 특징 검출에서는 **"있느냐 없느냐"** 가 중요합니다.
> 3×3 영역 어딘가에 세로 엣지가 있으면 "있다"고 하면 됩니다. 평균을 내면 희석됩니다.

### 풀링의 특징

| 특징 | 설명 |
|---|---|
| **파라미터 0** | 학습할 값이 없음. 단순 계산 |
| **채널 수 유지** | 채널마다 독립적으로 적용 |
| 크기만 줄임 | `(28,28,32)` → `(14,14,32)` |
| 미분 가능 | Max는 최댓값 위치로만 기울기 전달 |

```
입력 (28, 28, 32)
     ↓ MaxPooling2D(2)
출력 (14, 14, 32)      ← 채널 32는 그대로
```

### 풀링 출력 크기 공식

**합성곱과 같은 공식입니다.**

```
출력 = (입력 + 2×패딩 - 풀크기) // 스트라이드 + 1
```

**기본값 — Keras `MaxPooling2D(2)`**

```
pool_size = 2
strides = pool_size (기본값. 즉 2)
padding = "valid"

출력 = (n - 2) // 2 + 1 = n // 2      (n이 짝수일 때)
```

| 입력 | 출력 |
|---|---|
| 28 | 14 |
| 26 | 13 |
| 13 | **6** (13//2 = 6, 홀수는 버림) |
| 11 | **5** |
| 5 | 2 |

> ⚠️ **홀수는 버려집니다.** 13 → 6 (마지막 행/열 손실).
> `padding="same"` 을 주면 13 → 7이 됩니다. 다만 크게 중요하지 않습니다.

### 필터 개수를 늘려가는 관례

```python
Conv2D(32, 3) → Pool → Conv2D(64, 3) → Pool → Conv2D(128, 3)
       ↑                      ↑                        ↑
      32                     64                      128     (2배씩)
```

**왜 늘리는가**

| 이유 | 설명 |
|---|---|
| **공간이 줄어듦** | 28×28 → 14×14 → 7×7. 정보 총량을 유지하려면 채널을 늘려야 함 |
| **특징이 복잡해짐** | 깊은 층일수록 검출할 패턴의 종류가 많음 |
| 계산 균형 | 크기가 1/4로 줄 때 채널을 2배 하면 계산량이 절반 |

```
층 1: 28×28×32 = 25,088 개 값
층 2: 14×14×64 = 12,544 개 값       (절반)
층 3:  7× 7×128 = 6,272 개 값       (또 절반)
```

**정보를 점진적으로 압축하면서 추상화합니다.**

**비용**

```
Conv2D(32,3) on 1채널  : (3×3×1)×32 + 32 = 320
Conv2D(64,3) on 32채널 : (3×3×32)×64 + 64 = 18,496      ← 58배
Conv2D(128,3) on 64채널: (3×3×64)×128 + 128 = 73,856    ← 4배
```

**입력 채널 × 출력 채널로 파라미터가 늘어납니다.** 깊은 층일수록 무겁습니다.

### GlobalAveragePooling — Flatten의 대안

```
Flatten:                (7, 7, 128) → (6272,)
GlobalAveragePooling:   (7, 7, 128) → (128,)      ← 채널별 평균
```

```
채널 0의 7×7 값들 → 평균 1개
채널 1의 7×7 값들 → 평균 1개
...
채널 127          → 평균 1개
                    합계 128개
```

| | Flatten | GlobalAveragePooling |
|---|---|---|
| 출력 크기 | `H×W×C` | **`C`** |
| 다음 Dense 파라미터 | 매우 큼 | **매우 작음** |
| 입력 크기 의존 | **있음** | **없음** |
| 위치 정보 | 보존 | 버림 |

**예시 — `(7,7,128)` 다음에 `Dense(10)`**

```
Flatten  : 6272 × 10 + 10 = 62,730
GlobalAvg:  128 × 10 + 10 =   1,290      ← 48배 적음
```

> **현대 CNN은 대부분 GlobalAveragePooling을 씁니다.**
> 파라미터가 적고, **입력 이미지 크기가 달라져도 동작**합니다.
> [Day 098](day-098.md)의 전이학습에서 반드시 씁니다.

### ★ CNN 파라미터 계산 완전 정리

| 층 | 출력 shape | 파라미터 |
|---|---|---|
| `Input(H,W,C)` | `(H,W,C)` | 0 |
| `Conv2D(F, k, "valid")` | `(H-k+1, W-k+1, F)` | `(k×k×C)×F + F` |
| `Conv2D(F, k, "same")` | `(H, W, F)` | `(k×k×C)×F + F` |
| `Conv2D(F, k, "same", s=2)` | `(⌈H/2⌉, ⌈W/2⌉, F)` | `(k×k×C)×F + F` |
| `MaxPooling2D(p)` | `(H//p, W//p, C)` | **0** |
| `Flatten()` | `(H×W×C,)` | **0** |
| `GlobalAveragePooling2D()` | `(C,)` | **0** |
| `Dense(n)` | `(n,)` | `입력×n + n` |
| `Dropout(r)` | 그대로 | **0** |
| `BatchNormalization()` | 그대로 | `4×C` |

> **`BatchNormalization` 의 `4×C`** — 채널마다 γ, β(학습), 이동평균·분산(비학습) 4개씩입니다.
> 이 중 학습되는 것은 `2×C` 입니다. [Day 096](day-096.md)에서 다룹니다.

### Step 1. 풀링 직접 구현하고 비교

```python
import matplotlib.pyplot as plt
import numpy as np


def max_pool2d(image, pool_size=2, stride=None):
    stride = stride or pool_size
    H, W = image.shape
    oh = (H - pool_size) // stride + 1
    ow = (W - pool_size) // stride + 1
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            region = image[i * stride:i * stride + pool_size,
                           j * stride:j * stride + pool_size]
            out[i, j] = region.max()
    return out


def avg_pool2d(image, pool_size=2, stride=None):
    stride = stride or pool_size
    H, W = image.shape
    oh = (H - pool_size) // stride + 1
    ow = (W - pool_size) // stride + 1
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            region = image[i * stride:i * stride + pool_size,
                           j * stride:j * stride + pool_size]
            out[i, j] = region.mean()
    return out


# ── 손계산 검증 ──
img = np.array([

print("=" * 66)

print(f"\nMaxPooling(2×2)  shape {mp.shape}:")
print(mp.astype(int))
print("\n계산:")
print("  (0,0): max(1,3,2,1) = 3")
print("  (0,1): max(2,4,0,1) = 4")
print("  (1,0): max(5,6,1,2) = 6")
print("  (1,1): max(7,8,3,4) = 8")

print(f"\nAveragePooling(2×2)  shape {ap.shape}:")
print(ap)
print("\n계산:")
print("  (0,0): (1+3+2+1)/4 = 1.75")
print("  (0,1): (2+4+0+1)/4 = 1.75")

### Step 2. 풀링이 위치 변화에 둔감한 것 확인

```python
import matplotlib.pyplot as plt
import numpy as np


def max_pool2d(image, pool_size=2):
    H, W = image.shape
    oh, ow = H // pool_size, W // pool_size
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            out[i, j] = image[i*pool_size:(i+1)*pool_size,
                              j*pool_size:(j+1)*pool_size].max()
    return out


def avg_pool2d(image, pool_size=2):
    H, W = image.shape
    oh, ow = H // pool_size, W // pool_size
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            out[i, j] = image[i*pool_size:(i+1)*pool_size,
                              j*pool_size:(j+1)*pool_size].mean()
    return out


print("=" * 70)
print("특징의 위치가 조금 바뀌어도 풀링 결과는 유지되는가")
print("=" * 70)

base = np.zeros((8, 8))

# 같은 특징(강한 값 9)이 조금씩 다른 위치에 있는 경우
cases = []
for (r, c) in [(1, 1), (1, 2), (2, 1), (2, 2), (0, 0), (3, 3)]:
    img = base.copy()
    img[r, c] = 9
    img[r, c + 1] = 5 if c + 1 < 8 else 0
    cases.append((f"peak at ({r},{c})", img))

print(f"{'경우':<20}{'MaxPool 결과 (좌상단 2×2)':>34}{'동일?':>10}")
print("-" * 70)

ref = None
for name, img in cases:
    mp = max_pool2d(img, 2)
    corner = mp[:2, :2]
    if ref is None:
        ref = corner
    same = np.array_equal(corner, ref)
    print(f"{name:<20}{str(corner.astype(int).tolist()):>34}{str(same):>10}")

print("=" * 70)

# ── 시각화 ──
img1 = np.zeros((8, 8))
img1[2, 2] = 9
img1[2, 3] = 6
img1[3, 2] = 4

img2 = np.zeros((8, 8))
img2[2, 3] = 9      # 1픽셀 이동
img2[2, 4] = 6
img2[3, 3] = 4

fig, axes = plt.subplots(2, 4, figsize=(15, 7))

for row, (img, label) in enumerate([(img1, "original"), (img2, "shifted 1px")]):
    axes[row, 0].imshow(img, cmap="viridis", vmin=0, vmax=9)
    axes[row, 0].set_title(f"{label}\n{img.shape}", fontsize=10)

    mp = max_pool2d(img, 2)
    axes[row, 1].imshow(mp, cmap="viridis", vmin=0, vmax=9)
    axes[row, 1].set_title(f"MaxPool(2)\n{mp.shape}", fontsize=10)

    ap = avg_pool2d(img, 2)
    axes[row, 2].imshow(ap, cmap="viridis", vmin=0, vmax=9)
    axes[row, 2].set_title(f"AvgPool(2)\n{ap.shape}", fontsize=10)

    mp4 = max_pool2d(img, 4)
    axes[row, 3].imshow(mp4, cmap="viridis", vmin=0, vmax=9)
    axes[row, 3].set_title(f"MaxPool(4)\n{mp4.shape}", fontsize=10)

for ax in axes.ravel():
    ax.axis("off")

fig.suptitle("Same feature, shifted 1px — pooling absorbs small shifts", fontsize=14)
fig.tight_layout()
plt.show()

# ── 수치로 확인 ──
print("\n원본과 1픽셀 이동 이미지의 차이")
print(f"{'단계':<22}{'차이의 절댓값 합':>20}")
print("-" * 44)
print(f"{'원본 이미지':<22}{np.abs(img1 - img2).sum():>20.1f}")
for p in [2, 4, 8]:
    d = np.abs(max_pool2d(img1, p) - max_pool2d(img2, p)).sum()
    print(f"{f'MaxPool({p}) 후':<22}{d:>20.1f}")
print("-" * 44)
print("풀링 크기가 클수록 위치 변화에 둔감해집니다.")
print("다만 위치 정보도 그만큼 잃습니다. 균형이 필요합니다.")
```

from tensorflow import keras


def pool2d(image, pool_size=2, mode="max"):
    H, W = image.shape
    oh, ow = H // pool_size, W // pool_size
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            region = image[i*pool_size:(i+1)*pool_size,
                           j*pool_size:(j+1)*pool_size]
            out[i, j] = region.max() if mode == "max" else region.mean()
    return out

import pandas as pd
from tensorflow import keras
from tensorflow.keras import layers


def conv_out(n, k, padding="valid", stride=1):
    p = (k - 1) // 2 if padding == "same" else 0
    return (n + 2 * p - k) // stride + 1


def pool_out(n, p, stride=None):
    stride = stride or p
    return (n - p) // stride + 1


def conv_params(k, c_in, filters):
    return k * k * c_in * filters + filters


def dense_params(n_in, units):
    return n_in * units + units

from tensorflow.keras import layers


def build(head, input_size=28, channels=1):
    base = [
        layers.Input(shape=(input_size, input_size, channels)),

X_train = (X_train.astype("float32") / 255.0)[..., np.newaxis]

def build(pool_type="max", head="flatten", n_blocks=2):
    L = [layers.Input(shape=(28, 28, 1))]
    filters = 32
    for i in range(n_blocks):
        L.append(layers.Conv2D(filters, 3, padding="same", activation="relu"))
        if pool_type == "max":
            L.append(layers.MaxPooling2D(2))
        elif pool_type == "avg":
            L.append(layers.AveragePooling2D(2))
        elif pool_type == "stride":
            L[-1] = layers.Conv2D(filters, 3, padding="same",
                                  strides=2, activation="relu")
        elif pool_type == "none":
            pass
        filters *= 2

    if head == "flatten":
        L.append(layers.Flatten())
    else:
        L.append(layers.GlobalAveragePooling2D())
    L += [layers.Dense(64, activation="relu"),
          layers.Dense(10, activation="softmax")]
    return keras.Sequential(L)

## ⑤ 자주 하는 실수

### 풀링 후 크기가 홀수가 되는 것을 놓침

```
26 → Pool(2) → 13 → Pool(2) → 6      (13//2 = 6, 1픽셀 손실)
```

**해결 방법 두 가지**

```python
# ① padding="same" 을 주면 올림
layers.MaxPooling2D(2, padding="same")     # 13 → 7

# ② Conv에 padding="same" 을 써서 크기를 짝수로 유지
layers.Conv2D(32, 3, padding="same")       # 28 → 28 → Pool → 14
```

> **`padding="same"` 을 Conv에 쓰면 크기 관리가 쉬워집니다.**
> 28 → 14 → 7 처럼 깔끔하게 절반씩 줄어듭니다.

### 풀링을 너무 많이 함

```python
Conv → Pool → Conv → Pool → Conv → Pool → Conv → Pool      # 28 → 1
```

```
28 → 14 → 7 → 3 → 1
```

**1×1이 되면 공간 정보가 완전히 사라집니다.**

**해결** — 입력 크기에 맞춰 풀링 횟수를 정하세요.

| 입력 | 권장 풀링 횟수 | 최종 크기 |
|---|---|---|
| 28×28 | 2 | 7×7 |
| 32×32 | 2~3 | 8×8 or 4×4 |
| 128×128 | 4 | 8×8 |
| 224×224 | 5 | 7×7 |

> **최종 특성맵을 7×7 정도로 만드는 것이 관례**입니다. (ResNet, VGG 등)

### `Flatten` 을 안 넣고 `Dense` 를 붙임

```python
layers.Conv2D(64, 3),
layers.Dense(10),          # ✗
```

**에러가 안 납니다.** 출력이 `(None, 5, 5, 10)` 이 됩니다.

```
Dense는 마지막 차원에만 적용됩니다.
(5, 5, 64) → Dense(10) → (5, 5, 10)
```

**해결** — `Flatten()` 또는 `GlobalAveragePooling2D()` 를 넣으세요.

> **`model.summary()` 로 출력 shape을 확인하는 습관**을 들이세요.
> 마지막 층이 `(None, 10)` 이 아니면 뭔가 잘못된 것입니다.

### 풀링에 파라미터가 있다고 생각

```
max_pooling2d (MaxPooling2D)   (None, 13, 13, 32)   0
                                                    ↑ 항상 0
```

**풀링은 학습할 값이 없습니다.** 단순히 최댓값을 고를 뿐입니다.
`Flatten`, `Dropout`, `Reshape` 도 마찬가지로 0입니다.

### GlobalAveragePooling을 중간에 씀

```python
layers.Conv2D(32, 3),
layers.GlobalAveragePooling2D(),      # ✗ 여기서 (32,)가 됨
layers.Conv2D(64, 3),                 # 에러
```

**GAP은 공간 차원을 완전히 없앱니다.** 반드시 **마지막 Conv 뒤**에 씁니다.

### 필터 수를 줄여가며 쌓음

```python
Conv2D(128, 3) → Pool → Conv2D(64, 3) → Pool → Conv2D(32, 3)      # ✗ 관례와 반대
```

**일반적으로는 늘려갑니다.**

```python
Conv2D(32, 3) → Pool → Conv2D(64, 3) → Pool → Conv2D(128, 3)      # ✓
```

> **첫 층에 필터를 많이 두는 것도 비효율적입니다.**
> 첫 층은 엣지 같은 단순한 패턴만 검출하므로 필터가 적어도 됩니다.
> 깊은 층일수록 조합의 종류가 많아져 필터가 많이 필요합니다.

### AveragePooling과 GlobalAveragePooling을 혼동

```python
layers.AveragePooling2D(2)           # (28,28,32) → (14,14,32)
layers.GlobalAveragePooling2D()      # (28,28,32) → (32,)
```

| | 하는 일 |
|---|---|
| `AveragePooling2D(2)` | 2×2 영역마다 평균. **공간 차원 유지** |
| `GlobalAveragePooling2D()` | 전체 공간의 평균. **공간 차원 제거** |

### 스트라이드 Conv와 Pooling을 둘 다 씀

```python
layers.Conv2D(32, 3, strides=2),
layers.MaxPooling2D(2),              # 크기가 1/4로 급감
```

```
28 → 14 (stride) → 7 (pool)
```

**의도한 것이 아니라면 하나만 쓰세요.**

    rows = []
    total = 0
    rows.append({"층": "Input", "출력 shape": f"({h}, {w}, {c})",
                 "파라미터": 0, "계산식": "-"})

    for item in spec:
        kind = item[0]
        if kind == "conv":
            _, f, k, pad = item
            p = (k - 1) // 2 if pad == "same" else 0
            params = k * k * c * f + f
            calc = f"({k}×{k}×{c})×{f} + {f}"
            h = (h + 2 * p - k) + 1
            w = (w + 2 * p - k) + 1
            c = f
            name = f"Conv2D({f},{k},{pad})"
        elif kind == "pool":
            _, p = item
            params = 0
            calc = "-"
            h, w = h // p, w // p
            name = f"MaxPool({p})"
        elif kind == "gap":
            params = 0
            calc = f"평균 → 채널 {c}개"
            h, w = 1, 1
            name = "GlobalAvgPool"
        elif kind == "flatten":
            params = 0
            calc = f"{h}×{w}×{c} = {h*w*c}"
            c = h * w * c
            h = w = 1
            name = "Flatten"
        elif kind == "dense":
            _, units = item
            n_in = c if h == 1 else h * w * c
            params = n_in * units + units
            calc = f"{n_in}×{units} + {units}"
            c = units
            h = w = 1
            name = f"Dense({units})"
        elif kind == "dropout":
            params = 0
            calc = "-"
            name = f"Dropout({item[1]})"

        total += params
        shape = f"({c},)" if h == 1 and w == 1 else f"({h}, {w}, {c})"
        rows.append({"층": name, "출력 shape": shape,
                     "파라미터": params, "계산식": calc})

    return pd.DataFrame(rows), total

def build(head="flatten", filters=(16, 32, 64, 128), dense_units=64):
    L = [layers.Input(shape=(64, 64, 3))]
    for f in filters:
        L += [layers.Conv2D(f, 3, padding="same", activation="relu"),
              layers.MaxPooling2D(2)]
    L += [layers.Flatten() if head == "flatten" else layers.GlobalAveragePooling2D()]
    L += [layers.Dense(dense_units, activation="relu"), layers.Dropout(0.4),
          layers.Dense(5, activation="softmax")]
    return keras.Sequential(L)

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| 풀링의 목적 | **크기 축소** + **위치 변화에 둔감** |
| **파라미터** | **0** (학습할 값 없음) |
| 채널 수 | **유지됨** (채널마다 독립 적용) |
| MaxPooling | 최댓값. **기본 선택** (특징의 유무가 중요) |
| AveragePooling | 평균. 전체 밝기 유지 |
| **출력 크기** | `(n - pool) // stride + 1`. 기본 stride = pool |
| 홀수 입력 | 버림. 13 → 6. `padding="same"` 이면 7 |
| 필터 수 관례 | 32 → 64 → 128 (**2배씩 증가**) |
| 늘리는 이유 | 공간이 줄어드니 채널로 정보량 보전 |
| **GlobalAvgPool** | `(H,W,C)` → `(C,)`. **입력 크기 무관** |
| Flatten vs GAP | 224×224에서 **139배** 파라미터 차이 |
| 풀링 횟수 | 최종 **7×7 정도**가 관례. 너무 많으면 정보 소실 |
| 파라미터 비중 | **Flatten 직후 Dense가 대부분** |

**오늘 반드시 기억할 세 가지**
> ① **풀링은 파라미터가 0입니다.** 그런데 파라미터를 8배 이상 줄여 줍니다 (Flatten 크기 축소).
> ② **`model.summary()` 의 모든 숫자를 손으로 계산할 수 있어야 합니다.** 설계의 기본입니다.
> ③ **파라미터가 가장 많은 곳은 Flatten 직후 Dense입니다.** 여기를 손봐야 효과가 큽니다.
