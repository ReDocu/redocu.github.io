## ③ 개념 설명

### API 란

**A**pplication **P**rogramming **I**nterface — 프로그램끼리 데이터를 주고받는 **약속된 창구**입니다.

```
[내 코드]  ──  "서울 관광지 20개 줘"  ──▶  [관광공사 서버]
           ◀──  JSON 데이터          ──
```

식당에 비유하면 이렇습니다.

| 비유 | API |
|---|---|
| 메뉴판 | **API 문서** — 뭘 시킬 수 있는지 |
| 주문 | **요청(Request)** — 파라미터로 조건 지정 |
| 음식 | **응답(Response)** — JSON |
| 회원카드 | **인증키(API Key)** — 누가 시켰는지 |
| 1인 5그릇 제한 | **요청 한도(Rate limit)** |

### REST 개념

**웹 주소(URL)로 자원을 구분하고, HTTP 메서드로 동작을 표현**하는 방식입니다.

```
GET    /api/tours/123      123번 관광지 조회
GET    /api/tours?area=1   서울 관광지 목록
POST   /api/tours          새로 등록
PUT    /api/tours/123      수정
DELETE /api/tours/123      삭제
```

| 메서드 | 용도 | 데이터 수집에서 |
|---|---|---|
| **GET** | 조회 | **거의 100% 이것만 씁니다** |
| POST | 생성 | 검색 조건이 복잡할 때 가끔 |
| PUT/PATCH/DELETE | 수정/삭제 | ❌ 수집에서는 쓸 일 없음 |

> ⚠️ **수집 목적으로는 `GET` 만 사용합니다.**
> `POST` `PUT` `DELETE` 는 **서버의 데이터를 바꾸는** 동작입니다.
> 남의 서버에 대해 함부로 호출하면 안 됩니다.

### 요청 구성 요소

```python

| 구성 | 역할 |
|---|---|
| **엔드포인트** | 어떤 데이터를 주는 창구인지 |
| **쿼리 파라미터** | 조건 (지역·개수·페이지·형식) |
| **헤더** | 인증 토큰이 헤더로 가는 API도 많음 |
| **타임아웃** | 응답이 없을 때 포기할 시간 |

### ⚠️ Encoding 키 vs Decoding 키 — 가장 많이 막히는 지점

마이페이지에 키가 **두 개** 보입니다.

```
일반 인증키(Encoding)  :  aB3dEf9%2BXyZ%2F1234%3D
일반 인증키(Decoding)  :  aB3dEf9+XyZ/1234=
```

**같은 키인데 하나는 URL 인코딩된 것**입니다. (`+` → `%2B`, `/` → `%2F`, `=` → `%3D`)

```python
# ✅ 방법 A — Decoding 키를 params 로 (권장)
requests.get(url, params={"serviceKey": DECODING_KEY, ...})
#   requests 가 알아서 인코딩해 줍니다

# ✅ 방법 B — Encoding 키를 URL 에 직접
requests.get(f"{url}?serviceKey={ENCODING_KEY}&numOfRows=20")

# ❌ 방법 C — Encoding 키를 params 로  ← 가장 흔한 실수
requests.get(url, params={"serviceKey": ENCODING_KEY, ...})
#   %2B 가 %252B 로 이중 인코딩 → 인증 실패
```

```
SERVICE_KEY_IS_NOT_REGISTERED_ERROR
```

> **키가 분명 맞는데 인증 오류가 난다면 99% 이 문제입니다.**
> **`params` 를 쓸 거면 Decoding 키**를 쓰세요.

### 응답 구조 파악 — 공공데이터포털 공통 형식

```python

  "response": {
    "header": { "resultCode": "0000", "resultMsg": "OK" },

          { "title": "남산타워", ... }

    }
  }

```

**꺼내는 경로가 4단계입니다.**

```python
items = data["response"]["body"]["items"]["item"]     # ❌ 위험
```

| 함정 | 상황 | 결과 |
|---|---|---|
| **items 가 빈 문자열** | 결과 0건일 때 `"items": ""` | `TypeError: string indices must be integers` |
| **item 이 dict** | 결과가 **1건**일 때 리스트가 아님 | `for` 문이 키를 순회함 |
| **XML 이 옴** | `_type=json` 을 빼먹음 | `JSONDecodeError` |
| **에러도 200** | 인증 실패인데 상태 코드는 200 | `resultCode` 를 봐야 함 |

**✅ 안전한 추출**

```python
def extract_items(data):
    """공공데이터포털 응답에서 항목 리스트를 안전하게 꺼냅니다."""
    body = (data or {}).get("response", {}).get("body", {})
    items = body.get("items")

    if not items:                       # "" 또는 None → 0건
        return []

    item = items.get("item") if isinstance(items, dict) else items

    if item is None:
        return []
    if isinstance(item, dict):          # 1건이면 dict
        return [item]

    return item
```

### 결과 코드 확인

**HTTP 200이어도 실패일 수 있습니다.**

```python
header = data["response"]["header"]
code = header.get("resultCode")

if code not in ("00", "0000"):
    raise RuntimeError(f"API 오류 [{code}] {header.get('resultMsg')}")
```

| resultCode | 의미 | 대응 |
|---|---|---|
| `00` / `0000` | 정상 | — |
| `03` | 데이터 없음 | 조건을 바꾸거나 종료 |
| `12` | 폐기된 서비스 | 다른 API 찾기 |
| `20` | 서비스 접근 거부 | 활용신청 확인 |
| `22` | **요청 한도 초과** | **중단.** 내일 다시 |
| `30` | 등록되지 않은 키 | **Encoding/Decoding 확인** |
| `31` | 기한 만료 | 연장 신청 |

### 요청 한도 관리

```python
class RateLimiter:
    """일일 호출 횟수를 세고 한도를 넘지 않게 합니다."""

    def __init__(self, daily_limit=1000, min_interval=0.2):
        self.daily_limit = daily_limit
        self.min_interval = min_interval
        self.count = 0
        self.last = 0.0

    def wait(self):
        if self.count >= self.daily_limit:
            raise RuntimeError(f"일일 한도 {self.daily_limit}회 도달")

        gap = time.perf_counter() - self.last
        if gap < self.min_interval:
            time.sleep(self.min_interval - gap)

        self.last = time.perf_counter()
        self.count += 1
```

```python
"""공공 API 첫 호출 — 인증키는 코드 밖에서."""

import json
import os

import requests
from dotenv import load_dotenv

# ── ① 키 불러오기 ──
load_dotenv()
KEY = os.getenv("DATA_GO_KR_KEY")

print("=" * 74)
print("                  공공 API 첫 요청")
print("=" * 74)

print(f"\n[① 인증키]")
if not KEY:
    print("  ✗ DATA_GO_KR_KEY 가 없습니다")
    print("    .env 파일에 다음 줄을 추가하세요:")
    print("    DATA_GO_KR_KEY=발급받은_Decoding_키")
    raise SystemExit
print(f"  ✓ 불러옴 — {KEY[:8]}...{KEY[-4:]}  (길이 {len(KEY)})")

if "%" in KEY:
    print(f"  ⚠ 키에 '%' 가 있습니다 — Encoding 키일 수 있습니다")
    print(f"    params 로 넘길 때는 Decoding 키를 쓰세요")

# ── ② 요청 ──
URL = "http://apis.data.go.kr/B551011/KorService1/areaBasedList1"

params = {
    "serviceKey": KEY,
    "numOfRows": 5,
    "pageNo": 1,
    "MobileOS": "ETC",
    "MobileApp": "AcademyPractice",
    "_type": "json",              # ← 빼먹으면 XML 이 옵니다
    "areaCode": 1,                # 1 = 서울
    "arrange": "A",               # A=제목순
}

res = requests.get(URL, params=params, timeout=10)

print(f"\n[② 응답]")
print(f"  상태 코드   : {res.status_code}")
print(f"  Content-Type: {res.headers.get('Content-Type')}")
print(f"  크기        : {len(res.text):,} bytes")
print(f"  요청 URL    : {res.url[:100]}...")

# ── ③ JSON 인지 확인 ──
if res.text.lstrip().startswith("<"):
    print(f"\n  ⚠ XML 이 왔습니다. '_type': 'json' 을 확인하세요")
    print(f"  {res.text[:300]}")
    raise SystemExit

try:
    data = res.json()
except json.JSONDecodeError as e:
    print(f"\n  ✗ JSON 파싱 실패: {e}")
    print(f"  {res.text[:300]}")
    raise SystemExit

# ── ④ 결과 코드 확인 ──
header = data.get("response", {}).get("header", {})
code = header.get("resultCode")

print(f"\n[③ 결과 코드]")
print(f"  resultCode : {code}")
print(f"  resultMsg  : {header.get('resultMsg')}")

if code not in ("00", "0000"):
    print(f"  ✗ API 오류 — 아래 표에서 원인을 확인하세요")
    raise SystemExit

# ── ⑤ 구조 확인 ──
body = data["response"]["body"]

print(f"\n[④ 응답 구조]")
print(f"  totalCount : {body.get('totalCount'):,}건")
print(f"  numOfRows  : {body.get('numOfRows')}")
print(f"  pageNo     : {body.get('pageNo')}")

items = body.get("items", {}).get("item", [])
print(f"  받은 항목  : {len(items)}개")

print(f"\n[⑤ 첫 항목의 전체 필드]")
for k, v in list(items[0].items()):
    preview = str(v)[:44]
    print(f"  {k:<16}{preview}")

print("\n" + "=" * 74)
```

```python
"""한국관광공사 TourAPI 클라이언트."""

import json
import logging
import math
import os
import time
from pathlib import Path

import pandas as pd
import requests
from dotenv import load_dotenv

load_dotenv()

# ══════════ 설정 ══════════
BASE = "http://apis.data.go.kr/B551011/KorService1"
KEY = os.getenv("DATA_GO_KR_KEY")

COMMON = {
    "serviceKey": KEY,
    "MobileOS": "ETC",
    "MobileApp": "AcademyPractice",
    "_type": "json",
}

TIMEOUT = 10
RETRIES = 2
MIN_INTERVAL = 0.3            # 요청 간 최소 간격(초)
DAILY_LIMIT = 1000            # 개발계정 한도

RAW_DIR = Path("data/raw")
RAW_DIR.mkdir(parents=True, exist_ok=True)

logging.basicConfig(level=logging.INFO,
                    format="%(asctime)s [%(levelname)s] %(message)s",
                    datefmt="%H:%M:%S")
log = logging.getLogger("tourapi")

AREA_CODES = {
    1: "서울", 2: "인천", 3: "대전", 4: "대구", 5: "광주", 6: "부산",
    7: "울산", 8: "세종", 31: "경기", 32: "강원", 33: "충북", 34: "충남",
    35: "경북", 36: "경남", 37: "전북", 38: "전남", 39: "제주",
}

CONTENT_TYPES = {
    12: "관광지", 14: "문화시설", 15: "축제공연행사", 25: "여행코스",
    28: "레포츠", 32: "숙박", 38: "쇼핑", 39: "음식점",
}

RESULT_MSG = {
    "03": "데이터 없음", "12": "폐기된 서비스", "20": "서비스 접근 거부",
    "22": "요청 한도 초과", "30": "등록되지 않은 인증키",
    "31": "기한 만료된 인증키", "32": "등록되지 않은 IP",
}


class ApiError(Exception):
    """API 가 오류 코드를 반환했을 때."""


class QuotaExceeded(ApiError):
    """요청 한도 초과 — 즉시 중단."""


class RateLimiter:
    """요청 간격과 일일 한도를 관리합니다."""

    def __init__(self, daily_limit=DAILY_LIMIT, min_interval=MIN_INTERVAL):
        self.daily_limit = daily_limit
        self.min_interval = min_interval
        self.count = 0
        self._last = 0.0

    def wait(self):
        if self.count >= self.daily_limit:
            raise QuotaExceeded(f"일일 한도 {self.daily_limit}회 도달")

        gap = time.perf_counter() - self._last
        if gap < self.min_interval:
            time.sleep(self.min_interval - gap)

        self._last = time.perf_counter()
        self.count += 1

    def report(self):
        pct = self.count / self.daily_limit * 100
        return f"{self.count}/{self.daily_limit}회 ({pct:.1f}%)"


limiter = RateLimiter()
session = requests.Session()


# ══════════ 응답 처리 ══════════

def extract_items(data):
    """응답에서 항목 리스트를 안전하게 꺼냅니다."""
    body = (data or {}).get("response", {}).get("body", {})
    items = body.get("items")

    if not items:                                  # "" 또는 None → 0건
        return []

    item = items.get("item") if isinstance(items, dict) else items

    if item is None:
        return []
    if isinstance(item, dict):                     # 1건이면 dict
        return [item]

    return item


def check_result(data):
    """resultCode 를 확인합니다. 실패면 예외."""
    header = (data or {}).get("response", {}).get("header", {})
    code = str(header.get("resultCode", "")).strip()
    msg = header.get("resultMsg", "")

    if code in ("00", "0000"):
        return

    detail = RESULT_MSG.get(code.zfill(2), msg)

    if code.zfill(2) == "22":
        raise QuotaExceeded(f"[{code}] {detail}")

    raise ApiError(f"[{code}] {detail}")


# ══════════ 호출 ══════════

def call(operation, **params):
    """
    API 를 호출합니다.

    operation : 'areaBasedList1', 'detailCommon1' 등
    반환      : 응답 dict
    """
    if not KEY:
        raise SystemExit("DATA_GO_KR_KEY 가 없습니다. .env 를 확인하세요.")

    url = f"{BASE}/{operation}"
    query = {**COMMON, **params}

    for attempt in range(RETRIES + 1):
        limiter.wait()

        try:
            res = session.get(url, params=query, timeout=TIMEOUT)
        except requests.RequestException as e:
            wait = 2 ** attempt
            log.warning(f"  {type(e).__name__} — {wait}초 후 재시도")
            time.sleep(wait)
            continue

        if res.text.lstrip().startswith("<"):      # XML 응답
            snippet = res.text[:200].replace("\n", " ")
            raise ApiError(f"XML 응답 — _type 확인 필요: {snippet}")

        try:
            data = res.json()
        except json.JSONDecodeError:
            log.warning(f"  JSON 파싱 실패 — 재시도")
            continue

        check_result(data)                          # 한도 초과면 여기서 예외
        return data

    raise ApiError(f"{operation} 최종 실패")


def fetch_all(operation, rows=100, max_pages=None, **params):
    """
    페이지를 끝까지 순회하며 모든 항목을 모읍니다.

    rows      : 페이지당 건수 (최대 100 권장)
    max_pages : 상한 (None 이면 totalCount 기준)
    """
    first = call(operation, numOfRows=rows, pageNo=1, **params)

    body = first["response"]["body"]
    total = int(body.get("totalCount", 0))

    if total == 0:
        log.info(f"  결과 0건")
        return []

    pages = math.ceil(total / rows)
    if max_pages:
        pages = min(pages, max_pages)

    log.info(f"  전체 {total:,}건 → {pages}페이지 수집")

    all_items = extract_items(first)

    for page in range(2, pages + 1):
        try:
            data = call(operation, numOfRows=rows, pageNo=page, **params)
        except QuotaExceeded:
            raise
        except ApiError as e:
            log.warning(f"  {page}페이지 실패: {e}")
            continue

        items = extract_items(data)

        if not items:                               # 종료 조건
            break

        all_items.extend(items)

    return all_items
```

> **눈여겨볼 점 8가지**
> - **지역마다 캐시 파일** — 중단돼도 이어서 수집합니다. ([Day 053](day-053.md)과 같은 원칙)

> - `limiter.report()` 로 **한도를 얼마나 썼는지** 출력합니다. 51/1000 — 안전합니다.
> - **`MAX_PAGES_PER_AREA=3`** — 전국을 전부 받으면 500회 이상입니다. 실습에서는 제한합니다.
> - `pd.json_normalize` 로 펼치고, **필요한 열만 골라 이름을 바꿉니다.**
> - **좌표를 `to_numeric`** — API 는 좌표도 **문자열**로 줍니다. 안 바꾸면 지도에 못 올립니다.
> - **좌표 범위 검증** — 한반도 밖 3건은 데이터 오류입니다. ([Day 057](day-057.md) 이상치)
> - `tel` 결측 57% — **결측이 많다고 나쁜 게 아닙니다.** 전화번호가 없는 관광지가 많을 뿐입니다.

"""헤더 인증 API (카카오 로컬) — 주소를 좌표로."""

import os

import requests
from dotenv import load_dotenv

load_dotenv()
KAKAO_KEY = os.getenv("KAKAO_REST_KEY")

URL = "https://dapi.kakao.com/v2/local/search/address.json"


def geocode(address):
    """주소 → (위도, 경도). 실패하면 (None, None)."""
    if not KAKAO_KEY:
        return None, None

    res = requests.get(URL,
                       params={"query": address},
                       headers={"Authorization": f"KakaoAK {KAKAO_KEY}"},
                       timeout=10)

    if not res.ok:
        return None, None

    docs = res.json().get("documents", [])
    if not docs:
        return None, None

    return float(docs[0]["y"]), float(docs[0]["x"])      # y=위도, x=경도


if __name__ == "__main__":
    samples = [
        "서울특별시 종로구 사직로 161",
        "부산광역시 해운대구 우동",
        "존재하지않는주소12345",
    ]

    print("=" * 66)
    print("            주소 → 좌표 (카카오 로컬 API)")
    print("=" * 66)
    print(f"\n  {'주소':<32}{'위도':>11}{'경도':>12}")
    print("  " + "-" * 56)

    for addr in samples:
        lat, lng = geocode(addr)
        if lat is None:
            print(f"  {addr:<32}{'실패':>11}{'':>12}")
        else:

    print("\n" + "=" * 66)

    raise SystemExit("DATA_GO_KR_KEY 가 없습니다")

URL = "http://apis.data.go.kr/B551011/KorService1/areaBasedList1"
ROWS = 100                                    # ⑨ 요청 수 1/10
DELAY = 0.3                                   # ⑩ 지연
MAX_PAGES = 30

RAW = Path("data/raw")
RAW.mkdir(parents=True, exist_ok=True)

COMMON = {
    "serviceKey": KEY,
    "MobileOS": "ETC",                        # ④ 필수
    "MobileApp": "AcademyPractice",           # ④ 필수
    "_type": "json",                          # ③ JSON 요청
}


def extract_items(data):                      # ⑦ 안전한 추출
    body = (data or {}).get("response", {}).get("body", {})
    items = body.get("items")

    if not items:
        return []

    item = items.get("item") if isinstance(items, dict) else items

    if item is None:
        return []
    return [item] if isinstance(item, dict) else item


def check(data):                              # ⑥ 결과 코드 확인
    header = (data or {}).get("response", {}).get("header", {})
    code = str(header.get("resultCode", "")).strip()

    if code not in ("00", "0000"):
        raise RuntimeError(f"[{code}] {header.get('resultMsg')}")


def call(page, rows=ROWS, **extra):
    time.sleep(DELAY)                          # ⑩ 지연

    res = requests.get(URL,
                       params={**COMMON, "numOfRows": rows,
                               "pageNo": page, **extra},
                       timeout=10)             # ⑤ 타임아웃
    res.raise_for_status()

    if res.text.lstrip().startswith("<"):      # ③ XML 방어
        raise RuntimeError(f"XML 응답: {res.text[:150]}")

    data = res.json()
    check(data)
    return data


# ── ① 첫 요청으로 전체 건수 확인 ──                ⑧
first = call(page=1, areaCode=1, contentTypeId=12)
total = int(first["response"]["body"]["totalCount"])
pages = min(math.ceil(total / ROWS), MAX_PAGES)

print(f"전체 {total:,}건 → {pages}페이지 (상한 {MAX_PAGES})")

rows_data = extract_items(first)

# ── ② 나머지 페이지 ──
for page in range(2, pages + 1):
    cache = RAW / f"area01_page{page:03d}.json"    # ⑩ 원본 저장

    if cache.exists():
        rows_data.extend(json.loads(cache.read_text(encoding="utf-8")))
        continue

    try:
        data = call(page, areaCode=1, contentTypeId=12)
    except RuntimeError as e:
        print(f"  {page}페이지 실패: {e}")
        continue

    items = extract_items(data)

    if not items:
        break

    cache.write_text(json.dumps(items, ensure_ascii=False), encoding="utf-8")
    rows_data.extend(items)

    print(f"  {page}/{pages} — 누적 {len(rows_data):,}건")

# ── ③ 정리 ──
df = pd.json_normalize(rows_data)

df["mapx"] = pd.to_numeric(df.get("mapx"), errors="coerce")
df["mapy"] = pd.to_numeric(df.get("mapy"), errors="coerce")

before = len(df)
df = df.drop_duplicates(subset=["contentid"]).reset_index(drop=True)

print(f"중복 제거 {before:,} → {len(df):,}")

df.to_csv("data/result.csv", index=False, encoding="utf-8-sig")   # ⑩
print(f"저장 완료 ({len(df):,}건)")

"""JSON 응답 구조 분석 도구."""

import json


def explore(data, max_depth=5, max_items=3, indent=0, key="root"):
    """
    중첩된 JSON 의 구조를 트리로 출력합니다.

    max_depth : 몇 단계까지 파고들지
    max_items : 리스트에서 몇 개까지 볼지
    """
    pad = "  " * indent
    arrow = "└─ " if indent else ""

    if indent > max_depth:
        print(f"{pad}{arrow}{key}: ...")
        return

    if isinstance(data, dict):
        print(f"{pad}{arrow}{key}: dict ({len(data)} keys)")
        for k, v in data.items():
            explore(v, max_depth, max_items, indent + 1, k)

    elif isinstance(data, list):
        print(f"{pad}{arrow}{key}: list ({len(data)} items)")
        for i, v in enumerate(data[:max_items]):
            explore(v, max_depth, max_items, indent + 1, f"[{i}]")
        if len(data) > max_items:
            print(f"{pad}  ... {len(data) - max_items}개 더")

    else:
        preview = str(data)
        if len(preview) > 46:
            preview = preview[:46] + "..."
        print(f"{pad}{arrow}{key}: {type(data).__name__} = {preview}")


def find_records(data, min_len=2, path=""):
    """
    '레코드 리스트'로 보이는 지점을 찾습니다.
    (같은 구조의 dict 가 여러 개 들어 있는 리스트)
    """
    found = []

    if isinstance(data, list) and len(data) >= min_len:
        if all(isinstance(x, dict) for x in data):
            keys = set(data[0].keys())
            if all(set(x.keys()) == keys for x in data[:5]):
                found.append((path, len(data), sorted(keys)))

    if isinstance(data, dict):
        for k, v in data.items():
            found += find_records(v, min_len, f"{path}.{k}" if path else k)
    elif isinstance(data, list):
        for i, v in enumerate(data[:3]):
            found += find_records(v, min_len, f"{path}[{i}]")

    return found


def field_report(records):
    """레코드 리스트의 필드별 채움 비율과 예시를 출력합니다."""
    if not records:
        return

    keys = sorted({k for r in records for k in r.keys()})

    print(f"\n  {'필드':<18}{'채움':>8}{'비율':>8}  {'타입':<10}예시")
    print("  " + "-" * 74)

    for k in keys:
        values = [r.get(k) for r in records]
        filled = [v for v in values if v not in (None, "", [], {})]
        pct = len(filled) / len(values) * 100

        sample = str(filled[0])[:26] if filled else "-"
        vtype = type(filled[0]).__name__ if filled else "-"

        mark = " " if pct == 100 else ("⚠" if pct < 50 else " ")
        print(f" {mark}{k:<18}{len(filled):>8}{pct:>7.1f}%  {vtype:<10}{sample}")

@dataclass

    ok_codes: tuple = ("00", "0000")

    @property
    def key(self):

class ApiClient:
    """ApiSpec 하나를 담당하는 클라이언트."""

    def __init__(self, spec):

        self.session = requests.Session()

        self.errors = []
        self._last = 0.0

    def _wait(self):
        if self.count >= self.spec.daily_limit:
            raise RuntimeError(f"{self.spec.name} 한도 도달")

        gap = time.perf_counter() - self._last
        if gap < self.spec.min_interval:
            time.sleep(self.spec.min_interval - gap)

        self._last = time.perf_counter()
        self.count += 1

    def _auth(self, params, headers):
        s = self.spec

        if s.auth == "param":
            params[s.key_param] = s.key
        elif s.auth in ("header", "bearer"):
            fmt = "Bearer {key}" if s.auth == "bearer" else s.header_format
            headers[s.key_header] = fmt.format(key=s.key)

        return params, headers

    def get(self, path, **params):
        """API 를 호출하고 레코드 리스트를 반환합니다."""
        if not self.spec.available:
            raise RuntimeError(f"{self.spec.key_env} 가 .env 에 없습니다")

        self._wait()

        query = {**self.spec.common_params, **params}
        headers = {"User-Agent": "AcademyPractice/1.0"}
        query, headers = self._auth(query, headers)

        res = self.session.get(f"{self.spec.base_url}/{path}",
                               params=query, headers=headers, timeout=10)
        res.raise_for_status()

        if res.text.lstrip().startswith("<"):
            raise RuntimeError("XML 응답 — 파라미터 확인")

        data = res.json()
        self._check(data)

        return self._records(data), data

    def _check(self, data):
        """공공데이터포털 형식이면 resultCode 확인."""
        header = (data or {}).get("response", {}).get("header")

        if not header:
            return

        code = str(header.get("resultCode", "")).strip()
        if code not in self.spec.ok_codes:
            raise RuntimeError(f"[{code}] {header.get('resultMsg')}")

    def _records(self, data):
        """정의된 경로에서 레코드를 꺼냅니다."""
        node = data

        for part in self.spec.records_path:
            if node is None or node == "":
                return []
            node = node.get(part) if isinstance(node, dict) else None

        if node is None or node == "":
            return []
        if isinstance(node, dict):
            return [node]

        return node

    def close(self):
        self.session.close()

    def report(self):
        pct = self.count / self.spec.daily_limit * 100
        return (f"{self.spec.name:<20}{self.count:>6}/{self.spec.daily_limit:<8}"
                f"({pct:>5.1f}%)  실패 {len(self.errors)}건")


# ══════════ 파이프라인 ══════════

class Pipeline:
    """여러 API 수집 단계를 순서대로 실행합니다."""

    def __init__(self):
        self.clients = {k: ApiClient(s) for k, s in SPECS.items()}
        self.results = {}
        self.skipped = []

    def check_keys(self):
        print("=" * 72)
        print("                     API 준비 상태")
        print("=" * 72)

        for key, client in self.clients.items():
            spec = client.spec
            mark = "✓" if spec.available else "✗"
            note = "" if spec.available else f"  ← .env 에 {spec.key_env} 추가 필요"
            print(f"  {mark} {spec.name:<22}{spec.key_env:<20}{note}")

        print("=" * 72)
        return all(c.spec.available for c in self.clients.values())

    def step(self, name, api, func, required=False):
        """
        수집 단계 하나를 실행합니다.

        required : True 면 실패 시 파이프라인 전체 중단
        """
        client = self.clients[api]

        if not client.spec.available:
            log.warning(f"[{name}] 건너뜀 — 인증키 없음")
            self.skipped.append((name, "인증키 없음"))
            return None

        cache = RAW / f"step_{name}.json"

        if cache.exists():
            data = json.loads(cache.read_text(encoding="utf-8"))
            log.info(f"[{name}] 캐시 사용 ({len(data)}건)")
            self.results[name] = data
            return data

        log.info(f"[{name}] 실행")

        try:
            data = func(client, self.results)
        except Exception as e:
            log.error(f"[{name}] 실패: {type(e).__name__}: {e}")
            client.errors.append({"step": name, "reason": str(e)})
            self.skipped.append((name, str(e)))

            if required:
                raise RuntimeError(f"필수 단계 '{name}' 실패 — 중단")
            return None

        cache.write_text(json.dumps(data, ensure_ascii=False),
                         encoding="utf-8")
        self.results[name] = data
        log.info(f"[{name}] {len(data)}건 완료")

        return data

    def report(self):
        print("\n" + "=" * 72)
        print("                     파이프라인 결과")
        print("=" * 72)

        print(f"\n  [단계별]")
        for name, data in self.results.items():
            print(f"    ✓ {name:<24}{len(data):>8,}건")

        for name, reason in self.skipped:
            print(f"    ✗ {name:<24}{reason}")

        print(f"\n  [API 사용량]")
        for client in self.clients.values():
            print(f"    {client.report()}")

        print("=" * 72)

    def close(self):
        for c in self.clients.values():
            c.close()


# ══════════ 사용 ══════════
if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO, format="%(message)s")

    pipe = Pipeline()
    pipe.check_keys()

    # ── 단계 1: 관광지 목록 (필수) ──
    def collect_spots(client, prev):

## 오늘의 정리

| 개념 | 핵심 |
|---|---|
| API vs 크롤링 | **API가 있으면 무조건 API** |
| REST | URL = 자원 · 메서드 = 동작 · **수집은 GET만** |
| 인증키 관리 | **`.env` + `.gitignore`** — 코드에 절대 금지 |
| Encoding/Decoding | **`params` 에는 Decoding 키** |
| 필수 파라미터 | `_type=json` · `MobileOS` · `MobileApp` |
| 성공 판정 | HTTP 200 ≠ 성공 → **`resultCode` 확인** |
| `items` 함정 | 0건이면 `""`, 1건이면 **dict** |
| 페이지 계산 | `ceil(totalCount / numOfRows)` |
| 한도 | 개발계정 **일 1,000회** · `numOfRows` 키워 요청 수 줄이기 |
| 원본 보존 | `data/raw/*.json` — 파싱은 다시 할 수 있게 |
| 좌표 | API는 **문자열**로 줌 → `to_numeric` 필수 |
| 중첩 JSON | **`pd.json_normalize`** |

**오늘 반드시 기억할 세 가지**
> ① **인증키는 `.env` 에.** 한 번 GitHub에 올라가면 폐기 말고는 방법이 없습니다.
> ② **HTTP 200이 성공이 아닙니다.** `resultCode` 를 반드시 확인하세요.
> ③ **응답 원본을 저장하세요.** 한도를 다 쓰고 파싱 오류를 발견하면 내일까지 기다립니다.
