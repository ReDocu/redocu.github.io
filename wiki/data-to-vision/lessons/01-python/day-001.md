## ② 왜 필요한가

요리를 배우러 왔는데 주방에 칼도 도마도 없다면 첫날부터 아무것도 못 합니다.
오늘 하는 일이 정확히 그 **주방 정리**입니다.

앞으로 179일 동안 여러분은 매일 코드를 씁니다. 그런데 환경이 어긋나 있으면 이런 일이 벌어집니다.

| 환경 문제 | 실제로 겪게 되는 일 |
|---|---|
| 파이썬이 PATH에 없음 | 터미널에서 `python`을 쳐도 "명령을 찾을 수 없습니다" |
| 가상환경을 안 씀 | 다음 달에 pygame을 설치했더니 다른 프로젝트가 망가짐 |
| Git을 안 씀 | 잘 돌던 코드를 고치다 망쳤는데 되돌릴 방법이 없음 |

특히 **가상환경**은 처음엔 귀찮게 느껴지지만, 대단원 03에서 TensorFlow를 설치할 때 이걸 안 해두면 반드시 사고가 납니다.
지금 10분 투자하면 나중에 하루를 아낍니다.

## ③ 개념 설명

### 파이썬은 무엇인가

**파이썬(Python)** 은 프로그래밍 언어입니다. 사람이 읽기 쉬운 문법으로 컴퓨터에게 명령을 내립니다.

우리가 `.py` 파일에 쓴 글자를 컴퓨터가 바로 이해하지는 못합니다. 중간에서 통역해 주는 프로그램이 필요한데, 그게 **인터프리터(interpreter)** 입니다. 파이썬을 "설치한다"는 건 이 통역사를 내 컴퓨터에 들여놓는다는 뜻입니다.

```
[내가 쓴 hello.py]  →  [파이썬 인터프리터]  →  [컴퓨터가 실행]
```

### 에디터와 IDE

| 용어 | 뜻 | 예 |
|---|---|---|
| **에디터(editor)** | 글자를 쓰는 프로그램 | 메모장 |
| **IDE** | 에디터 + 실행 + 디버깅 + 자동완성을 합친 통합 도구 | PyCharm |
| **VS Code** | 에디터인데 확장을 붙이면 IDE처럼 쓸 수 있음 | 우리가 쓸 것 |

우리는 **VS Code**를 씁니다. 가볍고, 무료이고, 나중에 HTML·JavaScript까지 같은 화면에서 다룰 수 있기 때문입니다.

### 가상환경 (virtual environment)

프로젝트마다 필요한 도구(패키지)가 다릅니다. 게임 프로젝트엔 pygame이, 데이터 분석엔 pandas가 필요하죠.

이걸 전부 한 곳에 설치하면 **버전 충돌**이 납니다.
A 프로젝트는 pandas 1.5가 필요한데 B 프로젝트가 pandas 2.0을 깔아 버리면, A가 갑자기 안 돌아갑니다.

**가상환경 = 프로젝트 전용 도구상자**입니다.

```
내 컴퓨터
├── 게임프로젝트/
│   └── venv/          ← 여기엔 pygame만
└── 분석프로젝트/
    └── venv/          ← 여기엔 pandas만
```

서로 간섭하지 않으니 마음 놓고 설치할 수 있습니다.

### pip

**pip**는 파이썬 패키지를 설치해 주는 도구입니다. 앱스토어라고 생각하면 됩니다.
`pip install pygame` 이라고 치면 인터넷에서 pygame을 받아 지금 활성화된 가상환경에 넣어 줍니다.

### Git과 GitHub

| 용어 | 뜻 |
|---|---|
| **Git** | 내 컴퓨터에서 코드 변경 이력을 기록하는 프로그램 |
| **GitHub** | 그 기록을 인터넷에 올려 두는 웹사이트 |
| **커밋(commit)** | "여기까지의 상태를 저장" 하는 행위. 게임의 세이브 포인트 |
| **푸시(push)** | 내 컴퓨터의 커밋을 GitHub로 올리는 것 |

36주 뒤 여러분의 GitHub는 **포트폴리오 그 자체**가 됩니다. 오늘부터 매일 커밋합니다.

## ④ 단계별 실습

### Step 1. 파이썬 설치와 확인

1. <https://www.python.org/downloads/> 에서 **Python 3.11.x** 를 내려받습니다.
2. 설치 화면 맨 아래 **`Add python.exe to PATH`** 를 반드시 체크합니다. (이걸 놓치면 ⑤번 첫 번째 에러가 납니다)
3. `Install Now` 를 누릅니다.

설치가 끝나면 터미널(PowerShell)을 열어 확인합니다.

```powershell
python --version
```

실행 결과:

```
Python 3.11.9
```

버전 숫자가 보이면 성공입니다.

### Step 2. VS Code 설치와 설정

1. <https://code.visualstudio.com/> 에서 내려받아 설치합니다.
2. 왼쪽 확장(Extensions, `Ctrl+Shift+X`) 아이콘을 누르고 아래 두 개를 설치합니다.
   - **Python** (Microsoft 제작)
   - **Korean Language Pack** (메뉴를 한글로 보고 싶다면)

### Step 3. 첫 프로그램 실행하기

작업 폴더를 하나 만듭니다. 예: `C:\workspace\mbc-python`

VS Code에서 `파일 > 폴더 열기`로 그 폴더를 엽니다. 그리고 `hello.py` 파일을 만들어 아래를 입력합니다.

```python
# 화면에 글자를 출력합니다
print("안녕하세요, 파이썬!")
print("오늘은 Day 001 입니다.")
```

`Ctrl + F5` 또는 오른쪽 위 ▶ 버튼으로 실행합니다.

실행 결과:

```
안녕하세요, 파이썬!
오늘은 Day 001 입니다.
```

> `print()` 는 괄호 안의 내용을 화면에 보여 주는 명령입니다. 앞으로 가장 많이 쓰게 될 함수입니다.

### Step 4. 가상환경 만들기

VS Code 터미널(`Ctrl + Shift + ~`)에서 아래를 순서대로 실행합니다.

```powershell
# 1. venv 라는 이름의 가상환경을 만듭니다
python -m venv venv

# 2. 가상환경을 켭니다 (활성화)
.\venv\Scripts\Activate.ps1
```

실행 결과 — 프롬프트 앞에 `(venv)` 가 붙으면 성공입니다.

```
(venv) PS C:\workspace\mbc-python>
```

> **활성화(activate)** 는 "지금부터 이 도구상자를 쓰겠다"는 선언입니다.
> 터미널을 새로 열 때마다 다시 활성화해야 합니다.

끌 때는 `deactivate` 를 입력합니다.

### Step 5. pip로 패키지 설치해 보기

가상환경이 켜진 상태에서 실행합니다.

```powershell
pip install pygame
pip list
```

실행 결과:

```
Package    Version
---------- -------
pip        24.0
pygame     2.6.1
setuptools 65.5.0
```

목록에 `pygame` 이 보이면 성공입니다. W04에서 이걸로 게임을 만듭니다.

설치한 패키지 목록을 파일로 남겨 둡니다. 다른 컴퓨터에서 똑같은 환경을 재현할 때 씁니다.

```powershell
pip freeze > requirements.txt
```

### Step 6. Git 저장소 만들고 GitHub에 올리기

먼저 <https://github.com> 에서 계정을 만들고, `mbc-python` 이라는 이름의 **빈 저장소**를 생성합니다.

그다음 VS Code 터미널에서:

```powershell
# 처음 한 번만: 내 정보 등록
git config --global user.name "홍길동"
git config --global user.email "hong@example.com"

# 이 폴더를 Git 저장소로 만듭니다
git init

# 가상환경 폴더는 올리지 않습니다 (용량이 크고 컴퓨터마다 다름)
echo "venv/" > .gitignore

# 모든 변경사항을 담고, 저장 지점을 만듭니다
git add .
git commit -m "Day 001: 개발 환경 구축"

# GitHub 저장소와 연결하고 올립니다
git remote add origin https://github.com/사용자명/mbc-python.git
git branch -M main
git push -u origin main
```

실행 결과:

```
Enumerating objects: 4, done.
Writing objects: 100% (4/4), 320 bytes | 320.00 KiB/s, done.
To https://github.com/사용자명/mbc-python.git
 * [new branch]      main -> main
```

브라우저에서 내 저장소를 새로고침해 `hello.py` 가 보이면 성공입니다. **오늘의 목표 달성입니다.**

## ⑤ 자주 하는 실수

### `'python'은(는) 내부 또는 외부 명령... 이 아닙니다`

```
'python'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는
배치 파일이 아닙니다.
```

**원인** — 설치할 때 `Add python.exe to PATH` 를 체크하지 않았습니다. 컴퓨터가 파이썬이 어디 있는지 모릅니다.
**해결** — 파이썬 설치 파일을 다시 실행 → `Modify` → `Next` → **`Add Python to environment variables`** 체크 → `Install`. 그 후 터미널을 **새로 열어서** 확인합니다.

### `이 시스템에서 스크립트를 실행할 수 없으므로...`

```
.\venv\Scripts\Activate.ps1 : 이 시스템에서 스크립트를 실행할 수 없으므로
C:\workspace\...\Activate.ps1 파일을 로드할 수 없습니다.
```

**원인** — Windows PowerShell의 보안 정책이 스크립트 실행을 막고 있습니다.
**해결** — PowerShell에서 아래를 한 번 실행합니다.

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

`Y` 를 눌러 승인한 뒤 다시 활성화를 시도합니다.

### `ModuleNotFoundError: No module named 'pygame'`

```
Traceback (most recent call last):
  File "game.py", line 1, in <module>
    import pygame
ModuleNotFoundError: No module named 'pygame'
```

**원인** — 가상환경을 활성화하지 않은 상태에서 실행했거나, VS Code가 다른 파이썬을 쓰고 있습니다.
**해결** — ① 터미널 프롬프트에 `(venv)` 가 있는지 확인 ② VS Code에서 `Ctrl+Shift+P` → `Python: Select Interpreter` → `venv` 가 붙은 항목 선택.

### 한글이 깨져서 나옵니다

```
����ϼ���, ���̽�!
```

**원인** — 터미널의 문자 인코딩이 UTF-8이 아닙니다.
**해결** — 파일을 저장할 때 VS Code 오른쪽 아래 인코딩이 `UTF-8` 인지 확인합니다. 그래도 안 되면 터미널에서 `chcp 65001` 을 실행합니다.

## ⑥ 확인 문제

**1.** 가상환경을 쓰지 않고 모든 패키지를 한 곳에 설치하면 어떤 문제가 생길 수 있나요?

<details>
<summary>답 보기</summary>

프로젝트마다 필요한 패키지 버전이 다를 때 **버전 충돌**이 납니다.
예를 들어 A 프로젝트가 `pandas 1.5`를 쓰는데 B 프로젝트를 만들면서 `pandas 2.0`으로 덮어쓰면, A 프로젝트의 코드가 갑자기 에러를 냅니다.
가상환경은 프로젝트별로 도구상자를 분리해 이 충돌을 막습니다.
</details>

**2.** 터미널에 `(venv)` 가 보이지 않는 상태에서 `pip install pandas` 를 실행하면 어디에 설치될까요?

<details>
<summary>답 보기</summary>

가상환경이 아니라 **컴퓨터 전체(전역)** 파이썬에 설치됩니다.
그러면 그 프로젝트의 `requirements.txt` 에는 잡히지 않고, 다른 사람이 내 코드를 받아 실행하면 "왜 나는 안 되지?" 하는 상황이 생깁니다.
설치 전에 항상 `(venv)` 를 확인하는 습관을 들이세요.
</details>

**3.** `.gitignore` 파일에 `venv/` 를 적는 이유는 무엇인가요?

<details>
<summary>답 보기</summary>

가상환경 폴더는 ① 용량이 수백 MB로 크고 ② 운영체제·파이썬 버전마다 내용이 달라서 다른 컴퓨터에서 그대로 쓸 수 없기 때문입니다.
대신 `requirements.txt` 만 올려 두면, 받는 사람이 `pip install -r requirements.txt` 한 줄로 같은 환경을 재현할 수 있습니다.
</details>

## 오늘의 정리

| 명령 | 하는 일 |
|---|---|
| `python --version` | 파이썬 설치 확인 |
| `python -m venv venv` | 가상환경 생성 |
| `.\venv\Scripts\Activate.ps1` | 가상환경 활성화 |
| `pip install 패키지명` | 패키지 설치 |
| `pip freeze > requirements.txt` | 설치 목록 저장 |
| `git add .` → `git commit -m "메시지"` → `git push` | 코드 저장하고 GitHub에 올리기 |

**과제** — 자기소개를 출력하는 프로그램(`intro.py`)을 `print()` 만 사용해 만들고 GitHub에 커밋하세요.
