## ② 왜 필요한가

어제는 "어떻게 그리는가"를 배웠습니다. 오늘은 **"무엇으로 그리는가"** 입니다.

같은 데이터를 파이차트와 막대그래프로 그려 봅시다.

```
파이차트                          막대그래프
                                  A ████████████████ 24%
    ╭─────╮                       B ███████████████  23%
   ╱  A  ╲                        C ██████████████   22%
  │ D   B │                       D █████████████    21%
   ╲  C  ╱                        E ██████            10%
    ╰─────╯
```

**파이차트에서 A와 B 중 뭐가 큰지 보이나요?**
막대에서는 **1초**면 압니다. 사람은 **각도보다 길이를 훨씬 정확하게** 비교합니다.

> **차트 선택은 취향이 아닙니다.**
> 잘못 고르면 **읽는 사람이 잘못된 결론을 내립니다.**
> 그리고 그 책임은 그린 사람에게 있습니다.

## 1부 · 목적 → 차트

### 핵심 표 — 이것만 외우면 됩니다

| 알고 싶은 것 | 질문 예시 | 차트 |
|---|---|---|
| **비교** | 어느 지역이 많은가 | **막대(bar)** |
| **추세** | 시간에 따라 어떻게 변했나 | **선(line)** |
| **관계** | 가격이 오르면 평점도 오르나 | **산점도(scatter)** |
| **분포** | 값이 어디에 몰려 있나 | **히스토그램 / 박스플롯** |
| **구성** | 전체 중 비중이 어떤가 | 막대 (파이는 신중히) |
| **순위** | 상위 10개는? | **가로 막대(barh)** |

### 비교 — 막대그래프

```python
ax.bar(x, y)                          # 세로
ax.barh(y_labels, values)             # 가로 ⭐ 라벨이 길 때
```

**언제 가로 막대인가**

| 상황 | 방향 |
|---|---|
| 라벨이 길다 (`"서울특별시 종로구"`) | **가로** |
| 항목이 8개 이상 | **가로** |
| 순위를 보여 준다 | **가로** |
| 시간 순서가 있다 | 세로 |

```python
# 순위는 정렬 + 가로 막대
top10 = df.nlargest(10, "visitors").sort_values("visitors")   # 오름차순 ⭐
ax.barh(top10["name"], top10["visitors"])
```

> **`barh` 는 아래부터 그려집니다.** 1위를 맨 위에 두려면 **오름차순** 정렬하세요.

**막대의 철칙**

```python
ax.set_ylim(0, None)         # ⭐ 반드시 0부터
```

> ⚠️ **막대의 길이가 곧 값입니다.** 0부터 시작하지 않으면 **길이 비율이 거짓**이 됩니다.
> (선그래프는 "변화"를 보므로 0부터가 아니어도 되는 경우가 있습니다)

### 추세 — 선그래프

```python
ax.plot(x, y)
ax.fill_between(x, y, alpha=0.2)      # 아래를 채워 강조
```

**선그래프의 조건 — x축에 순서가 있어야 합니다**

```python
ax.plot(["서울", "부산", "제주"], [100, 80, 60])     # ❌ 의미 없음
```

지역 사이를 잇는 선은 **아무 뜻이 없습니다.** 이건 막대여야 합니다.

| x축 | 선그래프 |
|---|---|
| 날짜·시간 | ✅ |
| 나이·온도 등 연속값 | ✅ |
| 지역·카테고리 | ❌ **막대** |

### 관계 — 산점도

```python
ax.scatter(x, y, s=크기, c=색, alpha=0.5)
```

```python
ax.scatter(df["price"], df["rating"],
           s=df["review_count"] / 20,     # 점 크기 = 세 번째 변수
           c=df["area_code"],             # 점 색 = 네 번째 변수
           cmap="viridis", alpha=0.6, edgecolors="white")
```

**추세선 추가**

```python
import numpy as np

coef = np.polyfit(x, y, 1)                # 1차 회귀
ax.plot(x, np.poly1d(coef)(x), "--", color="red", label="추세선")

corr = np.corrcoef(x, y)[0, 1]
ax.text(0.02, 0.95, f"r = {corr:.3f}", transform=ax.transAxes)
```

> ⚠️ **상관은 인과가 아닙니다.**
> "아이스크림 판매량과 익사 사고 수"의 상관계수는 매우 높습니다.
> **아이스크림이 익사를 일으키는 게 아니라 둘 다 여름에 늘어납니다.**
>
> 산점도에 추세선을 그으면 **인과처럼 보입니다.** 해석 문장에서 반드시 구분하세요.

**점이 겹칠 때 (overplotting)**

```python
ax.scatter(x, y, alpha=0.3)                       # 투명도
ax.scatter(x, y, s=8)                             # 작게
ax.hexbin(x, y, gridsize=30, cmap="Blues")        # 육각형 밀도 ⭐
```

### 분포 — 히스토그램

```python
ax.hist(values, bins=30, color="#2563eb", edgecolor="white")
ax.hist(values, bins=[0, 5000, 10000, 20000])     # 경계 직접 지정
ax.hist(values, density=True)                      # 비율로
```

**`bins` 개수가 결론을 바꿉니다**

```
bins=5                    bins=50
 ████                      ▌ ▌  ▌▌ ▌
 ████████                  ▌▌▌▌▌▌▌▌▌▌
 ████                      ▌▌ ▌▌ ▌ ▌
"봉우리 하나"              "봉우리 두 개"
```

| `bins` | 문제 |
|---|---|
| 너무 적음 | 세부 구조가 뭉개짐 |
| 너무 많음 | 노이즈가 패턴처럼 보임 |
| **적정** | `int(np.sqrt(n))` 또는 `"auto"` |

```python
ax.hist(values, bins="auto")          # matplotlib 이 자동 결정 ⭐
```

> **`bins` 를 바꿔 가며 2~3번 그려 보세요.**
> 어떤 값에서도 보이는 패턴만 **진짜 패턴**입니다.

### 분포 — 박스플롯

```python
ax.boxplot([group1, group2, group3], labels=["A", "B", "C"])
ax.boxplot(data, vert=False)                  # 가로
ax.boxplot(data, showmeans=True)              # 평균 표시
```

**읽는 법**

```
        Q1    중앙값   Q3
         │      │      │
    ├────┤██████│██████├────┤        ●    ●
    │    └──────┴──────┘    │
  하단             상단      이상치
  수염             수염
  (Q1-1.5IQR)   (Q3+1.5IQR)
```

| 요소 | 의미 |
|---|---|
| 상자 | **중간 50%** (Q1~Q3) |
| 상자 안 선 | **중앙값** |
| 수염 | 이상치가 아닌 범위 |
| 점 | **이상치** ([Day 057](day-057.md)) |

**박스플롯의 강점** — 여러 그룹의 분포를 **한눈에 비교**합니다.

```python
groups = [df[df["category"] == c]["price"] for c in categories]
ax.boxplot(groups, labels=categories)
```

**약점** — **봉우리가 두 개인 분포를 못 보여 줍니다.**

```
실제 분포        박스플롯
 ██    ██          ├──███──┤
 ██    ██          (하나의 덩어리처럼 보임)
```

> **박스플롯과 히스토그램을 함께 보는 것**이 안전합니다.
> 또는 바이올린 플롯 ([Day 063](day-063.md))

### 구성 — 파이차트는 신중히

```python
ax.pie(sizes, labels=labels, autopct="%1.1f%%")
```

**파이차트를 써도 되는 조건 3가지**

| 조건 | 이유 |
|---|---|
| 항목이 **5개 이하** | 많으면 구분 불가 |
| 비율 차이가 **뚜렷** | 24% vs 23% 는 각도로 구분 못 함 |
| 합이 **100%** | 부분의 합이 전체여야 함 |

**하나라도 안 맞으면 막대그래프**입니다.

```python
# ❌ 파이
ax.pie([24, 23, 22, 21, 10])

# ✅ 가로 막대 + 비율 라벨
pct = values / values.sum() * 100
bars = ax.barh(labels, pct)
for bar, p in zip(bars, pct):
    ax.text(p + 0.5, bar.get_y() + bar.get_height() / 2,
            f"{p:.1f}%", va="center")
```

> ⚠️ **3D 파이차트는 절대 쓰지 마세요.**
> 원근 때문에 **앞쪽 조각이 실제보다 커 보입니다.**
> 같은 20%인데 앞에 있으면 30%처럼 보입니다. **거짓말하는 그래프**입니다.

### ① y축 절단 — 가장 흔한 왜곡

```
y축 0부터                    y축 100부터
                              
 110┤ █ █ █                   110┤     █
    │ █ █ █                      │   █ █
  55┤ █ █ █                   105┤ █ █ █
    │ █ █ █                      │ █ █ █
   0└─────────                100└─────────
   102 105 108                  102 105 108
   "거의 같다"                  "3배 차이!"
```

**실제 차이는 6%** 인데 오른쪽은 **엄청난 차이**로 보입니다.

| 차트 | y축 0 시작 |
|---|---|
| **막대** | **필수** — 길이가 값이므로 |
| 선 (추세) | 선택 — 변화를 보는 것이므로 |
| 산점도 | 선택 |

### ② 이중 축 (twinx)

```python
ax2 = ax.twinx()
```

```
매출과 광고비를 이중 축으로     →  "완벽하게 같이 움직인다!"

```

**대안**

```python
# 정규화해서 같은 축에
normalized = (series - series.min()) / (series.max() - series.min())

# 또는 증감률로
pct = series.pct_change() * 100

# 또는 위아래 서브플롯으로 (sharex=True)
fig, (ax1, ax2) = plt.subplots(2, 1, sharex=True)
```

### ③ 면적·부피로 크기 표현

```
값이 2배인데 원의 반지름을 2배로 → 면적은 4배 → 4배로 보임
```

```python
# ❌ 반지름에 값을 직접
ax.scatter(x, y, s=values)

# ✅ 면적이 값에 비례하도록 (s 는 면적 단위)
ax.scatter(x, y, s=values / values.max() * 300)
```

> matplotlib 의 `s` 는 **면적**(points²)이라 그나마 낫습니다.
> 직접 원을 그릴 때는 **반지름 = √값** 으로 해야 합니다.

### ④ 체리피킹 — 유리한 기간만

```
전체 10년: 하락 추세
최근 3개월만 잘라서: 상승 추세  →  "회복 중입니다!"
```

**대응** — 전체 기간을 함께 보여 주거나, 왜 그 기간인지 밝힙니다.

### ⑤ 누적 막대의 함정

```
누적 막대에서 맨 아래 계열만 비교하기 쉽습니다.
가운데 계열은 시작점이 제각각이라 비교가 거의 불가능합니다.
```

**대안** — 비교가 목적이면 **그룹 막대**를, 총량이 목적이면 누적을.

### ⑥ 평균 하나로 요약

```
"평균 연봉 8,000만원"    ← 대표 1명이 50억, 나머지 99명이 3,000만원
```

**대안** — 중앙값을 함께, 또는 **분포 자체를 보여 주기** (히스토그램·박스플롯).

### ⑦ 색으로 유도

```
우리 회사 = 선명한 파랑,  경쟁사 = 흐린 회색
```

강조 자체는 정당하지만, **데이터가 아니라 색이 결론을 만들면** 왜곡입니다.

## ④ 단계별 실습

### Step 1. 같은 데이터, 5가지 차트

```python
"""하나의 데이터를 5종 차트로 그려 비교합니다."""

import platform

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from pathlib import Path

plt.style.use("seaborn-v0_8-whitegrid")
plt.rcParams["font.family"] = ("Malgun Gothic" if platform.system() == "Windows"
                               else "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False

OUT = Path("output")
OUT.mkdir(exist_ok=True)

# ── 실습 데이터 ──
rng = np.random.default_rng(42)
N = 400

df = pd.DataFrame({
    "category": rng.choice(["자연", "역사", "체험", "쇼핑", "음식"], N,
                           p=[0.30, 0.24, 0.20, 0.14, 0.12]),
    "price": np.concatenate([
        np.zeros(90),
        rng.lognormal(8.6, 0.65, N - 90).round(-2)]),
    "rating": rng.normal(4.0, 0.5, N).round(1).clip(1, 5),
    "visitors": rng.lognormal(8.4, 1.1, N).round(),
    "month": rng.integers(1, 13, N),
})
df = df.sample(frac=1, random_state=1).reset_index(drop=True)

# 가격이 높을수록 평점이 약간 높게 (상관 만들기)
df["rating"] = (df["rating"] + df["price"] / 60000).round(1).clip(1, 5)

print("=" * 78)
print("                  같은 데이터, 5가지 차트")
print("=" * 78)

CHARTS = [
    ("① 막대", "비교", "어느 카테고리가 많은가"),
    ("② 선", "추세", "월별로 어떻게 변하는가"),
    ("③ 산점도", "관계", "가격과 평점은 관련이 있는가"),
    ("④ 히스토그램", "분포", "가격이 어디에 몰려 있는가"),
    ("⑤ 박스플롯", "분포 비교", "카테고리마다 가격 분포가 다른가"),
]

print(f"\n  {'차트':<14}{'목적':<12}{'답하는 질문'}")
print("  " + "-" * 62)
for name, purpose, question in CHARTS:
    print(f"  {name:<14}{purpose:<12}{question}")

# ══════════ ① 막대 — 비교 ══════════
fig, ax = plt.subplots(figsize=(9, 5.5))

counts = df["category"].value_counts()

bars = ax.bar(counts.index, counts.values,
              color="#2563eb", edgecolor="white", width=0.65)

for bar, v in zip(bars, counts.values):
    ax.text(bar.get_x() + bar.get_width() / 2, v + 3,
            f"{v}", ha="center", fontsize=10)

ax.set_title("카테고리별 관광지 수", pad=14)
ax.set_xlabel("카테고리")
ax.set_ylabel("개수 (곳)")
ax.set_ylim(0, counts.max() * 1.15)

fig.savefig(OUT / "chart1_bar.png")
plt.close(fig)

print(f"\n[① 막대]")
print(f"  {counts.to_dict()}")
print(f"  → 자연이 가장 많고 음식이 가장 적음. 크기 차이가 명확")

# ══════════ ② 선 — 추세 ══════════
fig, ax = plt.subplots(figsize=(10, 5.5))

monthly = df.groupby("month").size()

ax.plot(monthly.index, monthly.values,
        color="#2563eb", linewidth=2.5,
        marker="o", markersize=7, markerfacecolor="white", markeredgewidth=2)

ax.fill_between(monthly.index, monthly.values, alpha=0.12, color="#2563eb")

ax.set_title("월별 등록 관광지 수", pad=14)
ax.set_xlabel("월")
ax.set_ylabel("개수 (곳)")
ax.set_xticks(range(1, 13))
ax.set_ylim(0, None)

fig.savefig(OUT / "chart2_line.png")
plt.close(fig)

print(f"\n[② 선]")
print(f"  최다 {monthly.idxmax()}월({monthly.max()}곳) · "
      f"최소 {monthly.idxmin()}월({monthly.min()}곳)")
print(f"  → x축에 순서(시간)가 있으므로 선이 의미를 가짐")

# ══════════ ③ 산점도 — 관계 ══════════
fig, ax = plt.subplots(figsize=(9, 6))

paid = df[df["price"] > 0]

sc = ax.scatter(paid["price"], paid["rating"],
                s=paid["visitors"] / 120,
                c=paid["visitors"], cmap="viridis",
                alpha=0.6, edgecolors="white", linewidths=0.5)

coef = np.polyfit(paid["price"], paid["rating"], 1)
xs = np.linspace(paid["price"].min(), paid["price"].max(), 50)
ax.plot(xs, np.poly1d(coef)(xs), "--", color="#ef4444",
        linewidth=2, label="추세선")

corr = paid["price"].corr(paid["rating"])
```

```python
    "line": {

        "when": "시간·연속값에 따른 변화",
        "rules": ["x축에 순서가 있어야 함", "y축 절단 시 명시"],
    },
    "scatter": {
        "name": "산점도", "api": "ax.scatter(x, y)",
        "when": "두 수치 변수의 관계",
        "rules": ["상관 ≠ 인과", "점이 겹치면 alpha 또는 hexbin"],
    },
    "hist": {
        "name": "히스토그램", "api": "ax.hist(values, bins=30)",
        "when": "한 변수의 분포",
        "rules": ["bins 를 2~3개 값으로 바꿔 확인", "치우침 여부 확인"],
    },
    "box": {
        "name": "박스플롯", "api": "ax.boxplot(groups)",
        "when": "그룹별 분포 비교",
        "rules": ["봉우리 2개는 못 잡음", "히스토그램과 함께 보기"],
    },
    "heatmap": {
        "name": "히트맵", "api": "sns.heatmap(pivot)",
        "when": "두 범주의 교차 집계 또는 상관행렬",
        "rules": ["발산형 컬러맵은 중앙값 고정", "값 라벨 표시 권장"],
    },
}


def recommend_chart(df, x=None, y=None, hue=None, purpose=None, verbose=True):
    """
    데이터 타입과 목적으로부터 차트를 추천합니다.

    purpose : 'compare' | 'trend' | 'relation' | 'distribution' | 'composition'
    """
    def kind_of(col):
        if col is None or col not in df.columns:
            return None
        s = df[col]
        if pd.api.types.is_datetime64_any_dtype(s):
            return "datetime"
        if pd.api.types.is_numeric_dtype(s):
            if s.nunique() <= 12 and (s.dropna() % 1 == 0).all():
                return "ordinal"          # 월, 등급 같은 정수 소범주
            return "numeric"
        return "category"

    kx, ky, kh = kind_of(x), kind_of(y), kind_of(hue)

    candidates = []

    # ── 규칙 기반 추천 ──
    if kx == "datetime" or (kx == "ordinal" and purpose in (None, "trend")):
        candidates.append(("line", "x축에 시간·순서가 있음"))
        candidates.append(("bar", "각 시점의 크기를 강조하려면"))

    elif kx == "category" and ky in ("numeric", None):
        n_cat = df[x].nunique()
        max_len = df[x].astype(str).str.len().max()

        if n_cat > 8 or max_len > 6:
            candidates.append(("barh", f"항목 {n_cat}개, 라벨 최대 {max_len}자"))
            candidates.append(("bar", "항목이 적다면"))
        else:
            candidates.append(("bar", f"항목 {n_cat}개로 세로 막대 적합"))

        if ky == "numeric":
            candidates.append(("box", "그룹별 분포까지 보려면"))

    elif kx == "numeric" and ky == "numeric":
        candidates.append(("scatter", "두 수치 변수의 관계"))
        n = len(df)
        if n > 3000:
            candidates.append(("heatmap", f"점 {n:,}개 — hexbin/2D 밀도 권장"))

    elif kx == "numeric" and y is None:
        candidates.append(("hist", "한 변수의 분포"))
        candidates.append(("box", "이상치를 확인하려면"))

    elif kx == "category" and ky == "category":
        candidates.append(("heatmap", "두 범주의 교차 집계"))
        candidates.append(("bar", "그룹 막대로도 가능"))

    if not candidates:
        candidates.append(("bar", "기본값"))

    # ── 출력 ──
    if verbose:
        print("=" * 80)
        print("                        차트 추천")
        print("=" * 80)

        print(f"\n  [입력]")
        print(f"    x    : {x}  ({kx})")
        print(f"    y    : {y}  ({ky})")
        print(f"    hue  : {hue}  ({kh})")
        print(f"    행수 : {len(df):,}")

        print(f"\n  [추천]")
        for i, (key, reason) in enumerate(candidates[:3], 1):
            g = CHART_GUIDE[key]
            mark = "★" if i == 1 else " "
            print(f"\n  {mark}{i}. {g['name']}  —  {reason}")
            print(f"      용도 : {g['when']}")
            print(f"      코드 : {g['api']}")
            print(f"      주의 : {' / '.join(g['rules'])}")

        # ── 데이터 특성 경고 ──
        warns = []

        for col in (x, y):
            if col and pd.api.types.is_numeric_dtype(df.get(col, pd.Series())):
                s = df[col].dropna()
                if len(s) > 3:
                    skew = s.skew()
                    if abs(skew) > 2:
                        warns.append(f"'{col}' 왜도 {skew:.1f} — "
                                     f"평균보다 중앙값, 로그 축 검토")

                    if s.min() >= 0 and s.max() / max(s[s > 0].min(), 1) > 1000:
                        warns.append(f"'{col}' 값 범위가 1000배 이상 — "
                                     f"로그 스케일 검토")

        if x and df.get(x) is not None and kind_of(x) == "category":
            n = df[x].nunique()
            if n > 15:
                warns.append(f"'{x}' 범주 {n}개 — 상위 N개만 표시 검토")

        if warns:
            print(f"\n  [데이터 특성 주의]")
            for w in warns:
                print(f"    ⚠ {w}")

        print("\n" + "=" * 80)

    return [c[0] for c in candidates]


# ══════════ 사용 ══════════
if __name__ == "__main__":
    print(">>> 케이스 1: 카테고리별 개수\n")
    recommend_chart(df, x="category")
```

> - **타입** — `datetime` / `numeric` / `ordinal` / `category`

> 이걸 그냥 `numeric` 으로 보면 산점도를 추천하게 됩니다.

## ⑤ 자주 하는 실수

### 막대그래프의 y축을 자름

```python
ax.set_ylim(100, 110)          # 6% 차이가 3배로 보임
```

**해결** — `ax.set_ylim(0, None)`

### 카테고리에 선그래프

```python
ax.plot(["서울", "부산", "제주"], values)
```

**해결** — `ax.bar(...)`

### 항목이 많은데 파이차트

```python
ax.pie(values)                  # 8조각 — 구분 불가
```

**해결** — 정렬된 가로 막대

### 3D 차트

**해결** — 쓰지 않습니다. 3D는 **읽기를 어렵게만** 합니다.

### 이중 축으로 관계를 주장

**해결** — 정규화 후 같은 축, 또는 산점도로 상관을 직접 보여 줍니다.

### 산점도에서 점이 뭉개짐

```python
ax.scatter(x, y)                # 5,000개 → 검은 덩어리
```

**해결** — `alpha=0.2`, `s=5`, 또는 `ax.hexbin(x, y)`

### `bins` 를 확인하지 않음

**해결** — 5, 30, 100 으로 바꿔 보고 **공통으로 보이는 패턴**만 신뢰합니다.

### 정렬하지 않은 순위 막대

```python
ax.barh(df["name"], df["visitors"])     # 뒤죽박죽
```

**해결** — `df.sort_values("visitors")` 후 그립니다.

### 치우친 분포에 평균만 보고

**해결** — 중앙값을 함께, 또는 히스토그램·박스플롯으로 분포를 보여 줍니다.

### 박스플롯만 보고 분포를 단정

봉우리가 2개여도 박스플롯은 하나로 보입니다.

**해결** — 히스토그램이나 바이올린 플롯을 함께 봅니다.

### 색으로 결론을 유도

**해결** — 강조는 하되, **강조하지 않은 것도 읽을 수 있게** 합니다.

### 누적 막대로 그룹 비교

**해결** — 비교가 목적이면 **그룹 막대**를 씁니다.

**판단 순서 3단계**

```
① 알고 싶은 것이 무엇인가?    비교 / 추세 / 관계 / 분포
       ↓

       ↓

```

> **⑥번(비중)에서 파이 대신 막대를 쓴 이유**

> **비율 라벨을 붙인 정렬 막대**가 언제나 더 정확하게 읽힙니다.

```python
"""그래프 왜곡 진단."""

import matplotlib.pyplot as plt
import numpy as np


def detect_distortion(fig, verbose=True):
    """
    그래프에서 오해를 부를 수 있는 요소를 찾습니다.

    반환: dict(risk_score, findings)
    """
    findings = []
    axes = fig.get_axes()
    line = "=" * 78

    if verbose:
        print(line)
        print("                      그래프 왜곡 진단")
        print(line)

    for i, ax in enumerate(axes):
        label = f"Axes[{i}]" if len(axes) > 1 else "Axes"
        found = []

        has_bars = len(ax.containers) > 0
        has_lines = len(ax.get_lines()) > 0
        ymin, ymax = ax.get_ylim()

        # ══════════ ① y축 절단 (막대) ══════════
        if has_bars and ymin > 0:
            # 실제 데이터 범위 추정
            heights = []
            for container in ax.containers:
                heights += [p.get_height() for p in container
                            if hasattr(p, "get_height")]

            if heights:
                dmin, dmax = min(heights), max(heights)
                real_ratio = dmax / dmin if dmin > 0 else np.inf
                shown_ratio = ((dmax - ymin) / (dmin - ymin)
                               if dmin > ymin else np.inf)

                exaggeration = shown_ratio / real_ratio if real_ratio else 1

                found.append((
                    "높음",
                    f"막대 y축이 {ymin:,.0f} 부터 시작 — "
                    f"실제 {real_ratio:.2f}배 차이가 "
                    f"{shown_ratio:.1f}배로 보임 (약 {exaggeration:.0f}배 과장)",
                    "ax.set_ylim(0, None)"))

        # ══════════ ② 이중 축 ══════════
        # 같은 위치에 Axes 가 겹쳐 있으면 twinx
        for other in axes:
            if other is ax:
                continue
            if (ax.get_position().bounds == other.get_position().bounds
                    and ax.get_ylabel() != other.get_ylabel()):
                found.append((
                    "높음",
                    "이중 축(twinx) 사용 — 눈금 조절로 관계를 조작할 수 있음",
                    "정규화 후 같은 축 / 증감률 / 위아래 서브플롯"))
                break

        # ══════════ ③ 카테고리에 선 ══════════
        if has_lines and not has_bars:
            labels = [t.get_text() for t in ax.get_xticklabels()]
            texty = [l for l in labels
                     if l and not l.replace(".", "").replace("-", "").isdigit()]

            if len(texty) >= 3 and len(texty) == len([l for l in labels if l]):
                found.append((
                    "중간",
                    f"x축이 범주형인데 선그래프 — "
                    f"'{texty[0]}'과 '{texty[1]}' 사이의 선은 의미가 없음",
                    "ax.bar() 로 변경"))

        # ══════════ ④ 로그 축 미표시 ══════════
        if ax.get_yscale() == "log" and "로그" not in ax.get_ylabel():
            found.append((
                "중간",
                "y축이 로그 스케일인데 라벨에 표시 없음 — 차이를 과소평가하게 됨",
                "ylabel 에 '(로그 스케일)' 추가"))

        # ══════════ ⑤ 파이 조각 과다 ══════════
        wedges = [p for p in ax.patches
                  if type(p).__name__ == "Wedge"]
        if len(wedges) > 5:
            found.append((
                "중간",
                f"파이 조각 {len(wedges)}개 — 각도로 구분하기 어려움",
                "정렬된 가로 막대(barh)로 변경"))

        # ══════════ ⑥ 3D ══════════
        if hasattr(ax, "get_zlim"):
            found.append((
                "높음",
                "3D 차트 — 원근 때문에 앞쪽이 크게 보임",
                "2D 차트로 변경"))

        # ══════════ ⑦ 산점도 과밀 ══════════
        for coll in ax.collections:
            offsets = getattr(coll, "get_offsets", lambda: [])()
            n = len(offsets) if offsets is not None else 0

            if n > 2000:
                alphas = coll.get_alpha()
                if alphas is None or (isinstance(alphas, float) and alphas > 0.6):
                    found.append((
                        "낮음",
                        f"산점도 점 {n:,}개인데 alpha 미설정 — 뭉개져서 밀도를 못 봄",
                        "alpha=0.2 또는 ax.hexbin()"))
                break

        # ══════════ ⑧ 데이터 대비 잉크 ══════════
        n_series = len(ax.get_lines()) + len(ax.containers)
        if n_series > 7:
            found.append((
                "낮음",
                f"계열 {n_series}개 — 색으로 구분하기 어려움",
                "상위 N개만 강조하고 나머지는 회색 처리"))

        if verbose:
            icon = ("🔴" if any(l == "높음" for l, _, _ in found)
                    else "🟡" if found else "✅")
            print(f"\n  {icon} [{label}]  "
                  f"{ax.get_title()[:36] or '(제목 없음)'}")

            if found:
                for level, msg, fix in found:
                    mark = {"높음": "🔴", "중간": "🟡", "낮음": "🔵"}[level]
                    print(f"     {mark} [{level}] {msg}")
                    print(f"        → {fix}")
            else:
                print(f"     왜곡 요소 없음")

        findings += [(label, l, m, f) for l, m, f in found]

    # ══════════ 점수 ══════════
    weights = {"높음": 30, "중간": 15, "낮음": 5}
    risk = min(100, sum(weights[l] for _, l, _, _ in findings))

    if verbose:
        print(f"\n{line}")
        grade = ("✅ 안전" if risk == 0
                 else "🟡 주의" if risk < 30
                 else "🔴 왜곡 위험 높음")
        print(f"  왜곡 위험도: {risk}/100   {grade}")
        print(line)

        if risk >= 30:
            print(f"\n  ⚠ 이 그래프는 읽는 사람에게 잘못된 인상을 줄 수 있습니다.")
            print(f"    발표·보고 전에 수정하세요.")
            print(line)

    return {"risk_score": risk, "findings": findings}


# ══════════ 사용 ══════════
if __name__ == "__main__":
    # 왜곡이 심한 그래프
    fig, ax = plt.subplots(figsize=(8, 5))
    ax.bar(["A", "B", "C"], [102, 105, 108], color="#ef4444")
    ax.set_ylim(100, 110)
    ax.set_title("분기별 매출 (억원)")
    ax.set_ylabel("매출")

    ax2 = ax.twinx()
    ax2.plot([0, 1, 2], [50, 55, 60], color="blue")
    ax2.set_ylabel("광고비")

    print(">>> 왜곡이 심한 그래프\n")
    detect_distortion(fig)
    plt.close(fig)
```

| # | 검사 | 위험 | 왜 |
|---|---|---|---|
| ① | **막대 y축 절단** | **높음** | **길이 = 값** 이 깨짐 ⭐ |
| ② | **이중 축** | **높음** | 관계를 임의로 만듦 |
| ③ | 카테고리에 선 | 중간 | 없는 연속성을 암시 |
| ④ | 로그 축 미표시 | 중간 | 차이를 과소평가 |
| ⑤ | 파이 조각 과다 | 중간 | 각도 비교 불가 |
| ⑥ | 3D | 높음 | 원근 왜곡 |
| ⑦ | 산점도 과밀 | 낮음 | 밀도를 못 봄 |
| ⑧ | 계열 과다 | 낮음 | 색 구분 불가 |

> **①번의 "과장 배수" 계산이 이 도구의 핵심입니다.**
>
> ```
> 실제 비율   = 108 / 102 = 1.06배
> 보이는 비율 = (108-100) / (102-100) = 4.0배
> 과장        = 4.0 / 1.06 ≈ 4배
> ```
>
> **"몇 배로 과장됐는지"를 숫자로 보여 주면** 반박하기 어렵습니다.
> "y축을 0부터 해야 한다"는 말보다 **"이 그래프는 4배 과장입니다"** 가 설득력 있습니다.

```
     기법      : y축 눈금을 각각 (99~110), (15~50)으로 맞춤
                 눈금만 바꾸면 '무관'하게도 보이게 만들 수 있음

==================================================================================
[✅ 정직한 그래프가 주는 인상]
==================================================================================

  ③ 우상단 — '전체 기간 + y축 0'
     보이는 것 : 3년간 거의 평평. 완만한 상승
     추가 정보 : 총 성장률을 숫자로 명시

  ④ 우하단 — '산점도'
     보이는 것 : 점들이 흩어져 있음 → 약한 관계
     추가 정보 : r, R², '상관 ≠ 인과' 경고를 함께 표시

==================================================================================
[체크리스트 — 그래프를 내보내기 전에]
==================================================================================
  1. □ 막대의 y축이 0부터 시작하는가
  2. □ 기간을 자의적으로 자르지 않았는가 (전체를 보여 줬는가)
  3. □ 이중 축 대신 정규화·산점도를 쓸 수 있는가
  4. □ 강조 색이 데이터가 아닌 결론을 만들고 있지 않은가
  5. □ 평균만 보여 주고 분포를 숨기지 않았는가
  6. □ 상관을 인과처럼 서술하지 않았는가
  7. □ 축 라벨에 단위가 있는가
  8. □ 이 그래프를 반대 입장인 사람이 봐도 공정하다고 할까
==================================================================================
```

**왜곡 기법 3가지가 결합될 때의 위력**

| 단독 | 효과 |
|---|---|
| y축 절단만 | 차이가 4배 과장 |
| 체리피킹만 | 정체가 상승으로 |
| 색·화살표만 | 시선 유도 |
| **셋 다** | **연 2.9% 성장이 "폭발적 성장"으로** |

> **각각은 "실수"라고 변명할 수 있지만, 세 개가 겹치면 의도입니다.**
>
> **체크리스트 8번이 가장 중요합니다.**
> "이 그래프를 반대 입장인 사람이 봐도 공정하다고 할까?"
>
> 기술적 규칙은 다 지켰는데도 **인상이 한쪽으로 기운다면**, 그건 아직 정직하지 않은 것입니다.
>
> **정직한 그래프의 목표는 "내 주장을 관철시키는 것"이 아니라 "읽는 사람이 스스로 판단할 수 있게 하는 것"입니다.**
</details>

## 오늘의 정리

| 목적 | 차트 | 핵심 주의 |
|---|---|---|
| **비교** | 막대 `bar` / `barh` | **y축 0부터** · 8개↑ 는 가로 |
| **추세** | 선 `plot` | x축에 **순서**가 있어야 |
| **관계** | 산점도 `scatter` | **상관 ≠ 인과** · 과밀 시 `alpha`/`hexbin` |
| **분포** | 히스토그램 `hist` | **`bins` 를 바꿔 확인** |
| **분포 비교** | 박스플롯 `boxplot` | 봉우리 2개는 못 잡음 |
| **구성** | 가로 막대 (파이 신중히) | 파이는 5개 이하 + 차이 뚜렷할 때만 |
| **교차** | 히트맵 | 두 범주의 집계 |

**오해를 부르는 그래프 7가지**

| # | 기법 | 대응 |
|---|---|---|
| ① | **y축 절단** | 막대는 반드시 0부터 |
| ② | **이중 축** | 정규화 / 산점도 |
| ③ | 면적·부피 왜곡 | 면적이 값에 비례하게 |
| ④ | **체리피킹** | 전체 기간 제시 |
| ⑤ | 누적 막대로 비교 | 그룹 막대 |
| ⑥ | **평균만 제시** | 중앙값 + 분포 |
| ⑦ | 색으로 유도 | 강조하되 나머지도 읽히게 |

**오늘 반드시 기억할 세 가지**
> ① **차트는 취향이 아니라 목적입니다.** "무엇을 알고 싶은가"부터 정하세요.
> ② **막대의 y축을 자르지 마세요.** 6% 차이가 4배로 보입니다.
> ③ **파이차트를 쓰기 전에 한 번 더 생각하세요.** 대부분은 정렬된 가로 막대가 낫습니다.

① 자기 데이터로 **5종 차트**를 각각 1개씩 그리고, 무엇을 알게 됐는지 한 문장씩
② **잘못된 그래프 1개를 찾아** (뉴스·보고서·논문 등) 캡처하고 문제점 지적
