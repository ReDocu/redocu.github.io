## ① 학습 목표

이 레슨을 마치면 이렇게 할 수 있습니다.

- 게임 상태(타이틀/플레이/일시정지/게임오버)를 관리하고 전환할 수 있다.

## ② 왜 필요한가

어제까지 만든 게임은 **실행하면 바로 시작하고, 죽으면 끝**입니다.
실제 게임에는 반드시 이런 흐름이 있습니다.

```
[타이틀] → [플레이] ⇄ [일시정지]
              ↓
          [게임오버] → [타이틀]
```

이걸 `if` 문 몇 개로 처리하려 하면 금세 이렇게 됩니다.

```python
if not started:
    ...
elif paused:
    ...
elif game_over:
    ...
elif showing_ranking:
    ...
```

플래그가 4개면 조합이 16가지입니다. **`paused` 와 `game_over` 가 동시에 True 면?**
관리가 불가능해집니다.

**해결은 "지금 상태는 딱 하나"라고 정하는 것**입니다.

```python
state = "TITLE"      # 이 값 하나가 현재 상태를 결정
```

그리고 **연출**은 게임의 완성도를 결정합니다.
같은 게임이라도 적이 터질 때 파편이 튀고 화면이 흔들리면 완전히 다르게 느껴집니다.

```python
            elif state == STATE_GAME_OVER and event.key == pygame.K_RETURN:
                state = STATE_TITLE

    # ── 갱신: PLAYING 일 때만 ──

        all_sprites.update()
        handle_collisions()
        if stats.is_game_over:
            state = STATE_GAME_OVER

    # ── 그리기: 상태마다 ──
    screen.fill(BG)

    if state == STATE_TITLE:
        draw_title(screen)
    else:
        all_sprites.draw(screen)
        draw_hud(screen)

        if state == STATE_PAUSED:
            draw_pause_overlay(screen)
        elif state == STATE_GAME_OVER:
            draw_game_over(screen)

    pygame.display.flip()
```

> **핵심 원칙 세 가지**
> ① 상태는 **항상 하나**입니다. 동시에 두 상태일 수 없습니다.
> ② `PAUSED` 일 때 **`update()` 는 멈추지만 `draw()` 는 계속** 돕니다. 그래서 화면이 유지됩니다.
> ③ 상태 전환은 **한 곳에서만** 일어나게 하면 추적이 쉽습니다.

### 파티클 이펙트

**파티클** = 짧게 살았다 사라지는 작은 조각입니다. 폭발·연기·불꽃을 표현합니다.

```python
class Particle(pygame.sprite.Sprite):
    """수명이 있는 작은 조각."""

    def __init__(self, x, y, color, speed=4.0, life=30, size=5):
        super().__init__()
        angle = random.uniform(0, math.tau)          # 0 ~ 2π
        speed = random.uniform(speed * 0.4, speed)

        self.vel_x = math.cos(angle) * speed
        self.vel_y = math.sin(angle) * speed

        self.pos_x, self.pos_y = float(x), float(y)
        self.life = life
        self.max_life = life
        self.base_size = size
        self.color = color

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        self.rect = self.image.get_rect(center=(x, y))
        self._redraw()

    def _redraw(self):
        """수명에 따라 크기와 투명도를 바꿔 다시 그립니다."""
        ratio = self.life / self.max_life
        size = max(int(self.base_size * ratio), 1)
        alpha = int(255 * ratio)

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (*self.color, alpha), (size, size), size)
        self.rect = self.image.get_rect(center=self.rect.center)

    def update(self):
        self.life -= 1
        if self.life <= 0:
            self.kill()
            return

        self.vel_y += 0.12                # 중력
        self.vel_x *= 0.98                # 공기 저항
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y

        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self._redraw()
```

**폭발 만들기**

```python
def make_explosion(x, y, color, count=18, groups=()):
    """파티클 여러 개로 폭발을 만듭니다."""
    for _ in range(count):
        p = Particle(x, y, color)
        for g in groups:
            g.add(p)
```

> **`(*self.color, alpha)`** — RGB 튜플을 풀어서 RGBA로 만듭니다. `(231, 76, 60)` + `alpha` → `(231, 76, 60, 200)`.

### 화면 흔들림 (screen shake)

타격감을 만드는 가장 쉬운 방법입니다.

```python
class ScreenShake:
    def __init__(self):
        self.timer = 0
        self.power = 0

    def shake(self, power=8, duration=12):
        """더 강한 흔들림이 요청되면 덮어씁니다."""
        if power >= self.power:
            self.power = power
            self.timer = duration

    def update(self):
        if self.timer > 0:
            self.timer -= 1
        else:
            self.power = 0

    @property
    def offset(self):
        """현재 흔들림 오프셋 (dx, dy)."""
        if self.timer <= 0:
            return 0, 0
        return (random.randint(-self.power, self.power),
                random.randint(-self.power, self.power))
```

**적용 방법 — 별도 Surface에 그리고 어긋나게 붙입니다.**

```python
game_surface = pygame.Surface((SCREEN_WIDTH, SCREEN_HEIGHT))

# 게임 내용을 game_surface 에 그림
game_surface.fill(BG)
all_sprites.draw(game_surface)

# 화면에 어긋나게 붙임
dx, dy = shaker.offset
screen.fill((0, 0, 0))
screen.blit(game_surface, (dx, dy))

# HUD 는 흔들리지 않게 screen 에 직접
draw_hud(screen, ...)
```

> **HUD는 흔들지 않는 것**이 보기 좋습니다. 점수가 떨리면 읽기 힘듭니다.

```python
def load_sound(path, volume=0.5):
    """사운드를 불러옵니다. 실패하면 None."""
    try:
        s = pygame.mixer.Sound(path)
        s.set_volume(volume)
        return s
    except (pygame.error, FileNotFoundError):
        print(f"[경고] 사운드를 불러올 수 없습니다: {path}")
        return None


def play(sound):
    """None 이어도 안전하게 재생합니다."""
    if sound is not None:
        sound.play()
```

### 애니메이션 — 프레임 전환

```python
class AnimatedSprite(pygame.sprite.Sprite):
    def __init__(self, frames, x, y, frame_delay=6):
        super().__init__()
        self.frames = frames              # Surface 리스트
        self.index = 0
        self.timer = 0
        self.frame_delay = frame_delay

        self.image = self.frames[0]
        self.rect = self.image.get_rect(center=(x, y))

    def update(self):
        self.timer += 1
        if self.timer >= self.frame_delay:
            self.timer = 0
            self.index = (self.index + 1) % len(self.frames)
            self.image = self.frames[self.index]
```

> `(self.index + 1) % len(self.frames)` — 마지막 프레임 다음에 0으로 돌아갑니다. [Day 003](day-003.md)의 나머지 연산입니다.
> 한 번만 재생하고 사라지게 하려면 `if self.index >= len(self.frames) - 1: self.kill()`.

### Step 1. 상태 관리 뼈대

`states_v1.py` 를 만들어 실행합니다.

```python
import pygame

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

BG = (18, 20, 30)
WHITE = (240, 240, 240)
YELLOW = (241, 196, 15)
RED = (231, 76, 60)
GRAY = (140, 145, 160)

# ── 상태 상수 ──
TITLE = "TITLE"
PLAYING = "PLAYING"
PAUSED = "PAUSED"
GAME_OVER = "GAME_OVER"

pygame.init()
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 025 - 상태 관리")
clock = pygame.time.Clock()

font = pygame.font.SysFont("malgungothic", 20)
big_font = pygame.font.SysFont("malgungothic", 52)
mid_font = pygame.font.SysFont("malgungothic", 28)

state = TITLE
score = 0
play_frames = 0
state_log = []


def change_state(new_state):
    """상태를 바꾸고 기록합니다."""
    global state
    state_log.append(f"{state} → {new_state}")
    if len(state_log) > 6:
        state_log.pop(0)
    state = new_state


def draw_center(surface, text, font, color, y_offset=0):
    t = font.render(text, True, color)
    surface.blit(t, t.get_rect(center=(SCREEN_WIDTH // 2,
                                       SCREEN_HEIGHT // 2 + y_offset)))


def draw_overlay(surface, alpha=170):
    o = pygame.Surface((SCREEN_WIDTH, SCREEN_HEIGHT), pygame.SRCALPHA)
    o.fill((0, 0, 0, alpha))
    surface.blit(o, (0, 0))


running = True
while running:
    # ══ ① 이벤트 — 상태별로 분기 ══
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False

            elif state == TITLE:
                if event.key == pygame.K_RETURN:
                    score = 0
                    play_frames = 0
                    change_state(PLAYING)

            elif state == PLAYING:
                if event.key == pygame.K_p:
                    change_state(PAUSED)
                elif event.key == pygame.K_g:
                    change_state(GAME_OVER)      # 테스트용 강제 종료

            elif state == PAUSED:
                if event.key == pygame.K_p:
                    change_state(PLAYING)
                elif event.key == pygame.K_q:
                    change_state(TITLE)

            elif state == GAME_OVER:
                if event.key == pygame.K_RETURN:
                    change_state(TITLE)

    # ══ ② 갱신 — PLAYING 일 때만 ══
    if state == PLAYING:
        play_frames += 1
        score += 1
        if play_frames > 15 * FPS:              # 15초 후 자동 종료
            change_state(GAME_OVER)

    # ══ ③ 그리기 ══
    screen.fill(BG)

    if state == TITLE:
        draw_center(screen, "SPACE SHOOTER", big_font, YELLOW, -60)
        draw_center(screen, "ENTER 를 눌러 시작", mid_font, WHITE, 20)
        draw_center(screen, "ESC = 종료", font, GRAY, 70)

    else:
        # 플레이 화면 (여기에 게임 객체를 그립니다)
        pygame.draw.rect(screen, (40, 44, 60), (50, 80, SCREEN_WIDTH - 100, 420), 2)
        screen.blit(font.render(f"SCORE {score:,}", True, WHITE), (60, 20))
        screen.blit(font.render(f"{play_frames // FPS}초", True, WHITE),
                    (SCREEN_WIDTH - 120, 20))
        draw_center(screen, "(게임 화면)", mid_font, (70, 74, 95), -30)

        if state == PAUSED:
            draw_overlay(screen)
            draw_center(screen, "PAUSED", big_font, YELLOW, -40)
            draw_center(screen, "P = 계속   Q = 타이틀로", font, WHITE, 30)

        elif state == GAME_OVER:
            draw_overlay(screen, 190)
            draw_center(screen, "GAME OVER", big_font, RED, -60)
            draw_center(screen, f"최종 점수 {score:,}", mid_font, WHITE, 10)
            draw_center(screen, "ENTER = 타이틀로", font, GRAY, 70)

    # ── 상태 전환 기록 (학습용) ──
    screen.blit(font.render(f"[현재 상태] {state}", True, YELLOW), (12, SCREEN_HEIGHT - 170))
    for i, log in enumerate(state_log):
        screen.blit(font.render(log, True, GRAY), (12, SCREEN_HEIGHT - 140 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

### Step 2. 파티클 이펙트와 화면 흔들림

```python
import pygame
import random
import math

SCREEN_WIDTH, SCREEN_HEIGHT = 800, 600
FPS = 60

BG = (18, 20, 30)
WHITE = (240, 240, 240)
COLORS = [(231, 76, 60), (241, 196, 15), (46, 204, 113),
          (52, 152, 219), (155, 89, 182)]


class Particle(pygame.sprite.Sprite):
    """수명이 있는 작은 조각."""

    def __init__(self, x, y, color, speed=5.0, life=35, size=6, gravity=0.12):
        super().__init__()
        angle = random.uniform(0, math.tau)
        spd = random.uniform(speed * 0.3, speed)

        self.vel_x = math.cos(angle) * spd
        self.vel_y = math.sin(angle) * spd
        self.pos_x, self.pos_y = float(x), float(y)

        self.life = life
        self.max_life = life
        self.base_size = size
        self.color = color
        self.gravity = gravity

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        self.rect = self.image.get_rect(center=(x, y))
        self._redraw()

    def _redraw(self):
        ratio = max(self.life / self.max_life, 0)
        size = max(int(self.base_size * ratio), 1)
        alpha = int(255 * ratio)

        self.image = pygame.Surface((size * 2, size * 2), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (*self.color, alpha), (size, size), size)
        self.rect = self.image.get_rect(center=self.rect.center)

    def update(self):
        self.life -= 1
        if self.life <= 0:
            self.kill()
            return

        self.vel_y += self.gravity
        self.vel_x *= 0.98
        self.pos_x += self.vel_x
        self.pos_y += self.vel_y

        self.rect.center = (int(self.pos_x), int(self.pos_y))
        self._redraw()


class ScreenShake:
    """화면 흔들림을 관리합니다."""

    def __init__(self):
        self.timer = 0
        self.power = 0

    def shake(self, power=8, duration=12):
        if power >= self.power:
            self.power = power
            self.timer = duration

    def update(self):
        if self.timer > 0:
            self.timer -= 1
        else:
            self.power = 0

    @property
    def offset(self):
        if self.timer <= 0:
            return 0, 0
        return (random.randint(-self.power, self.power),
                random.randint(-self.power, self.power))


def make_explosion(x, y, group, color=None, count=22, power=6.0):
    """폭발 파티클을 생성합니다."""
    c = color or random.choice(COLORS)
    for _ in range(count):
        group.add(Particle(x, y, c, speed=power,
                           life=random.randint(25, 45),
                           size=random.randint(4, 9)))

pygame.display.set_caption("Day 025 - 이펙트")

font = pygame.font.SysFont("malgungothic", 18)

# 게임 내용을 그릴 별도 Surface

particles = pygame.sprite.Group()
shaker = ScreenShake()

auto_explode = False
auto_timer = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_SPACE:
                # 화면 가운데에서 큰 폭발
                make_explosion(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2,
                               particles, count=60, power=10)
                shaker.shake(power=14, duration=20)
            elif event.key == pygame.K_a:
                auto_explode = not auto_explode
            elif event.key == pygame.K_c:
                particles.empty()

        elif event.type == pygame.MOUSEBUTTONDOWN:
            make_explosion(*event.pos, particles)
            shaker.shake(power=7, duration=10)

    # 자동 폭발
    if auto_explode:
        auto_timer += 1
        if auto_timer >= 20:
            auto_timer = 0
            x = random.randint(80, SCREEN_WIDTH - 80)
            y = random.randint(80, SCREEN_HEIGHT - 80)
            make_explosion(x, y, particles, count=16)

    particles.update()
    shaker.update()

    # ── 게임 내용은 game_surface 에 ──
    game_surface.fill(BG)

    for x in range(0, SCREEN_WIDTH + 1, 80):
        pygame.draw.line(game_surface, (34, 37, 50), (x, 0), (x, SCREEN_HEIGHT))
    for y in range(0, SCREEN_HEIGHT + 1, 80):
        pygame.draw.line(game_surface, (34, 37, 50), (0, y), (SCREEN_WIDTH, y))

    particles.draw(game_surface)

    # ── 흔들림을 적용해 화면에 붙임 ──
    dx, dy = shaker.offset
    screen.fill((0, 0, 0))
    screen.blit(game_surface, (dx, dy))

    # ── HUD 는 흔들리지 않게 screen 에 직접 ──
    info = [
        f"파티클: {len(particles)}개",
        f"흔들림: power {shaker.power}, timer {shaker.timer}",
        f"자동 폭발: {'ON' if auto_explode else 'OFF'}",
        f"FPS: {clock.get_fps():.0f}",
        "",
        "SPACE=대폭발   클릭=그 자리 폭발   A=자동   C=정리",
    ]
    for i, line in enumerate(info):
        screen.blit(font.render(line, True, WHITE), (12, 12 + i * 22))

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **`A` 를 눌러 자동 폭발을 켜고 파티클 개수와 FPS를 관찰하세요.**
> 파티클이 500개를 넘으면 FPS가 떨어지기 시작합니다. **개수 제한이 필요하다**는 것을 알 수 있습니다.
>
> **격자가 흔들리고 HUD는 고정**되는 것이 보입니다. 이것이 별도 Surface에 그리는 이유입니다.

### Step 3. 슈팅게임 통합 — W05 완성본 (오늘의 종합 예제)

W05에서 만든 모든 요소를 하나로 합칩니다.
(`Bullet`, `Enemy`, `TankEnemy`, `Player`, `GameStats` 는 [Day 024](day-024.md) Step 3의 것을 그대로 사용합니다)

```python
# ══════════ 사운드 (파일이 없어도 동작) ══════════
def load_sound(path, volume=0.4):
    try:
        s = pygame.mixer.Sound(path)
        s.set_volume(volume)
        return s
    except (pygame.error, FileNotFoundError):
        return None


def play(sound):
    if sound is not None:
        sound.play()


pygame.init()
pygame.mixer.init()

SND_SHOOT = load_sound("assets/shoot.wav", 0.2)
SND_HIT = load_sound("assets/hit.wav", 0.4)
SND_EXPLODE = load_sound("assets/explode.wav", 0.5)

# ══════════ 상태 ══════════
TITLE, PLAYING, PAUSED, GAME_OVER = "TITLE", "PLAYING", "PAUSED", "GAME_OVER"

screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Day 025 - 슈팅게임 W05 완성본")
clock = pygame.time.Clock()
game_surface = pygame.Surface((SCREEN_WIDTH, SCREEN_HEIGHT))

font = pygame.font.SysFont("malgungothic", 20)
small_font = pygame.font.SysFont("malgungothic", 15)
mid_font = pygame.font.SysFont("malgungothic", 30)
big_font = pygame.font.SysFont("malgungothic", 52)

shaker = ScreenShake()

state = TITLE
player = None
all_sprites = bullets = enemies = items = particles = None
stats = None
spawn_timer = item_timer = 0


def start_game():
    """게임 상태를 초기화합니다."""
    global player, all_sprites, bullets, enemies, items, particles
    global stats, spawn_timer, item_timer

    player = Player(SCREEN_WIDTH // 2, SCREEN_HEIGHT - 70)
    all_sprites = pygame.sprite.Group(player)
    bullets = pygame.sprite.Group()
    enemies = pygame.sprite.Group()
    items = pygame.sprite.Group()
    particles = pygame.sprite.Group()
    stats = GameStats(lives=3)
    spawn_timer = item_timer = 0


def draw_center(surface, text, f, color, dy=0):
    t = f.render(text, True, color)
    surface.blit(t, t.get_rect(center=(SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2 + dy)))


def draw_overlay(surface, alpha=170):
    o = pygame.Surface((SCREEN_WIDTH, SCREEN_HEIGHT), pygame.SRCALPHA)
    o.fill((0, 0, 0, alpha))
    surface.blit(o, (0, 0))


running = True
while running:
    # ══ ① 이벤트 ══
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False

            elif state == TITLE and event.key == pygame.K_RETURN:
                start_game()
                state = PLAYING

            elif state == PLAYING and event.key == pygame.K_p:
                state = PAUSED

            elif state == PAUSED:
                if event.key == pygame.K_p:
                    state = PLAYING
                elif event.key == pygame.K_q:
                    state = TITLE

            elif state == GAME_OVER and event.key == pygame.K_RETURN:
                state = TITLE

    # ══ ② 갱신 ══
    if state == PLAYING:
        spawn_timer += 1
        if spawn_timer >= 45:
            spawn_timer = 0
            cls = TankEnemy if random.random() < 0.25 else Enemy
            e = cls.spawn()
            all_sprites.add(e)
            enemies.add(e)

        item_timer += 1
        if item_timer >= 480:
            item_timer = 0
            it = HealItem.spawn()
            all_sprites.add(it)
            items.add(it)

        keys = pygame.key.get_pressed()
        player.handle_input(keys)

        if keys[pygame.K_SPACE]:
            b = player.shoot()
            if b:
                all_sprites.add(b)
                bullets.add(b)
                stats.shots += 1
                play(SND_SHOOT)

        all_sprites.update()
        particles.update()
        shaker.update()

        # ── 충돌 ① 총알 ↔ 적 ──
        hits = pygame.sprite.groupcollide(bullets, enemies, True, False)
        for bullet, enemy_list in hits.items():
            stats.hits += 1
            for enemy in enemy_list:
                if enemy.take_damage(bullet.damage):
                    stats.add_kill(enemy)
                    make_explosion(enemy.rect.centerx, enemy.rect.centery,
                                   particles, enemy.COLOR, count=20)
                    shaker.shake(power=5, duration=8)
                    play(SND_EXPLODE)
                else:
                    make_explosion(bullet.rect.centerx, bullet.rect.top,
                                   particles, (241, 196, 15), count=5, power=3)
                    play(SND_HIT)

        # ── 충돌 ② 플레이어 ↔ 적 ──
        hit_enemies = pygame.sprite.spritecollide(
            player, enemies, False, pygame.sprite.collide_circle)

        if hit_enemies and player.take_damage(25):
            make_explosion(player.rect.centerx, player.rect.centery,
                           particles, (231, 76, 60), count=14)
            shaker.shake(power=12, duration=16)
            play(SND_EXPLODE)

            if player.hp <= 0:
                if stats.lose_life():
                    state = GAME_OVER
                else:
                    player.revive()
                    shaker.shake(power=18, duration=24)
            else:
                stats.reset_combo()

        # ── 충돌 ③ 아이템 ──
        for it in pygame.sprite.spritecollide(player, items, True):
            player.hp += HealItem.HEAL
            stats.score += 20
            make_explosion(it.rect.centerx, it.rect.centery,
                           particles, (46, 204, 113), count=12, power=4)

    # ══ ③ 그리기 ══
    game_surface.fill(BG)

    if state == TITLE:
        draw_center(game_surface, "SPACE SHOOTER", big_font, (241, 196, 15), -80)
        draw_center(game_surface, "ENTER 를 눌러 시작", mid_font, WHITE, 10)
        draw_center(game_surface, "이동 = 방향키   발사 = SPACE   일시정지 = P",
                    small_font, (140, 145, 160), 70)
        draw_center(game_surface, "ESC = 종료", small_font, (140, 145, 160), 100)
    else:
        all_sprites.draw(game_surface)
        particles.draw(game_surface)
        for e in enemies:
            e.draw_hp_bar(game_surface)

    # 흔들림 적용
    dx, dy = shaker.offset
    screen.fill((0, 0, 0))
    screen.blit(game_surface, (dx, dy))

    # HUD (흔들리지 않음)
    if state != TITLE:
        draw_hud(screen, stats, player, font, small_font)

        if state == PAUSED:
            draw_overlay(screen)
            draw_center(screen, "PAUSED", big_font, (241, 196, 15), -40)
            draw_center(screen, "P = 계속   Q = 타이틀로", font, WHITE, 30)

        elif state == GAME_OVER:
            draw_overlay(screen, 190)
            draw_center(screen, "GAME OVER", big_font, (231, 76, 60), -90)
            for i, line in enumerate([
                f"최종 점수   {stats.score:,}",
                f"처치        {stats.kills}마리",
                f"최고 콤보   {stats.max_combo}",
                f"명중률      {stats.accuracy:.1f}%",
            ]):
                draw_center(screen, line, font, WHITE, -20 + i * 30)
            draw_center(screen, "ENTER = 타이틀로", small_font, (140, 145, 160), 120)

    pygame.display.flip()
    clock.tick(FPS)

pygame.quit()
```

> **눈여겨볼 점 6가지**
> - **`start_game()` 함수**가 초기화를 전담합니다. 타이틀에서 ENTER를 누를 때마다 깨끗한 상태로 시작합니다.
> - **적을 죽였을 때와 데미지만 줬을 때 이펙트가 다릅니다.** 작은 불꽃 vs 큰 폭발. 피드백이 명확해집니다.
> - **흔들림 강도를 상황별로 다르게** 줬습니다. 적 처치 5 / 피격 12 / 부활 18.
> - 사운드가 없어도 `play(None)` 이 조용히 넘어가므로 **파일 없이도 실행됩니다.**
> - `game_surface` 에 게임을, `screen` 에 HUD를 그려 **흔들림이 HUD에 영향을 주지 않습니다.**
> - 상태 전환이 **이벤트 처리 한 곳에서만** 일어납니다. (게임오버 전환만 갱신부에 있음)

## ⑤ 자주 하는 실수

### 상태를 여러 불리언 플래그로 관리

```python
paused = False
game_over = False
in_title = True
```

**문제** — `paused=True, game_over=True` 같은 불가능한 조합이 생깁니다.
**해결** — 문자열/상수 하나로 관리합니다. `state = PAUSED`

### 일시정지에서 `draw()` 까지 멈춤

```python
if state == PAUSED:
    continue          # 그리기도 건너뜀
```

**증상** — 화면이 검게 되거나 멈춘 것처럼 보입니다.
**해결** — **`update()` 만 건너뛰고 `draw()` 는 계속** 돌립니다.

### 파티클 개수 제한이 없음

**증상** — 폭발이 잦으면 파티클이 수천 개가 되어 FPS가 급락합니다.
**해결** — 상한을 둡니다.

```python
if len(particles) < 400:
    make_explosion(...)
```

### 파티클 수명 감소를 안 함

```python
def update(self):
    self.pos_x += self.vel_x       # life -= 1 이 없음
```

**증상** — 파티클이 영원히 남습니다.
**해결** — `self.life -= 1` 과 `if self.life <= 0: self.kill()` 을 반드시 넣습니다.

### 흔들림을 `screen` 에 직접 적용

```python
all_sprites.draw(screen)
screen.blit(screen, (dx, dy))     # 자기 자신에 붙임 — 동작 안 함
```

**해결** — 별도 `game_surface` 에 그린 뒤 `screen` 에 어긋나게 붙입니다.

### `pygame.mixer.init()` 을 안 함

```
pygame.error: mixer not initialized
```

**해결** — `pygame.init()` 다음에 `pygame.mixer.init()` 을 호출합니다.
(`pygame.init()` 이 mixer도 초기화하지만, 명시하는 편이 안전합니다)

### 사운드 파일이 없어서 프로그램이 죽음

```python
sound = pygame.mixer.Sound("assets/shoot.wav")
```

```
pygame.error: Unable to open file 'assets/shoot.wav'
```

**해결** — `try/except` 로 감싸고 `None` 을 반환합니다. 재생 시에도 `None` 검사를 합니다.

### 매 프레임 사운드를 재생

```python
if keys[pygame.K_SPACE]:
    shoot_sound.play()        # 1초에 60번 재생 → 소리가 뭉개짐
```

**해결** — 실제로 발사됐을 때만 재생합니다.

```python
b = player.shoot()
if b:
    play(SND_SHOOT)
```

### 상태 전환이 여러 곳에 흩어짐

**증상** — 어디서 상태가 바뀌었는지 추적 불가능.
**해결** — `change_state()` 함수를 만들어 한 곳을 거치게 하면 디버깅이 쉬워집니다.

## ⑥ 확인 문제

**1.** 일시정지 상태에서 `update()` 는 멈추고 `draw()` 는 계속 실행하는 이유를 설명하세요.

<details>
<summary>답 보기</summary>

**`draw()` 를 멈추면 화면이 유지되지 않기 때문입니다.**

게임 루프의 마지막에는 항상 `pygame.display.flip()` 이 있습니다.
그리기를 건너뛰면 화면 버퍼가 갱신되지 않아, 검은 화면이 되거나 이전 프레임 잔상이 남습니다.

```python
# ❌ 잘못된 방식
if state == PAUSED:
    continue                      # 그리기까지 건너뜀 → 화면 이상

# ✅ 올바른 방식
if state == PLAYING:
    all_sprites.update()          # 갱신만 조건부

screen.fill(BG)
all_sprites.draw(screen)          # 그리기는 항상
if state == PAUSED:
    draw_pause_overlay(screen)    # 위에 오버레이만 추가
pygame.display.flip()
```

**부수적인 장점** — 일시정지 화면에 **게임 장면이 비쳐 보입니다.**
반투명 오버레이를 씌우면 "잠깐 멈춘 것"이라는 느낌이 나서 사용자 경험이 좋아집니다.

> 이것이 [Day 021](day-021.md)에서 배운 **`update()` / `draw()` 분리의 실질적 이유**입니다.
</details>

**2.** 적을 처치할 때 **적의 색과 같은 색 파티클**이 터지고, 처치 수가 10의 배수일 때는 **화면 전체가 잠깐 밝아지는** 연출을 추가하세요.

<details>
<summary>답 보기</summary>

```python
class FlashEffect:
    """화면 전체를 잠깐 밝히는 효과."""

    def __init__(self):
        self.timer = 0
        self.duration = 0
        self.color = (255, 255, 255)

    def flash(self, color=(255, 255, 255), duration=10):
        self.color = color
        self.timer = duration
        self.duration = duration

    def update(self):
        if self.timer > 0:
            self.timer -= 1

    def draw(self, surface):
        if self.timer <= 0:
            return
        # 남은 시간에 비례해 투명도 감소
        alpha = int(140 * self.timer / self.duration)
        overlay = pygame.Surface(surface.get_size(), pygame.SRCALPHA)
        overlay.fill((*self.color, alpha))
        surface.blit(overlay, (0, 0))


# ── 초기화 ──
flasher = FlashEffect()

# ── 충돌 처리에서 ──
hits = pygame.sprite.groupcollide(bullets, enemies, True, False)

for bullet, enemy_list in hits.items():
    stats.hits += 1
    for enemy in enemy_list:
        if enemy.take_damage(bullet.damage):
            stats.add_kill(enemy)

            # ① 적의 색으로 폭발
            make_explosion(enemy.rect.centerx, enemy.rect.centery,
                           particles, enemy.COLOR, count=20)
            shaker.shake(power=5, duration=8)

            # ② 10킬마다 화면 플래시
            if stats.kills % 10 == 0:
                flasher.flash(color=(255, 240, 180), duration=14)
                shaker.shake(power=10, duration=14)

# ── 갱신부에 ──
flasher.update()

# ── 그리기 (HUD 앞, 게임 객체 뒤) ──
screen.blit(game_surface, (dx, dy))
flasher.draw(screen)                  # ← 여기
draw_hud(screen, ...)
```

**포인트 4가지**
- `enemy.COLOR` 를 그대로 넘겨 **적 종류별로 다른 색 폭발**이 납니다. 클래스 변수를 특성으로 정의해 둔 덕분입니다. ([Day 023](day-023.md))
- `stats.kills % 10 == 0` — 나머지 연산으로 "N의 배수"를 판정합니다. ([Day 003](day-003.md))
- **투명도를 시간에 따라 줄여** 자연스럽게 사라지게 합니다. 갑자기 꺼지면 부자연스럽습니다.
- **플래시는 HUD보다 뒤에** 그립니다. HUD가 하얗게 덮이면 점수를 읽을 수 없습니다.
</details>

**3.** 아래 코드는 `P` 를 눌러도 일시정지가 되지 않거나, 눌렀다 떼면 바로 풀립니다. 원인과 해결책을 쓰세요.

```python
keys = pygame.key.get_pressed()

if keys[pygame.K_p]:
    if state == PLAYING:
        state = PAUSED
    else:
        state = PLAYING
```

<details>
<summary>답 보기</summary>

**원인 — 상태 방식(`get_pressed`)으로 토글을 처리했습니다.**

`get_pressed()` 는 **누르고 있는 동안 매 프레임 `True`** 입니다. ([Day 020](day-020.md))
`P` 를 0.5초만 눌러도 30프레임 동안 실행되어 상태가 30번 뒤집힙니다.

```
프레임 1: PLAYING → PAUSED
프레임 2: PAUSED  → PLAYING
프레임 3: PLAYING → PAUSED
...
```

짝수 번 뒤집히면 원래 상태로 돌아오므로, **눌렀다 떼면 아무 일도 안 일어난 것처럼 보입니다.**

**해결 — 토글은 이벤트 방식(`KEYDOWN`)으로**

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_p:
            if state == PLAYING:
                state = PAUSED
            elif state == PAUSED:
                state = PLAYING
```

**`elif` 를 쓴 이유** — `else` 로 쓰면 `TITLE` 이나 `GAME_OVER` 상태에서 `P` 를 눌렀을 때
갑자기 `PLAYING` 으로 넘어가는 버그가 납니다. **명시적으로 조건을 적는 편이 안전합니다.**

> **[Day 020](day-020.md)의 원칙을 다시 확인하세요.**
>
> | 목적 | 방식 |
> |---|---|
> | 이동·가속·조준 | 상태 방식 (`get_pressed`) |
> | 발사·점프·**토글**·메뉴 선택 | 이벤트 방식 (`KEYDOWN`) |
>
> **"누르고 있는 동안 계속 일어나야 하는가?"** — 이 질문 하나로 판단할 수 있습니다.
</details>

## 오늘의 정리 · W05 총정리

| 개념 | 핵심 |
|---|---|
| 상태 관리 | 상수 하나로. 플래그 여러 개 ❌ |
| 일시정지 | `update()` 만 멈추고 `draw()` 는 계속 |
| 상태 전환 | 이벤트 방식(`KEYDOWN`) · 한 곳에 모으기 |
| 파티클 | 수명(`life`) 감소 → `kill()` · 개수 상한 필수 |
| 화면 흔들림 | 별도 Surface에 그린 뒤 어긋나게 `blit` |
| HUD | 흔들리지 않게 `screen` 에 직접 |
| 사운드 | `try/except` 로 감싸 파일 없어도 동작 |
| 그리기 순서 | 게임 → 이펙트 → 플래시 → HUD → 오버레이 |

### W05에서 배운 것

| Day | 내용 | 핵심 |
