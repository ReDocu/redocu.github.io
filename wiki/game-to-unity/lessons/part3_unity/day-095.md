## 3. 개념

### 3-1. 포스트 프로세싱이란

**왜 필요한가** — 화면 전체를 후처리한다.

```
   ★ 렌더링 순서

   ① 씬을 렌더 텍스처에 그린다
        ↓
   ② 그 텍스처에 셰이더를 적용한다   ← 포스트 프로세싱
        ↓
   ③ 화면에 출력
```

```
   ★ Day 94의 파이프라인 확장

   버텍스 → 래스터화 → 프래그먼트 → 병합 → [포스트 프로세싱] → 화면
                                                    ↑ 오늘
```

```
   ★ Day 68과의 대응

   Part 2:  백버퍼에 다 그린 뒤 BitBlt로 화면에

   만약 BitBlt 전에 백버퍼 전체를 한 번 더 처리한다면?
   → 그것이 포스트 프로세싱

   예)  화면 전체를 어둡게 (Day 69의 결과 화면)
        for (y) BlendLine(0, y, w, y, RGB(0,0,0), 0.55);
```

```
   ⚠️ 비용

   화면 전체 픽셀 × 효과 개수
   1920×1080 × 5개 효과 = 1천만 번 계산/프레임
   → 모바일에서는 신중하게
```

### 3-2. Volume 시스템

**왜 필요한가** — URP의 포스트 프로세싱 구조.

```
   ★ 3요소

   ① Volume Profile   설정을 담은 애셋
   ② Volume           씬에 놓인 컴포넌트
   ③ Camera           Post Processing ✔ 필요
```

```
   GameObject → Volume → Global Volume
```

| Volume Mode | 동작 |
|---|---|
| **Global** | 씬 전체에 적용 |
| **Local** | Collider 안에서만 적용 |

```
   ★ Local Volume의 활용

   터널에 들어가면 어두워진다
   물속에 들어가면 푸르게

   → Blend Distance로 부드럽게 전환
```

```
   ⚠️ 효과가 안 보이는 이유

   ① 카메라의 Post Processing 체크 해제
   ② Volume에 Profile 없음
   ③ URP Asset에서 Post-processing 비활성
   ④ Volume Mask 레이어 불일치
   ⑤ 효과의 체크박스 미체크 (각 항목마다 있다)
```

### 3-3. 주요 효과 — Bloom

**왜 필요한가** — 밝은 것이 번진다.

| 필드 | 의미 |
|---|---|
| **Threshold** | 이 밝기 이상만 번진다 |
| **Intensity** | 번짐 강도 |
| Scatter | 번짐 범위 |
| Tint | 번짐 색 |
| High Quality Filtering | 품질 (비쌈) |

```
   ★ Day 94의 HDR 발광이 여기서 완성된다

   Emission을 HDR로 2.0 이상 주고
   Bloom Threshold 1.0
   → 그 부분만 번진다
```

```
   ⚠️ Threshold가 0이면

   화면 전체가 뿌옇게 된다
   → 1.0 근처에서 시작
```

```
   ★ HDR 렌더링 필요

   URP Asset → Quality → HDR ✔
   → 1을 넘는 밝기를 표현할 수 있다
```

```csharp
public class MinimapUI : MonoBehaviour
{
    [SerializeField] private TrackPath path;
    [SerializeField] private RectTransform mapArea;
    [SerializeField] private UILineRenderer trackLine;
    [SerializeField] private RectTransform playerIcon;
    [SerializeField] private RectTransform[] aiIcons;

    private Vector2 worldMin, worldSize;

    void Start()
    {
        CalculateBounds();
        DrawTrack();
    }

    private void CalculateBounds()
    {
        Vector2 min = new Vector2(float.MaxValue, float.MaxValue);
        Vector2 max = new Vector2(float.MinValue, float.MinValue);

        foreach (Waypoint wp in path.Waypoints)
        {
            min.x = Mathf.Min(min.x, wp.position.x);
            min.y = Mathf.Min(min.y, wp.position.z);
            max.x = Mathf.Max(max.x, wp.position.x);
            max.y = Mathf.Max(max.y, wp.position.z);
        }

        // ★ 여백
        Vector2 margin = (max - min) * 0.08f;
        worldMin = min - margin;
        worldSize = (max - min) + margin * 2f;
    }

    // ★ 월드 좌표 → 미니맵 로컬 좌표
    private Vector2 WorldToMap(Vector3 world)
    {
        float u = (world.x - worldMin.x) / worldSize.x;
        float v = (world.z - worldMin.y) / worldSize.y;

        Vector2 size = mapArea.rect.size;

        return new Vector2((u - 0.5f) * size.x, (v - 0.5f) * size.y);
    }

    void LateUpdate()
    {
        playerIcon.anchoredPosition = WorldToMap(player.position);

        // ★ 아이콘 회전 (진행 방향)
        float angle = -player.eulerAngles.y;
        playerIcon.localRotation = Quaternion.Euler(0, 0, angle);

        for (int i = 0; i < aiIcons.Length; i++)
            aiIcons[i].anchoredPosition = WorldToMap(aiCars[i].position);
    }
}
```

```

   Part 2:  화면 ↔ 월드 ↔ 타일
   Unity:   월드 ↔ 미니맵 UV ↔ UI 로컬
```

{

    [SerializeField] private float vignetteMin = 0.2f;
    [SerializeField] private float vignetteMax = 0.45f;

    [Header("Motion Blur")]
    [SerializeField] private float blurMin = 0f;
    [SerializeField] private float blurMax = 0.35f;

    [Header("Chromatic")]
    [SerializeField] private float chromaticMax = 0.6f;

    [Header("Saturation")]
    [SerializeField] private float boostSaturation = 25f;

    [Header("반응")]
    [SerializeField] private float effectLerpSpeed = 4f;

    // Volume 컴포넌트 캐시
    private Vignette vignette;
    private MotionBlur motionBlur;
    private ChromaticAberration chromatic;
    private ColorAdjustments colorAdj;
    private LensDistortion lensDistortion;

    private float smoothSpeedRatio;
    private float smoothBoost;

    void Start()
    {
        // ★ 한 번만 가져온다
        volume.profile.TryGet(out vignette);
        volume.profile.TryGet(out motionBlur);
        volume.profile.TryGet(out chromatic);
        volume.profile.TryGet(out colorAdj);
        volume.profile.TryGet(out lensDistortion);
    }

    void Update()
    {
        float dt = Time.deltaTime;

        float rawRatio = Mathf.Clamp01(car.ForwardSpeed / car.MaxSpeed);
        float rawBoost = car.IsBoosting ? 1f : 0f;

        // ★ 부드럽게
        smoothSpeedRatio = Mathf.Lerp(smoothSpeedRatio, rawRatio,
                                       effectLerpSpeed * dt);
        smoothBoost = Mathf.Lerp(smoothBoost, rawBoost, effectLerpSpeed * dt);

        ApplyFov(dt);
        ApplyPostFx();
    }

    private void ApplyFov(float dt)
    {
        if (vcam == null) return;

        float target = Mathf.Lerp(baseFov, maxFov, smoothSpeedRatio)
                       + boostFovAdd * smoothBoost;

        vcam.Lens.FieldOfView = Mathf.Lerp(
            vcam.Lens.FieldOfView, target, fovLerpSpeed * dt);
    }

    private void ApplyPostFx()
    {
        if (vignette != null)
            vignette.intensity.value =
                Mathf.Lerp(vignetteMin, vignetteMax, smoothSpeedRatio);

        if (motionBlur != null)
            motionBlur.intensity.value =
                Mathf.Lerp(blurMin, blurMax, smoothSpeedRatio);

        if (chromatic != null)
            chromatic.intensity.value = chromaticMax * smoothBoost;

        if (colorAdj != null)
            colorAdj.saturation.value = boostSaturation * smoothBoost;

        if (lensDistortion != null)
            lensDistortion.intensity.value = -0.15f * smoothBoost;
    }
}

    // ★ 비율 유지
    private Vector2 WorldToMap(Vector3 world)
    {
        Vector2 size = mapArea.rect.size;

        // 더 큰 축에 맞춘다
        float worldAspect = worldSize.x / worldSize.y;
        float mapAspect = size.x / size.y;

        float scale = worldAspect > mapAspect
            ? size.x / worldSize.x
            : size.y / worldSize.y;

        float x = (world.x - worldMin.x - worldSize.x * 0.5f) * scale;
        float y = (world.z - worldMin.y - worldSize.y * 0.5f) * scale;

        return new Vector2(x, y);
    }

| 멀미 | FOV/블러 급변 | Lerp + 설정 옵션 |
| 스피드 라인이 뒤에 남음 | Simulation Space World | **Local** |
| 스키드 마크가 긴 선 | Trail 미초기화 | `Clear()` |
| 스키드 마크가 안 보임 | 지면에 묻힘 | y 오프셋 |
| **미니맵이 찌그러짐** | 비율 미고려 | 축 스케일 통일 |
| 미니맵이 안 맞음 | x/z 혼동 | 3D는 z가 앞 |
| GC 발생 | 매 프레임 문자열 | 값 변경 시에만 |
