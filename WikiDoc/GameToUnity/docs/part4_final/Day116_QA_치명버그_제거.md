## 3. 개념

### 3-1. QA란

**왜 필요한가** — 체계적으로 부순다.

```
   ★ QA (Quality Assurance)

   "정상 플레이"가 아니라
   "비정상 플레이"를 시도한다
```

```
   ★ 개발자의 맹점

   개발자는 자기가 만든 대로 플레이한다
   → 의도한 경로만 검증된다
   → 플레이어는 의도하지 않은 짓을 한다
```

```
   ★ QA의 기본 자세

   "이걸 하면 어떻게 되지?"
   "이 순서로 누르면?"
   "여기서 끊으면?"
```

namespace OneFloor.Core
{
    public static class TimeController
    {
        private static readonly HashSet<string> pauseRequests = new();

        public static void RequestPause(string reason)
        {
            pauseRequests.Add(reason);
            Apply();
        }

        public static void ReleasePause(string reason)
        {
            pauseRequests.Remove(reason);
            Apply();
        }

        public static void ClearAll()
        {
            pauseRequests.Clear();
            Time.timeScale = 1f;
        }

        private static void Apply()
        {
            Time.timeScale = pauseRequests.Count > 0 ? 0f : 1f;
        }
    }
}
