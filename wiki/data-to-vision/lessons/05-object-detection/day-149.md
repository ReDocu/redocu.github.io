이 레슨을 마치면 이렇게 할 수 있습니다.

- 동영상 추론 파이프라인을 만들고 **프레임별 결과를 기록**할 수 있다.

**감으로 정하면 안 됩니다.** 데이터로 정합니다.

## ③ 개념 설명

### `predict()` 주요 인자

```python
results = model.predict(
    source="image.jpg",     # 입력
    conf=0.25,              # ★ 신뢰도 임계값
    iou=0.7,                # ★ NMS IoU 임계값
    imgsz=640,              # 추론 해상도
    max_det=300,            # 이미지당 최대 검출 수
    classes=[0],            # ★ 특정 클래스만
    agnostic_nms=False,     # 클래스 무시하고 NMS
    device=0,
    half=False,             # FP16 (GPU에서 속도↑)
    stream=False,           # ★ 제너레이터 (영상·웹캠 필수)
    save=False,             # 결과 이미지 저장
    save_txt=False,         # YOLO 형식 라벨 저장
    save_conf=False,        # txt 에 conf 포함
    save_crop=False,        # 검출 영역 잘라 저장
    verbose=True,
)
```

| 인자 | 기본값 | 의미 | 우리가 조정할 것 |
|---|---|---|---|
| **`conf`** | 0.25 | 이 점수 미만은 버림 | ★ 오늘 결정 |
| **`iou`** | 0.7 | NMS 겹침 임계 | ★ 오늘 결정 |
| `imgsz` | 학습값 | 추론 해상도 | 학습과 같게 |
| `max_det` | 300 | 최대 검출 수 | 보통 그대로 |
| `classes` | None | 클래스 필터 | ★ 운영 시 사용 |
| `agnostic_nms` | False | 클래스 무시 NMS | 상황에 따라 |
| `half` | False | FP16 추론 | GPU면 True |
| `stream` | False | 제너레이터 | ★ 영상은 True |

> ⚠️ **`conf` 기본값이 `predict` 는 0.25, `val` 은 0.001 입니다.**
> 평가할 때는 PR 곡선 전체를 봐야 하므로 매우 낮게 잡습니다.
> **두 값을 혼동하면 "val 성능과 실제가 다르다"는 착각을 합니다.**

### ★ NMS — 비최대 억제 (Non-Maximum Suppression)

**문제**

```
모델은 8,400개 위치에서 예측합니다
한 객체 주변의 여러 위치가 동시에 "여기 사람 있다"고 답합니다

  ┌─────────┐
  │┌───────┐│  conf 0.91
  ││┌─────┐││  conf 0.88
  │││ 👤  │││  conf 0.85
  ││└─────┘││  conf 0.79
  │└───────┘│
  └─────────┘
  → ★ 하나만 남겨야 합니다
```

**NMS 알고리즘**

```
[1] 모든 예측을 conf 내림차순 정렬
[2] 가장 높은 것을 채택
[3] 채택한 것과 IoU ≥ iou_thr 인 나머지를 ★ 제거 (억제)
[4] 남은 것 중 다음으로 높은 것을 채택
[5] 더 이상 없을 때까지 반복
```

**단계별 예시 (`iou=0.7`)**

```
초기 예측
  A conf 0.91  (100, 100, 200, 300)
  B conf 0.88  (105, 98,  198, 305)   A와 IoU 0.93
  C conf 0.85  (108, 102, 205, 298)   A와 IoU 0.89
  D conf 0.79  (300, 100, 400, 300)   A와 IoU 0.00
  E conf 0.72  (305, 105, 398, 295)   D와 IoU 0.91

[1] A 채택 (0.91)
    → B (IoU 0.93 ≥ 0.7) 제거
    → C (IoU 0.89 ≥ 0.7) 제거
    → D (IoU 0.00 < 0.7) 유지

[2] D 채택 (0.79)
    → E (IoU 0.91 ≥ 0.7) 제거

★ 최종: A, D 두 개
```

### ★ `iou` 값이 만드는 차이

| `iou` | 동작 | 부작용 |
|---|---|---|
| **0.3** (낮음) | 조금만 겹쳐도 제거 | ★ **겹친 두 객체를 하나로 병합** |
| **0.5** | 중간 | |
| **0.7** (기본) | 많이 겹쳐야 제거 | |
| **0.9** (높음) | 거의 안 제거 | ★ **중복 박스 다수 생존** |

```
★ 핵심 이해

  iou 낮음 → 억제가 강함 → 박스가 적게 남음
  iou 높음 → 억제가 약함 → 박스가 많이 남음

  헷갈리기 쉬우니 이렇게 외우세요
  "iou 는 '이만큼 겹치면 지운다'는 기준"
```

**우리가 만난 문제와 연결**

```
[Day 147](day-147.md) 관찰
  "겹친 사람 두 명을 하나의 큰 박스로 검출"

  → 두 사람이 실제로 IoU 0.55 로 겹쳐 있었다면
  → iou=0.45 였다면 하나가 지워짐
  → ★ iou 를 0.7 로 올리면 둘 다 살아남음

  "중복 검출 10건"
  → iou 가 너무 높았을 수도
  → ★ 두 문제가 상충합니다. 균형점을 찾아야 합니다
```

### `agnostic_nms` — 클래스를 무시할 것인가

```python
agnostic_nms=False    # 기본. 클래스별로 따로 NMS
agnostic_nms=True     # 클래스 무관하게 NMS
```

```
사람이 상자를 들고 있는 장면

  agnostic_nms=False
    person 박스와 box 박스가 겹쳐도 ★ 둘 다 유지
    → 우리 프로젝트에 맞음

  agnostic_nms=True
    겹치면 conf 높은 하나만 남김
    → box 가 사라짐  ✗
```

> **★ 클래스가 겹칠 수 있는 프로젝트에서는 반드시 `False`** (기본값).
> 같은 물체를 여러 클래스로 중복 검출하는 것이 문제일 때만 `True`.

### `max_det` — 최대 검출 수

```
max_det=300   기본

★ 검출 수가 이보다 많으면 conf 상위 300개만 남김
```

```
우리 프로젝트: 한 화면에 사람이 10명을 넘지 않음

★ 군중 카운팅 프로젝트라면 1000 으로 올려야 함
```

## ④ 단계별 실습

### Step 1. `conf` 스윕 — 전체 곡선 그리기

```python
"""conf_sweep.py — conf 임계값별 성능 측정"""
from pathlib import Path

import numpy as np
import pandas as pd
from ultralytics import YOLO

import bbox_utils as B
from metrics import iou_xyxy

ROOT = Path("C:/vision/datasets/cctv_v1")
RUN = Path("C:/vision/runs/exp01_n_640_50ep")


def load_gt(txt, w, h):
    if not Path(txt).exists():
        return []
    out = []
    for line in Path(txt).read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        p = line.split()
        out.append((int(p[0]),
                    B.yolo_to_voc(tuple(float(v) for v in p[1:5]), w, h)))
    return out


def collect_predictions(model, split="val", conf_min=0.01, iou_nms=0.7):
    """★ conf 를 최소로 낮춰 한 번만 추론하고, 이후는 필터링만"""
    import cv2
    img_dir = ROOT / "images" / split
    lbl_dir = ROOT / "labels" / split

    all_gt, all_pred = {}, {}
    for p in sorted(img_dir.glob("*.jpg")):
        img = cv2.imread(str(p))
        if img is None:
            continue
        h, w = img.shape[:2]
        all_gt[p.stem] = load_gt(lbl_dir / (p.stem + ".txt"), w, h)
        r = model.predict(str(p), conf=conf_min, iou=iou_nms, verbose=False)[0]
        all_pred[p.stem] = [(int(b.cls), tuple(b.xyxy[0].tolist()), float(b.conf))
                            for b in r.boxes]
    return all_gt, all_pred


def evaluate(all_gt, all_pred, conf_thr, iou_thr=0.5, cls_filter=None):
    """주어진 conf 에서 TP/FP/FN 집계"""
    tp = fp = fn = 0
    for stem, gt in all_gt.items():
        g = [(c, b) for c, b in gt if cls_filter is None or c in cls_filter]
        pred = [(c, b, s) for c, b, s in all_pred.get(stem, [])
                if s >= conf_thr and (cls_filter is None or c in cls_filter)]
        pred.sort(key=lambda x: -x[2])

        used = set()
        for pc, pb, _ in pred:
            best, bj = 0.0, -1
            for j, (gc, gb) in enumerate(g):
                if j in used or gc != pc:
                    continue
                v = iou_xyxy(gb, pb)
                if v > best:
                    best, bj = v, j
            if best >= iou_thr:
                used.add(bj); tp += 1
            else:
                fp += 1
        fn += len(g) - len(used)

    prec = tp / (tp + fp) if (tp + fp) else 0.0
    rec = tp / (tp + fn) if (tp + fn) else 0.0
    f1 = 2 * prec * rec / (prec + rec) if (prec + rec) else 0.0
    f2 = 5 * prec * rec / (4 * prec + rec) if (4 * prec + rec) else 0.0
    return {"conf": conf_thr, "TP": tp, "FP": fp, "FN": fn,
            "P": prec, "R": rec, "F1": f1, "F2": f2}


model = YOLO(RUN / "weights/best.pt")
all_gt, all_pred = collect_predictions(model)

CONFS = np.arange(0.05, 0.96, 0.05)
rows = [evaluate(all_gt, all_pred, c, cls_filter=[0]) for c in CONFS]   # person만
df = pd.DataFrame(rows)

print("=" * 96)
print("conf 스윕 — person 클래스 (IoU 0.5 기준)")
print("=" * 96)
print(f"{'conf':>7}{'TP':>7}{'FP':>7}{'FN':>7}{'Precision':>12}{'Recall':>10}"
      f"{'F1':>9}{'F2':>9}   비고")
print("-" * 96)
for _, r in df.iterrows():
    note = ""
    if r["R"] >= 0.90 and r["P"] >= 0.70:
        note = "★ 목표 충족"
    elif r["R"] >= 0.90:
        note = "R 충족, P 미달"
    elif r["P"] >= 0.70:
        note = "P 충족, R 미달"
    print(f"{r['conf']:>7.2f}{int(r['TP']):>7}{int(r['FP']):>7}{int(r['FN']):>7}"
          f"{r['P']:>12.3f}{r['R']:>10.3f}{r['F1']:>9.3f}{r['F2']:>9.3f}   {note}")
print("=" * 96)
```

### Step 3. NMS 직접 구현

```python
"""nms.py — 비최대 억제 직접 구현"""
import numpy as np

from metrics import iou_xyxy, iou_matrix


def nms(boxes, scores, iou_thr=0.7):
    """단순 NMS — 반환: 살아남은 인덱스"""
    idx = np.argsort(-np.asarray(scores))
    keep = []
    while len(idx):
        i = idx[0]
        keep.append(i)
        if len(idx) == 1:
            break
        rest = idx[1:]
        ious = np.array([iou_xyxy(boxes[i], boxes[j]) for j in rest])
        idx = rest[ious < iou_thr]          # ★ 임계 이상은 제거
    return keep


def nms_per_class(boxes, scores, classes, iou_thr=0.7):
    """클래스별 NMS — Ultralytics 기본 동작"""
    keep = []
    for c in set(classes):
        idxs = [i for i, cc in enumerate(classes) if cc == c]
        sub_keep = nms([boxes[i] for i in idxs],
                       [scores[i] for i in idxs], iou_thr)
        keep += [idxs[k] for k in sub_keep]
    return sorted(keep, key=lambda i: -scores[i])


def nms_agnostic(boxes, scores, classes, iou_thr=0.7):
    """클래스 무시 NMS"""
    return nms(boxes, scores, iou_thr)


# ── 검증 ──
boxes = [
    (100, 100, 200, 300),      # A
    (105,  98, 198, 305),      # B — A와 매우 겹침
    (108, 102, 205, 298),      # C — A와 겹침
    (300, 100, 400, 300),      # D — 독립
    (305, 105, 398, 295),      # E — D와 겹침
    (150, 120, 260, 320),      # F — A와 절반쯤 겹침
]
scores = [0.91, 0.88, 0.85, 0.79, 0.72, 0.68]
classes = [0, 0, 0, 0, 0, 0]

print("=" * 88)

print("=" * 88)

# IoU 행렬 출력
M = iou_matrix(boxes, boxes)
print("[IoU 행렬]")
print("     " + "".join(f"{l:>8}" for l in LABELS))
for i, l in enumerate(LABELS):
    print(f"  {l}  " + "".join(f"{M[i,j]:>8.3f}" for j in range(len(boxes))))

print(f"\n{'iou 임계':>10}{'살아남은 박스':<30}{'개수':>6}   해석")
print("-" * 88)
for thr in (0.3, 0.45, 0.5, 0.6, 0.7, 0.8, 0.9):
    keep = nms(boxes, scores, thr)
    kept = "".join(LABELS[i] for i in sorted(keep))
    note = ""
    if len(keep) <= 2:
        note = "★ 억제 강함 — 겹친 객체 병합 위험"
    elif len(keep) >= 5:
        note = "★ 억제 약함 — 중복 다수"
    print(f"{thr:>10.2f}{kept:<30}{len(keep):>6}   {note}")
print("=" * 88)
```

```python
def infer_video(model, video, out_video=None, out_csv=None,
                conf=CONF, iou=IOU, skip=1, classes=None, show_fps=True):
    """동영상 추론 + 프레임별 검출 기록"""
    cap = cv2.VideoCapture(str(video))
    if not cap.isOpened():
        raise RuntimeError(f"열 수 없음: {video}")

    w = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    h = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
    fps = cap.get(cv2.CAP_PROP_FPS) or 30

    writer = None
    if out_video:
        writer = cv2.VideoWriter(str(out_video),
                                 cv2.VideoWriter_fourcc(*"mp4v"),
                                 fps / skip, (w, h))

    rows = []
    frame_i, processed, t0 = 0, 0, time.time()
    last_vis = None

    while True:
        ok, frame = cap.read()
        if not ok:
            break

        if frame_i % skip == 0:
            r = model.predict(frame, conf=conf, iou=iou, classes=classes,
                              verbose=False)[0]
            processed += 1
            for b in r.boxes:
                x1, y1, x2, y2 = b.xyxy[0].tolist()
                rows.append({
                    "frame": frame_i,
                    "time_s": round(frame_i / fps, 3),
                    "class_id": int(b.cls),
                    "class": model.names[int(b.cls)],
                    "conf": round(float(b.conf), 4),
                    "x1": round(x1, 1), "y1": round(y1, 1),
                    "x2": round(x2, 1), "y2": round(y2, 1),
                    "w": round(x2 - x1, 1), "h": round(y2 - y1, 1),
                    "cx": round((x1 + x2) / 2, 1),
                    "cy": round((y1 + y2) / 2, 1),
                    "area_ratio": round((x2-x1)*(y2-y1)/(w*h)*100, 3),
                })
            last_vis = r.plot()
            if show_fps:
                el = time.time() - t0
                cv2.putText(last_vis, f"FPS {processed/max(el,1e-6):.1f}  "
                            f"det {len(r.boxes)}", (12, 30),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)

        if writer and last_vis is not None:
            writer.write(last_vis)
        frame_i += 1

    cap.release()
    if writer:
        writer.release()

    if out_csv:
        Path(out_csv).parent.mkdir(parents=True, exist_ok=True)
        with open(out_csv, "w", newline="", encoding="utf-8-sig") as f:
            wtr = csv.DictWriter(f, fieldnames=list(rows[0].keys()) if rows
                                 else ["frame"])
            wtr.writeheader()
            wtr.writerows(rows)

    dt = time.time() - t0
    return {"총 프레임": frame_i, "처리": processed, "검출": len(rows),
            "소요(초)": round(dt, 1), "FPS": round(processed / dt, 2),
            "해상도": f"{w}×{h}"}


model = YOLO(RUN / "weights/best.pt")
stat = infer_video(model, "C:/vision/day149/videos/test.mp4",
                   out_video=OUT / "test_det.mp4",

print("=" * 76)
```

def in_excluded(box, zones, overlap_thr=0.6):

```python
from collections import deque

class SlidingDetector:
    def __init__(self, window=10, min_hits=7):
        self.buf = deque(maxlen=window)
        self.min_hits = min_hits

    def update(self, detected):
        self.buf.append(1 if detected else 0)
        return sum(self.buf) >= self.min_hits
```

```python
class ZoneCooldown:
    def __init__(self, global_s=30, same_zone_s=300, grid=4):
        self.global_s, self.zone_s, self.grid = global_s, same_zone_s, grid
        self.last_global = -1e9
        self.last_zone = {}

    def allow(self, t, box, img_wh):
        if t - self.last_global < self.global_s:
            return False
        gx = int((box[0]+box[2])/2 / img_wh[0] * self.grid)
        gy = int((box[1]+box[3])/2 / img_wh[1] * self.grid)
        key = (gx, gy)
        if t - self.last_zone.get(key, -1e9) < self.zone_s:
            return False
        self.last_global = t
        self.last_zone[key] = t
        return True
```
