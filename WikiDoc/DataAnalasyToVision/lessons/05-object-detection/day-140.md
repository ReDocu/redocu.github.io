## ③ 개념 설명

### YOLO 데이터셋 폴더 구조

```
datasets/cctv/                  ← 데이터셋 루트
├── images/
│   ├── train/
│   │   ├── ours_0001.jpg
│   │   └── ours_0002.jpg
│   ├── val/
│   │   └── ours_0091.jpg
│   └── test/                   ← 선택
├── labels/
│   ├── train/
│   │   ├── ours_0001.txt
│   │   └── ours_0002.txt
│   ├── val/
│   │   └── ours_0091.txt
│   └── test/
└── data.yaml                   ← ★ 학습 설정
```

**절대 바꾸면 안 되는 두 가지**

```
① 폴더 이름이 정확히  images  와  labels
② 이미지와 라벨의 하위 폴더 이름이 동일 (train ↔ train)
```

**Ultralytics의 라벨 경로 계산**

```python
# 내부적으로 이렇게 찾습니다
img = ".../datasets/cctv/images/train/ours_0001.jpg"
lbl = img.replace(f"{os.sep}images{os.sep}", f"{os.sep}labels{os.sep}")
lbl = lbl.rsplit(".", 1)[0] + ".txt"
# → .../datasets/cctv/labels/train/ours_0001.txt
```

> ⚠️ **경로 문자열에 `images` 가 두 번 나오면 문제가 생깁니다.**
> ```
> C:/my_images/datasets/cctv/images/train/a.jpg
>       ↑ 여기도 치환될 수 있음
> ```
> **상위 폴더 이름에 `images` 를 쓰지 마세요.** `C:/vision/datasets/...` 처럼 두세요.

### `data.yaml` — 각 키의 의미

```yaml
# datasets/cctv/data.yaml

path: C:/vision/datasets/cctv     # 데이터셋 루트 (절대 경로 권장)
train: images/train               # path 기준 상대 경로
val: images/val
test: images/test                 # 선택 — 없으면 생략

nc: 3                             # 클래스 수 (최신 버전은 생략 가능)
names:
  0: person
  1: helmet
  2: box
```

| 키 | 의미 | 주의 |
|---|---|---|
| **`path`** | 데이터셋 루트 | **절대 경로를 권장** |
| **`train`** | 학습 이미지 폴더 | `path` 기준 상대 경로 |
| **`val`** | 검증 이미지 폴더 | ★ **필수** |
| `test` | 최종 평가용 | 선택 |
| `nc` | 클래스 개수 | `names` 와 개수가 맞아야 함 |
| **`names`** | 번호 → 이름 | **순서가 곧 라벨의 클래스 id** |

**`names` 는 두 가지 방식이 있습니다**

```yaml
# 방식 ① 딕셔너리 (권장 — 번호가 명시적)
names:
  0: person
  1: helmet
  2: box

# 방식 ② 리스트 (구버전 스타일)
names: ['person', 'helmet', 'box']
```

> **★ 딕셔너리 방식을 쓰세요.**
> 리스트는 순서를 실수로 바꿔도 알 수 없지만, 딕셔너리는 번호가 보입니다.

### train / val / test — 무엇을 위한 것인가

대단원 04와 역할이 같습니다.

| 셋 | 용도 | 몇 번 보는가 |
|---|---|---|
| **train** | 가중치 학습 | 매 에폭 |
| **val** | 학습 중 성능 확인 · 모델 선택 · 조기 종료 | 매 에폭 |
| **test** | ★ **최종 성능 보고** | **딱 한 번** |

```
★ val 을 보고 하이퍼파라미터를 고르면
  val 성능은 낙관적으로 편향됩니다

  → 진짜 성능을 알려면 test 가 필요합니다
```

**우리 수업의 현실적 선택**

```
데이터 500장 규모에서 8:1:1 로 나누면
  test 가 50장 → mAP 추정치의 흔들림이 너무 큼

★ 권장
  · W28~W31 학습 단계   : train 80% / val 20%  (test 없음)
  · W35~36 최종 프로젝트 : train 70% / val 15% / test 15%
    또는 ★ "발표 당일 새로 촬영한 영상"을 test 로 사용   ← 가장 정직함
```

> **★ "새로 촬영한 영상으로 시연"이 최고의 테스트입니다.**
> 분할로 만든 test 셋보다 훨씬 설득력이 있습니다. [Day 180](day-180.md) 발표에서 이걸 합니다.

### ★ 분할 방법 — 무작위가 답이 아닙니다

**문제: 비슷한 사진이 train과 val에 갈라지면 성능이 부풀려집니다.**

```
영상 프레임 추출 데이터

  frm_0100  ┐
  frm_0101  │ 거의 같은 장면
  frm_0102  ┘

  무작위 분할 → 0100은 train, 0101은 val
  → val 에서 "처음 보는 사진"이 아님
```

**해결: 그룹 단위로 나눕니다.**

| 데이터 성격 | 분할 기준 |
|---|---|
| 영상에서 추출 | **영상 파일 단위** — 같은 영상은 한쪽에만 |
| 같은 장소 연속 촬영 | **촬영 세션 단위** |
| 여러 사람이 수집 | 사람 단위 (도메인 차이 확인용) |
| 서로 무관한 사진 | 무작위 OK |
| 시간 순서가 있음 | **시간 분할** (앞 80% train, 뒤 20% val) |

```
★ 우리 CCTV 프로젝트

  촬영 세션 A (오전, 현관)   → train
  촬영 세션 B (오후, 현관)   → train
  촬영 세션 C (야간, 현관)   → ★ val

  → "야간에서 잘 되는가"를 정직하게 측정
```

> **분할 기준이 곧 "무엇을 측정하고 싶은가"입니다.**
> 야간 성능이 궁금하면 야간을 val에 넣고, 일반 성능이 궁금하면 골고루 섞습니다.

### 클래스 균형도 봐야 합니다

## ④ 단계별 실습

### Step 1. 데이터셋 폴더 구성

```python
import random
import shutil
from collections import Counter, defaultdict
from pathlib import Path

SRC_IMG = Path("C:/vision/day138/images")
SRC_LBL = Path("C:/vision/day138/labels")
DST = Path("C:/vision/datasets/cctv")

IMG_EXTS = (".jpg", ".jpeg", ".png", ".bmp")


def build_dataset(src_img, src_lbl, dst, val_ratio=0.2,
                  group_fn=None, seed=42, copy=True, test_ratio=0.0):
    """이미지·라벨을 YOLO 데이터셋 구조로 배치한다

    group_fn: 파일 stem → 그룹 키. 같은 그룹은 같은 split 에 들어감
              None 이면 무작위 분할
    """
    src_img, src_lbl, dst = Path(src_img), Path(src_lbl), Path(dst)
    splits = ["train", "val"] + (["test"] if test_ratio > 0 else [])
    for s in splits:
        (dst / "images" / s).mkdir(parents=True, exist_ok=True)
        (dst / "labels" / s).mkdir(parents=True, exist_ok=True)

    imgs = sorted(p for p in src_img.iterdir() if p.suffix.lower() in IMG_EXTS)

    # ── 그룹 구성 ──
    if group_fn is None:
        groups = {p.stem: [p] for p in imgs}
    else:
        groups = defaultdict(list)
        for p in imgs:
            groups[group_fn(p.stem)].append(p)
        groups = dict(groups)

    keys = sorted(groups)
    rnd = random.Random(seed)              # ★ seed 고정 — 재현성
    rnd.shuffle(keys)

    n_total = len(imgs)
    n_val = int(n_total * val_ratio)
    n_test = int(n_total * test_ratio)

    assign, counts = {}, Counter()
    for k in keys:
        size = len(groups[k])
        if counts["test"] + size <= n_test:
            s = "test"
        elif counts["val"] + size <= n_val:
            s = "val"
        else:
            s = "train"
        assign[k] = s
        counts[s] += size

    # ── 복사 ──
    op = shutil.copy2 if copy else shutil.move
    moved = Counter()
    for k, s in assign.items():
        for p in groups[k]:
            op(str(p), str(dst / "images" / s / p.name))
            txt = src_lbl / (p.stem + ".txt")
            target = dst / "labels" / s / (p.stem + ".txt")
            if txt.exists():
                op(str(txt), str(target))
            else:
                target.write_text("", encoding="utf-8")   # ★ 빈 라벨 명시 생성
            moved[s] += 1

    return {"groups": len(groups), "splits": dict(moved), "assign": assign}


# 파일명이 frm_0042 형태이고 영상 1개에서 나왔다면 그룹은 하나
# 여러 영상이라면 접두사로 그룹을 나눈다
def by_session(stem):
    """ours_camA_0042 → camA"""
    parts = stem.split("_")
    return parts[1] if len(parts) >= 3 else "default"


stat = build_dataset(SRC_IMG, SRC_LBL, DST, val_ratio=0.2,
                     group_fn=by_session, seed=42)
```

```python
"""dataset_check.py — YOLO 데이터셋 품질 검사

체크리스트 8항목 + 통계
사용:  python dataset_check.py data.yaml
"""
import sys
from collections import Counter, defaultdict
from pathlib import Path

import cv2
import yaml

IMG_EXTS = (".jpg", ".jpeg", ".png", ".bmp", ".webp")

# ── 임계값 (프로젝트에 맞게 조정) ──
MIN_SIDE_RATIO = 0.01        # 짧은 변이 이미지의 1% 미만이면 경고
MAX_ASPECT = 8.0             # 종횡비 (긴 변 / 짧은 변)
DUP_IOU = 0.90               # 중복 판정 IoU


def iou_yolo(a, b):
    """YOLO 좌표 두 개의 IoU (정규화 공간에서 계산)"""
    def to_xyxy(t):
        cx, cy, w, h = t
        return cx - w / 2, cy - h / 2, cx + w / 2, cy + h / 2
    ax1, ay1, ax2, ay2 = to_xyxy(a)
    bx1, by1, bx2, by2 = to_xyxy(b)
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw, ih = max(0.0, ix2 - ix1), max(0.0, iy2 - iy1)
    inter = iw * ih
    ua = (ax2 - ax1) * (ay2 - ay1) + (bx2 - bx1) * (by2 - by1) - inter
    return inter / ua if ua > 0 else 0.0


def check_split(root, split, names, read_image_size=True):
    img_dir = root / "images" / split
    lbl_dir = root / "labels" / split
    issues = []
    stats = {
        "images": 0, "labeled": 0, "background": 0, "boxes": 0,
        "per_class": Counter(), "sizes": [], "aspects": [], "areas": [],
    }

    if not img_dir.exists():
        issues.append(("ERROR", split, "-", f"이미지 폴더 없음: {img_dir}"))
        return stats, issues
    if not lbl_dir.exists():
        issues.append(("ERROR", split, "-", f"라벨 폴더 없음: {lbl_dir}"))
        return stats, issues

    imgs = {p.stem: p for p in img_dir.iterdir() if p.suffix.lower() in IMG_EXTS}
    lbls = {p.stem: p for p in lbl_dir.glob("*.txt") if p.stem != "classes"}

    # [1] 파일 매칭
    for stem in sorted(set(lbls) - set(imgs)):
        issues.append(("ERROR", split, stem, "이미지 없는 고아 라벨"))
    for stem in sorted(set(imgs) - set(lbls)):
        issues.append(("WARN", split, stem, "라벨 파일 없음 (배경으로 취급됨)"))

    # 위험한 파일명
    for stem, p in imgs.items():
        if p.suffix != p.suffix.lower():
            issues.append(("WARN", split, p.name, "확장자 대문자 (Linux에서 매칭 실패)"))
        if " " in p.name or any(ord(c) > 127 for c in p.name):
            issues.append(("WARN", split, p.name, "파일명에 공백/비ASCII"))

    for stem, img_path in sorted(imgs.items()):
        stats["images"] += 1
        W = H = None
        if read_image_size:
            im = cv2.imread(str(img_path))
            if im is None:
                issues.append(("ERROR", split, stem, "이미지를 읽을 수 없음"))
                continue
            H, W = im.shape[:2]

        txt = lbls.get(stem)
        rows = []
        if txt is not None:
            for ln, line in enumerate(txt.read_text(encoding="utf-8").splitlines(), 1):
                s = line.strip()
                if not s:
                    continue
                parts = s.split()
                # [4] 형식
                if len(parts) != 5:
                    issues.append(("ERROR", split, stem, f"{ln}행: 값 {len(parts)}개 (5개여야 함)"))
                    continue
                try:
                    cid = int(parts[0])
                    cx, cy, bw, bh = (float(v) for v in parts[1:])
                except ValueError:
                    issues.append(("ERROR", split, stem, f"{ln}행: 숫자 파싱 실패"))
                    continue
                # [3] 클래스 id
                if cid not in names:
                    issues.append(("ERROR", split, stem,
                                   f"{ln}행: 클래스 id {cid} 가 names 에 없음"))
                    continue
                # [2] 좌표 범위
                if not all(0 <= v <= 1 for v in (cx, cy, bw, bh)):
                    issues.append(("ERROR", split, stem,
                                   f"{ln}행: 0~1 범위 밖 ({cx:.3f},{cy:.3f},{bw:.3f},{bh:.3f})"))
                    continue
                # [5] 크기 0
                if bw <= 0 or bh <= 0:
                    issues.append(("ERROR", split, stem, f"{ln}행: 크기 0 이하"))
                    continue
                # 경계 초과
                if (cx - bw / 2 < -1e-6 or cx + bw / 2 > 1 + 1e-6 or
                        cy - bh / 2 < -1e-6 or cy + bh / 2 > 1 + 1e-6):
                    issues.append(("WARN", split, stem, f"{ln}행: 박스가 이미지 경계를 벗어남"))
                # [6] 아주 작은 박스
                if min(bw, bh) < MIN_SIDE_RATIO:
                    px = f"{bw*W:.0f}×{bh*H:.0f}px" if W else ""
                    issues.append(("WARN", split, stem,
                                   f"{ln}행: 아주 작은 박스 {bw:.4f}×{bh:.4f} {px}"))
                # [7] 종횡비
                if W:
                    pw, ph = bw * W, bh * H
                    asp = max(pw, ph) / max(min(pw, ph), 1e-6)
                    if asp > MAX_ASPECT:
                        issues.append(("WARN", split, stem,
                                       f"{ln}행: 극단적 종횡비 {asp:.1f}"))
                    stats["aspects"].append(pw / ph if ph else 0)
                    stats["sizes"].append((pw, ph))
                stats["areas"].append(bw * bh)
                stats["per_class"][cid] += 1
                stats["boxes"] += 1
                rows.append((cid, cx, cy, bw, bh))

        # [8] 중복 박스
        for i in range(len(rows)):
            for j in range(i + 1, len(rows)):
                if rows[i][0] == rows[j][0] and iou_yolo(rows[i][1:], rows[j][1:]) > DUP_IOU:
                    issues.append(("WARN", split, stem,
                                   f"중복 의심 박스 {i+1}행 ↔ {j+1}행"))

        if rows:
            stats["labeled"] += 1
        else:
            stats["background"] += 1

    return stats, issues


def check_dataset(yaml_path, verbose=True):
    cfg = yaml.safe_load(Path(yaml_path).read_text(encoding="utf-8"))
    root = Path(cfg["path"])
    names = cfg["names"]
    if isinstance(names, list):
        names = {i: n for i, n in enumerate(names)}

    all_stats, all_issues = {}, []
    for key in ("train", "val", "test"):
        if key not in cfg:
            continue
        split = Path(cfg[key]).name
        st, iss = check_split(root, split, names)
        all_stats[split] = st
        all_issues += iss

    if verbose:
        report(cfg, names, all_stats, all_issues)
    return all_stats, all_issues


def report(cfg, names, stats, issues):

    print("-" * 96)

    print(f"{'split':<8}{'이미지':>8}{'라벨있음':>10}{'배경':>8}{'박스':>8}{'박스/장':>10}")
    print("-" * 96)
    for sp, st in stats.items():
        per = st["boxes"] / st["images"] if st["images"] else 0
        print(f"{sp:<8}{st['images']:>8}{st['labeled']:>10}"
              f"{st['background']:>8}{st['boxes']:>8}{per:>10.2f}")

    print("\n[클래스별 박스 수]")
    print(f"{'클래스':<14}" + "".join(f"{sp:>10}" for sp in stats) + f"{'합계':>10}{'비율':>9}")
    print("-" * 96)
    totals = Counter()
    for st in stats.values():
        totals.update(st["per_class"])
    grand = sum(totals.values()) or 1
    for cid, name in sorted(names.items()):
        row = "".join(f"{stats[sp]['per_class'].get(cid, 0):>10}" for sp in stats)
        print(f"{name:<14}{row}{totals.get(cid,0):>10}{totals.get(cid,0)/grand*100:>8.1f}%")

    # 불균형 경고
    if totals:
        mx, mn = max(totals.values()), min(totals.values())
        if mn and mx / mn > 10:
            print(f"\n  ⚠ 클래스 불균형 {mx/mn:.1f}배 — Day 141·150 에서 대응 필요")
        for cid, name in sorted(names.items()):
            v = stats.get("val", {}).get("per_class", {}).get(cid, 0)

                print(f"  ⚠ val 의 '{name}' 이 {v}개 — AP 신뢰도 낮음")

    # 박스 크기 분포
    import statistics as S
    for sp, st in stats.items():

            continue
        a = sorted(st["areas"])

        mid = sum(1 for v in a if 0.01 <= v < 0.09)
        large = len(a) - small - mid
        print(f"\n[{sp} 박스 크기]  중앙 면적 {S.median(a)*100:.2f}%  "
              f"소 {small} / 중 {mid} / 대 {large}")

    if issues:
        print("\n" + "-" * 96)
        print("발견된 문제")
        print("-" * 96)

                continue

            mark = "✗" if lv == "ERROR" else "⚠"
            print(f"  {mark} [{lv:<5}] {sp:<6}{stem:<24}{msg}")
        print(f"  ... 총 {len(issues)}건")

    print("\n" + "=" * 96)
    print("  " + ("✓ 학습 가능 — ERROR 0건" if n_err == 0
                  else f"★ ERROR {n_err}건을 먼저 해결하세요"))
    print("=" * 96)


if __name__ == "__main__":
```

```python
from pathlib import Path

import cv2
import yaml

import bbox_utils as B

ROOT = Path("C:/vision/datasets/cctv")


def fix_labels(root, names, clip=True, drop_tiny=None, drop_dup_iou=0.95,
               dry_run=True):
    """자동 수정 가능한 문제를 고친다 — ★ dry_run 기본 True"""
    root = Path(root)
    changes = []

    for split in ("train", "val", "test"):
        lbl_dir = root / "labels" / split
        img_dir = root / "images" / split
        if not lbl_dir.exists():
            continue
        for txt in sorted(lbl_dir.glob("*.txt")):
            img = next((p for p in img_dir.iterdir()
                        if p.stem == txt.stem), None)
            if img is None:
                changes.append((txt, "삭제", "이미지 없는 고아 라벨"))
                if not dry_run:
                    txt.unlink()
                continue
            im = cv2.imread(str(img))
            if im is None:
                continue
            H, W = im.shape[:2]

            rows, changed = [], []
            for ln, line in enumerate(txt.read_text(encoding="utf-8").splitlines(), 1):
                if not line.strip():
                    continue
                parts = line.split()
                if len(parts) != 5:
                    changed.append(f"{ln}행 형식 오류 → 제거")
                    continue
                cid = int(parts[0])
                cx, cy, bw, bh = (float(v) for v in parts[1:])

                if cid not in names:
                    changed.append(f"{ln}행 클래스 {cid} → 제거")
                    continue
                if bw <= 0 or bh <= 0:
                    changed.append(f"{ln}행 크기 0 → 제거")
                    continue

                if clip:
                    voc = B.clip_voc(B.yolo_to_voc((cx, cy, bw, bh), W, H), W, H)
                    if voc[2] - voc[0] < 1 or voc[3] - voc[1] < 1:
                        changed.append(f"{ln}행 clip 후 크기 0 → 제거")
                        continue
                    ncx, ncy, nbw, nbh = B.voc_to_yolo(voc, W, H)
                    if abs(ncx - cx) > 1e-6 or abs(nbw - bw) > 1e-6:
                        changed.append(f"{ln}행 경계 clip")
                    cx, cy, bw, bh = ncx, ncy, nbw, nbh

                if drop_tiny and min(bw * W, bh * H) < drop_tiny:
                    changed.append(f"{ln}행 {bw*W:.0f}×{bh*H:.0f}px 너무 작음 → 제거")
                    continue

                rows.append((cid, cx, cy, bw, bh))

            # 중복 제거
            keep = []
            for r in rows:
                if any(r[0] == k[0] and _iou(r[1:], k[1:]) > drop_dup_iou for k in keep):
                    changed.append("중복 박스 제거")
                    continue
                keep.append(r)

            if changed:
                changes.append((txt, "수정", " / ".join(changed[:4])))
                if not dry_run:
                    txt.write_text(
                        "\n".join(f"{c} {a:.6f} {b:.6f} {w:.6f} {h:.6f}"
                                  for c, a, b, w, h in keep) + ("\n" if keep else ""),
                        encoding="utf-8")
    return changes


def _iou(a, b):
    from dataset_check import iou_yolo
    return iou_yolo(a, b)


cfg = yaml.safe_load((ROOT / "data.yaml").read_text(encoding="utf-8"))
names = cfg["names"] if isinstance(cfg["names"], dict) else \
    {i: n for i, n in enumerate(cfg["names"])}

changes = fix_labels(ROOT, names, clip=True, drop_tiny=12, dry_run=True)

print("=" * 92)
print(f"자동 수정 계획 — {len(changes)}건 (dry_run)")
print("=" * 92)
for path, kind, why in changes:
    print(f"  [{kind}] {path.parent.name}/{path.name:<26}{why}")
print("-" * 92)
print("""
  ★ 자동으로 고칠 수 있는 것 / 없는 것

    ✓ 자동 가능
        · 경계 초과 → clip
        · 크기 0 · 형식 오류 → 제거
        · 완전 중복 박스 → 제거
        · 고아 라벨 → 삭제

    ✗ 사람이 판단해야 하는 것
        · 클래스 id 3 이 왜 생겼는가        ← 라벨링 중 클래스를 잘못 골랐을 수 있음
```

### Step 5. 이상 라벨 시각 확인

```python
from pathlib import Path

import cv2
import yaml

import bbox_utils as B
from dataset_check import check_dataset

ROOT = Path("C:/vision/datasets/cctv")
OUT = ROOT.parent / "check" / "issues"
OUT.mkdir(parents=True, exist_ok=True)

stats, issues = check_dataset(ROOT / "data.yaml", verbose=False)

cfg = yaml.safe_load((ROOT / "data.yaml").read_text(encoding="utf-8"))
names = cfg["names"]

targets = sorted({(sp, stem) for lv, sp, stem, _ in issues
                  if lv in ("ERROR", "WARN") and stem != "-"})

print("=" * 84)
print(f"문제 이미지 시각화 — {len(targets)}장")
print("=" * 84)

for sp, stem in targets:
    img_dir = ROOT / "images" / sp
    img_path = next((p for p in img_dir.iterdir() if p.stem == stem), None)
    if img_path is None:
        print(f"  · {sp}/{stem}: 이미지 없음 (고아 라벨)")
        continue
    img = cv2.imread(str(img_path))
    if img is None:
        continue
    H, W = img.shape[:2]
    txt = ROOT / "labels" / sp / f"{stem}.txt"

    if txt.exists():
        for ln, line in enumerate(txt.read_text(encoding="utf-8").splitlines(), 1):
            if not line.strip():
                continue
            parts = line.split()
            if len(parts) != 5:
                continue
            cid = int(parts[0])
            yolo = tuple(float(v) for v in parts[1:])
            ok = all(0 <= v <= 1 for v in yolo) and cid in names \
                and min(yolo[2] * W, yolo[3] * H) >= 12
            color = (60, 220, 60) if ok else (60, 60, 240)
            x1, y1, x2, y2 = B.to_int(B.clip_voc(B.yolo_to_voc(yolo, W, H), W, H))
            cv2.rectangle(img, (x1, y1), (x2, y2), color, 2)
            label = names.get(cid, f"id{cid}") if isinstance(names, dict) else f"id{cid}"
            cv2.putText(img, f"{ln}:{label}", (x1 + 3, max(y1 - 6, 16)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.5, color, 2, cv2.LINE_AA)

    msgs = [m for lv, s, st, m in issues if st == stem][:3]
    cv2.rectangle(img, (0, H - 24 * len(msgs) - 8), (W, H), (0, 0, 0), -1)
    for i, m in enumerate(msgs):
        cv2.putText(img, m[:90], (8, H - 24 * (len(msgs) - i - 1) - 12),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 200, 255), 1, cv2.LINE_AA)

    cv2.imwrite(str(OUT / f"{sp}_{stem}.jpg"), img)
    print(f"  ✓ {sp}/{stem}  →  {OUT / f'{sp}_{stem}.jpg'}")

print("-" * 84)
print("  ★ 이 이미지들을 열어서 하나씩 판단하세요.")
print("    빨간 박스 = 문제로 판정된 것. 정말 문제인지 눈으로 확인합니다.")
print("=" * 84)
```

### ① 분할 전략 3가지

**전략 A — 무작위 분할**

```python
random.shuffle(all_images)
train, val = all[:400], all[400:]
```

| | |
|---|---|
| 측정하는 것 | **"같은 영상 안에서 다른 프레임"에 대한 성능** |
| 장점 | 구현이 쉽고 클래스 균형이 자연스럽게 맞음 |
| **문제** | ★ **1초 간격 프레임이 train/val에 갈림 → 성능 부풀려짐** |
| 예상 val mAP | 0.90+ (실제보다 훨씬 높음) |

**전략 B — 영상 단위 분할**

```

camC         →  val    (약 100장)
```

| | |
|---|---|
| 측정하는 것 | **"처음 보는 각도"에 대한 성능** |
| 장점 | 누수 없음. 일반화 성능을 정직하게 측정 |
| 문제 | camC가 주간만 있어 **야간 성능을 못 봄** |
| 예상 val mAP | 0.65~0.75 (현실적) |

**전략 C — 시간 분할 (각 영상의 앞/뒤)**

```
각 영상의 앞 80% → train
각 영상의 뒤 20% → val
```

| | |
|---|---|
| 측정하는 것 | **"같은 장소, 다른 시간대"에 대한 성능** |
| 장점 | 세 영상의 특성이 train/val 모두에 들어감 |
| 문제 | 경계 근처 프레임은 여전히 비슷함 (완충 구간 필요) |
| 예상 val mAP | 0.75~0.85 |

**전략 D (추가) — 목적 지향 분할**


**★ 전략 C(시간 분할) + 완충 구간, 그리고 별도로 전략 D를 진단용으로 병행**

```python
import re
import shutil
from collections import defaultdict
from pathlib import Path

SRC_IMG = Path("C:/vision/raw/images")
SRC_LBL = Path("C:/vision/raw/labels")
DST = Path("C:/vision/datasets/cctv")

VAL_RATIO = 0.2
BUFFER = 5          # ★ 경계 앞뒤 5프레임은 버림 (누수 완충)


def parse_stem(stem):
    """camA_주간_0137 → ('camA_주간', 137)"""
    m = re.match(r"(.+)_(\d+)$", stem)
    if not m:
        return stem, 0
    return m.group(1), int(m.group(2))


def split_by_time(src_img, val_ratio=0.2, buffer=5):
    groups = defaultdict(list)
    for p in sorted(src_img.iterdir()):
        if p.suffix.lower() not in (".jpg", ".jpeg", ".png"):
            continue
        video, idx = parse_stem(p.stem)
        groups[video].append((idx, p))

    assign, dropped = {}, []
    for video, items in groups.items():
        items.sort()
        n = len(items)
        cut = int(n * (1 - val_ratio))
        for i, (idx, p) in enumerate(items):
            if cut - buffer <= i < cut + buffer:     # ★ 완충 구간
                dropped.append(p)
            elif i < cut:
                assign[p] = "train"
            else:
                assign[p] = "val"
    return assign, dropped, groups


assign, dropped, groups = split_by_time(SRC_IMG, VAL_RATIO, BUFFER)

for s in ("train", "val"):
    (DST / "images" / s).mkdir(parents=True, exist_ok=True)
    (DST / "labels" / s).mkdir(parents=True, exist_ok=True)

for p, s in assign.items():
    shutil.copy2(p, DST / "images" / s / p.name)
    txt = SRC_LBL / (p.stem + ".txt")
    target = DST / "labels" / s / (p.stem + ".txt")
    if txt.exists():
        shutil.copy2(txt, target)
    else:
        target.write_text("", encoding="utf-8")

# ── 결과 보고 ──
from collections import Counter
cnt = Counter()
per_video = defaultdict(Counter)
for p, s in assign.items():
    cnt[s] += 1
    per_video[parse_stem(p.stem)[0]][s] += 1

print("=" * 76)
print("시간 분할 결과 (완충 구간 적용)")
print("=" * 76)
print(f"  train {cnt['train']}장 / val {cnt['val']}장 / 버림 {len(dropped)}장")
print("-" * 76)
print(f"{'영상':<20}{'train':>8}{'val':>8}{'val 비율':>10}")
print("-" * 76)
for v, c in sorted(per_video.items()):
    tot = c["train"] + c["val"]
    print(f"{v:<20}{c['train']:>8}{c['val']:>8}{c['val']/tot*100:>9.1f}%")
print("=" * 76)
```

<details>
<summary>답 보기</summary>

**1.**
```
분류         : 클래스 1개
검출         : (클래스 + 박스 좌표 + 신뢰도) N개, N은 가변
의미 분할     : 픽셀마다 클래스 (개체 구분 없음)
인스턴스 분할 : 픽셀마다 클래스 + 개체 ID
```

**2.**
```
원점: 좌측 상단 (0, 0)
y축: 아래로 갈수록 증가
img.shape = (높이 H, 너비 W, 채널 C)
→ h, w = img.shape[:2]
```

**3.**
```
W=1920, H=1080, VOC (480, 270, 960, 810)

COCO:
  x = 480, y = 270
  w = 960 - 480 = 480
  h = 810 - 270 = 540
  → (480, 270, 480, 540)

YOLO:
  cx = (480 + 960)/2 / 1920 = 720 / 1920 = 0.375000
  cy = (270 + 810)/2 / 1080 = 540 / 1080 = 0.500000
  w  = 480 / 1920 = 0.250000
  h  = 540 / 1080 = 0.500000
  → (0.375000, 0.500000, 0.250000, 0.500000)
```

**4.**
```
학습 시 이미지를 반드시 리사이즈하는데(배치로 묶기 위해),
정규화 좌표는 크기가 변해도 값이 그대로 유효하기 때문.
픽셀 좌표라면 리사이즈할 때마다 라벨을 다시 계산해야 함.
```

**5.**
```
640×640 이미지, 창 64×64, 8픽셀 이동
  → 73 × 73 = 5,329
창 크기 5종 × 비율 3종 → 약 36,000회

분류 1회 3ms → 108초 / 장
게다가 창의 83%가 겹쳐 같은 픽셀을 반복 계산

YOLO는 CNN을 1회만 통과 → 0.06초
```

**6.**
```
2-stage: ① 영역 제안(~2,000개) → ② 각 후보를 분류·보정
1-stage: 격자로 나눠 각 칸이 한 번에 예측 (제안 단계 없음)

1-stage를 고른 이유
  ① 라즈베리파이에서 실행 가능해야 함 (2-stage는 0.3~0.5 FPS)
  ② 실시간 스트리밍이 요구사항
  (+ Ultralytics 생태계로 학습·배포가 간단)
```

**7.**
```
bbox = [x_min, y_min, width, height]   (픽셀)

주의점
  · category_id 는 1부터 시작하고 중간에 빈 번호가 있을 수 있음
  · 따라서 "id - 1" 은 틀림
  · categories 배열을 읽어 이름 → 우리 클래스 인덱스 매핑을 만들어야 함
  · iscrowd=1 인 annotation 은 제외
```

**8.**
```
필요한 이유
  · "여기엔 객체가 없다"를 모델에게 가르쳐 오검출(FP)을 줄임
  · 실제 CCTV 운영 시간의 대부분이 아무도 없는 상태

권장 비율: 전체의 5~15%
표현: YOLO는 .txt 가 없거나 빈 파일 (둘 다 배경으로 취급)
      ★ 빈 파일로 명시하는 편이 "확인했다"는 증거가 됨
```

**9.**
```
① 폴더 이름이 정확히 images / labels 인가       ← 1순위
② data.yaml 의 path·train·val 경로가 실제로 존재하는가
③ 이미지와 라벨의 파일명(stem)이 일치하는가
   (확장자 대소문자 포함)

+ 라벨 수정 후라면 labels/*.cache 삭제
```

**10.**
```
문제
  · 1초 간격 프레임은 거의 같은 장면
  · train에 있던 것과 거의 동일한 사진으로 채점하게 됨
  · val mAP 가 실제 성능보다 크게 부풀려짐 (예: 0.94 vs 실제 0.61)
  · 검출판 데이터 누수

대안
  ① 영상/촬영 세션 단위 분할 — 같은 영상은 한쪽에만
  ② 시간 분할 — 각 영상의 앞 80% train, 뒤 20% val
     + 경계 앞뒤 몇 프레임을 버리는 완충 구간
  ③ 최종 확인은 새로 촬영한 영상으로
```
