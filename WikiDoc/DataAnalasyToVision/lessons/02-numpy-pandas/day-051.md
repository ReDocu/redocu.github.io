W15 프로젝트 "여행지 추천"을 하려면 이런 데이터가 필요합니다.

```
관광지 이름 · 위치 · 카테고리 · 평점 · 리뷰 수 · 운영시간 · 가격
```

**이걸 어디서 구하나요?**

| 방법 | 난이도 | 안정성 | 우선순위 |
|---|---|---|---|
| ① 공개 데이터셋 | 쉬움 | 높음 | **1순위** |
| ② 공식 API | 보통 | 높음 | **2순위** |
| ③ 웹 크롤링 | 어려움 | 낮음 | **3순위** |
| ④ 직접 생성 | — | — | 최후 |

> **크롤링은 마지막 수단입니다.**
> 공개 데이터나 API 가 있으면 반드시 그쪽을 쓰세요. 더 빠르고, 안정적이고, 합법적입니다.

그리고 **오늘 배울 것 중 가장 중요한 건 기술이 아니라 판단 기준**입니다.
"이 데이터를 수집해도 되는가"를 스스로 판단할 수 있어야 합니다.

## ③ 개념 설명

### ⚠️ 수집 윤리 — 오늘의 첫 번째 주제

**이 주차를 시작하기 전에 반드시 합의합니다.**

#### 지켜야 할 원칙 7가지

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **`robots.txt` 를 확인하고 따른다** | 사이트 운영자의 명시적 의사 |
| 2 | **이용약관을 확인한다** | 약관에 수집 금지가 있으면 하지 않는다 |
| 3 | **요청 사이에 지연을 둔다** (최소 1초) | 서버 부하는 다른 이용자에게 피해 |
| 4 | **로그인·결제가 필요한 영역은 수집하지 않는다** | 인증 우회는 명백한 위반 |
| 5 | **개인정보를 수집하지 않는다** | 이름·연락처·주소 등은 법적 문제 |
| 6 | **수집 목적을 명확히 한다** | 수업 목적으로만 사용, 재배포 금지 |
| 7 | **공식 API 가 있으면 그것을 쓴다** | 크롤링은 최후 수단 |

#### 법적으로 문제가 되는 경우

| 행위 | 문제 |
|---|---|
| 과도한 요청으로 서버 마비 | **업무방해** |
| 로그인 우회·자동 가입 | **정보통신망법 위반** |
| 개인정보 수집·저장 | **개인정보보호법 위반** |
| 저작물을 그대로 재배포 | **저작권법 위반** |
| DB 를 통째로 복제 | **데이터베이스권 침해** |

> **실제 판례가 있습니다.** 국내에서 경쟁사 사이트를 대량 크롤링해
> 형사·민사 책임을 진 사례가 여러 건 있습니다.
> **"기술적으로 가능하다"는 것과 "해도 된다"는 것은 다릅니다.**

#### 이 수업의 규칙

```
① 실습은 크롤링 연습용으로 공개된 사이트에서만 합니다.
   - https://quotes.toscrape.com  (연습 전용)
   - https://books.toscrape.com   (연습 전용)

② 실제 사이트 수집은 robots.txt 확인 후, 강사와 함께 판단합니다.

③ 요청 간 최소 1초 지연을 넣습니다. 예외 없습니다.

④ 수집한 데이터는 수업 과제 외에 사용하지 않습니다.

⑤ 개인정보(이름·연락처·주소·리뷰 작성자)는 수집하지 않습니다.
```

#### robots.txt 읽는 법

모든 사이트의 `도메인/robots.txt` 에 있습니다.

```
https://example.com/robots.txt
```

```
User-agent: *              ← 모든 크롤러에게
Disallow: /admin/          ← 이 경로는 금지
Disallow: /private/
Allow: /public/            ← 이 경로는 허용
Crawl-delay: 10            ← 10초 간격 요청

User-agent: BadBot         ← 특정 크롤러에게
Disallow: /                ← 전체 금지
```

| 지시어 | 뜻 |
|---|---|
| `User-agent: *` | 모든 크롤러 대상 |
| `Disallow: /path` | 그 경로 수집 금지 |
| `Disallow: /` | **전체 금지** |
| `Allow: /path` | 허용 (Disallow 보다 우선) |
| `Crawl-delay: n` | n초 간격 요청 |
| `Sitemap: url` | 사이트맵 위치 |

**파이썬으로 확인하기**

```python
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()

rp.can_fetch("*", "https://example.com/products")     # True / False
rp.crawl_delay("*")                                    # 지연 시간
```

> **`robots.txt` 는 법적 구속력이 없지만**, 이를 무시한 수집은
> 분쟁 시 **"고의성"의 증거**가 됩니다. 반드시 확인하세요.

### HTTP — 웹의 대화 규칙

```
[브라우저]  ──── 요청(Request) ────>  [서버]
            <─── 응답(Response) ────
```

**요청의 구성**

```
GET /products?page=2 HTTP/1.1        ← 메서드, 경로, 버전
Host: example.com                     ← 헤더
User-Agent: Mozilla/5.0 ...
Accept: text/html
```

**응답의 구성**

```
HTTP/1.1 200 OK                       ← 상태 코드
Content-Type: text/html; charset=utf-8
Content-Length: 12345

<!DOCTYPE html>                       ← 본문
<html>...
```

**HTTP 메서드**

| 메서드 | 뜻 | 크롤링에서 |
|---|---|---|
| `GET` | 조회 | **대부분 이것** |
| `POST` | 생성·전송 | 검색 폼, 로그인 |
| `PUT` / `PATCH` | 수정 | 거의 안 씀 |
| `DELETE` | 삭제 | 절대 안 씀 |

**상태 코드**

| 코드 | 뜻 | 대응 |
|---|---|---|
| **200** | 성공 | 정상 처리 |
| 301 / 302 | 리다이렉트 | 자동 처리됨 |
| **403** | 접근 금지 | **수집이 차단된 것** — 중단 |
| **404** | 없음 | URL 확인 |
| **429** | 요청 과다 | **지연 시간 늘리기** |
| 500 | 서버 오류 | 재시도 (횟수 제한) |
| 503 | 일시 불가 | 나중에 재시도 |

> ⚠️ **403 이나 429 를 받으면 즉시 멈추세요.**
> "차단됐으니 우회하자"는 생각은 위반입니다. **수집하지 말라는 신호**입니다.

### URL 구조

```
https://example.com:443/products/list?category=book&page=2#section
└─┬──┘  └─────┬────┘└┬┘└──────┬────┘ └─────────┬─────────┘ └──┬──┘
프로토콜    도메인   포트    경로            쿼리 파라미터      프래그먼트
```

| 부분 | 설명 |
|---|---|
| 프로토콜 | `http` / `https` (암호화) |
| 도메인 | 서버 주소 |
| 경로 | 리소스 위치 |
| **쿼리 파라미터** | `?key=value&key2=value2` — **페이지 번호가 여기 있는 경우가 많음** |
| 프래그먼트 | `#id` — 브라우저 내부용, 서버에 전송 안 됨 |

### HTML 구조

```html
<!DOCTYPE html>
<html>
<head>
    <title>페이지 제목</title>
</head>
<body>
    <div class="container" id="main">
        <h1>제목</h1>
        <ul class="item-list">
            <li class="item" data-id="1">
                <span class="name">상품A</span>
                <span class="price">10,000원</span>
                <a href="/detail/1">상세보기</a>
            </li>
            <li class="item" data-id="2">
                <span class="name">상품B</span>
                <span class="price">20,000원</span>
            </li>
        </ul>
    </div>
</body>
</html>
```

**용어**

| 용어 | 예 | 설명 |
|---|---|---|
| **태그** | `<li>` | 요소의 종류 |
| **속성** | `class="item"` | 태그의 부가 정보 |
| **`class`** | `class="item"` | **여러 요소가 공유** |
| **`id`** | `id="main"` | **페이지에 하나만** |
| **텍스트** | `상품A` | 태그 안의 내용 |
| 자식/부모 | `<span>` 은 `<li>` 의 자식 | 계층 구조 |

### CSS 선택자 — 원하는 요소 찾기

| 선택자 | 의미 | 예 |
|---|---|---|
| `태그` | 태그 이름 | `li` |
| `.클래스` | class 값 | `.item` |
| `#아이디` | id 값 | `#main` |
| `A B` | A 안의 모든 B (자손) | `.item-list li` |
| `A > B` | A의 직계 자식 B | `ul > li` |
| `A, B` | A 또는 B | `.name, .price` |
| `[속성]` | 속성이 있는 것 | `[href]` |
| `[속성="값"]` | 속성이 정확히 일치 | `[data-id="1"]` |
| `[속성^="값"]` | ~로 시작 | `[href^="/detail"]` |
| `[속성*="값"]` | ~를 포함 | `[href*="product"]` |
| `:first-child` | 첫 자식 | `li:first-child` |
| `:nth-child(2)` | n번째 자식 | `li:nth-child(2)` |

**조합 예시**

```css
.item-list .item .name           /* 상품 이름들 */
li.item[data-id="1"]             /* data-id 가 1인 li */
#main > div.container            /* main 의 직계 자식 div.container */
a[href^="/detail"]               /* /detail 로 시작하는 링크 */
```

> **클래스가 여러 개일 때** — `class="item featured"` 는
> `.item` 으로도, `.featured` 로도, `.item.featured` 로도 선택됩니다. (점 사이 공백 없음)

### Step 1. robots.txt 확인하기

`check_robots.py`

```python
"""수집 가능 여부를 확인합니다. 크롤링 전 필수 절차."""

from urllib.parse import urlparse
from urllib.robotparser import RobotFileParser

import requests


def check_robots(url, user_agent="*", timeout=10):
    """
    robots.txt 를 확인해 수집 가능 여부를 반환합니다.

    반환: dict (allowed, crawl_delay, robots_url, raw)
    """
    parsed = urlparse(url)
    base = f"{parsed.scheme}://{parsed.netloc}"
    robots_url = f"{base}/robots.txt"

    result = {
        "url": url,
        "robots_url": robots_url,
        "allowed": None,
        "crawl_delay": None,
        "raw": None,
        "error": None,
    }

    # ── ① robots.txt 원문 가져오기 ──
    try:
        res = requests.get(robots_url, timeout=timeout,
                           headers={"User-Agent": "Mozilla/5.0 (교육용 학습)"})
        if res.status_code == 200:
            result["raw"] = res.text
        else:
            result["error"] = f"robots.txt 응답 {res.status_code}"
    except requests.RequestException as e:
        result["error"] = f"접근 실패: {type(e).__name__}"

    # ── ② 파서로 판정 ──
    try:
        rp = RobotFileParser()
        rp.set_url(robots_url)
        rp.read()

        result["allowed"] = rp.can_fetch(user_agent, url)
        result["crawl_delay"] = rp.crawl_delay(user_agent)
    except Exception as e:
        result["error"] = f"파싱 실패: {e}"

    return result


def print_report(info):
    """확인 결과를 보기 좋게 출력합니다."""
    print("=" * 70)
    print(f"  대상: {info['url']}")
    print(f"  robots.txt: {info['robots_url']}")
    print("=" * 70)

    if info["error"]:
        print(f"\n  ⚠ {info['error']}")

    allowed = info["allowed"]
    if allowed is True:
        print(f"\n  ✅ 수집 허용 (robots.txt 기준)")
    elif allowed is False:
        print(f"\n  ❌ 수집 금지 — 이 경로는 수집하지 마세요")
    else:
        print(f"\n  ❓ 판정 불가 — 수동으로 확인 필요")

    delay = info["crawl_delay"]
    if delay:
        print(f"  ⏱  Crawl-delay: {delay}초  ← 반드시 지킬 것")
    else:
        print(f"  ⏱  Crawl-delay 미지정 → 최소 1초 권장")

    if info["raw"]:
        print(f"\n  [robots.txt 내용 (앞 20줄)]")
        for line in info["raw"].splitlines()[:20]:
            print(f"    {line}")

    print("\n" + "-" * 70)
    print("  ⚠ robots.txt 허용 = 무조건 수집 가능이 아닙니다.")
    print("    이용약관도 함께 확인하세요.")
    print("=" * 70)


if __name__ == "__main__":
    # 크롤링 연습용으로 공개된 사이트
    targets = [
        "https://quotes.toscrape.com/",
        "https://books.toscrape.com/",
    ]

    for url in targets:
        info = check_robots(url)
        print_report(info)
        print()
```

실행 결과:

```
======================================================================
  대상: https://quotes.toscrape.com/
  robots.txt: https://quotes.toscrape.com/robots.txt
======================================================================

  ⚠ robots.txt 응답 404

  ❓ 판정 불가 — 수동으로 확인 필요
  ⏱  Crawl-delay 미지정 → 최소 1초 권장

----------------------------------------------------------------------
  ⚠ robots.txt 허용 = 무조건 수집 가능이 아닙니다.
    이용약관도 함께 확인하세요.
======================================================================
```

> **`robots.txt` 가 없으면(404) 어떻게 하나?**
> 명시적 금지가 없다는 뜻이지만, **허용이라는 뜻도 아닙니다.**
> 이용약관을 확인하고, 지연을 충분히 두고, 소량만 수집하세요.
>
> `quotes.toscrape.com` 과 `books.toscrape.com` 은 **크롤링 연습을 위해 만들어진 사이트**입니다.
> 실습에는 이런 사이트를 쓰세요.

### Step 2. HTTP 요청과 응답 이해하기

`http_basics.py`

```python
"""HTTP 요청과 응답의 구조를 확인합니다."""

import time

import requests

HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36 "
```

## ⑤ 자주 하는 실수

### robots.txt 를 확인하지 않고 시작

**문제** — 나중에 문제가 됐을 때 "몰랐다"는 변명이 안 됩니다.
**해결** — **수집 전 반드시 확인**하고, 확인한 내용을 기록으로 남기세요.

### 403 을 받고 User-Agent 를 바꿔 우회 시도

```python
# 403 이 나왔다고
headers = {"User-Agent": "Mozilla/5.0 ..."}      # 바꿔서 재시도
```

**문제** — 403 은 **"수집하지 말라"는 명시적 거부**입니다. 우회는 위반입니다.
**해결** — **즉시 중단**하고 다른 데이터 소스를 찾으세요.

### 지연 없이 반복 요청

```python
for page in range(1, 101):
    requests.get(f"{url}?page={page}")       # 지연 없음 → 서버 부하
```

**결과** — 429 차단, IP 차단, 최악의 경우 업무방해.
**해결** — `time.sleep(1)` 이상. `Crawl-delay` 가 있으면 그것을 따릅니다.

### 개발자도구 Copy selector 를 그대로 사용

```
#content > div:nth-child(3) > ul > li:nth-child(2) > span.name
```

**문제** — 페이지 구조가 조금만 바뀌어도 깨집니다.
**해결** — 의미 있는 클래스로 단순화하세요. `.place-item .name`

### `id` 와 `class` 를 혼동

```css
#item      /* id="item" — 페이지에 하나 */
.item      /* class="item" — 여러 개 */
```

**해결** — 여러 개를 선택하려면 `.` (클래스)를 씁니다.

### 클래스가 여러 개일 때 선택자 작성

```html
<li class="place-item featured">
```

```css
.place-item featured      /* ❌ 공백 = 자손 관계 */
.place-item.featured      /* ✅ 둘 다 가진 요소 */
```

### `select` 와 `select_one` 혼동

```python
soup.select(".name")          # 리스트 (없으면 [])
soup.select_one(".name")      # 하나 (없으면 None)

soup.select(".name").get_text()       # AttributeError — 리스트에는 없음
soup.select_one(".name").get_text()   # ✅
```

### `select_one` 결과가 `None` 인데 바로 사용

```python
name = item.select_one(".name").get_text()
```

```
AttributeError: 'NoneType' object has no attribute 'get_text'
```

**해결** — 존재를 확인합니다.

```python
el = item.select_one(".name")
name = el.get_text(strip=True) if el else ""
```

| ① | **❌ 하지 않는다** | `Disallow: /` 는 전체 수집 거부의 명시적 표현. 공개 게시판이어도 마찬가지 |
| ② | **❌ 하지 않는다** | 이용약관이 `robots.txt` 보다 **법적 구속력이 큽니다** |
| ③ | **✅ 한다** | 공식 API. 발급받은 키의 사용 조건 안에서 정당 |
| ④ | **❌ 하지 않는다** | 인증이 필요한 = 비공개 영역. 자동 로그인은 정보통신망법 위반 소지 |
| ⑤ | **⚠ 조건부** | 기술적으로는 문제없어 보이나 아래 확인 필요 |

**⑤번의 추가 확인 사항**

```
□ 수집한 데이터에 개인정보가 포함되는가?
   (작성자 이름, 프로필, 연락처 → 포함되면 중단)

□ 저작물을 그대로 복제하는가?
   (기사 전문, 사진 → 통계·분석 목적의 메타데이터만 수집)

□ 상업적으로 이용할 것인가?
   (수업 과제 = 괜찮음 / 서비스 출시 = 별도 검토 필요)

□ 재배포할 것인가?
   (GitHub 에 원본 데이터 업로드 = 하지 말 것)

□ 서버에 부담이 되는 규모인가?
   (100건 = 괜찮음 / 10만 건 = 재검토)
```

**판단 순서**

```
① 공개 데이터셋이 있는가?     → 있으면 그걸 쓴다 (끝)
② 공식 API 가 있는가?         → 있으면 그걸 쓴다 (끝)
③ robots.txt 가 허용하는가?   → 금지면 중단
④ 이용약관이 허용하는가?      → 금지면 중단
⑤ 개인정보·저작물이 있는가?   → 있으면 제외하거나 중단

⑦ 목적을 문서로 남긴다
```

**안전한 요청 함수** `safe_fetch.py`

```python
"""수집 윤리를 지키는 안전한 HTTP 요청 도구."""

import logging
import time
from urllib.parse import urlparse
from urllib.robotparser import RobotFileParser

import requests

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)
log = logging.getLogger("crawler")


class PoliteCrawler:
    """
    수집 윤리를 지키는 크롤러.

    - robots.txt 를 확인하고 따름
    - 요청 간 지연 보장
    - 403/429 수신 시 즉시 중단
    - 요청 횟수 상한
    """

    # 즉시 중단해야 하는 상태 코드
    STOP_CODES = {401, 403, 429}

    def __init__(self, delay=1.0, max_requests=200, timeout=10,
                 respect_robots=True):
        self.delay = delay
        self.max_requests = max_requests
        self.timeout = timeout
        self.respect_robots = respect_robots

        self.session = requests.Session()
        self.session.headers.update({
            "User-Agent": (
                "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                "AppleWebKit/537.36 (KHTML, like Gecko) "
                "Chrome/120.0.0.0 Safari/537.36 "
                "(educational-purpose)"
            ),
            "Accept-Language": "ko-KR,ko;q=0.9",
        })

        self.request_count = 0
        self.last_request_time = 0.0
        self._robots_cache = {}
        self.stopped = False
        self.stop_reason = None

    # ══════════ robots.txt ══════════

    def _get_robots(self, url):
        """도메인별 robots.txt 를 캐싱해 반환합니다."""
        parsed = urlparse(url)
        base = f"{parsed.scheme}://{parsed.netloc}"

        if base not in self._robots_cache:
            rp = RobotFileParser()
            rp.set_url(f"{base}/robots.txt")
            try:
                rp.read()
            except Exception as e:
                log.warning(f"robots.txt 읽기 실패 ({base}): {e}")
                rp = None
            self._robots_cache[base] = rp

        return self._robots_cache[base]

    def can_fetch(self, url):
        """robots.txt 기준 수집 가능 여부."""
        if not self.respect_robots:
            return True

        rp = self._get_robots(url)
        if rp is None:
            return True                        # 판단 불가 시 허용 (지연은 유지)

        return rp.can_fetch("*", url)

    def get_crawl_delay(self, url):
        """robots.txt 의 Crawl-delay. 없으면 기본값."""
        rp = self._get_robots(url)
        if rp is None:
            return self.delay

        delay = rp.crawl_delay("*")
        return max(delay or 0, self.delay)

    # ══════════ 요청 ══════════

    def _wait(self, required_delay):
        """직전 요청으로부터 required_delay 만큼 지날 때까지 대기."""
        elapsed = time.time() - self.last_request_time
        remaining = required_delay - elapsed
        if remaining > 0:
            time.sleep(remaining)

    def get(self, url, **kwargs):
        """
        안전하게 GET 요청을 보냅니다.

        반환: Response 또는 None (중단·거부·실패 시)
        """
        # ── 중단 상태 확인 ──
        if self.stopped:
            log.error(f"수집이 중단된 상태입니다: {self.stop_reason}")
            return None

        # ── 요청 횟수 상한 ──
        if self.request_count >= self.max_requests:
            self.stop(f"요청 상한 {self.max_requests}회 도달")
            return None

        # ── robots.txt 확인 ──
        if not self.can_fetch(url):
            log.warning(f"robots.txt 가 거부: {url}")
            return None

        # ── 지연 ──
        delay = self.get_crawl_delay(url)
        self._wait(delay)

        # ── 요청 ──
        try:
            res = self.session.get(url, timeout=self.timeout, **kwargs)
            self.last_request_time = time.time()
            self.request_count += 1

        except requests.Timeout:
            log.error(f"타임아웃: {url}")
            return None
        except requests.RequestException as e:
            log.error(f"요청 실패 ({type(e).__name__}): {url}")
            return None

        # ── 상태 코드 확인 ──
        if res.status_code in self.STOP_CODES:
            self.stop(f"HTTP {res.status_code} 수신 — 수집이 거부되었습니다")
            return None

        if res.status_code != 200:
            log.warning(f"HTTP {res.status_code}: {url}")
            return None

        log.info(f"[{self.request_count}/{self.max_requests}] "
                 f"{res.status_code} {url} ({len(res.content):,}B, "
                 f"{res.elapsed.total_seconds():.2f}s)")
        return res

    def stop(self, reason):
        """수집을 중단합니다."""
        self.stopped = True
        self.stop_reason = reason
        log.error(f"⛔ 수집 중단: {reason}")

    def report(self):
        """수집 현황을 출력합니다."""
        print("\n" + "=" * 60)
        print(f"  요청 횟수 : {self.request_count} / {self.max_requests}")
        print(f"  기본 지연 : {self.delay}초")
        print(f"  상태      : {'중단됨 — ' + self.stop_reason if self.stopped else '정상'}")
        print("=" * 60)


# ══════════ 사용 ══════════
if __name__ == "__main__":
    crawler = PoliteCrawler(delay=1.0, max_requests=5)

    urls = [
        "https://quotes.toscrape.com/",
        "https://quotes.toscrape.com/page/2/",
        "https://quotes.toscrape.com/page/3/",
    ]

    for url in urls:
        res = crawler.get(url)
        if res is None:
            break
        # 여기서 파싱 (Day 052)

    crawler.report()
```

| **`robots.txt` 자동 확인** | 잊어버릴 수 없게 코드에 내장 |
| **`Crawl-delay` 우선** | 사이트가 지정한 값을 존중 |
| **403/429 시 즉시 중단** | 우회 시도를 원천 차단 |
| **요청 횟수 상한** | 실수로 무한 루프에 빠져도 안전 |
| `Session` 재사용 | 연결을 재사용해 서버 부담 감소 |
| robots 캐싱 | 매번 robots.txt 를 요청하지 않음 |
| 로그 기록 | 무엇을 언제 수집했는지 증거로 남음 |

> **`STOP_CODES` 에 403 과 429 를 넣은 것이 핵심입니다.**
> 이 코드는 **차단을 우회할 수 없게** 만들어져 있습니다.

| HTTP | 요청/응답 · 상태 코드 200/403/404/429 |

> ② **403 이나 429 를 받으면 즉시 중단**합니다. 우회는 위반입니다.
> ③ 요청 사이에 **최소 1초 지연**을 넣으세요. 예외 없습니다.
