## ② 왜 필요한가

W02에서 배운 반복문과 함수는 **따로 배울 때는 쉬운데, 합치는 순간 어려워집니다.**

```
"게임 루프는 while, 턴 처리는 함수, 데미지 계산도 함수...
 그런데 이 함수가 저 값을 알아야 하는데 어떻게 넘기지?"
```

오늘은 새 문법을 배우지 않습니다. **이미 배운 것을 조립하는 훈련**을 합니다.

이 훈련이 중요한 이유는, 앞으로 만들 모든 것이 조립이기 때문입니다.
W08의 슈팅게임도, 대단원 02의 데이터 분석 파이프라인도, 대단원 05의 CCTV 시스템도
"작은 함수 여러 개를 어떻게 엮을 것인가"의 문제입니다.

## ③ 개념 설명

### 프로그램을 설계하는 순서

코드를 바로 치지 마세요. 이 순서를 따르면 훨씬 빠릅니다.

```
1. 무엇을 만들 것인가       — 한 문장으로 쓴다
2. 어떤 화면이 나오는가      — 종이에 그린다
3. 어떤 데이터가 필요한가    — 변수 목록을 적는다
4. 어떤 동작이 필요한가      — 함수 목록을 적는다
5. 그다음에 코드를 친다
```

### 오늘 만들 것 — 설계 예시

**1. 무엇을 만들 것인가**
> 플레이어가 몬스터와 턴제로 싸우고, 이기면 다음 몬스터가 나오는 텍스트 RPG.

**2. 화면**

```
========================================
  용사 Lv.1   HP [████████░░] 80/100
  고블린      HP [██████░░░░] 48/80
========================================
 1. 공격   2. 강공격   3. 회복   4. 도망
> 1
```

**3. 필요한 데이터**

| 데이터 | 자료형 | 설명 |
|---|---|---|
| `player_name` | str | 플레이어 이름 |
| `player_hp` / `player_max_hp` | int | 현재/최대 체력 |
| `player_attack` / `player_defense` | int | 공격력/방어력 |
| `player_potion` | int | 남은 회복약 개수 |
| `enemy_name` | str | 몬스터 이름 |
| `enemy_hp` / `enemy_max_hp` | int | 몬스터 체력 |
| `stage` | int | 현재 스테이지 |

**4. 필요한 동작(함수)**

| 함수 | 하는 일 | 반환 |
|---|---|---|
| `show_hp_bar()` | 체력 바 출력 | 없음 |
| `show_status()` | 전체 상태창 출력 | 없음 |
| `show_menu()` | 행동 메뉴 출력 | 없음 |
| `get_choice()` | 유효한 메뉴 번호를 받을 때까지 입력받기 | int |
| `calculate_damage()` | 데미지 계산 (치명타 포함) | (int, bool) |
| `create_enemy()` | 스테이지에 맞는 몬스터 생성 | (name, hp, atk, def) |
| `is_alive()` | 생존 여부 | bool |

### 함수를 나누는 기준

| 기준 | 신호 |
|---|---|
| **하나의 일만** | 함수 설명에 "그리고"가 들어가면 나눈다 |
| **20줄 이내** | 넘으면 안에서 나눌 수 있는지 본다 |
| **같은 코드가 두 번** | 두 번째 쓸 때 함수로 뺀다 |
| **깊이 3단계 이상** | `if` 안의 `for` 안의 `if` 면 안쪽을 함수로 |

> **처음부터 완벽하게 나누려 하지 마세요.** 일단 동작하게 만든 뒤, 중복이 보이면 그때 함수로 빼는 것이 현실적입니다.
> 이것을 **리팩터링**이라고 하며, [Day 030](day-030.md)에서 본격적으로 배웁니다.

### 값을 주고받는 방식

어제 배운 원칙 — **"받은 것만 보고, 결과만 돌려준다"** 를 지킵니다.

```python
# ❌ 나쁜 예 — 전역변수를 몰래 바꿈
def attack():
    global enemy_hp
    enemy_hp -= 10

# ✅ 좋은 예 — 받아서 돌려줌
def attack(enemy_hp, damage):
    return enemy_hp - damage

enemy_hp = attack(enemy_hp, 10)
```

> 클래스를 배우면([Day 016](day-016.md)) 이런 값 전달이 훨씬 깔끔해집니다.
> 오늘 "값을 계속 넘기는 게 번거롭다" 고 느끼는 것이, 다음 주 클래스를 배울 이유가 됩니다.

### Step 2. 입력 함수 만들기

잘못된 입력을 걸러 내는 함수를 만듭니다.

```python
def show_menu():
    """행동 메뉴를 출력합니다."""
    print(" 1. 공격    2. 강공격(빗나갈 수 있음)    3. 회복    4. 도망")


def get_choice(low=1, high=4):
    """low~high 사이의 숫자를 입력받을 때까지 반복합니다."""
    while True:
        answer = input("> ").strip()

        if not answer.isdigit():
            print(f"  숫자를 입력해 주세요 ({low}~{high})")
            continue

        num = int(answer)

        if num < low or num > high:
            print(f"  {low}~{high} 사이로 입력해 주세요")
            continue

        return num


# 테스트
show_menu()
choice = get_choice()
print(f"선택: {choice}")
```

실행 결과:

```
 1. 공격    2. 강공격(빗나갈 수 있음)    3. 회복    4. 도망
> abc
  숫자를 입력해 주세요 (1~4)
> 9
  1~4 사이로 입력해 주세요
> 2
선택: 2
```

> **`.isdigit()`** 은 문자열이 숫자로만 이루어졌는지 확인합니다.
> 이걸 안 쓰고 `int(input())` 을 바로 쓰면, 사용자가 글자를 입력했을 때 `ValueError` 로 프로그램이 죽습니다.
> **입력 검증을 함수 한 곳에 모으는 것**이 이 Step의 핵심입니다.

### Step 3. 전투 계산 함수 만들기

```python
import random


def calculate_damage(attack, defense, multiplier=1.0, accuracy=1.0, critical_rate=0.15):
    """
    데미지를 계산합니다.
    반환: (데미지, 치명타 여부, 명중 여부)
    """
    # 명중 판정
    if random.random() > accuracy:
        return 0, False, False

    base = attack - defense // 2
    if base < 1:
        base = 1

    damage = int(base * multiplier * random.uniform(0.85, 1.15))

    # 치명타 판정
    is_critical = random.random() < critical_rate
    if is_critical:
        damage *= 2

    return damage, is_critical, True


def show_attack_result(attacker, target, damage, is_crit, is_hit):
    """공격 결과를 문장으로 출력합니다."""
    if not is_hit:
        print(f"  {attacker}의 공격! …빗나갔다!")
        return

    mark = "  치명타!" if is_crit else ""
    print(f"  {attacker}의 공격! {target}에게 {damage}의 피해{mark}")


# 테스트
for i in range(3):
    dmg, crit, hit = calculate_damage(attack=15, defense=4, multiplier=1.8, accuracy=0.7)
    show_attack_result("용사", "고블린", dmg, crit, hit)
```

### Step 4. 몬스터 생성 함수

```python
def create_enemy(stage):
    """스테이지에 맞는 몬스터를 생성합니다. 반환: (이름, 체력, 공격력, 방어력)"""
    names = "슬라임 고블린 오크 트롤 드래곤"
    name_list = names.split()

    # 스테이지가 목록보다 크면 마지막 몬스터를 반복 사용합니다
    index = stage - 1
    if index >= len(name_list):
        index = len(name_list) - 1

    name = name_list[index]

    # 스테이지가 오를수록 강해집니다
    hp = 50 + stage * 25
    attack = 8 + stage * 4
    defense = 2 + stage * 2

    return name, hp, attack, defense


# 테스트
for s in range(1, 6):
    name, hp, atk, dfn = create_enemy(s)
    print(f"스테이지 {s}: {name} (HP {hp} / 공격 {atk} / 방어 {dfn})")
```

### Step 5. 전체 조립 (오늘의 완성본)

지금까지 만든 함수를 한 파일에 모으고 게임 루프를 붙입니다.

```python
import random


# ══════════════ 출력 함수 ══════════════

def show_hp_bar(name, current, maximum, width=10):
    """체력 바를 출력합니다."""
    if current < 0:
        current = 0
    filled = int(width * current / maximum)
    bar = "█" * filled + "░" * (width - filled)
    print(f"  {name:<10} HP [{bar}] {current}/{maximum}")


def show_status(p_name, p_hp, p_max, e_name, e_hp, e_max, stage, potion):
    """전투 상태창을 출력합니다."""
    print()
    print("=" * 44)
    show_hp_bar(p_name, p_hp, p_max)
    show_hp_bar(e_name, e_hp, e_max)
    print(f"  스테이지 {stage}   회복약 {potion}개")
    print("=" * 44)


def show_menu():
    """행동 메뉴를 출력합니다."""
    print(" 1. 공격    2. 강공격    3. 회복    4. 도망")


def show_attack_result(attacker, target, damage, is_crit, is_hit):
    """공격 결과를 문장으로 출력합니다."""
    if not is_hit:
        print(f"  {attacker}의 공격! …빗나갔다!")
        return
    mark = "  치명타!" if is_crit else ""
    print(f"  {attacker}의 공격! {target}에게 {damage}의 피해{mark}")


# ══════════════ 입력 함수 ══════════════

def get_choice(low=1, high=4):
    """low~high 사이의 숫자를 입력받을 때까지 반복합니다."""
    while True:
        answer = input("> ").strip()
        if not answer.isdigit():
            print(f"  숫자를 입력해 주세요 ({low}~{high})")
            continue
        num = int(answer)
        if num < low or num > high:
            print(f"  {low}~{high} 사이로 입력해 주세요")
            continue
        return num


# ══════════════ 계산 함수 ══════════════

def calculate_damage(attack, defense, multiplier=1.0, accuracy=1.0, critical_rate=0.15):
    """데미지를 계산합니다. 반환: (데미지, 치명타 여부, 명중 여부)"""
    if random.random() > accuracy:
        return 0, False, False

    base = attack - defense // 2
    if base < 1:
        base = 1

    damage = int(base * multiplier * random.uniform(0.85, 1.15))

    is_critical = random.random() < critical_rate
    if is_critical:
        damage *= 2

    return damage, is_critical, True


def create_enemy(stage):
    """스테이지에 맞는 몬스터를 생성합니다."""
    name_list = "슬라임 고블린 오크 트롤 드래곤".split()

    index = stage - 1
    if index >= len(name_list):
        index = len(name_list) - 1

    return name_list[index], 50 + stage * 25, 8 + stage * 4, 2 + stage * 2


def is_alive(hp):
    """살아 있는지 확인합니다."""
    return hp > 0


def heal(current_hp, max_hp, amount=40):
    """회복 후 새 체력을 반환합니다. 최대 체력을 넘지 않습니다."""
    new_hp = current_hp + amount
    if new_hp > max_hp:
        new_hp = max_hp
    return new_hp


# ══════════════ 메인 게임 ══════════════

PLAYER_MAX_HP = 120
PLAYER_ATTACK = 18
PLAYER_DEFENSE = 6

print("=" * 44)
print("          텍스트 RPG — 몬스터 사냥")
print("=" * 44)

player_name = input("용사의 이름을 입력하세요: ").strip()
if not player_name:
    player_name = "용사"

player_hp = PLAYER_MAX_HP
potion = 3
stage = 1
running = True

while running:
    # 새 몬스터 등장
    enemy_name, enemy_max_hp, enemy_attack, enemy_defense = create_enemy(stage)
    enemy_hp = enemy_max_hp

    print(f"\n★ 스테이지 {stage} — {enemy_name}(이)가 나타났다!")

    # 한 마리와의 전투
    while is_alive(player_hp) and is_alive(enemy_hp):
        show_status(player_name, player_hp, PLAYER_MAX_HP,
                    enemy_name, enemy_hp, enemy_max_hp, stage, potion)
        show_menu()
        choice = get_choice(1, 4)
        print()

        # ── 플레이어 행동 ──
        if choice == 1:                       # 일반 공격
            dmg, crit, hit = calculate_damage(PLAYER_ATTACK, enemy_defense)
            show_attack_result(player_name, enemy_name, dmg, crit, hit)
            enemy_hp -= dmg

        elif choice == 2:                     # 강공격
            dmg, crit, hit = calculate_damage(PLAYER_ATTACK, enemy_defense,
                                              multiplier=2.0, accuracy=0.6)
            show_attack_result(player_name, enemy_name, dmg, crit, hit)
            enemy_hp -= dmg

        elif choice == 3:                     # 회복
            if potion <= 0:
                print("  회복약이 없습니다! (턴을 낭비했다)")
            else:
                before = player_hp
                player_hp = heal(player_hp, PLAYER_MAX_HP)
                potion -= 1
                print(f"  회복약 사용! HP {before} → {player_hp}")

        else:                                 # 도망
            if random.random() < 0.5:
                print("  도망쳤다! 게임을 종료합니다.")
                running = False
                break
            print("  도망칠 수 없었다!")

        # 몬스터가 쓰러졌는지 확인
        if not is_alive(enemy_hp):
            break

        # ── 몬스터 행동 ──
        dmg, crit, hit = calculate_damage(enemy_attack, PLAYER_DEFENSE)
        show_attack_result(enemy_name, player_name, dmg, crit, hit)
        player_hp -= dmg

    # 전투 종료 판정
    if not running:
        break

    if not is_alive(player_hp):
        print(f"\n{player_name}은(는) 쓰러졌다…")
        print(f"최종 기록: 스테이지 {stage}")
        break

    # 승리
    print(f"\n  {enemy_name}을(를) 물리쳤다!")
    potion += 1
    player_hp = heal(player_hp, PLAYER_MAX_HP, amount=20)
    print(f"  회복약을 얻었다. (총 {potion}개)  HP가 조금 회복되었다.")

    stage += 1

    print("\n계속 진행하시겠습니까?  1. 계속   2. 여기서 종료")
    if get_choice(1, 2) == 2:
        print(f"\n모험을 마쳤습니다. 최종 스테이지: {stage - 1}")
        break

print("\n" + "=" * 44)
print("            게임 종료")
print("=" * 44)
```

## ⑤ 자주 하는 실수

### 이중 `while` 에서 `break` 가 안쪽만 끝냄

```python
while running:              # 바깥: 스테이지 반복
    while is_alive(...):    # 안쪽: 한 마리와의 전투
        if choice == 4:
            break           # 안쪽 전투만 끝남 — 게임은 계속됨
```

**원인** — `break` 는 자기가 속한 반복문 하나만 끝냅니다. ([Day 007](day-007.md))
**해결** — 위 완성본처럼 `running = False` 플래그를 세우고, 바깥에서 다시 확인합니다.

```python
if choice == 4 and random.random() < 0.5:
    running = False
    break                   # 안쪽 탈출

# ... 안쪽 while 끝난 뒤 ...
if not running:
    break                   # 바깥도 탈출
```

### 체력이 음수인데 계속 싸움

```python
while player_hp > 0 and enemy_hp > 0:
    # 플레이어 공격
    enemy_hp -= damage
    # 몬스터 공격  ← 이미 죽은 몬스터가 반격함
    player_hp -= damage
```

**원인** — 조건 검사는 반복 **시작 시점**에만 합니다. 블록 중간에 체력이 0이 돼도 그 회차는 끝까지 실행됩니다.
**해결** — 플레이어 공격 직후에 확인합니다.

```python
if not is_alive(enemy_hp):
    break
```

### 회복이 최대 체력을 넘어감

```python
player_hp += 40      # 120/120 인데 160이 됨
```

**해결** — 상한을 두는 함수를 씁니다.

```python
def heal(current_hp, max_hp, amount=40):
    new_hp = current_hp + amount
    if new_hp > max_hp:
        new_hp = max_hp
    return new_hp
```

> 체력 바 계산도 깨집니다. `int(width * 160 / 120)` = `13` 이라 `width=10` 을 넘어가 바가 이상해집니다.

### 함수에 인자가 너무 많음

```python
def show_status(p_name, p_hp, p_max, e_name, e_hp, e_max, stage, potion):
```

인자가 8개입니다. 하나만 순서가 틀려도 엉뚱한 결과가 나옵니다.

**지금의 해결** — 키워드 인자로 호출해 실수를 줄입니다.
**진짜 해결** — [Day 016 클래스](day-016.md)에서 `Player` / `Enemy` 객체로 묶으면 인자가 2개로 줄어듭니다.

```python

```

> **오늘 이 불편함을 느끼는 것이 중요합니다.** 클래스는 이 문제를 풀기 위해 존재합니다.

### 입력 검증을 빼먹어 프로그램이 죽음

```python
choice = int(input("> "))       # 사용자가 "공격" 이라고 입력하면 ValueError
```

함수 4개로 나누면 이렇게 됩니다.

```python
dmg, crit, hit = calculate_damage(enemy_attack, PLAYER_DEFENSE)

    dmg = dmg // 2
```

**포인트 3가지**

</details>

**3.** 아래 코드에는 버그가 있습니다. 몬스터를 쓰러뜨렸는데도 몬스터가 반격합니다. 원인과 해결책을 쓰세요.

```python
while is_alive(player_hp) and is_alive(enemy_hp):
    # 플레이어 공격
    dmg, crit, hit = calculate_damage(PLAYER_ATTACK, enemy_defense)
    enemy_hp -= dmg
    show_attack_result(player_name, enemy_name, dmg, crit, hit)

    # 몬스터 공격
    dmg, crit, hit = calculate_damage(enemy_attack, PLAYER_DEFENSE)
    player_hp -= dmg
    show_attack_result(enemy_name, player_name, dmg, crit, hit)
```

<details>
<summary>답 보기</summary>

**원인** — `while` 의 조건은 **반복이 시작될 때 한 번만** 검사합니다.
플레이어 공격으로 `enemy_hp` 가 0 이하가 되어도, 그 회차의 나머지 코드(몬스터 공격)는 그대로 실행됩니다.

실제 출력:

```
  용사의 공격! 고블린에게 30의 피해     ← 고블린 HP -5
  고블린의 공격! 용사에게 12의 피해     ← 죽은 고블린이 반격!
```

**해결** — 플레이어 공격 직후에 생존을 확인하고 `break` 합니다.

```python
while is_alive(player_hp) and is_alive(enemy_hp):
    # 플레이어 공격
    dmg, crit, hit = calculate_damage(PLAYER_ATTACK, enemy_defense)
    enemy_hp -= dmg
    show_attack_result(player_name, enemy_name, dmg, crit, hit)

    if not is_alive(enemy_hp):        # ← 추가
        break

    # 몬스터 공격
    dmg, crit, hit = calculate_damage(enemy_attack, PLAYER_DEFENSE)
    player_hp -= dmg
    show_attack_result(enemy_name, player_name, dmg, crit, hit)
```

> **교훈** — 반복문 안에서 상태가 바뀌면, **그 자리에서 바로 확인**해야 합니다.
> "조건은 반복 시작 시점에만 검사한다"는 것이 이런 버그의 근원입니다. W05의 게임 충돌 판정에서도 똑같은 문제가 나옵니다.
</details>
