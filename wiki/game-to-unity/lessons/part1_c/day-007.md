# Day 007 · break / continue — 루프에서 빠져나가기

> **Week 2** · 연결 문서 `02 탈출 루프` — Step 2
> 선수: Day 006 (반복문 3종)

---

## 1. 오늘 만드는 것

메뉴에 **0번(종료)** 이 생기고, 잘못된 입력은 시간을 소모하지 않는다.

```
---------------------------------
[ 남은 시간 20 ]

무엇을 하시겠습니까?
  1. 주변을 둘러본다
  2. 문을 살펴본다
  3. 소리를 지른다
  0. 포기한다

선택: 9

그런 선택지는 없다. (시간은 흐르지 않는다)

---------------------------------
[ 남은 시간 20 ]        ← 줄지 않았다

...

선택: 0

당신은 탈출을 포기했다.

=================================
       G A M E   O V E R
       남은 시간  17
=================================
```

**조작** — 0~3 입력. 0을 누르면 정상 종료된다.

## 2. 막히는 상황

어제 코드에는 두 가지 문제가 있다.

**문제 1 — 나가는 문이 없다**

```c
while (timeLeft > 0)
{
    // ... 메뉴 ...
    timeLeft--;
}
```

열쇠를 찾아 문을 열어도 **시간이 다 될 때까지 20번을 채워야** 끝난다.
게임을 그만두고 싶어도 방법은 `Ctrl + C`뿐이다.

**문제 2 — 잘못된 입력도 시간을 먹는다**

```
선택: 9
그런 선택지는 없다.
[ 남은 시간 19 ]      ← 오타 하나에 1턴을 잃는다
```

```
   지금:   ┌──────────────────┐
           │  본문 전체 실행   │  ← 무슨 일이 있어도 끝까지 간다
           └──────────────────┘

   필요:   ┌──────────────────┐
           │  ─── break ──────┼──▶ 루프 완전 탈출
           │  ─── continue ───┼──▶ 이번 회차만 건너뛰고 다음으로
           └──────────────────┘
```

> **루프 중간에서 나가거나 건너뛰는 방법이 필요하다.** → **`break` / `continue`**

---

## 3. 개념

### 3-1. `break` — 루프를 즉시 탈출

**왜 필요한가** — 종료 조건을 만족한 순간 더 돌 이유가 없다.

```c
while (1)
{
    printf("선택: ");
    scanf_s("%d", &choice);

    if (choice == 0)
    {
        printf("종료합니다.\n");
        break;                    // ★ 여기서 루프 완전 탈출
    }

    printf("계속 진행\n");
}

printf("루프 밖입니다.\n");        // break 하면 여기로 온다
```

```
   while (1)
   {
       ...
       if (조건) break;  ──────┐
       ...                     │
   }                           │
   printf("루프 밖");  ◀───────┘
```

### 3-2. `continue` — 이번 회차만 건너뛰기

**왜 필요한가** — "이번 입력은 무효니까 아래 처리를 하지 말고 다시 물어봐라".

```c
while (timeLeft > 0)
{
    printf("선택: ");
    scanf_s("%d", &choice);

    if (choice < 0 || choice > 3)
    {
        printf("그런 선택지는 없다.\n");
        continue;                 // ★ 아래를 건너뛰고 루프 처음으로
    }

    // ... 정상 처리 ...
    timeLeft--;                   // 잘못된 입력일 때는 여기 도달 안 함
}
```

```
   while (조건)
   {
       ...
       if (무효) continue;  ──┐
       ...                    │
       timeLeft--;            │  ← 건너뛴다
   }  ◀──────────────────────┘  루프 처음으로 (조건 검사부터)
```

**`break` vs `continue`**

| | `break` | `continue` |
|---|---|---|
| 하는 일 | 루프를 **완전히** 나간다 | **이번 회차만** 건너뛴다 |
| 다음 실행 위치 | 루프 **다음 줄** | 루프 **조건 검사** |
| 쓰는 곳 | 종료, 탈출 성공, 찾았음 | 무효 입력, 건너뛸 항목 |

```
   for (i = 0; i < 5; i++)              for (i = 0; i < 5; i++)
   {                                    {
       if (i == 2) break;                   if (i == 2) continue;
       printf("%d ", i);                    printf("%d ", i);
   }                                    }
   출력: 0 1                            출력: 0 1 3 4
                                                  ▲ 2만 빠졌다
```

### 3-3. ⚠️ `switch` 안의 `break`는 루프를 못 벗어난다

**왜 필요한가** — 오늘 가장 많이 나오는 오류다.

```c
while (1)
{
    scanf_s("%d", &choice);

    switch (choice)
    {
    case 0:
        printf("종료\n");
        break;              // ✘ switch만 빠져나간다. while은 계속 돈다!
    case 1:
        printf("공격\n");
        break;
    }
}
```

```
   while (1)
   {
       switch (choice)
       {
       case 0:
           break;  ──────┐
       }                 │
       ◀─────────────────┘   ← 여기까지만 온다. while은 그대로
       (다시 위로)
   }
```

**해결 방법 — 플래그 변수**

```c
int running = 1;                     // 게임이 돌고 있는가

while (running)
{
    scanf_s("%d", &choice);

    switch (choice)
    {
    case 0:
        printf("종료\n");
        running = 0;                 // ✔ 조건 자체를 거짓으로 만든다
        break;                       //   (switch 탈출용)
    case 1:
        printf("공격\n");
        break;
    }
}
```

> **플래그 변수 패턴**은 앞으로 계속 쓴다.
> Day 21의 게임 루프도 `while (running)`, Day 38의 WINAPI 게임 루프도 `while (running)`이다.

### 3-4. 중첩 루프에서의 `break`

**왜 필요한가** — `break`는 **가장 안쪽 루프 하나만** 벗어난다.

```c
for (int y = 0; y < 3; y++)
{
    for (int x = 0; x < 3; x++)
    {
        if (map[y][x] == 'E')
            break;              // 안쪽 for만 탈출. 바깥 for는 계속
    }
    // ← 여기로 온다
}
```

```
   for (y)
   {
       for (x)
       {
           break;  ──┐
       }             │
       ◀─────────────┘   ← 여기까지. 바깥 y 루프는 계속 돈다
   }
```

**해결 — 플래그 변수**

```c
int found = 0;

for (int y = 0; y < 3 && !found; y++)      // 조건에 플래그 추가
{
    for (int x = 0; x < 3; x++)
    {
        if (map[y][x] == 'E')
        {
            found = 1;
            break;
        }
    }
}
```

> C에는 여러 겹을 한 번에 나가는 문법이 없다. (`goto`는 있지만 권장하지 않는다)
> **플래그 변수** 또는 **함수로 분리해서 `return`** 을 쓴다.

### 3-5. 게임 루프의 다중 종료 경로

**왜 필요한가** — 게임은 끝나는 방법이 여러 가지다. 각각을 구분해야 결말도 달라진다.

```
   ┌─────────────────────────────────────────────┐
   │  while (running)                             │
   │                                              │
   │    ├─ 시간 초과      → running = 0, ending = TIMEOUT
   │    ├─ 사용자 종료    → running = 0, ending = QUIT
   │    ├─ 탈출 성공      → running = 0, ending = ESCAPE
   │    └─ 사망           → running = 0, ending = DEAD
   │                                              │
   └─────────────────────────────────────────────┘
                        │
                        ▼
              ending 값에 따라 다른 결말 출력
```

```c
#define ENDING_NONE     0
#define ENDING_TIMEOUT  1
#define ENDING_QUIT     2
#define ENDING_ESCAPE   3

int running = 1;
int ending  = ENDING_NONE;

while (running)
{
    if (timeLeft <= 0) { running = 0; ending = ENDING_TIMEOUT; continue; }
    // ...
}

// 루프 밖에서 결말 처리
if (ending == ENDING_TIMEOUT)  printf("시간이 다 되었다...\n");
else if (ending == ENDING_QUIT) printf("당신은 포기했다.\n");
else if (ending == ENDING_ESCAPE) printf("탈출 성공!\n");
```

> 이 `ending` 변수가 내일 배울 **상태 변수**이고, Day 17의 `enum`으로 다듬어진다.

## 4. 따라 만들기

### Step 1 — 종료 메뉴 추가 (`break`)

```c
    while (timeLeft > 0)
    {
        printf("\n---------------------------------\n");
        printf("[ 남은 시간 %d ]\n", timeLeft);

        printf("\n무엇을 하시겠습니까?\n");
        printf("  1. 주변을 둘러본다\n");
        printf("  2. 문을 살펴본다\n");
        printf("  3. 소리를 지른다\n");
        printf("  0. 포기한다\n");                    // ← 추가
        printf("\n선택: ");

        int choice = 0;
        scanf_s("%d", &choice);

        if (choice == 0)                              // ← 추가
        {
            printf("\n당신은 탈출을 포기했다.\n");
            break;                                    // ← 루프 탈출
        }

        // ... 기존 처리 ...
        timeLeft--;
    }
```

**✅ 여기까지 실행하면** — 0을 입력하면 "탈출을 포기했다"가 뜨고 프로그램이 **정상 종료**된다.

### Step 2 — 잘못된 입력 건너뛰기 (`continue`)

```c
        int choice = 0;
        scanf_s("%d", &choice);

        if (choice == 0) { /* ... break ... */ }

        if (choice < 0 || choice > 3)                        // ← 추가
        {
            printf("\n그런 선택지는 없다. (시간은 흐르지 않는다)\n");
            continue;                                        // ← 아래 건너뛰기
        }

        // ... 정상 처리 ...
        timeLeft--;              // continue 하면 여기 도달 안 함
```

**✅ 여기까지 실행하면** — 9를 입력해도 `남은 시간`이 줄지 않고 그대로 20이다.

### Step 3 — 플래그 변수로 바꾸기

`break`를 여러 군데 쓰면 흐름이 흩어진다. 플래그로 정리한다.

```c
    int running   = 1;            // ← 추가
    int timeLeft  = 20;
    int ending    = 0;            // ← 추가  0=없음 1=시간초과 2=포기 3=탈출

    while (running)               // ← timeLeft > 0 에서 변경
    {
        if (timeLeft <= 0)                       // ← 추가
        {
            running = 0;
            ending  = 1;
            continue;                            // 바로 루프 조건 검사로
        }

        // ... 메뉴 출력 ...

        int choice = 0;
        scanf_s("%d", &choice);

        if (choice == 0)
        {
            running = 0;                         // ← break 대신
            ending  = 2;
            continue;
        }

        if (choice < 0 || choice > 3) { /* continue */ }

        // ... 정상 처리 ...
        timeLeft--;
    }
```

**✅ 여기까지 실행하면** — 동작은 Step 2와 동일하지만, 종료 지점이 `running = 0` 한 가지로 통일된다.

### Step 4 — 결말 분기

```c
    // 루프 밖
    printf("\n=================================\n");

    if (ending == 1)
    {
        printf("       T I M E   O V E R\n");
        printf("  문은 영원히 잠겼다.\n");
    }
    else if (ending == 2)
    {
        printf("       G A M E   O V E R\n");
        printf("  당신은 포기했다.\n");
    }
    else if (ending == 3)
    {
        printf("       E S C A P E !\n");
        printf("  당신은 방을 빠져나왔다.\n");
    }

    printf("       남은 시간  %d\n", timeLeft);
    printf("=================================\n");
```

**✅ 여기까지 실행하면** — 종료 방식에 따라 다른 결말 화면이 나온다.

<!-- SHOT: Step 4 실행 화면 -->

### Step 5 — `switch`로 정리 (`break` 함정 확인)

```c
        switch (choice)
        {
        case 1:
            printf("\n먼지 쌓인 책상이 있다. 서랍이 잠겨 있다.\n");
            break;                    // switch 탈출용
        case 2:
            printf("\n두꺼운 철문이다. 열쇠 구멍이 보인다.\n");
            break;
        case 3:
            printf("\n아무도 대답하지 않는다.\n");
            break;
        }

        timeLeft--;
```

> 여기서 `case 0:`에 `break;`만 쓰면 **게임이 안 끝난다.** 반드시 `running = 0;`을 함께 넣는다.
> 직접 `running = 0`을 빼고 실행해서 **무한 반복되는 것을 확인**하고 넘어간다.

**✅ 여기까지 실행하면** — Step 4와 동일하게 동작하며, `switch` 구조로 정리된다.

### Step 6 — 시도 횟수 제한 (확장)

```c
    int shoutCount = 0;                     // 소리 지른 횟수

    // case 3 안에서
    shoutCount++;
    if (shoutCount >= 3)
    {
        printf("목이 완전히 쉬었다. 더는 소리 지를 수 없다.\n");
    }
    else
    {
        printf("아무도 대답하지 않는다. (%d/3)\n", shoutCount);
    }
```

**✅ 여기까지 실행하면** — 같은 행동을 3번 하면 더는 못 하게 된다.

## 5. 실행 결과

**정상이라면 이렇게 보인다.**

```
---------------------------------
[ 남은 시간 20 ]

무엇을 하시겠습니까?
  1. 주변을 둘러본다
  2. 문을 살펴본다
  3. 소리를 지른다
  0. 포기한다

선택: 9

그런 선택지는 없다. (시간은 흐르지 않는다)

---------------------------------
[ 남은 시간 20 ]

선택: 1

먼지 쌓인 책상이 있다. 서랍이 잠겨 있다.

---------------------------------
[ 남은 시간 19 ]

선택: 0

당신은 탈출을 포기했다.

=================================
       G A M E   O V E R
  당신은 포기했다.
       남은 시간  19
=================================
```

- [ ] 0을 입력하면 프로그램이 **정상 종료**된다 (`Ctrl+C` 불필요)
- [ ] 잘못된 숫자를 넣으면 시간이 줄지 않는다
- [ ] 시간이 0이 되면 시간 초과 결말이 나온다
- [ ] 종료 방식에 따라 결말 메시지가 다르다
- [ ] `switch` 안의 `break`만으로는 루프가 안 끝난다는 것을 확인했다

## 6. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 0을 눌러도 안 끝남 | `switch`의 `break`가 루프를 못 벗어남 | `running = 0;` 플래그 사용 |
| `continue` 후 무한 루프 | `while`에서 증감을 건너뜀 | 증감을 `continue` **위**로 옮기거나 `for` 사용 |
| 중첩 루프에서 안 나가짐 | `break`는 한 겹만 | 플래그 변수 또는 함수 `return` |
| 결말이 항상 하나만 나옴 | `if/else if` 순서, 또는 `ending` 미설정 | 종료 지점마다 `ending` 대입 확인 |
| `break` 뒤 코드가 실행 안 됨 | 정상. `break` 아래는 도달 불가 | 순서 재배치 |
| 루프를 나왔는데 값이 이상함 | 루프 안에서 선언한 변수를 밖에서 참조 | 루프 밖에서 선언 |
| 종료 후에도 창이 안 닫힘 | `Ctrl+F5`의 정상 동작 | "아무 키나 누르십시오" 확인 |

## 7. 정리

### 오늘 배운 것

| 개념 | 한 줄 요약 |
|---|---|
| `break` | 루프를 **완전히** 나간다 |
| `continue` | **이번 회차만** 건너뛰고 조건 검사로 돌아간다 |
| `switch`의 `break` | **switch만** 벗어난다. 루프는 안 끝난다 |
| 플래그 변수 | `while (running)` — 종료 지점을 한 곳으로 통일 |
| 중첩 루프 탈출 | `break`는 한 겹만. 플래그 또는 함수 분리 |
| 다중 종료 경로 | 어떻게 끝났는지를 기록해야 결말이 달라진다 |

### 직접 해보기

| 난이도 | 과제 | 힌트 |
|:--:|---|---|
| ★ | 같은 행동을 5번 반복하면 자동 종료 | 카운터 + `running = 0` |
| ★★ | 1~100 중 소수만 출력 (합성수는 `continue`) | 나누어떨어지면 `continue` |
| ★★★ | 5×5 격자에서 특정 값을 찾아 좌표 출력 후 이중 루프 탈출 | 플래그 변수 또는 함수로 분리해 `return` |
